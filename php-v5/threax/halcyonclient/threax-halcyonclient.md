# threax/halcyonclient

> 标签: PHP

## 简介

Connect to .Net Core Api servers using Threax.AspNetCore.Halcyon.Ext

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
