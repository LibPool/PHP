# uncgits/cirqlive-api-php-library

> 标签: api, cirqlive, php, uncg, uncgits

## 简介

PHP Library used to interact with the CirQlive API for UNCG

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
