# robquistnl/simplehtmltotext

> 标签: HTMLToText, html2text, simplehtml2text

## 简介

A Simple PHP Class to transform HTML to Text

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
