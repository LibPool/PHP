# undkonsorten/typo3-site-config-modifier

> 标签: TypoScript, modifier, site config

## 简介

Adds the new TypoScript modifier := getSiteConfig() for TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
