# flyingflip/oauth2-fitbit

> 标签: Authentication, authorization, client, fitbit, oauth, oauth2

## 简介

Fitbit OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
