# mojave-hq/bricks

> 标签: plugins, wordpress

## 简介

Bricks is a WordPress starter plugin to quickly and cleanly build Gutenberg blocks with Tailwind CSS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
