# eclemens/php-validation

> 标签: jquery-validation, php-validation, validation, validator

## 简介

PHP Validation class inspired by the jQuery Validation Plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
