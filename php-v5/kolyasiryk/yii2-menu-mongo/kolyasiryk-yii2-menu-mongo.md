# kolyasiryk/yii2-menu-mongo

> 标签: list creator, menu, mongo, yii2

## 简介

Yii2 module for menu creation adaptive for MongoDB.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
