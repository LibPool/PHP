# webnexx/carcopy-api-client

> 标签: carapi, client, soap

## 简介

a client to use the carapi from CarCopy https://www.carcopy.com/fahrzeugdaten-api/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
