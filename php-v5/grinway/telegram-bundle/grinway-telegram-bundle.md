# grinway/telegram-bundle

> 标签: Telegram-Bot-API, bundle, grinway, symfony, symfony-ux, telegram-bot, telegram-bundle

## 简介

This bundle is intended to create telegram bots

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
