# phalcongelist/php-diff

> 标签: diff, phalcon, php

## 简介

A comprehensive library for generating differences between two hashable objects (strings or arrays).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
