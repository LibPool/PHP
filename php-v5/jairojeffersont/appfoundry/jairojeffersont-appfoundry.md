# jairojeffersont/appfoundry

> 标签: PHP

## 简介

Esqueleto básico de uma aplicação PHP desenvolvida com Slim Framework, Twig e Eloquent ORM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
