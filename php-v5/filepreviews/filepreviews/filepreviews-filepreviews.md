# filepreviews/filepreviews

> 标签: OCR, Thumbnails, exif, file, metadata, previews

## 简介

PHP client library for FilePreviews.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
