# shopsys/phpstorm-inspect

> 标签: code quality, inspection, phpstorm

## 简介

Package for running PhpStorm's inspections from CLI and displaying results

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
