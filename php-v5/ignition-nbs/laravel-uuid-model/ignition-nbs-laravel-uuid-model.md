# ignition-nbs/laravel-uuid-model

> 标签: PHP

## 简介

Enable Laravel's Eloquent Model to be identified by UUID (string) rather than ID (increment or bigIncrement)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
