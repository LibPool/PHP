# lenh/laravel-multichain-api

> 标签: api, blockchain, laravel, multichain

## 简介

Laravel 5 wrapper for the Mulitchain php library by Kunstmaan (http://www.kunstmaan.be/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
