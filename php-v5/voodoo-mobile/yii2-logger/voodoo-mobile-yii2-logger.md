# voodoo-mobile/yii2-logger

> 标签: component, logger, redis, slack, voodoo-mobile, yii, yii 2, yii2

## 简介

Additional Redis and Slack log target for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
