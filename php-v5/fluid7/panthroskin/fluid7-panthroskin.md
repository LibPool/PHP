# fluid7/panthroskin

> 标签: PHP

## 简介

PanthroSkin is a skinning tool to pull website elements from a Panthro CMS powered website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/fluid7/panthroskin
- Packagist 页面：https://packagist.org/packages/fluid7%2Fpanthroskin

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require fluid7/panthroskin`
- Packagist 仓库：https://repo.packagist.org/p2/fluid7/panthroskin.json
- PHP 要求：>=5.6.0
