# azakur4/lum-pdf

> 标签: dompdf, laravel, lumen, pdf

## 简介

compatibility fork of k98kurz/pdf-lumen (dompdf wrapper) for Laravel Lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
