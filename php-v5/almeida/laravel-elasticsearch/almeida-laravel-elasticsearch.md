# almeida/laravel-elasticsearch

> 标签: elasticsearch, laravel

## 简介

Laravel 4.2+ wrapper for ElasticSearch

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
