# ops-talent/apibundle

> 标签: Symfony 3, api, elasticsearch, redis, restful

## 简介

Basic RESTful api bundle + oauth2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
