# dunrocom/libphonenumber-for-php

> 标签: geocoding, geolocation, libphonenumber, mobile, phonenumber, validation

## 简介

PHP Port of Google's libphonenumber

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
