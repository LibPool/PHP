# bravo3/image-manager

> 标签: aws, azure, google cloud, image

## 简介

A PHP 5.4 library to control dynamic image assets in a cloud environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
