# meanbee/royalmail-php-library

> 标签: PHP Library, meanbee, royalmail, shipping method

## 简介

PHP library for Royal Mail shipping shipping methods

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
