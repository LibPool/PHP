# messageagency/ma_gridmenu

> 标签: PHP

## 简介

This module and core patch patch provides the necessary codebase to add grid-style children menus to Drupal 8 sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
