# alihann/laravel-rockid

> 标签: decrypt, encrypt, ids, laravel, obfuscate, optimus, rockid

## 简介

Laravel package for id obfuscation using jenssegers/optimus.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
