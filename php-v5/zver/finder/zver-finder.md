# zver/finder

> 标签: directories, directory, file, files, find, finder, folder, folders, zver

## 简介

Class to find files and folders, apply callbacks to it and etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
