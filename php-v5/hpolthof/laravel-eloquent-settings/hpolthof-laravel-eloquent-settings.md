# hpolthof/laravel-eloquent-settings

> 标签: database, eloquent, laravel

## 简介

Allow for dynamic blobbed settings in Eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
