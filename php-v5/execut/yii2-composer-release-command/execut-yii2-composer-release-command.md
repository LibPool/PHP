# execut/yii2-composer-release-command

> 标签: yii2 composer, yii2 git helper, yii2 packagist

## 简介

Yii2 command for fast releasing and versioning composer packages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
