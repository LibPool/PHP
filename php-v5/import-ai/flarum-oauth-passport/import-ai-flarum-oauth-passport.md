# import-ai/flarum-oauth-passport

> 标签: flarum, laravel, oauth, passport

## 简介

Laravel Passport OAuth provider for Flarum - standalone implementation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
