# elliptic/elliptic-sdk

> 标签: PHP

## 简介

Elliptic SDK for PHP - A Guzzle wrapper for connecting to Elliptic APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
