# dmstr/yii2-json-editor

> 标签: json, json-editor, yii2

## 简介

Yii2 wrapper for "json-editor/json-editor" (is a fork of "jdorn/json-editor")

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
