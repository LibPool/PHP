# halleck45/phpmetrics-collector-bundle

> 标签: phpmetrics, symfony, symfony4, symfony5

## 简介

Display PhpMetrics informations in Symfony Debug bar

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
