# chriscubos/assets

> 标签: Chriscubos, Laravel Package Builder, packagist

## 简介

Make Building a Laravel Package with Assets easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Packagist 页面：https://packagist.org/packages/chriscubos%2Fassets
