# yikesinc/yikes-inc-easy-mailchimp-extender

> 标签: list, mailchimp, mailing, plugin, wordpress

## 简介

Powerful Mailchimp plugin for WordPress created by Code Parrots.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
