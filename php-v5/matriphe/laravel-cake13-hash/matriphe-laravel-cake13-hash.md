# matriphe/laravel-cake13-hash

> 标签: cake, laravel, password, sha1

## 简介

Laravel 5 package to use legacy CakePHP 1.3 for password hash

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
