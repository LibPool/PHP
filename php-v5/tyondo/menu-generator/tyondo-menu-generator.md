# tyondo/menu-generator

> 标签: admin, laravel, menu, nav, navigation

## 简介

Backend navigation menu generator for Laravel 5.3 and 5.4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
