# datafactory/http-cache

> 标签: caching, http, invalidation, nginx, purge, varnish

## 简介

Tools to manage HTTP caching proxies with PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
