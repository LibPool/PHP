# urmaul/gravacage

> 标签: avatar, gravatar, nicolas cage

## 简介

Gravatar class that inserts Nicolas Cage into default avatars.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
