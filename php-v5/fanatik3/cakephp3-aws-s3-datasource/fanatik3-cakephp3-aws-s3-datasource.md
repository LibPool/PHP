# fanatik3/cakephp3-aws-s3-datasource

> 标签: aws, cakephp3, datasource, s3

## 简介

AWS S3 datasource in CakePHP3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
