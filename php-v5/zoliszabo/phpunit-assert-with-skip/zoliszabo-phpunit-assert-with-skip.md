# zoliszabo/phpunit-assert-with-skip

> 标签: PHP

## 简介

Conditional PHPUnit assertions that skip tests instead of failing when rules are met.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
