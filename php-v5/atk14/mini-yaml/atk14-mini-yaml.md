# atk14/mini-yaml

> 标签: yaml

## 简介

Minimalistic YAML loader and dumper for PHP supporting nested structures, block scalars and PHP template evaluation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
