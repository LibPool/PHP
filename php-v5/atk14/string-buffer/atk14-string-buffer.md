# atk14/string-buffer

> 标签: Buffer, buffering, string, strings

## 简介

StringBuffer is a PHP class providing operations for efficient string buffering

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
