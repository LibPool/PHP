# atk14/csv-writer

> 标签: csv, export, exporter, writer, xls, xlsx

## 简介

Writes CSV into string output or a file. Also provides export to XLSX format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
