# atk14/api-data-fetcher

> 标签: api, atk14, client, restful

## 简介

PHP client library for communication with ATK14 RESTful APIs and other JSON APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
