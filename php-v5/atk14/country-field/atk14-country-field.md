# atk14/country-field

> 标签: Forms, atk14, country, field, localized

## 简介

Country select field localized for every single language. It is intended to be used in ATK14 Forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
