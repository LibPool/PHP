# photonsh/photon-php

> 标签: highlight, photon, php, syntax

## 简介

photon-php is a PHP library for Photon

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://photon.sh
- 源码仓库：https://github.com/photonsh/photon-php.git
- Packagist 页面：https://packagist.org/packages/photonsh%2Fphoton-php
