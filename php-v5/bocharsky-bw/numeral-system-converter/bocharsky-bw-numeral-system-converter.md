# bocharsky-bw/numeral-system-converter

> 标签: binary, converter, decimal, hexadecimal, numeral system, octal, radix

## 简介

Convert numbers to different numeral systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
