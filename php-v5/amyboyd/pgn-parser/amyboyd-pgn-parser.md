# amyboyd/pgn-parser

> 标签: PHP

## 简介

A PHP parser for the chess game notation format, PGN. There are no external dependencies. It's simple to use, namespaced and testable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
