# shinsenter/defer.php

> 标签: HTML minify, PHP Library, PageSpeed, avoid render blocking, defer, defer.php, dom optimization, gtmetrix, lazy loading, lazyload, lazyload css, lazyload facebook, lazyload font, lazyload image, lazyload js, lazyload video, lazyload wordpress, lazyload youtube, loading lazy, page speed, site performance, speed optimization

## 简介

🚀 A PHP library that focuses on minimizing payload size of HTML document and optimizing processing on the browser when rendering the web page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
