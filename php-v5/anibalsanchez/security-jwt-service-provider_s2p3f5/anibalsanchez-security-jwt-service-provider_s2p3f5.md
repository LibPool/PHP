# anibalsanchez/security-jwt-service-provider_s2p3f5

> 标签: PHP

## 简介

Silex Security JWT Service Provider, updated to Silex 2.2, Pimple 3 and Firebase 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
