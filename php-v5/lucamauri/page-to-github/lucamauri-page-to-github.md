# lucamauri/page-to-github

> 标签: github, lua, mediawiki, mediawiki-extension, sync

## 简介

Allow the transport of page content to GitHub on page save

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
