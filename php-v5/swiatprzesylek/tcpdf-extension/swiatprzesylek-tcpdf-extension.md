# swiatprzesylek/tcpdf-extension

> 标签: TCPDF, generator, pdf, php

## 简介

This library extends the TCPDF library for example with a smart API for creating tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
