# enlitepro/enlite-seo

> 标签: framework, helper, seo, zend framework 2, zf2

## 简介

Adds an entity, a helper for control SEO tags in ZF2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
