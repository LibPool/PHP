# acseo/wp-acseo-migrations

> 标签: wordpress

## 简介

A WordPress plugin for managing upgrades and data from the Wordpress backoffice or from the console.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
