# innoscience/comrade-opml

> 标签: opml, rss

## 简介

Comrade need help with OPML, da? We read and write OPML data together no problem. It to spec & simple too, with PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
