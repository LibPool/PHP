# tecbeast/laravel-frontend-rights

> 标签: PHP

## 简介

A package for Laravel 5.1+ where you can restrict certain routes from frontend to a set of roles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
