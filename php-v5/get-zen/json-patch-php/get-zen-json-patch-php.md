# get-zen/json-patch-php

> 标签: PHP

## 简介

Produce and apply json-patch objects. Forked from mikemccabe/json-patch-php (https://github.com/mikemccabe/json-patch-php).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
