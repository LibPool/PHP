# bloke/smd_thumbnail

> 标签: images, multiple, plugin, sizes, src-set, textpattern

## 简介

Multiple image thumbnails of arbitrary dimensions within Textpattern CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
