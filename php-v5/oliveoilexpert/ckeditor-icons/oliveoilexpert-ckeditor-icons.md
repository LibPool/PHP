# oliveoilexpert/ckeditor-icons

> 标签: CKEditor, FontAwesome, editor, icons, plugin, typo3

## 简介

Adds an icon dropdown to CKEditor in TYPO3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
