# philetaylor/php-gpglib

> 标签: encryption, gpg

## 简介

A wrapper around GPG for stateless operations. PSR/Log 1.0+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
