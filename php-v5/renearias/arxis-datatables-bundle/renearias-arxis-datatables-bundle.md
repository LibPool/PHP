# renearias/arxis-datatables-bundle

> 标签: Symfony2, datagrid, datatable, grid, pagination, table

## 简介

Symfony2 Datatable Bundle For Doctrine2 Entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
