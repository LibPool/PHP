# esperance/esperance-phpunit

> 标签: BDD, TDD, assertion, phpunit

## 简介

PHPUnit TestCase class integrated with Esperance assertion library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
