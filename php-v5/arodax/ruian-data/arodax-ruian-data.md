# arodax/ruian-data

> 标签: ruian, ruian-data

## 简介

This Symfony bundle provides data for RÚIAN, usually used with arodax/ruian-bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
