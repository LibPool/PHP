# texthtml/mediawiki-oauth2-auth

> 标签: auth, extension, login, mediawiki, oauth2

## 简介

Authenticate Mediawiki from external OAuth2 server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
