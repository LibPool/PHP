# nwidart/laravel-forecast

> 标签: forecast, laravel, weather

## 简介

Laravel-forecast provides a service provider and a facade around the Forecast-php wrapper

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
