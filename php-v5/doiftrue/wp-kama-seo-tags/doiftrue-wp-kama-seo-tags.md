# doiftrue/wp-kama-seo-tags

> 标签: wordpress

## 简介

Simple SEO class for WordPress to create page metatags: title, description, robots, keywords, Open Graph.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
