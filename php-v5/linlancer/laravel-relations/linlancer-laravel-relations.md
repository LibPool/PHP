# linlancer/laravel-relations

> 标签: eloquent, laravel, model, relation, 关联, 匹配, 扩展, 模型, 自定义

## 简介

laravel扩展关联 多字段关联匹配 特殊字符分隔关联匹配

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
