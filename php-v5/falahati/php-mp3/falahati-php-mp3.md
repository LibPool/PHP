# falahati/php-mp3

> 标签: audio, edit, mp3

## 简介

PHP-MP3 is a simple library for reading and manipulating MPEG audio (MP3)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
