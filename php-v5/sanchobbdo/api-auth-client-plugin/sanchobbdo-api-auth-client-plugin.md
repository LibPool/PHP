# sanchobbdo/api-auth-client-plugin

> 标签: Authentication, Guzzle, api_auth, rest, ruby

## 简介

Guzzle authentication plugin for Ruby's api_auth gem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
