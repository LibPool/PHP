# whaze/whodunit-coding-standards

> 标签: Whodunit, phpcs, standards, static analysis, wordpress

## 简介

PHP_CodeSniffer rules (sniffs) to enforce Whodunit coding conventions, based on WordPress Coding Standards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
