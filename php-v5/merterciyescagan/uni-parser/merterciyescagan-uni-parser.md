# merterciyescagan/uni-parser

> 标签: PHP

## 简介

The package parses CSV, JSON, XLSX, or XML files and generates CREATE TABLE and INSERT INTO SQL statements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
