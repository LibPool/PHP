# pinano/bootstrap3-bundle

> 标签: bootstrap, bootstrap3, bundle

## 简介

Symfony2 bundle for wrapping Twitter Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
