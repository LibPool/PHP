# drupal/dockerize

> 标签: PHP

## 简介

Containerize a Drupal project for use as a standalone Docker/Podman container, a Docker Compose/Swarm setup, or on Kubernetes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
