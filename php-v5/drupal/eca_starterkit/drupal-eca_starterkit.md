# drupal/eca_starterkit

> 标签: PHP

## 简介

This recipe provides a quick-start setup for ECA with the recommended models being downloaded and installed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
