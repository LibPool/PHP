# drupal/mercury_editor_demo_recipe

> 标签: PHP

## 简介

Sets up the Mercury Editor demo content type, paragraph types, and content builder configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
