# drupal/everbright

> 标签: PHP

## 简介

Designed for a portfolio site, this template features a sharp and striking black-and-white design, along with articles and a project portfolio.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
