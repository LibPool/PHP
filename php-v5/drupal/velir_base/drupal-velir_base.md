# drupal/velir_base

> 标签: Drupal base install, best practices, recipe, simple install

## 简介

A recipe tailored to best practices for kick-starting a new Drupal 11+ project by Velir.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
