# drupal/varbase_webform_base

> 标签: Forms, Varbase recipes, drupal recipe, drupal recipes, recipe, varbase recipe, web forms, webform

## 简介

A recipe to manage default installed webform modules, configurations, and permissions for Varbase webform experience.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
