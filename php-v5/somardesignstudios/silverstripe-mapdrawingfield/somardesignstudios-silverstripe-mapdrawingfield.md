# somardesignstudios/silverstripe-mapdrawingfield

> 标签: googlemaps, maps, silverstripe

## 简介

Provides an interface for drawing geocoded shapes using Google Maps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
