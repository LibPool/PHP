# upscale/swoole-dispatch

> 标签: Connection, affinity, circular, client, dispatch, dispatcher, fixed, request, round robin, round-robin, session, sticky, swoole, worker

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
