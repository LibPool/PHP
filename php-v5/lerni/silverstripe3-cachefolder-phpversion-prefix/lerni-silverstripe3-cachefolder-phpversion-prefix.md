# lerni/silverstripe3-cachefolder-phpversion-prefix

> 标签: cache, patch, silverstripe

## 简介

A patch for SilverStripe to prefix cache-folder with php version - prevent 503 on version change

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
