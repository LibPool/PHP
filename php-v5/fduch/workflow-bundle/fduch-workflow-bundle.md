# fduch/workflow-bundle

> 标签: workflow

## 简介

workflow bundle for https://github.com/symfony/workflow component backported for Symfony 2.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
