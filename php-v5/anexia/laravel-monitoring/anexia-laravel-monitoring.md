# anexia/laravel-monitoring

> 标签: PHP

## 简介

A laravel module to monitor runtime (php, laravel) versions, composer package versions and composer package licenses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
