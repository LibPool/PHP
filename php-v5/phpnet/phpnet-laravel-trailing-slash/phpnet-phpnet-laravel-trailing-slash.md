# phpnet/phpnet-laravel-trailing-slash

> 标签: laravel, php, redirect

## 简介

Adds redirection with trailing slash in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
