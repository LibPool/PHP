# orthodoxauto/ziggy-without-const

> 标签: Ziggy, javascript, laravel, routes

## 简介

Identical to ziggy but uses var instead of const.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
