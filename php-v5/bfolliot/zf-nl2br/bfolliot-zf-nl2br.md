# bfolliot/zf-nl2br

> 标签: br, filter, html, new line, nl2br, zf2

## 简介

Provides a ZF2 filter for the php nl2br function

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
