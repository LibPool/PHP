# montanabay39/mpesa

> 标签: laravel

## 简介

laravel package for implementing C2B & B2C transactions as prescribed by Safaricom's daraja API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
