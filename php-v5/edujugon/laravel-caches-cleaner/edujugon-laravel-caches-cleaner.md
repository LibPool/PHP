# edujugon/laravel-caches-cleaner

> 标签: cache, command, console, laravel, queue, restart

## 简介

Laravel Console Command Package to clean all caches and restart queue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
