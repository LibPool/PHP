# asiviero/doctrine-timestamp

> 标签: datetime, doctrine, orm, timestamp

## 简介

A library adding the timestamp type to Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
