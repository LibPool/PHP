# fcpauldiaz/doctrine-extensions-bundle

> 标签: behaviors, doctrine2, extensions, gedmo, loggable, nestedset, sluggable, sortable, timestampable, translatable, tree

## 简介

Integration of the gedmo/doctrine-extensions with Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
