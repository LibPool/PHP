# kitzberger/tight

> 标签: TYPO3 CMS

## 简介

Tight Backend: Tweaks the backend CSS of TYPO3 **13.4** to reduce the vast space set between the UI elements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
