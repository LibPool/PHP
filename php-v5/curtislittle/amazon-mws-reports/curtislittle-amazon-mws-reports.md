# curtislittle/amazon-mws-reports

> 标签: amazon, api, client, library, mws, reports

## 简介

Amazon Marketplace Web Service(MWS) Reports PHP Client Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
