# mistcheng/sowechat

> 标签: framework, laravel, php, wechat, weixin, 微信, 框架

## 简介

基于Laravel PHP框架的微信网页版Api架构 & Wechat(WeiXin) Web Api Based On Laravel PHP Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
