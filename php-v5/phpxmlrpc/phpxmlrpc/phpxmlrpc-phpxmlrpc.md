# phpxmlrpc/phpxmlrpc

> 标签: webservices, xml-rpc, xmlrpc

## 简介

A php library for building xmlrpc clients and servers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
