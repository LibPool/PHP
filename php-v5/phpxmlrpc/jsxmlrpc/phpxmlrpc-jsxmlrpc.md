# phpxmlrpc/jsxmlrpc

> 标签: ajax, jsonrpc, webservices, xmlrpc

## 简介

A javascript library for building xmlrpc and jsonrpc clients

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
