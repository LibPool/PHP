# samrap/gestalt

> 标签: boilerplate, configuration, php, wrapper

## 简介

Gestalt is a simple, elegant PHP package for managing your framework's configuration values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
