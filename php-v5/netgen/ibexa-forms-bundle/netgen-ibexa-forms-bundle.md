# netgen/ibexa-forms-bundle

> 标签: Forms, ibexa, ibexa-forms, ibexa-forms-bundle, netgen

## 简介

Integration of Symfony's Form component with Ibexa Platform Public API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
