# factorenergia/yii2-widget-alert

> 标签: alert, block, bootstrap, extension, flash, jquery, notification, plugin, widget, yii2

## 简介

A widget to generate alert based notifications using bootstrap-alert plugin (sub repo split from yii2-widgets)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
