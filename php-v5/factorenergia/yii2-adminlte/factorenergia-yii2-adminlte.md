# factorenergia/yii2-adminlte

> 标签: AdminLTE, admin, backend, bootstrap 3, template, theme, yii2

## 简介

yii2-adminlte is a package for yii framework 2 that consists a very popular admin template AdminLTE (based on bootstrap 3).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
