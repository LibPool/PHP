# pfitzer/pegelonline

> 标签: Pegelonline, WSV, api, rest

## 简介

Library to use REST data from www.pegelonline.wsv.de

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
