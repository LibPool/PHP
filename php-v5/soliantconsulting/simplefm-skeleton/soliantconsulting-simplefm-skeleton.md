# soliantconsulting/simplefm-skeleton

> 标签: FileMaker, adapter, framework, zf2

## 简介

This application demonstrates use of the SimpleFM\ZF2 package as the Model layer of a Zend Framework 2 MVC application, using the FMServer_Sample database as a data provider.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
