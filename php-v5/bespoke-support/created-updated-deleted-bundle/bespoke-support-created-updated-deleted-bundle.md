# bespoke-support/created-updated-deleted-bundle

> 标签: PHP

## 简介

Symfony Bundle to add Created Updated and Deleted columns to entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
