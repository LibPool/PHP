# waxedphp/suneditor

> 标签: PHP

## 简介

Suneditor is a lightweight, flexible, customizable WYSIWYG text editor for your web applications - within WaxedPHP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
