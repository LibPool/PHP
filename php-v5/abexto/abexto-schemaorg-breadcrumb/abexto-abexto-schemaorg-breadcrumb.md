# abexto/abexto-schemaorg-breadcrumb

> 标签: JSON-LD, TypoScript, breadcrumb, extension, json, schema, schema.org, seo, typo3

## 简介

Generates http://schema.org/BreadcrumbList data for as JSON-LD

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
