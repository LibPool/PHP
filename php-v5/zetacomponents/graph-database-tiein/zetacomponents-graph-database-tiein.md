# zetacomponents/graph-database-tiein

> 标签: PHP

## 简介

The GraphDatabaseTiein provides functionality to directly use PDO statements as basis for ezcGraph Datasets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
