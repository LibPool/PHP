# zetacomponents/mvc-feed-tiein

> 标签: PHP

## 简介

This component provides a view handler that renders result data as an ATOM or RSS feed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
