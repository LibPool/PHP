# udwio/squirt

> 标签: asset, javascript, laravel, loading, mix, webpack

## 简介

A package to provide the global helper `squirt` in Laravel projects to handle loading webpack assets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
