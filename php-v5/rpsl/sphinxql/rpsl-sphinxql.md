# rpsl/sphinxql

> 标签: database, mysql, search, sphinx, sphinxql, sql

## 简介

Simple library for work with SphinxQL Api ( uses mysqli php extension )

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
