# ryanwinchester/laravel-auto-presenter

> 标签: eloquent, laravel, presenter

## 简介

A system for auto-decorating models with presenter objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
