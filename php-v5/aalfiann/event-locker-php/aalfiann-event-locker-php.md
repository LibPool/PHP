# aalfiann/event-locker-php

> 标签: event, locker, parallel, psr4

## 简介

Event Locker class to stop multiple or parallel execution in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
