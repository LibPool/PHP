# aalfiann/slim-skeleton

> 标签: microframework, psr11, psr7, rest, router

## 简介

This is a very simple, fast and secure of slim-skeleton.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
