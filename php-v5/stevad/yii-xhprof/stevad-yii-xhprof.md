# stevad/yii-xhprof

> 标签: debug, extension, profiling, xhprof, yii

## 简介

Yii extension to profile application with Facebook XHProf

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
