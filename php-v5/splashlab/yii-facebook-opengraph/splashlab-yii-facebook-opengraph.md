# splashlab/yii-facebook-opengraph

> 标签: facebook, opengraph, yii

## 简介

Yii1 Extension for the Facebook Open Graph 2.x and PHP SDK 4.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
