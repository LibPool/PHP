# parafusodixital/meteogalicia-apiv5

> 标签: PHP

## 简介

Small API to get rain amount in Galicia from Meteogalicia using API v5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
