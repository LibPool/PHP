# devmatic/laravel-instantclick

> 标签: Devmatic, Laravel-InstantClick, diaafares, instantclick, laravel

## 简介

An InstantClick middleware for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
