# sjaakp/yii2-symbol-picker

> 标签: extension, font-awesome, widget, yii, yii2

## 简介

Widget to select Font Awesome symbol for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
