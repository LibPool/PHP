# sonarsoftware/importer

> 标签: sonar, sonar api, sonar importer, sonar software, sonar software api

## 简介

An importer for Sonar, utilizing the Sonar API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
