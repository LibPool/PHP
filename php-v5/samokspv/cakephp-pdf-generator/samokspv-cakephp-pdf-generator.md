# samokspv/cakephp-pdf-generator

> 标签: PHP

## 简介

Adds button pdf generation to the page for task pdf generation (get data from current url, format json)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
