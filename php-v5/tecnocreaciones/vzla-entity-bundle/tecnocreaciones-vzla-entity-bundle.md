# tecnocreaciones/vzla-entity-bundle

> 标签: Base venezuela state municipality parish

## 简介

Provides states, municipalities, parishes and regions of Venezuela

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
