# gemorroj/command-scheduler-bundle

> 标签: command, cron, scheduler, symfony, task

## 简介

This Symfony2 bundle will allow you to schedule all your commands just like UNIX crontab

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
