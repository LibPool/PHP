# dfware/ar-softdelete

> 标签: active, delete, integrity, record, smart, soft, yii2

## 简介

Provides support for ActiveRecord soft delete in Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
