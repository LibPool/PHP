# cboelter/contao-tinymce-dynamic-templates

> 标签: contao, templates, tinymce

## 简介

Provides a backend module to generate tinymce templates in the backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
