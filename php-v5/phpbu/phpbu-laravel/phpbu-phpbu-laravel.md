# phpbu/phpbu-laravel

> 标签: backup, laravel

## 简介

Laravel backup package - integrates phpbu with the laravel artisan command line tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
