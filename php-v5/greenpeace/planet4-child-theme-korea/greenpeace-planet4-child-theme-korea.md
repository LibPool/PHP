# greenpeace/planet4-child-theme-korea

> 标签: PHP

## 简介

Child theme for the GPEA P8 website of the Planet 4 Wordpress project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
