# greenpeace/planet4-plugin-gutenberg-blocks

> 标签: PHP

## 简介

This repository contains the WordPress plugin that provides the gutenberg blocks for Planet4 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
