# lch/docker-symfony

> 标签: docker, lamp, phpmyadmin, symfony

## 简介

Ready-To-Start LAMP stack with Symfony and PHPMyAdmin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
