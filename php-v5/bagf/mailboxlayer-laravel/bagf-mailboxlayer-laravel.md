# bagf/mailboxlayer-laravel

> 标签: PHP

## 简介

Adds Laravel 5 validation rule for checking e-mail addresses using the mailboxlayer API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
