# ghopper/array_to_xml

> 标签: xml feed generator array

## 简介

Convenient way for xml-feed generation. You can get an multi-depth feed right from a SQL-query result.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
