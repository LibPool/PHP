# viharm/php-aria2-rpc

> 标签: aria2, php, rpc

## 简介

A PHP library to interact with Aria2 download manager via the Aria2 RPC interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
