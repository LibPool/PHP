# michaeljoyner/edible

> 标签: PHP

## 简介

Maps a basic content structure outlined in a yaml file to Eloquent models in your Laravel app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
