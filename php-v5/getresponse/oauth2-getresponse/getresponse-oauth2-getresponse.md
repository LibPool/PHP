# getresponse/oauth2-getresponse

> 标签: PHP

## 简介

GetResponse OAuth 2.0 Client Provider for thephpleague/oauth2-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
