# linking/flashr

> 标签: flash, flash messages, laravel, liinkiing, messages

## 简介

A Laravel package made for displaying flashes messages in a conveniant way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
