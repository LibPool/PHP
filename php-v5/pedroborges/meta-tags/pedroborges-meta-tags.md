# pedroborges/meta-tags

> 标签: facebook, head, meta, meta tags, open graph, seo, twitter cards

## 简介

HTML meta tags generator for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
