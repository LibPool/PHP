# dunp/smsend-laravel

> 标签: PHP

## 简介

Un pacchetto che fornisce una libreria per l'invio di SMS utilizzando l'API di Smsend.it. Il pacchetto è progettato per semplificare l'integrazione dell'invio di SMS nelle applicazioni Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
