# afaqurk/linux-dash

> 标签: dashboard, linux, linux-dash, server dashboard

## 简介

A drop-in, low-overhead monitoring web dashboard for a linux machine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
