# atog/phpokemon

> 标签: atog, phpokemon, pokeapi

## 简介

atog/phpokemon is a PHP 5.5+ wrapper for PokeAPI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
