# shivang-pandit/payment-gateway-paypal-omnipay

> 标签: gateway, merchant, omnipay, pay, payment, payments, paypal

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
