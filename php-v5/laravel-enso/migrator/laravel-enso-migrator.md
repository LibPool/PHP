# laravel-enso/migrator

> 标签: Structures, enso-helper, laravel-enso, migrator

## 简介

Structure-aware migration helpers for Laravel Enso packages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
