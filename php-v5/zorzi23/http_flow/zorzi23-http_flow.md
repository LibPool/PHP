# zorzi23/http_flow

> 标签: PHP

## 简介

A PHP library for managing HTTP flows, providing utilities for handling HTTP requests and responses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
