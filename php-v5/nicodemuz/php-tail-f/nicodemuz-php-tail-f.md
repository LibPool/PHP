# nicodemuz/php-tail-f

> 标签: PHP

## 简介

A simple implementation to provide tail -f functionality in PHP code. Allows you to monitor newly added lines to a given file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
