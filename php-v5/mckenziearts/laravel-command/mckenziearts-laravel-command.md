# mckenziearts/laravel-command

> 标签: artisan-cli, generators, helper, laravel, observer, repository

## 简介

A simple Laravel package to provide artisan new commands

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
