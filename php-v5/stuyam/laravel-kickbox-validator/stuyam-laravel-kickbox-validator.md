# stuyam/laravel-kickbox-validator

> 标签: email, kickbox, laravel, validation, validator

## 简介

A kickbox email validator for form requests in laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
