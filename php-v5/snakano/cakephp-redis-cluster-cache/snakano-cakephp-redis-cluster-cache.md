# snakano/cakephp-redis-cluster-cache

> 标签: cache, cakephp, plugin, redis, redis cluster

## 简介

Redis Cache Engine for CakePHP 2.x (support redis cluster)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
