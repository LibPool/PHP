# dhtmlx/dhtmlx-gii

> 标签: dhtmlx, generator, gii, yii2

## 简介

Gii Generator for the generation of grid on a given url with the help of DHTMLX Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
