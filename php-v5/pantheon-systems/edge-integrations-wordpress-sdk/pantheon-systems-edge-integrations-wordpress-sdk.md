# pantheon-systems/edge-integrations-wordpress-sdk

> 标签: PHP

## 简介

A one-stop shop for integration your WordPress site on Pantheon with advanced Edge Integrations tools.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
