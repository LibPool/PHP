# pantheon-systems/decoupled-kit-acf

> 标签: PHP

## 简介

Adds examples related to using advanced custom fields on a decoupled WordPress site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
