# pantheon-systems/terminus-drupal-console-plugin

> 标签: PHP

## 简介

Drupal Console - A Terminus plugin for running Drupal Console commands on a Pantheon site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
