# pantheon-systems/pantheon-wordpress-edge-integrations

> 标签: PHP

## 简介

WordPress plugin to support Pantheon Edge Integrations and personalization features

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
