# pantheon-systems/drops-8-scaffolding

> 标签: PHP

## 简介

Project template for Drupal 8 projects with composer following drupal/drupal layout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
