# zxbodya/yii2-elfinder

> 标签: elfinder, extension, file manager, tinymce, widget, yii2

## 简介

Extension to use elFinder 1.x file manager in Yii2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
