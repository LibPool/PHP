# wearerequired/members-unfiltered-html

> 标签: capability, members, unfiltered-html, wordpress

## 简介

WordPress mu-plugin to allow adding the `unfiltered_html` capability to a role in a multisite install via Members.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
