# nodeone/qbank3api-phpwrapper

> 标签: api, qbank

## 简介

A PHP-Wrapper for QBank 3's API. Provides a simple way to communicate with QBank 3 from PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
