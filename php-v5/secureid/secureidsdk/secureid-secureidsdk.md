# secureid/secureidsdk

> 标签: PHP

## 简介

Ce kit de développement logiciel (Software Development Kit ou SDK) est un SDK dédié à l'API, conçu pour faciliter la communication et l'intégration d'une API de gestion des sauvegardes d'identifiants dans notre projet Laravel, nommé SecureID. Cette API repose sur la technologie Node.js, en particulier le framework ExpressJS, et utilise une base de données NoSQL, MongoDB, avec le package Mongoose.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
