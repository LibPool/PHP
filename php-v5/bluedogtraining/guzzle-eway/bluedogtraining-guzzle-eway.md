# bluedogtraining/guzzle-eway

> 标签: Guzzle, australia, eway, payment

## 简介

A Guzzle client for interacting with the Eway Direct Transactions API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
