# vahid/respond

> 标签: json, respond, vahid

## 简介

Easy JSON response for Laravel and Lumen, a useful package for handle your RESTful API endpoint

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
