# legit-health/medical-device-sdk-bundle

> 标签: PHP

## 简介

Bundles that integrates the SDK for working with the Legit.Health's Medical Device API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
