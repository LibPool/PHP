# orz/pitk

> 标签: PHP

## 简介

Personal Integration Toolkit, Memory Cache, Apcu Cache, Memcached Cache, Gump Validation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
