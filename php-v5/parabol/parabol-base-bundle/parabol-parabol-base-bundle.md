# parabol/parabol-base-bundle

> 标签: base

## 简介

Base bundle for symfony project base on symfony2admingenerator and ParabolAdminCoreBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
