# ash/laravel-measurement-protocol

> 标签: PHP

## 简介

A Laravel wrapper for Krizon's Google Analytics Measurement Protocol PHP Client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
