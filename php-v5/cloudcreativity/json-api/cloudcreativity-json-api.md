# cloudcreativity/json-api

> 标签: JSON-API, api, cloudcreativity, json, jsonapi, jsonapi.org

## 简介

Framework agnostic JSON API serialization and deserialization.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
