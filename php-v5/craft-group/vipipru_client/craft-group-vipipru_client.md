# craft-group/vipipru_client

> 标签: sdk, vipip, wrapper

## 简介

A simple VipIP.ru SDK wrapper which aims to be much more comfortable and usable than the original

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
