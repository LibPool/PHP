# wronx/php-google-cloud-storage

> 标签: cloud, google, php, storage

## 简介

A simple PHP class to perform basic actions on Google Cloud Storage files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
