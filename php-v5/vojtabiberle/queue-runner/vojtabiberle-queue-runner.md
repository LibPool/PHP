# vojtabiberle/queue-runner

> 标签: PHP

## 简介

Simple daemon in PHP for running background job on server. Uses MongoDB as MessageQueue for job descriptions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
