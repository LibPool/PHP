# fhenne/laravel-informix

> 标签: database, eloquent, informix, laravel, model, moloquent

## 简介

A Informix based Eloquent model and Query builder for Laravel (Moloquent)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
