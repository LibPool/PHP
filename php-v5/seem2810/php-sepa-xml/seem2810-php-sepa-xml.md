# seem2810/php-sepa-xml

> 标签: sepa, xml

## 简介

Simple classes for creating SEPA transfer and direct debit xml files. No dependencies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
