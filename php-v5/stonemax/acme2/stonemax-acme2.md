# stonemax/acme2

> 标签: PHP

## 简介

Another PHP client for acme protocal (version 2) implementation, used for generating letsencrypt's free ssl certificates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
