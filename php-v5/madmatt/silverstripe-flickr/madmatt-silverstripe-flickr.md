# madmatt/silverstripe-flickr

> 标签: PHP

## 简介

Provides simple bindings for the Flickr API, converting API responses into SilverStripe objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
