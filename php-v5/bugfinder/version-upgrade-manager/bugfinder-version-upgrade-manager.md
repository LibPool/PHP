# bugfinder/version-upgrade-manager

> 标签: PHP

## 简介

Laravel package for BugFinder version upgrade + auto inject menu to generalsettings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
