# itsreddi/yii2-firebase-rest-dynlinks

> 标签: dynamic links, firebase, yii2

## 简介

Lightweight firebase url shortener

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
