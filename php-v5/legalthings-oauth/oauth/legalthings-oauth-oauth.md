# legalthings-oauth/oauth

> 标签: legalthings

## 简介

LegalThings OAuth 2.0 Client Provider which makes use of the OAuth2-Client from The PHP League

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
