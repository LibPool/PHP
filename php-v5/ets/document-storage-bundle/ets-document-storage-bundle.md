# ets/document-storage-bundle

> 标签: aws, cloud, document-storage, echosign, s3

## 简介

Symfony bundle that integrates with ets/document-storage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
