# alexdin/yii2-file-session

> 标签: alexdin, file-session, multi-session, session, yii2

## 简介

Extention Class for Yii2 File Session based on yii/web/Session

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
