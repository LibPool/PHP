# brightnucleus/php-releases

> 标签: PHP

## 简介

Automatically fetch a list of PHP releases from the official PHP website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://packagist.org/packages/brightnucleus%2Fphp-releases
- 源码仓库：https://github.com/brightnucleus/php-releases.git
- Packagist 页面：https://packagist.org/packages/brightnucleus%2Fphp-releases

## 历史版本号

- 当前版本：v0.1.0

## 获取地址

- Composer 安装：`composer require brightnucleus/php-releases`
- Packagist 仓库：https://repo.packagist.org/p2/brightnucleus/php-releases.json
- 许可证：MIT
- PHP 要求：>=5.2
