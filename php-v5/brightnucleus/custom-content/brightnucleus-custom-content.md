# brightnucleus/custom-content

> 标签: PHP

## 简介

Config-driven WordPress Custom Content Definitions (Custom Post Types, Custom Taxonomies).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
