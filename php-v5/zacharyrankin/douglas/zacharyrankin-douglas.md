# zacharyrankin/douglas

> 标签: jasper, jasperserver, php, report

## 简介

Douglas PHP library for running Jasper Reports using their report REST API (v2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
