# mugoweb/ezfind

> 标签: PHP

## 简介

eZ Find is a search extension for eZ Publish legacy, providing more functionality and better results than the default search in eZ Publish.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
