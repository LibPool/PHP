# pizar/carbon-it-holidays

> 标签: Bank, carbon, holiday, holidays

## 简介

IT Holidays Wrapper for the Carbon DateTime Library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
