# benfurfie/laravel-preset-tailwind

> 标签: laravel, postcss, preset, tailwind, tailwindcss

## 简介

A PostCSS-powered TailwindCSS preset for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
