# risan/ktp

> 标签: kpu, ktp, nik, pemilu

## 简介

HTTP client library for finding 2014 Indonesian presidential election voter's data based on it's NIK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
