# aberdeener/minecraft-oauth

> 标签: PHP

## 简介

Provides easy layer to get a Minecraft profile from a Microsoft Live OAuth session

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
