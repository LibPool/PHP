# rovak/kj-sencha

> 标签: extjs, sencha, zf2

## 简介

Ext-JS / Sencha Touch RPC Intergration Module for Zend Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
