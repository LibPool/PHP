# bitpiston/woocommerce-facebook-remarketing

> 标签: facebook, marketing, tracking, woocommerce, wordpress

## 简介

Facebook custom audience event tracking integration for WooCommerce allowing remarketing via targeted ads

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
