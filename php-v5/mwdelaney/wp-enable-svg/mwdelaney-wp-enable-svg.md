# mwdelaney/wp-enable-svg

> 标签: muplugin, svg, wordpress

## 简介

Allows SVGs in the WordPress Media Library and fixes display of SVGs in the WordPress Admin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
