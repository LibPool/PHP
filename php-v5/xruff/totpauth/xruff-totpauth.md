# xruff/totpauth

> 标签: component, google, nette, nette-framework, qr, qrcode, totp

## 简介

Nette extension for Time-Based One-Time Password Algorithm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
