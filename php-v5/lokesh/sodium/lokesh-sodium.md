# lokesh/sodium

> 标签: cmy, cmyk, color, colour, convert, gif, hex, hsb, hsl, hsv, image, lab, rgb

## 简介

A Smart color library to create, convert, mix, generate, export colors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
