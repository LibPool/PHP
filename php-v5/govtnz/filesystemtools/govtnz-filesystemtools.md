# govtnz/filesystemtools

> 标签: PHP

## 简介

Tools for dealing with the filesystem and files. Requires SilverStripe >= 3.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
