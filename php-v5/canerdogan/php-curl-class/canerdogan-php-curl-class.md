# canerdogan/php-curl-class

> 标签: PHP

## 简介

PHP Curl Class is an object-oriented wrapper of the PHP cURL extension. v1.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
