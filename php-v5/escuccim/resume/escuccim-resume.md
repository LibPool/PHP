# escuccim/resume

> 标签: curriculum vitae, escuccim, laravel, multilingual, resume

## 简介

A Laravel package to administer and display a multi-lingual CV

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
