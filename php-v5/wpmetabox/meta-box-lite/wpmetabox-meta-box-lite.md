# wpmetabox/meta-box-lite

> 标签: PHP

## 简介

A single plugin that provides UI and all free features for managing custom fields and dynamic content on WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
