# sms77/craft

> 标签: Craft, cms, commerce, sms, text2speech, tts

## 简介

Send SMS via Sms77.io SMS Gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
