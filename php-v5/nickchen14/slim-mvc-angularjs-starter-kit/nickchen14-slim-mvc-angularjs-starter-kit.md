# nickchen14/slim-mvc-angularjs-starter-kit

> 标签: PHP

## 简介

Slim-Skeleton-MVC + Medoo + League/Plates + angularjs 製作前後台管理系統

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
