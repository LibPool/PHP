# cmsgears/module-paystack

> 标签: cmsgears, module, paystack, yii, yii2

## 简介

The Paystack Module to integrate the payment solutions provided by Paystack.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
