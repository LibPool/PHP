# cmsgears/plugin-seo

> 标签: cmsgears, plugin, seo, yii2

## 简介

The Seo Plugin for CMSGears provides options to manage the SEO meta tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
