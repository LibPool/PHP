# cmsgears/module-cms

> 标签: cms, cmsgears, module, yii, yii2

## 简介

The CMS module provides cms features including pages, posts, sidebars, widgets, menus and links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
