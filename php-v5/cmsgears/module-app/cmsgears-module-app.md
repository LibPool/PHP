# cmsgears/module-app

> 标签: app, application, cmsgears, module, yii, yii2

## 简介

The Application Module required for CMSGears based projects. It provides features specific to manage child applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
