# boxedcode/silex-config-service-provider

> 标签: PHP

## 简介

A Silex Configuration Service Provider (more on silex: http://silex.sensiolabs.org/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
