# kitlabs/kit-paginator-bundle

> 标签: kit-paginator-bundle, kitlabs, paginator, paginator bundle

## 简介

Support Native Sql Query for KnpPaginatorBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
