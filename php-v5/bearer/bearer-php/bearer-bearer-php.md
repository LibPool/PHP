# bearer/bearer-php

> 标签: PHP

## 简介

The Bearer PHP client helps you call any API in minutes with out-of-the-box managed authentication and log monitoring.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
