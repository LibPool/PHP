# danieltrolezi/twitter-oauth

> 标签: PHP

## 简介

A simple PHP class that makes more easy to work with themattharris/tmhoauth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
