# foskym/flarum-activity-graph

> 标签: activity, extension, flarum, graph, heatmap

## 简介

Show an activity graph (heatmap) in user page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
