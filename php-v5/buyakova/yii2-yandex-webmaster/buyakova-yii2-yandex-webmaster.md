# buyakova/yii2-yandex-webmaster

> 标签: extension, webmaster, yandex, yii2

## 简介

Api wrapper for webmaster.yandex.ru for yii

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
