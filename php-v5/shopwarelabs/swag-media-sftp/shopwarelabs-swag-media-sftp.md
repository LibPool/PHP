# shopwarelabs/swag-media-sftp

> 标签: PHP

## 简介

The SFTP adapter allows you to manage your media files in shopware on a SFTP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
