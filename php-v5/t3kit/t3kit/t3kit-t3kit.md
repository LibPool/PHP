# t3kit/t3kit

> 标签: cms, starter, t3kit, t3kit10, typo3

## 简介

t3kit project. A TYPO3 website starterkit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
