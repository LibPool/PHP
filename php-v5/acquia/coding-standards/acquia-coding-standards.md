# acquia/coding-standards

> 标签: drupal, phpcs, standards, static analysis

## 简介

PHP_CodeSniffer rules (sniffs) for Acquia coding standards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
