# acquia/acquia-sdk-php-cloud-memcache

> 标签: acquia

## 简介

Acquia Cloud memcache component for the Acquia SDK for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
