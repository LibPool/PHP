# reisraff/phulp

> 标签: assets-management, builder, gulp, php, phulp, task, task-manager, task-runner, watcher

## 简介

The task manager for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
