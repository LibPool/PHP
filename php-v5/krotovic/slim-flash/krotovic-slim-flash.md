# krotovic/slim-flash

> 标签: flash, framework, message, provider, slim

## 简介

Slim Framework Flash message service provider [fork of slim/flash]

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
