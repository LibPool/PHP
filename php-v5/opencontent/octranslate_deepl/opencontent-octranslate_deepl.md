# opencontent/octranslate_deepl

> 标签: PHP

## 简介

Deepl handler for OpenCity CMS Translation tools (embed a deeplcom/deepl-php php-7.2 porting)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
