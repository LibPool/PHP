# bedigit/laravel-omnipay

> 标签: laravel, laravel5, omnipay, payments

## 简介

Integerates Omnipay with Laravel and provides an easy configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
