# verumconsilium/laravel-browsershot

> 标签: PHP

## 简介

Browsershot Laravel wrapper to generate PDF files and Screenshots using Headless Chrome

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
