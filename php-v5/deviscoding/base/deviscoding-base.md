# deviscoding/base

> 标签: css, maps, sass, scss, strapless, variables

## 简介

SASS Functions & mixins for managing variables within various SASS components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
