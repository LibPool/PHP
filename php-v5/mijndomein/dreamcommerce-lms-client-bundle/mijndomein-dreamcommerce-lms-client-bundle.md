# mijndomein/dreamcommerce-lms-client-bundle

> 标签: PHP

## 简介

Symfony 2 integration for dreamcommerce license manager client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
