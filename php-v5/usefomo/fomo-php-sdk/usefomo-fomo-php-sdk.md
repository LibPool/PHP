# usefomo/fomo-php-sdk

> 标签: api, fomo, notifications, social proof, wrapper

## 简介

Fomo PHP SDK is the official SDK wrapper for the Fomo API service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
