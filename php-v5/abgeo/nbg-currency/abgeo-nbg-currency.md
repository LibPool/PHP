# abgeo/nbg-currency

> 标签: Banking, api, currency, nbg

## 简介

Library for getting data from National Bank of Georgia (NBG)'s API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
