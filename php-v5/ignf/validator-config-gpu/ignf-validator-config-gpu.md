# ignf/validator-config-gpu

> 标签: PHP

## 简介

Dépôt de gestion de la configuration de IGNF/validator pour la validation des standards CNIG au niveau du Géoportail de l'Urbanisme (GpU).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
