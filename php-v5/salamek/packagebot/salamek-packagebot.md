# salamek/packagebot

> 标签: PPL, Packagebot, api, czech post, ulozenka, Česká pošta

## 简介

Packagebot service to handle packages simply and fast

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
