# leanzo/discussion-thumbnail

> 标签: flarum, friendsofflarum, leanzo

## 简介

Replace author avatars with the first image in a discussion's starting post

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
