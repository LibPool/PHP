# tyhand/background-process-bundle

> 标签: PHP

## 简介

A basic bundle to provide some background process tools without requiring anything beyond vanilla php and symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
