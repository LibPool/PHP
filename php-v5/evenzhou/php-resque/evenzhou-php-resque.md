# evenzhou/php-resque

> 标签: background, job, redis, resque

## 简介

Redis backed library for creating background jobs and processing them later. Based on resque for Ruby.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
