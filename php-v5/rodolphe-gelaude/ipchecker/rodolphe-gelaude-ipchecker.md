# rodolphe-gelaude/ipchecker

> 标签: Abuse, IP, access-control, blacklist, brute-force, drupal, ip-blocking, ip-check, login-security, module, monitoring, protection, security

## 简介

IP Checker helps to block abusive IP addresses on specific error codes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
