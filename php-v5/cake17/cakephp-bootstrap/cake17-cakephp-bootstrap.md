# cake17/cakephp-bootstrap

> 标签: bootstrap, cakephp, form, helpers, html, twitter

## 简介

To easily use Bootstrap Twitter 3.x in CakePHP projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
