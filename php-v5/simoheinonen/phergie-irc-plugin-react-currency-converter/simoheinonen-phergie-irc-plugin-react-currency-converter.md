# simoheinonen/phergie-irc-plugin-react-currency-converter

> 标签: irc, phergie

## 简介

Phergie IRC bot plugin to convert currencies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
