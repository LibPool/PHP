# oscarricardosan/cache_object

> 标签: PHP

## 简介

Small package for handling cache in code block and not having to use session and avoid 'array_has' or the like.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
