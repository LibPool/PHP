# artistan/revive-xmlrpc

> 标签: adsserver, api, revive, xmlrpc

## 简介

package of the library classes to provide XmlRpc routines for accessing revive ad servers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
