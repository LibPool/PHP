# hryvinskyi/magento2-data-layer-pack

> 标签: PHP

## 简介

GA4 Data Layer for Magento 2: browser and server-side GA4 ecommerce events, Google Tag Manager or gtag.js, and a setup wizard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
