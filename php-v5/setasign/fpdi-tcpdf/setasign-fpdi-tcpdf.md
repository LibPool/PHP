# setasign/fpdi-tcpdf

> 标签: TCPDF, fpdi, pdf

## 简介

Kind of metadata package for dependencies of the latest versions of FPDI and TCPDF.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
