# generalsoftwareinc/sendreach-php-sdk

> 标签: PHP

## 简介

The official SendReach PHP SDK. Just hosted by GSI on GitHub.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
