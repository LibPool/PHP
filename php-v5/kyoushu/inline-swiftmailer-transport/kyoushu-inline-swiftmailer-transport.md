# kyoushu/inline-swiftmailer-transport

> 标签: PHP

## 简介

A SwiftMailer transport which inlines CSS before forwarding the message to another transport for delivery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
