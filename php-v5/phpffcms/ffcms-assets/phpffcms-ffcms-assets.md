# phpffcms/ffcms-assets

> 标签: JS, assets, bower, css, ffcms, npm, packages

## 简介

FFCMS 3 asset package with all builded dist from npm, bower

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
