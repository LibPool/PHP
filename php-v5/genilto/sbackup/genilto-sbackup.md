# genilto/sbackup

> 标签: adapter, backup, sbackup, send

## 简介

A small layer created to abstract the ways to send backups to different cloud services with php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
