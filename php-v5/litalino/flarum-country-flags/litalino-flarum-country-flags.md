# litalino/flarum-country-flags

> 标签: Country flag, country, flag, flarum, flarum extension

## 简介

Add country flags attribute to Flarum Users

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
