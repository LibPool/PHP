# bnsoftware/lti-1p3-tool

> 标签: LTI

## 简介

A library used for building IMS-certified LTI 1.3 tool providers in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
