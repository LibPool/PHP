# wenpeng/curl

> 标签: PHP cURL, curl download, curl library, curl lightweight, curl post, curl upload

## 简介

一个轻量级的PHP网络操作类，实现GET、POST、UPLOAD、DOWNLOAD常用操作，出错自动重试，支持链式写法

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
