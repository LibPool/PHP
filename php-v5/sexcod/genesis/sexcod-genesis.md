# sexcod/genesis

> 标签: base for developer web, micro framework

## 简介

base for developer web php with angular and doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Packagist 页面：https://packagist.org/packages/sexcod%2Fgenesis
