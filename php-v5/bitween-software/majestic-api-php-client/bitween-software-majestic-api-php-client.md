# bitween-software/majestic-api-php-client

> 标签: PHP

## 简介

PHP Client for the Majestic HTTP API. Forked from majestic/PHP-API-Connector.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
