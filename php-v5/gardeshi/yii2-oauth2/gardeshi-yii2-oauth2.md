# gardeshi/yii2-oauth2

> 标签: aminkt, jwt, library, oauth2, yii2

## 简介

Usefull package to add some class to yii2-oauth2 extention.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
