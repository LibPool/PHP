# cliffparnitzky/user-member-bridge

> 标签: Users, assigment, contao, members, synchronisation

## 简介

Assigning members to users for synchronizing common account data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
