# cliffparnitzky/birthday-lister

> 标签: birthday, birthdaylist, birthdaylisting, contao

## 简介

Provides a module to list member birthdays (past, actual, upcoming).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
