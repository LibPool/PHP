# cliffparnitzky/tiny-mce-bundle-text-color

> 标签: bundle, contao, metapackage, tiny editor, tinymce, tinymce bundle, tinymce textcolor, tinymce4

## 简介

Installs the TinyMCE plugin loader, the text color plugin and needed additional plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
