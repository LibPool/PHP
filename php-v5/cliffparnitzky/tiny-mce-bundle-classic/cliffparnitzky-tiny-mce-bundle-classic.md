# cliffparnitzky/tiny-mce-bundle-classic

> 标签: bundle, contao, metapackage, tiny editor, tinymce, tinymce bundle, tinymce classic, tinymce4

## 简介

Installs the TinyMCE plugin loader and the missing default plugins known from TinyMCE 3 (anchor, colorpicker, emoticons, textcolor).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
