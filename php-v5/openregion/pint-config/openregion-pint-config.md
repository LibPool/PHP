# openregion/pint-config

> 标签: Pint, code-style, configuration, formatter, laravel, php

## 简介

Shared Laravel Pint configuration for Open Region projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
