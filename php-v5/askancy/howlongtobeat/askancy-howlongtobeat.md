# askancy/howlongtobeat

> 标签: hl2b, how long to beat, howlongtobeat

## 简介

A PHP wrapper to fetch data from howlongtobeat.com with dynamic API key extraction

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
