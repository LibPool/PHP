# caherrera/fullcsv

> 标签: csv, csv reader, csv writer

## 简介

FullCSV is a simple Object Oriented CSV manipulation library for PHP 5.6+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
