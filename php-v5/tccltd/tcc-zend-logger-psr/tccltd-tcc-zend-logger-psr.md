# tccltd/tcc-zend-logger-psr

> 标签: PHP

## 简介

Provides a PSR-3 compatible wrapper for Zend Logger (using Psr/Log).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
