# sonofliberty/php-cryptocurrency-address-validation

> 标签: PHP

## 简介

Cryptocurrency address validation. Currently supports litecoin and bitcoin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
