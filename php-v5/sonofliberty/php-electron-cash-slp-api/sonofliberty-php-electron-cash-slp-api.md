# sonofliberty/php-electron-cash-slp-api

> 标签: BitcoinCash, api, electroncash, jsonrpc, payment, slp

## 简介

PHP wrapper for Electron Cash SLP JSONRPC-API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
