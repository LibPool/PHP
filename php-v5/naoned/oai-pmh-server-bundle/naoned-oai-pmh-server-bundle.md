# naoned/oai-pmh-server-bundle

> 标签: OAI-PMH, oaipmh

## 简介

Bundle for Symfony2 that provides an Oai-Pmh server for your data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
