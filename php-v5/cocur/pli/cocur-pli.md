# cocur/pli

> 标签: PHP

## 简介

Pli is a library and set of conventions to bootstrap Console applications with Symfony Console, DependencyInjection and Config components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
