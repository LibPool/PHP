# lizhaomiusi/yii2-qrcode-helper

> 标签: 2amigos, extension, helper, qrcode, yii, yii 2, yii2

## 简介

Create QrCodes based on libqrencode C library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
