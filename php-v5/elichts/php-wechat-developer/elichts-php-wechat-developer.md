# elichts/php-wechat-developer

> 标签: WeChatDeveloper, WeMini, alipay, wechat, wechatpay, wepay

## 简介

WeChat platform and WeChat payment development tools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
