# stadline/monolog-html-reversed-formatter

> 标签: formatter, html, html formatter, log, monolog

## 简介

this formatter displays the logs in reverse chronological order

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
