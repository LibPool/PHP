# opgginc/rememberable

> 标签: caching, eloquent, laravel, remember

## 简介

Query caching for Laravel 5 with jenssegers's MongoDB ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
