# baumann-at/php-polygonscan-api

> 标签: EtherScan.io, api, ethereum, etherscan

## 简介

PHP client for the Etherscan API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
