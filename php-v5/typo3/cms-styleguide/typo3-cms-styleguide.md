# typo3/cms-styleguide

> 标签: style guide, typo3, typo3 backend

## 简介

TYPO3 extension to showcase TYPO3 Backend capabilities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
