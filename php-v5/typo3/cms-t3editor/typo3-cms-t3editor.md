# typo3/cms-t3editor

> 标签: PHP

## 简介

TYPO3 CMS T3Editor - JavaScript-driven editor with syntax highlighting and code completion. Based on CodeMirror.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
