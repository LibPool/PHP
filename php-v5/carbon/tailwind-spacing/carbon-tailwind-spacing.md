# carbon/tailwind-spacing

> 标签: Neos, neoscms, tailwindcss

## 简介

Editor to set tailwind spacing classes in Neos CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
