# dlimars/laravel-tenant-subdomain

> 标签: PHP

## 简介

Pacote para facilitar criação de rotas e troca de banco de dados baseado no subdominio da sua aplicação

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
