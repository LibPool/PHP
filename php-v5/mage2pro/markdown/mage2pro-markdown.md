# mage2pro/markdown

> 标签: backend, ecommerce, editor, magento, magento 2, magento extension, markdown

## 简介

The «Markdown» extension for Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
