# mage2pro/portal

> 标签: Web portal, cms, ecommerce, magento, magento 2, magento extension

## 简介

A web portal extension for Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
