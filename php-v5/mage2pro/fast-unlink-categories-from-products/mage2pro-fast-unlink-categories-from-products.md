# mage2pro/fast-unlink-categories-from-products

> 标签: magento 2

## 简介

This module for Magento 2 makes unlinking categories from products 1000 times faster

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
