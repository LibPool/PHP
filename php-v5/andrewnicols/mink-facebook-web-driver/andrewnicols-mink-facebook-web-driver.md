# andrewnicols/mink-facebook-web-driver

> 标签: ajax, browser, javascript, testing, webdriver

## 简介

Mink driver for facebook's webdriver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
