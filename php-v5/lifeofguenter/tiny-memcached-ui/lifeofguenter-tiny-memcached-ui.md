# lifeofguenter/tiny-memcached-ui

> 标签: admin, memcached, tiny, ui, web, webinterface

## 简介

Minimalistic web interface to manage Memcached.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
