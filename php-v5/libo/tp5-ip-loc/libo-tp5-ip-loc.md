# libo/tp5-ip-loc

> 标签: libo, thinkphp5, tp5-ip-loc

## 简介

基于ThinkPHP5.1框架的ip地址查询库，可以针对ip地址进行查询，返回省份城市

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
