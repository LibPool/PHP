# steampixel/simple-php-portals

> 标签: PHP

## 简介

This is a simple, puristic and small PHP portal engine. Throw your contents back and forth through time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
