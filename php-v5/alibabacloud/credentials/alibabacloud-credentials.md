# alibabacloud/credentials

> 标签: alibaba, alibabacloud, aliyun, client, cloud, credentials, library, sdk, tool

## 简介

Alibaba Cloud Credentials for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
