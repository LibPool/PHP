# spicy/fork-laravel-tcpdf

> 标签: TCPDF, laravel, pdf

## 简介

A simple Laravel 4 service provider with some basic configuration for including the TCPDF library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
