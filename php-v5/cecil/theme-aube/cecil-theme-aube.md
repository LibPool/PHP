# cecil/theme-aube

> 标签: aube, blog, bootstrap, cecil, documentation, theme

## 简介

Cecil Aube theme, a Bootstrap 6 documentation and blog theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
