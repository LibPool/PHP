# exocet/yii2-bootstrap-material-design

> 标签: bootstrap, material, yii, yii2

## 简介

Composer package for implementing MDB in Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
