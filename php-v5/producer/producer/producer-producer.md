# producer/producer

> 标签: bitbucket, git, github, gitlab, hg, library, mercurial, package

## 简介

Tools for releasing library packages; supports Git, Mercurial, Github, Gitlab, and Bitbucket.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
