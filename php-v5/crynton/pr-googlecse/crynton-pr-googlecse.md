# crynton/pr-googlecse

> 标签: TYPO3 CMS, custom search engine, google, typo3

## 简介

Frontend search plugin that uses the Google CSE api.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
