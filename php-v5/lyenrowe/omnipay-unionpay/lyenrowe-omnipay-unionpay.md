# lyenrowe/omnipay-unionpay

> 标签: gateway, laravel, merchant, omnipay, pay, payment, purchase, sdk, union, unionpay, 无跳转支付, 银联

## 简介

UnionPay gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
