# meeteeor/sdk

> 标签: api, meeteeor, payment, php, sdk

## 简介

Meeteeor SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://github.com/Meeteeor/php-sdk
- 源码仓库：https://github.com/Meeteeor/php-sdk.git
- Packagist 页面：https://packagist.org/packages/meeteeor%2Fsdk

## 获取地址

- Composer 安装：`composer require meeteeor/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/meeteeor/sdk.json
- 许可证：Apache-2.0
- PHP 要求：>=5.6
