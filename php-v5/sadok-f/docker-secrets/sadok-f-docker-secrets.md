# sadok-f/docker-secrets

> 标签: docker secret, docker secrets, php, php docker secrets

## 简介

Simple PHP library to read docker secrets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
