# lilweb/coffeescript-bundle

> 标签: Symfony2, assetic, coffeescript

## 简介

An assetic filter for CoffeeScript in pure PHP implementation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
