# oguzcabuk07/php-iban

> 标签: PHP

## 简介

php-iban is a library for parsing and validating IBAN (and IIBAN) bank account information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
