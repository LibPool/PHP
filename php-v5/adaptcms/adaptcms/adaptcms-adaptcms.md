# adaptcms/adaptcms

> 标签: Laravel CMS, PHP CMS, cms, laravel

## 简介

AdaptCMS is the modern solution to the CMS problem. Laravel, Plugins and Themes, easy and quite fast.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
