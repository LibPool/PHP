# madebykind/craft-vue-tailwind

> 标签: Craft, Vue.js, cms, craftcms, project, tailwind, tailwindcss, vue, vue js

## 简介

Craft CMS + Vue.js + TailwindCSS + Nanobox Boilerplate

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
