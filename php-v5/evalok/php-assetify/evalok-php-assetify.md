# evalok/php-assetify

> 标签: asset management, assetic, cpanel, https, mod_spdy

## 简介

extremely simple to use wrapper for basic Assetic usage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
