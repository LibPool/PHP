# fiamma06/yii2-adldap-module

> 标签: active directory, ad, adLDAP, ldap, yii2

## 简介

yii2 adldap extention (wrapper for adldap/adLDAP Module)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
