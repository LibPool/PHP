# soupmix/elasticsearch

> 标签: Abstraction Layer, adapters, database, elasticsearch

## 简介

Simple Elasticsearch abstraction layer adapter to handle CRUD operations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
