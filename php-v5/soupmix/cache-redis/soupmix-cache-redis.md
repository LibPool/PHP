# soupmix/cache-redis

> 标签: adapters, cache, redis, simplecache

## 简介

Framework agnostic Redis adapter for SimpleCache Interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
