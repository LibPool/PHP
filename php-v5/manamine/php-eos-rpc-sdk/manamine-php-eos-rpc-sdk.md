# manamine/php-eos-rpc-sdk

> 标签: api, blockchain, crypto, eos, php, rpc, sdk

## 简介

PHP SDK for the EOS RPC API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
