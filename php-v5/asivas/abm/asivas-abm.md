# asivas/abm

> 标签: PHP

## 简介

The CRUD-Resouce controller implementation make simple base of an app based on resources, with NavItems and FormFields backend representation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
