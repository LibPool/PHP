# clubdrei/typo3-env-config

> 标签: PHP

## 简介

Dependency-free parser for converting flat environment variables into nested PHP arrays (TYPO3-focused, framework-agnostic)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
