# goetas/xsd-reader

> 标签: parser, php, xml, xmlschema, xsd

## 简介

Read any XML Schema (XSD) programmatically with PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
