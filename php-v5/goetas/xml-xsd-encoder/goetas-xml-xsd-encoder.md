# goetas/xml-xsd-encoder

> 标签: xml, xsd

## 简介

Convert PHP to XML and viceversa using XML Schema definition as encoding style

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
