# slm/queue-beanstalkd

> 标签: beanstalk, beanstalkd, job, pheanstalk, queue, zf2

## 简介

Zend Framework 2 module that integrates with Beanstalkd queuing system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
