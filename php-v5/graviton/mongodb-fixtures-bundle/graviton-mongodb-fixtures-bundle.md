# graviton/mongodb-fixtures-bundle

> 标签: PHP

## 简介

A drop-in replacement for liip/test-fixtures-bundle that is dependency free and only focuses on MongoDB ODM fixtures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
