# james2doyle/parsetweet

> 标签: function, hashtags, parse, tweet

## 简介

This function can parse tweets and wrap @mentions, #hashtags, and URLs in link tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
