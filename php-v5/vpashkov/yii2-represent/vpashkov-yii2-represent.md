# vpashkov/yii2-represent

> 标签: crud, declarative, laravel, mysql, pgsql, represent, yii2

## 简介

CRUD operations with data structures in relational databases.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
