# jrglasgow/c2patool

> 标签: PHP

## 简介

PHP Wrapper for the c2patool command line utility found at https://github.com/contentauth/c2patool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
