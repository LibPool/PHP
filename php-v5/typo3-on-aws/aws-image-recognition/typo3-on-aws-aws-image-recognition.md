# typo3-on-aws/aws-image-recognition

> 标签: aws, extension, rekognition, typo3

## 简介

Integrates Amazon Web Service (AWS) to detect objects, scenes, faces, recognize celebrities in images uploaded at the TYPO3 backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
