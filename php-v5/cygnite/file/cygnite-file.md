# cygnite/file

> 标签: Cygnite, file, thumbnail, upload

## 简介

Cygnite File Component. This package use for File Upload, Image Thumbnail Creation etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
