# cygnite/stripe

> 标签: Cygnite, cartalyst, php, stripe

## 简介

Cygnite 2.0 integration for the Cartalyst Stripe package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
