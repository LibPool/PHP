# icron/yii-dynamic-model

> 标签: dynamic, extension, model, validation, yii

## 简介

DynamicModel is a model class primarily used to support ad hoc data validation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
