# carsonarrow/silverstripe-weservimage

> 标签: silverstripe

## 简介

Allows manipulation of externally hosted images in SilverStripe templates through weserv/images API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
