# silassare/kli

> 标签: cli, command, command-line, command-line-tool, kli, php-cli

## 简介

Kli helps you add an interactive command-line interface to your php project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
