# guenther/guenther

> 标签: bolt, bolt cms, bootstrap, cli, helper, tool

## 简介

Command line tool to bootstrap and build Bolt CMS extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
