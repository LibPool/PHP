# insign/laravel-decaptcha

> 标签: 2captcha, 2captcha.com, anti-captcha, anti-captcha.com, captcha, captcha24, captcha24.com, curl, laravel, php, pixodrom, pixodrom.com, recognition, rucaptcha, rucaptcha.com, socialink, socialink.ru

## 简介

A Laravel package for captcha recognition for popular services like rucaptcha.com, 2captcha.com, pixodrom.com, captcha24.com, socialink.ru, anti-captcha.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
