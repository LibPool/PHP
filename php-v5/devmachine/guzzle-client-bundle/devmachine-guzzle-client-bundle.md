# devmachine/guzzle-client-bundle

> 标签: Guzzle, api, forumcinemas, markus, rottentomatoes

## 简介

Integration of devmachine Guzzle clients into Symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
