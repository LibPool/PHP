# antoinelemaire/blacklist-bundle

> 标签: blacklist, email

## 简介

Provides a Blacklist system for Symfony using Annotations with Sonata admin integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
