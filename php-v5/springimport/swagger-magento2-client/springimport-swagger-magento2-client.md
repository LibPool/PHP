# springimport/swagger-magento2-client

> 标签: api, php, sdk, swagger

## 简介

Rest API client for Magento 2 generated by swagger-codegen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
