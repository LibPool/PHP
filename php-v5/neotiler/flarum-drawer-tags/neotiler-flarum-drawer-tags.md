# neotiler/flarum-drawer-tags

> 标签: Neo, drawer, flarum, mobile, navigation, tags

## 简介

Neo Mobile Tag Drawer: Moves tags to the mobile navigation drawer for a cleaner and more accessible experience.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
