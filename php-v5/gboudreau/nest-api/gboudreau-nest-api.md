# gboudreau/nest-api

> 标签: api, nest

## 简介

This is a simple library that will allow you to monitor and control your Nest Learning Thermostat, and Nest Protect.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
