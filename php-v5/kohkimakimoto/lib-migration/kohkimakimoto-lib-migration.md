# kohkimakimoto/lib-migration

> 标签: database, db, migrations, mysql

## 简介

LibMigration is a minimum database migration library and framework for MySQL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
