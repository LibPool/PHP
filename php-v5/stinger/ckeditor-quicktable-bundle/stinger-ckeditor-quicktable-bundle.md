# stinger/ckeditor-quicktable-bundle

> 标签: CKEditor, plugin, quick, symfony, table

## 简介

Symfony2 Bundle to integrate the CKEditor plugin quick table

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
