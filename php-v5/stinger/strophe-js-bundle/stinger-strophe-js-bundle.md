# stinger/strophe-js-bundle

> 标签: bosh, browser, message, symfony, websocket, xmpp

## 简介

Symfony2 Bundle to integrate the strophe js library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
