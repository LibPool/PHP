# thecmsthread/installer

> 标签: admin panel installer, cms, composer plugin, plugin installer, thecmsthread, theme installer

## 简介

Installer for the themes, plugins, and the admin panel of the The CMS Thread.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
