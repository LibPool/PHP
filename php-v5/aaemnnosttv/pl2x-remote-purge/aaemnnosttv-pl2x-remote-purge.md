# aaemnnosttv/pl2x-remote-purge

> 标签: PHP

## 简介

A utility to allow for PL2X cache to be purged remotely using a dynamic url.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
