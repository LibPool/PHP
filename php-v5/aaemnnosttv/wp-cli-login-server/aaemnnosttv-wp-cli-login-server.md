# aaemnnosttv/wp-cli-login-server

> 标签: PHP

## 简介

Companion plugin to the WP-CLI Login Command to handle magic passwordless sign-in requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
