# yujin1st/yii2-user

> 标签: User management, yii2, yii2-user, yujin1st

## 简介

Flexible user registration and authentication module for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
