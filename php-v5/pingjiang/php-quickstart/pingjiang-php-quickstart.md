# pingjiang/php-quickstart

> 标签: composer, php, phpunit, quickstart

## 简介

PHP quickstart project using composer manage dependencies and tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
