# paulovitorbal/php-ynab4

> 标签: api, budget, transactions, ynab4

## 简介

API to read and write transactions to a YNAB4 json database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
