# lobostome/furry-bear

> 标签: Sunlight Capitol Words API, Sunlight Congress API, Sunlight Open States API, open data

## 简介

A PHP wrapper for various open data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
