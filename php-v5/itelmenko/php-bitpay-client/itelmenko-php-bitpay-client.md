# itelmenko/php-bitpay-client

> 标签: bitcoin, bitpay

## 简介

PHP Library to work with the new cryptographically secure BitPay API (support for Symfony v5)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
