# cheplv/qtranslate-x

> 标签: i18n, qtranslate-x, qtranslate-xt, wordpress, wordpress-plugin

## 简介

qTranslate-XT (eXTended): Adds a user-friendly multilingual dynamic content management.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
