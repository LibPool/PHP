# fab/mailing

> 标签: TYPO3 CMS, mailing list

## 简介

Define and assign list of recipients in the plugin settings. Users can send bunch of messages to them on the FE.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
