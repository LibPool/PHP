# pa3py6aka/yii2-sape

> 标签: sape, sape.ru, yii 2, yii2, yii2 sape

## 简介

Wrapper for php Sape client for yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
