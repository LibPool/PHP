# alenkalac/symfony-payments-client

> 标签: PHP

## 简介

The client to interact with https://github.com/alenkalac/PHP-Payment-Processor microservice

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
