# mmxca/cakephp-bootstrap

> 标签: bootstrap, cakephp, plugin

## 简介

Twitter Bootstrap 3 packaged as a CakePHP plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/mmxca/cakephp-bootstrap
- 源码仓库：https://github.com/mmxca/cakephp-bootstrap.git
- Packagist 页面：https://packagist.org/packages/mmxca%2Fcakephp-bootstrap
