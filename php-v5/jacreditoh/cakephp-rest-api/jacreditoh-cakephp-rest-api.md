# jacreditoh/cakephp-rest-api

> 标签: api, cakephp, rest

## 简介

CakePHP 3 plugin to provide basic support for building REST API services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
