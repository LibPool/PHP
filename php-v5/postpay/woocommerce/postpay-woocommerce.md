# postpay/woocommerce

> 标签: gateway, payment, postpay, woocommerce, wordpress

## 简介

Postpay Payment Gateway for WooCommerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
