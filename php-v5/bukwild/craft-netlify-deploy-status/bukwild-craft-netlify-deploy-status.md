# bukwild/craft-netlify-deploy-status

> 标签: Craft, cms, craft netlify deploy status, craft-plugin, craftcms

## 简介

Craft plugin that shows Netlify deploy statuses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
