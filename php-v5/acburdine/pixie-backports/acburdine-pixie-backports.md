# acburdine/pixie-backports

> 标签: database, mysql, postgresql, query builder, sql, sqlite

## 简介

A lightweight, expressive, framework agnostic query builder for PHP. Contains backports for PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
