# muspi/feedbundle

> 标签: atom, bundle, feed, rss

## 简介

A Symfony bundle to build RSS feeds from entities, clone from eko/feedbundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
