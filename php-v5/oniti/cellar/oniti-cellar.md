# oniti/cellar

> 标签: PHP

## 简介

Gestion de l'upload et du téléchargement de fichiers sur Cellar, technologie de Clever Cloud

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
