# john-kariuki/potato-orm

> 标签: Potato-ORM, john-kariuki

## 简介

Andela Checkpoint two. A simple agnostic ORM that can perform the basic crud database operations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
