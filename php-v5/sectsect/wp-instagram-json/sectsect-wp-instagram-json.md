# sectsect/wp-instagram-json

> 标签: github, instagram, json, plugin, wordpress

## 简介

Generate JSON file with object data returned from Instagram API for Sandbox Mode.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
