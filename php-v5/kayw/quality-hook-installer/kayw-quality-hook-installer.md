# kayw/quality-hook-installer

> 标签: PHP

## 简介

Install an execute script of specify quality tools to your git pre-commit hook, and it executes only for changed files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
