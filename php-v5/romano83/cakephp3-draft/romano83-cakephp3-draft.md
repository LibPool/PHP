# romano83/cakephp3-draft

> 标签: Behavior, cakephp3, draft, model

## 简介

This Draft plugin give you the ability to quickly create draft system for your models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
