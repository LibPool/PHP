# laker-ls/yii2-ar-image

> 标签: Behavior, extension, widget, widgetInput, yii2

## 简介

A set for upload, delete and display images.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
