# mediabeast/fancy-devbuild

> 标签: admin, build, dev, mediabeast, silverstripe, tool

## 简介

Simple SilverStripe module to trigger a dev/build via ajax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
