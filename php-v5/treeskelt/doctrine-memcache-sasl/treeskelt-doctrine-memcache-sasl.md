# treeskelt/doctrine-memcache-sasl

> 标签: binary, cache, memcache, sasl

## 简介

A PHP Memcache client with binary protocol and SASL support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
