# teamteatime/laravel-filer

> 标签: attachments, files, laravel, laravel-5

## 简介

A simple Laravel ORM file attachment solution supporting multiple relationship types

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
