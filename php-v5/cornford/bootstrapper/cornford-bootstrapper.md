# cornford/bootstrapper

> 标签: alerts, bootstrap, form, laravel, templates, twitter, views

## 简介

An easy way to intergrate Twitter Bootstrap with Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
