# tributemedia/testimonials

> 标签: PHP

## 简介

Provides the Testimonials content type, sample content, and view with page, standard block, and rotating block displays.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
