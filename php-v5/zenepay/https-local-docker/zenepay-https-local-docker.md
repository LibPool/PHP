# zenepay/https-local-docker

> 标签: docker, https, mariadb, nginx, phpmyadmin, ssl

## 简介

Dev evironment with nginx, mariadb, phpmyadmin and ssl cert for localhost

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
