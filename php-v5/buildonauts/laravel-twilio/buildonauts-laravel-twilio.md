# buildonauts/laravel-twilio

> 标签: PHP

## 简介

A simple Laravel service provider and facade for accessing latest version of Twilio/SDK (which supports only PHP7.1+)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
