# vegasje/xero-oauth

> 标签: oauth, xero, xerooauth

## 简介

PHP class for the Xero API V2 http://developer.xero.com/getting-started/code/php/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
