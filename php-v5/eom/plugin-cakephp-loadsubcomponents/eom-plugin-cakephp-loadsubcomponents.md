# eom/plugin-cakephp-loadsubcomponents

> 标签: PHP

## 简介

Plugin CakePHP 2.x for Load SubComponents in SubFolders.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
