# dotsunited/cabinet

> 标签: amazon, file, s3, storage

## 简介

Cabinet is a PHP 5.3+ library providing a simple file storage layer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
