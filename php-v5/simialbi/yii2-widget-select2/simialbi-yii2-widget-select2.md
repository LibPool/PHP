# simialbi/yii2-widget-select2

> 标签: dropdown, select2, widget, yii2, yii2-widgets

## 简介

Yii2 wrapper for the Select2 jQuery plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
