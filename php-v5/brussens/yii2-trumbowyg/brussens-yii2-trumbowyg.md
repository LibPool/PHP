# brussens/yii2-trumbowyg

> 标签: extension, trumbowyg, widget, wysiwyg, yii, yii2

## 简介

Trumbowyg extension for YiiFramework 2.x.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
