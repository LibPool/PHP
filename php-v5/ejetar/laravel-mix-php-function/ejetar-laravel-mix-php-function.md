# ejetar/laravel-mix-php-function

> 标签: laravel, mix, php

## 简介

A lightweight and simple library that adds Laravel Mix's mix() function to your PHP project 🚀

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
