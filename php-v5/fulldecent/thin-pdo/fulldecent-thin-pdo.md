# fulldecent/thin-pdo

> 标签: database, mysql, oracle, pdo, postgresql, wrapper

## 简介

A minimal extension for PHP's PDO class designed to make running SQL statements easier

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
