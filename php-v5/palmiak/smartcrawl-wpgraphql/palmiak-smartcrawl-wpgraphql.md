# palmiak/smartcrawl-wpgraphql

> 标签: smartcrawl, wordpress, wpgraphql

## 简介

A WPGraphQL extension for SmartCrawl.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
