# betothreeprod/markdown-plugin

> 标签: cakephp, markdown, plugin

## 简介

A CakePHP plugin that facilitates the use of PHP Markdown with CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
