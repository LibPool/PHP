# c33s/static-page-content-bundle

> 标签: bundle, c33s, consistency, content, page, static

## 简介

Easy serving of Static Page Content with Symfony using Twig Templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
