# nibynool/fitbit-interface-bundle

> 标签: fitbit, symfony

## 简介

A Symfony >=2.3.0 Bundle for accessing the Fitbit API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
