# rap2hpoutre/nestor

> 标签: Up, laravel, package, rollback, task, transaction

## 简介

Do task, rollback if something goes wrong. Just like database transactions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
