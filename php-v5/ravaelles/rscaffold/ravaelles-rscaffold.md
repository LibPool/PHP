# ravaelles/rscaffold

> 标签: generators, laravel, laravel5, mongodb, scaffold

## 简介

Laravel 5 scaffold that provides easy MongoDB (schemaless) support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
