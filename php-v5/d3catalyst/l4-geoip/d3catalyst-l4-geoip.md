# d3catalyst/l4-geoip

> 标签: Ip information, d3catalyst.com, geoip, ip to location, no local geodatabase required, retrieve location

## 简介

Laravel 4 Library for detecting geogpraphical location info.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
