# newebtime/publish_button-extension

> 标签: Streams, extension, publish, pyrocms

## 简介

Publish and Unpublish buttons for TableBuilder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
