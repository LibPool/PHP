# koolreport/querybuilder

> 标签: PHP Reporting Framework, charts, graphs, mysql reporting tools, php, php reprting tools, query builder, sql query generator

## 简介

Create query by php code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
