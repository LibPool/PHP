# koolreport/platesphp

> 标签: Data Report, Reporting Tools, php, platesphp, template engine

## 简介

Allow KoolReport to use platesphp template engine to render view

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
