# monsieurbiz/mbiz_iwantmysymlinksback

> 标签: PHP

## 简介

Magento module which re-activate the Allow Symlinks configuration in backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
