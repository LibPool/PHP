# eborges78/micrometa

> 标签: PHP

## 简介

A meta parser for extracting micro information out of web documents, currently supporting Microformats 1+2, HTML Microdata, RDFa Lite 1.1 and JSON-LD

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
