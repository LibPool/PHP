# joshtronic/php-redirect

> 标签: 301, 302, forward, http, permanment, redirect, response, temporary

## 简介

Permanent (301) and temporary (302) redirection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
