# marionnewlevant/picture

> 标签: Craft, craftcms, img, lazysizes, picture, plugin, srcset

## 简介

Generate responsive <picture> and <img> elements based on configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
