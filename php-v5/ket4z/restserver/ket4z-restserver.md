# ket4z/restserver

> 标签: http, json, light-weight, mit, php, rest, rest-server

## 简介

PHP REST server for very light-weight REST APIs. forked from Jacob Wright's RestServer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
