# mrottow/vite-wordpress

> 标签: vite, vitejs, wordpress, wordpress vite

## 简介

A collection of back-end utilities for ViteWordpress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
