# ramon/point-system

> 标签: Gamification, auto-group, avatar, decoration, flarum, points, shop

## 简介

Points, avatar frames and group tiers for Flarum 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
