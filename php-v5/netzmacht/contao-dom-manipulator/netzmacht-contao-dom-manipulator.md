# netzmacht/contao-dom-manipulator

> 标签: contao, document, dom, html, manipulate

## 简介

This extension integrates the PHP dom manipulator into Contao.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
