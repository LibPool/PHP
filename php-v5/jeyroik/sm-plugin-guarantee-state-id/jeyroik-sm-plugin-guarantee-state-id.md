# jeyroik/sm-plugin-guarantee-state-id

> 标签: PHP

## 简介

Plugin for jeyroik StateMachine. Guarantee that every state has id.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
