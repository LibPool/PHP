# pmvc-plugin/underscore

> 标签: array, camelcase, plug-in, pmvc, underscore

## 简介

Convert array or camel case to underscore, or underscore to others.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
