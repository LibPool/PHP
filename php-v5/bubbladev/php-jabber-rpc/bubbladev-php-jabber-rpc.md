# bubbladev/php-jabber-rpc

> 标签: ejabberd, jabber, rpc, wrapper, xml, xml-rpc, xmpp

## 简介

PHP wrapper for ejabberd xml-rpc module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
