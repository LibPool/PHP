# artkost/yii2-trumbowyg

> 标签: trumbowyg, widget, wysiwyg, yii 2, yii2

## 简介

The Trumbowyg WYSIWYG Editor widget for yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
