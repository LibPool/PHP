# moafak/laravel-weak-etag-middleware

> 标签: Etag, http, laravel, middleware, weak etag

## 简介

A Laravel middleware to add weak etags to HTTP response headers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
