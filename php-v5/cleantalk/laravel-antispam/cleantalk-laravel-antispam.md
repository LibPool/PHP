# cleantalk/laravel-antispam

> 标签: antispam, cleantalk, laravel

## 简介

Anti-spam laravel extension by CleanTalk with protection against spam bots and manual spam.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
