# cedricblondeau/php-moneris-eselectplus

> 标签: eSELECTplus, moneris

## 简介

An alternative and modern way to access the Moneris eSELECTplus API with PHP 5.3+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
