# windwork/image

> 标签: image, thumb, watermark

## 简介

windwork image component, implement thumb and watermark function. windwork图片处理组件，生支持成缩略图和打水印功能。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
