# 8fold/php-eventbrite-sdk

> 标签: PHP

## 简介

Something that seems easier and more complete than the official Eventbrite SDK for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
