# lw/l10n-translator

> 标签: PHP

## 简介

Translate l10n files (label files) in a TYPO3 backend module. Maintain l10n folder with CLI tasks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
