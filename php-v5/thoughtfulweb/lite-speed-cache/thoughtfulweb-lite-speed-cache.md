# thoughtfulweb/lite-speed-cache

> 标签: Craft, cms, craft-plugin, craftcms, litespeed cache

## 简介

Clear the LiteSpeed cache on page save.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
