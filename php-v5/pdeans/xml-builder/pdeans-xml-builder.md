# pdeans/xml-builder

> 标签: builder, writer, xml, xml builder, xml generator, xml writer

## 简介

Simple and lightweight library to make generating XML a breeze.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
