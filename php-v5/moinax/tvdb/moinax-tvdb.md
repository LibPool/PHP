# moinax/tvdb

> 标签: api

## 简介

PHPTVDB is a PHP library for accessing TV show information such as episodes, actors, showtimes and descriptions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
