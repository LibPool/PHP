# davidnineroc/easy-extends

> 标签: curl, easy, extends, memcache, php, redis

## 简介

一个简单快速安装PHP扩展的程序

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
