# rossjcooper/laravel-amazon-products

> 标签: amazon, api, laravel, paapi, products

## 简介

A Laravel wrapper for the Amazon Products API SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
