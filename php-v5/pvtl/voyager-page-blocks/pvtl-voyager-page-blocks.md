# pvtl/voyager-page-blocks

> 标签: blocks, frontend, laravel, page, voyager

## 简介

Ahoy! - A package to implement page blocks into Voyager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
