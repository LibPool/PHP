# dipnot/paytr-php

> 标签: composer, payment-gateway, paytr, php-library

## 简介

Unofficial PayTR API Wrapper for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
