# heidelpay/modified

> 标签: modified, modified eCommerce, payment-gateway, php, xtc-fork

## 简介

This extension for modified eCommerce provides a direct integration of the heidelpay payment methods to your modified shop.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
