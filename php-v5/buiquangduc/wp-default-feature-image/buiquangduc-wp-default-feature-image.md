# buiquangduc/wp-default-feature-image

> 标签: PHP

## 简介

A WordPress plugin which helps you to choose default feature images for any post types, categories, tags,...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
