# deployecommerce/module-redis-flush

> 标签: PHP

## 简介

Provides the ability to flush Redis via the Cache Management page and provide statistics of Redis consumption.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
