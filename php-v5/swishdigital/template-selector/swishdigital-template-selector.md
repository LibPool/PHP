# swishdigital/template-selector

> 标签: Craft, cms, craft-plugin, craftcms, template selector

## 简介

A fieldtype that allows you to select a template from a dropdown.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
