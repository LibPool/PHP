# jyoungblood/dbkit

> 标签: abstraction, database, mysql, pdo, utilities

## 简介

PHP functions to handle database connection and CRUD operations with PDO.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
