# jyoungblood/s3-client

> 标签: PHP

## 简介

A standalone Amazon S3 (REST) client for PHP using CURL that does not require PEAR.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
