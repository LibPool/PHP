# nlp-tools/nlp-tools

> 标签: machine learning, nlp

## 简介

NlpTools is a set of php 5.3+ classes for beginner to semi advanced natural language processing work.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
