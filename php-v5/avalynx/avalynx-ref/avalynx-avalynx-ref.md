# avalynx/avalynx-ref

> 标签: avalynx, react, ref, vue

## 简介

AvalynxRef is a Ref implementation for updating elements with a value like React's Ref or Vue's Ref.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
