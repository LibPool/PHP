# avalynx/avalynx-simpleadmin

> 标签: admin, avalynx, bootstrap, bootstrap5

## 简介

AvalynxSimpleAdmin is a simple admin interface based on Bootstrap >=5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
