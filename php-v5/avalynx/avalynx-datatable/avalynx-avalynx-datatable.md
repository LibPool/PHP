# avalynx/avalynx-datatable

> 标签: ajax, avalynx, bootstrap, bootstrap5, component, datatable, datatables, datatables-ajax, datatables-serverside, table

## 简介

AvalynxDataTable is a simple, lightweight, and customizable datatable for the web. Based on Bootstrap >=5.3 without any framework dependencies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
