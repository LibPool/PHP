# classy-org/constantcontact-php-client

> 标签: PHP

## 简介

Wrapper around Guzzle Http Client to interact with Constant Contact APIv2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
