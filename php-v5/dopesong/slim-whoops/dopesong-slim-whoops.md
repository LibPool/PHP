# dopesong/slim-whoops

> 标签: error, framework, handler, slim, whoops

## 简介

Slim Framework 3 error handler built on top of the Whoops error handler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
