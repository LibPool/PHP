# aksw/ontowiki

> 标签: Linked Data, OntoWiki, RDF, Semantic Web, Triple Store

## 简介

Semantic data wiki as well as Linked Data publishing engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
