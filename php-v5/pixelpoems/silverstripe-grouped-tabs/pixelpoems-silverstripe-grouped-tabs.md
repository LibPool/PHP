# pixelpoems/silverstripe-grouped-tabs

> 标签: silverstripe

## 简介

Silverstripe module that allows grouped tabs for ModelAdmins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
