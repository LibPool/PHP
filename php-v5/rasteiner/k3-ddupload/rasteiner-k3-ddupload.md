# rasteiner/k3-ddupload

> 标签: PHP

## 简介

Replaces standard image block preview to allow you to directly upload images by drag&dropping them on the block preview.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
