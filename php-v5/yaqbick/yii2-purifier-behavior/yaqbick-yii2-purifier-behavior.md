# yaqbick/yii2-purifier-behavior

> 标签: Behavior, Purifier, extension, yii2

## 简介

Purifier provides an ability to clean up HTML from any harmful code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
