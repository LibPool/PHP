# ijuniorfu/flysystem-oss

> 标签: AliyunOSS, Flysystem, aliyun, oss

## 简介

This is a Flysystem adapter for the Aliyun OSS ^2.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
