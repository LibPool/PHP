# open-telemetry/opentelemetry

> 标签: Metrics, logging, open-telemetry, opentelemetry, otel, tracing

## 简介

OpenTelemetry metapackage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
