# open-telemetry/opentracing-shim

> 标签: opentelemetry, opentracing, otel, shim

## 简介

OpenTracing shim for OpenTelemetry

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
