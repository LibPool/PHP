# omasn/decaptcha-bundle

> 标签: 2captcha, 2captcha.com, anti-captcha, anti-captcha.com, bundle, captcha, captcha24, captcha24.com, decaptcha, pixodrom, pixodrom.com, recognition, rucaptcha, rucaptcha.com, socialink, socialink.ru, symfony

## 简介

Symfony Decaptcha bundle, распознавание капч для всех популярных сервисов rucaptcha.com, 2captcha.com, pixodrom.com, captcha24.com, socialink.ru, anti-captcha.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
