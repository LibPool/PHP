# recaptcha/php5-v2

> 标签: api, captcha, google, php, recaptcha

## 简介

A properly coded PHP 5 reCaptcha class that will allow you to interact with Google's reCaptcha API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
