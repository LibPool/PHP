# drutopia/drutopia

> 标签: PHP

## 简介

Drutopia's base distribution provides an enhanced starting place for building sites for grassroots organizations and other purposes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
