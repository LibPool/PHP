# melhorenvio/php-cs-fixer

> 标签: melhorenvio, php-cs-fixer

## 简介

This package is intended to centralize all PHP CS Fixer rules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
