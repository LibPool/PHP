# rhymedigital/contao_slick

> 标签: carousel, contao, slick

## 简介

Adds the ability to configure a Slick carousel https://github.com/kenwheeler/slick/ within Contao CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
