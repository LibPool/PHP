# jacques/php-smartcall-httpclient

> 标签: PHP

## 简介

Providers an HTTP Client around SmartCall's Restful (v3) API for both Smartcall SmartLoad and SmartRICA

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
