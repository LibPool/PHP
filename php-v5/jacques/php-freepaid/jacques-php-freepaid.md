# jacques/php-freepaid

> 标签: airtime, freepaid

## 简介

Library for interacting with Freepaid's SOAP interface for vending pre-paid Airtime Vouchers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
