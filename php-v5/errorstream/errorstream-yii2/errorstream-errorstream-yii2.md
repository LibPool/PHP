# errorstream/errorstream-yii2

> 标签: errors, errorstream, logging, yii, yii2

## 简介

Yii 2 Package for ErrorStream.com integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
