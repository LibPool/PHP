# loveorigami/yii2-shortcodes-pack

> 标签: plugin, shortcode, yii2

## 简介

Shortcodes collection as WP for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
