# samuelbie/karix

> 标签: Karix, laravel, php, sms, whatsapp

## 简介

Allow you to use karix sms and whatsapp as custom channel in laravel notifications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
