# roerjo/laravel-notifications-sendgrid-driver

> 标签: laravel, sendgrid

## 简介

This library adds a 'sendgrid' notification driver to Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
