# zbin/deploy

> 标签: git, linux, shell, ssh, svn, 发布, 发布脚本

## 简介

支持git，svn版本控制的发布脚本

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
