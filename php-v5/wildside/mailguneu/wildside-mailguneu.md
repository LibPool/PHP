# wildside/mailguneu

> 标签: eu, gdpr, laravel, mailgun

## 简介

Provides a replacement MailServiceProvider in Laravel which requires setting the full Mailgun base URL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
