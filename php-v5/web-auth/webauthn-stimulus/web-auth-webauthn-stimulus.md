# web-auth/webauthn-stimulus

> 标签: FIDO2, fido, symfony, symfony-ux, webauthn

## 简介

Webauthn integration for Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
