# lys/php-shard-upload

> 标签: HTML5, javascript, php, php-shard-upload

## 简介

前端Javascript+Html5+后端PHP分块上传文件，PHP分块上传大文件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
