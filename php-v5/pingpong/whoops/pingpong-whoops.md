# pingpong/whoops

> 标签: errors, laravel, pingpong, whoops

## 简介

With this package you can get the whoops errors style like the laravel's style in versions 4.0 and 4.1.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
