# skeeks/cms-assets-auto-compress

> 标签: JS, Sx, app, assets, auto assets, css, framework, skeeks, yii

## 简介

Automatically compile and merge files js + css for SkeekS CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
