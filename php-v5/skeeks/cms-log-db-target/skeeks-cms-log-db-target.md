# skeeks/cms-log-db-target

> 标签: Sx, app, cms, log, logger, module, skeeks, target, yii2

## 简介

Error logging in mysql database for SkeekS CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
