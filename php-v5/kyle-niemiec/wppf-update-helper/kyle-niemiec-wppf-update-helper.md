# kyle-niemiec/wppf-update-helper

> 标签: PHP

## 简介

A small, importable framework for integrating a WPPF plugin with the WordPress Plugin Update Server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
