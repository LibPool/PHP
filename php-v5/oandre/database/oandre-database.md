# oandre/database

> 标签: PHP

## 简介

A lightweight database layer on top of PHP's PDO that allows you to utilize a database without having to take care of differences in SQL dialects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
