# acacha/adminlte-laravel-installer

> 标签: AdminLTE, admin, bootstrap, laravel, pratt, theme

## 简介

Adminlte-laravel application installer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
