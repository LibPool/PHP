# himiklab/yii2-handsontable-widget

> 标签: grid, handsontable, widget, yii2

## 简介

A minimalist Excel-like grid widget for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
