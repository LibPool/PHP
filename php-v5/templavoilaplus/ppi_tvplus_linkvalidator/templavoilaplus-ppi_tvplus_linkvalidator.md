# templavoilaplus/ppi_tvplus_linkvalidator

> 标签: TemplaVoila, extension, typo3

## 简介

Allows the Link Validator to check links inside TemplaVoilà! Plus elements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
