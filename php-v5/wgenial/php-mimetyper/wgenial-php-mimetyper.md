# wgenial/php-mimetyper

> 标签: PHP

## 简介

PHP mime type and extension mapping library: compatible with Symfony, powered by jshttp/mime-db

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
