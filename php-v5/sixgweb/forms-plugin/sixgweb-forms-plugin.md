# sixgweb/forms-plugin

> 标签: PHP

## 简介

Frontend/Backend form builder for OctoberCMS that utilizes Sixgweb.Attributize and Sixgweb.Conditions plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
