# codetiv/upgates-php-sdk

> 标签: api, php, sdk, upgates

## 简介

Elegant SDK written in PHP to work with the Upgates API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
