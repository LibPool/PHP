# baffo/googleapi

> 标签: api, google, googleapi, laravel, laravel4, v3

## 简介

a Google API v3 wrapper for Laravel 4.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
