# porterai/plugin-simple-admin-branding

> 标签: PHP

## 简介

Lightweight plugin to brand the WordPress login page using the built-in site icon assets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
