# kamal-abouzayed/quick-translate

> 标签: PHP

## 简介

Easily integrate Google Translate API with Laravel to automate multilingual translations across your app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
