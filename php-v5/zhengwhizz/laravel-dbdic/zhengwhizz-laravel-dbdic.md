# zhengwhizz/laravel-dbdic

> 标签: database dictionary, dbdic, laravel, zhengwhizz

## 简介

mysql、postgresql 数据字典，自动读取数据库信息并显示在网页上，支持导出Html和PDF文件。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
