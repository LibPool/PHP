# tod/omnipay-vegaah

> 标签: gateway, merchant, omnipay, pay, payment, vegaah

## 简介

Vegaah gateway for the Omnipay 2.x payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
