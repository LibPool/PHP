# phalcon-plugins/ip-data

> 标签: Phalcon plugin, ip lookup, ipdata.co, phalcon

## 简介

Allows lookup the location of any IP address

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
