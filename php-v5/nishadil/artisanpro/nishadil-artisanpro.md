# nishadil/artisanpro

> 标签: PHP

## 简介

Artisan Pro is an advance laravel artisan command collection. You can use it to create a Service, Trait, View(filename.blade.php), and much more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
