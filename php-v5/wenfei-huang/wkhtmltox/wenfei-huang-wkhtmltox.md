# wenfei-huang/wkhtmltox

> 标签: binary, convert, focal, htmltoimage, htmltopdf, htmltox, jpg, pdf, png, snapshot, thumbnail, ubuntu

## 简介

wkhtmltopdf and wkhtmltoimage linux binaries - Convert HTML to PDF or IMAGE using Webkit (QtWebKit)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
