# wemakecustom/wp-skeleton-installer

> 标签: PHP

## 简介

Installer scripts for https://github.com/wemakecustom/wp-skeleton

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
