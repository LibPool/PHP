# netresearch/file-search-skill

> 标签: PHP

## 简介

AI agent skill for efficient code and file search using ripgrep, ast-grep, fd, rga, tokei

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
