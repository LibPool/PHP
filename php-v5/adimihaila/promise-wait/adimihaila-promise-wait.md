# adimihaila/promise-wait

> 标签: async, promise, reactphp, sync, wait

## 简介

Provides a wait functionality for ReactPHP/Promise library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
