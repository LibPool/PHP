# lancerhe/phpunit-mock

> 标签: function, mock, phpunit, runkit, testing

## 简介

PHPUnit extension to Mock PHP internal functions using Runkit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
