# dancasdev/dqb

> 标签: dqb, php

## 简介

DQB (Dynamic Query Builder) DQB es una librería de PHP diseñada para simplificar la construcción de consultas SQL dinámicas y complejas.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
