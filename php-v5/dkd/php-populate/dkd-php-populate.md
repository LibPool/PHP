# dkd/php-populate

> 标签: json, php, trait

## 简介

Trait for PHP classes, allowing properties to be populated from sources like JSON, via getters but using a single method

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
