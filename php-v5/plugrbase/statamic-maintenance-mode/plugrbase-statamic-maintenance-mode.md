# plugrbase/statamic-maintenance-mode

> 标签: PHP

## 简介

Statamic addon to set the website in maintenance mode and block all non-logged in users from accessing it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
