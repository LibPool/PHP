# tijsverkoyen/uitdatabank

> 标签: PHP

## 简介

PHP UitDatabank is a (wrapper)class to communicate with the UitDatabank Webservices.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
