# flexflux/laravel-elastic-email

> 标签: elastic, elastic email, email, flexflux, laravel

## 简介

Package to send emails with attachements via an Elastic Email Mailer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
