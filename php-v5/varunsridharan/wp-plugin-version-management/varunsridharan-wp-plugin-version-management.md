# varunsridharan/wp-plugin-version-management

> 标签: PHP

## 简介

Simple WordPress Plugin Library To Handle Version Management To Provide Easy Upgrade Handling.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
