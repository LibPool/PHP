# frozzare/wp-conauth

> 标签: conauth, email, login, password

## 简介

Signing in to WordPress by link sent to your email. The link will expire in fifteen minutes and can only be used once.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
