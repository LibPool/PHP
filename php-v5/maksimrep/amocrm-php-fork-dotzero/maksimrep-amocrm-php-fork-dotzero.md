# maksimrep/amocrm-php-fork-dotzero

> 标签: amoCRM, api, crm

## 简介

Удобный и быстрый клиент для работы с API V2 amoCRM(fork dotzero) Добавлен метод работы с компаниями в неразобранном

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
