# bizpay/payments

> 标签: PHP

## 简介

Client SDK package to the BizPay Payments API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/bizpay-nl/payments-examples
- 源码仓库：https://bitbucket.org/bizpay-nl/payments-examples.git
- Packagist 页面：https://packagist.org/packages/bizpay%2Fpayments

## 获取地址

- Composer 安装：`composer require bizpay/payments`
- Packagist 仓库：https://repo.packagist.org/p2/bizpay/payments.json
- PHP 要求：^5.4 || ^7.0
