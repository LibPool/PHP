# frieser/wsse-authentication-bundle

> 标签: Authentication, bundle, wsse

## 简介

Symfony2 bundle to implement WSSE authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
