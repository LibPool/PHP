# omgwagon/laravel-oauth-consumer

> 标签: PHP

## 简介

An OAuth 1.0 Consumer package to be used for signing OAuth messages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
