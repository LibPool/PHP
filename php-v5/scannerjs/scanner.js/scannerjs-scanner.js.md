> 标签: Scanner.js, ScannerJS, Twain, WIA, acquire, and, browser, cameras, document, from, html, images, javascript, jpg, pdf, scan, scanner, scanners, scanning, to, web, webcam

## 简介

ScannerJS: JavaScript web scan JPG PDF images from TWAIN WIA scanners in browser (Chrome, Edge, Firefox or IE)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
