# jeffreycwitt/lombardpress

> 标签: publishing, xml

## 简介

Framework for web publishing transcriptions of commentaries on the Sentences of Peter Lombard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
