# vendic/hyva-checkout-eu-vat-id-format-validator

> 标签: PHP

## 简介

This Magento 2 extension validates the syntax of the VAT ID in the Hyvä checkout for EU countries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
