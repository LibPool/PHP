# claretnnamocha/php-logger

> 标签: clareo, debugging, logging, php-logger, terminal

## 简介

A simple PHP logger used to ouput data to server terminal

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
