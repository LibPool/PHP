# airoinfo/laravel-alert

> 标签: alert, laravel, notifier

## 简介

A simple PHP package to show alerts with the Laravel Framework and Vue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
