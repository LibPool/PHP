# raffaelj/cockpit-rljutils

> 标签: cockpit, cosmetics, dark theme, hardening

## 简介

Addon for Cockpit CMS v1, that adds some hardening, cosmetics and helpers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
