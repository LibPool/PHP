# mostlyserious/craftcms-sveltekit

> 标签: PHP

## 简介

Split monorepo bootstrap for headless Craft CMS projects with a SvelteKit frontend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
