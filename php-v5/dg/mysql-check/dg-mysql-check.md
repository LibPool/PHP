# dg/mysql-check

> 标签: mysql

## 简介

Checks a MySQL database for orphaned records or invalid foreign keys, i.e., keys pointing to missing rows.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
