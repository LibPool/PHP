# eviweb/fuelphp-phpcs

> 标签: PHP

## 简介

PHP Code Sniffer standard for Fuel PHP with dedicated CLI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
