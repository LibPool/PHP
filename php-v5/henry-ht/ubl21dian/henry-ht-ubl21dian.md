# henry-ht/ubl21dian

> 标签: core, dian, soap dian, ubl, web service, xml

## 简介

Core for electronic invoicing pre-validation - DIAN UBL 2.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
