# pmmp/bedrock-item-upgrade-schema

> 标签: PHP

## 简介

JSON schemas for upgrading items found in older Minecraft: Bedrock world saves

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
