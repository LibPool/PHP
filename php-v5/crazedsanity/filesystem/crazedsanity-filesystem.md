# crazedsanity/filesystem

> 标签: dry, filesystem, oaoo, php

## 简介

Library for manipulating the filesystem for all things Crazed(Sanity).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
