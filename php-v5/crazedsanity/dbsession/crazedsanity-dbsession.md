# crazedsanity/dbsession

> 标签: database, dry, oaoo, php, session

## 简介

Library for handling web-based sessions, for all things Crazed(Sanity).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
