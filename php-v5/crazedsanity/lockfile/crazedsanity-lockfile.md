# crazedsanity/lockfile

> 标签: dry, oaoo, php

## 简介

Create a *.lock file, such as to lock down upgrades from running concurrently.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
