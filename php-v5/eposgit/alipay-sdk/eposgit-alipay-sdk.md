# eposgit/alipay-sdk

> 标签: PHP

## 简介

支付宝（蚂蚁金服）开放平台第三方 PHP SDK，基于官方 3.3.0 版本。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://packagist.org/packages/eposgit%2Falipay-sdk
- 源码仓库：https://github.com/eposgit/alipay-sdk.git
- Packagist 页面：https://packagist.org/packages/eposgit%2Falipay-sdk

## 获取地址

- Composer 安装：`composer require eposgit/alipay-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/eposgit/alipay-sdk.json
- PHP 要求：>=5.4
