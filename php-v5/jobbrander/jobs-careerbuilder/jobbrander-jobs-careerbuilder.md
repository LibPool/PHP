# jobbrander/jobs-careerbuilder

> 标签: api client, careerbuilder, jobs, object

## 简介

Making it simple to integrate your application with Careerbuilder Jobs API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
