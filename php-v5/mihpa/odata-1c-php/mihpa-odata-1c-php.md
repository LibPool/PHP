# mihpa/odata-1c-php

> 标签: 1С, 8.3, odata, php

## 简介

Библиотека доступа к 1С:Предприятие 8.3 через протокол OData. Язык программирования PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
