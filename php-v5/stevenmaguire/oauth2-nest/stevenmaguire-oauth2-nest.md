# stevenmaguire/oauth2-nest

> 标签: authorisation, authorization, client, nest, oauth, oauth2

## 简介

Nest OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
