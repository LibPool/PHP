# dlin/keen-bundle

> 标签: keen.io, symfony

## 简介

A Syfmony 2 Bundle for Keen.IO using the office Keen.IO library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
