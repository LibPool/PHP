# schams-net/nagios-extensionlist

> 标签: PHP

## 简介

Generates a list of insecure extensions for EXT:nagios based on the extension list in the current TYPO3 instance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
