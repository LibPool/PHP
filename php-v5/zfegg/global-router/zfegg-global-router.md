# zfegg/global-router

> 标签: global, route, zf2, zfegg

## 简介

Zend Framework V2 or V3 global route config '/[:module[:/controller[:/action]]]'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
