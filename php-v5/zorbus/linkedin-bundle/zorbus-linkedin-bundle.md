# zorbus/linkedin-bundle

> 标签: api, bundle, linkedin, symfony

## 简介

A bundle for the PHP library that interacts with the LinkedIn API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
