# rochamarcelo/cake-pimple-di

> 标签: cake3, cakephp, dependency, injection, pimple, plugin

## 简介

A cakephp plugin for dependency injection based on Pimple library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
