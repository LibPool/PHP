# outtolunch/lightning

> 标签: bulma, laravel-mix, php, vue

## 简介

Lickety-split PHP app with autoloading classes, Vue, Laravel Mix, and the Bulma CSS framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
