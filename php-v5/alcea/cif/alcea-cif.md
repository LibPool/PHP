# alcea/cif

> 标签: CIF, CUI, Validare, php

## 简介

PHP validation for Romanian VAT code (Validare PHP pentru CIF | CUI)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
