# pekral/cursor-rules

> 标签: PHPStan, clean-code, coding-standards, composer-plugin, cursor, cursor-editor, cursor-rules, laravel, laravel-cursor-rules, pest, php, php-cursor-rules, rules

## 简介

Composer plugin for PHP and Laravel projects that installs Cursor/Claude/Codex rules and agent skills — coding standards, testing, and conventions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
