# kevintweber/ktw-database-menu-bundle

> 标签: database, menu

## 简介

Symfony bundle for extending KnpMenuBundle to store menu items in a database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
