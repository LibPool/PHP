# hyperwallet/sdk

> 标签: ach, bankaccount, creditcard, hyperwallet, payout, rest, sdk

## 简介

A library to manage users, transfer methods and payments through the Hyperwallet API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
