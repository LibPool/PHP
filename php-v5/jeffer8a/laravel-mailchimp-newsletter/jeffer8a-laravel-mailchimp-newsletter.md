# jeffer8a/laravel-mailchimp-newsletter

> 标签: PHP

## 简介

Simple mailchimp newsletter subscription box for Laravel 5.* with Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
