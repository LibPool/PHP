# martyn911/whois-parser

> 标签: php, whois, whoisparser

## 简介

Lookup domain names, IP addresses and AS numbers by WHOIS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
