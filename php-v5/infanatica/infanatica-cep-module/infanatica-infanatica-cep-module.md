# infanatica/infanatica-cep-module

> 标签: cep, correios, endereco, framework, modulo, zend, zf2

## 简介

Modulo em Zend Framework 2 para consulta de endereco via CEP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
