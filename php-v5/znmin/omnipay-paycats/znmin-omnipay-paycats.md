# znmin/omnipay-paycats

> 标签: gateway, omnipay, pay, paycats, payment

## 简介

Paycats gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
