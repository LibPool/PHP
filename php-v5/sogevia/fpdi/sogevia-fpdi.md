# sogevia/fpdi

> 标签: fpdf, fpdi, pdf

## 简介

FPDI is a collection of PHP classes facilitating developers to read pages from existing PDF documents and use them as templates in FPDF.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
