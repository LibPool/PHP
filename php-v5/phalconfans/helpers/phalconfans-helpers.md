# phalconfans/helpers

> 标签: PHP7, helpers, phalcon, phalconfans

## 简介

PhalconFans Helpers is a helper function collection for phalcon project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
