# jarouche/viacep

> 标签: Pesquisa, cep, viacep

## 简介

Classe para pesquisar o CEP atraves do servico gratuito viacep

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
