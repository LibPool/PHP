# okcoder/think-swoole-websocket

> 标签: PHP

## 简介

thinkphp6框架think-swoole3类拓展 websocket解析 不想用socketio可以试一下

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
