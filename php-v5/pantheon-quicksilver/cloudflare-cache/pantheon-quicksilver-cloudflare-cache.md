# pantheon-quicksilver/cloudflare-cache

> 标签: PHP

## 简介

Composer-installable script to purge Cloudflare cache when your live environment's cache is cleared

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
