# andrylik/yii2-settings

> 标签: Settings, config, i18n, translate, yii2

## 简介

Settings Manager for Yii2 with the possibility of translating values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
