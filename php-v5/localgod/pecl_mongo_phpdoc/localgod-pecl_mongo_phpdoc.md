# localgod/pecl_mongo_phpdoc

> 标签: mongo

## 简介

Skeleton classes for the PHP PECL mongo extension, for IDE auto completion.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
