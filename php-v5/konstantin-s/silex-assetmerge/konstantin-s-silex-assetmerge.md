# konstantin-s/silex-assetmerge

> 标签: PHP

## 简介

Merging list of JS or CSS files to one.  Merged files is cached to disk. Twig required.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
