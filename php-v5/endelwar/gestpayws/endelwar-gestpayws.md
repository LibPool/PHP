# endelwar/gestpayws

> 标签: bancasella, gestpay, webservice

## 简介

PHP implementation of GestPay (Banca Sella) Web Services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
