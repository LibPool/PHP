# thevelement/laravel-auditable-eloquent

> 标签: PHP

## 简介

Extension to the Laravel Schema Builder to support audit-tracking fields in models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
