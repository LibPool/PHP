# crisu83/yiistrap-widgets

> 标签: bootstrap, extension, widgets, yii, yiistrap

## 简介

Extension library for Yiistrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
