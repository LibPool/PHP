# soee/googletagmanager

> 标签: Neos, flow, google, integration, manager, seo, soee, tag

## 简介

Easily integrates Google Tag Manager code with your Neos website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
