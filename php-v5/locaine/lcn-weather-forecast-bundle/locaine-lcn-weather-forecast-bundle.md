# locaine/lcn-weather-forecast-bundle

> 标签: forecast.io, symfony 2

## 简介

Integrate Weather Forecasts by Forecast.io into your Symfony 2 projects. With API request normalization and caching.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
