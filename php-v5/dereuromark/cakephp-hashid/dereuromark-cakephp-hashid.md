# dereuromark/cakephp-hashid

> 标签: Behavior, cakephp, hashids, plugin

## 简介

A CakePHP plugin to allow using hashids instead of numeric primary keys.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
