# atpay/tokens

> 标签: AtPay, api, payment processing

## 简介

AtPay API bindings for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://developer.atpay.com
- 源码仓库：https://github.com/atpay/atpay_php.git
- Packagist 页面：https://packagist.org/packages/atpay%2Ftokens
