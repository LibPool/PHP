# maximilianoraul/yii2-openldap-user

> 标签:  openldap,  yii2, auth

## 简介

Enable the use of OpenLDAP to authenticate users

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
