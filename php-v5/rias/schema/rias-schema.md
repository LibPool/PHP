# rias/schema

> 标签: Craft, cms, craft-plugin, craftcms, schema

## 简介

A fluent builder Schema.org types and ld+json generator based on Spatie's schema-org package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
