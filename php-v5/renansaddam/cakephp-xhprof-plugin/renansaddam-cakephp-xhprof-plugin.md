# renansaddam/cakephp-xhprof-plugin

> 标签: cakephp, debug, profiling, xhprof

## 简介

Plugin that quickly enables XHProf profiling for your CakePHP application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
