# msgphp/eav

> 标签: ddd, domain-driven-design, eav, entity-attribute-value, rich domain model

## 简介

A domain layer providing basic EAV management

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
