# leafs/api-starter

> 标签: api, framework, leaf, leaf api, leafPHP, mvc

## 简介

A lightweight PHP MVC framework for rapid API development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
