# ygalescot/behat-swarrot-context

> 标签: PHP

## 简介

Behat Swarrot Context to test AMQP messages, based on Swarrot library and PECL AMQP php extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
