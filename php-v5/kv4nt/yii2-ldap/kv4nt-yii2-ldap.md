# kv4nt/yii2-ldap

> 标签: Authentication, active-directory, authorization, extension, ldap, ldap-authentication, user-management, yii2, yii2-extension

## 简介

Authorize, search users, get user groups and other from LDAP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
