# aira-virtual/promocodes

> 标签: coupon code, discount code, laravel, php, promo code

## 简介

Promotional Codes Generator for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
