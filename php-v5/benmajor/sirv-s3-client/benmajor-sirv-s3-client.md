# benmajor/sirv-s3-client

> 标签: cdn, s3, sirv, sirvs3

## 简介

A simple PHP client for the Sirv S3 service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
