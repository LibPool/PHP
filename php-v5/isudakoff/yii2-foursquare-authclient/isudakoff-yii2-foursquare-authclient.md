# isudakoff/yii2-foursquare-authclient

> 标签: authclient, foursquare, oauth, yii2

## 简介

Foursquare extension for using via yii2-authclient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
