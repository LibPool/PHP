# sammyk/facebook-query-builder

> 标签: facebook, graph api, sdk

## 简介

An elegant and efficient way to generate nested requests for Facebook's Graph API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
