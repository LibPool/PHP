# exactquery/xq-sassy

> 标签: assetic, php, pleasing, sass, sassc, scss

## 简介

PHP Drivers for Dart Sass, SassC, PHP Sass, and scssphp, designed to work with Assetic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
