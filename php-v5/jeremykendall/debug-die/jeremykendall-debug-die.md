# jeremykendall/debug-die

> 标签: convenience function, debugging, helper, helper function

## 简介

Convenience wrapper around var_dump() and die(var_dump())

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
