# ner0tic/jquery-plus-bundle

> 标签: javascript, jquery, jquery-ui

## 简介

Bundle for Symfony2 containing often used jquery plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
