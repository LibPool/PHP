# kksoftwareag/slickcarousel

> 标签: PHP

## 简介

slick - the last carousel you'll ever need. For more informations please have a look at https://github.com/misterboe/slickcarousel. If you need more features please create an issue on github.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
