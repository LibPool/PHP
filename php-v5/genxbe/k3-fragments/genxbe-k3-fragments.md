# genxbe/k3-fragments

> 标签: PHP

## 简介

Kirby3 plugin to make it possible to use translated strings that can be easily translated in the panel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
