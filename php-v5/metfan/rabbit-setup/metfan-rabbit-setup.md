# metfan/rabbit-setup

> 标签: api, rabbitmq, setup

## 简介

Tools to ease creation of exchanges, queues, parameters on rabbitMQ

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
