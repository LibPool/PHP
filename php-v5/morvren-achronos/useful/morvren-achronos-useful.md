# morvren-achronos/useful

> 标签: PHP

## 简介

Useful is a PHP non-framework. It's a collection use utility classes. Take what you want, leave the rest.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
