# stru/stru-hyperf-auth

> 标签: PHP

## 简介

集成到Hyperf中类似 Laravel 的 Auth 组件， 配合 stru/stru-hyperf-ui 使用可提供界面

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
