# ben-tech/tree-purview

> 标签: interface, tree, treegrid, treeview, yii2

## 简介

Extension for Yii2 Framework to work with jQuery TreeGrid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
