# diggindata/yii2-kjua

> 标签: kjua, qrcode, widget, yii2

## 简介

Yii2 widget to display a QRCode using the kjua library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
