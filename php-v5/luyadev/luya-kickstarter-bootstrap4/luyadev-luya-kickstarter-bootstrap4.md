# luyadev/luya-kickstarter-bootstrap4

> 标签: PHP

## 简介

LUYA boilerplate to kickstart projects with Bootstrap 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
