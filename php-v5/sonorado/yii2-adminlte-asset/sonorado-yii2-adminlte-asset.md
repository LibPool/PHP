# sonorado/yii2-adminlte-asset

> 标签: AdminLTE, admin, asset, backend, css, extension, less, theme, yii2

## 简介

AdminLTE backend theme asset bundle for Yii 2.0 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
