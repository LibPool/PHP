# alphayax/phpdoc_md

> 标签: Documentation generator, markdown, phpdoc

## 简介

A PHPDoc markdown documentation generator in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
