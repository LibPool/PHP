# zogot/constraints-date

> 标签: PHP

## 简介

DateTime Constraints Library. Use this to add constraints to a validator and verify DateTime objects pass those constraints.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
