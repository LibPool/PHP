# hectorjunior/silex-mailchimp-api

> 标签: PHP

## 简介

Super-simple, minimum abstraction MailChimp API v3 wrapper for Silex PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
