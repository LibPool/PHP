# mailboxvalidator/mailboxvalidator-cakephp

> 标签: cakephp, email validation, mailboxvalidator

## 简介

MailboxValidator plugin for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
