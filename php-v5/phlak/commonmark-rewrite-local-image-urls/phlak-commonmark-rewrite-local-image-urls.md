# phlak/commonmark-rewrite-local-image-urls

> 标签: PHP

## 简介

CommonMark extension for rewriting local, relatiave image URLs to absolute URLs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
