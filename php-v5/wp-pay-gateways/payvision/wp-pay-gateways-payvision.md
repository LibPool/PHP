# wp-pay-gateways/payvision

> 标签: gateway, pay, payvision, pronamic, wordpress, wp

## 简介

Payvision driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
