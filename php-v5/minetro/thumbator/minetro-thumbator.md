# minetro/thumbator

> 标签: PHP

## 简介

Easy-use util for resizing images on website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/minetro/thumbator.git
