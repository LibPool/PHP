# shanmuga/laravel-cloudinary

> 标签: cloudinary, laravel, laravel-cloudinary, php, shanmuga

## 简介

Cloudinary Wrapper for Laravel 5,6 and 7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
