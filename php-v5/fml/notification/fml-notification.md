# fml/notification

> 标签: abdulklarapl, funky, funkymonkeylabs, mail, monkey, notification, sms

## 简介

Library which help you to send notification via different channels

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
