# hello-motto/config-service-provider

> 标签: serviceprovider, silex, yaml

## 简介

A service provider to configurate silex ~2.0 with yaml, json and php files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
