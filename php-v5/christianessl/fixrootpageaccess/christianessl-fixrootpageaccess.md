# christianessl/fixrootpageaccess

> 标签: extension, typo3

## 简介

Resolves #87985 on Forge, where editors cannot save changes on the root page of multilanguage sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
