# t3brightside/youtubevideo

> 标签: gdpr, responsive, typo3, video, youtube

## 简介

TYPO3 CMS extension for YouTube videos with custom cover images, gallery layout, pagination, GDPR options and backend previews.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
