# t3brightside/formcsv

> 标签: PHP

## 简介

TYPO3 v14 Form Finisher to generate and attach a custom mapped CSV file to email finishers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
