# t3brightside/microtemplate

> 标签: design, fluid, template, typo3

## 简介

TYPO3 CMS template – sectioned one pager with light box like sub pages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
