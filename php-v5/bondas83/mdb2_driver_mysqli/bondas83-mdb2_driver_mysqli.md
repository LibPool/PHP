# bondas83/mdb2_driver_mysqli

> 标签: PEAR, database, mdb2, mysqli

## 简介

This is the Mysqli MDB2 driver.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
