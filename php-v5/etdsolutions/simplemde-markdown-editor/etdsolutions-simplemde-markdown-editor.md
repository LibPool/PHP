# etdsolutions/simplemde-markdown-editor

> 标签: PHP

## 简介

A simple, beautiful, and embeddable JavaScript Markdown editor. Features autosaving and spell checking.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
