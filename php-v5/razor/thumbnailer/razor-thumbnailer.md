# razor/thumbnailer

> 标签: crop, image, thumbnail, watermark, zf2

## 简介

An image thumbnailer service module for Zend Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
