# siebird/craft-watchtower

> 标签: Craft, cms, craft-plugin, craft-queue, craftcms, cron-job, monitoring, oh-dear, ohdear, queue, queue-manager, siebird

## 简介

Monitors the Craft queue manager for bottlenecks and send notifications emails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
