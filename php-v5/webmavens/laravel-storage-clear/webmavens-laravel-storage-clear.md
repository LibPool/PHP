# webmavens/laravel-storage-clear

> 标签: PHP

## 简介

Laravel package for Clear a specific folder or all contents of a given storage disk (e.g., local, public, s3)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
