# matthewbdaly/unframework

> 标签: PHP

## 简介

Not a framework. An opinionated collection of PHP libraries and some simple glue code binding them together.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
