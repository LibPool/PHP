# kagagnon/bem-php

> 标签: BEM, blade, laravel, php, shortcode

## 简介

PHP shortcodes to generate BEM class with a Laravel integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
