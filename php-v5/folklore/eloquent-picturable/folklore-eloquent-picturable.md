# folklore/eloquent-picturable

> 标签: cms, content, eloquent, image, laravel, picture

## 简介

Laravel 4 package to add pictures capabilities to Eloquent Models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
