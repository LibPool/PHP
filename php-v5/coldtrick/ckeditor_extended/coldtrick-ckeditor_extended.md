# coldtrick/ckeditor_extended

> 标签: CKEditor, elgg, plugin, wysiwyg

## 简介

offers you the ability to change the configuration of the editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
