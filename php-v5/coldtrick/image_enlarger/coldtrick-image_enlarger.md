# coldtrick/image_enlarger

> 标签: content, elgg, images, plugin

## 简介

Allows images to be enlarged in content. Clicking them will open a lightbox with the image.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
