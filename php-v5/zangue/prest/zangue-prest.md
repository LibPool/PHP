# zangue/prest

> 标签: api, client, pest, php, prest, rest

## 简介

A REST client for PHP based on Pest.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/zangue/prest.git
