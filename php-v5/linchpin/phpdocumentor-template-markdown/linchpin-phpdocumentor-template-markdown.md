# linchpin/phpdocumentor-template-markdown

> 标签: PHP

## 简介

phpDocumentor Template for github Wiki. Forked from oliveratgithub/phpDocumentor-Template-ghwiki

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
