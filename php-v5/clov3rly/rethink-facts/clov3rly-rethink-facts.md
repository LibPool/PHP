# clov3rly/rethink-facts

> 标签: custom-post-type, plugin, wordpress

## 简介

Adds the facts custom post type to the Rethink Tobacco website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
