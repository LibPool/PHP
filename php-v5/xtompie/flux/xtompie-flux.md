# xtompie/flux

> 标签: events, logs, logstash

## 简介

Tool for managing events and logs. Collect, transform, stash with inputs, filters and outputs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
