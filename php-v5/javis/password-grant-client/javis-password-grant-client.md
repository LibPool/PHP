# javis/password-grant-client

> 标签: api, client, grant, http, oauth2, password

## 简介

A PHP library to easily OAuth2 to your APIs using the Password Grant

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
