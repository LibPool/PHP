# fewedev/php-bin

> 标签: nativephp, php

## 简介

PHP binaries used by the NativePHP framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://nativephp.com
- 源码仓库：https://github.com/fewe-dev/php-bin.git
- Packagist 页面：https://packagist.org/packages/fewedev%2Fphp-bin
