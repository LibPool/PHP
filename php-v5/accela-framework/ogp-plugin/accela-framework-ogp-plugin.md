# accela-framework/ogp-plugin

> 标签: Accela, SPA, ogp, open graph, php framework, twitter card

## 简介

OGP (Open Graph Protocol) meta tags generator for Accela

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
