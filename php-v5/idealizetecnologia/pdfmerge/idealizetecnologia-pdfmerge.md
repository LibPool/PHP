# idealizetecnologia/pdfmerge

> 标签: fpdf, merge, pdf

## 简介

Ferramenta para Juntar arquivos PDF em um só

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
