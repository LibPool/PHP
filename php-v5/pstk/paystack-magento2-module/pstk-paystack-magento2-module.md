# pstk/paystack-magento2-module

> 标签: PHP

## 简介

Paystack Magento2 Module using \Magento\Payment\Model\Method\AbstractMethod

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
