# iaretedd/pixelizer

> 标签: PHP

## 简介

Pixelizer is a PHP library that allows you to convert any data into a PNG picture and decode it back into the original data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
