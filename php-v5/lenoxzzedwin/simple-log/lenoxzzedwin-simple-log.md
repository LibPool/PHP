# lenoxzzedwin/simple-log

> 标签: file, log, write

## 简介

A simple package for write in a file all messages and variables sets ,inspired by https://www.redips.net/php/write-to-log-file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
