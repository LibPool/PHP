# hqsoft/reportkit

> 标签: csv, excel, layout, pdf, php, reportes

## 简介

Framework para generar reportes y documentos en PDF, Excel y CSV mediante un layout de 24 columnas.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
