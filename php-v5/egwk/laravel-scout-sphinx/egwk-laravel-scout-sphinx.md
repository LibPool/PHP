# egwk/laravel-scout-sphinx

> 标签: laravel, search, sphinxsearch

## 简介

Sphinx Search Engine for Laravel Scout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
