# turkeyfried/uglifycss-dist

> 标签: css, minify, stylesheet, uglify

## 简介

Port of YUI CSS Compressor to NodeJS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
