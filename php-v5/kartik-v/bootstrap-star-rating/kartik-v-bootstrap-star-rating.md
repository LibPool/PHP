# kartik-v/bootstrap-star-rating

> 标签: Rating, awesome, bootstrap, font, glyphicon, star, svg

## 简介

A simple yet powerful JQuery star rating plugin for Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
