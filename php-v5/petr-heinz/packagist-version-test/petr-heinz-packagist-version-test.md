# petr-heinz/packagist-version-test

> 标签: PHP

## 简介

Repo made for testing versions in format SERIES.MAJOR.MINOR.PATCH, eg. 7.1.0.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
