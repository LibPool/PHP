# weboap/winput

> 标签: Html Purifier, framework, input, laravel, security, xss

## 简介

yet another Laravel 4 XSS (CI Based) & html input filter for laravel4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
