# riper/dissect

> 标签: PHP

## 简介

Toolkit to manipulate metrics report from phpunit/phpmd/phpcs/phpcpd/pdepend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
