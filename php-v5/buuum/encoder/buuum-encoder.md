# buuum/encoder

> 标签: crypt, decode, decoding, decrypt, encode, encoding

## 简介

A simple library to encode and decode data in PHP. Crypt/Decrypt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
