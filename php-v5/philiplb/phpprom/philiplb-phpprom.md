# philiplb/phpprom

> 标签: performance measurement, prometheus, silex

## 简介

PHPProm is a library to measure some performance relevant metrics and expose them for Prometheus

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
