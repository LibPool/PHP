# pmvc/pmvc

> 标签: framework, mvc, phramework, plug, plug-in, pmvc

## 简介

Pure plugin framework (PMVC with PHP8), use anything you like. No mvc, http inside.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
