# phillarmonic/cpf-cnpj

> 标签: cnpj, cpf, formatting, validation

## 简介

A PHP library for validating and formatting CPF and CNPJ numbers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
