# waas-hero/waas-builder-mu

> 标签: PHP

## 简介

This plugin stores all media to cloud. High performance one click implementation of object cache and Google Cloud CDN for Waashero cloud platform users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
