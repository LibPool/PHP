# kamikax/wtsphinxphp

> 标签: api, search, sphinx

## 简介

Sphinx Search PHP 5.3+ API with PSR compliance / old version string filter recovery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
