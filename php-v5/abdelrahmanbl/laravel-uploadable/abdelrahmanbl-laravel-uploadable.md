# abdelrahmanbl/laravel-uploadable

> 标签: PHP

## 简介

this package adding behaviour to a model for self uploading images like avatar or any files type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
