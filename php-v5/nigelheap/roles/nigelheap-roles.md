# nigelheap/roles

> 标签: acl, auth, illuminate, laravel, permissions, roles

## 简介

Powerful package for handling roles and permissions in Laravel 5.3 and 5.6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
