# garvinhicking/adhoc-tasks

> 标签: PHP

## 简介

Allows to run any TYPO3 (v14+) Scheduler Task on the command line, with custom configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
