# r15ch13/peculiar

> 标签: ardent, eloquent, guid, laravel, model, sentry, uuid

## 简介

An extension to the Laravel Eloquent Model. It allows the use of UUIDs (ramsey/uuid) as primary keys.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
