# luzilla/hcloud-housekeeping

> 标签: PHP

## 简介

An auxillary script for Molecule to clean-up orphaned instances, volumes and SSH keys on Hetzner Cloud.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
