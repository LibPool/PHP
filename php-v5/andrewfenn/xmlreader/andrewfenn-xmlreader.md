# andrewfenn/xmlreader

> 标签: XMLReader, XMLWriter, dom, xml

## 简介

andrewfenn/xmlreader is an XML library that makes sabre/xml package easier to use

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
