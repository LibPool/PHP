# jan-vince/smallextensions-plugin

> 标签: PHP

## 简介

Set of small tools for Rainlab.Pages and Rainlab.Blog plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
