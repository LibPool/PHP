# laravelarab/tarjama

> 标签: eloquent, i8n, laravel, laravel-package, model, multilingual, tarjama, translate, translation

## 简介

It's a laravel model columns translation manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
