# eyeem/php-wrapper

> 标签: PHP

## 简介

Wrapper for Eyeem API V2 and PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/eyeem/API-php-wrapper
- 源码仓库：https://github.com/eyeem/php-wrapper.git
