# vi-kon/laravel-auth

> 标签: Authentication, laravel, permission, role, route

## 简介

Role-permission based authenticator for Laravel 5.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
