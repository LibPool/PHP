# misarji/zend-oauth2

> 标签: module, oauth2, zf2

## 简介

Great OAuth2 client for ZF2. It provides clients for github, google, facebook and linkedin, others are coming soon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
