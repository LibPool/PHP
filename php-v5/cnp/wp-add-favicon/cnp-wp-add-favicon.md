# cnp/wp-add-favicon

> 标签: PHP

## 简介

Customize favicon definitions per host and front-end/back-end. Includes filter for favicon uri modification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
