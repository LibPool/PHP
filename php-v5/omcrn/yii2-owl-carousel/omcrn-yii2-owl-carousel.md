# omcrn/yii2-owl-carousel

> 标签: assetBundle, extension, owl, owl-carousel, widget, yii2

## 简介

Simple owl carousel widget for yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
