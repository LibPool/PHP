# omcrn/yii2-i18ncontent

> 标签: cms, i18n articles, i18n carousels, i18n pages, module, yii2

## 简介

Show text widgets, pages, articles in chosen language

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
