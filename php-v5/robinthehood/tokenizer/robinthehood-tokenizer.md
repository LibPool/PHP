# robinthehood/tokenizer

> 标签: lexer, parser, token, tokenizer

## 简介

With Tokenizer you can easily convert a string to a stream or array of tokens.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
