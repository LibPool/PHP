# galmet/mpdf-port-bundle

> 标签: mpdf, pdf

## 简介

A wrapper for mPDF class which allows to use mPDF in Symfony2 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
