# piercemcgeough/phpquartiles

> 标签: PierceMcGeough, phpquartiles

## 简介

PHP package for working out quartile values and placements based on a numeric array

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
