# brebvix/workerman

> 标签: asynchronous, event-loop

## 简介

An asynchronous event driven PHP framework for easily building fast, scalable network applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
