# dragonee/php-silverplate

> 标签: html, markdown, silverplate, static, website

## 简介

A minimal stack for creating static HTML/Markdown websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
