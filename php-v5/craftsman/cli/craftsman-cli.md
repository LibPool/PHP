# craftsman/cli

> 标签: cli, codeigniter, craftsman

## 简介

Craftsman CLI provides a number of helpful commands for your use while developing your Codeigniter application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
