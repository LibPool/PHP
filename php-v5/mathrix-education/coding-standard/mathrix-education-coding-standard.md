# mathrix-education/coding-standard

> 标签: coding, mathrix, phpcs, rules, sniffs, standard, style

## 简介

The official Mathrix PHP_CodeSniffer coding standard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
