# yiiviet/yii2-n2w

> 标签: Behavior, extension, n2w, number-to-words, yii2

## 简介

Behavior hổ trợ chuyển đổi số sang chữ số.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
