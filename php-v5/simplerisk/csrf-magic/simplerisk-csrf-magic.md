# simplerisk/csrf-magic

> 标签: csrf, php, security

## 简介

Cross Site Request Forgery security library. Fork from ezyang/csrf-magic with extra functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
