# gorriecoe/silverstripe-htmltag

> 标签: html, markup, silverstripe, templates

## 简介

Provides a simply method for wrapping strings with html tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
