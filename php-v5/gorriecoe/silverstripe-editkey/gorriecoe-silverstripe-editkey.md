# gorriecoe/silverstripe-editkey

> 标签: edit, silverstripe

## 简介

Enables the use of the key press ctrl+e or alt+e to access cms page edit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
