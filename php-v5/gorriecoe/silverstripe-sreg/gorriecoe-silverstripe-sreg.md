# gorriecoe/silverstripe-sreg

> 标签: silverstripe, sreg, tokenizer

## 简介

Simple tokenizer that allows you to use .ss template like variables in a dataobjects string.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
