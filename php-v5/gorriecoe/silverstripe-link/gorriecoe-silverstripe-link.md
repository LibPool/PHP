# gorriecoe/silverstripe-link

> 标签: link, silverstripe

## 简介

Adds a Link Object that can be link to a URL, Email, Phone number, an internal Page or File.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
