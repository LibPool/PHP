# nicard/laravel-kahlan

> 标签: BDD, Kahlan, TDD, laravel, spec, testing

## 简介

Kahlan specs suite for testing Laravel applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
