# elshaden/apiato-otpkey

> 标签: 2fa, Autenticator, MFA, api, apiato, framework

## 简介

Implementation of 2 factor Authentication using TOTP In Apiato Projects .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
