# drteam/pcrecruiter

> 标签: pcr, pcrecruiter, rest-api

## 简介

PHP library for work with PCRecruiter RESTful API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
