# rajangdavis/osvc_php

> 标签: PHP

## 简介

An unofficial PHP wrapper for Oracle Service Cloud (fka RightNow Technologies) REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
