# post2go/microsoft-translator-service-provider

> 标签: Microsoft Translator, bing, translate

## 简介

Silex service provider for using the Microsoft Translator V2 API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
