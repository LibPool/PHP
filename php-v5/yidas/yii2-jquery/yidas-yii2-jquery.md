# yidas/yii2-jquery

> 标签: asset, asset bundle, jquery, yii, yii2

## 简介

jQuery Asset Bundle extension with fixed and CDN sources for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
