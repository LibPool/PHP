# yidas/client-ip

> 标签: IP, client ip, loadbalancer ip, proxy ip, real ip

## 简介

Get client IP with safe and coincident way from server even behind Proxy or Load-Balancer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
