# yidas/yii2-helpers

> 标签: bootstrap, extension, helper, utilities, yii, yii2

## 简介

A collection of useful helpers for Yii Framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
