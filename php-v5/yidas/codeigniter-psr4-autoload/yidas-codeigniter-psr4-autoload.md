# yidas/codeigniter-psr4-autoload

> 标签: PSR-4, autoload, autoloader, codeigniter

## 简介

CodeIgniter 3 PSR-4 Autoloader for Application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
