# microdesign/chatify

> 标签: Messenger, chat, conversations, laravel, php, pusher, real-time, realtime

## 简介

A package for Laravel PHP Framework to add a complete real-time chat system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
