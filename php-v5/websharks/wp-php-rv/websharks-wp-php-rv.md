# websharks/wp-php-rv

> 标签: php, websharks, wordpress, wpsharks

## 简介

Stub for WordPress themes/plugins that require PHP vX.x+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
