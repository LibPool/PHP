# buzorin/php-cobinhood-api

> 标签: api, cobinhood

## 简介

A simple to use API-client in PHP for Cobinhood The World's First ZERO Trading Fees Cryptocurrency Exchange.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
