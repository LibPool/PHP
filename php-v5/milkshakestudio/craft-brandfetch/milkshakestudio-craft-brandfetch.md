# milkshakestudio/craft-brandfetch

> 标签: Craft, brandfetch, cms, craft-plugin, craftcms

## 简介

Craft CMS Plugin that allows you quickly get the logo of a website via the Brandfetch API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
