# itiden/statamic-fa-widget

> 标签: fathom analytics, laravel, statamic

## 简介

Statamic addon to add a widget with statistics from Fathom Analytics

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
