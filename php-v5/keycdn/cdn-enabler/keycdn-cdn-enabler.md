# keycdn/cdn-enabler

> 标签: PHP

## 简介

A content delivery network (CDN) integration plugin for WordPress that rewrites URLs, like for CSS, JavaScript, and images, to be served by a CDN.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
