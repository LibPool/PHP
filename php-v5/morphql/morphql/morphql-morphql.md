# morphql/morphql

> 标签: csv, data-transformation, edifact, json, morphql, transform, xml

## 简介

PHP wrapper for MorphQL — transform data with declarative queries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
