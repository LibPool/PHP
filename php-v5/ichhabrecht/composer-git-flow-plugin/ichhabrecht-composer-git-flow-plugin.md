# ichhabrecht/composer-git-flow-plugin

> 标签: PHP

## 简介

This plugin allows to use repositories using the Git Flow workflow (or any other branching model) with Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
