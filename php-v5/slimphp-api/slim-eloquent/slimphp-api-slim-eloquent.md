# slimphp-api/slim-eloquent

> 标签: api, eloquent, orm, slim, slimapi

## 简介

A module for slim-api for eloquent integration, using eloquent as the ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
