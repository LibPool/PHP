# slimphp-api/slim-mvc

> 标签: PHP

## 简介

A module for slim-api for mvc, creating structure, generators for creating controllers/models and scaffold

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
