# l0gin/slim-3-poo-skeleton

> 标签: MDL, Skeleton, boilerplate, slim-framework

## 简介

Slim Framework 3 POO skeleton with Web, Secured API and Cli endpoints.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
