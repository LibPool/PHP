# dragonfly/lists

> 标签: action, bulk, datatables, grid, helper, laravel, request, table

## 简介

Laravel DataTables generator/request handler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
