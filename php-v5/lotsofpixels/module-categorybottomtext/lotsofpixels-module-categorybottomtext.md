# lotsofpixels/module-categorybottomtext

> 标签: PHP

## 简介

Adds a text field at the bottom of the category page (PLP) for SEO purposes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
