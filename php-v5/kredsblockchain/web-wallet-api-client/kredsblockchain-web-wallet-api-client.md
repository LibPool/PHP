# kredsblockchain/web-wallet-api-client

> 标签: WebWallet, api, client, php, rest

## 简介

A Client for using the the Kreds WebWallet API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
