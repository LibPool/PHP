# andrey-tech/calendar-js

> 标签: calendar, cssgrid, javascript, jquery

## 简介

Класс Calendar. Формирует календарь на год или на месяц с версткой CSS Grid Layout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
