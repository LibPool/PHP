# cyrodjohn/l5-media-manager

> 标签: browser, file, laravel, manager, media, package

## 简介

Creates an amazing user interface for upload media files and manage them

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
