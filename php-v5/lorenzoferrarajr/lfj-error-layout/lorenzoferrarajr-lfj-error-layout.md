# lorenzoferrarajr/lfj-error-layout

> 标签: zf2

## 简介

LfjErrorLayout is a ZF2 module that allows you to use an alternative layout when a dispatch errors occur.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
