# beastbytes/yii2-leaflet

> 标签: leaflet, map, mapping, maps, widget, yii2

## 简介

Yii2 extension to integrate the Leaflet JavaScript mapping library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
