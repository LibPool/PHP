# mediawiki/numer-alpha

> 标签: formatting, mediawiki

## 简介

Provides methods of inserting incrementing numbers, letters, and roman numerals into MediaWiki.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
