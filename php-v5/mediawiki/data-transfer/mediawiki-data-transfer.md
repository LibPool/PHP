# mediawiki/data-transfer

> 标签: csv, export, import, mediawiki, xml

## 简介

A MediaWiki extension for importing and exporting data in CSV and XML formats.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
