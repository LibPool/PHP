# mediawiki/piwik-integration

> 标签: matomo, mediawiki, piwik

## 简介

The Matomo (ex-Piwik) extension inserts your Matomo tracking code to the bottom of every page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
