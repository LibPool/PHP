# transport-canada-php/pcoc

> 标签: PHP

## 简介

Unofficial PHP Interface for Transport Canada's Pleasure Craft Operator Competency Database System

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
