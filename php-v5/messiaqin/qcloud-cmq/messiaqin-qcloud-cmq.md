# messiaqin/qcloud-cmq

> 标签: cmq, laravel, php, qcloud, tencent

## 简介

Tencent cloud cmq queue driver for laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
