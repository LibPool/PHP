# zentheme/wpikaday

> 标签: calendar, pikaday, wordpress customizer

## 简介

A Pikaday calendar Control for Wordpress customizer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
