# regulus/solid-site

> 标签: PHP

## 简介

A Laravel 5 composer package that assigns section names & titles to pages, simplifies creation of breadcrumb trails, pagination, and other components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
