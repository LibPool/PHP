# ddelrio1986/ninja-service-layer

> 标签: doctrine2, zf2

## 简介

A ZF2 module which allows the easy creation of a service layer using Doctrine2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
