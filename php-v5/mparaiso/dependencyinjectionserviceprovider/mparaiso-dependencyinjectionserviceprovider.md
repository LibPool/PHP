# mparaiso/dependencyinjectionserviceprovider

> 标签: container, dependency-injection, extensions, silex

## 简介

Dependency injection service provider for Silex

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
