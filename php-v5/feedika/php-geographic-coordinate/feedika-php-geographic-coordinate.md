# feedika/php-geographic-coordinate

> 标签: coordinate, geographic, location, php

## 简介

php-geographic-coordinate is a PHP geographic coordinate library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
