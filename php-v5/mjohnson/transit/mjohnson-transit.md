# mjohnson/transit

> 标签: application, archive, audio, cloud, cloudfiles, exif, file, glacier, image, importer, opencloud, rackspace, s3, text, transformer, transit, transporter, uploader, validator, video

## 简介

A file uploader with support for validation, image transformation and remote transportation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
