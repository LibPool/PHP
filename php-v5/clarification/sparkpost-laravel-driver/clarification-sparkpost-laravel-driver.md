# clarification/sparkpost-laravel-driver

> 标签: driver, laravel, mail, sparkpost

## 简介

Sparkpost mail driver for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
