# f21/dnsmadeeasy

> 标签: DNSMadeEasy, api, php

## 简介

A simple php library to work with DNSMadeEasy's API v2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
