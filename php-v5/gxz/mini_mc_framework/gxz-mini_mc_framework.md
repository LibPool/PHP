# gxz/mini_mc_framework

> 标签: framework, mc, mini_framework

## 简介

基于TP-ORM组件框架, 小型的数据处理操作业务以组件的形式提供

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
