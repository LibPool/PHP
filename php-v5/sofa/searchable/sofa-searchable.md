# sofa/searchable

> 标签: eloquent, laravel, searchable

## 简介

Extension for Laravel Query Builder providing simple yet powerful fulltext search.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
