# rawebone/micro

> 标签: http, micro, minimal, testable, testing, web

## 简介

A minimalist, get-the-job-done web framework with an emphasis on testability

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
