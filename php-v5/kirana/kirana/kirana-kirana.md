# kirana/kirana

> 标签: blade, css, kirana, laravel, symfony, twig

## 简介

Kirana for server templates, under its other name: installs kirana-style/kirana.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
