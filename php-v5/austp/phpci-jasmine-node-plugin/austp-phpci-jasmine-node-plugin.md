# austp/phpci-jasmine-node-plugin

> 标签: BDD, jasmine, jasmine-node, phpci, plugin, test

## 简介

A plugin for PHPCI to run Jasmine tests via jasmine-node

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
