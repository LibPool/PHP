# hasegawa-tomoki/tsvio

> 标签: cakephp, cakephp3, export, import, tsv

## 简介

Shell command to import / export database table records from / to tsv filles. CakePHP3 plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
