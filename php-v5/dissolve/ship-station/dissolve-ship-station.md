# dissolve/ship-station

> 标签: api, ship, ship-station, shipping, shipstation, wrapper

## 简介

A php wrapper for ship station's rest api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
