# intelogie/zendesk_api_client_php

> 标签: PHP

## 简介

PHP Client for Zendesk REST API. See http://developer.zendesk.com/api-docs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
