# intelogie/highlightjs

> 标签: PHP

## 简介

Highlight.js highlights syntax in code examples on blogs, forums and in fact on any web pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
