# alphp/crypto-key-tools

> 标签: PHP

## 简介

A self-hosted collection of tools for generating, converting and inspecting cryptographic keys and related formats.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
