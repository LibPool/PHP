# thamtech/yii2-scheduler

> 标签: cron, scheduler, task, yii2

## 简介

A configuration-driven scheduled task runner for Yii2 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
