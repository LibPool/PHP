# castamir/sandbox

> 标签: PHP

## 简介

This custom extension of nette/sandbox. It has predefined admin and Front modules and files are slightly reorganized

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
