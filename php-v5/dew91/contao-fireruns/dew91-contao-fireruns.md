# dew91/contao-fireruns

> 标签: contao, einsatzliste, einsätze, fire, list, runs

## 简介

Contao bundle for showing a list of fire runs filtered by year.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
