# hectordev15/laravel-mongodb-passport

> 标签: designmynight, laravel, laravel-mongodb, laravel-mongodb-passport, laravel-passport, mongodb, passport

## 简介

A package to allow laravel/passport use with jenssegers/laravel-mongodb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
