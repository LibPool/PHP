# evgmel/simple-encryptor

> 标签: SimpleEncryptor, decryption, encryption

## 简介

SimpleEncryptor package is necessary to perform two-way encryption / decryption of eny string

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
