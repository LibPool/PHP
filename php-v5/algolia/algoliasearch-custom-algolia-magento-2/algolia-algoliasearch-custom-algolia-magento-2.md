# algolia/algoliasearch-custom-algolia-magento-2

> 标签: PHP

## 简介

Custom boilerplate module to extend Algolia Magento 2 extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
