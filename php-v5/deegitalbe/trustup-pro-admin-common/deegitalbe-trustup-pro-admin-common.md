# deegitalbe/trustup-pro-admin-common

> 标签: PHP

## 简介

This package contains pieces of code that are shared between 'admin.trustup.pro' and 'trustup.pro'.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
