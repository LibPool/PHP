# deegitalbe/chargebee-php

> 标签: chargebee, payments, recurring billing, subscription billing

## 简介

ChargeBee API client implementation for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
