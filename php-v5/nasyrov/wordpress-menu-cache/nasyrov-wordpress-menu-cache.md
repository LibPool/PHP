# nasyrov/wordpress-menu-cache

> 标签: cache, menu, mu-plugin, wordpress

## 简介

WordPress mu-plugin for a faster wp_nav_menu.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
