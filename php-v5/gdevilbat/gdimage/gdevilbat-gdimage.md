# gdevilbat/gdimage

> 标签: gd, image, merge, overlay, php-gd, resize, rotate, watermark

## 简介

Easy to use image manipulation tool based on PHP-GD extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
