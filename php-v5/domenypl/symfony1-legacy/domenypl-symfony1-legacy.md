# domenypl/symfony1-legacy

> 标签: symfony1

## 简介

symfony1-legacy is the unofficial Git mirror for symfony 1.0.22 with Domeny.pl (http://domeny.pl) modifications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
