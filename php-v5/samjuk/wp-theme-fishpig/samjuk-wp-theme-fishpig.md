# samjuk/wp-theme-fishpig

> 标签: fishpig, magento, magento-2, theme, wordpress

## 简介

Fishpig Theme for integrating Wordpress with Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
