# ramsey/identifier

> 标签: UID, guid, id, identifier, snowflake, ulid, uuid

## 简介

A PHP library for generating and working with identifiers, including UUIDs, ULIDs, and Snowflakes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
