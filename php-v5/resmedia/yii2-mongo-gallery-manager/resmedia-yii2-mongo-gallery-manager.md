# resmedia/yii2-mongo-gallery-manager

> 标签: extension, gallery, image, mongodb, yii2

## 简介

Extension for yii2 with mongodb, that allows to manage image galleries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
