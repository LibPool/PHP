# akkaweb/cakephp-facebook

> 标签: cakephp, cakephp3, facebook

## 简介

CakePHP 3 Facebook Plugin - Facebook SDKv5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
