# mhinspeya/inspeya-hyva-loginviaapp

> 标签: MHinspeya, firebase, hyva, login, magento, magento2, mobile-app

## 简介

Provides app-based customer login and registration integration for Magento 2 using Firebase Authentication. When a user logs in or registers from the mobile app, the module automatically authenticates or creates the customer in the web shop and assigns the customer to the App User group. Requires Google Firebase configuration and credentials.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
