# mhinspeya/module-orderitemsgrid

> 标签: MHinspeya, magento, magento 2

## 简介

OrderItemsGrid module to manage order item sync, pick statuses, and credit memos.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
