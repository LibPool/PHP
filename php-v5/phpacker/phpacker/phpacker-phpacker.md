# phpacker/phpacker

> 标签: PHP

## 简介

Package a PHP script as a standalone cross-platform binary. Convenience wrapper around static-php & phpmicro using general-purpose php binaries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
