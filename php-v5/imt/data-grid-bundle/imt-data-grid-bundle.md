# imt/data-grid-bundle

> 标签: datagrid, jqgrid, jquery

## 简介

This bundle provides a simple integration of the IMTDataGrid library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
