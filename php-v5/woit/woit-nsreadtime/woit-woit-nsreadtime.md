# woit/woit-nsreadtime

> 标签: extension, news, nsreadtime, typo3, woit

## 简介

This extension is useful for displaying read time in  news detail view.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
