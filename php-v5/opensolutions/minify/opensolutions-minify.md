# opensolutions/minify

> 标签: minifier, minify

## 简介

A JS and CSS minifier tool (with additional benefits for projects using template engines such as Smarty)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
