# anglemx/airports

> 标签: airports, angle, iata

## 简介

Auto-generated PHP abstract class that contains the global IATA Aiport database in pure PHP code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
