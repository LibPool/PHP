# db1-fpp/laravel-elasticache

> 标签: Elasticache, amazon, aws, cache, laravel

## 简介

Add new cache and session driver to use AWS ElastiCache with auto discovery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
