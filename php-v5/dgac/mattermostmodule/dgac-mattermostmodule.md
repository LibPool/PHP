# dgac/mattermostmodule

> 标签: Mattermost, bootstrap, chat, laminas

## 简介

Module to use Mattermost in a Zend Framework and Bootstrap application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
