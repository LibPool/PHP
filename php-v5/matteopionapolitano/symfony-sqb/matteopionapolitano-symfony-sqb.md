# matteopionapolitano/symfony-sqb

> 标签: PHP

## 简介

A simple Symfony Command that helps in converting Native SQL Query in QueryBuilder PHP Code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
