# zebratrois/lessphp

> 标签: PHP

## 简介

lessphp is a compiler for LESS written in PHP - Forked to add PHP8.1 compat

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
