# peterkahl/ip2asn

> 标签: IP, asn, asn-to-prefix, bgp, ip-to-asn

## 简介

Maps IP address to ASN. ASN to prefix. Both IPv4 and IPv6.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
