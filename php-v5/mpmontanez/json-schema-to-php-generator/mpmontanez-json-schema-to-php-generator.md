# mpmontanez/json-schema-to-php-generator

> 标签: PHP

## 简介

Code generation tool for converting JSON schema documents to simple PHP classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
