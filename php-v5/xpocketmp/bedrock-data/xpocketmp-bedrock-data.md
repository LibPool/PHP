# xpocketmp/bedrock-data

> 标签: PHP

## 简介

Blobs of data generated from Minecraft: Bedrock Edition, used by XPocketMP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
