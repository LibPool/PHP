# wainstan/arraymysql

> 标签: Simple, array, database, mysql, pdo

## 简介

Simple array based without text queryes MySQL class (Composer support)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
