# swayok/peskycmf

> 标签: admin, cmf, database, laravel, php, web

## 简介

PeskyCMF - CMF based on Laravel Framework 5, PeskyORM and AdminLTE UI template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
