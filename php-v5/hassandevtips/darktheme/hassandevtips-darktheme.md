# hassandevtips/darktheme

> 标签: PHP

## 简介

DarkTheme - A simple Laravel package to enable dark mode using Bootstrap 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
