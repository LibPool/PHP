# cmsexperts/simplessl

> 标签: TYPO3 CMS, https, redirects, ssl

## 简介

An easy tool to enforce SSL for any domain with TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
