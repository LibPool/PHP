# concept/cartesian-tree

> 标签: PHP

## 简介

A Laravel package that implements the cartesian algorithm to generate permutations out of a sequence of arrays.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
