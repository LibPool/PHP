# belamov/laravel-rabbitmq-listener

> 标签: laravel, rabbitmq

## 简介

This package allows you to listen RabbitMQ events via artisan command

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
