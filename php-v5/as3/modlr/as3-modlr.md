# as3/modlr

> 标签: PHP

## 简介

Simplified PHP library for fast and efficient RESTful API for MongoDB. Designed for use with front end web frameworks such as EmberJS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
