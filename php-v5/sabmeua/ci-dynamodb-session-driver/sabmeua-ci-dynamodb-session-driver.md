# sabmeua/ci-dynamodb-session-driver

> 标签: aws, codeigniter, dynamodb, session

## 简介

A DynamoDB session driver for CodeIgniter 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
