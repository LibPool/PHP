# wineworlds/image-on-demand-service

> 标签: Image Service, TYPO3 CMS, image processing

## 简介

A TYPO3 extension for providing on-demand image processing services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
