# sheershoff/yii2-module-urlrules

> 标签: UrlRules, extension, module, routing, sheershoff, url, url rules, yii, yii2

## 简介

Extension to support module url rules for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
