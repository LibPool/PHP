# elfstack/unit-test-lite

> 标签: test, tests, unit, unit test, unit-test

## 简介

A light unit test class providing basic test function and beautiful report.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
