# cedcommerce/google-auth

> 标签: Authentication, google, oauth2

## 简介

Google Auth Library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://github.com/google/google-auth-library-php
- 源码仓库：https://github.com/cedcommerce/google-auth.git
- Packagist 页面：https://packagist.org/packages/cedcommerce%2Fgoogle-auth

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require cedcommerce/google-auth`
- Packagist 仓库：https://repo.packagist.org/p2/cedcommerce/google-auth.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4
