# jordanbrauer/deployer-mysql

> 标签: PHP

## 简介

An unofficial Deployer recipe containing a set of useful tasks for interacting with MySQL locally & remotely.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
