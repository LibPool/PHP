# fukuball/ckip-client-php

> 标签: PHP

## 简介

中研院斷詞系統的 Client 端程式，讓有中文斷詞需求的研究者或程式人員可以專注於開發自己的核心演算法。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
