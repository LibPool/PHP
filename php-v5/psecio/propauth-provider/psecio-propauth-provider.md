# psecio/propauth-provider

> 标签: Policy, authorization, blade, laravel, property

## 简介

A Laravel provider for adding PropAuth checking to Blade templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
