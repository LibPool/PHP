# hubtel/hubtel-sms

> 标签: api, hubtel, sms

## 简介

A PHP open source library for integrating with the Hubtel SMS API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/hubtel/hubtel-sms-php
- 源码仓库：https://github.com/hubtel/hubtel-sms-php.git
- Packagist 页面：https://packagist.org/packages/hubtel%2Fhubtel-sms

## 获取地址

- Composer 安装：`composer require hubtel/hubtel-sms`
- Packagist 仓库：https://repo.packagist.org/p2/hubtel/hubtel-sms.json
- PHP 要求：^5.3
