# vinai/magento-message-queue-backport

> 标签: PHP

## 简介

Metapackage to install the Magento Open Source 2.3 Message Queue related packages backported to Magento Open Source 2.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
