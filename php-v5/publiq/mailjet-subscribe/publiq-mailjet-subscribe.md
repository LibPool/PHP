# publiq/mailjet-subscribe

> 标签: Craft, Mailjet, cms, craft-plugin, craftcms

## 简介

Simple Craft plugin for subscribing to a Mailjet list.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
