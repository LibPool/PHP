# simplesamlphp/simplesamlphp-module-infocard

> 标签: infocard, simplesamlphp

## 简介

A SimpleSAMLphp module that works with Information Cards techcnologies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
