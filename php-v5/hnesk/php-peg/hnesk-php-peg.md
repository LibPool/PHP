# hnesk/php-peg

> 标签: DSL, compiler, parser, peg

## 简介

Minimally invasive fork of hafriedlander/php-peg with support for composer autoloading

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
