# starteed/crowdfunding

> 标签: api, client, crowdfunding, starteed, wrapper

## 简介

A PHP wrapper for Starteed Crowdfunding's API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
