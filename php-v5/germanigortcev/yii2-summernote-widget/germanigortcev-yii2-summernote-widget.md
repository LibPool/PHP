# germanigortcev/yii2-summernote-widget

> 标签: summernote, widget, wysiwyg, yii2

## 简介

Yii2 Summernote widget. Super simple WYSIWYG editor on Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
