# razielsd/webdriverlib

> 标签: appium, selendroid, selenium

## 简介

API for JSON Wire Protocol, support Selenium, Selendroid, Appium

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
