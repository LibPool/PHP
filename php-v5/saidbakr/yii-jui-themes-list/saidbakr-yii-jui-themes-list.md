# saidbakr/yii-jui-themes-list

> 标签: change theme, jui, themes, widget, yii2

## 简介

Yii2 widget to list and apply yii-jui themes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
