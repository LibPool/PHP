# dotzero/ypaginator

> 标签: pager, pagination, paginator

## 简介

A lightweight PHP paginator without a database dependency, for generating pagination controls in the style of Yandex

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
