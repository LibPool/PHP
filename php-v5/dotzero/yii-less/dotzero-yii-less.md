# dotzero/yii-less

> 标签: Behavior, extension, yii

## 简介

The Yii LessPhp extension that allows developers to compile LESS files into CSS on the fly, using the LessPhp compiler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
