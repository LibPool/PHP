# dotzero/yii-amocrm

> 标签: amoCRM, api, crm, extension, yii

## 简介

Расширения для Yii Framework реализующее клиент для работы с API amoCRM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
