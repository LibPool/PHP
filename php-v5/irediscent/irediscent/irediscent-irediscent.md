# irediscent/irediscent

> 标签: Irediscent, iredis, lightweight, redis, redisent

## 简介

Lightweight php handler for iredis with redisent fallback

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
