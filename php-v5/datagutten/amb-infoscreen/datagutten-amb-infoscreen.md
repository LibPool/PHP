# datagutten/amb-infoscreen

> 标签: PHP

## 简介

Show lap times using data from a AMB or MyLaps decoder. This tool is designed to work offline without internet connection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
