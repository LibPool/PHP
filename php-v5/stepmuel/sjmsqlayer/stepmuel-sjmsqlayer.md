# stepmuel/sjmsqlayer

> 标签: sql, sqlayer, sqlite

## 简介

SJMSQLayer simplifies the creation of SQL queries in PHP using a printf-like syntax.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
