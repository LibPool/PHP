# kduma/dotenv-filler

> 标签: artisan, command, dotenv, env, laravel

## 简介

Laravel 5.1 command to create/fill missing fields in .env file based on rules in .env.example file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
