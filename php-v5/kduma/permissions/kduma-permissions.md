# kduma/permissions

> 标签: eloquent, laravel, permission, roles

## 简介

Simple (really?) package to provide Roles and Permissions to Laravel 5.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
