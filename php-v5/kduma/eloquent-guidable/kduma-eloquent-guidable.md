# kduma/eloquent-guidable

> 标签: eloquent, guid, laravel, uuid

## 简介

Eases using and generating guid's in Laravel Eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
