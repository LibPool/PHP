# sti-vcx/oe-module-installer-plugin

> 标签: openemr, openemr-module

## 简介

OpenEMR Module Installer plugin for installing custom modules into the OpenEMR codebase.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
