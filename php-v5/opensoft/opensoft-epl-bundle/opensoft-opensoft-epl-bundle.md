# opensoft/opensoft-epl-bundle

> 标签: epl, epl2, symfony

## 简介

OpensoftEplBundle is wrapper for opensoft/epl library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
