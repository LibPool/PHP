# opensoft/epl

> 标签: epl, epl2, php

## 简介

The library is a php wrapper for the EPL2 Programming Language. At present do not support all commands EPL2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
