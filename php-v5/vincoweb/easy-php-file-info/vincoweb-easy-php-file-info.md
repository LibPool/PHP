# vincoweb/easy-php-file-info

> 标签: file data, file info, image info, php

## 简介

Get file information from local and also remote file(mime type, extension, file name ...).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
