# tecksolke-tpay/app-api

> 标签: PHP

## 简介

This package contains all t-pay/api, that is api for making requests to t-pay payment gateway for any app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
