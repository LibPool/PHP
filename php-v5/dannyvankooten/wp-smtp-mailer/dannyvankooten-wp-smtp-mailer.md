# dannyvankooten/wp-smtp-mailer

> 标签: smtp, wordpress, wp_mail

## 简介

A WordPress plugin that configures wp_mail to use SMTP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
