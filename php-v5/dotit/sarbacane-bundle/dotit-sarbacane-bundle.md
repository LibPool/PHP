# dotit/sarbacane-bundle

> 标签: mailing, sarbacane

## 简介

SarbacaneBundle is a Symfony 3.4 bundle for sarbacane

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
