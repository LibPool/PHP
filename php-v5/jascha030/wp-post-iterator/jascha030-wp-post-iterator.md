# jascha030/wp-post-iterator

> 标签: PHP

## 简介

Simple adapter for the WP_Query class, built mainly for, but not limited to usage with twig/twig.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
