# jascha030/wp-ajax

> 标签: PHP

## 简介

WP Ajax with OOP, also includes provider class for usage with jascha030/wp-subscriptions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
