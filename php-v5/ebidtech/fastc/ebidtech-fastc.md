# ebidtech/fastc

> 标签: Guzzle, client, http, library, php, service

## 简介

A light layer on top of Guzzle service descriptions that enables faster HTTP client development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
