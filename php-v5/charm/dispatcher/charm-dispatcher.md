# charm/dispatcher

> 标签: PHP

## 简介

Creates PSR-7 Server Server Requests for PSR-15 Server Request Handlers and Middlewares from a web server, ReactPHP, Swoole or the command line.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
