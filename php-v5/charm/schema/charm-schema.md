# charm/schema

> 标签: PHP

## 简介

A simple to use schema validator allowing you to validate strings, numbers, arrays and objects. Modelled after JSON Schema written as PHP arrays.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
