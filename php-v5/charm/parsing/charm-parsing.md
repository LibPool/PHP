# charm/parsing

> 标签: PHP

## 简介

A PEG grammar parser, for parsing most context free grammar such as programming languages, database queries and mathematical expressions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
