# wiejeben/craft-laravel-mix

> 标签: PHP

## 简介

Integrates Laravel Mix Cache Busting plugin with the Craft Twig template engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
