# mikenz/silverstripe-simplesubsites

> 标签: multisite, silverstripe, subsites

## 简介

Run multiple sites from a single SilverStripe install.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
