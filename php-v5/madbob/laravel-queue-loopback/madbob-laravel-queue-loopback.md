# madbob/laravel-queue-loopback

> 标签: laravel, queue

## 简介

Dummy Laravel queue driver to run jobs as detached HTTP requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
