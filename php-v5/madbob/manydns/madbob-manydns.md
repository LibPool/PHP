# madbob/manydns

> 标签: changedns, dns, duckdns, dyndns, dynu, noip

## 简介

Wrapper for many dynamic DNS providers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
