# madbob/larastrap

> 标签: blade, bootstrap, bootstrap5, laravel

## 简介

Opinionated Bootstrap5 components for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
