# ssigwart/letsencryptdns-cloudflare

> 标签: ACME, acmev2, cloudflare, letsencrypt, ssl, wildcard

## 简介

PHP Let's Encrypt Wildcard DNS Client (Cloudflare DNS support)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
