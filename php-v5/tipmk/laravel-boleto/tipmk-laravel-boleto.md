# tipmk/laravel-boleto

> 标签: laravel-boleto, tipmk

## 简介

Biblioteca com boletos para o laravel, compatível com Laravel 12

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
