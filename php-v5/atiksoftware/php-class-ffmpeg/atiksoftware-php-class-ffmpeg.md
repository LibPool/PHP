# atiksoftware/php-class-ffmpeg

> 标签: PHP

## 简介

With this class you can use FFmpeg with PHP without installing php-ffmpeg extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
