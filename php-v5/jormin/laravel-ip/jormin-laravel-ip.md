# jormin/laravel-ip

> 标签: IP, Jormin, laravel

## 简介

解析IP地址，使用 [ipip.net](http://www.ipip.net/) 的服务。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/jormin/laravel-ip.git

## 获取地址

- Composer 安装：`composer require jormin/laravel-ip`
