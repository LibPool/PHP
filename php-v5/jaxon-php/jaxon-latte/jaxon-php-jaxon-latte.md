# jaxon-php/jaxon-latte

> 标签: Jaxon, ajax, latte, php, template, view, xajax

## 简介

Jaxon view renderer for the Latte template engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
