# jaxon-php/jaxon-zend

> 标签: Jaxon, ajax, framework, php, xajax, zend

## 简介

Jaxon library integration for the Zend Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
