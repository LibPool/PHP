# axolotl-pm/bedrock-block-upgrade-schema

> 标签: PHP

## 简介

Schemas describing how to upgrade saved block data in older Minecraft: Bedrock Edition world saves

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
