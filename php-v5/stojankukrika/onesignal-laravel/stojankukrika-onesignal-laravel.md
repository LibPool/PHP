# stojankukrika/onesignal-laravel

> 标签: WebPush, laravel, laravel 5, onesignal, push

## 简介

OneSignal Push Wrapper Laravel with addition icon color

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
