# backpack/backupmanager

> 标签: backpack, backup, backupmanager, laravel, tabacitu, updivision

## 简介

Admin interface for managing backups in Backpack, on Laravel 5.2+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
