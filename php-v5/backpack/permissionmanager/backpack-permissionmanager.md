# backpack/permissionmanager

> 标签: backpack, backpack permission, backpack roles, backpack user management, laravel backpack, manage permission, manage roles, manage users, tabacitu, updivision, users roles admin

## 简介

Users and permissions management interface for Laravel 5 using Backpack CRUD.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
