# backpack/newscrud

> 标签: NewsCRUD, backpack

## 简介

An admin panel for news with categories and tags, using Backpack\CRUD on Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
