# browserlife/zf2-recaptcha

> 标签: captcha, recaptcha, zf2

## 简介

ReCaptcha v2.0 module for Zend Framework 2 (ZF2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
