# linshunwei/qrcode-reader

> 标签: laravel, qr code decoder, qr code reader

## 简介

Simple PHP QR Code Reader / Decoder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
