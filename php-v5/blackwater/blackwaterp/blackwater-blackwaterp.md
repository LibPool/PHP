# blackwater/blackwaterp

> 标签: Blackwater, Ratchet, WebSockets, server, sockets

## 简介

PHP WebSocket library based on WAMP and Ratchet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
