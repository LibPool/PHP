# brainboxlabs/brain-socket

> 标签: Ratchet, WebSockets, artisan, events, laravel

## 简介

Websockets for event-driven Laravel apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
