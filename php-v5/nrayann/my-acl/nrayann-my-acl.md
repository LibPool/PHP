# nrayann/my-acl

> 标签: acl, cakephp, cakephp3, plugin

## 简介

CakePHP plugin for manage ACL with a friendly interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
