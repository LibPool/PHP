# ptournet/laravel-preset

> 标签: laravel, preset

## 简介

Patrick Tournet's Laravel Frontend Preset (based on Adam Wathan's one)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
