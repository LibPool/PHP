# friendsofoxid/oxideshop-metapackage-ce-smarty

> 标签: OXID eShop, metapackage, smarty, wave

## 简介

This is shop compilation metapackage for the OXID eShop with Smarty template renderer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
