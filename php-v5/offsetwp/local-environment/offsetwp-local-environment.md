# offsetwp/local-environment

> 标签: caddy, development, docker, local, offsetwp, wordpress

## 简介

The local server of an OffsetWP project, on Docker: Caddy, PHP 8.5 by default, MariaDB or MySQL, and Mailpit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
