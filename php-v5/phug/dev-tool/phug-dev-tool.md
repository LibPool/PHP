# phug/dev-tool

> 标签: dev tools, dialect, html, jade, php, phtml, phug, presentation, pug, render, template, views

## 简介

Phug unit tests, coverage and code style tools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
