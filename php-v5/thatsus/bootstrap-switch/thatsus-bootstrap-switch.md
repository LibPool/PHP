# thatsus/bootstrap-switch

> 标签: JS, bootstrap, javascript, switch

## 简介

Turn checkboxes and radio buttons in toggle switches.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
