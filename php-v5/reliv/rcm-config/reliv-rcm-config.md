# reliv/rcm-config

> 标签: config, module, rcm, zf2

## 简介

Extend the functionality of ZF2 config as well as allow config sources to be changed

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
