# igormatkovic/laravel-phumbor

> 标签: laravel, phumbor, thumbor

## 简介

Laravel package adding support for the Phumbor PHP library for Thumbor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
