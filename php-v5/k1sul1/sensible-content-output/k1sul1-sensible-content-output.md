# k1sul1/sensible-content-output

> 标签: PHP

## 简介

Make the_content() output a little more sane with these features. All features are optional and disabling them is easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
