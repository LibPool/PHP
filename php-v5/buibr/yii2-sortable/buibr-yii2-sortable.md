# buibr/yii2-sortable

> 标签: bootstrap, extension, jquery, range, sortable, widget, yii2

## 简介

Create sortable lists and grids using HTML5 drag and drop API for Yii 2.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
