# dashzeveg/flarum-meta-tags

> 标签: flarum

## 简介

Automatically adds Open Graph, Twitter Card, and meta description tags to your Flarum forum for better SEO and social media sharing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
