# symsensor/actuator-maintenance-bundle

> 标签: actuator

## 简介

Extension for the ActuatorBundle which provides health checking capabilities for maintenance modes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
