# mordilion/zf2-module-layouts

> 标签: module layouts, zf2

## 简介

ZF2ModuleLayouts is a simple module to build module specified layouts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
