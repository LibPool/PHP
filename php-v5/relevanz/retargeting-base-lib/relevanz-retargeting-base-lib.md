# relevanz/retargeting-base-lib

> 标签: Advertising, releva.nz, retargeting

## 简介

Base lib for releva.nz retargeting plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
