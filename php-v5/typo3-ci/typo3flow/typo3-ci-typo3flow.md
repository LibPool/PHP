# typo3-ci/typo3flow

> 标签: codesniffer, coding guidelines, flow, phpcs, quality assurance, standards, typo3

## 简介

This package contains a selection of sniffs which implements the Coding Guidelines for TYPO3 FLOW which was former known as FLOW3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
