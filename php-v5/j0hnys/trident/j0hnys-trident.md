# j0hnys/trident

> 标签: PHP

## 简介

A laravel package for developing applications following Domain Driven Design (DDD) and Test Driven Design (TDD) principles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
