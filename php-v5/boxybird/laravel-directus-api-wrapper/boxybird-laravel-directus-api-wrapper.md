# boxybird/laravel-directus-api-wrapper

> 标签: api, directus, facade, laravel, wrapper

## 简介

A collection of Laravel facades to interact with Directus CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
