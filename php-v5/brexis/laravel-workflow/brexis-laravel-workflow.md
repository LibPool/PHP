# brexis/laravel-workflow

> 标签: laravel, laravel5, laravel6, symfony, workflow

## 简介

Integerate Symfony Workflow component into Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
