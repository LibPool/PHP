# elhardoum/meta-php

> 标签: PHP

## 简介

Makes it easier saving meta data into the database, inspired by WordPress meta (users, options, posts, etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
