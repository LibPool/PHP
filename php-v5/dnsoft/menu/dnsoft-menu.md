# dnsoft/menu

> 标签: PHP

## 简介

This is module menu. We can build a menu by this package. If you need to install, please contact me at dong.joseph2810@gmail.com to get a core module to run this package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
