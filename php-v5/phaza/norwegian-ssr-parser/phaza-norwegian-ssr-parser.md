# phaza/norwegian-ssr-parser

> 标签: PHP

## 简介

Parses the Norsk stedsnavnregister (Norwegian location name register) geojson dump as a stream

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
