# batchnz/craft-ckeditor

> 标签: CKEditor, cms, craftcms, html, yii2

## 简介

Edit rich text content in Craft CMS using CKEditor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
