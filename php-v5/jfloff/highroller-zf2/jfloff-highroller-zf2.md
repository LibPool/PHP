# jfloff/highroller-zf2

> 标签: highcharts, highroller, zend framework 2, zf2

## 简介

Highcharts module for Zend Framework 2 based on HighRoller.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
