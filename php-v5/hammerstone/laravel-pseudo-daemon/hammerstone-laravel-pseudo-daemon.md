# hammerstone/laravel-pseudo-daemon

> 标签: PHP

## 简介

A Laravel package to mimic daemons via scheduled commands without having to change server configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
