# adamculp/api-consumer

> 标签: Api Wrapper, api, mashery api, wrapper

## 简介

Basic API wrapper for dealing with Mashery and other GET based APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
