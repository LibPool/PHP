# pronamic/changelog-md-to-wordpress-plugin-readme-txt

> 标签: PHP

## 简介

Automates syncing of changelog entries from CHANGELOG.md to WordPress plugin readme.txt.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
