# pronamic/wp-orbis-tasks

> 标签: PHP

## 简介

The Orbis Tasks plugin extends your Orbis environment with the option to add tasks and connect them to Orbis projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
