# mrkrstphr/peridot-automock-plugin

> 标签: PHP

## 简介

A plugin to reduce mocking boilerplate for a given class using Prophecy

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
