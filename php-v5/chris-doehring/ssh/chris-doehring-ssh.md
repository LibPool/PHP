# chris-doehring/ssh

> 标签: 5.6, php, ssh

## 简介

A lightweight package to execute commands over an SSH connection, based on `spatie/ssh`, with php 5.6 compatibility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
