# delight-im/otp

> 标签: 2fa, google-authenticator, hotp, otp, rfc-4226, rfc-6238, rfc4226, rfc6238, tfa, totp, two-factor, two-factor-authentication

## 简介

One-time password (OTP) implementation for two-factor authentication with TOTP in accordance with RFC 6238 and RFC 4226

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
