# mcustiel/php-simple-cache

> 标签: Simple, abstraction, cache, drivers, manager, minimalist

## 简介

A simple library to abstract different cache servers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
