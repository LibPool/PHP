# buepro/typo3-easyconf

> 标签: TYPO3 CMS, TypoScript, configuration, constants, setup, site

## 简介

Provides a module to easily configure main aspects from a website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
