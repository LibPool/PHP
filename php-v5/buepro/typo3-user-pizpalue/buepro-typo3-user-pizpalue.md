# buepro/typo3-user-pizpalue

> 标签: TYPO3 CMS, bootstrap, frontend, pizpalue, responsive, theme, web

## 简介

TYPO3 site package being used with template pizpalue.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
