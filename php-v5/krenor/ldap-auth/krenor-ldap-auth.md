# krenor/ldap-auth

> 标签: LDAP Authentication, Laravel 5.2, Laravel Auth, active directory, krenor, laravel, laravel authentication, ldap

## 简介

Basic readonly authentication via LDAP for Laravel 5.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
