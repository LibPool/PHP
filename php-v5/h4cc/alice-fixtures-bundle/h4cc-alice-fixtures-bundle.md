# h4cc/alice-fixtures-bundle

> 标签: Symfony2, alice, doctrine, fixtures, loader, mongodb, orm

## 简介

Symfony2 Bundle for loading fixture data with the Alice library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
