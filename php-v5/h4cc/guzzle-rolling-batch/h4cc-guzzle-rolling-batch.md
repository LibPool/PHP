# h4cc/guzzle-rolling-batch

> 标签: Guzzle, client, curl, http, parallel

## 简介

A parallel executor for Guzzle Requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
