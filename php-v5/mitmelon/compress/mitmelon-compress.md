# mitmelon/compress

> 标签: advance file compresser, archive, compress, compress files, encrypt file, encryption, file, file compresser, remove meta, save memory, zip

## 简介

Advanced file compresser which reduces and encrypt large files to smaller chunks by saving them as binary for later use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
