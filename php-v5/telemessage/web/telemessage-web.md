# telemessage/web

> 标签: IP, TeleMessage, fax, mms, send, sms, text message, voice

## 简介

TeleMessage PHP library for sending messages via TeleMessage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
