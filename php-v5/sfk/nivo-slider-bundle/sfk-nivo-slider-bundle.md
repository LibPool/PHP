# sfk/nivo-slider-bundle

> 标签: image slider, jquery, nivo, slider

## 简介

jQuery Nivo Slider plugin integration for symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
