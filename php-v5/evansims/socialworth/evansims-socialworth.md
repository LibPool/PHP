# evansims/socialworth

> 标签: analytics, facebook, google plus, hackernews, linkedin, pinterest, popularity, reddit, social network, stumbleupon, twitter

## 简介

A simple PHP library for determining the popularity of a URL across social networks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
