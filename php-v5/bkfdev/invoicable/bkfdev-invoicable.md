# bkfdev/invoicable

> 标签: bkfdev, eloquent, invoicable, invoice, laravel, laravel-invoicable, payments

## 简介

Easy invoice generation using Laravel Eloquent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
