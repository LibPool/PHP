# nizerin/baidu-mini-program-sdk

> 标签: PHP

## 简介

百度小程序第三方 PHP SDK，助力智能小程序开发。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
