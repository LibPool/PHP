# jbdelhommeau/simplesamlphp-module-symfony

> 标签: provider, symfony

## 简介

A SimpleSAMLphp module adding support for the Symfony2 default Password encoder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
