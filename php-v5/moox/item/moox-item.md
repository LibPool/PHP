# moox/item

> 标签: MOOX, Moox package, filament, laravel, laravel package

## 简介

Item is a simple Moox Entity, that can be used to create and manage simple entries, like logs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
