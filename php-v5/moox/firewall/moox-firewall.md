# moox/firewall

> 标签: MOOX, Moox package, filament, firewall, laravel, laravel package

## 简介

Moox Firewall is a simple application level firewall for Laravel and Filament.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
