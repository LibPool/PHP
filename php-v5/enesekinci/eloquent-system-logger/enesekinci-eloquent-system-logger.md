# enesekinci/eloquent-system-logger

> 标签: PHP

## 简介

It keeps user-based logs of creation, update and deletion of Laravel ORM Models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
