# alex-net/tiny-file-man

> 标签: Responsive file namager, authmanager, tinymce, widgets, yii 2, yii2

## 简介

Компонент реализующий подключение к полю textarea визуального редактора TinyMCE5 и файлового менеджера Responsive FileManager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
