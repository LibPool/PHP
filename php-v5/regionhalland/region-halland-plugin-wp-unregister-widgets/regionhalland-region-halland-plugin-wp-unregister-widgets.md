# regionhalland/region-halland-plugin-wp-unregister-widgets

> 标签: PHP

## 简介

Tar bort de widgets vi inte använder på Region Halland

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
