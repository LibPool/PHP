# christopherdarling/silverstripe-dataobjecturlsegment

> 标签: silverstripe, urlsegment

## 简介

Extension + field to add URLSegment to DataObjects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
