# perseids/oauth2-orm-bridge

> 标签: oauth2

## 简介

An Implementation of ORM for oAuthBucket oAuth2 implementation using clients issued by perseids/clients-manager and user issued by jasongrimes/silex-simpleuser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
