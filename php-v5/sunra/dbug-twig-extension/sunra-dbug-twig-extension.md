# sunra/dbug-twig-extension

> 标签: dbug, dump, twig

## 简介

Enable for Twig dBug class as filter (https://github.com/sunra/dBug)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
