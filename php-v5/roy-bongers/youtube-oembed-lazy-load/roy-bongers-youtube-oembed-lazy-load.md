# roy-bongers/youtube-oembed-lazy-load

> 标签: lazyload, plugin, wordpress, youtube

## 简介

WordPress plugin to Lazy Load YouTube video's in order to save bandwidth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
