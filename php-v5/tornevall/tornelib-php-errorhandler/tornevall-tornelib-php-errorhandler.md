# tornevall/tornelib-php-errorhandler

> 标签: PHP

## 简介

Global exception and errorhandling for TorneLIB, with all errorcodes stored in the same place.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
