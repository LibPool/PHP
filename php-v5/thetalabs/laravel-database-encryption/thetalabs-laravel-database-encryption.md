# thetalabs/laravel-database-encryption

> 标签: PHP

## 简介

A no fuss Laravel model trait to add encrypted model attributes with the option of blind indexes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
