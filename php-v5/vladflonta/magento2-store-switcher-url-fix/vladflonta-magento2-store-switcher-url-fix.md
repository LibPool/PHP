# vladflonta/magento2-store-switcher-url-fix

> 标签: PHP

## 简介

Fixes the URL used for switching to a specific store view page for which a URL rewrite exists.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
