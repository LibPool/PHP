# wallacemaxters/bless-ui

> 标签: blade, tailwindcss, ui

## 简介

The Bless UI is a package to make easy your ui elements with tailwindcss or another framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
