# cursedcoder/geonames-bundle-fork

> 标签: bundle, geonames, symfony

## 简介

Symfony2 bundle to import and use Geonames toponyms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
