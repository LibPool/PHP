# morket/hmvc-bundle

> 标签: hmvc, pac, rad, rest

## 简介

Symfony2 Bundle providing a fast Hierarchical Model View Controller (HMVC) solution utilizing Symfony's dispatch flow

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
