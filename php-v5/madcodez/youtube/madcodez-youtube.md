# madcodez/youtube

> 标签: api, php youtube downloader, video, youtube, youtube downloader

## 简介

PHP wrapper for the Youtube Data API v3 & YouTube Downloader

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
