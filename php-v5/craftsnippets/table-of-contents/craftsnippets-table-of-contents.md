# craftsnippets/table-of-contents

> 标签: craft cms, craftcms, table of contents

## 简介

This plugin generates a table of contents from HTML headers in text.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
