# askew0/bitrix-typograf.ru

> 标签: bitrix, typograf

## 简介

Модуль типографирования для нового визуального редактора битрикса, с использованием API сайта typograf.ru

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
