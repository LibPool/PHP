# vojtasvoboda/oc-locationtowns-plugin

> 标签: city, location, october, plugin, town

## 简介

Adds towns to states managed by RainLab.Location plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
