# carlbennett/php-mvc

> 标签: api, backend, cms, content, frontend, management, mvc, php, rest, restful, system

## 简介

A PHP micro-framework for use as a frontend and/or backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
