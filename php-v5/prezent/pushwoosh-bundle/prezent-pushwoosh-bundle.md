# prezent/pushwoosh-bundle

> 标签: bundle, mobile, push, pushwoosh

## 简介

Integrates the gomoob/php-pushwoosh library into a Symfony2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
