# vojtech-dobes/composer-extension

> 标签: composer, config, di, nette

## 简介

Autoregisters extensions downloaded via Composer (for Nette Framework)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
