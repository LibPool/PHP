# torann/embedder

> 标签: audio, dailymotion, embed, embedder, oembed, opengraph, videos, vimeo, vine, youtube

## 简介

Fetch embeddable links from text and fetch OpenGraph data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
