# torann/podcastfeed

> 标签: feed, laravel, podcast, podcast generator, rss, xml

## 简介

Generate RSS feeds for podcasts in Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
