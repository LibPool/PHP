# torann/baun-asset-manifest

> 标签: baun, baun assets, baun gulp, baun manifest, baun plugin

## 简介

A Baun plugin that adds gulp asset manifest helper

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
