# webeleven/easyflickr

> 标签: EasyFlickr, flickr, laravel plugin, phpflickr

## 简介

EasyFlickr manager package for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
