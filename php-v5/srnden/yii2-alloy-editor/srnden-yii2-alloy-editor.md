# srnden/yii2-alloy-editor

> 标签: extension, yii2

## 简介

Yii2 Alloy Editor widget. https://alloyeditor.com/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
