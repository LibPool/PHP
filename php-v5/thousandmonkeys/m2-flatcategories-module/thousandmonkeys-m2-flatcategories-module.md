# thousandmonkeys/m2-flatcategories-module

> 标签: PHP

## 简介

A flat category rest endpoint for magento2 to work round the stupidity that is the default tree interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
