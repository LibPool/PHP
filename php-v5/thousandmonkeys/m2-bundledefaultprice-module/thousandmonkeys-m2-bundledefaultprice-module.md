# thousandmonkeys/m2-bundledefaultprice-module

> 标签: PHP

## 简介

This module allows you to show the default price of a bundle in the catalog and product pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
