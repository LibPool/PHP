# td-wp-plugin/td-zoho-crm-sdk-wrapper

> 标签: PHP

## 简介

Helps with initializing the Zoho CRM PHP SDK in WordPress via WP CLI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
