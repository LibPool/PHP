# perchten/neat_html

> 标签: arrays, comments, console, debug, html, json, objects, php, pretty-print, print, print_r, var_dump, var_export

## 简介

Pretty-print PHP objects and arrays in html, json etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
