# cylab/php-libvirt

> 标签: PHP

## 简介

On object oriented wrapper for the libvirt-php extention. Allows to create, start, stop, modify virtual machines in a programmatic way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
