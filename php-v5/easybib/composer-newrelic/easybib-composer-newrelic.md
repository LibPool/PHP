# easybib/composer-newrelic

> 标签: composer, composer-plugin, monitoring, newrelic, performance, plugin

## 简介

A composer plugin that allows to tag composer runs in New Relic

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
