# splashmedia/linkedin-php

> 标签: api client, linkedin

## 简介

LinkedIn OAuth client based on abrah.am's Twitter OAuth library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
