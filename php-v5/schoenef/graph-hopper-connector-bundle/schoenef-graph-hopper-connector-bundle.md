# schoenef/graph-hopper-connector-bundle

> 标签: PHP

## 简介

Allows to use the GraphHopper geocoding api at https://graphhopper.com/api/1/docs/geocoding/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
