# dimadin/commonwp

> 标签: cdn, jsDelivr

## 简介

Offload open source static assets to the free, public CDN

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://milandinic.com/wordpress/plugins/commonwp/
- 源码仓库：https://github.com/dimadin/commonWP.git
- Packagist 页面：https://packagist.org/packages/dimadin%2Fcommonwp

## 获取地址

- Composer 安装：`composer require dimadin/commonwp`
- Packagist 仓库：https://repo.packagist.org/p2/dimadin/commonwp.json
- 许可证：GPL-2.0-or-later
