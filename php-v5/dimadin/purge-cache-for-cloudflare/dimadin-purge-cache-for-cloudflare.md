# dimadin/purge-cache-for-cloudflare

> 标签: cache, cloudflare, wordpress

## 简介

Simple full HTML page cache purger for CloudFlare

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
