# superbig/craft-pjax

> 标签: Craft, cms, craft-plugin, craftcms, pjax

## 简介

Automagically return the headers and container that PJAX expects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
