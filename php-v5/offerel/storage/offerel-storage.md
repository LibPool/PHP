# offerel/storage

> 标签: WebDAV, elfinder, filemanager, files

## 简介

Directly integrate elFinder as App in to Roundcubewith SSO.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
