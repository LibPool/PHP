# gryfoss/twig-smart-mailer

> 标签: PHP

## 简介

Smart mailer based on Symfony Mailer which supports dynamic source mailboxes and easy integration of files within emails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
