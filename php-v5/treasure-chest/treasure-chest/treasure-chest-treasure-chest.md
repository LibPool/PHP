# treasure-chest/treasure-chest

> 标签: apc, cache, caching, memcached

## 简介

A simple key/value store with namespace support and backends for memcached, apc, and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
