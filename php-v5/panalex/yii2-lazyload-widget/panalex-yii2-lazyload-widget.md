# panalex/yii2-lazyload-widget

> 标签: extension, image, lazyload, widget, yii2

## 简介

wrapper of https://github.com/verlok/lazyload library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
