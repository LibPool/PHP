# magojr/laravel-smpp

> 标签: laravel, onlinecity, smpp, sms

## 简介

SMS sending via SMPP protocol for Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
