# spoetnik/recurring-events

> 标签: event, events, processwire, recurrence, recurring

## 简介

Create Recurring events. Recurrences are calculated, and only created when needed. (https://medium.com/@ScullWM/design-and-manage-recurring-events-fb43676e711a)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
