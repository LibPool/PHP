# anguinus/gpsoauthphp

> 标签: PHP

## 简介

PHP port of gpsoauth python library https://github.com/simon-weber/gpsoauth/tree/master/gpsoauth

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
