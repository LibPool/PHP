# terranc/laravel-s

> 标签: LaravelS, async, coroutine, http, inotify, laravel, laravel-s, lumen, performance, process, server, swoole, task, tcp, timer, udp, websocket

## 简介

🚀 LaravelS is an out-of-the-box adapter between Swoole and Laravel/Lumen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
