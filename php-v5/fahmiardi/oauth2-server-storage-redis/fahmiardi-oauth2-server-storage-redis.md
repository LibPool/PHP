# fahmiardi/oauth2-server-storage-redis

> 标签: adapter, league, oauth2, redis, server, storage

## 简介

Redis storage adapter for the League's PHP OAuth 2.0 server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
