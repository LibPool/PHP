# wyrihaximus/ratchet

> 标签: Ratchet, WebSockets, cakephp

## 简介

Ratchet websockets integration plugin for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
