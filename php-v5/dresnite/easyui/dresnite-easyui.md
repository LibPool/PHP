# dresnite/easyui

> 标签: PHP

## 简介

EasyUI is an intuitive and easy-to-use form library for PocketMine-MP. Designed to let you focus on your project and not on how the library works.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
