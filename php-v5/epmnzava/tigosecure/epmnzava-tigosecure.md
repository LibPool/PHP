> 标签: MobileMoney, epmnzava, tanzania, tigo, tigopesa tanzania, tigosecure

## 简介

This is a laravel package for integration with TigoPesa online API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
