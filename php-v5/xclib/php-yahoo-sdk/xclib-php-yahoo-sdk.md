# xclib/php-yahoo-sdk

> 标签: php, sdk, social, yahoo

## 简介

Yahoo! Social SDK - PHP5 library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://developer.yahoo.com/social/sdk/php/
- 源码仓库：https://gitee.com/xuchangzhang/php-yahoo-sdk.git
- Packagist 页面：https://packagist.org/packages/xclib%2Fphp-yahoo-sdk
