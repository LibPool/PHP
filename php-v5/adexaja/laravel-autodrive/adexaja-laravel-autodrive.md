# adexaja/laravel-autodrive

> 标签: cloud platform, google, laravel

## 简介

Google api php client wrapper with Cloud Platform and Laravel 4 & 5 support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
