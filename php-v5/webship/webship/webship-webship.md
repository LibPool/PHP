# webship/webship

> 标签: PHP

## 简介

The Webship installer: choose a site template, like the Webship Starter or the Website Starter. Webship uses the UI Suite UIkit theme (UIkit and HTMX) on top of Drupal and Display Builder. Not to be used in production.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
