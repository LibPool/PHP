# webship/vdo

> 标签: PHP

## 简介

The Visual Distribution Operator (VDO) management system helps Drupal 8 distribution maintainers manage the base code and logic for the work cycle of development with number of workspaces for custom profiles, sub-profiles on local development machines or servers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
