# betalabs/amazon-es-php

> 标签: aws, client, elasticsearch, iam, search

## 简介

Support for using IAM authentication with the official Elasticsearch PHP client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
