# hansel23/wkhtmltox

> 标签: binary, pdf, wkhtmltoimage, wkhtmltopdf, wkhtmltox

## 简介

Static linked binary linux-generic-amd64 distributions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
