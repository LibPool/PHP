# sellerworks/amazon-mws

> 标签: SellerCentral, amazon, mws

## 简介

A PHP client for the Amazon Marketplace Web Services (MWS) API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
