# buckleshusky/fontawesomeiconpicker

> 标签: FontAwesome, font awesome, icons, picker, silverstripe

## 简介

Adds a Font Awesome 6.x icon picker for SilverStripe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
