# richardoentaryo/fpf1.00

> 标签: PHP

## 简介

A small, simple, and naked PHP MVC framework skeleton that encapsulates a lot of features also implements security layers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
