# haijin/specs

> 标签: DSL, assertions, expectations, phpunit, rspec, specs, testing

## 简介

A testing framework that uses a simple DSL, inspired by RSpec.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
