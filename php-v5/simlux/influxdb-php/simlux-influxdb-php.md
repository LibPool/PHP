# simlux/influxdb-php

> 标签: client, influxdata, influxdb, influxdb class, influxdb client, influxdb library, time series

## 简介

InfluxDB client library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
