# larryli/yii2-pushbear

> 标签: PHP

## 简介

PushBear Yii2 组件，使用 yii2-httpclient 包装 API。并提供 PushBearTarget 日志处理。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
