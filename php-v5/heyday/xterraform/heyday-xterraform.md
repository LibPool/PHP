# heyday/xterraform

> 标签: aws, cloud, code, infrastructure, terraform

## 简介

xTerraform package will provide project with easily scalable and maintainable cloud infrastructure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
