# parkwayprojects/paywithbank3d-php

> 标签: infinitypaul, parkwayprojects, payment gateway, paywithbank3d-php

## 简介

A PHP API wrapper for PayWithBank3D.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
