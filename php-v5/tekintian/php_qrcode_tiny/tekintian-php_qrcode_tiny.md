# tekintian/php_qrcode_tiny

> 标签: PHP二维码, phpqrcode, qrcode, tiny qrcode, 二维码工具

## 简介

PHP qrcode 二维码工具类 精简版本

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
