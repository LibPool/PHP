# tim-itwakes/plist

> 标签: plist

## 简介

Library for reading and writing Apple's CFPropertyList (plist) files in XML as well as binary format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
