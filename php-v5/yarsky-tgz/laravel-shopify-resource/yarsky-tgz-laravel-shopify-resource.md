# yarsky-tgz/laravel-shopify-resource

> 标签: PHP

## 简介

Package for Laravel providing high level ORM/Resource like abstraction level for Shopify API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
