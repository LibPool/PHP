# ticketpark/v11

> 标签: ESR, Einzahlungsschein, Payment slip, besr, v11

## 简介

A php library to process ESR/BESR v11 files (Swiss payment slips / Einzahlungsscheine mit Referenznummer)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
