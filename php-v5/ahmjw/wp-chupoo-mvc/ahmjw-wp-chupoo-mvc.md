# ahmjw/wp-chupoo-mvc

> 标签: dom, framework, mvc, php, plugin, wordpress

## 简介

MVC framework for Wordpress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
