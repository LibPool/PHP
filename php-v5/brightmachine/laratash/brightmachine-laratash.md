# brightmachine/laratash

> 标签: laravel, laravel 5, mustache, php

## 简介

A Laravel 5+ wrapper for mustache.php, a PHP implementation of http://mustache.github.io/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
