# ixtensa/zixbigdropdown

> 标签: big-drop-down, contao, drop-down, drop-down navigation, extension, navigation, special navigation

## 简介

Big drop-down navigation for Contao. This extension add special features like custom image and custom text on the regular pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
