# schnti/photoswipe

> 标签: kirby, kirby-cms, kirby-plugin

## 简介

A plugin for Kirby CMS to intecrate photoswipe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
