# yadelivery/serializer

> 标签: deserialization, jaxb, json, serialization, xml

## 简介

Library for (de-)serializing data of any complexity; supports XML, JSON, and YAML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
