# rubaxa/fileapi

> 标签: file upload, fileapi, jquery, multiupload, upload

## 简介

jQuery plugin for FileAPI (multiupload, image upload, crop, resize and etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
