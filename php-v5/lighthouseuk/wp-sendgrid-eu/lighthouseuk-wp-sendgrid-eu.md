# lighthouseuk/wp-sendgrid-eu

> 标签: sendgrid, wordpress

## 简介

WordPress plugin Shim to update SendGrid URL for the EU region.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
