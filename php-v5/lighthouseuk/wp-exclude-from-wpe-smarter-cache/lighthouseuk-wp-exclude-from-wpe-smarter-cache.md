# lighthouseuk/wp-exclude-from-wpe-smarter-cache

> 标签: PHP

## 简介

Exclude WordPress posts from WP Engine's Smarter Cache

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
