# redsql/redsql

> 标签: php, redbean plugin, redsql

## 简介

Programmatic and database agnostic SQL helper for RedBean delivered as a plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
