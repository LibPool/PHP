# markocupic/import_from_csv

> 标签: Import from csv, contao

## 简介

Import datarecords from csv-textfile. Backend extension for the Contao Open Source CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
