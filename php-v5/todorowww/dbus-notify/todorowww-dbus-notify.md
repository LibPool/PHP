# todorowww/dbus-notify

> 标签: d-bus, dbus, notify, php-dbus

## 简介

D-Bus Notification Library for Derick Rethans D-Bus PHP extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
