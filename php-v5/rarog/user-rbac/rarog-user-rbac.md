# rarog/user-rbac

> 标签: ZendFramework, module, zf3

## 简介

A Zend Framework module to easily integrate ZfcUser and ZfcRbac

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
