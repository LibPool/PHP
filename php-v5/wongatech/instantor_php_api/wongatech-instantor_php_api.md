# wongatech/instantor_php_api

> 标签: instantor

## 简介

Unofficial Instantor API for integration of Instantor service with third-party systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.instantor.com/api/doc
