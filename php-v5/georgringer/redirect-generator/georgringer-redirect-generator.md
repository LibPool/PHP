# georgringer/redirect-generator

> 标签: csv, export, extension, import, redirect, typo3

## 简介

Generate redirect entries from a given set of URLs and export all to CSV

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
