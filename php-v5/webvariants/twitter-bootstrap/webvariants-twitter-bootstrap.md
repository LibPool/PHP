# webvariants/twitter-bootstrap

> 标签: SallyCMS, bootstrap, twitter

## 简介

AddOn for SallyCMS, integrating the Twitter Bootstrap ui-framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
