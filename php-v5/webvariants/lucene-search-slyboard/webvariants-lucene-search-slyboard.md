# webvariants/lucene-search-slyboard

> 标签: PHP

## 简介

Provides an indexer for the SlyBoard addOn to the Lucene Search addOn.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
