# webvariants/fullpagecache

> 标签: PHP

## 简介

AddOn for SallyCMS to cache complete HTML pages and don't load Sally on every request.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
