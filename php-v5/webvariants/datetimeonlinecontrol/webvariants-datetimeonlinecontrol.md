# webvariants/datetimeonlinecontrol

> 标签: PHP

## 简介

An addon for SallyCMS, which adds online/offline handling by timestamp for articles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
