# webvariants/guestbook-antispam

> 标签: PHP

## 简介

AddOn for SallyCMS, providing spam detection via webservices for the guestbook addOn

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
