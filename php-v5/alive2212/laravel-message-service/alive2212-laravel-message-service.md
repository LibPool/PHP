# alive2212/laravel-message-service

> 标签: Alive2212, LaravelMessageService

## 简介

This is a laravel package for handle all message of system (SMS, PushNotif, Store to DB)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
