# hauerheinrich/hh-ext-faqs

> 标签: FAQ, TYPO3 CMS, extension, typo3

## 简介

Accessible, SEO friendly FAQ extension with live frontend search and jpfaq migration wizards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
