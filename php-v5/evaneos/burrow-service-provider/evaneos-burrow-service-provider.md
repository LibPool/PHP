# evaneos/burrow-service-provider

> 标签: PHP

## 简介

Bundle evaneos/burrow, an AMQP library in PHP, to be easily used with Silex.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
