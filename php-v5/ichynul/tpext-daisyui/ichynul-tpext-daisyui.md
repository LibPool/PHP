# ichynul/tpext-daisyui

> 标签: DaisyUI, alpine, tailwind, thinkphp, tpext

## 简介

tpext-builder UI library with Tailwind CSS + DaisyUI + Alpine.js (standalone replacement)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
