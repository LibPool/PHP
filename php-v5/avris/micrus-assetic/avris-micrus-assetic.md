# avris/micrus-assetic

> 标签: JS, assetic, assets, css, javascript, less, micrus, sass, scss, uglify

## 简介

Plugin integrating Assetic with Micrus Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
