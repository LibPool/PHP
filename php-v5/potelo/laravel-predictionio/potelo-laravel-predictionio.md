# potelo/laravel-predictionio

> 标签: api, laravel, machine learning, predictionio, wrapper

## 简介

Laravel wrapper for PredictionIO v0.9.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
