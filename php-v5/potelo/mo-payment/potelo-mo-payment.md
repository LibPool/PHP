# potelo/mo-payment

> 标签: billing, laravel, moip, pagamentos

## 简介

MoPayment fornece uma interface para controlar pagamentos no moip.com.br

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
