# ujjwal/h-commons

> 标签: zf2

## 简介

A Zend Framework 2 module which contains some usefull abstract classes that can be used across multiple modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
