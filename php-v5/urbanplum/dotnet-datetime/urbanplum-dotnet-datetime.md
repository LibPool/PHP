# urbanplum/dotnet-datetime

> 标签: .net, converter, date, datetime, dotnet-datetime, format, php, time, urbanplum

## 简介

Tools to convert between .NET and PHP date formats

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
