# mcguffin/acf-quick-edit-fields

> 标签: PHP

## 简介

WordPress Plugin implementing Column Displaying, QuickEdit and BulkEdit for Advanced Custom Fields (ACF)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
