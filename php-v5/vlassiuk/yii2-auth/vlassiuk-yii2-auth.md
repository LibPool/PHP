# vlassiuk/yii2-auth

> 标签: auth, extension, oauth2, yii2

## 简介

Module allow do authenticate users by social networks accaunt, create users account, profiles, check access rights, etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
