# mindgruve/two-factor-auth

> 标签: PHP

## 简介

PHP Implementation of RFC 6238 used by the Google Authenticator Token Generator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
