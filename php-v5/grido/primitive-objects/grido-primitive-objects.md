# grido/primitive-objects

> 标签: PHP

## 简介

Bring a bit of true OOP to your PHP code by using primitives (strings, numbers, arrays) as a first-class objects :)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
