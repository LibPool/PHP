# esyst/soapclient

> 标签: esyst, nusoap, soap

## 简介

Glue library that glues NuSoap together with the API of the native PHP SoapClient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
