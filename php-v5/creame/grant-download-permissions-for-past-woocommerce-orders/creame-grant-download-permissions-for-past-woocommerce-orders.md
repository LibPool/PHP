# creame/grant-download-permissions-for-past-woocommerce-orders

> 标签: downloads, permissions, plugin, woocommerce, wordpress

## 简介

This plugin grants downloads permissions like WooCommerce 2.6.x, granting permissions for new files added to a downloadable product.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
