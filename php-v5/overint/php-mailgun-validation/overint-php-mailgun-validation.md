# overint/php-mailgun-validation

> 标签: PHP

## 简介

Validate email address with Mailgun's validation service (Syntax checks, DNS validation, MX validation)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
