# sahaza/sahaza-group-intranet-project

> 标签: PHP

## 简介

Modèle de projet Composer pour installer la distribution Drupal Sahaza Group intranet en une seule commande.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
