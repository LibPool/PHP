# txtnation/txtnation-gateway-php

> 标签: Cell, billing, mobile, phone, sms, text

## 简介

A PHP library to help you integrate the txtNation Gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
