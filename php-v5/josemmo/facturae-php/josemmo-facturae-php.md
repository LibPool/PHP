# josemmo/facturae-php

> 标签: face, faceb2b, facturae, xades

## 简介

Librería para la generación, firma y envío de facturas electrónicas

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
