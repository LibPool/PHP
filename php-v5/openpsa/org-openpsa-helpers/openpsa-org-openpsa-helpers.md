# openpsa/org-openpsa-helpers

> 标签: helpers, midcom, openpsa

## 简介

OpenPSA helpers for AJAX and workgroup filtering, and some common housekeeping tasks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
