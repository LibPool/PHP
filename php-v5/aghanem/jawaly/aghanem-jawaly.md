# aghanem/jawaly

> 标签: 4jawaly, gateway, sms

## 简介

Laravel package to send SMS using 4jawaly.net API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://4jawaly.net
- 源码仓库：https://github.com/aghanemsure/4jawaly.git
