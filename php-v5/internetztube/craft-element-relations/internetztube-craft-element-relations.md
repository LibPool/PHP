# internetztube/craft-element-relations

> 标签: Craft, cms, craft-plugin, craftcms, element-relations, relations, replace, unused assets, usage, where used

## 简介

See where every element is used: one native list across all element types, sites and supported plugins, with Twig, GraphQL and element query support. Pro: unused filter, replace with undo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
