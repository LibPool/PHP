# cpbdigital/correios

> 标签: brazil, cep, frete, laravel

## 简介

Package para pesquisa de serviços de busca por cep, calculo de frete e etc, diretamente nos serviços dos Correios.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
