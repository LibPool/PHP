# tomiii/decoda-extended

> 标签: HOOK, bbcode, decoda, filter, lexer, markup, parser

## 简介

A lightweight lexical string parser for BBCode styled markup.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
