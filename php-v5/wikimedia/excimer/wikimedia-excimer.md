# wikimedia/excimer

> 标签: PHP

## 简介

Excimer is a PHP extension which provides a low-overhead interrupting timer and sampling profiler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
