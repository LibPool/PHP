# rezuankassim/bqanalytic

> 标签: BQAnalytic, laravel

## 简介

This is a package to ease integration between BigQuery and Firebase Analytics

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
