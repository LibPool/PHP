# cyruscollier/wp-test

> 标签: phpspec, phpunit, test-driven development, wordpress

## 简介

A framework for running unit and integration tests on WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
