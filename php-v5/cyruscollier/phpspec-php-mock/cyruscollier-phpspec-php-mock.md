# cyruscollier/phpspec-php-mock

> 标签: phpmock, phpspec, prophecy, test

## 简介

Adds the PHP Mock function mocking library as a phpspec Collaborator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
