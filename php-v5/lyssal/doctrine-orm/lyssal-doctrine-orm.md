# lyssal/doctrine-orm

> 标签: doctrine, manager, orm, repository

## 简介

Extensions for the Doctrine ORM library ; more cool functions in the Doctrine repositories and managers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
