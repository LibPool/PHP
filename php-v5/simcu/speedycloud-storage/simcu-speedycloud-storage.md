# simcu/speedycloud-storage

> 标签: cloud, sdk, speedycloud, storage

## 简介

Speedycloud Object Storage sdks for php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 许可证：BSD
