# adcetera/webform_ajax_datalayer

> 标签: PHP

## 简介

Provides a webform handler that can interact with the dataLayer for Ajax forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
