# dreamfactory/df-cassandra

> 标签: api, cassandra, database, dreamfactory, nosql, rest

## 简介

Cassandra database service for DreamFactory Platform 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
