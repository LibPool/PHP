# pattern-lab/starterkit-mustache-demo

> 标签: demo, mustache, pattern lab, starterkit

## 简介

The Mustache-based demo StarterKit for Pattern Lab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
