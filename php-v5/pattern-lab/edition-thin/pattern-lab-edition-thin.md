# pattern-lab/edition-thin

> 标签: pattern lab

## 简介

The Thin Edition of Pattern Lab. It only installs Pattern Lab core.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
