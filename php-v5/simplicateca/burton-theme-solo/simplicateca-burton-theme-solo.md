# simplicateca/burton-theme-solo

> 标签: craft-cms, custom-theme, theme

## 简介

Solo is a Burton Protosite Base Theme for Craft CMS 5+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
