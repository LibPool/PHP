# presshub-io/php-sdk

> 标签: api, client, framework, http, json, media, news, php, press, requests, rest, restful, social, social media, web service

## 简介

Presshub PHP SDK. Content distribution API for publishers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
