# phpspec/phpspec2

> 标签: BDD, SpecBDD, TDD, spec, specification

## 简介

Specification-oriented BDD framework for PHP 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
