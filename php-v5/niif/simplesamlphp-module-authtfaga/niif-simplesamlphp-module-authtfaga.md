# niif/simplesamlphp-module-authtfaga

> 标签: PHP

## 简介

Two-factor authentication module for simpleSAMLphp using Google Authenticator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
