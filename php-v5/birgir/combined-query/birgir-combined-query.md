# birgir/combined-query

> 标签: wordpress

## 简介

Modify the WP_Query to support the combined_query parameter. Combine multiple WP_Query queries into a single query.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
