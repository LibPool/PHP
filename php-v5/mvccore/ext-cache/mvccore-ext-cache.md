# mvccore/ext-cache

> 标签: cache, ext, extension, framework, interface, mvc, mvccore, plug-in, plugin, store

## 简介

MvcCore - Extension - Cache - register and use cache instances, cache interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
