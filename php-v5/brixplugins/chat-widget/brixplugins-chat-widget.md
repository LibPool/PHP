# brixplugins/chat-widget

> 标签: Craft, chat widget, cms, craft-plugin, craftcms

## 简介

Install an simple and easy to customize chat widget on your website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
