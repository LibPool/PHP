# impleri/laravel-resource

> 标签: Laravel 4, json, laravel, rest

## 简介

Alternative API-only RESTful resource implementation for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
