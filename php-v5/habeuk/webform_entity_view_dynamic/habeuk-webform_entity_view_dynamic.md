# habeuk/webform_entity_view_dynamic

> 标签: PHP

## 简介

Adds dynamic entity selection for Webform Entity View elements using URL parameters or Webform values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
