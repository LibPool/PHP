# corny-phoenix/tex-tools

> 标签: bibtex, latex, lualatex, pdf, post script, tex, xelatex

## 简介

PHP library for (La)TeX abstraction

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
