# inquid/yii-cd-ci

> 标签: continuous, deployment, git, integration, mercurial, selfupdate, update, vcs, yii2

## 简介

Basic extension for the Yii2 project self-update from VCS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
