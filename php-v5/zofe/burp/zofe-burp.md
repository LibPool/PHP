# zofe/burp

> 标签: Simple, filter, front controller, php, router

## 简介

Simple PHP router that works with query-string and uri-segments, laravel filter system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
