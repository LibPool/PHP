# codelight-eu/wp-migrate-db-pro-extended

> 标签: PHP

## 简介

Prevents anonymizing Administrator, Editor and Shop Manager roles. Uses example.org domains for user emails.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
