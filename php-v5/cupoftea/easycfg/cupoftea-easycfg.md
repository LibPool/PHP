# cupoftea/easycfg

> 标签: config, configuration, eloquent, laravel, meta, metadata

## 简介

Easily add configuration data to your Eloquent Models or Application in Laravel 5!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
