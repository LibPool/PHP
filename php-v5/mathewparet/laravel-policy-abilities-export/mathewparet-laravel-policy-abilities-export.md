# mathewparet/laravel-policy-abilities-export

> 标签: PHP

## 简介

Export Laravel Policy abilities to JSON for use with VueJS front end

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
