# juratitov/zfc-user

> 标签: zf2

## 简介

A generic user registration and authentication module for ZF2. Supports Zend\Db and Doctrine2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
