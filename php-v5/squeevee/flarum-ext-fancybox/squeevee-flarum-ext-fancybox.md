# squeevee/flarum-ext-fancybox

> 标签: PHP

## 简介

Image formatting and lightbox modal using FancyBox. (see https://fancyapps.com/fancybox)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
