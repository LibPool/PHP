# jouwweb/jw-persistent-user-doctrine

> 标签: zf2

## 简介

Extends JwPersistentUser to use Doctrine to manage tokens.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
