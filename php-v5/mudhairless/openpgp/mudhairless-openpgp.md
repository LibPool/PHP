# mudhairless/openpgp

> 标签: PGP, crypto, cryptography, encryption, gnupg, key-pair, openpgp, security, signature, signing

## 简介

Implementation of OpenPGP for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
