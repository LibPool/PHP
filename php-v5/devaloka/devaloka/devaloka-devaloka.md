# devaloka/devaloka

> 标签: di, event, event-dispatcher, pimple, plugin, wordpress

## 简介

A WordPress plugin brings DI Container, Event Dispatcher to WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
