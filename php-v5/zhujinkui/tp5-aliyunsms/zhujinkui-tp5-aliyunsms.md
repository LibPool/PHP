# zhujinkui/tp5-aliyunsms

> 标签: PHP

## 简介

This is a Ali cloud communication business based on ThinkPHP5 framework integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
