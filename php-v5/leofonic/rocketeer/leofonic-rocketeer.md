# leofonic/rocketeer

> 标签: deploy, deployment, laravel, ssh, task

## 简介

Rocketeer is a fast and simple deployer for the PHP world

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
