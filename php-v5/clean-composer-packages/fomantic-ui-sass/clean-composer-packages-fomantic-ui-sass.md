# clean-composer-packages/fomantic-ui-sass

> 标签: fomantic, fomantic-ui, sass

## 简介

Composer build of Fomantic UI for Sass.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
