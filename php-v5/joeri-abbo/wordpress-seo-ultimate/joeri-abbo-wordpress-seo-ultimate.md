# joeri-abbo/wordpress-seo-ultimate

> 标签: plugin, wp, wp-plugin

## 简介

The magical plugin to glue Yoast and acf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
