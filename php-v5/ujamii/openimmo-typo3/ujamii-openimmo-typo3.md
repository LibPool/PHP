# ujamii/openimmo-typo3

> 标签: PHP

## 简介

TYPO3 CMS extension for showing OpenImmo based data on a TYPO3 based website

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
