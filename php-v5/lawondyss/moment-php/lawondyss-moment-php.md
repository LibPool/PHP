# lawondyss/moment-php

> 标签: date, datetime, formatting, manipulate, parse, time

## 简介

MomentPHP is library for parsing, manipulating and formatting dates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
