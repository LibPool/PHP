# alextigaer/team-auth

> 标签: laravel, multi-auth, multiauth, team-auth, teamauth

## 简介

A simple multi-auth package for laravel 5.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
