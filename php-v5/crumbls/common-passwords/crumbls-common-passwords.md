# crumbls/common-passwords

> 标签: PHP

## 简介

A laravel validation rule to exclude not allow the most common 10,000 passwords and any that you add in.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
