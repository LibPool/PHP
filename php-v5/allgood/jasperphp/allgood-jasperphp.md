# allgood/jasperphp

> 标签: jaspersoft, jrxml, pdf, report

## 简介

Pure PHP library to read JRXML files made with 'JasperSoft Studio' and generate reports in PDF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
