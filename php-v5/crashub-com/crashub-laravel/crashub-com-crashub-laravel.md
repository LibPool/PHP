# crashub-com/crashub-laravel

> 标签: debugging, errors, exceptions, logging, monitoring, reporting

## 简介

Crashub client for your Laravel project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
