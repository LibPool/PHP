# geggleto/slim-pimple-bridge

> 标签: PHP

## 简介

Slim Pimple Bridge. Inject's slim's dependencies into a Pimple Container

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
