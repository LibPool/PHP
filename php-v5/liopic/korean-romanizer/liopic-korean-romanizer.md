# liopic/korean-romanizer

> 标签: hangeul, hangugeo, hangul, korean, romanization, romanize

## 简介

Library to romanize Korean in UTF-8 format

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
