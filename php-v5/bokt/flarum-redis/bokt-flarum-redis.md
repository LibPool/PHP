# bokt/flarum-redis

> 标签: blomstra, cache, flarum, queue, redis, session

## 简介

Adds Redis cache, sessions and queue to Flarum

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
