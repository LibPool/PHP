# maxodrom/yii2-mango-office-api

> 标签: api, mango office, module, yii2

## 简介

Yii2 module for working with Mango API (https://www.mango-office.ru/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
