# bmilesp/saas-overrides

> 标签: PHP

## 简介

Overrides for Saas Projects - to be used in conjunction with CakePHPPostINstall package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
