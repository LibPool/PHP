# lmatte7/platform-bundle

> 标签: mysql, platform.sh, rsync, symfony

## 简介

Symfony commands that can be used with the Platform.sh hosting service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
