# duellsy/pockpack

> 标签: get pocket, getpocket, pocket, pockpack, read it later, readitlater

## 简介

Package to handle communication with GetPocket.com API neatly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
