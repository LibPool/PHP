# pleets/sqlwebmanager

> 标签: framework, php

## 简介

Web application for managing databases

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.sqlwebmanager.com
- 源码仓库：https://github.com/Pleets/SQLWebManager.git
- Packagist 页面：https://packagist.org/packages/pleets%2Fsqlwebmanager

## 历史版本号

## 获取地址

- Composer 安装：`composer require pleets/sqlwebmanager`
