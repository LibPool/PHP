# php-llm/mcp-bundle

> 标签: PHP

## 简介

Symfony integration bundle for Model Context Protocol (via php-llm/mcp-sdk)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
