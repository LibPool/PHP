# ventrec/timestampr

> 标签: mysql, timestamp

## 简介

Updates timestamp columns in your database that violates the new nullable requirement in newer mysql versions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
