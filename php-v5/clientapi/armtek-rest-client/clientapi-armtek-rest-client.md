# clientapi/armtek-rest-client

> 标签: api, armtek, rest

## 简介

Armtek HTTP клиент для работы с веб-сервисами (JSON или XML)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
