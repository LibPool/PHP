# laelaps/phpunit-test-aware

> 标签: aware, phpunit, test

## 简介

Collection of PHPUnit aware objects for some deeper testing and mocking.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
