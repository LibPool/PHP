# dilab/omnipay-xendit

> 标签: gateway, merchant, omnipay, xendit

## 简介

Xendit gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
