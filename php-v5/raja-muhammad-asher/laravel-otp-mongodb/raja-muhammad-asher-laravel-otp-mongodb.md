# raja-muhammad-asher/laravel-otp-mongodb

> 标签: PHP

## 简介

A simple package to generate and validate OTPs for mongodb/laravel-mongodb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
