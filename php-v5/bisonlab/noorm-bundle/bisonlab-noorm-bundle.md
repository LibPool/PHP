# bisonlab/noorm-bundle

> 标签: Nosql adapter rest arrayaccess

## 简介

Bundle for simple access to (mainly) nosql databases for Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
