# xima/ddep

> 标签: cli, database, ddev, docker, rsync, ssh, symfony, typo3

## 简介

Developer tooling for containerised remote environments: pull/push media and database dumps over SSH, open a shell, and follow logs of a remote Docker Compose application container.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
