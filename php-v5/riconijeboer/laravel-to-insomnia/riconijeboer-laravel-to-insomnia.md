# riconijeboer/laravel-to-insomnia

> 标签: PHP

## 简介

This package enables you to convert your Laravel routes to a JSON file which you can import in Insomnia

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
