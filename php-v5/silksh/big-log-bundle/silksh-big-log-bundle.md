# silksh/big-log-bundle

> 标签: symfony3 redis sql

## 简介

Symfony3 bundle to use the Redis and an SQL database to store logs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
