# alexandre-fernandez/json-translation-bundle

> 标签: doctrine, i18n, orm, symfony

## 简介

Manage localized content in your Symfony applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
