# yiier/yii2-translate

> 标签: extension, translate, yii2

## 简介

腾讯翻译君翻译、百度翻译 、谷歌翻译（Google 翻译）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
