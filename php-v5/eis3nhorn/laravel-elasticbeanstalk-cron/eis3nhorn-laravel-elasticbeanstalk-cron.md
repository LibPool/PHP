# eis3nhorn/laravel-elasticbeanstalk-cron

> 标签: PHP

## 简介

Ensure only one Laravel instance is running CRON jobs in an EB environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
