# fengkui/xcx

> 标签: PHP

## 简介

整合多端小程序（微信、QQ、百度、字节跳动、钉钉、支付宝）相关信息获取与使用

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
