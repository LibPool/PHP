# zfr/zfr-mailchimp

> 标签: campaign, mail, mailchimp

## 简介

PHP library for interacting with the v2 MailChimp REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
