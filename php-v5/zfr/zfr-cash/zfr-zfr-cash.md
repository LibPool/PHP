# zfr/zfr-cash

> 标签: payment, stripe, zf2

## 简介

Zend Framework 2 module that simplify payments with Stripe payment gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
