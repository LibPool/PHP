# metaslider/flexslider

> 标签: automattic, flexslider, jquery, slider, woocommerce

## 简介

An awesome, fully responsive jQuery slider toolkit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
