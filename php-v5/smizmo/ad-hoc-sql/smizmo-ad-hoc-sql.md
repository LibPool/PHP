# smizmo/ad-hoc-sql

> 标签: ad hoc, cms, query, report, silverstripe

## 简介

Allows user to construct reports using sql select statements to run through model admin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
