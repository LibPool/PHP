# youthage/laravel-geohash

> 标签: PHP

## 简介

LBS地理位置距离计算方法geohash，将一个经纬度信息，转换成一个可以排序，可以比较的字符串编码，用于高效搜索

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
