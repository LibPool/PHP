# boxberry-delivery/php-api-c2c

> 标签: api, boxberry, boxberry-api, boxberry-delivery, c2c, delivery, delivery-api

## 简介

Реализация Boxberry API для работы с сервисами ЛК и ПиП (письма и посылки)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
