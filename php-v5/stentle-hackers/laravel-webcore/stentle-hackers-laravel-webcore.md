# stentle-hackers/laravel-webcore

> 标签: stentle

## 简介

It provides a class sets to facilitate communication with the api of stentle. Support for laravel 5.3.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
