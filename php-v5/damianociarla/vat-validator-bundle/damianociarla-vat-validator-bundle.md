# damianociarla/vat-validator-bundle

> 标签: Symfony2, constraint, soap, validator, vat, view

## 简介

This Bundle provides a validator for the VAT number for Symfony2 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
