# sgalinski/sg-ajax

> 标签: PHP

## 简介

DEPRECATED: Legacy Extbase AJAX dispatcher for TYPO3. Migrate to sgalinski/sg-apicore as the successor for API routing, authentication, and JSON/HTML responses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
