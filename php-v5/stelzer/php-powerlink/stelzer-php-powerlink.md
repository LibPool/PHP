# stelzer/php-powerlink

> 标签: cli, powerlink, powerlink wrapper

## 简介

A PHP wrapper around the PowerLink CRM API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
