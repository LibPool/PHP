> 标签: amazon S3, dropbox, image, image handler, image resize, image-resizer, imagehandler, images, ninja-image, ninjaimg, php-sdk, resizing, upload api

## 简介

NinjaImg PHP SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
