# diffywebsite/diffy-terminus-build-tools-plugin

> 标签: PHP

## 简介

Diffy Integration Terminus command. Used for setting up Pantheon Build Tools workflow.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
