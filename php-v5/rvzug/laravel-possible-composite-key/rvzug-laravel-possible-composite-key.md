# rvzug/laravel-possible-composite-key

> 标签: PHP

## 简介

PHP trait to use composite keys in your Laravel Eloquent models and does not fail on possible missing column.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
