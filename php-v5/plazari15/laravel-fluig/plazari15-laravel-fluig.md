# plazari15/laravel-fluig

> 标签: PHP

## 简介

Laravel Package for TOTVS Fluig REST Api. Compatible with Fluig >= 1.5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
