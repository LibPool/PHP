# webappz/jsonml

> 标签: PHP

## 简介

Provides an XML Schema for JSON-values and a parser to cast PHP-values to schema-aware DOMElements and vice versa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
