# webtrendi/lexiconic

> 标签: gettext, internationalization, localization, translation

## 简介

Utility and classes to facilitate gettext style translations in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
