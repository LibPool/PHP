# daffie/sql-like-to-regular-expression

> 标签: PCRE, like, regex, regular expression, sql

## 简介

Library to convert SQL Like patterns to regular expressions patterns

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
