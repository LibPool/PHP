# mavimedia/shopware6-primary-order-transaction

> 标签: PHP

## 简介

Automatically sets primaryOrderTransactionId for orders created via API without the cart flow

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
