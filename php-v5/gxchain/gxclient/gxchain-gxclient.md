# gxchain/gxclient

> 标签: api, blockchain, crypto, gxc, gxclient, php, rpc, sdk

## 简介

A client to interact with gxchain implemented in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
