# techdivision/websocketcontainer

> 标签: PHP

## 简介

Web socket container implementation that serves web socket requests for thread based PHP ApplicationServer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
