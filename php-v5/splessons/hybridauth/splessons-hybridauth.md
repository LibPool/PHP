# splessons/hybridauth

> 标签: Authentication, OpenId, api, authorization, facebook, google, oauth, social, twitter

## 简介

PHP Social Authentication Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
