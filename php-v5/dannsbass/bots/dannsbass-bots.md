# dannsbass/bots

> 标签: Telegram bot library, telegram, telegram bot, telegram bot api

## 简介

Simple Telegram Bot API library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
