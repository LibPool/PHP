# romeoz/rock-db

> 标签: Active Record, CUBRID, dao, database, dbal, mssql, mysql, orm, persistence, postgresql, rdbms, sqlite

## 简介

Object Relational Mapping (ORM) for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
