# romeoz/rock-sphinx

> 标签: Active Record, search, search engine, sphinx, sphinxql, sphinxsearch

## 简介

Object Relational Mapping (ORM) for Sphinx Search.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
