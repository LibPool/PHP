# mandarinmedien/mmcmfmenubundle

> 标签: PHP

## 简介

This bundle provides the functionality to organize and render multiple menus with custom entries based on NodeRoute entites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
