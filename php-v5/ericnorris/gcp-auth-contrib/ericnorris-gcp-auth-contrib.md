# ericnorris/gcp-auth-contrib

> 标签: PHP

## 简介

Unofficial Google Cloud Platform authentication library focusing on speed and correctness.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
