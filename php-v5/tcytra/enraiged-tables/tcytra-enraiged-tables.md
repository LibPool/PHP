# tcytra/enraiged-tables

> 标签: enraiged, tables

## 简介

Enraiged Tables provides table handling features for Laravel Enraiged projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
