# mhytry/simplebus-commandbus-silex-provider

> 标签: SimpleBus, commandbus, provider, service, silex

## 简介

A silex service provider for commandbus using simplebus/messagebus

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
