# iphp/filestore-bundle

> 标签: file upload, sonata admin file upload, symfony file upload, upload

## 简介

Upload files for doctrine entities in symfony 2 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
