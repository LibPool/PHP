# lemmotresto/laravel-moneybird

> 标签: laravel, moneybird

## 简介

Fork of Casdr/laravel-moneybird. Moneybird package for Laravel based on Picq'ers client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
