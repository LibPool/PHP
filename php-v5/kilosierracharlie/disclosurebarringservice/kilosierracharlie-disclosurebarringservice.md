# kilosierracharlie/disclosurebarringservice

> 标签: CRB, DBS, api, disclosure, update service

## 简介

A PHP library for interacting with the DBS update service API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
