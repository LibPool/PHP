# cubear/cwd_base_bootstrap

> 标签: PHP

## 简介

A lightweight Drupal 8 theme built on Bootstrap, implementing Cornell Branding and standard CWD components; from Cornell University CIT-CD.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
