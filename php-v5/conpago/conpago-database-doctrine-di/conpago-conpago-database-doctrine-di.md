# conpago/conpago-database-doctrine-di

> 标签: PHP

## 简介

Doctrine ORM adapter implementation dependency injection module for Conpago framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
