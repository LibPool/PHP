# bootpress/validator

> 标签: bootpress, form, validation

## 简介

Form validation that is designed to simplify and work seamlessly with Jörn's jQuery Validation Plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
