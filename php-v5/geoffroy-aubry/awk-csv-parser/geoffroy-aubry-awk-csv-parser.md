# geoffroy-aubry/awk-csv-parser

> 标签: awk, bash, csv parser

## 简介

AWK and Bash code to easily parse CSV files, with possibly embedded commas and quotes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
