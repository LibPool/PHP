# geoffroy-aubry/mutex

> 标签: flock, mutex, semaphore

## 简介

Mutex & Semaphore PHP implementations both based only on flock() function.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
