# jonas-bostoen/db-seeder

> 标签: PHP

## 简介

Simple to use PHP db seeding tool that uses faker generators based on thebazil/db-seeder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
