# drez/hjson-to-propel-xml

> 标签: config, hjson, human, json, parser, propel

## 简介

Convert JSON for Humans (HJSON) to Propel XML Schema.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
