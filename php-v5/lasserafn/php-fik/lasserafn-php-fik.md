# lasserafn/php-fik

> 标签: Accounting, FIK, LasseRafn, invoice, reminder

## 简介

Generate danish FIK numbers easily.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
