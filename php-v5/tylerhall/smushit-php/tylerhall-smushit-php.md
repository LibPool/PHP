# tylerhall/smushit-php

> 标签: image optimization, php, smushit

## 简介

A PHP wrapper around Yahoo!'s Smush.it image compression web service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
