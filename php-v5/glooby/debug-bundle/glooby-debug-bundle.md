# glooby/debug-bundle

> 标签: Guzzle, bundle, debug, glooby, http, logging, rest, symfony

## 简介

Symfony debugging and log bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
