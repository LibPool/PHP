# saritasa/tsheets

> 标签: api, library, php, rest, tsheets

## 简介

PHP Helper Library for TSheets API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/TSheetsTeam/api_phplib
- 源码仓库：https://github.com/Saritasa/tsheets.git
- Packagist 页面：https://packagist.org/packages/saritasa%2Ftsheets

- PHP 要求：>=5.5.0
