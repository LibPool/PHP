# jmflava/mongo-morph

> 标签: flat, mongo

## 简介

A PHP object that can flatten MongoDB data or restore flattened data to MongoDb format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
