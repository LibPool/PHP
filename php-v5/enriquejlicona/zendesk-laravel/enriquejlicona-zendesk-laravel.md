# enriquejlicona/zendesk-laravel

> 标签: Zendesk

## 简介

Laravel wrapper for zendesk/zendesk_api_client_php package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
