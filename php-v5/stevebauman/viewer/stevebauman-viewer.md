# stevebauman/viewer

> 标签: Viewer, eloquent, laravel, php, presenter

## 简介

A presenter-like package but used for attaching modular views on a retrieved eloquent record

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
