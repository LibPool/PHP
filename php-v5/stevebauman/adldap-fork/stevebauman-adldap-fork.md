# stevebauman/adldap-fork

> 标签: active directory, ldap, windows

## 简介

adLDAP, PHP LDAP library for manipulating Active Directory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
