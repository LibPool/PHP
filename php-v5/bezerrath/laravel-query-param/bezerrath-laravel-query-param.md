# bezerrath/laravel-query-param

> 标签: eloquent, laravel

## 简介

Treats binary data in a correct way with Laravel's database system (Eloquent)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
