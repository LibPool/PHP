# liteweb/dotpay

> 标签: Liteweb, dotpay, laravel

## 简介

Package for Dotpay payments via api instead of form

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/Liteweb/Dotpay
- 源码仓库：https://github.com/liteweb-io/dotpay.git
- Packagist 页面：https://packagist.org/packages/liteweb%2Fdotpay
