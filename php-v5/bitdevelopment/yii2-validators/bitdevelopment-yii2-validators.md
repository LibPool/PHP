# bitdevelopment/yii2-validators

> 标签: count, dependent, extension, form, validators, widget, word, yii2

## 简介

Set of validators that doesn't exist in Yii by default

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
