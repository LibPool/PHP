# samuel4x4/chefauth-guzzle-plugin

> 标签: Guzzle, chef, http

## 简介

A guzzle (v3) plugin handling all authentication for Chef server API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
