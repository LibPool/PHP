# hashworks/phergie-whois-on-join-plugin

> 标签: bot, handler, irc, join, phergie, plugin, whois

## 简介

Phergie plugin to whois a user on join and handle the result.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
