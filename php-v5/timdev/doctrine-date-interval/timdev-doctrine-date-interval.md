# timdev/doctrine-date-interval

> 标签: dateinterval, dbal, doctrine

## 简介

Backported Doctrine DBAL DateIntervalType for use with DBAL <2.6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
