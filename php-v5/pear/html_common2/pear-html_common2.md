# pear/html_common2

> 标签: PEAR, attribute, element, html

## 简介

Abstract base class for HTML classes (PHP5 port of HTML_Common package).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
