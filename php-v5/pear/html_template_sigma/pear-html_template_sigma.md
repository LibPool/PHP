# pear/html_template_sigma

> 标签: template-engine, templating

## 简介

A fork of Integrated Templates (PEAR HTML_Template_IT) with template "compilation" added

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
