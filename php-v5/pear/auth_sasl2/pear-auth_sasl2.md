# pear/auth_sasl2

> 标签: sasl

## 简介

Provides code to generate responses to common SASL mechanisms, including: [Digest-MD5, Cram-MD5, Plain, Anonymous, Login (Pseudo mechanism), SCRAM]

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
