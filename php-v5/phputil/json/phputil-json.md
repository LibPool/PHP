# phputil/json

> 标签: decode, encode, json, object, php, private, protected

## 简介

A JSON encoder and decoder that can also convert PHP objects with private or protected attributes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
