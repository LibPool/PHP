# ilab/ilab-flysystem-aws-s3-v3

> 标签: PHP

## 简介

Flysystem adapter for the AWS S3 SDK v3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
