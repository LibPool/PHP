# ilab/ilab-docs

> 标签: admin, docs, documentation, markdown

## 简介

Adds markdown documentation for your theme or plugin to the WordPress admin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
