# gavinggordon/helphp

> 标签: class creation, cli, code-generation, command, console, file creation, generation, helper functions, helpers, php, psr-4 compliant, simplification, templates, templating, v1.0.0

## 简介

A PHP CLI package that provides the developer with the means to generate PHP related files, like classes and .ini's, in a variety of different levels of both simplicity and complexity.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
