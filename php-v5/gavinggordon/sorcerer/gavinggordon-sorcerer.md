# gavinggordon/sorcerer

> 标签: collection, crawling, data collecting, html code, http, inspection, investigation, php, scraper, scraping, source code, v1.0.0, web crawler, web crawling, web scraping, webpage, website

## 简介

An easy-to-use PHP class for scraping webpages' source code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
