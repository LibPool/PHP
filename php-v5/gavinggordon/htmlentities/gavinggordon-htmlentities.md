# gavinggordon/htmlentities

> 标签: decode, decoder, decoding, encode, encoder, encoding, entities, formatter, get_html_translation_table, html, html_translation, html_translation_table, htmlentities, php, translation_table, v4.1

## 简介

A PHP class which allows the decoding and encoding of a wider variety of characters compared to the standard htmlentities and html_entity_decode functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
