# j7mbo/aurex

> 标签: Skeleton, auryn, dependency injection, php, silex

## 简介

aurex is a merge between the Silex micro-framework and the awesome Auryn dependency injector.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
