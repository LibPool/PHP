# rstgroup/php-consul-kv-array-getter

> 标签: PHP

## 简介

This library allows you to receive the consul's KV Store's keys as a structured array.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
