# ifcastle/events

> 标签: event-dispatcher, event-listener, event-subscriber, events

## 简介

Implementation of the Events + EventDispatcher pattern.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
