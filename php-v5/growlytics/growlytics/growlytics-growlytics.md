# growlytics/growlytics

> 标签: debugging, errors, exceptions, growlytics, logging, tracking

## 简介

Official Growlytics notifier sdk for PHP applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://docs.growlytics.in/php-integration/php-integration
- 源码仓库：https://bitbucket.org/rockstar123/growlytics-php-plugin.git
- Packagist 页面：https://packagist.org/packages/growlytics%2Fgrowlytics
