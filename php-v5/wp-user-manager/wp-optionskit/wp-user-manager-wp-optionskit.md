# wp-user-manager/wp-optionskit

> 标签: optionskit, wordpress

## 简介

A toolkit for developers to create administration options panels for WordPress powered by Vuejs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
