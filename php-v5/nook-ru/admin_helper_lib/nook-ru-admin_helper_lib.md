# nook-ru/admin_helper_lib

> 标签: admin, api, bitrix

## 简介

API for custom admin interface in Bitrix by DigitalWand and Notamedia agency

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
