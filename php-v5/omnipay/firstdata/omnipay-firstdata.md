# omnipay/firstdata

> 标签: first data, firstdata, gateway, merchant, omnipay, pay, payment

## 简介

First Data driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
