# morethanthemes/extra_ux

> 标签: PHP

## 简介

Orchestrates multiple enhancements to improve the default Drupal CMS user experience, including reusable blocks, sample content, landing pages, and a style guide.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
