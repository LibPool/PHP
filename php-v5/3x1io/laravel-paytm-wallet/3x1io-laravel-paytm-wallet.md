# 3x1io/laravel-paytm-wallet

> 标签: laravel, paytm wallet

## 简介

Integrate paytm wallet easily with this package. This package uses official Paytm PHP SDK's

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
