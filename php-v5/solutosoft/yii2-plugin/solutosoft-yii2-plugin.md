# solutosoft/yii2-plugin

> 标签: core, plugin, widget, yii, yii2

## 简介

Yii 2 core code to write extensions based on javascript plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
