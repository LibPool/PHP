# faonni/module-shipping-multi-flat

> 标签: PHP

## 简介

MultiFlatShipping extension will create 5 flat rate shipping methods with different prices and conditions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
