# faonni/module-bitcoin

> 标签: PHP

## 简介

A Bitcoin payment method for the Magento2 ecommerce app using Bitcoin RPC API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
