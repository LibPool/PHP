# fomvasss/laravel-punycode

> 标签: domain, idn, laravel, punycode

## 简介

Package for encoding of Unicode for Internationalized Domain Names in Applications (IDNA)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
