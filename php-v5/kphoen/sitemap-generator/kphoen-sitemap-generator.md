# kphoen/sitemap-generator

> 标签: Sitemap, generator, seo

## 简介

Provides a way to create/generate a sitemap using Propel, Doctrine, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
