# mark-wff/craft-var-dumper

> 标签: Craft, cms, craft-plugin, craft-var-dumper, craftcms

## 简介

Adds Symfony Var-Dumper to Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
