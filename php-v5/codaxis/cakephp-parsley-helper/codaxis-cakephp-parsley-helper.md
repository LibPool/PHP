# codaxis/cakephp-parsley-helper

> 标签: cakephp, form, parsley, validation

## 简介

CakePHP Form Helper for Parsley.js automatic validation integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
