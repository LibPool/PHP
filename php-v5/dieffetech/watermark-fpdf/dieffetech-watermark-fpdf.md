# dieffetech/watermark-fpdf

> 标签: PHP

## 简介

Library for apply watermark on pdf using setasign/fpdi and setasign/fpdf

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
