# schaapdigitalcreatives/sdc-wp-ai-content-migration

> 标签: PHP

## 简介

The WordPress plugin to migrate content from Google Drive into Kennisbank using OpenAI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
