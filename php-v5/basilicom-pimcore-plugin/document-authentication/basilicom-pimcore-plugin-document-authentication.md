# basilicom-pimcore-plugin/document-authentication

> 标签: Authentication, password, pimcore

## 简介

Enables selective HTTP Basic Auth via document properties

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
