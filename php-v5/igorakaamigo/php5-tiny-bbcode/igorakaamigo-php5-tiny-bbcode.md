# igorakaamigo/php5-tiny-bbcode

> 标签: bbcode, library, php5, utils

## 简介

A tiny BBCode implementation for old PHP5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
