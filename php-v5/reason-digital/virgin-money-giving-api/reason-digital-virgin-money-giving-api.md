# reason-digital/virgin-money-giving-api

> 标签: VMG, api

## 简介

Provides a PHP library for interacting with the Virgin Money Giving API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
