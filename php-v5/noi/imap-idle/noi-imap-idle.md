# noi/imap-idle

> 标签: PEAR, idle, imap, imap_idle, library, mail, net, net_imap

## 简介

An implementation of the IMAP IDLE (RFC 2177) based on the pear/Net_IMAP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
