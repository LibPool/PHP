# elliotchance/intuit-quickbooks

> 标签: PHP

## 简介

The PHP SDK for QuickBooks v3 is set of PHP classes that make it easier to call QuickBooks APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
