# pantheon-systems-ps/pantheon_nextjs_demo

> 标签: PHP

## 简介

Configures a Drupal site as the headless backend for a single Next.js front end on Pantheon: content model, JSON:API, OAuth, and the Next.js module wired up.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
