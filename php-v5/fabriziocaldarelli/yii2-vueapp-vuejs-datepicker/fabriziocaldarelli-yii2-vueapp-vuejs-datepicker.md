# fabriziocaldarelli/yii2-vueapp-vuejs-datepicker

> 标签: datepicker, extension, vue, yii2

## 简介

VueJs Datepicker plugin for Yii2 VueApp package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
