# fabriziocaldarelli/yii2-vueapp

> 标签: extension, vue, yii2

## 简介

A Vue.js helper for create Vue app in Yii2 without webpack or similar

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
