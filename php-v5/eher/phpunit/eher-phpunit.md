# eher/phpunit

> 标签: PHP

## 简介

Unofficial version of PHPUnit to be handled with Composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/eher%2Fphpunit
- 源码仓库：https://github.com/EHER/phpunit-all-in-one.git
