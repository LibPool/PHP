# vanilla/legacy-passwords

> 标签: legacy, password, php, vanilla, vanilla forums

## 简介

Provides support for legacy password hashing in common frameworks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
