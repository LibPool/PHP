# mesh-research/linked-open-profiles

> 标签: PHP

## 简介

WordPress plugin for displaying data from the public scope of multiple ORCID profiles on pages, posts, and sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
