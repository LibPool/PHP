# localgovdrupal/localgov_content_access_control

> 标签: PHP

## 简介

Creates access control mechanisms so specific editors can only edit specific sections of the website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
