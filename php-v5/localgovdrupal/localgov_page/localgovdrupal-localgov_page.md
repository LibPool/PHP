# localgovdrupal/localgov_page

> 标签: PHP

## 简介

A page content type for LocalGov Drupal that allows the building of rich content using Paragraphs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
