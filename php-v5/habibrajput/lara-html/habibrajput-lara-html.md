# habibrajput/lara-html

> 标签: PHP

## 简介

Package is used to access html, php, .blade.php files with creating controller and adding  routes in web.php files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
