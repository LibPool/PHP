# birjemin/curl

> 标签: PHP cURL, curl delete, curl library, curl lightweight, curl post, curl put

## 简介

一个轻量级的PHP网络操作类，实现GET、POST、PUT、DELETE常用操作，出错自动重试，支持链式写法

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
