# bojaspus/zendamf

> 标签: amf, zf2

## 简介

provides support for Adobe's » Action Message Format (AMF), to allow communication between Adobe's » Flash Player and PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
