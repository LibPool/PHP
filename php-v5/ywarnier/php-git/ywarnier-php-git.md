# ywarnier/php-git

> 标签: git

## 简介

Simple wrapper for Git

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.github.com/sebastianbergmann/git
- 源码仓库：https://github.com/ywarnier/php-git.git
- Packagist 页面：https://packagist.org/packages/ywarnier%2Fphp-git
