# mf2/mf2

> 标签: html, microformats, microformats 2, parser, semantic

## 简介

A pure, generic microformats2 parser — makes HTML as easy to consume as a JSON API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
