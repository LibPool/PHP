# peertopark/composer-grunt-bridge

> 标签: Bridge, composer, composer-plugin, grunt, integration, package, plugin

## 简介

Grunt integration for Composer packages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
