# magepow/whatsappcontact

> 标签: PHP

## 简介

Magento 2 WhatsApp Contact is an extension to show up the Whatsapp button chat on the website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
