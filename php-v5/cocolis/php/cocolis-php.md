# cocolis/php

> 标签: cocolis, php

## 简介

PHP library to use Cocolis.fr API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/Cocolis-1/cocolis-php.git
