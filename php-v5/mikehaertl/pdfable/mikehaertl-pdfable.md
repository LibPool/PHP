# mikehaertl/pdfable

> 标签: pdf, yii

## 简介

PDFable is a Yii extension to create PDFs from web pages with PHPWkHtmlToPdf(included)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
