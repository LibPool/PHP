# arquivei/intercom-php

> 标签: Guzzle, api, arquivei, intercom, intercom.io

## 简介

Intercom API client built on top of Guzzle 6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
