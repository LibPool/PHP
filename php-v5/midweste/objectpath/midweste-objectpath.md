# midweste/objectpath

> 标签: json, json path, jsonpath, object path

## 简介

Generic 'dot path' class for accessing and modifying data classes and arrays

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
