# totallydave/auto-deploy

> 标签: auto, deploy, module, web hook, zend framework 2

## 简介

Auto deployment module for Zend Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
