# nsept/yii2-mousewheel

> 标签: asset, extension, jquery, mousewheel, yii2

## 简介

A jQuery plugin that adds cross-browser mouse wheel support with delta normalization.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
