# mrclay/elgg-http-combiner

> 标签: amd, elgg, http, plugin, webperf

## 简介

Reduces HTTP requests by merging files and AMD modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
