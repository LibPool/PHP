# switchbox/switchbox

> 标签: Settings, config, configuration, ini

## 简介

Quick and extensible configuration library that can load and save in JSON, YAML, INI, and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
