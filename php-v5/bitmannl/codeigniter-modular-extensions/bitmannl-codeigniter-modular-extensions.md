# bitmannl/codeigniter-modular-extensions

> 标签: PHP

## 简介

Install CodeIgniter Modular Extensions HMVC (WireDesignz) via Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
