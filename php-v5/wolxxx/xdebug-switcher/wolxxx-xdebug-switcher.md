# wolxxx/xdebug-switcher

> 标签: PHP

## 简介

enable or disable xdebug, as xdebug helper for chrome is disabled. no further need for browser extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
