# pablolovera/modules-laravel

> 标签: laravel, laravel 5 modules, modules, modulos

## 简介

Modules for applications based on laravel 5.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
