# humanmade/wp-scripts-asset-loader

> 标签: PHP

## 简介

Use WP Scripts to load compile and load global assets, custom blocks, and extend block assets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
