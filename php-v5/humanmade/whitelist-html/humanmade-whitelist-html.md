# humanmade/whitelist-html

> 标签: PHP

## 简介

Whitelist HTML for WordPress. Adds esc_*()-like function to allow some HTML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
