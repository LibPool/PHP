# oxblue/oauth2-plangrid

> 标签: Authentication, authorization, client, oauth, oauth2, plangrid

## 简介

An OAuth2 wrapper to authenticate with Plangrid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
