# yusu/unioncloud-api-php

> 标签: PHP

## 简介

A wrapper to allow integration with the APIs of the UnionCloud platform operated by NUS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
