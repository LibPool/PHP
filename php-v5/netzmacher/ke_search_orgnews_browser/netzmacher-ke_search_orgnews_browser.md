# netzmacher/ke_search_orgnews_browser

> 标签: PHP

## 简介

Faceted Search Indexer for the Organiser table news. Page for the detail view must have a Browser plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
