# yii2mod/yii2-data-sync-behavior

> 标签: yii2, yii2 export

## 简介

Behavior for export data to local files from database tables. Changes are tracked using model events.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
