# alibayat/laravel-logviewer

> 标签: Laravel Log Viewer, laravel, log viewer, logs

## 简介

Showing Laravel log files in a web page using dataTables

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
