# coldwinds/glutorrent

> 标签: bencode, bittorrent, glutorrent, torrent

## 简介

The BEncoded BitTorrent class developed by GluTorrent.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
