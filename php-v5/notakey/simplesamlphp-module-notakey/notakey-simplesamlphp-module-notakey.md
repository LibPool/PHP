# notakey/simplesamlphp-module-notakey

> 标签: 2fa, notakey

## 简介

A SimpleSAMLphp module adding support for Notakey multi factor authentication with free mobile app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
