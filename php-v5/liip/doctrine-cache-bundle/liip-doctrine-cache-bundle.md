# liip/doctrine-cache-bundle

> 标签: Symfony2, cache

## 简介

This Bundle provides integration into Symfony2 with the Doctrine Common Cache layer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
