# wegmeister/databasestorage

> 标签: PHP

## 简介

This package adds the ability to store inputs of a form (or other input) into database and export the stored data as xlsx.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
