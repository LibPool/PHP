# dynamic/silverstripe-foxy-inventory

> 标签: cms, silverstripe

## 简介

A simple inventory add-on for SilverStripe Foxy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
