# dynamic/silverstripe-link-migrator

> 标签: link, linkable, migrate, silverstripe

## 简介

Migrate Linkable Link records to SilverStripe Link

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
