# dynamic/silverstripe-foxy-feed-parser

> 标签: cms, silverstripe

## 简介

An add-on module to parse the Foxy.io datafeed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
