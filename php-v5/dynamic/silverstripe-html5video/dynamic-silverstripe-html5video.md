# dynamic/silverstripe-html5video

> 标签: HTML5, dynamic, silverstripe, video

## 简介

HTML5Video is a SilverStripe module to add HTML5 Video to your website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
