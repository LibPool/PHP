# dynamic/silverstripe-foxy

> 标签: cms, ecommerce, foxy, shop, silverstripe

## 简介

Foxy.io integration for SilverStripe websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
