# dynamic/silverstripe-blocks-to-elemental-migrator

> 标签: blocks, elemental, silverstripe

## 简介

Migrate data from SilverStripe Blocks to SilverStripe Elemental

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
