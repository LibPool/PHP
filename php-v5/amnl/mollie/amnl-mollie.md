# amnl/mollie

> 标签: api, client, ideal, minitix, mollie, payment, paysafecard, webservice

## 简介

PHP 5.3 library to communicate with Mollie (PSP).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
