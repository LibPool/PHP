# indieweb/wordpress-micropub

> 标签: PHP

## 简介

A Micropub Endpoint for WordPress http://wordpress.org/plugins/micropub/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
