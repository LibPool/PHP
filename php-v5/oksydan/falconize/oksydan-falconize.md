# oksydan/falconize

> 标签: PHP

## 简介

Falconize is a simple tool designed to help you create a database structure and register hooks in PrestaShop modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
