# matthiasnoback/php-coding-standard

> 标签: Coding Standard, code sniffer

## 简介

PHP_CodeSniffer coding standard based on PSR-1 and PSR-2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
