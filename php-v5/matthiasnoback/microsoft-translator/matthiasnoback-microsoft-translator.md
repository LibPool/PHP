# matthiasnoback/microsoft-translator

> 标签: Microsoft Translator, bing, translate

## 简介

Library for making calls to the Microsoft Translator V2 API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
