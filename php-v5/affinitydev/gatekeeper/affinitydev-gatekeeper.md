# affinitydev/gatekeeper

> 标签: authorization, php, rbac, security, user

## 简介

Decoupled, interface-based, and standalone resource authorization component for PHP 5.4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
