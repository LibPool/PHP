# typo3-documentation-team/speeddemo

> 标签: TYPO3 CMS

## 简介

Demonstrate how fast a PHP class can be loaded into TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
