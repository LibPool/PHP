# wilkques/ssh

> 标签: PHP

## 简介

SSH local port-forward tunneling, remote command execution, and SFTP/SCP file transfer for PHP — speaks the SFTP protocol directly over an ssh subprocess, no protocol library dependency

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
