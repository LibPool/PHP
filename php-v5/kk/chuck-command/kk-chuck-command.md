# kk/chuck-command

> 标签: chuck, command, console, norris

## 简介

Simple Symfony2 Bundle displaying a random Chuck Norris fact for every console command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
