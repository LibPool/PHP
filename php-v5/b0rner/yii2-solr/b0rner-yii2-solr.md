# b0rner/yii2-solr

> 标签: Yii2 Extension, b0rner, extension, php8, solarium, solr, yii2, yii2-extension

## 简介

Solr plugin for the Yii2 framework built on top of Solarium 6 and PHP 8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
