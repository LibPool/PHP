# weltongbi/mikrotik-api

> 标签: api, mikrotik, routeros

## 简介

Mikrotik API PHP Library for working with RouterOS API 2018

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
