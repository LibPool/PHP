# thomasgreen/amp-toolbox

> 标签: PHP

## 简介

A collection of AMP tools making it easier to publish and host AMP pages with PHP 5.5.9.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
