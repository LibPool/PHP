# laravelbook/laravel4-powerpack

> 标签: form, framework, html, laravel, string, support

## 简介

Port of Laravel 3's HTML, Form and Str classes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
