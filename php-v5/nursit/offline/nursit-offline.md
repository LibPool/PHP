# nursit/offline

> 标签: JS, offline, serviceworkers

## 简介

SPIP Plugin for adding offline mode feature to websites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://git.nursit.net/open/offline
- Packagist 页面：https://packagist.org/packages/nursit%2Foffline
