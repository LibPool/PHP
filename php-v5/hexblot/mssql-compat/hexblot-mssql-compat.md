# hexblot/mssql-compat

> 标签: PHP

## 简介

Small wrapper for PDO that emulates the deprecated mssql_* functions, and allows legacy software to work on PHP 5.3 through 8.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
