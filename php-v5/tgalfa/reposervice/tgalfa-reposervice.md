# tgalfa/reposervice

> 标签: cli, generator, laravel, php, repository, service

## 简介

Generate repository, service and interface files for Repository-Service Pattern.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
