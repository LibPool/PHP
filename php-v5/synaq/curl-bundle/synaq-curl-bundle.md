# synaq/curl-bundle

> 标签: Symfony2, api, curl

## 简介

A Symfony2 wrapper for Curl

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/synaq/SynaqCurlBundle
- 源码仓库：https://github.com/synaq/SynaqCurlBundle.git
- Packagist 页面：https://packagist.org/packages/synaq%2Fcurl-bundle

## 获取地址

- Composer 安装：`composer require synaq/curl-bundle`
- Packagist 仓库：https://repo.packagist.org/p2/synaq/curl-bundle.json
- PHP 要求：>=5.5
