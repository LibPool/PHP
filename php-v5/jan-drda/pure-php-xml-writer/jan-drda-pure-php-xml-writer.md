# jan-drda/pure-php-xml-writer

> 标签: pure php, xml, xml writer

## 简介

Simple XML writer library written with basic PHP functions only.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
