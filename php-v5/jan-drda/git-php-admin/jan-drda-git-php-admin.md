# jan-drda/git-php-admin

> 标签: admin, administration, bootstrap, git, html, php, version

## 简介

Simple HTML UI written in PHP for executing GIT commands from web page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
