# madeweb/eloquent-api

> 标签: api, eloquent, microservices

## 简介

An Eloquent model with support for API, is a wrapper for use endpoints how to model entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
