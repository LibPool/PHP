# sjbr/static-info-tables

> 标签: Static Info Tables, typo3

## 简介

Data and API for countries, languages and currencies for use in TYPO3 CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
