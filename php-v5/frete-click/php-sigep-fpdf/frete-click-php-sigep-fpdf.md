# frete-click/php-sigep-fpdf

> 标签: PHP

## 简介

Unofficial FPDF library - Cópia do FPDF 1.7 usado pelo projeto stavarengo/php-sigep.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
