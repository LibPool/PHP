# crada/phalcon-user-plugin

> 标签: facebook, google-plus, linkedin, login, phalcon, twitter, user

## 简介

User plugin for Phalcon PHP framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
