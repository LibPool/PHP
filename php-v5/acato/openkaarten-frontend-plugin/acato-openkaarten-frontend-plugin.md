# acato/openkaarten-frontend-plugin

> 标签: PHP

## 简介

Adds OpenKaarten Blocks with an Openstreetmap block to the Gutenberg editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
