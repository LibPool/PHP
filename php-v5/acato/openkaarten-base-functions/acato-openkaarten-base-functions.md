# acato/openkaarten-base-functions

> 标签: PHP

## 简介

Adds global functions for OpenKaarten Base and OpenKaarten add-on plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
