# joe1992w/laravel-media-embed

> 标签: laravel, package development

## 简介

Laravel Wrapper for dereuromark/MediaEmbed to generate embed HTML for popular media hosts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
