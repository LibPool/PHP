# ucs/search

> 标签: Symfony2, UCS, form, search

## 简介

UCS Search Bundle Pattern, easy integrate search forms in your backoffice application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
