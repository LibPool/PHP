# ucs/adminstrap-bundle

> 标签: adminstrap, backend, backoffice, bootstrap, bootstrap form, extra form, form, template

## 简介

Easy integration of UCS adminstrap into symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
