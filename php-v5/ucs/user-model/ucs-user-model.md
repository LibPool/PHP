# ucs/user-model

> 标签: FOSUserBundle, Symfony2, UCS, User management

## 简介

BackOffice User integration for your Rich Web Applications in Symfony2 UCS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
