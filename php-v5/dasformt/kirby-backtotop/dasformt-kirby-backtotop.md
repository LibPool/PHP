# dasformt/kirby-backtotop

> 标签: PHP

## 简介

Ein konfigurierbarer 'Zurück nach oben' Button für Kirby CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
