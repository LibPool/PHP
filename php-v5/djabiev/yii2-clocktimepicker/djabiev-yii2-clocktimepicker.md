# djabiev/yii2-clocktimepicker

> 标签: clockpicker, timepicker, yii2

## 简介

Yii2 wrapper for clockpicker (clock-like time picker) plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
