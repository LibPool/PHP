# code-x/xtest

> 标签: ci, development, extension, magento, module, test

## 简介

Simple Magento Testing Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/code-x/magento-xtest.git
- Packagist 页面：https://packagist.org/packages/code-x%2Fxtest
