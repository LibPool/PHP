# davidyell/sortable

> 标签: PHP

## 简介

A small component to implement sortable tables with id's in a Cake view. This allows you to easily attach sorting to any table.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
