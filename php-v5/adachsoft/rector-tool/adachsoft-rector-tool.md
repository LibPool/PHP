# adachsoft/rector-tool

> 标签: ai, code-quality, php, rector, refactoring, tool

## 简介

AI tool wrapper for running Rector (analyze/fix) via adachsoft/rector-wrapper-lib.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
