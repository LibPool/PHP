# akai/magento2-module-admin-theme-switcher

> 标签: PHP

## 简介

A module that adds an option to switch between admin themes to Magento 2 admin panel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
