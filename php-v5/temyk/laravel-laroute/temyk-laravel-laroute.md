# temyk/laravel-laroute

> 标签: javascript, laravel, routes, routing

## 简介

Access Laravels 11 URL/Route helper functions, from JavaScript.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
