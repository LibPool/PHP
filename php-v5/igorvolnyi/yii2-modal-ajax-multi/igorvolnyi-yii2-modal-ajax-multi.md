# igorvolnyi/yii2-modal-ajax-multi

> 标签: ajax-modal, bootstrap, modal, multiple, nested, stacked, yii2

## 简介

Widget for Yii2 framework. Create referenced data in stacked modal dialogs using AJAX.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
