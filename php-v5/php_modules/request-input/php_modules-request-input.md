# php_modules/request-input

> 标签: body-parser, http, http-body, http-request-body, http-request-body-parser, http-request-input, http-request-input-parser, input, input-parser, request-body-parser, request-input-parser

## 简介

HTTP Request input/body parser for php rest API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
