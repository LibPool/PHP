# pnikolov/spin.js

> 标签: CSS3, animation, spinner

## 简介

Wrapper of spin.js component. An animated CSS3 loading spinner with VML fallback for IE.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
