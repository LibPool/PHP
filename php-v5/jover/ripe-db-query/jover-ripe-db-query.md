# jover/ripe-db-query

> 标签: PHP

## 简介

Simple wrapper for Ripe DB RESTlike search queries, it returns a SimpleXMLElement

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
