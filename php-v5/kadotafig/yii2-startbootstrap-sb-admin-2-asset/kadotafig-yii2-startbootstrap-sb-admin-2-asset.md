# kadotafig/yii2-startbootstrap-sb-admin-2-asset

> 标签: extension, yii2

## 简介

This extensions is library for Startbootstrap SB Admin 2 Template with Bootstrap4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
