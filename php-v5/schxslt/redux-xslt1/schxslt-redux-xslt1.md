# schxslt/redux-xslt1

> 标签: schematron, validation, xml

## 简介

An implementation of an XSLT 1.0 ISO Schematron processor for the XSLT 1.0 query language binding

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
