# efureev/yii2-recover-innodb-table

> 标签: InnoDB, db, recover, yii2

## 简介

Yii2 component for recovering an innodb table from only an *.ibd file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
