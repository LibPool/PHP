# picoauth/picoauth

> 标签: Authentication, SSO, Users, authorization, flat-file, oauth2, pico, picocms, plugin

## 简介

PicoAuth provides authentication and authorization for flat file CMS Pico.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
