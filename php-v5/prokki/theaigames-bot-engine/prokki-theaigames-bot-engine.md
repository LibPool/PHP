# prokki/theaigames-bot-engine

> 标签: Challenge, ai, conquest, theaigames

## 简介

A bot engine to create bots for various games on http://theaigames.com/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
