# unloq/unloq-php-sdk

> 标签: 2fa, Authentication, Multi Factor Authentication, Two Factor Authentication, UNLOQ Two Factor Authentication, php 2fa, unloq

## 简介

UNLOQ PHP SDK provides methods for all of UNLOQ API functionalities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
