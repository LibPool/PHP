# solvebeam/wp-text-domain-replacer

> 标签: PHP

## 简介

A developer tool for replacing WordPress translation text domains in PHP, JavaScript, and `block.json` files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
