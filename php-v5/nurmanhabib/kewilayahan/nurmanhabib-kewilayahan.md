# nurmanhabib/kewilayahan

> 标签: PHP

## 简介

API Data Wilayah Provinsi, Kota/Kab, Kecamatan, Kel/Desa di Indonesia dengan data dari BPS Tahun 2013.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
