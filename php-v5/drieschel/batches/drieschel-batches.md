# drieschel/batches

> 标签: batch jobs, batches, scheduling

## 简介

lightweight php lib for creating batch jobs and integrating them easily in php applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
