# rasalas/easycrypt

> 标签: PHP

## 简介

turns array data or strings in url safe(optional) signed crypt strings and can decrypt them again and make sure it's the same data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
