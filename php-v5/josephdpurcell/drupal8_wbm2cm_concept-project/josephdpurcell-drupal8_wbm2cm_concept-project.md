# josephdpurcell/drupal8_wbm2cm_concept-project

> 标签: PHP

## 简介

Easily create a Drupal 8 to show Workbench Moderation to Content Moderation migration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
