# freefair/rest-bundle

> 标签: controller, delete, get, http, json, post, put, rest

## 简介

This Bundle proviedes functionality for rest services in symfony3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
