# donquixote/d7-cfr-recommended

> 标签: PHP

## 简介

Helper package to download the Drupal cfr module with dependencies, without composer_manager.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
