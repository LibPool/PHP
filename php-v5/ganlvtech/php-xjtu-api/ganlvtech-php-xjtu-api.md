# ganlvtech/php-xjtu-api

> 标签: api, xjtu

## 简介

API for Xi'an Jiao Tong University's commonly used online service by simulating operation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
