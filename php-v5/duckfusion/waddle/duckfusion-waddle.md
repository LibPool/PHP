# duckfusion/waddle

> 标签: gps, gpx, parse, pwx, running, tcx

## 简介

PHP Library for parsing running GPS activities and calculating metrics

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
