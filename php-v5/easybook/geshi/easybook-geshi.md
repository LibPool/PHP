# easybook/geshi

> 标签: highlight, highlighter, syntax

## 简介

GeSHi - Generic Syntax Highlighter. This is an unmodified port of GeSHi project code found on SourceForge.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
