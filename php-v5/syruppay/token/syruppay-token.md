# syruppay/token

> 标签: SyrupPay, syrup, syruppay-token

## 简介

This is used to encrypt SyrupPay payment and issue AccessToken. It makes for purpose of deploying to SyrupPay merchants.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
