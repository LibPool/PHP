# i-lateral/silverstripe-systemmessages

> 标签: messages, notifications, silverstripe

## 简介

Add popup notification messages to a Silverstripe site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
