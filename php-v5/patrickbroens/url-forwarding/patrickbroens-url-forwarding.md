# patrickbroens/url-forwarding

> 标签: redirect, shortcut, typo3

## 简介

Redirects (301, 302, 303, 307) to internal/external page or file, based on domain and path

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
