# perryfaro/sepa

> 标签: Banking, SCT, sepa, xml

## 简介

Creates an XML file for a Single Euro Payments Area (SEPA) Credit Transfer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
