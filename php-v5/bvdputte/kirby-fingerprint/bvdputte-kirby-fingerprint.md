# bvdputte/kirby-fingerprint

> 标签: Fingerprint, cache-bust, hash, kirby3, kirby3-plugin

## 简介

Cache-busting utility to fingerprint assets (JS/CSS) in Kirby 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
