# quangvule/spamassassin

> 标签: spamassassin, spamd

## 简介

Spamd protocol client for PHP. PHP package that implements the spamd protocol specification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
