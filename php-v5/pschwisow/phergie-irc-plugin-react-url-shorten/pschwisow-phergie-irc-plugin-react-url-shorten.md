# pschwisow/phergie-irc-plugin-react-url-shorten

> 标签: bot, irc, phergie, plugin

## 简介

Phergie plugin to provide URL shortening services for Url plugin (and others)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
