# rioastamal/porsi-haji-checker

> 标签: PHP

## 简介

Sebuah pustaka untuk mendapatkan informasi keberangkatan haji berdasarkan nomor porsi

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
