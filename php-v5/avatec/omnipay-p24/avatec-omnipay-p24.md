# avatec/omnipay-p24

> 标签: Przelewy24, gateway, merchant, omnipay, pay, payment, transfer

## 简介

Przelewy24 driver for the Omnipay payment processing library. Forked from ticketswap/omnipay-przelewy24

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
