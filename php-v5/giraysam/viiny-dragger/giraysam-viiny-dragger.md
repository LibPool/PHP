# giraysam/viiny-dragger

> 标签: drag and drop, javascript, viiny

## 简介

viiny-dragger is a drag and drop plugin for javascript

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
