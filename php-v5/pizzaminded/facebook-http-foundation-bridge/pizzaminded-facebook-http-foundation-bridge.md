# pizzaminded/facebook-http-foundation-bridge

> 标签: PHP

## 简介

Integrates facebook/php-graph-sdk with symfony/http-foundation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
