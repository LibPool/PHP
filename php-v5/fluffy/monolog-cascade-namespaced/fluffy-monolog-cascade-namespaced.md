# fluffy/monolog-cascade-namespaced

> 标签: log, log4j, logger, monolog, monolog utils, monolog-cascade extension, monolog-cascade plugin, namespace, namespaced logger

## 简介

Monolog cascade extension allows to configure loggers for a specific namespace/class (log4j style)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
