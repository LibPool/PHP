# flagrow/flarum-ext-latex

> 标签: expressions, flagrow, flarum, latex, math, tex

## 简介

Renders LaTeX expressions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
