# urands/firephp

> 标签: firefox, firephp, log, logging

## 简介

Log variables to the Firefox 51+ console (alternate solution for FirePHP via Chrome Logger protocol).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
