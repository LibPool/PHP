# ronisaha/easy-bangla-date

> 标签: Bangla, Bangla Date, Bangla DateTime

## 简介

Extended DateTime Class For Bangla Date and Time

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
