# gzero/eloquent-tree

> 标签: eloquent, laravel

## 简介

Eloquent Tree is a tree model for Laravel Eloquent ORM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
