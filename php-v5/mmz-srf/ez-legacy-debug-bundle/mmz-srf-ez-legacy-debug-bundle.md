# mmz-srf/ez-legacy-debug-bundle

> 标签: SRF, bundle, debug, symfony

## 简介

Symfony bundle 'SRFEzLegacyDebugBundle' show EzLegacy debug informations in the Web-Profiler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
