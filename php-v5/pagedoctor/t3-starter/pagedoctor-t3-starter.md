# pagedoctor/t3-starter

> 标签: Pagedoctor, Provider Extension, TYPO3 CMS, content elements

## 简介

Provider extension to start TYPO3 projects with Pagedoctor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
