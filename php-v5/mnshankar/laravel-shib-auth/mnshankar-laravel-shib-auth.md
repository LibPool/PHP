# mnshankar/laravel-shib-auth

> 标签: PHP

## 简介

Convert Shibboleth tokens to equivalent Laravel User Table columns so Laravel auth semantics can be used

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
