# atoum/stubs

> 标签: TDD, atoum, test, unit testing

## 简介

Stubs for atoum, the simple modern and intuitive unit testing framework for PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
