# atoum/phpunit-extension

> 标签: TDD, atoum, atoum-extension, phpunit, test, unit testing

## 简介

atoum PHPUnit extension - Run your PHPUnit tests with atoum

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
