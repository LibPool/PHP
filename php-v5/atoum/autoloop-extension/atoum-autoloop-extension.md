# atoum/autoloop-extension

> 标签: TDD, atoum, atoum-extension, test, unit testing

## 简介

Automaticly run atoum's loop mode on file change

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
