# atoum/deprecated-extension

> 标签: TDD, atoum, deprecated, test, unit testing

## 简介

atoum extension to avoid failures on deprecated errors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
