# ripaclub/zf2-hanger-snippet

> 标签: JS, Zend Framework, append, appender, facebook, google analytics, google no recaptcha, google recaptcha 2.0, hanger, javascript, snippet, snippets, universal analytics, zf2

## 简介

A module to attach HTML/JS snippets into a ZF2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
