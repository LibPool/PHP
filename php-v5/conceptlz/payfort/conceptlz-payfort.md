# conceptlz/payfort

> 标签: credit card, laravel, online payments, payfort, payment gateway, payment gateway in uae, payments, php, uae payment gateway

## 简介

A PHP library to work with the Payfort payment gateway API. This library will support the Merchant Page 2.0 and the Payfort Services API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
