# municipes/fundamentum

> 标签: PHP

## 简介

Fundāmentum è un modulo drupal che gestisce i field storage dell'entity Node necessari all'implementazione dell'architettura dei contenuti dei comuni.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
