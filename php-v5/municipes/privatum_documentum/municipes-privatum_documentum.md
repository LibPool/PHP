# municipes/privatum_documentum

> 标签: PHP

## 简介

Privatum Documentum è un modulo Drupal che gestisce il tipo di contenuto Documento privato.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
