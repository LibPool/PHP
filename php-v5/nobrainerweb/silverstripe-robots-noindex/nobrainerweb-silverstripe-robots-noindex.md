# nobrainerweb/silverstripe-robots-noindex

> 标签: index, noindex, robots, silverstripe, warning

## 简介

Show a warning in the CMS when site is set to noindex

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
