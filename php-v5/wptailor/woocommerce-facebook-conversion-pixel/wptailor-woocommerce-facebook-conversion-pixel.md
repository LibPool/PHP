# wptailor/woocommerce-facebook-conversion-pixel

> 标签: PHP

## 简介

Set up the Facebook conversion pixel and event tracking for WooCommerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
