# benf45/imagine

> 标签: drawing, graphics, image manipulation, image processing

## 简介

Image processing for PHP 5.3 - A fork of the original package with additional features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
