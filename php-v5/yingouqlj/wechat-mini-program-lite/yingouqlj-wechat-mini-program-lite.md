# yingouqlj/wechat-mini-program-lite

> 标签: miniprogram, wechat, weixin, weixin-sdk

## 简介

微信小程序sdk,wechat miniprogram sdk.(前面堆一下关键字而已.这个包主要是只有微信小程序,轻巧无负担,无需安装各种依赖包.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
