# cerpus/cerpusauthlib-core

> 标签: Cerpus JWT support library, laravel, lumen

## 简介

Library for core functionality with regards to authentication and profile data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
