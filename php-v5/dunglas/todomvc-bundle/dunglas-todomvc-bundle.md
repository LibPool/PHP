# dunglas/todomvc-bundle

> 标签: backbone.js, chaplin.js, todoMVC

## 简介

This Bundle is a Symfony2 / Backbone.js / Chaplin.js implementation of TodoMVC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
