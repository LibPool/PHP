# pleade/drupal-pleade

> 标签: PHP

## 简介

Module personnalisé pour intégrer l'application 'Pleade'. Pour plus d'informations, aller sur http://pleade.com.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
