# vsc55/mac-address

> 标签: DHCP, IP, MAC, address, ifconfig, linux, unix

## 简介

Get, validate and generate MAC addresses. (Fork BlakeGardner/php-mac-address)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
