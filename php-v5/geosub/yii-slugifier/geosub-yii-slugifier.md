# geosub/yii-slugifier

> 标签: slug, transliterate, transliterator, url, yii

## 简介

Yii Extension to translate unsave string to save for url and filename

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
