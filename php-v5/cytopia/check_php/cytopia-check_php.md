# cytopia/check_php

> 标签: icinga, icinga2, nagios, nagios-plugin, php, php-error

## 简介

Nagios or Icinga plugin to check for php startup errors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
