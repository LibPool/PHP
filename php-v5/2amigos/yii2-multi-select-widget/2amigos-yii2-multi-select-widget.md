# 2amigos/yii2-multi-select-widget

> 标签: extension, multiselect, widget, yii

## 简介

Multiselect Bootstrap widget for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
