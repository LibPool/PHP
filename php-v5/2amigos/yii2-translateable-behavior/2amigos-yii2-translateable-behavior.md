# 2amigos/yii2-translateable-behavior

> 标签: Behavior, extension, translation, yii

## 简介

ActiveRecord attributes translations for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
