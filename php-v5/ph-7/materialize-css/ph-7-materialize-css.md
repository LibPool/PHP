# ph-7/materialize-css

> 标签: css, materialize, materialize composer, materialize packagist, php materialize

## 简介

Builds Materialize distribution packages for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
