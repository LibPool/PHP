# iionly/userpoints_group_widget

> 标签: elgg, plugin

## 简介

Adds an (optional) widget to groups profile pages listing group members with most userpoints.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
