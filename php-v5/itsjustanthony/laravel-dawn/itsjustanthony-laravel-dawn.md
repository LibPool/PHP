# itsjustanthony/laravel-dawn

> 标签: dusk, laravel, testing, webdriver

## 简介

Extends the Laravel Dusk command to enable server defined $APP_ENV variable

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
