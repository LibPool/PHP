# jenssegers/mongodb-lite

> 标签: database, eloquent, laravel, model, mongo, mongodb

## 简介

A lightweight MongoDB database library and model for Laravel 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
