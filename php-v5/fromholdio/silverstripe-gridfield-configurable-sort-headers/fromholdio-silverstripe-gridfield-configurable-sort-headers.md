# fromholdio/silverstripe-gridfield-configurable-sort-headers

> 标签: silverstripe

## 简介

Allows excluding named column headers from being sortable

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
