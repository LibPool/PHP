# fromholdio/silverstripe-cmsmessagefield

> 标签: silverstripe

## 简介

Very simple form field wrapping literal field to add message into CMS UI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
