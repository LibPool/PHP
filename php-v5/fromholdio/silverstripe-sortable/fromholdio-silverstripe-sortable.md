# fromholdio/silverstripe-sortable

> 标签: dataobject, orderable, silverstripe, sort, sortable

## 简介

Adds an extension to make any SilverStripe DataObject sortable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
