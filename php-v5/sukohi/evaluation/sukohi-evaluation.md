# sukohi/evaluation

> 标签: PHP

## 简介

A Laravel package to manage evaluation data like LIKE, DISLIKE, FAVORITE and REMEMBER.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
