# kodefarmers/nrb-forex

> 标签: PHP

## 简介

Laravel Package to consume Nepal Rastra Bank's foreign exchange rate API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
