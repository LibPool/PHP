# fluency/yaml-config-service-provider

> 标签: micro-framework, php, silex, yaml

## 简介

Bootstrap Silex MicroFramework using Symfony2 like yaml config files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
