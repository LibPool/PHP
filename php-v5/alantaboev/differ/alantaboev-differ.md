# alantaboev/differ

> 标签: PHP

## 简介

Вычислитель отличий – программа, определяющая разницу между двумя структурами данных в формате yaml или json. Отчет генерируется в виде plain text, stylish и json

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
