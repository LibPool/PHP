# sarahman/sendgrid-plugin-for-october-cms

> 标签: admin, cms, email, october, sendgrid

## 简介

SendGrid plugin of sending email in OctoberCMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
