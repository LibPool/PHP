# ciricihq/cake-sitemap

> 标签: Sitemap, cakephp

## 简介

A CakePHP Plugin for adding automatic XML and HTML Sitemaps to an app

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
