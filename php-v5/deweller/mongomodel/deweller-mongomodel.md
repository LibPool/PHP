# deweller/mongomodel

> 标签: model, mongo, mongodb, orm

## 简介

A simple, lightweight and useful framework for mapping MongoDB documents and PHP models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
