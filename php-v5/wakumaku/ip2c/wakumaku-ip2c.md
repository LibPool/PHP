# wakumaku/ip2c

> 标签: IP, country, dns, ip to country, ip2c, maxmind, whois

## 简介

Small and simple library to resolve the country where an Ip comes from.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
