# zhusg/thinkphp51-addons

> 标签: PHP

## 简介

addons package for thinkphp5.1 on fastadmin-addons

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/hellowzsg/thinkphp51-addons.git
- 源码仓库：https://github.com/hellowzsg/fastadmin-addons-thinkphp51.git
- Packagist 页面：https://packagist.org/packages/zhusg%2Fthinkphp51-addons

## 获取地址

- Composer 安装：`composer require zhusg/thinkphp51-addons`
- Packagist 仓库：https://repo.packagist.org/p2/zhusg/thinkphp51-addons.json
- 许可证：Apache-2.0
