# ampeco/omnipay-rapyd

> 标签: PHP

## 简介

Omnipay plugin for https://docs.rapyd.net/build-with-rapyd

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
