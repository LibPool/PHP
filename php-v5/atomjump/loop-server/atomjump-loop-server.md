# atomjump/loop-server

> 标签: im, instant messaging, messaging, messaging server

## 简介

A server to the open messaging client AtomJump Loop https://atomjump.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
