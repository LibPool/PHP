# neconix/yii2-oci8

> 标签: database, oci8, oracle, yii2

## 简介

Yii2 extension which uses well written pdo-via-oci8 package for standard PHP Oracle functions (OCI8)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
