# igorescobar/jquery-mask-plugin

> 标签: jquery, mask, plugin

## 简介

A jQuery Plugin to make masks on form fields and html elements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
