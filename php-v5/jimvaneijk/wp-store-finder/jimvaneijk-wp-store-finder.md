# jimvaneijk/wp-store-finder

> 标签: PHP

## 简介

This plugin gives you the opportunity to add store to a map so customers can explore where you are located.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
