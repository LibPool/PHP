# laraditz/user-security

> 标签: 2fa, laravel, mnemonic, pin, security, user

## 简介

Add security pin, mnemonic key and 2fa authentication feature to users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
