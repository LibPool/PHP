# xprt64/injectable-router-middleware

> 标签: PHP

## 简介

Zend Framework middle-ware that, using reflection, detects and injects the parameters in the invoke method

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
