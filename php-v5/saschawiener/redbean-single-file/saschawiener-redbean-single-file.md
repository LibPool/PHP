# saschawiener/redbean-single-file

> 标签: CUBRID, InnoDB, mariadb, mysql, postgresql, sqlite3

## 简介

RedBeanPHP is an easy-to-use, on-the-fly ORM for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
