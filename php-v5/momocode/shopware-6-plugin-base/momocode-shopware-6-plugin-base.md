# momocode/shopware-6-plugin-base

> 标签: PHP

## 简介

Base library that can be loaded as a composer dependency inside of Shopware 6 plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
