# upwebdesign/spark

> 标签: billing, laravel, scaffolding, stripe

## 简介

Laravel Spark provides a starter scaffolding for Laravel SaaS applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
