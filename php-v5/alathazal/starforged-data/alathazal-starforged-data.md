# alathazal/starforged-data

> 标签: PHP

## 简介

A fan-made composer package providing base game data for the Ironsworn: Stargforged tabletop roleplaying game.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
