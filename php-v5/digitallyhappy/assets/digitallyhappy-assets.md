# digitallyhappy/assets

> 标签: Load CSS once, Load JS once, assets, laravel

## 简介

Dead-simple way to load CSS or JS assets only once per page, when using Laravel 8+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
