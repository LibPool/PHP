# lefuturiste/slim3_multilanguage

> 标签: middleware, multilanguage, slim3

## 简介

Multilanguage middleware class for slim framework 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
