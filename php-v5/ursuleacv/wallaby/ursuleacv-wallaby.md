# ursuleacv/wallaby

> 标签: Simple, micro, mvc, php, wallaby

## 简介

A simple lightweight framework for building small apps in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
