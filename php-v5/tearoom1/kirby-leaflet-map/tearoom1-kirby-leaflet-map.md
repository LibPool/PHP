# tearoom1/kirby-leaflet-map

> 标签: block, interactive, kirby, leaflet, map, panel

## 简介

Kirby plugin that adds an interactive map block using Leaflet.js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
