# expstudio/friendly-url

> 标签: eloquent, laravel, slug

## 简介

Easy creation of slugs for your Eloquent models in Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
