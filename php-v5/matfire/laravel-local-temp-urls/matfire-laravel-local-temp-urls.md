# matfire/laravel-local-temp-urls

> 标签: PHP

## 简介

A Laravel 11 compatible way to create a temporary url for files stored using the 'local' driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
