# mrad/notifications-bundle

> 标签: notificaiton bundle, pusher, symfony notifications

## 简介

Implement notifications system in your symfony project using Pusher API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
