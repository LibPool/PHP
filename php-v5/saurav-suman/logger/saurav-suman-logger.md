# saurav-suman/logger

> 标签: alerts, apilog, debug, debugging, error, log, logger, logging, rabbitmq, syslog

## 简介

PHP client to publish realtime logs to rabbitmq

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
