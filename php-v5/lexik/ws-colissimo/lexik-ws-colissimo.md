# lexik/ws-colissimo

> 标签: coliposteletterservice, colissimo, webservice

## 简介

A library for consuming the SOAP WSColiPosteLetterService

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
