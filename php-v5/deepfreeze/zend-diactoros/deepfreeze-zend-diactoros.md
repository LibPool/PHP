# deepfreeze/zend-diactoros

> 标签: http, psr, psr-7

## 简介

Zend Diactoros for PHP 5.3.8-5.3.x. See zendframework/zend-diactoros for PHP 5.4+ support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
