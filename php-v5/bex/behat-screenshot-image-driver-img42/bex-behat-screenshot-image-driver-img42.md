# bex/behat-screenshot-image-driver-img42

> 标签: BDD, Behat, TDD, behat-screenshot

## 简介

img42.com image driver for bex/behat-screenshot behat extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
