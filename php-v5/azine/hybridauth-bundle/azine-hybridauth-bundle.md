# azine/hybridauth-bundle

> 标签: oauth, xing, xing api

## 简介

Symfony2 bundle to access the profiles via Xing- and Linkedin-API, uses HybridAuth

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
