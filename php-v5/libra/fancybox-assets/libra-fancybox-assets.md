# libra/fancybox-assets

> 标签: ZendFramework, cms, fancybox, libra, zf, zf2

## 简介

Default fancyBox assets for ZF2 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
