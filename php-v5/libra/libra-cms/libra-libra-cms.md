# libra/libra-cms

> 标签: Zend Framework, cms, zf, zf2

## 简介

ZF2 based CMS that allows easily create your own web-site with necessary tools like article menagment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
