# phpfastcgi/silex-adapter

> 标签: daemon, fast cgi, fastcgi, server, silex

## 简介

An adapter to integrate PHPFastCGI with the Silex micro-framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
