# honl/magento2-nl-nl

> 标签: PHP

## 简介

Reach Digital Magento 2 Dutch Translations / Nederlandse Vertalingen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
