# waldson/twig-module-for-kohana

> 标签: kohana, templating, twig

## 简介

TWIG module for Kohana 3.3 to use twig templates as Kohana views seamlessly

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
