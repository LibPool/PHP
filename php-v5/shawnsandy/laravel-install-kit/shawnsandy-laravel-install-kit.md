# shawnsandy/laravel-install-kit

> 标签: laravel-install-kit, shawnsandy

## 简介

A simple starter package for creating composer packages, based on php-league skelton

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
