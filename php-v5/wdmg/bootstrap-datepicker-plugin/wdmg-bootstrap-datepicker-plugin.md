# wdmg/bootstrap-datepicker-plugin

> 标签: bootstrap, datepicker, timepicker, twitter-bootstrap

## 简介

A date/time picker plugin for Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
