# wdmg/yii2-tagsinput

> 标签: bootstrap, extension, input, tags, wdmg, widget, yii, yii2

## 简介

Bootstrap3 tags input widget for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
