# wdmg/yii2-robots

> 标签: robots, robots.txt, wdmg, yii2, yii2-robots

## 简介

Module for automatically generating and edit the robots.txt file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
