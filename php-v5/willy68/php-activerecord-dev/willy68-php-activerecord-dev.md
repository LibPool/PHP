# willy68/php-activerecord-dev

> 标签: activerecord, orm

## 简介

php-activerecord is an open source ORM library based on the ActiveRecord pattern.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
