# novay/laravel-samarinda

> 标签: api, desa, kecamatan, kelurahan, laravel, samarinda

## 简介

Package Laravel yang berisi data Kecamatan, dan Keluarahan/Desa di Samarinda.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
