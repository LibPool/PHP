# mblajek/mbn

> 标签: bignumber, decimal, math

## 简介

Library for PHP and JS to do calculations with any precision and correct (half-up) rounding.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
