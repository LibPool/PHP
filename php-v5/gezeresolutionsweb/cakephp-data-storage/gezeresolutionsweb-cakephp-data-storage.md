> 标签: Behavior, bootstrap, cakephp, data, file, framework, helpers, plugin, storable, twitter

## 简介

CakePHP Data Storage abstration plugin for CakePHP 2.x.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
