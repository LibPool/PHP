# fgonzales/xml-sign-wrapper

> 标签: security, signature, soap, xml, xmldsig

## 简介

Tool for easy management of XML Signatures (http://www.w3.org/TR/xmldsig-core/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
