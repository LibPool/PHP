# rtcamp/elementary

> 标签: PHP

## 简介

A starter theme that facilitates a quick head start for developing new block-based themes along with a bunch of developer-friendly features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
