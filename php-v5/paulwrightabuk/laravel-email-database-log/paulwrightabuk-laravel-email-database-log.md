# paulwrightabuk/laravel-email-database-log

> 标签: laravel, markdown

## 简介

A simple database logger for all outgoing emails sent by Laravel website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
