# jaybizzle/itunes-connect-ingest

> 标签: connect, data, downloads, ingest, itunes, sales

## 简介

A simple PHP library to get sales/download data from iTunes Connect

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
