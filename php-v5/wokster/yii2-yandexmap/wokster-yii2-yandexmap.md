# wokster/yii2-yandexmap

> 标签: extension, map, widget, yandex, yandexmap, yii2

## 简介

widgets to display yandex maps and get coordinates to input

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
