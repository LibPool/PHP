# inblank/yii2-sortable

> 标签: order, sort, sortable, yii2

## 简介

Extension for Yii2 to support sorting in ActiveRecord models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
