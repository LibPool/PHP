# inblank/yii2-seobility

> 标签: Behavior, html, seo, yii2

## 简介

Behavior for Yii 2 to support work with SEO data in ActiveRecord

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
