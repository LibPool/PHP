# hasmikk/dhl-shipping-api

> 标签: dhl, labels, php, shipment, shipping, soap

## 简介

DHL Business customer shipping API to request shipment and generate label

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
