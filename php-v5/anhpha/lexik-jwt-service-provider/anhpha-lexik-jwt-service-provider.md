# anhpha/lexik-jwt-service-provider

> 标签: PHP

## 简介

This is a provider for silex 2.0 using lexik jwt authentication provider class to create a encoder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
