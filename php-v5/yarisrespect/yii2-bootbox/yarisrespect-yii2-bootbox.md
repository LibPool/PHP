# yarisrespect/yii2-bootbox

> 标签: assets, bootbox, extension, yii2

## 简介

Overrides standard browser dialog window for Yii2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
