# ayesh/geo-ip-database

> 标签: PHP

## 简介

Weekly updated database of IP CIDR to Country codes, indexed by the first 1/4th of the IP address

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
