# webforge/testdata-repository

> 标签: data, testdata, unit test

## 简介

A repository for data that you can use to fill your unit tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://github.com/pscheit/webforge-testdata-repository
- 源码仓库：https://github.com/webforge-labs/webforge-testdata-repository.git
- Packagist 页面：https://packagist.org/packages/webforge%2Ftestdata-repository

- Composer 安装：`composer require webforge/testdata-repository`
