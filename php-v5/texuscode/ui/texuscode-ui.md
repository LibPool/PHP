# texuscode/ui

> 标签: PHP

## 简介

A set of modern UI designs and useful commands to speed up development. Easy to integrate, visually appealing, and efficient for any project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
