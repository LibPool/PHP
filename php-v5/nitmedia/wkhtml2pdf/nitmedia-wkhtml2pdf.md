# nitmedia/wkhtml2pdf

> 标签: illuminate, laravel, pdf, wkhtml2pdf, wkhtmltopdf

## 简介

Html 2 Pdf - using wkhtml2pdf, work on 32bit and 64 bit linux + MacOS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
