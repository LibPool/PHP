# chromeheadlessio/php-client

> 标签: pdf export service, php client

## 简介

An Open Source PHP client to use cloud export service chromeheadless.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://chromeheadless.io
- 源码仓库：https://github.com/chromeheadlessio/php-client.git
