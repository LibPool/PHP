# masilia/clamav-bundle

> 标签: PHP

## 简介

This bundle provides easy scanning virus with clamAv antivirus for Symfony and eZ Platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
