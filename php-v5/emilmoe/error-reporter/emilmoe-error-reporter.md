# emilmoe/error-reporter

> 标签: PHP

## 简介

Reports errors and exceptions for analysis. Works in background and does not interrupt Laravel error output.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
