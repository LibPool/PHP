# torzer/awesome-landlord

> 标签: multitenancy, multitenant, tenancy, tenant

## 简介

A simple, single database multi-tenancy solution for Laravel 5.2+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
