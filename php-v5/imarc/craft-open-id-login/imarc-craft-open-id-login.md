# imarc/craft-open-id-login

> 标签: Craft, cms, craft-plugin, craftcms, openid login

## 简介

Allows for CP login with Google's OpenID.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
