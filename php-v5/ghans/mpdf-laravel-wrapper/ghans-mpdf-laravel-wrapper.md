# ghans/mpdf-laravel-wrapper

> 标签: pdf, php, utf-8

## 简介

A PHP class to generate PDF files from HTML with Unicode/UTF-8 and CJK support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
