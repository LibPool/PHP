# comwrap/typo3-twig_for_typo3

> 标签: PHP

## 简介

A TYPO3 extension that integrates the Twig template engine into TYPO3 CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
