# ggggino/skuskucart-bundle

> 标签: bundle, cart, symfony, symfony3, symfony4

## 简介

This bundle aim to be a slim cart manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
