# epilgrim/php-hooks

> 标签: git, php-cs-fixer, pre-commit

## 简介

Adds php lint and php-cs-fixer to a git pre-commit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
