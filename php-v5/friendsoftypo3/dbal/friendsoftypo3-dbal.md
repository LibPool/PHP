# friendsoftypo3/dbal

> 标签: PHP

## 简介

A database abstraction layer implementation for TYPO3 4.6+ based on ADOdb and offering a lot of other features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
