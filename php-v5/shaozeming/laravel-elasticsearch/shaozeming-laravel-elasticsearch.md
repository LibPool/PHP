# shaozeming/laravel-elasticsearch

> 标签: elasticsearch, eloquent, laravel, lumen

## 简介

Maps Laravel and lumen Eloquent models to Elasticsearch types.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
