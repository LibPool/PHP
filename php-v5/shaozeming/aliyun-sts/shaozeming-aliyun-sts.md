# shaozeming/aliyun-sts

> 标签: PHP

## 简介

基于阿里云openapi系列接口中STS最新版本的SDK进行封装的composer package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
