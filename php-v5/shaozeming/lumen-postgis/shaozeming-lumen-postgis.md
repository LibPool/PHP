# shaozeming/lumen-postgis

> 标签: PHP

## 简介

Postgis extensions for laravel+lumen. Aims to make it easy to work with geometries from laravel models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
