# illuminatech/enum-seeder

> 标签: database, db, dictionary, enum, laravel, seed, seeder

## 简介

Allows easy creation of DB seeders for the dictionary (enum) type tables

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
