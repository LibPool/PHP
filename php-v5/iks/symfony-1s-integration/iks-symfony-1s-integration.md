# iks/symfony-1s-integration

> 标签: 1c, 1c-integration, 1c-php, 1c-symfony, 1s, 1s-integration, 1s-symfony, commerceml

## 简介

Orders exchanger between 1c and Symfony4 application via CommerceML protocol

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
