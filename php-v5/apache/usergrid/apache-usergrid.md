# apache/usergrid

> 标签: PHP

## 简介

Apache Usergrid PHP SDK guzzle web service client and service descriptor to interact with usergrid management and application api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
