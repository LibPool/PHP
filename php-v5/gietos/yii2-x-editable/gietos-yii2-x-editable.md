# gietos/yii2-x-editable

> 标签: extension, mcms, x-editable, yii2

## 简介

X-editable extensions for Yii 2, based in X-editable with Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
