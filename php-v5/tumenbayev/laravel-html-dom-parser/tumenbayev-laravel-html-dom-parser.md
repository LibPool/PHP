# tumenbayev/laravel-html-dom-parser

> 标签: dom parser, html dom parser, laravel

## 简介

Laravel wrapper for the PHP Simple HTML DOM Parser package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
