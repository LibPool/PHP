# robroypt/odoo-client

> 标签: odoo, rpc, xml, xmlrpc

## 简介

A PHP Client for Odoo using Ripcord RPC library (as used in Odoo Web API docs)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
