# oscargalileo/liga3

> 标签: FUSION, RUTA, html, liga, mysql

## 简介

Microframework que facilita el uso de la base de datos y genera código HTML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
