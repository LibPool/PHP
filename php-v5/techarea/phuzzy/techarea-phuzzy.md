# techarea/phuzzy

> 标签: fuzzy, phuzzy

## 简介

Phuzzy adalah sebuah library PHP untuk algoritma fuzzy

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
