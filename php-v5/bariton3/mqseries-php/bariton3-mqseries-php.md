# bariton3/mqseries-php

> 标签: PHP

## 简介

client to WebSphere MQ Queue Manager using the PHP mqseries pecl extension for Laravel framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
