# caponica/amazon-mws-bundle

> 标签: amazon, mws, symfony

## 简介

Symfony2 service wrapper for Amazon MWS PHP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
