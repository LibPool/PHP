# alhimik1986/yii2_crud_module

> 标签: crud, gii, module, yii2

## 简介

Excellent yii2 gii code generator for creating ajax applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
