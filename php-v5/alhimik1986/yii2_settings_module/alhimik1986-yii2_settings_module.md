# alhimik1986/yii2_settings_module

> 标签: Settings, module, yii2

## 简介

Module, allowing get and set your settings, and having access throw the web page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
