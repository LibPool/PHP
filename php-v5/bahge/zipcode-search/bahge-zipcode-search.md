# bahge/zipcode-search

> 标签: PHP

## 简介

Lib para tradução de cep para código de ibge, baseada nas informações dos correios: https://buscacepinter.correios.com.br/app/faixa_cep_uf_localidade/index.php e na tabela de municípios do ibge: https://www.ibge.gov.br/explica/codigos-dos-municipios.php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
