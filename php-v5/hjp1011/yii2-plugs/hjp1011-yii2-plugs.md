# hjp1011/yii2-plugs

> 标签: extension, yii2

## 简介

YiiFrame based plug-in center, you can install and uninstall plug-ins online

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
