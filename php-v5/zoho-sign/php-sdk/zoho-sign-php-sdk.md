# zoho-sign/php-sdk

> 标签: Zoho, Zoho Sign PHP SDK, Zoho Sign PHP examples, Zoho Sign SDK, digital signature, sign

## 简介

Zoho Sign's v1 api wrapper SDK in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
