# dotsplatform/laravel-fcm

> 标签: FCM, Firebase Cloud Messaging, firebase, laravel, lumen, notification, push

## 简介

Laravel / Lumen package for Firebase Cloud Messaging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
