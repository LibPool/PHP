# transportersio/omnipay-judopay

> 标签: gateway, judopay, merchant, omnipay, pay, payment

## 简介

Judopay driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
