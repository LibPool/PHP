# creativestyle/magesuite-quick-reorder

> 标签: PHP

## 简介

This module makes making reorders easier via reorder banner, recently bought products carousel, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
