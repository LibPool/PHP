# creativestyle/magesuite-session-lifetime

> 标签: PHP

## 简介

Regenerates session while going through pages (Default Magento 2.1 functionality is after customer session lifetime is setup and never changed again.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
