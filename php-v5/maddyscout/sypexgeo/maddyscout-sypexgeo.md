# maddyscout/sypexgeo

> 标签: geoip, geolocation, laravel, laravel 5, location

## 简介

Supports GeoIP services (sypexgeo.net).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
