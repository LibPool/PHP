# sham/load-parameters-laravel

> 标签: PHP

## 简介

Carga los parámetros enviados por PUT, POST o GET; y los valida según las reglas asignadas.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
