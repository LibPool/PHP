# ppast/browser_tools

> 标签: PHP

## 简介

Composer library for browser-side code (JS, CSS) ; ECMASCRIPT 5+ required, 6 for Promises feature support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
