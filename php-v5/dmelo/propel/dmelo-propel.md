# dmelo/propel

> 标签: Active Record, orm, persistence

## 简介

Propel2 is an open-source Object-Relational Mapping (ORM) for PHP 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.propelorm.org/
- 源码仓库：https://github.com/dmelo/Propel2.git
- Packagist 页面：https://packagist.org/packages/dmelo%2Fpropel

## 历史版本号

- 当前版本：2.0.0-alpha4

## 获取地址

- Composer 安装：`composer require dmelo/propel`
- Packagist 仓库：https://repo.packagist.org/p2/dmelo/propel.json
- 许可证：MIT
