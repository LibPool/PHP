# tegansnyder/idiorm-datatable-json-bridge

> 标签: datatables, idiorm, json

## 简介

A bridge between the PHP Idiorm ORM and the popular Datatables javascript library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
