# huhushow/monolog-azuretable

> 标签: azure, log, logging, monolog

## 简介

A handler for Monolog that sends messages to Azure Table Stotage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
