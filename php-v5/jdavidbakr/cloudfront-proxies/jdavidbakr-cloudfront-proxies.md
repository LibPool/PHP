# jdavidbakr/cloudfront-proxies

> 标签: cloudfront, laravel, trusted proxies

## 简介

Sets proxy settings for Cloudfront in a Laravel project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
