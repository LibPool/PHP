# jdavidbakr/upload-aws

> 标签: PHP

## 简介

A service that manages file uploads and sends them to AWS.  Utilities include several image processing functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
