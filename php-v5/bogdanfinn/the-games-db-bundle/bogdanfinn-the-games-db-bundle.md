# bogdanfinn/the-games-db-bundle

> 标签: api, bundle, symfony, theGamesDB

## 简介

A symfony bundle for accessing the http://thegamesdb.net/ Api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
