# xiphe/base

> 标签: callbacks, configuration, singleton

## 简介

Basic logic for new projects. Provides singleton, configuration, callback and basic api methods.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
