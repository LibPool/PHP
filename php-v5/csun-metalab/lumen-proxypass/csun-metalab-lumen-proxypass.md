# csun-metalab/lumen-proxypass

> 标签: PHP

## 简介

Composer package for Lumen that resolves the correct absolute URLs when behind a proxy

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
