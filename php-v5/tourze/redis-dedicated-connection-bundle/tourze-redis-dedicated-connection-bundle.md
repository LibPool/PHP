# tourze/redis-dedicated-connection-bundle

> 标签: dedicated-connection, symfony

## 简介

为服务自动创建和注入专用的 Redis 连接，支持属性、标签、环境变量等多种配置方式

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
