# tourze/symfony-routing-auto-loader-bundle

> 标签: PHP

## 简介

Symfony bundle for automatic routing enhancement and auto-loading

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
