# tourze/coupon-command-bundle

> 标签: PHP

## 简介

口令优惠券系统，提供基于口令的优惠券发放、验证和使用记录功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
