# tourze/wechat-mini-program-express-bundle

> 标签: PHP

## 简介

微信小程序同城配送服务，提供即时配送功能及其相关API接口

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
