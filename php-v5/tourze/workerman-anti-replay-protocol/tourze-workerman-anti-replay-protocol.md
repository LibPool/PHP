# tourze/workerman-anti-replay-protocol

> 标签: PHP

## 简介

Workerman防重放攻击协议实现，提供数据包重放检测和防护功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
