# tourze/doctrine-sensitive-tag-bundle

> 标签: PHP

## 简介

Symfony Bundle for tracking sensitive data access with Doctrine entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
