# tourze/order-core-bundle

> 标签: PHP

## 简介

综合订单管理核心模块 - 提供购物车、订单创建、支付处理、发货追踪等完整电商订单功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
