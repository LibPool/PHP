# tourze/wechat-mini-program-auth-bundle

> 标签: PHP

## 简介

微信小程序用户授权管理组件，支持 OAuth 登录和权限管理

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
