# tourze/doctrine-indexed-bundle

> 标签: PHP

## 简介

A Symfony bundle that enhances Doctrine ORM with automatic index management using PHP 8 attributes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
