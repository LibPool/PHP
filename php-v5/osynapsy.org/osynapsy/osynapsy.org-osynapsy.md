# osynapsy.org/osynapsy

> 标签: Rich application, framework, mvc

## 简介

Osynapsy is a framework MVC for develop Rich Internet Application (RIA).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
