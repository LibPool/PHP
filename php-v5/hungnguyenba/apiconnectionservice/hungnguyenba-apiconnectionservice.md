# hungnguyenba/apiconnectionservice

> 标签: PHP

## 简介

Service for eloquent ApiConnection (validate eloquent model, send api request to curl)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
