# kimhf/woocommerce-stubs

> 标签: static analysis, woocommerce, wordpress

## 简介

Stubs for the WooCommerce WordPress plugin, used for static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
