# netandreus/pdfjs-viewer-bundle

> 标签: pdf viewer, pdfjs, symfony, symfony4

## 简介

This bundle provides an integration of pdf.js from mozilla with Symfony 4 framework and customizable parameters on server side. Fix for Symfony 4.4+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
