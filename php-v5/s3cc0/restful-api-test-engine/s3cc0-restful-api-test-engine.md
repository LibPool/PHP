# s3cc0/restful-api-test-engine

> 标签: api, restful, test

## 简介

This is a simple API Test-Engine. With simple JSON files you can run tests for all your RESTful API's.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
