# cleey/phppoem

> 标签: framework, phppoem, poem

## 简介

如诗一般简洁、优美的PHP框架,PhpPoem is a poetic , simple and beautiful php framework, write php as a poem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
