# gabidj/dot-controller-compat

> 标签: PHP

## 简介

psr/http-server-middleware compatibility layer for controller using http-interop/http-middleware

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
