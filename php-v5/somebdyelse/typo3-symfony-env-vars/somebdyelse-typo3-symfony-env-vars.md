# somebdyelse/typo3-symfony-env-vars

> 标签: PHP

## 简介

TYPO3 Extension that replaces the stock environment variable processor by Symfony's

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
