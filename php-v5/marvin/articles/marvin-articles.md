# marvin/articles

> 标签: articles, cms, micro cms, plugin, silex, simple cms

## 简介

Articles plugin for Marvin - PHP micro CMS based on Silex framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
