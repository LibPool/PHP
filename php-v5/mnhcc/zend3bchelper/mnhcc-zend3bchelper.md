# mnhcc/zend3bchelper

> 标签: PHP

## 简介

A Zend Framework 3 backwards compatibility helper modul. Get many behavior from ZF 2.5 on 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
