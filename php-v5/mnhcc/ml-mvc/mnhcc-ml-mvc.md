# mnhcc/ml-mvc

> 标签: framework, mvc, php54, router, template

## 简介

Minimalus Layoutilus — MVC framework (Control, View, Template, Router)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
