# blackboard-open-source/moodle-plugin-ci

> 标签: ci, moodle, testing, travis

## 简介

Assists with running Moodle plugins in Travis CI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
