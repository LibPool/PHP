# gwtphp/gwtphp

> 标签: gwt, gwtphp, php, rpc

## 简介

The Google Web Toolkit RPC protocol server-side application, implemented in PHP. Strives to be a drop-in replacement.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
