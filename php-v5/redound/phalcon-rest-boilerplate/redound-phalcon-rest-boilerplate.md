# redound/phalcon-rest-boilerplate

> 标签: api, boilerplate, phalcon, rest, restful

## 简介

Phalcon REST Boilerplate to use with Phalcon REST library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
