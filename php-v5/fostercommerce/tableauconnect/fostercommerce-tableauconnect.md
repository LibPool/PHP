# fostercommerce/tableauconnect

> 标签: Craft, cms, craft-plugin, craftcms, tableau connect

## 简介

Tableau integration plugin for Craft

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
