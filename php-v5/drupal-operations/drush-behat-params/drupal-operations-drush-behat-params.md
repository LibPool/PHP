# drupal-operations/drush-behat-params

> 标签: PHP

## 简介

Drush command wrapper for behat that pre-configures BEHAT_PARAMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
