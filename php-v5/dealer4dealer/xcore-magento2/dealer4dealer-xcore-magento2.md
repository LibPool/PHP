# dealer4dealer/xcore-magento2

> 标签: PHP

## 简介

This module extends the rest api of Magento2 and is needed for the usage of the xCore.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
