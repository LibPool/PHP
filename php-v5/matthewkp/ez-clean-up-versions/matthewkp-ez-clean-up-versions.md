# matthewkp/ez-clean-up-versions

> 标签: ezplatform, ezpublish, versions

## 简介

This tools clean ups all versions from all content in eZ Platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
