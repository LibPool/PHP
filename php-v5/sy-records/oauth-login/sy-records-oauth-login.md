# sy-records/oauth-login

> 标签: OAuthLogin2.0, github, php, qq, weibo

## 简介

This is an extension that integrates third-party logins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
