# timurmelnikov/yii2-showloading

> 标签: ajax, jquery, showLoading, widget, yii2

## 简介

Yii2 расширение для подключения плагина jQuery showLoading

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
