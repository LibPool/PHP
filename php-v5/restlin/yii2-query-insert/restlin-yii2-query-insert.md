# restlin/yii2-query-insert

> 标签: db, extension, query builder, yii2

## 简介

Class for Yii2 PHP framework helps to generate insert sql query from other tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
