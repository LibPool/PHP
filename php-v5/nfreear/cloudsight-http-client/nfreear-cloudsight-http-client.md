# nfreear/cloudsight-http-client

> 标签: OCR, picture, search, vision

## 简介

HTTP client for CloudSight's image recognition API. (Not endorsed by CloudSight.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
