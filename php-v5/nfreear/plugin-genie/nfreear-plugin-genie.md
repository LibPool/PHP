# nfreear/plugin-genie

> 标签: IET-OU, OpenUniversity, PSR-4, autoload, composer, ouplayer, plugin

## 简介

PHP plugin discovery library built on PSR-4 autoloading.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
