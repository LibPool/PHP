# studiobonito/silverstripe-omnipayable

> 标签: gocardless, omnipay, payment, paypal, silverstripe

## 简介

The Omnipayable module adds support for the Omnipay library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
