# lia/lia_multicolumnwizard

> 标签: PHP

## 简介

TYPO3 extension for introducing a new TCA type for grouping fields into duplicable rows.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
