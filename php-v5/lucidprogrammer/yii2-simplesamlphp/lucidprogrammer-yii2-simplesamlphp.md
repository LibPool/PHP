# lucidprogrammer/yii2-simplesamlphp

> 标签: saml, simplesamlphp, yii, yii2

## 简介

SAML Service Provider(SP) for Yii2 using simplesamlphp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
