# theofidry/loopback-api-bundle

> 标签: Hydra, JSON-LD, LoopBack, api, json, rest

## 简介

Loopback like Doctrine ORM filters for DunglasApiBundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
