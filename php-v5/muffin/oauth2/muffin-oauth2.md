# muffin/oauth2

> 标签: Authentication, auth, cakephp, league, muffin, oauth2

## 简介

CakePHP 3 authentication using the league/oauth2-client family

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
