# naturalweb/nwlaravel-dropbox

> 标签: dropbox, laravel, php, sdk-dropbox

## 简介

Dropbox SDK Service Provider for the Laravel PHP Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
