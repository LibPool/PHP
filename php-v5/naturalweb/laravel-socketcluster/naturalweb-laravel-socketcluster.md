# naturalweb/laravel-socketcluster

> 标签: Broadcasting, laravel, socketcluster

## 简介

SocketCluster.io library Broadcaster for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
