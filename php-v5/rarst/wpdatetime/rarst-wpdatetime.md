# rarst/wpdatetime

> 标签: date, time, timezone, wordpress

## 简介

Extension of PHP’s DateTime and DateTimeZone classes for WordPress context.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
