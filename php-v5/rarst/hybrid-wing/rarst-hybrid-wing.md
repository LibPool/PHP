# rarst/hybrid-wing

> 标签: bootstrap, hybrid, wordpress

## 简介

Toolkit theme for WordPress, based on Hybrid Core and Twitter Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
