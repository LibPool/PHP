# yarri/link-finder

> 标签: Linkify, e-mail, email, link, url, urlize, urlizer

## 简介

Converts non-clickable URLs and email addresses in text (plain or HTML) into clickable HTML links

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
