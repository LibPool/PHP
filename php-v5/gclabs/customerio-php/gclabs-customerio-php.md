# gclabs/customerio-php

> 标签: Customerio, Guzzle, api, customerio-api

## 简介

PHP bindings for the Customer.io API (http://customer.io/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
