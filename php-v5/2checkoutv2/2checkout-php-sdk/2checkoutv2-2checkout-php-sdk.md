# 2checkoutv2/2checkout-php-sdk

> 标签: 2checkout, 2co, gateway, payment, verifone

## 简介

2Checkout PHP SDK by Verifone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
