# raindrop/geoip-bundle

> 标签: geoip, maxmind

## 简介

Raindrop GeoIP Symfony2 Bundle with Maxmind data source

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
