# thisisdevelopment/laravel-tenants

> 标签: laravel, multi-tenancy, tenants

## 简介

A package to provide multi tenancy to laravel applications with minimal effort

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
