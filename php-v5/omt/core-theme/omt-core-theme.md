# omt/core-theme

> 标签: assets, blade, laravel, package, themes, views

## 简介

Laravel 5 Themes: Asset & Views folder per theme. Theme inheritance. Blade integration and more...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
