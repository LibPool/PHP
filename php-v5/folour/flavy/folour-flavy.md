# folour/flavy

> 标签: audio, conversion, converter, ffmpeg, laravel, video, video thumbnailer

## 简介

FFmpeg layer for Laravel 5.2-5.4, this is a fork of rafasamp/sonus package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
