# lengthofrope/create-jsonld-tiny

> 标签: JSON-LD, jsonld

## 简介

Simple PHP library to create JSON-LD output. Tiny version

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
