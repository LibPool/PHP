# sixty-nine/find-vendors

> 标签: PHP

## 简介

Find the vendors directory from inside packages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://bitbucket.org/sixty-nine/find-vendors.git
