# beatswitch/lock-laravel

> 标签: acl, asserts, beatswitch, conditions, drivers, laravel, permissions, roles, security

## 简介

A Laravel Driver for Lock.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
