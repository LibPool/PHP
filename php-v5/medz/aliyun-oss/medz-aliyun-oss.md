# medz/aliyun-oss

> 标签: aliyun-oss-sdk, medz, oss, php, streamwrapper, wrapper

## 简介

The package is Aliyun OSS SDK, And support streamWrapper register.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
