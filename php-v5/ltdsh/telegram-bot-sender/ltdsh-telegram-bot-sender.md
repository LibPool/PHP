# ltdsh/telegram-bot-sender

> 标签: Sender, message, php, reusable bundle, symfony, telegram

## 简介

Simple class for sendinf messages with telegram bot

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
