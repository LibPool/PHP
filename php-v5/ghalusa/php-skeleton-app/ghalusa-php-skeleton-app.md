# ghalusa/php-skeleton-app

> 标签: OOP, Skeleton, app, mvc, php

## 简介

An MVC-based PHP skeleton application for rapid development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
