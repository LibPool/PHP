# bitpatroon/bpn_expiring_fe_groups

> 标签: groups, security, service, typo3

## 简介

Allows to give an fe_group to an fe_user for a specified amount of time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
