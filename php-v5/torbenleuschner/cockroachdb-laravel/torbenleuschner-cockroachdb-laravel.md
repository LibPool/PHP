# torbenleuschner/cockroachdb-laravel

> 标签: cockroach, cockroachdb, laravel

## 简介

CockroachDB driver for Laravel 5.6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
