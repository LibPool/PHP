# gremo/pjax-bundle

> 标签: ajax, jquery, pjax, pushState

## 简介

Symfony bundle that provide a lightweight yet powerfull integration with pjax jQuery plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
