# bingying2/yii2-apidoc

> 标签: api, apidoc, documentation, phpdoc, yii2

## 简介

API Documentation generator for the Yii framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
