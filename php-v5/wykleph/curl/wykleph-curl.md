# wykleph/curl

> 标签: Multi-thread, asynchronous, automation, bot, crawler, curl, http, internet, mit, parallel, request, requests, scraper, spider, web, web request

## 简介

Simple synchronous and asynchronous cURL requests in php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
