# dreadlabs/app-migration-typo3

> 标签: PHP

## 简介

Integrates dreadlabs/app-migration infrastructure into TYPO3.CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
