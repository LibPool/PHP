# mrcoco/phalms

> 标签: crud generator, elearning, framework, lms, modular, module generator, phalcon, phalms, sample app

## 简介

This is a LMS (Learning Management System) sample application for the Phalcon PHP Framework based on Vokuro-modular

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
