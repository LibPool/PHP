# argayash/core-bundle

> 标签: site management, symfony 2, symfony 2 module

## 简介

Bundle for creating modules and site structure in symfony 2.1 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
