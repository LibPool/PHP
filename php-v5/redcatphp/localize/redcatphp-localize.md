# redcatphp/localize

> 标签: Common Locale Data Repository, cldr, gettext, i18n, internationalization, l10n, localization, localize

## 简介

Localize - Internationalization Toolbox with Gettext wrapper, Extractors, Unicode Common Locale Data Repository

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
