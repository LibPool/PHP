# redcatphp/framework

> 标签: Agile, framework, full-stack, mvc, rad, solid

## 简介

PHP Framework - Complete set of RedCat's PHP Components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
