# kuleshov/check-correct-parenthesis

> 标签: PHP

## 简介

Пакет, который позволяет проверить строку на корректность закрытах и открытах скобок

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
