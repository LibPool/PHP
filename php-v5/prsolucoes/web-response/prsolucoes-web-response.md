# prsolucoes/web-response

> 标签: ajax, json, response, web, xml

## 简介

Return service or ajax response data in a nice format. You can return in JSON or XML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
