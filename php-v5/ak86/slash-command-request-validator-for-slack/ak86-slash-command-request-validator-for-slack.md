# ak86/slash-command-request-validator-for-slack

> 标签: PHP

## 简介

A simple PHP package for validating the requests sent through a slack app slash commands.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
