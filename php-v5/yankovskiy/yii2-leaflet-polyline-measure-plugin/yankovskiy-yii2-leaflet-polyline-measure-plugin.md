# yankovskiy/yii2-leaflet-polyline-measure-plugin

> 标签: extension, leaflet, yii2

## 简介

Plugin to measure distances of simple lines as well as of complex polylines

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
