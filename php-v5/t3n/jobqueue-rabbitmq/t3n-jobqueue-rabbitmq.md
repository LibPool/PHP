# t3n/jobqueue-rabbitmq

> 标签: PHP

## 简介

A Flowpack.JobQueue.Common implementation to support RabbitMQ as backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
