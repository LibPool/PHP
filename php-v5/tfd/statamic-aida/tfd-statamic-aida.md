# tfd/statamic-aida

> 标签: AI-generated content, Statamic addon, accessibility, ai, alt-text, automatic alt text, image optimization, seo, statamic, web accessibility

## 简介

A Statamic addon that automates the generation of image alt texts using AI, enhancing web accessibility and SEO with minimal effort.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
