# omatech/editora-dbinterface

> 标签: PHP

## 简介

Extract or Load information from Editora in powerful and misterious ways using closures with Eloquant like syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
