# yama/tanggalan-api

> 标签: PHP

## 简介

Ini adalah sebuah library API kalender untuk scrapping data kalender dari tanggalan.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
