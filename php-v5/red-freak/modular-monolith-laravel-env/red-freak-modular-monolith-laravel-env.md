# red-freak/modular-monolith-laravel-env

> 标签: PHP

## 简介

dotenv management for modular monoliths inspired by https://github.com/avosalmon/modular-monolith-laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
