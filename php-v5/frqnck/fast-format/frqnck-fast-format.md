# frqnck/fast-format

> 标签: apix, format, sprintf, template

## 简介

Fast and simple string formater/templater engine. Provides named and nested substutions. Extendable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
