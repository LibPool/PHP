# hudhaifas/silverstripe-genealogist

> 标签: family tree, genealogist, genealogy, silverstripe

## 简介

Genealogist module for the SilverStripe CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
