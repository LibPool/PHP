# coldlook/yii2-cropper

> 标签: cropper, extension, widget, yii2

## 简介

Yii2 Bootstrap Cropper Input Widget [yii2图片裁剪插件]

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
