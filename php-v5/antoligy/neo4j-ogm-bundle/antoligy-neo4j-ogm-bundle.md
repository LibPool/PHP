# antoligy/neo4j-ogm-bundle

> 标签: neo4j

## 简介

A Symfony bundle for using the Neo4j graphing database in your projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
