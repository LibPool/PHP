# jbithell/gridwatch

> 标签: electricity, grid

## 简介

PHP Wrapper for the UK National Grid Live Data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Packagist 仓库：https://repo.packagist.org/p2/jbithell/gridwatch.json
