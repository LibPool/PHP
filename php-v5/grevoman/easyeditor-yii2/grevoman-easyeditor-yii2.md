# grevoman/easyeditor-yii2

> 标签: PHP

## 简介

Example project. Yii2 widget for im4aLL/easyeditor WYSISYG editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
