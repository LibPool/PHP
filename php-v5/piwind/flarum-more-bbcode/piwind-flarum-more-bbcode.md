# piwind/flarum-more-bbcode

> 标签: flarum, flarum extension

## 简介

Adds more BBCode. Forked from xypp/flarum-more-bbcode with maintained updates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
