# mbaynton/launch-cli-editor

> 标签: cli, console, editor, terminal, text editor

## 简介

Launch the user's preferred terminal editor to input or update large strings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
