# mbaynton/batch-framework

> 标签: PHP

## 简介

An API and foundational algorithms for efficient processing of long-running jobs that can be divided into small work units.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
