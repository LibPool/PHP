# kamranahmedse/smasher

> 标签: directories, directories-to-json, directory, directory-to-json, folder, folder-to-json, folders, folders-to-json, json

## 简介

A PHP package to easily smash directories and convert them to JSON

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
