# krzychu12350/metasploitapi

> 标签: PHP

## 简介

This package will auto generate API allows to interact with Metasploit framework using krzychu 12350/phpmetasploit package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
