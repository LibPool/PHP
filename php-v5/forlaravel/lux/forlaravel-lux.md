# forlaravel/lux

> 标签: blade, components, forlaravel, laravel, livewire, lux, shadcn, ui

## 简介

Laravel Lux is a set of laravel blade components based on shadcn/ui

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
