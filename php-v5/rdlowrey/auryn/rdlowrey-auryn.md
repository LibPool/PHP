# rdlowrey/auryn

> 标签: dependency injection, dic, ioc

## 简介

Auryn is a dependency injector for bootstrapping object-oriented PHP applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
