# bbrala/php7-mysql-shim

> 标签: PHP

## 简介

A PHP 7 shim for ext/mysql. Temporary which doesn't break old PHP's

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
