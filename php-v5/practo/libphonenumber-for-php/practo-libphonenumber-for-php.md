# practo/libphonenumber-for-php

> 标签: libphonenumber, mobile, phonenumber, validation

## 简介

Clone of Phone number handling library by Davide Mendolia

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
