# awsmug/torro-forms-plugin-boilerplate

> 标签: Forms, api, extension, form builder, plugin, torro forms, wordpress

## 简介

Plugin Boilerplate for Torro Forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
