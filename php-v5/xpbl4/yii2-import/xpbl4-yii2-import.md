# xpbl4/yii2-import

> 标签: csv, excel, xls, xlsx, yii2

## 简介

Extension for the Yii2 framework for importing Excel data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
