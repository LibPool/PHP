# meuhmeuhconcept/wkhtmltopdf-alpine

> 标签: alpine, binary, convert, docker, pdf, wkhtmltopdf

## 简介

Binary of wkhtmltopdf runnable in docker alpine container.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
