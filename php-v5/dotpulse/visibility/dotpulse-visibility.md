# dotpulse/visibility

> 标签: PHP

## 简介

Use this plugin for showing and hiding content by device via media query. Also included are settings for toggling content when printed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
