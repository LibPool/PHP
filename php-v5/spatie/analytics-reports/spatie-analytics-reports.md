# spatie/analytics-reports

> 标签: analytics, google, laravel, reports, retrieve

## 简介

An opinionated Laravel 4 package to retrieve Google Analytics data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
