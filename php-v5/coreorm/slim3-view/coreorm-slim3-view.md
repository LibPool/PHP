# coreorm/slim3-view

> 标签: PHP

## 简介

view renderer for slim3 with very straightforward and simple (yet still customisable) theme/layout/templates structure

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
