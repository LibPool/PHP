# hounddd/wn-mallimportexport-plugin

> 标签: mall, plugin, winter, winter cms

## 简介

Import or export data to OFFLINE.mall.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
