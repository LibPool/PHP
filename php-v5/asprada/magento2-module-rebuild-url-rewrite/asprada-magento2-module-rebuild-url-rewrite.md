# asprada/magento2-module-rebuild-url-rewrite

> 标签: PHP

## 简介

Magento 2 module to rebuild url rewrites for categories, products and cms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
