# czukowski/phpunit-mock-db

> 标签: database, mock, phpunit

## 简介

Database Abstraction Layer mocking helpers for PHPUnit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
