# metabolism/wp-redis-user-session-storage

> 标签: PHP

## 简介

Store WordPress user session tokens in Redis rather than the usermeta table. Requires PECL Redis library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
