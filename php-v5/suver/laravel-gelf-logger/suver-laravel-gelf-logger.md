# suver/laravel-gelf-logger

> 标签: gelf, graylog, laravel, laravel-gelf, php, suver

## 简介

A package to send logs to a gelf compatible backend like graylog

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
