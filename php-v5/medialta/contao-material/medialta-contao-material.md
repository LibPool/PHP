# medialta/contao-material

> 标签: backend, backend theme, contao, contao-material, material, theme

## 简介

Backend theme Contao Material for Contao Open Source CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
