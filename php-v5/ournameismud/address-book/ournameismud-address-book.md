# ournameismud/address-book

> 标签: Craft, address book, cms, craft-plugin, craftcms

## 简介

Plugin to manage customer addresses independently of Craft Commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
