# orken/cakephp3-mandrill-api

> 标签: api, cakephp, mandrill

## 简介

Send mail using Mandrill Api (with MailChimp)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
