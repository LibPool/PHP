# cmarfil/laravel-multiuser-json-settings

> 标签: Settings, json, laravel, user

## 简介

Simple user json settings facade for Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
