# boospot/uclient

> 标签: automatic updates, license server, plugin auto updates, theme auto updates, wordpress

## 简介

This is client package for uLicense main server plugin to provide auto updates for WordPress plugin or theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
