# frankkuipers/solopenidclient

> 标签: Authentication, OpenId, security

## 简介

Lightweight PHP5 library for easy SOL OpenID authentication.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
