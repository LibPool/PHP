# epokmedia/msgpackrpc

> 标签: messagepack, msgpack, rpc

## 简介

Port of PEAR MessagePack RPC Client to PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
