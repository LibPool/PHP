# yanli0303/yii-minify-client-script

> 标签: PHP

## 简介

A PHP Yii framework extension to minify JavaScript and CSS files for a web page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
