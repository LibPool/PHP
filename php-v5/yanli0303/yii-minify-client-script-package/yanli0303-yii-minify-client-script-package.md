# yanli0303/yii-minify-client-script-package

> 标签: PHP

## 简介

A PHP console application for minifying JavaScript and CSS files of a PHP Yii web application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
