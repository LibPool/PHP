# frc/wp-env-heroku-amazon-aws

> 标签: amazon aws, amazon web services, heroku, wordpress

## 简介

Export Amazon AWS configuration for amazon-web-services WP plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
