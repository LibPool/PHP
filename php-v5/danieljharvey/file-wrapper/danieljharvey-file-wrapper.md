# danieljharvey/file-wrapper

> 标签: file, testing, wrapper

## 简介

A simple file system function wrapper that can be easily mocked or stubbed for testing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
