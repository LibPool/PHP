# mediamonks/crawler-bundle

> 标签: crawler, dom, prerender, prerender.io, robot, seo, spider

## 简介

Integrates the mediamonks/crawler package into Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
