# denngarr/smf-bridge

> 标签: PHP

## 简介

This plugin uses the SeAT users with APIs to create SMF users and auto-login to the forums.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
