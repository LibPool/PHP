# zyx/widget-imagex

> 标签: image, images, microdata, opengraph, schema.org

## 简介

Adding opengraph meta tags and microdata markdown to images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
