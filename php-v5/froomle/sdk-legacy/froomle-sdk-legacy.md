# froomle/sdk-legacy

> 标签: PHP

## 简介

Froomle SDK with auto-installing integration for Drupal (and later Laravel/Symfony).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://bitbucket.org/froomle/froomle-sdk-php-legacy

- Packagist 页面：https://packagist.org/packages/froomle%2Fsdk-legacy
