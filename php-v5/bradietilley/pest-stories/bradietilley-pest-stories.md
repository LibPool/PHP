# bradietilley/pest-stories

> 标签: PHP

## 简介

A tool to assist in creating complex permutations of test case scenarios in Pest PHP (for Laravel)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
