# davidyan/asyntask

> 标签: PHP

## 简介

A lightweight asynchronous queue manager, supporting real-time, timing, long-term, periodic tasks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
