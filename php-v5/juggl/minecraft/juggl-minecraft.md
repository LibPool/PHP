# juggl/minecraft

> 标签: Mojang, api, minecraft

## 简介

Laravel wrapper for Mojang's Minecraft API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/svenluijten/Minecraft
- 源码仓库：https://github.com/Jugglio/Minecraft.git
- Packagist 页面：https://packagist.org/packages/juggl%2Fminecraft

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require juggl/minecraft`
- Packagist 仓库：https://repo.packagist.org/p2/juggl/minecraft.json
- 许可证：MIT
- PHP 要求：>=5.3.0
