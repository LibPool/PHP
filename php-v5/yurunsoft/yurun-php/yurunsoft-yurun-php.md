# yurunsoft/yurun-php

> 标签: PHP

## 简介

YurunPHP是宇润软件专为懒人开发者设计的一款开源PHP框架，基于MVC动态分层架构，开发者可以根据需要自行扩充分层。它来自中国！

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
