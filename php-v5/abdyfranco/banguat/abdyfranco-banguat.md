# abdyfranco/banguat

> 标签: banguat, exchange, money

## 简介

Provides an easy-to-use class for communicating with the exchange rate web service of Banco de Guatemala.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
