# azco/laravel-keycloak-web-guard2

> 标签: Authentication, jwt, keycloak, laravel

## 简介

Simple Keycloak Guard to Laravel Web Routes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
