# captcha-com/cakephp-captcha

> 标签: botdetect, cakephp captcha, cakephp captcha plugin, captcha, captcha generator, captcha plugin

## 简介

CakePHP Captcha Plugin -- BotDetect PHP Captcha generator integration for the CakePHP framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
