# captcha-com/symfony-captcha-bundle

> 标签: botdetect, captcha, captcha bundle, captcha generator, symfony captcha, symfony captcha bundle

## 简介

Symfony Captcha Bundle -- BotDetect PHP Captcha generator integration for the Symfony framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
