# jheimbach/pico-content-vars

> 标签: pico, pico-content-vars, picocms, picocms-plugin

## 简介

A Content variables plugin for Pico CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
