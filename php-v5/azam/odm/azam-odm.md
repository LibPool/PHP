# azam/odm

> 标签: doctrine, laravel, mongodb, odm

## 简介

Doctrine MongoDB ODM integration with Laravel. Aim to be interoperable with other frameworks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
