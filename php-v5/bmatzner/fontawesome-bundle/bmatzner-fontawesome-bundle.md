# bmatzner/fontawesome-bundle

> 标签: css, graphics, symfony, typography, webfonts

## 简介

FontAwesome Bundle for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
