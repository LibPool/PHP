# ruckusing/ruckusing-migrations

> 标签: database, migrations, mysql, postgres, rake, ruckusing, task

## 简介

Framework for generating and managing database migrations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
