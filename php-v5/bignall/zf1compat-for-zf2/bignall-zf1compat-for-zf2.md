# bignall/zf1compat-for-zf2

> 标签: PHP

## 简介

ZF1 (Zend Frameworks version 1) Compatibility Layer for ZF2 (Zend Frameworks version 2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
