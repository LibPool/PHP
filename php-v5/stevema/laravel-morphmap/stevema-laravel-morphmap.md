# stevema/laravel-morphmap

> 标签: laravel, map, morph, morphmap

## 简介

laravel的别名配置-多态关系动态添加不用自己写服务提供者了，配置文件中定义一下就行

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
