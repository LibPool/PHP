# blackpulp/ministryplatform

> 标签: blackpulp, ministryplatform

## 简介

Library to consume the MinistryPlatform SOAP XML API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
