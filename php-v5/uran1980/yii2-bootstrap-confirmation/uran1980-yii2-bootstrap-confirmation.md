# uran1980/yii2-bootstrap-confirmation

> 标签: bootstrap, confirmation, yii2

## 简介

Bootstrap plugin for on-place confirm boxes using Popover for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
