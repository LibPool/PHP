# kwrz/twig-exception

> 标签: exception, route, twig, view

## 简介

Use to make customizables Twig exception pages for routes or specific HTTP status codes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
