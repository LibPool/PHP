# paulmenheere/laravel5-magento

> 标签: laravel, magento, soap

## 简介

A simple Magento Integration using SOAP v1 and v2. Forked from michaelkmartin/laravel5-magento

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
