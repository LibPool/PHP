# sheaf/cli

> 标签: artisan-command, cli, laravel, laravel-package, package, sheaf

## 简介

A CLI tool for Sheaf UI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
