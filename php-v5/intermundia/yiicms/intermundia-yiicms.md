# intermundia/yiicms

> 标签: extension, yii2, yii2 CMS core

## 简介

Package contains core models, migrations, behaviors, controllers etc. For the Yii2 CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
