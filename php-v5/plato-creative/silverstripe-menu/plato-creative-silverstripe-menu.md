# plato-creative/silverstripe-menu

> 标签: cms, link, menu, modular, silverstripe

## 简介

Adds multiple menus that are defined via yml and managed via the cms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
