# stephanecoinon/autoversion

> 标签: PHP

## 简介

Prefix asset file name with a timestamp to invalidate cache if a new asset is uploaded on the server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
