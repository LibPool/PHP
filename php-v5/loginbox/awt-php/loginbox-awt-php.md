# loginbox/awt-php

> 标签: PHP

## 简介

Loginbox authentication web tokens for php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://loginbox.io
- 源码仓库：https://github.com/loginbox/awt-php.git
- Packagist 页面：https://packagist.org/packages/loginbox%2Fawt-php
