# jambagecom/base-excel

> 标签: PhpOffice, excel, extension, typo3

## 简介

This provides the PhpSpreadsheet library, formerly phpExcel, from phpOffice.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
