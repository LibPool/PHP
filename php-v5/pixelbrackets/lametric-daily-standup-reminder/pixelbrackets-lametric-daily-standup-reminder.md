# pixelbrackets/lametric-daily-standup-reminder

> 标签: PHP

## 简介

Send a reminder notification to all local LaMetric devices when the daily standup is due

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
