# gasparesganga/php-shapefile

> 标签: ESRI, Shapefile, dbf, geojson, shape, shp, wkt

## 简介

PHP library to read and write ESRI Shapefiles, compatible with WKT and GeoJSON

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
