# yana/dr

> 标签: PHP Log Parser, framework, log, log parser

## 简介

PHP Log Parser LightWeight - updated 2021 - This package contains an authentication page and log display

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
