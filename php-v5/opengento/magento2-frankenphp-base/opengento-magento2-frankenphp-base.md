# opengento/magento2-frankenphp-base

> 标签: application, frankenphp, magento, magento2, php

## 简介

Magento 2 Base for FrankenPHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
