# evemarket/eve-market-details

> 标签: api, eveonline, fetching, framework, http

## 简介

EveOnline is a public crest API library that makes fetching api end points easier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
