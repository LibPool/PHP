# strekoza/module-available-slash-for-categor-url-key

> 标签: PHP

## 简介

Magento 2 extension. Will available in use Slash "/" in Url Key of Category.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
