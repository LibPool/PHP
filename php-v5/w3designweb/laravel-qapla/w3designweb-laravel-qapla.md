# w3designweb/laravel-qapla

> 标签: Qapla, W3design, laravel

## 简介

Package to integrate Qapla API functionalities in your Laravel web application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
