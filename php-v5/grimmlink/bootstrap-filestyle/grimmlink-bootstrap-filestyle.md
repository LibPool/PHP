# grimmlink/bootstrap-filestyle

> 标签: PHP

## 简介

jQuery customization of input html file for Bootstrap Twitter http://markusslima.github.io/bootstrap-filestyle/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
