# dhsservices/magento2-default-shipping-payment

> 标签: PHP

## 简介

Allows a shipping method and payment method to be pre-selected on Magento 2 checkout page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
