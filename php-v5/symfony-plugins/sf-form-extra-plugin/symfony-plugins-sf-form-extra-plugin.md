# symfony-plugins/sf-form-extra-plugin

> 标签: PHP

## 简介

The sfFormExtraPlugin packages useful validators, widgets, and forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
