# mytoysgroup/patternlab-twig-bridge

> 标签: PHP

## 简介

Dummy Implementation of Symfony Twig Bridge for Pattern Lab; Forked from symfony/twig-bridge

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
