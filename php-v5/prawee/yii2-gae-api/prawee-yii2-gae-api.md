# prawee/yii2-gae-api

> 标签: api, gae, google app engine, restful, yii2

## 简介

Create RESTful for deploy on Google App Engine with Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
