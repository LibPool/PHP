# creof/doctrine2-php-uuid-generator

> 标签: database, generator, id, orm, uuid

## 简介

Doctrine2 pre-insert UUID id generator using PECL UUID (*nix) or COM (Windows)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
