# phapi/http

> 标签: http message, phapi, psr-7

## 简介

Phapi HTTP Message is an implementation of PSR-7 used by the Phapi framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
