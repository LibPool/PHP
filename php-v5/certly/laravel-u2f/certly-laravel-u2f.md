# certly/laravel-u2f

> 标签: otp, security, u2f

## 简介

U2F support for laravel 5 (forked from lahaxearnaud/laravel-u2f)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
