# lin3s/wp-phpspec-brigde

> 标签: Bridge, lin3s, phpspec, wordpress

## 简介

PhpSpec bridge for using this BDD fw with WordPress internal functions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
