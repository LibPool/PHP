# oudmane/oudyplat

> 标签: application, framework, oudy, oudyplat, php, plat, web

## 简介

OudyPlat is a framework for PHP developed to build robust Web Applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
