# donnyutama/yii2-adminlte2

> 标签: PHP

## 简介

AdminLTE v2 theme asset bundle for Yii 2.0 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
