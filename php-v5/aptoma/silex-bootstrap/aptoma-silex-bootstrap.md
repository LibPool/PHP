# aptoma/silex-bootstrap

> 标签: bootstrap, silex

## 简介

Basic bootstrap for Silex based projects. Use as template for getting started quickly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
