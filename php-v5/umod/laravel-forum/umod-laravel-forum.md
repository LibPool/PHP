# umod/laravel-forum

> 标签: discuss, forum, laravel, laravel-5

## 简介

A Laravel 5 package providing a solid foundation for building discussion forums

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
