# jontynewman/html-filter

> 标签: file, filter, html, jontynewman, pointer, resource, stream

## 简介

A stream filter for converting special HTML characters.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
