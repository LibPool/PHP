# gud3/yii2-rest-auth

> 标签:  yii2 rest,  yii2 rest authorized, yii2

## 简介

Authorization for rest, which is made for increased security.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
