# reinfi/zf-dompdf-module

> 标签: dompdf, pdf, zf2

## 简介

A Zend Framework 2 module for incorporating DOMPDF support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
