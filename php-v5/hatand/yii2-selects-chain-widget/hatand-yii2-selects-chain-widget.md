# hatand/yii2-selects-chain-widget

> 标签: yii2, yii2-selects-chain-widget, yii2-widget

## 简介

Chain of HTML 'select' elements for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
