# pilskalns/f3-wcurl

> 标签: F3, Fat Free Framework, api, curl

## 简介

F3 Wrapper for cURL to talk with external REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
