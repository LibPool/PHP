# hazaarlabs/hazaar-socket

> 标签: hazaar, hmvc, net, networking, php, sockets

## 简介

The Sockets layer for Hazaar MVC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
