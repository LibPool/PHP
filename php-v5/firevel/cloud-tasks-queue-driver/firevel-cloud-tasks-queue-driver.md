# firevel/cloud-tasks-queue-driver

> 标签: cloud tasks, firevel, laravel, queue

## 简介

Cloud Tasks queue driver for Laravel apps running inside Google App Engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
