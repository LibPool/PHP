# beetpix/silverstripe-screenshot

> 标签: capture, pdf, screenshot, silverstripe

## 简介

SDK with helpers to access printscreenapi.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
