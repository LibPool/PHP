# koriit/eventdispatcher

> 标签: dispatcher, event, eventdispatcher, koriit, php-di

## 简介

Simple event dispatcher based on PHP-DI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
