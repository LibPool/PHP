# bushbaby/doctrine-reconnect

> 标签: doctrine, zf2

## 简介

Zend Framework 2 module which attempts to reconnect when the database has 'gone away'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
