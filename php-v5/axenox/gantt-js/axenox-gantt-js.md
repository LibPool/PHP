# axenox/gantt-js

> 标签: gantt, multiple tasks per row, project management, riel-gantt, svg, task aggregation, timeline aggregation

## 简介

Riel Gantt is an upgraded version of Frappe Gantt with support for multiple tasks per row and task aggregation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
