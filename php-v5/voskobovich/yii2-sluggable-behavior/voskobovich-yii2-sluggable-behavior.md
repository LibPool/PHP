# voskobovich/yii2-sluggable-behavior

> 标签: Behavior, slug, sluggable, yii2

## 简介

Adds transliteration slugs to the standard solution from Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
