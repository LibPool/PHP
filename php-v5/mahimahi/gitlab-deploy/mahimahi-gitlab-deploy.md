# mahimahi/gitlab-deploy

> 标签: deployment, git, gitlab, laravel

## 简介

Helps automate the deployment of projects onto servers by utilising Gitlab web hooks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
