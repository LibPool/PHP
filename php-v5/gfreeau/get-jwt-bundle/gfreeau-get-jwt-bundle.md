# gfreeau/get-jwt-bundle

> 标签: Authentication, JWS, Symfony2, bundle, jwt

## 简介

This Symfony2 bundle provides a security listener to return a JWT

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
