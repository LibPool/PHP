# superbalist/monolog-google-cloud-json-formatter

> 标签: PHP

## 简介

A Monolog extension for formatting log entries for Google Cloud Logging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
