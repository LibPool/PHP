# skyshab/rootstrap-tabs

> 标签: wordpress

## 简介

Rootstrap Tabs extends Rootstrap to add tabbed navigation for customizer sections.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
