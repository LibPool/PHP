# webit-de/typo3-extemconf-to-composer-converter

> 标签: PHP

## 简介

Convert the ext_emconf.php file of a TYPO3 extension into a composer.json file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
