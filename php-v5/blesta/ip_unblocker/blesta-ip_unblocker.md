# blesta/ip_unblocker

> 标签: PHP

## 简介

A plugin for Blesta that integrates with cPanel and DirectAdmin to unblock blacklisted IPs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
