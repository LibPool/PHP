# ondrs/nette-mailgun-mailer

> 标签: mailer, mailgun, nette

## 简介

Implementation of Nette\IMailer for Mailgun PHP SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
