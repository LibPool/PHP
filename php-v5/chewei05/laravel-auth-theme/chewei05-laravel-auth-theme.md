# chewei05/laravel-auth-theme

> 标签: PHP

## 简介

Laravel 5 authentication themes with username customization, such as AdminLTE and etc...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
