# leo108/geolite2-db

> 标签: PHP

## 简介

This repository aims to provide an easy solution to require GeoIP2 / GeoLite2 databases inside your project using composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
