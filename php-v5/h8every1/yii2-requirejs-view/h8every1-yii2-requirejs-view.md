# h8every1/yii2-requirejs-view

> 标签: extension, modules, requirejs, view, yii2

## 简介

Yii2 View class with ability to register RequireJS modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
