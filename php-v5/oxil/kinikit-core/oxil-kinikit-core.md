# oxil/kinikit-core

> 标签: application, json webservices, mvc, orm, persistence framework, php, webservices

## 简介

Kinikit - PHP Application development framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
