# htmlburger/wpemerge-theme

> 标签: starter theme, theme, wordpress, wpemerge

## 简介

A modern WordPress starter theme which uses the WP Emerge framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
