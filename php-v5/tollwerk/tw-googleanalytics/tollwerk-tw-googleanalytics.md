# tollwerk/tw-googleanalytics

> 标签: PHP

## 简介

Frontend plugin for advanced Google / Universal Analytics integration with a wide range of features including pageView and event tracking, custom variables / metrics, cross domain tracking, tracking of file downloads and external domains and much more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
