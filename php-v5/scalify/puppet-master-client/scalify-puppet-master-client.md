# scalify/puppet-master-client

> 标签: puppet-master, puppet-master client, puppet-master.io, scalify

## 简介

Client library for the puppet-master HTTP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
