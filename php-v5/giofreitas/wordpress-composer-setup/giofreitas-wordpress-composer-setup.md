# giofreitas/wordpress-composer-setup

> 标签: composer, wordpress, wp-config

## 简介

A composer plugin to setup your WordPress environment to be friends with composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
