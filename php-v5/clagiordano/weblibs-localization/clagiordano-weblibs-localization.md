# clagiordano/weblibs-localization

> 标签: clagiordano, gettext, intl, library, localization, weblibs

## 简介

Abstraction library for the PHP-gettext backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
