# academe/laraveldkim

> 标签: dkim, email, laravel, spam

## 简介

A Laravel plugin to sign all outgoing emails using DKIM from within the application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
