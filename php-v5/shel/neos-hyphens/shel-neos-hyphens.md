# shel/neos-hyphens

> 标签: CKEditor, Neos, editor, flow, hyphens, neoscms

## 简介

A plugin for Neos CMS which provides hyphens for the inline editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
