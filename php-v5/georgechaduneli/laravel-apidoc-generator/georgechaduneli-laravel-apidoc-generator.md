# georgechaduneli/laravel-apidoc-generator

> 标签: api, documentation, laravel

## 简介

Generate beautiful API documentation from your Laravel application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
