# phpseclib/bcmath_compat

> 标签: BigInteger, bcmath, bigdecimal, math, polyfill

## 简介

PHP 5.x-8.x polyfill for bcmath extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
