# sut/pmapi

> 标签: PMAPI, Permission marketing, Sign-Up.to

## 简介

PHP client library for Sign-Up.to's Permission Marketing API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
