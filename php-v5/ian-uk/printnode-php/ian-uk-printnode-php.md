# ian-uk/printnode-php

> 标签: PrintNode, api, php, printing

## 简介

Connect any printer to your application with PrintNode Client and easy to use JSON API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
