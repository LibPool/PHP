# timhovius/documentor-bundle

> 标签: phpDocumentor

## 简介

Symfony2 bundle to implement phpDocumentor into any project from which the documentation is accessible with a browser.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
