# beskhue/cookietokenauth

> 标签: Authentication, cakephp, cookies, remember

## 简介

Remember CakePHP user authentications with token cookies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
