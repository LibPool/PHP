# kiddyu/beanbun

> 标签: crawler, scraper, spider

## 简介

Beanbun 是用 PHP 编写的多进程网络爬虫框架，具有良好的开放性、高可扩展性

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
