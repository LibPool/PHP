# primefaceshero/mobile-traffic-meter

> 标签: PHP

## 简介

Mobile Traffic Meter - Package that allows to obtain the traffic by views of a mobile application for reporting

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
