# rumd3x/php-ftp

> 标签: client, ftp, php, php-ftp, rumd3x

## 简介

A Nice and easy to use PHP utility for handling Files over FTP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
