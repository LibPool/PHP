# pomander/symfony2

> 标签: Symfony2, deploy, git, pomander, svn

## 简介

Pomander plugin to deploy and manage Symfony2 sites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
