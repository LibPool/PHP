# lorddashme/php-mailchimp

> 标签: api, mailchimp, marketing, php, subscriber

## 简介

A PHP package wrapper for MailChimp API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
