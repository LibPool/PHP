# lorddashme/php-gnupg-simple-tool

> 标签: cryptography, encryption, gnupg

## 简介

A simple PHP tool to manage GnuPG commands.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
