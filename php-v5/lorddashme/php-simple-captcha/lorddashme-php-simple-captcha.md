# lorddashme/php-simple-captcha

> 标签: Simple, captcha, github, php, security

## 简介

A simple captcha package that suite to any type of web application built on php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
