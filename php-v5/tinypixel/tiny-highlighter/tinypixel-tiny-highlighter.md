# tinypixel/tiny-highlighter

> 标签: blade, blocks, gutenberg, laravel, template, wordpress

## 简介

Inline highlighting plugin for WordPress 5 block editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
