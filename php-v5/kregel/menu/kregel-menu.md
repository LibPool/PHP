# kregel/menu

> 标签: automatic-menu, generate-menu, laravel, menu

## 简介

This will automatically build/ generate a menu based upon your configuration file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
