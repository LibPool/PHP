# vincentvete/tcpdi

> 标签: TCPDF, fpdi, pdf, tcpdi

## 简介

PDF importer for TCPDF based on FPDI (supports optimized PDF 1.5+)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
