# agielks/yii2-log-json

> 标签: extension, json, log, logstash, redis, yii2

## 简介

Convert your yii2 application logs as json and save it to file, redis, or logstash

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
