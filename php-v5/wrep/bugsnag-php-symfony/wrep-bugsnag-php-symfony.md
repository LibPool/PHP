# wrep/bugsnag-php-symfony

> 标签: bugsnag, exceptions, logging

## 简介

An integration bundle for the bugsnag-php module into the Symfony2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
