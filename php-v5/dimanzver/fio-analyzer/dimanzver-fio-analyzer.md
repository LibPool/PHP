# dimanzver/fio-analyzer

> 标签: analyze, names, russian, split

## 简介

Analyze user input string, and split it into Russian first name, second name and last name

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
