# simexis/oembed

> 标签: laravel, laravel-oembed, oembed, simexis

## 简介

Laravel 5 - Retrieve page info using oembed, opengraph, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
