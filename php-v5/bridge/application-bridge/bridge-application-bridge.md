# bridge/application-bridge

> 标签: builder, dispatcher, framework, openapi, route, slim, swagger

## 简介

standard Application bridge to interface with frameworks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
