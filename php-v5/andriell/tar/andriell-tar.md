# andriell/tar

> 标签: archive, compression, tar, tar.gz

## 简介

Tar / tar.gz writer. You can use it to work with large files without creating temporary files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
