# estey/laravel-react-middleware

> 标签: laravel, middleware, react, reactjs, server-side rendering

## 简介

Middleware for React.js server-side rendering in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
