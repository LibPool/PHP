# dataworkstr/apiclient

> 标签: google

## 简介

Client library for Google APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://developers.google.com/api-client-library/php
- 源码仓库：https://github.com/dataworkstr/google-api-php-client.git
- Packagist 页面：https://packagist.org/packages/dataworkstr%2Fapiclient
