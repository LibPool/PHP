# multidimensional/cakephp-seaff

> 标签: cakephp, cakephp3, shopify

## 简介

Shopify Embedded App Frontend Framework (SEAFF) for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
