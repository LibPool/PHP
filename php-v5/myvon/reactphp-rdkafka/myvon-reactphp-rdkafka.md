# myvon/reactphp-rdkafka

> 标签: kafka, myvon, rdkafka, reactphp, reactphp-kafka

## 简介

RdKafka Consumer and Producer implementation with ReactPHP Event Loop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
