# darkdrim/yii2-simplehtmldom

> 标签: curl, dom, extension, parse, parser, simple_html_dom, simplehtmldom, yii, yii2

## 简介

Simple HTML Dom parser for Yii2 + cURL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
