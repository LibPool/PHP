# mickmelon/flarum-ext-coloured-usernames

> 标签: design, extension, flarum, groups

## 简介

Set the username colour to the same as the rank colour (only on posts)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
