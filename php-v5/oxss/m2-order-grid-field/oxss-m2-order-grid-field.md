# oxss/m2-order-grid-field

> 标签: PHP

## 简介

This module will add the "Coupon Code" column to the admin order grid. This new column will be searchable and filterable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
