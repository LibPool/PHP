# whisperbuddy/whisperbuddy-php

> 标签: viral, whisperbuddy

## 简介

PHP library for whisperbuddy.com's Lead and Listener

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
