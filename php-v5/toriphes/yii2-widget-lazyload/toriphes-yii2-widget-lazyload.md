# toriphes/yii2-widget-lazyload

> 标签: extension, image, lazyload, widget, yii2

## 简介

wrapper of http://www.appelsiini.net/projects/lazyload jquery library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
