# deselbi/php-jira-rest-client

> 标签: jira, jira-php, jira-rest, rest

## 简介

JIRA REST API Client for PHP Users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
