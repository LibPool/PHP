# mattcg/cjsdelivery

> 标签: commonjs, compiler, javascript, modules

## 简介

Deliver CommonJS-syntax JavaScript modules to clients as a single file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
