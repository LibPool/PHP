# aydin-hassan/php-git-hooks

> 标签: PHP

## 简介

Some simple git hooks to run a variety of PHP analysis tools, including PHPUnit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
