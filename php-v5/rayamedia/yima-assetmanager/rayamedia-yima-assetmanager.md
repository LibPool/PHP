# rayamedia/yima-assetmanager

> 标签: asset, asset manager, zend framework 2, zf2

## 简介

An assetmanager module for Zend Framework 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
