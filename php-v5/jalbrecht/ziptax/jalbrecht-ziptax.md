# jalbrecht/ziptax

> 标签: postal code, tax, tax rate, vutran, zip-tax, zipcode

## 简介

A PHP wrapper for the zip-tax.com API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/jalbrecht/ziptax.git
