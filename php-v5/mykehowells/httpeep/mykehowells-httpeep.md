# mykehowells/httpeep

> 标签: api, client, http, httpeep, php, request, response, rest

## 简介

PHP HTTP client for API endpoint/resource requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
