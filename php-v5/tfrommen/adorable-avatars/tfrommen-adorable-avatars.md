# tfrommen/adorable-avatars

> 标签: avatar, image, profile, user

## 简介

This plugin integrates the Adorable Avatars avatar placeholder service into WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
