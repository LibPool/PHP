# udir-moodle/tool_mergeusers

> 标签: PHP

## 简介

Merge user accounts — Composer/Packagist mirror of the Moodle plugin tool_mergeusers, auto-updated from the Moodle plugins directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
