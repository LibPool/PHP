# soprex/findologic-test-lib

> 标签: findologic-test, soprex-findologic

## 简介

Base library for unit testing FINDOLOGIC shop modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
