# kattsoftware/phassets-amazon-s3-deployer

> 标签: PHP

## 简介

Amazon (AWS) S3 deployer for Phassets lib.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
