# satoripophq/codeigniter-composer

> 标签: Satoripop, codeigniter, composer, installer

## 简介

Package to install The CodeIgniter framework 3 via Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
