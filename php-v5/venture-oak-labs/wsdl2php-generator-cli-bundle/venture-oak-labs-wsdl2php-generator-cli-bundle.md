# venture-oak-labs/wsdl2php-generator-cli-bundle

> 标签: bundle, command, console, symfony, wsdl2phpgenerator

## 简介

Bundle to integrate Console Client for wsdl2phpgenerator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
