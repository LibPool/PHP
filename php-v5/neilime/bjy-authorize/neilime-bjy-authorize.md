# neilime/bjy-authorize

> 标签: acl, zf2, zfc-user

## 简介

Zend\Acl based firewall system for ZF2 dispatch protection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
