# rollerworks/breadcrumbs-bundle

> 标签: PHP

## 简介

Easy breadcrumbs navigation for Symfony powered applications (Not the Symfony FrameworkBundle)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
