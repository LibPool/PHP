# armankt/pdohunt

> 标签: builder, pdo, php, query, sql

## 简介

Powerfull Query Builder, A Built in PDO Class for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
