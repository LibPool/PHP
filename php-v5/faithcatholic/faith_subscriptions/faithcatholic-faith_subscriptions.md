# faithcatholic/faith_subscriptions

> 标签: PHP

## 简介

The Faith Subscriptions theme is a custom theme that is based on the core Stark theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
