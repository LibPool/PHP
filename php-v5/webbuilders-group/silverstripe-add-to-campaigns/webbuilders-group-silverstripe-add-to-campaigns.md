# webbuilders-group/silverstripe-add-to-campaigns

> 标签: campaigns, silverstripe

## 简介

Capability to add any Versioned object to a campaign easily for CMS Admins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
