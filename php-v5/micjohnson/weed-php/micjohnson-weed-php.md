# micjohnson/weed-php

> 标签: blob, client, clob, image storage, weedfs

## 简介

PHP client for Weed-FS, a simple and highly scalable distributed file system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
