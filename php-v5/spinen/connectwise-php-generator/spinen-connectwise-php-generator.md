# spinen/connectwise-php-generator

> 标签: api, connectwise, library, spinen

## 简介

Generates the php library for ConnectWise from their WSDL's and contains a client to consume the library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
