# yippy/flarum-tag-with-themes

> 标签: base, flarum, tag, themes

## 简介

Provide multiple themes choices for discussion layout by tag.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
