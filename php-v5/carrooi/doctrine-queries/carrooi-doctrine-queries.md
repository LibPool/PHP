# carrooi/doctrine-queries

> 标签: builder, carrooi, database, doctrine, query

## 简介

Builder for doctrine query builders based on kdyby/doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
