# kenvix/curl

> 标签: curl

## 简介

A very lite and high compatibility but powerful curl class(especially you're processing http headers and cookies). No dependence.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
