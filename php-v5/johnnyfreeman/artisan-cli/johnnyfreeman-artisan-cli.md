# johnnyfreeman/artisan-cli

> 标签: artisan, artisan-cli, global, laravel

## 简介

A global command line tool for Laravel's Artisan.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
