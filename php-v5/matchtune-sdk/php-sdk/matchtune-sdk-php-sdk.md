# matchtune-sdk/php-sdk

> 标签: matchtune, music, sdk

## 简介

A framework library to access MatchTune API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.matchtune.com/
- 源码仓库：https://github.com/matchtune-sdk/php-sdk.git
- Packagist 页面：https://packagist.org/packages/matchtune-sdk%2Fphp-sdk

## 历史版本号

- 当前版本：1.0

- 1.0

## 获取地址

- Composer 安装：`composer require matchtune-sdk/php-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/matchtune-sdk/php-sdk.json
- 许可证：proprietary
- PHP 要求：>=5.3.0
