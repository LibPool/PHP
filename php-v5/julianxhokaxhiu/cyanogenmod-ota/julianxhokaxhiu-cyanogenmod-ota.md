# julianxhokaxhiu/cyanogenmod-ota

> 标签: android, cyanogenmod, lineageos, ota, php, rest

## 简介

A simple OTA REST Server for LineageOS OTA Updater System Application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
