# sunaryohadi/ezsql-mysqli

> 标签: PHP

## 简介

Fork ezSQL, just for mysqli. With additional prepare() function from WPdb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
