# kingsoft/persist

> 标签: PHP

## 简介

Make persistance easy and fast. Use it to store data in files, databases, or any other storage system. It's easy to use and extend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
