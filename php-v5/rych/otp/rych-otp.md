# rych/otp

> 标签: hotp, oath, otp, rfc4226, rfc6238, security, totp

## 简介

PHP implementation of the OATH one-time password standards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
