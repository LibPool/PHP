# yakubenko/easyform

> 标签: PHP

## 简介

Библиотека, которая позволяет создать правила валидации для любой формы и выполнить необходимые триггеры при ее успешной отправке.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
