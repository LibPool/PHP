# tburschka/phpseclib-bridge

> 标签: php, phpseclib, scp, sftp, ssh

## 简介

Bridge to simplify usage of phpseclib

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
