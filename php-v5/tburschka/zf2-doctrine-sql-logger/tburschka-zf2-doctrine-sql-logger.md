# tburschka/zf2-doctrine-sql-logger

> 标签: doctrine, log, sql, zf2

## 简介

Logs Doctrine DBAL queries with a Zend Log.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
