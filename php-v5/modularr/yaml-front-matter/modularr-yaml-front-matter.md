# modularr/yaml-front-matter

> 标签: frontmatter, metadata, parser, parsing, php

## 简介

YAML-FrontMatter is a simple to use PHP only FrontMatter type parser Library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
