# fduch2k/yii-sms-manager

> 标签: atompark, epochta, sms, smsfeedback, yii

## 简介

Yii Component for sending SMS with gateway balancing and events for low balance alert

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
