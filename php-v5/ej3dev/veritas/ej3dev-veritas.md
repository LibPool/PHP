# ej3dev/veritas

> 标签: PSR-4, ej3, ej3dev, validation, validator, verification, verifier, veritas

## 简介

A pragmatic and concise validation library written in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
