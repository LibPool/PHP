# ptphp/ptphp

> 标签: framework, ptphp

## 简介

a simple php framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/ptphp/ptphp.git
