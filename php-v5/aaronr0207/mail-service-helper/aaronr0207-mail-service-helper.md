# aaronr0207/mail-service-helper

> 标签: PHP

## 简介

Helper para enviar correos electrónicos haciendo uso de un microservicio externo a través de GuzzleHttp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
