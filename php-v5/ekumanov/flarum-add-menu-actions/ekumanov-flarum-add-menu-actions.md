# ekumanov/flarum-add-menu-actions

> 标签: discussion controls, flarum, flarum-extension

## 简介

Add Ignore, Read/Unread and other actions to Discussion Controls

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
