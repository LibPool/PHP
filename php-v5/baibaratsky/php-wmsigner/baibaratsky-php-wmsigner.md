# baibaratsky/php-wmsigner

> 标签: WMXI, signer, webmoney, wmsigner

## 简介

WebMoney Signer: a native PHP implementation of the WMSigner module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
