# baibaratsky/php-mailgun

> 标签: email, mail, mailgun, mailing lists, yii, yii2

## 简介

Mailgun API PHP library and Yii extension (as well as Yii2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
