# devless/php-sdk

> 标签: Devless, php, sdk

## 简介

Official Devless SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://devless.io
- 源码仓库：https://github.com/DevlessTeam/DV-PHP-SDK.git
- Packagist 页面：https://packagist.org/packages/devless%2Fphp-sdk

## 获取地址

- Composer 安装：`composer require devless/php-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/devless/php-sdk.json
- 许可证：APACHE 2.0
- PHP 要求：>=5.5.9
