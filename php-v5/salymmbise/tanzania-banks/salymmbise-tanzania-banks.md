# salymmbise/tanzania-banks

> 标签: PHP

## 简介

A PHP library for listing all banks in Tanzania, their branches and SWIFT Codes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
