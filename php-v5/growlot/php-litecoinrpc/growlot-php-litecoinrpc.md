# growlot/php-litecoinrpc

> 标签: Guzzle, api, jsonrpc, litecoin, ltc

## 简介

Litecoin JSON-RPC client based on GuzzleHttp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
