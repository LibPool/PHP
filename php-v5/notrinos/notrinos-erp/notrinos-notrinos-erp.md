# notrinos/notrinos-erp

> 标签: Accounting, ERP, mysql, php

## 简介

A web-based erp, accounting system that written in PHP and MySql

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
