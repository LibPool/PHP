# yiivgeny/yii-phpdoc-crontab

> 标签: cron, crontab, schedule, yii

## 简介

Simple and convenient installing console commands as cron jobs for Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
