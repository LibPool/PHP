# archintel-dev/laravel-ses

> 标签: PHP

## 简介

Allows you to track opens, deliveries, bounces, complaints and clicked links when sending emails through Laravel and Amazon SES. Credits to Oliver Eady <oliveready7@gmail.com>.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
