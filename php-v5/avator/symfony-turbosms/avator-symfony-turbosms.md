# avator/symfony-turbosms

> 标签: bundle, sms, symfony, symfony turbosms

## 简介

Symfony2/3 send sms from Turbosms.ua by SOAP Edit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
