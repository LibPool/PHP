# terramar/resque-bundle

> 标签: php, resque

## 简介

A fork of BCCResqueBundle, provides integration with php-resque and Symfony2 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
