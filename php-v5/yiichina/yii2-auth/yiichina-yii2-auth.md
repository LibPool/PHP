# yiichina/yii2-auth

> 标签: auth, extension, yii2

## 简介

Yii2 中使用第三方登录扩展，包括：微博，QQ，微信，百度等

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
