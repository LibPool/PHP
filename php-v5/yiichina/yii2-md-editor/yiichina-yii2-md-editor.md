# yiichina/yii2-md-editor

> 标签: editor, extension, markdown, yii2

## 简介

Yii2 中使用 Markdown 在线文本编辑器

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
