# sl0wik/laravel-scout-elasticsearch-driver

> 标签: elastic, elasticsearch, laravel, scout

## 简介

Elasticsearch Driver for Laravel Scout with multi-index support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
