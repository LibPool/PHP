# taylornetwork/encrypter

> 标签: PHP

## 简介

A custom encrypter class that uses Laravel's Encrypter class with a custom key instead of the application key.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
