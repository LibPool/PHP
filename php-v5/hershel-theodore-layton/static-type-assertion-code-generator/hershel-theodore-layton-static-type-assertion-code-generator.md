# hershel-theodore-layton/static-type-assertion-code-generator

> 标签: PHP

## 简介

Codegen functions equivalent to type testing `as` expressions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
