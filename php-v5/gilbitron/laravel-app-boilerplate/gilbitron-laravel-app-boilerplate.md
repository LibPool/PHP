# gilbitron/laravel-app-boilerplate

> 标签: boilerplate, laravel

## 简介

A Laravel 4 boilerplate package for creating web apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
