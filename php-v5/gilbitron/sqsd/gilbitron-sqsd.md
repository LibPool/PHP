# gilbitron/sqsd

> 标签: aws, daemon, sqs, sqsd, worker

## 简介

A replica of the AWS Elastic Beanstalk worker SQS daemon (sqsd) in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
