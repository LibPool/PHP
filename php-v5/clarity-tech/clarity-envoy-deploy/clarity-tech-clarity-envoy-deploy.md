# clarity-tech/clarity-envoy-deploy

> 标签: PHP

## 简介

Deployment scripts for envoy standard zero deployments along with gitlab templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
