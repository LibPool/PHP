# fadion/maneuver

> 标签: deployment, ftp, git, laravel, ssh

## 简介

Easily deploy Laravel projects via FTP or SFTP, using Git for versioning.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
