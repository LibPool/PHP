# smarteng/yii2-daterange-picker

> 标签: daterangepicker, extension, smarteng, widget, yii2

## 简介

DateRangePicker widget for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
