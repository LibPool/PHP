# sealink/craft-cpcss

> 标签: PHP

## 简介

Craft Plugin that easily overwrites the default Control Panel styles, can help with Redactor styling.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
