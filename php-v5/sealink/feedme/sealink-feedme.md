# sealink/feedme

> 标签: PHP

## 简介

Craft plugin to make it easy to import entries and entry data from XML, RSS, ATOM or JSON feeds.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
