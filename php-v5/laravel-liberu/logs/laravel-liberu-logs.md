# laravel-liberu/logs

> 标签: laravel-liberu, laravel-logs, log-manager, logs

## 简介

Log management dependency for Laravel Liberu

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
