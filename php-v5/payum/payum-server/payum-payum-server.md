# payum/payum-server

> 标签: PHP

## 简介

PHP 5.3+ Payment micro service. Setup once and rule them all: Paypal, Stripe, Payex, Authorize.NET, Be2bill, Klarna, IPNs...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
