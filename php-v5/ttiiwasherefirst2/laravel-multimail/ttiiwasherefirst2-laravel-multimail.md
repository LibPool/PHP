# ttiiwasherefirst2/laravel-multimail

> 标签: emails, laravel, multiple providers

## 简介

A package to send mails easily from multiple mail accounts with Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
