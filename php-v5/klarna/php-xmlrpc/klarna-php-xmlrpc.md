# klarna/php-xmlrpc

> 标签: PHP

## 简介

PHP SDK for Klarna's XMLRPC API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://developers.klarna.com
- 源码仓库：https://github.com/klarna/php-xmlrpc.git
- Packagist 页面：https://packagist.org/packages/klarna%2Fphp-xmlrpc
