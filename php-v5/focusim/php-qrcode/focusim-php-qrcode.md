# focusim/php-qrcode

> 标签: phpqrcode, qr, qr code, qrcode, qrcode-generator

## 简介

A QR code generator. PHP 8.1+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
