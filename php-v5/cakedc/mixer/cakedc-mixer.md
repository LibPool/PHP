# cakedc/mixer

> 标签: Skeleton, cakephp, discovery, generate, mixer, plugin, update

## 简介

A plugin to discover and manage CakePHP plugins and generate skeleton application code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
