# lemonway/php-sdk

> 标签: Lemon Way, LemonWay, marketplace, payment, wallet

## 简介

PHP SDK for Lemon Way API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
