# zymeli/yii2-rbac-activerecord-manager

> 标签: extension, manager, rbac, yii2

## 简介

ActiveRecord support for Yii2 application RBAC Manager.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
