# ppeev/glechats

> 标签: GleChatS, Google-Chat, google chat, web-hook, webhook

## 简介

Small library for posting messages to Google Chat, using their webhooks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
