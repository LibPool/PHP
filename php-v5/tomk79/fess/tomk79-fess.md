# tomk79/fess

> 标签: PHP

## 简介

FESS は、一般的によく利用されるCSSドキュメントモジュールを集めた、基本定義集です。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
