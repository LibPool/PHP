# tomk79/diffdir

> 标签: PHP

## 简介

2つのディレクトリを比較し、検出された差分をレポートしてくれるコマンドです。ライブラリとしても利用できます。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
