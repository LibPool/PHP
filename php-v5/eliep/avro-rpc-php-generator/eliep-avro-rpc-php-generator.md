# eliep/avro-rpc-php-generator

> 标签: avro, rpc, serialization

## 简介

This library generates an Avro RPC client based on eliep/avro-rpc-php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
