# moodev/weasel

> 标签: deserialization, jackson, json, marshall, marshalling, serialization

## 简介

Object marshalling library for PHP supporting JSON and XML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
