# jb/api-yahoo-weather

> 标签: weather, yahoo api

## 简介

A library to call Yahoo Weather Api. Just give the woeid code which correspond of your city

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
