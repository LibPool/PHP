# daniel-de-wit/laravel-model-active

> 标签: eloquent, laravel

## 简介

Simple trait for scoping Eloquent models by 'active' boolean

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
