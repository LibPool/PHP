# wienkit/bol-plaza-php-client

> 标签: Bol.com, api, bol, php, plaza

## 简介

A PHP Client for the BOL.com Plaza API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
