# five-say/laravel-model-ext-trait

> 标签: model, observer, validate

## 简介

基于 trait 的 laravel 模型特性拓展：自动注册模型观察者；创建与更新数据前，自动校验请求数据。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
