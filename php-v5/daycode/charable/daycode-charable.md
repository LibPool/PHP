# daycode/charable

> 标签: PHP

## 简介

Get expected return value from char such as Alphabetic, Alphanumeric, Digit, Upper and Lower Case

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
