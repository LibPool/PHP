# nitsan/ns-statcounter

> 标签: TYPO3 CMS, counter, nitsan, ns_statcounter, stat

## 简介

Statcounter extension brings you all the powerful StatCounter.com (free real time visitor stats) features to your TYPO3 site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
