# nitsan/ns-license

> 标签: TYPO3 CMS, bootstrap, frontend, license, ns, responsive, template, theme

## 简介

License Manager — activate and manage licenses for T3Planet TYPO3 templates and extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
