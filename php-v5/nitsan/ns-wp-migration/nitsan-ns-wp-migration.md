# nitsan/ns-wp-migration

> 标签: TYPO3 CMS, blog, migration, news, nitsan, wordpress

## 简介

TYPO3 WordPress Migration Tool - Plug-n-play TYPO3 extension to migrate wordpress page and page data to your TYPO3 site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
