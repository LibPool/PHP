# jjpmann/ee-addons

> 标签: addons, eecms, extensions, fieldtypes, modules

## 简介

Base addons builder for ExpressionEngine 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
