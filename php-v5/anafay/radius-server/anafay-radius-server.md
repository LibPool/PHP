# anafay/radius-server

> 标签: PHP

## 简介

Implementation of RADIUS server: both authorization and accounting (RFC 2865, 2866, 2867)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
