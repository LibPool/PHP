# chilldev/file-manager-bundle

> 标签: Symfony2, chilldev, file manager, files, filesystem

## 简介

File manager bundle for Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
