# globalis/wp-unhooked

> 标签: admin, clean, disable, optimize, unhook, wordpress, wp

## 简介

Unhook things we don't want from WordPress core

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
