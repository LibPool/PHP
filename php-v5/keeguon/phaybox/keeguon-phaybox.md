# keeguon/phaybox

> 标签: paybox

## 简介

Phaybox is a small library wrote in PHP allowing e-commerce website to interact easily with the Paybox API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
