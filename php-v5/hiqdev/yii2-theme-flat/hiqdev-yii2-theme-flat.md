# hiqdev/yii2-theme-flat

> 标签: extension, flat, theme, yii2

## 简介

Flat Theme for hiqdev/yii2-thememanager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
