# hiqdev/yii2-asset-datatables

> 标签: asset, datatables, extension, yii2

## 简介

Yii2 asset for DataTables jQuery plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
