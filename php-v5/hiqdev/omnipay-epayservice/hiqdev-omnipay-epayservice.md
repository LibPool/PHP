# hiqdev/omnipay-epayservice

> 标签: epayservice, merchant, omnipay, payment, php

## 简介

ePayService driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
