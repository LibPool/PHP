# hiqdev/omnipay-bitpay

> 标签: bitpay, merchant, omnipay, payment, php

## 简介

BitPay driver for Omnipay PHP payment libray

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
