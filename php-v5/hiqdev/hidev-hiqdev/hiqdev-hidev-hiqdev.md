# hiqdev/hidev-hiqdev

> 标签: config, hidev, hiqdev, vendor

## 简介

HiDev plugin for HiQDev vendor configuration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
