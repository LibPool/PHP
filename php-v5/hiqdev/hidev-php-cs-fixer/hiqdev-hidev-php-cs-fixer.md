# hiqdev/hidev-php-cs-fixer

> 标签: hidev, php-cs-fixer, plugin

## 简介

HiDev plugin for PHP-CS-Fixer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
