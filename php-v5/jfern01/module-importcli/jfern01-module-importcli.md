# jfern01/module-importcli

> 标签: PHP

## 简介

A console command for importing catalog files. Based on cedricblondeau/magento2-module-catalog-import-command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
