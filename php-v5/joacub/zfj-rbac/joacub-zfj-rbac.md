# joacub/zfj-rbac

> 标签: module, permissions, rbac, zf2

## 简介

Zend Framework 2 Module that provides a layer of features of Zend\Permissions\Rbac

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
