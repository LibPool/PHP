# vlaim/yii2-file-upload

> 标签: aws, file, s3, upload, yii, yii 2, yii2

## 简介

Yii2 FileUpload – PHP library for uploading files to local server or Amazon S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
