# willemabc/deep-copy-debugger

> 标签: PHP

## 简介

DeepCopy is powerful, but hard to debug. The DeepCopyDebugger makes it easier to spot incorrect or missing filters.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
