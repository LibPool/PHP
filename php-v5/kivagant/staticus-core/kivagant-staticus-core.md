# kivagant/staticus-core

> 标签: api, file, generator, manager

## 简介

The core part of Staticus Project. See more in the kivagant/staticus project on the GitHub.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
