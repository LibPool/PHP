# codemommy/cookiephp

> 标签: CodeMommy, CookiePHP, php

## 简介

CodeMommy CookiePHP is a cookie helper for web development under license Apache 2.0. It helps you to operate cookie easily.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
