# floppy/client

> 标签: file, file storage, file upload, filesystem, image

## 简介

Floppy is a file storage library. This library allows you to upload files to FloppyServer instance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
