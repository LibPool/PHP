# labs7in0/omnipay-wechat

> 标签: gateway, merchant, omnipay, pay, payment, purchase, wechat

## 简介

WeChat driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
