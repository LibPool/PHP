# nswdpc/silverstripe-linkfield

> 标签: cms, link, modular, silverstripe

## 简介

Adds a link field for nswdpc/silverstripe-link

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
