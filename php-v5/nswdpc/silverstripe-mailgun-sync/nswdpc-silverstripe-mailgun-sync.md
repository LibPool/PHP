# nswdpc/silverstripe-mailgun-sync

> 标签: email, mail, mailgun, mime, silverstripe

## 简介

Send messages via Mailgun and synchronise with Mailgun Events API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
