# nswdpc/silverstripe-elemental-iframe

> 标签: elemental, iframe, nsw, silverstripe

## 简介

Elemental iframe module, supports lazy loading of iframes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
