# sandstorm/mxgraph

> 标签: PHP

## 简介

Integrate Diagrams.net / Draw.io into Neos as Node Type for creating interactive diagrams and flowcharts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
