# sandstorm/neosh5p

> 标签: Neos, h5p, lms, lrs, neos plugin, rich content

## 简介

H5P Platform Integration Plugin for Neos CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
