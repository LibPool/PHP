# fm/swift-bundle

> 标签: Openstack, cdn, keystone, object-store, swift

## 简介

Implementation of the OpenStack Swift protocol. Can be used for an object-store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
