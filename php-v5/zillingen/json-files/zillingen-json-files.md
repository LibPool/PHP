# zillingen/json-files

> 标签: boltcms, files, json, rest

## 简介

The Bolt CMS extension allows upload files via POST multipart/form-data requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
