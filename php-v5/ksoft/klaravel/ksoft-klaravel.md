# ksoft/klaravel

> 标签: PHP

## 简介

Laravel control panel for developers, comes with integrated Scaffold generator, backups, logs, and built in instructions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
