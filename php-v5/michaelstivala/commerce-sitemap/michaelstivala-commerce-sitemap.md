# michaelstivala/commerce-sitemap

> 标签: Craft, Sitemap, cms, craft commerce, craft-plugin, craftcms, seo, sitemap.xml, webmaster tools

## 简介

Craft 3 plugin that provides an easy way to provide and manage a sitemap supporting Craft Commerce products.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
