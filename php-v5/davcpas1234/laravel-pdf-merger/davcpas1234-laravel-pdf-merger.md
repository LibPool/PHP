# davcpas1234/laravel-pdf-merger

> 标签: grofgraf, laravel, merger, pdf, pdf-merger, pdfmerger

## 简介

Package for Laravel that merges multiple PDFs into one.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
