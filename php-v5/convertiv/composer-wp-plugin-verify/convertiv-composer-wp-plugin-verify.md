# convertiv/composer-wp-plugin-verify

> 标签: composer-plugin, installer

## 简介

Verifies installed wp plugins according to the directy path given in composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
