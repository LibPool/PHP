# unicodeveloper/laravel-wikipedia

> 标签: laravel, laravel-wikipedia, php, unicodeveloper, wikipedia

## 简介

Laravel Bridge for Wikipedia

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
