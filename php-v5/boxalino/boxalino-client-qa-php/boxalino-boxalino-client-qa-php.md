# boxalino/boxalino-client-qa-php

> 标签: boxalino, php-unit, qa

## 简介

The Boxalino QA SDK provides a simple and efficient way of testing the  Boxalino Search & Recommendations services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
