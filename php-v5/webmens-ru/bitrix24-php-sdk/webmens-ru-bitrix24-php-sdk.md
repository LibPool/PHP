# webmens-ru/bitrix24-php-sdk

> 标签: Bitrix24, api, php, rest

## 简介

A powerfull PHP library for the Bitrix24 REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
