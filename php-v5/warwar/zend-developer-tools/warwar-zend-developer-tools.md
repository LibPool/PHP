# warwar/zend-developer-tools

> 标签: ZendFramework, debug, developer, module, zf

## 简介

Module for developer and debug tools for use with zend-mvc applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
