# mg-code/yii2-intl-js

> 标签: Internationalization API, asset, extension, intl, intl.js, javascript, yii2

## 简介

Yii2 wrapper for popular JavaScript andyearnshaw/Intl.js library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
