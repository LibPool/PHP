# den67rus/yii2-sypexgeo

> 标签: geo, geoip, geolocation, sypexgeo, yii2

## 简介

Yii2 extension for Sypex Geo API (http://sypexgeo.net)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
