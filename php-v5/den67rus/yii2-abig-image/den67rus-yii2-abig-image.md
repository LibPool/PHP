# den67rus/yii2-abig-image

> 标签: ABigImage, extension, widget, yii2

## 简介

This is widget wrapper of ABigImage https://github.com/makryl/ABigImage for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
