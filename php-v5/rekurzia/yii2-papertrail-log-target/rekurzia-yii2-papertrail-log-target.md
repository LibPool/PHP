# rekurzia/yii2-papertrail-log-target

> 标签: log, papertrail, target, yii2

## 简介

Minimal implementation of Yii2 log target sending messages to Papertrail

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
