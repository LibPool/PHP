# basemax/phpas

> 标签: parsers, tools, utilities

## 简介

PHP Auto Style: A tool for format and beautify the style of PHP code with my style.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
