# credit-union-2-0-llc/laravel-azure-ad-oauth

> 标签: PHP

## 简介

Provides single-sign-on ability to Microsoft Azure Active Directory enabled apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
