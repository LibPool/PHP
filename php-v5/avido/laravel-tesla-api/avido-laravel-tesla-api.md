# avido/laravel-tesla-api

> 标签: api, laravel, php, tesla

## 简介

Laravel Tesla Api Client Wrapper for https://packagist.org/packages/avido/tesla-api-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
