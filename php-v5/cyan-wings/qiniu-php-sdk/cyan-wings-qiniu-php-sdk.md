# cyan-wings/qiniu-php-sdk

> 标签: cloud, laravel 12, qiniu, sdk, storage

## 简介

Qiniu Cloud Storage PHP SDK supports Laravel 12

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
