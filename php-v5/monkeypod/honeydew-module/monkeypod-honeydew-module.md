# monkeypod/honeydew-module

> 标签: PHP

## 简介

Create and assign tasks, optionally associated with specific MonkeyPod records (e.g., transactions or relationships)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
