# elcodedocle/openpgpjs

> 标签: PGP, aes, gpg, openpgp, rsa

## 简介

GnuPG compatible Javascript client library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
