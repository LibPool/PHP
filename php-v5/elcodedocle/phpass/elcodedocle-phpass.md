# elcodedocle/phpass

> 标签: bcrypt, password hashing, password salting, password_hash, password_verify, phpass, rainbow attack protection, secure password storage

## 简介

fork of Solar Designer's http://www.openwall.com/phpass/ with enhanced security updates

按 require.php 推断最低支持 PHP 3；已收录于 php-v5, php-v7, php-v8。
