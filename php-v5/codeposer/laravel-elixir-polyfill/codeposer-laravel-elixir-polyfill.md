# codeposer/laravel-elixir-polyfill

> 标签: codeigniter, codeposer, laravel-elixir

## 简介

Laravel Elixir Polyfill for CodePoser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
