# dorsetdigital/silverstripe-simpleinstagram

> 标签: instagram, silverstripe, social

## 简介

Retrieves the Instagram feed for a given user for embedding in a template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
