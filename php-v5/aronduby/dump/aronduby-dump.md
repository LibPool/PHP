# aronduby/dump

> 标签: debug, debugging, dump, krumo, pretty, print, print_r, var_dump

## 简介

D::ump - a PHP 5.4 print_r/var_dump replacement base on Krumo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
