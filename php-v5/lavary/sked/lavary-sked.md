# lavary/sked

> 标签: Laravel Task Scheduler, PHP Task Scheduler, Task Scheduler, cron, cron jobs, scheduler

## 简介

Schedule your tasks right from the code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
