# ejen/yii2-datetime-behavior

> 标签: Behavior, date, datetime, time, yii2

## 简介

Yii2 extension for saving datetime in given format

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
