# cviebrock/guzzle-stripbom-plugin

> 标签: Guzzle, bom, json, plugin, xml

## 简介

Plug-in for Guzzle that strips BOMs from server responses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
