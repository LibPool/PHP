# christymcgrory/es-wp-query

> 标签: PHP

## 简介

A drop-in replacement for WP_Query to leverage Elasticsearch for complex queries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
