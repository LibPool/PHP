# trupedia/laravel-blade-haml

> 标签: HAML, blade, laravel

## 简介

Wraps MtHaml for ease use in Laravel 5 with Blade syntax style

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
