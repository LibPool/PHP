# wasiliana/laravel-sdk

> 标签: LaravelSdk, laravel

## 简介

This package is built to make it easier to interact with Wasiliana Api for Laravel developers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
