# petercoles/cluster-manager

> 标签: cloud management, cluster management, php, server monitoring

## 简介

Manage, scale and contract server clusters with PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
