# uegmobile/uuid-twig-extension-bundle

> 标签: bundle, symfony, twig, uuid

## 简介

Symfony twig extension bundle to use uuid function (based on ramsey/uuid bundle)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
