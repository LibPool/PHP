# yii-ext/yii-easyimage

> 标签: cache, extension, image, realtime, thumbnail, yii

## 简介

Yii Framework extension for easy creating and caching thumbnails on real time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
