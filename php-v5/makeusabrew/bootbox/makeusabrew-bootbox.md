# makeusabrew/bootbox

> 标签: PHP

## 简介

Wrappers for JavaScript alert(), confirm() and other flexible dialogs using the Bootstrap framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
