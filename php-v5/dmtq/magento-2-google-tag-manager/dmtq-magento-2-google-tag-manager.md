# dmtq/magento-2-google-tag-manager

> 标签: PHP

## 简介

Magento2 google tag manager module, A simple, clear and fully functional GA module. Compatible with breeze theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
