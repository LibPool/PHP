# matthiasbayer/datadog-client

> 标签: DataDog, client, http, standalone

## 简介

Standalone DataDog PHP Client, works without datadog agent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
