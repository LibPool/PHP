# rayful/pagination

> 标签: PHP

## 简介

A Library for Pagination, interagted in DB-Manager. Can be extended to change display, can See ViewBase Class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
