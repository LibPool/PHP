# esler/phpunit-graceful-interrupt

> 标签: graceful, interrupt, phpunit

## 简介

Allow gracefully interrupt running PHPUnit tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
