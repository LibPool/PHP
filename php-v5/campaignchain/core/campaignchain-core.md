# campaignchain/core

> 标签: campaignchain

## 简介

Core bundle of CampaignChain.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://www.campaignchain.com
- 源码仓库：https://github.com/CampaignChain/core.git
- Packagist 页面：https://packagist.org/packages/campaignchain%2Fcore

## 获取地址

- Composer 安装：`composer require campaignchain/core`
- Packagist 仓库：https://repo.packagist.org/p2/campaignchain/core.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4
