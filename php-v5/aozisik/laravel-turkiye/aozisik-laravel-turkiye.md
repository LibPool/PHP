# aozisik/laravel-turkiye

> 标签: PHP

## 简介

Türkiye için geliştirilen Laravel uygulamalarınıza yardımcı olan paket

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
