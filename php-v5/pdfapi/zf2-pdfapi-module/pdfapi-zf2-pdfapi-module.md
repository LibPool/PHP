# pdfapi/zf2-pdfapi-module

> 标签: PHP

## 简介

Zend Framework 2 module for converting PDF documents via pdfapi.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://pdfapi.io/
- 源码仓库：https://github.com/pdfapi/zf2-pdfapi-module.git
- Packagist 页面：https://packagist.org/packages/pdfapi%2Fzf2-pdfapi-module
