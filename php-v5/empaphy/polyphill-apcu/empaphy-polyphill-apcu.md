# empaphy/polyphill-apcu

> 标签: apcu, compatibility, polyfill, portable, shim

## 简介

A metapackage that installs an APCU polyfill if needed, or removes it if redundant.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
