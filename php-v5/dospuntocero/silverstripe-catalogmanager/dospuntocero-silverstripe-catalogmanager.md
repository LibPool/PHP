# dospuntocero/silverstripe-catalogmanager

> 标签: PHP

## 简介

Catalog Manager provides extension for ModelAdmin editing of SiteTree instances

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
