# rundiz/data-table

> 标签: data table, datatable, folded table, list table, responsive data table, responsive list table, table data

## 简介

The data table class for listing data in the table.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
