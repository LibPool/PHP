# rundiz/thai-date

> 标签: Thai date, date, date thai, date translation, datethai, thaidate

## 简介

Display date in Thai language use PHP date() and strftime()

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
