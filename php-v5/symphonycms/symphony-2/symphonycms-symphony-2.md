# symphonycms/symphony-2

> 标签: PHP

## 简介

Symphony is a PHP & MySQL based CMS that utilises XML and XSLT as its core technologies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
