# wwwision/neos-creationdialogproperties

> 标签: PHP

## 简介

Simple package to easily expose Node properties to the CreationDialog that's available since Neos 3.3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
