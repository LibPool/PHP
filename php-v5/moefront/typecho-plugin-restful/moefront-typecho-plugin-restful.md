# moefront/typecho-plugin-restful

> 标签: typecho, typecho plugin

## 简介

Yet another awesome Typecho plugin to make your blog RESTful.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
