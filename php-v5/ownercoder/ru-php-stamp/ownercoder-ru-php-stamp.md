# ownercoder/ru-php-stamp

> 标签: docx, template, word

## 简介

A library for true XSL-way templating of XML-based Office documents. Supports MS Word docx.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
