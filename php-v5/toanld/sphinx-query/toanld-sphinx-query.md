# toanld/sphinx-query

> 标签: database, query builder, search, sphinx, sphinxql, sql

## 简介

A PHP query builder for SphinxQL. Uses MySQLi to connect to the Sphinx server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
