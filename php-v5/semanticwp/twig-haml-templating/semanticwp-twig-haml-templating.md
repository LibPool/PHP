# semanticwp/twig-haml-templating

> 标签: HAML, semantic, templating, twig, wordpress

## 简介

Twig templating for WordPress, using HAML syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
