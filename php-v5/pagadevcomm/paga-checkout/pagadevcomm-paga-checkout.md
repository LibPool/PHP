# pagadevcomm/paga-checkout

> 标签: Paga, Payment authorization, api, bank card, credit card, ecommerce, magento, magento 2, magento extension, payment, payment gateway, payment integration

## 简介

A Magento 2 module that is used for making payments via paga payment gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
