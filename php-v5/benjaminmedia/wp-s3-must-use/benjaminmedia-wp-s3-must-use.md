# benjaminmedia/wp-s3-must-use

> 标签: plugin, s3, wp

## 简介

Automatically Enables and configures the WP Offload S3 module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
