# benjaminmedia/bbpress-exif-lightbox

> 标签: bbPress, exif, lightbox, plugin, wordpress

## 简介

Displays exif data within a lightbox

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
