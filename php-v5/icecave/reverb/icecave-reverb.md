# icecave/reverb

> 标签: dead, deadlock, doctrine, lock, optimistic, pessimistic, retry, transaction, transactional

## 简介

A transaction executor for the Doctrine ORM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
