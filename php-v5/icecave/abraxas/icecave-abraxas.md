# icecave/abraxas

> 标签: crypto, generate, generation, generator, passphrase, password, random

## 简介

Generate random passwords using a cryptographically secure RNG.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
