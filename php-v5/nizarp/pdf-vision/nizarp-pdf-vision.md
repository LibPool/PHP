# nizarp/pdf-vision

> 标签: convert, google-cloud-vision, nizarp, pdf, pdf-vision, text

## 简介

Convert PDF file to text using Google Vision API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
