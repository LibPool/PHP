# demi/yii2-gii-migrations-gui

> 标签: generator, gii, migration, yii2

## 简介

Generate Yii2 database migrations in the gii interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
