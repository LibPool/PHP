# zulfajuniadi/php-rest-server

> 标签: PHP

## 简介

Plug and Play PHP Rest Server. Just download and run. Supports Backbone.js out of the box.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
