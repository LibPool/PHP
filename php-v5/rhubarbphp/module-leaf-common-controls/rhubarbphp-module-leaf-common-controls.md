# rhubarbphp/module-leaf-common-controls

> 标签: framework, leaf, mvp, php, presenter, rhubarb

## 简介

Common form control leaves for the leaf module of Rhubarb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
