# rhubarbphp/module-leaf-html5upload

> 标签: HTML5, framework, leaf, mvp, php, presenter, rhubarb, upload

## 简介

Leaf patterns for HTML 5 uploads.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
