# rhubarbphp/scaffold-authentication

> 标签: Authentication, framework, php, rhubarb

## 简介

Provides some an out of the box solution for login and authentication.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
