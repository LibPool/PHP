# rhubarbphp/scaffold-application-settings

> 标签: Settings, framework, php, rhubarb

## 简介

Stores system wide application settings in the default repository.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
