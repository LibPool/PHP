# rhubarbphp/module-build-status-updater

> 标签: bitbucket, build, git, github, hudson, jenkins, php, rhubarb, status

## 简介

Provides a provider for updating common cloud git hosting services with build status.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
