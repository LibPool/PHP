# rhubarbphp/module-postmark-email

> 标签: email, framework, php, postmark, rhubarb

## 简介

Provides an email provider for postmarkapp.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
