# ducks-project/remote-protocol

> 标签: ftp, protocol, remote, sftp, ssh2, ssl

## 简介

Manage some remote protocole like SFTP (Currently the only one)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
