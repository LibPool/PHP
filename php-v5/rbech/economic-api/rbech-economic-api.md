# rbech/economic-api

> 标签: PHP

## 简介

Lightweight wrapper for the E-conomic REST API heavily inspired by drewm/mailchimp-api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
