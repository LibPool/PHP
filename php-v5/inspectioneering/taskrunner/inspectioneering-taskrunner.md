# inspectioneering/taskrunner

> 标签: cron

## 简介

Run all of your project's recurring tasks through a single PHP script instead of having to create endless cron jobs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
