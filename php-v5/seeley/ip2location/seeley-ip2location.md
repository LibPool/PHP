# seeley/ip2location

> 标签: geolocation, ip2location, ip2locationlite

## 简介

[Official Release] IP2Location PHP API to get location info from IPv4 and IPv6 address.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
