# phpro/zf-smartcrud

> 标签: module, smartcrud, zend, zf2

## 简介

Module for creating smartcrud with the ZF2 MVC layer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
