# phpro/zf-mail-manager

> 标签: mail, mailmanager, module, zend, zf2

## 简介

An easy-to-use mailmanager for ZF2 that lets you focus on creating your mails.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
