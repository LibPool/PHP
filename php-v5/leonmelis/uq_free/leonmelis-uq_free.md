# leonmelis/uq_free

> 标签: api, authenticate, php, ubiqu, ubiqu free

## 简介

An unofficial PHP implementation for the Ubiqu Free API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
