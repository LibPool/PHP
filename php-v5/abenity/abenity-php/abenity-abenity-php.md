# abenity/abenity-php

> 标签: abenity, api, discounts, perks, php, rest, web service, wrapper

## 简介

PHP client for the Abenity API documented at https://abenity.com/developers/api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
