# vagovszky/imokutr

> 标签: Thumbnails, images, nette

## 简介

PHP image thumbnailer created with primary use for Nette framework, but also usable as a standalone PHP library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
