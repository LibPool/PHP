# kjcy8/phpanalysis

> 标签: PHP

## 简介

PHPAnalysis居于Unicode编码词典的PHP中文分词器，使用RMM逆向匹配算法进行分词

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
