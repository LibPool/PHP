# martinbean/laravel-bootstrap

> 标签: blade, bootstrap, laravel

## 简介

A Laravel package to add Blade components for Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
