# feimx/csd

> 标签: cfdi, csd, sat

## 简介

Este paquete te permite encriptar, validar y convertir archivos .cer y .key en .pem para la facturacion electronica en méxico

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
