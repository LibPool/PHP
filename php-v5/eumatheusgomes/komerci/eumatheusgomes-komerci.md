# eumatheusgomes/komerci

> 标签: komerci, payment, rede, redecard, webservice

## 简介

A PHP client for Rede's Komerci payment webservice

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
