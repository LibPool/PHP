# mrohnstock/bootstrap-multiselect

> 标签: JS, bootstrap, css, jquery, less, multiselect

## 简介

JQuery multiselect plugin based on Twitter Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
