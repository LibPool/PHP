# darvinstudio/darvin-bitrix24-bundle

> 标签: Bitrix24

## 简介

This bundle provides Bitrix24 integration for Symfony-based applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
