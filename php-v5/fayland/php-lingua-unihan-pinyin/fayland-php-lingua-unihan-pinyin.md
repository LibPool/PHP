# fayland/php-lingua-unihan-pinyin

> 标签: Chinese, Pinyin, hanzi, unihan

## 简介

convert Chinese into pinyin with unihan database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
