# iyngaran/send-grid-transport

> 标签: SendGrid module, zf2, zf3

## 简介

SendGrid Transport for Zend Framework 3 to send emails using SendGrid - https://sendgrid.com/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
