# rafapaulino/docker-php

> 标签: PHP

## 简介

Um ambiente Docker personalizável para PHP, MySQL/PostgreSQL, Redis e Mailpit, similar ao Laravel Sail.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
