# rediris-es/simplesamlphp-module-papi

> 标签: PAPI, RedIRIS, SIR, simplesamlphp

## 简介

A SimpleSAMLphp module adding support for the PAPI protocol.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
