# r1si/apache-vhost-helper

> 标签: apache, apache config, vhost, virtualhost

## 简介

A PHP library used to generate and getter information about Apache Vhost

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
