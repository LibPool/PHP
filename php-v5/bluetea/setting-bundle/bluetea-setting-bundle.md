# bluetea/setting-bundle

> 标签: Settings, Symfony2, bundle, setting

## 简介

Symfony2 settings Bundle for application and entity settings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
