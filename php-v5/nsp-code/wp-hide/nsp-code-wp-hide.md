# nsp-code/wp-hide

> 标签: Hacking, admin hide, custom login, hide, improve security, security, wordpress hide, wp hide, wp-admin, wp-loging.php

## 简介

Hide and increase Security for your WordPress website instance using smart techniques. No files are changed on your server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
