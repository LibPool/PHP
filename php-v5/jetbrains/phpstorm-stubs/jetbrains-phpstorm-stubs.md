# jetbrains/phpstorm-stubs

> 标签: autocomplete, code, inference, inspection, jetbrains, phpstorm, stubs, type

## 简介

PHP runtime & extensions header files for PhpStorm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
