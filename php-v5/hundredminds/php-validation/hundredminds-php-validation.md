# hundredminds/php-validation

> 标签: validation

## 简介

A PHP 5.3 Class for Easy Form Validation, forked from blackbelt/php-validation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
