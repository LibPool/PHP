# adevpmftc/msisdn-ph

> 标签: globe, mobile number, msisdn, msisdn philippines, smart, sun

## 简介

An MSISDN identification and cleaner library for Philippine telco subscribers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
