> 标签: JOSE, JWE, JWK, JWKSet, JWS, Jot, RFC7515, RFC7516, RFC7517, RFC7518, RFC7519, RFC7520, bundle, jwa, jwt, symfony

## 简介

Easy toolset to use the JWT Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
