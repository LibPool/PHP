# thecsea/caldav-client-adapter

> 标签: CalDAV, Simple, adapter, client

## 简介

Caldav adapter that uses other thecsea libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
