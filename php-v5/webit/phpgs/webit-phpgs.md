# webit/phpgs

> 标签: ghost script, ghostscript, gs, pdf merge, pdf split

## 简介

PHP Wrapper for Ghost Script

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
