# programming_cat/dotname-request

> 标签: PHP

## 简介

Convert dotted form parameters to array format / ドット区切りのフォームパラメータを配列形式に変換してRequestに設定します。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
