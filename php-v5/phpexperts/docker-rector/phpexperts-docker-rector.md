# phpexperts/docker-rector

> 标签: docker, dockerize, rector, static analysis

## 简介

The quickest and easiest way to run rector/rector with any PHP app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
