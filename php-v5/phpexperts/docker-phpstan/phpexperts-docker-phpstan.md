# phpexperts/docker-phpstan

> 标签: PHPStan, docker, dockerize, static analysis

## 简介

The quickest and easiest way to run phpstan/phpstan with any PHP app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
