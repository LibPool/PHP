# ondrej-vrto/php-filename-sanitize

> 标签: clean, filename, ondrej vrto, php, sanitize

## 简介

Removes all forbidden characters from the file name or path.

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
