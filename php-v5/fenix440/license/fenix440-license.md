# fenix440/license

> 标签: license

## 简介

Contains various license files for different projects / packages. Unless you are working with/on Fenix440 projects, this package is very useless for you!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
