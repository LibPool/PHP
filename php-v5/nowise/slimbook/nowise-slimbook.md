# nowise/slimbook

> 标签: DTD, bmc, schema, slimbook, uup, xml

## 简介

Simple XML schema for web page markup and type setting of books.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
