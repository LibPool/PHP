# warlof/slackbot

> 标签: PHP

## 简介

This plugin provide an extension to the standard SeAT character Job which handle automatic invitation to an existing Slack Team

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
