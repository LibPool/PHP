# kunstmaan/google-api-custom

> 标签: PHP

## 简介

A custom fork of alchemy/google-plus-api-client for the use into the Kunstmaan Bundles CMS without the composer warnings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
