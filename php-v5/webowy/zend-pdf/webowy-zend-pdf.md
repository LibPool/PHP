# webowy/zend-pdf

> 标签: framework, pdf, webowy, zend

## 简介

Provides an easy to use functionality to output PDF in Zend Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
