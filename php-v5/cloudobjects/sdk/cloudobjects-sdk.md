# cloudobjects/sdk

> 标签: cloudobjects, sdk

## 简介

CloudObjects SDK for PHP for working with COIDs and object descriptions from CloudObjects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
