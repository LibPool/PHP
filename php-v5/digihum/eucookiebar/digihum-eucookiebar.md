# digihum/eucookiebar

> 标签: PHP

## 简介

The plugin is a wrapper for the GDPR/CCPA compliant Cookie Consent JavaScript library. It provides a simple way to add a customisable cookie notice to your Omeka site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
