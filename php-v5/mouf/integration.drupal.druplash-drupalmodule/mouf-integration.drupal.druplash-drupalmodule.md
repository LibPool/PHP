# mouf/integration.drupal.druplash-drupalmodule

> 标签: drupal, mouf, mvc, splash

## 简介

This is the Drupal module used by Druplash, the MVC framework for Drupal

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
