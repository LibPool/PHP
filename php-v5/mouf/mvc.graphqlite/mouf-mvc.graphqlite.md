# mouf/mvc.graphqlite

> 标签: graphql, mouf, orm

## 简介

A binding package between thecodingmachine/graphqlite and the Mouf framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
