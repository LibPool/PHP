# mouf/database.doctrine-dbal-wrapper

> 标签: database, dbconnection, mouf

## 简介

This package contains wrapper classes that make Doctrine DBAL easy to use in Mouf

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
