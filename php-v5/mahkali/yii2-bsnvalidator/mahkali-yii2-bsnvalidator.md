# mahkali/yii2-bsnvalidator

> 标签: bsn, extension, form, input, validator, yii, yii2

## 简介

BSN validator for Yii Framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
