# mahdiaslami/laravel-mermaid

> 标签: er diagram, laravel, mermaidjs

## 简介

Create ER diagram based on the database by MermaidJS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
