# lightspeedhq/ls-ecom-guzzle

> 标签: Guzzle, api, ecommerce, lightspeed, pos, rest

## 简介

A Guzzle HTTP Client extension for Lightspeed eCommerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
