# kanellov/transelot

> 标签: 843, elot, greek, greeklish, iso, iso843, translitterate

## 简介

A simple function that translitterate greek to latin based on iso 843

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
