# projek-xyz/slim-plates

> 标签: framework, plates, slim, template, view

## 简介

Slim Framework 3 view helper built on top of the Plates templating component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
