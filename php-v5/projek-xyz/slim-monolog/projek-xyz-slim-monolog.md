# projek-xyz/slim-monolog

> 标签: framework, logger, monolog, slim

## 简介

Slim Framework 3 log helper built on top of the Monolog logger component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
