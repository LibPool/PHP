# braunson/laravel-html5-forms

> 标签: PHP

## 简介

This package extends Laravel's FormBuilder to include some (soon all) HTML5 elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
