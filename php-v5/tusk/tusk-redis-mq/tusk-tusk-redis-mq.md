# tusk/tusk-redis-mq

> 标签: message, predis, queue, redis

## 简介

A simple producer/consumer and RPC message queue on top of Redis and the equally fantastic Predis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
