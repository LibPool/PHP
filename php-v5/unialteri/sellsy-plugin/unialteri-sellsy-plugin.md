# unialteri/sellsy-plugin

> 标签: lead, module, sellsy, wordpress

## 简介

Wordpress plugin to generate contact form with Sellsy and send it leads captured

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
