# heimrichhannot/contao-ldap

> 标签: auth, contao, developer, ldap, module

## 简介

A simple module extending the standard login module with ldap functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
