# webmex/eshop-project

> 标签: PHP

## 简介

Webmex e-shop sandbox project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/webmexteam/webmex-eshop
- 源码仓库：https://bitbucket.org/webmexteam/webmex-eshop-project.git
- Packagist 页面：https://packagist.org/packages/webmex%2Feshop-project

- Packagist 仓库：https://repo.packagist.org/p2/webmex/eshop-project.json
- PHP 要求：>=5.3.0
