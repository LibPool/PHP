# biberltd/phporient

> 标签: orient db, orientdb, orientechnologies

## 简介

PHPOrient is a good php driver based on the binary protocol of OrientDB.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
