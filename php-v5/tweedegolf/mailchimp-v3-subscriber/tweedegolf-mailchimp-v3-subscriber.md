# tweedegolf/mailchimp-v3-subscriber

> 标签: PHP

## 简介

Simple wrapper around the MailChimp v3 API to subscribe and unsubscribe people from you mailing lists

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
