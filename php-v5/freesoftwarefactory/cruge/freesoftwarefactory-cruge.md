# freesoftwarefactory/cruge

> 标签: Authentication, auth, authorization, rbac, user

## 简介

authentication/authorization extension for yii2 (yii framework 2.0)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
