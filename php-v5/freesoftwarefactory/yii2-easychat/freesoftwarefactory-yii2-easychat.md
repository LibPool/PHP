# freesoftwarefactory/yii2-easychat

> 标签: PHP

## 简介

a small abstract chat widget for yii framework 2 applications, jquery-based.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
