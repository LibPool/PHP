# scribe/pygments-bundle

> 标签: markdown, pygments, sundown

## 简介

A bundle that integrates Pygments to provide code-highlighting within Sundown rendered Markdown

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
