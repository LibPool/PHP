# jandc/inline-css-provider

> 标签: Email markup, css, php, silex, twig

## 简介

Silex provider which wraps the features of CssToInlineStyles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
