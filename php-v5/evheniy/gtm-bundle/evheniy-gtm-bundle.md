# evheniy/gtm-bundle

> 标签: google, gtm, latest, manager, symfony, tag

## 简介

The GtmBundle adds the ability to add Google Tag Manager code to your application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
