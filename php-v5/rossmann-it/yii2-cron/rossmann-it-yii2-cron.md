# rossmann-it/yii2-cron

> 标签: cron, crontab, schedule, tasks manager, yii 2, yii2

## 简介

Flexible cron tasks manager for the Yii2 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
