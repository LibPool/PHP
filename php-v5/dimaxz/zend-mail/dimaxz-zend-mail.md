# dimaxz/zend-mail

> 标签: ZendFramework, mail, zf

## 简介

Provides generalized functionality to compose and send both text and MIME-compliant multipart e-mail messages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
