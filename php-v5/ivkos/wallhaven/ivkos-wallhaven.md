# ivkos/wallhaven

> 标签: api, batch, download, downloader, library, wallbase, wallhaven, wallpapers

## 简介

Wallhaven API - Search, filter and download wallpapers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
