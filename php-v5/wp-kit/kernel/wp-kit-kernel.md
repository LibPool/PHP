# wp-kit/kernel

> 标签: headers, routing, themosis, wordpress, wp-kit

## 简介

A Themosis component that handles routing by acting as a kernel and allows headers to be sent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
