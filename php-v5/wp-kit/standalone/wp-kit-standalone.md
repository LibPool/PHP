# wp-kit/standalone

> 标签: OOP, framework, wordpress, wpkit

## 简介

WPKit is a RAD (Rapid Application Framework) framework for Wordpress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
