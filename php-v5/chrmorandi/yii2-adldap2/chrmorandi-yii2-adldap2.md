# chrmorandi/yii2-adldap2

> 标签: active directory, ad, adldap2, ldap, php, yii2

## 简介

Yii2 wrapper for PHP LDAP Library with Active Directory Manipulation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
