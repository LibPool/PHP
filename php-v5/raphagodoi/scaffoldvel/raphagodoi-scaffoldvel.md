# raphagodoi/scaffoldvel

> 标签: generators, laravel, laravel5, scaffold

## 简介

Extend Laravel 5's generators scaffold and create custom views

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
