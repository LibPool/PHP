# hparadiz/aws-instance-connect

> 标签: PHP

## 简介

Uses AWS Instance Connect API to authorize an SSH key and automatically runs the SSH command using that key for you.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
