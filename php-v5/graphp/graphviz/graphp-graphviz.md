# graphp/graphviz

> 标签: dot output, graph drawing, graph image, graphp, graphviz

## 简介

GraphViz graph drawing for the mathematical graph/network library GraPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
