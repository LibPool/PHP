# anime-db/my-anime-list-sync-bundle

> 标签: PHP

## 简介

Synchronizes the changes in the list of items with the MyAnimeList.net

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
