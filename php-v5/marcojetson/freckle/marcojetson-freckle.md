# marcojetson/freckle

> 标签: data mapper, database, orm

## 简介

A minimalistic ORM built on top of Doctrine DBAL and heavily inspired by Spot2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
