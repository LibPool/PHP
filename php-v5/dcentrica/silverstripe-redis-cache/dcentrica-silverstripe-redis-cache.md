# dcentrica/silverstripe-redis-cache

> 标签: cache, redis, silverstripe, valkey

## 简介

Enables Redis cache for Silverstripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
