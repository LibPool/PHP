# maba/webpack-migration-bundle

> 标签: Symfony2, amd, assetic, assets, commonjs, symfony, webpack

## 简介

Bundle to Help Migrating From Assetic to Webpack

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
