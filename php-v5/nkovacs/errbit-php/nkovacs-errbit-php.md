# nkovacs/errbit-php

> 标签: airbrake, errbit, errbit php, error tracking

## 简介

errbit/airbrake integration with php with psr-2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
