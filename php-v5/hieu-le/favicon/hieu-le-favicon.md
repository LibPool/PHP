# hieu-le/favicon

> 标签: favicon, generate, ico, png

## 简介

A configurable PHP solution to auto generate favicons and HTML meta tags from a original PNG file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
