# maadhattah/wppb-mod

> 标签: boilerplate, plugin, wordpress

## 简介

A modern WordPress development boilerplate, based on Tom McFarlin's wppb.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
