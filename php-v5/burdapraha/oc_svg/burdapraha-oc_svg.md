# burdapraha/oc_svg

> 标签: opencart, opencart-2, opencart-theme, svg

## 简介

OpenCart 2.x hacked to allow SVG support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
