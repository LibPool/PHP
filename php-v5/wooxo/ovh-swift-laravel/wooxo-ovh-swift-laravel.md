# wooxo/ovh-swift-laravel

> 标签: laravel, ovh, swift

## 简介

Library to use OVH PCI Object Storage API with Laravel 4.2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
