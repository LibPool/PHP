# max-dreamsoft/yii2-tree-dropdown

> 标签: checkbox, dropdown, extension, tree, widget, yii2

## 简介

A dropdown widget containing expandable treeview with checkboxes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
