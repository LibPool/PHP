# mayconbordin/l5-db-commands

> 标签: commmands, database, laravel, laravel 5

## 简介

A set of commands to create/drop/dump/restore databases on Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
