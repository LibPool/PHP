# sammaye/yii2-solr

> 标签: Yii2 Extension, extension, sammaye, solarium, solr, yii2, yii2-extension

## 简介

Solr plugin for the Yii2 framework built ontop of Solarium

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
