# r0adrunn3r/easy-pnp

> 标签: card, cardgame, fpdf, game, pdf, pnp, tabletop

## 简介

EasyPnP is a PHP class which allows to generate easily a PDF for PnP (Print and Play) Games from images.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
