# backtory/storage-php

> 标签: backtory, backtory-sdk, backtory-storage, cloud, cloud-storage, storage

## 简介

PHP SDK for Backtory Cloud Storage :)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
