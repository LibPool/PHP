# moonbaselabs/laravel-neverbounce

> 标签: email, laravel, neverbounce, verification

## 简介

A laravel wrapper for the NeverBounceAPI-PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
