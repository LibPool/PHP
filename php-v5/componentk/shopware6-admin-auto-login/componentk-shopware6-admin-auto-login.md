# componentk/shopware6-admin-auto-login

> 标签: PHP

## 简介

Designed for developer environment Shopware 6 only. Just auto logs in using the default admin user/pass

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
