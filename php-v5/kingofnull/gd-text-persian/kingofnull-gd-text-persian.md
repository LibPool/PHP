# kingofnull/gd-text-persian

> 标签: PHP

## 简介

A class drawing multiline and aligned text on pictures. Uses GD extension OPTIMIZED FOR PERSIAN.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
