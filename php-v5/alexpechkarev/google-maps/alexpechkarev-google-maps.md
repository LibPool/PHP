# alexpechkarev/google-maps

> 标签: Google Maps API, elevation api, geocoding api, geolocation api, google maps api for laravel, google maps web service for laravel, laravel google maps api, places api web service, roads api, routes api, time zone api

## 简介

Collection of Google Maps API Web Services for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
