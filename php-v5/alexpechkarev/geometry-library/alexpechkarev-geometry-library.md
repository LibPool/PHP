# alexpechkarev/geometry-library

> 标签: computations polygons and polylines, encoding and decoding polyline paths utilities, google maps geometry library, php geometry library, spherical geometry utilities

## 简介

PHP Geometry library provides utility functions for the computation of geometric data on the surface of the Earth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
