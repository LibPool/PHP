# icap/notification-bundle

> 标签: Claroline, ICAP, notification

## 简介

Notification bundle for Claroline Connect. See https://github.com/claroline/Claroline

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
