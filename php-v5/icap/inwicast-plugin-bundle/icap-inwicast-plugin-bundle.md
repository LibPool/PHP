# icap/inwicast-plugin-bundle

> 标签: Claroline, ICAP, plugin, website

## 简介

Inwicast plugin for Claroline Connect

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
