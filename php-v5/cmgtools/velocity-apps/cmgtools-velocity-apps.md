# cmgtools/velocity-apps

> 标签: JS, framework, front-end, velocity, web

## 简介

Velocity Apps provides generic applications and controllers used to communicate with backend including CMSGears modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
