# lav45/yii2-ajax-create

> 标签: ajax, extension, widget, yii2

## 简介

This widget is designed to quickly create missing related entities when filling out the form.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
