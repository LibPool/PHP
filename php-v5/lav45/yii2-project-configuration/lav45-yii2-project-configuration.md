# lav45/yii2-project-configuration

> 标签: Settings, config, extension, yii2

## 简介

This extension helps you to easily store and retrieve settings for your project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
