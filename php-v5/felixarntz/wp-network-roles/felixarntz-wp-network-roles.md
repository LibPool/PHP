# felixarntz/wp-network-roles

> 标签: multinetwork, multisite, network, network roles, plugin, wordpress

## 简介

Implements network-wide user roles in WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
