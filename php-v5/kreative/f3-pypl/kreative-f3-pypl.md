# kreative/f3-pypl

> 标签: F3, express checkout, fatfree, paypal

## 简介

PayPal Express Checkout integration for the PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
