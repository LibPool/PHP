# pradosoft/jsmin-php

> 标签: compress, jsmin, minify

## 简介

Provides a modified port of Douglas Crockford's jsmin.c, which removes unnecessary whitespace from JavaScript files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
