# alorel/phpunit-auto-rerun

> 标签: auto, failed, phpunit, rerun, retry, test

## 简介

Allows failed PHPUnit tests to automatically rerun.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
