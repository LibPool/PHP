# tecnocen/yii2-disable-submit-buttons

> 标签: activeform, disable, jquery, yii, yii2

## 简介

Yii2 asset to automatically disable submit buttons on Yii2 ActiveForm.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
