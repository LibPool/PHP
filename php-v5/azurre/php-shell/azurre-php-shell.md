# azurre/php-shell

> 标签: async, asynchronous, cmd, linux, none blocking, process, shell

## 简介

A convenient none blocking asynchronous shell

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
