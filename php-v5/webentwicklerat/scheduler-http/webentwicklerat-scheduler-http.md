# webentwicklerat/scheduler-http

> 标签: http, scheduler, typo3

## 简介

Invoke scheduler via HTTP-Request and add scheduler tasks doing GET-Requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
