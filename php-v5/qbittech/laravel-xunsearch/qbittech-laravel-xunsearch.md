# qbittech/laravel-xunsearch

> 标签: laravel, qbittech, xunsearch

## 简介

Laravel 5+ package for full-text search over Eloquent models based on XunSearch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
