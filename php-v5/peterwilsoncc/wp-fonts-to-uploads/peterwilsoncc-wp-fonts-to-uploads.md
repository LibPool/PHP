# peterwilsoncc/wp-fonts-to-uploads

> 标签: PHP

## 简介

A WordPress plugin to relocate the fonts directory to uploads.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
