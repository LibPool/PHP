# chrisyue/auto-json-response-bundle

> 标签: json, response

## 简介

A Symfony bundle with a listener which converts controller returned data to a appropriate JsonResponse.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
