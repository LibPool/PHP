# vrtc/yii2-querybuilder

> 标签: builder, dynamic, interface, query, querybuilder, yii2

## 简介

Extension for Yii2 Framework to work with jQuery QueryBuilder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
