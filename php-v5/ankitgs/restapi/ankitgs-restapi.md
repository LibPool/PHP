# ankitgs/restapi

> 标签: REST API, Zend Framework, cors, rest, zf3

## 简介

Zend Framework 3 module to build REST APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
