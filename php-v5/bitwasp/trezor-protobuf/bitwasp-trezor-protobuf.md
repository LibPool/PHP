# bitwasp/trezor-protobuf

> 标签: protobuf, satoshilabs, trezor

## 简介

Protobuf messages for trezor hardware wallet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
