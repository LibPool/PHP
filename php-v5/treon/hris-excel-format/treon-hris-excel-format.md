# treon/hris-excel-format

> 标签: PHP

## 简介

This is a compile HrisExcel Format in Treon projects, Please note that you dont need to require PHPExcel because it is already loaded in Treon Projects..

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
