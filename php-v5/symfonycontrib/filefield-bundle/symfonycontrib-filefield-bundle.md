# symfonycontrib/filefield-bundle

> 标签: bundle, file, form, symfony, upload

## 简介

Symfony2 Advanced File Field Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
