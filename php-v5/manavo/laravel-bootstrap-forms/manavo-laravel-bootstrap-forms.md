# manavo/laravel-bootstrap-forms

> 标签: PHP

## 简介

Reduce the boilerplate code required to get forms in Laravel to have Bootstrap styling

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
