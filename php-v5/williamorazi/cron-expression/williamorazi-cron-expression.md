# williamorazi/cron-expression

> 标签: cron, schedule

## 简介

CRON for PHP: Calculate the next or previous run date and determine if a CRON expression is due

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
