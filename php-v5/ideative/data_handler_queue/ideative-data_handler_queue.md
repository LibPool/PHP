# ideative/data_handler_queue

> 标签: PHP

## 简介

Provides an API for registering DataHandler data and commands and replay them asynchronously at a later point in time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
