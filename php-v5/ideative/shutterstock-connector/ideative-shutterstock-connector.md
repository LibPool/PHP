# ideative/shutterstock-connector

> 标签: PHP

## 简介

Plugin for extension id_stock_pictures that connects the Shutterstock API to the TYPO3 backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
