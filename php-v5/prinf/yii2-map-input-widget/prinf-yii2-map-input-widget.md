# prinf/yii2-map-input-widget

> 标签: coordinates, extension, geo-coordinates, geocoding, input, map, widget, yii2

## 简介

Fork of kolyunya/yii2-map-input-widget. Yii2 map input widget. Allows you to select geographcal coordinates via a human-friendly interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
