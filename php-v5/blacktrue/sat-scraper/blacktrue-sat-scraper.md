# blacktrue/sat-scraper

> 标签: PHP

## 简介

Web Scraping para extraer facturas electronicas masivamente desde la pagina del SAT

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
