# bueltge/wp-offline

> 标签: PHP

## 简介

Block external calls, like http for scripts, styles and updates. Helpful for local development, audits and also for intranet solutions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
