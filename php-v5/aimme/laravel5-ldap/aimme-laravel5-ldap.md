# aimme/laravel5-ldap

> 标签: active directory, authenticate, laravel, ldap, windows

## 简介

Ldap (Active Directory) authentication for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
