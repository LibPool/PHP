# lagan/template-trumbowyg

> 标签: lagan, property, template, trumbowyg, wysiwyg

## 简介

Template for the Trumbowyg WYSIWYG editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
