# lagan/property-slug

> 标签: controller, lagan, property, slug

## 简介

Controller for the Lagan slug property. Creates a slug from a string, and checks if it's unique.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
