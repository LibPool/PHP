# joefallon/phpautoloader

> 标签: Simple, autoloader, namespace, psr-0

## 简介

Joe's simple to use and versatile PHP autoloader.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
