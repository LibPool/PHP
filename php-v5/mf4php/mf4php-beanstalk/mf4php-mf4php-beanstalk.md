# mf4php/mf4php-beanstalk

> 标签: beanstalk, facade, mf4php, wrapper

## 简介

This is an mf4php binding for Beanstalk.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
