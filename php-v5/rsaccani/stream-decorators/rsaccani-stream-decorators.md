# rsaccani/stream-decorators

> 标签: decorators, mail, mime, psr7, stream

## 简介

PHP psr7 stream decorators for mime message part streams

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
