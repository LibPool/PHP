# black-lamp/yii2-multi-lang

> 标签: language, languages, manager, multi, url, yii2

## 简介

Yii2 url manager with supporting multi languages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
