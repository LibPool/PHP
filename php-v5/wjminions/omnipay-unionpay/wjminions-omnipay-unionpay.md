# wjminions/omnipay-unionpay

> 标签: gateway, merchant, omnipay, pay, payment, purchase, union, unionpay, 银联

## 简介

UnionPay gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
