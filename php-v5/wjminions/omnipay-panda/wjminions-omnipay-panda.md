# wjminions/omnipay-panda

> 标签: Panda, gateway, merchant, omnipay, pay, payment, purchase

## 简介

Panda gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
