# monext/magento2-module

> 标签: Monext, Payline, magento 2, payment, wallet, widget

## 简介

Magento2 Extension to use the Payline payment solution by Monext

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
