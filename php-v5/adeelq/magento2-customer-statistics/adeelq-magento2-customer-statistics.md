# adeelq/magento2-customer-statistics

> 标签: PHP

## 简介

A module which adds grid in Magento admin backOffice for viewing customer lifetime statistics.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
