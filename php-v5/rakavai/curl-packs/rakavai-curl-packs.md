# rakavai/curl-packs

> 标签: curl, dot, http

## 简介

Curl wrapper object in php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/rakavai/curl-lib-php
- 源码仓库：https://github.com/rakavai/curl-lib-php.git
- Packagist 页面：https://packagist.org/packages/rakavai%2Fcurl-packs

- 1.0.0

## 获取地址

- Composer 安装：`composer require rakavai/curl-packs`
- Packagist 仓库：https://repo.packagist.org/p2/rakavai/curl-packs.json
- PHP 要求：>=5.3.0
