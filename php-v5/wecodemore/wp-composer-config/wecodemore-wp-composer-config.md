# wecodemore/wp-composer-config

> 标签: composer, config, env, wordpress, wp, wp-config

## 简介

Auto generate your wp-config as Composer Script

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
