# wecodemore/current-admin-info

> 标签: admin, debug, development, wordpress

## 简介

Displays info about the current admin screen and its globals, contextual hooks, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
