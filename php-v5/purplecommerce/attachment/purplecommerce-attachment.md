# purplecommerce/attachment

> 标签: add attachment, attachment, how to add attachment in magento 2, magento, magento 2, upload attachment

## 简介

A module which allow to add attachment and display them through widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
