# rbnvrw/pico-load-plugins-composer

> 标签: composer, picocms

## 简介

Automatically load Pico plugins from the Composer vendor directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
