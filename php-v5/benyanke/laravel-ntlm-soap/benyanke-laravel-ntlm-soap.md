# benyanke/laravel-ntlm-soap

> 标签: client, laravel, soap, wrapper

## 简介

A SoapClient wrapper integration for Laravel with NTLM support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
