# virtphp/virtphp

> 标签: environment, virtual, vm

## 简介

virtPHP is a tool to create isolated PHP environments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://virtphp.org
- 源码仓库：https://github.com/virtphp/virtphp.git
- Packagist 页面：https://packagist.org/packages/virtphp%2Fvirtphp
