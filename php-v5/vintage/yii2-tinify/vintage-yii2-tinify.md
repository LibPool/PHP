# vintage/yii2-tinify

> 标签: api, component, compress, images, resize, tinify, tinyjpg, tinypng, yii2

## 简介

Facade of Tinify API for Yii2 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
