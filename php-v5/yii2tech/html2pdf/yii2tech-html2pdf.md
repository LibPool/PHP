# yii2tech/html2pdf

> 标签: conversion, convert, html2pdf, pdf, php2pdf, template, yii2

## 简介

Provides support for HTML to PDF and PHP to PDF conversion

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
