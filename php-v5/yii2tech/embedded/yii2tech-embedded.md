# yii2tech/embedded

> 标签: elastic, elasticsearch, embed, embedded, json, mongo, mongodb, nested, yii2

## 简介

Provides support for embedded (nested) models in Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
