# ekspress-digital/php-rql

> 标签: database, driver, reql, rethinkdb

## 简介

A PHP client driver for the RethinkDB query language (ReQL)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
