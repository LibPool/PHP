# imevul/scopefilter

> 标签: annotation, class, data filter, filter, oauth2, scope

## 简介

Lightweight array filtering library that uses 'scopes' to define filters.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
