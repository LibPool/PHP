# cejobelo/hamtaro-starter

> 标签: hamtaro, hamtaro-starter

## 简介

Start your Hamtaro application with hamtaro-starter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
