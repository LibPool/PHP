# vaughan/ubl-invoice

> 标签: electronic invoice, invoice, ubl, ublinvoice, xml, xml invoice

## 简介

A PHP wrapper for UBL invoices

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
