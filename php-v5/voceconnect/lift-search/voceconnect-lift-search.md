# voceconnect/lift-search

> 标签: cloudsearch, search, wordpress

## 简介

Lift leverages the search index power of Amazon CloudSearch to improve your WordPress-powered site’s search experience. Learn more at: http://getliftsearch.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
