# xemlock/wp-post-thumbnail-endpoint

> 标签: PHP

## 简介

A WordPress plugin that provides a special URL for accessing Post Thumbnails by their corresponding Post ID

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
