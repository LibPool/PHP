# zha/laravel-log-view

> 标签: laravel log-viewer, log, log viewer, log-viewer, logviewer

## 简介

Laravel Log Viewer 通过Web界面查看Laravel日志文件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
