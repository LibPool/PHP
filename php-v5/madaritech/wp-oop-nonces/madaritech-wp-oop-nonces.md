# madaritech/wp-oop-nonces

> 标签: Nonces, OOP, wordpress

## 简介

Classes that serves the WordPress Nonces functionality in an object oriented way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
