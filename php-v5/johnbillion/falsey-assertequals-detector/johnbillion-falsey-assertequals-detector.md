# johnbillion/falsey-assertequals-detector

> 标签: PHP

## 简介

Detects usage of assertEquals() with falsey values and marks the test as risky.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
