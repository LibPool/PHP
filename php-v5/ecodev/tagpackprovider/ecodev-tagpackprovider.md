# ecodev/tagpackprovider

> 标签: PHP

## 简介

This Data Provider relies on tags from extension Tag Pack to provide lists of items. More info on http://www.typo3-tesseract.com/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
