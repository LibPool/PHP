# mindplay/funit

> 标签: test, unit

## 简介

A simple test suite for PHP 5.3+, partially inspired by QUnit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://github.com/mindplay/funit
- 源码仓库：https://github.com/mindplay-dk/funit.git
- Packagist 页面：https://packagist.org/packages/mindplay%2Ffunit
