# azishapidin/nyebut

> 标签: PHP

## 简介

Package untuk menyebutkan angka menjadi teks, contoh jika parameternya 100 maka library ini akan return string seratus.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
