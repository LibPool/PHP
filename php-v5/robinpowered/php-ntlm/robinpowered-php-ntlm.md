# robinpowered/php-ntlm

> 标签: Authentication, NTLM, hash, lm, nt

## 简介

Message encoder/decoder and password hasher for the NTLM authentication protocol

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
