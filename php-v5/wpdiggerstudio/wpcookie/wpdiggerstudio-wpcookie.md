# wpdiggerstudio/wpcookie

> 标签: WPEngine, cookies, hhvm, php, wordpress

## 简介

PHP library for handling cookies especially created for WPEngine hosted sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
