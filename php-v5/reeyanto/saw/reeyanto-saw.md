# reeyanto/saw

> 标签: PHP

## 简介

Library PHP yang mengimplementasikan algoritma SAW (Simple Additive Weighting) untuk Sistem Pendukung Keputusan (SPK).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
