# mingyuanyun/yii2-ifile

> 标签: OBS, file, minio, oss, storage, upload, yii2

## 简介

该组件提供统一的文件存储客户端编程模型，支持简单上传、分片上传、下载、文件内容查看等。目前已支持MinIO，阿里OSS，招商COS。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
