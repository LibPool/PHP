# manulith/sketchfab-php

> 标签: L4, laravel, sketchfab

## 简介

A Laravel package for uploading 3D objects to the Sketchfab API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
