# stevegrunwell/wp-admin-tabbed-settings-pages

> 标签: PHP

## 简介

A polyfill for Trac #51086, bringing tabbed settings pages into WP-Admin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
