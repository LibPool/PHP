# silvercommerce/reports

> 标签: commerce, ecommerce, products, reports, sales, silverstripe

## 简介

Add reports to a SilverCommerce install (for orders, products sold, etc)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
