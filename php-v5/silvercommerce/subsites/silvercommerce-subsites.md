# silvercommerce/subsites

> 标签: commerce, ecommerce, silverstripe, subsites

## 简介

Module adding extra extensions to allow automatic integration of silverstripe/subsites with SilverCommerce Modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
