# silvercommerce/tax-admin

> 标签: commerce, ecommerce, silverstripe, tax

## 简介

Module allowing creation of tax rates and categories in the CMS via SiteConfig

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
