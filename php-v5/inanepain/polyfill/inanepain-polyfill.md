# inanepain/polyfill

> 标签: compatibility, inane, polyfill, portable, shim

## 简介

Various Polyfill functions for php backwards compatibility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
