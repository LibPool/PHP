# district09/robo-district09-drupal-anonymize

> 标签: PHP

## 简介

Anonymize drupal backups using the [Configurable Anonymizer](https://www.drupal.org/project/configurable_anonymizer) module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
