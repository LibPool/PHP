# mateodioev/multi-lang

> 标签: i18n, l10n, language, multi-language, php, translate, translation

## 简介

A simple PHP class to manage multi-language websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
