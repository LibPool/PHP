# miffy/miffyzq

> 标签: PHP

## 简介

backend theme asset bundle for Yii 2.0 Framework;基于H+的后台模板第一版

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
