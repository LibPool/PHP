# nghiemdp/omnipay_paypal

> 标签: gateway, merchant, omnipay, pay, payment, paypal, purchase

## 简介

PayPal gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
