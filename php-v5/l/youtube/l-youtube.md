# l/youtube

> 标签: alaouy, api, laravel, video, youtube

## 简介

Laravel PHP Facade/Wrapper for the Youtube Data API v3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
