# webforcehq/shipoffers

> 标签: PHP

## 简介

This is a SDK built in PHP for consuming shipoffers api as detailed in https://api.shipoffers.com/swagger/#!/stores

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
