# vinou/vinou-connector

> 标签: Vinou, extension, typo3

## 简介

Extension that provides a connection for vinou.de and display wines and winelists via fluid templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
