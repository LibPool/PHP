# fritzmg/contao-form-code-redirect

> 标签: code, contao, form, redirect

## 简介

Simple Contao extension to automatically redirect a user to a specific page after he entered a "code" in a form.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
