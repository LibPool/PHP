# swixpop/colour-pal

> 标签: Craft, cms, colour pal, craft-plugin, craftcms

## 简介

A friendly palette picker field with predefined colour palette configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
