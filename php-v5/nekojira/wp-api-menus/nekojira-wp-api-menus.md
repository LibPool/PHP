# nekojira/wp-api-menus

> 标签: api, json, wordpress, wp, wp-api, wp-rest-api

## 简介

Extends WordPress WP API with menu routes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
