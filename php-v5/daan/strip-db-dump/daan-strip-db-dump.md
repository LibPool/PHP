# daan/strip-db-dump

> 标签: PHP

## 简介

Adds shorthands in WP-CLI to easily create database dumps without sensitive data, i.e. customers, users and/or orders.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
