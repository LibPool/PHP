# divante-ltd/pimcore-classification-tree

> 标签: pimcore, pimcore-plugin

## 简介

Classification Tree lets you add new custom view with classification tree.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
