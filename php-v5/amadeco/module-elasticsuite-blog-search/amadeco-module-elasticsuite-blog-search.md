# amadeco/module-elasticsuite-blog-search

> 标签: PHP

## 简介

Comwrap Elasticsuite - Blog Post Search Module for Smile Elasticsuite.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
