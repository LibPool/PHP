# stw-on/craft-extended-search

> 标签: Craft, cms, craft-plugin, craftcms, extended search

## 简介

Retrieve additional context for Element searches

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
