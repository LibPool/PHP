# xaamin/encoding

> 标签: ISO88591, WIN1252, encoding, latin1, utf8

## 简介

PHP Class Encoding that fixes mixed encoded strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
