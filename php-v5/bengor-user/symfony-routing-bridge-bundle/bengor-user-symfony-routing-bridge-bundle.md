# bengor-user/symfony-routing-bridge-bundle

> 标签: bundle, ddd, routing, symfony, user

## 简介

Symfony bundle that glues UserBundle and SymfonyRouting

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
