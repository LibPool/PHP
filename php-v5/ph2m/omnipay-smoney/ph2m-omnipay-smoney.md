# ph2m/omnipay-smoney

> 标签: S-Money, gateway, merchant, omnipay, pay, payment, purchase

## 简介

S-Money gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
