# zachgarwood/php-morrisjs

> 标签: Morris.js, chart

## 简介

PHP library for interactiing with the http://www.oesmith.co.uk/morris.js Javascript library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
