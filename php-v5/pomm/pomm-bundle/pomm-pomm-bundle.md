# pomm/pomm-bundle

> 标签: database, orm, postgresql, symfony

## 简介

The Symfony2 bundle for Postgresql Object Model Manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
