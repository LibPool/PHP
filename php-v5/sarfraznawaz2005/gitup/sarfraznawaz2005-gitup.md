# sarfraznawaz2005/gitup

> 标签: deploy, ftp, laravel, upload

## 简介

Laravel package to upload git commits to server(s) via (s)ftp.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
