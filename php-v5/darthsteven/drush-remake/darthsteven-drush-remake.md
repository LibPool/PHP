# darthsteven/drush-remake

> 标签: Drush

## 简介

Helps to re-run Drush make for install profiles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.drupal.org/project/drush_remake
- 源码仓库：http://git.drupal.org/project/drush_remake.git
