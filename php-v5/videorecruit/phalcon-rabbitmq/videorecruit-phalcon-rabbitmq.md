# videorecruit/phalcon-rabbitmq

> 标签: phalcon, php-amqp, rabbitmq

## 简介

Integration of php-amqplib with RabbitMq and Phalcon Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
