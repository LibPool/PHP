# vearutop/php-obscene-censor-rus

> 标签: censor, антимат, модерация, хуй, цензура

## 简介

Класс для фильтрации нецензурных выражений (матов).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
