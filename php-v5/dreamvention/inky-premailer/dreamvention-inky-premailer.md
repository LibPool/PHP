# dreamvention/inky-premailer

> 标签: PHP

## 简介

Implementation of ZURB Inky + CssToInlineStyles. Compile responsive emails on the fly with ease.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
