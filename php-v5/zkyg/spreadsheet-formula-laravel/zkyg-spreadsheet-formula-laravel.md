# zkyg/spreadsheet-formula-laravel

> 标签: PHP

## 简介

Parsing and calculate simple Ms Excel formula using PHP(through PHPSpreadsheet) for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
