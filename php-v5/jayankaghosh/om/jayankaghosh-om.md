# jayankaghosh/om

> 标签: PHP

## 简介

The Advanced Object Manager with dependency injection, plugins, preferences, and much more... NO MORE new Obj()!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
