# jarlskov/laravel-untappd

> 标签: PHP

## 简介

Small library that makes it easy to use the Jarlskov/Untappd API wrapper in your Laravel project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
