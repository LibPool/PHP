# sngular/sngulauth

> 标签: auth, connect, keycloak, onelogin, saml, sngular

## 简介

Auth package against Keycloak for Saml and Openid-Connect

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
