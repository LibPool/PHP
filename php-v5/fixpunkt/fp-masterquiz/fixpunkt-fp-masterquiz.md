# fixpunkt/fp-masterquiz

> 标签: quiz poll masterquiz

## 简介

A modern extension that offers quiz, polls and tests. The result can be displayed as a chart.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
