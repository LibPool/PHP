# fixpunkt/backendtools

> 标签: PHP

## 简介

9 admin tools for extension listing, recent pages, pages with layouts, redirects, missing or unused files, images with no alt- or title-tag and links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
