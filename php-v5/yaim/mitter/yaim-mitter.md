# yaim/mitter

> 标签: controller handler, eloquent, form generator, laravel, model saver

## 简介

A Model-Sitter for Laravel Eloquent.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
