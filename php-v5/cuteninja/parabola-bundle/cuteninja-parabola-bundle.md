# cuteninja/parabola-bundle

> 标签: api, testing

## 简介

Common code handling API for Cute-Ninja projects (ResponseBuilder, Testing, ...)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
