# werkraum/websocket-provider

> 标签: cli, command, extension, typo3, websocket

## 简介

Run a websocket server within the TYPO3 context with extensible server logic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
