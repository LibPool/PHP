# kotchuprik/yii2-instagram-authclient

> 标签: authclient, instagram, oauth, yii2

## 简介

Instagram extenion for using via yii2-authclient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
