# hackzilla/ticket-message

> 标签: help desk, helpdesk, support, ticket, ticketing

## 简介

This library provides ticketing functionality for PHP applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
