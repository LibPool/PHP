# alaxos/cakephp3-bootstrap-theme

> 标签: bake, bootstrap, cakephp, libraries, theme

## 简介

Bootstrap bake templates for CakePHP 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
