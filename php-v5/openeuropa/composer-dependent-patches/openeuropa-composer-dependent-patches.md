# openeuropa/composer-dependent-patches

> 标签: PHP

## 简介

A Composer plugin that extends cweagans/composer-patches to support dependent patches functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
