# progcode/billingo-api-v3-php-sdk

> 标签: api, billingo, clone, php, sdk, swagger, v3

## 简介

This is a Billingo (billingo.hu) API V3 PHP SDK clone from SwaggerHUB.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
