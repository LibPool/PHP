# php-kit/html5-tools

> 标签: HTML5, highlighter, html, parser, sax, syntax

## 简介

A collection of libraries for working with HTML5 markup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
