# php-kit/composer-expose-packages-plugin

> 标签: composer, plugin

## 简介

Makes package development easier by editing them on any project via the same central filesystem location

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
