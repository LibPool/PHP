# indatus/ranger

> 标签: PHP

## 简介

This package adds some power to your api rest server by allowing you to specify joins and eager loaded associations using http query parameters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
