# digitalzenworks/consumer-provider

> 标签: consumer, pattern, provider

## 简介

A package providing an interface to allow a provider object to feed a consumer object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
