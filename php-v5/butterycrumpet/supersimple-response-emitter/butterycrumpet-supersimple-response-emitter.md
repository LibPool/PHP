# butterycrumpet/supersimple-response-emitter

> 标签: PHP

## 简介

Super simple response emitter for flushing PSR7 response interfaces to the client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
