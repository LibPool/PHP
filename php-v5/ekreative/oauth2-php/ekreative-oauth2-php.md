# ekreative/oauth2-php

> 标签: PSR-1, PSR-2, PSR-4, oauth2, psr-3, silex

## 简介

The standard compliant OAuth2.0 library based on the Symfony Components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
