# magefast-dragonfly/module-json-ld

> 标签: PHP

## 简介

Magento module Dragonfly_JsonLd. Add json-ld markup - this is good for SEO.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
