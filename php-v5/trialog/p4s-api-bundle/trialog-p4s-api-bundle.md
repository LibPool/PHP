# trialog/p4s-api-bundle

> 标签: PHP

## 简介

Un bundle PHP / Symfony2 permettant une intégration facile de l'API du P4S - Projet AMISURE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
