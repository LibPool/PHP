# barretstorck/tempus-machina

> 标签: clock, psr-20, psr20, time, timestamp

## 简介

A PSR-20 compliant PHP clock library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
