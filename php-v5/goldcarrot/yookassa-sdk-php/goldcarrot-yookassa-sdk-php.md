# goldcarrot/yookassa-sdk-php

> 标签: api, payments, sdk, yookassa, yoomoney

## 简介

This is a developer tool for integration with YooMoney.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
