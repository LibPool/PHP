# editor42/editor42-drupal

> 标签: drupal, editor42, html editor, rich text editor, wysiwyg

## 简介

Editor42, the free MIT-licensed WYSIWYG HTML editor, as a Drupal library: the same build as editor42/editor42, installed into web/libraries/editor42.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
