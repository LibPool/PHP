# mingalevme/illuminate-google

> 标签: google, google-api, laravel, lumen

## 简介

Provides Google API Library for PHP wrapper for Laravel/Lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
