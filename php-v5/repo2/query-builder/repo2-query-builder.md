# repo2/query-builder

> 标签: builder, mysql, query, sql

## 简介

Query Builder is a fast compiler for MySQL compatible queries written in PHP 5.4+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
