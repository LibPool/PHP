# danielneis/moodle-mod_webrtcexperiments

> 标签: PHP

## 简介

This is a Moodle plugin for users interact with audio and video using WebRTC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
