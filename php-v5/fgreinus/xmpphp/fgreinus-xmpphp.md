# fgreinus/xmpphp

> 标签: PHP

## 简介

XMPPHP is an elegant PHP library for XMPP (aka Jabber, Google Talk, Facebook etc).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
