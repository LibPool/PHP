# genouest/biomaj-bundle

> 标签: biomaj, genouest

## 简介

This bundle allows you to use the BioMAJ REST API from a Symfony application. For more information on BioMAJ, see http://biomaj.genouest.org/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
