# stellarwp/learndash-php-sniffs

> 标签: PHP

## 简介

A set of PHP_CodeSniffer sniffs that I couldn't find anywhere else

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
