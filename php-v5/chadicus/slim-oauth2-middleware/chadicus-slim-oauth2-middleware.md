# chadicus/slim-oauth2-middleware

> 标签: middleware, oauth2, slim

## 简介

OAuth2 middleware for use within a Slim Framework API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
