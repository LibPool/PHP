# siganurame/acl-gate

> 标签: Policy, acl, gate, laravel, permissions, roles

## 简介

Simple Laravel 5 ACL: roles and permissions based on Laravel Gate system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
