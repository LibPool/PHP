# hungtrinh/zend-mail-oauth2

> 标签: xoauth2, zend-mail, zend-mail-oauth2, zend-mail-xoauth2

## 简介

IMAP, POP3, SMTP work with XOAUTH2 authentication for Zend Mail, Zend Framework 1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
