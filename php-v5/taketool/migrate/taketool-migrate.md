# taketool/migrate

> 标签: PHP

## 简介

Toolset for supporting Typo3 migrations by rewriting templates, folders, files using commands or migration wizards.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
