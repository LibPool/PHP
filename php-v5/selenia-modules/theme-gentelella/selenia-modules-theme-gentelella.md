# selenia-modules/theme-gentelella

> 标签: electro, plugin, selenia

## 简介

A theme for Selenia based on the Open Source Gentelella Bootstrap 3 Admin Template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
