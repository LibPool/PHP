# webdevstudios/wds-shortcodes

> 标签: json, wordpress, wp-api

## 简介

Base plugin/classes/functionality for creating shortcodes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
