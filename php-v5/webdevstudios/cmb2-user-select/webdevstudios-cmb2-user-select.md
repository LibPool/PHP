# webdevstudios/cmb2-user-select

> 标签: CMB2, meta, wordpress

## 简介

Special CMB2 Field that allows users to define an autocomplete text field for users

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
