# jheferson-br/tpdf

> 标签: PHP

## 简介

Lib em PHP para criação de arquivos PDF. Uso restrito para projetos Adianti

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
