# figuren-theater/label-printing

> 标签: Label-Printing, blocks, gutenberg, print.css, theater, wordpress, wordpress-plugin

## 简介

Create printable labels with blocks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
