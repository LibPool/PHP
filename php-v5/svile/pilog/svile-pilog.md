# svile/pilog

> 标签: file, logging, pilog, psr

## 简介

A simple PHP logging system which is PSR-2, PSR-3 and PSR-4 compliable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
