# league/factory-muffin-faker

> 标签: factory, faker, testing

## 简介

The goal of this package is to wrap faker to make it super easy to use with factory muffin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
