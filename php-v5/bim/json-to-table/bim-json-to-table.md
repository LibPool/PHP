# bim/json-to-table

> 标签: json, jsonpath, path

## 简介

JSONPath implementation for querying and updating JSON objects with support for json flattening into a table

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
