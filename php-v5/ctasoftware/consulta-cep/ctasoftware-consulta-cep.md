# ctasoftware/consulta-cep

> 标签: cep, correios, php

## 简介

Com esse pacote você poderá realizar consultas de CEP gratuitamente.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
