# appserver-io/authenticator

> 标签: dependency, injection, interface, php

## 简介

Authenticator implementations for Basic, Digest and Form based HTTP authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
