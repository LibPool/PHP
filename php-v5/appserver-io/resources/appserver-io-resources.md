# appserver-io/resources

> 标签: Settings, bundle, resources

## 简介

Package that provides basic functionality to handle resource bundles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/appserver-io/resources
- 源码仓库：https://github.com/appserver-io/resources.git
- Packagist 页面：https://packagist.org/packages/appserver-io%2Fresources

- Composer 安装：`composer require appserver-io/resources`
