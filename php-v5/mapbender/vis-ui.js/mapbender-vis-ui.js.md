# mapbender/vis-ui.js

> 标签: assets, jquery, vis-ui

## 简介

JavaScript UI generator framework based on jQuery UI  and some other elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
