# php-parallel-lint/php-parallel-lint

> 标签: lint, static analysis

## 简介

This tool checks the syntax of PHP files about 20x faster than serial check.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
