# bupy7/xml-constructor

> 标签: library, php, xml, xml constructor, xml maker, xml writter

## 简介

The array-like constructor of XML document structure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
