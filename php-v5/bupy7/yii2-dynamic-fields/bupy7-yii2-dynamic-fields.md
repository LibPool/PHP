# bupy7/yii2-dynamic-fields

> 标签: dynamic, extension, fields, multiple, pjax, widget, yii2

## 简介

Widget for display dynamic fields, adding and removing their use Pjax.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
