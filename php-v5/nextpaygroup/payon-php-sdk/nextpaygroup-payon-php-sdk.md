# nextpaygroup/payon-php-sdk

> 标签: nextpay, payment, payon, vimo

## 简介

PayOn SDK is the payment solution for web/app support: ATM, QR-code, Visa/Mastercard/JCB ...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
