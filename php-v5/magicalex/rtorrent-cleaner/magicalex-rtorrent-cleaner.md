# magicalex/rtorrent-cleaner

> 标签: clean, cleaner, console, file, phar, rtorrent, rutorrent

## 简介

rtorrent-cleaner is a tool to clean up unnecessary files in rtorrent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
