# magicalex/write-ini-file

> 标签: file, ini, write, write_ini_file

## 简介

Write-ini-file php library for create, remove, erase, add, and update ini file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
