# elibyy/tcpdf-laravel

> 标签: TCPDF, laravel, pdf

## 简介

tcpdf support for Laravel 6, 7, 8, 9, 10, 11

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
