# fornit1917/yii2-emigrate

> 标签: migrations, yii2

## 简介

Yii2 Framework extension for simplification of code generation when creating some migrations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
