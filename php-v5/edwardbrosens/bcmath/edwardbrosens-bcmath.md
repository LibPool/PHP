# edwardbrosens/bcmath

> 标签: Arbitrary-precision, bcmath, class, php

## 简介

Convenience wrapper for the php bcmath extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
