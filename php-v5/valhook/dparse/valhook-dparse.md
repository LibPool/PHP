# valhook/dparse

> 标签: dom, dparse, ganon, php

## 简介

dParse is a strong jQuery-like HTML/XML parser written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
