# lithemod/upload

> 标签: PHP

## 简介

A versatile module for efficiently managing file uploads in PHP, ensuring seamless integration and robust error handling.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
