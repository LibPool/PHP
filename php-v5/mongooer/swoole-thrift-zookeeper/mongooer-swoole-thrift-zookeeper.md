# mongooer/swoole-thrift-zookeeper

> 标签: PHP

## 简介

swoole + thrift + zookeeper 实现 RPC微服务客户端服务端的集中管理

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
