# nathanday/module-subcategoryblocks

> 标签: PHP

## 简介

Extend Magento 2 Category Display Options to add Functionality to show Subcategory Blocks or List

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
