# puerari/moodle_rest_api

> 标签: Puerari, api, moodle, rest

## 简介

MOODLE_REST_API is a PHP package that abstracts the interaction with Moodle through its REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
