# calcinai/phpi

> 标签: GPIO, pi, pwm, raspberry, rpi, spi, websocket

## 简介

Event driven bindings for the Raspberry Pi GPIO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
