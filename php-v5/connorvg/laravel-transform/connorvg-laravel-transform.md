# connorvg/laravel-transform

> 标签: api, array, laravel

## 简介

An array transformer, built for APIs, w/ Laravel bindings (Laravel not required)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
