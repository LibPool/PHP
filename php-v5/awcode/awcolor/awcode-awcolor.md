# awcode/awcolor

> 标签: color, hex, hsl, rgb

## 简介

Color management class allowing usage and manipulation between rgb, hex, and hsl colours.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
