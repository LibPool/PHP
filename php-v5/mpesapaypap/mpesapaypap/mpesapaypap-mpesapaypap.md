# mpesapaypap/mpesapaypap

> 标签: daraja-api, mpesa, mpesa-payment

## 简介

A simple mpesa daraja api helper in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
