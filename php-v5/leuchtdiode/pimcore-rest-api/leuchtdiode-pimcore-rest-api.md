# leuchtdiode/pimcore-rest-api

> 标签: module, pimcore, zend framework 2

## 简介

Zend Framework 2 module for accessing pimcore via its REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
