# dukim/php-emv

> 标签: ber, ber-tlv, codec, decoder, emv, encoder, tlv

## 简介

A collection of EMV tools and utilities for PHP 5.3+ (fork of Massimo Lombardo's project)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
