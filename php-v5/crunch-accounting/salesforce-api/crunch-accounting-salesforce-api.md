# crunch-accounting/salesforce-api

> 标签: api, oauth2, rest, salesforce

## 简介

A library for interacting with the Salesforce REST API and managing the OAuth flow

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
