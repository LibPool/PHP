# fos-gregooz/elastica-bundle

> 标签: doctrine2, elastica, elasticsearch, mongodb, search

## 简介

Elasticsearch PHP integration for your Symfony project using Elastica

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
