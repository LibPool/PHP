# tde/twig-webpack-manifest

> 标签: PHP

## 简介

Injects CSS/JS in HTML templates, based on the generated Webpack manifest.json

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
