# teamones/phpcent

> 标签: centrifugo, messaging, realtime, websocket

## 简介

PHP library to communicate with Centrifugo HTTP API（use workerman support async request）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
