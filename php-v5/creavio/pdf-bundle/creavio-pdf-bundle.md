# creavio/pdf-bundle

> 标签: Symfony2, bundle, creavio, mpdf, pdf, symfony3

## 简介

Symfony Bundle for generating PDF with mPDF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
