# ehann/jquery-bundle

> 标签: Symfony2, bundle, jquery

## 简介

Makes available jQuery, jQuery UI, and some jQuery plugins in Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
