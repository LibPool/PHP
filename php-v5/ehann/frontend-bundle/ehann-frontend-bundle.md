# ehann/frontend-bundle

> 标签: Symfony2, bootstrap, bundle, frontend, twitter

## 简介

Provides frontend components and layouts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
