# ferdynator/phpword

> 标签: Symfony2, doc, docx, word

## 简介

PHPWord is a library written in PHP that create word documents. This Package is modified to work with Symfony 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
