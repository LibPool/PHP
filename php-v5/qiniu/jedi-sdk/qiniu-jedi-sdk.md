# qiniu/jedi-sdk

> 标签: cloud, jedi, qiniu, sdk, storage, video

## 简介

Qiniu Video Solution SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
