# yunhanphp/lumen-dev-db-doc

> 标签: DBDoc, YunhanTech, laravel

## 简介

每次开发项目时，总是会被要求提供数据字典，每次手动写文档太累了，所以写了这个扩展，自动读取数据库信息并显示在网页上，支持导出Html和PDF文件。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
