# lshtmweb/mailer-laravel

> 标签: drivers, emails, laravel, mailer

## 简介

Mail driver for Mailer system. You will need the mailer system for this to work.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
