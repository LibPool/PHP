# sylius/taxonomies-bundle

> 标签: categorization, category, ecommerce, shop, sylius, taxonomies, taxonomy

## 简介

Flexible categorization system for Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
