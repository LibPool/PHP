# blocktrail/cryptojs-aes-php

> 标签: PHP

## 简介

Small openssl_encrypt/decrypt wrapper to be compatible with CryptoJS.AES

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
