# vinelab/oauth-clients-generator-redis

> 标签: client, client-generator, database, oauth2, redis

## 简介

Redis Client Generator for the League's PHP OAuth 2.0 server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
