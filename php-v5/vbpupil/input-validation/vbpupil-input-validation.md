# vbpupil/input-validation

> 标签: form, input, regex, validate, validation

## 简介

Very simple Form Input Validation for when you want to use your own existing forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
