# rene-roscher/teamspeak3-framework

> 标签: api, framework, serverquery, teamspeak3, ts3

## 简介

TeamSpeak 3 PHP Framework refactored to be compatible with composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
