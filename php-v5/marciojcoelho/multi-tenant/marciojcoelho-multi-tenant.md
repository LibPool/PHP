# marciojcoelho/multi-tenant

> 标签: domains, laravel, multisite

## 简介

A simple and lightweight package to craft multi-tenant applications with Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
