# nikrolls/ss_firephp

> 标签: firebug, firephp, silverstripe

## 简介

A module to allow easy installation of FirePHP in Silverstripe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
