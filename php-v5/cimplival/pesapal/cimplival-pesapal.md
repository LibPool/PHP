# cimplival/pesapal

> 标签: Orange Money, laravel 5, mastercard, mpesa, payments, pesapal, visa

## 简介

A laravel package that integrates into the pesapal api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
