# loops/gif

> 标签: animated gif, gif

## 简介

Unpacker/packer for GIF and especially animated GIF.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/lxxps/loops-gif
- 源码仓库：https://bitbucket.org/lxxps/loops-gif.git
- Packagist 页面：https://packagist.org/packages/loops%2Fgif
