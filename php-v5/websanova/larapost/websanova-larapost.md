# websanova/larapost

> 标签: blog, docs, documentation, larapost, laravel, markdown, posts, tag, tagging, tags

## 简介

Drop in blog, docs, tagging solution for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
