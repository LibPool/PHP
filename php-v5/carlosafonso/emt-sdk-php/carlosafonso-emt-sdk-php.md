# carlosafonso/emt-sdk-php

> 标签: carlosafonso, emt-sdk-php

## 简介

Unofficial PHP SDK for Madrid's EMT OpenData API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
