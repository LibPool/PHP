# jlozanomaltos/json-reducer

> 标签: json, laravel, lumen, reducer

## 简介

An array size reducer (for JSON output purposes) using Models, Collections, Arrays

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
