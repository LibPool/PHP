# josephfusco/twentytwenty-font-fix

> 标签: PHP

## 简介

This WordPress plugin is a temporary solution for the font rendering issue introduced in Chrome 79.0.3945.88.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
