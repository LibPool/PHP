# josephfusco/symlinked-plugin-branch

> 标签: git, plugin, wordpress

## 简介

Easily identify the current git branch of your symlinked WordPress plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
