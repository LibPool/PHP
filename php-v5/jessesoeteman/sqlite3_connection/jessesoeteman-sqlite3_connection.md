# jessesoeteman/sqlite3_connection

> 标签: PHP

## 简介

This class is used to connect to a SQLite3 database. It contains methods to execute queries and statements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
