# wnipun/wp-memoize

> 标签: Memoize Cache, Memoize Caching, wordpress

## 简介

Simple disk based caching library for WordPress builds that use roots.io Bedrock.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
