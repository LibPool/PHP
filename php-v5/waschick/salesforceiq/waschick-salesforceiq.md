# waschick/salesforceiq

> 标签: api, laravel, laravel4, relateiq, salesforce, salesforceiq, standalone, wrapper

## 简介

SalesforceIQ (RelateIQ) API v2 client for Laravel & standalone projects. Forked from torann/relateiq.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
