# lcoy/synopsis

> 标签: discussion, excerpt, excerpts, flarum, summaries, summary, synopsis

## 简介

Show summary excerpts on discussion lists with media control.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
