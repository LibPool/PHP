# dutchie027/govee

> 标签: govee, home automation, lights, php, plugs

## 简介

A simple PHP package for controlling Govee Wi-Fi systems via their API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
