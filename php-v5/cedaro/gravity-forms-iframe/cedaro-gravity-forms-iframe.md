# cedaro/gravity-forms-iframe

> 标签: gravity forms, iframe, wordpress

## 简介

Embed a Gravity Form on any site using an iframe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
