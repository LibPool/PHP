# vitorbari/glpi-webservice-php-wrapper

> 标签: glpi, webservice

## 简介

PHP wrapper class for GLPI Webservice Plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
