# bulaohe/swoole

> 标签: http, laravel, lumen, performance, server, swoole

## 简介

High performance HTTP server based on Swoole. Speeds up your Laravel and Lumen applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
