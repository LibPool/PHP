# llack/php-toss-stock

> 标签: api, korea, rest, stock, toss, toss-securities, tossinvest, trading

## 简介

토스증권 Open API 비공식 PHP 클라이언트. client_id/client_secret 두 개로 초기화하는 단일 클래스. PHP 5.6 ~ 8.x 지원.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
