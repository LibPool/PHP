# fragotesac/phpqrcode

> 标签: php, qrcode

## 简介

A PHP class to generate QR Code. Fork of t0k4rt/phpqrcode with composer support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
