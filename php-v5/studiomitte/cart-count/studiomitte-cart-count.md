# studiomitte/cart-count

> 标签: cart, count, extension, typo3

## 简介

Endpoint for EXT:cart cart information which can be retrieved by an AJAX request

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
