# itgalaxy/pillar

> 标签: wordpress, wordpress-plugin

## 简介

Collection WordPress mini plugins (theme features) to apply theme-agnostic modifications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
