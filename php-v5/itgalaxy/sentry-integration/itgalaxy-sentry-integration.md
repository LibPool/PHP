# itgalaxy/sentry-integration

> 标签: sentry, wordpress

## 简介

A (unofficial) WordPress plugin to report PHP and JavaScript errors to Sentry

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
