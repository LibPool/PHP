# unionofrad/li3_docs

> 标签: api, docblock, docs, documentation, li3, lithium, wiki

## 简介

An API and wiki-like documentation generator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
