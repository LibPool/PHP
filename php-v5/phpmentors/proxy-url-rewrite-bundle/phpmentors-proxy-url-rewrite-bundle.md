# phpmentors/proxy-url-rewrite-bundle

> 标签: URL rewriting, proxy, symfony

## 简介

A Symfony bundle to rewrite URLs for applications behind reverse proxies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
