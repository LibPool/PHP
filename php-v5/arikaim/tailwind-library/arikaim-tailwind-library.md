# arikaim/tailwind-library

> 标签: Arikaim, Tailwind CSS library for Arikaim CMS, ui

## 简介

Tailwind CSS library for Arikaim CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
