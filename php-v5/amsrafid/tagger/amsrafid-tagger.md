# amsrafid/tagger

> 标签: amsrafid, attribute, html, markup, tag, tagger, view

## 简介

Perfect view builder for php with inbuilt control statement.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
