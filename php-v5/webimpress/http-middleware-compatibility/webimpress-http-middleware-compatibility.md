# webimpress/http-middleware-compatibility

> 标签: middleware, psr-15, webimpress

## 简介

Compatibility library for Draft PSR-15 HTTP Middleware

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
