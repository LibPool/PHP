# immobiliare/sentry-php

> 标签: log, logging, php 5.2, php52, sentry, sentry-php

## 简介

Fork of a PHP client for Sentry (http://getsentry.com) that work also with php5.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
