# pushword/template-editor

> 标签: admin, cms, pushword, template-editor, theme-editor, twig

## 简介

Edit Twig view files online from the Pushword admin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
