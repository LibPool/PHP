# xorti/mxgraph-editor

> 标签: PHP

## 简介

This repository contains the grapheditor example and the mxGraph src to display the necessary files to build your own editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
