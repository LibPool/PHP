# lykegenes/laravel-table-view

> 标签: datatable, laravel

## 简介

An API-based table view for Laravel. Based on Vue.js and Element-UI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
