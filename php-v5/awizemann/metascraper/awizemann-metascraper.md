# awizemann/metascraper

> 标签: laravel, meta tags

## 简介

Laravel package to get all the meta data from a URL (forked from rookmoot/metascraper)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
