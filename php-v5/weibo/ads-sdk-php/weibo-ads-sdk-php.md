# weibo/ads-sdk-php

> 标签: ad sdk, weibo

## 简介

php SDK for Weibo AD

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://developers.biz.weibo.com
- 源码仓库：https://github.com/weiboad/weibo-ads-php-sdk.git
- Packagist 页面：https://packagist.org/packages/weibo%2Fads-sdk-php

## 获取地址

- Composer 安装：`composer require weibo/ads-sdk-php`
- Packagist 仓库：https://repo.packagist.org/p2/weibo/ads-sdk-php.json
- PHP 要求：>=5.5
