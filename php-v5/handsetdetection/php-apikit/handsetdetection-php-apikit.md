# handsetdetection/php-apikit

> 标签: detection, device, user-agent

## 简介

A library for stand alone or web service device detection, using HandsetDetection.com.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
