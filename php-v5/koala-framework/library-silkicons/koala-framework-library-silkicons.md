# koala-framework/library-silkicons

> 标签: famfamfam, icons, silk

## 简介

This is the Famfamfam silk icon set, wrapped into an easy to use PHP composer package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
