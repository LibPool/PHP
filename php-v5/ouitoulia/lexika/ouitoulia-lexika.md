# ouitoulia/lexika

> 标签: PHP

## 简介

Lexikà è un modulo Drupal che installa i vocabolari utilizzati dalle scuole.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
