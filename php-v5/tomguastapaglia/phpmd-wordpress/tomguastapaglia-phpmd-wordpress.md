# tomguastapaglia/phpmd-wordpress

> 标签: PHP

## 简介

phpmd rules to add snake_case validation for Wordpress coding style convention

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
