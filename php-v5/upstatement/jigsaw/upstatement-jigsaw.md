# upstatement/jigsaw

> 标签: admin, tweaks, wordpress

## 简介

Provides an easy API for developers to tweak the admin options of a WordPress install

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
