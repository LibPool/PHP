# drupal-eca-recipe/eca_lib_0046

> 标签: PHP

## 简介

One model building an editorial desk: a composite block assembled element by element from a heading, a dropbutton, an embedded view and a details panel; a deferred region resolved through a lazy element; an endpoint serving JSON, an HTMX fragment and a bare timestamp with per-branch status codes, headers and cache lifetimes; and a counter that re-fetches only when the endpoint announces an event through the HX-Trigger header.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
