# sharelov/notification

> 标签: flash, instant, laravel, messages, notifications

## 简介

Package for Laravel for helping to manage flash / instant notifications / messages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
