# verdet/sphinxsearch-bundle

> 标签: Symfony2, sphinx, sphinxsearch

## 简介

Sphinx search bundle for Symfony 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
