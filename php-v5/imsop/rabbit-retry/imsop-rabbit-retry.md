# imsop/rabbit-retry

> 标签: PHP

## 简介

Delay RabbitMQ messages by a set amount, or re-queue them a limited amount of time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
