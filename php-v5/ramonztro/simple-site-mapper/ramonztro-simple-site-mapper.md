# ramonztro/simple-site-mapper

> 标签: PHP

## 简介

SimpleSiteMapper allows you to easily create and edit sitemap.xml files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
