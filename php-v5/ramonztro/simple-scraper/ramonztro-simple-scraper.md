# ramonztro/simple-scraper

> 标签: PHP

## 简介

SimpleScraper allows you to fetch Open Graph Protocol data, Twitter Card data and/or meta tags data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
