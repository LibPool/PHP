# ignitekit/wp-query-builder

> 标签: database, models, query builder, wordpress

## 简介

Wordpress Query Builder class library for custom models and data querying.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
