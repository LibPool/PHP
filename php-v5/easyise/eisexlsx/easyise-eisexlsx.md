# easyise/eisexlsx

> 标签: OpenXML, SpreadSheetML, excel, spreadsheets, xlsx

## 简介

XLSX file data read-write library that operates with native cell addresses like A1 or R1C1.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
