# adamb/sitemap

> 标签: PHP

## 简介

Create a sitemap for your domain, crawls all URL's except those with nofollow links and those explicitly stated to ignore to create the sitemap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
