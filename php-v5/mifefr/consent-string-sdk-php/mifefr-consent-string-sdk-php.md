# mifefr/consent-string-sdk-php

> 标签: TCF, cmp, consent, consent-string, cookie, gdpr, iab, iabtcf, privacy, rgpd, tcf-v2, tcstring

## 简介

IAB Europe Transparency and Consent Framework (TCF) v2.3 and v1.1 consent string decoder and encoder for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
