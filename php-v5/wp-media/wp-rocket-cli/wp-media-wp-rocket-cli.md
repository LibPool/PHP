# wp-media/wp-rocket-cli

> 标签: cache, rocket, wp-cli

## 简介

Add a `wp rocket` command to support the WP Rocket plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
