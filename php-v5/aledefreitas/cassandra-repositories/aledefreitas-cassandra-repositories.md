# aledefreitas/cassandra-repositories

> 标签: PHP

## 简介

Implementation of `aledefreitas/eloquent-repositories` using Cassandra as database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
