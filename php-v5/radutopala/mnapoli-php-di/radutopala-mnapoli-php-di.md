# radutopala/mnapoli-php-di

> 标签: container, dependency injection, di

## 简介

PHP-DI is a Container that makes Dependency Injection as practical as possible in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
