# arkitecht/firewall

> 标签: blacklist, firewall, laravel, whitelist

## 简介

A Laravel 4.1+ IP whitelisting and blacklisting

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
