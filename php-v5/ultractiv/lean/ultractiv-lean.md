# ultractiv/lean

> 标签: api, framework, lean, lean development, mvc, rest

## 简介

The PHP framework for simple, REST API backend. It gets out of your way, so you can get your work done.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
