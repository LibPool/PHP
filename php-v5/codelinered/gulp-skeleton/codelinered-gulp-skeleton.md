> 标签: FontAwesome, Skeleton, boilerplate, bootstrap, carousel, cookie, cookieconsent, css user agent, cssua, docker, gulp, jquery, lazyload, slick, templating

## 简介

Skeleton to create templates with Gulp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
