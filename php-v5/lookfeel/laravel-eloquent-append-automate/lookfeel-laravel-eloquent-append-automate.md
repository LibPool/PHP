# lookfeel/laravel-eloquent-append-automate

> 标签: laravel, laravel accessors, laravel appends

## 简介

根据 appends 配置的关联字段映射关系，自动维护需要的 appends。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
