# sandrokeil/citools

> 标签: badges, ci, coveralls, php, qa, scrutenizer, tools, travis

## 简介

Composer meta package of QA tools for Travis, Coveralls and Scrutenizer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
