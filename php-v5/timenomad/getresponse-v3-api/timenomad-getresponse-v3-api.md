# timenomad/getresponse-v3-api

> 标签: getresponse, oauth2

## 简介

A PHP wrapper for the GetResponse V3 API, supporting OAuth2 authorization flow

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
