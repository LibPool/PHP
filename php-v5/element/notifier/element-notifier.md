# element/notifier

> 标签: Element core, messages, notifications, slack, sms

## 简介

Element package for sending out messages - either as a text-message with gatewayAPI or as a Slack notification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
