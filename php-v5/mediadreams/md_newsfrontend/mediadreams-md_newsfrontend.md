# mediadreams/md_newsfrontend

> 标签: extension, fe_users, frontend, news, typo3

## 简介

This TYPO3 extension enables frontend users to created news records.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
