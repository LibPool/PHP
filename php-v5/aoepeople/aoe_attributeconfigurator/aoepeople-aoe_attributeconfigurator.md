# aoepeople/aoe_attributeconfigurator

> 标签: PHP

## 简介

Module for attribute creation and maintenance by file instead of setup scripts or backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
