# latrell/aliyun-sls-laravel

> 标签: SLS, aliyun, l5, laravel, laravel 5

## 简介

Aliyun simple log service (SLS) SDK in Laravel5 package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
