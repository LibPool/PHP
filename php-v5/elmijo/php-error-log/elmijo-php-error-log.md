# elmijo/php-error-log

> 标签: error, error_log, log, logging, php

## 简介

Una pequeña libreria para manejar los logs de tu aplicación de forma simple.. rapida.. y directa!!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
