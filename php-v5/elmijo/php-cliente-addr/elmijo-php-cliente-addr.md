# elmijo/php-cliente-addr

> 标签: HTTP_CLIENT_IP, HTTP_FORWARDED, HTTP_FORWARDED_FOR, HTTP_X_CLUSTER_CLIENT_IP, HTTP_X_FORWARDED, HTTP_X_FORWARDED_FOR, IP, REMOTE_ADDR, addr, cliente, hostname

## 简介

Una pequeña clase para obtener la IP y el HostName del cliente

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
