# alexmanno/serializer-bundle

> 标签: deserialization, jaxb, json, serialization, xml

## 简介

Allows you to easily serialize, and deserialize data of any complexity

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
