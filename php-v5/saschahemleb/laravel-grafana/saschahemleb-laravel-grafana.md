# saschahemleb/laravel-grafana

> 标签: grafana, laravel

## 简介

A saschahemleb/php-grafana-api-client bridge for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
