# mrbase/smesg

> 标签: communication, gateway, sms

## 简介

Providing wrappers for danish sms gateways

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/mrbase/Smesg
- 源码仓库：https://github.com/mrbase/Smesg.git
- Packagist 页面：https://packagist.org/packages/mrbase%2Fsmesg

## 获取地址

- Composer 安装：`composer require mrbase/smesg`
- Packagist 仓库：https://repo.packagist.org/p2/mrbase/smesg.json
- PHP 要求：>=5.3.2
