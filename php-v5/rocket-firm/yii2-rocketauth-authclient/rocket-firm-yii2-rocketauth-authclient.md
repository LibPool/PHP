# rocket-firm/yii2-rocketauth-authclient

> 标签: auth, firm, oauth2, rocket, rocketfirm, yii2, yii2-authclient

## 简介

RocketAuth extension for using via yii2-authclient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
