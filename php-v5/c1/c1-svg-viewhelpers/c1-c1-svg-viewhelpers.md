# c1/c1-svg-viewhelpers

> 标签: ViewHelpers, fluid, svg, symbol, templating

## 简介

SVG viewhelpers - include SVGs as symbol files in TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
