# adamjenkins/moodle-local_langcrowd

> 标签: crowdsourcing, l10n, language, local, moodle, translation

## 简介

Language Crowdsourcing for Moodle — users collaboratively build and vote on language pack translations inline in the Moodle interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
