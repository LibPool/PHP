# adamjenkins/moodle-local_gradeheatmap

> 标签: PHP

## 简介

Colour-codes the Moodle gradebook grader report by grade percentage, so teachers can see at a glance where students are struggling and excelling

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
