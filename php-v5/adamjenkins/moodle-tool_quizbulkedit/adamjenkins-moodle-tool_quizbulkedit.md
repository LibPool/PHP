# adamjenkins/moodle-tool_quizbulkedit

> 标签: PHP

## 简介

A Moodle admin tool that changes the settings of some or all quizzes in a course in one go

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
