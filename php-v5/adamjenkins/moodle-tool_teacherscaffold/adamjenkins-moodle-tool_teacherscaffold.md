# adamjenkins/moodle-tool_teacherscaffold

> 标签: PHP

## 简介

A Moodle admin tool that eases new teachers into Moodle, starting them with a small set of simple activity types and unlocking more in stages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
