# firebrandhq/s3fileupload

> 标签: aws, s3, silverstripe, uploadfield

## 简介

Extend the SilverStripe UploadField to allow storing file in Amazone S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
