# paga/paga-merchant

> 标签: PHP

## 简介

The PAGA Merchant API platform exposes operations that are useful for Merchants to provide PAGA’s services to themselves or third-party clients.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
