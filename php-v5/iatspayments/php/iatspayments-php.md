# iatspayments/php

> 标签: api, payment processing

## 简介

iATS Payments API PHP wrapper library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/iatspayments/php
- 源码仓库：https://github.com/iATSPayments/PHP.git
- Packagist 页面：https://packagist.org/packages/iatspayments%2Fphp
