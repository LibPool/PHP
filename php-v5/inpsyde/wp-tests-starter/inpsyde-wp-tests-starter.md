# inpsyde/wp-tests-starter

> 标签: integration tests, tests, wordpress

## 简介

A package that helps you setting up WordPress integration test environments quickly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
