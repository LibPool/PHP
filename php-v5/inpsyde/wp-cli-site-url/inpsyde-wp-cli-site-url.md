# inpsyde/wp-cli-site-url

> 标签: PHP

## 简介

Provides a commandline interface to WordPress multisite site URLs using WP-CLI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
