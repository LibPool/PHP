# vtmer/gdut-login-helper

> 标签: api, gdut, login

## 简介

API libraries used to verify student's identity and retrieve informations from GDUT's websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
