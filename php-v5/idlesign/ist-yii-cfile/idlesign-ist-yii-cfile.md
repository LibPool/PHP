# idlesign/ist-yii-cfile

> 标签: files, filesystem, yii

## 简介

CFile provides means to manipulate filesystem objects both from Yii and standalone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
