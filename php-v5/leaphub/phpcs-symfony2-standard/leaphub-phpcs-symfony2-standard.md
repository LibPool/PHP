# leaphub/phpcs-symfony2-standard

> 标签: Coding Standard, phpcs, symfony 2

## 简介

A PHP_CodeSniffer standard for Symfony 2 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
