# rkw/rkw-graphics

> 标签: E-Mails, RKW, TYPO3 CMS, newsletter

## 简介

Extension for displaying charts with ApexCharts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
