# flatorb/moldssp

> 标签: datatables, laravel, mongodb, pagination, server side processing, ssp

## 简介

A package library to use laravel pagination with datatables and mongodb.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
