# arifpavel/elementor-stubs

> 标签: elementor, static analysis

## 简介

Elementor function, class, and global variable declaration stubs for easier static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
