# diemedialen/dm-developerlog

> 标签: PHP

## 简介

An extension to capture TYPO3 devlog messages for debugging. Provides a backend module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
