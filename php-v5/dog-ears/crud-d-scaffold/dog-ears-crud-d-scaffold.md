# dog-ears/crud-d-scaffold

> 标签: crud, generators, laravel, laravel7, scaffold

## 简介

Extend Laravel 7's generators scaffold.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
