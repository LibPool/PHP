# clientedigital/pipefy

> 标签: graphql, pipefy

## 简介

A Pipefy API wrapper that uplift productivity of newcomers to graphQL tech.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
