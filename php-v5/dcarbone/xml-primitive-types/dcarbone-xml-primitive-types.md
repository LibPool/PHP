# dcarbone/xml-primitive-types

> 标签: factory, primitive, primitives, xml, xsd

## 简介

Library containing PHP classes for XML Primitives and Derived Primitives

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
