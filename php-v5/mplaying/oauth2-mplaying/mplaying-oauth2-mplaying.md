# mplaying/oauth2-mplaying

> 标签: PHP

## 简介

MPlaying Reallife OAuth2 Provider implementation for thephpleague/oauth2-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
