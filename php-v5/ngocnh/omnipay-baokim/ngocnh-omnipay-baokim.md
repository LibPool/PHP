# ngocnh/omnipay-baokim

> 标签: baokim, gateway, merchant, omnipay, pay, payment, paypal, purchase

## 简介

Baokim gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
