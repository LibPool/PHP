# hpcloud/hpcloud-php

> 标签: Openstack, cloud, hpcloud, nova, swift

## 简介

Access HPCloud and OpenStack services in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
