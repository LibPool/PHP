# jervdesign/php-unit-mock

> 标签: class, mock, object, phpunit

## 简介

Base Class for creating reusable PHPUnit Mock Objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
