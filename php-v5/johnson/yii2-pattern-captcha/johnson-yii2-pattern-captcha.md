# johnson/yii2-pattern-captcha

> 标签: extension, yii2

## 简介

Yii2 pattern captcha is nine dots based pattern Captcha to match with the numbers given in the box

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
