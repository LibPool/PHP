# webcito/bs-layer

> 标签: bootstrap, jquery, layer

## 简介

A lightweight sliding layer system for jQuery and Bootstrap 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
