# webcito/jquery-heatmap

> 标签: heatmap, interactive, jquery, plugin, visualization

## 简介

A jQuery plugin for creating interactive heatmap visualizations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
