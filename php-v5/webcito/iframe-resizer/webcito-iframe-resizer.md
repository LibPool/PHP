# webcito/iframe-resizer

> 标签: Resizer, communication, iframe, javascript, library

## 简介

A JavaScript library for dynamic iframe resizing and communication.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
