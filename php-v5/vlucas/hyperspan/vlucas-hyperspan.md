# vlucas/hyperspan

> 标签: Siren, api, hal, hal json, hypermedia, hypermedia api, siren json

## 简介

Build a Hypermedia API response once and return it in multiple formats

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
