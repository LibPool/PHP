# ryssbowh/craft-triggers

> 标签: Craft, cms, craft-plugin, craftcms, event, trigger

## 简介

Run actions when events are triggered in Craft

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
