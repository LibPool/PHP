# piphp/pipin

> 标签: GPIO, pi, pin, pins, pipin, raspberry

## 简介

A tool for accessing the GPIO pins on a Raspberry Pi

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
