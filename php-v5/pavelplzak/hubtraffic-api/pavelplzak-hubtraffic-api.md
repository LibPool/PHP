# pavelplzak/hubtraffic-api

> 标签: hubtraffic, pornhub, redtube, youporn

## 简介

Get video information from servers like redtube.com, pornhub.com and youporn.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
