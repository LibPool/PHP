# primitivesocial/bluemoonsoapwrapper

> 标签: BlueMoonSoapWrapper, laravel

## 简介

Bluemoon SOAP wrapper for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
