# nails/driver-geo-ip-ipstack

> 标签: GeoIP Module, Nails, Shed Collective, codeigniter, driver, ipstack

## 简介

This is the "IPStack" driver for the Nails GeoIP module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
