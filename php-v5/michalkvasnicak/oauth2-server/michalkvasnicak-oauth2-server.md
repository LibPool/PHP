# michalkvasnicak/oauth2-server

> 标签: Authentication, authorization, oauth, php, security

## 简介

OAuth 2.0 server implementation for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
