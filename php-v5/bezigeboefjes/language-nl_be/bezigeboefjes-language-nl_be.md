# bezigeboefjes/language-nl_be

> 标签: PHP

## 简介

Bezigeboefjes Dutch (Belgium) Language Pack for Magento 2 (CE)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
