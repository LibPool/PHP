# jp3cki/yii2-ubuntu-font

> 标签: PHP

## 简介

Ubuntu webfont asset for Yii Framework 2 (uses Google Fonts)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
