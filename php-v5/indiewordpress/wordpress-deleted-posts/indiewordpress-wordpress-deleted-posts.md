# indiewordpress/wordpress-deleted-posts

> 标签: PHP

## 简介

Sends a HTTP 410 (Gone) response to requests for trashed posts/pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
