# 99designs/moa

> 标签: 99designs, activerecord, datamapper, mongo, mongodb, odm, orm

## 简介

The rightweight data mapper for mongoDB and PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
