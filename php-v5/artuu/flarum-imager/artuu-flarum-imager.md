# artuu/flarum-imager

> 标签: artuu, flarum, imager

## 简介

Allows you to set default sizes for photos uploaded to the forum and change their size in the url.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
