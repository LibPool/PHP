# gnugat/redaktilo-bundle

> 标签: bundle, editor, insert, line, redaktilo, remove, replace, symfony

## 简介

Provides Redaktilo's Editor and TextFactory as services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
