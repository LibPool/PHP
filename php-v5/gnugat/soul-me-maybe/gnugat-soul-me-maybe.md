# gnugat/soul-me-maybe

> 标签: EPITECH, NetSoul, client

## 简介

A NetSoul client to allow internet connection at EPITECH.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
