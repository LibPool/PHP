# moell/laravel-layui-admin

> 标签: admin, laravel, laravel admin, laravel layui admin, layui, layui admin

## 简介

基于 Laravel, Layui 构建的 RBAC 后台管理系统。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
