# jucksearm/yii2-sly-slider

> 标签: image slide, jquery, slider, sly, yii2

## 简介

Yii2 extension is a wrapper for the jquery slider 'sly' http://darsa.in/sly/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
