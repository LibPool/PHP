# heige/hg-php

> 标签: PHP

## 简介

hg-php framework based tp3.2 + slim2.6 + laravel routing mechanism to build the tp-mvc framework for api, web development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
