# fipps/contao-jasny-bootstrap

> 标签: bootstrap, contao, jasny

## 简介

Jasny Bootstrap extension for Contao Open Source CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
