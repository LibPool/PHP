# components/rubaxa-sortable

> 标签: HTML5, and, dnd, drag, drop, list, reorder, sortable

## 简介

Sortable is a JavaScript library for reorderable drag-and-drop lists.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
