# wpscholar/wp-trait-post-thumbnail

> 标签: PHP

## 简介

A trait for adding methods for fetching data related to post thumbnails in WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
