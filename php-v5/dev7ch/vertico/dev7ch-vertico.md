# dev7ch/vertico

> 标签: PHP

## 简介

LUYA CMS boilerplate to kickstart projects with Verti Theme by HTML5UP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
