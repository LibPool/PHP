# mattgrayisok/craft-list-builder

> 标签: Craft, cms, craft-plugin, craftcms, email, list builder, mailing list

## 简介

The ultimate Craft CMS mailing list builder. Collect emails easily and sync with popular mailing list services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
