# rmccue/requests

> 标签: curl, fsockopen, http, idna, ipv6, iri, sockets

## 简介

A HTTP library written in PHP, for human beings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
