# bereank/coupler

> 标签: PHP

## 简介

A dedicated Laravel-PHP library crafted exclusively for seamless integration with the SAP Business One Service Layer API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
