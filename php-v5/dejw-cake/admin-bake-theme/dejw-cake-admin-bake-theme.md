# dejw-cake/admin-bake-theme

> 标签: admin, bake, cakephp, cms, crud, generator, make

## 简介

Bake plugin for CakePHP to scaffold modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
