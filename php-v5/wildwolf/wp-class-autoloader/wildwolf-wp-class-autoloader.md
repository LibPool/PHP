# wildwolf/wp-class-autoloader

> 标签: autoload, autoloader, class, helper, wordpress

## 简介

Helper to load WordPress core classes automatically

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
