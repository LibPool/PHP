# lajax/yii2-asset-minifier

> 标签: JS, combine client script, compress, css, extension, minify, register, yii2

## 简介

Runtime minification and combination of asset files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
