# addons/elasticsearch

> 标签: collection, elasticsearch, l5, laravel, laravel 5, monolog, paginator

## 简介

Laravel's elasticsearch Paginator/Collection/Logger Helper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
