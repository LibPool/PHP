# edofre/yii2-fullcalendar-scheduler

> 标签: calendar, event, fullcalendar-scheduler, javascript, scheduler

## 简介

Yii2 widget for fullcalendar scheduler module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
