# edofre/laravel-softdelete-cleanup

> 标签: cleanup, command, console, laravel, softdelete

## 简介

Console command to cleanup your database from softdeleted models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
