# whois-server-list/whois-api

> 标签: domain, whois

## 简介

Client library for the Whois API. You can check the availability of internet domain names or perform whois queries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
