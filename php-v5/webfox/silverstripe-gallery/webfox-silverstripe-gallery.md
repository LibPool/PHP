# webfox/silverstripe-gallery

> 标签: carousel, gallery, silverstripe, webfox

## 简介

A Silverstripe extension to add up to two galleries/carousels etc to any page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
