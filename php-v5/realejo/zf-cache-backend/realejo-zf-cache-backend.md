# realejo/zf-cache-backend

> 标签: backend, cache, redis, sqlite3, terranet, zf

## 简介

SQLite3 and Redis support for Zend Framework 1.11.xx backend cache

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
