# pyrex-fwi/id3

> 标签: PHP

## 简介

The package lays the basis for the simple manipulation of ID3 tags.You can define readers and writers to manipulate the metadata in read or write.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
