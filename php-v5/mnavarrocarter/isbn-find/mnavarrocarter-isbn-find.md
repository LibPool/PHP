# mnavarrocarter/isbn-find

> 标签: ISBN, books, scrapper

## 简介

A web scrapper for getting books info based on ISBN10/13.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
