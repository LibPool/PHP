# ericpoe/ophp

> 标签: PHP

## 简介

Forget Haystack vs Needle order, the object IS the Haystack. Haystack is a library that allows for pipelining and immutable structures.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
