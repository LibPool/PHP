# guttmann/silverstripe-gulp-connect-php

> 标签: PHP

## 简介

A router for gulp-connect-php to make it serve SilverStripe sites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
