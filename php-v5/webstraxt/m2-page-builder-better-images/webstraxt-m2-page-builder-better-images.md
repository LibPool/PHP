# webstraxt/m2-page-builder-better-images

> 标签: PHP

## 简介

Adds options to specify explicit dimensions and loading behaviour of Page Builder images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
