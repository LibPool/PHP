# guillermo-rod/convert-string-to-file

> 标签: PHP

## 简介

Converts rich text to file (html, css, js, etc..), useful when you needs print rich text but on secure mode.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
