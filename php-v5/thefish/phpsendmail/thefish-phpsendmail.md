# thefish/phpsendmail

> 标签: PHP

## 简介

Small (one-file, to be exact) library for sending emails via SMTP server (or sendmail utility). Allows you to handle multiple recipients and attachments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
