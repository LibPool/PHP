# 023sec/svg-captcha

> 标签: captcha, no-dependency, svg

## 简介

A performant SVG Captcha PHP library, without any 3rd party dependency !

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
