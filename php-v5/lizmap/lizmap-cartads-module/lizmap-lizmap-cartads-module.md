# lizmap/lizmap-cartads-module

> 标签: cartads, jelix, lizmap, module

## 简介

Jelix module for Lizmap, enabling interactions with Cart@DS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
