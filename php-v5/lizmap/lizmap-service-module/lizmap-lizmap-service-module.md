# lizmap/lizmap-service-module

> 标签: WFS, jelix, lizmap, module, service

## 简介

Jelix module to manage direct WFS to a dedicated Lizmap project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
