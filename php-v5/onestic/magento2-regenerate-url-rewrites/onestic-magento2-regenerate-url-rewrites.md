# onestic/magento2-regenerate-url-rewrites

> 标签: extension, magento, magento 2 extension, magento 2 module, magento2 extension, magento2 module, module

## 简介

Add into Magento 2 a CLI feature which allow to regenerate a Url Rewrites of products and categories

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
