# viktorprogger/async-soap-guzzle

> 标签: Guzzle, asynchronous, soap

## 简介

An asynchronous SOAP client build on top of Guzzle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
