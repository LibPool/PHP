# fryiee/kube_accordion_block-extension

> 标签: block type, blocks, streams addon

## 简介

Display content within collapsible accordions scaffolded with Kube.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
