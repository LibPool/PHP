# cn-consult/filecloud-php

> 标签: api, filecloud, php, sdk, swagger

## 简介

The FileCloud API in an easy to use, swagger based PHP API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
