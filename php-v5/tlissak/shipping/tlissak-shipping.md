# tlissak/shipping

> 标签: PHP

## 简介

Generate PDF Label for Chronpost or Colissimo,get only the pdf to print and the tracking number

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
