# suin/symfony2-csrf-firewall-bundle

> 标签: Symfony2, csrf

## 简介

Cross site request forgery firewall bundle for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
