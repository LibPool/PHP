# suin/php-rss-writer

> 标签: feed, generator, php, rss, writer

## 简介

Yet another simple RSS writer library for PHP 5.4 or later.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
