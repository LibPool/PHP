# haberberger/redisstoragebundle

> 标签: ahaberberger, bundle, redis, symfony

## 简介

Several high level storage strategies on Redis as a Symfony2 Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
