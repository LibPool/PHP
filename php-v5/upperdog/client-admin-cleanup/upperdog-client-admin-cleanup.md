# upperdog/client-admin-cleanup

> 标签: wordpress

## 简介

This WordPress plugin hides and restricts access to some parts of the wp-admin for clients.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
