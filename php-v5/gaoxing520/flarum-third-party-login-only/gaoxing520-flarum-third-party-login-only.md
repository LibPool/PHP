# gaoxing520/flarum-third-party-login-only

> 标签: PHP

## 简介

Only allow login and sign ups from oAuth extensions. fork from v17development, fixed for Flarum 1.8.x.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
