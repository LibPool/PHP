# andriilive/wp-cli-media-regenerate-svg-fix

> 标签: plugin, wordpress

## 简介

`wp-cli-media-regenerate-svg-fix` plugin fix the wp-cli media regenerate error for SVG images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
