# andriilive/wp-disable-users-endpoint

> 标签: bedrock, composer, plugin, wordpress, wp-api

## 简介

`wp-disable-users-endpoint` plugin completely and for real disables WordPress &amp; plugins image sizes generation with no need for configuration. Supports bedrock and composer install

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
