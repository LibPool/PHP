# digicademy/beaconizer

> 标签: Digital Humanities, beacon, linked open data, typo3

## 简介

BEACON link harvesting and generation with TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
