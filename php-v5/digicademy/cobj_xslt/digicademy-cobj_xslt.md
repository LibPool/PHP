# digicademy/cobj_xslt

> 标签: Digital Humanities, typo3, xml, xslt

## 简介

Extends TYPO3 with a new content object XSLT for flexible XML transformations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
