# wubbleyou/yii2-widget-jquery-postcodes

> 标签: extension, jquery, postcodes, yii2

## 简介

Attaches a jquery.postcodes instance to a form

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
