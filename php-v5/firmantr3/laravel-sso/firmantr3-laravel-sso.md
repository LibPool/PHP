# firmantr3/laravel-sso

> 标签: SSO, laravel, provider, single sign on, user

## 简介

Laravel Single Sign On (SSO) authenticatable credentials implementation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
