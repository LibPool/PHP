# levmyshkin/ckeditor5-textselection

> 标签: PHP

## 简介

A plugin that makes CKEditor 5 keep its text selection when switching between Visual and Source mode.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
