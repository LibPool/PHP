# levmyshkin/jquery-colorpicker

> 标签: EBT, colorpicker, drupal, jquery, vanilla

## 简介

The Eyecon Color Picker JS/CSS library - no dependencies, jQuery optional. Fork from jaypan/jquery_colorpicker.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
