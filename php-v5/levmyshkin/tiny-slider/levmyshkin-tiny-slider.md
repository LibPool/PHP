# levmyshkin/tiny-slider

> 标签: PHP

## 简介

Fork from ganlanyuan/tiny-slider. Tiny slider for all purposes, inspired by Owl Carousel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
