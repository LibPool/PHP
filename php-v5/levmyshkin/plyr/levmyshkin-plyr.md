# levmyshkin/plyr

> 标签: PHP

## 简介

Plyr is a simple, lightweight, accessible and customizable HTML5, YouTube and Vimeo media player that supports modern browsers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
