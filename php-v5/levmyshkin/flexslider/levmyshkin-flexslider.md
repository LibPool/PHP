# levmyshkin/flexslider

> 标签: EBT, automattic, drupal, flexslider, jquery, slider, vanilla, woocommerce

## 简介

Fork from woocommerce/flexslider. An awesome, fully responsive slider toolkit - no dependencies, jQuery optional.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
