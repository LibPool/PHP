# msztorc/image-processor

> 标签: GD2, image, imagick, wrapper

## 简介

ImageProcessor is a wrapper class for graphics libraries like GD2, ImageMagick and epeg.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
