# youyiio/php-airpayee

> 标签: Wxpay, alipay, laravel, paysdk, php, thinkphp, unionpay

## 简介

php-airpayee is a php library for wechat and alipay's pay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
