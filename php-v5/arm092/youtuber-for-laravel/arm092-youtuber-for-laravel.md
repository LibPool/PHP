# arm092/youtuber-for-laravel

> 标签: PHP

## 简介

The package will help you to upload videos to youtube with privacy parameter and making youtube api much easier

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
