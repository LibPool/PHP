# haokeed/captcha

> 标签: PHP

## 简介

php gd2 captcha for api;专属API接口开发使用的图形验证码，基于PHP的GD2扩展

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
