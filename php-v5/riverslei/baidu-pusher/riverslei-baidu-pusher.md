> 标签: baidu push, laravel baidu push, laravel push sdk, laravel 消息推送, push sdk, 消息推送, 百度消息推送

## 简介

在laravel5中基于百度php sdk v3.0.0开发的消息推送。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
