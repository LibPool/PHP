# michaelmeneses/moodle-composer

> 标签: composer, moodle

## 简介

Manage Moodle LMS and plugins using Composer at a root directory level (example ROOT/moodle).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
