# blackbird/module-orange-sms-notification

> 标签: magento, magento2, notification, orange, php, sms

## 简介

Orange Sms connector to the Sms Notification module adapters.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
