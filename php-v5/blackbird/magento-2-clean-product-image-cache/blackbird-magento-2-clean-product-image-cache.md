# blackbird/magento-2-clean-product-image-cache

> 标签: PHP

## 简介

Clean product images cache file in Magento 2. Usefull if image name doesn't change

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
