# yubime/omnipay-bcash

> 标签: bcash, gateway, merchant, omnipay, pay, payment, purchase

## 简介

Bcash driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
