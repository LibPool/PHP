# infostreams/excel-merge

> 标签: PHPExcel, combine, excel, merge, xls, xlsm, xlsx

## 简介

A PHP library to merge two or more Excel files into one

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
