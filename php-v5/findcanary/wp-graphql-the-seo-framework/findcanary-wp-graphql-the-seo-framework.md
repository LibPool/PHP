# findcanary/wp-graphql-the-seo-framework

> 标签: PHP

## 简介

Adds The SEO framework support to the WPGraphQL Plugin for posts, pages and custom post types.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
