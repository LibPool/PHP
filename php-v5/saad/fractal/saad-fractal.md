# saad/fractal

> 标签: api, fractal, laravel, laravel-fractal, lumen, spatie, transform

## 简介

Wraper for spatie fractal package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
