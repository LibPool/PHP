# speisg/sfmc

> 标签: PHP

## 简介

ExactTarget Fuel SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://code.exacttarget.com/apis-sdks/fuel-sdks/
- 源码仓库：https://github.com/internetservicesgroup/SFMC_PHP_SDK.git
- Packagist 页面：https://packagist.org/packages/speisg%2Fsfmc
