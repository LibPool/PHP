# lpphan/riot-api

> 标签: LoL, Riot, api, facade, league of legends, proxy, wrap

## 简介

A simple wrapper for the League of Legends API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
