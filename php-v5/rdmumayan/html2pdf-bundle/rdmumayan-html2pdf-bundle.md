# rdmumayan/html2pdf-bundle

> 标签: TCPDF, html2pdf, pdf

## 简介

Forked version of Tristan's html2pdf-bundle. Use HTML2PDF as a Symfony2 Service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
