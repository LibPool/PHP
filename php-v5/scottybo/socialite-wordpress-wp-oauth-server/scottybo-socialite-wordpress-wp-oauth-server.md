# scottybo/socialite-wordpress-wp-oauth-server

> 标签: PHP

## 简介

A Laravel Socialite Provider for a self-hosted WordPress site using the WP OAuth2 Server plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
