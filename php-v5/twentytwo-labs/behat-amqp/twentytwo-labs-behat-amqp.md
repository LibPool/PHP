# twentytwo-labs/behat-amqp

> 标签: AMQP, Behat

## 简介

Behat Amqp Context to test AMQP messages, based on Swarrot library and PECL AMQP php extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
