# macfly/yii2-webserver-auth

> 标签: apache, htaccess, httpd, mod_authnz_external, nginx, ngx_http_auth_request_module, yii2

## 简介

Module for Yii framwork to enable Nginx authentification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
