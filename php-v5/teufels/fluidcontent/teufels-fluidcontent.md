# teufels/fluidcontent

> 标签: TYPO3 CMS, bootstrap, fedext, fluid, fluidcontent, flux, templating

## 简介

Create Flexible Content elements in pure fluid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
