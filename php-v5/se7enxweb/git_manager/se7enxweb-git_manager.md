# se7enxweb/git_manager

> 标签: eZ Publish Legacy, eZ Publish Platform, extension, ez publish, git, kernel updater, manager, module, vcs

## 简介

Git Manager offers Local / remote branch checkout - Use this feature to update your website to the latest available commit in your git repository

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
