# se7enxweb/bcgooglesitemaps

> 标签: Sitemap, cronjob, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, generator

## 简介

eZ Publish extension which provides cronjob scripts to generate complex website sitemaps. Great for smart developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
