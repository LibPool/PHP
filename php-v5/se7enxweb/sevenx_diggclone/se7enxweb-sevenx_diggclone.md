# se7enxweb/sevenx_diggclone

> 标签: design, digg, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, module, solution, vote

## 简介

7x DiggClone is a simple eZ Publish Platform (Legacy) datatype extension which replaces the ezoption datatype. Great for advanced developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
