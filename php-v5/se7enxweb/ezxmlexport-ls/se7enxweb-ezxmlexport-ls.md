# se7enxweb/ezxmlexport-ls

> 标签: PHP

## 简介

eZ Publish Legacy Extension for exporting large amounts of content for for instance pushing to static cache or backup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
