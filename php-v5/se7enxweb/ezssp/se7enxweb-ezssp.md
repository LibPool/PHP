# se7enxweb/ezssp

> 标签: PHP

## 简介

Subtree Skeleton Publisher copies a skeleton node tree to a given node via workflow event. Great for savy developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
