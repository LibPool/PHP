# danxill/php-meminfo-analyzer

> 标签: PHP

## 简介

Tools to analyze meminfo dump files, it's a part of bitone/mem-info project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
