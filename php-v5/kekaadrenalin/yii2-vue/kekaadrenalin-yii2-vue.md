# kekaadrenalin/yii2-vue

> 标签: extension, vue, vuejs, vuex, yii2, yii2-vue, yii2-vuejs

## 简介

This is the Vue.js extension for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
