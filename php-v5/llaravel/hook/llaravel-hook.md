# llaravel/hook

> 标签: HOOK, laravel, 动态配置, 拦截

## 简介

你可以动态配置env环境变量、config参数,拦截http请求,修改响应数据....你可以根据自己的业务代码来实现这些功能!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
