# zapheus/zapheus

> 标签: PHP Library, interoperable, php framework, zapheus

## 简介

An independent and framework-friendly PHP micro-framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
