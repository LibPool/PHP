# marcel-mathias-nolte/contao-jquery-in-backend

> 标签: PHP

## 简介

Bundle to provide jQuery to the Contao Open Source CMS' backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
