# wsr/feusersmap

> 标签: extension, openstreet map, radial search, typo3

## 简介

Openstreetmap / leaflet maps with radial search for fe_users and fe_groups.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
