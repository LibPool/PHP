# craigmccoy/backbone.babysitter

> 标签: backbone, browser, client, computed, field, model, plugin

## 简介

Manage child views in a Backbone.View.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
