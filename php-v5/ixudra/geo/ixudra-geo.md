# ixudra/geo

> 标签: Ixudra, geo, geocode, laravel

## 简介

Custom PHP geo-location services library for the Laravel 5 framework - developed by Ixudra

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
