# yii2-extensions/skill

> 标签: agent-skills, claude-code, codex, opencode, yii2

## 简介

Agent skills for Yii 22 applications, framework subsystems, and Yii 2.0 upgrades.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
