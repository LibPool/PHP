# fgendorf/phpeasyui

> 标签: PHP

## 简介

jQuery EasyUI framework helps you build your web pages easily. Homepage: http://jeasyui.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
