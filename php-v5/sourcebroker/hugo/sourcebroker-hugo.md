# sourcebroker/hugo

> 标签: PHP

## 简介

Export TYPO3 pages and content in a way that is able to be consumed by typo3-hugo-theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
