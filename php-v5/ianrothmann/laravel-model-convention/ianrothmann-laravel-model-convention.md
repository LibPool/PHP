# ianrothmann/laravel-model-convention

> 标签: PHP

## 简介

A Model Trait to override standard laravel 5 model conventions for use with larger scale databases

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
