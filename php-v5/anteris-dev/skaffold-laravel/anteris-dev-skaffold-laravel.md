# anteris-dev/skaffold-laravel

> 标签: docker, laravel, skaffold

## 简介

Skaffolds a Laravel project ready to run in a Docker container.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
