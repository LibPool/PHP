# lshin/sendgrid-newsletter

> 标签: laravel, laravel4, sendgrid, sendgrid newsletter

## 简介

Laravel 4 Wrapper for the Sendgrid Newsletter API Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
