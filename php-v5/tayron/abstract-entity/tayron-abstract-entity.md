# tayron/abstract-entity

> 标签: PHP

## 简介

Classe abstrata para ser extendida por entidades que venha poder expor seus atributos no formado de xml, string, array e json.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
