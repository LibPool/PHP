# hailwood/smartless4laravel

> 标签: assets, css, illuminate, laravel, less, php

## 简介

An advanced LESS PHP compiler package for Laravel4 based on the LESSisMore L3 bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
