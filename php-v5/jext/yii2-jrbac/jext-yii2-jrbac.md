# jext/yii2-jrbac

> 标签: admin, extension, module, rbac, yii2

## 简介

JRBAC - Yii2 RBAC admin control panel and dashboard that's based on Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
