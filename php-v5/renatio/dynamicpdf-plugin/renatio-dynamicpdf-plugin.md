# renatio/dynamicpdf-plugin

> 标签: dompdf, laravel, octobercms, octobercms-plugin, pdf, php

## 简介

October HTML to PDF converter using dompdf library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
