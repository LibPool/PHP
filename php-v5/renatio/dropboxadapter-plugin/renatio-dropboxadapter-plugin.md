# renatio/dropboxadapter-plugin

> 标签: dropbox, laravel, octobercms, octobercms-plugin, php

## 简介

Dropbox filesystem adapter plugin for October CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
