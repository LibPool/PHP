# cogpowered/shortener

> 标签: convert, encoding, id, integer, number, shortener, url

## 简介

Encodes integers as short string and back. Useful in URL shorteners.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
