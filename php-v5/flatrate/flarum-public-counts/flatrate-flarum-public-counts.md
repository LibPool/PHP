# flatrate/flarum-public-counts

> 标签: PHP

## 简介

Read-only guest-visible discussion and reply counts for one closed UTC week. Flarum 1.8.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
