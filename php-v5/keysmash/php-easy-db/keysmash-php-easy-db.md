# keysmash/php-easy-db

> 标签: database, mysql, php, postgresql

## 简介

Easy to use MySQL and PostgreSQL database library for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
