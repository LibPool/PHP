# mecha-cms/x.comment.hint

> 标签: PHP

## 简介

Adds a few instructions for your visitors on how to leave a comment, just below the comment message field.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
