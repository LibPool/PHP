# peridot-php/peridot-jumpstart

> 标签: BDD, TDD, testing

## 简介

Starter kit to start BDD testing in PHP with Peridot

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
