# zoilorys/craft-react-external-server

> 标签: Craft, isomorphic, react, reactjs, twig

## 简介

Client and Server-side React rendering for CraftCMS using external server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
