# aliirfaan/mu-phone-number-kit

> 标签: Mauritius, mobile number, phone number

## 简介

Package to work with Mauritius phone numbers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
