# getrootid/radicati-recipe-media

> 标签: PHP

## 简介

Base settings for the Drupal admin for a Radicati site. Includes Gin, rename admin paths, and various other admin-y things.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
