# chervand/yii2-oauth2-server

> 标签: Authentication, MAC, api, auth, authorisation, authorization, hmac, league, oauth, oauth 2, oauth 2.0, oauth2, protect, resource, secure, server, thephpleague

## 简介

OAuth 2.0 server for Yii 2.0 with MAC tokens support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
