# gabrielqs/pagseguro-redirect

> 标签: PHP

## 简介

Integração transparente entre o Magento 2 e a Cielo utilizando o método de integração WebService

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
