# ezsystems/ezxmlinstaller-ls

> 标签: PHP

## 简介

The eZ XML Installer extension is a plattform to define proccesses for eZ Publish and execute them.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
