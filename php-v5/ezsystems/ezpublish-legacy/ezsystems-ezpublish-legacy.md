# ezsystems/ezpublish-legacy

> 标签: PHP

## 简介

eZ Publish Legacy (aka LegacyStack in 5.x. Is an updated version of eZ Publish 4.x cable of being combined with eZ Platform)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
