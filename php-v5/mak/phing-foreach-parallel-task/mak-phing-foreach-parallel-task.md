# mak/phing-foreach-parallel-task

> 标签: PHP

## 简介

phing task to run sub-tasks in a foreach-loop in separate, parallel processes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
