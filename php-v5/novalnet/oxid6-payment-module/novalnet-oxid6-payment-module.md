# novalnet/oxid6-payment-module

> 标签: OXID, eshop, modules, payment

## 简介

Seamless integration with 150+ payment methods worldwide from Novalnet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
