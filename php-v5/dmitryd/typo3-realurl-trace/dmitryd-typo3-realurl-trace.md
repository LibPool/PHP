# dmitryd/typo3-realurl-trace

> 标签: RealURL, cms, typo3

## 简介

Answers a popular question: "Why did realurl make this speaking url?"

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
