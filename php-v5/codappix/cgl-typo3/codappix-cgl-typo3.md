# codappix/cgl-typo3

> 标签: cgl, cms, php, phpcs, typo3

## 简介

Contains PHP_CodeSniffer rules for TYPO3 that we like. Uses CGL-PHP as base rules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
