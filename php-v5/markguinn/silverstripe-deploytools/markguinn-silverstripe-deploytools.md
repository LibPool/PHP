# markguinn/silverstripe-deploytools

> 标签: backup, deploy, git, silverstripe

## 简介

Provides automated git deployment and (soon) assets/database backup.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
