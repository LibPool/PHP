# headzoo/bitcoin-tools

> 标签: bitcoin, crypto

## 简介

Small library used to work with Bitcoin. Currently only contains a single class which validates Bitcoin addresses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
