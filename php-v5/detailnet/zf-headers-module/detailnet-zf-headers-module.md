# detailnet/zf-headers-module

> 标签: detailnet, dfw, header, http, module, zf2

## 简介

Zend Framework 2 Module for sending proper HTTP headers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
