# otifsolutions/aclmenu

> 标签: PHP

## 简介

An ACL Menu Package that includes User Roles, Permissions, Db based Menu Items, rights and permission based menu items

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
