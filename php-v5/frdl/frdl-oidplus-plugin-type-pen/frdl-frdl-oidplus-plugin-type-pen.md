# frdl/frdl-oidplus-plugin-type-pen

> 标签: iana, oid, oiplus, pen

## 简介

OIDplus ObjectType Plugin to lookup external IANA PEN (Private Enterprise Number)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
