# frdl/oidplus-io4-bridge-plugin

> 标签: io4, oiplus

## 简介

Bridge from OIDplus to Webfat/IO4, OIDplus Composer (Plugins) GUI, Admin-/Devtools, OIDplus Setup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
