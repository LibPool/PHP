# geeklab/html

> 标签: HTML5, html, xhtml

## 简介

Programmatically create HTML (XHTML, 4.x, 5) for PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
