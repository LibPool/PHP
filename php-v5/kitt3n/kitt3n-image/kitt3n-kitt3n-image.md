# kitt3n/kitt3n-image

> 标签: TYPO3 Kit, image, kitt3n, picture, view helper

## 简介

Image tt_content element using <picture> tag. Provides different ViewHelpers to use images e.g. in other extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
