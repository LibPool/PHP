# tdmalone/tm-code-standards

> 标签: php, phpcs, wpcs

## 简介

My own flavour of coding standards. Heavily based on the WordPress Coding Standards.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
