# friendlydev/meshtastic-protobufs

> 标签: friendlydev, meshtastic, protobuf

## 简介

PHP Compiled Protobufs from the Official Meshtastic Protobufs repository

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
