# letsweb/container-manage-children

> 标签: PHP

## 简介

Extension pour gérer les éléments enfants directement dans l'interface d'édition des conteneurs b13/container

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
