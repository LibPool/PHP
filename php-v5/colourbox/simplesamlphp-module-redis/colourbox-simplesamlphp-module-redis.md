# colourbox/simplesamlphp-module-redis

> 标签: redis, simplesamlphp, store

## 简介

A SimpleSAMLphp module for using Redis for session storage etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
