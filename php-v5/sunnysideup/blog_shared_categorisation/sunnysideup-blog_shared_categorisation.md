# sunnysideup/blog_shared_categorisation

> 标签: Silverstripe-CMS, blog, categorisation, categorisations, cms, grouping, many blogs, silverstripe, tag, tags, taxonomy

## 简介

Adds shared categorisation to the Silverstripe Blog.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
