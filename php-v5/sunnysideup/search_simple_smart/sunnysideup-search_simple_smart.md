> 标签: Silverstripe-CMS, cms, elastic, filter, indexing, search, searchengine, silverstripe, solr

## 简介

Silverstripe Module that allows you to set up complex search algorythms in an easy way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
