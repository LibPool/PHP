# sunnysideup/dashboard

> 标签: cms, dashboard, silverstripe

## 简介

Adds a customisable dashboard to the SilverStripe CMS (fork of Unclecheese's module)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
