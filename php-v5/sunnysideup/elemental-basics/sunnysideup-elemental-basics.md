# sunnysideup/elemental-basics

> 标签: background-colour, blocks, design, elemental, extension, margin, padding, styling

## 简介

Provides a Base Element Extension to Elemental that allows the content editor to make basic design / styling choices such as top and bottom margin and background colour

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
