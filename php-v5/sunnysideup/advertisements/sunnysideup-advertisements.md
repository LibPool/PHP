# sunnysideup/advertisements

> 标签: Silverstripe-CMS, advertisements, carousel, cms, cycle, silverstripe, slide show, slides, slideshow

## 简介

Uses the jQuery extension cycle to create advertisements / slides

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
