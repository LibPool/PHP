# sunnysideup/gitignore

> 标签: .gitignore, dev tool, gitignore, install, setup

## 简介

No more manual editing for .gitignore - adds all the basics in one go

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
