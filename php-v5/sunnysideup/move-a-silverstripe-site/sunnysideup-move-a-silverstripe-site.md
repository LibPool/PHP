# sunnysideup/move-a-silverstripe-site

> 标签: Silverstripe-CMS, cms, cron, deploy, ftp, migrate, move, move a site, mysql, silverstripe, ssh

## 简介

Tool to help you to move a Silverstripe site from one place to another.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
