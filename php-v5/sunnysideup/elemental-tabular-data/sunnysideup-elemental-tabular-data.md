# sunnysideup/elemental-tabular-data

> 标签: Silverstripe CMS, blocks, data, elemental, silverstripe, table, tabular

## 简介

Allows adding tabular data to a page using Elemental

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
