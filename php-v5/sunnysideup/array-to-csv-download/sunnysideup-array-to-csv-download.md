# sunnysideup/array-to-csv-download

> 标签: Silverstripe-CMS, cms, csv, download, export, silverstripe

## 简介

Create a CSV download file from any array.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
