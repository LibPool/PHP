# sunnysideup/googlemap

> 标签: Silverstripe-CMS, cms, directions, geo, geospatial, google, google map, googlemap, googlemaps, map, maps, silverstripe

## 简介

adds an in-depth application of the google map API to your Silverstripe application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
