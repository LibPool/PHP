# sunnysideup/set-focus-point-from-anywhere

> 标签: crop better, focus point, focuspoint, form field, image, image focus point, jonom, nice cropping, non-react, react

## 简介

React or not react - this provides a FormField that allows you to set the focus point of an image

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
