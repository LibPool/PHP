# sunnysideup/sskube

> 标签: Silverstripe-CMS, cms, imperavi, kube, silverstripe, silverstripe webpack, webpack, webpack theme

## 简介

Base SilverStripe theme that can be used in conjunction with Silverstripe Webpack engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
