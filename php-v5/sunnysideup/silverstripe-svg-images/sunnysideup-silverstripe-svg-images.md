# sunnysideup/silverstripe-svg-images

> 标签: silverstripe

## 简介

Basic SVG Image support for Silverstripe (Assets/Uploads)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
