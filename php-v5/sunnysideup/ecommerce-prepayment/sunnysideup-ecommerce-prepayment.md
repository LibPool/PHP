# sunnysideup/ecommerce-prepayment

> 标签: Silverstripe-CMS, cms, e-commerce, ecommerce, pre-order, pre-pay, preorder, prepay, silverstripe

## 简介

Allows Silverstripe-CMS Ecommerce to get customers to prepay for a product.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
