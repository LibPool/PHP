# mailfinder/mailfinder-v1

> 标签: PHP

## 简介

Biblioteca para utilização em conjunto com a plataforma Mailfinder de validações de emails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
