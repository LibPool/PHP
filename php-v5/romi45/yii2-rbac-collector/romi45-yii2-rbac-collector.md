# romi45/yii2-rbac-collector

> 标签: rbac, romi45, yii2

## 简介

Using extension you can organize your RBAC configuration in separate files in application modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
