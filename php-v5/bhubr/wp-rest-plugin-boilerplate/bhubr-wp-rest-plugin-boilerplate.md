# bhubr/wp-rest-plugin-boilerplate

> 标签: backbone, rest, wordpress

## 简介

Boilerplate for WordPress plugins with REST API and Backbone.js admin app

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
