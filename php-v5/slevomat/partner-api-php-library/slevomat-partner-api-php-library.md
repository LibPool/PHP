# slevomat/partner-api-php-library

> 标签: api, slevomat, voucher, zlavomat

## 简介

PHP library for the Slevomat.cz/Zlavomat.sk voucher API for partners

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
