# mvbcoding/config-service-provider

> 标签: configuration, json, silex, toml, yaml

## 简介

A config ServiceProvider for Silex with support for php, json, yaml and toml.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
