# simonov/simon-lib

> 标签: PHP

## 简介

MVC (framework) library, routes, user friendly URL, form verification, registration, authorization, pagination, orm, log, bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
