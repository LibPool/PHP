# neapoli/christes

> 标签: Chrístes, drupal, module

## 简介

Chrístes, dal greco utenti, è un modulo Drupal per la gestione degli utenti della scuola

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
