# zhuyongnetwork/laravel-u-editor

> 标签: laravel, laravel-u-editor, laravel5 web text editor, steven yang, ueditor, zhuyongnetwork

## 简介

UEditor for laravel5. Support i18n. UEditor is a Rich Text Web Editor From Baidu. 融合阿里云oss

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
