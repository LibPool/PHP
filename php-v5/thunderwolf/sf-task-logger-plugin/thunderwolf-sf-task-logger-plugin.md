# thunderwolf/sf-task-logger-plugin

> 标签: symfony, task

## 简介

symfony 1.x Task Logger plugin - Allow you to run tasks and store the results in both database and/or a log file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
