# smartysoft/yii2-smartysoft-pdfjs

> 标签: PDF Reader, extension, pdf, pdfjs, yii2

## 简介

Yii2 Extension  pdf.js Portable Document Format (PDF) viewer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
