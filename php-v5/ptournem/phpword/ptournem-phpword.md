# ptournem/phpword

> 标签: ISO IEC 29500, OOXML, Office Open XML, OpenDocument, OpenXML, PhpOffice, PhpWord, Rich Text Format, WordprocessingML, doc, docx, html, odt, office, pdf, php, ptournem, reader, rtf, template, template processor, word, writer

## 简介

Fork of PHPWord - A pure PHP library for reading and writing word processing documents (DOCX, ODT, RTF, HTML, PDF) with added functionnalities for images and templating

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
