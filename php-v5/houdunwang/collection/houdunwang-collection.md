# houdunwang/collection

> 标签: collection, hdphp, houdunwang, json, 集合管理

## 简介

Collection 组件提供一个流畅、方便的封装来操作数据

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
