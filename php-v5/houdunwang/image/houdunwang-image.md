# houdunwang/image

> 标签: hdphp, houdunwang, image, 后盾人, 后盾网, 后盾网向军

## 简介

图片组件提供了缩略图、水印等图像处理功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
