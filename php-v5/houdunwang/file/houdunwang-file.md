# houdunwang/file

> 标签: hdphp, houdunwang, 后盾人, 后盾网, 向军老师, 文件上传

## 简介

File组件提供非常方便的上传处理与下载等相关功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
