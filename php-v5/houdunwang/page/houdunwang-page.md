# houdunwang/page

> 标签: hdphp, houdunwang, page, 后盾人, 后盾网, 后盾网向军

## 简介

分页组件可以产生基于当前页面的智能「范围」链接，所产生的 HTML 兼容 Bootstrap CSS 框架.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
