# houdunwang/backup

> 标签: hdphp, houdunwang, 后盾人, 后盾网, 向军老师, 数据库备份

## 简介

backup组件可轻松完成数据备份与恢复操作

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
