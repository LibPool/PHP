# dracoder/filter-bundle

> 标签: PHP

## 简介

Classes that allows the usage of Filters in a Doctrine Repository in a more readable, object oriented way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
