# maksimdimitrov/mdim-amqp-laravel

> 标签: laravel, rabbitmq

## 简介

Laravel service provider for php-amqplib to use RabbitMQ

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
