## 简介

The package was created by Miqayel Ishkhanyan special for php developers. The package able to help to work with images more easily. This image upload package provides functions such as upload, resize, crop, rotate, delete

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
