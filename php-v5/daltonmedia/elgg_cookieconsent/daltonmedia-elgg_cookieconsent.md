# daltonmedia/elgg_cookieconsent

> 标签: cookie, cookieconsent, cookies, elgg, plugin

## 简介

Adds a configurable cookie consent message to your Elgg install

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
