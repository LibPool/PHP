# klinson/laravel-cache-response

> 标签: auto, cache, klinson, laravel, middleware, response

## 简介

Laravel请求结果自动缓存中间件，缓存返回数据，适用于接口返回json或其他格式数据

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
