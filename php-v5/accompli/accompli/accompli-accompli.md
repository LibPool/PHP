# accompli/accompli

> 标签: Accompli, deployment, ftp, ftps, sftp, ssh

## 简介

An easy to use and extendable deployment tool for PHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
