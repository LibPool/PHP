# tantacula/ip2country

> 标签: IP, country, geocode, geolookup, ip address, ip lookup, ipv4, laravel, location

## 简介

Laravel package to lookup the country associated with an IPv4 address

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Composer 安装：`composer require tantacula/ip2country`
