# zizuu-store/zzcleanurls

> 标签: PHP

## 简介

Prestashop"Clean URLs" module. It removes objects' IDs from URLs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
