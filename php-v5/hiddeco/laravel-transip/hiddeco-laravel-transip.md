# hiddeco/laravel-transip

> 标签: Bridge, api, framework, laravel, soap, transip

## 简介

Laravel TransIP is a bridge for the TransIP SOAP client and Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
