# grmule/php-ziptastic

> 标签: postal, zip, ziptastic

## 简介

A simple class for accessing the Ziptastic API (https://www.getziptastic.com/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
