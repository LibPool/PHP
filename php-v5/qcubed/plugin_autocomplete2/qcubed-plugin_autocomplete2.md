# qcubed/plugin_autocomplete2

> 标签: autocomplete, qcubed

## 简介

QCubed wrapper for the jquery.ui.autocomplete2.js jQuery plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
