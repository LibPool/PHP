# qcubed/i18n

> 标签: gettext, i10n, i18n, po

## 简介

Comprehensive i18n project for translating PHP files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/qcubed/i18n
- 源码仓库：https://github.com/qcubed/i18n.git
- Packagist 页面：https://packagist.org/packages/qcubed%2Fi18n

## 获取地址

- Composer 安装：`composer require qcubed/i18n`
- Packagist 仓库：https://repo.packagist.org/p2/qcubed/i18n.json
