# tavoweb/flarum-lang-lithuanian

> 标签: flarum, lithuanian-locale, locale

## 简介

Lithuanian language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
