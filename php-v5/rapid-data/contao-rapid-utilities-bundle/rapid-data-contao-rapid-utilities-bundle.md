# rapid-data/contao-rapid-utilities-bundle

> 标签: PHP

## 简介

Bundle providing common modules and utilities for RAPID-DATA projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
