# melvilleco/instagram-basic-display

> 标签: Craft, cms, craft instagram, craft-plugin, craftcms, instagram, instagram api, instagram basic display, instagram embed, instagram feed, instagram oembed

## 简介

Provides endpoints and helper console commands that make it easier to work with the Instagram Basic Display API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
