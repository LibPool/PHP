# splitit/sdk

> 标签: api, sdk, splitit

## 简介

Splitit Web API SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/Splitit/Splitit.SDKs.php.git
