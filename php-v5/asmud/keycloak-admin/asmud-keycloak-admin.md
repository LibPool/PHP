# asmud/keycloak-admin

> 标签: PHP

## 简介

Connect to keycloak admin api easily - patch onto mohammad-waleed/keycloak-admin-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
