# jengo/base

> 标签: PHP

## 简介

Modern web development library for CodeIgniter 4 with Vite, modules, unified setups, and automated CLI installer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
