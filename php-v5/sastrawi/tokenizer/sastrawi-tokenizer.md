# sastrawi/tokenizer

> 标签: bahasa, indonesia, indonesian, natural language processing, nlp, text preprocessing, tokenization, tokenizer

## 简介

PHP library that allows you to tokenize Bahasa Indonesia.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
