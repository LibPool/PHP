# sankaest/yii2-notification

> 标签: alert, flash, growl, lobibox, module, notific8, notification, noty, notyfy, notyjs, pnotyfy, sweetalert, toast, toastr, yii2

## 简介

This module for renders a message from session flash (with ajax, pjax support and etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
