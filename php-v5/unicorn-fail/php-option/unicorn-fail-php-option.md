# unicorn-fail/php-option

> 标签: language, option, php, phpoption, type, typed

## 简介

A highly extensible replacement for [phpoption/phpoption] with `TypedOption` support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
