# irmmr/flarum-ext-rtl

> 标签: flarum, flarum-ext, flarum-rtl, rtl

## 简介

Right-to-Left (rtl) direction support for "Flarum" core and extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
