# swoogo/authorizenet

> 标签: authorize.net, authorizenet, ecommerce, payment

## 简介

Official PHP SDK for Authorize.Net

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
