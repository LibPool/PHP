# soqrate/tcpdf

> 标签: TCPDF, pdf

## 简介

TCPDF is a PHP class for generating PDF documents.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.tcpdf.org/
- 源码仓库：https://github.com/soqrate/TCPDF.git
- Packagist 页面：https://packagist.org/packages/soqrate%2Ftcpdf
