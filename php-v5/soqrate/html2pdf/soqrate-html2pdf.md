# soqrate/html2pdf

> 标签: conversion, convert, convertisseur, fpdf, generate, generation, html, pdf, php5

## 简介

HTML2PDF est un convertisseur de code HTML vers PDF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
