# aimedidierm/fdisms

> 标签: PHP

## 简介

This is a PHP library to help developers include SMS service with FDI SMS gateway from Rwanda.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
