# chinasearch/digium-switchvox-api

> 标签: api, digium, json, switchvox, xml

## 简介

PHP wrapper for Switchvox API, Forked from Shrimpwagon

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
