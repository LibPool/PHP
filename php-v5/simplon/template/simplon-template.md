# simplon/template

> 标签: fast, lightweight, mustache, phtml, templates

## 简介

Simple templating solution w/ assets handling (mustache, phtml, assets)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
