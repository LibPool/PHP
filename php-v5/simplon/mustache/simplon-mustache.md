# simplon/mustache

> 标签: fast, leightweight, less, logic, logic-less, mustache, template

## 简介

Lightweight & fast implementation of Mustache - Logic-less templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
