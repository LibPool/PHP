# syma.dev/parsedown-checkbox

> 标签: checkbox, markdown, parsedown, parser

## 简介

An extension of Parsedown that adds support for checkbox

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
