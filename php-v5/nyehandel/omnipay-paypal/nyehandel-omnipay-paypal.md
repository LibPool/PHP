# nyehandel/omnipay-paypal

> 标签: gateway, merchant, omnipay, pay, payment, paypal, purchase, v2

## 简介

Omnipay support for PayPal checkout v2 api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
