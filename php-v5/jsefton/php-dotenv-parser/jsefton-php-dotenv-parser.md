# jsefton/php-dotenv-parser

> 标签: array-env, dotenv, env, parser, php

## 简介

Allows you get .env file as array and convert array back to .env file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
