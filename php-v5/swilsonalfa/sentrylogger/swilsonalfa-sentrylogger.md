# swilsonalfa/sentrylogger

> 标签: error, log, logging, raven, sentry, silverstripe

## 简介

Publish SilverStripe errors and warnings to Sentry using the Raven client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
