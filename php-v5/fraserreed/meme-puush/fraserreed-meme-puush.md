# fraserreed/meme-puush

> 标签: meme, puu.sh, puush

## 简介

Generate a meme to a local file, echo to the screen, or upload to puu.sh using their API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
