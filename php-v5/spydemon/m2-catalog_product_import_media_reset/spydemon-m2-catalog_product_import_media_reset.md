# spydemon/m2-catalog_product_import_media_reset

> 标签: PHP

## 简介

Add a new column in product import files that allows you to reset media content on imported products.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
