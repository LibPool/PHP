# arewebs/jet-vuetify

> 标签: laravel, ui, vuetify

## 简介

Frontend UI package made with Vuetify for Laravel Jetstream with Inertia scaffolding.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
