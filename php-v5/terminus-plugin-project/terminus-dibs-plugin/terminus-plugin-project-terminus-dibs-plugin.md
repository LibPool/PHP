# terminus-plugin-project/terminus-dibs-plugin

> 标签: PHP

## 简介

Dibs - A Terminus plugin that allows you to call dibs on your Pantheon environments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
