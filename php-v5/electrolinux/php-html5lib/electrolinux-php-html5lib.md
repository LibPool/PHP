# electrolinux/php-html5lib

> 标签: HTML5, php

## 简介

A PHP implementations of a HTML parser based on the WHATWG HTML5 specification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
