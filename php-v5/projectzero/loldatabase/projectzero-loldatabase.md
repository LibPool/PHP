# projectzero/loldatabase

> 标签: PHP

## 简介

An API wrapper for Riot Games League of Legends that stores and caches the data retrieved in a database format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
