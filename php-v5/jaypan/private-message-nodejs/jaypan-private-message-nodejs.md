# jaypan/private-message-nodejs

> 标签: PHP

## 简介

The Node.js backend for the Drupal Private Message Nodejs sub-module of the Private Message module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
