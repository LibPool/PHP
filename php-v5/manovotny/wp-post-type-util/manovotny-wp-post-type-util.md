# manovotny/wp-post-type-util

> 标签: admin, custom, post types, posts, utility, wordpress

## 简介

A lovely collection of post type utilities for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
