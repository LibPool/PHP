# manovotny/wp-enqueue-util

> 标签: css, enqueue, javascript, scripts, wordpress

## 简介

A convenient enqueuing utility for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
