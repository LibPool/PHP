# bd808/monolog-udp2log-handler

> 标签: log, mediawiki, monolog, udp2log

## 简介

A handler for Monolog that emits udp2log datagrams.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
