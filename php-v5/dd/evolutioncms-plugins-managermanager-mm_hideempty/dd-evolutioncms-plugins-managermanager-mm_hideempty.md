# dd/evolutioncms-plugins-managermanager-mm_hideempty

## 简介

A widget for ManagerManager plugin that allows to hide all empty sections and tabs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
