# symfonysi/magento2-sl-si

> 标签: language pack, magento2, sl_SI, slovenian

## 简介

Slovenian (Slovenia) language package for Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
