# skullyframework/skully-amazon-s3

> 标签: PHP

## 简介

Amazon S3 Integration with Skully Framework. Can be used with Skully Admin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
