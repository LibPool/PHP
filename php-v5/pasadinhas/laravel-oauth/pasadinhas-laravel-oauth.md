# pasadinhas/laravel-oauth

> 标签: laravel, laravel4, laravel5, oauth, pasadinhas, php

## 简介

A wrapper for handling OAuth requests for Laravel 4/5 Applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
