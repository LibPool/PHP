# serfhos/my-search-crawler

> 标签: Benjamin Serfhos, Serfhos, cms, elastic, extbase, index, search, typo3

## 简介

TYPO3 Extension: Elastic Indexing web crawler based on TYPO3 9.5 routing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
