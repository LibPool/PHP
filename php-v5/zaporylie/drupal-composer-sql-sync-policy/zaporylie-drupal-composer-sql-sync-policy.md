# zaporylie/drupal-composer-sql-sync-policy

> 标签: PHP

## 简介

Prevent syncing in wrong direction (i.e. from @dev to @prod).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
