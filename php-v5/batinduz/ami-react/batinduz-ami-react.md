# batinduz/ami-react

> 标签: Asterisk Manager Interface, ami, async, react

## 简介

Async, event-driven access to the Asterisk Manager Interface (AMI)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
