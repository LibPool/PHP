# digitalconvergenceca/digitalconvergence_utilities

> 标签: PHP

## 简介

A set of utilities, helpers and so forth to assist in rapid Drupal 8 development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
