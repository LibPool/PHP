# cwhite92/b2-sdk-php

> 标签: b2, backblaze, backup, cloud, filesystem, storage

## 简介

A SDK for working with B2 cloud storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
