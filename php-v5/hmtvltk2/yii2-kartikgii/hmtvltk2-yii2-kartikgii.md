# hmtvltk2/yii2-kartikgii

> 标签: PHP

## 简介

Gii Generator base on Kartik-V extension https://github.com/kartik-v

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
