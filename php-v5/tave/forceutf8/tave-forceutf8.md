# tave/forceutf8

> 标签: PHP

## 简介

PHP Class Encoding featuring popular Encoding::toUTF8() function --formerly known as forceUTF8()-- that fixes mixed encoded strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
