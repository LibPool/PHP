# vleks/sdk

> 标签: api, sdk, vleks, vleks.com

## 简介

A PHP client SDK for the Vleks.com API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.vleks.com
- 源码仓库：https://github.com/Vleks/sdk.git
- Packagist 页面：https://packagist.org/packages/vleks%2Fsdk
