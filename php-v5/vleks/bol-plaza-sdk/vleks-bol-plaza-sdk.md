# vleks/bol-plaza-sdk

> 标签: Bol.com, api, bol, client, plaza, sdk, vleks

## 简介

A PHP client SDK for the Bol.com Plaza API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
