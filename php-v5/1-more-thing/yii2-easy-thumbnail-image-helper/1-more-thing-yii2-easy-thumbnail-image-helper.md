# 1-more-thing/yii2-easy-thumbnail-image-helper

> 标签: helper, image, thumbnail, yii2

## 简介

Yii2 helper for creating and caching thumbnails on real time

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
