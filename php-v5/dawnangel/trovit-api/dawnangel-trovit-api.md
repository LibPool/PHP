# dawnangel/trovit-api

> 标签: trovit

## 简介

A simple PHP implementation of Trovit Affiliates API http://publishers.trovit.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://publishers.trovit.com
- 源码仓库：https://github.com/DawnAngel/trovit-api.git
- Packagist 页面：https://packagist.org/packages/dawnangel%2Ftrovit-api
