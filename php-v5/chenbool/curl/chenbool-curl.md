# chenbool/curl

> 标签: curl, 网络操作类

## 简介

一个轻量级的 PHP 网络操作类, 基于 Curl 封装并实现了 Get | Post | Upload | Download 等常用方法

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
