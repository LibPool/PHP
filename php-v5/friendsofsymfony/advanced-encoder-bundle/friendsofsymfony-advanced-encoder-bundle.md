# friendsofsymfony/advanced-encoder-bundle

> 标签: Symfony2, encoder, security

## 简介

Symfony2 bundle adding a way to specify the encoder on a user instance basis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
