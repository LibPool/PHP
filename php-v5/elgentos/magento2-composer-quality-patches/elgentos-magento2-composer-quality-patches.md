# elgentos/magento2-composer-quality-patches

> 标签: PHP

## 简介

Converts Magento's Quality Patches to a JSON format to be used with vaimo/composer-patches

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
