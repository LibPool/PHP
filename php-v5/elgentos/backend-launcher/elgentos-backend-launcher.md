# elgentos/backend-launcher

> 标签: PHP

## 简介

Magento 2 module which adds a launcher to the Magento 2 backend interface. Inspired by PulseStormLauncher.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
