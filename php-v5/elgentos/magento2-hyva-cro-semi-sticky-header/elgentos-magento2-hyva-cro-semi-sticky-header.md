# elgentos/magento2-hyva-cro-semi-sticky-header

> 标签: PHP

## 简介

Changes the Hyvä header to a semi-sticky header (dissapears down and reappears up)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
