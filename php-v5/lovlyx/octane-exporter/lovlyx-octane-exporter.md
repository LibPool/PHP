# lovlyx/octane-exporter

> 标签: Metrics, grafana, laravel, octane, php, prometheus, swoole

## 简介

Export Laravel Octane metrics using this Prometheus exporter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
