# toiba/fullcalendar-bundle

> 标签: calendar, fullcalendar, jquery calendar, symfony calendar

## 简介

Symfony integration of FullCalendar.js library. Events can be stored with Doctrine, MongoDB, CouchDB and others

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
