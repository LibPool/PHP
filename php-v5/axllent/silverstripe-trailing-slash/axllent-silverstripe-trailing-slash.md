# axllent/silverstripe-trailing-slash

> 标签: seo, silverstripe, urls

## 简介

Ensure that a single trailing slash is always added to the URL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
