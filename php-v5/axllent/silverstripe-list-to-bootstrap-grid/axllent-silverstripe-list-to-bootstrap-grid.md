# axllent/silverstripe-list-to-bootstrap-grid

> 标签: bootstrap, list, silverstripe

## 简介

Create a Bootstrap grid layout from a SilverStripe List

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
