# axllent/silverstripe-scss

> 标签: css, sass, scss, scssphp, silverstripe

## 简介

A wrapper for scssphp to integrate scss compiling directly into Silverstripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
