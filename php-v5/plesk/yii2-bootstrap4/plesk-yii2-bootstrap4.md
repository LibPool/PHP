# plesk/yii2-bootstrap4

> 标签: bootstrap, bootstrap4, yii2

## 简介

The Twitter Bootstrap extension for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
