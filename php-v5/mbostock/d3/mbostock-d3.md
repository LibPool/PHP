# mbostock/d3

> 标签: W3C, animation, canvas, dom, svg, visualization

## 简介

A JavaScript visualization library for HTML and SVG.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
