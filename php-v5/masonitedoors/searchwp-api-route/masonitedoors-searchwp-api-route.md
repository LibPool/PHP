# masonitedoors/searchwp-api-route

> 标签: searchwp, wordpress, wp-api, wp-json-api

## 简介

Adds an endpoint to the WordPress REST API for searching via SearchWP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
