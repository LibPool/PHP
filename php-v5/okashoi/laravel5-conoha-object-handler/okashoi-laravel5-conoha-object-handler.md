# okashoi/laravel5-conoha-object-handler

> 标签: ConoHa, laravel, laravel5

## 简介

An object handler for the Conoha Object Storage on Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
