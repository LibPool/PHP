# salaros/wp-purge-pagespeed-button

> 标签: PageSpeed, button, cache, purge, wordpress

## 简介

One-click PageSpeed cache purging using an admin bar button

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
