# salaros/mr-press-composer

> 标签: composer, database, deploy, script, wordpress

## 简介

Set of tools used during installation and configuration of Mr. Press project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
