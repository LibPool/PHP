# salaros/mysql-dump-importer

> 标签: database, dump, import, importer, mysql, sql

## 简介

Imports MySQL dump files (.sql) using php-mysqli extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
