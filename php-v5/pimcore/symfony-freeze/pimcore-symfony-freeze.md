# pimcore/symfony-freeze

> 标签: constraints, pimcore, symfony

## 简介

Metapackage to freeze Symfony components at version 7.x to match Pimcore 12.2 compatibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
