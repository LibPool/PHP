# b3n/azurestorage

> 标签: azure, extension, storage, typo3

## 简介

TYPO3 FAL driver extension for Microsoft Azure Blob Storage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
