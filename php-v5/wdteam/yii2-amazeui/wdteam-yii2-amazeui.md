# wdteam/yii2-amazeui

> 标签: extension, yii2

## 简介

Amaze UI 是基于社区开源项目构建的一个跨屏前端框架。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
