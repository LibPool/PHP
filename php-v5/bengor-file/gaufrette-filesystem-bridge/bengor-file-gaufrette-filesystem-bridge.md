# bengor-file/gaufrette-filesystem-bridge

> 标签: adapter, ddd, file, filesystem, gaufrette

## 简介

Adapter to make File compatible with Gaufrette filesystem

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
