# fyrst/shogun

> 标签: bootstrap, bundle, scss, shopware, storefront, template, theme, twig

## 简介

Rocket start for custom theme development in Shopware 6. Pure Bootstrap by default with first class opt-in components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
