# ra/silex-rest-api

> 标签: PHP

## 简介

Silex based REST API, which can be used to retrieve data from arbitrary systems to feed into the renzel.agentur Admin, for search and the SEO tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
