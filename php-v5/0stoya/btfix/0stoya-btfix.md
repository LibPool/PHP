# 0stoya/btfix

> 标签: PHP

## 简介

Fixes malformed SQL aliases (main_table.main_table) caused by Braintree or other extensions in Magento 2 admin order grid.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
