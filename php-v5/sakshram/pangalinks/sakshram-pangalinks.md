# sakshram/pangalinks

> 标签: Banklink, Pangalink, estonia

## 简介

Adds a functionality for making payments in Estonia using Banklink (Pangalink) transfer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
