# nouralhadi/stemmer

> 标签: PHP

## 简介

The first free open source Arabic stemmer ever written in PHP for Laravel framework implementing ISRI algorithm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
