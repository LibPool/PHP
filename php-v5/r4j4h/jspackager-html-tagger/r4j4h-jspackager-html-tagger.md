# r4j4h/jspackager-html-tagger

> 标签: html, link, script, stylesheet

## 简介

Simple bare bones HTML tag generator for <script> and <link> tags

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
