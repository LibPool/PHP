# blainesch/li3_unit

> 标签: li3, lithium, test, testing, unit, unit testing

## 简介

Adds extra assert methods and simple ways to create models, controllers, and helpers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
