# blainesch/magicoracle

> 标签: phpunit, proxy, testing, unit

## 简介

A proxy class developed for unit testing that makes all methods and properties public to you.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
