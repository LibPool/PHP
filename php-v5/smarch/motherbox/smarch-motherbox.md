# smarch/motherbox

> 标签: gemerator, laravel 5, packages, workbench

## 简介

A Laravel 5 package generator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/SmarchSoftware/motherbox
- 源码仓库：https://github.com/SmarchSoftware/motherbox.git
- Packagist 页面：https://packagist.org/packages/smarch%2Fmotherbox

## 获取地址

- Composer 安装：`composer require smarch/motherbox`
- Packagist 仓库：https://repo.packagist.org/p2/smarch/motherbox.json
