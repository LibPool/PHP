# bkwld/craft-importable-shopify-feeds

> 标签: PHP

## 简介

A Craft plugin that maps Shopify data into feeds that are more easily consumed by FeedMe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
