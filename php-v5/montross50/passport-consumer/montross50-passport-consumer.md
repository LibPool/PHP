# montross50/passport-consumer

> 标签: Laravel 5.6, laravel, passport

## 简介

Library to consume laravel passport, handle oauth endpoints, and map remote users to local

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
