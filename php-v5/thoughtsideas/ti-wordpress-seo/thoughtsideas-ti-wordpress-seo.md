# thoughtsideas/ti-wordpress-seo

> 标签: composer, seo, wordpress, wp

## 简介

Tweak WordPress SEO plugin for simplicity.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
