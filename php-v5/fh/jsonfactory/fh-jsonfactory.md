# fh/jsonfactory

> 标签: FH, Food for the Hungry, JSONFactory, factory, json

## 简介

JsonFactory libraries. Creates a self-enforcing PHP object that conforms to a JSON Schema.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
