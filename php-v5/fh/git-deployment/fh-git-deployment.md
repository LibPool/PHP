# fh/git-deployment

> 标签: customizable, deploy, deployment, git, gitolite, hooks, phar, post-receive, ssh, strategy, test, testable, unit

## 简介

Server side gitolite post-receive deployment hooks for git projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
