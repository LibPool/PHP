# boboldehampsink/element-type-generator

> 标签: PHP

## 简介

This script will generate a basic Craft Element Type based on the Events sample plugin by Pixel & Tonic

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
