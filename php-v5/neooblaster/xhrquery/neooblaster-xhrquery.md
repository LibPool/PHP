# neooblaster/xhrquery

> 标签: ajax, dot notation, javascript, xmlhttprequest

## 简介

A JavaScript class focused on AJAX technology. It simplify AJAX integration for non jQuery users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
