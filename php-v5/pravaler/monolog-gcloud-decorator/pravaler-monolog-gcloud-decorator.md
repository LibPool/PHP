# pravaler/monolog-gcloud-decorator

> 标签: gcloud, google, logging, monolog

## 简介

Decorates monolog json formatter towards gcloud compatibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
