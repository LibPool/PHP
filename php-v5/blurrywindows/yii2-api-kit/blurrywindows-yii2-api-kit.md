# blurrywindows/yii2-api-kit

> 标签: api, basic, framework, kit, project template, yii2

## 简介

Yii 2 based kit that may be used to quickly start building an api from it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
