# blurrywindows/yii2-key-helper

> 标签: PHP

## 简介

Simple Yii 2 helper that generates unique keys and validates them against a database table and column.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
