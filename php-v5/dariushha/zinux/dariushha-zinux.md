# dariushha/zinux

> 标签: Simple, design pattern, lightweight, mvc, php, powerful, zinux

## 简介

A simple and lightweight but powerful framework supporting MVC design pattern

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
