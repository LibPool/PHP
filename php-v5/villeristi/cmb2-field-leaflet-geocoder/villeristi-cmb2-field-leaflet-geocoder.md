# villeristi/cmb2-field-leaflet-geocoder

> 标签: plugin, wordpress

## 简介

Leaflet (with Geocoder) field type for CMB2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
