# c2is/socialwall-bundle

> 标签: api, facebook, flick, google, instagram, social, twitter, youtube

## 简介

Bundle integrating the C2iS SocialWall component into Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
