# romanpitak/dotmailer-api-v2-client

> 标签: api, client, dotmailer, rest, v2, version 2

## 简介

Client library for the dotMailer v2 (REST) API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
