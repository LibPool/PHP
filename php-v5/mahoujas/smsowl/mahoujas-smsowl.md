# mahoujas/smsowl

> 标签: bulk sms, promotional sms, sms, sms india, smsowl, transactional sms

## 简介

This is PHP wrapper for SmsOwl REST API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
