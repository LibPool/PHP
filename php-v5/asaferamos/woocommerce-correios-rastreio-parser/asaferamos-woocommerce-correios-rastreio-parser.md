# asaferamos/woocommerce-correios-rastreio-parser

> 标签: PHP

## 简介

Atualize automaticamente o andamento do pedido com o rastreio dos Correios

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
