# fisharebest/php-polyfill

> 标签: compat, compatibility, php, polyfill, shim

## 简介

Polyfills for PHP 5.3 onwards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
