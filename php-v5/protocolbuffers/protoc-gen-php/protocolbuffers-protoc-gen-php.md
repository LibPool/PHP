# protocolbuffers/protoc-gen-php

> 标签: protoc, protocol buffers

## 简介

protoc generator plugin for PECL ProtocolBuffers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
