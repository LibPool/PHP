# thereference/drupal-security-audit

> 标签: PHP

## 简介

drupal-security-audit is a set of PHP_CodeSniffer rules that finds vulnerabilities and weaknesses related to security in your Drupal code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
