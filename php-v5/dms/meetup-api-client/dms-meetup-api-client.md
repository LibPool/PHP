# dms/meetup-api-client

> 标签: Guzzle, api, dms, meetup.com

## 简介

Meetup.com API client written on top of Guzzle. This supports all API operations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
