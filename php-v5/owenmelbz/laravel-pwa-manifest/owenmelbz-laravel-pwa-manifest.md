# owenmelbz/laravel-pwa-manifest

> 标签: laravel, manifest, pwa

## 简介

Laravel 5.5+ helper to generate basic PWA style manifests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
