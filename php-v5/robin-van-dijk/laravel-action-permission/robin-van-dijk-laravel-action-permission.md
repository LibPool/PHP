# robin-van-dijk/laravel-action-permission

> 标签: LaravelActionPermission, RobinVanDijk

## 简介

A package to generate permissions from laravel controller actions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
