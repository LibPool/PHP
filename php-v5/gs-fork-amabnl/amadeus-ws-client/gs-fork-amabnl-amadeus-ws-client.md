# gs-fork-amabnl/amadeus-ws-client

> 标签: airline, amadeus, booking, car, client, gds, hotel, masterpricer, offer, rental, service, soap, travel, webservice, wsdl, xml

## 简介

SOAP Web Service client library for interacting with the Amadeus GDS through its SOAP interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
