# jelix/jpref-module

> 标签: jelix, preferences

## 简介

module for Jelix, providing the deprecated jpref module for Jelix 1.9+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/jelix/jpref-module.git
- Packagist 页面：https://packagist.org/packages/jelix%2Fjpref-module
