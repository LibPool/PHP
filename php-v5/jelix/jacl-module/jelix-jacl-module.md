# jelix/jacl-module

> 标签: acl, authorization, jelix

## 简介

module for Jelix, providing  the deprecated jacl modules for Jelix 1.9+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
