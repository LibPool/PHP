# jelix/wikirenderer-plugin

> 标签: castor, jelix, jtpl, wiki

## 简介

a plugin for Jelix or Castor to render wiki content in a template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
