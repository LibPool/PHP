# jelix/fakeserverconf

> 标签: _SERVER PHP configuration unit tests

## 简介

Fill the $_SERVER array with various PHP server configuration for unit tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
