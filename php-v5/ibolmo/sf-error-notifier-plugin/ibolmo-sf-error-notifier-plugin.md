# ibolmo/sf-error-notifier-plugin

> 标签: PHP

## 简介

sfErrorNotifierPlugin sends automatically email notifications when application errors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
