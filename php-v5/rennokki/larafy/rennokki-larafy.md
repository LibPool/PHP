# rennokki/larafy

> 标签: Album, albums, api, laravel, music, playlist, playlists, songs, spotify, track, tracks, wrapper

## 简介

Larafy is a Laravel API wrapper for Spotify.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
