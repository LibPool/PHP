# mos/ctextfilter

> 标签: Html Purifier, YAML front matter, bbcode, education, json front matter, markdown, shortcode

## 简介

PHP classes for text filtering and formatting to HTML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
