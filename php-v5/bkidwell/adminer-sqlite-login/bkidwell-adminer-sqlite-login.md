# bkidwell/adminer-sqlite-login

> 标签: PHP

## 简介

Login plugin for Adminer to access SQLite databases authenticated with a global password.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
