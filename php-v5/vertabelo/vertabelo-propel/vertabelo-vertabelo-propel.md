# vertabelo/vertabelo-propel

> 标签: database, orm, propel, vertabelo

## 简介

Converts Vertabelo xml file into Propel schema.xml file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
