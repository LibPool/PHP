# etitov-cm/yii2-redis

> 标签: active-record, cache, redis, session, yii2

## 简介

Redis 3.x Cluster Cache, Session and ActiveRecord for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
