# asdfx/phergie-irc-plugin-react-urban-dictionary

> 标签: PHP

## 简介

Phergie plugin for returning entries from urban dictionary.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
