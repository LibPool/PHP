# burakerenel/devtube

> 标签: devswebdev, devtube, downloader, laravel, laravel downloader, laravel youtube downloader, laravel-package, media downloader, mp3, mp3 downloader, mp4, video downloader, youtube-dl, youtube-downloader

## 简介

A Laravel package for downloading videos from the net by simply passing a URL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
