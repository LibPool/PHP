# allenjd3/tuple-routing-stubs

> 标签: laravel, routing, tuple

## 简介

This package allows you to stub out tuple or array routing on fresh installs of laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
