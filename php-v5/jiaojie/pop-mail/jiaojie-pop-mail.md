# jiaojie/pop-mail

> 标签: mail, mail queue, php, pop, pop php, send mail

## 简介

Pop Mail Component for Pop PHP Framework. Patch for PHP version 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
