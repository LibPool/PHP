# povils/omnipay-paysera

> 标签: Paysera, gateway, merchant, omnipay, pay, payment, purchase

## 简介

Paysera gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
