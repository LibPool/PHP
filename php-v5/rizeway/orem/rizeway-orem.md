# rizeway/orem

> 标签: api, orm, php, rest

## 简介

Rizeway OREM is a Restful API Abstraction Layer. It is to Restful APIs what doctrine is for databases.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
