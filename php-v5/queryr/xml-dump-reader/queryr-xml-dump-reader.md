# queryr/xml-dump-reader

> 标签: QueryR, resources, serializers, wikibase

## 简介

Reader for Wikidata/Wikibase XML dumps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
