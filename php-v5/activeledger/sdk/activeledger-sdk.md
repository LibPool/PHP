# activeledger/sdk

> 标签: activeledger, blockchain, distributed ledger technology, dlt, ledger, network, node, sdk, smart contracts

## 简介

PHP package for use when integrating with Activeledger

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
