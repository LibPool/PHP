# planetadeleste/privateplugins

> 标签: PHP

## 简介

Manage private plugins, from Github or Bitbucket repositories. Plugins that are not in OctoberCMS Marketplace.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/planetadeleste/oc-private-plugins
- 源码仓库：https://bitbucket.org/planetadeleste/oc-private-plugins.git
- Packagist 页面：https://packagist.org/packages/planetadeleste%2Fprivateplugins
