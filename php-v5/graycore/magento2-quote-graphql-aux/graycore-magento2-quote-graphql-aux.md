# graycore/magento2-quote-graphql-aux

> 标签: PHP

## 简介

A Magento 2 package that contains additional GraphQl modifications to the cart to solve common UI problems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
