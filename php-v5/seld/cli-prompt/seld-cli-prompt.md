# seld/cli-prompt

> 标签: cli, console, hidden, input, prompt

## 简介

Allows you to prompt for user input on the command line, and optionally hide the characters they type

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
