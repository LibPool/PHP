# titzu/shortpixel-web

> 标签: compress, images, optimize, shortpixel, web tool

## 简介

ShortPixel generic web interface using the PHP SDK. Read more at https://shortpixel.com/api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
