# micsay/yii2-captcha

> 标签: base64, captcha, extension, restful, yii2

## 简介

yii2-captcha for restful api by returning image's base64 extend yii/captcha/CaptchaAction

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
