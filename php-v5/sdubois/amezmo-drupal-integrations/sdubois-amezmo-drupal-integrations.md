# sdubois/amezmo-drupal-integrations

> 标签: PHP

## 简介

Add this project to any Drupal distribution based on drupal/core-composer-scaffold to enable it for use on Amezmo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
