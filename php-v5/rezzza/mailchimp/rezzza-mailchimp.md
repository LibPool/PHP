# rezzza/mailchimp

> 标签: api, mailchimp, newsletter

## 简介

MailChimp PHP API Wrapper 1.3.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://apidocs.mailchimp.com/api/downloads/#php
- 源码仓库：https://github.com/rezzza/mailchimp.git
- Packagist 页面：https://packagist.org/packages/rezzza%2Fmailchimp

## 历史版本号

- 当前版本：1.3.1

- 1.3.1

## 获取地址

- Composer 安装：`composer require rezzza/mailchimp`
- Packagist 仓库：https://repo.packagist.org/p2/rezzza/mailchimp.json
- 许可证：MIT
- PHP 要求：>=5.0.0
