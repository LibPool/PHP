# rezzza/payment-be2bill-bundle

> 标签: be2bill, bundle, payment, symfony

## 简介

Payment Bundle providing access to the Be2bill API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
