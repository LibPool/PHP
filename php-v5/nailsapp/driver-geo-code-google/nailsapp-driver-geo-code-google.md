# nailsapp/driver-geo-code-google

> 标签: GeoCode Module, Nails, Shed Collective, codeigniter, driver, google geocoding api

## 简介

This is the "Google" driver for the Nails GeoCode module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
