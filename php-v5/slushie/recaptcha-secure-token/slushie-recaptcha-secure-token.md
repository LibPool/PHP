# slushie/recaptcha-secure-token

> 标签: recaptcha, secure token, stoken

## 简介

Generate ReCaptcha-compatible secure tokens

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
