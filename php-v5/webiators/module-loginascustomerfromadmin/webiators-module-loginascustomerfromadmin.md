# webiators/module-loginascustomerfromadmin

> 标签: PHP

## 简介

Login as Customer From Admin extension by Webiators allow Admin to log in to any customer account.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
