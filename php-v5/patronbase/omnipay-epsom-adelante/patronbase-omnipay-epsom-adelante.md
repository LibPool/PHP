# patronbase/omnipay-epsom-adelante

> 标签: adelante, connectpay, gateway, merchant, omnipay, pay, payment, smartpay, websmartconnect

## 简介

Epsom connector to Adelante (ConnectPay) driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
