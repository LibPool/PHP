# serwin35/laravel-filemanager

> 标签: CKEditor, file, filemanager, image, laravel, manager, tinymce, upload

## 简介

A file upload/editor intended for use with Laravel and CKEditor / TinyMCE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
