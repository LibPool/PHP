# amercier/cli-helpers

> 标签: cli, command, command-line, helpers, line, utilities, utility

## 简介

Utility classes to write PHP command-line scripts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
