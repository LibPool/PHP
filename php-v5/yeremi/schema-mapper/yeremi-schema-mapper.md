# yeremi/schema-mapper

> 标签: api, attributes, normalizer

## 简介

A PHP library for mapping external API data to PHP objects using PHP 8 attributes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
