# biliboobrian/microservice-crud

> 标签: Microservice, crud, framework, laravel, lumen

## 简介

A CRUD convenience layer for microservices built in Lumen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
