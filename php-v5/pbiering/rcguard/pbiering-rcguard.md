# pbiering/rcguard

> 标签: captcha, mail, roundcube, security

## 简介

Roundcube plugin that enforces requirement of solving a Captcha during login

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
