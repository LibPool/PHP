# pear2/cache_shm

> 标签: abstraction, apc, cache, caching, lock, locking, pear2, shm, wincache

## 简介

Wrapper for shared memory and locking functionality across different PHP extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
