# yetopen/yii2-usuario-ldap

> 标签: extension, ldap, usuario, yii2

## 简介

An Yii2 extension to add LDAP auth (and sync) to yii2-usuario

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
