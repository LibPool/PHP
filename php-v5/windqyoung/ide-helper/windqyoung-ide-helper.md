# windqyoung/ide-helper

> 标签: PHP

## 简介

ide helper, 生成PHP中的类, 函数, 常量, 等的代码结构, 以便ide能提示自动完成. 比如生成 phalcon框架, mongodb扩展的PHP代码

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
