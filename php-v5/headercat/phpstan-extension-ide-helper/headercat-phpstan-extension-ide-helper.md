# headercat/phpstan-extension-ide-helper

> 标签: PHP

## 简介

PHPStan extension IDE helper, provides dummy PHPStan namespace classes and functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
