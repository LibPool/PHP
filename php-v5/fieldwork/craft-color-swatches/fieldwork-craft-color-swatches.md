# fieldwork/craft-color-swatches

> 标签: Craft, cms, color-swatches, craft-plugin, craftcms

## 简介

Let clients choose from a predefined set of colors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
