# dominicsayers/isemail

> 标签: email, validation

## 简介

Checks an email address against the following RFCs: 3696, 1123, 4291, 5321, 5322

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
