# biurad/filephp

> 标签: FilePHP, PHP7, biurad, biurad-toolbox, filesystem, php5

## 简介

This file is used to get rid of some discouraged file funtions when it comes to php filesystem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
