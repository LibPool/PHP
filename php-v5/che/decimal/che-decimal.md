# che/decimal

> 标签: bcmath, big, bigdecimal, decimal, money, number

## 简介

Immutable arbitrary-precision decimal implementation for php 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
