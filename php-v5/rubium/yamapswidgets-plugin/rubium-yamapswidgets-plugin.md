# rubium/yamapswidgets-plugin

> 标签: october, yandex-maps

## 简介

Backend Yandex Maps Widgets for OctoberCMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
