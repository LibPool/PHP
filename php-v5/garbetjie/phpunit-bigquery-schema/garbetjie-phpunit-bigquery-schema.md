# garbetjie/phpunit-bigquery-schema

> 标签: PHP

## 简介

A custom PHPUnit constraint to validate a given object/array against a BigQuery schema.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
