# anfa/vk-auth

> 标签: authorization, remixsid, vk, vkontakte

## 简介

tiny lib to get vk auth cookie (remixsid) using valid mobile phone number and password

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
