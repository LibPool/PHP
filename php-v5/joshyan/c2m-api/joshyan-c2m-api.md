# joshyan/c2m-api

> 标签: click2mail, php

## 简介

click2mail api with composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/joshyan/c2m-api.git
