# addgod/omnipay-dibs-d2

> 标签: dibs, dibs d2, gateway, merchant, omnipay, pay, payment, transfer

## 简介

Dibs D2 driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
