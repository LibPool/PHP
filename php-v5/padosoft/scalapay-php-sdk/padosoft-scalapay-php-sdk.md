# padosoft/scalapay-php-sdk

> 标签: payments, scalapay, shopping

## 简介

Padosoft-maintained clone of the Scalapay PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/padosoft/scalapay-php-sdk
- 源码仓库：https://github.com/padosoft/scalapay-php-sdk.git
