# pembuatan/bot

> 标签: Telegram bot library, telegram, telegram bot, telegram bot api

## 简介

Pustaka sederhana untuk pembuatan bot Telegram dengan menggunakan bahasa PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
