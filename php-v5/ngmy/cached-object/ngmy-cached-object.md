# ngmy/cached-object

> 标签: Laravel 4, cache

## 简介

A caching scheme for an object for Laravel 4, inspired by Enterprise Rails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
