# nikjaysix/omnipay-pin

> 标签: gateway, merchant, omnipay, pay, payment, pin

## 简介

Pin Payments driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
