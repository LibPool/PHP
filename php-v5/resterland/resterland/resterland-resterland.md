# resterland/resterland

> 标签: TYPO3 CMS, bootstrap, responsive

## 简介

This theme from ResterLand WebAtelier extends the TYPOO3 bootstrap-package by Benjamin Kott.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
