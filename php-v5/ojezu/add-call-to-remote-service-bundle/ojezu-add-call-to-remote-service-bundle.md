# ojezu/add-call-to-remote-service-bundle

> 标签: PHP

## 简介

Symfony2 bundle that allows injecting method from one service declaration in DI to another

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
