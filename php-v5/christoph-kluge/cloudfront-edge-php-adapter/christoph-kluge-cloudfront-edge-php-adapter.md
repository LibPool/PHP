# christoph-kluge/cloudfront-edge-php-adapter

> 标签: PHP

## 简介

A cloudfront edge event transformer for symfony or laravel request objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
