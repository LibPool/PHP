# xdna/xdna

> 标签: enterprise, framework, multi apps, mvc

## 简介

xDNA is a MVC Enterprise Framework for multi app projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
