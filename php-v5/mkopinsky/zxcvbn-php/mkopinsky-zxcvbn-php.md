# mkopinsky/zxcvbn-php

> 标签: password, zxcvbn

## 简介

Realistic password strength estimation PHP library based on Zxcvbn JS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
