# jeanjar/laravel-from-brasil

> 标签: PHP

## 简介

Tradução dos métodos mais utilizados do Eloquent, apenas para diversão

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
