# craftcms/hexdec

> 标签: cms, craftcms, hexdec, yii2

## 简介

Adds a new hexdec filter to Craft, which will convert a hexadecimal value to a decimal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
