# craftcms/guest-entries

> 标签: cms, craftcms, entries, guest, yii2

## 简介

This plugin allows you to save guest entries from the front-end of your website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
