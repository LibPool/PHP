# webmarketer/webmarketer-php

> 标签: app.webmarketer.io, sdk, webmarketer

## 简介

The official PHP SDK for Webmarketer (app.webmarketer.io)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
