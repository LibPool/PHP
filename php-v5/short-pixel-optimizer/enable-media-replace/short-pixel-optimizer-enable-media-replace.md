# short-pixel-optimizer/enable-media-replace

> 标签: PHP

## 简介

A free, lightweight and easy to use WordPress plugin that allows you to seamlessly replace an image or file in your Media Library by uploading a new file in its place.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
