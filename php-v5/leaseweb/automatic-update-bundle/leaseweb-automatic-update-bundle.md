# leaseweb/automatic-update-bundle

> 标签: composer, debug, update

## 简介

Enables automatic updates of the application from the Web Debug Toolbar.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
