# leaseweb/version-information-bundle

> 标签: subversion, svn, version

## 简介

Adds output of SVN and Git 'status' commands to the Web Debug Toolbar

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
