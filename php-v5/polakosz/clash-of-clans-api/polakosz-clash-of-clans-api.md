# polakosz/clash-of-clans-api

> 标签: ClashOfClansAPI, CoC, PoLáKoSz, SuperCell, api, wrapper

## 简介

PHP wrapper for SuperCell's official ClashOfClans API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
