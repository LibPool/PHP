# veka-server/form

> 标签: JS, form, minimalist, php, popin, table, validation

## 简介

Une lib PHP / JS / CSS de gestion des formulaires, des tableau et des popin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
