# veka-server/rooter

> 标签: minimalist, onefile, psr-15, rooter

## 简介

Un rooter minimaliste dérivé de Xesau/Router

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
