# systemico/conector_db

> 标签: PHP

## 简介

Singleton pattern to connect database Mysql, PostgreSQL, Oracle, SQL Server, and others.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
