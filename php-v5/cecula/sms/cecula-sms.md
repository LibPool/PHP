# cecula/sms

> 标签: A2P, Cecula, Nigeria, api, bbn, bulk, bulksms, messaging, p2p, sms, text

## 简介

PHP library for sending A2P and P2P SMS on Cecula https://www.cecula.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
