# socloz/ninja-mutex

> 标签: flock, lock, locking, memcache, memcached, mutex, mysql

## 简介

Simple to use mutex implementation that can use flock, memcache, memcached or mysql for locking

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
