# asdfdotdev/utm.codes

> 标签: analytics, link builder, plugin, utm codes, wordpress

## 简介

A plugin that makes building analytics friendly links quick and easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
