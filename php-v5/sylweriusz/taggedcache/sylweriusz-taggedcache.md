# sylweriusz/taggedcache

> 标签: cache, memcache, redis, tags

## 简介

Cache (redis or memcache), fast delete, optionally based on tags

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
