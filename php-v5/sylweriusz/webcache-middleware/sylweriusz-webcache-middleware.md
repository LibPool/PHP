# sylweriusz/webcache-middleware

> 标签: cache, middleware, redis, slim, webcache

## 简介

Static aka Html pages cache for Slim3 middleware stack

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
