# fterenzani/swiftmail

> 标签: mail, mailer, swiftmailer

## 简介

An implementation of the Facade pattern for Swift Mailer 5 and later

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
