# foglcz/jsonrpc2

> 标签: json, nette, rpc

## 简介

jsonrpc2 implementation for generic use. Test suite for Nette Framework included.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
