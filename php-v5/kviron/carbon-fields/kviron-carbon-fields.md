# kviron/carbon-fields

> 标签: PHP

## 简介

WordPress plugin loader for Carbon Fields.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://carbonfields.net/
- 源码仓库：https://github.com/kviron/wordpress-plugin-carbon-fields.git
- Packagist 页面：https://packagist.org/packages/kviron%2Fcarbon-fields
