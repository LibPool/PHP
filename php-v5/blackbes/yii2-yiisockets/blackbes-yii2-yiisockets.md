# blackbes/yii2-yiisockets

> 标签: WebSockets, extension, ratchet with yii2, sockets, yii2

## 简介

PHP Websockets with Yii2 integration based on Ratchet.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
