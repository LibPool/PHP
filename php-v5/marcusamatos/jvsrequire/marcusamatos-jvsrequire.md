# marcusamatos/jvsrequire

> 标签: css, developer, javascript, jvs, jvsrequire, module, zf2

## 简介

Module for manager Javascript and Css files when necessary.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
