# julianpitt/dbmanager

> 标签: LaravelDatabaseManager, dbmanager, julianpitt

## 简介

A highly configurable database backup and restore solution for laravel projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
