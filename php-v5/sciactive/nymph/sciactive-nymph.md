# sciactive/nymph

> 标签: Object Relational Mapping, Object relational mapper, mysql, object data store, object database, orm, postgres, postgresql

## 简介

Don't use sciactive/nymph anymore. You should use sciactive/nymph-server and sciactive/nymph-pubsub.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
