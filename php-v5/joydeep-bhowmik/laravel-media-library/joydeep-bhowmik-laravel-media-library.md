# joydeep-bhowmik/laravel-media-library

> 标签: file upload1, laravel, laravel media library

## 简介

A laravel media library for associating files with laravel models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
