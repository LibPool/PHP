# hjk/vb-phoenix

> 标签: Ergebnisdienst, Phoenix, contao, content elements, extension, result service, volleyball, wvv

## 简介

Extension providing content elements to embed volleyball results, schedules and more provided by the Phoenix result service of the WVV volleyball assisiation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
