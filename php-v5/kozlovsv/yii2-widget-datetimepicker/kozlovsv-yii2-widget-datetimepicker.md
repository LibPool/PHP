# kozlovsv/yii2-widget-datetimepicker

> 标签: datetime, extension, form, jquery, picker, plugin, select2, widget, yii2

## 简介

Enhanced Yii2 wrapper for the bootstrap datetimepicker plugin. Masked Input

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
