# ismael-gonzalez/mysql-queue

> 标签: laravel, mysql, queue

## 简介

A laravel 4.2 queue driver using MySQL database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
