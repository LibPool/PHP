# konapun/pdo-decorator

> 标签: database, decorator, mysql, oracle, pdo, postgres

## 简介

A decorator interface for PDO and some basic decorators

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
