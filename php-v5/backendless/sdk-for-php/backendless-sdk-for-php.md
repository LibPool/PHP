# backendless/sdk-for-php

> 标签: api, baas, backendless, cloud backend, mbaas, mobile backend

## 简介

Backendless SDK for PHP. Contains APIs to work with the cloud mobile backend provided by Backendless

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/Backendless/PHP-SDK.git
