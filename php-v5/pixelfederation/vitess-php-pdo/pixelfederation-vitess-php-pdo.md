# pixelfederation/vitess-php-pdo

> 标签: Vitess, driver, pdo

## 简介

PHP PDO compliant driver for Vitess PHP client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
