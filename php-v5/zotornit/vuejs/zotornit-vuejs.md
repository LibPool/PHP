# zotornit/vuejs

> 标签: Vue.js, requirejs, typo3, vue, vuejs, zotorn, zotornit

## 简介

Vue.js Framework for TYPO3 Backend Modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
