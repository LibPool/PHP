# vrkansagara/zend-framework-enterprise-starter-kit

> 标签: framework, mvc, zf

## 简介

Enterprise Web application starter kit using Zend Framework 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
