# phergie/phergie-irc-plugin-dns

> 标签: bot, irc, phergie, phergieplugin, plugin, react

## 简介

Phergie plugin for Looking up IP's by hostnames

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
