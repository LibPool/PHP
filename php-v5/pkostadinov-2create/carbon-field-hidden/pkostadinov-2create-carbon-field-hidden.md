# pkostadinov-2create/carbon-field-hidden

> 标签: carbon, carbon-field, carbon-field-hidden, wordpress

## 简介

A basic Carbon Fields extension, that adds support for Hidden type field.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
