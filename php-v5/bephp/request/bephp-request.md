# bephp/request

> 标签: auth, curl, get, jsonrpc, post, request

## 简介

Simple, straight forward request helper, frok from https://github.com/fightbulc/simplon_request, support php5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
