# ofbeaton/granite-php

> 标签: Code style, Coding Style, PHP_CodeSniffer, code sniffer, lint

## 简介

Opinionated PHP Coding Style enforcement for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
