# yuzuru-s/parse-rss

> 标签: RDF, atom, parser, rss

## 简介

This PHP library can easily parse xml files, especially RSS1.0, RSS2.0 and ATOM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
