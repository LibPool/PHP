# sydes/sydes

> 标签: cmf, cms, sqlite, sydes

## 简介

SyDES - Lightweight CMF for a simple sites with SQLite database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
