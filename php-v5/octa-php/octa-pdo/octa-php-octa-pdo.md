# octa-php/octa-pdo

> 标签: PHP

## 简介

A light-weight PHP-PDO database class, this database class is inspired by codeigniter's active record.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
