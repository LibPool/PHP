# pioneer-dynamics/inertia-api-middleware

> 标签: PHP

## 简介

Easily use standard HTTP Controllers for API calls as well when using inertia as front end

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
