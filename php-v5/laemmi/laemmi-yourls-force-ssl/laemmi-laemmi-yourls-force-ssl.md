# laemmi/laemmi-yourls-force-ssl

> 标签: plugin, yourls

## 简介

Plugin for YOURLS. Bind login username to url entry.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
