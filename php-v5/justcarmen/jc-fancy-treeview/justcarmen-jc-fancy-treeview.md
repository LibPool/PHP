# justcarmen/jc-fancy-treeview

> 标签: genealogy, webtrees, webtrees-module

## 简介

webtrees module to display a fancy treeview of the genealogy in a narrative way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
