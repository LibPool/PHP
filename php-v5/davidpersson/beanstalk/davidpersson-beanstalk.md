# davidpersson/beanstalk

> 标签: Socket, beanstalk, beanstalkd, queue

## 简介

Minimalistic PHP client for beanstalkd.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
