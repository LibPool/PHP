# imagerelay/imagerelay-php

> 标签: api, imagerelay

## 简介

The Image Relay PHP Library makes it easy for developers to leverage the Image Relay API in their applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
