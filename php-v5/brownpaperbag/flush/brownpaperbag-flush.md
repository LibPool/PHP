# brownpaperbag/flush

> 标签: chunked, flush, long-polling, requests, zoobie

## 简介

Library to flush data friendly. To use in long-polling and zombie requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
