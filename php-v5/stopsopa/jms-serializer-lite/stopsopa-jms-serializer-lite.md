# stopsopa/jms-serializer-lite

> 标签: PHP

## 简介

Simple library to easy dump/shape objects/arrays from db to make it ready to expose through RESTful API - one direction

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
