# karatbars/karatbars_tools

> 标签: csv, typo3

## 简介

Karatbars Tools for TYPO3 contains various overrides, tasks, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
