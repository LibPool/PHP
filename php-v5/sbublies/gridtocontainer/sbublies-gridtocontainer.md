# sbublies/gridtocontainer

> 标签: PHP

## 简介

EXT:gridtocontainer is a small migration extension with backend module for those who want to switch from EXT:gridelements to EXT:container.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
