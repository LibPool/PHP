# twitter/bootstrap-bundle

> 标签: front-end framework, symfony twitter bootstrap, twitter, twitter bootstrap

## 简介

Sleek, intuitive, and powerful front-end framework for faster and easier web development. integration into Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
