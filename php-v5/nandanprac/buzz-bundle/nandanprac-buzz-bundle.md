# nandanprac/buzz-bundle

> 标签: buzz, gremo, http client

## 简介

Symfony Bundle for using the lightweight Buzz HTTP client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
