# webcoast/dot-forms

> 标签: Flexform, TCA, cms, dynamic, fields, form, json, typo3

## 简介

TYPO3 CMS extension for storing TCA fields with dot notation into a single field

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
