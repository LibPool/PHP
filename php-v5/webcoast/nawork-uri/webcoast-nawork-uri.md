# webcoast/nawork-uri

> 标签: PHP

## 简介

A modern, flexible extension for creating and managing urls and redirects in the TYPO3 CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
