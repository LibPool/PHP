# phpmk/devicedata

> 标签: detection, device, php.mk

## 简介

PHP.mk PHP Library for using Device API service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://php.mk/
- 源码仓库：https://github.com/mihajlo/device-data.git
- Packagist 页面：https://packagist.org/packages/phpmk%2Fdevicedata

## 获取地址

- Composer 安装：`composer require phpmk/devicedata`

- 许可证：GPL-3.0-or-later
