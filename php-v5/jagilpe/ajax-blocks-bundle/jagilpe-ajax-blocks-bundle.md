# jagilpe/ajax-blocks-bundle

> 标签: ajax, block, symfony

## 简介

Symfony Bundle for rendering blocks refreshable with ajax requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
