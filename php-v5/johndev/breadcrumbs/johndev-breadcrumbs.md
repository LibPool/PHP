# johndev/breadcrumbs

> 标签: breadcrumbs, framework, generation, laravel, package

## 简介

Build breadcrumbs automatically in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
