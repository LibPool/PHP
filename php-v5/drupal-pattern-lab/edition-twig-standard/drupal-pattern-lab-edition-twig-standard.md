# drupal-pattern-lab/edition-twig-standard

> 标签: pattern lab

## 简介

Standard Edition of Pattern Lab for Twig. Installs all Twig-related assets except for a StarterKit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
