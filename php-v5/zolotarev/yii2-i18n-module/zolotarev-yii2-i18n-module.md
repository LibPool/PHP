# zolotarev/yii2-i18n-module

> 标签: i18n, translation, translations, yii2

## 简介

Yii2 i18n (internalization) module makes the translation of your application so simple

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
