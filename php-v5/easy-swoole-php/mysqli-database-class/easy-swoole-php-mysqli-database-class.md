# easy-swoole-php/mysqli-database-class

> 标签: PHP

## 简介

PHP MySQL Wrapper and object mapper which utilizes MySQLi and prepared statements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
