# 10quality/license-keys-php-client

> 标签: api, license keys, php, wordpress

## 简介

PHP client for WooCommerce License Keys wordpress plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
