# 10quality/php-data-model

> 标签: data, models

## 简介

PHP Library that provides generic and scalable Data Models (abstract model class) for any type of data handling.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
