# sifei/timbrado-soap-client

> 标签: PHP

## 简介

SOAP WS client. Cliente de servicio web de Sifei para timbrado y cancelacion basado en SOAP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
