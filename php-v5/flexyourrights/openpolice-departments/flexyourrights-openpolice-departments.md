# flexyourrights/openpolice-departments

> 标签: Accountability, Flex Your Rights, Open Police, Open Police Complaints, SurvLoop, commendations, compliments, laravel, misconduct, oversight, police departments, survey

## 简介

This repository can install the OpenPolice.org database of 18,000 police departments in the U.S..

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
