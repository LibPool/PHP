# flexyourrights/docker-openpolice

> 标签: Accountability, Flex Your Rights, Open Police, Open Police Complaints, SurvLoop, commendations, compliments, laravel, misconduct, oversight, police departments, survey

## 简介

Docker Compose configuration for Open Police Complaints ^0.1 running PHP 7.3 with Nginx, PHP-FPM, PostgreSQL 11.2 and Composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
