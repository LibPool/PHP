# zugoripls/laravel-framework

> 标签: framework, laravel

## 简介

Customized(replaced illuminate/encryption with zugoripls/openssl-encryption) Laravel Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
