# mojitowp/pymexpress

> 标签: PHP

## 简介

Clase de conexión para el nuevo Web Service de Correos de Costa Rica (Pymexpress).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
