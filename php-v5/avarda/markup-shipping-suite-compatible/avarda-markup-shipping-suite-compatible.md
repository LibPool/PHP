# avarda/markup-shipping-suite-compatible

> 标签: PHP

## 简介

Compatibility module for Markup Shipping Suite to Avarda Checkout3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
