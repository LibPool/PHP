# clue/term-react

> 标签: C0, CSI, ansi, apc, ascii, c1, control codes, dps, osc, pm, reactphp, streaming, terminal, vt100, xterm

## 简介

Streaming terminal emulator, built on top of ReactPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
