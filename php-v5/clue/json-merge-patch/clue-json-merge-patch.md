# clue/json-merge-patch

> 标签: JSON merge patch, RFC 7396, patch file

## 简介

JSON merge patch (RFC 7396) is a simple alternative to JSON patch (RFC 6902)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
