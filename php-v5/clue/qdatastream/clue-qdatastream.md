# clue/qdatastream

> 标签: QDataStream, binary, parse, qt, serialize

## 简介

Lightweight PHP library that allows exchanging binary data with Qt programs (QDataStream)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
