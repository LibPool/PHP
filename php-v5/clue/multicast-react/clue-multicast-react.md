# clue/multicast-react

> 标签: async, mcast, multicast, reactphp, udp

## 简介

Simple, event-driven multicast UDP message client and server for ReactPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
