# pecserke/universal-mappings

> 标签: Symfony2, doctrine, mapping

## 简介

Symfony2 Twig DoctrineLoader Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
