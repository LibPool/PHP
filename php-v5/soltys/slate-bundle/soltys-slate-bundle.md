# soltys/slate-bundle

> 标签: api, bundle, rest, slate, soltys, symfony

## 简介

This bundle provides a configurable Slate documentation for your REST APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
