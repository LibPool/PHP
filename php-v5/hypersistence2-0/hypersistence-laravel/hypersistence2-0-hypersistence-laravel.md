# hypersistence2-0/hypersistence-laravel

> 标签: framework, laravel, microframework, persistence

## 简介

PHP Object Oriented persistence framework to Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
