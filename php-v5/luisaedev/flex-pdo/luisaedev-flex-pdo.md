# luisaedev/flex-pdo

> 标签: PHP

## 简介

Flexible and fancy class for PHP, it will help you to handle PDO connections and PDO statements through a single instance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
