# openlss/lib-xport

> 标签: rpc, sdk authentication, sdk transport, stream, stream compression, stream encryption, transport

## 简介

Service RPC transport layer / protocol implemented in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
