# socialengineers/tbs

> 标签: OpenID Connect, OpenId, authentickated, facebook, fitbit, google, jwt, linkedin, oauth, twitter

## 简介

OAuth social media library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
