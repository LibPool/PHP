# coliff/bootstrap-ie11

> 标签: bootstrap, css, ie, internet-explorer, polyfill

## 简介

Bootstrap 5 for Internet Explorer 11

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
