# skydiver/laravel-adminer

> 标签: adminer, database, laravel5, management

## 简介

Adminer (by Jakub Vrana) wrapper for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
