# venatus/xmaven-php-sdk

> 标签: media, video, vod, xmaven

## 简介

PHP Wrapper for Xmaven Remote Web Services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://docs.xmaven.com/api/01-installation
- 源码仓库：https://github.com/Venatus/xmaven-php-sdk.git
