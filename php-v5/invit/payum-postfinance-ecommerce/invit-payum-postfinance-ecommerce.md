# invit/payum-postfinance-ecommerce

> 标签: ecommerce, payment, postfinance

## 简介

The Payum extension. It provides Postfinance Ecommerce payment integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
