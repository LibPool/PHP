# digitoimistodude/woothemes-updater

> 标签: plugin, woocommerce, wordpress

## 简介

WooThemes Helper for updating WooThemes plugins and lisences via wp-admin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
