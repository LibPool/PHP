# kipchak/driver-cloudflare-dns

> 标签: Mamluk, apis, cloudflare, dns, microservices

## 简介

A Cloudflare DNS driver for the Kipchak API Development Kit (ADK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
