# kipchak/middleware-error

> 标签: Mamluk, apis, http, microservices

## 简介

An Error Handling Middleware for the Kipchak API Development Kit (ADK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
