# kipchak/driver-sftp

> 标签: Mamluk, Managed File Transfer, apis, file transfer, microservices, sftp, ssh

## 简介

An SFTP driver for exchanging files with partners and other systems from the Kipchak API Development Kit (ADK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
