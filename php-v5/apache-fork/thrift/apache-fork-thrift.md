# apache-fork/thrift

> 标签: PHP

## 简介

Apache Thrift RPC system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://thrift.apache.org/
- 源码仓库：https://github.com/askuiop/thrift.git
- Packagist 页面：https://packagist.org/packages/apache-fork%2Fthrift

- Composer 安装：`composer require apache-fork/thrift`

- 许可证：Apache-2.0
- PHP 要求：>=5.3.0
