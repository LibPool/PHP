# mgamadeus/ddd-argus

> 标签: PHP

## 简介

External API repository layer for mgamadeus/ddd — batched HTTP calls with multi-tier caching

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
