# fourello-devs/granular-search

> 标签: GranularSearch, laravel

## 简介

Granular Search is a package for Laravel which aims to provide automatic searching feature to Eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
