# stikmanw/file-event-watcher

> 标签: PHP

## 简介

File system watcher allowing for observeable handlers when a directory changes or content of the directory changes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
