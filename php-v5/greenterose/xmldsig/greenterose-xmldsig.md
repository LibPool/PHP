# greenterose/xmldsig

> 标签: security, signature, sunat, xml, xmldsig

## 简介

Libreria para firmar XML según normativa de SUNAT en Facturación Electrónica

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
