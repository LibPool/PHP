# davidgorges/color-contrast

> 标签: WCAG 2.0, color, contrast, library, usability

## 简介

A tiny library to find color combinations with a contrast threshold

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
