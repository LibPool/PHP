# wilber/wilbercsv

> 标签: csv, eloquent, export, laravel

## 简介

A Laravel package to easily generate CSV files from Eloquent model.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
