# taylorotwell/laravel-oauth2

> 标签: laravel, oauth2

## 简介

Authorize users in your application with multiple OAuth 2.0 providers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
