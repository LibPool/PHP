# fof/passport

> 标签: flarum, league, oauth, oauth2, passport

## 简介

The OAuth2 (and Laravel passport) compatible oauth extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
