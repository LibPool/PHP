# jlorente/zadarma-php-sdk

> 标签: jlorente, php, zadarma

## 简介

A PHP package to access the Zadarma API by a comprehensive way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
