# mrfabulous/laravel-shibboleth

> 标签: PHP

## 简介

Enable basic Shibboleth support for Laravel. Forked from razorbacks/laravel-shibboleth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
