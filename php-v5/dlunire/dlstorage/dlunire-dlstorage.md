# dlunire/dlstorage

> 标签: PHP

## 简介

Librería de almacenamiento de datos binarios, optimizada para su integración con el framework DLUnire. Permite almacenar, gestionar y recuperar datos en formatos binarios de manera eficiente.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
