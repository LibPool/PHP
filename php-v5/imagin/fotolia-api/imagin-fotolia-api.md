# imagin/fotolia-api

> 标签: api, fotolia

## 简介

Composer package of the Fotolia API toolkit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/Fotolia/Fotolia-API
- 源码仓库：https://github.com/imagin/fotolia-api.git
- Packagist 页面：https://packagist.org/packages/imagin%2Ffotolia-api
