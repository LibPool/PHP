# flowpack/elasticsearch-contentgraphadapter

> 标签: PHP

## 简介

The ElasticSearch adapter for the Neos Content Repository using the in-memory content graph

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
