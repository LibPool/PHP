# tasker/tasker-concat-files

> 标签: concat files, jsifalda, taks runner, task, tasker

## 简介

Task which will be concatenate your files for task manager Tasker

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
