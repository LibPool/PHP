# maclof/omnipay-realex

> 标签: gateway, merchant, omnipay, pay, payment, purchase, realex

## 简介

Realex gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
