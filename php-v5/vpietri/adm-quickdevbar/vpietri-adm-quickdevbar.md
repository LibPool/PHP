# vpietri/adm-quickdevbar

> 标签: debug, dev, developer, profiler, toolbar

## 简介

QuickDevBar is a developer toolbar for magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
