# robsontenorio/lighthouse-dashboard

> 标签: Metrics, analytics, dashboard, graphql, laravel, lighthouse

## 简介

Dashboard for Laravel Lighthouse GraphQL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
