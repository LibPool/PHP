# ocsp/responder

> 标签: certificate, check, https, ocsp, online certificate status protocol, request, revocation, revoke, revoked, rfc6069, security

## 简介

Library implement an Online Certificate Status Protocol (OCSP) responder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
