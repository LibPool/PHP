# pleonovich/log

> 标签: log, php

## 简介

Simple way to write log information into txt file from PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/pleonovich/log
- 源码仓库：https://github.com/pleonovich/log.git
- Packagist 页面：https://packagist.org/packages/pleonovich%2Flog

## 获取地址

- Composer 安装：`composer require pleonovich/log`
- Packagist 仓库：https://repo.packagist.org/p2/pleonovich/log.json
