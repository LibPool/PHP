# kevinlangleyjr/wp-media-categories

> 标签: category, media, taxonomy, wordpress

## 简介

Adds a custom taxononomy (media-categories) Media Categories to the WordPress Media Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
