# marena/yii2-meta-trait

> 标签: extension, trait, yii2

## 简介

Providers WordPress-like meta table functionality for tables represented by an ActiveRecord class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
