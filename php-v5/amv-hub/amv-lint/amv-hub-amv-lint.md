# amv-hub/amv-lint

> 标签: PHP

## 简介

This is a tool for checking a consistency and coding convention of Laravel project. Please contact me if you have any problem when using it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
