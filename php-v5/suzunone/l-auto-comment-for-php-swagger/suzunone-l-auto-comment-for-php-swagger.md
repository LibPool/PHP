# suzunone/l-auto-comment-for-php-swagger

> 标签: PHP

## 简介

Automatically generate PHP Swagger comments from Laravel's Controller, Model, and form requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
