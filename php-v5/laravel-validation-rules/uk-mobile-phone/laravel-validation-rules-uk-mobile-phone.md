# laravel-validation-rules/uk-mobile-phone

> 标签: laravel, phone, uk, validation

## 简介

Validate that a given UK mobile phone number is valid.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
