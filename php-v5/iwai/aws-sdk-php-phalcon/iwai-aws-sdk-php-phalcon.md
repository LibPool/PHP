# iwai/aws-sdk-php-phalcon

> 标签: amazon, aws, dynamodb, ec2, phalcon, s3, sdk

## 简介

A simple Phalcon service provider for including the AWS SDK for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
