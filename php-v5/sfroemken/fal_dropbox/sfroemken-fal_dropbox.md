# sfroemken/fal_dropbox

> 标签: TYPO3 CMS, driver, dropbox, fal, typo3

## 简介

Add a FAL driver for Dropbox to TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
