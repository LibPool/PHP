# avtonom/creole-bundle

> 标签: creole, markup, parser, wiki, wikitext

## 简介

A bundle for Symfony 2 PHP Framework with support for Creole 1.0 Wiki markup language.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
