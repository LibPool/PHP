# woofmang/scanner

> 标签: csv, scanner, url

## 简介

Scan an array of URLs and report inaccessible URLs (from Josh Lockhart's Modern PHP)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
