# locomotivemtl/charcoal-contrib-property-filter

> 标签: charcoal, filter

## 简介

Charcoal service provider for a collection filtering widget that uses model properties as filters.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
