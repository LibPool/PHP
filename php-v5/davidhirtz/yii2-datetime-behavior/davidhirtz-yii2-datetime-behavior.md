# davidhirtz/yii2-datetime-behavior

> 标签: datetime, extension, yii2

## 简介

Initiates database date columns as DateTime PHP classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
