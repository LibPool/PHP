# davidhirtz/yii2-curl

> 标签:  curl, extension, restful, yii2

## 简介

Easy and nice cURL extension with RESTful support for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
