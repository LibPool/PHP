# danog/php-rtc-srtp

> 标签: srtp

## 简介

Pure-PHP SRTP and SRTCP encryption using phpseclib, with AES-CM and AES-GCM profiles. MadelineProto's PHP 8.2+ fork removes the libsrtp/FFI dependency.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
