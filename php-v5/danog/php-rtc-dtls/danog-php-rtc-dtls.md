# danog/php-rtc-dtls

> 标签: certificate, crypto, dtls, openssl, privateKey, rtp, ssl, x509

## 简介

Pure-PHP DTLS 1.2 for WebRTC, powered by phpseclib and Amp v3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
