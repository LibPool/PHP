# elmatella/simple-facebook-laravel-sdk

> 标签: PHP

## 简介

A simple Package to use the PHP Facebook SDK into your Laravel application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
