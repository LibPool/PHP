# budimanlai/yii2-pkg

> 标签: PHP

## 简介

Yii2 extension package berisi kumpulan helper, storage driver, trait, dan base class yang dapat digunakan kembali di berbagai project Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
