# stratease/salesforcery

> 标签: client, database, model, orm, php, rest, salesforce

## 简介

A PHP Salesforce ORM, inspired by Eloquent's API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
