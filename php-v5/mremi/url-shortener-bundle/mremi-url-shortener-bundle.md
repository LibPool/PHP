# mremi/url-shortener-bundle

> 标签: Symfony2, api, shortener, symfony3, url

## 简介

Implementation of UrlShortener library for Symfony2/Symfony3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
