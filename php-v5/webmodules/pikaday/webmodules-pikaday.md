# webmodules/pikaday

> 标签: calendar, date, datepicker

## 简介

A refreshing JavaScript Datepicker — lightweight, no dependencies, modular CSS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
