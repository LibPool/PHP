# webmodules/webcomponentsjs

> 标签: api, rudra

## 简介

A suite of polyfills supporting the HTML Web Components specs: http://webcomponents.org/polyfills/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
