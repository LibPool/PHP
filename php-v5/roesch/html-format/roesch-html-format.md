# roesch/html-format

> 标签: format, html, tidy

## 简介

A simple to use HTML prettifier class written in PHP. Added as a composer library in memory of Bennett Roesch (spyrosoft)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
