# qbus/ivm-pro-client-contao-manager-plugin

> 标签: PHP

## 简介

Provides the qbus/ivm-pro-client-bundle for the Contao Manager Plugin to enable the bundle automatically

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
