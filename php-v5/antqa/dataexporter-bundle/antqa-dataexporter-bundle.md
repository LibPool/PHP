# antqa/dataexporter-bundle

> 标签: csv, exporter, json, xls, xml

## 简介

Easy export data to CSV, XML, HTML, JSON or XLS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
