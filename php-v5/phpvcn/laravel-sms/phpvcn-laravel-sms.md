# phpvcn/laravel-sms

> 标签: LuoSiMao, laravel, send, sms, text messages

## 简介

Laravel SMS 是为 Laravel 提供国内发送短信服务的支持包

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
