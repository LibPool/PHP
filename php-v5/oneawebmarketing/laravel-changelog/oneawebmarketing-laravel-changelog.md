# oneawebmarketing/laravel-changelog

> 标签: PHP

## 简介

This package supplies 2 helper functions for getting the changelog app version and the changelog as html

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
