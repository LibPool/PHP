# disrex/stylesmuggler-adobe-patches-mageos

> 标签: apsb26-146, cve-2026-75650, mage-os, magento, patch, security, stylesmuggler

## 简介

Adobe's official APSB26-146 (CVE-2026-75650) fix for Mage-OS stores on the Magento 2.4.9 equivalent line, via cweagans/composer-patches. Patch content is Adobe's, not MIT.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
