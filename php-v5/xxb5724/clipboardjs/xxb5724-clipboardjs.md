# xxb5724/clipboardjs

> 标签: clipboardjs, code language, flarum

## 简介

Add a modern approach to copy code to clipboard with code language display.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
