# scan/kss-php

> 标签: css documentation, kss, styleguide

## 简介

A PHP implementation of KSS: a methodology for documenting CSS and generating styleguides

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
