# blueways/bw-cache-uri

> 标签: atom, crawler, dom, feeds, parser, rss, typo3, xml

## 简介

TYPO3 extension to parse remote content and save to tt_content element

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
