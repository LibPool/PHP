# blueways/bw-covid-numbers

> 标签: chart, corona, covid-19, typo3

## 简介

TYPO3 extension for showing COVID-19 numbers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
