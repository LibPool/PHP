# tavy315/composer-cleanup-plugin

> 标签: PHP

## 简介

A composer cleanup plugin, to remove tests and documentation to save space based on barryvdh/composer-cleanup-plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
