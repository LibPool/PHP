# seymenkonuk/framework

> 标签: PHP

## 简介

Modern PHP uygulamaları için geliştirilmiş hafif, sade ve genişletilebilir bir framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
