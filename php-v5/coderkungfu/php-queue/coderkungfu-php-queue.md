# coderkungfu/php-queue

> 标签: queue, transaction

## 简介

A unified front-end for different queuing backends. Includes a REST server, CLI interface and daemon runners.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
