# oro/calendar-bundle

> 标签: ORO, OroCrm, OroPlatform, calendar

## 简介

Calendar bundle for OroPlatform-based applications.See https://doc.oroinc.com/user/back-office/activities/calendar-events/ for more information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
