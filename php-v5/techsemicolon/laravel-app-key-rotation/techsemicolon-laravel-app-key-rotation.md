# techsemicolon/laravel-app-key-rotation

> 标签: PHP

## 简介

A helper library to re-encrypt the existing encrypted data when you rotate your Laravel APP_KEY

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
