# huoxin/user-handles

> 标签: extension, flarum, handles, identity, name, nickname, username

## 简介

Display @username handles alongside nicknames across the forum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
