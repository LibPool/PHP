# alairock/quip-test

> 标签: PHP

## 简介

An Implementation of the multi-armed bandit test. (See: http://stevehanov.ca/blog/index.php?id=132)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
