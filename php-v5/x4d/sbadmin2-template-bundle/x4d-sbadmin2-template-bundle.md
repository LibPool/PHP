# x4d/sbadmin2-template-bundle

> 标签: admin, template

## 简介

Symfony2 Bundle for Start Bootstrap SB Admin 2 Template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
