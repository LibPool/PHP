# dev-nanny/composer-plugin

> 标签: composer, composer-plugin, plugin, quality-assurance

## 简介

Add dev-nanny to any PHP based project using Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
