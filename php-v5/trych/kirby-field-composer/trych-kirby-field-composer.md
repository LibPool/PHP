# trych/kirby-field-composer

> 标签: content-fields, field, field-methods, helper-functions, kirby, kirby-cms, kirby-plugin, method-chaining, php, plugin, strings, templating

## 简介

Kirby plugin providing methods to intelligently handle field values to compose complex strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
