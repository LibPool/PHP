# flairlabs/magpie-php-sdk

> 标签: magpie

## 简介

Magpie PHP SDK to allow developers to connect to Magpie REST APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
