# brightzone/gremlin-php

> 标签: driver, gremlin, gremlin-server, rexpro, rexpro-php

## 简介

gremlin-server client for php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
