# pixelpinplugins/pixelpin-auth

> 标签: pixelpin, zf2

## 简介

Uses the HybridAuth PHP library to Enable authentication via PixelPin!, etc for the ZfcUserPixelpin ZF2 module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
