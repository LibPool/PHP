# fridzema/cdn-prefixer

> 标签: asset, cdn, laravel, prefixer

## 简介

Little optional cdn url prefixer, can be used as an replacement for the default asset helper

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
