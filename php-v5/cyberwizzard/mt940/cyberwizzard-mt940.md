# cyberwizzard/mt940

> 标签: mt940, parser, parsing

## 简介

Addon for the MT940 bank statement parser to add Rabobank CSV support using PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
