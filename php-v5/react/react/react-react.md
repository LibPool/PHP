# react/react

> 标签: asynchronous, reactor, reactphp, 事件驱动, 异步

## 简介

ReactPHP: Event-driven, non-blocking I/O with PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
