# react/promise-timer

> 标签: async, event-loop, promise, reactphp, timeout, timer

## 简介

A trivial implementation of timeouts for Promises, built on top of ReactPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
