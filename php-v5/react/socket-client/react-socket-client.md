# react/socket-client

> 标签: Connection, Socket, async, reactphp, stream

## 简介

Async, streaming plaintext TCP/IP and secure TLS based connections for ReactPHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
