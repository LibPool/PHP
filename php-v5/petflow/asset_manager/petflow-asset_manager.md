# petflow/asset_manager

> 标签: Sprockets, coffeescript, less, sass

## 简介

Compiles Less, Sass, SCSS and CoffeeScript into CSS/JS and concatenates and minifies files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
