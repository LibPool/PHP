# fafiebig/faf-optim

> 标签: imageoptim, optimization, optipng, plugin, wordpress

## 简介

Wordpress Plugin for Image Optimization based on ImageOptim and OptiPNG

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
