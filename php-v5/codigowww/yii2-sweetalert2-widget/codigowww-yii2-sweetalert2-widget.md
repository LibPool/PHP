# codigowww/yii2-sweetalert2-widget

> 标签: Dominus77, extension, sweetalert2, widget, yii2

## 简介

Renders a SweetAlert2 widget for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
