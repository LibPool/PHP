# butopea/vue-storefront-opencart-vsbridge

> 标签: opencart, vsbridge, vue-storefront

## 简介

Vue Storefront Connector Extension for OpenCart

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
