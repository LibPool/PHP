# dhannyjsb/tad-php

> 标签: ZK, attendance, tad, time

## 简介

PHP class that allows you interact with ZK Time & Attendance devices.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
