## 简介

Supplementary, Easily Interchangeable Data Structures for PHP 5. Provides alternatives and supplements to the Standard PHP Library (SPL) Datastructures.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
