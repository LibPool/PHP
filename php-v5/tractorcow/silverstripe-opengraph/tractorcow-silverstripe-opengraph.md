# tractorcow/silverstripe-opengraph

> 标签: facebook, opengraph, silverstripe

## 简介

Implementation of the Facebook Open Graph protocol for SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
