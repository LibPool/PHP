# contao-dms/bundle-all

> 标签: bundle, contao, dms, document, files, management, metapackage

## 简介

Installs the Contao DMS and all available additional components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
