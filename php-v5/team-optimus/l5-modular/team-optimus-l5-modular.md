# team-optimus/l5-modular

> 标签: easy-command, l5-modular, laravel, module-generator, stub

## 简介

A laravel package to create a better house keeping of modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
