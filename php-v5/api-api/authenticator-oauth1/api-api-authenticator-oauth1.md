# api-api/authenticator-oauth1

> 标签: api-api, authenticator, authenticator-oauth1

## 简介

Authenticator implementation for OAuth 1.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
