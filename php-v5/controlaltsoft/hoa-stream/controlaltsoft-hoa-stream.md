# controlaltsoft/hoa-stream

> 标签: Context, bucket, composite, filter, in, library, out, protocol, stream, wrapper

## 简介

A fork of the Hoa\Stream library for adding php8 support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
