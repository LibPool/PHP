# bold-commerce/module-checkout-self-hosted

> 标签: PHP

## 简介

Provides a self-hosted checkout experience for the Bold Checkout extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
