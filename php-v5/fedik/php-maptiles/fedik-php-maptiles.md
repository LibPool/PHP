# fedik/php-maptiles

> 标签: convert image to map, map from image, map tile, map tile generator, php map generator, php map tiles, php tile generator

## 简介

Simple Map Tiles Generator. Allow to make a Map Tiles with PHP and Imagick.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
