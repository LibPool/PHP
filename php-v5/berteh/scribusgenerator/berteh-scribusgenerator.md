# berteh/scribusgenerator

> 标签: PHP

## 简介

Create beautiful documents with data - Open source pdf (and Scribus) template and mail-merge alternative

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
