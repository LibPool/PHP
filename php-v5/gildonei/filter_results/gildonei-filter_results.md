# gildonei/filter_results

> 标签: cakephp, filter, filter_results, php, results

## 简介

CakePHP Plugin to add PRG filters to controllers and views

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
