# omgdef/yii2-unisender-mailer

> 标签:  mailer,  unisender, extension, yii2

## 简介

This extension implements MailerInterface for sending emails via UniSender

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
