# flarum-lang/lithuanian

> 标签: Lithuanian, extension, flarum, locale, translation

## 简介

Lithuanian language extension pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
