# flarum-lang/albanian

> 标签: albanian, albanian-locale, flarum, flarum-locale, locale, sq-locale

## 简介

Albanian language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
