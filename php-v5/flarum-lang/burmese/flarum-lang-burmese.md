# flarum-lang/burmese

> 标签: burmese, burmese-locale, flarum, flarum-locale, locale, my-locale

## 简介

Burmese language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
