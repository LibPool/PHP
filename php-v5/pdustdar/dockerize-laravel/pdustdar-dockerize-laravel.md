# pdustdar/dockerize-laravel

> 标签: deploy, docker, framework, laravel

## 简介

Deploy Dockerized Laravel Framework With Nginx.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
