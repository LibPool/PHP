# cino/macos-phpswitch

> 标签: laravel, macos, php, php-switch, switch, valet

## 简介

Easily switch between php version MacOS when using Laravel Valet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
