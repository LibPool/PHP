# kmj/toolkitbundle

> 标签: KMJ, toolkit

## 简介

Symfony2 Bundle that adds basic user account entity and city/state/country setup as well

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
