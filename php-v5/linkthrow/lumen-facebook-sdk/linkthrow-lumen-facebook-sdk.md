# linkthrow/lumen-facebook-sdk

> 标签: facebook, facebook query builder, facebook sdk v4, lumen, sdk

## 简介

Fully unit tested Lumen Facebook SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
