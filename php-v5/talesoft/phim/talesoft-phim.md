# talesoft/phim

> 标签: CIEDE2000, cie, color, gd, hsl, hsv, image, imagick, lab, manipulation, processing

## 简介

An image and color manipulation and processing library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
