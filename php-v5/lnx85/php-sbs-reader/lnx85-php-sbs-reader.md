# lnx85/php-sbs-reader

> 标签: 1090mhz, base station, sbs-1

## 简介

A PHP library that implements SBS-1 BaseStation protocol

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
