# rygilles/laravel-openapi-schema-generator

> 标签: laravel, openapi, schema

## 简介

Generate OpenAPI schema from your Laravel Api project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
