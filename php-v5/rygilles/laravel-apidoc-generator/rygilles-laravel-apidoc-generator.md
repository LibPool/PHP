# rygilles/laravel-apidoc-generator

> 标签: PHP

## 简介

Laravel API documentation generator, based on mpociot lib with Passport integration and user UUID

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
