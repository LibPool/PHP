# checkdomain/comodo-bundle

> 标签: bundle, comodo, symfony

## 简介

Checkdomain/ComodoBundle a service to the comodo util class, to communicate with the comodo SSL Api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
