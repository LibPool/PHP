# checkdomain/comodo

> 标签: comodo, ssl

## 简介

Checkdomain/Comodo provides functions to communicate with the comodo SSL certificate provider

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
