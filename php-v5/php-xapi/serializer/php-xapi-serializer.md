# php-xapi/serializer

> 标签: Experience API, Tin Can API, serializer, xAPI

## 简介

transform Experience API model objects to JSON strings and vice versa

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
