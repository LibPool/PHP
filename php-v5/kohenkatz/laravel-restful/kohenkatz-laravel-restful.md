# kohenkatz/laravel-restful

> 标签: controller, laravel, rest, restful, routing

## 简介

Create your own REST API in Laravel. Supports JSON, JSONP, and XML output.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
