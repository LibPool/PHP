# kinglozzer/htmleditorscripts

> 标签: htmleditorfield, javascript, script, silverstripe, tags

## 简介

Enable <script> tags in SilverStripe’s HtmlEditorField

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
