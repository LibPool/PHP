# dragonzap/openai-chatgpt-assistant

> 标签: PHP

## 简介

Provides clean abstraction for the chatgpt assistant API. Build and run assistants with a clean easy to use design

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
