# janit/typescript-generator-bundle

> 标签: PHP

## 简介

A Symfony Bundle that provides a command to generate TypeScript interfaces from PHP classes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
