# drunomics/behat-drupal-smoke

> 标签: Behat, drupal, logintest, smoke, smoketest

## 简介

Provides utilities for running smoke tests and various useful behat contexts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
