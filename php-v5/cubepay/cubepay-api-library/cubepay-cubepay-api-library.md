# cubepay/cubepay-api-library

> 标签: api, cryptocurrency, cubepay, payment

## 简介

CubePay API library for PHP, a third-party cryptocurrency payment gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
