# phix/autoloader

> 标签: autoloader, phix

## 简介

Phix's Autoloader is a PSR0-compliant autoloader which supports PHP's include_path

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
