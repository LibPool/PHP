# phix/consoledisplaylib

> 标签: ansi color, console, output, wordwrap

## 简介

ConsoleDisplayLib is a simple library for CLI apps to output to the console

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
