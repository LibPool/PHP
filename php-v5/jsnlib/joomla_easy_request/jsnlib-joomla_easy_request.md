# jsnlib/joomla_easy_request

> 标签: easy, get, joomla, post

## 简介

Joomla! 中使用 POST 或 GET 更簡單

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
