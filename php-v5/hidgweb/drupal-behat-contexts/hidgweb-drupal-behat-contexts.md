# hidgweb/drupal-behat-contexts

> 标签: Behat, contexts, drupal

## 简介

Provides additional step definitions for testing Drupal sites using the Behat Drupal Extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
