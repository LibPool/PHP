# bbaga/buildkite-php-guzzle-client

> 标签: PHP

## 简介

PSR-18 Wrapper for Guzzle to be used with bbaga/buildkite-php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
