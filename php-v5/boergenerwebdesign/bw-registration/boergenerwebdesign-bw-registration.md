# boergenerwebdesign/bw-registration

> 标签: PHP

## 简介

Stellt eine Maske zur Registrierung für Veranstaltungen bereit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
