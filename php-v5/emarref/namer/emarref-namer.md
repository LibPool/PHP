# emarref/namer

> 标签: namer, naming

## 简介

A simple library for determining whether or not a given name is available for use, and generating a new name based on a strategy if it is not.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
