# mortenscheel/laravel-ide-helper-plus

> 标签: Doc-blocks, automation, ide-helper, laravel

## 简介

An automation extension for barryvdh/laravel-ide-helper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
