# malkusch/bav

> 标签: Bank, account, bankaccount, check, konto, validation

## 简介

BAV provides validation for German Bank Accounts (Konto)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
