# linelab-studio/country-provider

> 标签: country, country privider, locale privider, php

## 简介

Udostępnia obiekt country na podstawie kodu iso lub nagłówka locale. ZF2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
