# lafayettecollege/moodle-block_clampmail

> 标签: PHP

## 简介

CLAMPMail is a Moodle block that provides selective, bulk emailing within courses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
