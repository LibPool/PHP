# lafayettecollege/moodle-report_roster

> 标签: PHP

## 简介

This is a simple report which displays the user pictures for everyone enrolled in the given course.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
