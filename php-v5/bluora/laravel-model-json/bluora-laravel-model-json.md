# bluora/laravel-model-json

> 标签: eloquent, illuminate, json, laravel, schema-free, schemaless

## 简介

Provides JSON column support for for Laravel's Eloquent Model.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
