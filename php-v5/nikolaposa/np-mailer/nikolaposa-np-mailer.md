# nikolaposa/np-mailer

> 标签: email, mail, mailer, module, zend, zf2

## 简介

ZF2 Module which facilitates and simplifies sending of email messages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
