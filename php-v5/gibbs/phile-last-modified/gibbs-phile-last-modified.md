# gibbs/phile-last-modified

> 标签: cms, modified, phile, philecms, updated

## 简介

A simple philecms plugin that returns the Unix timestamp of the page (file)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
