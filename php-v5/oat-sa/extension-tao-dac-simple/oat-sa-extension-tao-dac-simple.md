# oat-sa/extension-tao-dac-simple

> 标签: TAO, computer-based-assessment

## 简介

extension that allows admin to give access to some resources to other people

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
