# oat-sa/lib-test-cat

> 标签: OAT, TAO, computer-based-assessment

## 简介

Library to connect the taoTests engine to a computer adaptive test

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
