# oat-sa/extension-tao-devtools

> 标签: OAT, QTI, TAO, computer-based-assessment

## 简介

Extension that gathers development tools for TAO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
