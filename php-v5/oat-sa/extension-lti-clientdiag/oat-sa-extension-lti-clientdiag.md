# oat-sa/extension-lti-clientdiag

> 标签: TAO, computer-based-assessment

## 简介

Grants access to the client diagnostic functionalities using LTI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
