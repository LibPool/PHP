# oat-sa/extension-tao-datauri

> 标签: TAO, computer-based-assessment

## 简介

An extension providing the necessary tools to create DataURIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
