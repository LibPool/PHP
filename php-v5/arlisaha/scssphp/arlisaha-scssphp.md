# arlisaha/scssphp

> 标签: css, less, sass, scss, stylesheet

## 简介

Fork from Leafo SCSS PHP compiler (see homepage).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
