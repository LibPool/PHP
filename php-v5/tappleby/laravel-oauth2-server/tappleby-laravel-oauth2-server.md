# tappleby/laravel-oauth2-server

> 标签: PHP

## 简介

Wrapper around bshaffer/oauth2-server-php library for use with Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
