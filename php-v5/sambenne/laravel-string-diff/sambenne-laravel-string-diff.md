# sambenne/laravel-string-diff

> 标签: diff, iamkate, laravel

## 简介

A laravel friendly wrapper around iamkate diff implementation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
