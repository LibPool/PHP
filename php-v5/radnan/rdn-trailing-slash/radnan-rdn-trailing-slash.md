# radnan/rdn-trailing-slash

> 标签: redirect, slash, trailing, zend, zf2, zf3

## 简介

Zend Framework module to trim trailing slashes from requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
