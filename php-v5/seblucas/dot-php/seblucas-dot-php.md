# seblucas/dot-php

> 标签: Rendering, dot, engine, template

## 简介

PHP rendering engine for doT.js (The fastest + concise javascript template engine for nodejs and browsers)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
