# justustheis/registry

> 标签: Settings, caching, config-management, configuration, dot-access, dynamic-config, encryption, frontend-settings, inertia, key-value-store, laravel, registry, scoping, settings-ui, tenant-settings, vue

## 简介

Flexible key–value store for Laravel with model scoping, encryption, caching, and runtime config overrides.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
