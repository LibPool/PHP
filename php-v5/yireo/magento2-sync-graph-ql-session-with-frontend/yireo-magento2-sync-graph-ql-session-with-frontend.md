# yireo/magento2-sync-graph-ql-session-with-frontend

> 标签: composer-installer, magento

## 简介

Magento 2 module to sync a GraphQL session with the regular session

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
