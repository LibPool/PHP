# yireo/magento2-disable-service-worker-in-admin

> 标签: composer-installer, magento

## 简介

Disable ServiceWorkers when entering the Magento 2 backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
