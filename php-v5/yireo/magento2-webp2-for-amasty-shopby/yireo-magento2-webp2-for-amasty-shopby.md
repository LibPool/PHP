# yireo/magento2-webp2-for-amasty-shopby

> 标签: PHP

## 简介

Magento 2 add-on to make Yireo_Webp2 work with Amasty_Shopby

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
