# larapack/attribute-manipulation

> 标签: larapack, laravel, package

## 简介

Allows multiple traits to manipulate with the attributes of an Eloquent Model.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
