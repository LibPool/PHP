# pili-engineering/pili-sdk-php

> 标签: cloud, dash, hdl, hds, hls, pili, qiniu, rtmp, streaming, web-service

## 简介

Pili Streaming Cloud server-side library for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
