# redpilllinpro/sugarcrm-bundle

> 标签: symfony rest sugarcrm

## 简介

Bundle for simple access to the REST API of Sugar CRM 7 and up.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
