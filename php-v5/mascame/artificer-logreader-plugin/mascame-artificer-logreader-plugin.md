# mascame/artificer-logreader-plugin

> 标签: artificer, laravel, log, plugin

## 简介

Log Reader plugin. Let you see and search logs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
