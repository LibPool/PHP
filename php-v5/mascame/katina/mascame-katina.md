# mascame/katina

> 标签: PHP

## 简介

Test helper class that validates any kind of output based on the rules passed. Useful to test API reponses or data that changes over time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
