# catcoder/agent

> 标签: Agent, browser, laravel, mobile, platform, user agent, useragent

## 简介

A PHP desktop/mobile user agent parser with support for Laravel, based on Mobiledetect

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
