# wcm/git-php-hooks

> 标签: git, git hook, hooks, php

## 简介

Write git hooks with PHP, organize them on a per-project base and automatically add them

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
