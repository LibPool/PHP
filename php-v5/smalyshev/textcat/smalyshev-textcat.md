# smalyshev/textcat

> 标签: PHP

## 简介

PHP port of the TextCat language guesser utility, see http://odur.let.rug.nl/~vannoord/TextCat/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
