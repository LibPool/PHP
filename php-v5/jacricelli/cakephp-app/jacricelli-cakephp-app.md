# jacricelli/cakephp-app

> 标签: cakephp, cakephp-app, cakephp-skeleton, cakephp-template, php

## 简介

Plantilla de aplicación para proyectos de CakePHP 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
