# afaanbilal/laravel-has-uuid

> 标签: PHP

## 简介

Autogenerate UUIDs for your Models on insert and set the route-model-binding key to uuid.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
