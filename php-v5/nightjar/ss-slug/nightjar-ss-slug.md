# nightjar/ss-slug

> 标签: extension, silverstripe, slug

## 简介

Serve DataObjects as pages through an Action on a relation's Controller without referencing the ID

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
