# dcsg/mailchimp-api-connector-bundle

> 标签: mailchimp

## 简介

Symfony2 bundle to integrate Mailchimp Api Connector

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
