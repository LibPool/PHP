# francescogabbrielli/aws-ses-wrapper

> 标签: aws-ses, bulk-email, email, email-templates

## 简介

An utility for wrapping Aws SesClient Api (part of AWS SDK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
