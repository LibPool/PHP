# rothkj1022/php-xss-sanitizer

> 标签: PHP

## 简介

PHP XSS Sanitizer uses HTMLPurifier to recursively clean up get, post, and files arrays to protect your application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
