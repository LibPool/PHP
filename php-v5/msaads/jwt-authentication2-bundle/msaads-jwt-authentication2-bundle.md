# msaads/jwt-authentication2-bundle

> 标签: Authentication, JWS, api, bundle, jwt, rest, symfony

## 简介

This bundle provides JWT authentication for my Symfony REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
