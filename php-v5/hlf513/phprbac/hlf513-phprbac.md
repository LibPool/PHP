# hlf513/phprbac

> 标签: owasp, permission, rbac, security

## 简介

OWASP/phprbac的修改版。修复了一些bug,并对数据库配置的获取做了调整

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
