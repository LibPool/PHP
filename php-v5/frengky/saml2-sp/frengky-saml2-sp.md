# frengky/saml2-sp

> 标签: SAML2, SSO, adfs, laravel, php, saml

## 简介

Laravel package for a SAML2 SSO service provider (SP)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
