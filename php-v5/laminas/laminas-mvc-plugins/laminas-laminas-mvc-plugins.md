# laminas/laminas-mvc-plugins

> 标签: laminas, mvc, plugins

## 简介

Collection of all stable laminas-mvc plugins served via separate packages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
