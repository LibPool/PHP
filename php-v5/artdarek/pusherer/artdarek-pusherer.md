# artdarek/pusherer

> 标签: Laravel 4, Pusher.com, laravel, laravel4, notifications, pusher, realtime

## 简介

Pusher.com service provider for Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
