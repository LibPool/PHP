# faparicior/far-symfony2-jquery-upload

> 标签: Bundle JqueryUpload FlySystem Symfony2

## 简介

Integrates JqueryUpload into Symfony2 with OneUpFlySystem

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
