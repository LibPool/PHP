# heybigname/backup-manager

> 标签: PHP

## 简介

Database backup manager for dumping to and restoring databases from S3, Dropbox, FTP, and SFTP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
