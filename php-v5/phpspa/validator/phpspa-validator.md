# phpspa/validator

> 标签: php, phpspa, phpspa-validator, validator

## 简介

Attribute-based request validator for PhpSPA and other PHP libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
