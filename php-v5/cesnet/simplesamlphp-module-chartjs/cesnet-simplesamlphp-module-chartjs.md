# cesnet/simplesamlphp-module-chartjs

> 标签: chartjs, javascript, simplesamlphp

## 简介

A SimpleSAMLphp module that includes the Chart.js Javascript library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
