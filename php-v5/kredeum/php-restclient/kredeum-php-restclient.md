# kredeum/php-restclient

> 标签: api, client, curl, json, multipart, rest, xml

## 简介

A generic REST API client for PHP with multipart capabilities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
