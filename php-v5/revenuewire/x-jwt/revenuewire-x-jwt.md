# revenuewire/x-jwt

> 标签: PHP

## 简介

Inspired by JWT protocol, X-JWT is designed to use AWS KMS to securly encrypt and decrypt data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
