# pensoft/psr3-bridge

> 标签: acl, casbin, logger, permission, psr-3, rbac

## 简介

This library provides a PSR-3 compliant bridge for Casbin Logger.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
