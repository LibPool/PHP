# theposeidonas/laravel-emoji-parser

> 标签: emoji, laravel, parser

## 简介

A Laravel package for handling emoji expressions in blade files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
