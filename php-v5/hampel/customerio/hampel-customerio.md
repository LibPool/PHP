# hampel/customerio

> 标签: Guzzle, api, automation, customer.io, drip, email, marketing

## 简介

Wrapper for the Customer.io REST API using Guzzle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
