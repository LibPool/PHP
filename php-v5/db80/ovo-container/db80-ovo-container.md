# db80/ovo-container

> 标签: container, dependency injection, ioc

## 简介

A lightweight Dependency Injection / Inversion of control Framework for PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
