# bb24/dashboardtransmitter

> 标签: PHP

## 简介

Package zum Erkennen und senden von Fehlern, requests etc. an das Dashboard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
