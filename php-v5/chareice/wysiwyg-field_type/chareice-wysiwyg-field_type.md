# chareice/wysiwyg-field_type

> 标签: field type, streams addon, streams field type

## 简介

A WYSIWYG editor field type powered by RedactorJS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
