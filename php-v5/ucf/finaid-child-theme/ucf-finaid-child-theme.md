# ucf/finaid-child-theme

> 标签: PHP

## 简介

WordPress theme for the UCF Office of Student Financial Assistance website.  Built as a child theme of the UCF WordPress Theme, using the Athena Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
