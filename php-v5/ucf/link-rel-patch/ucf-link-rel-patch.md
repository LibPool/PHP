# ucf/link-rel-patch

> 标签: PHP

## 简介

Removes the noreferrer rel value that is added to links set to open in a new tab on post update or publish.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
