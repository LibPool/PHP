# ucf/ucf-vertical-slide-plugin

> 标签: PHP

## 简介

Vertical slide plugin retrieves data, including image URL, title, subtitle, and description, from ACF Pro. Users can change slides by scrolling the mouse wheel on desktops or by touching on mobile phones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
