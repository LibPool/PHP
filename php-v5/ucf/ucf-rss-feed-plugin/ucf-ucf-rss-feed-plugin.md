# ucf/ucf-rss-feed-plugin

> 标签: PHP

## 简介

Provides a shortcode and default styles for displaying RSS feeds within post content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
