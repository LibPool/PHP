# developerhub/php-testcase

> 标签: PHP

## 简介

PHPUnit testing tool for PHP. Support >= PHPUnit3.6 and SeleniumRC 2, Webdriver.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
