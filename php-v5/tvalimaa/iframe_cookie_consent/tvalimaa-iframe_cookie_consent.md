# tvalimaa/iframe_cookie_consent

> 标签: PHP

## 简介

Adds Ckeditor plugin which converts Youtube iframe embeds to support cookie consent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
