# jdsdev/craft-recentlyupdated

> 标签: Craft, cms, craft-plugin, craftcms

## 简介

Add a Craft dashboard widget to show recently updated entries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
