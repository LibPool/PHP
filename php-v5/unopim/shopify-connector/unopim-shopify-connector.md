# unopim/shopify-connector

> 标签: PHP

## 简介

A Shopify integration package for Unopim, enabling seamless product data synchronization between Unopim and Shopify.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
