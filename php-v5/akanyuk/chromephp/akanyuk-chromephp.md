# akanyuk/chromephp

> 标签: log, logging

## 简介

Fork of ccampbell/chromephp with PHP >=8.2 supported. Log variables to the Chrome console (via Chrome Logger Google Chrome extension).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
