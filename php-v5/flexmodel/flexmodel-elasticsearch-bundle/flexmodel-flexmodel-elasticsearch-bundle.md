# flexmodel/flexmodel-elasticsearch-bundle

> 标签: PHP

## 简介

FlexModel-based Elasticsearch integration for Symfony 3+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
