# bentools/arraytools

> 标签: array, associative array, flatten array, indexed array, multidimensionnal arrays, sort array

## 简介

Some extra functions to work with arrays.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
