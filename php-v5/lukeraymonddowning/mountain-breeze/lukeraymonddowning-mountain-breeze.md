# lukeraymonddowning/mountain-breeze

> 标签: PHP

## 简介

A Wordpress theme implementing Tailwind CSS and Alpine JS, and removing jQuery once and for all.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
