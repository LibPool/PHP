# minimalic/silverstripe-sitetools

> 标签: silverstripe, siteconfig

## 简介

SiteTools extension for custom 'siteconfig' fields in Silverstripe CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
