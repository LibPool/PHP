# slimore/slimore

> 标签: hmvc, microframework, mvc, rest, restful, router

## 简介

Slimore: Fully (H)MVC for Slim PHP Framwork.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
