# tidycode/ai-php-sdk

> 标签: PHP

## 简介

Tidycode AI PHP SDK is a PHP API client that allows you to integrate artificial intelligence services deployed by Tidycode.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
