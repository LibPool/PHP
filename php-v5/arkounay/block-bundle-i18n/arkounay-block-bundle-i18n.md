# arkounay/block-bundle-i18n

> 标签: bundle, inline, symfony, tinymce, wysiwig

## 简介

WYSIWIG HTML editable blocks and entities bundle (multilingual version)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
