# cyzonetech/think-glide

> 标签: glide, think-glide, thinkphp, thinkphp-glide

## 简介

ThinkPHP adapter for using Glide image manipulation library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
