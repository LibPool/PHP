# pointybeard/shell-args

> 标签: argc, arguments, argv, command line, shell

## 简介

A simple interface for processing arguments passed on the command line to PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
