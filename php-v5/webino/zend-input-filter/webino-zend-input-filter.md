# webino/zend-input-filter

> 标签: ZendFramework, inputfilter, zf

## 简介

Normalize and validate input sets from the web, APIs, the CLI, and more, including files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
