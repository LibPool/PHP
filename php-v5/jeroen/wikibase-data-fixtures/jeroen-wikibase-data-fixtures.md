# jeroen/wikibase-data-fixtures

> 标签: fixtures, wikibase

## 简介

Fixtures for Wikibase data that can be used in tests or examples

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
