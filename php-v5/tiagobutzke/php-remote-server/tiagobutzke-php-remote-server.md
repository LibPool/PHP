# tiagobutzke/php-remote-server

> 标签: connect, remote server, run command, ssh, telnet

## 简介

Library to connect and manage remote servers via PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
