# konekt/payum-otp-hungary

> 标签: SimplePay, otp, payment, payum, sylius, symfony

## 简介

Custom Payum Gateway for SimplePay Hungary via Legacy OTP Bank integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
