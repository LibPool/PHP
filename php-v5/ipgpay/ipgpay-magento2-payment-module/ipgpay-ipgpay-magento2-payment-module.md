# ipgpay/ipgpay-magento2-payment-module

> 标签: gateway, ipgpay, magento2, payment

## 简介

IPGPAY payment gateway implementation for Magento2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
