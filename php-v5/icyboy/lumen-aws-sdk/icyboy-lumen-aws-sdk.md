# icyboy/lumen-aws-sdk

> 标签: amazon, aws, dynamodb, ec2, lumen, lumen 5, s3, sdk

## 简介

A simple lumen 5 service provider for including the AWS SDK for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
