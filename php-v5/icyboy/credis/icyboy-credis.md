# icyboy/credis

> 标签: PHP

## 简介

Credis is a lightweight interface to the Redis key-value store which wraps the phpredis library when available for better performance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
