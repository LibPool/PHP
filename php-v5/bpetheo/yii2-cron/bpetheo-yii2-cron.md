# bpetheo/yii2-cron

> 标签: cron, extension, yii2, yii2 cron, yii2cron

## 简介

Cron implementation for yii2 framework. Executes scheduled commands defined in yii config.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
