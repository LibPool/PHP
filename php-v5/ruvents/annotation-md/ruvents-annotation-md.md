# ruvents/annotation-md

> 标签: annotations, phpdoc, slate

## 简介

This library parses phpdoc annotations and generates md document that can be parsed by slate

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
