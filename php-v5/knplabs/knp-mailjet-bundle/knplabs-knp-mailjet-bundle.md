# knplabs/knp-mailjet-bundle

> 标签: Mailjet, api, bundle

## 简介

Symfony2 Bundle for initializing Mailjet PHP API wrapper and handling Event API callbacks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
