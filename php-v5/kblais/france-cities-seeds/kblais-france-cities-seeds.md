# kblais/france-cities-seeds

> 标签: PHP

## 简介

Extract the tree structure of French metropolitan regions, departments and cities from www.data.gouv.fr CSV

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
