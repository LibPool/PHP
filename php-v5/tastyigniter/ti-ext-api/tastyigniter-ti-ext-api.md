# tastyigniter/ti-ext-api

> 标签: api, rest, tastyigniter

## 简介

Manages and generates RESTful APIs using available models in your TastyIgniter app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
