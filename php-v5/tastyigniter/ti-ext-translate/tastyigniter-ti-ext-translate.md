# tastyigniter/ti-ext-translate

> 标签: PHP

## 简介

Allows multilingual websites with TastyIgniter, making it easy to translate menu items.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
