# kapxapot/plasticode-boilerplate

> 标签: Plasticode, api, boilerplate, bootstrap, php, slim, twig

## 简介

Boilerplate for the Plasticode framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
