# wkse/pathauto

> 标签: PHP

## 简介

Provides a generic set of views plugins a mechanism for modules to automatically generate aliases for the content they manage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
