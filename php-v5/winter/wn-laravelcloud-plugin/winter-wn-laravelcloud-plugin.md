# winter/wn-laravelcloud-plugin

> 标签: cloud, laravel, laravel cloud, plugin, wintercms

## 简介

Simple plugin to support running Winter CMS on Laravel Cloud

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
