# winter/wn-drivermsgraph-plugin

> 标签: MsGraph, driver, mail, wintercms

## 简介

Driver that adds support for MS GRAPH API mailer to WinterCMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
