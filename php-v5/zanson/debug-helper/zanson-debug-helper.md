# zanson/debug-helper

> 标签: PHP

## 简介

A utility to display PHP Errors and exceptions in a more readable way. Also adds a JS console.log style PHP output class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
