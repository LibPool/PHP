# mikk150/yii2-tagdependency-invalidator

> 标签: cache, extension, tagdependency, yii2

## 简介

Invalidates Yii2's TagDependency tags on model update/delete and insert

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
