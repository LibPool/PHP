# xcoreplatform/magento1-soapapi

> 标签: PHP

## 简介

This module extends the soap api of Magento1 and is needed for the usage of the xCore.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
