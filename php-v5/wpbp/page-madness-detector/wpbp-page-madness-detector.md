# wpbp/page-madness-detector

> 标签: visual builder, wordpress

## 简介

A WordPress library to detect if the website is using a pagebuilder/visual builder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
