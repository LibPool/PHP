# pixelcoda/typo3-storybook-fluid-api

> 标签: PHP

## 简介

TYPO3 extension that provides an API to render TYPO3 Fluid templates and partials through HTTP/HTTPS requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
