# faurelia/t2-simple-pagination

> 标签: PHP Pagination, pagination

## 简介

A simple PHP pagination (with Bootstrap 3 example)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
