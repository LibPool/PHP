# juho-jaakkola/elgg-notification_tools

> 标签: elgg, notifications, plugin

## 简介

Provides notification related tools for Elgg site administrations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
