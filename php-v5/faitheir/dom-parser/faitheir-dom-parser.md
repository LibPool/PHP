# faitheir/dom-parser

> 标签: dom, dom-tree, php-dom, php-library, reactjs, vue

## 简介

A PHP library , use to parse normal and special DOM string like vue react.  to DOM Tree .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
