# natanfelles/adminer-bootstrap-like

> 标签: adminer, bootstrap, database

## 简介

Adminer interface inspired by the Bootstrap Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
