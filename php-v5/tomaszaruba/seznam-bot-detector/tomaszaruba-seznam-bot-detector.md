# tomaszaruba/seznam-bot-detector

> 标签: PHP

## 简介

Detect Seznam.cz bot crawling websites. Detection for page crawler and thumbnail screening bot.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
