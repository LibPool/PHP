# dimabdc/yii2-simple_html_dom

> 标签: extension, html, parser, yii2

## 简介

Simple HTML DOM parser for Yii 2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
