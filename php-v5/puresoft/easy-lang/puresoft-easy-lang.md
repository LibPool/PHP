# puresoft/easy-lang

> 标签: easy, i18n, language, localization, multi-language, php, translate

## 简介

A simple PHP class for creating pages with multiple languages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
