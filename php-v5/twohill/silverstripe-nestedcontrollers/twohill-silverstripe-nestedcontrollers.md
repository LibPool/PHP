# twohill/silverstripe-nestedcontrollers

> 标签: crud, nested, silverstripe

## 简介

Base for easily setting up CRUD pages in the front end using nested controllers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
