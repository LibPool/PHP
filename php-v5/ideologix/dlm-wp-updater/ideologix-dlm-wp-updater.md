# ideologix/dlm-wp-updater

> 标签: PHP

## 简介

PHP WordPress updater for your plugins and themes that utilizes the Digital License Manager PRO REST APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
