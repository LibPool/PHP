# shabbir/guzzle-request-response-middleware-stack

> 标签: PHP

## 简介

This will create the client of guzzle and will use request and reponse middleware for logging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
