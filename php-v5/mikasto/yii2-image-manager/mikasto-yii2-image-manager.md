# mikasto/yii2-image-manager

> 标签: categories, category, collections, crop, extension, image, manager, module, tag, upload, widget, yii2

## 简介

A Yii2 module/widget for upload, cropping images, separating by tag, category

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
