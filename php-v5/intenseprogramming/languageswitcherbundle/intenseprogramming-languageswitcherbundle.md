# intenseprogramming/languageswitcherbundle

> 标签: PHP

## 简介

Intense Programming Language Switcher Bundle is an eZ Publish 5 bundle able to generate siteaccess-specific links from content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
