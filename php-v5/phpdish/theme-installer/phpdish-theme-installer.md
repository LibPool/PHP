# phpdish/theme-installer

> 标签: PHP

## 简介

A composer installer for installing PHPDish themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.phpdish.com
- 源码仓库：https://github.com/phpdish/theme-installer.git
- Packagist 页面：https://packagist.org/packages/phpdish%2Ftheme-installer
