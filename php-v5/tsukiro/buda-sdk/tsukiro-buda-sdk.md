# tsukiro/buda-sdk

> 标签: api, php, sdk, swagger

## 简介

Este proyecto tiene como finalidad generar un SDK en PHP para utilizar los endpoints del sitio Buda.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
