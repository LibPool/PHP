# get-stream/stream-zend

> 标签: activity, activity feed, aggregated feed, feed, feedly, getstream, newsfeed, notification feed, stream, zend, zf3

## 简介

Build newsfeeds and activity feeds with Zend Framework using getstream.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
