# masnathan/config4all

> 标签: config, json, neon, php, xml, yaml

## 简介

This class helps you load your application configs, it supports php, xml, ini and json files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
