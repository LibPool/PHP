# remic/guzzlecache

> 标签: Guzzle, api, cache, http, laravel5, lumen, proxy

## 简介

Laravel 5 package for caching Guzzle's GET requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
