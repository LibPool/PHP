# klevu/module-mysqlcompat

> 标签: PHP

## 简介

Klevu Search MySQL compatibility module from Magento 2.0 to Magento 2.3.x versions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
