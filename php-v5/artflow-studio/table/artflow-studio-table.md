# artflow-studio/table

> 标签: artflow, component, datatable, laravel, livewire, table

## 简介

A custom package to render Livewire components using the @AFtable directive.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
