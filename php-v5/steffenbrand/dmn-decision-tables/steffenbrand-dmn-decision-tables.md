# steffenbrand/dmn-decision-tables

> 标签: DMN, Decision Table, bpmn, camunda

## 简介

PHP library to programmatically create DMN decision tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
