# garoevans/php-enum

> 标签: enum, enumeration, php, splenum, type

## 简介

Convenient way to always have an Enum object available and utilise Spl Types if available.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
