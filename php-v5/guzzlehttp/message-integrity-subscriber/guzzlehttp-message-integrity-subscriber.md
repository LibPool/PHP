# guzzlehttp/message-integrity-subscriber

> 标签: Guzzle, http

## 简介

Verifies the integrity of HTTP responses using customizable validators (Guzzle 4+)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
