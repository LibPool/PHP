# marjose123/laravel-numberizer

> 标签: MarJose123, laravel, laravel-numberizer

## 简介

Laravel package to create autonumber for Eloquent model

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
