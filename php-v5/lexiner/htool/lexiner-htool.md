# lexiner/htool

> 标签: PHP

## 简介

一个工具库，功能很简单，封装了常用的函数、基础功能等。只为提高你的开发效率，多多陪家人。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
