# groton-school/slim-oauth2-api-proxy

> 标签: PHP

## 简介

Server-side actions and routes for authenticating to and accessing an REST API from a web client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
