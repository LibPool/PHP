# imagex/openedu-project-docksal

> 标签: PHP

## 简介

Project template for Drupal 8 sites built with the OpenEDU distribution and Docksal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
