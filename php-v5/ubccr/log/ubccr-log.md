# ubccr/log

> 标签: log, logging

## 简介

PEAR Logging Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://pear.github.io/Log/
- 源码仓库：https://github.com/ubccr/Log.git
- Packagist 页面：https://packagist.org/packages/ubccr%2Flog
