# wappr/logger

> 标签: Flysystem, GridFS, aws, azure, ftp, logger, psr, psr-3, s3, wappr

## 简介

A PSR-3 logger that uses Flysystem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
