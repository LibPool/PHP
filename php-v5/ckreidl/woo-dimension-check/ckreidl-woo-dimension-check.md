# ckreidl/woo-dimension-check

> 标签: PHP

## 简介

Checks WooCommerce product database via Woo's REST API to identify items that have no weight or dimensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
