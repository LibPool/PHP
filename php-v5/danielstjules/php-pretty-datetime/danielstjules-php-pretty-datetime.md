# danielstjules/php-pretty-datetime

> 标签: date, datetime, human, pretty, readable, string, time

## 简介

Generates human-readable strings for PHP DateTime objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
