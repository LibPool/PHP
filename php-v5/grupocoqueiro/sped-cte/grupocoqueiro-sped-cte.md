# grupocoqueiro/sped-cte

> 标签: cte, nfephp, sped

## 简介

API para geração e comunicação da CTe com as SEFAZ autorizadoras.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
