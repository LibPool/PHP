# coksnuss/yii2-gii-modelgen

> 标签: gii, model template, yii2

## 简介

A tweaked model generator for the Gii module of the Yii 2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
