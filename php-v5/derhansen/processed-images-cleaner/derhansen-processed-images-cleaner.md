# derhansen/processed-images-cleaner

> 标签: TYPO3 CMS, cleanup, images, processed

## 简介

Symfony console command to clean up processed images by several conditions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
