# t3s/newsslider

> 标签: TYPO3 CMS, news, newsslider, typo3

## 简介

Slider plugins for versatile news extension (tx_news).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
