# vardot/jquery.fancytree

> 标签: drupal, drupal-library, fancytree, jquery, tree

## 简介

Fancytree, a jQuery tree view plugin, packaged as a Drupal library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
