# vardot/swagger-ui

> 标签: api, documentation, drupal, drupal-library, openapi, swagger

## 简介

Swagger UI distribution build, packaged as a Drupal library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
