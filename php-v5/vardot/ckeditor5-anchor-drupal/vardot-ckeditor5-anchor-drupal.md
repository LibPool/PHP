# vardot/ckeditor5-anchor-drupal

> 标签: ckeditor5, drupal, plugin

## 简介

Anchor feature for CKEditor 5, adapted for Drupal

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
