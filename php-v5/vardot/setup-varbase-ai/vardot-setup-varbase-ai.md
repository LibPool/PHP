# vardot/setup-varbase-ai

> 标签: Setup Drupal AI, Varbase recipes, drupal recipe, drupal recipes, recipe, setup AI, varbase recipe

## 简介

A Drupal recipe to setup default Varbase AI installed modules, configs and permissions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
