# dlzer/mfp-php

> 标签: api, mfp, myfitnesspal, php, php-mfp, scraper, service

## 简介

PHP Libary for accessing MyFitnessPal diary data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
