# solo/assets

> 标签: asset, mincss, minify, minjs, solo framework

## 简介

Component for combining and compressing JavaScript and CSS files for Solo framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
