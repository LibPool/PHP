# bluemove/laravel-lumen-rollbar

> 标签: error, laravel, logging, monitoring, rollbar

## 简介

Rollbar error monitoring integration for Laravel projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
