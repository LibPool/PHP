# srag/jasperreport

> 标签: ILIAS, jasper, report

## 简介

This is an ILIAS wrapper for the JasperReport library. It allows ILIAS to print pretty PDF reports.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
