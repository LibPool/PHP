# spiffy/spiffy-assetic-module

> 标签: PHP

## 简介

Spiffy\AsseticModule is a module for Zend Framework to help manage assets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
