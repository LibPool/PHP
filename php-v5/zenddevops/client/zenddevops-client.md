# zenddevops/client

> 标签: api, cli, zend server, zf2

## 简介

ZF2 CLI tool to access Zend Server Web API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/zendtech/ZendServerSDK
- 源码仓库：https://github.com/zend-patterns/ZendServerSDK.git
- Packagist 页面：https://packagist.org/packages/zenddevops%2Fclient
