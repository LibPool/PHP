# filesite/dirscanner

> 标签: scandir, scanner

## 简介

Dir and file scanner, a PHP implement of filesite.io.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/filesite-io/dirscanner.git
