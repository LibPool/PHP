# double-star-systems/zxcvbn-symfony

> 标签: PHP

## 简介

Password strength validator for Symfony framework. Based on Dropbox's zxcvbn project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
