# contaoblackforest/contao-doctrine-orm-timestampable

> 标签: contao, doctrine, orm, timestampable

## 简介

Doctrine ORM Timestampable Bridge for Contao CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
