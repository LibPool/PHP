# ssx/module-webapi-logs

> 标签: PHP

## 简介

This module allows you to log and analyze all webapi REST calls to your Magento/Adobe Commerce store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
