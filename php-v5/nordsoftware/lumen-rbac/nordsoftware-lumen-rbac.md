# nordsoftware/lumen-rbac

> 标签: laravel, lumen, overseer, permissions, rbac

## 简介

RBAC module for the Lumen framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
