# symbiote-library/silverstripe-s3publisher

> 标签: s3, silverstripe, static

## 简介

A static publisher which publishes the site to an S3 bucket

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
