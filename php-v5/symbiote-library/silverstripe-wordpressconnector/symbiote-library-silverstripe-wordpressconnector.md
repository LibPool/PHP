# symbiote-library/silverstripe-wordpressconnector

> 标签: PHP

## 简介

A Wordpress connector for SilverStripe that allows you to link to and import posts and pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
