# drillcoder/amocrm_wrap

> 标签: amo, amoCRM, crm, drillcoder, wrap

## 简介

Обёртка для простого взаимодействия с Api AmoCRM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
