# ropendev/curl

> 标签: Multi-thread, bot, crawler, curl, http, parallel, request, spider

## 简介

PHP POO cURL wrapper (PSR friendly) : light and simple.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
