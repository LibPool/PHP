# progpark/aliyun-mns-laravel

> 标签: aliyun, laravel, mns

## 简介

Laravel queue driver bases on Aliyun Message Service（MNS）.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
