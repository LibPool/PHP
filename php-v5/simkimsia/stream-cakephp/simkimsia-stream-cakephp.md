# simkimsia/stream-cakephp

> 标签: activity, activity feed, aggregated feed, getstream, newsfeed, notification feed

## 简介

Build newsfeeds and activity feeds on CakePHP 3.x using getstream.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
