# titon/annotation

> 标签: annotation, attribute, meta, metadata, titon, wire

## 简介

The annotation packages provides class and method level metadata through annotations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
