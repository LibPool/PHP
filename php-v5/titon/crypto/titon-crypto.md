# titon/crypto

> 标签: cipher, crypto, decode, decrypt, digest, encode, encrypt, payload, titon

## 简介

The crypto package provides secure ecrypting and decrypting of data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
