# bookking3000/guzzcache

> 标签: PHP

## 简介

A in-File JSON-Cache for storing Guzzle HTTP Responses from REST-APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
