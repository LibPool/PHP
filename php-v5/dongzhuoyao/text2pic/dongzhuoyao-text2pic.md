# dongzhuoyao/text2pic

> 标签: generate picture, text2pic, 文字生成图片

## 简介

文字生成图片,生成长微博,text generate picture

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
