# idealogica/lavanda

> 标签: admin, administrator, control, crud, laravel, lavanda, panel

## 简介

Administrator control panel for Laravel application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
