# masroore/flight

> 标签: PHP

## 简介

Flight is a fast, simple, extensible framework for PHP. Flight enables you to quickly and easily build RESTful web applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
