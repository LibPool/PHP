# s4studio/yii2-redactor

> 标签: Redactor, extension, html editor, imperavi, wysiwyg, yii2

## 简介

Extension redactor for Yii2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
