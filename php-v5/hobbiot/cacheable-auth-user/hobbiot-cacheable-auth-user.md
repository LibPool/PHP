# hobbiot/cacheable-auth-user

> 标签: auth, cache, laravel

## 简介

Cache Auth::user() for Laravel 5.3. This package add new driver to laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
