# zendframework/zend-uri

> 标签: ZendFramework, uri, zf

## 简介

A component that aids in manipulating and validating » Uniform Resource Identifiers (URIs)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
