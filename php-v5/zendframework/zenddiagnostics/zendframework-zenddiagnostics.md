# zendframework/zenddiagnostics

> 标签: ZendFramework, diagnostics, php, test, zf

## 简介

A set of components for performing diagnostic tests in PHP applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
