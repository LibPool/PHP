# dangermark/laravel-getresponse

> 标签: getresponse, laravel, laravel5

## 简介

A Laravel 5 wrapper for the GetResponse API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
