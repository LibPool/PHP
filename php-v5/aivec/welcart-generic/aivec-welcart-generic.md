# aivec/welcart-generic

> 标签: PHP

## 简介

Generic interfaces/abstract-classes/utils for Welcart libraries (settlement modules, customizations, etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
