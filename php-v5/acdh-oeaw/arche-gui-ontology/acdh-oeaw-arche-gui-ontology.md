# acdh-oeaw/arche-gui-ontology

> 标签: PHP

## 简介

Drupal CKEDitor module for the ACDH ARCHE GUI plugin. It is displaying a table based on the imported ontology.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
