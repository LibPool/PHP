# codigosecafe/horizon-sqs-fifo-queue

> 标签: aws, fifo, illuminate, laravel, lumen, queue, sqs

## 简介

Adiciona um driver de fila Laravel para filas Amazon SQS FIFO.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
