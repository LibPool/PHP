# aimeos/ai-zend

> 标签: adapter, aimeos, e-commerce, framework, shop, zend

## 简介

Zend Framework adapter for Aimeos web shops and e-commerce solutions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
