# aimeos/ai-container

> 标签: aimeos, container, e-commerce, extension, shop

## 简介

Container/Content extension for Aimeos web shops and e-commerce solutions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
