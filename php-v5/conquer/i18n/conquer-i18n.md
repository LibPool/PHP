# conquer/i18n

> 标签: google-translate, i18n, yandex-translate, yii2

## 简介

The I18n automatic translation extension for the Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
