# chris48s/cakephp-geodistance

> 标签: cakephp, distance, geo, geography

## 简介

CakePHP 3 model behavior for querying geocoded data based on distance

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
