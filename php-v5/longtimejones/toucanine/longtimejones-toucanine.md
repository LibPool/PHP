# longtimejones/toucanine

> 标签: framework, hmvc, router

## 简介

A very simple, yet flexible, PHP5 HMVC-alike micro framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
