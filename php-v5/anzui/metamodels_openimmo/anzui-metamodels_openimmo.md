# anzui/metamodels_openimmo

> 标签: contao, metamodels, openimmo

## 简介

Import OpenImmo-Data into an existing MetaModel (for Contao CMS)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
