# devgeniem/wp-stateless-bucket-link-filter

> 标签: PHP

## 简介

Enables filtering WP Stateless bucket link via a PHP constant.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
