# jinnguyen/puja-paginator

> 标签: paginator, puja

## 简介

Puja-Paginator is a flexible component for paginating collections of data and presenting that data to users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
