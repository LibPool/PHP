# lewiscom/presto

> 标签: Craft, cms, craft-plugin, craftcms, presto

## 简介

A static cache plugin for Craft CMS 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
