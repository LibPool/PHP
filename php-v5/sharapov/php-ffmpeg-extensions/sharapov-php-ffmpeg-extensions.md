# sharapov/php-ffmpeg-extensions

> 标签: alpha layer, audio, audio processing, avconv, avprobe, chromakey, colorkey, ffmpeg, ffmpeg overlay, ffprobe, mov, php-ffmpeg, video, video processing

## 简介

An extensions library for the PHP FFMpeg (https://github.com/PHP-FFMpeg/PHP-FFMpeg)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
