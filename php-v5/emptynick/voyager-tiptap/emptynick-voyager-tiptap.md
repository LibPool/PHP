# emptynick/voyager-tiptap

> 标签: tiptap, voyager, voyager2-plugin, wysiwyg

## 简介

Tiptap WYSIWYG editor for Voyager II

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
