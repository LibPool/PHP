# plaisio-ts/helper-cast

> 标签: Cast Safely, PhpPlaisio

## 简介

PhpPlaisio (TypeScript): Safely cast mixed values to bool, number (float or integer), or string

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
