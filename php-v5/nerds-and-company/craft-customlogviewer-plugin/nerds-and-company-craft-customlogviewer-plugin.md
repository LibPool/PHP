# nerds-and-company/craft-customlogviewer-plugin

> 标签: PHP

## 简介

Plugin for Craft CMS that adds the ability to view custom log files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
