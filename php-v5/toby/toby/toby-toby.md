# toby/toby

> 标签: framework, rackem, route, sinatra, web

## 简介

Put 'ol Toby in your pipe and smoke it. A micro web framework similar to Sinatra that makes PHP fun again.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
