# bestboysmedialab/language-list

> 标签: PHP

## 简介

List of all languages with names and ISO 3166-1 codes in all languages and data formats for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
