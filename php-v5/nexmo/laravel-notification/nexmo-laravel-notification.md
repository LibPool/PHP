# nexmo/laravel-notification

> 标签: PHP

## 简介

Send SMS, WhatsApp, Viber and Facebook Messenger messages via Nexmo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
