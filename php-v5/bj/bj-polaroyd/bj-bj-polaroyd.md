# bj/bj-polaroyd

> 标签: Poaroyd, TYPO3 CMS, bootstrap, portfolio, responsive, template, theme, typo3

## 简介

The TYPO3 theme which includes a full configured frontend theme for TYPO3, based on the Bootstrap CSS Framework. URL: https://templatemag.com/demo/Polaroyd/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
