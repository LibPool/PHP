# markdown-extended/mde-editor

> 标签: editor, embeddable, markdown, markdown-extended

## 简介

MarkdownExtended web editor (based on EpicEditor)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
