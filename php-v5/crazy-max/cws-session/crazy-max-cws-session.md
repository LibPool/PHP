# crazy-max/cws-session

> 标签: database, encrypt, session

## 简介

PHP class to manipulate sessions. Data are securely encrypted and sessions are stored in database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
