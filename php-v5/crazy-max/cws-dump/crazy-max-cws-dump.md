# crazy-max/cws-dump

> 标签: Xdebug, dump, print_r, var_dump

## 简介

PHP class to replace var_dump(), print_r() based on the Xdebug style.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
