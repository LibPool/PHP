# webgriffe/pdftotext-bundle

> 标签: Symfony2, pdf, pdf2text, pdftotext

## 简介

This bundle integrates Symfony2 with pdftotext binary command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
