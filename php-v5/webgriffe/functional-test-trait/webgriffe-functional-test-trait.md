# webgriffe/functional-test-trait

> 标签: PHP

## 简介

Trait which enables functional testing in Magento with EcomDev_PHPUnit and using a CgiHttpKernel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
