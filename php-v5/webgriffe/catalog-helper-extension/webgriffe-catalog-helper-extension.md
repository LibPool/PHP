# webgriffe/catalog-helper-extension

> 标签: PHP

## 简介

Magento extension. Adds useful method to be used in catalog install/upgrade scripts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
