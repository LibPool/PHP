# dark-kitt/wordpress-mu-plugin-autoloader

> 标签: PHP

## 简介

This WordPress MU-Plugin loads MU-Plugins from subdirectories

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
