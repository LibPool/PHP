# vladan-me/fingerprint

> 标签: Fingerprint, elasticsearch, ngram

## 简介

Provides a custom implementation of fingerprint and ngram algorithms in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
