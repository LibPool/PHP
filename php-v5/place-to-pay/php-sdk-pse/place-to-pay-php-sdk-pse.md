# place-to-pay/php-sdk-pse

> 标签: PHP

## 简介

Una simple libreria para conectarse al webservice SOAP suministrado por Place To Pay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
