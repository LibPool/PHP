# paravibe/less-php

> 标签: PHP

## 简介

lessphp is a compiler for LESS written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/paravibe/less-php.git
