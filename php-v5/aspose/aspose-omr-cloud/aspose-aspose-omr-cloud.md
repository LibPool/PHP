# aspose/aspose-omr-cloud

> 标签: aspose, cloud, omr, php, sdk

## 简介

PHP library for communicating with the Aspose.OMR Cloud API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
