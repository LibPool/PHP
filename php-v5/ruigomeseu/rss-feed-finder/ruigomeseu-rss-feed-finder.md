# ruigomeseu/rss-feed-finder

> 标签: atom, feed, finder, rss, scraper, search

## 简介

Find and extract any RSS or ATOM feeds in a URL or domain

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
