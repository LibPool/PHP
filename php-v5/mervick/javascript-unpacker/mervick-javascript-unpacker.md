# mervick/javascript-unpacker

> 标签: PHP

## 简介

PHP helper that makes easy to unpack JavaScript code packed by Dean Edwards packer tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
