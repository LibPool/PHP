# myfossil/pbdb

> 标签: paleobiodb, paleobiology, pbdb, pbdbhttpapiphp, taxonomy

## 简介

PHP client for the Paleobiology Database API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
