# gafhyb/justgage

> 标签: PHP

## 简介

JustGage is a handy JavaScript plugin for generating and animating nice & clean dashboard gauges. It is based on Raphaël library for vector drawing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
