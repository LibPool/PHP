# allantatter/laravel-react

> 标签: blade, laravel, react, reactjs

## 简介

Render React.js components seemlessly on the server side within Laravel Blade views.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
