# divengine/nodes

> 标签: database, no-sql, serialization, storage

## 简介

Div PHP Nodes is a No-SQL Database System for PHP written in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/divengine/nodes.git
