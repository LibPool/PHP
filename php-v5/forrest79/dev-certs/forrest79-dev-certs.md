# forrest79/dev-certs

> 标签: certificates, https, ssl

## 简介

Create SSL wildcards domain certificates with own certificate authority for and ONLY for development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
