# karelwintersky/arris.toolkit.emoji-finder

> 标签: PHP

## 简介

A PHP emoji search engine optimized for search-as-you-type experience

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
