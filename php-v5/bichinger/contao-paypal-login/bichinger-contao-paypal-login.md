# bichinger/contao-paypal-login

> 标签: contao, paygate, paypal

## 简介

Enable to redirect member after registration to paypal and grants access only if paid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
