# angus-dv/in_array_r

> 标签: array, column, in_array_r

## 简介

Provides functionality for in_array_r() to projects using PHP earlier than version 5.5 or greater.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
