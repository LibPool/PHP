# inpassor/yii-eassetmanager

> 标签: asset, css, less, manager, yii

## 简介

Extended Asset Manager Compiles .less file(s) on-the-fly and publishes output .css file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
