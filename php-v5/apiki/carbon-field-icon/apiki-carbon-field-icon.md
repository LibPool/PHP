# apiki/carbon-field-icon

> 标签: carbon-field, carbon-field-icon, wordpress

## 简介

Carbon Fields extension, that adds a Icon field type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
