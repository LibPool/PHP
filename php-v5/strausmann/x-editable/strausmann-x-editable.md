# strausmann/x-editable

> 标签: bootstrap, editable, table, x-editable

## 简介

In-place editing with Twitter Bootstrap, jQuery UI or pure jQuery.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
