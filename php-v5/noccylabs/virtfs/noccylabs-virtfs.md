# noccylabs/virtfs

> 标签: autoload, physfs, virtual filesystem

## 简介

Virtual filesystems (like physfs) - with autoloading!

按 require.php 推断最低支持 PHP 2；已收录于 php-v5, php-v7, php-v8。
