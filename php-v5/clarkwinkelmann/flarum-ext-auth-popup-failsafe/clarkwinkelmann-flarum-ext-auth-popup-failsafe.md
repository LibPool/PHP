# clarkwinkelmann/flarum-ext-auth-popup-failsafe

> 标签: auth, flarum

## 简介

Failsafe in case the browser blocks the Flarum auth popup from closing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
