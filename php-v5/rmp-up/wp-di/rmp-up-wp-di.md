# rmp-up/wp-di

> 标签: PHP

## 简介

Simple Dependency Injection / Service Container for more OOP in WordPress (PSR-11 compatible)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
