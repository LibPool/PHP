# helium/eloquent-flex-model

> 标签: PHP

## 简介

Eloquent model class for translating MySQL flexible JSON fields into native object attributes and vise-versa

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
