# frosh/admin-dashboard

> 标签: PHP

## 简介

Replaces the Shopware administration dashboard with a modular, drag-and-drop widget board. The layout is persisted per-user.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
