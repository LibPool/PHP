# symfocode/twig-i18n

> 标签: i18n, internationalization, l10n, locale, localization, symfony, twig

## 简介

Twig internationalization tools for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
