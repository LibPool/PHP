# linkorb/buckaroo

> 标签: api, buckaroo, payment, php, psp

## 简介

Buckaroo BPE3 API client for PHP. PSR-0 Compliant.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
