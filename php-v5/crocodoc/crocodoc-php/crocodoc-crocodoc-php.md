# crocodoc/crocodoc-php

> 标签: api, crocodoc

## 简介

PHP wrapper for the Crocodoc API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://crocodoc.com/docs/api/
- 源码仓库：https://github.com/crocodoc/crocodoc-php.git
- Packagist 页面：https://packagist.org/packages/crocodoc%2Fcrocodoc-php

## 历史版本号

- 当前版本：v1.0.1

## 获取地址

- Composer 安装：`composer require crocodoc/crocodoc-php`
- Packagist 仓库：https://repo.packagist.org/p2/crocodoc/crocodoc-php.json
- 许可证：BSD
- PHP 要求：>=5.3
