# frozennode/xssinput

> 标签: laravel, xss

## 简介

A simple extension of the Laravel Input facade that mimics CodeIgniter's xss filtering

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
