# teddan/search-pickers

> 标签: date, filter, flarum, gambit, search, tags

## 简介

Click-to-pick date-range and tag filters in the Flarum search dropdown, collapsed by default.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
