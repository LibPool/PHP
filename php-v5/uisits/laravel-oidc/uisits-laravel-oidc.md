# uisits/laravel-oidc

> 标签: Laravel Socialite Shibboleth Provider, laravel, shibboleth, socialite

## 简介

Shibboleth OIDC driver for Laravel Socialite

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
