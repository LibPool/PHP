# contao-bootstrap/grid-editor

> 标签: Grid editor, bootstrap, columns, contao, grid

## 简介

Backend grid editor for Contao CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
