# bioshock/xlsx-wrapper

> 标签: PHPExcel, json, xlsx

## 简介

a list of helper class for phpoffice/phpexcel and league/csv

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
