# gtk/gapi

> 标签: api response, gapi, laravel, lumen, restful

## 简介

A RESTful API package for the Laravel and Lumen frameworks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
