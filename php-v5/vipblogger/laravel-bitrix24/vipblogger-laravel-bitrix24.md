# vipblogger/laravel-bitrix24

> 标签: PHP

## 简介

This is a wrapper for the Bitrix24 PHP SDK. Allows you to use Bitrix through Dependency Injection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
