# gruzilla/hydra-bundle

> 标签: Hydra, Symfony2, aggregation, social media

## 简介

PHP 5.4+ symfony2 bundle for the hydra social media channel aggregation library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
