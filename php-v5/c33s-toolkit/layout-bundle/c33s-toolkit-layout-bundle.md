# c33s-toolkit/layout-bundle

> 标签: PHP

## 简介

Base layouts for Symfony 3 applications to be used with c33s-toolkit/bootstrap3-bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
