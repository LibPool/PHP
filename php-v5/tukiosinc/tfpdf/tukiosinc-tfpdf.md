# tukiosinc/tfpdf

> 标签: fpdf, pdf, tfpdf, unicode

## 简介

This class is a modified version of FPDF that adds UTF-8 support. The latest version is based on FPDF 1.85.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
