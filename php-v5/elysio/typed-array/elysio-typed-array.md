# elysio/typed-array

> 标签: PHP

## 简介

A PHP package for managing typed arrays, simulating TypeScript interfaces, and improving array handling in PHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
