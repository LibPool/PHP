# hafsoft/php-minifier

> 标签: compression, minification

## 简介

Pure PHP JS and CSS Minifier. Thanks to phpmin & cssmin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
