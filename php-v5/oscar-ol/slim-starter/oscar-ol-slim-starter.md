# oscar-ol/slim-starter

> 标签: PHP

## 简介

A PHP application boilerplate using Slim v4, featuring a Laravel-inspired architecture.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
