# andykillen/wordpress-deployment

> 标签: cms, composer, deployment, htaccess, robots.txt, wordpress

## 简介

Deploy Wordpress via composer with extra tools to make it easier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
