# yiisoft/yii2-mongodb

> 标签: GridFS, MongoDB, active-record, mongo, mongodb, yii2, 数据库

## 简介

MongoDB extension for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
