# houseoftech/cakephp-boost-cake

> 标签: bootstrap, cakephp, twitter

## 简介

BoostCake is a plugin for CakePHP using Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
