# sibilino/yii2-openlayers

> 标签: OpenLayers, map, openlayers3, widget, yii, yii2

## 简介

Map widget encapsulating the OpenLayers 3 library for easy use in Yii 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
