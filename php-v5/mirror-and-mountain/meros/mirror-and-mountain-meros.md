# mirror-and-mountain/meros

> 标签: acorn, laravel, livewire, meros, wordpress

## 简介

A block-based starter theme for Wordpress using the Meros Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
