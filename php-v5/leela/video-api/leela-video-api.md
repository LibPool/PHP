# leela/video-api

> 标签: PHP

## 简介

Gets the Videos from all the major video sharing websites. Supports Youtube, Dialymotion and Vimeo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
