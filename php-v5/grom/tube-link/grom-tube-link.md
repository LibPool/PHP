# grom/tube-link

> 标签: dailymotion, parser, spotify, url, video, vimeo, youtube

## 简介

Extract video/music information from any URL and render HTML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
