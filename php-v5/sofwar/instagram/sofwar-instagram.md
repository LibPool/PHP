# sofwar/instagram

> 标签: api, instagram

## 简介

An easy-to-use PHP Class for accessing Instagram's API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/sofwar/Instagram-PHP-API
- 源码仓库：https://github.com/sofwar/Instagram-PHP-API.git
