# webtrend/cookie-set

> 标签: Craft, cms, cookie set, craft-plugin, craftcms

## 简介

A plugin that stores Google Analytics utm_parameter query string to a client cookies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
