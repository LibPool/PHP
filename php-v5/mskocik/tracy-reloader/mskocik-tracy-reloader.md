# mskocik/tracy-reloader

> 标签: Server-Sent Events, livereload, sse, tracy

## 简介

Automatic page refresh - watching changes with SSE or connect your LiveReload server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
