# t4web/pages

> 标签: zf2

## 简介

ZF2 Module for easily creating static pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/t4web/Pages
- 源码仓库：https://github.com/t4web/Pages.git
- Packagist 页面：https://packagist.org/packages/t4web%2Fpages

## 获取地址

- Composer 安装：`composer require t4web/pages`
- Packagist 仓库：https://repo.packagist.org/p2/t4web/pages.json
