# kebacorp/arrayexcelbuilder

> 标签: LibreOffice, excel, export, spreadsheet, xls, xlsx

## 简介

The extension creates an Excel file from the data array.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
