# pasinter/package-migrations-composer-plugin

> 标签: bundle, doctrine, migrations, package, symfony

## 简介

Composer plugin that integrates package (eg Symfony Bundle) Doctrine migrations into the project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
