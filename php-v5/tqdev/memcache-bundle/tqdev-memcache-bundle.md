# tqdev/memcache-bundle

> 标签: cache, memcache, memcached, session

## 简介

Memcache Doctrine caching and session storage in the Web Debug Toolbar

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
