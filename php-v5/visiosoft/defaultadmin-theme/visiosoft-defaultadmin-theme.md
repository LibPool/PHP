# visiosoft/defaultadmin-theme

> 标签: addon, cms, laravel, theme, visiosoft

## 简介

The official admin theme for Visiosoft.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
