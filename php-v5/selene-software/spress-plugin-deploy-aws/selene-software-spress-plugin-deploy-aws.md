# selene-software/spress-plugin-deploy-aws

> 标签: plugin, spress

## 简介

Deploy your site to an AWS S3 bucket for static site hosting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
