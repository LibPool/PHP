# dhlparcel/magento2-plugin-hyva

> 标签: PHP

## 简介

Compatibility extension between DHLParcel_Shipping and Hyva_Checkout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
