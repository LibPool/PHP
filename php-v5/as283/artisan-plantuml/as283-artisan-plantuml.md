# as283/artisan-plantuml

> 标签: PHP

## 简介

Laravel Artisan commands for generating migrations and Eloquent models from PlantUML class diagrams and vice-versa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
