# neos/contentrepositoryregistry-postgresdbalclient

> 标签: PHP

## 简介

PostgreSQL-optimized Doctrine DBAL client for the Neos Content Repository Registry

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
