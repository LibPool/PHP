# pdffiller/laravel-influx-provider

> 标签: influx-db, laravel

## 简介

Service provider to set up and use InfluxDB SDK in Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
