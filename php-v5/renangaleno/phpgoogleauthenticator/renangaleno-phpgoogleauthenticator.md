# renangaleno/phpgoogleauthenticator

> 标签: auth, authenticator, google, php

## 简介

PHP Class for handling Google Authenticator 2-factor authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
