# lake/larke-jwt-sm2

> 标签: admin, lake, laravel, larke, larke-jwt, sm2

## 简介

A JWT Signer library with SM2 and SM3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
