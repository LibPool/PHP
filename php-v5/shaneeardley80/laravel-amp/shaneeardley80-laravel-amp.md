# shaneeardley80/laravel-amp

> 标签: laravel-amp, shaneeardley80

## 简介

Package that helps you set up AMP (Accelerated Mobile Pages) using Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
