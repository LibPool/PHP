# simonbackx/slack-php-webhook

> 标签: channels, logging, message, slack, webhook

## 简介

Post messages to your Slack channels with this easy to use library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
