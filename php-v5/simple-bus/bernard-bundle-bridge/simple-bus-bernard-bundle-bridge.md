# simple-bus/bernard-bundle-bridge

> 标签: bernard, command bus, event bus, message bus, messages

## 简介

Use BernardBundle with SimpleBus/AsynchronousBundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
