# financialplugins/omnipay-trongrid

> 标签: crypto, omnipay, tron, trongrid

## 简介

Trongrid driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
