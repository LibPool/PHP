# drmonty/chosen

> 标签: dropdown, form, input, multiselect, select, ui

## 简介

Chosen is a library for making long, unwieldy select boxes more friendly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
