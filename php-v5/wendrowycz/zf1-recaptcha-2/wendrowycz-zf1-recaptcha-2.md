# wendrowycz/zf1-recaptcha-2

> 标签: ZF1, google, recaptcha, zend

## 简介

A quick package to assist with using Google reCAPTCHA version 2 with ZF1 (php 5.3.27)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
