# concrete5-community/error_notifier

> 标签: addon, alert, cms, concrete, concrete5, concreteCMS, error, notification, package

## 简介

A ConcreteCMS/concrete5 package that send errors and warnings to Slack or Telegram

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
