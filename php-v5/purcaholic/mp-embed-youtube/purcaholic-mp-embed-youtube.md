# purcaholic/mp-embed-youtube

> 标签: CONTENIDO, embed, module, video, youtube

## 简介

YouTube video embed module for CONTENIDO CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
