# twibs/zf2-facebook

> 标签: facebook, module, sdk, zf2

## 简介

Zend Framework 2 Module that allows easy integration the Facebook SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/Vibre/facebook
- 源码仓库：https://github.com/twibs/facebook.git
- Packagist 页面：https://packagist.org/packages/twibs%2Fzf2-facebook

## 获取地址

- Composer 安装：`composer require twibs/zf2-facebook`
- Packagist 仓库：https://repo.packagist.org/p2/twibs/zf2-facebook.json
- 许可证：Apache
