# mswarak/write-to-image

> 标签: image, imagejpeg, rtl, write

## 简介

Add a text into jpg images with customized align (ltr, center and rtl)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
