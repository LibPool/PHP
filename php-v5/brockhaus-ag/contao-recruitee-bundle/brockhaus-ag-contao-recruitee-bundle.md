# brockhaus-ag/contao-recruitee-bundle

> 标签: BROCKHAUS AG, bundle, contao, recuitee

## 简介

Mit dem Contao Recruitee Bundle der BROCKHAUS AG können Sie Bewerbungen über ein Formular an Recruitee senden.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
