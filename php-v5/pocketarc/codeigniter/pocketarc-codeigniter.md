# pocketarc/codeigniter

> 标签: PHP

## 简介

Actively maintained CodeIgniter 3 fork with support for PHP 5.4 - PHP 8.6 (and beyond). Fully backward compatible.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
