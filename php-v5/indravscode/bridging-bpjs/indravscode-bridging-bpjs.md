# indravscode/bridging-bpjs

> 标签: PHP

## 简介

Package wrapper untuk bridging BPJS (VClaim, Aplicare, PCare dan i-Care)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
