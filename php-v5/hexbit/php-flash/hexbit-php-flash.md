# hexbit/php-flash

> 标签: flash, hexbit, message, redirect, session, smarteist, wordpress

## 简介

Its a session based redirector with flash messages for php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
