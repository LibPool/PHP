# bakery/framework2

> 标签: RDF, framework, php, security

## 简介

BakeryFramework2 is an embelished RDF (Rapid Development Framework) designed for PHP5.5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/mikemackintosh/BakeryFramework2.git
