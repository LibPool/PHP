# wuhen/mysql-to-es

> 标签: MysqlToEs, elasticsearch, es, mysql, mysql2elasticsearch, mysql2es, restful, sql, sql2es, sqltoes

## 简介

mysql sql to elasticsearch,mysql语句转换ES语句查询

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
