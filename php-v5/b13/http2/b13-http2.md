# b13/http2

> 标签: PHP

## 简介

HTTP2 Server Push Support for TYPO3 - Speed up TYPO3 rendering via HTTP/2 Server Push

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
