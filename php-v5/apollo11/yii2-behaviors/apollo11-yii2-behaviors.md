# apollo11/yii2-behaviors

> 标签: Behavior, global-behavior, yii2

## 简介

Collection of global helper behaviors for Yii2 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
