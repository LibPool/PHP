# powerbuoy/sleek-login

> 标签: PHP

## 简介

Improves the login screen and hides admin bar from subscribers, also redirects them to the home page upon login.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
