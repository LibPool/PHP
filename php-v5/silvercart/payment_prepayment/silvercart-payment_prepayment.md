# silvercart/payment_prepayment

> 标签: ecommerce, online shop, payment, prepayment, shop, silvercart, silverstripe, webshop

## 简介

Payment module for the SilverCart ecommerce module for SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
