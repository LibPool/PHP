# tshabatyn/magento2-deployer-plus

> 标签: deploy, deployer, deployment, magento2, tool

## 简介

Magento 2 deployment tool based on deployer.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
