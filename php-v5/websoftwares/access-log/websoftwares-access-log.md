# websoftwares/access-log

> 标签: PSR3, http, log, psr7, request

## 简介

Log PSR-7 http messages using a PSR-3 logger instance following apache2 access log format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
