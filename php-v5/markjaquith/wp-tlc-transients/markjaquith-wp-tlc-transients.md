# markjaquith/wp-tlc-transients

> 标签: cache, wordpress

## 简介

A WP transients interface with support for soft-expiration, background updating of the transients.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
