# renus/last-tweet

> 标签: Symfony 2 tweets twitter last tweets

## 简介

Symfony 2 bundle to add quickly last tweets on your website

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
