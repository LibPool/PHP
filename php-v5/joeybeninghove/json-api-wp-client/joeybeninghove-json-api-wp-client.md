# joeybeninghove/json-api-wp-client

> 标签: api, json, wordpress

## 简介

WordPress client library for consuming JSON APIs following the 1.0 spec at jsonapi.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
