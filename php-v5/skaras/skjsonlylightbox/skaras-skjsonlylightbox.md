# skaras/skjsonlylightbox

> 标签: PHP

## 简介

TYPO3 extension providing the pure Javascript GLightbox for text with image and tx_news.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
