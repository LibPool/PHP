# basketin/cart-delta

> 标签: PHP

## 简介

Cart delta package for Basketin — discount rules, coupons and a promotion engine for Laravel e-commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
