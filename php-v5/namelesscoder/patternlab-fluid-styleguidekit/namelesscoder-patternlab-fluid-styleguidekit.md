# namelesscoder/patternlab-fluid-styleguidekit

> 标签: fluid, pattern lab, styleguide

## 简介

Fluid-based style guide kit for Pattern Lab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
