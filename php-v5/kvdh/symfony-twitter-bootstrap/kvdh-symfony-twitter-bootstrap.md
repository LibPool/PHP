# kvdh/symfony-twitter-bootstrap

> 标签: bootstrap, symfony, twitter, twitter bootstrap

## 简介

Twitter Bootstrap vendor package for Symfony 2.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
