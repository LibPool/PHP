# jennchen/duckpatrol

> 标签: PHP

## 简介

DuckPatrol is a PHP library designed to automatically protect your web applications from Cross-Site Request Forgery (CSRF) attacks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
