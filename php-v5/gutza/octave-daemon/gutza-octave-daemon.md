# gutza/octave-daemon

> 标签: PHP

## 简介

The PHP network daemon for GNU Octave http://projects.moongate.ro/octave-daemon/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
