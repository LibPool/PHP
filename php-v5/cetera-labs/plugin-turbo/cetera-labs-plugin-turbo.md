# cetera-labs/plugin-turbo

> 标签: PHP

## 简介

Возможность создавать турбо-страницы в Яндексе, Гугле и Телеграме.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
