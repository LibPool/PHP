# ipc/reactphp

> 标签: PHP

## 简介

Commands for Symfony Framework 3|4 and Silex 2 to run the application with a ReactPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://bitbucket.org/ideaplexus/reactphp.git
