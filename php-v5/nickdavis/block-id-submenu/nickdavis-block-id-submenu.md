# nickdavis/block-id-submenu

> 标签: PHP

## 简介

WordPress plugin which generates a submenu from block ID attributes in the WordPress editor. Requires developer setup.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
