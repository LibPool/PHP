# nickdavis/acf-site-options

> 标签: PHP

## 简介

WordPress MU-Plugin which registers a Site Options admin page with Advanced Custom Fields

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
