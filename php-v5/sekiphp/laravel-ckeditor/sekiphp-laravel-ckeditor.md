# sekiphp/laravel-ckeditor

> 标签: CKEditor, editor, fckeditor, html, javascript, laravel, richtext, text, wysiwyg

## 简介

JavaScript WYSIWYG web text editor (for laravel).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
