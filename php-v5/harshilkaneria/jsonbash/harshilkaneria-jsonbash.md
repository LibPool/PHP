# harshilkaneria/jsonbash

> 标签: PHP

## 简介

A PHP Function for Generating Basic Structure for Json Response Like Status , Message , Data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
