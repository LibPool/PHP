# makeitbetter/yiiimages

> 标签: extension, images manager, makeitbetter, module, yii, yii 2, yii2

## 简介

Images manager module for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
