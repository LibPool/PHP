# tmf/wp-hookable-service

> 标签: PHP

## 简介

A Pimple ServiceProvider that registers pimple services and hooks them up the WordPress Plugin system (actions, filters)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
