# shyam-achuthan/google-cloud

> 标签: PHP

## 简介

A library for easy access of google cloud platform - PubSub ( Alternative to Amazon SQS )

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
