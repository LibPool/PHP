# dongww/silex-base

> 标签: PHP

## 简介

SilexBase 是以 Silex 为基础构建的骨架程序，可作为中小型项目开发的起点。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
