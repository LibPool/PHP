# malirobot/sonata-form-builder

> 标签: Symfony2, admin, builder, drag, drop, form, project, sonata

## 简介

A drag&drod form builder for sonata admin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
