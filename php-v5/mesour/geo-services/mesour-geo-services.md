# mesour/geo-services

> 标签: directions, geolocation, google api, services

## 简介

Mesour GeoServices is a service for easy to use Google Directions API and more GEO APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
