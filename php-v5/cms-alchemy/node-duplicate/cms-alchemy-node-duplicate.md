# cms-alchemy/node-duplicate

> 标签: PHP

## 简介

Adds a duplicate operation for Drupal nodes with safe defaults and redirect to edit form.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
