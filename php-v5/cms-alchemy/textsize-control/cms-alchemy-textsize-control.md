# cms-alchemy/textsize-control

> 标签: PHP

## 简介

Drupal module providing dynamic user-controlled text scaling with intelligent fallback strategies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
