# friendica/json-ld

> 标签: JSON-LD, Linked Data, RDF, Semantic Web, json, jsonld

## 简介

A JSON-LD Processor and API implementation in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
