# im-denisenko/php-json-encode

> 标签: json, json_encode

## 简介

Provides features, added to json_encode since version 5.3.0, for version 5.3.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
