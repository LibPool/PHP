# netom/logentries-monolog-handler

> 标签: laravel, log, logentries, logging, monolog, symfony

## 简介

A handler for Monolog that sends messages to Logentries.com.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
