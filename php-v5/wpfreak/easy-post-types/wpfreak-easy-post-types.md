# wpfreak/easy-post-types

> 标签: PHP

## 简介

Provides a crazy simple, and easy to use wrapper for the Wordpress custom posts api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
