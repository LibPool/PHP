# brocode/module-image-optimizer-amqp

> 标签: PHP

## 简介

Magento 2 module for the AMQP (RabbitMQ) integration of the Image Optimizer Queue module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
