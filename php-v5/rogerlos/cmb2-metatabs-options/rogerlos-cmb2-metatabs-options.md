# rogerlos/cmb2-metatabs-options

> 标签: PHP

## 简介

Extends CMB2 to allow WordPress options pages with multiple metaboxes and optional tabs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
