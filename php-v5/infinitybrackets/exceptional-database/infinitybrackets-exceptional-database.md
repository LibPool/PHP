# infinitybrackets/exceptional-database

> 标签: PHP

## 简介

PHP ORM Core of Infinity Brackets for PHP MVC Core (infinitybrackets/php-mvc-core)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
