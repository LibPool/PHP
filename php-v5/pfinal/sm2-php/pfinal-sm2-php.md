# pfinal/sm2-php

> 标签: sm2, spaced repetition

## 简介

Spaced repetition algorithms (SuperMemo algorithm SM-2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
