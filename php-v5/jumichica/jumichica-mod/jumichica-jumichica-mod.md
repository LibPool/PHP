# jumichica/jumichica-mod

> 标签: framework, jumichica, jumichica module

## 简介

Módulo inicial para facilitar  a un proyecto desarrollado con el microframework **Jumíchica**.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
