# monyxie/aliyun-openapi-sdk-vod

> 标签: aliyun, openapi, php, sdk

## 简介

The VOD SDK for Aliyun OpenAPI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
