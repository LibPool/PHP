# doge-dev/laravel-sms-verification

> 标签: aws, laravel, sms, verification

## 简介

Library for sending out and verifying SMS codes using AWS SNS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
