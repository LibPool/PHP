# wbe/rapyd

> 标签: Rapyd, admin, administrator, backend, crud, datatable, form, laravel

## 简介

crud widgets for laravel, to make an admin in few lines of code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
