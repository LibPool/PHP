# nepstor/yii2-datetime-compare-validator

> 标签: datetime, datetime compare, extension, validator, yii2

## 简介

Yii2 validator for compare datetime.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
