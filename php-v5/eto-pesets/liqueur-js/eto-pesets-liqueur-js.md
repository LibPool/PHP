# eto-pesets/liqueur-js

> 标签: ethanol, javascript, liqueur, sucrose, sugar, syrup

## 简介

Library for composition/calculation of ethanol-sucrose-water solutions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
