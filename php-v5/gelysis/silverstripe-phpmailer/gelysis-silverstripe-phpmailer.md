# gelysis/silverstripe-phpmailer

> 标签: phpmailer, silverstripe

## 简介

PHPMailer implementation for SilverStripe allowing custom smtp.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
