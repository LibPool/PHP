# creads/api2symfony

> 标签: api, converter, php, raml, symfony

## 简介

PHP library to automatically generate Symfony2 controllers from API specifications (RAML, Blueprint, Swagger...)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
