# tobymaxham/laravel-odbc-driver

> 标签: laravel, odbc, sqlserver, tobymaxham

## 简介

An ODBC Driver for SQL Server within Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
