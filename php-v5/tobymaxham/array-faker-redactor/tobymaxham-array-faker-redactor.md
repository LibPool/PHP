# tobymaxham/array-faker-redactor

> 标签: Redactor, array, faker, laravel, redact

## 简介

A PHP package to redact or fake array values by their keys.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
