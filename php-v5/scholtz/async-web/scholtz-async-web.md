# scholtz/async-web

> 标签: AsyncWeb, Asynchonous web, Ratchet, WebSockets, frontend, server, sockets

## 简介

PHP WebSocket frontend and server libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
