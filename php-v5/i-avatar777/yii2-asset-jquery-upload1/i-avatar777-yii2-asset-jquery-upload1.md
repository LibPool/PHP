# i-avatar777/yii2-asset-jquery-upload1

> 标签: yii2-asset-jquery-upload1

## 简介

Ресурс для Yii2 который позволяет создать загрузчик файла

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
