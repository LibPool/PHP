# mix/guzzle-hook

> 标签: Guzzle, mix, swoole

## 简介

让 Guzzle 支持 Swoole 的 PHP Stream Hook 协程

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
