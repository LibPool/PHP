# prexview/prexview

> 标签: PHP

## 简介

A composer library to use PrexView, a fast, scalable and friendly service for programatic HTML, PDF, PNG or JPG generation using JSON or XML data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
