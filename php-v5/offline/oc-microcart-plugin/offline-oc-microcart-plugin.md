# offline/oc-microcart-plugin

> 标签: cart, cms, e-commerce, october, plugin, shop

## 简介

Simple shopping cart for October CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
