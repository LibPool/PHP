# finteza/finteza-php-sdk

> 标签: analytics, finteza, proxy, tracking

## 简介

Official SDK for sending events to Finteza servers and proxying analytics requests through the your site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
