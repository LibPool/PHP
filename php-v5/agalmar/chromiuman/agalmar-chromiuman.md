# agalmar/chromiuman

> 标签: chrome, codeception, extension, headless

## 简介

The Codeception extension for automatically starting and stopping Chromedriver when running tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
