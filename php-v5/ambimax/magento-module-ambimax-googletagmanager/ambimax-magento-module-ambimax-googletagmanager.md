# ambimax/magento-module-ambimax-googletagmanager

> 标签: PHP

## 简介

Magento 1 Module to activate Google Tag Manager on different website and store views.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
