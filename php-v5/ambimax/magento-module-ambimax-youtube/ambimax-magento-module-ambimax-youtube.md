# ambimax/magento-module-ambimax-youtube

> 标签: PHP

## 简介

Magento 1 module for embedding YouTube videos and playlists on product pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
