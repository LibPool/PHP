# runar1/lumen-lambda

> 标签: amazon, aws, lambda, laravel, lumen

## 简介

Enables lumen to run on AWS Lambda.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
