# matthew-p/yii2-toggle-column

> 标签: active, column, extension, grid, gridview, models, record, toggle, yii2

## 简介

Simple widget for toggle model column in grid view

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
