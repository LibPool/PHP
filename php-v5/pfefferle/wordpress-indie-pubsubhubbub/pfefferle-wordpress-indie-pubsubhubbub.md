# pfefferle/wordpress-indie-pubsubhubbub

> 标签: PHP

## 简介

Pushes the (microformatted) main blog URL via PubSubHubbub

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
