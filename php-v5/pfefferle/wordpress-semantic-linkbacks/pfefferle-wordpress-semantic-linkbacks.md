# pfefferle/wordpress-semantic-linkbacks

> 标签: PHP

## 简介

Semantic Linkbacks for WebMentions, Trackbacks and Pingbacks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
