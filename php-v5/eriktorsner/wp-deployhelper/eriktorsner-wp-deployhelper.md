# eriktorsner/wp-deployhelper

> 标签: ftp, wordpress

## 简介

A small util for deploying WordPress installations via ftp. Only fast.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
