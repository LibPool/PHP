# ipeevski/pauseonfail

> 标签: TDD, acceptance testing, functional testing, notification, unit testing

## 简介

Extension for Codeception to Pause on Fail

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
