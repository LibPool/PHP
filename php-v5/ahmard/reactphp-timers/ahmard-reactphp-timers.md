# ahmard/reactphp-timers

> 标签: asynchronous, asyncphp, reactphp

## 简介

Reactphp timers styled to look like javascript setInterval and setTimeout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
