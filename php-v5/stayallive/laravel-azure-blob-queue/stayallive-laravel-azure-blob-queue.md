# stayallive/laravel-azure-blob-queue

> 标签: azure, blob, laravel, queue

## 简介

Extending the Laravel queue to support the Microsoft Azure Blob Queue.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
