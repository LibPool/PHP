# shadz3rg/lexer

> 标签: annotations, docblock, lexer, parser, php

## 简介

PHP Doctrine Lexer parser library that can be used in Top-Down, Recursive Descent Parsers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
