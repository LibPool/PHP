# devgarden/benchmark

> 标签: benchmark

## 简介

Benchmark is a extension what can be used command driven or injected to benchmark your code in executiontime, memoryusage and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
