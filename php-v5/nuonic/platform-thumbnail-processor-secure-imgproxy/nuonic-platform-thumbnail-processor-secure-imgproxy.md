# nuonic/platform-thumbnail-processor-secure-imgproxy

> 标签: Media Manager, admin, backend, cdn, media, shopware, storage, thumbnail

## 简介

This plugin allows you to use a secured imgproxy integration in the Shopware thumbnail processor, enabling signed URLs and enhanced media delivery options.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
