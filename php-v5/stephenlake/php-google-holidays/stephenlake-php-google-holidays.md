# stephenlake/php-google-holidays

> 标签: calendar, holidays

## 简介

A PHP package to assist in retrieving a country's year holidays from Google Calendar API's.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
