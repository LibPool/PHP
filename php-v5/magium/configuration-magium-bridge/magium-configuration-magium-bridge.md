# magium/configuration-magium-bridge

> 标签: PHP

## 简介

This is a utility library that links Magium Configuration and the Magium Selenium Testing Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
