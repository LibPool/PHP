# magium/twitter

> 标签: selenium, testing, twitter, webdriver

## 简介

Provides a mechanism for logging in to Twitter to validate OAuth-based tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
