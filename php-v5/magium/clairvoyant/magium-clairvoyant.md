# magium/clairvoyant

> 标签: PHP

## 简介

An API for reporting on PHPUnit and Magium tests at https://clairvoyant.magiumlib.com/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
