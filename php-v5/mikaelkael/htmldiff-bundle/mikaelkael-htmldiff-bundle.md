# mikaelkael/htmldiff-bundle

> 标签: diff, diffing, html

## 简介

Symfony Bundle for php-htmldiff (caxy/php-htmldiff)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
