# rougin/expresso

> 标签: php-blog, static-blog, static-site

## 简介

Static blog platform based on Staticka.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://roug.in/staticka/expresso/
- 源码仓库：https://github.com/rougin/expresso.git
- Packagist 页面：https://packagist.org/packages/rougin%2Fexpresso
