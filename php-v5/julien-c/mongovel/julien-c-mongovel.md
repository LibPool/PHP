# julien-c/mongovel

> 标签: Laravel 4, laravel, mongo, mongodb

## 简介

A Laravel-ish wrapper to the PHP Mongo driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
