# rtxlabs/datatransformation-bundle

> 标签: bundle, doctrine, entity, json

## 简介

Provides mappers for generate complex JSON outputs from entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
