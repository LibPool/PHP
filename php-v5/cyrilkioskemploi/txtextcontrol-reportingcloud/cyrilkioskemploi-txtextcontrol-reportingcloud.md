# cyrilkioskemploi/txtextcontrol-reportingcloud

> 标签: PHP

## 简介

PHP wrapper for ReportingCloud Web API. Authored and supported by Text Control GmbH.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
