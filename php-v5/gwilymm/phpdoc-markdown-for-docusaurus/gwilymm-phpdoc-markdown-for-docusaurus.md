# gwilymm/phpdoc-markdown-for-docusaurus

> 标签: Docusaurus, documentation, markdown, phpDocumentor, phpdoc, template

## 简介

phpDocumentor v3 template that generates Markdown documentation for Docusaurus.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
