# sauce/connect

> 标签: Sauce, SauceLabs, api, phpunit, selenium, testing, tunnel

## 简介

PHP package for the Sauce Connect Java binary

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
