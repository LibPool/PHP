# ikkez/f3-pagination

> 标签: F3, fatfree, pagebrowser, pagination

## 简介

Provides a pagebrowser and some pagination utilities for the PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
