# wirelab/quotes_widget-extension

> 标签: pyrocms, pyrocms 3, quote, random quote, wirelab

## 简介

A widget which shows a random quote.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
