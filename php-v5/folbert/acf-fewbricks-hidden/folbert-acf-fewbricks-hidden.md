# folbert/acf-fewbricks-hidden

> 标签: acf, advanced custom fields, fewbricks, hidden

## 简介

Hidden field for Advanced Custom Fields. Written especially for Fewbricks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
