# an3/laravel-couchdb

> 标签: couchdb, database, eloquent, laravel, model

## 简介

A CouchDB based Eloquent model and Query builder for Laravel 5.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
