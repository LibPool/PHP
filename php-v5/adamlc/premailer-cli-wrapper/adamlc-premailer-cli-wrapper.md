# adamlc/premailer-cli-wrapper

> 标签: PHP

## 简介

PHP CLI wrapper for Premailer (https://github.com/premailer/premailer)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
