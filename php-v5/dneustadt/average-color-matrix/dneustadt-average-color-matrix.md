# dneustadt/average-color-matrix

> 标签: average, colors, hex, image, matrix, rgb, svg

## 简介

Generates a matrix in desired resolution of average colors of an image

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
