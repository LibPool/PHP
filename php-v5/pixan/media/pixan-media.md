# pixan/media

> 标签: PHP

## 简介

Pixan package for media manipulation and storage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://pixan.io
- 源码仓库：https://bitbucket.org/pixan/media.git
- Packagist 页面：https://packagist.org/packages/pixan%2Fmedia
