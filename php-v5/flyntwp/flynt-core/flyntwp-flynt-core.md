# flyntwp/flynt-core

> 标签: PHP

## 简介

The Flynt Core Plugin provides a small public interface, combined with several WordPress hooks, to achieve the main principles of the Flynt Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
