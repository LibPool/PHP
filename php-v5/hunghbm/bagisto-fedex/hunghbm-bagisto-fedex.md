# hunghbm/bagisto-fedex

> 标签: FedEx, fedex-bagisto, fedex-extension

## 简介

This extension used for calculating shipping rate with FeDex services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
