# swapnilsarwe/icndb

> 标签: chuck-norris, icndb, jokes

## 简介

A fork of PHP Wrapper for The Chuck Norris Db API, created by cyrus david.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
