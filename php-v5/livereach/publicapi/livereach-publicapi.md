# livereach/publicapi

> 标签: client, java, rest

## 简介

PHP bindings for LiveReach public API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/livereach/public-api-php.git
