# compropago/simplestore

> 标签: pagos internet, payment gateway

## 简介

Simplestore usando el SDK de compropago

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://compropago.com/documentacion/librerias
- 源码仓库：https://github.com/compropago/docs-php-sdk.git
- Packagist 页面：https://packagist.org/packages/compropago%2Fsimplestore

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require compropago/simplestore`
- Packagist 仓库：https://repo.packagist.org/p2/compropago/simplestore.json
- 许可证：Apache-2.0
- PHP 要求：>=5.5
