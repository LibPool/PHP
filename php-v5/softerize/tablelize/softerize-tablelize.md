# softerize/tablelize

> 标签: eloquent, html, laravel, table

## 简介

Customizable Laravel Eloquent html tables with pagination, search, sorting and buttons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
