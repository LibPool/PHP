# ondrakub/bank-php

> 标签: BIC, Bank, IBAN, account, code, name, number, swift, valid

## 简介

Easy-to-use library for getting Czech code or name of bank.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
