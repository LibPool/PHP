# creifenscheid/db-rector

> 标签: PHP

## 简介

This TYPO3 extension is an typo3-fractor adapter with backend module to refactor sys_template.config data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
