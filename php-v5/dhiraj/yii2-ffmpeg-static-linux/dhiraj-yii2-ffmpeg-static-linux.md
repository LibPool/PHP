# dhiraj/yii2-ffmpeg-static-linux

> 标签: PHP

## 简介

Provides static ffmpeg binaries for linux with a convenient path lookup for both ffmpeg and ffprobe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
