# markusvolkmer/typo3-distribution

> 标签: PHP

## 简介

Simple TYPO3 distribution package derived from typo3/cms-base-distribution and helhum/typo3-distribution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
