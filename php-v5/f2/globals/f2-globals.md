# f2/globals

> 标签: PHP

## 简介

Provides a function `F2\globals(string $namespace):array` that allow you to save data without polluting the `$_GLOBALS` superglobal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
