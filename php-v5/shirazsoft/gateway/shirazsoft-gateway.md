# shirazsoft/gateway

> 标签: Bank, Meli, Payline, asan-pardakht, dargah, gateway, ipay, iran, iranian-banks, irankish, jahanpay, laravel, mellat, pardakht, parsian, pasargad, pay, pay-ir, payment, paypal, persian-banks, poolport, port, sadad, saderat, saman, shaparak, zarinpal

## 简介

A Laravel package for connecting to all Iraninan payment  gateways

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
