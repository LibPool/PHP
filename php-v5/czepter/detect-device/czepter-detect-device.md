# czepter/detect-device

> 标签: PHP

## 简介

fork of the incredible work of Kevin Warren (detectdevice.com). Easy to use lib for device detection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
