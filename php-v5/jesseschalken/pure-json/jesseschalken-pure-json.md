# jesseschalken/pure-json

> 标签: PHP

## 简介

json_encode/json_decode wrapper with error checking and one-to-one mapping between PHP and JSON values

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
