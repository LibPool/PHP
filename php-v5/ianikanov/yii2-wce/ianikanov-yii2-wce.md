# ianikanov/yii2-wce

> 标签: crud, extension, widget, yii2

## 简介

Ability to generate widgets with interface similar to controller with basic CRUD actions for specific model

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
