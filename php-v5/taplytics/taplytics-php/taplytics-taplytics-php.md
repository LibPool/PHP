# taplytics/taplytics-php

> 标签: Taplytics Decisions API, api, php, sdk

## 简介

Taplytics PHP SDK for fast A/B testing and Feature Flagging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
