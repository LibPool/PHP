# acplo/acploui

> 标签: acplo, module, ui, zf2

## 简介

AcploUi provides some UI utility classes your ZF2 application using Jquery2, Bootstrap3, Chosen, etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
