# fedoskin/wave

> 标签: audio, chunk, php, riff, wave, waveform

## 简介

A php package to read WAV data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/ptelevich/Wave.git

- Packagist 仓库：https://repo.packagist.org/p2/fedoskin/wave.json
