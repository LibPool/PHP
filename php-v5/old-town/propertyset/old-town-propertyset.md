# old-town/propertyset

> 标签: module, storage, zend

## 简介

PropertySet is a persistence-agnostic module that can be used to fulfill storage requirements in applications that can change constantly

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
