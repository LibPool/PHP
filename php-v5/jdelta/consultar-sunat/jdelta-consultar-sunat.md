# jdelta/consultar-sunat

> 标签: consulta, curl, peru, php, sunat

## 简介

Módulo para realizar consultas a SUNAT mediante el numero de RUC o DNI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
