# petrofcikmatus/zf-layout-change

> 标签: change, framework, layout, module, zend, zf

## 简介

Zend Framework module for layout change based on used controller namespace.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
