# zirak/linkable-dataobjects

> 标签: dataobject, link, silverstripe, tinymce

## 简介

This module adds the ability to link DataObjects in TinyMCE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
