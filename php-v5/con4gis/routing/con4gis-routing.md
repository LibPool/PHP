# con4gis/routing

> 标签: RoutingBundle, c4g, con4gis, contao, routing

## 简介

Routing bundle with to extend the usual Router from the MapsBundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
