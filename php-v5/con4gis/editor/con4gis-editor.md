# con4gis/editor

> 标签: EditorBundle, c4g, con4gis, contao, editor

## 简介

Editor bundle with to extend the usual editor from the MapsBundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
