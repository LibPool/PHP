# hettiger/laravel-starter

> 标签: framework, hettiger, laravel, point, starter, starting

## 简介

A fresh Starting Point for Laravel Applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
