# adhiana46/bpjs

> 标签: PHP

## 简介

PHP package to access BPJS Kesehatan API. This is a wrapper for BPJS Kesehatan API https://dvlp.bpjs-kesehatan.go.id:8888/trust-mark/portal.html

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
