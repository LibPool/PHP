# mathiasgrimm/arraypath

> 标签: Xpath, array, array_key_exists_recursive, php, util

## 简介

php array utility to manipulate array in a xpath way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
