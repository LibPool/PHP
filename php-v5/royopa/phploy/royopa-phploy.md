# royopa/phploy

> 标签: PHP

## 简介

PHPloy - Incremental Git (S)FTP deployment tool that supports submodules, multiple servers and rollbacks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
