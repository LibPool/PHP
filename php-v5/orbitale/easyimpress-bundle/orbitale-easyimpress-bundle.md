# orbitale/easyimpress-bundle

> 标签: bundle, impress, presentation, slides, symfony

## 简介

Symfony Bundle to create presentations with Impress.js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
