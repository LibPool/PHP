# klsoft/yii3-datareader-doctrine

> 标签: datareader, doctrine, orm, yii3

## 简介

The package provides a Yii 3 data reader that uses the Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
