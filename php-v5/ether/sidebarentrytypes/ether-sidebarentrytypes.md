# ether/sidebarentrytypes

> 标签: Craft, cms, craft-plugin, craftcms, sidebar entry types

## 简介

Easily switch between entry types in entries section

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
