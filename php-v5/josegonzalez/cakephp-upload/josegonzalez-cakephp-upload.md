# josegonzalez/cakephp-upload

> 标签: Behavior, cakephp, files, orm, upload

## 简介

CakePHP plugin to handle file uploading sans ridiculous automagic

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
