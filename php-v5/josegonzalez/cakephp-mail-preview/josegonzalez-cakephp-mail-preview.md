# josegonzalez/cakephp-mail-preview

> 标签: cakephp, email, mail, preview

## 简介

CakePHP plugin for use with previewing emails during development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
