# waavi/url-shortener

> 标签: laravel, shortener, url, url short, url shortener, waavi

## 简介

Url Shortener for Laravel 5 with support for Google and Bitly drivers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
