# econda/tracking

> 标签: PHP

## 简介

Library to generate JavaScript code for econda analytics web tracking.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://git.econda.de/php-sdk/tracking.git
