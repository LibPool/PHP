# majalin/php-webbot

> 标签: PHP

## 简介

This project is based on Michael Schrenk's WebbotsSpidersScreenScraper Library REV 2.0, and I just modify to use it on composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
