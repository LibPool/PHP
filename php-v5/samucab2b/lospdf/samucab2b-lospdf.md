# samucab2b/lospdf

> 标签: los, mpdf, pdf, zf2

## 简介

Fork do módulo LosPdf (ZF2) para geração de PDF — mantido por samucab2b

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
