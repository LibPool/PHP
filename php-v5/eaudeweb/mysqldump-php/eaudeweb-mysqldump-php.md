# eaudeweb/mysqldump-php

> 标签: PHP7, database, hhvm, mariadb, mysql, mysql-backup, mysqldump, pdo, php, php5, sql

## 简介

PHP version of mysqldump cli that comes with MySQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
