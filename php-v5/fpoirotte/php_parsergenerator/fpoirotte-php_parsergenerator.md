# fpoirotte/php_parsergenerator

> 标签: lemon, lempar, parser

## 简介

Translate grammar files in Lemon Parser Generator format into a PHP 5 parser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
