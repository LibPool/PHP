# fpoirotte/xrl

> 标签: client, rpc, server, xml, xml-rpc, xmlrpc

## 简介

Simple XML-RPC Library (both client and server)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
