# ijiabao/phpquery-onefile

> 标签: PHP

## 简介

phpQuery单文件版本，此为原始镜像，无任何修改。原始项目主页：http://code.google.com/p/phpquery/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
