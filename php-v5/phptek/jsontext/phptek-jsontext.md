# phptek/jsontext

> 标签: dbfield, json, jsonpath, multi, multivalue, multivaluefield, postgres, query, silverstripe, text

## 简介

JSON storage, querying and modification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
