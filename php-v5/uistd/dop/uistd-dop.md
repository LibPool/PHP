# uistd/dop

> 标签: dop, ui service, uistd

## 简介

数据转对象的代码自动生成工具，主要用于模型对象的自动生成的数据 打包、解包方法生成。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
