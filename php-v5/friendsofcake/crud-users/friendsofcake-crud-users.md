# friendsofcake/crud-users

> 标签: Users, cakephp, crud

## 简介

Adds basic users support to CakePHP applications that use the Crud plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
