# gomoob/php-embedded-mongo

> 标签: In Memory, embedded, gomoob, mongo, phpunit

## 简介

Start an embedded Mongo DB server and run your PHPUnit integration tests easily.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
