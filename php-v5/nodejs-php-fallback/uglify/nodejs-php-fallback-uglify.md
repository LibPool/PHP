# nodejs-php-fallback/uglify

> 标签: PHP

## 简介

PHP wrapper to execute uglify-js/clean-css node package or fallback to PHP alternatives

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
