# axiolab/bs-select-bundle

> 标签: symfony form bootstrap-select

## 简介

Override symfony choice type implementing bootstrap-select js plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
