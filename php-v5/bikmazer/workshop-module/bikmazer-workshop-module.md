# bikmazer/workshop-module

> 标签: asgardcms, modules, workshop

## 简介

Workshop module for AsgardCMS. Handles the activation of modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
