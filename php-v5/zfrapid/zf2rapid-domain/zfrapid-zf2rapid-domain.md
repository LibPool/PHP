# zfrapid/zf2rapid-domain

> 标签: PHP

## 简介

ZF2 module with a domain class library to be used by ZF2rapid Skeleton Application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
