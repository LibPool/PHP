# chondal/telegram-user-suscription

> 标签: PHP

## 简介

Captar id de chat de telegram y asociarlo a un usuario para enviarle mensajes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
