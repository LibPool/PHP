# hesper/hesper

> 标签: PHP

## 简介

Hesper is the mature multi-purpose object-oriented PHP framework. It is a logical continuation of onPHP framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
