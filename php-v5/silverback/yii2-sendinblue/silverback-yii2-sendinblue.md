# silverback/yii2-sendinblue

> 标签: email, mailer, sendinblue, yii2

## 简介

Sendinblue integration and Mailer for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
