# dhrechanyi/activecampaign-api-v3-wrapper

> 标签: PHP

## 简介

Wrapper for ActiveCampaing API v3, which allows to work with their services, using PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
