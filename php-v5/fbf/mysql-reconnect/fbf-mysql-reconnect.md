# fbf/mysql-reconnect

> 标签: PHP

## 简介

A PDO wrapper that reconnects automatically and re-issues queries on receiving MySQL server timeout errors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
