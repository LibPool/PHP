# fbf/laravel-competitions

> 标签: competitions, laravel

## 简介

A Laravel 4 package to add simple competitions, with entries tied to a logged in user, to a site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
