# sirbrillig/spies

> 标签: mocking, phpunit, spies, spy, stubs

## 简介

Easier spies, stubs, and mocking for PHP tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
