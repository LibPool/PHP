# dbrisinajumi/yeeki

> 标签: yii

## 简介

Yeeki is a flexible wiki engine that can be used either as a standalone application or as an Yii framework module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
