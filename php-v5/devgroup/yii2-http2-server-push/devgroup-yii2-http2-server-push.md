# devgroup/yii2-http2-server-push

> 标签: assetmanager, http2, push, server push, yii2

## 简介

HTTP/2 server push support for Yii2 Asset Manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
