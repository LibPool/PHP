# tscheckenbach/php-bad-words

> 标签: bad, words

## 简介

PHP Bad words filtering. Checks for existence of bad word in a string but checks too an alone word or among the string

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
