# wikimart/log4php-graylog2

> 标签: graylog2, log, log4php, logging, php

## 简介

Log4php appenders and layouts for compatibility with graylog2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
