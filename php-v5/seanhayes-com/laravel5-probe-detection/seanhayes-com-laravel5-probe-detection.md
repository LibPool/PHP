# seanhayes-com/laravel5-probe-detection

> 标签: laravel, probe, seanhayes, security, website

## 简介

A Laravel 5 package to log known website probing attacks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
