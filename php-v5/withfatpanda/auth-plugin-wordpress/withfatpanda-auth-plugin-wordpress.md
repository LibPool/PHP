# withfatpanda/auth-plugin-wordpress

> 标签: PHP

## 简介

Social login and registration, built with Bamboo and powered by Laravel Socialite

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
