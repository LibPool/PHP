# withfatpanda/bugsnag-mini-php

> 标签: PHP

## 简介

A minimal PHP-based implementation of a client for reporting application errors to Bugsnag

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
