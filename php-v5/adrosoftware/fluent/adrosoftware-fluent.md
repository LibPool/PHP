# adrosoftware/fluent

> 标签: data mapper, database, doctrine, fluent, mapping driver, mappings, orm

## 简介

A fluent PHP mapping driver for Doctrine2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
