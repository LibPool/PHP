# diego3/php-export-data

> 标签: csv, excel, library

## 简介

A simple library for exporting tabular data to Excel-friendly XML, CSV, or TSV

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
