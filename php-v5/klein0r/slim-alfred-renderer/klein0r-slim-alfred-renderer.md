# klein0r/slim-alfred-renderer

> 标签: alfred, framework, renderer, slim

## 简介

Render Alfred XML into a PSR-7 Response object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
