# shad/daniyel

> 标签: Daniyel-Vanguard, php bot, self shad, shad, shad bot, shad-self

## 简介

ShadBot is a lightweight PHP library designed to automate interactions with the Shad educational platform. It provides a flexible and developer-friendly interface for building self-bots that can authenticate, send messages, manage sessions, and interact with Shad’s API endpoints.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
