# dlu/dluphpsettings

> 标签: dluphpsettings, module, php settings, zend framework 2, zf2

## 简介

ZF2 module to set PHP ini settings based on the configuration data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
