# eru/avro-phonetic

> 标签: Bangla, avro, bengali, laravel, phonetic, transliteration

## 简介

Avro Phonetic - Bengali/Bangla transliteration library for PHP and Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
