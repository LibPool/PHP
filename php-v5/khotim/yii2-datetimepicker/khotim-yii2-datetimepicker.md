# khotim/yii2-datetimepicker

> 标签: DateTimePicker, datepicker, jQuery UI, timepicker, yii2

## 简介

The DatetimePicker extension for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
