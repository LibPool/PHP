> 标签: Cascading Style Sheets, Fast CSS, JS, Style Sheets, compressor, css, fast-css.com, fcss, file, javascript, laravel, php, php-compressor

## 简介

PHP compressor merge multiple css and js files into one file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
