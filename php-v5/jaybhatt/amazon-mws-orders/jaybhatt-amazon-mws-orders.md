# jaybhatt/amazon-mws-orders

> 标签: amazon, mws, orders

## 简介

Amazon Marketplace Web Service Orders API - PHP for managing Orders with Amazon market place.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
