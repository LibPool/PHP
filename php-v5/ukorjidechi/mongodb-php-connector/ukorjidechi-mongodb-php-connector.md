# ukorjidechi/mongodb-php-connector

> 标签: mongoDB connector, mongodb, php

## 简介

A wrapper class for connecting to mongoDB base on MongoDB PHP driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
