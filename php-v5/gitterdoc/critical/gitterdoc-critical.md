# gitterdoc/critical

> 标签: Above the fold, PageSpeed, critical, gitterdoc, stylesheet

## 简介

Laravel provider that will extract critical CSS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
