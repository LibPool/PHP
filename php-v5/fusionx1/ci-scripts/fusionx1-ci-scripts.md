# fusionx1/ci-scripts

> 标签: PHP

## 简介

Scripts helpful for testing a Drupal site on a Continuous-Integration server, or locally.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
