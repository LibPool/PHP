# cake-cms/extensions

> 标签: cakephp, cakephp community, cakephp users, cms cakephp

## 简介

CakePHP CMS extensions plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
