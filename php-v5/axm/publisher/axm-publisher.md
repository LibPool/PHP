# axm/publisher

> 标签: framework, microframework, php, rest, router

## 简介

Simple, performant and powerful PHP micro-framework for rapid web app & API development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
