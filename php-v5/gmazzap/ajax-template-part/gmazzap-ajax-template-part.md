# gmazzap/ajax-template-part

> 标签: ajax, template, template partials, wordpress, wordpress plugin

## 简介

Like get_template_part(), but AJAX powered.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
