# karlmonson/tenant

> 标签: Settings, database, laravel

## 简介

Tenant allows for storing configuration settings in the database. This package is perfect for multitenant applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
