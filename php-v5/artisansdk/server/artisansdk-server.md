# artisansdk/server

> 标签: Socket, async, laravel, process, reactphp, realtime, server, websocket

## 简介

A service-based, Laravel PHP implementation of an async, realtime, WebSocket server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
