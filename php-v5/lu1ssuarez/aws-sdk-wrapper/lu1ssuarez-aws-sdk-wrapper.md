# lu1ssuarez/aws-sdk-wrapper

> 标签: amazon, aws, laravel, laravel 5, php, s3, sdk, wrapper

## 简介

A simple AWS SDK for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
