# baru/correios

> 标签: correios, correios api, rastrerio correios

## 简介

Biblioteca que gera uma API a partir de parsing da página de rastreio dos Correios.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
