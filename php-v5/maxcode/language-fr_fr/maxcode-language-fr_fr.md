# maxcode/language-fr_fr

> 标签: PHP

## 简介

EN: French complement for Magento 2: translates what the community language pack leaves out, for the core and common third-party modules. FR : Complément français pour Magento 2 : ce que le pack communautaire ne traduit pas, pour le cœur et les modules tiers courants.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
