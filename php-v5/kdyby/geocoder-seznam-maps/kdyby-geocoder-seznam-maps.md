# kdyby/geocoder-seznam-maps

> 标签: geo, geocoder, geocoding, kdyby, location, map, maps, seznam

## 简介

Seznam Maps api v4 provider for willdurand/geocoder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
