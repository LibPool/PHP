# affinity4/heap

> 标签: PHP

## 简介

Full Binary Heap implementation with maxheap, minheap and memory-efficient O(nlogn) and space-complexity of O(1) heapsort algorithm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
