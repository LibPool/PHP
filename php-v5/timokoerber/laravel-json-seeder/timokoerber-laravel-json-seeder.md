# timokoerber/laravel-json-seeder

> 标签: database, laravel, seeder, seeds

## 简介

Create and use JSON files to seed your database in your Laravel applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
