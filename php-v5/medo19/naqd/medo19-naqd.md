# medo19/naqd

> 标签: PHP

## 简介

Naqd is a lightweight package that provides ISO 4217-compliant currency data along with corresponding Unicode symbols and SVG icons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
