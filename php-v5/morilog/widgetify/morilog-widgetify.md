# morilog/widgetify

> 标签: laratalks, laravel, morilog, view-composer, widget, widgets

## 简介

A powerful laravel widget package. capsulate ui componenet as widget. similar to Yii widgets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
