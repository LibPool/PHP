# anam/phantommagick

> 标签: Html 2 jpg, Html 2 pdf, Laravel pdf, Phantom, Screen capture, converter, html to image, html to pdf, html to png, image converter, invoice, laravel, pdf, pdf converter, phantomjs

## 简介

PhantomMagick provides a simple API to ease the process of converting HTML to PDF or images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
