# lluiscamino/php-doc2pdf

> 标签: pdf phpdocumentor, phpdoc, phpdoc2pdf

## 简介

Create PDF formatted documentation for your PHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
