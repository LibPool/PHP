# aozen/prism2torchlight

> 标签: Prismjs, code, code blocks, highlighting, laravel, laravel package, laravel syntax, laravel torchlight, syntax highlighting, tinymce, torchlight

## 简介

Laravel package to seamlessly convert PrismJS HTML code blocks to Torchlight syntax highlighting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
