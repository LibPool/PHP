# aozen/astar

> 标签: Algorithm, astar, graph, image

## 简介

A PHP package for finding the closest path and generating images of graphs using the A-star algorithm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
