# sithous/antispam-bundle

> 标签: anti spam, brute force, protection

## 简介

Provides Anti-Spam capabilities to Symfony in an easy to use package..

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
