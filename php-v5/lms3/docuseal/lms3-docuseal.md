# lms3/docuseal

> 标签: PHP

## 简介

Allows TYPO3 to integrate with DocuSeal services, enabling frontend users to securely sign documents using the DocuSeal API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
