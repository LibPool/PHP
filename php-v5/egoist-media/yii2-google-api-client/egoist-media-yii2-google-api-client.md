# egoist-media/yii2-google-api-client

> 标签: api, google, yii2

## 简介

A Yii2 wrapper for the official Google API PHP Client v2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
