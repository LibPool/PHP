# abdeslam/kmbt

> 标签: PHP

## 简介

a PHP big numbers (K => thousand, M => million, B => billion, T => trillion) formatter and converter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
