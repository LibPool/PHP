# ollieread/justgiving-oauth2

> 标签: Authentication, authorization, client, justgiving, oauth, oauth2

## 简介

JustGiving OAuth2 provider for use with league/oauth2-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
