# innoweb/silverstripe-robots

> 标签: robots, robots.txt, seo, silverstripe

## 简介

Adds a Robots.txt file that is configurable from /admin/settings/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
