# innoweb/silverstripe-tinymce-clearfloats

> 标签: clear, floats, silverstripe, tinymce, wysiwyg

## 简介

Adds a clear-floats plugin the CMS WYSIWYG editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
