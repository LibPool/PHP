# menatwork/frontendcheckboxmenu

> 标签: Forms, checkbox, frontend

## 简介

Include the select all checkbox for frontend checkbox widgets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
