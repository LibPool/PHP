# magenxcommerce/magenxcommerce-modules

> 标签: graphql, headless, magento, magento2, metapackage

## 简介

Metapackage installing all Magenx Commerce companion Magento 2 modules for the headless storefront.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
