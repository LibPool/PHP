# kraenzle-ritter/markdown-to-ead

> 标签: EAD, laravel, markdown

## 简介

Convert Markdown to EAD (Encoding Archival Description)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
