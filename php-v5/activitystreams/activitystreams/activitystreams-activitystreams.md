# activitystreams/activitystreams

> 标签: activity, activitystreams, federated, indieweb, social, web

## 简介

A set of PSR-0 autoloadable classes for representing ActivityStreams activities and objects in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
