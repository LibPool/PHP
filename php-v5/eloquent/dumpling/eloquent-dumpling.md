# eloquent/dumpling

> 标签: cli, command, dump, improved, mysql, mysqldump

## 简介

Diff-friendly mysqldump with an improved interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
