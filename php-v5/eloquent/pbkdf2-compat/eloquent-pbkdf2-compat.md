# eloquent/pbkdf2-compat

> 标签: compat, compatibility, hash, hash_pbkdf2, pbkdf, pbkdf2, pkcs, pkcs5

## 简介

A compatibility library for the PHP 5.5 function hash_pbkdf2().

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
