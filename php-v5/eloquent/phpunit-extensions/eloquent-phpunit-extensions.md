# eloquent/phpunit-extensions

> 标签: case, extension, parameterized, phpunit, test, testing

## 简介

Extensions for PHPUnit to provide additional functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
