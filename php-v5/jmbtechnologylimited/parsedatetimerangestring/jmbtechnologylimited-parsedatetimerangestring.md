# jmbtechnologylimited/parsedatetimerangestring

> 标签: date, time

## 简介

Takes a string with a date and time range, tries to parse it into date objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
