# illchuk/zf3-symfony-console

> 标签: console, zf3

## 简介

A simple way to extend your existing Zend Framework 3 app with a Symfony Console facet.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
