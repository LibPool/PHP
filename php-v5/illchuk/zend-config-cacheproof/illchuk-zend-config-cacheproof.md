# illchuk/zend-config-cacheproof

> 标签: cache, config, zend-config, zf3

## 简介

Create *.cacheproof.php config files that skip the cache, with custom loading.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
