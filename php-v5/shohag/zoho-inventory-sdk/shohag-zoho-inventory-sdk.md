# shohag/zoho-inventory-sdk

> 标签: Zoho, api, inventory, php, sdk

## 简介

SDK for ZOHO Inventory API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.zoho.com/inventory/api/v1/
- 源码仓库：https://github.com/shohag121/Zoho-Inventory-SDK.git
