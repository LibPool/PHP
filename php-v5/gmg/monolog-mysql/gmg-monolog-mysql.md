# gmg/monolog-mysql

> 标签: laravel, laravel5, log, monolog, mysql

## 简介

Laravel 5 MySQL driver for Monolog forked from markhilton/monolog-mysql

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
