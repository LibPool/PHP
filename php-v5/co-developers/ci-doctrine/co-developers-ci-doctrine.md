# co-developers/ci-doctrine

> 标签: codeigniter, codeigniter 3, doctrine, orm

## 简介

Librería de CodeIgniter 3 para utilizar Doctrine como ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
