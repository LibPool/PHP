# ragephp/jsonrpc-server

> 标签: Symfony2, json-rpc, silex

## 简介

Ultra-simple JSON-RPC 2.0 server for symfony-based frameworks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
