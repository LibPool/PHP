# bostondv/bootstrap-share-buttons

> 标签: bootstrap, buttons, email, facebook, google, linkedin, pinterest, print, sharing, social, twitter, wordpress

## 简介

Super lightweight Bootstrap social sharing buttons (without counters)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
