# opensaucesystems/mail

> 标签: OpenSauceSystems, phpmailer, smtp

## 简介

PHPMailer helper class for sending emails using SMTP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
