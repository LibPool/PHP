# redchamps/module-login-emoji

> 标签: PHP

## 简介

Inspired from Telegram web Login. It will add an interactive emoji on Magento admin login page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
