# starcitizentools/ag-grid

> 标签: ag grid, aggrid, extension, mediawiki

## 简介

Renders AG Grid data grids in MediaWiki

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
