# telabotanica/tb-auth-php

> 标签: SSO, tela botanica, tela-botanica, telabotanica

## 简介

A library that helps integrating your PHP software with Tela Botanica's SSO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
