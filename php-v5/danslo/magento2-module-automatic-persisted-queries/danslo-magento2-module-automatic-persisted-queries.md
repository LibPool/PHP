# danslo/magento2-module-automatic-persisted-queries

> 标签: PHP

## 简介

Apollo-compatible automatic persisted queries, to improve GraphQL network performance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
