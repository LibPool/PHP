# statenweb/page-for-post-type

> 标签: wordpress

## 简介

Allows you to set pages for any custom post type archive. Purely forked to update composer/installers to 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
