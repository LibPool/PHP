# psagnataf/sphinxsearch

> 标签: laravel, laravel 6, sphinx, sphinxsearch

## 简介

Laravel package to query Sphinxsearch in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
