# tcwei/db

> 标签: PHP

## 简介

mysql 数据库操作；安全：全程预处理模式防SQL注入，自动添加反引号防表字段与关键词冲突；支持主从分布，支持配置参数保存；

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
