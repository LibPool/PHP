# tcwei/page

> 标签: PHP

## 简介

PHP 分页 ，支持ajax模式和普通跳转模式，内置4种分页样式，也可前端自定义样式。通过参数可控制其中的部件是否显示。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
