# scoutnet/sh-scoutnet-kalender

> 标签: Pfadfinder, ScoutNet, ScoutNet Kalender, TYPO3 CMS, extension

## 简介

Official Typo3 plugin to display scoutnet.de calendar

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
