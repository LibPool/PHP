# sevenshores/encryption-compat

> 标签: PHP

## 简介

Encryption Service Provider for Laravel < 5.1 for PHP 7.1 compatibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
