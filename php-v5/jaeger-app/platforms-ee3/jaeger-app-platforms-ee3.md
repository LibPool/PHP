# jaeger-app/platforms-ee3

> 标签: EECMS3, ExpressionEngine 3

## 简介

An ExpressionEngine 3 CMS Platform object for use with Jaeger.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
