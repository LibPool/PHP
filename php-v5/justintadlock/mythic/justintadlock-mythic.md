# justintadlock/mythic

> 标签: wordpress

## 简介

Mythic is a next-generation starter theme designed to help theme authors write elegant, intelligent, and modern code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
