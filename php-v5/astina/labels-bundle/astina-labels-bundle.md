# astina/labels-bundle

> 标签: filter, labels, search

## 简介

Symfony bundle that offers categorized labels for Doctrine entities to be used for filtered search.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
