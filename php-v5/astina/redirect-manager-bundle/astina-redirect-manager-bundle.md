# astina/redirect-manager-bundle

> 标签: 301, 302, astina, manager, redirect, redirection

## 简介

User gets ability to specify redirection through web GUI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
