# dmk/mkcache_queue

> 标签: TYPO3 CMS, cache, performance, queue

## 简介

Clear the TYPO3 caches via a queue instead of doing it directly

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
