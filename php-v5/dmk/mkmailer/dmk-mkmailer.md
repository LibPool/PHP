# dmk/mkmailer

> 标签: TYPO3 CMS, mail, phpmailer

## 简介

Makes the Open Source project phpmailer available for TYPO3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
