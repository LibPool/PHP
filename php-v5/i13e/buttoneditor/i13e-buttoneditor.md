# i13e/buttoneditor

> 标签: Neos, buttons, editor, inspector, neoscms

## 简介

A plugin for Neos CMS which provides a button editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
