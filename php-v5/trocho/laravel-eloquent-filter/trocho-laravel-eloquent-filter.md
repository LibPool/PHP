# trocho/laravel-eloquent-filter

> 标签: eloquent, filter, input, laravel, request

## 简介

Allows filtering Eloquent queries by input filters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
