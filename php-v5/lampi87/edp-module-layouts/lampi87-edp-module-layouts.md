# lampi87/edp-module-layouts

> 标签: zf2

## 简介

EdpModuleLayouts is very simple Laminas module for making module-specific layouts insanely easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
