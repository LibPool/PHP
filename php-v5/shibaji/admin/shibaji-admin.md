# shibaji/admin

> 标签: PHP

## 简介

Laravel Admin Panel for laravel developers. You can create Quick Admin Panel with essential requirement.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
