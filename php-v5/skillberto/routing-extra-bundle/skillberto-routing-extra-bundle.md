# skillberto/routing-extra-bundle

> 标签: database-routing, routing, routing-extra

## 简介

This bundle is an extra router. With SonataAdminBundle can routing from database, and create custom database routing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
