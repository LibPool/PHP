# portrino/px_hybrid_auth

> 标签: cms, hybridauth, portrino, socialauth, typo3

## 简介

Adds social sign-in via HybridAuth to TYPO3-Login and -Logout. (by portrino GmbH)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
