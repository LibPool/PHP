# cgdsoftware/multitenancy

> 标签: cgdsoftware, laravel, middleware, multitenancy

## 简介

User actions logger dependency for Laravel Enso

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
