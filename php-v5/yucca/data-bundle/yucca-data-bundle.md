# yucca/data-bundle

> 标签: data, fixtures, installer, orm, updater, yucca

## 简介

Add powerful symfony commands to your yucca installation : patch your schema, and add fixtures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
