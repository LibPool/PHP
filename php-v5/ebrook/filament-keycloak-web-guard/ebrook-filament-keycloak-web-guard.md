# ebrook/filament-keycloak-web-guard

> 标签: Authentication, jwt, keycloak, laravel

## 简介

Filament-ready Keycloak Web Guard (based on vizir/laravel-keycloak-web-guard)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
