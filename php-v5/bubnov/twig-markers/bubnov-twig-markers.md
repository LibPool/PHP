# bubnov/twig-markers

> 标签: placeholder, symfony, twig, twig extension

## 简介

php Twig extention filter allows you replace placeholders in text by content context

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
