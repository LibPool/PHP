# bubnov/php-antigate-client

> 标签: antigate, captcha, decaptcha, decaptcher

## 简介

Lightweight client for Antigate service upgraded by Bubnov

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
