# mediactive-digital/laravel-bootstrap-4-forms

> 标签: Forms, bootstrap, composer, form-builder, laravel, package, php

## 简介

Bootstrap 4 form builder for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
