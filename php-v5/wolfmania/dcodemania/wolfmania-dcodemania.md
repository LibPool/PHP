# wolfmania/dcodemania

> 标签: curl, dcodemania, http, library, php, request, sahil kumar, wolfmania

## 简介

DcodeMania is a PHP library for making simple HTTP Requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
