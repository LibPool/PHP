# alexanderomara/flarum-gravatar

> 标签: avatar, flarum, gravatar, user

## 简介

Flarum Gravatar: Use Gravatar for user avatars

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
