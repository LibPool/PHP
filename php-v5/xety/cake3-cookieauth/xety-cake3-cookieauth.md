# xety/cake3-cookieauth

> 标签: auth, authenticate, cake3, cakephp, cookie, login, plugin

## 简介

A simple Cake3 plugin to authenticate users with Cookies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
