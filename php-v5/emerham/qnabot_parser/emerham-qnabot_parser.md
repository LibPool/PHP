# emerham/qnabot_parser

> 标签: PHP

## 简介

Parse the QnA Dump from Amazon's QnA Bot into a Spreadsheet for use in Botium Box.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
