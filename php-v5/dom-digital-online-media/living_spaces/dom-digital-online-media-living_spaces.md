# dom-digital-online-media/living_spaces

> 标签: PHP

## 简介

Distribution for user spaces (groups) that designed for extranet/intranet workflow.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
