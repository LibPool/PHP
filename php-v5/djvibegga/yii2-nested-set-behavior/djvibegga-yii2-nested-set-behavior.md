# djvibegga/yii2-nested-set-behavior

> 标签: Behavior, extension, nested set, yii

## 简介

This extension allows you to get functional for nested set trees.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
