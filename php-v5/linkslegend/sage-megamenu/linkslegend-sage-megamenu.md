# linkslegend/sage-megamenu

> 标签: bootstrap 4, iconmenu, navbar, navwalker, wordpress

## 简介

Bootstrap 4 Navbar component navwalker for Sage 9 based themes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
