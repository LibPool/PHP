# codemasher/php-ext-xz

> 标签: lzma2, php-extension, xz

## 简介

A PHP Extension providing xz (LZMA2) compression/decompression via PHP streams.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
