# mediastuttgart/guestbook-googleplus

> 标签: PHP

## 简介

A plugin for the SallyCMS guestbook addon, which fetches the latest Google+ activities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
