# mediastuttgart/oneclickonlinecontrol

> 标签: PHP

## 简介

An addOn for SallyCMS, adding oneclick on-/offline handling for articles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
