# mediastuttgart/varisale-realurl2

> 标签: PHP

## 简介

RealURL2 PlugIn for the SallyCMS AddOn varisale.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
