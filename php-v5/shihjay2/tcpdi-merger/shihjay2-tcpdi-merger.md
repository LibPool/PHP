# shihjay2/tcpdi-merger

> 标签: concatenate, merge, pdf

## 简介

PDF Importer that supports PDF versions 1.6+. Based on: https://github.com/pauln/tcpdi

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
