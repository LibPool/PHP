# riconet/t3-extension-fal-pois

> 标签: TYPO3 CMS, extension, fal, poi

## 简介

This extension extends file references by the possibility to add points of interests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
