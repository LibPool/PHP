# wanphp/plugins-oauth2-authorization

> 标签: authorization, oauth 2.0, wanphp-plugin

## 简介

OAuth 2.0 认证服务器扩展插件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
