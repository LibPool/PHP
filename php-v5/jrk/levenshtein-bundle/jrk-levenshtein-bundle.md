# jrk/levenshtein-bundle

> 标签: doctrine, levenshtein, search, soundex

## 简介

Levenshtein function bundle for symfony2 and doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
