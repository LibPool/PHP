# aretusa/flash-bundle

> 标签: ajax, flash messages, json

## 简介

This bundle extends the Symfony2 flash message system to handle messages for AJAX requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
