# weboftalent/responsive-mce-images

> 标签: images, responsive, silverstripe, tinymce, weboftalent

## 简介

Render images added to TinyMCE in a responsive manner

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
