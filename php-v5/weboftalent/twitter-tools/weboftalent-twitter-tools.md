# weboftalent/twitter-tools

> 标签: shortcode, silverstripe, twitter, twitter cards

## 简介

Embed tweets using shortcodes.  Optionally add Twitter cards to pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
