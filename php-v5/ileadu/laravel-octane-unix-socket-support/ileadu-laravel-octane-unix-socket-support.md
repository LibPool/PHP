# ileadu/laravel-octane-unix-socket-support

> 标签: laravel, octane, swoole

## 简介

Add support for UNIX socket in Octane Swoole server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
