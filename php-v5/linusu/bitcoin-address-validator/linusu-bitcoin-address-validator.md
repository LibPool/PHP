# linusu/bitcoin-address-validator

> 标签: address, bitcoin, validation, validator

## 简介

A simple, easy to use PHP Bitcoin address validator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
