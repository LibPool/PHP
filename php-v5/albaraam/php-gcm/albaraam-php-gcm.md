# albaraam/php-gcm

> 标签: gcm, php, php-gcm

## 简介

A PHP library for sending messages to devices registered through Google Cloud Messaging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
