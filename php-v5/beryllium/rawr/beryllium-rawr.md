# beryllium/rawr

> 标签: cr2, exif, exiftool, exiv, exiv2, photo, raw, rawr

## 简介

Image processing library for RAW/CR2 files, providing a wrapper for exiv2 and exiftool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
