# agmakonts/zf2-json-serializable-hydrator

> 标签: PHP

## 简介

ZF2 hydrator that allows for use of JsonSerialize method from JsonSerializable interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
