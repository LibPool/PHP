# mokhosh/laravel-youtube-api

> 标签: LaravelYoutubeApi, Youtube Api V3, Youtube Backup, Youtube Channel, Youtube LiveStream, Youtube Video, google api, laravel, mokhosh, oauth, php

## 简介

It is a wrapper over Youtube Api v3 which simplifies functionalities the laravel way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
