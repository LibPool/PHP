# maispace/assets

> 标签: PHP

## 简介

Intelligent asset pipeline for TYPO3 with critical CSS, SVG sprites, responsive images, font preloading, and self-optimising above-fold detection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
