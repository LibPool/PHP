# code-lives/kuaishou

> 标签: PHP

## 简介

快手小程序（支付、手机号解密、获取Token、模版消息、支付异步通知、退款、订单查询）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
