# code-lives/im

> 标签: PHP

## 简介

腾讯Im 加入聊天池 系统发送自定义消息 加入群组 创建群组 获取群成员列表 检测用户是否在加入Im 更改未读状态 拉取聊天记录 设置个人资料

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
