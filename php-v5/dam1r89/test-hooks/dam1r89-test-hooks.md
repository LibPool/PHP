# dam1r89/test-hooks

> 标签: PHP

## 简介

Creates a webhooks that make end to end or manual testing of Laravel apps easier. Allows creating db snapshots and changing app date.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
