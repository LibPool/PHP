# sabas/oauth1-openstreetmap

> 标签: OpenStreetMap, client, oauth, oauth1

## 简介

Openstreetmap OAuth 1.0 Client Provider for The PHP League OAuth1-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
