# xethron/l4-to-string

> 标签: convert, print_r, string

## 简介

Laravel 4 version of xethron/to-string, which adds query and queryLog to string functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
