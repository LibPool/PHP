# pkeogan/laravel-alpacajs

> 标签: alpaca, alpacajs, laravel

## 简介

A package to build AlpacaJS forms via Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
