# eschrade/zf2-query-auth

> 标签: PHP

## 简介

A simple class that wraps the ZF2 request object so it can be used with jeremykendall/query-auth

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
