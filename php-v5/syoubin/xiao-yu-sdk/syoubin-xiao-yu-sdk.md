# syoubin/xiao-yu-sdk

> 标签: sdk, 云视频, 小鱼易连

## 简介

小鱼易连云端REST接口的PHP实现

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
