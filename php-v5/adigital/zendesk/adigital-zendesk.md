# adigital/zendesk

> 标签: Craft, Zendesk, cms, craft-plugin, craftcms

## 简介

Creates a new support ticket in Zendesk using the JSON API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
