# dotsunited-wordpress-plugin/responsify

> 标签: iframe, plugin, responsive, table, wordpress

## 简介

Automagically responsify HTML elements like iframe's and table's.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
