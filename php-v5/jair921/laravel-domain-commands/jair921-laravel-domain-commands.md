# jair921/laravel-domain-commands

> 标签: PHP

## 简介

Artisan commands to Laravel apps that utilizes Domain Driven Design. Based on notiv/laravel-domain-commands

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
