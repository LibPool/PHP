# nblakefriend/mailchimp-apiv3

> 标签: api, mailchimp, php

## 简介

Complete PHP Wrapper for MailChimp API v3.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
