# code-orange/jot

> 标签: documentation, laravel, phpdoc

## 简介

Laravel package that generates RESTful API documentation in Markdown based on PHPDoc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
