# qambar/datetimepicker-bundle

> 标签: bootstrap, bundle, datepicker, picker, symfony, timepicker

## 简介

Symfony bundle for Bootstrap DateTime picker

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
