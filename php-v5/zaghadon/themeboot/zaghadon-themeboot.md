# zaghadon/themeboot

> 标签: cli, command-line, template, theme, wordpress, wp

## 简介

A Free and OpenSource Lightweight CLI app to bootstrap WordPress Theme Development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
