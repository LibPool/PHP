# ghoster/better-boolean-attribute

> 标签: PHP

## 简介

Change default look of boolean attribute Magento 2 frontend: Yes - No to ✔️ - ❌

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
