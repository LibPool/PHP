# mottie/keyboard

> 标签: accessibility, customizable, jquery-plugin, keyboard, osk, ui

## 简介

A jQuery on-screen keyboard (OSK) plugin that works in the browser.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
