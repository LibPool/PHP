# carloswph/wp-secure-headers

> 标签: content security policy, csp, headers, http headers, https, secure headers, security, security headers, strict transport

## 简介

Add and configure HTTP secure headers and more, for Wordpress websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
