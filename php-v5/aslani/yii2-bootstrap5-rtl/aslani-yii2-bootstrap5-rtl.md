# aslani/yii2-bootstrap5-rtl

> 标签: asset-bundle, bootstrap, bootstrap5, rtl, yii2

## 简介

Twitter Bootstrap 5 RTL extension for the Yii 2.0 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
