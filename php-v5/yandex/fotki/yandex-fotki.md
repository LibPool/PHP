# yandex/fotki

> 标签: api, fotki, yandex

## 简介

PHP-library for interactions with Yandex.Fotki / PHP реализация API для работы с сервисом Яндекс.Фотки

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
