# fdevs/css-fixer-bundle

> 标签: Code style, css, csscomb, fdevs

## 简介

Allows you to check if .css files follow general rules and convention or fix them

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
