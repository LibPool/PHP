# roboticsexpert/laravel-stapler

> 标签: aws, file, laravel, paperclip, s3, stapler, upload

## 简介

Easy file upload management for the Laravel Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
