# scandio/troba

> 标签: database, db, dbal, library, mysql, orm, pdo, php, scandio, sqlite

## 简介

troba is a easy to use and extensible PHP (5.4) entity and query manager based on PDO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
