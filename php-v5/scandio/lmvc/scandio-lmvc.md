# scandio/lmvc

> 标签: library, mvc, php, scandio

## 简介

LMVC is an easy-to-use and extensible PHP (5.3) MVC framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
