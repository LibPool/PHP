# svikramjeet/laravel-pdf

> 标签: laravel, laravel4, pdf, wkhtmltopdf

## 简介

Provides the HTML2PDF functionality using the wkhtmltopdf library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
