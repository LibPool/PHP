# fourmation/mongo

> 标签: dbabstract, framework, mongo, mongodb, zf2, zfcommons

## 简介

MongoDB Abstract based on zfCommons

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- PHP 要求：>=5.3.3
