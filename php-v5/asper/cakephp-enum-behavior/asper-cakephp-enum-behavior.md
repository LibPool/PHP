# asper/cakephp-enum-behavior

> 标签: Behavior, cakephp, enum

## 简介

Introduces an alternative way to support some ENUM types in CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
