# wernerwa/pat-template

> 标签: PHP

## 简介

patTemplate is a powerful, non-compiling templating engine, that uses XML tags to divide a document into different parts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
