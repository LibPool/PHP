# webprofil/wp-directmailreturn

> 标签: PHP

## 简介

Bounced Email manager. direct_mail return mail analysis without fetchmail installed (uses php imap functions)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
