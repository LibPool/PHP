# kubrey/geoservice

> 标签: free geo location, geoip, geolocation, ip service, ipgeobase, ipgeobase.ru

## 简介

Geolocation module using multiple free geo services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
