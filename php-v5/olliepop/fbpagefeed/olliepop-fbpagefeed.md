# olliepop/fbpagefeed

> 标签: PHP

## 简介

Retrieves posts from a Facebook page for a SilverStripe site, pulling posts and storing them via CliController task

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
