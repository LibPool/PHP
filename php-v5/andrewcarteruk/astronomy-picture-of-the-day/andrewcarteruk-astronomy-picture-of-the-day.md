# andrewcarteruk/astronomy-picture-of-the-day

> 标签: PHP

## 简介

A wrapper for the Astronomy Picture of the Day API provided by NASA.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
