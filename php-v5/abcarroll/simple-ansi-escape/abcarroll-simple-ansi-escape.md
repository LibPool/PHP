# abcarroll/simple-ansi-escape

> 标签: ansi, php-cli

## 简介

Intuitively use ANSI escape sequences to add color and formatting to your php-cli scripts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
