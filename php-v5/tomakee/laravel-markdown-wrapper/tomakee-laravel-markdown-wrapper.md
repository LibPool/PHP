# tomakee/laravel-markdown-wrapper

> 标签: extensible, laravel, markdown, markdown-extra

## 简介

Simple Laravel wrapper class for markdown parser.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
