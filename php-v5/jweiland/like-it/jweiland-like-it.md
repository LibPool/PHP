# jweiland/like-it

> 标签: Simple, TYPO3 CMS, like, typo3

## 简介

Like nearly any frontend content thanks to a custom view helper. No login required.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
