# goma/goma-test-core

> 标签: PHP

## 简介

GomaUnitTest is a wrapper class to support PHP 5 and PHP 7 for tests. In addition it gives some helper asserts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
