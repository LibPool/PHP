# nessworthy/decasteljau

> 标签: PHP

## 简介

A stupid way of using De Casteljau's algorithm to calculate control points of a segment in a cubic bezier curve.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
