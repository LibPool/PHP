# bogdananton/mysql-to-object-mapper

> 标签: PHP

## 简介

MySQL-to-object-mapper outputs PHP objects from SQL dumps or servers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
