# schmiddim/mvg-package

> 标签: PHP

## 简介

mvg-package is an API Wrapper for fetching infos from the MVV public transportation network in munich.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
