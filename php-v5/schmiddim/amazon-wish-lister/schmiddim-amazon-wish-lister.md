# schmiddim/amazon-wish-lister

> 标签: amazon, csv, export, wishlist

## 简介

Simple script that parses a public amazon wishlist and export the items to a CSV file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
