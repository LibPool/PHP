# schmiddim/mvcauth-api-key

> 标签: Api Key, apigility, module, mvc-auth, zf2

## 简介

ZF2 Module providing API Key Authentication for MvcAuth

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
