# reolservices/cloudflare

> 标签: cloudflare v1

## 简介

A Yii2 extension to communicate with CloudFlare API V1 and manage DNS records

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
