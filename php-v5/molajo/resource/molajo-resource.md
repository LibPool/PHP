# molajo/resource

> 标签: loader, psr-0

## 简介

Molajo Loader: Loads filesystem resources like Classes, Asset Media, and Model definitions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
