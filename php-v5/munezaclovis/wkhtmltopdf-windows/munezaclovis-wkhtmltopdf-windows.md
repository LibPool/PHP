# munezaclovis/wkhtmltopdf-windows

> 标签: binary, convert, htmltoimage, htmltopdf, pdf, snapshot, thumbnail, wkhtmltopdf

## 简介

Convert html to pdf and image format using webkit using windows binaries for 32 bit and 64 bit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
