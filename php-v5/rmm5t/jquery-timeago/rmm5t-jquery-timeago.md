# rmm5t/jquery-timeago

> 标签: microformat, time

## 简介

jQuery plugin that makes it easy to support automatically updating fuzzy timestamps (e.g. "4 minutes ago" or "about 1 day ago").

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
