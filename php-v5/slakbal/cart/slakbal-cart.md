# slakbal/cart

> 标签: laravel, shoppingcart

## 简介

Shoppingcart fork for Laravel that allows zero (0) quantity for an item in the cart

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
