# lummy/laravel-vue-api-crud-generator

> 标签: PHP

## 简介

Creates a basic skeleton for a CRUD app in both Laravel & Vue.js single file components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
