# tr8n/tr8n-client-sdk

> 标签: i18n, internationalization, l10n, localization, t9n, tr8n, translation

## 简介

Translation framework for PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
