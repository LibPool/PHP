# php-stubs/wp-cli-stubs

> 标签: PHPStan, static analysis, wordpress, wp-cli

## 简介

WP-CLI function and class declaration stubs for static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
