# nadialabs/yii2-elasticsearch-odm

> 标签: ELK, elastic, elasticsearch, yii2

## 简介

An integration of ElasticsearchODM for Yii2 frameworks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
