# discoverygarden/islandora_iiif_presentation_api

> 标签: PHP

## 简介

Provides metadata and canvas information for IIIF Presentation API manifests in Drupal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
