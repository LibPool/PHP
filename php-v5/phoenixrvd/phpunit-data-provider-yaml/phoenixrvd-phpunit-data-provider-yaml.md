# phoenixrvd/phpunit-data-provider-yaml

> 标签: PHP

## 简介

Allow to use YAML, JSON or PHP files to storing a data for PHP-Unit-DataProviders

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
