# joserick/phplex

> 标签: api, media, plex

## 简介

A PHP library for interacting with the Plex (https://www.plex.tv) HTTP Control API. (forked from https://github.com/joserick/phplex)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
