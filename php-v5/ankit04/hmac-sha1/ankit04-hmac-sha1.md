# ankit04/hmac-sha1

> 标签: PHP

## 简介

This is Larvel package that gives you the accessibility and reliability to make things hashed using HMAC-SHA1 algorithms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
