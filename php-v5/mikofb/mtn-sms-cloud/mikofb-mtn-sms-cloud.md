# mikofb/mtn-sms-cloud

> 标签: PHP

## 简介

Lavarel package for performing sms campaigns using the MTN SMS CLOUD service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
