# pipecraft/flarum-ext-id-slug

> 标签: flarum, slug, slug-driver

## 简介

A Flarum extension. Use id as slug in discussion URL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
