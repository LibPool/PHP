# chasegiunta/youtube-downloader

> 标签: download youtube, download youtube videos, youtube downloader

## 简介

PHP powered alternative for youtube-dl

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
