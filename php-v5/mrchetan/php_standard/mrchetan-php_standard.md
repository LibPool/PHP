> 标签: coding-standard, devanox, laravel, mrchetan, php, php-code-sniffer, phpcs, phpcs-ruleset, phpcs-standard, phpcs-standard-laravel

## 简介

PHP coding standard to be followed in Laravel projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
