# arkadedigital/country-list

> 标签: PHP

## 简介

Comprehensive list of all country names and ISO 3166-1 codes for Laravel and Lumen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
