# clarity-project/cdn-bundle

> 标签: Symfony2, cdn, php, symfony

## 简介

Symfony2 bundle for file storage on local or remote cdn

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
