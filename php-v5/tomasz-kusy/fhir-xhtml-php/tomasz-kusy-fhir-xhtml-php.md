# tomasz-kusy/fhir-xhtml-php

> 标签: PHP

## 简介

PHP representation of http://www.w3.org/1999/xhtml namespace. Contains only part allowed by FHIR

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
