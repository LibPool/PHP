# suny-upstate-cwt/phpmailerqol

> 标签: PHP

## 简介

PHPMailerQOL is a non-intrusive quality-of-life extension of PHPMailer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
