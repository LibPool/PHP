# ibonly/laravel-ngplaces

> 标签: Nigeria, cities, github, ibonly, laravel, laravel-ngplaces, ng-places, ngplaces, open source, php, states, verem

## 简介

A laravel app that is built on ng-places api, it provides places in Nigeria like state, lga, city, bank, market etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
