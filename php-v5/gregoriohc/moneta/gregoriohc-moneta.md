# gregoriohc/moneta

> 标签: gregoriohc, moneta

## 简介

A framework agnostic, multi-gateway payment processing library for PHP 7.0+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
