# eminos/statamic-set-header-toggle

> 标签: PHP

## 简介

A Statamic addon to be able to add extra mini toggles to replicator and bard set headers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
