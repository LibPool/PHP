# vkr/settings-bundle

> 标签: Settings, Symfony2, configuration, symfony3

## 简介

A bundle for Symfony2/3 that simplifies retrieving settings from config files and Doctrine entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
