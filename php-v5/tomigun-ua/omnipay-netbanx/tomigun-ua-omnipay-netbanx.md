# tomigun-ua/omnipay-netbanx

> 标签: gateway, merchant, netbanx, omnipay, pay, payment

## 简介

NetBanx driver for the Omnipay 3.0 payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
