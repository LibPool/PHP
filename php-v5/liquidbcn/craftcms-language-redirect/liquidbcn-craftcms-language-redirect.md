# liquidbcn/craftcms-language-redirect

> 标签: Craft, cms, craft-plugin, rate limit

## 简介

Simple language redirector based on browser preferences

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
