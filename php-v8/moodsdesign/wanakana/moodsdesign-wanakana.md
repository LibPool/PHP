# moodsdesign/wanakana

> 标签: hiragana, ime, japanese, kana, katakana, romaji

## 简介

JS library for Japanese input and kana/romaji conversion

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
