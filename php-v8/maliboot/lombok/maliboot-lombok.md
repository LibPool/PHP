# maliboot/lombok

> 标签: Maliboot, hyperf, lombok, php, swoole

## 简介

这是一个通过注解来减少`重复代码`的工具。本插件参考了[Java库-Lombok](https://projectlombok.org/)奇思妙想编写而成。实现了setter、getter、日志、类委托、属性委托、常用的工具类方法注解等....

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
