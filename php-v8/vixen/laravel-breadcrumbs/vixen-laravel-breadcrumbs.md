# vixen/laravel-breadcrumbs

> 标签: blade, breadcrumbs, inertia, laravel, navigation

## 简介

A simple breadcrumbs package for Laravel, with support for Blade and Inertia.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
