# caspahouzer/lemonsqueezy-api-client

> 标签: JSON-API, PSR-4, api, client, lemonsqueezy, psr-18, psr-7

## 简介

PSR-4 compliant PHP API client for LemonSqueezy REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
