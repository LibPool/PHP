# wb-crowdfusion/tarzan-api

> 标签: PHP

## 简介

Tarzan is a fast, powerful PHP toolkit for building web applications with Amazon Web Services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
