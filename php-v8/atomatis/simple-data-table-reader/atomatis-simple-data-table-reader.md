# atomatis/simple-data-table-reader

> 标签: csv, data table, file, reader, xlsx

## 简介

For easily parse basic data table files (xlsx, csv, ...).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
