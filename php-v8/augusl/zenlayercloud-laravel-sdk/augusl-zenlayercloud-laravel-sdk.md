# augusl/zenlayercloud-laravel-sdk

> 标签: cloud, ip-transit, ipt, laravel, sdk, vm, zec, zenlayer, zenlayercloud

## 简介

Laravel SDK for Zenlayer Cloud — Virtual Machine (VM), IP Transit (IPT), and Elastic Compute (ZEC) services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
