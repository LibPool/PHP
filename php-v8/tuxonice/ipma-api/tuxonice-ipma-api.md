# tuxonice/ipma-api

> 标签: API-Client, forecast, ipma, portugal, weather

## 简介

PHP Package to manage IPMA API (https://api.ipma.pt/)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
