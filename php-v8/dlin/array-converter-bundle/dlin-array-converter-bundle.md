# dlin/array-converter-bundle

> 标签: array, fromArray, serialize, toArray

## 简介

A Symfony2 Bundle supporting Object/Array conversion using annotation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
