# dlin/zendesk-bundle

> 标签: Zendesk, symfony

## 简介

A Syfmony 2 Bundle for Dlin Zendesk client library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
