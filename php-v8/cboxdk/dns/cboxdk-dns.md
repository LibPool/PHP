# cboxdk/dns

> 标签: DNSSEC, authoritative, caa, cname, dane, delegation, dig, dkim, dmarc, dns, dns-diagnostics, dns-over-https, dns-resolver, dns-trace, doh, domain-verification, https-record, idn, intodns, mxtoolbox, networking, php, propagation, ptr, punycode, resolver, reverse-dns, spf, sshfp, svcb, tlsa

## 简介

Zero-dependency raw PHP DNS resolver, domain-ownership verification, and intoDNS/MxToolbox-style diagnostics. Queries authoritative nameservers directly over sockets — never trusts the recursive cache for ownership checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
