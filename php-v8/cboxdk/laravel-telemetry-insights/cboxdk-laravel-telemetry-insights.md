# cboxdk/laravel-telemetry-insights

> 标签: alerting, cbox, incidents, issues, laravel, observability, root-cause, telemetry

## 简介

Stateful insights on top of cboxdk/laravel-telemetry-ui: deduplicated issues, incident correlation across error groups, alerting and periodic digests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
