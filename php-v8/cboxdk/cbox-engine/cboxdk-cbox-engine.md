# cboxdk/cbox-engine

> 标签: cbox, developer-experience, docker, gateway-api, kind, kubernetes, laravel, local-development, paas, platform, preview-environments, scale-to-zero

## 简介

The engine behind the cbox CLI and the Cbox Local desktop app — one local Kubernetes cluster running an application the way production does.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
