# cboxdk/telemetry-native

> 标签: cbox, extension, observability, profiler, profiling, telemetry

## 简介

Deep PHP runtime telemetry for the Cbox stack: statistical CPU profiling, native operation timing, runtime counters and crash breadcrumbs. Optional companion to cboxdk/laravel-telemetry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
