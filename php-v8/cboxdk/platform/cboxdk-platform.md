# cboxdk/platform

> 标签: autoscaling, cbox, compiler, deployment, diff, gateway-api, internal-developer-platform, kubernetes, manifests, paas, plan, platform, platform-engineering, scale-to-zero

## 简介

Cbox Platform — the typed application model, deterministic Kubernetes compiler, and plan/diff primitives shared by Cbox Local and Cbox Cortex.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
