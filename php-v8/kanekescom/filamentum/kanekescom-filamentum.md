# kanekescom/filamentum

> 标签: filament, filamentum, framework, kanekescom, laravel, starter-kit

## 简介

Filamentum is a Laravel starter kit with Filament admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
