# foundry-co/laravel-snowflake

> 标签: database, driver, eloquent, laravel, snowflake

## 简介

Snowflake database driver for Laravel using REST API - no PDO extension required

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
