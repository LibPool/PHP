# foundry-co/tableau-api

> 标签: Guzzle, laravel, rest-api, sdk, tableau

## 简介

A framework-agnostic PHP client for the Tableau Server / Tableau Cloud REST API, built on Guzzle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
