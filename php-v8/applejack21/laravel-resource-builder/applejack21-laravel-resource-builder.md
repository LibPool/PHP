> 标签: Policy, artisan, code-generation, controller-generator, crud, crud-generator, form-request, laravel, laravel-generator, laravel-package, laravel-scaffolding, resource

## 简介

A Laravel package that generates action, controller, policy, and request files for the specified model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
