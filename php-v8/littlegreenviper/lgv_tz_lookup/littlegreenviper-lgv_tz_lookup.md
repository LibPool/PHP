# littlegreenviper/lgv_tz_lookup

> 标签: geocode, geojson, timezone, tz

## 简介

Look up IANA time zones from longitude and latitude using a preloaded MySQL or PostgreSQL boundary database.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
