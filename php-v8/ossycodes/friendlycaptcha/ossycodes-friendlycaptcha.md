# ossycodes/friendlycaptcha

> 标签: captcha, friendlycaptcha, laravel

## 简介

A simple package to help integrate FriendlyCaptcha in your Laravel applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
