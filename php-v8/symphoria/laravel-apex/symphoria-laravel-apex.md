# symphoria/laravel-apex

> 标签: laravel, queue, supervisor, symphoria, workers

## 简介

Queue worker supervisor with scale-to-zero, activity-aware warm pools and boot-storm prevention.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
