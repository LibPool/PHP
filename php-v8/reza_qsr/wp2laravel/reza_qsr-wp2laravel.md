# reza_qsr/wp2laravel

> 标签: PHP

## 简介

A Laravel package that provides WordPress-like functions and utilities to simplify migrating or adapting WordPress projects to Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
