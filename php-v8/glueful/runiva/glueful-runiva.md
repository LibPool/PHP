# glueful/runiva

> 标签: frankenphp, roadrunner, runtime, server, swoole

## 简介

Runiva: Server runtime integration for Glueful (RoadRunner, Swoole, FrankenPHP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
