# glueful/thallo-search

> 标签: PHP

## 简介

Search for Thallo: a public, delivery-parity content search API over Postgres full-text search or Meilisearch, as a removable capability pack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
