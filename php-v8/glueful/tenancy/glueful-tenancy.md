# glueful/tenancy

> 标签: glueful, multi-tenancy, row-level, tenancy

## 简介

Shared-database, row-level multi-tenancy for Glueful (tenant resolution, scoping, enforcement).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
