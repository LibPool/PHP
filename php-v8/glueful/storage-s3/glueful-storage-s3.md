# glueful/storage-s3

> 标签: Flysystem, glueful, minio, r2, s3, spaces, storage, wasabi

## 简介

AWS S3 and S3-compatible storage driver for the Glueful framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
