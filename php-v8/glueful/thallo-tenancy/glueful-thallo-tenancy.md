# glueful/thallo-tenancy

> 标签: PHP

## 简介

Multi-tenancy foundation for Thallo: tenant-owned schema, scoping, seed/sync and enablement as a capability pack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
