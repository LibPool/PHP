# phpclaw/phpclaw-magento

> 标签: Agent, adobe-commerce, ai, anthropic, llm, magento, openai, phpclaw

## 简介

phpClaw adapter for Magento 2 / Adobe Commerce. Module, CLI command, ResourceConnection memory.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
