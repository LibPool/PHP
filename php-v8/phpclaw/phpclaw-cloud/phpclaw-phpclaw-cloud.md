# phpclaw/phpclaw-cloud

> 标签: Agent, ai, cloud, phpclaw

## 简介

phpClaw Cloud transport. Wildcard hook listener, payload builder, and HTTP client for the phpClaw Cloud service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
