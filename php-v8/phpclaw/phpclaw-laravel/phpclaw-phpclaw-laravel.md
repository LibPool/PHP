# phpclaw/phpclaw-laravel

> 标签: Agent, ai, anthropic, laravel, llm, openai, phpclaw

## 简介

phpClaw adapter for Laravel. Add AI agents to any Laravel app with a single composer require.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
