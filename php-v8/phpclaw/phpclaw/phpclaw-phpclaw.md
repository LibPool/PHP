> 标签: Agent, Gemini, ai, ai-agent, ai-agent-framework, anthropic, claw, groq, llm, openai, php, phpclaw, tool-calling

## 简介

phpClaw: open-source AI agent framework for PHP. Tool-calling agent loop, memory and security guards, with any LLM provider. No framework dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
