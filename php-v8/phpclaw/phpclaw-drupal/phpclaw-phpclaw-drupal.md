# phpclaw/phpclaw-drupal

> 标签: Agent, Drupal10, Drush, ai, anthropic, drupal, drupal11, llm, ollama, openai, phpclaw, tools

## 简介

phpClaw adapter for Drupal 10/11. Module, Drush commands, admin UI, 22 tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
