# biplane/yandex-direct

> 标签: sdk, yandex, yandex.direct, Яндекс.Директ

## 简介

PHP library for Yandex.Direct API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
