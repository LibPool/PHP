# sgrodzicki/clicktale

> 标签: ClickTale

## 简介

PHP integration module for ClickTale

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://wiki.clicktale.com/Article/PHP_integration_module
- 源码仓库：https://github.com/sgrodzicki/ClickTale.git
- Packagist 页面：https://packagist.org/packages/sgrodzicki%2Fclicktale
