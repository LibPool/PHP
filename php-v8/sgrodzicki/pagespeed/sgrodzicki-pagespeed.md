# sgrodzicki/pagespeed

> 标签: Insights, PageSpeed, api, google

## 简介

A PHP library to interact with the PageSpeed Insights API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
