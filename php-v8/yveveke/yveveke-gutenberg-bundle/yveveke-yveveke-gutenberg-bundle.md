# yveveke/yveveke-gutenberg-bundle

> 标签: easyadmin, editor, flexible-content, symfony

## 简介

A Symfony bundle for EasyAdmin that provide a flexible content editor

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
