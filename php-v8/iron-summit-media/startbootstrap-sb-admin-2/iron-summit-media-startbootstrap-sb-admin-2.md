# iron-summit-media/startbootstrap-sb-admin-2

> 标签: PHP

## 简介

SB Admin 2 is an open source, admin dashboard template for Bootstrap created by Start Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
