# shufo/laravel-opensearch

> 标签: client, laravel, opensearch, search

## 简介

An easy way to use the official PHP OpenSearch client in your Laravel applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
