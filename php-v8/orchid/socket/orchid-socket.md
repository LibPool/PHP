# orchid/socket

> 标签: Ratchet, Socket, framework, laravel, php, server, web, websocket

## 简介

Laravel library for asynchronously serving WebSockets.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
