# bnussbau/epaper-pipeline-php

> 标签: bnussbau, e-paper, epaper, epaper-pipeline-php

## 简介

Convert HTML content into optimized images for a range of e-paper devices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
