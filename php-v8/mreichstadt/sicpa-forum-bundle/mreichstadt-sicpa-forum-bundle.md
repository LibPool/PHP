# mreichstadt/sicpa-forum-bundle

> 标签: PHP

## 简介

SicpaForumBundle Symfony 7 inrae cati/sicpa avec catégories, sujets, messages, pagination, recherche et administration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
