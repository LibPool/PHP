# eurekos/symfony-messenger-monitor

> 标签: Messenger, bundle, monitor, queue, symfony

## 简介

A simple Symfony bundle to view the current Messenger queue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
