# eurekos/symfony-monolog-viewer

> 标签: Viewer, bundle, logs, monolog, symfony

## 简介

A simple Symfony bundle to view Monolog log files in the browser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
