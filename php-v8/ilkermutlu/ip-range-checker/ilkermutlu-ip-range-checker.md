# ilkermutlu/ip-range-checker

> 标签: IP, check, ip address, range

## 简介

This package is a little helper to check if a given IP address is in a certain IP range.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
