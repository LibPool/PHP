# konnektiv/badgeos-timelimit-add-on

> 标签: PHP

## 简介

This BadgeOS add-on adds the ability to limit achievement rewarding per time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
