# seerbit/magento2-module

> 标签: Online banking, creditcard, debitcard, global payment gateway, magento, magento 2, mobile money, payment, payment gateway, seerbit

## 简介

Official Magento2 package for SeerBit payment gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
