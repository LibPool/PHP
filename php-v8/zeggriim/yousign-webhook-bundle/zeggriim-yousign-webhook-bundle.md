# zeggriim/yousign-webhook-bundle

> 标签: bundle, remote-event, symfony, webhook, yousign

## 简介

A Symfony bridge for handling Yousign webhooks via RemoteEvent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
