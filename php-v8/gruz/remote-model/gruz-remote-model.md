# gruz/remote-model

> 标签: api, custom models, eloquent, laravel, model, remote data

## 简介

An eloquent-like model, for the Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
