# coldtrick/mmenu

> 标签: elgg, menu, plugin, theme

## 简介

Replaces topbar site menu items with a mobile like sidebar menu

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
