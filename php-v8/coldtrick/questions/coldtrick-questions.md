# coldtrick/questions

> 标签: elgg, plugin

## 简介

Q&A functionality analogous to Quora, Stack Overflow, or Facebook Questions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
