# coldtrick/breadcrumb_menu

> 标签: elgg, menu, navigation, plugin

## 简介

Moves the ownerblock menu items into the breadcrumb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
