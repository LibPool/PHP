# elgibor-solution/laravel-whatsapp-meta

> 标签: PHP

## 简介

Laravel package for Meta WhatsApp Business Cloud API: templates CRUD, sending messages, multi-account, broadcasts, webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
