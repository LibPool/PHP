# elgibor-solution/laravel-payment-bca

> 标签: PHP

## 简介

Laravel package for BCA OpenAPI Virtual Account (Inquiry, Payment Flag, Status) with caching and signatures.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
