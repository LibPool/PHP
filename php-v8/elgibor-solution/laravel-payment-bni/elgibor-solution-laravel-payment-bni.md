# elgibor-solution/laravel-payment-bni

> 标签: PHP

## 简介

Laravel package for BNI eCollection (VA) & QRIS with auditing, granular errors, tests & Postman.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
