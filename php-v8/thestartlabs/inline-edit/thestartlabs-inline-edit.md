# thestartlabs/inline-edit

> 标签: acf, inline-editing, page-builder, timber, wordpress

## 简介

Front-end editing for Timber and ACF sites: change text and images on the page, and add, move and remove page builder blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
