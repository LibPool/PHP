# alexlis/yii2-bootstrap-colorpicker

> 标签: colorpicker, extension, widget

## 简介

Bootstrap colorpicker widget for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
