# bmvc/bmvc

> 标签: api-rest, cli, framework, français, i18n, mvc, orm, php, routing

## 简介

Framework web moderne et professionnel 100% en français - MVC avec CLI, i18n, API REST et Tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
