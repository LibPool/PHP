# mecha-cms/x.minify

> 标签: PHP

## 简介

Reduces CSS, HTML, JavaScript, JSON, PHP, and XML code size on the server side.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
