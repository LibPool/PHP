# afk11/ecssh

> 标签: ECDSA, deploy, git, github, phpecc, ssh

## 简介

Utility to manage elliptic curve ssh keys

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
