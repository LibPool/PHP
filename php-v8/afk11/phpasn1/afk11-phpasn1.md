# afk11/phpasn1

> 标签: PHP

## 简介

A PHP Framework that allows you to encode and decode arbitrary ASN.1 structures using the ITU-T X.690 Encoding Rules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
