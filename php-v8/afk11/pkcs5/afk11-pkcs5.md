# afk11/pkcs5

> 标签: ECDSA, aes, derivation, encryption, key, pbkdf2, pkcs5

## 简介

Library for PKCS5 v2 key derivation & and message encryption

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
