# tribepeer/sdk

> 标签: ai-learning, digital-education, e-campus, e-library, lms, training, tribepeer

## 简介

TribePeer client for digital education — e-campus, training centres, e-library, and AI-powered learning. Server keys stay on the server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
