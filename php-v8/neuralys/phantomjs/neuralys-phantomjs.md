# neuralys/phantomjs

> 标签: PHP

## 简介

PhantomJS binaries to work with Packagist

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://packagist.org/packages/neuralys%2Fphantomjs
- 源码仓库：https://github.com/neuralys/phantomjs.git
- Packagist 页面：https://packagist.org/packages/neuralys%2Fphantomjs
