# akim-bow/guzzle-proxy-handler

> 标签: PHP

## 简介

Middleware for GuzzleHTTP, allowing easy use of multiple proxy configs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
