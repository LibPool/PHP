# rconfig/laravel-zabbix

> 标签: api, client, fluent, json-rpc, laravel, monitoring, zabbix

## 简介

Laravel-first Zabbix JSON-RPC API client with fluent, testable DX.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
