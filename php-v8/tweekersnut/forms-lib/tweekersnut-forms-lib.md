# tweekersnut/forms-lib

> 标签: PHP

## 简介

A comprehensive PHP forms library for Laravel and Core PHP with Bootstrap/Tailwind support, AJAX handling, and validation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
