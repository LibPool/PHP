# mg-code/yii2-filters

> 标签: Behavior, ajax, extension, filter, yii2

## 简介

A collection of useful filters for Yii framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
