# rayzenai/project-management

> 标签: PHP

## 简介

Project & task tracking workspace (projects, tasks, subtasks, assignments, notes, contacts) for Laravel + Inertia applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
