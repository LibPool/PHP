# rayzenai/file-manager

> 标签: filamentphp, file-manager, kirantimsina, laravel

## 简介

This is FileHandling package to be used with FilamentPHP/Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
