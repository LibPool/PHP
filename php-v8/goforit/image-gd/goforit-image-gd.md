# goforit/image-gd

> 标签: crop, gd, image, php8, resize, thumpnail, watermark

## 简介

PHP8 Image processing library, based on DDD and SOLID design principles.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
