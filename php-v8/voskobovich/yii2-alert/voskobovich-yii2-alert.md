# voskobovich/yii2-alert

> 标签: alert, flash, helper, message, toolkit, widget, yii2

## 简介

Toolkit to manage the flash messages for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
