# voskobovich/yii2-tree-manager

> 标签: editor, nestable, nested sets, widget, yii2

## 简介

Tree Manager using jquery.nestable plugin for Yii 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
