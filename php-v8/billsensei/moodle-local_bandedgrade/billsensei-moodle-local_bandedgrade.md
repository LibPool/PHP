# billsensei/moodle-local_bandedgrade

> 标签: PHP

## 简介

Moodle plugin that scores a quiz by the number of fully correct questions, mapped through teacher-defined bands, and writes the score to its own gradebook item.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
