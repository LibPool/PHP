# billsensei/moodle-tiny_fontsizecolor

> 标签: PHP

## 简介

TinyMCE plugin for Moodle that adds font size and font colour buttons and menu items, with admin-configurable lists.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
