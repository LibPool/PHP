# slipstream/slipstream

> 标签: deploy, envoyer, laravel, webhook, zero-downtime

## 简介

Open-source zero-downtime deploy platform for Laravel (Envoyer-style, no SSH)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
