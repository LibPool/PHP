# phpextra/event-manager

> 标签: event, event manager, listener, observer, phpextra, psr, psr-0

## 简介

Event manager based on reflection, annotations and priority queue

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
