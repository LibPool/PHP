# rubenmartindev/prestashop-module-installer

> 标签: configuration, database, hooks, install, modules, prestashop, tabs, uninstall

## 简介

Install and uninstall helpers for PrestaShop modules (hooks, configuration, database and tabs)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
