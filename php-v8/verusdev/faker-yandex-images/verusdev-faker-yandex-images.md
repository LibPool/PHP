# verusdev/faker-yandex-images

> 标签: crm, faker, images, photos, provider, seeder, yandex

## 简介

Faker provider that fills projects with real images found on Yandex.Images by search phrase (e.g. 'bmw x5') — downloads them locally and returns file paths. Ideal for seeding CRM photos.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
