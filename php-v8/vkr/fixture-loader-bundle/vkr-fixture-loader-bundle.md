# vkr/fixture-loader-bundle

> 标签: Symfony2, doctrine, fixtures, mysql, symfony3

## 简介

A bundle for Symfony2/3 that adds loading mechanisms for MySQL Doctrine fixtures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
