# vkr/s3-uploader-bundle

> 标签: Symfony2, amazon, aws, s3, symfony3

## 简介

A bundle for Symfony2/3 that handles file uploads to Amazon S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
