# jonston/symfony-sanctum-bundle

> 标签: Authentication, api, sanctum, symfony, token

## 简介

Простая token-based аутентификация для Symfony, вдохновленная Laravel Sanctum. Обеспечивает легкую аутентификацию через API токены без сложностей OAuth.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
