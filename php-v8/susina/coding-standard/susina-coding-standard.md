# susina/coding-standard

> 标签: Code style, Coding Standard, PSR-1, php-cs-fixer, psr-12

## 简介

Shared config for php-cs-fixer, based on PSR1 and PSR2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
