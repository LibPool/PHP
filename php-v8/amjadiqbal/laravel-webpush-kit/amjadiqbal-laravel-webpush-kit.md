# amjadiqbal/laravel-webpush-kit

> 标签: WebPush, amjadiqbal, blade, browser-notifications, declarative-web-push, ios, laravel, laravel-package, livewire, notifications, push-notifications, pwa, service-worker, vapid, web-push

## 简介

The browser side of Laravel web push notifications for laravel-notification-channels/webpush: a Blade and Livewire subscribe button with a polite two-step permission prompt, a service worker, routes that save and delete push subscriptions, iOS Home Screen guidance, declarative web push, and a push:test artisan command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
