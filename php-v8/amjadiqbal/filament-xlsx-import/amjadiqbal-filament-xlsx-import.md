# amjadiqbal/filament-xlsx-import

> 标签: excel, filament, filament-plugin, filamentphp, import, laravel, ods, openspout, spreadsheet, xlsx

## 简介

Excel (.xlsx) and OpenDocument (.ods) files in Filament's core ImportAction, with your existing Importer classes. Filament 4 and 5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
