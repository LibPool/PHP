# amjadiqbal/laravel-sonner

> 标签: alerts, alpinejs, blade, flash-messages, laravel, laravel-package, livewire, notifications, sonner, toast, toast-notifications, toaster, ui

## 简介

Sonner toast notifications for Laravel without React: flash toasts from PHP with toast()->success(), show them with a Blade component, and toast from Livewire, Alpine or JavaScript with Sonner's real styles and animations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
