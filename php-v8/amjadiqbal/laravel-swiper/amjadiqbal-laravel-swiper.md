# amjadiqbal/laravel-swiper

> 标签: accessibility, blade, blade-components, carousel, image-gallery, image-slider, laravel, laravel-package, livewire, responsive-images, slider, swiper, swiperjs, thumbnail-gallery, wire-navigate

## 简介

Swiper sliders and carousels for Laravel: Blade components with typed props for navigation, pagination, thumbs, autoplay and lazy loading; Livewire-safe (survives updates and wire:navigate); slides from Eloquent models, Spatie Media Library or a storage disk folder, with responsive images and accessible defaults.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
