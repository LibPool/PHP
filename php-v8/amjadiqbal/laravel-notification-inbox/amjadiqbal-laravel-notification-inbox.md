# amjadiqbal/laravel-notification-inbox

> 标签: FCM, amjadiqbal, discord, laravel, laravel-notifications, laravel-package, microsoft-teams, notification-catcher, notification-channels, notifications, push-notifications, slack, sms, telegram, testing, web-push

## 简介

Catch every non-mail Laravel notification in local and staging instead of sending it: web push, FCM, APNs, Expo, Slack, Microsoft Teams, Telegram, Discord, Twilio and Vonage SMS, and broadcast. Realistic previews in one inbox, plus test assertions on the real payloads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
