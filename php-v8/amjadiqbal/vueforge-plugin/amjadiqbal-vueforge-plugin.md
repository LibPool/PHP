# amjadiqbal/vueforge-plugin

> 标签: backend, form widget, october cms, vue, vue3

## 简介

The rapid Vue 3 component & widget engine for October CMS backend interfaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
