# amjadiqbal/laravel-ninja-keys

> 标签: blade, cmd-k, command-menu, command-palette, hotkeys, keyboard-shortcuts, laravel, laravel-package, livewire, ninja-keys, search, spotlight, web-components

## 简介

Cmd+K command palette for Laravel: build ninja-keys actions in PHP, filter them by Gate abilities, render the keyboard shortcut menu with one Blade component, with Livewire wire:navigate support and no npm build step.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
