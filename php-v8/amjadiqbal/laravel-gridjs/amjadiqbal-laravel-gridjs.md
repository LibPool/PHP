# amjadiqbal/laravel-gridjs

> 标签: data-table, datagrid, datatables-alternative, eloquent, grid.js, gridjs, laravel, laravel-package, pagination, search, server-side, sortable, table

## 简介

Grid.js datagrid for Laravel: turn any Eloquent query into a searchable, sortable, paginated data table with server-side processing, a fluent PHP API and no jQuery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
