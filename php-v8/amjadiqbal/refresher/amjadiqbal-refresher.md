# amjadiqbal/refresher

> 标签: RefreshDatabase, ci, database-snapshot, faster-tests, laravel, laravel-package, lazilyrefreshdatabase, mariadb, migrate-fresh, mysql, pest, phpunit, sqlite, test-database, testing

## 简介

Faster Laravel tests: a drop-in for RefreshDatabase that caches the migrated (and seeded) test database as a snapshot and restores it instead of running migrate:fresh. MySQL, MariaDB and SQLite, PHPUnit and Pest.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
