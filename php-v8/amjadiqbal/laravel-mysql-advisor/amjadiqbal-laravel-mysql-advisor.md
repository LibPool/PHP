# amjadiqbal/laravel-mysql-advisor

> 标签: amjadiqbal, database, database-health, database-performance, indexes, laravel, laravel-package, mariadb, mysql, n-plus-one, performance, performance-schema, query-optimization, slow-queries, unused-indexes

## 简介

Read-only MySQL and MariaDB health advisor for Laravel: finds unused, redundant and missing indexes, full table scans, slow and N+1 queries, fragmented tables and server pressure, with the exact SQL or migration to fix each one. Artisan report with a CI exit code plus a Blade dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
