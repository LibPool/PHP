# amjadiqbal/laravel-webhook-console

> 标签: amjadiqbal, dashboard, debugging, failed-jobs, laravel, laravel-package, laravel-webhook-client, queue, spatie, webhook, webhook-client, webhook-dashboard, webhook-replay, webhook-retry, webhooks

## 简介

Dashboard and replay tool for spatie/laravel-webhook-client: browse every received webhook by config, status and date, inspect payloads and headers with secrets masked, see failures (stored exceptions and failed queue jobs), replay one or bulk-retry failed webhooks, prune old calls, plus webhooks:failed and webhooks:replay artisan commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
