# amjadiqbal/laravel-pennant-dashboard

> 标签: admin, amjadiqbal, audit-log, blade, dashboard, feature-flags, feature-management, feature-toggles, gradual-rollout, laravel, laravel-package, laravel-pennant, pennant, percentage-rollout

## 简介

Standalone feature flag dashboard for Laravel Pennant: see every feature's state per user, team or any model, toggle it for one scope or everyone, run sticky percentage rollouts, purge stored values and keep an audit log of who changed what. Plain Blade, no Filament or Nova needed. Unofficial community package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
