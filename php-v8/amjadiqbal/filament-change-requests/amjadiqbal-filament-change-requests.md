# amjadiqbal/filament-change-requests

> 标签: approval, approval-workflow, change-request, diff, eloquent, filament, filament-plugin, filamentphp, four-eyes, laravel, maker-checker

## 简介

Hold record edits in Filament as change requests: field-by-field diff, approve, reject and roll back. Built on cjmellor/approval.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
