# amjadiqbal/laralink

> 标签: artisan, artisan-command, composer, developer-tools, git, laravel, laravel-package, local-development, monorepo, package-development, path-repository, symlink

## 简介

Local package development for Laravel: link a package from a local folder or a Git repository into your app with one artisan command (Composer path repository + symlink), see what is linked, and switch back to the Packagist release when you're done.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
