# devanoxltd/laravel-revive

> 标签: Code style, devanox, laravel, php, revive

## 简介

Automatic configuration for Laravel apps to apply Devanox's standard linting & code standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
