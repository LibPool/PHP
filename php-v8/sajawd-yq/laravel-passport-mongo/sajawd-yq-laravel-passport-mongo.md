# sajawd-yq/laravel-passport-mongo

> 标签: laravel, mongodb, oauth, passport

## 简介

Laravel Passport provides OAuth2 server support to Laravel with mongoDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
