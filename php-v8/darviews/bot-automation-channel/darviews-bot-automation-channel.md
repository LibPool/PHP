# darviews/bot-automation-channel

> 标签: 2waysms, Messenger, darviews, integration, ivr, office report tools, sms

## 简介

Value Added Service channel robot automation framework for Shortcode, USSD, Whatsapp, Telegram, Facebook Messenger e.t.c

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
