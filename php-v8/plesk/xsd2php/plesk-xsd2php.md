# plesk/xsd2php

> 标签: converter, jms, php, serializer, xml, xsd

## 简介

Convert XSD  (XML Schema) definitions into PHP classes and JMS metadata

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
