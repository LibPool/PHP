# plesk/wappspector

> 标签: PHP

## 简介

Command-line interface utility to analyze the file structure of a web hosting server and identify the frameworks and CMS used in the websites hosted on it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
