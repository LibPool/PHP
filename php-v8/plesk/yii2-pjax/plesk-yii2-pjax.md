# plesk/yii2-pjax

> 标签: extension, pjax, plesk, yii2

## 简介

Plesk extension for Yii2 framework to extend it's PJAX functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
