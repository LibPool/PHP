# bangsamu/plugin-manager

> 标签: PHP

## 简介

Dashboard plugin manager for installing/removing/updating bangsamu/* packages via UI — WordPress-like plugin experience for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
