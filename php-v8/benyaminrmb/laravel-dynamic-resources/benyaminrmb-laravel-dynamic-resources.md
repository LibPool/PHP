# benyaminrmb/laravel-dynamic-resources

> 标签: api, dynamic, json, laravel, resources, sparse-fieldsets

## 简介

Composable, IDE-discoverable API resource views and safe sparse fieldsets for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
