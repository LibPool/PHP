# fernandozueet/upload-image-manipulation

> 标签: crop, image, image manipulation, resize, upload, watermaks image

## 简介

Upload and manipulation image, crop, resize, watermarks, filters, flip, rotate, image text and gamma correct

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
