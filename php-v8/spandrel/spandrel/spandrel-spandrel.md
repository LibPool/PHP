# spandrel/spandrel

> 标签: architecture, dev, static analysis

## 简介

Spandrel is a static analysis tool for PHP applications, enforcing architectural rules over a codebase's dependency graph.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
