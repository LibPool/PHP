# osoobe/dimepay-laravel-sdk

> 标签: dimepay, gateway, laravel, payment, sdk

## 简介

Laravel SDK for DimePay payment gateway — orders, payments, cards, split, recurring, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
