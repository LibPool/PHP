# dadkhah-dev/laravel-persian-string

> 标签: laravel, persian, string

## 简介

Convert Arabic/English/etc numbers and characters to Persian numbers and characters in Laravel models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
