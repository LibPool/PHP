# laikait/laika-queue

> 标签: framework, jobs, laika, php, queue, worker

## 简介

Queue package for the Laika PHP MVC Framework — database, Redis, and JSON drivers with a signal-aware worker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
