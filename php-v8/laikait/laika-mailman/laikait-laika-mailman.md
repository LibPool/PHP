# laikait/laika-mailman

> 标签: email, imap, laika, mail, phpmailer, pop3, smtp

## 简介

Mail package for the Laika PHP MVC Framework — send via PHPMailer (SMTP/sendmail/mail/qmail), read via built-in IMAP and POP3 clients.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
