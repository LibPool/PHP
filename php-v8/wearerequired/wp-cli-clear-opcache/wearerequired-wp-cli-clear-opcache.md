# wearerequired/wp-cli-clear-opcache

> 标签: Opcache, wordpress, wp-cli

## 简介

Use WP-CLI to clear the OPcache for a site via HTTP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
