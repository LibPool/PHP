# debuggy/gauger

> 标签: benchmark, debug, gauge, profiler, timer

## 简介

Highly extensible and comprehensive tool for measuring and debugging PHP scripts and applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
