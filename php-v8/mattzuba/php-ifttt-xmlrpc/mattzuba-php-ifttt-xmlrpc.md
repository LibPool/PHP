# mattzuba/php-ifttt-xmlrpc

> 标签: PHP

## 简介

Creates a fake Wordpress XMLRPC Server for use with IFTTT to do anything you want.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
