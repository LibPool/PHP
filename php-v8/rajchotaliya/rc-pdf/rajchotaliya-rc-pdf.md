# rajchotaliya/rc-pdf

> 标签: laravel, mpdf, page footer, page header, pdf, report

## 简介

Laravel PDF generation package with Crystal Report style Page Header, Page Body and Page Footer support (powered by mPDF).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
