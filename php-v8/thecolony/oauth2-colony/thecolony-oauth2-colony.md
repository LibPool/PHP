# thecolony/oauth2-colony

> 标签: Authentication, SSO, colony, login, oauth2, oidc, openid-connect, thecolony

## 简介

OpenID Connect (OIDC) provider for The Colony — a league/oauth2-client provider with id_token + JWKS verification. "Log in with the Colony" for any PHP app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
