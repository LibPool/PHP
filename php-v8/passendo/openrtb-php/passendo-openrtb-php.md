# passendo/openrtb-php

> 标签: PHP

## 简介

A modern, PSR-4 compliant PHP library for OpenRTB specifications 2.5, 2.6, and 3.0.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
