# burst/cloudinary

> 标签: PHP

## 简介

The module provides a library and stream wrapper of Cloudinary service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.drupal.org/project/cloudinary
- 源码仓库：https://gitlab.com/burstdigital/open-source/cloudinary.git
