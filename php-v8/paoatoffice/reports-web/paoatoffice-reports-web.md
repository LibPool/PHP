# paoatoffice/reports-web

> 标签: Reports.Web, Reports.net, business-forms, estimate, invoice, japanese, label, pdf, pdf-generation, prepdj, prepej, report, report-designer, reports, wasm, webassembly, 帳票

## 简介

Reports.Web for PHP: build PREPEJ print data from report definitions (.prepdj) and render PDF with the Reports.Web engine (C++ WebAssembly). Japanese business forms such as invoices, estimates and labels. Trial build.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
