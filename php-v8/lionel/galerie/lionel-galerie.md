# lionel/galerie

> 标签: Galleria, Picasa, flickr, gallery, iframe, slideshow, video

## 简介

Professional pictures galleries for the web and mobile devices.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
