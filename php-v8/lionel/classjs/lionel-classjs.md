# lionel/classjs

> 标签: JS, classjs

## 简介

This extension adds the class "no-js" to the html tag and replaces it with the class "js" if JavaScript is enabled.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
