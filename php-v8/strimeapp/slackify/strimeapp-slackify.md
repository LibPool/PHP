# strimeapp/slackify

> 标签: api, chat, communication, notifications, php, slack, webhooks

## 简介

Slackify, an Object Oriented library to communicate with Slack API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
