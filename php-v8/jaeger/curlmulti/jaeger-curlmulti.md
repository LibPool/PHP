# jaeger/curlmulti

> 标签: PHP

## 简介

CurlMulti是PHP多线程类库,修改用于QueryList(http://querylist.cc ),CurlMulti项目地址:https://github.com/ares333/php-curlmulti

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
