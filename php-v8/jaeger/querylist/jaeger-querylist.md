# jaeger/querylist

> 标签: QueryList, phpQuery, spider

## 简介

Simple, elegant, extensible PHP Web Scraper (crawler/spider),Use the css3 dom selector,Based on phpQuery! 简洁、优雅、可扩展的PHP采集工具(爬虫)，基于phpQuery。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
