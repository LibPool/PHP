# kakuilan/guzzle-jsonrpc

> 标签: Guzzle, guzzlehttp, http, json, json-rpc, jsonrpc, ring, rpc

## 简介

JSON-RPC 2.0 client for Guzzle,forked from graze/guzzle-jsonrpc

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
