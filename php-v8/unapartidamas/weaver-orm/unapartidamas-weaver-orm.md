# unapartidamas/weaver-orm

> 标签: database, mapper, orm, php, pyrosql, symfony

## 简介

PHP 8.4+ ORM for Symfony. Zero reflection, no proxies, no memory leaks. Worker-safe by design.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
