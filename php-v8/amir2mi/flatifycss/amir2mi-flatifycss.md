# amir2mi/flatifycss

> 标签: JS, css, duolingo, flat, flat-design, front-end, responsive, sass, web

## 简介

Modern flat design framework for the web — inspired by Duolingo design system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
