# cakephp/orm

> 标签: ORM, cakephp, data-mapper, data-mapper pattern, orm, 数据库

## 简介

CakePHP ORM - Provides a flexible and powerful ORM implementing a data-mapper pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
