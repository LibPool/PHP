# cakephp/http

> 标签: HTTP, cakephp, http, psr-13, psr-15, psr-17, psr-18, psr-7, 基础库

## 简介

CakePHP HTTP client and PSR-7, PSR-13, PSR-15, PSR-17, PSR-18 compliant libraries

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
