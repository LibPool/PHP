# myanmyanpay/mmpay-php-sdk

> 标签: PHP

## 简介

PHP One Time MMQR generation and Payment integration software developement kit created by MyanMyanPay Team

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
