# mossengine/fivecode-parsers-strings

> 标签: 5GL, code, fivecode, parser, string

## 简介

A Parser for the FiveCode library that provides string based logical instructions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
