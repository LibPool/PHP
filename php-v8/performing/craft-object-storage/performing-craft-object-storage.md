# performing/craft-object-storage

> 标签: Flysystem, craftcms, object-storage, plugin, s3

## 简介

A Craft 4 plugin that integrates with fortrabbit's S3 compatible Object Storage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
