# volcy/translator-core

> 标签: blade, flightphp, i18n, laravel, localization, multilingual, translation

## 简介

Framework-agnostic Blade string extraction and JSON-based translation catalog.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
