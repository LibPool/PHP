# samuelpietro/cnpjutils

> 标签: brasil, cnpj, gerar, validar

## 简介

Funções úteis para gerar e validar números de CNPJ no novo padrão alfanumérico.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
