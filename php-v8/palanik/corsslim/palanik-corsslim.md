# palanik/corsslim

> 标签: cors, corsslim, cross-origin, preflight, slim, slimphp

## 简介

Cross-origin resource sharing (CORS) middleware for PHP Slim.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
