# codesvault/wp-bundler

> 标签: PHP

## 简介

WP Bundler is a CI/CD tool. It can configure and run build process, and bundle zip(s) for WordPress plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
