# niangpro/framework

> 标签: framework, micro-framework, minimal, orm, php, router

## 简介

Le framework NiangPro (v2) : les 14 paquets niangpro/* réunis. Pour créer une application : composer create-project niangpro/niangpro mon-app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
