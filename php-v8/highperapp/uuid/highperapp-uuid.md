# highperapp/uuid

> 标签: concurrent, ffi, guid, performance, rfc9562, rust, uuid

## 简介

High-performance UUID generator library implementing RFC 9562 with optional Rust FFI acceleration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
