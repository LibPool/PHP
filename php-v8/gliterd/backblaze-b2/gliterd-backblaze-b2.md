# gliterd/backblaze-b2

> 标签: b2, backblaze, backup, cloud, cloud-storage, filesystem, storage

## 简介

PHP SDK for working with backblaze B2 cloud storage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
