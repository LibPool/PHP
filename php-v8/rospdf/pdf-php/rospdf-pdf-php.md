# rospdf/pdf-php

> 标签: PHP

## 简介

The R&OS Pdf class supports the creation of PDF documents without any adiditional modules or extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
