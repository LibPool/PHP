# yii2-module/yii2-insee-sirene

> 标签: INSEE, Siren, Siret, ban, base, entreprises, php, sirene, yii2

## 简介

A module that structures the data of the SIRENE database from the INSEE

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
