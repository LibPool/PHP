# luiscamp/laravel-log-monitor

> 标签: laravel, log-viewer, logs, monitor, monolog

## 简介

View, search, filter and manage Laravel log files from a modern, secure web interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
