# alphalabs/filter-engine

> 标签: doctrine, expression, filter

## 简介

Filter engine which could be used to alter Doctrine queries based on filter expression

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
