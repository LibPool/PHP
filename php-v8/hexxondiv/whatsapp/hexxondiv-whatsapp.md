# hexxondiv/whatsapp

> 标签: PHP

## 简介

Lightweight PHP library for WhatsApp API to send the WhatsApp messages in PHP using ultramsg.com API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
