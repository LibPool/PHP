# field-vn/zalo

> 标签: chatbot, laravel, oauth, php, sdk, vietnam, webhook, zalo, zalo-bot, zalo-oa, zbs

## 简介

Zalo OA & Bot SDK cho Laravel — quản lý nhiều OA, tự refresh token, có UI cấu hình

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
