# crowdstar/vertica-swoole-adapter

> 标签: swoole, vertica

## 简介

Provides a Db layer for Swoole-based application to communicate to HP Vertica databases.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
