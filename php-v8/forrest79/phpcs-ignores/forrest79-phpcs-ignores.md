# forrest79/phpcs-ignores

> 标签: baseline, ignore, phpcs

## 简介

PHPCS-Ignores provides functionality to use baseline or other ignoring for original PHPCS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
