# forrest79/pagination

> 标签: logarithmic, neighbour, pages, pagination, paginator, php

## 简介

Create pages list for pagination with logarithmic scale, neighbour pages or all pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
