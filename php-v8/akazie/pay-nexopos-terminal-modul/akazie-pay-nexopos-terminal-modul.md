# akazie/pay-nexopos-terminal-modul

> 标签: akazie-pay, nexopos, nexopos-module, payment, payment-terminal, payrexx, pos

## 简介

NexoPOS-Modul: Anbindung eines akazie-pay Kartenterminals (Payrexx ECR API) als Zahlungsart. Ein Terminal pro Kasse, Polling statt Webhook.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
