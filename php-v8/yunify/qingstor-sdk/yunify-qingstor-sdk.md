# yunify/qingstor-sdk

> 标签: object storage, qingcloud, qingstor, sdk, yunify

## 简介

The official QingStor SDK for the PHP programming language.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
