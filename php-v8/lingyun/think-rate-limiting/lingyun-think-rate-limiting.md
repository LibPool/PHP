# lingyun/think-rate-limiting

> 标签: PHP

## 简介

基于 ThinkPHP 缓存实现的限流器，提供了一个简单的方法来限制指定时间内的任何操作

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
