# zoghal/holoo-client

> 标签: PHP

## 简介

PHP Client Webservice for Holoo(Torfenagar) accounting and financial software(holoo.co.ir)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
