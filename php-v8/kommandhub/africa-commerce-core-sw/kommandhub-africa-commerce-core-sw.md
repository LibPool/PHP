# kommandhub/africa-commerce-core-sw

> 标签: africacommercecore, cli, custom-fields, shopware, shopware-plugin, shopware6, storefront

## 简介

Localization, geography and address foundation for African markets: ISO reference data, administrative divisions, extra address fields and phone normalization for Shopware 6.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
