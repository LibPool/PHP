# kommandhub/base-theme-sw

> 标签: shopware, shopware-plugin, shopware-theme, shopware6, theme

## 简介

Modern, premium base theme for Shopware 6.7: neutral monochrome UI with colour reserved for meaning, design tokens, dark mode, accessible navigation and refined checkout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
