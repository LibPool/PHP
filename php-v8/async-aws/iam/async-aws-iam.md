# async-aws/iam

> 标签: access, amazon, async-aws, aws, iam, identity, management, sdk

## 简介

IAM client, part of the AWS SDK provided by AsyncAws.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
