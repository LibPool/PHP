# async-aws/cloud-watch

> 标签: amazon, async-aws, aws, cloud-watch, sdk

## 简介

CloudWatch client, part of the AWS SDK provided by AsyncAws.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
