# async-aws/dynamo-db

> 标签: amazon, async-aws, aws, dynamo-db, sdk

## 简介

DynamoDb client, part of the AWS SDK provided by AsyncAws.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
