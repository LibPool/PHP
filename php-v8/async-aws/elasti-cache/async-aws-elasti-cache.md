# async-aws/elasti-cache

> 标签: amazon, async-aws, aws, elasti-cache, sdk

## 简介

ElastiCache client, part of the AWS SDK provided by AsyncAws.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
