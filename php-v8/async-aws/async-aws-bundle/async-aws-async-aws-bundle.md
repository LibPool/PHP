# async-aws/async-aws-bundle

> 标签: amazon, async-aws, aws, bundle, sdk, symfony

## 简介

Configure all your AsyncAws services and enjoy the autowire greatness.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
