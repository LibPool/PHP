# async-aws/media-convert

> 标签: amazon, async-aws, aws, media-convert, sdk

## 简介

MediaConvert client, part of the AWS SDK provided by AsyncAws.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
