# bannerstop/keycloak-laravel

> 标签: SSO, auth, guard, keycloak, laravel, oidc, openid-connect

## 简介

Laravel integration of bannerstop/keycloak: Keycloak single sign-on, bearer token guard, role middleware and logout

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
