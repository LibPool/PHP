# bannerstop/keycloak

> 标签: SSO, jwt, keycloak, oauth2, oidc, openid-connect, pkce

## 简介

Framework-agnostic Keycloak / OpenID Connect client: login with PKCE, logout, token verification against JWKS, role mapping and the admin user directory

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
