# teepluss/epay

> 标签: gateway, laravel, laravel4, paypal

## 简介

Laravel Epay is payment gateway adapter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/teepluss/laravel4-epay.git
