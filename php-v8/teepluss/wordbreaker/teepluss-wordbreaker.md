# teepluss/wordbreaker

> 标签: fulltext, laravel, laravel4, tokenizer

## 简介

Word breaker is Thai wording separator for using with fulltext software.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
