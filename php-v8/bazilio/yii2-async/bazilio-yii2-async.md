# bazilio/yii2-async

> 标签: AMQP, Tasks, async, rabbitmq, redis, yii2

## 简介

Provides translucent api for moving large tasks out of request context

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
