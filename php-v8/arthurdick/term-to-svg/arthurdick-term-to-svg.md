# arthurdick/term-to-svg

> 标签: animation, cli, recorder, svg, terminal

## 简介

A command-line PHP tool that converts terminal session recordings into animated SVG files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
