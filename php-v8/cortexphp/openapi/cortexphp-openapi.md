# cortexphp/openapi

> 标签: cortex, json-schema, oas, openapi, openapi-3.1, swagger

## 简介

A fluent OpenAPI 3.1 builder for PHP, built on top of cortexphp/json-schema

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
