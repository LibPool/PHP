# mosesolayemi/laravel-cms

> 标签: cms, content-management, filament, laravel, page-builder

## 简介

A self-contained CMS for Laravel: content models, a page builder, its own admin guard and a Filament back office.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
