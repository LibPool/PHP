# rehike/spfphp

> 标签: dynamic loading, page fragments, php spf, php spf.js, spf, spf parser, spf.js

## 简介

A PHP library for generating SPF.js-compatible page fragments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
