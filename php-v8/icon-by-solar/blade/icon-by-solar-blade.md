# icon-by-solar/blade

> 标签: blade, duotone, icon-by-solar, icons, laravel, solar-icons, svg

## 简介

Idiomatic Laravel Blade icon component for Icon by Solar. Supports Bold, Bold Duotone, and Outline styles with zero React dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
