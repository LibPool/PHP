# fishmad/wkhtmltopdf-windows

> 标签: barryvdh, binary, convert, htmltoimage, htmltopdf, laravel-snappy, pdf, snapshot, thumbnail, wkhtmltopdf

## 简介

Convert html to pdf using webkit (qtwebkit). Static linked windows binary for 32 bit and 64 bit systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
