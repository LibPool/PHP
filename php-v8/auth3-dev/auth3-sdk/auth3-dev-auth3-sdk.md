# auth3-dev/auth3-sdk

> 标签: Authentication, auth3, authorization, identity, oauth2

## 简介

Library for the Auth3 Identity Platform APIs, learn more at https://auth3.dev/.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://auth3.dev
- 源码仓库：https://github.com/auth3-dev/php-sdk.git
- Packagist 页面：https://packagist.org/packages/auth3-dev%2Fauth3-sdk
