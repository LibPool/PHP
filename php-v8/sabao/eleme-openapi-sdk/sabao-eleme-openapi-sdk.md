# sabao/eleme-openapi-sdk

## 简介

饿了么开放平台 PHP SDK（基于官方 SDK 优化维护：PHP 8.2+、完整类型注释、CS-Fixer / PHPStan 检查）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
