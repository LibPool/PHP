# kgaut/healthcheck

> 标签: drupal, health, healthcheck, monitoring

## 简介

Point de santé /health pour Drupal, extensible par plugins : base, Redis, Search API, fichiers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
