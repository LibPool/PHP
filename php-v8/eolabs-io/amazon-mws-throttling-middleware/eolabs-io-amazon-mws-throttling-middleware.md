# eolabs-io/amazon-mws-throttling-middleware

> 标签: amazon-mws-throttling-middleware, eolabs-io

## 简介

A Laravel Middleware for throttling Amazon MWS endpoint calls

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
