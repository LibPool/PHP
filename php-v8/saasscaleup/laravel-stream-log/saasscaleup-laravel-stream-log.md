# saasscaleup/laravel-stream-log

> 标签: Laravel Debug, Laravel log, Sever Sent Events, SeverEvents, Stream Log, debug, event, laravel, log, notifications, polling, realtime, server, sse

## 简介

Easily stream your Laravel application logs to the frontend in real-time using server-sent event (SSE)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
