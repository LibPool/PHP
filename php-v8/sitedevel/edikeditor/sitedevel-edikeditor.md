# sitedevel/edikeditor

> 标签: edik, edit bundle, editor, image editor, sitedevel

## 简介

EdikEditor plugin for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
