# juniora/laravel-redis-paginator

> 标签: laravel, pagination, paginator, redis

## 简介

Create a Laravel Paginator or LengthAwarePaginator from a Redis sorted set

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
