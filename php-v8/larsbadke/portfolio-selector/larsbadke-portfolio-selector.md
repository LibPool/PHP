# larsbadke/portfolio-selector

> 标签: optimize, portfolio, stock

## 简介

Portfolio-Selector is a PHP library that helps you to optimize your stock portfolio.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
