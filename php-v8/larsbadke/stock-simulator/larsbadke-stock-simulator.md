# larsbadke/stock-simulator

> 标签: data, simulator, stock

## 简介

Stock-Simulator is a PHP library that simulates fake stock data for you.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
