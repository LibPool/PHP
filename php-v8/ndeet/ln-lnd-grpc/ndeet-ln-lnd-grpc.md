# ndeet/ln-lnd-grpc

> 标签: Lightning, bitcoin, gRPC, lnd

## 简介

Lightning Network LND gRPC client for Bitcoin and other supported coins. The classes and client is generated from rpc.proto.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
