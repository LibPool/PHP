# wikigods/laravel-installer

> 标签: environment, installer, laravel, setup

## 简介

A community-maintained Laravel web installer, continued from the original LaravelInstaller project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
