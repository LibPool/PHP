# torii/backend

> 标签: auth, jwt, laravel, sdk, torii

## 简介

Backend SDK for torii — verify end-user JWTs without a per-request round trip, manage users from your PHP server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
