# mohamedgaldi/vilt-filepond

> 标签: Vilt stack, file upload, filepond, laravel, upload, vilt, vue

## 简介

A Laravel package for handling file uploads with FilePond in VILT stack

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
