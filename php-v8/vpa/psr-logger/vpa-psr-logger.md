# vpa/psr-logger

> 标签: CLI console logger, Injectable, JS console logger, logger, php 8.x, psr-3

## 简介

Implementations of PSR-3 Logger Interface for Developer Console and CLI console

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
