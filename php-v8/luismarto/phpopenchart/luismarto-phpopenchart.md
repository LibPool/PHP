# luismarto/phpopenchart

> 标签: bar charts, chart, charts, line charts, pie charts

## 简介

PHP library to draw Column, Bar, Line and Pie Charts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
