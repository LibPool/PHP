# shipaurora/cms

> 标签: ai, aurora, aurora-cms, cms, content-management, filament, headless, laravel, mcp, page-builder, visual-editor

## 简介

Aurora: a content management system for Laravel, built on Filament.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
