# shipaurora/minimal

> 标签: admin-theme, aurora, aurora-cms, aurora-cms-theme, cms, dark-mode, filament, filament-theme, laravel, minimal, tailwindcss, theme

## 简介

A minimal admin theme for Aurora CMS: quiet, flat and neutral, in light and dark.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
