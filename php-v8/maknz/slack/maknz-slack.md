# maknz/slack

> 标签: laravel, slack

## 简介

A simple PHP package for sending messages to Slack, with a focus on ease of use and elegant syntax. Includes Laravel support out of the box.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
