# codingms/fullscreen

> 标签: extension, fullscreen, toolbar, typo3

## 简介

TYPO3 Fullscreen by coding.ms: TYPO3 Fullscreen adds a fullscreen button to the TYPO3 backend toolbar. It lets users activate and deactivate fullscreen mode directly in the backend, making efficient use of the available workspace.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
