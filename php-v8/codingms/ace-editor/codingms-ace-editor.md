# codingms/ace-editor

> 标签: editor, extension, typo3

## 简介

TYPO3 ACE-Editor Integration by coding.ms: This extension adds the famous ACE-Editor in the fileadmin in TYPO3 backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
