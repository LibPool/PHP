# codingms/modules

> 标签: Backend modules, backend, extension, typo3

## 简介

TYPO3 Modules by coding.ms: TYPO3 toolbox for Frontend-User-Registration, Profile, Invitations, Listing with detailview, Addressmanagement, and Frontend-Recordmanagement. User friendly Backendmodule for managing Frontend- and Backend-Users and other Records. Toolbox for frontend and backend modules in TYPO3 for registration, profile editing, address management, and user listings with detail view, plus extensive intranet and application areas.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
