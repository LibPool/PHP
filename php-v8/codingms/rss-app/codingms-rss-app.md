# codingms/rss-app

> 标签: extension, facebook, instagram, pinterest, rss, twitter, typo3, youtube

## 简介

TYPO3 RSS.App - RSS-Feeds by coding.ms: This Plugin enables you to display RSS.App feeds (Instagram, LinkedIn, X/Twitter, YouTube, Facebook and more) in TYPO3 - more information on https://rss.app

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
