# codingms/messages

> 标签: extension, messages, typo3

## 简介

TYPO3 Messages by coding.ms: TYPO3 Messaging Extension for User Messaging and Direct Messages between frontend users, providing Private Messages, a Messaging Inbox and a Conversation System for structured Frontend User Communication and Internal Communication, including unread message display and controlled User Interaction with configurable recipients (vergleichbar mit WhatsApp, Telegram und co.).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
