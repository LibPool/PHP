# codingms/portfolios

> 标签: extension, portfolio, references, showcase, typo3

## 简介

TYPO3 Portfolios by coding.ms: Extension for displaying portfolios, references, and work examples with categories, tags, detail and teaser views, plus related entries. Bookmarks, Isotope multi-filter, PDF generator, images, downloads, and radial search improve presentation, navigation, and discovery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
