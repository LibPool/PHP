# thirdestonks/memorylane

> 标签: apm, laravel, memorylane, n-plus-one, profiler, thirdestonks

## 简介

Lightweight, self-hosted, prod-safe request profiler for Laravel: duration, memory, queries and NPlusOnes per request.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
