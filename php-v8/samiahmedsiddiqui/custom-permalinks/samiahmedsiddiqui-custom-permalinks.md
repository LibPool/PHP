# samiahmedsiddiqui/custom-permalinks

> 标签: address, custom post type, link, permalink, redirect, url, wordpress

## 简介

Set custom permalinks on a per-post basis in WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
