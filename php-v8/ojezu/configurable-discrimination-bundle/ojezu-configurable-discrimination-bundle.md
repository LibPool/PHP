# ojezu/configurable-discrimination-bundle

> 标签: PHP

## 简介

Symfony2 bundle that allows configuring Doctrine discrimination maps in children bundles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
