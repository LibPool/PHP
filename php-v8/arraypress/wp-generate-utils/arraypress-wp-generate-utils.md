# arraypress/wp-generate-utils

> 标签: Passwordless, download-link, expiring, hmac, magic-link, signed-url, token, wordpress

## 简介

Licence keys, discount codes, references, slugs and UUIDs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
