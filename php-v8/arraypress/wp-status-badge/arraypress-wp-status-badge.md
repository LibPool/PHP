# arraypress/wp-status-badge

> 标签: admin, arraypress, badge, frontend, label, status, ui, wordpress

## 简介

A lightweight WordPress library for rendering styled status badges

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
