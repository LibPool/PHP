# arraypress/wp-ipinfo

> 标签: asn, geolocation, hosting-detection, ip-geolocation, ip-information, ip-lookup, ipinfo, privacy-detection, proxy-detection, vpn-detection, wordpress

## 简介

A PHP library for integrating with the IPInfo.io API in WordPress, providing geolocation, ASN data, privacy detection, and hosting information. Features plan-aware responses and WordPress transient caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
