# arraypress/wp-ipqualityscore

> 标签: anti-fraud, asn, dark-web-monitoring, data-breach, email-validation, email-verification, fraud-prevention, ip-lookup, ipqualityscore, leak-detection, phone-verification, proxy-detection, security, threat-detection, transaction-scoring, url-scanning, vpn-detection, wordpress

## 简介

A PHP library for integrating with the IPQualityScore API in WordPress, providing proxy, VPN & email validation, phone verification, dark web monitoring, URL scanning, and fraud prevention. Features comprehensive response handling and WordPress transient caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
