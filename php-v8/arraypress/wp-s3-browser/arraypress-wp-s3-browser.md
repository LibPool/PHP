# arraypress/wp-s3-browser

> 标签: aws, aws-s3, backup-storage, bucket-management, cdn, cloud-storage, cloudflare-r2, digitalocean-spaces, file-download, file-hosting, file-storage, file-upload, linode-object-storage, media-browser, minio, object-management, object-storage, presigned-urls, s3, s3-compatible, storage-provider, vultr-object-storage, wordpress, wp-plugin

## 简介

A comprehensive PHP library for integrating S3-compatible storage providers with WordPress. Features advanced media browser, upload/download management, presigned URLs, and support for multiple providers including AWS S3, Cloudflare R2, DigitalOcean Spaces, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
