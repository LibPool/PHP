# arraypress/wp-register-importers

> 标签: batch-processing, csv, data-migration, import, wordpress, wp-admin

## 简介

Declarative CSV import screens for WordPress plugins: field mapping, validation, dry runs and batch processing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
