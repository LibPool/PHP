# arraypress/wp-mapsco-geocoding

> 标签: OpenStreetMap, address, address-lookup, coordinates, coordinates-lookup, geocoding, geolocation, latitude, location, location-data, longitude, maps, maps.co, reverse-geocoding, wordpress

## 简介

A PHP library for integrating with the Maps.co Geocoding API in WordPress, providing both forward and reverse geocoding capabilities with WordPress transient caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
