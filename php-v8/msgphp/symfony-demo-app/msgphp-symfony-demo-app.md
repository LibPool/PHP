# msgphp/symfony-demo-app

> 标签: PHP

## 简介

A Symfony demo application with basic user management, a REST/GraphQL API and OAuth/JWT authentication.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
