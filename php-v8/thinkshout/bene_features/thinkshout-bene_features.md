# thinkshout/bene_features

> 标签: PHP

## 简介

Provides admin UI and infrastructure to support features built for the Bene Distribution for Non-profits.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
