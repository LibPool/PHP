# lovattj/php-skydrive

> 标签: OneDrive, SkyDrive, api, client, microsoft, php

## 简介

A PHP client library for Microsoft SkyDrive/OneDrive

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
