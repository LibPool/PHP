# reiterus/microapi-core

> 标签: api, engine, microapi, reiterus, rest, symfony

## 简介

MicroApi Core is an ultra-lightweight, tiny engine based on Symfony packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
