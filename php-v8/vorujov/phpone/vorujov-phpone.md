# vorujov/phpone

> 标签: PHP7, application, development, framework, php, website

## 简介

Simple and flexible PHP 5.6+ MVC micro-framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
