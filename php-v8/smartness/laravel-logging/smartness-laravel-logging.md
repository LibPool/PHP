# smartness/laravel-logging

> 标签: json, laravel, logging, loki, monolog, structured-logging

## 简介

Structured JSON logging for Laravel with bounded normalization, redaction and request/job correlation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
