# mograine/laravel-sendinblue-template

> 标签: laravel, sendinblue

## 简介

A Laravel 7/8/9 service provider, facade and config file for the SendinBlue's API v3 official PHP library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
