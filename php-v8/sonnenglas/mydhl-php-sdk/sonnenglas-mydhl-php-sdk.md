# sonnenglas/mydhl-php-sdk

> 标签: api, client, dhl, dhl-express, mydhl, php

## 简介

Unofficial PHP SDK for MyDHL REST API (DHL Express)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
