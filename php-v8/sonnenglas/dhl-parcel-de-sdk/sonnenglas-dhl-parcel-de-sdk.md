# sonnenglas/dhl-parcel-de-sdk

> 标签: api, client, dhl, dhlparcel, mydhl, parcel, php, rest

## 简介

Unofficial PHP SDK for DHL Parcel DE (Post & Parcel Germany) Rest API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
