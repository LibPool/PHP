# cpsit/t3events-template

> 标签: events, extension, template, typo3

## 简介

Event Templates is an extension for the TYPO3 CMS. It extends t3events by templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
