# farbesdev/laravel-ronin

> 标签: auth, laravel, laravel-ronin, permissions, roles, ronin

## 简介

Un paquete simple y flexible para la gestión de roles y permisos en Laravel. Controla el acceso a rutas y vistas de forma eficiente mediante un sistema basado en ACL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
