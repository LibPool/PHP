# silencewatch/laravel

> 标签: cron, dead-mans-switch, heartbeat, laravel, monitoring, scheduler, silencewatch

## 简介

Declare and monitor the scheduled tasks of a Laravel application with SilenceWatch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
