# javierms/subadmin_toolbar

> 标签: admin, drag and drop, drupal, icons, menu, roles, subadmin, toolbar

## 简介

A responsive, customizable administration toolbar for secondary roles with modern visual drag-and-drop builder, granular role permissions, and decoupled icon packages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
