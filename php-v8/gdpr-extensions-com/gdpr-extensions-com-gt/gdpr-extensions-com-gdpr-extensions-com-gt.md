# gdpr-extensions-com/gdpr-extensions-com-gt

> 标签: PHP

## 简介

Track your website viewers behavior and get your user analytics but only if they consent to!. Stay GDPR compliant when your website is scanned by any Cookie or GDPR Scanner, when using Google Analytics.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
