# irfantoor/engine

> 标签: framework, irfans-engine, mini, php, psr-7

## 简介

A bare-minimum PHP framework, focussing on the requests and the responses. A swiss-knife for world-wide-web

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
