# kinow-io/sendinblue-wrapper

> 标签: laravel, sendinblue

## 简介

A Laravel 5 wrapper for the SendInBlue API PHP class (as provided by SendInBlue)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
