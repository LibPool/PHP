# kinow-io/pipedrive-laravel-55

> 标签: api, client, laravel, pipedrive

## 简介

Complete Pipedrive API client for PHP and/or Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
