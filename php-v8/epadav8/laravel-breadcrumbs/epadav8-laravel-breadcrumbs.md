# epadav8/laravel-breadcrumbs

> 标签: laravel

## 简介

A simple Laravel-style way to create breadcrumbs in Laravel 4+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
