# a35g/json-to-xml

> 标签: cdata, composer, converter, dom, json, json-to-xml, mixed-content, php, xml, xml-attributes, xml-to-json, xxe-protection

## 简介

Lightweight PHP JSON <-> XML converter with attributes, mixed content, automatic CDATA, repeated elements and XXE-safe parsing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
