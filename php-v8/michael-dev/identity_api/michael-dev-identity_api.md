# michael-dev/identity_api

> 标签: alias, email, identities, identity, plugin, privacy, rest-api, roundcube, shop

## 简介

Per-shop e-mail addresses (<prefix>-<shop>-<year>-<random>@domain) as Roundcube identities, created on the fly through a token-authenticated REST API, e.g. from the browser extension Shop-Adressen for Firefox and Chrome.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
