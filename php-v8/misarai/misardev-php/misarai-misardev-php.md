# misarai/misardev-php

> 标签: API-Client, app-builder, chat-completions, code-search, deploy, hosting, misar, misar-dev, misardev, misardev-php, openai-compatible, rag, sdk, sse, streaming, templates

## 简介

PHP client for the Misar.Dev API: create projects, write files, build and deploy apps, start from templates, OpenAI-compatible chat completions, code search and usage — every route generated from the API, with retries, typed plan-limit errors carrying the upgrade offer, and SSE streaming.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
