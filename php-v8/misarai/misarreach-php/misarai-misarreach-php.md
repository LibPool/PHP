# misarai/misarreach-php

> 标签: API-Client, cold-email, crm, email-marketing, lead-finder, lead-generation, misarreach, outreach, sales-automation, sales-pipeline, sms, sse, whatsapp

## 简介

PHP client for the MisarReach outreach API: async lead finder over 23 sources with SSE progress, CRM deals and Kanban pipeline, multi-step email/SMS/WhatsApp/push/social campaigns, AI sales agent, autopilot, plan quotas, typed errors and retrying transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
