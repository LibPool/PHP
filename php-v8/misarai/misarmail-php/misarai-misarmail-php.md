# misarai/misarmail-php

> 标签: API-Client, analytics, automation, campaigns, contacts, deliverability, dmarc, email, email-api, email-marketing, email-validation, marketing-automation, misar, misarmail, misarmail-php, newsletter, segments, smtp, sse, templates, transactional-email, webhooks

## 简介

PHP client for MisarMail's transactional and marketing email API: send mail, run campaigns and A/B tests, manage contacts, segments, templates and automations, verify domains and DMARC, validate addresses, track revenue and read analytics — 33 resource groups, retries, typed plan-limit errors, SSE streaming.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
