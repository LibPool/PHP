# misarai/misarseo-php

> 标签: API-Client, Backlinks, ai-search, keyword-research, misar, misarseo, rank-tracking, sdk, search-console, seo, site-audit

## 简介

PHP client for the MisarSEO API: keyword research, site audits, rank tracking, backlinks, AI search visibility, Search Console, GA4 and Business Profile — 221 methods, retries, typed plan-limit errors with the upgrade offer, SSE crawl progress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
