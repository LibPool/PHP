# iiiicaro/sentiment-thermometer

> 标签: PHP

## 简介

Measure the sentiment around a word, name, sentence or hashtag using social networks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
