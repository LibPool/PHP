# laposta/laposta-signup-embed

> 标签: embed, form, laposta, marketing, newsletter, plugin, wordpress

## 简介

WordPress plugin that adds Laposta embedded signup forms to your site.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
