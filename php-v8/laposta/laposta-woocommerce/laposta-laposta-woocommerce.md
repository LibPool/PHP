# laposta/laposta-woocommerce

> 标签: checkout, laposta, newsletter, plugin, woocommerce, wordpress

## 简介

WordPress plugin that adds a Laposta newsletter signup checkbox to WooCommerce checkout.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
