# asterios/app

> 标签: PHP

## 简介

Scaffold App for AsteriosPHP. AsteriosPHP is a simple and flexible PHP 8.+ framework, inspired from the best features of other frameworks, in a modern and elegant way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
