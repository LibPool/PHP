# zhengbingdong/easy-qq-info

> 标签: PHP

## 简介

非QQ授权的情况下，根据QQ号码解析出QQ昵称与QQ头像地址

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
