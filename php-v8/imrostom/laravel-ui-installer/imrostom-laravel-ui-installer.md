# imrostom/laravel-ui-installer

> 标签: installer, laravel, setup, tailwind, wizard

## 简介

A plug-and-play multi-step web installer UI for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
