# dmk/mklog

> 标签: TYPO3 CMS, devlog, log, notification

## 简介

Keep track of developer logs. Provides automatic email notification about important errors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
