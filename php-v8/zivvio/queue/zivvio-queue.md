# zivvio/queue

> 标签: async, beanstalk, db, gearman, queue, rabbitmq, redis, sqs, yii

## 简介

Yii2 Queue Extension which supported DB, Redis, RabbitMQ, Beanstalk, SQS and Gearman

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
