# autotix/php-sdk

> 标签: PHP

## 简介

Shared PHP core for Autotix framework integrations (Drupal, WordPress, Laravel). Wire format, HTTP client, auth, and utilities — framework-agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
