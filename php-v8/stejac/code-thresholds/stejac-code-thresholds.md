# stejac/code-thresholds

> 标签: ci, code-quality, complexity, php, pre-commit, static-analysis

## 简介

Dependency-free size and complexity gate for PHP that checks only changed files: method count, parameters, returns, function length, nesting depth, unused variables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
