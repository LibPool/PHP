# devhamidshahbazi/number-normalizer

> 标签: PHP

## 简介

Laravel package to automatically normalize any non-English digits (Persian, Arabic, Urdu, etc.) to English numbers in all requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
