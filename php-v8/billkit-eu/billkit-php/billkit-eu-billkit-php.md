# billkit-eu/billkit-php

> 标签: billing, billkit, eu, mollie, saas, stripe, subscriptions

## 简介

Official PHP SDK for BillKit: a Stripe-Billing-shape multi-tenant SaaS API on Mollie.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
