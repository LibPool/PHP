# a9f/fractor-yaml

> 标签: automation, dev, fractor, migration, refactoring, upgrade

## 简介

YAML extension for the File Read-Analyse-Change Tool. Allows modifying YAML files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
