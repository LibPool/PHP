# a9f/typo3-fractor

> 标签: automation, dev, fractor, migration, refactoring, typo3, upgrade

## 简介

TYPO3 extension for the File Read-Analyse-Change Tool. Allows modifying XML files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
