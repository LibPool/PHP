# a9f/typo3-better-redirects

> 标签: PHP

## 简介

Improved redirects handling for TYPO3, including optimized caching for large numbers of redirects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
