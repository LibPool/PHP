# kechankrisna/php_payway

> 标签: aba, cambodia, checkout, payment, payway, sdk

## 简介

ABA PayWay Ecommerce Checkout client for PHP: purchase, check, close, refund and list transactions, exchange rates, and callback verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
