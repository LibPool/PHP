# kechankrisna/payway-partner

> 标签: aba, cambodia, partner, payment, payway, sdk

## 简介

ABA PayWay partner API client for PHP. Register merchants, decrypt the pushback and inquire merchant info.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
