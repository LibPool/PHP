# kechankrisna/php_wing

> 标签: cambodia, checkout, payment, sdk, wing, wing bank

## 简介

Wing Bank online payment (Web SDK v2) client for PHP: authorize payments, open Wing's payment page, inquire transactions, and decrypt callbacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
