# amonray/laravel-rbac

> 标签: acl, auth, laravel, permissions, rbac, roles, security

## 简介

Role based access control for Laravel 5+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
