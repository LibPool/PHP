# bartoszbartniczak/array-object

> 标签: PHP

## 简介

ArrayOfObjects is the extension of the SPL ArrayObject concept. ArrayOfObjects may contain only objects of given type.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
