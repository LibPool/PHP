# pannella/laravel-cti

> 标签: CTI, class table inheritance, eloquent, inheritance, laravel, multi-table, orm, polymorphic, subtype casting

## 简介

A Laravel package for Class Table Inheritance support with automatic subtype casting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
