# zertex/yii2-zx-bootstrap-select

> 标签: bootstrap, bootstrap-select, extension, yii2, zertex

## 简介

Bootstrap-select widget for Yii2. Extended dropdown list.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
