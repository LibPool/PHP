# guimauve/craft-twig-view-composers

> 标签: PHP

## 简介

Allow composable PHP classes to be called before page view rendering, hence allowing organizing code à-la Laravel View Composers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
