# kendenigerian/payzephyr

> 标签: fintech, flutterwave, laravel, laravel-package, mollie, monnify, opay, paddle, payment, payment-gateway, payments, paypal, paystack, razorpay, square, stripe, webhook

## 简介

A unified payment abstraction layer for Laravel supporting multiple providers (Paystack, Flutterwave, Monnify, Stripe, PayPal, Square, OPay, Mollie, Paddle, Razorpay) with automatic fallback and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
