# glpzzz/otel-log

> 标签: NDJSON, json, log, logging, observability, openobserve, opentelemetry, otel, tracing, yiisoft-log

## 简介

ECS-aligned single-line JSON (NDJSON) log formatting for yiisoft/log, with request-trace propagation, for shipping into OpenObserve.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
