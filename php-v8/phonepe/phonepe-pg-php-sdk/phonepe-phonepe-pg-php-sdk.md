# phonepe/phonepe-pg-php-sdk

> 标签: PhonePe, payment gateway

## 简介

This SDK helps merchants integrate PhonePe Payments Gateway with their PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
