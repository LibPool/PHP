# sitecockpit/easy-vision-contao5

> 标签: PHP

## 简介

Integrate SiteCockpit into Contao: automated accessibility monitoring, frontend widget & legally compliant accessibility declaration. Integration takes just a few minutes!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
