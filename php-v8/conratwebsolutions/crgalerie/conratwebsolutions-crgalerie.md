# conratwebsolutions/crgalerie

> 标签: Responsive Images, extension, galerie, gallery, lightbox, photoswipe, typo3

## 简介

ConRat Photo Gallery - image galleries maintained centrally in a backend module, with responsive images and an accessible lightbox

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
