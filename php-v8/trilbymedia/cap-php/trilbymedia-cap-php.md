# trilbymedia/cap-php

> 标签: cap, cap.js, captcha, pow, proof-of-work, security, sha256

## 简介

PHP port of the Cap proof-of-work captcha server. Wire-compatible with @cap.js/widget.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
