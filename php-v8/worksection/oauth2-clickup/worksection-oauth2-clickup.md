# worksection/oauth2-clickup

> 标签: PHP

## 简介

ClickUp Oauth 2.0 Client Provider for the PHP league OAuth2 Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
