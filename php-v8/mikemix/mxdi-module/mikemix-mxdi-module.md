# mikemix/mxdi-module

> 标签: ZendFramework, annotations, dependency injection, di, yaml, zf2

## 简介

Configure dependency injection in ZF2 using annotations/YAML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
