# leocavalcante/hyperf-doctrine

> 标签: doctrine, hyperf, orm, php

## 简介

This project provides an integration for the Doctrine ORM and the Hyperf framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
