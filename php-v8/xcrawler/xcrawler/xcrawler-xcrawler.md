# xcrawler/xcrawler

> 标签: PHP

## 简介

A fast, simple and powerful PHP web crawler (scraper/spider) 快速、简洁且强大的爬虫/采集框架

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
