# hboie/ews-bundle

> 标签: Symfony2, bundle, ews, exchange, php-ews, symfony3, symfony4, symfony5

## 简介

Symfony 2-5 / Symfony Flex Bundle integrating a PHP Exchange Web Services from (garethp/php-ews)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
