# mameyugo/jsonq

> 标签: database, extension, integration-tests, json, jsonl, mongodb-style, php, queries, rust, storage, transactions

## 简介

High-performance JSON file storage engine for PHP, powered by Rust

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
