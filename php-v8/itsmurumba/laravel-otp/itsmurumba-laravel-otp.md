# itsmurumba/laravel-otp

> 标签: email, laravel, laravel 12, laravel 13, otp, slack

## 简介

Laravel Package for sending otps via SMS, Email, Slack

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
