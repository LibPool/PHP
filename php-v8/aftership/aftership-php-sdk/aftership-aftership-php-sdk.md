# aftership/aftership-php-sdk

> 标签: FedEx, aftership, dhl, shipping, track, tracking, ups, usps

## 简介

The PHP SDK of AfterShip API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
