# falc/flysystem-sftp-symlink-plugin

> 标签: Flysystem, plugin, sftp, symlink

## 简介

Sftp symlink plugin for Flysystem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
