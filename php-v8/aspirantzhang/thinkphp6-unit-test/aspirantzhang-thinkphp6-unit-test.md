# aspirantzhang/thinkphp6-unit-test

> 标签: PHP

## 简介

A simple tool for unit testing with PHPUnit and ThinkPHP 6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
