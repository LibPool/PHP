# enolaphp/api-rest-client

> 标签: api, enolaphp, libs, rest

## 简介

Cliente PHP que permite consultar de forma facil e intuitiva aplicaciones API REST.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
