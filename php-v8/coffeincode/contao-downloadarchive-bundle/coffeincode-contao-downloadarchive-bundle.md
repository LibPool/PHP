# coffeincode/contao-downloadarchive-bundle

> 标签: PHP

## 简介

Downloadarchive for 5.3 - this extension is a fork/port of laemmi/contao-downloadarchive which ported the original Downloadarchive by felixpfeiffer/contao-downloadarchive. Credit goes to felixpfeiffer, as the concept is not my work  - I only ported it to Contao 5.3 and moved it to using twig and as much symfony as possible.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
