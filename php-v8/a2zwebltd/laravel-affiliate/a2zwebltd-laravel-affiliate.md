# a2zwebltd/laravel-affiliate

> 标签: affiliate, commission, laravel, partners, payouts, referral, revenue-share

## 简介

Generic affiliate / revenue-share engine for Laravel: opt-in workflow, monthly commission closure, admin adjustments, partner-initiated payout requests, Blade+Alpine and Livewire dashboards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
