# diplodok/yii2-unitegallery-widget

> 标签: extension, unite gallery, widget, yii2

## 简介

Простейший виджет на основе галереи Unite Gallery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
