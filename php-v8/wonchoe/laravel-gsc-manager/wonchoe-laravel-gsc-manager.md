# wonchoe/laravel-gsc-manager

> 标签: analytics, google-search-console, gsc, laravel, search-console, seo, service-account

## 简介

Reusable Laravel package for discovering, storing, and syncing Google Search Console data via service account JSON credentials.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
