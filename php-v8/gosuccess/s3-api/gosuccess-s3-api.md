# gosuccess/s3-api

> 标签: RustFS, api, aws, client, minio, object-storage, s3, signature-v4

## 简介

A modern, strongly-typed, dependency-free PHP client for S3-compatible object storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
