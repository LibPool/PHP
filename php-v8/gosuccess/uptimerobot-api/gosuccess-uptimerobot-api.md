# gosuccess/uptimerobot-api

> 标签: api, client, incidents, monitoring, status-page, uptime, uptimerobot

## 简介

A modern, strongly-typed, dependency-free PHP client for the UptimeRobot API v3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
