# gosuccess/easybill-api

> 标签: EasyBill, api, client, invoicing, psr-18, rest

## 简介

A modern, strongly-typed PHP client for the easybill REST API with built-in rate limiting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
