# gosuccess/wordfence-api

> 标签: api, client, cve, security, vulnerabilities, webhook, wordfence, wordpress

## 简介

A modern, strongly-typed, dependency-free PHP client for the Wordfence Intelligence vulnerability data feed and its webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
