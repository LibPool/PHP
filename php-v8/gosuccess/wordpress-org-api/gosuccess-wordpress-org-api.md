# gosuccess/wordpress-org-api

> 标签: api, client, plugins, themes, wordpress, wordpress.org

## 简介

A modern, strongly-typed, dependency-free PHP client for the public wordpress.org API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
