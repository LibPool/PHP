# gosuccess/bunny-api

> 标签: Bunny.net, api, bunny, bunnyCDN, cdn, client, edge-scripting, edge-storage, magic-containers, shield, stream

## 简介

A modern, strongly-typed, dependency-free PHP client for all bunny.net APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
