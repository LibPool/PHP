# mmollay/gridkit

> 标签: Forms, admin, admin-panel, ai-agent, ajax, components, crud, dashboard, datatable, framework, material-design, php, table, ui, zero-dependency

## 简介

Agent-ready PHP component framework for admin dashboards. Zero dependencies, Material Design 3, AJAX-first.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
