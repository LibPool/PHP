# fastmon/shopware-collector

> 标签: PHP

## 简介

Real user monitoring for your Shopware storefront: Core Web Vitals, JavaScript errors and per-layer Server-Timing from real visitors. EU-hosted and cookieless.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
