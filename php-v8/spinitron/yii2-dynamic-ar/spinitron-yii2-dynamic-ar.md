# spinitron/yii2-dynamic-ar

> 标签: Dynamic Columns, Maria, activerecord, ar, mariadb, orm, yii2

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
