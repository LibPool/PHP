# mohammad_sulaiman/dashboard_setup

> 标签: PHP

## 简介

A library for setting up a Laravel dashboard, creating language switch middleware, routes, controllers, and language files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
