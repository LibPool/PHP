# coffrify/coffrify-php

> 标签: coffrify, encrypted, file-transfer, sdk, webhooks

## 简介

Official PHP SDK for Coffrify — encrypted file transfer infrastructure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
