# hyperion360/kipsaas

> 标签: billing, kip, multi-tenant, php, saas, sqlite, starter-kit, stripe, subscription

## 简介

Open-source SaaS starter kit for the Kip framework: multi-tenant subscriptions with production-hardened Stripe billing. Zero build step, SQLite-first.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
