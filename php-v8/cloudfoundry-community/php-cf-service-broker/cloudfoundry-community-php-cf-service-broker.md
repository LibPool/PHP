# cloudfoundry-community/php-cf-service-broker

> 标签: Cf, Cloud Foundry, Service Broker, cloud

## 简介

A Cloud Foundry service broker made for Cloud Foundry

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
