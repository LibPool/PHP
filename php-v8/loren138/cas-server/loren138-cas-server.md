# loren138/cas-server

> 标签: SSO, cas, laravel

## 简介

A CAS Server form Single Sign On (SSO) implemented as a Laravel Package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
