# smart-dato/brt-tracking

> 标签: brt-tracking, brt-vas100, laravel, smart-dato

## 简介

Laravel package for interfacing with the BRT VAS100 tracking SOAP webservices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
