# smart-dato/desk365-sdk

> 标签: SmartDato, desk365-sdk, laravel

## 简介

Desk365 Laravel SDK - A Laravel package to interact with the Desk365 API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
