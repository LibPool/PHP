# artificertech/laravel-hubspot

> 标签: artificertech, hubspot, laravel, laravel-hubspot

## 简介

A laravel wrapper for the https://github.com/HubSpot/hubspot-api-php package

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
