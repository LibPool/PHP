# magenxcommerce/module-platform

> 标签: PHP

## 简介

Platform status dashboard for the Magento admin — live health and metrics for MariaDB, Redis, RabbitMQ, OpenSearch, PHP-FPM and Nginx, read from the connection details Magento already holds. Read-only, admin-only, no storefront surface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
