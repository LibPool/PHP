# magenxcommerce/module-sitemap

> 标签: PHP

## 简介

Rewrites Magento XML sitemap URLs into the headless storefront's route shape (store/locale prefix, category and product path prefixes, url suffix stripping).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
