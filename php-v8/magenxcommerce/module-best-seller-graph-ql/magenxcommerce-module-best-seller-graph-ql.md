# magenxcommerce/module-best-seller-graph-ql

> 标签: PHP

## 简介

GraphQL coverage for Magento best sellers: a bestSellers query (store-wide or per category) and an Amazon-style per-category best-seller badge on products. Reads the sales_bestsellers_aggregated_* report tables; leaves the core modules untouched.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
