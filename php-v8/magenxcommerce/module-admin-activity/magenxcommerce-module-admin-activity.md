# magenxcommerce/module-admin-activity

> 标签: PHP

## 简介

Admin action audit log for Magento 2 — records admin add/edit/delete/view/print/mass-update operations with field-level before/after values, login and logout activity, and the IP address and user agent behind each action.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
