# magenxcommerce/module-catalog-graph-ql-batch

> 标签: PHP

## 简介

Removes per-product database lookups from Magento's GraphQL product lists: pre-loads catalog rule and tier prices once per product collection, and resolves ProductInterface.rating_summary and review_count with one query per list.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
