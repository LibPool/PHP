# magenxcommerce/module-garan-graph-ql

> 标签: PHP

## 简介

EU harmonised legal guarantee notice and EU GARAN durability label (Implementing Regulation (EU) 2025/1960) over GraphQL for headless storefronts. Fork of copex/module-warranty-label.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
