# magenxcommerce/module-graph-ql-app-server

> 标签: PHP

## 简介

PoC: serve Magento /graphql from a FrankenPHP worker that keeps the application bootstrapped in memory and resets request state between requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
