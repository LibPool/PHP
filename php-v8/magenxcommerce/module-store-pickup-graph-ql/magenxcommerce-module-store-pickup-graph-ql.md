# magenxcommerce/module-store-pickup-graph-ql

> 标签: PHP

## 简介

In-store pickup for a headless Magento storefront: an offline 'In-Store Pickup' shipping carrier, admin-configured physical store addresses, a storePickupLocations GraphQL query, a setStorePickupLocationOnCart mutation, and the chosen pickup location echoed on Cart / CustomerOrder. Leaves the core modules untouched.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
