# magenxcommerce/module-product-feed

> 标签: PHP

## 简介

Product feed generation and delivery for Magento 2 — define feeds in the admin, filter the catalog with the standard condition widget, render XML/CSV/TSV/JSONL from a safe template language, publish on a schedule, and deliver by public URL, FTP/SFTP, the Google Merchant API, or a push catalog API such as Meta's. Backend-only: there is no storefront GraphQL surface, because feeds are an operator feature with no storefront consumer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
