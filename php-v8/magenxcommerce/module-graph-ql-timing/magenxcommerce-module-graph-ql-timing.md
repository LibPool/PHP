# magenxcommerce/module-graph-ql-timing

> 标签: PHP

## 简介

Emits a Server-Timing response header with the GraphQL controller's dispatch duration so storefront request latency can be split into network vs Magento app time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
