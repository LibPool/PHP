# magenxcommerce/module-social-login-graph-ql

> 标签: PHP

## 简介

Headless social-login bridge: a secret-gated GraphQL mutation that verifies a provider-signed OpenID Connect ID token (Google, Apple) against the issuer's JWKS and exchanges it for a Magento customer token, find-or-creating the customer by the token's verified email.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
