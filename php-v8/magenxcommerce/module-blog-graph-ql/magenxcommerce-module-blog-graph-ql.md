# magenxcommerce/module-blog-graph-ql

> 标签: PHP

## 简介

GraphQL surface for Magenx_Blog: posts, categories, tags, related posts and related products, for a Next.js storefront.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
