# magenxcommerce/module-rma-graph-ql

> 标签: PHP

## 简介

GraphQL coverage for Magenx_Rma: customer + guest return lookup, return creation, comments, and the return-attribute metadata the headless create-return form needs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
