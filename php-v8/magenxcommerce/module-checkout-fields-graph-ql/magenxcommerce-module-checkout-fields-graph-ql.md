# magenxcommerce/module-checkout-fields-graph-ql

> 标签: PHP

## 简介

Order comment and delivery date / time slot for a headless Magento checkout, exposed over GraphQL: a setCheckoutFieldsOnCart mutation, Cart.checkout_fields with the server-computed delivery calendar, and the values echoed on CustomerOrder, the admin order view, the order grid and the order confirmation email. Hidden for in-store pickup. Leaves the core modules untouched.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
