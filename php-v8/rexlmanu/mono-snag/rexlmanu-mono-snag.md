# rexlmanu/mono-snag

> 标签: bugsnag, error, logging, monolog

## 简介

Bugsnag integration for monolog. An abstract handler that sends messages to Bugsnag

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
