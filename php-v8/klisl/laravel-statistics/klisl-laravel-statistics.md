# klisl/laravel-statistics

> 标签: laravel, statistics, statistics by IP

## 简介

Package for getting statistics by IP for your site in Laravel-5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
