# wpify/scoper

> 标签: composer-plugin, dependency-conflicts, isolation, namespace, php-scoper, prefixing, scoper, woocommerce, wordpress

## 简介

Composer plugin that scopes WordPress and WooCommerce dependencies for usage in WordPress plugins and themes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
