# tancky/upscale-calculator

> 标签: aspect-ratio, dimensions, dpi, image, print, resolution, upscale, upscaler

## 简介

Dependency-free PHP helpers for image upscaling math: scaled dimensions, the smallest upscale factor for a target size, and print sizes at a given DPI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
