# disruptiveadvertising/bladewind

> 标签: Ui Components, blade components, laravel, tailwindcss

## 简介

Laravel UI Components using TailwindCSS, Blade Templates and vanilla Javascript.  A clone of the original for customization.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
