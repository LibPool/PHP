# jane/openapi-runtime

> 标签: PHP

## 简介

Jane OpenAPI Runtime Library, dependencies and utility class for a library generated by jane/openapi

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
