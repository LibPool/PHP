# marcelxyz/php-xml-digital-signature

> 标签: pkcs, signature, xml, xml-dsig, xml-sig, xmldsig

## 简介

A PHP library for signing XML documents using digital signatures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
