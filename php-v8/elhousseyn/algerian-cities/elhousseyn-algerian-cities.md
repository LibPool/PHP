# elhousseyn/algerian-cities

> 标签: Algeria, Wilaya, cities, commune, laravel

## 简介

A Laravel package to create/load Cities and towns of Algeria

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
