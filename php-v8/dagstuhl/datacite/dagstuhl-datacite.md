# dagstuhl/datacite

> 标签: DOI registration, datacite, metadata

## 简介

A DataCite API client for creating/updating DOI metadata (Schema 4.4), developed and used by Dagstuhl Publishing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
