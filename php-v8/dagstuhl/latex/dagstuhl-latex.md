# dagstuhl/latex

> 标签: LaTeX-to-UTF8 conversion, latex, metadata

## 简介

A library for handling LaTeX files (parsing/manipulating/extracting metadata).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
