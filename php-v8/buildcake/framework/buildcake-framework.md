# buildcake/framework

> 标签: buildcake, code-generation, framework, php, scaffold

## 简介

Framework BuildCake - Scaffold de módulos, tabelas, APIs e serviços para geração de código (composer create-project).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
