# matryoshka-model/rest-wrapper

> 标签: api, matryoshka, model, rest, restful, wrapper

## 简介

Matryoshka wrapper aimed at creating restful API clients

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
