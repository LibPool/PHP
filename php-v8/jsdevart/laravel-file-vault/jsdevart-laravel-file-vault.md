# jsdevart/laravel-file-vault

> 标签: file-storage, file-upload, laravel, private-files, s3, signed-url

## 简介

Private file storage for Laravel with signed URLs and multi-context.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
