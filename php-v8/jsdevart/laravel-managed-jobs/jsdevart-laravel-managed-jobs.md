# jsdevart/laravel-managed-jobs

> 标签: PHP

## 简介

Framework plug-and-play para background jobs con lifecycle tracking, progreso en tiempo real y manejo de archivos en Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
