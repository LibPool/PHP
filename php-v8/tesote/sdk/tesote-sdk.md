# tesote/sdk

> 标签: Banking, api, payments, sdk, tesote

## 简介

Official PHP client SDK for the equipo.tesote.com API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/tesote/sdk.git
- Packagist 页面：https://packagist.org/packages/tesote%2Fsdk
