# rouxtaccess/laravel-sync

> 标签: database, development, laravel, rouxtaccess, sync

## 简介

Pull production databases, files and S3 buckets down to your local Laravel environment.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
