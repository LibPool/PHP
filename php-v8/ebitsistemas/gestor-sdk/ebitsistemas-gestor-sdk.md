# ebitsistemas/gestor-sdk

> 标签: ERP, api, gestor integrado, sdk

## 简介

SDK em PHP da API do Gestor Integrado (cadastros, vendas, compras, ordens de serviço, financeiro, estoque e notas fiscais).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
