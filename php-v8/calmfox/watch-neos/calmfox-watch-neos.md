# calmfox/watch-neos

> 标签: Neos, flow, health, monitoring, security

## 简介

Monitoring wnętrza Neosa dla Calmfox Watch: sekretny adres kontrolny ze stanem usług (baza, dysk, poczta, pamięć podręczna, publikacja zasobów, repozytorium treści), podstawowa higiena bezpieczeństwa i historia zmian wersji pakietów.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
