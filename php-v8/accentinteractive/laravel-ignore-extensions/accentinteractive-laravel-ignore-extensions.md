# accentinteractive/laravel-ignore-extensions

> 标签: accentinteractive, laravel-ignore-extensions

## 简介

Do not process URLs with a extensions like .jpg, .png et cetera.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
