# nettsite/nettmail-laravel

> 标签: laravel, nettmail

## 简介

NettMail Laravel package - Eloquent models, service provider, queued jobs, and Livewire admin UI for the NettMail core package

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
