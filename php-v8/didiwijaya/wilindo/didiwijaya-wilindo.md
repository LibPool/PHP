# didiwijaya/wilindo

> 标签: cities, districts, indonesia, laravel, php, provinces, villages, wilayah

## 简介

Package Laravel (Migration & Seeder) untuk wilayah Indonesia berdasarkan data SPLP Kemendagri

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
