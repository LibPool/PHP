# gsebastiao/laravel-settings

> 标签: Settings, configuration, laravel, multi-tenant, preferences, user-settings

## 简介

Settings para Laravel guardadas na base de dados: valores globais, por utilizador e por tenant, com tipos automáticos e cache.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
