# klimapi/php

> 标签: api, klimapi, php, rest, sdk

## 简介

This API offers you the possibility to calculate and offset emissions, create checkout links, get statistics and much more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
