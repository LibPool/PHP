# lucinda/framework

> 标签: Simple, caching, errors, fast, i18n, internationalization, light weight, localization, logging, mvc, nosql, oauth2, security, sql, templating

## 简介

Lucinda Framework 4.0: High performance, component-based PHP application skeleton

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
