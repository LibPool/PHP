# lucinda/process

> 标签: Streams, io multiplexing, pool, process, stderr, stdin, stdout

## 简介

Light weight API performing single/multiple shell command execution using IO multiplexing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
