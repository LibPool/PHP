# lucinda/errors

> 标签: aop, aspect oriented programming, errors, handler, renderer, reporter

## 简介

Bootstraps errors and handles them via reporters and renderers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
