# lucinda/oauth2-client

> 标签: client, oauth2, providers

## 简介

API abstracting communication with OAuth2 providers (eg: facebook) for PHP applications based on IETF standards

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
