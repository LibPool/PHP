# lucinda/sql-data-access

> 标签: data access, processing, querying, sql

## 简介

API abstracting communication with SQL providers (eg: MySQL) on top of PDO inspired by Java JDBC

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
