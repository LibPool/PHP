# manggala/universal-panel

> 标签: admin-panel, blade, inertia-react, inertia-vue, laravel, livewire, manggala, resource-builder, universal-panel, wordpress-sidebar

## 简介

Universal Multi-Stack Admin Panel & Resource Builder Framework for Laravel with 160px WordPress-Inspired Compact Sidebar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
