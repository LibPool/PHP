# manggala/tenancy

> 标签: laravel, manggala, multi-db, multi-tenancy, row-level-security, saas, single-db, subdomain, tenancy, tenant

## 简介

Universal Multi-Tenancy Engine for Laravel supporting Single-DB (Row-Level), Multi-DB & Hybrid Isolation Modes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
