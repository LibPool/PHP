# hellocron/php

> 标签: cron, dead-mans-switch, heartbeat, hellocron, monitoring, sdk, uptime

## 简介

Official PHP SDK for HelloCron: cron job, heartbeat and uptime monitoring. Ping API and Management API clients with typed errors, on any PSR-18 HTTP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
