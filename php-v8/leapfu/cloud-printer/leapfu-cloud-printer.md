# leapfu/cloud-printer

> 标签: cloud-printer, laravel, php sdk, printer, receipt, thermal-printer, thinkphp, 中午云, 云小票机, 云打印SDK, 优声云, 佳博云, 多驱动, 快递100, 打印驱动, 易联云, 映美云, 统一API, 芯烨云, 飞鹅云

## 简介

高扩展性云小票打印SDK，支持飞鹅云、芯烨云、易联云、快递100、映美云、佳博云、中午云、优声云等主流云打印服务，兼容 Laravel、ThinkPHP 等主流框架，统一API，易集成，易扩展。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
