# messaged/php-mime-mail-parser

> 标签: MimeMailParser, mail, mailparse, mime

## 简介

Mailparse extension wrapper for PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
