# sc-laravel-presets/default-tailwindcss

> 标签: laravel, preset, tailwindcss

## 简介

Laravel frontend preset for default setup and Tailwind CSS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
