# mmhospedagem/mvo-facebook-php

> 标签: experimental, facebook, mvo, persistent-session, php

## 简介

Módulos experimentais PHP para Páginas, conteúdo e negócios no Facebook Web.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
