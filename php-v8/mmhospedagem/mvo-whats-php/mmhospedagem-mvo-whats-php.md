# mmhospedagem/mvo-whats-php

> 标签: llm, mcp, messaging, multi-session, mvo, php, qr-code, whatsapp, whatsapp-web

## 简介

Biblioteca PHP nativa para WhatsApp: QR Code, sessões persistentes, mensagens, mídia, grupos e MCP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
