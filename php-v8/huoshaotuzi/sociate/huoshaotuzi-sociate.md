# huoshaotuzi/sociate

> 标签: PHP

## 简介

基于Laravel开发的第三方登录插件，支持QQ、新浪微博、百度登录。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
