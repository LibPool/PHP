# frontend-services/craft-soft-hyphen

> 标签: PHP

## 简介

Adds a soft hyphen (&amp;shy;) and non breaking space (&amp;nbsp;) button to CKEditor in Craft CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
