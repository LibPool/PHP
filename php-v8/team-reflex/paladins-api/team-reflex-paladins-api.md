# team-reflex/paladins-api

> 标签: api, esports, game, hirez, paladins

## 简介

Easy access to the Hi-Rez Studios API for Paladins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
