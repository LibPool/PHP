# vinktarhq/php

> 标签: analytics, error-tracking, monitoring, php, vinktar

## 简介

Vinktar for PHP: product analytics and error tracking with request-scoped identity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
