# bertoost/craft-ssmtpmailer

> 标签: Craft, craftcms, craftcms plugin, mailer, plugin, ssmtp

## 简介

Craft 3 CMS plugin for adding the sSMTP mailer (sendmail replacement).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
