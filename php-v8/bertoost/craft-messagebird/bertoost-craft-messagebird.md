# bertoost/craft-messagebird

> 标签: Craft, craftcms, craftcms plugin, messagebird, plugin, sms, whatsapp

## 简介

Craft CMS plugin for Messagebird messaging features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
