# bertoost/craft-mailerchain

> 标签: Chain, Craft, adapter, craftcms, craftcms plugin, mailer, plugin

## 简介

Craft CMS plugin for adding a chain of mail adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
