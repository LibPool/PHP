# s4studio/yii2-switchery-widget

> 标签: extension, s4studio, switchery, yii, yii 2, yii2

## 简介

iOS 7 style switch widget for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
