# hongyi/message

> 标签: PHP

## 简介

消息通知(机器人类型)集合，集合国内外各大平台的不同类型机器人的消息推送，支持每个类型机器人的不同消息体类型的推送和回复

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
