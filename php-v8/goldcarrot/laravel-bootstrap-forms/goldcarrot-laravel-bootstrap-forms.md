# goldcarrot/laravel-bootstrap-forms

> 标签: PHP

## 简介

Provides an easy way to use bootstrap components within your Laravel projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
