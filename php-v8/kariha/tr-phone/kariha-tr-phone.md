# kariha/tr-phone

> 标签: E164, Turkish, Turkiye, formatter, gsm, mobile, normalization, phone, phone-number, php, telephone, turkey, validation

## 简介

PHP toolkit for validating, normalizing, parsing and formatting Turkish phone numbers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
