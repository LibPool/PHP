# tajawal/lodash-php

> 标签: __, bottomline, functions, library, lodash, utility

## 简介

A full-on PHP manipulation utility-belt that provides support for the usual functional.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
