# gorriecoe/silverstripe-dbstringextras

> 标签: dbstring, silverstripe, string

## 简介

Adds extra methods to Silverstripe DBStrings to help manipulate them.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
