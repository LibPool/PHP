# gorriecoe/silverstripe-advancedemaillink

> 标签: bcc, cc, email, link, silverstripe

## 简介

Adds cc, bcc, subject and body options to email link type for Link Object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
