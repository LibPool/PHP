# preferans/oauth-bridge

> 标签: Authentication, api, auth, authorisation, authorization, micro, oauth, oauth 2, oauth 2.0, oauth2, phalcon, preferans, resource, secure, server

## 简介

A library focused on API Authentication for Phalcon applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
