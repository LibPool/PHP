# kaveraa/slug-history

> 标签: 301, doctrine, eloquent, laravel, permalink, redirect, seo, slug, sluggable, symfony, url

## 简介

Keep the old URLs working when a slug changes, for Laravel and Symfony/Doctrine: past slugs are remembered and answered with a 301 to the current address

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
