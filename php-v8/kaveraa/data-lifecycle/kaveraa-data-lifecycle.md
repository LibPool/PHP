# kaveraa/data-lifecycle

> 标签: anonymize, doctrine, eloquent, gdpr, inactive-users, laravel, lifecycle, privacy, retention, rgpd, symfony

## 简介

Keep personal data only as long as needed, for Laravel and Symfony/Doctrine: warn, disable with a grace period, then anonymise or delete

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
