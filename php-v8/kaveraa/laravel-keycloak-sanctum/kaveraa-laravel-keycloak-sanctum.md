# kaveraa/laravel-keycloak-sanctum

> 标签: Authentication, SPA, SSO, backchannel-logout, keycloak, laravel, oidc, openid-connect, sanctum, socialite

## 简介

Keycloak login (SSO) for a front-end with a Laravel API: Sanctum token, roles, back-channel logout and idle timeout

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
