# kaveraa/api-gouv-publique-fr

> 标签: Siren, Siret, adresse, api-gouv, ban, bundle, commune, france, geo, laravel, open-data, symfony

## 简介

Typed PHP client for French public APIs (company search, address and Geo) with Laravel and Symfony bridges. Unofficial.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
