# kaveraa/unaccent-search

> 标签: accent, diacritics, doctrine, dql, eloquent, laravel, like, search, symfony, unaccent

## 简介

Search without accents and case in SQL, for Laravel and Symfony/Doctrine (MySQL, MariaDB, PostgreSQL, SQLite)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
