# jonatas-sas/yii2-m2m-behavior

> 标签: Behavior, extension, many-to-many, relations, yii2

## 简介

A Yii2 behavior to easily manage many-to-many relations using ActiveRecord.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
