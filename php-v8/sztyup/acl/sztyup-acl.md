# sztyup/acl

> 标签: acl, auth, laravel, permissions, roles, security

## 简介

Light-weight role-based permissions for Laravel 5 with a great degree of customization

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
