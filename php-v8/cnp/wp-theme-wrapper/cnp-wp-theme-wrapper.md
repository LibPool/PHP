# cnp/wp-theme-wrapper

> 标签: PHP

## 简介

A wrapper function that intercepts WordPress' template_include function, allowing us to use base.php instead.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
