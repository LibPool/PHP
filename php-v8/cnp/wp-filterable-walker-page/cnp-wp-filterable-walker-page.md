# cnp/wp-filterable-walker-page

> 标签: PHP

## 简介

Add an args filter to the Page Walker, plus before and after arguments to match wp_nav_menu

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
