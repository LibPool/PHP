# isckosta/laravel-tiktok-shop

> 标签: TikTok , ecommerce, integration, laravel, tiktok-shop

## 简介

Laravel integration for TikTok Shop (multi-tenant, webhooks, DTOs, retries).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
