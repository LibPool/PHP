# gavinggordon/predefiner

> 标签: constants, environment, php, predefined, setting, setup

## 简介

A simple package to quickly and dynamically set PHP constants.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
