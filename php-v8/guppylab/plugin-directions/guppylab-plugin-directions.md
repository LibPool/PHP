# guppylab/plugin-directions

> 标签: directions, distance, eta, mapkit, mobile, nativephp, osrm, routing

## 简介

Real-route distance and ETA to multiple destinations for NativePHP Mobile: MapKit on iOS, OSRM on Android

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
