# guppylab/plugin-push

> 标签: FCM, apns, mobile, nativephp, notifications, push, remote

## 简介

Push notifications for NativePHP Mobile: direct APNs (.p8, no Firebase) on iOS and Firebase Cloud Messaging on Android, with payload delivery, notification taps, unenrolment and the badge

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
