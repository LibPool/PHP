# phpbb/pages

> 标签: extension, pages, phpbb, static

## 简介

An extension which allows you to add static pages to your phpBB forum

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://www.phpbb.com/customise/db/extension/pages/
- 源码仓库：https://github.com/phpbb-extensions/pages.git
