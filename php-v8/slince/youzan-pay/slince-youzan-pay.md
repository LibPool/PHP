# slince/youzan-pay

> 标签: alipay, wechat, youzan, 微信支付, 支付宝, 有赞

## 简介

An integrated alipay and wechat payment solution based on YouZan using php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
