# phannaly/php-datetime-khmer

> 标签: cambodia, datetime, helpers, khmer

## 简介

The PHP library for convert datetime to Khmer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
