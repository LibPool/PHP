# short-edition/knp-gaufrette-bundle

> 标签: abstraction, file, filesystem, media

## 简介

Allows to easily use the Gaufrette library in a Symfony project

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
