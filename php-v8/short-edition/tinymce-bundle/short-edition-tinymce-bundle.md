# short-edition/tinymce-bundle

> 标签: Symfony2, bundle, editor, tinymce, wysiwyg

## 简介

This Bundle integrates TinyMCE WYSIWYG editor into a Symfony2 project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
