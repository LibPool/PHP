# lucasmichot/eloquentuuid

> 标签: eloquent, laravel, uuid, versioning

## 简介

Provides a unique Base62-encoded UUID representing a given state of a model instance

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
