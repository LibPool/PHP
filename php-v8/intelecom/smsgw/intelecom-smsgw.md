# intelecom/smsgw

> 标签: api, gateway, intelecom, rest, sms, smsgw

## 简介

PHP client library for Intelecom SMS Gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
