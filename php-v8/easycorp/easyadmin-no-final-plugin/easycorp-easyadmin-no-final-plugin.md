# easycorp/easyadmin-no-final-plugin

> 标签: PHP

## 简介

It removes the 'final' PHP keyword from all EasyAdmin classes so you can extend those classes in your projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
