# agencypowerstack/typo3-blog-sync

> 标签: agency-powerstack, blog, cms, sync, typo3, webhook

## 简介

Synchronize blogs from Agency Powerstack to TYPO3 Blog extension via REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
