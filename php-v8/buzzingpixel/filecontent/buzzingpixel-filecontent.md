# buzzingpixel/filecontent

> 标签: Craft, cms, craft-plugin, craftcms, filecontent

## 简介

Add flat file content capability to your CraftCMS site

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
