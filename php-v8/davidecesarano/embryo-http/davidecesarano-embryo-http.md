# davidecesarano/embryo-http

> 标签: http-factory, http-message, php, psr-17, psr-7

## 简介

A PSR-7 and PSR-17 implementation for HTTP messages and factory.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
