# district5/mondoc

> 标签: district5, library, mondoc, mongo, mongodb, odm

## 简介

Mondoc is a lightweight and easy to use model and service based abstraction library for MongoDB

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
