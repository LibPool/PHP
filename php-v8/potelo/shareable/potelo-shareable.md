# potelo/shareable

> 标签: facebook, google plus, laravel, share, social, twitter

## 简介

A Laravel 4 package to make it easy to add social sharing buttons to your application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
