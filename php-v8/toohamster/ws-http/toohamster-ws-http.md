# toohamster/ws-http

> 标签: api-testing, assertion, curl, http, ws-http

## 简介

ws-http: Simplified, lightweight HTTP client library with assertion and scenario-based API testing engine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
