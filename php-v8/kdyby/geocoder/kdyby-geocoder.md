# kdyby/geocoder

> 标签: geo, geocoder, geocoding, geoip, google, kdyby, location, map, maps, nette, seznam

## 简介

Integration of willdurand/geocoder into Nette Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
