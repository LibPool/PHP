# raaabdullah1/meta-graph-errors

> 标签: Messenger, errors, facebook, graph-api, instagram, meta, retry, whatsapp

## 简介

Classify Meta Graph API, Instagram, Messenger and WhatsApp error codes into category, retryability and recovery action.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
