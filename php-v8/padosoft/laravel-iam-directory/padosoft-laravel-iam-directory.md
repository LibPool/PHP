# padosoft/laravel-iam-directory

> 标签: PHP

## 简介

Modulo opzionale Directory di Laravel IAM: LDAP/Active Directory (LdapRecord) in v1; SCIM in v2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
