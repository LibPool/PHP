# padosoft/laravel-flow-connect

> 标签: automation, connectors, http, laravel, laravel-flow, nodes, orchestration, triggers, webhooks, workflow

## 简介

Triggers and nodes for padosoft/laravel-flow: cron, event and signed-webhook triggers, plus HTTP/API, transform, condition, delay and batch graph nodes. Part of the Laravel Flow 2.0 suite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
