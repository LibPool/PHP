# padosoft/laravel-iam-agents

> 标签: ai-agents, authorization, delegated-access, iam, laravel, oauth2, rfc8693, token-exchange

## 简介

Delegated access for AI agents per Laravel IAM: agent registry, delegation grants con consenso step-up, OAuth2 Token Exchange (RFC 8693) con claim act, intersection PDP (utente ∩ agente), audit stream=delegation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
