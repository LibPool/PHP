# padosoft/laravel-rebel-email-otp

> 标签: Authentication, Passwordless, Rebel, email, laravel, login, otp, padosoft

## 简介

Login passwordless email-OTP enterprise per Laravel Rebel: anti-enumeration, rate-limit multidimensionale, multi-tenant/purpose/risk, emissione token Sanctum. Parte di padosoft/laravel-rebel-*.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
