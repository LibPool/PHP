# padosoft/laravel-presenter

> 标签: laravel-presenter, padosoft, present, presenter, view

## 简介

Implementation for Laravel of the presenter design pattern.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
