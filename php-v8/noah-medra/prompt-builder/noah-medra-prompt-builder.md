# noah-medra/prompt-builder

> 标签: PHP

## 简介

Compose and execute structured AI prompts in PHP with a fluent, framework-agnostic API (Laravel-friendly).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
