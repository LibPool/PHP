# podcasthosting/podcast-client-spotify

> 标签: api, feed, podcast, podcaster, podcasting, rss, spotify

## 简介

Create (add) and remove (delete) podcasts on Spotify

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
