# idleberg/wordpress-vite-assets

> 标签: vite, vite manifest, vitejs, wordpress

## 简介

Injects assets from a Vite manifest to the Wordpress head, supports themes and plugins

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
