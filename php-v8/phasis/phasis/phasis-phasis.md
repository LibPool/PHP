# phasis/phasis

> 标签: PHP

## 简介

Pure PHP JavaScript engine. Lexes, parses, and executes ECMAScript without Node.js, FFI, or extensions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
