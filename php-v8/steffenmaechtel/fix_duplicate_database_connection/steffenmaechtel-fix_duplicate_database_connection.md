# steffenmaechtel/fix_duplicate_database_connection

> 标签: cms, typo3

## 简介

TYPO3 CMS extension: fix duplicate database connection for old extensions using $GLOBALS['TYPO3_DB']

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
