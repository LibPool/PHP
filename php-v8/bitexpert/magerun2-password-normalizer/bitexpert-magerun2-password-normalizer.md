# bitexpert/magerun2-password-normalizer

> 标签: magerun2, n98-magerun2

## 简介

Plugin for netz98 Magerun2 to normalize all customer email addresses and passwords

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
