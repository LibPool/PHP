# jinyicheng/kim-web

> 标签: elegant, fast, framework, kim-framework, orm

## 简介

An elegant and fast php web framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：http://kimphp.com/
- 源码仓库：https://github.com/jinyicheng/kim-web.git
- Packagist 页面：https://packagist.org/packages/jinyicheng%2Fkim-web
