# yiranzai/file-cache

> 标签: file-cache, yiranzai

## 简介

PHP File Cache, use Separate Chaining resolve hash conflict. one cache, one file, one bucket.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
