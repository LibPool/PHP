# fev/serializer

> 标签: json, serialize, serializer, unserialize, xml, yaml

## 简介

Simple library for serialize/un(de)serialize JSON, YAML, XML.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
