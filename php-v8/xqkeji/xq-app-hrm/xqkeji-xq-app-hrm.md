# xqkeji/xq-app-hrm

> 标签: PHP

## 简介

一个基于新齐低代码开发框架(xqkeji)的快速后台管理系统(fast-admin)的企业人事管理模块。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
