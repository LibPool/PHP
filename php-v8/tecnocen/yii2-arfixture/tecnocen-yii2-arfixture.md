# tecnocen/yii2-arfixture

> 标签: Fixture, activerecord, ar, dao, testing, tests, yii, yii2

## 简介

Yii2 library to run fixtures the ActiveRecord Dao

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
