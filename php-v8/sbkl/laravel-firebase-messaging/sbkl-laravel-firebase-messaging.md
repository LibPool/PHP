# sbkl/laravel-firebase-messaging

> 标签: PHP

## 简介

Firebase Cloud Messaging integrated with Laravel based on kreait/laravel-firebase

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
