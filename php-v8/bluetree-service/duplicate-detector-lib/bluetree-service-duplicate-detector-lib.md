# bluetree-service/duplicate-detector-lib

> 标签: console, duplicate, files, hash

## 简介

Find duplicated files (single process or multiple processes, optionally through Redis) and list, report or delete them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
