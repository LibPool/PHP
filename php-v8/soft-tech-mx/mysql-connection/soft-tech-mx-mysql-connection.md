# soft-tech-mx/mysql-connection

> 标签: PHP

## 简介

Paquete PHP para realizar conexion con mysql de forma nativa usando un estilo orientado a objetos.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
