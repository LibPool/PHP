# soft-tech-mx/laravel-made

> 标签: boilerplate, laravel, softtechmx

## 简介

Conjunto base de dependencias y configuración inicial que SoftTechMX usa en todos sus proyectos Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
