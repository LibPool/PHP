# cybersafe-lab/saqr

> 标签: ISO27001, anthropic, claude, compliance, cybersecurity, grc, nca-ecc, pdpl, rag, retrieval-augmented-generation, sama, saudi-arabia

## 简介

Grounded retrieval-augmented Q&A library for Saudi Arabia's cybersecurity and data-protection frameworks (PDPL, NCA-ECC, NCA-CCC, SAMA, ISO 27001).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
