# cerbos/cerbos-sdk-laravel

> 标签: access-control, authorization, authz, cerbos, laravel, permission

## 简介

Cerbos PHP Laravel SDK for interacting with the Cerbos PDP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
