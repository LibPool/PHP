# presprog/contao-tooltipster

> 标签: PHP

## 简介

This Contao extension adds the tooltipster library to Contao. After installing the extension, simply add the j_tooltipster template to your page layout and start using Tooltipster.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
