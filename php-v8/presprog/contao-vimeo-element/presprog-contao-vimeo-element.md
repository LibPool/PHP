# presprog/contao-vimeo-element

> 标签: PHP

## 简介

This extension backports the Vimeo content element introduced in Contao 4.2 to Contao 3.5. Edit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
