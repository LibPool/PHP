# 3sidedcube/laravel-redoc

> 标签: 3sidedcube, laravel-redoc

## 简介

A lightweight package for rendering API documentation using OpenAPI and Redoc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
