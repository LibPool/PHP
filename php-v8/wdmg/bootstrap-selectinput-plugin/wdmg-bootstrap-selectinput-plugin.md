# wdmg/bootstrap-selectinput-plugin

> 标签: autocomplete, bootstrap, dropdown, select, twitter-bootstrap

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
