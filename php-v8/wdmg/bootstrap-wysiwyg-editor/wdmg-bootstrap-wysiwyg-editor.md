# wdmg/bootstrap-wysiwyg-editor

> 标签: bootstrap, editor, twitter-bootstrap, wysiwyg

## 简介

Simple WYSIWYG editor plugin for Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
