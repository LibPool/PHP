# wdmg/yii2-editor

> 标签: bootstrap, editor, extension, wdmg, widget, wysiwyg, yii, yii2

## 简介

WYSIWYG editor for Yii2 based on Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
