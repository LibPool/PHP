# camindo/module-pdf

> 标签: TCPDF, camindo, cms, module, pdf

## 简介

camindo CMS module: PDF documents from frontend templates (CMS:PDF_* commands) based on tc-lib-pdf

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
