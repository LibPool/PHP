# genesis/db-backup-restore

> 标签: BDD, Behat, browser, data, database, mysql, pdo, sql, test, testing, web

## 简介

Quickly backup and restore your local database after a test run.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
