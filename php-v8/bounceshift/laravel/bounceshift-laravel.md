# bounceshift/laravel

> 标签: bounceshift, deliverability, email, email-validation, email-verification, laravel, sdk, validation-rule

## 简介

Laravel adapter for the BounceShift email-validation SDK — facade, config, and a Deliverable validation rule.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
