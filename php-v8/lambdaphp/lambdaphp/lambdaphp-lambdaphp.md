# lambdaphp/lambdaphp

> 标签: PHP

## 简介

Quick and Dirty PHP website hosting on Aws Lambda (pay by requests instead of monthly hosting fees)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
