# melentev-av/opmin

> 标签: Opcache, differential testing, opcodes, optimization, rector

## 简介

Minimizes PHP opcodes without changing behavior: counts opcodes per function, applies Rector and LLM rewrites, verifies behavior on every step.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
