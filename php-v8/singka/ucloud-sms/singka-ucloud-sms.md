# singka/ucloud-sms

> 标签: PHP

## 简介

ThinkPHP系列Ucloud的短信接口，支持ThinkPHP6、ThinkPHP5.1和ThinkPHP5.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
