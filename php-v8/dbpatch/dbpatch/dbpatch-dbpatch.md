# dbpatch/dbpatch

> 标签: database, db, migrations

## 简介

DbPatch is a commandline utility to manage/track (my)sql/php patch files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
