# jeyroik/sm-plugin-error-state

> 标签: PHP

## 简介

Plugin for jeyroik StateMachine. Let to use error state - valid state but in invalid case.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
