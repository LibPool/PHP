# jeyroik/sm-plugin-on-failure

> 标签: PHP

## 简介

Plugin for jeyroik StateMachine. Allow to use on failure transition.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
