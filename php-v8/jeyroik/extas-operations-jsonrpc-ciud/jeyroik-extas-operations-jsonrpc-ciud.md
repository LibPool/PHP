# jeyroik/extas-operations-jsonrpc-ciud

> 标签: PHP

## 简介

Meta package with create, index, update and delete methods for JSON RPC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
