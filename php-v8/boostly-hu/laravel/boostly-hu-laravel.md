# boostly-hu/laravel

> 标签: boostly, laravel, leads, marketing, popup, webhook

## 简介

Boostly integráció Laravelhez — kampány-snippet beágyazása és lead-webhookok fogadása aláírás-ellenőrzéssel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
