# uneca/plotly-chart-editor

> 标签: chart, laravel, livewire, plotly, plotly-chart-editor, uneca

## 简介

A reactive visual Plotly chart builder package for Laravel/Livewire.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
