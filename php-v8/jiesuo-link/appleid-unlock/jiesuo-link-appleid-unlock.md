# jiesuo-link/appleid-unlock

> 标签: account-sharing, apple-id, appleid, appleid-unlock, laravel, panel-integration, slim, sspanel, sspanel-uim, v2board, xboard

## 简介

Apple ID unlock and account sharing connector for V2Board, Xboard and SSPanel-UIM, with Laravel and Slim integration for Jiesuo.link V2 APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
