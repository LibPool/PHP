# waqidevs/waqi-php-client

> 标签: AQICN, WAQI, air quality, api, wrapper

## 简介

PHP wrapper for the AQICN (air quality) APIs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
