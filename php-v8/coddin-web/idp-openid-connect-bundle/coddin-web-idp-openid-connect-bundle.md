# coddin-web/idp-openid-connect-bundle

> 标签: Authentication, OpenID Connect, authorisation, authorization, bundle, identity provider, idp, oidc, symfony, symfony-bundle

## 简介

A Symfony bundle to set up an IdentityProvider with OpenID Connect implemented

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
