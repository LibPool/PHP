# cjpanilag/simple-notifications

> 标签: SimpleNotifications, laravel

## 简介

Simplified notifications for AWS SNS, FCM Push Notifications, emails, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
