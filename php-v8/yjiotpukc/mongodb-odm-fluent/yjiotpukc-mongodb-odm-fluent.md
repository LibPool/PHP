# yjiotpukc/mongodb-odm-fluent

> 标签: data mapper, database, doctrine, fluent, laravel, mapping driver, mappings, mongodb, odm

## 简介

A fluent PHP mapping driver for Doctrine MongoDB ODM.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
