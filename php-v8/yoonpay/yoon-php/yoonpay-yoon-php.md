# yoonpay/yoon-php

> 标签: Sénégal, dexpay, laravel, naboopay, orange-money, paydunya, payments, symfony, wave

## 简介

PHP client for Yoon, the self-hosted payment gateway for African payment providers, with Laravel and Symfony integrations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
