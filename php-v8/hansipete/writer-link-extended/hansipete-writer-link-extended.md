# hansipete/writer-link-extended

> 标签: kirby, kirby-plugin

## 简介

Extends the Kirby Writer Link dialog to allow for toggling a button class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
