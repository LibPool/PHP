# dustingraham/react-mysql

> 标签: asynchronous, mysql, react

## 简介

Non-blocking MySQLi database access with PHP. Designed to work with reactphp/react.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
