# ablogcms/plugin-skeleton

> 标签: PHP

## 简介

Skeleton for a-blog cms plugin development, with a PHPUnit setup based on the bundled SamplePlugin

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
