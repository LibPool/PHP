# agweria/mpesa

> 标签: agweria, agweria llc, api, equitel, equity, laravel, mobile money, mpesa, mpesa api, payments, pesa, samerior group, samueldervis

## 简介

MPESA API wrapper for Laravel 8 with dashboards and multiple accounts for C2B, B2C and B2B.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
