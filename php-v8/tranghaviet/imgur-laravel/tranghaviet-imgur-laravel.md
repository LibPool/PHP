# tranghaviet/imgur-laravel

> 标签: api, imgur, laravel, wrapper

## 简介

Laravel Package for Imgur API 3. Provides easy access to the j0k3r/php-imgur-api-client library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
