# smartystudio/gallerycrud

> 标签: backpack crud, galleries, gallery, laravel backpack, manage galleries

## 简介

Gallery management interface for Laravel using Backpack CRUD.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
