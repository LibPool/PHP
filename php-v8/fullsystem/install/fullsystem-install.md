# fullsystem/install

> 标签: frontend, installer, laravel, recipe, shadcn

## 简介

Install a recipe into your project: files that mirror the project root, and a schema declaring what has to happen for them to work.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
