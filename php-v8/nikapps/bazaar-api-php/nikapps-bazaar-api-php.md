# nikapps/bazaar-api-php

> 标签: Bazaar, CafeBazaar, Cafebazaar Api, In App Purchase, api, iap, wrapper

## 简介

A PHP API wrapper for CafeBazaar Rest Api v2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
