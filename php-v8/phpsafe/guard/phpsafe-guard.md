# phpsafe/guard

> 标签: csrf, firewall, php, scanner, security, sql-injection, static-analysis, waf, xss

## 简介

Zero-dependency security layer for PHP: request shield, static code scanner and safe helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
