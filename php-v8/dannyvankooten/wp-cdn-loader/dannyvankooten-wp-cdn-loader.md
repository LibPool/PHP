# dannyvankooten/wp-cdn-loader

> 标签: cdn, wordpress

## 简介

Replaces WordPress theme & plugin asset URL's with a CDN's URL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
