# riki137/multitron

> 标签: async, batch-processing, concurrency, multi-threading, parallel-processing, php, process-management, symfony-console, task-orchestrator, task-runner, workflow

## 简介

Tool for managing fast both asynchronous and multi-threaded execution of tasks. Focused on performance and pleasant CLI interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
