# bvlinsky/explorer

> 标签: elastic, elasticsearch, explorer, laravel, scout, search

## 简介

Next-gen Elasticsearch driver for Laravel Scout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
