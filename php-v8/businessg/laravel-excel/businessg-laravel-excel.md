# businessg/laravel-excel

> 标签: excel, export, import, laravel, php

## 简介

Excel 同步/异步智能配置导入导出组件，为 Laravel 框架提供强大的 Excel 处理能力,支持无限极列头配置,页码、列头、列样式配置。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
