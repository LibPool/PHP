# feyman/laravel-sql-logger

> 标签: laravel-sql-logger, log-query, lumen-query-logger, query-logger

## 简介

A tool to log all queries for laravel/lumen application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
