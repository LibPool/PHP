# sveltorestframework/sveltorestframework

> 标签: Simple, api, framework, mvc, rest

## 简介

A micro mvc framework useful for rapid REST API developement

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
