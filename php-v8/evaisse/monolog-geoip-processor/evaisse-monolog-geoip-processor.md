# evaisse/monolog-geoip-processor

> 标签: geo-ip, geoip, maxmind, monolog, processor

## 简介

A GeoIP decorator/processor for monolog

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
