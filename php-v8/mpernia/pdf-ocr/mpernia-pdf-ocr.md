# mpernia/pdf-ocr

> 标签: OCR, Tesseract, pdf, pdf-parser, poppler, text-extraction

## 简介

Extensible PDF reader with native text extraction and optional OCR adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
