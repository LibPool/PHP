# zembula/module-connect

> 标签: adobe-commerce, magento, magento2, zembula

## 简介

Connects a Magento Open Source or Adobe Commerce store to Zembula through a Magento integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
