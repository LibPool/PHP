# snowplow/snowplow-tracker

> 标签: analytics, event analytics, snowplow

## 简介

Snowplow event tracker for PHP. Add analytics into your PHP apps and scripts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
