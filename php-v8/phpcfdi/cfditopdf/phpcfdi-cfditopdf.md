# phpcfdi/cfditopdf

> 标签: cfdi, factura, invoice, mexico, pdf

## 简介

Create a generic PDF file from a CFDI 3.3 & 4.0 (CLI included)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
