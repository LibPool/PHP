# phpcfdi/sat-catalogos

> 标签: catalogos, cfdi, sat

## 简介

Catálogos de SAT para CFDI 3.3, CFDI 4.0 y Nómina 1.2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
