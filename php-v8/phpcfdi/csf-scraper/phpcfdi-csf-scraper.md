# phpcfdi/csf-scraper

> 标签: csf, phpcfdi, sat

## 简介

Obtiene los datos fiscales actuales de una persona moral o física dado su RFC y CIFID

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
