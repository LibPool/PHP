# phpcfdi/sat-estado-retenciones

> 标签: cfdi, mexico, retenciones, sat

## 简介

Consulta el estado de un CFDI de Retenciones haciendo scrap del sitio del SAT

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
