# phpcfdi/cfdi-expresiones

> 标签: cfdi, phpcfdi, sat

## 简介

Genera expresiones de CFDI 4.0, CFDI 3.3, CFDI 3.2, RET 1.0 y RET 2.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
