# phpcfdi/cfdi-sat-scraper

> 标签: Scrap, cfdi, mexico, sat

## 简介

Web Scraping para extraer facturas electrónicas desde la página del SAT

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
