# chleniang/cls-captcha

> 标签: PHP

## 简介

适用于 TP6/TP8 的验证码库；尤其适用于API开发，不使用session的场景；基于 think-captcha 改写;

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
