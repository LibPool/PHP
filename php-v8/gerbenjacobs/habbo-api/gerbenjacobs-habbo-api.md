# gerbenjacobs/habbo-api

> 标签: api, habbo, habbowidgets, wrapper

## 简介

A PHP wrapper for the (undocumented) Habbo Hotel API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
