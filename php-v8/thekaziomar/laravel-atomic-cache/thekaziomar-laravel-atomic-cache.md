# thekaziomar/laravel-atomic-cache

> 标签: atomic, cache, laravel, redis, stampede-protection

## 简介

A simple, stampede-proof, and tag-aware caching package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
