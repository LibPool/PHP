# lavaphp/http-client

> 标签: PHP

## 简介

LavaPHP http-client pack — small PSR-18 client on ext-curl with timeouts, bounded retries, and non-2xx as LavaProblems.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
