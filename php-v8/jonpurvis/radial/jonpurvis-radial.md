# jonpurvis/radial

> 标签: blade, chart, donut, livewire

## 简介

Beautiful donut and pie charts for Flux UI. Drop-in components with hover effects, legends, and dark mode support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
