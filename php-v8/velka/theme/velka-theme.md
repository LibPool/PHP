# velka/theme

> 标签: asset, laravel, layout, theme

## 简介

Theme support for Laravel with assets, theme extends etc. (this fork add support for typescript, tailwind & meta json file theme:create-v2)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
