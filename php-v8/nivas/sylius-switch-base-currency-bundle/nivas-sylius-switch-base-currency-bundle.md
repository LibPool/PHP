# nivas/sylius-switch-base-currency-bundle

> 标签: currency, sylius, sylius-plugin

## 简介

Plugin for Sylius that adds new cli command witch switches base currency for another currency in the system

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
