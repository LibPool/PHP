# queueit/knownuserv3

> 标签: PHP

## 简介

The Queue-it Security Framework is used to ensure that end users cannot bypass the queue by adding a server-side integration to your server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
