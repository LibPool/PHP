# spira/zuora-laravel-sdk

> 标签: laravel, lumen, sdk, soap, zuora

## 简介

Lumen/Laravel service provider for interfacing with Zuora SOAP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
