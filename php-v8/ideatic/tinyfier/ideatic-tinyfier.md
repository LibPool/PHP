# ideatic/tinyfier

> 标签: JS, css, html, image, minification, minify, optimization

## 简介

Complete suite for compressing, preprocessing, and optimizing HTML/Javascript/CSS and Images.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
