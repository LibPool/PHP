# beyerz/aws-queue-bundle

> 标签: Queue Management, SNS, Simple Notification Service, Simple Queue Service, Symfony2, amazon web services, aws, sqs, symfony

## 简介

Symfony bundle to connect AWS sns and sqs to create offline queue processing

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
