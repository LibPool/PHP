# beyerz/api-adapter-bundle

> 标签: REST API, Symfony2, api, api adapter, soap api, symfony

## 简介

Symfony bundle to act as an api connector and adapter for third party apis

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
