# jeffersongoncalves/laravel-ahrefs

> 标签: API-Client, Backlinks, ahrefs, keywords, laravel, seo

## 简介

A lightweight Ahrefs API v3 client for Laravel — domain rating, backlinks, referring domains, organic keywords, top pages, and keyword research.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
