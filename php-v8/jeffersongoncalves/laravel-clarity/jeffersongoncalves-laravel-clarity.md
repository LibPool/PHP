> 标签: analytics, clarity, heatmaps, jeffersongoncalves, laravel, laravel-clarity, microsoft-clarity, session-recording, spatie-laravel-settings

## 简介

Microsoft Clarity for Laravel: inject the Clarity tracking tag (heatmaps, session recordings, insights) into your Blade layouts, with the project ID stored in the database via spatie/laravel-settings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
