# jeffersongoncalves/laravel-saved-filter

> 标签: filters, laravel, multi-tenant, saved-filters, saved-views, table-views

## 简介

Saved table filters for Laravel: store, share and restore filters, sort, search and column visibility per user, tenant and resource, with presets, JSON export/import and pruning.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
