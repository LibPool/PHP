# jeffersongoncalves/filament-sso-client

> 标签: Authentication, SSO, filament, filament-plugin, laravel, single-logout, single-sign-on

## 简介

Filament panel integration for laravel-sso-client: SSO login page, forced IdP redirect and federated logout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
