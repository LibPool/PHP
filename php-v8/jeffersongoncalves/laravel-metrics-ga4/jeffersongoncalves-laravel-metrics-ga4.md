# jeffersongoncalves/laravel-metrics-ga4

> 标签: Metrics, analytics, data-api, ga4, google-analytics, laravel, pageviews, visitors

## 简介

Google Analytics 4 metrics for Laravel: visitors, sessions, pageviews, bounce rate, session duration, top pages, sources, countries, browsers, devices and realtime users via the GA4 Data API, authenticated with a service account.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
