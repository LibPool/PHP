# jeffersongoncalves/laravel-buffer

> 标签: Buffer, api, bufferapp, laravel, social-media

## 简介

PHP/Laravel client for the Buffer (bufferapp.com) REST API v1: user, profiles, and scheduled/pending/sent updates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
