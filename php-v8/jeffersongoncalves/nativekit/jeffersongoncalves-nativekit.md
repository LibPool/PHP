> 标签: desktop-app, electron, filament, filament-starter-kit, filament-v3, laravel, laravel-starter-kit, livewire, nativephp, nativephp-starter-kit, starter-kit, tailwindcss

## 简介

NativeKit starter kit built on Laravel 13.x, Filament 3.x and NativePHP for native desktop applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
