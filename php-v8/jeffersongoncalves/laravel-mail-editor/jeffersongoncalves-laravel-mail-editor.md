# jeffersongoncalves/laravel-mail-editor

> 标签: email, email-builder, email-template, html-email, laravel, mail, newsletter

## 简介

Block-based email templates for Laravel: 22 email-safe blocks, table-based inline-CSS HTML export, template variables, review workflow, versioning, A/B variants, brand kits, themes and quality checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
