# jeffersongoncalves/filament-translation-manager

> 标签: filament, filament-plugin, filament-translation-manager, i18n, jeffersongoncalves, laravel, localization, translation-manager, translations

## 简介

Translation manager for Filament: edit app, JSON and vendor package translations from the panel, filter the keys missing per locale and export the result back to lang files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
