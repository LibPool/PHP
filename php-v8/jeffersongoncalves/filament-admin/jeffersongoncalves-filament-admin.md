# jeffersongoncalves/filament-admin

> 标签: admin, admins, filament, filament-plugin, laravel, multi-auth, starter-kit

## 简介

Filament Admin model, AdminResource, status-aware Login page and plugin for a separate admin guard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
