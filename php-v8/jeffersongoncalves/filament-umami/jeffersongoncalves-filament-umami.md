# jeffersongoncalves/filament-umami

> 标签: filament-umami, jeffersongoncalves, laravel

## 简介

Filament plugin for Umami analytics — tracking script injection and a Settings Page to manage Umami configuration directly from your Filament panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
