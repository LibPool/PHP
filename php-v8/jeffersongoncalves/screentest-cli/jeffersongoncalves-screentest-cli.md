# jeffersongoncalves/screentest-cli

> 标签: cli, documentation, filament, laravel, puppeteer, screenshots

## 简介

CLI tool for automated screenshot generation of Filament plugins.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
