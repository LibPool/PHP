# jeffersongoncalves/laravel-telegram-logger

> 标签: jeffersongoncalves, laravel, laravel-telegram-logger, logging, monolog, telegram, telegram-bot

## 简介

Send Laravel logs to a Telegram chat with deduplication, configurable error grouping, rate limiting, async delivery, forum topics and a graceful no-op when the bot is not configured.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
