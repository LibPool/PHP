# jeffersongoncalves/laravel-cnpj

> 标签: cnpj, jeffersongoncalves, laravel, laravel-cnpj, minha-receita, receita-federal

## 简介

A simple and efficient Laravel package for querying Brazilian company registrations (CNPJ), including the new alphanumeric format, through the Minha Receita API with local database caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
