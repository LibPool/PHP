> 标签: content-security-policy, csp, filament, filament-plugin, filament-security-headers, hsts, jeffersongoncalves, laravel, security-headers, spatie-laravel-settings

## 简介

Filament settings page for laravel-security-headers: edit the Content Security Policy, response headers and HSTS from the panel, with a report-only mode to try a policy before enforcing it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
