# jeffersongoncalves/laravel-report-url

> 标签: download-links, expiring-links, laravel, reports, signed-urls, temporary-files

## 简介

Temporary, signed, expiring download links for generated files in Laravel, with owner checks, download tracking and pruning.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
