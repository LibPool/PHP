# jeffersongoncalves/laravel-customer-io

> 标签: Customerio, api, client, customer-io, laravel, marketing, messaging, transactional

## 简介

Laravel client for Customer.io's Track and App APIs: customer profiles, events, campaigns and transactional messaging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
