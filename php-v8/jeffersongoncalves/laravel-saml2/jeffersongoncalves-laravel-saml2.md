# jeffersongoncalves/laravel-saml2

> 标签: SAML2, SSO, adfs, azure-ad, entra-id, jeffersongoncalves, keycloak, laravel, multi-tenant, okta, onelogin, saml, single-sign-on

## 简介

Multi-tenant SAML2 Service Provider for Laravel. Connect any number of Identity Providers (Entra ID, Okta, Google Workspace, Keycloak, ADFS, OneLogin) on top of the OneLogin toolkit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
