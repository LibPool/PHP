# jeffersongoncalves/filament-cnpj-field

> 标签: cnpj, filament, filament-cnpj-field, jeffersongoncalves, laravel

## 简介

The Filament CNPJ Field is a custom input component for Brazilian company registrations (CNPJ), including the new alphanumeric format. It handles CNPJ formatting, check digit validation and automatic company lookup through the Minha Receita API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
