# jeffersongoncalves/teamkitv4

> 标签: filament, filament-starter-kit, filament-v4, laravel, laravel-starter-kit, livewire, starter-kit, tailwindcss

## 简介

TeamKit starter kit built on Laravel 13.x and Filament 4.x with a ready-to-use multi-panel structure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
