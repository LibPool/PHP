# jeffersongoncalves/filament-ace-editor-field

> 标签: ace-editor, filament, filament-ace-editor-field, jeffersongoncalves, laravel

## 简介

A Laravel Filament v5 field that integrates the Ace code editor into your forms, providing a rich, syntax‑highlighted code editing experience.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
