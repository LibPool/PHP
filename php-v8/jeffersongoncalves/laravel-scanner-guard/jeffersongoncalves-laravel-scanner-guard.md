# jeffersongoncalves/laravel-scanner-guard

> 标签: ban, firewall, laravel, scanner-guard, security, waf

## 简介

Detect and ban vulnerability-scanner traffic on Laravel apps, with optional ASN-level blocking via laravel-visitor-fingerprint

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
