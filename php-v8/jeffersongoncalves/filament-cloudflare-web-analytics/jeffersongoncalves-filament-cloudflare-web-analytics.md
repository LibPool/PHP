# jeffersongoncalves/filament-cloudflare-web-analytics

> 标签: cloudflare, cloudflare-web-analytics, cookieless, filament, filament-cloudflare-web-analytics, filament-plugin, jeffersongoncalves, laravel, privacy, spatie-laravel-settings, web-analytics

## 简介

Filament plugin for Cloudflare Web Analytics: injects the tracking script into your panels and adds a settings page, powered by Spatie Laravel Settings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
