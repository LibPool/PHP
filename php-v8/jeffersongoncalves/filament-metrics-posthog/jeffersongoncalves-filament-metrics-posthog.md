# jeffersongoncalves/filament-metrics-posthog

> 标签: Metrics, analytics, filament, filament-metrics-posthog, filament-plugin, jeffersongoncalves, laravel, posthog, spatie-laravel-settings, widgets

## 简介

Filament plugin with PostHog dashboard widgets (realtime visitors, visitors chart, top pages, sources, countries, browsers and devices) and a Settings Page powered by Spatie Laravel Settings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
