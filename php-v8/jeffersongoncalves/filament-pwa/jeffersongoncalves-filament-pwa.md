# jeffersongoncalves/filament-pwa

> 标签: favicon, filament, filament-pwa, jeffersongoncalves, laravel, manifest, pwa

## 简介

Filament plugin that injects the full PWA <head> markup (favicons, Apple touch icons, manifest link, msapplication tiles, theme-color and mobile web-app metas) into your panels via laravel-pwa-favicon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
