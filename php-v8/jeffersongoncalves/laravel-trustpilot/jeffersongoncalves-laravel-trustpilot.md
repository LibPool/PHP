# jeffersongoncalves/laravel-trustpilot

> 标签: Trustpilot, api, client, invitations, laravel, ratings, reputation, reviews

## 简介

A Laravel client for the Trustpilot API — business units, public and private reviews, replies, email invitations, and review tags.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
