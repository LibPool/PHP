# jeffersongoncalves/laravel-autentique

> 标签: assinatura-digital, autentique, e-signature, graphql, laravel, webhooks

## 简介

Laravel client for the Autentique GraphQL API (e-signature): documents, signers, folders, sandbox, rate-limit aware requests and signed webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
