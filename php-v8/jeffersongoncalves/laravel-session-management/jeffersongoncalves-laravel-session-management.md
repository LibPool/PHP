# jeffersongoncalves/laravel-session-management

> 标签: database-sessions, laravel, session, session-management, sessions

## 简介

Read and manage Laravel's database session table (sessions) through a model and a service layer: decode payloads, revoke and prune sessions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
