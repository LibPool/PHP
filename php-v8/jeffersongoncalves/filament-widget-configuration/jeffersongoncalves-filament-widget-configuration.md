# jeffersongoncalves/filament-widget-configuration

> 标签: filament, filament-plugin, laravel, lazy-loading, polling, widget

## 简介

Configure global defaults for Filament widget polling interval and lazy loading, without editing every widget class by hand

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
