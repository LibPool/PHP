# jeffersongoncalves/laravel-auto-translate

> 标签: jeffersongoncalves, laravel, laravel-auto-translate, mymemory, translatable, translation

## 简介

Queued machine translation for Laravel translatable model attributes (spatie/laravel-translatable). Ships a free, keyless MyMemory driver that protects product names, vendor/package ids and code from being translated, splits long text under the request limit, and never saves a quota warning as a translation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
