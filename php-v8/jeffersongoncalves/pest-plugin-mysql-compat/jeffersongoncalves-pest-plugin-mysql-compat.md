# jeffersongoncalves/pest-plugin-mysql-compat

> 标签: laravel, mysql, pest, pest-plugin, sqlite, testing

## 简介

MySQL compatibility shims (UDFs) for running MySQL-flavored Pest/PHPUnit test suites against SQLite

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
