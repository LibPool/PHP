# jeffersongoncalves/filament-saml2

> 标签: SAML2, SSO, adfs, entra-id, filament, filament-plugin, filament-saml2, jeffersongoncalves, keycloak, laravel, multi-tenant, okta, saml, single-sign-on

## 简介

Filament 5 plugin for SAML2 single sign-on with multi-tenant Identity Providers, powered by jeffersongoncalves/laravel-saml2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
