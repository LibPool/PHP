# jeffersongoncalves/laravel-intercom

> 标签: api, crm, customer-messaging, intercom, laravel, support

## 简介

PHP/Laravel client for the Intercom REST API: contacts, conversations, messages, companies, tags, articles, admins and events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
