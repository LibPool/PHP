# jeffersongoncalves/laravel-settings-discord-logger

> 标签: Settings, discord, jeffersongoncalves, laravel, laravel-discord-logger, laravel-settings-discord-logger, logging, spatie-laravel-settings

## 简介

Manage laravel-discord-logger from the database with spatie/laravel-settings: webhook URL, level, mentions, deduplication, rate limits and more, injected at runtime instead of read from .env.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
