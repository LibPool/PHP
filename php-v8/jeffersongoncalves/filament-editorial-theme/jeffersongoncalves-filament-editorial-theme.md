# jeffersongoncalves/filament-editorial-theme

> 标签: dark-mode, editorial, filament, filament-plugin, filament-theme, jeffersongoncalves, laravel, terminal, theme

## 简介

Editorial Terminal: a paper + terminal theme for Filament 3, 4 and 5. Fraunces / DM Sans / JetBrains Mono typography, amber palette, light and dark schemes, sidebar layout fixes, footer and status partials and an optional terminal-style login.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
