# jeffersongoncalves/filament-oidc

> 标签: Authentication, SSO, filament, filament-oidc, filament-plugin, jeffersongoncalves, laravel, oidc, openid-connect, single-sign-on, socialite

## 简介

Filament 5 plugin for OpenID Connect (OIDC) single sign-on, powered by jeffersongoncalves/laravel-oidc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
