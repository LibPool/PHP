# daniel-jorg-schuppelius/php-elearning-toolkit

> 标签: LTI, cmi5, elearning, lms, scorm, xAPI

## 简介

Framework-freie E-Learning-Standards für PHP: SCORM 1.2/2004, xAPI, cmi5 und LTI 1.3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
