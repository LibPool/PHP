# ekyna/payum-monetico-bundle

> 标签: CIC, bundle, monetico, payum, php, symfony

## 简介

Symfony Bundle for Payum Monetico (Credit Mutuel/CIC) gateway

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
