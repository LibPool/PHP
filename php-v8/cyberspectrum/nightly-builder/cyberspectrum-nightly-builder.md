# cyberspectrum/nightly-builder

> 标签: PHP

## 简介

Create an nightly package from a composer designed repository including all dependencies for nightly distribution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
