# anil/apexdocs

> 标签: Postman, api, bruno, documentation, insomnia, laravel, openapi, php, swagger, symfony, webhook

## 简介

Framework-agnostic OpenAPI 3.1 documentation generator. Works with Laravel, Symfony, Slim, or any PHP 8.2 project. Zero framework dependencies in the core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
