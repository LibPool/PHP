# iresis/simple-qrcode

> 标签: Simple, generator, laravel, qrcode, wrapper

## 简介

Modern QR Code generator for Laravel based on SimpleSoftwareIO/simple-qrcode.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
