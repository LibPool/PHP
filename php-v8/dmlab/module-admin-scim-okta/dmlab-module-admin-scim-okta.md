# dmlab/module-admin-scim-okta

> 标签: PHP

## 简介

Okta setup for the admin-scim SCIM 2.0 server — admin guidance for wiring an Okta SCIM app. Installing it pulls dmlab/module-admin-scim.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
