# dmlab/module-typesafe-core

> 标签: ai, api client, classification, jev, llm, magento 2, magento2, magento2-module, typesafe

## 简介

TypeSafe (Jev) AI client for Magento 2: shared connection with your own encrypted API key, response cache, monthly token budget, retries and rate limiting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
