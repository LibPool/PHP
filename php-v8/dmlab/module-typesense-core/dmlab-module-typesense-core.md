# dmlab/module-typesense-core

> 标签: PHP

## 简介

Typesense access layer for Magento 2: HTTP client, collection lifecycle, aliases, document writes, synonym sets, schema reconciler, diagnostic CLI. No catalog or search-subsystem knowledge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
