# dmlab/module-sso-core

> 标签: PHP

## 简介

Shared OIDC/SSO engine for DmLab identity products (generic OIDC client, mapping engine, provider preset contract).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
