# kynetcode/wpzylos-wp-cli

> 标签: cli, commands, migrations, wordpress, wp-cli, wpzylos

## 简介

WP-CLI bridge for WPZylos framework (only loaded when WP_CLI)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
