# lordoffreaks/puzzle

> 标签: blade, generator, grunt, laravel, rest, site, static

## 简介

Simple static sites with Laravel's Blade + Grunt + REST server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
