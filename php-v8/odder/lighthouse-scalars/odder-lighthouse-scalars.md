# odder/lighthouse-scalars

> 标签: graphql, laravel, lighthouse, php

## 简介

A collection of custom scalar types for usage with https://github.com/webonyx/graphql-php

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
