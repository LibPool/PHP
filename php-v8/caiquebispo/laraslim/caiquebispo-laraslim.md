# caiquebispo/laraslim

> 标签: api, backend, composer, framework, laravel, laravel-like, lightweight, microframework, mvc, php, php-framework, rest, slim, slim-framework

## 简介

A lightweight PHP microframework combining Slim and Laravel features for fast and structured API development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
