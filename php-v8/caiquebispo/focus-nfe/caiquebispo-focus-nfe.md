# caiquebispo/focus-nfe

> 标签: PHP

## 简介

PHP SDK para a API Focus NFe com suporte multi-CNPJ - Emissão de NFe, NFCe, NFSe, CTe, MDFe e mais

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
