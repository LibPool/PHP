# mixudev/security-defense

> 标签: SIEM, alerting, anti-redos, brute-force, credential-stuffing, fail2ban, impossible-travel, laravel, quarantine, security, security-defense, threat-detection, waf

## 简介

Enterprise-grade, modular, and configurable Laravel security defense package for threat detection, correlation, IP quarantine, alerting, and prevention without duplicating auth.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
