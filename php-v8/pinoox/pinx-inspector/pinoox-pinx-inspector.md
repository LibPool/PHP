# pinoox/pinx-inspector

> 标签: Devtools, inspector, pinoox, pinx

## 简介

Development-only Pinx Inspector dashboard for Pinoox projects (single-app and multi-app platform)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
