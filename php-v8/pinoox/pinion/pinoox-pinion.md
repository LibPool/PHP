# pinoox/pinion

> 标签: axios, chunk, laravel, pinion, pinoox, resumable, upload

## 简介

Pinion — resumable chunked upload protocol for PHP (Pinoox, Laravel, any framework)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
