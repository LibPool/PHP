# pinoox/pinx-cli

> 标签: cli, hmvc, pinoox, pinx

## 简介

Developer CLI for single-app Pinoox projects — scaffold, dev, build, and release .pinx packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
