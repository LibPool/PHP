# blackpig-creatif/epitre

> 标签: BlackpigCreatif, epitre, filament, filament-plugin, filamentphp, laravel

## 简介

A filamentPHP plugin to manage email templates for Mailables

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
