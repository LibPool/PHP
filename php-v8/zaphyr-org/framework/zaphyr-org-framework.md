# zaphyr-org/framework

> 标签: framework, zaphyr

## 简介

A PHP framework based on ZAPHYR repositories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://zaphyr.org
- 源码仓库：https://github.com/zaphyr-org/framework.git
- Packagist 页面：https://packagist.org/packages/zaphyr-org%2Fframework

## 历史版本号

- 当前版本：1.0.0-alpha.8

- -

## 获取地址

- Composer 安装：`composer require zaphyr-org/framework`
- Packagist 仓库：https://repo.packagist.org/p2/zaphyr-org/framework.json
- 许可证：MIT
- PHP 要求：>=8.1
