# zaphyr-org/http-message

> 标签: http, http-factory, http-message, psr-17, psr-7

## 简介

Lightweight and strict implementation of PSR-7 HTTP Message including PSR-17 HTTP Factories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
