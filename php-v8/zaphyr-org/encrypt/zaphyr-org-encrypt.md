# zaphyr-org/encrypt

> 标签: encrypt, opensll, security

## 简介

A convenient interface for encrypting and decrypting text via OpenSSL using AES-128 and AES-256 encryption.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
