# zaphyr-org/container

> 标签: Autowiring, PSR-11, container, dependency, di, injection, provider, service

## 简介

Powerful auto wiring dependency injection container including PSR-11.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
