# hn/typo3-agent

> 标签: PHP

## 简介

TYPO3 extension that integrates an AI agent directly into TYPO3, using the MCP ToolRegistry for native tool execution with an OpenAI-compatible LLM API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
