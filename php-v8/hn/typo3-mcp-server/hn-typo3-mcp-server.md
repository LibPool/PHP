# hn/typo3-mcp-server

> 标签: PHP

## 简介

TYPO3 extension that provides a Model Context Protocol (MCP) server for interacting with TYPO3 pages and records

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
