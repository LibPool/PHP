# meta-engine/laravel-meta

> 标签: api, facebook, laravel, meta, sdk

## 简介

A modular Meta API SDK/integration package for Laravel, with optional persistence and optional automation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
