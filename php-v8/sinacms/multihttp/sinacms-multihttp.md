# sinacms/multihttp

> 标签: api, async, asynchronous, concurrency, curl, http, multi, parallel, php, requests, rest, restful, threads

## 简介

a tool for  multi-curl written in php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
