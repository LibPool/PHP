# ahmed-bhs/pyra

> 标签: ci, phpunit, quality, test, test-pyramid, testing

## 简介

Standalone CLI that validates the shape of your test pyramid (unit/integration/e2e ratios) for any PHP project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
