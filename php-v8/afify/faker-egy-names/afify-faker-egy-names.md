# afify/faker-egy-names

> 标签: arabic, egy-names, egyptian, faker, names, onomastics, testing

## 简介

Faker provider for grounded Egyptian names — the same generate() rules as faker-egy-names for Python.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
