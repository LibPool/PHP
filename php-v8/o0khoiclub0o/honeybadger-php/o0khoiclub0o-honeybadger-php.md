# o0khoiclub0o/honeybadger-php

> 标签: error, exception, honeybadger, reporting

## 简介

Unofficial PHP library for reporting errors to honeybadger.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
