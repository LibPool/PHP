# agoradesign/agoramobilemenu

> 标签: PHP

## 简介

Agoradesign Drupal 8 Mobile Menu Module. Provides a mobile menu block, allowing to combine different menus into one.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
