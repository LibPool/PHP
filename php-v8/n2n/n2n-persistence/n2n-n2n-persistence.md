# n2n/n2n-persistence

> 标签: db meta api, n2n, orm, persistence

## 简介

Persistence library for n2n. Includes ORM and Meta API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
