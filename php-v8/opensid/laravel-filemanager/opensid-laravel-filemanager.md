# opensid/laravel-filemanager

> 标签: OpenSID, filemanager, laravel

## 简介

Storage/Flysystem-backed Laravel file manager package, derived from Responsive Filemanager

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
