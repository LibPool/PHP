# devgarden/simpleq

> 标签: MQ, SF2, queue, queueing, scheduler, simpleq, symfony, worker

## 简介

Generic queue system based on Symfony. Light weight, easy and fast to configure and initiate.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
