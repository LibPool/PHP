# shewa12/wp-http-client

> 标签: http_client, wp_remote_request

## 简介

A wrapper class for making HTTP requests using WordPress wp_remote_request API's.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
