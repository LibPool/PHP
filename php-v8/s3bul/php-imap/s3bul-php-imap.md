# s3bul/php-imap

> 标签: imap, mail, mailbox, php, pop3, receive emails

## 简介

Manage mailboxes, filter/get/delete emails in PHP (supports IMAP/POP3/NNTP)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
