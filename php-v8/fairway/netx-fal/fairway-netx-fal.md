# fairway/netx-fal

> 标签: Asset Browser, DAM, File abstraction layer, NetX, assets, digital asset management, fairway, fal, file storage, images, typo3

## 简介

Integrates NetX Digital Asset Management with TYPO3 and provides access to centrally managed digital assets from within the TYPO3 backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
