# alexsancho/wp-admin-no-ajax

> 标签: PHP

## 简介

A WordPress plugin that lightens the WP AJAX routine and directs the requests to front-end rather than admin back-end.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
