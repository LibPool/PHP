# sinkcup/laravel-filesystem-cos-updated

> 标签: PHP

## 简介

A Cos storage filesystem for Laravel. 升级依赖版，支持 guzzle 7、Laravel 8

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
