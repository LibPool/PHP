# appotter/phppdf

> 标签: PHPPdf, Thai PHPPdf, pdf

## 简介

Pdf and graphic files generator library for PHP (Combined with Thai font named `THSarabun`)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
