# php-spellcheck/spellcheck-core

> 标签: aspell, code-quality, continuous-integration, developer-tools, dictionary, hunspell, i18n, icu, ispell, l10n, lint, linter, messageformat, php, php-parser, pspell, psr-6, spell-check, spell-checker, spellcheck, spelling, static-analysis, symfony, translation, translations, typo, typos, xliff, yaml

## 简介

Framework-agnostic PHP spell checking engine for source code and translation files. Hunspell, Aspell, pspell or pure PHP backends, character-accurate positions, PSR-6 caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
