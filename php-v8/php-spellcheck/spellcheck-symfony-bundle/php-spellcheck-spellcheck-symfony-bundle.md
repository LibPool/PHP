# php-spellcheck/spellcheck-symfony-bundle

> 标签: aspell, code-quality, continuous-integration, developer-tools, hunspell, i18n, icu, l10n, linter, php, spell-checker, spellcheck, spelling, static-analysis, symfony, symfony-bundle, translations, typo

## 简介

Spell check Symfony translations and PHP code in CI. Hunspell/Aspell backends, ICU aware, baseline for legacy projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
