# cruworldwine/cru-api-php

> 标签: api, cru, cruworldwine, sdk, trading, wine

## 简介

PHP SDK for the Cru Trading API, Cru World Wine's partner REST API v1.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
