# responsivevoice/sdk

> 标签: api, responsivevoice, sdk, speech-synthesis, text-to-speech, tts, voice

## 简介

Official PHP client for the ResponsiveVoice text-to-speech API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
