# elpandape/quipu-laravel

> 标签: cpe, facturacion-electronica, invoicing, laravel, peru, sunat, ubl

## 简介

Laravel integration for quipu — SUNAT electronic invoicing (CPE Peru). Wires the quipu emitter into the Laravel container, config and facades.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
