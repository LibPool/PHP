# elpandape/filament-activitylog

> 标签: Audit, activitylog, filament, filament-plugin, laravel

## 简介

An activity log panel for Filament, built on spatie/laravel-activitylog

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
