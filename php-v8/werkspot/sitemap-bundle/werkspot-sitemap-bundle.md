# werkspot/sitemap-bundle

> 标签: Sitemap, bundle, seo, symfony

## 简介

Bundle for generating dynamic sitemap.xml content with support for multiple sections

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
