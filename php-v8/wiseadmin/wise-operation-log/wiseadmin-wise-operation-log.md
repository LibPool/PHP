# wiseadmin/wise-operation-log

> 标签: PHP

## 简介

WiseAdmin 操作日志扩展包 — 基于 PHP 8 Attribute 的声明式操作日志记录，支持敏感数据脱敏、异常检测与自动归档

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
