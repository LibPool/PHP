# wiseadmin/wise-backup

> 标签: PHP

## 简介

WiseAdmin 数据库备份与恢复包 — 一键备份、多地容灾、自动清理，支持本地/FTP/SFTP/S3 多种存储驱动

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
