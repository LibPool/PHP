# wiseadmin/wise-health-check

> 标签: environment, health, health-check, monitoring, thinkphp, wiseadmin

## 简介

WiseAdmin 环境与健康检测包 — 服务器环境诊断、PHP 扩展检查、目录权限验证与系统状态实时监控

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
