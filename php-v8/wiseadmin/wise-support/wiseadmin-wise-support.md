# wiseadmin/wise-support

> 标签: PHP

## 简介

WiseAdmin 基础设施层 — ExtPoint 扩展注册中心 / Auth+JWT 统一认证 / ServiceBus 服务总线 / Connector 连接器 / CircuitBreaker 断路器 / Backoff 退避策略 / DistributedLock 分布式锁 / RateLimiter 限流 / ConfigCheck 配置检查 / Context 请求上下文 / Crypto AES-GCM / WebSocket 基础设施 / Pipeline / Exception 错误码体系

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
