# wiseadmin/wise-webhook

> 标签: thinkphp, webhook, webhook-client, webhook-server, wiseadmin

## 简介

WiseAdmin Webhook 发送与接收解决方案 — 支持签名、重试、退避、多端点、队列处理

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
