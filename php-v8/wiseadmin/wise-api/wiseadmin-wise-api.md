# wiseadmin/wise-api

> 标签: api, api-log, jwt, rate-limit, sign, thinkphp, wiseadmin

## 简介

WiseAdmin API 快速开发工具包 — 提供限流、签名验证、JWT 鉴权、统一响应格式、调试面板与 API 日志记录能力

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
