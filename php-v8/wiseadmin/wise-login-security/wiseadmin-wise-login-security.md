# wiseadmin/wise-login-security

> 标签: 2fa, captcha, device-management, ip-blacklist, login-security, thinkphp, totp, wiseadmin

## 简介

WiseAdmin 登录安全包 — 验证码校验、失败次数锁定、IP 黑白名单、双因素认证（TOTP）与可信设备管理

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
