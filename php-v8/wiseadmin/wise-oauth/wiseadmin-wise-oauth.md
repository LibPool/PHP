# wiseadmin/wise-oauth

> 标签: dingtalk, github, oauth, qq, socialite, thinkphp, wechat, wiseadmin

## 简介

WiseAdmin 第三方 OAuth 登录包 — 支持微信/QQ/GitHub/钉钉/Gitee/Google/微博等平台，自动关联或创建账号，多账号绑定解绑

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
