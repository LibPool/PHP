# wiseadmin/wise-auth

> 标签: access-control, auth, permission, rbac, role, thinkphp6, thinkphp8

## 简介

WiseAdmin 通用 RBAC 权限管理包 — 支持多应用、多用户类型、角色继承（RBAC1）与职责分离约束（RBAC2）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
