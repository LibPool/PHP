# wiseadmin/wise-image

> 标签: gd, image, imagick, thinkphp, wiseadmin

## 简介

WiseAdmin 图片处理包 — 支持 GD/Imagick 双驱动、阿里云 OSS 风格参数处理、防盗链与签名验证

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
