# wiseadmin/wise-form-schema

> 标签: form, schema, thinkphp, wiseadmin

## 简介

WiseAdmin 统一表单定义语言内核 — Fluent API 字段构建器 + 验证规则生成 + 数据过滤

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
