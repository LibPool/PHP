# wiseadmin/wise-attachment

> 标签: attachment, file-manager, thinkphp6, upload, wiseadmin

## 简介

WiseAdmin 多驱动附件管理包 — 支持本地、FTP、七牛云、阿里云 OSS、腾讯云 COS 存储，集成图片处理、软删除与多态关联

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
