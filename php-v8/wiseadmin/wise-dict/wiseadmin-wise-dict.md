# wiseadmin/wise-dict

> 标签: Dict, Settings, config, configuration, dictionary, thinkphp6, wiseadmin

## 简介

WiseAdmin 键值配置与字典管理包 — 支持多类型值、分组缓存、历史版本追溯与 HTML 净化过滤

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
