# wiseadmin/wise-notification

> 标签: dingtalk, email, message, notification, sms, thinkphp

## 简介

WiseAdmin 多通道消息通知组件 — 支持邮件、短信、钉钉、站内信等通道，提供模板引擎、中间件与事件驱动能力

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
