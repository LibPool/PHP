# wiseadmin/wise-jwt

> 标签: auth, jwt, thinkphp, token, wiseadmin

## 简介

WiseAdmin JWT 令牌管理包 — 签发、校验、吊销、续签，支持 HMAC/RSA/ECDSA/EdDSA 多种算法

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
