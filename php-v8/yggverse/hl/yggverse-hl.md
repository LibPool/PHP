# yggverse/hl

> 标签: half-life, hl, ipv6, master, xash3d, yggdrasil

## 简介

PHP 8 library for Half-Life API with native IPv6 / Yggdrasil support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
