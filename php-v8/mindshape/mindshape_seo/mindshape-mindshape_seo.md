# mindshape/mindshape_seo

> 标签: PHP

## 简介

Comprehensive SEO suite for TYPO3 featuring Google SERP preview, metadata validation, and 410 support. Provides privacy-compliant analytics integration (GA4/Matomo/GTM) and flexible multi-domain configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
