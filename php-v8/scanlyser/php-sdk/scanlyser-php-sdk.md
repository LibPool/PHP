# scanlyser/php-sdk

> 标签: accessibility, api, scanlyser, sdk, seo, wcag

## 简介

PHP SDK for the ScanLyser API — accessibility, SEO, and security scanning.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
