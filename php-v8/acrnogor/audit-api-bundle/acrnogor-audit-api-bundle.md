# acrnogor/audit-api-bundle

> 标签: Audit, api, bundle, symfony

## 简介

Symfony bundle providing an API interface for damienharper/auditor-bundle audits.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
