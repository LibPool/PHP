# fromholdio/silverstripe-notrackingtabs

> 标签: silverstripe

## 简介

Removes link dependency tracking tabs from SilverStripe CMS data object fields.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
