# xpbl4/yii2-typeahead-widget

> 标签: extension, typeahead, widget, yii2

## 简介

Yii2 wrapper for the Twitter Typeahead widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
