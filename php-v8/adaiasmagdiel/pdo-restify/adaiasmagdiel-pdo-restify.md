# adaiasmagdiel/pdo-restify

> 标签: PHP

## 简介

A framework-agnostic REST API layer on top of PDO, for MySQL, MariaDB and SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
