# ddbase3/php-struql

> 标签: parser, php, query, query-language, sql, struql

## 简介

A PHP implementation of the Struql query language — parse, merge, expand, and translate Struql JSON into SQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
