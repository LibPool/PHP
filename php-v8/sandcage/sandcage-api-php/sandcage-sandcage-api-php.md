# sandcage/sandcage-api-php

> 标签: api, cdn, client library, cloud, image management, library, php, sandcage, sdk

## 简介

PHP client library for SandCage's API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
