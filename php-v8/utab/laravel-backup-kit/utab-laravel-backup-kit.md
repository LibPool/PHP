# utab/laravel-backup-kit

> 标签: arvancloud, backup, database, laravel, monitoring, s3, spatie

## 简介

Encrypted, monitored database backups for Laravel on S3-compatible storage, built on spatie/laravel-backup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
