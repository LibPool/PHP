# mmtech/mmt-risk-sdk

> 标签: Guzzle, MMT, laravel, rest, risk

## 简介

PHP SDK for MMT Risk Management Service API (Guzzle transport, typed commands and responses). Laravel 11–13 compatible.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
