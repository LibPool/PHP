# diegofxm/cofacture

> 标签: UBL2.1, colombia, cufe, dian, documento-soporte, electronic-invoicing, facturacion-electronica, nomina-electronica, ubl, xades

## 简介

A PHP toolkit for Colombian DIAN electronic invoicing: UBL 2.1 document generation, XAdES-EPES signing, CUFE/CUDE/CUDS/CUNE computation, and a SOAP client for DIAN's WcfDianCustomerServices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
