# frantzmicccoli/geocoder-php-geoportail-lu

> 标签: geocoder, geoportail

## 简介

Geocoder provider for the geoportail.lu API https://wiki.geoportail.lu/doku.php?id=en:api:rest

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
