# carbonorm/carbonphp

> 标签: carbon, io, pipes, routing, session, sockets

## 简介

A PHP 8.1+ tool kit featuring RESTFUL ORM, sockets, session management, and routing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
