# yeonik/laravel-legacy-password-upgrader

> 标签: Authentication, bcrypt, hashing, laravel, legacy, migration, password, rehash

## 简介

Transparently upgrade legacy password hashes (MD5/SHA1/salted) to bcrypt the first time a user signs in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
