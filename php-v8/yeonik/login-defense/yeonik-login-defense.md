# yeonik/login-defense

> 标签: brute-force, captcha, lockout, login, psr, rate-limiting, security

## 简介

Progressive login protection for PHP: track failed attempts, escalate to a captcha challenge, then to a timed lockout. Framework-agnostic core, thin Laravel bridge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
