# xisio/yii2-uuid-behavior

> 标签: before, beforesave, save, uuid, yii2

## 简介

Set UUID before save on Yii 2 models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
