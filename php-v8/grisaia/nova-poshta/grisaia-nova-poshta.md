# grisaia/nova-poshta

> 标签: 2.0, api, nova, nova poshta, poshta, Нова Пошта

## 简介

PHP library to communicate with Ukrainian delivery service Nova Poshta via API 2.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
