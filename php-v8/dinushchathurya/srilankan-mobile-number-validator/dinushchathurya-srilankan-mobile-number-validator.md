# dinushchathurya/srilankan-mobile-number-validator

> 标签: Mobile Number Vaidator, Mobile Number Validator SriLanka, SriLankan Mobile Number Validator, SriLankan Phone Number Validation, Srilankan Mobile Validator

## 简介

This package validate all Sri Lanakan phone number including mobile and landline numbers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
