# sandronimus/nelmio-form-get-parameter-plugin-bundle

> 标签: PHP

## 简介

Extends NelmioApiDocBundle by providing ability to auto-register simple forms items as GET parameters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
