# atk14/http

> 标签: atk14, http, request

## 简介

PHP classes encapsulating HTTP request, HTTP response, cookie, uploaded file etc. This package is part of the ATK14 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
