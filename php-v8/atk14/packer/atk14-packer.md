# atk14/packer

> 标签: PHP

## 简介

Converts any PHP variable into a URL-safe string with HMAC signing, optional AES-256-CBC encryption, and optional gzip compression.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
