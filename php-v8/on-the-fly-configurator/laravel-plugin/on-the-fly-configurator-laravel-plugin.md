# on-the-fly-configurator/laravel-plugin

> 标签: cms, laravel, laravel-plugin, ontheflyintegration

## 简介

Integration of On The Fly to your eCommerce website. This allows users to navigate from OTF to the eCommerce cart with the OTF plugins added to their cart.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
