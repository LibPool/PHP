# dutchcodingcompany/laravel-hetzner-dns-api

> 标签: dutchcodingcompany, laravel, laravel-hetzner-dns-api

## 简介

An unofficial PHP SDK for the Hetzner DNS API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
