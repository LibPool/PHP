# iliaal/phonetic

> 标签: beider-morse, bmpm, daitch-mokotoff, double-metaphone, fuzzy-matching, match-rating, metaphone, nysiis, phonetic, php-extension, pie, soundex

## 简介

Native phonetic matching for PHP: Double Metaphone, Beider-Morse Phonetic Matching, Daitch-Mokotoff Soundex, NYSIIS, and Match Rating Approach.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
