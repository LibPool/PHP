# oihana/php-ftp

> 标签: file-transfer, ftp, ftp-client, ftps, php, tls

## 简介

The Oihana PHP FTP library - a modern, strongly-typed FTP/FTPS client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
