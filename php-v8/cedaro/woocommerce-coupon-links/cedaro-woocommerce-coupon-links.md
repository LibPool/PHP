# cedaro/woocommerce-coupon-links

> 标签: wordpress

## 简介

A WordPress plugin to automatically apply a WooCommerce coupon code to the cart with a URL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
