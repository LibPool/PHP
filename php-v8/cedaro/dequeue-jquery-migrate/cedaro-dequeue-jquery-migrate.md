# cedaro/dequeue-jquery-migrate

> 标签: wordpress

## 简介

A WordPress plugin to remove the jquery-migrate.js script dependency.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
