# bibitelles/buscador-top-noticias

> 标签: PHP

## 简介

Projeto que busca e retorna as postagens de maior relevância do dia, utilizando o agregador social Reddit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
