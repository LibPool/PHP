# skrull/sylius-quick-edit-bar-plugin

> 标签: open-source, quick-edit, sylius, sylius-plugin, test-application

## 简介

Adds a quick edit bar with links into the Sylius admin to the storefront for logged-in administrators.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
