# naiuz/sdk

> 标签: API-Client, Transcription, chat-completions, embeddings, neuronai, sdk, speech-to-text, text-to-speech, uzbek, voice-cloning

## 简介

The official PHP client for the NeuronAI API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
