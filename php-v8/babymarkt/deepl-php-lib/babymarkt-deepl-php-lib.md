# babymarkt/deepl-php-lib

> 标签: babymarkt, deepl, deeply, i18n, translation, translator

## 简介

DeepL API Client Library supporting PHP >= 7.3 && PHP <= 8.1

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
