# sanf/iran-bank-detector

> 标签: Bank, Iran-Bank-Detector, IranBankDetector, iran, php

## 简介

A lightweight PHP library to detect Iranian banks from card numbers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
