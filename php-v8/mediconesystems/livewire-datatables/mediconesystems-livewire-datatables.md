# mediconesystems/livewire-datatables

> 标签: laravel, livewire, php

## 简介

Advanced datatables using Laravel, Livewire, Tailwind CSS and Alpine JS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
