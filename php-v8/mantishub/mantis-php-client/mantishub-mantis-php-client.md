# mantishub/mantis-php-client

> 标签: MantisBT, api, mantishub, soap

## 简介

Library to interact with MantisBT or MantisHub via SOAP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
