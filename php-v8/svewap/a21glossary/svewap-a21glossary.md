# svewap/a21glossary

> 标签: TYPO3 CMS, glossary, typo3

## 简介

automatic conversion of all abbreviations and acronyms in the special tags for accessibility issues

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
