# svewap/ws-scss

> 标签: compiler, css, sass, scss, scssphp, typo3

## 简介

Compiles SCSS to CSS at runtime with caching, TypoScript variables and EXT: import support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
