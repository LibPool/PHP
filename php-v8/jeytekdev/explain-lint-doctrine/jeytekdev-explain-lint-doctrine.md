# jeytekdev/explain-lint-doctrine

> 标签: dbal, doctrine, explain, query-analysis, sql, testing

## 简介

Doctrine DBAL bridge for jeytekdev/explain-lint — captures queries via a Driver\Middleware and re-runs EXPLAIN on the same connection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
