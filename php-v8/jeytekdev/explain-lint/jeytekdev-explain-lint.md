# jeytekdev/explain-lint

> 标签: explain, index, mysql, performance, phpunit, postgresql, query-analysis, sql, testing

## 简介

Re-runs EXPLAIN against every SQL query captured during your test suite and fails the build on full table scans, lost indexes, filesort and temporary tables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
