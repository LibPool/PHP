# jeytekdev/explain-lint-laravel

> 标签: explain, laravel, query-analysis, sql, testing

## 简介

Laravel bridge for jeytekdev/explain-lint — captures queries via DB::listen() and provides a service provider with auto-discovery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
