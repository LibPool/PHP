# jeytekdev/explain-lint-codeception

> 标签: codeception, explain, query-analysis, sql, testing

## 简介

Codeception bridge for jeytekdev/explain-lint — analyzes and reports captured queries via a Codeception\Extension, for projects whose tests run through codecept run instead of vendor/bin/phpunit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
