# jeytekdev/explain-lint-yii2

> 标签: explain, query-analysis, sql, testing, yii2

## 简介

Yii2 bridge for jeytekdev/explain-lint — wraps the DB connection's PDO handle and re-runs EXPLAIN on the same connection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
