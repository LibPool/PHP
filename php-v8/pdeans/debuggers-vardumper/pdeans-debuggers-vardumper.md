# pdeans/debuggers-vardumper

> 标签: VarDumper, debug, debugger, vardump

## 简介

Extension of Symfony's VarDumper component, with a Github inspired color theme.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
