# muchwat/opendataloader-pdf-laravel

> 标签: converter, extraction, laravel, markdown, opendataloader, opendataloader-pdf, pdf

## 简介

Laravel wrapper around the opendataloader-pdf CLI: turn a PDF into Markdown, one string per physical page, via Laravel's Process facade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
