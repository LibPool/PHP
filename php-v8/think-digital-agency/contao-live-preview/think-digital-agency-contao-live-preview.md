# think-digital-agency/contao-live-preview

> 标签: backend, contao, contao-bundle, contao-extension, frontend edit helper, frontend editor, frontend helper, hover, live preview, preview, sidebar

## 简介

Live preview sidebar for the Contao 5 backend — articles and content elements hot-refreshed in real time, with hover inspection and one-click edit navigation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
