# snroki/date-interval-bundle

> 标签: dateinterval, iso 8601, milliseconds

## 简介

Override the php DateInterval class to allow milliseconds (ISO 8601)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
