# fudaoyuan/phpexcel-package

> 标签: PHP

## 简介

在millionmile/php-spreadsheet基础上修改的PHPspreadsheet封装类库，方便导出导入数据

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
