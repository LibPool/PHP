# done/php-altcoinrpc

> 标签: Guzzle, altcoin, api, jsonrpc

## 简介

Altcoin JSON-RPC client based on GuzzleHttp

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
