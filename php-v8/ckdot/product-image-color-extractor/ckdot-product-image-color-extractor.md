# ckdot/product-image-color-extractor

> 标签: PHP

## 简介

ckdot/product-image-color-extractor is a PHP library for extracting colors from product images like they are common in E-Commerce.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
