# gosimple/tezga

> 标签: E-Invoice, ekasa, fiscal-receipt, fiscalization, gosimple, pos, sdk, sef, serbia, suf, tezga, v-pfr

## 简介

Official PHP SDK for the Tezga Fiscal API: issue and fiscalize legal receipts in Serbia (eKasa / SUF) over a single REST API, no L-PFR hardware. A GoSimple product.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
