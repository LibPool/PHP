# gosimple/rs-fiscal

> 标签: fiscal, fiscalization, gosimple, ips-qr, nbs, pib, serbia, tezga, validation

## 简介

Serbian fiscal helpers for PHP: PIB (tax ID) validation and NBS IPS QR code generation. A GoSimple product.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
