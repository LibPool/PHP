# gosimple/tezga-laravel

> 标签: E-Invoice, ekasa, fiscalization, gosimple, laravel, sef, serbia, tezga, webhook

## 简介

Laravel integration for the Tezga Fiscal API: config, a Tezga facade, and a signed webhook route. A GoSimple product.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
