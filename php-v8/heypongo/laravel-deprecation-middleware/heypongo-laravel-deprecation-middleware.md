# heypongo/laravel-deprecation-middleware

> 标签: PHP

## 简介

A Laravel middleware to signal HTTP route deprecation (Deprecation, Sunset, Link headers)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
