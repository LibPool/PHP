# mukadi/wp-sf-skeleton

> 标签: Skeleton, boilerplate, symfony, wordpress

## 简介

A Composer builded stack for combining Wordpress and Symfony

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
