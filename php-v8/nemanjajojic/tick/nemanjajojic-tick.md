# nemanjajojic/tick

> 标签: Tasks, cron, cron-scheduler, php, psr-20, psr-3, scheduler, task-scheduler, tick

## 简介

Tick — a PHP task scheduler. One tick per cron minute. No daemon, no framework, no surprises.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
