# samoscon/controller-framework

> 标签: OO framework, controller, mvc

## 简介

MVC controller Framework based on book of M. Zandstra PHP 8 Objects, Patterns, and Practise Resources

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
