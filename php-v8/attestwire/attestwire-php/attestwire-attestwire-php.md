# attestwire/attestwire-php

> 标签: E-Invoice, EN16931, ZUGFeRD, cii, compliance, e-invoicing, einvoice, factur-x, facturx, invoice, invoicesuite, peppol, ubl, vat, xrechnung

## 简介

Create and validate EN 16931 e-invoices (XRechnung, Factur-X/ZUGFeRD PDFs, Peppol BIS 3) with the hosted Attestwire API. Includes an adapter for horstoeko/invoicesuite's validator so its users can validate without a Java KoSIT install.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
