# mrmanchot/miniorm

> 标签: orm, php

## 简介

Just a mini ORM, for using Object Model and MySQL Abstraction Layer as simply as possible

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
