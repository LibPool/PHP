# lireincore/imgcache-bundle

> 标签: bundle, cache, effect, image, preset, resize, symfony, thumb

## 简介

The lireincore/imgcache integration for the Symfony framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
