# dft/silverstripe-modeladminplus

> 标签: admin, dataobject, modeladmin, silverstripe

## 简介

Adds some extra features to a standard ModelAdmin field

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
