# zirkeldesign/acorn-fse

> 标签: block theme, fse, gutenberg, wordpress

## 简介

A Roots Acorn package, to provide FSE compatibility for Sage 10.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
