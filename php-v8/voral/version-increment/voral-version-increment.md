# voral/version-increment

> 标签: PHP Library, automated versioning, automation tool, changelog, changelog formatting, changelog generator, commit analysis, composer, conventional commits, dev tool, git, git integration, php tool, release management, semantic versioning, version control, version increment, version management

## 简介

A tool for semantic versioning and changelog generation in Composer projects based on Git commits.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
