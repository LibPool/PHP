# weatherflux/weatherflux

> 标签: influxdb, weather, weatherflow

## 简介

A gateway to listen WeatherFlow stations on a local network and write weather data in InfluxDB 2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
