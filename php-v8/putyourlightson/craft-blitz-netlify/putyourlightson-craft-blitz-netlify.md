# putyourlightson/craft-blitz-netlify

> 标签: blitz, cache, craftcms, deployer, netlify

## 简介

Netlify deployer for the Blitz plugin for Craft CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
