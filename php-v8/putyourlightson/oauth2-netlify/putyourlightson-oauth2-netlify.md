# putyourlightson/oauth2-netlify

> 标签: authorisation, authorization, client, netlify, oauth, oauth2

## 简介

Netlify deployer for the Blitz plugin for Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
