# codefit/ecommerce-xml

> 标签: PHP

## 简介

Generátor XML feedů pro Zboží CZ, Heureka CZ, Heureka SK, Google Merchant, Facebook

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
