# duxet/sentry-symfony

> 标签: errors, logging, sentry, symfony

## 简介

Symfony integration for Sentry (http://getsentry.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://getsentry.com
- 源码仓库：https://github.com/duxet/sentry-symfony.git
- Packagist 页面：https://packagist.org/packages/duxet%2Fsentry-symfony
