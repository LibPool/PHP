# morganchester/php-unicode-space-cleaner

> 标签: PHP

## 简介

A Unicode whitespace cleaner that replaces exotic Unicode spaces with a single ASCII space.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
