# diagonal/laravel-ts-enum-generator

> 标签: diagonal, ts-enum-generator

## 简介

Generate runtime-usable TypeScript objects and enums from PHP enums with utils

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
