# functionlabs/wp-single-value-taxonomy-ui

> 标签: taxonomy, term, wordpress

## 简介

This plugin adds the basic UI for single-valued taxonomies for heirarchical taxonomies. Updated version of abandonded plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
