# dsdcr/tronweb

> 标签: blockchain, cryptocurrency, dsdcr, laravel, laravel-package, laravel-tron, trc20, tron, tron-api, tron-lib, tron-php, tron-rest-api, tronweb, trx

## 简介

专业的PHP SDK，用于与TRON波场区块链网络交互，提供HTTP API封装、智能合约部署与调用、TRC20代币管理、交易构建与签名功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
