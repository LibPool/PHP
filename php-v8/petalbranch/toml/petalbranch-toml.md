# petalbranch/toml

> 标签: configuration, decoder, dumper, encoder, parser, php, toml

## 简介

An industrial-grade, zero-copy TOML parser and dumper for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
