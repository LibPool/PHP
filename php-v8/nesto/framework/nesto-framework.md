# nesto/framework

> 标签: api, attributes, dependency-injection, framework, frankenphp, modules, nesto, openapi, orm, php, prisma, psr-15, psr-7, rest, swagger, typeorm

## 简介

Nesto — a PHP framework: modules, dependency injection, guards, pipes, interceptors, filters, validation, an ORM and a Prisma-style client, OpenAPI, queues, scheduling and a CLI, all with attributes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
