# allanadan05/laravel-payments

> 标签: braintree, gateway, laravel, payments

## 简介

Reusable, gateway-agnostic payment integration module for Laravel. Ships with a Braintree driver; add more by implementing the PaymentGateway contract.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
