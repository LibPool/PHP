# php-upgrade-preflight/laravel

> 标签: composer, dependency-analysis, laravel, php, upgrade

## 简介

Laravel adapter and rules for PHP Upgrade Preflight.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
