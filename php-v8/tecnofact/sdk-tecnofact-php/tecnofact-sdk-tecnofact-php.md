# tecnofact/sdk-tecnofact-php

> 标签: Electronica, api, cfdi, cfdi-3.3, cfdi-4.0, facturacion, mexico, sat, sdk, timbrado, xml

## 简介

SDK oficial de PHP para la integración con el servicio de Timbrado CFDI 4.0 de TecnoFact

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
