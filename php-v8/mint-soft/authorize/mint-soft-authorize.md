# mint-soft/authorize

> 标签: access, acl, authorize, permission, rbac, role

## 简介

Zend Framework 2 module for Authorized access to system resources

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
