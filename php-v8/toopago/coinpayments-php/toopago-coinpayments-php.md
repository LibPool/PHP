# toopago/coinpayments-php

> 标签: api, bitcoin, btc, coinpayments, crypto, cryptocurrency, currency, ethereum, litecoin, merchant, payment gateway, payment method, payment processor, paypal, php

## 简介

A PHP wrapper for the CoinPayments.net v1 API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
