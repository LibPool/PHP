# spoonx/sxbootstrap

> 标签: Zend Framework, assetmanager, bootstrap, twitter, zf2

## 简介

A twitter bootstrap module for ZF2 (zend framework 2) based on rwoverdijk/assetmanager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
