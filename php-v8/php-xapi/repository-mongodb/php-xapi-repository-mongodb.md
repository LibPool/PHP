# php-xapi/repository-mongodb

> 标签: Experience API, Tin Can API, database, document, mongodb, repository, storage, xAPI

## 简介

MongoDB implementation of an xAPI (Experience API) repository

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
