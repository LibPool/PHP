# ooasis/module-magento-agent

> 标签: PHP

## 简介

UCP agentic commerce endpoints for Magento 2 / Adobe Commerce — self-hosted, RFC 9421 signatures, real checkout sessions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
