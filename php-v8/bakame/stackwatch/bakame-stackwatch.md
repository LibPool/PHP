# bakame/stackwatch

> 标签: CPU, embeddable, hrtime, memory_usage, microtime, multi-metric, profiler, stopwatch

## 简介

A minimalist, embeddable, multi-metric, and framework-agnostic profiler for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
