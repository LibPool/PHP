# bakame/cron

> 标签: Value Object, cron, enum, schedule, validator

## 简介

CRON for PHP: Validate CRON expression, Calculate run date, determine if a CRON expression is due

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
