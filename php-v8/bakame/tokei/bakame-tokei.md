# bakame/tokei

> 标签: LocalTime, algebra, arithmetic, circular ranges, clock, comparison, deterministic, difference, duration, immutable, intersection, interval, iso80000, iso8601, iteration, microseconds, normalization, precision, temporal, time, time-of-day, truncation, union

## 简介

Immutable value objects for expressive temporal modeling: time, duration, circular 24-hour intervals, and interval sets, without timezone handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
