# letraceursnork/russian-validators

> 标签: PHP

## 简介

Библиотека для валидации русских идентификаторов таких, как ИНН, СНИЛС, ОГРН/ОГРНИП и др.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
