# letraceursnork/bitrix-cache

> 标签: bitrix, cache, caching, psr-16

## 简介

Comfortable fluent interface for Bitrix cache. Anti-stampede cache protection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
