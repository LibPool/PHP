# lodestone/lodestone

> 标签: admin, dashboard, inertia, laravel, react, shadcn

## 简介

Server-driven UI for Laravel admin panels. Build pages, tables, forms and buttons with PHP builders; Lodestone draws them with React and shadcn and calls your callbacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
