# leinonen/yii2-hostname-language

> 标签: hostname, i18n, language, locale, yii2

## 简介

Simple component which helps to configure the app locale based on the hostname

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
