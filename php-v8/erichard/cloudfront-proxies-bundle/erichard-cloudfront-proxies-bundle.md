# erichard/cloudfront-proxies-bundle

> 标签: PHP

## 简介

Trusts the AWS Cloudfront proxies IP in your Symfony projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
