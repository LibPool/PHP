# smsfly/smsflyapi

> 标签: PHP

## 简介

PHP Class for SmsFly JSON Api: https://sms-fly.ua/public/api.v2.03.pdf

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
