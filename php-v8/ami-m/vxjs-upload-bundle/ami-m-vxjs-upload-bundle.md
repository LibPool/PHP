# ami-m/vxjs-upload-bundle

> 标签: Symfony Bundle, blueimp, bundle, file, jquery, symfony, upload, uploader

## 简介

File uploads bundle for Symfony based on Blueimp jQuery File Upload

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
