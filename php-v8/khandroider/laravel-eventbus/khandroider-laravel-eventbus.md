# khandroider/laravel-eventbus

> 标签: AMQP, event-bus, inbox, laravel, outbox, rabbitmq

## 简介

Transactional outbox and idempotent inbox over RabbitMQ for Laravel. Mark an event with PublishableEvent and it is published reliably.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
