# marshmallow/nova-styling

> 标签: Laravel Nova Dark Mode, Laravel Nova Theme, Marshmallow Theme, Responsive Laravel Nova Theme, dark mode, laravel, marshmallow, nova

## 简介

A Responsive Laravel Nova Marshmallow Theme based on 'A Responsive Laravel Nova theme'. With dark mode :)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
