# marshmallow/nova-map-box-field

> 标签: laravel, map box, nova

## 简介

A field for Laravel Nova 4 to create mapbox polygons and store them into your database. Awesome stuff really!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
