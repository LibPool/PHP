# marshmallow/nova-tooltip-field

> 标签: laravel, marshmallow, nova, tooltip

## 简介

This Laravel Nova field enables you to make use of the default Nova Tooltip component.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
