# marshmallow/cart

> 标签: cart, ecommerce, laravel, marshmallow, shopping-cart

## 简介

Framework-agnostic e-commerce cart, order and discount engine for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
