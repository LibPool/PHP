# marshmallow/nova-totals-footer

> 标签: laravel, marshmallow, nova, totals

## 简介

This Laravel Nova package is used for calculating the total of the columns that you wish to show.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
