# decifra-captcha/decifra-captcha-php

> 标签: PHP

## 简介

Solução para resolver, burlar e decifrar captchas e reCaptchas

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
