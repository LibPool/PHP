# letwang/hookphp

> 标签: AI编程, API网关, C扩展, HookPHP, OpenResty, 业务模型, 前后分离, 常驻内存, 微服务, 热插拔

## 简介

HookPHP基于C扩展搭建内置AI编程的架构系统-支持微服务部署|热插拔业务组件-集成业务模型|权限模型|UI组件库|多模板|多平台|多域名|多终端|多语言-含常驻内存|前后分离|API平台|LUA

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
