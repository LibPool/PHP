# sabsab43/vcard-fusion

> 标签: merge, occurrences, vCard, vcf

## 简介

This library can merges multiple vcard/vcf files with an occurrences search option.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
