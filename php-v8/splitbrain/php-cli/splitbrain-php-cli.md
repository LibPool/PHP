# splitbrain/php-cli

> 标签: argparse, cli, command line, console, getopt, optparse, terminal

## 简介

Easy command line scripts for PHP with opt parsing and color output. No dependencies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
