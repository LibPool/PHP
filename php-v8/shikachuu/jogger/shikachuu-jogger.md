# shikachuu/jogger

> 标签: jogger, log, logging, psr-3

## 简介

PSR-3 compatible logger library for PHP mostly based on a Go project rs/zerolog.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
