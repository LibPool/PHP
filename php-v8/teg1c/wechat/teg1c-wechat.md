# teg1c/wechat

> 标签: performance, php, wechat

## 简介

wechat PHP 微信 微信授权 微信用户信息 微信token 微信模板 微信自定义菜单生产 微信JDK 微信关键字回复 微信模板消息发送

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
