# warlog7997/pdfsplit

> 标签: extract, merge, parser, pdf, php, split

## 简介

Pure PHP library for PDF splitting, page extraction, and merging. No external dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
