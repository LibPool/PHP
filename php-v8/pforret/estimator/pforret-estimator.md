# pforret/estimator

> 标签: estimation, extrapolation, pforret, statistics

## 简介

PHP package to help with statistic estimation (extrapolation) based on historic reference data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
