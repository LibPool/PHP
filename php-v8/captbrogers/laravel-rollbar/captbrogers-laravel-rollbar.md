# captbrogers/laravel-rollbar

> 标签: error, laravel, logging, monitoring, rollbar

## 简介

Rollbar error monitoring integration for Laravel 5.4 projects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
