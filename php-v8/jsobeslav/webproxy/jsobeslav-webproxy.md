# jsobeslav/webproxy

> 标签: PHP

## 简介

WebProxy is PHP library that offers consistent interface for communicating with standard third-party web services, be it API or an ordinary website

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
