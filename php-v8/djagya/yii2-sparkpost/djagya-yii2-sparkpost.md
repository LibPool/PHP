# djagya/yii2-sparkpost

> 标签: email, extension, mailer, sparkpost, yii, yii2

## 简介

A library provides Yii2 integration with SparkPost mail service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
