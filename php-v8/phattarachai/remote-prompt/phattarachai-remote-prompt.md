# phattarachai/remote-prompt

> 标签: cli, deployment, laravel-prompts, rsync, sftp, ssh, terminal, tui

## 简介

A PHPStorm-style remote host panel for the terminal — pick a project's server, open a shell in its deploy path, browse, download and upload files over your own ssh config. One global command for every project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
