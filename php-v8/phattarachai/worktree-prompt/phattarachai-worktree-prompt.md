# phattarachai/worktree-prompt

> 标签: cli, git, laravel, laravel-prompts, mysql, postgres, terminal, worktree

## 简介

Set up a git worktree of a Laravel project in one command — real vendor, .env, storage, an optional database of its own and build assets — and tear it down again, through Laravel Prompts. One global command for every project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
