# phattarachai/files-backup-laravel

> 标签: Flysystem, backup, devops, files, google-drive, laravel, rclone, retention, s3

## 简介

Incremental off-site backup of a Laravel app's content files (uploads, media library) through rclone or any Flysystem disk — versioned overwrites and deletes, staleness events and restore drills. The files sibling of phattarachai/db-snapshot-sync-laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
