# phattarachai/ops-core

> 标签: Metrics, alerting, histogram, monitoring, observability, ops

## 简介

Framework-free core of the Ops monitoring suite: rollup math, latency histograms, alert rule evaluation and incident lifecycle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
