# phalanx-php/cli

> 标签: cli, doctor, installer, phalanx, swoole

## 简介

Phalanx CLI: doctor, Swoole installer using PIE, and project scaffolding

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
