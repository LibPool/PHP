# phalanx-php/phpstan

> 标签: PHPStan, async, phalanx, static-analysis, swoole

## 简介

PHPStan safety rules for Phalanx concurrent and parallel PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
