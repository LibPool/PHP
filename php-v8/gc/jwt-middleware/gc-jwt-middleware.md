# gc/jwt-middleware

> 标签: PHP

## 简介

This middleware supports server-to-server interactions and *not* when you authorize on behalf of end user so that consent is not required

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
