# zuqongtech/laravel-db-introspection

> 标签: PHP

## 简介

A Laravel package for automatic database introspection and model generation supporting MySQL, PostgreSQL, SQL Server, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
