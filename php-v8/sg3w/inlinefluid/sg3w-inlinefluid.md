# sg3w/inlinefluid

> 标签: PHP

## 简介

Write Fluid templates directly in a TYPO3 content element and render them in the frontend — with custom variables, JSON/YAML/XML/CSV data providers and FAL media, cached or uncached

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
