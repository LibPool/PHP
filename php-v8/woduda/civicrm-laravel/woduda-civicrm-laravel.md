# woduda/civicrm-laravel

> 标签: PHP

## 简介

Thin Laravel adapter around woduda/civicrm-php (PSR-18 CiviCRM APIv4 client)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
