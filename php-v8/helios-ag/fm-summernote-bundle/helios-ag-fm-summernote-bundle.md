# helios-ag/fm-summernote-bundle

> 标签: editor, summernote, symfony, wysiwyg

## 简介

Summernote bundle, adds Summernote WYSIWYG editor to your Symfony project

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
