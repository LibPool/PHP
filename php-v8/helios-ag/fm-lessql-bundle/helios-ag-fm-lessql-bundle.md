# helios-ag/fm-lessql-bundle

> 标签: lessql, orm, sql

## 简介

Lessql bundle, adds LessQL ORM PHP to your Symfony2 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
