# boerl/zf1-log-psr3

> 标签: PSR3, ZF1, facade, log, psr-3, wrapper, zend

## 简介

A wrapper around a Zend Framework 1 Logger to make it PSR-3 compatible.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
