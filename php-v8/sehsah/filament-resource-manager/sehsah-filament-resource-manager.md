# sehsah/filament-resource-manager

> 标签: admin, filament, filament-plugin, laravel, navigation, resources

## 简介

Manage Filament resource navigation - label, icon, group, sort and visibility - from an admin UI. Supports Filament v3, v4 and v5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
