# sehsah/filament-remember-table

> 标签: filament, filament-plugin, filters, laravel, saved-views, table

## 简介

Save, name and switch between table views (filters, search, sort, columns, grouping) in Filament.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
