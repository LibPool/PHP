# hafael/laraflake

> 标签: 64bit, id, laravel, shard, snowflake

## 简介

Laravel Package based on Twitter Snowflake ID Generator (64 bit ID).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
