# wirecn/laravel-wirecn

> 标签: blade, laravel, tailwind, ui, wirecn

## 简介

Laravel Blade UI (wirecn): components with Tailwind class merging via cn()

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
