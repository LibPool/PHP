# sidus/elastica-filter-bundle

> 标签: datagrid, elastic, elastica, filter, search, sort

## 简介

Extension for sidus/filter-bundle to handle Elastic Search index search

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
