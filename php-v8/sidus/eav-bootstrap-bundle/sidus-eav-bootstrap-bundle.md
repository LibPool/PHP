# sidus/eav-bootstrap-bundle

> 标签: bootstrap, eav

## 简介

Bootstrap implementation and helpers for Sidus/EAVModelBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
