# sidus/eav-model-bundle

> 标签: doctrine, eav, model

## 简介

Symfony3 & Doctrine implementation of a Entity-Attribute-Value model, easily extendable

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
