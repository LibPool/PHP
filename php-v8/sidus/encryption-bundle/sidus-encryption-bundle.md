# sidus/encryption-bundle

> 标签: encryption, mcrypt

## 简介

The EncryptionBundle allows you to store encrypted files and data in Doctrine's entity in a very simple way

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
