# cosmira/yii1-strangler-proxy

> 标签: Yii1, api-migration, incremental-migration, legacy, proxy, strangler, strangler-fig, yii, yii-1.1

## 简介

A Yii 1.1 filter for incremental JSON API migration with contract adaptation and legacy access checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
