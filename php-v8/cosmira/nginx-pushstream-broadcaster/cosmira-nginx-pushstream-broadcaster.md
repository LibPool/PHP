# cosmira/nginx-pushstream-broadcaster

> 标签: Broadcasting, laravel, nginx, push-stream, websocket

## 简介

Laravel broadcast driver and HTTP publisher for nginx Push Stream.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
