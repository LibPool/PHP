# kozo/cryptenv

> 标签: Poly1305, Xchacha20, cakephp, encryption, env, environment, plugin, sodium

## 简介

CakePHP plugin for encrypting and decrypting environment files using XChaCha20-Poly1305

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
