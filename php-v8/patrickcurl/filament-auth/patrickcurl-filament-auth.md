# patrickcurl/filament-auth

> 标签: cli, filament, laravel, resource, ui, user

## 简介

User & Role (via Spatie Roles/Permissions) Manager Resource For Filament Admin, forked from forked from phpsa/filament-authentication - added Bouncer as an option for permissions as well.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
