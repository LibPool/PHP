# inja-online/ftp-deployer

> 标签: FTPDeployer, cpanel, deployer, ftp, laravel

## 简介

Deploy Laravel applications to cPanel-style FTP-only hosts with a temporary HTTP runner.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
