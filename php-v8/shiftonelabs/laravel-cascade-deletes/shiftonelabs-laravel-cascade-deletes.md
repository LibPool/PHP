# shiftonelabs/laravel-cascade-deletes

> 标签: cascade, deletes, eloquent, laravel, lumen, model

## 简介

Adds application level cascading deletes to Eloquent Models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
