# glhd/linearavel

> 标签: api, graphql, laravel, linear, sdk

## 简介

A fully-typed Linear API SDK for PHP and Laravel, generated from Linear's GraphQL schema.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
