# snipershady/amilon

> 标签: amilon, api client, gift card, rest, voucher, welfare

## 简介

PHP client library for the Amilon API: order, manage and distribute digital gift cards at scale

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
