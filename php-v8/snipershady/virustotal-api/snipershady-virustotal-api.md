# snipershady/virustotal-api

> 标签: api, v3, virustotal, virustotal.com

## 简介

A simple wrapper for virustotal.com service, without any external dependencies, pure PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
