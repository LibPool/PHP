# snipershady/queue-bridge

> 标签: AMQP, dlq, messaging, queue, rabbitmq, redis, redis-streams

## 简介

Backend-agnostic PHP 8.3+ message queue: one typed API for Redis Streams and RabbitMQ, with retries, DLQ, delayed messages and automatic Redis version detection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
