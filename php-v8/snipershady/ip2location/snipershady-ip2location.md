# snipershady/ip2location

> 标签: geolocation, ip2location, ip2location.com

## 简介

Free wrapper to easily implements ip2location.com free API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.spinfo.it
- 源码仓库：https://github.com/snipershady/ip2location.git
- Packagist 页面：https://packagist.org/packages/snipershady%2Fip2location

## 获取地址

- Composer 安装：`composer require snipershady/ip2location`
