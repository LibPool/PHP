# snipershady/emailvalidator

> 标签: PHP

## 简介

Simple, clean and reliable email validator for PHP >= 8.3: syntax, RFC 5322 format and MX/Null-MX record checks, with sanitized-address retrieval.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
