# rimote/updater

> 标签: PHP

## 简介

Update utility that can be called by a deployment script, able to perform installation specific configuration, database updates and/or rollbacks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
