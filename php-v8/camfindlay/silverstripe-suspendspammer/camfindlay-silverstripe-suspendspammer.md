# camfindlay/silverstripe-suspendspammer

> 标签: forum, silverstripe, spam

## 简介

Suspends a suspected forum spammer registration based on user supplied keywords

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
