# jeronimofagundes/email-validator

> 标签: email, emailvalidation, emailvalidator, validation, validator

## 简介

A library for validating emails against several RFCs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
