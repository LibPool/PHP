# prayerzone/prayer-times

> 标签: adhan, api, islam, mosque, prayer-times, qibla, salah, salat

## 简介

Official PHP SDK for the pray.zone prayer-times API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://pray.zone/api
- 源码仓库：https://github.com/PrayerZone/prayer-times-sdk-php.git
- Packagist 页面：https://packagist.org/packages/prayerzone%2Fprayer-times

- Composer 安装：`composer require prayerzone/prayer-times`
