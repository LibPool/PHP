# beholdr/sendsay-laravel

> 标签: laravel, mailer, sendsay

## 简介

Unofficial Sendsay.ru mailer transport for Laravel to sending transactional emails.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
