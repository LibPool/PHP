# ahsankhatri/cryptolib-php

> 标签: Rijndael, aes-encryption, cryptolib

## 简介

A library to encrypt or decrypt with random password generator based on secret key defined.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
