# groupone/wap-client

> 标签: ai, chat, group-one, wap, wordpress

## 简介

WordPress AI Platform (WAP) client library — drop-in Composer package for integrating AI chat into any WordPress plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
