# corevisys/laravel-license-client

> 标签: corevisys, laravel, license, licensing, saas

## 简介

Official Laravel client SDK for the CoreVisys licensing platform — activate, verify, and monitor software licenses with signed, offline-capable verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
