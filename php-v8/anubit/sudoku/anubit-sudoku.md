# anubit/sudoku

> 标签: PHP

## 简介

Sudoku - Sudoku puzzle plugin (Extbase/Fluid rewrite of the legacy EXT:sudoku by Andreas Kastl)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
