# anubit/pageflipper

> 标签: PHP

## 简介

PageFlipper - Content element that displays FAL PDFs as a responsive collection of lazy-loaded flipbooks (PDF.js + StPageFlip).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
