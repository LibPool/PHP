# newo-io/laravel-sdk

> 标签: deprecated, laravel, newo, onesto, sdk

## 简介

DEPRECATO — usa onesto-it/laravel-sdk. Questo pacchetto è un metapackage di compatibilità: installa onesto-it/laravel-sdk e mantiene attivi i vecchi nomi `Newo::` / `Newo\Sdk\` / `NEWO_TOKEN`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
