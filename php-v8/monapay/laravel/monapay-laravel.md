# monapay/laravel

> 标签: bank-transfer, laravel, monapay, vietqr, webhook

## 简介

Tích hợp MONA Pay cho Laravel 10, 11 và 12: VietQR động, webhook có chữ ký và event thanh toán.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
