# aaronjan/academe

> 标签: database, datamapper, laravel, orm

## 简介

Academe is an awesome data-mapper for MySQL & MongoDB (maybe more), support Laravel & natvie PHP project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
