# aaronjan/kobe

> 标签: laravel, swagger

## 简介

Kobe is a Swagger definition writing tool for PHP, it can be used with framework like Laravel or just native PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
