# ebsco/edsapi-drupal8-plugin

> 标签: EDS, drupal, drupal8, ebsco

## 简介

A Drupal 9 module for the EBSCO Discovery Service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
