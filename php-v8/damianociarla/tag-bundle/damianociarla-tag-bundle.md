# damianociarla/tag-bundle

> 标签: Symfony2, tag

## 简介

DCSTagBundle adds tagging to your Symfony project, with the ability to associate tags with any number of different entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
