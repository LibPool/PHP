# finesse/web-fonts-repository

> 标签: css, font, google fonts, hosting, repository, webfonts

## 简介

A simple webfont hosting. Google Fonts alternative for your own fonts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
