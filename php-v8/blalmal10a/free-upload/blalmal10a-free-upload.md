# blalmal10a/free-upload

> 标签: filament, filament-plugin, filamentphp, laravel

## 简介

Filament v4/v5 file upload plugin with custom XHR uploads, PXVT encoding, and proxy decoding

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
