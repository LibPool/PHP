# magebitcom/magento2-mcp-inventory-tools

> 标签: PHP

## 简介

Inventory-domain MCP tools for Magebit_Mcp (multi-source inventory: sources, stocks, source items, salable quantity)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
