# magebitcom/magento2-mcp-tax-tools

> 标签: PHP

## 简介

Tax and currency MCP tools for Magebit_Mcp (read + write over tax rates, rules, classes, and currency rates)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
