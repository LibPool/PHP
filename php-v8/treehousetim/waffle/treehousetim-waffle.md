# treehousetim/waffle

> 标签: Skeleton, docker, doppler, pest, slim, starter, vue

## 简介

Web Application Foundation For Lay Engineers: a test-first starting point for PHP 8.5 + Slim 4 + Vue 3 web apps, with Docker Compose, Doppler secrets and a one-server GitHub Actions deploy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
