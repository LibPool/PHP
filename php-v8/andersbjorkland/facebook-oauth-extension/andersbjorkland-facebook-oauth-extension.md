# andersbjorkland/facebook-oauth-extension

> 标签: PHP

## 简介

👍 The Facebook Oauth Extension allows you to login to your admin interface with Facebook.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
