# vortechron/filament-block-editor

> 标签: block-editor, blocknote, filament, filament-plugin, laravel, page-builder

## 简介

A Notion-style block editor and page builder for Filament 5: BlockNote content, styled sections, block styles, saved blocks and a media library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
