# divineomega/thisishowirole

> 标签: library, permissions, php, roles

## 简介

'This Is How I Role' is a PHP role management system that can be applied to any class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
