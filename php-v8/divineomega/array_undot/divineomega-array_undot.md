# divineomega/array_undot

> 标签: PHP

## 简介

array_undot (the opposite of the array_dot helper function) expands a dot notation array into a full multi-dimensional array.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
