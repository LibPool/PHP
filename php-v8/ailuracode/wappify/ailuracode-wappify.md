# ailuracode/wappify

> 标签: laravel, whatsapp

## 简介

Wappify is a package that allows you to receive messages to WhatsApp using the WhatsApp Cloud API for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
