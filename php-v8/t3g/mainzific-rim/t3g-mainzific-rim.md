# t3g/mainzific-rim

> 标签: SkillDisplay, TCCE, TYPO3 CMS

## 简介

Mainz in Danger - the site package for SkillDisplays gamification adventure for ongoing TYPO3 CMS certified editors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
