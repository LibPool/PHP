# t3g/blog

> 标签: PHP

## 简介

This blog extension uses TYPO3s core concepts and elements to provide a full-blown blog that users of TYPO3 can instantly understand and use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
