# cebe/color-nick

> 标签: chat, color, colorize, nick, string

## 简介

A simple PHP lib that can color nick names to make them distinguishable in a chat room.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
