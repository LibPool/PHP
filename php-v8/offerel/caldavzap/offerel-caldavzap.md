# offerel/caldavzap

> 标签: CalDAV, CalDAVZap, Tasks, calendar, todo

## 简介

A plugin for Roundcube to include CalDAVZap in to the main GUI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
