# bitbag/sylius-feed-plugin

> 标签: PHP

## 简介

Plugin to generate feeds within the Sylius ecommerce platform, developed by Setono - forked by BitBag

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
