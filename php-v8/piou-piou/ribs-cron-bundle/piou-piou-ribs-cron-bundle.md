# piou-piou/ribs-cron-bundle

> 标签: cron, curl cron, ribs bundle

## 简介

RibsCronBundle is a bunlde to use cron via curl a url of you website with cron based time

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
