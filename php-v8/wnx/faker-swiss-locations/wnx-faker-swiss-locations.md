# wnx/faker-swiss-locations

> 标签: cities, fake-data, faker, swiss, switzerland, wnx

## 简介

Provider to generate valid Swiss location data for Faker PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
