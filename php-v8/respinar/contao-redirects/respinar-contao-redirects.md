# respinar/contao-redirects

> 标签: 301, 302, 410, bundle, contao, redirect

## 简介

A simple Contao extension for URL redirects (301, 302) and 410 (Gone) responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
