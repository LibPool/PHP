# lde/laravel-pubsub-queue

> 标签: gcp, google, laravel, lde, pubsub, queue

## 简介

Queue driver for Google Cloud Pub/Sub.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
