# stop14/ckeditor5_extended_special_characters

> 标签: PHP

## 简介

A Drupal module that provides a configurable interface and toolbar button to supply a customized list of special characters to the CKEditor 5 WYSIWYG.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
