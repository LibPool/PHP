# stop14/agile_slide_viewer

> 标签: PHP

## 简介

A Drupal module that provides a slide viewer as a View and custom web component. Uses Slick Carousel as its core component.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
