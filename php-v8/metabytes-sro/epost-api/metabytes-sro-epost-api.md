# metabytes-sro/epost-api

> 标签: API-Client, Deutsche Post, e-post, e-postbusiness, einschreiben, epost, hybrid mail, letter

## 简介

PHP client for the Deutsche Post E-POSTBUSINESS API: send PDFs as physical letters, track delivery, estimate prices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
