# dinja/poste-delivery-business-sdk

> 标签: Poste Delivery Business, ecommerce, logistics, pdb

## 简介

Unofficial PHP SDK for Poste Delivery Business Rest API services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
