# flarum-lang/marathi

> 标签: flarum, flarum-locale, locale, marathi, marathi-locale, mr-locale

## 简介

Marathi language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
