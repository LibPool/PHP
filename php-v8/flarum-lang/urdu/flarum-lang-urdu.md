# flarum-lang/urdu

> 标签: flarum, flarum-locale, locale, ur-locale, urdu, urdu-locale

## 简介

Urdu language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
