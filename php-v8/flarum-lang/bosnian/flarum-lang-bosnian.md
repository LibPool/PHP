# flarum-lang/bosnian

> 标签: bosnian, bosnian-locale, bs-locale, flarum, flarum-locale, locale

## 简介

Bosnian language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
