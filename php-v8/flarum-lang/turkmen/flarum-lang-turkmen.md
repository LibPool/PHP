# flarum-lang/turkmen

> 标签: flarum, flarum-locale, locale, tk-locale, turkmen, turkmen-locale

## 简介

Turkmen language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
