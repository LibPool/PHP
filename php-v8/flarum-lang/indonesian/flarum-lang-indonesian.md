# flarum-lang/indonesian

> 标签: flarum, flarum-locale, id-locale, indonesian, indonesian-locale, locale

## 简介

Indonesian language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
