# flarum-lang/norwegian-bokmal

> 标签: flarum, flarum-locale, locale, nb-locale, norwegian-bokmal, norwegian-bokmal-locale

## 简介

Norwegian Bokmål language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
