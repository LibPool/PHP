# flarum-lang/tajik

> 标签: flarum, flarum-locale, locale, tajik, tajik-locale, tg-locale

## 简介

Tajik language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
