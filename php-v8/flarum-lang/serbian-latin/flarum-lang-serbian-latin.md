# flarum-lang/serbian-latin

> 标签: flarum, locale, sr-locale, sr_Latn-locale

## 简介

Serbian (Latin) language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
