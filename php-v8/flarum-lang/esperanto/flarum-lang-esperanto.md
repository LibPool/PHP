# flarum-lang/esperanto

> 标签: Esperanto, eo-locale, esperanto-locale, flarum, flarum-locale, locale

## 简介

Esperanto language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
