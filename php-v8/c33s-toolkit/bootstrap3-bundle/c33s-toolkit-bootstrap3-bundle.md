# c33s-toolkit/bootstrap3-bundle

> 标签: PHP

## 简介

Twitter Bootstrap 3 layout for Symfony 3 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
