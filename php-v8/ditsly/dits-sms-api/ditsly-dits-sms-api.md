# ditsly/dits-sms-api

> 标签: PHP

## 简介

DITS SMS API is build for DITS SMS - Bulk SMS Application For Marketing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
