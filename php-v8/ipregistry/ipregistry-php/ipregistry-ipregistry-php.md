# ipregistry/ipregistry-php

> 标签: IP, geoip, geolocation, ip-address, ip-data, ip-geolocation, ipregistry, proxy-detection, threat-data, user-agent, vpn-detection

## 简介

Official PHP client library for the Ipregistry IP geolocation and threat data API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
