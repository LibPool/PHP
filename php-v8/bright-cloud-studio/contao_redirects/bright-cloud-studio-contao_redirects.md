# bright-cloud-studio/contao_redirects

> 标签: 301, 302, bright, cloud, contao, htaccess, redirect, rewrite, studio, url

## 简介

Allows internal and external redirects to be set within Contao.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
