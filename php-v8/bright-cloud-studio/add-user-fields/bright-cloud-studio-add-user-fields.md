# bright-cloud-studio/add-user-fields

> 标签: add, contao, fields, user

## 简介

Adds two custom user fields, image and bio, so they can be displayed on News posts and elsewhere

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
