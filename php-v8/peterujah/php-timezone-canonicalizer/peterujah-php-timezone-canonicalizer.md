# peterujah/php-timezone-canonicalizer

> 标签: DateTimeZone, alias, canonical, iana, php, time zone, timezone, tz database, tzdata

## 简介

Lightweight PHP library that resolves backward-compatible IANA timezone aliases (e.g. Asia/Calcutta) to their canonical identifiers (e.g. Asia/Kolkata).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
