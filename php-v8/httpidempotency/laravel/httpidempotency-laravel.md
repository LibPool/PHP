# httpidempotency/laravel

> 标签: idempotency, idempotency-key, laravel, middleware, rfc9457

## 简介

Laravel middleware implementing the IETF Idempotency-Key HTTP header draft.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
