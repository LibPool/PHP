# saaspass/module

> 标签: PHP

## 简介

Module that makes it possible to login to Magento with SAASPASS credentials

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://saaspass.com
- 源码仓库：https://github.com/saaspass/magento2-extension.git
- Packagist 页面：https://packagist.org/packages/saaspass%2Fmodule

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require saaspass/module`
- Packagist 仓库：https://repo.packagist.org/p2/saaspass/module.json
