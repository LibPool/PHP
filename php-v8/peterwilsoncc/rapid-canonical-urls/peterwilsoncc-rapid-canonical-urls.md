# peterwilsoncc/rapid-canonical-urls

> 标签: PHP

## 简介

Reduce 301 redirects and HTTP requests to show visitors WordPress's correct, canonical URL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
