# arte/hateoas-bundle

> 标签: HATEOAS, rest

## 简介

Generates fixed Hateoas adder classes, based on BazingaHateoasBundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
