# frontuser/magento2-integration

> 标签: PHP

## 简介

A Magento 2 modules for Frontuser. Frontuser is a easiest platform to maximize user engagement, retention & conversion.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
