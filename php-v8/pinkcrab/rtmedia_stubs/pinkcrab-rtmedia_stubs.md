# pinkcrab/rtmedia_stubs

> 标签: PHPStan, rtMedia, static analysis, wordpress

## 简介

rtMedia for WordPress, BuddyPress and bbPress stubs for static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
