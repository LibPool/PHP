# pinkcrab/http

> 标签: PHP

## 简介

Wrapper around Nyholm\Psr7 library with a few helper methods and a basic emitter. For use in WordPress during ajax calls.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
