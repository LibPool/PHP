# pinkcrab/bladeone-provider

> 标签: PHP

## 简介

An implementation of the PinkCrab Renderable Interface used in the PinkCrab Plugin Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
