# epay-et/php-sdk

> 标签: Ethiopia, Telebirr, cbe, epay, laravel, payment-gateway, payments

## 简介

Official ePay Business API client for PHP, with a Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
