# mountsoftware/symfony-toon-serializer

> 标签: PHP

## 简介

Symfony Serializer integration for TOON (Token-Oriented Object Notation) on top of helgesverre/toon

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
