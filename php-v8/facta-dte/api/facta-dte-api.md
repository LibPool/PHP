# facta-dte/api

> 标签: api, dte, el-salvador, facta, factura-electronica, sdk

## 简介

PHP client for the Facta DTE API (El Salvador electronic invoicing). No required dependencies.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/Facta-DTE/facta-api-sdk-php.git
