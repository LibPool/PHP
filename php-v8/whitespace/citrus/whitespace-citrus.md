# whitespace/citrus

> 标签: Craft, citrus, cms, craft-plugin, craftcms

## 简介

Automatically purge and ban cached elements in Varnish

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
