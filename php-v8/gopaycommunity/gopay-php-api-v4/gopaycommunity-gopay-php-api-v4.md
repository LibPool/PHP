# gopaycommunity/gopay-php-api-v4

> 标签: gopay, payment, php, sdk

## 简介

GoPay PHP SDK for server-side use — wraps the GoPay Payments API v4.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
