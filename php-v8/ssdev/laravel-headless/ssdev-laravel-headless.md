# ssdev/laravel-headless

> 标签: Teams, inertia, laravel, multi-tenancy, starter-kit, two-factor, vue

## 简介

Installable Laravel foundation with authentication, teams, roles, 2FA and multi-tenancy, shipped with a Vue + Inertia UI and a JSON API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
