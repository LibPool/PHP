# kaho88/seat-manualpap

> 标签: calendar, eve-online, pap, plugin, seat

## 简介

Manual PAP insertion plugin for SeAT (works with seat-calendar).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
