# genderapi/phone-validator

> 标签: PHP

## 简介

PHP SDK for validating and formatting phone numbers using the GenderAPI Phone Number Validation & Formatter API (https://genderapi.io)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
