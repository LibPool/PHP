# ksfraser/ksf-oauth2-server

> 标签: PHP

## 简介

Production-grade OAuth2 and OpenID Connect server implementation with PKCE, JWT, and multi-tier caching support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
