# ksfraser/ksf-modules-dao

> 标签: PHP

## 简介

Cross-platform DAO abstraction (DB, WordPress, SuiteCRM, FrontAccounting, CSV, XML)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
