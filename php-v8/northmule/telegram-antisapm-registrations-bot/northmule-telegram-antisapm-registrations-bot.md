# northmule/telegram-antisapm-registrations-bot

> 标签: PHP

## 简介

Skeleton of the Laminas application with a module for combating spam registration in the Telegram group

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
