# dniccum/linear-sdk

> 标签: eloquent, issues, laravel, linear, sdk

## 简介

A Laravel SDK for creating Linear issues from Eloquent models, with an optional branded configuration page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
