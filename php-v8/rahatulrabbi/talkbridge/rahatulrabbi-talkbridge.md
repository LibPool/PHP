# rahatulrabbi/talkbridge

> 标签: Broadcast, chat, group-chat, laravel, messaging, pusher, reactions, real-time, reverb, talkbridge, websocket

## 简介

A professional real-time chat package for Laravel with private and group conversations, message reactions, file attachments, message status tracking, and WebSocket support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
