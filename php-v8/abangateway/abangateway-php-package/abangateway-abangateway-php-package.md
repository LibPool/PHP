# abangateway/abangateway-php-package

> 标签: abangateway, card-to-card, gateway, iran, laravel, payment, webhook

## 简介

AbanGateway card-to-card payment gateway for PHP and Laravel: invoices with automatic confirmation, signed webhooks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
