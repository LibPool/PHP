# krusemedien/cron-export

> 标签: PHP

## 简介

Plugin zur Erweiterung des Import-Export-Addons. Exporte durch URL Aufruf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
