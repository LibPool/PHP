# lanos/laravel-bfl

> 标签: ai, black-forest-labs, flux, image-generation, laravel, php, sdk

## 简介

Laravel wrapper for Black Forest Labs FLUX API - AI-powered image generation and fine-tuning services

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
