# lanos/laravel-cashier-stripe-connect

> 标签: billing, laravel, stripe, stripe-connect

## 简介

Adds Stripe Connect functionality to Laravel's main billing package, Cashier.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
