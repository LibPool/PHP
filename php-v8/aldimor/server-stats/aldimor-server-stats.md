# aldimor/server-stats

> 标签: magento 2, magento 2 stats

## 简介

Server Stats extension for Magento 2 helps the store owner visualize the performance of the Magento server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
