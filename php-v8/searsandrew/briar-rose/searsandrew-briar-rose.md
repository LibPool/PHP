# searsandrew/briar-rose

> 标签: PHP

## 简介

NetSuite RESTlet + SuiteTalk REST client for Laravel (OAuth 1.0a TBA, HMAC-SHA256).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
