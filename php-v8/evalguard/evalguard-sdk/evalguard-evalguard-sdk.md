# evalguard/evalguard-sdk

> 标签: ai-security, evalguard, evals, llm, red-team

## 简介

EvalGuard PHP SDK — reservation. Public API forthcoming. The supported surface today lives in evalguardai-sdk (npm) and evalguardai (PyPI). https://evalguard.ai

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
