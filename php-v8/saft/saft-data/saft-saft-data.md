# saft/saft-data

> 标签: Linked Data, RDF, Saft, Semantic Web, parser, serializer

## 简介

Data interface for parsind and serializing RDF data for the Saft library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
