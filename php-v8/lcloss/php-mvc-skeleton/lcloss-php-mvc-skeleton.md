# lcloss/php-mvc-skeleton

> 标签: Skeleton, blade, framework, micro-framework, mvc, php

## 简介

Framework PHP simples, sem dependências pesadas, para páginas e pequenos sites. Skeleton para `composer create-project`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
