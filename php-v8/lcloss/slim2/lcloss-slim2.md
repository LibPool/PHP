# lcloss/slim2

> 标签: api, framework, micro, router

## 简介

Slim is a PHP micro framework that helps you quickly write simple yet powerful web applications and APIs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
