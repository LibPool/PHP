# xupaoye/cangqiong-captcha

> 标签: cangqiong, captcha, gd, pow, slider

## 简介

Cangqiong CAPTCHA: open-source image challenges and proof-of-work primitives implemented in PHP/GD.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
