# makarms/text-probe

> 标签: PHP

## 简介

Simple and extensible PHP library for text analysis and pattern matching, designed to help developers probe, parse, and manipulate text efficiently.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
