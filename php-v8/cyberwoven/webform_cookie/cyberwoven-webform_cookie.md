# cyberwoven/webform_cookie

> 标签: PHP

## 简介

Webform submission handler that sets a cookie on a webform submission. This is a modified version of the original module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
