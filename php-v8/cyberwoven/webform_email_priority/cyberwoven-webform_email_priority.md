# cyberwoven/webform_email_priority

> 标签: drupal, priority, webform

## 简介

This module extends the the Webform module's Email Webform Handler plugin by adding a priority flag dropdown.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
