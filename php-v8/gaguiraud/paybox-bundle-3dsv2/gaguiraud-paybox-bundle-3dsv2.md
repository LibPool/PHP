# gaguiraud/paybox-bundle-3dsv2

> 标签: Symfony2, bundle, paybox, payment

## 简介

PayboxBundle3DSV2 eases the implementation of the Paybox payment system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
