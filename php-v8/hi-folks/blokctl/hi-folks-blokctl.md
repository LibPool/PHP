# hi-folks/blokctl

> 标签: PHP

## 简介

An unofficial Storyblok automation toolkit providing a command-line interface, reusable PHP API, and Configuration as Code provisioning.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
