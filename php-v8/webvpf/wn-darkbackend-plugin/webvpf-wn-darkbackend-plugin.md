# webvpf/wn-darkbackend-plugin

> 标签: winter cms, wintercms, wintercms-plugin

## 简介

Dark Theme for Backend Winter CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
