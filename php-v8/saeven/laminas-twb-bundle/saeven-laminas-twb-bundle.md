# saeven/laminas-twb-bundle

> 标签: module, twitter bootstrap, zend framework 2

## 简介

Laminas module for easy integration of Twitter Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
