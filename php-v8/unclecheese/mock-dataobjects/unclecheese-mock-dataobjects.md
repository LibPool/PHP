# unclecheese/mock-dataobjects

> 标签: content, dataobject, fake, seeding, silverstripe

## 简介

Allows DataObjects to self-populate intelligently using fake data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
