# openlss/lib-pdns

> 标签: dns, mysql dns, pdns, powerdns

## 简介

PHP library for modifying an PowerDNS MySQL database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
