# openlss/lib-crypt

> 标签: aes, decryption, encryption, mcrypt

## 简介

Shorthand library for using AES encryption provided by PHP-Mcrypt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
