# rohnstock/bootstrap-daterangepicker

> 标签: DateTimePicker

## 简介

Date range picker component for Bootstrap http://www.daterangepicker.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://www.daterangepicker.com
