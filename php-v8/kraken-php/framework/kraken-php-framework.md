# kraken-php/framework

> 标签: Agent, Thread, agent-model, async, asynchronous, concurrent, daemon, demon, distributed, distribution, error-tolerance, error-tolerant, event-driven, fault-tolerance, fault-tolerant, framework, kraken, kraken-php, message-driven, multi-processed, multi-threaded, parallel, process, service, soa

## 简介

The first and only multi-processed, multi-threaded, fault-tolerant framework for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
