# artsoft/yii2-print-this

> 标签: PrintThis, extension, html, print, yii, yii2

## 简介

Print html by selector for Yii Framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
