# nguyenary/covid-api

> 标签: PHP

## 简介

This is a small project of mine to provide API for statistics of covid cases in Vietnam as well as in the world using PHP language.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
