# nguyenary/vietnam-address-api

> 标签: PHP

## 简介

Một thư viện được viết bằng PHP để lấy thông tin các đơn vị hành chính Việt Nam (Tỉnh, Thành Phố, Quận, Huyện, Xã, Phường, Thị Trấn...)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
