# sleqq/tibia-reader

> 标签: Outfits, dat, spr, sprites, tibia

## 简介

Reader for Tibia client .dat and .spr files (all versions with Tibia.dat and Tibia.spr, 7.10-11.00): sprite extraction, object parsing and outfit rendering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
