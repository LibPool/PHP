# cordis-php/cordis

> 标签: composition, cordis, plugins, runtime, yaml

## 简介

A strictly typed, YAML-composed plugin runtime for PHP 8.2+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
