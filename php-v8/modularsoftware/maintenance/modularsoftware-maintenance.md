# modularsoftware/maintenance

> 标签: PHP

## 简介

Modular Maintenance is a work in progress for property services. SPA based on Enso SPA (Laravel 5.6, Vue and Bulma)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
