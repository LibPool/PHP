# herobrinefr/minecraft-server-bundle

> 标签: PHP

## 简介

The Minecraft server bundle provides an easy way to integrate a Minecraft Java server connexion within a Symfony app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
