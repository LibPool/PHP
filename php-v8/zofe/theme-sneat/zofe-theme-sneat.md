# zofe/theme-sneat

> 标签: bootstrap, laravel, rapyd-admin, sneat, theme

## 简介

Sneat theme for rapyd-admin: the Sneat admin template (Bootstrap 5.3, MIT) as the admin, public and auth layouts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
