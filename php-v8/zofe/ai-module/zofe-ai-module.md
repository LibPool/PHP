# zofe/ai-module

> 标签: ai, anthropic, chatbot, laravel, livewire, ollama, openai, rapyd-admin

## 简介

AI widget, tool registry and multi-provider service (Anthropic, OpenAI-compatible, Ollama) for rapyd-admin

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
