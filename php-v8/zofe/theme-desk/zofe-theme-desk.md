# zofe/theme-desk

> 标签: admin, bootstrap, laravel, rapyd-admin, theme

## 简介

Desk theme for rapyd-admin: the classic admin look (blue sidebar, off-white content) on the bundled layout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
