# zofe/theme-tabler

> 标签: bootstrap, laravel, rapyd-admin, tabler, theme

## 简介

Tabler theme for rapyd-admin: the Tabler admin template (Bootstrap 5) as the admin, public and auth layouts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
