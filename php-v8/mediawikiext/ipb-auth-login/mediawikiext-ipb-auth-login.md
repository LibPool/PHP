# mediawikiext/ipb-auth-login

> 标签: Authentication, IPB, ips, login, mediawiki

## 简介

Log into the MediaWiki installation using IPB user accounts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
