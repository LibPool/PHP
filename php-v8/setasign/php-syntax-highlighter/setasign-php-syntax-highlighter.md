# setasign/php-syntax-highlighter

> 标签: PHP

## 简介

A PHP syntax highlighter, written in PHP, that automatically links classes, methods, class constants and functions to their documentation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
