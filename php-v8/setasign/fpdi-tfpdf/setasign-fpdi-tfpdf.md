# setasign/fpdi-tfpdf

> 标签: fpdi, pdf, tfpdf

## 简介

Kind of metadata package for dependencies of the latest versions of FPDI and tFPDF.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
