# setasign/setapdf-signer-addon-safe

> 标签: PHP

## 简介

A SetaPDF-Signer component signature module for the "Serviço de Assinatura de Faturas Eletrónicas" (SAFE) of the Portuguese State.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
