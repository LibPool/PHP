# rkw/rkw-solrsearch

> 标签: RKW, TYPO3 CMS, solr

## 简介

Extension for website search. Primarily for TYPO3 SOLR.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
