# rkw/rkw-registration

> 标签: Frontend Users, RKW, TYPO3 CMS, login, register, registration, user groups

## 简介

Extension for registration of FE-Users and FE-Usergroups

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
