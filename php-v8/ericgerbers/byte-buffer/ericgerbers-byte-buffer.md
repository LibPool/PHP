# ericgerbers/byte-buffer

> 标签: Buffer, binary, byte, hex, pack, unpack

## 简介

A fast and simple ByteBuffer implementation using SplFixedArray.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
