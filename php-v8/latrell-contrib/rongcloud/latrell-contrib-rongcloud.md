# latrell-contrib/rongcloud

> 标签: RongCloud SDK, l5, laravel, laravel 5, rongCloud

## 简介

融云服务端SDK在Laravel的封装包。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
