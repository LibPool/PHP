> 标签: 2fa, action-otp, confirmation, laravel, laravel-13, magic-link, one-time-code, one-time-password, otp, sms, verification, verification-code

## 简介

Confirm any action with a one-time code in Laravel 13: the action runs once, only after the code is verified

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
