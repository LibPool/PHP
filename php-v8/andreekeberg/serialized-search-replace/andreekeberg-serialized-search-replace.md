# andreekeberg/serialized-search-replace

> 标签: replace, search, search-replace, serialize, serialized, unserialize

## 简介

Search and replace serialized strings, and update all string lengths

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
