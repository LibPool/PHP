# andreekeberg/wp-search-replace-cli

> 标签: cli, database, dump, export, file, import, mysql, replace, search, search-replace, serialize, serialized, sql, tool, unserialize, wordpress, wp

## 简介

Command line tool to replace serialized strings in WordPress database dump files

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
