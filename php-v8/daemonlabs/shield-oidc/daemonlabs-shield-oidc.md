# daemonlabs/shield-oidc

> 标签: SSO, azure-ad, codeigniter, codeigniter4, entra-id, keycloak, oidc, okta, openid-connect, shield

## 简介

OpenID Connect single sign-on for CodeIgniter Shield: Microsoft Entra ID, Okta, Google Workspace, Keycloak, Auth0 and any other OIDC provider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
