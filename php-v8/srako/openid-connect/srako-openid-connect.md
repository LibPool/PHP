# srako/openid-connect

> 标签: OpenID Connect, OpenId, oidc, php

## 简介

PHP implementation of https://openid.net/specs/openid-connect-core-1_0.html

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
