# srako/webman-kms

> 标签: aliyun, kms, secretsmanager, webman

## 简介

Aliyun KMS local-agent (sidecar) secrets client for webman: fetch MySQL/Redis credentials from the local secretsmanager agent with in-process memory caching, automatic rotation reload and graceful fallback.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
