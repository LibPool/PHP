# unionco/craft-sync-db

> 标签: Craft, cms, craft-plugin, craft-sync-db, craftcms

## 简介

Craft 3 plugin to sync database across environments

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
