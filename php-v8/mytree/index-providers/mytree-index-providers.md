# mytree/index-providers

> 标签: genealogical indexes, genealogy, geneteka, metryki wolyn, mytree

## 简介

Standalone PHP providers for acquiring genealogical indexes from Geneteka and Metryki-Wołyń, designed for integration with MyTree and Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
