# syntatis/wp-plugin-readme-parser

> 标签: markdown, parser, plugin, readme, wordpress

## 简介

Retrieve information from WordPress plugin readme files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
