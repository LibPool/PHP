# endlessdreams/fao-toolkit

> 标签: doi, fao toolkit, smta, wiews

## 简介

FAO toolkit, to manage FAO services such as SMTA api, DOI api and WIEWS code and organization data fetching

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
