# lisoing/calendar

> 标签: calendar, holidays, internationalization, laravel, lunar, solar

## 简介

Universal lunar and solar calendar library with worldwide holidays for Laravel and PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
