# xen3r0/adf-converter

> 标签: Confluence, adf, atlassian, html, jira, markdown

## 简介

A PHP toolkit to parse the Atlassian Document Format (ADF) and export it to HTML or Markdown

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
