# silverorange/mdb2

> 标签: database, dbal, metabase, orm

## 简介

PEAR MDB2 is a merge of the PEAR DB and Metabase php database abstraction layers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
