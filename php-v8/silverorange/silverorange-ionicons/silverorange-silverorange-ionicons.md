# silverorange/silverorange-ionicons

> 标签: fonts, icon font, icons, ionic, web font

## 简介

The premium icon font for Ionic Framework. Modified for use by silverorange.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
