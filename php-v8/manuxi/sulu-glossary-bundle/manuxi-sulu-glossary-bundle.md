# manuxi/sulu-glossary-bundle

> 标签: abbreviations, glossary, sulu, sulu bundle, sulucms

## 简介

Glossary bundle for Sulu CMS: abbreviations, acronyms and terms with draft/live publishing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
