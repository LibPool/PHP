# manuxi/sulu-block-validation-bundle

> 标签: Forms, blocks, json-schema, sulu, sulucms, validation, visibleCondition

## 简介

Sulu admin forms: mandatory fields and block entries are only checked where their visibleCondition shows them; blocks with invalid fields open after a failed save

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
