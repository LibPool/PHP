# manuxi/sulu-pdf-bundle

> 标签: dompdf, download, pdf, sulu, sulucms

## 简介

PDF download for Sulu content: renders the public page of an article, event or page and sets its content into a designed PDF layout

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
