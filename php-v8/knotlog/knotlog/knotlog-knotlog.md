# knotlog/knotlog

> 标签: contextual, knot, logger, logging, logs, psr-15, psr-3, psr-7, structured, wide

## 简介

Wide logging implementation for PHP - one comprehensive, context-rich event per request

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
