# weatherlink/weatherlink_v2_api_sdk

> 标签: Davis Instruments, WeatherLink

## 简介

WeatherLink v2 API SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://weatherlink.github.io/v2-api/php-sdk
- 源码仓库：https://github.com/weatherlink/weatherlink-v2-api-sdk-php.git
- Packagist 页面：https://packagist.org/packages/weatherlink%2Fweatherlink_v2_api_sdk

## 历史版本号
