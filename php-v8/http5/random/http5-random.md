# http5/random

> 标签: PRNG, RNG, gaussian distribution, mersenne twister, normal distribution, php, pseudo random, random, random number generator, rnd, uniform distribution, xorshift, ziggurat algorithm

## 简介

Deterministic pseudo-random generators library with dozens of useful functions and several sources of randomness

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
