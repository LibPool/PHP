# dizatech/cutlet-recaptcha

> 标签: google-recaptcha, laravel, laravel-captcha, laravel-recaptcha, laravel7, laravel7-package, php, recaptcha

## 简介

A package to use google recaptcha v2 with component and rule in laravel apps.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
