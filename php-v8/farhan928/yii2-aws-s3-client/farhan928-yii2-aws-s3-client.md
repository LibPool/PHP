# farhan928/yii2-aws-s3-client

> 标签: AWS S3, aws, extension, s3, s3 client, yii2

## 简介

Yii2 wrapper extension for aws sdk s3 client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
