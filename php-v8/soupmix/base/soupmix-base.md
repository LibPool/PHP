# soupmix/base

> 标签: Abstraction Layer, adapters, database, elasticsearch, microsoft sql server, mongodb, mysql, oracle, postgresql, sqlite

## 简介

Simple database abstraction layer adapters collection to handle CRUD operations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
