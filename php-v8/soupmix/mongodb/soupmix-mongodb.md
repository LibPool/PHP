# soupmix/mongodb

> 标签: Abstraction Layer, adapters, database, mongodb

## 简介

Simple MongoDB abstraction layer adapter to handle CRUD operations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
