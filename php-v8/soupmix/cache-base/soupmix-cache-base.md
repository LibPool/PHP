# soupmix/cache-base

> 标签: adapters, cache, interface, simplecache

## 简介

Provides framework agnostic implementation of PSR-16 Simple Cache Interface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
