# dtm/dtm-client

> 标签: dtm, dtm-client, hyperf, php

## 简介

A PHP coroutine client for distributed transaction manager DTM. 分布式事务管理器 DTM 的 PHP 协程客户端

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
