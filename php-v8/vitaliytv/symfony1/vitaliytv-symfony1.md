# vitaliytv/symfony1

> 标签: PHP

## 简介

Fork of symfony 1.4 with dic, form enhancements, latest swiftmailer and better performance

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
