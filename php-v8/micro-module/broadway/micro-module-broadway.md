# micro-module/broadway

> 标签: cqrs, ddd, domain-driven design, event sourcing

## 简介

Infrastructure and testing helpers for creating CQRS and event sourced applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
