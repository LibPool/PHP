# micro-module/fault-tolerance-bundle

> 标签: PHP

## 简介

MicroModule FaultTolerance Symfony bundle — circuit breaker + retry + reconnect for Enqueue producers/consumers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
