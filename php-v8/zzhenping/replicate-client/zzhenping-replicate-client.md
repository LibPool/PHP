# zzhenping/replicate-client

> 标签: hyperf, php, replicate

## 简介

这是一个基于 Hyperf 框架封装的 PHP 客户端，用于调用 Replicate 的 AI 推理 API。支持同步推理、Webhook 通知、以及协程等待任务完成。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
