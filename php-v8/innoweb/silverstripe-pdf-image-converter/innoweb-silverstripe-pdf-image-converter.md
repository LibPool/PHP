# innoweb/silverstripe-pdf-image-converter

> 标签: convert, image, pdf, silverstripe

## 简介

Converts the first page of a PDF file to an image

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
