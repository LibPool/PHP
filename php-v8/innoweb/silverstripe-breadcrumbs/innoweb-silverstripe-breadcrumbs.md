# innoweb/silverstripe-breadcrumbs

> 标签: breadcrumbs, silverstripe

## 简介

Adds configurable and extendable breadcrumbs to the site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
