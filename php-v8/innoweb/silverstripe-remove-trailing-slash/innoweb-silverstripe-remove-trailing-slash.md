# innoweb/silverstripe-remove-trailing-slash

> 标签: seo, silverstripe, trailing slash

## 简介

Removes the trailing slash from page links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
