# innoweb/silverstripe-minify-html

> 标签: hmtl, minify, performance, silverstripe

## 简介

Minifies the HTML output for all frontend requets using a middleware.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
