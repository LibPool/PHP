# splash/skills

> 标签: PHP

## 简介

Agent Skills for Splash Sync connectors development: guidance for AI coding agents (Claude Code, Cursor, Copilot, Codex, Gemini, Mistral...)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.splashsync.com
- 源码仓库：https://gitlab.com/SplashTools/skills.git
- Packagist 页面：https://packagist.org/packages/splash%2Fskills
