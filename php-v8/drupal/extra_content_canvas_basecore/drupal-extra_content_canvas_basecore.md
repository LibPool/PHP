# drupal/extra_content_canvas_basecore

> 标签: PHP

## 简介

Adds sample Canvas pages, reusable patterns, and Basecore component definitions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
