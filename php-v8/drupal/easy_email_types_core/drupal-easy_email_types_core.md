# drupal/easy_email_types_core

> 标签: drupal

## 简介

Easy Email templates that replicate and override the content of emails sent by Drupal core with HTML-formatted versions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
