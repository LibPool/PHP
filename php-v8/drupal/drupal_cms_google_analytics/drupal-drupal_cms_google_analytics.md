# drupal/drupal_cms_google_analytics

> 标签: PHP

## 简介

Adds tracking of website traffic using Google Analytics and Google Tag Manager. Requires a Google Tag Manager ID.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
