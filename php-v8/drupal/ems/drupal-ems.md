# drupal/ems

> 标签: EMS, admin, drupal, extensions, menus, permissions, suite, taxonomy

## 简介

A unified admin dashboard for the Enhanced Manager family of modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
