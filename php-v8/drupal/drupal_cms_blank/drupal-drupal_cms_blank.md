# drupal/drupal_cms_blank

> 标签: PHP

## 简介

A blank template with the foundational features of Drupal CMS, for those who truly want to start from scratch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
