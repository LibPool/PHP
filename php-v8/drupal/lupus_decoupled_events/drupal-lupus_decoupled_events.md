# drupal/lupus_decoupled_events

> 标签: PHP

## 简介

A recipe to install Drupal CMS Project recipe including Lupus Decoupled Drupal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
