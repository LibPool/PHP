# drupal/varbase_seo_base

> 标签: Varbase recipes, drupal recipe, drupal recipes, metatag, recipe, search engine optimization, seo, varbase recipe, yoast

## 简介

A recipe to manage default installed modules, configs and permissions for Varbase Search Engine Optimization (SEO) Core features and settings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
