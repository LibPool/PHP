# drupal/seidor_recipe_core

> 标签: PHP

## 简介

This recipe installs the Seidor starter pack installer. It is a basic setup for Seidor CMS with essential security features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
