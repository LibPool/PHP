# drupal/archimedes

> 标签: PHP

## 简介

Sets up a site designed for a primary/secondary education website, this template includes landing pages, a blog, newsletter sign up and other features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
