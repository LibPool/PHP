# drupal/at_base

> 标签: Drush, api, autoloader, config, container, dependency injection, drupal

## 简介

Provide some more API for developer to work with Drupal

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
