# drupal/display_builder_cms

> 标签: drupal recipe, drupal recipes, recipe

## 简介

Provide extra contrib modules and settings for a Display Builder website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
