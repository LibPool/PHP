# drupal/jsonrpc_mcp

> 标签: PHP

## 简介

Exposes Drupal JSON-RPC method plugins as MCP (Model Context Protocol) tools, enabling integration with AI assistants like Claude Desktop

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
