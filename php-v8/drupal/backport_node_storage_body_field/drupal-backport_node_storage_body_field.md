# drupal/backport_node_storage_body_field

> 标签: PHP

## 简介

Polyfill for the node_storage_body_field sub-module introduced in Drupal 11.3. On 11.3+ this is a no-op metapackage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
