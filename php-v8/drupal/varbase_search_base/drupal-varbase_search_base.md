# drupal/varbase_search_base

> 标签: Varbase recipes, database search, drupal recipe, drupal recipes, recipe, search, search api, varbase recipe

## 简介

A recipe to manage default installed modules, configs and permissions for Varbase search functionality using Search API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
