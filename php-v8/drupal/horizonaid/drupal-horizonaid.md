# drupal/horizonaid

> 标签: PHP

## 简介

A Drupal CMS site template recipe for NGOs, nonprofits and humanitarian/aid organizations, built the Varbase recipe-first way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
