# drupal/varbase_ai_figma_base

> 标签: PHP

## 简介

Base recipe for Varbase AI Figma (vartheme_bs5 / Bootstrap 5.3) - applies Varbase AI Base, installs ai_figma + varbase_ai_figma, Context Control Center, and the targeted Figma AI Context items, and wires the Figma tools into the Drupal Canvas AI Orchestrator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
