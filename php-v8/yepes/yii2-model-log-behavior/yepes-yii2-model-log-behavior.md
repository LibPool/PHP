# yepes/yii2-model-log-behavior

> 标签: Behavior, extension, log, model, yii2

## 简介

A simple log behavior for your Yii2 models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
