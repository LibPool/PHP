# sfere-io/sfere-laravel

> 标签: CDP, analytics, conversions api, laravel, server-side tracking, sfere

## 简介

Sfere server SDK for Laravel: server-to-server event collection that forwards the end user's IP, user agent and ad click IDs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
