# clementtalleu/easyadmin-markdown-bundle

> 标签: easyadmin, easymde, editor, field, markdown, symfony

## 简介

A Markdown editor field for EasyAdmin, powered by EasyMDE.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
