# ykan/elastickit-laravel

> 标签: DSL, builder, elastickit, elasticsearch, laravel, query

## 简介

Laravel integration for ElasticKit: client bootstrapping and native pagination.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
