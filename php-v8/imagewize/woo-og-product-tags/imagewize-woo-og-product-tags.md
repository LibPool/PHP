# imagewize/woo-og-product-tags

> 标签: merchant-center, open-graph, opengraph, plugin, seo, woocommerce, wordpress

## 简介

Prints the Open Graph product tags (product:price:amount, product:price:currency, product:availability) on single WooCommerce product pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
