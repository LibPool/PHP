# imagewize/elayne

> 标签: PHP

## 简介

Elayne WordPress block theme with 140+ patterns, including ready-to-insert page patterns, 8 style variations, and WooCommerce-ready design systems for spa, legal, F&B, home improvement, nail salon, publishing, and store verticals.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
