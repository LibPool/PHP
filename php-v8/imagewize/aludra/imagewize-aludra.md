# imagewize/aludra

> 标签: aludra, block-patterns, blocks, carousel, full-site-editing, gutenberg, mega-menu, page-builder, patterns, plugin, sections, wordpress

## 简介

A page builder made of real blocks — 30 WordPress blocks, 21 section patterns and 8 page layouts for everything between the header and the footer. Native block editor, no shortcodes, theme-neutral.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
