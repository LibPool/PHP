# imagewize/nynaeve

> 标签: wordpress

## 简介

Nynaeve, the Imagewize.com production theme: Sage 11 (Roots.io stack) with Laravel Blade templating, Tailwind CSS 4, Vite, and 35 custom WordPress blocks, plus quote-based WooCommerce integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
