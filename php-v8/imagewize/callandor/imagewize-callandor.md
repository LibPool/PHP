# imagewize/callandor

> 标签: block-patterns, blocks, gutenberg, patterns, plugin, sage, tailwind, wordpress

## 简介

Pattern library for Sage 11 hybrid themes with Tailwind CSS and theme.json support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
