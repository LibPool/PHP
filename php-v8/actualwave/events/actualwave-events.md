# actualwave/events

> 标签: callback, communication, component, dispatcher, event, fire, listener

## 简介

Includes Event, EventDispatcher classes and IEventDispatcher interface for events support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
