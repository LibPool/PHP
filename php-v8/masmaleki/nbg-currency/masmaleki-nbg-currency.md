# masmaleki/nbg-currency

> 标签: Bank, Rate, currency, georgia, nbg

## 简介

National Bank of Georgia (NBG) currency service API wrapper

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
