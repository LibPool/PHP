# astrophp/trail

> 标签: ai-agents, ai-monitoring, cost-tracking, laravel, laravel-ai, laravel-ai-sdk, llm, llm-observability, observability, token-usage, tracing

## 简介

Self-hosted observability for Laravel AI SDK agents. Track execution traces, tool calls, token usage, estimated costs, and failures.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
