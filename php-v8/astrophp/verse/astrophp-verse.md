# astrophp/verse

> 标签: blade, blog, cli, markdown, ssg, static-site, static-site-generator

## 简介

AstroPHP Verse: a static site generator. Write in Markdown, design with Blade, publish anywhere.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
