# dekor/devio

> 标签: cli, deploy, devops, docker, docker-compose, phar, ssh, task-runner

## 简介

Laravel-style dev & deploy scripts for Docker-based PHP projects: shell, SSH, Docker, notifications. Ships as a single phar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
