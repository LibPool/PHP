# sejongtf/synology

> 标签: calendar, chat, contacts, dsm, mailplus, nas, psr-18, synology, webapi

## 简介

A framework-independent PHP client for the Synology DSM Web API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
