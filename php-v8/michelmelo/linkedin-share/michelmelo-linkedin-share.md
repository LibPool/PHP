# michelmelo/linkedin-share

> 标签: linkedin, linkedin API v2, linkedin share

## 简介

This package allows you to easily share content on Likedin, using the v2 API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
