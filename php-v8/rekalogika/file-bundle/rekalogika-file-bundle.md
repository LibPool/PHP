# rekalogika/file-bundle

> 标签: Flysystem, file, file-upload, filesystem, symfony, symfony-bundle, upload

## 简介

Integrates the rekalogika/file library into the Symfony framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
