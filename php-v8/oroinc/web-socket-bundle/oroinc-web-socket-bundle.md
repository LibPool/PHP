# oroinc/web-socket-bundle

> 标签: Ratchet, WAMP, Web Socket Bundle, io, websocket

## 简介

A fork of Symfony Web Socket Bundle that enables PHP 8.4 and Symfony 7 support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
