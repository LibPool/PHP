# jsor/stack-hal

> 标签: StackPHP, hal, rest, stack, symfony, vnd.error

## 简介

Stack and Symfony middlewares and utilities for working with the Hypertext Application Language (HAL).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
