# jsor/stack-jwt

> 标签: Authentication, StackPHP, jwt, rest, stack, stack-2

## 简介

JSON Web Token (JWT) Stack middleware.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
