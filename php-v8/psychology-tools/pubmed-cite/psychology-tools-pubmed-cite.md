# psychology-tools/pubmed-cite

> 标签: api, citation, cite, pmid, pubmed

## 简介

A library for formatting and fetching citations to pubmed articles from the eFetch API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
