# ozzyboshi/yii2-gridview-multiheader

> 标签: extension, gridview, multiheader, widget, yii2

## 简介

An extended gridview widget for Yii 2 with multi headers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
