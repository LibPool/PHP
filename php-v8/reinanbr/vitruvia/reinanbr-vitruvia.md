# reinanbr/vitruvia

> 标签: framework, micro-framework, mvc, php, router

## 简介

Lightweight MVC micro-framework for building small PHP web apps and JSON APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
