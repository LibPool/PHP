# capachow/arcane

> 标签: arcane, micro-framework, microframework, php, php-framework, php-micro-framework, web-development, zero-dependency

## 简介

A deceptively powerful 14kb dependency-free single-file PHP microframework built to keep things easy and minimal.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
