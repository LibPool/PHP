# nunomaduro/laravel-sluggable

> 标签: eloquent, laravel, php, slug, sluggable

## 简介

Automatic slug generation for Eloquent models via the #[Sluggable] attribute.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
