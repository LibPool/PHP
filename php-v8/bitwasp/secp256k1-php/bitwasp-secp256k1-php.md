# bitwasp/secp256k1-php

> 标签: ECDSA, bitcoin, bitwasp, cryptocurrency, ecc, extension, php, secp256k1

## 简介

PHP Extension with bindings for bitcoin/secp256k1.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
