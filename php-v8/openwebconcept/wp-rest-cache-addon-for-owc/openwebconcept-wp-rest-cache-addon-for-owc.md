# openwebconcept/wp-rest-cache-addon-for-owc

> 标签: PHP

## 简介

Adds caching of the OpenWebConcept endpoints to the WP REST Cache.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
