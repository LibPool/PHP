# faulkj/db

> 标签: MS SQL, microsoft sql, sql, sqlsrv

## 简介

A wrapper class for SQLSRV (MS SQL) in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
