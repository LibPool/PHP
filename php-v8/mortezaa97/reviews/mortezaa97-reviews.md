# mortezaa97/reviews

> 标签: mortezaa97, reviews

## 简介

A Laravel package designed to implement a reviews feature similar to Instagram Stories or Google Web Stories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
