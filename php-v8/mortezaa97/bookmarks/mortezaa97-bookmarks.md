# mortezaa97/bookmarks

> 标签: bookmarks, mortezaa97

## 简介

A Laravel package for managing user bookmarks, allowing users to save, view, and delete bookmarks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
