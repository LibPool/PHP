# fewchurs/laravel

> 标签: feature-requests, feedback, fewchurs, laravel, roadmap

## 简介

Drop a Fewchurs feature-request board into any Laravel app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
