# ox-harris/phpfront

> 标签: html, php, syntaxless templating, template engine, templating

## 简介

Template Engine for PHP - Well-Engineered for Templating. Uses no template syntaxes!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
