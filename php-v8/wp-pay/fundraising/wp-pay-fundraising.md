# wp-pay/fundraising

> 标签: addon, crowdfunding, donations, fundraising, pay, progress, pronamic, target, wordpress, wp

## 简介

Fundraising add-on for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
