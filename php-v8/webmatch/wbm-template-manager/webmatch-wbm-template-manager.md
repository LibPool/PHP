# webmatch/wbm-template-manager

> 标签: shopware, shopware-plugin, smarty, template

## 简介

Shopware-Plugin to extend or overwrite templates within the backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
