# amirrh6/simpleslug

> 标签: PHP

## 简介

SimpleSlug is a straightforward PHP library designed to help you generate amusing and meaningful combinations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
