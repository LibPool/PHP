# kosovopay/php-sdk

> 标签: api, kosovopay, payments, saloon, sdk

## 简介

Strongly-typed PHP client for the KosovoPay payment orchestrator API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
