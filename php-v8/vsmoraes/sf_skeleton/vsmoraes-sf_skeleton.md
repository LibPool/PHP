# vsmoraes/sf_skeleton

> 标签: Skeleton, api, framework, symfony

## 简介

A modification to the "Symfony Standard Edition" distribution to make it little and API friendly.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
