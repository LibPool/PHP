# infinityfree/acmecore

> 标签: acmephp, certificate, csr, encryption, https, letsencrypt, openssl, ssl, x509

## 简介

Raw implementation of the ACME protocol in PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
