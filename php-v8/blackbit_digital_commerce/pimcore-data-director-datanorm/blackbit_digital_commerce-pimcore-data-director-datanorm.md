# blackbit_digital_commerce/pimcore-data-director-datanorm

> 标签: PHP

## 简介

Add-on bundle for Pimcore Data Direktor to support Datanorm exports

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
