# blackbit_digital_commerce/pimcore-external-sitemaps

> 标签: PHP

## 简介

Add URLs from external sitemaps / sitemap index files to the Pimcore-generated sitemap.xml

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
