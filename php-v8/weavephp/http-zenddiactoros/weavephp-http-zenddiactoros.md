# weavephp/http-zenddiactoros

> 标签: adaptor, psr7, weave

## 简介

Weave glue-framework Zend Diactoros PSR7 HTTP Message adaptor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
