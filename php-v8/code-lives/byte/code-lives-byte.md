# code-lives/byte

> 标签: PHP

## 简介

抖音小程序（支付、手机号解密、获取Token、支付异步通知、退款、订单查询、分账、模版消息）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
