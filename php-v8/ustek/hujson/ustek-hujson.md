# ustek/hujson

> 标签: JSON5, comments, config, hujson, json, jwcc

## 简介

PHP port of tailscale/hujson: a parser and packer for the JWCC format (JSON With Commas and Comments).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
