# magician79/coding-standard

> 标签: PHPStan, coding-standard, phpcs, psr-12, slevomat

## 简介

Shared coding standards: PHPCS (PSR-12 + Slevomat) and PHPStan defaults for PHP8 projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
