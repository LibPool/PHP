# antibodies-online/omnipay-vr-payment

> 标签: gateway, merchant, omnipay, pay, payment, vr

## 简介

VR Payment gateway driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
