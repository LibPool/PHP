# mindkomm/theme-lib-backend-rename-post-type-menu

> 标签: PHP

## 简介

Helper class to make it possible to rename the menu for a post type in the WordPress backend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
