# pixelbin/pixelbin

> 标签: api, image management, php, pixelbin, sdk

## 简介

Pixelbin Backend SDK for PHP helps you integrate the core Pixelbin features with your application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
