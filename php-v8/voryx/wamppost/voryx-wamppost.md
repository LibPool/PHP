# voryx/wamppost

> 标签: WAMP, WAMP2, WebSockets, http, proxy, publish, pubsub

## 简介

HTTP to WAMP Publishing Proxy

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
