# voryx/pgasync

> 标签: async, driver, pgsql, postgres, postgresql, react, reactive, rx.php

## 简介

Async Reactive Postgres Driver for PHP (Non-blocking)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
