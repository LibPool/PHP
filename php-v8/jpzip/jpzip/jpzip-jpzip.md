# jpzip/jpzip

> 标签: japan, jpzip, postal-code, sdk, zipcode

## 简介

jpzip PHP SDK — 日本の郵便番号を CDN 配信の JSON データから引く

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
