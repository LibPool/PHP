# aisuvro/laravel-storage-linker

> 标签: disk, filesystem, laravel, storage, symlink

## 简介

A Laravel package to create symbolic links for storage disks with interactive selection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
