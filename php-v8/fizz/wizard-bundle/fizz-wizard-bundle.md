# fizz/wizard-bundle

> 标签: Js Routing, javascript, routing

## 简介

A pretty nice way to expose your Symfony2 routing to client applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
