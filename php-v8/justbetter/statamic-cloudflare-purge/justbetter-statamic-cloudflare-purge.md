# justbetter/statamic-cloudflare-purge

> 标签: caching, cloudflare, statamic

## 简介

Addon that hooks into the statamic invalidation process and purges cloudflare caches

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
