# kevinbaubet/kss-php-markup

> 标签: css documentation, kss, kss php, styleguide

## 简介

An extension of kss-php for get markup by url and html selector.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
