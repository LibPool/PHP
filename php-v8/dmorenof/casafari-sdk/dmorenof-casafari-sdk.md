# dmorenof/casafari-sdk

> 标签: API-Client, casafari, casafari-crm, php, real-estate, sdk

## 简介

Unofficial PHP SDK for the Casafari CRM API, with typed DTOs, typed collections and HTTP middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
