# blacklinecloud/gowa-php-sdk

> 标签: API-Client, gowa, php, psr, sdk, webhook, whatsapp

## 简介

Type-safe PHP SDK for Go WhatsApp Web MultiDevice (REST & webhooks)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
