# michaelgooden/mdg-uuid

> 标签: uuid

## 简介

Simple UUID generation functionality, using Zend Framework 2's Zend\Math\Rand component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
