# domwebber/array-toggle-permutations

> 标签: PHP

## 简介

PHP array permutations iterator. A simple way to loop through every possible combination of items in an array.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
