# mateuszbieniek/ezplatform-form-builder-multi-step-forms

> 标签: PHP

## 简介

Adds feature to create multi-step forms in eZ Platform 2.5 Form Builder

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
