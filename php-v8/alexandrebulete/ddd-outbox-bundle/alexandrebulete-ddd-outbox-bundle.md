# alexandrebulete/ddd-outbox-bundle

> 标签: PHP

## 简介

Asynchronous effects you can trust in a DDD application: sent if and only if the action commits, tracked one by one, retried from the back office — on the Messenger Doctrine transport, without an extra outbox table.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
