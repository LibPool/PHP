# alexandrebulete/ddd-scheduler-bundle

> 标签: PHP

## 简介

See and run your Symfony Scheduler tasks from the back office: a read-only catalogue (command, cron, next run, last run and status) with a one-click manual run, built on Symfony Scheduler and Messenger.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
