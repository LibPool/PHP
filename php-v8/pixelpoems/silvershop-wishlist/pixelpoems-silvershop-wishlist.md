# pixelpoems/silvershop-wishlist

> 标签: ecommerce, silvershop, silverstripe, wishlist

## 简介

Silverstripe Wishlist Module for Silvershop, allowing customers to create and manage a single wishlist.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
