# pixelpoems/silverstripe-instagram-feed

> 标签: element, instagram, silverstripe

## 简介

Silverstripe module that generates an instagram feed for a given user.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
