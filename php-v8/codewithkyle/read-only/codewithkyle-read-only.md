# codewithkyle/read-only

> 标签: Craft, Read only, cms, craft-plugin, craftcms

## 简介

Adds a read only text field to Craft CMS with click-to-copy functionality.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
