# elvesora/domain-lookup-laravel

> 标签: company domain, domain lookup, elvesora, laravel

## 简介

Self-contained Laravel client for the Elvesora Company Domain Lookup API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
