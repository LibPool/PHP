# elvesora/domain-lookup-php

> 标签: company domain, domain lookup, elvesora, php sdk

## 简介

Framework-independent PHP client for the Elvesora Company Domain Lookup API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
