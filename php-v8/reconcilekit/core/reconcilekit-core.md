# reconcilekit/core

> 标签: finance, fintech, laravel, payments, reconciliation

## 简介

Financial reconciliation for Laravel: compare internal payments with provider data and detect missing, duplicate and mismatched transactions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
