# edulazaro/larasearch

> 标签: command palette, eloquent, full-text, fulltext, laravel, multi-tenant, search

## 简介

Text search for Eloquent models on your own database: a normalized search_text column per model for fast list searches, and an optional global index for command palettes, scoped by tenant and filtered by what each user may see. No Elasticsearch, no Meilisearch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
