# edulazaro/laratox

> 标签: content-moderation, laravel, moderation, spam, toxicfilter, toxicity, validation

## 简介

Content moderation for Laravel, powered by ToxicFilter

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
