# edulazaro/wiretables

> 标签: alpine, blade, datatable, laravel, livewire, table, ui

## 简介

Tables for Laravel, Livewire and Alpine: Blade components that read the same on a phone and a desktop, header sorting and a row actions menu. Pure CSS, themed with the wire* family.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
