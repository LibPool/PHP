# edulazaro/larameili

> 标签: eloquent, laravel, meilisearch, odm, search, vector-search

## 简介

Eloquent-style models for Meilisearch. Treat a Meilisearch index as your database: find, search (keyword or hybrid), save and delete documents through a model class, with index settings declared in code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
