# edulazaro/astronomy

> 标签: JPL, astronomy, eclipses, elp2000, ephemeris, horizons, vsop87

## 简介

A pure PHP astronomical engine: planetary and lunar ephemerides, fixed stars, eclipses, occultations and rise and set times, verified against JPL Horizons.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
