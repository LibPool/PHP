# edulazaro/toxicfilter-sdk

> 标签: PHP

## 简介

The official PHP client for the ToxicFilter content moderation API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://toxicfilter.com/docs/sdks
- 源码仓库：https://github.com/toxicfilter/php-sdk.git
- Packagist 页面：https://packagist.org/packages/edulazaro%2Ftoxicfilter-sdk

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require edulazaro/toxicfilter-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/edulazaro/toxicfilter-sdk.json
- 许可证：MIT
