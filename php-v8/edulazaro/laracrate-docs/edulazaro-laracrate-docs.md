# edulazaro/laracrate-docs

> 标签: documents, drive, editor, laracrate, laravel, prosemirror, tiptap, versions

## 简介

Native editable documents for Laracrate: the file is the drive index, the content lives apart. Versions, named fields and PDF export.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
