# edulazaro/wirefence

> 标签: bots, firewall, ip-blocking, laravel, livewire, security

## 简介

Fences Livewire apps against tampered requests: a property sent a value no form can produce, a locked property, an unknown property or method. Answers 400 instead of a 500 in the log, and blocks the address for a while.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
