# edulazaro/wirepicker

> 标签: alpine, calendar, date-range, datepicker, laravel, livewire, ui

## 简介

Framework-agnostic date and date-range picker for Laravel, Livewire and Alpine. Pure CSS, themed through CSS variables, localized through Intl. Sibling of wiremodal and wiretoast.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
