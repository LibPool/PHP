# edulazaro/laradomains

> 标签: Public Suffix List, dns over https, domain, idn, laravel, punycode, rdap, whois

## 简介

Everything you can learn about a domain without visiting it: parsing with the Public Suffix List, RDAP registration data, age, DNS over HTTPS and malware or adult screening

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
