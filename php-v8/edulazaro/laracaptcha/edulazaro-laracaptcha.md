# edulazaro/laracaptcha

> 标签: PHP

## 简介

Driver-based captcha for Laravel: Cloudflare Turnstile and Google reCAPTCHA v2/v3 behind a single API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
