# edulazaro/wirelist

> 标签: alpine, blade, cards, grid, laravel, list, livewire, ui

## 简介

Lists for Laravel, Livewire and Alpine: records as divided rows, separate cards or a grid, each opening its record, with the row actions menu and load more of wiretables. Pure CSS, themed with the wire* family.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
