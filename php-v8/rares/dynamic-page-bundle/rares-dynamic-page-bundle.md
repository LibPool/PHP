# rares/dynamic-page-bundle

> 标签: ajax, dynamic

## 简介

Bundle that lets you dynamically modify parts of a page using AJAX requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
