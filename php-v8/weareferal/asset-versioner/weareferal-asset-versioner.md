# weareferal/asset-versioner

> 标签: Craft, asset versioner, cms, craft-plugin, craftcms

## 简介

Automatically create cache-busting versions of all your assets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
