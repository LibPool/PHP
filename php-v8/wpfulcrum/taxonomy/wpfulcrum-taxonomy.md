# wpfulcrum/taxonomy

> 标签: custom-taxonomy, wordpress

## 简介

Fulcrum Taxonomy Module - custom taxonomies made easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
