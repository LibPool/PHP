# koomai/laravel-cli-scheduler

> 标签: koomai, laravel, laravel-cli-scheduler

## 简介

Dynamically schedule your Laravel tasks using artisan commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
