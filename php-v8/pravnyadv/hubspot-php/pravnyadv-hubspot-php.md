# pravnyadv/hubspot-php

> 标签: api, crm, hubspot, oauth, php, sdk

## 简介

A lightweight, date-versioned PHP client for the HubSpot API, with auto-refreshing OAuth, retrying HTTP middleware, cursor pagination, and webhook signature verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
