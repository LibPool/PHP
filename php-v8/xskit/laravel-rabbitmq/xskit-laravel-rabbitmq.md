# xskit/laravel-rabbitmq

> 标签: PHP

## 简介

采用laravel queue的方式监听 RabbitMQ 消息，完成 分布式 服务的通信功能。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
