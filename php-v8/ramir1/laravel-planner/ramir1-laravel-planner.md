# ramir1/laravel-planner

> 标签: Planner, artisan, commands, deferred, laravel, queue, scheduler

## 简介

Database-backed planner of one-off deferred artisan commands for Laravel: schedule a command for a given time, group, cancel and inspect it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
