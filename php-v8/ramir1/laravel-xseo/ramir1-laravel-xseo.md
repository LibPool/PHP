# ramir1/laravel-xseo

> 标签: PHP

## 简介

Generic SEO meta-tags manager for Laravel: title, description, canonical, hreflang alternates, Open Graph, Twitter Card and JSON-LD, driven by simple named rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
