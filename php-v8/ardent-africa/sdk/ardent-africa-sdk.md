# ardent-africa/sdk

> 标签: Ghana, api, ardent, ardent-africa, fundraising, petitions, sdk

## 简介

Typed, read-only PHP client for the Ardent Africa public API (/public/v1).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
