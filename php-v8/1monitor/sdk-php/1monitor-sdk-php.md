# 1monitor/sdk-php

> 标签: 1monitor, cron, heartbeat, monitoring, observability, ping, uptime

## 简介

Official PHP SDK for 1Monitor — ping your cron jobs, workers and scheduled tasks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
