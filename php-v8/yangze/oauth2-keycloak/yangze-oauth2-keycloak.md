# yangze/oauth2-keycloak

> 标签: authorisation, authorization, client, keycloak, oauth, oauth2

## 简介

A wrapper for the Keycloak OAuth 2.0 Client Provider

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
