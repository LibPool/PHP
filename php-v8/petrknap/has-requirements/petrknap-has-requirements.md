# petrknap/has-requirements

> 标签: composer, composer-suggest, dependency, dependency-check, optional-dependencies, optional-requirements, requirements, requirements-check, runtime-check, suggest-check

## 简介

Simple trait to check if requirements of your code are fulfilled

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
