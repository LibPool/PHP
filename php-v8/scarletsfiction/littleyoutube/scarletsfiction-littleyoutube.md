# scarletsfiction/littleyoutube

> 标签: library, littleyoutube, php, youtube

## 简介

LittleYoutube is a library for retrieving youtube data with PHP script

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
