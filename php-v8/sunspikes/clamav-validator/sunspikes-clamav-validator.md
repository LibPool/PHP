# sunspikes/clamav-validator

> 标签: antivirus, clamav, laravel, validator, virus

## 简介

Custom Laravel anti-virus validator for file uploads using ClamAV.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
