# phyozawtun/substr_mm

> 标签: PHP

## 简介

PHP function extracts a substring with a specified length starting from a location in the Myanmar Language input.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
