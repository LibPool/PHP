# swaggest/json-cli

> 标签: PHP

## 简介

JSON CLI tool (diff, rearrange, pretty print, minify, yaml convert, etc...)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
