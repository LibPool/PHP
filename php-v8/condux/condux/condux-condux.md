# condux/condux

> 标签: condux, error-monitoring, observability, sentry

## 简介

The Condux SDK for PHP: report errors to a Condux relay with a resilient, never-throwing transport. Zero runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
