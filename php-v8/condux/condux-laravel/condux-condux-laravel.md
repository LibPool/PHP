# condux/condux-laravel

> 标签: condux, error-monitoring, laravel, observability, sentry

## 简介

Laravel integration for the Condux SDK: automatic exception reporting to a Condux relay, zero config beyond a DSN.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
