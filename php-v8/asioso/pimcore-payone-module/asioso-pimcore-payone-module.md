# asioso/pimcore-payone-module

> 标签: e-commerce, payone, pimcore, pimcore-plugin

## 简介

A bundle to help with e-commerce and payone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
