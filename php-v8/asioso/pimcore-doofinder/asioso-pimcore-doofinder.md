# asioso/pimcore-doofinder

> 标签: doofinder, e-commerce, pimcore, pimcore-plugin

## 简介

Connects Pimcore with the Powerful, Easy and Affordable E-Commerce Search Engine Doofinder providing Autocomplete, Custom Results, Facets navigation, Boosting, Real-time statistics, Synonyms and many more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
