# bigpoint/slim-bootstrap3

> 标签: microframework, rest, router, slim

## 简介

These classes provide a simple way to bootstrap a slim v3 application with authentication.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
