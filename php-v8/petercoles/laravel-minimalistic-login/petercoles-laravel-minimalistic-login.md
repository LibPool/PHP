# petercoles/laravel-minimalistic-login

> 标签: Authentication, laravel, login

## 简介

A minimalistic login for Laravel projects that don't need a full registration and authentication system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
