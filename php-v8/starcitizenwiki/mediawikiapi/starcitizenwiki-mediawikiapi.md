# starcitizenwiki/mediawikiapi

> 标签: PHP

## 简介

Laravel Package to interact with a Mediawiki Installation through the API, authenticated via OAuth

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
