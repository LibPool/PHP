# makise-co/postgres

> 标签: client, coro, coroutine, pgsql, postgres, swoole

## 简介

A Pure coroutine PHP client for PostgreSQL based on libpq

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
