# btelle/ethereum-rpc

> 标签: cryptocurrency, ethereum, etherium, json-rpc

## 简介

A PHP interface to the geth JSON-RPC API. All documented API functions are present.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
