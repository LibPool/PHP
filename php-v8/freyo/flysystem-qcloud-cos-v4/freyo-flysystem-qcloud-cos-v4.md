# freyo/flysystem-qcloud-cos-v4

> 标签: flysystem-adapter, qcloud, qcloud-cos, qcloud-sdk

## 简介

Flysystem Adapter for Tencent Qcloud COS SDK V4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
