# pecl/pdo_oci

> 标签: database, oracle, pdo, pdo_oci

## 简介

Use the PDO_OCI extension to access Oracle Database via PHP Data Objects (PDO) APIs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
