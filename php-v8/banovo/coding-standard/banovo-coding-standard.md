# banovo/coding-standard

> 标签: Banovo, Coding Standard, phpcs

## 简介

CodeSniffer ruleset for the Banovo PHP coding standard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
