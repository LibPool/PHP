# riipandi/altstack

> 标签: alpinejs, framework, laravel, tailwindcss

## 简介

Alpine.js, Laravel, and Tailwind. An alternative full-stack development solution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
