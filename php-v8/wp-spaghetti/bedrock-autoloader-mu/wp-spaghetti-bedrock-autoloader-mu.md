# wp-spaghetti/bedrock-autoloader-mu

> 标签: autoloader, bedrock, mu-plugins, must-use, wordpress

## 简介

Self-contained Bedrock MU-Plugin Autoloader, auto-synced daily from roots/bedrock

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
