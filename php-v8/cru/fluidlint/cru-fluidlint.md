# cru/fluidlint

> 标签: fluid, lint, static-analysis, templates, typo3

## 简介

Linting, cyclomatic complexity and dead-code analysis for TYPO3 Fluid templates

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
