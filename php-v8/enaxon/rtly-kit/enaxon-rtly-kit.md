# enaxon/rtly-kit

> 标签: Jalali, arabic, calendar, carbon, datetime, hebrew, hijri, iran, persian, prayer-times, rtl, shamsi, umm-al-qura, validation

## 简介

Dates, numbers and checks for Persian and Arabic PHP apps: Jalali, Hijri and Hebrew calendars, Iranian validators, number words, holidays and prayer times. No required dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
