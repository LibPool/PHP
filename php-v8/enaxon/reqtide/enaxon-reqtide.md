# enaxon/reqtide

> 标签: api, bulkhead, circuit-breaker, http, rate-limit, rate-limiter, resilience, retry

## 简介

Dependency-free resilience core for PHP: deadlines, retries, rate limiting, circuit breaking and bulkheads with explicit, testable guarantees.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
