# enaxon/reqtide-guzzle

> 标签: Guzzle, bulkhead, circuit-breaker, http, rate-limit, resilience, retry

## 简介

Guzzle integration for Reqtide: retries, deadlines, rate limits, circuit breaking and bulkheads around Guzzle 7 requests. Work in progress, not released.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
