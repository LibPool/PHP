# enaxon/reqtide-redis

> 标签: bulkhead, circuit-breaker, predis, rate-limit, redis, resilience, retry

## 简介

Redis state backends for Reqtide: shared rate limits, circuit breakers, bulkheads, retry budgets and cooldowns. Work in progress, not released.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
