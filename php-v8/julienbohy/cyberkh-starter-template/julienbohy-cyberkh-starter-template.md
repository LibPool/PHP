# julienbohy/cyberkh-starter-template

> 标签: PHP

## 简介

Symfony 8.1 starter template: PHP 8.5, Doctrine/PostgreSQL, users with email verification, Symfony UX, Tailwind + shadcn, PHPStan max, Castor

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
