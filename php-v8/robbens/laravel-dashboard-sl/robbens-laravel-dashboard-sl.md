# robbens/laravel-dashboard-sl

> 标签: laravel-dashboard-sl, robbens

## 简介

Real time updates for public transport in Stockholm, Sweden.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
