# by/guest-entries-notification

> 标签: Craft, cms, craft-plugin, craftcms, guest entries notification

## 简介

A plugin to get notification when an entry is created.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
