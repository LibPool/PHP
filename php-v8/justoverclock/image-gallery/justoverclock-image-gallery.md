# justoverclock/image-gallery

> 标签: flickr, flickr gallery, gallery, image gallery

## 简介

Add an image gallery to Flarum directly from Flickr

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
