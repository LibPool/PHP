# bentools/shh

> 标签: Private Key, decrypt, decryption, encrypt, encryption, openrsa, openssl, passphrase, public key, secret, secrets, symfony

## 简介

A PHP library to encrypt/decrypt secrets using OpenSSL.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
