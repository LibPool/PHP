# bentools/guzzle-duration-middleware

> 标签: PHP

## 简介

A GuzzleHTTP Middleware that adds a X-Request-Duration header to all responses to monitor response times.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
