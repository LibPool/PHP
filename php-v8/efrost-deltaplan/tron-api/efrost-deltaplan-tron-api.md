# efrost-deltaplan/tron-api

> 标签: iexbase, tron-api, tron-lib, tron-php, tron-rest-api

## 简介

A PHP API for interacting with Tron (Trx) using web3p/web3.php

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
