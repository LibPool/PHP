# davidepastore/slim-markdown-view

> 标签: framework, markdown, md, renderer, slim, template, view

## 简介

Render PHP view scripts into a PSR-7 Response object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
