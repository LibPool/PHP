# shortinc/n8n-eloquent

> 标签: automation, eloquent, laravel, n8n, shortinc, webhooks, workflow

## 简介

A Laravel package for seamlessly integrating Eloquent models with n8n workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
