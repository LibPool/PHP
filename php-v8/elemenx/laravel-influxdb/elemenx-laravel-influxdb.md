# elemenx/laravel-influxdb

> 标签: influxdb, laravel, package, time-series-db

## 简介

A service made to provide, set up and use the library influxdb-php in Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
