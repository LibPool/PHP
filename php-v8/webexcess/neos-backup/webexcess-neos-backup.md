# webexcess/neos-backup

> 标签: PHP

## 简介

Neos CMS Module for the incremental & encrypted Backup Package WebExcess.Flow.Backup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
