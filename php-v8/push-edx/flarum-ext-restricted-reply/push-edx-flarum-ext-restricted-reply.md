# push-edx/flarum-ext-restricted-reply

> 标签: flarum, push-edx, pushedx, restricted-reply

## 简介

Restrict reply to all tags (AND all permissions).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
