# yanlongli/papayment

> 标签: PHP

## 简介

PHP Aggregation Payment Client, 专注小程序支付下单，支持：支付宝、微信、百度、快手、字节跳动（抖音、头条）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
