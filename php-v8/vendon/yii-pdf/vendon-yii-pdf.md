# vendon/yii-pdf

> 标签: PHP

## 简介

Yii-wrapper for PHP-PDF libraries (mPDF, HTML2PDF)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
