# iperamuna/laravel-hypercacheio

> 标签: cache, distributed, laravel, performance, sqlite

## 简介

High-performance distributed Laravel cache driver using SQLite & HTTP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
