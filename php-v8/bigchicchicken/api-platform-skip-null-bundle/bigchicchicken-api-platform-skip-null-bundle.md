# bigchicchicken/api-platform-skip-null-bundle

> 标签: api-patform, skip_null, symfony

## 简介

Bundle to globally define skip_null_values parameter on all entities for ApiPlatform

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
