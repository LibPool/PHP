# gavd/li3_flash_message

> 标签: PHP

## 简介

The Flash Message plugin  for Lithium provides a straightforward interface for displaying status messages to the user.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
