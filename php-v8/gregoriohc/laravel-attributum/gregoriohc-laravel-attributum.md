# gregoriohc/laravel-attributum

> 标签: attributes, laravel, model, package, properties

## 简介

Laravel package that adds custom dynamic attributes to models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
