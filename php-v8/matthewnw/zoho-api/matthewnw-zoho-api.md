# matthewnw/zoho-api

> 标签: Zoho, api, creator, reports, zohocreator

## 简介

A class to consume Zoho's Creator and Reports API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
