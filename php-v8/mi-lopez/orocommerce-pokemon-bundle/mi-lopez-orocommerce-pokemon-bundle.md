# mi-lopez/orocommerce-pokemon-bundle

> 标签: PHP

## 简介

Code used as an example for oro tech 7 using the oro integration package and the pokemon API https://pokeapi.co/

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
