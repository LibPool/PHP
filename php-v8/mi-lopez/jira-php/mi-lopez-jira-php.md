# mi-lopez/jira-php

> 标签: api, client, jira, php, sdk, service-desk

## 简介

Jira PHP is a supercharged PHP API client that allows you to interact with the Jira API and the Service Desk API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
