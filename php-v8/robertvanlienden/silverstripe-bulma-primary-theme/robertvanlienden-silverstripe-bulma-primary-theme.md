# robertvanlienden/silverstripe-bulma-primary-theme

> 标签: silverstripe, theme

## 简介

A simple SilverStripe primary colored theme based on the Bulma CSS Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
