# nargotik/early-hints

> 标签: 103, early hints, http, link, performance, preload

## 简介

Tiny PHP polyfill to send HTTP 103 Early Hints (Link: preload ...) safely and ergonomically.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
