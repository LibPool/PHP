# yosiazwan/php-facedetection

> 标签: PHP

## 简介

PHP class to detect one face in images. A pure PHP port of an existing JS code from Karthik Tharavad.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
