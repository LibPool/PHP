# artroot/koala

> 标签: BTS, bug tracking system, prototype, telegram bot

## 简介

Bug Tracker System supporting prototypes and telegram bot management

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/artroot/koala.git
- Packagist 页面：https://packagist.org/packages/artroot%2Fkoala
