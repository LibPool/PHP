# rantes/dumbophp

> 标签: OOP, active, framework, mvc, orm, php, record

## 简介

PHP Framework project built with MVC architecture, OOP paradigm and full ORM (native, not vendor).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
