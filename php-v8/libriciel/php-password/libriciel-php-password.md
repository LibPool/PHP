# libriciel/php-password

> 标签: PHP

## 简介

Bibliothèque PHP permettant de calculer la force et l'entropie d'un mot de passe et de générer des mots de passes aléatoires.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
