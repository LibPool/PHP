# wonittecnologia/interage-sdk-php

> 标签: interage, omnichannel, pabx, sdk, whatsapp, wonit

## 简介

SDK PHP oficial da API pública de clientes da plataforma Interage+ (Wonit).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
