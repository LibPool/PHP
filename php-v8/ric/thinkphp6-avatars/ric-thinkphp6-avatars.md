# ric/thinkphp6-avatars

> 标签: avatars, think, thinkphp6, 头像

## 简介

用于php根据传入的字符串生成头像，可指定大小

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
