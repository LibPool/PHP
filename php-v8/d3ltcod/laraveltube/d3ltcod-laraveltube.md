# d3ltcod/laraveltube

> 标签: bootstrap, laravel, mp4, video, vue

## 简介

Open source project about sharing videos platform built on Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
