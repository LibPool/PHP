# jiriknesl/mockista

> 标签: BDD, TDD, mock, mocking, mockista, phpunit, testing, tests

## 简介

Mockista is library for mocking, which I've written, because I find mocking in PHPUnit slow.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
