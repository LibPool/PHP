> 标签: datatables, extension, widget, yii2, yii2 datatables, yii2 widget datatables

## 简介

DataTables plug-in jQuery Javascript library. for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
