# mouf/javascript.ace

> 标签: ace, javascript, mouf

## 简介

This package contains the ACE Javascript code editor (and a Mouf wrapper installer).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
