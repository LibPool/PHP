# mouf/oo-amqp-client

> 标签: TDBM, hydrator

## 简介

An object oriented wrapper on top of php-amqplib helping work with RabbitMQ in a more object oriented way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
