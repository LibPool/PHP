# mouf/html.widgets.select2

> 标签: mouf, select2

## 简介

This package contains a pure PHP object representation of a select box rendered with the jQuery Select2 plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
