# oxid-projects/pdf-invoice-module

> 标签: OXID, eshop, invoice, modules, pdf

## 简介

This is Invoice PDF module for OXID eShop.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
