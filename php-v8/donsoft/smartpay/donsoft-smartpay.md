# donsoft/smartpay

> 标签: currency support, intelligent routing, laravel, laravel package, multi-processor, payment, payment gateway, payment processing, smart pay, transaction cost, transaction routing

## 简介

A Laravel package to intelligently route payment transactions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
