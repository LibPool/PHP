# packstub/filament-flow

> 标签: automation, automations, filament, filament-automations, filament-flow, filament-plugin, filament-v5, flowchart, laravel, no-code, packstub, triggers, workflow, workflows

## 简介

Visual workflow automations for Filament panels: triggers, conditions and actions drawn on a canvas, run by your queue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
