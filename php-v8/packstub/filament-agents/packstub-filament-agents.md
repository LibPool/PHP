# packstub/filament-agents

> 标签: agents, ai, assistant, chat, filament, filament-panel, filament-plugin, filament-v5, laravel, laravel-ai, mcp, mcp-server

## 简介

An in-panel AI assistant and an MCP server for Filament v5 panels, built on laravel/ai and laravel/mcp through packstub/agents: one tool list for both, the panel's own authorization, approve-in-chat writes, live tables and charts in answers, per-workspace budgets and an operator limits page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
