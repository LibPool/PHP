# packstub/filament-session-replay

> 标签: filament, filament-plugin, laravel, livewire, rrweb, session-recording, session-replay, support

## 简介

Session replay inside a Filament panel: every recording of packstub/session-replay in a filterable resource, the player with errors, failed Livewire requests and web vitals on the timeline, a relation manager and a "Watch last session" action for your users, masking declared on the form field, workspace-aware in multi-tenant panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
