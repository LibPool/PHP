# packstub/filament-nitpick

> 标签: dark-mode, filament, filament-plugin, filament-theme, filament-themes, filament-v5, laravel, nitpick, packstub, theme, theme-switcher, themes, ui

## 简介

Themes for Filament panels: designed looks with a per-panel default, an open registry any package can add a theme to, and a picker that lets each user choose their own.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
