# packstub/filament-kanban

> 标签: drag-and-drop, filament, filament-kanban, filament-plugin, filament-v5, kanban, kanban-board, laravel, livewire, packstub, pipeline

## 简介

A fast, simple Kanban board for Filament: optimistic drag and drop, per-user columns and drop rules, a focus mode without the sidebar, and cards shaped in one closure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
