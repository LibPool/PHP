# packstub/agents

> 标签: agents, ai, assistant, chat, laravel, laravel-ai, laravel-mcp, mcp, mcp-server

## 简介

AI agents for Laravel: an agent engine and an MCP server sharing one tool list, built on laravel/ai and laravel/mcp — tools gated by the app's own abilities, read or write tokens for Claude Code, Claude Desktop and Cursor, queued turns, budgets and limits per workspace and per user. packstub/filament-agents adds the chat and the operator pages to a Filament panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
