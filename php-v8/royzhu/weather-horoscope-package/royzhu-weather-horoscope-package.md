# royzhu/weather-horoscope-package

> 标签: Taiwan, astrology, cwb, forecast, horoscope, laravel, weather

## 简介

Laravel 天氣資訊和星座運勢套件，整合中央氣象局 API 和星座運勢爬取功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
