# mapo-89/core-panel

> 标签: PHP

## 简介

A Laravel admin starter kit built with Inertia, Vue, Tailwind CSS, Fortify, Passport, Horizon, and Wayfinder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
