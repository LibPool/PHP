# mapo-89/laravel-qr-decoder

> 标签: laravel-qr-decoder, mapo-89

## 简介

A cross‑platform Laravel package for decoding QR codes from PNG images using Python

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
