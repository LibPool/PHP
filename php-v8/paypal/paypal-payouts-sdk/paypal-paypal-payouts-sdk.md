# paypal/paypal-payouts-sdk

> 标签: payouts, paypal, rest, sdk

## 简介

PayPal's PHP SDK for Payouts REST APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
