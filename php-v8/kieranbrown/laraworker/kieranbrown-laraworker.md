# kieranbrown/laraworker

> 标签: cloudflare, laravel, php-wasm, wasm, workers

## 简介

Run Laravel on Cloudflare Workers via php-cgi-wasm

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
