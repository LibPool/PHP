# mago-assistant/magento2-mago

> 标签: PHP

## 简介

AI-powered admin assistant for Magento 2. Chat with your store using Anthropic, OpenAI, Gemini, Ollama and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
