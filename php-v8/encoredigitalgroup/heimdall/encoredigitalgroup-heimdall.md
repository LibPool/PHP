# encoredigitalgroup/heimdall

> 标签: PHP

## 简介

Heimdall — a Composer plugin that guards the bridge between Packagist and your vendor directory against supply chain attacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
