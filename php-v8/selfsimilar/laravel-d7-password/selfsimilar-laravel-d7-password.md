# selfsimilar/laravel-d7-password

> 标签: drupal, hashing, laravel, password

## 简介

Laravel package that checks and creates Drupal 7 password hashes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
