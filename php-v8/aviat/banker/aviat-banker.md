# aviat/banker

> 标签: cache, memcached, psr-16, psr-6, psr16, psr6, redis

## 简介

A caching library implementing PSR-6 (psr/cache) and PSR-16 (psr/simple-cache)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
