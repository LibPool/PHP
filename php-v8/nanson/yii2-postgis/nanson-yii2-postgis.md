# nanson/yii2-postgis

> 标签: Behavior, extension, postgis, postgre, postgres, postgresql, spatial, yii, yii2

## 简介

Yii2-extension to work with postgis data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
