# joydeep-bhowmik/quire

> 标签: blade, file-based, folio, middleware, pages, router, routing

## 简介

File-based page router for plain PHP: every .php or .blade.php file is a route, with middleware and named routes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
