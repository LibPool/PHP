# mlocati/imap

> 标签: base64, email, imap, mail, mailbox, mailboxes, message, messages, ssl, tls

## 简介

A PHP library to fetch IMAP messages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
