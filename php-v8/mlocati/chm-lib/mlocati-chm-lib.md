# mlocati/chm-lib

> 标签: chm, decompress, extract, help, list, lzx

## 简介

Read CHM (Microsoft Compiled HTML Help) files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
