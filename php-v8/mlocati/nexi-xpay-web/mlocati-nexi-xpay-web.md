# mlocati/nexi-xpay-web

> 标签: gateway, intesa, nexi, payment, x-pay, xpay

## 简介

An unofficial SDK for the Nexi XPay Web payment gateway (Intesa Sanpaolo bank)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
