# mlocati/concrete5-translation-library

> 标签: concrete5, i18n, internationalization, l10n, localization, packages, translate, translation

## 简介

Library to handle concrete5 core and package translations

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
