# scajal/laravel-react-starter-kit

> 标签: filament, inertia, laravel, react, saas, starter-kit, typescript, workos

## 简介

An opinionated, production-minded starter kit for building SaaS apps with Laravel, Inertia and React.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
