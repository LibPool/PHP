# haijin/testing

> 标签: assertions, expectations, phpunit, testing

## 简介

Extensions to PHPUnit to ease testing and improve tests expressiveness.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
