# frolaxhq/laravel-typescript

> 标签: codegen, eloquent, interfaces, laravel, types, typescript

## 简介

Generate TypeScript interfaces from your Laravel Eloquent models

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
