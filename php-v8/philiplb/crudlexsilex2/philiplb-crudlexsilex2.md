# philiplb/crudlexsilex2

> 标签: Admin Generator, crud, silex

## 简介

The Silex 2 implementation for CRUDlex ( https://github.com/philiplb/CRUDlex ).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
