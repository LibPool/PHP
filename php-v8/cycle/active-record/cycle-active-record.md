# cycle/active-record

> 标签: active-record, activerecord, cycle, cycle-orm, database, model, orm

## 简介

Provides a simple way to work with your database using Active Record pattern and Cycle ORM

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
