# williamgall/simpletest

> 标签: SimpleTest, code-coverage, selenium, testing, unit-test

## 简介

SimpleTest is a framework for unit testing, web site testing and mock objects for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
