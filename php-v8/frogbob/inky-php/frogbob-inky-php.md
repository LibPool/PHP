# frogbob/inky-php

> 标签: inky, php, reponsive-emails

## 简介

PHP Implementation of ZURB's Foundation for Email parser - Based on thampe/inky

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
