# edwinhoksberg/slim-framework-skeleton

> 标签: Skeleton, slim, slim framework

## 简介

A skeleton framework with built-in features, made with Slim Framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
