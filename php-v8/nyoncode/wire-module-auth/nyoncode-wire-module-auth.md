# nyoncode/wire-module-auth

> 标签: Authentication, auth, fortify, laravel, livewire, login, nyoncode, two-factor, wire, wirestack

## 简介

The signed-out screens for wire: login, password reset, email verification and the two-factor challenge, over Laravel Fortify.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
