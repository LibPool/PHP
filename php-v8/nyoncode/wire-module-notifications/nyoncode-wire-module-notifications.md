# nyoncode/wire-module-notifications

> 标签: database-notifications, inbox, laravel, livewire, notifications, nyoncode, wire, wirestack

## 简介

Stored notifications for wire: the history behind the bell, as a resource.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
