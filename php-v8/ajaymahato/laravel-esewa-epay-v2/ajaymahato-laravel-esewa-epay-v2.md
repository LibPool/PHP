# ajaymahato/laravel-esewa-epay-v2

> 标签: epay, esewa, laravel, nepal, npr, payment, payment-gateway

## 简介

Production-ready eSewa ePay v2 integration for Laravel 10, 11, 12 and 13: HMAC signing, verified callbacks, status reconciliation and payable models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
