# cap60552/php-sip2

> 标签: PHP

## 简介

PHP class library to facilitate communication with Integrated Library System (ILS) servers via 3M's SIP2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
