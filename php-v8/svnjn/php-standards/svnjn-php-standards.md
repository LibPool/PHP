# svnjn/php-standards

> 标签: PHPStan, Pint, pest, rector, standards, strict

## 简介

Shared strict coding standards, static analysis rules and tooling for svnjn PHP packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
