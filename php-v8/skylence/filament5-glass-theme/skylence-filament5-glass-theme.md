# skylence/filament5-glass-theme

> 标签: clean, corporate, filament, glass, glassmorphism, laravel, modern, theme

## 简介

A modern glassmorphism theme for FilamentPHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
