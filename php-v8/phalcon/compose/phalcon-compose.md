# phalcon/compose

> 标签: Skeleton, boilerplate, compose, docker, phalcon

## 简介

Open-source and community-driven boilerplate for Phalcon projects by using Docker and Docker Compose

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
