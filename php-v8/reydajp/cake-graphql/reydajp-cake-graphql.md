# reydajp/cake-graphql

> 标签: GraphQLite, cakephp, cakephp-plugin, cakephp5, graphql, webonyx

## 简介

GraphQL endpoint plugin for CakePHP 5 using GraphQLite and Webonyx GraphQL PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
