# notorious/bitsharesphp-ws

> 标签: Graphene, altcoins, api, bitcoin, bitshares, crypto, cryptobridge, php, websocket

## 简介

A PHP websocket interface for Bitshares.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
