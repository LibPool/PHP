> 标签: darksky, darksky.net, forecast, forecast.io, weather

## 简介

Drop dead simple DarkSky.net API v2 wrapper in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
