# sirserik/starter-theme

> 标签: PHP

## 简介

Twenty-Twenty-Four-style starter theme for meta/admin-core sites. Layouts, header/footer/modals, error pages, design tokens, Tailwind preset.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
