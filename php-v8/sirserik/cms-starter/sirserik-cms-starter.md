# sirserik/cms-starter

> 标签: admin, cms, headless, laravel, starter

## 简介

Laravel + meta/admin-core + meta/starter-theme skeleton. Ready CMS in one composer create-project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
