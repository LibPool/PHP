# sirserik/admin-core

> 标签: PHP

## 简介

Headless admin panel core for META University sites (Inertia + Vue 3 + Tiptap). Provides base Inertia controllers, Resource API, block library, and reusable Vue components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
