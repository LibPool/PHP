# chiiya/laravel-passes

> 标签: android, apple, chiiya, google, ios, laravel, passes, wallet

## 简介

Laravel library for creating iOS and Android Wallet Passes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
