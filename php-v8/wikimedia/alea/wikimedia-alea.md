# wikimedia/alea

> 标签: PRNG, alea

## 简介

PHP port of the (non-cryptographic) Alea pseudo-random number generator

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.mediawiki.org/wiki/Alea
- 源码仓库：https://github.com/wikimedia/mediawiki-libs-alea.git
- Packagist 页面：https://packagist.org/packages/wikimedia%2Falea
