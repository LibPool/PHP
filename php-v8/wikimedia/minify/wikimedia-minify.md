# wikimedia/minify

> 标签: PHP

## 简介

Minification of JavaScript code and CSS stylesheets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://gerrit.wikimedia.org/g/mediawiki/libs/Minify
- 源码仓库：https://github.com/wikimedia/mediawiki-libs-Minify.git
