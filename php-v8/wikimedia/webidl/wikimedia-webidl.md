# wikimedia/webidl

> 标签: webidl, wikipeg

## 简介

WebIDL parser for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.mediawiki.org/wiki/WebIDL
- 源码仓库：https://github.com/wikimedia/mediawiki-libs-WebIDL.git
