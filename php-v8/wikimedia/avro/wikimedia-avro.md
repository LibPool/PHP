# wikimedia/avro

> 标签: serialization

## 简介

A library for using Apache Avro with PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://avro.apache.org/
- 源码仓库：https://github.com/wikimedia/avro-php.git
- Packagist 页面：https://packagist.org/packages/wikimedia%2Favro

## 获取地址
