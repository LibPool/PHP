# wikimedia/message

> 标签: Wikimedia, message

## 简介

This library provides interfaces and value objects for internationalization (i18n) of applications in PHP, using 'en' as the default language code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
