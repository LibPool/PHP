# sunnybyte/craft-deployments

> 标签: Craft, craft-cloud, craft-plugin, craftcms, deploy, deployment, notifications, webhook

## 简介

Send a configurable webhook after a Craft CMS deployment, from a console command or automatically after Craft Cloud's cloud/up.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
