# aduh95/html-generator

> 标签: dom, generator, html, jquery, php

## 简介

HTML generator in PHP, implementing most of the jQuery DOM manipulation API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
