# teppokoivula/admin-bar

> 标签: module, processwire

## 简介

AdminBar is a ProcessWire CMS/CMF module that provides easy front-end admin bar for editing page content.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
