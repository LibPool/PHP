# teppokoivula/page-render-find-replace

> 标签: module, processwire

## 简介

Page Render Find/Replace is a ProcessWire CMS/CMF module that applies replacements specified via TextformatterFindReplace to rendered page content.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
