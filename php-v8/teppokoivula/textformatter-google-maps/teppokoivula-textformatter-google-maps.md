# teppokoivula/textformatter-google-maps

> 标签: module, processwire

## 简介

ProcessWire CMS/CMF module for converting Google Maps links to embedded maps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
