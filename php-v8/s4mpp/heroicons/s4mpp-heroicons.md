# s4mpp/heroicons

> 标签: PHP

## 简介

Blade components with Heroicons (https://heroicons.com)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 获取地址

- Composer 安装：`composer require s4mpp/heroicons`
- Packagist 仓库：https://repo.packagist.org/p2/s4mpp/heroicons.json
- PHP 要求：>=7.4
