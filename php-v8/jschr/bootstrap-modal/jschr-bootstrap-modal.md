# jschr/bootstrap-modal

> 标签: bootstrap, javascript, modal

## 简介

Extends the default Bootstrap Modal class. Responsive, stackable, ajax and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
