# kaninstein/laravel-pagarme

> 标签: abecs, boleto, brazil, credit-card, debit-card, gateway, laravel, pagar.me, pagarme, payment, payment-gateway, pix, voucher

## 简介

Complete integration with Pagar.me payment gateway (API v5) for Laravel. Supports all payment methods: Credit/Debit Card, PIX, Boleto, Voucher. Includes ABECS codes mapping and complete test simulators.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
