# httpsoft/http-server-request

> 标签: http, http-message, http-server-request, php, psr-7

## 简介

Infrastructure for creating PSR-7 ServerRequest and UploadedFile

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
