# arcp/sdk

> 标签: Agent, arcp, protocol, runtime, stdio, websocket

## 简介

PHP reference implementation of the Agent Runtime Control Protocol (ARCP) v1.1

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
