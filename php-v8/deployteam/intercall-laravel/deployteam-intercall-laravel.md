# deployteam/intercall-laravel

> 标签: communication, inter-system, intercall, laravel, messagepack, microservices, redis

## 简介

Laravel adapter for Intercall - event-based inter-system communication

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
