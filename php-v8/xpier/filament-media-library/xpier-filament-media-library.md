# xpier/filament-media-library

> 标签: admin-panel, filament, filament-plugin, laravel, media-library, media-manager, media-picker

## 简介

A Filament-native media library with folder browser, inline upload, soft deletes, and a drop-in MediaPicker form field.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
