# onekb/chat-gpt

> 标签: ChatGpt, chat-gpt, chatbot

## 简介

ChatGPT for PHP，和简易终端实现。NOT GPT-3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
