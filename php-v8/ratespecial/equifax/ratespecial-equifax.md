# ratespecial/equifax

> 标签: equifax luminate, equifax open banking, equifax sdk, equifax xml2 consumer

## 简介

SDK to access Equifax Luminate, XML2 Consumer, and Opening Banking

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
