# fortytwo/php-sdk-core

> 标签: fortytwo

## 简介

Fortytwo’s Core SDK. Used as base for all the Fortytwo PHP SDKs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
