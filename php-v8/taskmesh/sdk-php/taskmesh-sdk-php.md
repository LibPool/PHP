# taskmesh/sdk-php

> 标签: cron, sdk, task-mesh, taskmesh, tracking, worker

## 简介

Task Mesh Worker 埋点 SDK，用于向 Task Mesh 上报 runStart / runFinish / event

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
