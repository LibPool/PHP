# orkan/tlc

> 标签: Scrap, crawler, curl, flaresolverr, net

## 简介

Simple PHP/cURL (T)ransport framework with (L)ogger, (C)ache and more!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
