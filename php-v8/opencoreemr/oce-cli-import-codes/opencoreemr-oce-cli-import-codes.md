# opencoreemr/oce-cli-import-codes

> 标签: ICD, cli, codes, cqm, healthcare, medical, openemr, rxnorm, snomed

## 简介

OpenEMR CLI tool for importing standardized code tables (RXNORM, SNOMED, ICD, CQM_VALUESET), by OpenCoreEMR Inc

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
