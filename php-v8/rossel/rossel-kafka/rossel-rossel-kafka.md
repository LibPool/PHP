# rossel/rossel-kafka

> 标签: PHP

## 简介

A ready-to-use PHP library for seamless communication with Rossel's Kafka infrastructure, handling both production and consumption of messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
