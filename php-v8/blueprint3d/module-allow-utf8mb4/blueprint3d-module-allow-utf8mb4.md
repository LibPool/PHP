# blueprint3d/module-allow-utf8mb4

> 标签: PHP

## 简介

Unlocks full UTF8MB4 database support for Magento 2 (Emojis and 4-byte characters)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
