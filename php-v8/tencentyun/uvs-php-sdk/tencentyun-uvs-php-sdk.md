# tencentyun/uvs-php-sdk

> 标签: qcloud, sdk, tencentyun

## 简介

php sdk for www.qcloud.com uvs service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.qcloud.com/
- 源码仓库：https://github.com/tencentyun/uvs-php-sdk.git
- Packagist 页面：https://packagist.org/packages/tencentyun%2Fuvs-php-sdk
