# diablomedia/phpunit-pretty-printer

> 标签: phpunit, printer, result, test, unit

## 简介

A PHPUnit result printer that shows per-file test progress and execution times

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
