# nhaynes/jira-sdk-php

> 标签: api, atlassian, client, issues, janephp, jira, jiraapi, openapi, sdk, tickets

## 简介

Jira SDK generated using janephp from the Jira Cloud OpenAPI spec.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
