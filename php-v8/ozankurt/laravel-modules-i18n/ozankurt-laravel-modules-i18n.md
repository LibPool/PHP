# ozankurt/laravel-modules-i18n

> 标签: i18n, kurtmodules, laravel, localization, translations

## 简介

Self-hosted translation-file manager for Laravel — edit JSON and PHP array lang files (including deeply nested keys) through a Tailwind UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
