# ozankurt/laravel-modules-resource-library

> 标签: filament, knowledge-base, kurtmodules, laravel, library, resources

## 简介

SaaS resource library: nested folders with per-folder permissions, versioned items (video link, file, document, URL).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
