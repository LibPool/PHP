# ozankurt/laravel-modules-forum

> 标签: community, filament, forum, kurtmodules, laravel, moderation

## 简介

Community forum for Laravel: boards, threads, replies, voting, moderation, subscriptions, badges.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
