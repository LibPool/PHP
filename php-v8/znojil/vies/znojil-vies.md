# znojil/vies

> 标签: api, client, eu, vat, vat number, vat validation, vies

## 简介

🧾 A simple and modern PHP library for communicating with the EU VIES VAT number validation service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
