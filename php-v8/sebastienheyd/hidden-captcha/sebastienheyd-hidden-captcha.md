# sebastienheyd/hidden-captcha

> 标签: captcha, hidden, invisible, laravel

## 简介

Fully hidden captcha for Laravel without reCaptcha

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
