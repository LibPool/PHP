# gtfs-media/gtfs-realtime-php

> 标签: gtfs, gtfs-realtime, gtfs-rt, protobuf, realtime, service-alerts, transit, trip-updates, vehicle-positions

## 简介

GTFS Realtime protobuf bindings for PHP, generated from the official specification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
