# abublihi/laravel-external-jwt-guard

> 标签: abublihi, laravel-external-jwt-guard

## 简介

It's a laravel custom auth guard for authenticating users using External JWT

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
