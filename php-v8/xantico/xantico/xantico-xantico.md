# xantico/xantico

> 标签: View Model, bootstrap

## 简介

A PHP helper to build Bootstrap compatible html code automatically using OOP syntax.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
