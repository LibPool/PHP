# riesenia/cakephp-duplicatable

> 标签: cakephp, copy, duplicate, orm

## 简介

CakePHP ORM plugin for duplicating entities (including related entities)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
