# rma/rmabdd_light

> 标签: bundle, database, dump, mysql

## 简介

Bundle pour gérer des extract de base de données en ligne de commande ou CRON

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
