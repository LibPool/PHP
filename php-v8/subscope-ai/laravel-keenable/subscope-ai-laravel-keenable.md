# subscope-ai/laravel-keenable

> 标签: agents, ai, fetch, keenable, laravel, laravel-ai, search, search-api, web-search 

## 简介

Laravel client for the Keenable search & fetch API, with tools for Laravel AI agents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
