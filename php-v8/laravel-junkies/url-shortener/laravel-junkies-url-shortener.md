# laravel-junkies/url-shortener

> 标签: shortener, tobymaxham, url, ux9

## 简介

The official UX9 URL Shortener API for Laravel Users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
