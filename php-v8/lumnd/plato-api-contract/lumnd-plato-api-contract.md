# lumnd/plato-api-contract

> 标签: api, api-generator, code-generation, contract-first, dto, openapi, openapi-generator, php, php-framework, platophp

## 简介

Contract-first API generator for PHP controllers, Logic skeletons and OpenAPI 3.1

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
