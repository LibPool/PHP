# ryangjchandler/laravel-bunny-fonts

> 标签: laravel, laravel-bunny-fonts, ryan chandler

## 简介

Manage Bunny Fonts programatically in your Laravel projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
