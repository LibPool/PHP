# ryangjchandler/laravel-json-settings

> 标签: laravel, laravel-json-settings, ryangjchandler

## 简介

Store your Laravel application settings in an on-disk JSON file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
