# eduplus/qr

> 标签: PHP

## 简介

Laravel package for QR Code and Barcode generation using EduplusQR and EduplusBarcode with configurable binary paths.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
