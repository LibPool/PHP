# eduplus/cdn

> 标签: Flysystem, cdn, eduplus, laravel, storage

## 简介

Laravel Storage driver and standalone PHP client for mdscdn

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
