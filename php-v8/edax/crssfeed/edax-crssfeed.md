# edax/crssfeed

> 标签: SimplePie, feed, rss

## 简介

CRssFeed is SimplePie wrapper-class for generating objects that can be used to render a RSS feed

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
