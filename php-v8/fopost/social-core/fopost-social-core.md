# fopost/social-core

> 标签: content-syndication, facebook, fopost, publishing, social-media, telegram, twitter, x

## 简介

Framework-agnostic PHP core for FoPost: content publishing and synchronization engine for social media platforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
