# mediarox/module-billiger-de-tracking-pixel

> 标签: PHP

## 简介

This extension for Magento >=2.4 implements a billiger.de tracking pixel on checkout success page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
