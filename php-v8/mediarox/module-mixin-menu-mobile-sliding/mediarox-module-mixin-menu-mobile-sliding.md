# mediarox/module-mixin-menu-mobile-sliding

> 标签: PHP

## 简介

A javascript mixin to replace the "collapse" of submenus with a "slide" effect

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
