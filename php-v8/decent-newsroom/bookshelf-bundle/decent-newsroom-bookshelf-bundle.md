# decent-newsroom/bookshelf-bundle

> 标签: PHP

## 简介

Reusable Symfony bundle for a Nostr-based bookshelf and e-reader backed by the Decent Newsroom Books API with Mercury fallback

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
