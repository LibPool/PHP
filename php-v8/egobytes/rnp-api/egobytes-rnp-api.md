# egobytes/rnp-api

> 标签: api, costa-rica, placa, registro-nacional, vehiculos, vin

## 简介

Cliente PHP del API de consulta vehicular del Registro Nacional de Costa Rica.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
