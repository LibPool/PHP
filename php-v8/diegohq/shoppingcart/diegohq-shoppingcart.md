# diegohq/shoppingcart

> 标签: laravel, shoppingcart

## 简介

Laravel Shoppingcart. Added support to Laravel 5.7 while original doesn't.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
