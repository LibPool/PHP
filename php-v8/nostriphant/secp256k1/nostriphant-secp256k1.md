# nostriphant/secp256k1

> 标签: PHP

## 简介

Wrapper around 1ma/secp256k1-nostr extension, falls back to simplito/elliptic (pure PHP implementation) when the extension is not available

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
