# danielbbarcelos/laravel-bancos

> 标签: bacen, bancos, boleto, c6, laravel, pagamentos, pix, sicredi

## 简介

Integração com bancos brasileiros (Pix, boleto, pagamentos, conciliação) sob um contrato único, com drivers por banco.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
