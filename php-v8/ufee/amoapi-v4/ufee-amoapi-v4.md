# ufee/amoapi-v4

> 标签: amoCRM, api, client, integration, kommo, oauth, php, sdk

## 简介

PHP API client for amoCRM/Kommo (v4) with OAuth, caching, pagination and events

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
