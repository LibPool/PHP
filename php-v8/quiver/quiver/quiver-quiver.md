# quiver/quiver

> 标签: framework

## 简介

The Quiver PHP framework. A lite extension of a thin HTTP library that gives you the freedom to write and organize PHP applications however you like.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
