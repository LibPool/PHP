# xrdebug/laravel

> 标签: PHP

## 简介

Laravel client for xrDebug

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://xrdebug.com
- 源码仓库：https://github.com/xrdebug/laravel.git
- Packagist 页面：https://packagist.org/packages/xrdebug%2Flaravel

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require xrdebug/laravel`
- Packagist 仓库：https://repo.packagist.org/p2/xrdebug/laravel.json
- 许可证：Apache-2.0
- PHP 要求：^8.2
