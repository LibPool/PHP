# xsanz/magento2-module-admin-color-captcha

> 标签: PHP

## 简介

Magento 2 admin image CAPTCHA with optional per-character colors and grayscale noise (XavierSanz_ColorCaptcha).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
