# bgaze/laravel-kvstore

> 标签: Settings, cache, casting, key-value, laravel, options, store

## 简介

Database-backed key-value store for Laravel, cached and with per-entry type casting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
