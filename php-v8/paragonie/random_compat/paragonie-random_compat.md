# paragonie/random_compat

> 标签: csprng, polyfill, pseudorandom, random, 兼容, 随机数

## 简介

PHP 5.x polyfill for random_bytes() and random_int() from PHP 7

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
