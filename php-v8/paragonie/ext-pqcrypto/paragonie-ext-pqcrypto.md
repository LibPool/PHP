# paragonie/ext-pqcrypto

> 标签: cryptography, ml-dsa, ml-kem, post-quantum, pqc, slh-dsa, x-wing

## 简介

PHP extension for post-quantum cryptography (ML-KEM, X-Wing, ML-DSA, SLH-DSA)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
