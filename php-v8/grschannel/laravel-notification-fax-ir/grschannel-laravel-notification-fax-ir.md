# grschannel/laravel-notification-fax-ir

> 标签: fax, fax notification, fax notifications channel, fax php, fax.ir, laravel, notification

## 简介

You can use this Package to send fax notifications using www.fax.ir

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
