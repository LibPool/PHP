# templatefox/sdk

> 标签: api, document-generation, html-to-pdf, invoice, pdf, pdf-api, pdf-generation, pdf-template, report, sdk, template, templatefox

## 简介

Official TemplateFox PHP SDK - Generate PDFs from HTML templates

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
