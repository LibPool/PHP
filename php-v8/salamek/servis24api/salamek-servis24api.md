# salamek/servis24api

> 标签: api, servis24.cz, transactions

## 简介

API for servis24.cz using servis24.cz as source of data (parsing loaded HTML).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
