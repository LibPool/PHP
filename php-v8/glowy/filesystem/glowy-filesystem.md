# glowy/filesystem

> 标签: filesystem, glowy, glowyphp, php, php-filesystem

## 简介

Filesystem Component provide a fluent, object-oriented interface for working with filesystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
