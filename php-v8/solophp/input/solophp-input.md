# solophp/input

> 标签: dto, immutable, input, mapping, php, php8, psr-7, request, strict-types, validation

## 简介

Typed, validated input DTOs for PHP 8.3+: immutable classes built through their constructor from HTTP input, with attribute-driven validation, casting and processing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
