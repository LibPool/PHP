# solophp/dotenv

> 标签: dotenv, env, php, php8, psr, strict-types

## 简介

Simple, zero-dependency .env loader for PHP. Loads files into $_ENV with optional $_SERVER population.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
