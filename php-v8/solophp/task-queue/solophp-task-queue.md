# solophp/task-queue

> 标签: Tasks, async, jobs, php, queue, scheduler

## 简介

Enhanced PHP task queue using Solo Database with retry mechanism and task expiration support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
