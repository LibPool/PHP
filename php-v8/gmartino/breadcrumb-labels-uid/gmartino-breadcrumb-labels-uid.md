# gmartino/breadcrumb-labels-uid

> 标签: TYPO3 CMS, backend, breadcrumb

## 简介

Restores the pre-v14 backend behaviour of appending the record uid to breadcrumb labels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
