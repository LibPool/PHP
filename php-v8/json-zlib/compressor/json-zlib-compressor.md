# json-zlib/compressor

> 标签: compress, decompress, deflate, inflate, json, zip, zlib

## 简介

A library to (de-)compress JSON strings using `zlib`.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
