# vs-point/kb-adaa

> 标签: Banking, account-direct-access, adaa, api, kb, komercni-banka, open-banking

## 简介

A PHP library for communication with the Komerční banka Account Direct Access (ADAA) API v2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
