# vs-point/moneys3

> 标签: Accounting, api, graphql, money, moneys3, seyfor, ucetnictvi

## 简介

A strictly typed PHP library for communication with the Money S3 accounting software via its GraphQL API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
