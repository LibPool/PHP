# wayaquick/payment-sdk

> 标签: Nigeria, bvn, collect, fintech, payments, payout, wayapay, wayaquick

## 简介

PHP client for the WayaPay Merchant API v2: collect, payout, accounts, identity, transactions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
