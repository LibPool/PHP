# dykhuizen/laravel-datatable

> 标签: filtering, laravel, paginating, searching, selecting, sorting

## 简介

A Laravel package that contains queries for constructing a datatable

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
