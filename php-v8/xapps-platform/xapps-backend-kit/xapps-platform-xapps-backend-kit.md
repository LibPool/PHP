# xapps-platform/xapps-backend-kit

> 标签: PHP

## 简介

Modular PHP backend kit for the current Xapps backend contract (tenant surface today, shared actor-adapter direction later)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
