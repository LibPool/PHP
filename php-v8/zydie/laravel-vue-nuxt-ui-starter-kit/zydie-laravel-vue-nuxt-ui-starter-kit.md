# zydie/laravel-vue-nuxt-ui-starter-kit

> 标签: framework, laravel

## 简介

Laravel 13 Starter Kit with Inertia.js, Vue 3, TypeScript, Tailwind CSS v4, Nuxt UI, and Wayfinder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
