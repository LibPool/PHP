# satoken/webman

> 标签: auth, middleware, permission, sa-token, webman

## 简介

Sa-Token PHP webman 集成包 - 为 webman 提供开箱即用的权限认证

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
