# satoken/satoken

> 标签: Authentication, auth, laravel, permission, rbac, sa-token, thinkphp, webman

## 简介

Sa-Token PHP 核心包 - 轻量级 PHP 权限认证框架（Java Sa-Token 1:1 复刻，框架无关）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
