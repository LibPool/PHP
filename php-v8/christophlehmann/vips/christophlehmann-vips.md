# christophlehmann/vips

> 标签: imageprocessing, libvips, performance

## 简介

Faster and less memory hungry thumbnail generation for TYPO3 with vips php module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
