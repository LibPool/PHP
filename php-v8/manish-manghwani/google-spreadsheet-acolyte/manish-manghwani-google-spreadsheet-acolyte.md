# manish-manghwani/google-spreadsheet-acolyte

> 标签: google-spreadsheet-acolyte, manish-manghwani

## 简介

Package to insert data from google spreadheet into database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
