# ephpicman/boolean-utility

> 标签: boolean, logic, php, utility

## 简介

A comprehensive Boolean utility for PHP, supporting logical operations, counting, and majority evaluation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
