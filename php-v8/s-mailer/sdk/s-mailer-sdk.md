# s-mailer/sdk

> 标签: api, email, messaging, s-mailer, sdk, sms, whatsapp

## 简介

PHP SDK for the S-Mailer API — send messages, manage webhooks, and more

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
