# anik/mercure

> 标签: Broadcasting, Server-Sent Events, broadcaster, dunglas-mercure, events, laravel, laravel-mercure, lumen, lumen-mercure, mercure, notifications, php-mercure, protocol, sse

## 简介

dunglas/mercure publisher implementation for any PHP-based application. Publish messages to the Mercure hub with Laravel Event Broadcasting & Laravel Notifications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
