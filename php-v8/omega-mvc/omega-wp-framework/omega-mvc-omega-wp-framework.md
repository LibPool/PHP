# omega-mvc/omega-wp-framework

> 标签: PHP

## 简介

Omega WP Framework is a framework for creating WordPress plugins. It includes support for Database, Controllers, Validator, Routes, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
