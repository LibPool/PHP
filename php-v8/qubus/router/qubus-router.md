# qubus/router

> 标签: URL Routing, psr-15, psr-7, router, routing

## 简介

Qubus Router is a powerful and fast PHP router for PSR-7/PSR-15 messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
