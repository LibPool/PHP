# fiunchinho/phpunit-randomizer

> 标签: phpunit, testing, unit testing

## 简介

Execute your test cases in random order, so you can check if they have hidden dependencies

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
