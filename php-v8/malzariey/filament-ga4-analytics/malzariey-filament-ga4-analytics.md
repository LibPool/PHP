# malzariey/filament-ga4-analytics

> 标签: Malzariey, filament, filament-ga4-analytics, ga4, google-analytics, laravel

## 简介

A Google Analytics 4 reports page for Filament panels: live visitors, KPIs, funnel, events, breakdowns and traffic sources, read through the GA4 Data API with a read-only service account.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
