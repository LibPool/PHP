# featureflip/featureflip-openfeature

> 标签: feature-flags, feature-toggles, openfeature, sdk

## 简介

OpenFeature provider for Featureflip, backed by the Featureflip PHP SDK

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
