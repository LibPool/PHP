# tnt-framework/core

> 标签: PHP

## 简介

Simple, superfast and resource-light PHP framework for older servers, PSR-aware custom router, custom DI container and logger

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
