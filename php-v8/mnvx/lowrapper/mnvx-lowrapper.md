# mnvx/lowrapper

> 标签: LibreOffice, converter, docx, excel, pdf, word, xls, xlsx

## 简介

PHP wrapper over LibreOffice converter

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
