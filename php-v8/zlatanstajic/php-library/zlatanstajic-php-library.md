# zlatanstajic/php-library

> 标签: OOP, library, php, php-library

## 简介

A reusable collection of lightweight PHP components for validation, files, spreadsheets, HTTP services, databases, and other common web-development tasks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
