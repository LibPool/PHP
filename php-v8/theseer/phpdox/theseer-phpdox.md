# theseer/phpdox

> 标签: PHP

## 简介

A fast Documentation generator for PHP Code using standard technology (SRC, DOCBLOCK, XML and XSLT) with event based processing

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
