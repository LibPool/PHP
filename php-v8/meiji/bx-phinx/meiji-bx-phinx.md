# meiji/bx-phinx

> 标签: bitrix, database, database migrations, db, migrations, phinx

## 简介

Bitrix Adapter for Phinx Database Migrations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
