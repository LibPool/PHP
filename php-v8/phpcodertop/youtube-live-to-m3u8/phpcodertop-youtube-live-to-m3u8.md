# phpcodertop/youtube-live-to-m3u8

> 标签: download, laravel, m3u8, youtube

## 简介

Package for converting live YouTube videos into m3u8 file and downloading it .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
