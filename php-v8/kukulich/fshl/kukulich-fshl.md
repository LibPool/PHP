# kukulich/fshl

> 标签: highlight, library, syntax

## 简介

FSHL is a free, open source, universal, fast syntax highlighter written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
