# asmaa-gamal/laravel-meta-messaging

> 标签: Messenger, chatbot, facebook, graph-api, instagram, laravel, messaging, meta, send-api

## 简介

Send Facebook Messenger and Instagram messages from Laravel — every message type, with pre-flight validation and clear, structured errors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
