# woodfish/tntsearch-chinese

> 标签: fulltext, search, teamtnt, tntsearch

## 简介

A fully featured full text search engine written in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
