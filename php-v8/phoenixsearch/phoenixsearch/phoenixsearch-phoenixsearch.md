# phoenixsearch/phoenixsearch

> 标签: PHP

## 简介

PhoenixSearch is a fast and modern full-text real-time search engine based on Redis + PHP7

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
