# toanchet/toanchetpay-sdk

> 标签: cambodia, gateway, khqr, mpgs, payment, toanchet, toanchetpay

## 简介

ToanchetPay Payment Gateway SDK for PHP — supports all payment types: standard, MPGS, KHQR, POS, mobile deeplink.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
