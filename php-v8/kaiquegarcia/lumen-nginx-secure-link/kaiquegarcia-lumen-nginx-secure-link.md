# kaiquegarcia/lumen-nginx-secure-link

> 标签: PHP

## 简介

Trait to easily adapt a Lumen/Laravel project for using NGINX secure link

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
