# swivl/php-coding-standard

> 标签: Coding Standard, Swivl, phpcs, symfony

## 简介

Swivl Coding Standard for PHP_CodeSniffer

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
