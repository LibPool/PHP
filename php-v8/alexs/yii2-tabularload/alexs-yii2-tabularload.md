# alexs/yii2-tabularload

> 标签: loading models, tabular forms, yii 2, yii2

## 简介

A simple extension for complex forms have a tabular input for Yii2 Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
