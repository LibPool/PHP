# rcdesign/rcgallery

> 标签: PHP

## 简介

Simple TYPO3 Gallery with a list preview and a creation date

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/chrcan/rcgallery.git
