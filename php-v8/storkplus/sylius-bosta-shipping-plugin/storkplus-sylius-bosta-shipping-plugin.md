# storkplus/sylius-bosta-shipping-plugin

> 标签: Egypt, bosta, cod, shipping, sylius, sylius-plugin

## 简介

Bosta (Egypt) shipping for Sylius: shipping calculator, automatic delivery creation, webhooks, tracking and retries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
