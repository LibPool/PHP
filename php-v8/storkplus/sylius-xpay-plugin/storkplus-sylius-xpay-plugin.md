# storkplus/sylius-xpay-plugin

> 标签: Egypt, fawry, payment, sylius, sylius-plugin, valu, xpay

## 简介

XPay (Egypt) payment gateway for Sylius: hosted checkout, signed webhooks, refunds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
