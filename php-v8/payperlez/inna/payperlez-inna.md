# payperlez/inna

> 标签: Inna, Inna framework, Inna php framework, do it yourself, framework, payperlez php framework

## 简介

A PHP minimal framework which allows you to control every bit of it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
