# oceanmoon/core

> 标签: arrays, comparable, equatable, floats, ieee-754, integers, math, numbers, php, stringify, traits, types, utilities

## 简介

Core PHP utilities for floats, integers, arrays, types, and string conversion with IEEE-754 support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
