# mdcass/support

> 标签: PHP

## 简介

A set of helpers and classes to aid with package development within Laravel. Inspired by Laravel's Eloquent Model functionality amongst other things.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
