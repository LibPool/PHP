# pmjones/php-styler

> 标签: beautifier, beautify, code, coding, format, formatter, guide, parser, php, standard, style, styler

## 简介

Companion to PHP-Parser that rebuilds PHP code from AST.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
