# pmjones/caplet

> 标签: container, dependency, dependency injection, di, injection, inversion of control, ioc

## 简介

A minimal PSR-11 compliant autowiring dependency injection container.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
