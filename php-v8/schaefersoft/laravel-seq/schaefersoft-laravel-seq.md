# schaefersoft/laravel-seq

> 标签: Datalust, clef, laravel, logging, monolog, seq, structured-logging

## 简介

Structured logging to Seq for Laravel. Ships batched CLEF events after the response is sent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
