# romaricdrigon/fastimage

> 标签: PHP

## 简介

Finds the size and type of a remote image by fetching as little as needed. PHP port of Ruby fastImage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
