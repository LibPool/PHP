# brandonkal/phpcs-neutron-refined

> 标签: PHP

## 简介

A base ruleset for EventsMadeLive projects. Based heavily on the Neutron Ruleset by Automattic

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
