# sinfonie/multi_array_viewer

> 标签: PHP

## 简介

Library that enables displaying data in the form of a table. Own and external data filtering and sorting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
