# coding-socks/laravel-chunk-uploader

> 标签: PHP

## 简介

This package helps integrate a Laravel application with chunk uploader libraries eg. DropzoneJS and Resumable.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
