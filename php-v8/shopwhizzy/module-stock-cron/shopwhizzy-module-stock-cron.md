# shopwhizzy/module-stock-cron

> 标签: PHP

## 简介

Scheduled stock (qty / is_in_stock) import from a nightly CSV drop, with duplicate-file protection, targeted reindex and cache invalidation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
