# falak/apm-laravel

> 标签: apm, falak, laravel, observability, opentelemetry, otlp

## 简介

Falak APM for Laravel: Nightwatch-style request, query, job, cache, mail, notification, command, schedule, exception and log telemetry exported as OTLP/HTTP JSON to the local falak-agent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
