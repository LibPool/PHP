# libertyphp/libertyphp

> 标签: MVC Framework, fast framework, framework, micro framework, php

## 简介

The Liberty PHP framework. Fast and extensible micro framework for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
