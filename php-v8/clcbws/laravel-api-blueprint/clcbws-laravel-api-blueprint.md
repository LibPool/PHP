# clcbws/laravel-api-blueprint

> 标签: PHP

## 简介

Zero-dependency automatic Laravel API route documentation, TypeScript/Swift/Java/Dart/Go schema, and Postman exporter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
