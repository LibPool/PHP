# phdomiciano/tripsmanager

> 标签: crud, framework, laravel, tripslist, tripsmanager

## 简介

This is a simple CRUD of races list with Laravel and that use the transactions by JSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
