# phdomiciano/phcodemvc

> 标签: courses, courseslist, crud, framework, mvc

## 简介

This is a simple CRUD of courses list with MVC but without Frameworks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
