# matronator/mtrgen

> 标签: file generation, file generator, file templates, generator, json-templates, neon, php-generator, yaml-templates

## 简介

PHP file generator engine for generating files from templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
