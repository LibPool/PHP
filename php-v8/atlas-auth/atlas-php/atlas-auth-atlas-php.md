# atlas-auth/atlas-php

> 标签: Authentication, SSO, atlas, auth, authorization, jwt, sdk

## 简介

Official PHP backend SDK for Atlas — the secret-key Backend API client plus session-token/JWT verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
