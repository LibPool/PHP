# katzen48/laravel-twitch-eventsub

> 标签: PHP

## 简介

This package provides support for subscribing to Twitch EventSub. It's based on laravel-twitch and fully compatible.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
