# friendsoftypo3/fontawesome-provider

> 标签: PHP

## 简介

Integrates legacy FontawesomeIconProvider and FontAwesome 4.7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
