# friendsoftypo3/frontend-editing

> 标签: TYPO3 CMS, frontend editing

## 简介

Enable editors to work with the content in the most intuitive way possible

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
