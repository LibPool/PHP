# oliverearl/martian-time

> 标签: carbon, mars, mars24, martian, time

## 简介

Dependency-free Martian solar time calculations based on the NASA Mars24 algorithm, with optional Carbon integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
