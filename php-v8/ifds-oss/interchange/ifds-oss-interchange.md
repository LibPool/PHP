# ifds-oss/interchange

> 标签: circuit-breaker, http, http-client, laravel, resilience, retry

## 简介

Driver-based outbound HTTP integration layer for Laravel: fluent client builder, retry/backoff, circuit breaking, lifecycle events, config-driven driver registration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
