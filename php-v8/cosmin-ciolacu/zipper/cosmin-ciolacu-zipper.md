# cosmin-ciolacu/zipper

> 标签: zip, zipper, zipper-library, zipper-php

## 简介

A simple zip utility for creating zip files and extracting items to a specific path

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
