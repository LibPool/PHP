# power-modules/dependency-graph-mermaid

> 标签: analysis, architecture, dependency-graph, dependency-visualizer, encapsulation, framework, mermaid, modular, module-dependencies, php, power-modules, visualization

## 简介

Mermaid renderer plugin for power-modules/dependency-graph (flowchart, class diagram, timeline)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
