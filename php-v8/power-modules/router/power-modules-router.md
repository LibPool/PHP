# power-modules/router

> 标签: component-based, dependency-injection, di-container, encapsulation, framework, http-routing, middleware, modular, modular-architecture, power-modules, router, routing

## 简介

A modular router component for the Power Modules framework with encapsulated routing capabilities and explicit module integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
