# power-modules/dependency-graph

> 标签: analysis, architecture, dependency-graph, dependency-visualizer, encapsulation, framework, modular, module-dependencies, php, power-modules, visualization

## 简介

A modular dependency graph tool for PHP applications using the Power Modules framework. Visualizes and analyzes encapsulated module dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
