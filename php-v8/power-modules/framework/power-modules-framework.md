# power-modules/framework

> 标签: component-based, dependency-injection, di-container, ecosystem, encapsulation, framework, microservices, modular, modular-architecture, plugin-system, power-modules, powermodulesetup

## 简介

Framework for building modular PHP applications and plugin ecosystems with encapsulated modules and PowerModuleSetup extensions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
