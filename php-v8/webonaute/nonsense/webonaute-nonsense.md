# webonaute/nonsense

> 标签: PHP

## 简介

Nonsense Generator allows you to display sentences or paragraphs of nonsensical, but syntactically correct sentences.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
