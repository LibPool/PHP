# melakudemeke/kenat-php

> 标签: abushakir, amharic calendar, bahire hasab, calendar, calendar converter, date, date converter, ethiopian, ethiopian calendar, ethiopian date, ethiopian holidays, geez calendar, habesha, kenat, time, zemen

## 简介

A modern PHP library for the Ethiopian calendar: date conversion, formatting, arithmetic, calendar grids, and a full Bahire Hasab implementation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
