# springbokagency/faker-xpdo-orm-adapter

> 标签: faker, modx, xpdo

## 简介

A Faker ORM adapter to populate xPDO objects with fake data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
