# helpvox/sdk

> 标签: helpvox, oauth, opencart, voice agent, webhooks, woocommerce

## 简介

Official PHP SDK for the HelpVox app platform: OAuth install, REST API, signed events, agent tools and dashboard session tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
