# microweber-deps/filament-modules

> 标签: FilamentModules, coolsam, filament, laravel

## 简介

Organize your Filament Code into modules using nwidart/laravel-modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
