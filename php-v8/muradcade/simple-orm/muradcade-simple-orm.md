# muradcade/simple-orm

> 标签: PHP

## 简介

A lightweight, maintainable PHP ORM for modern CRUD operations. Easy to use, secure, and framework-agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
