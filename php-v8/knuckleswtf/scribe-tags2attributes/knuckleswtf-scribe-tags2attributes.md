# knuckleswtf/scribe-tags2attributes

> 标签: Scribe, api, documentation, laravel

## 简介

Automatically convert most Scribe v3 docblock tags to v4 PHP 8 attributes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
