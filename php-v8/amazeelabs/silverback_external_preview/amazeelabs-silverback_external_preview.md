# amazeelabs/silverback_external_preview

> 标签: PHP

## 简介

Provides a UI to preview pages (published and draft) on external websites - usually a Gatsby or NextJS frontend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
