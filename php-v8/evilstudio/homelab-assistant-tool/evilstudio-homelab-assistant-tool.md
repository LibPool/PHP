# evilstudio/homelab-assistant-tool

> 标签: assistant, helper, homelab, tool

## 简介

Homelab operations tool: CLI and web UI for devices, UPS units, schedules, and action logs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
