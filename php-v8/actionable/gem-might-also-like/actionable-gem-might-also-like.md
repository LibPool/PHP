# actionable/gem-might-also-like

> 标签: PHP

## 简介

Pull in recent blog posts from Actionable public websites to make a 'You Might Also Like' widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
