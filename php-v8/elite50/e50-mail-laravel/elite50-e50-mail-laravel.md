# elite50/e50-mail-laravel

> 标签: facade, laravel, mail, mailgun

## 简介

Laravel email facade with support for multiple Mailgun domains.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
