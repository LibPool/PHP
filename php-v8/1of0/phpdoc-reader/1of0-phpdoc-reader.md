# 1of0/phpdoc-reader

> 标签: phpdoc, reflection

## 简介

PhpDocReader parses @var and @param values in PHP docblocks (supports namespaced class names with the same resolution rules as PHP)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
