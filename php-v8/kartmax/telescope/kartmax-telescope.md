# kartmax/telescope

> 标签: debugging, laravel, monitoring, s3, s3 logs

## 简介

A fork of Laravel Telescope fine tuned for KartmaX

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
