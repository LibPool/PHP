# 1naturalway/laravel-sms

> 标签: laravel, messaging, sms, twilio

## 简介

A driver-based SMS abstraction layer for Laravel, following the MailManager pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
