# dasann/kubernetes-client

> 标签: cluster, container, docker, kubernetes

## 简介

A simple yet elegant client for accessing and controlling a Kubernetes cluster.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
