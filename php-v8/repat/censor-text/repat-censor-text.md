# repat/censor-text

> 标签: address, addresses, censor, email, expression, laravel, regex, regular, text

## 简介

Help search and replace specific texts, such as email address(es).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
