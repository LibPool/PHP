# repat/laravel-mysql-enum-values

> 标签: enum, laravel, macro, mysql, repat, valid, values

## 简介

Small Laravel Query Builder Macro that returns valid values for a MySQL ENUM

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
