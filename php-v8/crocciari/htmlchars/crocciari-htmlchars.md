# crocciari/htmlchars

> 标签: Caracteres, CeuAzulCode, Crocciari, Especiais, html, specialchars

## 简介

The HtmlChars class converts letters and numbers into their respective HTML entities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
