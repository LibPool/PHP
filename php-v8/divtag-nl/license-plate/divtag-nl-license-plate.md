# divtag-nl/license-plate

> 标签: License plate, php

## 简介

PHP library to validate and format license plate numbers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/divtag-nl/license-plate.git
- Packagist 页面：https://packagist.org/packages/divtag-nl%2Flicense-plate
