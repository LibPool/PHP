# rodrigopedra/laravel-versionable

> 标签: history, laravel, model, restore, version

## 简介

Allows to create Laravel 5.6 and 6.0 Model versioning and restoring

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
