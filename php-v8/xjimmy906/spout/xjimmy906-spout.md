# xjimmy906/spout

> 标签: PHP

## 简介

基于box/spout的一个快速读写excel文件(csx,xlsx and ods)的php库(详细文档:https://opensource.box.com/spout/)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
