> 标签: API-Client, bot, bot-framework, chatbot, laravel, long-polling, max, max messenger, max-bot-api, php, psr-18, sdk, symfony, webhook

## 简介

PHP SDK for the Max messenger Bot API: typed API client, bot framework, webhooks, long polling, Laravel and Symfony integrations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
