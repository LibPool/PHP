# olix/backoffice-bundle

> 标签: admin, back office, back-end, bootstrap, olix, symfony, template, theme

## 简介

Admin theme bundle for Symfony 5+ based on AdminLTE 3.2 with Forms

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
