# salaun/geonames

> 标签: city, country, eloquent, geonames, laravel, location, salaun, timezone

## 简介

Geonames importer and models for Eloquent ORM. This repo is a fork from Yurtesen/Geonames.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
