# salaun/laravel-complex-upsert

> 标签: laravel, laravel-complex-upsert, salaun

## 简介

A tool to efficiently upsert a database without having to relly on a primary id.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
