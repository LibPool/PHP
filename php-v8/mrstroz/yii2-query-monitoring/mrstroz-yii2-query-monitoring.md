# mrstroz/yii2-query-monitoring

> 标签: database, extension, mongodb, monitoring, mysql, n-plus-one, performance, postgresql, queries, queue, sql, yii2

## 简介

Production query monitoring for Yii 2: every MySQL, PostgreSQL and MongoDB query of a request, console command or queue job, with its time, normalised text and caller.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
