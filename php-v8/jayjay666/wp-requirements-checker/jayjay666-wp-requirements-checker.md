# jayjay666/wp-requirements-checker

> 标签: WP Plugin, WordPress Plugin Validator, WordPress Plugin Validator Requirements, WordPress Plugin Validator Requirements Checker, WordPress Requirements, WordPress Requirements Checker, wordpress, wordpress plugin, wordpress plugin development, wp

## 简介

Utility for WordPress plugin developers to check requirements. Lightweight library class for validation PHP version, PHP extensions, plugins and theirs versions in Wordpress Plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
