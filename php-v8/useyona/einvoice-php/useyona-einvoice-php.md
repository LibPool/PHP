# useyona/einvoice-php

> 标签: API-Client, E-Invoice, Nigeria, billing, einvoice, electronic-invoice, invoice, nrs, psr-18, sdk, tax, tax-compliance, yona

## 简介

Official PHP SDK for the Yona e-invoicing API — what an API key may call: invoicing, submissions to the tax authority, buyers, items, received invoices, billing reads and webhooks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
