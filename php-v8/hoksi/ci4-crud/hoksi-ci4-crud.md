# hoksi/ci4-crud

> 标签: admin, bootstrap5, codeigniter, codeigniter4, crud, library, php, react, tabulator

## 简介

CodeIgniter 4 CRUD library — Auto-generate CRUD interfaces with minimal code. Supports React SPA (Mode A) and PHP hybrid (Mode B).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
