# postscale/postscale-php

> 标签: email, email-api, postscale, sdk, smtp, transactional-email

## 简介

Official Postscale PHP SDK for email sending, domain management, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
