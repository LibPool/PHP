# dmoen/mailtrap-test-helper

> 标签: PHP

## 简介

Test helper library for testing email submissions through Mailtrap, based on PHPUnit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
