# shkubu18/filament-widget-tabs

> 标签: filament-widget-tabs, laravel, shkubu

## 简介

Widget Tabs are a modified version of Filament Tabs, displayed as widgets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
