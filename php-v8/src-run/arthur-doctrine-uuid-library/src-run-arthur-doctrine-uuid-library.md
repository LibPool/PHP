> 标签: Scribe, arthur-doctrine-uuid-library, get.src.run, library, scribe-arthur-doctrine-uuid-library, scribe-software, scribe-systems, scribenet

## 简介

A string and binary UUID-4 Doctrine ORM-type implementation as well as complimentary ORM-generator strategy implementations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
