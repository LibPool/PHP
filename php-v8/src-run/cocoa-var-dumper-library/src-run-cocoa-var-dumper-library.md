# src-run/cocoa-var-dumper-library

> 标签: cocoa, cocoa-var-dumper-library, library, rmf, src-run, var-dumper

## 简介

A simple variable var-dumper/transformer library wrapping the symfony/var-dumper component.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
