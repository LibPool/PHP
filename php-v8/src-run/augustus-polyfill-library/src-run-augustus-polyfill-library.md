> 标签: augustus, augustus-polyfill-library, library, polyfill, rmf, src-run

## 简介

Symfony/polyfill-* and provides an Error/Throwable implementation for pre-7.0 PHP release.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
