# src-run/augustus-dumper-library

> 标签: augustus, augustus-dumper-library, file, library, rmf, src-run

## 简介

A simple library to facilitate dumping of files to native php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
