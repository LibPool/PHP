# migears/ai-proxy

> 标签: ai, migears, openai, proxy, sse, stream

## 简介

A minimal AI streaming proxy for PHP 8.1+ — SSE relay + OpenAI-compatible model abstraction

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
