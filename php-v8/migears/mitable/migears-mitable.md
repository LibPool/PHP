# migears/mitable

> 标签: crud, database, ddl, migears, migration, pdo, table

## 简介

Minimalist single-table execution helper for one-off data migrations — DDL, CRUD, introspection, and cursor-based iteration, with a class per SQL dialect.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
