# migears/i18n

> 标签: date, i18n, internationalization, l10n, localization, timezone, translation

## 简介

Minimalist internationalization library — array and gettext translations, plus timezone-aware date rendering

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
