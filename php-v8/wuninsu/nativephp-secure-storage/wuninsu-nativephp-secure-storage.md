# wuninsu/nativephp-secure-storage

> 标签: keychain, keystore, mobile, nativephp, secure-storage

## 简介

Keep small secrets (such as API tokens) in the iOS Keychain or the Android Keystore from a NativePHP Mobile app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
