# lsv/ean-search

> 标签: ISBN, ISBN13, barcode, ean, rest, upc, webservice

## 简介

A library for EAN and ISBN name lookup and validation using the API on ean-search.org

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
