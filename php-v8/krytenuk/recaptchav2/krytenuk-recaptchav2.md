# krytenuk/recaptchav2

> 标签: freedom, google, laminas, recaptcha, zf3

## 简介

Laminas/Zend Framework module for using Google reCaptcha version 2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
