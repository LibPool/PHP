# krytenuk/doctrine-crypt

> 标签: decryption, doctrine, encryption, freedom, laminas, orm

## 简介

Laminas module for automatic encrypting/decrypting data in Doctrine entities

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
