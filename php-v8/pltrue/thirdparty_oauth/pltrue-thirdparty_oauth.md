# pltrue/thirdparty_oauth

> 标签: PHP

## 简介

这是一个第三方授权登录扩展包。目前支持GITHUB、GITEE、谷歌、微博、微信、QQ等授权登录

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
