# medzuch/jwt-php

> 标签: JOSE, JWE, JWS, RFC7519, auth, jwt, rfc8725, security

## 简介

Standalone, RFC 7519 / 7797 / 8725-compliant JWT library for PHP 8.3 and 8.4. Framework-agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
