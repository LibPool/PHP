# jced-artem/uopz

> 标签: php, runtime, testing, unit, uopz

## 简介

Wrapper for php uopz library's functions. Useful for unit testing for changing function's behavior in runtime

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
