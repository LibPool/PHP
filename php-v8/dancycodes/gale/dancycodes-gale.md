# dancycodes/gale

> 标签: SPA, alpine, alpinejs, blade, fragments, galemedia, htmx-alternative, laravel, livewire-alternative, reactive, real-time, server-sent-events, sse

## 简介

Laravel-native reactive frontends using Alpine Gale. Build dynamic UIs with Blade templates and Server-Sent Events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
