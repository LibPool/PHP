# dancycodes/hyper

> 标签: Datastar, SPA, blade, fragments, htmx-alternative, hypermedia, laravel, livewire-alternative, reactive, real-time, signals, validation

## 简介

Laravel-native reactive frontends using Datastar. Build dynamic UIs with Blade templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
