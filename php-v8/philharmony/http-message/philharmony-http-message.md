# philharmony/http-message

> 标签: http, http-message, psr, psr-7, request, response, stream, uri

## 简介

PSR-7 HTTP message implementation with Enum typing for Philharmony

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
