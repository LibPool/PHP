# philharmony/http-psr-extension

> 标签: extension, http, interfaces, psr-17, psr-7

## 简介

Optional extensions for PSR-7 and PSR-17 HTTP interfaces

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
