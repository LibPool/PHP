# jx3dev/jx3dev-php

> 标签: api, jx3, jx3dev, sdk, websocket

## 简介

Official-style PHP SDK for the jx3dev API. HTTP and WebSocket channels, zero runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
