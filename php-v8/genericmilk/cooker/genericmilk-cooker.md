# genericmilk/cooker

> 标签: bundler, cooker, esbuild, frontend, laravel, react, tailwind, vue

## 简介

The Laravel-native frontend toolkit. Tailwind, React, Vue, TS — without the Node baggage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
