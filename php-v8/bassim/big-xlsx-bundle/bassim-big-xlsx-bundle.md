# bassim/big-xlsx-bundle

> 标签: csv, excel, php, spreadsheet, xlsx

## 简介

Symfony2 Bundle for generating large multi-sheeted xlsx files with low memory usage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
