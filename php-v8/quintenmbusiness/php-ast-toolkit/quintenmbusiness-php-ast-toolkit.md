# quintenmbusiness/php-ast-toolkit

> 标签: PHP

## 简介

A powerful PHP toolkit for analyzing, modifying, and generating code using AST (Abstract Syntax Tree).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
