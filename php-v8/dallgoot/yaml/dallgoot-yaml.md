# dallgoot/yaml

> 标签: parser, reader, writer, yaml

## 简介

Provides loader, dumper and an API for YAML content. Loader builds to equivalent data types in PHP 8.x

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
