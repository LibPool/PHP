# ultrono/laravel-sitemap

> 标签: Sitemap, generator, google-news, html, laravel, php, xml

## 简介

Sitemap generator for Laravel 11, 12 and 13

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
