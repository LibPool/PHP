# geopard/flexgrid

> 标签: FUSION, flex, grid, neos-plugin, neoscms

## 简介

A simple but full featured flexbox grid Package for Neos <i>CMS</i>.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
