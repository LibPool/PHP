# xfix/xfix-pay

> 标签: banks, mpesa, paypal, streampay, xfix, xfixpay

## 简介

Unified PHP SDK for XfixPay - M-Pesa, PayPal, Banks, StreamPay

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
