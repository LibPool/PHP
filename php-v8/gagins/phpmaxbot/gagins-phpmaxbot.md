# gagins/phpmaxbot

> 标签: bot, bot-api, max, max-bot, max-messenger, php-max

## 简介

MAX messenger bot framework written in PHP with full Bot API support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
