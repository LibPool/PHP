# datadistillr/drill-sdk-php

> 标签: Apache Drill, DataDistiller, DataDistillr, Drill, big data, data analysis, data exploration, data science, database, sql, views

## 简介

PHP SDK for programmatically connecting to Apache Drill.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
