# renexx/qrcode

> 标签: class, library, qr code, qr code class, qr code library, vCard

## 简介

Light QRCode PHP class (library). QR Code Generator using vCard 3.0 and the Google Chart AP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
