# olivestudio/craft-olivemenus

> 标签: Craft, cms, craft-plugin, craftcms, olivemenus

## 简介

A powerful menus plugin for Craft 5 built for the need of simplicity and flexibility

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
