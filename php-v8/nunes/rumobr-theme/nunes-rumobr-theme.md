# nunes/rumobr-theme

> 标签: components, laravel, theme, ui, vue

## 简介

Tema padrão para ser utilizado em todos os projetos interno e externos da Rumobr Tecnologia (www.rumobr.com.br)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
