# daigo75/geoip

> 标签: geoip, geolocation, maxmind

## 简介

Fork of MaxMind GeoIP PHP API with improved error handling

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://dev.maxmind.com/geoip/legacy/downloadable
- 源码仓库：https://github.com/daigo75/geoip-api-php.git
- Packagist 页面：https://packagist.org/packages/daigo75%2Fgeoip
