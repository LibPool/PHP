# daigo75/php-rsyslog

> 标签: log, logging, remote syslog, rsyslog, syslog

## 简介

A PHP library to send messages to a Remote SysLog server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
