# synergitech/laravel-docblocks

> 标签: PHPStan, eloquent, laravel, phpdoc, static-analysis

## 简介

Automatically generate PHPDoc types for various elements within Laravel project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
