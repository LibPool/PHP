# objectiveweb/dice

> 标签: dependency injection, dependency injection container, di, ioc

## 简介

A fork from the level-2/dice minimalist Dependency injection container (DIC) for PHP. This version only supports PHP 8+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
