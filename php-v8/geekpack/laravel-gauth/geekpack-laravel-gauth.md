# geekpack/laravel-gauth

> 标签: gauth, geekpack, laravel

## 简介

Package to handle authentication, registration, email verification, logout, and password reset with API and Sanctum paths. Requires geekpack/laravel-api.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
