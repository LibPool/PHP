# rufusmaiwald/prompt

> 标签: JS, bootstrap, css, framework, front-end, mobile-first, responsive, sass, web

## 简介

A CSS Framework based on Bootstrap 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
