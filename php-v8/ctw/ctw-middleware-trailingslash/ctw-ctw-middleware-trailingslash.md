# ctw/ctw-middleware-trailingslash

> 标签: PHP

## 简介

This PSR-15 middleware adds a trailing slash to all URIs, redirecting with an HTTP 301 ("Moved Permanently") Location header.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
