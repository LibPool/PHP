# ctw/ctw-http

> 标签: PHP

## 简介

This package provides utility classes and constants to facilitate common operations of PSR-7 and a group of exceptions which represent HTTP status codes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
