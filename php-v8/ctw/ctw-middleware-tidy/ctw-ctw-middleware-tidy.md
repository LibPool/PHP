# ctw/ctw-middleware-tidy

> 标签: PHP

## 简介

This PSR-15 middleware formats, fixes and beautifies the HTML in the Response body using HTML Tidy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
