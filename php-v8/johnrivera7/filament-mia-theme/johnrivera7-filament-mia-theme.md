# johnrivera7/filament-mia-theme

> 标签: admin-theme, dark-mode, design-system, filament, filament-plugin, filament-theme, filamentphp, johnrivera7, laravel, tailwindcss, theme

## 简介

A warm editorial theme for Filament v5, for panels that are part of the product. Cream and champagne in the light, espresso in the dark, serif headings and hairline borders. Every surface set by hand rather than derived from an accent colour. Ships pre-compiled: no build step.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
