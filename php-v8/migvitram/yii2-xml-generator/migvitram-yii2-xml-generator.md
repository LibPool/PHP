# migvitram/yii2-xml-generator

> 标签: Sitemap, extension, yii2

## 简介

Module for generation xml files on-the-fly (e.g. sitemap.xml)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
