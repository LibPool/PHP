# porterai/plugin-wp-admin-notices

> 标签: PHP

## 简介

Helper plugin for developers to easily time-based admin notices for posts, comments, or taxonomies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
