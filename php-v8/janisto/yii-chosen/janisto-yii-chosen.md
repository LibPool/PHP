# janisto/yii-chosen

> 标签: chosen, extension, yii

## 简介

Yii Widget for Chosen - Chosen is a JavaScript plugin that makes long, unwieldy select boxes much more user-friendly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
