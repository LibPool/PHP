> 标签: dhash, difference-hash, hamming-distance, hash, image, image-comparison, image-processing, image-similarity, legitphp, libvips, pdq, pdq-hash, perceptual-hash, phash, vips

## 简介

A performance-oriented PHP package for image hashing algorithms using VIPS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
