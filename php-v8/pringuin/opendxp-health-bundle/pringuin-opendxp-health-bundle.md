# pringuin/opendxp-health-bundle

> 标签: composer-audit, health-check, monitoring, opendxp, opendxp-bundle, symfony-bundle

## 简介

Health checks for OpenDXP projects: composer audit, stuck message queue detection and more - with report display in the admin UI and email notifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
