# console-helpers/prophecy-phpunit

> 标签: phpunit, prophecy

## 简介

Integrating the Prophecy mocking library in PHPUnit test cases

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
