# console-helpers/phpunit-compat

> 标签: PHP

## 简介

Compatibility layer for PHPUnit test cases/test suite to work on different major PHPUnit versions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
