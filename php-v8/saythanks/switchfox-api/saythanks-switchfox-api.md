# saythanks/switchfox-api

> 标签: 1foryou, Api Wrapper, cellular, flash, laravel, package

## 简介

API Wrapper for various Flash APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
