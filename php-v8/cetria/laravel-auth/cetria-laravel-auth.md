# cetria/laravel-auth

> 标签: Authentication, Laravel Sanctum, REST API, api, auth, bearer token, laravel, laravel package, sanctum, token authentication

## 简介

Laravel package providing customizable authentication API endpoints using Sanctum and Bearer tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
