# hrodic/guzzle5-log-subscriber

> 标签: Guzzle, log, plugin

## 简介

Logs HTTP requests and responses as they are sent over the wire (Guzzle 4+)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
