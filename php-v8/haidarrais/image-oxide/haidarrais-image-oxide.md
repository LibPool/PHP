# haidarrais/image-oxide

> 标签: Webp, avif, daemon, gd, image, oxide, resize

## 简介

PHP client for the image-oxide daemon with a GD fallback driver. Speaks the 001 wire protocol.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
