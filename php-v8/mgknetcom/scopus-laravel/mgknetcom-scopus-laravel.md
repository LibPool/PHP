# mgknetcom/scopus-laravel

> 标签: Scopus, elsevier, filament, laravel, publications

## 简介

Reusable Laravel integration for Scopus author metrics and publication suggestions, with optional Filament administration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
