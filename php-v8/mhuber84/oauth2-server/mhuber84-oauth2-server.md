# mhuber84/oauth2-server

> 标签: PHP

## 简介

Use TYPO3 as an OAuth2 Server. Based on https://oauth2.thephpleague.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
