# madtechservices/theme-madmin

> 标签: Backpack Addon, Backpack for Laravel, ThemeMadmin, backpack, laravel

## 简介

MADmin - Tailwind based UI for Backpack v6.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
