# timersys/geo-blocker

> 标签: geo blocker, geolocation, plugin, restrict by country, wordpress

## 简介

WordPress plugin to restrict access to the site by geolocation that works with GeotargetingWP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
