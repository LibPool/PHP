# timersys/geo-links

> 标签: geo links, geolocation, geotargeting, plugin, wordpress

## 简介

WordPress plugin to make geotargeted links that works with GeotargetingWP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
