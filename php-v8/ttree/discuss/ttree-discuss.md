# ttree/discuss

> 标签: PHP

## 简介

TYPO3 Neos package for Comments and Discussion in the Frontend, based on TYPO3CR (Content Repository)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
