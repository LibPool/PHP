# bluefly/api_normalizer

> 标签: ai, api development, drupal

## 简介

API-first development approach with GraphQL as primary API and REST fallback. Provides entity field enhancements, normalization, and comprehensive API specifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
