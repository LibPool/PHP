# bluefly/ai_agent_orchestra

> 标签: LLM Platform, ai, drupal, enterprise

## 简介

Multi-agent AI orchestration with vector memory, cross-framework coordination, and multi-site management capabilities for Drupal 11.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
