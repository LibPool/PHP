# bluefly/llm

> 标签: LLM Platform, ai, drupal, enterprise

## 简介

Enterprise-grade LLM Platform with AI conversation management, multi-provider support, and unified admin interface optimized for Drupal 10.5

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
