# xchert/file-reader

> 标签: charset-conversion, csv, encoding, file-iterator, file-reader

## 简介

A memory-efficient PHP library for streaming and iterating files with built-in charset conversion

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
