# xchert/exception

> 标签: error-handling, error-mapping, exception, http-exception, json-response, symfony, symfony-bundle, validation

## 简介

A Symfony bundle for structured exception handling, error mapping, and JSON-serializable error responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
