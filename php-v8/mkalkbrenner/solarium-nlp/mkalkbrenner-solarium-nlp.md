# mkalkbrenner/solarium-nlp

> 标签: nlp, php, search, solr

## 简介

Provides testing dependencies for the solarium library to test Solr's openNLP integration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
