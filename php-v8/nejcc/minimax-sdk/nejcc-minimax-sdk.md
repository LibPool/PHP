# nejcc/minimax-sdk

> 标签: PHP

## 简介

Laravel SDK for the Minimax accounting API (SI/HR/RS): OAuth2 auth and issued invoices, orders, customers, items and code lists.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
