# dionyyy/maya

> 标签: Maya, cash-in, mini-app, paymaya, payments, philippines

## 简介

Simple PHP SDK for Maya Mini App integration (Profile, Payments, Cash-in)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
