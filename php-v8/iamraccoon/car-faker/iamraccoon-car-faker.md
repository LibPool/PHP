# iamraccoon/car-faker

> 标签: car-faker, data, faker, fixtures

## 简介

Car-Faker is a PHP library that generates fake-car data for you.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
