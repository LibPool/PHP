# jobmetric/laravel-ban-ips

> 标签: IP, ban, jobmetric, laravel, package

## 简介

This is an annoying IP management package for Laravel that you can use in your projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
