# jobmetric/laravel-toon

> 标签: ChatGpt, ai, data-conversion, data-serialization, jobmetric, json, laravel, llm, openai, php, prompt, prompt-engineering, structured-data, token-optimized, toon

## 简介

Laravel integration for TOON format: encode/decode JSON data into a token-optimized notation for LLMs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
