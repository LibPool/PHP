# magedin/module-log

> 标签: magento, magento-module, magento2, magento2-logger, magento2-module

## 简介

This module adds a new ability to create custom logs in the Magento application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
