# wasp/wasp-laravel

> 标签: PHP

## 简介

Wasp automatically grabs all errors created by your application and notifies you in realtime using the Wasp.io web service.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
