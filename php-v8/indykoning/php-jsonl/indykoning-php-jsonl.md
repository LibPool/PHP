# indykoning/php-jsonl

> 标签: JSON Lines, Line delimited JSON, NDJSON, Newline delimited JSON, json, jsonl, jsonlines, ldjson, line-delimited JSON, newline-delimited JSON, php

## 简介

PHP JSONL library for fast JSON Lines parsing and writing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
