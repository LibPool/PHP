# x3p0-dev/x3p0-hooks

> 标签: actions, attributes, filters, hooks, wordpress

## 简介

A lightweight, attribute-based hook system for WordPress plugins and themes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
