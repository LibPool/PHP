# octfx/deeply

> 标签: api, client, deepl, deeply, english, french, german, language, translate, translation

## 简介

DeepLy is a PHP client for the DeepL.com translation API v2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
