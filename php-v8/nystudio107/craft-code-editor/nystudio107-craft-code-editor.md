> 标签: Craft, Monaco, cms, code, craftcms, css, editor, javascript, markdown, twig

## 简介

Provides a code editor field with Twig & Craft API autocomplete

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
