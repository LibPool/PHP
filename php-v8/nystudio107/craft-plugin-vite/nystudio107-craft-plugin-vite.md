# nystudio107/craft-plugin-vite

> 标签: craftcms, plugin, vite

## 简介

Plugin Vite is the conduit between Craft CMS plugins and Vite, with manifest.json & HMR support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
