# nystudio107/craft-imageoptimize-imgix

> 标签: craftcms, image-optimize, image-transform, imgix

## 简介

Provides an Imgix image transform type for the ImageOptimize plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
