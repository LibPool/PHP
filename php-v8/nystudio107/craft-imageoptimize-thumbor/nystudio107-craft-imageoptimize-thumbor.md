# nystudio107/craft-imageoptimize-thumbor

> 标签: craftcms, image-optimize, image-transform, thumbor

## 简介

Provides an Thumbor image transform type for the ImageOptimize plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
