# nystudio107/craft-vite

> 标签: Craft, cms, craft-plugin, craftcms, vite

## 简介

Allows the use of the Vite.js next generation frontend tooling with Craft CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
