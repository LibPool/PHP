# nystudio107/routemap

> 标签: PHP

## 简介

Returns a list of Craft/Vue/React route rules and entry & asset URLs for ServiceWorkers from Craft entries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
