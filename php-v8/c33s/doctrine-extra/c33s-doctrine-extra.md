# c33s/doctrine-extra

> 标签: ValueObject, doctrine, featureflag, helper, nanoid, traits, types, uuid

## 简介

A Collection of Traits which can be used to build a Doctrine Entity.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
