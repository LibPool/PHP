# worldline-acquiring/acquiring-sdk-php

> 标签: sdk

## 简介

PHP SDK to communicate with the Worldline Acquiring platform using the Worldline Acquiring API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
