# rockhopsoft/fallacy

> 标签: Fallacy Me Bro, SurvLoop, brain games, critical thinking, crowd-sourced, games, laravel, logical fallacies, logical fallacy, multiplayer

## 简介

Don't Fallacy Me is a free, collaborative, multiplayer mind game! It provides an example, and you select the clearest logical fallacy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
