# jayanta/laravel-threat-detection

> 标签: ai-security, bot-detection, ddos, ids, intrusion-detection, laravel, llm-security, logging, mcp, middleware, prompt-injection, security, sql-injection, threat-detection, xss

## 简介

Passive intrusion detection for Laravel. Logs SQL injection, XSS, scanners and probes for exposed AI infrastructure, flags prompt injection aimed at your LLM, and ranks attackers. Never blocks a request.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
