# eduardaleal/laravel-clean-flow

> 标签: PHP

## 简介

Biblioteca para geração de arquitetura limpa (Controller -> Service -> Repository) no Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
