# gardi/mcp-laravel

> 标签: agents, ai, laravel, mcp, model-context-protocol

## 简介

An MCP server that lets AI agents inspect a Laravel app — routes, models, schema, and read-only queries — over stdio.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
