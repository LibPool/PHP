# omarelgabry/lumen-api-oauth

> 标签: Authentication, api, authorization, lumen, oauth, rest

## 简介

A RESTful API based on Lumen micro-framework with OAuth2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
