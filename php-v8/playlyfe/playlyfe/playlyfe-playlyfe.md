# playlyfe/playlyfe

> 标签: Gamification, Playlyfe

## 简介

This is the official OAuth 2.0 PHP client SDK for the Playlyfe API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
