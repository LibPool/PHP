# fixmind/phptohtml

> 标签: generator, html, php2html, phpManageHtml, phpToHtml, phphtml, selector

## 简介

Fast and easy html generator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
