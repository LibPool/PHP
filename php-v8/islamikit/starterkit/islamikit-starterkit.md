# islamikit/starterkit

> 标签: admin-panel, inertiajs, laravel, starter-kit, vue3

## 简介

A Laravel 13 starter kit powered by Inertia.js, Vue 3, Fortify, and Spatie packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
