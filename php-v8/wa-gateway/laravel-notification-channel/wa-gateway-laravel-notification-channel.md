# wa-gateway/laravel-notification-channel

> 标签: laravel, notifications, wa-gateway, whatsapp

## 简介

Send WhatsApp messages from Laravel notifications through the WA Gateway API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
