# vormkracht10/oauth2-genesys

> 标签: oauth2-genesys, vormkracht10

## 简介

This package provides Genesys OAuth 2.0 support for the PHP League's OAauth 2.0 Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
