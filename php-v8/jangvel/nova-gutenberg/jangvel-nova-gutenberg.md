# jangvel/nova-gutenberg

> 标签: gutenberg, laraberg, laravel, nova

## 简介

Implementation of the Gutenberg editor as a Laravel Nova Field based on Laraberg.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
