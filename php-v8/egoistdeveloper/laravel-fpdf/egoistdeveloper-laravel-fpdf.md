# egoistdeveloper/laravel-fpdf

> 标签: fpdf, laravel, pdf

## 简介

Laravel package to include Fpdf. It ships with Fpdf 1.84.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
