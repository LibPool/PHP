# remzikocak/cloudflare-php

> 标签: PHP

## 简介

PHP binding for v4 of the Cloudflare Client API. (fork of cloudflare/sdk)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
