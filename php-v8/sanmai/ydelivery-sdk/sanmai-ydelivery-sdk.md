# sanmai/ydelivery-sdk

> 标签: delivery, yandex, служба доставки, яндекс

## 简介

Яндекс.Доставка PHP SDK, библиотека для работы с API Яндекс.Доставки

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
