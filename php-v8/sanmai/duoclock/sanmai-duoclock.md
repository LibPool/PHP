# sanmai/duoclock

> 标签: PHP

## 简介

PHP time mocking for tests - PSR-20 clock with mockable sleep(), time(), and TimeSpy for PHPUnit testing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
