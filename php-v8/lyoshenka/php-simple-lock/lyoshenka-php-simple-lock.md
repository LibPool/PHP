# lyoshenka/php-simple-lock

> 标签: lock, lockfile, locking, php

## 简介

A simple PHP advisory lock implementation. Uses flock() internally.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
