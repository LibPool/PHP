# rafalmasiarek/dashboard-kit-addon-compress

> 标签: PHP

## 简介

HTML output compression middleware for rafalmasiarek/dashboard-kit. Strips whitespace and comments while preserving script, pre and textarea blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
