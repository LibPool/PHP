# rafalmasiarek/dashboard-kit-addon-sso

> 标签: PHP

## 简介

OAuth2/OIDC SSO plugin for dashboard-kit — Authorization Code + PKCE, RS256 JWT, JWKS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
