# rafalmasiarek/dashboard-kit-addon-scheduler

> 标签: PHP

## 简介

Scheduler addon for rafalmasiarek/dashboard-kit. Cron-expression task runner with queue+redirect anti-timeout, file/PDO state stores and /cron HTTP endpoints.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
