# rafalmasiarek/dashboard-kit-addon-recaptcha

> 标签: PHP

## 简介

Google reCAPTCHA v2 addon for rafalmasiarek/dashboard-kit. Injects captcha into login and register forms with always or x-failed-attempts modes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
