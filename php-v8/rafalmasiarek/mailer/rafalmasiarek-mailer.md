# rafalmasiarek/mailer

> 标签: PHP

## 简介

From-scratch SMTP client + MIME builder (no PHPMailer dependency) with native PGP/MIME body support and structured PSR-3 SMTP diagnostics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
