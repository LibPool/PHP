# rafalmasiarek/dashboard-kit-addon-request-id

> 标签: PHP

## 简介

Per-request correlation ID addon for dashboard-kit. Injects request_id into all Monolog channels and propagates it via X-Request-ID header.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
