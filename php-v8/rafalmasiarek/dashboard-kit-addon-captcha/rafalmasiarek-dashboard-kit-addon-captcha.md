# rafalmasiarek/dashboard-kit-addon-captcha

> 标签: PHP

## 简介

CAPTCHA addon for rafalmasiarek/dashboard-kit — injects CAPTCHA (reCAPTCHA, Cloudflare Turnstile, hCaptcha, via rafalmasiarek/captcha) into login and register forms, with DB-backed failed-attempt throttling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
