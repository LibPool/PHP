# rafalmasiarek/dashboard-kit-addon-mail-tracking

> 标签: PHP

## 简介

Open-tracking pixel addon for dashboard-kit outgoing email — decorates MailerInterface to append a pixel to every message, independent of which controller sends it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
