# rafalmasiarek/dashboard-kit-addon-api

> 标签: PHP

## 简介

API plugin for dashboard-kit: token auth with scopes, versioned module routes, OpenAPI registry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
