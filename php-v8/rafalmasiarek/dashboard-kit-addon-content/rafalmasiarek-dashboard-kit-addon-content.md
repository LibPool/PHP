# rafalmasiarek/dashboard-kit-addon-content

> 标签: PHP

## 简介

Content type management addon for dashboard-kit. Define content types via blueprints in admin_modules, auto-generates admin CRUD, and provides ContentRepository for public module access.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
