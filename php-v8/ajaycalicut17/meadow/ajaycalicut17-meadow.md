# ajaycalicut17/meadow

> 标签: ajaycalicut17, laravel, meadow

## 简介

Meadow is a laravel package used for instant admin panel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
