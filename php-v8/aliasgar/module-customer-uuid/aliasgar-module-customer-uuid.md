# aliasgar/module-customer-uuid

> 标签: PHP

## 简介

Adds an immutable, unique UUID attribute to Magento customers, exposed via GraphQL and the admin customer grid.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
