# exbil/reselling-api-client

> 标签: KVM, Reselling, api, billing, client, cloudservices, containers, domain, exbil, gameserver, hosting, mailcow, rootserver, teamspeak, vpn

## 简介

Official PHP client for the Exbil Reselling Portal API — Root Server, Cloud Services, Game Server, TeamSpeak, VPN, Mailcow, Domain and Accounting endpoints.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
