# smarta-lab/jxt

> 标签: cli, developer-tools, joomla, joomla-extension, release

## 简介

Manifest-driven CLI for Joomla!® extension development: sync to a local test site, build installable ZIP packages, check before a release.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
