# fruitware/php-form-validation

> 标签: form, validation

## 简介

PHP form validation Class , simple and easy to use class , yet flexible and easy to upgrade

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
