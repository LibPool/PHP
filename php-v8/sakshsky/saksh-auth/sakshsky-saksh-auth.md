# sakshsky/saksh-auth

> 标签: Authentication, Passwordless, laravel, otp

## 简介

A lightweight, passwordless OTP-based authentication system for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
