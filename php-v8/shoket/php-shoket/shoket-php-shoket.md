# shoket/php-shoket

> 标签: alphaolomi, mobile-money, payment-api, payments, php-shoket, shoket, tanzania

## 简介

Shoket is a PHP client for the Shoket Payment API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
