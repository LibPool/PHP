# lyyteam/huaxia-lunar-calendar

> 标签: bazi, calendar, chinese-calendar, chinese-lunar, eight-char, framework-agnostic, jieqi, lunar, lyyteam, solar-term, true-solar-time, 八字, 农历, 四柱, 节气

## 简介

面向 PHP 8 的专业中国历法库：公历/农历/佛历/道历、24 节气（寿星天文历秒级）、四柱八字、大运流年、真太阳时与法定假日，零框架依赖，适用于 ThinkPHP/Laravel/任意 PHP 项目

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
