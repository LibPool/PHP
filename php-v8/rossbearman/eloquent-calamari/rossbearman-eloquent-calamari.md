# rossbearman/eloquent-calamari

> 标签: eloquent, hashids, laravel, sqids

## 简介

Obfuscate incrementing IDs with Sqids for Laravel and Eloquent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
