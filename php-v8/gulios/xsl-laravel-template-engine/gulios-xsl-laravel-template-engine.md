# gulios/xsl-laravel-template-engine

> 标签: laravel, template, view, xslt

## 简介

Xslt template engine for laravel. Based on krowinski/laravel-xslt.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
