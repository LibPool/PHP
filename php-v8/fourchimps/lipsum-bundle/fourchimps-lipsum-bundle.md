# fourchimps/lipsum-bundle

> 标签: Fixture, generator, lorem

## 简介

Wrapper for Lorem Ipsum API for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
