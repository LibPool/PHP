# mediaessenz/vueture

> 标签: TYPO3 CMS, template, vuejs, vueture

## 简介

Template for using VueJS in TYPO3 Frontend/Backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
