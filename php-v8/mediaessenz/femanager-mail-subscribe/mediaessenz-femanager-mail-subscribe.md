# mediaessenz/femanager-mail-subscribe

> 标签: extension, femanager, mail, newsletter, subscription, typo3

## 简介

Adds newsletter subscription fields for mail extension to femanager

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
