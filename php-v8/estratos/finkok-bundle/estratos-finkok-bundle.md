# estratos/finkok-bundle

> 标签: cancelacion, cfdi, facturacion, finkok, sat, soap, symfony, symfony-bundle, timbrado, xml

## 简介

Bundle de Symfony 7.4 para timbrar y cancelar CFDI consumiendo los Web Services SOAP de Finkok, sin depender de ext-soap.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
