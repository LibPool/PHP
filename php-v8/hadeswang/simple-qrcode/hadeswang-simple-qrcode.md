# hadeswang/simple-qrcode

> 标签: Simple, generator, laravel, qrcode, wrapper

## 简介

Simple QrCode is a QR code generator made for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
