# il4mb/routing

> 标签: PHP

## 简介

Deterministic routing engine with an HTTP attribute router adapter (priority, fallback, wildcard matching, tracing, and reloadable rules)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
