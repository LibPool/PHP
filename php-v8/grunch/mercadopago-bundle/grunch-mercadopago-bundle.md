# grunch/mercadopago-bundle

> 标签: Symfony2, api, bundle, credito, mercadopago, tarjeta

## 简介

This is a Symfony2 Bundle helps you use the mercadopago API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
