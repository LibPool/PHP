# dmanavi/ddns

> 标签: cloudflare, ddns, digitalocean, dns, dyndns, route53, self-hosted, vultr

## 简介

Self-hosted dynamic DNS server exposing a simplified API over DigitalOcean, Vultr, Cloudflare and other DNS providers, usable over HTTP or from the CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
