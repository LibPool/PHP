# francerz/oauth2-authorization-server

> 标签: oauth2, psr-7

## 简介

Authorization Server library for OAuth 2.0 Authorization Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
