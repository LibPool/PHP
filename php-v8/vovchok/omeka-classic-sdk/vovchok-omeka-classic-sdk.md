# vovchok/omeka-classic-sdk

> 标签: Omeka Classic, api, omeka, sdk

## 简介

An Omeka Classic SDK for PHP. Use the Omeka Classic API in your PHP projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
