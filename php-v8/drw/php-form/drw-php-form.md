# drw/php-form

> 标签: form, form-generator, form-library, html-form, php, php-form-generator, web

## 简介

This form is use to generate HTML form using PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
