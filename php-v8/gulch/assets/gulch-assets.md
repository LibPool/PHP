# gulch/assets

> 标签: assets, css, javascript, php, preload, script, styles, stylesheets

## 简介

Package for gathering some type of assets (js, css) and write once into document.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
