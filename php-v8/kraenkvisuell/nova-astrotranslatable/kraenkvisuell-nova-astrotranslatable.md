# kraenkvisuell/nova-astrotranslatable

> 标签: i18n, laravel, nova, translatable, translate

## 简介

An Astrotomic Translatable extension for Laravel Nova.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
