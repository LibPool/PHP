# tooma/laravel-sms-api

> 标签: laravel, receive, send, sms, text message, tooma

## 简介

Send and receive SMS anywhere in the world using our web services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
