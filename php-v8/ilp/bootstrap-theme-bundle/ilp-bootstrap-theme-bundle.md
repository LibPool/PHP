# ilp/bootstrap-theme-bundle

> 标签: PHP

## 简介

Symfony2 Boostrap Theme/Template management bundle, with live theme editing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
