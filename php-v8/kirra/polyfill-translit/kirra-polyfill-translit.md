# kirra/polyfill-translit

> 标签: compatibility, polyfill, portable, shim, translit

## 简介

Kirra polyfill for the PECL Translit extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
