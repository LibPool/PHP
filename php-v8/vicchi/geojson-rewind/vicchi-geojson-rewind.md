# vicchi/geojson-rewind

> 标签: Polygon, geojson, php, winding order

## 简介

PHP helper classes to enforce RFC7946 polygon winding order in GeoJSON

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
