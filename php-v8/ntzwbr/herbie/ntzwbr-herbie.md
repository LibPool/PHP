# ntzwbr/herbie

> 标签: blog, cms, flat-file, herbie

## 简介

Herbie is a flat-file CMS & blog system. Simple installation - no database - just text files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
