# phapi/middleware-postbox

> 标签: content-type, middleware, phapi, postbox

## 简介

Postbox has one simple task; check if the Content-Type of the request is supported

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
