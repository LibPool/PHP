# phapi/middleware-cors

> 标签: HTTP access control, access, control, cors, middleware, phapi

## 简介

Middleware handling HTTP access control (CORS) requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
