# phapi/middleware-mistake

> 标签: error handler, exception handler, middleware, phapi

## 简介

Error and exception handling middleware for the Phapi Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
