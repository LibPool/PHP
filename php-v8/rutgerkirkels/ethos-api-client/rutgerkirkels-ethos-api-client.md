# rutgerkirkels/ethos-api-client

> 标签: client, ethos, ethosdistro, mining

## 简介

A PHP client to connect to your ethOS mining rig through the Ethos Panel API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
