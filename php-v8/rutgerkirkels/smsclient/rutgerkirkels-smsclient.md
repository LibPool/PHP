# rutgerkirkels/smsclient

> 标签: VoipCheap, client, sms

## 简介

Use this SMS client to send text messages through various providers, like VoipCheap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
