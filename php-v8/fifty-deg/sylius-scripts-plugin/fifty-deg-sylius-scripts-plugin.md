# fifty-deg/sylius-scripts-plugin

> 标签: fiftydeg, sylius, sylius-plugin

## 简介

A plugin that let's you inject scripts into your storefront from the admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
