# wexample/symfony-remote-peppol

> 标签: PHP

## 简介

Peppol e-delivery through an access point: participants, documents, transmissions, inbox and webhooks, whatever the provider

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
