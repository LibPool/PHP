# wexample/php-bpmn

> 标签: PHP

## 简介

BPMN 2.0 in plain PHP: a typed model of processes, read from and written to XML with their diagram, built in code, validated, and walked path by path

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
