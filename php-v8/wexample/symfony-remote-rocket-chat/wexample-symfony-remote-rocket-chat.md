# wexample/symfony-remote-rocket-chat

> 标签: PHP

## 简介

Rocket.Chat REST client for Symfony, built on wexample/php-api and declared as a symfony-remote client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
