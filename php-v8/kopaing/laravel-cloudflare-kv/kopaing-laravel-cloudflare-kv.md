# kopaing/laravel-cloudflare-kv

> 标签: cache, cache-driver, cloudflare, kv, laravel, workers-kv

## 简介

A Laravel cache store backed by Cloudflare Workers KV, with honest semantics for TTLs, atomicity and consistency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
