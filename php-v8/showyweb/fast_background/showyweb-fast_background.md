# showyweb/fast_background

> 标签: PHP

## 简介

Интеллектуальный JavaScript загрузчик изображений для веб-проектов (поддерживает WebP и IntersectionObserver)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
