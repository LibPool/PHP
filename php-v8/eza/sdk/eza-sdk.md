# eza/sdk

> 标签: email, eza, kenya, m-pesa, mpesa, smtp, stk push, transactional email

## 简介

Eza Cloud for PHP: transactional email, PayEdge M-Pesa STK push and signed webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
