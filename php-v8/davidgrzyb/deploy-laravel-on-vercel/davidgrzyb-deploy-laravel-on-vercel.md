# davidgrzyb/deploy-laravel-on-vercel

> 标签: davidgrzyb, deploy-laravel-on-vercel

## 简介

A package for generating files required for deployment to serverless Vercel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
