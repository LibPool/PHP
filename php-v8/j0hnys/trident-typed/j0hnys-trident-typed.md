# j0hnys/trident-typed

> 标签: generics, structs, tuple, typed, typed list

## 简介

Improvements to PHP's type system in userland: generics, typed lists, tuples and structs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
