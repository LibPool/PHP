# webx-ui/module-seo

> 标签: admin, laravel, redirects, seo, webx-ui

## 简介

SEO for the WebX UI admin panel: rules for addresses, redirects, site-wide defaults, and the <head> the public side prints.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
