# webx-ui/nested-set

> 标签: eloquent, hierarchy, laravel, nested-set, tree, webx-ui

## 简介

Nested set (modified preorder tree traversal) for Eloquent models: ordered trees with cheap subtree reads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
