# webx-ui/site

> 标签: Skeleton, cms, laravel, webx-ui

## 简介

A Laravel application with the WebX UI admin panel on it, ready for the modules the site needs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
