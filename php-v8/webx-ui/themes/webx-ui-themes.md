# webx-ui/themes

> 标签: blade, design-tokens, laravel, theme, views, webx-ui

## 简介

Site themes as layers: a local theme over a packaged one over the modules, resolved into one view order, one token vocabulary and one set of assets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
