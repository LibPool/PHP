# webx-ui/module-catalog-stock

> 标签: admin, catalog, cms, e-commerce, laravel, webx-ui

## 简介

Stock statuses for the WebX UI catalogue: in stock, out of stock, on order — one per product, a line on the card, a filter, the refusal to sell and products()->inStock() in a template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
