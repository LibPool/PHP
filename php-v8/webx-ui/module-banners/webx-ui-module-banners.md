# webx-ui/module-banners

> 标签: admin, banners, cms, laravel, slider, webx-ui

## 简介

Banners for the WebX UI admin panel: a picture (and one for phones), a video, a title, a text and up to three buttons, kept in named places and printed by the site's own templates through banners().

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
