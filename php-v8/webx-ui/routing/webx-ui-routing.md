# webx-ui/routing

> 标签: eloquent, laravel, routing, seo, slug, url, webx-ui

## 简介

The registry of a site's public addresses: one flat namespace, one row per addressable entity, one resolver that hands a path to whoever owns it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
