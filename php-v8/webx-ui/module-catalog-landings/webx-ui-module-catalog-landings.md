# webx-ui/module-catalog-landings

> 标签: admin, catalog, cms, e-commerce, laravel, seo, webx-ui

## 简介

Landing pages of the WebX UI catalogue: a category's list with a set of filters chosen in advance, under an address, an SEO card and texts of its own, with recommended products and links between the catalogue's pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
