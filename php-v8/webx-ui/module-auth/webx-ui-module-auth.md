# webx-ui/module-auth

> 标签: Authentication, admin, cms, laravel, permissions, webx-ui

## 简介

Administrators, roles and sign-in for a WebX UI admin panel — kept separate from the site's own users.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
