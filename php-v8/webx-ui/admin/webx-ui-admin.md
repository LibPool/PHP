# webx-ui/admin

> 标签: admin, cms, laravel, modules, webx-ui

## 简介

The frame a WebX UI admin panel is built on: a module contract, the manifest the front end reads, and the routes that serve it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
