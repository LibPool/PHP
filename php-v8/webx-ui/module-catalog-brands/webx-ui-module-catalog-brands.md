# webx-ui/module-catalog-brands

> 标签: admin, catalog, cms, e-commerce, laravel, webx-ui

## 简介

Brands for the WebX UI catalogue: one per product, each with its own page of the catalogue, a logo and a description, a filter, a line on the card, products()->brand() and brands()->featured() in a template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
