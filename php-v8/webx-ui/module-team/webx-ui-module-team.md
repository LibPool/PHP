# webx-ui/module-team

> 标签: Team, admin, cms, laravel, staff, webx-ui

## 简介

The team for the WebX UI admin panel: people with a photo, a name, a job title, a short text and their social links, shown on any page as a block — a grid, a slider or a list — and in templates through team().

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
