# webx-ui/module-events

> 标签: admin, cms, events, laravel, webx-ui

## 简介

Events for the WebX UI admin panel: workshops, meetings and webinars with a date, a place, a price and a link to book, each a page of fixed structure, flat categories with pages of their own, related services, an .ics file and schema.org Event.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
