# webx-ui/module-audit

> 标签: Audit, admin, cms, laravel, seo, webx-ui

## 简介

A site audit for the WebX UI admin panel: the production config, the host's mirrors, slashes and headers, and every address in the database that points at a development stand.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
