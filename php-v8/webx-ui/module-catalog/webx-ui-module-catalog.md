# webx-ui/module-catalog

> 标签: admin, catalog, cms, e-commerce, laravel, webx-ui

## 简介

A product catalogue for the WebX UI admin panel: products, a tree of categories, prices, a gallery and the registries its satellite modules plug into.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
