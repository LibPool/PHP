# webx-ui/module-tariffs

> 标签: admin, cms, laravel, pricing, tariffs, webx-ui

## 简介

Tariffs for the WebX UI admin panel: price cards with a badge, a price in a currency of the site's list or words instead of one, what the plan includes, a description and a button, in flat groups, shown on any page as a block — a slider or a grid — and in templates through tariffs().

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
