# webx-ui/module-debug

> 标签: admin, cms, debug, laravel, webx-ui

## 简介

A debug bar at the bottom of a WebX UI site's pages, for an administrator and never in production: the SQL a page ran with its repeats, a timeline, regions and blocks, the versioned cache, what the resolver found — and the same report to an agent over MCP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
