# webx-ui/module-catalog-labels

> 标签: admin, catalog, cms, e-commerce, laravel, webx-ui

## 简介

Labels for the WebX UI catalogue: top, sale, new — several per product, a badge on the card, a filter with a multiple choice and products()->label('sale') in a template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
