# webx-ui/module-catalog-manticore

> 标签: admin, catalog, cms, e-commerce, laravel, manticore, search, webx-ui

## 简介

Manticore Search as the engine of the WebX UI catalogue: a table per language with the morphology of every language of the site, facets and counts in one round trip, rebuilds swapped in whole, and the database to fall back on.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
