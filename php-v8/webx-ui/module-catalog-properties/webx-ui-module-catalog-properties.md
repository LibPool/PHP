# webx-ui/module-catalog-properties

> 标签: admin, catalog, cms, e-commerce, laravel, webx-ui

## 简介

Properties of products for the WebX UI catalogue: reference books, numbers, texts and yes/no, sets inherited down the categories, facets from the database picked by coverage, merging of values and an index document.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
