# webx-ui/module-tasks

> 标签: Tasks, admin, agents, cms, laravel, webx-ui

## 简介

A queue of work between people and AI agents for the WebX UI admin panel: tasks with a specification and ordered stages, handed out one at a time, reported on, reviewed, and journalled.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
