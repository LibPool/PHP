# webx-ui/module-press

> 标签: admin, cms, laravel, media-coverage, press, webx-ui

## 简介

Press for the WebX UI admin panel: the outlets that wrote about the site — a logo, a name, a link — and the articles in them, each leading out to the article or a PDF; a page per outlet, three blocks, and press() in templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
