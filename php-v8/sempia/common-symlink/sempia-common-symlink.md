# sempia/common-symlink

> 标签: common, composer-plugin, omeka-s, symlink

## 简介

Composer plugin to create symlink for Omeka S module Common (backward compatibility with old modules)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
