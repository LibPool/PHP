# sempia/external-assets

> 标签: assets, composer-plugin, download, external

## 简介

Composer plugin to download external assets (JS, CSS, fonts, images) for any PHP project

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://gitlab.com/sempia/composer-plugin-external-assets
- 源码仓库：https://gitlab.com/Sempia/composer-plugin-external-assets.git
