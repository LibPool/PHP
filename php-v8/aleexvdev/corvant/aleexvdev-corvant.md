# aleexvdev/corvant

> 标签: PHP

## 简介

Identity & Access Management library for Laravel — authentication, MFA, RBAC, multi-tenancy, sessions and audit log, embedded as a package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
