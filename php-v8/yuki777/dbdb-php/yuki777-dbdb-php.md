# yuki777/dbdb-php

> 标签: composer, database, manager, mongodb, mysql, plugin, postgresql, redis, version

## 简介

Database version manager for MySQL, PostgreSQL, MongoDB & Redis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
