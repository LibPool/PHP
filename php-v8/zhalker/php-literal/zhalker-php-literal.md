# zhalker/php-literal

> 标签: backtick, literal, php, template, template-literals

## 简介

Backtick-powered PHP literal templating with embedded expressions, inspired by JavaScript template literals.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
