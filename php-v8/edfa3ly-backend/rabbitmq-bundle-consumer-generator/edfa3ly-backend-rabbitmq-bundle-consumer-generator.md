# edfa3ly-backend/rabbitmq-bundle-consumer-generator

> 标签: PHP

## 简介

This is an extension for php-amqplib/rabbitmq-bundle for dynamically generating consumers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
