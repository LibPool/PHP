# remember/laravel-spreadsheet

> 标签: laravel-spreadsheet, remember

## 简介

Based on phpoffice/phpSpreadsheet package in laravel, let developers get started faster

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
