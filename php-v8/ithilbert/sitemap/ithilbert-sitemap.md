# ithilbert/sitemap

> 标签: Sitemap, it-hilbert, laravel

## 简介

Sitemap-Generator für Laravel – Routen werden direkt als Sitemap-Einträge deklariert.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
