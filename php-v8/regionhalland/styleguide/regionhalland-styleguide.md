# regionhalland/styleguide

> 标签: styleguide

## 简介

Region Hallands stilguide innehåller alla de komponenter som används för att bygga våra digitala kundmöten. För mer information besök stilguide.regionhalland.se

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
