# regionhalland/region-halland-plugin-find-on-page

> 标签: PHP

## 简介

Front-end-plugin som skapar en array för 'Hitta på sidan'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
