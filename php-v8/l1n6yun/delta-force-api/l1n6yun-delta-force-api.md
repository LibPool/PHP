# l1n6yun/delta-force-api

> 标签: api, delta-force, deltaforce, game, sdk

## 简介

三角洲行动（Delta Force）API 的无框架 SDK 包，覆盖游戏数据、微信/QQ/Wegame 登录鉴权、Steam 封禁查询等接口。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
