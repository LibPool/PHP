# emyoutis/laravel-whitehouse-responder

> 标签: WhiteHouse, api, laravel

## 简介

A simple API for generating responses in WhiteHouse standards in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
