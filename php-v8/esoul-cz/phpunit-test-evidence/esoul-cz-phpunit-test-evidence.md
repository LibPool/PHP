# esoul-cz/phpunit-test-evidence

> 标签: evidence, phpunit, regression, report, testing

## 简介

PHPUnit extension and CLI that turn a tagged group of tests into a Markdown evidence report, optionally compared against the code before a fix.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
