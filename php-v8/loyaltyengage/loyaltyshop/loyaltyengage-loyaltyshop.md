# loyaltyengage/loyaltyshop

> 标签: cart, ecommerce, hyva, hyva-compatible, loyalty, magento2, points

## 简介

Magento 2 module to add products to cart based on loyalty points

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
