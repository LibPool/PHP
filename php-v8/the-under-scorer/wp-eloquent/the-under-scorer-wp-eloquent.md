# the-under-scorer/wp-eloquent

> 标签: eloquent, orm, plugin, sql, wordpress

## 简介

Eloquent ORM for WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
