# kwxs/wkhtmltopdf

> 标签: binary, pdf, wkhtmltopdf

## 简介

The wkhtmltopdf binaries for OSX and Ubuntu Xenial, Bionic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
