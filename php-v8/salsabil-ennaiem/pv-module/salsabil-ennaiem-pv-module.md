# salsabil-ennaiem/pv-module

> 标签: PV, laravel, pdf, proces-verbal, signature, workflow

## 简介

Module autonome de gestion de Procès-Verbaux signés numériquement (workflow brouillon → en_attente → valide, génération PDF via templates, signatures, notifications, versioning).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
