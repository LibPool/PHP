# benoitchantre/wp-composer-auto-updates

> 标签: composer, updates, wordpress

## 简介

Enables minor core auto updates even when DISALLOW_FILE_MODS is set to true.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
