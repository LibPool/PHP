# krasnyd/eet-client-php

> 标签: EET, czech, elektronicka-evidence-trzeb, soap

## 简介

PHP client for Czech EET 2.0 (Elektronická evidence tržeb) SOAP protocol

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
