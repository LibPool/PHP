# sethorax/typo3-assetloader

> 标签: JS, PageSpeed, assets, cms, css, frontend, typo3

## 简介

Pagespeed friendly asset loader for TYPO3 CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
