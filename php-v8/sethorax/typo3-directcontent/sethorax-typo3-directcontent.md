# sethorax/typo3-directcontent

> 标签: cms, fluid, typo3

## 简介

Adds special doktype to TYPO3 CMS to edit a single content element directly in page view.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
