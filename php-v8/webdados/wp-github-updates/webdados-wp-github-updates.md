# webdados/wp-github-updates

> 标签: github, plugin, plugin-update-checker, theme, updates, wordpress

## 简介

Updates for private or public WordPress plugins and themes from GitHub releases, with the access token kept out of the code.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
