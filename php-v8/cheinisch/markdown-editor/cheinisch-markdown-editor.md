# cheinisch/markdown-editor

> 标签: PHP

## 简介

It's a simple Markdown editor (HTML/JS/CSS) packaged for easy embedding in PHP apps via Composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
