# voltageek/livewire-toasts-flowbite

> 标签: PHP

## 简介

Laravel Livewire toast notifications using Alpine JS & Flowbite component (Fork of aliowa/livewire-toasts)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
