# pohoc/sa-token

> 标签: Authentication, SSO, auth, authorization, jwt, oauth2, sa-token, session

## 简介

一个轻量级 PHP 权限认证框架，灵感源自 sa-token

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
