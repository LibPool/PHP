# pohoc/crypto-sm

> 标签: crypto, encryption, gm, sm2, sm3, sm4, 国密

## 简介

国密算法 SM2、SM3 和 SM4 的 PHP 版实现

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
