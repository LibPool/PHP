# weirdan/codeception-psalm-module

> 标签: codeception, psalm, psalm-plugin

## 简介

Provides codeception assertions to be used for Psalm acceptance testing

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
