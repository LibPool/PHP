# neocode/aps-connect

> 标签: aps-connect, laravel, meledjearmel, neocode

## 简介

A stateless Laravel client for Registra licence verification and App Station software distribution & auto-updates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
