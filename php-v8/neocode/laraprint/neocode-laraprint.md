# neocode/laraprint

> 标签: airprint, escpos, ipp, laravel, pos, printer, receipt, snmp, thermal, zebra, zpl

## 简介

SDK d'impression thermique (ESC/POS) et gestion d'imprimantes pour Laravel 11+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
