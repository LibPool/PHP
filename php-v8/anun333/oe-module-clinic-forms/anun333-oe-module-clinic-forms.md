# anun333/oe-module-clinic-forms

> 标签: Forms, intake, openemr, openemr-module, paperwork, printing

## 简介

Printable clinic paperwork for OpenEMR: consents, releases, referral letters and blank intake packets, filled with the clinic's own details, and paper versions of any layout form

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
