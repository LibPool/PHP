# anun333/openhealthcare-common

> 标签: openemr, openemr-module

## 简介

Code shared by the openhealthcare OpenEMR modules: one compatibility layer for OpenEMR 7.0 to 8.5, a check that translated strings carry no apostrophes or quote marks, and the tool that writes each module's FOOTPRINT.md.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
