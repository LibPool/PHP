# anun333/oe-module-sliding-fee

> 标签: fqhc, health-center, hrsa, openemr, openemr-module, sliding-fee

## 简介

Sliding fee discount program for OpenEMR, following HRSA's Health Center Program requirements: the clinic's schedule checked against Compliance Manual Chapter 9, each patient's income assessment, the discount each visit is owed, and the utilization figures the program's evaluation needs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
