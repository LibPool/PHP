# anun333/oe-module-title-x-report

> 标签: family-planning, fpar, openemr, openemr-module, title-x

## 简介

Title X Report for OpenEMR: the FPAR 2.0 file for the Office of Population Affairs, with OPA's columns and codes, and what to fix before upload.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
