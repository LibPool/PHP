# anun333/oe-module-ccbhc-report

> 标签: behavioral-health, ccbhc, openemr, openemr-module, quality-measures, samhsa

## 简介

The CCBHC clinic-collected quality measures for OpenEMR: Time to Services, social drivers screening and depression screening, in the shape of SAMHSA's reporting template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
