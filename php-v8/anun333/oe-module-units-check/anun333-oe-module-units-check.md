# anun333/oe-module-units-check

> 标签: fhir, interoperability, openemr, openemr-module, ucum, units

## 简介

See what an OpenEMR site keeps as units in UCUM terms, the unit codes FHIR, C-CDA, eCQMs and HL7 v2 exchange, and add UCUM codes to its unit list options

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
