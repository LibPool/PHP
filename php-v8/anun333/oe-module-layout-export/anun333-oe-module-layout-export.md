# anun333/oe-module-layout-export

> 标签: Forms, Lists, backup, layouts, openemr, openemr-module, version-control

## 简介

Export OpenEMR's layout forms and lists to files you can keep in version control, compare a file with a site or with another file, and read the SQL files the old backup.php page wrote, without running them

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
