# anun333/oe-module-uds-report

> 标签: fqhc, health-center, hrsa, openemr, openemr-module, uds

## 简介

HRSA Uniform Data System (UDS) report for OpenEMR: Patients by ZIP Code and Tables 3A, 3B and 4, with a list of record problems to fix before submission

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
