# feelri/laravel-start

> 标签: Laravel Start, Quick development, framework, laravel

## 简介

Laravel Start 是一个快速开发框架，基于 Laravel 框架，封装了常用功能，简化开发流程，提高开发效率。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
