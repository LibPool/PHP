# ybelenko/smsgorod-api-client

> 标签: api, client-library, notifications, sdk, sms

## 简介

Library for using SMSGateway service provided by SmsGorod.ru.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
