# ingresse/message-queue-php

> 标签: AMQP, pubsub, queue

## 简介

Message Queue php library to publish and subscribe to queues with diferent types of adapters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
