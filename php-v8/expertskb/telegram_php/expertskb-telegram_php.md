# expertskb/telegram_php

> 标签: PHP

## 简介

The 'TelegramPhp' class facilitates database backup operations by exporting tables and data into a SQL file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
