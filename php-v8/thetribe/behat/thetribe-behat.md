# thetribe/behat

> 标签: Agile, BDD, ScenarioBDD, Scrum, StoryBDD, User story, business, development, documentation, examples, symfony, testing

## 简介

Scenario-oriented BDD framework for PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
