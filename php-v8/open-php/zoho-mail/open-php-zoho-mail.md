# open-php/zoho-mail

> 标签: Zoho, mail, php, smtp

## 简介

A lightweight PHP wrapper for sending mail via Zoho using PHPMailer

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
