# hrevert/ht-country-module

> 标签: ZendFramework, country, geography, location, module, zf2

## 简介

A Zend Framework 2 module for country and subdivision data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
