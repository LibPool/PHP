# loadsys/cakephp_sociallinks

> 标签: Behavior, cakephp, model, social

## 简介

Adds fields to a model for saving social links, eg. Blog, Facebook, Twitter, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
