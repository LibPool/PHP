# blockbreakerteam/block-breaker-game

> 标签: PHP

## 简介

Block Breaker game engine - ball physics, paddle control, collision detection. Play at https://block-breaker-game.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
