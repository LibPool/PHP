# pisethchhun/bakong-khqr-php

> 标签: bakong, cambodia, khqr, payment, php, qr-code

## 简介

PHP package for generating and parsing Bakong KHQR (Cambodian QR payment) codes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
