# titasgailius/terminal

> 标签: bash, exec, laravel, process, symfony, terminal

## 简介

Terminal is an Elegent wrapper around Symfony's Process component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
