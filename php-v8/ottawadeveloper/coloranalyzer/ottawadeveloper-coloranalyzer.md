# ottawadeveloper/coloranalyzer

> 标签: accessibility, color, luminosity, wcag

## 简介

Provides WCAG information about CSS colors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
