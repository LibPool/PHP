# zmr-robin/php-markdown

> 标签: PHP

## 简介

PHPMarkdown is a simple PHP class that converts Markdown syntax into HTML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
