# brunocfalcao/laravel-openclaw-bridge

> 标签: PHP

## 简介

OpenClaw bridge for Laravel — WebSocket client, real-time streaming, CDP screenshots, memory management

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
