# rspeekenbrink/monolog-microsoft-teams

> 标签: PHP

## 简介

Monolog Handler for sending messages to Microsoft Teams using the Incoming Webhook connector

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
