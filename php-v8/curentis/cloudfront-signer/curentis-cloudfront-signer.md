# curentis/cloudfront-signer

> 标签: aws, cloudfront, laravel, security, signed-url

## 简介

A fluent Laravel SDK for generating AWS CloudFront signed URLs and cookies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
