> 标签: Ruslan_A7, core, framework, ra7, ra7-ofl, system, web, wesyf

## 简介

This is a metapackage of the WeSyF (Web System Framework) from RA7

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
