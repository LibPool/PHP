# contenir/contenir-asset-mezzio

> 标签: contenir, mezzio, psr-15, responsive-images, srcset

## 简介

Mezzio adapter for Contenir assets — keyed, profile-driven responsive image variants (incl. WebP/AVIF) backed by contenir/contenir-storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
