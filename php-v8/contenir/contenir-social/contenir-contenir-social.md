# contenir/contenir-social

> 标签: contenir, rel-me, share, social, social-links, web-share

## 简介

Framework-free social profiles and share links for Contenir: a network catalogue, profile URL checks for twelve networks, share links with no third-party scripts, inline SVG icons and a small script for Copy link and Share.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
