# contenir/tracking-laminas-mvc

> 标签: analytics, consent-mode, contenir, laminas, mvc, tracking

## 简介

Laminas MVC view helpers for contenir/contenir-tracking: tracking()->head() and tracking()->bodyStart() write a site's tags, Consent Mode first, with the page's CSP nonce.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
