# contenir/cache-laminas-mvc

> 标签: PHP

## 简介

Laminas MVC adapter for contenir/cache — MvcEvent page-cache listener driven by the standard pagecache config.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
