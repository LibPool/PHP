# contenir/contenir-formbuilder-laminas-mvc

> 标签: PHP

## 简介

Laminas MVC adapter for contenir/formbuilder — Laminas\Db loader, view helper, submit controller, Module + ConfigProvider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
