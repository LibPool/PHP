# contenir/contenir-preview-laminas-mvc

> 标签: cms, contenir, laminas, mvc, preview

## 简介

Laminas MVC renderer for the Contenir preview protocol: answers the CMS's signed previews at /api/resource/preview by rendering the record's page with its unsaved values.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
