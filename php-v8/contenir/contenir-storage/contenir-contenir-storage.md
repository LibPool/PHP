# contenir/contenir-storage

> 标签: PHP

## 简介

Framework-agnostic asset storage for Contenir CMS — local, S3-compatible, and Cloudflare Images adapters with a shared variant pipeline.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
