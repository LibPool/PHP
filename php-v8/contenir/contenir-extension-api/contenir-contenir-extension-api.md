# contenir/contenir-extension-api

> 标签: add-on, cms, contenir, extension, plugin

## 简介

The add-on API for Contenir CMS: the contracts add-ons build against, the event catalogue, a conformance suite for hosts and an in-memory host. Framework free: PSR-3, PSR-7, PSR-11, PSR-14 and PSR-20 only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
