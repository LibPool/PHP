# contenir/contenir-log

> 标签: contenir, laminas, log, logger, mezzio, psr-3

## 简介

Pluggable PSR-3 logger for Laminas MVC and Mezzio, with filesystem and database storage backends.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
