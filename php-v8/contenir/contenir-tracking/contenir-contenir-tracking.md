# contenir/contenir-tracking

> 标签: analytics, consent-mode, contenir, csp, gtag, tracking

## 简介

Framework-free analytics and tracking tags for Contenir: tag definitions (Google tag, Tag Manager, Meta pixel, LinkedIn Insight), Consent Mode v2, ID validation and snippet rendering with a CSP nonce.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
