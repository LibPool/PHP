# contenir/contenir-cdn

> 标签: cache, cdn, cloudflare, contenir, purge

## 简介

Framework-free CDN purging for Contenir: the purger interface, cache-tag naming, URL batching, debouncing and a Cloudflare API client that signs in with a token.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
