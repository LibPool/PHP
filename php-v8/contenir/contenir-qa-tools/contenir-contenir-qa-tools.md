# contenir/contenir-qa-tools

> 标签: coding-standards, contenir, formatter, linter, mago, qa, static-analysis

## 简介

Shared QA toolchain for Contenir components: Mago formatting, linting and static analysis, plus the PHPUnit baseline and CI workflow. Forked from php-db/phpdb-qa-tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
