# contenir/contenir-errors-laminas-mvc

> 标签: PHP

## 简介

Laminas MVC adapter for contenir/contenir-errors — swaps the default error rendering with admin-authored per-status pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
