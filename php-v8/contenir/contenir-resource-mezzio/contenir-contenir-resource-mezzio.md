# contenir/contenir-resource-mezzio

> 标签: contenir, metadata, mezzio, psr-15, resource, seo

## 简介

Mezzio adapter for contenir/contenir-resource: workflow routing and navigation for Contenir resources, a middleware that resolves the routed resource and its page metadata, resource URLs and optional laminas-view helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
