# contenir/contenir-workflow-mezzio

> 标签: cms, mezzio, navigation, routing, workflow

## 简介

Database-driven workflow system for Mezzio that generates routes and navigation from hierarchical page structures

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
