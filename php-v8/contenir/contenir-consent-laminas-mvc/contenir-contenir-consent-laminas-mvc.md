# contenir/contenir-consent-laminas-mvc

> 标签: consent, consent-mode, contenir, cookie-consent, laminas, mvc

## 简介

Laminas MVC adapter for contenir/contenir-consent: consent()->head() and consent()->bodyEnd() write the cookie banner and Consent Mode, consentScript() gates a site's own embeds, consentPreferencesLink() reopens the preferences, and a route serves the banner's files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
