# contenir/contenir-db-model-tools

> 标签: cli, code-generation, contenir, data-mapper, php-db

## 简介

Command-line tools for contenir-db-model: generate entities from live tables, upgrade 1.x entities and validate mappings

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
