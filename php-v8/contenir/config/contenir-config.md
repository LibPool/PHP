# contenir/config

> 标签: PHP

## 简介

Framework-agnostic PHP-array config file reader/writer with atomic writes and opcache invalidation. Adapted from Laminas\Config.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
