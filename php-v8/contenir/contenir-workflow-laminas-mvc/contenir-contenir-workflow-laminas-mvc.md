# contenir/contenir-workflow-laminas-mvc

> 标签: contenir, laminas, mvc, navigation, routing

## 简介

Builds laminas-mvc routes and laminas-navigation pages from a tree of Contenir resources, one workflow per resource type

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
