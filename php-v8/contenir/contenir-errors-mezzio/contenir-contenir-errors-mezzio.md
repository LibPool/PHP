# contenir/contenir-errors-mezzio

> 标签: contenir, errors, mezzio, middleware, psr-15

## 简介

Mezzio (PSR-15) adapter for contenir/contenir-errors — renders admin-authored per-status pages for 4xx/5xx responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
