# contenir/contenir-resource-laminas-mvc

> 标签: contenir, laminas, metadata, mvc, resource, seo

## 简介

laminas-mvc adapter for contenir/contenir-resource: workflow routing and navigation for Contenir resources, a route listener that resolves the routed resource and its page metadata, the resource() controller plugin and the resource, resourceMeta, resourceUrl and resourceContent view helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
