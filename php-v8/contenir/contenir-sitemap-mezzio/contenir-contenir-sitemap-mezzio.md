# contenir/contenir-sitemap-mezzio

> 标签: Sitemap, contenir, mezzio, psr-15, robots.txt

## 简介

Mezzio adapter for Contenir sitemaps: PSR-15 handlers for /sitemap.xml and /robots.txt, built from the contenir-workflow-mezzio navigation or any SitemapSourceInterface

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
