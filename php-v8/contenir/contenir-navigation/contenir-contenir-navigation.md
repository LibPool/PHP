# contenir/contenir-navigation

> 标签: cms, contenir, menu, navigation

## 简介

Managed site navigation for Contenir CMS: menus of nested items linking to records or URLs, edited as a draft and published as revisions. Framework free: PSR-11 and PSR-20, stored with php-db on MySQL or SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
