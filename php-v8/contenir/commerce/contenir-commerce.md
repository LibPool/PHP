# contenir/commerce

> 标签: PHP

## 简介

Commerce domain for Contenir CMS — orders, artworks, GST-inclusive money and Stripe checkout for small-volume gallery sales.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
