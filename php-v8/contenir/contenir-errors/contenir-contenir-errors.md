# contenir/contenir-errors

> 标签: PHP

## 简介

Framework-agnostic admin-authored error-page content for Contenir CMS — admin writes per-status titles and bodies, Site renders.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
