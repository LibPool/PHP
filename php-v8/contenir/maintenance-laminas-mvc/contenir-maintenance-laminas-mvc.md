# contenir/maintenance-laminas-mvc

> 标签: PHP

## 简介

Laminas MVC adapter for contenir/maintenance — short-circuits dispatch with 503 when maintenance mode is active.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
