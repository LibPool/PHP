# contenir/contenir-cache-mezzio

> 标签: PHP

## 简介

Mezzio (PSR-15) adapter for contenir/cache: a full-page output cache middleware controlled by the Contenir admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
