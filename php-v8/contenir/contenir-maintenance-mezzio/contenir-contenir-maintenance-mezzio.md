# contenir/contenir-maintenance-mezzio

> 标签: PHP

## 简介

Mezzio adapter for contenir/contenir-maintenance — PSR-15 middleware that answers every request with 503 while maintenance mode is active.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
