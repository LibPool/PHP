# pbmedia/laravel-browser-kit-macro

> 标签: laravel-browser-kit, protone-media

## 简介

A macro to use the Laravel 5.3 testing layer inside your Laravel 5.4+ tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
