# hagmann/ht-user-registration-doctrine-orm

> 标签: PHP

## 简介

A ZfcUser based module to add ORM to HtUserRegistration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
