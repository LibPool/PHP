# seoultra/open-consent

> 标签: Consent management, cmp, consent mode v2, cookie banner, cookie consent, gdpr, google consent mode, privacy

## 简介

Free, open-source cookie consent: a browser consent engine with real script blocking and Google Consent Mode v2, plus a PHP library to configure it and read the consent cookie server-side.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
