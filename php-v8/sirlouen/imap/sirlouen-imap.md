# sirlouen/imap

> 标签: c-client, imap, mail, nntp, pop3

## 简介

An extension to operate with the IMAP protocol, as well as the NNTP, POP3, and local mailbox access methods.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
