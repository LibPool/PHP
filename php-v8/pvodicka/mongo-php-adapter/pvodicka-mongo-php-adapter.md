# pvodicka/mongo-php-adapter

> 标签: database, mongodb

## 简介

Adapter to provide ext-mongo interface on top of mongo-php-library. Modified to use my mongo-php-library fork.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
