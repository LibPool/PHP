# valekstepanov/yii2-flexslider

> 标签: extension, flexslider, widget, yii2

## 简介

This is widget wrapper of Flexslider https://github.com/woothemes/FlexSlider for Yii2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
