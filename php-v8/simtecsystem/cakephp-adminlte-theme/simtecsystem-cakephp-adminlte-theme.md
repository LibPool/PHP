# simtecsystem/cakephp-adminlte-theme

> 标签: cakephp, plugin, templates

## 简介

CakePHP 3.x AdminLTE Theme 3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
