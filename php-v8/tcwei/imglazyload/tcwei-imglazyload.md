# tcwei/imglazyload

> 标签: PHP

## 简介

文章图片懒加载，当文章中存在大量图片时，可使用该库进行图片懒加载，看不到的图片不进行加载，节省带宽

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
