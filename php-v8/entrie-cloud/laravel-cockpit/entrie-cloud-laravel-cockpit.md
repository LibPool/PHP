# entrie-cloud/laravel-cockpit

> 标签: cockpit, cockpit-cms, cockpit-package, entrie, entrie-cloud, laravel, laravel-cockpit

## 简介

Integrates Cockpit CMS with Laravel with caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
