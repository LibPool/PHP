# badmushroom/digstatsreader

> 标签: NBT, minecraft, parser, stats

## 简介

Tool for parsing Minecraft's NBT (Named Bindary Tag) data files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
