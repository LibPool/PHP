# z1lab/openid-client

> 标签: OpenId, client, laravel, passport

## 简介

Z1lab OpenID Client is a package developed for connect Z1lab's Laravel projects to our Oauth2 Server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
