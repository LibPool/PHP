# goldspecdigital/laravel-eloquent-uuid

> 标签: eloquent, laravel, php, uuid

## 简介

A simple drop-in solution for providing UUID support for the IDs of your Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
