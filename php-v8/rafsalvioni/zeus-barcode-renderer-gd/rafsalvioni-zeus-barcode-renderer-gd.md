# rafsalvioni/zeus-barcode-renderer-gd

> 标签: barcode, gd, gif, image, jpeg, jpg, png, renderer, zeus

## 简介

Provides a renderer to draw barcodes as images using GD extension

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
