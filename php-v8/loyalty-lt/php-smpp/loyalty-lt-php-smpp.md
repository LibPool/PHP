# loyalty-lt/php-smpp

> 标签: Lithuanian, lib, loyalty, php, smpp, sms

## 简介

Implementation SMPP v3.4 protocol with Lithuanian language support. Fork of glushkovds/php-smpp.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
