# hoheisel-it/lexoffice-laravel-api

> 标签: Accounting, invoices, laravel, lexoffice, sync

## 简介

Synchronize Laravel models with Lexoffice — contacts, invoices, and products via event-driven queue jobs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
