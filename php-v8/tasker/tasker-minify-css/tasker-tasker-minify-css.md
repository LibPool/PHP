# tasker/tasker-minify-css

> 标签: css, minify files, taks runner, task, tasker

## 简介

Task which will be concatenate and minify your files for task manager Tasker

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
