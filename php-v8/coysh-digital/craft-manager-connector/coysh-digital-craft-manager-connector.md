# coysh-digital/craft-manager-connector

> 标签: Craft, cms, craft-plugin, craftcms, manager, monitoring

## 简介

Reports operational metadata from a Craft CMS installation to a Manager platform over signed outbound requests, with one inbound endpoint whose only meaning is "check in now".

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
