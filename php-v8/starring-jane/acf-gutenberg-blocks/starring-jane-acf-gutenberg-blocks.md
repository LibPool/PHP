# starring-jane/acf-gutenberg-blocks

> 标签: PHP

## 简介

An elegant way for developers to register Gutenberg blocks using the ACF PRO blocks feature

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
