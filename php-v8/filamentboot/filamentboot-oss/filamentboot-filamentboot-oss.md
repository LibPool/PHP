# filamentboot/filamentboot-oss

> 标签: Flysystem, aliyun, cloud-storage, filament, filament-plugin, laravel, oss, storage

## 简介

阿里云 OSS 存储插件，为 filamentboot/filamentboot 提供 Flysystem OSS 磁盘驱动与后台凭证配置页。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
