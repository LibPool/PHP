# filamentboot/filamentboot-cos

> 标签: admin-panel, cloud-storage, cos, filament, filament-plugin, laravel, storage, tencent

## 简介

腾讯云 COS 存储插件：为 filamentboot/filamentboot 提供 COS 凭证后台配置与 Flysystem 磁盘注入。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
