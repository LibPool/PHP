# filamentboot/filamentboot-site

> 标签: cms, filament, filament-plugin, laravel, official-site, website

## 简介

面向中小企业的前台官网管理插件，提供案例/方案/产品/资讯/页面/询盘六类内容管理，中文单语言，支持主题切换。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
