# polidog/tehilim

> 标签: PHP

## 简介

Prisma-style schema-first database toolkit for PHP. No class mapping; generated query clients with PHPStan-friendly array shapes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
