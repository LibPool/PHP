# agents-full-duplex/laravel-realtime-agent

> 标签: agents, full-duplex, laravel, realtime, voice

## 简介

Provider-neutral Laravel core and browser bridge for full-duplex realtime agents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
