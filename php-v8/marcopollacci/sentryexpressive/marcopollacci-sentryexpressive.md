# marcopollacci/sentryexpressive

> 标签: marcopollacci, php, sentry, ze, zend, zend-expressive

## 简介

Utility to connect Zend Expressive Framework to Sentry

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
