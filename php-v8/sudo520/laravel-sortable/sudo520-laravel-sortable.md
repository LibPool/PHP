# sudo520/laravel-sortable

> 标签: database, laravel, ordering, sorting

## 简介

Simple package to add sorting functionality to your Laravel models. (fork of ninoman/laravel-sortable)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
