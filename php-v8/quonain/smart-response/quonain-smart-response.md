# quonain/smart-response

> 标签: JSON-API, api, api-response, blade, codeigniter, composer, content-negotiation, framework-agnostic, http, inertia, json, laravel, legacy-api, livewire, packagist, php, php-library, response, response-formatter, rest-api, smart-response, xml

## 简介

PHP response library for standardizing REST/API responses across JSON, XML, legacy contracts, and Laravel web responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
