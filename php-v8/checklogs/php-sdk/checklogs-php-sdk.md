# checklogs/php-sdk

> 标签: checklogs, logging, monitoring, php, sdk

## 简介

SDK PHP officiel pour CheckLogs.dev - Système de surveillance des logs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
