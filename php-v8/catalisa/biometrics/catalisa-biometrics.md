# catalisa/biometrics

> 标签: biometrics, catalisa, face-match, kyc, liveness

## 简介

Catalisa Biometrics PHP SDK — liveness and face-match sessions, signed evidence and webhook verification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
