# huseyinfiliz/language-detection

> 标签: analytics, detection, flarum, i18n, language, locale

## 简介

Automatically selects the visitor's Flarum language based on their browser language or IP location.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
