# criztianix/cakephp-cremilla

> 标签: cakephp, queue, shell

## 简介

CakePHP wrapper plugin around CakePHPQueuesadilla with some improves

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
