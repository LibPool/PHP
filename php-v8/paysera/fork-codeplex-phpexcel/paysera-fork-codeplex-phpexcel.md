# paysera/fork-codeplex-phpexcel

> 标签: OpenXML, excel, php, spreadsheet

## 简介

PHPExcel - OpenXML - Create Excel2007 documents in PHP - Spreadsheet engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
