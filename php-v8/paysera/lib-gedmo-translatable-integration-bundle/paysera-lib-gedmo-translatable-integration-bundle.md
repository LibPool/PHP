# paysera/lib-gedmo-translatable-integration-bundle

> 标签: PHP

## 简介

This library provides means to easily integrate Gedmo Translatable doctrine extension into your project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
