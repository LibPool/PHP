# paysera/lib-maba-webpack-extension-bundle

> 标签: PHP

## 简介

Provides extensions for maba/webpack-bundle to integrate better into developer environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
