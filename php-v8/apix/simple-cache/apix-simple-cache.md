# apix/simple-cache

> 标签: Taggable, cache, cache-busting, caching, psr-16, psr-6, psr-cache, psr-simple-cache, psrCache, session

## 简介

The PSR-16 extension to Apix-Cache.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
