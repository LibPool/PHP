# jeddsaliba/laravel-apcopay

> 标签: apcopay, gateway, laravel, payment

## 简介

Laravel integration for ApcoPay payment gateway (hosted page and payment status)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
