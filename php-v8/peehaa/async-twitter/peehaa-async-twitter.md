# peehaa/async-twitter

> 标签: async, client, non-blocking, oauth, parallel, twitter

## 简介

Asynchronous parallel Twitter client built on the Amp concurrency framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
