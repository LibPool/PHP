# edith/admin

> 标签: admin, amis, edith, edith-admin, laravel

## 简介

翼搭快速开发框架，一个基于Laravel、Amis整合Ant的快速后台框架。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
