# isaackogan/tiktok-shop-api

> 标签: ecommerce, tiktok shop, tiktok shop api, tiktok shop oauth, tiktok shop open api, tiktok shop partner api, tiktok shop php, tiktok shop sdk, tiktok shop webhooks, unofficial

## 简介

PHP client for the TikTok Shop API (TikTok Shop Partner API): request signing, OAuth, multi-shop support and typed webhooks. Unofficial. Not affiliated with or endorsed by TikTok or ByteDance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
