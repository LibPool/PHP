# dragonsoftware/modalizable

> 标签: PHP

## 简介

This package would help create modal edit form for both normal tables and datatable with ease using bootstrap 4 styling

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
