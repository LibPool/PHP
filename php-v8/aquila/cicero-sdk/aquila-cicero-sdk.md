# aquila/cicero-sdk

> 标签: PHP

## 简介

SDK for Cicero application such as Sophia NLU engine

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://cicero.sh
- 源码仓库：https://github.com/cicero-ai/sdk.git
- Packagist 页面：https://packagist.org/packages/aquila%2Fcicero-sdk

## 历史版本号

- 当前版本：0.1.2

- 0.1.2

## 获取地址

- Composer 安装：`composer require aquila/cicero-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/aquila/cicero-sdk.json
- PHP 要求：>=8.1
