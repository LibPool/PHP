# quizlet/fb_intercept_polyfill

> 标签: PHP

## 简介

A polyfill for using fb_intercept across hhvm 3.24 -> 4.present

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
