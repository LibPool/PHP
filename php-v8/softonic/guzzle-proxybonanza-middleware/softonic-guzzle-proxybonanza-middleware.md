# softonic/guzzle-proxybonanza-middleware

> 标签: Guzzle, middleware, proxy, proxybonanza

## 简介

This package allows you to use proxybonanza transparently in guzzle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
