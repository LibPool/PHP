# softonic/laravel-middleware-request-id

> 标签: laravel, middleware, tracking

## 简介

Middleware for Laravel Framework to add the X-Request-ID header in the requests and responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
