# silverassist/wp-coding-standards

> 标签: PHP

## 简介

WordPress-plugin PHPCS ruleset, PHPStan config, and reusable CI/CD workflows for Silver Assist plugins. Requires silverassist/coding-standards for the framework-agnostic PSR-12 base.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
