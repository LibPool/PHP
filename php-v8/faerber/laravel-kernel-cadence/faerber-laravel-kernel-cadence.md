# faerber/laravel-kernel-cadence

> 标签: cadence, cron, laravel, offset, scheduler, stagger

## 简介

Phase-offset sub-hourly cron cadences for the Laravel scheduler. Stop stacking every-N-minutes tasks on the top of the hour.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
