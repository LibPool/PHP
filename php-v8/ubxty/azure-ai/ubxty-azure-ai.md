# ubxty/azure-ai

> 标签: ChatGpt, ai, azure, gpt, laravel, openai, streaming

## 简介

Azure OpenAI integration for Laravel — chat, streaming, multi-key rotation, cost tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
