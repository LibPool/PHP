# foun10/dashboard

> 标签: OXID, admin, dashboard, eshop, modules, statistics

## 简介

Sales dashboard for the OXID eShop admin start page: revenue KPIs with comparisons, trend, customer types, payment methods, countries, top sellers and open baskets

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
