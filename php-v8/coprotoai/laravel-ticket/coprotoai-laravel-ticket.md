# coprotoai/laravel-ticket

> 标签: Customer support, crm, helpdesk, laravel, support, ticket

## 简介

A simple ticketing system for Laravel 5.1 - 5.8 and 6.* - 7.* - 8.* - 9.* - 10.* - 11.* - which integrates smoothly with Laravel default users and auth system. Fork of binshops/laravel-ticket maintained for Laravel 11+ compatibility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
