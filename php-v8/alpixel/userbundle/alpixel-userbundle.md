# alpixel/userbundle

> 标签: Symfony2, alpixel, bundle, symfony, user, userbundle

## 简介

FOSUserBundle integration to Sonata & ALPIXEL tools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
