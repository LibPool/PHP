# alpixel/phoneformatterbundle

> 标签: Symfony2, alpixel, bundle, formatting, phone number, symfony, twig extension

## 简介

Provides helper to format phone number easily

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
