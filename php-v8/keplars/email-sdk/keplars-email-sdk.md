# keplars/email-sdk

> 标签: api, email, keplars, priority, sdk, transactional

## 简介

Official PHP SDK for Keplars Email API - modern transactional email service with priority-based delivery

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
