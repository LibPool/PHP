# mosaxiv/stream-filter-mbencoding

> 标签: SplFileObject, csv, mb_convert_encoding, stream-filter

## 简介

Provides some PHP stream filter for mb_convert_encoding.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
