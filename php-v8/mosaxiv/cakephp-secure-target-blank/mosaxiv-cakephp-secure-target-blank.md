# mosaxiv/cakephp-secure-target-blank

> 标签: cakephp, plugin, secure

## 简介

Adds noopener and noreferrer to target _blank in Html Helper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
