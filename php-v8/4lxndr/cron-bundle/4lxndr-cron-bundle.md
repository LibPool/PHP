# 4lxndr/cron-bundle

> 标签: automation, bundle, command, cron, cronjob, dependencies, dependency, execute, interval, job-scheduler, schedule, shapecode, symfony, tagging, tags, time, workflow

## 简介

Symfony bundle for scheduled command execution with dependency resolution, job tagging, and automatic failure handling

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
