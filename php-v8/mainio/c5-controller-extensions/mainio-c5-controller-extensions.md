# mainio/c5-controller-extensions

> 标签: concrete5, controller, extension, extensions

## 简介

Provides some useful extensions for concrete5 controllers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
