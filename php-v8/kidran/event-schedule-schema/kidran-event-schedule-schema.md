# kidran/event-schedule-schema

> 标签: composer, event-schedule, json-schema, laravel, schedule

## 简介

Laravel package for generating and validating Barq-compatible furry event schedule JSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
