# plank/blueprint-data

> 标签: blueprint, dto, laravel, laravel-data, plank

## 简介

Blueprint addon that generates spatie/laravel-data Data classes (DTOs) for every model in your draft file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
