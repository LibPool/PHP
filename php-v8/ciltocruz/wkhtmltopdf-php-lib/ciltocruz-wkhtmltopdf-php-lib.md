# ciltocruz/wkhtmltopdf-php-lib

> 标签: binary, convert, htmltopdf, pdf, wkhtmltopdf

## 简介

HTML to PDF Converter based on wkhtmltopdf for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
