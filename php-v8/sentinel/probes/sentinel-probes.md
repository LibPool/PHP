# sentinel/probes

> 标签: apm, dynamic-instrumentation, observability, opentelemetry, probes, sentinel

## 简介

Sentinel Dynamic Instrumentation for PHP: metric, span and span-tag probes on methods and probe points, changed at runtime without a deploy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
