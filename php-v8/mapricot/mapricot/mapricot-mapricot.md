# mapricot/mapricot

> 标签: geocoding, ip-geolocation, maps, places, routing

## 简介

Official client for the Mapricot API: geocoding, places, routing, and IP geolocation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
