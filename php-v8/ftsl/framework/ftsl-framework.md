# ftsl/framework

> 标签: framework, mvc, zend

## 简介

Extensions of Zend Framework 3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 许可证：AGPL-3.0-or-later
- PHP 要求：>=7.0
