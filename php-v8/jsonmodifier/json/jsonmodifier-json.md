# jsonmodifier/json

> 标签: PHP

## 简介

PHP package allows developers to manipulate JSON files by performing data lookup and many other operations such as read, write, delete and update.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
