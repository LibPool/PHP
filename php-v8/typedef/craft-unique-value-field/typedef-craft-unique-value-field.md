# typedef/craft-unique-value-field

> 标签: craft cms, craft plugin, unique field, validation

## 简介

A Craft CMS field type for enforcing unique values with flexible scoping and optional format validation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
