> 标签: DOCX-to-PDF, api, conversion, document-convert, enconvert, heic-to-webp, html-to-pdf, image-convert, pdf, screenshot, sdk, url-to-markdown, url-to-pdf, url-to-screenshot

## 简介

PHP SDK for Enconvert — read any page or file into agent-ready Markdown, JSON, or screenshots (scored 0.0-1.0), plus file conversion. V2 perception + MCP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
