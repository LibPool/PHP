# ararahq/sdk

> 标签: api, arara, brazil, messaging, sdk, sms, whatsapp

## 简介

Official PHP SDK for AraraHQ platform. Simple, typed, and developer-first.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
