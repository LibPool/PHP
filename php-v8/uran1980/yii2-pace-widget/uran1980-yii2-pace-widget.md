# uran1980/yii2-pace-widget

> 标签: PACE, widgets, yii2, yii2-pace-widget

## 简介

An Yii2 widget for automatic web page progress bar.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
