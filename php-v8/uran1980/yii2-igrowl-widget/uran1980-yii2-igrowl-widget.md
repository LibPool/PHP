# uran1980/yii2-igrowl-widget

> 标签: iGrowl, widgets, yii2, yii2-igrowl-widget

## 简介

An Yii2 igrowl widget based on iGrowl jQuery plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
