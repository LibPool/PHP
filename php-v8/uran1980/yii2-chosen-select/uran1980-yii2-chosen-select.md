# uran1980/yii2-chosen-select

> 标签: chosen, javascript, jquery plugin, yii2, yii2-chosen-select

## 简介

An Yii2 chosen select extension based on Chosen jQuery plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
