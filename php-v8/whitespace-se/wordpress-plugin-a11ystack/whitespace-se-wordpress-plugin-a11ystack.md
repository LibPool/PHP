# whitespace-se/wordpress-plugin-a11ystack

> 标签: PHP

## 简介

Wordpress plugin that adds a11ystack-specific enhancements and features to Wordpress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
