# whitespace-se/wordpress-plugin-wp-graphql-extras

> 标签: PHP

## 简介

Wordpress plugin that adds additional types and fields to the GraphQL API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
