# crayon/nova-rtl-theme

> 标签: laravel, nova, rtl, theme

## 简介

RTL layout for Laravel Nova. This package has been forked from pishran/nova-rtl-theme

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
