# codetech/laravel-eupago

> 标签: Eupago, credit-card, laravel, mbway, multibanco, payment, payment-gateway, paysafecard, payshop, portugal

## 简介

Eupago payment gateway integration for Laravel — Multibanco, MB WAY, PayShop, PaysafeCard and Credit Card payments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
