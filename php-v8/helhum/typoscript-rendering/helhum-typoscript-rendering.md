# helhum/typoscript-rendering

> 标签: Rendering, frontend, typo3

## 简介

Can render a TypoScript path by URL, especially useful for Ajax dispatching

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
