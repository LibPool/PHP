# helhum/php-error-reporting

> 标签: error reporting, sentry

## 简介

Create ErrorException with clean trace from PHP error handler errors, inspired by Sentry PHP SDK

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
