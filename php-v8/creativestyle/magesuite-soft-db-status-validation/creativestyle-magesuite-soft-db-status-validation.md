# creativestyle/magesuite-soft-db-status-validation

> 标签: PHP

## 简介

Makes the db (schema) validation silently log error instead of throwing critical exception

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
