# creativestyle/magesuite-elasticsuite-ajaxifier

> 标签: PHP

## 简介

Extension adds infinite scroll feature on POP and asynchronous filters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
