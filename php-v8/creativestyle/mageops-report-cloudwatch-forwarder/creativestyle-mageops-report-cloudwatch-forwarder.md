# creativestyle/mageops-report-cloudwatch-forwarder

> 标签: aws, cloudwatch, logging, magento

## 简介

Forwards exception report files to CloudWatch Logs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
