# creativestyle/magesuite-content-constructor-remove-layout-validation

> 标签: PHP

## 简介

Extension removes custom layout update validation introduced in Magento 2.3.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
