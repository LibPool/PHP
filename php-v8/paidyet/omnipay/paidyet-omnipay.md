# paidyet/omnipay

> 标签: gateway, merchant, paid yet, paidyet, pay, payment, secure

## 简介

PaidYET driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
