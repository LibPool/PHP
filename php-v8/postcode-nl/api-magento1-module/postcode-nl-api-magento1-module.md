# postcode-nl/api-magento1-module

> 标签: address, api, autocomplete, international, netherlands, postcode, postcodenl, rest, validation

## 简介

Postcode.nl International Address API module for Magento 1. Adds autocompletion for addresses in multiple countries using official postal data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
