# lakedrops/ahoy

> 标签: Ahoy, development, drupal, install, update

## 简介

This plugin collects available ahoy scripts from installed LakeDrops plugins and configures ahy in the project root.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
