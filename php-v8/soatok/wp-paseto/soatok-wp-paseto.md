# soatok/wp-paseto

> 标签: PHP 5.6, encryption, paseto

## 简介

PASETO v4.local implementation that supports PHP 5.6+ (for WordPress projects)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
