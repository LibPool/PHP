# sysmoh/nextcloud-api-wrapper

> 标签: api, nextcloud, wrapper

## 简介

A simple wrapper around nextcloud user provisioning api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
