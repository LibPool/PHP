# mediawiki/semantic-forms-select

> 标签: Page Forms, SMW, Semantic MediaWiki, mediawiki

## 简介

Allows to generate a select field in a form whose values are retrieved from a query

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
