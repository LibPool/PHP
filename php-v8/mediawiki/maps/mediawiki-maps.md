# mediawiki/maps

> 标签: OpenLayers, OpenStreetMap, Semantic Maps, Semantic MediaWiki, geocode, geocoding, google maps, leaflet, maps, mediawiki, osm

## 简介

Adds various mapping features to MediaWiki

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
