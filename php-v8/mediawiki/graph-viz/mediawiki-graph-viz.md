# mediawiki/graph-viz

> 标签: Mscgen, dot, graphviz, mediawiki, wiki

## 简介

Online DOT graph renderer and message sequence chart renderer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
