# mediawiki/semantic-cite

> 标签: SMW, Semantic MediaWiki, citation, mediawiki, wiki

## 简介

A Semantic MediaWiki extension to manage citation resources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
