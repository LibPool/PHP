# mediawiki/custommessages

> 标签: extension, mediawiki, messages, parserhook

## 简介

MediaWiki extension to print custom messages via tooltips or other JavaScript enabled methods

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
