# mediawiki/chameleon-skin

> 标签: bootstrap, mediawiki, skin, twitter, wiki

## 简介

A highly flexible MediaWiki skin using Bootstrap 5

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
