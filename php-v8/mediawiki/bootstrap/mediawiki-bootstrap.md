# mediawiki/bootstrap

> 标签: bootstrap, extension, mediawiki, twitter, wiki

## 简介

Provides the Bootstrap 5 web front-end framework to MediaWiki skins and extensions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
