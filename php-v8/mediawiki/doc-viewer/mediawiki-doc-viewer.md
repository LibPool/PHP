# mediawiki/doc-viewer

> 标签: document, mediawiki, odf, pdf

## 简介

Extension for embedding a document viewer for PDF, ODF and other kind of documents.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
