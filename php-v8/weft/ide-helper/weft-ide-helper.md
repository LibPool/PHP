# weft/ide-helper

> 标签: PHPStan, autocomplete, ide, psalm, stubs, weft

## 简介

IDE stubs for the weft PHP extension: autocomplete and static analysis only, never executed

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
