# hermesihq/hermesi

> 标签: email, hermesi, notifications, psr-18, push, sdk

## 简介

Server-side client for Hermesi: publish events and read what became of them, keep subscribers in sync, send a direct message, mint subscriber tokens and preference links. Works with any PSR-18 HTTP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
