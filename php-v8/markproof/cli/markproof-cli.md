# markproof/cli

> 标签: PHP

## 简介

Accessibility checks from the command line: finds the problems that can be proven from a page's HTML and quotes the exact markup responsible.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
