# jpmmartin/sylius-nmi-plugin

> 标签: nmi, payment, payment-gateway, sylius, sylius-plugin

## 简介

NMI payment gateway for Sylius: card payments, 3-D Secure, refunds and voids

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
