# minvws/puzi-php

> 标签: UZI, asn.1, asn1, crypto, cryptography, security, signature, x.509, x509

## 简介

PHP library to read data from an UZI pass.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
