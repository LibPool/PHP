# krike/wp-elements

> 标签: PHP

## 简介

An easy to use Library Class to speed the process of writting wordpress plugin and the structure layout of your plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
