# clarifai/clarifai-php-grpc

> 标签: api, artificial intelligence, clarifai, image recognition, text recognition, video recognition

## 简介

Clarifai PHP gRPC client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
