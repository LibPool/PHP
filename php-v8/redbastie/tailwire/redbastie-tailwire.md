# redbastie/tailwire

> 标签: PHP

## 简介

Build reactive web apps without having to write HTML, CSS, or JavaScript! Powered by Laravel Livewire and Tailwind.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
