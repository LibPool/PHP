# pots/php-befunge

> 标签: befunge, befunge-93, esolang, esoteric, interpreter

## 简介

A Befunge-93 interpreter library for PHP with injectable input, strict types and no global state.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
