# lukemadhanga/php-document-parser

> 标签: PHP

## 简介

A PHP parser for getting the text from a .doc, .docx, .rtf or .txt file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
