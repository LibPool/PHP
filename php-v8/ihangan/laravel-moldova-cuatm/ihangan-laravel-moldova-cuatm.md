# ihangan/laravel-moldova-cuatm

> 标签: Moldova, administrative-divisions, cuatm, geo, laravel, localities, locations

## 简介

Moldova's CUATM administrative-territorial divisions (districts, cities, towns and villages) as Eloquent models with multilingual names and coordinates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
