# codebyzach/cbz-shopify

> 标签: graphql, rest-api, shopify, shopify-api

## 简介

PHP library for interacting with the Shopify REST & GraphQL API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
