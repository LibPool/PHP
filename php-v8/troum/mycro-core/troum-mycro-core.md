# troum/mycro-core

> 标签: dto, hydration, messaging, microservices, rabbitmq

## 简介

Core library for marketplace microservices: typed DTOs, RabbitMQ integration, logging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
