# lilicbush/imap-to-yii2

> 标签: extension, imap, yii2

## 简介

Extended Imap agent component for Yii2 (camohob/yii2-imap)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
