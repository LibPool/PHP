# swishdigital/db-dump

> 标签: Craft, backup, cms, craft-plugin, craftcms, db dump

## 简介

A simple way to perform database backups in Craft CMS 3/4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
