# fup/wordpress-middleware

> 标签: PHP

## 简介

This PSR-15 middleware allows you to include Wordpress into your Middleware-Pipeline

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
