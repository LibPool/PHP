# kennysoft/parsedown-tablespan

> 标签: markdown, markdown extra, parsedown, parser

## 简介

An extension of ParsedownExtra that adds support for rowspan and colspan.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
