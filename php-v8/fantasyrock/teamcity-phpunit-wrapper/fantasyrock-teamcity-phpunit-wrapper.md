# fantasyrock/teamcity-phpunit-wrapper

> 标签: PHP

## 简介

A wrapper around PHPUnit using Teamcity service messages to report test progress to Teamcity UI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
