# djiele/multipart

> 标签: form-data, http, laravel, multipart, rest, symfony

## 简介

Parse HTTP multipart/form-data request body. Useful for REST APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
