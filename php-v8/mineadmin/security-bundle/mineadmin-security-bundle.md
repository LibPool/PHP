# mineadmin/security-bundle

> 标签: PHP

## 简介

MineAdmin Security bundle,类似 Symfony/Security 组件，提供用户认证、授权、安全上下文等功能。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
