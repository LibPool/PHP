# trinityrank/laravel-schema-org-builder

> 标签: JSON-LD, laravel, php, schema

## 简介

Schema.org builder. Creating multiple nodes and makes relations between them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
