# zithis/licence-client

> 标签: licence, license, licensing, php, software-licensing, wordpress

## 简介

Framework-independent, product-neutral PHP licence client and runtime integrators for Zithis LicenceServer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
