# andersoncorso/cakephp-app

> 标签: PHP

## 简介

Projeto CakePHP pronto para iniciar qualquer aplicação que necessite de Login e Controle de Acessos com ACL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
