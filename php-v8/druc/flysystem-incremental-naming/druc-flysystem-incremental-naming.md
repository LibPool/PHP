# druc/flysystem-incremental-naming

> 标签: druc, flysystem-incremental-naming

## 简介

Flysystem plugins to increment file names when dealing with duplicates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
