# nng/nnrestapi

> 标签: PHP

## 简介

A RESTful Api Extension for TYPO3. Sets TYPO3 up with everything you need to get your own REST Api up and running without headaches.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
