# citomni/helloai

> 标签: Gemini, ai, anthropic, api, cache, chat, chatbot, citomni, citomni-framework, citomni-php, curl, deterministic, deterministic-config, framework, green-by-design, high-performance, http, llm, low-overhead, openai, php, php8

## 简介

Lean chatbot API integration package for CitOmni: Unified chat request/response format, provider adapters, DB-backed cache, and reuse of the existing Curl infrastructure service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
