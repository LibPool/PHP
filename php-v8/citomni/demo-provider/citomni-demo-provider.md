> 标签: Best-Practices, ai-guidelines, citomni, coding-conventions, composer-package, demo, documentation, example, modular-architecture, php, php-framework, php85, provider, provider-package, reference-implementation

## 简介

Reference provider package for the CitOmni PHP framework: site notices with a Registry, a service, routes, templates, translations, CLI commands and an Operation. Shows each layer the canonical way, with a README per folder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
