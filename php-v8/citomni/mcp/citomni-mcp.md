# citomni/mcp

> 标签: ai, citomni, citomni-framework, citomni-php, deterministic, json-rpc, llm, mcp, mcp-server, model-context-protocol, php, php8, provider, streamable-http, tool-calling

## 简介

MCP (Model Context Protocol) server endpoint for CitOmni applications. Exposes tools registered explicitly in config to AI clients over authenticated Streamable HTTP. Built on the official MCP PHP SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
