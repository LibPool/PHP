# citomni/app-skeleton

> 标签: Skeleton, app-skeleton, application-skeleton, application-template, citomni, citomni-framework, citomni-php, composer, create-project, framework, lightweight-framework, php, php-framework

## 简介

Neutral application skeleton for CitOmni. Provides the app container, core wiring points, and installer lifecycle tooling without assuming HTTP or CLI mode.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
