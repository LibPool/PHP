# citomni/installer

> 标签: citomni, citomni-framework, citomni-php, developer-tools, diff, installer, lifecycle, php, php-framework, php8, repair, repair-service, scaffold, scaffolder, scaffolding, sync

## 简介

Deterministic scaffold materializer and lifecycle tool for CitOmni applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
