# citomni/cli

> 标签: citomni, citomni-framework, citomni-php, cli, cli-app, command-line, command-runner, console, deterministic, green-coding, high-performance, kernel, low-overhead, php, php-cli, php-cli-framework, php-framework, php8, runtime, service-container

## 简介

High-performance CLI runtime for CitOmni apps: kernel boot glue, command runner, console dispatch, and CLI error handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
