# citomni/upload

> 标签: Thumbnails, citomni, file-storage, file-upload, file-validation, files, high-performance, image-upload, local-storage, low-overhead, mime-validation, php, upload, uploads

## 简介

File intake and storage for CitOmni apps: validated uploads, local public/private storage, and image outputs delegated to citomni/image.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
