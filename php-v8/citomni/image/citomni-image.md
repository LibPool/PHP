# citomni/image

> 标签: Thumbnails, Webp, avif, captcha, citomni, exif, gd, high-performance, image, image-conversion, image-crop, image-processing, image-resize, jpeg, low-overhead, php, png

## 简介

Deterministic, reusable image inspection, transformation and encoding, plus captcha rendering, for CitOmni applications and packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
