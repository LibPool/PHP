# citomni/kernel

> 标签: Service-Locator, deterministic, framework, framework-PHP, frameworks, high-performance, kernel, lazy-loading, lazy-loading-components, lightweight, lightweight-framework, low-overhead, php-framework, php8, service-map

## 简介

Ultra-lean application kernel for CitOmni-based apps. PHP, PSR-4, deterministic boot, zero runtime magic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
