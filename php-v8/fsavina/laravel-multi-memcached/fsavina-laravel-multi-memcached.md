# fsavina/laravel-multi-memcached

> 标签: cache, dotenv, framework, laravel, memcached

## 简介

Extract multiple memcached server configuration from .env file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
