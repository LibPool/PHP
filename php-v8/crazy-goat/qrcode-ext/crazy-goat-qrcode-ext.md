# crazy-goat/qrcode-ext

> 标签: barcode, extension, generator, qr, qrcode, simd

## 简介

Native PHP extension backing crazy-goat/scanmephp — the C++ QR encoder behind NativeEncoder

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
