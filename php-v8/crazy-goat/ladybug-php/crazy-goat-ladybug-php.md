# crazy-goat/ladybug-php

> 标签: cypher, extension, ffi, graph, graph-database, kuzu, ladybug, ladybugdb

## 简介

PHP client for LadybugDB (embedded graph database) — native extension and FFI connectors behind one API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
