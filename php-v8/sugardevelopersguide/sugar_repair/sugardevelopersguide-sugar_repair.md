# sugardevelopersguide/sugar_repair

> 标签: PHP

## 简介

CLI Quick Repair and Rebuild for SugarCRM, without going through the web UI or a working bin/sugarcrm console.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
