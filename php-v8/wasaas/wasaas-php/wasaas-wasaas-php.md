# wasaas/wasaas-php

> 标签: api, laravel, messaging, sdk, wasaas, whatsapp

## 简介

Official PHP/Laravel SDK for the Wasaas WhatsApp API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
