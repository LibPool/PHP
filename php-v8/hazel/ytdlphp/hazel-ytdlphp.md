# hazel/ytdlphp

> 标签: cli, download, media, video, youtube, youtube-dl, yt-dlp

## 简介

A typed PHP 8.5+ wrapper for the yt-dlp command-line tool

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
