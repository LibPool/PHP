# labelixa/labelixa

> 标签: TSPL, barcode, cpcl, epl, label, printing, thermal-printer, zebra, zpl

## 简介

Thin PHP client for the Labelixa API: render, validate and convert ZPL, EPL, TSPL and CPCL label code without a printer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
