# korioinc/laravel-expo-integrity

> 标签: korioinc, laravel, laravel-expo-integrity

## 简介

Verify Expo request HMAC signatures and prevent replay in Laravel with file or Redis cache

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
