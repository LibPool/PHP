# developertugrul/paytr-laravel-client

> 标签: Turkish, credit-card, direct-api, iframe, laravel, payment, payment-gateway, paytr

## 简介

Laravel için güncel, güvenli ve kapsamlı PayTR ödeme entegrasyon paketi. Güncel PayTR API dokümantasyonuna tam uyumlu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
