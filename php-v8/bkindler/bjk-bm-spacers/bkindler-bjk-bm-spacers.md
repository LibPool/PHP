# bkindler/bjk-bm-spacers

> 标签: PHP

## 简介

Adds visual spacers and indentation to the TYPO3 backend module menu for improved clarity and navigation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
