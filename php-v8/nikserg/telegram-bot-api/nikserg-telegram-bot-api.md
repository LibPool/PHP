# nikserg/telegram-bot-api

> 标签: bot, bot api, php, telegram

## 简介

PHP Wrapper for Telegram Bot API. poll_answer support added

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
