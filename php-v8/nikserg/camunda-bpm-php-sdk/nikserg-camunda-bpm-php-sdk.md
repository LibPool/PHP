# nikserg/camunda-bpm-php-sdk

> 标签: camunda, rest, sdk

## 简介

PHP SDK for Camunda BPM engine rest service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
