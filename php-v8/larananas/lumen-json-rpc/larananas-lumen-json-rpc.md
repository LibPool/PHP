# larananas/lumen-json-rpc

> 标签: api, json, json-rpc, lumen, php, rpc, server

## 简介

Framework-free JSON-RPC 2.0 server library for modern PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
