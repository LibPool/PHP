# janfish/phpmyadmin-sql-parser

> 标签: analysis, lexer, parser, sql

## 简介

A validating SQL lexer and parser with a focus on MySQL dialect.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
