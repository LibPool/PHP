# fixstacks/module-zero-mollie

> 标签: ideal, magento, magento-open-source, magento2, mollie, payment, zero

## 简介

Zero for Magento Open Source: payment on Mollie's page for Zero Checkout: iDEAL, Bancontact, cards, SEPA, Klarna and every method switched on for the order's currency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
