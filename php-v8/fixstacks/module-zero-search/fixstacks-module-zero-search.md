# fixstacks/module-zero-search

> 标签: magento, magento-open-source, magento2, opensearch, search, typo-tolerance, zero

## 简介

Zero for Magento Open Source: store search that forgives typos and finds categories, pages and posts too.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
