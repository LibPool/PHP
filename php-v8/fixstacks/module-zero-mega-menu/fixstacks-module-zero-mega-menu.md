# fixstacks/module-zero-mega-menu

> 标签: magento, magento-open-source, magento2, mega-menu, navigation, zero

## 简介

Zero for Magento Open Source: a mega menu managed in the admin: full-width panels with subcategory columns, extra links and a promo card, plus the menu's own links; CSS only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
