# fixstacks/module-zero-redirects

> 标签: 404, magento, magento-open-source, magento2, redirects, seo, zero

## 简介

Zero for Magento Open Source: a log of the storefront's 404s, most asked for first, and a 301 redirect for each in one click, with a suggested target from the catalog.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
