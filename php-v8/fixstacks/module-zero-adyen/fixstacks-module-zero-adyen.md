# fixstacks/module-zero-adyen

> 标签: adyen, magento, magento-open-source, magento2, payment, zero

## 简介

Zero for Magento Open Source: payment on Adyen's hosted page for Zero Checkout: cards, wallets and every local method switched on in the Adyen account; HMAC-signed webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
