# fixstacks/module-zero-abandoned-cart

> 标签: abandoned-cart, email, magento, magento-open-source, magento2, zero

## 简介

Zero for Magento Open Source: one reminder email for a cart left with items in it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
