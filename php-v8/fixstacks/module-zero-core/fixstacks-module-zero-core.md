# fixstacks/module-zero-core

> 标签: headless, htmx, magento, magento-open-source, magento2, storefront, zero

## 简介

Zero for Magento Open Source: storefront core for the Zero theme (HTMX fragments for private content, view models, no Knockout).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
