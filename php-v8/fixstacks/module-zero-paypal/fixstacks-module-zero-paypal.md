# fixstacks/module-zero-paypal

> 标签: magento, magento-open-source, magento2, payment, paypal, zero

## 简介

Zero for Magento Open Source: PayPal (Standard and Express) for Zero Checkout, without JavaScript on the shop's pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
