# fixstacks/module-zero-google-analytics

> 标签: ga4, google-analytics, gtm, magento, magento-open-source, magento2, zero

## 简介

Zero for Magento Open Source: GA4 e-commerce events with gtag.js or Google Tag Manager, with Consent Mode v2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
