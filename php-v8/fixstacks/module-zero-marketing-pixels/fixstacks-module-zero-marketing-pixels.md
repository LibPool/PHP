# fixstacks/module-zero-marketing-pixels

> 标签: TikTok , magento, magento-open-source, magento2, marketing, meta-pixel, pixel, zero

## 简介

Zero for Magento Open Source: Meta, TikTok, Pinterest and Microsoft Clarity from an ID in the admin each, loaded only after consent, fed by the storefront's GA4 e-commerce events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
