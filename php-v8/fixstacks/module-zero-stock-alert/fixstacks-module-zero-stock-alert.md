# fixstacks/module-zero-stock-alert

> 标签: back-in-stock, magento, magento-open-source, magento2, stock-alert, zero

## 简介

Zero for Magento Open Source: "Tell me when it's back" on sold-out products, for any visitor, and one email when it is.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
