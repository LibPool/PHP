# prismdb/client

> 标签: client, database, document, driver, key-value, multi-model, prism, prismdb, sql

## 简介

Pure-PHP client for PrismDB over the binary wire protocol (no extension required).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
