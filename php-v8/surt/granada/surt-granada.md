# surt/granada

> 标签: Active Record, database, eager-loading, idiorm, orm, paris

## 简介

Active Record / ORM with eager loading, lazy loading and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
