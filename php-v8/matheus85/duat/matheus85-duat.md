# matheus85/duat

> 标签: backoff, bulkhead, circuit-breaker, fallback, rate-limiter, resilience, retry, timeout

## 简介

Unified resilience patterns for modern PHP: retry, circuit breaker, timeout, bulkhead and fallback, with rate limiting on the roadmap. Zero required dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
