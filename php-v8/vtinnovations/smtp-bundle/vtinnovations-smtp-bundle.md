# vtinnovations/smtp-bundle

> 标签: bundle, contao, email, mailer, smtp

## 简介

Contao backend UI to configure SMTP/API mailer — tests credentials, writes to .env.local, clears cache safely

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
