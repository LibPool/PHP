# vtinnovations/contao-security-suite

> 标签: auditing, contao, contao-bundle, csp, hardening, login-security, monitoring, security, security-dashboard

## 简介

Contao-Erweiterung zur zentralen Analyse, Überwachung und Behebung sicherheitsrelevanter Konfigurationen, Anmeldeaktivitäten, HTTP-Header, CSP, Dateien, Benutzerrechte und Erweiterungen.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
