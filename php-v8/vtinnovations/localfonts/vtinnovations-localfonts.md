# vtinnovations/localfonts

> 标签: contao, dsgvo, fonts, gdpr, google-fonts, performance

## 简介

Local Fonts — crawls the site for Google Fonts, downloads them locally and injects a local stylesheet (GDPR-friendly).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
