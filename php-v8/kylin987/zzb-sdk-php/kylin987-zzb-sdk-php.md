# kylin987/zzb-sdk-php

> 标签: cinema, php, sdk, zzb

## 简介

PHP SDK for ZZB cinema, screen, film query APIs and ticket reporting

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
