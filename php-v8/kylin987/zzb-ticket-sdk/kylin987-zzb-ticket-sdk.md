# kylin987/zzb-ticket-sdk

> 标签: PHP

## 简介

专资办购票交易 SDK（legacy 协议）— 影院/影厅/场次/座位查询、锁座、下单、退票

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
