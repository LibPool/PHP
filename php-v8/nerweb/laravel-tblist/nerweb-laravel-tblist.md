# nerweb/laravel-tblist

> 标签: admin, eloquent, laravel, listing, table, view

## 简介

Simple admin table listing for bootstrap 3 and laravel 4|5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
