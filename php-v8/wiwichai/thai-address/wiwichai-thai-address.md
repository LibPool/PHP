# wiwichai/thai-address

> 标签: address, laravel, thai, thailand

## 简介

A Laravel package for managing Thai addresses. from https://github.com/earthchie/jquery.Thailand.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
