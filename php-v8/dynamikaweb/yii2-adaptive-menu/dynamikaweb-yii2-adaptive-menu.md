# dynamikaweb/yii2-adaptive-menu

> 标签: dynamika, menu, yii2

## 简介

Complex, adaptable, responsive and self-correcting menu.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
