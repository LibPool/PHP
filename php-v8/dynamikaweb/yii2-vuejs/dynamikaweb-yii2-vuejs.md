# dynamikaweb/yii2-vuejs

> 标签: dynamika, vuejs, yii2

## 简介

dependency to use Vue progressive JavaScript Framework with Yii2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
