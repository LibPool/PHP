# dynamikaweb/yii2-youtube

> 标签: dynamika, yii, yii2, youtube

## 简介

environment for use with youtube, has validators, helpers, apis, widgets...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
