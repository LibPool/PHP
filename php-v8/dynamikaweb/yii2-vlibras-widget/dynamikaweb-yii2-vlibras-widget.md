# dynamikaweb/yii2-vlibras-widget

> 标签: dynamika, libras, widget, yii2

## 简介

Widget to use the Brazilian tool vlibras anywhere in the view in yii2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
