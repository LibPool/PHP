# victorio/filament-acceptance

> 标签: acceptance, approval, audit-trail, contracts, e-signature, filament, filament-plugin, laravel, public-links, quotes, victorio

## 简介

Send any Filament record for approval: sealed, tamper-evident versions and provable accept or decline decisions on public links.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
