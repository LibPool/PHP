# victorio/filament-public-links

> 标签: expiring links, filament, filament-plugin, laravel, magic links, public links, share, shareable links, signed url, victorio

## 简介

Expiring, revocable public links to any Eloquent model for Filament: share a record without a login, with an access log, a branded public page and a relation manager.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
