# berecont/contao-percentage-scroll-bundle

> 标签: contao, percent, scroll, toTop

## 简介

Stellt ein Scroll-to-top mit prozentueller Anzeige für Contao bereit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
