# rsc-kit/laravel

> 标签: SSR, laravel, react, react-server-components, rsc, streaming

## 简介

React Server Components for Laravel: the renderer serves the request, Laravel answers it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
