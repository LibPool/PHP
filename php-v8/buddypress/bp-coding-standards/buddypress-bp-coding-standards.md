# buddypress/bp-coding-standards

> 标签: buddypress, phpcs, standards, wordpress

## 简介

PHP_CodeSniffer rules (sniffs) to enforce BuddyPress minimum coding conventions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
