# route-forge/thinkphp

> 标签: SPA, api, frontend, inertia, lazy-loading, metadata, named-route, on-demand, php, react, route, routes, routing, single-source-of-truth, thinkphp, tier, tiered-routing, types, typescript, vue

## 简介

ThinkPHP 命名路由的 SPA 后端：按层级（tier）懒加载的 HTTP 元信息端点、自动发现摘要、TypeScript 类型生成、零注解路由导出。route-forge 项目的 ThinkPHP 适配包。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
