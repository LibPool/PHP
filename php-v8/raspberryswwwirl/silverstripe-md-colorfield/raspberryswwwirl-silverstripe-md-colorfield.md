# raspberryswwwirl/silverstripe-md-colorfield

> 标签: cms, silverstripe

## 简介

Proof-of-concept for Material Design colorpicker built with Vue.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
