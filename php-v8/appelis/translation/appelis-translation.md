# appelis/translation

> 标签: kdyby, nette, translation

## 简介

Integration of Symfony/Translation into Nette Framework Forked from kdyby/translation because we need nette 3 support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
