# mv/postal-address

> 标签: address, adresse, adresse postale, afnor, postal address

## 简介

Manage address in PHP, particulary AFNOR XPZ 10-011 for french postal address

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
