# leocolomb/wp-algolia

> 标签: algolia, search, wordpress

## 简介

A (unofficial) WordPress plugin to use Algolia as a search engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
