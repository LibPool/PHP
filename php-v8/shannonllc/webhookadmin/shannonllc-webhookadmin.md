# shannonllc/webhookadmin

> 标签: sdk, standard-webhooks, webhook, webhookadmin, webhooks

## 简介

PHP SDK for Webhook Admin: send webhooks, manage endpoints and verify signatures.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
