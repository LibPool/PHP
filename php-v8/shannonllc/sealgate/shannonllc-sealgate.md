# shannonllc/sealgate

> 标签: FIDO2, passkey, passkeys, sdk, sealgate, standard-webhooks, webauthn

## 简介

PHP SDK for SealGate: passkey registration and login, users and passkeys, recovery, audit log and stats, and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
