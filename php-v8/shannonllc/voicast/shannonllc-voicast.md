# shannonllc/voicast

> 标签: conversational-ai, sdk, standard-webhooks, voicast, voice, voice-ai

## 简介

PHP SDK for voicast: manage agents, tenants and calls, and verify webhooks and in-call tool requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
