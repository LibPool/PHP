# shannonllc/avacast

> 标签: WebRTC, avacast, avatar, realtime, sdk

## 简介

PHP SDK for avacast realtime avatars: create sessions, make the avatar speak and read usage from your server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
