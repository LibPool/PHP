# janisvepris/zpl-builder-php

> 标签: barcode, label, printer, zebra, zpl

## 简介

A simple PHP library for building ZPL (Zebra Programming Language) label payloads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
