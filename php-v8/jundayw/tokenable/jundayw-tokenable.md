# jundayw/tokenable

> 标签: Authentication, SPA, SSR, api-auth, cookie-auth, jwt, laravel, multi-model, multi-platform, oauth, refresh-token, token

## 简介

Laravel Tokenable provides multi-model and multi-platform authentication with refresh tokens for APIs, SPAs, and SSR.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
