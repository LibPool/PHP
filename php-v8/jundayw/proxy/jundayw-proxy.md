# jundayw/proxy

> 标签: HOOK, annotation, aop, interceptor, proxy, service proxies

## 简介

A lightweight, type-safe, inheritance-based proxy and interception framework for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
