# jundayw/composer-version-plugin

> 标签: ComposerVersionPlugin, composer version, composer-version-plugin

## 简介

A Composer plugin for semantic version bumping, Git commit and tag automation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
