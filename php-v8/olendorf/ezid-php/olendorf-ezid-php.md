# olendorf/ezid-php

> 标签: api, ark, client, doi, http client, rest

## 简介

A library to simplify interacting with the EZID API for managing DOIs and ARKs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
