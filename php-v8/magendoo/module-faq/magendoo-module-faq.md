# magendoo/module-faq

> 标签: PHP

## 简介

Magento 2 FAQ and Product Questions module — SEO-optimized FAQ pages, product Q&A tabs, ask-a-question forms, ratings, and admin knowledge base management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
