# empiricompany/maho-nocacheheader

> 标签: PHP

## 简介

Adds Cache-Control: no-cache, private header globally on all frontend pages, restoring OpenMage default behavior. Configurable via admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
