# dmstr/yii2-pages-module

> 标签: Sitemap, extension, navigation, yii2

## 简介

Application sitemap and navigation manager module for Yii 2.0 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
