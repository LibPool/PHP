# dmstr/php-bc4-client

> 标签: api, basecamp, basecamp4, bc3-api, client, oauth

## 简介

Modern PHP client for Basecamp 4 (BC3 API) — OAuth 2.0 with refresh-token rotation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
