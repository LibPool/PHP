# dmstr/yii2-rest-sdk

> 标签: extension, rest, yii2

## 简介

Yii2 extension providing typed entities, attribute mapping, and resource abstraction for consuming REST APIs via Guzzle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
