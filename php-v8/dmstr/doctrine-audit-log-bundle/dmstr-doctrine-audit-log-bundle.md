# dmstr/doctrine-audit-log-bundle

> 标签: PHP

## 简介

Audit logging for Doctrine entities via Gedmo Loggable: concrete LogEntry entity exposed as read-only API Platform admin resource.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
