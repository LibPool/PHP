# ramiroestrella/sendgrid-campaigns-sdk

> 标签: PHP

## 简介

A PHP SDK for managing SendGrid single send campaigns, including creation, scheduling, and analytics.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
