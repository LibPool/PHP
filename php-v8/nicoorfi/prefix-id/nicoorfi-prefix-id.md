# nicoorfi/prefix-id

> 标签: id, nicoorfi, prefix, unique

## 简介

Generate unique, URL-safe, alphanumeric IDs with a specified prefix.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
