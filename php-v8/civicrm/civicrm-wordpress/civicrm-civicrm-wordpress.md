# civicrm/civicrm-wordpress

> 标签: PHP

## 简介

Open source constituent relationship management for non-profits, NGOs and advocacy organizations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
