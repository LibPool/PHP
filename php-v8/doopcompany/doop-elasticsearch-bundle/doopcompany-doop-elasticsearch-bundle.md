# doopcompany/doop-elasticsearch-bundle

> 标签: elasticsearch, sulu

## 简介

Small bundle for allowing specific Elasticsearch indexes with mapped properties in Sulu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
