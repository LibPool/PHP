# qobo/cakephp-roles-capabilities

> 标签: acl, cakephp, roles, security

## 简介

Roles and Capabilities plugin for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
