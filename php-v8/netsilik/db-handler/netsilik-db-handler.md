# netsilik/db-handler

> 标签: database, mariadb, mysql, mysqli

## 简介

PHP wrapper around the MySQLi Database Extensions, providing intuitive access to prepared queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
