# webrgp/craft-ignition

> 标签: Craft, cms, craftcms, error, error-reporting, ignition, php

## 简介

Ignition error handling alternative for Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
