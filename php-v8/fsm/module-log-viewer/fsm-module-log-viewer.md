# fsm/module-log-viewer

> 标签: admin, log, log-viewer, mage-os, magento, magento2

## 简介

Magento / Mage-OS admin Log Viewer with per-role glob patterns and download ACL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
