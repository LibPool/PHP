# marcusamatos/jvslayout

> 标签: developer, jvs, jvslayout, module, zendframework2, zf2

## 简介

JvsLayout provides a suite of classes to layout manager.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
