# queuewatch/laravel

> 标签: failed-jobs, laravel, monitoring, notifications, queue, queuewatch

## 简介

Laravel package for Queuewatch - Real-time queue failure monitoring

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
