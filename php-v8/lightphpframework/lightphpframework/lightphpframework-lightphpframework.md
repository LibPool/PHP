# lightphpframework/lightphpframework

> 标签: framework, lightphpframework, lpf, mvc, php

## 简介

LightPHPFramework (LPF) is a simple PHP 5 web framework. It is extremely portable, works on almost any server and provide a clean and readable syntax.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
