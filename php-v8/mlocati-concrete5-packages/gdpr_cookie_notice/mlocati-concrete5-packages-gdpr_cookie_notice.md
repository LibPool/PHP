# mlocati-concrete5-packages/gdpr_cookie_notice

> 标签: concrete, concrete5, concreteCMS, consent, cookie, gdpr, package, tag manager

## 简介

A ConcreteCMS/concrete5 package to display a cookie-based notice (useful for GDPR purposes)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
