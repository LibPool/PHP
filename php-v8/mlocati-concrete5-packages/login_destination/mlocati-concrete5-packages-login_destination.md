# mlocati-concrete5-packages/login_destination

> 标签: Users, access, concrete5, destination, groups, login, package, page

## 简介

Specify where users should be redirected upon login.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
