# slepic/psr-http-message-tracy-panel

> 标签: PHP

## 简介

A panel for Tracy, that traces PSR HTTP messages travelling between your PHP backend and other HTTP servers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
