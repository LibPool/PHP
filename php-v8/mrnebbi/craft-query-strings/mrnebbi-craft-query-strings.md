# mrnebbi/craft-query-strings

> 标签: PHP

## 简介

Add your query strings back into your Craft CMS pagination. Pull an array of all query strings, including duplicate keys

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
