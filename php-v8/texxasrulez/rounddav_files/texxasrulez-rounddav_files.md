# texxasrulez/rounddav_files

> 标签: PHP

## 简介

Roundcube plugin to enable RoundDAV Attachments and provides a File page linked to your Files page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
