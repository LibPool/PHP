# vatsim/xml

> 标签: feeds, laravel, vatsim, xml

## 简介

A simple laravel package for retrieving data from public VATSIM XML Feeds.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
