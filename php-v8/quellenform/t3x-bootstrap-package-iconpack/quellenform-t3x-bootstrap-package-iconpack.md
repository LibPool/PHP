# quellenform/t3x-bootstrap-package-iconpack

> 标签: bootstrap, extension, icons, typo3

## 简介

Replaces the icons in bootstrap_package with iconpacks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
