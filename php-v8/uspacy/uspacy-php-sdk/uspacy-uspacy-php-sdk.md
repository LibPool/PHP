# uspacy/uspacy-php-sdk

> 标签: Messenger, api, crm, sdk, uspacy

## 简介

PHP SDK for Uspacy – a single workspace for managing key processes of your organization with a focus on results.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
