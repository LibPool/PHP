# quitscope/laravel-flow-tracer

> 标签: architecture, diagram, flow, graphviz, laravel, tracing, visualization

## 简介

Trace Laravel request flows and export Graphviz diagrams from routes, controller actions, services, and models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
