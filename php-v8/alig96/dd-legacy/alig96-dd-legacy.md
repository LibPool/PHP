# alig96/dd-legacy

> 标签: dd, debug, dump

## 简介

Provides mechanisms for walking through any arbitrary PHP variable (for legacy projects)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
