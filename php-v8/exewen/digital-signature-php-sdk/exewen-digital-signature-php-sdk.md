# exewen/digital-signature-php-sdk

> 标签: api, cryptography, digital signature, security

## 简介

(Custom) An SDK for using eBay's APIs that require a digital signature

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
