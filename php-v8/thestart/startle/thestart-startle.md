# thestart/startle

> 标签: PHP

## 简介

A sleek WordPress error and downtime notifier that keeps you in the loop via Slack and email. Silent when all's good, loud when it matters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
