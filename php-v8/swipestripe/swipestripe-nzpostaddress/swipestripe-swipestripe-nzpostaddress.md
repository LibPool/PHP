# swipestripe/swipestripe-nzpostaddress

> 标签: addresses, e-commerce, ecommerce, shop, silverstripe, swipe stripe, swipestripe

## 简介

Module for nzpost address lookup in SwipeStripe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
