# hooshid/imdb-scraper

> 标签: graphql, imdb, imdb-metadata, imdb-scraper, imdb-scraping, imdb-webscrapping, imdb.com, movie, php, scraper, scraping, series

## 简介

Library for retrieving movie, tv series information from imdb.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
