# exantrix/module-marketplace

> 标签: PHP

## 简介

Vendez vos produits Magento sur la marketplace Exantrix : catalogue et stock synchronises, commandes notifiees.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
