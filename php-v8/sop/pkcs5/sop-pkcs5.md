# sop/pkcs5

> 标签: key-derivation, password, pbes1, pbes2, pbkdf1, pbkdf2, pkcs5

## 简介

A PHP implementation of PKCS #5 password-based cryptography.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
