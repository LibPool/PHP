# sop/crypto-bridge

> 标签: cryptography, decrypt, encrypt, pkcs, sign, verify

## 简介

A PHP library providing cryptography support for various PKCS applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
