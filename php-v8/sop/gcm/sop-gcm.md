# sop/gcm

> 标签: AES-GCM, Galois Counter Mode, aes, decrypt, encrypt, galois, gcm

## 简介

A PHP library for Galois/Counter Mode encryption with AES.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
