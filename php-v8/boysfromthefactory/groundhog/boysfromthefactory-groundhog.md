# boysfromthefactory/groundhog

> 标签: Boys From The Factory, eloquent, groundhog, laravel, recurrence, rrule

## 简介

Declarative recurring Eloquent models backed by RFC 5545 rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
