# punktde/quickedit

> 标签: Quickedit, TYPO3 CMS, pages, toolbar

## 简介

This extension allows to define quick edit buttons for page property fields.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
