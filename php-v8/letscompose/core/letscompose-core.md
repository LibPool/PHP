# letscompose/core

> 标签: array mapping, letscompose, object mapping, php

## 简介

LetsCompose Core package - object and array mapping via yaml definition, and other LetsCompose core tools

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
