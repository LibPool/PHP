# sinensia/nova-range-filter

> 标签: filter, laravel, nova, nova-component, range

## 简介

A reusable range filter component for Laravel Nova with input masking and formatting.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
