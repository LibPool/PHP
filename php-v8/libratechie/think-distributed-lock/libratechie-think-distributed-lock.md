# libratechie/think-distributed-lock

> 标签: PHP

## 简介

一个专为 ThinkPHP 框架设计的轻量级分布式锁组件，帮助开发者轻松实现高并发场景下的资源互斥访问

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
