# regexp1987/blake3

> 标签: PHP

## 简介

Native PHP extension for the BLAKE3 cryptographic hash function — 4x faster than SHA-256 with SIMD support (AVX-512, AVX2, SSE4.1, SSE2, NEON)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
