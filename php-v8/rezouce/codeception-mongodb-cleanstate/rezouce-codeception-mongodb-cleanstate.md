# rezouce/codeception-mongodb-cleanstate

> 标签: PHP

## 简介

Drop MongoDB databases to ensure each test using MongoDB are in a clean environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
