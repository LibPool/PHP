# grinet/duplicatefix

> 标签: magento, magento2

## 简介

Fixes 'Item with the same ID “ID” already exists' error. Inspired from http://www.rscoder.com/2019/12/magento-2-how-to-resolve-item-with-same.html

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
