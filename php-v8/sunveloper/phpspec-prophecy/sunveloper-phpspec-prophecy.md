# sunveloper/phpspec-prophecy

> 标签: Double, Dummy, fake, mock, spy, stub

## 简介

Highly opinionated mocking framework for PHP 5.3+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
