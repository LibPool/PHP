# jason-munro/cypht

> 标签: atom, cypht, e-mail, imap, jmap, managesieve, news-reader, php, rss, sieve, smtp, webmail, webmail-client

## 简介

Lightweight Open Source webmail written in PHP and JavaScript

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
