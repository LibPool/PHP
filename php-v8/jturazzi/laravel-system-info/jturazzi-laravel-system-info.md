# jturazzi/laravel-system-info

> 标签: health-check, laravel, monitoring, status, system-info

## 简介

Exposes a token-protected /api/system-info endpoint (versions, database, queue, disk, health) for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
