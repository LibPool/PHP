# stacktoast/installer

> 标签: billing, boilerplate, cli, inertia, installer, laravel, livewire, saas, saas-boilerplate, saas-starter-kit, scaffolding, starter-kit, stripe, subscriptions

## 简介

Installer for Stack Toast, the Laravel SaaS starter kit. Starts a project from any edition, and checks a machine meets the requirements first.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
