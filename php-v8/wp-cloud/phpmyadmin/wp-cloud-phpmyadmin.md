# wp-cloud/phpmyadmin

> 标签: mysql, phpmyadmin, web

## 简介

Deployment ready version of phpmyadmin-all-languages. All Languages; without: doc, examples, setup folders!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
