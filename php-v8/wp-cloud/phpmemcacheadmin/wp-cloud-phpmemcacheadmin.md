# wp-cloud/phpmemcacheadmin

> 标签: memcache, memcached, phpmemcacheadmin, web

## 简介

Graphic stand-alone administration for memcached to monitor and debug purpose

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
