# exeba/simplesamlphp-module-hashsqlauth

> 标签: hash, simplesamlphp, sqlauth

## 简介

This is a authentication module for authenticating a user against a SQL database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
