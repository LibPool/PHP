# tvorwachs/phpass

> 标签: blowfish, crypt, hash, password, portable, security

## 简介

Portable PHP password hashing framework based on http://openwall.com/phpass/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
