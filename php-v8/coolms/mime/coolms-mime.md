# coolms/mime

> 标签: RFC5322, email, mime, parser, rfc2045, streaming

## 简介

A streaming MIME parser for PHP: RFC 5322 / 2045-2049 / 2047 / 2231 / 2183 / 6532, including message/rfc822 and message/global. No dependencies, no ext-mailparse.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
