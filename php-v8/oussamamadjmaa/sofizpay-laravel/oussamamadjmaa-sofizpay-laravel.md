> 标签: Algeria, Dz, Ooredoo, algerie-telecom, api-wrapper, bill-payment, carte-interbancaire, cib, cib-payment, djezzy, idoom, internet-recharge, laravel, mobile-recharge, mobilis, payment, payment-gateway, phone-recharge, php, recharge, sdk, sofizpay, sonelgaz

## 简介

A Laravel wrapper for the SofizPay API — CIB card payments and prepaid service operations (phone, internet, game recharge, bill payments) for Algeria, with typed DTOs, response objects, and built-in sandbox mocking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
