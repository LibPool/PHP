# mf/collections-php

> 标签: PHP

## 简介

Collections for PHP - It's basically a syntax sugar over classic array structure, which allows you to use it as classic array, but adds some cool features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
