# mf/docker-ip

> 标签: PHP

## 简介

Finds suitable IP from `ifconfig` and then distribute this IP into hosts and docker file and allows revert changes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
