# hatchetaustralia/fakerphp-loremflickr-kittens

> 标签: LoremFlickr, faker, images, php

## 简介

Alternative image provider for fakerphp using loremflickr.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
