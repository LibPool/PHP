# un-dev-suisse/laravel-files-storage

> 标签: PHP

## 简介

File stores for Laravel: named stores over filesystem disks, optional AES-256-GCM encryption with key rotation, an S3 round-trip check, and for spatie/laravel-backup an optional guard and an optional encryption of the archives with age.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
