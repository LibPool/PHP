# api-check/magento2-module

> 标签: addressapi, addressvalidation, apicheck, magento2, postalcodeapi

## 简介

A Magento 2 module that adds address suggestions to the checkout

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
