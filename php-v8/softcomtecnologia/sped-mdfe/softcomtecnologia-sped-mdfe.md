# softcomtecnologia/sped-mdfe

> 标签: mdfe, nfephp, sped

## 简介

API para geração e comunicação da MDFe com as SEFAZ autorizadoras.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
