# sms-proxima/sdk

> 标签: api, notification, php, proxima, sms

## 简介

Official PHP SDK for the SMS Proxima API — send SMS, track delivery receipts and manage blacklists

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
