# sms-proxima/notifier

> 标签: Bridge, notifier, proxima, sms, symfony

## 简介

Symfony Notifier Bridge for SMS Proxima — send SMS via the SMS Proxima API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
