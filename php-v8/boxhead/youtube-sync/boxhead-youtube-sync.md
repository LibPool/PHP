# boxhead/youtube-sync

> 标签: Craft, cms, craft-plugin, craftcms, youtube

## 简介

Communicate and process data from the YouTube Data API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
