# boxhead/church-suite

> 标签: Craft, churchsuite, cms, craft-plugin, craftcms

## 简介

Communicate and process data to and from the ChurchSuite API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
