# algolia/algoliasearch-magento-2-es-compatibility

> 标签: PHP

## 简介

Algolia Search ES Compatibility module for Magento >=2.3.1|>=2.2.8 and Algolia Search >=1.12 extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
