# asciisd/zoho-v8

> 标签: ZOHO-CRM, Zoho, api, crm, laravel, wrapper

## 简介

Minimal Laravel wrapper for Zoho CRM PHP SDK 8.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
