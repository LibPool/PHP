# asciisd/cashier-core

> 标签: cashier, laravel, payment, payment-processing, psp, webhooks

## 简介

Connection-based multi-provider payment engine for Laravel: contracts, DTOs, webhook pipeline, fees, and withdrawal workflow

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
