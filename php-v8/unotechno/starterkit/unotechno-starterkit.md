# unotechno/starterkit

> 标签: cms, inertia, laravel, react, starter-kit

## 简介

Laravel + React/Inertia starter kit with a CMS admin panel, JWT API, OTP, SMS and push notifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
