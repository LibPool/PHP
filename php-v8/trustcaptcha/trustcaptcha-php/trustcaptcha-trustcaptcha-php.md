> 标签: backend-security, bot-detection, captcha, eu, european-union, gdpr, made-in-germany, php, php-library, privacy, security, server-security, spam-protection, trustcaptcha, user-verification

## 简介

TrustCaptcha for PHP, providing captcha, security features, and GDPR-compliant user verification.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
