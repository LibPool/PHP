# marcustansoon/spatie-calendar-links-adapter

> 标签: PHP

## 简介

PHP Adapter for Spatie/CalenderLinks (Google/iCal/Yahoo Calendar)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
