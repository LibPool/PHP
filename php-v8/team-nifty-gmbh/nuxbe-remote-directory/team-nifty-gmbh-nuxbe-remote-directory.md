# team-nifty-gmbh/nuxbe-remote-directory

> 标签: PHP

## 简介

Serves Flux ERP contacts as a remote directory for phone clients (XML phonebook, searchable by name, company or number).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
