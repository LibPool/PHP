# marrow/anvil

> 标签: development-environment, docker, docker-compose, framework, marrow

## 简介

A local Docker development environment for Marrow applications — Sail's role, Marrow's own name (forge shapes the code, Anvil runs it).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
