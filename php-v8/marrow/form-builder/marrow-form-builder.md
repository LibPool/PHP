# marrow/form-builder

> 标签: Forms, framework, marrow, twig, validation

## 简介

Django-style declarative forms for Marrow — define fields on the backend, validate with the framework's existing rule engine, render on the frontend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
