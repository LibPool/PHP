# marrow/ui

> 标签: alpinejs, components, framework, marrow, tailwind, twig, ui

## 简介

A ready-to-use Tailwind + Alpine.js component library for Marrow — 30+ components (Button, Card, Select, Breadcrumb, a Form bridge to marrow/form-builder, and more) built on the framework's existing Component/ComponentRegistry primitives.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
