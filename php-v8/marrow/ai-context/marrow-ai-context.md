# marrow/ai-context

> 标签: agents, agents.md, ai, developer-tools, framework, marrow

## 简介

Generates AGENTS.md — a live, accurate map of an Marrow app (modules, routes, config) plus Marrow-specific conventions and gotchas — for AI coding agents (and human contributors) to read before exploring the codebase.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
