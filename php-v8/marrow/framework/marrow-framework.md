# marrow/framework

> 标签: framework, hmvc, laravel, marrow, modular, module, php, tailwind

## 简介

Marrow is a PHP 8.2+ framework designed for modular, scalable, and testable applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
