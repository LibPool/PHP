# ldebrouwer/distance

> 标签: coordinates, distance, gps, latitude, location, longitude, php

## 简介

Distance helps you calculate the distance between GPS coordinates, in vanilla PHP. Pure and simple.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
