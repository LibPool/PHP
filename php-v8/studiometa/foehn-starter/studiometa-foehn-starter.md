# studiometa/foehn-starter

> 标签: foehn, starter, tempest, theme, wordpress

## 简介

Starter theme for Foehn — a modern WordPress framework powered by Tempest.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
