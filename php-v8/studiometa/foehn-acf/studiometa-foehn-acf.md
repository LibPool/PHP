# studiometa/foehn-acf

> 标签: acf, advanced-custom-fields, attributes, blocks, discovery, foehn, wordpress

## 简介

Advanced Custom Fields integration for Foehn — ACF blocks, field groups and options pages, discovered from attributes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
