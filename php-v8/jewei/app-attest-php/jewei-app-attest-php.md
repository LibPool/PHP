# jewei/app-attest-php

> 标签: app-attest, apple, assertion, attestation, devicecheck, ios

## 简介

Verify Apple App Attest attestations and assertions in PHP, with no dependencies beyond ext-openssl

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
