# cryptoman3/graph-sdk

> 标签: facebook, sdk

## 简介

Facebook SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/facebook/php-graph-sdk

- Packagist 页面：https://packagist.org/packages/cryptoman3%2Fgraph-sdk
