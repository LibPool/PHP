# unit-testing/mockery-helper

> 标签: mockery, phpunit, testing, trait

## 简介

a simple trait for convenient implementation of mockery mocks and spies in PHPUnit tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
