# iron-io/iron_cache

> 标签: cache, cloud storage, iron, iron_cache, store

## 简介

Client binding for IronCache (A key/value store in the cloud)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
