# forumaker/yandex-smartcaptcha

> 标签: captcha, flarum, flarum-extension, smartcaptcha, yandex

## 简介

Adds Yandex SmartCaptcha to the login and registration modals

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
