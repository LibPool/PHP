# forumaker/magicslider

> 标签: banner, flarum, flarum-extension, hero, image, magic, slider

## 简介

MagicSlider replaces the WelcomeHero with a configurable image slider

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
