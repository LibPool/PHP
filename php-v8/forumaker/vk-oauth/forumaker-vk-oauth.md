# forumaker/vk-oauth

> 标签: flarum, flarum-extension, oauth, vk, vkid, vkontakte

## 简介

Adds a VK ID OAuth provider for FoF OAuth

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
