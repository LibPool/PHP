# forumaker/steam-oauth

> 标签: OpenId, flarum, flarum-extension, oauth, steam, steamid

## 简介

Adds a Steam OAuth provider for FoF OAuth

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
