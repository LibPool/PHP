# forumaker/magicbb

> 标签: bbcode, composer, flarum, flarum-extension, formatting, magic, toolbar

## 简介

Adds handy buttons, extra BBCodes and new text formatting styles

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
