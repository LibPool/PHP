# forumaker/bento

> 标签: flarum, flarum-extension, grid, navigation, tags, tile

## 简介

Replaces the default navigation on the tags page with tiles, pills, or a horizontal slider

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
