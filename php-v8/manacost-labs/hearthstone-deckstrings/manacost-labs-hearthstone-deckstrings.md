# manacost-labs/hearthstone-deckstrings

> 标签: deckstrings, hearthstone

## 简介

Dependency-free Hearthstone deckstring codec, validation, and clipboard export library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
