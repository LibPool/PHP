# tina4stack/tina4php-graphql

> 标签: PHP

## 简介

Lightweight GraphQL engine for Tina4 PHP — recursive descent parser, executor, auto-schema from ORM

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
