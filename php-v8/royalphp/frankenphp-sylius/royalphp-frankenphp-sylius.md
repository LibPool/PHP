# royalphp/frankenphp-sylius

> 标签: frankenphp, royalphp, sylius, symfony

## 简介

Starting point for Sylius eCommerce powered by FrankenPHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
