# royalphp/sylius-bootstrap-theme

> 标签: bootstrap, royalphp, sylius, sylius-theme

## 简介

Minimalist theme for Sylius projects using Bootstrap css-framework and tools like Sass and Typescript.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
