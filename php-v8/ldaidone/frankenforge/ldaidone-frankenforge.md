# ldaidone/frankenforge

> 标签: frankenphp, htmx, kernel, php, worker-mode

## 简介

Minimal FrankenPHP worker-mode kernel for building HTMX-first applications in raw PHP 8.3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
