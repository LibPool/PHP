# elcheco/nette-phinx-bridge

> 标签: PHP

## 简介

Extension integrating Phinx commands to contributte/console in Nette Framework using the framework's config file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
