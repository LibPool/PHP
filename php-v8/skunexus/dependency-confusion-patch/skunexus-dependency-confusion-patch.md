# skunexus/dependency-confusion-patch

> 标签: PHP

## 简介

This repository was created to reserve a namespace and eliminate dependency confusion attack. Do not use it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
