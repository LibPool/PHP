# warsawmedia/newrelic-instrumentation

> 标签: apm, instrumentation, new relic, typo3

## 简介

Improves New Relic transaction naming, grouping and custom parameters for TYPO3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
