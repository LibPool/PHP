# alibabacloud/mpaas

> 标签: alibaba, alibabacloud, aliyun, cloud, library, mpaas, sdk

## 简介

Alibaba Cloud MPaaS SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
