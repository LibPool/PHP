# cmpas2/ayforrest

> 标签: force, force.com, laravel, rest, salesforce

## 简介

Salesforce / Force.com REST API Client for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
