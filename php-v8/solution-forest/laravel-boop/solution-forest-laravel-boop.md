# solution-forest/laravel-boop

> 标签: boop, laravel, laravel-boop, notifications, push, solutionforest

## 简介

Send events to a self-hosted Boop server from Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
