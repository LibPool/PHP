# t3graf/website-toolbox

> 标签: PHP

## 简介

Versatile, universal and very flexibly customizable website toolbox. It offers a simplified configuration of the website, a tool for choosing themes (templates) and allows automatic integration of a project sitepackage. See the documentation for more information.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
