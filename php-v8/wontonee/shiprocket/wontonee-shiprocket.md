# wontonee/shiprocket

> 标签: bagisto, ecommerce, laravel, logistics, shipment, shiprocket

## 简介

Shiprocket integration for Bagisto to manage shipments, track orders, and automate logistics from your admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
