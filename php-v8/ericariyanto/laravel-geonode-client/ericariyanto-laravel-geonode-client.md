# ericariyanto/laravel-geonode-client

> 标签: Eric Ariyanto, laravel, laravel-geonode-client

## 简介

Modern Laravel client for GeoNode API v2+ (datasets, layers, styles, metadata).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
