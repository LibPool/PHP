# kompas/flysystem

> 标签: WebDAV, aws, dropbox, filesystem, ftp, remote, s3, sftp

## 简介

Filesystem abstraction, but easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
