# sparkcrm/spark-sdk

> 标签: checkout, dtc, payments, sdk, sparkcrm

## 简介

PHP SDK for the SparkCRM DTC Checkout API (init, lead, order, upsell, complete, PayPal, refunds).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
