# thinreports-php/thinreports-php

> 标签: pdf, reporting

## 简介

An implementation of Thinreports Generator in PHP. It provides easy and simple way for generating a PDF on pure PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
