# 20steps/versioning-bundle

> 标签: semantic, semver, version, versioning

## 简介

Symfony2|3 application versioning, simple console command to manage version (with handlers e.g. git tag) of your application using Semantic Versioning 2.0.0 recomendations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
