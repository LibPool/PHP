# lara-zeus/rain

> 标签: filamentphp, frontpage, landing page, lara-zeus, laravel, widgets

## 简介

Zeus Dynamic Dashboard to manage widgets for filament dashboard your website landing page

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
