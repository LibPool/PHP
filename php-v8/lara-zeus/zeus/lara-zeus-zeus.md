# lara-zeus/zeus

> 标签: filament, framework, laravel, larazeus

## 简介

a standalone app., a Starter Kit; it's pre-configured to run all Zeus packages and some extra perks..

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
