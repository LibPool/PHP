# cmsig/seal-symfony-bundle

> 标签: Bridge, abstraction, algolia, bundle, cmsig, elasticsearch, integration, loupe, meilisearch, opensearch, redisearch, seal, search, search-abstraction, search-client, solr, symfony, symfony-bundle, typesense

## 简介

An integration of CMS-IG SEAL search abstraction into Symfony Framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
