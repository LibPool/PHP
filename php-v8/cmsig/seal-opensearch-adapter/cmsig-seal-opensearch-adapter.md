# cmsig/seal-opensearch-adapter

> 标签: cmsig, cmsig-seal-adapter, opensearch, seal, seal-adapter, search-client

## 简介

An adapter to support opensearch in cmsig/seal search abstraction.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
