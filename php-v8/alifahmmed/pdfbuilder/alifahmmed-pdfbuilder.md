# alifahmmed/pdfbuilder

> 标签: bootstrap, css, headless-chromium, html-to-pdf, javascript, laravel, laravel-package, pdf, pdf-builder, pdf-generation, pdf-generator, php, tailwindcss, wkhtmltopdf

## 简介

Laravel 12 package: generate PDF via headless chromium or wkhtmltopdf without Node.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
