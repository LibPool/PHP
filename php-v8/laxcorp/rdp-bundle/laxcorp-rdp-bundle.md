# laxcorp/rdp-bundle

> 标签: Windows Remote Desktop, rdp file generator

## 简介

Generate Windows Remote Desktop file.rdp files.rdp.zip

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
