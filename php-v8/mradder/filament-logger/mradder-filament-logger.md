# mradder/filament-logger

> 标签: activity-log, activity-tracking, admin-panel, alerts, audit-log, compliance, exports, filament, filament-logger, filamentphp, laravel, laravel-activitylog, security, spatie-activitylog

## 简介

Audit logging, activity tracking, exports, alerts, and dashboards for Filament admin panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
