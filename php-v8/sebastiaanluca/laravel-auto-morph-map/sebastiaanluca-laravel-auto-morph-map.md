# sebastiaanluca/laravel-auto-morph-map

> 标签: class, eloquent, laravel, map, model, morph, php

## 简介

Automatically alias and map the polymorphic types of Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
