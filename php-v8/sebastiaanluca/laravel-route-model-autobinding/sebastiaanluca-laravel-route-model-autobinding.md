# sebastiaanluca/laravel-route-model-autobinding

> 标签: bind, eloquent, laravel, model, php, route

## 简介

Automatically bind Eloquent models to be used as route segments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
