# in-square/pimcore-simple-search-bundle

> 标签: pimcore, pimcore-bundle, pimcore-plugin, search

## 简介

MySQL FULLTEXT based frontend search index for Pimcore (Documents + DataObjects).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
