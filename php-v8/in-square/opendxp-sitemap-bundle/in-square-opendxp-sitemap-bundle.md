# in-square/opendxp-sitemap-bundle

> 标签: Sitemap, opendxp, opendxp-bundle, opendxp-plugin

## 简介

Static XML sitemap generator for OpenDXP (Documents + DataObjects).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
