# inanepain/http

> 标签: client, http, inane, inanepain, library, psr-18, psr-7, request, response, serve

## 简介

Http client (psr-18), request and response object message interfaces (psr-7).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
