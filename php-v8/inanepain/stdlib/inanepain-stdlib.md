# inanepain/stdlib

> 标签: array, config, exception, inane, inanepain, json, notice, stdlib

## 简介

Common classes that cover a wide range of cases that are used throughout the inanepain libraries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
