# orebarranco/filament-ddd-starter

> 标签: Espanol, boilerplate, ddd, filament, laravel, spanish, starter-kit

## 简介

Starter kit Laravel para proyectos en español, con FilamentPHP v5 y arquitectura Domain-Driven Design.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
