# meita/zatca-engine

> 标签: E-Invoice, ZATCA, php-library, qr-code, ubl

## 简介

Framework-agnostic ZATCA Phase 2 engine for generating UBL 2.1 e-invoices (XML, hashing, signing, QR, chaining).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
