# meita/jsonbolt

> 标签: cache, database, dbe, file, framework, json, jsonbolt, laravel, nosql, orm, storage

## 简介

JSONBolt: fast JSON file database engine with relations and caching for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
