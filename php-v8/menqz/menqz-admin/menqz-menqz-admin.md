# menqz/menqz-admin

> 标签: admin, form, free, grid, laravel, menqz, menqz-admin, open

## 简介

menqz-admin. Open-source Laravel Admin panel. No pro or paid package, free & open. Based on open-admin

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
