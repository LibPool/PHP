# davix/customs-domain

> 标签: Tariff, commodity-code, compliance, customs, hmrc, hs-code, uk-trade-tariff

## 简介

Platform-agnostic customs and tariff domain logic: commodity code validation, UK Trade Tariff mapping, and compliance rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
