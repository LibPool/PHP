# lornequinn/auth

> 标签: PHP

## 简介

ARCHIVED - Fortify-based authentication with Livewire views for Laravel. Superseded by the official Laravel Livewire starter kit (Fortify variant).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
