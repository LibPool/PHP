# zooxsmart/richfilemanager

> 标签: connector, filemanager, php, plugin, richfilemanager

## 简介

PHP connector for RichFilemanager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
