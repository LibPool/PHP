# gigerit/laravel-mysql-optimizer

> 标签: database, laravel, mariadb, mysql, optimize, table

## 简介

A laravel package that optimizes mysql/mariadb database tables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
