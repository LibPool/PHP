# gigerit/larapex-charts

> 标签: apexcharts, arielmejiadev, charts, gigerIT, larapex

## 简介

Package to provide easy api to build apex charts on Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
