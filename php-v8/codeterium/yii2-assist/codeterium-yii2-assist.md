# codeterium/yii2-assist

> 标签: extension, yii2

## 简介

Codeterium assistant classes for yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/Codeterium/yii2-assist
- 源码仓库：https://github.com/Codeterium/yii2-assist.git
- Packagist 页面：https://packagist.org/packages/codeterium%2Fyii2-assist

## 获取地址

- Composer 安装：`composer require codeterium/yii2-assist`
- Packagist 仓库：https://repo.packagist.org/p2/codeterium/yii2-assist.json
- 许可证：Apache-2.0
- PHP 要求：>=5.0.3
