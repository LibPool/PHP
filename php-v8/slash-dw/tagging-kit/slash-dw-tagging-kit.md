# slash-dw/tagging-kit

> 标签: PHP

## 简介

SlashDw shared tagging infrastructure for Laravel projects (Spatie laravel-tags based, multi-tenant + multi-locale + config-driven)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
