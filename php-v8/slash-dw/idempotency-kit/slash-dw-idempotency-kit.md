# slash-dw/idempotency-kit

> 标签: PHP

## 简介

HTTP-layer idempotency middleware for Laravel with atomic locking, path validation, payload fingerprinting, and alert system

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
