# zabaala/phonenumber

> 标签: PHP

## 简介

Simply retrieve phone number informations by extracting them from the PHP version of Google handling library http://giggsey.com/libphonenumber/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
