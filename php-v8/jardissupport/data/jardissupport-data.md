# jardissupport/data

> 标签: Headgent, change-tracking, data, domain-driven-design, entity, entity-hydration, field-mapping, hexagonal-architecture, hydration, identity, jardis, nanoid, php, snapshot, uuid

## 简介

Entity hydration with change tracking, bidirectional field mapping, and identity generation (UUID v4/v5/v7, NanoID)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
