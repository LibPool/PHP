# jardissupport/response

> 标签: Headgent, domain-driven-design, envelope, failure-forms, jardis, php, request-response, response

## 简介

Response building for Jardis request-response use cases: failure forms, response objects, response envelope data and the door steps

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
