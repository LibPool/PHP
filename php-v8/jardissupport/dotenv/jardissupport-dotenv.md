# jardissupport/dotenv

> 标签: configuration, domain-driven-design, dotenv, env, environment, environment-variables, hexagonal-architecture, jardis, jardisSupport, loader, php

## 简介

Environment file loader with cascading overrides, variable interpolation, type casting, and include directives

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
