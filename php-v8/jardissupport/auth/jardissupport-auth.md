# jardissupport/auth

> 标签: Authentication, Headgent, access-control, auth, authorization, domain-driven-design, hexagonal-architecture, jardis, password-hashing, php, rbac, security, session, token

## 简介

Signed access tokens and opaque refresh tokens with SQL token store and token authentication (subject + tenant), session handling, password hashing, and role-based access control for PHP DDD applications — framework-free, no JWT, no third-party runtime dependencies beyond PHP built-ins and the Jardis contracts and dbquery packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
