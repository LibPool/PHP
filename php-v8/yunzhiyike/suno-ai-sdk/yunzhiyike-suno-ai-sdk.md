# yunzhiyike/suno-ai-sdk

> 标签: PHP

## 简介

This is an unofficial Suno API based on PHP; it provides support for all Suno interfaces.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
