# yunzhiyike/pdd-merchant

> 标签: PHP

## 简介

这是一个基于拼多多商家后台的爬虫型API，它不是拼多多官方开放出来的而是通过爬虫进行协议提取出来

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
