# boomdevs/toc

> 标签: TOC, table of contents

## 简介

Simple Table-of-Contents Generator for PHP.  Generates TOCs based off H1...H6 tags

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
