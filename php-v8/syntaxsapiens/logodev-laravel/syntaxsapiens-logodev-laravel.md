# syntaxsapiens/logodev-laravel

> 标签: laravel, logo, logo.dev, logodev-laravel, syntaxsapiens

## 简介

A Laravel package that simplifies interaction with the Logo.dev API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
