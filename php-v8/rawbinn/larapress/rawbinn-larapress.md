# rawbinn/larapress

> 标签: blade, cms, larapress, laravel, rawbinn, wordpress

## 简介

A WordPress-inspired CMS package for Laravel with admin panel, themes, plugins, and content management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
