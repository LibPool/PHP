# rawbinn/themes

> 标签: blade, laravel, rawbinn, theme-engine, themes

## 简介

A standalone theme engine for Laravel 13 - Blade namespaces, parent themes, manifests, and assets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
