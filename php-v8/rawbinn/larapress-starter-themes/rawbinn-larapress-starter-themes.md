# rawbinn/larapress-starter-themes

> 标签: larapress, laravel, rawbinn, starter, themes

## 简介

Starter frontend themes and favicon assets for Rawbinn Larapress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
