# dynamik-dev/cloak-laravel

> 标签: DynamikDev, Masking, cloak, laravel, pii, sensitive-data

## 简介

Laravel adapter for cloak-php - mask and unmask sensitive data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
