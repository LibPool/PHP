# phloxcz/forms-editor

> 标签: bootstrap, editor, form, grid, html-editor, nette, nette-extension, nette-forms, richtext, wysiwyg

## 简介

Full-featured WYSIWYG editor form control for Nette Framework with Bootstrap 5.3 Grid builder, image upload, source view and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
