# wwwision/umadb-php

> 标签: dcb, dynamic-consistency-boundaries, event-sourcing, event-store, umadb

## 简介

PHP bindings for UmaDB event store with Rust FFI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
