# laravelgeekphp/laravel-rekognition

> 标签: laravel, laravel-rekognition, laravelgeekphp

## 简介

A simple package to enable image alt tag label detection with AWS Rekognition

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
