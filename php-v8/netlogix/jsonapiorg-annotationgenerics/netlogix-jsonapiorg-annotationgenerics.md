# netlogix/jsonapiorg-annotationgenerics

> 标签: PHP

## 简介

Map neos/flow objects to jsonapi.org input and output structures, purely by adding class and property annotations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
