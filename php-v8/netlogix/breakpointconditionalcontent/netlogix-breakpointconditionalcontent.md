# netlogix/breakpointconditionalcontent

> 标签: PHP

## 简介

Adds a content wrapper element that allows selectable, breakpoint identifying classes intended to be styled as needed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
