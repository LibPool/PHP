# netlogix/crowdclient

> 标签: PHP

## 简介

Provides a client and authentication provider to connect Flow and Neos applications to Atlassian Crowd.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
