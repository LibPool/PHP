# netlogix/ckeditor-linkclass

> 标签: PHP

## 简介

Extends the CKEditor 5 link editor with the functionality to add preconfigured CSS classes to selected links

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
