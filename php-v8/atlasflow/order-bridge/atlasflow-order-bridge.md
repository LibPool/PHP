# atlasflow/order-bridge

> 标签: Bridge, ERP, atlascore, atlasflow, order, php

## 简介

Serialisation, validation and transport for the Atlas Core Order Bridge API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
