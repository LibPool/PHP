# sukristyan/laravel-slack-sender

> 标签: Sender, laravel, laravel slack sender, message, slack

## 简介

Simple and flexible Slack message sender for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
