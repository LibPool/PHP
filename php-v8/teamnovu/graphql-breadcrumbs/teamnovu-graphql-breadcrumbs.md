# teamnovu/graphql-breadcrumbs

> 标签: PHP

## 简介

Graphql Breadcrumbs is an addon for Statamic that enhances entry types with breadcrumbs, offering flexibility and ease of navigation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
