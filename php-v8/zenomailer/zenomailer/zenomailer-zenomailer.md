# zenomailer/zenomailer

> 标签: brevo, email, jmap, mail, mailer, middleware, php8, postmark, ses, smtp

## 简介

ZenoMailer - Modern PHP 8.2+ email library with decoupled architecture, middleware pipeline, and multiple transport layers (SMTP, HTTP APIs, JMAP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
