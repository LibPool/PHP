# computerundsound/curserver

> 标签: PHP

## 简介

VHost-Manager for Windows (How to use multiple Domains with XAMPP and use multiple XAMPPS for different php-versions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
