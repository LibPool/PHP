# tomwright/currency-php-yahoo-rate-fetcher

> 标签: PHP

## 简介

An extension to fetch exchange rates from the Yahoo API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
