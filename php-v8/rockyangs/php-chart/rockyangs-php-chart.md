# rockyangs/php-chart

> 标签: php chart

## 简介

A PHP chart library, implemented 2D / 3D broken line chart, bar chart, pie chart etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
