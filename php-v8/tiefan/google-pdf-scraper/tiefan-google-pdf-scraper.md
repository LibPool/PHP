# tiefan/google-pdf-scraper

> 标签: google docs, keywords, pdf, scraping

## 简介

A php library to filter pdf documents in google driver for Daniel Fischl

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
