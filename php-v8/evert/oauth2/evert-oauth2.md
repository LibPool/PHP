# evert/oauth2

> 标签: PHP

## 简介

Light PHP wrapper for the OAuth 2.0 protocol (based on OAuth 2.0 Authorization Protocol draft-ietf-oauth-v2-15)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
