# smaily/module-connect-hyva

> 标签: PHP

## 简介

Hyvä theme compatibility for Smaily Connect (Smaily_Connect): framework-free browse tracker and attribution scripts, Tailwind storefront templates

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
