# groomershop/module-amasty-gdpr-magesuite-integration

> 标签: PHP

## 简介

Integration of Amasty_Gdpr and MageSuite_ContentConstructor plugins, so that the cms page is rendered correctly in a amasty popup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
