# g-efac/sdk

> 标签: PHP

## 简介

SDK de PHP para la API /v1 de G-eFac (facturacion electronica e-CF, DGII Republica Dominicana)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
