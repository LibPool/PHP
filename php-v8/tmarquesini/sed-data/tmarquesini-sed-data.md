# tmarquesini/sed-data

> 标签: PHP

## 简介

Biblioteca para obter dados de escolas, turmas e alunos no sistema SED, da Secretaria da Educação do Estado de São Paulo.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
