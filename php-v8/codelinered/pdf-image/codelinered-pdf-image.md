# codelinered/pdf-image

> 标签: TCPDF, convert, create, image, merge, pdf, symfony

## 简介

Converts uploaded images to PDF, merges 2 PDF files to 1 and converts a PDF to images

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
