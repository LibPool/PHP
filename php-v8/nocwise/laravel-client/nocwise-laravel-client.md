# nocwise/laravel-client

> 标签: error-tracking, laravel, logging, monitoring, nocwise

## 简介

Cliente oficial de Nocwise para Laravel: captura logs y excepciones y las envía a tu instancia de Nocwise.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
