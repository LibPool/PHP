# lman/sdk

> 标签: api, license keys, licensemanager, licensing, sdk

## 简介

PHP client for the LicenseManager API: products, policies, customers, licenses, machines and releases.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://licensemanager.dev
- 源码仓库：https://github.com/licenseman/licensemanager-php.git
- Packagist 页面：https://packagist.org/packages/lman%2Fsdk
