# symfony/polyfill-intl-icu

> 标签: compatibility, icu, intl, polyfill, portable, shim

## 简介

Symfony polyfill for intl's ICU-related data and classes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
