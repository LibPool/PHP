# symfony/html-sanitizer

> 标签: Purifier, html, sanitizer

## 简介

Provides an object-oriented API to sanitize untrusted HTML input for safe insertion into a document's DOM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
