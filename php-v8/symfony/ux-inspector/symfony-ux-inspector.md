# symfony/ux-inspector

> 标签: Devtools, inspector, live-components, stimulus, symfony-ux, turbo, ux

## 简介

Browser inspector for Symfony UX components: Stimulus, LiveComponent and Turbo

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
