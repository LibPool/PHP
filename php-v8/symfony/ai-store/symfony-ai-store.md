# symfony/ai-store

> 标签: ai, azure, chromadb, clickhouse, cloudflare, elasticsearch, mariadb, meilisearch, milvus, mongodb, neo4j, opensearch, pinecone, postgres, qdrant, supabase, surrealdb, typesense, weaviate

## 简介

Low-level abstraction for storing and retrieving documents in a vector store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
