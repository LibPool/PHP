# symfony/ai-mate-composer-plugin

> 标签: ai, auto-discovery, composer-plugin, mate

## 简介

Composer plugin that automatically discovers AI Mate extensions on install/update

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
