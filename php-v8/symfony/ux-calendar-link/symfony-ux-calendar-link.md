# symfony/ux-calendar-link

> 标签: calendar, ics, symfony-ux

## 简介

Generates 'Add to calendar' links for Google, Outlook, Office 365 and iCalendar (.ics) in Twig templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
