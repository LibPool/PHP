# symfony/browser-kit

> 标签: 测试, 浏览器模拟

## 简介

Simulates the behavior of a web browser, allowing you to make requests, click on links and submit forms programmatically

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
