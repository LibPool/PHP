# symfony/panther

> 标签: e2e, scraping, selenium, symfony, testing, webdriver, 测试, 浏览器

## 简介

A browser testing and web scraping library for PHP and Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
