# symfony/deepclone

> 标签: clone, deep, deepclone, export, serialize, symfony, var

## 简介

Export any serializable PHP values as pure arrays - accelerator for Symfony's DeepCloner

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
