# symfony/property-info

> 标签: doctrine, phpdoc, property, symfony, type, validator, 基础库, 类型推导

## 简介

Extracts information about PHP class' properties using metadata of popular sources

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
