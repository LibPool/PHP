# offline-agency/filament-spid

> 标签: Authentication, SAML2, SPiD, agid, filament, filament-plugin, italia, laravel, saml, single-sign-on

## 简介

SPID (Italian public digital identity) SAML 2.0 login for Filament panels, built on italia/spid-laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
