# offline-agency/laravel-fatture-in-cloud-v2

> 标签: api, fatture in cloud, integration, laravel

## 简介

A wrapper plugin with Fatture in Cloud Api V2 written in Laravel PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
