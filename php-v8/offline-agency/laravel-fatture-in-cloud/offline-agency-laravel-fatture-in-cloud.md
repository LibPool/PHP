# offline-agency/laravel-fatture-in-cloud

> 标签: api, fatture in cloud, integration, laravel

## 简介

An integration plugin with Fatture in Cloud Api written in Laravel PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
