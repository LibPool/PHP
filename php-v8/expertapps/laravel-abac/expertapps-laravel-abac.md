# expertapps/laravel-abac

> 标签: PHP

## 简介

Enterprise-grade Attribute-Based Access Control (ABAC) using Policy Group and Action Matrix Strategy for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
