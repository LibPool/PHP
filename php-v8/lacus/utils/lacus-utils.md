# lacus/utils

> 标签: Escape, html, random, sequence, type, utilities, utils

## 简介

Reusable utilities library for Lacus Solutions' packages (type description, HTML escaping, random sequences)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
