# opctim/chatgpt-schema-generator

> 标签: PHP

## 简介

This bundle creates a JSON schema from your classes or DTOs to be used with the ChatGPT API so that you get back what you expect.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
