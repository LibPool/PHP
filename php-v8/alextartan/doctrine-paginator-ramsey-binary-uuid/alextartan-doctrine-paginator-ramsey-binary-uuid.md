# alextartan/doctrine-paginator-ramsey-binary-uuid

> 标签: PHP

## 简介

An extension of DoctrinePaginator to make it work when ids are binary uuids generated with ramsey/uuid

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
