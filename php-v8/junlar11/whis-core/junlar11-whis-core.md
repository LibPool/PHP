# junlar11/whis-core

> 标签: PHP

## 简介

A new PHP MVC framework intended for use on any hosting. It can be shared hosting, VPS or a Server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
