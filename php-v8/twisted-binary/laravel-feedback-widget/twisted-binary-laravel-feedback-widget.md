# twisted-binary/laravel-feedback-widget

> 标签: PHP

## 简介

AI-powered feedback widget for Laravel + Inertia + Vue apps that creates GitHub issues.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
