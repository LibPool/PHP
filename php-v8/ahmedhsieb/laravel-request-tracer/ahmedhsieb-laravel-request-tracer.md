# ahmedhsieb/laravel-request-tracer

> 标签: Clockwork, dd, debug, debugbar, laravel, profiler, request-tracer, telescope, trace

## 简介

Trace a Laravel request end to end: per-step timing, input/output in dd() format, line-by-line Deep trace, table writes and problem detection. A production-safe replacement for dd().

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
