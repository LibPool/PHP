# maukirim/sdk

> 标签: gateway, maukirim, notification, otp, sdk, whatsapp

## 简介

Official PHP SDK for MauKirim - managed WhatsApp gateway for OTP, templated notifications, rented numbers and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
