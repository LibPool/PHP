# dynamis/framework

> 标签: PHP

## 简介

Dynamis is a lightweight component based PHP framework that integrates a modern workflow, through Tekton, into Wordpress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
