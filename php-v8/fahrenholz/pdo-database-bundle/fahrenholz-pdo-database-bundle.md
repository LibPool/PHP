# fahrenholz/pdo-database-bundle

> 标签: database, mysql, pdo, pgsql, sqlite, sybase

## 简介

Symfony3 bundle providing PDO connectivity without doctrine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
