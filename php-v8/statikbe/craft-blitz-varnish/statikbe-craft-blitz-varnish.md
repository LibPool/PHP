# statikbe/craft-blitz-varnish

> 标签: Craft, blitz, cache, cms, craftcms, plugin, purger

## 简介

Varnish Cache purger for the Blitz plugin for Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
