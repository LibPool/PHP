# statikbe/craft-trinity

> 标签: Craft, cms, columns, content-builder, craft-plugin, craftcms, grid, matrix

## 简介

Row and column layouts for Craft CMS Matrix fields: a row of 1–3 columns with one nested entry per column, width-aware validation and field conditions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
