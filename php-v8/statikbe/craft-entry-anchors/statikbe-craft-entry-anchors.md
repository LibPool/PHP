# statikbe/craft-entry-anchors

> 标签: Craft, anchor, cms, craft-plugin, craftcms, jump link, link

## 简介

Anchor titles for Craft CMS blocks, and an anchor dropdown on Link fields to link to a block on an entry

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
