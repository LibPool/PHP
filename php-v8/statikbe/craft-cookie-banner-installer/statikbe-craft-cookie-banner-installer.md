# statikbe/craft-cookie-banner-installer

> 标签: PHP

## 简介

Composer plugin that installs content migrations shipped with statikbe/craft-cookie-banner so they run during the standard Craft deploy flow.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
