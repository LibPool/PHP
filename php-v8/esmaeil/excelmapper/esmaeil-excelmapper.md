# esmaeil/excelmapper

> 标签: data-mapping, excel, excel-mapper, php, spreadsheet

## 简介

A PHP library that simplifies the process of mapping, parsing, and importing Excel data into your applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
