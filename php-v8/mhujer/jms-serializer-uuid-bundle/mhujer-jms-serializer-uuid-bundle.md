# mhujer/jms-serializer-uuid-bundle

> 标签: jms, serializer, symfony, uuid

## 简介

Symfony integration for Uuid serializer and deserializer for JMS Serializer library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
