# liquidstack/core

> 标签: PHP

## 简介

Core de arranque, routing y helpers para el framework Liquid Stack (repositorio: liquidstack-core). Incluye módulos JS/SCSS con animaciones GSAP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
