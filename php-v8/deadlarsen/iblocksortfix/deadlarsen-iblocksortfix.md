# deadlarsen/iblocksortfix

> 标签: bitrix, cms, elements, fix, iblock, module, sort

## 简介

1C-Bitrix module for fixing SORT field in iblock elements with 100-step algorithm

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
