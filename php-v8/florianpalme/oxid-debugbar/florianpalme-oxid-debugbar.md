# florianpalme/oxid-debugbar

> 标签: OXID, debug, eshop, florianpalme, modules

## 简介

Integriert eine erweiterbare DebugBar in den OXID eShop.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
