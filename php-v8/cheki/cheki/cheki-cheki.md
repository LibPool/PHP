# cheki/cheki

> 标签: Banking, Ethiopia, Telebirr, awash, cbe, cheki, dashen, eBirr, m-pesa, payment, receipt, sdk, verification, zemen

## 简介

PHP SDK for cheki, a free Ethiopian receipt verification service. 10 live banks: CBE, Telebirr, BOA, M-Pesa, Dashen, Awash, Zemen, CBE Birr, Siinqee, eBirr.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
