# sukohi/google-safe-browsing

> 标签: PHP

## 简介

A Laravel package to check if a specific URL is secure or not through Google Safe Browsing API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
