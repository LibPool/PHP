# sukohi/form-strap

> 标签: PHP

## 简介

A PHP package mainly developed for Laravel to generate form input tags of Bootstrap that can display errors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
