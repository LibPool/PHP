# invinbg/hyperf-http-message

> 标签: PHP

## 简介

A Hyperf extension for enhanced HTTP message handling, compatible with PSR-7/PSR-15 standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
