# papegaill/srb_theme

> 标签: PHP

## 简介

SRB Drupal 8 theme built to use Bootstrap, a sleek, intuitive, and powerful front-end framework for faster and easier web development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
