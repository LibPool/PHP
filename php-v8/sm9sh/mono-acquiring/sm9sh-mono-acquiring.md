# sm9sh/mono-acquiring

> 标签: PHP

## 简介

Simplest library for Monobank Acquiring to get payments. Based on REST API (v2304) docs located at https://api.monobank.ua/docs/acquiring.html

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
