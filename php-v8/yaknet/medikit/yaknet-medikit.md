# yaknet/medikit

> 标签: Gemini, ai, diagnostics, resilience, self-healing, yaknet

## 简介

A self-healing runtime for PHP that uses AI to diagnose and suggest fixes for errors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
