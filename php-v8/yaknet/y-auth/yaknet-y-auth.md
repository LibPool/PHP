# yaknet/y-auth

> 标签: PHP

## 简介

Official PHP SDK for YakNet Kimlik Doğrulama Platformu (SSO / OAuth2) integration, extending league/oauth2-client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
