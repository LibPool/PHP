# yaknet/websocket

> 标签: client, realtime, resilience, server, websocket, ws, wss, yaknet

## 简介

A lightweight, pure PHP WebSocket server and client adapter implementing RFC 6455.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
