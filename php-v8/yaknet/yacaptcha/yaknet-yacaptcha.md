# yaknet/yacaptcha

> 标签: ALTCHA, bot-protection, captcha, security, yacaptcha, yaknet

## 简介

Official PHP SDK for YakNet yaCaptcha (Altcha-based) & WAF integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
