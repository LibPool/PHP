# abdullahdheir/laravel-blog-mcp

> 标签: ai, blog, claude, cms, laravel, mcp, model-context-protocol

## 简介

A stateless MCP (Model Context Protocol) server for Laravel with ready-made blog tools: let Claude list, draft, edit, schedule and publish your posts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
