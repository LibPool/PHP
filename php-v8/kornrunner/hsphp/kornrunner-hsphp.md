# kornrunner/hsphp

> 标签: HandlerSocket, handler socket, mariadb, mysql, nosql, percona

## 简介

Client library for MySQL HandlerSocket extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
