# intrfce/laravel-public-ids

> 标签: identifiers, laravel, prefixed-id, stripe, uuid, uuid7

## 简介

Stripe-style, reversible prefixed public IDs for Eloquent models, backed by UUID v7.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
