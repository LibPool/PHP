# greenpeace/planet4-gpch-gutenberg-blocks

> 标签: PHP

## 简介

Provides Planet4 blocks editing in the Gutenberg editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
