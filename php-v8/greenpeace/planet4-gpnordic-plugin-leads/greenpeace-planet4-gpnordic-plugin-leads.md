# greenpeace/planet4-gpnordic-plugin-leads

> 标签: PHP

## 简介

This repository contains the Greenpeace Nordic Leads Plugin with ACF blocks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
