# greenpeace/gpi-cooltech-importer

> 标签: PHP

## 简介

This repository contains the WordPress plugin that imports the excel data of the cooltechnologies database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
