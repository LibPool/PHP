# michal78/laravel-sms-catcher

> 标签: debugging, development, laravel, mailpit, notifications, sms

## 简介

A development-only inbox for inspecting Laravel SMS notifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
