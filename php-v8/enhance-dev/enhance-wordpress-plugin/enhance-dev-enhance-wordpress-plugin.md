# enhance-dev/enhance-wordpress-plugin

> 标签: PHP

## 简介

A WordPress plugin that uses the Enhance SSR PHP library to render web components on the server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
