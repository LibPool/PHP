# nicko170/laravel-influxdb2

> 标签: laravel, laravel-influxdb2, nicko170

## 简介

A simple wrapper around `influxdata/influxdb-client-php` to make usage in Laravel easier.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
