# fusionspim/php-capsule-listener

> 标签: capsule, debug, eloquent, laravel, orm

## 简介

Simple debugging tool for usage with Laravel's Eloquent ORM

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
