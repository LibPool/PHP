# fusionspim/pangaea-php-sdk

> 标签: export, json, pangaea, php, walmart, xml

## 简介

PHP library for working with Pangaea platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
