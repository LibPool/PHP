# klkvsk/whoeasy

> 标签: php, rdap, whois, whoisparser

## 简介

Easily lookup domain names, IP addresses and AS numbers by WHOIS and RDAP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
