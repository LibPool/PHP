# spipu/html2pdf

> 标签: html, html2pdf, pdf

## 简介

Html2Pdf is a HTML to PDF converter written in PHP - It uses TCPDF - OFFICIAL PACKAGE

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
