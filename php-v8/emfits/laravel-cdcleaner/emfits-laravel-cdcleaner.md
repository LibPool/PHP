# emfits/laravel-cdcleaner

> 标签: cdcleaner, cleanup, deployment, emfits, laravel, releases

## 简介

Cleaning up old releases that won't be needed anymore.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
