# rton/laravel-qpdf-php-wrapper

> 标签: laravel, pdf, qpdf

## 简介

A Laravel service provider for the rton/qpdf-php-wrapper package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
