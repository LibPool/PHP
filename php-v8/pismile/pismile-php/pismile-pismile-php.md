# pismile/pismile-php

> 标签: mobile-money, paiement, payment, pi-spi, pismile, uemoa, webhooks, xof

## 简介

SDK serveur pismile pour PHP : bouton « Payer avec Alias PI-SPI », demandes de paiement et webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
