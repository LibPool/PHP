# ao2/tweeper

> 标签: facebook, instagram, rss, scraper, twitter

## 简介

Tweeper is a web scraper to convert popular social media sites to RSS (e.g. Twitter.com, Instagram.com).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
