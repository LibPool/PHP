# jansen/nv

> 标签: China Name Verification, Teleinfo, epp

## 简介

Extensible Provisioning Protocol (EPP) China Name Verification Mapping的PHP实现，目前支持的VSP为泰尔英福（Teleinfo.cn）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
