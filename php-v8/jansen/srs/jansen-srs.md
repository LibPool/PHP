# jansen/srs

> 标签: epp, verisign

## 简介

基于metaregistrar/php-epp-client开源项目，对外提供统一封装EPP的各类操作接口，内部以驱动方式整合接入各个注册局

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
