# loophp/phptree-ast-generator

> 标签: abstract syntax tree, ast, graph, tree

## 简介

Generates AST of a PHP script in DOT (Graphviz) or Image (PNG, JPG, SVG) formats.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
