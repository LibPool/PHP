# jsooo/jparis

> 标签: Active Record, model, orm, paris

## 简介

A lightweight Active Record implementation for PHP5, built on top of Idiorm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
