# kickflip/kickflip-router-nav-plugin

> 标签: kickflip cli plugin, kickflip plugin, static site generator plugin

## 简介

A Kickflip CLI plugin which provides  pseudo-router functionality with helpful URL and Nav generation features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
