# ptondereau/laravel-packme

> 标签: framework, laravel, package, packme, provider, starter

## 简介

A starter pack for developing a package with Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
