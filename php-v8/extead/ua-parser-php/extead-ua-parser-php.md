# extead/ua-parser-php

> 标签: parser, ua-parser, useragent

## 简介

PHP UA Parser library based on https://github.com/faisalman/ua-parser-js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
