# edtsz/f3-form-validator

> 标签: form, validation, validator

## 简介

Form validator for FatFreeFramework based on CodeIgniter Form Validation library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
