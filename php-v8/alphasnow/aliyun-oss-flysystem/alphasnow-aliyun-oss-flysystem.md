# alphasnow/aliyun-oss-flysystem

> 标签: adapter, aliyun, filesystem, oss

## 简介

Flysystem adapter for the Aliyun storage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
