# anjan-talukdar/laravel-api-mail

> 标签: PHP

## 简介

Multi-provider HTTP API Mail driver and fluent message builder for Laravel (Hostinger Mail API integration with automated mailbox resolution).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
