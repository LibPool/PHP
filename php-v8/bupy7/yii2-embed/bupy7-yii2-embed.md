# bupy7/yii2-embed

> 标签: embed, extension, faccebook, instagram, oembed, opengraph, rutube, twitter-cards, video, vimeo, vkontakte, widget, yii2, youtube

## 简介

Wrapper for PHP library https://github.com/oscarotero/Embed to get information from any web page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
