# bupy7/php-html-form

> 标签: PHP

## 简介

A basic framework agnostic form building package with a few extra niceties like remembering old input and retrieving error messages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
