# bupy7/yii2-pages

> 标签: extension, module, pages, static, yii2

## 简介

A static pages module implements CRUD using Imperavi Redactor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
