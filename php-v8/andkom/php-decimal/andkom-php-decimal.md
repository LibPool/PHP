# andkom/php-decimal

> 标签: Arbitrary-precision, bcmath, bigdecimal, bignumber, decimal, math

## 简介

Arbitrary-precision decimal arithmetic library for PHP, built on top of bcmath.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
