# marcincook/laravel-renteon-api-client

> 标签: api, car-rental, laravel, renteon, rest-client

## 简介

Laravel client for the Renteon REST API (multi-country, manager-style facade).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
