# npr/npr-one-backend-proxy

> 标签: npr, oauth, oauth2, proxy

## 简介

A server-side proxy for interacting with the NPR One API's authorization server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
