# nexthop/service-kit

> 标签: Ed25519, laravel, license, licensing, nexthop

## 简介

Licensing for Nexthop apps: every page needs a valid license from Nexthop Central, with ready-made License, error and reminder pages. No code in the app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
