# mmucklo/email-parse

> 标签: RFC2822, RFC5322, RFC6531, RFC822, batch-email, email, email-parse, internationalized-email, multiple-email, parse, utf-8

## 简介

RFC 5322 / RFC 6531-compliant library for batch parsing multiple (and single) email addresses

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
