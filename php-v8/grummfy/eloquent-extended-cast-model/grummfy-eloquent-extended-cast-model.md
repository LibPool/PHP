# grummfy/eloquent-extended-cast-model

> 标签: cast, eloquent, laravel, traits

## 简介

This library help you to make more advanced cast to eloquent model.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
