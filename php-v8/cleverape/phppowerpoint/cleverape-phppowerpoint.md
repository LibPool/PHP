# cleverape/phppowerpoint

> 标签: LibreOffice, PowerPoint, odp, php, ppt, pptx, presentations

## 简介

PHPPowerPoint - Read, Create and Write Presentations documents in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
