# billythekid/dekopay-api

> 标签: close brothers, dekopay, finance, pay4later, retail finance

## 简介

PHP wrapper of the dekopay finance API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
