# ddr/sonda

> 标签: branch-coverage, coverage, instrumentation, pest, phpunit, testing

## 简介

Line and branch coverage for PHP by instrumenting the source: much faster and lighter than Xdebug path coverage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
