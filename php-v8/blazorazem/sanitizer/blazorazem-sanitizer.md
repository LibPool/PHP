# blazorazem/sanitizer

> 标签: convert, cyrillic, sanitize, url, web-safe

## 简介

Sanitizer is a package convenient for sanitizing proper names, email addresses, URLs etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
