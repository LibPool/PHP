# uxi360/first-image

> 标签: Craft, cms, craft-plugin, craftcms, first image

## 简介

Get the first image from a Redactor or CKEditor field, with optional image transforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
