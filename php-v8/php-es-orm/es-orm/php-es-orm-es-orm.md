# php-es-orm/es-orm

> 标签: aggregation, elasticsearch, eloquent, es, laravel, orm, query-dsl, search

## 简介

An Eloquent-style, type-safe, production-ready Elasticsearch ORM for PHP, with full Query DSL, Aggregations, Search After, PIT, Bulk, Alias and Reindex support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
