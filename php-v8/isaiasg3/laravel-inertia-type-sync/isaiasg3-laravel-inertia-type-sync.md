# isaiasg3/laravel-inertia-type-sync

> 标签: ast, codegen, inertia, laravel, type-safety, typescript, vue

## 简介

Automatic End-to-End Type Safety between Laravel (FormRequests/JsonResources) and TypeScript for Inertia.js + Vue 3 apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
