# smolevich/reindexer-client

> 标签: algolia-alternative, document-database, elasticsearch-alternative, faceted-search, full-text-search, gRPC, in-memory-database, reindexer, sdk, search-engine

## 简介

PHP SDK for Reindexer — embeddable in-memory document database with full-text and faceted search (HTTP + gRPC transports)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
