# joshdovey/postcodes

> 标签: API-Client, GB, boundaries, geocoding, geojson, laravel, onspd, postcode, postcodes, reverse-geocoding, uk

## 简介

Laravel client for the GB Postcodes API — lookup, autocomplete, boundaries, distance, radius, reverse geocoding and ONSPD geography.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
