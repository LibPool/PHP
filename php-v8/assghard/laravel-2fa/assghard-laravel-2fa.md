# assghard/laravel-2fa

> 标签: 2fa, assghard, email, laravel, library, package, php, sms

## 简介

Laravel 2FA package which provides sending verification codes via e-mail and SMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
