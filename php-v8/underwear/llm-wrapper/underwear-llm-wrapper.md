# underwear/llm-wrapper

> 标签: ChatGpt, Gemini, ai, antropic, api, claude, gpt, llm, openai, wrapper

## 简介

A fluent PHP wrapper for LLM APIs with function calling support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
