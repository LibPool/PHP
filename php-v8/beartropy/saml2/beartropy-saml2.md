# beartropy/saml2

> 标签: SAML2, SSO, beartropy, idp, laravel, onelogin, saml, sp

## 简介

Multi-IDP SAML2 SP integration for Laravel using onelogin/php-saml

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
