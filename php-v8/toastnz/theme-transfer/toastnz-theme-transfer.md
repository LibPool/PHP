# toastnz/theme-transfer

> 标签: colours, fonts, modular, silverstripe, theme

## 简介

Copy a Silverstripe site's theme setup - colours, fonts, layout settings - between servers as JSON

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
