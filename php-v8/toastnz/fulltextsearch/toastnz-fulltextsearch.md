# toastnz/fulltextsearch

> 标签: fulltext, silverstripe, solr, sphinx

## 简介

Adds support for Fulltext Search engines like Sphinx and Solr to SilverStripe CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
