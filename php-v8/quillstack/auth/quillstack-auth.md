# quillstack/auth

> 标签: Authentication, auth, authorization, password, php8, quillstack, token

## 简介

Authentication for APIs: a route says what reaching it requires, and one place enforces it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
