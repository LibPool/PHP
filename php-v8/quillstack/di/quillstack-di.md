# quillstack/di

> 标签: PSR-11, class, constructor, container, dependency-injection, di, di-container, php8, properties, property

## 简介

The dependency injection container based on PSR-11: Container interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
