# quillstack/http-client

> 标签: client, curl, http, php8, psr-18, quillstack

## 简介

An HTTP client based on PSR-18, over cURL, saying what went wrong and where.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
