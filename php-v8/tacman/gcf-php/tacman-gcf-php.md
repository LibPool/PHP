# tacman/gcf-php

> 标签: Agent, gcf, llm, serialization, wire-format

## 简介

PHP implementation of GCF (Graph Compact Format), the AI-native wire format for structured data. Generic and graph profiles, delta encoding, session dedup, streaming.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
