> 标签: laravel, laravel telegram, telegram, telegram bot, telegram bot api, telegram php, telegram sdk

## 简介

Telegram Bot SDK for Laravel. Based on the official Telegram Bot API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
