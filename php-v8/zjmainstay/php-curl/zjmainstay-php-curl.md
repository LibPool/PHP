# zjmainstay/php-curl

> 标签: PHP cURL, php, php curl login, php 模拟登录, php 模拟登录采集

## 简介

PHP利用cURL实现模拟登录与采集

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
