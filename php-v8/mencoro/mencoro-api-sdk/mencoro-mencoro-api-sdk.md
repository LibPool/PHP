# mencoro/mencoro-api-sdk

> 标签: ai-search, api, brand-monitoring, geo, mencoro, rank-tracking, sdk, seo

## 简介

Official PHP client for the Mencoro API: projects, tracked queries, captures and AI-search visibility analytics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
