# bhamner/laravel-redis-streams

> 标签: Streams, consumer-groups, laravel, redis

## 简介

Eloquent- and queue-style API for Redis Streams consumer groups.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
