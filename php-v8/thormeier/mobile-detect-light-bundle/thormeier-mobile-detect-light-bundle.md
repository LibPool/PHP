# thormeier/mobile-detect-light-bundle

> 标签: PHP

## 简介

Symfony2 bundle for easy usage of mobiledetect class in Twig http://mobiledetect.net/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
