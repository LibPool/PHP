# dvictorjhg/braidphp

> 标签: braidphp, dvictorjhg

## 简介

An attribute-driven PHP framework with a router and lightweight single-process TCP HTTP runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
