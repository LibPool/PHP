# dvictorjhg/php-injector

> 标签: PSR-11, container, dependency-injection, injector, php, reflection

## 简介

Reflection-based dependency injection and PSR-11 container for modern PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
