# agriserv/exports

> 标签: PHP

## 简介

Queued spreadsheet exports for Laravel apps. Wraps maatwebsite/excel with a tracked ExportJob + Livewire status UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
