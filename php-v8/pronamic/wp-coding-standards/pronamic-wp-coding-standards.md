# pronamic/wp-coding-standards

> 标签: phpcs, pronamic, standards, wordpress

## 简介

Pronamic WordPress WordPress Coding Standards for PHP_CodeSniffer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
