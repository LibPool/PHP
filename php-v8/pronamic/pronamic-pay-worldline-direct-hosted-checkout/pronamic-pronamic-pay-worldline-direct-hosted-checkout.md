# pronamic/pronamic-pay-worldline-direct-hosted-checkout

> 标签: payment, pronamic, pronamic-pay, rabobank, wordpress, wordpress-plugin, worldline

## 简介

This plugin contains the Pronamic Pay integration for the Worldline Direct Hosted Checkout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
