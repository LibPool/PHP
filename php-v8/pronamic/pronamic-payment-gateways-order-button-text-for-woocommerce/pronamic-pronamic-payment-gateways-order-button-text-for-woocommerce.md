# pronamic/pronamic-payment-gateways-order-button-text-for-woocommerce

> 标签: gateway, gateways, payment, payments, pronamic, woocommerce, woocommerce-plugin, wordpress, wordpress-plugin

## 简介

This WordPress plugin adds a setting to all WooCommerce gateways for customizing the order button text.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
