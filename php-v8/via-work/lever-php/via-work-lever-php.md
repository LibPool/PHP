# via-work/lever-php

> 标签: data api, jobs, lever, wrapper

## 简介

Super-simple, minimum abstraction Lever DATA API v1 wrapper in PHP with support for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
