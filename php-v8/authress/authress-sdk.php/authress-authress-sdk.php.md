# authress/authress-sdk.php

> 标签: Authentication, Authress, Authress client, access management, access management as a service, authorization, authorization as a service, user authentication, user security

## 简介

Client SDK for Authress authorization as a service. Provides managed authorization api to secure service resources including user data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
