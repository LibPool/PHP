# sandofvega/bdgeocode

> 标签: bangladesh, geocode, laravel

## 简介

8 Division, 64 District, 491 Thana and 2350 Union fully mapped laravel package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
