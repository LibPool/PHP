# bordeaux-metropole/select-a11y

> 标签: PHP

## 简介

A Drupal-packaged fork of the Pidila select-a11y JavaScript library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
