# ez-php/media

> 标签: crop, ez-php, gd, image, imagick, media, php, resize

## 简介

Image resizing and file processing: transformations over a StorageInterface source via ext-gd or ext-imagick

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
