# ez-php/asyncapi

> 标签: Broadcast, asyncapi, documentation, ez-php, php, webhook, websocket

## 简介

AsyncAPI 3.0 document generation for broadcast channels, webhooks and WebSocket messages, attribute-driven

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
