# ez-php/queue

> 标签: async, ez-php, framework, jobs, php, queue, worker

## 简介

Async job queue for the ez-php framework — database and Redis drivers, Worker, and queue:work command

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
