# ez-php/ai-media

> 标签: ai-media, ez-php, php

## 简介

Image generation, audio transcription, and text-to-speech via OpenAI/Gemini drivers over ez-php/http-client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
