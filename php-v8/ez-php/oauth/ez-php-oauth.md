# ez-php/oauth

> 标签: SSO, authorization-code, ez-php, oauth, oauth2, php, pkce

## 简介

OAuth2/SSO client flows: authorization code flow with PKCE and state, token exchange via ez-php/http-client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
