# ez-php/dataloader

> 标签: Batching, dataLoader, ez-php, memoization, n-plus-1, php

## 简介

Generic keyed-batch loading and per-key memoization primitive for solving N+1 access patterns

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
