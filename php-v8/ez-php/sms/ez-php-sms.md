# ez-php/sms

> 标签: ez-php, php, sms, twilio, vonage

## 简介

SMS delivery (Twilio, Vonage, Log, Null drivers) over ez-php/http-client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
