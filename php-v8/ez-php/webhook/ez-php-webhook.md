# ez-php/webhook

> 标签: ez-php, framework, hmac, php, queue, webhook

## 简介

Outgoing webhooks for the ez-php framework — HMAC-signed delivery as a retrying queue job, plus middleware to verify incoming webhook signatures

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
