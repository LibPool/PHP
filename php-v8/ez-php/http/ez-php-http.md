# ez-php/http

> 标签: http, php, psr, request, response

## 简介

HTTP message objects for the ez-php framework — immutable Request, Response, RequestFactory, and ResponseEmitter. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
