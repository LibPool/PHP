# ez-php/http-client

> 标签: curl, ez-php, framework, http, http-client, php

## 简介

HTTP client module for the ez-php framework — fluent cURL-based client for making outgoing HTTP requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
