# ez-php/json-schema-validator

> 标签: ez-php, json-pointer, json-schema, php, validation

## 简介

Validates decoded JSON against the JSON Schema subset ez-php/json-schema generates, with JSON Pointer error paths

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
