# ez-php/event-store-snapshots

> 标签: event-sourcing, event-store, ez-php, php, snapshots

## 简介

Snapshot store for ez-php/event-store streams: PDO and in-memory stores, every-N-events policy, snapshot-aware loader

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
