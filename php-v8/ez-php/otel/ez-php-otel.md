# ez-php/otel

> 标签: ez-php, framework, observability, opentelemetry, otel, otlp, php, tracing

## 简介

OpenTelemetry-style spans and OTLP/HTTP JSON export for the ez-php framework, without a vendor SDK

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
