# ez-php/qrcode

> 标签: ez-php, php, png, qr, qrcode, svg

## 简介

Dependency-free QR code encoder (numeric/alphanumeric/byte, versions 1-40, ECC L/M/Q/H) with SVG and PNG (ext-gd) renderers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
