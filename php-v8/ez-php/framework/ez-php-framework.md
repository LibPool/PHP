# ez-php/framework

> 标签: dependency-injection, framework, middleware, migration, php, routing

## 简介

Lightweight PHP framework core — dependency injection, routing, middleware, and database migrations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
