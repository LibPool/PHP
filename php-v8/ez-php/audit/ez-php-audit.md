# ez-php/audit

> 标签: PHP

## 简介

Audit log module for ez-php — event-driven recording of entity lifecycle changes (CREATE, UPDATE, DELETE) into an audit_logs table with a fluent query API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
