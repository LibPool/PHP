# ez-php/webauthn-metadata

> 标签: FIDO2, attestation, ez-php, fido-mds, metadata, php, webauthn

## 简介

FIDO MDS trust-anchor lookups for WebAuthn: metadata blob download, JWT verification, trust-anchor cache and attestation chain trust decisions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
