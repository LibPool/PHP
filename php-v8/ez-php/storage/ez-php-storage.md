# ez-php/storage

> 标签: ez-php, filesystem, framework, php, s3, storage

## 简介

File storage abstraction for the ez-php framework — local filesystem and S3-compatible drivers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
