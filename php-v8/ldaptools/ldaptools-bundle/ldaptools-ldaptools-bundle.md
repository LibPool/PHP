# ldaptools/ldaptools-bundle

> 标签: Microsoft Exchange, active directory, ldap, openldap

## 简介

Provides easy LDAP integration for Symfony via LdapTools.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
