# dimadin/disable-wordpress-events-and-news-dashboard-widget

> 标签: dashboard

## 简介

Disable WordPress Events and News widget from the dashboard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
