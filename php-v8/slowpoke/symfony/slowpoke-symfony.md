# slowpoke/symfony

> 标签: doctrine, n-plus-one, performance, slowpoke, symfony

## 简介

Sends each Symfony request, console command and Messenger message, with the file:line origin of every Doctrine query, to the local Slowpoke agent.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
