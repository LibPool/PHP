# slowpoke/laravel

> 标签: laravel, n-plus-one, opentelemetry, performance, slowpoke

## 简介

Sends each Laravel request and job, with the file:line origin of every query, to the local Slowpoke agent.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
