# pfaciana/wp-debug-bar

> 标签: PHP

## 简介

Debug Bar that adds a debug menu to the admin bar that shows query, cache, and other helpful debugging information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
