# pfaciana/php-error-log-viewer

> 标签: PHP

## 简介

A WordPress plugin that provides an interface to view, manage, and analyze PHP error logs across your WordPress installation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
