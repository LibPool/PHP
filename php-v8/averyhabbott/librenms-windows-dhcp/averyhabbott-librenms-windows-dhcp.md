# averyhabbott/librenms-windows-dhcp

> 标签: DHCP, librenms, monitoring, plugin, powershell-universal, windows

## 简介

LibreNMS plugin package: monitor Windows DHCP server and scope health via PowerShell Universal (no SNMP).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
