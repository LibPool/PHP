# telemidia/graylog

> 标签: PHP

## 简介

Este pacote fornece uma interface simples e eficiente para enviar mensagens de log para o Graylog, seguindo o padrão utilizado pela Telemidia.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
