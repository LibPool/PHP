# conduit/gorilla-claw

> 标签: HOOK, action, composer, filter, wordpress

## 简介

Coherent WordPress action / filter hook API, with monkey-patching capabilities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
