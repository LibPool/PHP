# borysenko/yii2-liqpay-base

> 标签: e-commerce, liqpay, yii2

## 简介

The toolkit of integration LiqPay service in your project for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
