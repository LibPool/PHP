# oasys/core

> 标签: PSR-11, http, kernel, middleware, psr-15, psr-7, router

## 简介

Minimal PSR-compatible HTTP framework with routing, middleware pipeline, and exception handling

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
