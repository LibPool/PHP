# vatvit/freshen-symfony

> 标签: bundle, cache, freshen, stale-while-revalidate, stampede, swr, symfony

## 简介

Drop-in Symfony bundle for Freshen — stale-while-revalidate cache with cache-stampede prevention: declarative named caches, autowired by name, async invalidation pre-wired, and a Redis/PSR-6 backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
