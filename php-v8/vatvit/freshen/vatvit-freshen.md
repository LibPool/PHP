# vatvit/freshen

> 标签: cache, psr-16, psr-6, redis, stale-while-revalidate, stampede, swr

## 简介

Stale-while-revalidate PHP cache with cache-stampede prevention — single-flight recompute, jittered TTLs, non-blocking async invalidation, structured hierarchical keys (versioning + locale), and an atomic Redis/PSR-6 backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
