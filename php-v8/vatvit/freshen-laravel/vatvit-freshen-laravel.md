# vatvit/freshen-laravel

> 标签: cache, freshen, laravel, stale-while-revalidate, stampede, swr

## 简介

Drop-in Laravel bridge for Freshen — stale-while-revalidate cache with cache-stampede prevention: declarative named caches via facade/manager, queued async invalidation, and a Redis/PSR-6 backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
