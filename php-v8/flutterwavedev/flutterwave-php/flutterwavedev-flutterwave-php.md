# flutterwavedev/flutterwave-php

> 标签: africa, flutterwave, payment, rave, transfers

## 简介

A simple SDK for integrating to Flutterwave's Rave payment gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
