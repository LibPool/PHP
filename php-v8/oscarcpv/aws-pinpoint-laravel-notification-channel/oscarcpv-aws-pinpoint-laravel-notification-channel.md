# oscarcpv/aws-pinpoint-laravel-notification-channel

> 标签: PHP

## 简介

This package makes it easy to send notifications using AWS Pinpoint with Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
