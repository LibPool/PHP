# filakitphp/basev5

> 标签: filament, filament-starter-kit, filament-v5, laravel, laravel-starter-kit, livewire, starter-kit, tailwindcss

## 简介

Base starter kit built on Laravel 13.x and Filament 5.x with a ready-to-use admin panel structure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
