# razzbee/php-libimap

> 标签: Imap Client, PHP Imap Library, PHP Imap mail, mail, php, php imap, php libimap, php-imap

## 简介

A PHP IMAP library in Pure OOP for ease and simplicity

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
