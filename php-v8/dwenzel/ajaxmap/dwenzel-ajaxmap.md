# dwenzel/ajaxmap

> 标签: ajax, extension, map, typo3

## 简介

Versatile map extension for the TYPO3 CMS. Map data are requested dynamically via ajax.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
