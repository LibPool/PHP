# pho-adapters/index-elasticsearch

> 标签: PHP

## 简介

Elasticsearch adapter for indexing data from nodes and edges of graphs for the Phở stack.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
