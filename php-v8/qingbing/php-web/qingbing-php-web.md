# qingbing/php-web

> 标签: action, controller, framework, php, route, web

## 简介

简易的php框架，包含路由、接口返回等，默认提供json的数据返回，不支持页面渲染

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
