# qingbing/yii2-configure-logic

> 标签: configure, php, yii, yii2, yii2-configure-logic

## 简介

yii2获取配置组件，包含：网站配置，表头配置，表单配置等配置功能，主要用于程序设计开发时获取db数据

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
