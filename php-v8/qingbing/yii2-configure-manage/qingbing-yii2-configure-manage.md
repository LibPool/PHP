# qingbing/yii2-configure-manage

> 标签: configure, configure-logic, php, yii, yii2, yii2-configure-logic

## 简介

yii2配置组件，包含：网站配置，表头配置，表单配置等配置功能，主要用于程序设计开发使用时操作配置db

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
