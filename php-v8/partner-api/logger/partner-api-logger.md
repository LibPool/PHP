# partner-api/logger

> 标签: Metrics, Partner-API, laravel, logging, sdk

## 简介

Partner API Logger SDK for PHP — send structured logs and metrics to the Partner API ingest service

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
