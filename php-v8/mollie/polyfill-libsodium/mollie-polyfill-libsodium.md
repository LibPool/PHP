# mollie/polyfill-libsodium

> 标签: PHP

## 简介

A polyfill package to transition from the libsodium php extension to the sodium extension. Which is included in PHP 7.2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
