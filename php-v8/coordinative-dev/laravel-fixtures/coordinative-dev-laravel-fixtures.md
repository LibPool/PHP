# coordinative-dev/laravel-fixtures

> 标签: Fixture

## 简介

Laravel Fixtures are used to load a 'fake' set of data into a database that can then be used for testing

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
