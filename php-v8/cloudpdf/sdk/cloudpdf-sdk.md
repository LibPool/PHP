# cloudpdf/sdk

> 标签: api, cloudpdf, sdk

## 简介

CloudPDF PHP Library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.cloudpdf.com
- 源码仓库：https://github.com/embedpdf/cloudpdf-sdk-php.git
- Packagist 页面：https://packagist.org/packages/cloudpdf%2Fsdk

## 历史版本号

- 当前版本：v3.0.0-alpha.14

- -

## 获取地址

- Composer 安装：`composer require cloudpdf/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/cloudpdf/sdk.json
- 许可证：Apache-2.0
- PHP 要求：^8.1
