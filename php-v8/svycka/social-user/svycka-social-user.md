# svycka/social-user

> 标签: Social Login, ZendFramework, doctrine, facebook, google, laminas, mezzio, module, oauth2, oauth2-server-php, social-user

## 简介

This module adds custom grant types for oauth2-server-php to allow login with social services like google or facebook.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
