# webware/webware-admin

> 标签: admin, dashboard, mezzio, webware

## 简介

Mezzio admin dashboard framework: widget system, ACL-filtered rendering, and navigation for the webware-* package family.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
