# ridgeben/smart-chatbot

> 标签: ai, chatbot, database-chatbot, laravel, ollama

## 简介

Reusable Laravel database-aware AI chatbot using Ollama.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
