# ajit-das/laravel-msg91

> 标签: ajit-das, laravel, laravel-msg91

## 简介

Laravel notification channels for MSG91 SMS, WhatsApp and OTP, with fluent message builders.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
