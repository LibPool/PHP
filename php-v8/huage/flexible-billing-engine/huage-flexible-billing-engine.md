# huage/flexible-billing-engine

> 标签: billing, condition, formula, pricing, rule-engine

## 简介

灵活计费引擎 - 支持多层级条件判断、公式计算、规则匹配

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
