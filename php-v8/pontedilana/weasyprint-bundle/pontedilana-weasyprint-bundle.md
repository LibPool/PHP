# pontedilana/weasyprint-bundle

> 标签: WeasyPrint, bundle, pdf, symfony-bundle

## 简介

Easily create PDF in Symfony by converting Twig/HTML templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
