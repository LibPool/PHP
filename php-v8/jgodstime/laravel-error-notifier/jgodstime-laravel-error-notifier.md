# jgodstime/laravel-error-notifier

> 标签: email, error, exception, jgodstime, laravel, notifier, slack

## 简介

Email and Slack notifications for uncaught exceptions in a Laravel application, with an optional user feedback form on the 500 page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
