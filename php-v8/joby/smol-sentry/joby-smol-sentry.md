# joby/smol-sentry

> 标签: PHP

## 简介

A conceptually simple security logging and rule-enforcing system. Supports ingesting a wide variety of signals and using them to generate bot challenges and bans.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
