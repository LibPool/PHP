# jeslopcru/git-score

> 标签: PHP

## 简介

displays aggregate stats in a concise format for human consumption and provides a rough estimation of developer involvement in a project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
