# disrex/sample-data-themes-core

> 标签: demo-data, fixtures, mageOS, magento, magento2, sample-data

## 简介

Theme-based sample data framework for Magento 2 / MageOS — pluggable registry, fixture runner, multi-locale support and CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
