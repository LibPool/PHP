# disrex/magento-security-patches

> 标签: apsb26-146, apsb26-153, cosmicsting, magento, patches, security, sessionreaper

## 简介

Adobe's isolated and out-of-band security patches for Magento Open Source, Adobe Commerce and B2B, taken unmodified from Adobe's patch registry and applied by disrex/magento-patch-installer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
