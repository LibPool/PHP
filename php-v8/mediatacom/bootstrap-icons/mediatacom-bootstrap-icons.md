# mediatacom/bootstrap-icons

> 标签: bootstrap, icon font, icons, svg

## 简介

Official open source SVG icon library for Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/mediatacom/bootstrap-icons.git
