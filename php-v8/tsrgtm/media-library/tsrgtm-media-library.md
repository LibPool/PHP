# tsrgtm/media-library

> 标签: filament, filament-form-field, filament-media-picker, filament-v5, google-drive-workspace, laravel, media-library, media-manager, polymorphic-media, responsive-images, resumable-upload, tus-upload

## 简介

Advanced Laravel media library and Filament 5 plugin with a reusable media picker field, resumable uploads, folders, tags, responsive images and rich previews.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
