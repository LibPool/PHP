# beryldev/laravel-emaillabs

> 标签: driver, emial, emiallabs, labs, laravel, mail

## 简介

Simple package to integrate Laravel email with EmailLabs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
