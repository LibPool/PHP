# xenon/paystation

> 标签: Bangladeshi payment gateway, api, nagad, nagad payment gateway, nagad php library, nagad sdk, payment gateway, paystation, paystation gateway, paystation php sdk

## 简介

Paystation is a php library for Bangladeshi payment gateway provider. You can integrate this in your php application and get customer payment using mfs, credit card and so on

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
