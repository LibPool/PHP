# xenon/sweet-alert

> 标签: alert, laravel, notifier, sweet

## 简介

A simple PHP package to show Sweet Alerts with the Laravel Framework forked from uxweb/sweet-alert

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
