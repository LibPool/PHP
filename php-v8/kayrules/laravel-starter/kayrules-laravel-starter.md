# kayrules/laravel-starter

> 标签: bootstrap, cms, framework, laravel, starter, theme

## 简介

The Laravel 4.2 Starter CMS Template with Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
