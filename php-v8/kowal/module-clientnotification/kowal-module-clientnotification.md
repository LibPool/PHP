# kowal/module-clientnotification

> 标签: PHP

## 简介

Wyświetla komunikat na sklepie Magento w okienku. Po zaakceptowaniu komunikatu przestaje.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
