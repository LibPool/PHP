# integrated/slug-bundle

> 标签: Integrated, slug

## 简介

Provides a slugger which can generate a slug from a string and event listeners to auto-generate slugs on chosen fields

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
