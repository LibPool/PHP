# integrated/theme-bundle

> 标签: Integrated, theme

## 简介

Provides website theme support, which makes it easy to share themes between websites or use a multi-site in your application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
