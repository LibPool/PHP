# integrated/menu-bundle

> 标签: Integrated, menu

## 简介

Provides MenuEvents to allow adding navigation menu items to the Integrated backend and a database provider to read navigation items from the database (which allows front-end navigation menu editing when used with the website-bundle)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
