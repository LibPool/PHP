# makowskid/sg-nric

> 标签: NRIC, Singapore, fin, validator

## 简介

Package to easily validate Singapore NRIC/FIN numbers in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
