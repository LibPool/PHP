# hostkurd/flocms-admin

> 标签: admin, admin-panel, crud, flocms, multilingual, rtl

## 简介

Admin panel builder for FloCMS: resources declared in PHP, server-rendered CRUD pages, translatable fields and RTL support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
