# hostkurd/flocms-cli

> 标签: cli, console, flocms, framework, generator, migrations, scheduler

## 简介

Command line interface for FloCMS: one command kernel for the framework, its packages and your application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
