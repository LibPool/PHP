# inisium/laravel-compose

> 标签: coolify, docker, docker-compose, laravel, serversideup

## 简介

Generate a production Dockerfile and docker-compose.yaml (serversideup/php, Coolify-ready) for a Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
