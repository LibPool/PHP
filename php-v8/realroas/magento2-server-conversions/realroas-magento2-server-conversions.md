# realroas/magento2-server-conversions

> 标签: TikTok , capi, conversions, facebook, google-ads, magento2, meta, pinterest, roas, server-side, tracking

## 简介

Free server-side conversions module for Magento 2. Sends purchase events via API to Google Ads, Meta (Facebook/Instagram), TikTok, and Pinterest. Works alongside your existing tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
