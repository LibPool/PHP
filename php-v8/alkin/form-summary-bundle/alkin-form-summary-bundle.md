# alkin/form-summary-bundle

> 标签: Read-Only, form, summary, symfony, twig

## 简介

Read-only summaries for Symfony Forms using existing labels, choices and view data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
