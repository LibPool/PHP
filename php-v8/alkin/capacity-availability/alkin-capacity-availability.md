# alkin/capacity-availability

> 标签: availability, booking, capacity, doctrine, reservations, scheduling, sweep-line

## 简介

Calculate continuous capacity availability from overlapping reservations, with optional Doctrine DBAL booking support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
