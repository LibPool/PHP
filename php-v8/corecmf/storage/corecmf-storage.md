# corecmf/storage

> 标签: CoreCMF, cos, oss, qiniu, storage, upyun

## 简介

corecmf storage package 对象云存储包支持阿里云、腾讯云、七牛云、又拍云

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
