# georgemosesgroup/filament-media-library

> 标签: admin-panel, drag-drop, filament, file-manager, file-picker, file-upload, laravel, media-library, media-picker, multi-tenancy

## 简介

A powerful media library package for Filament v3/v4/v5+ with MediaPicker form component, drag & drop uploads, folder management, and built-in responsive thumbnail generation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
