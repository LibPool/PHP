# 6tail/tyme4php

> 标签: 公历, 农历, 回历, 干支, 星座, 月相, 法定假日, 生肖, 节气, 藏历

## 简介

Tyme是一个非常强大的日历工具库，可以看作 Lunar 的升级版，拥有更优的设计和扩展性，支持公历、农历、藏历、回历、星座、干支、生肖、节气、月相、法定假日等。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
