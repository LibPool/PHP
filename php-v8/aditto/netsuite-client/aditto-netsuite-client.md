# aditto/netsuite-client

> 标签: SuiteTalk, laravel, netsuite, rest, suiteql

## 简介

Framework-agnostic PHP client for NetSuite's SuiteTalk REST API, with an optional Laravel bridge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
