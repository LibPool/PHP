# codalaya/php-project-install-wizard

> 标签: installation, installer, laravel, laravel Installer, laravel package, setup

## 简介

Web installer for Laravel products: requirements, permissions, database, optional purchase-code step and admin account. Records the installation in the database and locks itself afterwards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
