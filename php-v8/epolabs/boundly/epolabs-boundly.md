# epolabs/boundly

> 标签: api, attributes, boilerplate, ddd, framework, laravel, metadata-driven, php8, rest

## 简介

The Metadata-Driven PHP Framework. Define your Domain. BOUNDLY handles the rest.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
