# oybek-daniyarov/laravel-trpc

> 标签: Postman, api, client-generator, codegen, full-stack, inertia, laravel, react-query, routes, type-safe, typed-api, typescript

## 简介

End-to-end type-safe APIs for Laravel. Like tRPC, but for Laravel + TypeScript.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
