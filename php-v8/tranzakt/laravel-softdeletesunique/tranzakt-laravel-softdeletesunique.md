# tranzakt/laravel-softdeletesunique

> 标签: deleted_at, laravel, timestamps

## 简介

Package to allow correct unique indexing of null softDelete deleted_at columns.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
