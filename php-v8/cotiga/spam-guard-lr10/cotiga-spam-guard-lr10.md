# cotiga/spam-guard-lr10

> 标签: PHP

## 简介

Antispam et gestion des erreurs HTTP pour applications Laravel (géoblocage, filtrage email, ban IP automatique).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
