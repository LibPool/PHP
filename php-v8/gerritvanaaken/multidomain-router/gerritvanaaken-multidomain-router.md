# gerritvanaaken/multidomain-router

> 标签: kirby, kirby-plugin, multidomain, routing

## 简介

A Kirby plugin for routing and managing multiple domains in a single Kirby installation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
