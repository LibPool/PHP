# gladcodes/ravephp

> 标签: flutterwave, payment, rave

## 简介

Simple PHP SDK for integrating Flutterwave's Rave payment gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/gladchinda/rave-php.git
