# eddiejaoude/phpunit-wrapper

> 标签: phpunit, wrapper

## 简介

PHPUnit wrapper - wraps the functionality of phpunit with easy to use plain English

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
