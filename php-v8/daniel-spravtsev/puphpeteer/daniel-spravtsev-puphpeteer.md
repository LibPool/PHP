# daniel-spravtsev/puphpeteer

> 标签: automation, developer-tools, headless-chrome, php, puppeteer, testing, web

## 简介

A Puppeteer bridge for PHP, supporting the entire API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
