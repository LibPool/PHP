# noirapi/framework

> 标签: fast-route, framework, latte, php, tracy

## 简介

Small PHP 8.4 web framework: FastRoute routing, Latte views, noirapi/database models, Tracy debugging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
