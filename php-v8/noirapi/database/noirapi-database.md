# noirapi/database

> 标签: Abstraction Layer, database, mysql, postgresql, query, query builder, schema builder, sql, sqlite, sqlserver

## 简介

A strictly typed database abstraction layer over PDO with a query builder and a schema builder (fork of opis/database)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
