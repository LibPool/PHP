# ashutosh1007/smartmailer

> 标签: PHP

## 简介

Smart Mailer for Laravel to handle dynamic from-address, SMTP rotation, failover, and monitoring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
