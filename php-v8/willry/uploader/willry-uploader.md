# willry/uploader

> 标签: Image upload, file upload, upload, uploader, willry

## 简介

Automatizar o upload de arquivos, validando o tipo de arquivo e otimizando imagens

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
