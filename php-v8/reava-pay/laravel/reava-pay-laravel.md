# reava-pay/laravel

> 标签: africa, laravel, mobile-money, mpesa, payments, reava-pay

## 简介

Official Laravel package for the Reava Pay payment gateway — Admin UI, webhooks, transaction tracking, one-click connect

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
