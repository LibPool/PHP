# markup-carve/tempest-highlight-carve

> 标签: carve, crv, highlight, markup, syntax-highlighting, tempest

## 简介

Carve markup language support for tempest/highlight: server-side syntax highlighting for .crv source.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
