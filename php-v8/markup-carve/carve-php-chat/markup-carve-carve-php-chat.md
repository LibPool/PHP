# markup-carve/carve-php-chat

> 标签: carve, chat, discord, export, markup, mrkdwn, slack, telegram, whatsapp

## 简介

Render Carve documents to chat-platform markup (WhatsApp, Slack, Telegram, Discord) via data-driven flavor definitions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
