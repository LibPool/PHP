# markup-carve/symfony-carve

> 标签: bundle, carve, djot, html, markup, symfony, twig

## 简介

Symfony bundle to render Carve markup to HTML via carve-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
