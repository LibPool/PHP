# markup-carve/carve-php-media-embed

> 标签: audio, carve, embed, iframe, markup, media, video, youtube

## 简介

Opt-in Carve extension that embeds audio/video from 30+ providers via dereuromark/media-embed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
