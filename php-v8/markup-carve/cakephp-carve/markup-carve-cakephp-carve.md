# markup-carve/cakephp-carve

> 标签: cakephp, carve, markup, parser, plugin

## 简介

CakePHP plugin for Carve: rendering, views, validation, ORM behavior, commands and caching

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
