# markup-carve/laravel-carve

> 标签: blade, carve, laravel, markup, package, parser

## 简介

Laravel integration for Carve: rendering, validation, views, casts, imports, commands and caching

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
