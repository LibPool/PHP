# eddturtle/phpword

> 标签: ISO IEC 29500, OOXML, Office Open XML, OpenDocument, OpenXML, PhpOffice, PhpWord, Rich Text Format, WordprocessingML, doc, docx, html, odf, odt, office, pdf, php, reader, rtf, template, template processor, word, writer

## 简介

PHPWord - A pure PHP library for reading and writing word processing documents (OOXML, ODF, RTF, HTML, PDF)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
