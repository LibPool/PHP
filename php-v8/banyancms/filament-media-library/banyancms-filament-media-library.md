# banyancms/filament-media-library

> 标签: DAM, alt text, banyan, filament, focal point, laravel, media library

## 简介

A governed media library for any Filament v5 panel: alt text required, focal-point crops, versioned replacements, licence expiry, usage tracking and signed renditions. Part of Banyan, usable without it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
