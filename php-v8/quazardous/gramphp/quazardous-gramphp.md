# quazardous/gramphp

> 标签: DAG, journal, lease, mariadb, queue, retry, workflow

## 简介

A small workflow graph for work queues that already live in a storage: nodes, joins, retries, leases — over pluggable drivers (memory, MariaDB). A PHP port of grampy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
