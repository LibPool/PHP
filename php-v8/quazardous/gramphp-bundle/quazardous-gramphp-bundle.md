# quazardous/gramphp-bundle

> 标签: DAG, bundle, gramphp, queue, symfony, workflow

## 简介

Symfony integration for gramphp: graphs declared in configuration as journal services over the Doctrine connection, the tables in the Doctrine schema, janitor and drawing commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
