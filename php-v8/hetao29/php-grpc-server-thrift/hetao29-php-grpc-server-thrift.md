# hetao29/php-grpc-server-thrift

> 标签: gRPC, nginx, php, php-fpm, server, thrift

## 简介

The php grpc server framework with thrift and DO NOT use any 3rd libraries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
