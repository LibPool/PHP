# cbaconnier/laravel-http-pool-callback

> 标签: PHP

## 简介

A Laravel package that enhances the HTTP pool functionality by allowing users to apply callbacks to the results.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
