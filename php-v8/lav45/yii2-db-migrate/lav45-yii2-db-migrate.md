# lav45/yii2-db-migrate

> 标签: db, extension, migrate, yii2

## 简介

This extension allows you to easily create large migrations associated with many foreign keys.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
