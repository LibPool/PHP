# iszmxw/mysql-markdown

> 标签: markdown, mysql, mysql markdown, mysql文档, mysql文档生成, mysql转markdown

## 简介

mysql生成文档，转markdown文档，只需要mysql连接参数

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
