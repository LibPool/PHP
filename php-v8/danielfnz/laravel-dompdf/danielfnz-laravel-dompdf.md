# danielfnz/laravel-dompdf

> 标签: laravel, mpdf, pdf

## 简介

Generate PDFs in Laravel with this mPDF wrapper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
