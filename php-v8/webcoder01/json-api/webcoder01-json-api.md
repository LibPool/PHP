# webcoder01/json-api

> 标签: JSON-API, JSON_API, json, php

## 简介

A framework-agnostic library designed to use HTTP requests with ease in accordance with the JSON:API specification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
