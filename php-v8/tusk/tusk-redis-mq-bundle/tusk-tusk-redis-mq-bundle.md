# tusk/tusk-redis-mq-bundle

> 标签: message, predis, queue, redis, symfony

## 简介

Symfony Bundle for the tusk-redis-mq component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
