# edwinjuarezpe/cr-mh-sign

> 标签: PHP

## 简介

PHP library for Costa Rica MH e-invoicing: XMLDSig/XAdES-EPES electronic signatures for XML documents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
