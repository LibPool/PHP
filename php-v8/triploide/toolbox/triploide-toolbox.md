# triploide/toolbox

> 标签: PHP

## 简介

A Laravel CRUD toolkit that auto-resolves controllers, dataproviders, repositories, validators, filters, and more by convention.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
