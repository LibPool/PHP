> 标签: PHPStan, Pint, ai, ai-agents, anthropic, claude, claude-code, code-quality, code-style, coding-standards, conventions, cursor, developer-experience, developer-tools, git-hooks, github-copilot, larastan, laravel, llm, mcp, pest, quality-gate, scaffolding, static-analysis

## 简介

One command sets up Claude Code (and any AI coding agent) on a Laravel project: engineering rules, a quality gate (PHPStan, Pint, Pest), skills, git hooks, and stack-aware frontend tooling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
