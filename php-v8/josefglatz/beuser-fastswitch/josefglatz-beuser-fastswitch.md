# josefglatz/beuser-fastswitch

> 标签: editors, extension, improvements, maintenance, productivity, typo3

## 简介

Fast backend user switch for TYPO3 CMS administrator users.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
