# omerkoseoglu/devextreme-data-symfony

> 标签: bundle, datagrid, devextreme, doctrine, pivotgrid, server-side, symfony

## 简介

Symfony bundle for omerkoseoglu/devextreme-data: server-side DevExtreme data processing over Doctrine DBAL, ORM entities and arrays.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
