# omerkoseoglu/devextreme-data-laravel

> 标签: datagrid, devextreme, eloquent, grouping, laravel, pagination, pivotgrid, server-side

## 简介

Laravel integration for omerkoseoglu/devextreme-data: server-side DevExtreme data processing over Eloquent models, query builders and collections.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
