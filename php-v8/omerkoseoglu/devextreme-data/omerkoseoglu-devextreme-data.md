# omerkoseoglu/devextreme-data

> 标签: aspnet-data, datagrid, datasource, devexpress, devextreme, grouping, pagination, pdo, pivotgrid, server-side

## 简介

Server-side data processing for DevExtreme widgets in PHP: filtering, sorting, paging, grouping, summaries and select over arrays and SQL (PDO). A PHP port of DevExtreme.AspNet.Data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
