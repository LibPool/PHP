# friendsoftypo3headless/headless-kesearch

> 标签: headless, json, ke_search, pwa, typo3

## 简介

This extension provides integration with ke_search to output content from TYPO3 in JSON format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
