# alexyav/phpspec-code-coverage

> 标签: code-coverage, coverage, phpspec, report, spec, test, tests

## 简介

Generate Code Coverage reports for PhpSpec tests

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
