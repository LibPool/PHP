# lauroguedes/laravel-astro-landing

> 标签: astro, github-actions, landing-page, laravel, marketing-site, static-site

## 简介

Keep an Astro landing page in the same repository as your Laravel application, scaffold it with one command, run it alongside `composer run dev`, and deploy it on its own.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
