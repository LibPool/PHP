# jascha030/service-provider

> 标签: PHP

## 简介

Service Provider interface for usage with PSR-11 ContainerInterface, based on container-interop/service-provider.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
