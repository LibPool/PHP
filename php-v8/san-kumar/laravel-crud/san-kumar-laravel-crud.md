# san-kumar/laravel-crud

> 标签: artisan, blade, crud, laravel, templates, view

## 简介

Laravel CRUD generator: Generate CRUD for any db table with the crud:generate command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
