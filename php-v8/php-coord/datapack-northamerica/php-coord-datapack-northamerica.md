# php-coord/datapack-northamerica

> 标签: coord, geo, grid ref, latitude, longitude, map, north america, projection

## 简介

PHPCoord high-accuracy addon datapack for North America

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
