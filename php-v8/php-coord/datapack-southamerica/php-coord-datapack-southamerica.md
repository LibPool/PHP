# php-coord/datapack-southamerica

> 标签: coord, geo, grid ref, latitude, longitude, map, projection, south america

## 简介

PHPCoord high-accuracy addon datapack for South America

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
