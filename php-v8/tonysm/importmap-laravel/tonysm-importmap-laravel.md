# tonysm/importmap-laravel

> 标签: importmap-laravel, laravel, tonysm

## 简介

Use ESM with importmap to manage modern JavaScript in Laravel without transpiling or bundling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
