# tietge/silverstripe-markup

> 标签: Kommentare, elemental, feedback, markup, review, silverstripe

## 简介

Anmerkungen direkt auf der Website für SilverStripe: eingeloggte Kunden markieren einen Punkt oder Bereich, beschreiben, was anders sein soll, und hängen Bilder an — die Agentur arbeitet die Anmerkungen im CMS ab.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
