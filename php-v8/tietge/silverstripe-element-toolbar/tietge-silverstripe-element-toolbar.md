# tietge/silverstripe-element-toolbar

> 标签: editing, elemental, frontend, silverstripe, spacing, toolbar

## 简介

Werkzeugleiste für Elemental-Blöcke im Frontend: Sprung ins CMS und Stufenfelder (z. B. Abstände) direkt am Block stellen – mit sofortiger Vorschau und Speichern im Hintergrund.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
