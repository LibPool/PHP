# tietge/silverstripe-shipping-dpd

> 标签: dpd, etikett, shipping, silvershop, silverstripe, versand

## 简介

DPD-Paketdienst für tietge/silverstripe-shipping — Etiketten über die SOAP-Webdienste von DPD Deutschland.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
