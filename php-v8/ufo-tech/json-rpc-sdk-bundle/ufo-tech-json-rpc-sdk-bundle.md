# ufo-tech/json-rpc-sdk-bundle

> 标签: Ufo, api, bundle, generator, json-rpc, sdk, sdk-generate, symfony

## 简介

The Symfony bundle for simple usage Json-RPC api with dynamic SDK

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
