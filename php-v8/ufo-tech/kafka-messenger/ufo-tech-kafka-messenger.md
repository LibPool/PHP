# ufo-tech/kafka-messenger

> 标签: Messenger, kafka, rdkafka, symfony, transport

## 简介

Kafka transport for Symfony Messenger, built directly on librdkafka: one DSN per environment, confirmed delivery and partition keys.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
