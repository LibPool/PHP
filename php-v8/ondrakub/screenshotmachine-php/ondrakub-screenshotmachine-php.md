# ondrakub/screenshotmachine-php

> 标签: machine, screenshot, screenshotmachine

## 简介

Easy-to-use library for works with https://screenshotmachine.com.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
