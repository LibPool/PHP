# larago/socket

> 标签: Authentication, Broadcasting, Socket, channel, go, golang, jwt, laravel, private-channels, public-channels, real-time, server, websocket

## 简介

Real-time WebSocket Broadcasting Engine for Laravel. Go-powered server with cross-platform support (Windows, macOS, Linux). Public & Private channels with JWT authentication.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
