# wunderdata/mailchimp-bundle

> 标签: api, email, mailchimp

## 简介

Symfony2 Bundle for Mailchimp v2.0 API and Export v1.0 API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
