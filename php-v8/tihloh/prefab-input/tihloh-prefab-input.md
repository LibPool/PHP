# tihloh/prefab-input

> 标签: casting, filtering, framework-independent, input, modular, multipart, normalization, php, prefab, sanitization, upload, validation

## 简介

Framework-independent input validation, normalization, casting, wildcard arrays and multipart upload handling for Prefab PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
