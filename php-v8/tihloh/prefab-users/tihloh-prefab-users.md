# tihloh/prefab-users

> 标签: Users, framework-independent, modular, php, prefab, user-management

## 简介

Standalone, framework-independent user management and project-table mapping for Prefab PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
