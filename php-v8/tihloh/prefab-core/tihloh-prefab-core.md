# tihloh/prefab-core

> 标签: cache, cli, core, database, date, dotenv, framework-independent, modular, php, prefab, runtime, session, time, utilities, value

## 简介

Shared infrastructure for Prefab PHP modules: runtime, config, database, session, cache, contracts, diagnostics and CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
