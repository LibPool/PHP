# tihloh/prefab-image

> 标签: Webp, avif, framework-independent, gd, image, jpeg, modular, php, prefab, resize, thumbnail

## 简介

Fast framework-independent image inspection, resizing, conversion, optimization and delivery for Prefab PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
