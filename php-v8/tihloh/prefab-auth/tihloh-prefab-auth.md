# tihloh/prefab-auth

> 标签: Authentication, auth, framework-independent, modular, oauth, php, prefab

## 简介

Standalone, framework-independent authentication building blocks for Prefab PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
