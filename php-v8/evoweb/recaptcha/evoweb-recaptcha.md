# evoweb/recaptcha

> 标签: Invisible captcha, nocaptcha 2, recaptcha

## 简介

Easy on Humans, Hard on Bots

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
