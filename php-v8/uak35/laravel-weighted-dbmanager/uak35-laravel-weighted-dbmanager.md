# uak35/laravel-weighted-dbmanager

> 标签: database, laravel, laravel-package, load-balancing, pgcat, read-replicas, read-write-splitting, redis, swrr

## 简介

Smooth weighted round-robin read-replica routing, windowed writer fallback and replica health tracking for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
