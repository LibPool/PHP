> 标签: ardent, history, laravel, model, restore, version

## 简介

Fork from mpociot/versionable Allows to create Laravel 4 / 5 / 6 / 7 Model versioning and restoring

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
