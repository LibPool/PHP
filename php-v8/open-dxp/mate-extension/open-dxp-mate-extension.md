# open-dxp/mate-extension

> 标签: Agent, ai, mate, opendxp

## 简介

Symfony AI Mate extension for OpenDXP. Gives coding agents the facts of the installation and the skills to build on it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
