# puli/factory

> 标签: PHP

## 简介

A factory API for Puli's core services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://puli.io
- 源码仓库：https://github.com/puli/factory.git
- Packagist 页面：https://packagist.org/packages/puli%2Ffactory
