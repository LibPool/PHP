# fabriq/streaming

> 标签: PHP

## 简介

Fabriq Streaming — Live-streaming pipeline with HLS, WebRTC signaling, transcoding, chat moderation, and viewer tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
