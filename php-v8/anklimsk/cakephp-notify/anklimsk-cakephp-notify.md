# anklimsk/cakephp-notify

> 标签: PHP

## 简介

Sending E-mail using task queues and sending a notification to the user using WEB Notifications API from CakePHP 2.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
