# theimagingsource/tisd-sdk

> 标签: PHP

## 简介

PHP wrapper for The Imaging Source Download System Web API. Authored and supported by The Imaging Source Europe GmbH.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
