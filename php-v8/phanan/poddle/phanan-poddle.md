# phanan/poddle

> 标签: feed, parser, podcast, psp-1, rss, xml

## 简介

Parse podcast feeds with PHP following PSP-1 Podcast RSS Standard

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
