# dedomorozoff/kommo-api-php

> 标签: ajax, amoCRM, api, api-wrapper, crm, kommo, logging, oauth2, throttling

## 简介

Simple wrapper PHP7+ for API kommo/amoCRM with oAuth 2.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
