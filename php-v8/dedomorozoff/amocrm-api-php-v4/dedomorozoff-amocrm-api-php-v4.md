# dedomorozoff/amocrm-api-php-v4

> 标签: ajax, amoCRM, api, api-wrapper, crm, logging, oauth2, throttling

## 简介

Простая обертка для работы с API amoCRM v4 с авторизацией по протоколу oAuth 2.0 или по API-ключу пользователя, поддержкой AJAX-запросов к frontend-методам, троттлингом запросов, блокировкой одновременного обновления одной сущности и логированием запросов/ответов к API в файл

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
