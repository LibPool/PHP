# azure-oss/storage-blob-flysystem-bundle

> 标签: PHP

## 简介

Symfony bundle bridge for the PHP OSS for Azure Flysystem adapter (league/flysystem-bundle 3.7+).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
