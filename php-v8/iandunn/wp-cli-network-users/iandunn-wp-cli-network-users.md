# iandunn/wp-cli-network-users

> 标签: Users, multisite, wordpress, wp-cli

## 简介

WP-CLI commands for managing users across a WordPress Multisite network

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
