# panelify/metadata

> 标签: PHP

## 简介

Laravel Blade admin module for managing model metadata with CRUD, views, and routes, built on jobmetric/laravel-metadata for seamless Panelio integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
