# panelify/language

> 标签: PHP

## 简介

Laravel Blade admin module for managing model language with CRUD, views, and routes, built on jobmetric/laravel-language for seamless Panelio integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
