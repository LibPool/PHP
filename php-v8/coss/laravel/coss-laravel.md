# coss/laravel

> 标签: coss, email, laravel, mail, transport

## 简介

Send Laravel mail through coss.com.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://coss.com/docs/integrations/laravel
- 源码仓库：https://github.com/cosscom/coss-laravel.git
- Packagist 页面：https://packagist.org/packages/coss%2Flaravel

## 历史版本号

- 当前版本：v0.1.0

- v0.1.0

## 获取地址

- Composer 安装：`composer require coss/laravel`
- Packagist 仓库：https://repo.packagist.org/p2/coss/laravel.json
- 许可证：MIT
- PHP 要求：^8.2
