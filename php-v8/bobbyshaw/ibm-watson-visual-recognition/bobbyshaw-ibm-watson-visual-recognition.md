# bobbyshaw/ibm-watson-visual-recognition

> 标签: bluemix, ibm, visual recognition, watson

## 简介

A php library to provide API calls & handle authentication with the Bluemix visual recognition

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
