# saitho/legacy-icons

> 标签: PHP

## 简介

Legacy Backend Icons - Restores the original colorful icons to TYPO3 CMS v14 backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
