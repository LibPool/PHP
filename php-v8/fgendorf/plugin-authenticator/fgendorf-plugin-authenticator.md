# fgendorf/plugin-authenticator

> 标签: PHP

## 简介

2FA authentication plugin for sysPass based on TOTP algorithm (RFC 6238)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://syspass.org
- 源码仓库：https://github.com/fgendorf/plugin-Authenticator.git
- Packagist 页面：https://packagist.org/packages/fgendorf%2Fplugin-authenticator
