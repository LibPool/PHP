# up2dev/user-totp

> 标签: PHP

## 简介

Ajoute un TOTP (2FA) optionnel et par utilisateur au-dessus d'un système d'authentification existant, sans le modifier. Aucun service externe : tout le calcul TOTP est local (RFC 6238).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
