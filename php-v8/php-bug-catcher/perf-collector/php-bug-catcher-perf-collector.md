# php-bug-catcher/perf-collector

> 标签: bug-catcher, monitoring, performance, profiling

## 简介

Per-request performance collector for Bug Catcher: an auto_prepend_file hook and a cron aggregator, with no PHP extension and no dependencies

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
