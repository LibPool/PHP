# php-bug-catcher/perf-collector-bundle

> 标签: bug-catcher, monitoring, performance, profiling, symfony

## 简介

Symfony integration for the Bug Catcher performance collector: the aggregator as a console command, and Doctrine SQL metrics in every sample

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
