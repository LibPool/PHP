# chroma-x/qr-code-suite

> 标签: code, encode, qr, quick response

## 简介

A collection of classes to QR enccode strings and render them as PNG, TIFF and vectorized EPS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
