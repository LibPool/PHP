# richbrains/ai-textarea

> 标签: PHP

## 简介

AI-powered textarea for Symfony as a dedicated form type with a clean modal UI. Let users rewrite text using an OpenAI‑compatible API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
