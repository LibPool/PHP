# spiffy/spiffy-view

> 标签: PHP

## 简介

Spiffy\View is a light-weight, HHVM compatible, and dependency free view compatability layer. It does not provide its own templating system!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
