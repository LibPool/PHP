# spiffy/spiffy-dispatch

> 标签: PHP

## 简介

Spiffy\Dispatch is a light-weight, HHVM compatible, and dependency free dispatching library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
