# spiffy/spiffy-package

> 标签: PHP

## 简介

Spiffy\Package is a light-weight, HHVM compatible, and dependency lite package manager.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
