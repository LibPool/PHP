# spiffy/spiffy-framework

> 标签: PHP

## 简介

Spiffy\Framework is a full-stack framework for PHP built from light weight components and 100% HHVM compatible.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
