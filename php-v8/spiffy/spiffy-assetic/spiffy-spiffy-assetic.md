# spiffy/spiffy-assetic

> 标签: PHP

## 简介

Spiffy\AsseticPackage is a package for SpiffyFramework that helps you manage your assets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
