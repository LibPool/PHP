# semitexa/theme-sky

> 标签: semitexa, skin, sky, theme, tokens

## 简介

Sky theme for Semitexa — brand skin, base layout, and header/footer partials built on semitexa/platform-ui.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
