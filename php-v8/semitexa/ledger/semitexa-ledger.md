# semitexa/ledger

> 标签: event-sourcing, jetstream, ledger, nats, semitexa, sqlite

## 简介

Semitexa Ledger — SQLite append-only event ledger with NATS JetStream multi-node propagation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
