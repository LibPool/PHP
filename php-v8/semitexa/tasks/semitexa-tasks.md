# semitexa/tasks

> 标签: Tasks, os, productivity, semitexa, task-manager

## 简介

Semitexa OS task manager: an ORM-backed task list (status, progress, deadlines) with an AI-assistant integration that proactively reports auto-completed tasks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
