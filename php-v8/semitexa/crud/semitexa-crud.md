# semitexa/crud

> 标签: admin, crud, feed, grid, semitexa

## 简介

Semitexa CRUD: admin screens declared in one class — a list with its live feed, forms and actions (#[AsCrud]), settings pages (#[AsSettingsPage]), dashboard widgets for screens, field-driven collection feeds (#[AsCollectionFeed]).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
