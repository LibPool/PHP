# semitexa/api

> 标签: api, m2m, machine-auth, semitexa, versioning

## 简介

Semitexa API - external API product layer with machine credentials, versioned routes, and M2M contracts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
