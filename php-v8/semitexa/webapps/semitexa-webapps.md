# semitexa/webapps

> 标签: iframe, launcher, os, semitexa, web-apps

## 简介

Semitexa OS external web-apps registry: wrap any site (YouTube, Netflix, Google Docs…) as a first-class OS app the model can add on demand

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
