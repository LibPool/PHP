## 简介

Stop AI coding agents from faking "done" in Laravel. ai:verify runs only the tests, Larastan, Pint and Laravel checks a diff needs, fails on deleted or skipped tests, and stamps verified commits for CI. ai:graph gives agents a code graph of routes, controllers, models, views and tests, with impact analysis.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
