# semitexa/graphql

> 标签: graphql, handler, payload, schema, semitexa

## 简介

Semitexa GraphQL - opt-in GraphQL operation discovery built on Payload DTO, Handler, and typed output contracts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
