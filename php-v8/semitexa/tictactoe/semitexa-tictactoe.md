# semitexa/tictactoe

> 标签: game, llm, os, semitexa, tic-tac-toe

## 简介

Semitexa OS tic-tac-toe: a UI-skill game you play against Semi (every move is a real LLM call)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
