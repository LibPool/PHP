# semitexa/showcase-kit

> 标签: docs-site, feature-pages, layouts, semitexa, showcase

## 简介

Shared structural layer (layout, feature-tree, L1/L2/L3 feature page, components) for docs-backed feature-showcase sites. Consumed by semitexa-demo and semitexa-platform-site; only palette and content differ per site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
