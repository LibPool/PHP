# geniusauth/laravel

> 标签: Authentication, laravel, oauth2, oidc, openid-connect, passkeys, webauthn

## 简介

Official Laravel SDK for GeniusAuth OpenID Connect authentication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
