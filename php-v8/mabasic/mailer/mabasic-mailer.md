# mabasic/mailer

> 标签: email, laravel, mail, mailer

## 简介

Laravel 4 package for more efficient email sending inspired by Laracasts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
