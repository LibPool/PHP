# silverback/wp-ecommerce

> 标签: PHP

## 简介

A metapackage to manage installation of WP plugins to build a successfule ecommerce. Companion for silverback/wp-website

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
