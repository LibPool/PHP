# pixelfed/google2fa

> 标签: 2fa, Authentication, Two Factor Authentication, google2fa, laravel

## 简介

A One Time Password Authentication package, compatible with Google Authenticator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
