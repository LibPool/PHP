# adachsoft/packagist-releaser-lib

> 标签: composer, package, packagist, publishing, release, validation

## 简介

Library for validating and releasing PHP packages to Packagist with automatic metadata resolution and routing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://packagist.org/packages/adachsoft%2Fpackagist-releaser-lib
- 源码仓库：https://gitlab.com/a.adach/packagist-releaser-lib.git
- Packagist 页面：https://packagist.org/packages/adachsoft%2Fpackagist-releaser-lib
