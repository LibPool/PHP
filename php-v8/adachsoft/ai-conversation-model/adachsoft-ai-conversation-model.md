# adachsoft/ai-conversation-model

> 标签: ai-conversation-model

## 简介

Provider-agnostic, multimodal data model for AI conversations (messages, content parts, tool calls/results, response format, token usage, cost).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
