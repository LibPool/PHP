# adachsoft/file-tool-security-policy

> 标签: Policy, allowlist, denylist, extension, file, glob, path, php, security

## 简介

Configurable security policy for file tools with path and extension allow and deny rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
