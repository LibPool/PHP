# adachsoft/workflow

> 标签: automation, business-process, context-isolation, orchestration, php-workflow, plugin-system, step-based, workflow, workflow-engine

## 简介

Lightweight, extensible PHP workflow engine with plugin-based steps, context isolation, debugging and nested workflow support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
