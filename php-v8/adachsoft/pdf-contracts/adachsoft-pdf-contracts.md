# adachsoft/pdf-contracts

> 标签: contracts, conversion, pdf, text-extraction, value-objects

## 简介

Contracts, DTOs, Enums and Value Objects for PDF conversion and text extraction.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
