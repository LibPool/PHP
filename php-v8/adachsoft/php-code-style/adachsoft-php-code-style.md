# adachsoft/php-code-style

> 标签: PHPStan, code-style, coding-standards, php-cs-fixer, psr-12

## 简介

Shared PHP code style (PHP-CS-Fixer) and PHPStan baseline for PHP 8.3+ projects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
