# adachsoft/text-to-audio-xai

> 标签: adachsoft, audio, text-to-speech, tts, xai

## 简介

Explainable text-to-audio library built on top of adachsoft/text-to-audio-contract.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
