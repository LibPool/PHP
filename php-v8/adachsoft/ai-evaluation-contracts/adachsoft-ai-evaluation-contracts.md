# adachsoft/ai-evaluation-contracts

> 标签: Evaluation, ai, contracts, php, rules, verdicts

## 简介

Provider-agnostic PHP contracts for evaluating text against structured AI rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
