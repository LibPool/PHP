# adachsoft/phpunit-runner-lib

> 标签: cli, php, phpunit, test-runner, testing

## 简介

Library for running PHPUnit via CLI and parsing results into structured DTOs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
