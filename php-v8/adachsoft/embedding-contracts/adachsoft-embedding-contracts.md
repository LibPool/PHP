# adachsoft/embedding-contracts

> 标签: ai, collections, contracts, dto, embeddings, nlp, vector

## 简介

Provider-agnostic contracts and DTOs for text embeddings in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
