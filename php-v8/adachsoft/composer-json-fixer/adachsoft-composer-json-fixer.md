# adachsoft/composer-json-fixer

> 标签: adachsoft, cli, composer, composer.json, fixer, validator

## 简介

Validate and automatically fix composer.json files for PHP libraries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
