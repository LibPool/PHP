# adachsoft/version-php

> 标签: composer, git, php, semantic-versioning, version-management

## 简介

PHP adapters for reading and calculating semantic versions from Composer metadata and Git tags.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
