# adachsoft/task-api-repository

> 标签: api, http, php, repository, task

## 简介

HTTP implementation of the adachsoft/task-contracts repositories backed by adachsoft/task-api.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
