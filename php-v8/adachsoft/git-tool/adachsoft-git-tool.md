# adachsoft/git-tool

> 标签: adapter, ai-tool, ai-tool-call, git, spi

## 简介

Git tool adapter for adachsoft/ai-tool-call built on top of adachsoft/gitlib.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
