# adachsoft/web-content-fetch-contract

> 标签: content-fetching, http, scraping, spi, web-content

## 简介

Provider-agnostic SPI contracts and exceptions for fetching and extracting web content from URLs in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
