# adachsoft/ssh-tool

> 标签: ai-tool, ai-toolcall, command-pattern, php, remote-exec, remote-execution, session-management, ssh, ssh-client, ssh-exec, strategy-pattern

## 简介

SSH integration for AdachSoft AiToolCall — login, remote command execution and session management for pluggable AI tool actions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
