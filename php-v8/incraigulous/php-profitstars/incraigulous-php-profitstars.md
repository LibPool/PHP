# incraigulous/php-profitstars

> 标签: ProfitStars, ach

## 简介

A service that processes ACH transactions throgh Jack Henry's ProfitStars API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
