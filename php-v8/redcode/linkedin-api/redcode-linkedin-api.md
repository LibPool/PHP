# redcode/linkedin-api

> 标签: api, cache, filesystem, linkedin, oauth

## 简介

A PHP implementation of the LinkedIn API with caching ability

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
