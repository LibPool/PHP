# cstudios/turbo

> 标签: Craft, cms, craft-plugin, craftcms, page cache, turbo

## 简介

This plugin utilizes the PageCache filter from yii2 into your craft 3 instance

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
