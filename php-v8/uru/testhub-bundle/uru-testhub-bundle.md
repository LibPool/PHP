# uru/testhub-bundle

> 标签: PHP

## 简介

TestHub Bundle for Symfony: routes HttpClient traffic to a TestHub sandbox from the web profiler (dev only)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
