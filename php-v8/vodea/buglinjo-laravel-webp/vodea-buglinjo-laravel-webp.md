# vodea/buglinjo-laravel-webp

> 标签: Buglinjo, LaravelWebp, Webp, laravel

## 简介

Laravel 5 package for WebP image format

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
