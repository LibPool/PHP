# aure-ex/sdk

> 标签: aure-ex, aureex, crypto, openapi, payments, sdk

## 简介

SDK oficial da API AureEX para PHP (tipado via OpenAPI)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
