# serpcheap/laravel

> 标签: SERP, api, google, laravel, scraping, search

## 简介

Laravel integration for the serp.cheap Google SERP API — ServiceProvider, Facade, cached client, and an artisan command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
