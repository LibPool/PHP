# serpcheap/serpcheap

> 标签: SERP, api, google, scraping, search

## 简介

Official PHP client for the serp.cheap Google SERP API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/SerpCheap/serpcheap-php.git
- Packagist 页面：https://packagist.org/packages/serpcheap%2Fserpcheap
