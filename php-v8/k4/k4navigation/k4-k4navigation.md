# k4/k4navigation

> 标签: Craft, cms, craft-plugin, craftcms, k4navigation, navigation plugin

## 简介

Advanced navigation and breadcrumb Plugin (Twig filter) for Craft CMS 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
