# splittlogic/fw

> 标签: bootstrap, framework, laravel, livewire, splittlogic

## 简介

Framework package for Laravel: Livewire 3.0.10, Bootstrap 5.3.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
