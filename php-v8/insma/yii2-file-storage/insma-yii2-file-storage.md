# insma/yii2-file-storage

> 标签: database storage, extension, file, local storage, storage, web storage, yii2

## 简介

File storage extension for Yii2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
