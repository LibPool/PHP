# bluebeetle/api-toolkit

> 标签: JSON-API, api, laravel, rest, toolkit

## 简介

JSON:API compliant toolkit for building REST APIs with Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
