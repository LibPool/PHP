# wpmetabox/meta-box-facetwp-integrator

> 标签: custom-field, custom-post-type, meta-box, select2, ui, wordpress, wordpress-plugin, wp-admin

## 简介

Integrates Meta Box custom fields with FacetWP. Make custom fields filterable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
