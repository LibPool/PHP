# tanglephp/chronicle-client

> 标签: crypto, iota, shimmer, stardust, tangle

## 简介

Client to interact with a Shimmer/IOTA (Stardust) ChronicleNode

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
