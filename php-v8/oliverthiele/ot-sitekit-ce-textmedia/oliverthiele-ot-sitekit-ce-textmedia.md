# oliverthiele/ot-sitekit-ce-textmedia

> 标签: PHP

## 简介

CE Textmedia - TYPO3 content element that displays an image with text. Integrates with the Sitekit and ot-irrebuttons extensions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
