# oliverthiele/ot-ceheader

> 标签: CKEditor, content-element, extension, header, rte, typo3

## 简介

CE Header - Adds an optional RTE-based header field (header_rte) with preheader and icon support for tt_content headers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
