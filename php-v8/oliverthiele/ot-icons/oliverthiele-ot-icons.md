# oliverthiele/ot-icons

> 标签: PHP

## 简介

Icon ViewHelper - ViewHelper for rendering icons in your FluidTemplates. The output can be changed from one icon set to another at a later date.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
