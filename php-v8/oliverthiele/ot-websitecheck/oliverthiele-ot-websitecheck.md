# oliverthiele/ot-websitecheck

> 标签: Sitemap, TYPO3 CMS, TYPO3 Extension, broken links, migration, redirect, relaunch, seo

## 简介

Website Check - Store TYPO3 XML sitemaps as snapshots, record HTTP status and error markers per URL, and check whether the URLs of a live site still lead to the same content after a relaunch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
