# oliverthiele/ot-recordselector

> 标签: PHP

## 简介

Record Selector - Custom backend form element for selecting TYPO3 records with translated titles, AJAX autocomplete, permission checks, and hidden-record indicators

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
