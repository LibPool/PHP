# imt/data-grid

> 标签: datagrid, jqgrid, jquery

## 简介

This library provides a simple, powerful and fully customizable tool for generating data-bound grids

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
