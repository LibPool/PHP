# stezkoy/flarum-feed2forum

> 标签: atom, discussions, feeds, flarum, rss

## 简介

A Flarum extension that turns RSS/Atom feeds into real forum discussions, posted to tags by a selected user.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
