# stezkoy/flarum-audex

> 标签: PHP

## 简介

Per-block script injection into the page head or before the closing body tag, omitted for selected users and groups. Ads, analytics, widgets — any HTML/JS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
