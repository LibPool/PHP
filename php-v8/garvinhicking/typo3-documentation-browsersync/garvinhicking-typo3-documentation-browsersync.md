# garvinhicking/typo3-documentation-browsersync

> 标签: PHP

## 简介

Standalone project (NodeJS, browsersync) to render and hot-reload changes in ReST documentation to your browser window

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
