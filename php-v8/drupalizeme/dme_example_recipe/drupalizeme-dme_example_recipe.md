# drupalizeme/dme_example_recipe

> 标签: PHP

## 简介

Example Drupal recipe that adds a Blog content type with Tags and content editor permissions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
