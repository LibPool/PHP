# square1/laravel-idempotency

> 标签: api, idempotency, laravel-idempotency, square1

## 简介

Add idempotency to Laravel-based APIs, preventing duplicate request processing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
