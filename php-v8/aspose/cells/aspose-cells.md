# aspose/cells

> 标签: Excel to PDF, MHTML, OOXML, SpreadSheetML, XLSB, XPS, convert, csv, docx, excel, html, jpg, json, markdown, numbers, ods, pdf, pptx, spreadsheet, sql, svg, xls, xlsm, xlsx, xml

## 简介

A powerful library for manipulating and converting Excel (XLS, XLSX, XLSB), ODS, CSV and HTML files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
