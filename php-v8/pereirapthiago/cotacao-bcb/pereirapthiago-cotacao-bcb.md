# pereirapthiago/cotacao-bcb

> 标签: PHP

## 简介

Pacote PHP 8.2 para download e parse de cotações de todas as moedas do Banco Central do Brasil

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
