# imonroe/mimeutils

> 标签: imonroe, mimetypes, mimeutils

## 简介

A helper for working with MIME types, particularly for validating uploads.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
