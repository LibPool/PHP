# itpajaku/sippenkripsi

> 标签: codeigniter, encryption, enkripsi, mahkamah-agung, mcrypt, perkara-id, phpseclib, rijndael-256, sipp

## 简介

Library PHP standalone untuk enkripsi dan dekripsi perkara_id SIPP (Sistem Informasi Penelusuran Perkara) kompatibel dengan CodeIgniter 2 / PHP 5 mcrypt.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
