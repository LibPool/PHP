# lavoiesl/doctrine-cache-provider

> 标签: PHP

## 简介

Library to add a Doctrine Provider to allow Doctrine Cache to connect to databases.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
