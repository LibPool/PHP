# pvlima/media-feed

> 标签: RSS feed, instagram api, instagram feed, media feed, social media api

## 简介

API para obter um feed de publicações de uma determinada pagina de rede social

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
