# pulseline/jalali-events

> 标签: Jalali, calendar, events, holidays, iran, iranian-calendar, laravel, official-holidays, persian-calendar, time.ir

## 简介

A Laravel package for Iranian Jalali calendar events, official holidays, date ranges, and automatic calendar synchronization.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
