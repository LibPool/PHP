# econea/nusoap

> 标签: client, http, nusoap, php, soap, transport, xml

## 简介

Fixed NuSOAP for PHP 5.4 - 8.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
