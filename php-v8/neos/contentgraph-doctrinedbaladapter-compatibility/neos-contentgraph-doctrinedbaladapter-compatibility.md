# neos/contentgraph-doctrinedbaladapter-compatibility

> 标签: PHP

## 简介

Forward compatibility layer to allow smooth upgrades to Neos version which provide a new content graph implementation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
