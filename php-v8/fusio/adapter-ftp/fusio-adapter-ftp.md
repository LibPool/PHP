# fusio/adapter-ftp

> 标签: fusio-adapter

## 简介

Adapter to serve files via FTP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.fusio-project.org
- 源码仓库：https://github.com/apioo/fusio-adapter-ftp.git
