# phix/exceptionslib

> 标签: error handling, exceptions

## 简介

exceptionslib is a simple-to-use PHP component that simplifies error handling in your PHP apps and components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
