# studio1/batch-operation

> 标签: PHP

## 简介

This bundle extends Pimcore core functionality by adding buttons in asset list view, e.g. to add / replace tags or move selected assets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
