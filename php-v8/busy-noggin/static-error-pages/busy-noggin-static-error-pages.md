# busy-noggin/static-error-pages

> 标签: PHP

## 简介

Integration to serve error documents as TTL-configurable and auto-refreshing static versions of an URL or TYPO3 page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
