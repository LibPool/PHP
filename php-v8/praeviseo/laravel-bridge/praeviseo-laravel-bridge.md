# praeviseo/laravel-bridge

> 标签: Bridge, laravel, praeviseo, publishing, seo

## 简介

Official lightweight Laravel bridge for connecting a client site to PraeviSEO.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
