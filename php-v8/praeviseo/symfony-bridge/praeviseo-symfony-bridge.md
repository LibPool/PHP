# praeviseo/symfony-bridge

> 标签: Bridge, praeviseo, publishing, seo, symfony

## 简介

Official lightweight Symfony bridge for connecting a client site to PraeviSEO.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
