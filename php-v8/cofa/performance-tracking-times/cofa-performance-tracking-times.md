# cofa/performance-tracking-times

> 标签: Server-Timing, laravel, monitoring, performance, response-time, waterfall

## 简介

Per-request timing breakdown for Laravel (calculating, network out, delay, service, network return) with a dashboard and a waterfall diagram for every request.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
