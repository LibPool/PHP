# uazgraduatecollege/cakephp-casauth

> 标签: PHP

## 简介

CAS Authentication wrapper for CakePHP 4.x using Apereo (formerly Jasig) phpCAS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
