# cheese-burgames/php-xtralife-gateway

> 标签: PHP

## 简介

Gateway for XtraLife game-as-a-platform backoffice and backend API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
