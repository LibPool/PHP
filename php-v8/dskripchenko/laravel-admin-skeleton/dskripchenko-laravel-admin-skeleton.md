# dskripchenko/laravel-admin-skeleton

> 标签: Skeleton, admin, admin-panel, crud, dashboard, laravel

## 简介

A Laravel application with dskripchenko/laravel-admin built in: users, roles, audit log, an example resource and dashboard — ready to log in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
