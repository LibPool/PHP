# dskripchenko/php-pdf-cloud-kms

> 标签: PHP-PDF, aws-kms, azure-key-vault, google-cloud-kms, hsm, kms, pades, pdf, signature

## 简介

Cloud KMS signers for dskripchenko/php-pdf: sign PDFs (PAdES, RSA and ECDSA) with keys held by AWS KMS, Google Cloud KMS or Azure Key Vault — the key never leaves the cloud.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
