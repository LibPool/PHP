# dskripchenko/laravel-admin-oidc

> 标签: SSO, admin, dskripchenko, keycloak, laravel, oidc, openid-connect

## 简介

Sign in to dskripchenko/laravel-admin panels with OpenID Connect — Keycloak, Microsoft Entra ID, ADFS, Authentik or any OIDC provider: account provisioning, role mapping, per-tenant providers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
