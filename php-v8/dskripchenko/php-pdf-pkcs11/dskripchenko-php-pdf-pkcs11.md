# dskripchenko/php-pdf-pkcs11

> 标签: PHP-PDF, gost, hsm, pades, pdf, pkcs11, rutoken, signature, smart-card, softhsm, token, yubikey

## 简介

PKCS#11 signer for dskripchenko/php-pdf: sign PDFs (PAdES: RSA, ECDSA and GOST R 34.10-2012) with a key held by an HSM, a smart card or a USB token, through the php-pkcs11 extension.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
