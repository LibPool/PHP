# dohernandez/chassis

> 标签: api, framework, micro-service

## 简介

Simple php's application chassis based on open-sources packages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://packagist.org/packages/dohernandez%2Fchassis
- 源码仓库：https://github.com/dohernandez/chassis.git
