# ebess/laravel-inertia-shared-data-provider

> 标签: inertia, inertiajs, laravel, laravel-inertia

## 简介

Provide shared data to inertia js application in laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
