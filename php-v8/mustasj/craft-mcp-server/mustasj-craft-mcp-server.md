# mustasj/craft-mcp-server

> 标签: ai, craft-cms, craftcms, mcp, model-context-protocol

## 简介

MCP-server for Craft CMS 5 — eksponerer innhold over Model Context Protocol med token-autentisering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
