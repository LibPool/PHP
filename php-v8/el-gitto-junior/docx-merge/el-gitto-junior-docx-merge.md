# el-gitto-junior/docx-merge

> 标签: docx, merge, placeholder

## 简介

Simple library for merging multiple MS Word ".docx" files into one

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
