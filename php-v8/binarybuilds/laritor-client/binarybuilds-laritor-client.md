# binarybuilds/laritor-client

> 标签: Laravel Debug, application performance monitoring, laravel, laravel analytics, laravel apm, laravel monitoring, laravel observability, laravel performance, laravel tracing

## 简介

The official Laritor client for Laravel. Stream traces, exceptions, queries, jobs, and more to your Laritor dashboard in under 30 seconds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
