# segpacto/yii2-ews

> 标签: calendar, ews, exchange, extension, mailbox, yii2

## 简介

Extension conversion of 'EWS' to yii2 extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
