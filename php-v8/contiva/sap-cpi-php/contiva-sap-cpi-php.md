# contiva/sap-cpi-php

> 标签: auto-motor, automotive, integration flows, message mappings, sap, sap btp, sap cpi, sap integration suite, script collections, value mappings

## 简介

Comprehensive PHP library for SAP Cloud Platform Integration (CPI) APIs with full CRUD operations, cross-system transport, and Auto-Motor examples

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
