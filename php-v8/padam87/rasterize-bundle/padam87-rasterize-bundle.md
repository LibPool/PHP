# padam87/rasterize-bundle

> 标签: pdf, phantomjs, puppeteer, rasterize, symfony

## 简介

HTML to PDF Symfony bundle. Works with Puppeteer, PhantomJS, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
