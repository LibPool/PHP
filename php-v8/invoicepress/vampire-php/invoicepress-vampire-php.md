# invoicepress/vampire-php

> 标签: PHP

## 简介

Dependency-free, Java-free PHP validator for EN 16931 / XRechnung e-invoices (UBL + CII): native XSD, syntax-rule and business-rule pipeline, own XPath 2.0 subset interpreter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
