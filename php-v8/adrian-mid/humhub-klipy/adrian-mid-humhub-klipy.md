# adrian-mid/humhub-klipy

> 标签: gif, humhub, humhub-module, klipy, media

## 简介

Add GIF search and attachment to HumHub posts and comments via the KLIPY API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
