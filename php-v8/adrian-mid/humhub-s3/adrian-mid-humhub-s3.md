# adrian-mid/humhub-s3

> 标签: aws, files, humhub, humhub-module, s3, storage, upload

## 简介

Store HumHub file uploads in Amazon S3 or an S3-compatible service. Version 2.x requires HumHub 1.18 or later.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
