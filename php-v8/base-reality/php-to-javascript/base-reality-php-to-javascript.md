# base-reality/php-to-javascript

> 标签: PHP

## 简介

A PHP to Javascript converter for automatically converting PHP source code (including Classes) into Javascript.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
