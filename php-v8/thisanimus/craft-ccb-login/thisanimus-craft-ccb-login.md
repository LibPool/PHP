# thisanimus/craft-ccb-login

> 标签: Craft, ccb-login, cms, craft-plugin, craftcms

## 简介

Log in via the CCB API, and log user info in session.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
