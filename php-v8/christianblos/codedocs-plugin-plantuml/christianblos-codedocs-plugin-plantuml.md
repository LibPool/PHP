# christianblos/codedocs-plugin-plantuml

> 标签: PHP

## 简介

Plugin for CodeDocs to generate UML diagrams via PlantUML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
