# forja-de-onix/tanuki-framework

> 标签: framework, lightweight, mvc, php, vanilla-php

## 简介

A lightweight PHP MVC framework for developers who like vanilla PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
