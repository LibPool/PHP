# howincodes/laravel-rabbitmq

> 标签: AMQP, laravel, queue, rabbitmq

## 简介

A Laravel RabbitMQ wrapper with automatic dead-letter retry

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
