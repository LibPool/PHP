# actra/autoloader

> 标签: PHP

## 简介

A simple, lightweight, and efficient PHP Autoloader supporting PSR-4, PSR-0, and filesystem caching with OPcache support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
