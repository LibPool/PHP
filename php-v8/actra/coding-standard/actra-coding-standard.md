# actra/coding-standard

> 标签: PHPStan, actra, agents, coding-standard, per-cs, php-cs-fixer, psr

## 简介

Coding standard of Actra AG: rules for developers and AI assistants, strict PHPStan and PHP-CS-Fixer configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
