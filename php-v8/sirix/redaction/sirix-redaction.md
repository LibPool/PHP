# sirix/redaction

> 标签: Masking, anonymization, data-masking, data-protection, gdpr, laminas, log, logging, mezzio, monolog, monolog-processor, php, pii, privacy, psr-3, redaction, sanitization, security

## 简介

PHP library for data redaction, masking, and sanitization with optional Monolog integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
