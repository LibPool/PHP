# wdb/wdb-remcanlink

> 标签: canonical, seo, seo-meta, typo3, typo3-extension

## 简介

Add the option on pages to remove the canonical link.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
