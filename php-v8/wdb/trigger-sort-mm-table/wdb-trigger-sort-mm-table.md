# wdb/trigger-sort-mm-table

> 标签: PHP

## 简介

This TYPO3 extension includes most relevant TCA configuration to demonstrate and test a MySQL-Trigger.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
