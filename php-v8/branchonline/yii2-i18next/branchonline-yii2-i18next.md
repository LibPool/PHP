# branchonline/yii2-i18next

> 标签: i18n, i18next, yii2

## 简介

Loads the 81next assets and initializes with the languages specified in the app config

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
