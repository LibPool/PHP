# shawnmccool/minimal-php-postmark-sdk

> 标签: PHP

## 简介

A minimal PHP Postmark SDK that enables you to send single and batched email through the PostmarkApp.com service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
