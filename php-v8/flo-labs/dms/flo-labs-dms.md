# flo-labs/dms

> 标签: PHP

## 简介

PHP parser for DMS — a data syntax with strong typing, ordered maps, multi-line heredocs, and front-matter metadata.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
