# darkgoldblade01/velocify

> 标签: php, sdk, velocify

## 简介

Velocify PHP API - an easy to use version of the PHP Velocify API using GuzzleHTTP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
