# darkgoldblade01/infusionsoft

> 标签: infusionsoft, php, sdk

## 简介

Infusionsoft PHP API - an easy to use version of the PHP Infusionsoft API using GuzzleHTTP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
