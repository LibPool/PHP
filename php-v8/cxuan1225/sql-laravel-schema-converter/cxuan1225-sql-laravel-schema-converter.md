# cxuan1225/sql-laravel-schema-converter

> 标签: PHP

## 简介

Convert MySQL or MariaDB CREATE TABLE SQL into Laravel migration schema code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
