# gatherdigital-pimcore-plugin/microsofttranslator

> 标签: azure, microsoft, pimcore, plugin, translator

## 简介

A Plugin to provide access to Microsoft translate service for Pimcore 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
