# bearlikelion/medoo-provider

> 标签: autarky, medoo, orm

## 简介

Service Provider for use of the Eloquent ORM in the Autarky framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
