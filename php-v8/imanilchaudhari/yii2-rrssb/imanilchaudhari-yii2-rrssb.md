# imanilchaudhari/yii2-rrssb

> 标签:  extension,  rrssb,  share bar,  social share, yii2

## 简介

This is a responsive social bar widget for Yii2 projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
