# derry/phalcon-debugbar

> 标签: debug, debugbar, phalcon, profiler, webprofiler

## 简介

Integrates PHP Debug Bar with Phalcon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
