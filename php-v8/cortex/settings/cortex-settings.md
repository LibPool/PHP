# cortex/settings

> 标签: Flexible, application, cortex, enterprise, framework, laravel, module, multi-lingual, rinvex, setting

## 简介

Cortex Settings is a new module for rinvex/cortex applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
