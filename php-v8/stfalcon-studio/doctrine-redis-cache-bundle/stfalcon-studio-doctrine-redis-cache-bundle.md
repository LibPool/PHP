# stfalcon-studio/doctrine-redis-cache-bundle

> 标签: bundle, cache, cache pool, doctrine, redis, symfony

## 简介

Add custom namespace for doctrine cache pools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
