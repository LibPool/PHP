# yangjisen/baum

> 标签: database, eloquent, hierarchy, laravel, nested set, tree

## 简介

Baum is an implementation of the Nested Set pattern for Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
