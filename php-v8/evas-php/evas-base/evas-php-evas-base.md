# evas-php/evas-base

> 标签: evas-php, framework

## 简介

Evas-php base module (App class, RunDirHelper, PhpHelper and more helpers)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
