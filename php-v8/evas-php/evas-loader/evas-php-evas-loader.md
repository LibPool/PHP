# evas-php/evas-loader

> 标签: evas-php, loader, psr0, psr4

## 简介

Classes, Traits and Interfaces autoloader - partially supports PSR0, PSR4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
