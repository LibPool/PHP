# soliphp/aes

> 标签: AES-128-CBC, aes, aes-192-cbc, aes-256-cbc, openssl, soliphp

## 简介

OpenSSL-compatible AES (128, 192, or 256) CBC library for PHP, based on openssl.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
