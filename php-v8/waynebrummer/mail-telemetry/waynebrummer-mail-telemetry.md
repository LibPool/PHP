# waynebrummer/mail-telemetry

> 标签: api, email, laravel, lumen, telemetry, tracker

## 简介

Logs mail transactions and provides a report for email telemetry.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
