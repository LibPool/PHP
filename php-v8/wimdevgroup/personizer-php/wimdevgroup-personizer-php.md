# wimdevgroup/personizer-php

> 标签: calendar, events, ics, personizer, php

## 简介

PHP client library for Personizer calendar API to fetch and filter calendar events from ICS feeds

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
