## 简介

Extends Doctrine with native PostgreSQL support for arrays, JSONB, ranges, PostGIS geometries, text search, ltree, uuid, and 100+ PostgreSQL-specific functions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
