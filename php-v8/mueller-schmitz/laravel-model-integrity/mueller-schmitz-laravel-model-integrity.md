# mueller-schmitz/laravel-model-integrity

> 标签: Audit, eloquent, gobd, hash-chain, integrity, laravel, tamper-evident, versioning

## 简介

Immutable and versioned Eloquent models with a gapless, cryptographically verifiable history.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
