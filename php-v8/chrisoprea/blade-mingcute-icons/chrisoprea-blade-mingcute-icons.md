# chrisoprea/blade-mingcute-icons

> 标签: MingCute Icons, blade, laravel

## 简介

A package to easily make use of MingCute icons in your Laravel Blade views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
