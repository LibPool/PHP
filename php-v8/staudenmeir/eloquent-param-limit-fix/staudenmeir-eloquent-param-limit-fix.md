# staudenmeir/eloquent-param-limit-fix

> 标签: PHP

## 简介

Laravel Eloquent eager loading fix for parameter limits of SQLite and SQL Server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
