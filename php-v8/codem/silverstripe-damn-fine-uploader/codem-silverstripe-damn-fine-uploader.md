# codem/silverstripe-damn-fine-uploader

> 标签: HTML5, file upload, silverstripe, uploader, uploads, uppy

## 简介

An HTML5 upload field for Silverstripe, including editable form fields for silverstripe/userforms

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
