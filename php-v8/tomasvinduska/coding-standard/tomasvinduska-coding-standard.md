# tomasvinduska/coding-standard

> 标签: PHP

## 简介

Coding Standard for PHP_CodeSniffer complements Consistence Coding Standard by providing sniffs with additional checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
