# airmoi/yii2-fmconnector

> 标签: FileMaker, FileMaker API-PHP, extension, odbc, yii2

## 简介

FileMaker ODBC and PHP-API integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
