# wal3fo/phone-country

> 标签: PHP

## 简介

Resolve country code from phone number for Laravel, with AI-powered normalization, disambiguation, fraud detection, and metadata enrichment.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
