# flexyourrights/openpolice-extension

> 标签: Accountability, Flex Your Rights, Open Police, Open Police Complaints, SurvLoop, commendations, compliments, laravel, misconduct, oversight, police departments, survey

## 简介

This package provides a starting point to build country-specific variations of OpenPolice.org.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
