# i-rocky/laravel-twilio

> 标签: PHP

## 简介

Twilio Fax, SMS, MMS, Voice Call recording, receiving, sending support for laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
