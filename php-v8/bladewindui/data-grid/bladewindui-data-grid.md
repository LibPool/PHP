# bladewindui/data-grid

> 标签: blade, bladewindui, content, data-grid, laravel, table, tailwindcss

## 简介

BladewindUI accessible data grid — a higher-level companion to Table with column sorting, filtering, selection, sticky headers, and server-driven state

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
