# besanek/laravel-firebase-notifications

> 标签: filesystem, firebase, laravel, notifications

## 简介

Thin layer for integrate Firebase Messaging as Laravel Notifications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
