# ricardoper/twitteroauth

> 标签: API v1.1, oauth, php, twitter

## 简介

PHP library to communicate with Twitter OAuth API version 1.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
