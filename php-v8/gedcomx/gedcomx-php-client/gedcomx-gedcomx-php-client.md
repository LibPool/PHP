# gedcomx/gedcomx-php-client

> 标签: familysearch, gedcomx, genealogy, sdk

## 简介

PHP libraries for GEDCOM X.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
