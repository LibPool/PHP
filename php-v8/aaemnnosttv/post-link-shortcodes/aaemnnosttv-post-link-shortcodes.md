# aaemnnosttv/post-link-shortcodes

> 标签: PHP

## 简介

A collection of shortcodes for building links, images, or URLs to a given post/archive of any type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
