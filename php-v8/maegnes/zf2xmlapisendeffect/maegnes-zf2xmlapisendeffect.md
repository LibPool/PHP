# maegnes/zf2xmlapisendeffect

> 标签: api, sendeffext, xml, zf2

## 简介

ZF2 module which integrates the sendeffect xml api into your zf2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
