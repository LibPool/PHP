# tenderfield/verifyemail

> 标签: PHP

## 简介

PHP class that can be easily used to verify an email address and make sure it is valid and does exist on the mail server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
