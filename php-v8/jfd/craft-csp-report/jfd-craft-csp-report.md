# jfd/craft-csp-report

> 标签: PHP

## 简介

Sets a Content-Security-Policy-Report-Only header, creates an action to receive CSP violation reports, and logs them to a file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
