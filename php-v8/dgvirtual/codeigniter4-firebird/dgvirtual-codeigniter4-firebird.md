# dgvirtual/codeigniter4-firebird

> 标签: codeigniter4, database, firebird, interbase, pdo

## 简介

PDO-based Firebird/InterBase database driver for CodeIgniter 4

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
