# appstore-reviews-parser/parser

> 标签: appstore, itunes, parser, reviews, rss

## 简介

A standalone PHP library for parsing App Store reviews from iTunes RSS feed

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
