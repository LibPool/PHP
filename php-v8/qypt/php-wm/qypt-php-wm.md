# qypt/php-wm

> 标签: 快手去水印, 抖音去水印, 视频去水印

## 简介

php短视频去水印接口案例，集成了抖音去水印、快手去水印、微视去水印、头条去水印、火山去水印

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
