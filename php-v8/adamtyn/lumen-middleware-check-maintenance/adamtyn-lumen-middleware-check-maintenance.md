# adamtyn/lumen-middleware-check-maintenance

> 标签: adamtyn, framework, laravel, lumen

## 简介

移植Laravel的 `CheckForMaintenanceMode` [检查维护模式]中间件到Lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
