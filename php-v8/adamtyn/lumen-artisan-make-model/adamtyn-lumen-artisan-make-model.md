# adamtyn/lumen-artisan-make-model

> 标签: adamtyn, framework, laravel, lumen

## 简介

移植Laravel的 `php artisan make:model` [快速创建模型] 指令到Lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
