# adamtyn/lumen-artisan-serve

> 标签: adamtyn, framework, laravel, lumen

## 简介

移植Laravel的 `php artisan serve` [快速启动服务]指令到Lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
