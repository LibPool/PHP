# beboc/laravel-sms

> 标签: laravel, lumen, sms

## 简介

A Laravel and Lumen integration for matthewbdaly/sms-client to enable sending SMS messages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
