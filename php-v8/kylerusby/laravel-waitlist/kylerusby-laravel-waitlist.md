# kylerusby/laravel-waitlist

> 标签: Kyle Rusby, laravel, laravel-waitlist

## 简介

A package for laravel to allow users to sign up to a waitlist.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
