# mikopbx/core

> 标签: FreePBX, asterisk, mikopbx, pbx, phalcon, sip, telephony, uc, voip

## 简介

Free PBX system for SMB based on Asterisk

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
