# redanlaxe/powerbi-embed-php

> 标签: embed, php, powerbi, service-principal

## 简介

A PHP library to embed Power BI reports using the App Owns Data (service principal) method.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
