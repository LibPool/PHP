# geo-sot/laravel-env-editor

> 标签: EnvEditor, geo-sot, laravel, laravel-env-editor

## 简介

A laravel Package that supports .Env File, editing and backup

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
