# particle-academy/teachers-aid

> 标签: Agent, ai, authoring, courses, curriculum, laravel, particle-academy

## 简介

Teachers Aid Chat (TAC) — an authoring agent that reads course material and proposes curriculum, course and test changes for review. LLM-library agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
