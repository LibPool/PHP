# particle-academy/prism-workspace

> 标签: agents, ai, filesystem, laravel, llm, prism, sandbox, workspace

## 简介

Sandboxed, session-scoped agent workspaces for Laravel — a scoped Storage disk behind a path guard, shipped with the adversarial corpus that proves the boundary holds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
