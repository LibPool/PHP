# particle-academy/gmail-inbox-php

> 标签: api, connector, email, fancy-ui, gmail_inbox, particle-academy

## 简介

Gmail Inbox for PHP — the service descriptor, its faker, its webhook verification, one class per operation, and a fancy-flow-php executor per node. Plain HTTP on particle-academy/fancy-connector-core; no vendor SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
