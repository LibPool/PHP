# afrizalmy/textsearch-id

> 标签: bahasa, indonesia, indonesian, pemeringkatan kata, pencarian kata

## 简介

Package untuk menghitung kesamaan teks dengan metode TF-IDF dan Jaccard Similarity

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
