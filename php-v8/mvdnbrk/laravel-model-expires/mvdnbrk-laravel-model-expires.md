# mvdnbrk/laravel-model-expires

> 标签: Expires, date, eloquent, expirable, expiration, expire, laravel, model

## 简介

A package to assign expiration dates to Eloquent models

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
