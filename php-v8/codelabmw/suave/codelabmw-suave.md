# codelabmw/suave

> 标签: Authentication, CodelabMW, api, api-authentication, auth, laravel, sanctum, suave, verification, verification-code

## 简介

A Laravel package that scaffolds API authentication for both token & session based authentication using laravel/sanctum.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
