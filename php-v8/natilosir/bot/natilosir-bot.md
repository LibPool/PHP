# natilosir/bot

> 标签: PHP

## 简介

A simple and flexible PHP package for building Telegram bots, featuring route handling, user state management, logging, path helpers, and an Illuminate-based container.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
