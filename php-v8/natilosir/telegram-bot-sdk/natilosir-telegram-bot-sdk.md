# natilosir/telegram-bot-sdk

> 标签: Telegram-Bot-API, bot, bot-sdk, laravel, php, telegram, telegram-bot, telegram-sdk

## 简介

A powerful PHP SDK for building Telegram bots with Laravel integration, queue support, and easy setup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
