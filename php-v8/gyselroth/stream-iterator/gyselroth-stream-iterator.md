# gyselroth/stream-iterator

> 标签: iterator, psr-7, stream

## 简介

Provides \StreamIterator which allows traversing through an iterator and stringify each element

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
