# braseidon/vaal-api

> 标签: api, ggg, oauth, path-of-exile, poe, rate-limiting

## 简介

PHP client for the Path of Exile API with OAuth 2.1, rate limiting, and full endpoint coverage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
