# pictomancer/pictomancer

> 标签: Webp, avif, compress, image, optimization, pictomancer, resize

## 简介

PHP SDK for Pictomancer.ai - agent-native image optimization API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
