# codeitamarjr/laravel-cro-api

> 标签: Ireland, api, cro, laravel, register

## 简介

Laravel wrapper for the Irish CRO API with helpers for searching companies and submissions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
