# codeitamarjr/laravel-attachments

> 标签: attachments, files, filesystem, laravel, uploads

## 简介

Persist and manage polymorphic file attachments in Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
