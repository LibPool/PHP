# asagiri-moe/xendit-wrapper

> 标签: asagiri-moe, xendit-wrapper

## 简介

A Laravel Wrapper for Xendit Payment Gateway (ID/PH)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
