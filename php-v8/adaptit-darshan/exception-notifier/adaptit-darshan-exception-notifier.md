## 简介

Production-ready exception notification system for Laravel 8-13 with intelligent rate limiting, critical exception handling, and customizable email templates. Supports Laravel 8, 9, 10, 11, 12, and 13.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
