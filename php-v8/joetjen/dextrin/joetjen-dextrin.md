# joetjen/dextrin

> 标签: cbor, codec, dextrin, dxn, serialization

## 简介

Under heavy development: not for production use before 1.0.0. DXN (Data eXchange Notation) for PHP -- .dxn text, .dxnb binary, and .dxns schema documents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
