# joetjen/cooper-config

> 标签: casc, config, configuration, cooper

## 简介

Under heavy development: not for production use before 1.0.0. Loads an application's CASC configuration once, at startup, with joetjen/cooper -- converted into plain PHP values, secrets handled by a per-application policy, compiled to an opcache-friendly PHP file between requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
