# joetjen/cooper-laravel

> 标签: casc, config, configuration, cooper, laravel

## 简介

Under heavy development: not for production use before 1.0.0. Laravel integration of Cooper: the configuration repository filled from a CASC document, .env files read by Cooper, and cooper:import to move config/*.php into CASC.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
