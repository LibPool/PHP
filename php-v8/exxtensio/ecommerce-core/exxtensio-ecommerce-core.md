# exxtensio/ecommerce-core

> 标签: Laravel shopping cart, Online store, checkout, digital products, ecommerce, exxtensio, exxtensio ecommerce, laravel, laravel ecommerce, laravel orders, laravel store, multi-currency, orders, physical products, product attributes, product catalog, shopping cart

## 简介

Exxtensio eCommerce Core is a build for Laravel 11.x which includes all the necessary for your online store backend application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
