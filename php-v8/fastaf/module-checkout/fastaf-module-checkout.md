# fastaf/module-checkout

> 标签: PHP

## 简介

Magento Fast Checkout Extension - A Checkout and Payment solution for Magento using the Fast checkout interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
