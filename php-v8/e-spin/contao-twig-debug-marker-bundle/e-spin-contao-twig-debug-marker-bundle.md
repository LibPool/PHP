# e-spin/contao-twig-debug-marker-bundle

> 标签: contao, debug, template, twig

## 简介

Wraps Twig template output with the same debug-mode TEMPLATE START/END markers Contao's legacy .html5 templates have always had - closing the gap for any Twig template that takes precedence over one.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
