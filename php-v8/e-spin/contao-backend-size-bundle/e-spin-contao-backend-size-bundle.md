# e-spin/contao-backend-size-bundle

> 标签: accessibility, backend, contao, icon, size

## 简介

Let each backend user scale the icons of the Contao backend to a size that suits them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
