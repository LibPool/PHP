# chriscubos/packager

> 标签: Chriscubos, Laravel Package Builder, Package Class, packager, packagist, service provider

## 简介

Automagic package installer. One line of code to publish.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
