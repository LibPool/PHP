# vani8987/mini-framework

> 标签: api, framework, pdo, php, router

## 简介

Небольшой PHP-фреймворк с роутингом, запросами, ответами, доступом к базе данных, миграциями и логированием.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
