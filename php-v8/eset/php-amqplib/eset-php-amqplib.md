# eset/php-amqplib

> 标签: message, queue, rabbitmq

## 简介

Formerly videlalvaro/php-amqplib.  This library is a pure PHP implementation of the AMQP protocol. It's been tested against RabbitMQ.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
