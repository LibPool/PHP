# gentor/oauth1-etsy

> 标签: authorisation, authorization, client, etsy, oauth, oauth1

## 简介

Etsy API OAuth 1.0 Client Provider for The PHP League OAuth1-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
