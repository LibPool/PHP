# fixik/openai-client

> 标签: ChatGpt, laravel, openai, php

## 简介

A PHP client for the OpenAI API with chat, embeddings, images, fine-tuning, Laravel support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
