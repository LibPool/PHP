# dezwork/dwphp-framework

> 标签: Framework php7, dwphp, dwphp-framework, framework, php

## 简介

Framework php7 with environment development, testing, staging and production.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
