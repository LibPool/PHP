# logue/igo-php

> 标签: chasen, igo, morphological analysis, php

## 简介

Morphological analysis engine 'Igo' porting and changed for PHP 7.4 or later and composer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
