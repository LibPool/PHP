# ngutech/lightningd-adapter

> 标签: adapter, bitcoin, clightning, lightning-network, lightningd

## 简介

Lightningd (c-lightning) service adapter for Daikon-CQRS projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
