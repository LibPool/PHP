# easybdit/laraveleasyattendance

> 标签: Leave, attendance, biometric, check-in, filament, hr, laravel, overtime, payroll, salary, timesheet, zkteco

## 简介

Drop-in attendance, HR, and payroll core for any Laravel app: check-in/out, corrections, ZKTeco device sync (pull + ADMS push), shifts, leave, holidays, overtime, salary generation, and reports.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
