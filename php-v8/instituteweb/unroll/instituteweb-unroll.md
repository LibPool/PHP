# instituteweb/unroll

> 标签: PHP

## 简介

Adds options to TYPO3's save buttons, to unroll them from dropdown, just display icons and changing the order.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
