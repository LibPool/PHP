# robase/sdk

> 标签: 2fa, africa, otp, robase, sms, transactional-sms, verification

## 简介

Official PHP client for the Robase SMS OTP and transactional SMS API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://robase.dev
- 源码仓库：https://github.com/mantissatech/robase-sdk-php.git
- Packagist 页面：https://packagist.org/packages/robase%2Fsdk
