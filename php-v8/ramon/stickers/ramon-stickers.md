# ramon/stickers

> 标签: animated, flarum, lottie, stickers, tgs

## 简介

Sticker manager for Flarum with native support for animated TGS and Lottie stickers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
