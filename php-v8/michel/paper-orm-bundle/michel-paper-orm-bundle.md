# michel/paper-orm-bundle

> 标签: PHP

## 简介

PaperORMBundle is a Symfony bundle that integrates PaperORM, a lightweight and performant PHP ORM.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
