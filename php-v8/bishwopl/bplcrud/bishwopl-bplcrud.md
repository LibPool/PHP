# bishwopl/bplcrud

> 标签: crud, doctrine, form-generator, laminas-form

## 简介

Simple crud package and form generator using laminas-form and doctrine-orm

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
