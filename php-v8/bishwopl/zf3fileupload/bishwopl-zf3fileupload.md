# bishwopl/zf3fileupload

> 标签: custom element, form

## 简介

Custom file upload element for zf3, supports filesystem and database storage(using DoctrineORM)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
