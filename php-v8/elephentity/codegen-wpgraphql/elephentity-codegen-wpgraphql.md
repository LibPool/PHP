# elephentity/codegen-wpgraphql

> 标签: PHP

## 简介

The WPGraphQL builder for Elephentity: compiles the IR into a GraphQL manifest and a conformance verifier. Build-time only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
