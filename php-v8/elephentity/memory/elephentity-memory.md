# elephentity/memory

> 标签: PHP

## 简介

An in-process StorageAdaptor with no backend of its own. The neutral driver for a project that wants raw PHP objects rather than WordPress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
