# cmelda/pohoda

> 标签: Accounting, mserver, pohoda, stormware, xml

## 简介

Strictly typed PHP client for the STORMWARE POHODA mServer XML API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
