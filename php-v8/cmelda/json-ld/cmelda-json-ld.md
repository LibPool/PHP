# cmelda/json-ld

> 标签: JSON-LD, graph, schema, schema.org, seo, structured-data

## 简介

PHP Schema.org JSON-LD builder with typed entities and automatic @graph references

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
