# trilbdev/two-factor-library

> 标签: Authentication, MFA, Multi Factor Authentication, Two Factor Authentication, authenticator, authy, php, tfa

## 简介

A PHP 2FA library for TOTP, QR codes, passkeys, and recovery codes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
