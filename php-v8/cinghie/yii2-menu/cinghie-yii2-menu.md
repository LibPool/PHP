# cinghie/yii2-menu

> 标签: menù yii2, yii2 menù

## 简介

Yii2 Menu to create, manage, and delete dynamic menus in a Yii2 site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
