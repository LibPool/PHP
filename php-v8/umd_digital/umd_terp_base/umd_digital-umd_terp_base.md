# umd_digital/umd_terp_base

> 标签: UMD.EDU, drupal

## 简介

UMD Terp Base is the base module for all UMD drupal projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
