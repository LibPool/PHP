# maksimovic/slim-oauth2-http

> 标签: Bridge, http, message, oauth2, psr7, request, response, slim

## 简介

Bridge components for PSR-7 and bshaffer's OAuth2 Server http messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
