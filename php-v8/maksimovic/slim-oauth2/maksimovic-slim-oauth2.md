# maksimovic/slim-oauth2

> 标签: api, http, middleware, oauth2, psr7, routes, slim

## 简介

OAuth2 routes, middleware and utilities for use within a Slim Framework API (PHP 8.1+ fork)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
