# maksimovic/php-zip

> 标签: archive, extract, unzip, winzip, zip, ziparchive

## 简介

Fork of nelexa/zip — PhpZip library for extended work with ZIP-archives. This fork adds PHP 8.5 support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
