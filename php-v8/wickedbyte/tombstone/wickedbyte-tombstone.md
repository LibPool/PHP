# wickedbyte/tombstone

> 标签: code quality, dead code, refactoring, tombstone, zombie code

## 简介

Basic implementation of the Tombstone pattern for PHP to uncover zombie code

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
