# wickedbyte/link-tortilla

> 标签: http, http-link, hypermedia, link, psr, psr-13

## 简介

Provides a simple set of traits to allow wrapping user classes as PSR-13 Link implementations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
