# jivtesh/ci4-api-generator

> 标签: CI4, api, codeigniter4, generator, php, rest

## 简介

Automatic API generator for CodeIgniter 4 based on database tables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
