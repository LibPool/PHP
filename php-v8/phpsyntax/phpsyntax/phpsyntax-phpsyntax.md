# phpsyntax/phpsyntax

> 标签: ast, code generation, cst, lexer, lossless, parser, php-parser, refactoring, static analysis, syntax tree, tokenizer

## 简介

🌳 PhpSyntax: a lossless concrete syntax tree (CST) for PHP. Every token, space and comment is kept, so the tree prints back byte for byte and a tool changes only what it touches. Comes with a mutation API for refactoring tools and formatters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
