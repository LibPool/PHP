# gisoo/gisoo-php

> 标签: ai, chat, gisoo, laravel, llm, openai, php, sdk

## 简介

Official PHP SDK and Laravel package for the Gisoo AI API (OpenAI-compatible): chat, streaming, embeddings, images, speech, transcription, video and music.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
