# avninc/chartjs-wrapper

> 标签: Chart.js, OOP, charts, php, php charts

## 简介

This allows to generate chart.js charts using PHP fluid interface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
