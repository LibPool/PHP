# ajcastro/searchable

> 标签: eloquent-search, laravel, laravel-package, pattern-matching-search, query, query-builder

## 简介

Pattern-matching search for Laravel eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
