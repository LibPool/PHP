# laravel-liberu/ocr

> 标签: OCR, laravel, laravel-liberu, ocrmypdf, text recognition

## 简介

A wrapper to work with ocrmypdf inside PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
