# laravel-liberu/auth

> 标签: PHP

## 简介

Standardizes and streamlines authentication across all projects in the organization, providing a robust, customizable, and secure authentication solution

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
