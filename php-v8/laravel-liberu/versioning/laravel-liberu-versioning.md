# laravel-liberu/versioning

> 标签: laravel-liberu, optimistic-lock, trait, versioning

## 简介

Prevents update conflicts using the optimistic lock pattern in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
