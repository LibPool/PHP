# rumbleh/laravel-ciot-antt

> 标签: antt, ciot, frete, laravel, pef, rntrc, transporte

## 简介

Cliente Laravel para emissão de CIOT junto ao web service PEF da ANTT (Pagamento Eletrônico de Frete).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
