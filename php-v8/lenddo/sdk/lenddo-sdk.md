# lenddo/sdk

> 标签: lenddo

## 简介

SDK for communicating with Lenddo Services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.lenddo.com
- 源码仓库：https://github.com/Lenddo/php-lenddo.git
- Packagist 页面：https://packagist.org/packages/lenddo%2Fsdk
