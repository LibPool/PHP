# ahinest/laravel-print-kit

> 标签: html, labels, laravel, printing, qr-code

## 简介

Infraestructura configurable de formatos de impresión y etiquetas para Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
