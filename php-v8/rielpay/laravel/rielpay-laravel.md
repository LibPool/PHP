# rielpay/laravel

> 标签: aba, bakong, cambodia, khqr, laravel, payment, payway, rielpay

## 简介

Official Laravel SDK for RielPay — accept KHQR payments from every bank in Cambodia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
