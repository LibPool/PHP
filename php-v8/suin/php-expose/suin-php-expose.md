# suin/php-expose

> 标签: expose, phpunit, testable, unittest

## 简介

Makes non-public properties and methods be testable to help your unit tests with PHPUnit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
