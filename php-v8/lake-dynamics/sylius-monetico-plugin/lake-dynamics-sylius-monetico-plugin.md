# lake-dynamics/sylius-monetico-plugin

> 标签: monetico, payment, sylius, sylius-plugin

## 简介

Sylius plugin for Monetico payment gateway integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
