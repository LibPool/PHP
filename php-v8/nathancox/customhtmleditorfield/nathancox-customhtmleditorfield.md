# nathancox/customhtmleditorfield

> 标签: editor, silverstripe, tinymce

## 简介

Allows per-editor TinyMCE configurations and body classes in SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
