# tfs/sendy

> 标签: PHP

## 简介

Consumes Sendy's API and provides a usable class with method processRequest() allowing easy requesting quote as well as completing request.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
