# barnemax/wp-data-cli

> 标签: csv, import, vip, wordpress, wp-cli, xlsx

## 简介

CLI-first WordPress import library. Stream CSV and XLSX into WordPress via WP-CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
