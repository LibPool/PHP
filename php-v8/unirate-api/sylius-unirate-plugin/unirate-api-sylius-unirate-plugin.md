# unirate-api/sylius-unirate-plugin

> 标签: currency, currency-converter, ecommerce, exchange-rates, fintech, forex, fx, sylius, sylius-plugin, unirate

## 简介

Sylius plugin that keeps your store's exchange rates up to date from the UniRate currency-exchange API — autowired client service plus a console command that upserts Sylius ExchangeRate entities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
