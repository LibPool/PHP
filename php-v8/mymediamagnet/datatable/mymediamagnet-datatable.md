# mymediamagnet/datatable

> 标签: Dynatable, ajax, datatables, jquery, laravel

## 简介

This is a Laravel 6 fork of OpenSkill Datatables for the server and client side of DataTables (http://datatables.net/)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
