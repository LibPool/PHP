# limetecbiotechnologies/yaml-fixtures-bundle

> 标签: data fixtures doctrine yaml

## 简介

Symfony bundle for easy loading of YAML based fixtures.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
