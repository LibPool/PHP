# astrotomic/pixpipe

> 标签: Flysystem, glide, http, image, image-manipulation, image-processing, images, intervention-image, laravel, signed-urls

## 简介

On-the-fly image manipulation and delivery for Laravel using Intervention Image and Glide (signed URLs, caching, Flysystem).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
