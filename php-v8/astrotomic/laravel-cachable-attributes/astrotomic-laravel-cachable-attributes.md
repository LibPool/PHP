# astrotomic/laravel-cachable-attributes

> 标签: accessor, attribute, cache, eloquent, getter, laravel, model

## 简介

Allows to cache attribute accessor values in an easy way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
