# strack/yurun-oauth-login

> 标签: PHP

## 简介

YurunOAuthLogin是一个PHP 第三方登录授权 SDK，集成了QQ、微信、微博、Github等常用接口。可以轻松嵌入支持 PHP >= 5.4 的任何系统中。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
