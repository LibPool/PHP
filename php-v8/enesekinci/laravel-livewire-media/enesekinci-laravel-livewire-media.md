# enesekinci/laravel-livewire-media

> 标签: file-manager, laravel, livewire, media, picker, r2, s3

## 简介

R2/S3 media library picker for Laravel Livewire (upload, browse, select).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
