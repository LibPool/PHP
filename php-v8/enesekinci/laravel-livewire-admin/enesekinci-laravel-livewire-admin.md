# enesekinci/laravel-livewire-admin

> 标签: admin, laravel, livewire, tailwind

## 简介

Meta package for the Enes Ekinci Livewire admin stack (UI, toast, confirm, search-select).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
