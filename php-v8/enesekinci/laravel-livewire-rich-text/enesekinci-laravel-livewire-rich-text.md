# enesekinci/laravel-livewire-rich-text

> 标签: alpine, editor, laravel, livewire, richtext, tiptap, wysiwyg

## 简介

TipTap-based rich text editor for Laravel Livewire (wire:ignore + Alpine + wire:model).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
