# spryker-community/search-debug

> 标签: debug, elasticsearch, explain, relevance, search, spryker

## 简介

Search relevance debugging for Spryker storefronts: per-product Elasticsearch score/token overlay on the search results page, and a token-source page that attributes matched tokens back to the raw product fields they were indexed from.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
