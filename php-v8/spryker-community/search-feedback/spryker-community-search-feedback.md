# spryker-community/search-feedback

> 标签: feedback, search, spryker, support, ticketing

## 简介

SRP feedback ticketing: lets an authorized storefront admin file a free-text ticket about a set of search results (query, filters, page, SKUs shown), and lets Zed admins hold a conversation about it back-office. A voice-of-customer capture tool, not a ranking-signal one.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
