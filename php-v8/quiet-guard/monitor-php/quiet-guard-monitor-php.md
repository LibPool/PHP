# quiet-guard/monitor-php

> 标签: error-tracking, exceptions, logging, monitoring, php

## 简介

Framework-agnostic PHP core for Quiet Guard clients (Laravel, Symfony, WordPress).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
