# altek/accountant

> 标签: Accountability, Audit, accountable, accountant, auditing, changes, eloquent, history, laravel, ledger, liable, log, logging, record

## 简介

The auditing & accountability package for Laravel's Eloquent ORM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
