# booreiland/responsive-pics

> 标签: image, php, picture, resizing, wordpress

## 简介

Responsive Pics is a Wordpress tool for resizing images on the fly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
