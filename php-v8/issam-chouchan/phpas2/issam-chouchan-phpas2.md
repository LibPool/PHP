# issam-chouchan/phpas2

> 标签: as2, edi, ediint, server, x12

## 简介

PHPAS2 is a php-based implementation of the EDIINT AS2 standard

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
