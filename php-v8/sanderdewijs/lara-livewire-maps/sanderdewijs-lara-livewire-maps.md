# sanderdewijs/lara-livewire-maps

> 标签: component, google-maps, laravel, livewire, livewire3, livewire4, maps

## 简介

Laravel Livewire 3/4 Google Maps component with markers, events, and optional clustering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
