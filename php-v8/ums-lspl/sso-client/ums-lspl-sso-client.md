# ums-lspl/sso-client

> 标签: Authentication, SSO, laravel, smartexam

## 简介

Laravel client package for SmartExam SSO — verify tokens and authenticate users in consumer apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
