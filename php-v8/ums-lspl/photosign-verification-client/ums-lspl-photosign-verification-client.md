# ums-lspl/photosign-verification-client

> 标签: laravel, passport, photosign, signature, smartexam, validation

## 简介

Laravel client for PhotoSign Verification — validate passport photos and handwritten signatures before storing them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
