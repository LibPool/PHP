# headjam/craft-rex

> 标签: Craft, cms, craft rex, craft-plugin, craftcms

## 简介

A plugin that syncs REX data with Craft.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
