# fredmansky/eventsky

> 标签: Craft, cms, craft-plugin, craftcms, event management, events, eventsky

## 简介

Craft plugin for event management and attendee registration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
