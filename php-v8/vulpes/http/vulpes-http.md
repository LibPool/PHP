# vulpes/http

> 标签: http-client, http-factories, http-message, psr, psr-17, psr-18, psr-7

## 简介

PSR-7 HTTP Message & PSR-17 HTTP Factories & PSR-18 HTTP Client implementation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
