# safronik/db-wrapper

> 标签: database, migration, schema

## 简介

Wrapper for different relation databases drivers such as PDO, Mysqli, WPDB, Drupal, and any other

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
