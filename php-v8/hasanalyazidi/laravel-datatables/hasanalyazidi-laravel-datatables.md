# hasanalyazidi/laravel-datatables

> 标签: bootstrap, csv, datatables, excel, export, jquery, laravel, pdf, responsive, server-side

## 简介

Server-side and client-side jQuery DataTables for Laravel: one PHP class, one route line, one Blade tag — bundled responsive front end, a delete-row flow, and Excel, CSV and PDF (Arabic/RTL) exports.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
