# apermo/classic-to-gutenberg

> 标签: blocks, classic-editor, gutenberg, migration, wordpress

## 简介

Batch migration from classic editor content to Gutenberg blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
