# apermo/wp-update-server

> 标签: automatic updates, composer repository, package server, plugin updates, plugin-update-checker, self-hosted, theme updates, update server, wordpress, wp-update-server

## 简介

Self-hosted update API for WordPress plugins and themes, compatible with Plugin Update Checker and Composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
