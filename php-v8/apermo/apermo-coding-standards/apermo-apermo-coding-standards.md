# apermo/apermo-coding-standards

> 标签: coding-standards, phpcs, static-analysis, wordpress

## 简介

Shared PHPCS coding standards for WordPress projects by Apermo.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
