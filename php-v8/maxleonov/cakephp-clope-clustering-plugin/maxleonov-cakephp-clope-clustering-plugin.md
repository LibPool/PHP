# maxleonov/cakephp-clope-clustering-plugin

> 标签: cakephp, clope, clustering, plugin

## 简介

Cake-PHP plugin for CLOPE clustering algorithm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
