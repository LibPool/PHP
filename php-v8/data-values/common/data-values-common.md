# data-values/common

> 标签: datavalues, valueformatters, valueparsers, valuevalidators, wikidata

## 简介

Contains common implementations of the interfaces defined by DataValuesInterfaces

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
