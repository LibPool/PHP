# fgsl/curlphp

> 标签: administration, console, curl, curlphp, fgsl

## 简介

PHP proxy for curl aimed to API testing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/fgsl/curlphp
- 源码仓库：https://github.com/fgsl/curlphp.git
- Packagist 页面：https://packagist.org/packages/fgsl%2Fcurlphp
