# banana-dev/banana-dev

> 标签: Api Wrapper, Banana client, Banana.dev, banana, sdk

## 简介

A PHP client to interact with Banana's machine learning inference APIs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
