# piotrpress/icons

> 标签: block, blocks, fse, full-site-editing, gutenberg, icon, icons, svg, wordpress, wp

## 简介

This WordPress plugin adds SVG Icon block and format to Gutenberg editor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
