# piotrpress/typed-collection

> 标签: ArrayAccess, array, collection, iterable, object collection, php collection, php typed collection, scalar collection, strict collection, typed collection

## 简介

A strict typed collection for PHP with runtime validation for scalar and object-based item types.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
