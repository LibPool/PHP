# piotrpress/composer-classmapper

> 标签: autoload, autoloader, class map, classmap, classmapper, composer, composer classmap, composer command, composer map, composer plugin, composer script, map, php

## 简介

This Composer command generates a classmap.php file based on project files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
