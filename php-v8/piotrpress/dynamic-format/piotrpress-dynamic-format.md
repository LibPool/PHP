# piotrpress/dynamic-format

> 标签: block, blocks, dynamic-block, dynamic-blocks, dynamic-format, format, format-api, formatting-toolbar-api, fse, full-site-editing, gutenberg, php-block, php-blocks, wordpress, wp

## 简介

This WordPress plugin adds a dynamic format which renders an output of a selected php callback function added via a filter hook.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
