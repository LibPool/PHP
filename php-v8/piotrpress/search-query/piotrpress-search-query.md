# piotrpress/search-query

> 标签: block, blocks, dynamic-block, dynamic-blocks, found, found-posts, fse, full-site-editing, gutenberg, php-block, php-blocks, query, result, results, search, search-query, wordpress, wp

## 简介

This WordPress plugin adds a Search Query block which renders the contents of the search WordPress query variable.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
