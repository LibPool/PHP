# piotrpress/remoter

> 标签: Chain, chainable, file_get_contents, header, headers, http, http client, http-client, httpclient, remoter, request, response, url

## 简介

This library is a chainable HTTP Client based on file_get_contents() function.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
