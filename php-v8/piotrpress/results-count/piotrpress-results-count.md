# piotrpress/results-count

> 标签: block, blocks, count, counter, counts, dynamic-block, dynamic-blocks, found, found-posts, fse, full-site-editing, gutenberg, php-block, php-blocks, result, results, wordpress, wp

## 简介

This WordPress plugin adds a Results Count block which renders a number of found posts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
