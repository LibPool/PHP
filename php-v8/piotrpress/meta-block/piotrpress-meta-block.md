# piotrpress/meta-block

> 标签: block, blocks, custom-fields, dynamic-block, dynamic-blocks, field, fields, fse, full-site-editing, gutenberg, meta, meta-fields, metadata, php-block, php-blocks, post-meta, post-meta-fields, wordpress, wp

## 简介

This WordPress plugin adds a Meta Block which renders a selected post meta field.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
