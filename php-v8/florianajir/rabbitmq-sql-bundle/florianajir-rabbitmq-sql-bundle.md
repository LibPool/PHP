# florianajir/rabbitmq-sql-bundle

> 标签: RabbitMQ to Sql, consumer, rabbitmq, sql

## 简介

RabbitMQ to sql consumer, using doctrine/dbal and php-amqplib/rabbitmq-bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
