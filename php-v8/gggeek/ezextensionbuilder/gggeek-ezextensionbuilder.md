# gggeek/ezextensionbuilder

> 标签: PHP

## 简介

Provides tools to build (package) extensions for eZ Publish (4.x or Legacy Stack extensions only)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
