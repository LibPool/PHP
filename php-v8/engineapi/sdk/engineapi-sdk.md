# engineapi/sdk

> 标签: Danfe, fiscal, nfce, nfe, nfse, nota-fiscal, sefaz

## 简介

SDK PHP oficial da Engine API — emissão fiscal (NFe, NFCe, NFSe) via SEFAZ, com tratamento de erro previsível

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
