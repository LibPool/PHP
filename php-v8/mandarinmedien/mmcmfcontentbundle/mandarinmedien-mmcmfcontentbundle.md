# mandarinmedien/mmcmfcontentbundle

> 标签: PHP

## 简介

This is the bridge between doctrine content entities and twig which will be the base of the MMCmfBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
