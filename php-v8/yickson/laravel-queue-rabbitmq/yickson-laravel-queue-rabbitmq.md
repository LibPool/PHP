# yickson/laravel-queue-rabbitmq

> 标签: PHP

## 简介

RabbitMQ driver for Laravel Queue. Supports Laravel Horizon. Support PHP-8

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
