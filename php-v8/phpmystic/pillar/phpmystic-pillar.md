# phpmystic/pillar

> 标签: PHP

## 简介

A local-first static site generator built on Liqx: markdown and liqx templates in, plain HTML out, with a schema-driven visual editor and git as the store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
