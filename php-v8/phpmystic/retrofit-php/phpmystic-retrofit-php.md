# phpmystic/retrofit-php

> 标签: Guzzle, api, async, cache, client, file-upload, http, http-client, interceptor, multipart, psr-18, psr-7, rest, retrofit, retry, serializer, streaming, symfony, type-safe, xml

## 简介

A type-safe HTTP client for PHP inspired by Square's Retrofit. Turn your HTTP API into a PHP interface using attributes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
