# michielkempen/laravel-http-client

> 标签: Laravel HTTP client, Michiel Kempen

## 简介

An easy to use Laravel HTTP client on top of Guzzle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
