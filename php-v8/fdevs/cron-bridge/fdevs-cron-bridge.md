# fdevs/cron-bridge

> 标签: cron, crontab

## 简介

Symfony 2 bridge which allows you to use config to configure cron to run your console commands.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
