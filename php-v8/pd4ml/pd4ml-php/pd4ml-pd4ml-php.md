# pd4ml/pd4ml-php

> 标签: PDFA, docx, html, html-to-pdf, pd4ml, pdf, rtf

## 简介

PD4ML for PHP: HTML to PDF, PDF/A, PDF/UA, DOCX, RTF and image conversion (the PD4ML Java API through a bridge)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
