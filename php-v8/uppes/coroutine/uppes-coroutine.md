# uppes/coroutine

> 标签: async, await, cooperative, coroutine, event-driven, event-loop, generator, libuv, multitasking, parallel, process, spawn, task, yield

## 简介

Cooperative multitasking using generators. The basics of coroutines, async and await!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
