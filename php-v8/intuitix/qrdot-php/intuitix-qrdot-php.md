# intuitix/qrdot-php

> 标签: api, qr, qrcode, qrdot

## 简介

Official PHP client for the QR. API (qrdot.dev)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://qrdot.dev/libraries/
- 源码仓库：https://github.com/intuitix/qrdot-clients.git
- Packagist 页面：https://packagist.org/packages/intuitix%2Fqrdot-php
