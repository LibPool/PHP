# sarmadict/filament-media

> 标签: filament, file-browser, file-upload, laravel, media, media-library

## 简介

A reusable Filament 5 media library, filesystem browser, and media picker for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
