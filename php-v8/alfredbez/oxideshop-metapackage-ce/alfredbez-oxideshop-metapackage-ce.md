# alfredbez/oxideshop-metapackage-ce

> 标签: metapackage, oxidEshop

## 简介

This is OXID eShop compilation metapackage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
