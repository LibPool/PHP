# piratelp/iba

> 标签: Content management system, Database CMS, Hybrid CMS, Laravel CMS, MIT Laravel CMS, Open Source CMS, cms

## 简介

iAtelier: indipendent content management system for independent content creators

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
