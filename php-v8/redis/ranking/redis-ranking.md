# redis/ranking

> 标签: Social Game, ranking, realtime, redis, sorted set

## 简介

Wrapping Redis's sorted set APIs for specializing ranking operations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
