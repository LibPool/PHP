# nakamuraagatha/crudder

> 标签: crud, crudbooster, generator, laravel

## 简介

CRUDBooster Is A New Way Laravel CRUD Generator. It's easy, fleksible, and powerful.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
