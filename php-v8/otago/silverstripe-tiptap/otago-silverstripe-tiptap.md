# otago/silverstripe-tiptap

> 标签: editor, silverstripe, tiptap, wysiwyg

## 简介

SilverStripe Tiptap WYSIWYG editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
