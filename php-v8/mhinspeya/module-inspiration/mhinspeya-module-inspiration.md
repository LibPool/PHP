# mhinspeya/module-inspiration

> 标签: ai-fashion, ai-stylist, alpinejs, fashion-styling, hyva, hyva-theme, magento2, outfit-generator, product-inspiration, product-looks, tailwindcss

## 简介

Magento 2 AI-powered Inspiration module for generating automated outfit styling suggestions, AI-generated fashion looks, and scene-based product inspirations directly on the storefront product detail pages. Fully compatible with Hyvä Theme, Alpine.js, and modern Magento frontend architectures.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
