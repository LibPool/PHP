# codewithkyrian/jinja-php

> 标签: PHP

## 简介

A minimalistic PHP implementation of the Jinja templating engine, specifically designed for parsing and rendering ML chat templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
