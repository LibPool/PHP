# codewithkyrian/onnxruntime-downloader-plugin

> 标签: PHP

## 简介

A lightweight composer plugin for `ankane/onnxruntime` package to download the ONNXRuntime binaries for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
