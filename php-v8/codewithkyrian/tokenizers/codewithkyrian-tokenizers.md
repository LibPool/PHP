# codewithkyrian/tokenizers

> 标签: Bert, bpe, encoding, gpt, huggingface, llm, machine-learning, natural-language-processing, nlp, sentencepiece, text-processing, tokenization, tokenizer, transformers, wordpiece

## 简介

Fast, pure-PHP tokenizer library compatible with Hugging Face tokenizers for encoding and decoding text

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
