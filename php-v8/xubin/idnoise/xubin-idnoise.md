# xubin/idnoise

> 标签: PHP

## 简介

对一个具有系列规律的ID数字进行干扰使其看上去不再规律，并能反向恢复之。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
