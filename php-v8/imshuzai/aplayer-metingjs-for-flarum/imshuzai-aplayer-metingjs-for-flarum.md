# imshuzai/aplayer-metingjs-for-flarum

> 标签: discussion

## 简介

Using Aplayer and MetingJS to embed music in Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
