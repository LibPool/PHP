# hxgf/dw-utilities

> 标签: utilities

## 简介

A collection of utility functions to facilitate an efficient workflow with the Darkwave web application toolkit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
