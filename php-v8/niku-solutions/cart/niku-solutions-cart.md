# niku-solutions/cart

> 标签: Laravel cart, laravel cart manager, laravel checkout manager

## 简介

A codeable and flexible custom cart manager for Laravel with custom fields. Extendable and as dynamic as you wish.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
