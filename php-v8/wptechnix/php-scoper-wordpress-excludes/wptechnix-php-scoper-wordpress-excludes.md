## 简介

Curated, auto-updated PHP-Scoper exclude-symbol lists for WordPress core, WooCommerce, Action Scheduler, ACF PRO, WP-CLI and Plugin Update Checker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
