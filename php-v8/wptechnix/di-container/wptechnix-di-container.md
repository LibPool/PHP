# wptechnix/di-container

> 标签: PSR-11, container, dependency-injection, di, ioc, service-provider

## 简介

A minimal, explicit PSR-11 dependency injection container for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
