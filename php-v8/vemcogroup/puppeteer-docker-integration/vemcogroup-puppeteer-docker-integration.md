# vemcogroup/puppeteer-docker-integration

> 标签: docker, laravel, puppeteer

## 简介

Interact with puppeteer in alekzonder's docker images.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
