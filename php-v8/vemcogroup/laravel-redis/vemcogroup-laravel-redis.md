# vemcogroup/laravel-redis

> 标签: laravel, phpredis, redis, vemcogroup

## 简介

Enhancements to redis driver, such as enabling a serializer and/or compression

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
