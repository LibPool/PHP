# agentsib/crontab-bundle

> 标签: cron, cronjob, crontab, scheduler, symfony, task

## 简介

Crontab bundle for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
