# nirajp/timezone

> 标签: PHP

## 简介

Helps manage timezones in Laravel. Includes <select> form builder for timezones. Forked from camroncade/timezone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
