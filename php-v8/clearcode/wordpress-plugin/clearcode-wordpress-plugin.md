# clearcode/wordpress-plugin

> 标签: blog, boilerplate, cms, composer, plugin, wordpress, wp

## 简介

WordPress Plugin boilerplate by Clearcode.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
