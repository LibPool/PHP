# shieldci/laravel

> 标签: Best-Practices, code-quality, enlightn, enlightn-alternative, laravel, performance, reliability, security, shieldci, static-analysis, vulnerability-scanner

## 简介

Automated code analysis for Laravel applications covering security, performance, reliability, code quality and best practices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
