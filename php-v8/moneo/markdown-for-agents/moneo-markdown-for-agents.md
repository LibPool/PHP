# moneo/markdown-for-agents

> 标签: agents, ai, cloudflare, conversion, laravel, markdown

## 简介

Laravel package for Cloudflare's Markdown conversion services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
