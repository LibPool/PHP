# hi/go-zero-api-parser

> 标签: api, go-zero, json, parser, php

## 简介

go-zero API 文件解析器 - 通过 PHP 调用 Go 可执行文件解析 .api 文件

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
