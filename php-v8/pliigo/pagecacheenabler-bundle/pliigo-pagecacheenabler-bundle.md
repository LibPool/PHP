# pliigo/pagecacheenabler-bundle

> 标签: cache, contao, page

## 简介

This Extension enables the PageCache in Contao 4.4.7+, that is broken since Symfony 3.4.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
