# gonebusy/gonebusy-php-client

> 标签: GoneBusy API, api, sdk

## 简介

This is a PHP client for communicating with the full Gonebusy API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
