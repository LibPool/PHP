# puerari/cwp_api

> 标签: Puerari, Web Panel, api, centos, cwp

## 简介

CWP_API is a PHP package that abstracts the interaction with CentOS Web Panel through its API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
