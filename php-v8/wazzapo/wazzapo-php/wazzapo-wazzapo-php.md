# wazzapo/wazzapo-php

> 标签: crm, sdk, wazzapo, whatsapp, whatsapp-business-api

## 简介

PHP SDK для API Wazzapo v2: WhatsApp Business API, переписки, контакты, сделки, вебхуки

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
