# codefareith/cf-beskin

> 标签: backend, css, extension, typo3

## 简介

Define your own css rule-sets for the TYPO3 CMS backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
