# nzo/url-encryptor-bundle

> 标签: aes, authenticated encryption, data, decrypt, decryption, encrypt, encryption, hmac, id, key rotation, link, security, url

## 简介

Symfony bundle to encrypt and decrypt the data passed through the URL, or any other value, with authenticated encryption

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
