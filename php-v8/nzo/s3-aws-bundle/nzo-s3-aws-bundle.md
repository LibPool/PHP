# nzo/s3-aws-bundle

> 标签: amazon, aws, files, s3, upload

## 简介

The NzoS3AwsBundle is a Symfony Bundle used to handle AWS S3 Files Upload.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
