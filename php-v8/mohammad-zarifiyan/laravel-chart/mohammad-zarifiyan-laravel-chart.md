# mohammad-zarifiyan/laravel-chart

> 标签: chart, eloquent, eloquent-orm, laravel, orm

## 简介

A Laravel package that helps you to quickly create charts from database.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
