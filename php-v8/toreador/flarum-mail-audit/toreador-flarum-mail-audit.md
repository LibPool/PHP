# toreador/flarum-mail-audit

> 标签: Audit, email, flarum, log, mail, outbox, smtp

## 简介

Records every outgoing Flarum email in the database and lets admins inspect recipients, subject, HTML/text bodies and headers from the admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
