# konekt/resource

> 标签: api, artkonekt, konekt, resource, rest

## 简介

API Resources library to transform entities/models into REST API objects. Inspired by Laravel - usable in any Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
