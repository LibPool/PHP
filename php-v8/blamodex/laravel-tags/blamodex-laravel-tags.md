> 标签: categorization, eloquent, labels, laravel, tagging, tags, taxonomy

## 简介

A simple, Laravel-ready tagging package for rapid prototyping and lightweight use cases.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
