# cidram/aggregator

> 标签: IP, aggregator, cidr, cidram, ipv4, ipv6, networking, subnets

## 简介

A stand-alone class implementation of the IPv4+IPv6 IP+CIDR aggregator from CIDRAM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
