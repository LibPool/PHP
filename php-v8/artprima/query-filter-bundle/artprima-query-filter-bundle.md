# artprima/query-filter-bundle

> 标签: doctrine, filter, query, symfony

## 简介

An easy way to filter requests in your Symfony 4/5/6 application (that uses Doctrine2 as ORM).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
