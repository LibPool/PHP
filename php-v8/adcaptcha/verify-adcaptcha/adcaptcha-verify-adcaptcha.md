# adcaptcha/verify-adcaptcha

> 标签: adCAPTCHA, anti-spam, block bots, captcha, security

## 简介

A PHP package for verifying adCAPTCHA tokens via the adCAPTCHA API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
