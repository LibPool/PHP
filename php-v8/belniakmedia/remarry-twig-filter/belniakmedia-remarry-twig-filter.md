# belniakmedia/remarry-twig-filter

> 标签: Craft, Orphan, cms, craft-plugin, craftcms, remarry twig filter, widow

## 简介

A CraftCMS Twig Filter that prevents paragraph text widows in plain text and complex HTML user supplied content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
