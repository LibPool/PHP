# andskur/coinmc

> 标签: bitcoin, coinmarketcap, coinmarketcap.com, cryptocurrency, laravel

## 简介

CoinMarketCap.com api wrapper for Laravel 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
