# projectjoker/craft-alt-extend

> 标签: Craft, accessibility, alt, cms, craftcms, seo

## 简介

Appends or prepends a configurable text to image alt attributes in Craft CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
