# digiloopinc/laravel-pausable-batch

> 标签: digiloopinc, laravel-pausable-batch

## 简介

A Laravel package that adds pause and resume controls to queued batch jobs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
