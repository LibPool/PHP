# therealworld/formrecaptchav3-module

> 标签: OXID, eshop, modules

## 简介

A Google-Recaptcha-V3-Module for public forms like contact-form in OXID7.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
