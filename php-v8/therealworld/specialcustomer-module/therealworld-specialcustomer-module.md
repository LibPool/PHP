# therealworld/specialcustomer-module

> 标签: OXID, eshop, modules

## 简介

Customers can tell you are 'special' during signup. The shop merchant then receives an email and can start further manual actions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
