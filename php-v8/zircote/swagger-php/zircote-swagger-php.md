# zircote/swagger-php

> 标签: api, json, rest, service discovery

## 简介

Generate interactive documentation for your RESTful API using PHP attributes (preferred) or PHPDoc annotations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
