# chargemap/ocpi-protocol

> 标签: PHP

## 简介

Library to handle OCPI. Compatible with PSRs. Uses JsonSchema to validate payloads.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
