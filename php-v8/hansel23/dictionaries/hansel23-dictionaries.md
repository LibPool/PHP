# hansel23/dictionaries

> 标签: PHP

## 简介

Dictionary with interface. It's losely based on the Dictionary type of other famous languages. Strict typed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
