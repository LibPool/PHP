# bohnmedia/contao-flag-icons-bundle

> 标签: PHP

## 简介

Contao 5 wrapper around lipis/flag-icons — render country flags via insert tag or Twig function.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
