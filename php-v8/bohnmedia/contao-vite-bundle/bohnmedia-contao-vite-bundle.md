# bohnmedia/contao-vite-bundle

> 标签: assets, contao, contao-bundle, vite

## 简介

Integrates Vite into Contao 5, based on the Symfony bundle pentatrion/vite-bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
