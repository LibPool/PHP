# yangweijie/opentelemetry-auto-thinkphp

> 标签: instrumentation, open-telemetry, opentelemetry, otel, thinkphp, tracing

## 简介

OpenTelemetry auto-instrumentation for ThinkPHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
