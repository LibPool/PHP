# yangweijie/think-runtime

> 标签: frankenphp, high-performance, roadrunner, runtime, swoole, thinkphp

## 简介

高性能环境下运行的ThinkPHP Runtime扩展包，支持Swoole、RoadRunner、FrankenPHP等多种运行时

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
