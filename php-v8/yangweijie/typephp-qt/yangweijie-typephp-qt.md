# yangweijie/typephp-qt

> 标签: aot, aot-compiler, desktop, gui, native, php, qt, qt-widgets, qt6, tpc, typephp

## 简介

Rapid development framework for native desktop GUI applications built with TypePHP (AOT-compiled PHP) and Qt 6 — declarative widget tree, one-command build, self-verifying packaging and headless testing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
