# lombokclarion/routing

> 标签: PHP

## 简介

Explicit route table, middleware pipeline, Kernel, and runtime adapters (FPM/Function/Swoole) for LombokClarion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
