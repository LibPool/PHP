# lombokclarion/bus

> 标签: PHP

## 简介

Explicit CommandBus, QueryBus, and EventBus for LombokClarion. One handler per command/query, explicitly registered; no auto-discovery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
