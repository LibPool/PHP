# lombokclarion/facades

> 标签: PHP

## 简介

Optional static-accessor facades for LombokClarion. Explicitly isolated from core and domain layer (§2.6, §4.12). MUST NOT leak into app/Domain/**.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
