# lombokclarion/persistence

> 标签: PHP

## 简介

QueryBuilder (bound parameters only), SchemaBuilder, and an explicit-manifest MigrationRunner for LombokClarion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
