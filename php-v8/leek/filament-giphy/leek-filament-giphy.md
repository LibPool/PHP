# leek/filament-giphy

> 标签: filament, filamentphp, giphy, laravel, leek, rich-editor, tiptap

## 简介

Search GIPHY and insert a GIF into a Filament rich text field.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
