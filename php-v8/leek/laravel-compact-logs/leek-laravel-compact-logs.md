# leek/laravel-compact-logs

> 标签: compact, laravel, logging, monolog, stack-trace

## 简介

Truncate verbose stack traces in Laravel log files for cleaner, more readable logs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
