# fresns/fresns

> 标签: SNS, bbs, club, communities, community, forum, fresns, group, laravel, social

## 简介

Cross-platform general-purpose multiple content forms social network service software.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
