# nanayawkumi/nyk-db-sync

> 标签: database, laravel, migration, mysql, postgres, postgresql, sync

## 简介

Bidirectional MySQL and PostgreSQL schema translation, row sync, dual-write, and cutover for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
