# alkauni/planogrid

> 标签: PHP

## 简介

Framework-agnostic PHP package for Planogram Spatial Grid Sorting and AWS Rekognition Image Annotation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
