# pasquale-cs/zipsms-php-sdk

> 标签: gateway, laravel, sdk, sms, zipsms

## 简介

SDK PHP ufficiale per ZipSMS Gateway — invio SMS tramite il proprio dispositivo Android.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
