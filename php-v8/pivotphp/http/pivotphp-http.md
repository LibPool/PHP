# pivotphp/http

> 标签: http, php, pivotphp, psr-15, psr-17, psr-7, request, response

## 简介

HTTP foundation for PivotPHP - PSR-7/PSR-17 messages built on nyholm/psr7 with Express.js-inspired helpers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
