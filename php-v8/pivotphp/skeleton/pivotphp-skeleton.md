# pivotphp/skeleton

> 标签: Skeleton, api, express, framework, pivotphp, project-template, psr-15, psr-7, rest

## 简介

Project template for PivotPHP 4 — Express.js-style PHP API on PSR-7/PSR-15

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
