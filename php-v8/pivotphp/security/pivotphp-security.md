# pivotphp/security

> 标签: cors, csrf, jwt, middleware, php, pivotphp, psr-15, rate-limit, security, security-headers

## 简介

Security middlewares for PivotPHP and any PSR-15 pipeline: CORS, trusted proxies, security headers, CSRF, JWT and rate limiting

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
