# pivotphp/logger

> 标签: logger, logging, monolog, opentelemetry, php, pivotphp, psr-3

## 简介

PSR-3 logging implementation for PivotPHP powered by Monolog with multi-channel and telemetry support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
