# ins0/github-changelog-generator

> 标签: changelog, generator, github, keepachangelog, markdown

## 简介

Creates a markdown changelog for your GitHub repository.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
