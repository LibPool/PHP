# verstka/sdk

> 标签: api, cms, editor, sdk, verstka

## 简介

PHP SDK for Verstka API v2: open editor sessions, verify callbacks, download and process material content (media + fonts).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
