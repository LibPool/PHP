# lacodix/laravel-scoped-mail-config

> 标签: config, dynamic, lacodix, laravel, mail, scope, tenant

## 简介

A package that enables user or tenant specific mail driver configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
