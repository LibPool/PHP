# kubill/etcd

> 标签: api, configuration, distributed, etcd, php

## 简介

Etcd client library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://github.com/kubill/etcd
- 源码仓库：https://github.com/kubill/etcd.git
- Packagist 页面：https://packagist.org/packages/kubill%2Fetcd
