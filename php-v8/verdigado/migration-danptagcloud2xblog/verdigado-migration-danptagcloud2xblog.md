# verdigado/migration-danptagcloud2xblog

> 标签: PHP

## 简介

Migrates danp_tagcloud plugins to xBlog plugin Tag Cloud

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
