# ensalza/ether

> 标签: Opcache, cache, composer, file-cache, php, stale-cache, static-cache, varexporter

## 简介

Lightweight static PHP cache with file persistence, OPcache acceleration and automatic regeneration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
