# arabcoders/database

> 标签: database, mysql, pdo, pgsql, sqlite

## 简介

Standalone database toolkit for PDO with query building, ORM, schema migrations, and seeding.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
