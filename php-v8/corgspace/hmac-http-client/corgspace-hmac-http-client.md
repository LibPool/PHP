# corgspace/hmac-http-client

> 标签: Guzzle, api, hmac, http-client, laravel, middleware, signing

## 简介

HMAC-signed HTTP client middleware for Laravel server-to-server APIs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
