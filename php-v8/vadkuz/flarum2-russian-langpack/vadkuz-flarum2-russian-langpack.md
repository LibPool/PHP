# vadkuz/flarum2-russian-langpack

> 标签: extension, flarum, language, locale, localization, ru-locale, russian, translation

## 简介

Russian language pack for Flarum 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
