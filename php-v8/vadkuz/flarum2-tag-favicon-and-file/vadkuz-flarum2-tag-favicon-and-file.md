# vadkuz/flarum2-tag-favicon-and-file

> 标签: PHP

## 简介

Adds favicon URL support for tag/category icons as an alternative to Font Awesome classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
