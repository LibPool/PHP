# vadkuz/flarum2-secondary-tags-master

> 标签: PHP

## 简介

Bind global secondary tags to specific primary tags and control whether they appear in All Discussions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
