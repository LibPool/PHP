# lighthinkstudio/siasync

> 标签: PHP

## 简介

SIASYNC adalah sebuah library konfigurasi API SIASN untuk Framework Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
