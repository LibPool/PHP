# walle89/swedbank-json

> 标签: Banking, api, client, json

## 简介

Unofficial API client for the Swedbank's and Sparbanken's mobile apps in Sweden.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
