# serganbus/statements-parser

> 标签: Sovcombank, VTB, money, parser, statement, ВТБ, Совкомбанк

## 简介

Набор парсеров для парсинга выписок по операциям по счету различных банков РФ

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
