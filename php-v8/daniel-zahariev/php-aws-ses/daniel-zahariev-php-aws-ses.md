# daniel-zahariev/php-aws-ses

> 标签: amazon, api, aws, email, rest, ses

## 简介

Send emails via Amazon Simple Email Service (SES) with REST-like interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
