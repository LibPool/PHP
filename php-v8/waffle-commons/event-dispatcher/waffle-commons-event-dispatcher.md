# waffle-commons/event-dispatcher

> 标签: PHP

## 简介

PSR-14 event dispatching for Waffle Commons: listener providers, stoppable events, and a worker-safe dispatcher wired at boot.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
