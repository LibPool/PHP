# waffle-commons/log

> 标签: PHP

## 简介

PSR-3 logging for Waffle Commons: a minimal stream logger with channel separation, safe to hold across FrankenPHP worker requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
