# max-antipin/php-code-sniffs

> 标签: dev, phpcs, standards, static analysis

## 简介

Coding Standard for PHP_CodeSniffer by Max Antipin provides sniffs with additional checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
