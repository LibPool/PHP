# rzajac/vagrant-prov

> 标签: vagrant

## 简介

Vagrant provisioning scripts for PHP, MySQL, Apache and Nginx

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
