# convergine/craft-sharebox

> 标签: Craft, amazon S3, azure blob storage, cloud storage, cms, convergine, craft file manager, craft-plugin, craftcms, file hosting, file library, files sharing, public file sharing

## 简介

ShareBox allows to share files hosted on Azure Blob Storage or Amazon S3 with your site visitors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
