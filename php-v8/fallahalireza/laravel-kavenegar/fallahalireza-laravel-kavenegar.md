# fallahalireza/laravel-kavenegar

> 标签: kavenegar, laravel, notification, sms

## 简介

درایور تمیز، توسعه‌پذیر و تست‌پذیر ارسال پیامک کاوه‌نگار برای لاراول (Notification Channel، Facade، Fake)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
