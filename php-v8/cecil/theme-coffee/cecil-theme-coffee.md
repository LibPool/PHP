# cecil/theme-coffee

> 标签: blocks, cecil, corporate, tailwind, theme

## 简介

Cecil theme: Coffee, a corporate theme built with blocks, powered by Tailwind CSS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
