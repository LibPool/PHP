# josespinal/odoo-rpc

> 标签: ERP, jsonrpc, laravel, odoo, php, xmlrpc

## 简介

PHP Odoo RPC connector with JSON-RPC and XML-RPC support, prepared for Laravel integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
