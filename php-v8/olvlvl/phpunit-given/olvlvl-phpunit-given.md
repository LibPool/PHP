# olvlvl/phpunit-given

> 标签: mock, phpunit, test double

## 简介

An alternative to PHPUnit's ReturnValueMap and ReturnCallback. A convenient solution to migrate from Prophecy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
