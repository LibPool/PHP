# matmper/php-telegram-sdk-bot

> 标签: PHP

## 简介

The PHP Telegram SDK (BOT) is a easy-to-use package designed to simplify the integration of Telegram bots into PHP applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
