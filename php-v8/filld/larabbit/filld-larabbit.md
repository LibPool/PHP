# filld/larabbit

> 标签: AMQP, filld, laravel, laravel5, lumen, message queue, package, queue, rabbitmq

## 简介

AMQP wrapper for Laravel and Lumen to publish and consume messages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
