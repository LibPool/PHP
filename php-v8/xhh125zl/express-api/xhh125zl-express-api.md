# xhh125zl/express-api

> 标签: PHP

## 简介

一个通用的快递API集成包，支持多种快递公司（EMS、韵达、申通、中通、菜鸟、顺丰、通用打印面单设计器等）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
