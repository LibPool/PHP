# andegna/geezify

> 标签: ethiopian, geez, geezify

## 简介

A library to convert ascii number like '3456' to geez number '፴፬፻፶፮' and vise versa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
