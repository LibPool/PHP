# adamjenkins/moodle-tool_bass

> 标签: PHP

## 简介

Bulk Activity Settings Selector: a Moodle admin tool that changes the settings of some or all activities of one type in a course in one go

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
