# adamjenkins/moodle-local_accessibility

> 标签: PHP

## 简介

A Moodle accessibility toolbar that lets every user adjust how Moodle looks and reads for them: text size, spacing, fonts, colours, motion and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
