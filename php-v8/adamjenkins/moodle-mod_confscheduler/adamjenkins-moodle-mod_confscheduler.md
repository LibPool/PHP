# adamjenkins/moodle-mod_confscheduler

> 标签: PHP

## 简介

Conference Scheduler - a Moodle activity module that turns accepted submissions into a drag-and-drop block schedule (time x room grid), with autoscheduling and print support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
