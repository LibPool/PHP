# adamjenkins/moodle-mod_confsubmissions

> 标签: PHP

## 简介

Conference Submissions - a Moodle activity module for running a call for abstracts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
