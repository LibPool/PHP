# adamjenkins/moodle-mod_confprogram

> 标签: PHP

## 简介

Conference Program - a Moodle activity module that runs submissions through a reviewer vetting workflow, then displays the accepted programme to attendees.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
