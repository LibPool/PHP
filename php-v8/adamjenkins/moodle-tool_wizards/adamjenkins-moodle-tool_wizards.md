# adamjenkins/moodle-tool_wizards

> 标签: admin tool, course creation, moodle, new teachers, wizard

## 简介

Moodle admin tool with friendly step-by-step wizards for creating a course and adding its first content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
