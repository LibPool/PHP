# adamjenkins/moodle-tiny_ruby

> 标签: PHP

## 简介

A TinyMCE editor plugin for Moodle that edits the Ruby (furigana) filter's inline markup through a dialog and copies a word list of the text's readings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
