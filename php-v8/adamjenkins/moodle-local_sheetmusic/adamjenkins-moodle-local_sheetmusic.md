# adamjenkins/moodle-local_sheetmusic

> 标签: PHP

## 简介

The shared engine behind the sheetmusic Moodle plugin suite: a document model, ABC and MusicXML serialisers, a MIDI importer, playback, and a bundled Verovio engraver, all running client-side

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
