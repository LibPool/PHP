# rabbitevents/symfony-bundle

> 标签: AMQP, Broadcast, event-driven, events, messaging, microservices, protobuf, publish, pubsub, queue, rabbitmq, subscribe, symfony

## 简介

RabbitEvents for Symfony — publish and listen to events across microservices via RabbitMQ

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
