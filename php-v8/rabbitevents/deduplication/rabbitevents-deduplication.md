# rabbitevents/deduplication

> 标签: deduplication, idempotency, laravel, rabbitevents, rabbitmq

## 简介

Skips messages redelivered to RabbitEvents listeners, using a Laravel cache store shared by the workers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
