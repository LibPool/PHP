# antqa/payum-perfectmoney

> 标签: payment, payum, perfect money, perfectmoney, symfony

## 简介

The Payum extension. It provides Perfectmoney payment integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
