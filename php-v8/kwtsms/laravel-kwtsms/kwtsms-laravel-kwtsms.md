# kwtsms/laravel-kwtsms

> 标签: kuwait, kwtsms, laravel, notification, otp, sms

## 简介

Laravel notification channel for the kwtSMS SMS gateway (Kuwait)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
