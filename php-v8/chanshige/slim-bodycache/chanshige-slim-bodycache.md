# chanshige/slim-bodycache

> 标签: filesystem, framework, middleware, psr-16, psr-7, simple-cache, slim

## 简介

A slim middleware for Filesystem Cache based on symfony/cache

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
