# de-swebhosting-typo3-extension/mediaoembed

> 标签: PHP

## 简介

External media (YouTube, Flickr, ...) content elements using the https://oembed.com/ standard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
