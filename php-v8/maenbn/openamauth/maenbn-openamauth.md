# maenbn/openamauth

> 标签: Authentication, Ben Norcombe, BenNorcombe, OpenAM, OpenAmAuth, auth, opemam auth, openam authentication

## 简介

OpemAmAuth is a client for authenticating against OpenAM in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
