# ip-api-io/ipapi-php

> 标签: IP API, asn lookup, email validation, fraud detection, geoip, ip geolocation, risk score, tor detection, vpn detection, whois

## 简介

Official PHP client for ip-api.io — IP geolocation, email validation, fraud detection and risk scoring API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
