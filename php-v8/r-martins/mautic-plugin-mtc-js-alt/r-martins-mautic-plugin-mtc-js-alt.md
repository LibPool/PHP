# r-martins/mautic-plugin-mtc-js-alt

> 标签: Mautic, analytics, mautic-plugin, mtc.js, tracking

## 简介

Mautic plugin: optional alternate public URL (filename) for the tracking script, same output as mtc.js. Configured under Settings → Configuration → Tracking settings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
