# milescellar/phpbb-translation-validator

> 标签: PHP

## 简介

A validator for phpBB language packs. Translations are required to pass this validator when submitted to the Customisation Database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
