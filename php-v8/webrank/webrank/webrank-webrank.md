# webrank/webrank

> 标签: Pagerank, authority, domain, popularity, rank, seo, tranco

## 简介

Open domain popularity + authority rank — a free Tranco alternative (webrank + pagerank).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
