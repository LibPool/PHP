# kikwik/command-blameable-bundle

> 标签: PHP

## 简介

Subscriber for gedmo/doctrine-extension Blameable that set the actual command name in the createdBy and updatedBy fields

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
