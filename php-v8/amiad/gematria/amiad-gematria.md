# amiad/gematria

> 标签: conversion, converter, gematria, hebrew, jewish

## 简介

Simple Gematria library for PHP - convert Hebrew letters to numbers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
