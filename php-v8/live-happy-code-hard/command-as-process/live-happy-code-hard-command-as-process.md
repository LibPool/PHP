# live-happy-code-hard/command-as-process

> 标签: PHP

## 简介

Object wrappers around PHP program execution functions: proc_open(), proc_close(), proc_terminate(), proc_get_status()

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
