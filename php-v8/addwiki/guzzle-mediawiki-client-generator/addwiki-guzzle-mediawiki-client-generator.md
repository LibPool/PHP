# addwiki/guzzle-mediawiki-client-generator

> 标签: Guzzle

## 简介

Used to generate a Guzzle service description for the Mediawiki Api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
