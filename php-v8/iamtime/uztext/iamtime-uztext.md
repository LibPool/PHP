# iamtime/uztext

> 标签: ozbek, search, stemmer, transliteration, uzbek

## 简介

Uzbek text for search: apostrophes, Latin and Cyrillic, wrong keyboard layout, word endings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
