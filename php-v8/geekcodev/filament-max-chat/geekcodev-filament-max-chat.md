# geekcodev/filament-max-chat

> 标签: chat, filament, laravel, livewire, max, max messenger, operator

## 简介

Filament plugin: operator chat with MAX messenger users, on top of geekcodev/laravel-max-client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
