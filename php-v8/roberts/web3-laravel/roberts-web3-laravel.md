# roberts/web3-laravel

> 标签: laravel, roberts, web3-laravel

## 简介

Protocol-first, chain-agnostic Web3 toolkit with native EVM JSON-RPC and signer for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
