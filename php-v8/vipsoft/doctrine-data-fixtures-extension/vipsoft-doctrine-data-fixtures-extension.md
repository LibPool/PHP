# vipsoft/doctrine-data-fixtures-extension

> 标签: BDD, Behat, Data fixtures, doctrine

## 简介

Doctrine data fixtures extension for Behat

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
