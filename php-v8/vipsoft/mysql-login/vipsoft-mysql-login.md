# vipsoft/mysql-login

> 标签: Authentication, credentials, mariadb, mysql, security

## 简介

Reader/decoder for .mylogin.cnf -- obfuscated MySQL authentication credentials

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
