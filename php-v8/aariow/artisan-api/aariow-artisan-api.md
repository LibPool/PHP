# aariow/artisan-api

> 标签: api, artisan, command, console, http, laravel, php, rest

## 简介

Execute Laravel Artisan commands via REST APIs and HTTP requests safely.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
