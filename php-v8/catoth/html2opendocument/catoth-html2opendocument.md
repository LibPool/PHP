# catoth/html2opendocument

> 标签: OpenDocument, html, ods, odt

## 简介

Converting simple HTML to Opendocument Text (ODT) or Spreadsheets (ODS)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
