# pietervanleuven/vitodeploy-mcp

> 标签: ai, claude, mcp, model-context-protocol, vitodeploy, vitodeploy-plugin

## 简介

MCP server for VitoDeploy: manage servers, sites, deployments, databases, workers and more from Claude and other AI agents, using your Vito API keys

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
