# pietervanleuven/vitodeploy-bunny

> 标签: Bunny.net, bunny, cdn, dns, storage, vitodeploy, vitodeploy-plugin

## 简介

Bunny.net integration for VitoDeploy: DNS provider, Edge Storage backups and CDN cache purging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
