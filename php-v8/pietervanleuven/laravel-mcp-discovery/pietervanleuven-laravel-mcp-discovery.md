# pietervanleuven/laravel-mcp-discovery

> 标签: agents, ai, discovery, laravel, llms.txt, mcp, model-context-protocol, server-card

## 简介

Make your laravel/mcp servers discoverable by AI agents: server cards, llms.txt, robots.txt, Link headers and a bot gate.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
