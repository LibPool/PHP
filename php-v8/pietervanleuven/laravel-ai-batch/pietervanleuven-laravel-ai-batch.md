# pietervanleuven/laravel-ai-batch

> 标签: OpenRouter, ai, anthropic, batch, laravel, openai

## 简介

Asynchronous batch API support (OpenAI, Anthropic, OpenRouter) for the Laravel AI SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
