# pascalheidmann/mago-jms-serializer

> 标签: PHP

## 简介

Mago analyzer plugin that treats JMS Serializer annotated/attributed properties as externally read and written, avoiding false unused-property / write-only-property findings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
