# makepay/makepay-php

> 标签: crypto-payments, makecrypto, makepay, payment-links, webhooks

## 简介

Official MakePay PHP SDK for payment links, settings, and webhook verification.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
