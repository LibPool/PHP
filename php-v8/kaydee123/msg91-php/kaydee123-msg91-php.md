# kaydee123/msg91-php

> 标签: api, messaging, msg91, otp, sms

## 简介

A PHP client library for MSG91 SMS and OTP services. Compatible with PHP 8.0 through 8.5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
