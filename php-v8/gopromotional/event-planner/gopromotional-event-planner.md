# gopromotional/event-planner

> 标签: countdown, event-planning, giveaways, gopromotional, trade-show

## 简介

Event countdown, planning timeline, giveaway quantities and print order-by dates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
