# coffeemail/coffeemail-php

> 标签: PHP

## 简介

SDK oficial do CoffeeMail para PHP moderno (8.2+). Envio transacional de e-mails, templates, domínios e webhooks com tipagem estrita e retorno seguro.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
