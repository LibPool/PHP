# dotkernel/dot-router

> 标签: FastRoute, dotkernel, mezzio, psr-15, router

## 简介

Dotkernel component to build complex routes, based on mezzio/mezzio-fastroute

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
