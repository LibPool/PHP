# sbodak/magento2-checkout-custom-form

> 标签: checkout form, custom checkout, magento2, magento2-module

## 简介

Add a custom form to Magento 2 checkout on the shipping step.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
