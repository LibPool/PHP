# ismailelbery/laravel-ldap-sync

> 标签: PHP

## 简介

Sync users from Active Directory OUs into a local Eloquent model, with live LDAP search and manager resolution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
