# flyimg/flyimg

> 标签: Flysystem, ImageMagick, MozJPEG, crop, image, resize

## 简介

Server image resizing and cropping on the fly base on ImageMagick+MozJPEG

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
