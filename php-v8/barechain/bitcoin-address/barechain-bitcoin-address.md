# barechain/bitcoin-address

> 标签: address, bitcoin, generator

## 简介

A simple P2PK, P2PKH, P2SH, P2WPKH, P2WSH output script/address generator.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
