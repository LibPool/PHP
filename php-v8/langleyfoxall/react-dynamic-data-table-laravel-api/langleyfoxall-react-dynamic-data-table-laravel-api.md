# langleyfoxall/react-dynamic-data-table-laravel-api

> 标签: PHP

## 简介

Provides a Laravel API endpoint responder for the `react-dynamic-data-table` component.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
