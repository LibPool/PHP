# langleyfoxall/eloquent-report-generator

> 标签: PHP

## 简介

Generates reports from Eloquent models in CSV, PDF, Markdown, HTML, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
