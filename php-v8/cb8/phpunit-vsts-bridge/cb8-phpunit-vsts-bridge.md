# cb8/phpunit-vsts-bridge

> 标签: junit, phpunit, test, testcase, unit-test, vsts

## 简介

Publish test results from PHPUnit to VSTS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
