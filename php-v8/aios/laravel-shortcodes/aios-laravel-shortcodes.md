# aios/laravel-shortcodes

> 标签: laravel, shortcodes, wordpress

## 简介

Wordpress like shortcodes for Laravel 5, 6, 7 and 8

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
