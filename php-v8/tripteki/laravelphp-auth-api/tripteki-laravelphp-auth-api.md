# tripteki/laravelphp-auth-api

> 标签: PHP

## 简介

Trip Teknologi's Laravel.php Auth API (Session/Token Sanctum, Token JWT, Token OAuth Passport)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
