# dirkpersky/typo3-dp_http2

> 标签: http2, scriptmerger, typo3

## 简介

This Plugin add HTTP2 Push header or preloads, scripts and css files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
