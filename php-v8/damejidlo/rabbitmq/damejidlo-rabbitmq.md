# damejidlo/rabbitmq

> 标签: AMQP, message, messaging, nette, queue, rabbit, rabbitmq

## 简介

Integrates php-amqplib with RabbitMq and Nette Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
