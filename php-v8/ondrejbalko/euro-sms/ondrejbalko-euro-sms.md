# ondrejbalko/euro-sms

> 标签: delivery-report, eurosms, notifications, psr-18, slovakia, sms, sms-gateway, viber

## 简介

PHP client for the EuroSMS gateway: sending, delivery statuses, CallBack notifications and Viber over SMS API v3.1.15.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
