# nytodev/inertia-bundle

> 标签: SPA, bundle, inertia, inertiajs, react, svelte, symfony, vue

## 简介

Symfony Bundle implementing the Inertia.js v3 server-side protocol

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
