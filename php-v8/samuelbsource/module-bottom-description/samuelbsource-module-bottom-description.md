# samuelbsource/module-bottom-description

> 标签: PHP

## 简介

Adds a WYSIWYG-enabled bottom description attribute to Magento 2 categories and displays it below the main content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
