# jcore/runner

> 标签: PHP

## 简介

JCORE Script Runner. A WordPress plugin to easily allow manual running of scripts for maintenance and utility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
