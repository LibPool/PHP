# mito/yii2-jquery-fileupload

> 标签: extension, fileupload, jquery, yii2

## 简介

jQuery File Upload Yii 2 wrapper extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
