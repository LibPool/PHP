# mailchannels/mailchannels-php

> 标签: email, email-api, laravel, mailchannels, psr-18, psr-7, sdk, smtp, symfony, transactional-email

## 简介

Official MailChannels Email API SDK for transactional email, with Laravel and Symfony Mailer integrations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
