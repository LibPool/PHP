# wielorzeczownik/phalcon-inertia

> 标签: SPA, SSR, Ziggy, inertia, inertiajs, phalcon, php, react, routes, svelte, vite, vue

## 简介

Inertia.js server adapter for Phalcon 3.4 to 6, with Ziggy style named routes for JavaScript.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
