# blahtesoftware/bspdf

> 标签: bspdf, image, laravel, pdf, wkhtmltoimage, wkhtmltopdf

## 简介

PHP HTML to PDF conversion with support for modern HTML and CSS. Built on wkhtmltopdf.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
