# litvinenko/object

> 标签: PHP

## 简介

Litvinenko\Common\Object class that powers Varien Object class with data validation rules taken from 'illuminate\validation' package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
