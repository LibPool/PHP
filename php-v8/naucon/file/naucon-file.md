# naucon/file

> 标签: copy, delete, dir, file, filesystem, io, move, rename

## 简介

This package contains php classes to access, change, copy, delete, move, rename files and directories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
