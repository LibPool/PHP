# paspo/export_provisioning

> 标签: Settings, configuration, export, ios, roundcube

## 简介

Lets you export a configuration file for iOS/OSX/WLM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
