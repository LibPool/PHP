# salsan/clubs

> 标签: Federazione Scacchistica Italiana, chess, fsi, scacchi

## 简介

Library to get data about chess clubs from website Federazione Scacchistica Italiana

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
