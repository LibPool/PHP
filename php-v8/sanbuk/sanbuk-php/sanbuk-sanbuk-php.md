# sanbuk/sanbuk-php

> 标签: Advertising, conversion-tracking, cpa, postback, sanbuk

## 简介

Official PHP SDK for Sanbuk — CPA conversion tracking and server-to-server postbacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
