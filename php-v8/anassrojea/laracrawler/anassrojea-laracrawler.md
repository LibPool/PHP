> 标签: Sitemap, crawler, hreflang, image-sitemap, indexability, laracrawler, laravel, laravel-package, multilingual, priority-scoring, search-engine-optimization, seo, seo-tools, video-sitemap, xml-sitemap

## 简介

Laravel sitemap generator and crawler package for SEO optimization. Supports multilingual sites, image/video indexing, link validation, priority scoring, and advanced crawling automation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
