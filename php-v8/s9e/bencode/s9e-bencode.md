# s9e/bencode

> 标签: bencode, bittorrent, torrent

## 简介

Fast and efficient bencode decoder/encoder, designed to handle malformed and malicious input gracefully.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
