# cardanopress/framework

> 标签: cardano, cardanopress, generator-themeplate, themeplate, wordpress

## 简介

A ThemePlate project for Cardano WordPress integration

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
