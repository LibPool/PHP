# jlopezmx/simple-logging

> 标签: PHP

## 简介

A singleton logger implementation using MonoLog with simple configuration to control format dates, messages and log files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
