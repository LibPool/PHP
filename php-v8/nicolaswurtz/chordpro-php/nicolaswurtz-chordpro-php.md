# nicolaswurtz/chordpro-php

> 标签: PHP

## 简介

Parse, transpose and format (html,json,plaintext) ChordPro format for songs lyrics with chords.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
