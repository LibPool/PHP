# faudin/php-ssh

> 标签: ssh, ssh2

## 简介

Provides an object-oriented wrapper for the php ssh2 extension. (based on herzult package)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
