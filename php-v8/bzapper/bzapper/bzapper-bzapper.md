# bzapper/bzapper

> 标签: api, bzapper, gateway, messaging, sdk, whatsapp

## 简介

SDK oficial do bZapper em PHP — gateway de WhatsApp multi-tenant (envio de mensagens, instâncias, keys e uso).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
