# simmbiote/sim-export-excel

> 标签: PHP

## 简介

Extend existing features of your WordPress admin interface to enable proper Excel exports of data (not just CSV).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
