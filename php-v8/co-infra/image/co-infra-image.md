# co-infra/image

> 标签: atproto, bluesky, cdn, image, srcset

## 简介

Build img.infra.coop URLs and srcsets. Zero dependencies, framework agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/co-infra/image-php.git
- Packagist 页面：https://packagist.org/packages/co-infra%2Fimage
