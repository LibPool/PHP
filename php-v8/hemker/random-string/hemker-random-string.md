# hemker/random-string

> 标签: PHP

## 简介

Creation of random strings (e.g. for coupon codes in webshops, hashes for one-time links/passwords, accound codes, etc. pp.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
