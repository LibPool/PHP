# coloredcow/laravel-gsuite

> 标签: coloredcow, gsuite, laravel, socialite

## 简介

A Laravel package to setup Google OAuth and GSuite Admin SDK

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
