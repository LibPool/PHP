# timneutkens/magento2-module-enquire-js

> 标签: PHP

## 简介

Add Enquire.js from CDN as a require.js module shim. With fallback to local version when CDN is offline.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
