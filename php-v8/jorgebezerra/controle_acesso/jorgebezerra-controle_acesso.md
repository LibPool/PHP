# jorgebezerra/controle_acesso

> 标签: PHP

## 简介

Pacote para controle de acesso, baseado em papel/permissão, inclui interfaces gráficas em AdminLTE

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
