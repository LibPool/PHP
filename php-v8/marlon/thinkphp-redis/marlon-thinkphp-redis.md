# marlon/thinkphp-redis

> 标签: PHP

## 简介

thinkphp 5.0.*下的redis升级版本驱动,支持各种官方不支持的red操作

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
