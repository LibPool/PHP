# soloterm/vtail

> 标签: cli, laravel, log, tail, terminal

## 简介

Vendor-aware tail for Laravel logs with stack trace formatting and vendor frame collapsing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
