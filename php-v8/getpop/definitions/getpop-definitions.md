# getpop/definitions

> 标签: Gato, GatoGraphQL, definitions, graphql, php

## 简介

Enables to define a name for an element (such as modules, resources, etc) through different strategies

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
