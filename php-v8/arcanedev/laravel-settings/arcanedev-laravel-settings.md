# arcanedev/laravel-settings

> 标签: Settings, arcanedev, array, config, database, db, json, laravel

## 简介

This package allows you to persists configs/settings for Laravel projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
