# arcanedev/agent

> 标签: Devices, arcanedev, detect, detector, laravel, mobile, user agent

## 简介

Agent is a PHP/Laravel package for detecting devices/bots via the http request.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
