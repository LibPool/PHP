# arcanedev/laravel-messenger

> 标签: Messenger, arcanedev, chat, conversation, discussion, laravel, message

## 简介

Simple messaging system for Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
