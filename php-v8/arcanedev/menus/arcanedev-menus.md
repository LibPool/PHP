# arcanedev/menus

> 标签: arcanedev, bootstrap, builder, laravel, menu, menus, nav, navbar, navigation

## 简介

Menu builder for Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
