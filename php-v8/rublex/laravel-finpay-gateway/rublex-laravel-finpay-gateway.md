# rublex/laravel-finpay-gateway

> 标签: finpay, gateway, laravel, payment, rublex

## 简介

A Laravel payment gateway package for Finpay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
