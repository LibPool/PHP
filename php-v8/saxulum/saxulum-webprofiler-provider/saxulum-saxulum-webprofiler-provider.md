# saxulum/saxulum-webprofiler-provider

> 标签: saxulum, silex, webprofiler

## 简介

A extended webprofiler for saxulum (silex)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
