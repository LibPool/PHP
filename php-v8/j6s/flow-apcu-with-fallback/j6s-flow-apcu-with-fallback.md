# j6s/flow-apcu-with-fallback

> 标签: PHP

## 简介

Package that provides an APCu cache backend that falls back to a given fallback if the APCu extension is not installed.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
