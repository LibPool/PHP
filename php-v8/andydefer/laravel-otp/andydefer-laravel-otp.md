# andydefer/laravel-otp

> 标签: PHP

## 简介

Laravel package providing OTP (One-Time Password) management with Repository pattern, DTOs, Enums, and Value Objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
