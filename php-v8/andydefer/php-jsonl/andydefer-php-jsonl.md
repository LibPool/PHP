# andydefer/php-jsonl

> 标签: PHP

## 简介

High-performance JSONL (JSON Lines) file management library with temporal and key-based storage strategies, automatic batching, and cache expiration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
