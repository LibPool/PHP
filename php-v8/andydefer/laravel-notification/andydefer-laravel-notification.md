# andydefer/laravel-notification

> 标签: PHP

## 简介

Extensible polymorphic notification system for Laravel with multi-channel support (Mail, Database, SMS, WhatsApp, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
