# andydefer/php-vo

> 标签: PHP

## 简介

A collection of reusable Value Objects and Enums for PHP applications (Email, Money, Address, PostalCode, Iso8601DateTime, Currency, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
