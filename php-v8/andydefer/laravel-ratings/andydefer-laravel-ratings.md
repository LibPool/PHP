# andydefer/laravel-ratings

> 标签: PHP

## 简介

Polymorphic rating and review system for Laravel with star ratings (1-5), reviews, average calculations, and distribution statistics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
