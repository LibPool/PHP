# andydefer/laravel-activity

> 标签: PHP

## 简介

Polymorphic activity tracking for Laravel models with typed activity types, JSON data payloads, causer/subject relations, and query helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
