# andydefer/laravel-locationiq

> 标签: OpenStreetMap, api, directions, geocoding, geospatial, laravel, laravel-package, locationiq, nominatim, open-source, php, reverse-geocoding, timezone

## 简介

Laravel SDK for integrating LocationIQ and Nominatim geospatial services (balance, timezone, directions, reverse geocoding).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
