# andydefer/laravel-likes

> 标签: PHP

## 简介

Laravel package providing polymorphic reactions (like, love, haha, wow, sad, angry) with Repository pattern, DTOs, Enums, and Value Objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
