# andydefer/laravel-comments

> 标签: PHP

## 简介

Laravel package providing polymorphic comments with Repository pattern, DTOs, Enums, Status management, and Value Objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
