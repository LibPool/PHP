# andydefer/data-validator

> 标签: array-validator, constraints, data-filter, data-validation, input-validation, metadata, php-validator, sanitization, structured-data, validation

## 简介

Validates and sanitizes structured data arrays with configurable constraints (size, depth, nesting, key/value types).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
