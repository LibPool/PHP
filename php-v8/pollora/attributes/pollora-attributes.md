# pollora/attributes

> 标签: attributes, hooks, php, pollora, post-types, wordpress

## 简介

PHP attributes to declare WordPress post types, taxonomies, hooks, REST routes, meta, roles, schedules and more. Declarations only: they run without the framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
