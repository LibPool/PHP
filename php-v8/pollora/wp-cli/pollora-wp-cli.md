# pollora/wp-cli

> 标签: attributes, pollora, wordpress, wp-cli

## 简介

WP-CLI commands declared with PHP attributes: a class with #[WpCli], subcommands with #[Command], synopsis, hooks and conditions as attributes. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
