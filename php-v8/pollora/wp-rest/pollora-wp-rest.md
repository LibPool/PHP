# pollora/wp-rest

> 标签: attributes, pollora, rest-api, wordpress

## 简介

WordPress REST API routes declared with PHP attributes: a controller class, #[WpRestRoute] and #[Method], permissions as classes. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
