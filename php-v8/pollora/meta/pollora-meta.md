# pollora/meta

> 标签: meta, pollora, post-meta, typed, wordpress

## 简介

Typed WordPress meta declared with attributes: register_meta(), typed reads and writes, rules, schemas for UI drivers. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
