# pollora/abilities

> 标签: abilities, abilities-api, ai, mcp, wordpress

## 简介

A modern PHP package for the WordPress Abilities API, with a fluent declaration API and a hexagonal architecture

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
