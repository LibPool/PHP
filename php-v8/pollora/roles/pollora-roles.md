# pollora/roles

> 标签: capabilities, pollora, roles, wordpress

## 简介

WordPress roles and capabilities declared with attributes: a #[Role] class, #[ModifyRole] adjustments, post type and taxonomy capabilities, compiled into the roles WordPress stores. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
