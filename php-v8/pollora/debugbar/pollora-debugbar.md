# pollora/debugbar

> 标签: debugbar, laravel, pollora, query-monitor, wordpress

## 简介

Laravel Debugbar for Pollora: WordPress queries, hooks, the template hierarchy and Pollora's internals in the debug bar

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
