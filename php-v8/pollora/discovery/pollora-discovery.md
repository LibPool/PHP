# pollora/discovery

> 标签: attributes, discovery, php, pollora, wordpress

## 简介

Find the PHP classes that carry attributes in themes, plugins and modules, and hand them to the code that registers them. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
