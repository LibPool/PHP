# pollora/schedule

> 标签: cron, pollora, schedule, wordpress, wp-cron

## 简介

Scheduled and deferred tasks for WordPress: one engine, a fluent API and #[Schedule] attributes, WP-Cron as the default driver. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
