# pollora/block-bindings

> 标签: block-bindings, blocks, gutenberg, pollora, wordpress

## 简介

WordPress Block Bindings declared with attributes: a #[BlockBinding] class is a source, its methods are fields, and the post meta, term meta, author meta and options Pollora ships are ready to bind. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
