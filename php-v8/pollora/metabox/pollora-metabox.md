# pollora/metabox

> 标签: custom-fields, fluent, gutenberg-blocks, meta-box, metabox, pollora, wordpress

## 简介

Declare Meta Box meta boxes, fields, blocks and settings pages with a fluent PHP API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
