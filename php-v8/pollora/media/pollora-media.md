# pollora/media

> 标签: Flysystem, media, pollora, s3, uploads, wordpress

## 简介

WordPress media on any Flysystem disk: uploads, public URLs, private files, image sizes and thumbnails, behind two settings. Runs with or without Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
