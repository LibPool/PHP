# craftcms/yii2-cache-cascade

> 标签: cache, cascade, fallback, resilience, yii2

## 简介

A Yii2 cache component that cascades through multiple cache drivers on failure

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
