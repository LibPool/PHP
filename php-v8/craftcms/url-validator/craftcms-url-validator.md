# craftcms/url-validator

> 标签: IP, craftcms, security, ssrf, url, validation

## 简介

Validate URLs and IP addresses against SSRF, DNS rebinding, and cloud-metadata attacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
