# craftcms/http-message-signatures

> 标签: Authentication, http, rfc9421, security, signature

## 简介

PSR-7 compliant PHP 8.1+ implementation of HTTP Message Signatures (RFC 9421)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
