# yuhal/laravel-sync-database

> 标签: database, laravel, migration, mysql, package, php, sync, tool

## 简介

Laravel tool helps to sync databases without refreshing the migration

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
