# diegocopat/laravel-deploy

> 标签: artisan, build, deploy, git, laravel

## 简介

Comando Artisan per build, clean e deploy automatico su Laravel con rilevamento branch Git

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
