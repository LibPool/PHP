# koded/i18n

> 标签: .po, i18n, multilanguage, translation

## 简介

Simple internationalization library with support for .po and .php translation files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/kodedphp/i18n/
- 源码仓库：https://github.com/kodedphp/i18n.git
