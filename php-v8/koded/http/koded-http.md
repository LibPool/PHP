# koded/http

> 标签: http, http-client, negotiation, psr-17, psr-7, pst-18, request, response, stream

## 简介

Koded HTTP component. Implements PSR-7, PSR-17 and PSR-18

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
