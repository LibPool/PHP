# vmlyr-drupal/kit

> 标签: PHP

## 简介

Project template for VMLY&R Drupal 10 projects with composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.drupal.org/project/drupal
- 源码仓库：https://github.com/VMLYR/Drupal-KIT.git
