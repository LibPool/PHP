# farmani/yii2mailgunmailer

> 标签: extension, mailer, mailgun, yii2

## 简介

Mailgun Mailer for Yii 2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
