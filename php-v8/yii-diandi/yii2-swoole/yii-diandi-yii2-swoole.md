# yii-diandi/yii2-swoole

> 标签: coroutine, swoole, yii2

## 简介

run yii2 in swoole coroutine mode，基于店滴云开源框架的swoole扩展

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
