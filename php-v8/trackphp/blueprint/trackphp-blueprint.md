# trackphp/blueprint

> 标签: framework, php, starter, trackPHP

## 简介

Starter project for trackPHP, a lightweight, convention-driven PHP framework for building web applications with minimal setup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
