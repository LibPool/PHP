# silylink/laravel

> 标签: checkout, hmac, laravel, payment, silylink

## 简介

SDK Laravel officiel pour l'API marchande SilyLink (checkout, charges, transfers, payouts, webhooks).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
