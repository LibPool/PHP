# silylink/php

> 标签: checkout, hmac, payment, php, silylink

## 简介

SDK PHP officiel pour l'API marchande SilyLink (checkout, charges, transfers, payouts, webhooks).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
