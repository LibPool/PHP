# lsxiao/user-agent-for-laravel5

> 标签: Agent, laravel, laravel5, useragent

## 简介

a UserAgent parser package for laravel5 which is based on WhichBrowser/Parser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
