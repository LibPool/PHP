# bagisto-eu/azure-auth

> 标签: Authentication, SSO, admin, azure, bagisto, microsoft entra

## 简介

Enable SSO for your Bagisto admin panel with Microsoft Azure

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
