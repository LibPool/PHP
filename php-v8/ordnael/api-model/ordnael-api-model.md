# ordnael/api-model

> 标签: PHP

## 简介

Extendable class for REST API based models - instead of the traditional Database based one - that integrates common Laravel's Model class functionalities.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
