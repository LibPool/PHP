# anomaly/github_api-extension

> 标签: extension, streams addon, streams extension

## 简介

Easily integrate GitHub APIs into your Streams Platform projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
