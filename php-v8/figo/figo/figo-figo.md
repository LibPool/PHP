# figo/figo

> 标签: PHP

## 简介

API wrapper for figo Connect.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/figo-connect/php-figo.git
