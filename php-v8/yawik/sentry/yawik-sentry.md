# yawik/sentry

> 标签: error reporting, laminas, module, monitoring, sentry, yawik

## 简介

This module integrates Sentry error reporting in an YAWIK instance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
