# shankscode/haki

> 标签: api, dump, framework, jwt, microframework, rest, router

## 简介

Miniframework PHP simples para APIs REST, com rotas, injeção de dependências, middleware e autenticação JWT própria.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
