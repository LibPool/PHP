# diswebru/phpexcel

> 标签: OpenXML, excel, php, spreadsheet, xls, xlsx

## 简介

PHP library for writing and reading files in EXCEL format. Modified to work on PHP 8.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
