# oss-tools/laravel-libretranslate

> 标签: laravel-libretranslate, oss-tools

## 简介

Package to introduce a Client for translating text using LibreTranslate in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
