# aoe/tagging

> 标签: automatic, build, git, subversion, tag, tagging, vcs

## 简介

Build-Tool to automatic increase the version and create a tag in the remote VCS repository.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
