# aoe/scheduler_timeline

> 标签: TYPO3 CMS, scheduler, timeline

## 简介

Logs information about scheduler task execution and displays them in a graphical timeline

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
