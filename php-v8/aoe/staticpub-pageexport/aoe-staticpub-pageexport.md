# aoe/staticpub-pageexport

> 标签: extbase, staticpub-pageexport, typo3

## 简介

Exports pages (as ZIP-file) via staticpub

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
