# qsfx/bacon-qr-code

> 标签: PHP

## 简介

BaconQrCode is a QR code generator for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/qsfx/BaconQrCode
- 源码仓库：https://github.com/qfsx/BaconQrCode.git
- Packagist 页面：https://packagist.org/packages/qsfx%2Fbacon-qr-code

## 历史版本号

- 1.0.0

## 获取地址

- Composer 安装：`composer require qsfx/bacon-qr-code`
