# wp-coding-standards/wpcs

> 标签: phpcs, standards, static analysis, wordpress

## 简介

PHP_CodeSniffer rules (sniffs) to enforce WordPress coding conventions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
