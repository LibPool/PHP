# mrdebug/laravel-watchdog

> 标签: PHP

## 简介

Monitoring package for Laravel: 404/422/500 tracking, visits, activity, login attempts, sent emails, with Discord alerts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
