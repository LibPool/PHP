# springimport/yii2-magento2-activeapi

> 标签: api client, extension, magento2, yii2

## 简介

Implementation of Magento 2 REST API, made in the ActiveRecord-style

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
