# harish81/laravel-duckdb

> 标签: harish81, laravel, laravel-duckdb

## 简介

DuckDB CLI wrapper to interact with duckdb databases through laravel query builder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
