# rhrebecek/gedmo

> 标签: PHP

## 简介

Gedmo Doctrine Extensions integration into Nette Framework using Kdyby/Doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
