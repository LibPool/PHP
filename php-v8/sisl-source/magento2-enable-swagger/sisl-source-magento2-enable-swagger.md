# sisl-source/magento2-enable-swagger

> 标签: PHP

## 简介

Adds the option to re-enable Swagger via configuration. It's disabled in production mode sind Magento 2.4.4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
