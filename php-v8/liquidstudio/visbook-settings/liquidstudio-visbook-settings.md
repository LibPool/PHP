# liquidstudio/visbook-settings

> 标签: Craft, cms, craft-plugin, craftcms, visbook settings

## 简介

A craft plugin for Visbook custom settings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
