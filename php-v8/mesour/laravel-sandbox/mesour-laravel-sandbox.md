# mesour/laravel-sandbox

> 标签: framework, laravel, mesour components

## 简介

The sandbox is how to use mesour/laravel-bridges in the Laravel Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
