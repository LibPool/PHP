# krikrixs/php-beatsaver-api

> 标签: BeatSaber, BeatSaver, KriKrixs, Krixs, PHP-BeatSaver-API, map

## 简介

A Simple PHP library to interact with BeatSaver's API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
