# brunodebarros/fix-php-post-input

> 标签: compatibility, files, input, post

## 简介

If your $_POST/$_FILES are empty and they shouldn't be, this library fixes them.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
