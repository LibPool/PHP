# guidofaecke/ibmitoolkit

> 标签: IBM i, XMLSERVICE, as400, ibmitoolkit, ibmxmltoolkit, zend

## 简介

PHP frontend to XMLSERVICE for IBM i development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
