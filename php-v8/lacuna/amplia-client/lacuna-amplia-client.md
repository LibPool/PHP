# lacuna/amplia-client

> 标签: amplia, api, certificate, client, issue, pki, rest

## 简介

Classes to consume Lacuna Software's Amplia

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
