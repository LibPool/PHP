# dantleech/symfony-form-array-to-delimited-string-transformer

> 标签: PHP

## 简介

Data transformer for SF form. Transforms delimited to string to array and vice-versa

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
