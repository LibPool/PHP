# redisync/core

> 标签: cache, dbal, doctrine, middleware, psr-15, psr-7, redis

## 简介

Smart caching middleware for PHP using Redis and MySQL/PostgreSQL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
