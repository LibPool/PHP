# timbrs/database-dumps

> 标签: database, dump, export, import, laravel, mysql, oracle, postgresql, sql, symfony

## 简介

Framework-agnostic PHP package for managing database dumps with SQL exports/imports, supporting PostgreSQL, MySQL and Oracle

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
