# crypto_scythe/bundledassets

> 标签: assets, bundler, helper, laminas, mezzio, mvc

## 简介

A Laminas view helper for adding JavaScript and CSS assets created by bundlers

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
