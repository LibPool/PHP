# motomedialab/laravel-redis-driver

> 标签: PHP

## 简介

A Laravel Redis driver override that enforces clearing of cache using prefixes, rather than a flush

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
