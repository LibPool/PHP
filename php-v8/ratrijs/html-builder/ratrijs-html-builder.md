# ratrijs/html-builder

> 标签: OOP, Simple, builder, generator, html

## 简介

Small and easy-to-use class for HTML generation using object-oriented approach.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
