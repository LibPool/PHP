# siteation/magento2-icons-payment

> 标签: magento2, magento2-module, paymenticons, svg

## 简介

Payment-method icons for Magento 2. The SVG library plus view models that render an <img> anywhere, and inline SVG through Hyvä where it is installed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
