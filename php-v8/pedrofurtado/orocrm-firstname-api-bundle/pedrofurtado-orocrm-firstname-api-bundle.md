# pedrofurtado/orocrm-firstname-api-bundle

> 标签: ORO, OroCrm, OroPlatform

## 简介

Define Oro Contact 'firstName' field as filter and sorter in OroCRM JSON API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
