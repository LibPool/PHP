# ixnode/php-cli-image

> 标签: ascii, cli, gif, image, jpeg, jpg, php, png

## 简介

PHP Cli Image - This library converts a given image to ASCII string.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
