# urbanmonastics/sourcetextlibrary

> 标签: bible, liturgy, markdown, parser, scripture

## 简介

A simple way to load, read, and present texts from various source text libraries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
