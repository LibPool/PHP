# aineko-m/ivee-core

> 标签: CREST, EVE API, EVE Online, ivee, iveeCore

## 简介

PHP engine for calculations of EVE Online industrial activities and CREST library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
