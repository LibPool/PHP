# pkgmcp/adb-php

> 标签: adb, adbkit, android, apk, debug, install, logcat, shell

## 简介

Pure PHP 8.3 ADB client — full port of @devicefarmer/adbkit v3.3.8

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
