# danielmabadeje/php-solidity

> 标签: blockchain, ethereum, smart-contracts, solidity, transpiler, web3

## 简介

Write Ethereum smart contracts in PHP — a PHP-to-Solidity transpiler

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
