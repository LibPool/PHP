# vietiso/oneguide

> 标签: PHP

## 简介

SDK PHP tích hợp với hệ thống OneGuide: đồng bộ tour điều hành, mời hướng dẫn viên, truy vấn danh mục.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
