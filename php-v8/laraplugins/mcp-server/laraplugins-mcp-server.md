# laraplugins/mcp-server

> 标签: laravel, mcp, plugins

## 简介

LaraPlugins.io MCP Server - Connect to Laravel plugin directory MCP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
