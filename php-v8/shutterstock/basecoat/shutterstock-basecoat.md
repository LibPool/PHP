# shutterstock/basecoat

> 标签: framework, hierchical, router, traversal

## 简介

Basecoat Framework, a PHP base framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/shutterstock/basecoat
- 源码仓库：https://github.com/shutterstock/basecoat.git
- Packagist 页面：https://packagist.org/packages/shutterstock%2Fbasecoat

## 获取地址

- Composer 安装：`composer require shutterstock/basecoat`
- Packagist 仓库：https://repo.packagist.org/p2/shutterstock/basecoat.json
- PHP 要求：>=5.3.0
