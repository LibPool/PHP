# per-seo/psr-jwt

> 标签: Authentication, authorisation, json, json web tokens, jwt, php, psr-7, tokens

## 简介

A PSR 7 compliant JSON Web Token Middleware Library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
