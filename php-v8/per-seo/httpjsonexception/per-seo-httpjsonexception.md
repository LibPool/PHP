# per-seo/httpjsonexception

> 标签: 404, httpException, not found, slim, slim4

## 简介

HTTP Exception for Slim 4. This Middleware print a JSON when a 404 Not Found occours

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
