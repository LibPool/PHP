# nexofast/nexofast

> 标签: api, framework, jsonfdb, microframework, php, rest, router

## 简介

NexoFast is a lightweight and fast PHP micro-framework for building REST APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
