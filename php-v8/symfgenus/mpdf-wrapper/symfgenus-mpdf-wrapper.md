# symfgenus/mpdf-wrapper

> 标签: Symfony2, bundle, mpdf, symfony3, wrapper

## 简介

This bundle allows to use mpdf library with symfony3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
