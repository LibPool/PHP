# webtigers/tiger-core

> 标签: ZF1, multi-tenant, saas, tiger, tigerzf

## 简介

Tiger platform Core — kernel + multi-tenant substrate (org/user/org_user/ACL) on TigerZF

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
