# webtigers/tld-rules

> 标签: domains, icann, nexus, opensrs, registrar, registration, tld, tld_data, whois-privacy

## 简介

Zero-dependency catalog + query API of per-TLD domain-registration rules: required registrant extended attributes (OpenSRS tld_data), WHOIS-privacy availability, and registration-period bounds. Language-neutral JSON data included.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
