# gsixlabs/module-generator

> 标签: GSix, gsixlabs, laravel, module generator, module-generator

## 简介

Generates a new Module and it's structure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
