# messagebird/sdk

> 标签: api, bird, email, realtime, sdk, sms, verify, webhooks, whatsapp

## 简介

The official PHP SDK for the Bird API: email, SMS, WhatsApp, verification, and Realtime on one typed client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
