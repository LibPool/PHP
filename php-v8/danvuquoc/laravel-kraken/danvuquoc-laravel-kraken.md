# danvuquoc/laravel-kraken

> 标签: kraken, laravel

## 简介

A minimal service provider to set up and use the Kraken API PHP library in Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
