# scitu/oauth2-tu

> 标签: Authentication, TU, Thammasart University, api, authorization, client, oauth, oauth2, php

## 简介

TU OAuth 2.0 support for the PHP League's OAuth 2.0 Client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
