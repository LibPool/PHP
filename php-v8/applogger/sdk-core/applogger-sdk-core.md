# applogger/sdk-core

> 标签: error-tracking, framework-agnostic, logging, monitoring, psr-18

## 简介

Framework-agnostic PHP error-tracking SDK core for AppLogger (applogger.eu)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
