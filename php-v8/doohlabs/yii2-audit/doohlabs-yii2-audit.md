# doohlabs/yii2-audit

> 标签: Audit, logging, trail, yii2

## 简介

Yii2 Audit records and displays web/cli requests, database changes, php/js errors and associated data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
