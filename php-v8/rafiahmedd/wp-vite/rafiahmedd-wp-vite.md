# rafiahmedd/wp-vite

> 标签: Hmr, asset, css, javascript, plugin, react, theme, vite, wordpress

## 简介

Vite integration for WordPress plugin and theme development — handles JS modules, CSS, React HMR, dev/prod modes, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
