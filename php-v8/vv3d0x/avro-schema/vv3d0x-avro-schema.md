# vv3d0x/avro-schema

> 标签: PHP

## 简介

vv3d0x/avro-schema is a library for handling serialization and deserialization of Avro values and schemas, including RPC.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
