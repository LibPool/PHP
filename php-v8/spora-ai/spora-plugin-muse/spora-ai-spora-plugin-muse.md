# spora-ai/spora-plugin-muse

> 标签: image-generation, meta, muse, speech-to-text, spora, spora-plugin

## 简介

Meta Muse vendor home for Spora agents — speech-to-text (Muse Voice Transcribe) + image generation (Muse Image) today; future Muse Spark text, Muse Glimmer TTS, etc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
