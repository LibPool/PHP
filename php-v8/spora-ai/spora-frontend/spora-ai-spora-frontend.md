# spora-ai/spora-frontend

> 标签: PHP

## 简介

Spora admin UI — prebuilt assets delivered as a Composer package. Consumed by spora-ai/spora-skeleton via spora-ai/installer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
