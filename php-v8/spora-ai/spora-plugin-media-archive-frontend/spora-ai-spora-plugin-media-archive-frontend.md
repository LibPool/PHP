# spora-ai/spora-plugin-media-archive-frontend

> 标签: PHP

## 简介

Pre-built Vue SPA for browsing, filtering, and downloading Spora media-archive rows. Delivered as type `spora-plugin-frontend`; the host SPA lazy-loads it via /plugins/<parent-slug>/main.js (the parent plugin's `plugin.json#slug`, not this package's name).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
