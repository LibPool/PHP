# spora-ai/spora-plugin-team-graph-frontend

> 标签: PHP

## 简介

Pre-built Vue SPA for the Spora team-graph admin view. Renders a per-principal Mermaid graph of agent spawning relationships. Delivered as type `spora-plugin-frontend`; the host SPA lazy-loads it via /plugins/team-graph/main.js (the parent plugin's `plugin.json#slug`, not this package's name).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
