# spora-ai/spora-plugin-custom-skills-frontend

> 标签: PHP

## 简介

Pre-built Vue SPA for the Spora custom-skills admin panel. Delivered as type `spora-plugin-frontend`; the host SPA lazy-loads it via /plugins/custom-skills/main.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
