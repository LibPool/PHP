# vwlabs/vwdashboard-module

> 标签: asgardcms, dashboard

## 简介

Dashboard module for AsgardCMS. Handles the display of the dashboard.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
