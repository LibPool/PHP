# batatahub-tech/laravel-rabbitmq

> 标签: PHP

## 简介

Full RabbitMQ package for Laravel: manage exchanges, queues, bindings, publish and consume messages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
