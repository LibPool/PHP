# wazza/sync-model-to-crm

> 标签: crm, hubspot, laravel, package, sync

## 简介

Helper package to simplify Laravel Model data sync to CRM's. Currently only supported CRM - HubSpot.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
