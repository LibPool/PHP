# aristide/interact-sms

> 标签: aristide, interact-sms, laravel, phonovation, sms

## 简介

Client Laravel pour l'API Interact SMS (Phonovation) : campagnes SMS, sender IDs et webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
