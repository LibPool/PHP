# aristide/nimbasms

> 标签: aristide, laravel, nimbasms, otp, sms, whatsapp

## 简介

Client Laravel pour l'API Nimba SMS (SMS, WhatsApp, OTP et ressources associées).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
