# mima/dom-navigator

> 标签: PHP

## 简介

Simple wrapper for find elements in DOMNode. Adds XPath, Selector (like jQuery) mechanism to find elements, allow create own implementation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
