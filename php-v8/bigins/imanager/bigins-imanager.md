# bigins/imanager

> 标签: cmf, cms, framework, fts5, php, psr-14, repository-pattern, sqlite

## 简介

iManager — embeddable SQLite-backed CMF (Content Management Framework) for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
