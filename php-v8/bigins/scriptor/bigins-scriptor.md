# bigins/scriptor

> 标签: blog, cmf, cms, markdown, microsite, php, scriptor, sqlite, wiki

## 简介

Lightweight PHP CMS for microsites, blogs and wikis — SQLite + FTS5 search, Markdown, rich-text editing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
