# aquidify/sdk

> 标签: api, aquidify, intent, laravel, nlp, sdk, structured output

## 简介

PHP client for the Aquidify API, with a Laravel adapter: turn what people type into validated, structured intent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
