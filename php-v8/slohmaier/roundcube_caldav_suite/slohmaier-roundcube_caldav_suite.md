# slohmaier/roundcube_caldav_suite

> 标签: Baikal, CalDAV, Tasks, calendar, nextcloud, radicale, roundcube

## 简介

CalDAV Calendar & Tasks plugin for Roundcube - connects to any CalDAV server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
