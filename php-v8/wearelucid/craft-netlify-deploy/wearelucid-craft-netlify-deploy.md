# wearelucid/craft-netlify-deploy

> 标签: Craft, cms, craft-netlify-deploy, craft-plugin, craftcms

## 简介

A plugin to display a button to trigger a netlify deploy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
