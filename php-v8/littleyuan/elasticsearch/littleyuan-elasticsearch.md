# littleyuan/elasticsearch

> 标签: client, elasticsearch, search

## 简介

PHP Client for Elasticsearch 7.17.2 Compatible with Alibaba Cloud

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
