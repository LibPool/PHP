# 24hoursmedia/php-env-inject

> 标签: PHP

## 简介

Inject and interpolate environment variables into strings. Supports substituting default values of env variables, and escapers/formatters using callbacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
