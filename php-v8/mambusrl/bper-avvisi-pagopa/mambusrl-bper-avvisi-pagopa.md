# mambusrl/bper-avvisi-pagopa

> 标签: avviso, bper, iuv, pagopa, rt, soap

## 简介

Client PHP per il WS IUVOnline 1.4 di BPER Banca / BPS: generazione, variazione, annullo e recupero avvisi PagoPA, gestione ricevute telematiche (RT).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
