# silentgecko/sepa

> 标签: Banking, PHP7, SCT, php, sepa, xml

## 简介

Creates an XML file for a Single Euro Payments Area (SEPA) Credit Transfer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
