# devcharles/fortify-sanctum

> 标签: auth, fortify, fortify-sanctum, laravel, sanctum

## 简介

A zero config laravel package to use fortify flavours in sanctum.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
