# mkapoor/allure-codeception-custom

> 标签: PHP

## 简介

A fork of the Codeception adapater for Allure report which works with huge no of test cases including BDD.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
