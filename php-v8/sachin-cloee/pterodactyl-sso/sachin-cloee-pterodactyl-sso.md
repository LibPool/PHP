# sachin-cloee/pterodactyl-sso

> 标签: SSO, billing, laravel, paymenter, php, pterodactyl, pterodactyl-extension, single-sign-on

## 简介

Pterodactyl 2.x panel extension that signs customers in from a Paymenter billing installation using signed, single-use login links.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
