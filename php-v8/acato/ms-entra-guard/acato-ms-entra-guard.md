# acato/ms-entra-guard

> 标签: Authentication, azure-ad, entra, guard, jwt, laravel, microsoft

## 简介

Laravel authentication guard for Microsoft Entra ID (Azure AD) JWT bearer tokens

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
