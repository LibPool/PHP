# aleskapot/xlsx-fast-appender

> 标签: append, excel, low-memory, spreadsheet, streaming, xlsx

## 简介

Fast, low-memory appending of rows into an existing XLSX sheet (ZipArchive + streaming XMLWriter).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
