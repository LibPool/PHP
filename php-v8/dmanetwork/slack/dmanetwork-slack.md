# dmanetwork/slack

> 标签: php, slack

## 简介

An interface for interacting with Slack (slack.com). Their entire API is not yet implemented here, so far just sending messages to channels.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
