# dkkoma/php-grpc-lite

> 标签: gRPC, http2, php-extension, pie

## 简介

Source-built grpc extension for PHP: php-grpc-lite HTTP/2 transport drop-in candidate for ext-grpc

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
