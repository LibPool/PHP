# ferdiunal/laravel-ai-router

> 标签: ai, laravel, laravel-ai, laravel-ai-router

## 简介

Laravel AI SDK Laravel AI Router text provider with local key/model routing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
