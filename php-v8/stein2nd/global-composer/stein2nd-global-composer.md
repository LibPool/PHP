# stein2nd/global-composer

> 标签: ccu, clui, composer, composer-check-updates, global, packages, setup

## 简介

Manage globally installed Composer packages via composer.json with ccu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
