# jacerider/neo_migrate

> 标签: PHP

## 简介

Moves a legacy site (paragraphs, micon, escort, real_favicon, aeon) onto the Neo suite.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
