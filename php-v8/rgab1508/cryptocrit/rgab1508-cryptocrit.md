# rgab1508/cryptocrit

> 标签: cryptocurrency

## 简介

CryptoCRIT is an open-source Cryptocurrency project for making automated payments, The associated Cryptocurrency is called CritCoin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
