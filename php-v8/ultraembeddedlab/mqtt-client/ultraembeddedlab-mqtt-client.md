# ultraembeddedlab/mqtt-client

> 标签: aws-iot, azure-iot, broker, emqx, hivemq, home-assistant, iot, message-broker, mosquitto, mqtt, mqtt-3.1.1, mqtt-5, mqtt-client, mqtt3, mqtt5, mtls, pub-sub, publish-subscribe, qos, smart-home, telemetry, websocket

## 简介

MQTT 3.1.1 and MQTT 5.0 client for PHP 8.4+ — QoS 0/1/2, TLS and mutual TLS, WebSocket transport, auto-reconnect, persistent sessions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
