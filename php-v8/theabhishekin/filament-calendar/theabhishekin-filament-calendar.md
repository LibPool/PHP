# theabhishekin/filament-calendar

> 标签: alpine, calendar, filament, livewire, widget

## 简介

A calendar widget for Filament admin panels, powered by Livewire and Alpine.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
