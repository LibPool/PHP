# vojtech-dobes/nette-ajax-history

> 标签: ajax, nette, nette.ajax.js

## 简介

Adds History API support for Nette Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
