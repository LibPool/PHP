# vojtech-dobes/nette-goto-panel

> 标签: debugging, nette, panel

## 简介

Provides interface to go to any destination within Nette Framework application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
