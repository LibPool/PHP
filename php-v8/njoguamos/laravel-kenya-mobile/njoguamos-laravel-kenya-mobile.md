# njoguamos/laravel-kenya-mobile

> 标签: Kenya Mobile, Njogu Amos, airtel, laravel, safaricom, telekom

## 简介

A rule for validating Kenya mobile number in a Laravel 11+ application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
