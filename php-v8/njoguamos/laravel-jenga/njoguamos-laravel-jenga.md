# njoguamos/laravel-jenga

> 标签: Jenga API, Jenga V3 API, Njogu Amos, equity bank, laravel, payment gateway

## 简介

A Laravel package for setting up and interacting with Jenga V3 API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
