# beastbytes/yii2-csswidgets

> 标签: accordion, css, modal, tabs, ui, widget, yii2

## 简介

Yii2 Extension that provides UI widgets implemented in CSS only

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
