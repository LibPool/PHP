# safemood/laravel-magic-scopes

> 标签: Khalil Bouzidi, laravel, laravel-magic-scopes

## 简介

A Laravel package that automatically generates dynamic query scopes from field names and types

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
