# rvdlee/zf-image-resizer

> 标签: ImageMagick, Zend Framework 3, image resizer, zf3

## 简介

A package that allows you resize images with programs like ImageMagick.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
