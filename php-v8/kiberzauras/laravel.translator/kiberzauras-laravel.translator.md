# kiberzauras/laravel.translator

> 标签: eloquent, kiberzauras, laravel, multilanguage, translations

## 简介

Translatable Eloquent's for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
