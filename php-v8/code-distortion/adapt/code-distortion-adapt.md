# code-distortion/adapt

> 标签: DatabaseMigrations, DatabaseTransactions, RefreshDatabase, browser-tests, database, dusk, feature-tests, integration-tests, laravel, migrations, parallel, paratest, pest, phpunit, seeders, testing, tests, transactions, unit-tests

## 简介

A Laravel package that builds databases for your tests, improving their speed.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
