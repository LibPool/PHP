# electrolinux/yaskef

> 标签: framework, tool

## 简介

A PHP,SQL,Javascript live interpreter based on the Silex-Kitchen-Edition.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
