# twentyfourhoursmedia/comments-work

> 标签: Craft, cms, comments, comments work, craft-plugin, craftcms

## 简介

An easy to use comment plugin for Craft CMS 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
