# sonarsoftware/freeradius_genie

> 标签: freeradius, sonar, sonar freeradius, sonar software

## 简介

A simple installer and configuration tool for FreeRADIUS, specifically to use it with Sonar.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
