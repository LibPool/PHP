# stubbedev/laravel-dev-mcp

> 标签: debugging, developer-tools, laravel, mcp, telescope

## 简介

MCP server for local Laravel development (Go, distributed as a prebuilt binary)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
