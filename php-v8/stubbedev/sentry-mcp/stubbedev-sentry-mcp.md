# stubbedev/sentry-mcp

> 标签: ai, llm, mcp, model-context-protocol, sentry

## 简介

MCP server for self-hosted Sentry (Go, distributed as a prebuilt binary)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
