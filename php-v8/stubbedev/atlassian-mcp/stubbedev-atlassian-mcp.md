# stubbedev/atlassian-mcp

> 标签: atlassian, bitbucket, jira, mcp, model-context-protocol

## 简介

MCP server for self-hosted Jira and Bitbucket (Go, distributed as a prebuilt binary)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
