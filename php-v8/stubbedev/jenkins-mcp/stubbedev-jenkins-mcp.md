# stubbedev/jenkins-mcp

> 标签: ci, jenkins, mcp, model-context-protocol

## 简介

MCP server for Jenkins build status and logs (Go, distributed as a prebuilt binary)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
