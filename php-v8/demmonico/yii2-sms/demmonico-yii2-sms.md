# demmonico/yii2-sms

> 标签: component, extension, nexmo, send, sms, yii, yii2

## 简介

Yii2 extension which allow send sms using multiply providers. Now available Nexmo provider

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
