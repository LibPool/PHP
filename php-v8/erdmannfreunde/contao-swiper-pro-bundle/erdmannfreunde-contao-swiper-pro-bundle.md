# erdmannfreunde/contao-swiper-pro-bundle

> 标签: contao, content-element, slider, swiper

## 简介

A Contao CMS extension for creating Swiper sliders with custom YAML configurations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
