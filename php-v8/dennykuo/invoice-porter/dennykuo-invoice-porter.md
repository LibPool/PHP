# dennykuo/invoice-porter

> 标签: E-Invoice, Taiwan, einvoice, ezpay, invoice, newebpay, taiwan-einvoice, track, 字軌, 藍新, 電子發票

## 简介

台灣電子發票串接 PHP SDK，目前支援藍新（NewebPay/EZPay）發票與字軌管理

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
