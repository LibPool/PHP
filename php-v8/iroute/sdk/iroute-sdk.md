# iroute/sdk

> 标签: ai, llm, router, sdk, task-aware

## 简介

Thin PHP client for the iRoute runtime

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://iroute.dev/docs/sdk/php
- 源码仓库：https://github.com/lazineziri/iroute-php.git
- Packagist 页面：https://packagist.org/packages/iroute%2Fsdk

## 历史版本号

- 当前版本：0.1.0-alpha.3

## 获取地址

- Composer 安装：`composer require iroute/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/iroute/sdk.json
- 许可证：Apache-2.0
- PHP 要求：>=8.3
