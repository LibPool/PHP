# presseddigital/colorit

> 标签: Craft, cms, color, colors, colour, colours, craft-plugin, craftcms, palette, swatch

## 简介

A slick color picker fieldtype plugin for the Craft CMS 5 control panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
