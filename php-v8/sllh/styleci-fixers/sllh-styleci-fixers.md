# sllh/styleci-fixers

> 标签: StyleCI, configuration, php-cs-fixer

## 简介

Auto configure PHP-CS-Fixer from StyleCI config file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
