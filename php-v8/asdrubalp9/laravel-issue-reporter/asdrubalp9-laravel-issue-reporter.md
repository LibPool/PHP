# asdrubalp9/laravel-issue-reporter

> 标签: errors, gitlab, issues, laravel, monitoring

## 简介

Capture Laravel errors and report them as GitLab issues, with deduplication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
