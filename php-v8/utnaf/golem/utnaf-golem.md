# utnaf/golem

> 标签: apache, boilerplate, bootstrap, docker, mysql, php

## 简介

Despite the cool name, it's just a docker bootstrap with PHP, Apache and MariaDb.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
