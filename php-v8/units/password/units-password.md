# units/password

> 标签: Argon2id, argon2, bcrypt, credentials, dna, password, password_hash, provenance, unit

## 简介

Password-hashing unit - Argon2id, Argon2i and bcrypt via PHP's password_* functions, on the patterns/unit contract.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
