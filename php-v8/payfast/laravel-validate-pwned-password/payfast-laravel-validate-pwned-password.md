# payfast/laravel-validate-pwned-password

> 标签: PHP

## 简介

Adds Laravel validator rule to check if a password has been pwned from https://haveibeenpwned.com/API/v2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
