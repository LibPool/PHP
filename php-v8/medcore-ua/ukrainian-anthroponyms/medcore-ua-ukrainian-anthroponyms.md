# medcore-ua/ukrainian-anthroponyms

> 标签: PHP

## 简介

A PHP library for declension of Ukrainian anthroponyms in all 7 grammatical cases, with automatic gender detection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
