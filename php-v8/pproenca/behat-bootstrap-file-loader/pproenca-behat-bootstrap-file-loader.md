# pproenca/behat-bootstrap-file-loader

> 标签: BDD, Behat, bootstrap, file

## 简介

Introduces a new configuration option to include a custom bootstrap file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
