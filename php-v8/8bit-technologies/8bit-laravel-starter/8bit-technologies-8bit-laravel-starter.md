# 8bit-technologies/8bit-laravel-starter

> 标签: boilerplate, laravel, starter-kit

## 简介

An opinionated Laravel starter kit with authentication, member and admin panels, roles and permissions, user management, and a clean foundation for building modern applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
