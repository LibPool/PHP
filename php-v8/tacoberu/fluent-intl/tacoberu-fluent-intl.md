# tacoberu/fluent-intl

> 标签: format, formatting, ftl, gender, i18n, internationalization, l10n, language, locale, localization, parser, plural, translate, translation

## 简介

PHP implementation of Project Fluent. Localization library for expressive translations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
