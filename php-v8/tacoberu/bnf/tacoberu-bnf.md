# tacoberu/bnf

> 标签: abnf, ast, bnf, ebnf, lexer, parser, tokenizer

## 简介

Framework for building BNF like parsers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
