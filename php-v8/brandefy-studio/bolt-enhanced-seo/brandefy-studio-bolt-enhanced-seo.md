# brandefy-studio/bolt-enhanced-seo

> 标签: PHP

## 简介

Enhanced SEO extension for Bolt 5 and 6 with real-time analysis, meta tags, and Google preview

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
