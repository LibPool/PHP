# motivast/wp-cli-seed-command

> 标签: PHP

## 简介

WP CLI Seed Command is an extension for WP-CLI to seed database with sample data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
