# werk365/laraveloauthclient

> 标签: LaravelOAuthClient, laravel, oauth, oauthClient

## 简介

Multi purpose OAuth client to use in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
