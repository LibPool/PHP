# jw_301/jw_watermark

> 标签: TYPO3 CMS, viewhelper, watermark

## 简介

Watermark Extension for TYPO3, adding a ViewHelper that creates watermarks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
