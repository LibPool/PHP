# kpay/laravel-kpay

> 标签: k-pay, kpay, laravel, mastercard, momo, payments, visa

## 简介

Laravel 12 package for integrating with the K-Pay payment gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
