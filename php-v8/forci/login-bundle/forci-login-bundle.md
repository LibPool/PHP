# forci/login-bundle

> 标签: forci, hwi oauth token login integration, login bundle, login manager, oauth login bundle, wucdbm

## 简介

A Symfony ~3.0 Bundle that eases logging users to your Symfony application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
