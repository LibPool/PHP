# forci/pdf-generator-bundle

> 标签: html to pdf, pdf bundle, symfony html pdf, symfony pdf generator, wucdbm

## 简介

A WKHTMLTOPDF based PDF Generator

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
