# siktec/composer-starter-pack

> 标签: actions, composer, package, phpcs, phpunit, starter

## 简介

This is a starter pack for a composer package with (phpunit, phpcs, actions ....)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
