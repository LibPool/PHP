# coffeephp/component-registry

> 标签: coffee, coffeephp, component, dependency, di, injection, php, register, registrar, registry

## 简介

Provides an interface for registering components in the DI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
