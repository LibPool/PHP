# coffeephp/uncompress

> 标签: coffee, coffeephp, decompress, decompression, php, uncompress, uncompression

## 简介

Provides an interface for uncompressor classes to implement.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
