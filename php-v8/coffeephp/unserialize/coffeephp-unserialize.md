# coffeephp/unserialize

> 标签: coffee, coffeephp, deserialization, deserialize, php, unserialization, unserialize

## 简介

Provides an interface for unserializer classes to implement.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
