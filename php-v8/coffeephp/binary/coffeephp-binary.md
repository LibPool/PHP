# coffeephp/binary

> 标签: binary, coffee, coffeephp, deserialization, deserialize, php, php-serialized, serialization, serialize, serialized, translator, unserialization, unserialize

## 简介

Provides classes for handling PHP-Serialized (Binary) data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
