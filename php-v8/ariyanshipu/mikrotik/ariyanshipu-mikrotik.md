# ariyanshipu/mikrotik

> 标签: api, laravel, mikrotik, networking, routeros, ssh

## 简介

A Laravel package to manage MikroTik RouterOS devices via API (TCP/SSL) and SSH with Laravel-friendly integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
