# ariyanshipu/php-ip-calculator

> 标签: IP, calculator, ipv4, ipv6, php, subnet

## 简介

IP calculator written in PHP, IPv4 & IPv6 are supported, mainly functions for subnet allocation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
