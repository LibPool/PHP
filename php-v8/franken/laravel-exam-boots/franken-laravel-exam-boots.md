# franken/laravel-exam-boots

> 标签: framework, laravel

## 简介

Laravel CLI generator for certification exams — one-shot CRUD, Auth (JWT/Sanctum), Relations, Enums, Tests, Export, Rollback, and Dry-run mode

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
