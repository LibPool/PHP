# goetas/xsd2php

> 标签: converter, jms, php, serializer, xml, xsd

## 简介

Convert XSD  (XML Schema) definitions into PHP classes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
