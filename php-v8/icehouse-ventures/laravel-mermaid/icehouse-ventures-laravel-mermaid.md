# icehouse-ventures/laravel-mermaid

> 标签: diagram, flowchart, icehouseventures, laravel, mermaid

## 简介

Simple package to generate diagrams in Laravel using the Mermaid.js library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
