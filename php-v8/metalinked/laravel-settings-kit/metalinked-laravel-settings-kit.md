# metalinked/laravel-settings-kit

> 标签: Settings, configuration, feature-flags, laravel, preferences, typed-settings, user-settings

## 简介

Typed settings for Laravel, defined in code: global values with per-user (or per-model) overrides, one query per request, translated labels and ready-made settings panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
