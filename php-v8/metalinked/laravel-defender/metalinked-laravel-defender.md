# metalinked/laravel-defender

> 标签: Honeypot, abuseipdb, alerts, bot-protection, brute-force, country-blocking, defender, firewall, geoip, ip-logging, ip-reputation, laravel, login-protection, middleware, security

## 简介

One-line security middleware for Laravel: attack and scanner detection, failed-login protection, auto-blocking IP blocklist, monitor mode, AbuseIPDB reputation, country access control, honeypot spam protection, throttled multi-channel alerts, a Laravel Pulse card and a security audit command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
