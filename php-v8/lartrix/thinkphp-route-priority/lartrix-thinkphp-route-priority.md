# lartrix/thinkphp-route-priority

> 标签: PHP

## 简介

A ThinkPHP 8 route priority patch that prevents generic and prefix routes from shadowing exact static routes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
