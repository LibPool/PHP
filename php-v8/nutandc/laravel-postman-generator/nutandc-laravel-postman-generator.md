# nutandc/laravel-postman-generator

> 标签: Postman, api, documentation, generator, laravel, openapi

## 简介

Laravel Postman Documentation Generator with Postman v2.1 and OpenAPI outputs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
