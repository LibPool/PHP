# adriel/laravel-tinymce-simple-imageupload

> 标签: Image upload, laravel, laravel 5, php, tinymce

## 简介

Simple image upload for TinyMCE in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
