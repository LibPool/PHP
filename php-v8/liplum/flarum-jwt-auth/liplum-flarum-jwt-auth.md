# liplum/flarum-jwt-auth

> 标签: flarum, flarum-ext, flarum-extension, jwt

## 简介

Authentication based on JSON Web Token (JWT) token through HTTP request cookie.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
