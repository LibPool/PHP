# liplum/flarum-sync-profile

> 标签: flarum, flarum-ext, flarum-extension

## 简介

The user profile synchronization when authenticated by an external identity provider.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
