# waix/waix-php

> 标签: Kazakhstan, otp, waix, whatsapp

## 简介

WAIX WhatsApp API v1: messages, templates, OTP and signed webhooks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
