# mlucas/invoiceiq-bundle

> 标签: PHP

## 简介

Analyse et validation de factures pour Symfony (OCR, règles, VIES plus tard, LLM optionnel).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
