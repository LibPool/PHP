# aleksa/laravel-visitors-statistics

> 标签: PHP

## 简介

Simple visitor tracker and statistics package for Laravel 5 that can be used for dashboard graphs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
