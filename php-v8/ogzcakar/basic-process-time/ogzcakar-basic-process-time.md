# ogzcakar/basic-process-time

> 标签: Basic Process Time, Process Time

## 简介

The BasicProcessTime class allows you to see how long the processes you write work.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
