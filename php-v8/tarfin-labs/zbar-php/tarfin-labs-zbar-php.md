# tarfin-labs/zbar-php

> 标签: bar-code, qr-code, tarfin-labs, zbar-php

## 简介

zbar-php is a php package that provides an interface to the zbar bar-code reading library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
