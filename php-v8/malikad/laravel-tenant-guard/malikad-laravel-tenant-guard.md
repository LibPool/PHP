# malikad/laravel-tenant-guard

> 标签: PHPStan, ast, filament, laravel, security, static-analysis, tenancy

## 简介

AST static analysis guard for Laravel multi-tenant SaaS applications preventing cross-tenant data leaks, cache collisions, and unscoped queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
