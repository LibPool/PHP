# step2dev/lazy-ui

> 标签: component, components, daisy ui, design-system, framework, laravel, lazy component ui, lazy form, lazy ui, tailwind, tailwindcss, ui-library

## 简介

Lazy UI is a Laravel package that provides a set of Blade components to rapidly build forms with Tailwind CSS and Daisy UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
