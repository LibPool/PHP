# dandrea/audit

> 标签: PHP

## 简介

Package for adding basic audit capabilities to Laravel 5.5+ . It supports multiauth by providing polymorphical relations with user/auditor.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
