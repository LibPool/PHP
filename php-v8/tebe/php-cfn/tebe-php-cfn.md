# tebe/php-cfn

> 标签: PHP

## 简介

Userland implementation of PHP RFC: Consistent Function Names

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://wiki.php.net/rfc/consistent_function_names
- 源码仓库：https://github.com/tbreuss/php-cfn.git
- Packagist 页面：https://packagist.org/packages/tebe%2Fphp-cfn

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

- Composer 安装：`composer require tebe/php-cfn`
