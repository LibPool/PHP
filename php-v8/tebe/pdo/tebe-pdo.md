# tebe/pdo

> 标签: mysql, pdo, pdo-wrapper, pgsql, postgres, postgresql, sql server, sqlite, sqlserver, sqlsrv

## 简介

Provides an extension to the native PDO along with additional functionality.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
