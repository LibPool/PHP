# tebe/http-factory

> 标签: PSR-11, http, middleware, psr-15, psr-17, psr-7

## 简介

HTTP Factory provides automatic detection for Composer packages implementing the PSR-17 standard

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
