# uzbek/laravel-sms

> 标签: Uzbekistan, eskiz, laravel, playmobile, sayqal, sms, textup

## 简介

Unified SMS sending for Uzbek providers — Eskiz, PlayMobile, TextUp and Sayqal behind a single driver contract.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
