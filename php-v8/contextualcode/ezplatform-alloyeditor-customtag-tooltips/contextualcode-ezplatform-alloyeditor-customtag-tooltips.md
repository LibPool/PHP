# contextualcode/ezplatform-alloyeditor-customtag-tooltips

> 标签: alloy-editor, ezplatform, ezplatform-content, ezplatform-online-editor

## 简介

eZ Platform bundle which provides UI tooltips to custom tag icons in Online Editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
