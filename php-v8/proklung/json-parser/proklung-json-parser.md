# proklung/json-parser

> 标签: json, json-parser, lexer, memory, parser

## 简介

Zero-dependencies pull parser to read large JSON from any source in a memory-efficient way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
