# diegopires/boleto

> 标签: boleto, modulo, php

## 简介

Módulo para emissão de Boletos Bancários - Derivado do BoletoPHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
