# jambostack/jambo-api

> 标签: api, cms, graphql, headless, jambostack, rest, symfony

## 简介

Jambo API — Headless CMS open-source. Backend API REST + GraphQL pour le JamboStack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
