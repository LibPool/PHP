# rohitshakya/laravel-beacon

> 标签: admin-panel, blade, dashboard, inbox, laravel, laravel-echo, laravel-package, livewire, notification-ui, notifications, realtime, saas, tailwindcss, topbar, websocket

## 简介

Realtime notification UI for Laravel with topbar dropdown, inbox, and Livewire + Echo support. Fully customizable and production ready.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
