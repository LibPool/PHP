# jishan-shk/laravel-databricks

> 标签: databricks, laravel, odbc, spark, sql

## 简介

Databricks SQL client for Laravel over ODBC (Simba Spark / Databricks ODBC driver).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
