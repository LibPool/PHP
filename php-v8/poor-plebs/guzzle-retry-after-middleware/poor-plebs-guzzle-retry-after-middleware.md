# poor-plebs/guzzle-retry-after-middleware

> 标签: PHP

## 简介

A guzzle middleware to keep track of the Retry-After HTTP header and fail consecutive requests until this time has passed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
