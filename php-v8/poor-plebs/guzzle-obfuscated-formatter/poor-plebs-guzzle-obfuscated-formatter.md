# poor-plebs/guzzle-obfuscated-formatter

> 标签: PHP

## 简介

Guzzle HTTP message formatter with configurable obfuscation for safe logging of sensitive data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
