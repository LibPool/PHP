# zlik/magento-resque

> 标签: PHP

## 简介

Magento Upgrade Resque allows to organize a queue of SQL queries and use multiple workers to execute them in parallel during Magento upgrade.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
