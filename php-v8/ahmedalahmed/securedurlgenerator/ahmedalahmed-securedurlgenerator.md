# ahmedalahmed/securedurlgenerator

> 标签: PHP

## 简介

Simple package to protect url from being predectable to be downloaded or accessed by hackers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
