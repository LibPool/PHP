# hostbybelle/compressionbuffer

> 标签: PHP

## 简介

CompressionBuffer provides easy access to zstd, brotli, and gzip output buffering with PHP on any webserver.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
