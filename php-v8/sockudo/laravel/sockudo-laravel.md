# sockudo/laravel

> 标签: Broadcasting, laravel, pusher, realtime, sockudo, websocket

## 简介

Official Laravel broadcasting driver and service-container integration for Sockudo

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
