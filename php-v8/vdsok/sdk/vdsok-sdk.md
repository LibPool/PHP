# vdsok/sdk

> 标签: api, hosting, psr-18, sdk, vds, vdsok, vps

## 简介

Official PHP SDK for the VDSok Client API v1 (servers, domains, balance, invoices, webhooks).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
