# index-now-ru/evocms-index-now-ru

> 标签: evocms, evolution-cms, index-now-ru, indexing, seo

## 简介

Evocms package that submits published document URLs to Index-Now.ru.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
