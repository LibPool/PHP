# entidi/silverstripe-gtkdoc

> 标签: dataobject, gtkdoc, silverstripe

## 简介

A module that imports a gtk-doc manual under a silverstripe page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
