# entidi/silverstrap-module

> 标签: bootstrap, module, silverstrap, silverstripe, theme

## 简介

A helper module for the silverstrap theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
