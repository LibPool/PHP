# p2made/p2y2-themes

> 标签: Start-Bootstrap, asset, bundle, php, theme, ui, user-interface, yii, yii2

## 简介

Themes from Start Bootstrap, http://startbootstrap.com/, as UIs for Yii 2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
