# nassiry/filesize-handler

> 标签: file-size, php-file-zie, php-size-binary, php-size-decimal

## 简介

A PHP package for handling file size with binary, decimal & locale units support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
