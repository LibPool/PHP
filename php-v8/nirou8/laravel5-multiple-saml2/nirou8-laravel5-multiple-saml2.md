# nirou8/laravel5-multiple-saml2

> 标签: SAML2, idp, laravel5, onelogin, saml, sp

## 简介

A Laravel5 package for Saml2 integration as an SP based on OneLogin toolkit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
