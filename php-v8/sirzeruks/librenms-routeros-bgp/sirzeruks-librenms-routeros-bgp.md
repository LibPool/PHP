# sirzeruks/librenms-routeros-bgp

> 标签: bgp, librenms, librenms-plugin, mikrotik, routeros

## 简介

LibreNMS plugin: BGP prefix counts for MikroTik RouterOS v7 (collected over REST, API, API-SSL or SSH), shown in the native LibreNMS BGP prefix graphs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
