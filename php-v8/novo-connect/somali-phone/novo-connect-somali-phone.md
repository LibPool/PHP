# novo-connect/somali-phone

> 标签: evc plus, golis, hormuud, laravel, msisdn, phone, somalia, somaliland, telesom, validation, waafi, zaad

## 简介

Validate, normalize and identify Somali mobile numbers: operator, virtual network and mobile money wallet. Works in plain PHP, with optional Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
