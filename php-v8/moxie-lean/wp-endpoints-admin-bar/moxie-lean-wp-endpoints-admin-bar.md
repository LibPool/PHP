# moxie-lean/wp-endpoints-admin-bar

> 标签: api, wordpress

## 简介

Generic endpoint to expose admin bar configuration via WP-API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
