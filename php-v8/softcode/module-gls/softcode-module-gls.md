# softcode/module-gls

> 标签: denmark, gls, magento2, pakkeshop, parcelshop, shipping

## 简介

GLS Denmark for Magento 2: delivery methods, parcel-shop picker, label creation and tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
