# softcode/module-csp-whitelist

> 标签: content-security-policy, csp, magento2, security, whitelist

## 简介

Manage Magento 2 Content Security Policy whitelist hosts from the admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
