# softcode/module-checkout-override

> 标签: b2b, checkout, cvr, denmark, ean, magento2, one-page-checkout

## 简介

Server-driven one-page checkout for Magento 2 with private, company (CVR) and public-sector (EAN) buyers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
