# flightphp/apm

> 标签: Application performance monitor, Simple, apm, application, application performance, application performance monitoring, flight, lightweight, monitor, monitoring, observability, performance, performance monitoring, php

## 简介

High-Performance Application Performance Monitoring (APM) for Flight PHP for better observability in your applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
