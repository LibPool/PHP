# jigal/migrate-redirects

> 标签: MyRedirects, RealURL, redirects, typo3

## 简介

Upgrade wizard to migrate redirects from RealUrl and MyRedirects to core redirects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
