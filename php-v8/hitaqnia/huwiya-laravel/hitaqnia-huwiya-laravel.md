# hitaqnia/huwiya-laravel

> 标签: Authentication, huwiya, identity, jwt, laravel, oauth

## 简介

A Laravel SDK for integrating with the Huwiya Identity Provider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
