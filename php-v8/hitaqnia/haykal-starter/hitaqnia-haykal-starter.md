# hitaqnia/haykal-starter

> 标签: PHP

## 简介

HiTaqnia Laravel app starter — Haykal pre-wired, Huwiya-backed authentication, ready to grow into any new project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
