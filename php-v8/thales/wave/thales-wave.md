# thales/wave

> 标签: Sénégal, laravel, mobile-money, payments, saloon, wave, wave-business, wave-money, xof

## 简介

A fully-typed PHP SDK for the Wave Business API, built on Saloon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
