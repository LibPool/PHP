# star-insure/omnipay-afterpay

> 标签: after pay, afterpay, gateway, merchant, omnipay, pay, payment

## 简介

AfterPay gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
