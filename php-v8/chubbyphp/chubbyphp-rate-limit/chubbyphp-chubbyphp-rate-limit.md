# chubbyphp/chubbyphp-rate-limit

> 标签: chubbyphp, middleware, psr-15, rate-limit, rate-limiter, symfony-rate-limiter, throttle, too-many-requests

## 简介

A minimal rate limiting middleware for PSR 15, built on symfony/rate-limiter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
