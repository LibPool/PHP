# chubbyphp/chubbyphp-laminas-config

> 标签: PSR-11, chubbyphp, container, laminas, mezzio

## 简介

Chubbyphp container adapter using laminas service manager configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
