# chubbyphp/chubbyphp-api

> 标签: api, chubbyphp, middleware, psr-15, psr-7, slim

## 简介

A set of CRUD middleware and request handlers for building APIs with PSR-15.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
