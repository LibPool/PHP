# phly/bookdown2mkdocs

> 标签: bookdown, documentation, mkdocs

## 简介

Tool for converting bookdown.json to mkdocs.yml for publishing bookdown docs to rtfd.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
