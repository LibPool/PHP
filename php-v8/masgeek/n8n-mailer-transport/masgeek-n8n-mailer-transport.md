# masgeek/n8n-mailer-transport

> 标签: PHP

## 简介

A Symfony Mailer & Laravel transport driver for routing outgoing emails directly to an n8n webhook.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
