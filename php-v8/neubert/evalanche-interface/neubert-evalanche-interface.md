# neubert/evalanche-interface

> 标签: connector, evalanche, interface, sc-networks, scn

## 简介

This interface is a consistent wrapper arround the SOAP API of Evalanche.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
