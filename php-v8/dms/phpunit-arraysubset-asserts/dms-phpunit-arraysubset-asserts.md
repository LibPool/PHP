# dms/phpunit-arraysubset-asserts

> 标签: PHP

## 简介

This package provides ArraySubset and related asserts once deprecated in PHPUnit 8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
