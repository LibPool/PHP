# jolanuk/filament-postcodes

> 标签: filament, filament-plugin, filament-postcodes, filamentphp, jolanUK, laravel

## 简介

A valid UK postcode generator for FilamentPHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
