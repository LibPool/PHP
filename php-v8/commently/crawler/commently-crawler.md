# commently/crawler

> 标签: PHP

## 简介

Polite URL crawler. Transport + politeness only (robots.txt, per-host rate limits, conditional requests). Parsing and consuming content is the caller's job.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
