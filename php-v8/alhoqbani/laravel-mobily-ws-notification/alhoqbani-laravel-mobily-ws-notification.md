# alhoqbani/laravel-mobily-ws-notification

> 标签: PHP

## 简介

Send SMS notifications using mobily.ws with Laravel 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
