# xisfacturacion/finkok

> 标签: PHP

## 简介

Clase auxiliar para el servicio de timbrado del PAC Finkok que se utilizara en el CFDI 3.3 (Factuxis v3)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
