# emma/orm

> 标签: PHP

## 简介

A PHP 8.2+ Attribute Based ORM for Object/Entity/DTO. Largely inspired by Java SpringBoot annotation based ORM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
