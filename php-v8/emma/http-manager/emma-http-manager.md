# emma/http-manager

> 标签: PHP

## 简介

A PHP 8.0+ Attributes Based HTTP Routing. Can be used for all cases, MVC and Middleware -  Class/Method/Function

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
