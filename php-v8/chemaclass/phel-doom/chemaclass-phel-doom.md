# chemaclass/phel-doom

> 标签: doom, functional, game, lisp, phel, raycaster

## 简介

DOOM-lite showcase written in Phel Lang. Terminal raycaster, pure functional state, ANSI render.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
