# chemaclass/phel-cli-gui

> 标签: functional, language, lisp, phel

## 简介

Phel functions to render in the terminal. It uses the Cursor from the Symfony Command module.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
