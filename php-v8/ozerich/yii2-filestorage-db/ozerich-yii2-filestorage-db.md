# ozerich/yii2-filestorage-db

> 标签: attachment, db, extension, file, storage, upload, yii2

## 简介

Extension for file uploading and attaching to the models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
