# webfactor/laravel-backpack-fluentsyntax

> 标签: Webfactor, backpack, fluent, laravel

## 简介

Adds fluent syntax for creating Laravel Backpack Fields and Columns

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
