# langacorp/kemproof

> 标签: attestation, fips-203, kyber, ml-kem, post-quantum

## 简介

Attest that an ML-KEM-768 key exchange really happened, with key confirmation, and record it with an expiry. It does not protect a channel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
