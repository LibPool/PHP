# mizbanha/sms-cloud-client

> 标签: laravel, mizbanha, observability, sms, telemetry

## 简介

Optional, fail-open telemetry client that reports mizbanha/laravel-sms operational metrics to Mizbanha SMS Cloud. Never on the sending path.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
