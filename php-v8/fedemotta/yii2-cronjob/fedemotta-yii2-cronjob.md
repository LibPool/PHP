# fedemotta/yii2-cronjob

> 标签: console, cron, crontab, extension, job, schedule, script, yii2

## 简介

Yii2 extension to help in the creation of automated console scripts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
