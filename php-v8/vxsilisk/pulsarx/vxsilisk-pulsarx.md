# vxsilisk/pulsarx

> 标签: anti-bot, anti-detection, async, browser-impersonation, client, cloudflare, curl, curl-impersonate, curl-multi, http, http-client, impersonate, ja3, ja4, requests, scraping, tls-fingerprint, user-agent, web-scraping 

## 简介

Browser-impersonating HTTP client for PHP — like curl_cffi/requests, but native. 32 TLS fingerprints, Sec-Fetch/Referer stealth, async (curl_multi), session cookies & multipart. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
