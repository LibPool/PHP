# itscoding/facebook-connector

> 标签: Craft, cms, craft-plugin, craftcms, facebookconnector

## 简介

Connect a Website to an Facebook Page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
