# vbanksdk/vbank-php-sdk

> 标签: VDF Bank SDK, vbank-php-sdk

## 简介

Laravel SDK to easily work with the VDF Microfinance Bank APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
