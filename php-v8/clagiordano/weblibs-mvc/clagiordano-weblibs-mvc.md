# clagiordano/weblibs-mvc

> 标签: api, clagiordano, framework, mvc, restful, routing, weblibs

## 简介

weblibs-mvc is an simple and lightweight php routing component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
