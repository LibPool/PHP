# univeros/cookie

> 标签: PHP

## 简介

Immutable value objects for HTTP cookies, plus a manager that reads, writes, and modifies them on PSR-7 requests and responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
