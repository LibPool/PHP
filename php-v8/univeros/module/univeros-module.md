# univeros/module

> 标签: PHP

## 简介

Pluggable extension modules for Univeros: a module self-registers its routes, PSR-15 middleware, Cycle entities, and migrations into a host app via one container tag.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
