# univeros/http

> 标签: PHP

## 简介

PSR-15 HTTP foundation with the Action/Domain/Input/Responder lifecycle, FastRoute routing, content negotiation, and JWT authentication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
