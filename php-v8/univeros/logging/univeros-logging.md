# univeros/logging

> 标签: PHP

## 简介

PSR-3 application logging for Altair, backed by Monolog and wired from LOG_* env vars. JSON-lines to stderr by default.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
