# univeros/filesystem

> 标签: PHP

## 简介

Flysystem v3 wrapper offering one swap-friendly API for local, S3, SFTP, FTP, and Dropbox storage, wired to the Altair container.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
