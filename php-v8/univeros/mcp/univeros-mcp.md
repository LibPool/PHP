# univeros/mcp

> 标签: PHP

## 简介

Model Context Protocol server: exposes the framework's capabilities as MCP tools so any MCP-capable agent can drive an Altair project natively.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
