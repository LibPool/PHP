# craftsnippets/craft-named-routes

> 标签: Craft, cms, craft named routes, craft-plugin, craftcms, routes, routing

## 简介

Named routes plugin for Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
