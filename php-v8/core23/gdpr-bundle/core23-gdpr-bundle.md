# core23/gdpr-bundle

> 标签: FLoC, block, bundle, cookie, dsgvo, gdpr, privacy, sonata, sonata-block, symfony, widget

## 简介

This bundle provides a GDPR conform cookie information for symfony applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
