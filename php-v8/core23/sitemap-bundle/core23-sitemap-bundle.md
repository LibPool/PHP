# core23/sitemap-bundle

> 标签: Sitemap, bundle, sitemap.xml, symfony

## 简介

This bundle provides some classes for an automatic sitemap.xml generation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
