# core23/menu-bundle

> 标签: bundle, generator, knpmenu, menu, sonata, sonata-block, symfony

## 简介

This bundle provides services for defining static menus for symfony applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
