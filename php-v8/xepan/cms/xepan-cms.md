# xepan/cms

> 标签: ERP, cms, drag and drop, saas, xepan

## 简介

Drag and Drop based Live editing CMS for xEpan platform frontend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
