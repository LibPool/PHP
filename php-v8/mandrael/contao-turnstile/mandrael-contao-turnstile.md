# mandrael/contao-turnstile

> 标签: captcha, cloudflare, contao, spam, turnstile

## 简介

Ersetzt das Standard-CAPTCHA von Contao global durch Cloudflare Turnstile. Ohne gültiges Token wird eine Einsendung eingestuft statt abgewiesen; sicherer Spam landet in einer Backend-Ablage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
