# mandrael/contao-event-tags

> 标签: calendar, contao, events, filter, tags

## 简介

Erweiterung für Contao, um Events zentrale Tags zuzuweisen und Eventlisten nach Tags zu filtern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
