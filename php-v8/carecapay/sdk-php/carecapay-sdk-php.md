# carecapay/sdk-php

> 标签: carecapay, gateway, pagamentos, pix, sdk

## 简介

SDK oficial PHP da CarecaPay — cobranças Pix, saldo e verificação de webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
