# abolotin/yii2-unique-id

> 标签: php, yii2

## 简介

Generating unique identificator for any purposes. Typically used by Yii-widgets ("id"-attribute of HTML elements).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
