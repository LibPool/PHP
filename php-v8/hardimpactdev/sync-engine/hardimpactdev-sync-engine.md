# hardimpactdev/sync-engine

> 标签: laravel, local-first, offline, reverb, sqlite, sync

## 简介

Local-first sync for Laravel: a per-scope change feed, a push endpoint and real-time pokes. Pairs with the TypeScript client @hardimpactdev/sync-engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
