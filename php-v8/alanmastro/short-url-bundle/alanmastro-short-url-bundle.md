# alanmastro/short-url-bundle

> 标签: short url, shortener, url

## 简介

Provides a service and twig extension for getting short urls like http://your.host/~short

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
