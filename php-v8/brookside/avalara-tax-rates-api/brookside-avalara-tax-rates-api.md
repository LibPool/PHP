# brookside/avalara-tax-rates-api

> 标签: AvaTax, avalara, tax, tax-rates

## 简介

Simple PHP wrapper for Avalara's Tax Rates API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
