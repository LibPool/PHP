# propeller-orm/propeller-orm

> 标签: Active Record, database, mapping, orm, persistence

## 简介

Propeller ORM is an open-source ORM for PHP with code generation (fork of Propel).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
