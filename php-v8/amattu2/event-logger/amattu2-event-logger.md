# amattu2/event-logger

> 标签: PHP

## 简介

A lightweight, basic PHP 7+ event message logger that eases the workload of writing and generating timestamped events.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
