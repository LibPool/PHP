# digicademy/typo3-sentry-transaction-handler

> 标签: extension, glitchtip, performance, sentry, tracing, typo3

## 简介

Opens a Sentry transaction per TYPO3 request so traces_sample_rate actually produces performance data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
