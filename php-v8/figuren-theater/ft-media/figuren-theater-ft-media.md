# figuren-theater/ft-media

> 标签: Webp, attachments, image compression, media, uploads, wordpress

## 简介

Optimizations related to media & attachments, packed for a WordPress multisite network like figuren.theater

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
