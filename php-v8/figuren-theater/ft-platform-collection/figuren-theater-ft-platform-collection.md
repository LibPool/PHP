# figuren-theater/ft-platform-collection

> 标签: multisite, wordpress

## 简介

Curated collection of all parts of the WordPress Multisite network for puppeteers - figuren.theater

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
