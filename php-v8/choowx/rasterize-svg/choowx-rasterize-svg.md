# choowx/rasterize-svg

> 标签: Webp, choowx, convert, jpeg, jpg, php, png, rasterize, rasterize-svg, svg

## 简介

A PHP library for converting SVG to JPEG, PNG, and WEBP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
