# tourze/wechat-work-server-bundle

> 标签: PHP

## 简介

企业微信服务端消息处理包，用于接收和处理企业微信回调消息

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
