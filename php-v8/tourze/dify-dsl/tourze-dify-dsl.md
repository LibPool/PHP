# tourze/dify-dsl

> 标签: DSL, ai, dify, llm, workflow, yaml

## 简介

A framework-agnostic PHP library for parsing and generating Dify DSL (Domain-Specific Language) workflows

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
