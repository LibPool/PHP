# tourze/yunpian-sms-bundle

> 标签: PHP

## 简介

云片短信服务集成包，提供短信发送、模板管理、签名管理等功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
