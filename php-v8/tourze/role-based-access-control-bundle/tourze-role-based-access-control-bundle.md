# tourze/role-based-access-control-bundle

> 标签: PHP

## 简介

基于角色的访问控制(RBAC)Bundle，为PHP Monorepo提供统一的权限管理系统

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
