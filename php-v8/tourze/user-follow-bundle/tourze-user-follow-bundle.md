# tourze/user-follow-bundle

> 标签: PHP

## 简介

Symfony bundle for user follow/follower relationship management with event handling and EasyAdmin integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
