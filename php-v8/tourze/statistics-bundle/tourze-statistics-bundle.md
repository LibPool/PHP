# tourze/statistics-bundle

> 标签: PHP

## 简介

Symfony 统计数据模块，提供日报生成、指标收集、统计表创建等功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
