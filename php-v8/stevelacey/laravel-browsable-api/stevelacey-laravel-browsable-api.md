# stevelacey/laravel-browsable-api

> 标签: api, browsable, drf, framework, laravel, rest

## 简介

Browsable API for Laravel, based on Django REST Framework's Browsable API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
