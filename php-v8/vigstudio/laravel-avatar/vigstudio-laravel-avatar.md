# vigstudio/laravel-avatar

> 标签: avatar, gravatar, laravel, laravolt

## 简介

Turn name, email, and any other string into initial-based avatar or gravatar.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
