> 标签: Publiq, UiTdatabank, entry, laravel, search, taxonomy

## 简介

A fluent Laravel client for publiq UiTdatabank APIs (Search available, more on roadmap)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
