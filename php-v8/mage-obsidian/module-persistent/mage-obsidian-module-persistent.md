# mage-obsidian/module-persistent

> 标签: PHP

## 简介

Persistent (Remember Me) compatibility for MageObsidian: the remember-me checkbox on the sign-in and registration forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
