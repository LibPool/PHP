# mage-obsidian/module-inventory-in-store-pickup

> 标签: PHP

## 简介

In-store pickup for the MageObsidian checkout: a delivery method selector and a pickup location finder over the Multi-Source Inventory pickup endpoints. Optional: stores without MSI do not install it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
