# mage-obsidian/module-multishipping

> 标签: PHP

## 简介

Multishipping (ship to multiple addresses) compatibility for MageObsidian: the multi-address checkout flow rendered with Twig over the native Multishipping blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
