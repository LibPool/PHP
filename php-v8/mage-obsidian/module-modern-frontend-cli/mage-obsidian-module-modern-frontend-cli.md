# mage-obsidian/module-modern-frontend-cli

> 标签: cli, frontend, magento, magento2, tailwindcss, vite, vue

## 简介

Magento 2 module that provides a CLI to manage modern frontend tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
