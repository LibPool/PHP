# mage-obsidian/module-review

> 标签: PHP

## 简介

Product reviews domain compatibility for MageObsidian: the PDP rating summary, approved review list and submit form on native Magento_Review blocks, with review/aggregateRating JSON-LD.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
