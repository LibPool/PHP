# mage-obsidian/theme-base

> 标签: PHP

## 简介

MageObsidian base storefront theme: pulls the modern-frontend engine and the full storefront module stack for Luma-level parity.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
