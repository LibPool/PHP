# mage-obsidian/module-send-friend

> 标签: PHP

## 简介

Send to a Friend compatibility for MageObsidian: the email-to-a-friend link on the product detail page and its share form.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
