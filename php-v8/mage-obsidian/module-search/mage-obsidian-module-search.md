# mage-obsidian/module-search

> 标签: frontend, layered-navigation, magento, magento2, performance, search, varnish

## 简介

Cacheable listing fragments for MageObsidian: filtering, sorting and pagination on category and search pages are served as HTML fragments rendered by the native blocks, instead of re-assembling the whole page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
