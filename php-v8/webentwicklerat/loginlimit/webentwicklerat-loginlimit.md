# webentwicklerat/loginlimit

> 标签: attack, backend, brute, force, frontend, login, typo3

## 简介

Protect backend and/or frontend login against brute-force attacks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
