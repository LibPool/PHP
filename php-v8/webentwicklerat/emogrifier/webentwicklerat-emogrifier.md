# webentwicklerat/emogrifier

> 标签: css, emogrifier, emogrify, inline, style, typo3

## 简介

Converts CSS styles into inline HTML styles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
