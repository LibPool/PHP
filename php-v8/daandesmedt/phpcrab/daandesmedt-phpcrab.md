# daandesmedt/phpcrab

> 标签: Belgium, crab, geolocation, opendata, php

## 简介

A PHP wrapper for the Flemisch CRAB (Centraal Referentieadressenbestand) SOAP webservices (WS & TOOLS)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
