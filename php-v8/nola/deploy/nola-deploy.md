# nola/deploy

> 标签: PHP

## 简介

High-performance Magento 2 deployment CLI — optimizes di:compile, static-content:deploy with change detection, parallelism, and zero-downtime switching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
