# simplystatic/simply-static

> 标签: PHP

## 简介

Convert your WordPress site into a static one with the free WordPress static site generator plugin, Simply Static.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
