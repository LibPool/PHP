# hyvor/sdk-core

> 标签: PHP

## 简介

Shared HTTP transport, auth, serialization, and exceptions for HYVOR product SDKs. Not intended to be required directly - installed transitively by hyvor/sdk-* product packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
