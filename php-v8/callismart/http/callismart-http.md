# callismart/http

> 标签: Socket, aws, client, curl, http, sigv4

## 简介

A lightweight, multi-adapter HTTP client for PHP 8.1+ with AWS SigV4 support and fallbacks for restricted environments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
