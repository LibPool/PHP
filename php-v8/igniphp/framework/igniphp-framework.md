# igniphp/framework

> 标签: framework, http, micro, middleware, psr-15, psr-7, swoole

## 简介

Swoole, PSR-7, PSR-15 modular micro anti-framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
