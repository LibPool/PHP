# illchuk/zfc-user-redirect-uri

> 标签: ZendFramework, zf3, zfcuser

## 简介

ZfcUser redirection to specific URI, rather than to a generic route

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
