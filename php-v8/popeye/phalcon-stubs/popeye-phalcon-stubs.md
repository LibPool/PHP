# popeye/phalcon-stubs

> 标签: framework, phalcon, stubs

## 简介

Stubs for Phalcon framework that can be used for autocompletion in IDE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
