# c0ntax/aws-ec2-check-tag

> 标签: aws, ec2, instance, tags

## 简介

A very simple service that pulls the tags for a given instance to see if a particular key = a particular value.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
