# be-soft/recaptcha-bundle

> 标签: recaptcha

## 简介

This bundle provides easy reCAPTCHA form field integration. (Forked from excelwebzone/EWZRecaptchaBundle)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
