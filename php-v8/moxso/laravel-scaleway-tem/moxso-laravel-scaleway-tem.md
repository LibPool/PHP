# moxso/laravel-scaleway-tem

> 标签: laravel, laravel-scaleway-tem, moxso

## 简介

A Laravel mailer driver for sending transactional emails through Scaleway TEM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
