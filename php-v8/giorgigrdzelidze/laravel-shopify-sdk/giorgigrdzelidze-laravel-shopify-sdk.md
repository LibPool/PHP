# giorgigrdzelidze/laravel-shopify-sdk

> 标签: filament, graphql, laravel, oauth, rest-api, shopify, shopify-api, webhooks

## 简介

Production-grade Laravel package for Shopify Admin API integration with OAuth, webhooks, data mirroring, and optional Filament support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
