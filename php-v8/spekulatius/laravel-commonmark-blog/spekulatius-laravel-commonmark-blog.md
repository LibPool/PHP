# spekulatius/laravel-commonmark-blog

> 标签: PHP

## 简介

A simple filesystem-based, SEO-optimized blog for Laravel using Commonmark.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
