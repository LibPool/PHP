# witrin/formal-theory

> 标签: automata, deterministic, dfa, expression, fa, finite, formal, lexer, nfa, nondeterministic, optimizer, regex, regular, state, theory, transform

## 简介

FormalTheory is a library that allows for manipulation and conversion of NFAs, DFAs and Regular Expressions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
