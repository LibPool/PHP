# markocupic/import-from-csv-bundle

> 标签: Import from csv, contao, spreadsheet

## 简介

Backend extension for the Contao Open Source CMS. Import data records from a CSV spreadsheet.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
