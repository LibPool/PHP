# markocupic/nav-page-container

> 标签: contao, nav-page-container, navigation, tl_page

## 简介

Contao plugin, add the 'not-clickable-page-container' css class to nav items.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
