# markocupic/fontawesome-icon-picker-bundle

> 标签: Font Awesome 5, backend, contao, icon, picker

## 简介

Add a FontAwesome icon picker input element to the Contao backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
