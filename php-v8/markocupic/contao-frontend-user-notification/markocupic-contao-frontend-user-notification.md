# markocupic/contao-frontend-user-notification

> 标签: Bootstrap toasts, contao, frontend, notifications

## 简介

Display notifications to logged in frontend users (Contao 5.3 and Contao 6)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
