# markocupic/contao-filepond-uploader

> 标签: PQINA, filepond, fileupload, widget

## 简介

Frontend file uploader widget for the Contao CMS form generator with browser-side image transformation (Contao 5.3 and Contao 6)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
