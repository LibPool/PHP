# markocupic/member-picture-feed

> 标签: contao, feed, member-picture-feed, picture

## 简介

Plugin for Contao CMS. Add a member picture feed backend module to your Contao project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
