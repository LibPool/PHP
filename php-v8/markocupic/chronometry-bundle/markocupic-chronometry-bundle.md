# markocupic/chronometry-bundle

> 标签: Vue.js, Zeitmessung, chronometry, contao, duathlon, ranking list, triathlon

## 简介

Zeitmessungs-Tool für Ausdauerwettkaempfe an Schulen.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
