# markocupic/contao-article-class-select-bundle

> 标签: PHP

## 简介

Contao Article Class Select Bundle: select a container class and background classes for articles (Contao 5.3 and Contao 6)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
