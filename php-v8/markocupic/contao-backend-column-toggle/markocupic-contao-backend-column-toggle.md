# markocupic/contao-backend-column-toggle

> 标签: backend, column toggle, contao, list view

## 简介

Contao backend column toggle: hide and show table columns dynamically with Stimulus, stored per user (Contao 5.3 and Contao 6).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
