# markocupic/contao-db-backup

> 标签: backup, contao, database

## 简介

Creates database backups with the Contao backup manager using a configurable cron job (Contao 5.3 and Contao 6).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
