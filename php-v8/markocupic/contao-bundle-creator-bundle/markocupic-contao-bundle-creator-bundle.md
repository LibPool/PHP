# markocupic/contao-bundle-creator-bundle

> 标签: Skeleton, boilerplate, bundle, contao, creator, extension, maker

## 简介

This bundle provides a bundle maker for Contao 5.3 and Contao 6. The extension will create a fully working backend- or/and frontend module after you have defined a few parameters in the Contao backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
