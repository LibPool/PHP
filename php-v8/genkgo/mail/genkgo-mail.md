# genkgo/mail

> 标签: PHP

## 简介

Library to send e-mails over different transports and protocols (like SMTP and IMAP) using immutable messages and streams. Also includes SMTP server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
