# gin0115/pixie-wpdb

> 标签: database, query builder, sql, wordpress, wpdb

## 简介

An adaptation of Pixie (created byusmanhalalit) for WordPress using WPDB over PDO.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
