# ratiw/jsonpdf

> 标签: fpdf, json, pdf

## 简介

JsonPDF is a wrapper class of FPDF for creating PDF using JSON data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
