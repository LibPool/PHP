# balatd/kern-ux

> 标签: accessibility, bitv, content-blocks, design-system, kern-ux, oeffentliche-verwaltung, typo3, wcag

## 简介

KERN UX-Standard for TYPO3 - accessible Fluid components, Content Blocks and form templates for German public sector websites. Independent community integration, not an official KERN project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
