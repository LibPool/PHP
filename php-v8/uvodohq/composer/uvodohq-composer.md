# uvodohq/composer

> 标签: composer, installer, plugin, uvodo

## 简介

Uvodo Composer plugin to register custom installer for Uvodo plugins/themese etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
