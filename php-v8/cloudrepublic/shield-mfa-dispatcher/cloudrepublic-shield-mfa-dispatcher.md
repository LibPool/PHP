# cloudrepublic/shield-mfa-dispatcher

> 标签: 2fa, MFA, codeigniter, codeigniter4, shield

## 简介

Lets a CodeIgniter Shield app offer several MFA methods (email, WhatsApp, TOTP, passkey, ...) and switch a user between them programmatically, despite Shield's Auth::$actions only accepting one class.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
