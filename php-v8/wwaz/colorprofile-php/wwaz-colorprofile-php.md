# wwaz/colorprofile-php

> 标签: cmyk, color-profile, icc, prepress, rgb, web-to-print

## 简介

PHP library and CLI for installing, managing and resolving ICC color profiles.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
