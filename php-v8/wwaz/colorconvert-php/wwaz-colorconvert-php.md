# wwaz/colorconvert-php

> 标签: cmyk, color, conversion, icc, lcms2, littlecms, rgb

## 简介

Converts CMYK to profiled RGB values and vice versa (ICC profiles, LittleCMS).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
