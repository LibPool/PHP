# netgen/ngclasslist

> 标签: PHP

## 简介

Netgen Class List Datatype is an eZ Publish extension that provides a datatype to select and store a list of content classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
