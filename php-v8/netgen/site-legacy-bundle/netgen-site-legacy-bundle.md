# netgen/site-legacy-bundle

> 标签: PHP

## 简介

Netgen Site Legacy Bundle is an Ibexa OSS bundle that implements common features that are used by Netgen to implement websites. This bundle acts as a glue between new and legacy kernels.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
