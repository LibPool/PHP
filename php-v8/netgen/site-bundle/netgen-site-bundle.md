# netgen/site-bundle

> 标签: ibexa, netgen, site-bundle

## 简介

Netgen Site Bundle is an Ibexa bundle that implements common features that are used by Netgen to implement websites

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
