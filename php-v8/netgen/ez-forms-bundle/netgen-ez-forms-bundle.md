# netgen/ez-forms-bundle

> 标签: Forms, ez-forms-bundle, ezforms, ezplatform, netgen

## 简介

Integration of Symfony's Form component with eZ Platform Public API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
