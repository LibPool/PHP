# ngankt2/laravel-helper

> 标签: Laravel helper, cast, data casting, data protection, encryption, field encryption, global functions, helper, laravel, openssl, php, security, utility functions

## 简介

A Laravel helper package that includes security utilities, field encryption, data casting, and commonly used helper functions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
