# johnsnook/yii2-parsel

> 标签: extension, parse, query, search, yii2

## 简介

Allows developers to provide a search query interface similar to Sphinx

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
