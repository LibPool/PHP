# dinesh/bugonemail

> 标签: Bug Email, BugOnEmail, Error on Email, bug, error, instant bug, instant error, laravel

## 简介

Get Laravel Bug or Error instant notification by Emails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
