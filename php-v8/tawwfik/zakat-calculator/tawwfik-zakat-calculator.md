# tawwfik/zakat-calculator

> 标签: calculator, gold, islamic, laravel, money, silver, zakat

## 简介

A Laravel package for calculating zakat on money, gold, and silver.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
