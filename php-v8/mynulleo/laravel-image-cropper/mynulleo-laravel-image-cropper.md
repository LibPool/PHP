# mynulleo/laravel-image-cropper

> 标签: PHP

## 简介

A lightweight and reusable Laravel Blade component for cropping images with custom aspect ratio, rotation, zoom, and base64 output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
