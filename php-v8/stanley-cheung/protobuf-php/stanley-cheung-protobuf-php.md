# stanley-cheung/protobuf-php

> 标签: protobuf, protocol buffer, serializing

## 简介

PHP implementation of Google's Protocol Buffers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
