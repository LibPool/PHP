# urbitech/sylius-product-variant-attribute-plugin

> 标签: sylius, sylius-plugin

## 简介

Plugin for Sylius to add attributes on product variants.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
