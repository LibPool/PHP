# use-lock/client-laravel

> 标签: SSO, client, laravel, lock, oidc

## 简介

Laravel integration for Lock: sign users in, handle back-channel logout and obtain API tokens

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
