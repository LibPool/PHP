# norman-huth/nova-detached-actions

> 标签: laravel, nova

## 简介

A Laravel Nova tool to allow for placing actions in the Nova toolbar detached from the checkbox selection mechanism.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
