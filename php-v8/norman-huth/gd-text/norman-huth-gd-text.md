# norman-huth/gd-text

> 标签: dynamic-image, ext-gd, gd, gd-library, image, image-generator, image-manipulation, laravel, php, php-8, text-to-image

## 简介

A class drawing multiline and aligned text on pictures. Uses GD extension.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
