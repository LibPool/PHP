# light-speak/laravel_model_cache

> 标签: PHP

## 简介

基于Redis的laravel模型数值缓存，可以减少并发修改对数据库的压力，减少数据库事务锁的使用

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
