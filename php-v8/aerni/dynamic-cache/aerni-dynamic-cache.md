# aerni/dynamic-cache

> 标签: statamic, static cache

## 简介

Supercharge Statamic's static cache by dynamically excluding URLs that shouldn't be cached statically

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
