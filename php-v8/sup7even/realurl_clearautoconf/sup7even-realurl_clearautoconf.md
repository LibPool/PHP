# sup7even/realurl_clearautoconf

> 标签: RealURL, clearcache, extension, typo3

## 简介

Delete the automatic generated typo3conf/realurl_autoconf.php via the TYPO3 CMS Backend (additional ClearCacheMenu item)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
