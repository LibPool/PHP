# zerofyi/media

> 标签: Webp, image, laravel, media, medialibrary, storage, upload, variants

## 简介

Production-grade Laravel media suite: zero-orphan storage lifecycle, automated WebP conversion, responsive variants, SVG sanitization, and atomic Eloquent orchestration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
