# rkl/autocomplete-for-indexedsearch

> 标签: TYPO3 CMS, autocomplete, search, typo3

## 简介

Adds autocomplete functionality to the TYPO3 indexed search field.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
