# sbehuret/user_config

> 标签: config, configuration, domain, file, include, multi, setup, user

## 简介

Roundcube plugin that loads user-specific configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
