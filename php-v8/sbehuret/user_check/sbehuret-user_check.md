# sbehuret/user_check

> 标签: blacklist, check, domain, multi, setup, user, whitelist

## 简介

Roundcube plugin that checks if users belong to a whitelist or blacklist.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
