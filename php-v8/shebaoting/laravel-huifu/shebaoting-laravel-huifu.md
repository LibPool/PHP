# shebaoting/laravel-huifu

> 标签: PHP

## 简介

可能是最好用的汇付天下斗拱平台 Laravel 扩展包，由 shebaoting 打造。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
