# event-sourcery/monolith-event-sourcery-driver

> 标签: cqrs, event sourcery, event sourcing, monolith

## 简介

Monolith Driver for a Minimalistic PHP Event Sourcing / CQRS Library with GDPR Support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
