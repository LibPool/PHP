# phrozenbyte/pico-deprecated

> 标签: compatibility, deprecation, pico, pico-deprecated, picocms, picocms-plugin

## 简介

This is PhrozenByte's fork of Pico's PicoDeprecated plugin. Pico is a stupidly simple, blazing fast, flat file CMS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
