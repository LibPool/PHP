# primal/errorhandler

> 标签: crash, error, exceptions, http, json

## 简介

Quick trigger class for handling all errors and exceptions internally. Defaults to outputting as JSON data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
