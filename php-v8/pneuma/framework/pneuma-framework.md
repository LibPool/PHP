# pneuma/framework

> 标签: PHP

## 简介

Pneuma is a PHP micro-framework that helps you quickly write simple yet powerful Common Gateway Interface and Command-Line Interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
