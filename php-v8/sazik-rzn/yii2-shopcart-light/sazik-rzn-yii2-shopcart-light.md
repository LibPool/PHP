# sazik-rzn/yii2-shopcart-light

> 标签: cart, component, sazik, shop, shopcart, yii2

## 简介

Lightweight shopcart component for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
