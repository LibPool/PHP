# botk/amlo

> 标签: AMLO, BOTK, KEES, Linked Data, MOPSO, RDF, aml, open data

## 简介

Super lightweight classes and tools for developing RDF gateways for AMLO and FIBO vocabularies.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
