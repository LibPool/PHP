# makingwaves/ezaddthisbundle

> 标签: PHP

## 简介

eZ Add This Bundle for eZ Publish Platform, integration with addthis.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
