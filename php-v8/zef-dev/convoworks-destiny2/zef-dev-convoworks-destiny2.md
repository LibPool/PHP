# zef-dev/convoworks-destiny2

> 标签: Bungie, Destiny, convoworks

## 简介

Convoworks package that aid with the Bungie.net API, used for Destiny 2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
