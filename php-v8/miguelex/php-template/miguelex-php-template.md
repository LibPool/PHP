# miguelex/php-template

> 标签: PHPStan, gulp, mvc, pest, php, template, vite

## 简介

PHP 8.2 MVC template with PHPStan, Pest, Gulp/Vite and AI agent support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
