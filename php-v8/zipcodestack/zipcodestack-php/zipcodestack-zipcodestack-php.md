# zipcodestack/zipcodestack-php

> 标签: api, client, distance, geolocation, postal, sdk, zip, zipcode

## 简介

PHP client for the zipcodestack.com API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
