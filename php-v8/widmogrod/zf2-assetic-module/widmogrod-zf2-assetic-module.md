# widmogrod/zf2-assetic-module

> 标签: JS, assetic, assets, css, less, resources

## 简介

Zend Framework 2 module that provides complete integration of Assetic library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
