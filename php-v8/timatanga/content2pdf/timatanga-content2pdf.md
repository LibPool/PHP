# timatanga/content2pdf

> 标签: HTML2FPDF, fpdf, html2pdf, image2pdf, mpdf

## 简介

The timatanga content2Pdf package. Generates PDF files from UTF-8 encoded content

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
