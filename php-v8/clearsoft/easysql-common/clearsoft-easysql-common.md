# clearsoft/easysql-common

> 标签: clearsoft, common, easysql, php, sdk, sql

## 简介

Shared code for the EasySQL PHP SDK packages (SQL safety validation, credential sanitization).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
