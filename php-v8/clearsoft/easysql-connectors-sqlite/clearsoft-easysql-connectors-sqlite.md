# clearsoft/easysql-connectors-sqlite

> 标签: clearsoft, connector, database, easysql, php, sdk, sqlite

## 简介

EasySQL SQLite connector package — local schema introspection and SELECT execution for SQLite files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
