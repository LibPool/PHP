# clearsoft/easysql-connectors-clickhouse

> 标签: clearsoft, clickhouse, connector, database, easysql, php, sdk

## 简介

EasySQL ClickHouse connector package — local schema introspection and SELECT execution over the HTTP interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
