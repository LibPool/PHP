# clearsoft/easysql-laravel

> 标签: clearsoft, easysql, laravel, php, sdk

## 简介

Laravel integration for the EasySQL PHP SDK — service provider, manager and facade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
