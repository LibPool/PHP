# clearsoft/easysql-schema-generation

> 标签: clearsoft, easysql, php, schema, sdk

## 简介

EasySQL schema generation package — transforms raw connector introspection output into the schema payload the API consumes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
