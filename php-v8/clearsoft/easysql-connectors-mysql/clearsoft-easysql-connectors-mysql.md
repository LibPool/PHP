# clearsoft/easysql-connectors-mysql

> 标签: clearsoft, connector, database, easysql, mariadb, mysql, php, sdk

## 简介

EasySQL MySQL connector package — local schema introspection and SELECT execution for MySQL/MariaDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
