# clearsoft/easysql-connectors-postgres

> 标签: clearsoft, connector, database, easysql, php, postgres, postgresql, sdk

## 简介

EasySQL PostgreSQL connector package — local schema introspection and SELECT execution for PostgreSQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
