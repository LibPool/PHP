> 标签: bigquery, clearsoft, clickhouse, connector, d1, database, db2, duckdb, easysql, firebird, hana, libsql, mariadb, mysql, oracle, php, postgres, sdk, snowflake, sqlite, sqlserver, trino

## 简介

EasySQL connector package — local schema introspection and SELECT execution for MySQL/MariaDB, PostgreSQL, SQLite, ClickHouse, SQL Server, Oracle, Firebird, Db2, DuckDB, libSQL, Cloudflare D1, Snowflake, BigQuery, Trino and SAP HANA.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
