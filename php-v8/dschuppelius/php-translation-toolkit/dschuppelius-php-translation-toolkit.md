# dschuppelius/php-translation-toolkit

> 标签: PHP

## 简介

Slim translation toolkit with provider abstraction, cache port and a DeepL provider built on php-api-toolkit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
