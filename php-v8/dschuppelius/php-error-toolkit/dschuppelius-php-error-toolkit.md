# dschuppelius/php-error-toolkit

> 标签: PHP

## 简介

Logging and error handling foundation for the Schuppelius PHP toolkits (PSR-3 loggers, global error handler, LoggerRegistry, Laravel bridge)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
