# encrypt/encrypt

> 标签: PHP

## 简介

A top-level secrets orchestrator. Not just another .env tool — this one encrypts, locks, and sets you up for secure local and team dev.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
