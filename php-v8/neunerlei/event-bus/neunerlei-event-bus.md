# neunerlei/event-bus

> 标签: PHP

## 简介

This package contains a PSR-14 compliant event dispatcher facade, which aims to bring the listener provider and dispatcher objects closer together.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
