# blackbricksoftware/civicrm-sms-chat

> 标签: PHP

## 简介

SMS Chat: a Google Messages-style, real-time SMS conversation tab on CiviCRM contact records, over native SMS activities. Env-driven configuration and subscriber-pattern hooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
