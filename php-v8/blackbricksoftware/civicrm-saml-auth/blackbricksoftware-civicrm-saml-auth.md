# blackbricksoftware/civicrm-saml-auth

> 标签: PHP

## 简介

SAML2-based Single Sign-On for CiviCRM Standalone with env-driven configuration and subscriber-pattern hooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
