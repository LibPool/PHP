# blackbricksoftware/civicrm-container-logs

> 标签: PHP

## 简介

Write CiviCRM Logs to stderr. Useful for running CiviCRM inside a Docker container.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
