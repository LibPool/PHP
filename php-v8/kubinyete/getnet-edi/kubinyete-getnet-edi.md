# kubinyete/getnet-edi

> 标签: PHP

## 简介

A simple yet useful EDI parser for Getnet, a brazillian payment acquirer institution

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
