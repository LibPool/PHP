# tomsgu/sylius-gift-plugin

> 标签: sylius, sylius-gift, sylius-plugin

## 简介

Sylius plugin to mark orders as gifts when ordering products.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
