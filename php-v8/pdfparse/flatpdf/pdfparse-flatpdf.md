# pdfparse/flatpdf

> 标签: no-dependencies, pdf, pdf-generator, pdf-writer, reports, tables

## 简介

A flat, zero-dependency PHP PDF writer built for speed and large documents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
