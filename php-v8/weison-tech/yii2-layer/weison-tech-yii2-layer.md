# weison-tech/yii2-layer

> 标签: yii2, yii2 alert, yii2 layer, yii2 layer alert

## 简介

Alert widget based on layer.js extension {@link https://github.com/sentsin/layer)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
