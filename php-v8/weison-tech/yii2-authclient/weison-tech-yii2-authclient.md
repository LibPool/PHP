# weison-tech/yii2-authclient

> 标签: OpenId, auth, oauth, yii2

## 简介

External authentication via OAuth and OpenID for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
