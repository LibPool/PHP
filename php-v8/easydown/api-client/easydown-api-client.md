# easydown/api-client

> 标签: API-Client, easydown, public-media, video-downloader-api

## 简介

PHP client for the EasyDown public-media API: normalized parsing, platform data and safe errors. Hosted API requires account, token and credits.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
