# mintbridge/eloquent-favourites

> 标签: eloquent, favorite, favourite, laravel

## 简介

An eloquent package for favouriting eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
