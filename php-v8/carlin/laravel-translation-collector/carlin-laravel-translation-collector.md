# carlin/laravel-translation-collector

> 标签: collector, i18n, laravel, localization, translation

## 简介

Laravel Translation Collector Package - 自动收集项目中的翻译文本并同步到外部翻译系统

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
