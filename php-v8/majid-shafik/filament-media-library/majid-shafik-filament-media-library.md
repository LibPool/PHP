# majid-shafik/filament-media-library

> 标签: deduplication, filament, filament-plugin, filamentphp, image-picker, laravel, media-library, media-manager, rtl

## 简介

An advanced, secure, and modern centralized Media Library plugin for Filament 5 with SHA-256 deduplication, hierarchical category tree, usage tracking, and native RTL support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
