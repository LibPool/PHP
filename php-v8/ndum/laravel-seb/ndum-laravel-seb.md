# ndum/laravel-seb

> 标签: Exam Configurations, Safe Exam Browser, exams, laravel, plist, seb, xml

## 简介

Laravel Package for generating encrypted SEB (Safe Exam Browser) client configurations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
