# rockys/ex-admin-ui

> 标签: Ex-admin, ExAdmin, admin, curd, php, ui

## 简介

基于Ant Design of Vue 的PHP通用前端渲染框架Ex-admin UI

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
