# ladbu/laravel-ladwire-module

> 标签: ladwire, laravel, modular, module, package

## 简介

A modular Laravel package that adds Ladwire components to fresh Laravel projects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
