# bale/gupa-panel

> 标签: Bale, gupa, management, panel, security

## 简介

Management panel for Gupa — sync blocked IPs, blacklists, whitelists to tenants with false positive detection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
