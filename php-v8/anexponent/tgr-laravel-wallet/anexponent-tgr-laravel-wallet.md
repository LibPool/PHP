# anexponent/tgr-laravel-wallet

> 标签: balance, credits, laravel, money, virtual-currency, wallet

## 简介

A modern Laravel package providing a simple virtual wallet system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
