# id-sign/image-bundle

> 标签: PHP

## 简介

Symfony bundle for automatic image optimization — resize, format negotiation (AVIF/WebP), srcset, blur placeholder, HTTP cache headers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
