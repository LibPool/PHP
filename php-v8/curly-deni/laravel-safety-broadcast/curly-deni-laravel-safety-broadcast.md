# curly-deni/laravel-safety-broadcast

> 标签: Curly Deni, laravel, laravel-safety-broadcast

## 简介

Safely dispatch Laravel broadcast events without failing the application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
