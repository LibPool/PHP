# quebecstudio-mods/laravel-consent-kit

> 标签: consent, cookies, gdpr, laravel, loi25

## 简介

Cookie consent banner for Laravel, built on consent-kit-core: no third-party cookie before consent, cache-safe HTML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
