# quebecstudio-mods/statamic-consent-kit

> 标签: consent, cookies, gdpr, loi25, statamic, statamic-addon

## 简介

Cookie consent banner for Statamic, built on consent-kit-core: no third-party cookie before consent, cache-safe HTML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
