# builtnoble/vite-php

> 标签: laminas view, php, plates, templating engine, twig, vite

## 简介

Use Vite with PHP templating engines like Twig, Plates, and Laminas View.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
