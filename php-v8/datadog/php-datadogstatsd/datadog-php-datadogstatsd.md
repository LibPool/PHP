# datadog/php-datadogstatsd

> 标签: DataDog, check, error-reporting, health, logging, monitoring, statsd

## 简介

An extremely simple PHP datadogstatsd client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
