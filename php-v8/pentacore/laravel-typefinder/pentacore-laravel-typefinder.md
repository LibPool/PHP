# pentacore/laravel-typefinder

> 标签: enums, laravel, models, php, types, typescript

## 简介

Auto-generate TypeScript type definitions from Laravel Models, Enums, Casts, and Requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
