# aimtofeel/wp-swift-mailer

> 标签: Swift Mailer, Wordpress mailer, wordpress

## 简介

Implementation of Swift Mailer for Wordpress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
