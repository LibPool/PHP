# mcbankske/filament-sms-notifier

> 标签: filament, laravel, notifications, sms, textsms

## 简介

A reusable Filament plugin for sending SMS notifications via multiple drivers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
