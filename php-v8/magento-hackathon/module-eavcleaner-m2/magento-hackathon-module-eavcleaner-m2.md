# magento-hackathon/module-eavcleaner-m2

> 标签: PHP

## 简介

Purpose of this project is to check for different flaws that can occur due to EAV and provide cleanup functions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
