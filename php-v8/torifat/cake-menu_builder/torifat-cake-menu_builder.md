# torifat/cake-menu_builder

> 标签: cakephp, dynamic, helper, menu

## 简介

A dynamic menu building helper for CakePHP 2.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
