# snapshotpl/zf-snap-hip-chat

> 标签: hipchat, log, logger, zf2

## 简介

HipChat module (api and logger) for Zend Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
