# fadhila36/laravel-multipayment

> 标签: PHP

## 简介

Multi-payment gateway integration for Laravel (Midtrans, Xendit, Duitku, AyoConnect, Doku) with Fonnte WhatsApp integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
