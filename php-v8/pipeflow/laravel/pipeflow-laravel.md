# pipeflow/laravel

> 标签: laravel, pipeflow

## 简介

Pipeflow for the Laravel framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://bitbucket.org/pipeflow/laravel-package.git

- 许可证：proprietary
