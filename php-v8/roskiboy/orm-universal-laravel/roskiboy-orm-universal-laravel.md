# roskiboy/orm-universal-laravel

> 标签: database, dialect, eloquent, laravel, mongodb, nosql, orm, persistence, query-builder, recordset, redis, sql, ude

## 简介

ORM Universal Laravel - universal data platform: contracts, relational engine (AST, SQL compiler, versioned dialects, PDO, recordsets, schema, migrations), NoSQL engine (documents, filters, pipelines) and Laravel integration (provider, adapters, hybrid mode, ude:* tooling).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
