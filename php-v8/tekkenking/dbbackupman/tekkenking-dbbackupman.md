# tekkenking/dbbackupman

> 标签: PHP

## 简介

Cross-DB backups (PostgreSQL/MySQL/MariaDB) with uploads, retention, and incremental options.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
