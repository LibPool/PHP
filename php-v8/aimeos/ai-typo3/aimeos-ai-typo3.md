# aimeos/ai-typo3

> 标签: adapter, aimeos, cms, e-commerce, shop, typo3

## 简介

TYPO3 adapter for Aimeos e-commerce integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
