# greenterose/xml

> 标签: facturación electrónica, greenter, xml

## 简介

XML generación de documentos electrónicos, Facturacion Electrónica SUNAT - Perú

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
