# payengine/php_sdk

> 标签: concardis, ecommerce, payengine, payment, provider, service

## 简介

PHP Library for Concardis PayEngine 3.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
