# iop/magento2-coupon

> 标签: composer-installer, magento

## 简介

Magento 2 apply coupon code from url.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/iop/magento2-coupon
- 源码仓库：https://github.com/iop/magento2-coupon.git
