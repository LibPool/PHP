> 标签: crop, ffmpeg, file, file manager, file system, hls, image, laravel, m3u8, media, mostafaznv, resize, s3, sftp, storage, stream, upload, video

## 简介

Larupload is a ORM based file uploader for laravel to upload image, video, audio and other known files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
