# botguard/php-sdk

> 标签: anti-bot, bot, botguard, captcha, verification

## 简介

BotGuard 服务端核验 SDK：签名调用 /v1/verify，按 Passed / Rejected / CallerError / Unknown 返回结果

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
