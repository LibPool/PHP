# botguard/laravel

> 标签: anti-bot, bot, botguard, captcha, laravel

## 简介

BotGuard 的 Laravel 适配：配置、Facade、表单验证规则 botguard:action、Blade 组件 <x-botguard>

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
