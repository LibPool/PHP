# ivoba/dump-die-shortcuts

> 标签: debug, dump, dump-die, shortcuts

## 简介

Shortcut functions for symfony VarDumper component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
