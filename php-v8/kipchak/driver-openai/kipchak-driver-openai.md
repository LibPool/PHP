# kipchak/driver-openai

> 标签: Mamluk, ai, apis, microservices, openai

## 简介

An OpenAI driver (dependency) for the Kipchak API Development Kit (ADK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
