# kipchak/driver-logger

> 标签: Mamluk, apis, configuration, http, microservices

## 简介

A Logging Kipchak driver (dependency) for the Kipchak API Development Kit (ADK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
