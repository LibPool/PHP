# kipchak/identity

> 标签: Mamluk, apis, identity, microservices, multi-tenancy

## 简介

Consumer and tenant identity for the Kipchak API Development Kit (ADK): who a request is from, read from API keys, verified tokens, request attributes or headers, defined once and shared by metering and quotas.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
