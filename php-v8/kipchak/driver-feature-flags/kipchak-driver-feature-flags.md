# kipchak/driver-feature-flags

> 标签: GrowthBook, Mamluk, apis, feature flags, feature toggles, flagsmith, microservices, unleash

## 简介

A feature flag driver for the Kipchak API Development Kit (ADK), evaluating flags from Unleash, Flagsmith or GrowthBook

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
