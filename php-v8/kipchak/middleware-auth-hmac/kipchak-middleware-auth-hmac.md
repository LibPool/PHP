# kipchak/middleware-auth-hmac

> 标签: Mamluk, Request Signing, apis, hmac, http, microservices, standard webhooks, webhooks

## 简介

The Official HMAC Request Signing Middleware for the Kipchak API Development Kit (ADK). Verifies signed requests and webhooks with replay protection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
