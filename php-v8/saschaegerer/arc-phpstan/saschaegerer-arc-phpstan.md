# saschaegerer/arc-phpstan

> 标签: PHP

## 简介

PHPStan for Arcanist - Arcanist integration for PHP Static Analysis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
