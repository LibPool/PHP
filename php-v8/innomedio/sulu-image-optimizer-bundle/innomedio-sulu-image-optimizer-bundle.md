# innomedio/sulu-image-optimizer-bundle

> 标签: image, innomedio, sulu, symfony, upload

## 简介

Optimizes images before they are being uploaded and stored in the Sulu media library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
