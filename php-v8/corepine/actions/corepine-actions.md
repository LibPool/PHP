# corepine/actions

> 标签: actions, counters, laravel, likes, reactions

## 简介

Polymorphic action tracking for Laravel (likes, dislikes, reactions) with synced counters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
