# sendaxe/senda-gnre

> 标签: framework, laravel, lumen

## 简介

API para a emissão de guias GNRE para a SEFAZ - Base no Projeto: nfephp-org/sped-gnre

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
