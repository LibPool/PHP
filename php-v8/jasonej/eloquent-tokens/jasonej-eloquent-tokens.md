# jasonej/eloquent-tokens

> 标签: PHP

## 简介

A simple package designed to make dealing with one time use tokens in eloquent a little bit easier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
