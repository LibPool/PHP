# hamari-agency/pimcore-code-editor-bundle

> 标签: Monaco, code editor, ide, pimcore

## 简介

Edit PHP, Twig, JS, CSS code from within the Pimcore admin page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
