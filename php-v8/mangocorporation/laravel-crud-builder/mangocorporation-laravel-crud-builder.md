# mangocorporation/laravel-crud-builder

> 标签: auto, crud, form, generator, laravel, views

## 简介

Laravel 5 CRUD builder inspired by CakePHP's bake.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
