# bibi4k0/apple-pusher

> 标签: apns, apple, http2, notification, push

## 简介

A simple library for creating and sending push-notifications to apple devices via APNs using HTTP/2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
