# germey/emissary

> 标签: dependency injection, laravel, service provider, slim

## 简介

Allows you to easily use Laravel Service Providers with Slim 3's DI container

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
