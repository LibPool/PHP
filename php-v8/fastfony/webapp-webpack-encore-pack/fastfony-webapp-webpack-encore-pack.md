# fastfony/webapp-webpack-encore-pack

> 标签: pack, symfony, webpack, webpack-encore

## 简介

An other webapp pack on top of the default skeleton with webpack-encore-bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
