# olafnorge/secrets-provider

> 标签: configuration, container, env, secret

## 简介

Simple helper to load a value from a mounted secret or, if not found, from an ENV var.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
