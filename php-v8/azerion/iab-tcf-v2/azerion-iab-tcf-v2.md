# azerion/iab-tcf-v2

> 标签: TCF, consent, consent-string, gdpr, iab, tcf-v2

## 简介

IAB TCF v2.x consent string decoder and encoder for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
