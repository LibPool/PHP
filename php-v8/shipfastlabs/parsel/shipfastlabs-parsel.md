# shipfastlabs/parsel

> 标签: OCR, anydoc, document, driver, lit, liteparse, parser, pdf, php

## 简介

An expressive, driver-based PHP API for local and remote document parsers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
