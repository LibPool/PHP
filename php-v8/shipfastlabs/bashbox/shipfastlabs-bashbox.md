# shipfastlabs/bashbox

> 标签: agents, ai, bash, interpreter, sandbox

## 简介

A sandboxed bash interpreter for AI agents, written in pure PHP 8.4+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
