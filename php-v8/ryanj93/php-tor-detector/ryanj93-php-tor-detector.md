# ryanj93/php-tor-detector

> 标签: proxy, security, tor, utilities, validator

## 简介

A very simple library to detect Tor connections using PHP 7 without any dependency.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
