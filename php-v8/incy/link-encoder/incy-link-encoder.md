# incy/link-encoder

> 标签: AES-GCM, deeplink, encryption, incy, vpn

## 简介

Encode subscription URLs into incy://crypt1/<payload> deep links (PHP port of @incy/link-encoder). AES-256-GCM with a key shared with the INCY iOS/Android/Desktop clients.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
