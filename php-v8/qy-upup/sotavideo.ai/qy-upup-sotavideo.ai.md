# qy-upup/sotavideo.ai

> 标签: PHP

## 简介

A professional PHP library for seamless integration with the sotavideo.ai platform, enabling efficient access to its video processing and analysis capabilities.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
