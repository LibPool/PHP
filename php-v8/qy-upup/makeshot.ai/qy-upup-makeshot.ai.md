# qy-upup/makeshot.ai

> 标签: PHP

## 简介

A robust PHP library providing seamless integration with the makeshot.ai API for automated screenshot generation and manipulation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
