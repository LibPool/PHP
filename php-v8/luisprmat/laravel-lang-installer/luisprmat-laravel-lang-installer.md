# luisprmat/laravel-lang-installer

> 标签: lang, laravel, translator

## 简介

Install translations from laravel-lang/lang package for Laravel 7 or higher

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
