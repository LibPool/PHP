# davos/graphy

> 标签: Metrics, graph, monitoring, rrd, rrdtool, timeseries

## 简介

A PHP abstraction layer for creating, updating, and fetching RRDTool databases with fluent model-based APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
