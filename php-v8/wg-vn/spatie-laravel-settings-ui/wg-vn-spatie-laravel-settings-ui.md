# wg-vn/spatie-laravel-settings-ui

> 标签: Settings, admin, blade, laravel, laravel-package, laravel-settings, spatie, ui

## 简介

A plain Blade admin UI for Spatie's Laravel Settings. No Filament, no Livewire, no build step.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
