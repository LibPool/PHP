# genaker/imageaibundle

> 标签: Gemini, Webp, ai-image, image-cache, image-optimization, image-processing, image-resize, magento, magento2, magento2-module

## 简介

Magento 2 module for intelligent image resizing with caching and AI-powered image modification support using Google Gemini API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
