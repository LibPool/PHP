# genaker/oro-commerce-log-stat-viewer

> 标签: OroCommerce, admin, bundle, log viewer, performance dashboard, symfony

## 简介

OroCommerce admin bundle — Log Viewer and Performance Dashboard with real-time metrics, live tail, grep, and multi-instance support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
