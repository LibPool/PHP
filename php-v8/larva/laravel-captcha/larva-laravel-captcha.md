# larva/laravel-captcha

> 标签: Larva, captcha, gd, imagick, laravel

## 简介

A simple captcha package for Laravel, supporting GD and ImageMagick libraries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
