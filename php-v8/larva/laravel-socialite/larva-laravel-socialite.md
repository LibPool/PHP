# larva/laravel-socialite

> 标签: alipay, baidu, larvacms, qq, socialite, wechat, weibo

## 简介

Laravel wrapper around OAuth 2 libraries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
