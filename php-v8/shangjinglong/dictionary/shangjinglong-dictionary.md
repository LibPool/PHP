# shangjinglong/dictionary

> 标签: database, laravel, lumen, mysql

## 简介

A toolkit that generates a database dictionary package for the Laravel and Lumen frameworks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
