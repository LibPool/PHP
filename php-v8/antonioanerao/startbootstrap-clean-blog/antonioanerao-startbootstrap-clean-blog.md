# antonioanerao/startbootstrap-clean-blog

> 标签: PHP

## 简介

Tema WordPress usando o Startbootstrap Clean Blog, com Widgets, barra lateral e comentários nativos do WP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
