# hainuo/think-rbac

> 标签: auth, rbac, thinkphp

## 简介

基于 zouxiang0639/thinkcms-auth 制作的通用权限管理系统，支持thinkphp5.0最新版本

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
