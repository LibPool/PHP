# plug-and-pay/sdk-php

> 标签: IMu, Internet Marketing Unie, PlugAndPay

## 简介

This is a PHP SDK to make easier to communicate with the Plug&Pay API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
