# hovjacky/nosql

> 标签: elasticsearch, nosql

## 简介

PHP Client for Elasticsearch (MongoDB and Cassandra are almost finished) - easy and unified queries

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
