# gwinto/reava-pay

> 标签: PHP

## 简介

Reava Pay integration for Gwinto - Multi-tenant rental management, wallet sync, merchant onboarding & payment collection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
