# seba1rx/tabmanager

> 标签: isolation, per-tab, php, session, tab, uuid

## 简介

Per-tab PHP session isolation — each browser tab gets its own namespaced $_SESSION slot via a UUIDv4 header

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
