# freeframework/developerauth-page-service

> 标签: Authentication, developer, freeframework, no database, page-service, php8, register

## 简介

A one-page service for registering a developer with FreeFramework. Without using a database.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
