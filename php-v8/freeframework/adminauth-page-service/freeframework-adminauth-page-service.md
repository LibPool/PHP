# freeframework/adminauth-page-service

> 标签: Authentication, admin, e-mail, freeframework, no database, page-service, php8, register

## 简介

A one-page service for registering an administrator in FreeFramework. With the ability to recover your password by mail. Without using a database

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
