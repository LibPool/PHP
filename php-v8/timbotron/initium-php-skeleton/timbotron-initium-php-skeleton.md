# timbotron/initium-php-skeleton

> 标签: PHP

## 简介

Boilerplate app for InitiumPHP: a small PHP starter with turnkey user authentication. Create a project from this, fill in config, and go.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
