# kartik-v/mpdf

> 标签: pdf, php, utf-8

## 简介

A PHP class to generate PDF files from HTML with Unicode/UTF-8 and CJK support. This is a fork of the official mPDF library.

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
