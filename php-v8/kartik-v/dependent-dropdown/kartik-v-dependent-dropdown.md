# kartik-v/dependent-dropdown

> 标签: dependent, dropdown, jquery, option, select

## 简介

A multi level dependent dropdown JQuery plugin that allows nested dependencies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
