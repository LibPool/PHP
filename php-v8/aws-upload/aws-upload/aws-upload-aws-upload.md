# aws-upload/aws-upload

> 标签: aws, cli, ec2, rsync, upload

## 简介

aws-upload - A delicious CLI Tool for uploading files to ec2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
