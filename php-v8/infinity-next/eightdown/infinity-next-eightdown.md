# infinity-next/eightdown

> 标签: PHP

## 简介

Eightdown is a Markdown implementation for Laravel that adds optional features imageboard users will be familiar with.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
