# rathil/yii2-mongodb

> 标签: active-record, mongo, mongodb, yii2

## 简介

Advanced original driver for working with MongoDB in Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
