# yahyaerturan/audit-codeigniter4

> 标签: Audit, adapter, audit-trail, codeigniter4

## 简介

CodeIgniter 4 adapter for the yahyaerturan/audit immutable audit-trail library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
