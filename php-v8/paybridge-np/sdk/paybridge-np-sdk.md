# paybridge-np/sdk

> 标签: esewa, gateway, khalti, nepal, paybridge, payment

## 简介

Official PHP SDK for PayBridgeNP — the payment gateway for Nepal

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
