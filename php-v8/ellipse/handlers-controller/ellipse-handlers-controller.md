# ellipse/handlers-controller

> 标签: PSR-11, controller, psr-15, request-handler

## 简介

Psr-15 request handler proxying a class method using a Psr-11 container entry

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
