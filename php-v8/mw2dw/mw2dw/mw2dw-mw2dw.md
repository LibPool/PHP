# mw2dw/mw2dw

> 标签: convert, dokuwiki, mediawiki, migrate, wiki

## 简介

Convert content in a MediaWiki installation to DokuWiki

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
