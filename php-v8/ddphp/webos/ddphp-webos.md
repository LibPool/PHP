# ddphp/webos

> 标签: ddphp, framework, laravel, webos

## 简介

基于 Laravel 5.3 的东大微信公众号管理系统。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
