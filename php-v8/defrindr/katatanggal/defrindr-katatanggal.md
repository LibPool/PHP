# defrindr/katatanggal

> 标签: PHP

## 简介

Kata tanggal adalah sebuah library untuk mengubah tanggal kedalam sebuah teks bahasa Indonesia.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
