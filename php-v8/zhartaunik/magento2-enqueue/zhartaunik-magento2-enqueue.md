# zhartaunik/magento2-enqueue

> 标签: AMQP, amazon-sqs, beanstalk, gearman, google-pubsub, kafka, magento, magento2, messaging, queue, rabbitmq, redis, sqs

## 简介

Message Queue solutions for Magento2. Supports RabbitMQ, AMQP, STOMP, Amazon SQS, Kafka, Redis, Google PubSub, Gearman, Beanstalk, Google PubSub

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
