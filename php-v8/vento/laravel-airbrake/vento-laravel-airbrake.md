# vento/laravel-airbrake

> 标签: airbrake, laravel, logging

## 简介

Laravel service provider for Airbrake https://github.com/airbrake/phpbrake

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
