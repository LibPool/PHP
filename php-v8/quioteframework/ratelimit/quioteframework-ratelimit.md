# quioteframework/ratelimit

> 标签: quiote, rate-limiting, security

## 简介

Rate limiting (login throttle, PDO-backed limiter storage) for Quiote, built on symfony/rate-limiter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
