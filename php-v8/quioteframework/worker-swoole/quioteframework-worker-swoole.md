# quioteframework/worker-swoole

> 标签: psr-7, quiote, runtime, swoole, worker

## 简介

Swoole worker runtime for Quiote, serving the app from an embedded Swoole HTTP server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
