# quioteframework/mcp

> 标签: mcp, model-context-protocol, quiote

## 简介

MCP (Model Context Protocol) server capability for Quiote -- expose Quiote actions/tools over MCP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
