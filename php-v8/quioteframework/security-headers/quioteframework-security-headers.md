# quioteframework/security-headers

> 标签: csp, headers, quiote, security

## 简介

Security response headers (CSP, X-Frame-Options, HSTS, etc.) middleware for Quiote.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
