# quioteframework/quiote-mcp-assistant

> 标签: PHP

## 简介

MCP server giving AI agents authoritative knowledge of, and read-only/scaffolding access to, Quiote applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
