# quioteframework/xslt

> 标签: quiote, renderer, template, xslt

## 简介

XSLT (.xsl) template renderer for Quiote, built on ext-xsl/ext-dom.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
