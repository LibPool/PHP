# quioteframework/db-propulsion

> 标签: database, orm, propel, propulsion, quiote

## 简介

Propulsion (Propel 1 fork) driver adapter for Quiote's database layer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
