# quioteframework/quiote

> 标签: framework, mvc

## 简介

Quiote is a full-featured MVC-style framework for PHP 8.5+ with a strong focus on structure, code reusability and flexibility.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
