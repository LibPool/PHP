# overtrue/chinese-calendar

> 标签: Chinese, calendar, lunar, lunar2solar, solar, solar2lunar

## 简介

中国农历（阴历）与阳历（公历）转换与查询工具

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
