# foundershub/foundershub-startupweekend-bundle

> 标签: Symfony2, bundle

## 简介

Symfony2 bundle containing the FoundersHub RheinMain StartupWeekend public website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
