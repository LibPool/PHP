# shapecode/imagine-thumbnail-gravity-filter

> 标签: filter, gravity, imagine, shapecode, tenolo, thumbnail

## 简介

Simple extension for imagine to enable thumbnail gravity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
