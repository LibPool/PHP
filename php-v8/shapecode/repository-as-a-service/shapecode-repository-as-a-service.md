# shapecode/repository-as-a-service

> 标签: bundle, doctrine, repository, service, shapecode, symfony

## 简介

Symfony2 Bundle which you can register repositories easily.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
