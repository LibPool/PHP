# framecreative/frame-media

> 标签: PHP

## 简介

Serves image variants from the Frame Media Kit worker: URL rewriting, Twig helpers, WP-CLI, face-detection ping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
