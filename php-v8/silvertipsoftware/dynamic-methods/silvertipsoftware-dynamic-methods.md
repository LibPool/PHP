# silvertipsoftware/dynamic-methods

> 标签: PHP

## 简介

Add dynamically attached methods to any class. Binding variation requires 5.4 and above

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
