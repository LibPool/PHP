# kovacs-laci/laravel-skeletons

> 标签: API generator, code generation, composer, crud generator, laravel, laravel command, migration, package, scaffolding, skeletons

## 简介

An artisan command to make skeletons with ready from box content for a Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
