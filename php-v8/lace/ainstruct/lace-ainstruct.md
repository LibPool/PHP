# lace/ainstruct

> 标签: agents, ai, aider, claude, cline, cursor, instructions, windsurf

## 简介

AI Instructions CLI — distribute per-framework AI instruction sets (AGENTS.md, CLAUDE.md, GEMINI.md, Cursor, Windsurf, Cline, Continue, Aider) into a consumer project from the current directory.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
