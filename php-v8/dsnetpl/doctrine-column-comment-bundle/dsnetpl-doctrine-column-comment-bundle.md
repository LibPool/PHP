# dsnetpl/doctrine-column-comment-bundle

> 标签: PHP

## 简介

Modifying doctrine metadata so that doctrine knows that columns in the database have additional information - a comment.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
