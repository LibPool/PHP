# damarbob/stardust

> 标签: dynamic-fields, json, mariadb, mysql, schema-partitioning, stardust, vertical-partitioning

## 简介

MySQL & MariaDB-native, framework-neutral Vertical Schema Partitioning engine for dynamic data models. Zero runtime framework dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
