# qadrlabs/php-rupiah

> 标签: IDR, currency, formatter, indonesia, php, rupiah

## 简介

A lightweight PHP library to format and parse Indonesian Rupiah (IDR) currency values.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
