# samuelbie/mzmsisdn

> 标签: movitel, msisdn, msisdn mozambique, tmcel, vodacom

## 简介

An MSISDN identification and cleaner library for Mozambique subscribers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
