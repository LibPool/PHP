# vergil-lai/oss-flysystem

> 标签: Flysystem, aliyun, filesystem, oss

## 简介

Flysystem adapter for Alibaba Cloud OSS using the OSS PHP SDK v2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
