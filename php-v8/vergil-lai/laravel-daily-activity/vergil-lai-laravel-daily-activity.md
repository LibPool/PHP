# vergil-lai/laravel-daily-activity

> 标签: bitmaps, laravel, laravel-daily-activity

## 简介

Track daily activities and streaks with compact yearly bitmaps for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
