# zenkilies/igdb-laravel

> 标签: api-wrapper, apicalypse, igdb, igdb-api, laravel, wrapper

## 简介

A Laravel Wrapper for the IGDB API v3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
