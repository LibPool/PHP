# codelight-eu/acf-simple-wysiwyg

> 标签: PHP

## 简介

WordPress plugin which creates a new ACF Wysiwyg field type with very limited controls.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
