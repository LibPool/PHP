# giginc/cakephp5-driver-mongodb

> 标签: cakephp, cakephp5, datasource, driver, mongodb, orm, plugin

## 简介

MongoDB datasource driver for CakePHP 5 (modern successor to giginc/mongodb).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
