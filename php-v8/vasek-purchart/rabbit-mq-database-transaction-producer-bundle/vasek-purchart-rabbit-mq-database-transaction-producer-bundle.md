# vasek-purchart/rabbit-mq-database-transaction-producer-bundle

> 标签: PHP

## 简介

Publish messages to RabbitMQ producer when database transaction was committed

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
