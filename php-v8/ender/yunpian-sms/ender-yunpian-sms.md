# ender/yunpian-sms

> 标签: duanxin, php, sms

## 简介

A php SDK for yunpian(云片网络短信服务商) sms RESTFULL API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
