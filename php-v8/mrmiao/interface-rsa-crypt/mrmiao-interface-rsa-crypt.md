# mrmiao/interface-rsa-crypt

> 标签: PHP

## 简介

Encrypt the JSON-type interface request and return data by using the RSA algorithm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
