# rainwaves/scale-monitor-client

> 标签: PHP

## 简介

Laravel client for Code Scale Tech's Scale Monitor: signed heartbeat/error/failed-job/deployment/metric/custom-event telemetry, a deep-health endpoint with pluggable checks, and an exception-handler hook. Fails open by design.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
