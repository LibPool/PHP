# d3creative/statamic-sentinel

> 标签: PHP

## 简介

Sentinel by D3 Creative - Platform and dependency audits for Statamic sites. Sentinel surfaces PHP version, Statamic version, and known package vulnerabilities in the Control Panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
