# helsingborg-stad/coordinate-transformation-library

> 标签: PHP

## 简介

Transform coordinates between swedish RT90, SWEREF99 and WGS8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
