# helsingborg-stad/wpmu-acf-fatal-error-when-used-too-early

> 标签: PHP

## 简介

Throws a descriptive exception when an ACF field is accessed before WordPress has initialized.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
