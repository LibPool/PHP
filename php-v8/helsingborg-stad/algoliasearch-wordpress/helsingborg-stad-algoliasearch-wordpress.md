# helsingborg-stad/algoliasearch-wordpress

> 标签: PHP

## 简介

Forked version of algolia Search plugin for Wordpress. Fixes some issues, for more information see feature branches in git-repository.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
