# helsingborg-stad/material-design-icons-json-svg-font-reduced

> 标签: PHP

## 简介

Reduced Material Symbols assets for Helsingborgs stad: outlined, rounded and sharp SVGs at weights 200, 400 and 600, plus variable WOFF2 fonts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
