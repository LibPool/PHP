# helsingborg-stad/wpmu-network-admin-url

> 标签: PHP

## 简介

Fixes network url's when running WordPress as multisite in a composer installed wp instance.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
