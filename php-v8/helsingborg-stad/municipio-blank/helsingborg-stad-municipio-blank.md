# helsingborg-stad/municipio-blank

> 标签: PHP

## 简介

A blank WordPress theme that redirects to the wp-json API. Use when a site is only used as a backend API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
