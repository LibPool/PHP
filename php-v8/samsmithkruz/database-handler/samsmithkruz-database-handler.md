# samsmithkruz/database-handler

> 标签: database, database handler, mongodb, mysql, orm, php, postgresql, redis

## 简介

A reusable database handler supporting SQL & NoSQL.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
