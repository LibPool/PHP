# dreammiu/zm-chat-gpt

> 标签: PHP

## 简介

这是一个基于炸毛v3.1.1开发的ChatGPT插件，他能通过炸毛方便在支持OneBotV12平台上使用

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
