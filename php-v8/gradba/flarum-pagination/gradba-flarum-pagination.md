# gradba/flarum-pagination

> 标签: discussion, flarum, pagination, posts

## 简介

Real page-number pagination for Flarum — for both the discussion list and the post stream inside a discussion.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
