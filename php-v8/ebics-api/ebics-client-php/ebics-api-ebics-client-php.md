# ebics-api/ebics-client-php

> 标签: cfonb.120, cfonb.240, client, ebics, mt940, mt942, openssl, php, rsa, x509

## 简介

PHP library to communicate with bank through EBICS protocol.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
