# doctrine/phpcr-odm

> 标签: content, data, mapper, mapping, object, odm, php

## 简介

PHP Doctrine Content Repository Object Document Mapper (ODM) provides transparent persistence for PHP objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
