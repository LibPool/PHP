# doctrine/dbal

> 标签: SQL, abstraction, database, db2, dbal, mariadb, mssql, mysql, oci8, oracle, pdo, pgsql, postgresql, queryobject, sasql, sql, sqlite, sqlserver, sqlsrv, 数据库

## 简介

Powerful PHP database abstraction layer (DBAL) with many features for database schema introspection and management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
