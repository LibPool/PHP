# doctrine/phpcr-dbal-symfony-pack

> 标签: PHP

## 简介

Symfony package repository to install dbal implementation of doctrine/phpcr-bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
