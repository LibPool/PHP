# doctrine/lexer

> 标签: annotations, docblock, lexer, parser, php, 解析, 词法

## 简介

PHP Doctrine Lexer parser library that can be used in Top-Down, Recursive Descent Parsers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
