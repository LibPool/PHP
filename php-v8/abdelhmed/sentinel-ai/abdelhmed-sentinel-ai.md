# abdelhmed/sentinel-ai

> 标签: Gemini, ai, debugging, errors, exceptions, laravel

## 简介

AI-powered error dashboard for Laravel: captures exceptions, explains them with Gemini and generates tests on demand.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
