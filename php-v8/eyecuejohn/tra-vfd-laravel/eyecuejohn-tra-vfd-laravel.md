# eyecuejohn/tra-vfd-laravel

> 标签: PHP

## 简介

Professional Laravel package for Tanzania Revenue Authority (TRA) VFD API integration integration with thermal PDF receipt support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
