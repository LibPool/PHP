# platine-php/router

> 标签: application, development, framework, handler, middleware, php, platine, request, route, router, website

## 简介

Platine Router is the a lightweight and simple router using middleware to match and dispatch the request.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
