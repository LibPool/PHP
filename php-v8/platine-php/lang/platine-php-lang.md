# platine-php/lang

> 标签: application, framework, i18n, internationalization, language, localization, php, platine, storage, translation

## 简介

Platine Lang is a translation library with extensible translator and storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
