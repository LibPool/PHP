# ruvelo/laravel-device

> 标签: bot, browser, client-hints, crawler, device-detection, jenssegers-agent, laravel, mobile, tablet, user-agent, useragent

## 简介

Device, browser, OS and bot detection for Laravel, with User-Agent Client Hints and a drop-in replacement for jenssegers/agent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
