# ruvelo/laravel-inbox

> 标签: bell, inbox, laravel, notification-center, notifications, preferences

## 简介

The in-app notification inbox Laravel never shipped: a header bell, an inbox page and per-type preferences, on top of the database notification channel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
