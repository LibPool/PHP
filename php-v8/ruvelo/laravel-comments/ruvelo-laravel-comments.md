# ruvelo/laravel-comments

> 标签: comments, eloquent, laravel, markdown, moderation, reactions, threads

## 简介

Free, polished comments for any Eloquent model: threads, Markdown, reactions, mentions and moderation. Blade or JSON, no Livewire required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
