# ruvelo/laravel-help-center

> 标签: FAQ, documentation, help-center, knowledge-base, laravel, markdown, support

## 简介

A public help center for Laravel: FAQ and knowledge base with categories, instant search, "Was this helpful?" feedback and an editor with live preview.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
