# godjarvis/phalcon-sse

> 标签: phalcon, rabbitmq, redis-stream, server-sent-events, sse

## 简介

A Server-Sent Events component for Phalcon 3.4 with Redis Stream and optional RabbitMQ drivers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
