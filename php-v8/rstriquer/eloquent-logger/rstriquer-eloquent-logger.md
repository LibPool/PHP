# rstriquer/eloquent-logger

> 标签: debugger, dev, eloquent, laravel, laravel-dev, logger

## 简介

Write SQL queries to a file into Laravel "storage/logs" directory.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
