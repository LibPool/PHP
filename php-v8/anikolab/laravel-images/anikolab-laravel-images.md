# anikolab/laravel-images

> 标签: Webp, avif, images, laravel, medialibrary, picture, srcset

## 简介

Responsive images for Laravel: presets, master copies, AVIF/WebP/JPEG variants on GD and one <x-picture> component for static photos and medialibrary uploads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
