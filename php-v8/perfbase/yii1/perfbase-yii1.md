# perfbase/yii1

> 标签: Perfbase, Yii1, apm, monitoring, profiling, yii

## 简介

Yii 1.1 integration for the Perfbase profiling tool.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
