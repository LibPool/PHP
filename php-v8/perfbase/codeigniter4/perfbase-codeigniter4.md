# perfbase/codeigniter4

> 标签: Perfbase, apm, codeigniter, codeigniter4, monitoring, profiling

## 简介

CodeIgniter 4 integration for the Perfbase profiling tool.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
