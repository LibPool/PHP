# shaunhare/meetup-cache

> 标签: meetup, phpminds

## 简介

package for intercepting calls from DMS\Service\Meetup and reading/writing response to filesystem written for phpminds

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
