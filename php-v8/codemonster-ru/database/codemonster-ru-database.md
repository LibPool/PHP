# codemonster-ru/database

> 标签: codemonster, database, database-manager, db-layer, framework-agnostic, migration-runner, migrations, mysql, orm-like, pdo, php-database, query, query-builder, schema, sql

## 简介

Lightweight, framework-agnostic database layer with PDO connections, fluent Query Builder, Schema Builder, and full migration system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
