# quansitech/cmf-module-media

> 标签: PHP

## 简介

QS CMF 媒体模块：TOS/OSS/COS 浏览器直传、内容哈希去重（秒传）、引用计数与归零自动清理、后台媒体管理

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
