# quansitech/cmf-module-area

> 标签: PHP

## 简介

QS CMF 行政区划模块：内置四级行政区划数据（省市区乡镇）、业务引用登记（merge_strategy）、上游变更 AI 升级流水线（diff → 判读 → 校验 → 延迟绑定迁移）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
