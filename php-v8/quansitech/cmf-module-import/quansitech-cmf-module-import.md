# quansitech/cmf-module-import

> 标签: cmf, excel, filament, import, openspout, template, xlsx

## 简介

QS CMF 导入扩展：Filament v5 ImportAction 的 xlsx 增强——仅 xlsx 导入（单元格归一与可疑值行级拒绝）、xlsx 模板生成（文本锁定/长度/下拉）、失败清单 xlsx 导出

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
