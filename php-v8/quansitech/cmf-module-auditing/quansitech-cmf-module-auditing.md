# quansitech/cmf-module-auditing

> 标签: PHP

## 简介

QS CMF 审计模块：操作审计后台（中文版 AuditResource）、回滚 Action、自定义审计事件支持

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
