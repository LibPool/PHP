# sdavis1902/eloquent-vars

> 标签: EloquentVars, sdavis1902

## 简介

Add ability to save additional fields or Vars on a Laravel model without a specific db column for it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
