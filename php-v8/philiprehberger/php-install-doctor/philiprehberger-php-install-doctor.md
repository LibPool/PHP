# philiprehberger/php-install-doctor

> 标签: check, diagnostic, doctor, extensions, php

## 简介

CLI diagnostic tool that checks PHP extensions, permissions, and configuration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
