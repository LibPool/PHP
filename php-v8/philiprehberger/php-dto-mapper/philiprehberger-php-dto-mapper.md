# philiprehberger/php-dto-mapper

> 标签: casting, data-transfer, dto, hydration, mapper

## 简介

Map arrays and JSON to strongly-typed DTOs with attribute-driven configuration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
