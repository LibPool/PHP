# philiprehberger/php-uuid-tools

> 标签: database, ordered, uuid, v4, v7, validation

## 简介

UUID v4 and v7 generation, validation, and ordered UUIDs for database indexing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
