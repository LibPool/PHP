# vsavritsky/monolog-telegram

> 标签: bot, log, logging, monolog, telegram

## 简介

Monolog handler that sends logs through Telegram bot to any chat in HTML format

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
