# toolcenter/sdk

> 标签: api, automation, pdf, qr-code, screenshot, sdk, toolcenter, web

## 简介

Official PHP SDK for ToolCenter API - Web automation tools including screenshots, PDFs, QR codes, metadata extraction, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/toolcenter-dev/sdk-php.git
