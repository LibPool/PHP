# arnipay/sdk-php

> 标签: PHP

## 简介

SDK for integrating with the Arnipay payment processing system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/arnipay/sdk-php
- 源码仓库：https://github.com/arnipay/sdk-php.git
- Packagist 页面：https://packagist.org/packages/arnipay%2Fsdk-php
