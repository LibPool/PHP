# jalendport/craft-metronome

> 标签: Craft, Tasks, cms, craft-plugin, craftcms, cron, crontab, scheduler

## 简介

Laravel-style task scheduling for Craft CMS: one crontab entry, everything else in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
