# jalendport/craft-hideadmin

> 标签: Craft, cms, craft-plugin, craftcms, hide admin

## 简介

Hide admin users from non-admin users

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
