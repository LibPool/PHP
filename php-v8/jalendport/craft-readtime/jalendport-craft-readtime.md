# jalendport/craft-readtime

> 标签: Craft, average read time, cms, craft-plugin, craftcms

## 简介

Estimated read times for Craft CMS entries, counting every field and nested block.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
