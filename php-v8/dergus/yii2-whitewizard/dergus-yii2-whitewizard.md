# dergus/yii2-whitewizard

> 标签: Forms, extension, multipart, multistep, yii2

## 简介

A Yii2 extension for easy handling multistep forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
