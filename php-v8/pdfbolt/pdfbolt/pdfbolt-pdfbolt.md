# pdfbolt/pdfbolt

> 标签: html-to-pdf, pdf, pdf-generation, pdfbolt, php, sdk, url-to-pdf, webhook

## 简介

Official PHP SDK for the PDFBolt API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
