# awanesia/sendgrid-4.0.4

> 标签: email, grid, send, sendgrid 4.0.4

## 简介

This library allows you to quickly and easily send emails through SendGrid using PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
