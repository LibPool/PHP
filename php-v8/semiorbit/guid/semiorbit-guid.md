# semiorbit/guid

> 标签: DCE UUID, GUID PHP, Microsoft .NET GUID, guid

## 简介

Generate a GUID in PHP that is compatible with  Microsoft .NET Framework (C#) GUID.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
