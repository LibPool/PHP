# cangelis/l4pdf

> 标签: html to pdf, laravel4, pdf, pdf converter, wkhtmltopdf

## 简介

Yet another HTML to PDF Converter for Laravel4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
