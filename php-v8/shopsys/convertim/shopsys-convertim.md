# shopsys/convertim

> 标签: SSFW, Shopsys Platform, checkout, convertim, integration

## 简介

A Symfony bundle to integrate Convertim into Shopsys Platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
