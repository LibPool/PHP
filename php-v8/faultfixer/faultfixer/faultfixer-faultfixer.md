# faultfixer/faultfixer

> 标签: error-tracking, faultfixer, monitoring, php

## 简介

FaultFixer error monitoring SDK for PHP — built on sentry/sentry (MIT).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
