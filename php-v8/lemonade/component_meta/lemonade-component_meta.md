# lemonade/component_meta

> 标签: dublin-core, html, lemonade, meta, opengraph, seo, tags, twitter

## 简介

A lightweight PHP library for generating SEO & social meta tags (HTML <meta>, OpenGraph, Twitter Cards, DC tags, …).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
