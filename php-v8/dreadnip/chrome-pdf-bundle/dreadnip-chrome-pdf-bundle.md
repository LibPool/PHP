# dreadnip/chrome-pdf-bundle

> 标签: chrome, chromium, pdf, symfony

## 简介

A wrapper around chrome-php/chrome to generate PDFs in Symfony projects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
