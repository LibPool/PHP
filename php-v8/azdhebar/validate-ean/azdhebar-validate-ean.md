# azdhebar/validate-ean

> 标签: azdhebar, validate-ean

## 简介

Validate EAN is a package which provides laravel validation extension to validate ean 8 and ean 13

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
