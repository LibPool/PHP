# blok/laravel-cms

> 标签: Blok, cms, laravel, strapi, wordpress

## 简介

A CMS Laravel opinionated data layer to handle your Headless CMS like Strapi, Wordpress etc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
