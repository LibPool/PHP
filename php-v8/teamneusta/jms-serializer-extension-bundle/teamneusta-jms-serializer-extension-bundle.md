# teamneusta/jms-serializer-extension-bundle

> 标签: PHP

## 简介

Extends the JMS Serializer Bundle to allow loading serializer configuration while ignoring the namespace prefixes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
