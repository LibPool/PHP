# victor.diaz/se-response-formater-soap

> 标签: PHP

## 简介

Este proyecto cambia el formato de respuesta que nos devuelven las aseguradoras que implementan SOAP y los transforma en uno que Softexpert si puede interpretar.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
