# panwenbin/laravel-u-editor

> 标签: laravel, laravel-u-editor, laravel5 web text editor, steven yang, stevenyangecho, ueditor

## 简介

UEditor for laravel. Support i18n. UEditor is a Rich Text Web Editor From Baidu.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
