# odinns/phpstan-pest-this

> 标签: PHPStan, pest, static-analysis, testing

## 简介

PHPStan extensions to infer Pest closure $this type from test file mappings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
