# shali/ydb-think-2fa

> 标签: 2fa, thinkphp, two factor auth, two-factor-auth

## 简介

this is a two factor auth tool for thinkphp 5,6.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
