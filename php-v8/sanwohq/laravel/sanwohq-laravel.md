# sanwohq/laravel

> 标签: Interswitch, flutterwave, laravel, monnify, payments, paystack, razorpay, sanwo

## 简介

Sanwo payment SDK for Laravel — Blade components for Paystack, Flutterwave, Razorpay, Monnify, Interswitch, and custom providers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
