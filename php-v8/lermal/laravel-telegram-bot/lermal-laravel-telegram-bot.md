# lermal/laravel-telegram-bot

> 标签: Telegram-Bot-API, bot, laravel, telegram

## 简介

Laravel package for Telegram Bot API interactions with webhook and polling support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
