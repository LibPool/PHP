# baril/smoothie

> 标签: adjacency list, attribute aliases, attribute mapping, closure table, closures, database, dates with zeros, eloquent, fuzzy dates, hierarchy, laravel, mutual relationship, nested sets, orderable, reciprocal relationship, sortable, tree

## 简介

Some fruity additions to Laravel's Eloquent: fuzzy dates, mutual many-to-many relationships, orderable behavior, closure tables.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
