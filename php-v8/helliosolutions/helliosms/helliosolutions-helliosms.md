# helliosolutions/helliosms

> 标签: bulk sms in Ghana, hellio messaging, laravel channel notification package, laravel integration sms, laravel notification package, laravel otp package, laravel sms, laravel ussd package, laravel voice sms package, sms laravel package, ussd ghana

## 简介

Official Laravel SDK for the Hellio Messaging API v1 (SMS, OTP, Voice, Number Lookup, Email Verification, USSD, Webhooks).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
