# proudcommerce/voucherlimit

> 标签: PHP

## 简介

Begrenzung von Gutscheinen auf einen maximalen Einkaufswert.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
