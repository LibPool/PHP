# tobento/app-translation-web

> 标签: app, package, tobento, translation, translator, ui

## 简介

A web interface for managing, editing, importing, exporting, collecting and publishing translations across multiple applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
