# tobento/service-responser

> 标签: Flash input data, PSR-7 response, flash messages, package, php, tobento

## 简介

Providing PSR-7 response wrapper classes with simplified methods.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
