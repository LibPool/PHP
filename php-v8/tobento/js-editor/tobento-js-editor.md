# tobento/js-editor

> 标签: html editor, tobento, wysiwyg

## 简介

Simple JavaScript WYSIWYG HTML Editor with inlined toolbar only.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
