# msurkov16/ntlm-soap-client

> 标签: matejsvajger, ntlm-soap-client

## 简介

PHP WDSL/Soap Client with NTLM Authentication for Microsoft Dynamics NAT Server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
