# prezent/doctrine-translatable-bundle

> 标签: bundle, doctrine, extensions, i18n, symfony, translatable

## 简介

Integrate the doctrine-translatable extension in Symfony

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
