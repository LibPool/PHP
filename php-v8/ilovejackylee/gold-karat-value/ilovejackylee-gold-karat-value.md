# ilovejackylee/gold-karat-value

> 标签: calculator, finance, gold, jewelry, karat

## 简介

Estimate gold melt and scrap value from karat, weight, and a 24K price per gram.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
