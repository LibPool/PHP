# ilovejackylee/make-image-square

> 标签: aspect-ratio, image, layout, padding, square

## 简介

Compute square canvas size and letterbox padding so an image fits 1:1 without cropping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
