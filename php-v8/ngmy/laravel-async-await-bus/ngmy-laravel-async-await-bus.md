# ngmy/laravel-async-await-bus

> 标签: Query Bus, bus, command bus, cqrs, laravel

## 简介

A Laravel bus decorator that allows to await asynchronous command responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
