# do1emu/module-ekkon

> 标签: Tasks, intranet, laravel, scheduler

## 简介

Übergangspaket ohne Code: Ekkon (Task-System, Benachrichtigungen, Webhook-Eingang) ist fester Bestandteil der Intranet-Plattform. Das Paket erfüllt nur noch bestehende require-Einträge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
