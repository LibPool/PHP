# do1emu/module-newsletter

> 标签: intranet, laravel, mail, modul, newsletter

## 简介

Newsletter-Modul für die modulare Intranet-Plattform: Rundmails an ausgewählte Benutzerrollen, gedrosselt über den Ausgangskorb des Core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
