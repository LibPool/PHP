# do1emu/module-schulzeugnis

> 标签: intranet, laravel, modul, schulzeugnis, waldorf, zeugnis

## 简介

Schulzeugnis-Modul für die modulare Intranet-Plattform (Waldorfschule): Textzeugnisse und Abschluss-Notenzeugnisse, je Schuljahr importierbare Stammdaten, vollständig vom Core entkoppelt.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
