# do1emu/module-userimport

> 标签: Users, import, intranet, laravel, modul

## 简介

Benutzer-Import-Modul für die modulare Intranet-Plattform: CSV-Import mit Rollen und Einladungslink. https://github.com/kleinebekele/intranet-core

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
