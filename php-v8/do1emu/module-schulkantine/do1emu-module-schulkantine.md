# do1emu/module-schulkantine

> 标签: intranet, kantine, laravel, modul, schulkantine

## 简介

Schulkantine-Modul für die modulare Intranet-Plattform: Saison-Kalender, Speiseplan, Vorbestellung, Ausgabe und Abrechnung – mit der Besonderheit, dass Eltern für ihre Kinder bestellen.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
