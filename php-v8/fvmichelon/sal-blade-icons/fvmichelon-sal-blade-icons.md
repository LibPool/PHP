# fvmichelon/sal-blade-icons

> 标签: blade, icons, laravel, sal, svg

## 简介

Blade Icons package with regular (real stroke), fill, and duotone families. Based on Phosphor Icons (MIT).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
