# uteek/log-tracker-sdk

> 标签: error-tracking, logging, monitoring, uteek

## 简介

PHP SDK for UTEEK Log Tracker – capture and send logs to the UTEEK Node.js backend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
