# hankchen/php-canvas-pdf-renderer

> 标签: canvas, pdf, renderer, tfpdf

## 简介

tFPDF-based PDF renderer backend for hankchen/php-canvas-next

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
