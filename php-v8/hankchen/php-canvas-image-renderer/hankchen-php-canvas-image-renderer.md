# hankchen/php-canvas-image-renderer

> 标签: canvas, gd, image, imagick, intervention-image

## 简介

intervention/image v4 bitmap renderer backend for hankchen/php-canvas-next

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
