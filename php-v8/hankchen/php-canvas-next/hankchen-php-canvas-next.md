# hankchen/php-canvas-next

> 标签: Rendering, canvas, layer, layout, qr-code

## 简介

next generation of php-canvas: layer tree (pure structure) + pluggable renderers (image now, pdf later)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
