# rhdevelopment/arg-parser

> 标签: args, arguments, cli, php, rhDevelopment

## 简介

Small, easy-to-use CLI argument parsing helpers for PHP scripts and cron tools.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
