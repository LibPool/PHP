# rhdevelopment/inflecta

> 标签: case-conversion, inflector, php, pluralize, slugify, string

## 简介

Inflecta: lightweight string inflector utilities for modern PHP projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
