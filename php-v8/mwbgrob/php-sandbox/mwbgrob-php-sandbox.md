# mwbgrob/php-sandbox

> 标签: blacklist, parser, php, sandbox, whitelist

## 简介

A PHP library that can be used to run PHP code in a sandboxed environment

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
