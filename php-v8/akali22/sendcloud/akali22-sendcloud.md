# akali22/sendcloud

> 标签: api, client, jouwweb, parcel, sendcloud, webhook

## 简介

Provides a client to interact with the Sendcloud API in an object-oriented way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
