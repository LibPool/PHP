# drupal-spider/drupalsecurity

> 标签: code review, drupal, phpcs, security, standards

## 简介

Drupal Security is a library to review security issue of Drupal code.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
