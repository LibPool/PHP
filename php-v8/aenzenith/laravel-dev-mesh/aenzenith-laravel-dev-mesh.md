# aenzenith/laravel-dev-mesh

> 标签: dashboard, development, horizon, laravel, scheduler, terminal, tui

## 简介

Run Horizon, the scheduler and other long-running artisan services of several Laravel projects from one live terminal dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
