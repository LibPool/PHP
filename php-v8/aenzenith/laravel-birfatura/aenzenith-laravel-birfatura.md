# aenzenith/laravel-birfatura

> 标签: E-Invoice, birfatura, e-arşiv, e-fatura, integration, invoice, laravel, turkey

## 简介

BirFatura "Özel Entegrasyon" (custom integration) server for Laravel: registers the endpoints BirFatura pulls orders from, authenticates its token, and turns typed order data into the exact JSON contract. Laravel 11 through 13, PHP 8.2+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
