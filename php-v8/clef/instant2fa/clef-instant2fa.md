# clef/instant2fa

> 标签: 2fa, Authentication, api, otp, two factor

## 简介

A PHP client for Instant2FA.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://instant2fa.com
- 源码仓库：https://github.com/clef/instant2fa-php.git
- Packagist 页面：https://packagist.org/packages/clef%2Finstant2fa
