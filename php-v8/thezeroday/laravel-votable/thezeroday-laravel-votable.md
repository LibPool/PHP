# thezeroday/laravel-votable

> 标签: 0Day, laravel, laravel-votable

## 简介

This package enables seamless implementation of likes and dislikes functionality in Laravel-based projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
