# hz-hbo-ict/laravel-core-ui

> 标签: PHP

## 简介

Easy to use package with authentication scaffold that provides an easy implementation of CoreUI within Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
