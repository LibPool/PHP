# saeidsharafi/filament-otp-auth

> 标签: Authentication, email, filament, laravel, login, otp, sms

## 简介

A Filament plugin for user login using email/phone and OTP verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
