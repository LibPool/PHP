# jayalfredprufrock/winx

> 标签: PHP

## 简介

An ajax-powered app framework built on top of Codeigniter 3 and Bootstrap 3, installable via composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
