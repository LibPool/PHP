# roky/laravel-route-analytics

> 标签: analytics, laravel, monitoring, performance, routes

## 简介

Dead-simple route usage tracking for Laravel — find unused and slow routes in minutes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
