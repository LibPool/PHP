# amrikasir/ziggy

> 标签: PHP

## 简介

Generates a Blade directive exporting all of your named Laravel routes. Also provides a nice route() helper function in JavaScript.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
