> 标签: Gemini, api, gemini-api, gemini-client, generative-ai, google, google-gemini, php

## 简介

A lightweight, efficient, custom PHP Client for seamless Google Gemini API integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
