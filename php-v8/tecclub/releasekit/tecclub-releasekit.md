# tecclub/releasekit

> 标签: app-updates, downloads, laravel, releasekit, releases, tecclub, version-check

## 简介

Headless Laravel package for managing app releases, build artifacts, downloads, and version checks across platforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
