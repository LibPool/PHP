# idno/flickr

> 标签: PHP

## 简介

Cross-post site content to Flickr. Contains <a href="https://github.com/lucasgd/DPZFlickr">a version of David Wilkinson's Flickr class</a>.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
