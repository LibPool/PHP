# anchorcms/anchor-cms

> 标签: anchor, anchorcms, cms

## 简介

Anchor is a free, lightweight, faster-than-a-bullet, simple blogging system, made for art–directed posts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
