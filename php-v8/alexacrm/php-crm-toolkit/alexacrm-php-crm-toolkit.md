# alexacrm/php-crm-toolkit

> 标签: Dynamics CRM, crm, php, sdk

## 简介

PHP Toolkit for Microsoft Dynamics CRM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
