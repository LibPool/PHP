# erolatex/wbisualception

> 标签: PHP

## 简介

Visual regression tests for Codeception (fork from https://github.com/nixdrey/VisualCeption)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
