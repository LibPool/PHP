# rayhan/ray-mailer

> 标签: cakephp, cron, email, preview

## 简介

A mailer plugin for CakePHP3 using database driven Layouts and Templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
