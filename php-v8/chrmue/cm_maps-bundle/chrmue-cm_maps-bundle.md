# chrmue/cm_maps-bundle

> 标签: OpenStreetMap, contao, googlemaps, leafletjs, map, nominatim

## 简介

Contao Base extension for Memberlist and Locationlist with GoogleMaps or OpenStreetMap

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
