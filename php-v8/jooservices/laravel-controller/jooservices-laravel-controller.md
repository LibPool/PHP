# jooservices/laravel-controller

> 标签: JOOservices, api, api-response, base-controller, controller, formatter, json-response, laravel, laravel12, laravel13, openapi, pagination, php, php85, problem-details, response-envelope, rfc7807, status-endpoint, trace-id

## 简介

Laravel API controller foundation for standardized JSON envelopes, RFC 7807 Problem Details, OpenAPI schemas, pagination, status checks, and custom formatters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
