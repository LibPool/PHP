# mehrdad-dadkhah/php-persian-natural-language-processor

> 标签: language, natural-processing, persian

## 简介

Simple php and python wrapper on hazm persian text processor

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
