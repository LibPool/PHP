# addiks/symfony_rdm

> 标签: Domain Driven Design, doctrine2, orm, php, symfony

## 简介

Helps with the use of domain driven design & rich domain model in symfony/doctrine applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
