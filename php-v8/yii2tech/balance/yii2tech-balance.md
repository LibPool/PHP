# yii2tech/balance

> 标签: Accounting, balance, bookkeeping, credit, debit, yii2

## 简介

Provides support for Balance accounting system based on debit and credit principle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
