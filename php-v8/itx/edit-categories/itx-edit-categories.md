# itx/edit-categories

> 标签: PHP

## 简介

Dedicated backend module for browsing sys_category records as a tree, with language filter and record actions (edit, hide, delete, new subcategory).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
