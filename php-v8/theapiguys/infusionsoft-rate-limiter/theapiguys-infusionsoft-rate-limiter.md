# theapiguys/infusionsoft-rate-limiter

> 标签: PHP

## 简介

This package extends Infusionsoft PHP client to handle rate limiting headers and throttling

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
