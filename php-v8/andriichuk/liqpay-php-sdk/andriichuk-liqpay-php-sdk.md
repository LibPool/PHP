# andriichuk/liqpay-php-sdk

> 标签: PHPStan, checkout, fluent, internet-acquiring, invoices, liqpay, liqpay-api, liqpay-sdk, payment-gateway, payments, php-sdk, psr-18, refunds, subscriptions

## 简介

Fluent PHP SDK for LiqPay API v7 with typed array responses, PSR-18 HTTP clients, checkout, subscriptions, refunds and invoices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
