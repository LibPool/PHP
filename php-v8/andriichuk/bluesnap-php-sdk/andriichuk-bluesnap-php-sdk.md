# andriichuk/bluesnap-php-sdk

> 标签: bluesnap, payments, sdk, subscriptions

## 简介

A framework-agnostic PHP SDK for the BlueSnap Payment API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
