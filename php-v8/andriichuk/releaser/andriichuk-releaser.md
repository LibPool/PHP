# andriichuk/releaser

> 标签: automation, code-review, deploy, deployment, git, horizon, install, laravel, migration, pre-commit, release, sail

## 简介

Bash toolkit for PHP/Laravel: release flow automation, local Sail bootstrap, pre-commit code review, and server deployment

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
