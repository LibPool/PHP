# moduspromethean/fire-sdk

> 标签: PHP

## 简介

PHP SDK for the Fire AI Inference API (L1 chat/image, L2 workflows, v2 multi-agent flows)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
