# dnl/twig-whitespace-collapse-extension

> 标签: collapse, templating, twig, whitespace

## 简介

Whitespace collapse extension for Twig

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
