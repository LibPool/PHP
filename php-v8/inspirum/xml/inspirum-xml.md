# inspirum/xml

> 标签: xml, xml-builder, xml-parser, xml-reader, xml-splitter, xml-to-array, xml-writer

## 简介

Simple XML writer and memory efficient XML reader with powerful xml-to-array cast

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
