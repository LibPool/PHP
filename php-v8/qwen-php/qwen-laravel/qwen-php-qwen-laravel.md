# qwen-php/qwen-laravel

> 标签: alibaba-ai, alibaba-api, alibaba-cloud, alibabaai, laravel-ai, laravel-qwen, openai, php-qwen, qwen-api, qwen-coder, qwen-integration, qwen-laravel, qwen-package, qwen-php, qwen-php-client

## 简介

A seamless Laravel integration for the qwen PHP client, enabling effortless interaction with the qwen API in your Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
