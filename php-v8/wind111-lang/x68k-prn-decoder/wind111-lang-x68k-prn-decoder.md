# wind111-lang/x68k-prn-decoder

> 标签: PHP

## 简介

X68000/XM6のSHARP形式PRNをUTF-8テキストと印刷用HTMLへ復号するCLIツール

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
