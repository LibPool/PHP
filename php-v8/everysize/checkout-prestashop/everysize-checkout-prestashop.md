# everysize/checkout-prestashop

> 标签: checkout, everysize, marketplace, prestashop, sneaker

## 简介

everysize Checkout for PrestaShop 8.1/9: imports everysize orders and reports shipping, tracking, cancellations, returns and refunds back to everysize

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
