# everysize/checkout-magento2

> 标签: checkout, everysize, magento

## 简介

everysize Checkout for Magento 2: imports everysize orders and reports shipping, tracking, cancellations, returns and refunds back to everysize

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
