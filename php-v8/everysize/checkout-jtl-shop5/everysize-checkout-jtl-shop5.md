# everysize/checkout-jtl-shop5

> 标签: PHP

## 简介

everysize Checkout for JTL-Shop 5: imports everysize orders and reports shipping, tracking codes, cancellations, returns and refunds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
