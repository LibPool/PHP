# richarddobron/ean-utils

> 标签: EAN-13, EAN-8, barcode, ean, ean-utils, eancode

## 简介

PHP library to generate and validate EAN-8 and EAN-13 barcodes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
