# gemvc/cli-dev

> 标签: cli, codegen, development, gemvc

## 简介

GEMVC development CLI: codegen, admin tools, database introspection. Internal ecosystem package — install with --dev only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
