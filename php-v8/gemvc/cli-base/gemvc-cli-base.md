# gemvc/cli-base

> 标签: PHP

## 简介

Internal GEMVC CLI foundation: terminal I/O, filesystem helpers, and codegen abstract base classes. For GEMVC ecosystem only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
