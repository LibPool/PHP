# vicgutt/laravel-components-backport

> 标签: backport, blade, component, laravel

## 简介

Backporting Laravel 7+ Blade components to Laravel 5.8+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
