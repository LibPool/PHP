# moonlydays/php-kannel

> 标签: dlr, gateway, kannel, mo, psr-14, psr-18, sms, smsc

## 简介

PHP client for the Kannel SMS gateway — sendsms, admin, and inbound DLR/MO handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
