# riftweb/superseeder

> 标签: batch seeding, database migrations, database seeder, database seeding, laravel, laravel package, migration-like seeders, riftweb, rollback seeders, seed management, seeder rollback, seeder tracking

## 简介

Migration-style execution tracking and safe rollbacks for Laravel seeders.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
