# ouun/zammad-wp

> 标签: helpdesk, livechat, support, wordpress, wordpress-block, zammad

## 简介

Integrates Zammad Helpdesk into WordPress

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
