# ouun/kirki-module-fonts_upload

> 标签: customizer, framework, wordpress

## 简介

Easy custom fonts upload and CSS injection with Kirki WordPress plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
