# nyxo-app/nyxo-printer

> 标签: escpos, laravel, nyxo, pdf, pos, printer, receipt, silent-printing, thermal-printer, ticket

## 简介

Universal silent printing subsystem for Laravel applications with support for thermal receipt printers (ESC/POS) and standard A4 printers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
