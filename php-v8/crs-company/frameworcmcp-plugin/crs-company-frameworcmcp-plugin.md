# crs-company/frameworcmcp-plugin

> 标签: PHP

## 简介

HTTP API for the FrameworC page builder, consumed by the frameworc-mcp MCP server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
