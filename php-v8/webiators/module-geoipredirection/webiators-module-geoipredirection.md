# webiators/module-geoipredirection

> 标签: PHP

## 简介

Webiators GeoIpRedirection and GeoIpLocker extension make it possible to identify your vistors's location and allow/deny them access to the store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
