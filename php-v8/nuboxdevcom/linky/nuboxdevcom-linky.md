# nuboxdevcom/linky

> 标签: enedis, linky, nubox, nuboxdevcom, php, rest

## 简介

Bibliothèque de récupération des données de consommation Linky depuis votre compte Enedis

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
