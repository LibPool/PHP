# nuboxdevcom/phpesker

> 标签: Esker, php, sbordier44, slye44, soap, webservice

## 简介

Library for PHP 7.2+ to interact with Esker Services

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
