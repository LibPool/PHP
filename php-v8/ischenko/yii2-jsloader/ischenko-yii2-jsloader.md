# ischenko/yii2-jsloader

> 标签: Behavior, assets, jsloader, view, yii2

## 简介

An Yii2 extension designed to handle JS files, code and asset bundles via various js loaders

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
