# t3xdeveloper/stripe-payment-jms

> 标签: ecommerce, ibexa, payment, stripe, symfony

## 简介

Stripe Payment Provider Package based and developed on JMSPaymentCoreBundle. Allow access to Stripe API by symfony framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
