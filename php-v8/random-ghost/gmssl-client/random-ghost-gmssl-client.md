# random-ghost/gmssl-client

> 标签: GmSSL, crypto, gin, gov-crypto, sm2, sm3, sm4, 国密

## 简介

PHP SDK for GMSSL Server - SM2/SM3/SM4 cryptographic operations, key management, and audit logging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
