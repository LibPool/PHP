# wackowiki/htmlsax3

> 标签: html, parser, safehtml, sax, wackowiki, xml

## 简介

A modernized PHP 8.5-compatible port of the classic HTMLSax3 SAX-style parser for HTML/XML, used by SafeHTML in WackoWiki.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
