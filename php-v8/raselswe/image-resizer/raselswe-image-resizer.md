# raselswe/image-resizer

> 标签: image resize, laravel, laravel image croper, laravel image resize, php

## 简介

Resize JPEG, JPG, PNG, WEBp, any other image to specfice dimention and extention

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
