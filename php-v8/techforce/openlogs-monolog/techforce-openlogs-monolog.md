# techforce/openlogs-monolog

> 标签: handler, logging, monolog, openlogs

## 简介

Framework-agnostic Monolog handler that ships logs to an OpenLogs server in batches.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
