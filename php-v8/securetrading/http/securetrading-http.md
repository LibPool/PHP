# securetrading/http

> 标签: PHP

## 简介

Secure Trading's HTTP package - provides a generic HTTP interface and an implementation that uses cURL.  Supports logic for retries; SSL verification; etc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
