# bref/symfony-messenger

> 标签: Messenger, SNS, aws, aws-lambda, bref, sqs, symfony

## 简介

Symfony Messenger bridge to run with SQS and SNS on AWS Lambda with Bref

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
