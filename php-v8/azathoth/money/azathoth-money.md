# azathoth/money

> 标签: Generic Sub-domain, Value Object, ddd, domain-driven design, money

## 简介

PHP implementation of Fowler's Money pattern

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
