# aaronheath/laravel-model-copy

> 标签: backup, copy, eloquent, laravel, model, move

## 简介

Copy one Laravel Eloquent model from one table to another.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
