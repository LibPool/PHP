# andexer/captcha

> 标签: captcha, gd, image, numeric, security

## 简介

Captcha numérico de imagen para PHP 8.2+, sin dependencias de runtime más allá de ext-gd

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
