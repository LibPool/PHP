# andexer/wp-laracode

> 标签: blade, cli, eloquent, laravel, livewire, plugin-framework, wordpress

## 简介

Create isolated, modern WordPress plugins using Laravel's power without conflicts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
