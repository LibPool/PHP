# black-forest/js-onepageloader

> 标签: framework, frontend, javascript, onepage

## 简介

A JavaScript library to merge individual pages to an OnPage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
