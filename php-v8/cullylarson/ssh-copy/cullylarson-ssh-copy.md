# cullylarson/ssh-copy

> 标签: copy, remote, ssh

## 简介

A library for performing remote copies. Copy to/from local, to/from remote, and even between two remote machines.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
