# luler/phpcrypt

> 标签: PHP

## 简介

这是一个PHP数据加密解密包，可以设置密码、过期时间，在一些需要对数据进行加密解密传输的应用中非常有用

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
