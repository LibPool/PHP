# thetempusproject/tempusdebugger

> 标签: debugging, php, thetempusproject, tools

## 简介

Framework for sending php messages to chrome for in-browser debugging.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
