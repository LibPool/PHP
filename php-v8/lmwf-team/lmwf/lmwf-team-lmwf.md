# lmwf-team/lmwf

> 标签: framework, lightweight, web

## 简介

Lightweight web framework that doesn't require tons of dependencies and keeps you in control.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://lmwf-team.github.io/lmwf/phpdoc/
- 源码仓库：https://github.com/lmwf-team/lmwf.git
- Packagist 页面：https://packagist.org/packages/lmwf-team%2Flmwf
