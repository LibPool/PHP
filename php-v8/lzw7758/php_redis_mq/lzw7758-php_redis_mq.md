# lzw7758/php_redis_mq

> 标签: MQ, message, php, queue, redis

## 简介

PHP Redis消息队列完整实现方案，支持可靠队列、重试机制、死信队列、多进程消费等功能

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
