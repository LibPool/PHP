# sbwerewolf/json-serialize-trait

> 标签: PHP

## 简介

Library with trait of ability to output all properties of class-exemplar at call json_encode()

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
