# boron/carbon

> 标签: Jalali, calendar, carbon, date, datetime, gregorian, hijri, icu, intl, islamic, laravel, persian, shamsi, time

## 简介

Boron (B, atomic number 5) - a multi-calendar (Jalali/Shamsi, Hijri, Gregorian) drop-in replacement for Carbon (C, atomic number 6).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
