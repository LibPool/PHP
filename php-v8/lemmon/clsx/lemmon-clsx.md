# lemmon/clsx

> 标签: class, clsx, css, php, utility

## 简介

A tiny PHP utility to conditionally build `class` attribute strings, inspired by clsx for JavaScript.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
