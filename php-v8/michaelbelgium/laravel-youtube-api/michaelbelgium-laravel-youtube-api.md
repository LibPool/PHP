# michaelbelgium/laravel-youtube-api

> 标签: laravel, laravel-youtube-api, michaelbelgium, youtube, youtube-api

## 简介

Add a youtube api to your Laravel instance

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
