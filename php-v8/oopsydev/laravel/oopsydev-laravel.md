# oopsydev/laravel

> 标签: bug-tracking, debugging, error-monitoring, error-reporting, error-tracking, exception-handler, exception-tracking, flare-alternative, laravel, monitoring, oopsy, sentry-alternative, stack-trace

## 简介

Lightweight error monitoring for Laravel — captures PHP exceptions with full stack traces, code context, breadcrumbs, and sends them to Oopsy. Two-line setup, zero config.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
