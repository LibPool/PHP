# thiago-vieira/saci

> 标签: blade, debug, development, laravel, saci, tracer, views

## 简介

A modern, elegant Laravel debugger that shows loaded views and their data in a floating bar

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
