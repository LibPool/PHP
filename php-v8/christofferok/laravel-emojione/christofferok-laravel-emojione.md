# christofferok/laravel-emojione

> 标签: ChristofferOK, LaravelEmojiOne, emoji, emojione, laravel

## 简介

Laravel helper for EmojiOne

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
