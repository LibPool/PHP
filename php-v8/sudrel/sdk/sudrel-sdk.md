# sudrel/sdk

> 标签: Emissao, brasil, nfse, nota-fiscal, sdk, sefin, sudrel

## 简介

SDK oficial da API de emissão de NFS-e da Sudrel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://sudrel.com.br/docs
- 源码仓库：https://github.com/sudrel/sudrel-sdk-php.git
- Packagist 页面：https://packagist.org/packages/sudrel%2Fsdk

## 历史版本号

- 当前版本：v0.1.0

- v0.1.0

## 获取地址

- Composer 安装：`composer require sudrel/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/sudrel/sdk.json
- 许可证：MIT
- PHP 要求：>=8.1
