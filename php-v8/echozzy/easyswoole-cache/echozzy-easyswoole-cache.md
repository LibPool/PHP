# echozzy/easyswoole-cache

> 标签: PHP

## 简介

易用的缓存工具类(FileSystem/Redis/Memcahced/SwooleTable)支持协程特性

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
