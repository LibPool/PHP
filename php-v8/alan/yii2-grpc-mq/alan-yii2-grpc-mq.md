# alan/yii2-grpc-mq

> 标签: gRPC, php, rabbitmq, yii2

## 简介

yii2 framwork use message queue with grpc(swoole)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
