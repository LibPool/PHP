# gstjohn/fastimage

> 标签: fastimage, image size, ruby port

## 简介

FastImage finds the size or type of an image given its uri by fetching as little as needed, ported by Tom Moor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
