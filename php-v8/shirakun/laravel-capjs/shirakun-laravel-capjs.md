# shirakun/laravel-capjs

> 标签: cap.js, captcha, laravel, laravel-capjs, shirakun

## 简介

A package to help you implement the cap.js (CAP Worker Service) CAPTCHA alternative

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
