# johnhenryspike/php-web-terminal

> 标签: emulator, php, sandbox, terminal, web

## 简介

A minimal single-endpoint PHP web terminal emulator with Bearer auth.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
