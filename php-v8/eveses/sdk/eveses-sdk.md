# eveses/sdk

> 标签: activations, api, eveses, sdk, sms

## 简介

Official Eveses SDK for PHP — numbers, proxy, web-unblocker, emails, captcha, wallet, webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
