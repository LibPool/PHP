# crontinel/laravel

> 标签: cron, crontinel, horizon, laravel, laravel-native, mcp, monitoring, queue, supervisor

## 简介

Laravel SDK for Crontinel — cron, queue & Horizon monitoring for Laravel applications. Detects silent supervisor failures, queue bottlenecks, and missed cron runs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
