# newebtime/localization-extension

> 标签: Streams, extension, intl, localization, pyrocms

## 简介

Intl extension for PyroCMS and Streams Platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
