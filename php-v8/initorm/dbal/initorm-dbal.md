# initorm/dbal

> 标签: Abstraction-layer, data-mapper, database, dbal, initorm, mysql, pdo, pgsql, sqlite

## 简介

Lightweight PDO-based database abstraction layer with a fluent result mapper.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
