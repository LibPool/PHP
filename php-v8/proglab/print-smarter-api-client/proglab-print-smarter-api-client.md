# proglab/print-smarter-api-client

> 标签: PHP

## 简介

Client for the Print Smarter API, a service that allows you to easily print PDF documents on demand.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
