# jowxidea/onesignal

> 标签: laravel, laravel - flutter - front, notification-service, notifications, onesignal, push

## 简介

A lightweight and easy-to-use Laravel package for integrating OneSignal push notifications into your application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
