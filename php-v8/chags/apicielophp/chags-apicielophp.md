# chags/apicielophp

> 标签: api, cielo, pagamentos, php, rest

## 简介

Pacote PHP para integração com a API RESTful da Cielo, suportando pagamentos com cartão de crédito, débito e mais.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
