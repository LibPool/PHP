# jamessessford/playing-cards

> 标签: cards, playing cards, verbs

## 简介

A PHP implementation of a deck of playing cards to be used with Verbs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
