# cekat/event-sdk

> 标签: cekat, events, laravel, psr-15, symfony, tracking

## 简介

Submit identity-bearing Cekat events from PHP backends with automatic browser visitor correlation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
