# vivlong/phalapi-wordpress

> 标签: phalapi, phalapi-wordpress, wordpress

## 简介

PhalApi 2.x扩展类库，操作Wordpress。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
