# bpt/bpt-multi

> 标签: api, bot, bots, bpt, bpt library, bptlib, bptproto, robot, telegram, telegram api, telegram bot, telegram bot api

## 简介

A simple library for manage and handle telegram bots(multi file version)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
