# yii2-cmslib/redis

> 标签: extension, multiple, redis, yii2

## 简介

Redis class, For yii2 extention. Support multiple configuration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
