# pfilsx/postgresql-doctrine-bundle

> 标签: PHP

## 简介

This Symfony bundle provides extended Doctrine DBAL and Doctrine migrations classes for postgresql specific features support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
