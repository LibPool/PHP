# pfilsx/dto-param-converter-bundle

> 标签: api, bundle, param-converter, rest, symfony

## 简介

This Symfony bundle provides a way to convert requests into dto easily

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
