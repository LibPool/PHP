# pfilsx/data-grid-bundle

> 标签: bundle, data-table, datagrid, filters, pagination, sort, symfony4, symfony5, table

## 简介

Provides a Data Grid tables for your Symfony project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
