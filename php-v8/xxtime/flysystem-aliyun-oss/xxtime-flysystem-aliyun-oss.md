# xxtime/flysystem-aliyun-oss

> 标签: Flysystem, aliyun-oss, flysystem-aliyun-oss

## 简介

AliYun OSS adapter for flysystem. Support PHP8. aliyuncs/oss-sdk-php ~2.6

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
