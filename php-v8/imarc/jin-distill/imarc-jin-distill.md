# imarc/jin-distill

> 标签: configuration, diff, dotink, formatter, hiraeth, jin, static-analysis

## 简介

Analyze, normalize, flatten, and diff Dotink/Jin configuration without evaluating it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
