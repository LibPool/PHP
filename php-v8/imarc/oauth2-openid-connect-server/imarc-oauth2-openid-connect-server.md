# imarc/oauth2-openid-connect-server

> 标签: PHP

## 简介

An OpenID Connect Server that sites on The PHP League's OAuth2 Server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
