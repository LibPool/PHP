# burgerbibliothek/ark-management-tools

> 标签: PHP

## 简介

PHP library for minting / validating Archival Resource Keys (ARK) and managing Electronic Resource Citation (ERC) Records.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
