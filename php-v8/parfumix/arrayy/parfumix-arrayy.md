# parfumix/arrayy

> 标签: Arrayy, array, helpers, manipulation, methods, utility, utils

## 简介

Array manipulation library for PHP, called Arrayy!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
