# milon/papyrus

> 标签: book, cli, epub, html, kdp, kindle, markdown, pdf, publishing, static-site

## 简介

PHP CLI for Markdown book projects — PDF, EPUB, HTML, multi-page site, and Amazon KDP exports

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
