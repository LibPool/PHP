# lcoy/waterfall

> 标签: gallery, images, masonry, waterfall

## 简介

A Pixiv-style image waterfall (masonry) sharing page for Flarum, with external image host uploads, async queue processing, likes and a recommendation feed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
