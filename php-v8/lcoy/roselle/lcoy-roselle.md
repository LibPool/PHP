# lcoy/roselle

> 标签: discourse, flarum, roselle, theme

## 简介

Roselle — 为 lcoy 的论坛打造的 Flarum 2 主题，灵感来自 Discourse Horizon。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
