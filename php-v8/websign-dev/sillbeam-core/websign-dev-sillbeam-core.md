# websign-dev/sillbeam-core

> 标签: modular-monolith, modules, sillbeam, symfony

## 简介

Modular architecture extension for Symfony applications, organized around Modules and optional Projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
