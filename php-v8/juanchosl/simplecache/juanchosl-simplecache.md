# juanchosl/simplecache

> 标签: apcu cache, cache, file cache, memcache cache, memcached cache, process cache, psr-16, redis cache, session cache, simple cache, yac cache

## 简介

A small collection of read/write for multiples cache systems using PSR-16

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
