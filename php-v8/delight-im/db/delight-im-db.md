# delight-im/db

> 标签: database, mysql, pdo, pgsql, postgresql, sql, sqlite

## 简介

Safe and convenient SQL database access in a driver-agnostic way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
