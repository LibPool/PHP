# delight-im/git-scraper

> 标签: git, scm, scraper, security, vcs

## 简介

Downloads entire Git repositories from publicly accessible ".git" folders over HTTP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
