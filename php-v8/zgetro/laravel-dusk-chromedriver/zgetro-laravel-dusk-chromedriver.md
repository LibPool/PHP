# zgetro/laravel-dusk-chromedriver

> 标签: PHP

## 简介

A Laravel Artisan command to download matching ChromeDriver binaries for Windows, Linux, Mac, with WSL host detection support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
