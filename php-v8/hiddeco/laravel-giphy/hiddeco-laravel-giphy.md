# hiddeco/laravel-giphy

> 标签: api, giphy, laravel

## 简介

Giphy API wrapper for Laravel and Lumen based on Guzzle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
