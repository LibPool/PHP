# customgento/module-koality-m2

> 标签: PHP

## 简介

koality.io Magento 2 Plugin can be used to continuously monitor a Magento 2 shop for business metrics.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
