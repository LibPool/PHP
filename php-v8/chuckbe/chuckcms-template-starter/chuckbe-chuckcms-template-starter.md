# chuckbe/chuckcms-template-starter

> 标签: chuckbe, chuckcms, cms, laravel, php

## 简介

A ChuckCMS template named 'Starter' - lightweight and responsive.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
