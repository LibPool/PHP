# terragamingmedia/laravel-ads

> 标签: Advertising, ads, blade, laravel, terragaming

## 简介

TerraGaming Media ads for Laravel: Blade components for the site tag and ad units.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
