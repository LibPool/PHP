# bissolli/php-match-card-game

> 标签: card game, php

## 简介

Simple card game built in PHP that let players have fun playing against each other. Wins who gets its own hand empty first!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
