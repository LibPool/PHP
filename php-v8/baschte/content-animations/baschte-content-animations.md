# baschte/content-animations

> 标签: Animations, TYPO3 CMS, frontend, raphael gmbh, tools, typo3

## 简介

TYPO3 CMS extension to have some fun and animate your content elements

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
