# tigrov/yii2-pgsql-audit

> 标签: Audit, extension, pgsql, postgres, postgresql, yii2

## 简介

Audit for ActiveRecord models for Yii2, for PostgreSQL only

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
