# tigrov/yii2-country

> 标签: continent, country, currency, i18n, internationalization, intl, l10n, language, locale, localization, measurement, region, time zone, timezone, yii2

## 简介

Country data for Yii2 using Intl extension and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
