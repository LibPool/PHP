# tigrov/yii2-mailqueue

> 标签: delay, email, extension, mail, queue, yii2

## 简介

Yii2 mail queue component for yii2-swiftmailer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
