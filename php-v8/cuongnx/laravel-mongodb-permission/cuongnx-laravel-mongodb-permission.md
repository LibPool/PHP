# cuongnx/laravel-mongodb-permission

> 标签: PHP

## 简介

A flexible and multi-guard Role & Permission system for Laravel 11+ and 12+, using MongoDB and inspired by Spatie.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
