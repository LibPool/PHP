# btx/sql-ai-query

> 标签: ChatGpt, ai, database, grok, openai, query, sql

## 简介

PHP package to generate SQL queries using AI based on database schema with conversation context.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
