# janczakb/blade-hugeicons

> 标签: Hugeicons, blade, filament, icons, laravel, svg

## 简介

Official Hugeicons Free SVG icons for Laravel Blade and Filament, generated from the pinned upstream npm release.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
