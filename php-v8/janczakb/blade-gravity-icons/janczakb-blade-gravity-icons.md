# janczakb/blade-gravity-icons

> 标签: blade, filament, gravity-ui, icons, laravel

## 简介

Complete Gravity UI icon set for Laravel Blade and Filament (MIT, Yandex).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
