# tiagodsn/oauth2-server-lumen

> 标签: PHP

## 简介

A Lumen bridge for lucadegasperi/oauth2-server-laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
