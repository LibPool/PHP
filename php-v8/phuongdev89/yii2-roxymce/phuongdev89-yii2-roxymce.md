# phuongdev89/yii2-roxymce

> 标签: file manager, navatech, roxy, tinymce, yii2

## 简介

Integrate tinymce + roxy manager to yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
