# codecrafting-io/adoldap

> 标签: ado, adodb, adsi, ldap, ldap-sso

## 简介

A PHP seamless way to search on the Active Directory with ADO and LDAP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
