# jonnyw/craft-awss3assets

> 标签: Craft, assets, aws, s3

## 简介

A Craft CMS plugin allowing you to upload assets to an AWS S3 bucket.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
