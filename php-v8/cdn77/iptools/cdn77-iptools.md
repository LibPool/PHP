# cdn77/iptools

> 标签: IP, IP-Tools, cidr, ipv4, ipv6, network, subnet

## 简介

PHP Library for manipulating network addresses (IPv4 and IPv6)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
