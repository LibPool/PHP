# syntro/silvershare

> 标签: meta, sharing, silverstripe, silverstripe 4, silverstripe metadata

## 简介

Silverstripe module handling meta tags for pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
