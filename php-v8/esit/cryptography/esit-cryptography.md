# esit/cryptography

> 标签: PHP

## 简介

Es handelt sich um eine Erweiterung für das Open Source CMS Contao, die es ermöglicht, Werte zu ver- und entschlüsseln.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
