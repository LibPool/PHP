# esit/esitbeforeafter

> 标签: after, before, contao, image, jquery

## 简介

Die Erweiterung bindet das jQuery-Plugin [Before/After](http://www.catchmyfame.com/catchmyfame-jquery-plugins/jquery-beforeafter-plugin/) von _Catch My Fame_ in Contao ein.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
