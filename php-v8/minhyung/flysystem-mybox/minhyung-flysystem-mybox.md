# minhyung/flysystem-mybox

> 标签: Flysystem, adapter, filesystem, laravel, mybox, naver, storage

## 简介

Flysystem adapter for Naver MYBOX, built on the minhyung/mybox SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
