# minhyung/sdwebui

> 标签: automatic1111, img2img, psr-18, sdk, sdwebui, stable-diffusion, txt2img

## 简介

Fluent PHP SDK for the Stable Diffusion WebUI (AUTOMATIC1111) API, built on PSR interfaces with auto-discovery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
