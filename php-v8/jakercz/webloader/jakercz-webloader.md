# jakercz/webloader

> 标签: build-tool, css, frontend, javascript, module-bundler, webloader

## 简介

Simple, easy to use, php bundler for javascript and css

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
