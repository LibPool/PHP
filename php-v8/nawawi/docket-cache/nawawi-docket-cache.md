# nawawi/docket-cache

> 标签: Object Cache, cache, flat-file, wordpress plugin

## 简介

A persistent object cache stored as a plain PHP code, accelerates caching with OPcache backend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
