# joshua-barbosa/erede-sdk

> 标签: Pagamento, erede, gateway, laravel, payment, rede, sdk

## 简介

SDK PHP para a API eRede (Rede) com autenticação OAuth 2.0, integrado ao Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
