# findologic/curl-bundle

> 标签: bundle, curl, http, httpkernel, symfony

## 简介

Allows you to easily create and execute HTTP Requests with cURL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
