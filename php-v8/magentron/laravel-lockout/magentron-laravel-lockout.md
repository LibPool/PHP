# magentron/laravel-lockout

> 标签: Read-Only, laravel, lockout, rappasoft

## 简介

Put your Laravel application into read-only mode. (forked from rappasoft/lockout)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
