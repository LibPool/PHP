# magentron/laravel-api-logger

> 标签: api, laravel, laravel-api-logger, logger

## 简介

Laravel API logger to log responses and requests to file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
