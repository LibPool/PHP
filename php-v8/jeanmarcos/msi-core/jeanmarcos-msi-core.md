# jeanmarcos/msi-core

> 标签: MSI, inventory, mage-os, magento, magento2, multi-source-inventory, stock

## 简介

Multi-Source Inventory as the single inventory system for Magento Open Source: one code path for every stock, no special Default Stock, and the cataloginventory_* tables no longer read or written. Derived from magento/inventory (Copyright Adobe), redistributed under AFL-3.0. Not affiliated with or endorsed by Adobe.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
