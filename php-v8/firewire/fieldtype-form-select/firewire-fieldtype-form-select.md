# firewire/fieldtype-form-select

> 标签: Forms, ajax, module, processwire

## 简介

An inputfield/fieldtype for creating fields to select forms in ProcessWire built with FormBuilder

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
