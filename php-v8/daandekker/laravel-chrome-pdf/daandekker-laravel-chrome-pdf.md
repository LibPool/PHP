# daandekker/laravel-chrome-pdf

> 标签: chrome, headless, laravel, pdf, tailwind

## 简介

Generate PDFs in Laravel using headless Chrome. Full CSS support, no Node.js required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
