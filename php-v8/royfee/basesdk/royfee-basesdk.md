# royfee/basesdk

> 标签: api, basesdk, http-client, middleware, php-sdk, psr-16, psr-3, sdk

## 简介

A modern PHP SDK foundation package for building API clients with ease.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
