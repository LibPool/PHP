# webdevstudios/cmb2

> 标签: metabox, plugin, wordpress

## 简介

CMB2 is a metabox, custom fields, and forms library for WordPress that will blow your mind.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
