# ajay/sylius-media-hub-plugin

> 标签: catalog, images, media, sylius, sylius-plugin

## 简介

Centralized Sylius admin dashboard for product and taxon images.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
