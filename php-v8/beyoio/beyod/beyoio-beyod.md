# beyoio/beyod

> 标签: asynchronous non-blocking, beyod, php sockets

## 简介

beyod - 高性能分布式、事件驱动、异步非阻塞php socket网络应用框架

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
