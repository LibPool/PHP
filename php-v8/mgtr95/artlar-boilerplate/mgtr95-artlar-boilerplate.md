# mgtr95/artlar-boilerplate

> 标签: artlar, docker, inertia, laravel, react

## 简介

Laravel 13 + React/Inertia starter with Docker (FrankenPHP, Postgres, Redis).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
