# sglms/pdf

> 标签: laravel, mpdf, pdf, sglms, signature

## 简介

Simple Laravel wrapper for mPDF with fluent view rendering and signing helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
