# syncroze/ldt-lang

> 标签: PHP

## 简介

ldt-lang — Logic Driven Text Language, an embeddable templating language (.ldt files), interpreted in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
