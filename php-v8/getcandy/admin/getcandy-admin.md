# getcandy/admin

> 标签: cart, e-commerce, ecommerce, getcandy, headless, laravel, shop, store

## 简介

Admin Hub for GetCandy. A modern headless e-commerce solution for Laravel PHP framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
