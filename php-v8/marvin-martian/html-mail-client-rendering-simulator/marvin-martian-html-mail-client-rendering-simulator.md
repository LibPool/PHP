# marvin-martian/html-mail-client-rendering-simulator

> 标签: PHP

## 简介

Creates simulated previews of HTML documents in various email clients in a modern webbrowser.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
