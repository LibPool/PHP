# raphhh/php-lib-bootstrap

> 标签: bootstrap, samurai

## 简介

A bootstrap for a PHP lib, including basic common files and settings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
