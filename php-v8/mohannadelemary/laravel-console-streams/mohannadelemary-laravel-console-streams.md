# mohannadelemary/laravel-console-streams

> 标签: artisan, cli, console, json, laravel, pipe, stderr, stdout

## 简介

Opt-in Artisan trait that keeps machine data on STDOUT and sends console components, line(), info() and other diagnostics to STDERR, so `artisan foo --json | jq` just works.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
