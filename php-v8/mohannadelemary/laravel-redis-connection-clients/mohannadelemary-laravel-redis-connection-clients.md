# mohannadelemary/laravel-redis-connection-clients

> 标签: Connection, client, laravel, phpredis, predis, redis, sentinel

## 简介

Pick the Redis client (phpredis, predis or a custom one) per connection in Laravel, instead of one global database.redis.client for every connection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
