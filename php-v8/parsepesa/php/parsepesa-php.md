# parsepesa/php

> 标签: fintech, kenya, mpesa, parsepesa, parser, sms

## 简介

Official PHP SDK for ParsePesa - The Stripe for M-Pesa SMS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
