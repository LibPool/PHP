# cloud-io/struct

> 标签: dto, immutable, json, struct, xml, yaml

## 简介

Generate immutable typed structs from arrays, JSON, XML, YAML and PHP configuration files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
