# desino/crud-engine

> 标签: crud, desino, generator, laravel, scaffold

## 简介

Laravel Artisan scaffold generator for Desino CRUD modules (model, controller, migration, views, routes, translations).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
