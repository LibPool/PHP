# mage2kishan/module-mega-menu

> 标签: drag-and-drop, header, hyva, luma, magento2, magento2-module, mega-menu, menu, navbar, navigation

## 简介

Advanced mega menu for Magento 2 — works on Hyva and Luma. Drag-and-drop tree builder, multi-column dropdowns, image and icon support per item, custom CMS block injection per column, mobile drawer with smooth animations, store-view scoped, FPC-aware caching, role-based access. Modern Tailwind + Alpine UI on Hyva, vanilla JS on Luma.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
