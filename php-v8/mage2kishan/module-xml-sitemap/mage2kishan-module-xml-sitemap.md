# mage2kishan/module-xml-sitemap

> 标签: Sitemap, hreflang, hyva, magento2, magento2-module, panth, seo, xml-sitemap

## 简介

Panth XML Sitemap — sharded XML sitemap generator for Magento 2: per-store profile CRUD, product/category/CMS/landing-page/blog/video/image/additional-link contributors, hreflang tags, image + video tags, auto-split at 50,000 URLs or 50 MB, optional gzip compression, changefreq and priority, XSL stylesheet, delta tracking, async shard queue, per-profile cron schedules, CLI generator. Hyva and Luma compatible. Extracted from Panth_AdvancedSEO.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
