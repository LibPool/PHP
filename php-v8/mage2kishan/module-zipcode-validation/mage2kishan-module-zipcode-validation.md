# mage2kishan/module-zipcode-validation

> 标签: Pincode, address, checkout, magento2, magento2-module, panth, validation, zipcode

## 简介

Panth ZipcodeValidation — validates ZIP/PIN codes at checkout against configurable country-specific ranges. Ships with pre-loaded ranges for India, US, UK, Canada, Australia, and Europe. Includes an admin grid for managing ranges, JSON import and export, and AJAX validation on the storefront.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
