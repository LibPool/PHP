# mage2kishan/module-core

> 标签: base, core, infrastructure, library, magento2, magento2-module, panth, shared

## 简介

Panth Core - base module providing shared utilities, admin configuration helpers, the optional ThemeBuildExecutorInterface contract, and the panth_modules registry used by every other Panth extension. Required dependency for all Panth Infotech extensions on the Magento Marketplace.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
