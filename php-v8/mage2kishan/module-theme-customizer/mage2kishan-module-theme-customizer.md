# mage2kishan/module-theme-customizer

> 标签: PHP

## 简介

Hyva Theme Customizer - Backend-driven theme configuration with CSS custom properties, color management, typography, and Tailwind CSS integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
