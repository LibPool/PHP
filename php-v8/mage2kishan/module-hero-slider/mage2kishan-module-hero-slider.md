# mage2kishan/module-hero-slider

> 标签: carousel, hero-slider, homepage-slider, hyva, luma, magento2, magento2-module, panth, splide

## 简介

Hero / homepage carousel for Magento 2 (Hyva + Luma). Center-focused 3-up Splide.js slider with autoplay, per-slide button styling, and responsive desktop/mobile artwork. Ships its own copy of Splide 4.1.4 (MIT license included) - no CDN or theme dependency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
