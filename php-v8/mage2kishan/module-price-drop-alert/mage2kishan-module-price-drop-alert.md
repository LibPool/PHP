# mage2kishan/module-price-drop-alert

> 标签: PHP

## 简介

Price Drop Alert module for Magento 2 - Allows customers to subscribe to price drop notifications on products.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
