# ruvart/openkm-client

> 标签: OpenKM, api, client, curl, json, rest, xml

## 简介

A generic unofficial REST API client for PHP for connecting with an OpenKM Server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
