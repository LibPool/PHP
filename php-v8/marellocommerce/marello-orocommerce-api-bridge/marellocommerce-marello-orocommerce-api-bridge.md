# marellocommerce/marello-orocommerce-api-bridge

> 标签: PHP

## 简介

Api Bridge for exposing additional resources from OroCommerce to integrate with Marello

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
