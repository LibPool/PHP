# marellocommerce/magento2-marello-bridge

> 标签: PHP

## 简介

Marello Bridge Extension for Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/marellocommerce/magento2-marello-bridge.git
