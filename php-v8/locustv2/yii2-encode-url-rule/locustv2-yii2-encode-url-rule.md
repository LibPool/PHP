# locustv2/yii2-encode-url-rule

> 标签: array, encode, rule, url, yii2

## 简介

Makes the encoding of query parameters easier when creating urls.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
