# mobikul/mobikul_loader

> 标签: loader, mobile, nativephp, nativephp-plugin

## 简介

Loader state bridge for NativePHP Mobile with optional Blade and web view helpers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
