# lepresk/momo-api

> 标签: MTN Mobile Money, africa payment, collection, disbursement, mobile money, mobile payment api, momo, mtn, payment, payment gateway, remittance, transfer

## 简介

PHP library for MTN Mobile Money (MoMo) API. Receive payments (Collection), send money (Disbursement), and manage mobile transactions in Africa.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
