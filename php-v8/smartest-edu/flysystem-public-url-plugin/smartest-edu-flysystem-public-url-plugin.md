# smartest-edu/flysystem-public-url-plugin

> 标签: AwsS3v2, Flysystem, aws, plugin, public, url

## 简介

Plugin for Flysystem to expose the public url.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
