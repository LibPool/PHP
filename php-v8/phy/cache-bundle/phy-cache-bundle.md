# phy/cache-bundle

> 标签: apc, cache, disk, memcache, memcached, redis, symfony

## 简介

Cache Bundle for Symfony2 that supports APC, Memcache, Memcached, Redis, Local, and Disk storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
