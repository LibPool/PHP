# noumenia/mmdbdaemon

> 标签: daemon, geoip, geolocation, mmdb

## 简介

mmDbDaemon is a memory-resident MaxMind Database reader implementation in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
