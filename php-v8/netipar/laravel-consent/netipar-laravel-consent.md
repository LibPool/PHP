# netipar/laravel-consent

> 标签: alpine, consent, consent-mode, cookie, cookie-consent, gdpr, laravel, livewire, netipar, vue

## 简介

Headless cookie-consent for Laravel: versioned consent cookie, server-side API and Blade directive, framework-free JS core with Google Consent Mode v2, unstyled Alpine/Livewire and Vue 3 adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
