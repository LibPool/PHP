# slimphp-api/slim-phinx

> 标签: api, phinx, slim, slimapi

## 简介

A module for slim-api for phinx migration, integrating migrations for slim-api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
