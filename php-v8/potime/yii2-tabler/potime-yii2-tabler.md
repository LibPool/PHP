# potime/yii2-tabler

> 标签: boostrap, extension, tabler, yii2

## 简介

Boostrap Tabler UI for Yii 2.0 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
