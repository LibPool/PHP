# appristas/qtranslate-x

> 标签: PHP

## 简介

Dynamic multilingual plugin for Wordpress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://wordpress.org/plugins/qtranslate-x/
- 源码仓库：https://github.com/appristas/qtranslate-x.git
