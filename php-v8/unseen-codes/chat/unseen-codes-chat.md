# unseen-codes/chat

> 标签: chat, laravel, livewire, messaging, real-time, volt

## 简介

Plug-and-play Livewire/Volt chat system for Laravel 11, 12, and 13

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
