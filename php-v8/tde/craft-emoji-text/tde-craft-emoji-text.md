# tde/craft-emoji-text

> 标签: Craft, cms, craft emoji text, craft-plugin, craftcms

## 简介

This plugin bypasses the error "X cannot contain emoji".

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
