# jacobtread/kni

> 标签: composer, my package, package

## 简介

KAMAR Notices Interface - A way to access notices from KAMAR in a bunch of languages (PHP)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
