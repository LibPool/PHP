# sevenymedia/l5-repository

> 标签: cache, eloquent, laravel, model, repository

## 简介

Laravel 5 - Repositories to the database layer. Extends andersao/l5-repository.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
