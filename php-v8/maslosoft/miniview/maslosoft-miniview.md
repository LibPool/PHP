# maslosoft/miniview

> 标签: PHP

## 简介

Mini view is minimal template rendering library with pluggable template engines. Out of the box it support plain PHP templates, Latte and Twig.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
