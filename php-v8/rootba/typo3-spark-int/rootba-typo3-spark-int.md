# rootba/typo3-spark-int

> 标签: PHP

## 简介

Integrations and glue-code for external TYPO3 extensions (News, EventNews, etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
