# hxm/extrafield

> 标签: extrafield, hxm, laravel, package, rule, validation

## 简介

Extra fields package, simple, extensible and powerful extra fields implementation for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
