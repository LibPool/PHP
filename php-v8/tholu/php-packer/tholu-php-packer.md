# tholu/php-packer

> 标签: JS, javascript, minification, minify, obfuscate, uglify

## 简介

A PHP version of Packer, JavaScript obfuscation library originally created by Dean Edwards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
