# iconicfreelancer/studio

> 标签: awps, themes, wordpress

## 简介

Nifty Command Line Application to quickly setup a new AWPS theme in WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
