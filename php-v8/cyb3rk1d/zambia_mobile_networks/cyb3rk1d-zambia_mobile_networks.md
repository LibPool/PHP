# cyb3rk1d/zambia_mobile_networks

> 标签: Zambia, airtel, laravel, mobile, msisdn, mtn, phone, zamtel

## 简介

Identify Zambian mobile networks (Airtel, MTN, Zamtel) from a phone number. Framework-agnostic core with optional Laravel service provider and facade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
