# naderman/composer-aws

> 标签: amazon, aws, composer, composer-plugin, plugin, s3

## 简介

A composer plugin that allows installing packages stored on S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
