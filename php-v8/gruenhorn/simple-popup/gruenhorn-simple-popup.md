# gruenhorn/simple-popup

> 标签: banner, modal, popup, shopware, shopware-plugin

## 简介

Once-per-session promo popup (Bootstrap modal) whose target URL is configurable in the admin

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
