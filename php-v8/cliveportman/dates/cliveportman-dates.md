# cliveportman/dates

> 标签: Craft, cms, craft-plugin, craftcms, dates

## 简介

Adds PHP's datePeriod function for looping through dates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
