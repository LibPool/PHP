# xhat/payjs

> 标签: PHP

## 简介

本项目是基于 PAYJS 的 API 开发的 Composer Package，可直接用于生产环境 https://payjs.cn

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
