# anonymhk/tronapi

> 标签: php, trc20, tron, trx

## 简介

Support TRON's TRX and TRC20, A PHP library to create Tron wallet addresses and manage wallets using the Tron API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
