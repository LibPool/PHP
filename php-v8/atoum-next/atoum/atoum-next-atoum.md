# atoum-next/atoum

> 标签: TDD, atoum, atoum-next, test, unit testing

## 简介

Simple modern and intuitive unit testing framework for PHP 8.1+ — the community-driven continuation of atoum

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
