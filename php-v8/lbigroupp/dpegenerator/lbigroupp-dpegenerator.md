# lbigroupp/dpegenerator

> 标签: PHP

## 简介

This package is use for generate French DPEG picture. This new DPEG is an evolution of ELAN law on 2021-07-01.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
