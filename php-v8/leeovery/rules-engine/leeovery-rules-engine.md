# leeovery/rules-engine

> 标签: Audit, business-rules, conditions, effective-dates, immutable, laravel, rules, rules-engine, versioning

## 简介

A rules engine for Laravel that resolves values from named rule sets against facts, with immutable, dated versions and a per-rule history of every change

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
