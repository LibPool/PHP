# kattsoftware/phassets-codeigniter-integration

> 标签: PHP

## 简介

CodeIgniter framework integration pack for Phassets lib.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/kattsoftware/phassets
