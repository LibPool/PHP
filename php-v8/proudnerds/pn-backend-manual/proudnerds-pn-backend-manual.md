# proudnerds/pn-backend-manual

> 标签: TYPO3 CMS, dashboard, documentation, manual, markdown

## 简介

Editor manuals in Markdown, registered by a sitepackage and shown as dashboard widgets with a full view in the TYPO3 backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
