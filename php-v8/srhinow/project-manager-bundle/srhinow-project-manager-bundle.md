# srhinow/project-manager-bundle

> 标签: Agreements, contao, credit, invoice, manager, offer, projects, reminder

## 简介

a project-management-tool with invoice, credit, offer, reminder, agreements parts for Contao CMS >= 5.3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
