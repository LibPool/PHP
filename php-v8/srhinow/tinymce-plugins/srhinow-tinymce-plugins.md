# srhinow/tinymce-plugins

> 标签: ImageTools, TOC, advlist, anchor, autolink, autoresize, bbcode, codemirror, colorpicker, contextmenu, emoticons, fullpage, help, hr, insertdatetime, legacyoutput, media, nonbreaking, noneditable, pagebreak, plugin, preview, print, rte, save, spellchecker, textcolor, textpattern, tiny, tinymce, wordcount

## 简介

It links additional TinyMCE plugins in order to set them in the tinyMCE.html5 templates yourself.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
