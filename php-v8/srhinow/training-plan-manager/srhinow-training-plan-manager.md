# srhinow/training-plan-manager

> 标签: contao, schedule, training, trainingsplan, weekly

## 简介

Wöchentlicher Trainingsplan (Wochentag + Von–Bis + Gruppe) für das Contao CMS – schlanke Alternative zu wiederkehrenden Kalender-Events

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
