# jketelaar/bitbucket

> 标签: Bridge, JKetelaar, Jeroen Ketelaar, Laravel Bitbucket, Laravel-Bitbucket, PHP Bitbucket API, bitbucket, bitbucket bridge, framework, laravel, php-bitbucket-api

## 简介

Bitbucket is a Bitbucket bridge for Laravel 5 based on the Github bridge from GrahamCampbell

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
