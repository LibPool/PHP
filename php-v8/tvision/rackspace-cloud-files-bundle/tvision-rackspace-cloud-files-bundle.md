# tvision/rackspace-cloud-files-bundle

> 标签: assetic, cloud, rackspace

## 简介

Provides rackspace cloud files support for #Symfony2 Bundles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
