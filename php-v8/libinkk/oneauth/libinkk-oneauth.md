## 简介

OneAuth is a modular Laravel authentication framework with session, Sanctum, JWT, OTP, social login, email verification, password reset, two-factor authentication, session management, and device security through one unified API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
