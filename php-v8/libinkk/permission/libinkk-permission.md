# libinkk/permission

> 标签: Audit, abac, acl, authorization, delegation, laravel, libinkk, multi-tenancy, permission, permissions, rbac, react, roles, vue

## 简介

Production-grade Laravel authorization engine (v1.0) with RBAC, ABAC, multi-tenancy, temporary access, delegation, audit logs, and Vue/React helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
