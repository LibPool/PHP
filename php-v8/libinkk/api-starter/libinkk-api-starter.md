# libinkk/api-starter

> 标签: api, api-response, api-starter, exception-handling, filtering, laravel, libinkk, pagination, rest, sorting, validation

## 简介

A production-ready API foundation for Laravel with standardized responses, filtering, sorting, validation, exception handling, and enterprise developer experience.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
