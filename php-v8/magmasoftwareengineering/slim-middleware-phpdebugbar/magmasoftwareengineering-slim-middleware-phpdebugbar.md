# magmasoftwareengineering/slim-middleware-phpdebugbar

> 标签: microframework, middleware, psr7

## 简介

A Slim Framework middleware module for PHPDebugBar

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
