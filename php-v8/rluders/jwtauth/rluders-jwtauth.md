# rluders/jwtauth

> 标签: Authentication, Web Token, api, cms, json, jwt, winter, wintercms

## 简介

JSON Web Token Authentication plugin for Winter CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
