# tyhpdef/php-ext-dba

> 标签: dev, static analysis

## 简介

Tyhp type definitions for the PHP dba extension (8.2+). Version-specific APIs are gated via declare(php=…) / #[\Tyhp\Php] (Story 20.5).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
