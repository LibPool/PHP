# schachbulle/contao-chesstable-bundle

> 标签: contao, csv, schach, tabelle, turnier

## 简介

Inhaltselement, das aus CSV-Daten mit Semikolon als Trennzeichen eine HTML-Tabelle erzeugt und dabei die Besonderheiten von Schachturniertabellen berücksichtigt.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
