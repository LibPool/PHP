# schachbulle/contao-navigation-bundle

> 标签: artikel, contao, inserttag, navigation, seiten, untermenue

## 简介

Inserttags für eine Navigation über die Unterseiten einer Seite und über die Artikel einer Seite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
