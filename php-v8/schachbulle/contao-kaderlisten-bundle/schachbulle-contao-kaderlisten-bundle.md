# schachbulle/contao-kaderlisten-bundle

> 标签: contao, kader, liste, schach, spieler

## 简介

Verwaltet Kaderlisten von Schachspielern und gibt sie im Frontend aus.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
