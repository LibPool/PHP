# schachbulle/contao-caroufredsel-bundle

> 标签: caroufredsel, contao, galerie, karussell, newsticker, slider, slideshow, swiper

## 简介

Bildkarussell auf Swiper-Basis (Portierung der Contao-3-Erweiterung dk_caroufredsel): Galerie mit Vorschauleiste, Newsticker, Hintergrund-Slideshow und Karussell für beliebige Inhaltselemente.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
