# schachbulle/contao-dsbapplayout-bundle

> 标签: DSB, app, contao, layout

## 简介

Schaltet für Aufrufe aus der App des Deutschen Schachbundes automatisch auf ein eigenes Seitenlayout um.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
