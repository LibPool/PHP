# schachbulle/contao-figcaption-bundle

> 标签: bildunterschrift, contao, figcaption, fotograf

## 简介

Ersetzt in Bildunterschriften einen von Platzhaltern umklammerten Text, damit sich zum Beispiel der Fotograf gesondert auszeichnen lässt.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
