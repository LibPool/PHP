# schachbulle/contao-helper-bundle

> 标签: bibliothek, cache, contao, helper

## 简介

Sammlung von Hilfsfunktionen für die übrigen Erweiterungen, darunter ein einfacher dateibasierter Cache.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
