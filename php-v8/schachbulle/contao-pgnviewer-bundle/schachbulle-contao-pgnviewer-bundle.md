# schachbulle/contao-pgnviewer-bundle

> 标签: PGN, contao, partien, schach, schachbrett

## 简介

Inhaltselement, mit dem sich Schachpartien im PGN-Format auf der Website abspielen lassen. Als Engine dient der PGN-Viewer von Chesstempo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
