# schachbulle/contao-domgrabber-bundle

> 标签: contao, dom, grabber, import, scraping

## 简介

Holt Inhalte von externen Webseiten über deren DOM-Struktur und bindet sie in die eigene Seite ein.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
