# schachbulle/contao-templateparser-bundle

> 标签: ausgabe, contao, ersetzen, template

## 简介

Ersetzt Inhalte in der fertigen Seite, kurz bevor sie an den Browser ausgeliefert wird.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
