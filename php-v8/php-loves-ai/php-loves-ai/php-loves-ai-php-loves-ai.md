# php-loves-ai/php-loves-ai

> 标签: ai, hugging-face, inference, llm, local, machine-learning, multimodal, speech-to-text, text-to-image, text-to-speech, whisper

## 简介

Run small Hugging Face AI models locally from PHP via prebuilt standalone binaries — no Python installation required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
