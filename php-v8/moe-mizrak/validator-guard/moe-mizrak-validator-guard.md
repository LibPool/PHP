# moe-mizrak/validator-guard

> 标签: Attribute Validation, Moe Mizrak, ValidatorGuard, attributes, dependency, laravel, laravel-validator-guard, permission, state, validation

## 简介

ValidatorGuard enables attribute-driven validation to control Laravel method behavior.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
