# kozz/collection

> 标签: LinkedList, collection, cursor, iterator, php, spl, storage

## 简介

Powerful Data Storage based on SplDoublyLinkedList

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
