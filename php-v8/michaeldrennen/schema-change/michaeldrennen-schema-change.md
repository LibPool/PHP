# michaeldrennen/schema-change

> 标签: PHP

## 简介

A PHP library that handles MySQL query exceptions to determine if you need to make a change to your schema.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
