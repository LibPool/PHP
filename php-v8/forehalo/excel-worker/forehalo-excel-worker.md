# forehalo/excel-worker

> 标签: PHPExcel, csv, excel, export, import, php

## 简介

A simple lib to import from or export into csv/xlxs/xml/json etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
