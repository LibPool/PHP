# jord-jd/php-languages

> 标签: PHP

## 简介

A tiny package to help convert between languages names (such as English, French, German) and various ISO language codes (such as en, fr, de).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
