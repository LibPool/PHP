# saade/facehash

> 标签: avatar, deterministic, facehash, identicon, laravel, svg

## 简介

Deterministic avatar faces from any string. Lightweight, pure SVG output. Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
