# saade/cep-php

> 标签: brasil api, cep, cep-php, correios, laravel, saade, viacep

## 简介

Async, high availability brazilian CEP finder with multiple providers for redundancy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
