# amocrm/oauth2-amocrm

> 标签: amoCRM, authorisation, authorization, client, oauth, oauth2

## 简介

amoCRM OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
