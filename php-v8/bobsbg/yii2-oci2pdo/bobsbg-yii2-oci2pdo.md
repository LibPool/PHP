# bobsbg/yii2-oci2pdo

> 标签: db, oci, oci8, oracle, pdo, php, yii2

## 简介

Yii2 extension to simulate a PDO connection to Oracle database using PHP OCI8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
