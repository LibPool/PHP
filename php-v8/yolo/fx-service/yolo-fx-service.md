# yolo/fx-service

> 标签: Microservice, framework, hyperf, php, swoole

## 简介

A coroutine framework that focuses on hyperspeed and flexible, specifically use for build microservices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
