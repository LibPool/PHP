# surrealdb/laravel

> 标签: database, laravel, orm, surqlize, surrealdb

## 简介

Laravel integration for the SurrealDB PHP SDK and Surqlize ORM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
