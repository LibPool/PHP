# cdsmths/laravel-cirrux-calendar

> 标签: availability, booking, calendar, cirrux, experimental, laravel, saloon

## 简介

Experimental Laravel package for the Cirrux calendar API: cached availability, booking and cancelling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
