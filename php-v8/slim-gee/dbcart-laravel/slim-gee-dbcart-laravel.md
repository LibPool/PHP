# slim-gee/dbcart-laravel

> 标签: Nabeel Al-Almai, database, dbcart-laravel, e-commerce, laravel, shopping cart

## 简介

Shopping Cart for Laravel > 5.5 and Laravel 6 that uses Database instead of Sessions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
