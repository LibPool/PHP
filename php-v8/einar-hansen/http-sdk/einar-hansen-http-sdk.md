# einar-hansen/http-sdk

> 标签: einar, einar-hansen, http, laravel, psr-18

## 简介

A PHP service that allows you to communicate with external apis using PSR-18 clients.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
