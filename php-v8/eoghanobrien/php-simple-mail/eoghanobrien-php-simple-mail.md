# eoghanobrien/php-simple-mail

> 标签: email, php5

## 简介

Provides a simple, chainable wrapper for creating and sending emails using the PHP mail() function.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
