# cyberline/filament-navigation-footermenu

> 标签: PHP

## 简介

Configurable footer navigation for Filament v4, v5: collapsible sidebar group and topbar dropdown (dark mode ready).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
