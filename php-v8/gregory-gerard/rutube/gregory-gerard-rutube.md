# gregory-gerard/rutube

> 标签: PHP

## 简介

RutubeM3U8Scrapper helps you to retrieve a list of HLS streams for a Rutube LiST video.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
