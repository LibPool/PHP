# skynettechnologies/statamic-skyneta11y-pdf-remediation

> 标签: EAA, accessibility, ada, laravel, pdf, remediation, section-508, statamic, statamic-addon, wcag

## 简介

SkynetA11y PDF Remediation addon for Statamic - upload or scan PDFs and remediate them for accessibility (WCAG, ADA, Section 508, EAA) with AI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
