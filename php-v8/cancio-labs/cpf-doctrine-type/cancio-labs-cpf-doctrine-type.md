# cancio-labs/cpf-doctrine-type

> 标签: brazil, cpf, doctrine, mapping type, type

## 简介

A custom mapping type for Brazilian CPF (Cadastro de Pessoas Físicas).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
