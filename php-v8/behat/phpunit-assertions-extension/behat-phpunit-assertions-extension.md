# behat/phpunit-assertions-extension

> 标签: BDD, Behat, documentation, testing

## 简介

Behat extension to support PHPUnit assertions in step definitions. NOTE: Not recommended for new projects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
