# sajjadhossainshohag/laravel-lang-cache

> 标签: cache, lang, laravel, localization, performance, translation

## 简介

Compile Laravel translation files into a single cached PHP file with php artisan lang:cache.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
