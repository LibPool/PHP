# breadhead/yii2-swagger

> 标签: yii2, yii2 api documentation generator, yii2 swagger

## 简介

Swagger Documentation Generator for Yii2 Framework with swagger v3.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
