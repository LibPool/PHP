# felixnagel/beautyofcode

> 标签: SyntaxHighlighter, extension, prism, syntax highlighting, typo3

## 简介

This TYPO3 CMS extension provides JavaScript based, state-of-the-art, feature rich syntax highlighting by using SyntaxHighlighter or Prism.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
