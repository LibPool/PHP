# felixnagel/generic-gallery

> 标签: TYPO3 CMS, extbase, fluid, gallery, image, lightbox, slider

## 简介

TYPO3 CMS image gallery extension. One gallery to rule them all. Extbase & Fluid driven for use with any gallery / slide / rotate plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
