# signawebsolutions/yii2-modal-login

> 标签: extension, login-form, modal-login, yii2

## 简介

Make a button that open a Bootstrap4 Modal with the login form

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
