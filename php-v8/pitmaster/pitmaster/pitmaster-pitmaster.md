# pitmaster/pitmaster

> 标签: diff, git, merge, pack, php, repository, vcs

## 简介

Pure PHP Git implementation. Reads and writes Git repositories without shelling out to git.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
