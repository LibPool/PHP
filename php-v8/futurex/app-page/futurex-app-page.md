# futurex/app-page

> 标签: analytics, app page, filament, landing page, laravel, package

## 简介

A Laravel package for app landing pages with analytics, screenshots, features, and Filament admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
