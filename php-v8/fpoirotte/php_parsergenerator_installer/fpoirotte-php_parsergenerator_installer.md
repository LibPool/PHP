# fpoirotte/php_parsergenerator_installer

> 标签: compiler, generator, lemon, lempar, parser

## 简介

Automatically compiles parsers upon a package's installation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
