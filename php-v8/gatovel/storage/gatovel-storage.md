# gatovel/storage

> 标签: files, filesystem, framework, gatovel, php, s3, storage, upload

## 简介

Sistema modular e independente de gerenciamento de arquivos para aplicações PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
