# zhongchuanhao/ex-webman-admin

> 标签: Ex-admin, ExAdmin, admin, curd, php, ui, webman

## 简介

Ex-Admin for webman 2.x：基于 Ant Design of Vue + webman 的后台系统构建工具（原 rockys/ex-admin 停更后的 PHP 8.4 + webman 2.2 适配版）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
