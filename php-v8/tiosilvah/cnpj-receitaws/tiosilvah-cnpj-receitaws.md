# tiosilvah/cnpj-receitaws

> 标签: PHP

## 简介

Biblioteca para buscar informações de um cnpj através receitaws.com.br

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
