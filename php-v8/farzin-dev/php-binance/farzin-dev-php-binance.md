# farzin-dev/php-binance

> 标签: api, binance, cryptocurrency, cryptocurrency-exchanges, php, php-library, wrapper-api

## 简介

A PHP wrapper for the Binance API endpoints.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
