# swiftchase/queue-sqs-s3event

> 标签: aws, job, queue, sqs, zf2

## 简介

Zend Framework 2 module for Amazon S3 Event Notifications queue manager for SlmQueue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
