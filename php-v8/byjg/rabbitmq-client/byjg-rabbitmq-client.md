# byjg/rabbitmq-client

> 标签: PHP

## 简介

It creates a simple abstraction layer to publish and consume messages from the RabbitMQ Server using the component byjg/message-queue-client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
