# byjg/phpthread

> 标签: PHP

## 简介

ByJG PHPThread simplifies working with threads and non-blocking code in PHP, bridging the gap for a language that was not inherently designed for threading.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
