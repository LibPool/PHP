# byjg/restserver

> 标签: PHP

## 简介

Create RESTFull services with different and customizable output handlers (JSON, XML, Html, etc.). Auto-Generate routes from swagger.json definition.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
