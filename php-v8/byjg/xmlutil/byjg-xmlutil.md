# byjg/xmlutil

> 标签: PHP

## 简介

A powerful and intuitive PHP library for working with XML documents. This utility makes XML manipulation, querying, and conversion simple and straightforward in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
