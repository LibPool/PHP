# byjg/anydataset-xml

> 标签: PHP

## 简介

XML abstraction dataset for the AnyDataset library. AnyDataset is an agnostic data source abstraction layer in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
