# byjg/jwt-wrapper

> 标签: PHP

## 简介

A simple and flexible wrapper around the Firebase JWT library that makes JWT token handling easy and intuitive in PHP applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
