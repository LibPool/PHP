# byjg/fonemabr

> 标签: PHP

## 简介

O Fonema BR tem por objetivo criar uma simplificação de palavras de tal forma que erros de ortografia e vogais não interfiram na busca

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
