# byjg/sms-cep-service-php5

> 标签: PHP

## 简介

Implementação em PHP para acesso ao WebService de CEP e SMS ByJG

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
