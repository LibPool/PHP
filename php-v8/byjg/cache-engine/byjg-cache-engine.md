# byjg/cache-engine

> 标签: PHP

## 简介

A powerful, versatile cache implementation providing both PSR-6 and PSR-16 interfaces with support for multiple storage drivers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
