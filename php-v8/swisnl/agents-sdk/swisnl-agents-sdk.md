# swisnl/agents-sdk

> 标签: agents-sdk, swisnl

## 简介

A lightweight yet powerful framework for building multi-agent workflows inspired by the OpenAi Agents SDK

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
