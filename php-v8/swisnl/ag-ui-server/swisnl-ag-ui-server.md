# swisnl/ag-ui-server

> 标签: ag-ui, swisnl

## 简介

PHP server integration for AG-UI - standardized AI agent frontend communication via Server-Sent Events

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
