# swisnl/openapi-spec-generator

> 标签: JSON-API, generator, laravel, openapi, openapi-spec, openapi-spec-generator, swisnl

## 简介

Creates Open API spec for a Laravel JSON:API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
