# baddybugs/agent

> 标签: Agent, apm, laravel, monitoring, observability, performance

## 简介

Intelligent monitoring agent for Laravel, the data collector for BaddyBugs platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
