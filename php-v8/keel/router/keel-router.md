# keel/router

> 标签: PHP

## 简介

Attribute-based HTTP router with constraints, group-count regex matching, 405 handling, URL generation and a PHP-array cache. Part of the Keel framework, usable on its own.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
