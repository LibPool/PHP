# keel/http

> 标签: PHP

## 简介

PSR-15 pipeline, HTTP exceptions, responder with streaming and Server-Sent Events, argument resolver with DTO hydration and validation, CORS / request-id / trusted-proxies / trusted-hosts / security-headers / body-limit / Server-Timing / HTTP-cache / deprecation / method-override middleware, SAPI emitter. Part of the Keel framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
