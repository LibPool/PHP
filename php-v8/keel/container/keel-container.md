# keel/container

> 标签: PHP

## 简介

PSR-11 container with constructor autowiring, attributes, PHP 8.4 lazy objects, per-request reset and a compiler. Part of the Keel framework, usable on its own.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
