# green-pixelbox/gp-design-element-group

> 标签: contao, contentelement, group, gruppe, hintergrundbild, hintergrundvideo, image, video

## 简介

Mit diesem Contao-Element kann man eine Contao Element Gruppe erzeugen (wrapper um weitere Elemente), hinter der man ein Hintergrundbild oder Hintergrundvideo legen kann. Das wird mittels object cover eingefügt, die Position lässt sich anpassen.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
