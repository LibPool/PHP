# green-pixelbox/gp-schema-org

> 标签: contao, geo, json ld, schema.org, seo

## 简介

Fügt JSON-LD-Daten für Schema.org / strukturierte Daten in den Head von Contao-Seiten ein. Eine globale JSON-LD-Textarea am Startpunkt (Root-Seite) wird auf jeder Seite ausgegeben, zusätzlich kann pro Seite eine seitenspezifische JSON-LD-Textarea gepflegt werden.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
