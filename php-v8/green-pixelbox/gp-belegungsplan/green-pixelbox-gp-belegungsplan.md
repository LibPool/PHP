# green-pixelbox/gp-belegungsplan

> 标签: belegungskalender, belegungsplan, contao, contentelement

## 简介

Einfache Belegungspläne / Belegungskalender im Backend erstellen und pflegen und im Frontend als Contao-Element ausgeben.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
