# hookpilot/webhook-client

> 标签: delivery, hmac, hookpilot, retry, sdk, signature, webhook, webhooks

## 简介

HookPilot PHP SDK: отправка подписанных событий в адрес приёма и типизированный клиент публичного API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
