# khalilleo-webagentur/vcard-parser

> 标签: nuovo, vCard, vcf parser

## 简介

vCard-parser is a simple vCard file parser with the focus on ease of use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
