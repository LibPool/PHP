# deviddev/billingo-api-v3-wrapper

> 标签: api, billingo, laravel, v3, wrapper

## 简介

This is a simple Laravel wrapper for Billingo (billingo.hu) API V3 SwaggerHUB PHP SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
