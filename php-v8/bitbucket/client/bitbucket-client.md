# bitbucket/client

> 标签: Bitbucket API, Bitbucket API Client, Bitbucket Client, BitbucketAPI, Graham Campbell, GrahamCampbell, bitbucket

## 简介

Bitbucket API 2.0 client for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
