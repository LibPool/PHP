# atatusoft/ppphp

> 标签: compiler, generics, php, programming-language, static-analysis, transpiler

## 简介

++PHP is a superset of PHP that compiles to clean PHP output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
