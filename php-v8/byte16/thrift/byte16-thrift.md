# byte16/thrift

> 标签: apache, thrift

## 简介

Mirror of apache thrift client lib of php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://thrift.apache.org/
- 源码仓库：https://github.com/byte16/thrift.git
- Packagist 页面：https://packagist.org/packages/byte16%2Fthrift

## 历史版本号

- 当前版本：0.11.0

- 0.11.0

## 获取地址

- Composer 安装：`composer require byte16/thrift`
- Packagist 仓库：https://repo.packagist.org/p2/byte16/thrift.json
- 许可证：Apache-2.0
- PHP 要求：>=5.0.0
