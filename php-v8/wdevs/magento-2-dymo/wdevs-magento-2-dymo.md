# wdevs/magento-2-dymo

> 标签: PHP

## 简介

Print shipping address labels with a Dymo LabelWriter from a Magento 2 backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
