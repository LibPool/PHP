# dedipanel/phpseclib-wrapper-bundle

> 标签: phpseclib, sftp, ssh

## 简介

PHPSeclib Wrapper with connections manager, logging, os-specific helpers, ...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
