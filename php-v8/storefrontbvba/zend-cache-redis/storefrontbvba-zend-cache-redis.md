# storefrontbvba/zend-cache-redis

> 标签: PHP

## 简介

Zend_Cache backend using Redis with full support for tags, but without the need for Magento.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
