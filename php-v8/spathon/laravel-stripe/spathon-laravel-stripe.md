# spathon/laravel-stripe

> 标签: l5, laravel, stripe

## 简介

Minimal Laravel 5 package wrapper for Stripe SDK 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
