# bmilleare/sonyflake-php

> 标签: distributed-id, id-generator, snowflake, sonyflake, unique-id

## 简介

A faithful PHP port of Sony's Sonyflake distributed unique-ID generator (v2).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
