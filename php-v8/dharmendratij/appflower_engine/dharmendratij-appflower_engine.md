# dharmendratij/appflower_engine

> 标签: builder, framework, rad

## 简介

AppFlower is a Rapid Application Development (RAD) tool which automatically generates user interface and backend code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
