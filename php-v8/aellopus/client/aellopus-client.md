# aellopus/client

> 标签: aellopus, awp, cache, client, database, key-value, kv

## 简介

Official Aellopus client for PHP — a synchronous, zero-dependency AWP/1 client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
