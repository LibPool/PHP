# baseapi/baseapi-template

> 标签: Skeleton, api, baseapi, php, template

## 简介

Project template for BaseAPI - a tiny, KISS-first PHP 8.4 framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
