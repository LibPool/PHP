# hammercommerce/magento-coding-standard

> 标签: PHP

## 简介

A set of Magento 2 specific PHP CodeSniffer rules designed for Weidenhammer Commerce Projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
