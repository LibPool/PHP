# neto737/hestiacp-api

> 标签: API-Client, api, control-panel, hestia, hestia-control-panel, hestiacp, sdk, web-hosting

## 简介

PHP client for the HestiaCP API: users, web domains, mail, DNS, databases, backups, cron jobs and packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
