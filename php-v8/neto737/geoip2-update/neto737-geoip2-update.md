# neto737/geoip2-update

> 标签: geoip, geoip2, geolite2, geolocation, maxmind

## 简介

Update GeoIP2/GeoLite2 databases from your script, program or via composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
