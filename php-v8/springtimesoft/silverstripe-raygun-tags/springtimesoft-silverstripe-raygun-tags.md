# springtimesoft/silverstripe-raygun-tags

> 标签: logging, raygun, silverstripe

## 简介

Automatically add Silverstripe tags to Raygun error logs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
