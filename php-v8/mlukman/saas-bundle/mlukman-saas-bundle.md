# mlukman/saas-bundle

> 标签: PHP

## 简介

Simplify implementation of Symfony 6.x/7.x web application with SaaS capabilities such as credit purchase, subscription management, usage tracking etc

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
