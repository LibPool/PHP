# alisajjad/php7_api

> 标签: PHP

## 简介

A PHP basic starter for single url API development. It provides the basic functionalities with different authorization handles as well as Mysqli Wrapper.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
