# alisajjad/php7_mysql

> 标签: PHP

## 简介

A simple PHP Mysqli Wrapper(prepare statements) with Result collection object which provides basic functionality.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
