# as2aas/php-client

> 标签: as2, b2b, edi, healthcare, integration, messaging, supply-chain

## 简介

PHP client library for AS2aaS - Making AS2 messaging as simple as sending an email

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
