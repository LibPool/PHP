# silvercart/payment-paypal

> 标签: ecommerce, online shop, payment, paypal, shop, silvercart, silverstripe, webshop

## 简介

Paypaly payment module for the SilverCart ecommerce module for SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
