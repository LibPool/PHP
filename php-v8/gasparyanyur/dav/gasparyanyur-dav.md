# gasparyanyur/dav

> 标签: CalDAV, CardDAV, WebDAV, framework, iCalendar

## 简介

WebDAV Framework for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
