# bar9/bolt-theme-skeleton

> 标签: DaisyUI, bolt, storybook, tailwind, theme

## 简介

A Bolt CMS theme skeleton based on tailwind 3, daisyui and storybook

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
