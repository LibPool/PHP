# tueen/database

> 标签: bot, database, dbal, doctrine, migrations, orm, php84, telegram, tueen, zero-config

## 简介

The zero-config, high-throughput relational database engine engineered for Telegram bots and the Tueen ecosystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
