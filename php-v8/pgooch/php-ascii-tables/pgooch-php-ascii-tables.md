# pgooch/php-ascii-tables

> 标签: ascii, cli, tables

## 简介

Convert multi-dimensional arrays into ASCII Tabled, and vise-versa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
