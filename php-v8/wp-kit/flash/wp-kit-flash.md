# wp-kit/flash

> 标签: OOP, assely, flash, notifications, themosis, wordpress, wp-kit

## 简介

A wp-kit component that handles frontend and admin flash notifications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
