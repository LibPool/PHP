# wp-kit/rest-kit

> 标签: OOP, rad, rapid application development, restkit, wordpress, wpkit

## 简介

A micro RAD solution for Wordpress REST API themes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
