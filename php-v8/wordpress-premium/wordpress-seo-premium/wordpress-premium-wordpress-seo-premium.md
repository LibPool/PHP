# wordpress-premium/wordpress-seo-premium

> 标签: premium, seo, wordpress, yoast

## 简介

Yoast SEO Premium - The most comprehensive WordPress SEO plugin. Includes advanced features like redirect management and internal linking suggestions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
