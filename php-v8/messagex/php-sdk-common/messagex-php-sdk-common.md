# messagex/php-sdk-common

> 标签: MX, email, library, messagex, php, sdk, sms

## 简介

Common libraries for MessageX PHP SDKs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
