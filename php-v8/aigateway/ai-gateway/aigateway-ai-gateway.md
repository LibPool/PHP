# aigateway/ai-gateway

> 标签: ChatGpt, Gemini, ai, anthropic, claude, google-ai, llm, openai

## 简介

PHP通用AI调用接口 - 对标Python OpenAI SDK风格，支持OpenAI/Claude/Gemini及所有兼容服务

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
