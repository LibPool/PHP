# hollodotme/fast-cgi-client

> 标签: Socket, async, fastcgi, php-fpm

## 简介

A PHP fast CGI client to send requests (a)synchronously to PHP-FPM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
