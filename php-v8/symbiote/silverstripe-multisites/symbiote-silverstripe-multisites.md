# symbiote/silverstripe-multisites

> 标签: multisites, silverstripe, subsites

## 简介

Allows for multiple websites to be managed through a single site tree.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
