# symbiote/silverstripe-addressable

> 标签: addressable, geocoding, silverstripe, symbiote

## 简介

SilverStripe addressable and geocoding module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
