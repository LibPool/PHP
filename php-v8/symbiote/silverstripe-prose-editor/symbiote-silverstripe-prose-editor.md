# symbiote/silverstripe-prose-editor

> 标签: prose, silverstripe, wysiwyg

## 简介

A wysiwyg editor based on prose mirror

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
