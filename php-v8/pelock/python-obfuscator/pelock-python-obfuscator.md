# pelock/python-obfuscator

> 标签: Virtualization, anti-debug, obfuscate, obfuscation, obfuscator, protection, py, python, script, self-defending, virtualizer, vm

## 简介

Python Obfuscator Web API interface can help you obfuscate and protect Python .py source code against analysis, reverse engineering and technology theft. Python Obfuscator provides advanced Python source code parsing based on AST trees, multiple advanced obfuscation, virtualization and protection strategies are available.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
