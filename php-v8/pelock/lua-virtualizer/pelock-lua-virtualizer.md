# pelock/lua-virtualizer

> 标签: lua, obfuscator, pelock, protection, virtualizer

## 简介

Lua Virtualizer Web API interface can help you obfuscate and protect Lua .lua source code against analysis, reverse engineering and technology theft. Lua Virtualizer provides advanced Lua source code parsing based on AST trees, multiple advanced obfuscation, virtualization and protection strategies are available.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
