# novuscom/cmfuserbundle

> 标签: cmf, cmf bundle, cmf user bundle

## 简介

Symfony2 user bundle for Novuscom CMF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
