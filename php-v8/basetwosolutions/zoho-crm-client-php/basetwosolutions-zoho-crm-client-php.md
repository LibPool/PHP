# basetwosolutions/zoho-crm-client-php

> 标签: Zoho, api, client, crm, rest, sdk

## 简介

Provides a clean readable PHP API to the Zoho Rest API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
