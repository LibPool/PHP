# phpmlkit/opal

> 标签: ffi, gd, image, image processing, imagick, libvips, machine learning, ml, ndarray, vips

## 简介

High-performance image processing for PHP, backed by libvips via FFI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
