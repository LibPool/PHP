# phpmlkit/soundfile

> 标签: audio, ffi, flac, libsamplerate, libsndfile, mp3, ogg, resample, sound, wav

## 简介

Low-level libsndfile + libsamplerate bindings for PHP via FFI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
