# shopapps/has-table-relation

> 标签: database, eloquent, illuminate, laravel, relations

## 简介

Provides a hasTable Eloquent relation to fetch all records from a table.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
