# wapmorgan/php-code-analyzer

> 标签: code analysis, command-line utility

## 简介

A program that finds usage of different non-built-in extensions in your php code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
