# epptools/sdk

> 标签: client, domains, epp, registrar, registry, rfc5730, rfc5731, rfc5910, sdk

## 简介

Standalone PHP client for EPP domain registries — RFC 5730-5734 over TLS, with a registry's own extensions discovered from its greeting. No framework, no project code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
