# fengche/payment

> 标签: alipay, weixin, 一网通, 微信支付, 招商一网通, 支付宝支付, 集成支付接口SDK

## 简介

支持hyperf 支付宝支付、微信支付、招商一网通支付php SDK。方便快速接入，最完整的开源支付 php sdk

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
