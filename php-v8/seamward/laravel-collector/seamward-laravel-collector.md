# seamward/laravel-collector

> 标签: collector, integration, laravel, observability, webhook

## 简介

Laravel adapter for the Seamward PHP collector.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://seamward.com
- 源码仓库：https://github.com/seamward/laravel-collector.git
- Packagist 页面：https://packagist.org/packages/seamward%2Flaravel-collector

- 当前版本：v0.1.0-alpha.1

## 获取地址

- Composer 安装：`composer require seamward/laravel-collector`
