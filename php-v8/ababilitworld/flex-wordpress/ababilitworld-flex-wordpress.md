# ababilitworld/flex-wordpress

> 标签: php, wordpress

## 简介

A flexible, Composer-managed package to handle Wordpress by following modern SOLID OOP best practices by Ababil IT Hub.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
