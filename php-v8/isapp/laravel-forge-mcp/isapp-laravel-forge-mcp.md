# isapp/laravel-forge-mcp

> 标签: ai, deployment, forge, laravel, mcp

## 简介

Native Laravel MCP server for managing Laravel Forge servers, sites and deployments via the Forge API v2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
