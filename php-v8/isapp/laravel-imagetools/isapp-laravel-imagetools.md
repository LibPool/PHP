# isapp/laravel-imagetools

> 标签: ImageTools, cdn, image, laravel, optimizer, spatie

## 简介

Laravel image tools: deterministic, query-driven image generation (vite-imagetools-like).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
