# hiqdev/yii2-mfa

> 标签: Authentication, multi-factor, rfc6238, totp, two-factor, yii2

## 简介

Multi-factor authentication for Yii2 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
