# hiqdev/omnipay-okpay

> 标签: merchant, okpay, omnipay, payment, php

## 简介

OKPAY driver for Omnipay PHP payment library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
