# rbbsoft/arca-sdk

> 标签: PHP

## 简介

SDK PHP PSR-4 standalone para facturacion electronica contra ARCA (WSAA + WSFE).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
