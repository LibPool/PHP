# webcraftdg/fractal-cms-import-export

> 标签: export, import, import-export, module, php, yii2

## 简介

Import / Export engine for FractalCMS (CSV, XLSX, SQL, Row Transformers)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
