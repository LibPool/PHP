# laboiteacode/filament-tribute-theme

> 标签: filament, filament-plugin, filament-theme, filament-tribute-theme, laboiteacode, theme, tribute

## 简介

A free Filament v5 theme paying tribute to filamentphp.com: cream corner-tick cards, honey pill buttons and Outfit headings, built on Filament's own CSS variables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
