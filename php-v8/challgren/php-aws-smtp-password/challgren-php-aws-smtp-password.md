# challgren/php-aws-smtp-password

> 标签: access secret, aws, aws smtp password, smpt password, smtp

## 简介

Converts an AWS secret access key to a SMTP password.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
