# italix/storage

> 标签: files, mime, storage, uploads

## 简介

File storage where the caller never chooses the filename: content-hash paths, extension from sniffed MIME through a whitelist

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
