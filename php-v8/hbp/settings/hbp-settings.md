# hbp/settings

> 标签: wordpress

## 简介

Layered settings resolution for Hybrid Core themes and plugins.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/hybopress/settings
- 源码仓库：https://github.com/hybopress/settings.git
- Packagist 页面：https://packagist.org/packages/hbp%2Fsettings
