# fyuri4/laravel-observability

> 标签: laravel, monitoring, observability, tracing

## 简介

Production-ready observability for Laravel: traces, spans, slow queries, exceptions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
