# sibidharan/zealphp

> 标签: async, coroutine, framework, http, middleware, openswoole, php, php-framework, psr-15, real-time, sse, streaming, swoole, websocket, zealphp

## 简介

Coroutine-native PHP framework on OpenSwoole — async HTTP, WebSocket, streaming, and real-time applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
