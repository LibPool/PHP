# acolyte/sms-laravel

> 标签: laravel, messaging, notifications, queue, sms, sms-gateway

## 简介

Laravel-native multi-provider SMS package with typed results, queues, events, and accurate message segmentation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
