# bjthecod3r/laravel-tmdb

> 标签: api, laravel, movies, themoviedb, tmdb, tv, wrapper

## 简介

A fluent, fully-typed Laravel wrapper for The Movie Database (TMDB) API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
