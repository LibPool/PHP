# bjthecod3r/laravel-discogs

> 标签: action-pattern, discogs, discogs-api, laravel, marketplace, music, vinyl

## 简介

A Laravel wrapper for the Discogs API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
