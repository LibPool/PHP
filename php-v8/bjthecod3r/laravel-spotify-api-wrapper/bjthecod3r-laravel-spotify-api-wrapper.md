# bjthecod3r/laravel-spotify-api-wrapper

> 标签: action-pattern, laravel, music, search, spotify, spotify-api, spotify-web-api

## 简介

A Laravel wrapper for the Spotify Web API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
