# bjthecod3r/laravel-recordables

> 标签: Metrics, analytics, eloquent, history, laravel, snapshots

## 简介

Record snapshots of Eloquent model data over time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
