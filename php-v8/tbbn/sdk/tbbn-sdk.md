# tbbn/sdk

> 标签: api, barter, exchange, sdk, tbbn, trade, trade by barter

## 简介

PHP client for the TBBN Platform API — publish listings, manage offers and trade sessions, and verify webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
