# aporat/scrapecreators-php

> 标签: API-Client, TikTok , instagram, laravel, scrape-creators, scrapecreators, scraping, sdk, social-media, twitter, youtube

## 简介

PHP client for the Scrape Creators API: typed methods for every documented endpoint across TikTok, Instagram, YouTube, X, Reddit, LinkedIn, Facebook and 20 more platforms, provider-side cache control, typed exceptions for missing, restricted and age-gated profiles, and an optional Laravel service provider

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
