# aporat/laravel-push-notifications

> 标签: FCM, android, apns, apple, firebase, ios, laravel, push notifications

## 简介

Laravel integration for aporat/push-notifications: APNs and FCM pushes per app, with events, a notification channel and a fake for tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
