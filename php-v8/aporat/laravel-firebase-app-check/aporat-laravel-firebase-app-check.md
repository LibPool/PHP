# aporat/laravel-firebase-app-check

> 标签: Authentication, app-attest, app-check, appcheck, firebase, id-token, laravel, middleware, play-integrity

## 简介

Firebase App Check for Laravel APIs: a middleware that verifies the X-Firebase-AppCheck token per request with soft and hard enforcement and cached verdicts, a Firebase ID-token sign-in verifier, projects keyed by app name, and fakes for tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
