# aporat/push-notifications

> 标签: FCM, android, apns, apple, firebase, ios, live activity, php, push notifications

## 简介

PHP client for Apple Push Notification service (APNs) and Firebase Cloud Messaging (FCM): token-based auth, persistent HTTP/2, typed payloads and normalized responses

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
