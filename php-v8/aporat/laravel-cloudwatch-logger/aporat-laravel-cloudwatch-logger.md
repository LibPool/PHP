# aporat/laravel-cloudwatch-logger

> 标签: aws, cloudwatch, laravel, logger, logging, monolog

## 简介

A Laravel logging driver for AWS CloudWatch Logs integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
