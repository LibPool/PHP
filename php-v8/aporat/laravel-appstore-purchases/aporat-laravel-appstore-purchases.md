# aporat/laravel-appstore-purchases

> 标签: In-App Purchase, Receipt Validation, amazon, android, app store, apple, google play, itunes, laravel, server notifications, subscription

## 简介

Laravel package for handling App Store and Google Play purchase receipts, subscriptions and notifications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
