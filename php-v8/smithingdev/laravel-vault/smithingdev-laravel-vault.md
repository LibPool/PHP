# smithingdev/laravel-vault

> 标签: approle, hashicorp, kv2, laravel, secrets, vault

## 简介

A small, focused Laravel client for HashiCorp Vault: AppRole/token auth and KV2 secret CRUD.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
