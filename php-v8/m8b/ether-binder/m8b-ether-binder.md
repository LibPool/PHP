# m8b/ether-binder

> 标签: PHP

## 简介

Set of utilities for interacting with Ethereum and it's smart contracts with PHP, with generating ABI bindings and Ethereum-related types

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
