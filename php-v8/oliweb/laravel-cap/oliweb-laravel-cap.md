# oliweb/laravel-cap

> 标签: cap, captcha, laravel, proof-of-work, spam-protection

## 简介

Laravel wrapper for Cap (tiagozip/cap) — self-hosted CAPTCHA alternative

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
