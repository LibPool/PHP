# opensymap.org/opensymap

> 标签: Rich application, framework, store

## 简介

Opensymap is a framework for manage rich internet application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.opensymap.org/
- 源码仓库：https://github.com/opensymap/osy.git
- Packagist 页面：https://packagist.org/packages/opensymap.org%2Fopensymap
