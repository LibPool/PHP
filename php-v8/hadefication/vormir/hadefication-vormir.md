# hadefication/vormir

> 标签: PHP

## 简介

Doi package for Laravel to server side render using Spatie's server-side-rendering package with focus on Node engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
