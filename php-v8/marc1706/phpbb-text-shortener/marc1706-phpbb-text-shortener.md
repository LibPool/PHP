# marc1706/phpbb-text-shortener

> 标签: bbcode, extension, extensions, minify, php, phpbb, post, shortening

## 简介

Library for shortening post text in phpBB 3.2.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
