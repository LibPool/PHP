> 标签: easyadmin, easyadmin wysiwyg, quill, quilljs, symfony form, symfony quill, symfony ux, symfony ux bundle, symfony wysiwyg, symfony-ux, wysiwyg

## 简介

Symfony UX Bundle to use Quill JS wysiwyg text editor with full and easy customisation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
