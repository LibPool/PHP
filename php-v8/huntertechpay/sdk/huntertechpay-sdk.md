# huntertechpay/sdk

> 标签: africa, huntertechpay, mobile money, payment

## 简介

Official PHP SDK for HunterTechPay mobile money payments API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://huntertechpay.com/merchant-api/documentation
- 源码仓库：https://github.com/hunter-tech-africa/huntertechpay-php.git
- Packagist 页面：https://packagist.org/packages/huntertechpay%2Fsdk

## 历史版本号

- 当前版本：v1.0.1

- v1.0.1

## 获取地址

- Composer 安装：`composer require huntertechpay/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/huntertechpay/sdk.json
- 许可证：MIT
- PHP 要求：>=7.4
