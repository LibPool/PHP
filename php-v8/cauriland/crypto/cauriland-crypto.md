# cauriland/crypto

> 标签: api, blockchain, cauri, crypto, currency

## 简介

A simple PHP Cryptography Implementation for the Cauri Blockchain.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
