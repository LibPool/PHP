# ifcastle/amphp-pool

> 标签: async, asynchronous, awaitable, concurrency, event, event-loop, future, non-blocking, promise, server

## 简介

Middle-level library for creating Stateful Asynchronous server-side applications using the pure PHP and AMPHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
