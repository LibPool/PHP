# cbagdawala/innlogger

> 标签: exceptions, innlogger, laravel, logging, monitoring

## 简介

Laravel SDK for InnLogger: signed, fail-silent application log and exception shipping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
