# ssddanbrown/yphp

> 标签: collaboration, crdt, ffi, sync, yjs

## 简介

PHP bindings for Y-CRDT (yrs, a y.js implementation) using PHP FFI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
