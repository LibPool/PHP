# musikhood/auth-client-bundle

> 标签: 2fa, JWKS, auth, jwt, symfony, symfony-bundle

## 简介

Symfony bundle for cookie-based auth against a central auth server (BEARER + refresh_token, JWT/JWKS validation, 2FA, user mirror).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
