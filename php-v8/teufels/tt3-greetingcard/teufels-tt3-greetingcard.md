# teufels/tt3-greetingcard

> 标签: PHP

## 简介

[teufels] Greetingcard - Greeting card service for the TYPO3 form framework with motif selection from a file storage folder and double opt-in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
