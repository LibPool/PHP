# tiny-blocks/http-logging

> 标签: http, logging, observability, psr-15, tiny-blocks

## 简介

PSR-15 middleware that logs HTTP request and response metadata with request duration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
