# tiny-blocks/time

> 标签: date, datetime, duration, instant, iso-8601, monotonic-clock, period, time, timezone, tiny-blocks, utc, value-object

## 简介

Models time as immutable value objects for PHP: instants, durations, periods, timezones, and time-of-day, all UTC-normalized.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
