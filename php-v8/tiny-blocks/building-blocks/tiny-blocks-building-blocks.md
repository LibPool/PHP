# tiny-blocks/building-blocks

> 标签: aggregate-root, building-blocks, ddd, domain-driven-design, domain-events, event-sourcing, integration-events, snapshot, tiny-blocks, upcaster, value-object

## 简介

Implements tactical DDD building blocks for PHP: entities, aggregate roots, domain events, snapshots, and upcasters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
