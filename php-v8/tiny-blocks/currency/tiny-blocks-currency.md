# tiny-blocks/currency

> 标签: currency, enum, iso-4217, tiny-blocks, value-object

## 简介

Models ISO-4217 currencies as a PHP enum, with per-currency fraction digit resolution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
