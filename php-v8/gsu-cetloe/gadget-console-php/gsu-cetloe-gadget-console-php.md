# gsu-cetloe/gadget-console-php

> 标签: PHP

## 简介

Gadget library for Symfony console apps: a logging-aware command base, a shell command runner, and a listener that logs command start, finish, and errors, with a Symfony bundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
