# gsu-cetloe/gadget-core-php

> 标签: framework, micro

## 简介

Gadget is a PHP micro framework of small, dependency-free helpers for casting, JSON, Base32, files, DOM parsing, timing, and one-time passwords

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
