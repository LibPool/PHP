# gsu-cetloe/brightspace-api-core-php

> 标签: PHP

## 简介

Core client for the D2L Brightspace API: web login with multi-factor support, OAuth token handling, versioned API URL rewriting, and paging helpers, with a Symfony bundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
