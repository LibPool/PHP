# gsu-cetloe/brightspace-api-php

> 标签: PHP

## 简介

Typed PHP clients for the D2L Brightspace REST API: users, enrollments, org units, and learning outcome registries, with a Symfony bundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
