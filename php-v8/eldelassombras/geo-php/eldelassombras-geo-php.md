# eldelassombras/geo-php

> 标签: api, geolocation, google, maps, php

## 简介

Esta clase PHP de geolocalización se conecta a la API de Google Maps para encontrar latitud / longitud o dirección.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
