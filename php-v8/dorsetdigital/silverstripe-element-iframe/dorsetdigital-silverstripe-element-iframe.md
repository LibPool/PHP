# dorsetdigital/silverstripe-element-iframe

> 标签: elemental, iframe, module, silverstripe

## 简介

Adds an elemental content block to embed an iframe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
