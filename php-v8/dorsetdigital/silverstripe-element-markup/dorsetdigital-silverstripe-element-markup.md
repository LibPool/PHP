# dorsetdigital/silverstripe-element-markup

> 标签: elemental, embed, markup, module, silverstripe

## 简介

Allows the addition of arbitrary markup in an Elemental block

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
