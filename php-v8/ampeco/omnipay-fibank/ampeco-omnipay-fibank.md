# ampeco/omnipay-fibank

> 标签: ecomm, fibank, omnipay, recurring payments

## 简介

Omnipay plugin for fibank ECOMM recurring payments

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
