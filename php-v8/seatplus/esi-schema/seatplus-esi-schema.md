# seatplus/esi-schema

> 标签: API-Client, ccp, dto, esi, eve, eve-online, eveonline, openapi, sdk, seatplus, typed

## 简介

Fully typed PHP SDK for EVE Online's ESI API, generated from the official OpenAPI spec. One class per endpoint with typed response DTOs, OAuth scopes, cache lifetimes and rate-limit metadata. Zero runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
