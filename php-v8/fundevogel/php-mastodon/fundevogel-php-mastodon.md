# fundevogel/php-mastodon

> 标签: api, mastodon, oauth, rest, social

## 简介

A small PHP library for interacting with Mastodon's REST API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
