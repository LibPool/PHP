# fundevogel/kirby3-donuts

> 标签: charts, kirby3, svg

## 简介

Kirby v3 wrapper for tiny-phpeanuts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
