# fundevogel/php-pcbis

> 标签: api, knv, pcbis, webservice, zeitfracht

## 简介

Simple PHP wrapper for Zeitfracht's webservice API, written in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
