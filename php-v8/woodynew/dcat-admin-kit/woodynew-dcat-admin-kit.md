# woodynew/dcat-admin-kit

> 标签: admin, dcat-admin, extension, laravel

## 简介

Reusable, project-neutral extensions for Woodynew Dcat Admin applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
