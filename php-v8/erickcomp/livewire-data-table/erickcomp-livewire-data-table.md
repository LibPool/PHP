# erickcomp/livewire-data-table

> 标签: data, data-table, framework, laravel, livewire, table

## 简介

Provides a html/blade centric data table approach leveraging Livewire's reactiveness for a great UX.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
