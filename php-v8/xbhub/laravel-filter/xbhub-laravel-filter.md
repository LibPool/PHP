# xbhub/laravel-filter

> 标签: eloquent, filter, filters, filtration, laravel, query, search

## 简介

A simple, clean and elegant way to filter Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
