# vadimermolenko8787/scanner-trap

> 标签: Honeypot, blacklist, firewall, ip-blocking, middleware, psr-15, redis, scanner, security, vulnerability-scanner, waf

## 简介

Blacklists vulnerability scanners on their first probe of a decoy path such as /.env. File, Redis or APCu storage, optional central database for several servers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
