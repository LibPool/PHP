# hasanhawary/export-builder

> 标签: csv, excel, export, laravel, pdf, xls, xlsx

## 简介

A modular Laravel export builder around maatwebsite/excel (CSV/XLS/XLSX,PDF)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
