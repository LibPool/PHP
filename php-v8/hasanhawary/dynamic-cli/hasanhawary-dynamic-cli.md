# hasanhawary/dynamic-cli

> 标签: cli, crud, generator, laravel, scaffolding

## 简介

A Laravel package providing a dynamic CLI scaffolder for CRUD generation (skeleton).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
