# anglemx/mexico-curp

> 标签: angle, curp, mexico, renapo

## 简介

PHP utility to handle Mexico's RENAPO (Registro Nacional de Población) CURP (Clave Única de Registro de Población)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
