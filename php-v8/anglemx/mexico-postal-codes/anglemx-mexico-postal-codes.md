# anglemx/mexico-postal-codes

> 标签: angle, mexico, postalcode, zipcode

## 简介

PHP utility and database to lookup Mexico Postal Code information

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
