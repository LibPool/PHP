# digitlimit/githook

> 标签: Laravel events, digitlimit, githook, github, github events, github webhook, github webhook events, github webhook listener, laravel, laravel github webhook, laravel listeners, listen for github events, webhook

## 简介

A Laravel package to handle GitHub webhooks seamlessly by dispatching Laravel events for all GitHub events. Users can listen to and handle these events easily.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
