# reallifekip/immutable-base

> 标签: array-conversion, data-transfer-object, ddd, domain-driven-design, dto, immutable, php, php84, readonly, reflection, serialization, single-value-object, svo, toArray, toJson, type-safety, validation, value-object, vo

## 简介

Strict immutable DTOs, VOs, and SVOs for PHP 8.4+ with construction-time type validation, deep path mutation, and automatic validation chaining.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
