# quinninteractive/silverstripe-auth-remote-user

> 标签: PHP

## 简介

Logs members in via the REMOTE_USER server variable; optionally creates new members.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
