# pschwisow/phergie-irc-plugin-react-puppet

> 标签: bot, irc, phergie, plugin

## 简介

Phergie plugin that allows a user to effectively speak and act as the bot.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
