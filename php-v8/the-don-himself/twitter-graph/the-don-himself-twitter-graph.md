# the-don-himself/twitter-graph

> 标签: Amazon Neptune, Azure Cosmos DB, Datastax Enterprise Graph, graph, gremlin-ogm, gremlin-php, janusgraph, neo4j, orientdb, twitter

## 简介

An example graph database implementation of Twitter using the Gremlin OGM library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
