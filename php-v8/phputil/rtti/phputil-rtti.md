# phputil/rtti

> 标签: php, private, protected, rtti, run-time

## 简介

A Run-Time Type Information extractor, useful for getting/setting private attributes from/to PHP objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
