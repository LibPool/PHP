# karelwintersky/monolog-pdo-handler

> 标签: database, log, logging, monolog, pdo

## 简介

A handler for Monolog that stores data via PDO driver to Database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
