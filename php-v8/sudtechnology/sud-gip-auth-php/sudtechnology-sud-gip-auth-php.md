# sudtechnology/sud-gip-auth-php

> 标签: Authentication, auth, gip, sdk, sud

## 简介

PHP implementation of Sud GIP authentication system with JWT support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
