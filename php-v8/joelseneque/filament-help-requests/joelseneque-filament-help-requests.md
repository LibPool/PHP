# joelseneque/filament-help-requests

> 标签: filament, github, help-desk, laravel, livewire, support

## 简介

A Filament v5 help desk: a floating in-app help widget, an admin triage resource, email + database notifications, and optional two-way GitHub issue sync via a GitHub App.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
