# madj2k/t3-gadgeto-google

> 标签: Google Geo, TYPO3 CMS, geolocation, google maps

## 简介

Extension with Utilites and ViewHelper for accession Google API and Google Maps

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
