# frankencms/franken-cms

> 标签: FrankenCMS, cms, filamentphp, franken-cms, laravel, wordpress

## 简介

Franken CMS is a Wordpress alternative powered by Laravel and FilamentPHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
