# codepower/sms-mitake

> 标签: Taiwan, mitake, sms, 三竹, 簡訊

## 简介

A PHP client for the Mitake (三竹簡訊) SMS HTTP API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
