# codepower/anybase

> 标签: base-convert, base-converter, base16, base32, base36, base58, base62, base64, crockford, decode, encode, hashids, id-obfuscation, obfuscation

## 简介

Convert integers between arbitrary bases with custom alphabets, salt, padding, and big-integer support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
