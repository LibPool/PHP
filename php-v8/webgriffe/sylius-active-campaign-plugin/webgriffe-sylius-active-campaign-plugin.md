# webgriffe/sylius-active-campaign-plugin

> 标签: sylius, sylius-plugin, test-appication

## 简介

Plugin allowing to integrate marketing automation made by ActiveCampaign in Sylius.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
