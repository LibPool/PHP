# webgriffe/sylius-pagolight-plugin

> 标签: heylight, pagolight, sylius, sylius-plugin

## 简介

Sylius plugin for HeyLight payment gateway (ex PagoLight BNPL and PagoLight PRO)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
