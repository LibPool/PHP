# webgriffe/magento2-phpunit

> 标签: PHP

## 简介

Metapackage that installs the correct PHPUnit version depending on the version of Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
