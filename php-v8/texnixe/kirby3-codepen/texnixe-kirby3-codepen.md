# texnixe/kirby3-codepen

> 标签: kirby3, kirby3-cms, kirby3-plugin

## 简介

Kirby 3 plugin providing a KirbyTag for CodePen embeds

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
