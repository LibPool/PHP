# pimcore-extensions/search-php

> 标签: lucene, pimcore, search

## 简介

Pimcore Website Search (powered by Zend_Search_Lucene)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
