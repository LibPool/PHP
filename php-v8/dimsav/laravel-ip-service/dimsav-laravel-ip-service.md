# dimsav/laravel-ip-service

> 标签: IP, country, laravel, nation

## 简介

A Laravel package to get the client's country using the ip. A wrapper for http://ip2nation.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
