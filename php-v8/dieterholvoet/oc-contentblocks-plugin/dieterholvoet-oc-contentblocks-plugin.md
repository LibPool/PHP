# dieterholvoet/oc-contentblocks-plugin

> 标签: Content Blocks, october, octobercms, paragraphs

## 简介

Attach model-based content blocks to pages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
