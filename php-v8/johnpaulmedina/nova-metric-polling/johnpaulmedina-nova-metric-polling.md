# johnpaulmedina/nova-metric-polling

> 标签: laravel, nova, nova4

## 简介

An extension of Laraval Nova Metrics to allow for interval polling.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
