# comtocode/ctc-socialnetworkimportbundle

> 标签: PHP

## 简介

This bundle is used to import social feeds (facebook, twitter, instagram, youtube,...) into eZ Platform content

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
