# webhook-ledger/webhook-ledger-bundle

> 标签: PHP

## 简介

Idempotent webhooks consumption with retries and replays, through transactional outbox, using Doctrine and Symfony messenger.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
