# lpdfio/lpdf

> 标签: PHP

## 简介

PHP SDK for Lpdf — PDF as Code on every platform. You describe a document as code or XML. Lpdf renders a compact, pixel-perfect PDF — identical across platforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
