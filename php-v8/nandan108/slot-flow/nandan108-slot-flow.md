# nandan108/slot-flow

> 标签: PHP

## 简介

SlotFlow is a domain-neutral, deterministic engine for modeling and executing quantity flows across a multidimensional state space.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
