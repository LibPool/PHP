# nandan108/dto-toolkit

> 标签: PHP

## 简介

A modern, framework-agnostic PHP 8.1+ DTO system with attribute-driven data normalization and mapping to entities or arrays.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
