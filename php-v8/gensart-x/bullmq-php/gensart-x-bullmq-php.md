# gensart-x/bullmq-php

> 标签: background, bullmq, job, queue, redis, scheduler, task, worker

## 简介

BullMQ Queue client for PHP - Schedule jobs to be processed by BullMQ workers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
