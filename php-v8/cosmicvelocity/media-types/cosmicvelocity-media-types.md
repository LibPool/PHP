# cosmicvelocity/media-types

> 标签: contenttype, mediatype, mime, mimetypes, php

## 简介

Detect the Media Type (MIME Type) of a file or extentions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
