# stmswitcher/yii2-ldap-auth

> 标签: auth, extension, ldap, yii2

## 简介

Simple library to handle auth over LDAP in Yii 2 applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
