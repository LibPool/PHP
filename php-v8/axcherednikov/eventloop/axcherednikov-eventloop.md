# axcherednikov/eventloop

> 标签: PHP

## 简介

Native PHP extension providing a high-performance event loop with epoll/kqueue/poll support. API-compatible with Revolt.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
