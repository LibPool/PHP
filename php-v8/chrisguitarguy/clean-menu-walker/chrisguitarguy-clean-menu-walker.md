# chrisguitarguy/clean-menu-walker

> 标签: wordpress

## 简介

A WordPress menu walker implementation that doesn't attempt to indent and cleans up class names.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
