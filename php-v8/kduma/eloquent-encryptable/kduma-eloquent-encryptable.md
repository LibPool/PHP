# kduma/eloquent-encryptable

> 标签: crypt, eloquent, encode, encrypt, laravel

## 简介

Adds possibility to encrypt fields in Laravel Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
