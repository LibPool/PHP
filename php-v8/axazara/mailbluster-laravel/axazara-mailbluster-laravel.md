# axazara/mailbluster-laravel

> 标签: AxaZara, laravel, mailbluster, mailbluster-laravel

## 简介

This is simple PHP Package for Laravel to interact with MailBluster API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
