# fajarsulaksono/laravel-countries

> 标签: capitals, countries, currency, iso_3166_2, iso_3166_3, laravel

## 简介

Modern Laravel Countries package providing ISO 3166-2, ISO 3166-3, currency, capital and more for all countries. Compatible with Laravel 10.x, 11.x, 12.x, and 13.x.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
