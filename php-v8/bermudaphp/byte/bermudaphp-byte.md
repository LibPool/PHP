# bermudaphp/byte

> 标签: bytes, conversion, data-size, file-size, formatting, units

## 简介

A robust PHP class for working with data size units (bytes, kilobytes, megabytes, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
