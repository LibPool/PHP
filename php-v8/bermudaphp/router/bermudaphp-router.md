# bermudaphp/router

> 标签: attributes, cache, middleware, php8, psr-15, router, routing, url-generation

## 简介

Flexible and performant routing library for PHP 8.4+ with route caching support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
