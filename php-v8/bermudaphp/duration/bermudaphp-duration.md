# bermudaphp/duration

> 标签: duration, duration-parser, immutable, iso8601, iso8601-duration, php, php84, value-object

## 简介

An immutable PHP library for handling time durations with ISO 8601 support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
