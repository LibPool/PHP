# kreait/tape-recorder-subscriber

> 标签: PHP

## 简介

Record HTTP interactions to replay them later with the Tape Recorder Subscriber for the Ivory HTTP Adapter

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
