# yalesov/php-cs-fixer

> 标签: php, standard

## 简介

Analyzes some PHP source code and tries to fix coding standards issues (PSR-1 and PSR-2 compatible)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
