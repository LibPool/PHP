# swow-cloud/archer

> 标签: async, coroutine, serendipity, server, swoole, swow, task

## 简介

基于Swow的Task组件，支持多种模式。轻松实现协程Task的队列、并发、Defer | Swow coroutine task kit - Swoole Humanization Library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
