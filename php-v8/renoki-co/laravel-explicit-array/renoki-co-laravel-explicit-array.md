# renoki-co/laravel-explicit-array

> 标签: arr, array, laravel, php, support

## 简介

Improved Laravel dot notation for explicit array keys.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
