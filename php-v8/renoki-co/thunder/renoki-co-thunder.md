# renoki-co/thunder

> 标签: billing, cashier, laravel, php, saas, stripe, thunder

## 简介

Thunder is an advanced Laravel tool to track user consumption using Cashier's Metered Billing for Stripe. ⚡

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
