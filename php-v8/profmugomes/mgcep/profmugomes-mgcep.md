# profmugomes/mgcep

> 标签: PHP

## 简介

É uma biblioteca leve e simples em PHP para consulta de CEP utilizando a API pública do ViaCEP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
