# profmugomes/blumiga

> 标签: blumiga, composer, framework, functional, lightweight, microframework, modular, mvc, php, procedural

## 简介

Blumiga é um microframework MVC procedural para PHP com suporte a MySQL/MariaDB via BlumigaDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
