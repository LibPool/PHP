# nadlambino/laravel-query-builder

> 标签: NadLambino, laravel-query-builder, spatie

## 简介

This is a forked of spatie/laravel-query-builder but decoupled the builder from request.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
