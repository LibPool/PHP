# mathsgod/light-server

> 标签: PHP

## 简介

A lightweight PHP 8.1+ file-based routing server inspired by Nuxt.js pages, built on PSR-7/PSR-15 with League Route and Laminas.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
