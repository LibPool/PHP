# payapi/somepay-branding

> 标签: PHP

## 简介

Defines the SomePay Branding code to use with Webshop plugins and PayApi PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
