# arnautdev/filament-deploy-indicator

> 标签: arnautdev, filament, filament-deploy-indicator, filament-deploy-info, filament-env, filament-plugin, filamentphp, laravel

## 简介

Show application ENV and latest deployment info inside your Filament admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
