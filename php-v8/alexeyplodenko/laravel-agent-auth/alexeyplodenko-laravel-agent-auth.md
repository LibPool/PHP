# alexeyplodenko/laravel-agent-auth

> 标签: agent-authentication, ai-agents, chrome-devtools, filament, filament-admin, filamentphp, laravel, mcp, model-context-protocol, passwordless-login, playwright, puppeteer, signed-url, temporary-signed-route, testing-automation

## 简介

Passwordless authentication and temporary signed-URL login for AI agents, Chrome DevTools MCP, Playwright, and Filament admin panels in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
