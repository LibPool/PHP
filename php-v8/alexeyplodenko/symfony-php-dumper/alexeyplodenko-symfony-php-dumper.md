# alexeyplodenko/symfony-php-dumper

> 标签: debug, dump

## 简介

The package provides a simple dump function, based on the Symfony VarDumper package, to output the variables and stop execution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
