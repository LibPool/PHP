# reeyanto/laravel-admin-starter

> 标签: admin, bootstrap, framework, laravel, sneat, starter kit

## 简介

Starter kit untuk pengembangan aplikasi web (bagian administrator) berbasis Laravel 10.10, dan CSS Bootstrap 5 (Template admin bernama Sneat)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
