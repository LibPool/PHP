# ls-a/font-finder

> 标签: MAC, finder, font, linux, operating-system, os, unix, windows

## 简介

Find every font registered on server Operating System. Inspiration found in Apache FOP FontFileFinder

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
