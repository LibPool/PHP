# ls-a/xsl-core

> 标签: W3C, a11y, accessibility, fo, fop, pdf, specification, xsl

## 简介

Port of XSL 1.1 specification (W3C Recommendation 05 December 2006).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
