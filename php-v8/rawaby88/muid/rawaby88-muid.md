# rawaby88/muid

> 标签: identifier, laravel, muid, prefixed-ids, stripe-ids, uuid

## 简介

Laravel package for generating prefixed, validatable unique identifiers similar to Stripe's ID format

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
