# teamgate/php-api-sdk

> 标签: PHP

## 简介

Teamgate API SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/teamgate/php-sdk
- 源码仓库：https://github.com/teamgate/php-sdk.git
- Packagist 页面：https://packagist.org/packages/teamgate%2Fphp-api-sdk
