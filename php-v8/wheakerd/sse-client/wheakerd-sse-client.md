# wheakerd/sse-client

> 标签: hyperf, php, server sent event, sse, super-kernel, swoole

## 简介

SSE coroutine client based on swoole implementation, suitable for hyperf or super-kernel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
