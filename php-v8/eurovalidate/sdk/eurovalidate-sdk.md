# eurovalidate/sdk

> 标签: Europe, IBAN, company, eori, eu, eurovalidate, lei, tax, validation, vat

## 简介

PHP SDK for the EuroValidate API — EU VAT, IBAN, EORI validation and company data lookup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
