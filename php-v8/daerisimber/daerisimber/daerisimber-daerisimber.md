# daerisimber/daerisimber

> 标签: framework, theme, wordpress

## 简介

A modern WordPress theme skeleton using Timber, ACF Pro, Tailwind CSS and Alpine JS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
