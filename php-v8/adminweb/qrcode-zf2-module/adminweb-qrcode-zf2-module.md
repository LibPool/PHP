# adminweb/qrcode-zf2-module

> 标签: framework, google, qr code, zend 2, zf2

## 简介

A zend framework 2 module for generate qr code using the google api.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
