# tallcms/tallcms

> 标签: alpinejs, cms, filament, laravel, livewire, tailwind, tallstack

## 简介

A modern CMS built on Laravel, Livewire, Alpine.js, and Filament. The TALL stack CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
