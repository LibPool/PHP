# dipinkrishna/laravel-merchantsuite

> 标签: laravel, linkly, merchantsuite, payment-gateway, payments, tokenisation

## 简介

Laravel client for the MerchantSuite (Linkly) payments API v5: transactions, tokens, AuthKey checkout and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
