# pacific/licentra-client

> 标签: codecanyon, envato, laravel, license, purchase-code

## 简介

License activation and install telemetry client for Isha Labs products (Envato purchase codes).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
