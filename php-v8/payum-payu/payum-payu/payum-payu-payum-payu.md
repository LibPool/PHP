# payum-payu/payum-payu

> 标签: gateway, payment, payu, payum, psr-18, recurring

## 简介

PayU (REST API 2.1) gateway for Payum: hosted checkout, card-token recurring payments, signed notifications, refunds and cancellation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
