# philetaylor/doctrine-encrypt

> 标签: decrypt, doctrine, encrypt, symfony

## 简介

Symfony 3.4+/PHP7.2+ bundle which allows to encrypt data in database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
