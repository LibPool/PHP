# philetaylor/akeeba

> 标签: Akeeba, BlueFlame, backup, dev

## 简介

Symfony 3+ bundle to interact with the Akeeba Backup API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
