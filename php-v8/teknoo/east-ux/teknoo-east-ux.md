# teknoo/east-ux

> 标签: East, live-component, stimulus, symfony-ux, twig-component, ux

## 简介

Symfony bundle, following the #East programming philosophy, build on Teknoo/East-Foundation and Teknoo/East-Common, providing the application-level UI pieces of an East application: Symfony UX Twig and Live Components (windows, forms, lists, menu bar, ...), their Stimulus controllers and stylesheet, a component renderer endpoint and a menu service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
