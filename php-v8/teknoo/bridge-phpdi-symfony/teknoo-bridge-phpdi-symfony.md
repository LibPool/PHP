# teknoo/bridge-phpdi-symfony

> 标签: Bridge, di, phpdi, symfony

## 简介

Userfriendly integration of PHP-DI with Symfony, Fork from php-di/symfony-bridge

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
