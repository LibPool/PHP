# elvi/auth0-symfony

> 标签: Authentication, JSON Web Token, JWK, OpenId, api, auth, auth0, authorization, json web key, jwt, login, oauth, protect, secure, symfony

## 简介

Symfony SDK for Auth0 Authentication and Management APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
