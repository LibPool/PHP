# jwtc/qccx-rpc-client

> 标签: PHP

## 简介

基于阿里SAE和网关路由的一个RPC客户端 部署在SAE的各个PHP服务间通过此客户端进行相互调用

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
