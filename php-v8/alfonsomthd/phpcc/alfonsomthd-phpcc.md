# alfonsomthd/phpcc

> 标签: automation, check, code, git, php, phpcc, pre-commit, tool

## 简介

A PHP code checks automation tool that can be used as git pre-commit hook.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
