# homlity/sdk-fincaraiz

> 标签: API-Client, colombia, finca-raiz, fincaraiz, homlity, inmobiliaria, integradores, proptech, real-estate, sdk, webhooks

## 简介

SDK PHP para la API de Integradores de Finca Raiz: publica, actualiza y sincroniza inmuebles con validacion de payloads, estados tipados y webhooks. Mantenido por Homlity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
