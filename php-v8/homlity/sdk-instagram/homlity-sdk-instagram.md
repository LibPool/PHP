# homlity/sdk-instagram

> 标签: Integración, api, content-publishing, graph-api, homlity, instagram, oauth, sdk, social-media

## 简介

SDK PHP de Homlity para la Instagram Graph API con Instagram Login: OAuth embebido, tokens de larga duracion renovables y publicacion de imagenes, carruseles y reels. Sin dependencias de runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
