# homlity/chat-sdk

> 标签: ai, chat, hmac, homlity, sdk, webhooks, whatsapp

## 简介

SDK PHP para la API de Chat Homlity: conversaciones de WhatsApp, asistente de IA, campañas y webhooks firmados para plataformas multi-inquilino.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
