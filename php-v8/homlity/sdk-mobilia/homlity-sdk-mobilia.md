# homlity/sdk-mobilia

> 标签: api, crm, homlity, inmobiliaria, mobilia, mobiliagestion, proptech, real-estate, sdk

## 简介

SDK PHP oficial de Homlity para la API de Mobilia Gestión: autenticación OAuth2, inmuebles, paginación y agentes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
