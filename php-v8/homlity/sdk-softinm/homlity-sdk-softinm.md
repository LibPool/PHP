# homlity/sdk-softinm

> 标签: api, homlity, inmobiliaria, inmuebles, sdk, softinm

## 简介

SDK de Homlity para consultar el inventario de inmuebles de SoftInm (Zona Clientes) desde PHP, Laravel o WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
