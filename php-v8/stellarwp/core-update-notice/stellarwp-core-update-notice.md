# stellarwp/core-update-notice

> 标签: PHP

## 简介

A WordPress core update notice scoped to consuming plugins' admin pages, with dismissal shared across plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
