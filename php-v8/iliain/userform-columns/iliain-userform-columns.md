# iliain/userform-columns

> 标签: columns, module, silverstripe, userforms

## 简介

Duplicates the Userform Field Group feature to allow adding columns to forms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
