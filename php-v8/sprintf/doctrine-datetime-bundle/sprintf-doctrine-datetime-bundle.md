# sprintf/doctrine-datetime-bundle

> 标签: date, daterange, datetime, doctrine, postgres

## 简介

Symfony Bundle by Sprint-F.RU designed to support date, datetime, daterange Postgres types

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
