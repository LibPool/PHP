# flux-se/sylius-hcaptcha-plugin

> 标签: sylius, sylius-plugin

## 简介

Plugin adding the hCaptcha field to some frontend FormType of Sylius

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
