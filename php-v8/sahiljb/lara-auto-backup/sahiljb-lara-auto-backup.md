# sahiljb/lara-auto-backup

> 标签: backup, cloudflare, database, laravel, mysql, postgresql, r2, s3, scheduled-backup

## 简介

Automated database backups for Laravel — dump MySQL, MariaDB, PostgreSQL or SQLite on a schedule and upload to AWS S3 or Cloudflare R2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
