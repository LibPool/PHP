# flowsell/connect

> 标签: PHP

## 简介

Official PHP SDK for FlowSell Connect wrapper APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://connect.flowsell.app
- 源码仓库：https://github.com/flowsell-connect/flowsell-connect-php-sdk.git
- Packagist 页面：https://packagist.org/packages/flowsell%2Fconnect

## 历史版本号

- 当前版本：v0.1.0

- v0.1.0

## 获取地址

- Composer 安装：`composer require flowsell/connect`
- Packagist 仓库：https://repo.packagist.org/p2/flowsell/connect.json
- 许可证：MIT
- PHP 要求：>=8.1
