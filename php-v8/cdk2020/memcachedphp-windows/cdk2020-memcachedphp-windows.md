# cdk2020/memcachedphp-windows

> 标签: cache, caching, emulator, memcache, memcached, windows

## 简介

Memcached PHP extension emulator for Windows environments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
