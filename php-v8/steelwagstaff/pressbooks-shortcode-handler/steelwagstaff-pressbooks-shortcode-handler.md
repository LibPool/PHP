# steelwagstaff/pressbooks-shortcode-handler

> 标签: PHP

## 简介

A plugin for Pressbooks which handles additional shortcodes used by Lumen Learning

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
