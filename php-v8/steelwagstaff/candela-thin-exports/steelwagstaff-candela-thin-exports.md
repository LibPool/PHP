# steelwagstaff/candela-thin-exports

> 标签: PHP

## 简介

A plugin which allows users to create Thin Common Cartridge Exports for Pressbooks titles. This plugin is based largely on Lumen Learning's Candela Thin Exports plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
