# codecrafter/laravel-menu

> 标签: codecrafter, filament, laravel, mega-menu, menu, navigation, tree

## 简介

Tree-based menu builder for Laravel with Filament 5 admin panel integration. Supports nested menus, mega-menu columns, caching and Blade components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
