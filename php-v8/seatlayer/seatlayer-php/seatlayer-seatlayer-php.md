# seatlayer/seatlayer-php

> 标签: box-office, event-ticketing, php, reserved-seating, seat-booking, seat-map, seating-chart, seatlayer, server-sdk, ticketing

## 简介

Official PHP server SDK for the SeatLayer reserved-seating API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
