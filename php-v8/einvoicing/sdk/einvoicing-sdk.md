# einvoicing/sdk

> 标签: EN16931, e-invoicing, invoice, peppol, ubl, vat

## 简介

PHP client for the einvoicing.dev API: validate, convert and look up Peppol e-invoices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
