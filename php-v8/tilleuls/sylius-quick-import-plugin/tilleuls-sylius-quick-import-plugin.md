# tilleuls/sylius-quick-import-plugin

> 标签: catalog, import, sylius, sylius-plugin

## 简介

Plugin to import taxons (one level only) and products in Sylius.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
