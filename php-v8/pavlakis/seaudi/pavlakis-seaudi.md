# pavlakis/seaudi

> 标签: container, di, ioc, reflection, slim

## 简介

A semi-automatic DI resolver retrieving dependencies through a container.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
