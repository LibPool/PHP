# dipenparmar12/exportcsv

> 标签: ExportCsv, dipen parmar, dipenparmar12, laravel

## 简介

Laravel package for export csv files from database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
