# monkeylearn/monkeylearn-php

> 标签: machine learning, monkeylearn, php

## 简介

Official PHP client for the MonkeyLearn API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
