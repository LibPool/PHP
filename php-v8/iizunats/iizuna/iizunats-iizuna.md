# iizunats/iizuna

> 标签: TYPO3 CMS, frontend, iizuna, templates

## 简介

A TYPO3 Extension that allows the use of server-side rendered but client side hydrated applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
