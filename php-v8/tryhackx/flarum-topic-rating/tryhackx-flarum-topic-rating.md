# tryhackx/flarum-topic-rating

> 标签: 5-star, Rating, discussion, extension, flarum, half-star, moderation, review, stars, tag-permissions

## 简介

Interactive 5-star topic rating system for Flarum with half-star precision, live hover previews, real-time polling updates, per-device list styles, and advanced per-tag permissions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
