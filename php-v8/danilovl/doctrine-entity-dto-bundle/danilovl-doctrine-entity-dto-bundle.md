# danilovl/doctrine-entity-dto-bundle

> 标签: bundle, php, symfony

## 简介

The Symfony bundle provides a simple mechanism to convert Doctrine entities to DTO objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
