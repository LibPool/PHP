# mercurioplatform/tables

> 标签: admin, blade, bootstrap, bulk-actions, datatable, laravel, saved-views, tables

## 简介

Reusable list/table engine for Laravel admin (Bootstrap 5 + jQuery + Blade).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
