# gsferro/select2easy

> 标签: Select2Easy, easy, eloquent, laravel, plugin, seach, select2

## 简介

Uso global e generico do plugin select2 ajax utilizando o laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
