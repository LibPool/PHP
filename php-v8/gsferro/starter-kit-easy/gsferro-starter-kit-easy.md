# gsferro/starter-kit-easy

> 标签: admin-panel, boilerplate, filament, laravel, starter-kit

## 简介

Starter kit Laravel 13 + Filament 5 pronto para uso: painéis app, admin e infra, permissões, observabilidade, IA local e Docker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
