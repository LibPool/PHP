# gsferro/filament-odometer-easy

> 标签: Odometer, animation, counter, dashboard, filament, filament-odometer-easy, filament-plugin, filamentphp, gsferro, laravel, number-flow

## 简介

Animated counters for Filament v3, v4 and v5 — tables, infolists, stats and navigation badges — powered by number-flow (default) or odometer.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
