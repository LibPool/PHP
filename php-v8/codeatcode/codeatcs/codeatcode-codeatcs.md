# codeatcode/codeatcs

> 标签: PHP

## 简介

Codeat PHPCS ruleset for OOP WordPress development on PHP 7.0+, include phpmd ruleset

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
