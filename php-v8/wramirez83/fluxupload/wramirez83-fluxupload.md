# wramirez83/fluxupload

> 标签: chunking, file-upload, laravel, large-files, resumable-upload

## 简介

Laravel package for large file uploads using chunking with automatic resumption

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
