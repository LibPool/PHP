# kevinkorb/opentok

> 标签: OpenTok, TokBox, WebRTC, php, streaming, video

## 简介

OpenTok is a platform for creating real time streaming video applications, created by TokBox.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
