# lekoala/kaly-tasks

> 标签: Tasks, jobs, outbox, postgresql, queue, sqlite, worker

## 简介

Durable PostgreSQL or SQLite task queue for Kaly invocable tasks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
