# lekoala/kaly

> 标签: PSR-11, framework, http, middleware, psr-15, psr-7, router

## 简介

A small modular PSR HTTP framework with convention-based routing and first-class dependency injection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
