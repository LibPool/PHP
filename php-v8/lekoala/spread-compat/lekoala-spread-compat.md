# lekoala/spread-compat

> 标签: csv, excel, package, php, spreadsheet, xls, xlsx

## 简介

Easily read and write CSV, XLSX and ODS using interchangeable adapters

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
