# facilie/whatsapp-api-client

> 标签: api, facilie, php, whatsapp

## 简介

Cliente PHP para integração com a API de WhatsApp da Facilie.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
