# paschaldev/eloquent-translate

> 标签: eloquent, google, i18n, laravel, paschaldev, translatable, translate

## 简介

A package for translating Laravel models with ease.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
