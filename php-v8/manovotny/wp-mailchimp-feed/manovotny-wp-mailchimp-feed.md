# manovotny/wp-mailchimp-feed

> 标签: email, feed, mailchimp, rss, wordpress

## 简介

Adds a WordPress feed for MailChimp for better content control.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
