# bromimo/btx-docker

> 标签: PHP

## 简介

Docker-окружение для разработки на 1С-Битрикс (Nginx + PHP + MySQL + PhpMyAdmin + Maildev)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
