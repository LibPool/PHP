# the-firehub-project/foundation

> 标签: firehub, foundation, php

## 简介

A high-level foundation layer of the FireHub ecosystem, built on top of Runtime to provide expressive and developer-friendly APIs for common programming tasks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
