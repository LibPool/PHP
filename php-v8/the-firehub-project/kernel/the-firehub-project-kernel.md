# the-firehub-project/kernel

> 标签: bootstrap, dependency-injection, firehub, framework, kernel, lifecycle, php

## 简介

Application kernel providing bootstrap orchestration, lifecycle management, and service integration for the FireHub Framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
