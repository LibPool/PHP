# the-firehub-project/container

> 标签: bootstrap, dependency-injection, firehub, framework, kernel, lifecycle, php

## 简介

A modular dependency injection container for The FireHub Project, providing service registration, dependency resolution, lifecycle management, and extensible service definitions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
