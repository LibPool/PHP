# letots/make-bundle

> 标签: 2fa, Authentication, asset, maker, php, sass, symfony, tailwind, user

## 简介

Extended maker bundle for Symfony : full authentication, full assets install, etc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
