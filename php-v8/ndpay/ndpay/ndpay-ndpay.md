# ndpay/ndpay

> 标签: PHP

## 简介

全场景支付涵盖（微信、支付宝、小程序、H5、PC、APP、公众号、生活号、线下扫码、人脸识别（微信/支付宝）、扫码POS、云喇叭、扫码枪、扫码盒）等等,一套接口全部完成

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
