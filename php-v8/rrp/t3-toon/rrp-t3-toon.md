# rrp/t3-toon

> 标签: decoder, encoder, json, llm, php, serialization, token-efficient, token-oriented-object-notation, toon, toon-format, typo3, typo3-cms-extension

## 简介

TOON for TYPO3 — Spec-compliant TOON for TYPO3: token-efficient AI data format with JSON ⇄ TOON conversion for LLMs and AI agents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
