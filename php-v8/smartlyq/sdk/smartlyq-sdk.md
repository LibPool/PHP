# smartlyq/sdk

> 标签: ai, api, crm, sdk, seo, smartlyq, social-media

## 简介

Official PHP SDK for the SmartlyQ API - social posting, AI content generation, SEO research, CRM, chatbots, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
