# whatis/phpdocumentor-markdown

> 标签: documentation, github, gitlab, markdown, phpDocumentor, phpdoc

## 简介

Markdown template for phpDocumentor3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
