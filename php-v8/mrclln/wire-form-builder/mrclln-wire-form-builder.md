# mrclln/wire-form-builder

> 标签: alpinejs, drag-and-drop, form-builder, laravel, livewire, tailwind

## 简介

A dynamic drag-and-drop form builder for Laravel Livewire. Generates form schema JSON and renders form fields with Tailwind CSS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
