# casperw/laravel-view-model-adaptor

> 标签: LaravelViewModelAdaptor, laravel, view, viewmodel

## 简介

A view model adaptor to simplify the use of view model classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
