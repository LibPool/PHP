# adata-team/php-jaeger

> 标签: jaeger, laravel, lumen, opentracing, php7.3, tracing

## 简介

Laravel/Lumen wrapper for Jaeger distributed tracing. PHP 7.3 compatible.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
