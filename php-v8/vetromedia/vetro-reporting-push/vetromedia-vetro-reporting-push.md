# vetromedia/vetro-reporting-push

> 标签: PHP

## 简介

This package helps push data from USSD & Whatsapp lines to the reporting tool hosted in https://reporting.vetroms.co.za

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
