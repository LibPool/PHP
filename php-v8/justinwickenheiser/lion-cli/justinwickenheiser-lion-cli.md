# justinwickenheiser/lion-cli

> 标签: cli, gvsu, laravel, lion, php

## 简介

A CLI to quickly spin up boiler-plate packages for gvsu-webteam development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
