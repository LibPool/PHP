# sms77/api

> 标签: 2fa, cnam, gateway, hlr, mnp, rcs, sms, text2speech, tts

## 简介

Official API Client for requesting the seven.io messaging Gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
