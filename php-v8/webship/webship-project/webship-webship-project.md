# webship/webship-project

> 标签: PHP

## 简介

Project template for the webship.co Portal site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Packagist 页面：https://packagist.org/packages/webship%2Fwebship-project
