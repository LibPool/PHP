# webship/drupal-patches

> 标签: composer, composer patches, drupal, drupal core, drupal core patches, patches, webship

## 简介

Curated Drupal core patches used by Webship, one branch per Drupal core major.minor version.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
