# lezhnev74/http-analyzer-laravel-adapter

> 标签: PHP

## 简介

Laravel package to track each http request/response and send them to apideveloper.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
