# thomas-liberato/acf-helper-generator

> 标签: acf, code generator, wordpress

## 简介

Automatically creates Helper classes for the ACF fields of a WordPress theme.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
