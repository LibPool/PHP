# ho-nl-fork/psr7-csv-factory

> 标签: csv, export, import, psr-7, read, write

## 简介

a factory to return league csv object from PSR-7 StreamInterface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
