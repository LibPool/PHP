# wisedata/mail-php

> 标签: contacts, email, laravel, transactional, wisedata

## 简介

Cliente PHP da API do WiseData Mail: contatos e envio de e-mail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
