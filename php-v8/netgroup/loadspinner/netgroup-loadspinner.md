# netgroup/loadspinner

> 标签: PHP

## 简介

Bei dieser Software handelt es sich um eine Erweiterung für das Open Source CMS Contao. Sie stellt einen LoadSpinner zur Verfügung.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
