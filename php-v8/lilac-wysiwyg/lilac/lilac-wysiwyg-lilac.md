# lilac-wysiwyg/lilac

> 标签: blade, editor, laravel, lilac, php, wysiwyg

## 简介

PHP and Laravel integration for the Lilac WYSIWYG editor — render the editor from server-side PHP or a Blade component.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
