# guillaumetissier/auth-server

> 标签: PHP

## 简介

Standalone OAuth 2 authorization server: Authorization Code + PKCE, TOTP 2FA, DPoP-bound tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
