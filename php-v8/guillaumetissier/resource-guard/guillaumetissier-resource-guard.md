# guillaumetissier/resource-guard

> 标签: JWKS, dpop, jwt, laravel, oauth2, psr-15, resource-server, rfc9449, symfony

## 简介

Protects an API with OAuth2 access tokens: offline JWT validation via JWKS, DPoP proofs (RFC 9449), domain-scoped access rights, impersonation rules and signed webhooks. Framework-agnostic core with Laravel, Symfony and PSR-15 adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
