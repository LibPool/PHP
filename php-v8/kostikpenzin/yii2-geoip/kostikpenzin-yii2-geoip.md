# kostikpenzin/yii2-geoip

> 标签: PHP7, geo, geoip, geoip-php, geolocation, sypexgeo, yii2

## 简介

Yii2 geoip extension for Sypex Geo API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
