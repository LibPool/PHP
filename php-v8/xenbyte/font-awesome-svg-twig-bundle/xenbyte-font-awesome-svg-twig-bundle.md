# xenbyte/font-awesome-svg-twig-bundle

> 标签: FontAwesome, icons, symfony, twig

## 简介

Symfony bundle to use FontAwesome svg icons as inline svg.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
