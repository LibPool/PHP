# dh_man/dhead-wp

> 标签: PHP

## 简介

A collection of classes to manage CPTs, Taxonomies, ACF Blocks, and Options Pages in WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
