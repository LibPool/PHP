# mawebdk/preg-match

> 标签: PHP

## 简介

PregMatch is an encapsulation of preg_match returning a boolean instead of 0/1 and throwing an exception in case of an error.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
