# fcsapi/rest

> 标签: bitcoin, crypto, cryptocurrency, currency, ethereum, exchange-rates, fcs, fcsapi, forex, market-data, rest-api, stock, trading

## 简介

PHP REST API client for Forex, Cryptocurrency, and Stock market data from FCS API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
