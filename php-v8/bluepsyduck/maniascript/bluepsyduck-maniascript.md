# bluepsyduck/maniascript

> 标签: ManiaPlanet, ManiaScript

## 简介

Lib helping you with building up the ManiaScript of a ManiaLink.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
