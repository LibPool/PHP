# korridor/laravel-model-validation-rules

> 标签: eloquent, exist, laravel, model, rule, validation

## 简介

A laravel validation rule that uses eloquent to validate if a model exists

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
