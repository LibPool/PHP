# magexon/turbosmtp-php

> 标签: api, email, mail, smtp, turboSMTP

## 简介

TurboSMTP PHP SDK for sending emails, managing relays, suppressions, and email validation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
