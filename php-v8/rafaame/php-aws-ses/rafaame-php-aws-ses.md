# rafaame/php-aws-ses

> 标签: aws, php, ses

## 简介

REST-based interface for Amazon Simple Mail Service (SES) written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
