# jakubsilny/eet2

> 标签: EET, eet2, evidence trzeb, financni sprava, pokladna

## 简介

Klient pro EET 2.0 (evidence tržeb od 2027) - podpis WS-Security, odeslání, zpracování odpovědí. Bez závislostí.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
