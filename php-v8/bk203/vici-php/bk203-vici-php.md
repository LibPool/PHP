# bk203/vici-php

> 标签: charon, ike, ipsec, strongswan, vici, vpn

## 简介

Pure-PHP client implementation of the strongSwan VICI protocol to monitor, configure and control the IKE daemon charon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
