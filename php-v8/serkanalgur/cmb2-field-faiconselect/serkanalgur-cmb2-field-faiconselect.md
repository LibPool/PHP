# serkanalgur/cmb2-field-faiconselect

> 标签: PHP

## 简介

Font Awesome icon selector for powerful custom metabox generator CMB2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
