> 标签: FedEx, api, bundle, carrier, fedex api, fedex integration, fedex shipping, fedex symfony, label, logistics, oauth2, rest, shipping, symfony, tracking

## 简介

Symfony bundle for integrating with the FedEx REST API (OAuth2, shipping, rates, tracking).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
