# typedduck/steins-attributes

> 标签: attributes, effects, purity, static analysis

## 简介

Effect-envelope attributes for the PHP;STEINS static analyzer: #[Pure] and #[Effect]. Inert at runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
