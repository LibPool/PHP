# wabuehamm/backtotop

> 标签: elgg, plugin

## 简介

This plugin for Elgg adds a hovering button to the lower right of the page, which scrolls back to the top of page when clicked.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
