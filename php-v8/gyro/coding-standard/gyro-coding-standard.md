# gyro/coding-standard

> 标签: checks, code, coding, cs, dev, gyro, rules, sniffer, sniffs, standard, style

## 简介

The Gyro Coding Standard is a set of PHPCS rules applied to all Gyro and Tideways projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
