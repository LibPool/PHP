# mezzio/mezzio-csrf

> 标签: csrf, laminas, mezzio, psr-15, psr-7, security, session

## 简介

CSRF token generation and validation for PSR-7 and PSR-15 applications using mezzio-session

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
