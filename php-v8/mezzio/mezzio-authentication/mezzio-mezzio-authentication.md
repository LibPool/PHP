# mezzio/mezzio-authentication

> 标签: Authentication, http, laminas, mezzio, middleware, psr-15, psr-7

## 简介

Authentication middleware for Mezzio and PSR-7 applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
