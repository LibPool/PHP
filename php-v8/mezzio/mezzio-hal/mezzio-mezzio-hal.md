# mezzio/mezzio-hal

> 标签: PSR-11, hal, http, laminas, mezzio, psr, psr-13, psr-17, psr-7, rest

## 简介

Hypertext Application Language implementation for PHP and PSR-7

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
