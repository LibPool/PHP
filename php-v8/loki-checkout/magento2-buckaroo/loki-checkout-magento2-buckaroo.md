# loki-checkout/magento2-buckaroo

> 标签: loki-checkout, loki-checkout-category-payment

## 简介

Compatibility module for the Buckaroo payment solution

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
