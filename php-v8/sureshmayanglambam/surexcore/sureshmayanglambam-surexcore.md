# sureshmayanglambam/surexcore

> 标签: blade, cms, codeigniter, codeigniter4, php, shared-hosting

## 简介

SurexCore — a lightweight CMS for shared hosting on CodeIgniter 4 + Blade: content types with a field builder, media library, preview, backups and a web installer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
