# plan2net/link-alchemy

> 标签: extension, internal-urls, link, rte, typo3

## 简介

Rewrite absolute URLs that point to internal pages/files, converting them to internal TYPO3 URLs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
