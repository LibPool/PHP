# plan2net/playwright-toolkit

> 标签: PHP

## 简介

Playwright testing toolkit for TYPO3 CMS: a throwaway database per test file, pre-seeded backend sessions, health and cleanup endpoints.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
