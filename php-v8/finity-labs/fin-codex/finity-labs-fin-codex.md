# finity-labs/fin-codex

> 标签: documentation, filament, help, knowledge-base, laravel

## 简介

In-app help for Filament. A contextual help drawer, help buttons on resources and pages, and an article editor, built on lin-codex.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
