# webbycrown/customization-for-bagisto

> 标签: bagisto, cms, customization, e-commerce, laravel, page-builder, webbycrown

## 简介

Dynamic page customization system for Bagisto - Create and manage page sections, fields, and content from the backend with API support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
