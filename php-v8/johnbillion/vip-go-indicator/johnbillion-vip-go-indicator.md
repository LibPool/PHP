# johnbillion/vip-go-indicator

> 标签: PHP

## 简介

Adds an admin toolbar indicator which identifies the current WordPress.com VIP Go environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
