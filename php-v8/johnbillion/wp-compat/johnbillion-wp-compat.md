# johnbillion/wp-compat

> 标签: PHPStan, wordpress

## 简介

PHPStan extension to help verify that your PHP code is compatible with a given version of WordPress

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
