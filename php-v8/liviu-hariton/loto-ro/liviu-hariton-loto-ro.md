# liviu-hariton/loto-ro

> 标签: laravel, loterie, loto, loto 5-40, loto 6-49, lottery

## 简介

A Laravel package that fetches the Romanian lottery history for the 6/49 and 5/40 draws

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
