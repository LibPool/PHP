# shrestharikesh/log-viewer

> 标签: laravel, log-viewer, logs, ripgrep, sse, streaming, tail

## 简介

High-performance, memory-safe log viewer for Laravel. Streams files of any size (10GB–100GB+) without loading them into memory. Pluggable into any admin dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
