# hyperf/hyperf

> 标签: Microservice, coroutine, hyperf, php, swoole

## 简介

A coroutine framework that focuses on hyperspeed and flexibility. Building microservice or middleware with ease.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
