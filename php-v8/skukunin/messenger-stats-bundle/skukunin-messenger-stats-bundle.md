# skukunin/messenger-stats-bundle

> 标签: Messenger, bundle, health-check, monitoring, prometheus, symfony, symfony-bundle

## 简介

Symfony bundle providing queue statistics, a health check and Prometheus metrics for Symfony Messenger transports

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
