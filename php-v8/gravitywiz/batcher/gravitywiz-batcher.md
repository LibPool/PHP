# gravitywiz/batcher

> 标签: PHP

## 简介

A class for bulk processing items in batches. Useful for migration routines, updating entries, generating content, and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
