# gutocf/cakephp-font-awesome

> 标签: FontAwesome, cakephp, helper

## 简介

Helper for CakePHP 4 that wraps khill/fontawesomephp library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
