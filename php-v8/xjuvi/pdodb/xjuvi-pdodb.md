# xjuvi/pdodb

> 标签: database, mysqli, orm, pdo, thingengineer, wrapper

## 简介

Modern, secure and fully compatible PDO-based replacement for ThingEngineer’s PHP-MySQLi-Database-Class

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
