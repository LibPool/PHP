# slfomin/pwa-laravel

> 标签: inertia, laravel, manifest, pwa, service-worker, vite

## 简介

Comprehensive PWA integration for Laravel 13 + Vite 7 with Inertia v3 support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
