# pactmandev/nonprofit-check-plus

> 标签: BMF, EIN, OFAC, charity, compliance, irs, nonprofit, pactman, pub78, sdk

## 简介

Official PHP SDK for the Pactman Nonprofit Check Plus API — verify US nonprofits by EIN against IRS BMF, Publication 78, Automatic Revocation and OFAC data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
