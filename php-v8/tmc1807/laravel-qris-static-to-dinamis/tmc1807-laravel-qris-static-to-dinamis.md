# tmc1807/laravel-qris-static-to-dinamis

> 标签: EMVCo, dynamic-qris, indonesia, laravel, payment, qr-code, qris

## 简介

Convert static QRIS payloads into dynamic QRIS with a fixed amount for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
