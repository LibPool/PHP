# docile/container

> 标签: Autowiring, PSR-11, container, di, docile, ioc

## 简介

Docile's PSR-11 autowiring dependency injection container with scopes, contextual bindings, and attribute support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
