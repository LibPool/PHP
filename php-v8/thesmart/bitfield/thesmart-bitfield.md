# thesmart/bitfield

> 标签: array, arrays, bitfield, bitmapper, options

## 简介

Map an array of options to a binary bitfield as a string or integer, and back again.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
