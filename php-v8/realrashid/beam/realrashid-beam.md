# realrashid/beam

> 标签: WebRTC, audio-call, beam, file-transfer, laravel, realrashid, reverb, screen-share, turn, video-call

## 简介

Real-time calls, screen sharing and peer-to-peer file transfer for Laravel. PHP authorises, rings and mints TURN credentials; the browser joins with one signed token.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
