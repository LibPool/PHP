# tonix-tuft/tempusdominus

> 标签: DateTimePicker, datepicker, moment, timepicker

## 简介

A date/time picker component designed for Momentjs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
