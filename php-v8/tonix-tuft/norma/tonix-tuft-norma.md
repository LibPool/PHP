# tonix-tuft/norma

> 标签: cli, di, framework, mvc, php, web

## 简介

A simple self-contained PHP framework for web, CLI and other types of PHP applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
