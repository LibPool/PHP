# tonix-tuft/tmp-file

> 标签: file, files, temporary, temporary-file, temporary-files, tmp, tmp-file, tmp-files

## 简介

A simple library to create temporary files in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
