# squipix/html

> 标签: PHP

## 简介

Fork and a Drop-in replacement for collective/html: HTML and Form Builders for the Laravel Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- Packagist 页面：https://packagist.org/packages/squipix%2Fhtml
