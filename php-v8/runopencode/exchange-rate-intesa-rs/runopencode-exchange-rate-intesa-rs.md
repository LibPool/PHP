# runopencode/exchange-rate-intesa-rs

> 标签: banca intesa, banca intesa serbia, exchange rate

## 简介

Plugin for 'runopencode/exchange-rate' library for fetching exchange rates from Banca Intesa Serbia.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
