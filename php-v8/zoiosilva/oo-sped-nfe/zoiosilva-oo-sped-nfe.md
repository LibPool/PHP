# zoiosilva/oo-sped-nfe

> 标签: nfe, nfephp, nota fiscal, nota fiscal eletronica, oo_nfephp, sefaz, sped

## 简介

Uma interface totalmente orientada a objetos para a geração e comunicação da NFe com as SEFAZ autorizadoras.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
