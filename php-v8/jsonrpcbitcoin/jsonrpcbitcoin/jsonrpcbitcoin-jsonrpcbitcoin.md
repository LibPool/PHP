# jsonrpcbitcoin/jsonrpcbitcoin

> 标签: bitcoin, json-rpc

## 简介

JSON-RPC client library for bitcoin in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
