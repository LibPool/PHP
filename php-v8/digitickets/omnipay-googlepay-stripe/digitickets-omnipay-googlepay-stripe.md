# digitickets/omnipay-googlepay-stripe

> 标签: googlepay, omnipay, stripe

## 简介

Custom OmniPay driver for Google Pay (with Stripe)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
