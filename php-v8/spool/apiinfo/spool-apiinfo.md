# spool/apiinfo

> 标签: PHP

## 简介

PHP框架API文档生成工具, 无需生成静态文档. 动态生成. 目前先基于Laravel和Hyperf

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
