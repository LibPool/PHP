# aliirfaan/laravel-simple-jwt

> 标签: jwt, laravel

## 简介

Generate and verify Json Web Token (JWT) in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
