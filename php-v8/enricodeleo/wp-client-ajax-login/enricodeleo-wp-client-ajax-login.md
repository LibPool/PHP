# enricodeleo/wp-client-ajax-login

> 标签: ajax, client, login, wordpress

## 简介

A simple plugin that allows login to wordpress through the client's browser via AJAX.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
