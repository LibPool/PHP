# stellarsecurity/application-insights-laravel

> 标签: PHP

## 简介

Stellar Security - Application Insights style telemetry for Laravel (HTTP, DB, jobs, mail, dependencies).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
