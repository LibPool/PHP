# stellarsecurity/subscription-laravel

> 标签: PHP

## 简介

Stellar Security Subscription client for PHP/Laravel – simple wrapper around the Stellar Subscription API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
