# stellarsecurity/laravel-hardening

> 标签: PHP

## 简介

Stellar Security hardening guard for Laravel (blocks APP_DEBUG=true on production-like hosts).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
