# stellarsecurity/stellarsecurity-commerce-laravel

> 标签: PHP

## 简介

Laravel client for Stellar Commerce Core/Base API (Client -> UI API -> Base API).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
