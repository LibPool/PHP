> 标签: asset-bundler, blade-components, bootstrap-5, bootstrap-laravel-component, icon-integration, iconify-laravel, laravel, laravel-component, laravel-package, quantavoxel, ui-framework, universal-icons

## 简介

A lightweight Laravel package offering reusable Bootstrap 5 Blade components, optimized asset bundling, and a highly flexible, universal icon integration system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
