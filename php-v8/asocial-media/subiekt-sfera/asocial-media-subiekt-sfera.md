# asocial-media/subiekt-sfera

> 标签: php, sfera, subiekt

## 简介

The PHP library to access and manage Subiekt GT and Navireo Sfera

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
