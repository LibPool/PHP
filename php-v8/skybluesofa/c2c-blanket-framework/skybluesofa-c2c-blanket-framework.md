# skybluesofa/c2c-blanket-framework

> 标签: c2c, crochet, laravel

## 简介

A Laravel (php) package that helps create C2C crochet designs for a temperature blanket

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
