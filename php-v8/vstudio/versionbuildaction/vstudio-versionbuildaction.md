# vstudio/versionbuildaction

> 标签: Vortechstudio, laravel, versionbuildaction

## 简介

Permet de récupérer la dernière version (release) de github et de l'afficher dans une vue

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
