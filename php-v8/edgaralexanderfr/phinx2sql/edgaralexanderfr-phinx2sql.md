# edgaralexanderfr/phinx2sql

> 标签: PHP

## 简介

Tool that allows you to print Phinx migrations displaying the SQL statements that pass through the `execute` method.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
