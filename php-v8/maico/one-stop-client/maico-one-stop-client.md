# maico/one-stop-client

> 标签: PHP

## 简介

Optional "Sign in with MAICO One-Stop" for Laravel applications: single sign-on, sign-out notices and opening inside One-Stop.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
