# yoosuf/laravel-dataflow

> 标签: NDJSON, csv, dataflow, eloquent, etl, export, filter, import, laravel, laravel-package, large-datasets, parquet, query-builder, queue, reporting, search, sort, streaming, xlsx

## 简介

Streaming-first Laravel data pipeline package for filter/search/sort/import/export workflows at any scale with queue-native execution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
