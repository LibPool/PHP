# selyusize/events-router

> 标签: event-dispatcher, events, listener, middleware, psr-14, router, slim

## 简介

Роутер событий для PHP: шаблоны топиков, группы и middleware в стиле Slim, несколько слушателей на событие, совместим с PSR-14.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
