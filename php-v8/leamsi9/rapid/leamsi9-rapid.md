# leamsi9/rapid

> 标签: blog, cms, generator, laravel, scaffolding, website

## 简介

A CLI driven Minimum Viable Website and micro-CMS generator.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
