# rudidevries/kaku

> 标签: PHP

## 简介

This library provides a basic object interface for calling a the KAKU program to switch devices with the Raspberry Pi and a 433mhz transmitter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
