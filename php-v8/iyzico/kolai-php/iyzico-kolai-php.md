# iyzico/kolai-php

> 标签: iyzico, iyzipay, kolai, magento, opencart, prestashop, woocommerce

## 简介

Kolai e-ticaret entegrasyonlari icin platformdan bagimsiz cekirdek: HMAC auth, yanit protokolu, adres/urun/yorum eslemesi, sozlesme sablonlari, iyzico iade/iptal.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
