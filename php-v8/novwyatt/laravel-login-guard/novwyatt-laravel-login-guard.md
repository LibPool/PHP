# novwyatt/laravel-login-guard

> 标签: brute-force, fortify, laravel, lockout, login, security, throttle

## 简介

Brute-force login protection for Laravel: progressive lockouts per IP and username, allow and block lists, events, alerts by mail, Slack or Telegram, and an audit log.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
