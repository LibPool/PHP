> 标签: Authentication, iam, keycloak, laravel, oauth2, oidc, openid-connect

## 简介

Laravel package for OIDC (OpenID Connect) authentication with Keycloak-compatible IAM servers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
