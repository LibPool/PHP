# robot-council/fleet-kit

> 标签: claude-code, fleet, pacing, psmux, robot-council, tmux, usage

## 简介

Operator tools for a Robot Council fleet: seat-stage stages a machine's seats, seat-pace paces a usage allowance

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
