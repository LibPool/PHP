# exolnet/laravel-envoy

> 标签: capistrano, continuous-deployment, deployment, envoy, exolnet, laravel

## 简介

Automated deployment template for Laravel Envoy based on Capistrano.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
