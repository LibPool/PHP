# exolnet/laravel-bootstrap4-form

> 标签: exolnet, laravel, laravel-bootstrap4-form

## 简介

Package use to extend laravelcollective/html and help building Boostrap4 form

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
