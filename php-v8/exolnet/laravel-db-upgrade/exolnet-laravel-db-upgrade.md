# exolnet/laravel-db-upgrade

> 标签: exolnet, laravel, laravel-db-upgrade

## 简介

Artisan command to migrate an existing production database structure to use Laravel migrations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
