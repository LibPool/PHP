# exolnet/laravel-heartbeat

> 标签: exolnet, laravel, laravel-heartbeat

## 简介

Periodically schedule a job to send a heartbeat to a monitoring system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
