# exolnet/wp-graylog

> 标签: exolnet, graylog, monolog, wordpress

## 简介

Adds a mu-plugin that register a Monolog handler to send exception to a Graylog channel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
