# extremesensio/easywordpressbundle

> 标签: easywordpressbundle, symfony, wordpress

## 简介

Easy implementation of Wordpress in Symfony 3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
