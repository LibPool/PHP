# alexgh12/backup-in-git

> 标签: backup database, in-git, in-laravel

## 简介

Comando para backup de base de datos en Laravel y sube cambios a un repositorio git

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
