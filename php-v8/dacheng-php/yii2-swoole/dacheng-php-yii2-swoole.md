# dacheng-php/yii2-swoole

> 标签: connection pools, coroutine, http server, swoole, yii2

## 简介

Yii2 Swoole extension, provides coroutine http server and more coroutine features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
