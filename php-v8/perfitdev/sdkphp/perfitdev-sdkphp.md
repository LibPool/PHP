# perfitdev/sdkphp

> 标签: perfit, php, sdk

## 简介

PHP SDK for Perfit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 获取地址

- Composer 安装：`composer require perfitdev/sdkphp`
- Packagist 仓库：https://repo.packagist.org/p2/perfitdev/sdkphp.json
- PHP 要求：>=5.4.0
