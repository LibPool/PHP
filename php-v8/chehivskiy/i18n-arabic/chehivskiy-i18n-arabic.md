# chehivskiy/i18n-arabic

> 标签: PHP

## 简介

Class enhances developing Arabic web applications by providing set of methods to process and present Arabic text

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
