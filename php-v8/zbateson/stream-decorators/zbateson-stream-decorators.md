# zbateson/stream-decorators

> 标签: base64, charset, decorators, mail, mime, psr7, quoted-printable, stream, uuencode

## 简介

PHP psr7 stream decorators for mime message part streams

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
