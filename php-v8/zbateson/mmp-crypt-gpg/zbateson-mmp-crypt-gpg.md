# zbateson/mmp-crypt-gpg

> 标签: PGP, email, encryption, gpg, mail-mime-parser, mime

## 简介

PGP/MIME implementation of zbateson/mmp-crypt using PEAR Crypt_GPG

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
