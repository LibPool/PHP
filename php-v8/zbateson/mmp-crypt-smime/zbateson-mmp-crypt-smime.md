# zbateson/mmp-crypt-smime

> 标签: cms, email, encryption, mail-mime-parser, mime, pkcs7, smime

## 简介

S/MIME implementation of zbateson/mmp-crypt using PHP OpenSSL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
