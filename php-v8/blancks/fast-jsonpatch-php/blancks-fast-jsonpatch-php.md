# blancks/fast-jsonpatch-php

> 标签: json, json patch, php

## 简介

Class designed to efficiently handle JSON Patch operations in accordance with the RFC 6902 specification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
