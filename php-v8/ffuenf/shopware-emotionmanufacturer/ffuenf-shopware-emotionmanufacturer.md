# ffuenf/shopware-emotionmanufacturer

> 标签: plugin, shopware

## 简介

This is a extension for Shopware that adds an emotion element to display a configurable list of manufacturers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
