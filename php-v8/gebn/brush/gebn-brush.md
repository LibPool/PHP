# gebn/brush

> 标签: api, pastebin, text, wrapper

## 简介

Brush is a complete object-oriented PHP wrapper for the Pastebin API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
