> 标签: Easy PHP Route, Easy Route, PHP Route, php routing, route, router, routes

## 简介

MinasRouter is simple, fast and extremely readable for routes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
