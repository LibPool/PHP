# hejunjie/bililive

> 标签: bili-live, bilibili, danmu, php

## 简介

B站直播 WebSocket 连接的核心组件库，提供简洁的接口实现，包括登录、直播间信息流加密/解密、以及相关的关键方法。适合集成到需要对接 Bilibili 直播间的项目中（弹幕监控，礼物答谢、定时广告、关注感谢，自动回复）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
