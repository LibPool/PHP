# xberg-io/tree-sitter-language-pack

> 标签: language-pack, parser, syntax, tree-sitter

## 简介

Pre-compiled tree-sitter grammars for 371 programming languages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
