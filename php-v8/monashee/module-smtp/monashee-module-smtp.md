# monashee/module-smtp

> 标签: magento 2, smtp

## 简介

Magento 2 extension which allows custom SMTP such as SendGrid, MailUp etc for sending transactional email

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
