# alexandre-fernandez/key-value-form-bundle

> 标签: Associative, array, form, key, map, symfony, type, value

## 简介

Symfony form type to manage associative array data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
