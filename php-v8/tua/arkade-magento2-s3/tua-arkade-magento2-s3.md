# tua/arkade-magento2-s3

> 标签: aws, cdn, magento, magento 2, magento2, module, plugin, s3

## 简介

Use Amazon S3 as the file storage backend for your store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
