# alfiosalanitri/laravel-flask-logger

> 标签: PHP

## 简介

A log handler for Laravel that sends logs to a Flask server started with https://github.com/alfiosalanitri/flask-log-monitor

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
