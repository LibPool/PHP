# tarekdj/nsfix

> 标签: PHP

## 简介

PHP_CodeSniffer custom sniff that finds a set of namespaces and replace it by new ones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
