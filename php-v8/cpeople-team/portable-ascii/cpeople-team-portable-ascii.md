# cpeople-team/portable-ascii

> 标签: ascii, clean, php

## 简介

Fork of Portable ASCII library - performance optimized (ascii) string functions for PHP by CreativePeople.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
