# elcreator/asocialauth

> 标签: evo, evocms, evolution, evolution-cms, facebook, google, hybridauth, linkedin, login, oauth, registration, social, telegram

## 简介

Social and password authentication for Evolution CMS: every HybridAuth provider, multi-provider account linking, and e-mail/password login, registration and recovery in one configurable widget.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
