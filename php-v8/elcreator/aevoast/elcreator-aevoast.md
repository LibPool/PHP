# elcreator/aevoast

> 标签: PHP

## 简介

AST symbol maps and embeddings generator for Evolution CMS — parse core, extras, and custom code into merged, searchable indexes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
