# heinhtet/api-authorizer

> 标签: api, authorizer, hmac, laravel, middleware, replay-attack, security, sha256, signature

## 简介

Protect Laravel APIs with HMAC-SHA256 request signing headers (X-POWERED-BY, X-TIMESTAMP, X-SIGNATURE) - authenticity, tamper-proofing and replay-attack prevention.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
