> 标签: created_by, deleted_by, eloquent, hrshadhin, kayiwarahim, laravel, updated_by, userstamps

## 简介

A simple Laravel package for Eloquent Model user specific fields.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
