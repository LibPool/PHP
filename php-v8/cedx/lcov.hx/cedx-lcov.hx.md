# cedx/lcov.hx

> 标签: coverage, formatter, lcov, parser, test

## 简介

Parse and format to LCOV your code coverage reports. The best way to share your code coverage stats.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
