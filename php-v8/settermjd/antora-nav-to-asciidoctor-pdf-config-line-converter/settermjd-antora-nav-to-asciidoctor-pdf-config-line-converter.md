# settermjd/antora-nav-to-asciidoctor-pdf-config-line-converter

> 标签: antora, asciidoctor, asciidoctor-pdf

## 简介

Converts an Antora navigation link to an asciidoctor-pdf config line

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
