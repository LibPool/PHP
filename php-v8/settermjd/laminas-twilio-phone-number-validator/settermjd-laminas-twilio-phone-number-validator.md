# settermjd/laminas-twilio-phone-number-validator

> 标签: laminas, twilio, validator, verify

## 简介

A laminas-validator class that validates phone numbers using Twilio's Verify API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
