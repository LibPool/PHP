# digitalkaoz/phpdotenv-middleware

> 标签: StackPHP, middleware, phpdotenv

## 简介

StackPHP Middleware for loading Environment Variables through PHPDotEnv

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
