# govelid/multi-smtp-mailer

> 标签: PHP

## 简介

Multi SMTP Mailer - Use for set multiple smtp mailer dynamically for your laravel web

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
