# typisttech/imposter

> 标签: composer, dependency, monkey-patching, namespace, wordpress

## 简介

Wrapping all composer vendor packages inside your own namespace. Intended for WordPress plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
