# typisttech/wp-org-closed-plugin

> 标签: Audit, abandoned, security, wordpress

## 简介

Composer plugin to mark packages as abandoned if closed on WordPress.org

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
