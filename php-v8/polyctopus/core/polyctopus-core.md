# polyctopus/core

> 标签: assets, cms, content, content management, content types, content variants, framework, library, multidimensional, multilingual, php, polyctopus, translations, versioning

## 简介

A modern, modular PHP library for multidimensional, multilingual content management with versioning, variants, translations, and asset handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
