# andronewille/sluis-onnx

> 标签: Dutch, ner, offline, onnx, pii

## 简介

A local ONNX model as a Sluis recogniser: the names, streets and towns that no pattern and no list can find.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
