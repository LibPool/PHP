# fisal/laravel-otp

> 标签: 2fa, 2factor, laravel, one-time-password, otp, verification

## 简介

Laravel OTP package with OTP type binding and attempts limiting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
