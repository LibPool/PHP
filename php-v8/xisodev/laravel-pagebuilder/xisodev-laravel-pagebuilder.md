# xisodev/laravel-pagebuilder

> 标签: laravel, pagebuilder

## 简介

드래그 앤 드롭을 활용한 AMUZCMS 전용 페이지빌더입니다.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
