# xrely/php-client

> 标签: Autocomplete search solution, Autocrawl Search, Intelligent search engine, Search discovery, Web search intelligence, install site search

## 简介

client library for xrely platform. For more information please visit https://www.xrely.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
