# webplusmultimedia/little-admin-architect

> 标签: laravel, little-admin-architect, webplusmultimedia

## 简介

A little admin with TALL Sack - Laravel, Livewire, ApineJs, TailwindCss

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
