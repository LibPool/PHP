# webplusmultimedia/filemanager

> 标签: filemanager, laravel, webplusmultimedia

## 简介

Manage files with this file manager made with alpinejs, livewire and tailwind CSS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
