# odesenvolvedor/juno-php-sdk

> 标签: Juno Boleto Fácil, api, boleto bancario, php, sdk

## 简介

SDK em PHP para Integração não-oficial com Boleto Fácil da Juno

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
