# dariobarila/comuni-italiani

> 标签: comuni-italiani, laravel, livewire

## 简介

Package Laravel per la selezione di regione, provincia e comune italiani utilizzando Livewire

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
