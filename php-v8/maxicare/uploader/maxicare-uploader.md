# maxicare/uploader

> 标签: cloud, hubspot, laravel, maxicare, oci, oracle, storage, upload

## 简介

A PHP Library for uploading files to cloud. Maintained and Developed by Maxicare IT Team

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
