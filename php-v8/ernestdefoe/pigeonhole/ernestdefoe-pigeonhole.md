# ernestdefoe/pigeonhole

> 标签: Private Messages, archive, flarum, flarum-extension, folders, inbox, messages

## 简介

Folders for Flarum's private messages. Each member files their own conversations into folders with a colour and an icon, archives what is done until a new message brings it back, and sees what is unread in each folder. Works with Group Messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
