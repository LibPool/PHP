# ernestdefoe/gatehouse

> 标签: approval, flarum, flarum-extension, moderation, registration, spam

## 简介

Approve new members before they get in: sign-ups from addresses you trust activate as normal, everyone else waits in a queue for an admin or moderator to approve or decline.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
