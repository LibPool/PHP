# ernestdefoe/rubric

> 标签: flarum, flarum-extension, label, prefix, thread-prefix

## 简介

Thread prefixes for Flarum 2: a short coloured label before a discussion's title — [Rumor], [Official], [Solved] — chosen when the discussion is started, separate from tags.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
