# ernestdefoe/nameplate

> 标签: flarum, flarum-extension, postbit, profile, signature

## 简介

The member's panel beside every post, the way traditional forums show it: rank, post count, join date, best answers and likes received — plus signature options that work with FoF Signature.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
