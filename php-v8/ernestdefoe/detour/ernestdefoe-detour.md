# ernestdefoe/detour

> 标签: 301, 404, SMF, broken links, discourse, flarum, invision, migration, mybb, not found, phpbb, redirect, redirects, seo, vbulletin, xenforo

## 简介

A 404 log and redirect manager for Flarum: see which addresses visitors hit that no longer exist, redirect them (301, 302 or 410; exact, prefix or regular expression), bring old phpBB, vBulletin, XenForo, MyBB, SMF, Invision and Discourse links back to life, and show a friendlier page not found.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
