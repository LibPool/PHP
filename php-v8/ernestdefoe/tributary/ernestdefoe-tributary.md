# ernestdefoe/tributary

> 标签: conversation, flarum, nested, replies, threaded

## 简介

Tributary — branching replies for Flarum 2. A reply remembers the post it answered, so a long discussion stops being one flat column of people talking past each other.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
