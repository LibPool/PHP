# ernestdefoe/warren

> 标签: flarum, flarum-extension, reddit, theme, threaded, votes, warren

## 简介

Warren — a Reddit-inspired theme for Flarum 2. Compact post rows with a vote pill, image and text previews, Hot/New/Top sorting, a collapsible rail and threaded comments. Shares fof/gamification's vote tables, so nothing is lost either way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
