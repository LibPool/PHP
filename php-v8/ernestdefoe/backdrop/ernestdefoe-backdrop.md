# ernestdefoe/backdrop

> 标签: banner, cover, flarum, flarum-extension, profile

## 简介

Profile covers for Flarum 2: upload, drag to frame, zoom. On profiles, hover cards and the member directory, without patching anything other extensions rely on.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
