# ernestdefoe/aurora

> 标签: aurora, dark, flarum, glassmorphism, gradient, theme

## 简介

An aurora-inspired theme for Flarum with vibrant gradients, glowing accents, and a modern glassmorphic feel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
