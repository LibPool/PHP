# ernestdefoe/resurface

> 标签: bump, bumping, classifieds, flarum, marketplace, scheduled

## 简介

Bump a discussion back to the top without replying: manual bumps with per-group cooldowns and daily limits, per-tag control, scheduled and automatic bumps, and a bump log for staff.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
