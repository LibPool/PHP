# ernestdefoe/concourse

> 标签: community, concourse, flarum, flarum-extension, sidebar, theme

## 简介

Concourse — a clean three-column community theme for Flarum 2. A left sidebar with your tag tree on every page, compact discussion rows with like and reply counts, and a right column with your profile card, Top Contributors and any widgets you add.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
