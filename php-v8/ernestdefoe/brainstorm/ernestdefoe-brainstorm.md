# ernestdefoe/brainstorm

> 标签: Gamification, flarum, flarum-extension, leaderboard, quiz, quizzes, test, trivia

## 简介

Brainstorm — quizzes and knowledge tests for Flarum. Single and multiple choice, true/false, typed answers and image questions; timers, pass marks and attempt limits enforced on the server; leaderboards that respect privacy; quizzes playable inside a post; rewards with FoF Badges and FoF Gamification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
