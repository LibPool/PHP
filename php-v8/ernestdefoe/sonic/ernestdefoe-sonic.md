# ernestdefoe/sonic

> 标签: flarum, fulltext, lightweight, search, sonic

## 简介

A light search driver for Flarum 2, backed by Sonic, the tiny Rust search backend. Free and MIT.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
