# ernestdefoe/og-image

> 标签: PHP

## 简介

Adds Open Graph and Twitter Card meta tags to Flarum 2 discussions for rich Facebook and social media previews

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
