# ernestdefoe/millwright

> 标签: composer, flarum, flarum-extension, rollback, updates

## 简介

Install, update and roll back Flarum extensions and Flarum itself, on any host including shared hosting. Nothing is deleted; every step is a checkpoint, so an interrupted update loses progress, never your site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
