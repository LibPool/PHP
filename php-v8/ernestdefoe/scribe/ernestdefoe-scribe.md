# ernestdefoe/scribe

> 标签: editor, flarum, tiptap, wysiwyg

## 简介

Scribe — a true WYSIWYG editor for Flarum. TipTap, with no Markdown anywhere in the stack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
