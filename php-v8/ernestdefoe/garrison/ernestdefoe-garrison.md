# ernestdefoe/garrison

> 标签: flarum, game, minecraft, panel, server, valheim

## 简介

Garrison — run your game servers from the forum the players already live in. Any server you can install, with or without Docker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
