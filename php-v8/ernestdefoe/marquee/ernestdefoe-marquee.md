# ernestdefoe/marquee

> 标签: PHP

## 简介

Link discussions to movies, TV shows (down to the episode) and games, shown in the discussion hero. Data from TMDB and IGDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
