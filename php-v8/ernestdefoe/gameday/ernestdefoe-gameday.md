# ernestdefoe/gameday

> 标签: CFB, college football, extension, flarum, game thread, sports

## 简介

A thread for every game, opened before kickoff and finished with a recap that says how the game was won.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
