# ernestdefoe/shelf

> 标签: Lists, books, flarum, games, marquee, movies, ratings

## 简介

Members rate, log and list the movies, shows, games, albums and books Marquee links to. Profile shelves, public lists and a top-rated view.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
