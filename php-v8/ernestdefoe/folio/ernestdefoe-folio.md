# ernestdefoe/folio

> 标签: docx, export, flarum, flarum-extension, markdown, pdf

## 简介

Export a Flarum discussion as a PDF, a Word document or Markdown — styled in the forum's colours, with only the posts the reader is allowed to see.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
