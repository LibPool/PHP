# ernestdefoe/typesense

> 标签: flarum, fulltext, search, typesense

## 简介

Fast, typo-tolerant Typesense search for Flarum 2 — a free, drop-in search driver.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
