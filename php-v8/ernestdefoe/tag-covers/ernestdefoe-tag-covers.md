# ernestdefoe/tag-covers

> 标签: covers, flarum, flarum-extension, images, tags

## 简介

Cover images for Flarum tags — upload a cover per tag and use it anywhere a tag is rendered as a card.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
