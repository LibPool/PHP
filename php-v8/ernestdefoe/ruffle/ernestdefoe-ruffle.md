# ernestdefoe/ruffle

> 标签: emulator, flarum, flarum-extension, flash, preservation, ruffle, swf

## 简介

Play Flash (.swf) in posts, with Ruffle. A sandboxed emulator, not the dead plugin — no ActiveX, no NPAPI, scripting and networking locked off by default.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
