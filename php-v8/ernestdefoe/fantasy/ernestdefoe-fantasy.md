# ernestdefoe/fantasy

> 标签: college football, extension, fantasy, flarum, nfl, pickem, sports

## 简介

A season-long fantasy league where members draft TEAMS rather than players. Snake draft, weekly lineups that lock at each team's own kickoff, head-to-head matchups, and a scoring system the commissioner sets. Plays whatever competition the Picks season is, and starts each league from that sport's own numbers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
