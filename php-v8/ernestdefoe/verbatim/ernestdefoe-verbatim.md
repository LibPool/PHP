# ernestdefoe/verbatim

> 标签: edits, flarum, provenance, quotes

## 简介

Verbatim — a quote that knows when it has gone stale. The words never change; the quote says so when the post it came from has been edited since.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
