# ernestdefoe/recipes

> 标签: cooking, flarum, flarum-extension, recipe, recipes, schema.org

## 简介

Structured recipes in posts: ingredients that scale with servings, one-click step timers, a clean print view and schema.org Recipe data for search engines. Works with Scribe, FoF Rich Text and the plain composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
