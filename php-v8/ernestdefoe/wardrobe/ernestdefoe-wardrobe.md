# ernestdefoe/wardrobe

> 标签: appearance, flarum, theme, themes

## 简介

Wardrobe — install several themes on one Flarum 2 forum and let every member choose the one they see.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
