# ernestdefoe/waymark

> 标签: breadcrumbs, flarum, flarum-extension, navigation, seo

## 简介

Breadcrumbs for Flarum 2: a trail on every page, from Home through tags to the discussion you are reading, matching the one search engines see.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
