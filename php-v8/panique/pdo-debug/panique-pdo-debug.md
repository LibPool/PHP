# panique/pdo-debug

> 标签: debug, debugger, log, logger, pdo, sql

## 简介

A super-simple function that returns the full SQL query from your PDO statements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
