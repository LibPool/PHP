# axyr/laravel-tractor

> 标签: api, boilerplate, crud, json, laravel, module, scaffolder

## 简介

Opiniated Laravel CRUD generator for a Module/Repository/Filter based CRUD setup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
