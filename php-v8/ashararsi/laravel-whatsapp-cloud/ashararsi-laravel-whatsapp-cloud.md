## 简介

Production-ready Laravel 13 WhatsApp platform with Meta Cloud API, Twilio, multi-account support, webhooks, conversation inbox, admin panel, queues, and notifications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
