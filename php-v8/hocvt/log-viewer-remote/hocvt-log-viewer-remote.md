# hocvt/log-viewer-remote

> 标签: laravel, log-viewer, logs, multi-host, n-plus-one, slow-query

## 简介

Mở rộng opcodesio/log-viewer: auth shared-secret giữa các host, tải file log của host ở xa qua host đang xem, và log query chậm / N+1.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
