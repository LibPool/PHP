# spoolpdf/sdk-php

> 标签: html-to-pdf, pdf, render, spoolpdf, url-to-pdf

## 简介

Official PHP client for the spoolpdf HTML/URL to PDF API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
