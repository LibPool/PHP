# freshcells/graphqlite-misc-types

> 标签: GraphQLite, graphql, types

## 简介

A collection of non-standard GraphQL types to be used with GraphQLite.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
