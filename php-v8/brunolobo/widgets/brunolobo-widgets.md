# brunolobo/widgets

> 标签: pactocrm

## 简介

Pacote de widgets originalmente criado por Arrilot, otimizado para uso no Pacto por Brunolobo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
