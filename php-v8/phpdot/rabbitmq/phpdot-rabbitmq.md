# phpdot/rabbitmq

> 标签: AMQP, consumer, dead-letter, messaging, publisher, rabbitmq, retry

## 简介

RabbitMQ client for PHP: publish, consume, retry, dead letter, topology.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
