# phpdot/routing

> 标签: http, middleware, psr-15, psr-7, router, routing, trie

## 简介

High-performance segment-trie routing for PHP. PSR-7/15/17 compliant.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
