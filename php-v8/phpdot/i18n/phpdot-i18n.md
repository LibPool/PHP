# phpdot/i18n

> 标签: i18n, icu, internationalization, locale, messageformat, psr-16, translation

## 简介

Internationalization with ICU MessageFormat, pluggable loaders, PSR-16 caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
