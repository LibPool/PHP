# phpdot/database

> 标签: database, dbal, migrations, mysql, postgresql, query-builder, schema, sqlite

## 简介

Query builder, schema management, and migrations for PHP. Built on Doctrine DBAL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
