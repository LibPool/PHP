# phpdot/totp

> 标签: 2fa, MFA, hotp, otp, phpdot, rfc4226, rfc6238, totp

## 简介

Coroutine-safe, zero-dependency HOTP/TOTP (RFC 4226 / RFC 6238) with provisioning URIs for the PHPdot ecosystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
