# phpdot/session

> 标签: csrf, flash, middleware, psr-15, redis, session

## 简介

Secure session management with pluggable handlers, flash data, CSRF tokens, and PSR-15 middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
