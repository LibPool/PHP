# phpdot/qrcode

> 标签: phpdot, png, qr, qrcode, svg

## 简介

Coroutine-safe QR code generation with SVG, PNG and data-URI renderers for the PHPdot ecosystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
