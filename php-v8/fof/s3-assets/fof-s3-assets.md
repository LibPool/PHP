# fof/s3-assets

> 标签: flarum

## 简介

Relocate Flarum disks onto S3 or compatible bucket

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://friendsofflarum.org
- 源码仓库：https://github.com/FriendsOfFlarum/s3-assets.git
- Packagist 页面：https://packagist.org/packages/fof%2Fs3-assets

## 历史版本号

- 当前版本：1.0.0-beta.4

- -

## 获取地址

- Composer 安装：`composer require fof/s3-assets`
- Packagist 仓库：https://repo.packagist.org/p2/fof/s3-assets.json
- 许可证：MIT
- PHP 要求：^8.0
