# idct/symfony-form-soft-delete-aware-entity-type

> 标签: PHP

## 简介

Repository which adds support for Soft Delete filter behavior to Symfony's EntityType.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
