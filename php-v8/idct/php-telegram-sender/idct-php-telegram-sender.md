# idct/php-telegram-sender

> 标签: instant message, php, telegram, telegramim

## 简介

Simple PHP library which simplifies the task of sending bot messages using Telegram IM

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
