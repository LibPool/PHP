# sunaoka/laravel-ssm-parameters-loader

> 标签: aws, env, laravel, ssm

## 简介

Load values from AWS SSM Parameter store into environment variables for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
