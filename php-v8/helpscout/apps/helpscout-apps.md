# helpscout/apps

> 标签: apps, dynamic-app, helpscout

## 简介

Client library to assist with building dynamic apps that integrate with the Help Scout UI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
