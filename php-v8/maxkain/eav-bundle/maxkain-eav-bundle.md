# maxkain/eav-bundle

> 标签: doctrine, easyadmin, eav, php, symfony

## 简介

Implementation of EAV (Entity-Attribute-Value) pattern for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
