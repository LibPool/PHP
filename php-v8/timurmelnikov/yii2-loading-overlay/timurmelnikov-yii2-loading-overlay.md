# timurmelnikov/yii2-loading-overlay

> 标签: LoadingOverlay, ajax, jquery, pjax, widget, yii2

## 简介

Yii2 виджет-обертка для использования плагина jQuery LoadingOverlay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
