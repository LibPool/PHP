# mauro-pinheiro/eloquent-uuid

> 标签: YourApp.Rocks, eloquent-uuid, universal unique id, uuid

## 简介

Adds support for UUID generation automatically for Models Eloquents.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
