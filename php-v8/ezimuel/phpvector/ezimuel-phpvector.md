# ezimuel/phpvector

> 标签: PHP

## 简介

A vector database in PHP implementing HNSW for approximate nearest-neighbor search and BM25 for hybrid full-text + vector retrieval.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
