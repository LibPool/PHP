# thanatosxia/yii2-oss

> 标签: PHP

## 简介

Aliyun Oss SDK for yii2, based on aliyun/aliyun-oss-php-sdk

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
