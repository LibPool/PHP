# thanatosxia/iseed

> 标签: artisan, generators, lumen, seed

## 简介

Generate a new Laravel database seed file based on data from the existing database table.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
