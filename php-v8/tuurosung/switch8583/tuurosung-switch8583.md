# tuurosung/switch8583

> 标签: acquiring, bcd, bitmap, emv, fintech, ghipss, iso 8583, iso-8583, iso8583, issuing, laravel, payment-switch, payments, pos, switching

## 简介

A clean, well-tested ISO 8583 message library for PHP: construction, parsing, and validation for the 1987 and 1993 standard versions, with BCD/ASCII encoding, LLVAR/LLLVAR fields, and dual bitmaps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
