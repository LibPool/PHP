# selectwin/sdk

> 标签: api, boleto, payments, pix, sdk, selectwin, subscriptions, webhooks

## 简介

Official Selectwin PHP SDK — payments (card, PIX, boleto), subscriptions, webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://selectwin.io/docs
- 源码仓库：https://github.com/selectwin/sdk-php.git
- Packagist 页面：https://packagist.org/packages/selectwin%2Fsdk
