# 3brs/sylius-gopay-payum-plugin

> 标签: gopay, payment-gateway, payum, sylius, sylius-plugin

## 简介

GoPay payment gateway plugin using Payum config for Sylius applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
