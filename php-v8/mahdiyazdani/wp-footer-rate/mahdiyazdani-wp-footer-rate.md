# mahdiyazdani/wp-footer-rate

> 标签: plugin, wordpress

## 简介

Library to be bundled with WordPress themes and plugins to ask for users to leave a review.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
