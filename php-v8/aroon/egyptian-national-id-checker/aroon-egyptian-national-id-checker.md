# aroon/egyptian-national-id-checker

> 标签: Egypt, laravel, national-id, php, validation

## 简介

A PHP package to parse and validate Egyptian National IDs, with Laravel support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
