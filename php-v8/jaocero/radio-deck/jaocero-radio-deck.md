# jaocero/radio-deck

> 标签: filament-form, filament-plugin, filamentphp, jaocero, laravel, radio-deck

## 简介

Turn filament default radio button into a selectable card with icons, title and description.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
