# patchx/laravel-saml2

> 标签: SAML2, SSO, laravel, onelogin, saml

## 简介

SAML2 Service Provider integration to your Laravel 5.4+ application, based on OneLogin toolkit

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
