# rathauslotse/bayernportal-api

> 标签: API-Client, bavaria, bayern, bayernportal, e-government, laravel, public-administration

## 简介

Laravel client for the BayernPortal REST API v3 (agencies, authorities, contacts, services, forms, online procedures and life situations of Bavarian public administration).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
