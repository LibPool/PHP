# ambengers/kinetic

> 标签: composer, inertia, inertia.js, inertiajs, laravel, view

## 简介

Adds view-composer like feature to Inertia.js Laravel adapter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
