# abdoub/omnipay-ecopayz

> 标签: ecopayz, gateway, merchant, omnipay, pay, payment

## 简介

Ecopayz driver for the Omnipay version (3.0.x-dev) payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
