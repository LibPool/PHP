# ose/coding-standard

> 标签: dev, phpcs

## 简介

OSE Fork of Slevomat Coding Standard for PHP_CodeSniffer complements Consistence Coding Standard by providing sniffs with additional checks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
