# olomadev/olobase

> 标签: api, laminas, mezzio, oloma, olomadev, rest

## 简介

Olobase is a tool that allows to you quickly and easily develop modern open api based rest apis using Mezzio framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
