# matiasnamendola/slimpower-jwt

> 标签: config, ini, json, php, xml, yaml, yml

## 简介

Config is a file configuration loader that supports PHP, INI, XML, JSON, and YML files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
