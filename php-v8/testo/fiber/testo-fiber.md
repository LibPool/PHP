# testo/fiber

> 标签: concurrency, coroutine, fiber, scheduler, testo

## 简介

Fiber/coroutine execution plugin for the Testo testing framework: run tests as cooperatively-scheduled plain fibers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
