# livaco/easydiscordwebhook

> 标签: discord, php, webhook

## 简介

An simple, lightweight, easy to use library to allow you to create and send discord webhooks in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
