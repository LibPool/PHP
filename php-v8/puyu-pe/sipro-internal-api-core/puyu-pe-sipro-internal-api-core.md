# puyu-pe/sipro-internal-api-core

> 标签: PHP

## 简介

Framework-agnostic core contracts, HMAC security utilities, and API response/error standards for SIPRO internal API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
