# tomsommer/oauth2-onpay

> 标签: SSO, authorisation, authorization, client, oauth, oauth2, onpay

## 简介

OnPay.io OAuth 2.0 provider client for the PHP League's OAuth 2.0 Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
