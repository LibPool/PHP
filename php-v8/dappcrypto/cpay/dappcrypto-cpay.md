# dappcrypto/cpay

> 标签: PHP

## 简介

DApp Crypto payment gateway SDK without KYC/KYB. Supports MetaMask and Trust Wallet. Payments in USDT, USDC, ETH, BNB, BTC.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
