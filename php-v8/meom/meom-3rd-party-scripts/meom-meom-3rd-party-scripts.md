# meom/meom-3rd-party-scripts

> 标签: PHP

## 简介

Create settings for 3rd party script like Google Tag Manager and Cookiebot.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
