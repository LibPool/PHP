# ttpryg/payment-engine

> 标签: PHP

## 简介

Production-ready, framework-agnostic PHP 8.1+ Payment Engine with generic payable/payer references, gateway abstraction, idempotent webhook processing, and append-only audit trail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
