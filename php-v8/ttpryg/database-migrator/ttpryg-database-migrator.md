# ttpryg/database-migrator

> 标签: database, migration, migrator, pdo, schema

## 简介

Framework-agnostic PDO schema migration runner with tracking and rollback for PHP 8.1+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
