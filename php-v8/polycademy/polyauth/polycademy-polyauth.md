# polycademy/polyauth

> 标签: Authentication, access control, authorisation, oauth, rbac, sessions, user accounts

## 简介

Authentication & Authorisation Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
