# level51/silverstripe-onesignal

> 标签: onesignal, silverstripe

## 简介

Silverstripe module wrapper for OneSignal PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
