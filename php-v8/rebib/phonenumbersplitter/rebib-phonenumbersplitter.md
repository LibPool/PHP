# rebib/phonenumbersplitter

> 标签: ハイフン付, ハイフン無し, 電話番号

## 简介

ハイフン無しの電話番号をハイフン付の形式に変換する

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
