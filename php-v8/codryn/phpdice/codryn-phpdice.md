# codryn/phpdice

> 标签: d20, dice, dice notation, gaming, parser, roller, rpg, tabletop

## 简介

A comprehensive PHP library for parsing and rolling dice expressions for tabletop RPG systems

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
