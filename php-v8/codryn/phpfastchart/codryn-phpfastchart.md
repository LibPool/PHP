# codryn/phpfastchart

> 标签: Simple, chart, fast, graph, library, php, visualization

## 简介

A fast and simple charting library for PHP, ideal for generating charts in web applications and reports.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
