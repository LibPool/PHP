# webksde/drowl_modulecount

> 标签: drupal

## 简介

Displays the sum of all currently active contrib modules to calculate the proper DROWL Drupal Updateservice contract (webks_up) in the status report

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
