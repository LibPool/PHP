# tm/tooly-composer-script

> 标签: composer, composer-phar, composer-script, phar, phar-handling, phar-management

## 简介

Simple composer script to manage phar files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
