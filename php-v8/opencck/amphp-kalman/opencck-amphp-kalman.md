# opencck/amphp-kalman

> 标签: amphp, async, filter, kalman, state-estimation, time-series, trading

## 简介

High-performance n-dimensional discrete Kalman filter for PHP with AMPHP v3 async streaming layer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
