# flarum/font-awesome

> 标签: flarum, font-awesome, fonts, icons

## 简介

A slim redistribution of Font Awesome Free, containing only the CSS and web fonts Flarum needs. Auto-synced to upstream releases.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
