# bluesignal/truemeeting-api

> 标签: PHP

## 简介

The official PHP Client of TrueMeeting

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://truemeeting.io
- 源码仓库：https://github.com/bluesignal/truemeeting-api.git
- Packagist 页面：https://packagist.org/packages/bluesignal%2Ftruemeeting-api

## 获取地址

- Composer 安装：`composer require bluesignal/truemeeting-api`
- Packagist 仓库：https://repo.packagist.org/p2/bluesignal/truemeeting-api.json
- PHP 要求：^7.4|^8.1
