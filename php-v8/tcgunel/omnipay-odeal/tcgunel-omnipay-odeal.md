# tcgunel/omnipay-odeal

> 标签: 3d secure, gateway, odeal, omnipay, pay by link, payment, sanal pos, virtual pos

## 简介

Omnipay extension for Ödeal - 3D/Non-3D virtual POS payments, pay-by-link, cancel, refund and transaction queries

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
