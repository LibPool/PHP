# tcgunel/omnipay-nestpay

> 标签: 3d secure, Anadolubank, Cardplus, Halkbank, Isbank, Sekerbank, TEB, akbank, alternatifbank, asseco, finansbank, gateway, ingbank, nestpay, omnipay, payment, turkiyefinans, ziraat

## 简介

Omnipay extension for NestPay (Asseco) - Supports 12 Turkish banks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
