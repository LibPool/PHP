# tcgunel/omnipay-pluxee-sodexo

> 标签: gateway, meal card, omnipay, otp, payment, pluxee, pluxeepay, sodexo, yemek karti

## 简介

Omnipay extension for Pluxee (formerly Sodexo) - OTP based meal card payments for online checkout

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
