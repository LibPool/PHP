# russsiq/laravel-zipper

> 标签: laravel, zip-archive, zip-wrapper, zipper

## 简介

Класс-обертка для архиватора ZipArchive в Laravel 9.x.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
