# russsiq/laravel-grecaptcha

> 标签: Google ReCaptcha, laravel

## 简介

Расширение валидатора Laravel 9.x для проверки Google reCAPTCHA v3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
