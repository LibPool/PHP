# nicoswd/putio

> 标签: api, bittorrent, cloud, put.io, putio, storage, torrent

## 简介

PHP 5.4 wrapper for PutIO's OAuth API (v2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
