# evgenmil/webhook-storage

> 标签: PHP

## 简介

Framework-agnostic webhook storage layer for PHP. Per-source MySQL tables, single schema, status lifecycle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
