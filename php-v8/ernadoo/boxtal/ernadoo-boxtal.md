# ernadoo/boxtal

> 标签: boxtal, carrier, chronopost, colissimo, label, mondial-relay, parcel-point, shipping, tracking

## 简介

Boxtal API client: quotes (v1), shipping orders, labels, tracking, parcel points and webhooks (v3). Framework-agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
