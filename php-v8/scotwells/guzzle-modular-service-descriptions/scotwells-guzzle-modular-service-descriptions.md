# scotwells/guzzle-modular-service-descriptions

> 标签: Guzzle, service description

## 简介

A better ServiceDescriptionLoader for Guzzle 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
