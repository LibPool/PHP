# rippleberry/youtube-laravel-api

> 标签: AlchemyGuy, Youtube Api V3, Youtube Backup, Youtube Channel, Youtube LiveStream, Youtube Video, YoutubeLaravelApi, google api, laravel, oauth, php

## 简介

It is a wrapper over Youtube Api v3 which simplifies functionalities the laravel way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
