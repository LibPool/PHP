# mitsuki/cors

> 标签: cidr, cors, http, ip-whitelist, listener, micro-framework, mitsuki, security, symfony

## 简介

Official CORS listener for the Mitsuki PHP framework with IP whitelisting support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
