# philtenno/filessyncgo

> 标签: contao, file, filesync, sync, synchonisation

## 简介

Contao-Erweiterung zum Auslösen einer Dateisynchronisation über öffentliche URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
