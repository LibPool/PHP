# rdapapi/rdapapi-php

> 标签: IP, api, asn, dns, domain, entity, nameserver, rdap, whois

## 简介

Official PHP SDK for the RDAP API — look up domains, IPs, ASNs, nameservers, and entities via RDAP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
