# tecnostack/module-cookie-consent

> 标签: consent mode, cookie banner, cookie consent, gdpr, magento2, pdpl

## 简介

Cookie banner and privacy preference centre for Magento 2 with Google Consent Mode v2, script/iframe/pixel blocking, a GTM dataLayer stream and a server-side consent log. Theme independent (Luma, Hyva, custom themes), RTL ready.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
