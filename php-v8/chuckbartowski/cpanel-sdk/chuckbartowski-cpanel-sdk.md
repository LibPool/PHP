# chuckbartowski/cpanel-sdk

> 标签: UAPI, api, cpanel, hosting, php, sdk, whm

## 简介

PHP SDK for the cPanel and WHM APIs (UAPI, API2, WHM API 1) with typed clients and high-level modules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
