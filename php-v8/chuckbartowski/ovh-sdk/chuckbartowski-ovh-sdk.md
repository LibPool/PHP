> 标签: api, cloud, domain, hosting, ovh, ovhcloud, php, sdk

## 简介

PHP SDK for the OVHcloud API — native request signing, typed clients and high-level modules for every product

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
