# chuckbartowski/plesk-sdk

> 标签: api, hosting, php, plesk, rest, sdk

## 简介

PHP SDK for the Plesk REST API (v2) with typed clients, high-level modules and a CLI bridge

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
