# directlease/silverstripe-algolia-page-sync-module

> 标签: algolia, cms, silverstripe

## 简介

A module that based on configuration syncs pages to an Algolia index

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
