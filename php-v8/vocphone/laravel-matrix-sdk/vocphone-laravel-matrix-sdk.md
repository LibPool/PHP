# vocphone/laravel-matrix-sdk

> 标签: Matrix Chat, Synapse, matrix, php

## 简介

PHP SDK for interacting with Matrix/Synapse.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
