# tinytank/framework

> 标签: Datastar, Opcache, blog, framework, markdown, static, twig

## 简介

TinyTank: a tiny, database-free PHP micro framework for static-like dynamic sites (Datastar, Symfony Routing, Twig, Markdown blog, translations, SEO), compiled for Opcache.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
