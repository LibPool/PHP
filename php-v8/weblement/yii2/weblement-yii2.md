# weblement/yii2

> 标签: behaviors, components, extensions, weblement, widgets, yii2

## 简介

Yii2 extensions and other useful components for yii2 applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
