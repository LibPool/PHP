# kurianvarkey/helper-buddy

> 标签: PHP

## 简介

Helper class to validate and correct JSON attribute types, ensuring proper structure and defaults for string, int, float, and boolean.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
