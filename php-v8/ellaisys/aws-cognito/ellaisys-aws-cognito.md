# ellaisys/aws-cognito

> 标签: 2fa, Authentication, Cognito, FIDO2, MFA, Passwordless, SRP, SSO, authorization, aws, aws-cognito, device authentication, fido, identity pool, jwt, laravel, oauth, passkey, php, user pool, webauthn

## 简介

Laravel authentication with AWS Cognito, supporting web, API, SSO, MFA, WebAuthn, passkeys, and passwordless authentication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
