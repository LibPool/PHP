# vireo/starter

> 标签: boilerplate, framework, inertia, php, react, starter, vertical-slice, vue

## 简介

Vireo Framework application starter template with Vertical Slice Architecture and Inertia.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
