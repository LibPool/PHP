# xiaosongshu/rabbitmq

> 标签: laravel, message, php, queue, rabbitmq, thinkphp, webman, yii

## 简介

支持rabbitmq消息队列，兼容thinkphp,laravel,webman,yii等多个框架

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
