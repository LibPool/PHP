# xiaosongshu/rtmp_server

> 标签: WebRTC, flv, hls, mp4, rtmp, rtmp-server

## 简介

Native PHP RTMP live server with FLV/HLS, MP4 slicing, PHP client, relay & gateway and webrtc server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
