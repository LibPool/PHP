# millionsend/millionsend

> 标签: email, millionsend, resend-compatible, ses, transactional-email

## 简介

Official PHP SDK for MillionSend — a self-hostable, Resend-compatible email API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
