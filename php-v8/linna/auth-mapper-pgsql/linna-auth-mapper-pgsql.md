# linna/auth-mapper-pgsql

> 标签: Authentication, authorization, mapper, php, postgres

## 简介

Postgres mapper implementation of the authentication and authorization interfaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
