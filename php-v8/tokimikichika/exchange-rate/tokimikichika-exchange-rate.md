# tokimikichika/exchange-rate

> 标签: PHP

## 简介

A simple PHP library and frontend for displaying USD to RUB exchange rate from the Central Bank.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
