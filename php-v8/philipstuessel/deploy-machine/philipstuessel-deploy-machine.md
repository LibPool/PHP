# philipstuessel/deploy-machine

> 标签: PHP

## 简介

Deploy any project to any server you can SSH into, and roll it back in a second. One bash script, one config file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
