# webalternatif/flysystem-failover-bundle

> 标签: Flysystem, adapter, bundle, failover, filesystem, storage

## 简介

A bundle to create failover Flysystem adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
