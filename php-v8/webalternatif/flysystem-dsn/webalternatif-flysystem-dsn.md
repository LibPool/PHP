# webalternatif/flysystem-dsn

> 标签: Flysystem, adapter, dsn, filesystem, storage

## 简介

A set of factories to build Flysystem adapters from DSN (Data Source Name)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
