# webalternatif/flysystem-dsn-bundle

> 标签: Flysystem, adapter, bundle, dsn, filesystem, storage

## 简介

A bundle to build Flysystem adapters from DSN (Data Source Name).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
