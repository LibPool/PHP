# webalternatif/flysystem-openstack-swift

> 标签: Flysystem, Openstack, adapter, filesystem, storage, swift

## 简介

Flysystem v3 adapter for OpenStack Swift

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
