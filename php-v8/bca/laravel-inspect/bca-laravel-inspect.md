# bca/laravel-inspect

> 标签: artisan, inspector, laravel

## 简介

Instant support for PHP Code Sniffer, PHP CS Fixer, and PHP MD in the Artisan CLI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
