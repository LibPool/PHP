# mhaggag/laravel-payments

> 标签: gateway, laravel, payments, paymob, paypal, stripe

## 简介

A comprehensive payment gateway package for Laravel with support for multiple payment providers such as Stripe, PayPal, paymob, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
