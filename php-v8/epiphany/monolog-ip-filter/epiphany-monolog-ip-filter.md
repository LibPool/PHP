# epiphany/monolog-ip-filter

> 标签: PHP

## 简介

Symfony Bundle that provides an activation strategy for monolog's FingersCrossed Handler to ignore IP addresses/ranges

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
