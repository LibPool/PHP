# explicatis/ns-protect-site

> 标签: TYPO3 CMS, page, password, protect, site

## 简介

This extension will help you to quickly password protected TYPO3 pages without frontend users management, check manual for more details.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
