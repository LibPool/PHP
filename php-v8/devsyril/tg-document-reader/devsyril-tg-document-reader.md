# devsyril/tg-document-reader

> 标签: OCR, cni, driver license, extraction, identification, identity card, passport, togo, validation

## 简介

Togolese identity documents OCR processor - extracts and validates data from CNI, passport, and driver license images

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
