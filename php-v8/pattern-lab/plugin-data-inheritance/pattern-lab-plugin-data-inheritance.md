# pattern-lab/plugin-data-inheritance

> 标签: data, inheritance, lineage, pattern lab

## 简介

Data inheritance based on pattern lineage for Pattern Lab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
