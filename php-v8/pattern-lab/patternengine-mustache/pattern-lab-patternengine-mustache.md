# pattern-lab/patternengine-mustache

> 标签: mustache, pattern engine, pattern lab

## 简介

Mustache-based PatternEngine for Pattern Lab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
