# theme-ultimate/installer-theme-ultimate-upgrader

> 标签: contao, installer, theme-ultimate, upgrader

## 简介

Installer package for Theme Ultimate Upgrader.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
