# theme-ultimate/installer-theme-ultimate

> 标签: contao, installer, private-repository, theme-ultimate

## 简介

Installer package for Theme Ultimate.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
