# lukasbableck/contao-tobii-lightbox-bundle

> 标签: a11y, accessibility, accessible, image, lightbox

## 简介

This bundle adds the accessible, open-source Tobii lightbox to Contao. Compatible with Contao 5.6+ Twig layouts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
