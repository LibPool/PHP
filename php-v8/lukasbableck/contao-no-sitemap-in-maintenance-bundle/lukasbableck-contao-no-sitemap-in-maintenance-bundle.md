# lukasbableck/contao-no-sitemap-in-maintenance-bundle

> 标签: Sitemap, maintenance, url, wartung

## 简介

This bundle disables the sitemap if the root page is in maintenance mode.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
