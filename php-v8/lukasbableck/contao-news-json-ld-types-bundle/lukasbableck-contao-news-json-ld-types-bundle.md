# lukasbableck/contao-news-json-ld-types-bundle

> 标签: JSON-LD, article, blog, contao, news, schema, structured data

## 简介

This bundle allows you to select the JSON-LD types Article, NewsArticle and BlogPosting for Contao news archives instead of always using NewsArticle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
