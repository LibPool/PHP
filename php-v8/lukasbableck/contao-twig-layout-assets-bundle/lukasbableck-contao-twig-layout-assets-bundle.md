# lukasbableck/contao-twig-layout-assets-bundle

> 标签: JS, contao, css, head, layout, twig

## 简介

This bundle re-adds the ability to add CSS and JS files, as well as HTML code that is inserted in the `<head>` section in Twig layouts in Contao 5.6+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
