# lukasbableck/contao-select-placeholder-bundle

> 标签: contao, dropdown, field, form, option, placeholder, select

## 简介

This bundle adds a placeholder option to the select form fields in the Contao form generator.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
