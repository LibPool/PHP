# andrekeher/wpdp-taxonomy-meta

> 标签: meta, taxonomy, wordpress

## 简介

Helps in a new metabox creation in Wordpress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
