# sideclick/entity-helper-bundle

> 标签: PHP

## 简介

Bundle for Symfony 2.6+ which introduces entity helper classes for each Doctrine entity in your bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
