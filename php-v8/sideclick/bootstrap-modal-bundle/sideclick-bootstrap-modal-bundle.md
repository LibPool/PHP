# sideclick/bootstrap-modal-bundle

> 标签: PHP

## 简介

Bundle for Symfony 3.4+ that makes it easy to load pages into a Bootstrap modal window.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
