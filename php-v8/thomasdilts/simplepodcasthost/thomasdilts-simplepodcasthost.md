# thomasdilts/simplepodcasthost

> 标签: podcast, podcasting, podcasting host

## 简介

This is a simple php podcast host that fulfills all the needs for podcasting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
