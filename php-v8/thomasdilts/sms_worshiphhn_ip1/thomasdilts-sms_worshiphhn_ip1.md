# thomasdilts/sms_worshiphhn_ip1

> 标签: sms, worshiphhn, yii2

## 简介

This is an SMS system using the sms supplier https://ip1sms.com for the worshiphhn project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
