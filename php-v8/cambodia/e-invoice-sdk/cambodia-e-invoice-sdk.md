# cambodia/e-invoice-sdk

> 标签: E-Invoice, UBL-2.1, cambodia, caminv, laravel, tax, ubl

## 简介

CamInv (Cambodia E-Invoicing) SDK for Laravel — OAuth, UBL 2.1 XML generation, document submission, webhooks, and member management

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
