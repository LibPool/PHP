# dashed/dashed-ecommerce-reseller

> 标签: Dashed, api, dashed-ecommerce-reseller, laravel, reseller

## 简介

Afnemers-API voor Dashed CMS: assortimenten, prijzen en voorraad voor zakelijke afnemers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
