# geobase/countries

> 标签: country, data, database, geoip, geolocation, province, region, state

## 简介

Data from Open Data providers compiled into easy to use PHP objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
