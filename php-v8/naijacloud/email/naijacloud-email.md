# naijacloud/email

> 标签: api, email, naija-cloud, naijamail, smtp, transactional-email

## 简介

Official PHP SDK for Naijamail, the transactional email API of Naija Cloud.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
