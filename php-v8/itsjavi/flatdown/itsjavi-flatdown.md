# itsjavi/flatdown

> 标签: cms, flat-file, markdown, microsite, php, psr-15, psr-7

## 简介

Minimalistic Flat-file CMS with Markdown support, written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
