# arafa/laravel-deadcode-detector

> 标签: cleanup, dead-code, laravel, static-analysis, unused-code

## 简介

Detect and report dead / unused code in Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
