# ojessecruz/resend-inbox

> 标签: email, inbound, inbox, jessecruz, resend, threading

## 简介

Framework-agnostic core of a Resend-powered shared inbox: webhook parsing, conversation threading, reply headers and auto-reply detection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
