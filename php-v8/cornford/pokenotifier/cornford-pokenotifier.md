# cornford/pokenotifier

> 标签: map, nearby, notification, pokemon, pokemon go, slack

## 简介

An easy way to send nearby Pokemon notifications to Slack.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
