# tg/tgwebvalid

> 标签: Authentication, auth, authorization, login, telegram, telegram-login, telegram-login-widget, telegram-mini-app, validation, verification, webapp

## 简介

An easy way to validate Telegram Login Widget and Telegram Mini App users on your website using PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
