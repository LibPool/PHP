# cerbero/json-objects

> 标签: cerbero, json, json-objects, parser, stream

## 简介

Extract objects from large JSON files, endpoints or streams while saving memory.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
