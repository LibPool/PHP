# cerbero/fluent-api

> 标签: api, cerbero, client, fluent-api, http

## 简介

Framework agnostic base package to extend for creating fluent APIs from scratch or on top of existing ones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
