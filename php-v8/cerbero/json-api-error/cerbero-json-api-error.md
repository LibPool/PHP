# cerbero/json-api-error

> 标签: JSON-API, api, error-handling, errors, json, laravel

## 简介

Laravel package to standardize API errors in compliance with the JSON:API spec.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
