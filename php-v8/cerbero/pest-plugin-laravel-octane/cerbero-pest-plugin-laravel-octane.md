# cerbero/pest-plugin-laravel-octane

> 标签: laravel, laravel-octane, octane, pest, test, testing

## 简介

Pest plugin to test Laravel applications powered by Octane.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
