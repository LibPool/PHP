# echovel/kitephp

> 标签: SPA, framework, micro-framework, php, reactive

## 简介

The Full Stack PHP Micro-Framework with a built-in SPA Reactive Engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
