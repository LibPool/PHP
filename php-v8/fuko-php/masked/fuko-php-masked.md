# fuko-php/masked

> 标签: black-list, blacklist, fuko, fuko-php, mask, masked, obfuscation, redact, security

## 简介

Masks sensitive data: replaces blacklisted elements with redacted values

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
