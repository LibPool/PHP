# bypassflow/standards

> 标签: bypassflow, coding-style, standards

## 简介

共有コーディング規約、php-cs-fixer custom fixer、関連文書を提供する standards package。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
