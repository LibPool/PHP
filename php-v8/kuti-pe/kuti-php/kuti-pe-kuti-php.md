# kuti-pe/kuti-php

> 标签: checkout, kuti, payments, peru, qr, yape

## 简介

SDK oficial de KUTI para PHP — crea checkout sessions, consulta pagos y verifica webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
