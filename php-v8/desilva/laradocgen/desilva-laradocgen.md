# desilva/laradocgen

> 标签: desilva, documentation, laradocgen, laravel, static site builder

## 简介

Generates static HTML documentation for Laravel based on Markdown with a realtime preview.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
