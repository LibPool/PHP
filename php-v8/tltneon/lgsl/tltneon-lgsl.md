# tltneon/lgsl

> 标签: SAMP, ark, cs, dayz, discord, fivem, gameserver, gmod, minecraft, query, rust

## 简介

PHP library retrieve game servers status from various types of games.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
