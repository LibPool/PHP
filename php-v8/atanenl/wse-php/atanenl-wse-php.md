# atanenl/wse-php

> 标签: WS-Security, soap, ws-addressing

## 简介

Libraries for adding WS-* support to ext/soap in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
