# assegaiphp/beanstalkd

> 标签: PHP

## 简介

Beanstalkd queue integration for AssegaiPHP framework, enabling job production and consumption using the Pheanstalk library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
