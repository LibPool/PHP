# assegaiphp/rabbitmq

> 标签: PHP

## 简介

RabbitMQ queue integration for AssegaiPHP framework, providing decorators and tools for producing and consuming AMQP-based jobs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
