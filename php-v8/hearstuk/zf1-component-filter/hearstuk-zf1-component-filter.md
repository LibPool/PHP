# hearstuk/zf1-component-filter

> 标签: PHP

## 简介

The Zend_Filter component from Zend Framework 1.12 abstracted out for use with composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
