# elidrissidev/magento-restextended

> 标签: magento, magento-module, openmage, openmage-module

## 简介

Full REST API implementation for Magento 1.9 and OpenMage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
