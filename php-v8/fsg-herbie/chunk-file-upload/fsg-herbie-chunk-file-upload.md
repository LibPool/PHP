# fsg-herbie/chunk-file-upload

> 标签: catlane, chunk_file, extension, laravel-admin

## 简介

文件上传小扩展，可支持大文件分块分片上传到七牛云or本地，优化您上传大文件的苦恼

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
