# fluvpay/fluvpay

> 标签: fluvpay, gateway, pagamentos, payments, pix, sdk, webhooks

## 简介

SDK oficial da FluvPay para PHP. Pagamentos PIX, saques, transferências internas e verificação de webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
