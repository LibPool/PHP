# nazg/skeleton

> 标签: adr, framework, hack, hhvm, middleware, request, response, route, xhp

## 简介

Action-Domain-Responder (ADR) Micro framework for HHVM/Hack

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
