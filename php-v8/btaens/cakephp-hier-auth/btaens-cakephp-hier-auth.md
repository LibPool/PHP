# btaens/cakephp-hier-auth

> 标签: acl, cakephp, hierarchy, hierauth, plugin, roles

## 简介

A CakePHP plugin for hierarchical, role based, simple authorization.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
