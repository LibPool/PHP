# eril/calendary

> 标签: appointments, availability, booking, calendar, scheduling, time-slots

## 简介

A lightweight, framework-agnostic PHP library for calendar availability, busy periods and bookable time slots.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
