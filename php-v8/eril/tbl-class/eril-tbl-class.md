# eril/tbl-class

> 标签: PSR-4, autocomplete, cli, code-generation, database-constants, database-schema, developer-experience, mysql, php, raw-sql, schema, sql, sqlite

## 简介

CLI tool that Generates stable PHP constants from your database schema to improve IDE autocomplete and avoid SQL typos.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
