# eril/db-model-entity

> 标签: active-record, database, orm, pdo, query-builder

## 简介

A lightweight, fluent, and efficient database toolkit separating query logic from data mutations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
