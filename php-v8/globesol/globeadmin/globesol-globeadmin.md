# globesol/globeadmin

> 标签: admin, administrator, cms, crm, laravel, php

## 简介

GlobeAdmin is a Open source Laravel Admin Panel / CMS which can be used as Admin Backend, Data Management Tool or CRM boilerplate for Laravel with features like CRUD Generation, Module Manager, Media, Menus, Backups and much more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
