# flexmind-software/currency-rate

> 标签: currency rate, currency rates, currency-converter, currency-exchange, flexmind, foreign exchange rates, laravel, mongo, mysql, pachages, php, postresql

## 简介

Library download currency rate and save in database, It's designed to be extended by any available data source.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
