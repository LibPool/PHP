# fiber-interop/process

> 标签: PHP

## 简介

Cooperative proc_open() for fiber-interop/api: fiber\process\run() and start() capture stdout/stderr, pipe stdin and wait for exit on any adapter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
