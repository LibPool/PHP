# fiber-interop/ext-scope

> 标签: async, extension, fiber, php-ext, scope

## 简介

The Scope class from the PHP RFC "Scope", as a PHP extension (PHP 8.2+).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
