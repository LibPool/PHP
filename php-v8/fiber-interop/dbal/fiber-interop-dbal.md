# fiber-interop/dbal

> 标签: PHP

## 简介

Doctrine DBAL drivers that run queries through fiber-interop/mysqli and fiber-interop/pg: cooperative DBAL queries inside fiber\run() with one line of configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
