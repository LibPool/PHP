# fiber-interop/scope

> 标签: async, fiber, polyfill, request, scope

## 简介

Scope: the identity of the operation (request, job) that code belongs to. PHP extension, with a userland polyfill when it is not loaded.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
