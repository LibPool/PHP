# fiber-interop/predis

> 标签: PHP

## 简介

Cooperative Predis for fiber-interop/api: a StreamConnection that waits on the socket with fiber\readable()/writable(), so Redis commands suspend only the calling task.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
