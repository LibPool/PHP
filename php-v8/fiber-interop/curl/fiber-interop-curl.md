# fiber-interop/curl

> 标签: PHP

## 简介

Cooperative curl_exec() for fiber-interop/api: fiber\curl\exec() and start() on any adapter, with native drivers where the runtime has one.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
