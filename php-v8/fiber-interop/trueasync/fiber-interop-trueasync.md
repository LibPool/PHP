# fiber-interop/trueasync

> 标签: PHP

## 简介

TrueAsync (ext true_async) coroutine adapter for fiber-interop/api: go, await, sleep, readable, writable on Async\Coroutine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
