# fiber-interop/api

> 标签: PHP

## 简介

One surface for fiber-based concurrency: go, await, sleep, readable, writable on phasync, Revolt, AMPHP and ReactPHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
