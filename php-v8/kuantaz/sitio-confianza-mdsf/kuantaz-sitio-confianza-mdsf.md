# kuantaz/sitio-confianza-mdsf

> 标签: PHP

## 简介

Librería de integración de Sitio de Confianza con MDSFID/VUS (flujo de identidad).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
