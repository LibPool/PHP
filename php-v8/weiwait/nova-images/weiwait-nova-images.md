# weiwait/nova-images

> 标签: drop, images, laravel, nova, 多图, 多图裁剪, 裁剪

## 简介

A Laravel Nova field for multiple images by json. Laravel Nova 多图组件，目前仅支持json格式

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
