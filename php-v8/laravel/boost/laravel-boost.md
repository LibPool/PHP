# laravel/boost

> 标签: ai, dev, laravel

## 简介

Laravel Boost accelerates AI-assisted development by providing the essential context and structure that AI needs to generate high-quality, Laravel-specific code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
