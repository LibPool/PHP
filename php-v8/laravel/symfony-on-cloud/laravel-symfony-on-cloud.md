# laravel/symfony-on-cloud

> 标签: PHP

## 简介

Bring Laravel Cloud features to Symfony — a feature-based bundle whose first capability is Managed Queues on top of Symfony Messenger.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
