# laravel/sanctum

> 标签: API, auth, laravel, sanctum, 认证

## 简介

Laravel Sanctum provides a featherweight authentication system for SPAs and simple APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
