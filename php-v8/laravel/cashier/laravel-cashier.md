# laravel/cashier

> 标签: billing, laravel, stripe, 支付, 订阅

## 简介

Laravel Cashier provides an expressive, fluent interface to Stripe's subscription billing services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
