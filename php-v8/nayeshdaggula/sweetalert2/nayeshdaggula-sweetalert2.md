# nayeshdaggula/sweetalert2

> 标签: alert, laravel, notifier, sweet

## 简介

A simple PHP package to show Sweet Alerts with the Laravel Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
