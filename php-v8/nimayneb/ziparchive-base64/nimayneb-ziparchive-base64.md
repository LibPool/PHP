# nimayneb/ziparchive-base64

> 标签: base64, unicode, utf-8, utf8, zip, ziparchive

## 简介

ZipArchive extended with support for UTF-8 encoded strings using base64.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
