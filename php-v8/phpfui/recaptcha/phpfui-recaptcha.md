# phpfui/recaptcha

> 标签: Abuse, captcha, recaptcha, spam

## 简介

Client library for Google's reCAPTCHA for PHP 8.4 and higher

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.google.com/recaptcha/
- 源码仓库：https://github.com/phpfui/recaptcha.git
- Packagist 页面：https://packagist.org/packages/phpfui%2Frecaptcha
