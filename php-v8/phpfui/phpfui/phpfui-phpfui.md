# phpfui/phpfui

> 标签: css, foundation, framework, html, object oriented, object-oriented, php, responsive, scss, ui

## 简介

PHP Object Oriented Wrapper for the Foundation CSS Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
