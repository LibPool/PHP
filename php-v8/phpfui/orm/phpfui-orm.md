# phpfui/orm

> 标签: activerecord, fast, lightweight, mapper, mapping, mariadb, model, mysql, object, orm, postgre, relational, sql, sqlite

## 简介

A Fast, Lightweight and Minimal ORM for MySQL, SQLite, MariaDB and PostGre

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
