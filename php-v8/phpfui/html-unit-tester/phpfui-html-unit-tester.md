# phpfui/html-unit-tester

> 标签: css, html, phpunit, test, testing, unit, validation

## 简介

PHPUnit Testing extensions for HMTL and CSS insures valid HTML and CSS via v.Nu validator

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
