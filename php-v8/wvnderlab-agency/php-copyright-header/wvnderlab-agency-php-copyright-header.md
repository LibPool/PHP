# wvnderlab-agency/php-copyright-header

> 标签: Code style, copyright, php, php-cs-fixer

## 简介

A custom fixer to provide copyright headers in each file via PHP-CS-Fixer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
