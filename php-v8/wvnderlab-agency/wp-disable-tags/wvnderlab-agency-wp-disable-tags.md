# wvnderlab-agency/wp-disable-tags

> 标签: wordpress, wordpress-muplugin, wordpress-plugin

## 简介

A simple WordPress mu-plugin to disable tags.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
