# wvnderlab-agency/php-codestyles

> 标签: Code style, php, php-cs-fixer

## 简介

A PHP package providing PHP-CS-Fixer configurations and rulesets for Wvnderlab Agency projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
