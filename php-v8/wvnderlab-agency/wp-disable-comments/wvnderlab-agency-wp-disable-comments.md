# wvnderlab-agency/wp-disable-comments

> 标签: wordpress, wordpress-muplugin, wordpress-plugin

## 简介

A simple WordPress mu-plugin to disable comments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
