# jorisros/feed-builder-bundle

> 标签: PHP

## 简介

Bundle that based on output channel bundle, this bundle can be triggered by publish a object or by commandline.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
