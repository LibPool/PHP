# jorisros/html-compress-twig

> 标签: compress, css, extension, html, javascript, minify, twig

## 简介

Twig extension for compressing HTML and inline CSS/Javascript

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
