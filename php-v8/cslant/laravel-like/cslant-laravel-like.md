# cslant/laravel-like

> 标签: cslant, cslant-laravel-like, cslant-like, cslant-package, laravel, laravel-dislike, laravel-like, laravel-like-package, laravel-love, like-dislike, like-package

## 简介

A package providing like, dislike, love and unlike interaction features for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
