# thomasvantuycom/statamic-iban-fieldtype

> 标签: PHP

## 简介

IBAN fieldtype for Statamic with built-in country code, length, and checksum validation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
