# icecave/stump

> 标签: factor, heroku, log, logging, psr-3, twelve

## 简介

Incredibly simple PSR-3 compliant logging for Twelve-Factor applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
