# icecave/overpass

> 标签: AMQP, call, job, procedure, publish, pubsub, queue, rabbit, remote, rmi, rpc, subscribe, task

## 简介

A basic pub/sub, RPC and task queue system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
