# pulseindex/pulseindex-php

> 标签: filtering, gRPC, geo, indexing, pulseindex, search

## 简介

Official PHP client SDK for PulseIndex — hosted search and filtering for large entity sets

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
