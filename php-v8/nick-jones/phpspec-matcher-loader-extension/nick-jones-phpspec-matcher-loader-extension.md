# nick-jones/phpspec-matcher-loader-extension

> 标签: custom, extension, loader, matcher, phpspec

## 简介

Allows custom phpspec matchers to be registered via configuration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
