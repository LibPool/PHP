# haveyb/export-csv

> 标签: yield, 内存, 导出, 数据

## 简介

PHP 数据导出，使用 yield 优化导出大数据量时内存占用过高导致宕机

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
