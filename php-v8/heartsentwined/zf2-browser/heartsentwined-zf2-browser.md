# heartsentwined/zf2-browser

> 标签: browser, curl, zf2

## 简介

web browser with quick browse methods using zf2's HTTP Client and cURL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
