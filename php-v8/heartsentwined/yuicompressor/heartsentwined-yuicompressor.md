# heartsentwined/yuicompressor

> 标签: JS, compressor, css, minifier, yui

## 简介

YUI Compressor is a popular CSS and JS minifier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
