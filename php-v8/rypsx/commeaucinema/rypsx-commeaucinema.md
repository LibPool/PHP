# rypsx/commeaucinema

> 标签: api, commeaucinema, php, tool

## 简介

A PHP tool to extract the cinema news from commeaucinema.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
