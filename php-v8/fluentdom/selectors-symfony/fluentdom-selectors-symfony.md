# fluentdom/selectors-symfony

> 标签: css, css selectors, dom, jquery, xml

## 简介

Provides CSS selector for FluentDOM using Symfony CSS Selectors.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
