# fluentdom/yaml-dipper

> 标签: dom, fluentdom, xml, yaml

## 简介

YAML support for FluentDOM (using Dipper)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
