# fluentdom/selectors-phpcss

> 标签: css, css selectors, dom, jquery, xml

## 简介

Provides CSS selector for FluentDOM using Carica PHPCss.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
