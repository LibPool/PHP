# fiscalo/laravel-sdk

> 标签: api, fiscalo, invoicing, laravel, php, portugal, sdk

## 简介

Fiscalo Laravel SDK for the public Fiscalo API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://docs.fiscalo.pt/integrations/laravel
- 源码仓库：https://github.com/fiscalo-pt/laravel-sdk.git
- Packagist 页面：https://packagist.org/packages/fiscalo%2Flaravel-sdk
