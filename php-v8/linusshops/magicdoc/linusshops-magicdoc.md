# linusshops/magicdoc

> 标签: canadas motorcycle, linus shops, magento, magicdoc, module, mx canada, utility

## 简介

Autogenerate phpdoc for magic methods from json documents

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
