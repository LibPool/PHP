# php-fhir/elements

> 标签: ehr, fhir, hl7, php, php-fhir

## 简介

Element Classes for the PHP implementation of the FHIR EHR specification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
