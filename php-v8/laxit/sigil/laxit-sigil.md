# laxit/sigil

> 标签: ascii, cistercian, dxf, glyph, identicon, sigil, svg

## 简介

Turn an integer into one recognizable Cistercian-style glyph: SVG, ASCII or DXF.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
