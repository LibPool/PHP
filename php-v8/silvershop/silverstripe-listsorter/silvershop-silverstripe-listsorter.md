# silvershop/silverstripe-listsorter

> 标签: arraylist, datalist, list, sort, sortable

## 简介

Easily provide front-end sorting controls for SilverStripe lists

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
