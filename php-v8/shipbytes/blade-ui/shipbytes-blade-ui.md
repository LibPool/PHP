# shipbytes/blade-ui

> 标签: alpinejs, blade, blade-components, design-system, design-tokens, laravel, tailwind, tailwindcss, ui-kit

## 简介

Blade UI components for Laravel — 41 accessible components with design tokens, dark mode and Tailwind v4 CSS included. Presentation only: no Livewire, no state.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
