# wmlc/pdf2image

> 标签: convert image , laravel, laravel 5, pdf, pdf to image, pdt-to-image

## 简介

Convert pdf files to images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
