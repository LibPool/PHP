# dweik/crud-generator

> 标签: artisan, bootstrap, command, command-line, commandline, crud, generate, generator, laravel, mysql, postgres, postgresql, route, sqlite

## 简介

it's a easy tool for laravel +5.1 to generate crud functions base database tables

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
