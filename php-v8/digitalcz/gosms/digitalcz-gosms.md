# digitalcz/gosms

> 标签: digitalcz, go-sms, gosms, php, www.gosms.eu

## 简介

Go SMS PHP library - provides communication with https://www.gosms.cz/api/ in PHP via PSR-18 HTTP Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
