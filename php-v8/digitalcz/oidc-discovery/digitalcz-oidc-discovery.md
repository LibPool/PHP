# digitalcz/oidc-discovery

> 标签: OpenId, oidc, oidc discovery, php

## 简介

PHP implementation of https://openid.net/specs/openid-connect-discovery-1_0.html

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
