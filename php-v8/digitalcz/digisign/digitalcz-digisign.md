# digitalcz/digisign

> 标签: digi-sign, digisign, digisign.cz, digisign.org, php

## 简介

DigiSign PHP library - provides communication with https://api.digisign.org in PHP via PSR-18 HTTP Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
