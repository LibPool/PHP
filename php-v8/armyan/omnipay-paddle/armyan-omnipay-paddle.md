# armyan/omnipay-paddle

> 标签: gateway, merchant, omnipay, paddle, pay, payment, purchase

## 简介

Paddle driver for the Omnipay Laravel Payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
