# neapoli/skholeio

> 标签: Skenografia, Skholeio, drupal, sub-theme, theme

## 简介

Skholeio è un sub-theme drupal, basato sul tema Skenografia, che implementa il design delle scuole.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
