# paynecta/paynecta-laravel-sdk

> 标签: api, bank-integration, kenya, kenya-payments, laravel, mpesa, mpesa-integration, paybill, payment, payment-gateway, paynecta, sdk, till, wallet

## 简介

Official Laravel SDK for the Paynecta API. Take M-Pesa payments in Kenya with hosted checkout, signed webhooks and settlement to your own bank, paybill or till.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
