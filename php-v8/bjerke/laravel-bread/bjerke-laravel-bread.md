# bjerke/laravel-bread

> 标签: api, bread, crud, eloquent, jesperbjerke, laravel, orm, query, rest

## 简介

A boilerplate package for BREAD operations through REST API in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
