# joetannenbaum/phpushbullet

> 标签: api, bullet, notification, php, push, pushbullet

## 简介

PHP API wrapper for Pushbullet.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
