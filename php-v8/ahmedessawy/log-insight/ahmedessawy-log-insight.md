# ahmedessawy/log-insight

> 标签: laravel, livewire, log-viewer, logs, monitoring

## 简介

Secure Laravel log viewer with tags, rich filtering, error grouping, metrics dashboard and alerts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
