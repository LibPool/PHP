# danielbachhuber/composer-lock-updater

> 标签: PHP

## 简介

Run composer-lock-updater in your CI system for bot-powered composer.lock pull requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
