# irstea/phpmd-shim

> 标签: mess detection, mess detector, pdepend, phpmd, pmd, shim

## 简介

Shim repository for phpmd/phpmd

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
