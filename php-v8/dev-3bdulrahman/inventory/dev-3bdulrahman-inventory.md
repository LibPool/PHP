# dev-3bdulrahman/inventory

> 标签: PHP

## 简介

An Inventory management module for Laravel ERP — warehouses, stock, transfers, adjustments & serial/batch tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
