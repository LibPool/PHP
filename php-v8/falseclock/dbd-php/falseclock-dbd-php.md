> 标签: 1c, 1С, Yellow ERP, YellowERP, cache, dbd, dbi, driver, microsoft sql server, mssql, mysql, odata, pdo, postgre, postgresql, sql

## 简介

Database driver for PHP (PostgreSQL, MySQL, MSSQL, OData, YellowERP, 1С)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
