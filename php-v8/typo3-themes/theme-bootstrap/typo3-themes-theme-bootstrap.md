# typo3-themes/theme-bootstrap

> 标签: TYPO3 CMS, TYPO3 THEMES, bootstrap, customize, fluid, themes

## 简介

TYPO3 THEMES Base-theme using Twitter bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
