# simplecms/dynamic_unit

> 标签: SimpleCMS, attributes, dynamic_unit, laravel, sku

## 简介

动态单元组件，可以丰富你的Model，让其具备更多的单元属性，无需对数据表进行多次修改调整， 仅需要简单调用即可让单一Model增加更多可控属性

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
