# tiacx/laravel-aliyun-log

> 标签: SLS, aliyun, laravel, log

## 简介

Laravel 阿里云 SLS 日志扩展包：Monolog 日志推送 + 访问日志中间件

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
