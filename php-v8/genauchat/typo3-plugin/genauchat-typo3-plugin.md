# genauchat/typo3-plugin

> 标签: PHP

## 简介

Adds the genau.chat AI chat widget to your TYPO3 website. Easy setup via backend module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
