# ianfoxdev/ledger

> 标签: Accounting, billing, credits, double-entry, fintech, ledger, money, wallet

## 简介

Double-entry ledger for PHP that runs inside your database transaction: balances derived from postings, idempotent transactions, holds and expiring credits.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
