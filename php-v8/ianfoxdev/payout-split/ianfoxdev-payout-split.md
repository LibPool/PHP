# ianfoxdev/payout-split

> 标签: affiliates, allocation, fintech, largest-remainder, money, payouts, revenue-share, royalties

## 简介

Splits a pool of money between partners by weights: the shares always add up to the pool, and recalculating a closed period gives the same result.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
