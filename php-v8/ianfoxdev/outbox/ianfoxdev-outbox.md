# ianfoxdev/outbox

> 标签: doctrine, event-driven, events, kafka, laravel, outbox, postgresql, rabbitmq, symfony, transactional-outbox

## 简介

Transactional outbox for PHP: store events in the same database transaction, publish them to Kafka or RabbitMQ with a separate relay.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
