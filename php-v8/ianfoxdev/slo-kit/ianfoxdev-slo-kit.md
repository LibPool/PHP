# ianfoxdev/slo-kit

> 标签: Metrics, burn-rate, error-budget, observability, prometheus, psr-15, sli, slo, sloth, sre

## 简介

SLOs for PHP services, measured right: latency histograms with a bucket at every SLO threshold, route templates, an explicit definition of an error, a check of /metrics against the SLO file, and a Sloth spec for burn-rate alerts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
