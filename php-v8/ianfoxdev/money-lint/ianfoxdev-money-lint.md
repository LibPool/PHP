# ianfoxdev/money-lint

> 标签: PHPStan, doctrine, fintech, laravel, money, payments, phpstan-extension, static-analysis, transactions

## 简介

PHPStan rules for code that moves money: floats in amounts, HTTP calls inside database transactions, balance updates that skip the ledger, check-then-act without a lock.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
