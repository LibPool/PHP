# ianfoxdev/psp-sandbox-php

> 标签: idempotency, mock, payment-gateway, payments, phpunit, psp, psr-18, sandbox, standard-webhooks, testing, webhooks

## 简介

PHP client for psp-sandbox: drive failure scenarios from tests, inspect callback deliveries and verify signatures.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
