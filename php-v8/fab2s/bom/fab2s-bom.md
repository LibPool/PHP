# fab2s/bom

> 标签: Byte-order-mark, Simple, big-endian, bom, helper, little-endian, php, utf-16, utf-32, utf-8, utf8

## 简介

Purely static zero dependencies BOM Helper to handle unicode BOMs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
