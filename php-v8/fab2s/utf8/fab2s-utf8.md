# fab2s/utf8

> 标签: Simple, helper, intl, mb_string, nfc, nfd, normalize, php, utf-8, utf8

## 简介

A purely static UTF8 Helper based on mb_string and ext-intl

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
