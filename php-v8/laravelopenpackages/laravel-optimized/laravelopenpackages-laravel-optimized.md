# laravelopenpackages/laravel-optimized

> 标签: compiled, eloquent, laravel, optimize, performance, routing

## 简介

Laravel, optimized: a compiled request path for Laravel applications, with Laravel's own code as the fallback.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
