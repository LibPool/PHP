# aleks-bar/wp-project

> 标签: bedrock, composer, roots, wordpress, wp, wp-config

## 简介

WordPress boilerplate with Composer, easier configuration, and an improved folder structure

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
