# lesspdf/laravel-sdk

> 标签: html-to-pdf, laravel, lesspdf, pdf, typst

## 简介

Laravel SDK for the lesspdf-engine HTML/Typst to PDF API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
