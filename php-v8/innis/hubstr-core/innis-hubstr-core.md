# innis/hubstr-core

> 标签: amphp, http-server, hubstr, kernel, migrations, nostr, sqlite

## 简介

Shared runtime kernel for Hubstr services: application lifecycle, configuration, logging, SQLite persistence, templating, and the shared amphp HTTP host kit

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
