# innis/coding-standards

> 标签: PHP

## 简介

PHPStan rules that enforce the Innis coding conventions: clean-architecture layering, banned traits, interface/collection/exception placement, value-object immutability, and naming smells; plus a check that no tracked path component exceeds 95 characters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
