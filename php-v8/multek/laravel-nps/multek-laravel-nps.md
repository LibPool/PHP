# multek/laravel-nps

> 标签: NPS, feedback, laravel, net-promoter-score, survey

## 简介

A simple, focused NPS (Net Promoter Score) package for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
