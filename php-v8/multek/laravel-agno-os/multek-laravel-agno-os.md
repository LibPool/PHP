# multek/laravel-agno-os

> 标签: agentos, agents, agno, ai, jwt, laravel

## 简介

A Laravel client and JWT token factory for Agno AgentOS 3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
