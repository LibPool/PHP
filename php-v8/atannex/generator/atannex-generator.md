# atannex/generator

> 标签: Reference, code, eloquent, generator, invoice-number, laravel, sequence

## 简介

Unique, human-readable codes for Laravel: reference numbers, invoice sequences, staff IDs, vouchers and tokens from one pattern language.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
