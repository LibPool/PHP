# atannex/scopable

> 标签: eloquent, expiry, laravel, publishable, query-scopes, schedule, scopes, soft-states

## 简介

Declarative state and date scopes for Laravel Eloquent: published / scheduled / draft, active flags, schedule windows, expiry, highlights, limits and composites, with matching PHP checks, mutators, period scopes (createdThisWeek, publishedWithin), default states and transition events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
