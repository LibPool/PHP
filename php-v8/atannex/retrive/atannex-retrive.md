# atannex/retrive

> 标签: cache, eloquent, filters, finder, laravel, query, repository, retrieval

## 简介

Data retrieval layer for Laravel Eloquent models: resource definitions, a fluent retriever, magic finders (getPostBySlug, getPostsByCategory…), request-driven filters, sorts and includes, visibility rules, hierarchy-aware relation filters, search, neighbours, related records and self-invalidating caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
