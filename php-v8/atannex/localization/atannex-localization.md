# atannex/localization

> 标签: filament, hreflang, i18n, l10n, laravel, locale, localization, multilingual, translatable, translation

## 简介

Complete localization for Laravel: locale registry with a built-in catalog, request negotiation (URL prefix, domain, query, user, session, cookie, Accept-Language, geo), localized URLs and hreflang, a language switcher, translatable Eloquent attributes with driver-aware JSON queries, locale-aware formatting, queue locale propagation, missing-key tracking, translation coverage tooling and a Filament plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
