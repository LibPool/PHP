# atannex/matrix

> 标签: analytics, bookmarks, comments, engagement, follows, laravel, likes, ratings, reactions, reviews, shares, trending, views

## 简介

The engagement matrix for Laravel: views, reading time, clicks, reactions, ratings, reviews, threaded comments, shares, bookmarks, follows and reports for any Eloquent model, for guests and accounts alike, with running counters, daily rollups, trending, scoring, moderation and a JSON API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
