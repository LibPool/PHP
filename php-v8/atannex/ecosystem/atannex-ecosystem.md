# atannex/ecosystem

> 标签: deep-search, eloquent, full-text, global-search, laravel, relevance, search

## 简介

Deep, ranked search for Laravel Eloquent: any relation depth, JSON paths, search syntax (phrases, exclusions, field filters, ranges), global multi-model search and highlighting, with no search server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
