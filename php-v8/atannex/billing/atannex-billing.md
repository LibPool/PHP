# atannex/billing

> 标签: Cameroon, billing, flutterwave, laravel, mobile-money, momo, mtn, orange-money, payments, paypal, stripe, webhooks, xaf

## 简介

Payments for Laravel across Stripe, MTN Mobile Money, Orange Money, PayPal and Flutterwave: one fluent API, smart gateway routing by currency and phone operator, a guarded payment state machine, verified webhooks, automatic reconciliation of mobile-money payments, refunds, an audit ledger and a test fake.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
