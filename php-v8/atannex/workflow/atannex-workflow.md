# atannex/workflow

> 标签: Audit, approval, bpm, eloquent, laravel, state-machine, workflow

## 简介

Workflow engine for Laravel Eloquent models: states and transitions, guards, multi-person approvals, task inboxes, deadlines with escalation, timers, automatic transitions and a full audit trail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
