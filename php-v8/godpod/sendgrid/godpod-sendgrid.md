# godpod/sendgrid

> 标签: email, grid, send, sendgrid

## 简介

This library allows you to quickly and easily send emails or make api calls through SendGrid using PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
