# sun/country

> 标签: country, country code, laravel, laravel country, laravel country code, php, planet, planet country code, sun, sun country code

## 简介

Sun Country is the package that helps you to get the country name & dialing code by the country ISO 3166-1 Alpha-2 code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
