# kruegge82/goexpress

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

API for creating, updating, canceling shipments and generating labels for GO! Express & Logistics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
