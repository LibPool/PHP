# hyperf-apex/wecom

> 标签: WeCom, apex, easywechat, hyperf, swoole, wechat-work

## 简介

Apex WeCom (企业微信) toolkit for Hyperf: multi-corp account resolver, shared EasyWeChat application, access token cache and OAuth login

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
