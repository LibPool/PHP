# hyperf-apex/apex

> 标签: apex, hyperf, metapackage, openapi, swoole

## 简介

Apex generic infrastructure, API engine and components for Hyperf (Metapackage)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
