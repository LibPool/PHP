> 标签: engagement, exit-intent, marketing, popup, sylius, sylius-plugin

## 简介

Exit-intent & engagement popup system for Sylius 2.x stores, fully managed from the admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
