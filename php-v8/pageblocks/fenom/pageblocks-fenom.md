# pageblocks/fenom

> 标签: fenom, template, templater, templating

## 简介

pbFenom — hardened Fenom fork for PageBlocks (isolated namespace, security fixes, linear-time compiler)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
