# ketapay/ketapay-laravel

> 标签: Nigeria, escrow, ketapay, laravel, payments, webhooks

## 简介

Laravel integration for the KetaPay PHP library: config, facade, and verified webhooks as Laravel events

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
