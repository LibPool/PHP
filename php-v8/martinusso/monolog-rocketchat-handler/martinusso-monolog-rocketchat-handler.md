# martinusso/monolog-rocketchat-handler

> 标签: handler, monolog, php, rocket.chat

## 简介

A Monolog handler for Rocket.Chat webhooks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
