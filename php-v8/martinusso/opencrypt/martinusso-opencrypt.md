# martinusso/opencrypt

> 标签: decrypt, encrypt, openssl, php

## 简介

Encrypts and decrypts data using PHP with OpenSSL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
