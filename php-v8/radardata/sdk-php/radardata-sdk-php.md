# radardata/sdk-php

> 标签: SERPRO, consultas, kyc, laravel, radardata, serasa, verify

## 简介

SDK oficial do RadarData para PHP e Laravel: consultas, Verify, Motor de Analises e webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
