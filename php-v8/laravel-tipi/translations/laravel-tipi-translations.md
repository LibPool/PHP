# laravel-tipi/translations

> 标签: eloquent, i18n, laravel, localization, translations

## 简介

Flexible Eloquent model translations for Laravel with dedicated-table, shared-table, and JSON storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
