# devuri/wp-hook-scanner

> 标签: actions, filters, hooks, scanner, static-analysis, wordpress

## 简介

Scans PHP files for WordPress hooks and outputs a categorized report or JSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
