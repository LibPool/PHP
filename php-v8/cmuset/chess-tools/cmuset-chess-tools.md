# cmuset/chess-tools

> 标签: PGN, applier, chess, fen, parser, san, tool, validator

## 简介

A chess tools library for parsing and exporting chess notations (PGN, SAN, FEN).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
