# bifrost-orbit/cms-sdk

> 标签: bifrost-orbit, cms, cms-orbit, delivery-api, headless-cms

## 简介

Read content from CMS Orbit: a PHP client for the delivery API, with SEO, sitemap, preview and webhook helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
