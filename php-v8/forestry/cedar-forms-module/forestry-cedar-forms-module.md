# forestry/cedar-forms-module

> 标签: Cedar, Forms, cedarcms, cms, filament, laravel, module

## 简介

Forms module for CedarCMS Core — form builder, submissions, and spam defenses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
