# namshi/google-doc-configuration-bundle

> 标签: PHP

## 简介

Configure the dependency injection container of your Symfony2 applications with a Google Doc. Crazy, ahm?

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
