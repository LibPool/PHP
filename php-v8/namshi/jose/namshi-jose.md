# namshi/jose

> 标签: JSON Web Signature, JSON Web Token, JWS, json, jwt, token

## 简介

JSON Object Signing and Encryption library for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
