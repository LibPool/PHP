# sdksio/swagger-petstore-3-sdk

> 标签: apimatic, openapi, petstore, swagger

## 简介

This is a sample Pet Store Server based on the OpenAPI 3.0 specification.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
