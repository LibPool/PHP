# xavrsl/cas

> 标签: SSO, cas, laravel, phpCAS

## 简介

Add CAS server SSO authentication to Laravel 4 and 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
