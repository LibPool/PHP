# devzone/log-monitor

> 标签: apm, devzone, laravel, logging, monitoring, queries, queue

## 简介

Monitors a Laravel application (requests, queries, outgoing HTTP calls, queued jobs, logs and exceptions) and ships redacted records to a DevZone monitoring server through a durable on-disk spool.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
