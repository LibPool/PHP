# nabeghe/buildify

> 标签: OOP, builder, builder design pattern, class, design pattern, fluent, fluent interface, get, getter, helper, library, object, set, setter, support, trait

## 简介

Buildify improves PHP OOP with enhanced getter and setter functionality inspired by Builder and Fluent Patterns.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
