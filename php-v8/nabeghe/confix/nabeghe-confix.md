# nabeghe/confix

> 标签: Settings, class-config, config, config-manager, config-system, configuration, dot-notation, file-config, helper, nested-config, options, options-manager, php-config, settings-manager, static, static-config, static-settings, support

## 简介

Static-architecture PHP configuration library. Simple, file-backed, class-based configuration with parent/child partitioning and dot-notation support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
