# nabeghe/alphanum

> 标签: URL-Shortener, alphanum, base36, base58, base62, bigint, decimal, hashids, link-shortener, number-converter, sexagesimal, snowflake, uuid-shortener

## 简介

High-performance PHP library for bi-directional conversion between decimal numbers and alphanumeric strings (Base62, Base58, Base60, Base36) with BigInt support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
