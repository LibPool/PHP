# nabeghe/shortnum

> 标签: helper, library, math, num, number, number abbreviation, number shortener, number shorthand, numbers, numerical notation, short, short num, short number, shortener, shortnum, shortnumber, support

## 简介

Shortening numbers and using abbreviated letters in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
