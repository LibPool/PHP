# nabeghe/nohtml

> 标签: DSL, helper, html, html dsl, library, nohtml, support

## 简介

Say no to HTML — write views in PHP with a clean, simple DSL.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
