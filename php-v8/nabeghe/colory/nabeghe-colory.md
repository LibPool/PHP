# nabeghe/colory

> 标签: color, color-converter, color-helper, color-manipulation, colory, contrast, helper, hex, hsl, hsv, library, palette, rgb, wcag

## 简介

Simple yet powerful colors helper & manipulation library for PHP with HEX, RGB, HSL, HSV, alpha, WCAG contrast, and CSS support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
