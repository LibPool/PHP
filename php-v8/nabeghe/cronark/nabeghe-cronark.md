# nabeghe/cronark

> 标签: background, background-process, background-task, backgroundtask, cron, cron-job, cronjob, job, job-queue, jobqueue, process, queue, task, worker

## 简介

A lightweight, cron-based background job scheduler and worker manager for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
