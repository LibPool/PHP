# digitalcloud/laravel-model-assignment

> 标签: assignable, assignment, digitalcloud, eloquent, laravel, laravel-assignment, package

## 简介

Laravel package allow you to assign eloquent models to assignee

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
