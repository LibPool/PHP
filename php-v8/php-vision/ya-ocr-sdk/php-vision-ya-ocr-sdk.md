# php-vision/ya-ocr-sdk

> 标签: OCR, cloud, http-client, ocr-php, ocr-text-reader, vision, yandex

## 简介

HTTP client for Yandex Cloud Vision OCR (sync/async)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
