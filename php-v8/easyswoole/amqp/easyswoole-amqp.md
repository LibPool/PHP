# easyswoole/amqp

> 标签: AMQP, async, easyswoole, framework, swoole

## 简介

A coroutine AMQP 0-9-1 client for Swoole

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.easyswoole.com/
- 源码仓库：https://github.com/easy-swoole/amqp.git
- Packagist 页面：https://packagist.org/packages/easyswoole%2Famqp

- Composer 安装：`composer require easyswoole/amqp`

- 许可证：Apache-2.0
