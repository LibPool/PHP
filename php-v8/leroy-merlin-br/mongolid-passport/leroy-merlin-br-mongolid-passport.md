# leroy-merlin-br/mongolid-passport

> 标签: laravel, mongodb, mongolid, mongolid-laravel, oauth, passport

## 简介

Mongolid Passport provides OAuth2 server support to Laravel and Mongolid.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
