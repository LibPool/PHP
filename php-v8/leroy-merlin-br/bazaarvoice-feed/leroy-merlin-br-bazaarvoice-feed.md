# leroy-merlin-br/bazaarvoice-feed

> 标签: bazaarvoice

## 简介

A PHP library for generating Bazaarvoice XML Product and Interaction Feeds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
