# northstar/cipher-laravel

> 标签: blind-index, eloquent, encryption, laravel, northstar, scout, search

## 简介

Northstar Cipher for Laravel: transparent, batched field-level encryption and blind-index search for Eloquent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
