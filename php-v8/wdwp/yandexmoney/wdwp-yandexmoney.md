# wdwp/yandexmoney

> 标签: payment, yandex

## 简介

PHP library for Yandex money forms and buttons api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/wdwp/yandexmoney
- 源码仓库：https://github.com/wdwp/yandexmoney.git
- Packagist 页面：https://packagist.org/packages/wdwp%2Fyandexmoney
