# ujjwal/auth

> 标签: zf2

## 简介

A Zend framework module based on ZfcUser to check if user is logged in and to manage session, session save handler etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
