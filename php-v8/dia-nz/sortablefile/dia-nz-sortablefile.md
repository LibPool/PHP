# dia-nz/sortablefile

> 标签: cms, file, silverstripe, sortable

## 简介

An extension for SilverStripe 4 that adds sorting to UploadField.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
