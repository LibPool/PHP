# marcohern/jwtauthorize

> 标签: authorization, jwt, jwtauthorize, laravel, marcohern, middleware

## 简介

Authorize Laravel requests with allow/deny route policies carried in a JWT claim.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
