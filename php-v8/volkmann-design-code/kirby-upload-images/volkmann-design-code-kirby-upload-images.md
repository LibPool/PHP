# volkmann-design-code/kirby-upload-images

> 标签: exif, heic, images, kirby, kirby-cms, kirby-plugin, resize, upload

## 简介

Uploaded images made web-ready: HEIC converted, big photos shrunk without running out of memory, EXIF kept as file fields

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
