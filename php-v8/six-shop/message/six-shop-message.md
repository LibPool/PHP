# six-shop/message

> 标签: message, notification, sixshop, thinkphp

## 简介

系统消息扩展，为SixShop应用提供消息管理功能，包括消息的发送、接收、存储和查询等核心功能。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
