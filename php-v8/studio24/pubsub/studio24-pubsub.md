# studio24/pubsub

> 标签: events, messaging, publish-subscribe, pubsub

## 简介

Simple implementation of the PubSub design pattern in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
