# yrodevgit/ctrx

> 标签: PHP

## 简介

Codetazer-X (CTRX) by Tyrone Malocon: a lightweight, JSON-first PHP framework for building fast, modern web apps and REST APIs with full developer control.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
