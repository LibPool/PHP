# kesha-dev/yii2-async

> 标签: async, extension, php-async, yii2, yii2-async

## 简介

Provide an easy way to run code asynchronously for Yii2 application

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
