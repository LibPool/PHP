# saintsweeto/nz-post

> 标签: nz-post, nz-post api, nz-post php wrapper

## 简介

A PHP wrapper for NZ Post API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
