# saintsweeto/addressfinder

> 标签: address-finder, address-finder api, address-finder php wrapper

## 简介

A PHP wrapper for NZ AddressFinder API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
