# electriccitizen/citizen_edge

> 标签: PHP

## 简介

Portable media file lifecycle package: entity usage tracking, file replace, file delete, and host-aware CDN cache purging on file replace/delete.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
