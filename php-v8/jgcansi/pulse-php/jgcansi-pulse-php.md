# jgcansi/pulse-php

> 标签: Metrics, apm, laravel, monitoring, observability, profiling, sqlite, telemetry, tracing

## 简介

Lightweight observability, monitoring and telemetry library for PHP 8.1+ and Laravel — fully local, backed by SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
