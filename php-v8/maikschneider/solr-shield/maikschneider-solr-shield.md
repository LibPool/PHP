# maikschneider/solr-shield

> 标签: bot-protection, psr-15, security, solr, typo3, typo3-cms-extension

## 简介

Protects the Apache Solr search endpoint of TYPO3 from bots and crawlers that enumerate search parameters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
