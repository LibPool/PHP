# maikschneider/category-tree

> 标签: backend, category, navigation, tree, typo3, typo3-cms-extension

## 简介

Reusable category tree navigation component for TYPO3 backend modules, plus an optional category management module.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
