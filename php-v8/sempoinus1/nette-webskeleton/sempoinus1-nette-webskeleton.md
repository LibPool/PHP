# sempoinus1/nette-webskeleton

> 标签: OOP, console, cron-ready, docker, mvc, nette, php, symfony, tracy, web skeleton

## 简介

A standardized OOP project for Nette with console command support (cron-ready) and full Dockerized setup. Features modular MVC, security, database management, caching, and debugging via Tracy. Includes Symfony Console for CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
