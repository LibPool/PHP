# frednandrin/ical-bundle

> 标签: calendar, iCalendar, ical, ics, symfony, welp

## 简介

Symfony Bundle to manage .ics iCal file (creating and eventually reading)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
