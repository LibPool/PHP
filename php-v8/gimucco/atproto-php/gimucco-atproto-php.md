# gimucco/atproto-php

> 标签: atproto, bluesky, dpop, oauth, par, pkce

## 简介

AT Protocol OAuth 2.1 client for PHP — PKCE, DPoP, and PAR support for authenticating with Bluesky and other atproto services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
