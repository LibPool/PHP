# skriva/statamic

> 标签: content, publishing, skriva, statamic, statamic-addon

## 简介

Statamic publish endpoints for Skriva: token-authenticated collection discovery and entry create/update.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
