# szenario/craft-embedded-posters

> 标签: Craft, cms, craft-plugin, craftcms, embedded-assets, gdpr, oembed, poster, privacy, thumbnail

## 简介

Local poster images for Embedded Assets embeds, so cookie-consent placeholders don't contact YouTube, Vimeo or SoundCloud.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
