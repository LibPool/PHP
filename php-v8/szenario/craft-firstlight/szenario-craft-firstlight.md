# szenario/craft-firstlight

> 标签: PHP

## 简介

Automatic poster images for video assets. firstlight grabs a frame with ffmpeg, and Craft transforms serve it as AVIF or WebP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
