# ilsondev/voyager

> 标签: admin, laravel, panel

## 简介

A maintained, actively-developed fork of Voyager - the Laravel Admin Package. This is an updated version that continues development after the original package was archived.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
