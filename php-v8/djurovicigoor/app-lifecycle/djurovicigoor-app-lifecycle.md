# djurovicigoor/app-lifecycle

> 标签: PHP

## 简介

App lifecycle state detection plugin for NativePHP Mobile detects foreground/background transitions on Android and iOS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
