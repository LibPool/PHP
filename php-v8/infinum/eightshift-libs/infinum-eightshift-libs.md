# infinum/eightshift-libs

> 标签: blocks, composer, gutenberg, installer, plugin, wordpress

## 简介

WordPress libs developed by Eightshift team to use in modern WordPress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
