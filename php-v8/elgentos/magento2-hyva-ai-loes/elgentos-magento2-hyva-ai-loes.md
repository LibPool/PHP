# elgentos/magento2-hyva-ai-loes

> 标签: ai, eu, hostyourai, hyva, llm, loes, magento2

## 简介

Loes.ai provider for the Hyvä AI framework: Dutch, EU-hosted open-weight LLMs via the OpenAI-compatible HostYourAI router.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
