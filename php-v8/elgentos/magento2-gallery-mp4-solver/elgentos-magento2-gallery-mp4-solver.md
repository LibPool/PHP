# elgentos/magento2-gallery-mp4-solver

> 标签: PHP

## 简介

MP4 support for the Magento media gallery: upload, sync, poster thumbnails and clean deletion of video assets

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
