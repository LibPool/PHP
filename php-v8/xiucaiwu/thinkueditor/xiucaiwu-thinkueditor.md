# xiucaiwu/thinkueditor

> 标签: tp5ueditor, tp6ueditor, tpueditor, ueditor, ueditor for thinkphp

## 简介

ThinkPHP定制版Ueditor,要求TP5以上版本

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
