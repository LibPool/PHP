# cybex/laravel-lodor

> 标签: chunked-uploads, cybex, dropzone, laravel-lodor, resumablejs

## 简介

Provides easy support for processing chunked uploads in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
