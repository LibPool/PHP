> 标签: collation, nastaliq, nlp, normalization, pakistan, roman-urdu, rtl, search, stemmer, stopwords, transliteration, unicode, urdu

## 简介

Zero-dependency Urdu text processing: normalization, collation, transliteration, search, numbers, detection, tokenization, statistics, stop words, stemming, dates, and name transliteration. PHP port of the TypeScript urdu-text-utils, consuming the same generated tables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
