# boutdecode/etl-bundle

> 标签: api, bundle, doctrine, etl, symfony

## 简介

Symfony Bundle providing Doctrine persistence and a REST API on top of boutdecode/etl-core-bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
