# paylod/paylod

> 标签: daraja, kenya, laravel, m-pesa, mpesa, paylod, payments, safaricom, stk-push

## 简介

Official PHP client for the paylod API - M-Pesa (Safaricom Daraja) STK Push, status polling, signed webhooks and offline error decoding, with first-class Laravel support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
