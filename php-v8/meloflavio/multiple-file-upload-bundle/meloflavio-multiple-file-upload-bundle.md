# meloflavio/multiple-file-upload-bundle

> 标签: angular-js, sonata, upload

## 简介

Bundle to add an AngularJS file upload field to Sonata Admin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
