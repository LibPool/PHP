# wouterlagerwerf/laravel-sns-queue-driver

> 标签: PHP

## 简介

A package that adds support for SNS as a queue driver for Laravel. Handy for microservice messaging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
