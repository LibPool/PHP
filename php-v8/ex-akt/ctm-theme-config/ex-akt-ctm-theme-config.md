# ex-akt/ctm-theme-config

> 标签: configuration, contao, deployment, scss, theme-manager

## 简介

Keeps the Contao Theme-Manager configuration in the repository instead of the database

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
