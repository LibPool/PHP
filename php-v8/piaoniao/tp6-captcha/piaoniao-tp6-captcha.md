# piaoniao/tp6-captcha

> 标签: PHP

## 简介

The Captcha class library for ThinkPHP 6.0, which relies on php_Imagick

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
