# nuwira/bandrek

> 标签: bandrek, laravel, nuwira, password

## 简介

Bandrek is password recovery token generation using number as code for Laravel 5.4.x based.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
