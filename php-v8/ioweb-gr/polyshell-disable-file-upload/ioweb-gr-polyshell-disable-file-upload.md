# ioweb-gr/polyshell-disable-file-upload

> 标签: PHP

## 简介

Magento 2 module that disables file custom option uploads as a temporary PolyShell mitigation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
