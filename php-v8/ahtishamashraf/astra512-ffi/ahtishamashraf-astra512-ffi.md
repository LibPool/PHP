# ahtishamashraf/astra512-ffi

> 标签: aead, astra512, crypto, ffi, siv

## 简介

PHP FFI bindings for ASTRA-512 (research SIV-style AEAD) with key management helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
