# bez/zfview-bundle

> 标签: symfony, templating, zend-view

## 简介

Multi-step layouts and view helpers for Symfony2 via Zend\View component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
