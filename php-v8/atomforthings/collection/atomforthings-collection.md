# atomforthings/collection

> 标签: atom, atom for things, atomforthings, internet of things, iot, protocol

## 简介

Support library for Atom's PHP Libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
