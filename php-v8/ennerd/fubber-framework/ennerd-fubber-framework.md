# ennerd/fubber-framework

> 标签: PHP

## 简介

Fubber Framework by Ennerd.com. Create web applications that share the same source hosted by Apache, Nginx or React PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
