# ajouve/rabbit-mq-wrapper

> 标签: AMQP, framework, rabbitmq

## 简介

rabbitMQWrapper is a wrapper for RabbitMQ

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
