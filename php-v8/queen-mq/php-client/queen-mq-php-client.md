# queen-mq/php-client

> 标签: broker, consumer-groups, fifo, laravel, message-queue, queue

## 简介

Queen MQ client for PHP and a Laravel queue driver: jobs in order per customer, workers that follow the backlog, an alternative to Horizon and Redis

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
