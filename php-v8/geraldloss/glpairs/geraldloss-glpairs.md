# geraldloss/glpairs

> 标签: extension, game, pairs, typo3

## 简介

Provide a flexible pairs game. You are able to configure the pairs game in many different types. You can assign two cards with the same image, two cards with similar images, two cards with an image and a description of the image or two text cards with the same description (i.e. in different languages). See an example on https://www.schulze-thulin.de/en/games/pairs-german-welsh-irish/pairs-halle-in-german

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
