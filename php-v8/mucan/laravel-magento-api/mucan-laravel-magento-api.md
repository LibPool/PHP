# mucan/laravel-magento-api

> 标签: grayloon, laravel-magento-api

## 简介

Magento 2 REST API Wrapper to export Magento data to use in your Laravel application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
