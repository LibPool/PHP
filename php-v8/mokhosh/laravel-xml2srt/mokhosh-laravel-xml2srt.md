# mokhosh/laravel-xml2srt

> 标签: Mo Khosh, laravel, laravel-caption, laravel-xml2srt

## 简介

Work with SRT files and YouTube XML subtitles in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
