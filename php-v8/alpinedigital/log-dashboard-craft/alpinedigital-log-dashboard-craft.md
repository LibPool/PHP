# alpinedigital/log-dashboard-craft

> 标签: PHP

## 简介

In-project log viewer for local development — reads the host project's own storage/logs from the Craft control panel, no SSH.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
