# dautkom/php.ipv4

> 标签: IP, ip-address, ipv4, mask, subnet

## 简介

PHP library for work with IPv4 addresses, subnets and masks

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
