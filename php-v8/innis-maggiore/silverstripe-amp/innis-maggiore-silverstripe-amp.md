# innis-maggiore/silverstripe-amp

> 标签: AMPHTML, google, mobile, silverstripe

## 简介

Module for converting SilverStripe Pages to Google AMP HTML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
