# drabek-digital/loopbind

> 标签: PHP

## 简介

🛠️️ CLI tool to easily bind localhost network interface with additional IP and ensure matching record in /etc/hosts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
