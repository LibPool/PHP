# storefront-x/magento-module-sfx-store-config

> 标签: PHP

## 简介

Magento 2 module for configuration new SFX store config fields in Magento and get their values

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
