# cedcommerce/freshdesk-sdk

> 标签: Freshdesk, api, customer service, help desk, support

## 简介

PHP SDK for the Freshdesk API (v2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
