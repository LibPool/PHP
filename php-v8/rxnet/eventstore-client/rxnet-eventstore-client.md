# rxnet/eventstore-client

> 标签: EventSourcing, EventStore, reactivex, reactphp

## 简介

EventStore asynchronous PHP client with reactiveX flavours

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
