# a-pb/horizon-ui

> 标签: dashboard, filter, horizon, jobs, laravel, queue, search, ui

## 简介

Enhanced UI for Laravel Horizon - adds job name search/filter to Pending, Completed, and Failed tabs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
