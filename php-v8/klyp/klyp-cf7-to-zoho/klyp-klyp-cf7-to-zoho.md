# klyp/klyp-cf7-to-zoho

> 标签: Zoho, cf7, contact form, contact form 7, plugin, wordpress

## 简介

This plugin allows you to map CF7 fields to ZOHO form fields.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
