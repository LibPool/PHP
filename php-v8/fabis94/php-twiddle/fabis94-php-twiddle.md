# fabis94/php-twiddle

> 标签: PHP

## 简介

The Chase's Twiddle algorithm rewritten in PHP that returns all combinations of m out of n objects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
