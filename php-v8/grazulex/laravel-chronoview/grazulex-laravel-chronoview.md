# grazulex/laravel-chronoview

> 标签: cron, dashboard, heartbeat, laravel, missed-runs, monitoring, schedule, scheduler

## 简介

Horizon-style dashboard for the Laravel scheduler: every run, every failure, every missed run

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
