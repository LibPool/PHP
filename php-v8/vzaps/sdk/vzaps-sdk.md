# vzaps/sdk

> 标签: api, php, sdk, vzaps, whatsapp

## 简介

Official PHP SDK for the VZaps public API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://docs.vzaps.com
- 源码仓库：https://github.com/VZaps/vzaps-sdk-php.git
