# infofactory/statamic-ai-translations

> 标签: ai, i18n, multilanguage, statamic, tools, translations

## 简介

A Statamic addon that lets you translate pages using AI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
