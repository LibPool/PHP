# fredbradley/imcapi

> 标签: HPE, api, imc, intelligent management center, network management, network monitoring

## 简介

PHP JSON API wrapper for the HPE IMC software to manage network switches

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
