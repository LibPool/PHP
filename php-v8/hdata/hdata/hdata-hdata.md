# hdata/hdata

> 标签: hdata

## 简介

Interact with HData servers using PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/hdata-org/php-hdata
- 源码仓库：https://github.com/HData-org/php-hdata.git
- Packagist 页面：https://packagist.org/packages/hdata%2Fhdata

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- Composer 安装：`composer require hdata/hdata`
- Packagist 仓库：https://repo.packagist.org/p2/hdata/hdata.json
- 许可证：Apache-2.0
- PHP 要求：^7.4|^8.0
