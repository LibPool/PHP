# aosmak/laravel-layer-sdk

> 标签: Layer Server API, laravel 5, layer, php 7.2

## 简介

Library that allows PHP developers to make requests to Layer Server API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
