# hhpack/publisher

> 标签: hack, hhvm, publisher, pubsub, subscriber

## 简介

Simple implementation of Pub/Sub for Hack

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
