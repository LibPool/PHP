# hhxsv5/php-coroutine

> 标签: coroutine, generator, php-coroutine, yield

## 简介

A lightweight library to implement coroutine by yield & Generator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
