# silmaril/ubi

> 标签: network, networking, ubi, ubiquiti, unifi

## 简介

A thin, standards-based PHP wrapper around Ubiquiti's API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
