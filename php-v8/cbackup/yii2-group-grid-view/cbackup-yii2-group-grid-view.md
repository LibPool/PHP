# cbackup/yii2-group-grid-view

> 标签: extension, grid, groupgrid, groupgridview, widget, yii, yii2

## 简介

GridView Extensions that groups rows by any column(s) for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
