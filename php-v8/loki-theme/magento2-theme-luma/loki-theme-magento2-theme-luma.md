# loki-theme/magento2-theme-luma

> 标签: PHP

## 简介

Independent Magento 2 theme to remove all Luma JavaScript but keep Luma LESS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
