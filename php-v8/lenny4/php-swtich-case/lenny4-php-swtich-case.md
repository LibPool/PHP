# lenny4/php-swtich-case

> 标签: Lenny4, php-swtich-case

## 简介

Switch string between (camel case, snake case, kebab case, pascal case, upper case)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
