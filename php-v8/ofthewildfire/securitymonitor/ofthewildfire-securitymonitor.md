# ofthewildfire/securitymonitor

> 标签: PHP

## 简介

Security Monitor plugin for OctoberCMS. Monitors suspicious password reset attempts and alerts users with IP tracking.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
