# abdasis/laravel-openqa

> 标签: PHP

## 简介

Dashboard QA standalone (Inertia React) yang membaca hasil exploration qa-explorer dari .openqa/ dan menampilkannya di /e2e.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
