# ruiyi/laadmin

> 标签: admin, form, grid, laravel, laravel saas admin, ruiyi, saas

## 简介

一个基于larval的后台管理插件包，基于dcat-admin改造而来。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
