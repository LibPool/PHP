# lasallecms/lasallecmsfrontend

> 标签: Bob Bloom, LaSalleCMS, South LaSalle, front, front-end, laravel, laravel5

## 简介

Front-end package for the LaSalle Content Management System.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
