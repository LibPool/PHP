# 51degrees/fiftyone.pipeline.did

> 标签: 51degrees, 51did, fodid, owid

## 简介

Strongly typed reader for the 51Did (51Degrees Identifier) returned by the 51Degrees Cloud service, and a client for the cloud's 51Did endpoints (public keys, signature verification and creator context redemption). Parses the OWID envelope and exposes the usage, the identifier type, the License Id, the match key and the terms. Compare match keys, never envelopes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
