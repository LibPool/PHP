# delicket/delicket-standard

> 标签: aesculis, coding-standard, phpcs, rules

## 简介

Aesculis Standard Coding Style for PHP_CodeSniffer, rules to be upheld by Aesculis projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
