# icawebdesign/hibp-php

> 标签: breaches, digiserv, haveibeenpwned, hibp, icawebdesign, passwords

## 简介

PHP library for accessing the Have I Been Pwned API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
