# robo-meister/flow-beacon-api

> 标签: api, flow-beacon, flowbeacon, jwt, robo-meister, sdk

## 简介

FlowBeacon API PHP SDK for validating Robo account JWTs and intent contexts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
