# majora/oauth-server-bundle

> 标签: bundle, oauth, server

## 简介

Provides a lightweight, extensive and highly customizable OAuth Server as a Symfony Bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
