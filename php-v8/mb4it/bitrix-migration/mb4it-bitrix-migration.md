# mb4it/bitrix-migration

> 标签: PHP

## 简介

Laravel-style versioned migrations for 1C-Bitrix (MB\Bitrix\Database\Migrations). Ships its console commands on top of mb4it/bitrix-console.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
