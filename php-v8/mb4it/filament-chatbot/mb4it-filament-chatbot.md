# mb4it/filament-chatbot

> 标签: Live Chat, chat, chatbot, conversation, filament, laravel, workflow

## 简介

Customer chat and a visual chatbot builder for any Filament panel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
