# hdrjpg/hdrjpg-sdk-php

> 标签: PHP

## 简介

The official PHP SDK to convert high dynamic range photos into web-ready HDR files using the hdrjpg.com API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
