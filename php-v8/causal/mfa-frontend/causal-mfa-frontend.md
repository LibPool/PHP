# causal/mfa-frontend

> 标签: 2fa, Authentication, MFA, TYPO3 CMS, multi-factor, one-time, otp, protection, secure, security

## 简介

Enable MFA (Multi-Factor Authentication) for Frontend accounts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
