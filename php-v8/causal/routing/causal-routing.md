# causal/routing

> 标签: TYPO3 CMS, http request, rest, routing, web service

## 简介

Service to route HTTP/REST requests to your own controller/actions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
