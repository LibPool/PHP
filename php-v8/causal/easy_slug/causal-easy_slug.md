# causal/easy_slug

> 标签: TYPO3 CMS, pages, slug, update, uri, url

## 简介

Updates the slug of a page automatically and logically when renaming a page or moving it around.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
