# crazzy501/gpt3-tokenizer

> 标签: GPT-3, decode, encode, gpt-2, openai, tokenizer

## 简介

PHP package for Byte Pair Encoding (BPE) used by GPT-3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
