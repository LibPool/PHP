# s1dd/magus

> 标签: csv, import, json, laravel, model

## 简介

Import data (with CSV/JSON parsing built-in) into any Laravel Model

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
