# sachittandukar/carbon-fields-image-gallery

> 标签: wordpress, wp

## 简介

Extends the base Carbon Fields with a ImageGallery field. Based on https://github.com/schrapel/carbon-fields-image-gallery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
