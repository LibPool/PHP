# icap/portfolio-bundle

> 标签: Claroline, portfolio

## 简介

Portfolio bundle for Claroline Connect. See https://github.com/claroline/Claroline

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
