# elipzis/nova-embed-card

> 标签: card, dashboard, embed, iframe, laravel, nova, url

## 简介

A custom Laravel Nova card to embed external content in an iframe

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
