# tieupmedia/hwt_memorylist

> 标签: Flexible Memorylist, TYPO3 CMS, extbase, fluid, universal

## 简介

This TYPO3 extension provides a flexible memory list for TYPO3 >= 7.6

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
