# pondit/jwt

> 标签: PHP JWT, api authentication, jwt, php

## 简介

A simple library to encode and decode JSON Web Tokens (JWT) in PHP, conforming to RFC 7519.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
