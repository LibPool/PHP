# diggin/diggin-http-charset

> 标签: charset, mbstring, scraper

## 简介

Detecting based on header's charset and html meta charset. Automatically convert to UTF-8.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
