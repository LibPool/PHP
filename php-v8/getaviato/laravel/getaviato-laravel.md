# getaviato/laravel

> 标签: aviato, back-office, laravel, plugin

## 简介

Extend an Aviato connector with custom actions, computed fields, hooks, segments, search and charts from your Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
