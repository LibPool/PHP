# blendcraft/recaptcha

> 标签: Craft, cms, craft-plugin, craftcms, recaptcha

## 简介

A simple craft plugin for validating Google's reCAPTCHA v3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
