# jyarali/to-sitemap

> 标签: Sitemap, generator, google-news, html, laravel, laravelium, php, xml

## 简介

Laravelium Sitemap package for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
