# matsevh/jeugdwerk-news

> 标签: PHP

## 简介

A packages for Jeugdwerk used to merge multiple news sources of an organization into one json

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
