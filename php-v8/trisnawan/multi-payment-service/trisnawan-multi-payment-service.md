# trisnawan/multi-payment-service

> 标签: PHP

## 简介

PHP Library untuk koneksi ke backend pembayaran (tertutup) by Trisnawan.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
