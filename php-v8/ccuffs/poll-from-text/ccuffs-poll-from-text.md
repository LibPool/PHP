# ccuffs/poll-from-text

> 标签: form, nlp, poll, questionnaire, survey

## 简介

Convenient package to create polls (questionnaires) from pure text minimally organized in lines.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
