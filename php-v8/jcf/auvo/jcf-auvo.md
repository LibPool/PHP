# jcf/auvo

> 标签: Integração, api, auvo, field-service, fsm, laravel

## 简介

Pacote Laravel para integração com a API do Auvo - Sistema de gestão de serviços de campo (field service management)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
