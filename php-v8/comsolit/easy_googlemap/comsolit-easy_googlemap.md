# comsolit/easy_googlemap

> 标签: cms, map, typo3

## 简介

Easy and simple Googlemap Extension for the TYPO3 CMS, Good use for company roadmap on websites and for responsive pages, based on the google maps API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
