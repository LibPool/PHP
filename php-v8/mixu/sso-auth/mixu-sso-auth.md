# mixu/sso-auth

> 标签: Authentication, SSO, activity-tracking, anomaly-detection, area-based-access, audit-trail, brute-force-detection, laravel, oauth2, role-based-access, security-monitoring, session-binding, session-hijacking-prevention, single-sign-on

## 简介

Comprehensive Laravel SSO Authentication package with Security Monitoring, Session Binding, Activity Tracking, and Global Logout Support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
