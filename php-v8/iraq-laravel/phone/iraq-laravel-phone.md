# iraq-laravel/phone

> 标签: alkafeel, asiacell, iraq, korek, laravel, phone, validation, zain

## 简介

Iraqi phone number validation, operator detection, and E.164 normalization for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
