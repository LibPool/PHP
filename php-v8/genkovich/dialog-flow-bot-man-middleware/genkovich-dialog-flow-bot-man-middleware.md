# genkovich/dialog-flow-bot-man-middleware

> 标签: Botman, Dialogflow, bot

## 简介

Middleware for BotMan (BotMan Studio). Integration with DialogFlow API v2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
