# hosmelq/ext-anydoc

> 标签: PowerPoint, anydoc, converter, csv, document, document-conversion, epub, excel, markdown, open-document, pdf, php, php-extension, rtf, word

## 简介

PHP extension for converting documents to GitHub-Flavored Markdown with Firecrawl anydoc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
