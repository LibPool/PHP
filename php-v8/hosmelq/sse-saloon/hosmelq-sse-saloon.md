# hosmelq/sse-saloon

> 标签: event-source, hosmelq, php, saloon, server-sent-events, sse, stream

## 简介

A Saloon plugin for consuming Server-Sent Events (SSE) streams.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
