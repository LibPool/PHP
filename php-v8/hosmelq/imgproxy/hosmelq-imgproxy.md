# hosmelq/imgproxy

> 标签: encryption, image-processing, image-transforms, imgproxy, imgproxy-php, php, signed-urls, url-builder

## 简介

Build imgproxy URLs in PHP with optional encryption and signing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
