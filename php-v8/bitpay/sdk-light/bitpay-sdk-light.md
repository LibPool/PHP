# bitpay/sdk-light

> 标签: bitcoin, bitpay, cash, gateway, payment

## 简介

Light version of the PHP library for the new cryptographically secure BitPay API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
