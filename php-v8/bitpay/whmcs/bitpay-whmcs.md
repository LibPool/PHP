# bitpay/whmcs

> 标签: Whmcs, bitcoin, bitpay, ecommerce, payment, plugin

## 简介

BitPay payment plugin for WHMCS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
