# cyto/phpdocumentor-llms

> 标签: ai, documentation, llm, llms, markdown, phpDocumentor, phpdoc, template

## 简介

LLM-friendly single-file documentation template for phpDocumentor

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
