# ogetit/ogetit

> 标签: OGame, UniverseView

## 简介

OGetIt is a open source PHP library for handling the new OGame API as of version 6.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
