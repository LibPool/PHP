# php-kit/php-server

> 标签: Built-in, Integrated, development, embedded, server, web server

## 简介

Makes the PHP's built-in web server easier and more practical to use

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
