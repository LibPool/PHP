# top-tl/toptl

> 标签: api, bot, directory, sdk, telegram, top.tl, toptl

## 简介

Official PHP SDK for the TOP.TL Telegram directory API — post bot stats, check votes, manage vote webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
