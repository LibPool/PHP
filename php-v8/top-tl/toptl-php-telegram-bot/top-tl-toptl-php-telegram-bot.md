# top-tl/toptl-php-telegram-bot

> 标签: bot, longman, plugin, telegram, toptl

## 简介

longman/telegram-bot plugin for TOP.TL — autopost bot stats & check votes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
