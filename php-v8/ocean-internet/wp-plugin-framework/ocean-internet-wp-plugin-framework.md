# ocean-internet/wp-plugin-framework

> 标签: plugin, wordpress

## 简介

(yet another) OOP Wordpress MyPlugin Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
