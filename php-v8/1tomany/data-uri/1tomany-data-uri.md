# 1tomany/data-uri

> 标签: 2397, data uri, data-uri, dataURI, rfc 2397, rfc2397, symfony

## 简介

A simple, low dependency library to parse and decode data URIs defined in RFC 2397

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
