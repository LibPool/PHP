# 1tomany/pdf-pack

> 标签: OCR, pdf, pdf to image, pdf to text, pdf2image, pdf2img, pdf2text, pdf2txt, pdfinfo, pdftoppm, poppler, symfony, xpdf

## 简介

A simple PHP library that makes rasterizing pages and extracting text from PDFs for large language models easy

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
