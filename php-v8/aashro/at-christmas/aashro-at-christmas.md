# aashro/at-christmas

> 标签: PHP

## 简介

Christmas theme is a modern and responsive TYPO3 template designed for Christmas, perfect for holiday promotions, events, and seasonal websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
