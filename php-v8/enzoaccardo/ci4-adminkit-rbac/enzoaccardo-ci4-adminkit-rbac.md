# enzoaccardo/ci4-adminkit-rbac

> 标签: PHP

## 简介

RBAC (ruoli/permessi) per ci4-adminkit: implementa il contratto AdminKit\Contracts\Rbac (soft-discovery), servizio, model, migrazioni.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
