# enzoaccardo/ci4-adminkit-adminlte4

> 标签: PHP

## 简介

Tema AdminLTE 4 (Bootstrap 5) per ci4-adminkit: layout pannello admin + pagine front auth, asset precompilati + sorgenti Vite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
