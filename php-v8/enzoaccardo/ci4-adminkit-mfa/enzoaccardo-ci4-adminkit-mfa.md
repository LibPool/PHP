# enzoaccardo/ci4-adminkit-mfa

> 标签: PHP

## 简介

MFA (TOTP + WebAuthn/Passkey + recovery codes) per ci4-adminkit: servizi, flusso front, model, migrazioni. Viste dal tema ci4-adminkit-adminlte4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
