# benjamincrozat/lumen-boilerplate

> 标签: api, boilerplate, framework, laravel, lumen, restful

## 简介

Opinionated way to start a new Lumen project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
