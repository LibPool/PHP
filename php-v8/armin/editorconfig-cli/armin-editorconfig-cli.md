# armin/editorconfig-cli

> 标签: PHP

## 简介

EditorConfigCLI is a free CLI tool (written in PHP) to validate and auto-fix text files based on given .editorconfig declarations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
