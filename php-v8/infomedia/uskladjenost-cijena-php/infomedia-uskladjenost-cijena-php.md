# infomedia/uskladjenost-cijena-php

> 标签: cjenik, croatia, nn-101-2026, price-compliance, sidrena-cijena, uskladjenost-cijena

## 简介

PHP SDK for the Usklađenost cijena API (uskladjenost-cijena.com): anchor prices and public price lists under NN 101/2026.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
