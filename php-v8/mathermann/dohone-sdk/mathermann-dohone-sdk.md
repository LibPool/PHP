# mathermann/dohone-sdk

> 标签: Cameroon, Dohone, mobile-payments, payment-integration, sdk

## 简介

A PHP 5.4+ SDK for easily use Dohone payment API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
