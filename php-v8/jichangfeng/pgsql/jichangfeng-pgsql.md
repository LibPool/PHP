# jichangfeng/pgsql

> 标签: pdo, pdo_pgsql, pgsql

## 简介

Long-living PostgreSQL connection for daemon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
