# cms-orbit/sendgo

> 标签: alimtalk, cms, kakao, laravel, orbit, sendgo, sms

## 简介

Orbit SendGo integration: admin GUI, template sync, campaign records, and phone verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
