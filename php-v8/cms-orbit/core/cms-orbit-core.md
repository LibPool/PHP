# cms-orbit/core

> 标签: admin, cms, inertia, laravel, orbit, react

## 简介

CMS Orbit core: server-driven Screen/Layout/Field engine rendered via Inertia + React.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
