# geekset/octane-doctor

> 标签: architecture, ci, code-quality, diagnostics, laravel, laravel-octane, long-lived-workers, octane, octane-readiness, static-analysis

## 简介

Octane readiness scanner for Laravel: detect long-lived worker risks, explain each finding, and gate CI on new ones.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
