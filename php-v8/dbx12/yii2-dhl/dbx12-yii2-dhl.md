# dbx12/yii2-dhl

> 标签: dhl, extension, parcel-tracking, yii2

## 简介

Connect you Yii2 application with the DHL parcel tracking API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
