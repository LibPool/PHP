# webmunkeez/cqrs-bundle

> 标签: Autowiring, command, cqrs, doctrine, event, query, symfony

## 简介

Command-Query-Responsibility-Segregation pattern made for Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
