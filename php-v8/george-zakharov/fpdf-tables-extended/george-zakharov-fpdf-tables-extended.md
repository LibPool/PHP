# george-zakharov/fpdf-tables-extended

> 标签: fpdf, pdf

## 简介

This library provides generation of PDF tables with FPDF.This library is originally forked from https://github.com/smichaelsen/fpdf-tables.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
