# eliashaeussler/typo3-sitemap-locator

> 标签: PHP

## 简介

Sitemap Locator - Looks up XML sitemaps as part of a configured site. Supports various sitemap providers, e.g. by configured page type or robots.txt, and allows to implement custom providers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
