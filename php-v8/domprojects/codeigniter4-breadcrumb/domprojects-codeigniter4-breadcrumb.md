# domprojects/codeigniter4-breadcrumb

> 标签: breadcrumb, codeigniter, codeigniter4, navigation, ui

## 简介

Breadcrumb builder and controller integration for CodeIgniter 4 projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
