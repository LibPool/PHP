# catchyui/catchy

> 标签: SPA, alpine, alpinejs, blade, html-over-the-wire, laravel, morph, pjax

## 简介

Convert standard Laravel applications into SPAs using Alpine.js and HTML-over-the-wire.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
