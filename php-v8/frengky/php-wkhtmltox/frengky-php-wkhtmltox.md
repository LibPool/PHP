# frengky/php-wkhtmltox

> 标签: html, image, pdf, php, wkhtmltoimage, wkhtmltopdf, wkhtmltox

## 简介

Simple wkhtmltox wrapper for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
