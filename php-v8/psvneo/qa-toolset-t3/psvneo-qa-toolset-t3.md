# psvneo/qa-toolset-t3

> 标签: analyze, qa, quality, test, tool, typo3

## 简介

This package contains a collection of tools used for QA of TYPO3 extensions developed at PSV NEO GmbH.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
