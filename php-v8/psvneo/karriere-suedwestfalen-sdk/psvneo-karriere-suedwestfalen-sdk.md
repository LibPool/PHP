# psvneo/karriere-suedwestfalen-sdk

> 标签: PHP

## 简介

This library provides an easy API to communicate with the Karriere Suedwestfalen API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
