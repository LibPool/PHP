# psvneo/t3-extension-seo

> 标签: TYPO3 CMS, extension

## 简介

This extension provides a bunch of SEO related tools for optimizations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
