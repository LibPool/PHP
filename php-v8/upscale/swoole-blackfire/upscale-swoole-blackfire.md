# upscale/swoole-blackfire

> 标签: Blackfire.io, blackfire, companion, integration, profiler, profiling, swoole

## 简介

Blackfire profiler integration for Swoole web-server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
