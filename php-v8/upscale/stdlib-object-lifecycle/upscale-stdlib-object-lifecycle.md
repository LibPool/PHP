# upscale/stdlib-object-lifecycle

> 标签: allocate, allocation, circular references, cli, cyclic references, debug, destruct, destructor, garbage collection, health, leak, life cycle, lifecycle, memory, object, ram, reactphp, script, swoole

## 简介

Library to monitor lifecycle of objects allocated by long-running PHP scripts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
