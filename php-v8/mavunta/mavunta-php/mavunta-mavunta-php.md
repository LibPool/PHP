# mavunta/mavunta-php

> 标签: USDT, crypto, mavunta, mpesa, payment-gateway, payments

## 简介

Official PHP SDK for the Mavunta Pay API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
