# voceconnect/voce-post-meta-widgets

> 标签: post meta, widgets, wordpress

## 简介

Extension of Voce Post Meta API to add widgets meta field

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
