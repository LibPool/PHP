# voceconnect/voce-post-meta-date

> 标签: post meta, wordpress

## 简介

Extension of Voce Post Meta Plugin to create date meta fields

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
