# vlados/laravel-spam-guard

> 标签: bot-protection, laravel, spam, turnstile, typesafe, validation

## 简介

Content-based spam detection powered by TypeSafe Jev, with optional Turnstile bot protection for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
