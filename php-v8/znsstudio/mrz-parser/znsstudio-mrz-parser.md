# znsstudio/mrz-parser

> 标签: mrz-parser, rakibdevs

## 简介

A PHP package for MRZ (Machine Readable Zones) code parser for Passport, Visa & Travel Documents.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
