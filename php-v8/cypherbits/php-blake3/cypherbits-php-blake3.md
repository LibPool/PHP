# cypherbits/php-blake3

> 标签: blake3, crypto, hash, php-extension, simd

## 简介

BLAKE3 hashing algorithm PHP extension (native C, SIMD) for fast cryptographic hashing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
