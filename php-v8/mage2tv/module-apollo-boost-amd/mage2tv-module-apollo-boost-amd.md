# mage2tv/module-apollo-boost-amd

> 标签: PHP

## 简介

The popular apollo-boost graphql library transpiled to AMD, wrapped in a Magento 2 module.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
