# clicktrail/twig

> 标签: PHP

## 简介

Render-only Twig 3 helpers for ClickTrail attribution: head loader tag, hidden form inputs, consent state attributes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
