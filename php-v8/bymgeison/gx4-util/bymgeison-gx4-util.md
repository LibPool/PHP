# bymgeison/gx4-util

> 标签: PHP

## 简介

GX4-UTIL centraliza classes e componentes reutilizáveis para sistemas internos da Golfran.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
