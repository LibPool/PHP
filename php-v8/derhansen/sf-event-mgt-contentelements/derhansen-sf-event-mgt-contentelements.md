# derhansen/sf-event-mgt-contentelements

> 标签: TYPO3 CMS, content elements, event management

## 简介

Adds a relation field for content elements to events

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
