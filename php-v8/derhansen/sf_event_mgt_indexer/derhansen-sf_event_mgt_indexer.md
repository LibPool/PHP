# derhansen/sf_event_mgt_indexer

> 标签: TYPO3 CMS, indexer, ke_search, sf_event_mgt

## 简介

Indexer for ke_search which indexed sf_event_mgt records

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
