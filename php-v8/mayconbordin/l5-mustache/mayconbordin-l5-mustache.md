# mayconbordin/l5-mustache

> 标签: laravel, laravel 5, mustache, php

## 简介

A Mustache.php wrapper for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
