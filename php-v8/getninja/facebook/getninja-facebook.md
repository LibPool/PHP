# getninja/facebook

> 标签: Api Wrapper, PSR-2, facebook, sdk

## 简介

A PSR-2 Facebook SDK Api Wrapper for php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 获取地址

- Composer 安装：`composer require getninja/facebook`
