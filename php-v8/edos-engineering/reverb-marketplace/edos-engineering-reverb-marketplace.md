# edos-engineering/reverb-marketplace

> 标签: api client, ecommerce, laravel, marketplace, music gear, reverb, reverb.com

## 简介

PHP and Laravel client for the Reverb.com marketplace API: listings, orders, shipping, offers, refunds, payouts and webhooks. Not related to Laravel Reverb (WebSockets).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
