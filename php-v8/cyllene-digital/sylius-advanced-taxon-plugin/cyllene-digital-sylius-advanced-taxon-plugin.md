# cyllene-digital/sylius-advanced-taxon-plugin

> 标签: facets, filters, mega-menu, merchandising, sylius, sylius-plugin, taxon, taxonomy

## 简介

Turns Sylius taxons into merchandising pages: branding, featured content, media zones, universe pages, advanced filters, conditional taxons and a mega menu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
