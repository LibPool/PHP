# cyllene-digital/sylius-translation-flags-plugin

> 标签: admin, flag, i18n, sylius, sylius-plugin, translation

## 简介

Sylius admin plugin that improves the translations accordions and the locales list: a flag before each locale and a capitalized locale name.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
