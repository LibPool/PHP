# idoo/idoodev-sdk

> 标签: api, gateway, hmac, idoo, idoodev, marketplace

## 简介

SDK oficial de idoo.dev para creadores de APIs: verificación de la firma HMAC del gateway y contexto del consumidor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
