# flagbit/metrics-bundle

> 标签: Metrics, logging

## 简介

FlagbitMetricsBundle provides easy integration of metrics collector services for the Symfony Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
