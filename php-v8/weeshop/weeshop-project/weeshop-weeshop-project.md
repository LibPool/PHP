# weeshop/weeshop-project

> 标签: PHP

## 简介

Project template for WeeShop with Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.weeshop.org
- 源码仓库：https://github.com/weeshop/weeshop_project.git
- Packagist 页面：https://packagist.org/packages/weeshop%2Fweeshop-project
