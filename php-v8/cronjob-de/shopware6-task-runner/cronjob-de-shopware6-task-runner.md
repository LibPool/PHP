# cronjob-de/shopware6-task-runner

> 标签: PHP

## 简介

Runs Shopware 6 scheduled tasks and the message queue on every call of a secret address, so an external cron service such as Cronjob.de can replace the admin worker and the server crontab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
