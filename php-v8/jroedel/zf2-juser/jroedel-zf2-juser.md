# jroedel/zf2-juser

> 标签: Authentication, Passwordless, laminas, magic-link

## 简介

Passwordless (magic-link) user module. A Laminas MVC module in 2.x; Symfony-oriented in 3.x.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
