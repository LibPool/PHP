# mattketmo/uuid-2x-bridge

> 标签: PHP

## 简介

Allow to use ramsey/uuid:3.x even if one of your dependencies requires version 2.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
