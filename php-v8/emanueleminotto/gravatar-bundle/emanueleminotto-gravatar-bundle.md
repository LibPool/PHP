# emanueleminotto/gravatar-bundle

> 标签: bundle, gravatar, symfony, twig

## 简介

Symfony 2 Bundle for the Gravatar library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
