# k3progetti/jwt-auth

> 标签: auth, jwt, symfony-auth

## 简介

Symfony jwt auth bundle. Comes with refresh token enabled by default

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
