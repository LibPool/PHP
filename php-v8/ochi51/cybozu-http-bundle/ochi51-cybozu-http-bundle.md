# ochi51/cybozu-http-bundle

> 标签: PHP

## 简介

Symfony2 HTTP client bundle for cybozu.com API (kintone API and User API)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
