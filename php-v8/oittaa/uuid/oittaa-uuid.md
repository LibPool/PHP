# oittaa/uuid

> 标签: guid, identifier, uuid

## 简介

A small PHP class for generating RFC 9562 universally unique identifiers (UUID) from version 3 to version 8.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
