# awsm3/mandrill-zend3

> 标签: Zend Framework, Zend Framework 3, mandrill, zf3

## 简介

A PHP client library for Mandrill's REST API for Zend Framework 3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
