# 1994/promo-bar-statamic

> 标签: announcement bar, banner, cargo, countdown, promo bar, statamic, statamic-addon

## 简介

Promo bars for Statamic: scheduled, targeted announcement bars with call-to-action buttons, countdowns, discount codes and Cargo free-delivery progress, styled in the Control Panel and safe behind static caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
