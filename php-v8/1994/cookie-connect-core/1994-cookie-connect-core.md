# 1994/cookie-connect-core

> 标签: cmp, consent mode, cookie consent, cookiebot, gdpr, onetrust, usercentrics

## 简介

The framework-free core shared by Cookie Connect for Craft CMS and Statamic: every cookie consent platform described as data, the head and blocking markup they need, Google Consent Mode v2, and one JavaScript consent API for all of them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
