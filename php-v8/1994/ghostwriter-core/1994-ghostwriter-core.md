# 1994/ghostwriter-core

> 标签: ai, content, ghostwriter, writing

## 简介

The framework-free core shared by the Ghostwriter addons for Statamic, Filament and Craft: draft text handling, prompts, the AI provider layer, the Studio (every model job), the schema model and layout algorithms, the domain model with its rules and store contracts, and photo search and image placeholders.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
