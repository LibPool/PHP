# cnam/jwt-api-extension

> 标签: api, jwt, test

## 简介

Behat extension for testing api secure with jwt token base in Behat WebApiExtension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
