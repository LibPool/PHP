# apeli/apelimailers

> 标签: analytics, email, mail, mailer, php, queue, smtp, tracking

## 简介

A lightweight, dependency-free PHP email library with SMTP, templating, queues, and analytics

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
