# rpnfernandes/rff-qrcode

> 标签: PSR-4, generator, pure-php, qr, qr-code, qrcode, svg, vector, zero-dependency

## 简介

Zero-dependency pure PHP QR Code generator (ISO/IEC 18004 compliant, Versions 1-40) with SVG and Data URI rendering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
