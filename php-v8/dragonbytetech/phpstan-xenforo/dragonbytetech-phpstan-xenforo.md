# dragonbytetech/phpstan-xenforo

> 标签: PHPStan, static analysis, xenforo

## 简介

PHPStan extension for analysing XenForo 2.3 add-ons without false positives from class extensions, entity structures and options

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
