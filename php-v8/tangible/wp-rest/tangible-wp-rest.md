# tangible/wp-rest

> 标签: PHP

## 简介

Shared WordPress REST API scaffolding for Tangible DDD plugins (endpoint base, exception mapping, UserContext, capability gate).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
