# tangible/wp-appearance

> 标签: PHP

## 简介

How Tangible looks on a WordPress site: the shared tangible-ui stylesheet handle, arbitrated across every Tangible plugin, and the site-wide front-end TUI theme.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
