# pdfzus/pdf-zusammenfuegen-cli

> 标签: cli, document, pdf, pdf merge, pdf zusammenfuegen

## 简介

PHP library and CLI to merge PDF files in order for practical workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
