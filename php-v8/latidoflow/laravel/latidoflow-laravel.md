# latidoflow/laravel

> 标签: heartbeat, laravel, monitoring, queue, scheduler

## 简介

Heartbeat monitoring for Laravel scheduler and queue workloads with LatidoFlow.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
