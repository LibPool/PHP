# fireup/fireup

> 标签: PHP

## 简介

A modern, lightweight PHP framework designed for simplicity and ease of use. Now with advanced CLI generators and rich OpenAPI docs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
