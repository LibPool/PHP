# hnher/scaffold

> 标签: Uni-app, laravel, react-native, scaffold, starter-kit

## 简介

A full-stack Laravel scaffold for web, mini program, and native app development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
