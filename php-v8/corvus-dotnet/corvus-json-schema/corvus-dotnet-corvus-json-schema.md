# corvus-dotnet/corvus-json-schema

> 标签: extension, json, json-schema, validation, validator

## 简介

A high-performance JSON Schema evaluator (draft 4, 6, 7, 2019-09 and 2020-12) as a PHP extension, backed by Rust.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
