# time-to-dev/statamic-code-transmitter

> 标签: fieldtype, html, statamic, transmitter, сode

## 简介

A Statamic fieldtype that allows to pass HTML code to the frontend (inline).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
