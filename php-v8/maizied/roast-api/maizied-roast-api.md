# maizied/roast-api

> 标签: api, cdn, developer, fun, humor, roast

## 简介

A PHP client for RaaS — Roast as a Service. CDN-served static JSON API for developer roasts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
