# ipdatainfo/sdk

> 标签: geoip, ip-api, ip-geolocation, ip-lookup, ipdata, threat-intelligence

## 简介

Official PHP client for the ipdata.info IP geolocation, ASN, and threat-intelligence API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://ipdata.info
- 源码仓库：https://github.com/IPDataInfo/ipdata-php.git
- Packagist 页面：https://packagist.org/packages/ipdatainfo%2Fsdk
