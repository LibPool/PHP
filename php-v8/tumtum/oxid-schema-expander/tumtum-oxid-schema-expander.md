# tumtum/oxid-schema-expander

> 标签: PHP

## 简介

Library to modify the OXID eShop database. Ideal for OXID modules to have their tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
