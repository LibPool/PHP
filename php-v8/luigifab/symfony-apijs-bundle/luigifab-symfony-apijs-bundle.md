# luigifab/symfony-apijs-bundle

> 标签: symfony, symfony-bundle

## 简介

JavaScript pop-ups and slideshow for Symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
