# serch3/bunny-stream

> 标签: Bunny.net, bunnyCDN, cdn, streaming, video

## 简介

A Lightweight PHP SDK for Bunny.net Streaming API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://bunny.net/stream/
- 源码仓库：https://github.com/serch3/bunny-stream-sdk-php.git
- Packagist 页面：https://packagist.org/packages/serch3%2Fbunny-stream
