# inertify/table

> 标签: filtering, headless, inertia, laravel, pagination, sorting, table, vue

## 简介

Headless tables for Laravel + Vue + Inertia with pagination, sorting, and filtering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
