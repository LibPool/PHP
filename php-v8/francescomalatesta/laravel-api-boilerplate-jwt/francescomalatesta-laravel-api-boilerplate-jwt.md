# francescomalatesta/laravel-api-boilerplate-jwt

> 标签: api, auth, boilerplate, jwt, laravel, rest

## 简介

An API Boilerplate to create a ready-to-use REST API in seconds.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
