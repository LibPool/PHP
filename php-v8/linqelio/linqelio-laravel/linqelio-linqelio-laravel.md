# linqelio/linqelio-laravel

> 标签: laravel, linqelio, messaging, omnichannel, telegram, viber, whatsapp

## 简介

Laravel integration for Linqelio — one API for WhatsApp, Telegram and Viber conversations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
