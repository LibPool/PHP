# seantrane/profiler

> 标签: anbu, debug bar, juy, laravel, profiler

## 简介

A profiler for Laravel 4. A continuation of the retired juy/profiler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
