# felixkerser/laravel-shopify-filestorage

> 标签: cdn, files, graphql, laravel, shopify, upload

## 简介

Fluent Laravel SDK for Shopify's staged file upload pipeline and CDN image transforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
