# graviton/php-rql-parser

> 标签: language, mongo, mongodb, parser, query, resource, rest, rql

## 简介

doctrine-odm query building wrapper to graviton/rql-parser

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
