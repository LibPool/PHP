# agentic-actions/laravel

> 标签: actions, agents, ai, laravel, mcp, precognition, tools, typescript

## 简介

One Action class for every surface of a Laravel app: web and JSON routes, the CLI, queued jobs, laravel/ai agents, MCP clients and typed TypeScript.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
