# nrep/form-forge

> 标签: alpine, bootstrap, builder, form, php, schema, tailwind

## 简介

Schema-driven form builder for PHP - Framework agnostic with Tailwind, Bootstrap, and Alpine.js support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
