# brnbio/laravel-starterkit-modules

> 标签: PHP

## 简介

A modern Laravel starter kit with InertiaJS, Vue 3, Tailwind CSS, and Laravel Sail pre-configured for rapid application development

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
