# enjin/platform-fuel-tanks

> 标签: enjin, enjin platform, enjin platform package, laravel, platform

## 简介

A package for integrating Fuel Tanks into the Enjin Platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
