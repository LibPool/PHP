# collecthor/spss

> 标签: cli, cli-app, dataset, ibm, por, pspp, reader, sav, spss, statistics, writer

## 简介

SPSS is a php-based implementation of IBM SPSS Statistics Standard

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
