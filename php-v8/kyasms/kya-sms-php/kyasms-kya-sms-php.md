# kyasms/kya-sms-php

> 标签: api, bulk-sms, campaign, kya, messaging, otp, sdk, sms

## 简介

Official PHP SDK for KYA SMS API - Send SMS, OTP, and manage campaigns

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
