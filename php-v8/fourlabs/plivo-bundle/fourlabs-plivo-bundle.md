# fourlabs/plivo-bundle

> 标签: Plivo Bundle, php, sms, symfony, text messaging

## 简介

Plivo Bundle for Symfony - Send and receive text messages

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
