# fhulufhelo/rapaport-parser

> 标签: diamond, parser, pdf, price-list, rapaport

## 简介

Extracts the colour x clarity price grids from Rapaport Diamond Report PDFs into structured data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
