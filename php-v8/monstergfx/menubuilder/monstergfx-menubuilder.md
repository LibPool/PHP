# monstergfx/menubuilder

> 标签: bootstrap, laravel4, menu

## 简介

A Menu Builder and renderer for Laravel4, Sentry2, and Twitter Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
