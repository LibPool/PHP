# steevanb/phpstan-rules

> 标签: PHPStan, phpstan-rules, static-analysis

## 简介

PHPStan rules: unnecessary named arguments, one mirrored coverage target per test, no class constants in tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
