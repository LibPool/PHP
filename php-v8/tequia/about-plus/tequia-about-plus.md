# tequia/about-plus

> 标签: Devtools, about, artisan, console, dashboard, laravel

## 简介

A richer, prettier replacement for `php artisan about` — a full project dashboard in your terminal.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
