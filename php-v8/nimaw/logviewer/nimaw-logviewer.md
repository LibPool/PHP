# nimaw/logviewer

> 标签: Laravel logs, Laravel logs viewer, Log viewer laravel

## 简介

Laravel & Lumen package for viewing laravel logs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
