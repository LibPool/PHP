# lodev09/php-models

> 标签: class, models, models-php, mysql, mysql-pdo, pdo, pdo-models, php

## 简介

A PHP library that allows you to easily create and define your models using PDO.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
