# lodev09/php-ssh2

> 标签: class, methods, php, scp, sftp, ssh2

## 简介

Wrapper class for PHP's SSH2 extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
