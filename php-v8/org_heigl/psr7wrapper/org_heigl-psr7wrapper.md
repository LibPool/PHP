# org_heigl/psr7wrapper

> 标签: PHP

## 简介

Wrap Request/Response-Objects from different frameworks into a PSR7-compliant envelope

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
