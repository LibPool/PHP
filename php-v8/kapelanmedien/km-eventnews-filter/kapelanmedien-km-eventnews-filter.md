# kapelanmedien/km-eventnews-filter

> 标签: extension, filter, news, typo3

## 简介

Filter event news by organizer, location, date, categories and tags

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
