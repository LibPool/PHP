# yetanotherape/diff-match-patch

> 标签: Fuzzy search, Match, diff, patch

## 简介

Port of the google-diff-match-patch (https://github.com/google/diff-match-patch) lib to PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
