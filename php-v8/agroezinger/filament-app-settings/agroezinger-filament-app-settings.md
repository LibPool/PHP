# agroezinger/filament-app-settings

> 标签: agroezinger, app-settings, filament, laravel

## 简介

Flexible polymorphic settings for Laravel with Multi-Tenancy and fallback support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
