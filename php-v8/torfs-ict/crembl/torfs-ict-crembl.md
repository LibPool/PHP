# torfs-ict/crembl

> 标签: api, bpost, crembl, json, mail, rest, wrapper

## 简介

Crembl API wrapper, allows you send regular (or registered) mail through the Crembl web service.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
