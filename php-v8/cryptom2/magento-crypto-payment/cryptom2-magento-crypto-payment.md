# cryptom2/magento-crypto-payment

> 标签: PHP

## 简介

Extension allows to receive crypto payments in USDT/USDC and native crypto currencies with Metamask wallet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
