# eleving/zend-json

> 标签: ZendFramework, json, zf

## 简介

provides convenience methods for serializing native PHP to JSON and decoding JSON to native PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
