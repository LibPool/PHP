# martkuper/onepagecrm-php

> 标签: api, crm, onepage, onepagecrm

## 简介

A PHP wrapper for the OnePageCRM API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
