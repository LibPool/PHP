# globus-studio/async

> 标签: async, await, concurrency, event-loop, fiber, promise, revolt

## 简介

Promise-style asynchronous programming for PHP, built on Revolt fibers and the event loop.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
