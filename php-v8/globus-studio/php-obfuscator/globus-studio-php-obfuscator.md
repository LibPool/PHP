# globus-studio/php-obfuscator

> 标签: minify, obfuscate, obfuscator, php, protection, source-code, tokenizer

## 简介

A token-based PHP source code obfuscator with full support for PHP 8.3 through 8.5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
