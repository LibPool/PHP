# globus-studio/atom

> 标签: PCRE, framework, micro-framework, php, router, template

## 简介

Atom - PHP 8.5 micro-framework. Single PCRE router, template engine, DI, validation, sessions, CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
