# spiritinlife/php-mapreduce

> 标签: big-data, mapreduce, parallel, processing

## 简介

A high-performance, framework-agnostic MapReduce implementation for PHP using Spatie Async

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
