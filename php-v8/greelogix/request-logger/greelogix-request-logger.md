# greelogix/request-logger

> 标签: api-logging, http-logging, laravel, logging, request-logger, request-tracking

## 简介

Request logger with masking and UI for Laravel 10 and 11.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
