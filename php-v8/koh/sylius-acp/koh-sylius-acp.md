# koh/sylius-acp

> 标签: Agent, acp, agentic-commerce, ai, feed, sylius

## 简介

Agentic Commerce Protocol discovery for Sylius: /.well-known/acp.json and a read-only product feed for agents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
