# koh/typo3-indexnow

> 标签: Sitemap, bing, indexnow, search-engine, seo, typo3, typo3-extension

## 简介

IndexNow for TYPO3: tells search engines within minutes which pages were published, changed, scheduled or removed. Per-host keys without configuration, a hard stop for non-production hosts, a retrying queue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
