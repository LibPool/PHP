# koh/sylius-auth-md

> 标签: Agent, auth.md, discovery, oauth, sylius

## 简介

Serves /auth.md — agent registration instructions rendered from the installed authentication methods.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
