# koh/sylius-markdown

> 标签: Agent, ai, content-negotiation, llm, markdown, sylius

## 简介

Accept: text/markdown content negotiation for Sylius, rendering entity data through templates rather than converting rendered HTML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
