# koh/sylius-agent-skills

> 标签: Agent, agent-skills, ai, discovery, sylius

## 简介

Publishes the Agent Skills discovery index at /.well-known/agent-skills/index.json with runtime-computed digests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
