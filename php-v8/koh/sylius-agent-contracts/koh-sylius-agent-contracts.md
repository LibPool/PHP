# koh/sylius-agent-contracts

> 标签: Agent, ai, contracts, discovery, sylius, well-known

## 简介

Shared contracts for the koh Sylius agent-readiness bundles: provider interfaces, DI tags, the channel-aware AgentContext and the single response-header listener.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
