# koh/crowdsec-bridge

> 标签: backend, crowdsec, lapi, security, typo3, typo3-cms-extension

## 简介

TYPO3 14 backend module for the CrowdSec Local API (LAPI): active decisions, alerts, IP quick-check and LAPI heartbeat; adding and deleting decisions with a full sys_log audit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
