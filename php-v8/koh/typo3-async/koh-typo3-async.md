# koh/typo3-async

> 标签: Messenger, async, kubernetes, mail, queue, typo3

## 简介

Asynchronous TYPO3 work over Symfony Messenger: mails leave the request, with retries and a failure queue, switched on per environment.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
