# koh/webmcp

> 标签: PHP

## 简介

WebMCP (Web Model Context Protocol) integration for TYPO3 — exposes structured tools (search, navigation, content) to AI agents via navigator.modelContext.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
