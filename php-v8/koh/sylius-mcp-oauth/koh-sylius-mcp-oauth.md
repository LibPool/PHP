# koh/sylius-mcp-oauth

> 标签: Agent, mcp, oauth2, oauth21, pkce, rfc8414, rfc9728, sylius

## 简介

OAuth 2.1 authorization server for MCP clients on Sylius: dynamic client registration, PKCE, and the RFC 8414 / RFC 9728 discovery metadata.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
