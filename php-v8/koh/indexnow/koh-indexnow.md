# koh/indexnow

> 标签: bing, indexnow, psr-18, search-engine, seo

## 简介

Framework-agnostic IndexNow client: key handling, a host policy that keeps non-production hosts out, spec-conform submissions and a PSR-18 transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
