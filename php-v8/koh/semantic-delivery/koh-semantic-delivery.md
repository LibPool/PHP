# koh/semantic-delivery

> 标签: PHP

## 简介

Multi-channel content delivery and distribution for TYPO3 — Markdown/AI-Agent/Voice channel negotiation, Distribution adapters for LinkedIn, X, Bluesky, Facebook, Instagram, Dev.to, Buffer, Ayrshare, n8n. Consumes Schema.org via koh/structured-content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
