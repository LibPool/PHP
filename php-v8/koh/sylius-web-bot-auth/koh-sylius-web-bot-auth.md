# koh/sylius-web-bot-auth

> 标签: Agent, Ed25519, JWKS, http-message-signatures, sylius, web-bot-auth

## 简介

Web Bot Auth key directory for Sylius: publishes an Ed25519 JWKS at /.well-known/http-message-signatures-directory.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
