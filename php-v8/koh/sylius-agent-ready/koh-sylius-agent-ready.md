# koh/sylius-agent-ready

> 标签: Agent, acp, agentic-commerce, ai, discovery, llms.txt, mcp, mpp, sylius, ucp, x402

## 简介

Metapackage pulling in the full koh agent-readiness surface for Sylius: discovery documents, llms.txt, agent authentication and the agentic commerce protocols.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
