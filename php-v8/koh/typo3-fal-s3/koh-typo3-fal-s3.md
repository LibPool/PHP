# koh/typo3-fal-s3

> 标签: aws, extension, fal, s3, storage, typo3

## 简介

TYPO3 FAL driver for Amazon S3: media without a FUSE mount, one IAM role per tenant via web identity, public URLs unchanged, a persistent metadata cache so S3 is asked once.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
