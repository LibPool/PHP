# yudiz/freelancer

> 标签: PHP

## 简介

Profile Lister extension where customers can create a lister profile in which all users can view the freelancer’s list & their profile details.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
