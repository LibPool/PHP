# nevela/laravel

> 标签: crud, dashboard, generator, laravel, nevela, nextjs, rest-api, scaffold

## 简介

Nevela for Laravel: describe a resource once and generate its model, migration, validation, policy and REST API, plus the Next.js dashboard screens for it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
