# visualbox/sentinel

> 标签: laravel, monitoring, observability, sentinel, telemetry

## 简介

Official Laravel agent for Sentinel. Batched telemetry for the VisualBox observability platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
