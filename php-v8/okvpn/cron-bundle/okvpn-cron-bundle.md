# okvpn/cron-bundle

> 标签: Messenger, cron, cron-bundle, cron-locking, cron-message-queue, cron-messenger, schedule, schedule-bundle, symfony, symfony-cron, symfony-messenger

## 简介

Docker friendly Symfony cron bundle for handle scheduled tasks consistently, parallel or across a cluster, like Symfony Messenger

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
