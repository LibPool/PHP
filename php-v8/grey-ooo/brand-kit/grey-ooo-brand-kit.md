# grey-ooo/brand-kit

> 标签: brand, design-system, grey.ooo, symfony, twig, ux

## 简介

Shared grey.ooo brand kit: a consistent top bar, app switcher and app shell for Grey.ooo Symfony apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
