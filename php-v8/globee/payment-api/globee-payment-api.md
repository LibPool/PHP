# globee/payment-api

> 标签: Monero, api, bitcoin, blockchain, crypto, cryptocurrency, decred, dogecoin, gateway, globee, litecoin, payment, sdk

## 简介

A PHP client to integrate your website with the GloBee payment api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
