# mailsenpai/symfony-mailer

> 标签: email, mailer, mailsenpai, smtp, smtp senpai, symfony, transport

## 简介

Symfony Mailer transport for SMTP Senpai by MailSenpai (EU SMTP relay and email API)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
