# laraneat/modules

> 标签: laraneat, laravel, modular monolith, modules

## 简介

Modular monolith infrastructure for Laravel: modules as Composer path packages, wired by conventions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
