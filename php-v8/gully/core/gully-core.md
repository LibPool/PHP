# gully/core

> 标签: PHP

## 简介

Gully paketi için core istemcileri barındıran paket. Bu paket olmadan Gully adına hiç bir veri çalıştırılamaz.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
