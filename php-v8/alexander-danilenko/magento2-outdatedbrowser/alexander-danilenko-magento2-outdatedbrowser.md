# alexander-danilenko/magento2-outdatedbrowser

> 标签: PHP

## 简介

Magento2 module that prevents site for being viewed in Internet Explorer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
