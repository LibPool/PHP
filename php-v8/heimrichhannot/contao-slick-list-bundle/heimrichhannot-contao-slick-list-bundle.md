# heimrichhannot/contao-slick-list-bundle

> 标签: PHP

## 简介

This bundle acts as a bridge between heimrichhannot/contao-list-bundle and heimrichhannot/contao-slick-bundle in order to offer generic lists using kenwheeler/slick.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
