# heimrichhannot/vex

> 标签: JS, component, contao, dialog, vex

## 简介

Contao component of the modern dialog library vex from hubspot which is highly configurable and easy to style.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
