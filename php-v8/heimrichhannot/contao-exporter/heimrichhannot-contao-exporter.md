# heimrichhannot/contao-exporter

> 标签: backend, contao, csv, developer, export, module, xls

## 简介

A backend module for exporting any contao entity to file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
