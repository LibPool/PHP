# heimrichhannot/contao-geonames

> 标签: contao, geonames, latitude, longitude, postal

## 简介

A contao helper module for developers, where postal code data with additional informations can be imported into contao.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
