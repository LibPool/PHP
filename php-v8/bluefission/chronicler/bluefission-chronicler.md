# bluefission/chronicler

> 标签: PHP

## 简介

DevElation-oriented storage objects, connectors, and query helpers for Kafka, Neo4j, GraphQL, and related data systems.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
