# shrd/laravel-microsoft-graph-mailer

> 标签: azure, laravel, mailer, microsoft-graph

## 简介

Adds a mailer transport that sends emails using the microsoft graph API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
