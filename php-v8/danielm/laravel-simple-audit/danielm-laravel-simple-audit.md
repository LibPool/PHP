# danielm/laravel-simple-audit

> 标签: Audit, activity-log, audit-log, events, laravel

## 简介

Scalable, queueable audit event logging for Laravel apps, with a fluent builder API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
