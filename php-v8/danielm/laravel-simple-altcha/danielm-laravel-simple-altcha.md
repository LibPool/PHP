# danielm/laravel-simple-altcha

> 标签: ALTCHA, captcha, inertia, laravel, proof-of-work, react

## 简介

ALTCHA (proof-of-work captcha) for Laravel: challenge endpoint, validation rule, middleware and Inertia/React stubs. Built on altcha-org/altcha v2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
