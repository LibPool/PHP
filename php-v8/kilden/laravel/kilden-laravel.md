# kilden/laravel

> 标签: CDP, analytics, feature-flags, kilden, laravel

## 简介

Kilden for Laravel — server-side events, queued delivery and the /kilden/identity endpoint.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
