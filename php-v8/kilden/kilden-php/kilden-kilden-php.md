# kilden/kilden-php

> 标签: CDP, analytics, events, feature-flags, kilden

## 简介

Kilden PHP SDK — server-side events, identity signing and feature flags. Zero dependencies, PHP 7.4+.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
