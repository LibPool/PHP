# itaja/itaja-laravel

> 标签: credits, itaja, laravel, licenses, payments, subscriptions, webhooks

## 简介

Itaja for Laravel: declare what you sell in code, push it, receive webhooks as Laravel events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
