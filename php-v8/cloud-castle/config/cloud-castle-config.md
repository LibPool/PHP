# cloud-castle/config

> 标签: PSR-11, cache, cloud-castle, config, configuration, dot-notation, dotenv, env, immutable, ini, json, neon, php, php8, properties, schema, secrets, xml, yaml

## 简介

Неизменяемая конфигурация для PHP 8.1+: точечный доступ и типизированное чтение, загрузка JSON/XML/YAML/NEON/INI/.env/.properties безопасными парсерами, профили окружений, подстановки %ключ% и %env()%, проверка по схеме, компиляция в PHP-кэш и маскирование секретов.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
