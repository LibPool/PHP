# cloud-castle/view

> 标签: Rendering, blade, cloud-castle, components, escaping, php, php8, template, template-engine, templating, twig, view, view-engine

## 简介

Быстрый безопасный движок представлений для PHP 8.1+: нативный PHP и компилируемый DSL, наследование шаблонов, секции, компоненты и слоты, стеки, контекстное автоэкранирование, sandbox, фильтры, функции, директивы, расширения и кэш скомпилированных шаблонов.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
