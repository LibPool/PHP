# cloud-castle/match

> 标签: Arbitrary-precision, Match, bcmath, bigdecimal, chemistry, cloud-castle, decimal, finance, geometry, hypothesis-testing, linear-algebra, math, mathematics, php, php8, physics, probability, regression, science, statistics, trigonometry

## 简介

Точная арифметика произвольной точности и научные вычисления на PHP 8.1+ поверх BCMath: математика, статистика и проверка гипотез, финансы, геометрия, физика и химия.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
