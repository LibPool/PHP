# cloud-castle/faker

> 标签: cloud-castle, data-generator, dummy-data, fake-data, faker, fixtures, i18n, localization, mock-data, php, php8, test-data

## 简介

Мультиязычный генератор фейковых данных для PHP 8.1+: имена, адреса, телефоны, e-mail, компании, тексты, даты, платёжные данные, UUID/ULID на 8 языках (ru/en/de/fr/es/pl/bg/ro) со склонением, плюрализацией и числами прописью из коробки. Сидируемый, детерминированный, без внешних зависимостей сверх экосистемы cloud-castle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
