# cloud-castle/http-response

> 标签: cloud-castle, http-response, php, php8

## 简介

PSR-7/PSR-17 неизменяемый HTTP-ответ и фабрика для PHP 8.1+: код состояния, стандартные фразы, заголовки и потоковое тело.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
