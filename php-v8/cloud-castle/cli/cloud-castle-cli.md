# cloud-castle/cli

> 标签: cli, cloud-castle, php, php8

## 简介

Инструментарий консольного вывода для PHP 8.1+ без зависимостей: ANSI-стили и сообщения, таблицы, рамки, деревья, колонки, прогресс-бары и спиннеры, интерактивные запросы (ввод, скрытый пароль, мультивыбор) с валидацией, генерация автодополнения shell.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
