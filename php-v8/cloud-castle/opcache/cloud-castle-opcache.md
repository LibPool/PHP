# cloud-castle/opcache

> 标签: Opcache, bytecode-cache, cache-warmup, cloud-castle, health-check, php, php8, preload, zend-opcache

## 简介

Объектная обёртка над Zend OPcache для PHP 8.1+: типобезопасный статус и конфигурация, сброс, инвалидация, массовый прогрев каталогов, генерация preload-скрипта, проверка здоровья с рекомендациями и ограничение операций каталогами — при нуле runtime-зависимостей.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
