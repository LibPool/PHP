# cloud-castle/metrics

> 标签: Metrics, cloud-castle, php, php8

## 简介

Метрики приложения для PHP 8.1+: счётчики, измерители (gauge) и гистограммы с метками в in-memory реестре, снятие и экспорт агрегатов. Нулевые внешние зависимости.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
