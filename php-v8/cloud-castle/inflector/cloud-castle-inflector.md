# cloud-castle/inflector

> 标签: cloud-castle, inflector, php, php8

## 简介

Многоязычный инфлектор для PHP 8.1+: множественное/единственное число, преобразования регистра, порядковые числительные, slugify с транслитерацией, склонение по падежам и грамматика нескольких языков. Единственная зависимость — словарь cloud-castle/dictionary.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
