# cloud-castle/parser-neon

> 标签: cloud-castle, config, neon, parser, parser-neon, php, php8, security

## 简介

Безопасный разбор и сериализация NEON для PHP 8.1+ без зависимостей: block + inline, только данные (нет entity/объектов), fail-loud, двунаправленность.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
