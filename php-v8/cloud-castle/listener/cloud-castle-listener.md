# cloud-castle/listener

> 标签: cloud-castle, listener, php, php8

## 简介

PSR-14 провайдер слушателей для PHP 8.1+: регистрация обработчиков атрибутом #[AsListener], автообнаружение через рефлексию и приоритеты. Дополняет любой PSR-14 диспетчер (напр. cloud-castle/event).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
