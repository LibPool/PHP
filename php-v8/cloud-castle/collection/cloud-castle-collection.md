# cloud-castle/collection

> 标签: cloud-castle, collection, php, php8

## 简介

Коллекции для PHP 8.1+: цепочечный fluent-API над массивами, ленивые коллекции (генераторы, экономия памяти), higher-order messages, макросы, dot-доступ и сериализация в JSON/массив. Суперсет API illuminate/collections.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
