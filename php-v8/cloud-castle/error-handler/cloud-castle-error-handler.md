# cloud-castle/error-handler

> 标签: cloud-castle, error-handler, php, php8

## 简介

Обработчик ошибок и исключений для PHP 8.1+: единый перехват ошибок, исключений и фатальных сбоев, рендеринг под окружение (CLI / HTML / JSON) и логирование через PSR-3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
