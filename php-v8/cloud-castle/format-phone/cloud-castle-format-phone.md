# cloud-castle/format-phone

> 标签: E164, cloud-castle, fintech, format-phone, libphonenumber, phone, phone-number, phone-type, phone-validation, php, php8, validation

## 简介

Телефонные номера для PHP 8.1+: нормализация в E.164, маскирование для логов, определение страны/типа/региона и валидация по правилам страны. Быстрее и легче libphonenumber, неизменяем, без runtime-зависимостей.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
