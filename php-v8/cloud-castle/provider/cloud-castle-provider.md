# cloud-castle/provider

> 标签: cloud-castle, php, php8, provider

## 简介

Сервис-провайдеры для PHP 8.1+ поверх cloud-castle/di: модульная регистрация сервисов, отложенные (deferred) провайдеры и загрузочное ядро (bootstrap) приложения.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
