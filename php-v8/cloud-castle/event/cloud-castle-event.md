# cloud-castle/event

> 标签: attributes, cloud-castle, event, event-dispatcher, listener, php, php8, priority, psr-14, subscriber, wildcard

## 简介

Самый функциональный и быстрый PSR-14 диспетчер событий для PHP 8.1+: приоритеты, порядок before/after с топосортировкой, иерархия типов, именованные и wildcard-события, атрибуты, ленивые сервисы, отладочный и буферизующий диспетчеры, компиляция провайдера. Зависимости — только PSR.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
