# cloud-castle/lock

> 标签: blocking-lock, cloud-castle, critical-section, flock, lock, locking, mutex, php, php8, psr-16, semaphore, synchronization

## 简介

Блокировки ресурсов для PHP 8.1+: межпроцессные (flock), распределённые (PSR-16) и внутрипроцессные — токен владельца, блокирующее ожидание, счётный семафор, TTL на инъектируемых часах (PSR-20), интроспекция TTL и synchronized(). Минимум зависимостей.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
