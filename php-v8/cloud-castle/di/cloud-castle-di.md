# cloud-castle/di

> 标签: cloud-castle, di, php, php8

## 简介

PSR-11 контейнер внедрения зависимостей для PHP 8.1+: автовайринг, атрибуты (#[AsService], #[Autowire], #[Inject], декораторы, алиасы), компиляция контейнера в PHP-код, контекстные привязки, теги, области видимости, ленивые сервисы и профилирование.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
