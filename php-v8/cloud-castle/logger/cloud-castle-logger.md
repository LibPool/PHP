# cloud-castle/logger

> 标签: cloud-castle, log, logger, logging, php, php8, pii-masking, psr-3

## 简介

Быстрый PSR-3 логгер для PHP 8.1+ с маскированием персональных данных из коробки, хендлерами, форматтерами и процессорами. Нулевые внешние зависимости.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
