# cloud-castle/idempotency

> 标签: cloud-castle, idempotency, php, php8

## 简介

Идемпотентное выполнение операций для PHP 8.1+: результат по ключу идемпотентности сохраняется в PSR-16 кэше, защищая от повторов и конфликтов при ретраях. Для платежей и API. Поверх psr/simple-cache.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
