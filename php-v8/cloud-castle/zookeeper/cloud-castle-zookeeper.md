# cloud-castle/zookeeper

> 标签: apache-zookeeper, cloud-castle, coordination, curator, distributed-lock, distributed-systems, jute, leader-election, php, php8, service-discovery, watch, zookeeper

## 简介

Чистый PHP-клиент Apache ZooKeeper без ext-zookeeper: полный клиентский протокол (3.5-3.9) и рецепты координации.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
