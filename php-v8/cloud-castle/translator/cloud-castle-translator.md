# cloud-castle/translator

> 标签: cloud-castle, php, php8, translator

## 简介

Переводчик сообщений для PHP 8.1+: домены, параметры-плейсхолдеры, множественное число по правилам плюрализации (cloud-castle/inflector), запасная локаль и загрузка каталогов из JSON/YAML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
