# cloud-castle/support

> 标签: cloud-castle, php, php8, support

## 简介

Набор утилит для PHP 8.1+: строки (Str), массивы (Arr) с dot-нотацией, числа (Num), даты (Dates), объекты (Obj) и глобальные хелперы. Маскирование ПД из коробки, минимум зависимостей (только PSR и инфраструктура cloud-castle).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
