# bergwerk/bwrk-onepage

> 标签: extension, onepage, typo3

## 简介

TYPO3 Onepage-Extension which allows you to use subpages as onepage layout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
