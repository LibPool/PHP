# martinlindhe/php-mb-helpers

> 标签: PHP

## 简介

Provides mb_ucwords(), mb_ucfirst(), mb_strrev(), mb_str_pad(), mb_count_chars(), mb_str_split()

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
