# jaxon-php/jaxon-flot

> 标签: Jaxon, ajax, chart, flot, graph, javascript, php, plot, xajax

## 简介

Javascript charts for Jaxon with the Flot library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
