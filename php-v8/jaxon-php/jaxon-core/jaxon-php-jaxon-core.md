# jaxon-php/jaxon-core

> 标签: Jaxon, ajax, asynchronous, php, xajax

## 简介

Jaxon is an open source PHP library for easily creating Ajax web applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
