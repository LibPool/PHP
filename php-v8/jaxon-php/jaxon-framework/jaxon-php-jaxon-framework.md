# jaxon-php/jaxon-framework

> 标签: Jaxon, ajax, framework, php, xajax

## 简介

Common classes  for the integration of the Jaxon library into PHP frameworks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
