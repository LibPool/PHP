# jaxon-php/jaxon-js

> 标签: Jaxon, ajax, asynchronous, php, xajax

## 简介

Javascript code for the Jaxon PHP library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
