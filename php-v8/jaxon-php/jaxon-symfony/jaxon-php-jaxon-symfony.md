# jaxon-php/jaxon-symfony

> 标签: Jaxon, ajax, php, symfony

## 简介

Jaxon library integration for the Symfony Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
