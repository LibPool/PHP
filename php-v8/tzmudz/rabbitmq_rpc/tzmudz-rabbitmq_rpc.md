# tzmudz/rabbitmq_rpc

> 标签: broker, message, queue, rabbitmq, rpc

## 简介

Very simple RabbitMQ RPC message handler. Based on RPC example.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
