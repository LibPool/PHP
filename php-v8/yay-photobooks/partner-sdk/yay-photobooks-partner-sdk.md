# yay-photobooks/partner-sdk

> 标签: api, partner, photobook, sdk, yay

## 简介

PHP SDK for YAY Photobook Partner API - Create beautiful photobooks programmatically

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
