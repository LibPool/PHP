# chez14/lib

> 标签: Skeleton, boilerplate, library, php, template

## 简介

Framework-agnostic PHP library template with PHPUnit, PHP-CS-Fixer, phpcs and GitLab CI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
