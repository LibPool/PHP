# scottchiefbaker/yaml-polyfill

> 标签: php-yaml, polyfill, yaml, yaml_emit, yaml_parse

## 简介

Pure-PHP polyfill for the PECL php-yaml extension: yaml_emit(), yaml_parse(), and friends (PHP 8.2+, zero dependencies)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
