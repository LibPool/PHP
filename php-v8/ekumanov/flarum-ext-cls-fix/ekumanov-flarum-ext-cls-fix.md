# ekumanov/flarum-ext-cls-fix

> 标签: cls, extension, flarum, images, performance

## 简介

Reserves layout space for inline images in posts to eliminate Cumulative Layout Shift (CLS).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
