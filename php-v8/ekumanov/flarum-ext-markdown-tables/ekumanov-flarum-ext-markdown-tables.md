# ekumanov/flarum-ext-markdown-tables

> 标签: extension, flarum, markdown, tables, tiptap

## 简介

Markdown tables for Flarum 2.0, with Tiptap rich-text editor integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
