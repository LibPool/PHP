# cruddy/ace

> 标签: ace, cruddy, markdown

## 简介

An ACE editor for Cruddy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/cruddy/ace.git
- Packagist 页面：https://packagist.org/packages/cruddy%2Face

- Composer 安装：`composer require cruddy/ace`
- Packagist 仓库：https://repo.packagist.org/p2/cruddy/ace.json
