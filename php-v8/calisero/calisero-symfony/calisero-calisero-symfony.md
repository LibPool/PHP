# calisero/calisero-symfony

> 标签: 2fa, calisero, notifier, otp, sms, symfony, symfony-bundle, webhook

## 简介

Symfony bundle for sending SMS through the Calisero API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
