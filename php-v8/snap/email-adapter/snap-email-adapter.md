# snap/email-adapter

> 标签: PHP

## 简介

An easy to use package of adapters to create a unified interface for multiple email libraries including PHPMailer and SwiftMailer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
