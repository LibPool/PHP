# jasonbaciulis/bedrock-commands

> 标签: bedrock, scaffold, statamic

## 简介

Artisan commands that scaffold, rename and delete page builder blocks and article sets in the Bedrock starter kit

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
