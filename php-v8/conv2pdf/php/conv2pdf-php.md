# conv2pdf/php

> 标签: api, conv2pdf, conversion, convert, docx, gdpr, merge, pdf, rgpd, sdk

## 简介

Official PHP SDK for the conv2pdf API: PDF conversion and manipulation, hosted in France, GDPR-compliant, DPA provided.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
