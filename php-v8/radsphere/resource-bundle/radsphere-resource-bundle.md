# radsphere/resource-bundle

> 标签: Symfony2, rest

## 简介

This Bundle provides sample managed api restful resource to be used with RadsRestBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
