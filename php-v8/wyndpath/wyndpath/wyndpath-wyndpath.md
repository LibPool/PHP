# wyndpath/wyndpath

> 标签: anti-bot, cardmarket, cloudflare, crawler, datadome, proxy-api, scraping-api, vinted, web-scraping 

## 简介

Official PHP client for WyndPath — Europe-hosted web scraping & anti-bot API (bypasses Cloudflare & DataDome, returns JSON, pay-per-success).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
