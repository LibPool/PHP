# pixelopen/kirby-googlemybusiness

> 标签: kirby, kirby-cms, kirby-plugin

## 简介

A plugin for Kirby CMS to handle Google My Business Website Profile

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
