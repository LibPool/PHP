# pixelopen/sulu-plausiblebundle

> 标签: PHP

## 简介

This bundle allows you to integrate Plausible analytics statistics into the Sulu administration interface via an embedded iframe.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
