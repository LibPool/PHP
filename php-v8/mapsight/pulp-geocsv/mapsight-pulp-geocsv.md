# mapsight/pulp-geocsv

> 标签: conversion, csv, geo, geojson, mapsight, pulp

## 简介

Utility to convert CSV files with geographic data to GeoJSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
