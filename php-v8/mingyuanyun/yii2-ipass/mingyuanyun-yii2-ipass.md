# mingyuanyun/yii2-ipass

> 标签: SSO, auth, pass, passport, token

## 简介

云链统一通行证 SDK，提供通行证身份令牌的校验、刷新及身份信息获取等通行证用户的基础服务功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
