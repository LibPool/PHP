# mingyuanyun/yii2-ilogin

> 标签: login, yii2

## 简介

统一登录组件，可扩展不同的登录方式，目前支持ldap登录、企业微信静默授权登录、企业微信扫码登录、普通账号密码登录，提供自定义登录退出事件处理类，登录成功后可获取用户上下文信息。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
