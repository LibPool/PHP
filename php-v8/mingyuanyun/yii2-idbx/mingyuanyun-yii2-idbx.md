# mingyuanyun/yii2-idbx

> 标签: DM, db, db extension, driver, translate, validate, yii2

## 简介

该组件扩展支持yii框架不支持的数据库驱动，目前只增加了DM数据库的支持，并对部分函数、关键字做了mysql格式的语法翻译。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
