# mingyuanyun/ggcp-http

> 标签: api, http, mingyuanyun, tcp, trace

## 简介

基于 GuzzleHttp 封装的 HTTP 请求服务，可通过服务配置开启调链追踪分析、监控预警

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
