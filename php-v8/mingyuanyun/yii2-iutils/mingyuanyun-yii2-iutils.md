# mingyuanyun/yii2-iutils

> 标签: utils, yii2

## 简介

框架基础软件包，包括错误管理，缓存管理，统一调用关系。底层统一错误捕获，数据统一返回格式，基类封装常用方法和请求校验，工具类提供快速校验、数组、字符串等操作，提高开发效率。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
