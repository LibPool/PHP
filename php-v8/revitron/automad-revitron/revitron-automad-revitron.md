# revitron/automad-revitron

> 标签: blog, documentation, theme

## 简介

An elegant documentation theme for Automad based on the Revitron Sphinx theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
