# mikepultz/php-quic

> 标签: dns-over-quic, doq, extension, http3, openssl, quic

## 简介

Raw QUIC transport for PHP (client + server, streams, DoQ), built on OpenSSL 3.5+ native QUIC.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
