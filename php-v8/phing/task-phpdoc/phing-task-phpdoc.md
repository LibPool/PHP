# phing/task-phpdoc

> 标签: PHP

## 简介

This task runs phpDocumentor 2, a API documentation tool. This project is the result of the merge of the phpDocumentor and DocBlox projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
