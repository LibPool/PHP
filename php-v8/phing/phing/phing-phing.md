# phing/phing

> 标签: ant, build, build-automation, build-tool, dev, make, phing, php, task, tool

## 简介

PHing Is Not GNU make; it's a PHP project build system or build tool based on Apache Ant.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
