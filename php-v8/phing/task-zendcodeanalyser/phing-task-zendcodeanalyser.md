# phing/task-zendcodeanalyser

> 标签: PHP

## 简介

The ZendCodeAnalyzerTask analyze PHP source files using the Zend Code Analyzer tool that ships with all versions of Zend Studio.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
