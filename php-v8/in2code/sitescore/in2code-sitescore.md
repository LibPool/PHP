# in2code/sitescore

> 标签: Gemini, ai, geo, seo, typo3

## 简介

AI-driven content quality dashboard providing SEO, GEO and accessibility scores directly in the TYPO3 page module

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
