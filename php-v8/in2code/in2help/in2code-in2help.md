# in2code/in2help

> 标签: helpmodule, iframe, onlinehelp

## 简介

Provides a help module, to display a page in the backend. This can be used for editors documentation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
