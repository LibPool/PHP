# in2code/powermail

> 标签: form, mailform, spamprevention, typo3

## 简介

Powermail is a well-known, editor-friendly, powerful and easy to use mailform extension for TYPO3 with a lots of features

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
