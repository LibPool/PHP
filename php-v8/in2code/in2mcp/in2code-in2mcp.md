# in2code/in2mcp

> 标签: Gemini, ai, claude, mcp, typo3

## 简介

Model Context Protocol (MCP) server for TYPO3 - connect Claude, Gemini and other MCP clients to your TYPO3 installation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
