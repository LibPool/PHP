# findyouractivity/laravel-userstamps

> 标签: created, deleted, laravel, updated, userstamps

## 简介

Package to add created_by, updated_by and deleted_by to models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
