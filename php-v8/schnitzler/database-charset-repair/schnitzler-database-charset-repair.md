# schnitzler/database-charset-repair

> 标签: PHP

## 简介

A TYPO3 CLI command that repairs fake latin1, genuine cp1252 and double-encoded content column by column and moves the schema to utf8mb4

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
