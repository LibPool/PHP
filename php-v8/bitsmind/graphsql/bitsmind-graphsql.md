# bitsmind/graphsql

> 标签: bitsmind, graphsql, laravel

## 简介

GraphSql is a Graphql like syntactical method to read data from SQL databases with an ease. It's built on top of Laravel Eloquent ORM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
