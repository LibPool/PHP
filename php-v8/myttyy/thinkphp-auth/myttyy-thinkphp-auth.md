# myttyy/thinkphp-auth

> 标签: auth, thinkphp, user

## 简介

适用于thinkPHP框架的权限认证库,mAuthentication Library for ThinkPHP Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
