# chebur/twig-php-functions-bundle

> 标签: Symfony2, bundle, functions, php, symfony, symfony3, symfony4, twig

## 简介

Symfony bundle to execute native php functions in twig templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
