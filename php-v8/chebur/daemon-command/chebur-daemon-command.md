# chebur/daemon-command

> 标签: command, cron, daemon, endless, loop, schedule, symfony

## 简介

Daemon (endless) symfony command which supports scheduled (cron like) code execution

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
