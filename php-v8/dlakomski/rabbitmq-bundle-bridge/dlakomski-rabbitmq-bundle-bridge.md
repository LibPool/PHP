# dlakomski/rabbitmq-bundle-bridge

> 标签: command bus, event bus, message bus, messages, rabbitmq

## 简介

Use OldSoundRabbitMQBundle with SimpleBus/AsynchronousBundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
