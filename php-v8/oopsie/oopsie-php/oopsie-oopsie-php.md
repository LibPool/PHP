# oopsie/oopsie-php

> 标签: errors, monitoring, observability, oopsie, php

## 简介

Oopsie PHP SDK for backend error capture, messages and release tracking.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
