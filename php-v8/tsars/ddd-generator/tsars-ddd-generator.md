# tsars/ddd-generator

> 标签: PHP

## 简介

CLI tool to generate DDD structure: bounded contexts, aggregates, entities, VOs, events, commands, queries and tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
