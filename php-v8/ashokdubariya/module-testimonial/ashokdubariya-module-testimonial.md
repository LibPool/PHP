# ashokdubariya/module-testimonial

> 标签: customer-reviews, graphql, hyva-theme, magento2, magento2-module, ratings, testimonial, testimonials

## 简介

Magento 2 Testimonial Module with GraphQL API support and Hyva Theme compatibility for managing customer testimonials with complete CRUD operations, admin panel, and frontend display.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
