# fluffydiscord/sylius-honkers-bundle

> 标签: PHP

## 简介

Plug-and-play Sylius wrapper for the Honkers chatbot tool-server: default tools, data sources and shop widget

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
