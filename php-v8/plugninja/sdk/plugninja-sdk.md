# plugninja/sdk

> 标签: api, auth, email, payments, plug.ninja, saas, sdk

## 简介

PHP SDK for plug.ninja — Email, Payments, Auth & Brazilian Data APIs in one API key.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
