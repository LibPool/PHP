# golles/php-3fm-now-playing

> 标签: 3FM, now playing, php

## 简介

Helper class to retrieve and decode now playing from Dutch radio 3FM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
