# olssonm/swedish-entity

> 标签: Organisationsnummer, Personnummer, Social security number, Swedish, laravel, olssonm, organizational number, package, personal identity number

## 简介

Validator and formatter for Swedish personnummer and organisationsnummer. With Laravel validators.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
