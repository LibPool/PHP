# takenek/mimeshield

> 标签: cms, encryption, pkcs12, plugin, roundcube, s-mime, signature, smime

## 简介

MIME Shield - S/MIME for Roundcube 1.7: sign, verify, encrypt, decrypt, PKCS#12 import, encrypted private key store, recipient certificate store, trust validation, multiple identities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
