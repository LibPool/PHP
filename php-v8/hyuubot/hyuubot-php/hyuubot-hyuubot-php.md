# hyuubot/hyuubot-php

> 标签: api, bot, client, hyuubot, sdk, telegram

## 简介

Official PHP client for the HYuuBot API. Zero dependencies (uses ext-curl), PHP 8.1+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
