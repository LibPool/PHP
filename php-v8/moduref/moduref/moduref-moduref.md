# moduref/moduref

> 标签: affiliate, attribution, laravel, mysql, pdo, points, postgres, referral, reward, sqlite, uuid

## 简介

Lightweight referral engine based on existing user UUIDs with transactional row-locking in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
