# yuninternet/php-ip-calculator

> 标签: IP, calculator, ipv4, ipv6, php, subnet

## 简介

IP calculator written in PHP 7.0, IPv4 & IPv6 are supported, mainly functions for subnet allocation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
