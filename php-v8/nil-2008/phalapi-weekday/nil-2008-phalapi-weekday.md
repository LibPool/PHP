# nil-2008/phalapi-weekday

> 标签: phalapi, phalapi-weekday, weekday

## 简介

PhalApi 2.x 扩展库 - 用于判断当天是否是工作日。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
