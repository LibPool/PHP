# muyilongh/owl-wechat-user

> 标签: extension, owl-admin, user, wechat

## 简介

OwlAdmin扩展: 微信用户管理, 包含微信小程序登录, 后台会员管理

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
