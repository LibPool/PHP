# chattrn/connector

> 标签: api, chattrn, ecommerce, laravel

## 简介

Serves the Chattrn API (devspec.txt: "Slice 3: Laravel package installer") from your own Laravel store, so Chattrn can read products, stock and orders the same way it reads a native Chattrn API or Shopify store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
