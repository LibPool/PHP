# hardworm/soap

> 标签: soap, soap client, soap server

## 简介

A fixed version of bohrlot/BeSimpleSoap used to build SOAP and WSDL based web services. This fork work php 7 and php 8

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
