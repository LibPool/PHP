# boxedcode/silex-knp-menu-service-provider

> 标签: PHP

## 简介

A Silex Knp Menu service provider which is compatible with Silex 2.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
