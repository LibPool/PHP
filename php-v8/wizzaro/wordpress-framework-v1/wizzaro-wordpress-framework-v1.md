# wizzaro/wordpress-framework-v1

> 标签: wizzaro, wordpress-framework

## 简介

This is simple framework for build wordpress advance themes and plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
