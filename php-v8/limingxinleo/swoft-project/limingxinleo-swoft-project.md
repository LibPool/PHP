# limingxinleo/swoft-project

> 标签: php, swoft, swoole

## 简介

Modern High performance AOP and Coroutine PHP Framework, base on Swoole 2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
