# ljguo-latex/openai-php

> 标签: ai, api, chat, client, gpt, llm, openai

## 简介

A PHP client for the OpenAI API with support for custom URL, API key, and model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
