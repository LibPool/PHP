# mikerow/bananophp

> 标签: Banano, blocks, cli, ipc, php, rpc, tools, websocket

## 简介

PHP libraries and tools for Banano currency

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
