# samhk222/nfe-xml-to-obj

> 标签: nfe, nota fiscal

## 简介

Pacote para transformar um xml de nota fiscal em um objeto PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
