# samhk222/json-string-parser

> 标签: PHP

## 简介

Parseia as informações de uma string, retornando em forma de array, os jsons que foram encontrados nela

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
