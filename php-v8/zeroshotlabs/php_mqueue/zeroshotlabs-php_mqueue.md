# zeroshotlabs/php_mqueue

> 标签: binding, ffi, message queue, mqueue, pmq, posix

## 简介

Speed-optimized PHP FFI bindings for POSIX message queues.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
