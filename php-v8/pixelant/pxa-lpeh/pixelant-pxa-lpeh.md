# pixelant/pxa-lpeh

> 标签: typo3

## 简介

Speeds up error page handling and frees up PHP workers by loading local page content without issuing an external HTTP request.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
