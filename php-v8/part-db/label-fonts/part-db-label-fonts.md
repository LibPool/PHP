# part-db/label-fonts

> 标签: font, fonts, part-db

## 简介

This library bundles the fonts used in Part-DB for label generators. Fonts are work of others.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
