# nao-pon/dropbox-php-sdk

> 标签: api, client, dropbox, elfinder, php, sdk

## 简介

Minimal maintenance fork of an unofficial Dropbox PHP SDK for modern PHP compatibility

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
