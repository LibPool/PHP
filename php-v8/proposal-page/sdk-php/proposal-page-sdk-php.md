# proposal-page/sdk-php

> 标签: page, proposal, sdk

## 简介

This module is a open source project with the goal of making the task of consuming the Proposal Page API easy and straight-forward

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
