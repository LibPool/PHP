# smalot/magento-client

> 标签: PHP

## 简介

Magento API Client (SOAP v1). Allows wrappers for each call, dependency injections and code completion.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
