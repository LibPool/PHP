# hryvinskyi/magento2-data-layer-server-side-frontend-ui

> 标签: PHP

## 简介

Storefront surface of server-side GA4 events: the collector browsers post their events to, its request rules, and the part of the browser settings that names each event's channel and the collector address.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
