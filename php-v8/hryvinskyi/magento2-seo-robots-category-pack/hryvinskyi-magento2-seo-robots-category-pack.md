# hryvinskyi/magento2-seo-robots-category-pack

> 标签: PHP

## 简介

Complete SEO Robots Category solution for Magento 2 with flexible directive management, multiselect UI, and independent X-Robots-Tag configuration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
