# hryvinskyi/magento2-activity-log

> 标签: PHP

## 简介

One journal of who did what in the store back office, through which channel and with what outcome; dashboard, search and detail views that channel modules extend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
