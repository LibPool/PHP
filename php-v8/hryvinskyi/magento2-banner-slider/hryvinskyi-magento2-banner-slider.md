# hryvinskyi/magento2-banner-slider

> 标签: PHP

## 简介

Banner Slider core module: persistence, editors, storefront read services, responsive crops with WebP/AVIF variants, media uploads, video providers, cache refresh and media clean-up

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
