# hryvinskyi/magento2-banner-slider-admin-ui

> 标签: PHP

## 简介

Banner Slider admin module: slider and banner grids and forms, responsive crop editor, uploads, ACL, menu and configuration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
