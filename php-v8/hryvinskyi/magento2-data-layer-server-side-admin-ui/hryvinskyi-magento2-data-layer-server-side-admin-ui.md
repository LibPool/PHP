# hryvinskyi/magento2-data-layer-server-side-admin-ui

> 标签: PHP

## 简介

Admin surface of server-side GA4 events: their group in the data layer's configuration section, the access rule of its actions, the delivery status and its actions (queue failed events again, send a test event), option lists, validation rules and validated settings, and the setup wizard's server-side step.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
