# hryvinskyi/magento2-data-layer-admin-ui

> 标签: PHP

## 简介

Admin surface of the GA4 data layer: its configuration section in the Sales tab, the access rule that guards it, the events table and the other field renderers, option lists, validation rules and validated settings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
