# hryvinskyi/magento2-data-layer-frontend-ui

> 标签: PHP

## 简介

Storefront surface of the GA4 data layer: the Tag Manager and gtag.js loaders, the page bootstrap and its browser module (with the gtag.js destination), product list data, the endpoint that hands server-detected events to the browser, and the content security policy for Google's tag, analytics and ads hosts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
