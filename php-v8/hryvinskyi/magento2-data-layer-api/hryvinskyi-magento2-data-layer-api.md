# hryvinskyi/magento2-data-layer-api

> 标签: PHP

## 简介

Published contracts of the GA4 ecommerce data layer: events and items as value types, the batch item-field extension point, price visibility, cart tracking policy, cart kinds that report events of their own, the server-event queue and the list-data renderer bridges use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
