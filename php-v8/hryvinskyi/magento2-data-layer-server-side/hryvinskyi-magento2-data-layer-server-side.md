# hryvinskyi/magento2-data-layer-server-side

> 标签: PHP

## 简介

Sends GA4 events from the server — GA4 Measurement Protocol or a server-side Tag Manager — with the visitor's GA identifiers, through an outbox delivered by cron.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
