# hryvinskyi/magento2-seo-robots-category-frontend

> 标签: PHP

## 简介

Frontend implementation for SEO Robots Category with independent X-Robots-Tag support and directive arrays

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
