# hryvinskyi/magento2-csp

> 标签: PHP

## 简介

Content Security Policy management for Magento 2: admin whitelist per store and area, violation reports with conversion, semantics-preserving header optimisation and splitting, script hashes for CMS content

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
