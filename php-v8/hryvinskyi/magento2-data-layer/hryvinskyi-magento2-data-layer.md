# hryvinskyi/magento2-data-layer

> 标签: PHP

## 简介

GA4 ecommerce data layer for Google Tag Manager: settings, events built on the server and while pages render, the item pipeline, product list data, the browser and server delivery channels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
