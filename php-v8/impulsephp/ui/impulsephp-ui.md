# impulsephp/ui

> 标签: PHP

## 简介

A comprehensive UI component provider for ImpulsePHP, offering pre-built components to rapidly design and develop modern web application interfaces

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
