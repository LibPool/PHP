# concept-image/wp-archive-base

> 标签: PHP

## 简介

A package for adding a base for managing archive to a theme with Acorn (base view composer for archive, pagination, filters, etc...)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
