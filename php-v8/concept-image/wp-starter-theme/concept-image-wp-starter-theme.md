# concept-image/wp-starter-theme

> 标签: PHP

## 简介

Base theme setup for WordPress with custom hooks and templates for Concept Image. Optimized for Roots Acorn.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
