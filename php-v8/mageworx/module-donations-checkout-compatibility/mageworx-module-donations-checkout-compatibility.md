# mageworx/module-donations-checkout-compatibility

> 标签: PHP

## 简介

Compatibility extension for MageWorx Donations with MageWorx Checkout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
