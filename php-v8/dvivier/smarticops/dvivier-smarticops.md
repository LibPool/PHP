# dvivier/smarticops

> 标签: Authentication, administration, authorization, dvivier, laravel, permission, permissions, role, roles, smarticops

## 简介

Permission-based Authorization package for Laravel 5.2, includes Authentication, developed on behalf of smartic.ca

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
