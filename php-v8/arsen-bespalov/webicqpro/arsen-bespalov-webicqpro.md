# arsen-bespalov/webicqpro

> 标签: icq, icq api, icq bot

## 简介

Set of PHP tools for simple and clear work with ICQ (OSCAR) protocol

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
