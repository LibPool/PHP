# betterauth/laravel

> 标签: 2fa, Authentication, laravel, magic-link, oauth, paseto

## 简介

Modern authentication for Laravel with Paseto V4 tokens, OAuth, 2FA, and Magic Links

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
