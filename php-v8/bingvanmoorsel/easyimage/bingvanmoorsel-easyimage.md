# bingvanmoorsel/easyimage

> 标签: gd, image, imagick, laravel, thumbnail, watermark

## 简介

Image handling and manipulation library with support for Laravel integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
