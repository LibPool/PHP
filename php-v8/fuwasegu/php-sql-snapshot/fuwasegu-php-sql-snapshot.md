# fuwasegu/php-sql-snapshot

> 标签: ast, mysql, phpunit, postgresql, sql, testing

## 简介

PHPUnit extension for testing SQL queries using AST comparison instead of string comparison

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
