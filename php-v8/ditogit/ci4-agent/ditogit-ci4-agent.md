# ditogit/ci4-agent

> 标签: Agent, CI4, codeigniter4, maintenance, monitoring

## 简介

Lightweight, secure, versioned REST API agent for CodeIgniter 4 — standardized monitoring & maintenance for CI4 Project Hub

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
