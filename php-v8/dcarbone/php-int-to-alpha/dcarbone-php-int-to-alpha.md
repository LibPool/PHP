# dcarbone/php-int-to-alpha

> 标签: columns, excel, php

## 简介

A lib that take a base 10 integer and turns it into a base 26 alphabet string

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
