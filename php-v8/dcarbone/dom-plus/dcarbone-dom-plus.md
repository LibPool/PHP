# dcarbone/dom-plus

> 标签: domdocument, php, smartdomdocument

## 简介

A DOMDocument class wrapper that adds some simple improvements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
