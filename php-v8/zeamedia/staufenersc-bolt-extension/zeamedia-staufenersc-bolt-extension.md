# zeamedia/staufenersc-bolt-extension

> 标签: PHP

## 简介

Staufener SC Bolt Erweiterung. Erzeugt einen Merge der Contenttypen 'Spiele', 'Termine' und 'Teams' um daraus in Twig die 'allevents' zu generieren.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
