# jinomdeveloper/helpers

> 标签: E164, Jinom, calculation, currency, finance, formatting, helpers, indonesia, indonesian, laravel, number-to-words, parsing, phone-number, ppn, rupiah, tax, terbilang

## 简介

Laravel package for Indonesian financial calculations including PPN tax (11%) and Rupiah currency formatting

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
