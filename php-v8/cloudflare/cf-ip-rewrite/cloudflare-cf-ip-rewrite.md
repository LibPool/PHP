# cloudflare/cf-ip-rewrite

> 标签: cloudflare, ip rewrite

## 简介

Library to rewrite CloudFlare IP Addresses to the end-user IP address

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
