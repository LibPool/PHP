# zwilias/zend-framework-1

> 标签: PHP

## 简介

Good old zend-framework one, composer-ready. For those of us stuck with it, but wanting to use composer nevertheless.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
