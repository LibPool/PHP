# fallen-komrades-dev/ksuid

> 标签: identifier, ksuid, sortable, unique, uuid

## 简介

K-Sortable Unique Identifier (KSUID) for PHP, ported from ksuid-go and based on tuupola/ksuid

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
