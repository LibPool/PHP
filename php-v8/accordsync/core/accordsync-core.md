# accordsync/core

> 标签: crdt, local-first, offline-first, sync

## 简介

Accord's merge core for PHP: hybrid logical clocks, operations, lww, counter, set and conflict.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
