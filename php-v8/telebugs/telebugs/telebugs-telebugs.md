# telebugs/telebugs

> 标签: crash-reporting, crashes, error-monitoring, error-reporting, error-tracking, errors, exceptions, telebugs

## 简介

Telebugs for PHP is an error reporting library for Telebugs (https://telebugs.com/), a simple error monitoring tool for developers. With Telebugs, you can track production errors in real-time and report them to Telegram.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
