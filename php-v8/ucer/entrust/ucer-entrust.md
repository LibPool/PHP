# ucer/entrust

> 标签: PHP

## 简介

This package provides a flexible way to add Role-based Permissions to Laravel, And modify on zizaco/entrust.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
