# erwane/line-awesome

> 标签: awesome, font, font-awesome, icons, icons8, line-awesome

## 简介

Replace Font Awesome with modern line icons https://icons8.com/line-awesome

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
