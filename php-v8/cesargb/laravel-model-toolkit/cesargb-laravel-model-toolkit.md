# cesargb/laravel-model-toolkit

> 标签: cleaner, laravel, morph, prune

## 简介

List all models, detect and delete orphaned morph relation records, and prune Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
