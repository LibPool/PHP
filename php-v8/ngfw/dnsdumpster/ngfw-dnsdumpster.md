# ngfw/dnsdumpster

> 标签: DNSDumpster, ngfw

## 简介

A Laravel package to fetch DNS reconnaissance data from the DNSDumpster API, easily installable via Composer and configurable as a service provider.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
