# rsvpify/laravel-mail-auto-embed

> 标签: laravel-mail-auto-embed, rsvpify

## 简介

Library for embed images in emails automatically

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
