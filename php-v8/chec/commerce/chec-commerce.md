# chec/commerce

> 标签: api, chec, commerce.js, ecommerce, sdk, shopping cart

## 简介

PHP client library for Commerce.js by Chec

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://commercejs.com/
- 源码仓库：https://github.com/chec/commerce.php.git
- Packagist 页面：https://packagist.org/packages/chec%2Fcommerce

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require chec/commerce`
- Packagist 仓库：https://repo.packagist.org/p2/chec/commerce.json
- 许可证：MIT
- PHP 要求：>=5.4.0
