# montross50/sshpubkey-validator

> 标签: SSHPubKeyValidator, montross50, sshpubkey-validator

## 简介

Validate ssh-rsa key for valid openssh format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
