# pes/pes-mail

> 标签: framework, mail, pes, phpmailer

## 简介

Mail sending layer for Pes (PHPMailer wrapper, assembly, SMTP configuration).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
