# pes/pes-bootstrap

> 标签: bootstrap, framework, pes

## 简介

Procedurální bootstrap skripty pro Pes (autoloader, prostředí, error handlery, logy).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
