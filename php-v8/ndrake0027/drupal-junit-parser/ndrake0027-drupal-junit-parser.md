# ndrake0027/drupal-junit-parser

> 标签: PHP

## 简介

JUnit parser for Drupal behat and PHPUnit output to a simple html table.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
