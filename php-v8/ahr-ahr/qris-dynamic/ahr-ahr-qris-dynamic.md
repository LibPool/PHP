# ahr-ahr/qris-dynamic

> 标签: dynamic-qris, emv, indonesia, payment, php, qris

## 简介

PHP library for parsing and generating dynamic QRIS payloads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
