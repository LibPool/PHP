# kablanfatih/encryption

> 标签: aes, attribute, attribute encryption, database, database encryption, db, decrypt, decryption, eloquent, eloquent encryption, encrypt, encryption, laravel, laravel encryption, model, model encryption

## 简介

A package for automatically encrypting and decrypting Eloquent attributes in Laravel , based on configuration settings.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
