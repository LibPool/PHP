# fabic/nql

> 标签: composer, graphql, laravel, package, rest

## 简介

NQL is not GraphQL, but some sort of GraphQL-like impl. for the Rest of us.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
