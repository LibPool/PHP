# hlev/jetstrap-minimal

> 标签: blade, bootstrap, jetstream, laravel, livewire, php

## 简介

A package for Laravel 10 to replace TailwindCSS with Bootstrap 5.3, Livewire + Blade, Teams

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
