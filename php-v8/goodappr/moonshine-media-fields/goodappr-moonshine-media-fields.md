# goodappr/moonshine-media-fields

> 标签: admin, audio, laravel, media, moonshine, video

## 简介

Audio, AudioList, Video, VideoList fields for MoonShine 4.x - media with preview and modals

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
