# crazyfd/php-blade

> 标签: blade, blade-template, illuminate-view, laravel, render, template, templating, view, webman, webman-blade, webman-view, workerman

## 简介

Webman 的 Laravel Blade 模板引擎（webman blade），支持 illuminate/view 10.x-13.x，含视图渲染与 blade:cache/blade:clear 命令 | Laravel Blade templating for Webman, powered by illuminate/view.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
