# thank/crypto

> 标签: encrypt, openssl加密, 对称加密

## 简介

Encrypt and decrypt data for PHP, 前端crypto.js + PHP的加解密方案

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
