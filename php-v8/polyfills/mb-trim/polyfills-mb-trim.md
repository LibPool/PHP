# polyfills/mb-trim

> 标签: PHP

## 简介

PHP: Provides a user-land polyfill for `mb_trim`, `mb_ltrim`, and `mb_rtrim` functions added in PHP 8.4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
