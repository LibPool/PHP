# polyfills/pdo-mysql-subclass

> 标签: compat, compatibility, php84, phpwatch, polyfill, polyfills, shim

## 简介

User-land PHP polyfill for PDO MySQL driver subclass.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
