# vierbeuter/craft-footnotes

> 标签: CKEditor, Craft, Redactor, cms, craft-plugin, craftcms, footnotes

## 简介

Adds a footnotes feature to CKEditor fields and Twig templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
