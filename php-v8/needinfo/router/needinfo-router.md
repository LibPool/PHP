# needinfo/router

> 标签: needinfo, php, route, router, routing

## 简介

Um roteador PHP simples, seguro e robusto criado para agilidade na abstração MVC através de verbos RESTful.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
