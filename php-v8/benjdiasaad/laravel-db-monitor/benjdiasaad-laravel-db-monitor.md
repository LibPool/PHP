# benjdiasaad/laravel-db-monitor

> 标签: database, laravel, monitoring, performance, slow-query

## 简介

Real-time database health monitoring for Laravel: slow queries, N+1 detection, and missing index suggestions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
