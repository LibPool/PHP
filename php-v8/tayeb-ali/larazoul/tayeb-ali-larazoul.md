# tayeb-ali/larazoul

> 标签: admin, cms, crud, generator, laravel, livewire, tailwind

## 简介

LaraZoul - A modern Laravel CMS and CRUD module generator rebuilt for Laravel 13 (Blade + Tailwind + Livewire).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
