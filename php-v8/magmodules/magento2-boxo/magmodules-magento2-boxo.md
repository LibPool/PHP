# magmodules/magento2-boxo

> 标签: PHP

## 简介

BOXO Reusable Packaging for Magento 2 — offer reusable or disposable packaging options during checkout with real-time availability via the BOXO API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
