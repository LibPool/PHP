# qingze-lab/esignbao-sdk-php-7.0

> 标签: Authentication, contract, e-signature, esignbao, php, rest, sdk

## 简介

易签宝 REST API PHP SDK，支持实名认证V3和PDF合同签署，包含令牌管理、可重试HTTP和领域服务。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
