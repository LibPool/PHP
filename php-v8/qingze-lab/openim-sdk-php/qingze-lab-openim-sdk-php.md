# qingze-lab/openim-sdk-php

> 标签: im, openim, php, rest, sdk

## 简介

OpenIM REST API PHP SDK with token management, retryable HTTP, and domain services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
