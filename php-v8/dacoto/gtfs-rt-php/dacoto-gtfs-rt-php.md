# dacoto/gtfs-rt-php

> 标签: gtfs, gtfs-realtime, protobuf, transit

## 简介

GTFS-Realtime library for PHP 8.4+ based on Google Protocol Buffers v5

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
