# weiaibaicai/big-file-upload

> 标签: big-file-upload, dcat-admin, extension

## 简介

Dcat Admin Extension 大文件上传（分片，目前仅支持七牛）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
