# tpaksu/xdebug-toggle

> 标签: tpaksu, xdebug-toggle

## 简介

Toggles on/of the already installed xdebug extension on php.ini file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
