# fivestones/laravel-gmp-report-jobs

> 标签: PHP

## 简介

Runs GMP reports in Laravel queue asynchronously and dispatch a new job to process the downloaded report.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
