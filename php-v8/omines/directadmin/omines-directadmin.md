# omines/directadmin

> 标签: api, control panel, direct admin, directadmin, library, php

## 简介

PHP client library to manage DirectAdmin control panel servers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
