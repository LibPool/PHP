# neosidekick/workspace-review

> 标签: PHP

## 简介

Human-readable review of workspace changes for Neos CMS: a React module with word-level text diffs, editor-aware value labels, a page tree, reviewer progress, keyboard review and a visual compare of the rendered pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
