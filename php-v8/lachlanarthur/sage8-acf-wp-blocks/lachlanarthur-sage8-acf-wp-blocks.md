# lachlanarthur/sage8-acf-wp-blocks

> 标签: advanced custom fields, gutenberg, wordpress

## 简介

Create Gutenberg blocks from Sage 8 templates and ACF fields.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
