# kevinfunk/canvas_component_manager

> 标签: canvas, component, devops, drupal, sync

## 简介

Provides a UI to sync (export/import) Canvas components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
