# softinvest/php-jsonpointer

> 标签: json, json pointer, json traversal

## 简介

Implementation of JSON Pointer (http://tools.ietf.org/html/rfc6901)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
