# mtechnik/pantherforum

> 标签: discussion, forum

## 简介

PantherForums, is a fast, yet very secure forum web application written in PHP and MySQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
