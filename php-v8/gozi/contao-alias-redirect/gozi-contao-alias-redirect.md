# gozi/contao-alias-redirect

> 标签: PHP

## 简介

Alte Seiten-Aliase bleiben als 301-Weiterleitung erhalten — automatisch beim Umbenennen, sichtbar direkt an der Seite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
