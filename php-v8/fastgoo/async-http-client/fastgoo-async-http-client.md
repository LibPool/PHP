# fastgoo/async-http-client

> 标签: async, http, swoole

## 简介

基于swoole扩展的HTTP异步请求扩展包，需要依赖swoole扩展

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
