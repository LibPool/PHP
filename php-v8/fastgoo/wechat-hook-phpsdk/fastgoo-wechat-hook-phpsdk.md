# fastgoo/wechat-hook-phpsdk

> 标签: PHP

## 简介

这是为易语言微信HOOK工具提供http对接服务的SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
