# bagoespantera/laravel-cron-mailer

> 标签: cron, laravel, mail, mailable, queue

## 简介

Queue e-mails into the database and deliver them from a scheduled console worker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
