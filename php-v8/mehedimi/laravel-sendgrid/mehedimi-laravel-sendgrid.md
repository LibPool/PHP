# mehedimi/laravel-sendgrid

> 标签: laravel-mail, laravel-sendgrid, sendgrid mailable

## 简介

A package for using sendgrid as an email sending driver for Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
