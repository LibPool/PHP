# digit7s/laravel-seo-sitemap

> 标签: Sitemap, digit7s, laravel, seo

## 简介

Reusable Laravel SEO sitemap abstraction for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
