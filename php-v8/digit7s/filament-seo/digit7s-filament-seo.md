# digit7s/filament-seo

> 标签: JSON-LD, Sitemap, filament, laravel, metadata, seo, structured-data

## 简介

SEO metadata, Static Pages, JSON-LD, and XML sitemap tools for Laravel and Filament.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
