# protonemedia/laravel-splade-breeze

> 标签: auth, laravel, laravel-splade, splade

## 简介

Minimal Laravel authentication scaffolding with Laravel Splade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
