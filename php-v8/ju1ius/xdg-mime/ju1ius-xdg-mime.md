# ju1ius/xdg-mime

> 标签: freedesktop, guesser, mime, mime-type, xdg

## 简介

PHP implementation of the Freedesktop Shared MIME-info Database standard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
