# wecodemore/astrofields-core

> 标签: Forms, astrofields, fields, wordpress

## 简介

A PHP Pattern Library for Fields, Forms and other User provided Input

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
