# wecodemore/wp-cli-composer

> 标签: bash, composer, plugins, profile, wordpress, wp, wp-cli

## 简介

Adds bash autocompletion for WP-CLI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
