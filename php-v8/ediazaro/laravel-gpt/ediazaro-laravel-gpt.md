# ediazaro/laravel-gpt

> 标签: gpt, laravel, openai

## 简介

Streamlined integration of OpenAI's ChatGPT (GPT-3.5, GPT-4) into Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
