# oleg-chulakov-studio/yii2-amocrm

> 标签: PHP

## 简介

Yii2 wrapper for working with AmoCRM RESTfull API v2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
