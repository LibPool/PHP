# fakecloud/fakecloud

> 标签: aws, emulator, fakecloud, localstack, mock, testing

## 简介

PHP client SDK for fakecloud — a local AWS cloud emulator

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
