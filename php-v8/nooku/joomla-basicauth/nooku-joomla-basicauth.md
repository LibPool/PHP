# nooku/joomla-basicauth

> 标签: Authentication, http, joomla, plugin

## 简介

A Joomla! plugin to allow users to login using basic HTTP authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
