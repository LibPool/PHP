# textflow/sms-api

> 标签: API-Client, api, simple-sms, sms, sms-api, sms-verification, text-message

## 简介

PHP library that helps you send SMS using TextFlow API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
