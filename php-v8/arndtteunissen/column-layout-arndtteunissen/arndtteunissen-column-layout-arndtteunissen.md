# arndtteunissen/column-layout-arndtteunissen

> 标签: arndtteunissen, column_layout

## 简介

Adds arndtteunissens column configuration to ext:column_layout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
