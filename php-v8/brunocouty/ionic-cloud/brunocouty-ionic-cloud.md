# brunocouty/ionic-cloud

> 标签: PHP

## 简介

Use the IonicCloud services on PHP! Push Notifications, Auth Service and much more from Ionic Cloud!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
