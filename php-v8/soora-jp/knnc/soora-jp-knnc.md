# soora-jp/knnc

> 标签: Numerals, convert, japanese, kanji, numeric, string

## 简介

Convert Japanese-Kanji numerals string and numeric each other

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
