# simplesquid/laravel-vend-sdk

> 标签: laravel, laravel-vend-sdk, point-of-sale, sdk, simplesquid, vend

## 简介

A Laravel package for our PHP SDK for Vend POS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
