# webrium/core

> 标签: PHP

## 简介

A lightweight set of PHP utility classes for common web tasks: routing, HTTP requests and headers, sessions, validation, file uploads, JWT, and hashing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
