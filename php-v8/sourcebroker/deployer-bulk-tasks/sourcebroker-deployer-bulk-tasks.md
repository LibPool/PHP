# sourcebroker/deployer-bulk-tasks

> 标签: deployer

## 简介

Provides bulk deployer cli commands for any application that provides raw list of cli commands.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
