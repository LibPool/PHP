# martin6363/filament-video-engine

> 标签: ffmpeg, filament, filament-plugin, hls, hls.js, laravel, plyr, streaming, transcoding, video

## 简介

Enterprise HLS video transcoding, adaptive streaming, and Filament UI for Laravel — FFmpeg, multi-resolution, Plyr/hls.js player, polymorphic HasVideoEngine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
