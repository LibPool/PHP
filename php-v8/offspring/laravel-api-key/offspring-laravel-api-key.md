# offspring/laravel-api-key

> 标签: Api Key, Authentication, api, authorization, laravel

## 简介

Authorize requests to your Laravel application with API keys

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
