# stainlessplugins/oxid-cookie-consent-base

> 标签: PHP

## 简介

Basic cookie consent module for oxid to be used by cookie consent modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
