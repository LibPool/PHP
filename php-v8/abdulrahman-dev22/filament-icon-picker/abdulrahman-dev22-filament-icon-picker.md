# abdulrahman-dev22/filament-icon-picker

> 标签: Heroicons, filament, filament-icon-picker, filament-plugin, icon, icon-picker, laravel, svg

## 简介

A searchable, tabbed icon picker form field for Filament v3, v4 and v5, with bundled Heroicons and custom SVG icon sets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
