# iqbalmalik89/guzzle-application-cache-subscriber

> 标签: PHP

## 简介

Guzzle Plugin resp. Guzzle Subscriber to selectively cache a request/response on application level.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
