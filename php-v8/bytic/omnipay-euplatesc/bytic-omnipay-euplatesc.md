# bytic/omnipay-euplatesc

> 标签: driver, euplatesc, gateway, merchant, omnipay, pay, payment

## 简介

Euplatesc driver for ThePhpLeague Omnipay multi-payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
