# dtyq/sandbox

> 标签: blacklist, parser, php, sandbox, whitelist

## 简介

A PHP library that can be used to run PHP code in a sandboxed environment

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://phpsandbox.org/
- 源码仓库：https://github.com/dtyq/sandbox.git
- Packagist 页面：https://packagist.org/packages/dtyq%2Fsandbox
