# ip2geo-dev/sdk

> 标签: IP, geo, geoip, geolocation, ip-to-geo, ip2geo

## 简介

Official PHP SDK for Ip2Geo - IP to Geolocation API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
