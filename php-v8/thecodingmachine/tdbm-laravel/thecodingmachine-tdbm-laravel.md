# thecodingmachine/tdbm-laravel

> 标签: TDBM, bean, dao, laravel, model, orm, persistence

## 简介

A Laravel service provider package to help you get started with TDBM in Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
