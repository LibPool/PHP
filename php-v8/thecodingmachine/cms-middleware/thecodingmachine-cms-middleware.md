# thecodingmachine/cms-middleware

> 标签: PHP

## 简介

A http-interop compatible CMS middleware. It only provides the middleware and delegates pages fetching to other packages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
