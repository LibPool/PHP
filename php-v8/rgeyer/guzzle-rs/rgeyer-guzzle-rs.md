# rgeyer/guzzle-rs

> 标签: Guzzle, RightScale, api, client

## 简介

Guzzle Client for RightScale API 1.0 and 1.5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
