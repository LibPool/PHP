# contributte/mobilni-platby

> 标签: PHP

## 简介

Dispatcher for Mobile Payments (www.mobilniplatby.cz) for Nette Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
