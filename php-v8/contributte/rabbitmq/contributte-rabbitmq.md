# contributte/rabbitmq

> 标签: bunny, bunnyphp, extension, nette, php, rabbit, rabbitmq

## 简介

Nette extension for RabbitMQ (using BunnyPHP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
