# contributte/event-dispatcher-extra

> 标签: Bridge, application, dispatcher, event, form, latte, nette, security, template

## 简介

Nette-based Symfony events for application, presenter, form, latte, templates, security and many others.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
