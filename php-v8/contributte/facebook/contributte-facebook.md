# contributte/facebook

> 标签: facebook, login, nette, oauth2, php, sdk

## 简介

Easy-to-use Facebook login wrapper for [`Nette Framework`](https://github.com/nette/).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
