# jorgecortesdev/sendgrid-laravel

> 标签: email, laravel, sendgrid, sendgrid-php

## 简介

Laravel wrapper for the official SendGrid PHP library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
