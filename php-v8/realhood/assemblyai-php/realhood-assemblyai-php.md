# realhood/assemblyai-php

> 标签: PHP

## 简介

A PHP SDK for the AssemblyAI API, enabling speech-to-text transcription and real-time audio analysis functionalities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
