# abolaradev/authora

> 标签: abolaradev, authora, laravel

## 简介

A reusable authentication package for Laravel, designed to provide a flexible and Livewire-friendly foundation for building authentication workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
