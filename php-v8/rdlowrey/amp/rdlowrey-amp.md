# rdlowrey/amp

> 标签: amp, async, concurrency, non-blocking, parallelization, pthreads, threads

## 简介

Non-blocking thread pool task dispatch

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
