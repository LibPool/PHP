# ordinary/clock

> 标签: clock, clock-interface, now, ordinary, psr-20, psr20, time

## 简介

A simple PSR-20 Clock implementation for accessing and mocking the current time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
