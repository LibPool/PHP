# websitinu/laravel-socialite-google-one-tap

> 标签: Google One Tap, google sign-in, laravel, login with google, socialite, websitinu

## 简介

A lightweight package to add Google One Tap login to Laravel applications using Socialite

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
