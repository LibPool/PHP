# taggrs/magento2-hyva-data-layer

> 标签: PHP

## 简介

This extension makes the Taggrs_DataLayer extension compatible with the Hyva theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
