# woweb/laravel-zgw-client

> 标签: autorisaties, besluiten, catalogi, documenten, laravel, notificaties, openzaak, woweb, zaken, zgw

## 简介

Laravel package for the Dutch ZGW (Zaakgericht Werken) APIs: Zaken, Catalogi, Documenten, Besluiten, Autorisaties and Notificaties.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
