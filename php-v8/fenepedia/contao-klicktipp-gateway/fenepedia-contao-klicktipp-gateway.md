# fenepedia/contao-klicktipp-gateway

> 标签: KickTipp, Klick-Tipp, contao, notification center

## 简介

Contao extension to provide a Notification Center Gateway for the KlickTipp API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
