# onlime-roundcube/jwt-sso

> 标签: Authentication, SSO, jwt, single-sign-on

## 简介

Roundcube plugin for Single-sign-on (SSO) login to external mailaccount management.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
