# mestrona/magento-module-categoryredirect

> 标签: PHP

## 简介

Magento 2 Module to simply customize the menu with additional URLs: Create a category, enter the redirect, done.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
