# mzh/hyperf-validate

> 标签: framework, hyperf, php, swoole

## 简介

hyperf-validate  支持request 和方法场景验证，兼容tp5写法 支持控制器注解验证、方法注解验证

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
