# illuma-law/laravel-vector-schema

> 标签: illuma-law, laravel, laravel-vector-schema

## 简介

Portable Laravel vector schema, casts, and cosine similarity queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
