# prestashopheaven/module-kit

> 标签: PHP

## 简介

Shared base for PrestaHaven PrestaShop modules: ModuleBase trait, module definition, installer, uninstaller, migrations and upgrade helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
