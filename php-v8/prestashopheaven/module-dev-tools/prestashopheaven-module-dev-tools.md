# prestashopheaven/module-dev-tools

> 标签: PHP

## 简介

Development tooling for PrestaHaven PrestaShop modules: validator pre-check, release zip with scoped vendor, Docker test shops, PHPStan against PrestaShop 8 and 9, conventions check and definition-of-done stamps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
