# surpaimb/laravel-admin-alioss

> 标签: alioss, extension, laravel-admin

## 简介

扩展laravel-admin的form表单，使其可以使用web直传阿里OSS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
