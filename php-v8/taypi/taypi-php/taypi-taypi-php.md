# taypi/taypi-php

> 标签: pagos, pasarela, peru, plin, qr, taypi, yape

## 简介

SDK oficial de TAYPI — Pagos QR interoperables para e-commerce en Perú

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
