# hipcreative/bb-featured-resource

> 标签: PHP

## 简介

A featured resource module for Beaver Builder. Perfect for sidebars or to breakup main content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
