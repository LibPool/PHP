# fdwebtech/lexik-jwt-command-bundle

> 标签: PHP

## 简介

This bundle provides command to generate SSH keys for LexikJWTAuthenticationBundle

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
