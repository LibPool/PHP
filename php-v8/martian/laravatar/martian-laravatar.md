# martian/laravatar

> 标签: DiceBear, amplifiedhq, avatar, avatars, boring-avatars, gravatar, laravel, laravel-12, laravel-13, laravel-package, php, robohash, ui-avatars, unavatar, vercel

## 简介

Avatar URLs for Laravel models from Gravatar, DiceBear, UI Avatars, Boring Avatars, Vercel, RoboHash and Unavatar

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
