# martian/laracaptcha

> 标签: Laravel reCAPTCHA, captcha, google, google-recaptcha, hcaptcha, invisible-recaptcha, laracaptcha, laravel, laravel-package, martian, no-captcha, php, reCAPTCHA V2, recaptcha, recaptcha v3, recaptcha-v2, recaptcha-v2-checkbox, recaptcha-v2-invisible, recaptcha-v3, validation

## 简介

A Laravel package to seamlessly use hCapthca or reCaptcha on your forms or RESTful APIs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
