# dlbb/active-user-indicator

> 标签: Users, admin, flarum, indicator

## 简介

Displays a clear active or inactive status badge on the admin user list based on email validation status.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
