# ministryofjustice/aws-secrets-cache-php

> 标签: Secrets Manager, aws, cache

## 简介

AWS Secrets Manager caching for PHP (PSR-16, APCu cache storage, ENV-prefixed secrets).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
