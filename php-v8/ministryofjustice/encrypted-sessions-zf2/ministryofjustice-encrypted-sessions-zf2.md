# ministryofjustice/encrypted-sessions-zf2

> 标签: PHP

## 简介

A decorator for classes implementing ZF2's Session SaveHandlerInterface that enables encryption of the session contents.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
