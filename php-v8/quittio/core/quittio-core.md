# quittio/core

> 标签: E-Invoice, EN16931, PDFA, ZUGFeRD, cii, einvoice, factur-x, peppol, php, ubl, xrechnung

## 简介

Country-neutral e-invoicing core: EN 16931 data model, calculation, validation, CII/UBL, ZUGFeRD/Factur-X PDF/A-3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
