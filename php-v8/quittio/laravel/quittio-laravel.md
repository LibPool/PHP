# quittio/laravel

> 标签: E-Invoice, ZUGFeRD, factur-x, laravel, peppol, xrechnung

## 简介

Laravel integration for Quittio e-invoicing: facade, configuration, Blade templates, commands and testing helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
