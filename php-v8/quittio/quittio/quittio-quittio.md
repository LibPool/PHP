# quittio/quittio

> 标签: E-Invoice, EN16931, ZUGFeRD, einvoice, factur-x, invoice, laravel, peppol, php, xrechnung

## 简介

E-invoicing for PHP and Laravel: create, validate, read and render EN 16931 invoices (ZUGFeRD/Factur-X, XRechnung, UBL, Peppol BIS). Bundles the core, the Laravel integration and the country pack for Germany; without Laravel use quittio/core and quittio/country-de.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
