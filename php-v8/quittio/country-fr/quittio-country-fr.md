# quittio/country-fr

> 标签: E-Invoice, TVA, factur-x, facture-electronique, france, php

## 简介

Quittio country pack for France: VAT presets and invoice mentions (CGI, Code de commerce), the mentions of the e-invoicing reform of 2026, SIREN, late payment penalties.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
