# moinframe/kirby-linkcheck

> 标签: cms, kirby, link checker, plugin

## 简介

Kirby CMS plugin to crawl a website and check for broken links. From the Kirby Panel or via the CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
