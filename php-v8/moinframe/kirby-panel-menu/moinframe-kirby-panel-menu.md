# moinframe/kirby-panel-menu

> 标签: kirby, kirby-plugin, kirby4, kirby5, menu, panel

## 简介

A fluent, chainable PHP class for managing Kirby CMS panel menu entries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
