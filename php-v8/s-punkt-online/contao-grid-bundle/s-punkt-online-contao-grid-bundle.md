# s-punkt-online/contao-grid-bundle

> 标签: columns, contao, grid, layout, spalten

## 简介

Visual 12-column grid for Contao 5.3+: rows with up to 4 columns, "Neues Grid" presets, +/- column widths, gaps and equal height in the backend preview.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
