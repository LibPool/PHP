# ondewo/vtsi-client-php

> 标签: client, gRPC, ondewo, protobuf, vtsi

## 简介

ONDEWO VTSI (Virtual Telephony Server Interface) gRPC client for PHP, generated from the ondewo-vtsi-api protocol buffer definitions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
