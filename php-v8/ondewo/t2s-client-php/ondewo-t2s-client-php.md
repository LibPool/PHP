# ondewo/t2s-client-php

> 标签: client, gRPC, ondewo, protobuf, t2s

## 简介

ONDEWO T2S (Text-to-Speech) gRPC client for PHP, generated from the ondewo-t2s-api protocol buffer definitions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
