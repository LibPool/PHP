# ondewo/s2t-client-php

> 标签: client, gRPC, ondewo, protobuf, s2t

## 简介

ONDEWO S2T (Speech-to-Text) gRPC client for PHP, generated from the ondewo-s2t-api protocol buffer definitions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
