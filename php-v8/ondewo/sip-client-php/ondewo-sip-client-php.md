# ondewo/sip-client-php

> 标签: client, gRPC, ondewo, protobuf, sip

## 简介

ONDEWO SIP (SIP Telephony) gRPC client for PHP, generated from the ondewo-sip-api protocol buffer definitions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
