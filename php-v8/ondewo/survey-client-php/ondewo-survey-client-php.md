# ondewo/survey-client-php

> 标签: client, gRPC, ondewo, protobuf, survey

## 简介

ONDEWO SURVEY (Survey) gRPC client for PHP, generated from the ondewo-survey-api protocol buffer definitions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
