# ionysdev/pkuatia

> 标签: Paraguay, dnit, documento-electronico, e-kuatia, ekuatia, factura-electronica, facturacion-electronica, sifen

## 简介

Implementación en PHP de la interfaz con el sistema e-Kuatia (SIFEN) de facturación electrónica de Paraguay

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
