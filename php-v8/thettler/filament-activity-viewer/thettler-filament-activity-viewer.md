# thettler/filament-activity-viewer

> 标签: filament, filament-activity-viewer, filament-plugin, filamentphp, laravel, thettler

## 简介

Spatie activity log integration for FilamentPHP which lets you view and search your activity Logs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
