# cruelvx/laravel-phpbb-bridge

> 标签: laravel, laravel5, phpbb, phpbb3

## 简介

Authentication module for Laravel 5.8 and phpBB 3.3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
