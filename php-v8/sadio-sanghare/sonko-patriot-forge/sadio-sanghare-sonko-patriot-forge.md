## 简介

SonkoPatriot Forge - Laravel 13 API and web scaffold generator with modern dashboard, Bootstrap tables or Yajra Laravel DataTables, Data, Query Builder, Permissions, OpenAPI, audit, media, search, Excel, queues and realtime broadcasting

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
