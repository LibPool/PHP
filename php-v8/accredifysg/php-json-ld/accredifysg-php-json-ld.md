# accredifysg/php-json-ld

> 标签: JSON-LD, RDF, W3C, jsonld, linked-data, semantic-web

## 简介

A PHP implementation of the JSON-LD 1.1 specification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
