# webwizardsusa/laravel-oembed

> 标签: laravel, laravel-oembed, oembed, webwizardsusa

## 简介

Generate external embed code from a URL via the oembed protocol

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
