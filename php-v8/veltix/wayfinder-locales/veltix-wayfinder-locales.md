# veltix/wayfinder-locales

> 标签: i18n, laravel, localization, routes, typescript, wayfinder

## 简介

Localized route URLs and TypeScript translation catalogs for Laravel Wayfinder (next branch).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
