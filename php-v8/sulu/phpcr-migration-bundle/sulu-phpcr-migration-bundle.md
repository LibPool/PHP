# sulu/phpcr-migration-bundle

> 标签: content-bundle, migration, phpcr, sulu

## 简介

The bundle provides command to migrate the Sulu database from phpCr to the SuluContentBundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
