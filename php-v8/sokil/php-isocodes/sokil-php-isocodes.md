# sokil/php-isocodes

> 标签: PHP

## 简介

ISO country, subdivision, language, currency and script definitions and their translations. Based on pythons pycountry and Debian's iso-codes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
