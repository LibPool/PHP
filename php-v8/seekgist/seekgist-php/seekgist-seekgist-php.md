# seekgist/seekgist-php

> 标签: arabic, autocomplete, ecommerce, sdk, search, seekgist

## 简介

SeekGist API client for PHP: Arabic-first e-commerce search, suggest, catalog sync and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://seekgist.com/docs/sdk/php
- 源码仓库：https://github.com/seekgist/seekgist-php.git
- Packagist 页面：https://packagist.org/packages/seekgist%2Fseekgist-php
