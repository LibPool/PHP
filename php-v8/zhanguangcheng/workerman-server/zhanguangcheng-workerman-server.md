# zhanguangcheng/workerman-server

> 标签: php, server, workerman

## 简介

用于管理Workerman Worker的PHP类库。它提供了一种简单的方式来启动和管理多个Workerman Worker，同时支持Windows和Linux系统。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
