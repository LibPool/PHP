# aliziodev/midtrans-php

> 标签: midtrans, payment-gateway, payments, php-sdk, qris, snap, snap-bi, unofficial

## 简介

Unofficial PHP SDK for Midtrans API (Snap, Core API, Subscriptions, Payment Link, Invoicing, Snap-BI, and webhook utilities) with retry and idempotency hardening.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
