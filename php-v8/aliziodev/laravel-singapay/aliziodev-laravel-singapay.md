# aliziodev/laravel-singapay

> 标签: disbursement, e-wallet, indonesia, laravel, payment, payment-gateway, qris, singapay, virtual-account, webhook

## 简介

Unofficial Laravel SDK for the SingaPay payment gateway (PT Abadi Singapay Indonesia) — payment links, virtual accounts, QRIS, e-wallet, disbursement, and verified webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
