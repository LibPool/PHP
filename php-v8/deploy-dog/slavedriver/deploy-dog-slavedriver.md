# deploy-dog/slavedriver

> 标签: cron, cronjob, cronjobs, crontab, job, job runner, jobs, scheduled job, scheduled jobs, scheduled task, scheduled tasks, task, task runner

## 简介

A PHP based cron job runner. Manage, monitor, log and react to problems with your scheduled tasks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
