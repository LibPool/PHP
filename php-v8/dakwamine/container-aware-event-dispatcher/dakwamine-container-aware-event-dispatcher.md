# dakwamine/container-aware-event-dispatcher

> 标签: PHP

## 简介

Simple event dispatcher compliant with PSR-14 and using PSR-11 containers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
