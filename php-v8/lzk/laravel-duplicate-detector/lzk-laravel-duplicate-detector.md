# lzk/laravel-duplicate-detector

> 标签: duplicates, eloquent, laravel

## 简介

Configurable, explainable read-only exact and fuzzy duplicate detection for Laravel Eloquent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
