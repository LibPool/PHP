# digitalstars/vk_api

> 标签: Posting, api, auth, bot, buttons, callback, chatbot, client, framework, keyboard, library, longpoll, oauth, php, sdk, vk, vk-api, vk-bot, vk.com, vkontakte, wrapper

## 简介

Powerful PHP library/framework for VK API bots, supporting LongPoll & Callback & OAuth

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
