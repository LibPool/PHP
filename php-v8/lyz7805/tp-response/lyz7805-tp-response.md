# lyz7805/tp-response

> 标签: jump, response, think, thinkphp, tp

## 简介

适配ThinkPHP6.0的响应类，让响应配置、响应内容更简单、更易用

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
