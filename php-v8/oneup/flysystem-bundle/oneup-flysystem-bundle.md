# oneup/flysystem-bundle

> 标签: Flysystem, abstraction, filesystem, symfony

## 简介

Integrates Flysystem filesystem abstraction library to your Symfony project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
