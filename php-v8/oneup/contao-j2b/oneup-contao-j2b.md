# oneup/contao-j2b

> 标签: body, bottom, contao, head, javascript

## 简介

This extension moves all javascript included in <head> just before closing <body>.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
