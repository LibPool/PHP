# mstzn/laravel-activitylog-mongodb

> 标签: activity, laravel, log, spatie, user

## 简介

[MONGODB] A very simple activity logger to monitor the users of your website or application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
