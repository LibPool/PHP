# snugcomponents/firebase

> 标签: SnugComponents, firebase, message, messaging, nette, notification, php, push, snugdesign

## 简介

Nette implementation of Firebase Admin SDK for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
