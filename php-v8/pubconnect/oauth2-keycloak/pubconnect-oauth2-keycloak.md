# pubconnect/oauth2-keycloak

> 标签: authorisation, authorization, client, keycloak, oauth, oauth2

## 简介

Keycloak OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
