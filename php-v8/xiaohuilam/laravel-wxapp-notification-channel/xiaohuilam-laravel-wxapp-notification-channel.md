# xiaohuilam/laravel-wxapp-notification-channel

> 标签: PHP

## 简介

Laravel package to enable wechat mini program template message notification as a channel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
