# open-gaia/ui-bundle

> 标签: ecommerce, shop, store, sylius, ui, user interface, webshop

## 简介

Generic UI bundle for Sylius eCommerce components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
