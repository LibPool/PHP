# yuges-code/laravel-reactable

> 标签: laravel, package, php, reactable, reaction, template, yuges

## 简介

👍 Package for easily attaching reactions to Laravel eloquent models

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
