# yuges-code/php-package-template

> 标签: package, php, template, yuges

## 简介

🚀 Starter template for all Yuges php packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://yuges-code.github.io/php-package-template
- 源码仓库：https://github.com/yuges-code/php-package-template.git
- Packagist 页面：https://packagist.org/packages/yuges-code%2Fphp-package-template

## 获取地址

- Composer 安装：`composer require yuges-code/php-package-template`
- Packagist 仓库：https://repo.packagist.org/p2/yuges-code/php-package-template.json
- 许可证：MIT
- PHP 要求：^8.4
