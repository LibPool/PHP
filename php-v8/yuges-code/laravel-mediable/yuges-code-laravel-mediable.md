# yuges-code/laravel-mediable

> 标签: laravel, mediable, medias, package, php, yuges

## 简介

🎴 Package for easily uploading and attaching media files to Laravel eloquent models

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
