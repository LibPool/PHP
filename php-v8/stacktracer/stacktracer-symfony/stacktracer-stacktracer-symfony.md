# stacktracer/stacktracer-symfony

> 标签: apm, bundle, debugging, error-tracking, exceptions, monitoring, observability, symfony, tracing

## 简介

Lightweight error tracking and tracing SDK for Symfony applications. Capture exceptions, request traces, and performance data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
