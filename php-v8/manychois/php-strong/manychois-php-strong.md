# manychois/php-strong

> 标签: PSR-11, cache, clock, container, event-dispatcher, http-client, http-factory, http-message, link, logger, middleware, psr, psr-13, psr-14, psr-15, psr-16, psr-17, psr-18, psr-20, psr-3, psr-6, psr-7, request-handler, simple-cache, strong-typing

## 简介

A utility library for PHP to help you write strong-typed code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
