# aecil/cirbe

> 标签: PHP

## 简介

Intercambio de informes CIRBE (Central de Informacion de Riesgos del Banco de Espana) en archivos de texto de ancho fijo. Proceso GRI-IE202501-V1.1 (GRIITR/GRIITE).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
