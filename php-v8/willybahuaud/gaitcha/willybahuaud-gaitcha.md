# willybahuaud/gaitcha

> 标签: PHP

## 简介

Frictionless, self-hosted CAPTCHA combining behavioral analysis, random field names, and HMAC tokens.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
