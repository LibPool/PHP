# alexispplin/sendcloud-v3

> 标签: api, client, psr-15, psr-7, psr15, psr7, sendcloud

## 简介

Provides a client to interact with the Sendcloud v3 API in an object-oriented way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
