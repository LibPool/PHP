# xrow/xrowanychart-ls

> 标签: PHP

## 简介

An AnyChart Implementation for eZ Publish. A powertool to create any kind of graphs, diagramms, charts and visual statistics.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
