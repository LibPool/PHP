# wts-calendar/server-php

> 标签: Etag, angular, calendar, calendar-api, calendar-backend, event-management, optimistic-concurrency, php, psr-15, psr-7, react, rest-api, scheduler, scheduling, vue, wts-calendar

## 简介

PSR-7/PSR-15 REST API server for calendar events, scheduling, validation, ETags, and pluggable PHP storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
