# storno/laravel-storno

> 标签: Romania, anaf, e-factura, invoicing, laravel, storno

## 简介

Laravel package for Storno invoicing API — e-Factura, clients, invoices, webhooks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
