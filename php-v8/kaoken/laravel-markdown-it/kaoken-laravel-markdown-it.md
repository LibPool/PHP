# kaoken/laravel-markdown-it

> 标签: laravel, markdown, markdown-it

## 简介

A thing for using PHP version markdown-it in Laravel 6.x.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
