# ambimax/magento-module-ambimax-disablemediaremoval

> 标签: PHP

## 简介

This module adds the ability to disable duplicate media gallery removal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
