# ghi/laravel-intranet-auth

> 标签: auth, ghi, intranet, laravel

## 简介

Paquete para integrar auntenticacion con la intranet de grupo hermes con Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
