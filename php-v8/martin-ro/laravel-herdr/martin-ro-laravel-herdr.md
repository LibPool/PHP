# martin-ro/laravel-herdr

> 标签: Socket, agents, herdr, laravel, multiplexer, terminal

## 简介

A fluent, Laravel-style client for the Herdr terminal workspace socket API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
