# xelax90/zf2-filter-htmlpurifier

> 标签: PHP

## 简介

Requires HTMLPurifier and adds a filter class for InputFilter

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
