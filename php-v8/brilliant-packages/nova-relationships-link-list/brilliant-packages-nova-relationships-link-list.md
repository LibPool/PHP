# brilliant-packages/nova-relationships-link-list

> 标签: laravel, nova

## 简介

A Laravel Nova field to display relationships as a comma-separated list of links, rather than a full table.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
