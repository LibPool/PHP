# amadeco/module-weee-configurable-products

> 标签: PHP

## 简介

Extends Magento Weee module for configurable products to prevent double taxation by adjusting WEEE tax calculation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
