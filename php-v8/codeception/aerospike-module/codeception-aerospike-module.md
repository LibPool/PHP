# codeception/aerospike-module

> 标签: aerospike, codeception, nosql, testing

## 简介

Aerospike Module for Codeception. Integrates Aerospike into Codeception tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
