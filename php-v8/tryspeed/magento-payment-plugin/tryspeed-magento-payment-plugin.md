# tryspeed/magento-payment-plugin

> 标签: PHP

## 简介

Speed is a lightning-network-based bitcoin payment gateway. Use a bitcoin or Lightning wallet to make a payment.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
