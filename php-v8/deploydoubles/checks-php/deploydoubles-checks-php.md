# deploydoubles/checks-php

> 标签: deploy, deploy-report, health, laravel, symfony, verification

## 简介

Generates the Deploy Doubles deploy report (/.well-known/deploy-report) for PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
