# tyto-php/router

> 标签: attributes, middleware, php, router, routing, tyto

## 简介

Roteador minimalista de alta performance em PHP puro com suporte a atributos, middlewares e cache

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
