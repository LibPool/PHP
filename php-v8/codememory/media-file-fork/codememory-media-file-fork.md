# codememory/media-file-fork

> 标签: aac, amr, avi, flac, mp3, mp4, ogg, wav, wma, wmv

## 简介

A unified reader of metadata from audio & video files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
