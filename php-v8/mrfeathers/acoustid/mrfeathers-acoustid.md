# mrfeathers/acoustid

> 标签: Fingerprint, acoustid, api, library, music, php

## 简介

Object Oriented PHP Wrapper for acoustid.org API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
