# innoboxrr/search-surge

> 标签: eloquent, filter, laravel, pagination, query, search

## 简介

Filtrado, ordenamiento y paginacion declarativa para modelos Eloquent. Auto-descubre filtros por convencion, funciona igual dentro de una app o dentro de un paquete de Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
