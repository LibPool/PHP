# innoboxrr/consultant-manager

> 标签: PHP

## 简介

Gestion de consultorias en Laravel: consultores y su disponibilidad, equipos, citas, asesorias, plantillas de expediente y chats de consulta.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
