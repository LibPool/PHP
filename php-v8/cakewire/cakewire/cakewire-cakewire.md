# cakewire/cakewire

> 标签: alpinejs, cakephp, cakephp-plugin, components, full-stack, livewire

## 简介

Live server-driven components for CakePHP powered by Alpine.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
