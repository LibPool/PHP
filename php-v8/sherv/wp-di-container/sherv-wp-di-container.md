# sherv/wp-di-container

> 标签: PSR-11, container, dependency-injection, di, ioc, wordpress

## 简介

PSR-11 compliant dependency injection container for WordPress plugin development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
