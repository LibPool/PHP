# janwebdev/mobile-detect-bundle

> 标签: mobile, mobile detect, mobile redirect, mobile view managing, symfony mobile

## 简介

Symfony5/6/7 bundle for detect mobile devices, managing mobile view types, redirect to mobile version.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
