# janwebdev/feed-io

> 标签: atom, cli, client, feed, jsonfeed, news, rss

## 简介

PHP library built to consume and serve JSONFeed / RSS / Atom feeds

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
