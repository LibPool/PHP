# allovince/evaoauth

> 标签: PHP

## 简介

EvaOAuth is an abstract interface to setup OAuth client, both support OAuth1.0a / OAuth2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
