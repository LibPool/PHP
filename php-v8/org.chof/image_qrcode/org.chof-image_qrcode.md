# org.chof/image_qrcode

> 标签: PHP

## 简介

Port of the Image_QRCode to Packagist from Pear

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/org.chof%2Fimage_qrcode
- 源码仓库：https://github.com/chof747/image_qrcode.git
- Packagist 页面：https://packagist.org/packages/org.chof%2Fimage_qrcode
