# efureev/yii2-noty

> 标签: alert, extension, noty, widget, yii2

## 简介

A Yii2 wrapper widget for the Noty, a noty plugin with jQuery.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
