# efureev/laratrust

> 标签: Teams, acl, authorization, laratrust, laravel, multiusers, permissions, php, rbac, roles

## 简介

This package provides a flexible way to add Role-based Permissions to Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
