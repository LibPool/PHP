# sfelix-martins/json-exception-handler

> 标签: api, exceptions, handler, json, jsonapi, laravel

## 简介

Adds more power to Laravel Exceptions Handler to treat json responses

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
