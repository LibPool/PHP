# logalysm/valide-facture

> 标签: API-Client, EN16931, cii, e-invoicing, factur-x, facture électronique, ubl, validation

## 简介

Client PHP de l'API valide-facture.fr : validation de factures électroniques Factur-X (PDF), CII et UBL (XML), rapport et erreurs typés.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
