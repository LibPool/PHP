# silarhi/tabler-ux-components

> 标签: bootstrap, shadcn, symfony, symfony-ux, tabler, twig, twig-component, ui

## 简介

Tabler-flavored Twig UX components for Symfony, following the shadcn composition pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
