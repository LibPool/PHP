# silarhi/cursor-pagination

> 标签: cursor, cursor-pagination, doctrine, orm, pagination

## 简介

A doctrine ORM cursor based pagination library for faster batch operations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
