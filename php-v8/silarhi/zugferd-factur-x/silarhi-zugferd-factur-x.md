# silarhi/zugferd-factur-x

> 标签: ZUGFeRD, factur-x, xrechnung

## 简介

XML generator for ZUGFeRD / Factur-X / XRechnung written in PHP. Convert PHP Objects to XML and back.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
