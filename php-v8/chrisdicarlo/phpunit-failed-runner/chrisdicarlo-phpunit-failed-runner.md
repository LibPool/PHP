# chrisdicarlo/phpunit-failed-runner

> 标签: chrisdicarlo, phpunit, phpunit-failed-runner, test

## 简介

Run only your failed PHPUnit tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
