# coffeecup/barista

> 标签: apm, error-tracking, laravel, logging, monitoring, observability

## 简介

Ship errors, logs, requests and slow queries from a Laravel application to a self-hosted Barista instance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
