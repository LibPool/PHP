# silviosln/arbor-validator

> 标签: arbor, attributes, cnpj, cpf, dto, php83, validation, validator, zod

## 简介

Biblioteca de validação moderna para PHP 8.3+, agnóstica de framework, combinando a DX do Zod com DTOs tipados e Atributos nativos do PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
