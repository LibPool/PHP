# silviosln/arbor-router

> 标签: app-router, file-system, filesystem, nextjs, php, router, routing

## 简介

Framework-agnostic file-system based routing library for PHP, inspired by Next.js App Router.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
