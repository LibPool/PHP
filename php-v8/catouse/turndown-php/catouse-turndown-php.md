# catouse/turndown-php

> 标签: commonmark, converter, gfm, html, markdown, turndown

## 简介

A configurable HTML-to-Markdown converter for PHP inspired by Turndown

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
