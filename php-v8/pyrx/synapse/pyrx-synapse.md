# pyrx/synapse

> 标签: Synapse, crm, email, pyrx, sdk

## 简介

Official PHP SDK for PYRX Synapse - CRM, email, and event tracking API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
