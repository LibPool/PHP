# talesoft/tale-jade

> 标签: dialect, html, jade, php, phtml, presentation, render, template, views

## 简介

A clean, lightweight and easy-to-use templating engine for PHP based on Jade/Pug

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
