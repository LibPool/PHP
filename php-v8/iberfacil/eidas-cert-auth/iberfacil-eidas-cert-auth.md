# iberfacil/eidas-cert-auth

> 标签: client-certificate, dnie, eidas, fnmt, laravel, lotl, mtls, ocsp, qualified-certificate, trusted-list, tsl, x509, xmldsig

## 简介

Autentica en PHP con certificados eIDAS (FNMT, DNIe y UE), listas de confianza firmadas y revocación. CLI y Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
