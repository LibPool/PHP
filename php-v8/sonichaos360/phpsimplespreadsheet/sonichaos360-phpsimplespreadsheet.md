# sonichaos360/phpsimplespreadsheet

> 标签: PHP

## 简介

Simple but powerful PHP library to generate on-disk XLSX spreadsheets focused in low memory usage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
