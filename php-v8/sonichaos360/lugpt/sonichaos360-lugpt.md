# sonichaos360/lugpt

> 标签: ai, chatbot, gpt, gpt-3.5-turbo, openai

## 简介

A PHP library for interacting with OpenAI's Completions and ChatCompletions API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
