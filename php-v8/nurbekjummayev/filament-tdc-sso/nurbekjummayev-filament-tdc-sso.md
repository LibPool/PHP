# nurbekjummayev/filament-tdc-sso

> 标签: SSO, filament, filament-plugin, laravel, oauth2, pkce, tdc

## 简介

TDC-SSO (OAuth2 Authorization Code + PKCE) login, screen lock and PIN unlock plugin for Filament panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
