# nurbekjummayev/laravel-media-api

> 标签: PHP

## 简介

Standalone media/file upload API for Laravel — upload once, get an id, link it from each model's own table. Private storage with token access and orphan cleanup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
