# nordsoftware/lumen-oauth2

> 标签: laravel, lumen, oauth2

## 简介

OAuth2 module for the Lumen PHP framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
