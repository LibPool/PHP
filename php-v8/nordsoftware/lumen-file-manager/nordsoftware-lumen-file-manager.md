# nordsoftware/lumen-file-manager

> 标签: cloudinary, file, laravel, lumen, manager, s3, upload

## 简介

File manager module for the Lumen framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
