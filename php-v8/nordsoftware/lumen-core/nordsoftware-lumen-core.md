# nordsoftware/lumen-core

> 标签: api, core, ddd, laravel, lumen, rest

## 简介

Core module for our REST API based on Lumen framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
