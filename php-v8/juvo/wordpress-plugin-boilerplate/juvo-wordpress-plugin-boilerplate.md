# juvo/wordpress-plugin-boilerplate

> 标签: PHP

## 简介

A boilerplate for WordPress plugin development. Supercharged with Autoloading, @wordpress/scripts, PHPStan and PHPCS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
