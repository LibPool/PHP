# uupcode/utilities

> 标签: PHP

## 简介

Fluent, expressive utilities for WordPress plugin development — DB, hooks, AJAX, REST,   assets, logging, caching, meta, post types, cron and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
