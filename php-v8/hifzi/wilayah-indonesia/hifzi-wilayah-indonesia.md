# hifzi/wilayah-indonesia

> 标签: administratif, desa, indonesia, kabupaten, kecamatan, kelurahan, kodepos, kota, laravel, provinsi, wilayah

## 简介

Package Laravel untuk data wilayah administratif Indonesia (Provinsi, Kabupaten/Kota, Kecamatan, Desa) lengkap dengan Kodepos. Super cepat dan ringan.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
