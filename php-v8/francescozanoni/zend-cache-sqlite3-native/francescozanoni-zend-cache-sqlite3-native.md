# francescozanoni/zend-cache-sqlite3-native

> 标签: PHP

## 简介

SQLite 3 cache engine for Zend Framework 1, based on native driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
