# rubricate/canvas

> 标签: canvas, crop, filter, gd, image, resize, rubricate, watermark

## 简介

A modern, fluent PHP image manipulation library for canvas operations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
