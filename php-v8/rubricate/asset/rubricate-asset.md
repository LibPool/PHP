# rubricate/asset

> 标签: JS, asset, cache-busting, css, image, rubricate, url, widget

## 简介

An immutable URL asset management component for versioned static files and HTML tag generation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
