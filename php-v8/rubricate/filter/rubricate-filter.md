# rubricate/filter

> 标签: camelcase, filter, rubricate, sanitize, slug, validation

## 简介

A flexible, lightweight, and object-oriented string filtering and sanitization library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
