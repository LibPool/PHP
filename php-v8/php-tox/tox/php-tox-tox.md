# php-tox/tox

> 标签: framework, php, tox

## 简介

An experimental PHP framework based on v5.3.0 or later.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/php-tox/tox
- 源码仓库：https://github.com/snakevil/tox.git
