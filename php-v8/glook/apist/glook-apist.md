# glook/apist

> 标签: api, crawler

## 简介

Package to provide api-like access to foreign sites based on html parsing (fork of sleeping-owl/apist package with updated dependencies)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
