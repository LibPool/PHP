# serixa/framework

> 标签: SSR, components, flutter, html, php, serixa, ui, widgets

## 简介

SERIXA — a Flutter-inspired PHP UI framework. Write PHP widgets, get semantic HTML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
