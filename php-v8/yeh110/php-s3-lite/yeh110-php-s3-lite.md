# yeh110/php-s3-lite

> 标签: RustFS, minio, object-storage, presign, s3, sigv4

## 简介

零第三方依赖的 S3 兼容对象存储客户端（PHP 8.1+），内置 AWS Signature V4

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
