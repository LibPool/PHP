# madnh/laravel-parsley

> 标签: collective, form, html, laravel, laravel 5, parsley, parsleyjs

## 简介

Converts FormRequest rules to Parsley rules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
