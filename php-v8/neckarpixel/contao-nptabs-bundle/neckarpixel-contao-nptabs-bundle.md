# neckarpixel/contao-nptabs-bundle

> 标签: ARIA, a11y, accessibility, contao, tabs, wcag

## 简介

Barrierefreie, responsive Tabs (WAI-ARIA APG, WCAG 2.2 AA) als verschachteltes Inhaltselement für Contao 5.7

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
