# frc/wp-env-heroku-database

> 标签: aws, database, heroku, wordpress

## 简介

Export Heroku environment DATABASE_URL configuration for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
