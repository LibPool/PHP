# frc/wp-env-heroku-sendgrid

> 标签: heroku, sendgrid, wordpress

## 简介

Export Heroku sendgrid addon configuration for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
