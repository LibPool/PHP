# frc/wp-amazon-c3-cloudfront-clear-cache

> 标签: PHP

## 简介

This is simple plugin that clear all cloudfront cache if you publish posts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
