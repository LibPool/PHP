# tea-m-speak-interface/gump

> 标签: filter, validators

## 简介

A fast, extensible & stand-alone PHP input validation class that allows you to validate any data for Tea(m)Speak-Interface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
