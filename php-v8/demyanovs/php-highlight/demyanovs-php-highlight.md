# demyanovs/php-highlight

> 标签: codehighlighter, codehighlighting, php-highlight, php_highlight, syntax-highlighting

## 简介

A PHP library for highlighting code syntax.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
