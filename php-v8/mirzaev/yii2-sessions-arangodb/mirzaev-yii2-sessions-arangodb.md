# mirzaev/yii2-sessions-arangodb

> 标签: ArangoDb, DbSession, yii2

## 简介

Module with yii\web\DbSession implementation for use with ArangoDB

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
