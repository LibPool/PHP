# chiron/pipeline

> 标签: container, handler, lazy, middleware, pipeline, psr11, psr15, request

## 简介

Pipe your PSR15 middlewares and execute the stack. Support a PSR11 Container for Lazy Loading.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
