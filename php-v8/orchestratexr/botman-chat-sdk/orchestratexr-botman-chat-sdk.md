# orchestratexr/botman-chat-sdk

> 标签: Agent, ai, chat, laravel, vue, widget

## 简介

Drop-in chat-widget UI and multi-channel adapter framework on top of the Laravel AI SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
