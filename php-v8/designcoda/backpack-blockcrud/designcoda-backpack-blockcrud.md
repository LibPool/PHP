# designcoda/backpack-blockcrud

> 标签: BlockCRUD, backpack, laravel

## 简介

An admin panel for block items, using Backpack\CRUD on Laravel 7, 8.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
