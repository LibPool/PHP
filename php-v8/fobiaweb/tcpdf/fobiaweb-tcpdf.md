# fobiaweb/tcpdf

> 标签: PDFD32000-2008, TCPDF, barcodes, datamatrix, pdf, pdf417, qrcode

## 简介

TCPDF is a PHP class for generating PDF documents.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
