# reliv/rcm-html-area

> 标签: content, manager, plugin, rcm, reliv

## 简介

A Reliv Content Manager Plugin for editable areas that allows you to add text, images, lists, links and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
