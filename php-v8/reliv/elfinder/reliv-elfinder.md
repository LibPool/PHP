# reliv/elfinder

> 标签: elfinder, module, plugin, zf2

## 简介

Zf2 Module for the ElFinder File Manager.  Includes CKEditor hooks

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
