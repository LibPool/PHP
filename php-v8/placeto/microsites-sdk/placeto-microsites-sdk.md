# placeto/microsites-sdk

> 标签: PHP

## 简介

Software development kit to connect with the Microsites api

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 获取地址

- Packagist 仓库：https://repo.packagist.org/p2/placeto/microsites-sdk.json
- PHP 要求：>=7.4
