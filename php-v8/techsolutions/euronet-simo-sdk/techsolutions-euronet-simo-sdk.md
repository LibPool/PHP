# techsolutions/euronet-simo-sdk

> 标签: bill-pay, laravel, moçambique, pagamentos, referencia, simo

## 简介

Biblioteca Laravel para gestão de pagamentos por entidade e referência (referência SIMO MOD 97-10 e API Validate/Notify Ren).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
