# phpdiscordsdk/phpdiscordsdk

> 标签: php discord bot, phpdiscord, phpdiscordsdk

## 简介

A Light Weight PHP Discord SDK Library to build Discord Bots with Web Panel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
