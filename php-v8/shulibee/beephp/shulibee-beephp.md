# shulibee/beephp

> 标签: PHP

## 简介

A simple framework for php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/SHUlibee/BeePHP
- 源码仓库：https://github.com/SHUlibee/BeePHP.git
- Packagist 页面：https://packagist.org/packages/shulibee%2Fbeephp
