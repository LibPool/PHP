# pou/lumen-opcache-clear

> 标签: Opcache, cache, clear, lumen, reset

## 简介

This package allows you to clear OPcache when running PHP in FPM mode.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
