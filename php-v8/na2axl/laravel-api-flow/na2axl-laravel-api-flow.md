# na2axl/laravel-api-flow

> 标签: api, flow, laravel, multi-step, onboarding, state-machine, wizard

## 简介

Server-driven multi-step API flows for Laravel: declare steps as a state machine, let the API tell clients which steps are legal next.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
