# flow-php/flow-php-ext

> 标签: DataFrame, binary, extension, native, rust, serializer

## 简介

Flow PHP native extension (Rust) - Floe frame-body encoder/decoder for DataFrame Rows

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
