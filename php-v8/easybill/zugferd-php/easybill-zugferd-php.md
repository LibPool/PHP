# easybill/zugferd-php

> 标签: ZUGFeRD, factur-x, xrechnung

## 简介

ZUGFeRD PHP SDK (Factur-X, XRechnung) - Convert PHP Objects to XML and back.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
