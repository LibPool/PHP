# artisan-build/sink-contracts

> 标签: contracts, envelope, laravel, mail, sink

## 简介

The thin, versioned mail capture envelope shared between sink-client and sink-server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
