# artisan-build/tobias

> 标签: Agent, ai, cli, coding, console, laravel-zero, tui

## 简介

Tobias — an agentic terminal coding assistant. Globally installable as `toby`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
