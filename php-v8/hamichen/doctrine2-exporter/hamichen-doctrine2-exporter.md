# hamichen/doctrine2-exporter

> 标签: cli, database, doctrine, mysql, mysql workbench

## 简介

MySQL Workbench Schema Exporter for Doctrine 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
