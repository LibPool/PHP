# wpboilerplate/wordpress-plugin-boilerplate

> 标签: donations, plugin, wordpress

## 简介

Composer to autoload the condition checking for which this add-on is made

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
