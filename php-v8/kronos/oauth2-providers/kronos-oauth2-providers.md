# kronos/oauth2-providers

> 标签: kronos, oauth2, oauth2-client, provider

## 简介

Kronos OAuth2 providers for https://github.com/thephpleague/oauth2-client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
