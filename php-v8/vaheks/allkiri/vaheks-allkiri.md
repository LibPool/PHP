# vaheks/allkiri

> 标签: asice, bdoc, digidoc, digital-signature, eID, eidas, estonia, id-card, mobile-id, smart-id, web-eid, xades

## 简介

Estonian eID for PHP: authenticate and digitally sign with ID-card (Web eID), Mobile-ID and Smart-ID; create and validate ASiC-E / XAdES-LT(A) containers compatible with DigiDoc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
