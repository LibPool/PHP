# lolautruche/embedtag-ls

> 标签: PHP

## 简介

Collection of custom tags for eZ Publish, to embed external content like from YouTube, DailyMotion or Vimeo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
