# jbtronics/dompdf-font-loader-bundle

> 标签: dompdf, fonts, symfony, symfony-bundle

## 简介

A symfony bundle to easily load custom fonts for dompdf (on cache warming)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
