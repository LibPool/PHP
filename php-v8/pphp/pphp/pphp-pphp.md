# pphp/pphp

> 标签: compiler, language, php, pphp, preprocessor, static-typing, transpiler, typescript

## 简介

Un préprocesseur PHP avec typage statique obligatoire, exécuté à la volée.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
