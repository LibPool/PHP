# neosrulez/hybridauth

> 标签: PHP

## 简介

A Neos CMS plugin which enables login with Google, Github and Facebook to the Neos CMS backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
