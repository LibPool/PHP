# neosrulez/cookieconsent

> 标签: PHP

## 简介

A Neos CMS plugin to integrate the Cookie Banner from cookieconsent.insites.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
