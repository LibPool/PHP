# neosrulez/bootstrap-gallery

> 标签: PHP

## 简介

Extends the NeosRulez.Bootstrap Gallery NodeType by a pagination.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
