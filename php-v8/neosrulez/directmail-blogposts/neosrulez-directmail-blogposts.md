# neosrulez/directmail-blogposts

> 标签: PHP

## 简介

A package to embed NeosRulez.Blog blog posts in NeosRulez.Newsletter newsletter

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
