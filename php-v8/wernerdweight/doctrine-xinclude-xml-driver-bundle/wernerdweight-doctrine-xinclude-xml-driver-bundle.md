# wernerdweight/doctrine-xinclude-xml-driver-bundle

> 标签: bundle, doctrine, driver, xinclude, xml

## 简介

Symfony bundle providing XInclude support for XML mapping of Doctrine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
