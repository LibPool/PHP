# wernerdweight/cors-bundle

> 标签: Cross-Origin Resource Sharing, bundle, cors, headers

## 简介

Symfony bundle that handles cross-origin resource sharing headers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
