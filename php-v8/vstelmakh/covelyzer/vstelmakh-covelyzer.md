# vstelmakh/covelyzer

> 标签: analyzer, cli, console, coverage, phpunit, report, test

## 简介

Tool to analyze PHPUnit test coverage report in clover format

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
