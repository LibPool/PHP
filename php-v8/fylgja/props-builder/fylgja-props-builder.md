# fylgja/props-builder

> 标签: css, custom properties, design-tokens, figma-tokens, fylgja, scss, style-dictionary, variables

## 简介

Effortlessly generate Design Tokens (CSS custom properties) from PHP arrays or JSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
