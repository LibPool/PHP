# chewei05/laravel-adminlte-lang

> 标签: PHP

## 简介

Traditional Chinese (zh-TW) Language for Laravel-AdminLTE with Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
