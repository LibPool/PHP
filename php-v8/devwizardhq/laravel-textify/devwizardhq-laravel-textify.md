## 简介

🚀 Enterprise-ready Laravel SMS package supporting 8+ providers including Bangladeshi (DhorolaSMS, BulkSMSBD, MimSMS, eSMS, REVE SMS, Alpha SMS) & international gateways (Twilio, Nexmo). Features automatic fallback, queue integration, activity tracking, balance checking, and fluent API for production-grade SMS solutions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
