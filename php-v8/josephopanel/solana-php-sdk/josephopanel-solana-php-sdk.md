# josephopanel/solana-php-sdk

> 标签: blockchain, json-rpc, php-sdk, solana, web3

## 简介

A PHP SDK for interacting with the Solana blockchain via JSON RPC and WebSocket methods.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
