# gourmet/robo

> 标签: Tasks, build, cakephp, plugin, robo, shell

## 简介

A simple shell to wrap around codegyre/robo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
