# gourmet/twitter_bootstrap

> 标签: bootstrap, cakephp, twitter

## 简介

Twitter Bootstrap 3 support for CakePHP 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
