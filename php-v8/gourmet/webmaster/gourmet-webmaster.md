# gourmet/webmaster

> 标签: cakephp, gourmet, plugin, webmaster

## 简介

Gourmet Webmaster Plugin for rapid CakePHP application development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
