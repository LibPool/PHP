# dr4g0nsr/sitemap-crawler

> 标签: PHP

## 简介

Crawler for any type of site using robots.txt and sitemap.xml as the source of URL. Useful for cache regenerating.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
