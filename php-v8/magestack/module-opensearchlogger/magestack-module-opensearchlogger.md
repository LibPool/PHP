# magestack/module-opensearchlogger

> 标签: PHP

## 简介

This Magento 2 module provides a mechanism to store a copy of your application logs into opensearch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
