# feast/json

> 标签: PHP

## 简介

Standalone JSON marshaller based off the one built into FEAST framework at feast/feast

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 源码仓库：https://github.com/FeastFramework/json.git
