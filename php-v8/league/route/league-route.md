# league/route

> 标签: PSR-15, dispatcher, league, psr-15, psr-7, psr15, psr7, route, router, 路由

## 简介

Fast routing and dispatch component including PSR-15 middleware, built on top of FastRoute.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
