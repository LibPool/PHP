> 标签: data-uri, file-uri, ftp, hostname, http, https, parse_str, parse_url, psr-7, query-string, querystring, rfc3986, rfc3987, rfc6570, uri, url, ws

## 简介

Common tools for parsing and resolving RFC3987/RFC3986 URI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
