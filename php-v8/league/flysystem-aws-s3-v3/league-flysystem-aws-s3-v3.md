# league/flysystem-aws-s3-v3

> 标签: Flysystem, S3, aws, file, files, filesystem, s3, storage, 文件系统

## 简介

AWS S3 filesystem adapter for Flysystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
