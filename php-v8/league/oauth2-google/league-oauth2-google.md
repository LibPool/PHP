# league/oauth2-google

> 标签: Authentication, Google, OAuth2, authorization, client, google, oauth, oauth2

## 简介

Google OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
