# league/flysystem-ftp

> 标签: FTP, Flysystem, file, files, filesystem, ftp, ftpd, 文件系统

## 简介

FTP filesystem adapter for Flysystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
