# league/flysystem-read-only

> 标签: Flysystem, Read-Only, filesystem, only, read, 只读, 文件系统

## 简介

Read-only filesystem adapter for Flysystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
