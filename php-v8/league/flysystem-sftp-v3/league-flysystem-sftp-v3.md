# league/flysystem-sftp-v3

> 标签: Flysystem, SFTP, file, files, filesystem, sftp, 文件系统

## 简介

SFTP filesystem adapter for Flysystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
