# dmamontov/ms-restapi

> 标签: api, client, crm, moy sklad, ms, rest

## 简介

PHPClient to work with through Moy Sklad Rest API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
