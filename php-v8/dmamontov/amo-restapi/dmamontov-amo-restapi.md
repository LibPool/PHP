# dmamontov/amo-restapi

> 标签: amoCRM, api, client, crm, rest

## 简介

PHPClient to work with through AmoCRM Rest API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
