# dmamontov/symfony-phpcron

> 标签: cron, crontab, daemon

## 简介

Daemon to run tasks scheduled cron written in php, works similar to crontab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
