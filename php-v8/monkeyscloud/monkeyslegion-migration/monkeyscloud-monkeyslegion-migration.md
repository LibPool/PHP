# monkeyscloud/monkeyslegion-migration

> 标签: PHP

## 简介

Entity-schema diff engine, SQL migration runner, and dialect-aware DDL generation for MonkeysLegion v2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
