# monkeyscloud/monkeyslegion-encryption

> 标签: PHP

## 简介

Standalone encryption for MonkeysLegion v2 — AES-GCM, XChaCha20, HMAC, key rotation, envelope encryption, PHP 8.4 hooks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
