# monkeyscloud/monkeyslegion

> 标签: PHP

## 简介

High-performance PHP 8.4 framework — attribute-first architecture, property hooks, compiled DI, MLC configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
