# monkeyscloud/monkeyslegion-apex

> 标签: PHP

## 简介

AI Orchestration Engine for PHP 8.4 — Multi-model routing, pipelines, guardrails, structured output, and agents in one package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
