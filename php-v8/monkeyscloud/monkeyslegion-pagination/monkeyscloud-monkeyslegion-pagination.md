# monkeyscloud/monkeyslegion-pagination

> 标签: PHP

## 简介

ORM-agnostic offset + cursor pagination — PHP 8.4 property hooks, RFC 8288 Link headers, JSON:API links, configurable envelopes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
