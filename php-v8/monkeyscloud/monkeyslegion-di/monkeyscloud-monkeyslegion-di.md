# monkeyscloud/monkeyslegion-di

> 标签: PHP

## 简介

Production-ready PSR-11 container for MonkeysLegion — auto-wiring, attributes, compiled container.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
