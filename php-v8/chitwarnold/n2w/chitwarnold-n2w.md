# chitwarnold/n2w

> 标签: PHP

## 简介

PHP Library for Spelling Numbers into Words. Give it an integer value like 50, and it returns the words Fifty

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
