# bd-payments/laravel-payment-gateway

> 标签: bangladesh, binance, bkash, gateway, laravel, nagad, payment, php

## 简介

A comprehensive Laravel 12 package for Nagad, bKash, and Binance payment gateways integration with PHP 8.4+ support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
