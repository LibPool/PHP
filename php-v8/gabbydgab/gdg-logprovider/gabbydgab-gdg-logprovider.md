# gabbydgab/gdg-logprovider

> 标签: log parsing, zf2 module

## 简介

Abstract application that provides log information in an ETL process such as data logs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
