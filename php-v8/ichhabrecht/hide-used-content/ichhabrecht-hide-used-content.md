# ichhabrecht/hide-used-content

> 标签: ColPos, TCA, TYPO3 CMS, content, extension

## 简介

Removes used content elements with own colPos configuration from "Unused" column

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
