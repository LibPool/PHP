# ichhabrecht/core-upgrader

> 标签: TYPO3 CMS, extension, update, upgrade, wizards

## 简介

Run upgrade wizards for multiple TYPO3 versions at once

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
