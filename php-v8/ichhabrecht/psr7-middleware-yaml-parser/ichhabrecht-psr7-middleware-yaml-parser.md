# ichhabrecht/psr7-middleware-yaml-parser

> 标签: middleware, psr-7, yaml

## 简介

PSR-7 middleware that parses Yaml files to ServerRequest attribute

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
