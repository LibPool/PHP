# uthando-cms/uthando-dompdf

> 标签: dompdf, pdf, zf2

## 简介

A Zend Framework 2 module for incorporating DOMPDF support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
