# sungmee/laravel-payment

> 标签: laravel, packages, payment

## 简介

『LaraPay』是为 Laravel 量身定制的 第三方支付 扩展包，可根据第三方支付平台提供的 API 接口，无限扩展本包支持的平台。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
