# lia/lia_imageserver

> 标签: ImageServer, Imageserver Adapter, adapter

## 简介

TYPO3 extension with ViewHelpers for responsive images, supporting external image servers but fully functional on its own.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
