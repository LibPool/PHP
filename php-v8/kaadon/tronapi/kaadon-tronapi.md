# kaadon/tronapi

> 标签: kaadon, tron-api, tron-lib, tron-php, tron-rest-api, tron-service, tronapi, tronservice

## 简介

A PHP API for interacting with Tron (Trx)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
