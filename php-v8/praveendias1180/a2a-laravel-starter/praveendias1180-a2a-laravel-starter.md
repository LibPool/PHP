# praveendias1180/a2a-laravel-starter

> 标签: a2a, a2a-protocol, agent2agent, ai-agents, laravel, starter, template

## 简介

A Laravel app that is already an A2A (Agent2Agent) agent. Clone it, run it, and replace the example agent with your own.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
