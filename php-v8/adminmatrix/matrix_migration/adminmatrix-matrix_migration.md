# adminmatrix/matrix_migration

> 标签: PHP

## 简介

基于 Phinx 的数据库迁移工具，支持 ThinkPHP 框架，提供数据库版本控制和迁移管理功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
