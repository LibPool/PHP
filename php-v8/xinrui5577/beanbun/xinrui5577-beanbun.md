# xinrui5577/beanbun

> 标签: crawler, scraper, spider

## 简介

老版本2018年4月份没有维护了.有bug,自己fork分支,自己维护,原来:Beanbun 是用 PHP 编写的多进程网络爬虫框架，具有良好的开放性、高可扩展性

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
