# opsofts/laravel-flutterwave

> 标签: flutterwave, laravel, payments

## 简介

A minimal Flutterwave integration for Laravel, built directly on Laravel's own HTTP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
