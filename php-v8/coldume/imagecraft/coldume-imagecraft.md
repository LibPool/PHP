# coldume/imagecraft

> 标签: animation, gd, image, resize, thumbnail, watermark

## 简介

A reliable and extensible PHP image manipulation library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
