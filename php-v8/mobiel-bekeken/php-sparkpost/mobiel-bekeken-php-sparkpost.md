# mobiel-bekeken/php-sparkpost

## 简介

Fork of sparkpost/sparkpost. With PHP 8.0 fixes with credits to omarlopesino. Client library for interfacing with the SparkPost API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
