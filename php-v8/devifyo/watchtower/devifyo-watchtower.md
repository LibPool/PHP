# devifyo/watchtower

> 标签: dashboard, exceptions, horizon, laravel, monitoring, queue, scheduler, telescope

## 简介

Production-safe, driver-agnostic dashboard for Laravel crons, queues and errors — that also lets you fix them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
