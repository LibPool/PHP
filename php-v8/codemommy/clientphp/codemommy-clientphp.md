# codemommy/clientphp

> 标签: ClientPHP, CodeMommy, php

## 简介

CodeMommy ClientPHP is a client helper for web development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.codemommy.com
- 源码仓库：https://github.com/CodeMommy/ClientPHP.git
- Packagist 页面：https://packagist.org/packages/codemommy%2Fclientphp

## 获取地址

- Composer 安装：`composer require codemommy/clientphp`
- Packagist 仓库：https://repo.packagist.org/p2/codemommy/clientphp.json
- 许可证：Apache 2.0
- PHP 要求：>=5.3.0
