# wecoprod/atproto-oauth-bundle

> 标签: atproto, bluesky, dpop, oauth, symfony, symfony-bundle

## 简介

Symfony bundle for AT Protocol (Bluesky) OAuth: confidential client with DPoP, PAR, PKCE and private_key_jwt

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
