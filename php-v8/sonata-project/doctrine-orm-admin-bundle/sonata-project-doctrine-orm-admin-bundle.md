# sonata-project/doctrine-orm-admin-bundle

> 标签: admin, admin-generator, bundle, doctrine, orm, sonata, symfony

## 简介

Integrate Doctrine ORM into the SonataAdminBundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
