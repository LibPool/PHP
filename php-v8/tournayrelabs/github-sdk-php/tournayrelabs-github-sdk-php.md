# tournayrelabs/github-sdk-php

> 标签: api, github, openapi, php, rest, sdk

## 简介

PHP SDK for the GitHub REST API, automatically generated from the official OpenAPI specification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
