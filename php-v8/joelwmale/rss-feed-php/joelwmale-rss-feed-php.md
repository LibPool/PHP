# joelwmale/rss-feed-php

> 标签: feed, php, rss

## 简介

RSS Feeds for PHP is a very small, lightweight, and easy-to-use library for consuming an RSS feed.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
