# blutrixx/generator-engine

> 标签: code-generator, crud, laravel, module, scaffolding, vue

## 简介

Module code generator engine for Laravel + Vue 3 + NativePHP Mobile. Generates backend modules, frontend pages, and mobile backend with offline sync -- CRUD, actions, and delegations -- from a config-array specification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
