# ownego/laravel-shopify-currency

> 标签: converter, currencty, laravel, shopify

## 简介

Currency converter using Shopify's currencies cdn file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
