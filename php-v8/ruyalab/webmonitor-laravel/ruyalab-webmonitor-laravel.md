# ruyalab/webmonitor-laravel

> 标签: health-check, laravel, monitoring, uptime, webmonitor

## 简介

Connect a Laravel app to Web Monitor (webmonitor.ruyalab.com): uptime, performance, SEO and security checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
