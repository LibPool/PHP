# ruyalab/webmonitor-codeigniter

> 标签: codeigniter, codeigniter4, health-check, monitoring, uptime, webmonitor

## 简介

Connect a CodeIgniter 4 app to Web Monitor (webmonitor.ruyalab.com): uptime, performance, SEO and security checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
