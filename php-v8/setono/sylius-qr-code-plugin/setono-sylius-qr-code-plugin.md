# setono/sylius-qr-code-plugin

> 标签: qr, qr-code, sylius, sylius-plugin

## 简介

QR code generation, management, and scan tracking plugin for Sylius.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
