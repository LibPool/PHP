# setono/quickpay-php-sdk

> 标签: API-Client, callback, payment, payment-gateway, payments, psr-18, quickpay, sdk, webhook

## 简介

PHP SDK for the Quickpay API: payments, payment-window links, and signed callback (webhook) verification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
