# basttyy/reactphp-orm

> 标签: async, database, orm, reactphp

## 简介

A database OMR for ReactPHP based on illuminate/database and react/mysql packages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
