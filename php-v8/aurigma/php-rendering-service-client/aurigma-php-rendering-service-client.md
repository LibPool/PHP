# aurigma/php-rendering-service-client

> 标签: Rendering, api client, customers canvas, web-to-print

## 简介

PHP API Client for Rendering service of Customer's Canvas web-to-print system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
