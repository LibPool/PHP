# anvilm/iva

> 标签: PHP

## 简介

CLI framework for PHP 8.4+ with a real command tree, strongly typed input DTOs, GNU/POSIX-style option parsing, and a section/progress-bar/spinner output model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
