# sinstry/yiilite-core

> 标签: PHP

## 简介

将yii2框架中最核心的面向对象和组件思想的代码剥离出来，便于在其它项目中复用

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
