# uzapoint/reporting-contracts

> 标签: contracts, dto, laravel-data, microservices, reporting, uzapoint

## 简介

UzaPoint reporting contracts: the typed snapshot and event payloads every microservice publishes to the Reports service. Owns WHAT UzaPoint reports; sammy-boy/laravel-reporting owns HOW it is published.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
