# k1sul1/woocommerce-installment-gateway

> 标签: PHP

## 简介

WooCommerce plugin that adds a new payment gateway meant for paying in parts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
