# axepress/wp-graphql-cs

> 标签: phpcs, standards, static analysis, wordpress, wpcs, wpgraphql

## 简介

PHP_CodeSniffer rules (sniffs) for the WPGraphQL ecosystem.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
