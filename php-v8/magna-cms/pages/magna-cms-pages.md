# magna-cms/pages

> 标签: blocks, cms, drag-and-drop, filament, laravel, magna, page-builder, visual-editor

## 简介

Rendered-frontend plugin for Magna CMS: pages, templates, menus, and the visual site builder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
