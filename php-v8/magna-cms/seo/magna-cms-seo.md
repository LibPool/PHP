# magna-cms/seo

> 标签: Sitemap, cms, laravel, magna, magna-cms, open-graph, plugin, schema, seo, structured-data

## 简介

SEO for Magna CMS — one meta layer for rendered HTML and the delivery API: titles, descriptions, canonicals, robots, Open Graph, Twitter, JSON-LD, sitemaps and redirects, correct by construction.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
