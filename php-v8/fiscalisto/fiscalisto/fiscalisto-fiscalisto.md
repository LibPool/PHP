# fiscalisto/fiscalisto

> 标签: cfdi, factura, facturacion, fiscalisto, mexico, sat, timbrado

## 简介

SDK de la API de facturación electrónica (CFDI 4.0) de Fiscalisto, para PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://fiscalisto.com/docs/api/sdk/php
- 源码仓库：https://github.com/fiscalisto/fiscalisto-php.git
