# egeniq/monolog-gdpr

> 标签: avg, gdpr, log, logger, monolog, processor

## 简介

Some Monolog processors that will help in relation to the security requirements under GDPR.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
