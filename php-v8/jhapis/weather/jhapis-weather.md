# jhapis/weather

> 标签: environment, weather, 天气, 预报

## 简介

整合多平台天气类查询接口、天气预报、空气质量、历史天气、极端天气预警

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
