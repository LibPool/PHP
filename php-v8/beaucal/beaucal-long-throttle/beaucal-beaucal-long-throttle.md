# beaucal/beaucal-long-throttle

> 标签: throttle, zf2

## 简介

Prevent an action for some long amount of time. Hours, day, months, years.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
