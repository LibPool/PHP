# beaucal/beaucal-array-reduce

> 标签: array_reduce, reduce

## 简介

Handy array-reduce functions, like 'are all matching', 'is one matching', 'first matching'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
