# ocus/laravel-launchdarkly

> 标签: Ocus, laravel, laravel-launchdarkly

## 简介

Wrap of the package launchdarkly/server-sdk for laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
