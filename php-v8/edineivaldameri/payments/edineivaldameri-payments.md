# edineivaldameri/payments

> 标签: LaravelPagamento, laravel, payments

## 简介

Pacote para gerar a Folha de Pagamento, remessas e leitura de retorno.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
