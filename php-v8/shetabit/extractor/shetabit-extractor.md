# shetabit/extractor

> 标签: api client, api extractor, api remote client, extractor, micro service, micro service client, micro service data extractor, remote micro service, shetabit

## 简介

a `micro client` generator to communicate between `micro services` in laravel apps

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
