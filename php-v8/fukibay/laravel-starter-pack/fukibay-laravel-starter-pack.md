# fukibay/laravel-starter-pack

> 标签: laravel, pattern, repository, scaffolding, service, starter

## 简介

Starter pack: minimal scaffolding helpers for new Laravel projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
