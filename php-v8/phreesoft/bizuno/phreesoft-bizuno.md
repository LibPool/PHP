# phreesoft/bizuno

> 标签: Accounting, ERP, bizuno, crm, phreesoft, web

## 简介

Bizuno is a full featured web based ERP/Accouting library written in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
