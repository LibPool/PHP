# mediashare/marathon

> 标签: Developer tools, Time Management, command line, commit history, list, marathon, productivity, projects, task, task management, time, time tracking, timer, todo, todo-list, version control, workflow

## 简介

Marathon is a command-line tool written in PHP and Symfony that empowers you to efficiently manage times from tasks for your projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
