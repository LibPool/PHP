# mediashare/show-content

> 标签: PHP

## 简介

Detect file type & generate html view for web interface user-friendly. (Image/Video/Audio/Text/Markdown)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
