# lunr/gravity

> 标签: database, mariadb, mysql, sql, sqlite

## 简介

Lunr.Gravity is a database library that doesn't limit functionality to the least common denominator.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
