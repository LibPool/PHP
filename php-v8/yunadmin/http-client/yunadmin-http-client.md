# yunadmin/http-client

> 标签: curl, http, http-client, middleware, php

## 简介

零依赖轻量级 HTTP 客户端类库，支持 cURL/Stream 双引擎、中间件、重定向、重试、JSON/FORM 表单、文件上传。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
