# yunadmin/yunstorage

> 标签: aliyun, baidu, bos, cos, object-storage, oss, qiniu, storage, tencent

## 简介

无 SDK 依赖的多云对象存储类库，支持阿里云 OSS (V4)、腾讯云 COS (V5)、七牛云 Kodo、百度云 BOS (V2)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
