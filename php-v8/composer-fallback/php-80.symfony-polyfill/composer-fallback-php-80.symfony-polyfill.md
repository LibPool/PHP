# composer-fallback/php-80.symfony-polyfill

> 标签: composer, default, fallback, php 8.0

## 简介

Satisfy "php 8.0" with packages provided by user, or fallback to "symfony-polyfill".

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
