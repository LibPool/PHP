# composer-fallback/intl.symfony-polyfill

> 标签: composer, default, fallback, intl

## 简介

Satisfy "intl" with packages provided by user, or fallback to "symfony-polyfill".

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
