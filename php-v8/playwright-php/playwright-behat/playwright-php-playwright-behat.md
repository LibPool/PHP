# playwright-php/playwright-behat

> 标签: Behat, behat-extension, browser, e2e, playwright, playwright-php

## 简介

Behat extension powered by Playwright PHP (Chromium/Firefox/WebKit).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
