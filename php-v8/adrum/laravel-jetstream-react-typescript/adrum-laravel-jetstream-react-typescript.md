# adrum/laravel-jetstream-react-typescript

> 标签: framework, laravel

## 简介

A starter kit for the Laravel framework using Jetstream, Inertia.js, React (TS), and HeadlessUI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
