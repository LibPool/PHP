# clientbg/php-boiler-pipe

> 标签: extract, html

## 简介

PhpBoilerPipe. Boilerplate Removal and Fulltext Extraction from HTML pages. Based on dotpack's PHP implementation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
