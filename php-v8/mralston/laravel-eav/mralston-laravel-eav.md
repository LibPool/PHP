# mralston/laravel-eav

> 标签: entity attribute value, laravel, mralston

## 简介

Implements the Entity-Attribute-Value pattern to supplement Eloquent with adhoc attributes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
