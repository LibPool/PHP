# mralston/trustpilot

> 标签: PHP

## 简介

A PHP/Laravel client for the Trustpilot API built on saloonphp/saloon with Laravel provider, facade, webhook handlers, and Pest tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
