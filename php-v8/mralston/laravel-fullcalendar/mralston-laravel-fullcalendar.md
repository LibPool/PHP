# mralston/laravel-fullcalendar

> 标签: PHP

## 简介

Laravel helper for FullCalendar.io. Forked from maddhatter/laravel-fullcalendar

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
