# mralston/diagnostics

> 标签: Broadcasting, checks, diagnostics, laravel, quality, queue, validation

## 简介

Run a suite of named checks against any Eloquent model, in parallel on the queue, with live progress, stored results and a drop-in Vue panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
