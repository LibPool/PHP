# davgothic/smushit

> 标签: image-optimization, smushit

## 简介

SmushIt is a PHP client for the popular Yahoo! image compression web service Smush.it

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
