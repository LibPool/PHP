# aoeng/laravel-binance

> 标签: BitMEX, Huobi, OKEX, binance, kucoin, kumex

## 简介

Binance API Like the official document interface, Support for arbitrary extension.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
