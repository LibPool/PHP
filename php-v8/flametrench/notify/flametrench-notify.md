# flametrench/notify

> 标签: flametrench, inbox, notification, notify

## 简介

Notification primitive for Flametrench: per-recipient, read-stateful notification records. Spec-conformant per ADR 0022.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
