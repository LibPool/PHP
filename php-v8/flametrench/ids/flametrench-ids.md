# flametrench/ids

> 标签: flametrench, id, identifier, uuid, uuidv7

## 简介

Prefixed wire-format IDs for Flametrench. UUIDv7 storage, self-describing public identifiers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
