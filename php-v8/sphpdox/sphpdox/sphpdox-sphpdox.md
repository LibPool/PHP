# sphpdox/sphpdox

> 标签: documentation, phpdoc, rst, sphinx

## 简介

PHPDoc to Sphinx phpdomain tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
