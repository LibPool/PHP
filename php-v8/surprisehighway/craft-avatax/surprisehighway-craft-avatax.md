# surprisehighway/craft-avatax

> 标签: AvaTax, Craft, cms, craft-plugin, craftcms

## 简介

Calculate and add sales tax to an order's base tax using Avalara's Avatax service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
