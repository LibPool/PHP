# long/guanzy

> 标签: Guanzy, adr, fast-route, framework, middleware, psr, router, sinpe, slim

## 简介

Guanzy Framwork, It is a simple PHP web framwork with ADR and PSR.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
