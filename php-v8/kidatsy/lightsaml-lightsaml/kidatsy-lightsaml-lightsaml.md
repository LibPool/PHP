# kidatsy/lightsaml-lightsaml

> 标签: SAML 2.0, Single Logout, Single SignOn, library, lightSAML, php

## 简介

Clone of Light SAML 2.0 PHP library, enabling PHP 5.6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
