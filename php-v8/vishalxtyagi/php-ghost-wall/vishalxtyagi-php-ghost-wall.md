# vishalxtyagi/php-ghost-wall

> 标签: PHP

## 简介

A package for monitoring code integrity, alerting on tampering, and sending server information on boot.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
