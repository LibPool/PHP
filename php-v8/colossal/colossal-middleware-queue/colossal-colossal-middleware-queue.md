# colossal/colossal-middleware-queue

> 标签: middleware, psr-15

## 简介

A PSR-15 middleware allowing multiple other PSR-15 middleware to be treated as a single entity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
