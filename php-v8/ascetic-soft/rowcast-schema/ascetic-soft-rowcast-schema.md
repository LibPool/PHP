# ascetic-soft/rowcast-schema

> 标签: database, migrations, pdo, php, rowcast, schema, yaml

## 简介

Schema-first migration tool for PDO databases, friendly to Rowcast

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
