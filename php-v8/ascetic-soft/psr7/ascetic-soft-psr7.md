# ascetic-soft/psr7

> 标签: http, message, psr-17, psr-7, request, response, stream, uri

## 简介

A lightweight, performance-optimized PSR-7 and PSR-17 implementation for PHP 8.4+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
