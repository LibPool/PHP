# chaloman/tonal-php

> 标签: chords, intervals, keys, midi, modes, music, notes, scales, theory, tonal

## 简介

PHP port of Tonal.js - A music theory library for notes, intervals, chords, scales, and more

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
