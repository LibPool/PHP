# jbboehr/perfidious

> 标签: libpfm, perf, perf_events, performance, pfm, profiling, windows

## 简介

PHP extension providing access to Linux, Windows, and macOS performance counters

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
