# ion/php-trans-porter

> 标签: PHP 5.6, back-porter, backporter, php, php 7.0, php 7.1, php 7.2, php converter, php trans porter, php transporter, source converter, trans porter, transporter

## 简介

A PHP command-line utility and class library to convert source code between PHP 5.6 / 7.0 / 7.1 / 7.2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
