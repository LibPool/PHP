# kefyusuf/laravel-shard

> 标签: database, distributed, laravel, multi-tenant, redis, scaling, sharding

## 简介

Modular database sharding for Laravel: deterministic shard routing with optional Redis map and shard-aware queues.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
