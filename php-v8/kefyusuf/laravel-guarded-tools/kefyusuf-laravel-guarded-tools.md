> 标签: agents, ai, laravel, laravel-ai, multi-tenancy, packstub, security, testing

## 简介

Guarded tools and assurance tests for Laravel AI agents: workspace isolation, honest failures and evidence on every tool call.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
