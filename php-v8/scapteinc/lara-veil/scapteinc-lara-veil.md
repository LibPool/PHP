# scapteinc/lara-veil

> 标签: cms, extensibility, hooks, laravel, media, plugin, theme

## 简介

A WordPress-like extensibility system for Laravel applications with dynamic plugin and theme loading

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
