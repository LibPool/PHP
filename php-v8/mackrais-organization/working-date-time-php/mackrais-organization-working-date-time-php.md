# mackrais-organization/working-date-time-php

> 标签: business-days, business-hours, calendar, date, datetime, non-working-days, shift-management, task-scheduler, time, weekends, work-schedule, working-date-time, working-time

## 简介

A PHP library for working date-time calculations that considers working hours, weekends, and holidays.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
