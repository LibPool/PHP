# weldist/spatie-medialibrary-doctor

> 标签: cleanup, laravel, media, medialibrary, missing-files, spatie

## 简介

Finds spatie/laravel-medialibrary media rows without a file and files without a media row, and safely removes them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
