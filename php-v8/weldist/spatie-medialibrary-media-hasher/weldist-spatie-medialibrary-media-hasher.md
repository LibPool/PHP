# weldist/spatie-medialibrary-media-hasher

> 标签: checksum, dhash, hash, laravel, medialibrary, perceptual-hash, spatie

## 简介

Computes one or more hashes (checksum, perceptual) of every file added to spatie/laravel-medialibrary and stores them in the media custom properties.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
