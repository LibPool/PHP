# weldist/laravel-passport-client-scopes

> 标签: client-credentials, insufficient-scope, laravel, oauth2, passport, scopes

## 简介

Per-client default scopes and RFC 6750 bearer challenges for Laravel Passport client credentials tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
