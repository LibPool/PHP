# boxberry-delivery/php-api-common

> 标签: api, boxberry, boxberry-api, boxberry-delivery, delivery, delivery-api

## 简介

Базовые компоненты для работы с Boxberry API на PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
