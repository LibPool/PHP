# mikk150/yii2-asset-manager-flysystem

> 标签: Flysystem, assetmanager, cdn, extension, yii2

## 简介

yii2 asset manager that uploads assets to flysystem

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
