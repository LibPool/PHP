# rahulmukati/hetzner-dns

> 标签: dns, free dns, hetzner, hetzner cloud, hetzner dns, php dns

## 简介

All new and simple Hetzner DNS library for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
