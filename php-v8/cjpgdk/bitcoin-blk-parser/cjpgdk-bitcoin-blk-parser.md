# cjpgdk/bitcoin-blk-parser

> 标签: bitcoin, blk file, btc, parser, reader

## 简介

A simple Bitcoin BLK block file parser/reader.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
