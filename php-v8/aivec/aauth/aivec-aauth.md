# aivec/aauth

> 标签: PHP

## 简介

Domain/SKU client-side authentication for a 継続課金 plugin/theme purchase. Client variant to server-side plugin ninsho-validator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
