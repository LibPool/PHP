# develpr/phindle

> 标签: book, ebook, kindle, mobi, ncx, opf

## 简介

Creates full featured opf/ncx files for Kindle (mobi) ebooks and allows for images and other static resources

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
