# magicalella/yii2-sef

> 标签: extension, meta, sef, yii2

## 简介

Componente per gestire le Sef URL , i Meta description ed i Title delle pagine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
