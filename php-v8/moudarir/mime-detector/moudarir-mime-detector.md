# moudarir/mime-detector

> 标签: detector, file, filetype, magic-number, mime, mime-type, php

## 简介

A PHP library for detecting the real MIME type of files by analyzing their content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
