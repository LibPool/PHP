# rumd3x/php-baseobject

> 标签: base, object, php-baseobject, rumd3x

## 简介

A very helpful class to extend from and use as a base for other classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
