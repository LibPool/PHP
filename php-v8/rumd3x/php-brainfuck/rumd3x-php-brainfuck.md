# rumd3x/php-brainfuck

> 标签: PHP

## 简介

A nice PHP Utility made out of boredom for encoding a string into brainfuck code and vice-versa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
