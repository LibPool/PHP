# demroos/versioning-bundle

> 标签: semantic, semver, version, versioning

## 简介

Symfony3|4 application versioning, simple console command to manage version (with providers e.g. git tag) of your application using Semantic Versioning 2.0.0 recommendations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
