# redrodrigo/ixc-sdk

> 标签: API-Client, isp, ixc, ixcsoft, sdk

## 简介

SDK PHP não-oficial para a API REST do IXC Soft, com adapter opcional para Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
