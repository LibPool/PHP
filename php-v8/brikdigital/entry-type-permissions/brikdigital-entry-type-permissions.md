# brikdigital/entry-type-permissions

> 标签: Craft, cms, craft-plugin, craftcms

## 简介

Configure permissions per entry type, allowing only certain users to create specific entry types.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
