# givanov95/laravel-shipping

> 标签: courier, delivery, ecommerce, laravel, shipping

## 简介

The delivery contract between a Laravel shop and its delivery methods: one interface for a courier, a flat rate or a pickup point

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
