# givanov95/laravel-data-table

> 标签: data-table, datatable, inertia, laravel, vue

## 简介

A server-side DataTable builder for Laravel with a matching Vue 3 + Inertia frontend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
