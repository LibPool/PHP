# givanov95/laravel-shipping-boxnow

> 标签: boxnow, courier, delivery, ecommerce, laravel, lockers, shipping

## 简介

BoxNow lockers as a delivery method of a Laravel shop: the API client and the adapter to the contract of givanov95/laravel-shipping

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
