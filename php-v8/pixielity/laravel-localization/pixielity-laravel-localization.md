# pixielity/laravel-localization

> 标签: i18n, internationalization, l10n, laravel, locale, localization, pixielity, timezone, translation

## 简介

Localization and internationalization package with translation files, locale detection, and timezone handling

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
