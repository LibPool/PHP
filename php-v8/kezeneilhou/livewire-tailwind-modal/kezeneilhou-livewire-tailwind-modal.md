# kezeneilhou/livewire-tailwind-modal

> 标签: PHP

## 简介

Dynamic Laravel Livewire 3 Tailwind modals.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
