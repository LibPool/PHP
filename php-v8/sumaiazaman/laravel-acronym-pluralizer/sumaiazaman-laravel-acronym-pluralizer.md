# sumaiazaman/laravel-acronym-pluralizer

> 标签: acronym, inflector, laravel, pluralizer, str

## 简介

Fix Laravel pluralizer for uppercase acronyms (CD → CDs, not CDS)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
