# emirustaoglu/barcode

> 标签: 2D Barcode, barcode, barkod, php, qr

## 简介

Lightweight PHP library for generating QR codes and 1D/2D barcodes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
