# guglielmopepe/callbackmapiterator

> 标签: callback iterator, iterator, map, map iterator

## 简介

This iterator applies the callback to the elements of the given iterator.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
