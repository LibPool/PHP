# mateusfbi/totvs-rm-soap

> 标签: laravel, php, rm, soap, totvs, totvs-rm

## 简介

Biblioteca SOAP para integração com TOTVS RM — funciona com Laravel ou PHP puro

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
