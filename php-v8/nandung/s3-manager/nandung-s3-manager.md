# nandung/s3-manager

> 标签: aws, cloudflare-r2, digitalocean-spaces, file-management, laravel, minio, multi-bucket, quota-management, s3, storage

## 简介

Laravel package for managing multiple S3-compatible storage buckets with quota management, URL embedding, and synchronization

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
