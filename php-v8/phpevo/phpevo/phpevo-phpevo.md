# phpevo/phpevo

> 标签: api, evolution, evolution php sdk, evolution-php-sdk, evolution-sdk, php, sdk

## 简介

Uma SDK em PHP para integração simplificada com a Evolution API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
