# hafriedlander/silverstripe-phockito

> 标签: mockito, mocks, testing

## 简介

Integrate Phockito (a PHP Mocking framework) with SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
