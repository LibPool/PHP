# envesko/twitch-api-php

> 标签: api, twitch, twitch-api, twitch-tv, twitch.tv

## 简介

A Twitch API client for PHP. A maintained, drop-in compatible fork of nicklaw5/twitch-api-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
