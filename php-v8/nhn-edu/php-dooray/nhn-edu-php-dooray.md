# nhn-edu/php-dooray

> 标签: Messenger, api, dooray, project

## 简介

Dooray SDK for PHP - Can easily use APIs provided by Dooray! (https://www.dooray.com) service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
