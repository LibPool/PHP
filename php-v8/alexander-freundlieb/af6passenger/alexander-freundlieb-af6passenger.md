# alexander-freundlieb/af6passenger

> 标签: TYPO3 CMS

## 简介

Simple extension to extend the sitepackage af6bus and add your own changes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
