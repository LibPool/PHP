# alezhu/dotenv-editor

> 标签: dotenv, dotenv-editor, laravel

## 简介

A fork of original koel/dotenv-editor package for edit .env file with some improvements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
