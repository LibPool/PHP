# odoorbell/fa6repair

> 标签: PHP

## 简介

Font Awesome 6 icon repair, addressing the issue of certain extensions being unable to display icons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
