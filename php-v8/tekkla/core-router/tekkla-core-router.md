# tekkla/core-router

> 标签: lightweight, router

## 简介

Extension of the lightweight Altorouter. This version adds some methods to retrieve and/or alter data from matches.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
