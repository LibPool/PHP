# gavtaylor/retentionpolicy

> 标签: archive, cleanup, doveadm, dovecot, email, plugin, retention, roundcube, roundcubemail, webmail

## 简介

Outlook-style per-folder retention policies: automatically delete or archive messages older than a set period, applied nightly on the Dovecot server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
