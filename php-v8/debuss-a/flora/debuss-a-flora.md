# debuss-a/flora

> 标签: database, document-store, faunadb, fql, json, mariadb, mysql, nosql, postgresql, sqlite

## 简介

A FaunaDB-like document store on PostgreSQL, MySQL, MariaDB and SQLite: JSON documents, indexes, sets, history and FQL-style queries in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
