# debuss-a/server-request-factory

> 标签: factory, psr-17, psr-7, server-request

## 简介

Creates PSR-7 server requests from globals or arrays, with any PSR-17 implementation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
