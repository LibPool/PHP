# rasclatt/smart-dto

> 标签: Data Transfer Object, Nubersoft, dto, php

## 简介

Fill Dtos with data using the mapping. Also allows rendering to different array key formats.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
