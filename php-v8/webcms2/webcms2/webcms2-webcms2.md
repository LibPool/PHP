# webcms2/webcms2

> 标签: cms, doctrine2, nette-based

## 简介

WebCMS2 content management system for Nette framework. This package contains system libraries and admin module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
