# fedale/rbac-bundle

> 标签: authorization, bundle, is-granted, permissions, rbac, roles, symfony, voter, yii2

## 简介

Symfony RBAC bundle inspired by Yii2 (auth_item / auth_item_child / auth_assignment / auth_rule): roles, permissions, hierarchy, per-user assignments and contextual rules, with a can() API and DB-driven role hierarchy

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
