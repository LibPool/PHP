# alfasix/alfakit-kanban

> 标签: alfakit, board, drag-and-drop, kanban, laravel, sortable

## 简介

Kanban boards for any Eloquent model in AlfaKit panels: drag and drop with keyboard and touch, WIP limits, transitions, swimlanes and authorised, tenant-scoped moves.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
