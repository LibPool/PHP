# alfasix/alfakit-calendar

> 标签: alfakit, calendar, events, fullcalendar, laravel, scheduling

## 简介

FullCalendar widgets for AlfaKit panels: month, week, day and list views, event actions, drag and drop.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
