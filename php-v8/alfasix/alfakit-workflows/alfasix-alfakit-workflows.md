# alfasix/alfakit-workflows

> 标签: Audit, alfakit, approvals, laravel, state-machine, workflow

## 简介

State machines and approval workflows for any model of an AlfaKit panel: transitions with guards, forms and policies, single, any-of, all-of and multi-level approvals with delegation, reminders and escalation, an approvals inbox, a history timeline and a workflow diagram.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
