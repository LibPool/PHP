# alfasix/alfakit-ai

> 标签: ai, alfakit, copilot, laravel, llm, mcp

## 简介

AI built into AlfaKit panels with laravel/ai: one-line AI actions, field writing assistance, natural-language table filters, a panel copilot that respects policies, an MCP server and usage logging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
