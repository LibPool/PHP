# alfasix/alfakit-media-library

> 标签: alfakit, file-upload, laravel, media-library, spatie

## 简介

Spatie Laravel Media Library fields, columns and entries for AlfaKit panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
