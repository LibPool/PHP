# alfasix/alfakit-feature-flags

> 标签: alfakit, feature-flags, feature-toggles, laravel, pennant, rollout

## 简介

A feature flag control centre for Laravel Pennant in AlfaKit panels: every feature with its status, kill switch, percentage and scheduled rollouts, per-user and per-tenant targeting, rich values and a full audit trail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
