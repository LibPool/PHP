# alfasix/alfakit-file-manager

> 标签: alfakit, file-manager, filesystem, laravel, s3, storage, uploads

## 简介

A Google-Drive-lite file manager for any Laravel filesystem disk in AlfaKit panels: folders, uploads with progress, drag and drop, previews, zip downloads, trash, shareable links and a file picker field. Every operation is authorised, path-checked and tenant-scoped.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
