# alfasix/alfakit

> 标签: admin, alfa six, alfakit, inertia, laravel, panel, react, shadcn, svelte, vue

## 简介

The frontend-agnostic admin panel builder for Laravel. Define panels, resources, forms, tables and actions in PHP; render them with React, Vue or Svelte via Inertia and shadcn.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
