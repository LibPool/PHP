# alfasix/alfakit-activity-log

> 标签: Audit, activity-log, alfakit, laravel, spatie

## 简介

Browse spatie/laravel-activitylog activities in an AlfaKit panel: an activity resource, a relation manager, a timeline entry and action logging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
