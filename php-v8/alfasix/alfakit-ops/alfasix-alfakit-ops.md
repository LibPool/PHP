# alfasix/alfakit-ops

> 标签: alfakit, failed-jobs, laravel, logs, maintenance, queues, scheduler

## 简介

An operations toolkit for AlfaKit panels: failed jobs, queues and batches, the scheduler, a log viewer, cache and maintenance mode, and system information.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
