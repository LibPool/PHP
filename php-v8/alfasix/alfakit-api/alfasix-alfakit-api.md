# alfasix/alfakit-api

> 标签: alfakit, api, laravel, openapi, rest, tokens

## 简介

Automatic, secure JSON REST APIs for AlfaKit resources: CRUD that reuses the resource form's validation, policies, tenancy, personal access tokens with abilities, rate limiting, RFC 7807 errors, ETags, idempotency keys and a generated OpenAPI 3.1 document with an in-panel API reference.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
