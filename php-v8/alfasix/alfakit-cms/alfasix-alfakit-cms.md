# alfasix/alfakit-cms

> 标签: alfakit, blocks, cms, headless, inertia, laravel, pages, seo

## 简介

A headless-friendly CMS for AlfaKit: block-based pages with drafts, scheduling, revisions and signed previews, SEO, sitemap and robots, redirects, menus, a public Inertia route with React, Vue and Svelte block renderers, and a read-only JSON API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
