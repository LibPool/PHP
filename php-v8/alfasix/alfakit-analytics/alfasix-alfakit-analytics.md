# alfasix/alfakit-analytics

> 标签: alfakit, analytics, cookieless, laravel, plausible, privacy, web-analytics

## 简介

Privacy-first web analytics for the public site of a Laravel app, viewed in an AlfaKit panel: a cookieless tracking snippet, server-side tracking, daily rollups, goals and a dashboard with filters, comparisons and realtime visitors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
