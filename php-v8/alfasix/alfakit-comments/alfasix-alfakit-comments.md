# alfasix/alfakit-comments

> 标签: alfakit, collaboration, comments, laravel, mentions, reactions

## 简介

Comments with mentions, reactions and notifications on any record of an AlfaKit panel: an infolist entry, a slide-over action, a table action and a polling widget.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
