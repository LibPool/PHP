# alfasix/alfakit-translation-manager

> 标签: alfakit, i18n, laravel, localization, translation-manager, translations

## 简介

Let non-developers edit your Laravel app's translations in an AlfaKit panel: a keyboard-driven spreadsheet of keys and locales, placeholder and plural checks, an instant database override layer, safe export to lang files, source code scanning for missing and unused keys, and reviewed AI translations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
