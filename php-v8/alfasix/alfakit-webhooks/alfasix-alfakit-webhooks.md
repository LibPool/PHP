# alfasix/alfakit-webhooks

> 标签: alfakit, events, hmac, integrations, laravel, webhooks

## 简介

Outgoing webhooks managed in an AlfaKit panel: endpoints with signed (HMAC-SHA256) queued deliveries, retries with exponential backoff, SSRF protection, auto-disable, a deliveries log with replay and tenant scoping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
