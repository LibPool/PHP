# alfasix/alfakit-translations

> 标签: alfakit, i18n, laravel, localization, rtl, translations

## 简介

Community translations of the Alfakit admin panel builder into many languages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/alfasixbh/alfakit-translations.git
