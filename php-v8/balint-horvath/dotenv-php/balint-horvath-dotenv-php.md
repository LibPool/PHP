# balint-horvath/dotenv-php

> 标签: PHP

## 简介

Simple .env file parser and ENV loader (.env to getenv() and $_ENV) based on standard PHP INI parser (parse_ini_file).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
