# lopescte/dje-php

> 标签: DJe, Domicílio Judicial Eletrônico

## 简介

Biblioteca para autenticação e conexão ao Domicílio Judicial Eletrônico do CNJ.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
