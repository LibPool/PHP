# lopescte/djen-php

> 标签: DJEN, Diário de Justiça Eletrônico Nacional

## 简介

Biblioteca para acesso às publicações do Diário de Justiça Eletrônico Nacional e Plataforma de Editais (DJEN).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
