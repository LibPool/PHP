# eram/pardakht

> 标签: gateway, idpay, iran, mellat, pardakht, parsian, pasargad, payment, sadad, saman, zarinpal, zibal

## 简介

A simple, type-safe PHP library for Iranian payment gateways.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
