# sunadmin/template

> 标签: admin, framework, orm, scaffold, sunadmin, template, thinkphp, vue3

## 简介

SunAdmin 脚手架模板 - 一句命令即可集成的通用后台管理系统框架（配套vue3前端,同样是一句命令即可安装）,便捷的更新方案,您可以随时更新sunadmin前后端,而无需担心对您项目的影响

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
