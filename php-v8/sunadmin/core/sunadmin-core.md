# sunadmin/core

> 标签: admin, framework, management, sunadmin, thinkphp

## 简介

sunadmin服务端php核心依赖库，一般无需独立安装，若要使用sunadmin完整版服务端，请使用composer create-project sunadmin/template命令创建完整服务端项目

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
