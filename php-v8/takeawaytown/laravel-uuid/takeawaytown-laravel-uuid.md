# takeawaytown/laravel-uuid

> 标签: generator, laravel, uuid, validator

## 简介

A package for using 'Universally Unique Identifiers' in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
