# rodiumai/laravel-sdk

> 标签: ChatGpt, africa, ai, claude, laravel, llm, openai, rodiumai, sdk

## 简介

Laravel/PHP SDK for the RodiumAI API — multi-model AI with Mobile Money payments

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
