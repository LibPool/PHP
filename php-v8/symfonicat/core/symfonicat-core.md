# symfonicat/core

> 标签: PHP

## 简介

Symfonicat Symfony application with admin, routing, module runtime, Electron tooling, and FrankenPHP starter infrastructure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
