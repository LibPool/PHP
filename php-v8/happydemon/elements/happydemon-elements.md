# happydemon/elements

> 标签: bootstrap, breadcrumb, kohana, kohana module, menu, navigation

## 简介

A Kohana module to help with building HTML navigation menus and breadcrumbs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
