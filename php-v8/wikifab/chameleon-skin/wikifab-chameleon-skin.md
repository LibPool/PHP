# wikifab/chameleon-skin

> 标签: bootstrap, mediawiki, skin, twitter, wiki

## 简介

A highly flexible MediaWiki skin using Twitter Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
