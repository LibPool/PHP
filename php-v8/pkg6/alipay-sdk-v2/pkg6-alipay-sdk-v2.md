# pkg6/alipay-sdk-v2

> 标签: PHP

## 简介

Alipay SDK for PHP让您不用复杂编程即可访支付宝开放平台开放的各项能力，SDK可以自动帮您满足能力调用过程中所需的证书校验、加签、验签、发送HTTP请求等非功能性要求。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
