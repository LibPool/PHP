# iranimij/openfilter-hyva-bundle

> 标签: ajax-filters, hyva, layered-navigation, mage-os, magento2, openfilter, opensearch

## 简介

OpenFilter for Hyvä in one require: layered navigation for Magento 2 and Hyvä (core, Hyvä render package and the shared base module). Free and MIT.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
