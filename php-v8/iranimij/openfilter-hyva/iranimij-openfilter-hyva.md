# iranimij/openfilter-hyva

> 标签: ajax-filters, hyva, layered-navigation, mage-os, magento2, openfilter

## 简介

OpenFilter render package for Hyvä themes: filter templates, one Alpine component for same-URL AJAX, mobile drawer, sliders and structural CSS. No Tailwind rebuild needed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
