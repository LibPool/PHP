# iranimij/module-base

> 标签: hyva, iranimij, mage-os, magento2

## 简介

Tiny shared base module for Iranimij Magento 2 extensions: a config tab, an installed-modules page and two typed helpers. No license checks. No phone-home. No ads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
