# iranimij/openlabel-hyva

> 标签: badges, hyva, mage-os, magento2, openlabel, product-labels

## 简介

OpenLabel render package for Hyvä themes: label slots in product listings and the product gallery, generated per-store CSS, no Tailwind rebuild needed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
