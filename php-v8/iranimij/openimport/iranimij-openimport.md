# iranimij/openimport

> 标签: csv, export, import, mage-os, magento2, openimport, scheduled-import, sftp, xlsx

## 简介

OpenImport: import and export for Magento 2 with profiles, column mapping, value transforms, a dry run that previews every change, schedules and remote sources (SFTP, FTP, URL). Built on Magento's own import engine. Free and MIT.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
