# vrtc/yii2-export

> 标签: PHPExcel, PhpWord, csv, dompdf, excel, export, extension, html, pdf, widget, word, xls, yii2

## 简介

Yii2 It saves data in xls, csv, word, html, pdf files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
