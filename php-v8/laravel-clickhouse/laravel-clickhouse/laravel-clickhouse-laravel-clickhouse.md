# laravel-clickhouse/laravel-clickhouse

> 标签: clickhouse, database, eloquent, laravel, model, php

## 简介

A ClickHouse based Eloquent model and Query builder for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
