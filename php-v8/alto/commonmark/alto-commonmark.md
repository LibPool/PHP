# alto/commonmark

> 标签: alto, code-block, commonmark, commonmark-extension, content-slicer, extension, heading, import, include, league-commonmark, link-rewriter, markdown, php, source, table-of-contents, tabs

## 简介

A collection of CommonMark extensions: code block titles, content slicing, heading level adjustment, file import/include, source display, table of contents, tabs, and link rewriting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
