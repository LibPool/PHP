# alto/code-kit

> 标签: annotations, code, code-slicing, snippet, source-code, syntax-highlighting

## 简介

Compose source slicing and semantic highlighting into immutable annotated code snippets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
