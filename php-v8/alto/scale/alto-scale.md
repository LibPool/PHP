# alto/scale

> 标签: design-system, fibonacci, geometric-progression, golden-ratio, grid, linear-scale, modular-scale, rhythm, scale, typography

## 简介

A nano package for computing and manipulating modular scales (typography, rhythm, grids).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
