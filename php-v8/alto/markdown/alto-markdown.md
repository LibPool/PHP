# alto/markdown

> 标签: commonmark, gfm, linter, markdown, parser, renderer

## 简介

Markdown document engine: parse, query, lint, build, render, and safely edit Markdown with minimal diffs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
