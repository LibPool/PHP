# alto/image

> 标签: Webp, avif, crop, gd, image, imagick, resize, thumbnail

## 简介

Lazy image resizing, cropping and encoding with predictable geometry and efficient multi-output rendering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
