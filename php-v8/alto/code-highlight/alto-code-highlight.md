# alto/code-highlight

> 标签: code-highlighting, highlight-js, php, php84, prism, semantic-parser, server-side, syntax-highlighter, themes, tokenizer

## 简介

Server-side syntax highlighting for PHP with semantic scopes, embedded languages, and adaptable themes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
