# alto/font

> 标签: font, opentype, truetype, woff, woff2

## 简介

Font file reading and metadata: parse OpenType/TrueType/WOFF/WOFF2, discover installed fonts, and expose per-glyph facts (metrics, outlines) without any drawing or shaping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
