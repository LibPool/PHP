# alto/bezier

> 标签: bezier, bezier-curve, computational-geometry, cubic, curve, curve-evaluation, curve-splitting, geometry, graphics, math, quadratic, svg

## 简介

Precision PHP toolkit for evaluating, splitting, and measuring quadratic, cubic, quintic and N-order Bezier curves

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
