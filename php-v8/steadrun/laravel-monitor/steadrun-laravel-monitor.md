# steadrun/laravel-monitor

> 标签: PHP

## 简介

Steadrun (steadrun.ru) client for Laravel: ping helper for the Scheduler and failed-job alerting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
