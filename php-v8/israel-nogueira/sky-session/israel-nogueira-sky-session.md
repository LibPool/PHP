# israel-nogueira/sky-session

> 标签: AES-256, encryption, php8, security, session

## 简介

Uma classe moderna, segura e com testes para gerenciamento de sessões em PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
