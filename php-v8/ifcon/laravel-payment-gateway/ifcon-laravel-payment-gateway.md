# ifcon/laravel-payment-gateway

> 标签: PHP

## 简介

Laravel payment gateway drivers for SenangPay, ToyyibPay, CHIP, DOKU, KiplePay, and PayPal

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
