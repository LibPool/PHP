# scandella/craft-squeeze

> 标签: Craft, assets, cms, craft-plugin, craftcms, squeeze, zip

## 简介

Zip one or multiple craft assets on the fly for frontend user to download.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
