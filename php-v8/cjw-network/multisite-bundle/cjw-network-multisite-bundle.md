# cjw-network/multisite-bundle

> 标签: PHP

## 简介

CjwMultiSiteBundle allows multiple fully independant sites within a single eZ Platform installation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
