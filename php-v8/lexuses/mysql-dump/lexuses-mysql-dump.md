# lexuses/mysql-dump

> 标签: dump, laravel, mysql, s3

## 简介

Laravel 5+ package for auto dump mysql database to local storage or to cloud

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
