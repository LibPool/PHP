# michaelstaatz/fast-blog

> 标签: TYPO3 CMS

## 简介

Fast Blog: imports blog posts from Markdown files (with YAML frontmatter) in fileadmin and renders them as a paginated list and a detail view.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
