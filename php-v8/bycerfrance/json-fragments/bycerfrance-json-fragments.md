# bycerfrance/json-fragments

> 标签: Flysystem, fragments, json, lazy-loading, references

## 简介

Externalize JSON branches into immutable storage fragments and resolve references lazily

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
