# components/jquery-cookie

> 标签: JS, cookie, javascript, jquery

## 简介

A simple, lightweight jQuery plugin for reading, writing and deleting cookies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
