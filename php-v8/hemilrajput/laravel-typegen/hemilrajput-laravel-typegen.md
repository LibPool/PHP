# hemilrajput/laravel-typegen

> 标签: codegen, eloquent, inertia, laravel, types, typescript

## 简介

Generate TypeScript types from Eloquent models, Enums & FormRequests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
