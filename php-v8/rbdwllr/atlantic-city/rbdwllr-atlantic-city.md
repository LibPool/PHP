# rbdwllr/atlantic-city

> 标签: PHP

## 简介

A replica of the default WordPress plugin Hello Dolly, but for composer powered WordPress and for the song Atlantic City.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
