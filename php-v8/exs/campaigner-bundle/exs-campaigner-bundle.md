# exs/campaigner-bundle

> 标签: Symfony2, api, bundle, campaigner, soap

## 简介

This bundle is a client for Campaigner's SOAP web services.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
