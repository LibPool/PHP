# programmernomad/laracorekit

> 标签: filament, laracorekit, laravel, starter-kit

## 简介

Editable modular Laravel starter with public frontend, Filament administration and UI components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
