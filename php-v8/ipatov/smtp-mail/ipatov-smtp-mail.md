# ipatov/smtp-mail

> 标签: mail, smtp

## 简介

PHP Class to Send Email using Yandex, Gmail, Mail.ru SMTP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
