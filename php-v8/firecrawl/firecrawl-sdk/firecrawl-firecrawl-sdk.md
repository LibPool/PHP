# firecrawl/firecrawl-sdk

> 标签: api, crawling, firecrawl, laravel, php, web-scraping 

## 简介

PHP SDK for the Firecrawl v2 API with Laravel support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
