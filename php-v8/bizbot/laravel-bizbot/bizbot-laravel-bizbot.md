# bizbot/laravel-bizbot

> 标签: bizbot, laravel, notification, sms, whatsapp

## 简介

Laravel package for BizBot – Send WhatsApp and SMS messages via the BizBot API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
