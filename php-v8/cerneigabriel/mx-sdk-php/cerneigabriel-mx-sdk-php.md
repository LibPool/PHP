# cerneigabriel/mx-sdk-php

> 标签: PHP

## 简介

MultiversX PHP SDK for interacting with the MultiversX blockchain (in general) and Smart Contracts (in particular).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
