# jimtools/jwt-auth

> 标签: auth, json, jwt, middleware, psr-15, psr-7

## 简介

PSR-15 JWT Authentication middleware, A replacement for tuupola/slim-jwt-auth

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
