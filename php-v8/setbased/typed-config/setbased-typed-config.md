# setbased/typed-config

> 标签: config, configuration, ini, json, strong typed, xml, yaml, yml

## 简介

A lightweight and strong typed that supports PHP, INI, XML, JSON, and YAML files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
