# duck7000/themoviedb-api-php

> 标签: api, movie, php, themoviedb, tmdb

## 简介

Library for retrieving film and tv information from TMDb (themoviedb) through API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
