# duck7000/musicbrainz-php

> 标签: Lp, api, audio, cd, encyclopedia, metadata, musicbrainz, php

## 简介

Library for retrieving music, cd lp etc from musicBrainz API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
