# lthn/php-developer

> 标签: core-php, debugging, developer-tools, laravel, route-inspector

## 简介

Developer tools module for Core PHP Framework - route inspector, database explorer, logs viewer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
