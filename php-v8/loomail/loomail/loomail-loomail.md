# loomail/loomail

> 标签: analytics, events, laravel, lifecycle-email, loomail

## 简介

Server-side client for Loomail: send identify and track events with a secret key. Includes a Laravel service provider and facade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
