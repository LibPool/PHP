# vivialconnect/sdk

> 标签: api, mms, php, sms

## 简介

VivialConnect is a simple SMS/MMS API. It's designed specifically for developers seeking a simple, affordable and scalable messaging solution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
