# mertyildiran/l5shell

> 标签: exec, laravel, shell

## 简介

Another fork of L4shell - Add shell command wrapper to Laravel 4.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
