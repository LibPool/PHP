# simplypaye/laravel

> 标签: airtel-money, drc, flexpay, laravel, mobile-money, mpesa, orange-money, payment, simply-paye, simplypaye

## 简介

SimplyPaye Mobile Money SDK for Laravel — Orange Money, Airtel Money, M-Pesa (DRC). API: https://api-simply-pay.net

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
