# ht3aa/zain-cash

> 标签: ht3aa, laravel, zain-cash

## 简介

This is a laravel package that provide all the functionality that you need to integrate your app with zain cash gateway api

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
