# helgesverre/libui

> 标签: cross-platform, desktop, ffi, gui, libui, native

## 简介

Native desktop GUI for PHP 8.5+ via libui-ng and FFI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
