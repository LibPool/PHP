# helgesverre/synapse

> 标签: ai, anthropic, executor, llm, openai, parser, prompt

## 简介

A modern PHP library for LLM orchestration with executors, prompts, parsers, and tool calling

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
