# helgesverre/turbovision

> 标签: console, ncurses, terminal, tui, turbo-vision

## 简介

A modern PHP 8.5 port of Borland's Turbo Vision text-mode UI framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
