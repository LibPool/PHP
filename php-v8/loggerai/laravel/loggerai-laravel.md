# loggerai/laravel

> 标签: Session Replay, apm, errors, laravel, loggerai, logging, monitoring, observability

## 简介

LoggerAI for Laravel: performance monitoring, errors, logs, alerts and user sessions, with AI that explains what went wrong.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
