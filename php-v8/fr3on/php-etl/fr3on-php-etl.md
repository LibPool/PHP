# fr3on/php-etl

> 标签: etl, generators, lazy, php84, pipeline, typed

## 简介

A typed, lazy PHP 8.4+ data pipeline / ETL library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
