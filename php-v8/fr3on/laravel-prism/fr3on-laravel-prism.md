# fr3on/laravel-prism

> 标签: auditor, eloquent, factory, laravel, model

## 简介

Static Eloquent model auditor - catches $fillable, $casts, $hidden, and factory drift before tests fail silently.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
