# fr3on/laravel-inbox

> 标签: dashboard, inbox, intercept, laravel, notifications

## 简介

A local notification intercept dashboard for Laravel — caught and previewed in one place across all channels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
