# gladehq/php-coerce

> 标签: casting, coercion, conversion, php, safe, type

## 简介

Safe, predictable type coercion for PHP. If it can't convert meaningfully, return null — never guess.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
