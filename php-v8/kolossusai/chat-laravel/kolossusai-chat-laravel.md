# kolossusai/chat-laravel

> 标签: ai, assistant, chat, chatbot, kolossus, laravel

## 简介

Add a KolossusAI chat assistant to your Laravel site with one command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
