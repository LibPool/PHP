# zoon/phpmorphy

> 标签: phpmorphy

## 简介

phpMorphy - PHP 8-compatible morphological analyzer library for Russian, English, German and Ukrainian languages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
