# zoon/commonmark-ext-youtube-iframe

> 标签: commonmark, extension, iframe, markdown, youtube

## 简介

Extension for league/commonmark to replace youtube link with iframe

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
