# uhifadhi/el-nino-module

> 标签: climate, el-nino, enso, flood, gis, postgis, rainfall, symfony, symfony-ux, uhifadhi

## 简介

El Niño watch: the state of the equatorial Pacific, the chance it lasts into the short rains, the rain of the last weeks over an area, and which roads and places lose access if it floods — one bulletin a week, from a producer the area names.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
