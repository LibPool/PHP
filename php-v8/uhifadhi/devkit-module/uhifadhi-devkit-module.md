# uhifadhi/devkit-module

> 标签: dev-tools, devkit, fixtures, seed, seeding, symfony, uhifadhi

## 简介

Devkit: the dev-only collector. Installed via require-dev, it gathers the inert Contracts\Devkit\ContentProviderInterface and CommandProviderInterface classes the core and other modules ship, and materialises them into a `fixtures:seed` seeder (run in dependsOn topological order) and real console commands — present only in a dev install.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
