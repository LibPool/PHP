# openxtrem/wkhtmltopdf-lib

> 标签: PHP

## 简介

Convert html to pdf using webkit (qtwebkit) for amd64 systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
