# openxtrem/rtf-html-php

> 标签: converter, rtf

## 简介

RTF to HTML converter in PHP. Fork of henck/rtf-html-php for PHP 8.2 compatibility

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
