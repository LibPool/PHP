# openxtrem/swagger

> 标签: PHP

## 简介

Swagger UI allows anyone to visualize and interact with the API’s resources. It’s automatically generated from your OpenAPI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
