# openxtrem/tcpdf-lib

> 标签: PHP

## 简介

Open Source PHP class for generating PDF documents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 源码仓库：https://gitlab.com/openxtrem_public/components/tcpdf.git
