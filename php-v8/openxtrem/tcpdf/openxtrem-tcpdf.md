# openxtrem/tcpdf

> 标签: PHP

## 简介

Open Source PHP class for generating PDF documents.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：git@gitlab.com:openxtrem_public/tcpdf.git
