# dragan1700/pdf-report-creator

> 标签: Craft, cms, craft-plugin, craftcms, pdf creator

## 简介

Craft CMS plugin to generate PDF from a collection of pages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
