# tuzex/cqrs-messenger

> 标签: PHP

## 简介

Implementation of CQRS (Command Query Responsibility Segregation) based on the Symfony Messenger 4.3 and higher

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
