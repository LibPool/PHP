# tuzex/cqrs-messenger-bundle

> 标签: PHP

## 简介

Symfony Messenger-based Command Query Responsibility Segregation (CQRS) integration into Symfony 4.3 and higher

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
