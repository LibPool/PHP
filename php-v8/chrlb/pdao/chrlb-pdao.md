# chrlb/pdao

> 标签: PHP

## 简介

Simple PDO wrapper 'DATA ACCESS OBJECT' for organizing and reusing named prepared statements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
