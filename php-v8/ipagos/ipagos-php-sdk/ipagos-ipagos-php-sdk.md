# ipagos/ipagos-php-sdk

> 标签: PHP

## 简介

SDK profesional de alto nivel para la integracion con iPagos en PHP, optimizado para PHP 8.2+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
