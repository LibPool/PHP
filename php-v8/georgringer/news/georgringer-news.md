# georgringer/news

> 标签: article, extension, news, typo3

## 简介

News system - Versatile news system based on Extbase & Fluid and using the latest technologies provided by TYPO3 CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
