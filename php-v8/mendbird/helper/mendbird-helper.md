# mendbird/helper

> 标签: composer, laravel, monitoring, security, vulnerabilities

## 简介

Lets Mendbird read the exact version of PHP, Laravel and every Composer package your app runs, so it can check each one against the lists of known security flaws every morning. Reads names and versions only, and answers only Mendbird.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
