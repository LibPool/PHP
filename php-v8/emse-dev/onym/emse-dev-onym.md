# emse-dev/onym

> 标签: blaspsoft, onym

## 简介

Onym is a lightweight Laravel package designed to generate unique, structured, and meaningful filenames effortlessly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
