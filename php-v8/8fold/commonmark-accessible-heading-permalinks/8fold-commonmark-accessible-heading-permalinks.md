# 8fold/commonmark-accessible-heading-permalinks

> 标签: PHP

## 简介

An extension of PHP League's CommonMark library to enable accessible Heading Permalinks usage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
