# bingcool/swoolefy

> 标签: auto relaod, monitor, php, swoole, swoolefy

## 简介

swoolefy is a HV Framework based on swoole extension, for everyone use it easily!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
