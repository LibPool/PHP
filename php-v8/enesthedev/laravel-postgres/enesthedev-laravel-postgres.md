# enesthedev/laravel-postgres

> 标签: laravel, laravel-postgres

## 简介

An extended PostgreSQL driver with support for some aditional PostgreSQL data types: hstore, uuid, jsonb.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
