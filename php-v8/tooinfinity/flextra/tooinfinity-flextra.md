# tooinfinity/flextra

> 标签: inertia, laravel, modules, react, svelte, vue

## 简介

Minimal Laravel Authentication with Inertia, React, Vue, Svelte, and nWidart Laravel Modules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
