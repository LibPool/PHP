# tooinfinity/inertia-datatables

> 标签: inertia-datatables, laravel, tooinfinity

## 简介

Server-side DataTables for Laravel + Inertia 3 with React, TanStack Table v8, and shadcn/ui

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
