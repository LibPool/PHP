# juksgraphic/bladetranslator

> 标签: ai-translation, blade, i18n, juksgraphic, laravel, translation

## 简介

An AI-powered package to extract, translate, and manage language files directly from Laravel Blade views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
