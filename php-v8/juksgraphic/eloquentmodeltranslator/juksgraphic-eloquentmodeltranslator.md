# juksgraphic/eloquentmodeltranslator

> 标签: eloquent, eloquentmodeltranslator, i18n, juksgraphic, laravel, llm, translatable, translation

## 简介

Per-attribute translations for Eloquent models, with optional LLM machine translation through PSR-18 providers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
