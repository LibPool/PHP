# swarming/buzzi-laravel

> 标签: buzzi, laravel, php, sdk

## 简介

A service which wraps the functionality of the Buzzi PHPSDK for easy use within the Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
