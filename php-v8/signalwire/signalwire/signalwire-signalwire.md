# signalwire/signalwire

> 标签: Relay, api, fax, freeswitch, iot, ivr, laml, mms, signalwire, sms, video, voice, voicemail, voip

## 简介

Client library for connecting to SignalWire.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
