# pdphilip/elasticsearch

> 标签: database, elastic, elasticsearch, eloquent, laravel, model

## 简介

An Elasticsearch implementation of Laravel's Eloquent ORM

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
