# pdphilip/omnicron

> 标签: Tasks, cron, laravel, monitoring, scheduler

## 简介

Unify your Laravel cron jobs into loggable, self-describing tasks with a queryable run history

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
