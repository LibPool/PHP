# vajiral/php-dumpdie

> 标签: PHP Library, die, dump, laravel, lightweight, var_dump

## 简介

Simple Laravel style dump and die (dd) command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
