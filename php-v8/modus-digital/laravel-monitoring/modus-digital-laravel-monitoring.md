# modus-digital/laravel-monitoring

> 标签: Modus Digital, laravel, laravel-monitoring

## 简介

OTLP-first observability for Laravel — traces, logs, and metrics via Grafana Alloy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
