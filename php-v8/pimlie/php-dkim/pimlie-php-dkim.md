# pimlie/php-dkim

> 标签: dkim, signature, verify

## 简介

Finally, a PHP5 class for not just signing, but _verifying_ DKIM signatures.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
