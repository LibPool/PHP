# simple-bus/doctrine-dbal-bridge

> 标签: command bus, dbal, doctrine, message bus

## 简介

Bridge for using SimpleBus with Doctrine DBAL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
