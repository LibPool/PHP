# simple-bus/jms-serializer-bridge

> 标签: asynchronous, message, serialization

## 简介

Bridge for using JMSSerializer as message serializer for SimpleBus/Asynchronous

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
