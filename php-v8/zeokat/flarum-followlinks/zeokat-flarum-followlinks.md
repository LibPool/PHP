# zeokat/flarum-followlinks

> 标签: Follow, bbcode, flarum, links, nofollow, seo

## 简介

Remove nofollow attribute from links using BBCODE.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
