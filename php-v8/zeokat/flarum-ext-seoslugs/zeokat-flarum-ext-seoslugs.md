# zeokat/flarum-ext-seoslugs

> 标签: flarum, links, seo, slug, transliteration

## 简介

Use friendly URLs (aka transliteration) in slugs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
