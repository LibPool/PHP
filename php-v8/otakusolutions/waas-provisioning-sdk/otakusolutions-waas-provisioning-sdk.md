# otakusolutions/waas-provisioning-sdk

> 标签: API-Client, hosting, provisioning, sdk, waas, website-as-a-service, wordpress

## 简介

PHP client for the WaaS Provisioning API: create and manage WordPress stores from your own code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
