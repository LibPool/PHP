# m1/stash-silex

> 标签: apc, cache, caching, extension, handler, m1, memcached, provider, redis, service, serviceprovider, session, sessionhandler, sessions, silex, stash, stash-silex, stashsilex

## 简介

StashSilex is a Silex service provider and session handler for the popular caching library Stash

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
