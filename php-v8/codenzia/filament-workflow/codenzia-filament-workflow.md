# codenzia/filament-workflow

> 标签: automation, diagrammer, filament, laravel, workflow

## 简介

Visual workflow automation engine for Filament 4+ built on filament-diagrammer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
