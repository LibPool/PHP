# maxdmyers/seedling

> 标签: composer, seedling, theme, timber, twig, wordpress, wp

## 简介

A WordPress starter theme based on the lovely Timber library and Bootstrap 4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
