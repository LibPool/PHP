# bynn/decisionnode

> 标签: api, batch, classification, decision, decision-engine, decisionnode, scoring, sdk, sessions

## 简介

PHP client for the DecisionNode decision engine API: ask yes-or-no, choice, score, number, point and box questions about text, images and video and get calibrated probabilities back, one by one, in live sessions or in batches.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
