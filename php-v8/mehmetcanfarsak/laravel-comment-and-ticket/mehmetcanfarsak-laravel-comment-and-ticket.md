# mehmetcanfarsak/laravel-comment-and-ticket

> 标签: ajax, comment, laravel, like

## 简介

Ajax based site wide like and comment system for laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
