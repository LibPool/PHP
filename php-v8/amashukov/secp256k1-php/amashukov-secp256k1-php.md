# amashukov/secp256k1-php

> 标签: ECDSA, bitcoin, blockchain, crypto, cryptography, ecc, eip-191, eip-712, elliptic-curve, ethereum, evm, pure-php, rfc6979, secp256k1, signature

## 简介

secp256k1 elliptic-curve arithmetic + RFC 6979 deterministic ECDSA sign / verify / recover in pure PHP on ext-gmp.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
