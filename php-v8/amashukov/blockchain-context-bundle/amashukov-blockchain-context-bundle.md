# amashukov/blockchain-context-bundle

> 标签: bitcoin, bitcoin-core, blockchain, crypto-payments, eip-191, ethereum, evm, json-rpc, php, signature, symfony, symfony-bundle, ton, tonconnect

## 简介

Symfony bundle providing typed Bitcoin Core, TON and EVM integration services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
