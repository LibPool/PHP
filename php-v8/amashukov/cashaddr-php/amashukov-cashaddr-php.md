# amashukov/cashaddr-php

> 标签: address, base32, bch, bitcoin-cash, blockchain, cashaddr, cashaddress, cashtokens, p2pkh, p2sh, p2sh32, php, polymod

## 简介

CashAddr codec for Bitcoin Cash in pure PHP — BCH polymod checksum, base32, bitcoincash / bchtest / bchreg prefixes, P2PKH / P2SH / P2SH32 and token-aware CashTokens address types as a typed immutable value object.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
