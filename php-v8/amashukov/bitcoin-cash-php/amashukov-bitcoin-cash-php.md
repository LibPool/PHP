# amashukov/bitcoin-cash-php

> 标签: bch, bchn, bitcoin-cash, bitcoin-cash-node, blockchain, cashaddr, cashtokens, json-rpc, php, psbt, sdk

## 简介

Bitcoin Cash SDK for PHP — CashAddr codec with token-aware CashTokens types and a typed Bitcoin Cash Node (BCHN) JSON-RPC client. Umbrella package pulling the pure-PHP Bitcoin Cash stack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
