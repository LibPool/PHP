# amashukov/bchn-rpc-client-php

> 标签: bch, bchn, bitcoin-cash, bitcoin-cash-node, blockchain, cashtokens, dsproof, json-rpc, php, psbt, psr-18, rpc, utxo

## 简介

Typed JSON-RPC client for Bitcoin Cash Node (BCHN) in pure PHP over any PSR-18 client — wallet, UTXO, PSBT, raw-transaction and double-spend-proof calls in the BCHN dialect, CashTokens token data, exact satoshi amounts, never floats.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
