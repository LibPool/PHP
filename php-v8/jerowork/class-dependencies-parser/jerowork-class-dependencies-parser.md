# jerowork/class-dependencies-parser

> 标签: dependencies, fqcn, fqn, parser, reflection

## 简介

Parse all dependencies (FQN) used in an object (e.g. class, trait, interface)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
