# ghalambaz/googleplay-spider

> 标签: crawler, google, googleplay, play, scraper, spider, store

## 简介

Another GooglePlay Website Scraper based on goutte

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
