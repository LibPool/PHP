# macgyer/yii2-icon

> 标签: FontAwesome, bootstrap, icon, material icons, widgets, yii2

## 简介

Icon helper classes and widgets for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
