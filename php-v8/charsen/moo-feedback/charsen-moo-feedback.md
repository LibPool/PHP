# charsen/moo-feedback

> 标签: feedback, inquiry, laravel, mooeen

## 简介

意见反馈 —— 「外部提交 → 后台受理 → 回复 → 状态流转」统一管理、统一实现的 Laravel 功能模块扩展包；匿名访客与登录用户两类提交人共表，单表自引用话题串，分类目录走 host 绑定的 FeedbackTypeResolver 契约声明。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
