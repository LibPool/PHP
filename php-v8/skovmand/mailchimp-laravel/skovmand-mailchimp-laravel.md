# skovmand/mailchimp-laravel

> 标签: PHP

## 简介

A minimal service provider to set up and use the Mailchimp Api v2 PHP library in Laravel 5.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
