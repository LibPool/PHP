# contoweb/laravel-pdflib

> 标签: documents, laravel, pdf, pdflib, print

## 简介

Laravel wrapper for PDFLib to make creating PDFs a breeze

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
