# contoweb/laravel-abacus-api

> 标签: ERP, abacus, api, laravel, odata, rest

## 简介

Laravel wrapper for Abacus REST API to consume it in a Laravel way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
