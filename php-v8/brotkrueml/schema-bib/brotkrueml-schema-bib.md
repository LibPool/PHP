# brotkrueml/schema-bib

> 标签: JSON-LD, TYPO3 CMS, TYPO3 Extension, schema.org, seo, structured data

## 简介

Schema.org extension for bibliography - Extend the schema extension with bibliographic-related terms

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
