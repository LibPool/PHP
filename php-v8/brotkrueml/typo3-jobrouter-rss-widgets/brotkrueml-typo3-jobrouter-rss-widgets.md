# brotkrueml/typo3-jobrouter-rss-widgets

> 标签: PHP

## 简介

TYPO3 dashboard widgets displaying RSS feeds from the JobRouter website (www.jobrouter.com)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
