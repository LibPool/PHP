# 18230/php-tuic-client

> 标签: ffi, php, proxy, quic, socks5, tuic

## 简介

Pure PHP TUIC client with a local SOCKS5 proxy runtime backed by cloudflare/quiche FFI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
