# willvincent/laravel-rateable

> 标签: Rating, fivestar, laravel, laravel 8, laravel 9, rateable, vote

## 简介

Allows multiple models to be rated with a fivestar like system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
