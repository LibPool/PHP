# gblix/escpos-php

> 标签: Epson, barcode, escpos, printer, receipt-printer

## 简介

PHP receipt printer library for use with ESC/POS-compatible thermal and impact printers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
