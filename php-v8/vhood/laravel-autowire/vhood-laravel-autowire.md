# vhood/laravel-autowire

> 标签: attributes, autowire, ddd, dependency-injection, di, laravel

## 简介

Clean and production-ready DI autowiring via PHP 8 attributes for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
