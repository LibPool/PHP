# hallmark/hallmark

> 标签: handler, log, logger, logging, monolog, psr-3, psr-log

## 简介

A modern, fully-typed PSR-3 logging library for PHP 8.3+ — the handler/formatter/processor architecture of Monolog, rebuilt from scratch around enums, readonly value objects and strict types.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
