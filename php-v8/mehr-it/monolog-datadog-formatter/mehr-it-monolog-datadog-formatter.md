# mehr-it/monolog-datadog-formatter

> 标签: PHP

## 简介

Monolog formatter for datadog JSON logs (timestamp instead of datetime and defaults with stacktrace)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
