# koolm/laravel-bittrex

> 标签: api, bittrex, crypto, exchange, laravel, php

## 简介

A simple wrapper to seamlessly communicate with the Bittrex API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
