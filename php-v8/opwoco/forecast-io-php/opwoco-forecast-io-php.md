# opwoco/forecast-io-php

> 标签: forecast, forecast-io, tave

## 简介

PHP wrapper for Forecast IO API (Forked from tave/forecast-io-php)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
