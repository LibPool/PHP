# opwoco/query-filter-bundle

> 标签: doctrine, filter, query, symfony

## 简介

An easy way to filter requests in your Symfony 4 application (that uses Doctrine2 as ORM).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
