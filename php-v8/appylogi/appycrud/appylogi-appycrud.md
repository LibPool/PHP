# appylogi/appycrud

> 标签: admin, crud, generator, php, tailwind, vanilla

## 简介

Generador de CRUD generico en PHP vanilla, agnostico de framework, con soporte multi-motor via PDO.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
