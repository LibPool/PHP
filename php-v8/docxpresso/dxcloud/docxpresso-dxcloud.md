# docxpresso/dxcloud

> 标签: DXCloud, Document Automation, Docxpresso, Open Document Format, REST API, Word merging, convert, odt, pdf, pdf generation, word

## 简介

A PHP SDK designed to simplify the connection to the FREE DXCloud REST API Service for the generation of PDF & Word files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
