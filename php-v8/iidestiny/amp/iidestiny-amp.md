# iidestiny/amp

> 标签: amp, drupal, mobile

## 简介

A set of useful classes and utilities to convert html to AMP html (See https://www.ampproject.org/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/Lullabot/amp-library
- 源码仓库：https://github.com/iiDestiny/amp-library.git
- Packagist 页面：https://packagist.org/packages/iidestiny%2Famp
