# sledgehammer/geoip

> 标签: PHP

## 简介

Sledgehammer GeoIP module: IP to Country lookup via an MaxMind GeoLite database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.maxmind.com/en/geolite
- 源码仓库：https://github.com/sledgehammer/geoip.git
- Packagist 页面：https://packagist.org/packages/sledgehammer%2Fgeoip
