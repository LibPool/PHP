# sledgehammer/laravel

> 标签: framework, laravel, sledgehammer

## 简介

Use the Sledgehammer Framework as a library in a Laravel project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
