# dpn/xml-sitemap-bundle

> 标签: Sitemap

## 简介

Generates XML sitemaps for your favourite search engine by extracting sitemap information out of the site's routes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
