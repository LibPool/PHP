# jlzan1314/wxapp-sdk

> 标签: miniapp, swoft2, wechat, wechat app

## 简介

一个微信小程序服务端SDK 支持swoft2，集成小程序服务端所有接口。A SDK of WeChat mini app.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
