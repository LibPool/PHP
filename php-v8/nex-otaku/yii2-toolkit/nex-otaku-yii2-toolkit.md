# nex-otaku/yii2-toolkit

> 标签: extension, yii2

## 简介

Yii2 typical commercial app infrastructure: soft-delete, UUID, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
