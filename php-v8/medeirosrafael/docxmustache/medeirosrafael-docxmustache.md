# medeirosrafael/docxmustache

> 标签: OpenXML, docx, laravel, mustache, php, template

## 简介

docx template manipulation class, based on mustache templating language

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
