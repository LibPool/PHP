# pitchanon/facebook-connect

> 标签: facebook, graph-api, laravel, meta, oauth

## 简介

A Laravel package for connecting to the Meta (Facebook) Graph API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
