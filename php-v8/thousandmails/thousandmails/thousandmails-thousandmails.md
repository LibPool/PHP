# thousandmails/thousandmails

> 标签: email, mailer, sdk, smtp, thousandmails, transactional-email

## 简介

Official PHP SDK for the ThousandMails client API — transactional email, attachments, statistics, delivery logs and a live event stream.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
