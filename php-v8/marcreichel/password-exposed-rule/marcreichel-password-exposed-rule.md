# marcreichel/password-exposed-rule

> 标签: laravel, password, security, validation

## 简介

Laravel Validation rule to check that a password hasn't been exposed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
