# marcreichel/laya-php

> 标签: ai, classification, decisions, jev, jev-ai, jev-api, laya, llm, machine-learning, multilingual, nlp, psr-18, sdk, sentiment, systemone, text-classification, ticket-triage, zero-shot

## 简介

Self-hosted multilingual text classification for PHP: typed decisions from Laya (via laya-serve), no LLM API needed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
