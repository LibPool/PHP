# notonfire/php

> 标签: analytics, error-tracking, laravel, monitoring, notonfire, sentry

## 简介

NotOnFire for Laravel and PHP: error tracking with strict privacy defaults and privacy-friendly analytics, in one package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
