# hcchi/yii2-websocket

> 标签: extension, swoole, websocket, yii2

## 简介

基于 yiiplus/yii2-websocket 的自定义修改版本

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
