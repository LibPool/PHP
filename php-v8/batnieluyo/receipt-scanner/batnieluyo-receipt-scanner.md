# batnieluyo/receipt-scanner

> 标签: laravel-package, receipt, scanner

## 简介

Use OpenAI to extract structured receipt and invoice data from Text, Html, Images and PDFs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
