# orangecat/module-prices-list

> 标签: b2b, magento2, orangecat, pricelist, prices

## 简介

Customer-specific B2B price lists with volume tiers, multi-list resolution, and import support for Magento 2

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
