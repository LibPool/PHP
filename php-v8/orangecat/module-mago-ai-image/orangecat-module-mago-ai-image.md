# orangecat/module-mago-ai-image

> 标签: PHP

## 简介

Mago Assistant add-on: AI product images from a gallery image and a prompt, with pluggable providers (Google Gemini, OpenAI).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
