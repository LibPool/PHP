# easeappphp/easeapp

> 标签: PHP

## 简介

EaseApp is a PHP based Micro Framework, that can be helpful in writing both Web Applications and REST APIs in a simple and easier way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
