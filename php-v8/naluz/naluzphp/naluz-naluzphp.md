# naluz/naluzphp

> 标签: framework, mailer, orm, php, psr, query-builder, queue, rest-api, scheduler, templating

## 简介

NaluzPHP application skeleton — clone, composer install, and start building. The framework itself is the naluz/framework package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
