# naluz/framework

> 标签: framework, mailer, orm, php, psr, query-builder, queue, rest-api, scheduler, templating

## 简介

NaluzPHP framework core: container, HTTP/PSR-15 router, ORM + query builder, NoSQL, queues, mail, scheduler, storage, templates, security.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
