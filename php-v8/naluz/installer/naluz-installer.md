# naluz/installer

> 标签: cli, framework, installer, naluz, naluzphp

## 简介

The NaluzPHP installer: create new NaluzPHP projects with `naluz new my-app`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
