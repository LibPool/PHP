# freefcw/ldap-auth

> 标签: Authentication, l5, laravel, laravel 5, ldap

## 简介

Laravel 5 Active Directory LDAP Authentication driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
