# simianbv/introspect

> 标签: introspect, laravel

## 简介

Laravel Middleware for letting a resource owner verify a OAuth2 access tokens with a remote authorization server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
