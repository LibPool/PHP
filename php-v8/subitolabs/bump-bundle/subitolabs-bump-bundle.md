# subitolabs/bump-bundle

> 标签: bump, bundle, cd, ci, command, git, version

## 简介

manage project version, changelog and deploy tag in a git project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
