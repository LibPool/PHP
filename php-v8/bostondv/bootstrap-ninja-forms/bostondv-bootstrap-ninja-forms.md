# bostondv/bootstrap-ninja-forms

> 标签: Forms, bootstrap, css, ninja forms, wordpress

## 简介

Adds Bootstrap classes to Ninja Forms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
