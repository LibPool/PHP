# middlebury/dynamic-add-users

> 标签: PHP

## 简介

Dynamic Add Users replaces the 'Add User' screen with a dynamic directory search.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
