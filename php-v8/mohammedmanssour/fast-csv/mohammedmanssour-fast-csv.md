# mohammedmanssour/fast-csv

> 标签: MohammedManssour, fast-csv

## 简介

Fast, Memory-light, CSV Importer/Exporter that provide better testing experience

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
