# dxgx/blade-tailwind-extract

> 标签: blade, dxgx, laravel, livewire, performance, tailwindcss

## 简介

Extract Tailwind CSS classes to reduce Livewire wire transfer size

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
