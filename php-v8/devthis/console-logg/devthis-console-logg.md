# devthis/console-logg

> 标签: PSR3, channels, console, consolelogg, laravel, logg, logger, psr-3, symfony

## 简介

Effortless artisan console output with your usual Laravel logger

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
