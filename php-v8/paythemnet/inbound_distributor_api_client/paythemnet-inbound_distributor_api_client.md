# paythemnet/inbound_distributor_api_client

> 标签: PHP

## 简介

This official PayThem.Net library for direct integration with the PayThem.Net Electronic Voucher Distribution API and other API subsystems. PHP 7.4 and above.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
