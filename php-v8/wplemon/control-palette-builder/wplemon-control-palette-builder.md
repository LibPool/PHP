# wplemon/control-palette-builder

> 标签: customizer, framework, wordpress

## 简介

Palette builder for the Gridd theme. Addon for the Kirki framework (v4.0 API).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
