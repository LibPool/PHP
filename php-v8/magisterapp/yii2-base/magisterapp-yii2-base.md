# magisterapp/yii2-base

> 标签: base, component, extension, filters, helpers, yii2

## 简介

Componentes, Helpers y Widgets base para proyectos de MagisterApp S.A.S.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
