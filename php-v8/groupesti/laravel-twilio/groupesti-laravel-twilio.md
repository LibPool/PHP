# groupesti/laravel-twilio

> 标签: laravel, mms, sms, totp, twilio, voice, webhook

## 简介

Intégration Twilio pour Laravel : messagerie SMS/MMS, appels vocaux, médias, TOTP, webhooks signés et audit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
