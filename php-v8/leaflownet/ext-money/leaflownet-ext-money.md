# leaflownet/ext-money

> 标签: bcmath, currency, decimal, micro, money, value-object

## 简介

Immutable Money value object with 10^-8 micro precision and BcMath-backed arithmetic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
