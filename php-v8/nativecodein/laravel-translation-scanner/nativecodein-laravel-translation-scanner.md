# nativecodein/laravel-translation-scanner

> 标签: auto-translate, blade, en.json, i18n, inertia, inertiajs, internationalization, l10n, lang, language, laravel, laravel-package, localization, missing-translations, php, react, translation, translation-extractor, translation-generator, translation-scanner, translations

## 简介

Laravel translation scanner that auto-extracts __(), trans() and t() strings from PHP, Blade, and Inertia React (JS/TS/JSX/TSX) files into resources/lang/en.json. Supports Laravel 10, 11, 12 and 13.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
