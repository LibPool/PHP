# jeremyrwross/query-monitor-image-sizes

> 标签: debugging, image sizes, plugin, query monitor, wordpress

## 简介

A Query Monitor extension that adds a tab to show registered image sizes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
