# jeremyrwross/frequency-scheduler

> 标签: cron, frequency, laravel, php, scheduler

## 简介

Run Laravel scheduled tasks with an independent probability within specified time periods.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
