# weboftalent/silverstripe-shortcode-gist

> 标签: gist, github, shortcode, silverstripe

## 简介

Adds a shortcode for GitHub gists in Silverstripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
