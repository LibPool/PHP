# weboftalent/adverts

> 标签: Advertising, adverts, silverstripe

## 简介

Add adverts to a site filtering by category. Ads can be images or JavaScript

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
