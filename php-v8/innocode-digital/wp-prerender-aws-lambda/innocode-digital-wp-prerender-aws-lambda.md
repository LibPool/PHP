# innocode-digital/wp-prerender-aws-lambda

> 标签: plugins, prerender, wordpress

## 简介

Generates HTML for client-side rendered content via AWS Lambda.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
