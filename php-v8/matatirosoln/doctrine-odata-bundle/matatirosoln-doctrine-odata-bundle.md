# matatirosoln/doctrine-odata-bundle

> 标签: PHP

## 简介

Symfony Bundle for matatirosoln/doctrine-odata-driver — auto-configures the OData DBAL driver including metadata caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
