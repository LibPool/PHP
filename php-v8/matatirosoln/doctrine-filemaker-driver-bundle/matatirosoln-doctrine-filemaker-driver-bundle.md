# matatirosoln/doctrine-filemaker-driver-bundle

> 标签: FileMaker, PHP API, cwp

## 简介

Symfony bundle to implement one of the FileMaker Doctrine drivers

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
