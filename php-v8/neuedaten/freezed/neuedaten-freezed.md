# neuedaten/freezed

> 标签: fluid, ssg, static, static site generator, templating, typo3fluid

## 简介

Freezed is a static site generator powered by the TYPO3 Fluid template engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
