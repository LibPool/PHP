# melia/object-storage

> 标签: cache, circular references, concurrency, data-store, deserializer, event-driven, expiration, file-based, json, lazy-loading, locking, metadata, object store, object-graph, object-storage, persistence, php, php8, references, serializer, snapshot, storage, stubs, ttl, uuid

## 简介

Lightweight PHP file-based object store with UUID persistence, lazy-loading references, in-memory cache, file locking, safe mode, and a simple viewer UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
