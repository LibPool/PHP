# parkktech/fastmagento-personalization

> 标签: fastmagento, magento, magento-2, magento2, opensearch, personalisation, personalization, recommendations, search

## 简介

FastMagento Personalization — per-shopper profiles built from browsing, search, facet, review and purchase signals, applied to FastMagento's OpenSearch-served listings and search. Requires FastMagento.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
