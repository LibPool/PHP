# mishak/web-resource-management

> 标签: dependency, manager, nette, resource, scripts, style

## 简介

Tools for management of scripts and styles (using Nette Framework)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
