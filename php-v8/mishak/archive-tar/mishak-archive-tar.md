# mishak/archive-tar

> 标签: archive, reader, tar

## 简介

Archive TAR reader for PHP - supports gz, bz2 and files over 2 GB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
