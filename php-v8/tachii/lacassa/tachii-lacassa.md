# tachii/lacassa

> 标签: cassandra, cql, database, lacassa, laravel, nosql, query builder

## 简介

Cassandra based query builder for laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
