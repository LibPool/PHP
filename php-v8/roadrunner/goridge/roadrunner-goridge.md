# roadrunner/goridge

> 标签: Relay, Socket, golang, goridge, ipc, pipes, protobuf, roadrunner, rpc

## 简介

High-performance PHP-to-Go IPC bridge: the RPC transport between PHP workers and the RoadRunner application server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
