# roadrunner/centrifugo

> 标签: centrifugo, proxy, pubsub, real-time, roadrunner, websocket

## 简介

Centrifugo bridge for RoadRunner: handle Centrifugo proxy events in PHP workers and call the Centrifugo server API over RPC

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
