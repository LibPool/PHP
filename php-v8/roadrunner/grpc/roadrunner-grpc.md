# roadrunner/grpc

> 标签: gRPC, microservices, protobuf, roadrunner, rpc, server

## 简介

gRPC server for PHP: serve gRPC services from RoadRunner PHP workers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
