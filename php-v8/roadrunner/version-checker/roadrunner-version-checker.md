# roadrunner/version-checker

> 标签: compatibility, roadrunner, semver, version, version-checker

## 简介

Checks that the installed RoadRunner binary matches the version required by the project's Composer packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
