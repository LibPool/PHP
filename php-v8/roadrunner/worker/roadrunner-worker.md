# roadrunner/worker

> 标签: application-server, goridge, long-running, roadrunner, worker

## 简介

Base PHP worker for the RoadRunner application server: receives payloads over Goridge, sends responses and manages the worker pool

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
