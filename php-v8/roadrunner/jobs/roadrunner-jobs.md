# roadrunner/jobs

> 标签: AMQP, beanstalk, jobs, kafka, nats, queue, queues, roadrunner, sqs, worker

## 简介

PHP API for the RoadRunner Jobs (queues) plugin: manage pipelines, push tasks and consume them in workers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
