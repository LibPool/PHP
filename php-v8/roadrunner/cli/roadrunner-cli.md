# roadrunner/cli

> 标签: binary, cli, console, download, installer, roadrunner

## 简介

RoadRunner command-line tool: downloads the RoadRunner binary and generates its configuration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
