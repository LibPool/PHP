# roadrunner/metrics

> 标签: Metrics, observability, prometheus, roadrunner, rpc

## 简介

Prometheus metrics for PHP workers: declare and update metrics in the RoadRunner metrics plugin over RPC

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
