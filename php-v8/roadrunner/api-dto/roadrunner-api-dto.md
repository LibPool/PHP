# roadrunner/api-dto

> 标签: api, dto, protobuf, roadrunner, rpc, temporal

## 简介

Pre-generated PHP DTOs for the RoadRunner API protocol buffers, used to make RPC calls to the RoadRunner server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
