# roadrunner/symfony-lock-driver

> 标签: distributed-lock, lock, roadrunner, store, symfony, symfony-lock

## 简介

Symfony Lock store backed by the RoadRunner lock plugin: use RoadRunner distributed locks through the symfony/lock API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
