# roadrunner/tcp

> 标签: Socket, roadrunner, server, tcp, worker

## 简介

PHP worker for the RoadRunner TCP plugin: handle raw TCP connection events and data in RoadRunner workers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
