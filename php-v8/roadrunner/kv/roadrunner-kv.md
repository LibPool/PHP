# roadrunner/kv

> 标签: boltdb, cache, key-value, kv, memcached, psr-16, redis, roadrunner, simple-cache

## 简介

PSR-16 cache on top of the RoadRunner Key-Value plugin storages (memory, boltdb, redis, memcached) over RPC

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
