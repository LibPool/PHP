# roadrunner/app-logger

> 标签: app-logger, logger, logging, roadrunner, rpc

## 简介

Send log messages from PHP workers to the RoadRunner app logger plugin over RPC

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
