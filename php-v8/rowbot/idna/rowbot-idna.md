# rowbot/idna

> 标签: idn, idna, international domain names, iri, tr46, unicode, uts46

## 简介

An implementation of UTS#46 Unicode IDNA Compatibility Processing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
