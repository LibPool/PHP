# rowbot/url

> 标签: WHATWG, query-string, querystring, uri, url, url-parser, url-parsing

## 简介

A WHATWG URL spec compliant URL parser for working with URLs and their query strings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
