# fastwebmedia/uk-mobile-validator

> 标签: PHP

## 简介

Checks and formats numbers into valid UK Mobile Numbers (In Local and International Format)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
