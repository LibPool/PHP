# suxianjia/xianjiasitemap

> 标签: PHP

## 简介

由于许多同学对站点地图的事似懂非懂，本项目就把这一篮子的事，都给出解决方案 xianjiasitemap

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
