# fyggi/laravel-simple-uuid

> 标签: fyggi, laravel, laravel-simple-uuid, uuid

## 简介

This package adds a simple trait to add UUID to your models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
