# wangqs/querylist-rule-baidu-abstract

> 标签: PHP

## 简介

QueryList Plugin: baidu with abstract. QueryList百度搜索插件,包含了每条结果的文字简介

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
