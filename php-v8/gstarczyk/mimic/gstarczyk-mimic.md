# gstarczyk/mimic

> 标签: mock, mocking, mockito, stub, stubbing, testing

## 简介

Stubbing and mocking tool for PHP loosely based on Java's Mockito

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
