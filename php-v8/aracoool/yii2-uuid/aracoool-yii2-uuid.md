# aracoool/yii2-uuid

> 标签: guid, uuid, yii, yii2

## 简介

Yii 2 UUID Extension. A PHP 7.0+ library for generating RFC 4122 version 3, 4, and 5 universally unique identifiers (UUID).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
