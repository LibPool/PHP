# bensondevs/laravel-faq

> 标签: Bensondevs, FAQ, Knowledge Base, laravel

## 简介

A simple, flexible, and customizable FAQ management package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
