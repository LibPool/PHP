# bensondevs/indonesian-ktp

> 标签: PHP

## 简介

Validate Indonesian NIK (Nomor Induk Kependudukan) using compiled wilayah data (cahyadsn/wilayah, MIT).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
