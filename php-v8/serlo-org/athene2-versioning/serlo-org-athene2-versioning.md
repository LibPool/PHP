# serlo-org/athene2-versioning

> 标签: athene2, core, module, versioning, zf2

## 简介

Zend Framework 2 Module that provides versioning components for Athene2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
