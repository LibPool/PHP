# honeybee/elasticsearch2-adapter

> 标签: adapter, elasticsearch, honeybee

## 简介

Elasticsearch 2.x adapter for Honeybee.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
