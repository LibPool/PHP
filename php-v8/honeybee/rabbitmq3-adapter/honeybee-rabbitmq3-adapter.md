# honeybee/rabbitmq3-adapter

> 标签: adapter, honeybee, rabbitmq

## 简介

RabbitMQ 3.x adapter for Honeybee.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
