# thenexxuz/agent

> 标签: Agent, browser, desktop, laravel, mobile, platform, user agent, useragent

## 简介

Desktop/mobile user agent parser with support for Laravel, based on Mobiledetect

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
