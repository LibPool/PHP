# slam/alert-on-composerlock-change

> 标签: PHP

## 简介

Composer plugin that alerts (in dev) that composer.lock changed and so the developer should run `composer install`

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
