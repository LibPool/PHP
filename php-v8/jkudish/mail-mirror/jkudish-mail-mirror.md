# jkudish/mail-mirror

> 标签: email, fastmail, gmail, jmap, laravel, mail-mirror

## 简介

Mirror Gmail and Fastmail accounts into account-scoped Laravel models and object storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
