# ypw/friendofmysql

> 标签: PHP

## 简介

Create your php project from scratch with the mysql query library, which allows you to organize the mysql query structure of your project in a single file

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
