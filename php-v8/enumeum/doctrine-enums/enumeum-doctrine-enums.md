# enumeum/doctrine-enums

> 标签: doctrine, enum, enumeration, enumeum, extensions, postgres

## 简介

Doctrine extension to manage enumerations in PostgreSQL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
