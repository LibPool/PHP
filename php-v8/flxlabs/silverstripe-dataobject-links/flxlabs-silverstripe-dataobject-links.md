# flxlabs/silverstripe-dataobject-links

> 标签: cms, silverstripe, tinymce

## 简介

Adds links to data objects in TinyMCE editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
