# relayaa/relaya-php

> 标签: hmac, laravel, relaya, signature, webhooks

## 简介

Verify webhooks forwarded by Relaya and call the Relaya API. Includes Laravel middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
