# sebastka/domeneshop-dashboard

> 标签: DNSSEC, dns, domeneshop, nameservers

## 简介

Read-only access to Domeneshop dashboard functions that the API does not expose. Unofficial and unsupported.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
