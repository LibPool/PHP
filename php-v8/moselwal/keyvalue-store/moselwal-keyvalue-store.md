# moselwal/keyvalue-store

> 标签: cache, keyvalue, lock, redis, session, typo3, valkey

## 简介

KeyValue Store integration for TYPO3 (Redis/Valkey) with PHPRedis >= 6.3, Sentinel and TLS/mTLS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
