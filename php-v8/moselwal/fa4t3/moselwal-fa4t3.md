# moselwal/fa4t3

> 标签: analytics, dashboard, fa4t3, fathom, privacy, typo3

## 简介

Fathom Analytics integration for TYPO3 CMS — Backend Dashboard, Page Analytics, Frontend Tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
