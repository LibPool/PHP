# riverslei/xmpush

> 标签: php xmpush, xmpush, 小米推送, 小米推送 php sdk, 推送SDK

## 简介

小米消息推送composer安装版本，sdk代码由小米提供，该接口只完成composer安装部分

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
