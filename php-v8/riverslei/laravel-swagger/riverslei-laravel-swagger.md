# riverslei/laravel-swagger

> 标签: Swagger-PHP, api, documentation, laravel, laravel swagger, laravel5, swagger

## 简介

在laravel5中使用swagger自动生成api接口文档

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
