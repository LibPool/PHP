# aybarsm/apache-apisix-admin-api

> 标签: API-Client, APISIX, apache

## 简介

Framework-agnostic, typed, resource-oriented PHP client for the Apache APISIX Admin REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
