# aybarsm/laravel-pandle

> 标签: api, client, laravel, pandle, php, sdk

## 简介

Highly customisable Laravel service provider package for Pandle (pandle.com) bookkeeping platform API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
