# flexagon/framework

> 标签: dao, framework, lightweight, microframework, phar

## 简介

Flexagon : a lightweight PHP web framework with no runtime dependencies

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://flexagon.org
- 源码仓库：https://github.com/flexagon/framework.git
- Packagist 页面：https://packagist.org/packages/flexagon%2Fframework
