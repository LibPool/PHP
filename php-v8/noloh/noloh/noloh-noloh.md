# noloh/noloh

> 标签: PHP

## 简介

Unified, object-oriented PHP Framework that eliminates the need for HTML, JavaScript, and AJAX

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
