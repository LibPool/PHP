# dahmen/automad-bootstrap

> 标签: theme

## 简介

A responsive multi-purpose theme for the Automad CMS based on the Bootstrap framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
