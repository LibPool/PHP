# akecul/pdfparser

> 标签: extract, parse, parser, pdf, text

## 简介

Forks from smalot/pdfparser library. Fixes text decoding error with some Chinese text.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
