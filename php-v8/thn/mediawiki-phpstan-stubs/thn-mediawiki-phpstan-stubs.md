# thn/mediawiki-phpstan-stubs

> 标签: PHP

## 简介

MediaWiki PHPStan stubs for use with PHPStan static analysis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
