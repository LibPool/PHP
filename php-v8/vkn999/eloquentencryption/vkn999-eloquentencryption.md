# vkn999/eloquentencryption

> 标签: eloquent, encryption, richardstyles, vkn999

## 简介

Allow Eloquent attributes to be encrypted and decrypted using a RSA 4096-bit private keys.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
