# cristianp6/slim-json-api-helper

> 标签: api, json, slim

## 简介

Slim3 JSON API Request & Response Helper inspired by jsonapi.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
