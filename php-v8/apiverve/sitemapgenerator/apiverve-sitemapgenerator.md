# apiverve/sitemapgenerator

> 标签: api, apiverve, sitemap generator, sitemap generator api, sitemapgenerator, website sitemap generator api, xml sitemap, xml sitemap generator api

## 简介

Sitemap Generator is a website sitemap generator API that creates valid XML sitemaps from URL lists following the sitemaps.org protocol for search engine optimization.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
