# hamidgh83/office2pdf

> 标签: PHP

## 简介

This library uses LibreOffice built-in command to convert office documents (e.g. doc, docx, xls, xlsx, ppt, etc.) into PDF format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
