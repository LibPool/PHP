# lindencms/templator

> 标签: PHP

## 简介

LindenCMS Templator - A native PHP component system that lets you build reusable HTML components with pure PHP and HEREDOC strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
