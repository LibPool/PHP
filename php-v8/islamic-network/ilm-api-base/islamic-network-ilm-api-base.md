# islamic-network/ilm-api-base

> 标签: PHP

## 简介

Shared serving runtime for the ilm domain APIs: snapshot repository, DTO utilities, response cache, base controller and search scanner.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
