# throttlestudio/activity-stream

> 标签: Follow, activity stream, activity-stream, feeds, laravel, laravel-activity-stream, newsfeed, notifications, social network, throttle.studio, throttlestudio, timeline

## 简介

Activity Stream for Laravel applications. Easily add Flat, Timeline, Custom and Notification feeds. Social network solution.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
