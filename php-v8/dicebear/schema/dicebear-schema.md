# dicebear/schema

> 标签: DiceBear, avatar, json-schema, schema

## 简介

JSON Schema definitions for DiceBear avatar styles and options

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
