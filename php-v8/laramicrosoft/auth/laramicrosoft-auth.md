# laramicrosoft/auth

> 标签: Office365, azure-ad, entra-id, laramicrosoft, laravel, microsoft, oauth2, openid-connect, social-auth

## 简介

LaraMicrosoft-Auth: autenticación social con Microsoft Entra ID (Office 365). Integrable con frontends Vue, Nuxt o React.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
