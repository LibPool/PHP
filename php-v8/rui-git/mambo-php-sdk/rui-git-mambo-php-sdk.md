# rui-git/mambo-php-sdk

> 标签: Gamification, api, game, mambo

## 简介

Non official Mambo PHP Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://api.mambo.io/
- 源码仓库：https://github.com/Rui-Git/mambo-php-sdk.git
- Packagist 页面：https://packagist.org/packages/rui-git%2Fmambo-php-sdk
