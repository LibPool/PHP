# xrobau/pami

> 标签: action, ami, asterisk, client, event, manager, monitor, telephony, voip

## 简介

Fork of marcelog's Asterisk Manager Interface (AMI) client for PHP, event driven, object oriented

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
