# ozi-ui/core

> 标签: blade, form-validation, laravel, livewire, ozi-ui, select, ui-components, vanilla-js, wysiwyg

## 简介

UI components for Laravel and Livewire, configured in HTML: select, rich-text editor, form validation, AJAX forms. Plain JavaScript, zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
