# ghoststreet/craft-smart-search

> 标签: PHP

## 简介

Smart Search: hybrid and RAG search for Craft CMS using OpenAI embeddings and PostgreSQL pgvector.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
