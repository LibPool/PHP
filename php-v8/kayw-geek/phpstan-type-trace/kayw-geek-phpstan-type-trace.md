# kayw-geek/phpstan-type-trace

> 标签: PHPStan, debug, static-analysis, types

## 简介

Visualize the full type-inference chain of a value in PHPStan analysis output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
