# bahdan/symfony-safe-http-client

> 标签: PHP

## 简介

SSRF-protected HTTP Client wrapper for Symfony HttpClient with DNS resolution pinning and subnet validation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
