# utexas/pantheon_saml_integration

> 标签: drupal

## 简介

Composer plugin that integrates the University of Texas Enterprise Authentication on Pantheon for the UT Drupal Kit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
