# synida/hunspell-php-wrapper

> 标签: hunspell, multithreading, spell-check, spell-checker, spellcheck, spellchecker, spelling, threading, wrapper

## 简介

PHP wrapper for HunSpell with threading support and custom dictionary support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
