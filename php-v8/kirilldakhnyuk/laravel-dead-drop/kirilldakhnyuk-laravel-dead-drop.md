# kirilldakhnyuk/laravel-dead-drop

> 标签: dead-drop, kirilldakhnyuk, laravel

## 简介

Plan and dump redacted, referentially-complete slices of production data for local and staging databases.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
