# puredazzle/wp-image-to-avif

> 标签: avif, image, performance, plugin, wordpress

## 简介

A WordPress plugin for converting images to AVIF format for optimal performance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
