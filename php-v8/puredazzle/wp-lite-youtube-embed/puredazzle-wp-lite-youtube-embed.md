# puredazzle/wp-lite-youtube-embed

> 标签: embed, plugin, video, wordpress, youtube

## 简介

A WordPress plugin for displaying YouTube videos in a lightweight and responsive way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
