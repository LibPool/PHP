# puredazzle/wp-block-heroicons

> 标签: Heroicons, plugin, tailwindcss, wordplate, wordpress

## 简介

A WordPress plugin for using Heroicons in your blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
