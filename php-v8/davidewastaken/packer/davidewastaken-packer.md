# davidewastaken/packer

> 标签: 3d packing, Box packing, bin packing, cuboid, shipping

## 简介

Fast 3D cuboid packing with a bundled native engine: boxes, stock, weight, rotations, stable support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
