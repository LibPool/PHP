# cmfcmf/column-width-calculator

> 标签: auto-width, calculate, column, table, width

## 简介

Calculate "perfect" table column widths in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
