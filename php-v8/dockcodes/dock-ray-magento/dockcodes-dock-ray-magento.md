# dockcodes/dock-ray-magento

> 标签: adobe-commerce, crash-reporting, error-monitoring, magento, magento2, performance-monitoring, vulnerability-scanner

## 简介

Magento 2 / Adobe Commerce module reporting PHP errors, exceptions, request timings, JavaScript errors and vulnerable software to DockRay

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
