# nercury/object-router

> 标签: friendly-url, routing

## 简介

Allows to create and manage friendly routes for objects. Requires doctrine-orm to store routes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
