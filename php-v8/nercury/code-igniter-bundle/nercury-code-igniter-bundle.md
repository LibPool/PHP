# nercury/code-igniter-bundle

> 标签: ci, code-igniter, codeigniter, migration

## 简介

Allows loading Code Igniter as a bundle and eases migration to Symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
