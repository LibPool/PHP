# theseoframework/wpcs-tsf

> 标签: phpcs, standards, tsf, wordpress

## 简介

Modified (for TSF) PHP_CodeSniffer rules (sniffs) to enforce WordPress and TSF coding conventions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
