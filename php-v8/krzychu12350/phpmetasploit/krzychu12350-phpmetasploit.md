# krzychu12350/phpmetasploit

> 标签: PHP

## 简介

This plugin allows to interact with Metasploit framework either through msfrpcd deamon or the msgrpc plugin running in msfconsole.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
