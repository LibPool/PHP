# hosnyadeeb/laravel-model-actions

> 标签: actions, artisan, crud, generator, laravel, model

## 简介

A Laravel package for generating action classes for models with CRUD operations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
