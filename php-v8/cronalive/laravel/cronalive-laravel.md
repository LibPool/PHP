# cronalive/laravel

> 标签: cron, dead-man-switch, healthcheck, heartbeat, laravel, monitoring, scheduler, uptime

## 简介

Heartbeat monitoring for Laravel scheduled jobs: scheduler macros that create the check and pass its schedule along, plus a ping client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
