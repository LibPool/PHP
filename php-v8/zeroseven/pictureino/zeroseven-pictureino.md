# zeroseven/pictureino

> 标签: PHP

## 简介

Responsive images – fully automated. No setup required. Boost PageSpeed and SEO with lazy loading and modern WebP delivery

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
