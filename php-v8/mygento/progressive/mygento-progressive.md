# mygento/progressive

> 标签: magento, mygento, progressive

## 简介

Magento extension that provides ability save JPEG images progressive

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/mygento/progressive
- 源码仓库：https://github.com/mygento/progressive.git
- Packagist 页面：https://packagist.org/packages/mygento%2Fprogressive
