# byteminus/laravel-bdpaygate

> 标签: BDT, aamarpay, bangladesh, bdpaygate, bkash, dgepay, eps, laravel, moneybag, nagad, payment, payment-gateway, paystation, portpos, portwallet, rocket, shurjopay, sslcommerz, uddoktapay, upay

## 简介

Every Bangladeshi payment gateway behind one Laravel API: bKash, Nagad, SSLCommerz, Upay, ShurjoPay, aamarPay, PortPos, PayStation, UddoktaPay, Moneybag, EPS, DGePay. Every callback verified server-to-server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
