# byteminus/laravel-ai-blog

> 标签: ChatGpt, JSON-LD, ai, blog, blogging, claude, cms, headless, laravel, laravel-blog, mcp, model-context-protocol, rss, seo, structured-data

## 简介

Laravel blog package with built-in SEO scoring, AI drafting (laravel/ai) and an MCP server so Claude and ChatGPT can write to it. Headless by default.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
