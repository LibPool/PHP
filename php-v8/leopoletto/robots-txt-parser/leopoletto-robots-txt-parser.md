# leopoletto/robots-txt-parser

> 标签: PHP

## 简介

A comprehensive PHP package for parsing robots.txt files, including support for meta tags and X-Robots-Tag HTTP headers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
