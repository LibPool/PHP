# rollerworks/pdb-symfony-bridge

> 标签: pdb, php-domain-parser, symfony

## 简介

PHP domain-parser Bridge for Symfony Cache, HTTP Client and FrameworkBundle (optional)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
