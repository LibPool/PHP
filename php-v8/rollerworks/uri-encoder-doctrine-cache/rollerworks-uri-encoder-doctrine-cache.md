# rollerworks/uri-encoder-doctrine-cache

> 标签: rollerworks

## 简介

Provides a Doctrine Cache adapter for the Rollerworks URIEncoder Component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
