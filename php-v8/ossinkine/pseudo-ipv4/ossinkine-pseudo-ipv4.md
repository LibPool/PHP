# ossinkine/pseudo-ipv4

> 标签: PHP

## 简介

Converts IPv6 address to Pseudo IPv4 (valid IPv4 address in Class E space)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
