# predictflow/sdk

> 标签: API-Client, demand-forecasting, ecommerce-analytics, inventory-intelligence, predictflow, rest-api, sdk, shopify, woocommerce

## 简介

Official PHP SDK for PredictFlow - demand forecasting, inventory intelligence, and pricing optimization for Shopify and WooCommerce stores

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
