# askdkc/bacon-qr-code

> 标签: PHP

## 简介

BaconQrCode is a QR code generator for PHP. SHIFT-JISエンコード時のエラーを修正した版

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
