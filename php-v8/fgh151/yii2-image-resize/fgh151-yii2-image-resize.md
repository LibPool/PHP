# fgh151/yii2-image-resize

> 标签: cache, component, extension, image, resize, yii2

## 简介

A Yii2 component for resizing images (and cache it)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
