# ekliptor/cashp

> 标签: billing, bitcoin, cryptocurrency, ecommerce, payment

## 简介

PHP library for Bitcoin Cash (BCH) and SLP token payments

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
