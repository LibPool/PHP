# composer/composer

> 标签: autoload, dependency, package

## 简介

Composer helps you declare, manage and install dependencies of PHP projects. It ensures you have the right stack everywhere.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
