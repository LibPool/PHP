# astromool/astromool-php

> 标签: api, astrology, jyotish, kundli, panchang, swiss-ephemeris, vedic

## 简介

Official client for the AstroMool Vedic astrology API (Swiss Ephemeris charts, 90 calculators, PDF reports).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
