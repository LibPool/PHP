# vardumper/ibexa-theme-translations-bundle

> 标签: PHP

## 简介

Ibexa DXP bundle for managing theme translations with tiered caching (static PHP arrays + Redis + Database)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
