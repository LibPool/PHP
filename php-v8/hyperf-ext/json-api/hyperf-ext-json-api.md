# hyperf-ext/json-api

> 标签: JSON-API, api, hyperf, json, jsonapi, jsonapi.org

## 简介

JSON API (jsonapi.org) support for Hyperf applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
