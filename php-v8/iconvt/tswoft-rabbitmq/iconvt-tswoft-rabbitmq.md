# iconvt/tswoft-rabbitmq

> 标签: php, php-amqplib, swoft, swoole

## 简介

基于swoft封装的rabbitmq连接池

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
