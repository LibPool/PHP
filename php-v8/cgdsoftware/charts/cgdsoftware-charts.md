# cgdsoftware/charts

> 标签: cgdsoftware, chartjs, charts, laravel

## 简介

Server-side data builder for Chart.js, with a VueJS component for the frontend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
