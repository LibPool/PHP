# cgdsoftware/select

> 标签: bootstrap-select, cgdsoftware, select, select-server-side

## 简介

Bootstrap Select data builder with server-side data fetching capability and a VueJS component

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
