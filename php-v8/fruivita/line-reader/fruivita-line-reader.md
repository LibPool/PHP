# fruivita/line-reader

> 标签: file-reader, fruivita, laravel, line-reader, php, reader

## 简介

Read large files, line by line, without causing memory overflow for Laravel applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
