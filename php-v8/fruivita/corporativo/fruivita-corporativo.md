# fruivita/corporativo

> 标签: corporativo, fruivita, importador, laravel, xml

## 简介

Importador de Estrutura Corporativa em formato de arquivo XML para aplicações Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
