# yourpaypayments/visma-connect

> 标签: PHP

## 简介

VismaConnect class for connecting and authorization against Vismas services base on a previous version made by Mathias Gajhede

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
