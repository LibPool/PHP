# rayne/virtual-path

> 标签: directory, path, traversal

## 简介

The VirtualPath library normalises paths and prevents directory traversal attacks without querying a file system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
