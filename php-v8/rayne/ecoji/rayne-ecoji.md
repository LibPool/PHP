# rayne/ecoji

> 标签: base1024, decoding, ecoji, emoji, encoding

## 简介

Encodes (and decodes) data as emojis. Implementation of the Ecoji Standard.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
