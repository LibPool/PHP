# octolab/cleaner

> 标签: PHP

## 简介

Composer plugin for removing development files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/octolab/Cleaner
- 源码仓库：https://github.com/octolab/cleaner.git
- Packagist 页面：https://packagist.org/packages/octolab%2Fcleaner
