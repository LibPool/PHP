# dasformt/kirby-favicons

> 标签: PHP

## 简介

Favicons, Apple Touch Icon und Webmanifest aus dem Kirby-Panel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
