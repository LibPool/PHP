# eberfreitas/cakephp-slugomatic

> 标签: Behavior, cakephp, plugin, seo, slug

## 简介

CakePHP behavior to automatically create slugs for your URLs from database records

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
