# toumoro/tm-cloudfront

> 标签: PHP

## 简介

this extension is designed to clear  the Amazon CloudFront cache based on the speaking path of a page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
