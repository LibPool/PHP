# rebelcode/wp-http

> 标签: client, http, psr-18, psr-7, wordpress

## 简介

A PSR-18 compliant HTTP client adapter for WordPress

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
