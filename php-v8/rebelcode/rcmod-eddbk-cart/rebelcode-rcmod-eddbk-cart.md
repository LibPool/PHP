# rebelcode/rcmod-eddbk-cart

> 标签: PHP

## 简介

A RebelCode module that adds EDD cart bookings functionality to EDD Bookings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
