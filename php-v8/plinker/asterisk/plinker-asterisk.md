# plinker/asterisk

> 标签: ami, asterisk, rpc

## 简介

An Asterisk component which hooks into the Asterisk Management Interface on remote systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
