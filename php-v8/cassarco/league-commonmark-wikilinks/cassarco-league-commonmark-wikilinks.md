# cassarco/league-commonmark-wikilinks

> 标签: cassarco, league-commonmark-wikilinks, markdown, wikilinks

## 简介

An extension that enables wikilinks parsing in league/commonmark.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
