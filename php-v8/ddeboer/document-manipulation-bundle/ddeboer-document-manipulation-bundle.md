# ddeboer/document-manipulation-bundle

> 标签: doc, document, mailmerge, merge, pdf

## 简介

Use this Symfony2 bundle to manipulate Microsoft Word and PDF documents

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
