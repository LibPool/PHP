# peekapi/peekapi

> 标签: analytics, api, laravel, middleware, peekapi, psr-15

## 简介

Zero-dependency PHP SDK for PeekAPI — PSR-15 and Laravel middleware for API analytics

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
