# basekit-laravel/basekit-laravel-slugs

> 标签: basekit, eloquent, laravel, localized, slug, slugs

## 简介

Slugs and localized slugs for Basekit Laravel — deterministic slug generation, normalization and validation plus a reusable Eloquent trait that any model (Page, Post, Product, ...) can opt into.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
