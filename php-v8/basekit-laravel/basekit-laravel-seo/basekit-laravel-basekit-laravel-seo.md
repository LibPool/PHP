# basekit-laravel/basekit-laravel-seo

> 标签: JSON-LD, Sitemap, basekit, laravel, robots, seo, structured-data

## 简介

Basekit Laravel SEO is a reusable, optional feature package for centralized metadata, structured data (JSON-LD), robots directives and XML sitemaps on Basekit-powered Laravel websites.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
