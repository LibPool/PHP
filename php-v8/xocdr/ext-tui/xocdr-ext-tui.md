# xocdr/ext-tui

> 标签: cli, extension, flexbox, layout, php, terminal, tui, yoga

## 简介

Terminal UI extension with Yoga layout engine for PHP (inspired by React INK)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
