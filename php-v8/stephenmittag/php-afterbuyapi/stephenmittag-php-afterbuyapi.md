# stephenmittag/php-afterbuyapi

> 标签: afterbuy

## 简介

The WkAfterbuyApi provides a Symfony2 service to interact with the Afterbuy XML API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
