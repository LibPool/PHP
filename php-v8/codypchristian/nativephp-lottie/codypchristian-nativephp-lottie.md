# codypchristian/nativephp-lottie

> 标签: PHP

## 简介

In-app Lottie EDGE component (<native:lottie-view>) for NativePHP Mobile v4 — bundled or URL dotLottie playback on iOS & Android.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
