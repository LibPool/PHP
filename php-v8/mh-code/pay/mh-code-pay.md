# mh-code/pay

> 标签: alipay, pay, payment, wechat, wechatpay, 微信支付, 微信支付v3, 支付宝

## 简介

一款零第三方依赖的 PHP 支付聚合包，基于微信支付 V3 API 实现主要功能，支持通过插件机制扩展新接口与支付宝等新渠道。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
