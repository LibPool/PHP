# jacklul/cachefs

> 标签: cache, cachefs, filesystem

## 简介

Filesystem wrapper that uses PSR-16 cache interface as storage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
