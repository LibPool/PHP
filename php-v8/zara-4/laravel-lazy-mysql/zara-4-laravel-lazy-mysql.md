# zara-4/laravel-lazy-mysql

> 标签: database, eloquent, laravel, lazy-mysql, model, mysql

## 简介

A lazy mysql based Eloquent model and Query builder for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
