# wthaiq/wthaiq-php

> 标签: api, contracts, digital signature, e-signature, eSignature, electronic signature, sdk, signature request, webhooks, wthaiq

## 简介

Official PHP library for the Wthaiq e-signature API: signature requests, templates, sessions, embedded signing, evidence records and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
