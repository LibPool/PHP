# jfcherng/php-aacodec

> 标签: aadecode, aadecoder, aaencode, aaencoder, codec, decoder, encoder, javascript

## 简介

Encode/decode JavaScript to/from Japanese style emoticons.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
