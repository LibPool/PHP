# jfcherng/php-levenshtein-distance

> 标签: edit-progress, levenshtein-distance

## 简介

Calculate the Levenshtein distance and edit progresses between two strings.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
