# luany/framework

> 标签: ast, compiler, framework, luany, mvc, php

## 简介

Luany Framework — Compiler-grade PHP MVC framework. Integrates luany/core and luany/lte.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
