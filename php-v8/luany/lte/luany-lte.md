# luany/lte

> 标签: ast, compiler, engine, lte, luany, php, template

## 简介

LTE — AST-based template engine for PHP. Compiler-grade templating with zero regex parsing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
