# inigopascall/clone-db

> 标签: PHP

## 简介

Package for cloning medium-size databases by ordering tables by foreign-key dependencies and running batch inserts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
