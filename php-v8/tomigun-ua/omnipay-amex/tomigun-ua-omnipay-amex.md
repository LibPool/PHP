# tomigun-ua/omnipay-amex

> 标签: amex, gateway, merchant, omnipay, pay, payment

## 简介

Amex driver for the Omnipay 3.0 payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
