# scrapingisnotacrime/sdk

> 标签: TikTok , app-store, bluesky, github, hacker-news, instagram, linktree, psr-18, scraping, twitch, youtube

## 简介

PHP client for the ScrapingIsNotACrime API: public data from Instagram, TikTok, YouTube, the App Store, GitHub, Hacker News, Bluesky, Twitch and Linktree.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
