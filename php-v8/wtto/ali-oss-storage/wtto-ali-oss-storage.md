# wtto/ali-oss-storage

> 标签: aliyun, filesystems, laravel, oss, storage

## 简介

aliyun oss filesystem storage for laravel 5+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
