# tronsave/sdk

> 标签: bandwidth, energy, sdk, tron, tronsave

## 简介

Fully-typed PHP SDK for the Tronsave v2 API (TRON Energy & Bandwidth).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
