# the-basement/libvirt

> 标签: KVM, Virtualization, hypervisor, libvirt, qemu, thebasement.club

## 简介

This package implements the domain service contract for the libvirt hypervisor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
