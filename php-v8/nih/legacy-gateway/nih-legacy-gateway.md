# nih/legacy-gateway

> 标签: incremental migration, legacy, legacy fallback, legacy migration, modernization, psr-15, psr-15 middleware, route-by-route migration, route-level, routing, strangler pattern

## 简介

Route-level legacy fallback for route-by-route migration in PSR-15 applications built on nih/http-kernel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
