# nih/http-kernel

> 标签: PSR-11, http, kernel, psr-15, psr-17, psr-7, request, response

## 简介

Minimal HTTP kernel for PSR-7, PSR-11, PSR-15 and PSR-17 based applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
