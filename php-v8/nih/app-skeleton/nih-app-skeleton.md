# nih/app-skeleton

> 标签: Skeleton, http, middleware, psr-15, psr-17, psr-7, routing, starter

## 简介

Lightweight starter project for PSR-7/PSR-15 HTTP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
