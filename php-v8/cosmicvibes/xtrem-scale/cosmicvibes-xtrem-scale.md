# cosmicvibes/xtrem-scale

> 标签: gram-xtreme, laravel, scale, udp, weighing

## 简介

Laravel package for communicating with Gram Xtreme F-06 scales over UDP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
