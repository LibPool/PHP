# domm98cz/image

> 标签: Webp, avif, gd, gif, image, imagick, psr-7, resize, steganography, watermark

## 简介

Driver-agnostic image manipulation for PHP: GD and Imagick behind one immutable, fluent API, with animation, watermarking and optimization.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
