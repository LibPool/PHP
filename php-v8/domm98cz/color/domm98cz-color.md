# domm98cz/color

> 标签: cielab, color, color-space, colour, contrast, css-color, oklch, palette, wcag

## 简介

Small PHP library for colors: create from hex, rgb, hsl or CSS, convert, tint and shade, harmonies, contrast, CSS output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
