# mevisoft/auth-accounts-luisml

> 标签: PHP

## 简介

Laravel client for Accounts LuisML: Continuar con LuisML (OpenID Connect) with central session control.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
