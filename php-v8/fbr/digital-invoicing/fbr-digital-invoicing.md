# fbr/digital-invoicing

> 标签: api, digital-invoicing, e-invoicing, fbr, fbr-api, government-api, integration, invoice, laravel, pakistan, pakistan-tax, sales-tax, sales-tax-api, tax-management

## 简介

Comprehensive Laravel package for Pakistan's Federal Board of Revenue (FBR) Digital Invoicing System API v1.12 integration with support for all 28 sandbox scenarios, reference data APIs, and complete invoice management

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
