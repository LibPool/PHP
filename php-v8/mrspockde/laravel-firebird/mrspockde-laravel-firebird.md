# mrspockde/laravel-firebird

> 标签: database, eloquent, firebird, laravel, migrations, pdo, schema-builder

## 简介

Firebird database driver for Laravel with Eloquent, Schema Builder and migration support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
