# imms/gitlab-theme-light

> 标签: gitlab, html, imms, imms-theme, light, markdown, php, theme

## 简介

A theme based on IMMS Dark (but is light), but for IMMS with Gitlab plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
