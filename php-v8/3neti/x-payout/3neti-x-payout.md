# 3neti/x-payout

> 标签: laravel, payouts, payroll, x-change, x-payout

## 简介

A thin Laravel 13 host for x-PayOut powered by 3neti/x-change.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
