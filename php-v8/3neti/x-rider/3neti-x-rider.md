# 3neti/x-rider

> 标签: PHP

## 简介

Programmable claimant experience layer for post-claim rider messages, redirects, splash, analytics seams, and future campaign runtimes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
