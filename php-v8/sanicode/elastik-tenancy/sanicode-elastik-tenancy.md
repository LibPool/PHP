# sanicode/elastik-tenancy

> 标签: framework, jetstream, laravel, multitenancy, saas

## 简介

The starterkit application, based on Laravel Jetstream for support multi-tenancy platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
