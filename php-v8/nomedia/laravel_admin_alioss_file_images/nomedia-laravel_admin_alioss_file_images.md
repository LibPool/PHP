# nomedia/laravel_admin_alioss_file_images

> 标签: extension, laravel-admin

## 简介

laravel-admin扩展，web直传阿里OSS（file，image，editor）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
