# webcrawlerapi/sdk

> 标签: api, crawler, data, llm, rag, scraper, sdk, webcrawler, webcrawlerapi, website

## 简介

A PHP SDK for WebCrawler API - turn website into data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
