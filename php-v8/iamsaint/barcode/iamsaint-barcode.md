# iamsaint/barcode

> 标签: CODABAR, CODE 128, CODE 39, CODE 93, Data Matrix, EAN-13, EAN-8, ITF, UPC-A, UPC-E, qr code

## 简介

UPC-A, UPC-E, EAN-13, EAN-8, Code 39, Code 93, Code 128, Codabar, ITF, QR Code, and Data Matrix generator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
