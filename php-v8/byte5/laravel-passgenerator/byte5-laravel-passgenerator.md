# byte5/laravel-passgenerator

> 标签: apple, laravel, passbook, php

## 简介

A Laravel package to create Apple Wallet (old Passbook) compatible tickets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
