# diego-ninja/granite

> 标签: auto-mapper, auto-mapping, data-mapper, data-object, data-structure, data-transfer-object, dto, immutable, objects, php, serializable, value-object

## 简介

A lightweight zero-dependency PHP library for building immutable, serializable objects with validation capabilities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
