# ahmedkhd/sylius-bot-plugin

> 标签: sylius, sylius-plugin

## 简介

Sylius Bot for publishing your store on messenger and start receiving orders from outside the front store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
