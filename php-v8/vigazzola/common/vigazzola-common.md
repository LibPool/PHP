# vigazzola/common

> 标签: ZendFramework, zend-expressive, zf

## 简介

Fornisce un metodo statico per avere in ogni punto del codice il ServiceManager pre i servizi IoC.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
