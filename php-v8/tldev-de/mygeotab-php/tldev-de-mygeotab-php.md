# tldev-de/mygeotab-php

> 标签: api, geotab, mygeotab, sdk

## 简介

Unofficial fork of unofficial PHP client for the MyGeotab API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
