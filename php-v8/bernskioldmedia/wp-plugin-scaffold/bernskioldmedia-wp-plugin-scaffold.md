# bernskioldmedia/wp-plugin-scaffold

> 标签: PHP

## 简介

A WordPress plugin scaffold that we use at Bernskiold Media when developing client specific plugins.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
