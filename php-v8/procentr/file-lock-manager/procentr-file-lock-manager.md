# procentr/file-lock-manager

> 标签: PHP

## 简介

A lightweight PHP library for managing file locks. No, seriously, it works. I mean... does anyone actually use this? ;-)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
