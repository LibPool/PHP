# cyberuslabs/cyberkey

> 标签: cyberkey, cyberuslabs, eliot pro, login, php

## 简介

Server side PHP library to integrate your system with Cybeurs Key easily

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
