# noehassiel/confetti

> 标签: Confetti, android, edge-component, ios, laravel, mobile, nativephp

## 简介

Native confetti celebrations for NativePHP Mobile — a custom EDGE element backed by Konfetti (Jetpack Compose) on Android and a hand-rolled SwiftUI particle system on iOS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
