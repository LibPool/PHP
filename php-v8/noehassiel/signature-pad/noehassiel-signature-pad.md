# noehassiel/signature-pad

> 标签: android, edge-component, ios, laravel, mobile, nativephp, signature

## 简介

Native signature capture for NativePHP Mobile — a freehand drawing surface (SwiftUI Path on iOS, Compose Canvas on Android) that hands PHP a base64-encoded PNG.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
