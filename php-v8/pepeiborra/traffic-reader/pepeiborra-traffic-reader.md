# pepeiborra/traffic-reader

> 标签: Audit, laravel, middleware, security, threat-detection, traffic-reader

## 简介

Lightweight SIEM middleware for Laravel: visit tracking, threat detection, and security alerting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
