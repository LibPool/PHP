# aoding9/compreface-laravel-sdk

> 标签: PHP

## 简介

本sdk是根据compreface-javascript-sdk开发的laravel版本，仅做封装，将js改为laravel的写法，文档后半部分demo代码仍为js语法，参考前面即可

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
