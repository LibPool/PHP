# weline/module-ali-ddns-server

> 标签: PHP

## 简介

Weline提供的基于WelineFramework框架的阿里云Ddns解析服务，支持ipv4和ipv6，支持多域名批量解析。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
