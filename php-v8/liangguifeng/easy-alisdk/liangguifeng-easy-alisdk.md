# liangguifeng/easy-alisdk

> 标签: Alipay API, alibaba, alipay, aliyun, easy-alisdk, php, sdk

## 简介

An Alibaba cloud's Alipay Function Expansion Kit, according to the official new version of SDK, is upgrading and upgrading, supporting the opening of API interface to Alipay, which is easy to develop small programs, intelligent business circles, payment points, car owners' services, security, payment and other related functions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
