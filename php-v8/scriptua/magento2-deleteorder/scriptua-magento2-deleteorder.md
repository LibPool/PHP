# scriptua/magento2-deleteorder

> 标签: PHP

## 简介

Delete bulk orders from orders list page in backend. Option to enable or disable order deletion from order view page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
