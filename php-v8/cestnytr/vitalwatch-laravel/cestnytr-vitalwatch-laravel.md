# cestnytr/vitalwatch-laravel

> 标签: error-tracking, kvkk, laravel, monitoring

## 简介

VitalWatch monitoring client for Laravel — reports exceptions, slow requests and slow queries without collecting personal data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
