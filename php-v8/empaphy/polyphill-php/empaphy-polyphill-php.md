# empaphy/polyphill-php

> 标签: compatibility, polyfill, portable, shim

## 简介

A metapackage for PHP that installs the polyfills you need, and removes those that are redundant.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
