# flute-cms/cms

> 标签: cms, counter strike, cs1.6, cs2, csgo, css, flute, flute cms, flute engine, flute-cms, minecraft

## 简介

A flexible and modular CMS tailored for managing game servers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
