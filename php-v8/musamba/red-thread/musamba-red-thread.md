# musamba/red-thread

> 标签: Relationships, eloquent, laravel, models, musamba, red-thread

## 简介

Red Thread is a laravel package that helps you easily list all relationships within a given model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
