# react/socket

> 标签: Connection, Socket, async, reactphp, stream, 网络

## 简介

Async, streaming plaintext TCP/IP and secure TLS socket server and client connections for ReactPHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
