# symfony70/polyfill-php80

> 标签: compatibility, polyfill, portable, shim

## 简介

PHP 7.0 version of Symfony polyfill backporting some PHP 8.0+ features to lower PHP versions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
