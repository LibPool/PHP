# cadix/laravel-moodle

> 标签: PHP

## 简介

A non-official Moodle REST API wrapper package for integration with Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://gitlab.com/cadix/web/laravel-moodle
- 源码仓库：git@gitlab.com:cadix/web/laravel-moodle.git
- Packagist 页面：https://packagist.org/packages/cadix%2Flaravel-moodle
