# ufomelkor/cli-tools-installer

> 标签: cli, command line, installer, tools

## 简介

Installer for various CLI Tools that are useful when developing PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
