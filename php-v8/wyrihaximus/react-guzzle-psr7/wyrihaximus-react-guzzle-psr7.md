# wyrihaximus/react-guzzle-psr7

> 标签: PHP

## 简介

Asyncronous Guzzle (PSR7) adapter powered by react/http-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
