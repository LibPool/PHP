# wyrihaximus/react-guzzle-http-client

> 标签: PHP

## 简介

Asynchronous adapter for different Guzzle versions powered by react/http-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
