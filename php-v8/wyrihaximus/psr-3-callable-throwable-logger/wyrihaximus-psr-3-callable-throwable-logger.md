# wyrihaximus/psr-3-callable-throwable-logger

> 标签: PHP

## 简介

callable throwable decorator around a PSR-3 logger (to be used with react/promise and reactivex/rxphp)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
