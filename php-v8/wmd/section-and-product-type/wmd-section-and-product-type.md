# wmd/section-and-product-type

> 标签: Craft, cms, commerce, craft-plugin, craft5, craftcms, entry type, field, field-type, page builder, product type, section, tag group

## 简介

Craft CMS field types for selecting sections, entry types, Commerce product types and tag groups. Built for page builders and dynamic content listings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
