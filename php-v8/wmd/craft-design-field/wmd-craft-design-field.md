# wmd/craft-design-field

> 标签: Craft, blocks, craft-plugin, craftcms, design-system, design-tokens, field, matrix, page-builder, tailwind

## 简介

One field for every design option of a block: tone, spacing, layout, columns and more, picked from named choices you define once. Swatches, picture tiles, sliders and position grids; options that only show when they apply.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
