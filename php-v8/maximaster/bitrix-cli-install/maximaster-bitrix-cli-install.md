# maximaster/bitrix-cli-install

> 标签: PHP

## 简介

Установка Битрикс из дистрибутива или резервную копию через консольную команду. Запуск веб-сервера не требуется

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
