# maximaster/tools.twig

> 标签: 1С Битрикс, bitrix, twig, максимастер, шаблонизатор

## 简介

Модуль подключения шаблонизатора twig к битриксу

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
