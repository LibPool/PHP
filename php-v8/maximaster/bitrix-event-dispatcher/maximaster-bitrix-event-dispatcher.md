# maximaster/bitrix-event-dispatcher

> 标签: PHP

## 简介

EventDispatcherInterface-совместимый диспетчер для регистрации обработки событий вызываемых через API Битрикс.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
