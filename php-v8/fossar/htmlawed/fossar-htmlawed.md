# fossar/htmlawed

> 标签: HTMLtidy, html, sanitize, strip, tags

## 简介

htmLawed - Process text with HTML markup to make it more compliant with HTML standards and administrative policies

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
