# xaboy/laravel-merge-request

> 标签: laravel, request

## 简介

laravel框架 根据路由规则创建/发起虚拟请求,可以在当前请求中发起多个虚拟请求

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
