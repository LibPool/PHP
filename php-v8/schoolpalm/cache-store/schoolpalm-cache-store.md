> 标签: array-cache, cache, cache-store, caching, context-aware, database-cache, driver, file-cache, laravel, laravel-package, multi-tenant, psr-16, redis-cache, schoolpalm

## 简介

A context-aware cache abstraction layer for Laravel applications with multi-tenant and multi-school support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
