# schoolpalm/app-settings

> 标签: Settings, app-settings, laravel, laravel-package, multi-tenant, school-context, schoolpalm, tenant-context

## 简介

A Laravel settings management package providing multi-tenant and context-aware configuration storage using CacheStore.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
