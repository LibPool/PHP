# mochipay/php-sdk

> 标签: api, checkout, crypto, mochipay, payment-gateway, payments

## 简介

Server-side PHP client for MochiPay crypto payments, independent request retries and verified order queries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
