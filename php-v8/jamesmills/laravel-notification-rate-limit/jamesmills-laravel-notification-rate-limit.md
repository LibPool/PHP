# jamesmills/laravel-notification-rate-limit

> 标签: jamesmills, laravel-notification-rate-limit

## 简介

Rate limiter to avoid flooding users with duplicate notifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
