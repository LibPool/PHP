# kevinlangleyjr/wp-contextual-help

> 标签: PHP

## 简介

WordPress plugin that allows a developer to easily extend the contextual help dropdown content area in WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
