# rhubarbphp/custard

> 标签: cli, command-line, custard, framework, php, rhubarb, tools

## 简介

Provides command line tools for Rhubarb projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
