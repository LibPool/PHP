# rhubarbphp/module-stem

> 标签: Modelling, data, framework, model, orm, php

## 简介

A data modelling and ORM module for the Rhubarb PHP framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
