# divino11/laravel-playtomic

> 标签: api, booking, laravel, padel, playtomic

## 简介

Laravel SDK for the Playtomic API — venue search, court availability, booking, and authentication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
