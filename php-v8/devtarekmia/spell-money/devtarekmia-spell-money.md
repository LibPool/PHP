# devtarekmia/spell-money

> 标签: convert number to word, lakh crore, number bangladeshi words, number to indian english, number to taka, number to word, number to words, spell money, spell-money, taka paisa, tarekmia

## 简介

By using this standalone package, you can convert numeric values into words in English based on Bangladeshi numeric counting (lakh-crore).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
