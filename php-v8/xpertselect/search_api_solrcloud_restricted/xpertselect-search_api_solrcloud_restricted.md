# xpertselect/search_api_solrcloud_restricted

> 标签: PHP

## 简介

This Drupal module provides a Search API Solr connector for SolrCloud instances that do not allow access to its admin API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
