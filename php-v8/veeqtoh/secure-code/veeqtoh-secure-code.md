# veeqtoh/secure-code

> 标签: clock-in, clock-out, laravel, laravel-package, palindrome, persistent-codes, random-code-allocation, repeated characters, secure-access, secure-code, unique characters, unique-codes, veeqtoh, victor-ukam

## 简介

A Laravel package for creating secure codes, providing unique and random n-digit codes for any use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
