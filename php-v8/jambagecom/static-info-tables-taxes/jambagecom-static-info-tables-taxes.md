# jambagecom/static-info-tables-taxes

> 标签: Static Info Tables, TYPO3 CMS, tax

## 简介

Tables and functions used for dealing with taxes. TYPO3 extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
