# jambagecom/static-info-tables-es

> 标签: Static Info Tables, TYPO3 CMS

## 简介

Static Info Tables (es) - Spanish (es) language pack for the Static Info Tables providing localized names for countries, currencies and so on.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
