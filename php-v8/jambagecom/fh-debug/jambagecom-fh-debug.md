# jambagecom/fh-debug

> 标签: TYPO3 CMS, debug, devlog, error, oops, syslog

## 简介

FH Debug - PHP debugger, sys_log and devLog Logger

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
