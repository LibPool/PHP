# tbolner/twitter-php-ads-sdk

> 标签: Twitter API, Twitter oAuth, ads, api, oauth, rest, social, twitter

## 简介

A Twitter supported and maintained Ads API SDK for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
