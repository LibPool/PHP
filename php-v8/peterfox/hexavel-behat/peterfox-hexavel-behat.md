# peterfox/hexavel-behat

> 标签: BDD, Behat, hexavel, laravel, page pattern

## 简介

A Library for Hexavel which makes BDD with Behat simpler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
