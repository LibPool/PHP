# xpaw/crimp

> 标签: Guzzle, async, asynchronous, curl, multi, parallel, rolling

## 简介

A simple multi curl implementation, optimized for high concurrency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
