# smronju/nativephp-secure-storage

> 标签: android, ios, keychain, keystore, laravel, mobile, nativephp, secure-storage

## 简介

Implements NativePHP Mobile's SecureStorage::set()/get()/delete() on both platforms — Android Keystore (AES-256-GCM) on Android, the Keychain on iOS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
