# statamic-addon/component-exporter

> 标签: PHP

## 简介

Export and import page sections — fieldsets, partials, baked Tailwind and previews travel together — as a ZIP, from the Control Panel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
