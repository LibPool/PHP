# ujy/bitrix24_api_authorization

> 标签: Bitrix24, access, api, token

## 简介

Authorization class to easy get Bitrix24 Access Tokens for use in API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
