# mohemian/flink-sdk-php

> 标签: JWKS, eID, flink, id-austria, jwt, laravel

## 简介

Verify FLINK's signed assertions (eID prefill, flow results) in a Laravel backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
