# omnitech-solutions/flowlight

> 标签: LightService, actions, orchestration, php, pipeline, service-object, workflow

## 简介

Lightweight workflow orchestration library for PHP. Provides a clean, composable pattern for chaining actions into pipelines, handling success/failure consistently. Inspired by Ruby’s LightService.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
