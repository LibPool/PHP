# v-dem/queasy-db

> 标签: crud, database, mysql, pdo, pdo wrapper, postgresql, sqlite

## 简介

Database access classes, part of QuEasy PHP framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
