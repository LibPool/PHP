# thomasdcodes/toolbox-bundle

> 标签: Toolbox, class collection, helper classes

## 简介

Gives a toolbox with a lot of helper classes and functionality needed in every project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
