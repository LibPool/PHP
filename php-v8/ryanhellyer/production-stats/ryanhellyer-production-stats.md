# ryanhellyer/production-stats

> 标签: laravel, load-time, monitoring, performance, production, stats, symfony

## 简介

Production-ready performance monitoring for Laravel and Symfony - automatically track and inject performance statistics into HTML responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
