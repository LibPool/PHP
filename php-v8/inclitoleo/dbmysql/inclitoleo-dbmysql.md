# inclitoleo/dbmysql

> 标签: cakephp, laravel, mysql, pdo, query-builder, symfony

## 简介

Simple, fast MySQL library for PHP. Raw SQL or query builder. Compatible with Laravel, CakePHP, and Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
