# blenderrus/flarum-indexnow

> 标签: bing, flarum, flarum-extension, indexnow, seo, yandex

## 简介

IndexNow for Flarum: tells Bing, Yandex and other search engines about new, changed and removed discussions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
