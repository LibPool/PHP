# pushword/installer

> 标签: cms, installer, pushword, symfony

## 简介

Run the post-install scripts shipped by Pushword bundles when a Pushword app is installed or updated.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
