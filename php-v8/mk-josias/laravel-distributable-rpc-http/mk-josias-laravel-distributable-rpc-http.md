# mk-josias/laravel-distributable-rpc-http

> 标签: http, laravel, microservices, rpc

## 简介

HTTP driver for the RPC of mk-josias/laravel-distributable: signed calls between modules, one endpoint per module.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
