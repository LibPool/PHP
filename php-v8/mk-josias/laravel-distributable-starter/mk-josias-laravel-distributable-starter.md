# mk-josias/laravel-distributable-starter

> 标签: distributable, laravel, modular-monolith, starter-kit

## 简介

Starter kit for laravel-distributable: a modular monolith deployable as one process or as one process per module.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
