# mk-josias/laravel-distributable-stream-redis

> 标签: events, laravel, microservices, stream-rediss

## 简介

Redis Streams driver for the events of mk-josias/laravel-distributable: one ordered stream, a consumer group per module, failed entries retried before later ones, or dropped.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
