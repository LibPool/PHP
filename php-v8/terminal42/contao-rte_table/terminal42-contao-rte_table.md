# terminal42/contao-rte_table

> 标签: contao, rte, table, tinymce

## 简介

Use tinyMCE (or in future maybe other Rich Text Editors) for every cell in the Contao table content element

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
