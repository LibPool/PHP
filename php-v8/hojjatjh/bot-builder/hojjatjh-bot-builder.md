# hojjatjh/bot-builder

> 标签: bot, bot-builder, generator, php, scaffold, telegram, template

## 简介

A PHP tool to scaffold ready-to-run Telegram bots from reusable templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
