# oneduo/lighthouse-category-handler

> 标签: category, extension, laravel, lighthouse, missing

## 简介

Adds the missing category handler that was removed from Lighthouse 6.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
