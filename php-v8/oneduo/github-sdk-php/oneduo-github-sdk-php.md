# oneduo/github-sdk-php

> 标签: github, github-sdk-php, laravel, oneduo, php, sdk

## 简介

PHP SDK for the GitHub REST API – OpenAPI based and fully typed for seamless integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
