# visol/ipauthtrigger

> 标签: PHP

## 简介

A TYPO3 frontend plugin triggering the IP Authentication (from aeo_ipauth) if the user is in a certain IP range

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
