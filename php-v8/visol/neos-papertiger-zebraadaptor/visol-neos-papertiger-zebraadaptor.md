# visol/neos-papertiger-zebraadaptor

> 标签: Forms, Neos, headless, neos-package, nextjs, papertiger, zebra

## 简介

Renders Sitegeist.PaperTiger forms through a headless Neos content API (Zebra / Next.js) instead of Fusion

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
