# leogopal/simplifii

> 标签: themes, wordpress

## 简介

Simplifii is a simple multipurpose and flexible Full Site Editing theme for WordPress with WooCommerce support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
