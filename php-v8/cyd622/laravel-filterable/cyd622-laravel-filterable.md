# cyd622/laravel-filterable

> 标签: Laravel 4, database, eloquent, laravel

## 简介

Laravel package for dynamically filtering Eloquent results using URL query string.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
