# comcast/splunk-http-event-collector-handler

> 标签: PHP

## 简介

Monolog handler for Splunk HTTP Event Collector (HEC) to send events to a REST API instead of a log forwarder

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
