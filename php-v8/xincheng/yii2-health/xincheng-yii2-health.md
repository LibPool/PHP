# xincheng/yii2-health

> 标签: health, healthcheck, kubernetes, liveness, readiness, yii2

## 简介

Health check extension for Yii2 (HTTP + CLI + Kubernetes probes).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
