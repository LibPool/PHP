# pigeonboys/fastpush

> 标签: PHP

## 简介

Fastpush is a lightweight PHP package for sending push notifications via an API, offering easy setup with channel and topic management.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
