# chredeur/pterodactyl-api-addon

> 标签: PterodactylApiAddon, laravel, pterodactyl-api-addon

## 简介

This package adds endpoints to the Pterodactyl application API: server transfers between nodes, and attaching/detaching mounts to a server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
