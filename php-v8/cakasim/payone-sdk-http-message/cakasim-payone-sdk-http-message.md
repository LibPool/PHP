# cakasim/payone-sdk-http-message

> 标签: payment, payone, psr-17, psr-7, sdk

## 简介

A PSR-7 and PSR-17 Implementation for the SDK for PAYONE Payment Integration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
