# cakasim/payone-sdk-stream-client

> 标签: payment, payone, psr-18, sdk

## 简介

A PSR-18 Stream Client Implementation for the SDK for PAYONE Payment Integration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
