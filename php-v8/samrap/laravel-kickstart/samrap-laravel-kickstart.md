# samrap/laravel-kickstart

> 标签: elixir, laravel, package

## 简介

An more advanced workflow for one of the most popular and fastest-growing PHP frameworks available.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
