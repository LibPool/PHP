# xsga/bbphp-emailsender-smtp-adapter

> 标签: adapter, bbphp, email, emailsender, library, php, smtp

## 简介

A PHP library that provides an SMTP adapter for the BBPHP EmailSender Core library, enabling email sending functionality via SMTP protocol.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
