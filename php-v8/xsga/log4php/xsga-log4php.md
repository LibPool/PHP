# xsga/log4php

> 标签: log, log4php, logger, logging, psr-3

## 简介

A PHP logging library based on Apache Log4PHP, PSR-3 compliant, supporting multiple appenders, layouts and log levels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
