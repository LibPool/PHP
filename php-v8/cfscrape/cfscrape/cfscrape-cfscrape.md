# cfscrape/cfscrape

> 标签: ScoLib, cfscrape, cloudflare

## 简介

A PHP module to bypass Cloudflare's anti-bot page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
