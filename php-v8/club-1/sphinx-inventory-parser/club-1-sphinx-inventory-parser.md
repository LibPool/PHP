# club-1/sphinx-inventory-parser

> 标签: PHP

## 简介

Parse Sphinx documentation's object.inv inventory file format into an indexed SphinxInventory object.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
