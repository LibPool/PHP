# tailflow/castable-dto

> 标签: laravel castable data transfer object, laravel castable dto, laravel castable value object, laravel data transfer object, laravel value object, tailflow

## 简介

Automatically cast JSON columns to PHP objects in Laravel using Spatie's data-transfer-object class

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
