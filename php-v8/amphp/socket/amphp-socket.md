# amphp/socket

> 标签: Socket, amp, async, encryption, non-blocking, sockets, tcp, tls, 异步

## 简介

Non-blocking socket connection / server implementations based on Amp and Revolt.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
