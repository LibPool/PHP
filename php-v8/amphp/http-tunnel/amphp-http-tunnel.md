# amphp/http-tunnel

> 标签: amphp, async, connect, connector, http, tunnel

## 简介

HTTP/1.1 CONNECT tunnel connector built on the Amp concurrency framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
