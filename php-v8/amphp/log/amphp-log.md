# amphp/log

> 标签: amp, amphp, async, log, logger, logging, non-blocking

## 简介

Non-blocking logging for PHP based on Amp, Revolt, and Monolog.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
