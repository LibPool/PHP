# amphp/amp

> 标签: async, asynchronous, awaitable, concurrency, event, event-loop, future, non-blocking, promise, 协程, 异步

## 简介

A non-blocking concurrency framework for PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
