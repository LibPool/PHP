# amphp/redis

> 标签: amp, amphp, async, client, redis, revolt

## 简介

Efficient asynchronous communication with Redis servers, enabling scalable and responsive data storage and retrieval.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
