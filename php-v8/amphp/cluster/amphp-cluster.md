# amphp/cluster

> 标签: amp, amphp, async, cluster, multi-core, multi-process, non-blocking, parallel, sockets, watcher

## 简介

Building multi-core network applications with PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
