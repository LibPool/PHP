# amphp/file

> 标签: amp, amphp, async, disk, file, filesystem, io, non-blocking, static

## 简介

Non-blocking access to the filesystem based on Amp and Revolt.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
