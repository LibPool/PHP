# amphp/http-client-guzzle-adapter

> 标签: Guzzle, adapter, amphp, async, client, http, http-client, psr7

## 简介

Guzzle adapter for Amp's HTTP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
