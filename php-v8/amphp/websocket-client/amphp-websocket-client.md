# amphp/websocket-client

> 标签: WebSocket, amp, amphp, async, client, http, non-blocking, websocket, 客户端

## 简介

Async WebSocket client for PHP based on Amp.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
