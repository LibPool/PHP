# rootpd/openpgp-php

> 标签: PHP

## 简介

Pure-PHP implementation of the OpenPGP Message Format (RFC 4880). This fork exists only to have tagged v0.5 compatible with PHP 8.1.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
