# exads/twilio-sdk

> 标签: api, sms, twilio

## 简介

Not official, A PHP wrapper for Twilio's API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- Packagist 页面：https://packagist.org/packages/exads%2Ftwilio-sdk
