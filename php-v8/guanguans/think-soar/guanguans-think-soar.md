# guanguans/think-soar

> 标签: debug, mysql, soar, sql, think

## 简介

SQL optimizer and rewriter extension package for thinkphp5 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
