# caturseptian/laravel-indonesia-territory

> 标签: desa, geojson, indonesia, kabupaten, kecamatan, kelurahan, kemendagri, kode-pos, kode-wilayah, kodifikasi-wilayah, kota, laravel, provinsi, region, territory, wilayah

## 简介

Indonesian administrative regions (Kemendagri codes) for Laravel: provinces, regencies, districts, villages, postal codes, coordinates, boundaries and islands. Install once, eject for zero runtime dependency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
