# vbuck/magento-module-bundler

> 标签: PHP

## 简介

Module bundling utility. Bundles Magento modules from Composer vendor spaces into ZIP artifacts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
