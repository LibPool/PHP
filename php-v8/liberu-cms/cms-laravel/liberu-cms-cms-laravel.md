# liberu-cms/cms-laravel

> 标签: cms, framework, laravel, liberu

## 简介

Liberu CMS: a modular Laravel application with API, Filament, and Livewire foundations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
