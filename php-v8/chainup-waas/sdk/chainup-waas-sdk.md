# chainup-waas/sdk

> 标签: blockchain, chainup, cryptocurrency, custody, mpc, waas, wallet

## 简介

ChainUp Custody PHP SDK - WaaS and MPC Wallet API Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
