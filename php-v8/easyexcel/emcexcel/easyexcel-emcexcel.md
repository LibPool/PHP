# easyexcel/emcexcel

> 标签: PHPExcel, excel, php, phpspreadsheet, xfxstudios

## 简介

Gestión simple de Archivos Excel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
