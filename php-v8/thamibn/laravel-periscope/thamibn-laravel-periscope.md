# thamibn/laravel-periscope

> 标签: Clockwork, Xdebug, ai-debugging, debug, debugbar, debugger, debugging, laravel, laravel-12, laravel-13, mcp, n-plus-one, observability, periscope, php-periscope, profiler, profiling, query-log, replay, request-debugging, rewind, rewind-request, sql-debugging, step-back, telescope, telescope-alternative, time-travel, time-travel-debugging, tracing, xdebug-alternative

## 简介

Laravel adapter for php-periscope — wires Telescope-tier observability events into the periscope C extension's trace. Time-travel debugging, SQL/log/cache/job inspection, and an AI-native MCP server in one package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
