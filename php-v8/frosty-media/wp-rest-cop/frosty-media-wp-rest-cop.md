# frosty-media/wp-rest-cop

> 标签: rate-limiting, wordpress-plugin, wordpress-rest-api

## 简介

A WordPress plugin for managing access to the WP REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
