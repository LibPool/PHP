# ftwex/fpdf-symfony2

> 标签: PHP

## 简介

fpdf vendor for use with symfony2, based on toooni/fpdf

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://github.com/royopa
- 源码仓库：https://github.com/FTwex/fpdf-symfony2.git
