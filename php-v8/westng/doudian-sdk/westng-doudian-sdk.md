# westng/doudian-sdk

> 标签: Doudian, api, coroutine, douyin, ecommerce, jinritemai, sdk, swoole

## 简介

抖店（抖音电商）开放平台 PHP SDK，支持710+个API接口，支持 Swoole 协程环境

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
