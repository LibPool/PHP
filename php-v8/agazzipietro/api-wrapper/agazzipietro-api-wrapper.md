# agazzipietro/api-wrapper

> 标签: api, client, php, remote, rest, wrapper

## 简介

A system for quickly developing PHP wrapper clients around remote APIs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
