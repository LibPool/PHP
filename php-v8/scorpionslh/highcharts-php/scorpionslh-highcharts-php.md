# scorpionslh/highcharts-php

> 标签: charts, highcharts, highstock, javascript, php

## 简介

A php wrapper for highcharts and highstock javascript libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
