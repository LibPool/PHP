# presta/datadog-bundle

> 标签: DataDog, monolog, symfony

## 简介

PrestaDatadogBundle is a Symfony bundle leveraging a Monolog handler for Datadog.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
