# gold-api/sdk-php

> 标签: api, gold, gold-price, palladium, platinum, precious-metals, quotes, sdk, silver, 行情, 贵金属, 金价, 黄金

## 简介

GoldAPI (gold-api.cn) 贵金属行情 PHP SDK —— 黄金/白银/铂金/钯金等 70+ 品种实时行情，一次请求最多批量 50 个品种

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
