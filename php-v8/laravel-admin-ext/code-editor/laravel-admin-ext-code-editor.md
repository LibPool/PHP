# laravel-admin-ext/code-editor

> 标签: code, code mirror, editor, extension, laravel-admin

## 简介

Code editor extension for laravel-admin based on code-mirror

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
