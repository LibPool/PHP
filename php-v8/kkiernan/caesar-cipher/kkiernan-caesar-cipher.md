# kkiernan/caesar-cipher

> 标签: PHP

## 简介

Encrypt, decrypt and crack messages using the simple Caesar Cipher algorithm.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
