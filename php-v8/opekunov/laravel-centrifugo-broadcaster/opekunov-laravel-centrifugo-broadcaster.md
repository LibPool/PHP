# opekunov/laravel-centrifugo-broadcaster

> 标签: Socket, broadcaster, centrifugo, laravel, laravel-broadcaster, real time, web socket, web-socket

## 简介

Centrifugo broadcaster for Laravel 8.75-13.x and Centrifugo >= 5.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
