# getodden/crm-core

> 标签: companies, contacts, crm, custom-properties, getodden, headless, laravel

## 简介

Headless CRM Core Engine for Odden (Contacts, Companies, Custom Properties, Associations, Timeline)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
