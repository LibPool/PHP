# getodden/inbound-mail

> 标签: bounce, email, helpdesk, inbound-email, laravel, mailgun, postmark, sendgrid, ses

## 简介

Receive email in Laravel from Amazon SES, Mailgun, Postmark and SendGrid as one hardened message object: a sender parsed like a mail client parses it, an honest authenticated flag, delivery reports and automatic-mail detection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
