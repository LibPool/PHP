# weglot/translate-bundle

> 标签: Symfony2, Weglot, i18n, languages, localization, php, symfony, symfony3, symfony4, translate, translation, translator, weglot-integration

## 简介

Seamless integration of Weglot into your Symfony project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
