# hostfog/hostfog-php

> 标签: API-Client, api, backups, control-panel, devops, dns, hostfog, hosting, rest, sdk, ssl

## 简介

Official PHP client for the HostFog Panel REST API: manage sites, databases, SSL, DNS, backups and server stats.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
