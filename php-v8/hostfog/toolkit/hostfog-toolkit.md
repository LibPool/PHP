# hostfog/toolkit

> 标签: certificate, devops, dns, dns-over-https, domain, health-check, hosting, nginx, punycode, ssl, sysadmin, tls

## 简介

Zero-dependency toolkit for web developers and server admins: domain normalisation, DNS-over-HTTPS lookups, SSL certificate checks, Nginx config builder, health checks and utilities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
