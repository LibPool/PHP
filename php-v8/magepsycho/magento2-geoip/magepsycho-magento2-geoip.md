# magepsycho/magento2-geoip

> 标签: PHP

## 简介

Shared IP geolocation service for MagePsycho extensions, powered by MaxMind GeoLite2 (City + ASN).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
