# murkrow/filament-ai

> 标签: embeddings, filament, laravel, llm, mcp, pgvector, rag, vector-search

## 简介

AI agents and a grounded knowledge base for Filament panels: resource-derived tools, retrieval with citations, native chat, metrics and an MCP server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
