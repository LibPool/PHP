# kschroeder/spaced-tracker

> 标签: SpaceTrack, omm, psr-18, satellites, space-track, tle

## 简介

Framework-agnostic PHP client for every Space-Track.org API controller and request class.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
