# kschroeder/spaced-tracker-ai

> 标签: llm, space-track, spacexai, xai

## 简介

Adapters for PHP AI libraries and orbital analysis for kschroeder/spaced-tracker. SpaceXAI is the default model provider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
