> 标签: Ks Sadi, Laravel Log Tracker, Laravel Log Viewer, Log Tracker By Sadi, debugging, laravel, log tracker, log viewer, logs, monitoring

## 简介

A powerful, intuitive, and efficient log viewer for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
