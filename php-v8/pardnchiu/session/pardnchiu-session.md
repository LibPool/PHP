# pardnchiu/session

> 标签: PHP

## 简介

PD\Session is a flexible PHP session manager with Redis support and filesystem fallback, providing secure session handling with automated storage selection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
