# oxmohsen/validating-data

> 标签: PHP

## 简介

example of how to validate incoming data from web app telegram bot to ensure that the data is come from telegram.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
