# artex/logger

> 标签: Artex, Artex-Agency, Artex-Software, custom-logger, efficient-logging, error-logging, lightweight-logger, logger, logging, php, php-library, php-logging, psr-3, psr-logger

## 简介

Lightweight, PSR-3-compliant PHP logger for fast and efficient logging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
