# faonni/module-breadcrumbs

> 标签: PHP

## 简介

Extension add breadcrumbs to pages in Magento 2 that by default do not have breadcrumbs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
