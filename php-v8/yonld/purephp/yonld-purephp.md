# yonld/purephp

> 标签: HTML5, php, render, template, templating-engine, vdom, virtual-dom, xml

## 简介

Pure is a PHP template engine inspired by ReactJS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
