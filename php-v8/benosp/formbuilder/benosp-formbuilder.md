# benosp/formbuilder

> 标签: BenOSP, builder, form, php oop

## 简介

BenOSP(Abass Ben Cheik Open-Source Project) php form builder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
