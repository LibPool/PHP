# duanvnc/php-resque

> 标签: background, job, redis, resque, worker

## 简介

Redis backed library for creating background jobs and processing them later. Based on Ruby resque.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
