# lake/laravel-admin-lapi

> 标签: admin, api, ext, lapi, laravel-admin

## 简介

The laravel-admin-lapi is an addon package for laravel-admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
