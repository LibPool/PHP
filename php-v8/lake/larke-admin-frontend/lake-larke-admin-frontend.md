# lake/larke-admin-frontend

> 标签: admin, element-ui, frontend, laravel, larke, larke-admin, larke-admin-frontend, vue, vue-element-admin

## 简介

A frontend for larke-admin with vue2 and element-ui.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
