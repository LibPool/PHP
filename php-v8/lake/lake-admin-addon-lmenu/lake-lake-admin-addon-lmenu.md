# lake/lake-admin-addon-lmenu

> 标签: addon, admin, lake, lake-admin, lmenu

## 简介

The Lake-admin-addon-lmenu is an addon package for lake-admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
