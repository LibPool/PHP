# lake/lake-admin-addon-lroute

> 标签: addon, admin, lake, lake-admin, lroute

## 简介

The Lake-admin-addon-lroute is an addon package for lake-admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
