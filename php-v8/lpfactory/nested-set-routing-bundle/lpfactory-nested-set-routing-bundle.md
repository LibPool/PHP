# lpfactory/nested-set-routing-bundle

> 标签: bundle, cmf, doctrine, nested, routing, symfony

## 简介

Cmf routing provider for Doctrine Nested Set Behavior

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
