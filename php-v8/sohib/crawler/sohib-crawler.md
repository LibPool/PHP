# sohib/crawler

> 标签: crawler, page, scanner, url

## 简介

Scan Http URLs from a url containing an HTML  and get Json or Xml or Array

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
