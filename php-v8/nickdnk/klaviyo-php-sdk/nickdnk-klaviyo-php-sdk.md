# nickdnk/klaviyo-php-sdk

> 标签: api, client, klaviyo, oauth, psr-18, sdk, webhooks

## 简介

A typed PHP client for the Klaviyo API with OAuth, webhooks and any PSR-18 HTTP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
