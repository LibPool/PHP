# hnhdigital-os/fs-watcher

> 标签: cli, filesystem, inotify, php, watcher

## 简介

Provides the ability to watch folders for changes and call a binary in response.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
