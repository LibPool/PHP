# hnhdigital-os/mysql-helper

> 标签: backup, cli, clone, console, mysql

## 简介

Provides a helper to sync, clone, and backup local & remote databases.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
