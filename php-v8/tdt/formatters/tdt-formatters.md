# tdt/formatters

> 标签: format rdf triple arrays objects

## 简介

Formats PHP arrays, PHP objects and RDF triples in a lot of formats.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
