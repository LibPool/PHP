# ymlluo/group-robot

> 标签: Feishu, GroupRobot, dingtalk, laravel, robot, wechat

## 简介

钉钉、企业微信、飞书 自定义群组机器人。支持链式语法创建发送消息。支持文本、Markdown、图片、文件、图文、卡片等消息。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
