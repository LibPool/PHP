# frankkessler/incontact-laravel-oauth2-rest

> 标签: incontact, oauth2, rest

## 简介

An inContact REST api wrapper utilizing oAuth2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
