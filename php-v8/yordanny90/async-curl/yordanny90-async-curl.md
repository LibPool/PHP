# yordanny90/async-curl

> 标签: async, curl, http, request

## 简介

Realiza múltiples solicitudes asíncronas y simultaneas desde PHP usando cURL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
