# brouwers/laravel-doctrine

> 标签: data mapper, database, doctrine, laravel, orm

## 简介

A Doctrine ORM bridge for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
