# laarino/simplesamlphp-module-oid4vp

> 标签: OID4VP, blue, dc4eu, did, ebsi, eudi-wallet, openid4vp, saml, simplesamlphp, simplesamlphp-module, verifiable-credentials

## 简介

OID4VP (OpenID for Verifiable Presentations) authentication source for SimpleSAMLphp, with EBSI and BLUE trust network support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
