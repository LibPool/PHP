# sallycms/frontend

> 标签: SallyCMS, cms, frontend, mysql, php

## 简介

Frontend Application for SallyCMS, handling articles, assets and custom routes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
