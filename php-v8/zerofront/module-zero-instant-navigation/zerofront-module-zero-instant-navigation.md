# zerofront/module-zero-instant-navigation

> 标签: magento, magento-open-source, magento2, performance, prerender, speculation-rules, zero

## 简介

Zero for Magento Open Source: the next page loads while the shopper still points at its link (Speculation Rules API).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
