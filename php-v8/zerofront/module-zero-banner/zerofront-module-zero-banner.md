# zerofront/module-zero-banner

> 标签: banner, carousel, magento, magento-open-source, magento2, slider, zero

## 简介

Zero for Magento Open Source: banners and sliders managed in the admin, rendered without JavaScript (CSS scroll snap).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
