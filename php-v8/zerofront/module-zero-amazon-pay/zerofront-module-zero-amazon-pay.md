# zerofront/module-zero-amazon-pay

> 标签: amazon-pay, magento, magento-open-source, magento2, payment, zero

## 简介

Zero for Magento Open Source: Amazon Pay for Zero Checkout: the customer pays on Amazon's page after placing the order, no Amazon script on the shop's pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
