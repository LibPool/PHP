# zerofront/module-zero-size-chart

> 标签: magento, magento-open-source, magento2, size-chart, size-guide, zero

## 简介

Zero for Magento Open Source: size guides on product pages: tables made in the admin, shown by category or per product in a dialog.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
