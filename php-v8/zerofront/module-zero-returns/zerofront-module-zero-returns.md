# zerofront/module-zero-returns

> 标签: magento, magento-open-source, magento2, returns, rma, zero

## 简介

Zero for Magento Open Source: returns (RMA): the customer asks from My Account, the store approves, receives and refunds in Sales > Returns, with messages and emails.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
