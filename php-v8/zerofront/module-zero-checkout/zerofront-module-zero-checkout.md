# zerofront/module-zero-checkout

> 标签: checkout, htmx, magento, magento-open-source, magento2, one-page-checkout, zero

## 简介

Zero for Magento Open Source: a one-page checkout without Knockout: server-rendered HTML, one native form, HTMX for the parts that refresh.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
