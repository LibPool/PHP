# zerofront/module-zero-product-feed

> 标签: google-merchant, magento, magento-open-source, magento2, product-feed, xml-feed, zero

## 简介

Zero for Magento Open Source: the catalog as XML feeds for Google Merchant Center, Hotline, Rozetka and Prom.ua, one per store view.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
