# zerofront/module-zero-quote-request

> 标签: b2b, magento, magento-open-source, magento2, quote, request-a-quote, zero

## 简介

Zero for Magento Open Source: request a quote from the cart or a product, and "price on request" products.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
