# zerofront/module-zero-consent

> 标签: CCPA, cookie-consent, gdpr, magento, magento-open-source, magento2, zero

## 简介

Zero for Magento Open Source: a cookie consent banner and settings for every tracker (GDPR), Global Privacy Control and "Do Not Sell" (CCPA).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
