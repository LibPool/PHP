# zerofront/module-zero-promotions

> 标签: cart-price-rules, free-gift, magento, magento-open-source, magento2, promotions, zero

## 简介

Zero for Magento Open Source: more cart price rule actions: "every Nth item, the cheapest, X% off" and a free gift.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
