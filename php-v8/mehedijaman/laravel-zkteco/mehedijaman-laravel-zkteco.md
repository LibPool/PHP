# mehedijaman/laravel-zkteco

> 标签: Fingerprint, TimeAttendance, laravel, zkteco

## 简介

Connect any zkteco fingerprint attendance machine to laravel application with no effort.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
