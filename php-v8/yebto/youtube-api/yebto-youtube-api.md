# yebto/youtube-api

> 标签: api, laravel, sdk, yeb, youtube

## 简介

Laravel SDK for the Youtube API (yeb.to)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://yeb.to
- 源码仓库：https://github.com/yebto/youtube-api.git
- Packagist 页面：https://packagist.org/packages/yebto%2Fyoutube-api

## 历史版本号

- 当前版本：v1.0.0

## 获取地址

- Composer 安装：`composer require yebto/youtube-api`
- Packagist 仓库：https://repo.packagist.org/p2/yebto/youtube-api.json
