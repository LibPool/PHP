# lagan/property-manytoone

> 标签: controller, lagan, many-to-one, property, relation

## 简介

Controller for the Lagan mamy-to-one property. Lets the user define a may-to-one relation between two content objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
