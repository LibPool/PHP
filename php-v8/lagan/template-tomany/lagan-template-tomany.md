# lagan/template-tomany

> 标签: lagan, many-to-many, one-to-many, onetomany, property, template

## 简介

Template to edit Lagan one-to-many and many-to-many properties.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
