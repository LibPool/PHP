# technobase/laravel-system-status

> 标签: incidents, laravel, monitoring, status-page, uptime

## 简介

A status page for Laravel backoffices: read-only probes, real per-route traffic, signals, automatic incidents, Telegram alerts and 1h / 24h / 7d / 90d history.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
