# beechit/json-to-code-climate-subset-converter

> 标签: PHPStan, PHP_CodeSniffer, beech, beech.it, code-climate, code-climate-subset, gitlab, json-to-code-climate-subset-converter, phan, phplint, phpmd, psalm

## 简介

CLI tool that'll convert supported JSON files to a subset of the Code Climate JSON format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
