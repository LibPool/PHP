# boruta/php-parallel-ide-autocomplete

> 标签: PHP

## 简介

This package allows you to activate the auto-complete in the IDE for native functions from the extension: PHP Parallel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
