# jenswittmann/kirby-update-check

> 标签: cron, kirby, kirby-plugin, security, updates

## 简介

Nightly cron route that emails all admins about Kirby core and plugin updates, incl. GitHub release notes and getkirby.com security notices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
