# laminas/laminas-pimple-config

> 标签: PSR-11, container, laminas, mezzio, pimple

## 简介

PSR-11 Pimple container configurator for Laminas and Mezzio applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
