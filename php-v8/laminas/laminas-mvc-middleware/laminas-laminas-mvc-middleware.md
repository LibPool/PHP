# laminas/laminas-mvc-middleware

> 标签: components, laminas, middleware, mvc, psr-15, psr-7

## 简介

Dispatch middleware pipelines in place of controllers in laminas-mvc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
