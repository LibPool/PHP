# laminas/laminas-servicemanager-migration

> 标签: laminas, migration, servicemanager

## 简介

Migrate your code to laminas-servicemanager 4.x compatibility utilizing Rector rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
