# laminas/laminas-http

> 标签: HTTP, http, http client, laminas, 客户端

## 简介

Provides an easy interface for performing Hyper-Text Transfer Protocol (HTTP) requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
