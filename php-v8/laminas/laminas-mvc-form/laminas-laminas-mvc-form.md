# laminas/laminas-mvc-form

> 标签: form, laminas, mvc

## 简介

Metapackage with all requirements needed to use laminas-form with laminas-mvc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
