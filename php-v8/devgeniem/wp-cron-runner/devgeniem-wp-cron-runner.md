# devgeniem/wp-cron-runner

> 标签: cron, mu-plugin, wordpress, wp-cron

## 简介

This mu-plugin lets you run WP cron for a site / network site via a single endpoint.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
