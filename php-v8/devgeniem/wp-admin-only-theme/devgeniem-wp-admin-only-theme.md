# devgeniem/wp-admin-only-theme

> 标签: minimal, multisite, theme, wordpress

## 简介

Super minimalistic theme for sites which only need wp-admin dashboard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
