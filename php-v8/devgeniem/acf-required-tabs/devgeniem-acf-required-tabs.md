# devgeniem/acf-required-tabs

> 标签: acf, wordpress

## 简介

An Advanced Custom Fields plugin that adds an indicator for tabs that contain unfilled required fields.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
