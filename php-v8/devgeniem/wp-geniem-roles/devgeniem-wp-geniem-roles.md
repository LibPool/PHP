# devgeniem/wp-geniem-roles

> 标签: Geniem, must use, roles, wordpress, wp, wrapper class

## 简介

Wrapper class for WordPress role creation and manipulation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
