# vunamhung/gutenberg-ramp

> 标签: gutenberg, wordpress

## 简介

Gutenberg Ramp is a plugin that manages the state of Gutenberg in the post-edit context.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
