# alariva/laravel-cashflow

> 标签: alariva, laravel, laravel-cashflow

## 简介

A lightweight Laravel package to simulate cashflow using recurring concepts and time-based projections.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
