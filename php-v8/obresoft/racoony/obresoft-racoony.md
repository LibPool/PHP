# obresoft/racoony

> 标签: Laravel Security, SAST, code scanner, cwe, php, php security, sast tool, secure coding, security, static analysis, symfony security, vulnerability, wordpress security

## 简介

A security-first static analysis tool for PHP applications and frameworks. Identifies risky patterns and vulnerabilities based on CWE classifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
