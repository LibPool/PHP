# omarwebdev/plass

> 标签: Class methods, Function conversion, Improved code organization, Improved syntax, Intuitive API, PHP functions, Readable code, Test Suite, compatibility

## 简介

The ultimate solution for converting PHP's built-in functions into class methods!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
