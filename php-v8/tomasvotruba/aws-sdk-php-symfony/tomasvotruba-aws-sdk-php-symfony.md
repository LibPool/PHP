# tomasvotruba/aws-sdk-php-symfony

> 标签: Symfony2, amazon, aws, sdk, symfony, symfony3

## 简介

A Symfony bundle for v3 of the AWS SDK for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
