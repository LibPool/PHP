# k2labs/base-tenant

> 标签: cashier, flux, gdpr, laravel, livewire, multi-tenant, multitenancy, passkeys, permissions, rbac, saas, stripe, tenancy, webauthn

## 简介

Multi-tenant SaaS foundation for Laravel 13: account isolation that survives queued jobs, per-account permissions, enforced plan limits and fifteen capability modules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
