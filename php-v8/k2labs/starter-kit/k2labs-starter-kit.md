# k2labs/starter-kit

> 标签: cashier, flux, laravel, livewire, multi-tenant, multitenancy, permissions, rbac, saas, starter-kit, tenancy

## 简介

Laravel starter kit for multi-tenant SaaS: accounts, granular permissions, database-driven navigation and feature flags.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
