# teltek/pumukit-oauth2-bundle

> 标签: client, oauth2, symfony, teltek

## 简介

OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
