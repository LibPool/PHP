# analytical42/googleanalyticscookie

> 标签: PHP

## 简介

Makes Google Analytics use a server side HTTP cookie instead of the default javascript cookie set with document.cookie.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
