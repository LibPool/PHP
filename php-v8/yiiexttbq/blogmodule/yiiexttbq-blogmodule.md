# yiiexttbq/blogmodule

> 标签: blog, extension, funson86, yii2

## 简介

funson86/yii2-blog 的扩展, 依赖yiiexttbq/adminlte. 加入了新的controller的namespace, 方便yii2basic模版

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
