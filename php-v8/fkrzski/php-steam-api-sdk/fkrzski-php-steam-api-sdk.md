# fkrzski/php-steam-api-sdk

> 标签: php, saloon, sdk, steam, steam-api

## 简介

Framework-agnostic PHP SDK for the Steam Web API, built on Saloon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
