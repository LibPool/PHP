# fkrzski/dotenv

> 标签: dotenv, env, environment, variables

## 简介

Library that adds the ability to access variables from '.env', $_ENV, and $_SERVER using the getenv() function

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
