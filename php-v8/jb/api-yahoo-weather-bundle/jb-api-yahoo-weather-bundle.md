# jb/api-yahoo-weather-bundle

> 标签: weather, yahoo api

## 简介

A bundle for SYmfony2 which use jb/api-yahoo-weather to get weather informations from Yahoo Api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
