# mehrancodes/veyoze

> 标签: ci, cli, console, continuous-integration, laravel-forge, laravel-harbor, laravel-zero, php, preview, provision, pull-requests, staging

## 简介

A CLI tool to Quickly create On-Demand preview environment for your apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
