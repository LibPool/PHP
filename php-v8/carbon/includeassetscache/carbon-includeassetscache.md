# carbon/includeassetscache

> 标签: FUSION, Neos, carbon, flow, helper

## 简介

Extension for Carbon.InlcudeAssets: Flush cache on file update

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
