# carbon/tailwindcolors

> 标签: Neos, color, editor, flow, neoscms, tailwindcss

## 简介

A plugin for Neos CMS which provides an editor for tailwindcss colors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
