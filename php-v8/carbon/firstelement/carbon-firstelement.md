# carbon/firstelement

> 标签: FUSION, Neos, carbon, flow, helper

## 简介

Get a boolean value returned if a content element is the first element in a ContentCollection or not

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
