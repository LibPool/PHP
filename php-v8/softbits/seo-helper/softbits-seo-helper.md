# softbits/seo-helper

> 标签: laravel, meta tags, open graph, seo, softbits, structured data

## 简介

SEO Helper package for Laravel & Softbits Platform. Provides easy-to-use tools for managing SEO meta tags, Open Graph, and structured data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
