# swoole/etcd-client

> 标签: client, coroutine, etcd, gRPC, http, http2, php, swoole

## 简介

Grpc PHP Client base on Swoole Http2 Coroutine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
