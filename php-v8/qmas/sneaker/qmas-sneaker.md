# qmas/sneaker

> 标签: email, exceptions, laravel

## 简介

An easy way to send emails with stack trace whenever an exception occurs on the server for Laravel Applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
