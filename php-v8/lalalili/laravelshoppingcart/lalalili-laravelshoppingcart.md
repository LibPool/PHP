# lalalili/laravelshoppingcart

> 标签: cart, ecommerce, laravel, shopping cart

## 简介

Shopping cart package for Laravel 12/13 with PHP 8.3+ support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
