# premium-contao-themes/pct_theme_installer

> 标签: contao, premium-contao-themes, premiumcontaothemes, themes

## 简介

Installation manager for the Premium Contao Themes: Eclipse, Eclipse + CustomCatalog Bundle. https://www.premium-contao-themes.com/

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
