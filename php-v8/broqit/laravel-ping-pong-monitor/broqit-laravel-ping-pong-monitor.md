# broqit/laravel-ping-pong-monitor

> 标签: framework, laravel

## 简介

Internal service monitoring system for HTTP/TCP/DB checks with incidents and multi-channel notifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
