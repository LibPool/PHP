# broqit/fields-ai

> 标签: ai-content-generation, broqit, fields-ai, filament-plugin, filamentphp, laravel, laravel-ai, laravel-package

## 简介

fields-ai is a powerful FilamentPHP plugin that integrates Laravel AI-powered features directly into your Filament forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
