# lionser/wallet-address-validator

> 标签: base58, base58check, bech32, bitcoin, eip55, erc20, ethereum, keccak256, solana, trc20, tron, validator, wallet

## 简介

Lightweight PHP validator for BTC (legacy + segwit/taproot), TRC20 (Tron), Solana and ERC20/Ethereum wallet addresses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
