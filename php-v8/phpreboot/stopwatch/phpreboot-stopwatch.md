# phpreboot/stopwatch

> 标签: stopwatch, timer

## 简介

PHP utility library for Stopwatch. Useful for optimization and other purpose.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
