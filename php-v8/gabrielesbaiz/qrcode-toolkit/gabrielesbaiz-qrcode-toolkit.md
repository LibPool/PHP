# gabrielesbaiz/qrcode-toolkit

> 标签: Gabriele Sbaiz, barcode, laravel, qr, qrcode, qrcode-toolkit, svg

## 简介

A style-first QR code toolkit for Laravel: module and eye shapes, gradients, logo knock-out, labels and frames, rendered to SVG, PNG, PDF and EPS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
