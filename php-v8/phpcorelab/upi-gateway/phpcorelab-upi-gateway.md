# phpcorelab/upi-gateway

> 标签: PhonePe, gateway, india, payment, paytm, qr, razorpay, upi

## 简介

Provider-agnostic PHP library for UPI QR code generation and payment status polling

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
