# kba-team/phplint.sh

> 标签: bash, check, lint, php, script, shell, syntax

## 简介

Bash script to lint PHP files in the given directories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
