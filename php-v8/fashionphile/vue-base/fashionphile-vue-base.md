# fashionphile/vue-base

> 标签: artisan, laravel, php, scaffolding, vue

## 简介

Artisan command that builds vue base that can use Vuex and Vue Router

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/fashionphile/vue-base.git
- Packagist 页面：https://packagist.org/packages/fashionphile%2Fvue-base
