# pluswerk/grumphp-typoscript-task

> 标签: TYPO3 CMS, TypoScript

## 简介

Connects the TypoScript linter from Martin Helmich with grumphp and adds some sniffer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
