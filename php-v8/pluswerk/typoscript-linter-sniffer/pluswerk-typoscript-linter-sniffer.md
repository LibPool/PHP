# pluswerk/typoscript-linter-sniffer

> 标签: TYPO3 CMS, TypoScript

## 简介

Adds some sniffer to the typoscript linter of Marting Helmich.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
