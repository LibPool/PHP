# emydev/laravel_paytabs

> 标签: E-comerce, laravel, payments, paytabs

## 简介

Official laravel package to implement PayTabs integration with laravel apps

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
