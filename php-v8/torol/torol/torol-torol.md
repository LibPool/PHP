# torol/torol

> 标签: csv, data, etl, excel, extract, json, load, pipeline, transform, xml

## 简介

A simple and elegant ETL (Extract, Transform, Load) library for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
