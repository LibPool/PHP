# lightwerk/surfrunner

> 标签: TYPO3 Surf, command line interface, deployment

## 简介

SurfRunner executes Surf Deployments with JSON configurations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
