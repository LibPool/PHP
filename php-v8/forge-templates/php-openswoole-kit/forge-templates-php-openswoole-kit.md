# forge-templates/php-openswoole-kit

> 标签: PHP

## 简介

Production-ready PHP OpenSwoole boilerplate with clean architecture, request/response layer, and scalable structure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
