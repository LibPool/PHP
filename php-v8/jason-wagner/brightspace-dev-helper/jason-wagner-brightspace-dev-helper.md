# jason-wagner/brightspace-dev-helper

> 标签: PHP

## 简介

This package allows for easier usage of D2L's Data Hub and Valence tools for their Brightspace LMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
