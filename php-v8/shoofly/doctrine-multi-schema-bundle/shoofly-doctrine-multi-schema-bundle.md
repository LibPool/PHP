# shoofly/doctrine-multi-schema-bundle

> 标签: bundle, dbal, doctrine, mysql, symfony

## 简介

Enables multiple schemas for Doctrine + Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
