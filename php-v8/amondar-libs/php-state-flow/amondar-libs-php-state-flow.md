# amondar-libs/php-state-flow

> 标签: US state abbreviations, US state codes, US state flow, US state lookup, US state names, US state parser, US state regex, US state validation, php, states, us states, usa states

## 简介

A lightweight PHP package for working with U.S. state codes and names.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
