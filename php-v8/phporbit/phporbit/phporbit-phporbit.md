# phporbit/phporbit

> 标签: framework, frankenphp, php, php-fpm, security, worker-mode

## 简介

A safe PHP framework that runs identically on its own server, FrankenPHP, nginx+FPM and Apache.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
