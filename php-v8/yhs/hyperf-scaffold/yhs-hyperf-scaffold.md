# yhs/hyperf-scaffold

> 标签: Microservice, framework, hyperf, middleware, php, scaffold, swoole

## 简介

基于hyperf3.1版本框架的初始化项目脚手架

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
