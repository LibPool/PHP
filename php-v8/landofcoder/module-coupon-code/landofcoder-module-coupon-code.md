# landofcoder/module-coupon-code

> 标签: coupon code magento 2, coupon generation for magento 2, landofcoder, landofcoder coupon code, magento 2 coupon code

## 简介

With Magento 2 Coupon Code you can define rule to generate coupon automatic and send dynamic coupon code to customer email.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
