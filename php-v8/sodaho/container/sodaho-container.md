# sodaho/container

> 标签: Autowiring, PSR-11, container, dependency-injection, di, php

## 简介

Lightweight PSR-11 dependency injection container with autowiring and caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
