# sodaho/php-router

> 标签: PSR-11, api, json, middleware, php, psr-15, psr-7, rest, router

## 简介

Lightweight PHP Router for REST APIs and SPAs. Standardized JSON responses, middleware, caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
