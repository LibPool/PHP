# fosseva/laravel-web-mcp

> 标签: WebMCP, agents, ai, laravel

## 简介

Expose Laravel AI SDK tools in Blade through browser-native WebMCP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
