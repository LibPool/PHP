# hdaklue/actioncrumb

> 标签: breadcrumb, laravel, livewire, navigation, tailwind

## 简介

A fluent breadcrumb builder with dropdown actions for Laravel Livewire

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
