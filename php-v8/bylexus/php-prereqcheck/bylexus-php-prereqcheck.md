# bylexus/php-prereqcheck

> 标签: check, prerequisite, requirements, system

## 简介

Helper class to create Prerequisite Check scripts for your software packages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
