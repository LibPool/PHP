# dru1x/expo-server-sdk-php

> 标签: expo, expo-server-sdk-php, php, push

## 简介

Server-side library for working with the Expo push notification service using PHP 8.2+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
