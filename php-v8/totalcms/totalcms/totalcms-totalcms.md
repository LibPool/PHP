# totalcms/totalcms

> 标签: cms, content-management, flat-file, flat-file-cms, headless-cms, json, no-database, php-cms, slim, total-cms, totalcms, twig

## 简介

Create a new Total CMS site — a modern flat-file CMS for PHP with no database, Twig templating, a REST API, and a Site Builder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
