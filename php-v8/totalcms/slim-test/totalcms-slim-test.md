# totalcms/slim-test

> 标签: framework, php, phpunit, plugin, slim, test, testing, unit

## 简介

Slim Framework test helper built on top of the PHPUnit test framework (maintained fork of nekofar/slim-test)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
