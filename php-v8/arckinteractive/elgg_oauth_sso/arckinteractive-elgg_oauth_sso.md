# arckinteractive/elgg_oauth_sso

> 标签: PHP

## 简介

Allows other sites/services to implement SSO using the Elgg as the source of truth for user info

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
