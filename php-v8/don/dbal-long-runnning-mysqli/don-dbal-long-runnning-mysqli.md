# don/dbal-long-runnning-mysqli

> 标签: database, dbal, doctrine, driver

## 简介

Doctrine DBAL driver for MySQLi used in long-running processes/scripts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
