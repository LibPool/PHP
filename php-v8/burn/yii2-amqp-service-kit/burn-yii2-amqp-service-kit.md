# burn/yii2-amqp-service-kit

> 标签: AMQP, extension, kit, microservices, service, soa, yii2

## 简介

Helpers kit for AMQP base daemon services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
