# drupol/htmltag

> 标签: attributes, html, html generation, tags

## 简介

A fast and extensible helper library for generating HTML, create tags, their attributes and content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
