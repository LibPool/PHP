# drupol/drupal7_psr3_watchdog

> 标签: drupal, log, logging, psr-3, watchdog

## 简介

A PSR3 logger using Drupal 7 watchdog.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
