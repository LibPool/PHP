# olaferlandsen/ffmpeg-php-class

> 标签: ffmpeg, video

## 简介

FFmpeg class to use with PHP without install FFmpeg-PHP extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
