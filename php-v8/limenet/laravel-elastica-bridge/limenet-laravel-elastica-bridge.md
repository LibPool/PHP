# limenet/laravel-elastica-bridge

> 标签: laravel, laravel-elastica-bridge, limenet

## 简介

A simple bridge between Laravel and Elasticsearch using Elastica

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
