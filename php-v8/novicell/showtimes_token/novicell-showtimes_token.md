# novicell/showtimes_token

> 标签: kino, token

## 简介

Used to deliver tokens for the ticket-flow of kino.dk.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://kino.dk
- 源码仓库：https://github.com/novicell-drupal/showtimes_token.git
