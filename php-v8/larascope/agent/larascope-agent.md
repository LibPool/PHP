# larascope/agent

> 标签: health, larascope, laravel, logs, monitoring, observability, pulse, security

## 简介

Secured, read-only monitoring agent for Laravel apps — health, Pulse, logs, stats, security and per-IP connection metrics, consumed by the Larascope mobile app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
