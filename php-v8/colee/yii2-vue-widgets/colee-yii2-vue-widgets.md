# colee/yii2-vue-widgets

> 标签: colee, vue, vuejs, widget, yii2, yii2-vue-widgets

## 简介

Vue.js library for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
