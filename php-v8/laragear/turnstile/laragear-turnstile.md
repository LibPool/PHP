# laragear/turnstile

> 标签: captcha, cloudflare, http2, http3, laragear, turnstile

## 简介

Use Cloudflare's no-CAPTCHA with HTTP/3 in your Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
