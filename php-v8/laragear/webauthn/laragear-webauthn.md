# laragear/webauthn

> 标签: Authentication, faceid, laravel, passkeys, touchid, webauthn, windows hello

## 简介

Authenticate users with Passkeys: fingerprints, patterns and biometric data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
