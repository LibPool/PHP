# brainbits/phpcs-gitlab-report

> 标签: code quality, gitlab, php-codesniffer, phpcs, phpcs-report

## 简介

Output your PHP CodeSniffer report as a GitLab Code Quality report

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
