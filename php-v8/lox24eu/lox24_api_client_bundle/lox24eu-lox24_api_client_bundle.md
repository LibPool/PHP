# lox24eu/lox24_api_client_bundle

> 标签: api, bundle, lox24, sms, symfony

## 简介

A simple Symfony bundle for the official sdk provided by LOX24.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
