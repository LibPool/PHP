# njbm/role-permission

> 标签: access-control, jabermasud, njbm, permission, role

## 简介

A simple, robust role-permission package for Laravel (one role per user).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
