# cnizzardini/cakephp-sakila-plugin

> 标签: cakephp, cakephp dummy data, cakephp sakila, cakephp seed

## 简介

A data seeder based on the MySQL Sakila database for CakePHP 4.x

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
