# cnizzardini/cakephp-yummy

> 标签: cakephp3, cakephp3 acl, cakephp3 bake, cakephp3 search

## 简介

Yummy plugin for CakePHP including an intuitive search, ACL, and bake theme

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
