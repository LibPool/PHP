# retjet/returns-api-php-client

> 标签: API-Client, ecommerce, php, psr-18, retjet, return management, returns, returns management, rma, warranty, warranty claims

## 简介

PHP client for the RetJet API - returns and warranty claims for online shops.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
