# oberonus/transformer

> 标签: api, declarative, functional, php, psr7, response, serializer, transformer

## 简介

Simple library for API transformation in declarative way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
