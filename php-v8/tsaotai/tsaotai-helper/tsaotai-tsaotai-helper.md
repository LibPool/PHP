# tsaotai/tsaotai-helper

> 标签: functions, helper, http, response, thinkphp

## 简介

TsaoTai Helper Functions - 提供 pull HTTP请求 和 push 统一响应等工具函数

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
