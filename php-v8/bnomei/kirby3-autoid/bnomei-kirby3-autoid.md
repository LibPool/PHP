# bnomei/kirby3-autoid

> 标签: Structures, autoid, cache, files, incremental, kirby3, kirby3-cms, kirby3-plugin, lookup, nested, pages, performance, random, sqlite, sqlite-database, tiny-url, token, uuid

## 简介

Automatic unique ID for Pages, Files and nested Structures including performant helpers to retrieve them. Bonus: Tiny-URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
