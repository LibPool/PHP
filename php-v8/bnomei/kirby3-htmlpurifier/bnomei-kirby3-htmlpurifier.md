# bnomei/kirby3-htmlpurifier

> 标签: clean, filter, form, headless, html, htmlawed, input, kirby3, kirby3-cms, kirby3-plugin, kql, kses, safe, sanitize, security, striptags, submit, uniform, xss

## 简介

Static class method, Uniform-Guard and Field-Method to filter your "dirty" HTML inputs to "clean" HTML.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
