# bnomei/kirby3-robots-txt

> 标签: kirby, kirby-cms, kirby-plugin, robots-exclusion-protocol, robots-txt

## 简介

Manage a virtual robots.txt from the Kirby config file

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
