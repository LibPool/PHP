# hashworks/phergie-plugin-wolfram-alpha

> 标签: alpha, bot, irc, phergie, plugin, wolfram

## 简介

Phergie plugin to access the Wolfram Alpha API trough IRC.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
