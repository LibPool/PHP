# aurorawebsoftware/asetting

> 标签: AuroraWebSoftware, asetting, laravel

## 简介

ASetting is a Laravel package that allows you to dynamically define your config definitions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
