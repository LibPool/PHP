# ec-europa/phpgit

> 标签: git, helper, php

## 简介

Php library for interacting with git binary

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/ec-europa/phpgit
- 源码仓库：https://github.com/ec-europa/phpgit.git
- Packagist 页面：https://packagist.org/packages/ec-europa%2Fphpgit

## 获取地址

- Composer 安装：`composer require ec-europa/phpgit`
- Packagist 仓库：https://repo.packagist.org/p2/ec-europa/phpgit.json
- 许可证：EUPL
- PHP 要求：>=5.3.0
