# otas/microservice

> 标签: PHP

## 简介

a laravel package to deal with specific case of micro-services connection. So, it doesn't suit all needs or handle all connection cases

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
