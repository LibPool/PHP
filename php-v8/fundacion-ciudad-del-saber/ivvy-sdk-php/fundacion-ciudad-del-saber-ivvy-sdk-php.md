# fundacion-ciudad-del-saber/ivvy-sdk-php

> 标签: PHP

## 简介

A PHP 7.1 compatible, PSR-4 and PSR-2 compliant SDK to work with iVvy's API 1.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
