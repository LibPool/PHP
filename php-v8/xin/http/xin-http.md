# xin/http

> 标签: PHP

## 简介

一个基于 PSR-7/PSR-18 标准的轻量级、高性能 HTTP 客户端，支持 Guzzle、Amp 和 Workerman 等多种驱动。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
