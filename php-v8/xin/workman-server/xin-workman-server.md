# xin/workman-server

> 标签: PHP

## 简介

基于 Workman 实现的服务器是一种高性能的 PHP 服务器解决方案，能够无缝接入 ThinkPHP、Laravel 等主流框架。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
