# xin/logger

> 标签: PHP

## 简介

Logger 是基于PSR-3规范做的辅助工具类库，同时支持结合Monolog开源类库，推荐在Hyperf和Webman以及主流CLI模式应用下使用。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
