# xin/excel

> 标签: PHP

## 简介

基于OpenSpout封装的轻量级高性能表格处理类库，仅占用3M内存，即可轻松实现上百万行数据的高效导入与导出。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
