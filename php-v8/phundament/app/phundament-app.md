# phundament/app

> 标签: 12factor, app, application, boilerplate, docker, docker-compose, dotenv, framework, phundament, template, yii2

## 简介

12factor Application Template for Yii 2.0 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
