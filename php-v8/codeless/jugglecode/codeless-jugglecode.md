# codeless/jugglecode

> 标签: deploy, join, manipulate, one-file, prettyprint

## 简介

A tool to manipulate PHP statements in scriptfiles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
