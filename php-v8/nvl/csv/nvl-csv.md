# nvl/csv

> 标签: csv, export, import, laravel, queue, validation

## 简介

Typed, memory-conscious CSV analysis, validation, transformation, import, export, and queued processing for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
