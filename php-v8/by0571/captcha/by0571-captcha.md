# by0571/captcha

> 标签: PHP

## 简介

奔跃软件验证码插件，基于ThinkPHP5、topthink/think-captcha端Cache版，解决API调用跨域问题。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
