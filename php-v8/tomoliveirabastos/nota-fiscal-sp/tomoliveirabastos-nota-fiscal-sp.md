# tomoliveirabastos/nota-fiscal-sp

> 标签: Emissão Nota Fiscal, Nota Fiscal Tomador de Serviços, Nota do Milhão, Prefeitura São Paulo, nfs, nfts, nota fiscal

## 简介

Integração com o WebService da Prefeitura de São Paulo para emissão de NFS e NTFS utilizando a API da nota do milhão

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
