# dkemens/yii2-aws-s3-manager

> 标签: aws, file manager, image manager, s3, widget, yii2

## 简介

A yii2 extension for managing files in AWS S3 buckets

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
