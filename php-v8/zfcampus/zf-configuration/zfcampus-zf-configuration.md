# zfcampus/zf-configuration

> 标签: ZendFramework, config, module, rest, zf

## 简介

Zend Framework module providing a REST resource for manipulating configuration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
