# zfcampus/zf-http-cache

> 标签: ZendFramework, api, apigility, cache, module, zend, zf

## 简介

ZF2 Module providing http cache headers support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
