# zfcampus/zf-hal

> 标签: hal, module, psr-13, rest, zend, zf2

## 简介

ZF2 Module providing Hypermedia Application Language assets and rendering

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
