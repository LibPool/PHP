# jasonmccreary/pspec

> 标签: BDD, TDD, framework, test

## 简介

PSpec is a modern, BDD-style testing framework for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
