# groundmail/symfony-mailer

> 标签: email, groundmail, mailer, symfony, symfony-mailer, transactional

## 简介

Symfony Mailer transport for the Groundmail transactional email API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
