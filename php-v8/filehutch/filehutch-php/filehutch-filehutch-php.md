# filehutch/filehutch-php

> 标签: file-upload, filehutch, laravel, r2, s3, storage

## 简介

PHP and Laravel client for FileHutch. Your app persists an opaque file id; FileHutch owns uploads, delivery and transforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
