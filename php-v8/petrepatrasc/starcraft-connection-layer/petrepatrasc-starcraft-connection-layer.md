# petrepatrasc/starcraft-connection-layer

> 标签: Starcraft 2, api, php, symfony

## 简介

A PHP 5.3+ cURL wrapper that allows easy access to popular Starcraft 2 service APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
