# elbojoloco/runescape-hiscores

> 标签: highscores, hiscores, osrs, rs3, runescape

## 简介

An easy-to-use wrapper for communicating with both the OSRS and RS3 hiscores.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
