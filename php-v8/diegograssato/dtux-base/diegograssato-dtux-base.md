# diegograssato/dtux-base

> 标签: PHP

## 简介

Modulo base para se trabalhar com Zend Framework 2, ele já está apto a trabalhar com Doctrine ORM e Doctrine ODM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
