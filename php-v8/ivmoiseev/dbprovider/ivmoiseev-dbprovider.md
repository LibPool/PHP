# ivmoiseev/dbprovider

> 标签: mysql, mysqli, pdo, php

## 简介

Simple data provider for MySQL Database. Uses MySQLi or PDO.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
