# dream-technologies/telebirr-laravel-plus

> 标签: Ethiopia, Telebirr, ethiotelecom, flutter, inapp, laravel, payment

## 简介

Production-ready Laravel backend package for Telebirr InApp Purchase, aligned with telebirr_inapp_purchase_plus Flutter SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
