# liuyx02/project_test

> 标签: message, yii2

## 简介

消息发送组件，提供多渠道（邮件、企业微信、短信）集中发送和批量消息发送功能。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
