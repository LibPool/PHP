# ionux/rapim

> 标签: Algorithm, addition, arbitrary, coprime, division, fft, integer, karatsuba, math, mathematics, modulo, multiplication, number, precision, prime, rapim, subtraction

## 简介

This project is a native Rich Arbitrary Precision Integer Mathematics Library implementation for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
