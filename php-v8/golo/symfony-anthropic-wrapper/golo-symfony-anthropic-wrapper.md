# golo/symfony-anthropic-wrapper

> 标签: anthropic, bundle, claude, profiler, sdk, symfony

## 简介

Symfony bundle for the official Anthropic PHP SDK: YAML-configured defaults, per-model options and presets, plus a profiler panel for every Claude call.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
