# crevillo/ezplatform-tinymce-html-fieldtype

> 标签: PHP

## 简介

Provides an integration of TinyMCE with eZ Platform to be able to have html codes all the way

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
