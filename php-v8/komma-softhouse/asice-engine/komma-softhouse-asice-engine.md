# komma-softhouse/asice-engine

> 标签: asice, digidoc, eID, estonia, id-kaart, komma-softhouse, mobile-id, signature, smart-id, xades

## 简介

ASiC-E containers with XAdES signatures for Estonian eID: ID-kaart, Smart-ID and Mobile-ID. Hash in, container out | Komma SoftHouse

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
