# arutil/ar-php

> 标签: arabic, hijri, islamic

## 简介

Arabic php utilities from Khaled Al-Sham'aa's library http://ar-php.org/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
