# ashus/phpqrcode

> 标签: barcode, maiscrm, php, qrcode

## 简介

PHP QRCode Generator Library, compatible with PHP 8.0 - 8.5

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
