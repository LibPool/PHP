# brdv/forerunner

> 标签: PHP

## 简介

A Laravel package that provides an elegant, migration-inspired API for defining JSON schemas that ensure your LLM responses are perfectly structured every time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
