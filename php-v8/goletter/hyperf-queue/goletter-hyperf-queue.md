# goletter/hyperf-queue

> 标签: async-queue, delay, hyperf, millisecond, php

## 简介

Millisecond-precision async queue driver for Hyperf, compatible with hyperf/async-queue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
