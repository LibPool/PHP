# goletter/hyperf-card

> 标签: airwallex, card, hyperf, hyperf-card, lampay, photonpay, php, slash, wasabi, youcardx

## 简介

Hyperf 多平台发卡 SDK（Airwallex / Slash / Lampay / Photonpay / Wasabi / Youcardx），含 Factory、Bundle 与可选统一适配层

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
