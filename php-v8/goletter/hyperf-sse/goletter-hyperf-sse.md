# goletter/hyperf-sse

> 标签: event-stream, hyperf, php, redis, server-sent-events, sse

## 简介

Server-Sent Events (SSE) component for Hyperf with Redis Stream, connection tickets, and optional presence.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
