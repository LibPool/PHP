# goletter/hyperf-archive

> 标签: archive, download, hyperf, pack, php, zip

## 简介

Multi-file archive (ZIP) builder for Hyperf with sync download and storage upload support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
