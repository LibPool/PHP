# webfan3/frdl-module-remote-psr4

> 标签: PHP

## 简介

An php psr4 Autoloader which is autoloading from a remote server [frdl-module#edition].

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
