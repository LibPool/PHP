# sourcentis/chartjs-gauge

> 标签: Chart.js, chart, gauge, javascript, laravel

## 简介

A Chart.js plugin providing a gauge chart type with needle and value label

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
