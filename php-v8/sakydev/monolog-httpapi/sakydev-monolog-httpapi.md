# sakydev/monolog-httpapi

> 标签: bots, channels, http, log, logging, monolog, monolog-httpapi

## 简介

A handler for Monolog that sends messages to external API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
