# ozanhazer/php-htpasswd

> 标签: htpasswd, php

## 简介

A lightweight - single class - library to read and write htpasswd. You can add or delete users or you can update their passwords...

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
