# ngames/framework

> 标签: PHP

## 简介

The NGames Framework is a simple PHP framework developped for the websites https://www.worldwar.fr and https://www.guide-tnt.fr

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
