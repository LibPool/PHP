# raksul/doctrine-set-type-bundle

> 标签: bundle, dbal, doctrine, mysql, set, symfony, type

## 简介

Provides support of MySQL SET type for Doctrine2 in Symfony2 applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
