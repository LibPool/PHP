# osaris-uk/cart

> 标签: cart, database, ecommerce, laravel, laravel6, shopping-cart

## 简介

Shopping Cart library for Laravel 6 that uses Database instead of Sessions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
