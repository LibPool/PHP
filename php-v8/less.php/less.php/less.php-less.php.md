# less.php/less.php

> 标签: css, less, less.js, lesscss, php, stylesheet

## 简介

PHP port of the Javascript version of LESS http://lesscss.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
