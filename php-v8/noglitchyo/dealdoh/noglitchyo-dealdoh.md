# noglitchyo/dealdoh

> 标签: dns, dns-client, dns-over-https, dns-proxy, dns-resolver, doh

## 简介

A simple DNS over HTTPS proxy built on PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
