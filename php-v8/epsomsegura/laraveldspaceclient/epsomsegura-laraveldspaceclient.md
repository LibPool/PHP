# epsomsegura/laraveldspaceclient

> 标签: PHP

## 简介

This is a laravel Dspace7 client to manage dublin core metadata between platforms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
