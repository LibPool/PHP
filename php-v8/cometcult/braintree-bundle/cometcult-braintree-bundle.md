# cometcult/braintree-bundle

> 标签: braintree, bundle, card, credit, payment

## 简介

Symfony 2 Bundle for Braintree's PHP client library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
