# rikochey/rikochey-php

> 标签: Forms, api, leads, rikochey, sdk

## 简介

Official PHP client for the Rikochey API: websites, forms, server-side submissions, JavaScript actions and API tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
