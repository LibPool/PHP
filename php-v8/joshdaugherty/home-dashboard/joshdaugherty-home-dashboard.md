# joshdaugherty/home-dashboard

> 标签: calendar, dashboard, flux, ical, kiosk, laravel, livewire, weather

## 简介

A responsive, touch-first family dashboard kiosk (Livewire + Flux) for a wall-mounted photo frame.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
