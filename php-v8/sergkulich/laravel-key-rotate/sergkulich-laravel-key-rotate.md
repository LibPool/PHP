# sergkulich/laravel-key-rotate

> 标签: command, key, laravel, re-encrypt, rotate

## 简介

A Laravel package to rotate app key and re-encrypt data stored in eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
