# ongudidan/laravel-multi-2fa

> 标签: PHP

## 简介

Unified Multi-Method Two-Factor Authentication for Laravel: Email OTP, Authenticator App (TOTP via Fortify), and Passkeys (WebAuthn).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
