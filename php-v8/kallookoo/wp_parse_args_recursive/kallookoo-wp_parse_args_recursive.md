# kallookoo/wp_parse_args_recursive

> 标签: PHP

## 简介

Like wp_parse_args but supports recursivity. By default converts the returned type based on the $args and $defaults

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
