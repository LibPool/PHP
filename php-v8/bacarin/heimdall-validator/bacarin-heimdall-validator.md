# bacarin/heimdall-validator

> 标签: PHP

## 简介

A pure PHP validation package inspired in Laravel way to validate data. Made in raw PHP without any dependency.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
