# oprokidnev/bitcoind-php

> 标签: bitcoin, bitcoind, bitcoins

## 简介

PHP Wrapper for a bitcoind daemon

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
