# grayscale/laravel-ads-sdk

> 标签: ads, api, bing-ads, facebook-ads, google-ads

## 简介

A Laravel Ads SDK for Google Ads, Bing Ads and Facebook Ads API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
