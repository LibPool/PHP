# wiserwebsolutions/laravel-pde-client

> 标签: afr, gfb, laravel, pde, pennsylvania, school-finance

## 简介

Fluent Laravel client for discovering, downloading, and querying Pennsylvania Department of Education (PDE) data files (starting with school financial data - GFB budgets, AFR actuals).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
