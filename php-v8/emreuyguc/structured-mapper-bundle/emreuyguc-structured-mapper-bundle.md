# emreuyguc/structured-mapper-bundle

> 标签: bundle, data-mapper, data-transformer, dto, dto-mapper, emreuyguc, entity-mapper, mapper, mapping, object-mapper, object-to-object, php, php-mapper, structured-mapper, symfony, transformation

## 简介

A Symfony bundle for the emreuyguc/structured-mapper package that provides powerful object-to-object data transformation using structured mapping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
