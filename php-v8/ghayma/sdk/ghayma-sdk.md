# ghayma/sdk

> 标签: auth, database, ghayma, paas, sdk, storage

## 简介

PHP client for the Ghayma platform: admin (project key) and stateless end-user auth (app slug + server key).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
