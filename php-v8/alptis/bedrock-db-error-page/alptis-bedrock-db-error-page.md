# alptis/bedrock-db-error-page

> 标签: bedrock, composer-plugin, database, db-error.php, error-page, wordpress

## 简介

Composer plugin that customizes the database connection error page of WordPress Bedrock projects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
