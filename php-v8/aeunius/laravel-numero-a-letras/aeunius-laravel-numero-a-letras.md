# aeunius/laravel-numero-a-letras

> 标签: Número a Letras, facturación electrónica, laravel, monto en letras, peru, sunat

## 简介

Convierte montos a letras con el formato de los comprobantes peruanos de la SUNAT: "MIL DOSCIENTOS CINCUENTA CON 50/100 SOLES". Núcleo en PHP puro, con integración opcional para Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
