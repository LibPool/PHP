# aeunius/laravel-peru-rules

> 标签: DNI, cci, laravel, peru, ruc, sunat, validation

## 简介

Reglas de validación y casts de Laravel para documentos y datos peruanos: RUC, DNI, carné de extranjería, pasaporte, celular, placa vehicular y CCI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
