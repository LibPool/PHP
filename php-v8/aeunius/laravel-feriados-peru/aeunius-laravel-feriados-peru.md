# aeunius/laravel-feriados-peru

> 标签: business-days, dias-habiles, feriados, holidays, laravel, peru, plazos

## 简介

Feriados nacionales del Perú y cálculo de días hábiles para plazos administrativos en Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
