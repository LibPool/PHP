# liufencn/flarum-short-slug

> 标签: flarum, flarum-extension, permalink, short-url, slug, url

## 简介

Shorten discussion URLs in Flarum 2.x: /d/{id} instead of /d/{id}-pinyin-slug. Comes with an admin toggle, optional custom slugs and CLI tools to clean up existing discussions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
