# liufencn/flarum-reply-pin

> 标签: PHP

## 简介

帖子内楼层（回复）置顶：把讨论内任意一条回复钉到讨论顶部，并加图钉徽标。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
