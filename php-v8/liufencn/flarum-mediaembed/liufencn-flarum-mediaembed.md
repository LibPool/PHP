# liufencn/flarum-mediaembed

> 标签: PHP

## 简介

中文媒体站点嵌入：给 Flarum 的 s9e MediaEmbed 补上国内常用视频 / 音乐站点（B站、AcFun、腾讯视频、网易云音乐、西瓜视频），链接自动转为内嵌播放器

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
