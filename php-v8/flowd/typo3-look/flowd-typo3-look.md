# flowd/typo3-look

> 标签: Content Blocks, backend, page module, preview, typo3

## 简介

"Look" what you'll see on your website: content elements in the TYPO3 page module rendered with the real frontend templates, inside an isolated preview frame

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
