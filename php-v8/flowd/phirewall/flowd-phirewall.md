# flowd/phirewall

> 标签: PHP

## 简介

A PHP Firewall and rate limiter based on PSR-7 and PSR-15 middleware (safelists, blocklists, throttles, fail2ban)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
