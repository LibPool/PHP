# flowd/typo3-firewall

> 标签: PHP

## 简介

Firewall for TYPO3 - Firewall implements a PSR-15 middleware that helps to protect your website against malicious requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
