# marcel-mathias-nolte/contao-push-bundle-news4ward-adapter

> 标签: PHP

## 简介

Adapter to provide 'Push Bundle' functionality for the 'News4ward' bundle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
