# pashkevich/loyverse-sdk

> 标签: loyverse, loyverse-api, loyverse-php, loyverse-sdk

## 简介

A simple to use PHP SDK for the Loyverse API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
