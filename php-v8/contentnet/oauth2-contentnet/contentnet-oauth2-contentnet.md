# contentnet/oauth2-contentnet

> 标签: authorization, client, contentnet, oauth, oauth2

## 简介

PHP OAuth2 client for ContentNet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
