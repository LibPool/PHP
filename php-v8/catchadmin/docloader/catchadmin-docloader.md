# catchadmin/docloader

> 标签: chunking, document, embedding, html, loader, parser, pdf, rag, text-splitter

## 简介

A PHP document loader and splitter for RAG applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
