# avtehnik/service-doc

> 标签: api, json, rest, service discovery

## 简介

service-doc - Generate interactive documentation for your RESTful API using phpdoc annotations

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
