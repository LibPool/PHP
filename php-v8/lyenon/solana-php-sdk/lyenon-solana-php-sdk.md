# lyenon/solana-php-sdk

> 标签: attestto, blockchain, php, sdk, sol, solana, solana-php-sdk

## 简介

Solana PHP SDK for interacting with the Solana blockchain

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
