# haroone/module-link-guest-order-to-customer

> 标签: admin, customer-account, ecommerce, guest-order, magento-extension, magento2, magento2-extension, order-management

## 简介

Safely link an eligible Magento guest order to the matching registered customer account from Admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
