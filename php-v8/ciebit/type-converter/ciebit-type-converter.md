# ciebit/type-converter

> 标签: conversão, tipos

## 简介

Módulo para garantia de conversão de tipos sem alerta de erros mesmo quando não é possível faze-lo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
