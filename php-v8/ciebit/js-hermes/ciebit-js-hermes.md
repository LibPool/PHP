# ciebit/js-hermes

> 标签: JS, avisos, ciebit, mensagens

## 简介

Módulo para gerenciamento de comunicação entre objetos

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
