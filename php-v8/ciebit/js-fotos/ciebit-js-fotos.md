# ciebit/js-fotos

> 标签: JS, ciebit, fotos, álbuns

## 简介

Módulo de gerenciamento de álbuns de fotos

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
