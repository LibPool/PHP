# ciebit/cb-instalador-composer

> 标签: PHP

## 简介

Plugin do Composer para instalação de pacotes do sistema CB desenvolvido pela Ciebit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
