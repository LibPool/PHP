# bvrignaud/ci4-admin

> 标签: AdminLTE 3, CodeIgniter 4

## 简介

Admin module for CodeIgniter 4 based on IonAuth and AdminLTE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
