# multiplayer-gratis/api-client

> 标签: api, client, gameserver, hosting, multiplayer.gratis

## 简介

PHP-Client für die REST-API von multiplayer.gratis – kostenloses Gameserver-Hosting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
