# marcin_jozwikowski/settings_in_db_bundle

> 标签: settings symfony2

## 简介

A Symfony2 bundle that allows an easy key-value storage in DB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
