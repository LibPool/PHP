# mosaicora/plugin-core-php

> 标签: JSON-LD, mosaicora, og-image, open-graph, php, seo

## 简介

Framework-agnostic Mosaicora Open Graph image URL and JSON-LD helpers for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
