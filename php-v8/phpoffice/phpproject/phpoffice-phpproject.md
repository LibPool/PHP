# phpoffice/phpproject

> 标签: GanttProject, gan, mpx, php, project

## 简介

PHPProject - Read, Create and Write Project Management documents in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
