# e164-com/e164-php-sdk

> 标签: Api Wrapper, E164, e164 SDK, phone number validation, phone number validation SDK

## 简介

A PHP SDK for interacting with the e164.com API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
