# aschmelyun/cleaver

> 标签: blade, generator, json, laravel, markdown, site, static

## 简介

A blazing-fast static site generator using Laravel's Blade templating engine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
