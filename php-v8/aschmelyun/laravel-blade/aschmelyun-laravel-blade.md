# aschmelyun/laravel-blade

> 标签: blade, laravel

## 简介

A standalone component for using the Laravel Blade templating engine. Forked from Philo/Laravel-Blade.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
