# briefingsource/laravel-timezone

> 标签: laravel, timezone

## 简介

Timezone storage and retrieval for Laravel. Forked from jamesmills/laravel-timezone and updated for Laravel 11 and 12.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
