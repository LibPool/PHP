# db2file/db2file

> 标签: csv, database, docx, export, mysql, pdf, pdo, php, xlsx

## 简介

A framework-independent PHP library for exporting MySQL database records to CSV, XLSX, DOCX and PDF.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
