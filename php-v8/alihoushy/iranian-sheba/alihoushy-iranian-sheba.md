# alihoushy/iranian-sheba

> 标签: Bank, IBAN, farsi, iran, persian, php, sheba, validation

## 简介

Validate and normalize Iranian SHEBA / IBAN numbers with mod-97 and detect the owning bank.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
