# alihoushy/iranian-national-id

> 标签: codemelli, farsi, iran, national-id, persian, php, validation

## 简介

Validate Iranian national ID (کد ملی) with the official mod-11 checksum and resolve the issuing province and city.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
