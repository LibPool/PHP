# muench-dev/statamic-ai-writer

> 标签: ai, ai-writer, bard, classification, editor, openai, statamic, statamic-addon, summarize, translate

## 简介

AI-powered writing assistant for Statamic: refine, resize, translate, summarize, classify content, and generate post titles directly within the text editor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
