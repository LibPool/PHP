# sunnysideup/model-admin-many-tabs

> 标签: Silverstripe-CMS, cms, google, model admin, modeladmin, silverstripe, tabs

## 简介

Allow many tabs to be added for one model (e.g. break down users by the first letter of their last name)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
