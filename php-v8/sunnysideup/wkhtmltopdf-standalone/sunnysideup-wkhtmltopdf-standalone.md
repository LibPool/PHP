# sunnysideup/wkhtmltopdf-standalone

> 标签: install, pdf maker, shared hosting, wkpdftohtml

## 简介

Brings together a bunch of binaries for a shared server where you do not have the ability to install it

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
