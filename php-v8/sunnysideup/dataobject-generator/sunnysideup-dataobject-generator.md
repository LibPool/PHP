# sunnysideup/dataobject-generator

> 标签: Silverstripe-CMS, cms, dataobject, dev tools, developer tool, generator, silverstripe, tool

## 简介

Developer Tool: generate DataObjects using a simple form. Helps you create a fully ornamented DataObject.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
