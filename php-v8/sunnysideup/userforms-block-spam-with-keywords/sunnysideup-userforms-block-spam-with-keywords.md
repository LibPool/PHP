# sunnysideup/userforms-block-spam-with-keywords

> 标签: eric the spammer, keywords, spam, user defined forms, userforms, validation

## 简介

Checks for keywords (e.g. eric@spam.com.nz) and block submissions of the strings are present

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
