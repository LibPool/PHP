# sunnysideup/elemental-switch-tabs

> 标签: Silverstripe-CMS, cms, cms fields, elemental, field, fields, link, silverstripe, switch tabs, tabs

## 简介

Helps CMS Users navigate through tabs in Elemental CMS Interface by providing clickable links to switch tabs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
