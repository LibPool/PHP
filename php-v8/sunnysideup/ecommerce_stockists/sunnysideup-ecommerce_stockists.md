# sunnysideup/ecommerce_stockists

> 标签: Silverstripe-CMS, agents, cms, e-commerce, ecommerce, retailers, shop, silverstripe, stockists

## 简介

Add stockists (retailers list) to your Silverstripe E-commerce application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
