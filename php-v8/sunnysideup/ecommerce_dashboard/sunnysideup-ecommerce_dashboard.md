# sunnysideup/ecommerce_dashboard

> 标签: Silverstripe-CMS, cms, dashboard, e-commerce, e-commerce dashboard, management summary, sales, silverstripe, statistics

## 简介

Adds a dash board to the silverstripe e-commerce application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
