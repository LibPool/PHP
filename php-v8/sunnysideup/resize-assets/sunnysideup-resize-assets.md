# sunnysideup/resize-assets

> 标签: assets, height, images, media, resize, width

## 简介

Resizes all images in a folder, recursively, to a max width and height.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
