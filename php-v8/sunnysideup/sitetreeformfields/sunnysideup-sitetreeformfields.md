# sunnysideup/sitetreeformfields

> 标签: Silverstripe-CMS, checkboxsetfield, cms, fields, form, form fields, formfields, gridfield, select page, silverstripe, sitetree

## 简介

Provides form fields for selecting and editing sitetree objects in the silverstripe CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
