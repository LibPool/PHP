# sunnysideup/ecommerce_vote

> 标签: Silverstripe-CMS, cms, silverstripe

## 简介

allows users to vote for products within the framework for Silverstripe e-commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
