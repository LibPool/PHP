# sunnysideup/array2ul

> 标签: array, cms, debug, nice, ul, unordered list

## 简介

Convert an associative Array to a UL for display in the CMS and elsewhere

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
