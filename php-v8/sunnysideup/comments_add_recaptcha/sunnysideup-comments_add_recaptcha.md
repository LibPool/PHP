# sunnysideup/comments_add_recaptcha

> 标签: Silverstripe-CMS, blog, captcha, cms, comment, comments, recaptcha, security, silverstripe, spam

## 简介

Adds Captcha to the comments module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
