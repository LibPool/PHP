# sunnysideup/elemental-edit-me-button

> 标签: Silverstripe-CMS, cms, elemental, elemental-edit-me-button, silverstripe

## 简介

Add an edit button to any elemental on the front-end.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
