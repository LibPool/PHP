# sunnysideup/folder-info

> 标签: count, file, files, filesize, filetime, folder

## 简介

Get recursive information about a folder or file in an efficient manner

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
