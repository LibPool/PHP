# sunnysideup/elemental-can-view

> 标签: Silverstripe-CMS, canView, cms, elemental, extendedCan, field, permissions, silverstripe

## 简介

Allows for more refined can view scenarios for elemental blocks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
