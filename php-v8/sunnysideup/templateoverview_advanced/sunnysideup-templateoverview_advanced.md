# sunnysideup/templateoverview_advanced

> 标签: Silverstripe-CMS, cms, page types, review, silverstripe, template review, templateoverview_advanced

## 简介

adds development tools for building silverstripe websites, in particular around managing page types.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
