# sunnysideup/ecommerce-mcp

> 标签: ai, brave new world, ecommerce, llm, mcp, no human in the middle

## 简介

Allows LLM Agents to get information from your shop using the MCP Protocol

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
