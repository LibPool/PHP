# sunnysideup/recently-changed

> 标签: Content Analysis, Silverstripe CMS, copying database, data-analysis, database, dev tool, dev-tools, make live, migration, recently changed, silverstripe

## 简介

Work out all the data objects and associated table data that has recently changed

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
