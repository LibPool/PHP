# sunnysideup/duplicate-urlsegments

> 标签: Silverstripe-CMS, URLSegments, cms, duplicate, link, silverstripe

## 简介

Remove duplicate URLSegments (e.g. my-page-2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
