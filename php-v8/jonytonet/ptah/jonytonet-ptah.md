# jonytonet/ptah

> 标签: crud, generator, laravel, livewire4, scaffolding, tailwind

## 简介

Ptah — Laravel scaffolding generator. CRUD, DTOs, Repositories, Services, Livewire 4, Tailwind v4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
