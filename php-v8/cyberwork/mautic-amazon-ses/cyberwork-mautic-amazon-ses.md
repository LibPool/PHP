# cyberwork/mautic-amazon-ses

> 标签: Mautic, amazon, integration, plugin, ses

## 简介

Mautic 6 plugin that provides Amazon SES as an email transport and callback to process bounces

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
