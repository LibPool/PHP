# nohara/laravel-latex-editor

> 标签: PHP

## 简介

Pustaka input rumus matematika LaTeX mandiri yang bebas lisensi dan mudah diintegrasikan di Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
