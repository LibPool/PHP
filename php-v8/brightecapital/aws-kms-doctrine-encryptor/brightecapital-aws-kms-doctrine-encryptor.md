# brightecapital/aws-kms-doctrine-encryptor

> 标签: PHP

## 简介

Custom encryptor for michaeldegroot/doctrine-encrypt-bundle to use AWS KMS for encryption

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
