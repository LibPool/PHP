# brightecapital/code-generator-templates

> 标签: PHP

## 简介

Templates for code generation based on openApi specification. Based on OpenAPITools/openapi-generator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
