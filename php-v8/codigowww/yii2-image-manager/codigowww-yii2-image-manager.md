# codigowww/yii2-image-manager

> 标签: crop, extension, image, manager, module, upload, widget, yii2

## 简介

A Yii2 module/widget for upload and cropping images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
