# elastic-php/ecs-logging-psr3

> 标签: ECS, elastic, filebeat, log, logging, psr-3

## 简介

Format and enrich your log files in the elastic common schema with psr/log3 support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
