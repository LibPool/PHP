# altzone/sievefilter-apply

> 标签: filter, managesieve, plugin, roundcube, sieve

## 简介

Retroactively apply Sieve filter rules to existing messages in a folder

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
