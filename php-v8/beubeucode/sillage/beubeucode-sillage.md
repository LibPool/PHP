# beubeucode/sillage

> 标签: Ahoy, analytics, inertia, laravel, privacy, tracking

## 简介

First-party, privacy-friendly event tracking for Laravel with native Blade and Inertia support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
