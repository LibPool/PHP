# fisafe/api-client

> 标签: PHP

## 简介

The `Fisafe Api Client` is a powerful PHP client designed to integrate seamlessly with the `fisafe.cloud` API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
