# clarkewing/handoff

> 标签: clarkewing, handoff, laravel, php

## 简介

Lightweight Laravel package for secure cross-application user handoff via signed URLs and route mapping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
