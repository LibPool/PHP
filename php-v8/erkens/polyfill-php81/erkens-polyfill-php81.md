# erkens/polyfill-php81

> 标签: compatibility, polyfill, portable, shim

## 简介

Symfony polyfill backporting some PHP 8.1+ features to lower PHP versions, compatible for >=PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
