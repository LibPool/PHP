# erkens/2fa-text

> 标签: 2fa, Authentication, sms, symfony, text, two-factor, two-step

## 简介

Extends scheb/2fa-bundle with two-factor authentication via simple text messages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
