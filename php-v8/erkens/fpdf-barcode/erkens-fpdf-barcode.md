# erkens/fpdf-barcode

> 标签: EAN13, UPC-A, barcode, code128, code39, fpdf, pdf

## 简介

FPDF Barcode support for EAN13, UPC-A, Code 39, Code 128

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
