# blade-ui-kit/blade-zondicons

> 标签: Zondicons, blade, laravel

## 简介

A package to easily make use of Zondicons in your Laravel Blade views.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
