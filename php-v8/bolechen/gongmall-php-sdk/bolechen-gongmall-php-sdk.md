# bolechen/gongmall-php-sdk

> 标签: PHP

## 简介

工猫（gongmall.com）sdk for php，非官方支持。基于官网文档：https://opendoc.gongmall.com 实现

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
