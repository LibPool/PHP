# gedachtegoed/workspace

> 标签: PHP

## 简介

Opinionated wrapper around tighten/duster with default configs, Larastan & Prettier blade formatting integration & CI workflows. For internal use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
