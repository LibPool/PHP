# tuuz/input

> 标签: commit-message, conventional-commits, input, parameter, php85, request, semver, thinkphp, thinkphp8, tuuz, type-safety, validation, validator, xss

## 简介

ThinkPHP 8 Input parameter validation package providing type-safe Post/Get extractors (Int/Float/Bool/DateTime/Json) and Conventional Commits message analyzer. Compatible with PHP 8.5+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
