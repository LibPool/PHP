# devuni/notifier-agent

> 标签: Agent, announcements, backup, devuni, laravel, notifier

## 简介

Laravel agent for the Devuni Notifier platform - encrypted backups and announcements.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
