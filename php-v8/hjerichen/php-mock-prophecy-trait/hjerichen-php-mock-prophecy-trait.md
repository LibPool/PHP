# hjerichen/php-mock-prophecy-trait

> 标签: PHP

## 简介

A Trait for php unit test cases to activate php-mock-prophecy from Markus Malkusch. Enables auto completion as well.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
