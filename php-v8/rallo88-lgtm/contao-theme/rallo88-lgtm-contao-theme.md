# rallo88-lgtm/contao-theme

> 标签: PHP

## 简介

RCT — Rallo's Contao Theme. A modern dark-mode design system with WebGL effects, custom content elements, and multi-layout support for Contao 5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
