# sacred/flysystem-lazy-migration-adapter

> 标签: PHP

## 简介

A Flysystem adapter that lazily migrates files from an old adapter to a new one as they are accessed.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
