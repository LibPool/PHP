# mariopenterman/php-webdriver

> 标签: Chromedriver, geckodriver, php, selenium, webdriver

## 简介

A PHP client for Selenium WebDriver. Previously facebook/webdriver.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
