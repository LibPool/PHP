# connectholland/openapi-specification-generator

> 标签: JSON Schema, api, json, openapi, swagger

## 简介

OpenAPI (Swagger) specification generator for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
