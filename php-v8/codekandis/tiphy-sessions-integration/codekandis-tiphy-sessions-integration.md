# codekandis/tiphy-sessions-integration

> 标签: integration, library, php, sessions, tiphy

## 简介

`codekandis/tiphy-sessions-integration` is a library integrating `codekandis/sessions` into `codekandis/tiphy`.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
