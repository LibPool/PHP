# codekandis/base64-codec

> 标签: base64, base64 codec, codec, decode, encode, php

## 简介

This library provides a codec to encode into and decode from Base64 in an object oriented way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
