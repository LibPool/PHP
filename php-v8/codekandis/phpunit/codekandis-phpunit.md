# codekandis/phpunit

> 标签: array-subset, assertions, constraints, data-provider, php, phpunit, subclass, test-case, testing

## 简介

`codekandis/phpunit` is a library for `PHPUnit` testing with enhanced test cases and custom constraint assertions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
