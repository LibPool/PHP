# parisek/drupal-kit

> 标签: PHP

## 简介

Shared Drupal infrastructure for sites built on the PORTA component pattern: services, base classes, Twig extensions, image resizer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
