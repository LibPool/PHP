# parisek/definition-kit

> 标签: acf, advanced custom fields, code-generation, drift-lint, drupal, gutenberg, paragraphs, wordpress, yaml

## 简介

Authored per-component definition (YAML) → CMS projection generator + drift-lint. Migrates ACF field groups and Drupal paragraph types to a semantic definition, regenerates acf.json/block.json, and fails CI when a projection or a Drupal config export drifts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
