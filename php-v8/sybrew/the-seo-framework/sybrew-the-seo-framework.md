# sybrew/the-seo-framework

> 标签: plugin, seo, wordpress

## 简介

An automated, advanced, accessible, unbranded and extremely fast SEO solution for any WordPress website.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
