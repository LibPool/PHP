# mschneider82/roundcube-opencloud

> 标签: PHP

## 简介

Roundcube plugin to connect each user's personal OpenCloud Space — save attachments to the cloud or attach files from it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
