# xoops/moduletools

> 标签: framework, modules, utilities, xoops

## 简介

Core-bundled reusable services and compatibility module helpers for XOOPS 2.8.0+ modules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://xoops.org
- 源码仓库：https://github.com/XOOPS/moduletools.git
- Packagist 页面：https://packagist.org/packages/xoops%2Fmoduletools

## 获取地址

- Composer 安装：`composer require xoops/moduletools`
