# phatnt93/php-upload-helper

> 标签: Webp, avif, batch-upload, class-upload, crop, file-upload, file-validation, gd, image-manipulation, image-upload, mime-validation, multi-upload, psr-7, resize, secure-upload, ssrf, upload, watermark

## 简介

A modern, secure and fluent PHP file upload and image manipulation library with first-class multi-file array support, inspired by class.upload.php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
