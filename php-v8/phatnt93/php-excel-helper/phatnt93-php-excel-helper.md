# phatnt93/php-excel-helper

> 标签: array-to-excel, csv, excel, excel-export, excel-import, excel-reader, excel-to-array, excel-writer, export, import, ods, phpspreadsheet, spreadsheet, xls, xlsx

## 简介

Read and write Excel/spreadsheet files (xlsx, xls, ods, csv) with simple array configuration: start row/column, typed columns, defaults, row-level validation errors, styled exports. Built on PhpSpreadsheet.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
