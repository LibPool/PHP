# phatnt93/php-file-helper

> 标签: PSR-4, atomic-write, checksum, directory, file, file-helper, file-system, filesystem, finder, folder, ftp, path-normalization, path-traversal, php, php8, security, sftp, stream, tar, zip

## 简介

A high-performance, expressive, and secure PHP file and directory manipulation library supporting create, delete, rename, copy, move, atomic writes, streaming, path traversal protection, finder, zip archiving, and remote FTP management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
