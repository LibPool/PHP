> 标签: GUMP, PSR-4, cphalcon, data-validation, file-upload-validation, filter, filtering, form-validation, nested-validation, phalcon, phalcon5, php, php8, request-validation, sanitization, sanitizer, validation, validator, wildcard-validation

## 简介

High-performance, expressive PHP data validation and sanitization library for Phalcon Framework v5, inspired by GUMP. Features 80+ validators, 17 filters, nested wildcard arrays, file upload validation, and Phalcon MVC Model ORM integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
