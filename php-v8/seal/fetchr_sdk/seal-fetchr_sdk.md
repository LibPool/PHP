# seal/fetchr_sdk

> 标签: Fetchr, delivery, php, sdk

## 简介

sdk for Delivery Service Fetchr ( https://fetchr.us/ )

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
