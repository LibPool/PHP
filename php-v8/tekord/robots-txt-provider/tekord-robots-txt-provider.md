# tekord/robots-txt-provider

> 标签: indexing, robots, robots.txt, search, seo

## 简介

Provides various framework-agnostic ways to generate the contents of the robots.txt file

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
