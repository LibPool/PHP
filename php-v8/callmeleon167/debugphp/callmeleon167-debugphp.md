# callmeleon167/debugphp

> 标签: debug, debugging, developer-tools, php, real-time, sse

## 简介

Real-time PHP debugging in the browser — zero config, zero dependencies, just send() and see.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
