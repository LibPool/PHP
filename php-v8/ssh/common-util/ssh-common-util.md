# ssh/common-util

> 标签: aes, aliyun, iot, oss, printer, sm-crypto, sm2, sm3, sm4, sms, sunmi, utility

## 简介

PHP 常用工具类集合，包含阿里云IoT/OSS/SMS、国密SM2/SM3/SM4加解密、AES加解密、商米云打印等工具

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
