# friendsofhyperf/telescope

> 标签: debugging, hyperf, swoole, v3.2

## 简介

An elegant debug assistant for the hyperf framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
