# friendsofhyperf/oauth2-server

> 标签: hyperf, oauth2, oauth2-server, v3.2

## 简介

The Oauth2 server for hyperf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
