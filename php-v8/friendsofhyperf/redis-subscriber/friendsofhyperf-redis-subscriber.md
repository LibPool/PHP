# friendsofhyperf/redis-subscriber

> 标签: redis, subscriber, swoole

## 简介

Redis native protocol Subscriber based on Swoole coroutine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
