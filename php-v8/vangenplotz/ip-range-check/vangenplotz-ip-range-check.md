# vangenplotz/ip-range-check

> 标签: Craft, cms, craft-plugin, craftcms, ip range check

## 简介

Checks if users ip is in a range og ips.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
