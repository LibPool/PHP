# brocosan/studio-addons

> 标签: Botman, bot, studio

## 简介

Fork of botman/studio-addons to be used with PHP 8 and Laravel 9. BotMan Studio specific addons.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
