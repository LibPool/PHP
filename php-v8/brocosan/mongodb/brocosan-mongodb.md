# brocosan/mongodb

> 标签: database, eloquent, laravel, model, moloquent, mongo, mongodb

## 简介

Fork of jenssegers/mongodb. A MongoDB based Eloquent model and Query builder for Laravel (Moloquent)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
