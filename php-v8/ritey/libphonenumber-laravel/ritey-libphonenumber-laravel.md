# ritey/libphonenumber-laravel

> 标签: laravel, mobile, phone, phonenumber, php

## 简介

Service Provider for libphonenumber-for-php package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
