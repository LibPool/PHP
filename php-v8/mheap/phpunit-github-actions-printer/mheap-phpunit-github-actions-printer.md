# mheap/phpunit-github-actions-printer

> 标签: PHP

## 简介

PHPUnit Printer for adding test failures as annotations on GitHub Actions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
