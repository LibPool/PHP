# t3ran13/bytebuffer

> 标签: Buffer, Bytehandling, Socket, binary data, library, pack, stream, wrapper

## 简介

Node.js inspired byte stream buffer for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
