# asawl/laravel-sqlite-manager

> 标签: admin, artisan, database, laravel, laravel-package, livewire, sqlite

## 简介

Livewire-powered SQLite database manager for Laravel 12 applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
