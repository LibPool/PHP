# dr3ads/paydock_php_sdk

> 标签: PHP

## 简介

The PayDock PHP SDK provides a PHP friendly wrapper around the PayDock API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
