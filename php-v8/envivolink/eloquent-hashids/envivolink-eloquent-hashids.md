# envivolink/eloquent-hashids

> 标签: eloquent, hashid, hashids, laravel

## 简介

Automatically generate hashids in Laravel for a new Eloquent Model.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
