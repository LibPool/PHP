# ausus/authoring

> 标签: DSL, ausus, authoring, framework

## 简介

AUSUS Authoring (L1) — closed PHP DSL producing an EE-RFC-012 EntityDefinition. EE-RFC-CLI-002/003.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
