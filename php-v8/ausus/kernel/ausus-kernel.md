# ausus/kernel

> 标签: ausus, framework, kernel, metadata

## 简介

AUSUS Kernel (L0) — contracts, value objects, DSL facade, and the Entity Engine model + runtime contracts (Definition / Contracts / Compiled). RFC-001 + contract surfaces of RFC-005 §2, RFC-013 §2, RFC-014 §2; EE-RFC-011 / EE-RFC-012.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
