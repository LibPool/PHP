# happytodev/blogr

> 标签: blogr, filamentphp, happytodev, laravel

## 简介

Blogr is a FilamentPHP plugin that adds a powerful blog system to your Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
