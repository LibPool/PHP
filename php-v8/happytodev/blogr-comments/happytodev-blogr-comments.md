# happytodev/blogr-comments

> 标签: blog, blogr, comments, filamentphp

## 简介

Comment system for Blogr CMS — threaded comments, moderation, voting, anti-spam, and notifications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
