# efadah/laravel-cognito-auth

> 标签: AWS Cognito, Auth Provider, efadah

## 简介

An auth provider for Laravel for AWS Cognito.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
