# disc/php-zabbix-sender

> 标签: zabbix

## 简介

PHP implementation of zabbix_sender utility. Works with Zabbix 2.0.8, 2.1.7+ and 4.0 versions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
