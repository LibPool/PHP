# samuelmwangiw/laravel-vite

> 标签: SamuelMwangiW, laravel, laravel-vite, vite

## 简介

A tiny package that adds @vite_assets blade directive and loads Vite assets

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
