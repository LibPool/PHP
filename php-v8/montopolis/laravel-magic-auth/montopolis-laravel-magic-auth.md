# montopolis/laravel-magic-auth

> 标签: Authentication, laravel, magic, otp, slack

## 简介

Package for implementing magical authentication (URL and token) in Laravel 5.2+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
