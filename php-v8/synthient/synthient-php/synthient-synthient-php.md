# synthient/synthient-php

> 标签: Proxy detection, ip intelligence, synthient, threat intelligence, vpn detection

## 简介

The official PHP client for the Synthient API: IP and domain intelligence, account details, and real-time and bulk data feeds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
