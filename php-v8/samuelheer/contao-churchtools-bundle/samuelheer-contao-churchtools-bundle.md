# samuelheer/contao-churchtools-bundle

> 标签: Church, calendar, churchtools, contao, events

## 简介

ChurchTools-Integration für Contao: Termine samt Flyer und Personen aus ChurchTools auf der Website, mandantenfähig für mehrere Gemeinden in einer Installation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
