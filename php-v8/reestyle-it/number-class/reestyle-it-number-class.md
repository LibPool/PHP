# reestyle-it/number-class

> 标签: arithmetic, currency, formatting, math, number, trigonometry

## 简介

Chainable numeric values, arithmetic, comparisons, trigonometry and currency formatting for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
