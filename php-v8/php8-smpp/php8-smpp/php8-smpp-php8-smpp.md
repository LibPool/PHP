# php8-smpp/php8-smpp

> 标签: gsm, smpp, sms, texting

## 简介

PHP8 SMPP client lib, based on fork of alexandr-mironov/php-smpp which is fork of onlinecity/php-smpp

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
