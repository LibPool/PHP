# biurad/flysystem

> 标签: PHP7, biuradphp, filemanager, filesystem, theleague flysytem

## 简介

BiuradPHP Framework FileManager for handling filesytem in php and cloud

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
