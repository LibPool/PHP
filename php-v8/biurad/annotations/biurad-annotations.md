# biurad/annotations

> 标签: annotations, biurad, php, phpdoc

## 简介

A library that provides a Simple, Lazy, Fast & Lightweight Annotation for php classes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
