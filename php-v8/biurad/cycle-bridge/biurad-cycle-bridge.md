# biurad/cycle-bridge

> 标签: PHP7, biurad, biuradphp

## 简介

Well-integrated Cycle ORM for Nette and Biurad Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
