# wonderfulpaymentsltd/one-api-sdk-php

> 标签: PHP

## 简介

Official PHP SDK for the Wonderful One API - Accept Open Banking payments, manage customers, orders, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
