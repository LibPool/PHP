# mikehaertl/xreturnable

> 标签: url, yii

## 简介

Yii extension to create URLs that allow to return to a page by storing its GET Parameters on a stack.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
