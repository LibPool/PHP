# mikehaertl/xcrudcontroller

> 标签: controller, crud, yii

## 简介

xcrudcontroller is a Yii base class to quickly build customized CRUD interfaces.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
