# mikehaertl/yii2-apidoc-vim

> 标签: apidoc, vim, yii2

## 简介

Yii 2 apidoc as Vim helpfiles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
