# mikehaertl/pdftk2-precise-amd64

> 标签: pdf, pdftk

## 简介

The pdftk 2 binary for Ubuntu 12.04 LTS (amd64)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
