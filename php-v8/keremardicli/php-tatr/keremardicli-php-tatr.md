# keremardicli/php-tatr

> 标签: cli, git, task, tql, tracker

## 简介

Task Tracker — git-friendly, file-based task management. PHP implementation of tsoding/tatr.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
