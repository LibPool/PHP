# khmer-pdf/laravel-kh-pdf

> 标签: khmer, khmer pdf, laravel, laravel pdf khmer, mpdf, package, pdf

## 简介

A simple Laravel package for supporting Khmer font in PDFs using mPdf.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
