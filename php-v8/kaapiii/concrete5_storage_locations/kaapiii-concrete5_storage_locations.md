# kaapiii/concrete5_storage_locations

> 标签: PHP

## 简介

Concrete5 package adds new file storage locations on AWS S3 and Google Cloud Storage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
