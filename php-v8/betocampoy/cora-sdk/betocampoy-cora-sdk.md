# betocampoy/cora-sdk

> 标签: PHP

## 简介

SDK PHP para integrar com as APIs da Cora na modalidade Integracao Direta (mTLS + client_credentials).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
