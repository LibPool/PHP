# betocampoy/champs-jadlog-sdk

> 标签: PHP

## 简介

SDK PHP da Champs para integração com a Jadlog (frete, pedidos, tracking, DACTE, PUDOs, QRCode e DCE)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
