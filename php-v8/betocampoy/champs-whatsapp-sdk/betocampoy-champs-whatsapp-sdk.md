# betocampoy/champs-whatsapp-sdk

> 标签: baileys, champs, gateway, whatsapp

## 简介

SDK PHP da Champs para o gateway WhatsApp (champs-whatsapp-gateway): sessões, QR code, envio de mensagens e regras do protocolo. Sem regra de negócio de nenhuma aplicação.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
