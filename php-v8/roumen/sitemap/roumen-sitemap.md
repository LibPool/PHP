# roumen/sitemap

> 标签: Sitemap, generator, google-news, html, laravel, php, symfony, xml

## 简介

Framework-agnostic Sitemap generator for PHP, Laravel, and Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
