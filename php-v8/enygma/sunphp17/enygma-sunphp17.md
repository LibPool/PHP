# enygma/sunphp17

> 标签: Skeleton, framework, slim, slimframework

## 简介

A skeleton of a Slim application (with extras) for SunshinePHP 2017

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
