# pixiekat/alicanto_learning_scorm_cloud

> 标签: PHP

## 简介

Embeds SCORM Cloud-hosted courses as Alicanto Learning activities, with xAPI-powered reporting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
