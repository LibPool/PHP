# nancheng/pfinal-request

> 标签: Q哥, pfinal, pfinal-request, php-request, request, 南丞

## 简介

Request组件是用于获取请求数据与对请求终端设备进行判断的组件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
