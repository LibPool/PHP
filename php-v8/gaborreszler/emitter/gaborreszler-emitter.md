# gaborreszler/emitter

> 标签: emitter, emitterio, phpmqtt

## 简介

PHP 8.0 compatible wrapper for emitter.io by bobbymaher/emitter around bluerhinos/phpmqtt

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
