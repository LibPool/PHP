# just/thumbnailbundle

> 标签: Symfony2, bundle, thumbnail

## 简介

A Symfony bundle that creates Thumbnails on the fly using the GD library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
