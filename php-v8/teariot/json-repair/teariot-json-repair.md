# teariot/json-repair

> 标签: JSONP, NDJSON, broken, comments, extract, fix, invalid, json, llm, malformed, mongodb, parse, python, repair, streaming, template

## 简介

Repair broken, malformed, or non-standard JSON — fix quotes, commas, comments, Python constants, JSONP, NDJSON, HTML entities, and more

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
