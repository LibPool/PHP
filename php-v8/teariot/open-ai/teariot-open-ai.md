# teariot/open-ai

> 标签: GPT-3, open-ai, orhanerday, php, teariot

## 简介

OpenAI GPT-3 Api Client in PHP. This is a fork of https://github.com/orhanerday/open-ai

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
