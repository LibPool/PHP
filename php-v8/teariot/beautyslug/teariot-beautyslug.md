# teariot/beautyslug

> 标签: Unique Slug, php, php Slug, random slug, random string, slug, slug generator, slugify, string generator, text generator

## 简介

Lightweight PHP library for generating random readable slugs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
