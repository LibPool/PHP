# plantgeekz/botanical-name

> 标签: botanical, botany, cultivar, gardening, icn, icncp, nomenclature, parser, plant, plants, scientific-name, taxonomy

## 简介

Parse, normalize and format botanical plant names (ICN + ICNCP): hybrids, infraspecific ranks, authors, cultivars, groups and correct italics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
