# wotz/socialite-zenith

> 标签: laravel, oauth, socialite, who owns the zebra, zenith

## 简介

Laravel Socialite provider for Zenith, the WOTZ OAuth2 server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
