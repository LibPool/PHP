# abc/job-server-bundle

> 标签: asynchronous, cron, distributed, job, queue, schedule

## 简介

A symfony bundle to manage asynchronous distributed processing of stateful jobs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
