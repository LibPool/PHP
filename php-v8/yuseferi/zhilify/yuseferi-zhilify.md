# yuseferi/zhilify

> 标签: debug, debugging, php, pretty, print, print_r, var_dump, zhilify

## 简介

Zhilify is a tool for debugging with dump variables, arrays and objects in a pretty way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
