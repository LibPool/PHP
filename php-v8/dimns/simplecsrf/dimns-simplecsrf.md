# dimns/simplecsrf

> 标签: csrf, php

## 简介

Simple CSRF-token class to prevent CSRF attacks. For forms and AJAX requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
