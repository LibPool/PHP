# knevelina/laravel-lighthouse-test

> 标签: graphql, laravel, lighthouse, testing

## 简介

Tools for testing Lighthouse GraphQL applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
