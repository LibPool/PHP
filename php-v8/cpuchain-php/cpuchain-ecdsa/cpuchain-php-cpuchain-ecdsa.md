# cpuchain-php/cpuchain-ecdsa

> 标签: CPUchain, ECDSA

## 简介

PHP library allowing to generate CPU addresses from private keys

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
