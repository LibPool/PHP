# vaneetjoshi/laravel-pdf

> 标签: devanagari, hindi pdf, laravel, laravel hindi pdf, laravel-pdf, mpdf, otl, pdf, pdf-generator, sanskrit, shared-hosting

## 简介

A pure-PHP, shared-hosting friendly PDF engine for Laravel with advanced Devanagari and Sanskrit OTL script support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
