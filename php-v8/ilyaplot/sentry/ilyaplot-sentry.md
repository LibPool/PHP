# ilyaplot/sentry

> 标签: crash-reporting, crash-reports, error-handler, error-monitoring, log, logging, sentry

## 简介

A PHP SDK for Sentry (http://sentry.io)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
