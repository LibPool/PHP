# taufikp/igscraper

> 标签: instagram, scraper

## 简介

Instagram web scraper based on PHP. You can get account information, photos and videos from Instagram web version

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
