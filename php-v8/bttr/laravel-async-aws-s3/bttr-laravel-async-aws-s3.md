# bttr/laravel-async-aws-s3

> 标签: Flysystem, async-aws, filesystem, laravel, s3, storage

## 简介

Laravel filesystem driver backed by the AsyncAws S3 client instead of the AWS SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
