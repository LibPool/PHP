# eposgit/bootstrap-table

> 标签: bootstrap, pagination, table, tablesort

## 简介

An extended Bootstrap table with radio, checkbox, sort, pagination and other features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
