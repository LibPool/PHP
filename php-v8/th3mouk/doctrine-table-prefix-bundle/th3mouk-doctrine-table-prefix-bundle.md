# th3mouk/doctrine-table-prefix-bundle

> 标签: doctrine, prefix, symfony, table

## 简介

Bundle for Symfony2 and Doctrine2 that allow prefixing yours databases tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
