# th3mouk/reactive-event-dispatcher

> 标签: PHP

## 简介

An immutable implementation of the PSR-14 (event-dispatcher) for ReactiveX PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
