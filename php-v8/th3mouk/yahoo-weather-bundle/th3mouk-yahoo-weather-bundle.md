# th3mouk/yahoo-weather-bundle

> 标签: bundle, forecasts, symfony, weather, yahoo

## 简介

Symfony bundle that include Yahoo Weather API and archive datas in database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
