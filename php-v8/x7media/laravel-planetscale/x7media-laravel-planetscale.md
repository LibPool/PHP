# x7media/laravel-planetscale

> 标签: LaravelPlanetscale, laravel

## 简介

A package for managing Laravel database migrations with Planetscale databases.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
