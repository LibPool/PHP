# hamada-emam-tech/esign-uaepass

> 标签: digital-signature, e-signature, esign, pades, uae, uae-pass

## 简介

UAE PASS digital signature driver for hamada-emam-tech/esign: qualified PAdES signatures with the signer's UAE PASS identity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
