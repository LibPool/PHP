# hamada-emam-tech/esign-adobe

> 标签: acrobat-sign, adobe, adobe-sign, e-signature, esign

## 简介

Adobe Acrobat Sign (REST API v6) driver for hamada-emam-tech/esign: agreements, signature fields, webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
