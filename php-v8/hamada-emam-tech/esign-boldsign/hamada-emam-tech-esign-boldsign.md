# hamada-emam-tech/esign-boldsign

> 标签: boldsign, e-signature, esign, webhook

## 简介

BoldSign driver for hamada-emam-tech/esign: e-signature documents over BoldSign API v1, with signed webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
