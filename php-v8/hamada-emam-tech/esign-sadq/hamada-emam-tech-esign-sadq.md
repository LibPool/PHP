# hamada-emam-tech/esign-sadq

> 标签: e-signature, esign, nafath, sadq, saudi

## 简介

SADQ (sadq.sa) driver for hamada-emam-tech/esign: Saudi e-signature envelopes with Nafath identity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
