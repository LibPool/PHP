# hamada-emam-tech/esign-dropbox

> 标签: dropbox, dropbox-sign, e-signature, esign, hellosign

## 简介

Dropbox Sign (formerly HelloSign) driver for hamada-emam-tech/esign: e-signature requests over the Dropbox Sign API v3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
