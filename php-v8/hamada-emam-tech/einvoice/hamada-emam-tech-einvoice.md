# hamada-emam-tech/einvoice

> 标签: Egypt, ZATCA, cades, e-invoicing, einvoice, eta, fatoora, pkcs11, saudi, ubl

## 简介

One interface for tax-authority e-invoicing: sign every invoice and submit it. Install the core, then only the authority you need (ZATCA, Egypt ETA...). The signing key is pluggable: software key, USB token or cloud HSM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
