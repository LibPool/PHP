# hamada-emam-tech/esign

> 标签: digital-signature, docusign, e-signature, eSignature, emdha, nafath, sadq, saudi, signit

## 简介

One interface for e-signature providers in Saudi Arabia and beyond. Install the core, then only the providers you use (SADQ, Signit, emdha, DocuSign...).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
