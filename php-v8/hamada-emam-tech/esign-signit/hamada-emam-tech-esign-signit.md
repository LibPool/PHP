# hamada-emam-tech/esign-signit

> 标签: dga, e-signature, esign, nafath, saudi, signit

## 简介

Signit (signit.sa) driver for hamada-emam-tech/esign: Saudi DGA-licensed e-signature with Nafath, and encrypted webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
