# hamada-emam-tech/esign-docusign

> 标签: docusign, e-signature, envelope, esign, webhook

## 简介

DocuSign eSignature REST API v2.1 driver for hamada-emam-tech/esign: JWT Grant, envelopes, Connect webhooks with HMAC.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
