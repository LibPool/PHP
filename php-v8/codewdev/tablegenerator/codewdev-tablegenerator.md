# codewdev/tablegenerator

> 标签: CodeWdev, WRRDev, php, tabelas banco de dados, table, tablegenerator

## 简介

Biblioteca de criação de tabelas para projetos em php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
