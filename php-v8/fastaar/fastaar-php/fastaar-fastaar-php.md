# fastaar/fastaar-php

> 标签: bangladesh, bkash, fastaar, nagad, payments

## 简介

PHP SDK for the Fastaar payment gateway — accept bKash & Nagad payments in Bangladesh.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
