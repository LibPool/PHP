## 简介

Commercial Magento 2 One Page Checkout extension — 4 layouts, 8 payment providers (Mollie, Stripe, PayPal, Klarna, Adyen, PayOne, Unzer, Amazon Pay), Hyvä-native & Luma-compatible, 11 languages, mobile-first. Module source delivered after purchase.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
