# storetown/module-b2b-register

> 标签: admin-approval, adobe-commerce, b2b, b2b-registration, company-account, customer-registration, hyva, magento-2, magento-extension, magento2, vat-id

## 简介

Commercial Magento 2 B2B customer registration extension — admin approval workflow, custom fields (company, VAT-ID), customer-group automation, 3 modes (B2B+B2C / B2B-only / B2C-only), email notifications, reCAPTCHA, 7 languages. Module source delivered after purchase.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
