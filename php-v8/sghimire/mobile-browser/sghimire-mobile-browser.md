# sghimire/mobile-browser

> 标签: browser, in-app-browser, laravel, mobile, nativephp, webview

## 简介

Self-contained native in-app browser (WKWebView / android.webkit.WebView) and external browser launcher for NativePHP Mobile own facade, fluent open builder, events, and JS bindings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
