# sghimire/mobile-secure-storage

> 标签: encryption, keychain, keystore, laravel, mobile, nativephp, secure-storage

## 简介

Self-contained hardware-backed secure storage (Android Keystore / iOS Keychain) for NativePHP Mobile — own facade, validated native implementation, and JS bindings, with no dependency on the paid nativephp/mobile-secure-storage plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
