# sghimire/mobile-scanner

> 标签: barcode, camera, laravel, mobile, nativephp, qr-code, scanner

## 简介

Self-contained native QR/barcode scanner (CameraX + ML Kit / AVFoundation) for NativePHP Mobile — own facade, fluent multi-format API, events, and JS bindings, with no dependency on the paid nativephp/mobile-scanner plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
