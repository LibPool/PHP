# mranger/yii2-ckeditor

> 标签: CKEditor, widget, wysiwyg

## 简介

CKEditor Yii2 widget working via official ckeditor composer package and using custom presets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
