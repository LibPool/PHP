# dvandersluijs/wsdl-to-class

> 标签: code-generation, generator, php, soap, soap-wsdl, wsdl

## 简介

Generate PHP7 code from an WSDL file

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
