# boxleaf/module-bannerslider

> 标签: PHP

## 简介

CoullWorks Banner Slider for Magento 2 — manage hero banners and sliders and place them via Page Builder content types or widgets, with parallax and a Slick carousel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
