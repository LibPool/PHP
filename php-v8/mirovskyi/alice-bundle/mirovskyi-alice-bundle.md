# mirovskyi/alice-bundle

> 标签: Fixture, Symfony2, alice, orm

## 简介

Symfony2 Bundle that helps loading fixture data written with the Alice library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
