# brigada/statamic-cms-starter

> 标签: PHP

## 简介

A ready-to-use Statamic starter package providing a pre-configured CMS setup with blueprints, collections, assets, and an admin user command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
