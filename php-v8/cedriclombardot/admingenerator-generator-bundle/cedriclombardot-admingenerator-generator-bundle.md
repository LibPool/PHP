# cedriclombardot/admingenerator-generator-bundle

> 标签: admin, generator, yaml

## 简介

Admingenerator for Symfony2 based on YAML configuration and Twig templating

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
