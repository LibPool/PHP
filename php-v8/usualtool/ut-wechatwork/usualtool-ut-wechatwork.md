# usualtool/ut-wechatwork

> 标签: UT Framework, usualtool, ut-wechatwork

## 简介

Wechat work API extension of UT framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
