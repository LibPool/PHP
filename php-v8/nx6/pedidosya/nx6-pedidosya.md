# nx6/pedidosya

> 标签: catalog-export, magento, magento-module, magento2, marketplace, pedidosya, promotions, sftp

## 简介

Magento 2 module that exports the catalog and promotions to PedidosYa over SFTP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
