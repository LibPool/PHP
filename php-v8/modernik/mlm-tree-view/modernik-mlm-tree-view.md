# modernik/mlm-tree-view

> 标签: PHP

## 简介

Une bibliothèque PHP pour générer des arbres MLM (multi-level marketing) avec un rendu HTML stylisé prêt à l'emploi.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
