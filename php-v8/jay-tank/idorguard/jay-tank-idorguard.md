# jay-tank/idorguard

> 标签: PHP

## 简介

Static analyzer that flags Laravel controller actions receiving a route-model-bound Eloquent model with no visible authorization check in the method body.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
