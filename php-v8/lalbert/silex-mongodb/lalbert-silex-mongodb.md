# lalbert/silex-mongodb

> 标签: mongodb, provider, silex

## 简介

Simple mongodb service provider for Silex 2.x and official mongodb driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
