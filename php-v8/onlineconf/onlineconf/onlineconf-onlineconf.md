# onlineconf/onlineconf

> 标签: cdb, config, configuration, onlineconf

## 简介

PHP client for OnlineConf: reads configuration from CDB modules generated by onlineconf-updater

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
