# onlineconf/onlineconf-laravel

> 标签: config, configuration, laravel, onlineconf

## 简介

Laravel integration for onlineconf-php: service provider, facade, config, test helpers and artisan commands

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
