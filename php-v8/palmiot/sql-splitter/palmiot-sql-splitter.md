# palmiot/sql-splitter

> 标签: file, php, pipe, split, splitter, sql, stream

## 简介

Tool for split SQL databases from a file or a pipe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
