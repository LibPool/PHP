# caydeesoft/saas-kit

> 标签: Audit, JSON-LD, billing, invoices, laravel, mcp, model-context-protocol, multi-tenant, open-graph, payments, rbac, saas, seo, stripe, subscriptions, webhooks

## 简介

A reusable Laravel SaaS infrastructure engine with multi-tenancy, billing, payments, RBAC, invoices, webhooks, audit logs, MCP tools, and SEO metadata utilities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
