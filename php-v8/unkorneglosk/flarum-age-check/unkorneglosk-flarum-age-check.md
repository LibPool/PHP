# unkorneglosk/flarum-age-check

> 标签: flarum

## 简介

Adds a modal that blocks site access until user accepts modal. Used for age verification or  critical announcements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
