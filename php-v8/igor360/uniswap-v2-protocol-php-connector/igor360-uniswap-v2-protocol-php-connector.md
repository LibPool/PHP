# igor360/uniswap-v2-protocol-php-connector

> 标签: connector, ethereum, php, uniswap

## 简介

It's package using for decode uniswap v2 transactions and call contract data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
