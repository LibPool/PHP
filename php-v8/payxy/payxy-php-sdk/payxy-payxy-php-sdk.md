# payxy/payxy-php-sdk

> 标签: checkout, payment gateway, payments, payxy, sdk

## 简介

PHP SDK for the Payxy payment gateway: Hosted Checkout, payment verification and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
