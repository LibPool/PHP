# jeevi/cabinet

> 标签: Microsoft Cabinet, cabextract, expand

## 简介

Microsoft Cabinet file extraction wrapper.  Uses either cabextract or expand

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
