# shoppingfeed/hal

> 标签: hal, hypermedia, json, rest, xml

## 简介

Fork of nocarrier/hal, an application/hal builder / formatter for PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
