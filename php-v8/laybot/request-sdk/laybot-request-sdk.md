# laybot/request-sdk

> 标签: Guzzle, NDJSON, http, laybot, sse, webman, websocket, workerman

## 简介

Reliable HTTP, SSE, JSON Lines and WebSocket client for PHP/Webman

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
