# laybot/ai-sdk

> 标签: ai, ark, deepseek, doubao, groq, laybot, llm, openai, qwen, webman, xai

## 简介

Provider-independent AI and speech SDK for PHP/Webman

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
