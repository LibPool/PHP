> 标签: cors, corslumen, cross-origin, laravel, lumen, lumencors

## 简介

Cross-origin resource sharing (CORS). Add CORS middleware for Lumen micro-framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
