# azettl/pdfreactor

> 标签: pdf, pdfreactor

## 简介

PHP Wrapper for PDFreactor. This class is taken from https://www.pdfreactor.com/.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
