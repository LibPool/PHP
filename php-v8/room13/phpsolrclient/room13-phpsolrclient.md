# room13/phpsolrclient

> 标签: PHP

## 简介

A github fork of the solr-php-client from google code at http://code.google.com/p/solr-php-client/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
