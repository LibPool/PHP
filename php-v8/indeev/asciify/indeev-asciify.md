# indeev/asciify

> 标签: asciify, indeev

## 简介

This tool is used to convert any string containing letters with diacritics to string with ASCII (a-zA-Z) version of accented letters

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
