# brainy/laravel-error-notifier

> 标签: discord, error, exceptions, laravel, monitoring, notifier, slack

## 简介

Lightweight, zero-config real-time error notifier for Laravel applications (Slack & Discord).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
