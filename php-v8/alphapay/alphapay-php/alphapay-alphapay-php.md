# alphapay/alphapay-php

> 标签: africa, alphapay, mobile-money, payment-gateway, payments

## 简介

Official PHP SDK for the AlphaPay payment aggregator API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
