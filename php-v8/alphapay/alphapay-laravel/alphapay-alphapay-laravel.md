# alphapay/alphapay-laravel

> 标签: africa, alphapay, laravel, mobile-money, moov, mtn, orange-money, payment-gateway, payments

## 简介

Laravel SDK officiel pour l'API AlphaPay (agrégateur de paiement multi-gateway) -- intégration Service Provider/Facade/webhooks au-dessus du SDK PHP alphapay/alphapay-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
