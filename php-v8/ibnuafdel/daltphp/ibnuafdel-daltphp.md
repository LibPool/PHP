# ibnuafdel/daltphp

> 标签: backend, beginner-friendly, debugging, education, framework, laravel-inspired, learning, php, sqlite, tailwind, tutorial, vite, vue

## 简介

Lightweight PHP micro-framework with optional built-in guided learning: lessons and broken-code challenges with automatic verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
