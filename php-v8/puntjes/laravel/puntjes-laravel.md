# puntjes/laravel

> 标签: api, laravel, loyalty, puntjes, sdk

## 简介

Laravel integration for the Puntjes loyalty API — service provider, facade, config and a cache-backed token store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
