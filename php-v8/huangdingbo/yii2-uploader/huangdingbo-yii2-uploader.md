# huangdingbo/yii2-uploader

> 标签: component, extension, upload, widget, yii2

## 简介

Yii2 大文件上传(支持断点续传)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
