# digital-creative/nova-json-wrapper

> 标签: json, json-wrapper, laravel, nova

## 简介

Allows you to group Nova fields and merge their output into a single JSON column.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
