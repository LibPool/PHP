> 标签: JSON-API, PSR-11, api, framework, graphql, openapi, php, php8, psr-15, psr-7, rest, swagger

## 简介

Modern PHP framework for building expressive and maintainable APIs with support for REST, JSON:API, and GraphQL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
