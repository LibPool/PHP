# jeavenguitar/web3php

> 标签: Polygon, abi, arbitrum, bsc, ethereum, evm, rpc, smart-contract, solidity, web3

## 简介

PHP Ethereum/EVM toolkit in web3.js style: robust JSON-RPC client (multi-endpoint failover, retry, keep-alive), full ABI encoder/decoder (tuple/array/named outputs), contract calls and locally signed transactions (EIP-155 / EIP-1559).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
