# raingad/webman-storage

> 标签: cos, filesystem, oss, qiniu, s3, storage, upload, webman

## 简介

Webman file storage and upload plugin (local / Aliyun OSS / Tencent COS / Qiniu / AWS S3).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
