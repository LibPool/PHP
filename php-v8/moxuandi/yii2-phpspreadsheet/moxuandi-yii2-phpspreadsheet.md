# moxuandi/yii2-phpspreadsheet

> 标签: excel, extension, yii2, 导入, 导出, 表格

## 简介

用于读写电子表格文件的纯PHP库

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
