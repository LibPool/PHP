# boomdraw/laravel-dummy-image

> 标签: Dummy, boomdraw, image, laravel, laravel-dummy-image

## 简介

Laravel dummy image generator based on kingkool68/dummyimage

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
