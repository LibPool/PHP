# aaronkatema/laravel-smilepay

> 标签: ecocash, innbucks, laravel, omari, payment-gateway, payments, smileandpay, smilecash, smilepay, zb-bank, zimbabwe

## 简介

Laravel SDK for the ZB Bank Smile&Pay payment gateway (Zimbabwe) — EcoCash, InnBucks, O'mari, SmileCash and card payments with polling, webhooks, refunds and a full transaction audit trail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
