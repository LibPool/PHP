# nks-hub/nette-ruian

> 标签: address, api, czech, geocoding, nette, ruian, validation

## 简介

Nette extension for RUIAN (Czech Address Registry) API client with caching support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
