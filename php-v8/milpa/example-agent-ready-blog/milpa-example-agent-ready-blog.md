# milpa/example-agent-ready-blog

> 标签: PHP

## 简介

Runnable example of the Milpa loop — plugin → capability → tool → verification → event → result — as a tiny agent-ready blog.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
