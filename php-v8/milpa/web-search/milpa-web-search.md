# milpa/web-search

> 标签: PHP

## 简介

A governed web:search capability for Milpa apps — read-only locally, but the query leaves the machine (Externality::ThirdParty), so the egress gate governs it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
