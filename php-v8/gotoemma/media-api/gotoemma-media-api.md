# gotoemma/media-api

> 标签: PHP

## 简介

Example for integration of Sonata MediaBundle with ApiPlatform 2.0 including media upload and exposing media formats in GET item operation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
