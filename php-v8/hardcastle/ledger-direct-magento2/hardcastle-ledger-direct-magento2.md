# hardcastle/ledger-direct-magento2

> 标签: blockchain, crypto, cryptocurrency, magento2, payment, stablecoin, xrp, xrpl

## 简介

Component for accepting online payments in Magento2 using the XRP Ledger

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
