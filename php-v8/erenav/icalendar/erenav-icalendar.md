# erenav/icalendar

> 标签: calendar, iCalendar, ical, ics, rfc5545, rfc5546, rfc7986, vevent

## 简介

A modern, strongly-typed, immutable iCalendar (RFC 5545 / 7986 / 5546) library for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
