# faithphilemon/sm-mvc

> 标签: PHP

## 简介

sm-mvc (small mvc) is a minimal, light-weight and simple PHP framework based on MVC.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
