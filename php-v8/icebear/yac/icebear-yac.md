# icebear/yac

> 标签: agents, ai, cli, comments, dev, phpdoc

## 简介

YAC (Yeet Agent Comments): keeps coding-agent notes out of PHP source in .yac/ sidecars anchored to code; list, check, promote, extract and yeet them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
