# vynex/pay-php

> 标签: api, pay, payments, pix, sdk, vynex

## 简介

SDK PHP oficial da API Vynex Pay (/api/v1): recursos por família, Idempotency-Key automática, retry com backoff, paginação automática e verificação de webhook.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
