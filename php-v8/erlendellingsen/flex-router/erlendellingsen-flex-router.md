# erlendellingsen/flex-router

> 标签: PHP

## 简介

A small, lightweight php-router for creating clean, RESTful urls. Extremely easy to setup and configure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
