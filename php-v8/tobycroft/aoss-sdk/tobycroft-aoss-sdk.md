# tobycroft/aoss-sdk

> 标签: PHP

## 简介

AOSS is a private platform support OSS upload,ExcelToJson,Image canvas,Gen Wechat code,Gen qrcode,Gen barcode

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
