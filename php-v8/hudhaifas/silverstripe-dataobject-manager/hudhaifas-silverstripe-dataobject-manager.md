# hudhaifas/silverstripe-dataobject-manager

> 标签: dataobject, page, silverstripe

## 简介

Wrap any Silverstripe DataObject in a page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
