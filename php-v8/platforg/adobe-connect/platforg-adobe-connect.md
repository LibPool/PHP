# platforg/adobe-connect

> 标签: AdobeConnect, adobe, api, connect, php

## 简介

Provides a PHP Client to interact with the Adobe Connect's API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
