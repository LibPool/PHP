# beemlabs/beem-symfony

> 标签: apm, beem, errors, monitoring, symfony, tracing

## 简介

Symfony bundle for the Beem SDK — auto-traces HTTP, Doctrine, Console, Messenger.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
