# zjkal/time-helper

> 标签: date, datetime, helper, php, time, zjkal

## 简介

一个简单快捷的PHP日期时间助手类库。 a smart PHP datetime helper library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
