# estasi/validator

> 标签: PSR-4, estasi, psr, psr-12, validator

## 简介

Validation classes for data validation, and the ability to link validators to create complex validation chains

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
