# dkvhin/nova-settings

> 标签: laravel, nova

## 简介

A Laravel Nova tool for editing custom settings using native Nova fields. This is a forked from optimistdigital/nova-settings

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
