# meirdick/laravel-cf-workersai

> 标签: ai, ai-gateway, cloudflare, embeddings, laravel, laravel-ai, llm, reasoning, workers-ai

## 简介

Cloudflare Workers AI provider for the Laravel AI SDK, with AI Gateway routing, reasoning-effort control and non-answer detection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
