# metasyntactical/psr-cache

> 标签: PHP

## 简介

Additional implementation for PSR-6 Cache providing AwareInterfaces (similar to PSR-3 LoggerAware) and NullCache Implementation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
