> 标签: database, easy-model, laravel, mariadb, mssql, mysql, orm, pdo, pgsql, postgresql, queryobject, sql, sqlite, sqlserver

## 简介

A Laravel package for enjoyably managing database queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
