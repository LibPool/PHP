# bitdreamit/laravel-mikopbx

> 标签: ARI, ami, asterisk, auto-dialer, call-center, crm, laravel, mikopbx, pbx, voip

## 简介

The most complete Laravel package for MikoPBX — CRM-ready call center with auto dialer, campaigns, live agent panel, web softphone, IVR builder, analytics, recordings, blacklist, callbacks & more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
