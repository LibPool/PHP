# logscope/logscope

> 标签: debugging, laravel, log-viewer, logs, monitoring

## 简介

View, search, filter, and correlate Laravel application logs through a web UI and JSON API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
