# microtec/cakephp-firebird-utility

> 标签: cakephp, database, driver, firebird

## 简介

CakePHP 3 Driver for Firebird Database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
