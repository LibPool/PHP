# oire/app-attest

> 标签: app-attest, apple, assertion, attestation, devicecheck, ios, security

## 简介

Verify Apple App Attest attestations and assertions in PHP: certificate chain, nonce, key id, counter. Stateless, no I/O.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
