# svenjuergens/miniredirect

> 标签: PHP

## 简介

A url with uppercase letters or umlauts is forwarded to the lowercase URL with ae, oe, ue, ss replacements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
