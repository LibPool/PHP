# svenjuergens/t3-mcp-addons

> 标签: ai, mcp, typo3, workspaces

## 简介

Additional tools for the TYPO3 MCP server (hn/typo3-mcp-server): workspace preview links and workspace publishing, plus a command for repeated scheduled publishing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
