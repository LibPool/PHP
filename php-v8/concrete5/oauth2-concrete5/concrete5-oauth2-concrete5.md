# concrete5/oauth2-concrete5

> 标签: PHP

## 简介

concrete5 OAuth2 Client Provider for PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
