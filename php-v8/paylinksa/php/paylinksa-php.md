# paylinksa/php

> 标签: api, integration, package, paylink, payment, payment gateway, php, sdk

## 简介

PHP package for integrating with Paylink payment gateway services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
