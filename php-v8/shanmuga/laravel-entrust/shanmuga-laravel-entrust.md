# shanmuga/laravel-entrust

> 标签: acl, authorization, entrust, laravel, laravel-entrust, permissions, php, roles

## 简介

This package provides a flexible solution to add ACL to Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
