# lambry/scafall

> 标签: plugin, wordpress

## 简介

WordPress plugin to help scaffold post types, taxonomies, user roles, options, meta boxes, rest endpoints and frontend routes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
