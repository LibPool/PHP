# nomadicjosh/vihzhuo

> 标签: beaver-builder, divi, elementor, pagebuilder, php-pagebuilder, phppagebuilder, vihzhuo

## 简介

A drag and drop pagebuilder to manage pages in any PHP project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
