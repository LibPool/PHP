# pteal79/nfc

> 标签: laravel, mobile, nativephp, ndef, nfc, supernative

## 简介

NativePHP Mobile v4 plugin for writing and reading NFC tags on iOS and Android

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
