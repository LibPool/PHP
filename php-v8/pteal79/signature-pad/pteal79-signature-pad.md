# pteal79/signature-pad

> 标签: PHP

## 简介

Freehand signature pad EDGE element (<native:signature-pad>) for NativePHP Mobile, SwiftUI and Jetpack Compose

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
