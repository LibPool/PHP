# pteal79/geo-map

> 标签: geofence, map, mapkit, maplibre, mobile, nativephp

## 简介

A native map for NativePHP Mobile with coloured markers and shaded circles sized in metres (e.g. geofences). MapKit on iOS, MapLibre on Android, no API keys.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
