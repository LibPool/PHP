# pteal79/otp-code

> 标签: PHP

## 简介

One-time code input EDGE element (<native:otp-code>) for NativePHP Mobile: one box per digit, SwiftUI and Jetpack Compose

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
