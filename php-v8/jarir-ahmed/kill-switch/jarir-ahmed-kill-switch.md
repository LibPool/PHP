# jarir-ahmed/kill-switch

> 标签: PHP

## 简介

A framework-agnostic PHP kill-switch package using PSR-15 middleware. Returns a maintenance page when enabled.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
