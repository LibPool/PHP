# jarir-ahmed/auth-token-maker

> 标签: auth, random, security, token

## 简介

Generate cryptographically secure, fixed-length auth tokens (hex) of any length.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
