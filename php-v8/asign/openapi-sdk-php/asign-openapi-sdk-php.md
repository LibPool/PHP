# asign/openapi-sdk-php

> 标签: asign, openapi, sdk, 电子合同, 电子签名, 电子签章

## 简介

爱签（AiSign）电子签约开放平台 PHP SDK - 模块化、结构清晰的 API 封装类库

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
