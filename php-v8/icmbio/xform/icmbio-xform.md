# icmbio/xform

> 标签: Forms, XForm, data-collection, icmbio, survey, xml

## 简介

Biblioteca PHP para processamento e manipulação de XForms do ICMBio

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
