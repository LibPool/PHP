# borschphp/borsch-skeleton

> 标签: Skeleton, borsch, framework, middleware, psr, psr-15, psr-7

## 简介

A Borsch Framework skeleton application to kick start development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
