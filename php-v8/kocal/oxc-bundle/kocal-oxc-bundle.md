# kocal/oxc-bundle

> 标签: bundle, format, lint, oxc, oxfmt, oxlint, symfony

## 简介

A Symfony Bundle to easily download tools from the JavaScript Oxidation Compiler (Oxc).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
