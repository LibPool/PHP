# validaide/googlemapbundle

> 标签: google, map, validaide

## 简介

Symfony Bundle for Google Map API v3 integration - PHP >= 8.1 Symfony = 4.4

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
