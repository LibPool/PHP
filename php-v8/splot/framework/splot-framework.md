# splot/framework

> 标签: dependency injection, di, event, fast, lightweight, mvc, rapid, web

## 简介

Splot Framework. Lightweight, fully featured framework for rapid web development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
