# aljerom/symfony-boilerplate

> 标签: PHP

## 简介

Symfony DDD/CQRS project boilerplate — buses, domain events, request resolver, HTTP/console subscribers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
