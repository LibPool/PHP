# heiner/agent-graph

> 标签: Agent, agent-graph, ai, checkpoint, graph, laravel, laravel-ai, memory, workflow

## 简介

Durable agent graph runtime for Laravel AI SDK agents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
