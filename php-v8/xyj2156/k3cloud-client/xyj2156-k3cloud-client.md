# xyj2156/k3cloud-client

> 标签: ERP, K3cloud, client, k3 cloud, kingdee, sdk, webapi, 二次开发, 云星空, 星空, 金蝶, 金蝶云星空

## 简介

面向金蝶云星空（K/3 Cloud）WebAPI 的非官方、独立编写 PHP 客户端；同时支持第三方应用签名鉴权（X-Kd / X-Api HMAC）与经典用户名/密码会话登录。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
