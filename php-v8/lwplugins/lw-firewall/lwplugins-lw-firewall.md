# lwplugins/lw-firewall

> 标签: PHP

## 简介

Lightweight firewall — rate-limits endpoints, blocks bots, bans repeat offenders, and adds security headers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
