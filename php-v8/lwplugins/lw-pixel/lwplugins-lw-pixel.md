# lwplugins/lw-pixel

> 标签: PHP

## 简介

Lightweight tracking pixel manager for WordPress: ChatGPT Ads, Meta, GA4, Google Ads, GTM, TikTok, Pinterest, Bing, Reddit, Snapchat, X and Barion, with server-side conversions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
