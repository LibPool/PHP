# originalmind/apiauth

> 标签: authorization, filter, laravel, oauth

## 简介

Laravel filters to implement common API authorisation tasks using OAuth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
