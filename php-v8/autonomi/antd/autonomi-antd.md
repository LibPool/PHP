# autonomi/antd

> 标签: antd, autonomi, client, decentralized, sdk, storage

## 简介

PHP SDK for the antd daemon — the gateway to the Autonomi decentralized network.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
