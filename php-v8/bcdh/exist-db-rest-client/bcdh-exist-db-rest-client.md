# bcdh/exist-db-rest-client

> 标签: eXist-db, laravel, php, rest, xquery, xslt

## 简介

A Laravel client for querying and transforming results from eXist-db via the REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
