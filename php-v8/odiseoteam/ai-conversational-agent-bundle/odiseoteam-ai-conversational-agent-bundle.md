# odiseoteam/ai-conversational-agent-bundle

> 标签: Agent, ai, anthropic, chat, claude, llm, symfony, symfony-bundle

## 简介

Vertical-agnostic core for conversational agents: capabilities, turn loop, gates, sessions, streaming and evals.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
