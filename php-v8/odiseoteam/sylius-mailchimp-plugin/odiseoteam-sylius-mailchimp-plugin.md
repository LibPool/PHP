# odiseoteam/sylius-mailchimp-plugin

> 标签: sylius, sylius-mailchimp, sylius-plugin

## 简介

Plugin for Sylius to add Mailchimp ecommerce features

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
