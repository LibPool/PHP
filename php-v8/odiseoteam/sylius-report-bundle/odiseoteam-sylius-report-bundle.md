# odiseoteam/sylius-report-bundle

> 标签: ecommerce, report, shop, sylius, webshop

## 简介

Flexible report system for Symfony2 ecommerce applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
