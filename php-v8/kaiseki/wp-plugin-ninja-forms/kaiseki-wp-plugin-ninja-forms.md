# kaiseki/wp-plugin-ninja-forms

> 标签: PHP

## 简介

WordPress helpers for the Ninja Forms plugin: register field template paths and remove the append-a-form metabox in the block editor

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
