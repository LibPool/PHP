# kaiseki/wp-reusable-blocks-admin-menu

> 标签: PHP

## 简介

Add a Reusable Blocks (wp_block) item to the WordPress admin menu via a kaiseki/wp-hook provider

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
