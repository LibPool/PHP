# kaiseki/wp-acf

> 标签: PHP

## 简介

Advanced Custom Fields (ACF) helpers for WordPress: local JSON sync, a Google Maps API key provider, and a WP-CLI field-group sync command

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
