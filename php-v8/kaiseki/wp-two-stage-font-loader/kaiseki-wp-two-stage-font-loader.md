# kaiseki/wp-two-stage-font-loader

> 标签: PHP

## 简介

Two-stage web font loading for WordPress: render @font-face CSS and preload links, toggling stage classes as fonts load

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
