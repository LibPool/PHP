# kaiseki/wp-menu-quick-search-title-only

> 标签: module, wordpress

## 简介

Restrict the WordPress admin menu quick-search to title-only matching, with configurable post types and result count

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
