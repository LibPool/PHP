# kaiseki/wp-plugin-ninja-forms-user-management

> 标签: PHP

## 简介

WordPress helper for the Ninja Forms User Management plugin: filter the registered user settings via container config

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
