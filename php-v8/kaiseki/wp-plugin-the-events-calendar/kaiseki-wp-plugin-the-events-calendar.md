# kaiseki/wp-plugin-the-events-calendar

> 标签: PHP

## 简介

WordPress helpers for The Events Calendar plugin: event/venue/organizer entity utilities, default-template and option filters

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
