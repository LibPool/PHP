# pkjinwo/vecdb

> 标签: ann, embedding, ffi, libjinwo, similarity-search, vector-db

## 简介

PHP binding (FFI) for JinWo VecDB — embedded vector database backed by libjinwo

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
