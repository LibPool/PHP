# wapplersystems/fe-registration

> 标签: TYPO3 CMS, double-opt-in, extension, fe_users, form, frontend-user, registration, typo3

## 简介

Frontend user registration for TYPO3 based on EXT:form with double opt-in confirmation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
