# wapplersystems/ws-components

> 标签: components, javascript, modular, scss, typo3

## 简介

Modular SCSS and JS component loader for TYPO3 — extensions request a key, the active site package maps it to files, scss is compiled per key, js is enqueued via AssetCollector.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
