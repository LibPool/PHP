# wapplersystems/t3-pricing

> 标签: comparison matrix, plans, price table, pricing, typo3

## 简介

Pricing tables for TYPO3 — plan cards, comparison table and compact rows from one data model. Any features in groups, prices per currency, net or gross, highlighted plan and optional select link.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
