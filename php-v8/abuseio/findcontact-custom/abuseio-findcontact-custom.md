# abuseio/findcontact-custom

> 标签: abuseio, custom, findcontact, laravel

## 简介

AbuseIO module for custom lookups to backend systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
