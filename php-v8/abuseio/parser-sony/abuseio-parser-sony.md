# abuseio/parser-sony

> 标签: abuseio, laravel, parser, sony

## 简介

Parser addon for handling notifications from no-reply@snei.sony.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
