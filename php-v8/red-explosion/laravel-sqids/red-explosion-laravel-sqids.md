# red-explosion/laravel-sqids

> 标签: laravel, laravel-sqids, red-explosion

## 简介

Easily generate Stripe/YouTube looking IDs for your Laravel models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
