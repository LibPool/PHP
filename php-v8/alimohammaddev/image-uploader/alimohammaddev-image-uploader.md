# alimohammaddev/image-uploader

> 标签: PHP

## 简介

A Laravel-ready image uploader package that supports validation, MIME filtering, and safe unique naming for uploaded files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
