# lucajackal85/pii-sanitizer-symfony

> 标签: bundle, gdpr, logging, monolog, pii, redaction, symfony

## 简介

Symfony bundle that scrubs PII and secrets from Monolog records via the local PII Sanitizer Engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
