# lucajackal85/pii-sanitizer-php

> 标签: gdpr, logging, monolog, pii, redaction

## 简介

Monolog processor and Unix-socket client that scrub PII and secrets via the local PII Sanitizer Engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
