# projectsaturnstudios/rocketship

> 标签: epoll, frankenphp, kqueue, laravel, native, octane, roadrunner, swoole

## 简介

Drop-in replacement for Laravel Octane, with a native server on epoll/kqueue: no Swoole, no Go binary.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
