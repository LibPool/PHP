# projectsaturnstudios/forte

> 标签: WebSockets, epoll, kqueue, laravel, pusher, reverb

## 简介

Drop-in replacement for Laravel Reverb on an epoll/kqueue event loop.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
