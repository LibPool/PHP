# projectsaturnstudios/starlight-inertia

> 标签: docs, inertia, laravel, starlight, theme, vue

## 简介

A Starlight-shaped documentation theme for Laravel + Inertia (Vue): tokens, chrome, markdown styling and the markdown renderer that matches it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
