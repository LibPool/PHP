# neurony/laravel-url

> 标签: custom, eloquent, laravel, url

## 简介

Generate custom URLs for any Eloquent model (Laravel 5.7 and up).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
