# uniquelibs/ember-data-serializer-bundle

> 标签: api, ember, rest

## 简介

A powerful symfony bundle to create secure and flexible ember data rest apis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
