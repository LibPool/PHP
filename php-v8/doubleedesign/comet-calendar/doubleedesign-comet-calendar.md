# doubleedesign/comet-calendar

> 标签: PHP

## 简介

WordPress plugin for centrally managing events and displaying them using Comet Components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://cometcomponents.io
- 源码仓库：https://github.com/doubleedesign/comet-calendar.git
- Packagist 页面：https://packagist.org/packages/doubleedesign%2Fcomet-calendar

## 历史版本号

- 当前版本：0.5.0

- 0.5.0

## 获取地址

- Composer 安装：`composer require doubleedesign/comet-calendar`
- Packagist 仓库：https://repo.packagist.org/p2/doubleedesign/comet-calendar.json
- PHP 要求：>=8.4
