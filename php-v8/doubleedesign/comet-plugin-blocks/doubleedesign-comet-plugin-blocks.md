# doubleedesign/comet-plugin-blocks

> 标签: PHP

## 简介

WordPress plugin implementing the Comet Components library and associated block editor customisations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://cometcomponents.io
- 源码仓库：https://github.com/doubleedesign/comet-plugin-blocks.git
- Packagist 页面：https://packagist.org/packages/doubleedesign%2Fcomet-plugin-blocks
