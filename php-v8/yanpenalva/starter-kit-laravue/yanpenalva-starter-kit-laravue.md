# yanpenalva/starter-kit-laravue

> 标签: boilerplate, laravel, quasar, starter, vite, vue

## 简介

Starter kit with Laravel , Vue 3, Quasar, Vite and Docker support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
