# openpolitics/twfyapi

> 标签: api, openaustralia, php, theyworkforyou

## 简介

PHP wrappers for the TheyWorkForYou.com and OpenAustralia.org.au APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
