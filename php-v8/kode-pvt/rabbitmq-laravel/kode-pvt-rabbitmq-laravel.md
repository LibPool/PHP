# kode-pvt/rabbitmq-laravel

> 标签: AMQP, laravel, messaging, queue, rabbitmq

## 简介

A lightweight RabbitMQ integration package for Laravel 12.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
