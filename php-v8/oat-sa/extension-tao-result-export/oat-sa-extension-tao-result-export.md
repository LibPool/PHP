# oat-sa/extension-tao-result-export

> 标签: OAT, QTI, TAO, computer-based-assessment, delivery, export, results

## 简介

Extension providing tools to export results.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
