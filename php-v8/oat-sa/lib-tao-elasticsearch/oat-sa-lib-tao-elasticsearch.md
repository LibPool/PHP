# oat-sa/lib-tao-elasticsearch

> 标签: OAT, TAO, elastic, elasticsearch, search

## 简介

Library to search in Tao using Elasticsearch

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
