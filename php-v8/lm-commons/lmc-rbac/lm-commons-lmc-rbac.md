# lm-commons/lmc-rbac

> 标签: laminas, module, permissions, rbac

## 简介

Authorization services to implement Role-based Access Control based on Laminas\Permissions\Rbac

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
