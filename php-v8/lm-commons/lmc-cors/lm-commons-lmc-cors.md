# lm-commons/lmc-cors

> 标签: Laminas mvc, cors, cross origin sharing resource, laminas, rest

## 简介

Laminas MVC module that let you deal with CORS requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
