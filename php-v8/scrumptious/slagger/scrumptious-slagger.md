# scrumptious/slagger

> 标签: documentation, json, middleware, slim, swagger

## 简介

Slim middleware for generating Swagger json for use with Swagger UI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
