# knppy/ui

> 标签: Knppy, alpinejs, blade, components, laravel, shadcn, tailwindcss, ui

## 简介

Knppy UI is a robust Shadcn/ui port for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
