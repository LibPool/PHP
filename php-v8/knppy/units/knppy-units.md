# knppy/units

> 标签: Knppy, units

## 简介

PHP library to make working with units safer, easier, and fun!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/knppy/units
- 源码仓库：https://github.com/Knppy/units.git
- Packagist 页面：https://packagist.org/packages/knppy%2Funits
