# donatj/phpuseragentparser

> 标签: browser, browser detection, parser, user agent, useragent

## 简介

Lightning fast, minimalist PHP UserAgent string parser.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
