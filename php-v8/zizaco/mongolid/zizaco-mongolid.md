# zizaco/mongolid

> 标签: Active Record, laravel, mongo, mongodb, nosql, odm

## 简介

Easy, powerful and ultrafast ODM for PHP and MongoDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
