# zizaco/mongolid-laravel

> 标签: illuminate, laravel, mongodb, nosql, odm

## 简介

Easy, powerful and ultrafast MongoDB ODM for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
