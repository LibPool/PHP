# xwp/custom-xml-sitemap

> 标签: Sitemap, seo, taxonomy, wordpress, xml-sitemap

## 简介

Custom taxonomy-based XML sitemap generator for WordPress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
