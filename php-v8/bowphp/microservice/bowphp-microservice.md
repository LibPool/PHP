# bowphp/microservice

> 标签: PHP

## 简介

NestJS-style multi-transport microservice layer for BowPHP (TCP, Redis, RabbitMQ, Kafka, gRPC).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
