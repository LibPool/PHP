# maeandrew/laya-laravel

> 标签: ai, classification, decisions, laravel, laya, system-one

## 简介

Laya as a first-class classification provider for laravel/ai: typed choice, score and yes/no decisions from a self-hosted, multilingual System 1 model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
