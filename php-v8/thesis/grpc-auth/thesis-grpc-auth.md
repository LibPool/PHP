# thesis/grpc-auth

> 标签: PHP

## 简介

Authentication interceptors for thesis/grpc: pluggable per-call credentials on the client, request verification on the server, unary & stream.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
