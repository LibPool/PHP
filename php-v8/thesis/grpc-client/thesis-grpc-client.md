# thesis/grpc-client

> 标签: PHP

## 简介

Async gRPC client for PHP with HTTP/2 transport, streaming RPCs, interceptors, TLS/mTLS, and client-side load balancing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
