# thesis/grpc-protocol

> 标签: PHP

## 简介

Shared gRPC protocol runtime for PHP: framing, metadata, status/error model, and encoding/compression primitives used by client and server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
