# thesis/grpc-server

> 标签: PHP

## 简介

Async gRPC server for PHP with HTTP/2 transport, unary and streaming RPC handlers, interceptors, and graceful shutdown.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
