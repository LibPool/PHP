# thesis/opentelemetry-grpc-transport

> 标签: PHP

## 简介

Pure-PHP gRPC transport for OpenTelemetry over thesis/grpc, no ext-grpc required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
