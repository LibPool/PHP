# devnullsoftware/api-generator

> 标签: PHP

## 简介

Easily and quickly generate APIs. Documents and api user interface is automatically generated at /apis route.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
