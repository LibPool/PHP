# appwrite/appwrite

> 标签: PHP

## 简介

Appwrite is an open-source self-hosted backend server that abstracts and simplifies complex and repetitive development tasks behind a very simple REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
