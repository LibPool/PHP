# angelov/phpunit-php-vcr

> 标签: php-vcr, phpunit, testing, tests, unit, vcr

## 简介

A library that allows you to easily use the PHP-VCR library in your PHPUnit tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
