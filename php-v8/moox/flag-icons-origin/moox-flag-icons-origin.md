# moox/flag-icons-origin

> 标签: Flag Icons Origin, blade, laravel

## 简介

A package to easily make use of Flag Icons Origin in your Laravel Blade views.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
