# moox/skeleton

> 标签: MOOX, Moox package, filament, laravel, laravel package

## 简介

This template is used for generating Laravel packages, all Moox packages are built with this template.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
