# cjuol/statguard

> 标签: comparative-stats, csv-export, data-analysis, data-integrity, outliers, php, robust-statistics, statguard, statistics

## 简介

Suite de estadística avanzada para PHP: cálculos robustos (IQR, S*, MAD) vs clásicos, detección de sesgos y exportación CSV/JSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
