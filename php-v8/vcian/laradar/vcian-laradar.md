# vcian/laradar

> 标签: ai, architecture, code-analysis, dashboard, discovery, documentation, laradar, laravel, visualization

## 简介

Automatically discover, visualize, and document Laravel application architecture with an interactive dashboard, HTML/JSON/Markdown reports, and AI-powered insights.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
