# manoakys/nusoap-bundle

> 标签: manoakys, noiselabs, soap, symfony

## 简介

Symfony2/3 bundle for NuSOAP - SOAP Toolkit for PHP with PHP 7 support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
