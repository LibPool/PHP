# ether/bookings

> 标签: Craft, bookings, cms, craft-plugin, craftcms, events

## 简介

An advanced booking plugin for Craft CMS and Craft Commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
