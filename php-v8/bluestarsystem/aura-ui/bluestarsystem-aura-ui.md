# bluestarsystem/aura-ui

> 标签: alpine, components, laravel, livewire, tailwind, ui

## 简介

Vibrant Depth UI component library for Laravel + Livewire + Alpine.js + Tailwind CSS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
