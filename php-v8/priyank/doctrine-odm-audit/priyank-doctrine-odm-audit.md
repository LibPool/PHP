# priyank/doctrine-odm-audit

> 标签: Audit, doctrine, odm

## 简介

To Store New/old value as audit in database on flush event of ODM Doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
