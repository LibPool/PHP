# kravcik/latte-font-awesome-icon

> 标签: font awesome, latte, macro, nette

## 简介

Simple {icon} macro for Latte, which allow short entry of font-awesome icons.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
