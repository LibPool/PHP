# botdigit/cryptogateway

> 标签: USDT, bitcoin, blockchain, bnb, composer-package, crypto-payments, cryptocurrency, erc20, ethereum, laravel, litecoin, payment-gateway, solana, trc20, tron, web3-laravel

## 简介

An open-source all-in-one cryptocurrency payment gateway package for Laravel supporting BTC, ETH, TRX, SOL, LTC, BNB, USDT, and USDC.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
