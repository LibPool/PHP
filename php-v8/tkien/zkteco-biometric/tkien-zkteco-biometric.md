# tkien/zkteco-biometric

> 标签: Fingerprint, attendance, biometric, device, laravel, zkteco

## 简介

Laravel package for ZKTeco biometric device integration with attendance management

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
