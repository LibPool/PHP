# gooby/laravel-debugbar-dd

> 标签: bd, dd, debugbar, laravel

## 简介

Ever wanted to dd() and see the debugbar? This package does just that by calling bd() - Bar Dump.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
