# pinkary-project/type-guard

> 标签: assert, narrow, php, pinkary-project, type, type-guard

## 简介

Type Guard module is part of the Gloss PHP, and allows you to narrow down the type of an variable to a more specific type.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
