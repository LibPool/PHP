# zendsms/laravel

> 标签: bangladesh, laravel, notification, otp, sms, zendsms

## 简介

Official Laravel package for the Zend SMS API — send SMS, OTP, check balance & DLR.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
