# pivvenit/acf-pro-installer

> 标签: acf, composer, env, plugin, pro, wordpress, wp

## 简介

A modern maintained install helper for Advanced Custom Fields PRO

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
