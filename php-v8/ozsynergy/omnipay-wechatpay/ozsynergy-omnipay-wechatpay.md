# ozsynergy/omnipay-wechatpay

> 标签: app, gateway, omnipay, pay, payment, php, purchase, sdk, wechat, 微信支付

## 简介

Wechat gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
