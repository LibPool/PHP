# fireless/php-pushwoosh

> 标签: fireless, push, pushwoosh

## 简介

A PHP Library to easily work with the Pushwoosh REST Web Services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
