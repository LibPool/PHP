# power/bitcoin

> 标签: PHP

## 简介

PHP Bitcoin library with functions for transactions, signatures, serialization, Random/Deterministic ECDSA keys, blocks, RPC bindings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
