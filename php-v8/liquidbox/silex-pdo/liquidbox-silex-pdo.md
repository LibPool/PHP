# liquidbox/silex-pdo

> 标签: database, mysql, odbc, pdo, php, postgresql, provider, service, silex, sqlite

## 简介

A PDO service provider for the Silex micro-framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
