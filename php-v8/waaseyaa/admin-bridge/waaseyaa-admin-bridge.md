# waaseyaa/admin-bridge

> 标签: PHP

## 简介

[DEPRECATED] PHP bridge for mounting the Waaseyaa Admin SPA. Use waaseyaa/admin-surface instead.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
