# waaseyaa/anokii

> 标签: PHP

## 简介

Anokii, the first opinionated distribution built on Waaseyaa. Sovereign workspace for First Nations. OCAP-by-architecture. Working name pending language-keeper verification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
