# phpolar/csrf-protection

> 标签: csrf, middleware, psr-15, psr-7, request handlers

## 简介

Provides request checking and response filtering to mitigate CSRF attacks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
