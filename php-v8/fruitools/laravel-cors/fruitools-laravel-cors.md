# fruitools/laravel-cors

> 标签: PHP

## 简介

Adds CORS (Cross-Origin Resource Sharing) headers support in your Laravel application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
