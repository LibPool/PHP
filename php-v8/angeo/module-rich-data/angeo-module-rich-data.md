# angeo/module-rich-data

> 标签: JSON-LD, ProductGroup, aeo, ai visibility, angeo, chatgpt shopping, magento2, rich data, schema.org, structured data

## 简介

Magento 2 JSON-LD Rich Data for AI Engine Optimization. Emits a linked @graph with Product, ProductGroup variants, Organization, BreadcrumbList, CollectionPage, FAQPage and WebSite schema. Fixes the 'Product schema — JSON-LD structured data' signal in angeo/module-aeo-audit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
