# angeo/module-webmcp

> 标签: WebMCP, adobe-commerce, aeo, agentic-commerce, ai-agents, chrome, hyva, magento2, mcp, model-context-protocol

## 简介

WebMCP for Magento 2 — registers structured tools (product search, product details, add to cart, view cart, go to checkout) in the shopper's browser, so in-browser AI agents act on your store through named functions instead of clicking through pages. Works with Luma and Hyvä.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
