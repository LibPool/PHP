# angeo/module-agent-activity

> 标签: WebMCP, aeo, agentic-commerce, ai-agents, ai-crawlers, analytics, magento2, mcp, ucp

## 简介

See what AI agents do in your Magento 2 store: UCP, MCP and WebMCP calls, AI crawler and agent page visits, agent-built orders and revenue. Admin report with charts, event log grid, CSV and CLI reports, bot IP verification. No IP addresses stored.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
