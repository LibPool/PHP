# angeo/module-robots-txt-aeo

> 标签: ChatGpt, aeo, aeo audit, ai crawlers, ai engine optimization, ai search, ai visibility, amazonbot, angeo, applebot, bot verification, claudebot, content signals, google-extended, gptbot, magento 2 module, magento2, meta-externalagent, oai-searchbot, perplexitybot, rfc 9421, robots.txt, rsl, web bot auth

## 简介

Magento 2 module for AI Engine Optimization (AEO). Manages AI crawler rules in robots.txt (OAI-SearchBot, GPTBot, ChatGPT-User, PerplexityBot, Google-Extended, ClaudeBot, Claude-SearchBot, Applebot-Extended, CCBot and more) without overwriting your existing configuration, emits IETF Content-Usage, Cloudflare Content-Signal and RSL License directives, and verifies that a crawler is genuine via Web Bot Auth request signatures (RFC 9421) or vendor-published IP ranges.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
