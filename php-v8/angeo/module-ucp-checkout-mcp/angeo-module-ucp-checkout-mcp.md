# angeo/module-ucp-checkout-mcp

> 标签: agentic-commerce, ai-agents, checkout, magento2, mcp, ucp

## 简介

UCP checkout over MCP for Magento 2: create_checkout, get_checkout, update_checkout, complete_checkout and cancel_checkout tools on the store MCP server, backed by angeo/module-ucp-checkout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
