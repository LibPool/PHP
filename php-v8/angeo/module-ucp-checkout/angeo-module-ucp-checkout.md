# angeo/module-ucp-checkout

> 标签: Gemini, adobe-commerce, agentic-commerce, ai-agents, checkout, google, magento2, ucp, universal-commerce-protocol

## 简介

UCP checkout for Magento 2 (dev.ucp.shopping.checkout + discount + fulfillment + order with webhooks, spec 2026-08-25). AI agents create, update and cancel real checkout sessions over REST and see live shipping rates; payment is handed off to the store's own checkout page via continue_url. No card data, no PCI scope.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
