# angeo/module-mcp-reorder

> 标签: adobe-commerce, agentic-commerce, ai-agents, b2b, claude, magento2, mcp, model-context-protocol, quick-order, reorder

## 简介

Signed-in customer tools for the Angeo MCP Server (Magento 2 / Adobe Commerce): an AI agent reads the buyer's own order history, reorders past orders and turns a SKU list into the buyer's own cart, at the buyer's own prices. The buyer checks out on the store. B2B-ready: quick order, repeat purchases, tier prices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
