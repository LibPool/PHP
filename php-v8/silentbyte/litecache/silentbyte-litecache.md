# silentbyte/litecache

> 标签: Opcache, cache, caching, config

## 简介

A lightweight, easy-to-use, and straightforward caching library for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
