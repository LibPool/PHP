# jvitasek/nwsltr

> 标签: Nette Framework, doctrine, mailing, newsletter, vuejs

## 简介

A ready-made self-hosted mailing system on PHP 8, Vue.js, Doctrine ORM and Nette Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
