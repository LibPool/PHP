# hfig/oauth2-http-client

> 标签: asynchronous, http-client, oauth, symfony

## 简介

An asynchronous, lightweight OAuth 2 decorator for the Symfony HTTP Client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
