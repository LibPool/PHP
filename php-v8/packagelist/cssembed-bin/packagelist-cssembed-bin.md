# packagelist/cssembed-bin

> 标签: css

## 简介

CSSEmbed packaged for composer. A small program/library to automate embedding of data URIs in CSS files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
