# nkey/caribu-mvc-bootstrap

> 标签: Addon Caribu MVC

## 简介

Bootstrap View addon for Caribu (M)VC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
