# dhavalsagepaypi/sagepay-pi

> 标签: api, opayo, opayo pi, payment, sagepay, sagepay pi

## 简介

Opayo PI (formerly SagePay PI) PHP API that uses PSR7, PSR17, PSR18 standards.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
