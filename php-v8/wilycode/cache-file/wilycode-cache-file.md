# wilycode/cache-file

> 标签: cache, file-cache, filesystem, php, psr-16, simple-cache, ttl

## 简介

Lightweight PSR-16 file cache with atomic writes and TTL support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
