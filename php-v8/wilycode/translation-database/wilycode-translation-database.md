# wilycode/translation-database

> 标签: cache, database, fallback, i18n, localization, mysql, pluralization, psr-16, translation, wilycode

## 简介

Lazy database-backed PHP translation provider with pluralization, language fallback, and optional PSR-16 caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
