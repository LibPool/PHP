# wilycode/profiler-php

> 标签: Metrics, Server-Timing, performance, php, profiler, profiling, tracing

## 简介

Framework-independent PHP profiler with aggregated metrics, traces and Server-Timing support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
