# wilycode/session-php

> 标签: namespaced session, native php session, php, session, session adapter, session interface, wilycode

## 简介

Native PHP session adapter with namespaced storage for wilycode/session.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
