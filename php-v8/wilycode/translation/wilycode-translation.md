# wilycode/translation

> 标签: formatter, i18n, l10n, locale, localization, php, pluralization, translation, wilycode

## 简介

Framework-agnostic translation contracts and configurable locale formatting for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
