# wilycode/session

> 标签: namespaced session, php, session, session contract, session interface, wilycode

## 简介

Storage-agnostic session contract with namespace-scoped key/value access for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
