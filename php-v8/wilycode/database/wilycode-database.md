# wilycode/database

> 标签: database, database-abstraction, database-driver, database-interface, php, transactions, wilycode

## 简介

Database-agnostic connection, query, and transaction contracts for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
