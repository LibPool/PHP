# wilycode/template-assets

> 标签: assets, cache-busting, css, javascript, minification, php, template, wilycode

## 简介

Page-scoped CSS and JavaScript asset collection, versioning, bundling, and minification for WilyCode Template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
