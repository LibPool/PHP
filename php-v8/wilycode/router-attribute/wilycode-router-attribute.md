# wilycode/router-attribute

> 标签: attributes, controllers, php, psr-15, psr-16, psr-7, router, routing

## 简介

PHP 8.4 attribute-based route discovery and caching for WilyCode Router.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
