# wilycode/container

> 标签: Autowiring, PSR-11, container, dependency-injection, php

## 简介

Lightweight PSR-11 dependency injection container with explicit factories and constructor autowiring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
