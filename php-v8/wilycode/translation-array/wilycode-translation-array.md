# wilycode/translation-array

> 标签: array, fallback, i18n, localization, php, pluralization, translation, wilycode

## 简介

Lazy PHP array translation provider with language fallback, pluralization, and resource mounts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
