# wilycode/database-query-executor-cache

> 标签: cache, caching, database, decorator, executor, psr-16, query, sql, transactions, wilycode

## 简介

PSR-16 caching decorator for WilyCode database query executors with transaction-aware invalidation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
