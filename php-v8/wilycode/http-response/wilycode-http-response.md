# wilycode/http-response

> 标签: http, json, php, psr-17, psr-7, redirect, response

## 简介

Typed PSR-7 response factory for HTML, JSON, redirects and empty responses.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
