# wilycode/database-driver-mysqli

> 标签: database, driver, mysql, mysqli, php, prepared-statements, query-builder, wilycode

## 简介

MySQLi database driver and canonical query binder for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
