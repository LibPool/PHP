# wilycode/database-repository

> 标签: Relationships, database, eager-loading, filtering, models, orm, pagination, php, query-builder, repository, wilycode

## 简介

Model repositories for PHP with eager loading, safe CRUD, relationship persistence, filters and pagination.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
