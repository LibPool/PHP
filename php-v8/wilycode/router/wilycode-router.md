# wilycode/router

> 标签: middleware, php, psr-15, psr-7, router, routing, url-generation

## 简介

PSR-7/PSR-15 router with named routes, typed rules, middleware and URL generation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
