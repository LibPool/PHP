# wilycode/database-query-executor

> 标签: database, executor, mysqli, pdo, query, query-builder, sql, transaction, wilycode

## 简介

Lightweight query execution layer connecting WilyCode SQL queries, binders and database drivers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
