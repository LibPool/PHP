# wilycode/database-model

> 标签: Relationships, attributes, change-tracking, database, hydration, model, orm, wilycode

## 简介

Attribute-based PHP database models with metadata, JSON hydration, relationships and change tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
