# nyco/wp-assets

> 标签: assets, configuration, css, enqueue, inline, integrations, javascript, nycopportunity, query-monitor, querymonitor, register, scripts, styles, theme, wordpress

## 简介

A developer plugin with helpers for managing assets in WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
