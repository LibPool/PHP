# kabiroman/adaptive-entity-manager

> 标签: PHP

## 简介

Adaptive Entity Manager implementing Doctrine ObjectManager for flexible entity management across multiple data sources

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
