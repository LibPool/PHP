# kabiroman/octawire-auth-service-php-client

> 标签: auth, jwt, octawire, tcp

## 简介

PHP client for Octawire Auth Service using JATP (JSON Auth Transport Protocol) over TCP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
