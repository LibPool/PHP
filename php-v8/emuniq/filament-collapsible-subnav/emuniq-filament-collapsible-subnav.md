# emuniq/filament-collapsible-subnav

> 标签: collapsible, filament, laravel, sidebar, subnavigation

## 简介

A Filament v3, v4 & v5 plugin for collapsible sub-navigation sidebar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
