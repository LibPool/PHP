# nailfor/leaflet

> 标签: extension, laravel, leaflet, maps, nailfor

## 简介

LeafLet Mobile-Friendly Interactive Maps Extension Library for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
