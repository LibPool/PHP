# kbrabrand/craft-tinymce

> 标签: cms, craftcms, html, tinymce, yii2

## 简介

Edit rich text content in Craft CMS using the TinyMCE editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
