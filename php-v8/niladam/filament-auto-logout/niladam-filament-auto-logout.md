# niladam/filament-auto-logout

> 标签: afk logout, autologout, filament auto logout, filament-auto-logout, laravel, logout if afk, logout if idle, logout on idle

## 简介

A filament plugin that auto logs out your users if they are idle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
