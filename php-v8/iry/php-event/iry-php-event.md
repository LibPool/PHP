# iry/php-event

> 标签: event, php event

## 简介

A simple php event engine to reduce the coupling between project modules.(一个简单php事件引擎，以便解耦项目中的各模块)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
