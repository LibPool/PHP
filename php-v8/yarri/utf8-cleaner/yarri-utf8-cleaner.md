# yarri/utf8-cleaner

> 标签: clean, cleaner, fix, glitch, glitches, remover, utf-8, utf8

## 简介

Removes invalid UTF-8 characters from the given text

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
