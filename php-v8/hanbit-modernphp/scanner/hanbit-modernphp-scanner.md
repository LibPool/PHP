# hanbit-modernphp/scanner

> 标签: csv, scanner, url

## 简介

URL 목록 배열을 스캔하고 접근할 수 없는 URL을 보고합니다.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
