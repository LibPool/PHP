# anorgan/qutee

> 标签: background, beanstalkd, job, mysql, queue, qutee, redis, task, worker

## 简介

Simple queue manager and task processor for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
