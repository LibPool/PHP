# ipscanner.io/sdk

> 标签: IP, agentscan, asn, bot detection, geolocation, ipscanner, proxy, vpn

## 简介

Official PHP client for the IPScanner API: IP lookups, VPN and proxy detection, bulk checks, Agentscan and provenance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
