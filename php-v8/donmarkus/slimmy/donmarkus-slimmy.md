# donmarkus/slimmy

> 标签: boilerplate, framework, laravel, slim 3, slimmy

## 简介

A Bootstrap Framework based on Slim3 and Laravel Components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
