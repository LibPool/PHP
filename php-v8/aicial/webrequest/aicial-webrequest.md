# aicial/webrequest

> 标签: file_get_contents, http, https, rest, webservice

## 简介

Web request library providing GET PUT POST HEAD Cookies and more for file_get_contents

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
