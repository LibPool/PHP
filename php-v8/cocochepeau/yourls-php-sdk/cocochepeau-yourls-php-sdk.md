# cocochepeau/yourls-php-sdk

> 标签: PHP

## 简介

A PHP SDK for interacting with the YOURLS API, enabling URL shortening, expansion, and statistics retrieval.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
