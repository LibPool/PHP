# max13/monobullet

> 标签: laravel, monolog, notification, pushbullet

## 简介

Monobullet is a Monolog handler that notifies via Pushbullet API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
