# motivo/editorjs-data-converter

> 标签: editorjs, laravel, motivo

## 简介

A package to convert JSON data that Editor.js generates back to html so it can be used.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
