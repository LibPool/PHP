# backfront/bf_wp_toolkit

> 标签: Skelleton, backfront, plugin, toolkit, umbrella, wordpress

## 简介

A toolkit plugin containing multiple shortcodes to Wordpress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
