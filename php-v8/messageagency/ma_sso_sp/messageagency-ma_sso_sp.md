# messageagency/ma_sso_sp

> 标签: Authentication, drupal, simplesamlphp

## 简介

Wrangle all the requirements to create a Drupal site as an SP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
