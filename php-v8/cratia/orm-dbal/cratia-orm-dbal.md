# cratia/orm-dbal

> 标签: PHP

## 简介

Database abstraction layer (DBAL) for execute Query based on https://www.doctrine-project.org/projects/dbal.html

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
