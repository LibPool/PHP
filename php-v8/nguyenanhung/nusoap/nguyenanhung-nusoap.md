# nguyenanhung/nusoap

> 标签: nusoap, soap

## 简介

My nuSOAP Library, fix code for for PHP 8.2 <=> 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
