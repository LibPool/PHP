# nguyenanhung/30-seconds-of-php-code

> 标签: PHP

## 简介

A curated collection of useful PHP snippets that you can understand in 30 seconds or less.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
