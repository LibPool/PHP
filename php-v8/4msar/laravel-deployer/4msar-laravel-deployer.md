# 4msar/laravel-deployer

> 标签: cli, deployer, deployment, github, laravel, releases, zero-downtime

## 简介

Zero-downtime deployment tool for Laravel applications from GitHub releases

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
