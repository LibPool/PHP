# datlechin/flarum-passkey

> 标签: Authentication, FIDO2, Passwordless, passkey, security, webauthn

## 简介

Sign in to Flarum with passkeys. Built on the W3C WebAuthn Level 3 standard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
