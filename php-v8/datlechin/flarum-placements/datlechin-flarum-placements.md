# datlechin/flarum-placements

> 标签: Advertising, ads, adsense, banner, flarum, placement, sponsor

## 简介

An ad server for Flarum: campaigns, targeting, scheduling and reporting, served from placements declared in code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
