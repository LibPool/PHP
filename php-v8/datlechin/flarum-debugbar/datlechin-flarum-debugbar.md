# datlechin/flarum-debugbar

> 标签: debug, debugbar, development, flarum, profiler

## 简介

A development debug bar for Flarum: queries, timeline, events, cache, mail and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
