# crocone/authclient-odnoklassniki

> 标签: authclient, oauth, odnoklassniki, yii2

## 简介

Odnoklassniki extenion for using via yii2-authclient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
