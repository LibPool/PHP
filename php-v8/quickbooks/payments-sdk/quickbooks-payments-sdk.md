# quickbooks/payments-sdk

> 标签: api, http, quickbooks payments, rest, smallbusiness

## 简介

The Official PHP SDK for QuickBooks Online Payments API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
