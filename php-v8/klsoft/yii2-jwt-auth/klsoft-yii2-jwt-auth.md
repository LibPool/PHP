# klsoft/yii2-jwt-auth

> 标签: Authentication, api, jwt, keycloak, yii2

## 简介

The package provides a Yii 2 authentication method based on a JWT token.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
