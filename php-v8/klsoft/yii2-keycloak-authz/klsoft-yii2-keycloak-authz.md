# klsoft/yii2-keycloak-authz

> 标签: api, authorisation, authorization, jwt, keycloak, yii2

## 简介

The package provides Keycloak authorization for the web service APIs of Yii 2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
