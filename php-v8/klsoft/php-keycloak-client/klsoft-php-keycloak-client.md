# klsoft/php-keycloak-client

> 标签: Authentication, authorisation, authorization, keycloak, oauth2

## 简介

A PHP library that can be used to secure web applications with Keycloak.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
