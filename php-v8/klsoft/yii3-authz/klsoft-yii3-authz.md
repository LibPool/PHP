# klsoft/yii3-authz

> 标签: authorisation, authorization, middleware, rbac, yii3

## 简介

The package provides Yii 3 authorization middleware that uses Yii RBAC

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
