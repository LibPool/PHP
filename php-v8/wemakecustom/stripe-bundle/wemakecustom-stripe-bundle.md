# wemakecustom/stripe-bundle

> 标签: Symfony2, bundle, stripe

## 简介

Symfony 2 StripeBundle, a wrapper for Stripe Api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
