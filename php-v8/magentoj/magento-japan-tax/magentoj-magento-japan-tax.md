# magentoj/magento-japan-tax

> 标签: PHP

## 简介

This module provides the correct tax calculation and qualified invoices as required by the Japanese Consumption Tax (JCT) law.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
