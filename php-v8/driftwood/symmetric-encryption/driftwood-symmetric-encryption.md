# driftwood/symmetric-encryption

> 标签: encryption

## 简介

PHP wrapper around the OpenSSL library providing preconfigured, binary safe, Authenticated Symmetric Encryption.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
