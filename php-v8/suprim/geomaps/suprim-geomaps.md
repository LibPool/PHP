# suprim/geomaps

> 标签: Craft, cms, craft-plugin, craftcms, geo, geocoding, geojson, google maps, leaflet, location, map, maps, proximity search

## 简介

Location fields for Craft CMS: address autocomplete, GeoJSON drawing, proximity search, static and embedded maps, GraphQL and Feed Me support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
