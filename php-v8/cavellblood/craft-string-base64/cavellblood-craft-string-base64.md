# cavellblood/craft-string-base64

> 标签: Craft, cms, craft-plugin, craftcms, decode, encode, string base64

## 简介

Twig filters to base64 encode/decode a string.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
