# capybash/magicbb

> 标签: bbcode, composer, flarum, flarum-extension, formatting, magic, toolbar

## 简介

Extra BBCodes, handy toolbar buttons, and unique text formatting for the forum composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
