# bigfork/silverstripe-oauth-login

> 标签: login, oauth, oauth2, silverstripe

## 简介

SilverStripe logins via OAuth2, using the PHP League's OAuth2 client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
