# bigfork/wp-html-sitemap

> 标签: Sitemap, html-sitemap, seo, wordpress

## 简介

Configurable HTML sitemap for WordPress, with SEO plugin aware noindex exclusion and multilingual support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
