# colorlibhq/adminlte-laravel

> 标签: AdminLTE, admin, blade, bootstrap, bootstrap5, dashboard, laravel, template, vite

## 简介

Official AdminLTE 4 integration for Laravel — Bootstrap 5.3, vanilla JS, Vite-ready.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
