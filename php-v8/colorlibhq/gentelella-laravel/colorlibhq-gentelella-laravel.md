# colorlibhq/gentelella-laravel

> 标签: admin, blade, crud, dashboard, gentelella, laravel, template, vite

## 简介

Official Gentelella v4 integration for Laravel — vanilla JS, SCSS, no Bootstrap, no jQuery, Vite-ready.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
