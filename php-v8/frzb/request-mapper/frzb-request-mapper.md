# frzb/request-mapper

> 标签: component, dependency, frzb, injection, library, mapper, request, request-mapper, serialize, serializer, symfony, validation

## 简介

The RequestMapper component allows you to serialize JSON request to Request class and validate it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
