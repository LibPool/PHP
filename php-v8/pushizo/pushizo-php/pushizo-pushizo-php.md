# pushizo/pushizo-php

> 标签: email, notifications, push, pushizo, sms, webhooks

## 简介

Pushizo PHP sunucu SDK'sı: public API'nin tamamı (bildirim, kullanıcı, segment, şablon, kampanya, analitik, veri aktarımı, webhook…)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
