# onehourtranslation/api2

> 标签: api, one hour translation, onehourtranslation, translation

## 简介

PHP client library for One Hour Translation API (version 2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.onehourtranslation.com
- 源码仓库：https://github.com/OneHourTranslation/API-2-Client-PHP.git
- Packagist 页面：https://packagist.org/packages/onehourtranslation%2Fapi2

## 获取地址

- Composer 安装：`composer require onehourtranslation/api2`
- Packagist 仓库：https://repo.packagist.org/p2/onehourtranslation/api2.json
- PHP 要求：>=5.3.0
