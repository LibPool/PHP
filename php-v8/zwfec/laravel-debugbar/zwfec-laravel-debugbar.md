# zwfec/laravel-debugbar

> 标签: debug, debugbar, laravel, profiler, webprofiler

## 简介

PHP Debugbar integration for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
