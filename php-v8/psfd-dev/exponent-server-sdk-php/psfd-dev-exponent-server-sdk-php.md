# psfd-dev/exponent-server-sdk-php

> 标签: expo, exponent, notifications, push

## 简介

Server-side library for working with Expo push notifications using PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
