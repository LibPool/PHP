# wbengine/wbengine

> 标签: framework, wbengine, webengine

## 简介

Wbengine is open source PHP Library that is easy to use for creating websites or intranet applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
