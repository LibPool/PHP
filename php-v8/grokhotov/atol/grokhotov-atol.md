# grokhotov/atol

> 标签: api, atol, online, php

## 简介

ATOL PHP API Client. Данная библиотека предназначена для работы с сервисом АТОЛ Онлайн (v5)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
