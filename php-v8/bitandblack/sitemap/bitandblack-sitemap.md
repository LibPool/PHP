# bitandblack/sitemap

> 标签: BitAndBlack, Köngeter, Sitemap, WirbelWild, crawler

## 简介

Creates a sitemap.xml by parsing the whole website.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
