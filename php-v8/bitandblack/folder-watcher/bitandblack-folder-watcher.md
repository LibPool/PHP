# bitandblack/folder-watcher

> 标签: cli, command line, directory, folder, watch

## 简介

Watches a folder and handles its files. This script is meant to run from your CLI.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
