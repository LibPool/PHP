# bitandblack/rows

> 标签: breakpoints, components, css, flexbox, gutter, responsive, scss, spaces

## 简介

A small and simple CSS gutter to create rows and cells using the flexbox model.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
