# bitandblack/idml-json-converter

> 标签: adobe, idml, indesign, indesign markup language

## 简介

Convert Adobe InDesign Markup Language Files (IDML) into JSON and JSON into IDML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
