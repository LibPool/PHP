# qdrant-labs/qdrant-laravel-scout

> 标签: Semantic Search, hybrid search, laravel, qdrant, scout, search, vector search

## 简介

A Qdrant driver for Laravel Scout with full-text, semantic, and hybrid search.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
