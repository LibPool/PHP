# 4oh3/live-files

> 标签: development, drupal, files, images, stage file proxy

## 简介

Serves images (and optionally other public files) from the live site instead of the local files directory. Intended for local development only.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
