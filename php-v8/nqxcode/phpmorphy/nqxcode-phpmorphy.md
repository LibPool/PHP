# nqxcode/phpmorphy

> 标签: php-morphy, phpmorphy

## 简介

phpMorphy - morphological analyzer library for Russisan, English and German languages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
