# ajaxray/ansikit

> 标签: PHP

## 简介

Tiny ANSI escape helper for terminal UIs (text styles, foreground & background colors, cursor positions, clearing) with table, progressbar, and more helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
