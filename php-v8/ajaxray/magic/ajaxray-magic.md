# ajaxray/magic

> 标签: dependency, dependency-injection-container, php, php-di

## 简介

Simple Auto-wiring, PSR-11 compliant Dependency injection library for PHP 8.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
