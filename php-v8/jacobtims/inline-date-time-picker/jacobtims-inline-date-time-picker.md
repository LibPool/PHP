# jacobtims/inline-date-time-picker

> 标签: Jacobtims, inline-date-time-picker, laravel

## 简介

A Filament plugin for adding inline Date-time Pickers to your Filament forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
