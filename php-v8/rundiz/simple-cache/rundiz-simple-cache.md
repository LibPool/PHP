# rundiz/simple-cache

> 标签: apc, apcu, cache, file system cache, filesystem cache, memcache, memcached, php cache

## 简介

The simple and easy PHP cache drivers for cache any PHP data type.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
