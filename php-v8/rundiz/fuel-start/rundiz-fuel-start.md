# rundiz/fuel-start

> 标签: FuelPHP ACL, FuelPHP account permission system, back office, backend, backoffice

## 简介

The backoffice system built on FuelPHP framework for developers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
