> 标签: api, laravel, php, php-stack-api, stackExchange, stackapi, stackapps

## 简介

Its a PHP SDK for StackExchange API version 2.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
