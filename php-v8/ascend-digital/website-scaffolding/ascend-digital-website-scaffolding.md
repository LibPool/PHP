# ascend-digital/website-scaffolding

> 标签: laravel mix, website scaffolding, wordpress

## 简介

A useful, secure folder structure and project set-up for using Laravel Mix to help develop websites with, which aren't built on the Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
