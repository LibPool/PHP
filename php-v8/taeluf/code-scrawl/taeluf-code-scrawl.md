# taeluf/code-scrawl

> 标签: PHP

## 简介

A documentation generation framework with some built-in extensions for exporting comments and code, and importing into markdown.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
