# murderxchip/trace

> 标签: PHP

## 简介

基于HTTP的链路日志跟踪Laravel/Lumen插件，A trace logger SDK for http request between Laravel/Lumen apps by supplying enhanced GuzzleClient implementation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
