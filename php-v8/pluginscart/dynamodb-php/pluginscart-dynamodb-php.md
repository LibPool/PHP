# pluginscart/dynamodb-php

> 标签: aws, dynamodb, dynamodb php

## 简介

Access AWS DynamoDB through simpler interface in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
