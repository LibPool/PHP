# zouloux/bowl

> 标签: acf, bedrock, bowl, cms, composer, plugin, wordplate, wordpress

## 简介

Advanced CMS fields workflow on top of Wordplate for Wordpress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
