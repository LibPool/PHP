# justinvoelker/yii2-separatedpager

> 标签: linkpager, pagination, yii2

## 简介

A Yii2 LinkPager that displays the first and last pages inline with other pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
