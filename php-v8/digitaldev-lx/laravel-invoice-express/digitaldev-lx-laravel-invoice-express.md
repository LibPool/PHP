# digitaldev-lx/laravel-invoice-express

> 标签: Saft, digitaldev, faturação, invoiceexpress, invoicexpress, invoicing, laravel, portugal

## 简介

A Laravel package for integrating with the InvoiceXpress API V2 (Portuguese invoicing).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
