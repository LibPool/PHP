# mcguffin/wp-dashboard-messages

> 标签: messages, plugin, wordpress, wp-admin

## 简介

Show Messages on the WP Admin Dashboard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
