> 标签: PHPStan, agent-skills, ai-agents, assertions, blade, claude-code, css-selector, dom, dom-crawler, html, laravel, laravel-boost, livewire, pest, phpstan-extension, phpunit, rector, symfony, tailwind, testing, typo3

## 简介

HTML assertions for PHPUnit and Pest: check rendered HTML with CSS selectors, never as a string. With PHPStan rules, a Rector rule and a skill for AI coding agents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
