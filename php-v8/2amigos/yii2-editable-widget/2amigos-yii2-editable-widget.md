# 2amigos/yii2-editable-widget

> 标签: 2amigos, extension, widget, x-editable, yii, yii 2, yii2

## 简介

X-Editable widget for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
