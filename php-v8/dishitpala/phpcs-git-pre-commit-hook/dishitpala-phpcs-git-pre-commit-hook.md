# dishitpala/phpcs-git-pre-commit-hook

> 标签: PHP

## 简介

A boilerplate for any git WordPress project where coding standards are mandatory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
