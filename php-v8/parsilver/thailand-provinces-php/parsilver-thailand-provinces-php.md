# parsilver/thailand-provinces-php

> 标签: address, district, dopa, iso-3166-2, laravel, postal-code, province, subdistrict, thailand, validation

## 简介

Thai provinces, districts and subdistricts with postal codes and ISO 3166-2 codes, from official sources. Plain PHP, with first-class Laravel support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
