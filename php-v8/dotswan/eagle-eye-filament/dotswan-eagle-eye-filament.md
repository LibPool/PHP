# dotswan/eagle-eye-filament

> 标签: Audit, activity-log, dotswan, eagle-eye, filament, filament-plugin, filament-v5, laravel, observability

## 简介

Filament 5 admin UI for dotswan/eagle-eye: activity explorer, trace timeline, overview dashboard and audit history, read through the driver-agnostic repository.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
