# kore-ui/kore-ui

> 标签: components, laravel, livewire, modal, overlay, tailwind, ui

## 简介

A modern UI component library for Laravel with Livewire 4, Tailwind CSS v4, and Alpine.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
