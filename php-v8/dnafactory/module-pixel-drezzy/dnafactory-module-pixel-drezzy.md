# dnafactory/module-pixel-drezzy

> 标签: drezzy, magento 2, pixel

## 简介

A simple module to add Drezzy's Pixel to Magento 2 checkout

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
