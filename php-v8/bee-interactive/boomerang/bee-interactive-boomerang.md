# bee-interactive/boomerang

> 标签: boomerang, errors, exceptions, laravel, monitoring

## 简介

Boomerang notifier for the Laravel PHP framework. Monitor and report Laravel errors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
