# itmages/yii-eauth

> 标签: PHP

## 简介

EAuth extension allows to authenticate users by the OpenID, OAuth 1.0 and OAuth 2.0 providers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
