# zoparga/laravel-model-status

> 标签: laravel, laravel-model-status, zoparga

## 简介

Add many status to many model with a single trait. E.g.: many status for a customer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
