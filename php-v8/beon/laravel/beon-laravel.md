# beon/laravel

> 标签: beon, laravel, messaging, otp, package, whatsapp

## 简介

Send WhatsApp messages from Laravel in 3 lines — powered by Beon API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
