# dud/contao-cursor-keeper

> 标签: ace, backend, contao, cursor, editor, scroll

## 简介

Positionsspeicherung und -wiederherstellung im internen Contao Code-Editor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
