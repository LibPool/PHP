# smarcet/jose4php

> 标签: ID Token, JOSE, JSON Web Algorithms, JSON Web Encryption, JSON Web Signature, JSON Web Token, JWE, JWS, OpenID Connect, jwa, jwt

## 简介

JWT, JWS, JWE, JWA and JWK implementation in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
