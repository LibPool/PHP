# angelohd/laravel-backup

> 标签: backup, database, dump, laravel, mariadb, mysql, restore

## 简介

Biblioteca Laravel para realizar backup automatico da base de dados.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
