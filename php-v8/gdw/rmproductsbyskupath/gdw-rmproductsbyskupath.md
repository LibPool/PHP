# gdw/rmproductsbyskupath

> 标签: command, crud, delete, gdw, gestion digital web, magento 2, sku, ssh

## 简介

Módulo GDW para Magento 2, permite eliminar productos por sku desde consola.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
