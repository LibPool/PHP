# inventor96/mako-vue

> 标签: boilerplate, framework, inertia, mako, vue

## 简介

Opinionated boilerplate for web apps using PHP/Mako on the backend, and Vue on the frontend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
