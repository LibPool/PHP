# bzync/nextsql

> 标签: client, database, driver, encryption, full-text-search, nextsql, sql, vector

## 简介

Official NextSQL PHP driver. Speaks the native NSQL v1 protocol. Keys never go in URLs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
