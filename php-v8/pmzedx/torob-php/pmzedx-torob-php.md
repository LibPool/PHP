# pmzedx/torob-php

> 标签: Guzzle, ecommerce, php, product-sync, torob, torob-api

## 简介

A PHP 8.1+ client and integration toolkit for Torob APIs, powered by Guzzle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
