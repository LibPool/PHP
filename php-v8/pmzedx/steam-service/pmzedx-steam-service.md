# pmzedx/steam-service

> 标签: Guzzle, api, steam, steam-api, valve

## 简介

A clean PHP wrapper for the Steam Web API using Guzzle HTTP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
