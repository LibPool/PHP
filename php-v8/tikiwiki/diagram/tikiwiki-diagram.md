# tikiwiki/diagram

> 标签: PHP

## 简介

MXGraph / Draw.io / diagrams.net component to be used within Tiki Wiki CMS Groupware

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
