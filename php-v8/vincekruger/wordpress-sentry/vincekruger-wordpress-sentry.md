# vincekruger/wordpress-sentry

> 标签: raven, sentry, wordpress

## 简介

A WordPress plugin to handle reporting php error to the Sentry error reporting system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
