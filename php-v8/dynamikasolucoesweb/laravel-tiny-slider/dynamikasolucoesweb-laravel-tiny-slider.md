# dynamikasolucoesweb/laravel-tiny-slider

> 标签: dynamika, laravel, tiny-slider

## 简介

Um componente Blade robusto e flexível para integração do Tiny Slider em aplicações Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
