# iamgold/yii2-dynamodb

> 标签: composer, dynamodb, iamgold, yii2

## 简介

This project is used to access Aws DynamoDb in Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
