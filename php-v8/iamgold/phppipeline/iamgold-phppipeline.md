# iamgold/phppipeline

> 标签: command builder, handler, iamgold, linux pipeline, php, pipeline

## 简介

This is a lightweight library for manipulating graphics magick commands in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
