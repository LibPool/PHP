# cblink/openai

> 标签: ChatGPT SDK, ChatGpt, GPT-3, PHP ChatGPT, codex, openai

## 简介

An OpenAI REST API Client with ChatGPT, GPT-3, Codex, DALL·E.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
