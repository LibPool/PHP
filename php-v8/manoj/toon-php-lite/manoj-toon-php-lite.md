# manoj/toon-php-lite

> 标签: decoder, encoder, json, llm, php, serialization, toon

## 简介

Lite PHP implementation of TOON (Token-Oriented Object Notation)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
