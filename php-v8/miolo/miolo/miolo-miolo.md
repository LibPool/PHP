# miolo/miolo

> 标签: PHP

## 简介

MIOLO PHP Framework v2.5 — archived for documentation and historical reference. This is a legacy version (PHP 5.x) and is not intended for production use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
