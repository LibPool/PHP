# victorap93/oauth2token

> 标签: microsoft, oauth 2.0, outlook, token

## 简介

This package is an easy way to use OAuth 2.0 Protocols to get authorization token

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
