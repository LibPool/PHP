# ktav-lang/ktav

> 标签: config, configuration, ffi, ktav, parser, serializer

## 简介

PHP bindings for Ktav — a plain configuration format with three rules, zero indentation, and no required quoting (quoted keys are supported). FFI over the reference Rust crate (default) plus a full pure-PHP parser/writer backend (requires only ext-json, no FFI or native binary); no extension compilation on the consumer side.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
