# orderingco/ordering-theme-engine

> 标签: design-tokens, json-schema, ordering, theme, theme-engine

## 简介

The Ordering.co API's theme engine (version 2 themes) in PHP: the same schema, the same rules, the same answer as the TypeScript package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
