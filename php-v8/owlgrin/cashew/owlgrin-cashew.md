# owlgrin/cashew

> 标签: L4, laravel, stripe, subscription, wrapper

## 简介

Simplest subscription billing for Laravel using Stripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
