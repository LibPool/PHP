# wycto/phpframe

> 标签: frame, framework, wycto

## 简介

一个轻量级的MVC框架、个人学习PHP框架、PHP框架、wycto框架

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
