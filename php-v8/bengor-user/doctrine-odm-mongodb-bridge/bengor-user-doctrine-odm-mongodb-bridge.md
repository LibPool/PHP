# bengor-user/doctrine-odm-mongodb-bridge

> 标签: adapter, ddd, doctrine, mongodb, odm, user

## 简介

Adapter to make User compatible with Doctrine ODM MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
