# mickeywaugh/captcha

> 标签: bot, captcha, spam

## 简介

Base On  Gregwar/Captcha , compatible with php 8.0+, add setImageType(), and setBackgroundColor() support alpha channel;

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
