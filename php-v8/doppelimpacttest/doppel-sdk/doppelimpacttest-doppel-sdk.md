# doppelimpacttest/doppel-sdk

> 标签: Shadow, doppel, llm, sdk, testing

## 简介

Official Doppel PHP SDK — capture LLM calls and forward them to Doppel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
