# gridguyz/facebooklogin

> 标签: facebook, facebook-login, gridguyz, login, module

## 简介

FacebookLogin module for Gridguyz CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
