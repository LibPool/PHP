# dotsplatform/uklon-delivery-api-sdk-laravel

> 标签: PHP

## 简介

This a laravel package for Uklon Delivery API - https://deliverygateway.uklon.com.ua/docs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
