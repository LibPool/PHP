# frostybee/slim-mvc

> 标签: mvc-php, php, slim, slim-framework-mvc, slim-mvc-skeleton, slim4

## 简介

An MVC-based web application project template that uses the Slim PHP microframework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
