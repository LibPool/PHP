# frostybee/slim-template

> 标签: api, php, rest, rest-api, slim, slim-micro-framework, slim4

## 简介

A Slim framework skeleton for implementing REST-based Web services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
