# idrinth/yaml-facade

> 标签: deserializer, facade, serializer, yaml, yml

## 简介

provides an facade for php-yaml, syck and symphony/yaml so switching in between is easier

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
