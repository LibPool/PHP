# webium/silverstripe-assets-sync

> 标签: assets, files, import, silverstripe, sync

## 简介

A SilverStripe module for importing files from a directory into the Assets system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
