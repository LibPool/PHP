# phpner/start-slim

> 标签: Skeleton, slim, template

## 简介

Skeleton of slim 3 with webpack and laravel Eloquent, laravel template blabe and so on

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
