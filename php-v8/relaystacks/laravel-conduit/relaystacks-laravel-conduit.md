# relaystacks/laravel-conduit

> 标签: PHP

## 简介

Laravel broadcast driver for the Conduit ecosystem. Writes events to a Unix socket via relaystacks/conduit-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
