# claromentis/opauth

> 标签: Authentication, OpenId, auth, facebook, google, oauth, omniauth, twitter

## 简介

Multi-provider authentication framework for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
