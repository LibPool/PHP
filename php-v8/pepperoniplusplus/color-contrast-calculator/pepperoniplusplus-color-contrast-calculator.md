# pepperoniplusplus/color-contrast-calculator

> 标签: PHP

## 简介

A package to calculate contrast given two colors. Provides functions to calculate color difference, brightness difference and luminosity contrast.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
