# liuwave/think-log-driver-sls

> 标签: log, think-log-driver-sls, thinkphp, 函数计算, 阿里云日志服务sls

## 简介

这是使用阿里云日志服务sls的thinkphp6.0日志驱动，支持函数计算

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
