# liuwave/think-filesystem-driver-kodo

> 标签: filesystem, kodo, think-filesystem-driver-kodo, 七牛云, 对象存储

## 简介

这是一个基于七牛云对象存储的thinkphp6.0 Filesystem驱动

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
