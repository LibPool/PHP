# liuwave/fc-thinkphp

> 标签: fc, fc-thinkphp, log, oss, php runtime, thinkphp, 函数计算, 对象存储, 日志服务sls, 阿里云

## 简介

deploy a thinkphp project on FC。在函数计算上部署thinkphp项目。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
