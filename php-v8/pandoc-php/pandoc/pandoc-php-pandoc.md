# pandoc-php/pandoc

> 标签: Bibliography, PowerPoint, ast, bibtex, converter, csv, docx, excel, html, jupyter, latex, locale, markdown, pandoc, pptx, xlsx

## 简介

A native PHP 8.4 port of the Pandoc document converter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
