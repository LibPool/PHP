# benkeen/generatedata

> 标签: Random Data, Sample Data, data generator, test data, testing

## 简介

Free, GNU-licensed, random custom data generator for testing software

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
