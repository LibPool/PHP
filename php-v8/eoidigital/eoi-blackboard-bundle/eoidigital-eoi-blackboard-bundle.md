# eoidigital/eoi-blackboard-bundle

> 标签: Blackboard API

## 简介

A Symfony2 Wrapper for the Blackboard's SOAP Web Service API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
