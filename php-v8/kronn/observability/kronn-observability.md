# kronn/observability

> 标签: apm, kronn, laravel, monitoring, observability, telemetry

## 简介

Telemetria e APM da plataforma Kronn para aplicações Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
