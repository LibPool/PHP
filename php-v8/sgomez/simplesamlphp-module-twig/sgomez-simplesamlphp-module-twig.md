# sgomez/simplesamlphp-module-twig

> 标签: simplesaml, simplesamlphp, twig

## 简介

A SimpleSAMLphp module adding support for the Twig template library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
