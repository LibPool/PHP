# sgomez/simplesamlphp-base-module-install

> 标签: simplesamlphp

## 简介

A Composer plugin that overrides simplesamlphp/composer-module-installer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
