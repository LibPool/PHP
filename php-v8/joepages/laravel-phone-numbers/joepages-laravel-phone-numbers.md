# joepages/laravel-phone-numbers

> 标签: laravel, multi-tenancy, phone-numbers, polymorphic

## 简介

Polymorphic phone numbers package for Laravel - Attach N phone numbers to any model

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
