# swarakaka/bridge-laravel

> 标签: Bridge, SPA, api, content-negotiation, laravel, sse

## 简介

Bridge: a server-driven application protocol for Laravel with Page, JSON and SSE modes from one controller

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
