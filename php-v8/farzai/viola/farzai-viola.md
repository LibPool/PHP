# farzai/viola

> 标签: ChatGpt, GPT-3, ai, bot, chat-gpt, farzai, gpt, gpt3, openai, viola, viola-cli

## 简介

Viola CLI is a command line tool for asking questions with ChatGPT.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
