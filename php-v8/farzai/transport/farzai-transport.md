# farzai/transport

> 标签: API-Client, cookie, file-upload, fluent-api, form-data, http, http-client, middleware, multipart, psr, psr-18, psr-7, rest-client, retry

## 简介

A modern, PSR-compliant HTTP client for PHP with middleware architecture, advanced retry strategies, and fluent API for building requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
