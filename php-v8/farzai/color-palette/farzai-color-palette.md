# farzai/color-palette

> 标签: accessibility, color, color-analysis, color-extraction, contrast-ratio, gd, hsl, hsv, image-processing, imagick, palette, rgb, theme-generation, wcag

## 简介

A robust PHP library for extracting, analyzing, and managing color palettes from images

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
