# brtnetwork/buffer

> 标签: Buffer, binary, hex, nodejs-buffer, php-buffer

## 简介

Toolbox for working with binary and hex data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
