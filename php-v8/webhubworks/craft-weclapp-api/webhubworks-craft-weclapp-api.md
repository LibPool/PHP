# webhubworks/craft-weclapp-api

> 标签: Craft, cms, craft-plugin, craft-weclapp-api, craftcms, weclapp

## 简介

A Craft CMS wrapper around webhubworks/weclapp-api-core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
