# webhubworks/weclapp-api-laravel

> 标签: Webhub, laravel, weclapp-api-laravel

## 简介

A Laravel wrapper around webhubworks/weclapp-api-core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
