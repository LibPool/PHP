# manialib/gbx

> 标签: ManiaLib, ManiaPlanet, Nadeo, ShootMania, TrackMania, Ubisoft

## 简介

Manialib/Gbx is a PHP package to manipulate Maniaplanet Gbx files metadata

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
