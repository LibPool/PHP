# smmtglux/smm-api

> 标签: API-Client, reseller, smm, smm-api, smm-panel, social-media-marketing, telegram

## 简介

PHP client for the standard SMM API v2 used by social media marketing panels. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
