# zhylon/zhylonid-service

> 标签: SSO, eu-hosted, identity, laravel, oauth2, zhylon

## 简介

Server-to-server client for the ZhylonID identity API (user existence checks, ecosystem user sync).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
