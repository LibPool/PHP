# zhylon/api-resources

> 标签: JSON-API, api, laravel, resources, zhylon

## 简介

Opinionated helpers for building consistent, JSON:API-inspired API resource responses in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
