# zhylon/laravel-statsd

> 标签: Metrics, laravel, netdata, statsd, zhylon

## 简介

Fire-and-forget StatsD metrics for Laravel, built for Netdata's built-in StatsD collector.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
