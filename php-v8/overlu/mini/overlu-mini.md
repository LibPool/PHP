# overlu/mini

> 标签: Simple, api, coroutine, fast, framework, mini, php, swoole, websocket

## 简介

A simple, lightweight and high-performance PHP coroutine framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
