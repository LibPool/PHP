# ifmx/webbackupper

> 标签: backup, backupper, ftp, sftp, web, wordpress

## 简介

A simple PHP WebBackupper for Wordpress Instances, databases, folders and FTP/SFTP-Folders local and to a FTP/SFTP Server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
