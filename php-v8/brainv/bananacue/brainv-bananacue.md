# brainv/bananacue

> 标签: PHP

## 简介

BananaCue — Universal PHP queue abstraction layer (SQS, RabbitMQ, Kafka, Redis, ActiveMQ, Pulsar, Database, In-Memory)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
