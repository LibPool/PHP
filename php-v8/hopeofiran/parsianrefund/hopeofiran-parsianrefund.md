# hopeofiran/parsianrefund

> 标签: parsian, parsianrefund, refund, refundparsian

## 简介

This package allows the use of Parsian payment gateway refund system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
