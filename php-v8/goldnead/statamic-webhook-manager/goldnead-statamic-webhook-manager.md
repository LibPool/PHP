# goldnead/statamic-webhook-manager

> 标签: automation, integration, statamic, statamic-addon, webhooks

## 简介

Statamic 6 Webhook Manager — central CP-native integration layer for outbound hooks, inbound endpoints, deliveries, retries, rules and templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
