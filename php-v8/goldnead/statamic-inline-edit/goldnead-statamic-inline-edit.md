# goldnead/statamic-inline-edit

> 标签: editor, frontend-editing, inline-editing, statamic, statamic-addon

## 简介

Edit text straight on the live page. Double-click, type, save. No control panel, no page builder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
