# goldnead/statamic-flow-canvas

> 标签: canvas, node-graph, statamic, statamic-addon, vue-flow

## 简介

The shared node-graph editor behind Goldnead's Statamic addons: canvas, node cards, config panel, auto-layout, history.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
