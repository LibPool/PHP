# goldnead/statamic-bard-assist

> 标签: bard, classification, editor, sets, statamic, statamic-addon

## 简介

Suggests which Bard set each paragraph should become, and fills its fields.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
