# goldnead/statamic-entitlements

> 标签: access-control, entitlements, grants, licensing, statamic, statamic-addon

## 简介

Brand-scoped entitlement grants for Statamic: one state machine, database-level idempotency, real revocation and four domain events. Decides who may access what; sends nothing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
