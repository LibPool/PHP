# goldnead/statamic-certificates

> 标签: certificates, courses, lms, pdf, statamic, statamic-addon

## 简介

Completion certificates for Statamic: a PDF when a course is finished, per-brand template, and a public verification URL a third party can check.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
