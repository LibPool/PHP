# goldnead/statamic-products

> 标签: PHP

## 简介

Products for Statamic: the thing that is sold, with a name, a list price and the access it grants. The piece between a price tag in a config file and an entitlement.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
