# goldnead/statamic-events

> 标签: calendar, events, ics, occurrences, statamic, statamic-addon

## 简介

Brand-scoped event and occurrence domain for Statamic: multi-date events, per-event timezones, venue or online location, ICS downloads and calendar feeds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
