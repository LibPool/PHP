# goldnead/statamic-bard-footnotes

> 标签: bard, footnotes, statamic, statamic-addon

## 简介

Footnotes for Statamic's Bard field: a toolbar button, inline superscript references, and an automatic source list.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
