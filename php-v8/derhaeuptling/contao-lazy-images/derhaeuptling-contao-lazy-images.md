# derhaeuptling/contao-lazy-images

> 标签: contao, images

## 简介

Lazy Images delays loading of images in long web pages for Contao Open Source CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
