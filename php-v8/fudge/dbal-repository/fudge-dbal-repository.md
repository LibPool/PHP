# fudge/dbal-repository

> 标签: database, dbal, doctrine, repository

## 简介

A wrapper for Doctrine DBAL to provide a standard repository

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
