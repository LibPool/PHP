# dandoetech/laravel-openapi-generator

> 标签: artisan, laravel, openapi, php, swagger

## 简介

Laravel bridge for DanDoeTech OpenAPI generator: artisan export command and wiring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
