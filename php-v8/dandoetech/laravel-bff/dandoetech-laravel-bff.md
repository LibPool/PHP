# dandoetech/laravel-bff

> 标签: SPA, bff, laravel, metadata, php, ui

## 简介

Laravel bridge for DanDoeTech BFF metadata: metadata endpoints, policy & visibility decorators.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
