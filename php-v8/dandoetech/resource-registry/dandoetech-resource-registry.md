# dandoetech/resource-registry

> 标签: api, crud, metadata, php, registry, resource

## 简介

Framework-agnostic Resource Registry for API resources (fields, relations, actions, policies).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
