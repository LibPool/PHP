# vortos/vortos-security

> 标签: PHP

## 简介

Vortos enterprise security — HTTP headers, CORS, CSRF, IP filtering, request signing, encryption, secrets, and data masking

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
