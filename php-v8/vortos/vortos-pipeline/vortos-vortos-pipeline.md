# vortos/vortos-pipeline

> 标签: PHP

## 简介

Provider-agnostic CI/CD generation — abstract Pipeline model + GitHub Actions emitter (pure codegen, SHA-pinned, least-privilege), owns split.yml

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
