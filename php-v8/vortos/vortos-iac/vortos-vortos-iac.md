# vortos/vortos-iac

> 标签: PHP

## 简介

Vortos IaC — Terraform/OpenTofu lifecycle (plan/apply/destroy), codegen (.tf.json), nine resource families, state backends, policy gate, audit trail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
