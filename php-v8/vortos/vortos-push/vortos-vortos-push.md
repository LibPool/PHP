# vortos/vortos-push

> 标签: PHP

## 简介

Vortos push-notification delivery — Web Push (VAPID + RFC 8291 aes128gcm) with a driver-based sender contract

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
