# bumpcore/json-patch

> 标签: json, json-merge-patch, json-patch, json-pointer

## 简介

RFC 6902 JSON Patch and RFC 7396 JSON Merge Patch implementation for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
