# hdgarau/logic-gate

> 标签: PHP

## 简介

Set a reference value and compare with another. Evaluate some coditions as tree (AND/OR) and return true/false.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
