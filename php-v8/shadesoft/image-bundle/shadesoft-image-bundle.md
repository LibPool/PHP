# shadesoft/image-bundle

> 标签: bundle, gd, image, picture, symfony

## 简介

An image editing bundle using PHP's GD library if other solutions fail for some reason.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
