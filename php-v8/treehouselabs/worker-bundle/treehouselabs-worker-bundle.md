# treehouselabs/worker-bundle

> 标签: beanstalk, beanstalkd, worker

## 简介

Adds worker functionality to a Symfony2 project, using Beanstalkd as the message queue

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
