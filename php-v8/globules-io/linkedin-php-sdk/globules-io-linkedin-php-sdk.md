> 标签: Authentication, api, auth, authorization, client, integration, linked in, linkedin, linkedin-api, linkedin-client, linkedin-login, linkedin-sdk, linkedin-signin, linkedin.com, oauth, oauth2, oauth2-authentication, oauth2-client, php-linkedin, platform, rest, social, social network, wrapper

## 简介

This package is an SDK for using LinkedIn V2 Marketing API. You can use it for managing Company Pages in this social network

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
