# iivannov/snitch

> 标签: laravel, log, sentry

## 简介

Easily log and report exceptions to multiple different places (file, database, Sentry, Bugsnag, ...)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
