# phptramp/phptramp

> 标签: ci, code quality, dev, static analysis, tramp data

## 简介

Static analyzer that detects tramp data: parameters passed through chains of PHP methods that never use them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
