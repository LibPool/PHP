# stallion/finfactor

> 标签: PHP

## 简介

PHP client for the Finfactor WealthScape API. Handles authentication, user subscription, AA consent flow, and financial data retrieval.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
