# riconet/dynamic-faq

> 标签: FAQ, TYPO3 CMS, extension, qanda

## 简介

This extension provides a full FAQ solution with user created questions answered by admins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
