# do-it-s/dropin-markdown

> 标签: PHP

## 简介

Drop-in markdown-file-backed static pages and sysadmin announcements for Laravel, with GFM + GitHub-style alert rendering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
