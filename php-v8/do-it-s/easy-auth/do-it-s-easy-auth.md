# do-it-s/easy-auth

> 标签: PHP

## 简介

Passwordless auth (passkeys + device UUID) with an invitation-chain tenant/role model, designed for low IT-literacy organizations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
