# jeroen/json-dump-reader

> 标签: bz2, dump, json, wikibase, wikidata

## 简介

Provides line-by-line readers and iterators for Wikibase/Wikidata JSON dumps

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
