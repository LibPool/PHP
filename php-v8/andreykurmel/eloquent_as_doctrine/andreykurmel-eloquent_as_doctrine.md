# andreykurmel/eloquent_as_doctrine

> 标签: doctrine, eloquent

## 简介

Hydrate Laravel Entities from Models to use all Eloquent benefits in Service/Repository pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
