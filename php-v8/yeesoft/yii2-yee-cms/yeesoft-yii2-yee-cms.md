# yeesoft/yii2-yee-cms

> 标签: cms, yee, yii2

## 简介

Yee CMS Based on Yii 2 Advanced Project Template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
