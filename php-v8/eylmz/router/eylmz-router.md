# eylmz/router

> 标签: api, mvc, php, restful, router

## 简介

Router - Fast, flexible routing for PHP, enabling you to quickly and easily build RESTful web applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
