# koneko/laravel-exchange-rates-api

> 标签: api, currencies, exchange, framework, koneko, laravel, rates

## 简介

Laravel Exchange Rates API, es un Servicio para obtener las tasas de cambio de las principales monedas del mundo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
