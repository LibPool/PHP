# rdpascua/jasperstarter

> 标签: jasper, reports

## 简介

JasperStarter is an opensource command line launcher and batch compiler for JasperReports

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
