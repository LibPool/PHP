# 1happyplace/ansi-terminal

> 标签: ansi, emulator, terminal

## 简介

PHP Terminal emulator controller utilizing ANSI escape sequence coding.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
