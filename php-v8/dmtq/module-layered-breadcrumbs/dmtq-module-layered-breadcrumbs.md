# dmtq/module-layered-breadcrumbs

> 标签: PHP

## 简介

Magento2 product hierarchy breadcrumbs and structured breadcrumb data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
