# dmtq/module-perfect-cache

> 标签: PHP

## 简介

Magento2 cms and product data cache. Used to improve the access speed of CMS pages and product detail pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
