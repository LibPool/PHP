# kostyan-org/vk-archiver

> 标签: api, cli, vk, архиватор, вконтакте

## 简介

Архиватор пользователей, сообществ, постов, лайков и комментариев с сайта vk.com через API ВКонтакте

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
