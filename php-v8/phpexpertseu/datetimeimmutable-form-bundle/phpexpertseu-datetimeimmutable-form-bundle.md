# phpexpertseu/datetimeimmutable-form-bundle

> 标签: PHP

## 简介

This bundle for Symfony3 replaces the mutable DateTime classes with DateTimeImmutable in forms

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
