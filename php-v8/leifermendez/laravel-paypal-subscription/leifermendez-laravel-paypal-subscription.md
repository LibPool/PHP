# leifermendez/laravel-paypal-subscription

> 标签: PHP

## 简介

Plugin especial para laravel el cual permite de forma facil el cobro de subscripcion con PAYPAL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
