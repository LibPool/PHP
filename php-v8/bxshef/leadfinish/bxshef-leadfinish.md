# bxshef/leadfinish

> 标签: Bitrix24, bitrix, crm, lead, module

## 简介

Битрикс24 (коробка): завершение обработки лида привязкой уже существующей сделки вместо создания новой

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
