# saucebase/breadcrumbs

> 标签: breadcrumbs, laravel, saucebase

## 简介

Minimal breadcrumbs package for Saucebase — a fork of diglactic/laravel-breadcrumbs without Blade rendering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
