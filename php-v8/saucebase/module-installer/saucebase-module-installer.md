# saucebase/module-installer

> 标签: PHP

## 简介

Custom Composer installer for Sauce Base modules (type: saucebase-module). Installs to modules/<name> (lowercase) with configurable base dir.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
