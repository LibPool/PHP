# saucebase/saucebase

> 标签: laravel boilerplate, laravel starter kit, saas boilerplate, saas starter kit

## 简介

A complete modular Laravel foundation for building SaaS applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
