# inspiredminds/contao-categories-news-filter

> 标签: PHP

## 简介

This package provides a bridge between codefog/contao-news_categories and inspiredminds/contao-news-filter-event.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
