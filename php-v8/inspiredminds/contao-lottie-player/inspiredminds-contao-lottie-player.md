# inspiredminds/contao-lottie-player

> 标签: PHP

## 简介

Contao extension to integrate the Lottie Web Player for Lottie or Telegram Sticker JSON files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
