# inspiredminds/contao-future-cache-invalidation

> 标签: PHP

## 简介

Invalidates cache tags in the future for any DCA in Contao that has a `start` or `stop` field.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
