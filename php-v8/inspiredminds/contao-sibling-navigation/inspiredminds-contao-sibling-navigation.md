# inspiredminds/contao-sibling-navigation

> 标签: contao, events, navigation, news, sibling

## 简介

Provides a previous/next navigation for news & events.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
