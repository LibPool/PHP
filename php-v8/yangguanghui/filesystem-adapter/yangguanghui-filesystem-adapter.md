# yangguanghui/filesystem-adapter

> 标签: cache, filesystem, psr-6, tag

## 简介

A PSR-6 cache implementation using filesystem. This implementation supports tags

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
