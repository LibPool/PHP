# srwiez/php-bin-with-grpc

> 标签: gRPC, nativephp, php

## 简介

PHP binaries for NativePHP app that needs gRPC support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
