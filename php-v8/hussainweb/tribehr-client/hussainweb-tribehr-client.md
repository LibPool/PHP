# hussainweb/tribehr-client

> 标签: kudos, tribehr, tribehr api

## 简介

TribeHR client is a Guzzle based client to interact with TribeHR API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
