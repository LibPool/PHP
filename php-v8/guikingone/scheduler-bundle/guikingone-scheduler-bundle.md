# guikingone/scheduler-bundle

> 标签: Tasks, automation, cron, schedule, scheduler

## 简介

A Symfony bundle that allows to schedule and create repetitive tasks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
