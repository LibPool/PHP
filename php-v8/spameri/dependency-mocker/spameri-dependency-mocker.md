# spameri/dependency-mocker

> 标签: dependency, mockery, nette

## 简介

Loads dependencies to mocked classes by Mockery for Nette Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
