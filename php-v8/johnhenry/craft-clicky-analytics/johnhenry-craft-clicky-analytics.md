# johnhenry/craft-clicky-analytics

> 标签: analytics dashboard, clicky, clicky analytics, dashboard widgets, live visitors, page stats, page views, traffic sources, visitor statistics, web analytics

## 简介

Clicky analytics in the Craft control panel: dashboard widgets, a live visitor feed and a Page Stats field for each entry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
