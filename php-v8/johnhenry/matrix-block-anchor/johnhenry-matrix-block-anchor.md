# johnhenry/matrix-block-anchor

> 标签: anchor, anchor links, deep linking, in-page navigation, jump links, matrix, matrix blocks, nested entries, page builder, section links, table of contents

## 简介

Anchor links for Matrix blocks, built from the block ID or set by an editor, with a copy button on each.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
