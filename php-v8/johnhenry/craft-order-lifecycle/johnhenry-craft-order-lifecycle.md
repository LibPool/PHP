# johnhenry/craft-order-lifecycle

> 标签: Audit Log, Customer support, abandoned carts, cart abandonment, checkout analytics, conversion rate, craft-commerce, failed payments, order export, order history, order timeline, refunds

## 简介

A timeline of every step each Craft Commerce order took, with store analytics and optional AI insights.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
