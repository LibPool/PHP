# johnhenry/craft-container-deposits

> 标签: Ireland, bottle deposit, can deposit, container deposits, craft-commerce, deposit return scheme, drinks, drs, multipacks, re-turn, receipts, vat exempt

## 简介

Container deposits for Craft Commerce, each on its own cart line and kept out of VAT and discounts. Set up for Ireland's Re-turn scheme.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
