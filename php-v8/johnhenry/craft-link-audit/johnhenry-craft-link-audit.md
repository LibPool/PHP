# johnhenry/craft-link-audit

> 标签: 404, broken link checker, broken links, content audit, dead links, external links, link checker, link rot, redirects, seo

## 简介

Finds broken links in your Craft content, checks each unique address once, and shows which entries to fix.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
