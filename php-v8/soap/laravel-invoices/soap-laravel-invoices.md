# soap/laravel-invoices

> 标签: eloquent, invoicable, invoices, laravel, laravel-invoices, payments

## 简介

Easy invoices generation using Laravel Eloquent

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
