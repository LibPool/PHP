# soap/dompdf-thai

> 标签: dompdf, dompdf-thai, font, laravel, pdf, soap, thai

## 简介

Add Thai fonts for Laravel DomPdf wrapper package

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
