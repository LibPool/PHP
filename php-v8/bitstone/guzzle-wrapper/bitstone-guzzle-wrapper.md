# bitstone/guzzle-wrapper

> 标签: Guzzle, http, laravel, request, wrapper

## 简介

A laravel wrapper around the Guzzle Client API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
