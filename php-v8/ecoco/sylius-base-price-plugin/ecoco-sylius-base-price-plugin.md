# ecoco/sylius-base-price-plugin

> 标签: ecoco, sylius, sylius-plugin

## 简介

Sylius base price plugin will show product base price next to its price and in cart

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
