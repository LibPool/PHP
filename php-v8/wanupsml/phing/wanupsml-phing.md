# wanupsml/phing

> 标签: build, phing, task, tool

## 简介

Apache Ant port for PHP. Fork from phingofficial but with particular improvements. See FORK.md

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
