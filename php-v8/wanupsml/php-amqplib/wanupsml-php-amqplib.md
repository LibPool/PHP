# wanupsml/php-amqplib

> 标签: message, queue, rabbitmq

## 简介

This library is a pure PHP implementation of the AMQP protocol. It's been tested against RabbitMQ.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
