# affinity4/tokenizer

> 标签: PHP

## 简介

A zero-dedpendency tokenizer written in PHP. Returns an easily navigatable Stream object of Token objects with public type, value, offset and length properties

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
