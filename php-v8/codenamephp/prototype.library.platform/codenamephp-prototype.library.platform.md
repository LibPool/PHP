# codenamephp/prototype.library.platform

> 标签: PHP

## 简介

Prototype for library projects that includes the basic directory layout, build tools, composer, ... via a installer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
