# mikeotizels/mpesa

> 标签: mpesa, mpesa-api, mpesa-rest, mpesa-sdk, payments, safaricom

## 简介

Mikeotizels implementation of the M-PESA REST APIs in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
