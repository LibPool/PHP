# depage/db

> 标签: database, db, pdo

## 简介

depage-pdo is a small wrapper around the pdo object which allows late/on demand initializition of the database connection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
