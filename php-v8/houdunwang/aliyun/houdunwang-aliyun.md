# houdunwang/aliyun

> 标签: aliyun, hdphp, houdunwang, 后盾人, 后盾网, 向军老师, 阿里云

## 简介

提供了常用的阿里云服务操作方法，是对阿里云官网SDK的封装，整体使用安装可靠。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
