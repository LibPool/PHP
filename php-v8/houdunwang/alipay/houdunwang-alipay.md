# houdunwang/alipay

> 标签: alipay, hdphp, houdunwang, 后盾人, 向军老师, 支付宝支付

## 简介

支付宝组件用于实现支付宝在线支付功能

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
