# houdunwang/hdphp

> 标签: framework, hdcms, houdunwang, 敖向军

## 简介

HDCMS 桌面/移动/微信/小程序可扩展内容管理系统

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
