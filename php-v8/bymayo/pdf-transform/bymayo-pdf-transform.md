# bymayo/pdf-transform

> 标签: Craft, cms, craft-plugin, craftcms, pdf transform

## 简介

Transform a PDF page to an image (JPEG, PNG)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
