# bymayo/akeneo

> 标签: PHP

## 简介

Akeneo is a Craft CMS plugin that syncs products and data from Akeneo PIM (https://akeneo.com) into Craft CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
