# vitnasinec/laravel-envoy-config

> 标签: deploy, envoy, laravel, rsync, ssh

## 简介

One Envoy setup for every project: a typed config block in your repo, every task in vendor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
