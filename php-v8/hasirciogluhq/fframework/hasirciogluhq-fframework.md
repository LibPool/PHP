# hasirciogluhq/fframework

> 标签: fframework, framework, http, mvc, php, routing

## 简介

Lightweight PHP framework: HTTP routing, views, config, and PDO-friendly database helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
