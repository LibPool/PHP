# acodeninja/laravel-pwned-passwords-validator

> 标签: PHP

## 简介

Validation package that checks Pwned Passwords to validate passwords https://haveibeenpwned.com/Passwords

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
