# cleentfaar/doctrine-table-prefix-bundle

> 标签: doctrine, symfony

## 简介

This bundle allows doctrine to recognize any prefix you might use on your table names (e.g. acme_)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
