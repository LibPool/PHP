# kadevland/laravel-easy-modules

> 标签: Flexible, artisan-commands, clean-architecture, code-organization, customizable, developer-tools, laravel, laravel-12, laravel-modules, laravel-package, modular, module-generator, php, rapid-development, scaffolding

## 简介

Laravel module generator with extensive Artisan commands for rapid modular development. Customizable architecture patterns including Clean Architecture templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
