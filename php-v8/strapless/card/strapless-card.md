# strapless/card

> 标签: card, css, panel, responsive, sass, scss, strapless

## 简介

Card component from Bootstrap 4, modified for usage as a standalone component, with Bootstrap 3, or with other DevIsCoding components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
