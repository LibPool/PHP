# jodit/yii2-jodit

> 标签: editor, extension, html, html editor, javascript, jodit, rich, rich editor, rich text editor, text, wysiwyg, yii2

## 简介

Jodit - awesome WYSIWYG Editor like widget for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
