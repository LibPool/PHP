# rmdmostakim/bdpayment

> 标签: PHP

## 简介

A Laravel payment integration package supporting bKash, Nagad, Rocket, and other Bangladeshi gateways with unified APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
