# black-lamp/yii2-seo-breadcrumbs

> 标签: breadcrumbs, schema, seo, widget, yii2

## 简介

Widget provides SEO schema for Breadcrumbs widget in Yii2 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
