# black-lamp/blcms-sitemap

> 标签: Sitemap, black-lamp, cms, generation, yii2

## 简介

Sitemap generation extension for Black-Lamp CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
