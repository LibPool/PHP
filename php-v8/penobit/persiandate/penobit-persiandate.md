# penobit/persiandate

> 标签: PersianDate, date, datetime, jDate, jalali date, laravel, penobit, persian datetime

## 简介

Persian datetime package to use and manipulate Persian (jalali) datetime.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
