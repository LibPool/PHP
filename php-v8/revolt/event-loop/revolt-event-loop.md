# revolt/event-loop

> 标签: async, asynchronous, concurrency, event, event-loop, non-blocking, scheduler

## 简介

Rock-solid event loop for concurrent PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
