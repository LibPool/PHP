> 标签: cmyk, color, conversion, hex, hexa, hsl, hsla, hsv, manipulation, oklch, rgb, rgba, transformation

## 简介

PHP library for color manipulation and conversion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
