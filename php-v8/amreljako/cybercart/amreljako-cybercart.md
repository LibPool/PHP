# amreljako/cybercart

> 标签: cart, ecommerce, headless, laravel, mada, paymob, security, tamara

## 简介

A secure, headless, high-performance embedded e-commerce core engine for Laravel with regional Arab & Gulf payments integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
