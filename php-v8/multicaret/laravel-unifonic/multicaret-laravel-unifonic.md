# multicaret/laravel-unifonic

> 标签: 2fa, api, laravel, number intelligence, sms, tts, unifonic, verify

## 简介

A library to integrate with Unifonic API to send SMS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
