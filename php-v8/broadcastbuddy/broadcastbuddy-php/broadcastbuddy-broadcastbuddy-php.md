# broadcastbuddy/broadcastbuddy-php

> 标签: broadcastbuddy, laravel, messaging, notifications, polls, sms-alternative, whatsapp, whatsapp-api

## 简介

Official PHP Client & Laravel Service Provider for Broadcast Buddy WhatsApp Gateway API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
