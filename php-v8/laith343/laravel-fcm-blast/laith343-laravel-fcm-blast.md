# laith343/laravel-fcm-blast

> 标签: FCM, curl-multi, firebase, high-throughput, laravel, push-notifications

## 简介

High-throughput Firebase Cloud Messaging blaster for Laravel. Pushes 10k+ req/s via a reused curl_multi handle pool, OAuth handled by kreait/firebase-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
