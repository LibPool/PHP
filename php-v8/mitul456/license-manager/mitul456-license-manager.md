# mitul456/license-manager

> 标签: activation, hmac, laravel, license, licensing

## 简介

Laravel client package for the Remote License Server — HMAC-signed activation, validation, grace-period enforcement and update checking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
