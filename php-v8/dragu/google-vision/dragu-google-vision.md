# dragu/google-vision

> 标签: api, cloud, face, google, image, landmark, recognition, vision

## 简介

Google Vision Api for PHP (https://cloud.google.com/vision/) with word features fixed

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
