# bondforge/coding-standard

> 标签: allman, bondforge, coding-standard, fixer, php-cs-fixer

## 简介

Shared PHP CS Fixer configuration and custom fixers for BondForge projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
