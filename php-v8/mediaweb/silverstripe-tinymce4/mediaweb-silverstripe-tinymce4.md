# mediaweb/silverstripe-tinymce4

> 标签: editor, htmleditor, silverstripe, tinymce

## 简介

Replaces the default Silverstripe HTMLEditor (TinyMCE v3) with TinyMCE v4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
