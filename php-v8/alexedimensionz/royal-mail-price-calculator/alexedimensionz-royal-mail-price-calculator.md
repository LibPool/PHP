# alexedimensionz/royal-mail-price-calculator

> 标签: calculator, postage, royal mail

## 简介

A library to calculate the cost of sending a package with Royal Mail.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
