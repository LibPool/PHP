# hei/laravel-scarlett-player

> 标签: analytics, beacons, clips, embed, hls, laravel, scarlett-player, video

## 简介

The server side of Scarlett Player for Laravel: analytics beacon ingest, clip generation, player configuration and the embed route

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
