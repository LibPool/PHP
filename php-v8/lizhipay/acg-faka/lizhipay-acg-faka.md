# lizhipay/acg-faka

> 标签: acg-shop, faka, lizhipay, 个人发卡, 发卡, 店铺, 网店

## 简介

一款基于php8开发的原生虚拟发卡系统、个人店铺系统！

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
