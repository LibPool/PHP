> 标签: laravel alawael, laravel alawael sms, laravel messaging gateway, laravel notifications, laravel notifications package, laravel sms gateway, laravel whatsapp notifications, notifications, sprig

## 简介

A Laravel package for handling various notifications like SMS, WhatsApp, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
