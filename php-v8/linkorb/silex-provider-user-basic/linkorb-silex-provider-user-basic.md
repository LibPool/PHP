# linkorb/silex-provider-user-basic

> 标签: PHP

## 简介

Custom Symfony Security User and in-memory User Provider for use in Silex apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
