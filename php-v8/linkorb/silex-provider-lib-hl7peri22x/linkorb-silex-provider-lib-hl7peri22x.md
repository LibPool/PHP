# linkorb/silex-provider-lib-hl7peri22x

> 标签: PHP

## 简介

Service providing conversion of HL7v2 to Peri22x Dossier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
