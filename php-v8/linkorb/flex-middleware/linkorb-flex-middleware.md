# linkorb/flex-middleware

> 标签: middleware, psr15

## 简介

Configure (using a .yaml file) a queue of HTTP middlewares for any PHP application (Symfony 4, Radvance, Silex)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
