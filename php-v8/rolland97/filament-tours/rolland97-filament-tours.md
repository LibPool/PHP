# rolland97/filament-tours

> 标签: Rolland97, filament, filament-plugin, filament-tours, filamentphp, laravel

## 简介

Guided product tours for Filament panels, powered by driver.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
