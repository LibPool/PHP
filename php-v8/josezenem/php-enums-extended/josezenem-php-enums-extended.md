# josezenem/php-enums-extended

> 标签: enums, josezenem, php-enums-extended

## 简介

PHP 8.1 Enums Extended adds additional functionality when working with PHP 8.1+ Enums.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
