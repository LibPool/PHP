# wiksoft/contao-lichess-pgnviewer-bundle

> 标签: PGN, chess, chessboard, contao, lichess, pgn-viewer, schach, schachbrett

## 简介

Schachpartien (PGN) im Contao-Frontend nachspielbar machen, mit dem lichess.org PGN-Viewer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
