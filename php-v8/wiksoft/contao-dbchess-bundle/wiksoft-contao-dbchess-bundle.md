# wiksoft/contao-dbchess-bundle

> 标签: PGN, chess, contao, database, datenbank, eco, partien, schach

## 简介

Schachpartien-Datenbank für Contao (Sammlungen, PGN-Import/-Export, ECO-Codes)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
