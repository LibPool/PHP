# slashmark/composer-suite

> 标签: Devtools, cli, composer, composer-lock, dependency-tree, license-checker, outdated, package-health, packagist, php-compatibility, security-advisories, semver

## 简介

PHP Package Intelligence Suite: 32 terminal tools to search, inspect, audit and manage Composer packages (security, licenses, conflicts, health scores, lock analysis and more).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
