# mocodo/flipt-sdk

> 标签: feature-flags, flipt, psr-18, sdk

## 简介

PHP SDK for Flipt feature flag evaluation, built on PSR-18/PSR-17.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
