# everrest/watcher

> 标签: DataDog, anthropic, claude, discord, laravel, llm, log-analysis, loki, lumen, monitoring, observability, slack, telegram

## 简介

Scheduled, model-routed log analysis that reports problems to Slack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
