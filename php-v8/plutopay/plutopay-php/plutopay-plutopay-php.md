# plutopay/plutopay-php

> 标签: ach, api, checkout, laravel, payments, plutopay, sdk, stripe-alternative

## 简介

PlutoPay PHP SDK — accept card, ACH, terminal, and hosted-checkout payments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
