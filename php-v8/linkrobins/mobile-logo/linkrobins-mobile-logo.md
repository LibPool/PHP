# linkrobins/mobile-logo

> 标签: branding, flarum, header, logo, mobile

## 简介

Puts your forum's logo in the mobile navigation bar, where phone users otherwise see only a menu button.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
