# linkrobins/flarum-warble

> 标签: flarum, polling, realtime, shared hosting, warble

## 简介

Realtime for Flarum with no server to run. Makes flarum/realtime work on any hosting, including shared hosting, by polling instead of a websocket.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
