# peroks/api-server

> 标签: api-server, event-dispatcher, psr-14, psr-15, psr-7, request-handler, rest-server, server-handler, server-middleware

## 简介

An ultra-light api server based on PSR-7, PSR-14 and PSR-15 best-practice standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
