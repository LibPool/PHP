# denis156/fcm-notification

> 标签: PHP

## 简介

Plugin NativePHP untuk integrasi Firebase Cloud Messaging (FCM) dan pengambilan token notifikasi perangkat.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
