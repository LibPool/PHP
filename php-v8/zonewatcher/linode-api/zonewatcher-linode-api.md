# zonewatcher/linode-api

> 标签: api, linode, rest, sdk

## 简介

An OpenAPI generated wrapper for the Linode V4 API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.linode.com/docs/api/
- 源码仓库：https://github.com/zonewatcher/linode-api.git
- Packagist 页面：https://packagist.org/packages/zonewatcher%2Flinode-api
