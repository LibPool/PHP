# wireblob/wire

> 标签: Socket, events, messaging, publish, push, real time, real-time, realtime, trigger, wire, wire-php-sdk, wireblob

## 简介

Library for interacting with the Wireblob Socket API, providing real-time messaging and event handling capabilities.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
