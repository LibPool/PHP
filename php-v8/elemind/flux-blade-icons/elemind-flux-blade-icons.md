# elemind/flux-blade-icons

> 标签: blade-icons, flux, icons, laravel, svg

## 简介

Import third-party Blade icon packages into Flux by generating Flux-compatible Blade icon views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
