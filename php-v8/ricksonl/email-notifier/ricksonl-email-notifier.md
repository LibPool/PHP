# ricksonl/email-notifier

> 标签: PHP

## 简介

Pacote responsável pelo envio automatizado de e-mails de sucesso ou erro para cada aplicação executada no servidor da Hypersoft.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
