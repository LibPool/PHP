# unquam/nette-maker

> 标签: artisan, cli, code-generator, form-request, generator, maker, migration, nette, nette-api, nette-framework, nette-maker, nette-migration, presenter, repository, scaffolding, service

## 简介

CLI code generator for Nette Framework: scaffold modules, migrations, seeders, factories, authentication, API resources, form requests and more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
