# lkwdwrd/wp-muplugin-loader

> 标签: loader, muplugin, wordpress

## 简介

A drop-in MU Plugin loader for WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
