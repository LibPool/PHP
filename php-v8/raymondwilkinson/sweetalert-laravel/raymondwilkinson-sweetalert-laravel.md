# raymondwilkinson/sweetalert-laravel

> 标签: alerts, flash messages, laravel, sweetalert

## 简介

Simple way to flash sweetalert messages to the screen for laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
