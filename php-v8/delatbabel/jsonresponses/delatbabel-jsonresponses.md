# delatbabel/jsonresponses

> 标签: api, json, laravel, laravel5

## 简介

A trait containing common JSON responses for an API built with Laravel 5.1.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
