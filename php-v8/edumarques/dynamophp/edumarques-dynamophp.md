# edumarques/dynamophp

> 标签: PHP

## 简介

DynamoPHP is a lightweight, strongly-typed Object Data Mapper designed to simplify development with Amazon DynamoDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
