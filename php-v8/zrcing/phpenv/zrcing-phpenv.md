# zrcing/phpenv

> 标签: env, getenv, phpenv, server

## 简介

Easy to load system enivronment configuration from $_ENV,$_SERVER,getenv.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
