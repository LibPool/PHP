# jetstreamlabs/jetstreampro

> 标签: framework, laravel, semantic-release, unplugin, vite, vue 3

## 简介

Laravel Jetstream Professional. Includes Vite, Unplugin, Semantic-Release, Github-Actions and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
