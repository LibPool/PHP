# jetstreamlabs/snowflake

> 标签: laravel snowflake, php snowflake, snowflake algorithm

## 简介

An ID Generator for PHP based on Snowflake Algorithm (Twitter announced).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
