# amosoft/mailjet-apiv3-php

> 标签: Mailjet, api, email, php, v3

## 简介

PHP 5.3 wrapper for the Mailjet API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
