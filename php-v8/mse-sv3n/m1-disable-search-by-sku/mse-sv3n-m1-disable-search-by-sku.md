# mse-sv3n/m1-disable-search-by-sku

> 标签: PHP

## 简介

This extension adds availability to disable search by SKU, even when SKU is globally set to searchable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
