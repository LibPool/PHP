# wuemv/content-sdk-php

> 标签: cms, content, headless-cms, laravel, php, sdk, wue

## 简介

Official PHP SDK for the Wue CMS — typed client for content, media, submissions, and apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
