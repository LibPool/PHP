# goaop/goaop-zend-expressive-middleware

> 标签: expressive, goaop, middleware, zend

## 简介

An Zend Expressive middleware for loading goaop aspects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
