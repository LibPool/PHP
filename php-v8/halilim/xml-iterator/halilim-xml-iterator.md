# halilim/xml-iterator

> 标签: SimpleXML, XMLReader, iterator, xml

## 简介

XML Reader to simplexml/array iterator with low memory usage and an acceptable level of ease of use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
