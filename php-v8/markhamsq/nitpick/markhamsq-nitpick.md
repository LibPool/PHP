# markhamsq/nitpick

> 标签: laravel, manual-testing, markhamsq, nitpick, qa, testing

## 简介

A local QA panel for Laravel: scenarios, one-click persona login and reset, checklists, captured mail, and round reports that an agent can read.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
