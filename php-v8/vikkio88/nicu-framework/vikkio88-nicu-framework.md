# vikkio88/nicu-framework

> 标签: Microservice, microframework, mvp, php-di, rest, slim

## 简介

a small framework (built on slim + php-di) to create restful api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
