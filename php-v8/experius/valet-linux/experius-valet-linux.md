# experius/valet-linux

> 标签: arch, fedora, laravel, linux, ubuntu, valet, wwdhhd, zonda

## 简介

A more enjoyable local development experience for Linux.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
