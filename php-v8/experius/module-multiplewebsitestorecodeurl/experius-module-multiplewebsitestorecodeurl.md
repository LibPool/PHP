# experius/module-multiplewebsitestorecodeurl

> 标签: PHP

## 简介

This module enabled you to use the same store_code multiple times for different websites in the url.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
