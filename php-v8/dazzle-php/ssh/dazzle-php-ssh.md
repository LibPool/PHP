# dazzle-php/ssh

> 标签: async, asynchronous, driver, kraken, kraken-php, ssh, ssh2

## 简介

Kraken Asynchronous SSH.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
