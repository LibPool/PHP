# logforge/logforge-laravel

> 标签: Audit, activity-log, compliance, laravel, logging

## 简介

LogForge: Unified audit logging for Laravel (create/update/delete with diffs, actor, context).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
