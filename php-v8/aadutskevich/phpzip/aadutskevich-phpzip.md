# aadutskevich/phpzip

> 标签: archive, compressed, compression, phpzip, pkzip, stream, zip

## 简介

Package to create and stream archives of compressed files in ZIP format with PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
