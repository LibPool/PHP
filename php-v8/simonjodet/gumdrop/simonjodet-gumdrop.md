# simonjodet/gumdrop

> 标签: generator, markdown, twig

## 简介

Gumdrop is a static website generator converting Markdown files and using the Twig templating engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
