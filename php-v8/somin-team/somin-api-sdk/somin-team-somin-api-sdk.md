# somin-team/somin-api-sdk

> 标签: api, multimedia analytics, sdk, social, somin

## 简介

SoMin API SDK is a PHP library for making calls to SoMin API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
