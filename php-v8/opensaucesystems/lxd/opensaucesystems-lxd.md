# opensaucesystems/lxd

> 标签: OpenSauceSystems, api, client, lxd, wrapper

## 简介

PHP-based API wrapper for LXD REST API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
