# mantix/livewire-jodit-text-editor

> 标签: editor, livewire, wysiwyg

## 简介

A powerful Livewire rich text editor (WYSIWYG) component built top of Jodit Editor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
