# gtmassey/thread

> 标签: String helpers, Thread, gtmassey, library, php, string manipulation, strings

## 简介

A framework-agnostic helper library for easily manipulating Strings in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
