# broadcast/broadcast-php

> 标签: Broadcast, email, email-marketing, newsletter, sendbroadcast, transactional

## 简介

PHP client for the Broadcast email platform. Subscribers, sequences, broadcasts, segments, templates, autopilot, webhooks, and transactional email.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
