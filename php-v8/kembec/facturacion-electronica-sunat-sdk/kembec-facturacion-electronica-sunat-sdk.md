# kembec/facturacion-electronica-sunat-sdk

> 标签: einvoicing, factura electronica, facturación electrónica, peru, php, sunat, ubl, xmldsig

## 简介

PHP client for the sunat-sdk binary: build, sign, zip, send and query SUNAT (Peru) electronic vouchers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
