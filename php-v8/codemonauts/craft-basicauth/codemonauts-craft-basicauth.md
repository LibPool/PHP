# codemonauts/craft-basicauth

> 标签: Craft, cms, craft-plugin, craftcms

## 简介

Craft CMS plugin for HTTP Basic Authentication within templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
