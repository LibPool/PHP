# codemonauts/craft-shortener

> 标签: Craft, cms, craft-plugin, craftcms, link, qrcode, shortener

## 简介

An URL Shortener for Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
