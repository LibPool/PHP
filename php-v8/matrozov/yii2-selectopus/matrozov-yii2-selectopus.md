# matrozov/yii2-selectopus

> 标签: jquery, multiple, select, selectopus, tag, widget, yii, yii 2, yii2

## 简介

Selectopus is a jQuery based replacement for select boxes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
