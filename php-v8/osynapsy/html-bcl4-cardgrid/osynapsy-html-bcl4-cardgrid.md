# osynapsy/html-bcl4-cardgrid

> 标签: Cardgrid component, Osynapsy

## 简介

Transforms data collections into a responsive Bootstrap 4 card grid, offering a modern alternative to classic table-based data views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
