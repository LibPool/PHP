# osynapsy/mailer

> 标签: ai, library

## 简介

Less code, more control. A clean, backend-driven mailer for PHP — modular, debuggable, and ready for your own delivery clients.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
