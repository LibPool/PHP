# laratribe/native-wheel-datepicker

> 标签: date-picker, edge, nativephp, nativephp-plugin, wheel-picker

## 简介

A wheel date picker EDGE component for NativePHP Mobile v4 (SwiftUI + Jetpack Compose).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
