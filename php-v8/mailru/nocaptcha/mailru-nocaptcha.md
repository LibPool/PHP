# mailru/nocaptcha

> 标签: antispam, captcha, mailru, nocaptcha

## 简介

PHP module for working with Nocaptcha Mail.Ru service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://nocaptcha.mail.ru
- 源码仓库：https://github.com/mailru/nocaptcha-php.git
- Packagist 页面：https://packagist.org/packages/mailru%2Fnocaptcha
