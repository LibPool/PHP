# smpackbuilder/laravel-payammatni-sms

> 标签: iran, laravel, payammatni, payammatni panel, persian, sms, soap, پیام متنی, پیامک

## 简介

Laravel package for sending SMS and checking credit / delivery status through the Payammatni (payammatni.com) SOAP SMS panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
