# gorankrgovic/larablog

> 标签: blog, larablog, laravel

## 简介

Larablog is simple but yet powerful Blog package for the Laravel 5.6 and up.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
