# ogidimitrov/diff

> 标签: Match, bitap, diff, diff-match-patch, fuzzy-search, myers, patch

## 简介

Character-based diff, fuzzy matching and unidiff-style patching for PHP, in the spirit of Google's Diff Match and Patch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
