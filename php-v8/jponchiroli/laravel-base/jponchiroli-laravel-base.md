# jponchiroli/laravel-base

> 标签: api, base, generator, i18n, laravel, resource, scaffolding, validation

## 简介

Base classes, standardized JSON responses with i18n messages (en, pt_BR) and a make:domain generator for Laravel API domains.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
