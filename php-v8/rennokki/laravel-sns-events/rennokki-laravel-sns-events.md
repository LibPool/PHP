# rennokki/laravel-sns-events

> 标签: laravel

## 简介

Laravel SNS Events eases the processing of incoming SNS webhooks using Laravel Events.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
