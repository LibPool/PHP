# inertiapixel/laravel-log-viewer

> 标签: dashboard, inertiapixel, laravel, log-viewer, logs, monolog

## 简介

InertiaPixel Laravel Log Viewer: a secure, read-only log dashboard for Laravel with search, filters, date ranges and charts. No npm or build step required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
