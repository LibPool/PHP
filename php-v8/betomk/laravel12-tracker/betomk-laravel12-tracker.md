# betomk/laravel12-tracker

> 标签: laravel, logging, mobile detection, pragmarx, tracker, tracking, user agent, visitor

## 简介

A Laravel Visitor Tracker for Laravel 12 - Tracking-only fork of deivide/laravel-tracker (pragmarx/tracker). Stats panel / Datatables removed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
