# hehex/hehep-hrouter

> 标签: PHP

## 简介

hehep-hrouter 是一个PHP路由基础组件,支持注释注解,PHP8原生注解,支持分组路由,支持key/value结构存储路由,支持合并路由解析操作,支持路由缓存,快速定位路由，提高匹配效率

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
