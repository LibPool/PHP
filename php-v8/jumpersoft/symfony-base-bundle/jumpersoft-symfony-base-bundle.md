# jumpersoft/symfony-base-bundle

> 标签: base-bundle, jumpersoft, symfony

## 简介

Symfony base bundle, contains general classes, controls and templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
