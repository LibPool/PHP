# goognet/blade-pint

> 标签: Pint, blade, formatter, html, laravel, prettier

## 简介

Makes Laravel Pint print plain HTML void elements in Blade views, without changing how you run Pint.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
