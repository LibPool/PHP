# goognet/vite-plain-html

> 标签: blade, html, laravel, vite

## 简介

Makes Laravel's Vite helper emit plain HTML link tags, without the XHTML style slash.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
