# goognet/ui

> 标签: blade, components, laravel, tailwindcss, ui

## 简介

Biblioteca de componentes Blade da Goognet para Laravel e Tailwind CSS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
