# hahadu/phpquery-single-cpoy

> 标签: PHP

## 简介

phpQuery单文件版本，是Querylist的依赖(http://querylist.cc/)，phpQuery项目主页:http://code.google.com/p/phpquery/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
