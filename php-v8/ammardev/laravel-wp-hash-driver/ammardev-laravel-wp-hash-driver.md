# ammardev/laravel-wp-hash-driver

> 标签: hash, hashing, laravel, passwords, wordpress

## 简介

Supports Wordpress passwords hashing and checking in Laravel's Hash facade.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
