# muensmedia/timeable

> 标签: Neos, flow, neoscms, timeable

## 简介

Muensmedia.Timeable is a package which enhances the usability of the official Neos.TimeableNodeVisibility package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
