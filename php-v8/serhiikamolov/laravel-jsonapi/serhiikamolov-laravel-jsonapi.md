# serhiikamolov/laravel-jsonapi

> 标签: PHP

## 简介

A set of interfaces and classes to facilitate the construction of an efficient Json Api application with the Laravel framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
