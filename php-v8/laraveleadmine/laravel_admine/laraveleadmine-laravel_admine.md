# laraveleadmine/laravel_admine

> 标签: Authentication, admin, breeze, captcha, laravel

## 简介

Laravel admin starter with login by username, puzzle CAPTCHA and user management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
