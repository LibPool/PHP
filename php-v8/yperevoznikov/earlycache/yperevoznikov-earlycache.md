# yperevoznikov/earlycache

> 标签: cache, page cache

## 简介

Implements early cache for web apps without dependencies. Caches entire page with headers and response code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
