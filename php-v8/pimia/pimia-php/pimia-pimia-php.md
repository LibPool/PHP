# pimia/pimia-php

> 标签: facturacion, oauth, pimia, sdk, verifactu

## 简介

Cliente PHP de la API de Pimia para apps de partner: OAuth con PKCE, rotación de refresh persistida, reintentos de rate limit y excepciones tipadas.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
