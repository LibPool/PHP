# khaledalam/unit

> 标签: dimensional-analysis, imperial, measurement, metric, physics, quantities, quantity, si-units, unit-conversion, units

## 简介

A lightweight, type-safe PHP library for units, quantities, and dimensional analysis with automatic conversion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
