# halloverden/symfony-scheduled-task-bundle

> 标签: Messenger, cron, job, schedule, symfony, task

## 简介

Enables the creation of cron-jobs tasks to be consumed by symfony/messenger

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
