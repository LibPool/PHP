# halloverden/symfony-brreg-http-client

> 标签: api, brreg, client, http, register, rest

## 简介

Provides a Symfony http client for the brreg (Brønnøysundregistrene) api

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
