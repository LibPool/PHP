# cliqthemes/log-lens

> 标签: error-monitoring, error-tracking, horizon, laravel, log-viewer, logs, self-hosted

## 简介

Laravel adapter for Log Lens — mount the dashboard and JSON API inside a Laravel app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
