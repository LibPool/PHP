# milzer/laravel-http-logger

> 标签: http, laravel, logging, middleware, request-logging, saloon, saloon-plugin, trace

## 简介

Structured, redacted logging of HTTP traffic in Laravel: incoming requests and outgoing Saloon calls, with one shared trace id.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
