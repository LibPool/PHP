# beecubu/php-foundation-helpers

> 标签: PHP

## 简介

Some basic helpers for Arrays, Strings, Dates, CSVs, HTMLs, etc…

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
