# beecubu/php-foundation-emailer

> 标签: PHP

## 简介

PHP Object Foundation Framework Emailer library for SMTP, EWS and Microsoft Graph

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
