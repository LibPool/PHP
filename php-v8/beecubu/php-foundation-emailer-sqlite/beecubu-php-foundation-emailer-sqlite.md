# beecubu/php-foundation-emailer-sqlite

> 标签: PHP

## 简介

SQLite persistence plugin for php-foundation-emailer. Provides the email queue repository backed by SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
