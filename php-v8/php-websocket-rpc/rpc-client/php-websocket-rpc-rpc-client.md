# php-websocket-rpc/rpc-client

> 标签: amphp, async, client, msgpack, proxy, rpc, websocket

## 简介

Async RPC client over WebSocket using amphp and msgpack

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
