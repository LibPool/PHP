# php-websocket-rpc/rpc-server

> 标签: amphp, async, msgpack, rate-limiter, rpc, server, websocket

## 简介

Async RPC server over WebSocket using amphp and msgpack

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
