# amyr-it/siat-bolivia-client

> 标签: PHP

## 简介

Biblioteca de cliente PHP para la integración con el servicio de facturación SIAT de Impuestos Nacionales de Bolivia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
