# gowelle/laravel-beem-africa

> 标签: addressbook, africa, airtime, beem, beem-africa, checkout, collections, contacts, disbursements, global-sms, international-sms, laravel, messaging, mobile-money, moja, otp, payment, sms, tanzania, whatsapp

## 简介

Laravel package for Beem API integration - SMS, Airtime, OTP, Payment Checkout, Disbursements, Collections, USSD, Contacts, Moja, and International SMS services

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
