# gowelle/laravel-route-matrix

> 标签: api, compute-routes, directions, google, laravel, maps, routes

## 简介

A Laravel wrapper package for Google Routes API (Compute Routes)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
