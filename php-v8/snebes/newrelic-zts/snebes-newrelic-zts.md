# snebes/newrelic-zts

> 标签: apm, extension, frankenphp, newrelic, zts

## 简介

Unofficial ZTS (thread-safe) build of the New Relic PHP agent extension for FrankenPHP and other ZTS PHP runtimes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
