# ashallendesign/short-url

> 标签: URL-Shortener, ashallendesign, laravel, laravel-package, short-urls

## 简介

A Laravel package for creating shortened URLs for your web apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
