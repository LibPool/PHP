# wpoets/code-handler

> 标签:  Awesome Enterprise, Low Code, shortcode, wordpress

## 简介

Instead of executing it outputs the code of Awesome enterprise modules.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
