# wpoets/jwt-handler

> 标签:  Awesome Enterprise, Low Code, jwt, shortcode, wordpress

## 简介

Handler for JWT token creation using jwt-firebase in Awesome Enterprise

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
