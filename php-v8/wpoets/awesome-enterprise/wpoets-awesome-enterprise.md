# wpoets/awesome-enterprise

> 标签:  Awesome Enterprise, Low Code, shortcode, wordpress

## 简介

The Awesome Enterprise Framework for low code development in PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
