# kybdev/lara-ai-assistant

> 标签: ai, assistant, eloquent, laravel, mcp, retrieval

## 简介

A reusable Laravel AI Assistant package for model discovery, authorized data retrieval, and safe AI tool integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
