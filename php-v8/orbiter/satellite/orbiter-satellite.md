# orbiter/satellite

> 标签: PHP

## 简介

PHP Event Dispatcher with listener and PSR-14 dispatcher, compatible with PSR-11 container and custom invokers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
