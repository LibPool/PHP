# triangle/oauth

> 标签: Authentication, OpenId, api, apple, authorization, facebook, google, identity, library, localzet, login, oauth, oauth2, security, social, twitter

## 简介

Triangle OAuth Plugin - это мощный плагин для OAuth-аутентификации, поддерживающий множество популярных провайдеров, таких как Google, Facebook, Twitter и Apple.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
