# gobtcpay/php-merchant-sdk

> 标签: bitcoin, gobtcpay, payments, pos, sdk, webhooks

## 简介

PHP client for the GoBTC Pay POS & merchant API — create Bitcoin payments, verify webhooks, and poll for settlement.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
