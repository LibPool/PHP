# bethinkpl/elastic-apm-laravel

> 标签: apm, debug, elastic, laravel, lumen, monitoring

## 简介

A package to integrate Elastic APM 7.x into Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
