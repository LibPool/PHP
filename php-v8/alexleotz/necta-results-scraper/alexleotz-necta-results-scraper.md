# alexleotz/necta-results-scraper

> 标签: Education data management, NECTA data access, NECTA integration, Tanzania examination council, Tanzanian education, Tanzanian educational statistics, Tanzanian exam results, Tanzanian school system, necta, necta api, necta results

## 简介

This package provides a PHP script that allows you to scrape students' results from the National Examinations Council of Tanzania (NECTA) website.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
