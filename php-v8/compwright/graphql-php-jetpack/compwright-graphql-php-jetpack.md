# compwright/graphql-php-jetpack

> 标签: directive, graphql, php, scalar

## 简介

Easily enable support for custom scalars and directives with https://github.com/webonyx/graphql-php

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
