# edumicro/daisyblade

> 标签: DaisyUI, alpinejs, blade, components, laravel, tailwind

## 简介

Pure Blade + Alpine.js UI components for Laravel ERP/CRM. DaisyUI styled.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
