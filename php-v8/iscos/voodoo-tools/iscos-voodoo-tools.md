# iscos/voodoo-tools

> 标签: Webp, auth, crop, image, login, php, tools, validation, watermark

## 简介

Voodoo Tools — ferramentas de reuso para quem programa PHP sem framework: Image (crop com posicionamento, WebP, marca d'agua), Validator e Auth (login + esqueci minha senha). Zero dependencias (so ext-gd).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
