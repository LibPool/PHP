# gammadia/voilab-slim-i18n

> 标签: PHP

## 简介

Partial split fork (contains only i18n related files) of voilab/slim-extensions with support for modern PHP versions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
