# ssbityukov/laravel-balance-engine

> 标签: Accounting, balance, double-entry, laravel, ledger, money, wallet

## 简介

Double-entry ledger for Laravel: race-safe deposits, withdrawals, transfers and reservations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
