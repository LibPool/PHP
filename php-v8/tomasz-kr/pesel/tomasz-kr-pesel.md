# tomasz-kr/pesel

> 标签: pesel, php, validation

## 简介

Obiekt PESEL, możliwość: walidacji, ustawienie zakresu roku poprawnych peseli, wyciągnięcia danych jakie znajdują się m.in data urodzenia, płeć

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
