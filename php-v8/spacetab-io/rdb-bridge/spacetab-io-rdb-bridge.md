# spacetab-io/rdb-bridge

> 标签: PHP

## 简介

Rdb bridge (spacetab-io/rdb) to use migration and seed commands with our configuration (spacetab-io/configuration).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
