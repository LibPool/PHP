# sematico/laravel-inertia-i18n

> 标签: i18n, inertia, laravel, localization, react, translations

## 简介

Bridge Laravel JSON translations with React apps built on Inertia.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
