# robwdwd/svg-icon-bundle

> 标签: Bootstrap Icons, icon, materialdesign icons, mdi, svg, symfony

## 简介

SVG Icon bundle for inserting SVG HTML Markup from SVG Icon files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
