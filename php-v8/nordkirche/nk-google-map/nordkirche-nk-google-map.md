# nordkirche/nk-google-map

> 标签: PHP

## 简介

TYPO3 Extension für die Darstellung von Karten mit Markern aus der NAPI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
