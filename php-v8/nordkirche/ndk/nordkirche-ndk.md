# nordkirche/ndk

> 标签: PHP

## 简介

Das NDK unterstützt bei der Entwicklung von PHP-Clients, um die Datenbank der Nordkirche anzubinden

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
