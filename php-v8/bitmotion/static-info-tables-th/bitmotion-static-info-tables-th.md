# bitmotion/static-info-tables-th

> 标签: PHP

## 简介

Thai (th) language pack for the Static Info Tables providing localized names for countries, currencies and so on.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
