# bitmotion/custom-error-page

> 标签: 403, 404, 503, error handling

## 简介

Shows custom 403/404/503 page depending on domain/language/current tree...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
