# bitmotion/bm-image-gallery

> 标签: extension, gallery, images, lightbox, typo3, videos

## 简介

Simple gallery using FileCollections.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
