# bitmotion/auth0

> 标签: SSO, auth0, login, typo3, user

## 简介

Auth0 for TYPO3 - Auth0 is the solution you need for web, mobile, IoT, and internal applications. Loved by developers and trusted by enterprises.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
