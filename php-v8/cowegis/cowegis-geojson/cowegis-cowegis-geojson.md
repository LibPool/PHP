# cowegis/cowegis-geojson

> 标签: geosjon, gis, webgis

## 简介

Cowegis GeoJSON - PHP GeoJSON specification (RFC 7946) implementation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
