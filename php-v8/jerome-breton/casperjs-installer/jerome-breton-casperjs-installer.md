# jerome-breton/casperjs-installer

> 标签: binaries, casperJs, headless, phantomjs

## 简介

A Composer package which installs the CasperJS binary for your project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
