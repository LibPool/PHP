# suncat/php-mobile-detect

> 标签: mobile, mobile detect, mobile detector, mobile device

## 简介

Lightweight PHP class for detecting mobile devices

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
