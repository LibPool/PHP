# pantheon-systems/wordpress-bedrock-integrations

> 标签: PHP

## 简介

Add this project to any WordPress install based on pantheon-systems/wordpress-bedrock-recommend to enable it for use on Pantheon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
