# pantheon-systems/pantheon-content-publisher-wordpress

> 标签: plugin, wordpress

## 简介

Publish WordPress content from Google Docs with Pantheon Content Cloud.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
