# pantheon-systems/quicksilver-pushback

> 标签: PHP

## 简介

Push commits made via the Pantheon dashboard back to original GitHub repository.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
