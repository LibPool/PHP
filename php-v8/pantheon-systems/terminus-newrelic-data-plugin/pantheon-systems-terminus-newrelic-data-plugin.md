# pantheon-systems/terminus-newrelic-data-plugin

> 标签: PHP

## 简介

Terminus Plugin that fetches metric data from new relic api and display via console

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
