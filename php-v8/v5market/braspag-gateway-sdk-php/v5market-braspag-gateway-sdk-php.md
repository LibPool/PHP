# v5market/braspag-gateway-sdk-php

> 标签: braspag

## 简介

Este SDK tem o objetivo de facilitar a integração de aplicações PHP com a solução de pagamento Pagador da Braspag.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
