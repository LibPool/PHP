# fakturnaut/sdk

> 标签: E-Invoice, EN16931, ZUGFeRD, e-factura, peppol, xrechnung

## 简介

Fakturnaut API client: issue, validate, deliver and check EN 16931 e-invoices (XRechnung, ZUGFeRD, RO e-Factura).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
