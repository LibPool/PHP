# pup/placeholderapi

> 标签: api, placeholder, plugin, pmmp, pocketmine, virion

## 简介

A simple and efficient placeholder system for PocketMine-MP. Originally created for the Kyro core.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
