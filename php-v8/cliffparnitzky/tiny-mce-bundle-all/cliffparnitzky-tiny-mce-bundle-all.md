# cliffparnitzky/tiny-mce-bundle-all

> 标签: bundle, contao, metapackage, tiny editor, tinymce, tinymce all, tinymce bundle, tinymce4

## 简介

Installs the TinyMCE plugin loader and all available plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
