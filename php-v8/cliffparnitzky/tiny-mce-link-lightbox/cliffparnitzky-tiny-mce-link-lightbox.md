# cliffparnitzky/tiny-mce-link-lightbox

> 标签: contao, link, link lightbox, tiny editor, tinymce, tinymce plugin, tinymce4

## 简介

Special TinyMCE plugin to set the rel attribute in the link dialog for opening links in a lightbox.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
