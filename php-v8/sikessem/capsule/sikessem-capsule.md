> 标签: accessor, capsule, container, dependency-injection, di, dic, encapsulation, encapsulator, event, getter, injector, ioc, method, mutator, php, property, psr, psr11, setter

## 简介

Capsule is designed to make it easier to manage dependencies and objects, while improving encapsulation and ensuring code quality.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
