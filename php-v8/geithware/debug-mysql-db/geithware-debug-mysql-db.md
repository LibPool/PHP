# geithware/debug-mysql-db

> 标签: debug, mysql, query, typo3

## 简介

Debug Mysql or other DB - Extends \TYPO3\CMS\Core\Database\Connection and \TYPO3\CMS\Typo3DbLegacy\Database\DatabaseConnection to show errors and debug messages. Debugging of SQL queries by debug and FileWriter. Useful for viewing and debugging of SQL queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
