# larapages/admin

> 标签: admin, backend, cms, laravel, panel

## 简介

An easy to implement, lightweight yet complete Laravel 5.5+ admin panel/backend and media/filemanager.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
