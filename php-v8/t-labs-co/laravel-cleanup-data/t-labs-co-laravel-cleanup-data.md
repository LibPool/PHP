# t-labs-co/laravel-cleanup-data

> 标签: anonymization, cleanup, compliance, data-protection, data-retention, gdpr, laravel, maintenance, pii, privacy, pruning, pseudonymization, right-to-be-forgotten

## 简介

GDPR-ready data retention, anonymization, and cleanup framework for Laravel — prune Eloquent models, pseudonymize PII fields, enforce retention policies, and schedule automated compliance operations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
