# t-labs-co/command-scheduler

> 标签: command-scheduler, cron, laravel, livewire, maryui, scheduler, t-labs-co, task-scheduling, ty-huynh

## 简介

Code-first command scheduling framework for Laravel — discover schedulable commands via PHP 8 attributes or interfaces, persist schedule definitions to database, enforce run windows, and control tasks via Livewire dashboard or CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
