# it-empower-solutions/security-headers

> 标签: content-security-policy, csp, http-headers, laravel, nonce, psr-15, security, symfony

## 简介

Génération moderne et configurable de headers HTTP de sécurité pour PHP, Laravel, Symfony et PSR-15.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
