# christianjbrown/api-client

> 标签: Guzzle, api, client, http, json, xml

## 简介

A thin, strongly-typed PHP 8.5+ client for JSON and XML APIs that wraps GuzzleHttp and normalizes its exceptions into a single, framework-agnostic hierarchy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
