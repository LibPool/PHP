# christianjbrown/code-quality-scripts

> 标签: code-quality, coding-standard, php-cs-fixer, phpcs, static-analysis

## 简介

An opinionated PHP_CodeSniffer standard and PHP CS Fixer rule sets (risky and safe), with shell wrappers, for keeping PHP projects to PSR, Symfony, PEAR and Generic standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
