# christianjbrown/met-office-weather-datahub-api-sdk

> 标签: api, client, coveragejson, edr, forecast, met-office, weather

## 简介

A strongly-typed PHP client for the Met Office Weather DataHub APIs (currently the Site-Specific / Global Spot forecast, the Site-Specific Blended Probabilistic Forecast, Observation (Land), Atmospheric Models, and Map Images), returning typed models instead of raw GeoJSON / CoverageJSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
