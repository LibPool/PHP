# christianjbrown/etsy-open-api-sdk

> 标签: api, client, ecommerce, etsy, open-api

## 简介

A strongly-typed PHP 8.5+ client for the Etsy Open API v3 that returns typed model objects instead of raw arrays, covering every read and write operation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
