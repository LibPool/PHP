# christianjbrown/oauth2-client

> 标签: access-token, client-credentials, oauth, oauth2, php, refresh-token

## 简介

A thin, strongly-typed PHP 8.5+ OAuth 2.0 client that manages access tokens (refresh-token and client-credentials grants), caching them behind a mockable key-value store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
