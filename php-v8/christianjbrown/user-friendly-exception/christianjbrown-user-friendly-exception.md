# christianjbrown/user-friendly-exception

> 标签: error-handling, exception, user-friendly

## 简介

A tiny PHP library providing a UserFriendlyException whose message is safe to display directly to end users.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
