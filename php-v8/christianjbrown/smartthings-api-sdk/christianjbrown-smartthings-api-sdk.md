# christianjbrown/smartthings-api-sdk

> 标签: api, client, home-automation, iot, smartthings

## 简介

A strongly-typed PHP 8.5+ client for the SmartThings API that returns typed model objects instead of raw arrays.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
