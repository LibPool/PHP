# christianjbrown/key-value-store

> 标签: configuration, doctrine, google-firestore, google-secret-manager, key-value, store

## 简介

A thin, strongly-typed PHP 8.5+ library of interchangeable key-value store implementations (database, Google Secret Manager, Google Firestore, in-memory) behind a single mockable interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
