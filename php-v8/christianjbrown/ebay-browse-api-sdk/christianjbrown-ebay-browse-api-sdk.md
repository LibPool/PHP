# christianjbrown/ebay-browse-api-sdk

> 标签: api, browse, client, ebay, ecommerce, marketplace

## 简介

A strongly-typed, read-only PHP 8.5+ client for the eBay Browse API that returns typed model objects instead of raw arrays.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
