# pyrrah/gravatar-bundle

> 标签: gravatar, gravatar symfony7, gravatar symfony8, picture gravatar, pyrrah

## 简介

The simple way to use Gravatar API for Symfony 7 and Symfony 8

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
