# alireza_malekei/peykad-sms

> 标签: driver, iran, laravel, peykad, sms, sms-gateway

## 简介

Peykad SMS: a driver-based SMS sending package for Laravel with support for bulk and scheduled messages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
