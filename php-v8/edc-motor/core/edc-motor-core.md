# edc-motor/core

> 标签: boardgame, edc-motor, laravel

## 简介

EdC Motor (Espadas de Ceniza Motor) — núcleo backend Laravel reutilizable para webs de juegos de mesa: auth y roles, contenido i18n, render a PNG, PDF recortables, CRM de páginas, configuración, usuarios y backup

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
