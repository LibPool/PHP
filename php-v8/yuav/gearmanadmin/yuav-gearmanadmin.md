# yuav/gearmanadmin

> 标签: admin, gearman, status

## 简介

Gearman admin library to get status and version, and list workers, set maxqueue or shutdown Gearman server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
