# mutebesi/safaricom-mpesa-php

> 标签: PHP

## 简介

A full-featured M-Pesa PHP SDK with advanced callback routing and proxy capabilities.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
