# infoway9/laravel-mpdf

> 标签: Laravel pdf, laravel, mpdf, pdf, php, php mpdf

## 简介

Generate PDF document in Laravel framework with this mPDF wrapper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
