# salla/ouath2-merchant

> 标签: authorisation, authorization, client, oauth, oauth2, salla

## 简介

Salla OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
