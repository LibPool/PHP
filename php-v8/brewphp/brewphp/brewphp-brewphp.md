# brewphp/brewphp

> 标签: admin, brewphp, django, framework, mvc, orm

## 简介

A small, Django-inspired PHP framework: easy to learn, readable core, zero runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://docs.brewphp.dev
- 源码仓库：https://github.com/brewphp/brewphp.git
- Packagist 页面：https://packagist.org/packages/brewphp%2Fbrewphp
