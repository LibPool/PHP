# brewphp/skeleton

> 标签: Skeleton, brewphp, framework, starter

## 简介

Starter project for BrewPHP, the small Django-inspired PHP framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://docs.brewphp.dev
- 源码仓库：https://github.com/brewphp/skeleton.git
- Packagist 页面：https://packagist.org/packages/brewphp%2Fskeleton

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require brewphp/skeleton`
- Packagist 仓库：https://repo.packagist.org/p2/brewphp/skeleton.json
- 许可证：MIT
- PHP 要求：>=8.2
