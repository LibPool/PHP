# hazardteam/autoclearchunk

> 标签: PHP

## 简介

A PocketMine-MP plugin that automatically clears chunks in specified worlds at regular intervals.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
