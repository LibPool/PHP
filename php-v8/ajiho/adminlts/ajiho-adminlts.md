# ajiho/adminlts

> 标签: JS, admin, back-end, bootstrap5, css, less, responsive, template, theme, web

## 简介

bootstrap-admin - Open source free background HTML template based on bootstrap 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
