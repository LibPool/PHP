# inbox/tld-extract

> 标签: TLDExtract, domain parser

## 简介

TLDExtract, library for extracting parts of domain, e.q. domain parser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
