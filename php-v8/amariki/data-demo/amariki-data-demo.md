# amariki/data-demo

> 标签: campaignchain

## 简介

Sample data that can be used to try CampaignChain or to demo it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.campaignchain.com
- 源码仓库：https://github.com/Amariki/data-demo.git
- Packagist 页面：https://packagist.org/packages/amariki%2Fdata-demo

- 当前版本：1.0.0-beta.4
