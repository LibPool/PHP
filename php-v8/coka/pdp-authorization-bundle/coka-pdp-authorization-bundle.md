# coka/pdp-authorization-bundle

> 标签: authorization, opa, pdp, pep, symfony, voter

## 简介

Symfony bundle providing fine-grained authorization using an external Policy Decision Point (PDP).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
