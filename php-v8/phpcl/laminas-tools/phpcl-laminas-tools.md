# phpcl/laminas-tools

> 标签: Zend Framework, laminas, phpcl, zf, zf3

## 简介

Create modules, controllers, controller-plugins, view helpers and factories for Laminas/ZF3 projects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
