# blue-energy/sendinblue-api-bundle

> 标签: api, bundle, sendinblue

## 简介

Official SendinBlue provided API V2 Symfony 2.x & 3.x Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
