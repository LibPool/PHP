# karls/media-bundle

> 标签: PHP

## 简介

Bundle for Unite-Cms. Provides a new Field Type for handling S3 Stored files select from Storage and save it right.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
