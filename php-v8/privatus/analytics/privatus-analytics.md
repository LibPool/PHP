# privatus/analytics

> 标签: analytics, blade, cookieless, laravel, privacy, privatus, symfony, twig

## 简介

Adds the cookieless Privatus Analytics tracking script to PHP, Laravel and Symfony/Twig apps. It only prints HTML and never sends data from your server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
