# freekrai/jolt-skeleton

> 标签: jolt, microframework, rest, router

## 简介

A Jolt Framework skeleton application for rapid development of Jolt apps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
