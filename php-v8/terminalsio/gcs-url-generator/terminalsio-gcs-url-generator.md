# terminalsio/gcs-url-generator

> 标签: PHP

## 简介

A laravel package for spatie medialibrary to extend UrlGenerator to support Google Cloud Platform

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
