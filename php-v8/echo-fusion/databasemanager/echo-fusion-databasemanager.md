# echo-fusion/databasemanager

> 标签: database, dbal, echoFusion, pdo, query-builder

## 简介

A small, replaceable database layer for EchoFusion: a PDO connection, a query builder, named connections and an optional Doctrine DBAL adapter, all behind one contract.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
