# echo-fusion/responsemanager

> 标签: echoFusion, json, psr-7, response

## 简介

PSR-7 HTML, JSON, XML and redirect response classes for the EchoFusion framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
