# echo-fusion/authmanager

> 标签: Authentication, auth, echoFusion, psr-15, session, token

## 简介

Authentication for EchoFusion: session and token guards, pluggable user providers and PSR-15 middleware. Depends only on echo-fusion/contracts and PSR interfaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
