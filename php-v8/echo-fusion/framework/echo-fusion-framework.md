# echo-fusion/framework

> 标签: PSR-11, echoFusion, framework, psr-14, psr-15, psr-7

## 简介

The EchoFusion framework: a kernel that boots configuration, modules, service providers, events and plugins and turns a PSR-7 request into a response, built from small replaceable packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
