# echo-fusion/templatemanager

> 标签: echoFusion, template, templates, twig, view

## 简介

Framework-independent template manager for EchoFusion: a built-in Twig/Smarty-style template language, plain PHP templates, and pluggable engines such as Twig through configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
