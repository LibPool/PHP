# echo-fusion/sessionmanager

> 标签: echoFusion, psr-15, session

## 简介

Session handling for the EchoFusion framework: native and in-memory sessions with flash messages, plus a PSR-15 middleware that starts the session.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
