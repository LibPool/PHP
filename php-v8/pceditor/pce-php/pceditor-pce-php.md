# pceditor/pce-php

> 标签: cms, editor, page-composer, renderer, templates

## 简介

Render Page Composer editor JSON to HTML using PHP/HTML templates, with CSS media-query compilation and caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
