# php-code-archeology/php-code-archeology

> 标签: analysis, architecture, code-metrics, code-quality, complexity, maintainability, mcp, php, qa, quality, static-analysis, technical-debt

## 简介

Static analyzer for PHP project archeology. Calculates various metrics for your codebase.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
