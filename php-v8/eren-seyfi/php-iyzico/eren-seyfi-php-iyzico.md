# eren-seyfi/php-iyzico

> 标签: iyzico, iyzipay, payment, php, subscription, turkey

## 简介

Unofficial, opinionated PHP helper library built on top of iyzico/iyzipay-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
