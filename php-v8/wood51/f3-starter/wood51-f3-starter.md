# wood51/f3-starter

> 标签: PHP

## 简介

Boilerplate Fat-Free Framework avec Tailwind CSS/HTMX/Hyperscript, Vite et Docker.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
