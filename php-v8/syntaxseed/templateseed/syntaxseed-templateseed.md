# syntaxseed/templateseed

> 标签: composer, package, template, templating, view

## 简介

Lightweight and simple templating class for PHP. Caching, and natural PHP template syntax.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
