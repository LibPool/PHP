# hydrafetch/hydrafetch

> 标签: crawler, hydrafetch, llm, markdown, rag, scraping, web-data

## 简介

Official PHP client for the Hydrafetch web data API. Turn any URL into clean Markdown and structured data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
