# johyunchol/php-gson2

> 标签: entity, gson, mapper

## 简介

PHP GSON equivalent - simple entity mapper. JSON to object and object to JSON. from archangeldesign/php-gson

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
