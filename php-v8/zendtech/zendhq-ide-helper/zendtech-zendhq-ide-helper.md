# zendtech/zendhq-ide-helper

> 标签: dev, zendhq

## 简介

Provides class stubs for ZendHQ classes to help with IDE completion when the ZendHQ extension is not installed

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
