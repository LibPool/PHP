# goodread/goodread

> 标签: PHP

## 简介

Doctest for markdown with comment-based assertions. Python/JavaScript/Ruby/PHP test runners and hackmd.io integration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
