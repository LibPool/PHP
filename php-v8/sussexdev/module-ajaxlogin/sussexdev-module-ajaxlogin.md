# sussexdev/module-ajaxlogin

> 标签: PHP

## 简介

A Magento 2 module that opens a modal enabling the customer to login when clicking on the Sign In top link.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
