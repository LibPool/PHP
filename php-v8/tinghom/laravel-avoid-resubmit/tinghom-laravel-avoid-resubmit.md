# tinghom/laravel-avoid-resubmit

> 标签: laravel, resubmit

## 简介

A package that is applied to Laravel to avoid resubmitting form data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
