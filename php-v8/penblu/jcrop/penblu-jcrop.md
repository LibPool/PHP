# penblu/jcrop

> 标签: extension, jcrop, yii2

## 简介

Extension creada por PenBlu para el uso de la libreria jquery-jcrop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
