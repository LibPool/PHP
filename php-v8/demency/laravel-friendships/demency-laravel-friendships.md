# demency/laravel-friendships

> 标签: eloquent, friend-system, friends, friendships, laravel

## 简介

This package gives Eloquent models the ability to manage their friendships.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
