# b44x/ksef-php

> 标签: E-Invoice, e-invoicing, fa3, invoice, ksef, poland, psr-18, xades

## 简介

Framework-agnostic PHP SDK for the Polish National e-Invoice System (KSeF) API 2.0: authentication, FA(3) invoices, online sessions, status polling and UPO retrieval.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
