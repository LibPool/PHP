# b44x/edoreczenia

> 标签: ade, e-delivery, e-doreczenia, edoreczenia, ezd, poland, psr-18, sdk

## 简介

Unofficial, framework-agnostic PHP SDK for the Polish e-Doręczenia (e-Delivery) APIs: signed-JWT system authentication, Search Engine API v4 and User Agent API v3 (mailbox, sending and receiving).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
