# sanjeev-kr/magento2-logrotation

> 标签: PHP

## 简介

magento 2 extension automatically and manually rotates and gzip-compresses Magento log files in the var/log directory.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
