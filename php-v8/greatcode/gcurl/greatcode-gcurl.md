# greatcode/gcurl

> 标签: antibot, cloudflare, curl, curl-impersonate, http2-fingerprint, ja3, ja4, php-ext, pie, scraper, tls-fingerprint

## 简介

Native PHP C extension and client wrapping libcurl-impersonate for browser fingerprint impersonation (TLS/HTTP2).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
