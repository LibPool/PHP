# xinadmin/laravel-attr-route

> 标签: annotation, attribute, laravel, route, routing, xin-admin, xinadmin

## 简介

使用 PHP 8 注解（Attributes）注册 Laravel 路由与 Sanctum 验证的轻量级组件

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
