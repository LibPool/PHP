# hintik-dev/oauth2-zcu

> 标签: Authentication, authorization, contributte, nette, oauth, oauth2, oidc, openid-connect, orion, shibboleth, zcu

## 简介

ZČU Orion (shib.zcu.cz) OpenID Connect provider for the PHP League's OAuth 2.0 Client, with optional Nette / Contributte integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
