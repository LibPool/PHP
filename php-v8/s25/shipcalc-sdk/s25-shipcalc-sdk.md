# s25/shipcalc-sdk

> 标签: PHP

## 简介

Calculate shipping rates, and get available service types and expected delivery time SDK for Shop25 shipping API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
