# s9y/serendipity

> 标签: blog, blogging, s9y, serendipity, serendipity-blog, weblog

## 简介

A reliable, secure & extensible PHP blog - Not mainstream since 2002

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
