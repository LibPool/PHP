# web-systems/gutenberg-bundle

> 标签: block-editor, bundle, cms, easyadmin, gutenberg, page-builder, symfony, wysiwyg

## 简介

Gutenberg (WordPress block editor) as a Symfony form field: visual page building, block storage, server-side rendering and PHP-defined custom blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
