# onex/laravel-azure-storage

> 标签: azure, laravel, storage

## 简介

Microsoft Azure Blob Storage integration for Laravel's Storage API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
