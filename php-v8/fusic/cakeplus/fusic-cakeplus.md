# fusic/cakeplus

> 标签: cakephp, validation

## 简介

[forked from ichikaway/cakeplus]Cake plus is cakephp plugin and provides some functions for CakePHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
