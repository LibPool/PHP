# brokeyourbike/uid-keys

> 标签: eloquent, laravel, php, ulid, uuid

## 简介

A simple drop-in solution for providing UUID and ULID support for the IDs of your Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
