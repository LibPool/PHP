# socialweb/rdf

> 标签: Canonicalization, Linked Data, RDF, n-quads, rdfc-1.0

## 简介

An RDF 1.1 library with N-Quads and RDF Dataset Canonicalization (RDFC-1.0)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
