# socialweb/http-message-signatures

> 标签: http, http-message-signatures, http-signatures, psr-7, rfc9421, signature

## 简介

Signs and verifies HTTP messages under RFC 9421 and draft-cavage-http-signatures-12

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
