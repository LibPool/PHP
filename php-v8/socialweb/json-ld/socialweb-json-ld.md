# socialweb/json-ld

> 标签: JSON-LD, Linked Data, RDF, expansion, json-ld-1.1

## 简介

A JSON-LD 1.1 processor for expansion and conversion to RDF

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
