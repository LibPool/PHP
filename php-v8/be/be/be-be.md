# be/be

> 标签: BE, Beyond Exception, php, 双驱框架

## 简介

PHP BE 双驱框架（Beyond Exception），支持普通PHP和Swoole两种方式部署，兼顾便捷与性能。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
