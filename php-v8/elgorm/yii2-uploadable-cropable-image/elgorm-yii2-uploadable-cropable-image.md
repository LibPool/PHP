# elgorm/yii2-uploadable-cropable-image

> 标签: Image upload, extension, image, image crop, jcrop, yii2

## 简介

Yii2 extension for upload and crop images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
