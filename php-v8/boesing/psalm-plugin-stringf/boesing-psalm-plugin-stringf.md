# boesing/psalm-plugin-stringf

> 标签: PHP

## 简介

Psalm plugin to work with `sprintf`, `printf`, `sscanf` and `fscanf`.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
