# slm/queue-amq

> 标签: active-mq, activeMQ, amq, job, queue, stomp, zf2

## 简介

Zend Framework 2 module that integrates with Active MQ queuing system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
