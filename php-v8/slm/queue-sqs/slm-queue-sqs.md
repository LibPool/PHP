# slm/queue-sqs

> 标签: amazon aws, job, queue, sqs, zf2

## 简介

Zend Framework 2 module that integrates with Amazon SQS queuing system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
