# ecentral/celum-connect-fal

> 标签: Asset Browser, DAM, File abstraction layer, NetX, assets, digital asset management, fairway, fal, file storage, images, typo3

## 简介

Integrates Celum Digital Asset Management with TYPO3 and provides direct access to centrally managed assets within the TYPO3 backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
