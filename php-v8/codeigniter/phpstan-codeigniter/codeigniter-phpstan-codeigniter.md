# codeigniter/phpstan-codeigniter

> 标签: PHPStan, codeigniter, codeigniter4, dev, static analysis

## 简介

CodeIgniter extensions and rules for PHPStan

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
