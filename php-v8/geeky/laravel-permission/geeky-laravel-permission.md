# geeky/laravel-permission

> 标签: acl, laravel, permission, security, spatie

## 简介

This is a fork of Spatia permission handling for Laravel 5.4 and up

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
