# codemax/tool-repository-json

> 标签: PHP

## 简介

El proyecta implementa un repositorio orientado a objetos, que persiste objetos en formato json a través de una interfaz CRUD.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
