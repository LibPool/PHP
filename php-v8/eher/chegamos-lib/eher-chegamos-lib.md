# eher/chegamos-lib

> 标签: PHP

## 简介

Core do Chegamos (https://github.com/EHER/chegamos) para ser usado em outros projetos :D

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
