# imsamurai/freebase-source

> 标签: cakephp, database, datasource, freebase, plugin

## 简介

Freebase (http://www.freebase.com/) source for CakePHP (HttpSource)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
