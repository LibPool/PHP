# yii1tech/i18n-fallback

> 标签: Yii1, fallback, i18n, language, locale, translation

## 简介

Provides support for Yii1 translation fallback to another message source

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
