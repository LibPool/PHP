# corvo-technology/corvo-nfse

> 标签: brazil, corvo, fiscal, invoice, nfse, nota-fiscal, sdk

## 简介

PHP SDK for the Corvo NFS-e API: issue Brazilian service invoices, calculate taxes, verify webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
