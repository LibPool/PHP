# zediz/frieren

> 标签: bucket, email, file-storage, php, phpmailer, utility

## 简介

Utilería PHP para manejo de archivos en bucket y envío de correos electrónicos.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
