# laravix/cms

> 标签: cms, content-management, filament, laravel, multi-tenant

## 简介

Laravix CMS core — a multi-tenant content management system built on Laravel and Filament.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
