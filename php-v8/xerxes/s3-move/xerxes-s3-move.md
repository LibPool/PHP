# xerxes/s3-move

> 标签: aws, cloud, file-migration, laravel, migration, s3, storage

## 简介

A Laravel package to migrate files from local storage to Amazon S3 with smart duplicate detection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
