# daxslab/yii2-calendly

> 标签: calendar, calendly, events, extension, schedule, yii2

## 简介

Embeds the Calendly widgets into Yii2 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
