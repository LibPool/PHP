# mopsyd/reflection-class-constant-patch

> 标签: PHP

## 简介

This is a backwards compatible patch of the PHP 7.1 ReflectionClassConstant for versions of PHP prior to 7.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
