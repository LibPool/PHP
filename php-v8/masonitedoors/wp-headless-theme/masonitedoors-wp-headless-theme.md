# masonitedoors/wp-headless-theme

> 标签: PHP

## 简介

This theme is intended to be used in a headless WordPress application with REST API logic offloaded to mu-plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
