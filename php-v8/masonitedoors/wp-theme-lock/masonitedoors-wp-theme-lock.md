# masonitedoors/wp-theme-lock

> 标签: PHP

## 简介

An mu-plugin that forces a WordPress theme to always be active. Requires https://github.com/masonitedoors/wp-headless-theme.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
