# masonitedoors/react-app-loader

> 标签: PHP

## 简介

An mu-plugin that provides an API for loading React applications built with create-react-app into the front-end of WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
