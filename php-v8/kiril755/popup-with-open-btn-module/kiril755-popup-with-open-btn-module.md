# kiril755/popup-with-open-btn-module

> 标签: PHP

## 简介

Magento 2 popup module, w/ open btn. Can chose image for open btn and add specific csm block for popup

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
