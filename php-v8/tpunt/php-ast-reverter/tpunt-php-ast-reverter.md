# tpunt/php-ast-reverter

> 标签: abstract syntax tree, ast, parse tree

## 简介

Reverts an AST back into (somewhat) PSR-compliant code

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
