# mindplay/sapi-host

> 标签: emitter, fcgi, front controller, host, http, psr-15, psr-17, psr-7, sapi

## 简介

FCGI SAPI host for dispatch of PSR-15 Handler

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
