# empye/empye-login-and-api

> 标签: PHP

## 简介

Official Magento2 Plugin login using social network, Qr Code and additional extended and simplified api features

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
