# nacholibre/coffee-cups

> 标签: CUPS, ipp, print, printer, printing

## 简介

A simple PHP library for CUPS IPP (Internet Printing Protocol) communication

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
