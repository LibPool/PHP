# birdsinthesun/fly_ux

> 标签: contao, drag, drop, fly_ux, media, tl_content, tl_files, wysiwyg

## 简介

Bindet eine Media-Kachel-Ansicht für Bilder ein zum schnellen Editieren von Bildern. Integriert eine Layout-Ansicht im Inhalts-Bereich mit Drag&Drop-Funktion. Ein individuelles Backend-Grid kann eingebunden werden. Entfernt die Artikel-Ebene in Contao CMS und optimiert die UX. Theme: https://packagist.org/packages/birdsinthesun/contao-theme-falke

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
