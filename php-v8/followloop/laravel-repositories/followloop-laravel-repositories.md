# followloop/laravel-repositories

> 标签: PHP

## 简介

A package that provides a neat implementation for integrating the Repository pattern with Laravel & Eloquent.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
