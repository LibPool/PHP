# mcfedr/awspushbundle

> 标签: FCM, SNS, amazon, apns, aws, bundle, c2dm, gcm, ios, notification, push, symfony

## 简介

A set of services to simplify using Aws to send push notifications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
