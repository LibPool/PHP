# jhorlima/wp-mocabonita

> 标签: mocabonita, plugin, uema, wordpress, wp-mocabonita

## 简介

Framework para desenvolvimento de plugins wordpress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
