# atldays/laravel-hashids

> 标签: atldays, hash, hashid, id, laravel

## 简介

Laravel Hashids package for generating short hashed identifiers for models and other numeric values.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
