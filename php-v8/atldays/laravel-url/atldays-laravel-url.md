# atldays/laravel-url

> 标签: browser-url, laravel, laravel-data, laravel-package, request-macros, spatie-url, url, url-sanitizer, url-validation, urls, value-object

## 简介

Laravel package for URL value objects, sanitization pipelines, browser URL support, validation rules, request macros, and Laravel Data integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
