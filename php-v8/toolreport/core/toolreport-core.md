# toolreport/core

> 标签: TCPDF, designer, dompdf, laravel, layout, pdf, report, templates

## 简介

PDF Designer for Laravel — template management, layout engine, dual PDF rendering (DomPDF + Composite TCPDF)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
