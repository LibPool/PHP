# netzhirsch/contao-mcp-bundle

> 标签: ai, automation, claude, contao, content-management, llm, mcp, model-context-protocol

## 简介

Connects Claude and other AI agents to Contao 5.3 LTS, 5.7 LTS and 6 via the Model Context Protocol — 196 MCP tools for pages, articles, news, files, templates, members, forms, newsletters and more, secured with OAuth 2.1 (PKCE + Dynamic Client Registration). Commercial extension: 30-day trial, then a subscription per Contao installation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
