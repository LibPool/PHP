# netwerkstatt/silverstripe-image-toolkit

> 标签: PHP

## 简介

A Silverstripe module with various image manipulations (Watermark, AutoOrient, ColorOverlay, etc.) via Intervention Image.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
