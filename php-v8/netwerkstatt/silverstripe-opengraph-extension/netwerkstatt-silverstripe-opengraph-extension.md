# netwerkstatt/silverstripe-opengraph-extension

> 标签: PHP

## 简介

Extends tractorcow/silverstripe-opengraph with better image handling (FocusPoint), Twitter cards, and Schema.org support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
