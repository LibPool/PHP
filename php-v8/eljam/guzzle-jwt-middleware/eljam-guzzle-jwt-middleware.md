# eljam/guzzle-jwt-middleware

> 标签: Guzzle, auth, guzzle6, handler, http, jwt, middleware, psr7

## 简介

A jwt authentication middleware for guzzle 6

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
