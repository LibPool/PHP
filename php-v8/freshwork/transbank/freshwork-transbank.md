# freshwork/transbank

> 标签: PHP

## 简介

SDK para webservices de transbank (Webpay Plus, Webpay OneClick, Webpay PatPass)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
