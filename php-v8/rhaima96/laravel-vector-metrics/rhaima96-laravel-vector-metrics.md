# rhaima96/laravel-vector-metrics

> 标签: embeddings, laravel, mariadb, pgvector, vector

## 简介

Euclidean and cosine vector distance queries and indexes for Laravel on MariaDB and Postgres.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
