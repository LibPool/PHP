# u2secured/u2auth

> 标签: PHP

## 简介

U2 Secured Authenticator SDK - push tap-to-approve two-factor auth, TOTP, and signed webhooks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
