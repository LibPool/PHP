# simkimsia/github-api-php-sdk

> 标签: PHP

## 简介

PHP SDK for GitHub API. Inspired by the facebook-php-sdk

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
