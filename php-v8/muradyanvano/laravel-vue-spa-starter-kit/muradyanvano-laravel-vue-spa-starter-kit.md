# muradyanvano/laravel-vue-spa-starter-kit

> 标签: SPA, fortify, laravel, passkeys, sanctum, starter-kit, typescript, vite, vue, vue-router, vue3, wayfinder, webauthn

## 简介

Laravel Vue SPA starter kit with Vue Router, Fortify, Sanctum, and passkeys — official-style UI without Inertia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
