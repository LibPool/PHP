# muradyanvano/php-lexorank

> 标签: drag-and-drop, eloquent, fractional-indexing, kanban, laravel, lexorank, ordering, ranking, sortable

## 简介

Production-ready LexoRank implementation for PHP — deterministic lexicographic ranking for ordered lists, Kanban boards, and drag-and-drop UIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
