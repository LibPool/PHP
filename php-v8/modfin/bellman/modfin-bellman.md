# modfin/bellman

> 标签: Gemini, ai, anthropic, bellman, embeddings, llm, openai

## 简介

PHP client for bellmand, the Bellman LLM proxy. One API key for OpenAI, Anthropic, Gemini, VoyageAI, Ollama and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
