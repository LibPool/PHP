# tastyigniter/ti-theme-orange

> 标签: orange, tastyigniter, theme

## 简介

Free Modern, Responsive and Clean TastyIgniter Theme based on Livewire and Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
