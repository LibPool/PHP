# askuri/muxconvert

> 标签: ManiaPlanet, Nadeo, ShootMania, TrackMania, convert, mux, ogg

## 简介

Convert Nadeo's .mux to .ogg files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
