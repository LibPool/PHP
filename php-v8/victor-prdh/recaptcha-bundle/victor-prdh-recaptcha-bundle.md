# victor-prdh/recaptcha-bundle

> 标签: PHP

## 简介

Use Google Recaptcha v2/v3 as form type with Symfony 6.4+, see v1.X for symfony 5.4

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
