# mirandaleyva/contao-architecture_references

> 标签: PHP

## 简介

Contao 5 module for managing and organizing architectural projects. Enables structured capture, storage, and management of project data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
