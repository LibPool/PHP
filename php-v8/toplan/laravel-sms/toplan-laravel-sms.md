# toplan/laravel-sms

> 标签: laravel, laravel-sms, mobile, phone, sms

## 简介

A mobile phone number validation solution based on laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
