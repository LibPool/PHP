# cysquale/plays-games-widget

> 标签: HTML5 games, engagement, game widget, games, infinite swipe, leaderboard, player rankings, scores, typo3

## 简介

Plays Games Widget - TikTok-style HTML5 game feed with player scores, leaderboards and personal rankings for TYPO3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
