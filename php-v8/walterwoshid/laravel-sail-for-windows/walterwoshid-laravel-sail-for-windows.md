# walterwoshid/laravel-sail-for-windows

> 标签: Powershell, laravel, sail, windows

## 简介

Windows (PowerShell) support for Laravel Sail on Windows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
