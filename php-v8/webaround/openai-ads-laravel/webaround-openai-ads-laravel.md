# webaround/openai-ads-laravel

> 标签: conversions-api, laravel, measurement, openai, openai-ads, pixel

## 简介

Laravel adapter for the OpenAI Ads toolkit: config, facade, queued delivery, request attribution and a Blade Pixel helper.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
