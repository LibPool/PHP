# webaround/openai-ads

> 标签: analytics, capi, conversions-api, measurement, openai, openai-ads

## 简介

OpenAI Ads measurement for PHP: typed events, identity normalization and the Conversions API. Framework-independent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
