# matthiasnoback/code-sniffer-sniff-dsl

> 标签: Coding Standard, DSL, code sniffer

## 简介

DSL for writing sniffs for PHP_CodeSniffer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
