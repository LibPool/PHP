# technote/gutenberg-packages

> 标签: gutenberg, wordpress

## 简介

Library to get gutenberg package info

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/technote-space/gutenberg-packages.git
