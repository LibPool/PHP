# technote/igo-php

> 标签: chasen, igo, morphological analysis, php

## 简介

Morphological analysis engine 'Igo' porting and changed for PHP 5.6 and composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
