# knutsv/flex-table

> 标签: Craft, cms, craft-plugin, craftcms, flextable

## 简介

This field type makes creating and editing tables in Craft a breeze.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
