# kalel1500/laravel-db-sync

> 标签: database, db, dbsync, laravel, loader, package, sync

## 简介

A Laravel package for syncing database tables and data across multiple connections.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
