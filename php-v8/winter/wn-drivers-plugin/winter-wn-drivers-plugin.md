# winter/wn-drivers-plugin

> 标签: cms, drivers, plugin, winter

## 简介

Winter CMS plugin integrating the AWS, Pheanstak, Iron MQ, Predis, Rackspace, and Guzzle drivers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
