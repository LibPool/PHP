# winter/wn-blocks-plugin

> 标签: block, blocks, builder, laravel, winter, wintercms

## 简介

Block based content management plugin for Winter CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
