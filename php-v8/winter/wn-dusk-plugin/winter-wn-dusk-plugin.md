# winter/wn-dusk-plugin

> 标签: browser, dusk, laravel, testing, winter, wintercms

## 简介

Integrates Laravel Dusk browser testing into Winter CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
