# winter/wn-octane-plugin

> 标签: cms, frankenphp, octane, performance, roadrunner, swoole, winter, worker

## 简介

Serves Winter CMS from a persistent application server (FrankenPHP, Swoole or RoadRunner) via Laravel Octane.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
