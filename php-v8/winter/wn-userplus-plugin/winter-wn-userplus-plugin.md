# winter/wn-userplus-plugin

> 标签: plugin, user, userplus, winter, winter cms

## 简介

Extends the Winter.User plugin for Winter CMS to add extra profile fields

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
