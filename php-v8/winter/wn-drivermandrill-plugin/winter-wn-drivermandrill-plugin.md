# winter/wn-drivermandrill-plugin

> 标签: driver, mail, mandrill, wintercms

## 简介

Driver that adds support for the Mandrill mailer to WinterCMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
