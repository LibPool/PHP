# euginepj/laravel-image-resizer

> 标签: Resizer, Webp, alpinejs, cropper, cropperjs, image, intervention-image, laravel

## 简介

Interactive image cropper and multi-format (WebP, JPEG, PNG, AVIF) converter package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
