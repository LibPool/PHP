# euginepj/laravel-password-strength

> 标签: entropy, laravel, password, password-strength, security, validation

## 简介

Comprehensive password strength analyzer, scoring engine, and validation rule package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
