# euginepj/laravel-api-logger

> 标签: api, dashboard, debugging, laravel, logger, middleware

## 简介

Global API request and response logging middleware with visual admin dashboard for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
