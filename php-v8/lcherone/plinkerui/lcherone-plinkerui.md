# lcherone/plinkerui

> 标签: PHP

## 简介

A little PHP script which is a demonstration usage for Plinker - Remote coded tasks run as root!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
