# subscribo/omnipay-subscribo-shared

> 标签: driver, omnipay, shared

## 简介

Package with shared functionality for some Omnipay payment processing library drivers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
