# roseshayan/form-guard

> 标签: IBAN, form, input-validation, iran, iranian, national-code, persian, php, sheba, validation, validator

## 简介

A lightweight, framework-agnostic PHP validation library with first-class Iranian form validation rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
