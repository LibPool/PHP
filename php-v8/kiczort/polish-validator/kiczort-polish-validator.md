# kiczort/polish-validator

> 标签: nip, pesel, pl validator, polish validator, regon, validator

## 简介

Validators for Polish identification numbers: PESEL, NIP, REGON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
