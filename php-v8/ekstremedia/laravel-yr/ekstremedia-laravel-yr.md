# ekstremedia/laravel-yr

> 标签: MET.no, forecast, laravel, norway, weather, yr

## 简介

A lightweight Laravel package for integrating weather data from Yr (api.met.no)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
