# pivot-pdf/pivot-pdf

> 标签: extension, pdf, pdf-generation, php-extension

## 简介

PHP stubs and installation guide for the pivot-pdf native PDF generation extension.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
