# xbyter/php-object-mapping

> 标签: bean, entity, mapping, object-fill, object-mapping, request

## 简介

PHP对象映射，可以将array/object映射为类对象。可做参数的传递、Request参数映射、Entity、Bean等

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
