# cleverage/filter-bundle

> 标签: datagrid, doctrine, filter, sort

## 简介

Simple yml-configuration-based filtering with Doctrine ORM abstraction

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
