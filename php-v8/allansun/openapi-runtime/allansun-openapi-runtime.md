# allansun/openapi-runtime

> 标签: docker, kubernetes, openapi, runtime, swagger

## 简介

Runtime library to be used with other SDK generated from OpenAPI docs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
