# guinee/eservice

> 标签: composer, dossier, eservice, guinee, partner, webhook

## 简介

eService partner PHP SDK — instruct dossiers via référence (sendMessage, sendDocument, requestDocuments, validAppointment).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
