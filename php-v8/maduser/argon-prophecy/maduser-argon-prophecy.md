# maduser/argon-prophecy

> 标签: PHP

## 简介

A strict, DI-first and PSR-compliant PHP runtime, for the law-abiding Prophets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
