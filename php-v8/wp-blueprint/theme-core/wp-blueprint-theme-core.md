# wp-blueprint/theme-core

> 标签: PHP

## 简介

WPBlueprint\Theme-Core: is serving as a core foundation and offering reusable functionalities for WordPress Themes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
