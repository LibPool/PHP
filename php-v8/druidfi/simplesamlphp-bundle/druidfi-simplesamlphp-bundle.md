# druidfi/simplesamlphp-bundle

> 标签: SSO, login, simplesamlphp, symfony

## 简介

Provides a tight integration of SimpleSAMLphp into the Symfony full-stack framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
