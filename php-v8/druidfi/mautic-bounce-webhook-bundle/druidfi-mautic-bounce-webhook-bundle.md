# druidfi/mautic-bounce-webhook-bundle

> 标签: Mailjet, Mautic, bounce, email, plugin, webhook

## 简介

Handles mailer transport webhook callbacks for bounce and spam events in Mautic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
