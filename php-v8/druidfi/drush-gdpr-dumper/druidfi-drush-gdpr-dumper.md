# druidfi/drush-gdpr-dumper

> 标签: PHP

## 简介

A drop-in replacement for mysqldump that optionally sanitizes DB fields for better GDPR conformity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
