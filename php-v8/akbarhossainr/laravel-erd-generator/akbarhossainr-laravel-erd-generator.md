# akbarhossainr/laravel-erd-generator

> 标签: PHP

## 简介

Laravel package to generate ERDs from Eloquent models (Mermaid.js, PlantUML, Graphviz)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
