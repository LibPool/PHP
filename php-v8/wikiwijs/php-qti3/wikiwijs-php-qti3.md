# wikiwijs/php-qti3

> 标签: Assessment, IMS, QTI, education, qti3, testing

## 简介

PHP library for reading, writing and manipulating QTI 3.0 packages, assessment tests and assessment items

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
