# u/i

> 标签: PHP

## 简介

A PHP UI components manager inspired by shadcn/ui, providing reusable components for plain HTML and Laravel Blade projects with Tailwind CSS integration

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
