# nicofuma/debugtools

> 标签: debug, extension, phpbb

## 简介

Additional debug tools for phpBB.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.phpbb.com
- 源码仓库：https://github.com/Nicofuma/phpbb-ext-debugtools.git
- Packagist 页面：https://packagist.org/packages/nicofuma%2Fdebugtools
