# snowsoft/laravel-payments

> 标签: database, feature, laravel, plan, recurring, subscription, value

## 简介

Laravel payments is a flexible plans and subscription management system for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
