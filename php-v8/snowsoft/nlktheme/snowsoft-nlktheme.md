# snowsoft/nlktheme

> 标签: json, laravel, pagebuilder, sections, shopify, theme

## 简介

FlexPage-style JSON-driven hybrid theme engine for Laravel 13

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
