# mix/http-message

> 标签: http, message, mix, psr, swoole

## 简介

Http message library based on PSR-7 / PSR-17 standard, support Swoole, WorkerMan

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
