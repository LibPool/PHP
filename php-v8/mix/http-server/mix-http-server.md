# mix/http-server

> 标签: coroutine, http, mix, server, swoole

## 简介

Http server library based on Swoole coroutine, following PSR-7 / PSR-15 standard

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
