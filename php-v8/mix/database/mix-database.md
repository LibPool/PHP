# mix/database

> 标签: database, mix, mysql, swoole, workerman

## 简介

Simple database for use in multiple execution environments, with support for FPM, Swoole, Workerman, and optional pools

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
