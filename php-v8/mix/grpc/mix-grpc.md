# mix/grpc

> 标签: client, coroutine, gRPC, mix, protoc, server, swoole

## 简介

PHP gRPC based on Swoole coroutine, including protoc code generator, server, and client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
