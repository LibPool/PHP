# corbado/php-sdk

> 标签: PHP

## 简介

Add passkeys to your PHP application with the Corbado PHP SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.corbado.com/passkeys/php
- 源码仓库：https://github.com/corbado/corbado-php.git
