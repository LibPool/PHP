# jengo/broadcasting

> 标签: PHP

## 简介

Enterprise-grade real-time event broadcasting subsystem for CodeIgniter 4 and the Jengo Framework with Pusher, Soketi, Server-Sent Events (SSE), and Redis support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
