# jengo/pesa

> 标签: PHP

## 简介

Unified multi-gateway payment processing subsystem for CodeIgniter 4 and the Jengo Framework with M-Pesa Daraja 3.0, Pesapal v3, Stripe, and Flutterwave support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
