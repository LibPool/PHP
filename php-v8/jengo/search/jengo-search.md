# jengo/search

> 标签: PHP

## 简介

Enterprise-grade, multi-driver full-text and semantic search engine subsystem for CodeIgniter 4 and the Jengo Framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
