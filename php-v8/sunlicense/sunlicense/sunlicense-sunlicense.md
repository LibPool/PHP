# sunlicense/sunlicense

> 标签: DRM, activation, anti-piracy, licence, license, license-key, licensing, sunlicense

## 简介

Official SunLicense client for PHP — licence key management and validation for indie software developers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
