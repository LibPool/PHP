# rsvp-system/rsvp-requirements

> 标签: PHP

## 简介

Metapackage for the RSVP System: Bundles all Drupal module dependencies for Gluebox event platforms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
