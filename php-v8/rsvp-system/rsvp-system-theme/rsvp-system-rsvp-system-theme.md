# rsvp-system/rsvp-system-theme

> 标签: PHP

## 简介

Modern Tailwind CSS v4 theme for the RSVP System, featuring SDC and AlpineJS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
