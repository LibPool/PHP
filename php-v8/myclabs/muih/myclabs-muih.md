# myclabs/muih

> 标签: bootstrap3, helper, ui

## 简介

PHP and Javascrcipt helpers for creation of Bootstrap 3 UI elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
