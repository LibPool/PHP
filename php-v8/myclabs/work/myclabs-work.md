# myclabs/work

> 标签: distributed, rabbitmq, task, work, work queue

## 简介

Work queue library letting you run distributed tasks using a generic abstraction

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
