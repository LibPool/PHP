# esheep/twigs

> 标签: cva, html, tailwind, tailwind-merge, twig

## 简介

A framework-agnostic Twig extension that bundles useful functions, filters, and tags into a single entry point.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
