# page-8/craft-manytomany

> 标签: Craft, cms, craft-plugin, craftcms, entries, fieldtype

## 简介

A Craft CMS field for managing element relationships from either side.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
