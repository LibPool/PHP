# akdeveloper/bootstrap-3-vanilla-js

> 标签: bootstrap, bootstrap3, css, front-end, javascript, jquery-free, responsive, ui, vanilla-js

## 简介

Bootstrap 3.4.1 CSS with a jQuery-free vanilla JS layer for alerts, dropdowns, collapse, modals, tabs, tooltips, and carousel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
