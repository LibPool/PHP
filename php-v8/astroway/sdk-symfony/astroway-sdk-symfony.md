# astroway/sdk-symfony

> 标签: api, astrology, astroway, bundle, sdk, symfony

## 简介

Symfony Bundle for astroway/sdk — DI integration, dataclass collector, Astroway service for autowiring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://api.astroway.info/docs/
- 源码仓库：https://github.com/astroway/astroway-php-symfony.git
- Packagist 页面：https://packagist.org/packages/astroway%2Fsdk-symfony
