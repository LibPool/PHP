# budanoff/yii2-register

> 标签: extension, yii2

## 简介

Расширение для автоматической регистрации заявок отправленных в ИАС Мониторинг (для подсистем программного комплекса)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
