# oi-lab/oi-laravel-umami

> 标签: analytics, dto, laravel, spatie-data, umami

## 简介

Laravel wrapper for the Umami analytics REST API returning typed spatie/laravel-data DTOs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
