# oi-lab/oi-laravel-drive

> 标签: attachments, documents, drive, files, folders, laravel, mcp

## 简介

Owned file spaces with folders for Laravel, built on oi-laravel-attachments, with API, MCP tools and events

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
