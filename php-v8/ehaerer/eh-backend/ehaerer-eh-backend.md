# ehaerer/eh-backend

> 标签: beginner, editor, extension, template, typo3

## 简介

A TYPO3 extension for optimizing the backend for editors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
