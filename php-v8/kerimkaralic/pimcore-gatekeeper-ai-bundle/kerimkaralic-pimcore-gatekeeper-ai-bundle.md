# kerimkaralic/pimcore-gatekeeper-ai-bundle

> 标签: Enrichment, PIM, ai, anthropic, claude, data-quality, pimcore, pimcore-bundle

## 简介

AI enrichment layer for the Gatekeeper completeness bundle: proposes values for missing DataObject fields from a Markdown knowledge base, stores them for review, applies approved ones.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
