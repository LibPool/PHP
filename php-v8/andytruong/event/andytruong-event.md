# andytruong/event

> 标签: api, event-dispatcher, wrapper

## 简介

Wrapper for Symfony EventDispatcher component to provide more functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
