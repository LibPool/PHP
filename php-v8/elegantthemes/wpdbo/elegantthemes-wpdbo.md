# elegantthemes/wpdbo

> 标签: PHP

## 简介

WordPress Database Objects - Work with posts and taxonomies, including queries and custom type registration, using OOP style.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
