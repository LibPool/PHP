> 标签: Telegram bot library, easy telegram sdk, easy to use telegram, telegram, telegram bot api, telegram bot api sdk

## 简介

An easy to use php library for using telegram bot api

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
