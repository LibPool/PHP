# flownative/neos-hostbaseddefaultpreset

> 标签: PHP

## 简介

This allows to have the default preset for content dimensions change depending on the hostname of a site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
