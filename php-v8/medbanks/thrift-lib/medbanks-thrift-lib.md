# medbanks/thrift-lib

> 标签: PHP

## 简介

Mirror of apache thrift client lib of php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/medbanks%2Fthrift-lib
- 源码仓库：https://github.com/medbanks/thrift-php.git
- Packagist 页面：https://packagist.org/packages/medbanks%2Fthrift-lib

## 获取地址

- Composer 安装：`composer require medbanks/thrift-lib`
- Packagist 仓库：https://repo.packagist.org/p2/medbanks/thrift-lib.json
- 许可证：Apache-2.0
- PHP 要求：>=5.3.0
