# entrepeneur4lyf/laravel-psl

> 标签: PSL, laravel, php-standard-library

## 简介

Laravel-first package that makes the PHP Standard Library feel natural inside Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
