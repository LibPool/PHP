# f4php/pechkin

> 标签: bot, f4, telegram

## 简介

Pechkin is a Telegram API wrapper and Bot for F4, a (really) lightweight web application framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
