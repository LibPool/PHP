# yousefaman/laravel-feedback-board

> 标签: bug-report, feedback, filament, laravel, livewire, support

## 简介

Self-hosted in-app feedback board for Laravel — clients report, developers resolve.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
