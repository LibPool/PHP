# yousefaman/filament-smart-fill

> 标签: Forms, OCR, ai, autofill, filament, laravel, livewire

## 简介

Fill Filament forms from a PDF, an image or pasted text with AI, and review every value before it lands

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
