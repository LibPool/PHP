# irwinlopez1023/mex-core

> 标签: MX, curp, estados, ine, mexican-states, mexico, norma, renapo

## 简介

Librería PHP para la normalización y conversión de los 32 estados de la República Mexicana. Soporta CURP (18 caracteres), ID numérico (1-32), abreviaturas y nombres completos, con interfaz fluida.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
