# private-captcha/typo3

> 标签: Forms, captcha, privacy, spam protection, typo3

## 简介

Private Captcha - CAPTCHA integration for TYPO3 forms and login

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
