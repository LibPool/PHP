> 标签: Aliyun TSDB cloud API, Aliyun TSDB cloud SDK, 阿里云时序数据库, 阿里云时序数据库接口

## 简介

阿里云时序数据库HTTP请求接口,aliyun TSDB cloud api,阿里云TSDB http请求API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
