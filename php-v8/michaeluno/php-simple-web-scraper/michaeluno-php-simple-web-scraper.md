# michaeluno/php-simple-web-scraper

> 标签: PHP

## 简介

A PHP application which runs on Heroku and dumps web site outputs including JavaScript generated contents.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
