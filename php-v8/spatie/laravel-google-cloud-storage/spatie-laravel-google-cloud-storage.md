# spatie/laravel-google-cloud-storage

> 标签: laravel, laravel-google-cloud-storage, spatie

## 简介

Google Cloud Storage filesystem driver for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
