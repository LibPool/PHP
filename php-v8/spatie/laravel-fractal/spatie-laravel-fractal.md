# spatie/laravel-fractal

> 标签: api, fractal, laravel, laravel-fractal, lumen, spatie, transform

## 简介

An easy to use Fractal integration for Laravel applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
