# spatie/browsershot

> 标签: chrome, convert, headless, image, pdf, puppeteer, screenshot, webpage, 截图, 浏览器

## 简介

Convert a webpage to an image or pdf using headless Chrome

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
