# spatie/laravel-blade-javascript

> 标签: blade, directive, javascript, laravel, laravel-blade-javascript, spatie

## 简介

A Blade directive to export variables to JavaScript

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
