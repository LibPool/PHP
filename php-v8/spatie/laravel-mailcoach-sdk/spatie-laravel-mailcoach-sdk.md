# spatie/laravel-mailcoach-sdk

> 标签: laravel, laravel-mailcoach-sdk, spatie

## 简介

An SDK to easily work with the Mailcoach API in Laravel apps

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
