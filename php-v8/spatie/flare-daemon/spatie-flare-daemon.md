# spatie/flare-daemon

> 标签: error-tracking, flare, flare-daemon, performance-monitoring, spatie

## 简介

Local HTTP daemon for asynchronous Flare delivery

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
