# spatie/laravel-robots-middleware

> 标签: SEO, index, robots, seo, spatie, 爬虫

## 简介

Add an `all` or `none` robots header to your requests via a middleware in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
