# spatie/laravel-translatable

> 标签: Laravel, eloquent, i8n, laravel-translatable, model, multilingual, spatie, translate, 翻译

## 简介

A trait to make an Eloquent model hold translations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
