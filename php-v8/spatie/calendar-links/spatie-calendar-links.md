# spatie/calendar-links

> 标签: calendar-links, google-calendar, ical, ics, outlook, spatie, yahoo

## 简介

Generate add to calendar links for Google, iCal and other calendar systems

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
