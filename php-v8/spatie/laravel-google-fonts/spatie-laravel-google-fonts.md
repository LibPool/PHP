# spatie/laravel-google-fonts

> 标签: google fonts, laravel, laravel-google-fonts, spatie

## 简介

Manage self-hosted Google Fonts in Laravel apps

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
