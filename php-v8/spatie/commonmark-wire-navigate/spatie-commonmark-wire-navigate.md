# spatie/commonmark-wire-navigate

> 标签: commmonmark, commonmark-wire-navigate, livewire, markdown, spatie

## 简介

Add a wire:navigate attribute to links rendered in Markdown

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
