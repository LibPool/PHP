# spatie/laravel-mailcoach-mailer

> 标签: laravel, laravel-mailcoach-mailer, mailcoach, spatie

## 简介

The driver for sending transactional mails using Mailcoach in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
