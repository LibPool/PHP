# spatie/laravel-sluggable

> 标签: eloquent, laravel, laravel-sluggable, self-healing, slug, slugs, spatie, translatable

## 简介

Generate slugs when saving Eloquent models

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
