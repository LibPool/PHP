# bonniss26/lqip

> 标签: blurhash, gd, image, imagick, lazy-loading, lqip, performance, placeholder

## 简介

Framework-agnostic LQIP (low-quality image placeholder) generator: dominant colour, CSS gradient, blurred data URI and CSS-only modes, on GD or Imagick.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
