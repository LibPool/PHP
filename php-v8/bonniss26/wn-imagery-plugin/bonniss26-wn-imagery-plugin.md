# bonniss26/wn-imagery-plugin

> 标签: images, lqip, performance, placeholder, twig, winter, wintercms

## 简介

LQIP image placeholders for Winter CMS - Twig filters, database caching, settings, console commands and queued generation, on GD or Imagick.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
