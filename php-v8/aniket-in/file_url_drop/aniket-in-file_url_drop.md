# aniket-in/file_url_drop

> 标签: attachments, drag-and-drop, file

## 简介

Enable drag-and-drop of remote links to download and attach files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
