# token27/cakephp-huawei-router-api-plugin

> 标签: cakephp, huawei, proxy, proxy-3g, routers

## 简介

The is an API for Huawei Routers 3G/4G/LTE.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
