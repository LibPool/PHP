# token27/cakephp-user-auth-plugin

> 标签: Users, acl, cakephp, permissions, roles

## 简介

Users Token Authentication and Roles Authorize (ACL) Plugin for CakePHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
