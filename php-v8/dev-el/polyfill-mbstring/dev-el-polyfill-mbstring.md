# dev-el/polyfill-mbstring

> 标签: compatibility, mbstring, polyfill, portable, shim

## 简介

Symfony polyfill for the Mbstring extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
