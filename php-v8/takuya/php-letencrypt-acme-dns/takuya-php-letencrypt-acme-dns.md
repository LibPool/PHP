# takuya/php-letencrypt-acme-dns

> 标签: acme-client, acme-dns, acme-v2, cloudflare, pure-php

## 简介

acme v2 to Let'sEncrypt by dns cloudflare or your own.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
