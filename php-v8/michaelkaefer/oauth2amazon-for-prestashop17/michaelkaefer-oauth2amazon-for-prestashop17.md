# michaelkaefer/oauth2amazon-for-prestashop17

> 标签: amazon, oauth, oauth2, php, prestashop

## 简介

Enables you in PrestaShop 1.7 to use oauth2-amazon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
