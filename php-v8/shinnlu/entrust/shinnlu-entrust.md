# shinnlu/entrust

> 标签: acl, auth, illuminate, laravel, lumen, permission, roles

## 简介

This package provides a flexible way to add Role-based Permissions to Laravel/Lumen 6

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
