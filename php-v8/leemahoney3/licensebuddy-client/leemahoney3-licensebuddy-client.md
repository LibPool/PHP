# leemahoney3/licensebuddy-client

> 标签: Whmcs, licensebuddy, licensing, php

## 简介

PHP library to connect to the LicenseBuddy WHMCS module to verify your license keys

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
