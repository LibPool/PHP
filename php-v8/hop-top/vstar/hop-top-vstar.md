# hop-top/vstar

> 标签: iCalendar, rfc5545, rfc6350, vCard, vstar

## 简介

V* calendar and contact interchange — PHP port of the Go reference implementation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
