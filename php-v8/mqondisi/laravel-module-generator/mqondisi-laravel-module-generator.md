# mqondisi/laravel-module-generator

> 标签: PHP

## 简介

Opinionated Laravel 9–13 module scaffolding (model, migration, repository, DTO, optional DAO, controllers)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
