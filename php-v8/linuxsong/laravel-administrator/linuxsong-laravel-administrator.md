# linuxsong/laravel-administrator

> 标签: admin, administrator, cms, database, laravel, laravel-administrator

## 简介

A database interface package for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
