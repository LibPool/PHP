# vbcherepanov/a2a-php-sdk

> 标签: Agent, a2a, agent-to-agent, gRPC, json-rpc, sse

## 简介

A2A 1.0 client and server SDK with JSON-RPC, REST, SSE and optional gRPC transports

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
