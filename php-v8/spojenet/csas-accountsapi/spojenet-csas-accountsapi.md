# spojenet/csas-accountsapi

> 标签: Spořka, api, csas, openapi, openapi-generator, openapitools, php, rest, sdk, Česká Spořitelna

## 简介

API for managing production accounts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
