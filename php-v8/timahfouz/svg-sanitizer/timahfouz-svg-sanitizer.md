# timahfouz/svg-sanitizer

> 标签: laravel, sanitizer, security, svg, validation, xss

## 简介

A Laravel package for sanitizing SVG files and SVG code to prevent XSS attacks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
