# linlancer/laravel-eloquent-mysqli

> 标签: connector, driver, laravel, lumen, mysql, mysqli

## 简介

MySQLi driver (connector) for Laravel 5.4 Eloquent database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
