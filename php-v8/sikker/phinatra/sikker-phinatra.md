# sikker/phinatra

> 标签: Simple, controller, light, rest, restful, router

## 简介

Phinatra is a lightweight PHP router inspired by Sinatra, ideal for light or RESTful applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
