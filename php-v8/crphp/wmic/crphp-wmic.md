# crphp/wmic

> 标签: acesso remoto, wmi

## 简介

Está biblioteca disponibiliza um mecanismo para CONSULTAR máquinas Windows remotamente

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
