# mongosoft/yii2-xmlpipe

> 标签: extension, sphinx, xml-pipe, xmlpipe, xmlpipe2, yii2

## 简介

Sphinx XmlPipe Extension for Yii 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
