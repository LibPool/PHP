# ingenico-epayments/connect-extension-magento1

> 标签: PHP

## 简介

Magento 1 Extension for connecting to the Ingenico ePayments Connect platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
