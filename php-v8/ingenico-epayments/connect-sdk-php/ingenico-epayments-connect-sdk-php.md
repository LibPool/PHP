# ingenico-epayments/connect-sdk-php

> 标签: sdk

## 简介

PHP SDK to communicate with the Ingenico ePayments platform server-to-server API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
