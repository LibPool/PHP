# ua0leg/yii2-log-viewer

> 标签: extension, file-target, log, log-viewer, yii2

## 简介

Smart Yii2 FileTarget log viewer — tail from end, parse GET/POST/URI/user, filters, multi-file aliases, download/clear/history

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
