# caio-brendo/rating-input

> 标签: PHP

## 简介

Componente que renderiza estrelas para seleção, bastante útil para trabalhar com avaliações.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
