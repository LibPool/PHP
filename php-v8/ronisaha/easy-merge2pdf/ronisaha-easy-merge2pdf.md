# ronisaha/easy-merge2pdf

> 标签: PHP

## 简介

Easy to use PHP library for merging Images and PDFs. Wrapper for ajaxray/merge2pdf

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
