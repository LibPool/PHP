# yourfightsite/mailchimp-socialite-provider

> 标签: laravel, mailchimp, oauth, socialite

## 简介

A Mailchimp provider for Laravel Socialite.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
