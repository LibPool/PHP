# terrylinooo/slimvc

> 标签: microframework, psr7, rest, router

## 简介

A Slim 3 Framework skeleton application with MVC structure for rapid development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
