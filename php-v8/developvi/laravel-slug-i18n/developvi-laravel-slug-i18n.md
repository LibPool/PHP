# developvi/laravel-slug-i18n

> 标签: PHP

## 简介

A Laravel package to generate multilingual slugs (UTF-8) with optional transliteration skipping for specific locales.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
