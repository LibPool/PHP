# quexer69/yii2-google-api

> 标签: api, extension, google, google map, yii2

## 简介

A collection of google map api calls, staticmap, geocode, iframe, for google api v3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
