> 标签: disposable, email validation, laravel, laravel 10, laravel 11, laravel 12, laravel 13, laravel 5, laravel 6, laravel 7, laravel 8, laravel 9, mailboxvalidator

## 简介

Laravel package to validate an email by using MailboxValidator API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
