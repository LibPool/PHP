# jacobbennett/laravel-http2serverpush

> 标签: laravel, laravel-http2serverpush, serverpush

## 简介

A HTTP2 Server Push Middleware for Laravel 5

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
