# jacobbennett/phpghostpost

> 标签: Ghost, blog, php, rss, xml

## 简介

A PHP Library for creating usable Post objects from Ghost RSS feeds

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
