# tbbc/rest-util-bundle

> 标签: api, rest, rest-util, restful

## 简介

Bundle for integrating tbbc/rest-util lib in a Symfony application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
