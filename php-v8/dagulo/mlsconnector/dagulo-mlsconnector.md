# dagulo/mlsconnector

> 标签: CARETS, CRMLS, RESO, matrix, mls, rets

## 简介

Connect to MLS using Masterdigm API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
