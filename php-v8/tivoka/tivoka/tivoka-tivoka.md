# tivoka/tivoka

> 标签: api, json, json-rpc, rpc, xml-rpc

## 简介

The universal JSON-RPC client/server library. JSON-RPC done right!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
