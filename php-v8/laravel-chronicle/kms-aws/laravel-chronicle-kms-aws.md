# laravel-chronicle/kms-aws

> 标签: Audit, ECDSA, aws, chronicle, kms, laravel, signing

## 简介

AWS KMS signing adapter for the Chronicle audit ledger - remote sign, local verify.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
