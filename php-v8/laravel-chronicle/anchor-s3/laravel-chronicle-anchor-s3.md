# laravel-chronicle/anchor-s3

> 标签: Audit, Worm, anchoring, aws, chronicle, laravel, object-lock, s3

## 简介

S3 Object Lock (WORM) anchoring adapter for the Chronicle audit ledger.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
