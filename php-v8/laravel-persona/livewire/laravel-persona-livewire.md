# laravel-persona/livewire

> 标签: Persona, contact, laravel, livewire, profile

## 简介

Persona Livewire - Livewire 3 UI components for managing contact data on top of the headless Persona core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
