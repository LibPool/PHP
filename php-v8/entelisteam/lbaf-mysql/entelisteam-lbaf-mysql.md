# entelisteam/lbaf-mysql

> 标签: database, mariadb, mysql, mysqli

## 简介

A simple and quick mysqli wrapper for connecting to MySQL from PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
