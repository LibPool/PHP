# tiisy/csv

> 标签: csv, csv-file, csv-reader, csv-writer, spreadsheet, transform

## 简介

Easy CSV file handling. Read CSV files from string, file, resource or URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
