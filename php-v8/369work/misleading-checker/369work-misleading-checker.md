# 369work/misleading-checker

> 标签: checker, compliance, ng-word, php, yakki, 景品表示法, 薬機法

## 简介

薬機法・景品表示法のNG表現を検出するPHPライブラリ。記事やLPの入稿前チェック、納品前の品質管理に。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
