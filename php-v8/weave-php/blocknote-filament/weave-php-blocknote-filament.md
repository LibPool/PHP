# weave-php/blocknote-filament

> 标签: blocknote, editor, filament, laravel, weave

## 简介

Weave BlockNote rich-text editor as a Filament form field for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
