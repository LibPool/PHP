# dracoder/s4-2fa

> 标签: Authentication, security, symfony, two-factor, two-step

## 简介

Two-factor authentication for Symfony applications (please use scheb/2fa-bundle to install)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
