# masterzero/yii2-activefield

> 标签: PHP

## 简介

Cumstom Yii class ActiveField to work with tinymce, elfinder, and auto translit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
