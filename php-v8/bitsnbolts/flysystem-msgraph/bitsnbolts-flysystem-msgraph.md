# bitsnbolts/flysystem-msgraph

> 标签: PHP

## 简介

A Flysystem Adapter that supports Microsoft OneDrive and Sharepoint Document Libraries using Microsoft Graph

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
