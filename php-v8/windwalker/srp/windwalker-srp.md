# windwalker/srp

> 标签: Passwordless, SRP, password, security

## 简介

A modern PHP/JS package of SRP-6a (RFC5054). Contains server and client part to help developer use on any cases.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
