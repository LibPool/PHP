# drewlabs/iso-country

> 标签: Iso3166, country, itu-t

## 简介

Provides International Standards Organization (ISO) country data such as iso3166, ITU-T etc..

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
