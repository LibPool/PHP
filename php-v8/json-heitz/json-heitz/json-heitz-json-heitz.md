# json-heitz/json-heitz

> 标签: Heitz System, api, heitz, json, webservice

## 简介

A unofficial PHP class to connect to JSON with CURL to the 'Heitz System' WebService.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
