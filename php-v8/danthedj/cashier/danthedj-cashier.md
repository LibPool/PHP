# danthedj/cashier

> 标签: billing, laravel, stripe

## 简介

Cashier provides an expressive, fluent interface to Stripe's subscription billing services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
