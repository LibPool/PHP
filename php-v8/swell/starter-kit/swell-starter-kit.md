# swell/starter-kit

> 标签: e-commerce, framework, inertia, laravel, react, starter-kit, swell

## 简介

Swell Starter Kit is a Laravel-based starter kit designed to kickstart your next e-commerce project with essential features and tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
