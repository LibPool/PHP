# elcobvg/laravel-opcache

> 标签: Opcache, cache, driver, laravel, webprofiler

## 简介

Custom OPcache Cache Driver for Laravel. Faster than Redis or memcached.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
