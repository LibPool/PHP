# rfpludwick/phpcs-teamcity-report

> 标签: phpcs, standards, teamcity

## 简介

A PHP Code Sniffer report format for JetBrains' TeamCity continuous integration server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
