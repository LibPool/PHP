# liwenyu/yii2-swiftmailer

> 标签: Office365, email, extension, mail, microsoft, outlook, yii2

## 简介

Yii2 extension for Microsoft mail sending functionality based on yii2-swiftmailer

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
