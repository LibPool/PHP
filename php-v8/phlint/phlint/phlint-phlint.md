# phlint/phlint

> 标签: PHP

## 简介

PHP code analyzer and tester.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://gitlab.com/phlint/phlint/
- 源码仓库：https://gitlab.com/phlint/phlint.git
