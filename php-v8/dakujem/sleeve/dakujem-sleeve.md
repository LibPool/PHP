# dakujem/sleeve

> 标签: PSR-11, dependency-injection-container, pimple

## 简介

Lightweight PSR-11 service container 📦. A trivial extension of Symfony Pimple container.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
