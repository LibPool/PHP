# dakujem/sqids-legacy-backport

> 标签: backport, decode, encode, generate, hashids, ids, php74, sqids

## 简介

Backport of sqids/sqids for PHP 7.4 and PHP 8.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
