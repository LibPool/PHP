# dakujem/oliva

> 标签: materialized path tree, recursive tree, tree, tree iterator

## 简介

Flexible tree structure, tree builders (materialized paths, recursive, wrappers), traversal iterators, filter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
