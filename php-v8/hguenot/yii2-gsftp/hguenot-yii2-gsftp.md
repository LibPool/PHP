# hguenot/yii2-gsftp

> 标签: extension, gftp, yii2

## 简介

Ftp is a FTP extension for [YII 2 Framework](http://www.yiiframework.com).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
