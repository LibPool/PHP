# hguenot/oecd-pib

> 标签: PHP

## 简介

Wrapper for PIB csv from https://data.oecd.org/fr/gdp/produit-interieur-brut-pib.htm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
