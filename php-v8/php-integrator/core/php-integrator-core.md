# php-integrator/core

> 标签: analysis, autocompletion, ide, indexer, indexing, refactoring, signature-help, static, tooltips

## 简介

Free and open source server providing code assistance for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
