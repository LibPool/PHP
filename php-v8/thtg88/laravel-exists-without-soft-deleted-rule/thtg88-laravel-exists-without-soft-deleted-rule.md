# thtg88/laravel-exists-without-soft-deleted-rule

> 标签: PHP

## 简介

Provide a Laravel `exists` validation rule that excludes soft-deleted models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
