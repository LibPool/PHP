# ardenexal/fhir-models

> 标签: fhir, healthcare, hl7, models, php, r4, r4b, r5

## 简介

Pre-generated FHIR model classes for R4, R4B, and R5 versions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
