# ardenexal/fhir-metadata

> 标签: fhir, healthcare, hl7, models, php, r4, r4b, r5

## 简介

Shared interfaces, attributes and utilities for FHIR packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
