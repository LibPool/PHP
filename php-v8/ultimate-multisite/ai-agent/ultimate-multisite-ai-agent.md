# ultimate-multisite/ai-agent

> 标签: PHP

## 简介

Agentic AI loop for WordPress — chat with an AI that can call WordPress abilities (tools) autonomously.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
