# ultimate-multisite/cli-abilities-bridge

> 标签: PHP

## 简介

Exposes WP-CLI and system commands as abilities via the WordPress Abilities API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
