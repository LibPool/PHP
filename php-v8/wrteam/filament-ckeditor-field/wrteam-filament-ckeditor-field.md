# wrteam/filament-ckeditor-field

> 标签: filament-ckeditor-field, laravel, wrteam

## 简介

A basic CKEditor 5 form field configured with non-premium features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
