# tequilarapido/letter-avatar

> 标签: avatar, generator, letter

## 简介

Provide a simple way to create letter avatar images, like those in your Gmail inbox

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
