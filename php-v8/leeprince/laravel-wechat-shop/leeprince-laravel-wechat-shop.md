# leeprince/laravel-wechat-shop

> 标签: PHP

## 简介

基于 laravel 开发微信公众号商城组件，并且包含各个模块的子组件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
