## 简介

PHP SDK for InPost Von Halsky (formerly InPost Buy, inpsa) marketplace API – offers, orders, returns, claims, refunds, price program, OAuth2 PKCE

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
