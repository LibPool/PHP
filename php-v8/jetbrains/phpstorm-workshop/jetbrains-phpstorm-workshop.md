# jetbrains/phpstorm-workshop

> 标签: PHP

## 简介

Materials for the PhpStorm workshop. Check https://github.com/jetbrains/phpstorm-workshop/ for more info.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
