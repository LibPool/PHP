# zhiisland/webman-jwt-lc5

> 标签: PHP

## 简介

Webman JWT plugin using lcobucci/jwt v5 with multi-guard, SSO, blacklist, token rotation, and extensibility.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
