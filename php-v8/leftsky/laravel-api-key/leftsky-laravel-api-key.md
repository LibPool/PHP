# leftsky/laravel-api-key

> 标签: Authentication, api, api-logs, filament, key, laravel, logging, token

## 简介

Laravel API密钥管理系统，支持API密钥的创建、验证和管理，包含完整的Filament管理界面和API调用日志功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
