# lexik/modelo-bundle

> 标签: bundle, modelo, symfony, symfony-bundle

## 简介

This bundle aim to provides an http client that performs and handle requests to modelo Api.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
