# lexik/jwt-authentication-bundle

> 标签: Authentication, JWS, api, bundle, jwt, rest, symfony

## 简介

This bundle provides JWT authentication for your Symfony REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
