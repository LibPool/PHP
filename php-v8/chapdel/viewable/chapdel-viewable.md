# chapdel/viewable

> 标签: counter, eloquent, hits, laravel, viewable, views, visitable, visits

## 简介

Laravel package that allows you to associate views with Eloquent models

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
