# djtommek/mapycz-api

> 标签: api, maps, mapy, mapy.cz, mapycz, seznam, seznam.cz, seznamcz

## 简介

Unofficial PHP 8 API wrapper for making requests to Mapy.cz

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
