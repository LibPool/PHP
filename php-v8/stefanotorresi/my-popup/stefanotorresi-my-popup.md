# stefanotorresi/my-popup

> 标签: cookie, module, popup, zend, zf2

## 简介

A very simple Zend Framework 2 module to handle cookie timed popups

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
