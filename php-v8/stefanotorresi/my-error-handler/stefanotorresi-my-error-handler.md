# stefanotorresi/my-error-handler

> 标签: module, zend, zf2

## 简介

A ZF2 module that introduces custom exceptions and error strategies for XHR requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
