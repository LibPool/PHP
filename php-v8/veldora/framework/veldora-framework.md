# veldora/framework

> 标签: auth, cli, framework, mvc, orm, php, veldora

## 简介

The Veldora PHP Framework Core — Expressive routing, native templates, ORM, CLI, Auth, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
