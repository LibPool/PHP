# assemien-dev/money-fusion-php

> 标签: PHP

## 简介

SDK PHP officiel pour interagir avec l'API Money Fusion Pay (création et suivi de paiements).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
