# felixmuhoro/laravel-mpesa-notify

> 标签: kenya, laravel, mpesa, notifications, payments, safaricom

## 简介

M-Pesa payment notification helpers for Laravel — SMS, email and webhook alerts on every payment event.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
