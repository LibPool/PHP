# felixarntz/wp-global-admin

> 标签: global admin, multinetwork, multisite, network, plugin, wordpress

## 简介

Introduces a global admin panel in WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
