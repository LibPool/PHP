# felixarntz/post-types-definitely

> 标签: bulk actions, custom-post-type, definitely, framework, list table, meta boxes, plugin, post filters, post meta, row actions, taxonomies, term meta, wordpress

## 简介

This framework plugin makes adding post types with taxonomies and meta to WordPress very simple, yet flexible.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
