# dnabeast/bladeimagecrop

> 标签: bladeimagecrop, dnabeast

## 简介

Creates a blade component that grabs an image and resizes it and crops it to match the blade settings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
