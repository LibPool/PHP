# tommarti/jwtopenauth

> 标签: Authentication, api, two-factor

## 简介

Two-factor authentication api that can be implemented very quickly and easily based on SlimFramework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
