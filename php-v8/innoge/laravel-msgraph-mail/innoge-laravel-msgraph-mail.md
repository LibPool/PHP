# innoge/laravel-msgraph-mail

> 标签: innoge, laravel, laravel-msgraph-mail

## 简介

Laravel Mail driver for Microsoft Office 365 using the MSGraph API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
