# tetranyble/storage

> 标签: cloud-drive, cloud-storage, file-manager, laravel, media-access, media-library, media-sharing, media-upload, media-versioning, multi-tenancy, storage, storage-quota

## 简介

Standalone storage and media services for Laravel, maintained by Tetranyble.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
