# nythros/engine

> 标签: PHP

## 简介

Nythros 游戏引擎核心（Game engine core）：契约、内核、调度、世界、实体、Actor、AOI、事件、网络、协议、安全、持久化、集群 15 个核心模块的物理合并。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
