# nythros/skeleton

> 标签: PHP

## 简介

Nythros 入门套件（create-project 模板）：最小但功能完整的 Map 游戏服务器——两种 World（AOI 局域 / 全量广播）、认证/移动/视野广播、巡游 NPC，基于 nythros/engine + nythros/framework 开箱即用。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
