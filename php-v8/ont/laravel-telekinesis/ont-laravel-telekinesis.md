# ont/laravel-telekinesis

> 标签: admin, eloquent, javascript, laravel, orm, rest

## 简介

Universal REST route with Eloquent-like API for javascript.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
