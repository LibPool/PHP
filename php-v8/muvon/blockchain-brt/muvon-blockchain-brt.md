# muvon/blockchain-brt

> 标签: blockchain, brt, business-revenue-token, coin, cryptocurrency, rpc, token

## 简介

Implementation of kiss-blockchain interface for BRT network

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
