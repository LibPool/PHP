# laemmi/laemmi-yourls-trim-url

> 标签: plugin, yourls

## 简介

Plugin for YOURLS. Trim the withespace before and after the orignial url before adding and editing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
