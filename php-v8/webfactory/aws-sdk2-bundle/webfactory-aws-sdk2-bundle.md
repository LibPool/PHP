# webfactory/aws-sdk2-bundle

> 标签: amazon, aws, dynamodb, ec2, s3, sdk, sdk v2, symfony

## 简介

A simple Symfony (2.x, 3.x and beyond) bundle for including the AWS SDK v2.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
