# webfactory/doctrine-orm-test-infrastructure

> 标签: doctrine, orm, testing

## 简介

Provides utils to create a test infrastructure for Doctrine 2 entities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
