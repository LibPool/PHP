# webfactory/object-routing-bundle

> 标签: annotations, routing

## 简介

Support for webfactory/object-routing in Symfony projects (started as a fork of benjam1/object-routing-bundle)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
