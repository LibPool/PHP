# webfactory/http-cache-bundle

> 标签: 304, caching, http, ifnotmodifiedsince, notmodified

## 简介

Symfony bundle to ease HTTP cache validation via last modified header

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
