# twstec/kit-auth

> 标签: Authentication, laravel, security, starter-kit, two-factor

## 简介

Autenticação do TWS Laravel Starter Kit, sem telas: login com bloqueio por tentativas, cadastro, verificação de e-mail, verificação em duas etapas por e-mail, senha de transação, ação sensível com token de uso único, política de senha, status da conta e contratos de resposta para qualquer front.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
