# twstec/starter-react

> 标签: inertia, laravel, lgpd, react, security, starter-kit, typescript

## 简介

TWS Laravel Starter Kit — starter React: aplicativo Laravel 13 com painel do usuário em React 19 + Inertia 3 + TypeScript + Tailwind 4 + shadcn/ui (a partir do kit oficial do Laravel), com a autenticação, a segurança e a auditoria dos pacotes twstec/kit-*. Contas e API, uploads, o painel /admin e os webhooks são opcionais: escolha com `php artisan tws:install`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
