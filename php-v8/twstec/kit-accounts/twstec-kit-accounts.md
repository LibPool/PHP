# twstec/kit-accounts

> 标签: api, api-keys, laravel, starter-kit, tenancy

## 简介

Contas e API do TWS Laravel Starter Kit, sem telas: projetos, chaves de API com par pública/secreta, hash com pepper, escopos, vínculo chave-projeto, rotação com período de graça, expiração por inatividade, autenticação e limites da API e a API v1.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
