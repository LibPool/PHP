# twstec/kit-installer

> 标签: installer, laravel, starter-kit

## 简介

Instalador do TWS Laravel Starter Kit: php artisan tws:install escolhe os módulos opcionais (contas, uploads, painel /admin) e a demonstração de um starter; php artisan tws:add acrescenta pacotes do kit a um aplicativo Laravel que já existe. Aplica com o Composer, roda as migrations e gera a APP_KEY e o pepper das chaves de API quando faltam. Ferramenta de desenvolvimento — instale em require-dev.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
