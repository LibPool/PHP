# twstec/kit

> 标签: installer, laravel, lgpd, livewire, react, security, starter-kit

## 简介

TWS Laravel Starter Kit — o comando único: `composer create-project twstec/kit meu-projeto` pergunta a interface (Livewire ou React) e os módulos opcionais (contas e API, uploads, painel /admin) e entrega o projeto pronto, com o starter escolhido e só os pacotes marcados.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
