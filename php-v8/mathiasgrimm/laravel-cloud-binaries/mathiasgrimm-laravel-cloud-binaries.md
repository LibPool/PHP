# mathiasgrimm/laravel-cloud-binaries

> 标签: PHP

## 简介

Pre-built static binaries for Laravel Cloud (jpegoptim, optipng, pngquant, cwebp, dwebp, avifenc, avifdec, gifsicle, ffmpeg, ffprobe, magick, zstd, qpdf, ssimulacra2, butteraugli_main)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
