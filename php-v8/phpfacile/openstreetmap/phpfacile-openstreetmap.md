# phpfacile/openstreetmap

> 标签: OpenStreetMap, overpass

## 简介

This service basically retrieves data from the Openstreetmap (OSM) data thanks to the Overpass API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
