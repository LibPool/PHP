# dhii/wp-containers

> 标签: container, dependency injection, di, wordpress

## 简介

PSR-11 container implementations that wrap some WP features, for convenience and interoperability.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
