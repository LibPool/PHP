# snce/utility-bundle

> 标签: ez, ez publish, utility

## 简介

This Bundle provides a set of Twig functions and Symfony helpers to speed up the eZ 5 development process

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
