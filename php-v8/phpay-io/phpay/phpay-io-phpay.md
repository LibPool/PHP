# phpay-io/phpay

> 标签: Asaas, efi, gateways, gateways de pagamento, mtls, phpay, pix, pix automatico, sdk asaas, sdk efi

## 简介

Biblioteca PHP para integração simples e padronizada com gateways de pagamento brasileiros.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
