# teleduino/php-teleduino2560-client

> 标签: arduino, iot, teleduino, teleduino328

## 简介

PHP Teleduino Client for interacting with your Teleduino2560 device.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
