# starkpay/omnipay

> 标签: bitcoin, cryptocurrency, gateway, merchant, omnipay, stark, starkpayments

## 简介

Stark driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
