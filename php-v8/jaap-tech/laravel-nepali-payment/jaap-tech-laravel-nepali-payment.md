# jaap-tech/laravel-nepali-payment

> 标签: ConnectIps, esewa, khalti, laravel, laravel payment package, nepali online payment, nepali payment api, nepali payment gateway, nepali payment sdk, payment integration

## 简介

Laravel package for integrating Nepali payment gateways like eSewa, Khalti, and ConnectIps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
