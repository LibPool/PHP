# whisperr/php

> 标签: analytics, churn, events, laravel, retention, tracking, whisperr

## 简介

Whisperr server-side SDK for PHP (with Laravel support) — reliable churn-signal event tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
