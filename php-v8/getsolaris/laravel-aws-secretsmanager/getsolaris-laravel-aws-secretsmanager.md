# getsolaris/laravel-aws-secretsmanager

> 标签: aws, aws-secretsmanager, getsolaris, laravel

## 简介

A Laravel package to retrieve key management from AWS Secrets Manager

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
