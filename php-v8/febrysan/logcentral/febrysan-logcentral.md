# febrysan/logcentral

> 标签: error-reporting, exceptions, laravel, logging

## 简介

Report Laravel exceptions to a central error-log API and serve a custom HTTP 500 page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
