# quellabs/canvas-scheduler-redis

> 标签: async, canvas-framework, job-queue, redis-queue

## 简介

Redis queue consumer and job dispatcher for the Canvas PHP framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
