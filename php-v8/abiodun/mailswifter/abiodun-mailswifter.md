# abiodun/mailswifter

> 标签: email, mail, mailer, template

## 简介

Mail swifter is a free mailer built on swiftmailer for html template injection and data parser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
