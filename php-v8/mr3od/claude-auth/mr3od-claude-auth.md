# mr3od/claude-auth

> 标签: accounts, auth, claude, claude-code, cli

## 简介

CLI tool to store and switch between multiple Claude Code account credentials, keeping settings/history/memory centralized.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
