# simbiat/db-maintainer

> 标签: analyze, check, fulltext, mysql, optimize, pdo, php, repair, table

## 简介

Library to maintain database tables using its built-in commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
