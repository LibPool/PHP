# runomine/runomine-php

> 标签: analytics, cookieless, laravel, privacy, runomine

## 简介

Cookieless, server-side analytics for runomine: pageviews, business events and revenue. Framework-agnostic client plus Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
