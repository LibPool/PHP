# quoyer/quoyer-php

> 标签: api, laravel, loyalty, points, quoyer, rewards, sdk, webhooks

## 简介

Official PHP SDK for the Quoyer loyalty API: customers, points, redemptions, webhooks, with Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
