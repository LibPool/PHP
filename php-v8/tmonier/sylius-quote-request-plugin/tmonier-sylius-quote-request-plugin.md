# tmonier/sylius-quote-request-plugin

> 标签: b2b, negotiable-quote, quotation, quote, request-for-quote, rfq, sylius, sylius-plugin

## 简介

B2B request for quote for Sylius 2: quote requests from the cart or a product page, admin negotiation (prices, discount, validity), proposals by e-mail, acceptance into a regular checkout with locked negotiated prices

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
