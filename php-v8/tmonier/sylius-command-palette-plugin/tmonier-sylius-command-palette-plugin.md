# tmonier/sylius-command-palette-plugin

> 标签: admin-search, back-office, command-palette, global-search, keyboard-shortcuts, sylius, sylius-plugin

## 简介

Command palette (Ctrl+K / Cmd+K global search) for the Sylius 2 admin panel: orders, customers, products, promotions and admin pages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
