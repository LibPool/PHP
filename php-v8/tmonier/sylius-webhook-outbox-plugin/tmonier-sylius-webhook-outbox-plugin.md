# tmonier/sylius-webhook-outbox-plugin

> 标签: ERP, integration, outbox, standard-webhooks, sylius, sylius-plugin, transactional-outbox, webhook, webhooks

## 简介

Transactional outbox for outgoing Sylius 2 webhooks: atomic event capture, Standard Webhooks signatures, retries, dead letters and replay from the admin panel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
