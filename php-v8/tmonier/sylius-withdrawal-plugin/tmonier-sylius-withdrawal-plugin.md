# tmonier/sylius-withdrawal-plugin

> 标签: consumer-rights, eu-compliance, retractation, right-of-withdrawal, sylius, sylius-plugin, widerrufsbutton, withdrawal

## 简介

EU withdrawal button (Directive (EU) 2023/2673, Art. 11a Consumer Rights Directive) for Sylius 2

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
