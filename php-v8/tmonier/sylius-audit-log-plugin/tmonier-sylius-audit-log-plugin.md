# tmonier/sylius-audit-log-plugin

> 标签: activity-log, audit-log, audit-trail, back-office, change-history, doctrine, gdpr, sylius, sylius-plugin

## 简介

Audit log of admin changes (who changed what, when) for the Sylius 2 admin panel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
