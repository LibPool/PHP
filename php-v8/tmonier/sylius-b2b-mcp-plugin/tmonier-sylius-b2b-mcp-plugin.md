# tmonier/sylius-b2b-mcp-plugin

> 标签: ChatGpt, b2b, claude, mcp, model-context-protocol, oauth2, reorder, sylius, sylius-plugin

## 简介

B2B tools for the official Sylius MCP server: signed-in buyers use Claude or ChatGPT to list and reorder their orders, quick order by SKU, request quotes and read their trade credit statement (OAuth 2.1 with PKCE, checkout handoff to the shop)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
