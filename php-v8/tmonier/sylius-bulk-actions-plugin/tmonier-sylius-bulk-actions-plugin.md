# tmonier/sylius-bulk-actions-plugin

> 标签: admin-grid, back-office, bulk-actions, bulk-edit, mass-actions, order-management, sylius, sylius-plugin

## 简介

Bulk actions for the Sylius 2 admin grids: enable/disable, taxons and channels for products, cancel orders, mark payments as paid, ship shipments, customer groups

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
