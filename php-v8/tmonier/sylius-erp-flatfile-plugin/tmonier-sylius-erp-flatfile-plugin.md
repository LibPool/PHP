# tmonier/sylius-erp-flatfile-plugin

> 标签: ERP, b2b, csv, ecommerce, export, flat-file, sylius, sylius-plugin

## 简介

Flat-file exchange with an ERP for Sylius 2: orders exported as CSV files (documented contract, UTF-8, ";" separator, minor-unit integers) from the events of the webhook outbox, deposited atomically in an exchange directory

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
