# tmonier/sylius-container-fill-plugin

> 标签: b2b, case-pack, container, load-planning, pallet, sylius, sylius-plugin, truckload, wholesale

## 简介

Pallet & Truckload Builder for Sylius 2: container types, logistics data per variant, a load planner (pallet places, payload, volume) with a fill gauge in the cart, B2B fill rules enforced at checkout (shop and API), per-container shipping

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
