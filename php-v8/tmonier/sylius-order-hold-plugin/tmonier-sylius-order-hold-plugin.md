# tmonier/sylius-order-hold-plugin

> 标签: b2b, order-hold, payment-methods, purchase-approval, sylius, sylius-plugin, trade-credit, unpaid-orders

## 简介

Shared order-hold kernel for Sylius 2: keeps held orders out of the unpaid-orders cancellation, filters payment methods everywhere (shop, API, default method, post-order change) and blocks payment entry, through single decorators and tagged checkers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
