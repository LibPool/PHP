# tmonier/sylius-quick-order-plugin

> 标签: b2b, bulk-order, csv-import, order-by-sku, quick-order, reorder, sylius, sylius-plugin

## 简介

B2B quick order for Sylius 2: paste SKU;quantity lines or upload a CSV, preview, add up to hundreds of lines to the cart in one pass, reorder past orders, bulk add through the shop API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
