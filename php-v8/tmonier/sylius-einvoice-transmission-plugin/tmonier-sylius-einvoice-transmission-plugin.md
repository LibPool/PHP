# tmonier/sylius-einvoice-transmission-plugin

> 标签: e-invoicing, einvoice, factur-x, facture-electronique, facturx, invoice-transmission, sylius, sylius-plugin

## 简介

Transmission of Factur-X electronic invoices for Sylius 2: replaceable transmitter port, log of the sends with their statuses, idempotent listener of the Factur-X plugin event

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
