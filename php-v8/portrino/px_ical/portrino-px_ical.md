# portrino/px_ical

> 标签: cms, ical, ics, portrino, typo3

## 简介

Provides classes to render ical via eluceo iCal lib (https://github.com/markuspoerschke/iCal)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
