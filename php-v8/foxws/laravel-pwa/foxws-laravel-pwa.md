# foxws/laravel-pwa

> 标签: blade, foxws, laravel, laravel-pwa, manifest, progressive-web-app, pwa, service-worker

## 简介

PWA manifest and Blade directives for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
