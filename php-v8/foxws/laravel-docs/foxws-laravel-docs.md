# foxws/laravel-docs

> 标签: documentation, foxws, github, laravel, laravel-docs, markdown

## 简介

Pull a package's docs/*.md folder from GitHub or a local folder into queryable Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
