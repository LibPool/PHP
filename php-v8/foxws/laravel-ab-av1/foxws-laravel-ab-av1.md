# foxws/laravel-ab-av1

> 标签: ab-av1, av1, encoding, ffmpeg, foxws, laravel, video

## 简介

A Laravel package for encoding videos to AV1 format using ab-av1.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
