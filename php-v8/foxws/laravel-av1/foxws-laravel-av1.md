# foxws/laravel-av1

> 标签: ab-av1, av1, compression, encoder, encoding, laravel, video, vmaf

## 简介

A Laravel package for ab-av1 video encoding with AV1

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
