# codelibrary/countries

> 标签: countries, csv, json, world, xml, yaml

## 简介

List of world countries in JSON, CSV, XML and Yaml

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://mledoze.github.io/countries/
- 源码仓库：https://github.com/CodeLibrary/countries.git
- Packagist 页面：https://packagist.org/packages/codelibrary%2Fcountries

## 获取地址

- Composer 安装：`composer require codelibrary/countries`
- Packagist 仓库：https://repo.packagist.org/p2/codelibrary/countries.json
- 许可证：ODbL-1.0
- PHP 要求：>=8.2
