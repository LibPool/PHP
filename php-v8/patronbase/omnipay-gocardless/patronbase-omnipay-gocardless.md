# patronbase/omnipay-gocardless

> 标签: direct debit, gateway, go cardless, gocardless, merchant, omnipay, pay, payment, redirect

## 简介

GoCardless payment gateway driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
