# tagadvance/trapdoor

> 标签: database, debug, logging, pdo, prepared-statement, sql

## 简介

A PDO extension that renders prepared queries with their bound values for debug-level logging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
