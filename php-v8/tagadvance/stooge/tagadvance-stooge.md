# tagadvance/stooge

> 标签: WebDAV, client, cookie, curl, http, https, query, request, session, url

## 简介

A fluent builder around PHP's cURL extension for making HTTP requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
