# analog/analog

> 标签: PSR3, alerts, amon, apprise, chrome-logger, console, debug, debugging, error, errors, firephp, gelf, log, logger, logging, logs, monitor, monitoring, psr-3, stderr, syslog

## 简介

Fast, flexible, easy PSR-3-compatible PHP logging package with dozens of handlers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
