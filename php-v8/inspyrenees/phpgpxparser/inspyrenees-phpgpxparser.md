# inspyrenees/phpgpxparser

> 标签: elevation, gpx, ign, parser

## 简介

GPX parsing and analysis toolkit in PHP, with elevation correction using the IGN API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
