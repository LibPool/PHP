# anrdaemon/minecraft-nbt

> 标签: PHP

## 简介

PHP classes to handle Minecraft NBT (Named Binary Tag) format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
