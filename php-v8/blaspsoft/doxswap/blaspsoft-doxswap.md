# blaspsoft/doxswap

> 标签: blaspsoft, doxswap

## 简介

Doxswap is a simple document conversion package for Laravel which uses LibreOffice to convert documents to a variety of formats.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
