# patricksamson/phpunit-flaky-fix

> 标签: flaky, pest, php, phpunit, reproduce, test, testing

## 简介

A PHPUnit extension to help reproduce flaky tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
