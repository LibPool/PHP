# yiiassets/yii2-bootbox-asset

> 标签: asset, bootbox, yii

## 简介

Yii2 asset bundle of bootbox plugin (http://bootboxjs.com/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
