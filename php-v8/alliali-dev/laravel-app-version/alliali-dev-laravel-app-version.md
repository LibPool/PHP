# alliali-dev/laravel-app-version

> 标签: app, artisan, laravel, semver, version

## 简介

Incrémente automatiquement la version d'une application Laravel via une commande Artisan.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
