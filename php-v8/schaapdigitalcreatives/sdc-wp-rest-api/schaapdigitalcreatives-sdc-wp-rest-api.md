# schaapdigitalcreatives/sdc-wp-rest-api

> 标签: PHP

## 简介

Custom endpoints and rest fields for WP Blocks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
