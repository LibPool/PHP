# albrightlabs/toggley-php

> 标签: feature flags, feature toggles, laravel, toggley

## 简介

Toggley feature flags for PHP and Laravel: evaluates flags locally from a cached config.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
