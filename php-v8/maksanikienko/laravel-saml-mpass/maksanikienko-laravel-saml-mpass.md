# maksanikienko/laravel-saml-mpass

> 标签: Authentication, Moldova, SSO, laravel, mpass, saml

## 简介

Laravel package for SAML 2.0 authentication via MPass — the Republic of Moldova government SSO/SLO service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
