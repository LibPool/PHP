# zohopayments/php-sdk

> 标签: Zoho, api, payment-gateway, payments, sdk

## 简介

Official PHP SDK for the Zoho Payments API (IN, IN Sandbox, and US editions).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.zoho.com/payments/
- 源码仓库：https://github.com/zoho/zoho-payments-php-sdk.git
- Packagist 页面：https://packagist.org/packages/zohopayments%2Fphp-sdk
