# khawarmd/laravel-broadcast-mqtt

> 标签: Broadcast, Broadcasting, events, iot, laravel, mqtt

## 简介

Laravel broadcast driver that publishes events over MQTT (using php-mqtt/laravel-client). Plug-and-play with Laravel events and ShouldBroadcast / ShouldBroadcastNow.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
