# c4ys/ueditor

> 标签: extension, ueditor, widget, yii2

## 简介

UEditor for Yii2, 允许配置上传路径以及上传action

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
