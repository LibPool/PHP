# brockhaus-ag/contao-microsoft-sso-bundle

> 标签: BROCKHAUS AG, SSO, adfs, bundle, contao

## 简介

Mit dem Contao Microsoft SSO Bundle der BROCKHAUS AG, können Sie sich ganz bequem per SSO im Contao Backend anmelden.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
