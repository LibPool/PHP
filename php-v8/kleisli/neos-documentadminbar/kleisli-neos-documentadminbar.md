# kleisli/neos-documentadminbar

> 标签: PHP

## 简介

A backend admin bar for Neos CMS to provide backend functions implemented in the document prototype.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
