# friendsoforo/oro-customer-tracking-bundle

> 标签: PHP

## 简介

OroCommerce Bundle to inject Tracking Code (eg LogRocket, Hotjar, FullStory, etc)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
