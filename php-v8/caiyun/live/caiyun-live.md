# caiyun/live

> 标签: PHP

## 简介

Caiyun multi-driver live streaming package for Laravel (Tencent / Aliyun / Huawei / Volcengine / Agora)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
