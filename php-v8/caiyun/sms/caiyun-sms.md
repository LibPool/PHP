# caiyun/sms

> 标签: aliyun, caiyun, cloopen, huawei, laravel, sms, tencent, volcengine

## 简介

Multi-driver SMS package for Laravel supporting Aliyun, Tencent, Huawei, Volcengine and Cloopen.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
