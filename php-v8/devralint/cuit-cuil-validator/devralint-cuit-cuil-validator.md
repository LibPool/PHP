# devralint/cuit-cuil-validator

> 标签: CUIT, afip, arca, argentina, cuil, cuit-validator, validador, validator

## 简介

Validador y parser de CUIT/CUIL argentinos (dígito verificador módulo 11). Sin dependencias de framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
