# vezolabs/pimcore-cloud-storage-bundle

> 标签: PHP

## 简介

Production-Ready Cloud Storage Manager for Pimcore 12 Studio supporting Amazon S3, Azure Blob, and Google Cloud Storage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
