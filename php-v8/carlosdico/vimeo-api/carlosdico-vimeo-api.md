# carlosdico/vimeo-api

> 标签: video, vimeo

## 简介

Fork Official PHP library for the Vimeo API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/carlosdico/vimeo.php.git
