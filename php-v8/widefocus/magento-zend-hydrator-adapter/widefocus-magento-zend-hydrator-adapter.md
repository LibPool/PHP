# widefocus/magento-zend-hydrator-adapter

> 标签: PHP

## 简介

A bridge to use the Zend Hydrator implementation instead of the Magento2 implementation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
