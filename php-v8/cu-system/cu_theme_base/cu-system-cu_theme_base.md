# cu-system/cu_theme_base

> 标签: PHP

## 简介

Default Drupal theme used with the CU Drupal Starter Kit, based on Bootstrap Barrio 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
