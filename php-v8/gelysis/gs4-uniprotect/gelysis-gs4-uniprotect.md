# gelysis/gs4-uniprotect

> 标签: silverstripe, spam, spamprotection

## 简介

Simple spam protection module for Silverstripe 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
