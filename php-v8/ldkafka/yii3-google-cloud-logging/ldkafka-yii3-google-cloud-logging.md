# ldkafka/yii3-google-cloud-logging

> 标签: cloud-logging, docker, gcplogs, google-cloud, logging, mcp, psr-3, stackdriver, yii3

## 简介

Google Cloud Logging for PHP 8 / Yii3 without the Google SDK: service-account auth, read and search entries, write entries, a PSR-3 logger, a query filter builder and an optional MCP tool

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
