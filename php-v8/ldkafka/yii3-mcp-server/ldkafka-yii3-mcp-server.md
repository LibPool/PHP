> 标签: ai, claude, github-copilot, http, json-rpc, mcp, model-context-protocol, psr-15, stdio, streamable-http, tool-server, yii, yii3

## 简介

Model Context Protocol (MCP) server framework for Yii3 applications - expose custom tools to AI assistants over stdio or Streamable HTTP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
