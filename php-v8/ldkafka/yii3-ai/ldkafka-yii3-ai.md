# ldkafka/yii3-ai

> 标签: ai, anthropic, claude, llm, mcp, model-context-protocol, psr-3, tool-use, yii3

## 简介

One request and response format for AI model APIs in PHP 8 / Yii3, without vendor SDKs: an Anthropic Messages adapter, a bounded tool loop, conversation stores, cost accounting and a client for remote MCP tools

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
