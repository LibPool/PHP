# ldkafka/yii2-queue-redis-ng

> 标签: aging, delay, lua, priority, priority-queue, queue, redis, retry, yii2, yii2-queue

## 简介

Redis driver for yii2-queue with job priority, atomic (crash-safe) reservation, configurable ordering of retried and delayed jobs, and optional aging against starvation. Drop-in replacement for the stock driver.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
