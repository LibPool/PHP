# digitalunited/wp-base

> 标签: plugin, wordpress

## 简介

Utiltiy for revisioning of acf and cpt-ui configurations and some other awesomeness

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
