# simsoft/slim

> 标签: Authentication, api, api-resource, cors, csrf, datatable, error-handler, middleware, php, psr-15, psr-7, quota, rate-limit, rest, router, routing, simsoft, slim, slim4, slimframework

## 简介

A fluent routing wrapper for Slim Framework 4 with simplified request/response helpers, middleware, error handling, API resources, and DataTable support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
