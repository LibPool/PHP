# simsoft/data-flow

> 标签: batch, csv, data-flow, data-processing, etl, extract, iterator, load, php, pipeline, spreadsheet, streaming, transform, xlsx

## 简介

A lightweight, composable ETL (Extract, Transform, Load) pipeline library for PHP with fluent API, spreadsheet support, and flow control.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
