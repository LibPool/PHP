# simsoft/validator

> 标签: constraints, form-validation, input-validation, laravel, php, rules, simsoft, symfony, validation, validator

## 简介

A Laravel-inspired validation wrapper for Symfony Validator with custom rules, error handling, and validated input support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
