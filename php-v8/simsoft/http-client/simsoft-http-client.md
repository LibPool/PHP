# simsoft/http-client

> 标签: API-Client, curl, fluent-api, http-client, middleware, oauth2, pkce, psr-18, psr-7, rest, retry, streaming

## 简介

A fluent PHP HTTP client with built-in OAuth2, retry, middleware, and streaming — powered by cURL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
