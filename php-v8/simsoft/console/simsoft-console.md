# simsoft/console

> 标签: PSR-11, artisan, cli, closure-command, command, command-line, console, cron, dependency-injection, laravel, php, scheduler, simsoft, symfony, terminal

## 简介

A lightweight, Laravel-inspired wrapper for Symfony Console — build PHP CLI commands with less boilerplate.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
