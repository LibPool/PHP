# dconco/phpspa

> 标签: SPA, component-based, component-library, jsx, php, phpspa

## 简介

A component-based library for building modern, reactive user interfaces in pure PHP. Inspired by React. ✨

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
