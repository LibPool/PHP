# brilliantmind/mkesh

> 标签: EWP, ericsson, laravel, mkesh, mobile-money, mozambique, pagamkesh, payments

## 简介

PHP package for the MKESH (PagamKesh) mobile money integration over the Ericsson EWP Aggregator (XML over HTTP), with first-class Laravel support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
