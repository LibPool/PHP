# sso-frappe/laravel

> 标签: OpenId, SSO, frappe, laravel, lumen, oauth, socialite

## 简介

OAuth2 / OIDC client for Frappe SSO — 'Login with Frappe' for Laravel and Lumen apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
