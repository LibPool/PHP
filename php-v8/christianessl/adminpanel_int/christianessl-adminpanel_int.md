# christianessl/adminpanel_int

> 标签: extension, typo3

## 简介

Extend the adminpanel by showing the actual info for each USER_INT object on the page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
