# christianessl/adminpanel_routing

> 标签: adminpanel, extension, routing, typo3

## 简介

Debug Routing information in the adminpanel in TYPO3 9.5+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
