# genealabs/laravel-maps

> 标签: biostall, googlemaps, laravel, phpgmaps

## 简介

Eay - peasy map integration for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
