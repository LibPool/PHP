# genealabs/laravel-appleseed

> 标签: PHP

## 简介

Prevent the pesky missing-favicon error log entries, and return 404 if they don't exist.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
