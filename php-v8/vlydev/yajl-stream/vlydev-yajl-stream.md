# vlydev/yajl-stream

> 标签: extension, json, parser, streaming, yajl

## 简介

Stream the elements of a huge JSON array out of a file in constant memory, on top of libyajl

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
