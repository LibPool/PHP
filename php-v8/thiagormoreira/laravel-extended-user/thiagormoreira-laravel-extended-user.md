# thiagormoreira/laravel-extended-user

> 标签: PHP

## 简介

This Laravel package adds profile page, account page, and extra features to Laravel's authenticated users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
