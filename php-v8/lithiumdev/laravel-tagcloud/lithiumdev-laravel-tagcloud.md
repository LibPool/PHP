# lithiumdev/laravel-tagcloud

> 标签: laravel, laravel tag cloud, laravel tagcloud, tag cloud, tagcloud

## 简介

A Laravel package for generating tag clouds.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
