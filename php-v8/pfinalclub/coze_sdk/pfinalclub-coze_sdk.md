# pfinalclub/coze_sdk

> 标签: PFinalClub, ai, api, bot, chat, coze, jwt, pfinal, php, sdk, streaming

## 简介

Coze AI PHP 版本的 SDK - 完整的聊天、机器人管理和流式处理功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
