# pfinalclub/regex-center

> 标签: library, pattern, php, regex, regular-expression, validation

## 简介

PHP 版本的正则表达式管理库，内置 100+ 精选正则，支持团队标准化

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
