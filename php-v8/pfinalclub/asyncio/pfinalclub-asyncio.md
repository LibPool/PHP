# pfinalclub/asyncio

> 标签: async, asyncio, concurrent, coroutine, event-loop, fiber, workerman

## 简介

An embeddable, composable, and reasonable PHP Async Runtime

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
