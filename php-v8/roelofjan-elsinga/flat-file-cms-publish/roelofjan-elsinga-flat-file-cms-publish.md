# roelofjan-elsinga/flat-file-cms-publish

> 标签: cms, file, laravel

## 简介

A publishing plugin for roelofjan-elsinga/aloia-cms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
