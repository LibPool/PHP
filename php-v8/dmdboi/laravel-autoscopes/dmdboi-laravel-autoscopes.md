# dmdboi/laravel-autoscopes

> 标签: dev, laravel, laravel-autoscopes

## 简介

Automatically generate scope traits for Laravel Models based on foreign key relationships.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
