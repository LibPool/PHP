# wpsmith/mupluginmanager

> 标签: mu-plugins, plugins, wordpress

## 简介

Manages the auto-installation of a mu-plugin for a plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
