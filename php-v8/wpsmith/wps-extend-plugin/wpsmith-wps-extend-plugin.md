# wpsmith/wps-extend-plugin

> 标签: dependency, extension, plugin, wordpress

## 简介

A class for your WordPress plugin to extend and declare another plugin as a plugin dependency.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
