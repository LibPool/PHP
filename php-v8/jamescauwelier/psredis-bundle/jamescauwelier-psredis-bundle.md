# jamescauwelier/psredis-bundle

> 标签: PHP

## 简介

A symfony bundle to make it easy to configure PSRedis project classes in the dependency injection container

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
