# cryptolike/sdk

> 标签: USDT, api client, bitcoin, crypto, crypto payments, cryptocurrency, cryptolike, hmac, invoices, payment gateway, payments, sdk, webhooks

## 简介

Official server-side SDK for the CryptoLike merchant API: signed requests, automatic Idempotency-Key, retries with backoff, webhook signature verification. PHP 7.4-8.x, no runtime dependencies, works without Composer (autoload.php).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
