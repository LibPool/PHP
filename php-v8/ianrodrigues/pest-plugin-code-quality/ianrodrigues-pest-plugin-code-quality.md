# ianrodrigues/pest-plugin-code-quality

> 标签: architecture, complexity, pest, pest-plugin, quality, static-analysis

## 简介

Method-level and class-level maintainability limits (complexity, body lines, parameters, methods, properties, inheritance depth) as Pest architecture expectations, with baselines for gradual adoption.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
