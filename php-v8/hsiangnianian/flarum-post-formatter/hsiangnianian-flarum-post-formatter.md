# hsiangnianian/flarum-post-formatter

> 标签: bbcode, formatting, html

## 简介

Allow posts to be formatted and rendered with a subset of BBCode and HTML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
