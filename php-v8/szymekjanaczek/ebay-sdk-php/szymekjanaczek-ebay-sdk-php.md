# szymekjanaczek/ebay-sdk-php

> 标签: api, ebay, php 8.2, sdk

## 简介

An eBay SDK for PHP. Fork of dts/ebay-sdk-php with support for PHP 8.2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
