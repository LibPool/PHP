# marekmiklusek/laravel-monitor-client

> 标签: error-tracking, exceptions, failed-jobs, heartbeat, laravel, logging, monitoring, observability, php, uptime

## 简介

Self-hosted error and uptime monitoring for Laravel. The client package that ships exceptions, failed jobs and heartbeats to your own server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
