# jfelixstudio/lumen-analytics

> 标签: JfelixStudio, analytics, google, laravel, lumen, reports, retrieve

## 简介

A lumen package to retrieve Google Analytics data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
