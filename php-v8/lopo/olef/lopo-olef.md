# lopo/olef

> 标签: CFB, compound, compound-file, ole, ole2, structured-storage

## 简介

PHP library for reading and writing Microsoft OLE Compound Documents (Structured Storage / CFB format)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
