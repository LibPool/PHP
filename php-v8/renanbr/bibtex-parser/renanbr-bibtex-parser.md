# renanbr/bibtex-parser

> 标签: Bibliography, bib, bibtex, citation, cite, latex, parser

## 简介

BibTex Parser provides an API to read .bib files programmatically

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
