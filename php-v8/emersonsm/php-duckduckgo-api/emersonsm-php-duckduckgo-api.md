# emersonsm/php-duckduckgo-api

> 标签: api, duckduckgo, search

## 简介

Open-source library for integrating DuckDuckGo's Zero-click Info API with PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
