# mivodev/laravel-radius

> 标签: facade, laravel, mivo, radius, udp

## 简介

Laravel Wrapper for Mivo Radius UDP Client with Hybrid Connection Manager.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
