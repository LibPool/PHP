# mivodev/radius

> 标签: COA, mivo, pod, radius, rfc2865, udp

## 简介

A pure PHP RADIUS protocol client (UDP) for Mivo Enterprise. Framework-Agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
