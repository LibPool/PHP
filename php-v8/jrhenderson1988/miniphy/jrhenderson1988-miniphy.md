# jrhenderson1988/miniphy

> 标签: PHP

## 简介

A HTML/PHP template minifier. Includes support for Laravel's Blade compiler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
