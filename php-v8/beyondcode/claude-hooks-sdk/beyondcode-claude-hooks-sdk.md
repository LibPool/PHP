# beyondcode/claude-hooks-sdk

> 标签: beyondcode, claude, claude-hooks-sdk, hooks

## 简介

A PHP SDK for building Claude Code hooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
