# php-forge/baseline-frontend

> 标签: baseline, css, frontend, linters, php-forge, prettier, scaffold-provider, scss, stylelint

## 简介

Frontend baseline for Prettier and stylelint tooling shared via yii2-extensions/scaffold.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
