# php-forge/baseline

> 标签: ECS, baseline, ci, coding-standards, editorconfig, linters, php, php-forge, prettier, quality, rector, scaffold-provider

## 简介

Centralized PHP development baseline: code style, linters, CI workflows, and dev environment tooling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
