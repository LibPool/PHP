# php-forge/foxy

> 标签: Bridge, asset, bun, composer, dependency manager, nodejs, npm, package, yarn

## 简介

Fast, reliable, and secure Bun/NPM/Yarn/pnpm bridge for Composer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
