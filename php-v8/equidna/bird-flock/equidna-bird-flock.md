# equidna/bird-flock

> 标签: PHP

## 简介

Bird Flock - messaging bus for multi-channel outbound messaging (SMS, WhatsApp, Email) with DLQ and idempotency

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
