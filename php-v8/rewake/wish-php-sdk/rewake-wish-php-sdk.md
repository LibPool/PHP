# rewake/wish-php-sdk

> 标签: merchant, php, sdk, wish

## 简介

A PHP SDK for Wish merchants

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://merchant.wish.com/api/documentation
- 源码仓库：https://github.com/rewake/wish-php-sdk.git
- Packagist 页面：https://packagist.org/packages/rewake%2Fwish-php-sdk

## 历史版本号

- 当前版本：v0.1.1

- v0.1.1

## 获取地址

- Composer 安装：`composer require rewake/wish-php-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/rewake/wish-php-sdk.json
- 许可证：Apache-2.0
- PHP 要求：>5.3.0
