# jcolombo/granola-api-php

> 标签: api, granola, granola.ai, meeting notes, php, rest, sdk, standard webhooks, transcripts, webhooks

## 简介

PHP SDK for the Granola meeting-notes API, with a framework-agnostic webhook parser and signature verifier

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
