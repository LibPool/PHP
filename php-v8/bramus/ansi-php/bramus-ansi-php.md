# bramus/ansi-php

> 标签: PHP

## 简介

ANSI Control Functions and ANSI Control Sequences (Colors, Erasing, etc.) for PHP CLI Apps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
