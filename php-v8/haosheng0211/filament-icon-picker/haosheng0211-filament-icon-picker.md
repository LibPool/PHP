# haosheng0211/filament-icon-picker

> 标签: FontAwesome, Heroicons, Phosphor, blade-icons, filament, filament-plugin, icon-picker, laravel, material-icons

## 简介

A beautiful icon picker component for Filament v3 using blade-ui-kit/blade-icons (fork of wallacemartinss/filament-icon-picker with Filament 3 / Laravel 10+ support)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
