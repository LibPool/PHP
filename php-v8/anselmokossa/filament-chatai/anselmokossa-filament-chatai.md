# anselmokossa/filament-chatai

> 标签: ai, assistant, chat, filament, filament-plugin, generative-ui, laravel, mcp

## 简介

An AI assistant for Filament panels — floating chat, a full-page chat and generative UI (KPIs, tables, charts) driven by your own tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
