# vespula/user

> 标签: acl, permissions, role, user, zend

## 简介

A simple user class for working with Laminas Permissions ACL. It extends the Laminas\Permissions\Acl\Role\RoleInterface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
