# vespula/paginator

> 标签: paginate, pagination

## 简介

A package that creates simple pagination links. No reliance on ORMs or arrays. Has a generic, bootstrap, and foundation adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
