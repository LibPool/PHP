# vespula/notifier

> 标签: Mattermost, email, ms teams, notifications, notifier, notify, slack

## 简介

A simple notification library to send notifications to various adapters such as email, mattermost.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
