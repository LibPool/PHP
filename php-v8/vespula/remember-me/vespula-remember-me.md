# vespula/remember-me

> 标签: cookie, persistent login, remember me

## 简介

A simple PHP package for managing persistent 'remember me' authentication using secure cookies and database-backed tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
