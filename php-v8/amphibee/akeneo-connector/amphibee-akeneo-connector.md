# amphibee/akeneo-connector

> 标签: plugin, wordpress

## 简介

Connect Akeneo with WooCommerce. The plugin uses the Akeneo api to import Akeneo PIM data (attributes, products, variations..)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
