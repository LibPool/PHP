# motsmanish/cakephp-mailgun

> 标签: cakephp, cakephp3, email, mailgun, transport

## 简介

Send mail via Mailgun SDK in CakePHP 3.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
