# masfernandez/nginx-proxy-local-development

> 标签: PHP

## 简介

Easy management for SSL/TLS certificates and proxying local webservers for fast development setups!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
