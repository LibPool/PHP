# vvk/id-card

> 标签: 15位身份证号转18位, vvk, 身份证号, 身份证号生成, 身份证归属地

## 简介

一个用于身份证号归属地查询、身份证号生成、15位身份证号转18位身份证号的包

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
