# netom/mandango-behaviors

> 标签: behaviors, mandango

## 简介

Behaviors for Mandango, the Simple, powerful and ultrafast Object Document Mapper (ODM) for PHP and MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
