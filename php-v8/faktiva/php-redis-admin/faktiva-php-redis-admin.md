# faktiva/php-redis-admin

> 标签: PHP

## 简介

PHP Redis Admin is a simple web interface to manage and monitor your Redis server(s).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
