# davmixcool/php-dbcloud

> 标签: database, db, mysql, postgresql, sql

## 简介

Easily backup PostgreSql or MySql database to the cloud

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
