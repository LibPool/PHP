# shawnveltman/laravel-openai

> 标签: laravel, laravel-openai, shawnveltman

## 简介

An OpenAI API wrapper that uses the Laravel Http facade for easier testing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
