# exeque/laravel-monocle

> 标签: Agent, debug, laravel, mcp, profiler, timing

## 简介

Agent-focused request profiler for Laravel with an MCP server: timing spans, queries, cache, filesystem, AI agent calls and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
