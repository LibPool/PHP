# dersonsena/yii2-deploy

> 标签: bitbucket deploy, deploy, github deploy, yii2

## 简介

Módulo de deploy automático no formato de Modules do Yii Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
