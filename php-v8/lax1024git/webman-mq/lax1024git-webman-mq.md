# lax1024git/webman-mq

> 标签: MQ, broker, message-queue, queue, wal, webman

## 简介

High-throughput local message queue broker plugin for Webman (WAL + sharded brokers, no Redis).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
