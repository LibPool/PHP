# cronheart/wp

> 标签: cron, cronheart, deadman-switch, healthcheck, monitoring, wordpress, wordpress-plugin, wp-cron

## 简介

Official WordPress plugin for cronheart.com — monitor WP-Cron events and detect when scheduled events stop firing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
