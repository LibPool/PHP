# shimmi2/ai-agent

> 标签: Agent, ai, assistant, email, llm, openai, plugin, roundcube

## 简介

Roundcube plugin for an AI agent over your mailbox: chat with the agent, its instructions and a log of its work. Server-side agent behind a small REST API and an OpenAI-compatible chat endpoint.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
