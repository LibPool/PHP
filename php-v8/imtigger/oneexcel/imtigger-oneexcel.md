# imtigger/oneexcel

> 标签: LibXL, PHPExcel, csv, excel, fputcsv, ods, spout, xls, xlsx

## 简介

PHP Excel read/write abstraction layer, support PhpSpreadSheet, LibXL, Spout and PHP fputcsv

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
