# globalis/chargebee-php-sdk

> 标签: API-Client, chargebee

## 简介

Chargebee API PHP Client (for API version 2 and Product Catalog version 2.0)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
