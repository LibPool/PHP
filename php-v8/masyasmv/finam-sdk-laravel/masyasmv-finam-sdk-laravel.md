# masyasmv/finam-sdk-laravel

> 标签: api, broker, finam, laravel, php, rest, sdk, trade, trading

## 简介

PHP SDK for Finam Trade API with Laravel integration (REST).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
