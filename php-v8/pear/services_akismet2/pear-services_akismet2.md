# pear/services_akismet2

> 标签: Akismet, spam

## 简介

Provides an object-oriented interface to the Akismet REST API. The Akismet API is used to detect and to filter spam.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
