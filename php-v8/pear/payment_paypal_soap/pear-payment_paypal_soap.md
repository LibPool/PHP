# pear/payment_paypal_soap

> 标签: paypal, soap

## 简介

Provides an easy-to-use wrapper of PHP 5's SOAP client for use with the PayPal SOAP API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
