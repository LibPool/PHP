# pear/crypt_gpg

> 标签: PGP, encryption, gnupg, gpg

## 简介

Provides an object oriented interface to the GNU Privacy Guard (GnuPG). It requires the GnuPG executable to be on the system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
