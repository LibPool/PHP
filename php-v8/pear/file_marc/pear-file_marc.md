# pear/file_marc

> 标签: PHP

## 简介

Supports the MAchine Readable Cataloging (MARC) file format documented at http://loc.gov/marc/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
