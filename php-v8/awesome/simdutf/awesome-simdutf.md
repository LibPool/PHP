# awesome/simdutf

> 标签: base64, simd, unicode, utf16, utf32, utf8

## 简介

Unicode (UTF8, UTF16, UTF32) and Base64 processing at billions of characters per second in PHP using the simdutf library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
