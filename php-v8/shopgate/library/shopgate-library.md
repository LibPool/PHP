# shopgate/library

> 标签: PHP

## 简介

A PHP framework supporting the implementation of the Shopgate Plugin API and abstracts access to the Shopgate Merchant API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
