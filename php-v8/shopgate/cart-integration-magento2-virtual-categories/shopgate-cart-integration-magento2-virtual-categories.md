# shopgate/cart-integration-magento2-virtual-categories

> 标签: PHP

## 简介

Shopgate virtual category module for Magento 2. Exports virtual categories created with the Smile_ElasticsuiteVirtualCategory module.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
