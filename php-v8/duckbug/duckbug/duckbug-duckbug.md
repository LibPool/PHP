# duckbug/duckbug

> 标签: crash-reporting, crash-reports, duckbug, error-handler, error-monitoring, log, logging, profiling, tracing

## 简介

Compatibility package and full PHP SDK for DuckBug (https://duckbug.io)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
