# nedarta/php-assetopt

> 标签: assets, compress, css, javascript, minify, optimizer

## 简介

PHP asset optimizer: a clean port of the YUI CSS compressor plus a whitespace/comment stripper for JavaScript

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
