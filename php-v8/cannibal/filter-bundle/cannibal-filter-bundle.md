# cannibal/filter-bundle

> 标签: criteria, filtering, filters, rest, search, sort

## 简介

Provides a standard interface for filtering any resource collection internally or via a uri request

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
