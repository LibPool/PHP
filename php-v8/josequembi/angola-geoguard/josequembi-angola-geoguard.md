# josequembi/angola-geoguard

> 标签: access-control, angola, angola-geoguard, geo-access-control, geo-blocking, geofencing, geolocation, geospatial, laravel, laravel-package, multi-tenant, saas, security, territorial-access

## 简介

Pacote PHP e Laravel para geolocalização, geofencing, controlo territorial, restrição de acesso e segurança geoespacial em Angola.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
