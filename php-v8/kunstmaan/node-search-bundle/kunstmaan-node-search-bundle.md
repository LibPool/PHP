# kunstmaan/node-search-bundle

> 标签: elasticsearch, kunstmaan, node, search

## 简介

This bundle uses the KunstmaanSearchBundle to search through Nodes from the KunstmaanNodeBundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
