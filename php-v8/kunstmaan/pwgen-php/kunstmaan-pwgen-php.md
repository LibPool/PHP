# kunstmaan/pwgen-php

> 标签: generator, password

## 简介

pwgen-php is a simple PHP class which aims to clone the GNU pwgen functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
