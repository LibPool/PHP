# neuronsearchlab/sdk-php

> 标签: neuronsearchlab, personalization, php, product-discovery, recommendation-systems, recommendations, sdk, search

## 简介

Official PHP SDK for NeuronSearchLab recommendations, events, catalogue sync, and search.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
