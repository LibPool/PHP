# webbuilders-group/silverstripe-facebook-login

> 标签: facebook, login, silverstripe

## 简介

Adds ability to login with facebook graph api v3.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
