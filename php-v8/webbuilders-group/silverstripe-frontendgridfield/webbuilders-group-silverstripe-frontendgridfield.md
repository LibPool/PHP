# webbuilders-group/silverstripe-frontendgridfield

> 标签: frontend, gridfield, silverstripe

## 简介

Wraps gridfield adding support for using it on the front-end.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
