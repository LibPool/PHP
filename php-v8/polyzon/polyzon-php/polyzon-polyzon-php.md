# polyzon/polyzon-php

> 标签: 3D-models, 3d-printing, api, makerworld, polyzon, printables, sdk, search, stl, thingiverse

## 简介

Official PHP SDK for the Polyzon public API: search 3D models across Thingiverse, Printables, MakerWorld, Cults3D and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
