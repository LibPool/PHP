# zaimea/charts

> 标签: apexcharts, charts, laravel, livewire, zaimea, zaimealabs

## 简介

Charts is a Laravel package that provides a simple, elegant integration of ApexCharts into your Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
