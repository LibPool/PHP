# nonzod/yii2-zend-ldap

> 标签: ZendFramework, ldap, yii2, zend-ldap

## 简介

yii2 ldap extention (wrapper for zendframework/zend-ldap Module)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
