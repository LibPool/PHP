# li-bao-jia/miniprogram-ci-service-php-sdk

> 标签: miniprogram, php, sdk, wechat

## 简介

miniprogram-ci-service 的 PHP SDK，便于在 PHP 系统中快速集成 miniprogram-ci-service 实现微信小程序上传、预览、……、成员管理等服务

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
