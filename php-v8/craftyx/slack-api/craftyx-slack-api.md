# craftyx/slack-api

> 标签: laravel, lumen, slack

## 简介

Wrapper for Slack.com WEB API. Based on Vagner do Carmo one, but compatible with GuzzleHttp6

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
