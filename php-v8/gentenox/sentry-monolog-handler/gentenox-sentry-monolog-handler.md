# gentenox/sentry-monolog-handler

> 标签: sentry, symfony

## 简介

Custom Sentry handler for Monolog for sending log context data to sentry eventsand it's focussed on ease-of-use and elegant syntax.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
