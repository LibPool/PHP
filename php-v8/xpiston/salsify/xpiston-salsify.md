# xpiston/salsify

> 标签: PIM, PXM, laravel, product-information-management, productxm, salsify, symfony, webhooks

## 简介

A PHP SDK for the Salsify ProductXM API: records, exports, imports and signed webhooks, for Laravel, Symfony or no framework at all.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
