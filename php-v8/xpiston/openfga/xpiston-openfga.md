# xpiston/openfga

> 标签: authorization, fga, fine-grained-authorization, laravel, openfga, psr-18, rebac, symfony, zanzibar

## 简介

A PHP SDK for OpenFGA: checks, relationship tuples, authorization models and a real DSL parser, for Laravel, Symfony or no framework at all.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
