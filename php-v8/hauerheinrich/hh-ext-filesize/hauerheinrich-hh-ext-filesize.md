# hauerheinrich/hh-ext-filesize

> 标签: FAQ, TYPO3 CMS, extension, typo3

## 简介

Hauer-Heinrich - List all file-sizes within given directory which are greater then e. g. 300kb.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
