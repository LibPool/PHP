# hauerheinrich/hh-readable-anchor

> 标签: TYPO3 CMS, anchor, extension

## 简介

Lesbare Sprungmarken (Anker-IDs) für alle Inhaltselemente – aus der Überschrift oder einem eigenen Feld.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
