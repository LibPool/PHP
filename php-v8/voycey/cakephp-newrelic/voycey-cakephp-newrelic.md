# voycey/cakephp-newrelic

> 标签: cakephp, middleware, newrelic, transaction name

## 简介

Adds transaction naming to NewRelic for CakePHP 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
