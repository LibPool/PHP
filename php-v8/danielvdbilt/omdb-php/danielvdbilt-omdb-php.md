# danielvdbilt/omdb-php

> 标签: PHP

## 简介

PHP API for omdb movie database with: movie info, imdb scores and rotten tomatoes scores

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
