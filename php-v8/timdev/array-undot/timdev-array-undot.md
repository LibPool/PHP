# timdev/array-undot

> 标签: PHP

## 简介

A utility to normalize arrays with dotted-string keys. ['a.b' => 'c'] ==> ['a' => ['b' => 'c']]

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
