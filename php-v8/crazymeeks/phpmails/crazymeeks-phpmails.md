# crazymeeks/phpmails

> 标签: PHP Mailer, email, grid, php mail library, send, sendgrid

## 简介

This library will help you send emails with SendGrid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
