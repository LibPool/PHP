# jaschweder/mandrill

> 标签: api, email

## 简介

API client library for the Mandrill email as a service platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/jaschweder/mandrill-api
- 源码仓库：https://github.com/jaschweder/mandrill-api.git
- Packagist 页面：https://packagist.org/packages/jaschweder%2Fmandrill

## 获取地址

- Composer 安装：`composer require jaschweder/mandrill`

- 许可证：Apache-2.0
