# dave-liddament/phpstan-effect-system

> 标签: PHPStan, effects, phpstan-extension, static analysis

## 简介

PHPStan extension implementing a lightweight effect system: declare effects at the source, infer transitive propagation, enforce effect-free boundaries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
