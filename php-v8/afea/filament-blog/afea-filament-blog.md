# afea/filament-blog

> 标签: afea, blog, cms, filament, laravel

## 简介

Blog module for the Afea Filament CMS package ecosystem: blog posts, categories, tags with SEO, media and polymorphic forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
