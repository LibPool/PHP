# afea/filament-faq

> 标签: FAQ, afea, cms, filament, laravel

## 简介

FAQ module for the Afea Filament CMS package ecosystem: categorized FAQs with polymorphic attachment to any content model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
