# afea/filament-files

> 标签: afea, cms, filament, files, laravel

## 简介

File manager module for the Afea Filament CMS package ecosystem: uploaded files + external links, grouped and orderable.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
