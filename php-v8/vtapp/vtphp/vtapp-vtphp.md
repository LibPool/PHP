# vtapp/vtphp

> 标签: api, framework, psr-15, psr-7, rest

## 简介

VtPhp — an independent, API-first PHP framework with Laravel-inspired developer experience, built on PSR standards and Symfony/Doctrine/Monolog components, with optional Eloquent ORM persistence and Blade templating.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
