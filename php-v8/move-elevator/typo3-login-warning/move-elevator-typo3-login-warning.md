# move-elevator/typo3-login-warning

> 标签: PHP

## 简介

Login Warning - Extends the TYPO3 backend login warning_mode functionality to inform about suspicious logins with several features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
