# max-currency-cloud/client

> 标签: cloud, currency

## 简介

A PHP library which implements the complete functionality of v2 of the The Currency Cloud API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
