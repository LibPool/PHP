# ahmedlaggoun/smsala

> 标签: laravel, notifications, otp, sms, smsala

## 简介

SOLID, driver-based SMS layer for Laravel with an SMSala gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
