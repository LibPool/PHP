# shanginn/jev-php

> 标签: OpenRouter, ai, classification, jev, sdk, typesafe

## 简介

Type-safe PHP SDK for JEV decisions on OpenRouter: choices, scores, probabilities and typed objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
