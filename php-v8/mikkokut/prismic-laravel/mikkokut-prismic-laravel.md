# mikkokut/prismic-laravel

> 标签: Prismic, api, cms, framework, laravel

## 简介

Integrates the Prismic PHP development kit with Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
