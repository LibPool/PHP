# vldmir/tin

> 标签: NINO, Ssn, bsn, input-mask, tax, tin, validation

## 简介

Enhanced Taxpayer Identification Number validator with input masks (fork of loophp/tin)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
