# klehm/content-blocks-i18n

> 标签: content-blocks, i18n, multilingual, page-builder, symfony, symfony-bundle, translation

## 简介

Content translation for ContentBlocks — one shared layout, per-locale field values, translation progress and pluggable machine translation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
