# klehm/content-blocks-kit

> 标签: blocks, content-blocks, page-builder, symfony, symfony-bundle, symfony-ux

## 简介

Nineteen ready-to-use, self-contained block types for ContentBlocks (title, text, rich text, image, gallery, button, card, tabs, video…).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
