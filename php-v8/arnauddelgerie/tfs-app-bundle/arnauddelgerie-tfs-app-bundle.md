# arnauddelgerie/tfs-app-bundle

> 标签: desktop-app, local-first, symfony, symfony-bundle, tfsapp, tfsapphub

## 简介

Symfony bundle for apps run by TFSAppHub, a host that installs and runs Symfony apps as local desktop apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
