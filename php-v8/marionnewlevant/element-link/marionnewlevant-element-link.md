# marionnewlevant/element-link

> 标签: Craft, cms, craft-plugin, craftcms, element link

## 简介

Add a link to the CP edit page for Entries, Categories, and other Elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
