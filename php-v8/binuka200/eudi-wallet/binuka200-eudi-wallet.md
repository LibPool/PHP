# binuka200/eudi-wallet

> 标签: eidas, eudi, openid4vp, pid, verifiable-credentials, wallet

## 简介

Framework-neutral PHP façade for EU Digital Identity Wallet verification via a remote OpenID4VP verifier.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
