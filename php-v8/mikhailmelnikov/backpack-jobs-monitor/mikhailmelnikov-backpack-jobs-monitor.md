# mikhailmelnikov/backpack-jobs-monitor

> 标签: Backpack Addon, Backpack for Laravel, backpack, failed jobs, laravel, queue, scheduler

## 简介

Backpack for Laravel add-on: scheduler tasks and database queue jobs in the admin panel — list, run, retry, forget, flush.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
