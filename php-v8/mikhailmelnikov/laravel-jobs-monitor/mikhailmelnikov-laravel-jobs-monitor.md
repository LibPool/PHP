# mikhailmelnikov/laravel-jobs-monitor

> 标签: failed jobs, jobs monitor, laravel, queue, scheduler

## 简介

Admin-agnostic core for monitoring Laravel scheduled tasks and database queue jobs: list, run, retry, forget, flush.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
