# guilhermedev98/larasms

> 标签: laravel, sms, smsgateway

## 简介

SMS gateway for Laravel using various vendors (SMSGateway.me, Zenziva, etc)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
