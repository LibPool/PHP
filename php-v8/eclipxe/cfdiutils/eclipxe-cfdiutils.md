# eclipxe/cfdiutils

> 标签: cfdi, cfdi33, cfdi40, electronic invoice, mexico

## 简介

PHP Common utilities for Mexican CFDI 3.2, 3.3 & 4.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
