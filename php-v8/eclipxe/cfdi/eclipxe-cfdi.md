# eclipxe/cfdi

> 标签: cfdi, cfdi3.3, mexico, sat

## 简介

Library to create a Mexican CFDI 3.3 (Comprobante Fiscal por Internet)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
