# leefipay/mpesa

> 标签: api, kenya, laravel, leefipay, mpesa, payments, stk-push

## 简介

Official Laravel package for integrating applications with the LeefiPay M-Pesa Open API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
