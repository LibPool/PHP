# stromcom/auth-client

> 标签: SSO, auth, client, jwt, oauth2, oidc, stromcom

## 简介

Official PHP client for the STROMCOM SSO / OAuth 2.0 / OIDC server (auth.stromcom.cz).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
