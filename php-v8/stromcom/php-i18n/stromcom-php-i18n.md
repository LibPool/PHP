# stromcom/php-i18n

> 标签: PHP

## 简介

Translator.stromcom.cz client + AST-based scanner for PHP / Twig / XSLT sources (keys and notification templates). Runtime t() helper, XSLT post-processor, PSR-15 locale middleware, Symfony Console workflow. Zero regex on sources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
