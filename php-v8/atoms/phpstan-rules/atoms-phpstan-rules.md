# atoms/phpstan-rules

> 标签: PHPStan, atoms, static analysis

## 简介

PHPStan rules enforcing the Atoms boundary: no framework symbols in Atom code, serialization-algebra checks, Shared-zone purity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
