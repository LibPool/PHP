# atoms/cli

> 标签: atoms, build, cli

## 简介

The `atoms` command-line tool: init, make, validate, build (closure walk + vendor stage), deploy, rollback, local, ai:install.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
