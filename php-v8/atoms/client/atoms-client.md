# atoms/client

> 标签: atoms, rpc, sdk

## 简介

Framework-agnostic monolith-side SDK for Atoms: RPC stub proxies, callback kernel, manifest loader.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
