# sowl/laravel-doctrine-jsonapi

> 标签: PHP

## 简介

Package for the Laravel that allows developers to create JSON:API endpoints using the Doctrine ORM for data persistence.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
