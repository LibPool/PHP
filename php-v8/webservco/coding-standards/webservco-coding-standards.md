# webservco/coding-standards

> 标签: coding-standard, webservco

## 简介

Custom, opinionated coding standards based on PSR12, SlevomatCodingStandard, and PHPCompatibility.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
