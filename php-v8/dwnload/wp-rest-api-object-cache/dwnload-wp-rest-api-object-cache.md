# dwnload/wp-rest-api-object-cache

> 标签: PHP

## 简介

Enable object caching for WordPress' REST API. Aids in increased response times of your applications endpoints.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
