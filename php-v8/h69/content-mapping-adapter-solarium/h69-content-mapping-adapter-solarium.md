# h69/content-mapping-adapter-solarium

> 标签: PHP

## 简介

Adapter for the solarium Solr client inside the h69/content-mapping mini framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
