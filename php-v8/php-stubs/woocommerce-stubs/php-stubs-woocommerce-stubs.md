# php-stubs/woocommerce-stubs

> 标签: PHPStan, static analysis, woocommerce, wordpress

## 简介

WooCommerce function and class declaration stubs for static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
