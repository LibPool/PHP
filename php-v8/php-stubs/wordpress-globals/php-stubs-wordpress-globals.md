# php-stubs/wordpress-globals

> 标签: PHPStan, constants, globals, static analysis, wordpress

## 简介

Global variables and global constants from WordPress core.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
