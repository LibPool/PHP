# php-stubs/wordpress-seo-stubs

> 标签: PHPStan, seo, static analysis, wordpress, yoast

## 简介

Yoas SEO function and class declaration stubs for static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
