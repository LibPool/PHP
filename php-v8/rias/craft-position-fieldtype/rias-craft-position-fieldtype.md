# rias/craft-position-fieldtype

> 标签: Craft, cms, craft-plugin, craftcms, position fieldtype

## 简介

Brings back the Position fieldtype from Craft 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
