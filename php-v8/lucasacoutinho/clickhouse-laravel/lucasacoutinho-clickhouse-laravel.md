# lucasacoutinho/clickhouse-laravel

> 标签: analytics, clickhouse, database, laravel, native, pdo

## 简介

ClickHouse database driver for Laravel using native TCP, typed inserts, and no cURL dependency

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
