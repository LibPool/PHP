# malek83/polish-vat-payer

> 标签: PHP

## 简介

Library using Polish Ministry of Finance WebService to validate if given VAT Number is registered as VAT Tax Payer in Poland

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
