# nanos/openai-exceptions

> 标签: PHP

## 简介

Use the OpenAI API together with Laravel Ignition's Suggestions to show AI-powered fixes for errors in your Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
