# samuel-olavo/laravel-rt-bestpratical

> 标签: bestpractical, helpdesk, laravel, request-tracker, rest2, rt, tickets

## 简介

Laravel package to interact with the Request Tracker (RT) REST2 API — tickets, correspondence, queues, users, custom fields and attachments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
