# ghostff/session

> 标签: memcached, non-blocking, redis, secured-session, segment, session, session-manger, sql

## 简介

PHP Session Manager (non-blocking, flash, segment, session encryption).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
