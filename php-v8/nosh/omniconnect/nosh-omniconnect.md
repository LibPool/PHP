# nosh/omniconnect

> 标签: catalog, delivery-hero, food-delivery, foodpanda, integration-middleware, laravel, omniconnect, orders, pakistan, pos

## 简介

OmniConnect — a Laravel package for integrating a restaurant/POS system with foodpanda (Delivery Hero's POS Integration Middleware). It is two-directional: it CALLS Delivery Hero to accept/reject orders, mark them prepared, push menus and toggle store/item availability, and it RECEIVES orders and updates from Delivery Hero over a mountable Plugin API (signed webhooks) that it normalizes and hands to your app. Platform-driven, multi-tenant, and extensible to further delivery platforms by design. A Nosh (RapidFlow) package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
