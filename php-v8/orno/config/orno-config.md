# orno/config

> 标签: array, config, ini, orno, xml, yaml

## 简介

A package to DRY the storage and retrieval of config items and files. Supports YAML, INI, XML and PHP arrays.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
