# orno/di

> 标签: container, dependency, di, injection, orno

## 简介

Orno\Di is a small but powerful dependency injection container with automatic resolution of dependencies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
