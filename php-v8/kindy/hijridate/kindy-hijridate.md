# kindy/hijridate

> 标签: Date Conversion, Date Conversion To Hijri, Hijri Date, Laravel Hijri Date, PHP Hijri Date, hijri

## 简介

Package for Hijri date conversion and manipulation in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
