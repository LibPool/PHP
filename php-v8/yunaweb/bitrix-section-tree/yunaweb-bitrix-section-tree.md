# yunaweb/bitrix-section-tree

> 标签: PHP

## 简介

Build/flatten section trees from flat lists (e.g. Bitrix CIBlockSection / D7 SectionTable rows) without hierarchy hacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
