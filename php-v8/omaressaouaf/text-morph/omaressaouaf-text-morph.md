> 标签: decoding, decoding-algorithms, encoding, encoding-algorithms, encoding-decoding, omaressaouaf, php, text-morph, text-transformation

## 简介

A lightweight PHP package for reversible text transformations using simple morphing algorithms and a composable pipeline

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
