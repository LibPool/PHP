# simpledatalogs/laravel

> 标签: analytics, events, laravel, logging, monolog, simpledatalogs

## 简介

Send events, Eloquent model changes, auth events and Laravel log channels to simpledatalogs through a disk outbox, never blocking the app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
