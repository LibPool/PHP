# fg/cakephp-elasticsearch

> 标签: client, elasticsearch, search

## 简介

A plugin to use the Elasticsearch client in a CakePHP 2 project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
