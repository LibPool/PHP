# mattyeend/prevent-destructive-commands

> 标签: Destructive, Prevent-Destructive-Commands, commands, laravel, package, prevent

## 简介

A Laravel package to stop destructive commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
