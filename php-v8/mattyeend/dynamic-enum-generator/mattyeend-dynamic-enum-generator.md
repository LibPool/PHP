# mattyeend/dynamic-enum-generator

> 标签: Dynamic-Enum, Dynamic-Enum-Generator, Dynamic-Enums, Generate-Enums, dynamic, enum, enums, generate, generate-enum, laravel, package

## 简介

Automatically generate PHP enums from database columns in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
