# thoughtsideas/dev-tools-wp

> 标签: PHP

## 简介

A collection of development tools for WordPress projects. Helping simplift and standardise your development process.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
