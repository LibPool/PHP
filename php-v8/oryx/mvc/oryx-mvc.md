# oryx/mvc

> 标签: framework, league, mvc, oryx, php, prototyping, web

## 简介

Lightweight MVC framework for rapid prototyping - A librarian package built on PHP League ecosystem

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
