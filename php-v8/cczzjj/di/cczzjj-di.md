# cczzjj/di

> 标签: PSR-11, attributes, container, dependency injection, di, ioc, psr11

## 简介

Simple Dependencies Container following PSR-11 standards, using php8 Attributes like Spring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
