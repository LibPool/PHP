# eiprice/php-webdriver

> 标签: PHP

## 简介

Webdriver for Eiprice bot

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：http://www.eiprice.com.br
- 源码仓库：https://gitlab.com/eiprice/libs/php/webdriver.git
- Packagist 页面：https://packagist.org/packages/eiprice%2Fphp-webdriver

## 获取地址

- Composer 安装：`composer require eiprice/php-webdriver`
- Packagist 仓库：https://repo.packagist.org/p2/eiprice/php-webdriver.json
- PHP 要求：>=7.1
