# devsitarget/sdk-pagarme-php

> 标签: PHP

## 简介

SDK PHP para integração com Pagar.me v5 (Boleto, Pix, Cartão e consulta de transações)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
