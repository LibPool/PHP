# devsitarget/sdk-cielo-php

> 标签: PHP

## 简介

SDK PHP para integração com a API E-commerce Cielo (crédito, consulta, captura e cancelamento)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
