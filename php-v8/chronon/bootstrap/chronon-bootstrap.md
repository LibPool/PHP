# chronon/bootstrap

> 标签: bootstrap, cakephp, plugin

## 简介

Twitter Bootstrap packaged as a CakePHP plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/chronon/CakePHP-Bootstrap-Plugin
- 源码仓库：https://github.com/chronon/CakePHP-Bootstrap-Plugin.git
- Packagist 页面：https://packagist.org/packages/chronon%2Fbootstrap
