# ekrembk/flysystem-backblaze

> 标签: Flysystem, api, backblaze, client, filesystem

## 简介

Backblaze adapter for the flysystem filesystem abstraction library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
