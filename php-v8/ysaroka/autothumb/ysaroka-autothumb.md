# ysaroka/autothumb

> 标签: Thumbnails, auto, cache, image, php, resize, thumb

## 简介

AutoThumb, PHP library to automatically create thumbnails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
