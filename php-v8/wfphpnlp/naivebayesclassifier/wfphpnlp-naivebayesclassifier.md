# wfphpnlp/naivebayesclassifier

> 标签: Naive Bayes Classifier, NaiveBayesClassifier, bahasa indonesia, klasifikasi naive bayes, klasifikasi teks, naive bayes, naivebayes, php Naive Bayes Classifier, php NaiveBayes, php NaiveBayesClassifier, php naive bayes

## 简介

PHP library for Indonesian text classification using the Naive Bayes Classifier (NBC) approach.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
