# dknx01/data-fixtures-phpunit

> 标签: Fixture, persistence, tests

## 简介

Symfony Bundle to use Doctrine data fixtures in PHPUnit tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
