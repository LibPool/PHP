# vmatkovskii/video-dl

> 标签: cli, composer package, downloader, ffmpeg, video, yt-dlp

## 简介

Simple terminal tool to download and re-encode videos using yt-dlp and ffmpeg

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
