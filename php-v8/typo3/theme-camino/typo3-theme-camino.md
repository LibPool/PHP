# typo3/theme-camino

> 标签: PHP

## 简介

TYPO3 Theme: "Camino" - The default theme for TYPO3 sites in the TYPO3 v14 series.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
