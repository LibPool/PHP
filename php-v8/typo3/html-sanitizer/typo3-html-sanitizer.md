# typo3/html-sanitizer

> 标签: PHP

## 简介

HTML sanitizer aiming to provide XSS-safe markup based on explicitly allowed tags, attributes and values.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
