# connectmedia/sms

> 标签: airtel, bulk sms, connect media, kenya, safaricom, sms, sms api

## 简介

Official PHP client for the Connect Media SMS API: bulk SMS to Safaricom, Airtel and Telkom in Kenya and 190+ countries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
