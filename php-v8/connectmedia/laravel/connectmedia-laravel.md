# connectmedia/laravel

> 标签: airtel, bulk sms, connect media, kenya, laravel, notification channel, notifications, safaricom, sms

## 简介

Laravel integration for the Connect Media SMS API: send bulk and transactional SMS and SMS notifications to Safaricom, Airtel and Telkom in Kenya.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
