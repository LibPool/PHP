# cline/json-schema

> 标签: json, json-schema, laravel, php, schema, validation

## 简介

Immutable JSON Schema implementation with support for drafts 2020-12, 2019-09, draft-07, draft-06, and draft-05

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
