# cline/intl

> 标签: address, country, currency, i18n, internationalization, intl, l10n, laravel, locale, localization, phone-number, postal-code, spatie-laravel-data, symfony-intl, timezone, validation, value-objects

## 简介

Type-safe internationalization value objects and validation rules for Laravel applications including countries, currencies, locales, phone numbers, postal codes, and addresses

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
