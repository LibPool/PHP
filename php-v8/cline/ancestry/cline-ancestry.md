# cline/ancestry

> 标签: ancestors, closure-table, descendants, eloquent, hierarchy, laravel, nested, tree

## 简介

Closure table hierarchies for Eloquent models with O(1) ancestor/descendant queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
