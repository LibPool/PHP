# cline/prism

> 标签: cli, php, prism, termwind, test-suite, testing

## 简介

Declarative test runner for validation libraries with snapshot testing, fuzzing, benchmarking, and parallel execution

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
