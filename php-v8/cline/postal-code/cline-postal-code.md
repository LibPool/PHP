# cline/postal-code

> 标签: formatting, laravel, php, postal-code, postcode, validation, zip-code

## 简介

Validates and formats postal codes for all countries with a Laravel-first approach

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
