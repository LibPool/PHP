# cline/sso

> 标签: SSO, auth, laravel, oidc, php, saml, scim

## 简介

Laravel-first SSO, OIDC, SAML, and SCIM primitives with package-owned persistence and adapter seams.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
