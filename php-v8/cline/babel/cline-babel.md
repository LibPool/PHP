# cline/babel

> 标签: ascii, encoding, i18n, php, string, transliteration, unicode, utf8

## 简介

Unicode-aware string encoding, conversion, and analysis library for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
