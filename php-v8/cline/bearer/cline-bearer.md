# cline/bearer

> 标签: Authentication, api-tokens, laravel, php, sanctum

## 简介

Stripe-style typed API tokens with groups, environments, and audit logging for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
