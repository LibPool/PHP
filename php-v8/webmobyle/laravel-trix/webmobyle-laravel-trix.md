# webmobyle/laravel-trix

> 标签: PHP

## 简介

A reusable Laravel Trix editor package with min/max validation, counters, error focus, sanitization, and toolbar presets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
