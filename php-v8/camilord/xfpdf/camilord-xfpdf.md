# camilord/xfpdf

> 标签: fpdf, fpdi, pdf, xfpdf

## 简介

Extended FPDF include FPDF, FPDF Protection, HTML2PDF, etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
