# camilord/php-simple-html-dom-parser

> 标签: dom, html, parser, util, utils

## 简介

Composer wrapper for PHP Simple HTML DOM Parser from sourceforge.net

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
