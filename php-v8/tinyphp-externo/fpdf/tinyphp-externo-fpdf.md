# tinyphp-externo/fpdf

> 标签: PHP FPdf, PHP PDF, fpdf, pdf, pdf-generator

## 简介

Based in http://www.fpdf.org/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
