# jlucki/spark

> 标签: aws, data, database, dynamodb, mapper, mapping, nosql, object, odm, php

## 简介

Spark is an Object Document Mapper (ODM) for use with Amazon DynamoDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
