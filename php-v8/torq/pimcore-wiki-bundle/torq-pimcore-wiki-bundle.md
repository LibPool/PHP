# torq/pimcore-wiki-bundle

> 标签: PHP

## 简介

A Pimcore bundle for displaying markdown documentation files as a wiki in the admin interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
