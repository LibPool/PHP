# phpbinary/phpbinary

> 标签: phpbinary

## 简介

A PHP library to work with binary data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/phpbinary/phpbinary
- 源码仓库：https://github.com/phpbinary/phpbinary.git
- Packagist 页面：https://packagist.org/packages/phpbinary%2Fphpbinary

## 获取地址

- Composer 安装：`composer require phpbinary/phpbinary`
