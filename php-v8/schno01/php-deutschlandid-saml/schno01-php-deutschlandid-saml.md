# schno01/php-deutschlandid-saml

> 标签: Federation, SAML2, SSO, identity, saml

## 简介

Simple SAML toolkit for bundID/deutschlandID in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
