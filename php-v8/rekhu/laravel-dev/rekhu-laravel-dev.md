# rekhu/laravel-dev

> 标签: Agent, ai, builder, debugging, laravel, monitoring, rekhu

## 简介

Rekhu Builder for Laravel: connects a Laravel app to its agent in a Rekhu account. It reads the running app, fixes errors on a git branch with tests, and watches the live site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
