# moderndesktop/oauth-forgejo

> 标签: flarum, forgejo, gitea, oauth

## 简介

Log in to Flarum with one or more Forgejo instances, using FoF OAuth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
