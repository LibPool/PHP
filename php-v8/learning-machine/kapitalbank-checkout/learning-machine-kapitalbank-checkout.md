# learning-machine/kapitalbank-checkout

> 标签: azerbaijan, birbank, checkout, kapitalbank, payments, psr-18

## 简介

Framework-agnostic PHP client for the Kapital Bank / Birbank Checkout API (OAuth2 token, payments, refunds, webhooks) with an optional Laravel service provider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
