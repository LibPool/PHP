# aquis/sylius-xporter-plugin

> 标签: sylius, sylius aquis plugin, sylius petro plugin, sylius-plugin, sylius-xporter-plugin

## 简介

Plugin allowing to export fixtures in yml format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
