# thiagoprz/cpfcnpj-validator

> 标签: PHP

## 简介

Laravel package to validate CPF (Brazilian taxpayer identification number) and CNPJ (national registry of legal entities in Brazil)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
