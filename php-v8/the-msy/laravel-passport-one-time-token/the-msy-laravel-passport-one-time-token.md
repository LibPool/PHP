# the-msy/laravel-passport-one-time-token

> 标签: laravel, one time token, passport

## 简介

Gives the ability to create one time tokens easily with Laravel Passport

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
