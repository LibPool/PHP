# okapi/aop

> 标签: aop, aspect-oriented-programming, php, php-aop

## 简介

PHP AOP is a PHP library that provides a powerful Aspect Oriented Programming (AOP) implementation for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
