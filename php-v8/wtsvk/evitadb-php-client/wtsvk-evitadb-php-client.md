# wtsvk/evitadb-php-client

> 标签: catalog, ecommerce, evitadb, gRPC, nosql

## 简介

PHP gRPC client for EvitaDB — generated stubs + session-based wrapper.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
