# anis-ly/partners

> 标签: Partner-API, anis, http-signatures, libya, rfc9421, sdk

## 简介

The PHP SDK for the Anis Partner API — signed requests, verified responses, typed operations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
