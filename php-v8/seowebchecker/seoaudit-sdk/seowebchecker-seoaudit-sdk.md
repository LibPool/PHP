# seowebchecker/seoaudit-sdk

> 标签: core-web-vitals, meta-tags, packagist-seo, seo, seo-audit, seo-checker, seowebchecker, website-audit

## 简介

Lightweight open-source client SDK and CLI tool for website SEO audits, on-page analysis, and Core Web Vitals checks by SEOWebChecker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
