# symkit/crud-bundle

> 标签: PHP

## 简介

Symfony bundle for generic CRUD, Live lists (filters, sort, pagination), Twig components (BackLink, DeleteForm, CrudList, CrudFilters) and Stimulus

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
