# lisachenko/protocol-fcgi

> 标签: binary, fastcgi, fcgi, network, php-fpm, protocol

## 简介

Implementation of the FastCGI (FCGI) protocol in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
