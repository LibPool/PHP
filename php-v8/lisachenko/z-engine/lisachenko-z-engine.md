# lisachenko/z-engine

> 标签: engine, extension, ffi, internals, operator-overloading, zend

## 简介

Write PHP extensions in pure PHP: direct FFI access to the Zend Engine internals

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
