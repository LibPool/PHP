# rabble/skeleton

> 标签: cms, data-managment, platform, project-template, rabble, symfony, web-application

## 简介

Project template for starting a project based on the Rabble admin system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
