# net-code/laravel-bus

> 标签: command-bus, cqrs, ddd, laravel, messaging, query-bus

## 简介

Attribute-routed command & query buses for Laravel with a configurable middleware pipeline.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
