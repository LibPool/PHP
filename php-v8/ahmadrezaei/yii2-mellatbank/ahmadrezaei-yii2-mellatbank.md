# ahmadrezaei/yii2-mellatbank

> 标签: extension, gateway, mellatbank, payment, yii2

## 简介

By this extension you can add mellat bank gateway to your yii2 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
