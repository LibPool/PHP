# fruitcake/phpunit-tia-laravel

> 标签: laravel, phpunit, test impact analysis, testing, tia

## 简介

Laravel integration for phpunit-tia: links tests to the views they render and the migrations of the tables they query

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
