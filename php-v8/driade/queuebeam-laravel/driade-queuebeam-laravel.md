# driade/queuebeam-laravel

> 标签: Google-Chat, discord, email, laravel, microsoft-teams, queues, retries, slack, webhooks

## 简介

Laravel SDK for Queuebeam durable outbound operations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
