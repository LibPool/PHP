# maatify/php-category

> 标签: category, content, hierarchy, maatify, mysql, pdo, php, taxonomy

## 简介

Framework-neutral hierarchical category and content domain with PDO persistence.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
