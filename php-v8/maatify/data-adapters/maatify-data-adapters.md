# maatify/data-adapters

> 标签: data-adapters, dependency-injection, di-boundary, doctrine-dbal, infrastructure, maatify, mongodb, pdo, predis, redis

## 简介

DI-first infrastructure adapters providing explicit ownership wrappers around real database and cache drivers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
