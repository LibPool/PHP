# maatify/php-slug

> 标签: Canonicalization, lifecycle, maatify, php, slug, slug-lifecycle

## 简介

Scoped slug lifecycle and canonicalization for PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
