# maatify/psr-logger

> 标签: hourly-rotation, logger, logging, maatify, maatify.dev, monolog, php, psr-3

## 简介

PSR-3 compatible logger with dynamic file naming and hourly rotation, powered by Monolog

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
