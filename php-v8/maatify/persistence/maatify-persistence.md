# maatify/persistence

> 标签: display-order, global-ordering, maatify, mysql, offset-pagination, ordering, pagination, pdo, pdo-pagination, pdo-transaction, persistence, php, savepoint, scoped-ordering, sort-order, transaction

## 简介

Standalone, framework-agnostic PDO ordering, transaction, and pagination utilities for Maatify projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
