# maatify/data-repository

> 标签: abstraction, adapter, clean-architecture, data-layer, data-repository, design-patterns, doctrine-dbal, maatify, mongo, mongodb, mysql, mysql-dbal, pdo, phpredis, predis, redis, repository, repository-pattern

## 简介

Unified repository abstraction layer normalizing MySQL, MongoDB, and Redis real drivers and fake drivers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
