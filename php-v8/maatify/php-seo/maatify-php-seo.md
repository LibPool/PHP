# maatify/php-seo

> 标签: JSON-LD, Sitemap, canonical, hreflang, maatify, metadata, open-graph, php, robots, schema, seo, twitter-card

## 简介

Standalone SEO library for metadata, JSON-LD, sitemaps, hreflang, redirects, and SEO validation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
