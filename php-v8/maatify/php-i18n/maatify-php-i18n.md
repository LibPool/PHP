# maatify/php-i18n

> 标签: i18n, internationalization, localization, maatify, mysql, php, translation

## 简介

Database-driven internationalization library for structured translation keys, exact language scopes, governance, and MySQL persistence.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
