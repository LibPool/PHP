# titugeorge/pubmed

> 标签: article, laravel, ncbi, pubmed

## 简介

API Wrapper to fetch PubMed article(s) with id(s) or by author name(s)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
