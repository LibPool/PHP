# jegex/laravel-media

> 标签: jegex, laravel, laravel-media

## 简介

Laravel media library — upload, image conversions, responsive images, video thumbnails, ZIP export, and more

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
