# fuseboxie/sdk

> 标签: ai, analytics, cost-control, fuseboxie, guardrails, tokens, usage

## 简介

Fuseboxie PHP SDK for guarding AI calls and tracking token usage from backend applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
