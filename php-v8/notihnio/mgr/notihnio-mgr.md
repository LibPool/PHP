# notihnio/mgr

> 标签: framework, greece, light, lightweight, mastrandrikos, megara, mvc, notihnio, notis, php

## 简介

Mgr is an open source light PHP Framwork framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
