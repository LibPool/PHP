# elmys/yii2-queue-redis

> 标签: extension, interface, queue, redis, web, yii2

## 简介

Quick deployment of an interface for easy work with queues based on Redis for Yii2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
