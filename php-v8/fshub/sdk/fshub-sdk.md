# fshub/sdk

> 标签: ICAO, flightsim, fshub, fshub.io, fsx, lrm, msfs2020, xplane

## 简介

The official PHP SDK for FsHub.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
