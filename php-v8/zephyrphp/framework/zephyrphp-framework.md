# zephyrphp/framework

> 标签: cms, framework, gui, php, secure, zephyr, zephyrphp

## 简介

ZephyrPHP - An open-source, GUI-first CMS platform for building modern websites.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
