# kwn/number-to-words

> 标签: currency, money, number, numbers, string, to, words

## 简介

Multi language standalone PHP number to words converter. Fully tested, open for extensions and new languages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
