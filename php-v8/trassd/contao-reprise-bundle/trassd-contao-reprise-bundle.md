# trassd/contao-reprise-bundle

> 标签: assets, contao, reprise, rsbuild, vite

## 简介

Integrates symfony/reprise (Vite/Rsbuild) into Contao: select entrypoints per page layout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
