# docuccino/laravel

> 标签: api-docs, api-documentation, documentation-generator, laravel, laravel-openapi, openapi, openapi-generator, rest-api, scramble-alternative, swagger, uir

## 简介

Generate OpenAPI 3.2 and 3.1 documentation for a Laravel API automatically, from the real types in your code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
