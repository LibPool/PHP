# thisismahabadi/laravel-feature-flags

> 标签: laravel

## 简介

This package helps you implement feature flags in your Laravel application without a 3rd party service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
