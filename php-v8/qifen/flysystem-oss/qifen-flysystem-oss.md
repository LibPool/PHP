# qifen/flysystem-oss

> 标签: Flysystem, aliyun-oss, flysystem-aliyun-oss

## 简介

AliYun OSS adapter for flysystem V2. aliyuncs/oss-sdk-php ~2.4

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
