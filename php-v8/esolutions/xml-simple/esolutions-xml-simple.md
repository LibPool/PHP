# esolutions/xml-simple

> 标签: cpe, facturacion-electronica, peru, sunat, ubl, xml

## 简介

Emision CPE SUNAT: construccion UBL, firma, envio (SUNAT/OSE/Nubefact/GRE) y validacion basica + CDR. Version estandar sin motor de reglas SFS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
