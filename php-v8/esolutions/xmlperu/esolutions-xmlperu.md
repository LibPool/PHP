# esolutions/xmlperu

> 标签: cpe, facturacion-electronica, peru, pse, sunat, ubl

## 简介

Cliente PHP de la API de xmlperu.dev: firma y emisión de comprobantes electrónicos (CPE) a SUNAT/OSE, y administración de empresas emisoras.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
