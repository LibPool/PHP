# jsrmalvarez/similar-numbers

> 标签: PHP

## 简介

Tools for getting visually similar numbers (e.g. 3 is similar to 8, 5 is similar to 6, specially when handwritten)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
