# mmo-and-friends/estados-municipios-mexico

> 标签: PHP

## 简介

Un paquete de php y javascript de los estados y municipios de mexico, soporta el comando mexico:publish para laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
