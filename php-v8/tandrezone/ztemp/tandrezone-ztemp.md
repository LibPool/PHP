# tandrezone/ztemp

> 标签: engine, template, templating

## 简介

A lightweight, secure PHP template engine supporting {{ $variable }}, @include(), and @foreach()/@endforeach directives.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
