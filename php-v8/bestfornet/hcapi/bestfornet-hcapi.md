# bestfornet/hcapi

> 标签: hcapi, heureka, kosik-api, marketplace

## 简介

Heureka shopping cart API - Bestfornet fork with Depot API codes and tolerant price validation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
