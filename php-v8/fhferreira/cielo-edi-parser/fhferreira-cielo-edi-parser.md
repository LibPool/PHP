# fhferreira/cielo-edi-parser

> 标签: cielo, concilar, edi, retorno

## 简介

Projeto para processar arquivo retorno no formato EDI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
