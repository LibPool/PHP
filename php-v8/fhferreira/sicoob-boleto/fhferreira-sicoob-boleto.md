# fhferreira/sicoob-boleto

> 标签: boleto, remessa, retorno, sicoob

## 简介

Projeto para criar arquivos de remessas e processar arquivos de retorno no formato CNAB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
