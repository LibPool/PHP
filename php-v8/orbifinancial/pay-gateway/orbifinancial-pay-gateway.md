# orbifinancial/pay-gateway

> 标签: PHP

## 简介

Official ORBI Pay Gateway SDK for server-side payments, PaySafe escrow, identity lookup, and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
