# saritasa/opbeat-laravel

> 标签: errors, laravel, logging, opbeat

## 简介

Laravel integration for Opbeat (https://opbeat.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://opbeat.com
- 源码仓库：https://github.com/Saritasa/opbeat-laravel.git
- Packagist 页面：https://packagist.org/packages/saritasa%2Fopbeat-laravel

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- Composer 安装：`composer require saritasa/opbeat-laravel`
- Packagist 仓库：https://repo.packagist.org/p2/saritasa/opbeat-laravel.json
- 许可证：MIT
