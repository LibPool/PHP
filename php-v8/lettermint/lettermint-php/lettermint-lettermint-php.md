# lettermint/lettermint-php

> 标签: email, lettermint, lettermint-php, php, sdk, transactional email, webhooks

## 简介

Official Lettermint PHP SDK: send email, manage the Team API and verify webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
