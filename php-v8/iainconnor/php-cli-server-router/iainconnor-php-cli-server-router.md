# iainconnor/php-cli-server-router

> 标签: PHP

## 简介

A simple router for the PHP CLI server and bindings for it to Lumen/Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
