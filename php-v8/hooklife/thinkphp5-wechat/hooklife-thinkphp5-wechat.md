# hooklife/thinkphp5-wechat

> 标签: thinkphp5, wechat, weixin

## 简介

微信 SDK for thinkphp5, 基于 overtrue/wechat

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
