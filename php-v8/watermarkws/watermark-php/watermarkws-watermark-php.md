# watermarkws/watermark-php

> 标签: api, image, pdf, video, watermark

## 简介

PHP client for the Watermark API: watermark, resize and convert images, videos and PDFs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://api.watermark.ws/docs
- 源码仓库：https://github.com/watermarkws/watermark-php.git
- Packagist 页面：https://packagist.org/packages/watermarkws%2Fwatermark-php
