# yoeunes/icu-parser

> 标签: ast, cli, i18n, icu, lexer, messageformat, parser, php, plural, select

## 简介

High-performance ICU MessageFormat parser with lexer, AST, type inference, and CLI tooling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
