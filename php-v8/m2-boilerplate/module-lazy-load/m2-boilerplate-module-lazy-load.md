# m2-boilerplate/module-lazy-load

> 标签: composer-installer, iframes, images, lazy-loading, lazyload, lazyload-iframes, lazyload-images, lazyload-script, lazyload-videos, magento, magento 2, vanilla-lazyload, videos

## 简介

Magento 2 module to add Lazy Load support to all images, videos and iframes in the Magento frontend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
