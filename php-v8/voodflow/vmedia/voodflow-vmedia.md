# voodflow/vmedia

> 标签: filament, filamentphp, gallery, laravel, media, spatie, vmedia, voodflow

## 简介

Filament Media Vault (Filament 5 + Spatie Media Library). Standalone admin, HTTP API, galleries; plugins register their own vault roots.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
