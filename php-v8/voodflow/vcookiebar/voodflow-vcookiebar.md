# voodflow/vcookiebar

> 标签: consent, cookie, cookie-banner, filament, filamentphp, gdpr, laravel, vcookiebar, voodflow

## 简介

Cookie consent for Laravel and Filament 5 — GDPR opt-in banner, script gating, multilingual admin settings. Standalone MIT; optional VoodBuilder theme.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
