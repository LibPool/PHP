# purelines/whapi-sdk

> 标签: api, sdk, whapi, whatsapp

## 简介

Fixed version of PHP SDK for Whapi.Cloud API to interact with WhatsApp via HTTP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
