# novius/laravel-backpack-menu

> 标签: Novius, backpack, laravel, menu

## 简介

Manages the editing and rendering of menus in Laravel application using Backpack

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
