# centamiv/vektor

> 标签: binary-storage, embeddings, hnsw, php, search, vector-database

## 简介

A native PHP Vector Database implementation with strict binary storage and Zero-RAM overhead.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
