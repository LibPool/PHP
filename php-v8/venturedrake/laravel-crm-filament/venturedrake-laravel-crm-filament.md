# venturedrake/laravel-crm-filament

> 标签: crm, filament, filament-plugin, filamentphp, laravel, laravel-crm, venturedrake

## 简介

Filament v4 & v5 panel plugin for the venturedrake/laravel-crm package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
