# matejch/yii2-sidebar-collapsible

> 标签: collapsible, extension, sidebar, widget, yii2

## 简介

Add sidebar that can be collapsed to smaller version

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
