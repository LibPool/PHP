# jlibs/medoo

> 标签: database, database library, lightweight, mariadb, mssql, mysql, oracle, php framework, postgresql, sql, sqlite

## 简介

The lightweight PHP database framework to accelerate development

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
