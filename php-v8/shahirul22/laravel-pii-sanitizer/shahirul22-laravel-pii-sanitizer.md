# shahirul22/laravel-pii-sanitizer

> 标签: anonymize, database, faker, gdpr, laravel, pii, sanitize

## 简介

A Laravel package for sanitizing PII in a database during local/dev workflows (e.g. after importing a production dump). Development-time tool only — never for production.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
