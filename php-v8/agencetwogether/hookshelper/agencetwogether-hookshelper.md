# agencetwogether/hookshelper

> 标签: agencetwogether, filament, filamentphp, helper, hooks, laravel

## 简介

Simple plugin to toggle display hooks available in current page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
