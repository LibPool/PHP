# swegio/twitteroauth

> 标签: Twitter API, Twitter oAuth, api, oauth, rest, social, twitter

## 简介

The most popular PHP library for use with the Twitter OAuth REST API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
