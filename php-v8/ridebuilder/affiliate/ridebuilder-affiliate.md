# ridebuilder/affiliate

> 标签: affiliate, attribution, postback, ridebuilder

## 简介

Server-side SDK for RideBuilder FirstParty affiliate tracking: capture click_id and send checkout/return postbacks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
