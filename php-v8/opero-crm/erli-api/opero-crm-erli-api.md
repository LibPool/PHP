# opero-crm/erli-api

> 标签: api, crm, erli, erli-api, laravel, opero-crm, php, rest

## 简介

Manual PHP client for the Erli marketplace shop API (OperoCRM).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
