# vironeer/toastr

> 标签: alerts, flash messages, frontend, laravel, messages, notification, pop-up, toast, toastr, user interface, vironeer

## 简介

A Laravel package for displaying toast notifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
