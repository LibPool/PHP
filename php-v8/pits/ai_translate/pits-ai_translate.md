# pits/ai_translate

> 标签: Gemini, claude, cohere, deepl, extension, googletranslate, gpt4, mistral, pits, translate, typo3

## 简介

AI Translate brings fast, flexible translation directly into the TYPO3 backend. Translate content elements and TCA records automatically using leading AI and translation services - including Google Translate, DeepL, OpenAI (ChatGPT), Gemini, Claude and Cohere. Editors can auto-detect source language or select languages manually, making it a powerful auto translate and language translation solution for multilingual TYPO3 websites.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
