# anderss0n/persiana

> 标签: convertor, farsi, farsi convertor, farsi normalizer, normalizer, persian, persian convertor, persian normalizer

## 简介

Persiana is a Persian text normalizer utility that support English for every day usage with texts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
