# ayangzy/real-seed

> 标签: ai, factory, fake-data, faker, laravel, seeder, seeding, synthetic-data, test-data

## 简介

Generate realistic, relational, temporally coherent synthetic data for non-production Laravel environments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
