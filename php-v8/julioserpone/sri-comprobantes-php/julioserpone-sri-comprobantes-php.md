# julioserpone/sri-comprobantes-php

> 标签: comprobantes, ecuador, facturacion-electronica, sri, xades

## 简介

Paquete PHP para emitir y consultar comprobantes electrónicos del SRI de Ecuador (esquema off-line).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
