# julioserpone/gig-economics

> 标签: Uber, didi, driver-earnings, fuel-consumption, fuel-efficiency, gig-economy, indrive, lyft, profitability, ride-hailing, rideshare

## 简介

Platform-agnostic, decoupled PHP library to measure fuel efficiency and the real profitability of a trip taken on Uber, DiDi, inDrive, Lyft or any ride-hailing platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
