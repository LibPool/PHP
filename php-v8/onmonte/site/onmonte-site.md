# onmonte/site

> 标签: helper, integration, monte, onmonte, site

## 简介

Functions to easily communicate with a site created on Monte.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://onmonte.com/
- 源码仓库：https://github.com/onmonte/site.git
- Packagist 页面：https://packagist.org/packages/onmonte%2Fsite
