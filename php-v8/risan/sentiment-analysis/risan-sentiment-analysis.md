# risan/sentiment-analysis

> 标签: indonesian, nlp, opinion-mining, sentiment, sentiment-analysis, vader

## 简介

Fast, dependency-free sentiment analysis for PHP. VADER scoring for English and Indonesian.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
