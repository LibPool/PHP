# mirafive/sdk-laravel

> 标签: analytics, experiments, feature-flags, gdpr, laravel, mirafive, privacy

## 简介

Laravel integration of MIRA FIVE, privacy-first EU analytics: server-side events, feature flags and the tracker tag.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
