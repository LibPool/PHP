# mirafive/sdk-php

> 标签: analytics, experiments, feature-flags, gdpr, mirafive, privacy

## 简介

PHP SDK for MIRA FIVE, privacy-first analytics: server-side events and feature flags.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
