> 标签: api, magento2, odoo, ripcord, rpc, xml, xml-rpc, xmlrpc

## 简介

Ripoo : a PHP8 XML-RPC client handler for Odoo External API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
