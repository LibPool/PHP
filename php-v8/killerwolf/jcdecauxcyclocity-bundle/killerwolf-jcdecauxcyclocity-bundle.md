# killerwolf/jcdecauxcyclocity-bundle

> 标签: PHP

## 简介

this bundle provides easy integration of the Cyclocity OpenData Rest API provided by JCDecaux

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
