# fortyfive/static-site-pipeline-sync

> 标签: Craft, aws-codebuild, cms, craft-plugin, craftcms, pipeline, pipeline-sync, publication-workflow, static-site, static-site-pipeline-sync

## 简介

Gives Craft CMS the ability to trigger AWS CodeBuild projects to update the content of static sites. (where the content source is of course Craft CMS)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
