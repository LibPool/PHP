# seromenho/tripadvisor-review-express-api

> 标签: Review Express, tripadvisor

## 简介

Wrapper for the Tripadvisor Review Express API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
