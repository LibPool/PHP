# dompat/stemmer

> 标签: czech, english, indexing, nlp, search, stemmer, stemming

## 简介

A strictly-typed stemming library for PHP 8.3+. Supports Czech and English with Light and Aggressive modes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
