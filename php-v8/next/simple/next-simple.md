# next/simple

> 标签: Flexible, fpm, nextphp, php framework, swoole, workerman

## 简介

一款支持swoole/workerman/cli-server/FPM环境的PHP框架。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
