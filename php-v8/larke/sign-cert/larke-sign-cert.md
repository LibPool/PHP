# larke/sign-cert

> 标签: ECDSA, EdDSA, admin, lake, larke, larke-admin, larke-admin-signcert, rsa, sign-cert

## 简介

Make RSA, EdDSA, ECDSA, DSA publickeys base on larke-admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
