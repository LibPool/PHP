# alexsasharegan/model-framework

> 标签: OOP, orm, pdo

## 简介

Make getting started with data-driven apps easier by using some solid model classes and database abstractions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
