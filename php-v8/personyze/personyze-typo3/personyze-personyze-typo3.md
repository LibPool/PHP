# personyze/personyze-typo3

> 标签: TYPO3 CMS, ab-testing, analytics, personalization, recommendations

## 简介

Adds the Personyze personalization tag to every page of a TYPO3 site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
