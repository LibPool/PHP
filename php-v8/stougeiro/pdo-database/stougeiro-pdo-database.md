# stougeiro/pdo-database

> 标签: database, driver, emulation, mariadb, model, mysql, pagination, pdo, postgresql, prepared-statements, query-builder, sql, sqlite, transactions

## 简介

A dialect-agnostic PDO model for SQLite, MySQL, MariaDB and PostgreSQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
