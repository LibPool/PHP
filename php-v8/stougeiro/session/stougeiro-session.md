# stougeiro/session

> 标签: Session Security, file session, middleware, php session, php-fpm, session, session cookie, session destroy, session expiration, session handler, session lifecycle, session manager, session regeneration, session start, session storage, sqlite session

## 简介

A secure, predictable and extensible session manager for PHP‑FPM applications, featuring custom lifecycle, automatic expiration, safe ID regeneration and pluggable storage handlers (file and SQLite).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
