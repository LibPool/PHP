# stougeiro/pdo-contract

> 标签: contract, database, driver, interface, ir, model, mysql, pdo, postgresql, query-tree, sql, sqlite

## 简介

PDO-based database contract: interfaces and enums for a dialect-agnostic model, a single-method IR-driven driver and a normalized raw/result layer, covering SQLite, MySQL and PostgreSQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
