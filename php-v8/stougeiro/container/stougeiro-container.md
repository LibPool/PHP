# stougeiro/container

> 标签: Service-Locator, architecture, container, dependency-injection, di-container, framework-agnostic, inversion-of-control, ioc, lightweight, performance, php, service-container

## 简介

A fast and minimalistic Dependency Injection container focused on predictable behavior, low overhead and clean architecture for modern PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
