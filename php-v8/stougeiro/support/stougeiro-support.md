# stougeiro/support

> 标签: array, base64, date, filesystem, fqcn, helpers, mask, password, slugify, string, toolkit, transliterate, ttl, utilities, zero-dependency

## 简介

Lightweight PHP 8.2+ utilities for arrays, strings, dates, passwords, files, base64, and TTL — zero dependencies, PHPStan Level 9.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
