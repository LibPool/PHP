# venusian-surface/windows

> 标签: gui, menus, surface, venusian, windows

## 简介

Surface windows: toolkit windows with configurable menu bars over the toolkit bridge; their activity arrives as loop mail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
