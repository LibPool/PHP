# venusian-surface/human-input

> 标签: PHP

## 简介

Surface human input: keyboards, mice, game pads and game controllers from an input.<engine> engine or an integrated circuit, polled on the IOPool dock.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
