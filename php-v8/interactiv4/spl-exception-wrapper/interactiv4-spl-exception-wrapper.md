# interactiv4/spl-exception-wrapper

> 标签: exception, interactiv4, spl, wrapper

## 简介

This package contains useful classes for exception wrapper contracts implementation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
