# interactiv4/composer-installer-magento-deployed-package

> 标签: composer, deployed, installer, interactiv4, magento, package

## 简介

This package allows to deploy another packages in Magento directory.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
