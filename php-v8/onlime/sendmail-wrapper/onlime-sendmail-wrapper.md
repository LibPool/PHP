# onlime/sendmail-wrapper

> 标签: MTA, mysql, php, sendmail, throttling, wrapper

## 简介

A powerful sendmail wrapper to log and throttle emails sent by PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
