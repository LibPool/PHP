# swiftotter/popup

> 标签: PHP

## 简介

SwiftOtter's Popup JS module adds a widget into your webpack/AMD-style code to trigger a popup wherever you are.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
