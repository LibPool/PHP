# filipefernandes/laravel-turbo-excel

> 标签: csv, excel, export, fast, laravel, openspout, stream, xlsx

## 简介

Blazing fast, memory-efficient Excel and CSV exports/imports for Laravel powerd by OpenSpout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
