# quantaforge/sanctum

> 标签: auth, quantaforge, sanctum

## 简介

QuantaForge Sanctum provides a featherweight authentication system for SPAs and simple APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
