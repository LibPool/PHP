# quantaforge/serializable-closure

> 标签: closure, quantaforge, serializable

## 简介

QuantaForge Serializable Closure provides an easy and secure way to serialize closures in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
