# lkallas/estonianpin

> 标签: Personal id, estonia, isikukood, national id, personal identification code, personal identification number, php, pin

## 简介

A simple library for processing Estonian Personal Identification Code (isikukood).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
