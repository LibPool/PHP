# ctapu4ok/vk-messenger-sdk

> 标签: Messenger, bot, client, longpoll, messager, sdk, vk

## 简介

PHP implementation of VK Messenger LongPoll protocol.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
