# naif/mailchimp-tool

> 标签: laravel, mailchimp, nova, tool

## 简介

A Laravel Nova tool that integrate with MailChimp to add/edit subscribe and send email messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
