# naif/cpanel-mail

> 标签: cpanel, email, email_address, emailaddress, emailaddresses, laravel, mail, nova

## 简介

A Laravel Nova tool to manage Cpanel Mail to list/add/delete email addresses

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
