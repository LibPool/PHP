# williamrox45/encrypt-model

> 标签: PHP

## 简介

The idea of this package is very simple; it is to add encryption to the model class attributes in an automated way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
