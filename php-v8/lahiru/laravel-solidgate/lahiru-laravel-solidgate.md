# lahiru/laravel-solidgate

> 标签: alternative-payments, api, gateway, laravel, payment, payment-processing, recurring-payments, solidgate, subscriptions, webhooks

## 简介

Laravel SDK for SolidGate — card & APM payments, subscriptions, webhooks, and reporting with official HMAC-SHA512 signing, typed responses, and smart API defaults.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
