# m2e/mirakl-magento-adobe-commerce

> 标签: m2e, magento, mirakl, mirakl connector, mirakl extension for magento 2, mirakl magento, sell on mirakl, selling on mirakl

## 简介

Start selling on Mirakl with M2E Mirakl Connect. This native Adobe Commerce extension lets you add and categorize Magento products on Mirakl while efficiently managing orders and inventory

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
