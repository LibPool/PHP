# ecolabor/filament-swiss-uid-search

> 标签: UID, company, enterprise, filament, identification, laravel, search, swiss, switzerland

## 简介

Filament v5 plugin for searching Swiss companies via the UID (Unternehmens-Identifikationsnummer) webservice

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
