# johnshopkins/mailchimp

> 标签: PHP

## 简介

A library to interact with the MailChimp API. Very minimal as it includes only methods JHU needs in its apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
