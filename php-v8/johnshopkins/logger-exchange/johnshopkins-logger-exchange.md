# johnshopkins/logger-exchange

> 标签: PHP

## 简介

A collection of PHP interfaces and adapters to make swapping out logger dependencies quick and easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
