# alies-dev/psalm-plugin-pest

> 标签: dev, pest, psalm, psalm-plugin, static-analysis

## 简介

Psalm plugin for Pest: types $this in test closures as the configured TestCase (with its traits and beforeEach() properties), resolves expectation and higher-order test chains, narrows types after expect() and accepts Pest's public API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
