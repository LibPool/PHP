# wlindabla/user-bundle

> 标签: 2fa, Authentication, doctrine, email-verification, password-reset, postgresql, security, session, sonata-admin, symfony, symfony-bundle, two-factor, user

## 简介

Reusable Symfony 6.4/7.4/8 user bundle (PHP 8.3+) with a ready-made security layer: login, email verification, password reset and temporary passwords, email-code two-factor authentication (2FA), single-session policy, login history, business permissions and double-confirmed email changes. SonataAdmin-friendly, PostgreSQL-first, with overridable repositories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
