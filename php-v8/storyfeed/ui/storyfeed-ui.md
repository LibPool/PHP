# storyfeed/ui

> 标签: activity-feed, inertia, laravel, storyfeed, vue

## 简介

Prefabricated detail forms and a Vue kit for Storyfeed activity feeds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
