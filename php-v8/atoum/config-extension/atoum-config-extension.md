# atoum/config-extension

> 标签: TDD, atoum, atoum-extension, config, test, unit testing

## 简介

atoum extension to use Yaml configuration files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
