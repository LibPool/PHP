# payshen/payshen-php

> 标签: api, payment orchestration, payments, payshen, psp, webhooks

## 简介

PHP client for the Payshen payment orchestration API: payments, captures, voids, refunds, events and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
