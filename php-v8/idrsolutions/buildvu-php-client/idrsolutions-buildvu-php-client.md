# idrsolutions/buildvu-php-client

> 标签: HTML5, Microservice, api, application, buildvu, client, converter, example, idrsolutions, pdf, php, server, web

## 简介

BuildVu PHP Client is the PHP API for IDRsolutions' BuildVu Microservice Example

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
