# tinkeshwar/imager

> 标签: gd, image, image-thumb, laravel, laravel-image

## 简介

This is a laravel package to create thumbs of any desired size on the fly from an existing image.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
