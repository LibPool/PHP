# mishasaz/bybit-php

> 标签: api, bybit, crypto, exchange, rest, trading, v5

## 简介

A clean, dependency-free PHP client for the Bybit v5 REST API (HMAC signing, typed endpoints, pluggable transport).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
