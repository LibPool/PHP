# hassanalisalem/querybuilder

> 标签: hassanalisalem, querybuilder

## 简介

This package is used to build a query from jQuery Query builder plugin rules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
