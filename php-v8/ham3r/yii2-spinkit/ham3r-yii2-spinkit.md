# ham3r/yii2-spinkit

> 标签: animation, asset, loading, spinkit, yii2

## 简介

SpinKit asset for Yii2 framework (https://github.com/tobiasahlin/SpinKit)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
