# phpspec/prophecy

> 标签: Double, Dummy, Mock, dev, fake, mock, spy, stub, 测试

## 简介

Highly opinionated mocking framework for PHP 5.3+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
