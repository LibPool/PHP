# nuclear/users

> 标签: Authentication, Users, authorization, kenarkose, laravel, laravel5, nuclear, nuclearcms, permissions, roles

## 简介

User and permission system scaffolds for the Nuclear CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
