# wazobia/helios-permissions

> 标签: PHP

## 简介

Laravel SDK for the Wazobia Tech platform's cross-service authorization. Cache-first callerHasPermission backed by a shared Redis.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
