# d-wid-codes/multiple_autologon

> 标签: autologon, identity, mail, select identity, switch

## 简介

This plugin allows users to automatically open a Roundcube session and easily switch between another configured sessions from a dropdown menu (optional).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
