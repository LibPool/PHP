# entensy/filament-kurdish-calendar

> 标签: calendar, ckb, filament, filament-plugin, kurdish, laravel

## 简介

Nawroz-based Kurdish calendar for Filament tables, infolists, and date pickers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
