# rekryt/tbank-lib

> 标签: algotrading, amphp, async, invest-api, revolt, t-invest, tbank, tinkoff, trading

## 简介

Асинхронная библиотека для T-Invest API (T-Bank Investments) на AMPHP v3 и Revolt Event Loop

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
