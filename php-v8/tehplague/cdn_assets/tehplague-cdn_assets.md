# tehplague/cdn_assets

> 标签: TYPO3 CMS, cdn, css, javascript, webpack

## 简介

CDN URL postprocessor capable of resolving Webpack asset manifests

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
