# jjalvarezl/pdfjs-viewer-bundle

> 标签: pdf viewer, pdfjs, symfony, symfony3

## 简介

This bundle provides an integration of pdf.js from mozilla with Symfony 3 framework and customizable parameters on server side

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
