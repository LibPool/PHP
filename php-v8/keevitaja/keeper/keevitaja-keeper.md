# keevitaja/keeper

> 标签: Authentication, guard, laravel, permissions, roles

## 简介

Keeper - Laravel authentication driver eloquent extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
