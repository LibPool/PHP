# pushery/matomo-analytics-for-laravel

> 标签: analytics, bot-detection, cookieless, gdpr, laravel, matomo, piwik, privacy, reporting-api, tracking, web-analytics, web-vitals

## 简介

Privacy-first Matomo analytics for Laravel with cookieless tracking, reports, Web Vitals, batching and bot filtering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
