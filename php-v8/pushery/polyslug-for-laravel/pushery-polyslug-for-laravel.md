# pushery/polyslug-for-laravel

> 标签: laravel

## 简介

Polymorphic, multilingual routable identity for Eloquent — leak-safe IDs, per-locale slugs, and hreflang out of the box.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
