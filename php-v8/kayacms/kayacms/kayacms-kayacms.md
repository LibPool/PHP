# kayacms/kayacms

> 标签: cms, codeigniter4, content-management, headless, php

## 简介

KayaCMS — a modular headless CMS built on CodeIgniter 4, with theme engine, RBAC, media queue, REST API and an admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
