# nacosvel/open-http

> 标签: OpenHTTP, client, curl, guzzlehttp, http client, php http client, psr-18, psr-7

## 简介

OpenHTTP is a PHP HTTP Client library based on GuzzleHttp.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
