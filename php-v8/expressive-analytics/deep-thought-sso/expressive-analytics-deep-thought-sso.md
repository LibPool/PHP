# expressive-analytics/deep-thought-sso

> 标签: SSO, deep thought, facebook, google, twitter

## 简介

Primary module for Deep Thought to create social media single sign-on functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
