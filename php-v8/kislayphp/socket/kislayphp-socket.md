# kislayphp/socket

> 标签: cpp-extension, distributed-php, interactive-php, microservices, php, php-extension, php-namespaces, php-realtime, php-rooms, php-socket, php-websocket, real-time, realtime-protocol, socket-transport, websocket

## 简介

High-performance C++ PHP extension providing realtime socket transport for long-running PHP services

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
