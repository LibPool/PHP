# kislayphp/persistence

> 标签: cache, cpp-extension, kislayphp, microservices, pdo, php, php-extension, request-lifecycle, transaction-guard

## 简介

Request-safe persistence runtime for KislayPHP (transaction guard + bounded cache)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
