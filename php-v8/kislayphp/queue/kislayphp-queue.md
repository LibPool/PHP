# kislayphp/queue

> 标签: at-least-once-delivery, cpp-extension, dead-letter-queue, delayed-jobs, distributed-job-queue, microservices, php, php-async-processing, php-background-jobs, php-extension, php-job-queue

## 简介

Native PHP distributed job queue with a standalone queue server, producer client, worker runtime, retries, and DLQ support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
