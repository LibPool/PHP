# kislayphp/metrics

> 标签: cpp-extension, distributed-monitoring, microservices, php, php-echo-system, php-extension, php-influxdb, php-metrics, php-microservices-metrics, php-monitoring, php-observability, php-performance-monitoring, php-prometheus, php-statsd, php-telemetry

## 简介

High-performance C++ PHP extension providing comprehensive metrics collection and monitoring for PHP microservices

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
