# kislayphp/core

> 标签: PHP-API, cpp-extension, distributed-php, high-performance, http-server, https-server, microservices, php, php-container, php-echo-system, php-extension, php-microservices, php-middleware, php-routing, php-ssl, php-tls

## 简介

High-performance C++ PHP extension providing HTTP/HTTPS server with routing and middleware for PHP microservices

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
