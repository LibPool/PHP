# kislayphp/config

> 标签: cpp-extension, distributed-config, dynamic-config, microservices, php, php-config, php-configuration-management, php-consul, php-echo-system, php-environment-config, php-etcd, php-extension, php-hot-reloading, php-microservices-config, php-redis-config

## 简介

High-performance C++ PHP extension providing dynamic configuration management for PHP microservices

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
