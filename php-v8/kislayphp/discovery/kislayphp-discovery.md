# kislayphp/discovery

> 标签: cpp-extension, distributed-services, microservices, php, php-consul, php-echo-system, php-etcd, php-extension, php-health-checks, php-load-balancing, php-microservices-discovery, php-service-discovery, php-service-mesh, php-service-registry, php-zookeeper

## 简介

High-performance C++ PHP extension providing service discovery and registration for PHP microservices

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
