# kislayphp/eventbus

> 标签: cpp-extension, distributed-php, interactive-php, microservices, php, php-broadcasting, php-echo-system, php-eventbus, php-extension, php-messaging, php-microservices-communication, php-namespaces, php-rooms, real-time, realtime-protocol, websocket

## 简介

High-performance C++ PHP extension providing realtime event protocol-compatible realtime communication for PHP microservices

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
