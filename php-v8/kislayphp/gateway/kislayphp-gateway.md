# kislayphp/gateway

> 标签: cpp-extension, microservices, php, php-api-gateway, php-authentication, php-cors, php-echo-system, php-extension, php-load-balancer, php-microservices-gateway, php-middleware, php-rate-limiting, php-reverse-proxy, php-service-discovery, php-traffic-management

## 简介

High-performance C++ PHP extension providing API gateway functionality with load balancing and routing for PHP microservices

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
