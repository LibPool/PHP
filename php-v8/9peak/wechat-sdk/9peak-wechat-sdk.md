# 9peak/wechat-sdk

> 标签: 9peak, sdk, wechat, wechat sdk

## 简介

PHP Wechat SDK, 微信sdk开发包

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
