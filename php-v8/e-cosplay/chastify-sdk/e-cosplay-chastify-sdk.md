# e-cosplay/chastify-sdk

> 标签: PHP

## 简介

PHP client for the Chastify Developer API. Developed free of charge by e-cosplay.fr for Chastify.net.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
