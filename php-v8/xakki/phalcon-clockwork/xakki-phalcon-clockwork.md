# xakki/phalcon-clockwork

> 标签: PHP

## 简介

The clockwork extension for working with the phalcon framework. Fork  by kolesa-team/phalcon-clockwork

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
