# atgp/factur-x

> 标签: ZUGFeRD, factur-x, invoice, pdf, php, xml

## 简介

PHP library to manage your Factur-X / ZUGFeRD 2.0 PDF invoices files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
