# keinos/parsedown-toc

> 标签: extension, markdown, parser

## 简介

Table of Contents Extension for Parsedown, the Parser for Markdown.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
