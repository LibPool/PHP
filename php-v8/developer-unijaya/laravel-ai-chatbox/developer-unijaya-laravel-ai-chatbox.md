## 简介

Drop-in AI chatbox widget for Laravel with RAG, streaming, Vue 3 frontend, and support for Ollama, OpenAI, Groq, and any OpenAI-compatible API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
