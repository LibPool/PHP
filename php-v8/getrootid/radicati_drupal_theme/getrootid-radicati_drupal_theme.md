# getrootid/radicati_drupal_theme

> 标签: PHP

## 简介

Parent theme for Drupal 8+ Websites using the Radicati suite of tools.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
