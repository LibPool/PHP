# savvii/openprovider-rest

> 标签: api, openapi, openapi-generator, openapitools, openprovider, php, rest, sdk

## 简介

PHP client for the Openprovider REST API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
