# botgento/facebook-messenger-chatbot

> 标签: abandoned cart, chatbot, facebook messenger chatbot, magento 2, magento2, product alert, shopping bot

## 简介

A Magento 2 module to integrate a full-featured chatbot for Magento website within 5 minutes. Zero coding skill required

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
