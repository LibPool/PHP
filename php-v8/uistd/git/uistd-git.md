# uistd/git

> 标签: git, ui service, uistd

## 简介

UI Service 简单的PHP Git工具，主要用于代码自动化生成之后，自动将代码push入库

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
