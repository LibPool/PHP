# uistd/tpl

> 标签: tpl, ui service, uistd

## 简介

UI Service 轻量化模板组件，兼容大部分Smarty语法，但不会生成临时文件，生成的代码会缓存在内存中（如果加载了apcu扩展）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
