# uistd/http

> 标签: http, ui service, uis

## 简介

UI Service Http协议接口请求组件，结合DOP代码自动化生成工具可以生成接口模板。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
