# sanixai/php-utils

> 标签: PHP

## 简介

A collection of PHP utility classes for phone number validation and formatting, checksum generation, and SSL certificate generation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
