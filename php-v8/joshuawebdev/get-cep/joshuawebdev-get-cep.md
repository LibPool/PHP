# joshuawebdev/get-cep

> 标签: PHP

## 简介

Biblioteca desenvolvida em PHP para obtenção de informações de um endereço por meio do Código de Enderçamento Posta (CEP) via método get

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
