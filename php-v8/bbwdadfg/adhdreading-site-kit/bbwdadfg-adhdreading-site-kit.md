# bbwdadfg/adhdreading-site-kit

> 标签: adhd, adhdreading, bionic-reading, focus, reading

## 简介

Small URL helpers for ADHD Reading, a Chrome extension for focused reading at https://adhdreading.org.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
