# bbwdadfg/beadpattern-site-kit

> 标签: bead-pattern, bead-pattern-generator, beadpattern, hama, perler

## 简介

Small URL helpers for BeadPattern, the free bead pattern generator at https://beadpattern.net.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
