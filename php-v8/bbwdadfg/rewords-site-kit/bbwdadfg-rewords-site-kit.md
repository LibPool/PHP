# bbwdadfg/rewords-site-kit

> 标签: ai-editor, image-text, photo-editor, rewords, rewordsai

## 简介

Small URL helpers for ReWords AI, an AI image text editor at https://rewordsai.app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
