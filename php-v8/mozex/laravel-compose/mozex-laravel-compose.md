# mozex/laravel-compose

> 标签: compose, containers, deployment, devops, docker, docker-compose, infrastructure, laravel, mozex

## 简介

Run and redeploy Docker Compose stacks owned by your Laravel app

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
