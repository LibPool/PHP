# mozex/commonmark-routes

> 标签: asset, cms, commonmark, content, documentation, extension, images, laravel, league-commonmark, markdown, markdown-pages, php, routes, static-pages, url

## 简介

A CommonMark extension that lets you use Laravel's route(), url(), and asset() helpers in Markdown links and images.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
