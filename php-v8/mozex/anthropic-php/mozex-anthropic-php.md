> 标签: ai, anthropic, api, claude, claude-haiku, claude-opus, claude-sonnet, client, generative-ai, llm, php, sdk, streaming, text-generation, thinking, tool-use

## 简介

PHP client for the Anthropic API: messages, streaming, tool use, thinking, web search, code execution, batches, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
