# mozex/laravel-modules

> 标签: auto-discovery, ddd, domain-driven-design, eloquent, filament, hmvc, laravel, laravel-modules, laravel-package, livewire, modular, modular-architecture, module, modules, mozex, package, package-structure, separation-of-concerns

## 简介

Laravel package that auto-discovers and registers module assets (configs, routes, views, migrations, commands, Livewire, Filament, Nova, and more) from a Modules/ directory at the project root.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
