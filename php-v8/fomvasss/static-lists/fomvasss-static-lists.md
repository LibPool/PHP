# fomvasss/static-lists

> 标签: array, builder, collection, enum, filter, list, php, static lists

## 简介

Deterministic list builder for arrays/iterables (only, except, added, unique, sort).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
