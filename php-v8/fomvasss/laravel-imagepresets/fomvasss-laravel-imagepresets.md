# fomvasss/laravel-imagepresets

> 标签: Webp, fomvasss, glide, image, laravel, preset, resize

## 简介

Image presets (on-the-fly resize/convert) for Laravel via League Glide

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
