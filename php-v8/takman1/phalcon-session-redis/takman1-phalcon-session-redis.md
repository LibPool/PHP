# takman1/phalcon-session-redis

> 标签: phalcon, php, php-redis, redis, session

## 简介

Phalcon sessions on Redis without deprecations. php-redis >= 5, php >= 7, 4 > php-phalcon >= 3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
