# twoir/qrcode

> 标签: laravel, laravel-qrcode, qrcode

## 简介

A lightweight, expressive QR code generator for Laravel. Generate PNG, SVG, or Base64 images with one line of code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
