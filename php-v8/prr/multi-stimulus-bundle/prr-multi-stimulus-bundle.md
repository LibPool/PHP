# prr/multi-stimulus-bundle

> 标签: asset-mapper, stimulus, symfony-ux

## 简介

Work alongside MultiAssetMapperBundle to allow a set of Stimulus controllers per asset collection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
