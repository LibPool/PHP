# gpoehl/phpreport

> 标签: grouping, php, report, reporting, sheets, subtotals, totals

## 简介

PHP library solving almost all common tasks for applications working with data sets. It manages group changes, provides aggregate functions and can even join data from different sources.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
