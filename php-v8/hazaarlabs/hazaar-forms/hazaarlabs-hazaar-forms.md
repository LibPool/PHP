# hazaarlabs/hazaar-forms

> 标签: Forms, framework, hazaar, hmvc, mvc, php

## 简介

Dynamic forms for The MVC framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
