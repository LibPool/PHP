# b4n1/b4n1-web

> 标签: Agent, ai, browser, headless, markdown, scraping

## 简介

Ultra-lightweight agentic browser for AI agents - PHP SDK wrapping the b4n1web binary

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
