# b4n1/boost

> 标签: compression, ffi, gzip, json, laravel, minify, native, performance, zstd

## 简介

High-performance native boost layer for PHP & Laravel: compression, minification and fast JSON validation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
