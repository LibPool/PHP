# lambda-twelve/one-record-laravel

> 标签: JSON-LD, air-cargo, iata, laravel, logistics, one-record

## 简介

Laravel integration for lambda-twelve/one-record: service provider, routes, database stores, authentication wiring and a notification outbox for the IATA ONE Record SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
