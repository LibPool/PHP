# lambda-twelve/one-record-drupal

> 标签: JSON-LD, air-cargo, drupal, iata, logistics, one-record

## 简介

Drupal integration for lambda-twelve/one-record: wires the IATA ONE Record SDK into Drupal's container, configuration, routing, database and queue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
