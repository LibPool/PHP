# lambda-twelve/one-record

> 标签: JSON-LD, air-cargo, iata, logistics, one-record

## 简介

A framework-agnostic PHP server (PSR-15) and client (PSR-18) implementation for the IATA ONE Record API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
