# tommyys/laravel_library

> 标签: PHP

## 简介

Default Laravel library for Axstarzy Dot Com that includes the most used libraries, plugins, helper classes, and migrations

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
