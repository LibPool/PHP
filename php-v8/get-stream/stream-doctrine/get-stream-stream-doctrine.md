# get-stream/stream-doctrine

> 标签: activity, activity feed, aggregated feed, doctrine, feed, feedly, getstream, newsfeed, notification feed, orm, stream, symfony

## 简介

Build newsfeeds and activity feeds with Doctrine using getstream.io

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
