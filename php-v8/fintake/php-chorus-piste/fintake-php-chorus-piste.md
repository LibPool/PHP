# fintake/php-chorus-piste

> 标签: PHP

## 简介

Package PHP pour la connexion et l'envoi de documents sur Chorus PRO par le biais de la plateforme de l'AIFE nommé PISTE

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
