# rginfotech/laravel-safe-schema

> 标签: laravel, linter, migrations, mysql, postgres, rginfotech

## 简介

Catch dangerous Laravel migrations before they take production down.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
