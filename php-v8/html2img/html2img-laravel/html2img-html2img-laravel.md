# html2img/html2img-laravel

> 标签: API-Client, facade, html-to-image, html-to-pdf, html-to-png, html2img, image-generation, laravel, og-image, open-graph, screenshot, screenshot-api, url-to-image

## 简介

Official Laravel integration for the html2img HTML-to-image API: a facade, config and Storage helpers around the html2img PHP SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
