# html2img/craft-og-images

> 标签: Craft, OG Image, craft-plugin, craftcms, html to image, open graph, social share image

## 简介

Automatic Open Graph images for Craft CMS entries, rendered in real Chrome by the HTML to Image API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
