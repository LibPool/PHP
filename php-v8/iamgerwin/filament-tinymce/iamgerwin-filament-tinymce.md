# iamgerwin/filament-tinymce

> 标签: editor, filament, iamgerwin, laravel, rich-text, tinymce, wysiwyg

## 简介

TinyMCE editor field for Filament v4 with full customization support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
