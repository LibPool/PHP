# revealit/laravel-azure-sdk

> 标签: laravel, laravel-azure-sdk, revealit

## 简介

A PHP Laravel wrapper for the Microsoft Azure REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
