# sinakl/laravel-inline-scheduler

> 标签: cpanel, cron, laravel, proc_open, scheduler, shared hosting

## 简介

Run Laravel's task scheduler on hosts where proc_open is disabled (common on shared hosting/cPanel), with zero changes to your existing schedule() definitions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
