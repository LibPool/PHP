# lingoda/ai-sdk

> 标签: ChatGpt, Gemini, ai, anthropic, bedrock, claude, machine-learning, openai

## 简介

Framework-agnostic PHP SDK for AI providers with typed results and platform abstraction

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
