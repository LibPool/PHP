# lingoda/behat-screenshot-image-driver-aws-s3

> 标签: BDD, Behat, TDD, aws, behat-screenshot, s3

## 简介

AWS S3 image driver for bex/behat-screenshot behat extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
