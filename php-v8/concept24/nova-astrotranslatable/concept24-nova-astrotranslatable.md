# concept24/nova-astrotranslatable

> 标签: astrotomic, i18n, laravel, nova, translatable, translate

## 简介

An astrotomic/laravel-translatable extension for Laravel Nova.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
