# potagerphp/grape

> 标签: contracts, potager, sanitizer, schema, type-safe, validation, validator

## 简介

Type-safe schema validation and data sanitization for PHP 8.2+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
