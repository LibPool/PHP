# trackleft/material-symbols-svg-rounded

> 标签: PHP

## 简介

Material Symbols Rounded SVG icon assets for use by PHP / Drupal projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
