# detain/phlix-hub

> 标签: PHP

## 简介

Central cloud directory + reverse-tunnel relay for Phlex media servers. Sign in once, reach any of your servers from anywhere. Self-hostable.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
