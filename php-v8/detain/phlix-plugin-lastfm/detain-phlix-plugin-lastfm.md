# detain/phlix-plugin-lastfm

> 标签: lastfm, music, phlix, phlix-plugin, scrobbler, scrobbling

## 简介

Last.fm scrobbler plugin for Phlix — scrobbles music playback to Last.fm.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
