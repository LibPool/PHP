# financialplugins/omnipay-coinpayments

> 标签: coinpayments, crypto, omnipay, payment gateway

## 简介

Coinpayments driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
