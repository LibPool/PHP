# financialplugins/omnipay-solana

> 标签: Phantom, crypto, omnipay, solana

## 简介

Solana driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
