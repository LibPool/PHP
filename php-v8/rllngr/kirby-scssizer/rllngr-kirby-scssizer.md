# rllngr/kirby-scssizer

> 标签: compiler, css, kirby, kirby-plugin, sass, scss

## 简介

Kirby plugin — SCSS compiler powered by scssphp, no Node.js or Ruby required

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
