# abnermouke/console-builder

> 标签: PHP

## 简介

ConsoleBuilder是一款优秀的管理后台/控制面板构建工具包，一键安装即可搭建一套完整后台模版，内含一套完整表格、表单构建器，开发高效，体验优良！

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
