# abnermouke/payments-builder

> 标签: PHP

## 简介

PaymentsBuilder是一款高效的支付构建工具包，集成Alipay（手机网站、PC、App）、Wechat（微信公众号、小程序、App、H5）等常用支付方式，支付也可以这么丝滑！

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
