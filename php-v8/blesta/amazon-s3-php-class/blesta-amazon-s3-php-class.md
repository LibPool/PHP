# blesta/amazon-s3-php-class

> 标签: PHP

## 简介

A standalone Amazon S3 (REST) client for PHP 7.2.x using CURL that does not require PEAR.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
