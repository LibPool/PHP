# fi1a/tokenizer

> 标签: PHP

## 简介

Лексический анализатор строк (tokenizer). Разбор входной последовательности символов на распознанные группы (лексемы).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
