# fi1a/bitrixd7moduleinstallerdemo

> 标签: PHP

## 简介

Демонстрация возможностей установки и обновления пакетов с типом bitrix-d7-module

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
