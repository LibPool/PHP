# basilicom-pimcore-plugin/hide-status-bar

> 标签: pimcore, plugin, statusbar

## 简介

Hides the Pimcore status bar (version info and warnings) for ordinary users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
