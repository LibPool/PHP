# basilicom-pimcore-plugin/cookie-notice

> 标签: cookie, notice, pimcore, plugin

## 简介

A Pimcore plugin that adds an editable cookie notice to your project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
