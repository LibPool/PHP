# ldv/sluggable-cyrillic

> 标签: cyrillic, elfinder, filesystem, slugable

## 简介

Плагин Sluggable с корректной обработкой кириллицы. Преобразует имена загруженных с помощью файлов yii2-elfinder так, что бы исключить из них некорректные для URI символы

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
