# ianhobbs/song-block

> 标签: audio, block, kirby, kirby-cms, kirby-plugin, music

## 简介

A song block for Kirby CMS: audio player with poster image (beside the text or as background), title, subtitle, description and colours

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
