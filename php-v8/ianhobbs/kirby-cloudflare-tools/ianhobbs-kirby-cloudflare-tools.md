# ianhobbs/kirby-cloudflare-tools

> 标签: cache, cdn, cloudflare, kirby, kirby-cms, kirby-plugin, kirby5, panel, purge

## 简介

Kirby CMS plugin — a Cloudflare control panel in the Panel: cache purge, zone settings, security, SSL/TLS, DNS and traffic analytics on any Cloudflare plan, including Free

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
