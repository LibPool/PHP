# magicoli/kick-inside

> 标签: igd, nat, port-forwarding, port-mapping, ssdp, upnp

## 简介

Pure PHP UPnP IGD port mapping (miniupnpc-like) without CLI dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
