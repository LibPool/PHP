# oblodai/sdk

> 标签: USDT, crypto, cryptocurrency, oblodai, payment-gateway, payments, payout, webhook

## 简介

Official PHP SDK for the Oblodai payment gateway: accepting payments, payouts, static wallets, webhooks. Generated from the gateway's OpenAPI contract.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
