# donmo-roundup/module-donations

> 标签: donate, donations, round up, roundup, ukraine

## 简介

Donmo Roundup Magento Plugin for collecting donations for Ukraine on the payment page

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
