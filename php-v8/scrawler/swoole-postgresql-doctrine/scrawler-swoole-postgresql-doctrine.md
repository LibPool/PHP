# scrawler/swoole-postgresql-doctrine

> 标签: PHP

## 简介

A Doctrine DBAL Driver implementation on top of Swoole Coroutine PostgreSQL extension

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
