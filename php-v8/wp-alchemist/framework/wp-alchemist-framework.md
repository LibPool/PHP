# wp-alchemist/framework

> 标签: framework, plugin, rest, vite, wordpress

## 简介

Runtime helpers for WordPress plugins scaffolded with wp-alchemist: lifecycle, modules, REST routing, Vite assets, migrations, settings and support helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
