# conduction/coding-standard

> 标签: coding-standard, conduction, dev, nextcloud, php-cs-fixer

## 简介

Conduction coding standards for the PHP CS Fixer. Extends nextcloud/coding-standard — adds rules, never overrides them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
