# condoedge/projects

> 标签: PHP

## 简介

Project management module (suggestions, feature requests, tasks, kanban, gantt, GitHub sync) for Kompo/Laravel applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
