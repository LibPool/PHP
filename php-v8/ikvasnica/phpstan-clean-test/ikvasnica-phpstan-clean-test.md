# ikvasnica/phpstan-clean-test

> 标签: PHPStan, phpstan-rules, phpstan-strict-rules, tests

## 简介

PHPStan extension with opinionated strict rules for better code in tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
