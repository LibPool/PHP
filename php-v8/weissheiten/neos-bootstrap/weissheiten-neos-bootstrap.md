# weissheiten/neos-bootstrap

> 标签: Neos, bootstrap

## 简介

Neos CMS Bootstrap Plugin, providing a variety of NodeTypes for out-of-the-box use

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
