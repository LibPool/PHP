# limpalair/stripe

> 标签: laravel, stripe

## 简介

Limpalair Stripe provides a simple and non-intrusive interface to Stripe's payment system in Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
