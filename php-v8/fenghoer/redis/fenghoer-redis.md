# fenghoer/redis

> 标签: framework, mixphp, swoole

## 简介

MixPHP 框架模块 http://www.mixphp.cn,本fork版本修复scan问题

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
