# bhittani/web-driver

> 标签: chrome, driver, phantomjs, php-webdriver, process, testing, web

## 简介

A convenience wrapper around facebook's php-webdriver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
