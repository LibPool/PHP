# wika-group/magento2-azure-ad-b2c-sso

> 标签: Authentication, SSO, magento, magento2, oauth, service provider, single sign on

## 简介

Module to add support for a login via Azure B2C

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
