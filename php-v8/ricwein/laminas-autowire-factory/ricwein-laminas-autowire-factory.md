# ricwein/laminas-autowire-factory

> 标签: BluePsyduck, auto-wire, factory, laminas

## 简介

A Laminas factory implementation allowing for auto-wiring like in Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
