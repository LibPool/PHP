# serafim/tf-idf

> 标签: TF-IDF, TFIDF, document, idf, statistic, text, tf

## 简介

Library to calculate TF-IDF (Term Frequency - Inverse Document Frequency) for generic documents

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
