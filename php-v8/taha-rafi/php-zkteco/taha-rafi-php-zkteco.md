# taha-rafi/php-zkteco

> 标签: Fingerprint, Socket, attendance, biometrics, commkey, php8, tx628, udp, zklibrary, zksoftware, zkteco

## 简介

Modern, pure native PHP 8.x socket communication library for ZKTeco Biometric Time & Attendance devices with native Comm Key authentication support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
