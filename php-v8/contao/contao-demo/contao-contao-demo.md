# contao/contao-demo

> 标签: PHP

## 简介

This is an example website for Contao, a powerful open source CMS that allows you to create professional websites and scalable web applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
