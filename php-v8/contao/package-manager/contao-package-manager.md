# contao/package-manager

> 标签: cms, contao, installer, manager, php, symfony, symfony-application, vuejs

## 简介

Contao Manager is the management tool for Contao 4 Open Source CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
