# jc5/google2fa-laravel

> 标签: Authentication, Two Factor Authentication, google2fa, laravel

## 简介

A One Time Password Authentication package, compatible with Google Authenticator.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
