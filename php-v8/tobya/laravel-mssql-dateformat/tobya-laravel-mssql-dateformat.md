# tobya/laravel-mssql-dateformat

> 标签: PHP

## 简介

Check and set MSSQL universal date format used by Laravel to 'Ymd' to ensure universal compatibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
