# chrisnoden/talkback

> 标签: growl, logging, prowl, psr-3

## 简介

Logging and messaging library that builds upon Psr-3 with Growl, Prowl, Html and other modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
