# refatrar/dynamic-dashboard-design

> 标签: charts, dashboard, inertia, laravel, vue

## 简介

Reusable dynamic dashboard design package for Laravel with Inertia and Vue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
