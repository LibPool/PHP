# babelhub/cli

> 标签: babelhub, ci, cli, i18n, localization, translation

## 简介

BabelHub CLI — send the keys your code uses, pull approved catalogs back, and gate a pull request in CI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
