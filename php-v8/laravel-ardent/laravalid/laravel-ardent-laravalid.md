> 标签: ardent, client side, client-side, jquery validation, laravel, laravel validation, laravel validation converter, laravel validation for client-side, laravel5, validation

## 简介

Integrates Ardent models validation rules into Laravel forms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
