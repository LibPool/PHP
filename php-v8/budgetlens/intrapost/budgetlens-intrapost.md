# budgetlens/intrapost

> 标签: dhl, gls, intrapost, laravel, parcels, postnl, shipping, track-trace

## 简介

Fluent PHP client for the Intrapost API (mail, parcels, track & trace)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
