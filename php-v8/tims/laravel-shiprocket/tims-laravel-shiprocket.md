# tims/laravel-shiprocket

> 标签: ecommerce, laravel, logistics, sdk, shipping, shiprocket

## 简介

Laravel integration for the Shiprocket PHP SDK (tims/shiprocket-php-sdk)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
