# tims/laravel-paapi

> 标签: affiliate, amazon, associates, creators-api, creatorsapi, laravel, paapi

## 简介

Laravel package for Amazon Creators API, built on tims/amazon-creatorsapi-php-sdk

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
