# uwdoem/admissions-crm-document

> 标签: PHP

## 简介

Helper library for attaching documents to the UW Admissions Microsoft Dynamics CRM instance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
