# 1manfactory/ai-costs

> 标签: Gemini, ai, anthropic, billing, claude, costs, llm, openai, tokens, usage

## 简介

Unofficial PHP library for calculating LLM API costs from usage payloads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
