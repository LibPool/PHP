# carljanzell/filament-insights

> 标签: analytics, charts, dashboard, filament, filament-plugin, laravel

## 简介

Admin-built stats and chart dashboards on any Filament resource, scoped exactly like the resource's own table.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
