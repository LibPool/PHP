# carljanzell/filament-page-builder

> 标签: drag-and-drop, filament, filament-plugin, laravel, livewire, page-builder

## 简介

A drag-and-drop visual page builder for Filament, storing content as ordered typed blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
