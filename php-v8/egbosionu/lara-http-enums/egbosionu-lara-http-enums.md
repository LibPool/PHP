# egbosionu/lara-http-enums

> 标签: enums, http, http-methods, laravel, status-codes

## 简介

A Laravel package for managing HTTP status codes, methods, and other related HTTP enums.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
