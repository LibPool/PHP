# plusinfolab/search

> 标签: laravel, plusinfolab, search

## 简介

Advanced search package for Laravel with multiple algorithms, Eloquent integration, and SQLite FTS support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
