# chinpei215/cakephp-stackable-finder

> 标签: cakephp, custom, finders, stack

## 简介

CakePHP 2.x plugin to make it possible to stack custom finders

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
