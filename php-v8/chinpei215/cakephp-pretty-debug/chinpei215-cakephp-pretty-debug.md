# chinpei215/cakephp-pretty-debug

> 标签: cakephp, debug

## 简介

CakePHP 2.x plugin to make debug toolbar pretty

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
