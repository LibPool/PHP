# rmunate/sql-server-lite

> 标签: altum, laravel, rmunate, sql, sqlserver

## 简介

Conexión PDO a SQLServer desde PHP estructurado o Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
