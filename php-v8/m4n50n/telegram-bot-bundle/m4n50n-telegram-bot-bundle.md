# m4n50n/telegram-bot-bundle

> 标签: api, bot, bundle, telegram, wrapper

## 简介

This bundle provides a wrapper for using longman/telegram-bot inside Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
