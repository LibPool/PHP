# m4n50n/oauth2-azure-bundle

> 标签: api, azure, bundle, login, microsoft, oauth2, wrapper

## 简介

This bundle provides a tiny wrapper for using thenetworg/oauth2-azure inside Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
