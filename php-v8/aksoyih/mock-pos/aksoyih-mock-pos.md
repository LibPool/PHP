# aksoyih/mock-pos

> 标签: laravel, mock, payments, pos, testing

## 简介

Laravel-local payment gateway mock for PayTR, iyzico, Lidio, and Garanti BBVA.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
