# zemit-cms/core

> 标签: acl, api, database, eager-loading, framework, jwt, orm, phalcon, phalcon-kit, phalcon-kit-core, phalcon-php, phalcon-toolkit, php, php-framework, rbac, rest, rest-api, scaffolding, websocket

## 简介

Build Phalcon REST APIs faster with database-first scaffolding, model relationships, eager loading, identity, permissions, CLI, and WebSocket support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
