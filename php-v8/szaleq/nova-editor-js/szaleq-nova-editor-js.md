# szaleq/nova-editor-js

> 标签: editor, editorjs, laravel, nova, wysiwyg

## 简介

A Laravel Nova field bringing EditorJs magic to Nova.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
