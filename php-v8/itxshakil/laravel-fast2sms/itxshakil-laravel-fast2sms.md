# itxshakil/laravel-fast2sms

> 标签: dlt, fast2sms, india, laravel, laravel-notifications, laravel-package, notifications, otp, php, sms, sms-gateway, webhooks, whatsapp, whatsapp-business-api

## 简介

A Laravel package for sending SMS and WhatsApp messages via the Fast2SMS API with a fluent interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
