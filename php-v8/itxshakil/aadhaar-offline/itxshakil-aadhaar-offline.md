# itxshakil/aadhaar-offline

> 标签: aadhaar, aadhaar-offline, aadhaar-qr, ekyc, fintech, india, kyc, offline-ekyc, paperless-kyc, php, secure-qr, uidai, verhoeff, xml-signature

## 简介

Read and verify Aadhaar Offline e-KYC (share-code ZIP / signed XML) and Secure QR codes in any PHP app: UIDAI signature checks against pinned certificates, mobile/email hash matching, freshness rules and privacy-safe defaults. No framework required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
