# itxshakil/cpanel-whm

> 标签: UAPI, cpanel, cpanel-api, hosting-automation, laravel, laravel-package, provisioning, reseller, web-hosting, whm, whm-api

## 简介

A typed, token-only, fakeable cPanel WHM API 1 client for Laravel, with UAPI through WHM, a whm:doctor connection check and Artisan commands for everyday account work.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
