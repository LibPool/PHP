# jessegall/concurrent

> 标签: cache, concurrent, laravel, locking, thread-safe

## 简介

A thread-safe wrapper for cached values with locking, validation, and read-only method support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
