# jessegall/code-commandments

> 标签: architecture, code-quality, commandments, laravel, static-analysis

## 简介

An architecture compiler — judges a PHP, Vue, TypeScript, Python and C# codebase against architectural disciplines and points every violation at the skill that fixes it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
