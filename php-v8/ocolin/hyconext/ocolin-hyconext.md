# ocolin/hyconext

> 标签: hyconext, mac-table, network, network-monitoring, php, poe, snmp, ssh, switch

## 简介

SNMP and SSH client for Hyconext switches

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
