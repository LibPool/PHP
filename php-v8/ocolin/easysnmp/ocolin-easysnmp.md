# ocolin/easysnmp

> 标签: arp, interfaces, mib, monitoring, network, php, snmp

## 简介

PHP SNMP client providing formatted, DTO-backed access to standard MIB-II data without requiring SNMP knowledge

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
