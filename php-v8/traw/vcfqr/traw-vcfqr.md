# traw/vcfqr

> 标签: TYPO3 12, TYPO3 13, TYPO3 CMS, qr-code, vcf

## 简介

Create vcf card with QR Code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
