# pallapay/pallapay-php-sdk

> 标签: bitcoin, crypto, gateway, pallapay, payment

## 简介

Pallapay PHP SDK to accept crypto currency payments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
