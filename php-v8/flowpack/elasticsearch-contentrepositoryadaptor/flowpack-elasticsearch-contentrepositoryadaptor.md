# flowpack/elasticsearch-contentrepositoryadaptor

> 标签: PHP

## 简介

This package provides functionality for using Elasticsearch on top of Neos.ContentRepository.Search

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
