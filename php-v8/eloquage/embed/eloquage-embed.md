# eloquage/embed

> 标签: Eloquage, embed

## 简介

Embedding helpers for PHP apps: normalize, chunk metadata, cache keys, and provider-agnostic embedding DTOs for RAG pipelines.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
