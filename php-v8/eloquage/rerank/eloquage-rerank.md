# eloquage/rerank

> 标签: Eloquage, rerank

## 简介

Cross-encoder and feature-based reranking helpers for PHP search pipelines (lexical + vector candidate sets).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
