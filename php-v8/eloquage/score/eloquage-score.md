# eloquage/score

> 标签: Eloquage, score

## 简介

In-request ML scoring for PHP: load exported linear/tree models and run fast predictions for ranking, fraud, and pricing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
