# eloquage/lex

> 标签: Eloquage, lex

## 简介

Lexical search toolkit for PHP: tokenization, n-grams, BM25 scoring, and inverted-index helpers for hybrid RAG.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
