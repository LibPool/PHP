# eloquage/chunk

> 标签: Eloquage, chunk

## 简介

Document chunking for RAG: overlapping windows, markdown/code-aware splits, and token-budget packing for embedding pipelines.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
