# eloquage/tokens

> 标签: Eloquage, tokens

## 简介

Fast tokenizers for PHP: BPE/WordPiece-style encode/decode, vocab loading, and batch tokenization for LLM and search pipelines.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
