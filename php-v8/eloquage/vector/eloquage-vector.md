# eloquage/vector

> 标签: Eloquage, vector

## 简介

In-process vector math for PHP: cosine, dot, L2, top-k, and batch similarity with a pure-PHP API and optional native acceleration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
