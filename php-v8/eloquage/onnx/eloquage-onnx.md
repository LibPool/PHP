# eloquage/onnx

> 标签: Eloquage, onnx

## 简介

Thin ONNX Runtime bindings/helpers for PHP inference—run portable models without standing up a Python sidecar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
