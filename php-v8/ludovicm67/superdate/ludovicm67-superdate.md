# ludovicm67/superdate

> 标签: PHP

## 简介

Nice methods to know if the specified date is on a weekend/weekday or holiday (for Alsace, France), and some other cool stuff

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
