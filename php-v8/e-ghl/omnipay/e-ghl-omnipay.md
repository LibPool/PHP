# e-ghl/omnipay

> 标签: eghl, gateway, merchant, omnipay, payment

## 简介

Omnipay payment processing library for eGHL payment Gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
