# neverbland/njax-bundle

> 标签: ajax, navigation, pjax, symfony

## 简介

NJAX - Navigation in AJAX. Integration with Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
