# sendclipper/sendclipper-php

> 标签: email, sdk, sendclipper, smtp, transactional-email, webhooks

## 简介

Official PHP SDK for the SendClipper email API: send mail, manage domains, templates, sandboxes, webhooks, contacts and suppressions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
