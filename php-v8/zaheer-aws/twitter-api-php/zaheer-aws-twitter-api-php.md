# zaheer-aws/twitter-api-php

> 标签: api, php, twitter

## 简介

Simple PHP Wrapper for Twitter API v1.1 calls

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
