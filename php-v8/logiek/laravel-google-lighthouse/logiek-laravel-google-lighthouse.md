# logiek/laravel-google-lighthouse

> 标签: google, laravel, lighthouse

## 简介

This package provides a wrapper for Google Lighthouse to audit the quality of web pages with Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
