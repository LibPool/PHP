# bitmatrix/craft-omnisearch

> 标签: CP, Craft, cms, craft-plugin, craftcms, omnisearch, query, search

## 简介

Powerful search filters for the control panel with full Matrix support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
