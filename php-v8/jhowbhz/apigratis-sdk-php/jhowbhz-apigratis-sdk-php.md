## 简介

SDK oficial PHP da plataforma APIBrasil - WhatsApp, SMS, consultas CPF/CNPJ, veiculos, CEP, correios, pagamentos e mais

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
