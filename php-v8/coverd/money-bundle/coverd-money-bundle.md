# coverd/money-bundle

> 标签: conversion, currency, fowler, money

## 简介

This is a Symfony bundle that integrates moneyphp/money library (Fowler pattern): https://github.com/moneyphp/money.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
