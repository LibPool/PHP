# terhuerne/contao-kraken.io

> 标签: compression, contao, image, kraken.io

## 简介

With this extension, you can use the advanced image compression technologies of kraken.io at your Contao based Homepage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
