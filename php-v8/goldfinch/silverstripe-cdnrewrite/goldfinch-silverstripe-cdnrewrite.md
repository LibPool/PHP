# goldfinch/silverstripe-cdnrewrite

> 标签: cdn, silverstripe

## 简介

Automatically rewrites the URLs of media and assets to use a CDN

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
