# goldfinch/taz

> 标签: command-line-interface, silverstripe, silverstripe-cli, silverstripe-taz

## 简介

Command Line Interface (CLI) for Silverstripe, to help and speed up development process

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
