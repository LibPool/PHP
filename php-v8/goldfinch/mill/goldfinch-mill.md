# goldfinch/mill

> 标签: fake-data, faker, faker-silverstripe, generate-fake-data, mill, silverstripe

## 简介

Mill is a factory component that helps you to generate fake records for Silverstripe

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
