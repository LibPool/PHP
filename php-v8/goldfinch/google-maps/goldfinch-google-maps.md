# goldfinch/google-maps

> 标签: advancedmarkerelement-events, google-maps, info-window-events, map-events, marker-events, silverstripe, silverstripe-google-maps

## 简介

The module helps to create and manage Google Maps in your Silverstripe project

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
