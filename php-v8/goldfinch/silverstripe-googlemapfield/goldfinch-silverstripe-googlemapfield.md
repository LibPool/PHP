# goldfinch/silverstripe-googlemapfield

> 标签: geolocation, google, googlemapfield, map, maps, silverstripe

## 简介

Save locations using latitude/longitude DataObject fields.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
