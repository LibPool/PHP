# errly/laravel-errly

> 标签: Queue-Monitoring, bugsnag-alternative, cron-monitoring, errly, error-monitoring, error-reporting, exception-handler, free-alternative, healthchecks, heartbeat, laravel, laravel-12, laravel-13, logging, notifications, slack

## 简介

Error monitoring with beautiful Slack notifications, plus scheduler and queue heartbeats, for Laravel applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
