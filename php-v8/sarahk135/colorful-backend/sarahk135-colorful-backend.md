# sarahk135/colorful-backend

> 标签: backend, color, colorful, icons, modulemenu, theme, typo3

## 简介

Adds back color to the Modulemenu Icons. Can be activated in user settings. Works with dark/light mode and all standard backend themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
