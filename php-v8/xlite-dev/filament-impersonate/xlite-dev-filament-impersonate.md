# xlite-dev/filament-impersonate

> 标签: developer-login, filament, filament-account-switcher, filament-impersonate, filament-plugin, filament-v5, impersonate, impersonation, laravel, linked-accounts, packstub, sub-accounts

## 简介

Switch between accounts in Filament: impersonate users, linked sub-accounts with password-confirmed escalation, and one-click developer logins.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
