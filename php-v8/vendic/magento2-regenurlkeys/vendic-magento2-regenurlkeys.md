# vendic/magento2-regenurlkeys

> 标签: PHP

## 简介

This Magento 2 module wil find all the products without an url key and regenerates them using the product name as a basis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
