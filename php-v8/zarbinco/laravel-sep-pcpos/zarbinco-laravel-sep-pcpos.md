# zarbinco/laravel-sep-pcpos

> 标签: fintech, iran, laravel, payment, pcpos, pos, saman-kish, sdk, sep

## 简介

An unofficial Laravel SDK for integrating with SEP Central PC-POS services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
