# wowoengine/sawitdb-php

> 标签: database, embedded, flatfile, nosql, php, sawitdb, wowoengine

## 简介

PHP Port of SawitDB Node.JS Version - A single-file NoSQL database for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
