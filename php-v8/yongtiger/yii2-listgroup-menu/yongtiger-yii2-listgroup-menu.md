# yongtiger/yii2-listgroup-menu

> 标签: extension, listgroup, menu, yii2

## 简介

Yii2 doc multi-level list group menu.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
