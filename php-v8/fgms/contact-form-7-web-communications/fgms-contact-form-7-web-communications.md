# fgms/contact-form-7-web-communications

> 标签: Contact 7 Forms, FGMS, plugin, wordpress

## 简介

Wordpress plugin to add communications to Contact 7 Forms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
