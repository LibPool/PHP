# gnugat/wizard-bundle

> 标签: bundle, command, install, remove, symfony, wizard

## 简介

Easing Symfony2 bundle installation to one single command

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
