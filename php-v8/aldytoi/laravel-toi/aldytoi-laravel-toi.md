# aldytoi/laravel-toi

> 标签: auth, boilerplate, laravel, lucide, starter-kit, tailwind

## 简介

Laravel 12 starter kit with authentication, admin dashboard, Tailwind CSS, and Lucide Icons.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
