# smile/hipay-sylius-plugin

> 标签: hipay, plugin, smile, sylius, symfony

## 简介

A Symfony plugin for Sylius to add payment method Hipay.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
