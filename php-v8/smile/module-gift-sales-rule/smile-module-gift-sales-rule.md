# smile/module-gift-sales-rule

> 标签: cart, free, gift, magento2, salesrule

## 简介

Extension of Magento2 Sales Rule to provide gifted (free) products.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
