# mohatt/package-skeleton-php

> 标签: Skeleton, boilerplate, starter, template

## 简介

A skeleton repository for PHP packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/mohatt/package-skeleton-php
- 源码仓库：https://github.com/mohatt/package-skeleton-php.git
- Packagist 页面：https://packagist.org/packages/mohatt%2Fpackage-skeleton-php

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require mohatt/package-skeleton-php`
- Packagist 仓库：https://repo.packagist.org/p2/mohatt/package-skeleton-php.json
- 许可证：MIT
- PHP 要求：^8.0
