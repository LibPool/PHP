# safesurf/safesurf

> 标签: phishing, phishing-detection, phishing-url-detector, url-analysis, url-scanner

## 简介

A PHP library for checking if a URL is safe to surf.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
