# shaferllc/fleet-idp-client

> 标签: PHP

## 简介

Laravel client for Fleet central auth: Passport OAuth, optional password grant, Eloquent user sync, fleet:idp:configure CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
