# mrkindy/multi-tenant-wordpress

> 标签: database, multi-tenant, saas, woocommerce, wordpress

## 简介

Database-per-tenant bootstrap for WordPress and WooCommerce SaaS platforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
