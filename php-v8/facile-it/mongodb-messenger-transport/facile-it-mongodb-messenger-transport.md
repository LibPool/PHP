# facile-it/mongodb-messenger-transport

> 标签: Messenger, database, mongodb, symfony, transport

## 简介

A Symfony Messenger transport on MongoDB, on top of facile-it/mongodb-bundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
