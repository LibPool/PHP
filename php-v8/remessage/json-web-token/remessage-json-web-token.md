# remessage/json-web-token

> 标签: JSON Web Encryption, JSON Web Signature, JSON Web Token, JWE, JWS, jwt

## 简介

A JSON Web Token (RFC 7519) implementation library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
