# freecart/freecart-core

> 标签: cart, facile, freecart, opensource, shopping cart

## 简介

Core Dependencies for FreeCart opensource Shopping CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
