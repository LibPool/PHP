# zoujingli/type-orm-sqlite

> 标签: PHP

## 简介

TypeApp ORM 的 SQLite PDO 驱动，支持文件数据库、内存数据库与迁移。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
