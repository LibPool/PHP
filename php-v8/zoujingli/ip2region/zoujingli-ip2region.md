# zoujingli/ip2region

> 标签: IP, Ip2Region, composer, geolocation, ipv4, ipv6, location, php, 企业级, 智能加载, 缓存策略, 零依赖, 高性能

## 简介

ip2region v3.0 for PHP - 企业级 IP 地理位置查询库，支持 IPv4 和 IPv6，多种缓存策略，零依赖，开箱即用

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
