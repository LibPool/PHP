# zoujingli/type-mqtt

> 标签: PHP

## 简介

TypeApp MQTT 3.1.1/5.0 客户端与服务端组件，提供连接、会话和消息路由能力。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
