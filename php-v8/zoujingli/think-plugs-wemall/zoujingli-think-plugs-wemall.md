# zoujingli/think-plugs-wemall

> 标签: PHP

## 简介

Distribution mall plugin with goods, orders, members, coupons and rebates for ThinkAdmin

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
