# zoujingli/type-project

> 标签: PHP

## 简介

TypeApp 独立应用模板：按需组合 Plugins，提供开发入口、数据库驱动选择与 TypePHP 构建配置。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
