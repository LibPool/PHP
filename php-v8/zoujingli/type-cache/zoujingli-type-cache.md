# zoujingli/type-cache

> 标签: PHP

## 简介

TypeApp Redis 缓存组件：显式类型编解码、TTL、命名空间隔离及 PSR 缓存接口。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
