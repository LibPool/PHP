# zoujingli/type-orm-pgsql

> 标签: PHP

## 简介

TypeApp ORM 的 PostgreSQL PDO 驱动，提供连接配置、查询方言与迁移支持。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
