# rotexsoft/slim-skeleton-mvc-tools

> 标签: framework, mvc, tools, utils

## 简介

A support package for the SlimPHP Skeleton MVC App ( https://github.com/rotexsoft/slim-skeleton-mvc-app ).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
