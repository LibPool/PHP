# rotexsoft/versatile-acl

> 标签: Lists, access, access-control, access-control-list, access-control-lists, acl, authorization, authorize, control, list, permissions, rbac, role, role-based, role-based-access-control, roles

## 简介

A simple light-weight and highly customizable package that can be used for implementing access control in any php application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
