# hlkaiyan/min-s3

> 标签: aws, ceph, minio, object-storage, s3, s3-client

## 简介

轻量 S3 客户端，面向自建 S3 服务器（MinIO / Ceph / 其他 S3 兼容存储），零第三方依赖

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
