# bookfrank/viaduct

> 标签: PHP

## 简介

Viaduct is a very simple php router, hope to be able to help the php-framework beginners to understand the principle of router better

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
