# yepsql/yepsql

> 标签: mysql, pdo, postgresql, sql, sqlite, yesql

## 简介

SQL templating helper for PHP inspired by yesql.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
