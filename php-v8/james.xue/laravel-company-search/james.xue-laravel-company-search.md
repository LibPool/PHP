# james.xue/laravel-company-search

> 标签: PHP

## 简介

Laravel Company Search API（根据企业全名、工商注册号、组织机构代码、统一信用代码查询企业各维度数据，包含工商基本信息（含40多个项目）、股东高管、投资公司、分支机构、变更、诉讼、商标、经营异常、年报等。）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
