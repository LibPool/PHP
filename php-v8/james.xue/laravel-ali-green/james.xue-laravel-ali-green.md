# james.xue/laravel-ali-green

> 标签: ali-green, green, laravel, yellow

## 简介

laravel 阿里鉴黄包括文本、图片、视频，关键词文本检测以及对图片涉黄、暴恐、敏感检测、广告、二维码视频色情、暴恐涉政视频等

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
