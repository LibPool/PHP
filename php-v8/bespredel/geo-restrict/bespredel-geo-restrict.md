# bespredel/geo-restrict

> 标签: IP, access, geo, geoip, laravel, location, middleware, restriction

## 简介

Middleware to restrict access to Laravel applications based on IP geolocation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
