# previewict/openerp-php-connector

> 标签: ERP, OpenERP, php, xmlrpc

## 简介

Connect your PHP driven web application with Open ERP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
