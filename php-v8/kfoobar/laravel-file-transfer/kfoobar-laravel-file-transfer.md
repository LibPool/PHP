# kfoobar/laravel-file-transfer

> 标签: file-transfer, ftp, laravel, phpseclib, sftp

## 简介

FTP and SFTP file transfer classes for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
