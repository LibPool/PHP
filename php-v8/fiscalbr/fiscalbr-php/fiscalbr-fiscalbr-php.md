# fiscalbr/fiscalbr-php

> 标签: brasil, core, efd, fiscalbr, sped

## 简介

Biblioteca comum com classes utilitárias e componentes compartilhados entre os módulos FiscalBr.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
