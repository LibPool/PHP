# cloudbear/api-argocd

> 标签: ArgoCD, api, argo-cd, client, gitops, kubernetes, sdk

## 简介

A typed PHP client for the Argo CD API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
