# nsrosenqvist/carte

> 标签: http, json, manifest, middleware, psr-15, psr-17, psr-7, router, yaml

## 简介

A declarative PSR-15 router based on the PSR-7 and PSR-17 standards

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
