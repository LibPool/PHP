# nsrosenqvist/phpdoc-validator

> 标签: PHPStan, documentation, phpdoc, psalm, static-analysis, validator

## 简介

Validates PHPDoc @param and @return tags against method signatures

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
