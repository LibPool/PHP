# dereuromark/cakephp-meta

> 标签: cakephp, canonical, meta, opengraph, plugin, seo, twitter-cards, view

## 简介

A CakePHP plugin for SEO meta tags, OpenGraph and Twitter Cards

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
