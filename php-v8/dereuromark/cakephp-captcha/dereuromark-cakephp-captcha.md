# dereuromark/cakephp-captcha

> 标签: admin-panel, cakephp, captchas, form, plugin, recaptcha, security, spam-prevention, standalone-ui

## 简介

A CakePHP plugin to integrate captchas.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
