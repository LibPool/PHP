# dereuromark/cakephp-tools

> 标签: behaviors, cakephp, components, datasources, helpers, plugin, tools, utils

## 简介

A CakePHP plugin containing lots of useful and reusable tools

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
