# dereuromark/cakephp-feed

> 标签: atom, cakephp, feed, plugin, rss, view

## 简介

A CakePHP plugin containing RssView and AtomView classes for generating RSS 2.0 and Atom 1.0 feeds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
