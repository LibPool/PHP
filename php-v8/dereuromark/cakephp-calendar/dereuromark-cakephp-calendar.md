# dereuromark/cakephp-calendar

> 标签: cakephp, calendar, dates, events, helper, plugin, scheduling

## 简介

A CakePHP plugin to easily create calendars.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
