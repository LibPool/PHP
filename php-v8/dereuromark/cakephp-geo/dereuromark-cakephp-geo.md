# dereuromark/cakephp-geo

> 标签: admin-panel, cakephp, coordinates, geocoding, google-maps, helpers, location, maps, plugin

## 简介

A CakePHP plugin around geocoding tools and helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
