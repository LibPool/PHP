# dereuromark/cakephp-i18n-lint

> 标签: cakephp, ci, gettext, i18n, lint, po, pot, translations

## 简介

Keeps CakePHP translation catalogs honest: POT drift check, PO sync and PO linting for plugins and apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
