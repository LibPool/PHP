# dereuromark/cakephp-markup

> 标签: bbcode, cakephp, highlighting, markdown, markup, parsing, plugin, syntax

## 简介

CakePHP plugin for markup (parsing and displaying)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
