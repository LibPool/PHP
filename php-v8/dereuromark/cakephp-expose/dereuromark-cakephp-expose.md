# dereuromark/cakephp-expose

> 标签: cakephp, expose, hashids, obfuscate, security, uuid

## 简介

CakePHP Expose Plugin to expose entities through UUIDs instead of AIIDs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
