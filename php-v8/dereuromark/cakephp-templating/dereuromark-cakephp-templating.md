# dereuromark/cakephp-templating

> 标签: FontAwesome, bootstrap, cakephp, helper, icons, plugin, templating

## 简介

CakePHP plugin around templating and (font) icons

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
