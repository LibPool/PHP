# dereuromark/cakephp-favorites

> 标签: Favorites, bookmarks, cakephp, plugin, stars, wishlist

## 简介

A CakePHP plugin for managing user favorites, bookmarks and wishlists

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
