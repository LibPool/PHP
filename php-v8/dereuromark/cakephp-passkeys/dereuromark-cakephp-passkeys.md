# dereuromark/cakephp-passkeys

> 标签: Authentication, FIDO2, cakephp, passkey, webauthn

## 简介

Public-quality passkey / WebAuthn authentication plugin for CakePHP 5

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
