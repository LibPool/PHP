# dereuromark/cakephp-qrcode

> 标签: admin-panel, barcode, cakephp, generator, image, plugin, qr code

## 简介

A CakePHP plugin for generating QR codes with helper and admin backend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
