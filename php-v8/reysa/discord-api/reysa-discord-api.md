# reysa/discord-api

> 标签: API-Client, discord, discord-api, discord-bot, laravel

## 简介

Full-coverage Discord HTTP API client for Laravel -- call Discord's REST API through simple static PHP methods instead of raw HTTP calls.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
