# tarunmangukiya/laravel-image-resizer

> 标签: PHP

## 简介

Laravel 5 Package for Image uploading, auto-resizing and retriving library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
