# notifius/php-wctp

> 标签: php, wctp, xml

## 简介

A PHP library for creating and handling XML request/response objects for the WCTP v1.3r1 specification.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
