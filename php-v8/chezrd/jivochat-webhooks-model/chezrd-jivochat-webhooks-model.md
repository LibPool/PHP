# chezrd/jivochat-webhooks-model

> 标签: Jivochat, Webhooks API, jivosite

## 简介

Library for parsing Jivochat (Jivosite) Webhooks API Requests into structured Model.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
