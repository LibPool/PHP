# bahricanli/message-manager-client

> 标签: PHP

## 简介

Laravel client + notification channel for sending WhatsApp template messages through Message Manager (message-manager.tr)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
