# jaydeep/laravel-preflight

> 标签: artisan, breaking-changes, compatibility, laravel, laravel-migration, laravel-preflight, laravel-upgrade, laravel-upgrade-tool, php-upgrade, preflight, static-analysis, upgrade, upgrade-assistant, upgrade-checker, version-upgrade

## 简介

Artisan command that scans your Laravel codebase for breaking changes and compatibility issues before you upgrade to Laravel 9, 10, 11, 12, or 13.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
