# pamellayamada/otphp

> 标签: 2fa, Authentication, google-authenticator, hotp, i18n, otphp, php, qrcode, security, steam-guard, svg, totp, two-factor

## 简介

Native, ultra-fast, hardened security and strictly typed engine for 2FA Tokens (TOTP/HOTP) with 27 i18n languages in PHP 8.3+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
