# ankitkaran99/ai-query

> 标签: PHP

## 简介

A small, safe, natural-language query layer for Laravel — powered by Prism. Returns structured query specs, never executes generated code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
