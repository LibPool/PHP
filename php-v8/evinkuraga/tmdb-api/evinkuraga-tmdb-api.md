# evinkuraga/tmdb-api

> 标签: api, movie, php, tmdb, tv, tv show, tvdb, wrapper

## 简介

This is a fork of the package php-tmdb/api. Instead of waiting for the maintainer to update the php-tmdb/api package to reflect the latest changes from the API, I've decided to fix these. These packages are actively used for http://flixi.com, which means I will most likely maintain these packages with the latest changes that TMDB implements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
