# belysh/laravel-socket-bridge

> 标签: Broadcasting, Socket.io, laravel, nestjs, redis, websocket

## 简介

Native Laravel broadcasting through a project-local NestJS Socket.IO gateway and Redis Streams.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
