# codedive-io/laravel-ncloud-mail-driver

> 标签: PHP

## 简介

네이버 Ncloud 의 Cloud Outbound Mailer 를 사용하는 Laravel mail driver

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
