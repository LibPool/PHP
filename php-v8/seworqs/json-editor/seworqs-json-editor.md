# seworqs/json-editor

> 标签: JSON Writer, array handling, dot notation, editor, immutable, json, json file, json manipulation, php, seworqs

## 简介

A dot-notated, chainable JSON editor for PHP with built-in file support and robust array handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
