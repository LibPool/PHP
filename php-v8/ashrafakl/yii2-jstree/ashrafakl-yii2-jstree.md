# ashrafakl/yii2-jstree

> 标签: extension, jstree, widget, yii2

## 简介

The yii2-jstree extension is a Yii2 wrapper widget for the jstree plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
