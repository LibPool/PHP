# rdhafiz/laravel-vue-spa

> 标签: PHP

## 简介

Laravel Vue SPA  - A php library to setup a Laravel Vue SPA project environment by couple of small commands

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
