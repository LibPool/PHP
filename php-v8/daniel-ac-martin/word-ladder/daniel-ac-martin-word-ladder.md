# daniel-ac-martin/word-ladder

> 标签: ladder, solver, word, word ladder, word ladder solver

## 简介

A command-line program and library for solving word ladder puzzles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
