# warriorxk/phpwebsockets

> 标签: Socket, client, ipc, php, phpwebsockets, server, websocket

## 简介

A websocket library with support for IPC using socket pairs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
