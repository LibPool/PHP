# silbinarywolf/multirecordfield

> 标签: frontend, gridfield, record editing, silverstripe

## 简介

A module for editing multiple records on a backend or frontend form.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
