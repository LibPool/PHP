# weggla/sulu-dynamic-form-ajax-validation-bundle

> 标签: Forms, sulu

## 简介

A small bundle for Sulu projects to validate dynamic forms via ajax request

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
