# testingbot/testingbot-php

> 标签: api, appium, cross-browser, cypress, screenshots, selenium, testing, testingbot

## 简介

PHP client for the TestingBot API (cross-browser & device testing, screenshots, tunnels, storage, codeless tests).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
