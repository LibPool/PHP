# maksudur-dev/laravel-logpilot

> 标签: activity-log, debugging, laravel, logging, tracing

## 简介

A lightweight activity logging package for Laravel with request tracing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
