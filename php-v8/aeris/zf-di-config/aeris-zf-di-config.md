# aeris/zf-di-config

> 标签: dependency injection, servicemanager, zend framework 2, zf2

## 简介

Configurable dependency injection for the ZF2 ServiceManager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
