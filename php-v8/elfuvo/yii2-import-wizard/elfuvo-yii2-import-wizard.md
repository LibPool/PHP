# elfuvo/yii2-import-wizard

> 标签: csv, extension, import, xlsx, yii2

## 简介

Step-by-step import from Excel files with mapping of model attributes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
