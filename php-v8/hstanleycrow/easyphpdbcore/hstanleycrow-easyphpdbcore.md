# hstanleycrow/easyphpdbcore

> 标签: crud, database, mariadb, model, mysql, pdo, php, query-builder

## 简介

Lightweight PDO-based database layer with a simple CRUD model for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
