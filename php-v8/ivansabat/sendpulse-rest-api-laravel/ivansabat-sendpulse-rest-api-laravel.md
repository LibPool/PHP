# ivansabat/sendpulse-rest-api-laravel

> 标签: api, laravel, php, rest, sendpulse

## 简介

A service provider and facade to set up and use the SendPulse PHP library in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
