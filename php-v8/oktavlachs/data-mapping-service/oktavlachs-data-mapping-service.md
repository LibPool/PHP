> 标签: array, cast, casting, converter, converting, data, json, map, mapper, mapping, raw, safe, service, simplexmlelement, stdclass, structure, transformation, translation, type, xml

## 简介

A type safe service, which maps raw data structures onto objects the >= PHP 8 way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
