# alleyinteractive/wp-openapi-generator

> 标签: alleyinteractive, wp-openapi-generator

## 简介

Generate an OpenAPI document for the WordPress REST API and browse it with Swagger UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
