# alleyinteractive/news-sitemap-for-publishers

> 标签: alleyinteractive, news-sitemap-for-publishers

## 简介

Extends WordPress' XML sitemaps feature to add a news sitemap

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
