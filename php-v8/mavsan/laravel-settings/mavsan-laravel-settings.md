# mavsan/laravel-settings

> 标签: Settings, database, json, key, laravel, storage, value

## 简介

Key-value storage for Laravel with cache and facade (fork of orchid/settings)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
