# jvelletti/jv-add2group

> 标签: frontend user, typo3, usergroup

## 简介

Add or Remove usergroup to TYPO3 Frontend user if has Group or has not

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
