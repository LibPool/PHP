# pekral/test-redundancy

> 标签: AI Agents, Test Coverage, Test Suite, code coverage, coverage, dev, duplicate tests, paratest, pest, pestphp, phpunit, redundant tests, test optimization, testing

## 简介

Finds PHPUnit and Pest tests whose covered lines other tests already cover, and shows what each candidate asserts beyond them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
