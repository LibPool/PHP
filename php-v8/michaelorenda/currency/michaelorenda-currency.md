# michaelorenda/currency

> 标签: Accounting, ERP, currency, currency conversion, exchange, exchange rates, finance, forex, fx, fx api, laravel, laravel-12, laravel-package, microfinance, modular packages, multi-currency, orenda, saas, sacco

## 简介

A Laravel 12 multi-currency accounting module with ISO 4217 data, exchange rates, conversions, and API endpoints.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
