# dadapas/mvola-php

> 标签: library, madagascar, mobile-money, mvola, php-sdk

## 简介

A simple class wrapper for MVola mobile money for Madagascar.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
