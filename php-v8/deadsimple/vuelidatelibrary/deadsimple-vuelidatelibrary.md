# deadsimple/vuelidatelibrary

> 标签: PHP

## 简介

A deadsimple module to use Vuelidate in your Modern Magento 2 Vue Projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
