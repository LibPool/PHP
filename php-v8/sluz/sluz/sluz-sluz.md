# sluz/sluz

> 标签: engine, php, smarty, template, templating

## 简介

Sluz is a minimalistic PHP templating engine with an emphasis on syntax similar to Smarty.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
