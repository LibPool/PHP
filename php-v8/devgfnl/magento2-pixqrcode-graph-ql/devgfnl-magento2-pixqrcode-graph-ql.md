# devgfnl/magento2-pixqrcode-graph-ql

> 标签: PHP

## 简介

This Magento 2 module adds support for GraphQL queries related to Pix QR Code payments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
