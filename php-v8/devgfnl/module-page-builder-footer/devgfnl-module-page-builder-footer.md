# devgfnl/module-page-builder-footer

> 标签: PHP

## 简介

A module for Magento 2 that adds a new content type to enable easy creation of footers using Page Builder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
