# hideyukimori/nene2

> 标签: PHP

## 简介

PHP micro-framework: JSON APIs first, minimal server HTML, easy React/SPA integration, structure friendly to AI tooling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
