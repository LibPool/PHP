# hyperzod/first-delivery-sdk-php

> 标签: first-delivery-sdk-php, hyperzod

## 简介

A PHP SDK to integrate FirstDelivery with your application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
