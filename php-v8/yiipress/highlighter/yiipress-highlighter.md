# yiipress/highlighter

> 标签: php-extension, pie, rust, syntax-highlighting, syntect, yiipress

## 简介

Native PHP extension for fast server-side syntax highlighting with syntect

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
