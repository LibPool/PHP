# acplo/acplocart-doctrine-orm

> 标签: acplocart, doctrine, library, module, zf2

## 简介

Addon module form AcploCart to persist the cart with doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
