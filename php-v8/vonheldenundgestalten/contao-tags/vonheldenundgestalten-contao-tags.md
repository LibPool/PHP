# vonheldenundgestalten/contao-tags

> 标签: contao, extension, module, tagcloud, tags

## 简介

tags is a Contao extension that provides an architecture to tag any Contao element.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
