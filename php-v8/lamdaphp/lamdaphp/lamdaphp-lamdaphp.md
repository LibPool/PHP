# lamdaphp/lamdaphp

> 标签: framework, lamdaphp, lightweight php framework, modular PHP framework, php framework, realtime php framework

## 简介

LamdaPHP lightWeight modular PHP framework with rendering data realtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
