# michaelalexeevweb/openapi-php-dto-generator

> 标签: api, deserialization, dto, dto-generator, framework-agnostic, laravel, openapi, openapi-validation, php, psr-7, request-validation, serializer, symfony, validation

## 简介

Generate PHP DTOs from OpenAPI and validate incoming HTTP requests against OpenAPI schema.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
