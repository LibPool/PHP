# michaelalexeevweb/yt-dlp-gui

> 标签: boson, desktop, downloader, gui, php, yt-dlp

## 简介

Desktop GUI wrapper around yt-dlp on PHP with Boson runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
