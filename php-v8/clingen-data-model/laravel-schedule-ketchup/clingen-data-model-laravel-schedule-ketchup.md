# clingen-data-model/laravel-schedule-ketchup

> 标签: catch-up, cron, laravel, schedule, scheduler

## 简介

Run Laravel scheduled tasks whose scheduled time has passed since they last ran, for apps that invoke schedule:run infrequently.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
