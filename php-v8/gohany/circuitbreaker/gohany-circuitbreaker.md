# gohany/circuitbreaker

> 标签: PHP

## 简介

Circuit breaker primitives for Symfony and CodeIgniter (PHP 7.4) with Redis stores and probe gating.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
