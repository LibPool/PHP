# marko/broadcasting-pusher

> 标签: PHP

## 简介

Pusher-protocol broadcasting driver for Marko Framework (Pusher, Soketi, Laravel Reverb)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
