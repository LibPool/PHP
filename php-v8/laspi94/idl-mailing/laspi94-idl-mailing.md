# laspi94/idl-mailing

> 标签: PHP

## 简介

package para realizar llamada al api de SGI Software y Dominios para obtener los contribuyentes registrados en la Secretaría de Estado de Tributación/Paraguay

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
