# dmvdigital/phpsfc

> 标签: components, php, sfc, single-file-components, template, templating, vue

## 简介

PHP Single File Components: CSS, JS, and HTML sections in one PHP file, Vue-SFC style.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
