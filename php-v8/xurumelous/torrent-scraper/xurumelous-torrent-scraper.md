# xurumelous/torrent-scraper

> 标签: kickass, piratebay, torrent

## 简介

Provide an abstraction to seach for torrent files on many websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
