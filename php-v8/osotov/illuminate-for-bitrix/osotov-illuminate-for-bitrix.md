# osotov/illuminate-for-bitrix

> 标签: bitrix, illuminate

## 简介

Adaptation of some Illuminate components for usage inside 1C-Bitrix framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
