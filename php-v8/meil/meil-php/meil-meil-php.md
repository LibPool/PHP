# meil/meil-php

> 标签: api, email, meil, newsletter, ses, transactional-email

## 简介

Official PHP client for the meil.ro email API: transactional email and newsletters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://meil.ro/docs
- 源码仓库：https://github.com/meilro/meil-php.git
- Packagist 页面：https://packagist.org/packages/meil%2Fmeil-php
