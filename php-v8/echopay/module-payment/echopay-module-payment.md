# echopay/module-payment

> 标签: bank-transfer, direct-debit, magento2, payment

## 简介

EchoPay Payment Module - Direct bank transfer payment gateway integration for Magento 2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
