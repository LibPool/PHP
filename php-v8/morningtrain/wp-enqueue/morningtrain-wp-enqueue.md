# morningtrain/wp-enqueue

> 标签: enqueue, morningtrain, wordpress

## 简介

A tool for enqueueing assets in WordPress with support for Laravel Mix manifest

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
