# kalimeromk/countries

> 标签: laravel

## 简介

Laravel Countries is a package for Laravel, providing Almost ISO 3166_2, 3166_3, currency, Capital and more for all countries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
