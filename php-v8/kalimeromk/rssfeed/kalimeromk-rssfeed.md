# kalimeromk/rssfeed

> 标签: content-extraction, feed, full-text, laravel, readability, rss

## 简介

Full-Text RSS extraction package for Laravel - converts partial RSS feeds to full content

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
