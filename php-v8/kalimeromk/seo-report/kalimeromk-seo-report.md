# kalimeromk/seo-report

> 标签: PHP

## 简介

Framework-agnostic PHP SEO analysis: analyze URL/sitemap, return API result (JSON). Works with Laravel, Yii, or plain PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
