# jamisonbryant/cakephp-secureids-plugin

> 标签: base64, cakephp, plugin, security, uuid

## 简介

A CakePHP plugin for using secure, non-incremental IDs for entities

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
