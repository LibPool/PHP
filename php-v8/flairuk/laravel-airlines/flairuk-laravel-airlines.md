# flairuk/laravel-airlines

> 标签: airlines, aviation, iata, laravel, travel

## 简介

IATA airline codes for Laravel: an in-memory lookup API, validation rule and optional database table.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
