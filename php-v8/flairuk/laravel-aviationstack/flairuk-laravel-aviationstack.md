# flairuk/laravel-aviationstack

> 标签: APILayer, airlines, airports, aviationstack, flight-tracking, flights, laravel

## 简介

The aviationstack API for Laravel: real-time and historical flights, airport timetables, future schedules, routes, airports, airlines and aircraft, with typed errors and lazy paging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
