# flairuk/laravel-booking-com

> 标签: API-Client, accommodation, affiliate, booking, booking.com, demand-api, hotels, laravel, travel

## 简介

A Laravel client for the Booking.com Demand API: search, availability, property content, orders and car rentals.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
