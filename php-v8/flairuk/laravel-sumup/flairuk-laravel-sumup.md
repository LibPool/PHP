# flairuk/laravel-sumup

> 标签: card-reader, checkout, laravel, oauth, payments, sumup, webhooks

## 简介

SumUp payments for Laravel: online checkouts, the Payment Widget, refunds, customers, Cloud API card readers, OAuth and verified webhooks, built on SumUp's official PHP SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
