# flairuk/laravel-countries

> 标签: calling-codes, countries, currencies, flags, iso-3166, laravel

## 简介

ISO 3166 countries for Laravel: codes, currencies, calling codes, regions, EEA membership and flags, with a lookup API, validation rule and optional database table.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
