# flairuk/laravel-square

> 标签: API-Client, laravel, payments, square, squareup, web-payments-sdk, webhooks

## 简介

Square payments for Laravel: the official Square PHP SDK, configured, plus webhooks, idempotency keys, money helpers, OAuth and a Web Payments card form.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
