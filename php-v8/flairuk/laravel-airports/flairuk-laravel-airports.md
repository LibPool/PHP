# flairuk/laravel-airports

> 标签: airport-codes, airports, aviation, iata, laravel, travel

## 简介

IATA airport codes for Laravel: an in-memory lookup API, validation rule and optional database table.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
