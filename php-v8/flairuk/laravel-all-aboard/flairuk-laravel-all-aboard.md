# flairuk/laravel-all-aboard

> 标签: API-Client, all-aboard, allaboard, graphql, interrail, laravel, rail, rail-pass, tickets, train, travel

## 简介

A Laravel client for the All Aboard rail API: European train journeys, offers, bookings, orders, rail passes and refunds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
