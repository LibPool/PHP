# flairuk/good-till-system

> 标签: API-Client, epos, good-till, goodtill, laravel, pos

## 简介

A Laravel client for the Goodtill EPOS API, with automatic token management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
