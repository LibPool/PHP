# flairuk/laravel-aircrafts

> 标签: aircraft-types, aircrafts, aviation, iata, laravel, travel

## 简介

IATA aircraft type codes for Laravel: an in-memory lookup API, validation rule and optional database table.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
