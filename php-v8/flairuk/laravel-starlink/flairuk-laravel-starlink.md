# flairuk/laravel-starlink

> 标签: alerts, iot, laravel, monitoring, satellite, starlink, telemetry

## 简介

Starlink for Laravel: poll the device telemetry stream, decode its column-indexed rows, resolve alerts into raised and cleared events, and read the latest values per terminal and router.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
