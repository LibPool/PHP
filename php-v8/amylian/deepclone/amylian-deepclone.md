# amylian/deepclone

> 标签: clone, cloning, deep clone, deep copy, deepclone, deepcopy, objects

## 简介

Provides Deep Cloning (Copying) of objects and arrays

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
