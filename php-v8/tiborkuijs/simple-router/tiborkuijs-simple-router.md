# tiborkuijs/simple-router

> 标签: TiborKuijs, framework, input-handler, laravel, php, request-handler, route, router, routing, routing-engine, simple-php-router, url-handling

## 简介

Simple, fast PHP router that is easy to get integrated and in almost any project. Heavily inspired by the Laravel router.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
