# chriskonnertz/deeply

> 标签: Neural, ai, api, client, deepl, deeply, language, library, translate, translation

## 简介

DeepLy is a PHP client for the DeepL.com translation API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
