# debjit/php-ai-hub

> 标签: ai, composer-plugin, laravel, no-sdk, sdk

## 简介

AI HTTP Service Installer (no-SDK) for Laravel: copy/paste provider stubs via Composer plugin events with JSON registry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
