# erdiko/theme

> 标签: erdiko, theme, theme-engine

## 简介

Erdiko micro theming engine, based on twig

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/Erdiko/theme.git
- Packagist 页面：https://packagist.org/packages/erdiko%2Ftheme
