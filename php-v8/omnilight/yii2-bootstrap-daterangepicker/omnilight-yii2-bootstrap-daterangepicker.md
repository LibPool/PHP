# omnilight/yii2-bootstrap-daterangepicker

> 标签: date, picker, range, yii2

## 简介

Date range picker component for Bootstrap for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
