# omnilight/icons

> 标签: font awesome, yii

## 简介

Yii2 extension for managing icons from Font Awesome

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/omnilight%2Ficons
- 源码仓库：https://github.com/omnilight/icons.git

## 获取地址

- Composer 安装：`composer require omnilight/icons`
- Packagist 仓库：https://repo.packagist.org/p2/omnilight/icons.json
- PHP 要求：>=5.4.0
