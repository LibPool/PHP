# omnilight/yii2-vuejs

> 标签: omnilight, vue, vuejs, yii2

## 简介

Vue.js library for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/omnilight/yii2-vuejs
- 源码仓库：https://github.com/omnilight/yii2-vuejs.git
