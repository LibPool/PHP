# qbnk/frontend-components-aad-oidc

> 标签: PHP

## 简介

Azure AD OpenID Connect (hybrid flow), part of Frontend Components for Slim-based frontends.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
