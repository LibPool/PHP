# qbnk/qbank-jobqueue-protocol

> 标签: PHP

## 简介

Contains shared code between QBank and Jobqueue consisting of ffmpeg, imageconvert & worker models

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
