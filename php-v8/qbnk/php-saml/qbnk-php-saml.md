# qbnk/php-saml

> 标签: SAML2, onelogin, saml

## 简介

This is a clone of the OneLogin PHP SAML Toolkit, modified to support seamless change of signing certificates.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
