# qbnk/guzzle-oauth2-plugin

> 标签: PHP

## 简介

An OAuth2 middleware for Guzzle ^7.0, forked from sainsburys/guzzle-oauth2-plugin

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
