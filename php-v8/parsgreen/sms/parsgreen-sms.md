# parsgreen/sms

> 标签: bulk-sms, laravel, otp, parsgreen, sms

## 简介

ParsGreen SMS gateway client for Laravel (send SMS, OTP, credit management, and more).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
