# georgeff/http-kernel

> 标签: PHP

## 简介

PSR-15 HTTP kernel.  Provides routing, a global middleware stack, per-route middleware, exception handling, and response emission

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
