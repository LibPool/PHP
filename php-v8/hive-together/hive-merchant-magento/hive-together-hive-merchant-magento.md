# hive-together/hive-merchant-magento

> 标签: discounts, hive, hivetogether, magento-module, magento2

## 简介

Hive Merchant integration for Magento 2.1.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
