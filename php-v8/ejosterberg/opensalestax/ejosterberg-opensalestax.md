# ejosterberg/opensalestax

> 标签: api, opensalestax, sales-tax, sdk, tax

## 简介

PHP SDK for the OpenSalesTax engine — open-source US sales tax calculation API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
