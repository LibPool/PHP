# mohsinqk/mindshape-cookie-consent

> 标签: PHP

## 简介

This extension is a fork of the original mindshape_cookie_consent extension. It provides functionality to create a customizable cookie consent for your website. It is developed for flexibility to be customized in accordance to your data security guidelines.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
