# mohsinqk/tinyimg

> 标签: compression, image, tinify, tinyjpg, tinypng

## 简介

Image compression for all pngs and jpgs uploaded to the backend (using the tinypng API)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
