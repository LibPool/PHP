# actiontecbr/falaai-api

> 标签: API-Client, Transcription, api, call-audit, compliance, falaai, php, rest, sdk, speech-to-text

## 简介

Official PHP SDK for the FalaAI API - AI-powered call transcription, diagnosis and compliance auditing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
