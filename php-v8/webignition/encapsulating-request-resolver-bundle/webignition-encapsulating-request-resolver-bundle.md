# webignition/encapsulating-request-resolver-bundle

> 标签: PHP

## 简介

Symfony controller action argument resolver for types that extend Symfony\Component\HttpFoundation\Request

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
