# webignition/web-resource

> 标签: Sitemap, json-document, model, psr-7, web-page

## 简介

Models for resources retrieved from the web, services to retrieve and create

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
