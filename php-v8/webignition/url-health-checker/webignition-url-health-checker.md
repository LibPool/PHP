# webignition/url-health-checker

> 标签: checker, health, url

## 简介

Check the health of a URL. Does it return 200 OK? 404 Not Found? Does in redirect indefinitely?

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
