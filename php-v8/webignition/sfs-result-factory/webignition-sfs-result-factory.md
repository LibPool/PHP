# webignition/sfs-result-factory

> 标签: factory, forum, result, spam, stopforumspam.com

## 简介

Factory to create result objects from api.stopforumspam.com responses

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
