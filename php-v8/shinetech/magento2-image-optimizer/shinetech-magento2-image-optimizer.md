# shinetech/magento2-image-optimizer

> 标签: image-optimizer, justbetter, magento 2

## 简介

Magento 2 Image optimizer wrapper build on https://github.com/spatie/image-optimize

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
