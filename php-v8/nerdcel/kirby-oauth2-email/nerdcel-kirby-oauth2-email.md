# nerdcel/kirby-oauth2-email

> 标签: PHP

## 简介

Kirby Plugin to setup OAuth for SMTP Mail (e.g. Outlook, Gmail, Yahoo, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
