# nerdcel/kirby3-favicon

> 标签: getkirby, kirby, kirby-cms, kirby-plugin, kirby3

## 简介

Kirby3 plugin to create favicons from the panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
