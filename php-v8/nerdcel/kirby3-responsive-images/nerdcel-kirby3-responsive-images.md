# nerdcel/kirby3-responsive-images

> 标签: getkirby, kirby, kirby-cms, kirby-plugin

## 简介

Kirby3 plugin to manage responsive images settings using the panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
