# quineworks/taxlane

> 标签: Nigeria, cgt, cit, import-duty, paye, payroll, sdk, stamp-duty, tax, tax-calculator, vat, withholding-tax

## 简介

Official PHP SDK for TaxLane's free Nigeria tax calculator API (PAYE, VAT, WHT, CIT, CGT & 6 more).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
