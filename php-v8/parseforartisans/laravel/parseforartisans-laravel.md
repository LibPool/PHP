# parseforartisans/laravel

> 标签: OCR, documents, laravel, markdown, parsing, pdf

## 简介

Parse documents to Markdown from Laravel. The client SDK for parseforartisans.com.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
