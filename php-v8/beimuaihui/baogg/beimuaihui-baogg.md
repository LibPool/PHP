# beimuaihui/baogg

> 标签: api, framework, micro

## 简介

Baogg is a PHP micro framework that helps you quickly write fast-security-simple web applications and APIs,Slim php framework extensions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
