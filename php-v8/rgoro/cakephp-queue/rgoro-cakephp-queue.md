# rgoro/cakephp-queue

> 标签: background, cakephp, deferred tasks, mongodb, queue

## 简介

The Queue plugin for CakePHP provides deferred task execution. This is a MongoDB implementation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
