# sayamaapps/kirby-higawari

> 标签: daily-menu, kirby, kirby-5, kirby-plugin, menu, privacy, restaurant

## 简介

Daily menu (Tageskarte) for Kirby CMS 5: dishes with a validity date and window, a Panel structure, a plain snippet and a Fude marker for changes by chat. No scripts, no third-party requests, no chat or write endpoint.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
