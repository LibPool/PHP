# sayamaapps/kirby-fude

> 标签: bot, chat, content, drafts, kirby, kirby-5, kirby-plugin

## 简介

Change declared website content by chat message: drafts as Kirby 5 content versions, preview link, explicit publish. Kirby side of the Fude module.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
