# sayamaapps/kirby-kizami

> 标签: analytics, cookieless, kirby, kirby-5, kirby-plugin, privacy, sqlite, statistics

## 简介

Cookieless, server-side page and link-click statistics for Kirby CMS. No JavaScript required, honours DNT/GPC, daily rotating salt, SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
