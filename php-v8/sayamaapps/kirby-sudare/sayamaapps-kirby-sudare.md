# sayamaapps/kirby-sudare

> 标签: access-control, basic-auth, kirby, kirby-5, noindex, preview, staging

## 简介

Preview protection for Kirby CMS sites before launch: Basic Auth in front of Kirby, noindex on every response, media and assets served through PHP so they are protected too. Runs before Kirby boots.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
