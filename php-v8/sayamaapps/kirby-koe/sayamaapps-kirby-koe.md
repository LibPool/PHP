# sayamaapps/kirby-koe

> 标签: google, kirby, kirby-5, kirby-plugin, places-api, privacy, reviews

## 简介

Google reviews for Kirby CMS, served from your own server: fetched on demand via the Places API (New) into a short-lived cache, rule-based selection, no request to Google from the visitor's browser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
