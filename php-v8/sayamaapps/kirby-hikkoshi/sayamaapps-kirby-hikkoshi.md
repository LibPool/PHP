# sayamaapps/kirby-hikkoshi

> 标签: 301, Wix, htaccess, jimdo, kirby, kirby-5, kirby-plugin, migration, redirects, wordpress

## 简介

Redirects for Kirby CMS after moving house from Jimdo, Wix or WordPress: a checked list of old paths (loops, chains, foreign domains, duplicates), tolerant matching (case, trailing slash, umlauts, .html/index.php suffixes, query strings), a converter for Apache .htaccess rules and a test helper for sites. No outbound HTTP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
