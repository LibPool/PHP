# sayamaapps/kirby-genba

> 标签: ci, deployment, kirby, kirby-5, kirby-plugin, link-check, operations, smoke-test

## 简介

Operations for a deployed Kirby CMS site: build stamp in the HTML, pre-deploy checks (CSP, built assets), post-deploy smoke test (build, content, delivery, Panel), foreign-link check against the source (YouTube, Digistore, purchase links), preflight hook. Command-line tools plus a tiny Kirby plugin part. No styling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
