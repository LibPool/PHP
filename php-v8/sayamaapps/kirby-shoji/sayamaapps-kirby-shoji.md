# sayamaapps/kirby-shoji

> 标签: Forms, brevo, click-to-load, embed, facade, gdpr, kirby, kirby-5, kirby-plugin, privacy, vimeo, youtube

## 简介

Click-to-load for Kirby CMS: YouTube, Vimeo, Digistore24 and HTML forms (Brevo) stay behind a placeholder with a preview image from your own server until the visitor clicks. No third-party host in the page, no cookies, no inline script.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
