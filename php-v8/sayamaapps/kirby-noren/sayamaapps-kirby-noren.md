# sayamaapps/kirby-noren

> 标签: holidays, kirby, kirby-5, kirby-plugin, local-business, opening-hours, schema-org

## 简介

Opening hours for Kirby CMS: weekly plan with several blocks per day, areas and locations, closures and special hours, German public holidays for all 16 states, an "open now" status and schema.org data. No styling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
