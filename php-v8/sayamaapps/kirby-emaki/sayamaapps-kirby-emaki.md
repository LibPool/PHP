# sayamaapps/kirby-emaki

> 标签: accessibility, csp, gallery, image-viewer, kirby, kirby-5, kirby-plugin, lightbox, srcset

## 简介

Image viewer for Kirby CMS 5: a dependency-free lightbox built on <dialog>, served from your own server, plus a thin gallery helper that renders srcset tiles and large views from Kirby's own thumb presets. No CDN, no inline code, no cookies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
