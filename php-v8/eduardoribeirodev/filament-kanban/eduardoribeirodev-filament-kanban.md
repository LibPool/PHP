# eduardoribeirodev/filament-kanban

> 标签: drag-and-drop, filament, infinite-scroll, kanban, laravel, livewire

## 简介

Kanban boards for Filament with native filters, actions, infolists, drag and drop, and progressive loading.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
