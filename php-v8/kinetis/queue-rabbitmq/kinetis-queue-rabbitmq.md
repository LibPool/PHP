# kinetis/queue-rabbitmq

> 标签: PHP

## 简介

A Fiber-native non-blocking RabbitMQ (AMQP 0-9-1) backend for kinetis/queue's QueueInterface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
