# kinetis/bref-adapter

> 标签: PHP

## 简介

AWS Lambda (Bref) runtime adapter for Kinetis — polls the Lambda Runtime API and converts API Gateway v2 payloads to/from PSR-7.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
