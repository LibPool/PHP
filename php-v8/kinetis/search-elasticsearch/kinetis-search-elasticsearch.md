# kinetis/search-elasticsearch

> 标签: PHP

## 简介

Fiber-native non-blocking Elasticsearch client construction for Kinetis, on kinetis/search's Revolt-backed HTTP transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
