# kinetis/storage-s3

> 标签: PHP

## 简介

S3 (and S3-compatible) file storage for Kinetis, plugging into kinetis/storage's FILESYSTEM_DRIVER=s3 — every S3 call travels on a Revolt-native HTTP transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
