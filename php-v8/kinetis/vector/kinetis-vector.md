# kinetis/vector

> 标签: admin, admin-panel, crud, kinetis, mcp, orm

## 简介

A schema-driven admin platform for Kinetis applications: a compiled resource registry, a REST admin API and MCP tools over kinetis/orm entities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
