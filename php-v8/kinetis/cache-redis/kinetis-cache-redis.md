# kinetis/cache-redis

> 标签: PHP

## 简介

PSR-16 SimpleCache for Kinetis, backed by Redis (single-node or Cluster) over kinetis/redis — non-blocking, Revolt-native, with TLS support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
