# graze/silex-trailing-slash-handler

> 标签: PHP

## 简介

Handle requests missing a trailing slash in Silex by appending a slash and issuing an internal sub-request.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
