# matiz-studio-creative/sri-toolkit

> 标签: clave-acceso, comprobante-retencion, comprobantes-electronicos, ecuador, electronic-invoicing, factura, factura-electronica, facturacion-electronica, guia-remision, modulo-11, nota-credito, nota-debito, pkcs12, servicio-de-rentas-internas, soap, sri, sri-ecuador, sri-xml, xades-bes, xml

## 简介

PHP toolkit for Ecuador SRI electronic documents: access keys, XML builders, XAdES-BES signing and SOAP delivery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
