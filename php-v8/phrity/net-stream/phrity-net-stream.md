# phrity/net-stream

> 标签: Socket, client, psr-17, psr-7, server, stream, stream factory

## 简介

Socket stream classes implementing PSR-7 Stream and PSR-17 StreamFactory

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
