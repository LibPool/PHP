# phrity/comparison

> 标签: comparable, comparator, comparison, equalable, filter, sort

## 简介

Interfaces and helper trait for comparing objects. Comparator for sort and filter applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
