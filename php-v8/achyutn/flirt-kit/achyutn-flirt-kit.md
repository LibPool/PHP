# achyutn/flirt-kit

> 标签: filament, flirt-kit, framework, laravel, rilt, starter-kit

## 简介

The skeleton application for the Laravel framework with RILT stack and Filament v4 as Admin Panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
