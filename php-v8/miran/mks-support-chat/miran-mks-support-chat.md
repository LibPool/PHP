# miran/mks-support-chat

> 标签: chat, filament, laravel, live-chat, support

## 简介

Filament-backed live support chat for Laravel. Visitor widget plus an admin inbox — no mobile app, no multi-site tabs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
