# saasykit/laravel-open-graphy

> 标签: Ahmad Mas, laravel, laravel-open-graphy

## 简介

An awesome open graph image (social cards) generator package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
