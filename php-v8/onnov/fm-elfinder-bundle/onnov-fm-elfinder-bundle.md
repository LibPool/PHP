# onnov/fm-elfinder-bundle

> 标签: elfinder, file manager, wysiwyg

## 简介

ElFinder bundle, adds ElFinder file manager to your Symfony project

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
