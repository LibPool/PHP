# smartgroup/smart-serializer

> 标签: PHP

## 简介

Smart-serializer is a tiny library which allows to serialize PHP objects. It supports routes, translations and nested objects of Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
