# bpez/infuse

> 标签: admin, laravel, laravel 5, scaffold

## 简介

Infuse is a laravel admin package for generating administration style interfaces

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
