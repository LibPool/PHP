# dem3trio/carbon-profiler-bundle

> 标签: PHP

## 简介

Symfony 2/3 profiler extension, to change the Carbon php date in the whole project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
