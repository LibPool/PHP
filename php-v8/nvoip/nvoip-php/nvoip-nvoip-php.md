# nvoip/nvoip-php

> 标签: api, nvoip, otp, sms, telefonia, voip, whatsapp

## 简介

SDK PHP oficial para integrar OAuth, chamadas, OTP, WhatsApp, SMS e saldo com a API v3 da Nvoip.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
