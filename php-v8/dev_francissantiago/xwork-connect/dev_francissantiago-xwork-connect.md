# dev_francissantiago/xwork-connect

> 标签: PHP

## 简介

Uma biblioteca para gerenciar conexões com banco de dados XWF e Firebird para o Gestão Profissional.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
