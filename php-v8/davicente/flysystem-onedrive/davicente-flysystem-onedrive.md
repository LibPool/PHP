# davicente/flysystem-onedrive

> 标签: Flysystem, OneDrive, api, client, filesystem

## 简介

OneDrive adapter for the flysystem filesystem abstraction library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
