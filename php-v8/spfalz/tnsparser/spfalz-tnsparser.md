# spfalz/tnsparser

> 标签: class, oracle, tns, tnsnames.ora

## 简介

Class for parsing Oracle TNS files (tnsnames.ora).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
