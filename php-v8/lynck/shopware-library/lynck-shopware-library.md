# lynck/shopware-library

> 标签: crefopay, ecommerce, library, lynck, payments, psp

## 简介

A derivative of lynck PHP library for an easier implementation of lynck`s Web-API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
