# ttbooking/mailspoon

> 标签: imap, laravel, mailgun, webhook

## 简介

Simple Mailgun compatible IMAP to HTTP webhook relay for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
