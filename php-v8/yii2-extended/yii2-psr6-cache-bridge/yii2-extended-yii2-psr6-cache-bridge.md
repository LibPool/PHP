# yii2-extended/yii2-psr6-cache-bridge

> 标签: Bridge, cache, psr6, yii2

## 简介

A library to bridge psr-6 caches with the yii caching system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
