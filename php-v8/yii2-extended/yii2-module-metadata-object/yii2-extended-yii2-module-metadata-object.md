# yii2-extended/yii2-module-metadata-object

> 标签: implementation, metadata, module, object, php, yii2

## 简介

This library is a simple implementation of the yii2-extended/yii2-module-metadata-interface library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
