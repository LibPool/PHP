# larawave/logic-as-data

> 标签: ast, business-rules, conditional-logic, json-rules, laravel, logic-as-data, logic-engine, rule-engine, workflow-automation

## 简介

Treat your business logic as data with this dynamic, data-driven engine for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
