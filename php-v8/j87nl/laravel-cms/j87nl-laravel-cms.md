# j87nl/laravel-cms

> 标签: Sitemap, blocks, cms, laravel, seo

## 简介

Block-based CMS core for Laravel: pages, blocks and server-side public rendering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
