# j87nl/laravel-mailbox

> 标签: imap, j87, laravel, shared-inbox, smtp

## 简介

Shared IMAP/SMTP mailboxes for Laravel: sync, folder actions, sending and an audit trail, independent of any frontend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
