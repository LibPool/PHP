# j87nl/laravel-mailing

> 标签: double-opt-in, laravel, mailing, newsletter, rfc8058

## 简介

Mailing lists for Laravel: double opt-in sign-up, consent records, one-click unsubscribe, suppressions and imports.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
