# j87nl/laravel-vue-mailbox

> 标签: imap, inertia, j87, laravel, shared-inbox, vue

## 简介

A VueJS/Inertia shared mailbox UI for j87nl/laravel-mailbox, built on the FormBuilder and TableBuilder

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
