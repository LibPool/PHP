# stoneholl/module-order-coupon-grid-filter

> 标签: coupon, discount, magento2, order-grid

## 简介

Coupon code, coupon usage, and discount amount fields for the Magento Open Source order grid.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
