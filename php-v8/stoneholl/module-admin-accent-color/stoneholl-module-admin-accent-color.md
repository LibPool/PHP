# stoneholl/module-admin-accent-color

> 标签: accent-color, admin, magento2

## 简介

Safe per-area and per-administrator accent colors for the standard Magento Admin theme.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
