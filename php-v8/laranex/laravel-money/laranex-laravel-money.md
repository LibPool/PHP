# laranex/laravel-money

> 标签: cast, currency, decimal, eloquent, laranex, laravel, laravel-money, money, moneyphp, percentage

## 简介

Money for Laravel: exact, currency-aware amounts with arithmetic, percentages, allocation, formatting and Eloquent casts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
