# laranex/laravel-schema-viewer

> 标签: DBML, Relationships, database, diagram, eloquent, er diagram, erd, laranex, laravel, laravel-schema-viewer, mermaid, schema

## 简介

Schema viewer for Laravel: an interactive diagram of your database tables and Eloquent relationships.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
