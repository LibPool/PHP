# laranex/next-laravel

> 标签: laranex, laravel, laravel-modular, next-laravel

## 简介

A package which allows you to build a next Laravel Application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://next-laravel.netlify.app
- 源码仓库：https://github.com/laranex/next-laravel.git
- Packagist 页面：https://packagist.org/packages/laranex%2Fnext-laravel

## 获取地址

- Composer 安装：`composer require laranex/next-laravel`
- Packagist 仓库：https://repo.packagist.org/p2/laranex/next-laravel.json
- PHP 要求：^8.2 || ^8.1
