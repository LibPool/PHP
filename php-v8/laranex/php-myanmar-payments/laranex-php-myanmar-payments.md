# laranex/php-myanmar-payments

> 标签: Myanmar, ayapay, cybersource, kbzpay, laranex, mmqr, payment-gateway, payments, php, php-myanmar-payments, psr-18, wavepay, wavepay-mini-app, yoma

## 简介

PHP SDK for Myanmar payment gateways: KBZ Pay, Wave Pay, Wave Pay Mini App, AYA Pay, Yoma MMQR and CyberSource. Typed requests and results, exact amounts, works with any PSR-18 HTTP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
