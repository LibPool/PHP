# roro/roroform

> 标签: Forms, accessibility, blade, blade-components, bootstrap, form-builder, laravel, php, repeatable, select, tailwind

## 简介

Laravel form components with repeatable groups that actually work — searchable selects, a chainable type-aware JS API, full old()/validation/CSRF integration, and a zero-CSS-framework theme. Zero JS dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
