# baklysystems/laravel-dompdf

> 标签: arabic, dompdf, laravel, pdf

## 简介

A DOMPDF Wrapper for Laravel with arabic support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
