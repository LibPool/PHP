# andrewfenn/aws-helper

> 标签: amazon, aws, s3, sdk, sqs

## 简介

A small helper library to make intergration of the AWS SDK easier

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
