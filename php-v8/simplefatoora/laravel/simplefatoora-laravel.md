# simplefatoora/laravel

> 标签: Saudi Arabia, ZATCA, e-invoicing, laravel, simple fatoora

## 简介

Official Laravel package for the Simple Fatoora API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
