# uniwue/uw_a11y_check

> 标签: TYPO3 CMS, a11y, accessibility

## 简介

Configurable a11y check for tt_content and extension records

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
