# nodejs-php-fallback/coffeescript

> 标签: PHP

## 简介

PHP wrapper to execute coffeescript node package or fallback to a PHP alternative

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
