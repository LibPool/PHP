# ehundu/andamio-minimo

> 标签: Skeleton, andamio, ehundu, generador-de-sitios-estaticos, plantilla, scaffold, scaffolding, sitio-estatico, starter

## 简介

Un sitio de presentación de cuatro páginas hecho con Ehundu, para empezar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
