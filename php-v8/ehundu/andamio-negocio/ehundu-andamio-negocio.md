# ehundu/andamio-negocio

> 标签: Skeleton, andamio, ehundu, generador-de-sitios-estaticos, negocio-local, plantilla, pyme, scaffold, scaffolding, sitio-estatico, starter

## 简介

Un sitio para un negocio local hecho con Ehundu, con servicios, horarios con excepciones, ubicación, contacto, preguntas frecuentes y páginas legales de modelo, para empezar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
