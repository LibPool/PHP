# ehundu/andamio-portfolio

> 标签: Skeleton, andamio, ehundu, generador-de-sitios-estaticos, plantilla, portafolio, portfolio, scaffold, scaffolding, sitio-estatico, starter

## 简介

Un portfolio personal hecho con Ehundu, con proyectos destacados, una ficha por proyecto, filtros por área, sobre mí y contacto, para empezar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
