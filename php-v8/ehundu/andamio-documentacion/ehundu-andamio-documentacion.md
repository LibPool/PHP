# ehundu/andamio-documentacion

> 标签: Skeleton, andamio, documentacion, ehundu, generador-de-sitios-estaticos, plantilla, scaffold, scaffolding, sitio-estatico, starter, wiki

## 简介

Una documentación hecha con Ehundu, con menú por secciones, índice de cada página, anterior y siguiente y enlace para editarla, para empezar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
