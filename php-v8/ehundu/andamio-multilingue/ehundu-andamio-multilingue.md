# ehundu/andamio-multilingue

> 标签: Skeleton, andamio, bilingue, ehundu, euskera, generador-de-sitios-estaticos, i18n, multilingue, plantilla, scaffold, scaffolding, sitio-estatico, starter

## 简介

Una web completa en dos idiomas (castellano y euskera) hecha con Ehundu, con sus páginas enlazadas entre idiomas, selector, hreflang, menús y textos por idioma, para empezar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
