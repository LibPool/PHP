# sigbits/php-amqp-client-bundle

> 标签: AMQP, amqp-1.0, messaging, symfony, symfony-bundle

## 简介

Thin Symfony bundle for configuring sigbits/php-amqp-client connection factories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
