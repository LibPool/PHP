# sigbits/php-amqp-client

> 标签: AMQP, amqp-1.0, amqp10, artemis, azure-service-bus, messaging, qpid, rabbitmq

## 简介

Pure PHP AMQP 1.0 client library in early development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
