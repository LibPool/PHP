# niainteractive/wnniacalendar

> 标签: PHP

## 简介

NiaCalendar is a fully functional events calendar for WinterCMS using FullCalendar.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
