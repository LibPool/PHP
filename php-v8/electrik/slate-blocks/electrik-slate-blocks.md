# electrik/slate-blocks

> 标签: Electrik, blade, blocks, laravel, slate, tailwind, ui

## 简介

Curated Blade UI blocks for Electrik Slate — marketing, auth, and application sections composed from Slate primitives.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
