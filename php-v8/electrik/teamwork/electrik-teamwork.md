# electrik/teamwork

> 标签: Electrik, Invite, Teams, laravel

## 简介

Electrik fork of mpociot/teamwork — user/team associations with invites for Laravel 10–13.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
