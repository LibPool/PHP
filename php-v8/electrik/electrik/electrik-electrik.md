# electrik/electrik

> 标签: Electrik, Teams, billing, laravel, livewire, saas, slate, starter-kit

## 简介

Laravel SaaS starter kit: auth, teams, and Stripe billing on Electrik Slate.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
