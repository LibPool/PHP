# electrik/slate

> 标签: blade, components, dark-mode, design-system, laravel, laravel-ui, livewire, shadcn, tailwind, tailwindcss, ui, ui-kit

## 简介

A shadcn-inspired Blade UI kit for Laravel with anonymous components, Tailwind CSS v4, and Slate-owned theme tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
