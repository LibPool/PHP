# aeneria/grdf-adict

> 标签: PHP

## 简介

A small library to use a part of GRDF ADICT API with PHP : https://site.grdf.fr/web/grdf-adict/

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
