# devhub/url-rewrite-pro

> 标签: PHP

## 简介

By using this extension, vendor(s) will be able to generate URL rewrites for Products, Categories and Stores.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
