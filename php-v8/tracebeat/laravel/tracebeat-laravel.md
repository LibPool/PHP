# tracebeat/laravel

> 标签: laravel, monitoring, nightwatch, observability, tracebeat

## 简介

Connect a Laravel application to TraceBeat. A thin layer over laravel/nightwatch that points the agent at your TraceBeat server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
