# unifiedcodes/arbor

> 标签: arbor, dependency-injection, framework, micro-framework, modular, php, psr

## 简介

A modular PHP micro-framework for fast, modern application development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
