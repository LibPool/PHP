# ryan-junio-oliveira/websocket-channels

> 标签: PHP

## 简介

Biblioteca PHP para servidor WebSocket com suporte a canais públicos e fechados usando Ratchet

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
