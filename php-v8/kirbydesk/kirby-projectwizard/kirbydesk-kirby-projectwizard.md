# kirbydesk/kirby-projectwizard

> 标签: kirby, kirby-plugin, projectwizard

## 简介

Project Wizard for Kirby CMS — installation, configuration & update tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
