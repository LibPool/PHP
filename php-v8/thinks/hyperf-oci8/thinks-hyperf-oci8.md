# thinks/hyperf-oci8

> 标签: hyperf, laravel, oci8, oracle, pdo_oci

## 简介

Oracle DB driver for Laravel 4|5|6|7 via OCI8

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
