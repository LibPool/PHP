# zeyn4loff/laravel-fluent-resources

> 标签: PHP

## 简介

Recursive dot-notation field control, multi-language support, and auto-pagination for Laravel API Resources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
