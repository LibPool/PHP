# chmat/excel-bundle

> 标签: PHP

## 简介

This bundle integrates phpExcel library into a Symfony bundle. It lets you read (and write) simple Excel|CSV files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
