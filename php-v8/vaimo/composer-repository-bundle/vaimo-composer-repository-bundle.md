# vaimo/composer-repository-bundle

> 标签: consolidated local repository, custom repository, install from github, install from remote tarball, install from zip, package bundle, project repository, sub-folder packages

## 简介

Allow packages to be installed from a repository or tarball bundle that have multiple packages in the sub-folders

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
