# vaimo/binary-chromedriver

> 标签: Browser Testing, Chromedriver, acceptance testing, binary, binary downloader, browser driver, chrome automation, composer extension, composer plugin, downloader, test-automation, testing, webdriver

## 简介

Utility for downloading Chrome Driver binary for current os/platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
