# olevik/grav-plugin-presentation

> 标签: fullscreen, grav, plugin, presentation, reveal.js, slides, slideshow

## 简介

Fullscreen navigational slideshows through Reveal.js

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
