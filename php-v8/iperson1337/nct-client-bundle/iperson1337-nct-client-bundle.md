# iperson1337/nct-client-bundle

> 标签: Kazakhstan, gtin, national-catalog, nationalcatalog, nct, ntin, symfony, symfony-bundle, xtin

## 简介

Symfony client for the National Catalog of Goods of Kazakhstan (НКТ): nationalcatalog.kz portal API (product requests, attributes, dictionaries) and nct.gov.kz public lookups, with retries, rate limiting and typed errors

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
