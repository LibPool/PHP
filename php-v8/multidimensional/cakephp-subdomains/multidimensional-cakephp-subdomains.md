# multidimensional/cakephp-subdomains

> 标签: cakephp, cakephp3, subdomains

## 简介

Easily add sub domains to your CakePHP application using route prefixes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
