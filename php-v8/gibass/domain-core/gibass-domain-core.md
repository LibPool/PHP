# gibass/domain-core

> 标签: clean-architecture, ddd, domain, domain-events, symfony, use-case

## 简介

Abstractions and helpers for domain layer in Symfony projects using Clean Architecture.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
