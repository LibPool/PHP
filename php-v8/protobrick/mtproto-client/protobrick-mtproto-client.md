# protobrick/mtproto-client

> 标签: Telegram-API, amphp, api, async, authorization, bot, client, library, mtproto, php, protobrick, protocol, sdk, tdlib, telegram, userbot, wrapper

## 简介

Modern async pure PHP client library for Telegram MTProto API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
