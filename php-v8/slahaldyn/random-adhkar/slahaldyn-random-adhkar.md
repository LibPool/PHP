# slahaldyn/random-adhkar

> 标签: PHP

## 简介

A simple PHP library to fetch random Adhkar (Text, Images, Audio, and Videos) from GitHub.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
