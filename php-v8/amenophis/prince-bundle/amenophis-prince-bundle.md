# amenophis/prince-bundle

> 标签: htmltopdf, pdf, prince

## 简介

Prince bundle. It integrates Prince XML library into Symfony2 application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
