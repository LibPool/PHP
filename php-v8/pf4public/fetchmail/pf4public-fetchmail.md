# pf4public/fetchmail

> 标签: download, fetchmail, mailbox

## 简介

Roundcube fetchmail plugin is a Roundcube plugin, which allows users to download their mail from external mailboxes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
