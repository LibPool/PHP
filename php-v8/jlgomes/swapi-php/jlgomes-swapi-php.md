# jlgomes/swapi-php

> 标签: client, http, http client, rest, swapi

## 简介

Projeto utilizado para simplificar a utilização da API do Starwars(SWAPI), utilizando pela url ou entidade+id

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
