# yiisoft/jquery-pjax

> 标签: PHP

## 简介

pushState + ajax = pjax, a forked maintainted by the Yii Framework core developers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
