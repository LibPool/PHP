# yiisoft/input-http

> 标签: dto, input, mapper, mapping, psr-7, request, yii3

## 简介

Maps data from PSR-7 HTTP request to PHP DTO representing user input.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
