# contenir-extension/navigation

> 标签: contenir, contenir-extension, menu, navigation

## 简介

Managed site navigation for Contenir CMS: the Navigation section of Site Pages, where editors build, publish and restore the site's menus, over contenir/contenir-navigation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
