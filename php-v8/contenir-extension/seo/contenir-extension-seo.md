# contenir-extension/seo

> 标签: JSON-LD, Sitemap, contenir, contenir-extension, robots, seo

## 简介

The SEO add-on for Contenir CMS: page titles, share defaults, hiding copies from search engines, site verification, the site's owner as JSON-LD, the XML sitemap and robots.txt.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
