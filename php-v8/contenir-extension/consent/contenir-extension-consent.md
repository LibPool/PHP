# contenir-extension/consent

> 标签: consent, consent-mode, contenir, contenir-extension, cookie-consent, gdpr

## 简介

The Consent add-on for Contenir CMS: a cookie banner and preferences, regional modes, Global Privacy Control, Google Consent Mode v2 and script gating for every add-on's scripts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
