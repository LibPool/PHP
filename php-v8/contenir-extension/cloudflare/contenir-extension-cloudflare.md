# contenir-extension/cloudflare

> 标签: cache, cdn, cloudflare, contenir, contenir-extension, purge

## 简介

The Cloudflare add-on for Contenir CMS: purges Cloudflare's cache when content and files change, with an API token, a connection test, Purge everything and Purge URLs, and a log of every purge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
