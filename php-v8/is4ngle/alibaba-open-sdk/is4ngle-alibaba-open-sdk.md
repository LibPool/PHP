# is4ngle/alibaba-open-sdk

> 标签: PHP

## 简介

Framework-agnostic PHP SDK for 1688 Open Platform (AOP param2 gateway client + message push: HTTP callback & WebSocket)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
