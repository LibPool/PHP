# n9c/typo3-monitor

> 标签: TYPO3 CMS, extension, monitoring, security, typo3, vulnerabilities

## 简介

N9C Inside Monitor - meldet sicherheitsrelevante Kennzahlen dieser TYPO3-Instanz (nur Zahlen und Flags, keine personenbezogenen Daten) an den N9C Monitoring-Dienst. Kostenloses Konto: https://dashboard.n9c.io/dashboard/register

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
