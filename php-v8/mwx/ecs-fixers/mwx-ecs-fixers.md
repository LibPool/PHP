# mwx/ecs-fixers

> 标签: PHP

## 简介

Custom php-cs-fixer fixers for the metaworx code style: control-structure braces, extends/implements wrapping, section comments, ternaries

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
