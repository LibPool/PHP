# athoscommerce/magento2-feed-parallel

> 标签: athoscommerce, feed, magento, magento2, magento2-module, parallel

## 简介

Optional add-on for the AthosCommerce Magento 2 connector that generates product feeds using parallel page workers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
