# hmuenzer/contao-timefield

> 标签: Time Field, contao, jquery, timepicker

## 简介

Frontend text field with timepicker for Contao Open Source CMS (uses jQuery)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
