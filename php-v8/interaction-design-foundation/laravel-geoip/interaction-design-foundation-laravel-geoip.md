# interaction-design-foundation/laravel-geoip

> 标签: IP API, geographical, geoip, geolocation, infoDB, laravel, location

## 简介

Support for multiple Geographical Location services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
