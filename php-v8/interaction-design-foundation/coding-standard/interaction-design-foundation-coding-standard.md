# interaction-design-foundation/coding-standard

> 标签: PHP

## 简介

IxDF coding standard: PHP_CodeSniffer rules and shared PHP-CS-Fixer configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
