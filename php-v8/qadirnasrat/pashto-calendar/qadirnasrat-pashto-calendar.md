# qadirnasrat/pashto-calendar

> 标签: Jalali, afghanistan, alpinejs, calendar, laravel, pashto, solar-hijri, tailwind

## 简介

A Laravel package for Pashto Solar Hijri calendar with events, holidays, localization, RTL support, and offline-ready assets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
