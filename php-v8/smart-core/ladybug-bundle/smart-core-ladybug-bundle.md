# smart-core/ladybug-bundle

> 标签: dump, ladybug, tree, twig

## 简介

Symfony2 bundle for Ladybug library (Simple and Extensible PHP Dumper)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
