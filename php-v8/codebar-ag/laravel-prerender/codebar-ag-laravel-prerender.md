# codebar-ag/laravel-prerender

> 标签: codebar-ag, laravel, prerender

## 简介

Laravel middleware for prerendering javascript-rendered pages on the fly for SEO

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
