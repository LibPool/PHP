# verbb/consume

> 标签: Craft, cms, consume, craft-plugin, craftcms

## 简介

Create HTTP requests in your Twig templates to consume JSON, XML or CSV content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
