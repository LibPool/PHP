# verbb/wishlist

> 标签: Craft, cms, craft-plugin, craftcms, wishlist

## 简介

Allow users to create lists to store favourite entries, save products in a wishlist and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
