# verbb/commerce-payflow

> 标签: Craft, cms, commerce, craft-plugin, craftcms, omnipay, payflow, paypal

## 简介

PayPal Payflow payment gateway plugin for Craft Commerce.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
