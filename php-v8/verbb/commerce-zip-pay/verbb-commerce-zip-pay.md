# verbb/commerce-zip-pay

> 标签: Craft, cms, commerce, craft-plugin, craftcms, omnipay, zip-pay, zipPay

## 简介

Zip Pay payment gateway plugin for Craft Commerce.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
