# verbb/icon-picker

> 标签: Craft, cms, craft-plugin, craftcms, icon-picker

## 简介

A slick field to pick icons from. Supports SVGs, Sprites, Webfonts, Font Awesome and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
