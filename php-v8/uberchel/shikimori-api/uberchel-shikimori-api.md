# uberchel/shikimori-api

> 标签: Shikimori parser, ShikimoriAPI, anime, php, shikimori api

## 简介

Shikimori API, searching and getting information by ID or name

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
