# rafaeldms/my-cropper

> 标签: image cache, image crop, image thumb, rafaeldms, thumbnails jpg, thumbnails png, thumbnails webp, upload, webp converter

## 简介

It is an easy and simple PHP image cropper and thumbnail cache manager based on RafaelDms Cropper by Robson V. Leite altered for Rafael D. Ferreira.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
