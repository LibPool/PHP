# yireo/magento2-linkpreload

> 标签: composer-installer, magento

## 简介

Magento 2 extension to set HTTP Link headers for primary resources to allow for HTTP/2 preloading

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
