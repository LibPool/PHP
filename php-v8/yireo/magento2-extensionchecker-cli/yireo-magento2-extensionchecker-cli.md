# yireo/magento2-extensionchecker-cli

> 标签: composer-installer, magento

## 简介

Add-on to Yireo_ExtensionChecker to run standalone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
