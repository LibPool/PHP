# yireo/magento2-webp2

> 标签: Yireo, composer-installer, exception, magento, magento 2

## 简介

Magento 2 module to add WebP support to the Magento frontend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
