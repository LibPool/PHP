# tystr/sendgrid-bundle

> 标签: email, sendgrid

## 简介

A bundle for integrating the sendgrid php library into the Symfony2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
