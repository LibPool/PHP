# everydatastore/everydefaultfolder

> 标签: PHP

## 简介

This is a submodule of the EveryDataStore ECM project. The EveryDefaultFolder app allows automatic creation of folder trees for RecordSetItems.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
