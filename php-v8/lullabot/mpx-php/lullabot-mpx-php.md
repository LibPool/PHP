# lullabot/mpx-php

> 标签: The Platform, mpx

## 简介

A PHP library for accessing and interacting with data MPX services from ThePlatform (mpx.theplatform.com).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
