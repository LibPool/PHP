> 标签: cfdi, factura-com, facturacion-electronica, facturaonline, laravel, mexico, php, sat

## 简介

Cliente PHP para consumir la API de FacturaOnline (CFDI 4.0)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
