# abbotton/dcat-infinity-select

> 标签: dcat-admin, extension

## 简介

基于Dcat Admin开发的无限级联动Select组件，主要解决不确定层级的树形数据的操作问题。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
