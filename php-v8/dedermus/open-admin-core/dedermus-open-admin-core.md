# dedermus/open-admin-core

> 标签: admin, form, free, grid, laravel, open, open-admin

## 简介

open-admin-core. Open-source Laravel Admin panel. No pro or paid package, free & open. Based on laravel-admin, with special thanks to z-song

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
