# qbcloud/laravel-cloudflare

> 标签: cloudflare, dns, domain, laravel, website

## 简介

A Laravel extension package for managing Cloudflare websites and domain names.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
