# scripturadesign/tailwindcss-laravel-preset

> 标签: laravel, preset, tailwind, tailwindcss

## 简介

Laravel >5.7.x Front-end preset for tailwindcss

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
