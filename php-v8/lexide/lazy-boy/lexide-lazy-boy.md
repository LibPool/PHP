# lexide/lazy-boy

> 标签: PHP

## 简介

A skeleton REST API application, using Slim and Syringe with support for Symfony Console, AWS Lambda and ApiGateway

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
