# maplephp/dto

> 标签: array, collection, darn-tidy-object, data-object, data-transfer-object, date, dom, dto, immutable, number, string, transform, travsers, utility

## 简介

DTO library in PHP provides benefits such as encapsulating data, enforcing immutability and facilitating data transformation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
