# maplephp/maplephp

> 标签: di, framework, mvc, php, psr

## 简介

MaplePHP is a high performance PHP framework built on PSR standards and modern best practices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://maplephp.github.io/maplephp/
- 源码仓库：https://github.com/maplephp/maplephp.git
- Packagist 页面：https://packagist.org/packages/maplephp%2Fmaplephp

## 获取地址

- Composer 安装：`composer require maplephp/maplephp`

- 许可证：Apache-2.0
- PHP 要求：>=8.2
