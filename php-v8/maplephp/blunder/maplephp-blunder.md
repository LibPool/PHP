# maplephp/blunder

> 标签: blunder, debugging-tool, error, error-handling, error-management, error-presentation, php, php-errors, pretty-error-interface

## 简介

Blunder is a well-designed PHP error handling framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
