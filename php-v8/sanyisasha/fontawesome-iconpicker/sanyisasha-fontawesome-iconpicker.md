# sanyisasha/fontawesome-iconpicker

> 标签: FontAwesome, bootstrap, iconpicker, picker, popover

## 简介

Font Awesome Icon Picker plugin for Twitter Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
