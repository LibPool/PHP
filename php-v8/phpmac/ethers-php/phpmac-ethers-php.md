# phpmac/ethers-php

> 标签: blockchain, ethereum, ethers, evm, smart-contract, web3

## 简介

PHP SDK for Ethereum, inspired by ethers.js v6

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
