# communitychair1/hv-client-lib

> 标签: healthvault, xml

## 简介

Easy to use lightweight PHP library to connect to Microsoft HealthVault.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
