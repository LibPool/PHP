# wubinworks/module-injecthead

> 标签: PHP

## 简介

A Magento 2 module that injects scripts and css to HTML <head> element. Users can choose which page they want to inject by specifying conditions including URI pattern. This module makes use of magento cache and browser local storage to achieve best performance.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
