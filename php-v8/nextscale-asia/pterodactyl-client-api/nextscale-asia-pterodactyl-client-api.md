# nextscale-asia/pterodactyl-client-api

> 标签: api-addon, api-key-management, client-api, egg-management, egg-variables, free-allocation, laravel, pterodactyl, server-transfer

## 简介

Application API endpoints for managing users' account API keys, listing free allocations, transferring servers through a relay, managing database hosts, nests and eggs in Pterodactyl Panel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
