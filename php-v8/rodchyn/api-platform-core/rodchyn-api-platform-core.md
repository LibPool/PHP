# rodchyn/api-platform-core

> 标签: Hydra, JSON-LD, api, graphql, hal, jsonapi, openapi, rest, swagger

## 简介

Build a fully-featured hypermedia or GraphQL API in minutes!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
