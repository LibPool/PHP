# varmtone/baidu-ai-sdk

> 标签: PHP

## 简介

百度Ai开放平台语音识别、合成 RESTful API PHP SDK，基于RESTful API-v1.6.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
