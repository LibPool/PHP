# halfpastfouram/zend-headminifier

> 标签: compress, minify, php, script, style, zend

## 简介

ZF3 module for minifying head scripts and head links using matthiasmullie/minify

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
