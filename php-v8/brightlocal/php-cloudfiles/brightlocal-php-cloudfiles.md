# brightlocal/php-cloudfiles

> 标签: Cloud Files, RSCF, php, rackspace

## 简介

PHP language bindings for Cloud Files API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
