# dregs/dregs-sdk

> 标签: Abuse, bot-detection, dregs, fraud, fraud-detection, risk-scoring

## 简介

PHP SDK for Dregs, the fraud and abuse scoring service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
