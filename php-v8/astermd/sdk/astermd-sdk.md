# astermd/sdk

> 标签: API-Client, astermd, healthcare, psr-18, psr-7, sdk, telehealth

## 简介

Official PHP SDK for the AsterMD order-flow API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
