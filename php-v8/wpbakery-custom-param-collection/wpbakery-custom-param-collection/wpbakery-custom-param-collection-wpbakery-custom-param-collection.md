# wpbakery-custom-param-collection/wpbakery-custom-param-collection

> 标签: PHP

## 简介

Collection of WPBakery custom params for element edit modal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
