# maniyatech/magento2-delete-orders

> 标签: PHP

## 简介

Easily delete Magento 2 orders via mass actions, individual view page, or command line.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
