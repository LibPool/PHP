# cita/image-cropper

> 标签: cropper tool, cropperjs, image cropper, silverstripe image cropper

## 简介

CitaNZ's image cropper for SilverStripe 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
