# cruide/starline-openapi-laravel

> 标签: api, laravel, slid, starline, telematics

## 简介

Laravel client for the StarLine OpenAPI (SLID auth, device state & remote control)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
