# cruide/php-daemon-abstract

> 标签: PHP

## 简介

Abstract PHP daemon base class for Unix/Linux (requires pcntl, posix). Fork, detach, PID management, signal handling, log rotation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
