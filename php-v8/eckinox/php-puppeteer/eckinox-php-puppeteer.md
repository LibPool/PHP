# eckinox/php-puppeteer

> 标签: pdf, php, puppeteer, screenshot

## 简介

PHP Wrapper for Google Chrome Puppeteer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
