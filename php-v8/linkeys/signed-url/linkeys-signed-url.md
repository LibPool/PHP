# linkeys/signed-url

> 标签: expire, laravel, link, linkeys, signed, single use, url

## 简介

Enhanced signed URLs for Laravel, including attaching data, click limits and expiry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
