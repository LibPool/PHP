# karelialabs/statamic-conversions

> 标签: UTM, conversions api, facebook capi, fbclid, ga4, gclid, measurement protocol, meta pixel, server-side tracking, statamic, statamic-addon, tiktok events api

## 简介

Server-side conversion tracking for Statamic: send form leads, sign-ups and orders to the Meta Conversions API, Google Analytics 4 and TikTok, with consent and click IDs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
