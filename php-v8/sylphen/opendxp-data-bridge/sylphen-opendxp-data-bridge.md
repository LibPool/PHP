# sylphen/opendxp-data-bridge

> 标签: PHP

## 简介

Sylphen Data Bridge for OpenDXP (based on Blackbit Data Director 3.10.4, adapted for OpenDXP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
