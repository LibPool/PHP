# getfaultline/faultline-php

> 标签: error-tracking, exceptions, faultline, laravel, monitoring, psr-15, sdk

## 简介

PHP SDK for Faultline error tracking, with a Laravel integration and a PSR-15 middleware

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
