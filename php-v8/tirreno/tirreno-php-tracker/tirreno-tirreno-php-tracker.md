# tirreno/tirreno-php-tracker

> 标签: analytics, antispam, application-monitoring, audit-trail, bot-detection, fraud-detection, monitoring, tirreno

## 简介

PHP client for tirreno security analytics API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
