# emporiqa/shopware-plugin

> 标签: ai, cart, chat, ecommerce, emporiqa, shopware, shopware-plugin, webhook

## 简介

Integrates your Shopware store with the Emporiqa chat assistant.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
