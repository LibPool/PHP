# emporiqa/sylius-plugin

> 标签: ai, cart, chat, ecommerce, emporiqa, sylius, sylius-plugin, webhook

## 简介

Integrates Sylius with Emporiqa chat assistant.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
