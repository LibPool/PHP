# w360/secure-data

> 标签: secure-data, w360

## 简介

Library to Encrypt Database Fields in Mysql using Advanced Encryption Standard (AES) and Data Encryption Standard (DES)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
