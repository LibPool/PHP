# apihub-cdc/audit-firma-simulacion-client-php

> 标签: api, apihub, php, sdk

## 简介

Esta API simula la sustitución de la firma autógrafa para sustentar la autorización por medio de NIP, huella digital o dicio.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
