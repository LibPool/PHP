# levmyshkin/splide

> 标签: canvas, carousel, drupal, slider, slideshow

## 简介

Lightweight and accessible accordion module with an extensible API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
