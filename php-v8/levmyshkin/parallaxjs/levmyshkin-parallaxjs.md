# levmyshkin/parallaxjs

> 标签: EBT, drupal, jquery, parallax.js, vanilla

## 简介

Parallax.js plugin as drupal-library - no dependencies, jQuery optional. Fork from pixelcog/parallax.js.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
