# levmyshkin/dreadmore

> 标签: PHP

## 简介

The plugin for collapsing and expanding long blocks of text. You can DISABLE it using CSS!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
