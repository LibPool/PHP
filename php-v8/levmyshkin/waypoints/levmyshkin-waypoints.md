# levmyshkin/waypoints

> 标签: EBT, drupal, jquery, scroll, sticky, vanilla, waypoints

## 简介

Waypoints is a library that makes it easy to execute a function whenever you scroll to an element - no dependencies, jQuery optional.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
