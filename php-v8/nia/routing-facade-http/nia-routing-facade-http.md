# nia/routing-facade-http

> 标签: Simple, facade, http, https, nia, request, response, rest, router, routing

## 简介

HTTP routing facade to simply add HTTP routes to a given router.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
