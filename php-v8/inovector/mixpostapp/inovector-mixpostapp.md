# inovector/mixpostapp

> 标签: inovector, mixpost, mixpost-lite

## 简介

Standalone application with the Laravel Package of Mixpost Lite pre-installed and configured

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
