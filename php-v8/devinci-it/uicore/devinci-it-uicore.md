# devinci-it/uicore

> 标签: PHP

## 简介

The composer_core_ui library simplifies the creation of interactive user interfaces for web applications with a rich feature set and modular architecture.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
