# cafali-com/laravel-openpay

> 标签: OpenPay, bbva, cafali, laravel, mexico, payments

## 简介

A Laravel package for OpenPay (BBVA) payment gateway integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
