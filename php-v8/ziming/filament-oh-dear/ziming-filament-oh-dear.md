# ziming/filament-oh-dear

> 标签: filament, filament-plugin, laravel, monitoring, oh-dear

## 简介

A read-only Filament 4/5 panel plugin for Oh Dear monitor insights.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
