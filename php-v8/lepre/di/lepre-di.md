# lepre/di

> 标签: PSR-11, container, dependency injection, dependency injection container, di, di container, dic

## 简介

A simple Dependency Injection Container, PSR-11 compliant.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
