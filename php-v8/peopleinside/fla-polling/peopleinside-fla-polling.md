# peopleinside/fla-polling

> 标签: PHP

## 简介

Lightweight real-time polling for Flarum 2.0 - No WebSocket, No SSH required

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
