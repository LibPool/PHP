# cryptothree/bitcoin-bch-addon

> 标签: bcash, bch, bitcoin cash, cashaddr

## 简介

Bridge to bitwasp/bitcoin for bch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
