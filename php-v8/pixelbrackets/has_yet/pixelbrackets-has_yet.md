# pixelbrackets/has_yet

> 标签: PHP

## 简介

Has … yet? Script to set up a Twitter bot tweeting answers to important questions like “Has something happend yet?”

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
