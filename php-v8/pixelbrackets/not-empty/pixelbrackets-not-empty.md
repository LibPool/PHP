# pixelbrackets/not-empty

> 标签: PHP

## 简介

not empty() - Adds methods to determine whether a variable is blank or present - Inspired by Ruby on Rails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
