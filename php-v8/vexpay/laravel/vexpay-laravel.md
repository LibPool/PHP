# vexpay/laravel

> 标签: c2p, checkout, laravel, pago movil, payments, venezuela, vexpay, webhooks

## 简介

Official Laravel integration for VEXPay: verified webhooks as events, Billable checkouts, marketplace payouts, and test fakes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
