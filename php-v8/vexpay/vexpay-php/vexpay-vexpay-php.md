# vexpay/vexpay-php

> 标签: c2p, checkout, pago movil, payments, sdk, venezuela, vexpay, webhooks

## 简介

Official PHP server SDK for the VEXPay payments API (Venezuela): C2P, card, Pago Móvil, checkout sessions, merchants, payouts and signed webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
