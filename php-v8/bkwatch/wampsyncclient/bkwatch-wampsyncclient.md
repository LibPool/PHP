# bkwatch/wampsyncclient

> 标签: WAMP, rpc

## 简介

Synchronous (blocking) PHP client for WAMP protocol implementing Caller and Publisher roles

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
