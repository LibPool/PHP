# cartograph/minecraft-nbt

> 标签: NBT, codec, minecraft, named-binary-tag, parser, snbt

## 简介

Read, write, and manipulate Minecraft's NBT (Named Binary Tag) format; both binary and SNBT.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
