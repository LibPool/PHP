# ayowande/cpanel-api

> 标签: PHP

## 简介

A lightweight PHP client for interacting with cPanel's API, providing methods for common tasks like managing domains, emails, and server resources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
