# phpolygon/php-vio

> 标签: Gamedev, Rendering, Vulkan, audio, extension, gpu, metal, opengl, video

## 简介

PHP extension for GPU rendering (OpenGL, Vulkan, Metal), audio, video recording, streaming, and input

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
