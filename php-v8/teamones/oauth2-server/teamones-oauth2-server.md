# teamones/oauth2-server

> 标签: auth, oauth, oauth2

## 简介

OAuth2 Server based on upstream v1.13.0, maintained for PHP 8.1–8.5

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
