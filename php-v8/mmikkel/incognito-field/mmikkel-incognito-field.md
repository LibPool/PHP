# mmikkel/incognito-field

> 标签: Craft, cms, craft-plugin, craftcms, incognito field

## 简介

PlainText drop-in replacement that can be set to disabled, hidden or readonly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
