# igorsgm/tibia-data-api

> 标签: api, data, igorsgm, tibia, tibia-data, tibiadata

## 简介

A library that allows you to access TibiaData API from your Laravel application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
