# tomaszboloz/laravel-updater

> 标签: auto-update, deployment, filament, filament-plugin, github, github-releases, laravel, migrations, self-update, updater

## 简介

Self-update Laravel applications from GitHub releases (public and private repositories): code, Composer, migrations, npm build and cache clearing - from the Filament admin panel or Artisan.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
