# filipac/mobilpay

> 标签: PHP

## 简介

Use MobilePay classes with composer PSR-0 autoloading. Just a mirror with composer wrapping.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
