# mostlyserious/craft-imgix-picture

> 标签: Craft, craft-plugin, craftcms, imgix, picture

## 简介

A Twig helper to generate picture tags from a set of imgix transforms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
