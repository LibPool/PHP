# hawk/thinkphp-addons

> 标签: PHP

## 简介

addons package for thinkphp5.1.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://gitee.com/fallcat/thinkphp-addons.git
- Packagist 页面：https://packagist.org/packages/hawk%2Fthinkphp-addons

## 历史版本号

- 当前版本：2.1.8

- 2.1.8

## 获取地址

- Composer 安装：`composer require hawk/thinkphp-addons`
- Packagist 仓库：https://repo.packagist.org/p2/hawk/thinkphp-addons.json
- 许可证：Apache-2.0
- PHP 要求：>=5.6.0
