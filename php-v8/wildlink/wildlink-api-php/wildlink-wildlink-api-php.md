# wildlink/wildlink-api-php

> 标签: PHP

## 简介

A simple PHP interface for the Wildlink API (learn more at https://www.wildlink.me/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
