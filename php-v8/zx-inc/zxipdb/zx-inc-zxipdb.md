# zx-inc/zxipdb

> 标签: PHP

## 简介

IPv4/IPv6 offline address database.IPv4/IPv6双栈地址离线数据库。IPv4 by 纯真网络，IPv6 by ZX Inc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
