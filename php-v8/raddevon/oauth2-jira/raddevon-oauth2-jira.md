# raddevon/oauth2-jira

> 标签: authorisation, authorization, client, jira, oauth, oauth2

## 简介

Jira OAuth 2.0 support for the PHP League's OAuth 2.0 Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
