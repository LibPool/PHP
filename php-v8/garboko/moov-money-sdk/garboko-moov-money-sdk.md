# garboko/moov-money-sdk

> 标签: PHP

## 简介

SDK PHP officiel pour l'intégration de l'API de paiement mobile Moov Money Burkina Faso

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
