# bigya/talibphp

> 标签: admin, framework, migrations, mvc, phinx, php

## 简介

talibphp — a simple, efficient PHP framework with Phinx migrations and a built-in admin panel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
