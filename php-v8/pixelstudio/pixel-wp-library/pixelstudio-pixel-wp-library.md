# pixelstudio/pixel-wp-library

> 标签: library, plugin, wordpress

## 简介

Collection of WordPress modules to be used together with pixel-wp-theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
