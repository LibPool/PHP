# invue/tables

> 标签: inertia, invue, laravel, tables, vue

## 简介

Native Vue 3 data table components for the Invue framework, wired to Eloquent via Inertia partial reloads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
