# nasirkhan/laravel-sharekit

> 标签: blade-components, frontend, laravel, share-buttons, share-links, sharekit, sharing, social-share, social-sharing, web-share-api

## 简介

Reusable social sharing Blade components for Laravel with themeable styles, metadata auto-detection, and page-scoped assets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
