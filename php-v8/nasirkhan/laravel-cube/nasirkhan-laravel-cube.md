# nasirkhan/laravel-cube

> 标签: Forms, alpine, blade-components, components, cube, flowbite, laravel, navigation, tailwind, ui-components

## 简介

Anonymous Blade component library for Laravel applications — Tailwind CSS (Flowbite) UI, forms, navigation, and backend scaffolding.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
