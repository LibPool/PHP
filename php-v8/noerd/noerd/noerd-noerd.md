# noerd/noerd

> 标签: admin, crud, framework, laravel, livewire, multi-tenant, yaml

## 简介

YAML-driven Livewire framework for multi-tenant Laravel applications: generic list, detail and page components, modals, themes, tenant apps and install/update tooling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
