# noerd/notifications

> 标签: in-app, laravel, livewire, multi-tenant, noerd, notifications

## 简介

In-app notifications for the noerd framework: a bell in the top bar with an unread badge, and one API every module sends through — a service call or a Laravel notification channel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
