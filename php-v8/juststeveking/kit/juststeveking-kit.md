# juststeveking/kit

> 标签: api, laravel, rfc9457, sanctum, starter-kit

## 简介

Opinionated Laravel API starter kit: token authentication, standards-compliant HTTP via api-toolbox, and contract-tested OpenAPI docs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
