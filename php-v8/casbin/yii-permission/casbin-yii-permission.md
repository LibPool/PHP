# casbin/yii-permission

> 标签: abac, acl, casbin, casbin-adapter, database, permission, rbac, yii

## 简介

Use Casbin in Yii3 PHP Framework, Casbin is a powerful and efficient open-source access control library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
