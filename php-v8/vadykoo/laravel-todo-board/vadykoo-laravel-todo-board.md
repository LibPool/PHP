# vadykoo/laravel-todo-board

> 标签: Tasks, board, kanban, laravel, todo

## 简介

A standalone Laravel kanban-style todo board with assignees, due dates, images, and drag-and-drop.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
