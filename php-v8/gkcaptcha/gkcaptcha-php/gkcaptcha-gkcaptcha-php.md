# gkcaptcha/gkcaptcha-php

> 标签: bot-protection, captcha, gatekeeper, verification

## 简介

PHP SDK for gkCAPTCHA token verification. Zero Composer runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
