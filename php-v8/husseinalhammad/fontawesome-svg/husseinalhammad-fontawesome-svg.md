# husseinalhammad/fontawesome-svg

> 标签: FontAwesome, svg

## 简介

PHP class to add Font Awesome 5+'s SVG icons inline without Javascript.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
