# byfareska/swoole-server-bundle

> 标签: bundle, http-server, long-running, performance, swoole, symfony, worker

## 简介

Long-running Swoole HTTP server for Symfony applications (PHP-FPM-like worker model, no coroutines)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
