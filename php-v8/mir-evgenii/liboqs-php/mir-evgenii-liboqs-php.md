# mir-evgenii/liboqs-php

> 标签: PHP

## 简介

Post-quantum cryptography (ML-KEM, ML-DSA) for PHP via FFI bindings to liboqs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
