# offdev/bandit

> 标签: armed, bandit, multi, offdev, test, testing

## 简介

An A/B/x testing algorithm written in PHP by implementing the solution to the multi armed bandit problem

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
