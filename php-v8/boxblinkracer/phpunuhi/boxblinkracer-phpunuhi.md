# boxblinkracer/phpunuhi

> 标签: Developer tools, automation, deepl, grammar-checker, language, localization, openai, shopware, spell-checker, translation

## 简介

Easy tool to work with translation files for validation, exports, imports and more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
