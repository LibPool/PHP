# jsoizo/php-result

> 标签: PHPStan, error-handling, functional-programming, result, type-safe

## 简介

A type-safe Result type for PHP 8.1+ with PHPStan support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
