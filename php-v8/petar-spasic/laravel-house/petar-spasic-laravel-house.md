# petar-spasic/laravel-house

> 标签: SvelteKit, agents, boost, caddy, claude-code, docker, frankenphp, git, htmx, kanban, laravel, skills, validation, worktree, zod

## 简介

House skills for Laravel projects, installed into Claude Code by Laravel Boost: project setup with per-layer CLAUDE.md rules, Docker hosting behind Caddy, a git-backed kanban board with worktree stacks and Claude Code agents, and the validation:export command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
