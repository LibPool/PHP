# rebuy/ean-isbn-library

> 标签: ISBN, conversion, ean, parser, parsing, validation

## 简介

A PHP library for EAN and ISBN validation and conversion

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
