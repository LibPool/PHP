# onelap/laravel-resilience-middleware

> 标签: circuit-breaker, fault-tolerance, laravel, microservices, middleware, rate-limiting, reliability, resilience, service-degradation

## 简介

Laravel弹性中间件包 - 提供限流、熔断器、服务降级等微服务保护功能

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
