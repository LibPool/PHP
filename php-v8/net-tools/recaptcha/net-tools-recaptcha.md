# net-tools/recaptcha

> 标签: Abuse, captcha, recaptcha, spam

## 简介

Client library for reCAPTCHA, a free service that protects websites from spam and abuse.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
