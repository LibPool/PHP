# sarkis-sh/spray-aop

> 标签: aop, aspect, attributes, laravel, proxy, spray

## 简介

A lightweight, high-performance Aspect-Oriented Programming (AOP) framework for Laravel using PHP 8.2+ Attributes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
