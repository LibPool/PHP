# nietocjr/laravel-chatwork-connect

> 标签: chatwork, laravel, laravel-chatwork-connect, nietocjr

## 简介

Seamless integration of Chatwork API with Laravel for easy messaging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
