# fortawesome/font-awesome

> 标签: FontAwesome, awesome, bootstrap, font, icon, svg

## 简介

The iconic font, CSS, and SVG framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
