# fortawesome/wordpress-fontawesome

> 标签: font awesome, font-awesome, icon, icons, svg, webfont

## 简介

Official Font Awesome WordPress plugin composer package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
