# sinemacula/laravel-resource-exporter

> 标签: api, export, laravel, resource, sine macula

## 简介

Content-negotiated Laravel API resource exports to CSV, TSV, XLSX, XML, JSON, and NDJSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
