# sinemacula/coding-standards-laravel

> 标签: PHP

## 简介

Laravel-specific coding standards, static-analysis rules, and code-quality tooling for Sine Macula's Laravel repositories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
