# cesnet/simplesamlphp-module-totp

> 标签: PHP

## 简介

A simple TOTP module for SimpleSAMLphp, based on SimpleTOTP, rewritten using the TwoFactorAuth library by RobThree

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
