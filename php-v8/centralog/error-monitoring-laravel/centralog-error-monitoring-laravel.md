# centralog/error-monitoring-laravel

> 标签: centralog, error-monitoring, laravel

## 简介

Laravel SDK for Centralog error monitoring. Captures exceptions and sends a copy to your Centralog platform without breaking your app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
