# bornfree/tactician-doctrine-domain-events

> 标签: PHP

## 简介

The bridge to provide Domain Events handling with Tactician command bus and Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
