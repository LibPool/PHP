# joomengine/mcp-client

> 标签: client, joomengine, joomla, mcp, model-context-protocol, stdio

## 简介

Standalone PHP client for database-driven JoomEngine MCP servers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
