# amircandy/litefs

> 标签: directory, file, file-manager, filesystem, lite, php

## 简介

LiteFS is a lightweight, fast, and easy-to-use PHP file system manager library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
