# socialdept/atp-orm

> 标签: Object Relational Mapping, at protocol, atp, bluesky, laravel, orm

## 简介

Eloquent-like ORM for AT Protocol remote records in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
