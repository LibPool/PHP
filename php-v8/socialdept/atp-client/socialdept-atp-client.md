# socialdept/atp-client

> 标签: at-protocol, atproto, bluesky, laravel, oauth, xrpc

## 简介

Type-safe AT Protocol HTTP client with OAuth 2.0 support for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
