# socialdept/tenant-domains

> 标签: ACME, Custom Domains, caddy, dns, laravel, multi-tenancy

## 简介

Custom domains for multi-tenant Laravel apps: ownership, DNS instructions, ACME delegation and certificates

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
