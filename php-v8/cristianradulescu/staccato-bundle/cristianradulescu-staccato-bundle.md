# cristianradulescu/staccato-bundle

> 标签: blog, markdown, static-site-generator, symfony-bundle, twig

## 简介

Symfony bundle that turns Markdown content into a static site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
