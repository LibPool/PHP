# etdsolutions/moment-timezone

> 标签: PHP

## 简介

Shim repository for timezone support for moment.js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://momentjs.com/timezone
- 源码仓库：https://github.com/etd-framework/moment-timezone.git
- Packagist 页面：https://packagist.org/packages/etdsolutions%2Fmoment-timezone
