# yiirocks/toast-bootstrap5

> 标签: bootstrap, bootstrap5, extension, flash, notification, toast, yii, yii3

## 简介

Bootstrap 5 toast notifications backed by Yii3 session flash messages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
