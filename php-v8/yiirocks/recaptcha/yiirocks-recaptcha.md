# yiirocks/recaptcha

> 标签: bot, captcha, extension, recaptcha, spam, validator, widget, yii, yii3

## 简介

Google reCAPTCHA v2 and v3 field + server-side validator for Yii3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
