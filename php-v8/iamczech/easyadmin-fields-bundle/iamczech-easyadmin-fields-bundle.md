# iamczech/easyadmin-fields-bundle

> 标签: symfony-ux

## 简介

Extends basic EasyAdmin fields and works well with AssetMapper and Smyfony 7.4^

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
