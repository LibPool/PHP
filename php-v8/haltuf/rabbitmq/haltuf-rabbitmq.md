# haltuf/rabbitmq

> 标签: AMQP, messaging, nette, php-amqplib, queue, rabbitmq

## 简介

Lightweight RabbitMQ integration for Nette Framework on top of php-amqplib. Seamless switch from the abandoned contributte/rabbitmq.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
