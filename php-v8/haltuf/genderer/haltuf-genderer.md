# haltuf/genderer

> 标签: czech, gender, name, salutation

## 简介

Independent library to detect gender by name in Czech. Also returns 5th grammatical case (vocative) for salutation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
