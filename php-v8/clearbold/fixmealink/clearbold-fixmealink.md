# clearbold/fixmealink

> 标签: Craft, cms, craftcms, obfuscate, twig, url

## 简介

Fix Me a Link is a Craft plugin with link utility functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
