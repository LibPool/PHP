# timclifford/drutiny-clamav-plugin

> 标签: Audit, Drush, clamav, report, security

## 简介

ALGM Drutiny plugin for ClamAV scans.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
