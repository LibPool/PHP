# codeconjure/foxpost-sylius-plugin

> 标签: foxpost, shipping, sylius, sylius-plugin, symfony-ux

## 简介

FoxPost szállítási integráció Syliushoz: csomagfeladás, címke, nyomkövetés.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
