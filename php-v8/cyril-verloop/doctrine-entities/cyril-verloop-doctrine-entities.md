# cyril-verloop/doctrine-entities

> 标签: PHP

## 简介

Some default doctrine entity/fields requiring PHP >=8.2 and Doctrine ORM 3.2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
