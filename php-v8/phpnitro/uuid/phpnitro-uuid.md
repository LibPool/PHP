# phpnitro/uuid

> 标签: PHP

## 简介

PhpNitro's UUID package — RFC 4122 v4/v7 UUID generation, no dependency (Engine\Uuid\*).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
