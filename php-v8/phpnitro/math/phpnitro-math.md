# phpnitro/math

> 标签: PHP

## 简介

PhpNitro's math package — numeric helpers, descriptive statistics, exact decimal arithmetic, and unit conversions (Engine\Math\*).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
