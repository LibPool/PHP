# phpnitro/cloudinary

> 标签: PHP

## 简介

PhpNitro's Cloudinary package — image upload/transform/delete via REST, no SDK dependency (Engine\Cloudinary\*).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
