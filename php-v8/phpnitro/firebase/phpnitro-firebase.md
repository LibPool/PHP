# phpnitro/firebase

> 标签: PHP

## 简介

PhpNitro's Firebase package — a plain Firebase Auth REST client plus Cloud Functions calls (Engine\Firebase\*), no Firebase SDK dependency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
