# phpnitro/geocoding

> 标签: PHP

## 简介

PhpNitro's geocoding package — forward/reverse geocoding via OpenStreetMap Nominatim, no API key (Engine\Geocoding\*).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
