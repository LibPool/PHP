# ivan-matthews/geo-package

> 标签: PHP

## 简介

PHP-массивы GEO-данных. Это для меня, чтоб не лить по 150МБ каждый раз, и не зипать по 40МБ.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
