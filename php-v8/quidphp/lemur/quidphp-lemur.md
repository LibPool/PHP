# quidphp/lemur

> 标签: lemur-cms, php-cms, php-framework, quid, quidphp

## 简介

LemurCMS, a content management system built on top of the QuidPHP framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
