# roteiro-testes/adianti-test-kit

> 标签: adianti, crud, filter, tests

## 简介

Kit para testar formularios e consultas em projetos Adianti (filtros, insercao, alteracao e exclusao).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
