# voicetel/sdk

> 标签: 10dlc, did, e911, mms, sdk, sms, telephony, voicetel, voip

## 简介

Official PHP SDK for the VoiceTel REST API (v2.2.10).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
