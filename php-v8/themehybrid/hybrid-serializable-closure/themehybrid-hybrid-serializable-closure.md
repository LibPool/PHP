# themehybrid/hybrid-serializable-closure

> 标签: closure, hybrid-core, serializable, wordpress

## 简介

Hybrid Core Serializable Closure provides an easy and secure way to serialize closures in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
