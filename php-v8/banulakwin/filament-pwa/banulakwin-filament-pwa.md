# banulakwin/filament-pwa

> 标签: admin, filament, laravel, pwa, web-push

## 简介

Filament PWA, web push, mobile bottom nav styling, and global search modal integration for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
