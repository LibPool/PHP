# janeklb/json-char-input-reader

> 标签: chunk, json, reader, stream

## 简介

Read a JSON stream and execute callbacks whenever complete JSON chunks are parsed

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
