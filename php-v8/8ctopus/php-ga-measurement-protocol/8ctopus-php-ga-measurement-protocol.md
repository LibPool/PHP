# 8ctopus/php-ga-measurement-protocol

> 标签: PHP

## 简介

Send data to Google Analytics from the server using PHP. This library fully implements GA measurement protocol.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
