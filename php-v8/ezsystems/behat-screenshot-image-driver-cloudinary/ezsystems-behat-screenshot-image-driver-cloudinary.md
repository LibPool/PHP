# ezsystems/behat-screenshot-image-driver-cloudinary

> 标签: BDD, Behat, TDD, behat-screenshot

## 简介

Cloudinary image driver for bex/behat-screenshot behat extension

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
