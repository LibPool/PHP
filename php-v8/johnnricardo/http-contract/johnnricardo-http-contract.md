# johnnricardo/http-contract

> 标签: PHP

## 简介

The HTTP contract applying the OTAKU philosophy and following the PSR-12, PSR-7, PSR-18, and PSR-14.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
