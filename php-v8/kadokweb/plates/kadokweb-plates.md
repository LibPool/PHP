# kadokweb/plates

> 标签: KadokWeb, package, templates, templating, views

## 简介

Plates, the native PHP template system that's fast, easy to use and easy to extend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
