# cardvs/oauth2-server-storage

> 标签: database, oauth, oauth2, server, storage, zetacomponents

## 简介

Storage oauth2 server implementation for league/oauth2-server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
