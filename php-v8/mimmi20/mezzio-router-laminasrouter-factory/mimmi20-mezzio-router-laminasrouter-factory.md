# mimmi20/mezzio-router-laminasrouter-factory

> 标签: PHP

## 简介

Provides a Factory to set a TranslatorAwareTreeRouteStack for a laminas-router in a Mezzio Application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
