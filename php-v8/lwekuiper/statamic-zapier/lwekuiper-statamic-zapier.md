# lwekuiper/statamic-zapier

> 标签: Forms, statamic, statamic-addon, webhooks, zapier

## 简介

Send Statamic form submissions to Zapier webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
