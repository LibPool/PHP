## 简介

Generate, sign and export FacturaE electronic invoices in PHP 8.2+ — fluent API, XAdES-EPES signing, zero dependencies. Genera y firma facturas electrónicas.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
