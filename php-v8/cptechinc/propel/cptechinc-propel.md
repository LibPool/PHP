# cptechinc/propel

> 标签: Active Record, orm, persistence

## 简介

Propel2 is an open-source Object-Relational Mapping (ORM) for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/cptechinc/Propel.git
