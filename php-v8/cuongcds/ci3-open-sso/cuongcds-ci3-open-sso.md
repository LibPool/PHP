# cuongcds/ci3-open-sso

> 标签: PHP

## 简介

Generic OAuth-style SSO client for CodeIgniter 3 apps: login redirect + callback token exchange, with pluggable redirect-target storage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
