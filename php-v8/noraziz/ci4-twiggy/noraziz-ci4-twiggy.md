# noraziz/ci4-twiggy

> 标签: codeigniter, codeigniter4, library, twig

## 简介

Twig template engine implementation for CodeIgniter 4, forked from https://github.com/edmundask/codeigniter-twiggy.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
