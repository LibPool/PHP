# alexpechkarev/google-geocoder

> 标签: geocoding, google geocoding api, laravel

## 简介

Simple Google Geocoding API v3 wrapper for Laravel 4/5, Slim3 etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
