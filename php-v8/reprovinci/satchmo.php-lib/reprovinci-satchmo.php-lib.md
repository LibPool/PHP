# reprovinci/satchmo.php-lib

> 标签: ajax, file, iframe, javascript, php, satchmo, upload

## 简介

A helper library written in PHP for handling Satchmo form submissions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
