# featherbb/db-layer

> 标签: db-layer, featherbb, idiorm, orm, query builder

## 简介

Idiorm-based FeatherBB Database Layer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
