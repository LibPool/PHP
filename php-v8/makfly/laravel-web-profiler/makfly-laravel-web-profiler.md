# makfly/laravel-web-profiler

> 标签: debug, laravel, performance, profiler, toolbar

## 简介

Symfony-style web profiler for Laravel with inline toolbar and React SPA dashboard

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
