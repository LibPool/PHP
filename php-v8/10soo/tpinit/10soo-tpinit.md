# 10soo/tpinit

> 标签: base-controller, excel, generator, migration, scaffold, thinkphp, thinkphp8

## 简介

ThinkPHP 8.x 脚手架工具：代码生成器 + 基类控制器 + 公共服务库

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
