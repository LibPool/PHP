# cross-solution/yawik

> 标签: ATS, Human Resource, applicant, jobboard, laminas, php, yawik

## 简介

Web based applicant tracking system for managing jobs and applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
