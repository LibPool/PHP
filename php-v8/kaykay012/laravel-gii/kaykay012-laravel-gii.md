# kaykay012/laravel-gii

> 标签: crud, gii, laravel, rules

## 简介

类似于yii2 的Gii工具,可以创建CURD逻辑及验证规则

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
