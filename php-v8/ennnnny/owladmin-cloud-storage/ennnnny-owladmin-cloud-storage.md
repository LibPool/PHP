# ennnnny/owladmin-cloud-storage

> 标签: extension, oss, owl-admin

## 简介

支持 本地，腾讯云、阿里云等OSS云存储功能，支持一键迁移，资源展示等功能。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
