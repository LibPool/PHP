# stackin-io/stackin-php-sdk

> 标签: brazil, e-invoicing, fiscal-document, invoice, nfe, nfse, nota-fiscal, nota-fiscal-eletronica, sefaz

## 简介

Official PHP SDK for the stackin fiscal document API — issue, consult, cancel NF-e and NFS-e.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
