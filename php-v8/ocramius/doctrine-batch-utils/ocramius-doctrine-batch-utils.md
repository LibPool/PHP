# ocramius/doctrine-batch-utils

> 标签: batch processing, doctrine, doctrine2, orm

## 简介

A set of utilities to operate with Doctrine ORM's batch processing functionality

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
