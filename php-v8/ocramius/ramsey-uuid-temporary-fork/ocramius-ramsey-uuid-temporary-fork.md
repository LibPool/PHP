# ocramius/ramsey-uuid-temporary-fork

> 标签: guid, identifier, uuid

## 简介

A PHP library for generating and working with universally unique identifiers (UUIDs).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
