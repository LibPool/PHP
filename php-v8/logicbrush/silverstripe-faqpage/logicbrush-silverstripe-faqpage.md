# logicbrush/silverstripe-faqpage

> 标签: FAQ, silverstripe

## 简介

A module for the SilverStripe CMS which allows you to construct a list of frequently-asked questions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
