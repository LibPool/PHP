# macdanson/jpesa-php-sdk

> 标签: PHP

## 简介

PHP SDK for JPesa API (Credit/Debit GWallet, Transaction lookup, KYC) with optional Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
