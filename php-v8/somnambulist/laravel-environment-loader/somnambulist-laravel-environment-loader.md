# somnambulist/laravel-environment-loader

> 标签: environment, laravel, service provider

## 简介

Deferred loading / dev dependency loading for Laravel 5.X projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
