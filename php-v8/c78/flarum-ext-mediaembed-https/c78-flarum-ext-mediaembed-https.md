# c78/flarum-ext-mediaembed-https

> 标签: acfun, bilibili, embed, ku6, media, mgtv, music, neteasemusic, qq, tucao, tudou, video, youku

## 简介

自动识别第三方网站的媒体（图片、视频、音频）并内嵌到 Flarum 。（https版本）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
