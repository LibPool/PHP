# ffraenz/plurio-net-php

> 标签: Luxembourg, Plurio.net, events

## 简介

Abstraction layer for the XML interface of Plurio.net

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
