# appoly/laravel-bootstrap-4-preset

> 标签: PHP

## 简介

Frontend preset for Bootstrap 4 for Laravel 5.5.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
