# zoreal/oauth2

> 标签: PHP

## 简介

Login with ZOREAL for PHP backends: exchanges the authorization code your frontend received from @zoreal/oauth2-react, verifies the ID token against the provider's JWKS, and reads personal claims from /userinfo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
