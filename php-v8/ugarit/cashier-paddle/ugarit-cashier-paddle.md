# ugarit/cashier-paddle

> 标签: billing, paddle, ugarit

## 简介

Cashier Paddle provides an expressive, fluent interface to Paddle's subscription billing services.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
