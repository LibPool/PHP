# ugarit/reverb

> 标签: WebSockets, real-time, ugarit, websocket

## 简介

Ugarit Reverb provides a real-time WebSocket communication backend for Ugarit applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
