# m2s/laravel-nuxt

> 标签: SPA, laravel, nuxt, nuxtjs, pwa, typescript

## 简介

NuxtJS framework integration for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
