# tomkyle/kurzelinks

> 标签: link shortener, shortener, shortening, url, url shortener

## 简介

Link shortener using the kurzelinks.de API. Supports PSR-6 caches and rate limits.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
