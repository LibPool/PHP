# tomkyle/tabulate

> 标签: array, cli, csv, json, markdown, table, yaml

## 简介

Format 2D arrays as CLI console table, Markdown, CSV, YAML, JSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
