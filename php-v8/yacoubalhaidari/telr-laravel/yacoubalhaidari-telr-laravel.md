# yacoubalhaidari/telr-laravel

> 标签: gateway, invoice, laravel, payment, quicklink, telr, webhook

## 简介

Laravel package for the Telr Payment Gateway: Hosted Payment Page, QuickLinks, Invoicing, Repeat Billing Agreements, Webhooks, and the Service API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
