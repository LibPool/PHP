# xetaio/xetaravel-counts

> 标签: belongsToMany, counts, database, eloquent, laravel, pivot

## 简介

Automatic *_count for Laravel belongsTo and belongsToMany relations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
