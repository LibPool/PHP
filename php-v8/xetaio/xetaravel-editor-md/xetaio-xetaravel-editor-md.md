# xetaio/xetaravel-editor-md

> 标签: editor.md, laravel, laravel-5-package, markdown, wysiwyg

## 简介

A wrapper to use Editor.md with Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
