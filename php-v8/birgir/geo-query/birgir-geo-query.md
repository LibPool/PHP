# birgir/geo-query

> 标签: wordpress

## 简介

Modify the WP_Query to support the geo_query parameter. Uses the Haversine SQL optimization by Ollie Jones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
