# laraarabdev/filament-recordkeeper

> 标签: Audit, activity-log, auditing, filament, filament-plugin, laravel, recordkeeper, rollback

## 简介

Filament 5 admin UI for laraarabdev/recordkeeper — audit resource, before/after diff viewer, timeline, stats widget, and permission-gated rollback.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
