# itholics/oxid-debug-twig

> 标签: OXID, Xdebug, component, debug, eshop, twig

## 简介

Twig extension to help debugging twig templates in OXID eShop 7.0.0+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
