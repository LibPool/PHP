# gilangwinduasmara/laravel-odoo

> 标签: ERP, integration, laravel, odoo, xmlrpc

## 简介

A Laravel package to easily integrate with Odoo via XML-RPC.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
