# gremo/assetic-extra

> 标签: assetic, babel, babeljs, browserify, csso, postcss, sass, scss

## 简介

A collection of extra assetic resources to use with Symfony AsseticBundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
