# zenstruck/resource-bundle

> 标签: admin, administration, crud, resource

## 简介

Provides an easy way to create a RESTful CRUD for your entities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
