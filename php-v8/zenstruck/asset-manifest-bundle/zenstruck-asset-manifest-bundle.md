# zenstruck/asset-manifest-bundle

> 标签: asset, css, frontend, grunt, gulp, javascript, twig

## 简介

Loads an asset manifest to map your assets to dynamic ones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
