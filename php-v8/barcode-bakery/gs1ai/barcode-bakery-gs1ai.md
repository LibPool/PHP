# barcode-bakery/gs1ai

> 标签: ai, bakery, barcode, barcodebakery, code128, generator, gs1, gs1-128

## 简介

Library to support GS1 barcodes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
