# barcode-bakery/barcode-1d

> 标签: CODABAR, Code11, Code93, EAN-13, EAN-8, EAN13, ISBN, MSI, UPC-A, UPC-E, bakery, barcode, barcodebakery, code128, code39, code39extended, ean8, generator, i25, s25, upcext2, upcext5

## 简介

Generates 1D barcodes from a PHP server to a file or HTML document.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
