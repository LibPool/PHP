# tahoelimited/qpush-bundle

> 标签: asynch, aws, bundle, iron mq, pub-sub, push, qpush, symfony

## 简介

Asynchronous processing for Symfony using Push Queues

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
