# xstreamka/yii2-recaptcha-widget

> 标签: captcha, extension, google, recaptcha, widget, yii2

## 简介

Spam check widget for Yii2, based on Google reCAPTCHA API v3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
