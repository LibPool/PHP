# cube-agency/filament-nested-list

> 标签: CubeAgency, filament, filament-nested-list, filament-plugin, laravel, nested-list, nested-set

## 简介

A drag-and-drop nested list form field for Filament, backed by nested sets

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
