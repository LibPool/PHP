# 4rn0/statamic-image-editor

> 标签: WebGL, crop, editor, filters, image, rotate, statamic, statamic-addon

## 简介

Edit images in the Statamic control panel: rotate, straighten, crop, adjust colours, apply filters. Keeps the original, reverts, edits in the browser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
