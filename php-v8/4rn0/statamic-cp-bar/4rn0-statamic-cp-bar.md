# 4rn0/statamic-cp-bar

> 标签: admin-bar, cp-bar, frontend, statamic, statamic-addon, static-caching, toolbar, wordpress

## 简介

WordPress's admin bar, rebuilt for Statamic: edit, add and refresh any page from the front end. No template changes, safe with static caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
