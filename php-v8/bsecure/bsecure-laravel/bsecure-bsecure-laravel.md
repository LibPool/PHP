# bsecure/bsecure-laravel

> 标签: SSO, bsecure, e-commerce, ecommerce, frictionless payment, payment-gateway, single-sign-on, two-step-checkout, universal-checkout, universal-login

## 简介

Pakistan's first universal checkout solution for e-commerce stores built on woocommerce, magento, shopify and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
