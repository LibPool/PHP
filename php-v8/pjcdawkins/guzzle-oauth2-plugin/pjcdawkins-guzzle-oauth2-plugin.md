# pjcdawkins/guzzle-oauth2-plugin

> 标签: PHP

## 简介

An OAuth2 plugin (subscriber) for Guzzle (forked from commerceguys/guzzle-oauth2-plugin)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
