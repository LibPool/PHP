# mnugter/jsonapi-rql-finder-bundle

> 标签: JSON-API, php, restful, symfony

## 简介

The jsonapi-bundle-rql-finder offers an RQL filter syntax for the paknahad/jsonapi-bundle bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
