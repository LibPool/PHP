# tereta/console

> 标签: PSR-11, cli, command, console, psr-3

## 简介

Building console (CLI) applications on PHP 8.2+ with PSR-3 output and a PSR-11 dependency container.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
