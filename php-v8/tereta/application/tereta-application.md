# tereta/application

> 标签: PHP

## 简介

Web application framework for PHP 8.2+ with Swoole, Symfony Cache, PSR-6, PSR-16, PSR-11, PSR-17, PSR-18, PSR-7, PSR-15, PSR-14, PSR-3 and other standards support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
