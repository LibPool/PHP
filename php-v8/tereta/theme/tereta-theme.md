# tereta/theme

> 标签: layout, php, phtml, render, template, template engine, theme, view

## 简介

Template engine for PHP 8.2+: a fluent view builder that renders .phtml templates with meta and data, and resolves nested includes relative to the theme root.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
