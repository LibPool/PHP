# tereta/application-development

> 标签: application, development, tereta

## 简介

Development tools for Tereta Application Framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://tereta.dev/library/application-development
- 源码仓库：https://gitlab.com/tereta/application/development.git
- Packagist 页面：https://packagist.org/packages/tereta%2Fapplication-development
