# tereta/di

> 标签: Autowiring, PSR-11, container, dependency injection, di, factory, service, singleton

## 简介

Dependency injection container with a PSR-11 interface.It stores services, creates objects with their dependencies and returns the same instance when it is needed again.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
