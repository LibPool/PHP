# tereta/application-migration

> 标签: database, dump, migration, restore, tereta application

## 简介

The migration package for the tereta/application framework.It applies database migrations of the application modules and dumps and restores table data with the database:migration, database:data:dump and database:data:restore console commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
