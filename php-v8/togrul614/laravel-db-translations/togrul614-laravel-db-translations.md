# togrul614/laravel-db-translations

> 标签: admin, i18n, laravel, localization, translations

## 简介

Database-backed translation manager for Laravel admin panels — publishable views, configurable authorization and languages, drop-in Translator loader.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
