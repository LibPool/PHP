# maniaplanet/maniaplanet-ws-sdk

> 标签: ManiaPlanet, ShootMania, TrackMania, curl, oauth2, rest, web services

## 简介

SDK for the ManiaPlanet Web Services API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
