# tawked/tawked-php

> 标签: 2fa, api, arabic, email, ksa, otp, phone-verification, psr-18, saudi-arabia, sdk, sms, sms-otp, tawked, transactional-email, webhooks, whatsapp, whatsapp-business-api

## 简介

Official Tawked SDK for PHP: SMS OTP verification, WhatsApp Business API messages, transactional email and webhooks for businesses in Saudi Arabia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
