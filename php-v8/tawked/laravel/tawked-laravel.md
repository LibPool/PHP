# tawked/laravel

> 标签: arabic, email, laravel, laravel-package, mail, mail-transport, notification-channel, notifications, otp, phone-verification, saudi-arabia, sms, tawked, transactional-email, webhooks, whatsapp, whatsapp-business-api

## 简介

Tawked for Laravel: a mail transport for transactional email, WhatsApp Business API notifications, SMS OTP verification for Saudi numbers, webhook events and a test fake.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
