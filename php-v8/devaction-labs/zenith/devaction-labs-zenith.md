# devaction-labs/zenith

> 标签: dashboard, horizon, inertia, laravel, monitoring, queues, react

## 简介

The operator console and orchestration layer for Laravel Horizon, built with React and Inertia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
