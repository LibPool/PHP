# shabushabu/laravel-paradedb-search

> 标签: laravel, paradedb, pg_search, shabushabu

## 简介

Integrates the pg_search extension by ParadeDB into Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
