# maikelvanmaurik/laravel-model-settings

> 标签: Settings, laravel, models

## 简介

Add simple yet flexible settings to your Laravel models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
