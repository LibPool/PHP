# technically/dependency-resolver

> 标签: PSR-11, auto-wiring, dependency-resolver, php

## 简介

Dependency-resolver utility based on PSR-11 container to be used for auto-wiring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
