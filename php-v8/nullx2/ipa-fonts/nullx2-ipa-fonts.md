# nullx2/ipa-fonts

> 标签: font, fonts, ipa, ipafont, japanese, pdf

## 简介

IPA fonts (IPA Mincho / IPA Gothic) distributed as a Composer package. Font files only.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
