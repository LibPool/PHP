# feiyun/tools

> 标签: database, filter, hyperf, query, swoole, tools, utilities

## 简介

飞云工具包 - 企业级 Hyperf 辅助工具集合，包含自动筛选等实用工具

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
