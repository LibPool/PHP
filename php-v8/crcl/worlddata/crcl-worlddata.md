# crcl/worlddata

> 标签: World data, continents, countries, currencies, timezones, tld

## 简介

Enrich country codes with names, continent, time zone, coordinates, and top-level domains.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
