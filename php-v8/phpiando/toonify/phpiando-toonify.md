# phpiando/toonify

> 标签: ai, json, llm, serialization, token-optimization, toon

## 简介

A PHP library to convert between JSON and TOON format for optimized LLM data exchange.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
