# bnjns/laravel-searchtools

> 标签: bnjns, bootstrap, filter, jquery, search

## 简介

A small package to provide a GUI for filtering and searching entries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
