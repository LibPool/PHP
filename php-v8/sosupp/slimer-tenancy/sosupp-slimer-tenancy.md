# sosupp/slimer-tenancy

> 标签: slimer-tenancy, sosupp

## 简介

An opinionated simple and slimer mulit-tenancy package for laravel. A drop in!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
