# nafigator/php-qa-hooks

> 标签: bash-script, code-standard, code-style, git, git-conflicts, git-hooks, php, php-syntax

## 简介

Git hooks for PHP commits QA.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
