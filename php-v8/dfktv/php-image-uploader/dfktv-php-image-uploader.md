# dfktv/php-image-uploader

> 标签: http, image uploader, php, remote upload

## 简介

Library for uploading image to picasa, flickr, imgur, imageshack

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
