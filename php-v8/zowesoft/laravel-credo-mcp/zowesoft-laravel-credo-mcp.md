# zowesoft/laravel-credo-mcp

> 标签: Nigeria, ai, credo, credocentral, laravel, mcp, model-context-protocol, payments

## 简介

An MCP (Model Context Protocol) server for the Credo payment gateway, powered by zowesoft/laravel-credo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
