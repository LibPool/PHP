# zowesoft/laravel-credo

> 标签: Nigeria, credo, credo-payments, credocentral, laravel, payment-gateway, payments

## 简介

A fluent Laravel package for the Credo payment gateway (credocentral.com / credodemo.com).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
