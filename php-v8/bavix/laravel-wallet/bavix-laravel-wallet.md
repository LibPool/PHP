# bavix/laravel-wallet

> 标签: bavix, credits, currency, laravel, laravel-package, laravel-wallet, payments, virtual, wallet

## 简介

It's easy to work with a virtual wallet.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
