# reliforp/reli-prof

> 标签: ffi, php, profiler

## 简介

A sampling profiler or a memory profiler for PHP written in PHP, which reads information about running PHP VM from outside of the process.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
