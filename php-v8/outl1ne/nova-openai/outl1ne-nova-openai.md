# outl1ne/nova-openai

> 标签: laravel, nova, openai

## 简介

OpenAI SDK for a Laravel application that also stores OpenAI communication and presents it in a Laravel Nova admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
