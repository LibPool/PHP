# kosmcode/google-recaptcha-v3-rule

> 标签: google, laravel, recaptcha, rule, v3, validiate

## 简介

Package to Laravel framework with Rule to validate Google ReCaptcha V3 captcha token

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
