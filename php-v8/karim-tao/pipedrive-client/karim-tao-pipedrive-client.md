# karim-tao/pipedrive-client

> 标签: pipedrive, pipedrive-api, pipedrive-client, psr-18

## 简介

Framework-agnostic PHP client for the Pipedrive API. PSR-18, OAuth handled, raw responses kept.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
