# karim-tao/pipedrive-laravel

> 标签: laravel, pipedrive, pipedrive-api, pipedrive-laravel

## 简介

Laravel integration for the Pipedrive API. Config-driven credentials and Laravel's own HTTP client under the hood.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
