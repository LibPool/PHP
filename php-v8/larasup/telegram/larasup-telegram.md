# larasup/telegram

> 标签: bot, laravel, telegram, telegram-bot, webhook

## 简介

Laravel package for building Telegram bots with declarative routing, typed views, and keyboard builders

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
