# poli-page/sdk

> 标签: Rendering, html, pdf, poli-page, template

## 简介

Poli Page SDK for PHP — render PDFs from HTML templates via the Poli Page API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
