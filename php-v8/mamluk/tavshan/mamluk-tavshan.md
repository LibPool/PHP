# mamluk/tavshan

> 标签: Rabbit MQ, queues

## 简介

Tavshan by Mamluk - a simplified Rabbit MQ library written on top of the PHP AMQP Library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
