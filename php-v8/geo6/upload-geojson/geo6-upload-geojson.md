# geo6/upload-geojson

> 标签: expressive, geojson, mezzio, php, upload, validator, zend, zend-framework

## 简介

Upload (validated) GeoJSON files in a specific directory using PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
