# idoit/apiclient

> 标签: api, cmdb, i-doit, it documentation, json-rpc

## 简介

Easy-to-use, but feature-rich client library for i-doit's JSON-RPC API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
