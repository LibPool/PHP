# umbrellio/laravel-heavy-jobs

> 标签: extension, laravel, redis, umbrellio

## 简介

Позволяет отдельно хранить огромные данные задачи из очереди.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
