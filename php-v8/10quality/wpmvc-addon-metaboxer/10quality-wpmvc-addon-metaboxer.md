# 10quality/wpmvc-addon-metaboxer

> 标签: metaboxer, wordpress, wpmvc

## 简介

Metabox generator for WordPress MVC (WPMVC) framework models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
