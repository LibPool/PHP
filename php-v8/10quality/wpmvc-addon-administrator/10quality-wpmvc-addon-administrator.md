# 10quality/wpmvc-addon-administrator

> 标签: administrator, wordpress, wpmvc

## 简介

Custom WordPress settings and admin menus for WordPress MVC (WPMVC) framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
