# castiron/typo3-plugin-rollbar

> 标签: TYPO3 CMS

## 简介

A Rollbar integration for TYPO3 (https://rollbar.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
