# pescheckit/pescheck-client

> 标签: api, official, pescheck, php, rest, sdk

## 简介

Official Pescheck API PHP SDK (generated). Install via `composer require pescheckit/pescheck-client`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
