# moxio/sqlite-extended-api

> 标签: ffi, pdo, sqlite, sqlite3, z-engine

## 简介

Exposes SQLite APIs that are otherwise not available in PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
