# ostrolucky/symfony-container-number-validator

> 标签: PHP

## 简介

Simple constraint for Symfony Validator which validates if supplied container number conforms to ISO 6346

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
