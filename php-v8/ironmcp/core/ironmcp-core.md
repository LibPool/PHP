# ironmcp/core

> 标签: additionalProperties, ai-agents, conformance, hardening, json-schema, laravel, mcp, model-context-protocol, strict-args, woocommerce, wordpress

## 简介

Hardened, conformant MCP tools that refuse undeclared arguments with a recoverable error and enforce exactly what they advertise.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
