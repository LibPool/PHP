# arkounay/quick-admin-generator-bundle

> 标签: admin, bundle, crud, generator, symfony

## 简介

QAG is a bundle that generates cruds admin for Symfony applications using Doctrine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
