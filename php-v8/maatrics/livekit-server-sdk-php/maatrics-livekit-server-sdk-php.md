# maatrics/livekit-server-sdk-php

> 标签: Ingress, WebRTC, egress, livekit, sdk, sip, video, webhooks

## 简介

LiveKit server SDK for PHP — room management, egress, ingress, SIP, agent dispatch, WhatsApp and Twilio connectors, access tokens and webhooks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
