# tecfinite/zatca-qr

> 标签: ZATCA, tecfinite, zatca invoice, zatca qr

## 简介

This package takes ZATCA invoice data and generates ZATCA TLV string and Qr code image.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
