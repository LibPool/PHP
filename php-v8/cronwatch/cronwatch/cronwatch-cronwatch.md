# cronwatch/cronwatch

> 标签: alerts, cron, heartbeat, laravel, monitoring, scheduled jobs, symfony, wordpress

## 简介

Cron and scheduled-job monitoring that lives inside your PHP app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
