# cronwatch/craft

> 标签: Craft, alerts, craft-plugin, craftcms, cron, monitoring, queue

## 简介

Watches Craft CMS's queue jobs and console commands, and alerts you when a run is missed, fails, gets stuck or runs slow.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
