# balping/laravel-hashslug

> 标签: hashid, hashids, hashslug, laravel, slug

## 简介

Package providing a trait to use Hashids on a model

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
