# buggregator/trap

> 标签: Fibers, WebSockets, binary dump, cli, console, debug, dev, dump, dumper, helper, sentry, server, smtp

## 简介

A simple and powerful tool for debugging PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
