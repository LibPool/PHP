# nitsan/ns-googledocs

> 标签: TYPO3 CMS, TYPO3 Google Docs , cloud, docs, google, site

## 简介

Google Docs - Manually transferring all content from Google Docs to your TYPO3 website can be a boring task, right? We understand your concerns, which is why we've created an efficient solution to simplify this migration process for TYPO3 users. Our innovative solution allows you to import your Google Docs directly into your TYPO3 pages with just one click, saving you valuable time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
