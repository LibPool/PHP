# nitsan/ns-facebook-comment

> 标签: App ID, TYPO3 CMS, comments, facebook, nitsan, ns_facebook_comment

## 简介

Grab this extension which will help you to add facebook comment plugin to add and share comments, reply, listing etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
