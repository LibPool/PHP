# andreapollastri/checkpoint

> 标签: PHP

## 简介

Laravel security scanner — checks CVEs, hardcoded secrets, SQL injection, XSS and more via a single Artisan command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
