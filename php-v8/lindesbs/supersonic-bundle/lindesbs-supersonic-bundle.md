# lindesbs/supersonic-bundle

> 标签: LibreOffice, OpenDocument, OpenOffice, bundle, document, generator, oasis, odf, odt, symfony

## 简介

Symfony Bundle zur programmatischen Erstellung von ODT-Dokumenten gemäß OASIS OpenDocument 1.2 Spezifikation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
