# linyuee/wechat

> 标签: PHP

## 简介

一个非常简单的微信开发工具包,集成了微信授权，微信支付，jssdk，公众号消息收发等功能

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
