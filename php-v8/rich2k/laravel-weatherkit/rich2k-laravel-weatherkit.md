# rich2k/laravel-weatherkit

> 标签: apple weatherkit, apple weatherkit api, forecast, laravel-weatherkit, rich2k, weather, weather forecast, weatherkit, weatherkit api

## 简介

Provides a Wrapper for the Apple WeatherKit API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
