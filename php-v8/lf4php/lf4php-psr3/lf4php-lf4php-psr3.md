# lf4php/lf4php-psr3

> 标签: PSR3, facade, lf4php, log, wrapper

## 简介

This is an lf4php binding for any PSR-3 logger.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
