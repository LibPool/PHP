# rewi.sh/craft-mcp

> 标签: ai, craft-plugin, craftcms, mcp, model-context-protocol

## 简介

MCP - All in one. An MCP server for Craft CMS with content tools and a control panel for tokens, activity, and agent drafts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
