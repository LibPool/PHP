# filefabrik/activitypub

> 标签: Federation, activitypub, activitystreams

## 简介

A PHP implementation of ActivityPub protocol based upon the ActivityStreams 2.0 data format.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
