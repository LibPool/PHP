# digitalclaim/azure-scheduler-laravel

> 标签: azure-scheduler-laravel, digitalclaim, laravel

## 简介

Laravel scheduler triggered by Azure Scheduled Functions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
