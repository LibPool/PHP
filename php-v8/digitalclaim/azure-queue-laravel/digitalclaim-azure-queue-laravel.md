# digitalclaim/azure-queue-laravel

> 标签: azure-queue-laravel, digitalclaim, laravel

## 简介

Azure Storage Queue for Laravel based on triggered Azure Functions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
