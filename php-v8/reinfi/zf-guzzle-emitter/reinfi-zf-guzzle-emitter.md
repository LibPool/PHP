# reinfi/zf-guzzle-emitter

> 标签: Guzzle, emitter, subscriber, zend

## 简介

A Zend Framework module adding subscribers to guzzle emitter via configuration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
