# reinfi/zfe-module-bridge-provider

> 标签: expressive, module, provider, zend

## 简介

An Zend Expressive module for loading ZF2 or ZF3 modules.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
