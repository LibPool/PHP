# anwarme/kafka-php

> 标签: kafka, php, rdkafka

## 简介

Some helper methods for ease of using apache kafka - the message broker. targeted at php developers using kafka as a message queueing system

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
