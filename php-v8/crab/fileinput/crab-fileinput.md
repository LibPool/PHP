# crab/fileinput

> 标签: PHP

## 简介

Bootstrap File Input 插件支持使用HTML 5 FormData和XHR2协议的基于AJAX的上传

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
