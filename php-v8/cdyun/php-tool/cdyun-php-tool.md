# cdyun/php-tool

> 标签: IP, array, cdyun, crypto, curl, geo, helper, message, php, string, time, tools, tree

## 简介

PHP8.1+通用工具包，包含数组处理、字符串处理、时间处理、加解密、IP、地理计算、Curl、全局辅助方法等功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
