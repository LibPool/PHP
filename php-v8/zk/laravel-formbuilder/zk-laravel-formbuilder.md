# zk/laravel-formbuilder

> 标签: Client-side form validation, Form builder for Laravel, JavaScript form builder, Laravel UI components, Laravel custom form components, Laravel dynamic forms, Laravel form builder, Laravel frontend validation, Laravel lazy loading forms

## 简介

A powerful and flexible form-building solution for Laravel, featuring Blade components, lazy loading, and a custom JavaScript library for client-side enhancements.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
