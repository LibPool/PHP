# accountdesk/mail-autodetect

> 标签: autoconfig, autodiscover, email, imap, mail, smtp

## 简介

Auto-detect IMAP and SMTP mail server settings for any domain

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
