# pkc/video-call

> 标签: WebRTC, laravel, laravel-reverb, real-time, video-call, video-chat

## 简介

Laravel video calling package using WebRTC and Laravel Reverb for real-time communication

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
