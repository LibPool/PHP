# pkc/laravel-realtime

> 标签: Broadcasting, echo, laravel, realtime, reverb

## 简介

Reusable Laravel realtime broadcasting helpers for admin dashboards (Reverb + Echo).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
