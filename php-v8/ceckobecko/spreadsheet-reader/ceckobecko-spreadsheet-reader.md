# ceckobecko/spreadsheet-reader

> 标签: excel, php, reader, spreadsheet

## 简介

PHPExcelReader/SpreadsheetReader - A class for reading Microsoft Excel (97/2003) Spreadsheets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
