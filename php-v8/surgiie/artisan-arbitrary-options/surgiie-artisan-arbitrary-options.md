# surgiie/artisan-arbitrary-options

> 标签: arbitrary, artisan, command, laravel, options, php

## 简介

Allow arbitrary options to be passed to laravel artisan commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
