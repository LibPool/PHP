# surgiie/vault-cli

> 标签: PHP

## 简介

A PHP command-line interface for storing encrypted `AES-256` or `AES-128` json data using an encryption key derived from a master password.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
