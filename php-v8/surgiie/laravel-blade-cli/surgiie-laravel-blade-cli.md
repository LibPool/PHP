# surgiie/laravel-blade-cli

> 标签: cli, console, laravel, laravel Blade, render, templating

## 简介

Render and save textual files from the command line using Laravel's Blade engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
