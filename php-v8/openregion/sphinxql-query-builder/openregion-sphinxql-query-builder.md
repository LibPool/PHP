# openregion/sphinxql-query-builder

> 标签: database, query builder, search, sphinx, sphinxql, sql

## 简介

A PHP query builder for SphinxQL and ManticoreQL with MySQLi and PDO drivers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
