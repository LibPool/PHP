# starme/laravel-es

> 标签: builder, elasticsearch, fulltext, indexing, laravel, orm, php

## 简介

Laravel, php elasticseach query builder to build complex queries using an elegant syntax

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
