# haxibiao/breeze

> 标签: PHP

## 简介

Haxibiao 架构的基础包,从用户认证到基本内容社交系统，长视频短视频媒体内容系统...

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
