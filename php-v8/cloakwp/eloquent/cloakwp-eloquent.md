# cloakwp/eloquent

> 标签: cloakwp, eloquent, laravel, wordpress

## 简介

A Laravel wrapper for WordPress that converts all WordPress tables into Laravel Eloquent Models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
