# factusmart/sdk

> 标签: boleta, cpe, factura, facturación electrónica, factusmart, peru, sunat, ubl

## 简介

SDK oficial en PHP del API de facturación electrónica de FactuSmart (SUNAT, Perú): facturas, boletas, notas, guías y anulaciones.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
