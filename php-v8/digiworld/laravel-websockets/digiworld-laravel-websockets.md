# digiworld/laravel-websockets

> 标签: digiworld, digiworld-dev, laravel-websockets

## 简介

fork from laravel-websockets to use WebSocket server compatible with laravel 12

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
