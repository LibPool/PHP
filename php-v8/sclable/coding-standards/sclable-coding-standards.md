# sclable/coding-standards

> 标签: PHP

## 简介

Our code of conduct requires strict adherence to the FIG PSR standards. The automated checks are collected in this Tool.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
