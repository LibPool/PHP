# satheez/laravel-package-doctor

> 标签: Audit, ci, composer, dependencies, dependency-analysis, laravel, outdated, package-health, security

## 简介

Audit a Laravel project's Composer dependencies for upgrade safety, security, and Laravel compatibility.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
