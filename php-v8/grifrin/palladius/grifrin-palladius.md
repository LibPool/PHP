# grifrin/palladius

> 标签: Chinese, Pinyin, cyrillic, palladius

## 简介

PHP library for transcribing Chinese characters (pinyin) into the Cyrillic alphabet (using Palladius system).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
