# oxphp/stubs

> 标签: PHPStan, autocomplete, ide, oxphp, php-extension, psalm, static-analysis, stubs

## 简介

OxPHP extension stubs for IDE autocompletion and static analysis (PHPStan, Psalm).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
