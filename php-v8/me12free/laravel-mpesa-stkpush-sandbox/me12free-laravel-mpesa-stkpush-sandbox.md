# me12free/laravel-mpesa-stkpush-sandbox

> 标签: PHP

## 简介

A free Laravel package for integrating M-Pesa STK Push (sandbox/testing) with best practices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
