# darren-nolan/styler

> 标签: css, laravel, less, scss, styles, stylesheets

## 简介

CSS Styler package for Laravel. Compiles Less/SCSS on the fly and supports serving cached content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
