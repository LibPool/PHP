# grok-s/socket

> 标签: PHP

## 简介

Full-featured, open-source WebSocket library for PHP (Socket.IO-like: events, rooms, ACKs, auth, encryption, DB integration)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
