# abdallahk/laravel-role-manager

> 标签: PHP

## 简介

A Laravel package for managing roles and permissions with Vue 3 UI built on top of Spatie Laravel Permission

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
