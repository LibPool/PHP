# vrza/terminal-palette

> 标签: Escape, ansi, codes, palette, php, sequences, terminal

## 简介

PHP library for using ANSI escape codes in the terminal

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
