# artisanpack-ui/bookings

> 标签: appointments, availability, bookings, calendar, laravel, scheduling

## 简介

Appointment scheduling and booking management for Laravel — services, availability, bookings, calendar sync, and a public booking widget.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
