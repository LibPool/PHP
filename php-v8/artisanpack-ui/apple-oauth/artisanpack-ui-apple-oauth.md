# artisanpack-ui/apple-oauth

> 标签: apple, artisanpack-ui, laravel, oauth, oauth2, sign-in-with-apple

## 简介

Initial scaffold for the shared Apple (Sign in with Apple) OAuth2 broker for ArtisanPack UI's Apple service integrations. No feature code yet — authentication, token storage/refresh, and scope management arrive in later releases.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
