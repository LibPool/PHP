# artisanpack-ui/google-business-profile

> 标签: GBP, artisanpack-ui, google, google-business-profile, laravel, local-seo

## 简介

OAuth-free, UI-free API client for the Google Business Profile family of APIs (locations, performance, reviews, posts).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
