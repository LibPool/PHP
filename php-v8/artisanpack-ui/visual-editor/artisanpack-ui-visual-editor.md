# artisanpack-ui/visual-editor

> 标签: PHP

## 简介

A Gutenberg-powered visual editor for Laravel — post editor, site editor, and Blade/React/Vue block renderers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
