# artisanpack-ui/microsoft-oauth

> 标签: artisanpack-ui, azure-ad, entra, laravel, microsoft, oauth, oauth2

## 简介

Shared Microsoft identity platform (Entra / Azure AD) OAuth2 authentication, token storage/refresh, and scope management that powers ArtisanPack UI's Microsoft service integrations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
