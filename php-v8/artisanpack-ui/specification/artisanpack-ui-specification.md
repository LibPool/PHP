# artisanpack-ui/specification

> 标签: artisanpack-ui, checks, laravel, okf, open-knowledge-format, site-readiness, specification, website-specification

## 简介

Ingests specification.website's Open Knowledge Format into a local index and exposes the SpecCheck registry other ArtisanPack UI packages build checks on.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
