# artisanpack-ui/google-search-console

> 标签: artisanpack-ui, google, google-search-console, laravel, search-console, seo

## 简介

Search Console performance data and UI components for ArtisanPack UI, built on the google base package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
