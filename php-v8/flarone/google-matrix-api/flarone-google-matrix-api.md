# flarone/google-matrix-api

> 标签: Google Matrix, Google Matrix Api, google, google api, matrix

## 简介

Wrapper for the Google Distance Matrix API (and Laravel friendly)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
