# refear99/easy-sls

> 标签: SLS, aliyun, easy-sls, sls-sdk

## 简介

This package provides a easy way to access Aliyun SLS API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
