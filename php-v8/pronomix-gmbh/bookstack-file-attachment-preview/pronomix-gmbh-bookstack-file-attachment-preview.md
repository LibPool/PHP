# pronomix-gmbh/bookstack-file-attachment-preview

> 标签: BookStack, attachment-preview, bookstack-module, heic

## 简介

Local previews for BookStack file attachments, installed through BookStack's theme module system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
