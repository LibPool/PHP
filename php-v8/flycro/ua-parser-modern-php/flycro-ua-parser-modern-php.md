# flycro/ua-parser-modern-php

> 标签: CPU, browser, device, os, parser, user-agent

## 简介

PHP port of ua-parser-modern - detect browser, engine, OS, CPU and device from User-Agent strings

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
