# senderkit/senderkit-laravel

> 标签: PHP

## 简介

Laravel integration for the SenderKit PHP SDK — service provider, facade, mail transport, notification channel, webhook middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
