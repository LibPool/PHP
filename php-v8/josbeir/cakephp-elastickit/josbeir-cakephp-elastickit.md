# josbeir/cakephp-elastickit

> 标签: cakephp, elasticsearch, plugin

## 简介

A lightweight CakePHP 5 plugin for working with Elasticsearch using the official PHP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
