# lara-zeus-kh/palsky

> 标签: Laravel CMS, cms, filamentphp, lara-zeus, laravel, menu, news, pages, posts, sky, wordpress alternative, wordpress laravel

## 简介

Lara-zeus sky is simple CMS for your website. It includes posts, pages, tags, and categories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
