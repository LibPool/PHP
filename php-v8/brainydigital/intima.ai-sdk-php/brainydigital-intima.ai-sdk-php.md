# brainydigital/intima.ai-sdk-php

> 标签: api, intima.ai, intimaai, intimai, php, sdk

## 简介

Implementação da API do Intima.ai em forma de SDK Client para PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
