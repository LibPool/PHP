# nash/pin

> 标签: PHP

## 简介

Pin 是一款零配置、无骨架、极小化的 Hyperf 发行版，它的灵感来源于 hyperf/nano。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
