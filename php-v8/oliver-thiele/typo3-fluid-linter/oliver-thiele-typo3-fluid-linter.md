# oliver-thiele/typo3-fluid-linter

> 标签: PHP

## 简介

A linter for TYPO3 Fluid templates — catches typographic quotes, deprecated syntax, and Fluid 5 breaking changes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
