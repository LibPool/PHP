# ducrot/twigcn-bundle

> 标签: components, stimulus, symfony, tailwind, twig, ui

## 简介

Beautiful, accessible UI components for Symfony & Twig. Inspired by shadcn/ui.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
