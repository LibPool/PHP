# kanopi/basic-firewall-wp

> 标签: PHP

## 简介

Evaluates every request against a set of rules and allows, challenges or blocks it, as early in the request as WordPress can act.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
