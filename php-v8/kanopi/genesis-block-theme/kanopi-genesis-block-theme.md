# kanopi/genesis-block-theme

> 标签: PHP

## 简介

A beautifully-simple yet powerful WordPress theme that integrates perfectly with the block editor and the Genesis Blocks plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
