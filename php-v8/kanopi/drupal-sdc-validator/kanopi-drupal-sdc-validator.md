# kanopi/drupal-sdc-validator

> 标签: cli, components, drupal, sdc, validator, yml

## 简介

CLI tool to validate Drupal Single Directory Component (.component.yml) files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
