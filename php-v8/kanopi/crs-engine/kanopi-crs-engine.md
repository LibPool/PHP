# kanopi/crs-engine

> 标签: PHP

## 简介

Standalone PHP engine that parses the OWASP Core Rule Set (CRS) and evaluates HTTP requests against it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
