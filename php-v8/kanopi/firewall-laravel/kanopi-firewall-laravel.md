# kanopi/firewall-laravel

> 标签: firewall, laravel, middleware, rate-limiting, security, waf

## 简介

Laravel integration for kanopi/firewall: middleware, config, Artisan commands and event wiring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
