# nevadskiy/laravel-tree

> 标签: eloquent, hierarchy, laravel, ltree, materialized path, path, tree

## 简介

Tree-like structure for Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
