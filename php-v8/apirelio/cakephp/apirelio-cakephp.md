# apirelio/cakephp

> 标签: api-monitoring, cakephp, customer-analytics, observability

## 简介

Fail-safe CakePHP middleware for Apirelio customer integration analytics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
