# apirelio/flightphp

> 标签: api-monitoring, customer-analytics, flightphp, observability

## 简介

Fail-safe FlightPHP middleware for Apirelio customer integration analytics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
