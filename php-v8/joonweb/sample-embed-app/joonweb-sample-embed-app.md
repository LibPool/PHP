# joonweb/sample-embed-app

> 标签: PHP

## 简介

Sample Embed App for JoonWeb to help developer clone it and customize it according to thier needs, Its an official JoonWeb Embed App SDK and system in PHP 8+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
