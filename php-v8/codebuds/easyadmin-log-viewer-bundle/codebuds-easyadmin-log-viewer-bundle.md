# codebuds/easyadmin-log-viewer-bundle

> 标签: Viewer, bundle, easyadmin, log, symfony

## 简介

A Symfony bundle that provides a log viewer interface for EasyAdmin backends

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
