# olorunda/laravel-zoho-cpaas

> 标签: Zoho, batch-email, cpaas, email-api, laravel, mail-driver, templates, transactional-email, zeptomail, zoho-mail

## 简介

Comprehensive Laravel package for Zoho CPaaS & ZeptoMail: Transactional Email API, Batch Sending, Templates, Mail Transport, Suppression, Agents, Domains, Logs & OAuth

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
