# aipencil/smoothie

> 标签: PHP

## 简介

A Filament Admin Agent skill package that extends Filament with reusable features, tools, and UI enhancements to speed up Laravel admin panel development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
