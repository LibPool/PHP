# codevelopers/markup

> 标签: bootstrap, starter theme, wordpress, wordpress starter theme

## 简介

Wordpress Starter Theme integrated with Bootstrap 4 Framework and Webpack Encore

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
