# numero2/contao-random-ce

> 标签: PHP

## 简介

Provides a wrapper (like accordion) for content elements to show a different, random element on each reload of the page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
