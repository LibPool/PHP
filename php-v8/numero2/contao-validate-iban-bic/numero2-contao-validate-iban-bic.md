# numero2/contao-validate-iban-bic

> 标签: BIC, IBAN, contao, rgxp, validator

## 简介

Add rgxp to validate given IBAN or BIC. This is available for form fields.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
