# numero2/contao-video-thumbnail

> 标签: contao, poster, thumbnail, video

## 简介

Allows editors to capture a video frame as thumbnail/poster directly in the Contao file manager.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
