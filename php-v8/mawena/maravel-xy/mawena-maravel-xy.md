# mawena/maravel-xy

> 标签: laravel, permissions, rbac, sanctum, starter-kit, template, vue, vuetify

## 简介

Template d'application Laravel + Vue 3 (Vuetify) avec authentification Sanctum, gestion des utilisateurs (CRUD) et système de rôles/permissions via Maravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
