# inrae/sicpa-documentation-bundle

> 标签: PHP

## 简介

SicpaDocumentationBundle Symfony du cati/sicpa avec catégories, articles, documents attachés, pagination, recherche et administration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
