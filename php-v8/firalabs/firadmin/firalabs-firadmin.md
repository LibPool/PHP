# firalabs/firadmin

> 标签: admin, cpanel, laravel, login, managment, privilege, user

## 简介

Basic admin panel for Laravel 4 with login and user controller implementation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
