# renolit/static-info-tables-zh

> 标签: Chinese, Static Info Tables, TYPO3 CMS

## 简介

Chinese (zh) language pack for the Static Info Tables providing localized names for countries and territories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
