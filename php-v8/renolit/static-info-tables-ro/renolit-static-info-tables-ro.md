# renolit/static-info-tables-ro

> 标签: Static Info Tables, TYPO3 CMS

## 简介

Romanian (ro) language pack for the Static Info Tables providing localized names for countries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
