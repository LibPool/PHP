# renolit/static-info-tables-nl

> 标签: Static Info Tables, TYPO3 CMS

## 简介

Dutch (nl) language pack for the Static Info Tables providing localized names for countries, currencies and so on.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
