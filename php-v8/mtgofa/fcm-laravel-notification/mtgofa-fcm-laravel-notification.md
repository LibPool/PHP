# mtgofa/fcm-laravel-notification

> 标签: PHP

## 简介

Driver to connect laravel´s notification system to Google Firebase Cloud Messaging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
