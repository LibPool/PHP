# marcelofecchio/siscomex-sdk

> 标签: cadastro de atributos, catalogo de produtos, comercio exterior, duimp, portal unico, pucomex, sdk, siscomex

## 简介

SDK PHP 8.4 para a API Pública do Portal Único Siscomex: autenticação (IMPEXP), Cadastro de Atributos e Catálogo de Produtos.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
