# marcelofecchio/correios-api

> 标签: Danfe, Rastreamento, correios, cws, etiqueta, laravel, pre-postagem, zpl

## 简介

Componente PHP para a API REST dos Correios (CWS) e para gerar etiquetas em ZPL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
