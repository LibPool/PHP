# marcelofecchio/safe2pay-api

> 标签: Pagamento, cartao-de-credito, checkout-transparente, pix, safe2pay

## 简介

Componente PHP enxuto para a API da Safe2Pay: Pix, cartão de crédito (à vista ou parcelado), consulta, estorno e webhook.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
