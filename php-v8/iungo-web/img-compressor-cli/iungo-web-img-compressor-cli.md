# iungo-web/img-compressor-cli

> 标签: cli, imagem, imagens

## 简介

Um simples utilitário para facilitar a exibição de mensagens no terminal enquanto o PHP é utilizado via linha de comando.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
