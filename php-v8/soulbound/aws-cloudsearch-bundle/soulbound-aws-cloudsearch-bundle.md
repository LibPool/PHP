# soulbound/aws-cloudsearch-bundle

> 标签: amazon, aws, aws-sdk-php, cloudsearch, web services

## 简介

A Symfony2 Bundle for interfacing with AWS CloudSearch

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
