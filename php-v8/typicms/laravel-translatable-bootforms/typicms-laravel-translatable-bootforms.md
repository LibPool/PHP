# typicms/laravel-translatable-bootforms

> 标签: bootforms, form, i18n, laravel, translatable

## 简介

Empowers typicms/bootforms with typicms/laravel-translatable.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
