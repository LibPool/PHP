# guilhermecfviana/nfsenacional

> 标签: brasil, nfse, nfse nacional, nfsenacional, nota fiscal eletrônica de serviço

## 简介

Projeto para gerar a DANFSe da NFSe Nacional do Brasil

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
