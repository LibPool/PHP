# terciuss/flanx-pusher

> 标签: Socket, daemon, laravel, pusher, realtime, websocket

## 简介

WebSocket Daemon пакет для Laravel приложений с поддержкой Pusher-совместимого протокола

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
