# bulatronic/api-kit

> 标签: api, bundle, dto, rest, symfony, validation

## 简介

Lightweight Symfony bundle for building REST APIs with DTO-first validation, standardized responses, and thin controllers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
