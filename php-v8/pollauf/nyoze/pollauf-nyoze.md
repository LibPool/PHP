# pollauf/nyoze

> 标签: api, architecture, crud, domain, entity, framework, php, pipeline

## 简介

Entity-oriented PHP framework focused on consistency between domain, action and consequence.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
