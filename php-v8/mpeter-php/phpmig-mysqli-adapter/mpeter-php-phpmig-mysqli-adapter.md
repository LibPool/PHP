# mpeter-php/phpmig-mysqli-adapter

> 标签: migration, mysqli, php, phpmig

## 简介

An adapter for phpmig which provides database access via mysqli

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
