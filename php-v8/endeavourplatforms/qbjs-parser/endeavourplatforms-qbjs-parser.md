# endeavourplatforms/qbjs-parser

> 标签: QBJS, QBJSParser, doctrine, jQuery-QueryBuilder, jquery, orm, parser, php, querybuilder, querybuilder.js, querybuilder.js.org, symfony

## 简介

Parse JSON coming from jQuery QueryBuilder, into database queries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
