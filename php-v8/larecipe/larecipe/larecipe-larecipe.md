# larecipe/larecipe

> 标签: agents, ai, docs, documentation, laravel, llms.txt, markdown, mcp

## 简介

Living documentation for Laravel apps. Your coding agents write the docs and keep them current; every reader, human or agent, gets the current answer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
