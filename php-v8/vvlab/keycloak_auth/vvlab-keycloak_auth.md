# vvlab/keycloak_auth

> 标签: Authentication, OpenId, concrete5, concreteCMS, keycloak

## 简介

Let users access your website using Keycloak OpenID servers

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
