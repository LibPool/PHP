# moo/hasoneselector

> 标签: Forms, cms, formfield, gridfield, has_one, silverstripe

## 简介

This module provides CMS field to manage data object defined in a has_one relation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
