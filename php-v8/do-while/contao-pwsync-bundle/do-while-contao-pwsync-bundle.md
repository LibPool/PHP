# do-while/contao-pwsync-bundle

> 标签: backend, contao, frontend, member, password, sync, user

## 简介

Automatically syncs the password of a Contao backend user with the frontend member (tl_member) who has the same username.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
