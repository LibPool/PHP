# davidkohr/ke-search-honeypot

> 标签: Honeypot, TYPO3 CMS, ke_search, security, spam protection

## 简介

Spam protection for ke_search using honeypot technique. Adds an invisible form field to catch bots.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
