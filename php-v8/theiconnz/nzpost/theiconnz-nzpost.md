# theiconnz/nzpost

> 标签: PHP

## 简介

Magento 2 NZ Post shipping module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://theicon.co.nz/magento2/nzpost
- 源码仓库：https://github.com/theiconnz/nzpost.git
- Packagist 页面：https://packagist.org/packages/theiconnz%2Fnzpost

## 获取地址

- Composer 安装：`composer require theiconnz/nzpost`
- Packagist 仓库：https://repo.packagist.org/p2/theiconnz/nzpost.json
- PHP 要求：~5.5.0|~5.6.0|~7.0.0
