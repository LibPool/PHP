# peltonsolutions/laravel-ownerable

> 标签: laravel, peltonsolutions

## 简介

A custom package for Laravel to make it easier to attach and require classes to belong to a tenant.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
