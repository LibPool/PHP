# nlgen/nlgen

> 标签: artificial intelligence, chatbot, computational linguistics, generation, grammar, natural language generation, natural language processing, nlg, nlp, recursive descent, text construction

## 简介

A library for creating recursive-descent natural language generators.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
