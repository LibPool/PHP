# bert-w/runescape-hiscores-api

> 标签: hiscores, osrs, rs07, runescape

## 简介

Retrieve Hiscore results easily from the OSRS RuneScape Hiscores page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
