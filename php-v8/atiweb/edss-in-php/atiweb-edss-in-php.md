# atiweb/edss-in-php

> 标签: clinical-assessment, disability-scale, edss, functional-systems, kurtzke, multiple-sclerosis, neurology

## 简介

PHP implementation of the Expanded Disability Status Scale (EDSS) calculator based on the Kurtzke/Kappos scoring table

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
