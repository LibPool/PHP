# vtech9nl/filament-polder-theme

> 标签: filament, filament-plugin, filament-theme, laravel, theme

## 简介

Polder: an inset-layout theme for Filament panels, with light and dark mode and an optional compact density

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
