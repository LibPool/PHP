# lbcdev/map-geometries

> 标签: Polygon, geometry, leaflet, map, marker, polyline

## 简介

Geometry classes for maps (Markers, Polylines, Polygons, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
