# kabbouchi/bignumber

> 标签: bignumber, bignumber-php, bignumber.php, php, web3

## 简介

A PHP package for arbitrary-precision decimal and non-decimal arithmetic inspired by bignumber.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
