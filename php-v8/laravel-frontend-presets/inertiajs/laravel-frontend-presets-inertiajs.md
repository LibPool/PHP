# laravel-frontend-presets/inertiajs

> 标签: inertiajs, laravel, preset

## 简介

A Laravel frontend preset to get you up and running with Inertia.js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
