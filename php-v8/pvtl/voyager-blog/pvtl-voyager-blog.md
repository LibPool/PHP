# pvtl/voyager-blog

> 标签: blog, frontend, laravel, posts, voyager

## 简介

Ahoy! - A package to provide a blog to Voyager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
