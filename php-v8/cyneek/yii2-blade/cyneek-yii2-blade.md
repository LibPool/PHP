# cyneek/yii2-blade

> 标签: blade, layout, yii, yii2

## 简介

Wrapper that fits in Blade layout system in Yii2 application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
