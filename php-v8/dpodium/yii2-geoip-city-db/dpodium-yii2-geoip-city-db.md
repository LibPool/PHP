# dpodium/yii2-geoip-city-db

> 标签: extension, geoip, maxmind, yii2

## 简介

Yii2 Component to allow for easy usage of the MaxMind Free dbs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
