# dpodium/sms-api

> 标签: clickatell, cm, mobile ace, sms, sms gateway, sms gateway api

## 简介

Multiple SMS API Providers packaged together for general SMS sending use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
