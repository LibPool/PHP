# akankov/html-ast

> 标签: HTML5, ast, html, parser, printer, tokenizer, visitor

## 简介

nikic/php-parser for HTML — an immutable HTML5 AST with positions, trivia, visitors, and a fidelity printer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
