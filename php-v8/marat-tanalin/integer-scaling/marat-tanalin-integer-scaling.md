# marat-tanalin/integer-scaling

> 标签: algorithms, graphics, image-scaling, integer-scaling, pixel-perfect-scaling

## 简介

Calculates integer ratios for pixel-perfect image upscaling with optional aspect-ratio correction.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
