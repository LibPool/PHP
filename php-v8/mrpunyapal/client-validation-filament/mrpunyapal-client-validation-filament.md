# mrpunyapal/client-validation-filament

> 标签: PHP

## 简介

Filament integration for Laravel Client Validation: native-field macros, render-time x-validate attributes, and custom validation messages/attributes forwarded to the browser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
