# mrpunyapal/laravel-auth-jobs

> 标签: Authentication, MrPunyapal, authorization, jobs, laravel, laravel-auth, laravel-auth-jobs, laravel-jobs, laravel-queue, queue

## 简介

This package allows you to access the authenticated user while processing jobs in the queue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
