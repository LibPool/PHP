# mrpunyapal/client-validation-livewire

> 标签: PHP

## 简介

Livewire integration for Laravel Client Validation: WithClientValidation trait, snapshot hook, and magic-mode browser binding.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
