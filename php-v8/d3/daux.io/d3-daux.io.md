# d3/daux.io

> 标签: docs, documentation, markdown, md

## 简介

Documentation generator that uses a simple folder structure and Markdown files to create custom documentation on the fly

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
