# d3/mailauthenticationcheck

> 标签: Authentication, dkim, dmarc, dns, e-mail, record, spf

## 简介

Checks for configured mail athentication methods like SPF, DKIM and DMARC

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
