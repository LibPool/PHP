# d3/oxid-dic-handler

> 标签: OXID, d3, dependency injection, eshop, services

## 简介

Provides bridges for OXID services that are not reliably listed in the DIC cache.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
