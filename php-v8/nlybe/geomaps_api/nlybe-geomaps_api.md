# nlybe/geomaps_api

> 标签: elgg, geo, maps, plugin

## 简介

The Geo Maps plugin offers an API with PHP/JS libraries for the creation geo-visualization maps of Elgg entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
