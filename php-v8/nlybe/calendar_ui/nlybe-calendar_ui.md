# nlybe/calendar_ui

> 标签: calendar, elgg, fullcalendar, plugin

## 简介

Elgg calendar UI integrating the JS library FullCalendar.io.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
