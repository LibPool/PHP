# sampoyigi/ti-ext-telescope

> 标签: laravel, php, tastyigniter, telescope

## 简介

Laravel Telescope integration for TastyIgniter, monitor and debug your application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
