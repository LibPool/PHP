# oncology-support/amazon-sms-helper-bundle

> 标签: SNS, amazon, aws, sms, symfony

## 简介

Symfony Bundle that simplifies sending SMS messages using Amazon SNS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
