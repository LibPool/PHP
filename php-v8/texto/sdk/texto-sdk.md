# texto/sdk

> 标签: australia, messaging, sms, texto

## 简介

Official PHP SDK for the Texto SMS API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://texto.com.au
- 源码仓库：https://github.com/textosms/texto-php.git
- Packagist 页面：https://packagist.org/packages/texto%2Fsdk

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require texto/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/texto/sdk.json
- 许可证：MIT
- PHP 要求：>=8.0
