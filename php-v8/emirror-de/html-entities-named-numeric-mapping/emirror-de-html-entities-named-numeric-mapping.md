# emirror-de/html-entities-named-numeric-mapping

> 标签: decoding, encoding, htmlentities, mapping

## 简介

Provides mapping from named to numeric html entities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
