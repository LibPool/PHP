# municipes/investigatio

> 标签: PHP

## 简介

Investigatĭo è un modulo Drupal che importa le impostazioni di ricerca indicizzata utilizzate dai Comuni.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
