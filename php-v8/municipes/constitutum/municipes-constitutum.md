# municipes/constitutum

> 标签: PHP

## 简介

Constitūtum è un modulo Drupal che gestisce il tipo di contenuto Appuntamento.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
