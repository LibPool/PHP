# ecomdev/compiler

> 标签: PHP

## 简介

Compiler of parseable data structures from (XML, JSON, etc) into PHP code that can be included into application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
