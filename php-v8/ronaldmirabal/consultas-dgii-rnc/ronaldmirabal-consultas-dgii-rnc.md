# ronaldmirabal/consultas-dgii-rnc

> 标签: PHP

## 简介

Es un paquete desarrollado para consultar el estado del rnc del contribuyente en República Dominicana.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
