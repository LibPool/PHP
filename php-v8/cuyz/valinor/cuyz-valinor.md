# cuyz/valinor

> 标签: array, conversion, hydrator, json, mapper, mapping, object, tree, yaml

## 简介

Dependency free PHP library that helps to map any input into a strongly-typed structure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
