# php-extended/php-bbcode-parser-interface

> 标签: bbcode, interface, parser, php

## 简介

Interfaces to implement parsing of bbcode text into bbcode tree structure.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
