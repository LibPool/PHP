# php-extended/php-suffix-list-bundle

> 标签: check, cookie, http, list, public, suffix, tld, top level domain, validation

## 简介

A library to safely validate top level domains

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
