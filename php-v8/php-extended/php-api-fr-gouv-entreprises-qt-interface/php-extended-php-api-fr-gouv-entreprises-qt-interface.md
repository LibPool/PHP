# php-extended/php-api-fr-gouv-entreprises-qt-interface

> 标签: api, entreprises.gouv.fr, php, qt

## 简介

A library that gets data from the portail qualite tourisme for entreprises.gouv.fr

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
