# php-extended/php-ulid-factory-object

> 标签: factory, implementation, object, php, ulid

## 简介

A library that implements the php-extended/php-ulid-factory-interface library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
