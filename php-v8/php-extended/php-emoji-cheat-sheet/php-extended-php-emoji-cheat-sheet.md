# php-extended/php-emoji-cheat-sheet

> 标签: WebpageFX, cheat, emoji, php, sheet, wrapper

## 简介

A wrapper around the WebpageFX/emoji-cheat-sheet.com emoji repository

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
