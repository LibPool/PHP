# php-extended/php-http-client-retry

> 标签: PSR3, client, header, http, php, psr18, retry

## 简介

A psr-18 compliant middleware client that handles retries for psr-7 http messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
