# php-extended/php-api-fr-gouv-entreprises-gmth-interface

> 标签: api, finances.gouv.fr, gmth, php

## 简介

A library that gets data from the gmth application for entreprises.gouv.fr

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
