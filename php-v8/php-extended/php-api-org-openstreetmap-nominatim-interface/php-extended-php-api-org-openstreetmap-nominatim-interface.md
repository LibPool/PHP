# php-extended/php-api-org-openstreetmap-nominatim-interface

> 标签: api, interface, nominatim.openstreetmap.org, php, specification

## 简介

A library that gets data from nominatim.openstreetmap.org website's api.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
