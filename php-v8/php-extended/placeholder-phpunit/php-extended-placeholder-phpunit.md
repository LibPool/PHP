# php-extended/placeholder-phpunit

> 标签: php, phpunit, placeholder

## 简介

A library that shows only the interfaces of phpunit, without requiring all the dependancies

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
