# php-extended/php-mioga-fgfr-api

> 标签: api, finances.gouv.fr, mioga, php

## 简介

A php API wrapper to connect to mioga.finances.gouv.fr instances

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
