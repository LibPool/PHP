# php-extended/php-mega-nz-api

> 标签: api, client, mega, mega.co.nz, mega.nz, php, wrapper

## 简介

A php API wrapper to connect to mega.nz API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
