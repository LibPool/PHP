# wp-grogu/acf-manager

> 标签: PHP

## 简介

An Object-Oriented library used to create ACF field groups and gutemberg blocks, and retreive the data easily. Requires Wordpress, ACF.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
