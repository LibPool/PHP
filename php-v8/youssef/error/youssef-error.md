# youssef/error

> 标签: debug, debugger, error, error handler, exception, exception handler, fatal

## 简介

Makes handling and debugging PHP errors suck less.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
