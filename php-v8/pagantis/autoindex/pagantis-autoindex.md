# pagantis/autoindex

> 标签: autoindex, index, module, prestashop

## 简介

Generate index.php file in all directories that does not contain index.php file. This is helpful for Prestashop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
