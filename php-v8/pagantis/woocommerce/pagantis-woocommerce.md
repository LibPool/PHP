# pagantis/woocommerce

> 标签: api, checkout, credit, ecommerce, financiación, financiar, financiera, module, pagantis, payment, rest, woocommerce

## 简介

Woocommerce module to add Pagantis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
