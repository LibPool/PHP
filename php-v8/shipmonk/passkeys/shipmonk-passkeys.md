# shipmonk/passkeys

> 标签: Authentication, FIDO2, Passwordless, passkeys, security, webauthn

## 简介

Passkeys (WebAuthn) library for PHP with zero dependencies

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
