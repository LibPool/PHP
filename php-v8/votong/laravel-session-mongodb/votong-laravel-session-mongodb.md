# votong/laravel-session-mongodb

> 标签: driver, laravel, mongo, mongodb, session

## 简介

A MongoDB session driver for Laravel 4, 5, 6, 7 and 8

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
