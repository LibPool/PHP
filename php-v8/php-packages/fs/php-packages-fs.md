# php-packages/fs

> 标签: api, directory, file, filesystem, library

## 简介

File and directory management in PHP 5.5+ done right.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/php-packages/fs.git
