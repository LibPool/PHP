# nerdsnipe/laravel-countries

> 标签: Laravel-Countries, NerdSnipe, country state city dropdown, country state city dynamic dependent dropdown, laravel, laravel city data, laravel country data, laravel state data

## 简介

Used to add country, state, city selectors to any laravel view. Provides all cities and states for 251 countries

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
