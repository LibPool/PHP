# chinleung/laravel-browserstack

> 标签: BrowserStack, automate, chinleung, laravel-browserstack, laravel-dusk, testing

## 简介

Run Laravel Dusk tests on BrowserStack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
