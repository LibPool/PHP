# lucascudo/laravel-pt-br-localization

> 标签: PHP

## 简介

Arquivos de linguagem em Português do Brasil (pt-BR) para Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
