# carteni/crypto-bundle

> 标签: aes, authenticated encryption, cipher, crypto, cryptography, encrypt, encryption, openssl, security, symmetric key cryptography

## 简介

Integrates the "Authenticated Secret-Key Encryption" feature in a symfony project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
