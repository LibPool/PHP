# awehttam/zmodem-php

> 标签: PHP

## 简介

Pure-PHP ZMODEM (sz/rz) file transfer protocol implementation for telnet/SSH-style byte streams.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
