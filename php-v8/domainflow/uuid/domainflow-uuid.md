# domainflow/uuid

> 标签: domainflow, identifier, immutable, php, rfc4122, uuid

## 简介

DomainFlow UUID implementation for versions 1–8, including inspection and validation utilities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
