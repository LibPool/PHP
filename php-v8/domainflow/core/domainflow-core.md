# domainflow/core

> 标签: Microservice, application, bootstrap, dependency injection, domainflow, framework, php, service container

## 简介

A lightweight PHP application bootstrapper with service providers, boot phases, middleware, and config management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
