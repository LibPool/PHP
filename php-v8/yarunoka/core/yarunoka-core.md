# yarunoka/core

> 标签: DSL, business-days, calendar, holidays, occurrence, recurrence, schedule, scheduling

## 简介

Calendar-aware schedule DSL and pure occurrence query engine

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
