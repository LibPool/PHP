# pbaszak/skeleton

> 标签: Skeleton, symfony

## 简介

A minimal project that allows you to quickly create a new project based on Symfony using useful tools: standard-version, php-cs-fixer, phpstan, phpunit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
