# gskema/phpcs-type-sniff

> 标签: gskema, phpcs, phpcs-type-sniff, sniff

## 简介

PHPCS sniff to enforce PHP7 types and array types

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
