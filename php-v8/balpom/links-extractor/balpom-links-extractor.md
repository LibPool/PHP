> 标签: css, extract, extractor, href, html, http, http2, link, parser, parsing, psr-13, psr-7, psr13, psr7, response, src, uri, url

## 简介

Extract all links from string in extended PSR-13 format.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
