> 标签: Guzzle, client, content, download, downloader, facade, file, http, http-client, https, https-client, psr-18, psr18, site, universal, uri, url, web, wrapper

## 简介

Downloads the contents of the specified URI (or file).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
