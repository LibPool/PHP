> 标签: Domain Driven Design, Modelling, abstract, clear, content, data, database, ddd, entity, framework, information, item, model, quant, repository, storage, store, unit, universal

## 简介

Entity is data modelling framework for DDD projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
