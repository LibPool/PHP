# balpom/downloader

> 标签: Simple, client, download, downloader, get, head, http, https, method, post, psr-17, psr-18, psr-7, psr17, psr18, psr7, script, uri, url

## 简介

Downloads the contents of the specified URI through a simple interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
