# gugiman/date-period-parser8601

> 标签: PHP

## 简介

PHP Class for rudimental parsing ob ISO8601 DatePeriods user e.g. by Amazon Alexas Slot type AMAZON.DATE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
