# php-io-extensions/imgdec

> 标签: image-decoding, jpeg, php-ext, png, tiff

## 简介

PNG, JPEG and TIFF into straight RGBA8 in C, through libpng, libjpeg and libtiff

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
