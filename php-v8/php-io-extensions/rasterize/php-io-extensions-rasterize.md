# php-io-extensions/rasterize

> 标签: antialiasing, php-ext, rasterize, scanline, spans

## 简介

Shapes into coverage spans in C: RasterScanner answers paths, ellipses, rings and one-pixel polylines as span bytes, hard-edged or anti-aliased

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
