# php-io-extensions/qt

> 标签: event-loop, gui, linux, php-ext, qt, qt6

## 简介

1:1 PHP bindings of Qt 6 as classes named after their C++ counterparts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
