# php-io-extensions/fb

> 标签: epaper, framebuffer, php-ext, pixels, rgb565

## 简介

Pixel storage in C: FbFormat describes a byte layout, FbBuffer holds one surface in it and reads, writes, converts and copies it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
