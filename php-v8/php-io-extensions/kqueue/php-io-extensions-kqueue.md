# php-io-extensions/kqueue

> 标签: PHP

## 简介

1:1 PHP bindings of kqueue(2): kqueue(), kevent(), kevent64(), EV_SET(), EV_SET64()

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
