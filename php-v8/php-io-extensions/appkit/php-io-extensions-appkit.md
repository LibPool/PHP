# php-io-extensions/appkit

> 标签: appkit, cocoa, gui, macos, php-ext, run-loop

## 简介

1:1 PHP bindings of AppKit and the CoreFoundation run loop it runs on, as classes named after their native counterparts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
