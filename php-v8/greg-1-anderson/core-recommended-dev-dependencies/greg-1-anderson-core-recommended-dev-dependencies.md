# greg-1-anderson/core-recommended-dev-dependencies

> 标签: PHP

## 简介

Pinned require-dev dependencies from drupal/drupal; use in addition to drupal/core-recommended-dependencies to run tests from drupal/core.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
