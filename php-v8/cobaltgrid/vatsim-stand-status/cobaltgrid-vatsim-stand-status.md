# cobaltgrid/vatsim-stand-status

> 标签: flight simulator, stand, stands, vatsim

## 简介

A PHP library to access the status of aircraft stands on VATSIM

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
