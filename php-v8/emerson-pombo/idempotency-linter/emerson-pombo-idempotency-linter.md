# emerson-pombo/idempotency-linter

> 标签: idempotency, jobs, laravel, linter, queue, static-analysis

## 简介

Static analyzer that finds Laravel queue jobs without protection against re-execution (idempotency) before they become production incidents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
