# thomaswelton/gravatarlib

> 标签: gravatar, templating, twig

## 简介

A lightweight PHP 5.3 OOP library providing easy gravatar integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
