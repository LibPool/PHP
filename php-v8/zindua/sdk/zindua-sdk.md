# zindua/sdk

> 标签: api, email, otp, sdk, transactional, whatsapp, zindua

## 简介

Official Zindua SDK for PHP — transactional email and WhatsApp via POST /api/v1/send.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
