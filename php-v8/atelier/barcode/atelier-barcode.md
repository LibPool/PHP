# atelier/barcode

> 标签: CODABAR, EAN-13, EAN-8, ISBN, ITF, ITF-14, UPC-A, UPC-E, barcode, code-128, code-39, code-93, data-matrix, datamatrix, gs1, gs1-128, gs1-datamatrix, interleaved-2-of-5, matrix-code, qr-code, qrcode, svg, vector-graphics

## 简介

PHP library that builds QR codes, matrix codes, and barcodes as SVG, PNG, or GIF

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
