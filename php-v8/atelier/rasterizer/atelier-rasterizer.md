# atelier/rasterizer

> 标签: bitmap, export, png, rasterize, rasterizer, render, resvg, rsvg, svg

## 简介

Rasterize SVG documents to bitmaps through external rendering adapters (resvg, rsvg-convert)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
