# atelier/svg

> 标签: accessibility, animation, filter, gradient, manipulation, morphing, optimization, parser, path, sanitization, svg, transform, validation, vector-graphics

## 简介

PHP library for SVG manipulation, optimization, and morphing: parsing, building, styling, transforms, validation, and sanitization

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
