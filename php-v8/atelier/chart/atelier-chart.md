# atelier/chart

> 标签: accessibility, atelier-svg, chart, charts, data-visualization, graph, php, php-svg, svg

## 简介

Accessible SVG charts for PHP, with typed models, layout, and themes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
