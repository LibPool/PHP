# atelier/field

> 标签: Landscape, Noise, atelier-svg, background, contour, field, generative, halftone, php-svg, procedural, svg, waves

## 简介

Procedural SVG drawings for PHP within a specified area: waves, dunes, mountains, contours, flow, halftone

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
