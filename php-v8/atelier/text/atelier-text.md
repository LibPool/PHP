# atelier/text

> 标签: font, glyph, opentype, svg, text, text-to-path, truetype, vector-graphics, woff, woff2

## 简介

Map Unicode text to positioned font glyphs, vector outlines, and SVG documents using alto/font and atelier/svg.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
