# taitava/silverstripe-eucookielawpopup

> 标签: silverstripe

## 简介

A wrapper for wimagguc/jquery-eu-cookie-law-popup for easy usage in SilverStripe CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
