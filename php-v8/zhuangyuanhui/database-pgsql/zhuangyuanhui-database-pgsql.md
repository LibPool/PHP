# zhuangyuanhui/database-pgsql

> 标签: database, hyperf, pgsql, php, postgresql, swoole

## 简介

A flexible swoole client postgresql database library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
