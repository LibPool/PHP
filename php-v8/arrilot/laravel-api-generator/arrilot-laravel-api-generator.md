# arrilot/laravel-api-generator

> 标签: api, fractal, generator, rest

## 简介

Two simple tools for building REST APIs with fractal: console generator and API skeleton

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
