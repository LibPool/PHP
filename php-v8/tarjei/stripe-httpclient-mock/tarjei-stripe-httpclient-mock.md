# tarjei/stripe-httpclient-mock

> 标签: PHP

## 简介

Mock of Stripe's HttpClient which can be used in testing purposes in order to test your code and not to perform actual HTTP requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
