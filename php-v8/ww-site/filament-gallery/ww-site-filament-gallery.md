# ww-site/filament-gallery

> 标签: filament, filamentphp, file-upload, gallery, laravel, media

## 简介

Reusable Filament gallery plugin for media source browsing and picking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
