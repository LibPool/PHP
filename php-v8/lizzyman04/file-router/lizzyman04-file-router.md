# lizzyman04/file-router

> 标签: file-based-routing, filesystem, nextjs, php, router, routing

## 简介

Next.js-style file-based routing for PHP. Zero dependencies, framework-agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
