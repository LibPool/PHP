> 标签: PHPStan, Pint, defaults, larastan, laravel, rector

## 简介

An opinionated starting configuration for Laravel, with Pint, PHPStan, Rector, and customizable application defaults.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
