# ileva/sdk-api-v3-auth

> 标签: ileva, oauth, redis, sdk, token

## 简介

Autenticação na API Ileva v3: gera o token de acesso e mantém sua validade, com cache compartilhado em Redis.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
