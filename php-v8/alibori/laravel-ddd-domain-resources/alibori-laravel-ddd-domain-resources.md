# alibori/laravel-ddd-domain-resources

> 标签: alibori, laravel, laravel-ddd-domain-resources

## 简介

Package to generate domain resources for a Laravel DDD application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
