# nightowl/agent

> 标签: Agent, laravel, monitoring, nightwatch, telemetry

## 简介

NightOwl monitoring agent — collects telemetry from laravel/nightwatch and writes to PostgreSQL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
