# mahmoudtr/snowflake-for-laravel

> 标签: MahmoudTR, distributed-id, eloquent, id-generator, laravel, redis, snowflake, snowflake-for-laravel, snowflake-id, sortable-id

## 简介

Distributed, time-sortable 64-bit Snowflake IDs for Laravel with Redis coordination and Eloquent integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
