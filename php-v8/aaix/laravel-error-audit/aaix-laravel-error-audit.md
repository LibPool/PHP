# aaix/laravel-error-audit

> 标签: Audit, ai, error-reporting, laravel, logs, monitoring

## 简介

AI-assisted daily audit of Laravel log errors and warnings, delivered by email.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
