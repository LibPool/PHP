# aaix/laravel-islands-search

> 标签: PHP

## 简介

A keyboard-driven global search modal built on Laravel Islands and Laravel Scout, with an optional Filament panel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
