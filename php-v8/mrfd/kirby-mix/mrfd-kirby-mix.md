# mrfd/kirby-mix

> 标签: kirby3, kirby3-cms, kirby3-plugin

## 简介

Laravel Mix integration for Kirby 3, which hooks into the existing helper functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
