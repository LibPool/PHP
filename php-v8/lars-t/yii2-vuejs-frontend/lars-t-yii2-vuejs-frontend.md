# lars-t/yii2-vuejs-frontend

> 标签: extension, vue, vuejs, yii2, yii2-vuejs

## 简介

Yii2 Vuejs frontend drop-in replacement, no more need for pjax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
