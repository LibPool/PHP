# ali-translator/url-template

> 标签: ALI, sli, template, url, url-template

## 简介

Helping on work with template url, example: "{country}.example.com/{language}/{city}"

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
