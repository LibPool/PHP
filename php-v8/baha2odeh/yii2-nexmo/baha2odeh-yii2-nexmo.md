# baha2odeh/yii2-nexmo

> 标签: nexmo, sms, yii2

## 简介

Yii2 nexmo is a wrapper for the Nexmo PHP library. Allow yii2 application to use nexmo services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
