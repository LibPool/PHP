# barefootjs/php

> 标签: PHP

## 简介

Engine-agnostic PHP runtime for BarefootJS -- the shared BarefootJS.php runtime the Twig, Blade, and other PHP engine adapters bind as a pluggable backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
