# ako/gateway

> 标签: Bank, Meli, Payline, asan-pardakht, dargah, gateway, ipay, iran, iranian-banks, jahanpay, laravel, mellat, next-pay, pardakht, parsian, pasargad, pay, pay-ir, payment, paypal, persian-banks, poolport, port, sadad, saman, shaparak, zarinpal

## 简介

Connect to Iran payment gateways through PHP(laravel).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
