# basementdevs/filament-webhooks

> 标签: Basement Developers, filament-webhooks, laravel

## 简介

A Filament plugin to log and inspect inbound webhooks in your admin panel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
