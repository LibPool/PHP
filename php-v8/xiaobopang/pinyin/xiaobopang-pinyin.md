# xiaobopang/pinyin

> 标签: PHP

## 简介

汉字转带有声调的汉语拼音，汉字转无声调的汉语拼音，汉字转成汉语拼音首字母

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
