# igorsantos07/yii-prefixed-url

> 标签: prefix, routing, url, yii

## 简介

Provides ability to include prefixes in URLs for external routing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
