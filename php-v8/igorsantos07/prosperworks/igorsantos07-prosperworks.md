# igorsantos07/prosperworks

> 标签: Guzzle, api-sdk, crm, prosperworks, sdk

## 简介

Unofficial (but pretty decent) SDK for the ProsperWorks CRM API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
