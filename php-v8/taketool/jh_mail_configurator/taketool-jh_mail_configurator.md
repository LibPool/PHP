# taketool/jh_mail_configurator

> 标签: PHP

## 简介

Temporarily change mail configuration to use another mailer than configured in install tool.Includes a validator to validate and test new mail configuration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
