# taketool/powermailextender

> 标签: PHP

## 简介

Add a finisher: If formuser is from t-online.de there is a problem sending the mail to receiver. So let the receiver know about the message.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
