# mamis/phpcs-coding-standard

> 标签: Coding Standard, Mamis, phpcs

## 简介

Mamis CodeSniffer ruleset for PHP Applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
