# mrsuh/php-var-sizeof

> 标签: memory_usage, sizeof, var_class_sizeof, var_sizeof

## 简介

Provides functions for getting full size of any PHP variable

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
