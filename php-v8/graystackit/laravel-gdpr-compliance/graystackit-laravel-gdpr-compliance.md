# graystackit/laravel-gdpr-compliance

> 标签: compliance, consent, data-protection, dsgvo, gdpr, laravel, privacy

## 简介

GDPR/DSGVO compliance toolkit for Laravel applications: consent, data export, erasure, legal hold, audit logging and package inventory.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
