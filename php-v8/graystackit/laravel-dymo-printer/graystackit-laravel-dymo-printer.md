> 标签: alpine, dymo, dymo-connect, label, laravel, livewire, printer, printing

## 简介

A Laravel package for DYMO LabelWriter integration with Alpine.js and Livewire support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
