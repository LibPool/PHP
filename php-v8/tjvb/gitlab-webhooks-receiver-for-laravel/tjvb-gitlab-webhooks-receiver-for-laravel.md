# tjvb/gitlab-webhooks-receiver-for-laravel

> 标签: gitlab, laravel, tjvb, webhook

## 简介

Receive webhooks from GitLab and store the data in the database.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
