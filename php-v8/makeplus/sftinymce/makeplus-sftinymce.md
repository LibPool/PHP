# makeplus/sftinymce

> 标签: asset-mapper, bundle, filestorage, richtext, symfony, symfony7.4, tinymce, wysiwyg

## 简介

Bundle Symfony 7.4 para integrar TinyMCE con gestor de archivos y AssetMapper.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
