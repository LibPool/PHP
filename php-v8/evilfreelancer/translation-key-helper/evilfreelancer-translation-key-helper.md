# evilfreelancer/translation-key-helper

> 标签: helper, laravel, package

## 简介

Laravel plugin for displaying translation key inside HTML comments nearby text strings.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
