# christhompsontldr/laravel-rng

> 标签: RNG, deterministic, laravel, random, seeded

## 简介

Deterministic, stream-isolated RNG for Laravel using PHP native Random extension

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
