# peekphp/peek

> 标签: boilerplate, package, php

## 简介

A package to ask any AI Client to give detailed answer of improvements on PHP files/snippets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/peekphp/peek.git
