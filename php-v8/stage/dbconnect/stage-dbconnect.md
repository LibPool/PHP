# stage/dbconnect

> 标签: Connection, connect, database, db, mysqli, php, stage framework

## 简介

MySQLi connection class for Stage Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
