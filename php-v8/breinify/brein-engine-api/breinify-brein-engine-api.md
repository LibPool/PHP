# breinify/brein-engine-api

> 标签: brein engine, breinify, collective intelligence

## 简介

A PHP library to exchange data through the API of the Brein Engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
