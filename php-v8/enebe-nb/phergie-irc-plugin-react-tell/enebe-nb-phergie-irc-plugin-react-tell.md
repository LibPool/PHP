# enebe-nb/phergie-irc-plugin-react-tell

> 标签: bot, irc, plugin, react

## 简介

Phergie plugin for send messages to users next time they are seen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
