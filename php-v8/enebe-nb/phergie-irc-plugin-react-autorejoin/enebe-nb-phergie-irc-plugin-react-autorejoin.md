# enebe-nb/phergie-irc-plugin-react-autorejoin

> 标签: bot, irc, plugin, react

## 简介

Phergie plugin for automatically rejoining IRC channels on PART or KICK event.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
