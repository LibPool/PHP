# innovativesprouts/laravel-semaphore

> 标签: laravel, notifications, otp, philippines, semaphore, sms

## 简介

A modern Laravel client and notification channel for the Semaphore SMS API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
