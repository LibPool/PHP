# hexydec/jslite

> 标签: JS, compiler, javascript, minifier, minify, parser

## 简介

A token based Javascript parser/minifier designed for compressing inline scripts on the fly, written in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
