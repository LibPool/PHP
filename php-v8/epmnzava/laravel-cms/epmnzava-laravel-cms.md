# epmnzava/laravel-cms

> 标签: cms, epmnzava, laravel-cms

## 简介

A laravel library to help you quickly gets started with cms items (menus,blog and pages)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
