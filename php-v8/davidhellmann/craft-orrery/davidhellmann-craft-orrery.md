# davidhellmann/craft-orrery

> 标签: Craft, cms, content model, craft-plugin, craftcms, fields, matrix, project config

## 简介

A live map of your Craft CMS content model: where content lives, what it’s made of, and how it all connects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
