# laratrist/laravel-royalty

> 标签: laratrist, laravel, loyalty-points, royalty, user-experience-points, user-points, user-rewards-points

## 简介

A user points package for Laravel that can be used to give rewards, loyalty or experience points with real time support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
