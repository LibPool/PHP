# kemel91/laravel-tarantool

> 标签: db, eloquent, eloquent-tarantool, laravel, orm, tarantool

## 简介

A Tarantool based Eloquent ORM and Query builder for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
