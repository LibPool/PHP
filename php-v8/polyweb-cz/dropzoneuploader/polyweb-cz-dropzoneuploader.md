# polyweb-cz/dropzoneuploader

> 标签: dropzone, multiupload, nette

## 简介

Dropzone Uploader for Nette Framework and DropzoneJs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
