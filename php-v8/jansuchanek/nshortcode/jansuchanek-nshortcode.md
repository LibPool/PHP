# jansuchanek/nshortcode

> 标签: PHP

## 简介

Universal shortcode parser for Nette — [prefix:args] syntax with registered handlers, Latte filter, DI extension

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
