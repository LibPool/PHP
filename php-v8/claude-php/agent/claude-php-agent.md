# claude-php/agent

> 标签: Agent, Multi-agent, agentic, ai, anthropic, autonomous-agents, chain-of-thought, claude, llm, plan-execute, rag, react, reflection, tool-use

## 简介

A powerful PHP framework for building AI agents with Claude, featuring ReAct loops, tool orchestration, and advanced agentic patterns

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
