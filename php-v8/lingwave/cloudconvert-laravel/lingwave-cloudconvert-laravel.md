# lingwave/cloudconvert-laravel

> 标签: cloudconvert, conversion, documents, laravel, laravel8, office, screenshot

## 简介

A Laravel wrapper for the CloudConvert API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
