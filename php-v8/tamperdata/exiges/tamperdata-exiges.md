# tamperdata/exiges

> 标签: degree, exiges, library, number, php, tamperdata, tiago-perrelli

## 简介

A simple php library to generate and convert degree numbers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
