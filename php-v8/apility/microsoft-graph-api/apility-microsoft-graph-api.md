# apility/microsoft-graph-api

> 标签: api, graph, laravel, microsoft, package

## 简介

This package provides a PHP client library for working with the Microsoft Graph API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
