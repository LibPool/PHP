# apility/laravel-vite-components

> 标签: PHP

## 简介

A Vite companion library for Laravel to be used together with @apility/vite-plugin-dev-manifest.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
