# masterjoa/htmlpurifier-html5

> 标签: PHP

## 简介

Load standalone HTMLPurifier with support for HTML5, TinyMCE, YouTube, Video

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
