# tiden/telemetry-php

> 标签: error-tracking, php, sdk, tiden

## 简介

Tiden error-tracking PHP SDK. Emits the envelope wire format to a Tiden ingest endpoint, with no third-party error-SDK dependency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
