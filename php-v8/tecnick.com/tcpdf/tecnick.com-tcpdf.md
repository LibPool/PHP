# tecnick.com/tcpdf

> 标签: PDFD32000-2008, TCPDF, barcodes, datamatrix, pdf, pdf417, qrcode

## 简介

Deprecated legacy PDF engine for PHP. Use instead tecnickcom/tc-lib-pdf.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
