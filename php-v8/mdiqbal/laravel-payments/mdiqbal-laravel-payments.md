# mdiqbal/laravel-payments

> 标签: gateway, laravel, payment, paypal, razorpay, stripe

## 简介

A unified payment gateway package for Laravel supporting 21+ payment providers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
