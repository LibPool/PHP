# gino-pane/php-ssh

> 标签: libssh2, ssh, ssh2

## 简介

Provides an object-oriented wrapper for the PHP SSH2 extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
