# gino-pane/nano-rest

> 标签: http, http client, minimalistic, nano rest, php rest, rest, rest client

## 简介

Minimalistic and self-contained cURL HTTP REST client for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
