# swinde/contao4-downloadarchive

> 标签: archive, download, permission

## 简介

Es werden Downloadarchive definiert, die es Benutzern erlauben, einzelne Dateien herunterzuladen.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
