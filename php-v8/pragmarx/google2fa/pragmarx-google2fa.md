# pragmarx/google2fa

> 标签: 2fa, Authentication, MFA, Two Factor Authentication, google-authenticator, google2fa, hotp, otp, rfc4226, rfc6238, totp

## 简介

A One Time Password Authentication package, compatible with Google Authenticator.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
