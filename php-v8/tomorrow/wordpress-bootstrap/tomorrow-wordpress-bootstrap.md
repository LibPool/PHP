# tomorrow/wordpress-bootstrap

> 标签: timber, twig, wordpress

## 简介

A WordPress bootstrap for Tomorrow Studio projects using Timber/Twig

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
