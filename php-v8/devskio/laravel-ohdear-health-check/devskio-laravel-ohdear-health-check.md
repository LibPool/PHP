# devskio/laravel-ohdear-health-check

> 标签: devskio, health-check, laravel, laravel-ohdear-health-check, ohdear

## 简介

A Laravel package to perform health checks for Oh Dear.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
