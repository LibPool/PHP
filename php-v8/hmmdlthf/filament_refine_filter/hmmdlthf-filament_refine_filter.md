# hmmdlthf/filament_refine_filter

> 标签: facet, faceted-search, filament, filter, laravel, refine-search

## 简介

A ScriptCase-style 'Refine Search' facet filter for Filament v5 tables — checkbox facets with live counts for BelongsTo relationships and backed PHP enums.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
