# ahsan-ul-alam/ahsan-all-zkteco-attendance

> 标签: Ahsan Alam, Fingerprint, TimeAttendance, fingerPrintAutomation, zkteco

## 简介

Connect any ZKTeco fingerprint attendance machine to a Laravel application with no effort.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
