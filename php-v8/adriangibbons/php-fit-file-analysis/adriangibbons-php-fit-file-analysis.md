# adriangibbons/php-fit-file-analysis

> 标签: Fit, garmin

## 简介

A PHP class for analysing FIT files created by Garmin GPS devices

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
