# zoclee/flux

> 标签: PHP

## 简介

FluxQ is a unified message broker built for reliability, extensibility, and interoperability, with a pure PHP core and PostgreSQL persistence.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
