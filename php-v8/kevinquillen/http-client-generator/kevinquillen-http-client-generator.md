# kevinquillen/http-client-generator

> 标签: Drush, drupal, drush commands, drush generator

## 简介

Adds Drush command(s) to scaffold out HTTP client(s) for interacting with remote APIs in Drupal modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
