# mrsmn/gitlab-ci-jumpstart

> 标签: PHP

## 简介

The aim of this package is to provide a jumpstart when using Gitlab CI for PHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
