# diezeel/laravel-sphinx

> 标签: Sphinx Eloquent, database, laravel, query builder, sphinx, sphinxql, sql

## 简介

A Laravel query builder for SphinxQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
