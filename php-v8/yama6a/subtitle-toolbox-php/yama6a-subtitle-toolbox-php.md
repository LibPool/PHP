# yama6a/subtitle-toolbox-php

> 标签: OCR, SCC, ass, chapters, cli, converter, lrc, mpsub, parser, pgs, srt, subtitle, transcript, ttml, vobsub, vtt, webvtt, whisper

## 简介

A PHP library and command line tool that reads, edits and writes subtitles, transcripts and chapter lists in more than 30 formats.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
