# yama6a/php-glyph-ocr

> 标签: OCR, bitmap, glyph, png, subtitle edit, text recognition

## 简介

Pure PHP OCR for clean rendered text bitmaps such as image subtitles. A port of the nOCR engine from Subtitle Edit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
