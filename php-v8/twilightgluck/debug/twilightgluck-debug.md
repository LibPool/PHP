# twilightgluck/debug

> 标签: PHP

## 简介

Lightweight Yii2 debugging helper with buffered dumps, call tracing, timers, counters, memory usage, and global shortcut functions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
