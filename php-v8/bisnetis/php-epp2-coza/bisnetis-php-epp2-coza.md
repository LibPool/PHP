# bisnetis/php-epp2-coza

> 标签: client, coza, domains, epp, registrar, registry, tcp

## 简介

A High Level EPP (Extensible Provisioning Protocol) TCP/SSL Client for PHP with COZA Extensions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
