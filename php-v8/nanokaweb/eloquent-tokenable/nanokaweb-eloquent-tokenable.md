# nanokaweb/eloquent-tokenable

> 标签: eloquent, hashids, laravel

## 简介

Allows using tokens (HashIDs) instead of id in Laravel Eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
