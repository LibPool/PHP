# barsmedia/bigbluebutton

> 标签: bigbluebutton, laravel, wrapper

## 简介

Bigbluebutton wrapper for laravel 5.5, 6, 7, 8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
