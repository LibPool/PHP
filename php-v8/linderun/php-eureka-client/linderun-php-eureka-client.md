# linderun/php-eureka-client

> 标签: discovery server, eureka, eureka client, php, php eureka client

## 简介

A PHP client for Spring Cloud Eureka discovery server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
