# prerender/laravel-prerender

> 标签: laravel, middleware, prerender, prerender.io, seo

## 简介

Laravel middleware for prerendering JavaScript-rendered pages via Prerender.io

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
