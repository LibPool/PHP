# yadakhov/insert-on-duplicate-key

> 标签: database, eloquent, mysql

## 简介

A trait for MySQL INSERT ON DUPLICATE KEY UPDATE.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
