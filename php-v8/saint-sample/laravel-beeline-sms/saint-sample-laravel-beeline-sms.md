# saint-sample/laravel-beeline-sms

> 标签: Beeline, laravel, laravel-beeline, laravel-sms, saint-sample, saintsample, sms

## 简介

Light laravel package for sms sending via Beeline API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
