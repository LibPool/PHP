# lsolesen/edbbrugs-php-sdk

> 标签: webservice

## 简介

PHP-SDK for integrating with EDB-BRUGS which is a platform used by the free schools in Denmark for managing students.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
