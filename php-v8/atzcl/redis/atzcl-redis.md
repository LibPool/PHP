# atzcl/redis

> 标签: PHP

## 简介

基于 nrk/predis 封装的 Redis 类，包含 string、hash、list、set、zset 类型的操作

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
