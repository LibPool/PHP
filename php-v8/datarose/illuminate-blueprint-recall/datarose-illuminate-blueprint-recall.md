# datarose/illuminate-blueprint-recall

> 标签: blueprint, change, laravel, migration, preserve, recall

## 简介

A Blueprint macro for Laravel to restore column attribute persistence in migrations. Update only what you need. (Unofficial)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
