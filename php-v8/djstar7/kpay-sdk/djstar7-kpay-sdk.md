# djstar7/kpay-sdk

> 标签: cameroun, freemopay, kpay, laravel, mobile-money, mtn-money, orange-money, payments, sdk

## 简介

SDK officiel KPay (PHP / Laravel) — paiements & retraits Mobile Money, mode USSD ou passerelle hébergée. Sans dépendance imposée.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
