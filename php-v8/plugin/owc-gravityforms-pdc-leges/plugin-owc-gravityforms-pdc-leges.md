# plugin/owc-gravityforms-pdc-leges

> 标签: PHP

## 简介

Haalt automatisch legestarieven op uit een PDC-leges endpoint voor Gravity Forms productvelden.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
