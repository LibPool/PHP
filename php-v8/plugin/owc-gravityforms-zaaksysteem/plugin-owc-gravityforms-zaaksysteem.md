# plugin/owc-gravityforms-zaaksysteem

> 标签: PHP

## 简介

Combine one or more 'zaaksystemen' with Gravity Forms and WordPress

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
