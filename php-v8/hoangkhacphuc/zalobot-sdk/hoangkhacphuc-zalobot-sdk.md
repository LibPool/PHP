# hoangkhacphuc/zalobot-sdk

> 标签: bot, bot-framework, messaging, php, phpunit, psr-18, sdk, webhook, zalo, zalo-bot-api, zalo-sdk, zalobot

## 简介

A lightweight, modular PHP SDK and Webhook handler for Zalo Bot Platform API (bot.zapps.me). Fully typed with PHPDoc and ready for production.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
