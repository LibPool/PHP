# octopus-llm/laravel

> 标签: PHP

## 简介

OpenAI-compatible AI gateway untuk Laravel dengan multi-key rotation, circuit breaker, dan zero-cost free tier management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
