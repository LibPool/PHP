# yuntian001/multi-process-queue

> 标签: PHP

## 简介

基于swoole的多进程队列系统，支持一键协程、多进程、低延时(最低毫秒级)、低资源占用、高可用。可与 laravel thinkphp 等框架配合使用

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
