# subugoe/typo3-cap

> 标签: PHP

## 简介

TYPO3 extension providing CAPTCHA (trycap.dev) bot protection via a PSR-15 middleware and invisible proof-of-work challenge

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
