# mnb/mnb-phpexcel-xlsx

> 标签: PHP

## 简介

Native XLSX reader/writer with password encryption, document protection, formulas, pivots, and low-memory streaming for MNB PHPExcel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
