# mnb/mnb-phpexcel-database

> 标签: PHP

## 简介

PDO imports, domain presets, validation, resumable manifests, and failed-row reporting for MNB PHPExcel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
