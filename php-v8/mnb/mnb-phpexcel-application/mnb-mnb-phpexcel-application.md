# mnb/mnb-phpexcel-application

> 标签: PHP

## 简介

Facade, workbook builder, application helpers, plugins, diagnostics, and full workflow API for MNB PHPExcel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
