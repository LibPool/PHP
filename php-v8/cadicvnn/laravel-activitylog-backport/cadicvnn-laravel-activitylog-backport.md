# cadicvnn/laravel-activitylog-backport

> 标签: activity, backport, laravel, linearsoft, log, spatie, user

## 简介

A backport of Spatie's Laravel-ActivityLog to PHP 5.6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
