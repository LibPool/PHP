# cywolf/semantic-suggestion-solr

> 标签: knn, mlt, more-like-this, recommendations, related-content, semantic-search, solr, tx-news, typo3, vector-search

## 简介

TYPO3 extension for suggesting semantically related content using Solr More Like This (MLT) and Semantic More Like This (SMLT)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
