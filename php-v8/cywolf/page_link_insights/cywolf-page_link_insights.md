# cywolf/page_link_insights

> 标签: PHP

## 简介

Maps internal linking from the TYPO3 reference index and draws it as an interactive force diagram, with per-language theme extraction and broken link detection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
