# orca-services/cakephp-heartbeat

> 标签: cakephp, heartbeat, plugin, sensor, status

## 简介

A CakePHP plugin providing an application heartbeat status page with configurable sensors

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
