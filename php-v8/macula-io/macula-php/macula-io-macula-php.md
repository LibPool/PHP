# macula-io/macula-php

> 标签: ffi, macula, mesh, post-quantum, pubsub, quic, rpc

## 简介

PHP client for the macula mesh: FFI over macula-go's released libmacula (calls and streams by direct dial, serving, pubsub, node-served content, the DHT)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
