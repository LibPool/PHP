# internal/path

> 标签: cross-platform, file, filepath, filesystem, helper, path, unix, windows

## 简介

Type-safe, immutable file path library with cross-platform support and automatic normalization.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
