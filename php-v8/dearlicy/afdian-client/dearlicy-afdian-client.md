# dearlicy/afdian-client

> 标签: afdian, php, sdk

## 简介

PHP SDK for interacting with the Afdian API, including order and sponsor information retrieval.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
