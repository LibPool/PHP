# modul-is/generator

> 标签: generator, nette, php

## 简介

Generates entities, repositories, presenters, templates, dials, forms and grids from DB table to given Module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
