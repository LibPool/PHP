# anatolkin/anatolkin-mosaic-gallery

> 标签: art, fal, gallery, glightbox, images, lightbox, masonry, mosaic, photo, typo3

## 简介

Anatolkin Mosaic Gallery - Flexible FAL image galleries for TYPO3 CMS 13.4 and 14.3 with multiple responsive layouts, metadata tools, design controls, and optional GLightbox.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
