# patchlevel/rango

> 标签: document database, jsonb, mongodb, patchlevel, postgres, postgresql

## 简介

A high-performance reimplementation of the MongoDB PHP API on top of PostgreSQL JSONB

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
