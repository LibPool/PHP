# patchlevel/odm

> 标签: hydrator, mongodb, odm, patchlevel, postgres, rango

## 简介

A lightweight Object Document Mapper for PHP that runs on both MongoDB and PostgreSQL with one consistent API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
