# patchlevel/event-sourcing

> 标签: Domain Driven Design, aggregates, cqrs, dcb, ddd, dynamic consistency boundary, event driven, event-sourcing, events, message driven, messages, patchlevel, processor, projection

## 简介

A lightweight but also all-inclusive event sourcing library with a focus on developer experience

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
