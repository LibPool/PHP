# postalservice14/php-actuator

> 标签: actuator, health, healthcheck

## 简介

PHP port of Spring Actuator which provides an easy health checking capability of services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
