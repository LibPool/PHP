# wiphi/contao-dielosungen

> 标签: Die Losungen, Herrnhuter Losung, contao, module

## 简介

Importiere die Herrnhuter Losung in Contao und zeige sie im Frontend an.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
