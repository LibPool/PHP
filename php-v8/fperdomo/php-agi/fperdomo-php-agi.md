# fperdomo/php-agi

> 标签: agi, ami, asterisk, callcenter, fastagi, ivr, phpagi, telephony, voip

## 简介

Modern PHP 8.4+ fork of PHPAGI for building Asterisk AGI, FastAGI, and AMI integrations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
