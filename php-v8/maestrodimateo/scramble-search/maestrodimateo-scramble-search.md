# maestrodimateo/scramble-search

> 标签: api, documentation, laravel, openapi, scramble, search

## 简介

Adds a keyboard-driven route search palette (Ctrl+K) to Scramble API docs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
