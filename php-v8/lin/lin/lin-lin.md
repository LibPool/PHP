# lin/lin

> 标签: framework, lin, orm, server

## 简介

高性能、全组件化、极简主义php7.2框架

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://www.lin-php.com
- 源码仓库：https://github.com/linlanye/lin.git
- Packagist 页面：https://packagist.org/packages/lin%2Flin

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require lin/lin`
- Packagist 仓库：https://repo.packagist.org/p2/lin/lin.json
- 许可证：Apache-2.0
- PHP 要求：>=7.2.0
