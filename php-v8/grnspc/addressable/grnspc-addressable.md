# grnspc/addressable

> 标签: PHP

## 简介

Laravel Addressable is a polymorphic Laravel package, for addressbook management. You can add addresses to any eloquent model with ease.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
