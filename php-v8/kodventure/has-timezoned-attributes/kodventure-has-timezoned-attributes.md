# kodventure/has-timezoned-attributes

> 标签: PHP

## 简介

Automatically adds *_tz attributes to Eloquent models for timestamp fields, based on the user's or application's timezone.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
