# masterkey/payment

> 标签: Checkout Transparente, Pagseguro, api

## 简介

Biblioteca para envio de pagamentos para o PagSeguro utilizando a API de checkout Transparente

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
