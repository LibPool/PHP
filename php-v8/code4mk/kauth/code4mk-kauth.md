# code4mk/kauth

> 标签: 0devco, api, auth, code4mk, jwt, jwt-auth, laravel, laravel-jwt

## 简介

kauth is JWT API Authentication ( jwt-auth ) for laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
