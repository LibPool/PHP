# me-io/appium-selenium-starter

> 标签: android-testing, appium, boilerplate, ios-testing, mobile-testing, selenium, test, testing, unit, unit-testing

## 简介

Simple and easy to use boilerplate for writing tests for mobile or web.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
