# bitapps/wp-ai-kit

> 标签: abilities, ai, mcp, oauth, wordpress

## 简介

Shared MCP server and AI assistant infrastructure for Bit Apps WordPress plugins. Plugins contribute domain tools; the kit provides the transport, authorization, OAuth 2.1, AI engines and the bridges to WordPress-native Abilities, MCP Adapter and AI Client APIs when present.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
