# acelle/aws-whitelabel

> 标签: PHP

## 简介

Hide AWS SES branding on customer-facing DKIM records by chaining CNAMEs through your own Route53-hosted brand domain.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
