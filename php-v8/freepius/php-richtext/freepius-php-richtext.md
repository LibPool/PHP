# freepius/php-richtext

> 标签: markdown, pimple, silex, twig

## 简介

A simple wrapper (and more) allowing to use Markdown(Extra) and SmartyPants(Typographer)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
