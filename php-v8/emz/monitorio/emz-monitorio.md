# emz/monitorio

> 标签: PHP

## 简介

Monitorio companion plugin for Shopware 6: read-only monitoring endpoints polled via the Admin API (shop logs, log volume, message queue backlog, disk space), JS error tracking loader for the storefront, and stock event push to the Monitorio ingest.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
