# asignua/filament-spreadsheet-grid

> 标签: bulk-edit, filament, filament-plugin, grid, inline-edit, laravel, spreadsheet, table

## 简介

Edit a Filament 5 table the way people edit a spreadsheet: arrow-key navigation, typing over a cell, mouse and Shift range selection, copy and paste TSV blocks from Excel, Google Sheets or LibreOffice, fill down and right, text/number/select/date/boolean cells, inline per-cell validation, dirty-cell highlighting and one "Save all" in a single transaction with per-row errors. Keeps your query, filters, pagination, policies and write path.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
