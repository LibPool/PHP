# asignua/filament-kanban

> 标签: board, drag-and-drop, filament, filament-plugin, kanban, laravel, sortable

## 简介

A drag-and-drop Kanban board for Filament 5: enum or database columns, reorder that respects filtered cards, transition modals, authorization, collapsible columns and a migration path from mokhosh/filament-kanban.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
