# asignua/filament-translation-manager

> 标签: filament, filament-plugin, filament-translation-manager, i18n, laravel, localization, spatie, translation-manager, translations

## 简介

Database-backed translation manager for Filament 5: edit, search, scan and quick-translate every __() string per locale, with a topbar language switcher. Successor of kenepa/translation-manager, built on spatie/laravel-translation-loader.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
