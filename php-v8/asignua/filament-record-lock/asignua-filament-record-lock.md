# asignua/filament-record-lock

> 标签: concurrent-editing, filament, filament-plugin, laravel, pessimistic-locking, record-lock, resource-lock

## 简介

Pessimistic record locking for Filament 5: one editor per record, a heartbeat, a blocking notice, gated takeover and a lock manager. The maintained successor of kenepa/resource-lock.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
