# asignua/filament-image-annotations

> 标签: annotations, drawing, filament, filament-5, filament-plugin, file-upload, image, image-annotation, laravel, markup, spatie-media-library

## 简介

Non-destructive vector annotations for Filament 5: arrows, rectangles, ellipses, lines, a pen, a highlighter and text drawn over an image as a separate JSON layer, with an editor, a read-only viewer and an Annotate button for uploads. The original file is never modified.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
