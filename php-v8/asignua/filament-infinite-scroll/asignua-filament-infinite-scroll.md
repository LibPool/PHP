# asignua/filament-infinite-scroll

> 标签: filament, filament-plugin, infinite-scroll, laravel, load-more, pagination, table

## 简介

Infinite scroll and a "Load more" button for Filament 5 tables with one line: ->infiniteScroll(). Works in resources, relation managers, table widgets and any page with InteractsWithTable; filters, search, sorting and bulk selection keep working while the table grows. Configurable chunk size, a record ceiling and how early the next chunk is requested.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
