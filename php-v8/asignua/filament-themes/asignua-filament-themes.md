# asignua/filament-themes

> 标签: dark-mode, filament, filament-plugin, filament-themes, laravel, theme-switcher, themes

## 简介

Theme switcher for Filament 5: pick a theme and a primary colour per user or for the whole panel. Six built-in light and dark themes, your own as plain PHP classes. Successor of hasnayeen/themes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
