# asignua/filament-json-yaml-editor

> 标签: codemirror, filament, filament-plugin, json, json-editor, json-schema, laravel, yaml, yaml-editor

## 简介

JSON and YAML editing for Filament 5: a JsonEditor field with a code view (highlighting, line numbers, folding) and an editable tree view, live validation with the error line, a Format button and optional JSON Schema; a YamlEditor field with live lint; read-only JsonEntry and YamlEntry for infolists with copy; and server-side JsonRule, YamlRule (symfony/yaml) and JsonSchemaRule.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
