# asignua/filament-rich-editor-toolkit

> 标签: accessibility, alt-text, caption, character-count, embed, filament, filament-plugin, fullscreen, html-source, iframe, image, image-alignment, laravel, link, nofollow, noopener, paste, paste-images, rel, rich-editor, source-code, sticky-toolbar, strict-paste, tiptap, word, word-count

## 简介

Ten independent plugins for the Filament 5 RichEditor (TipTap): PasteCleanPlugin removes Word and Google Docs junk (mso-* styles, fonts, colour spans), can upload the pictures of such a paste instead of dropping them (SSRF-guarded) and, in strict mode, cuts a paste down to the field's toolbar, LinkOptionsPlugin sets rel (nofollow, sponsored, ugc) and new-tab options on links, CustomAttributesPlugin keeps class, id, style and data-* attributes both in the browser and through the server sanitizer, EmbedPlugin allows safe iframe and video embeds from an allow-list, ImageUrlPlugin inserts an image by URL, ImagePropertiesPlugin adds alt text (with decorative images), captions and alignment to images, FullscreenPlugin adds a fullscreen mode, SourceCodePlugin adds an HTML source view, CharacterCountPlugin and the RichTextLength rule count and limit plain-text characters and words, and StickyToolbarPlugin keeps the toolbar visible on long content, even inside sections, tabs and repeaters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
