# asignua/filament-iban

> 标签: Bank, IBAN, filament, filament-plugin, laravel, validation

## 简介

IBAN input, validation rule, infolist entry and table column for Filament 5: grouped display, compact storage, SWIFT registry checks for every IBAN country and bank names for Ukraine and Poland.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
