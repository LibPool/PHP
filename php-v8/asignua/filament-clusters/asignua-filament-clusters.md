# asignua/filament-clusters

> 标签: filament, filament-plugin, laravel

## 简介

Group several Filament 5 fields into one input row with a shared label, joined borders and a shared focus ring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
