# asignua/filament-mail-log

> 标签: Audit, email-log, filament, filament-plugin, laravel, mail, mail-log

## 简介

Read-only log of every outgoing Laravel mail for Filament 5: status tracking across the queue, secrets redacted before storing, sandboxed preview.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
