# asignua/filament-translatable-fields

> 标签: Repeater, filament, filament-plugin, i18n, laravel, multilingual, spatie, translatable

## 简介

Per-field language tabs for spatie/laravel-translatable in Filament 5. Every locale is a real input in the form state at the same time, so translations survive Repeater, Builder, ->relationship() repeaters, settings pages and custom pages without a model. No global locale switcher that loses repeater data, validation runs for every language, plus table columns and infolist entries that show the current language with a fallback to the default and any filled one.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
