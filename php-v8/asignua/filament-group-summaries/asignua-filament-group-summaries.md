# asignua/filament-group-summaries

> 标签: filament, filament-plugin, grouping, laravel, summaries, table

## 简介

Column summaries (Sum, Average, Count, Range, Values or custom) printed in the group header row of Filament 5 tables, so they stay visible when the group is collapsed and respect filters and search; per-group control of the summary row Filament draws after each group; and a default sort direction per group. SummaryGroup extends Filament's Group, so it is a drop-in replacement; no Filament view is forked.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
