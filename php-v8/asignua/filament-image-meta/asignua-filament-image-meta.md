# asignua/filament-image-meta

> 标签: a11y, accessibility, alt-text, filament, filament-plugin, file-upload, focal-point, laravel, media-library, seo

## 简介

Per-file alt text (per locale), a decorative flag, caption, title and focal point for Filament 5's own FileUpload and SpatieMediaLibraryFileUpload — one wrapper around the upload you already have, no media library to adopt. A missing alt is reported (form badge, optional validation, data attribute) and never replaced by the file name; an accessible Blade <img> component renders alt, caption and the focal point as object-position.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
