# asignua/filament-toggle-icon-column

> 标签: column, filament, filament-plugin, icon, laravel, table, toggle

## 简介

A clickable icon column that toggles a boolean in place for Filament 5 tables and relation managers: the successor of archilex/filament-toggle-icon-column.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
