# onedrop/solr-extbase

> 标签: TYPO3 CMS, extbase, search, solr, typo3

## 简介

Extbase indexing addition to Apache Solr for TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
