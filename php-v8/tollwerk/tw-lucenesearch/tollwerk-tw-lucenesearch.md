# tollwerk/tw-lucenesearch

> 标签: PHP

## 简介

Simple and lightweight implementation of the Apache Lucene Index as frontend search solution for TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
