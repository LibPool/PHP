# aaron-apelt/akeneo-php-lib

> 标签: PIM, akeneo, api, client, ecommerce

## 简介

An extension of the Akeneo PHP API client for easier Akeneo service development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
