# souplette/fusbup

> 标签: PSL, Public Suffix List, cookie, domain, effective tld, etld, icann, tld, top level domain

## 简介

A fast & memory-efficient interface to the Mozilla Public Suffix List.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
