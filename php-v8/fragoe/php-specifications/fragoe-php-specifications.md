# fragoe/php-specifications

> 标签: PHP

## 简介

Specification pattern by Eric Evans and Martin Fowler (2002, "Specifications", martinfowler.com/apsupp/spec.pdf).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
