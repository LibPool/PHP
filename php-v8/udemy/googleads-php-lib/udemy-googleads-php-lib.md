# udemy/googleads-php-lib

> 标签: PHP

## 简介

Google Ads APIs Client Library for PHP (AdWords, Adx, and DFP)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
