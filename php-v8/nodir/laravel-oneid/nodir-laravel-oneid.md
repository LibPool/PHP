> 标签: SSO, Uzbekistan, egov, jwt, laravel, oauth, oneid, rbac

## 简介

O'zbekiston OneID (EGov SSO) OAuth integratsiyasi Laravel uchun. JWT autentifikatsiya, RBAC, auto user registration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
