# maruamyu/web-app-lib

> 标签: OpenId, http, jwt, oauth, oauth2, psr-7, request, response, ulid

## 简介

simple and useful library for web application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
