# newsletter2go/api

> 标签: api, client, newsletter2go, rest

## 简介

PHP API implementation of the Newsletter2Go REST API (https://docs.newsletter2go.com/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
