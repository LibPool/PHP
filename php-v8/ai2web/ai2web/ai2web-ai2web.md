# ai2web/ai2web

> 标签: agentic-web, agents, ai, ai2w, ai2web, manifest, mcp, protocol

## 简介

AI2Web (ai2w) PHP SDK - capability model, manifest builder, validator, negotiation, server handler.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
