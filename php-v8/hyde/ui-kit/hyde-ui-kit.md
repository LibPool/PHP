# hyde/ui-kit

> 标签: Hyde, blade, hydephp, laravel, ui-kit

## 简介

A set of minimalistic Blade & Tailwind components to kickstart development of your HydePHP site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
