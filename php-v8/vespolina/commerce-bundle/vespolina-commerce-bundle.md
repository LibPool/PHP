# vespolina/commerce-bundle

> 标签: ecommerce, item, shop, store, vespolina

## 简介

Vespolina Commerce bundle. Integrates vespolina libraries with Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
