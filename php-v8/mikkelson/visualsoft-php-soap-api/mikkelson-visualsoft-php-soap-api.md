# mikkelson/visualsoft-php-soap-api

> 标签: api, php, soap, visualsoft

## 简介

PHP SOAP bindings for the Visualsoft V3 API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
