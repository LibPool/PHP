# zhitoo/laravel-hls-converter

> 标签: converter, ffmpeg, hls, laravel, video

## 简介

Laravel package for converting videos to HLS format using the HLS Converter microservice

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
