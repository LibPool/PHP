# thaikolja/nominal-ai-provider-for-opencode

> 标签: ai, connector, llm, opencode, wordpress

## 简介

AI Provider for OpenCode for the PHP AI Client SDK. Works as both a Composer package and WordPress plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
