# phprivoxy/proxy

> 标签: high-performance, http, http-proxy, https, https-proxy, php, php-proxy, phprivoxy, privoxy, proxy, ssl, ssl-proxy

## 简介

Core library for HTTP/HTTPS proxy building.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
