# phprivoxy/x509

> 标签: authority, ca, certificate, certificates, certification, crt, https, key, open-ssl, openssl, pem, self-signed, selfsigned, ssl, x-509, x509

## 简介

Easy X.509 self-signed certificate creation (without OpenSSL).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
