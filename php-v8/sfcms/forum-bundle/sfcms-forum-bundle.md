# sfcms/forum-bundle

> 标签: bundle, sfcms, story

## 简介

Module allowing you to create a forum. Each forum will be made up of several topics, in which there will be comments, shares and likes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
