# io/export-fixed

> 标签: PHP

## 简介

Fixed-width record files for io-export: #[Fixed] column layouts, Windows-1252 or EBCDIC, for legacy-system interfaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
