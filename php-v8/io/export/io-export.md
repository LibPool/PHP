# io/export

> 标签: PHP

## 简介

Table downloads for Io: return a Sheet from a route and get CSV, JSON Lines, HTML, XML, XLSX or ODS, streamed row by row.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
