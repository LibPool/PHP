# io/charts

> 标签: PHP

## 简介

Server-rendered SVG charts for Io: bar and line charts with a data table, legend and accessible markup, tooltips as a progressive enhancement.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
