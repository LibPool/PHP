# wanecho/tron-api

> 标签: iexbase, tron-api, tron-lib, tron-php, tron-rest-api

## 简介

A PHP API for interacting with Tron (Trx)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
