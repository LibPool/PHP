# yii2-extensions/filepond

> 标签: cropper, cropperjs, file-upload, filepond, image-crop, image-upload, widget, yii2, yii2-extension

## 简介

FilePond file upload widget for Yii2 with Cropper.js image editing, previews, validation plugins, and server-side helpers for encoded uploads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
