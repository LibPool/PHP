# yii2-extensions/bootstrap6

> 标签: bootstrap, bootstrap6, widget, yii2, yii2-extension

## 简介

Bootstrap 6 widgets, forms, and asset bundles for Yii2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
