# yii2-extensions/inertia

> 标签: SPA, inertia, php, server-driven, yii2

## 简介

Yii2 adapter for the framework-agnostic Inertia.js PHP protocol core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
