# catzprint/catzprint-php

> 标签: api, catzprint, escpos, pdf, printing, receipt, sdk, webhooks

## 简介

Official PHP SDK for the CatzPrint cloud printing API: print receipts, PDFs and images, seal content, and verify webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
