# cocart-headless/cocart-sniffs

> 标签: CoCart, phpcs, standards, static analysis, wordpress

## 简介

Collection of PHP_CodeSniffer sniffs for CoCart development.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
