# freimaurerei/yii2-amqp

> 标签: AMQP, PHP7, extension, rabbitmq, yii2

## 简介

Yii2 extension wrapper to communicate with RabbitMQ server via AMQP. Inspired by t-kanstantsin/yii2-amqp

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
