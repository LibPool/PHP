# justinholtweb/craft-waver

> 标签: Accounting, bookkeeping, commerce, craft-commerce, craft-plugin, craftcms, invoicing, wave, waveapps

## 简介

Wave accounting integration for Craft Commerce — every order lands in Wave as balanced, deduplicated bookkeeping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
