# justinholtweb/craft-bouncer

> 标签: access-control, content-gating, craft-plugin, craftcms, membership, paywall, permissions, private-assets, protected-files

## 简介

Access rules for Craft CMS — protect sections, entries, categories, URIs and asset files behind login, user groups, permissions, passwords, date windows and IP rules, with a guarded file delivery route so protected uploads cannot be fetched directly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
