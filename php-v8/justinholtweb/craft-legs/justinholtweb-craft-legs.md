# justinholtweb/craft-legs

> 标签: TablePress, craft-plugin, craftcms, csv, spreadsheet, table, tables

## 简介

Build a table once, use it anywhere — a table library for Craft CMS with a spreadsheet editor, CKEditor and Redactor embedding, and sortable, searchable front-end tables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
