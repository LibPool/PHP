# justinholtweb/craft-awesemo

> 标签: CKEditor, FontAwesome, Redactor, craft-plugin, craftcms, font-awesome, icons, svg

## 简介

Font Awesome, managed. Pick a version or a kit, browse and search every icon in the control panel, insert icons in CKEditor and Redactor, and render them as web font or inline SVG from one Twig call.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
