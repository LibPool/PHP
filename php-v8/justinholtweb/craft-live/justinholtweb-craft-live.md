# justinholtweb/craft-live

> 标签: Craft, cms, craft-plugin, craftcms, live, live blog, live reporting, liveblog, minute by minute, realtime, sse

## 简介

Live blogging for Craft — publish updates in a keystroke, and put them on the site without touching the page cache.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
