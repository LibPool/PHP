# justinholtweb/craft-cleanair

> 标签: Craft, cleanair, cms, control panel, cpfilters, craft-plugin, craftcms, csv, export, filter, filters

## 简介

Advanced control panel filtering for every element type — build multi-criteria filters, save and share them, and export the results.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
