# justinholtweb/craft-scrub

> 标签: Craft, bulk edit, cms, content, craft-plugin, craftcms, find and replace, migration, regex, rename, scrub, search and replace

## 简介

Find and replace text across a Craft site with a preview you can trust, scoping that stops at the content you meant, and an undo. Plus real-time rules that rewrite output without touching the database.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
