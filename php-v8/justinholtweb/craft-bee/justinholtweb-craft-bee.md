# justinholtweb/craft-bee

> 标签: commerce, craft-commerce, craft-plugin, craftcms, personalization, recombee, recommendations, search

## 简介

Recombee recommendations for Craft CMS and Craft Commerce — catalog sync, interaction tracking, personalised recommendations and search, without writing a line of API code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
