# justinholtweb/craft-diploma

> 标签: PHP

## 简介

LMS plugin for Craft CMS 5. Create courses, lessons, quizzes, track progress, and issue certificates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
