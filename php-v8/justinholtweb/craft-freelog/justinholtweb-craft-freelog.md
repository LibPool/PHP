# justinholtweb/craft-freelog

> 标签: Craft, cms, craftcms, debugging, logs, server-logs

## 简介

View, search, filter, and download server logs from the Craft CMS control panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
