# justinholtweb/craft-archive

> 标签: Craft, archive, backup, cms, craft-plugin, craftcms, csv, export, json, migration, xml

## 简介

Export everything on a Craft site — entries, assets, relations, users and settings — into portable JSON, XML, CSV, YAML or NDJSON bundles for migration to any platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
