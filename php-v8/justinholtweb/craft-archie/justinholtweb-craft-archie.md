# justinholtweb/craft-archie

> 标签: Architect, Craft, archie, blueprint, cms, content model, craft-plugin, craftcms, project config, scaffolding, schema, yaml

## 简介

Author a Craft content model as a YAML or JSON blueprint — lint it, plan the diff, apply it, and roll it back. The Craft 5 replacement for Architect.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
