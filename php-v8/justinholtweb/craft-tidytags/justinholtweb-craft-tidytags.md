# justinholtweb/craft-tidytags

> 标签: craftcms, tag-manager, tags

## 简介

Tag manager for Craft CMS 5 with multi-site support and duplicate detection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
