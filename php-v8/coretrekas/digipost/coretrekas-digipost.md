# coretrekas/digipost

> 标签: API-Client, digipost, digital-mail, documents, norway, postal

## 简介

PHP client library for the Digipost API - Send digital mail to Norwegian citizens and businesses

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
