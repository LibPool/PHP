# alik75/voyager-visual-composer

> 标签: formfields, i8n, laravel, laravel-voyager, multilingual, visual composer, voyager formfields

## 简介

a new form field type with drag & drop feature and multi-component that is utilizable for the body of any page on the website

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
