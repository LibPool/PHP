# zactonz/zactonz-php

> 标签: OG Image, api, barcode, dns, email verification, html to pdf, link preview, markdown, qr code, screenshot, sdk, ssl, translation, whois, zactonz

## 简介

Official PHP client for the Zactonz REST APIs: QR codes, barcodes, screenshots and PDFs, social card images, image conversion, link previews, web page to Markdown, DNS, SSL, WHOIS, email checks and translation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
