# hansdeboeck/laravel-turnstile

> 标签: blade, bot, captcha, cloudflare, laravel, turnstile

## 简介

Cloudflare Turnstile voor Laravel: serverside verificatie, validatieregel, Blade-componenten en de bijhorende JavaScript.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
