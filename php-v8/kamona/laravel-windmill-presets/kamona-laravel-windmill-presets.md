# kamona/laravel-windmill-presets

> 标签: laravel, presets, tailwindcss, windmill-dashboard

## 简介

A laravel front-end scaffolding preset for windmill dashboard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
