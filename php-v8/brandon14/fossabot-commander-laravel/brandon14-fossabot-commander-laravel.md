# brandon14/fossabot-commander-laravel

> 标签: fossabot, laravel, library

## 简介

Library to bridge the brandon14/fossabot-commander library to a Laravel application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
