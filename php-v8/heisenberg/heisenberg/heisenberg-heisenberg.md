# heisenberg/heisenberg

> 标签: bilingual, blocks, blog, cms, content-engine, gutenberg, laravel

## 简介

A block-based content engine and bilingual blog backend for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
