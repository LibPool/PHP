# needletail/needletail-craft

> 标签: Craft, cms, craft-plugin, craftcms, needletail

## 简介

Needletail Search and Index package for Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
