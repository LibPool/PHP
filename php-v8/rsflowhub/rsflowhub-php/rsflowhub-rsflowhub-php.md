# rsflowhub/rsflowhub-php

> 标签: ai, ai-api, chatbot, knowledge-base, laravel, pii-redaction, rag, rsflowhub, sdk, sentiment-analysis, translation

## 简介

Official PHP SDK for the RSFlowHub AI API: sentiment analysis, translation, chat, PII redaction, review and ticket AI, knowledge bases (RAG) and chatbots. New APIs work without an SDK update.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
