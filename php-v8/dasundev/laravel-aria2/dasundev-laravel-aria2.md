# dasundev/laravel-aria2

> 标签: aria2, download, json-rpc, laravel, magnet, torrent

## 简介

A fluent Laravel client for aria2 JSON-RPC transfers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
