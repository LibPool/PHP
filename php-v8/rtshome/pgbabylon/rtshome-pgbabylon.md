# rtshome/pgbabylon

> 标签: copy, database, hstore, json, pdo, pgsql, postgres, postgresql

## 简介

PDO class extension with helpers for special PostgreSQL types

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
