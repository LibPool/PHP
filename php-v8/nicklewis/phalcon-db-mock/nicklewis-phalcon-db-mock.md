# nicklewis/phalcon-db-mock

> 标签: phalcon, phpunit

## 简介

Db Mock adds a mock database that you can insert into, delete, and select from for phpunit mocks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
