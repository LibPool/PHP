# luminarix/tempest-nextjs-starter

> 标签: docker, fullstack, nextjs, starter, tempest

## 简介

Full-stack starter with Tempest PHP backend and Next.js frontend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
