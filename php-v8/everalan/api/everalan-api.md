# everalan/api

> 标签: PHP

## 简介

放弃了 Dingo\Api 对系统的侵入式修改，同时又实现了大多数功能，同时增加了一些常用功能，同时支持多套 API 并存，用起来更优雅。A RESTful API package for the Laravel frameworks, Like dingo/api but more simple

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
