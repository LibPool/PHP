# langsys/laravel-api-keys

> 标签: Authentication, api, api-key, laravel, middleware, token

## 简介

Standalone API key authentication for Laravel: SHA-256 hashed keys, read/write scopes, per-key permissions, lifecycle events, and an authentication middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
