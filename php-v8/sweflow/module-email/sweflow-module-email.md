# sweflow/module-email

> 标签: email, module, phpmailer, plugin, smtp, sweflow

## 简介

Módulo de envio de e-mails para a plataforma Sweflow API. Implementa a capability 'email-sender'.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
