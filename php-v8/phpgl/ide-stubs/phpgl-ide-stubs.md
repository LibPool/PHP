# phpgl/ide-stubs

> 标签: 3d, Rendering, autocomplete, glfw, opengl, php-glfw, phpstorm

## 简介

IDE Stubs for PHP-GLFW / OpenGL. (PHPStorm, VSCode, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
