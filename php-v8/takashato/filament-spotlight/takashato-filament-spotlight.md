# takashato/filament-spotlight

> 标签: command-palette, filament, filament-plugin, search, spotlight

## 简介

Spotlight-style command palette for Filament v5 — pluggable sources, keyboard-first UX, WCAG 2.1 AA.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
