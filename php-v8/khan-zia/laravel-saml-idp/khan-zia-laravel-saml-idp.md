# khan-zia/laravel-saml-idp

> 标签: SAML 2.0, SSO, acl, auth, idp, laravel, saml

## 简介

Make your Laravel application an Identity Provider using SAML 2.0.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
