# crixuamg/laravel-api-debugger

> 标签: api, debug, debugger, dump, framework, json, laravel, log, queries

## 简介

Easily debug your JSON API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
