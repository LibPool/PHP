# belisoful/prado-publishing

> 标签: asset-manager, assets, extension, gd, images, imagick, metadata, prado, prado4, publishing

## 简介

Prado TPublishingManager: a TAssetManager that publishes files through asset objects and behaviors, with image processing, format conversion, and image metadata preservation and scrubbing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
