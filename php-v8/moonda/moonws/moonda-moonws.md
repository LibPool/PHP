# moonda/moonws

> 标签: Ratchet, WebSockets, framework, pattern, php, silex, symfony

## 简介

An abstract pattern for websocket-based projects, based on Ratchet.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
