# adrosoftware/lmrp-loader

> 标签: adorsoftware, laminas, mezio

## 简介

Laminas Mezzio helper class to load routes files and pipelines.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
