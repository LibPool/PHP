# dkweva01007/zero-bundle-standard

> 标签: 7.4, framework, mvc, php

## 简介

A PHP's web application for to make a web application with a MVC structure like Symfony but whitout Symfony's Tools. A project make with PHP native from scratch.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
