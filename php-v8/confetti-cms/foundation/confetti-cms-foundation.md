# confetti-cms/foundation

> 标签: Confetti, blade, cms, php, website

## 简介

This is a package for the foundation of the Confetti CMS. For example, it contains the abstract ORM classes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
