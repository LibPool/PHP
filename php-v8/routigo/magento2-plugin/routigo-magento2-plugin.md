# routigo/magento2-plugin

> 标签: Official GLS extension, RoutiGo, magento 2

## 简介

Allows you to send your order data to RoutiGo to set up route plans.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
