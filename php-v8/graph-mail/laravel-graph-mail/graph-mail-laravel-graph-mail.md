# graph-mail/laravel-graph-mail

> 标签: Office365, azure-ad, laravel, mail, mailer, microsoft-graph, outlook, smtp-alternative

## 简介

Send Laravel mail through the Microsoft Graph API (Mail.Send application permission) — no SMTP, no app passwords, works with modern-auth-only tenants.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
