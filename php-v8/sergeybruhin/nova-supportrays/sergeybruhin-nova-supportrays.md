# sergeybruhin/nova-supportrays

> 标签: helpdesk, laravel, nova, sergeybruhin, supportrays

## 简介

Laravel Nova 4 tool for working SupportRays («Лучи Поддержки») tickets from the admin panel, as each Nova user's own SupportRays manager account

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
