# publino/sdk

> 标签: api, blog, cms, delivery, headless, publino, sdk

## 简介

PHP client for the Publino headless delivery API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- Packagist 页面：https://packagist.org/packages/publino%2Fsdk
