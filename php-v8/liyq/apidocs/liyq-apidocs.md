# liyq/apidocs

> 标签: PHP

## 简介

根据laravel框架路由及Controller内的代码注释生成api文档并支持调用接口进行调试，支持FormRequest验证的参数读取

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
