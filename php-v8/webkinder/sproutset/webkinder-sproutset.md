# webkinder/sproutset

> 标签: acorn, blade, image-optimization, responsive-images, roots, wordpress

## 简介

Modern responsive image management for projects using the Roots Acorn framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
