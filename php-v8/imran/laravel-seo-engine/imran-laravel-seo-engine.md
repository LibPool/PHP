# imran/laravel-seo-engine

> 标签: JSON-LD, Sitemap, laravel, meta-tags, redirects, seo

## 简介

Model-level SEO engine for Laravel. Head tags, JSON-LD, sitemaps, redirects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
