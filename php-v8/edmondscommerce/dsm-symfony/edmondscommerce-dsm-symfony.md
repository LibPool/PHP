# edmondscommerce/dsm-symfony

> 标签: PHP

## 简介

A symfony bundle for Doctrine Static Meta (edmondscommerce/doctrine-static-meta) and Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
