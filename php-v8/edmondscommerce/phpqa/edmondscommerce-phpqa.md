# edmondscommerce/phpqa

> 标签: PHP

## 简介

Simple PHP QA pipeline and scripts. Largely just a collection of dependencies with configuration and scripts to run them together

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
