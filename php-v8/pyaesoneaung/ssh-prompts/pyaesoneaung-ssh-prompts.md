# pyaesoneaung/ssh-prompts

> 标签: Laravel Zero, cli, laravel prompts, pyaesoneaung, ssh

## 简介

SSH account management cli tool developed with Laravel Prompts and Laravel Zero

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
