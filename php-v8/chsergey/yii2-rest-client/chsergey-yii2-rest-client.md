# chsergey/yii2-rest-client

> 标签: Active Record, client, model, rest, yii2

## 简介

REST client (AR-like model) for Yii Framework 2.0 (via GuzzleHttp)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
