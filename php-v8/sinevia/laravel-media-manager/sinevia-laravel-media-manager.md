# sinevia/laravel-media-manager

> 标签: laravel, manager, media, php, sinevia

## 简介

Media manager for Laravel - browse / create / rename / delete files and folders.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
