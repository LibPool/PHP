# lucassouzaa/pt-br-validator

> 标签: PHP

## 简介

Uma biblioteca contendo validações de formatos Brasileiros, para o Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
