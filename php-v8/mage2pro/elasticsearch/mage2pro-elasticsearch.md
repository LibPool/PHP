# mage2pro/elasticsearch

> 标签: ecommerce, elasticsearch, magento, magento 2

## 简介

It adds new features to the built-in Magento's Elasticsearch module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
