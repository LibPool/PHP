# mage2pro/google-backend-login

> 标签: Authentication, backend, ecommerce, google, google api, google oauth2, magento, magento 2, magento extension, oauth2, single sign-on

## 简介

The «Backend Login with Google Account» extension for Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
