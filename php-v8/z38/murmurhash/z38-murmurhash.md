# z38/murmurhash

> 标签: hash, murmur, murmur3a, murmur3c, murmur3f, murmurhash, murmurhash3

## 简介

Murmur3F implementation for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
