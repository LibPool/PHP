# emulsify-ds/emulsify-wordpress-theme

> 标签: PHP

## 简介

Timber-first WordPress parent theme for Emulsify that generates child themes with Emulsify Core 4, Vite, Storybook, and Twig

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
