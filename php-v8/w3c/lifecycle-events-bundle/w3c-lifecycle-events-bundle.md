# w3c/lifecycle-events-bundle

> 标签: domain, events, lifecycle

## 简介

A Symfony bundle to dispatch usable entity lifecycle events (create, update, delete)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
