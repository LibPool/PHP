# dev-macb/poderoso

> 标签: PHP Data Object, crud, database, pdo, poderoso

## 简介

O Poderoso é um pacote PHP que oferece uma abstração de banco de dados completa e fácil de usar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
