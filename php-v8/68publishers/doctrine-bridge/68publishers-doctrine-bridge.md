# 68publishers/doctrine-bridge

> 标签: 68publishers, Bridge, doctrine, nette, orm

## 简介

Bridges between integrations of Doctrine ORM and '68publishers bundles.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
