# tmzwinkels/jqvmap

> 标签: PHP

## 简介

jVectorMap is a vector-based, cross-browser and cross-platform component for interactive geography-related data visualization on the web.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
