# silvershop-suite/import-excel

> 标签: csv, ecommerce, excel, import, phpspreadsheet, silvershop, silverstripe, spreadsheet

## 简介

Spreadsheet (Excel/CSV/ODS) source connector for silvershop-suite/import — reads a workbook into the import engine (upsert by SKU/GTIN, column-mapped, validated, dry-run) AND provides the export→correct→re-apply roundtrip: a result/error workbook the client fixes and re-uploads, plus a full catalogue export. The MVP connector: proves the engine end to end with no external system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
