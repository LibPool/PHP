# silvershop-suite/address-lookup

> 标签: address, autocomplete, checkout, openplz, pdok, postcode, silvershop, silverstripe, zippopotam

## 简介

Checkout address autocomplete for SilverShop (CMS 6): a server-side lookup service behind a per-country provider seam (postcode+number lookup / typeahead suggest / validation). Bundles three free, keyless providers — PDOK (NL), OpenPLZ (DE/AT/CH/LI) and Zippopotam (global postcode→city) — so NL + DACH autofill out of the box. Builds on silvershop-suite/address-formats; paid providers (MyParcel, Pro6PP, Loqate) ship as satellite add-ons.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
