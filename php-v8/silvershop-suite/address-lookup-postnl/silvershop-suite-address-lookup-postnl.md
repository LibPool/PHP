# silvershop-suite/address-lookup-postnl

> 标签: address, adrescheck, autocomplete, checkout, international, netherlands, postcode, postnl, silvershop, silverstripe

## 简介

PostNL Adrescheck provider for silvershop-suite/address-lookup (CMS 6): a satellite connector that resolves NL addresses structurally (postcode + house number -> street + city via PostNL's Dutch addresscheck) and every other country via free-text international autocomplete, over PostNL's unified Adrescheck Autocomplete (ACI) API. Authenticates with an `apikey` header (SS_POSTNL_API_KEY) and is inert without a key. Registers the `postnl` provider; carrier-aligned for shops shipping with PostNL/MyParcel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
