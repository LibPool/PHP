# silvershop-suite/address-lookup-myparcel

> 标签: Belgium, address, autocomplete, checkout, myparcel, postcode, silvershop, silverstripe, validation

## 简介

MyParcel Address API provider for silvershop-suite/address-lookup (CMS 6): a satellite connector that resolves NL addresses structurally (postcode + house number -> street + city + lat/lng) and BE + other countries via free-text autocomplete, plus address validation. Reuses the SS_MYPARCEL_API_KEY that silvershop-suite/shipping-myparcel already uses. Registers the `myparcel` provider and maps BE -> myparcel, closing the base module's Belgium gap.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
