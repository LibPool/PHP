# silvershop-suite/decimal-quantity

> 标签: decimal, ecommerce, fractional, quantity, silvershop, silverstripe, stock, unit-of-measure

## 简介

Per-product decimal / fractional order quantities for SilverShop (CMS 6) — sell some products by weight/length/area (kg, m², m) while others stay whole-unit, in one catalogue. Opt-in per product (QuantityIsDecimal + unit label + step/precision/min/max); carries the decimal beside core's integer quantity via extension hooks (no core overrides), with guarded decimal stock when silvershop/stock is installed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
