# silvershop-suite/conversion-tracking

> 标签: capi, consent, conversion-tracking, datalayer, ecommerce, ga4, pixel, silvershop, silverstripe

## 简介

Ad conversion / event tracking core for SilverShop (CMS 6): a normalised ViewContent→AddToCart→InitiateCheckout→Purchase event model, an always-on GA4-shaped dataLayer emit, hard consent gating bound to silvershop-suite/cookieconsent, deterministic purchase event_id dedup, and a queued server-side dispatch framework. Per-platform connectors (Meta, Google) plug in through the ConversionProvider seam.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
