# silvershop-suite/address-lookup-pro6pp

> 标签: address, autocomplete, checkout, postcode, pro6pp, silvershop, silverstripe, validation

## 简介

Pro6PP address provider for silvershop-suite/address-lookup (CMS 6): a satellite connector that resolves NL addresses structurally (postcode + house number -> street + settlement + municipality + province + lat/lng) via the Pro6PP v2 autocomplete API, and validates/canonicalises BE/DE/FR/LU (+ AT/CH/DK) addresses. Registers the `pro6pp` provider and fills the base module's FR + LU gaps. Paid per-call; key as SS_PRO6PP_API_KEY.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
