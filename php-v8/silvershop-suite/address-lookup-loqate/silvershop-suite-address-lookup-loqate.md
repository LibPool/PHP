# silvershop-suite/address-lookup-loqate

> 标签: GBG, address, addressy, autocomplete, checkout, global, loqate, postcode, silvershop, silverstripe, validation

## 简介

Loqate (GBG) Capture provider for silvershop-suite/address-lookup (CMS 6): the GLOBAL satellite connector. Resolves addresses in 250+ countries via Loqate's two-step Find -> Retrieve autocomplete, and installs itself as the registry's global `default` so every country without a regional mapping (NZ, US, rest-of-world) autofills through Loqate. Consent-gated (third-party global processor) and paid per lookup; reads SS_LOQATE_API_KEY.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
