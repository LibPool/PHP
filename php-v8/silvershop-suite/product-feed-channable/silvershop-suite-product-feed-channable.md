# silvershop-suite/product-feed-channable

> 标签: channable, channel, ecommerce, feed, marketplace, product-feed, silvershop, silverstripe

## 简介

Channable (complete / raw) feed connector for silvershop-suite/product-feed (CMS 6): a flat, un-namespaced 'expose every field' XML serializer + field map that turns the shared CatalogProductData into a rich source feed Channable pulls from a stable URL and remaps itself. Registers itself into the product-feed core's channel registry — no core change.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
