# silvershop-suite/barcodes

> 标签: EAN13, barcode, code128, ecommerce, gtin, label, qr, silvershop, silverstripe, svg

## 简介

Barcode image generation for SilverShop (CMS 6): render EAN-13, Code128 and QR codes to inline SVG or a PNG data-URI, from any code string or — guarded — from a product's GTIN stored by silvershop-suite/product-identity. For packing slips, invoices, shipping labels, PDFs and POS/scanning. Generation only; the codes live in product-identity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
