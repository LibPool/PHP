> 标签: ai, ai-query-generator, laravel, laravel-ask-database, mkreftsymfonia

## 简介

Laravel Eloquent AI is a Laravel package that allows asking an AI for database queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
