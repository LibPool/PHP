# morphql/morphql-symfony

> 标签: bundle, data-transformation, morphql, symfony, transform

## 简介

Symfony integration for MorphQL — YAML config, autowiring, and .morphql file convention

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
