# coursearc/php-lib

> 标签: PHP

## 简介

A public library for doing some common things in PHP at CourseArc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/coursearc-team/php-lib
- 源码仓库：https://bitbucket.org/coursearc-team/php-lib.git
