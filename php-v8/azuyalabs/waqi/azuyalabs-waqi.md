# azuyalabs/waqi

> 标签: AQI, Pollution, WAQI, air, air quality, api, pm2.5

## 简介

Simple PHP Wrapper for the World Air Quality Index API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
