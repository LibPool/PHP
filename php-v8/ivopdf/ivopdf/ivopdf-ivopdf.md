# ivopdf/ivopdf

> 标签: css-grid, cyrillic, dompdf, flexbox, html-to-pdf, mpdf, pdf, shared-hosting, utf-8

## 简介

Modern Pure-PHP HTML & CSS to PDF Engine with Flexbox, CSS Grid, and Full UTF-8/Cyrillic Support for Shared Hosting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
