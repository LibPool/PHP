# filiprigoir/pswkey

> 标签: base, charset, converter, decoding, derivation, derived key, deterministic, encoding, one-time-pad, pepper, php, salt, shuffle, stream key, transport key

## 简介

A deterministic base converter using shuffled alphabets derived from salt and optional pepper, with streamkey and one-time-pad support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
