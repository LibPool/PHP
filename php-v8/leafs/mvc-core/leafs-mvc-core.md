# leafs/mvc-core

> 标签: framework, leaf, microframework, mvc, php, rest

## 简介

Core files specific to MVC based leaf frameworks like Leaf MVC and Leaf API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
