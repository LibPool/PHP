# mage-os/module-claude-consumer-agent

> 标签: PHP

## 简介

AI shopping assistant for Hyva and Luma storefronts, on any AI service configured in Mage-OS AI Base.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
