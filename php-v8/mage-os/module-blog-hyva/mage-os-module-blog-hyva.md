# mage-os/module-blog-hyva

> 标签: PHP

## 简介

Hyvä compatibility module for MageOS_Blog — Hyvä-native storefront templates and Tailwind styles.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
