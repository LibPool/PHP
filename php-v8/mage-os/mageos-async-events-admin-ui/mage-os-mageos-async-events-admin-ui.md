# mage-os/mageos-async-events-admin-ui

> 标签: PHP

## 简介

Add event subscriptions for the Mage-OS Async Events module via an admin form instead of using REST requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
