# mage-os/module-extension-directory

> 标签: PHP

## 简介

Browse the Mage-OS Extension Directory from the Magento admin panel, enriched with the shop's installed modules and Magento version.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
