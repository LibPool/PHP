# mage-os/module-profiler

> 标签: PHP

## 简介

Profiler output types and application instrumentation for Mage-OS: a tabular report for CLI, REST, GraphQL and web requests, a JSON timeline driver, and per-seam timers for SQL, cache, Redis, search, HTTP, checkout, cron, indexers and queues.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
