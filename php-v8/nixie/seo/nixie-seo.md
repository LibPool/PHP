# nixie/seo

> 标签: laravel, meta-tags, open-graph, schema, seo, twitter-cards

## 简介

A comprehensive Laravel SEO package for managing meta tags, Open Graph, Twitter Cards, and structured data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
