# amazingdreams/phalcon-menumanager

> 标签: PHP

## 简介

The Phalcon Menumanager is a Phalcon module that helps you generate menus

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
