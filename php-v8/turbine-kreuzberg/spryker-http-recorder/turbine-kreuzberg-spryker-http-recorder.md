# turbine-kreuzberg/spryker-http-recorder

> 标签: PHP

## 简介

HTTP recorder for Spryker based on php-vcr (https://php-vcr.github.io/)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
