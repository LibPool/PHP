# myvars/form-flow

> 标签: bundle, controller, crud, form, hotwire, symfony, turbo

## 简介

Generic Symfony controller-flow coordinators (Form/Action/Confirm/Search/InlineEdit) — the FormFlow pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
