# simonet85/laravel-deepl

> 标签: deepl, i18n, laravel, localization, translation

## 简介

Laravel package for DeepL translation: facade, cache, placeholder protection and an Artisan command that fills your lang/*.json files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
