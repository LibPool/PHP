# nouxwell/tabula

> 标签: csv, excel, export, import, pdf, schema, spreadsheet, symfony, xlsx

## 简介

Schema-driven tabular export and import for Excel, CSV and PDF. One schema, three directions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
