# malhar-rathod/bilibili-media

> 标签: bilibili, extension, media, typo3, video

## 简介

Bilibili Online Media support for TYPO3 Text & Media element (v12, v13, v14)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
