# humaninitiative/yii2-minio-component

> 标签: aws-sdk, extension, minio, s3, yii2

## 简介

A Yii2 component to interact with MinIO using AWS SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
