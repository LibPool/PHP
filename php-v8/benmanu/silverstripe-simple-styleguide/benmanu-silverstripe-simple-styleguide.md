# benmanu/silverstripe-simple-styleguide

> 标签: silverstripe, styleguide

## 简介

Provides a kitchen sink template useful for theme development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
