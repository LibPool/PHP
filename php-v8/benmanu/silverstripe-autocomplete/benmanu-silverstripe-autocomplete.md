# benmanu/silverstripe-autocomplete

> 标签: autocomplete, field, form, silverstripe

## 简介

Autocomplete field that can be used as a SilverStripe form field

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
