# benmanu/silverstripe-knowledgebase-rating

> 标签: FAQ, Rating, dislike, knowledgebase, like, search, silverstripe, solr

## 简介

An addon module for knowledgebase that allows users to like/dislike to FAQ's.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
