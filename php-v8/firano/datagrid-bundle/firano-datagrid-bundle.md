# firano/datagrid-bundle

> 标签: datagrid, jqgrid, jquery, symfony

## 简介

This bundle provides easy creating of jqGrid datagrids

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
