# hsrtech/catc

> 标签: Cloud at Cost, Cloudatcost, api

## 简介

PHP Wrapper for Cloudatcost and vps-hosting.ca.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
