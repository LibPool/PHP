# agrodata/laravel-data-openapi-generator

> 标签: PHP

## 简介

Generate OpenAPI specification from Laravel routes and Laravel Data objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
