# nabu-3/cms

> 标签: cms, database, framework, nabu, nabu-3, web, web builder, website, websites

## 简介

nabu-3 CMS Website to manage nabu-3 database framework entities and websites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
