# bartacus/bartacus-bundle

> 标签: container, framework, integration, service container, services, symfony, twig, typo3

## 简介

Integrates the Symfony full-stack framework into TYPO3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
