# webee-online/g-cms

> 标签: PHP

## 简介

Simple CMS with a Git repository as a main content datastore

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/adam-webee/gCMS
- 源码仓库：https://github.com/adam-webee/gCMS.git
- Packagist 页面：https://packagist.org/packages/webee-online%2Fg-cms
