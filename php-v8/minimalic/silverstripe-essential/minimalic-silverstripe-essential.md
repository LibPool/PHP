# minimalic/silverstripe-essential

> 标签: base, essential, foundation, silverstripe

## 简介

Provides helpful functions for own templates in Silverstripe CMS 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
