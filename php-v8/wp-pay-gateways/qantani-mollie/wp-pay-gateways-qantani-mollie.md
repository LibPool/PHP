# wp-pay-gateways/qantani-mollie

> 标签: gateway, mollie, pay, pronamic, qantani, wordpress, wp

## 简介

Qantani Mollie driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
