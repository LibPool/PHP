# wp-pay-gateways/ogone

> 标签: gateway, ingenico, ogone, pay, pronamic, wordpress, wp

## 简介

Ingenico/Ogone driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
