# wp-pay-gateways/paypal

> 标签: gateway, pay, paypal, pronamic, wordpress, wp

## 简介

PayPal driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
