# wordpressvn/php-simple-html-dom-parser

> 标签: Simple, dom, html, html dom parser

## 简介

PHP Simple HTML DOM Parser with namespace and PHP 7.4 compatible

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
