# yntech/domain-forge

> 标签: PHP

## 简介

Hexagonal architecture generator for Laravel. Provides Artisan commands for structuring domains following the principles of DDD and Screaming Architecture.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
