# very-code-com/furgonetka-api-php

> 标签: api, client, courier, dhl, dpd, furgonetka, gls, inpost, labels, logistics, oauth2, parcel, poczta-polska, rest, shipping, tracking, ups, webhook

## 简介

PHP client for the Furgonetka.pl REST API: OAuth2, price comparison, shipments, labels, pickups, tracking, pickup points, returns, address book, notifications and webhooks. One API for DPD, InPost, DHL, UPS, GLS, FedEx, Poczta Polska, ORLEN Paczka and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
