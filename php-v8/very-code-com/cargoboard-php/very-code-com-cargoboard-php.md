# very-code-com/cargoboard-php

> 标签: adr, api, cargoboard, client, freight, ftl, groupage, logistics, ltl, rest, shipping

## 简介

PHP client for the Cargoboard REST API (quotations, bookings, labels, tracking, invoices, ADR data). Groupage, LTL, FTL, parcel and dangerous-goods shipments across Europe.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
