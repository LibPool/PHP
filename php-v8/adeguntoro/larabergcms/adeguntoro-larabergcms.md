# adeguntoro/larabergcms

> 标签: block-editor, blog, cms, gutenberg, laraberg, laravel

## 简介

Gutenberg-style content management for Laravel, built on van-ons/laraberg. Installable CRUD, media upload and Blade views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
