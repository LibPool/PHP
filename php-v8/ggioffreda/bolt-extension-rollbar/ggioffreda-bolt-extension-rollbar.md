# ggioffreda/bolt-extension-rollbar

> 标签: PHP

## 简介

Adds error reporting capabilities using Rollbar.com ( https://rollbar.com/ ).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
