# acamposm/ping

> 标签: icmp, laravel, php, ping

## 简介

Ping uses the ICMP protocol's mandatory ECHO_REQUEST datagram to elicit an ICMP ECHO_RESPONSE from a host or gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
