# abdallhsamy/laravel-hyperpay

> 标签: abdallhsamy, laravel-hyperpay

## 简介

Laravel package for Hyperpay payment gateway in MENA.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
