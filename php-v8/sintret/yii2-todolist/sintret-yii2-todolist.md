# sintret/yii2-todolist

> 标签: AdminLTE, ajax, jquery, plugin, todolist, yii2

## 简介

Yii2 extension for To Do list plugin using adminlte template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
