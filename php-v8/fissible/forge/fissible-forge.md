# fissible/forge

> 标签: generator, laravel, openapi, scaffolding, spec

## 简介

OpenAPI spec generation for PHP — scaffolds specs from routes and infers schemas from validation rules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
