# fissible/verdict-console-filament

> 标签: ai, ai-agents, approval, filament, human-in-the-loop, laravel, laravel-ai, verdict

## 简介

Filament plugin for the Verdict Console: approval queue, evidence browser, and ops surfaces over the console's headless contracts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
