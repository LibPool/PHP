# fissible/accord

> 标签: contract, laravel, mezzio, middleware, openapi, psr-15, psr-7, slim, validation

## 简介

OpenAPI contract validation for PHP — PSR-7/15 core with Laravel, Slim, and Mezzio drivers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
