# fissible/transmark-pdf

> 标签: converter, docx, dompdf, pdf, transmark

## 简介

PDF import/export for fissible/transmark: PdfWriter composes HtmlWriter output with dompdf/dompdf; PdfReader recovers a Document from PDF bytes via layout heuristics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
