# ephraitech/ci4-auth

> 标签: Authentication, CI4, api, authorization, codeigniter4, rbac, tokens

## 简介

DB-backed authentication (session + opaque token) and role/permission authorization for CodeIgniter 4, with multi-tenant support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
