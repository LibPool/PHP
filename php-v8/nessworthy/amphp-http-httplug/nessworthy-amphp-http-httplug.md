# nessworthy/amphp-http-httplug

> 标签: PHP

## 简介

A small crappy adapter package to support php-http/async-client-implementation via. amphp/http-client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
