# delfimcelestino/mpesa-connect-php

> 标签: mpesa, payment, sdk

## 简介

A PHP SDK for integrating MPesa payment services, including C2B, B2C, and other transaction methods.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
