# rpk/acid-storage

> 标签: A.C.I.D., php, storage

## 简介

Implementation of an ACID (Atomicity, Consistency, Isolation, Durability) storage using file system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
