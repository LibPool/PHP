# mmltech/cnp-decoder

> 标签: PHP

## 简介

O clasa simpla prin care se pot extrage componentele CNP-ului introdus, componente precum vârsta, jude?, gen, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
