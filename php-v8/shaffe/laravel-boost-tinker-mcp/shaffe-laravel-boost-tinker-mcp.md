# shaffe/laravel-boost-tinker-mcp

> 标签: Tinker, boost, laravel, mcp

## 简介

Tinker MCP tool for Laravel Boost — execute PHP code in the Laravel application context.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
