# huijiewei/yii2-nprogress

> 标签: assets, extension, nprogress, yii2

## 简介

Slim progress bars for Ajax'y applications. Inspired by Google, YouTube, and Medium.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
