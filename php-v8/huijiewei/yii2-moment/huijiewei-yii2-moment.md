# huijiewei/yii2-moment

> 标签: assets, extension, moment, momentjs, yii2

## 简介

A lightweight JavaScript date library for parsing, validating, manipulating, and formatting dates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
