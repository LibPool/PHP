# serphouse/serphouse-php

> 标签: Bing Serp Api, Google Serp Api, SERP, Serp Api, Yahoo Serp Api, api, client, curl, datamining, google, json, learning, localisation, ml, php sdk, rest, result, scrape, search, serphouse, xml

## 简介

Automate your search engines (Google, Bing, Yahoo) result (serp api) using Serphouse.com API client and retrive in structured JSON format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
