# luizfabianonogueira/navi-api

> 标签: api, cep, cnpj, cpf, sms, token

## 简介

Serviços de busca CPF, CNPJ e CEP envio de SMS, TOKEN SMS e muito mais para o seu sistema.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
