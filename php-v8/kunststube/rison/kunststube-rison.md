# kunststube/rison

> 标签: decode, encode, rison

## 简介

A PHP encoder and decoder for Rison, the compact JSON-like data format optimized for URIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
