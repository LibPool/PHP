# defenso/sdk-php

> 标签: defenso, laravel, middleware, security, symfony, waf

## 简介

Defenso PHP SDK — WAF, uptime, and attack-log middleware for Laravel and Symfony. Fails open.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
