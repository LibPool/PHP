# nahidferdous/laravel-shield

> 标签: api, laravel, passport, roles, sanctum, socialite

## 简介

Shield - A comprehensive Laravel package for authentication (Sanctum, Passport, JWT) and role/permission management with social login support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
