# michonnehsu/simpledingtalk

> 标签: api, client, dingtalk, enterprise, messaging

## 简介

A modern DingTalk API client with better architecture and error handling

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
