# dungang/yii2-duoshuo

> 标签: PHP

## 简介

A  duoshou for Yii2。多说是一款追求极致体验的社会化评论框，可以用微博、QQ、人人、豆瓣等帐号登录并评论

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
