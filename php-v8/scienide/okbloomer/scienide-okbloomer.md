# scienide/okbloomer

> 标签: Bloom Filter, layered bloom filter, scalable bloom filter

## 简介

An autoscaling Bloom filter with ultra-low memory usage for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
