# pseo/laravel-pseo

> 标签: Sitemap, laravel, llms.txt, programmatic-seo, pseo, robots, seo

## 简介

Laravel package that generates robots.txt, sitemap.xml, and llms.txt — and imports pSEO campaign archives.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
