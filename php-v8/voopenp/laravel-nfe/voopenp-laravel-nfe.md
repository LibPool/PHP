# voopenp/laravel-nfe

> 标签: PHP

## 简介

Emissão de NF-e (modelo 55) e NFC-e (modelo 65) na SEFAZ para aplicações Laravel: numeração segura sob concorrência, DANFE/DANFCE em PDF via dompdf e QR code de NFC-e.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
