# php-mtg/mtg-api-com-mtgjson-object

> 标签: api, implementation, mtgjson.com, object, php

## 简介

A library that implements the php-mtg/mtg-api-com-mtgjson-interface library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
