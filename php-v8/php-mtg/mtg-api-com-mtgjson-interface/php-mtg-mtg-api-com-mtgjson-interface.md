# php-mtg/mtg-api-com-mtgjson-interface

> 标签: api, interface, mtg, mtgjson.com, php

## 简介

A library that gets data from the mtgjson.com website's api

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
