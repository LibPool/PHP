# linlak/momoapi

> 标签: api, integration, library, linlak, linus, mobile money api, momo api, momo library, momo pay uganda, mtn momo, mtn momo pay api, mtn open api

## 简介

Momo php library is small php package that helps developers to integrate the momo api their project (s).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
