# antevemus/adeep-property-access

> 标签: array-access, dot-notation, getter, linq, nested, php8, property-access, property-accessor, reflection, specification

## 简介

Zero-dependency PHP 8.2+ property reader for arrays and objects: dot-notation paths, array/ArrayAccess keys, getX/x/isX/hasX methods, public and magic properties, and private fields only when the class author opts in with #[Specifiable]. The shared accessor of antevemus/aspecification and antevemus/alinq-collection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
