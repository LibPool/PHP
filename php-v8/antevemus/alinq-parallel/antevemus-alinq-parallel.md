# antevemus/alinq-parallel

> 标签: CPU, collection, lazy, linq, multiprocessing, parallel, php84, process-pool, worker

## 简介

CPU-parallel companion of antevemus/alinq-collection: selectParallel(), whereParallel(), selectManyParallel() and eachParallel() run per-item work in a pool of worker PHP processes (proc_open, no extension required), through an ordered, bounded, lazy window, returning core ALinq lazy collections

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
