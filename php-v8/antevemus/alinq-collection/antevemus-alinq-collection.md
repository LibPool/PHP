# antevemus/alinq-collection

> 标签: aggregation, array, collection, ddd, filtering, fluent-api, functional-programming, generics, linq, php84, query-builder, set-theory

## 简介

Enterprise LINQ-Style Collection Framework for PHP 8.4+ (Fluent API, Native Array Primitives, Query Builder, Set Operations, Dot-Notation Property Access)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
