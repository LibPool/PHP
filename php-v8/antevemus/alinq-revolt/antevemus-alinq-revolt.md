# antevemus/alinq-revolt

> 标签: amphp, async, collection, concurrency, event-loop, fiber, lazy, linq, php84, revolt

## 简介

Asynchronous companion of antevemus/alinq-collection: selectAsync(), whereAsync(), selectManyAsync() and eachAsync() over the Revolt event loop (Fibers, Amp futures), with an ordered, bounded, lazy window of items in flight, returning core ALinq lazy collections

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
