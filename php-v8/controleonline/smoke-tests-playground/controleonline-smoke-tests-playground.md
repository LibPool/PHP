# controleonline/smoke-tests-playground

> 标签: PHP

## 简介

Symfony bundle for exposing browser smoke test indexes and artifacts as JSON APIs in ControleOnline projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
