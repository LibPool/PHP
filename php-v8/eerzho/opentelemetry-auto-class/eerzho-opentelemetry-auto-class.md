# eerzho/opentelemetry-auto-class

> 标签: apm, auto-instrumentation, distributed-tracing, instrumentation, monitoring, observability, opentelemetry, otel, php-attributes, spans, telemetry, traces, tracing

## 简介

Trace what your methods received, returned, and threw — without writing a single span. No framework required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
