# pastusiak/tiny-ssi-php

> 标签: server side includes, ssi

## 简介

Tiny SSI - Apache Server Side Includes parser for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
