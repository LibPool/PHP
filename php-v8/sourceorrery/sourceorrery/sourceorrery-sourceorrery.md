# sourceorrery/sourceorrery

> 标签: Keyring, dotenv, ffi, secrets, security, vault

## 简介

Read secrets from SourceOrrery vaults, the encrypted replacement for .env files. Read-only: vaults are created and secrets stored with the sourceorrery CLI; the native library comes from the GitHub release.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
