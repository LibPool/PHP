# bensomething/craft-scribe

> 标签: Craft, cms, craftcms, docs, field, github, markdown, plugin, readme

## 简介

A field that pulls a GitHub README into your content, sliced by heading.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
