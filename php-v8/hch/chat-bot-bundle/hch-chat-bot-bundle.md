# hch/chat-bot-bundle

> 标签: ai, chatbot, openai, premium, symfony

## 简介

Bundle Symfony pour intégrer un chatbot IA avec support multi-LLM

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
