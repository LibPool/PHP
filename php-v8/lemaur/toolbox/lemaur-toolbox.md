# lemaur/toolbox

> 标签: Code style, PHPStan, Toolbox, dusk, laravel, lemaur, pest, php-cs-fixer, rector, refactor, static analysis, testing, tests

## 简介

Toolbox full of useful packages to keep your Laravel project compliant with your coding standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
