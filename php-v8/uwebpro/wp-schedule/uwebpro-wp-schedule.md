# uwebpro/wp-schedule

> 标签: blog, cron, laravel, schedule, uwebpro, wordpress

## 简介

A laravel inspired cron scheduler for WordPress

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
