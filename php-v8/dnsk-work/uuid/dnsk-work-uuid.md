# dnsk-work/uuid

> 标签: fieldtype, identifier, laravel, statamic, statamic-addon, uuid

## 简介

A UUID fieldtype for Statamic that auto-generates a stable, write-once unique ID for entries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
