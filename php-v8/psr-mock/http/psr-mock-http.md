# psr-mock/http

> 标签: discovery, http-client-implementation, http-factory-implementation, http-message-implementation, psr, psr-17, psr-18, psr-7

## 简介

Lightweight mock implementations of PSR-18, PSR-17 and PSR-7 tailored to simplify unit testing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
