# beto2l/mautic-aws-eum-sms

> 标签: Mautic, aws, integration, mms, plugin, sms

## 简介

Secure AWS End User Messaging SMS and MMS transport for Mautic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
