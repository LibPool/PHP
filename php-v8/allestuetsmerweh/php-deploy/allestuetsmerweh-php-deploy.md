# allestuetsmerweh/php-deploy

> 标签: deploy, ftp, ftps, php, sftp, shared hoster, upload

## 简介

Deploy your PHP code to a shared hoster

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
