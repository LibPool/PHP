# alrik11es/spanish-utils

> 标签: CIF, DNI, IBAN, NIE

## 简介

A set of tools for Spanish bureaucracy like CIF calculation, DNI, IBAN...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
