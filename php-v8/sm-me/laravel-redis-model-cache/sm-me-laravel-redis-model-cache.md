# sm-me/laravel-redis-model-cache

> 标签: cache, eloquent, laravel, model, packagist, redis

## 简介

Optimized Redis model and hash-set caching service for Laravel Eloquent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
