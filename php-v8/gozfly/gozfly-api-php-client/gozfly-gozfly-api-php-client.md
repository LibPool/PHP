# gozfly/gozfly-api-php-client

> 标签: Authentication, api, auth, authorization, client, gozfly, gozfly-api, gozfly-client, gozfly-login, gozfly-sdk, gozfly-signin, gozfly.com, integration, linked in, oauth, oauth2, oauth2-authentication, oauth2-client, php-gozfly, platform, rest, social, social network, wrapper

## 简介

Gozfly API PHP SDK with OAuth 2.0 & CSRF support. Can be used for social sign in or sharing on Gozfly. Examples. Documentation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
