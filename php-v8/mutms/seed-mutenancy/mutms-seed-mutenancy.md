# mutms/seed-mutenancy

> 标签: lms, moodle, mutms

## 简介

A Composer project template to seed a new multi-tenant Moodle LMS site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
