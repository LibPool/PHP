# rayhan-bapari/sslcommerz

> 标签: bangladesh, checkout, ecommerce, gateway, hosted, ipn, laravel, payment, ssl-commerz, sslcommerz

## 简介

A production-ready Laravel package for SSLCommerz payment gateway — supports hosted & checkout modes, IPN with hash verification, order validation, refunds, transaction queries. Laravel 9–12, PHP 8.1–8.5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
