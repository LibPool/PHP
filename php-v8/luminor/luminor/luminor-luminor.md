# luminor/luminor

> 标签: cqrs, ddd, domain-driven-design, event-sourcing, framework, luminor, observability, openapi, php, rest-api

## 简介

A modern, open-source DDD framework for building REST APIs and domain-driven applications with event sourcing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
