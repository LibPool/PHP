# chxj1992/hashring

> 标签: Consistent Hashing, libketama, php

## 简介

Consistent hashing "hashring" implementation in php (using the same algorithm as libketama)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
