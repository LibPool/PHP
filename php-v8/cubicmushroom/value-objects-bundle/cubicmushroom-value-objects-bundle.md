# cubicmushroom/value-objects-bundle

> 标签: PHP

## 简介

Symfony bundle to integrate value objects from the nicolopignatelli/valueobjects package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
