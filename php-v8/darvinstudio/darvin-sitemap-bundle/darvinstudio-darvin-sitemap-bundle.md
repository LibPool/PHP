# darvinstudio/darvin-sitemap-bundle

> 标签: Sitemap

## 简介

This bundle provides simple sitemap generating functionality for Symfony2-based applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
