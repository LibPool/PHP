# albertoarena/filament-truss

> 标签: database, database-diagram, er-diagram, erd, filament, filament-plugin, filamentphp, laravel, schema, truss

## 简介

A live ER diagram (ERD) of your real database as a native page inside a Filament panel. Built on Laravel Truss. Structure only, never data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
