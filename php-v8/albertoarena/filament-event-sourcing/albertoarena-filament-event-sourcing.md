# albertoarena/filament-event-sourcing

> 标签: aggregates, cqrs, event-sourcing, filament, laravel, spatie

## 简介

Bridge spatie/laravel-event-sourcing v7 with Filament admin panels: write through aggregates, audit stored events, and replay projectors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
