# bertugfahriozer/ci4commonmodel

> 标签: PHP

## 简介

With the codeigniter 4 database builder, I combined the general methods I used for myself into a single model.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
