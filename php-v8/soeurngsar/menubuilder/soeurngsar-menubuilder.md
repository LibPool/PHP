# soeurngsar/menubuilder

> 标签: Drag Drop, backpack, builder, laravel, menu

## 简介

drag and drop menu generator like wordpress for laravel backpack

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
