# authn-sh/sdk-php

> 标签: Authentication, authn, identity, sdk

## 简介

PHP backend SDK for authn.sh — BAPI client, JWT verification, and webhook signature verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
