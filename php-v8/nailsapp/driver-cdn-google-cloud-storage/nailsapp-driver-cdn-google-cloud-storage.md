# nailsapp/driver-cdn-google-cloud-storage

> 标签: CDN Module, Nails, Shed Collective, codeigniter, driver, google cloud storage

## 简介

This is the "Google Cloud Storage" driver for the Nails CDN module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
