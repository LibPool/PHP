# nailsapp/module-curl

> 标签: Curl Module, Nails, Shed Collective, codeigniter

## 简介

This is the "Curl" module for Nails.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
