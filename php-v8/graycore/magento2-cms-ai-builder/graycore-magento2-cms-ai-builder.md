# graycore/magento2-cms-ai-builder

> 标签: PHP

## 简介

A Magento 2 module that extends the CMS page editor with AI-powered content generation and visual preview capabilities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
