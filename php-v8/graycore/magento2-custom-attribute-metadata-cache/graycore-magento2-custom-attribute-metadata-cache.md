# graycore/magento2-custom-attribute-metadata-cache

> 标签: PHP

## 简介

A Magento 2 module that enables caching for customAttributeMetadata in GraphQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
