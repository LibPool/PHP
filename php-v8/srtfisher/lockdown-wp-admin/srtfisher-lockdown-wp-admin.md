# srtfisher/lockdown-wp-admin

> 标签: admin, security, wordpress

## 简介

WordPress Plugin to hide login and admin URLs when not logged into WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
