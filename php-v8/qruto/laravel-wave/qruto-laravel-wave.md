# qruto/laravel-wave

> 标签: event source, laravel, laravel-wave, live-update, php, qruto, realtime, server sent events, sse

## 简介

Painless Laravel Broadcasting with SSE.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
