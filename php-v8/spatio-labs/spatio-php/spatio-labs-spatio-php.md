# spatio-labs/spatio-php

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

PHP SDK for the SpatioAPI. Generated from the official OpenAPI spec.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
