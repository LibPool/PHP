# shiwildy/phptotp

> 标签: 2FA Auth, 2fa, Multi Auth, authenticator, google auth, totp

## 简介

A  simple TOTP library for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
