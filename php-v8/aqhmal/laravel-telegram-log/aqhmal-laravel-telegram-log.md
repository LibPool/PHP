# aqhmal/laravel-telegram-log

> 标签: laravel, log, lumen, monolog, telegram, telegram-bot

## 简介

A package to send Laravel/Lumen logs to Telegram via Telegram Bot.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
