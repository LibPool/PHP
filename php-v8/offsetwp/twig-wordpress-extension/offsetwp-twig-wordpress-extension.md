# offsetwp/twig-wordpress-extension

> 标签: extension, offsetwp, template, template-tags, theme, twig, wordpress

## 简介

The functions of WordPress in Twig: {{ the_permalink() }}, {{ wp_head() }}, fn() for every other one, and the variables site, theme and user

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
