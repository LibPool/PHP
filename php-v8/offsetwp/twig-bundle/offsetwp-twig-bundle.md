# offsetwp/twig-bundle

> 标签: bundle, offsetwp, template, templating, twig, view, wordpress

## 简介

Twig integration for the OffsetWP Framework: zero configuration to start, every option when you need it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
