# mattwright/urlresolver

> 标签: canonical, link, redirect, resolve, url

## 简介

PHP class that attempts to resolve URLs to a final, canonical link.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
