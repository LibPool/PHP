# notgosu/yii2-meta-tag-module

> 标签: meta tag, seo, yii2

## 简介

Yii2 meta tag module for creating and setting meta tags for your site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
