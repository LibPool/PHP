# toteph42/filesync

> 标签: contao, e-mail, email, file, notification, synchonisation

## 简介

Extended file synchronisation bundle with user e-mail notification for Contao Open Source CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
