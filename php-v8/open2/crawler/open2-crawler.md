# open2/crawler

> 标签: crawler, luya, luya-module, module, php, yii, yii2

## 简介

An full search page crawler to enable complex and customized searching abilities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
