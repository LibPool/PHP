# protonsystems/paragraph-info

> 标签: PHP

## 简介

Reusable Drupal 11 module exposing stable paragraph anchor IDs and a permission-gated paragraph info overlay.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
