> 标签: common, common-gateway-plugin, commongateway, conduction, eerste inschrijving, first registration, gateway, symfony

## 简介

An example package for creating symfony flex bundles as plugins

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
