# common-gateway/sim-xml-to-zgw-bundle

> 标签: SimXML, common, common-gateway-plugin, commongateway, conduction, gateway, sim, symfony, xml, zgw

## 简介

Symfony bundle for translating SimXML messages into ZGW objects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
