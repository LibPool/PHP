# common-gateway/brk-bundle

> 标签: BRK, common, common-gateway-plugin, commongateway, conduction, gateway, symfony

## 简介

An example package for creating symfony flex bundles as plugins

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
