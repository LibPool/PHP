# anuzpandey/laravel-nepal-geo

> 标签: anuzpandey, laravel, laravel-nepal-geo

## 简介

A Laravel Package for Nepal's Province, Districts and City Data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
