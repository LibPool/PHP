# pupiq/image-scaler

> 标签: image, resize, scale, watermark

## 简介

PHP library for image resizing, cropping and format conversion. Supports JPEG, PNG, animated GIF, WebP, AVIF and HEIC.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
