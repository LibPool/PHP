# aiptu/playerwarn

> 标签: PHP

## 简介

A PocketMine-MP plugin that allows server administrators to issue warnings to players and keep track of their warning history.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
