# ankus/ankus

> 标签: capabilities, composer, dependencies, malware, security, static-analysis, supply-chain

## 简介

Capability analysis for Composer dependencies: know what your vendor code can do, and fail CI when an update gives it new powers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
