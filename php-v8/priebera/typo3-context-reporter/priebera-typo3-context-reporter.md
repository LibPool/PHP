# priebera/typo3-context-reporter

> 标签: backend, bug-report, editor-workflow, feedback, issue-report, screenshot, support, typo3, typo3-extension, webhook

## 简介

Support and bug reports for the TYPO3 backend: editors report a problem where it happens, and the page, record, file, site, language, workspace and system context is attached automatically.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
