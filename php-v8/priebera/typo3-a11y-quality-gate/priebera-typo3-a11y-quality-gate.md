# priebera/typo3-a11y-quality-gate

> 标签: CKEditor, EAA, a11y, accessibility, accessibility-audit, accessibility-checker, bfsg, bitv, editor-workflow, quality-gate, typo3, typo3-accessibility, typo3-extension, wcag

## 简介

TYPO3 accessibility checker and quality gate with CKEditor feedback, WCAG issue management, rendered page checks and editor workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
