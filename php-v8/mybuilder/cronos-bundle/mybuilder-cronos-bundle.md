# mybuilder/cronos-bundle

> 标签: cron, cronos

## 简介

Symfony 4/5/6 bundle which allows you to use @Cron annotations to configure cron to run your console commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
