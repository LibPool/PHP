# veewee/ext-wasm

> 标签: extension, wasm, wasmtime, webassembly

## 简介

WebAssembly for PHP: compile, instantiate and call wasm modules with an API modelled on the JavaScript WebAssembly API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
