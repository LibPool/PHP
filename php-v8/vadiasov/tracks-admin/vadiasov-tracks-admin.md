# vadiasov/tracks-admin

> 标签: PHP

## 简介

This package creates DB table tracks (music tracks). It uploads tracks. It serves CRUD pages of tracks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
