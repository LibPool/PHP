# brediweb/imagemupload

> 标签: image, imagem, laravel, laravel-upload, redimensionar, resize, upload

## 简介

Pacote de upload de imagens para Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
