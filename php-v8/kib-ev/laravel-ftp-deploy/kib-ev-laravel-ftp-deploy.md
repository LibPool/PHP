# kib-ev/laravel-ftp-deploy

> 标签: deploy, ftp, hosting, laravel, upload

## 简介

Deploy Laravel project files to shared hosting via FTP (Artisan command)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
