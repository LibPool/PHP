# craftix/lite-eloquent

> 标签: eloquent, high-performance, php, query, querybuilder

## 简介

Lightweight, dependency-free Eloquent-style PDO Query Builder for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
