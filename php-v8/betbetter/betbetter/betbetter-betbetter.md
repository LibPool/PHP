# betbetter/betbetter

> 标签: API-Client, betting, mlb, nba, nfl, odds, predictions, sports

## 简介

Zero-dependency PHP client for the free Bet Better sports model API: win probabilities, fair odds and plain-English verdicts. No API key. Data CC BY 4.0. Model estimates, not betting advice. 18+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
