# elibri/watermarking-client

> 标签: API-Client, ebook, elibri, epub, mobi, watermarking

## 简介

PHP client for the elibri watermarking and transactional API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
