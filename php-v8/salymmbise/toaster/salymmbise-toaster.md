# salymmbise/toaster

> 标签: alerts, laravel, notification, php, toast, toaster, ui

## 简介

Beautiful colorful toast notifications for PHP & Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
