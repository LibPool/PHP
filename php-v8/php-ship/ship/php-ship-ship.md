# php-ship/ship

> 标签: cross-platform, development-environment, devops, docker, octane, php

## 简介

Framework-agnostic, cross-platform Docker development environment for PHP — no WSL required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
