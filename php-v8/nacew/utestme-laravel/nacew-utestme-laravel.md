# nacew/utestme-laravel

> 标签: PHP

## 简介

uTestMe server errors for Laravel: unhandled exceptions with their request, breadcrumbs, and requests and 5xx per minute.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
