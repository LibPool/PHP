# mshuo/reply-to-see

> 标签: flarum, flarum-extension, hide, reply

## 简介

Hide content inside [REPLY]...[/REPLY]. Only the discussion starter can hide content. Others can view it after replying.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
