# dentmate/rajahan

> 标签: CBC, MD5, aes, base64, crypto, hash, security, sha-256, sha256

## 简介

PHP package for encryption/decryption using AES algorithm compatible with CryptoJS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
