# kakaska/flysystem-aws-s3-v3

> 标签: Flysystem, aws, file, files, filesystem, s3, satis, storage

## 简介

Satis friendly fork of AWS S3 filesystem adapter for Flysystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
