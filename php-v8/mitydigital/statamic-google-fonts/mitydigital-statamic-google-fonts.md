# mitydigital/statamic-google-fonts

> 标签: PHP

## 简介

Antlers support for Spatie's Laravel Google Fonts package in Statamic 3.3+ and Statamic 4.0+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
