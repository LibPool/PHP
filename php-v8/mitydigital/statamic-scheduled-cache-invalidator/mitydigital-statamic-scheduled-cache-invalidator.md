# mitydigital/statamic-scheduled-cache-invalidator

> 标签: cache, statamic

## 简介

A command to help invalidate the cache when scheduled Statamic entries are due to go live.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
