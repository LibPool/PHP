# mitydigital/statamic-tinymce-cloud

> 标签: statamic, tiny cloud, tinymce, tinymce cloud

## 简介

A Statamic fieldtype for TinyMCE using Tiny Cloud for Statamic 6.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
