# garbetjie/http-request-logger

> 标签: Guzzle, http, laravel, logging, psr, request

## 简介

A request logger that can log all incoming & outgoing requests and responses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
