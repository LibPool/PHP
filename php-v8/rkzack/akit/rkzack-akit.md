# rkzack/akit

> 标签: ai, anthropic, api, claude, llm, toolkit

## 简介

Lightweight PHP 8.4 toolkit for the Anthropic API — zero production dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
