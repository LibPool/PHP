# hippomundo/sitemap

> 标签: Sitemap, generator, google-news, html, laravel, laravelium, php, xml

## 简介

A maintained fork of the Laravelium Sitemap package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
