# opensolr/typo3-opensolr-search

> 标签: TYPO3 CMS, ai, opensolr, rag, search, solr, typo3, vector search

## 简介

Opensolr Search for TYPO3: hybrid AI search (keyword + vector), faceted navigation, autocomplete, analytics, AI Hints, AI Reader, Chat Bot and data ingestion, powered by the Opensolr Web Crawler. Zero indexing load on TYPO3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
