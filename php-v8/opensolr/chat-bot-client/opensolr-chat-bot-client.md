# opensolr/chat-bot-client

> 标签: assistant, chat, chatbot, opensolr, rag, site search, solr, widget

## 简介

A chatbot for any website whose content is in an Opensolr Index: mounted on one URL path of your own site, set up in its own admin page, added to your pages with one script tag. The Opensolr API searches your index, runs the tools and writes the answer; the visitor talks only to your site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
