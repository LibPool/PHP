# opensolr/laravel-opensolr-search

> 标签: hybrid-search, laravel, opensolr, scout, search, solr, vue

## 简介

Sample Laravel application: hybrid semantic search over an Opensolr index through Laravel Scout, with a Vue 3 front end and a grounded AI answer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
