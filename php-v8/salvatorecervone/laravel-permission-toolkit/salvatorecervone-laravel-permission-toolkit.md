# salvatorecervone/laravel-permission-toolkit

> 标签: acl, audit-log, integrity-check, laravel, laravel-package, matrix, permissions, rbac, roles, simulator, spatie, spatie-permission, user-manager

## 简介

Supercharge Spatie Laravel Permission with an AWS IAM-style Diagnostic Simulator, Visual Matrix, User Access Manager, Audit Trail, and Integrity Doctor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
