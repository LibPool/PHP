# salvatorecervone/rolepermissionmanager

> 标签: abac, access-control, acl, admin-panel, authorization, blade-directives, cache-optimized, dynamic-permissions, gate, laravel, laravel-acl, laravel-package, middleware, permissions, rbac, roles, route-permissions, zero-downtime

## 简介

A dynamic, database-driven Role & Permission Manager for Laravel. Replaces static middleware-based permission checks with a centralized, zero-hardcoding ACL system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
