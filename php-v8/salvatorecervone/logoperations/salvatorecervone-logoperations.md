# salvatorecervone/logoperations

> 标签: Audit, Viewer, activity-log, audit-log, dashboard, http-logger, laravel, log, logging, middleware, monitoring, operations, stack-trace, tracing, transactions, vue, vue3

## 简介

Pacchetto Laravel per il tracciamento automatico delle operazioni HTTP con supporto polimorfico, gestione transazioni, stack trace a 2 livelli e interfaccia Vue 3 moderna.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
