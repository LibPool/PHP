# viridem/log4php

> 标签: log, logging, php

## 简介

A versatile logging framework for PHP. Forked from apache/log4php

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://logging.apache.org/log4php/
- 源码仓库：https://github.com/viridem-team/log4php.git
- Packagist 页面：https://packagist.org/packages/viridem%2Flog4php

- 许可证：Apache-2.0
