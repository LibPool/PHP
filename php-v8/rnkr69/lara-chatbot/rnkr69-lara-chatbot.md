# rnkr69/lara-chatbot

> 标签: chatbot, laravel, llm, prism, streaming, tools, web-component

## 简介

Embeddable chatbot for Laravel 11/12 with LLM streaming, backend tools, frontend tools and a stack-agnostic Web Component widget.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
