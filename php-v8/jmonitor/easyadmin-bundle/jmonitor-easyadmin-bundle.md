# jmonitor/easyadmin-bundle

> 标签: Metrics, Opcache, apache, easyadmin, frankenphp, monitoring, mysql, nginx, php, postgresql, redis, symfony, system

## 简介

Live monitoring pages inside EasyAdmin: system, PHP, FrankenPHP, Apache, Nginx, MySQL, PostgreSQL, Redis and Symfony metrics collected when you open the page, no worker required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
