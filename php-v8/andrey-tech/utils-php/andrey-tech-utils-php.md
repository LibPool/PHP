# andrey-tech/utils-php

> 标签: files, json, utils

## 简介

Набор трейтов, содержащих общие вспомогательные методы для работы с файлами, каталогами, данными в формате JSON и т.п.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
