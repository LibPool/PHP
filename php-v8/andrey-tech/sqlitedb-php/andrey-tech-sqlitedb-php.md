# andrey-tech/sqlitedb-php

> 标签: database, pdo, php, sqlite

## 简介

Простая библиотека для работы с СУБД SQLite 3 для несложных проектов на PHP7+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
