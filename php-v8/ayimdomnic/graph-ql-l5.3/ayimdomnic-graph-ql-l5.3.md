# ayimdomnic/graph-ql-l5.3

> 标签: api, graphql, laravel, php, schema

## 简介

A modern, feature-rich GraphQL package for Laravel — types, queries, mutations, subscriptions, pagination, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
