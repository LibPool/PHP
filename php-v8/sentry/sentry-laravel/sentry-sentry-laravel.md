# sentry/sentry-laravel

> 标签: crash-reporting, crash-reports, error-handler, error-monitoring, laravel, log, logging, profiling, sentry, tracing

## 简介

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
