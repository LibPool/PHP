# orieg/expanse

> 标签: data-structures, ffi, judy, libjudy, ordered-map, radix-tree, trie

## 简介

Native PHP bindings for Expanse via PIE / C ABI / FFI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
