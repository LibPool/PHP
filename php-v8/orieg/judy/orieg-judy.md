# orieg/judy

> 标签: bitset, data-structures, extension, judy, judy-arrays, memory, performance, pie, sparse-array, trie

## 简介

PHP Judy implements sparse dynamic arrays (aka Judy Arrays).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
