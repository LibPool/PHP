# flooris/laravel-toggl

> 标签: Laravel 5.2, laravel, laravel 5, laravel 5.3, timetracker, toggl

## 简介

Laravel 5 service provider for Toggl, the time tracker app

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
