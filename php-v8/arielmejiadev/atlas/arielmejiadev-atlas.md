# arielmejiadev/atlas

> 标签: arielmejiadev, atlas, geocoder, laravel, offline

## 简介

Offline geocoder for Laravel — fills latitude/longitude from a bundled SQLite database, no API calls.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
