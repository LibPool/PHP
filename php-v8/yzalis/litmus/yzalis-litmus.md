# yzalis/litmus

> 标签: email preview, email subject preview, email testing, spam testing

## 简介

Litmus API Wrapper allows you to run email, spam test and email subject preview.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
