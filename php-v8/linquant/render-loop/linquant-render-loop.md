# linquant/render-loop

> 标签: approval-testing, characterization-test, diff, golden-master, html, legacy, regression, snapshot

## 简介

A render regression net for PHP apps: capture a page's rendered HTML, change it, re-check — only the real change shows, the noise (DebugBar, scripts, CSRF tokens, timestamps) is masked. Semantic HTML diff, automatic noise calibration, golden-master mode. CLI + JSON, usable by a human or an AI agent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
