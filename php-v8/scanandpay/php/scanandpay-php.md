# scanandpay/php

> 标签: australia, payid, payments, payto, qr, scanandpay

## 简介

Official Scan & Pay PHP SDK — accept PayTo PayID payments via QR.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
