# pagamastarde/orders-api-client

> 标签: PHP

## 简介

Pagantis Orders Api Client in PHP. Use the api with simple methods and using OOP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
