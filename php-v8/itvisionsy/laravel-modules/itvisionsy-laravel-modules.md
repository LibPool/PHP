# itvisionsy/laravel-modules

> 标签: laravel, modules

## 简介

Laravel 5.1 library to allow modules structure. Each module can have its routes, controllers, views, config, ...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
