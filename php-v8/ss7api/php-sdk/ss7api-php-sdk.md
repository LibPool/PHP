# ss7api/php-sdk

> 标签: dtmf, otp, sms, ss7api, transactional-messaging, voice, webhooks

## 简介

Official PHP SDK for the SS7API transactional Call, SMS, OTP and Webhooks API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
