# twachikku/arangodb

> 标签: Arango, ArangoDb, database, distributed, document store, graph database, multi-model, nosql

## 简介

ArangoDB PHP client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
