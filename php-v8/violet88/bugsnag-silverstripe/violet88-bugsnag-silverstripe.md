# violet88/bugsnag-silverstripe

> 标签: Violet88, bugsnag, cms, silverstripe

## 简介

A module to use Bugsnag in SilverStripe projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
