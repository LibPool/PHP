# violet88/bugsnag-silverstripe-vue

> 标签: Violet88, bugsnag, cms, silverstripe

## 简介

A module to use Bugsnag in SilverStripe projects together with Bugsnag for Vue.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
