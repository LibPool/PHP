# chasdevs/avro-parser

> 标签: PHP

## 简介

A lightweight PHP library for parsing Avro .avsc strings into representative objects. Used in chasdevs/avro-to-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
