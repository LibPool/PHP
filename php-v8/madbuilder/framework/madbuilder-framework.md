# madbuilder/framework

> 标签: ERP, admin, ai, alpinejs, blade, components, crud, dashboard, framework, laravel, low-code, madbuilder, mcp, reactive

## 简介

Mad Framework: the open-source Laravel runtime behind MadBuilder apps. Server-driven <mad-*> Blade components, reactive UI without a build step, IAM, i18n, PDF, MCP server and AI copilot.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
