# grobitec/contao-backend-buttons-bundle

> 标签: backend, buttons, contao, copy, delete, extension, move, operations

## 简介

Contao 5.7 Erweiterung - Backend-Operationen (Kopieren, Verschieben, Löschen etc.) wieder direkt sichtbar machen

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
