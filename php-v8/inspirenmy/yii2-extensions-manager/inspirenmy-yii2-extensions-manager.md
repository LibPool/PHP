# inspirenmy/yii2-extensions-manager

> 标签: extension, extensions, plugin, plugins, yii2

## 简介

Manage and install your yii2 extensions in browser!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
