# layman/laravel-cipher

> 标签: aes, cipher, encryption, laravel, rsa

## 简介

基于 AES-256-GCM + RSA 的 Laravel API 请求与响应加密扩展包

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
