# rerout/sdk

> 标签: URL-Shortener, branded-links, qr-codes, rerout, sdk, short-links

## 简介

Official PHP SDK for the Rerout branded-link API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
