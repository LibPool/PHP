# lifo/php-color

> 标签: color, colorwheel, convert, harmonies, hsl, hsv, rgb

## 简介

Color library for PHP. Create and convert colors on the Color Wheel using rgb, hsl, hsv, cmy, cmyk formats.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
