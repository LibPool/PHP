# pursehouse/modeler-laravel-eloquent

> 标签: eloquent, laravel, model, models

## 简介

Generate model classes for Eloquent in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
