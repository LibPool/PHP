# dashserv/php-api-sdk

> 标签: PHP

## 简介

An official PHP SDK for the dashserv REST-API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://dashserv.io
- 源码仓库：https://github.com/dashserv/php-api-sdk.git
- Packagist 页面：https://packagist.org/packages/dashserv%2Fphp-api-sdk
