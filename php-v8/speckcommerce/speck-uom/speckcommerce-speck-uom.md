# speckcommerce/speck-uom

> 标签: ecommerce, speckcommerce, uom

## 简介

UoM codes as specified by UN/CEFACT Recommendation #20

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
