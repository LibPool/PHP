# symplely/hooks

> 标签: actions, api, dispatcher, emit, emitter, event, filters, hooks, trigger

## 简介

A simple event dispatching plugin library, a ported fork of WordPress hook API system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
