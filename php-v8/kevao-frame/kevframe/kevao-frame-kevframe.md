# kevao-frame/kevframe

> 标签: framework, mvc, orm, php

## 简介

Un framework de PHP ligero, seguro y elegante para el desarrollo rápido de aplicaciones web.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
