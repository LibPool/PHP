# rezzza/mailchimp-bundle

> 标签: bundle, mailchimp, newsletter, symfony

## 简介

Mailchimp bundle for Symfony2 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
