# mauticinsights/mautic-observer

> 标签: Mautic, plugin

## 简介

Observes Mautic contact, email, campaign, form, page and segment events and streams them to the Mautic Insights ingest API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
