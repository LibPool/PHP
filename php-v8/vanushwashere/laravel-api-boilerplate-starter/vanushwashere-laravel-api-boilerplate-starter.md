# vanushwashere/laravel-api-boilerplate-starter

> 标签: api, boilerplate, laravel

## 简介

A version of francescomalatesta/laravel-api-boilerplate-jwt but without jwt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
