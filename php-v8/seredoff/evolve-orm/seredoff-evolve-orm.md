# seredoff/evolve-orm

> 标签: array conversion, ddd, domain, hydrator, object conversion, orm, performance, serializer

## 简介

Адаптивное ORM для проектов с динамично развивающейся доменной моделью

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
