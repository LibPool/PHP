# rapidkit/laravel-camunda-client

> 标签: camunda, camunda client, laravel, laravolt

## 简介

High level model, something like Eloquent, to interact with Camunda resources via REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
