# vntrungld/zalo-bot-php-sdk

> 标签: bot, chatbot, messaging, sdk, zalo, zalo-bot

## 简介

PHP SDK for the Zalo Bot Platform API (https://bot.zapps.me/docs/)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
