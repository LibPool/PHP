# leapocr/leapocr-php

> 标签: OCR, ai, document-extraction, document-processing, php, sdk

## 简介

Official PHP SDK for LeapOCR - Transform documents into structured data using AI-powered OCR.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
