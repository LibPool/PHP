# swiss-social-archives/alephmarc2xml

> 标签: Aleph, marc, xml

## 简介

This php class converts an MARC output from Aleph to a XML file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
