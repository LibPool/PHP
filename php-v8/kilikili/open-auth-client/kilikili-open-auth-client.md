# kilikili/open-auth-client

> 标签: OpenId, authorisation, authorization, client, oauth, oauth2

## 简介

Abstract auth clinet for oauth, oauth2, openid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
