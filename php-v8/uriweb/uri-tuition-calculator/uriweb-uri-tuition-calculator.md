# uriweb/uri-tuition-calculator

> 标签: PHP

## 简介

URI Tuition Calculator is a Wordpress plugin that calculates the estimated cost of Summer and J-Term courses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
