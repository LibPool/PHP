# uriweb/uri-code-compliance

> 标签: PHP

## 简介

URI Code Compliance is a Wordpress plugin that checks for and displays errors related to ADA compliance and other coding issues.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
