# uriweb/uri-ticks

> 标签: PHP

## 简介

URI Ticks is a Wordpress plugin that creates custom posts, fields, and interaction for URI Tick Encounter data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
