# fast-media/contao-privacy-check

> 标签: Backend-Verwaltung, Datenschutz, Extern, Rechtliches, Seitenlayout, backend, check, cloud, dsgvo, google, google fonts, javascript, jquery, layout, mootools, problem, Überprüfung

## 简介

Datenschutz Check: Die Contao Erweiterung prüft nach Installation alle Seitenlayouts einer Contao Installation, ob Google Fonts oder Cloud-Dienste wie jQuery.com, bootstrap.com oder Google Analytics etc. eingebunden sind.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
