# fast-media/contao-extended-navigation

> 标签: Ausschließen, Hauptnavigation, Seitenstruktur, contao, navigation

## 简介

Erweiterte Navigation: Diese Contao Erweiterung Ignoriert auf Wunsch bestimmte Seiten in Navigation oder Breadcrumb

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
