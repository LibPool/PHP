# nobrainer/silverstripe-icon-picker

> 标签: cms, icon, icon-picker, silverstripe, svg

## 简介

A self-hosted, SVG-based icon picker field for Silverstripe CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
