# nobrainer/silverstripe-qr-code

> 标签: cms, qr, qrcode, silverstripe

## 简介

Create QR codes with redirection in Silverstripe CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
