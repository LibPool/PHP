# ecs/basic

> 标签: ECS, ecomstyle, ecomstyle.de

## 简介

Das Modul laedt einige Must-Have Module für OXID6 im Paket herunter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
