# mtubis/html-translator-laravel

> 标签: Gemini, ai, anthropic, html, html-translation, i18n, l10n, laravel, laravel-package, llm, localization, ollama, openai, translation

## 简介

Laravel integration for mtubis/html-translator: translate HTML with LLMs (OpenAI, Anthropic, Gemini, Ollama, …) while preserving markup — config, facade, Artisan, cache, logging and a test fake.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
