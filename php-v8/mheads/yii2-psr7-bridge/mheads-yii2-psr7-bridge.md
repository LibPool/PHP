# mheads/yii2-psr7-bridge

> 标签: Bridge, http, psr-17, psr-7, yii2

## 简介

Bridge for converting Yii2 HTTP request and response objects to and from PSR-7 HTTP messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
