# mheads/yii2-data-db

> 标签: adapter, data-reader, query, yii2, yiisoft-data

## 简介

Adapter for using Yii2 DB queries as yiisoft/data readers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
