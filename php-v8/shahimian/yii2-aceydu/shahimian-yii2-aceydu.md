# shahimian/yii2-aceydu

> 标签: acey, card game, ducey, extension, simulation, yii2

## 简介

This is a simulation of the Acey Ducey card game.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
