# inttegro/sdk

> 标签: Ghana, checkout, commerce, fintech, ghs, mobile-money, payments, sdk

## 简介

Official PHP SDK for the Inttegro API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
