# ysg/laravel-mpesa

> 标签: daraja, fintech, kenya, laravel, mpesa, payments, safaricom

## 简介

Official Safaricom Daraja M-Pesa integration for Laravel built on ysg/payment-core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
