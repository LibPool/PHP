# orvelo/heartbeat-client

> 标签: PHP

## 简介

Orvelo Heartbeat client - get alerts when your scripts don't complete a healthcheck check-in

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
