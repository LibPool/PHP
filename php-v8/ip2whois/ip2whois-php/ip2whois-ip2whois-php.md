# ip2whois/ip2whois-php

> 标签: PHP

## 简介

IP2WHOIS PHP SDK to help user to check WHOIS information for a particular domain.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
