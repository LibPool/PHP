# mercanpay/mercanpay-php

> 标签: USDT, crypto, gateway, mercanpay, payment, trc20, tron, trx

## 简介

Official PHP client for the MercanPay crypto payment gateway (TRX & USDT-TRC20)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
