# ziixdk/admin

> 标签: admin, alpinejs, form, free, grid, laravel, tailwind, ziix-admin, ziixdk

## 简介

ziix-admin v4. Open-source Laravel Admin panel with Tailwind CSS v4 + Alpine.js. Free & open. Based on laravel-admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
