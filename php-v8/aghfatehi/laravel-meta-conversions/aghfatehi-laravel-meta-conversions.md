# aghfatehi/laravel-meta-conversions

> 标签: PHP

## 简介

Laravel package for Facebook Pixel and Meta Conversion API (CAPI) with event deduplication, queue support, and ecommerce tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
