# wpackagist-plugin/wpal-autoload

> 标签: plugin, wordpress, wpal-autoload

## 简介

Wp Autoload with Namespaces (For better and clean plugin code using OOP)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
