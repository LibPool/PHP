# postyou/contao-pdf-metadata

> 标签: exiftool, gdpr, qpdf

## 简介

Extends the contao file manager to clean up the metadata of PDF files for privacy reasons

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
