# king-of-web-designs/laravel-xpos

> 标签: King Of Web Designs, laravel, laravel-xpos

## 简介

This package connects the Xpos till system to a laravel application via the Xpos API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
