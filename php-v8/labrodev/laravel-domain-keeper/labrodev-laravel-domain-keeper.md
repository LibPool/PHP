# labrodev/laravel-domain-keeper

> 标签: domain, expiry, labrodev, laravel, rdap, whois

## 简介

Domain registrar-expiry reader for Laravel — RDAP first with a port-43 WHOIS fallback.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
