> 标签: eloquent, labrodev, laravel, laravel-package, laravel-translatable, laravel-utility, laravel-utils, models, query-builder, translatable

## 简介

Laravel package providing a reusable trait for multilingual search in Eloquent JSON fields.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
