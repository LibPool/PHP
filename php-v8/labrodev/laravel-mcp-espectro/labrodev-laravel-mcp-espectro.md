# labrodev/laravel-mcp-espectro

> 标签: colors, espectro, laravel, mcp, palette, sanzo-wada

## 简介

Connect your Laravel app to the Espectro MCP server (Sanzo Wada color combinations).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
