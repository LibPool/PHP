# labrodev/php-enum-mapper

> 标签: enum, enum-mapper, helper, labrodev, php, static, utility

## 简介

PHP utility class for formatting Enums and to treat the cases as arrays

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
