# send4/php-sigep

> 标签: correios, logistica reversa, sigep

## 简介

Integração com Web Service do Correios + Logística Reversa. Fork do pacote stavarengo/php-sigep.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
