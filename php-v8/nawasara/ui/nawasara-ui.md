# nawasara/ui

> 标签: Nawasara, blade-components, laravel, livewire, lucide, tailwind, ui

## 简介

UI components, layouts, theme, and shared Livewire concerns for the Nawasara superapp framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
