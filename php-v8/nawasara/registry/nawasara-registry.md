# nawasara/registry

> 标签: Nawasara, asset, laravel, opd, ownership, pic, registry

## 简介

Master data for OPD (organizational units), PIC (person-in-charge), and asset ownership across Nawasara packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
