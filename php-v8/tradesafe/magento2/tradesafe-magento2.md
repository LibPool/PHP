# tradesafe/magento2

> 标签: PHP

## 简介

TradeSafe, backed by Standard Bank, provides an escrow payments-based solution that integrates seamlessly with your existing Magento store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
