# koutendb/koutendb

> 标签: database, ffi, koutendb, nosql, rag, retrieval

## 简介

PHP driver for KoutenDB with native TCP and optional embedded FFI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
