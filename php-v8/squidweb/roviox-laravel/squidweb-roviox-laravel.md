# squidweb/roviox-laravel

> 标签: laravel, mail, newsletter, roviox, transactional

## 简介

Laravel SDK for the Roviox API: transactional email, support tickets and newsletter campaigns.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
