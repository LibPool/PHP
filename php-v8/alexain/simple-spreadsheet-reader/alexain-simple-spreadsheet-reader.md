# alexain/simple-spreadsheet-reader

> 标签: PHP

## 简介

A lightweight Symfony bundle to read spreadsheet-like files (CSV, XLSX) using a unified, streaming-friendly API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
