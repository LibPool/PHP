# rawveg/gitlab

> 标签: PHP

## 简介

Provides a Service and Provider to allow your Laravel codebase to connect to the Gitlab API using the GitLab PHP API Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
