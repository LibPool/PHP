# postedin/fxmlrpc

> 标签: api, performance, rpc, xml, xmlrpc

## 简介

Fast and tiny XML/RPC client with bridges for various HTTP clients

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
