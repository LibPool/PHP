# i-avatar777/yii2-service-form-ajax

> 标签: yii2-service-form-ajax

## 简介

Сервис для yii2 для для валидации и исполнения формы по AJAX

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
