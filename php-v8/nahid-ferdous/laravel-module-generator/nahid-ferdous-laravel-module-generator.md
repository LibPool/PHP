# nahid-ferdous/laravel-module-generator

> 标签: Laravel Development Tools, code generator, controller generator, crud generator, laravel, laravel artisan, laravel automation, laravel module, laravel package, laravel scaffolding, migration generator, model generator, module generator, php code generation, request generator, resource generator, scaffolding, service layer, yaml

## 简介

Speeds up Laravel development by automating repetitive tasks. This package helps to generate module files (service, controller, model, migration, resource, request, collection) from YAML file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
