# nelmio/security-bundle

> 标签: security

## 简介

Extra security-related features for Symfony: signed/encrypted cookies, HTTPS/SSL/HSTS handling, cookie session storage, ...

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
