# ampersand/magento2-disable-stock-reservation

> 标签: PHP

## 简介

This module disables the inventory reservation logic introduced as part of MSI in Magento 2.3.3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
