# bpmore/statamic-a11y-docs

> 标签: a11y, accessibility, pdf, pdf-ua, statamic

## 简介

Document accessibility checking for the Statamic asset library: PDF, Word, PowerPoint and Excel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
