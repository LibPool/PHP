# bpmore/statamic-site-weather

> 标签: accessibility, dashboard, health, statamic, widget

## 简介

One dashboard tile that shows your site's overall health as weather, read from the addons that already measure it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
