# bpmore/statamic-a11y-gate

> 标签: a11y, accessibility, statamic, wcag

## 简介

Refuses to publish a Statamic entry that fails the accessibility checks it can actually run.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
