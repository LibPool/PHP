# bpmore/statamic-beacon

> 标签: Announcement, alert, banner, cap, emergency, statamic

## 简介

A site-wide alert banner for Statamic: authored locally or fed from a remote source, scheduled, severity-graded, audience-targeted, accessible, and correct behind static caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
