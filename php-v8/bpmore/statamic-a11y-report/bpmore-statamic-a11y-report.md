# bpmore/statamic-a11y-report

> 标签: a11y, accessibility, acr, report, statamic, wcag

## 简介

Scans every page of a Statamic site over time and keeps the evidence: findings, coverage, and the state of each problem from one scan to the next.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
