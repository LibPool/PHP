# jeffreyvanrossum/pace-logger

> 标签: PACE, dd, debug, dump, laravel, logger

## 简介

PHP client for the Pace logger panel — push values to a local Pace inspector over HTTP, with a `pace()` helper and a Laravel dump()/dd() hook.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
