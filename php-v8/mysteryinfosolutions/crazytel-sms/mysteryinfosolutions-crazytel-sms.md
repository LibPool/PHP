# mysteryinfosolutions/crazytel-sms

> 标签: australia, crazytel, laravel, sms

## 简介

Laravel package for sending SMS via the Crazytel API (https://developer.crazytel.io)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
