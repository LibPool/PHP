# ponito/elastico

> 标签: aggregations, elasticsearch, eloquent, ilm, laravel, orm, search

## 简介

Elasticsearch Eloquent ORM for Laravel: models, query builder, aggregations, ILM and scripted updates on Elasticsearch 8

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
