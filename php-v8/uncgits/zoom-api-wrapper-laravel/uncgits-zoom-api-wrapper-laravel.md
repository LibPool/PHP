# uncgits/zoom-api-wrapper-laravel

> 标签: api, laravel, php, uncg, uncgits, zoom

## 简介

Laravel Wrapper for Zoom API PHP Library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
