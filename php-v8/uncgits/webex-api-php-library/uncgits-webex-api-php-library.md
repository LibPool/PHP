# uncgits/webex-api-php-library

> 标签: api, php, uncg, uncgits, webex

## 简介

PHP Library used to interact with the WebEx API for UNCG

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
