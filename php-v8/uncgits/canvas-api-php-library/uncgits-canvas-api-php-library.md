# uncgits/canvas-api-php-library

> 标签: api, canvas, instructure, php, uncg, uncgits

## 简介

PHP Library used to interact with the Canvas API for UNCG

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
