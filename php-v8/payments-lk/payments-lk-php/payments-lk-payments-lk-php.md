# payments-lk/payments-lk-php

> 标签: checkout, lkr, payable, payments, payments.lk, sri lanka, webhooks

## 简介

PHP server SDK for the Payments.lk API: checkouts, payments, refunds, payment links, saved cards, events, the account and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
