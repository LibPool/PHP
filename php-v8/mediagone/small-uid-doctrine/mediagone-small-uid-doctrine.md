# mediagone/small-uid-doctrine

> 标签: UID, database, doctrine, entity, guid, primary key, type, ulid, uuid

## 简介

Provides Doctrine types for mediagone/small-uid package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
