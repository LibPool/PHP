# codebyray/livewire-media-uploader

> 标签: alpinejs, component, file-uploads, laravel, livewire, media-library, spatie, spatie-laravel-medialibrary, tailwindcss, uploader

## 简介

Reusable Livewire v3/v4 media uploader that integrates with Spatie Media Library and ships a publishable view.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
