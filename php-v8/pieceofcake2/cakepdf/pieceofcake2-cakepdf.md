# pieceofcake2/cakepdf

> 标签: cakephp, cakephp2, pdf

## 简介

CakePHP plugin for creating and/or rendering Pdf, several Pdf engines supported.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
