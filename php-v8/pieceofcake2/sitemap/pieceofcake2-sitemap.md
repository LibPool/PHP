# pieceofcake2/sitemap

> 标签: Behavior, Sitemap, cakephp, cakephp2, model

## 简介

A CakePHP 2 Plugin for adding automatic XML and HTML Sitemaps to an app

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
