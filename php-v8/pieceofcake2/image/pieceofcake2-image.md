# pieceofcake2/image

> 标签: Behavior, cakephp, cakephp2, image, svg, upload, validation, xss

## 简介

CakePHP 2 plugin that validates uploaded images by their contents: JPEG, PNG, GIF, WebP and strictly allowlisted SVG

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
