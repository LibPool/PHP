# pieceofcake2/panther

> 标签: Panther, cakephp, cakephp2, chrome, e2e, end-to-end, fixtures, phpunit, testing, webdriver

## 简介

End-to-End tests for CakePHP 2 applications with Symfony Panther and PHPUnit

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
