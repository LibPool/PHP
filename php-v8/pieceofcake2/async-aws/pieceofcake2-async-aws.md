# pieceofcake2/async-aws

> 标签: async-aws, aws, cakephp, cakephp2, dynamodb, s3, ses

## 简介

AsyncAws integration for CakePHP 2: DynamoDB session handler and cache, Amazon SES email transport, S3 helper

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
