# pieceofcake2/acl_menu

> 标签: acl, cakephp, cakephp2, menu, navigation

## 简介

CakePHP 2 component that builds navigation menus of the actions a user may access with ACL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
