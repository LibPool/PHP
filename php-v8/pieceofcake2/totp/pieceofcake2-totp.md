# pieceofcake2/totp

> 标签: 2fa, authenticate, cakephp, cakephp2, google-authenticator, otp, totp, two-factor

## 简介

Two-factor authentication with time-based one-time passwords (TOTP, RFC 6238) for the CakePHP 2 AuthComponent

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
