# pieceofcake2/acl_extras

> 标签: acl, aco, cakephp, cakephp2

## 简介

Console tools for DbAcl in CakePHP 2: generate ACOs for controllers and actions, verify and recover ACL trees

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
