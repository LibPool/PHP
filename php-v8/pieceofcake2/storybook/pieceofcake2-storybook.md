# pieceofcake2/storybook

> 标签: cakephp, cakephp2, storybook, vite

## 简介

Storybook for CakePHP 2 (development only): render Elements in Storybook (Vite), inspired by Storybook for Symfony

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
