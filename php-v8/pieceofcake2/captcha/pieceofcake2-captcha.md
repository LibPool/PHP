# pieceofcake2/captcha

> 标签: cakephp, cakephp2, captcha, hcaptcha, recaptcha, turnstile

## 简介

CAPTCHA plugin for CakePHP 2: Cloudflare Turnstile, Google reCAPTCHA v2/v3 and hCaptcha

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
