# pieceofcake2/filebinder

> 标签: attachment, cakephp, cakephp2, file, s3, upload

## 简介

Simple file attachment plugin for CakePHP 2: local files, database and Amazon S3 storage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
