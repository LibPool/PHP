# pieceofcake2/security-sca

> 标签: Audit, composer, cve, pdf, report, sca, security, vulnerability

## 简介

Software composition analysis of an application: the known vulnerabilities of its Composer packages (composer audit), as a PDF report by CVE and risk

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
