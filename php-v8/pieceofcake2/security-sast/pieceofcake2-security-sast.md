# pieceofcake2/security-sast

> 标签: PHPStan, SAST, cakephp, cakephp2, owasp, pdf, report, security, semgrep

## 简介

Static application security testing of a CakePHP 2 application with Semgrep or PHPStan, as a PDF report by rule and risk

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
