# pieceofcake2/phpcs-cakephp2

> 标签: Coding Standard, cakephp, cakephp2, codesniffer, phpcs

## 简介

PHP_CodeSniffer ruleset for CakePHP 2 applications and plugins, based on the CakePHP coding standard

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
