# pieceofcake2/docs

> 标签: ai, cakephp, cakephp2, docs, documentation, markdown

## 简介

Markdown documentation of pieceofcake2/cakephp (CakePHP 2 fork), for reading locally and by AI tools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
