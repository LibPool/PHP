# pieceofcake2/security-dast

> 标签: DAST, ZAP, cakephp, cakephp2, owasp, pdf, report, security, zaproxy

## 简介

Dynamic application security testing of a running CakePHP 2 application with the OWASP ZAP baseline scan, as a PDF report by alert and risk

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
