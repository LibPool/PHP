# pieceofcake2/security-check

> 标签: DAST, PHPStan, SAST, ZAP, cakephp, cakephp2, owasp, pdf, report, sca, security, semgrep

## 简介

The security checks of a CakePHP 2 application in one command: the Composer packages (SCA), the code (SAST) and the running application (DAST), each as a PDF report

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
