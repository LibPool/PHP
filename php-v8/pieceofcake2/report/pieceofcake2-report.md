# pieceofcake2/report

> 标签: chrome, headless, pdf, report, security, testing

## 简介

A4 PDF reports printed by the Chrome command line: a cover with the result, a list and a page for each item

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
