# pieceofcake2/security-headers

> 标签: cakephp, cakephp2, content-security-policy, csp, headers, hsts, security

## 简介

CakePHP 2 plugin that adds the security headers to every response of an application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
