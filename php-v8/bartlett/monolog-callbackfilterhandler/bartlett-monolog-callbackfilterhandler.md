# bartlett/monolog-callbackfilterhandler

> 标签: handler, log, logger, logging

## 简介

Monolog handler wrapper that filters records based on a list of callback functions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
