> 标签: approval-workflow, business-process, cache, database, eloquent, laravel, laravel-package, middleware, orchestration, pipeline, redis, state-machine, state-transition, workflow, workflow-engine

## 简介

Application-level workflow orchestration for Laravel with state transitions, audit history, rollback support, cache and database drivers, Eloquent integration, and a fluent API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
