# tavp/tavphub

> 标签: admin, bread, crud, panel, tavp

## 简介

TAVPhub — free Laravel-Nova-style admin panel for TAVP (Phalcon). Resources, filters, metrics, actions, lenses, relations, policies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
