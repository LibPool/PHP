# tavp/cms

> 标签: bread, cms, content-management, flat-file, phalcon, tavp

## 简介

TAVP CMS — standalone content management system built on tavp/core. Pluggable storage, headless API, BREAD admin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
