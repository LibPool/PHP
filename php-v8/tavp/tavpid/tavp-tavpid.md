# tavp/tavpid

> 标签: auth, jwt, otp, rbac, session, tavp

## 简介

TAVPid — OTP-first authentication for TAVP (email/SMS/WhatsApp OTP, JWT, session, RBAC).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
