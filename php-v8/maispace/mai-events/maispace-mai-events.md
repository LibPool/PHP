# maispace/mai-events

> 标签: PHP

## 简介

Event management extension with list and detail views and iCal export. Supports event registration with waiting list. Categories use TYPO3 `sys_category`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
