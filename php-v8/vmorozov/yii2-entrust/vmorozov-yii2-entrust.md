# vmorozov/yii2-entrust

> 标签: Users, extension, module, permissions, rbac, roles, yii2

## 简介

Roles and permissions system like zizaco/entrust in laravel for yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
