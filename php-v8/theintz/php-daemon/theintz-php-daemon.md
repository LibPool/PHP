# theintz/php-daemon

> 标签: daemon, php

## 简介

Create solid, long-running PHP daemon processes. This is a fork of shaneharter/php-daemon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
