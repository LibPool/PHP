# homelan/l3fsreader

> 标签: afs, econet filestore, econet level 3

## 简介

Provides class for reading disk images from the Acorn Econet level 3 fileserver, and the Acorn Econet filestore.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
