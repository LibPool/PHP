# homelan/acorn-mode7

> 标签: acorn, mode7, teletext, viewdata

## 简介

Provides a class for build png/jpeg/gif images of raw mode 7 graphics data from the BBC Mirco (teletext, and viewdata)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
