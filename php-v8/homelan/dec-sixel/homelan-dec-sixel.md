# homelan/dec-sixel

> 标签: VT200, VT320, VT330, VT340, sixel

## 简介

Provides a class that produces the sixel terminal ouput needed to display a png|jepg|gif image

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
