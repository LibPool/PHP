# liuzongquan/yii2-rabbitmq-log

> 标签: extension, log, rabbitmq, yii2

## 简介

Yii 2 extension wrapper to communicate with RabbitMQ server via AMQP. Based on php-amqplib/php-amqplib.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
