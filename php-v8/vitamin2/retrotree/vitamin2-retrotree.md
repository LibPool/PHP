# vitamin2/retrotree

> 标签: kirby-retro-tree, kirby3, kirby3-cms, kirby3-plugin, retro-tree, retrotree

## 简介

Retrotree is a kirby 3 section plugin to display pages in real retro tree fashion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
