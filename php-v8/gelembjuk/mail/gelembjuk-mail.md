# gelembjuk/mail

> 标签: PHP

## 简介

Creates email body and subject from templates using Smarty or Twig and send email with one of supported mailes (PHPMailer, mail() function etc)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
