# zxf/security

> 标签: IP, firewall, laravel, middleware, protection, security, thinkphp, zxf

## 简介

Laravel / ThinkPHP 安全中间件 - 简洁、轻量、低误报的跨框架请求拦截包

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
