# zxf/modules

> 标签: laravel, modular, module, modules, multi-module, package, zxf

## 简介

一个适用于Laravel 11+ / 12+ / 13+ 版本的现代化、多模块化扩展，最小化框架依赖

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
