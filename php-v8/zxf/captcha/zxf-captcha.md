# zxf/captcha

> 标签: captcha, laravel, php-captcha, slide-captcha, thinkphp, 滑动验证码, 验证码

## 简介

高性能滑动验证码 PHP 扩展包，支持 Laravel、ThinkPHP 等主流框架

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
