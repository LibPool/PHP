# zxf/dom

> 标签: HTML5, Xpath, css, curl, dom, html, html-parser, http, php, spider, util, utils, web-scraper, xml, xml-parser

## 简介

一个功能强大、易于使用的 PHP DOM 操作库，提供简洁的 API 来解析、查询和操作 HTML/XML 文档

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
