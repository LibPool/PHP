> 标签: DOM操作, Xpath, array, barcode, crypto, css, curl, dom, file, html, html-parser, http, image, oauth, php, php82, php83, php84, qrcode, tool, tools, tree, util, utils, web-scraper, xml, xml-parser, 工具

## 简介

现代化的 PHP 工具包，包含强大的 DOM 操作库、数据转换和一些常用的类库、HTTP网络请求、代码压缩、通用函数集和实用工具等

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
