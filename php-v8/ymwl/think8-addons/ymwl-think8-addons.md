# ymwl/think8-addons

> 标签: PHP

## 简介

The ThinkPHP 8.0.0 Addons Package, with unified addon config management (file defaults + addon_config database storage with cache)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
