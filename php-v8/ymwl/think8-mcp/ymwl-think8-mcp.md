# ymwl/think8-mcp

> 标签: ai, claude, cursor, mcp, model-context-protocol, thinkphp

## 简介

MCP (Model Context Protocol) server for ThinkPHP 8.x — let AI tools (Claude Code, Cursor, Windsurf) understand and operate your project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
