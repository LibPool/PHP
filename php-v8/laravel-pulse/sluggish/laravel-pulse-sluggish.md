# laravel-pulse/sluggish

> 标签: laravel-pulse-sluggish, laravel-slug-helper, laravel-unique-slug-generator, slug-generator, sluggish, unique-slug-generator, unique-slug-helper

## 简介

A complete solution for generating slug, uuid and unique number for any laravel projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
