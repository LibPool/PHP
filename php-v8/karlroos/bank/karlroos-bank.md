# karlroos/bank

> 标签: Bank, handelsbanken, seb

## 简介

Wrappers for accessing Swedish banks. Currently supports Handelsbanken and SEB.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
