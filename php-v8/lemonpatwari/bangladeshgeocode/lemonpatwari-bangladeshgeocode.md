# lemonpatwari/bangladeshgeocode

> 标签: bangladesh, bangladesh districts, bangladesh divisions, bangladesh upazila, bangladesh-geocode, geocode, geolocation, laravel, laravel bangladesh address, lemonpatwari

## 简介

A Laravel package for Bangladesh geolocation with divisions, districts, upazilas, and unions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
