# cortova/sdk

> 标签: api, cortova, crm, sdk

## 简介

Official PHP SDK for the Cortova CRM API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://app.cortova.ai
- 源码仓库：https://github.com/cortova/cortova-php.git
- Packagist 页面：https://packagist.org/packages/cortova%2Fsdk

## 历史版本号

- 当前版本：v0.1.0

- v0.1.0

## 获取地址

- Composer 安装：`composer require cortova/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/cortova/sdk.json
- 许可证：Apache-2.0
- PHP 要求：>=8.1
