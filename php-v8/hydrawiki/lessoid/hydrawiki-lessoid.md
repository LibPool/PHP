# hydrawiki/lessoid

> 标签: css, less, less.js, lesscss, php, stylesheet

## 简介

A persistent Less.js RESTful API parser service using Node.js.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
