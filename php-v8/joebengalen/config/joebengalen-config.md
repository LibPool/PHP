# joebengalen/config

> 标签: config, configuration

## 简介

Lightweight configuration manager library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/JoeBengalen/Config

- Packagist 页面：https://packagist.org/packages/joebengalen%2Fconfig
