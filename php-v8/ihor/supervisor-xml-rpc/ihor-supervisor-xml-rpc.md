# ihor/supervisor-xml-rpc

> 标签: api, supervisor, supervisorctl, supervisord, xml-rpc

## 简介

Simple Supervisor XML RPC Client in PHP (http://supervisord.org)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
