# permitcore/sdk

> 标签: activation, license, licensing, permitcore, sdk

## 简介

Official PHP client for PermitCore license management. Validate, activate, and deactivate license keys with built-in hardware fingerprinting and offline grace period caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
