# kreta/php-cs-fixer-config

> 标签: development, manager, php-cs-fixer, php-linter, project, tool

## 简介

PHP linting tool using PHP CS Fixer for Kreta packages

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
