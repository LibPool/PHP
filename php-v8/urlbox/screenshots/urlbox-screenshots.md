# urlbox/screenshots

> 标签: Thumbnails, browser, capture, convert, facade, headless, image, laravel, phantomjs, preview, provider, render, responsive, retina, screenshot, screenshots, thumbnail, urlbox, webpage, website

## 简介

Use urlbox to easily generate website thumbnail screenshots from a URL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
