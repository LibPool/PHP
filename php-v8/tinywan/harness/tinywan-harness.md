# tinywan/harness

> 标签: PHP

## 简介

A PHP library for driving AI coding CLIs (Claude Code, Codex, GitHub Copilot CLI, OpenCode) in headless mode.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
