# payamak/ghasedak

> 标签: Ghasedak, gateway, message, payamak

## 简介

Ghasedak driver for the Payamak PHP library for SMS messaging.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/nekofar/payamak-ghasedak
- 源码仓库：https://gitlab.com/payamak/ghasedak.git
- Packagist 页面：https://packagist.org/packages/payamak%2Fghasedak
