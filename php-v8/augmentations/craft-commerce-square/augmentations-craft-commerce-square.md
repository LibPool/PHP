# augmentations/craft-commerce-square

> 标签: commerce, craftcms, craftplugins, square

## 简介

Square payment gateway plugin for Craft Commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
