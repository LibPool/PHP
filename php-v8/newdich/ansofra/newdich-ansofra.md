# newdich/ansofra

> 标签: PHP

## 简介

Ansofra is a software Architecture framework that follows the CQRS pattern in PHP, grouping all important products into group, each product being a microservice.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
