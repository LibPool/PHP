# xfeng/smarty

> 标签: fis, fis smarty, laravel, smarty, templating, view

## 简介

改自latrell/smarty，增加配置项，让其支持fis smarty插件的配置项.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
