# patrickschur/html5gen

> 标签: builder, generator, html, html-builder, php

## 简介

An easy to use HTML5 generator written in PHP. Creates valid and secure HTML5 code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
