# tesla-software/jmbg

> 标签: Slovenia, bosnia, croatia, jmbg, macedonia, montenegro, serbia, unique master citizen number

## 简介

Validate, generate and extract data from JMBG (Unique Master Citizen Number)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
