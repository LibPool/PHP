# viest/xlswriter

> 标签: PHP

## 简介

xlswriter is a PHP C Extension that can be used to write text, numbers, formulas and hyperlinks to multiple worksheets in an Excel 2007+ XLSX file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
