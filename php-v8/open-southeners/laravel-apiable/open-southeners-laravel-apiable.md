# open-southeners/laravel-apiable

> 标签: JSON-API, apiable, laravel, laravel-package, open-southeners, request-params-filtering, request-query, request-search

## 简介

Integrate JSON:API resources on your Laravel API project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
