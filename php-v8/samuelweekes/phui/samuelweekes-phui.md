# samuelweekes/phui

> 标签: cli, components, console, reactive, terminal, tui, ui

## 简介

A PHP library for building terminal user interfaces (TUIs) with a component-based, reactive API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
