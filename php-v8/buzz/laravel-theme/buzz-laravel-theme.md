# buzz/laravel-theme

> 标签: laravel, laravel5, theme, theme management, theme manager, themes

## 简介

Theme Management for Laravel 5.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
