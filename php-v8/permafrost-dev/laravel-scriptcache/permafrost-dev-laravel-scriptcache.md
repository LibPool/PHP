# permafrost-dev/laravel-scriptcache

> 标签: cache, javascript, laravel, permafrost, scripts, server

## 简介

Allows client-side scripts to leverage the server's laravel cache

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
