# olaldennis/job-queue-bundle

> 标签: background, cron, job, queue, scheduled

## 简介

Allows to run and schedule Symfony 5 console commands as background jobs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
