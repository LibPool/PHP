# graftechnology/pdfshift

> 标签: Craft, cms, craft-plugin, craftcms, pdf, pdfshift

## 简介

Easily implement PDFShift (https://pdfshift.io/) into Craft CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
