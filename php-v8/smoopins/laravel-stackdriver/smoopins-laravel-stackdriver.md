# smoopins/laravel-stackdriver

> 标签: error reporting, google, laravel, logging, stackdriver, tracing

## 简介

Enables logging, tracing and error reporting to Google Stackdriver for the Laravel framework, forked from GlueDev/laravel-stackdriver

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
