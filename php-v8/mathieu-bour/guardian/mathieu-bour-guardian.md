# mathieu-bour/guardian

> 标签: Authentication, JWS, jwt, laravel, lumen, php

## 简介

Highly configurable JSON Web Token implementation for Laravel and Lumen.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
