# mathieu-bour/hydra

> 标签: TestBench, laravel, lumen, testing

## 简介

Hydra provides a simple and clean way to test Laravel and Lumen packages against multiple versions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
