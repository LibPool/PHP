# plokko/locale-manager

> 标签: Vue.js, javascript, language, locale, persistent, translation

## 简介

Laravel persistent locale and Javascript/Vue.js translation support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
