# lizmap/naturaliz-modules

> 标签: jelix, lizmap, module, naturaliz

## 简介

Jelix module to manage data on species observations for Lizmap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
