# lizmap/streaming-json-encoder

> 标签: encoder, json, psr-7, streaming

## 简介

Library for iteratively encoding large JSON documents piece by piece (maintained fork)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
