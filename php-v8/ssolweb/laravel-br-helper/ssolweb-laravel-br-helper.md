# ssolweb/laravel-br-helper

> 标签: brasil, casts, cnpj, cpf, formatter, laravel, telefone, validation

## 简介

Pacote Laravel para casts e validações de padrões brasileiros como CPF, CNPJ e telefone.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
