# vnuswilliams/laravel-geo-checkin

> 标签: attendance, check-in, checkin, geolocation, gps, laravel, pointage, presence

## 简介

Pointage de presence par geolocalisation (check-in / check-out) pour Laravel, partage entre une application RH/admin et un portail employe.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
