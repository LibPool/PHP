# bladeberg/bladeberg

> 标签: bladeberg, block-editor, cms, gutenberg, laravel, wordpress

## 简介

Gutenberg inside Laravel — bring the WordPress block editor to your Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
