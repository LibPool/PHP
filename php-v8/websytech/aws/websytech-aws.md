# websytech/aws

> 标签: PHP

## 简介

An object oriented wrapper for Amazon's AWS PHP SDK.  Specifically for sending bulk emails through SES.

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
