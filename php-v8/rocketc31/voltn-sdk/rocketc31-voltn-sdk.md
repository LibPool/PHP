# rocketc31/voltn-sdk

> 标签: API-Client, edm, file-storage, netexplorer, psr-18, sdk, voltn

## 简介

Unofficial, framework-agnostic PHP SDK for the Voltn (formerly NetExplorer) file-storage API: OAuth2, folders, files, streamed and TUS uploads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
