# scalapay/scalapay-magento-2-hyva-adapter

> 标签: adapter, hyva, magento, payments, scalapay

## 简介

Adapter module for Hyvä Checkout and scalapay/scalapay-magento-2 module

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
