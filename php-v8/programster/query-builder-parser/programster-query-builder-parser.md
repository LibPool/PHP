# programster/query-builder-parser

> 标签: builder, jquery, query, querybuilder

## 简介

A library for converting a jQuery query builder JSON rules string to an SQL statement.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
