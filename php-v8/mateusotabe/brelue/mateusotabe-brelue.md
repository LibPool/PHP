# mateusotabe/brelue

> 标签: brazil, docker, inertia, laravel, pt-BR, starter-kit, vue

## 简介

Esqueleto Laravel + Inertia/Vue limpo, dockerizado e localizado para o Brasil (pt-BR).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
