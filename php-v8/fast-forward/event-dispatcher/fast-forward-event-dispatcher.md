# fast-forward/event-dispatcher

> 标签: event-dispatcher, fast-forward, php, psr-14

## 简介

Fast-Forward PSR-14  Event Dispatcher is a simple and fast event dispatcher for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
