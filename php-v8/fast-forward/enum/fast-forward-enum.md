# fast-forward/enum

> 标签: backed-enum, enum, fast-forward, php, unit-enum

## 简介

Ergonomic utilities for PHP enums, including names, values, lookups, and option maps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
