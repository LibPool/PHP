# cmsgears/widget-text

> 标签: cmsgears, text, widget, yii2

## 简介

The Text Widget for CMSGears. It can be used to show key value pairs stored in database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
