# cmsgears/widget-newsletter

> 标签: cmsgears, newsletter, widget, yii2

## 简介

The Newsletter Widget for CMSGears allows site users to register to get news and updates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
