# cmsgears/widget-mapper

> 标签: cmsgears, mapper, widget, yii2

## 简介

The Mapper Widget for CMSGears provides options to map a single column.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
