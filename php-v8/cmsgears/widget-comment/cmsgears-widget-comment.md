# cmsgears/widget-comment

> 标签: cmsgears, comment, widget, yii2

## 简介

The Comment Widget for CMSGears. It provide options to write or view comments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
