# cmsgears/widget-tinymce

> 标签: cmsgears, tinymce, widget, yii2

## 简介

The TinyMCE Widget provide a wrapper for TinyMCE WYSIWYG HTML editor for CMSGears projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
