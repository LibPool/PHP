# cmsgears/template-basic

> 标签: basic, cmsgears, template, yii, yii 2, yii2

## 简介

The basic template uses core and forms modules with basic theme for website and admin theme for admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
