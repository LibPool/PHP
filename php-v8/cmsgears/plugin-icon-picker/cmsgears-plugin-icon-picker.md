# cmsgears/plugin-icon-picker

> 标签: cmsgears, icon picker, plugin, yii2

## 简介

The Icon Picker Plugin for CMSGears. It provide assets bundle for various icon libraries and options to configure them.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
