# cmsgears/plugin-piwik-analytics

> 标签: analytics, cmsgears, piwik, plugin, yii2

## 简介

The Piwik Analytics Plugin for CMSGears. It can be used to call Piwik APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
