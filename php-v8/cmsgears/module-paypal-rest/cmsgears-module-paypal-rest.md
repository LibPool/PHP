# cmsgears/module-paypal-rest

> 标签: cmsgears, module, paypal, paypal rest, yii2

## 简介

The Paypal REST Module required for the projects which need Paypal REST to accept payments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
