# etre2/magento-botblock

> 标签: PHP

## 简介

Implements self-updating PHP library nabble/semalt-blocker which blocks hundreds of spammy domains from ruining your website statistics

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
