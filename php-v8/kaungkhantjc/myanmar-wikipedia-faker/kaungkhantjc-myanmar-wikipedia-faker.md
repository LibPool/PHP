# kaungkhantjc/myanmar-wikipedia-faker

> 标签: PHP

## 简介

A high-performance Myanmar (Burmese) text generator based on the DatarrX Wikipedia Dataset.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
