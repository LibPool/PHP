# rvish/emoji

> 标签: browser, eecode, emoji, encoder, html, parser, rvish, unified

## 简介

An Emoji encoder and decoder with browser for Laravel 5 (unified to HTML)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
