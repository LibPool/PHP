# schnittstabil/psr7-middleware-stack

> 标签: expressive, middleware, psr, psr-7, psr7, slim, stack, stratigility

## 简介

Stack PSR-7 middlewares in a reusable way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
