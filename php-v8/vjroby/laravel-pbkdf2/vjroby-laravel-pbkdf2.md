# vjroby/laravel-pbkdf2

> 标签: hashing, laravel, pbkdf2

## 简介

This is a package for wrapping PBKDF2 class and using it in Laravel as a facade

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
