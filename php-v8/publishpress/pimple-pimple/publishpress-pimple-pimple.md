# publishpress/pimple-pimple

> 标签: container, dependency injection, publishpress

## 简介

Pimple, a simple Dependency Injection Container, prefixed for PublishPress

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
