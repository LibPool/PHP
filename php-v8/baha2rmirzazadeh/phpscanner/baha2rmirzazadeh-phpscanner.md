# baha2rmirzazadeh/phpscanner

> 标签: cli, input, input stream, php, prompt, scanner

## 简介

A php library to handle input stream. It inspired from Java Scanner class.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
