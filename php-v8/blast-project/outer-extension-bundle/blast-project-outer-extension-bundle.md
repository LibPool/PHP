# blast-project/outer-extension-bundle

> 标签: doctrine, outer extension, symfony

## 简介

Provides Outer Extension for Doctrine entities in Symfony bundles

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
