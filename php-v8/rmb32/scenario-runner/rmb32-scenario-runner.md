# rmb32/scenario-runner

> 标签: BDD, acceptance-testing, given-when-then, scenarios

## 简介

A small, generic Given/When/Then scenario execution engine — Act/Arrange/Assert/Authenticate ports, no framework or transport opinions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
