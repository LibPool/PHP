# rmb32/barn

> 标签: BDD, architecture, barn, story-mapping

## 简介

Build a barn: a PHP project with its story map (Barnspec) and its architecture (Barnark) under one roof, one CLI and one browser UI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
