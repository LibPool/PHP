# rmb32/barnspec-gui

> 标签: BDD, gui, story-mapping, user-stories

## 简介

A web GUI for managing Barnspec (Given When Then) Specification data, including Work's ticket board

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
