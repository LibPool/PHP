# rmb32/filesystem

> 标签: code-generation, filesystem

## 简介

Small file helpers: a JSON file store, a PHP class writer for code generators, and a minimal Markdown-to-HTML converter

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
