# rmb32/barnark-cli

> 标签: architecture, cli, scaffolding, templates

## 简介

The command-line delivery mechanism for Barnark — the template commands (list, scaffold, check, switch).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
