# rmb32/port-generator

> 标签: BDD, code-generation, given-when-then, ports

## 简介

Reads captured stories/scenarios from Barnspec (rmb32/barnspec) and generates Scenario Runner (rmb32/scenario-runner) Port stub classes from them — library plus the generate/check/export-vocabulary CLI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
