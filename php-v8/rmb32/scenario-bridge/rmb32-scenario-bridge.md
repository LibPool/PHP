# rmb32/scenario-bridge

> 标签: BDD, acceptance-testing, given-when-then

## 简介

Reads captured scenarios from Barnspec (rmb32/barnspec), converts them into Scenario Runner's (rmb32/scenario-runner) own execution shape, and runs them — the orchestrator between the two, keeping both Barnspec-agnostic — library plus the run/run-all CLI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
