# rmb32/typed-input

> 标签: console, json, typed-input, validation

## 简介

Typed readers for untyped input — decoded JSON and Symfony Console arguments/options — that fail with a clear message instead of leaking mixed

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
