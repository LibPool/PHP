# smm229/aliyunoss

> 标签: alioss-web-direct, extension, laravel-admin

## 简介

laravel-admin扩展，web直传阿里oss（file，image，editor），基于ezreal/admin-oss开发

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
