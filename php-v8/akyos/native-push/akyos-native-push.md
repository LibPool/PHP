# akyos/native-push

> 标签: PHP

## 简介

Symfony Notifier push transport sending straight to APNs (iOS) and FCM v1 (Android), with device token storage for any Doctrine entity

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
