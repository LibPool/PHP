# exadra37-docker/php-docker-stack

> 标签: Exadra37, WAMP, docker, docker laravel, docker laravel app, docker php stack, docker php7, docker php7 stack, docker stack, dockerize, dockerize laravel, dockerize laravel app, lamp, laravel, laravel 5, laravel app, laravel docker, laravel docker app, laravel docker container, lemp, php docker, php docker stack, php7 docker, php7 docker stack, xampp

## 简介

A Docker Stack to run Php Apps. Composed by Http, Php, Database, Cache, Queue, Logger, Cron Jobs and CLI services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
