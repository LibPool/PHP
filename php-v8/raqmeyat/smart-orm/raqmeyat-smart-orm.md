# raqmeyat/smart-orm

> 标签: api, data-object, dto, eloquent, filter, filters, laravel, mobile, orm, sparse-fieldsets

## 简介

Request-driven smart field selection and smart filters for Eloquent, with data-class and filter generators. Laravel 13+, PHP 8.4+, SQLite / MySQL / PostgreSQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
