# sfneal/crud-model-actions

> 标签: crud-model-actions, sfneal

## 简介

Abstraction layers for creating CRUD Action classes to execute actions on Eloquent Models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
