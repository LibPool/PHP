# tito10047/altcha-bundle

> 标签: ALTCHA, Symfony Bundle, bundle, captcha, form, form security, symfony, symfony-ux

## 简介

A simple package to help integrate Altcha on Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
