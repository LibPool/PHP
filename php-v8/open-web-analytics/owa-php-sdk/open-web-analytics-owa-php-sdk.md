# open-web-analytics/owa-php-sdk

> 标签: OWA, analytics, open-web-analytics, web-analytics

## 简介

PHP SDK for Open Web Analytics: server-side event tracking and the REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
