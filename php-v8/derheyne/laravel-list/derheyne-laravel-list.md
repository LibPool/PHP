# derheyne/laravel-list

> 标签: Daniel Heyne, laravel, laravel-list

## 简介

A Laravel Collection wrapper that enforces sequential 0-based keys at all times

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
