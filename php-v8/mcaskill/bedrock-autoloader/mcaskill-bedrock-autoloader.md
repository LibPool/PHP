# mcaskill/bedrock-autoloader

> 标签: bedrock, roots, wordpress, wp

## 简介

Standalone version of the Bedrock Autoloader for WordPress must-use plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
