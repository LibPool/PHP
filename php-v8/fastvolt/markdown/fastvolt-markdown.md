# fastvolt/markdown

> 标签: markdown, markdown-library, markdown-parser, markdown-to-html

## 简介

A Fast, Simple and Straight-forward Markdown to HTML Converter for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
