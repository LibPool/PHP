# jobviz/agent

> 标签: jobs, laravel, monitoring, observability, queue, symfony

## 简介

Lightweight agent SDK for monitoring Laravel Queue, Symfony Messenger, and custom PHP queue jobs with Jobviz

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
