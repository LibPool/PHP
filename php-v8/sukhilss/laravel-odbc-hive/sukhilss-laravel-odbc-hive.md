# sukhilss/laravel-odbc-hive

> 标签: database, hadoop, hive, laravel, odbc, pdo

## 简介

Apache Hive database driver for Laravel, over ODBC/PDO.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
