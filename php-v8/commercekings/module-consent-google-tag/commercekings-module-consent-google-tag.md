# commercekings/module-consent-google-tag

> 标签: PHP

## 简介

Consent for Magento's native Google tags (GA4, Universal Analytics, Google Ads via gtag) with Google Consent Mode v2, independent of the cookie banner.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
