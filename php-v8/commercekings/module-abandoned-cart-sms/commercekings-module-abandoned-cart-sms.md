# commercekings/module-abandoned-cart-sms

> 标签: PHP

## 简介

SMS abandoned cart reminders for Magento 2: a text next to the reminder email, with a consent checkbox for the number, quiet hours and STOP replies - on commercekings/module-abandoned-cart, sent by any SMS provider module.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
