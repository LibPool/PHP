# commercekings/module-consent-defaults

> 标签: PHP

## 简介

Shared banner categories (Necessary, Analytics, External content, Personalization, Marketing), installed with every CommerceKings consent banner adapter; each category shows only while a feature uses it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
