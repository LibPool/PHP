# commercekings/module-rate-limit

> 标签: PHP

## 简介

Rate limiting for Magento 2 storefront endpoints, built on Magento's backpressure: an open registry of controllers and REST services, limits per endpoint in the admin, HTTP 429 and an IP blocklist.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
