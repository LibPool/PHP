# commercekings/module-consent-notification

> 标签: PHP

## 简介

Connects commercekings/module-consent to commercekings/module-notification: subscriptions need a valid consent, and withdrawing it removes them. Install it for consent-based notifications; leave it out for opt-out.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
