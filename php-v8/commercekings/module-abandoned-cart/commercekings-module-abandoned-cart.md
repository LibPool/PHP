# commercekings/module-abandoned-cart

> 标签: PHP

## 简介

Privacy-first abandoned cart reminder for Magento 2: subscriptions, permission and sending through commercekings/module-notification - consent-based with commercekings/module-consent-notification, opt-out without it - and signed restore links.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
