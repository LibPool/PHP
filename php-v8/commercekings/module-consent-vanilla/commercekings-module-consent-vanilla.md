# commercekings/module-consent-vanilla

> 标签: PHP

## 简介

vanilla-cookieconsent (orestbida/cookieconsent v3) as a consent source for commercekings/module-consent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
