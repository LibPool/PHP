# couryo/couryo-php

> 标签: couryo, email, laravel, smtp, symfony mailer, transactional email, webhooks

## 简介

Official PHP SDK for the Couryo email API: retries, automatic Idempotency-Key, webhook verification and a Laravel mail transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
