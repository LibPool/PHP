# zerossl/cli-client

> 标签: PHP

## 简介

Create certificates and CSRs locally and easy in the CLI using newest PHP OpenSSL features and ZeroSSL for signing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
