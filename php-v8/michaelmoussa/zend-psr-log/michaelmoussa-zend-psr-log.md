# michaelmoussa/zend-psr-log

> 标签: PHP

## 简介

PSR3-compliant, backwards-compatible, drop-in replacement for Zend\Log\Logger.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
