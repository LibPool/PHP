# phpnexus/cors-psr7

> 标签: cors, middleware, psr-15, psr-7, psr15, psr7

## 简介

Provides a lightweight CORS middleware for PSR-7 and PSR-15 compatible frameworks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
