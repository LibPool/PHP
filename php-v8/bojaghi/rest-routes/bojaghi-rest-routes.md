# bojaghi/rest-routes

> 标签: PHP

## 简介

워드프레스 REST API 사용을 위한 `register_rest_route` 함수를 좀 더 편리하게 등록 관리해 주는 패키지입니다.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
