# bojaghi/clean-pages

> 标签: PHP

## 简介

워드프레스 플러그인에서 테마와 완전히 무관한 빈 페이지를 운영하게 도와줌니다.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
