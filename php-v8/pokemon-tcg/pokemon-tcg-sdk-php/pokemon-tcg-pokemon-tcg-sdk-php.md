# pokemon-tcg/pokemon-tcg-sdk-php

> 标签: pokemon, sdk, tcg

## 简介

This is the Pokémon TCG SDK PHP implementation. It is a wrapper around the Pokémon TCG API of pokemontcg.io.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
