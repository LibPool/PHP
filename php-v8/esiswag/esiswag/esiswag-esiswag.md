# esiswag/esiswag

> 标签: EVE Online, client, esi, framework, http, rest, swagger, web service

## 简介

Swag is a PHP library for interacting with the EVE ESI API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
