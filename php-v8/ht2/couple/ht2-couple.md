# ht2/couple

> 标签: PHP

## 简介

Port of ryansmith94/couple from JS to PHP. A library for coupling two objects together. This is useful for nested pattern matching.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
