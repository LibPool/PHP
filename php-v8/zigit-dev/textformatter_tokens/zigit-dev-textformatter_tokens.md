# zigit-dev/textformatter_tokens

> 标签: processwire, textformatter_tokens, tokens

## 简介

Allows other modules to register tokens and replace them with actual values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
