# apinator/apinator-php

> 标签: apinator, channels, pubsub, realtime, sdk, server, websocket

## 简介

PHP server SDK for Apinator — trigger events, authenticate channels, verify webhooks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
