# trekkpay/omnipay-trekkpay

> 标签: gateway, merchant, omnipay, pay, payment, trekkpay

## 简介

TrekkPay Gateway for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
