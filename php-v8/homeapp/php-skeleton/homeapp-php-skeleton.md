# homeapp/php-skeleton

> 标签: PHP

## 简介

A basic template for creating php packages with basic setup: psalm, php-cs-fixer, phpunit, CI with running test

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
