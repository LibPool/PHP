# rigosv/audit-bundle

> 标签: Audit, Symfony2, bundle, doctrine, log, orm

## 简介

Audit bundle for symfony2 and doctrine orm, logs any database change (Fork from data-dog/audit-bundle)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
