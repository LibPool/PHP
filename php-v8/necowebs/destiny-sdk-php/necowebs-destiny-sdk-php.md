# necowebs/destiny-sdk-php

> 标签: PHP

## 简介

A PHP Client/SDK/API Wrapper for the BungieNet.Platform.DestinyServices

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
