# mike-bronner/flux-fontawesome-icons

> 标签: FontAwesome, blade, converter, flux, font-awesome, icons, importer, laravel, svg

## 简介

Convert FontAwesome SVG icons to Flux Blade icon components for Laravel apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
