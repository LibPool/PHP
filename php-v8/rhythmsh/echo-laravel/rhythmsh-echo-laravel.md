# rhythmsh/echo-laravel

> 标签: echo, email, laravel, mail-catcher, rhythm, staging, testing, webhooks

## 简介

Rhythm Echo connector for Laravel: capture and seal the mail and HTTP calls a staging site sends.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
