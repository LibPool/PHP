# neo/pusher-beams

> 标签: Neo, beams, laravel, notification, push, push-notifications, pusher

## 简介

Pusher Beams is a push notification service from Pusher.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
