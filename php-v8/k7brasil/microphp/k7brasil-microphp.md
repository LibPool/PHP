# k7brasil/microphp

> 标签: PHP

## 简介

MicroPHP é um micro framework criado pela K7.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/k7brasil/MicroPHP
- 源码仓库：https://github.com/k7brasil/MicroPHP.git
- Packagist 页面：https://packagist.org/packages/k7brasil%2Fmicrophp

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require k7brasil/microphp`
- Packagist 仓库：https://repo.packagist.org/p2/k7brasil/microphp.json
- 许可证：MIT
- PHP 要求：^7.0 || ^8.0
