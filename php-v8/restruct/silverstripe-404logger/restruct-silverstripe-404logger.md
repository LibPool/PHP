# restruct/silverstripe-404logger

> 标签: 404, log, silverstripe, urls

## 简介

Logs 404 errors to the database (link & referrer + count), including report for CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
