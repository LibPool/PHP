# restruct/xpdf-static

> 标签: PHP

## 简介

Pre-compiled xpdf tools with PHP wrappers (pdftotext, pdfinfo, pdftopng, pdfimages) for Linux x64 and macOS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
