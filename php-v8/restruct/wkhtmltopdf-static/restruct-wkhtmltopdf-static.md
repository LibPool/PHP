# restruct/wkhtmltopdf-static

> 标签: PHP

## 简介

Pre-compiled wkhtmltopdf 0.12.6 (patched Qt) with PHP wrapper and Docker support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
