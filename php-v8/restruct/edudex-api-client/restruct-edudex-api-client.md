# restruct/edudex-api-client

> 标签: API-Client, edudex, silverstripe

## 简介

PHP client library for the EDU-DEX Data API. Framework-agnostic with optional SilverStripe integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
