# restruct/silverstripe-svg-images

> 标签: silverstripe, svg

## 简介

SVG Image support for Silverstripe with real manipulation and sanitization

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
