# gamee/php-jsonrpc

> 标签: PHP

## 简介

JSON-RPC toolset build on top of psr-7 (guzzlehttp), league/json-guard, league/json-reference, league/flysystem and nette/di

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
