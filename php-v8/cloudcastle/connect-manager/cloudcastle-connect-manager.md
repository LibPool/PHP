# cloudcastle/connect-manager

> 标签: async, cloudcastle, connect-manager, connection-pool, http, library, networking, osi, php, php8, protocols, psr, sockets, ssh, stream, tcp, tls, udp

## 简介

Унифицированный менеджер сетевых соединений PHP 8.1+: реестр протоколов OSI, TCP/UDP/TLS/Unix/socket, sync и async (Fibers), пул, SSRF-guard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
