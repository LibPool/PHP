# laxity7/yii2-trim-behavior

> 标签: behaviors, trim, yii2

## 简介

Behavior that truncates all spaces and other characters in all attributes in a model before validate

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
