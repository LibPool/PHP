# mattsplat/fastresize-php

> 标签: PHP

## 简介

PHP FFI binding for fastresize - a fast C++ image decode/resize/composite/encode library - as an alternative to libvips-backed wrappers like jcupitt/vips.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
