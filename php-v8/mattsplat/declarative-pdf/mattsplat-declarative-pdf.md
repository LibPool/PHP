# mattsplat/declarative-pdf

> 标签: AcroForm, fpdf, layout, pdf, pdf-forms, pdf-generation, typesetting

## 简介

A typed, declarative PDF generation library with a block-layout engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
