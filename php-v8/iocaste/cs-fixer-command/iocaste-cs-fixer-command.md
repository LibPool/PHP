# iocaste/cs-fixer-command

> 标签: artisan, codequality, laravel, lumen, php-cs-fixer, psr

## 简介

Lumen/Laravel wrapper around PHPCS-Fixer package. Used as artisan command.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
