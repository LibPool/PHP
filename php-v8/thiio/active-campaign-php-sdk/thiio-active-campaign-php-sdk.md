# thiio/active-campaign-php-sdk

> 标签: PHP

## 简介

This is a SDK built in PHP for consuming Active Campaing's v3 API as detailed in https://www.activecampaign.com/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
