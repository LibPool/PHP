# yzh52521/think-csv

> 标签: csv, eloquent, export, thinkphp

## 简介

一个thinkphp6包，可以轻松地从模型生成CSV文件。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
