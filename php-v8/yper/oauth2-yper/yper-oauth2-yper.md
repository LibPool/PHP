# yper/oauth2-yper

> 标签: Authentication, SSO, authorization, identity, idp, oauth, oauth2, single sign on, yper

## 简介

Yper OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
