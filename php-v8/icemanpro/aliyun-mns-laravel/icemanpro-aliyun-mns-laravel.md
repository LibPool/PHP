# icemanpro/aliyun-mns-laravel

> 标签: aliyun, l5, laravel, laravel 5, mns

## 简介

阿里云消息服务在Laravel5中的Queue拓展。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
