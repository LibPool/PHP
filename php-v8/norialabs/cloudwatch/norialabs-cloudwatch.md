# norialabs/cloudwatch

> 标签: aws, cloudwatch, laravel, logging, monolog

## 简介

AWS CloudWatch log driver for Laravel. Drop-in replacement — just switch LOG_CHANNEL=cloudwatch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
