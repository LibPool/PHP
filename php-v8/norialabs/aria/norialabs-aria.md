# norialabs/aria

> 标签: ai, assistant, embeddings, laravel, rag

## 简介

The layer between laravel/ai and a product: conversations, retrieval over a pluggable corpus, spend governance, and PII masking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
