# norialabs/platform

> 标签: Passwordless, audit-trail, laravel, multi-tenancy, postgres, rbac, row-level-security

## 简介

The chassis every Noria Laravel product sits on: workspace tenancy with row level security, RBAC, an audit trail, passwordless auth, database operations, and the shared primitives.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
