# norialabs/payments

> 标签: SasaPay, daraja, kcb-buni, kenya, laravel, mpesa, payments, paystack

## 简介

Laravel SDK for payment integrations: M-PESA Daraja, SasaPay, KCB Buni, and Paystack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
