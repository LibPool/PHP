# danog/madelineproto

> 标签: GB, Messenger, audio, bytes, client, files, mtproto, php, protocol, stickers, telegram, video

## 简介

Async PHP client API for the telegram MTProto protocol.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
