# danog/php-rtc-webrtc

> 标签: WebRTC, rtp

## 简介

A modular PHP WebRTC stack for PHP 8.2+, ported to Amp v3 with pure-PHP DTLS/SRTP and optional media FFI. Maintained by danog for MadelineProto.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
