# danog/php-rtc-mixin

> 标签: WebRTC

## 简介

Common PHP classes and traits for WebRTC components. MadelineProto's PHP 8.2+ fork is a Composer-compatible foundation of the modular danog/php-rtc stack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
