# smusatov/bzb-2u

> 标签: BZB-2U, GoDex, Thermal printer, label printer, printer, printing

## 简介

Library for thermal printer GoDex BZB-2U

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
