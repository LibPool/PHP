# litipk/php-bignumbers

> 标签: bcmath, bignum, decimal, gmp, number

## 简介

An opensource library to handle immutable big numbers inside PHP applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
