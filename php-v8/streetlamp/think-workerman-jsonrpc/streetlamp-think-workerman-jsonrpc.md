# streetlamp/think-workerman-jsonrpc

> 标签: PHP

## 简介

think-workerman-jsonrpc是基于workerman-json-rpc二次封装成一个Package，里面封装了客户端，服务端和统计分析服务

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
