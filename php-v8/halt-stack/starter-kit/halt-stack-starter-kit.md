# halt-stack/starter-kit

> 标签: alpine, framework, halt, htmx, laravel, starter kit, tailwind

## 简介

A Laravel starter kit with HTMX, Alpine.js, and Tailwind CSS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
