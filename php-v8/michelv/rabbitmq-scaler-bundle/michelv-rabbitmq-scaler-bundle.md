# michelv/rabbitmq-scaler-bundle

> 标签: AMQP, Symfony2, message, queue, rabbitmq

## 简介

Provides a command to scale RabbitMq consumers up when the need arises.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
