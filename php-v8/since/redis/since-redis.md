# since/redis

> 标签: PHP

## 简介

一个基于PHP 8+的高性能Redis客户端库，提供连接池+门面模式和原始单例模式两种使用方式，支持Redis所有数据结构操作，包含完整的类型声明和异常处理机制。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
