# since/sms

> 标签: PHP

## 简介

一个基于PHP 8+的短信发送客户端库，采用驱动(driver)设计模式，提供单例模式和门面模式两种使用方式，支持配置管理、短信发送和批量发送功能，包含完整的类型声明和异常处理机制，易于扩展支持多种短信服务商。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
