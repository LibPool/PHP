# emargareten/inertia-modal

> 标签: inertia, laravel, modal

## 简介

Inertia Modal is a Laravel package that lets you implement backend-driven modal dialogs for Inertia apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
