# rasteiner/k3-pagesdisplay-section

> 标签: PHP

## 简介

K3 plugin: display any page list in a section. Any parent, many parents, filtered, don't care.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
