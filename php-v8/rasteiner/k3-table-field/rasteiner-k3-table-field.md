# rasteiner/k3-table-field

> 标签: PHP

## 简介

K3 plugin. A very simple table editor. No expanding views, no modals. Just edit a table of strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
