# oeltimacreation/php-simplequery

> 标签: database, mariadb, mysql, pdo, query-builder, sqlite

## 简介

A small, framework-agnostic PDO query builder with deterministic SQL compilation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
