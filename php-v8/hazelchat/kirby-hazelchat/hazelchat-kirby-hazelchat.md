# hazelchat/kirby-hazelchat

> 标签: ai, chat, chat agent, chatbot, consent, enquiries, kirby, kirby-cms, kirby-plugin

## 简介

Adds the Hazelchat AI chat agent to every page of a Kirby site from one pasted installation code. It answers visitors from the pages you approve and passes on their enquiries. Needs a Hazelchat account; the Free plan covers one website.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
