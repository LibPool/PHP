# idealo/php-middleware-stack

> 标签: http, middleware, psr, psr-15, psr-7, request, response, stack

## 简介

Implementation of HTTP Middleware PSR-15 specification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
