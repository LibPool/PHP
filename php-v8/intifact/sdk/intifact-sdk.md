# intifact/sdk

> 标签: boleta, factura-electronica, facturacion, guia-remision, intifact, nota-credito, peru, sunat

## 简介

SDK PHP para la API de Facturacion Electronica SUNAT de Intifact (Peru): facturas, boletas, notas de credito/debito, guias de remision, resumenes diarios.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
