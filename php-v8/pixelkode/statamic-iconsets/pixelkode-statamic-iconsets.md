# pixelkode/statamic-iconsets

> 标签: fieldtype, icon-picker, icons, statamic, svg

## 简介

A Statamic fieldtype for selecting icons from multiple folders/sets

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
