# rokka/client-bundle

> 标签: image, imagemanipulation, images, rokka, rokka.io, symfony-bundle

## 简介

Defines services for accessing the Rokka image service in the symfony framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
