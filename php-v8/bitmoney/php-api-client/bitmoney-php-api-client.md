# bitmoney/php-api-client

> 标签: bitcoin, payment

## 简介

Bitmoney PHP API client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.bitmoney.eu
- 源码仓库：https://bitbucket.org/paweljendrusik/bitmoney-php-api-client.git
- Packagist 页面：https://packagist.org/packages/bitmoney%2Fphp-api-client

## 历史版本号

- 当前版本：v0.1

- v0.1

## 获取地址

- Composer 安装：`composer require bitmoney/php-api-client`
- Packagist 仓库：https://repo.packagist.org/p2/bitmoney/php-api-client.json
- PHP 要求：>=5.3.0
