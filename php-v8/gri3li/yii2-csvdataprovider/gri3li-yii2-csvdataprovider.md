# gri3li/yii2-csvdataprovider

> 标签: csv, dataprovider, yii2

## 简介

CsvDataProvider implements a data provider based on a csv

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
