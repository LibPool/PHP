# parvion/accessibility

> 标签: a11y, accessibility, ada-compliance, html, javascript, laravel, livewire, php, screen-reader, symfony, toolbar, vanilla-js, wcag, wcag-2.1, widget, wordpress

## 简介

An enterprise-grade, zero-dependency, highly configurable accessibility toolbar for PHP applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
