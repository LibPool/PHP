# estart/image

> 标签: gd, image, thumb, thumbnail, watermark

## 简介

EStart image component, implement thumbnail and watermark features. EStart 图片处理组件，实现生成缩略图和打水印功能。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
