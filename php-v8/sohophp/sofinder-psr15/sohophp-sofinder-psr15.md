# sohophp/sofinder-psr15

> 标签: file-manager, mezzio, psr-15, slim

## 简介

PSR-15 bridge for SoFinder, supporting Slim 4, Mezzio 3 and framework-free PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
