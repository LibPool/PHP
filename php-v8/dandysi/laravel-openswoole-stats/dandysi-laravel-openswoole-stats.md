# dandysi/laravel-openswoole-stats

> 标签: Metrics, laravel, openswoole, php, prometheus

## 简介

A laravel package to expose Open Swoole metrics to a scraping service like Prometheus

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
