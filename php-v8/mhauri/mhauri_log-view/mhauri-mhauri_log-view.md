# mhauri/mhauri_log-view

> 标签: PHP

## 简介

This Magento extension allows you to read the logfiles stored in Magento's /var/log directory directly in the admin backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
