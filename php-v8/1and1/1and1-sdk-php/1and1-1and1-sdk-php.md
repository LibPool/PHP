# 1and1/1and1-sdk-php

> 标签: 1and1, api, cloud, oneandone, php sdk, server

## 简介

Official PHP SDK for the 1and1 REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
