# botix-pro/sdk

> 标签: ai-assistant, botix, chatbot, rest-api, sdk, telegram, vk, whatsapp

## 简介

Официальный PHP SDK для публичного API BOTIX — платформы визуального конструктора чат-ботов и AI-ассистентов.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
