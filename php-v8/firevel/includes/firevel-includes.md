# firevel/includes

> 标签: JSON-API, Relationships, eloquent, firevel, include, laravel, with

## 简介

A query-string include parser for Laravel APIs (JSON:API-style relationship loading).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
