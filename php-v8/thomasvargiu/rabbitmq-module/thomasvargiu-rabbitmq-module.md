# thomasvargiu/rabbitmq-module

> 标签: AMQP, Zend Framework, laminas, mezzio, rabbitmq, zf2

## 简介

Integrates php-amqplib with Zend Framework 2 and RabbitMq

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
