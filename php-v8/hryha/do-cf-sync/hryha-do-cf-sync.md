# hryha/do-cf-sync

> 标签: DigitalOcean Firewall, cloudflare

## 简介

Sync Cloudflare IP ranges into a DigitalOcean Firewall (ingress rules)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
