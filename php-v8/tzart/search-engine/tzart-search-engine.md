# tzart/search-engine

> 标签: autocomplete, categories, fuzzy, json, laravel, search

## 简介

A JSON-tree based fuzzy search engine for Laravel with multi-domain and category filtering.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
