# popo/generator

> 标签: PHP

## 简介

Plain Old PHP Object (POPO) / Data Structure  / Data Transfer Object (DTO) Generator. Convert YAML schema to PHP class.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
