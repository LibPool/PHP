# z77/kernel

> 标签: flat-file, framework, json-storage, mvc, php, z77

## 简介

Z77 Kernel – boot (Core), platform (Shared) and data storage (Persistence) as one foundation package for all Z77 modules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
