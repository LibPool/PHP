# z77/module-frontend

> 标签: framework, frontend, mvc, php, z77

## 简介

Z77 Frontend Module | the public-facing site: routing, pages, navigation and localized rendering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
