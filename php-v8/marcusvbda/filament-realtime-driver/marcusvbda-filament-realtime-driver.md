# marcusvbda/filament-realtime-driver

> 标签: PHP

## 简介

Realtime WebSocket driver for Filament using Laravel Reverb, without Laravel Echo or pusher-js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
