# tippingmedia/verses

> 标签: Craft, cms, craft-plugin, craftcms, verses

## 简介

Craft CMS 3 Plugin Field Type for finding and outputting bible verses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
