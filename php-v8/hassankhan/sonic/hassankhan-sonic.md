# hassankhan/sonic

> 标签: cms, framework, markdown

## 简介

Zepto is a stupidly simple, blazing fast, flat-file CMS based on Pico

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
