# hassankhan/config

> 标签: config, configuration, ini, json, microphp, unframework, xml, yaml, yml

## 简介

Lightweight configuration file loader that supports PHP, INI, XML, JSON, and YAML files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
