# specshaper/gdpr-bundle

> 标签: PHP

## 简介

A Symfony 3|4 bundle for classifying entity parameters according to GDPR requirements and encrypting data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
