# itools/svgsecuritycheck

> 标签: XMLReader, allowlist, entity-expansion, file-upload, image-upload, libxml, php, security, stored-xss, svg, svg-sanitizer, svg-security, svg-upload, svg-validator, svg-xss, upload-validation, validator, xss, xxe

## 简介

Allowlist check for uploaded SVG files: rejects any that could run script, load an outside resource, or hang a renderer, even when opened outside an <img> tag, and never rewrites a file it accepts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
