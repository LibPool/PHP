# itools/smartstring

> 标签: Escape, UTF, chainable, encoding, fluent, format, html, json, manipulation, methods, multibyte, sanitize, security, smartarray, string, strip, trim, truncate, urlencode, utf8, xss

## 简介

XSS-safe strings for PHP templates: values HTML-encode themselves on echo, interpolation, and concatenation, at least 3x faster than calling htmlspecialchars() yourself

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
