# itools/smartarray

> 标签: Escape, SmartString, array, arrays, chainable, collection, column, database-rows, filter, fluent, groupBy, html, html-encoding, indexby, php, sanitize, security, sort, template, where, xss

## 简介

XSS-safe collections for PHP templates: database rows with fields that HTML-encode themselves, plus chainable filtering, sorting, and grouping

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
