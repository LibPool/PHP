# itools/htmlsecuritycheck

> 标签: CKEditor, HTML5, allowlist, css-injection, html, html-sanitizer, html-security, html5lib, htmlpurifier, php, rich-text, security, stored-xss, tinymce, tokenizer, wysiwyg, xss, xss-protection

## 简介

Allowlist check for HTML that has to be printed unencoded, such as rich text from a WYSIWYG editor: rejects content that could run script, send the page's data to another host, or mislead the visitor, and never rewrites what it accepts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
