# elavora/code-standards

> 标签: coding-standard, editorconfig, lint, per-cs, php-cs-fixer

## 简介

Regras de formatação e estilo da Elavora: PHP-CS-Fixer (PER-CS), EditorConfig e lint de sintaxe PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
