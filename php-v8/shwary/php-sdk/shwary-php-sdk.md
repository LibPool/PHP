# shwary/php-sdk

> 标签: PHP

## 简介

SDK PHP officiel pour l'API marchande Shwary - Paiements Mobile Money (RDC, Kenya, Ouganda)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
