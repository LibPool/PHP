# opotopo/seller-api

> 标签: catalog, marketplace, opotopo, psr-18, seller-api

## 简介

Клиент Seller API ОПОТОПО на PHP: синхронизация позиций каталога, загрузка файлов, приём вебхуков и выдача данных покупок

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
