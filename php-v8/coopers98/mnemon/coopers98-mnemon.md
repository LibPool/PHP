# coopers98/mnemon

> 标签: filament, laravel, mcp, memory, model-context-protocol, pgvector, second-brain

## 简介

A self-hosted second brain for AI agents: verbatim palace storage, a compiled wiki layer, and an MCP server over both.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
