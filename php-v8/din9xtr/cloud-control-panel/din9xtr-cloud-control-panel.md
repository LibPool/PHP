# din9xtr/cloud-control-panel

> 标签: cloud, docker, file-manager, php, self-hosted, storage

## 简介

A lightweight, self-hosted cloud management panel for personal storage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
