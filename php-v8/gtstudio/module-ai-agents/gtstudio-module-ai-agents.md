# gtstudio/module-ai-agents

> 标签: PHP

## 简介

Agent and tool registry for Magento 2. Provides admin CRUD for AI agents and tools, cron-based scheduled execution, and an execution log.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
