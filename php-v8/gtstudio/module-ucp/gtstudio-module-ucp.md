# gtstudio/module-ucp

> 标签: PHP

## 简介

Universal Commerce Protocol (UCP) implementation for Magento 2. Enables AI agent-driven checkout via Google's open commerce standard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
