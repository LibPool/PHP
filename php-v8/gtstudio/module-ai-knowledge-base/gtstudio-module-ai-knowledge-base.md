# gtstudio/module-ai-knowledge-base

> 标签: PHP

## 简介

Knowledge base management for Magento 2. Upload documents (PDF, TXT) that AI agents can retrieve as context before answering queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
