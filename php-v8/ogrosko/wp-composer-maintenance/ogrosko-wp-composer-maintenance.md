# ogrosko/wp-composer-maintenance

> 标签: composer, maintenance, wordpress

## 简介

Composer pre/post scripts for enabling/disabling wordpress maintenance mode

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
