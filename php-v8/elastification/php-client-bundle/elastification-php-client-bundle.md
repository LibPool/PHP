# elastification/php-client-bundle

> 标签: elasticsearch, elastification, nosql, php-client, symfony

## 简介

A Elastification client bundle for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
