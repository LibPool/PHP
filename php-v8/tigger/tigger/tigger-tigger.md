# tigger/tigger

> 标签: express, framework, micro-framework, middleware, router

## 简介

A tiny, Express.js-inspired micro-framework for PHP 8.3+ with zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
