# nombaone/nombaone-php

> 标签: Nigeria, api, billing, nomba, nombaone, payments, sdk, subscriptions

## 简介

Official PHP SDK for the NombaOne subscription-billing API — recurring billing for Nigeria over card, direct debit, and bank transfer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
