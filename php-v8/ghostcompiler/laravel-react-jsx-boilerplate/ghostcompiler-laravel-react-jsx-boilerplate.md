# ghostcompiler/laravel-react-jsx-boilerplate

> 标签: framework, laravel

## 简介

A blank Laravel boilerplate with React and JSX. For developers who prefer JavaScript over the default Laravel TSX starter kits.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
