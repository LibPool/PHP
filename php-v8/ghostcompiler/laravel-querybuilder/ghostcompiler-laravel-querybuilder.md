# ghostcompiler/laravel-querybuilder

> 标签: api, eloquent, filtering, laravel, query-builder

## 简介

Reusable query builder helpers for Eloquent APIs on Laravel 10 through 13.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
