> 标签: array, bit, datetime, extension, json, pgsql, postgres, postgresql, timestamp, yii2

## 简介

PostgreSQL schemas for Yii2, with fields jsonb, json

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
