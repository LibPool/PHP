# rossity/laravel-json-api-scaffolder

> 标签: JSON-API, api, json, laravel

## 简介

A highly opinionated package that rapidly scaffolds Laravel JSON API projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
