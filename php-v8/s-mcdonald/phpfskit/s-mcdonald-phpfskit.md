# s-mcdonald/phpfskit

> 标签: PHP

## 简介

A lightweight PHP filesystem abstraction layer providing a clean, unified API for working with files, directories and their attributes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
