# s-mcdonald/phpjson

> 标签: hydration, json, json-hydration, json-php, php-json, php-json-library, serializer

## 简介

PHPJson: An elegant and simple JSON object serialization library for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
