# shanept/assembly-simulator

> 标签: PHP

## 简介

Allows stepping through compiled assembly code. Provides access to registers and the stack for easy querying of values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
