# moyefu/translator

> 标签: PHP

## 简介

A PHP library for integrating with various translation APIs (Baidu, Google, Youdao, Tencent, Ali, Volcengine, Microsoft, etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
