# cgoit/contao-folder-gallery-bundle

> 标签: Responsive Images, contao, filesystem, folder, gallery, image gallery, lightbox, metadata, photoswipe, yaml

## 简介

Automatically build Contao image galleries from folders using YAML metadata and the native image pipeline.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
