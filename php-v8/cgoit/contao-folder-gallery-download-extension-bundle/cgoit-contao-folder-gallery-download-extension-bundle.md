# cgoit/contao-folder-gallery-download-extension-bundle

> 标签: archive, contao, contao-bundle, download, folder-gallery, gallery, image-gallery, photo-gallery, zip

## 简介

Adds downloadable ZIP archives for galleries managed by the Contao Folder Gallery Bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
