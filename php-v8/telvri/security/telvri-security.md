# telvri/security

> 标签: fraud, identity-security, openapi, php, sdk, sim-swap, telvri

## 简介

Official Telvri Security PHP SDK for SIM-swap and mobile identity checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
