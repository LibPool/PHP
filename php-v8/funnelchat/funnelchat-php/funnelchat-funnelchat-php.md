# funnelchat/funnelchat-php

> 标签: api, funnelchat, psr-18, sdk, webhooks, whatsapp

## 简介

Official PHP SDK for the Funnelchat public API: contacts, messages, templates, forms, groups, numbers and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
