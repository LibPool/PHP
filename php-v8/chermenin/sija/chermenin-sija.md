# chermenin/sija

> 标签: api, framework, json, rest, restful, sija

## 简介

sija is an open source micro-framework to create RESTful services for JSON API via PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
