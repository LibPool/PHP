# wilianx7/php-recurring

> 标签: calendar, carbon, date-generator, php, recurrence, recurrence-rule, recurring, repeat-dates, repeat-events, rrule, schedule, scheduling, task-scheduling

## 简介

PHP library for generating recurring dates, schedules, and repeated task recurrences.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
