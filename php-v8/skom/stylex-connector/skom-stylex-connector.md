# skom/stylex-connector

> 标签: css, fluid, stylex, typo3, viewhelper

## 简介

StyleX Connector - Bridges StyleX build-time CSS authoring with TYPO3 Fluid templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
