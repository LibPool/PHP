# jossmp/sunatphp

> 标签: consulta, curl, peru, php, sunat

## 简介

Clase para realizar consultas a sunat Peru mediante el numero de ruc o dni

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
