# musoftware/device-secret-laravel

> 标签: api, device, hardware, laravel, license, monitoring, registration, serial

## 简介

Laravel package for checking device registration status against the Musoftwares Serial Device API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
