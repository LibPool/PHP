# doriiaan/filament-astrotomic

> 标签: doriiaan, filament-astrotomic, filamentphp, laravel

## 简介

Filament plugin which allows translations to be added to Filament resources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
