# doriiaan/filament-menu

> 标签: doriiaan, filament-menu, laravel

## 简介

A filament menu, inspired by datlechin/filament-menu-builder to reproduce WordPress menu system

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
