# crawlora/youtube

> 标签: API-Client, crawlora, scraping-api, sdk, web-scraping , youtube, youtube-api, youtube-captions, youtube-channels, youtube-comments, youtube-data, youtube-playlists, youtube-scraper, youtube-search, youtube-transcripts, youtube-videos

## 简介

Crawlora YouTube API client with 14 endpoints for search, channels, videos, playlists, comments, captions, and transcripts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
