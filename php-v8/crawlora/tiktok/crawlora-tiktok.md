# crawlora/tiktok

> 标签: API-Client, TikTok , crawlora, scraping-api, sdk, tiktok-api, tiktok-comments, tiktok-creative-center, tiktok-data, tiktok-hashtag-search, tiktok-profiles-posts, tiktok-scraper, tiktok-top-ads-data, tiktok-trends, tiktok-user, tiktok-video, web-scraping 

## 简介

Crawlora TikTok API client with 53 endpoints for video, user, and hashtag search; profiles and posts; comments; trends; Creative Center; and Top Ads data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
