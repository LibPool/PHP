# fanmade/laravel-adr-manager

> 标签: adr, architecture, decision-records, documentation, laravel

## 简介

Git-first, file-based Architectural Decision Record (ADR) manager for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
