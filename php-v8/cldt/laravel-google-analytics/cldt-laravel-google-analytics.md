# cldt/laravel-google-analytics

> 标签: akki-io, laravel-google-analytics

## 简介

A Laravel package to retrieve data from Google Analytics 4 using the GA4 Query Explorer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
