# hkyss/evocms-fixtures

> 标签: benchmark, evocms, evolution-cms, fixtures, seeding, testing

## 简介

Generates Evolution CMS content at scale — a document tree with a consistent closure table, template variables, users and permissions — and removes exactly what it made

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
