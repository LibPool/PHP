# hkyss/evocms-tune

> 标签: evocms, evolution-cms, index, mysql, performance, schema

## 简介

Database tuning for Evolution CMS CE 3: diagnoses the live schema, adds the indexes the core omits, removes the ones that only cost writes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
