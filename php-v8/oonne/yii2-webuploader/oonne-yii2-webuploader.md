# oonne/yii2-webuploader

> 标签: extension, upload, webuploader, widget, yii2

## 简介

Yii2 extension for large file chunk upload. Base on WebUploader.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
