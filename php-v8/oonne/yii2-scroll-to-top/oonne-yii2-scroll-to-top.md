# oonne/yii2-scroll-to-top

> 标签: extension, scroll, scroll-to-top, top, yii2

## 简介

A Yii 2 widget to add scroll-to-top button.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
