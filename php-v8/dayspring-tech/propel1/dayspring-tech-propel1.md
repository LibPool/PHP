# dayspring-tech/propel1

> 标签: Active Record, database, mapping, orm, persistence

## 简介

Propel is an open-source Object-Relational Mapping (ORM) for PHP5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
