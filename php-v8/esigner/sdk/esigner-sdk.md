# esigner/sdk

> 标签: bankid, e-signature, eID, eSignature, esigner, mitid, pdf, signing, webhooks, wordpress

## 简介

Official PHP client for the esigner e-signing API: BankID, MitID and other eID signature requests, signed PDFs and verified webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
