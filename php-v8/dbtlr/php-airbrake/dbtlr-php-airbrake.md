# dbtlr/php-airbrake

> 标签: airbrake, errors, exceptions, logging

## 简介

A PHP 5.3 library for sending errors to the Airbrake.io service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
