# dallanj/laravel-query-filters

> 标签: dallanj, laravel, laravel-query-filters

## 简介

A composable, allowlist-based filtering pipeline for Laravel Eloquent queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
