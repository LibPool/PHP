# skoziel/silex-filesystem

> 标签: filesystem, silex, symfony

## 简介

The Symfony Filesystem Service Provider for Silex 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
