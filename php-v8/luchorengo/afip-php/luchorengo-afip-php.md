# luchorengo/afip-php

> 标签: afip, cae, contribuyente, facturacion-electronica, gratis, libreria, padron, soap

## 简介

Libreria para usar los Web Services de AFIP (Argentina)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
