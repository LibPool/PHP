# cleatsquad/php-bandit

> 标签: ab-testing, bandit, beta-bernoulli, multi-armed-bandit, reinforcement-learning, statistics, thompson-sampling

## 简介

Beta-Bernoulli Thompson Sampling multi-armed bandit, in dependency-free PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
