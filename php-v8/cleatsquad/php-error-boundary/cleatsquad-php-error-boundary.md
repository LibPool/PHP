# cleatsquad/php-error-boundary

> 标签: error-boundary, exception-handler, fatal-error, json-error, shutdown-handler

## 简介

Deterministic fatal error and uncaught exception boundary returning standard JSON envelopes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
