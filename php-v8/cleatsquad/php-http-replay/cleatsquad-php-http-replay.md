# cleatsquad/php-http-replay

> 标签: http, mock, psr-7, replay, testing, vcr

## 简介

Deterministic HTTP request recording and replay for PHP 8.2+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
