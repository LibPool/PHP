# havenshen/slim-born

> 标签: Authentication, Skeleton, slim, slim 3

## 简介

Slim Framework 3 skeleton application has authentication.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
