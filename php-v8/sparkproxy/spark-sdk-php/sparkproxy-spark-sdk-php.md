# sparkproxy/spark-sdk-php

> 标签: sdk, sparkproxy, static house proxy

## 简介

SparkProxy Open API SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
