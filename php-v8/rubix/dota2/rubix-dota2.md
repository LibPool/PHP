# rubix/dota2

> 标签: Example Project, classification, cross validation, data science, dataset, dota, dota 2, game outcome prediciton, machine learning, ml, naive bayes, php, php ml, rubix ml, rubixml, tutorial

## 简介

Build a classifier to predict the outcome of Dota 2 games with the Naive Bayes algorithm and the results of 102,944 sample games.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
