# rubix/har

> 标签: Example Project, classification, classifier, cross validation, data science, dataset, dimensionality reduction, har, human activity recognition, imu sensor, machine learning, ml, mobile phone sensor, momentum, php, php ml, rubix ml, rubixml, softmax, tutorial

## 简介

Recognize one of six human activities such as standing, sitting, and walking using a Softmax Classifier trained on mobile phone sensor data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
