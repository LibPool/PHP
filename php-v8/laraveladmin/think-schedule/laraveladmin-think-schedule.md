# laraveladmin/think-schedule

> 标签: cron, laravel-style, schedule, scheduler, task, thinkphp

## 简介

Laravel-style task scheduler for ThinkPHP: define tasks in PHP and keep only one system cron entry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
