# kucoin/kucoin-futures-php-sdk

> 标签: api, futures, kucoin, kumex, sdk

## 简介

PHP SDK for KuCoin Futures API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
