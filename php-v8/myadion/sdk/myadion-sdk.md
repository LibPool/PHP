# myadion/sdk

> 标签: adion, adion cloud, adion pay, api, myadion, payments, sdk, sms

## 简介

Official PHP library for the Adion Cloud API: Adion Pay, SMS and every other endpoint.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
