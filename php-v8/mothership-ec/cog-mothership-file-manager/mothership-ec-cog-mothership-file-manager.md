# mothership-ec/cog-mothership-file-manager

> 标签: asset, assets, cog, file, files, image, images, mothership, upload, uploads

## 简介

Cog module for file/asset management in Mothership

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
