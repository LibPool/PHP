# micayael/form-generator-bundle

> 标签: bundle, dynamic-forms, form, form-generator, json, symfony, yaml

## 简介

Generate Symfony forms from YAML, JSON or PHP array configurations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
