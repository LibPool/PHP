# devtheorem/php-handlebars

> 标签: compile, handlebars, mustache, parse, render, template

## 简介

A blazing fast, spec-compliant PHP implementation of Handlebars.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
