# devgiants/phar-application

> 标签: cli, console, docker, phar, php

## 简介

Boilerplate for fully maintenable PHP CLI applications packaged in PHAR

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
