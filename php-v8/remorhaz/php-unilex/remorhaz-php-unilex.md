# remorhaz/php-unilex

> 标签: lex, lexical analyzer, lexical analyzer generator, tokenizer, tokenizer generator

## 简介

Unilex: lexical analyzer generator with Unicode support written in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
