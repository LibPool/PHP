# kuick/qa-toolkit

> 标签: Kuick, qa

## 简介

Kuick QA toolkit. It is a meta-package with popular PHP testing tools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
