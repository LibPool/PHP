# ellisio/laravel-phone

> 标签: format, formatter, laravel, phone, twilio, validation, validator

## 简介

A phone validator for Laravel using the free Twilio phone lookup service.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
