# leantime/leantime

> 标签: Agile, Scrum, asana-alternative, clickup-alternative, gantt, innovation-management, jira-alternative, kanban, lean, mysql, neurodiversity-friendly, php, project-management, task-management

## 简介

Open source project management system for non-project managers. Simple like Trello, powerful like Jira. Built with neurodiversity in mind.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
