# yatmo/yatmo-php

> 标签: geocoding, isochrone, laravel, listing, map, neighbourhood, poi, points-of-interest, property, proptech, real-estate, seo, symfony, yatmo

## 简介

Real estate maps, points of interest and neighbourhood data for PHP: typed client for the Yatmo API (neighbourhood text for SEO, nearest schools, shops and public transport with travel times, scores, isochrones, routes, geocoding, static maps). Laravel, Symfony, WordPress, plain PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
