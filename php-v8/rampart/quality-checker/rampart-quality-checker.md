# rampart/quality-checker

> 标签: PHPStan, ci, laravel, phpcs, phpunit, quality, security, static-analysis

## 简介

Laravel CLI quality gate: wraps phpcs, phpstan, phpunit, composer audit, trivy and adds custom PHP-Parser analyzers for security, missing tests and conventions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
