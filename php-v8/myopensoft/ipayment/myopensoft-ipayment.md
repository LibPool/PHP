# myopensoft/ipayment

> 标签: Malaysia, ipayment, janm, laravel, myopensoft, payment

## 简介

Laravel integration with JANM iPayment (Sistem Terimaan Elektronik Kerajaan Persekutuan)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://gitlab.com/myopensoft/laravel-ipayment.git
- Packagist 页面：https://packagist.org/packages/myopensoft%2Fipayment
