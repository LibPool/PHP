# promethys/revive

> 标签: Promethys, RecycleBin, filament, laravel, revive

## 简介

A 'RecycleBin' page where users can restore or delete permanently soft-deleted models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
