# promethys/checkbox-tree

> 标签: Promethys, checkbox-tree, laravel

## 简介

A Filament form component that provides hierarchical checkbox selection with parent-child relationships.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
