# vsimke/article-finder

> 标签: PHP

## 简介

Framework-agnostic PHP package for finding articles via Bing and Google SERP scraping using a chain-of-responsibility finder pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
