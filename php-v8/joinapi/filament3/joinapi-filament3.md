# joinapi/filament3

> 标签: boilerplate, filament, filamentphp, framework, laravel, php, starter, template

## 简介

A starter template for building projects with Laravel and FilamentPHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
