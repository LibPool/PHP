# joinapi/filament-organizations

> 标签: Authentication, filament, filament organizations, filament-organizations, joinapi, laravel, multi-tenant, organization management, saas, socialite

## 简介

A comprehensive Laravel authentication and authorization system designed for Filament, focusing on multi-tenant organization management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
