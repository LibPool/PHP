# joinapi/doc-gcp-ai

> 标签: PHP

## 简介

Com este projeto, você pode enviar documentos via upload e processá-los usando o Google Document AI para extrair dados

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
