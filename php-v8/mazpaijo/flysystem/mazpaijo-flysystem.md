# mazpaijo/flysystem

> 标签: Cloud Files, WebDAV, abstraction, aws, cloud, copy.com, dropbox, file systems, files, filesystem, filesystems, ftp, rackspace, remote, s3, sftp, storage

## 简介

Filesystem abstraction: Many filesystems, one API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
