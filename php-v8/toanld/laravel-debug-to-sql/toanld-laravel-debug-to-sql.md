# toanld/laravel-debug-to-sql

> 标签: PHP

## 简介

Create the simplest and fastest admin with 1 admin module and use inertiajs combined with vuejs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
