# toanld/laravel-scout-tntsearch-driver

> 标签: laravel, scout, search, tntsearch

## 简介

Driver for Laravel Scout search package based on https://github.com/teamtnt/tntsearch

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
