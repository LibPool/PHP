# zanderwar/stride-ace

> 标签: PHP

## 简介

Decoupled version of no-conflict Ace Editor for use with silverleague/stride on the SilverStripe framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
