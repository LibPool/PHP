# gabelbart/nova-toolbar-tools

> 标签: laravel, nova, nova-toolbar, nova-tools

## 简介

Adds toolbar tools and toolbar resources to laravel nova.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
