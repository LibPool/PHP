# monorailphp/monorail

> 标签: admin, inertia, laravel, panel, react

## 简介

Server-Driven UI (SDUI) framework for Laravel + Inertia.js + React + shadcn/ui.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
