# av-lib/age-verification

> 标签: PHP

## 简介

Verify visitors age (ID/face scan/etc) in geographical regions that require it with multiple providers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
