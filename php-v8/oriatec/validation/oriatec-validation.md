# oriatec/validation

> 标签: php, psr-7, symfony, validation

## 简介

A re-write of somnambulist/validation providing Laravel like validation, psr-7 compliant, as a standalone library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
