# mykholy/laravel-flowguard

> 标签: deduplication, fault-tolerance, idempotency, inbox, laravel, outbox, payments, reconciliation, reliability, transactional-outbox, webhooks

## 简介

Laravel idempotency, durable webhook inbox, transactional outbox, and explicit reconciliation for uncertain operations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
