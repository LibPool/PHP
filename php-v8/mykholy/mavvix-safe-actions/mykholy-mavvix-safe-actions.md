# mykholy/mavvix-safe-actions

> 标签: authorization, bulk-actions, data-safety, eloquent, filament, filament-plugin, filamentphp, laravel, multi-tenancy, preflight, transaction

## 简介

Fail-closed, tenant-aware Filament 5 bulk actions with verified selections, expiring preflights and transactional execution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
