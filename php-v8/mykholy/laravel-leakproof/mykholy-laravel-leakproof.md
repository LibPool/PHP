# mykholy/laravel-leakproof

> 标签: Gemini, JSON-API, Laravel-Security, ai-security, anthropic, api-key-detection, api-security, api-testing, data-leak-prevention, laravel, laravel-package, llm, openai, php, phpunit, privacy, secret-scanning, security-testing, sensitive-data

## 简介

Detect sensitive data and AI API key leaks in Laravel JSON responses with PHPUnit assertions, CLI scanner and optional middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
