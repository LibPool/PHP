# mykholy/laravel-failurelab

> 标签: fault-injection, idempotency, integration-testing, laravel, replay, resilience, testing

## 简介

Deterministic fault-injection and delivery-replay assertions for Laravel integration tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
