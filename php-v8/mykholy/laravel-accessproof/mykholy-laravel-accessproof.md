# mykholy/laravel-accessproof

> 标签: authorization, bola, idor, laravel, multi-tenancy, phpunit, regression-testing, security-testing

## 简介

Catch Laravel authorization regressions, IDOR/BOLA, cross-tenant leaks and unauthorized database writes in HTTP feature tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
