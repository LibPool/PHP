# erasys/openapi-php

> 标签: OAI, illuminate, laravel, oas, openapi, openapi3, swagger, swagger3

## 简介

Open API 3.0 builder and validation library for PHP that helps you write valid specs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
