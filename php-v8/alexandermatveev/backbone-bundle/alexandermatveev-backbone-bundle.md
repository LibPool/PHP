# alexandermatveev/backbone-bundle

> 标签: backbone, javascript, jquery, symfony

## 简介

Backbone.js Bundle for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
