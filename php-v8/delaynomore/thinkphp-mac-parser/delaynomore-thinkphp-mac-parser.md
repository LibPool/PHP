# delaynomore/thinkphp-mac-parser

> 标签: action, controller, module, parser, thinkphp, url

## 简介

URL解析工具，支持模块、控制器、方法的解析

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
