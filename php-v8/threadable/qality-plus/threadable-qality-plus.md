# threadable/qality-plus

> 标签: jira, laravel, phpunit, qality, testing

## 简介

Laravel and PHPUnit integration for publishing automated test results to QAlity Plus.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
