# jyokum/healthgraph

> 标签: Guzzle, Health Graph, runkeeper

## 简介

PHP wrapper for the RunKeeper Health Graph API built on Guzzle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
