# quasarstream/sdp

> 标签: SDP, rtp

## 简介

A PHP library for parsing and generating SDP (Session Description Protocol).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://www.quasarstream.com/webrtc
- 源码仓库：https://github.com/PHP-WebRTC/sdp.git
- Packagist 页面：https://packagist.org/packages/quasarstream%2Fsdp
