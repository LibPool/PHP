# quasarstream/rtp

> 标签: WebRTC, real-time-transport-protocol, rtp

## 简介

A PHP library for handling RTP (Real-time Transport Protocol) packets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://www.quasarstream.com/webrtc
- 源码仓库：https://github.com/PHP-WebRTC/rtp.git
- Packagist 页面：https://packagist.org/packages/quasarstream%2Frtp
