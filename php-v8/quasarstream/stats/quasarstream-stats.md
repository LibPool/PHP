# quasarstream/stats

> 标签: WebRTC, stats

## 简介

A PHP implementation of the WebRTC Statistics API for tracking RTP, DTLS, and media performance metrics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/PHP-WebRTC/stats.git
- Packagist 页面：https://packagist.org/packages/quasarstream%2Fstats
