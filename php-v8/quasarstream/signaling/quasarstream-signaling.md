# quasarstream/signaling

> 标签: rtp, signaling

## 简介

A PHP library for managing signaling mechanisms in WebRTC. This package supports signaling over WebSocket, TCP, UDP, and UNIX sockets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
