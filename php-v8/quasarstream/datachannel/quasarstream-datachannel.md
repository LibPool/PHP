# quasarstream/datachannel

> 标签: WebRTC, datachannel

## 简介

A PHP implementation of WebRTC's RTCDataChannel interface for bidirectional peer-to-peer data communication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
