# quasarstream/rtcp

> 标签: rtcp, rtp

## 简介

A pure PHP implementation of RTP Control Protocol (RTCP) packet parsing and generation, compliant with RFC 3550 and related specifications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
