# quasarstream/ntp

> 标签: multicastdns, ntp

## 简介

The NetworkTimeProtocol class provides utility methods for working with NTP (Network Time Protocol) timestamps in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
