# quasarstream/sctp

> 标签: WebRTC, datachannel, sctp

## 简介

A PHP library implementing SCTP (Stream Control Transmission Protocol) for WebRTC data channels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
