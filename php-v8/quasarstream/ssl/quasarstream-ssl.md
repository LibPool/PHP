# quasarstream/ssl

> 标签: certificate, crypto, openssl, privateKey, ssl, x509

## 简介

A PHP wrapper for OpenSSL using FFI, tailored for WebRTC components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
