# quasarstream/vpx

> 标签: libvpx, vpx

## 简介

A PHP wrapper around the libvpx codec using FFI, providing tools for encoding and decoding VP8/VP9 video streams for WebRTC applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
