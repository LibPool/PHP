# gam/laravel-sat-catalogs

> 标签: cfdi, gam, laravel-sat-catalogs, sat

## 简介

Provides a artisan command to automatically update SAT catalogs. Use a DB facade to access them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
