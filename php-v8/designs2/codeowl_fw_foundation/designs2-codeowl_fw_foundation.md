# designs2/codeowl_fw_foundation

> 标签: codeowl, contao, foundation, framework, grid, responsive, system, zurb

## 简介

Codeowl Framework Foundation. The extension uses the Framework Foundation (Version 6.2.3) from Zurb. This Framework has a lot of awesome Plugins, many solutions for the daily work of a frontend designer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
