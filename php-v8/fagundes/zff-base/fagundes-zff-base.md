# fagundes/zff-base

> 标签: Doctrine 2, bootstrap 3, bootstrap 4, twbs, util, zf2

## 简介

A ZF2 module that gathers a set of classes which are commonly used in several ZF2 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
