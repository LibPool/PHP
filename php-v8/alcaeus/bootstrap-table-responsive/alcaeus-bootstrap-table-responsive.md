# alcaeus/bootstrap-table-responsive

> 标签: bootstrap, css, responsive

## 简介

Adds CSS classes for responsive tables to Twitter Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
