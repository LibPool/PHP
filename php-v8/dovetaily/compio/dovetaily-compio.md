# dovetaily/compio

> 标签: artisan, artisan-blade, artisan_blade, blade, component, console, laravel, laravel-blade, laravel_blade, php

## 简介

Generator of component - It works temporarily only on Laravel with Artisan(CLI) by generating Blade components and others are in development (like `Twig` `VueJs`, ...)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
