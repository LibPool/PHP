# tdc/pdo

> 标签: mariadb, mysql, pdo

## 简介

PDO MySQL/MariaDB/PostgreSQL/SQLite wrapper adding nested transactions and sane defaults

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
