# skylive/lienzo

> 标签: cms, landing-page, laravel, lienzo, page-builder, visual-editor

## 简介

Landing page builder for Laravel: a visual editor, a validated document format and a native PHP renderer. No Node at runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
