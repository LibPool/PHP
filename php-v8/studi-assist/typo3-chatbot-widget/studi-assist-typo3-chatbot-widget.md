# studi-assist/typo3-chatbot-widget

> 标签: PHP

## 简介

TYPO3 extension that adds a floating bottom-right chatbot widget and opens an iframe to a configured chatbot URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
