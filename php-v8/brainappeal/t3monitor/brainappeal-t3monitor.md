# brainappeal/t3monitor

> 标签: extension, t3monitor, t3monitoring, typo3

## 简介

T3Monitor - Monitors TYPO3 installation for updates and security issues (Requires an account on https://www.t3monitor.de)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
