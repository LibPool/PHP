# mmmohebi/gap-api

> 标签: Gap-API, Gap-Bot-API, Gap-Bot-PHP, Gap-SDP-API, gap

## 简介

A PHP wrapper for the Gap Messenger SDP API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
