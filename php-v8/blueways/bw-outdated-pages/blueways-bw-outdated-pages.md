# blueways/bw-outdated-pages

> 标签: backend, dashboard, outdated, pages, scheduler, typo3, typo3-cms-extension

## 简介

Scheduler task, backend module and dashboard widget notifying about outdated pages in a configurable branch of the page tree.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
