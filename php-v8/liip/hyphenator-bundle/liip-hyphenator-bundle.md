# liip/hyphenator-bundle

> 标签: hyphenation

## 简介

This Bundle provides support for hyphenating long words using the Org_Heigl_Hyphenator library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
