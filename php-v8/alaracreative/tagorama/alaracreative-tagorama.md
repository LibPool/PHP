# alaracreative/tagorama

> 标签: eloquent, laravel, tag, tagging

## 简介

An Eloquent tagging package for Laravel. Just a demo, don't expect much.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
