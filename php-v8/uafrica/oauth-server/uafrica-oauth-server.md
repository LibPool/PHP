# uafrica/oauth-server

> 标签: cakephp, oauth, oauth server, oauth2, oauth2 server

## 简介

OAuth Server for CakePHP 3 using the PHP League's OAuth2 Server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
