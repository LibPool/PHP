## 简介

A production-grade PHP SDK for NigeriaBulkSMS API. Provides SMS sending, voice calls, audio uploads, and data fetching functionality with Laravel integration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
