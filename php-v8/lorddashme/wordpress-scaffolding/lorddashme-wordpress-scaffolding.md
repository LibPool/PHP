# lorddashme/wordpress-scaffolding

> 标签: blog, cms, project, scaffolding, wordpress, wp, wp-scaffolding

## 简介

A kick starter project structure for Wordpress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
