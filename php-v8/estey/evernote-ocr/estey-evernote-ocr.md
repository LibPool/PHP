# estey/evernote-ocr

> 标签: OCR, evernote, evernote ocr, text recognition

## 简介

Use the Evernote API to perform text recognition (OCR) on an image file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
