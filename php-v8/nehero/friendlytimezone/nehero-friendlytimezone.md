# nehero/friendlytimezone

> 标签: friendlytimezone, nehero, ozzie, ozziexsh, timezone

## 简介

Display timezones to your users in a friendly way using locations as names

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
