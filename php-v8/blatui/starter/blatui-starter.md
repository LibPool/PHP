# blatui/starter

> 标签: alpinejs, blade, blatui, laravel, shadcn, starter-kit, tailwindcss

## 简介

A Laravel starter kit pre-wired with BlatUI — shadcn/ui for the BLAT stack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
