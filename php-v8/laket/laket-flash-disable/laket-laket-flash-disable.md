# laket/laket-flash-disable

> 标签: admin, flash, flash-disable, laket, laket-admin

## 简介

闪存插件禁用，禁用后插件将不能进行相关的操作

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
