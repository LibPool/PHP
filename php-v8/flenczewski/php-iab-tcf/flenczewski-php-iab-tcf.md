# flenczewski/php-iab-tcf

> 标签: TCF, consent, gdpr, gvl, iab, rodo, tc-string

## 简介

Encode and decode IAB TCF v2.3 (GDPR Transparency & Consent Framework) TC Strings in PHP, with Global Vendor List tooling and a CLI decoder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
