# crainios/leanqr

> 标签: dependency-free, php, png, qr-code, qr-code-generator, qrcode

## 简介

Lightweight QR Code generator for PHP with PNG output and optional labels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
