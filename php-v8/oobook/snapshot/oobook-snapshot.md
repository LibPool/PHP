# oobook/snapshot

> 标签: clone, copy, eloquent, laravel, oobook, snapshot

## 简介

Create a snapshot on the stage of creating record and always keeps the currently created data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
