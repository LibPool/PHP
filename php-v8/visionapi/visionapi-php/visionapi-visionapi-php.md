# visionapi/visionapi-php

> 标签: OCR, document-ai, extraction, invoice, pdf, receipt, vision, visionapi

## 简介

Official PHP client for the Vision API — credit-based OCR and visual intelligence. Extract structured JSON from images and PDFs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
