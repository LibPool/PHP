# dwr/openweather-bundle

> 标签: forecast, open weather api, weather, weather rest api

## 简介

Symfony3 bundle wraps Open Weather API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
