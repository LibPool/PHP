# devrabie/fluent-keyboard_plus

> 标签: api, bot, builder, fluent, keyboard, telegram

## 简介

Fluent Keyboard builder for ReplyKeyboardMarkup and InlineKeyboardMarkup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
