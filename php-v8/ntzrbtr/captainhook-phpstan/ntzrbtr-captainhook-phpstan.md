# ntzrbtr/captainhook-phpstan

> 标签: PHPStan, captainhook, git, hooks, pre-commit, static analysis

## 简介

CaptainHook action that runs PHPStan on staged files covered by the project's PHPStan configuration

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
