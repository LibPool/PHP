# ntzrbtr/shopware-custom-fields

> 标签: custom fields, shopware, shopware6

## 简介

Define custom field sets for Shopware 6 in PHP and install, update and uninstall them from plugins

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
