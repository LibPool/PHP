# kpqc/kpqc

> 标签: aimer, cryptography, haetae, kpqc, ntruplus, post-quantum, smaug-t

## 简介

PHP APIs for AIMer, HAETAE, NTRU+, and SMAUG-T.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
