# merzilla/inm-googlesitemap

> 标签: Google XML sitemap, TYPO3 CMS, seo

## 简介

Google sitemap.xml extension for TYPO3 projects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
