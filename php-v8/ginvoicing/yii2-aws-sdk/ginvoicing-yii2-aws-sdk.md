# ginvoicing/yii2-aws-sdk

> 标签: aws, sdk, wrapper, yii2

## 简介

Yii2 component AWS Sdk v3 wrapper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
