# bridgeeighteen/supporter-portal

> 标签: PHP

## 简介

The Bridge Eighteen Community's supporter portal. It should be used together with NFC cards or labels include a NTAG chip or follow the NFC Forum Tag Type 1 standard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
