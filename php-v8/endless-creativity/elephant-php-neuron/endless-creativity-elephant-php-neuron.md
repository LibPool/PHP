# endless-creativity/elephant-php-neuron

> 标签: docx, elephant-php, file-reader, neuron-ai, rag, word

## 简介

Neuron AI FileDataLoader reader for .docx files, powered by elephant-php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
