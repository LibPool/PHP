# endless-creativity/elephant-php

> 标签: OOXML, converter, document, docx, html, markdown, office, word

## 简介

An elephant never forgets your document structure — convert .docx to semantic HTML and Markdown in pure PHP. Inspired by mammoth.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
