# fostam/file

> 标签: PHP

## 简介

Convenience wrapper for PHP functions like `fopen()`, `fgets()` that offers object oriented usage and handles errors with exceptions instead of return results.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
