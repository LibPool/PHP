# beanworks/quickbooks-online-v3-sdk

> 标签: beanworks, qbo, quickbooks

## 简介

QBO v3 API SDK for PHP. Supported and used by BeanworksAP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
