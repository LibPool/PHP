# silvercommerce/silvercommerce-theme

> 标签: bootstrap4, silverstripe, theme

## 简介

A simple SilverStripe theme built on bootstrap 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
