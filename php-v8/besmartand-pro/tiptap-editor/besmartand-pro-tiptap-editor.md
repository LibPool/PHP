# besmartand-pro/tiptap-editor

> 标签: PHP

## 简介

Reusable Symfony Tiptap editor bundle with optional EasyAdmin integration and Flysystem uploads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
