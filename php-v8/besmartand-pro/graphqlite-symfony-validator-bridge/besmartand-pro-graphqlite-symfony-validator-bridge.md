# besmartand-pro/graphqlite-symfony-validator-bridge

> 标签: GraphQLite, graphql, symfony, validator

## 简介

A bridge to use Symfony validator with GraphQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
