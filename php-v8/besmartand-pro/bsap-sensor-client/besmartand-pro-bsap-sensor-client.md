# besmartand-pro/bsap-sensor-client

> 标签: api, php, sensor, temperature

## 简介

Framework-independent PHP client for the BeSmartAnd.Pro Sensor API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
