# nekudo/angela

> 标签: async, asynchronous, framework, manager, microservices, worker, zeromq, zmq

## 简介

PHP worker/microservice framework based on ZeroMQ.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
