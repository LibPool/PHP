# nekudo/shiny_deploy

> 标签: angular, deployment, gearman, git, javascript, php

## 简介

ShinyDeploy is a deployment tool written in PHP and JavaScript.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
