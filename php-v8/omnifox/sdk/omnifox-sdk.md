# omnifox/sdk

> 标签: Messenger, Webchat, api, crm, instagram, laravel, messaging, omnichannel, omnifox, sdk, whatsapp

## 简介

Official PHP SDK for the Omnifox.io REST API: inbox, contacts, CRM, boards, calendar, catalog, orders, quotes, workflows and reports.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
