# wangzd/laravel-custom-page

> 标签: PHP

## 简介

laravel-custom-page是一个用于管理你需要给普通用户可以编辑的页面内容

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
