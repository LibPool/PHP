# data-uri/twig-extension

> 标签: dataURI, dataURL, twig extension

## 简介

Twig extension for data URI ; Converts data to the data URI Url scheme (RFC 2397)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
