# fiscalapi-br/fiscalapi-php

> 标签: brasil, certidao, cnd, cnir, cnpj, fiscalapi, inscrição estadual, nfe, produtor rural, sefaz, sigef

## 简介

SDK da FiscalAPI (Brasil): Inscrição Estadual, CNPJ, certidões, NF-e, SIGEF, CNIR e perfil do produtor rural.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
