# marcuspi/doctrine-log-bridge

> 标签: dbal, doctrine, logger, psr-3, sqllogger

## 简介

Allows you to pass a PSR-3 compliant logger to Doctrine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
