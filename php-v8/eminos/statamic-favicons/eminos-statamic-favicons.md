# eminos/statamic-favicons

> 标签: addon, browser appearance, favicon, favicons, statamic

## 简介

Optional Statamic tag for rendering favicon markup generated by statamic-favicons.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
