# duva-mail/symfony-mailer

> 标签: Bridge, duva, email, mailer, symfony, transactional-email, transport

## 简介

Symfony Mailer transport for Duva, the transactional email API hosted in Canada.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
