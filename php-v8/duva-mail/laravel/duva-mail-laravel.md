# duva-mail/laravel

> 标签: duva, email, laravel, mail, mailer, transactional-email

## 简介

Laravel mail transport for Duva, the transactional email API hosted in Canada.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://duva.ca
- 源码仓库：https://github.com/duva-mail/duva-laravel.git
- Packagist 页面：https://packagist.org/packages/duva-mail%2Flaravel
