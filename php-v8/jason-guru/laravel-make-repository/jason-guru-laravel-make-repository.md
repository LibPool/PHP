# jason-guru/laravel-make-repository

> 标签: command, eloquent, laravel, make, repository

## 简介

A simple package to create a make:repository command for Laravel 10, 11, and 12.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
