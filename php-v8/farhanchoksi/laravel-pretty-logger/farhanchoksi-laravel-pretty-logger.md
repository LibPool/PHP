# farhanchoksi/laravel-pretty-logger

> 标签: debug, dio, http, laravel, logger, logging, middleware

## 简介

Laravel Pretty Logger — a pretty_dio_logger style HTTP request/response logger for Laravel: colored, boxed terminal output (and a readable file log) with automatic secret masking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
