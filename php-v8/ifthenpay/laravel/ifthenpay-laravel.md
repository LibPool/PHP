# ifthenpay/laravel

> 标签: ApplePay, googlepay, ifthenpay, laravel, mbway, multibanco, paybylink, payments, payshop, pix

## 简介

Laravel package for the ifthenpay Payment Gateway (Multibanco, MB WAY, Payshop, Credit Card, Pix, Pay by Link).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
