# ifthenpay/multibanco-magento

> 标签: gateway, ifthenpay, magento2, merchant, multibanco, pay, payment

## 简介

Método de pagamento multibanco Ifthenpay para Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
