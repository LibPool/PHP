# phpsa/laravel-yourls-plugin

> 标签: Shorturl, laravel, url shortener, yourls

## 简介

Plugin which integrates Laravel with Yourls (Your Own URL Shortener).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
