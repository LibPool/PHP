# maurobonfietti/slim4-api-skeleton

> 标签: api, mysql, php, rest, rest-api, slim, slim-micro-framework, slim4

## 简介

Useful skeleton for RESTful API development, using PHP and Slim 4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
