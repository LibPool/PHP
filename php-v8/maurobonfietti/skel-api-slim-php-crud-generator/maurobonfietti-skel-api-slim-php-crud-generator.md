# maurobonfietti/skel-api-slim-php-crud-generator

> 标签: PHP

## 简介

CRUD Generator for Slim 4 - Api Skeleton.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
