# davidbarratt/drupal-structure

> 标签: PHP

## 简介

Giving Drupal 6 & 7 a Directory Sturcture like Drupal 8 via Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
