# bit-part/craft-asset-trash

> 标签: PHP

## 简介

A Craft CMS plugin that intercepts asset deletion and moves files to a trash directory for later restoration or permanent deletion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
