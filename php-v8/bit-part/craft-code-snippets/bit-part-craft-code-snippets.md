# bit-part/craft-code-snippets

> 标签: PHP

## 简介

Manage and inject code snippets (GTM, Analytics, ad tags, etc.) into your Craft CMS site from the control panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
