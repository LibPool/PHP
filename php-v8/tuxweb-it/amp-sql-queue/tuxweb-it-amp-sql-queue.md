# tuxweb-it/amp-sql-queue

> 标签: PHP

## 简介

Async non-blocking SQL job queue for AMPHP, PostgreSQL, MySQL, and MariaDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
