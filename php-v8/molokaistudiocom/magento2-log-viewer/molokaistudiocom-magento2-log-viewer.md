# molokaistudiocom/magento2-log-viewer

> 标签: admin, log, log-viewer, magento2, magento2-module

## 简介

Read-only viewer for the var/log files in the Magento 2 admin: tail, page back, live follow, search and download

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
