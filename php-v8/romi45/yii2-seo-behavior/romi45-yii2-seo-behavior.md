# romi45/yii2-seo-behavior

> 标签: Behavior, patterns, romi45, seo, yii2

## 简介

Seo behavior for Yii2 models and meta tags helper with patterns using possibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
