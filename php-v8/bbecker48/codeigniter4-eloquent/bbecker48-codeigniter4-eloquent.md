# bbecker48/codeigniter4-eloquent

> 标签: codeigniter, codeigniter4, eloquent, laravel, orm

## 简介

Simple integration of Laravel Eloquent ORM into CodeIgniter 4 via Composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
