# pegziq/laravel-responder

> 标签: api, fractal, laravel, lumen, responder, response, transformer

## 简介

A Fractal Laravel package for building API responses, giving you the power of Fractal and the elegancy of Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
