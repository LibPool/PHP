# anshu-krishna/neo4j-bolt

> 标签: Socket, bolt, database, neo4j

## 简介

PHP driver for Bolt protocol for communication with Neo4j graph database over TCP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
