# paddlehq/paddle-php-sdk

> 标签: paddle, php, sdk

## 简介

Paddle's PHP SDK for Paddle Billing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://developer.paddle.com/api-reference/overview
- 源码仓库：https://github.com/PaddleHQ/paddle-php-sdk.git
