# blyattebayo/polymorph

> 标签: admin, cms, laravel, platform, plugins, records, schema

## 简介

Polymorph platform core: schema-driven CMS/records framework for Laravel with a bundled admin SPA, access control, media pipeline, and a plugin SDK surface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
