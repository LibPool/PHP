# blyattebayo/polymorph-plugin-test-kit

> 标签: PHP

## 简介

Polymorph Extension SDK V2 test kit: in-memory fakes + PluginTestCase for extension unit tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
