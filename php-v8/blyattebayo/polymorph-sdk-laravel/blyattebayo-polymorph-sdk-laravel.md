# blyattebayo/polymorph-sdk-laravel

> 标签: PHP

## 简介

Polymorph Extension SDK V2 — Laravel host binding (ExtensionProvider base). Host-provided at runtime; NOT bundled into extension artifacts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
