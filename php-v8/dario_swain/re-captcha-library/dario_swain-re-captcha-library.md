# dario_swain/re-captcha-library

> 标签: Guzzle, captcha, form, google, psr7, recaptcha, security, validation, webservice

## 简介

Google ReCAPTCHA (ver. 2) backend provider.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
