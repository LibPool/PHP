# rocareer/radmin

> 标签: High Performance, Radmin, admin, webman, workerman

## 简介

Radmin core: a high-performance Webman-based admin platform, distributed as a webman base plugin. Build multiple projects on one maintained core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
