# iosley/slim-auto-routes

> 标签: autoload, middleware, route, router, routes, slim

## 简介

The middleware for auto load routes to Slim Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
