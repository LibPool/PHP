# trustdpv/sdk

> 标签: api, sdk, trust, trustdpv, verification

## 简介

Official PHP SDK for the TrustDPV API — trust scores, verification, and batch checks

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
