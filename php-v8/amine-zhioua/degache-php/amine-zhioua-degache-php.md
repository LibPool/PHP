# amine-zhioua/degache-php

> 标签: RIB, car-plate, cin, currency, formatter, matricule-fiscal, phone-number, postal-code, tax-id, tunisia, tunisian, validation

## 简介

A framework-agnostic PHP library of Tunisian utilities: phone number, CIN, RIB, car plate, postal code, and tax ID validation, plus currency and date formatting for the Tunisian locale.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
