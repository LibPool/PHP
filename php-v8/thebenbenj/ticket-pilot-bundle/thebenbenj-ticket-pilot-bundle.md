# thebenbenj/ticket-pilot-bundle

> 标签: Agent, ai, automation, bundle, claude, cursor, devops, github, gitlab, jira, sentry, symfony

## 简介

Autonomous AI development pipeline for Symfony: turns tickets (Jira, Sentry, GitHub Issues) into merge/pull requests via a coding agent (Cursor CLI, Claude Code, ...).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
