# backtik-ch/laravel-ai-usage

> 标签: PHP

## 简介

Track and log AI usage (tokens, cost, duration) for any Laravel application, with optional auto-discovery for laravel/ai SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
