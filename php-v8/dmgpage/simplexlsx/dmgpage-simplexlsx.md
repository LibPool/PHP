# dmgpage/simplexlsx

> 标签: backend, excel, parser, php, xlsx

## 简介

Parse and retrieve data from Excel XLSx files. MS Excel 2007 workbooks PHP reader.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
