# thepixelage/craft-markasnew

> 标签: Craft, cms, craft-markasnew, craft-plugin, craftcms

## 简介

Mark As New is a Craft CMS plugin for marking content and products as new

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
