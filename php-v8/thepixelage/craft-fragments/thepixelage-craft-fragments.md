# thepixelage/craft-fragments

> 标签: Craft, cms, craft-fragments, craft-plugin, craftcms

## 简介

Fragments is a Craft CMS plugin for managing content and presentational fragments

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
