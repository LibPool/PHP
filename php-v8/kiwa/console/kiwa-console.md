# kiwa/console

> 标签: BitAndBlack, Kiwa, Köngeter, Tobias Köngeter, WirbelWild, cli, console, framework, template, web framework, website

## 简介

This library provides a CLI to help handling a website made with Kiwa.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
