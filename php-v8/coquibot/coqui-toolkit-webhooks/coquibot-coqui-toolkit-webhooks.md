# coquibot/coqui-toolkit-webhooks

> 标签: PHP

## 简介

Incoming webhooks for Coqui: HTTP receiver + management CRUD, HMAC verifiers (GitHub/Slack/generic), and the webhook toolkit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
