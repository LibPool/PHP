# manasija/drishti-sdk

> 标签: drishti-api, http-client, indian-stock-market, php, sdk, websocket

## 简介

PHP client for the Drishti API (/v1): Indian stock market news, filings, earnings, concalls and real-time WebSocket feeds

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
