# bokshorn-it/filament-self-updater

> 标签: filament, filament-plugin, filamentphp, github, laravel, self-update, updater

## 简介

A Filament plugin that updates a Laravel application from its own GitHub repository: finds the newest tag or release, installs it through a queued job, removes files the release dropped and runs a post-update script.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
