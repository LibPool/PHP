# iak/dispatch-group

> 标签: dispatch, dispatch-group, iaK, jobs, laravel, queued jobs, queues

## 简介

Run code when a group of queued jobs has completed, successfully or not.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
