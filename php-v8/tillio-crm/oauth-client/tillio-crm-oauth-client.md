# tillio-crm/oauth-client

> 标签: Authentication, OpenId, SSO, oauth, oauth2, tillio, tillio-crm

## 简介

Official PHP OAuth2 client for Tillio CRM single sign-on.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
