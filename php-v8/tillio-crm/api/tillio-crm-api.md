# tillio-crm/api

> 标签: API-Client, api, crm, rest, sdk, tillio, tillio-crm

## 简介

Official PHP SDK for Tillio API v2 - typed DTOs, both connection modes (direct API key and marketplace proxy), built-in retry and rate limiting. Documentation in Polish.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
