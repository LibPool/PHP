# tillio-crm/oauth-resources

> 标签: apps, firestore, gcs, oauth, sdk, storage, tillio, tillio-crm

## 简介

Official PHP SDK for Tillio app resources: per-app document storage and file storage proxy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
