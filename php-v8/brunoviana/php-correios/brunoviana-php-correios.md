# brunoviana/php-correios

> 标签: calculo, correios, frete, preços e prazos

## 简介

Kit de desenvolvimento para uso dos serviços dos Correios.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
