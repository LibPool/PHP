# brunoviana/dotenv-manipulator

> 标签: dotenv, laravel

## 简介

A mirror of absolutehh/dotenv-manipulator | This package can manipulate the .env file of a laravel project on runtime.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
