# germancoding/tls_icon

> 标签: icon, logging, ssl, tls

## 简介

Displays a lock next to the message if it was received using TLS. Requires TLS logging enabled in the MTA.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
