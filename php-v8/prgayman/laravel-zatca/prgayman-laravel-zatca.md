# prgayman/laravel-zatca

> 标签: ZATCA, e-invoicing, laravel, prgayman, qrcode

## 简介

Laravel package a helper to Generate the QR code and signed it for ZATCA E-invoicing

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
