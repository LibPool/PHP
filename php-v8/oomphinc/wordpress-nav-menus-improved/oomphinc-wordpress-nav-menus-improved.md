# oomphinc/wordpress-nav-menus-improved

> 标签: PHP

## 简介

Enhances WordPress Nav Menus with support for sub-menu rendering and post archives.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
