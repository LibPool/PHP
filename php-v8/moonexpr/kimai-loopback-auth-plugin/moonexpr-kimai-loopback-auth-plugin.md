# moonexpr/kimai-loopback-auth-plugin

> 标签: PHP

## 简介

Passwordless auto-login for same-machine (loopback) requests via the REMOTE_USER FastCGI param. No core files modified.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
