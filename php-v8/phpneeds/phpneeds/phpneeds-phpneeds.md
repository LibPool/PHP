# phpneeds/phpneeds

> 标签: NoFramework, lightweight, non-mvc, php, phpneeds

## 简介

PHPneeds is a lightweight non-MVC PHP library for quickly start a project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
