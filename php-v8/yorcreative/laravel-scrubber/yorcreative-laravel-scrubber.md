# yorcreative/laravel-scrubber

> 标签: framework, laravel, laravel log scrubber, log scrub, scrub logs, scrub sensitive information, scrubber, secret scrubber, sensitive information scrubber

## 简介

A laravel package that scrubs sensitive information for you.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
