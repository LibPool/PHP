# yorcreative/laravel-query-watcher

> 标签: capture queries, framework, laravel, queries, query capture, query monitoring, query watcher, slow query monitoring, sql monitoring

## 简介

A Laravel package that provides configurable application query capturing & monitoring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
