# savepinner/pinterest-url-normalizer

> 标签: normalizer, parser, pinterest, url, validation

## 简介

Parse, classify, and normalize Pinterest URLs without network requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
