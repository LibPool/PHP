# memora/laravel-antispam

> 标签: PHP

## 简介

Invisible anti-spam middleware for Laravel - honeypot, time trap, JS token, rate limiting. Zero friction for real users.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
