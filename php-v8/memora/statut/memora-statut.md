# memora/statut

> 标签: laravel, monitoring, robotalp, status-page, statut, uptime

## 简介

Page de statut publique multilingue pour applications Laravel, multi-provider (Robotalp et plus).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
