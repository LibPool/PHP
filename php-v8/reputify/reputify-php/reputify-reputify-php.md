# reputify/reputify-php

> 标签: api, reputation, reputify, reviews, sdk, trustscore

## 简介

PHP client for the Reputify API (api.reputify.io): reviews, scores, surveys, invitations, embeds, OAuth and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
