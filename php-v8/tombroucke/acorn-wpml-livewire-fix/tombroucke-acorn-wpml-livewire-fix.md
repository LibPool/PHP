# tombroucke/acorn-wpml-livewire-fix

> 标签: PHP

## 简介

Prevents WPML from appending the language path to home_url() when Acorn sets the Laravel root URL, fixing broken Livewire asset and update URLs on translated pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
