# asarach/translation

> 标签: asarach, laravel, laravel-translator, localization, translation, translator

## 简介

A Translation package for Laravel 5 with database and cache support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
