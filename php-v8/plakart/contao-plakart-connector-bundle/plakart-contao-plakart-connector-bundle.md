# plakart/contao-plakart-connector-bundle

> 标签: PHP

## 简介

Interne API-Verbindung zur Verwaltung von verschiedenen Contao-Installationen.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
