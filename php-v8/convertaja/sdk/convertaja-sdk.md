# convertaja/sdk

> 标签: Danfe, api, assinatura eletronica, boleto, cep, cnpj, convertaja, nfe, pdf, pix, sdk, zpl

## 简介

SDK oficial da API do Convertajá: PDF, DANFE, etiquetas ZPL, assinatura eletrônica, CNPJ, CEP, boleto e Pix.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
