# amaccis/datetai

> 标签: TAI64, TAI64N, TAI64NA, date, datetime, datetimeimmutable, tai, time

## 简介

A PHP library that includes a set of tools for handling the TAI time standard with DateTime and DateTimeImmutable instances.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
