# ngodingskuyy/laravel-module-generator

> 标签: crud, generator, laravel, module, shadcn-vue, tailwind, vue

## 简介

Modular CRUD Generator for Laravel + Vue + Tailwind (shadcn-vue)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
