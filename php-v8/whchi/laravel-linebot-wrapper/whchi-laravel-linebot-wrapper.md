# whchi/laravel-linebot-wrapper

> 标签: chatbot, laravel, line, wrapper

## 简介

A simple laravel wrapper for linecorp/line-bot-sdk

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
