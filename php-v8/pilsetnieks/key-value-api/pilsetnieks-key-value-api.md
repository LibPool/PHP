# pilsetnieks/key-value-api

> 标签: apc, cache, key-value, memcache

## 简介

Simple key-value cache API to abstract the underlying key-value store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
