# nhanchaukp/codeigniter4-cart-library

> 标签: PHP

## 简介

A basic port of the codeigniter 3 cart module for CodeIgniter 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
