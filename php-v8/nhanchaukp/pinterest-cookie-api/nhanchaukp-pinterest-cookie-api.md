# nhanchaukp/pinterest-cookie-api

> 标签: pinterest cookie api, pinterest pin api

## 简介

Library for get Boards, Account Info, Pin to Pinterest via cookie string.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
