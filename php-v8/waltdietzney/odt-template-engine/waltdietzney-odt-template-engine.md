# waltdietzney/odt-template-engine

> 标签: LibreOffice, OpenDocument, document-generation, odt, office, php, template

## 简介

A PHP template engine for generating editable OpenDocument Text (ODT) files with variables, conditions, loops, images, rich text, tables and styles.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
