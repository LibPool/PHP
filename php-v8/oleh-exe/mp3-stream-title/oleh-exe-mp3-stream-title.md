# oleh-exe/mp3-stream-title

> 标签: Shoutcast, icecast, metadata, mp3, stream, webradio

## 简介

Fetch and parse current track metadata from Icecast and Shoutcast MP3 streams.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
