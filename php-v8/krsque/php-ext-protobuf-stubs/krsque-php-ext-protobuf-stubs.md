# krsque/php-ext-protobuf-stubs

> 标签: PHPStan, ide, protobuf, psalm, static-analysis, stubs

## 简介

PHPStan / Psalm / PhpStorm stubs for ext-protobuf (the protobuf C extension for PHP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
