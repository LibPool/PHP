# jeremykenedy/laravel-ui-kit

> 标签: accessibility, alpinejs, blade, blade-components, bootstrap, components, dark-mode, design-system, laravel, livewire, react, svelte, tailwind, tailwindcss, ui, ui-kit, vue

## 简介

A multi-framework UI component library for Laravel. Supports Tailwind CSS, Bootstrap 5, and Bootstrap 4 with Blade, Livewire, Vue, React, and Svelte frontends.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
