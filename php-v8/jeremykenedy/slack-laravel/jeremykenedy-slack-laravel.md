# jeremykenedy/slack-laravel

> 标签: laravel, slack

## 简介

Laravel integration for the jeremykenedy/slack package, including facades and service providers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
