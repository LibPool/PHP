# groton-school/slim-lti-partitioned-session

> 标签: PHP

## 简介

Negotiate CHIPS partitioned third party session cookies from an embedded LTI Tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
