# groton-school/slim-lti-infrastructure-gae

> 标签: PHP

## 简介

Shim to implement packbackbooks/lti-1p3-tool storage interfaces in Firestore

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
