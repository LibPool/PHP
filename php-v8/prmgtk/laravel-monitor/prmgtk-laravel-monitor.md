# prmgtk/laravel-monitor

> 标签: error-monitoring, exceptions, laravel, monitoring, prmgtk

## 简介

Report errors from any Laravel site to the prmgtk error-monitoring platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
