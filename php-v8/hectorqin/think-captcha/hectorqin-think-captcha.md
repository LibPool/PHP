# hectorqin/think-captcha

> 标签: captcha, sdk, think, thinkphp

## 简介

Captcha package for ThinkPHP5 and ThinkPHP6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
