# weegosoft/bootstrap-form-builder

> 标签: PHP

## 简介

Un générateur de formulaires HTML compatible Bootstrap 4/5 avec gestion automatique du binding d'objets/tableaux et de l'échappement XSS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
