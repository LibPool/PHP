# notegame/date

> 标签: carbon, date, datetime, i18n, laravel, time, translation

## 简介

A date library to help you work with dates in different languages fix for support buddhist year

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
