# phpffcms/ffcms-weather

> 标签: api, app, ffcms, map, php, weather

## 简介

Weather application for ffcms 3 to use openweathermap.org api data and mapbox.com maps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
