# phpffcms/demo-app-package

> 标签: app, ffcms, php

## 简介

Demo of FFCMS 3 simple application package distributed under composer requirements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://ffcms.org
- 源码仓库：https://github.com/phpffcms/demo-app-package.git
