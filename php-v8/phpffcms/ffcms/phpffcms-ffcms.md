# phpffcms/ffcms

> 标签: PHP7, cms, ffcms, framework, mvc, pdo, php

## 简介

FFCMS 3 version based on MVC core ffcms-core.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
