# planetacodigo/pla

> 标签: PHP

## 简介

phpLiteAdmin is a web-based SQLite database admin tool written in PHP with support for SQLite3 and SQLite2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
