# kantorge/laravel-currency-exchange-rates

> 标签: kantorge, laravel, laravel-currency-exchange-rates

## 简介

A Laravel package to retrieve historical currency exchange rate data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
