# operatoroverload/restserver

> 标签: http, json, light-weight, mit, php, rest, rest-server

## 简介

php rest server for very light-weight REST APIs, forked from jacwright/RestServer and kevjett/RestServer to stabilize a version

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
