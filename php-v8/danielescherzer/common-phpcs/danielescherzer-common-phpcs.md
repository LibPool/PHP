# danielescherzer/common-phpcs

> 标签: PHP

## 简介

PHP CodeSniffer standards, partially based on mediawiki/mediawiki-codesniffer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
