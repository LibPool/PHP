# openwanderer/openwanderer

> 标签: 360, panoramas

## 简介

OpenWanderer is a project to create a 100% free and open source panoramas platform. This is the server package.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
