# canphp/canphp

> 标签: canphp, framework, speedphp

## 简介

the canphp Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.canphp.com/
- 源码仓库：https://github.com/canphp/canphp.git
- Packagist 页面：https://packagist.org/packages/canphp%2Fcanphp

## 历史版本号

- 当前版本：3.0.0

- 3.0.0

## 获取地址

- Composer 安装：`composer require canphp/canphp`
- Packagist 仓库：https://repo.packagist.org/p2/canphp/canphp.json
- 许可证：Apache2
- PHP 要求：>=5.3.0
