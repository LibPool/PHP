# larabros/oauth2-psn

> 标签: larabros, oauth2-psn

## 简介

PSN OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
