# enrise/zf-elasticsearch

> 标签: Zend Framework, elasticsearch, zf2

## 简介

A very simple but drop-in zf2 module for the elasticsearch client library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
