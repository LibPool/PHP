# hellosworldos/phing-webserver-debug

> 标签: PHP

## 简介

Phing targets to initialize debugging inside docker container with hellosworldos/webserver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
