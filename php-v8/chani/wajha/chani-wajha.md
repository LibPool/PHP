# chani/wajha

> 标签: PHP

## 简介

A fast, lightweight HTTP router for PHP 8.3+ combining O(1) static maps and bucketed PCRE2 regex evaluation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
