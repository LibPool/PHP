# maviance/smobilpay-php

> 标签: Mobile Payments, Smobilpay, Third Party, api, bill payments, mobile money, payments, php, topups

## 简介

Smobilpay Third Party (S3P) API client for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
