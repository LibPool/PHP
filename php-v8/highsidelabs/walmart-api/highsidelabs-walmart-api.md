# highsidelabs/walmart-api

> 标签: api, ecommerce, rest, sdk, walmart, walmart-1p-suppliers-api, walmart-api, walmart-content-providers-api, walmart-marketplace-api

## 简介

A PHP client for Walmart's Marketplace, 1P Supplier, and Content Provider APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
