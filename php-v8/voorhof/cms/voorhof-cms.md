# voorhof/cms

> 标签: blade, bootstrap, cms, laravel, starter kit

## 简介

Laravel CMS scaffolding using the Bootstrap frontend toolkit and Blade templating engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
