# evankford/pest-plugin-mutate-lines

> 标签: mutation, mutation-testing, pest, php, plugin, test, testing, unit

## 简介

Scope Pest mutation testing to changed lines (--mutate-diff) or explicit line ranges (--mutate-lines).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
