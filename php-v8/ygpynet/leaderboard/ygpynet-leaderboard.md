# ygpynet/leaderboard

> 标签: Gamification, flarum, leaderboard, points, ranking

## 简介

A points-based leaderboard for Flarum powered by ygpynet/point-system, with period filtering and podium display.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
