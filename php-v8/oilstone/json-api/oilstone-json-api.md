# oilstone/json-api

> 标签: JSON-API, api, json, jsonapi, jsonapi.org, oilstone

## 简介

Framework agnostic JSON API (jsonapi.org) implementation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
