# gerardo-cornejo/batch

> 标签: PHP

## 简介

Biblioteca para procesos batch (por lotes) en proyectos CodeIgniter 4 con patrón Read-Process-Write.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
