# thenlabs/class-builder

> 标签: builder, builder-pattern, php-builder, php-class, php-classes

## 简介

Dynamic management of classes, traits and interfaces in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
