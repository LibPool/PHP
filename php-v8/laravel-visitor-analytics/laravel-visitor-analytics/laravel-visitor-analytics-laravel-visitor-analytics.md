# laravel-visitor-analytics/laravel-visitor-analytics

> 标签: analytics, dashboard, laravel, statistics, visitor-tracking

## 简介

A lightweight, self-hosted, and privacy-focused visitor tracking package for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
