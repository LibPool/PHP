# drupalauth/simplesamlphp-module-drupalauth

> 标签: Authentication, drupal, simplesamlphp

## 简介

A SimpleSAMLphp module adding support for Drupal as the authentication source.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
