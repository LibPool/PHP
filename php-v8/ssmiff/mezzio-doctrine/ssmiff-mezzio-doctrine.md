# ssmiff/mezzio-doctrine

> 标签: dbal, doctrine, laminas, mezzio, migrations, orm

## 简介

Doctrine DBAL, ORM and Migrations for Mezzio with named connections selectable on every console command with --conn.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
