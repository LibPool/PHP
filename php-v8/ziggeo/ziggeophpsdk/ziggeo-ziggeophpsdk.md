# ziggeo/ziggeophpsdk

> 标签: PHP

## 简介

Ziggeo API (https://ziggeo.com) allows you to integrate video recording and playback with only two lines of code in your site, service or app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
