# boonkerz/php-pdf-preflight

> 标签: bleed, cmyk, dpi, fonts, pdf, pdfx, preflight, print, trimbox, web-to-print

## 简介

Preflight for PDF print data: configurable rule engine (page size, boxes, bleed, fonts, colours, image resolution) on top of the native pdf_preflight extension

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
