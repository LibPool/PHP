# marcin-orlowski/text-table

> 标签: ascii, cli, console, php, php8, php81, php82, php83, php84, table, text

## 简介

Fast and flexible PHP library for text tables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
