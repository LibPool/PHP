# kayrunm/package-base

> 标签: PHP

## 简介

Boilerplate for creating new packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://packagist.org/packages/kayrunm%2Fpackage-base
