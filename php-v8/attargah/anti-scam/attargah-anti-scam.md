# attargah/anti-scam

> 标签: anti-scam, attargah, laravel

## 简介

A Filament plugin to protect frontend forms from spam/scam bots with IP blocking and a blacklist management panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
