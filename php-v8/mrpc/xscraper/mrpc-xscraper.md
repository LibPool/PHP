# mrpc/xscraper

> 标签: X.com, graphql, pramnos, replies, scraper, twitter

## 简介

Read x.com posts and their replies from PHP without the official API. Request-frugal: incremental refresh, smart caching, single-flight locking and a shared throttle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
