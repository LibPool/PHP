# smsup/smsup-api-bundle

> 标签: bunle sms, sms, sms api

## 简介

Bundle Symfony2 para el uso de la api de smsup.es para el envio de sms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
