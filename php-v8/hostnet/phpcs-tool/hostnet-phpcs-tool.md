# hostnet/phpcs-tool

> 标签: PHP

## 简介

PHP_CodeSniffer tokenises PHP, JavaScript and CSS files and detects violations of a defined set of coding standards. Hostnet version

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
