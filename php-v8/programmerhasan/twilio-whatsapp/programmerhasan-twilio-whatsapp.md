# programmerhasan/twilio-whatsapp

> 标签: laravel-twilio, laravel-twilio-whatsapp, laravel-twilio-whatsapp-otp, twilio, twilio-whatsapp-otp, whatsapp-otp

## 简介

A Laravel package to send WhatsApp messages and OTPs via Twilio.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
