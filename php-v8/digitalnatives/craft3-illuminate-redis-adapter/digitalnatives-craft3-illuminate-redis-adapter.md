# digitalnatives/craft3-illuminate-redis-adapter

> 标签: Craft, adapter, cache, cms, craftcms, redis

## 简介

Redis Cache based on Illuminate redis for CraftCMS 3|4

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
