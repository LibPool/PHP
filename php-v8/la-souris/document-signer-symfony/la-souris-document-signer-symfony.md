# la-souris/document-signer-symfony

> 标签: PHP

## 简介

Symfony bundle for the document signer SDK: configuration, a driver manager, and verified webhook routes for ValidSign and DocuSign.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
