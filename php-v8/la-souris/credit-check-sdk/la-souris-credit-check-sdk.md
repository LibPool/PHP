# la-souris/credit-check-sdk

> 标签: PHP

## 简介

Provider-agnostic credit-check SDK for PHP: model applicants and their affordability profile as typed value objects, submit a check through any CreditChecker implementation (EDR/EDR, or your own) and read back a normalised decision.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
