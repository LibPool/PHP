# magefine/responsive-admin-lite

> 标签: admin, free, magento2, mobile, responsive, tablet

## 简介

A FREE Magento 2 module that makes your back office responsive for tablets (768px+). Upgrade to Pro for full mobile support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
