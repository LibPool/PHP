# adt/log-mover

> 标签: PHP

## 简介

Moves log tables from the application database into a separate log storage (typically TimescaleDB), keeping the source ids, and prints the target schema derived from Doctrine entities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
