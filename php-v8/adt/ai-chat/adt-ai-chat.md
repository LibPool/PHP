# adt/ai-chat

> 标签: agents, ai, anthropic, chat, claude, doctrine, llm

## 简介

AI chat over your database: an Anthropic Managed Agents conversation engine with safe read-only SQL tools over anonymized views

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
