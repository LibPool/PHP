# adt/request-logger

> 标签: PHP

## 简介

Logs HTTP requests (and optionally responses) of a Nette application into request_log / request_log_body tables, sanitized and written in a single transaction.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
