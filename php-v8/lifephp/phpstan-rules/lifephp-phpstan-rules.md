# lifephp/phpstan-rules

> 标签: PHPStan, php, rules, static analysis

## 简介

Reusable generic PHPStan rules, starting with #[CreateBy] factory-only instantiation enforcement.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
