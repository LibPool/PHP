# vzgcoders/telegramphp

> 标签: API-Client, async, bot, bot-api, openapi, reactphp, telegram

## 简介

An async ReactPHP framework for the Telegram Bot API — built like DiscordPHP, generated from the official Bot API spec.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
