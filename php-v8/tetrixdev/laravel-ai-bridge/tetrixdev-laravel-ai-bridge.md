# tetrixdev/laravel-ai-bridge

> 标签: PHP

## 简介

Laravel package for AI Bridge — unified streaming interface for CLI Bridge, BYOK, and managed AI modes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
