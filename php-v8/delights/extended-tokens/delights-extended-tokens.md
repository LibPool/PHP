# delights/extended-tokens

> 标签: extended, parser, php, tokens

## 简介

Facilitate PHP code highlighting by changing T_STRING tokens to a more accurate representation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
