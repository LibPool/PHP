# php-enspired/at_shared_exceptable

> 标签: PHP

## 简介

Shared implementation for `at/exceptable` and `at/peekaboo`. This package SHOULD NOT be a direct dependency for other projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
