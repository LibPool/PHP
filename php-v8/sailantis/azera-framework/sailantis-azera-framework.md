# sailantis/azera-framework

> 标签: cli, framework, mvc, orm, php, php-framework, query-builder, router

## 简介

A lightweight, fast PHP framework for building modern web and cli applications. Azera combines the best ideas from frameworks like Phalcon, CodeIgniter, Laravel and Twig into a minimal yet powerful toolkit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
