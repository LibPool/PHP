# f-liva/eloquent-merge-select

> 标签: Fliva, eloquent-merge-select, laravel

## 简介

Append selects to the existing ones exposing mergeSelect to the Eloquent Query Builder

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
