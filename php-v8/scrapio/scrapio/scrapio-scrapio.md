# scrapio/scrapio

> 标签: api, scrapio, sdk, web scraping

## 简介

Official PHP SDK for Scrapio — fetch, crawl, search, and extract structured data from any URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
