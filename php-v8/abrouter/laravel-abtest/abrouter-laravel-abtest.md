# abrouter/laravel-abtest

> 标签: PHP

## 简介

AbrLaravelClient :construction_worker_woman: is a PHP client for laravel to run ab-tests via ABRouter.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
