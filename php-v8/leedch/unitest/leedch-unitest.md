# leedch/unitest

> 标签: codemonkey, generate, leedch, phpunit, testing, unit test

## 简介

Generates PHPUnit test classes from regular PHP classes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
