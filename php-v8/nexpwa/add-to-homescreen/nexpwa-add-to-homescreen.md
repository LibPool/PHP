# nexpwa/add-to-homescreen

> 标签: PHP

## 简介

A magento extension to convert your Magento 2 store to a PWA with cool functionalities like Add To Homescreen, Offline browsing, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
