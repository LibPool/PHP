# genj/faq-admin-bundle

> 标签: FAQ, admin, bundle, genj, symfony

## 简介

Symfony Faq Admin bundle - backend version for GenjFaqBundle + SonataAdmin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
