# kriosmane/open-street-map

> 标签: OpenStreetMap, geolocation, laravel, map, open-street-map

## 简介

Package for integrate OpenStreetMap in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
