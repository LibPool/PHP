# kenjdavidson/oauth-yahoofantasysports

> 标签: PHP

## 简介

Provide OAuth2 providers and services for use with Yahoo! Fantasy Sports API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
