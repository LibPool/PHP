# stepapo/visualization

> 标签: component, grid, nette, nextras, table

## 简介

Component for Nette Framework and Nextras ORM, that helps generate visualizations from collections using Google Charts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
