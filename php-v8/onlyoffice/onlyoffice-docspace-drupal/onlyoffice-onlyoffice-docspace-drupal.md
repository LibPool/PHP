# onlyoffice/onlyoffice-docspace-drupal

> 标签: drupal, onlyoffice-docspace

## 简介

This module allows using ONLYOFFICE DocSpace, a room-based environment for effective document collaboration, right within Drupal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
