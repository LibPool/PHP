# onlyoffice/docspace-api-sdk

> 标签: docspace, onlyoffice, sdk

## 简介

A simple PHP SDK for integrating with the ONLYOFFICE DocSpace API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
