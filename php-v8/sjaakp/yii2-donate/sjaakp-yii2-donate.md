# sjaakp/yii2-donate

> 标签: donate, extension, mollie, widget, yii, yii2

## 简介

Donate form for Yii2, uses Mollie.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
