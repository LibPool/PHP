# jeromedia/laravel-github-service

> 标签: github, jeromedia, laravel, release, version

## 简介

A Laravel package that detects the deployed Git tag and compares it with the latest GitHub release.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
