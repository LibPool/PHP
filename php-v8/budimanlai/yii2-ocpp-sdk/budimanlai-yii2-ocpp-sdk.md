# budimanlai/yii2-ocpp-sdk

> 标签: Charging, Electric Vehicle, ev, ocpp, yii2

## 简介

Yii2 extension for OCPP (Open Charge Point Protocol) SDK - supports OCPP 1.6 and 2.0.1

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
