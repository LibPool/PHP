# roave/zf2-for-1

> 标签: ZF1, compatibility, zf2

## 简介

Compatibility layer for ZF1 application allowing usage of ZF2 features

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
