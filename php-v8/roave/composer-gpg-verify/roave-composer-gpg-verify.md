# roave/composer-gpg-verify

> 标签: PHP

## 简介

Composer plugin that verifies GPG signatures of downloaded dependencies, enforcing trusted GIT tags

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
