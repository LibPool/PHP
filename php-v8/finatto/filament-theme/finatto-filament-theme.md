# finatto/filament-theme

> 标签: filament, filament-plugin, finatto, theme

## 简介

Finatto UI — official Filament v5 theme plugin (light-only, black primary, red brand accent).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
