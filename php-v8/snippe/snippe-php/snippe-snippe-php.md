# snippe/snippe-php

> 标签: airtel, card-payments, mobile-money, mpesa, payment-gateway, payments, qr-payments, snippe, tanzania

## 简介

Official PHP SDK for Snippe Payment API - Simple mobile money, card & QR payments

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
