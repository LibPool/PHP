# kassner/magento-behat-extension

> 标签: BDD, Behat, magento

## 简介

MageBehat - framework to run Behat/Mink for Magento extension integration tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
