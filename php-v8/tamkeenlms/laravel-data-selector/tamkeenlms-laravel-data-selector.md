# tamkeenlms/laravel-data-selector

> 标签: database, laravel

## 简介

An extra layer on top of queries to help with selecting and retrieving data from the database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
