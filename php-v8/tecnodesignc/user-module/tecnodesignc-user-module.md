# tecnodesignc/user-module

> 标签: Authentication, authorisation, tecnodesign, user

## 简介

User module for EncoreCMS 2. Handles the authentication and authorisation as well as the user management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
