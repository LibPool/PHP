# zunyunkeji/think-addons

> 标签: PHP

## 简介

基于 thinkphp6 / thinkphp8 开发的插件管理扩展，支持多应用模型

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
