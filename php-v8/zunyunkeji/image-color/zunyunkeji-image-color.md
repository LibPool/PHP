# zunyunkeji/image-color

> 标签: color, image, 图片主色, 图片取色

## 简介

获取图片主要组成颜色并按颜色进行分组。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
