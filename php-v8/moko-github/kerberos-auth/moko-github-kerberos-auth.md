# moko-github/kerberos-auth

> 标签: Authentication, SSO, kerberos, laravel, remote-user, single-sign-on

## 简介

Kerberos SSO authentication package for Laravel (REMOTE_USER, demande d'acces, mode simulation)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
