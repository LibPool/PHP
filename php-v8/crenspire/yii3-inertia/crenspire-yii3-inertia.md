# crenspire/yii3-inertia

> 标签: SPA, adapter, inertia, inertiajs, psr-15, psr-7, vite, yii3

## 简介

Inertia.js server-side adapter for Yii3 and any PSR-15 application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
