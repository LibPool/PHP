# zentiq-labs/laravel-fast-pdf

> 标签: blade, chromium, fast-pdf, laravel, pdf, pdf-generation

## 简介

Official Laravel bridge for zentiq-labs/fast-pdf — Blade view rendering, Facade access, and Laravel HTTP response helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
