# zentiq-labs/fast-pdf

> 标签: chromium, headless, html-to-pdf, pdf, pdf-generation, php

## 简介

Framework-agnostic, high-performance PHP-to-PDF rendering via direct headless Chromium IPC pipes. Works in Core PHP, Laravel, CodeIgniter 4, Symfony, and WordPress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
