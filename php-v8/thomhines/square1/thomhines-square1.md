# thomhines/square1

> 标签: carousel, css, frontend, javascript, jquery, slider, slideshow

## 简介

Square1 jQuery slider (JS/CSS image/content slider with responsive srcset support).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
