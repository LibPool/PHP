# pack-php/pack

> 标签: PHP

## 简介

A Laravel Artisan command to search, preview, and install PHP packages from Packagist.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://packagist.org/packages/pack-php%2Fpack
- 源码仓库：https://github.com/pack-php/pack.git
- Packagist 页面：https://packagist.org/packages/pack-php%2Fpack

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require pack-php/pack`
- Packagist 仓库：https://repo.packagist.org/p2/pack-php/pack.json
