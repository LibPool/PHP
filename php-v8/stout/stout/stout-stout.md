# stout/stout

> 标签: framework, php-di, roadrunner, slim, stout

## 简介

Lightweight opinionated PHP framework built on Slim with strict types, PHP-DI, and RoadRunner.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
