# molayli/laravel-cloudflare-real-ip

> 标签: cloudflare, laravel, real ip address

## 简介

Get the real ip for laravel applications behind cloudflare's reverse proxy

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
