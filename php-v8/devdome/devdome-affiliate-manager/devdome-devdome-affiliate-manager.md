# devdome/devdome-affiliate-manager

> 标签: affiliate-links, link-management, wordpress, wordpress-plugin

## 简介

Free Amazon affiliate manager for WordPress: auto-tag Amazon Associates links for 22 marketplaces, keyword auto-linking, geo store routing, dead and out-of-stock link monitoring, click tracking. Free alternative to AAWP, Lasso and AmaLinks Pro.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
