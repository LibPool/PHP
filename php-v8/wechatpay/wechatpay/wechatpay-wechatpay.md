# wechatpay/wechatpay

> 标签: AES-GCM, aes-ecb, openapi-chainable, rsa-oaep, wechatpay, xml-builder, xml-parser

## 简介

[A]Sync Chainable WeChatPay v2&v3's OpenAPI SDK for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
