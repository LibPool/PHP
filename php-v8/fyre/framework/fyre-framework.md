# fyre/framework

> 标签: PSR-11, cache, console, email, framework, fyre, fyrephp, http, mvc, orm, php, psr, psr-15, psr-17, psr-7, queue, router

## 简介

Modular PHP framework with PSR-compliant HTTP handling, routing, ORM, templating, caching, queues, and CLI tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
