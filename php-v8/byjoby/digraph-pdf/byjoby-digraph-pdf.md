# byjoby/digraph-pdf

> 标签: PHP

## 简介

Digraph module to provide PDF versions of pages and content. Also designed to allow custom PDF generation using mPDF.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
