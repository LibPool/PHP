# byjoby/html-object-strings

> 标签: PHP

## 简介

A comprehensive PHP library for programmatically building HTML. Covers essentially all of HTML5, plus SVG and MathML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
