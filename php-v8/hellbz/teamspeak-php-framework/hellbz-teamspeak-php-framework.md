# hellbz/teamspeak-php-framework

> 标签: teamspeak3

## 简介

Clone of TS3 PHP Framework 1.1.34 providing the library as composer project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
