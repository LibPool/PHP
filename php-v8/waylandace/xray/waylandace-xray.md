# waylandace/xray

> 标签: AWS X-Ray, X-Ray, apm, aws, tracing

## 简介

A basic PHP instrumentation library for AWS X-Ray

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
