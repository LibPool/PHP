# ameax/laravel-glitchtip

> 标签: error-tracking, glitchtip, laravel, livewire, multitenancy, privacy, sentry

## 简介

Error tracking for Laravel with GlitchTip (or any Sentry compatible server): privacy mode, release detection for git and Deployer, and context for users, tenants and Livewire

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
