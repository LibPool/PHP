# railroad/mailora

> 标签: api, email, laravel, mail, wrapper

## 简介

Wrapper for Laravel's email functionality that adds HTTP API and front-end-dev-friendly view-creation and use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
