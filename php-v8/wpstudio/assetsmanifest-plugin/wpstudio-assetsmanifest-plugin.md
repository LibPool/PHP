# wpstudio/assetsmanifest-plugin

> 标签: assets, hash, json, manifest, webpack

## 简介

Extract full paths to assets files from manifest.json

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
