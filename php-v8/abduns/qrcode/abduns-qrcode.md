# abduns/qrcode

> 标签: barcode, iso-18004, png, qr, qr-code, qrcode, svg

## 简介

A from-scratch, framework-agnostic QR Code generator for PHP 8.2+ with zero required runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
