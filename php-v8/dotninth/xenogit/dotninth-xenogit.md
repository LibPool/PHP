# dotninth/xenogit

> 标签: ChatGpt, GPT-3, Gemini, claude, cli, commit, console, git, gitprompt, gpt, gpt-4, gpt3, message, perplexity

## 简介

Your CLI buddy for instant Git commit messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
