# mardy-git/hmac

> 标签: Authentication, guzzle-plugin, hash, hmac, pbkdf2

## 简介

A keyed-Hash Message Authentication Code (HMAC). Used for application to application authentication.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
