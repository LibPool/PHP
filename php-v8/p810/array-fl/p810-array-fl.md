# p810/array-fl

> 标签: PHP

## 简介

Provides a consolidated polyfill for array_key_first(), array_key_last(), and the unapproved functions array_value_first() and array_value_last().

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
