# natxet/operacore

> 标签: frameworks, php, symfony

## 简介

The core of the Opera PHP Framework, based on Symfony components. MVC + i18n everywhere

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
