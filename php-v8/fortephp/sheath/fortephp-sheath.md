# fortephp/sheath

> 标签: blade linter, laravel

## 简介

A Laravel-first Blade and HTML linter with rules for accessibility, security, SEO, performance, and template best practices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
