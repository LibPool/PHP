# collizo4sky/persist-admin-notices-dismissal

> 标签: PHP

## 简介

Simple library to persist dismissal of admin notices across pages in WordPress dashboard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
