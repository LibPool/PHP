# codeatlas/exporter-json

> 标签: codeatlas, exporter, json, schema, visualization

## 简介

CodeAtlas JSON exporter — canonical JSON output conforming to the CodeAtlas schema.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
