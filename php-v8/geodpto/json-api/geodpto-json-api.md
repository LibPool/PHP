# geodpto/json-api

> 标签: JSON-API, api, json, jsonapi, jsonapi.org

## 简介

Framework agnostic JSON API (jsonapi.org) implementation. This is a maintained fork of neomerx/json-api.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
