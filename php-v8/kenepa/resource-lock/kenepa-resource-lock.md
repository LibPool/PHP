# kenepa/resource-lock

> 标签: Kenepa, laravel, resource-lock

## 简介

Filament Resource Lock is a Filament plugin that adds resource locking functionality to your site.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
