# perfilov/php-dto-packer

> 标签: array, conversion, data-transfer-object, decode, deserializer, dto, encode, fast, hydrator, json, lightweight, mapper, mapping, object-conversion, object-mapper, packer, performance, php, serializer, strongly-typed, tree, type-safe, value-object

## 简介

Blazing-fast PHP library to convert arrays, JSON & objects into strongly typed DTOs (and back)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
