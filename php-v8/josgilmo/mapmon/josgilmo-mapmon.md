# josgilmo/mapmon

> 标签: mongo, mongodb, object document mapper, odm, php

## 简介

Yet another MongoDB ODM for PHP. Nothing unnecessary, with easy joins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
