# sparkworldke/kopokopo-laravel-support

> 标签: kopokopo, laravel, mpesa, patrickmwangi017

## 简介

A simple package for developers to consume Kopokopo Mpesa API in Laravel 9, 10, 11

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
