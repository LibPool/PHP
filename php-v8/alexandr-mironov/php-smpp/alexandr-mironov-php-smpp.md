# alexandr-mironov/php-smpp

> 标签: gsm, smpp, sms, texting

## 简介

PHP SMPP client lib, fork of onlinecity/php-smpp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
