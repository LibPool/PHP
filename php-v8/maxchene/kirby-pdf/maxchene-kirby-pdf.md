# maxchene/kirby-pdf

> 标签: TCPDF, dompdf, kirby, kirby3, kirby3-cms, kirby3-plugin, mpdf, pdf, wkhtmltopdf

## 简介

Kirby plugin that a PDF engine to convert HTML to PDF

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
