# pdf-x/secure-runner

> 标签: bubblewrap, bwrap, document-processing, linux, pdf, pdfcpu, php, sandbox, security

## 简介

Secure sandboxed document processing for PHP/Linux using Bubblewrap.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
