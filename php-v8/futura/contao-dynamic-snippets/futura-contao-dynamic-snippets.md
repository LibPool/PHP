# futura/contao-dynamic-snippets

> 标签: contao, contao5, content-element, snippet, template

## 简介

HTML-Snippets mit Platzhaltern als wiederverwendbare Inhaltselemente für Contao 5 – ohne eigene Modulprogrammierung

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
