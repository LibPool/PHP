# tumutech/laravel-qr-code

> 标签: Webp, barcode, blade, branded, inertia, laravel, laravel-package, logo, png, qr, qr-code, qrcode, qrcode-generator, scan-safe, svg, vCard, wifi

## 简介

Generate branded, scan-safe QR codes in Laravel with center logos, style templates, Blade, and Inertia data URIs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
