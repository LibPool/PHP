# drupal-eca-recipe/eca_lib_0015

> 标签: PHP

## 简介

Shows a message on the user profile edit form, limited to accounts holding one of three selected roles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
