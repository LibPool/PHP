# iscosta77/paginator

> 标签: links, pagina, paginacao, pagination, paginator, php

## 简介

Paginator — paginacao generica para PHP sem framework: fatia qualquer array/colecao, calcula paginas e renderiza os links de navegacao (primeira/anterior/1..N/proxima/ultima) em HTML ou JSON. Mensagens pt/en/es. Zero dependencias.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
