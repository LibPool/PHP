# iscosta77/gallery

> 标签: galeria, gallery, grid, imagens, lightbox, php, slider

## 简介

Gallery — galeria de imagens a partir de uma pasta, sem framework: lista as fotos de um diretorio (com thumbs opcionais), monta a grade responsiva e o slider/lightbox em JS puro. Zero dependencias (so PHP).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
