# iscosta77/auth

> 标签: autenticacao, auth, login, php, registro, senha

## 简介

Auth — login, registro e recuperacao de senha para PHP sem framework: password_hash nativo, sessao segura, mensagens pt/en/es. Integra com iscos/voodoo-2026 (banco) e iscosta77/validators.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
