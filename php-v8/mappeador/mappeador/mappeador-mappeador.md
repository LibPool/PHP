# mappeador/mappeador

> 标签: mappeador, orm

## 简介

Mappeador is a simple, flexible and easy way to perform php crud with MYSQL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
