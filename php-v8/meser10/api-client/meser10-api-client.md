# meser10/api-client

> 标签: Israel, email, hebrew, mailmonster, meser10, otp, sms, transactional

## 简介

PHP client for the Meser 10 JSON API: transactional SMS, transactional email and contacts. No dependencies.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
