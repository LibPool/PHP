# pkeidel/dbtolaravel

> 标签: db2laravel, dbtolaravel, laravel5, laravel6

## 简介

Reads a database and creates the migrations, models, controllers and blades for the tables

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
