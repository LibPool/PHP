# devriyad/polypay

> 标签: PHP

## 简介

Unified payment gateway interface for Laravel/PHP with pluggable drivers for bKash, SSLCommerz, Stripe, PayPal, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
