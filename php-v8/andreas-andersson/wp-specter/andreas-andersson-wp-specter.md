# andreas-andersson/wp-specter

> 标签: cli, dead-code, hooks, plugin, static-analysis, theme, unused-code, wordpress

## 简介

CLI tool to find unused code in WordPress projects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
