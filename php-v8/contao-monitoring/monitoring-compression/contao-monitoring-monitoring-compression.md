# contao-monitoring/monitoring-compression

> 标签: compress, compression, contao, monitoring, test result

## 简介

Provides components to compress the test results for the Contao Monitoring system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
