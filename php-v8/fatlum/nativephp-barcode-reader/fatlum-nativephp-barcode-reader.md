# fatlum/nativephp-barcode-reader

> 标签: barcode, mlkit, nativephp, qr, qrcode, scanner, vision

## 简介

Free QR code and barcode reading from image files for NativePHP Mobile v4: Apple Vision on iOS, ML Kit on Android. Works where PHP QR libraries cannot, because the PHP runtime on the phone has no GD or Imagick.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
