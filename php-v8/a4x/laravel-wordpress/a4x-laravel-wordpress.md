# a4x/laravel-wordpress

> 标签: laravel, wordpress

## 简介

A one-class package that locally caches your Wordpress posts as a Laravel collection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
