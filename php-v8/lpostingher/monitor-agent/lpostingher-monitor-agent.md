# lpostingher/monitor-agent

> 标签: exceptions, laravel, logs, monitoring, queues

## 简介

Reports exceptions, logs and queued jobs from Laravel apps to a self-hosted Monitor panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
