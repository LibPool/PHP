# stann/stream

> 标签: PHP

## 简介

Pipe-native stream processing for PHP 8.5+ — lazy, curried, zero-dependency collection functions designed for the |> pipe operator.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
