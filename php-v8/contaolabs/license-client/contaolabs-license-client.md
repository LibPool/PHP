# contaolabs/license-client

> 标签: PHP

## 简介

Lizenzprüfung für die Erweiterungen von contaolabs.de (Contao 4.13 und 5.x). Prüft einmal täglich im Hintergrund und zeigt bei fehlender Lizenz nur einen Hinweis im Backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
