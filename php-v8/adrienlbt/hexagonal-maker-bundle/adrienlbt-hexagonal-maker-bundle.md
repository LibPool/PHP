# adrienlbt/hexagonal-maker-bundle

> 标签: PHP

## 简介

Hexagonal Maker bundle add commands to Symfony Maker bundle to help you to create files for hexagonal architecture.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
