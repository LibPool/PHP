# cam5/domoarigato

> 标签: HTML5, attributes, builder, dom, elements, escaping, html, validation, xss

## 简介

Build HTML in PHP with elements and attributes as objects: escaped by default, every HTML5 element and attribute, and optional content validation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
