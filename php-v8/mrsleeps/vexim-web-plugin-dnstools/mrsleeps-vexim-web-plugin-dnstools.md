# mrsleeps/vexim-web-plugin-dnstools

> 标签: cloudflare, dns, filament, hosting, laravel

## 简介

DNS tools plugin for VExim Web UI dns plugins.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
