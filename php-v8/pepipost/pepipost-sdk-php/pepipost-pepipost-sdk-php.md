# pepipost/pepipost-sdk-php

> 标签: api, pepipost, sdk

## 简介

Pepipost API is used to send the mail to the receipients specified in the docs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
