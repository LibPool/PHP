# identifyorg/sdk-php

> 标签: bvn, identifyorg, identity-verification, kyc, livekit, nin

## 简介

IdentifyOrg server-side SDK for PHP — identity verification, prepaid billing, and realtime call/chat token issuance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
