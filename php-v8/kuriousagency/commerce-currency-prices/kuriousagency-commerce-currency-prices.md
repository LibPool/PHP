# kuriousagency/commerce-currency-prices

> 标签: Craft, cms, commerce, craft-commerce, craft-plugin, craftcms, currency prices, multi-currency, payment currencies

## 简介

Sell from one Craft Commerce store in several currencies, at prices you set for each currency rather than prices converted by an exchange rate.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
