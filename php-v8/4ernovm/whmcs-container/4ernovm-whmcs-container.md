# 4ernovm/whmcs-container

> 标签: PHP

## 简介

Apparently WHMCS has it's own DI container but we'll keep our own container aside because we don't want to mess things up

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
