# enadstack/laravel-api-contracts

> 标签: JSON-API, api, commerce, contracts, error-envelope, laravel, microservices

## 简介

Shared versioned commerce contracts for event schemas, API conventions, money DTOs, reference formats, error envelopes, pagination, and integration standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
