# pagadevcomm/paga-checkout-for-woocommerce

> 标签: Paga, custom-payment-gateway, plugin, woocommerce, wordpress

## 简介

The one plugin for making online payments which is embedded to your woocommerce site. PagaCheckout payment geteway provides an easy-to-integrate payment collection tool for any online merchant.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
