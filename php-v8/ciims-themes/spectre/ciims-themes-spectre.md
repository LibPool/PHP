# ciims-themes/spectre

> 标签: CiiMS, spectre, theme

## 简介

Spectre is a lightweight theme for CiiMS that utilizes purecss.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
