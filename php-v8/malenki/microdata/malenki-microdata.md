# malenki/microdata

> 标签: check, dom, html, json, microdata, semantic, seo, web

## 简介

Get microdata from web page and check each type found with schema.org!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
