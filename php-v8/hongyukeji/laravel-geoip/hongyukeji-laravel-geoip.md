# hongyukeji/laravel-geoip

> 标签: IP API, geoip, geolocation, infoDB, laravel, laravel 5, location, maxmind

## 简介

Support for multiple GeoIP services.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
