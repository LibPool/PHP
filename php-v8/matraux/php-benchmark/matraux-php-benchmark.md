# matraux/php-benchmark

> 标签: MATRAUX, PHP Benchmark, php-benchmark

## 简介

Benchmarking tool for PHP 8.4+ to measure code performance with accurate time and memory profiling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
