# matraux/filesystem

> 标签: MATRAUX, file system, filesystem

## 简介

A PHP 8.4+ library for object-oriented file and folder manipulation with support for PSR-7 and Nette\Http\FileUpload.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
