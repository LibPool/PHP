# matraux/xml-orm

> 标签: MATRAUX, XML ORM, xml-orm

## 简介

A PHP 8.4+ library for converting XML data to typed entities and back, with support for lazy-loading collections and XML namespaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
