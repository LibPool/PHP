# matraux/json-orm

> 标签: JSON ORM, MATRAUX, json-orm

## 简介

A PHP 8.5+ library for converting JSON data to typed entities and back, with support for lazy-loading collections.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
