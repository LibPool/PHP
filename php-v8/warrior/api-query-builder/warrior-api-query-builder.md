# warrior/api-query-builder

> 标签: api, clean-code, eloquent, filter, laravel, query-builder, rest

## 简介

Lightweight, fluent, and powerful API query builder for Laravel Eloquent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
