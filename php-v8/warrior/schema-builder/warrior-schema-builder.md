# warrior/schema-builder

> 标签: clean-code, crud, fluent, form-schema, laravel, schema-builder, solid, table-schema

## 简介

Declarative and fluent schema builder for dynamic tables, forms, and CRUDs in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
