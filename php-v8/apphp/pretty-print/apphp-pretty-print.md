# apphp/pretty-print

> 标签: Pretty print, array, array-formatting, data-formatting, debug, formatting, logging, matrix, matrix-format, php, pprint, pretty-print, print, tensor, tensor-formatting

## 简介

Callable pretty-printer for PHP arrays with Python-like formatting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
