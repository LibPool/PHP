# amazscript/laravel-einvoicing

> 标签: dgfip, e-invoicing, e-reporting, factur-x, facture-electronique, iopole, laravel

## 简介

French e-invoicing for Laravel: receive and send invoices through an accredited platform (Plateforme Agréée).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
