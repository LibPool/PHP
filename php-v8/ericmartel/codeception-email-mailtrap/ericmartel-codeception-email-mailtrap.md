# ericmartel/codeception-email-mailtrap

> 标签: PHP

## 简介

Provides test helpers for Codeception when testing email functionality with Mailtrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
