# teamtnt/tntsearch

> 标签: Fuzzy search, bm25, fulltext, geosearch, search, stemming, teamtnt, text classification, tntsearch

## 简介

A fully featured full text search engine written in PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
