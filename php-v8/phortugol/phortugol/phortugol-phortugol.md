# phortugol/phortugol

> 标签: ast, education, interpreter, parser, php, portugol, visualg

## 简介

A Portugol interpreter written in PHP — the educational pseudocode language used in VisuAlg

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
