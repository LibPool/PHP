# eugenecooper/world-locations

> 标签: all, cities, countries, global, list, provinces, regions, states

## 简介

Allows to retrieve all world's countries, cities and regions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
