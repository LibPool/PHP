# kch/smsapi-bundle

> 标签: bundle, mms, sms, vms

## 简介

Symfony 2 Bundle for SMSApi PHP Client library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
