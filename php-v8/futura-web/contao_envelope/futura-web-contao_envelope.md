# futura-web/contao_envelope

> 标签: PHP

## 简介

Simple HTML-wrapper for Contao CMS articles. Similar to slider || accordeon wrappers, but for static content.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
