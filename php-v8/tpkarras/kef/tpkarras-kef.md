# tpkarras/kef

> 标签: cryptography, decryption, encryption, format, openssl

## 简介

An encryption format designed for storing encrypted data within a range of a specific number of bytes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
