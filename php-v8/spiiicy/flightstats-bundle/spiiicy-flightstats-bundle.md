# spiiicy/flightstats-bundle

> 标签: api, flight, flightstats, rest

## 简介

This Bundle provides a wrapper for the FlightStats API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
