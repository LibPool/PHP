# pastuhov/php-file-stream

> 标签: Sitemap, export.yml, stream, yml

## 简介

Big file creation helper. May be used for sitemap.xml or YML files creation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
