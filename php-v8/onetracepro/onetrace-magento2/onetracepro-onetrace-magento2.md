# onetracepro/onetrace-magento2

> 标签: CDP, Marketing Automation, abandoned cart, adobe commerce, customer data platform, ecommerce, magento, magento2, onetrace, recommendations

## 简介

Magento 2 / Adobe Commerce module for the OneTrace.pro customer data platform: server-side orders, customers and newsletter consents, the website tracker, product catalog sync, recommendation widgets and Web Push.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
