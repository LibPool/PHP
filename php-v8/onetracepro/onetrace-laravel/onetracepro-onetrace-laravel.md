# onetracepro/onetrace-laravel

> 标签: CDP, Live Chat, Marketing Automation, analytics, customer data platform, events, laravel, loyalty, onetrace, promo codes, recommendations, tracking, transactional messages

## 简介

Laravel integration for the OneTrace.pro customer data platform: events after the response or via queues, tracker Blade directive, automatic identify, Eloquent product sync and a test fake.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
