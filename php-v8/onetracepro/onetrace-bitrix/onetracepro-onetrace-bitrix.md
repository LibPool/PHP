# onetracepro/onetrace-bitrix

> 标签: 1C-Bitrix, CDP, Marketing Automation, abandoned cart, bitrix, customer data platform, ecommerce, onetrace, recommendations

## 简介

1C-Bitrix module for the OneTrace.pro customer data platform: server-side orders, customers and consents, the website tracker, product catalog sync, recommendation widgets and Web Push.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
