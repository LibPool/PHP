# tschope/flightlogger-php

> 标签: api, aviation, flight, flightlogger, graphql, saloon

## 简介

A PHP SDK for integrating with FlightLogger GraphQL API using Saloon

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
