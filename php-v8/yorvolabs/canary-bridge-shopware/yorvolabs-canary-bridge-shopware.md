# yorvolabs/canary-bridge-shopware

> 标签: cache, deployment, devops, diagnostics, health, monitoring, shopware, shopware-plugin

## 简介

Shopware 6.6+ plugin bridge for yorvolabs/canary — secure health, cache, and deployment endpoints.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
