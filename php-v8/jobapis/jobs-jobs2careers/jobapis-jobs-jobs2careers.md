# jobapis/jobs-jobs2careers

> 标签: api client, jobs, jobs2careers, object

## 简介

Making it simple to integrate your application with the Jobs2Careers API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
