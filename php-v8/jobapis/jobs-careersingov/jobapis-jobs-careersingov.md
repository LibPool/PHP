# jobapis/jobs-careersingov

> 标签: api client, careersingov, jobs, php

## 简介

Making it simple to integrate your application with the Careers in Government RSS Feed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
