# qianxiong/hyperf-flysystem-obs

> 标签: Flysystem, OBS, filesystem, huawei, huaweicloud, hyperf, swoole

## 简介

Huawei Cloud OBS adapter for the official hyperf/filesystem component (Flysystem v3).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
