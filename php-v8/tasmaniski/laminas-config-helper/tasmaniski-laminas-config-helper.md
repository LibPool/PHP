# tasmaniski/laminas-config-helper

> 标签: Zend Framework, config, helper, plugin

## 简介

Provide Controller plugin and View helper for reading a config.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
