# multiotp/smsgateway

> 标签: android, class, flat-file, gateway, php, smartphone, sms, sms-gateway, smsgateway

## 简介

Flat-file based SMS gateway PHP class using an open source Android app

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
