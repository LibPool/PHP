# smartis/smartcallback-api-php-client

> 标签: PHP

## 简介

Basic lib for work with SmartCallBack service API - omnichannel system for communication business and people

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
