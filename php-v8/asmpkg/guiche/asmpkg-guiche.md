# asmpkg/guiche

> 标签: agents, ai, conversational-ai, php, plugins, tools

## 简介

Core PHP para assistentes conversacionais orientados a Tools, Plugins, estado, segurança, persistência e runtime de conversação.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
