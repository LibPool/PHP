# atendwa/laravel-reporting

> 标签: csv, filament, laravel, pdf, reporting, reports

## 简介

Queue-based reporting system for Laravel with Filament UI integration: generators, schedules, history, and CSV/PDF export.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
