# irnoti/php-sms-panel-api

> 标签: API-Client, iran, irnoti, otp, sdk, sms, sms-api

## 简介

Official framework-agnostic PHP SDK for the irnoti platform API (SMS, pattern, SOS, phonebook, services, verify, bots, VoIP, webhooks).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
