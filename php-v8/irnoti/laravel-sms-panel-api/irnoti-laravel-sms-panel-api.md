# irnoti/laravel-sms-panel-api

> 标签: API-Client, bulk-sms, irnoti, laravel, sdk, sms, sms-api, sms-gateway, sms-panel

## 简介

Official Laravel SDK for the irnoti platform API — SMS (single, bulk, pattern, scheduled, gradual, SOS), provider services, phonebook, link tracker, number banks, verify, bots and VoIP, with a typed fluent client and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
