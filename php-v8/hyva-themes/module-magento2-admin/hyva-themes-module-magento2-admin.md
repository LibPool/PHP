# hyva-themes/module-magento2-admin

> 标签: PHP

## 简介

This module aims to make creating grids and forms in the Magento 2 adminhtml area for developers joyful and fast

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
