# mhvefgh/microlite

> 标签: api, fast, lightweight, microframework, minimal, php, psr-15

## 简介

A modern, lightweight, PSR-15 compliant PHP microframework with zero bloat.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
