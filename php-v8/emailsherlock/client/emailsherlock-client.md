# emailsherlock/client

> 标签: MX, disposable, email, email-validation, email-verification, emailsherlock, smtp

## 简介

Official PHP client for the EmailSherlock email-verification API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
