# alvarodelera/pest-wp-plugin

> 标签: pest, phpunit, plugin, sqlite, testing, wordpress

## 简介

Pest plugin for WordPress testing with SQLite support and zero-config setup

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
