# usaikoo/littlepdf-php

> 标签: document, littlepdf, markdown, minimal, pdf, pdf-creation, pdf-generation, zero-dependencies

## 简介

Minimal PDF creation library for PHP. Less than 400 lines of code, zero dependencies, makes real PDFs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
