# mdy/costumcontentpreview

> 标签: backend, content, crop, extension, typo3

## 简介

Adds a better preview for the content elements: html, table and bullets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
