# fgtclb/t3oodle

> 标签: doodle, poll, schedule, typo3, voting

## 简介

Simple poll extension for TYPO3 CMS. t3oodle allows your frontend users to create new polls and vote for existing ones.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
