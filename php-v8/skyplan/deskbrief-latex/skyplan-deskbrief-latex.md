# skyplan/deskbrief-latex

> 标签: PHP

## 简介

A LaTeX rendering engine for Deskbrief.Latex minimum version is XeLaTeX or Advanced version is a mandate requirement for this package to work properly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
