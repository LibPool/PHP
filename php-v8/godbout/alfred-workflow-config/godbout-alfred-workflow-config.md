# godbout/alfred-workflow-config

> 标签: alfred, alfred-workflow, config, php, workflow

## 简介

Manage settings easily for your Alfred 3 or 4 Workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
