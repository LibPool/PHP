# godbout/alfred-workflow-scriptfilter

> 标签: alfred, alfred-workflow, php, results, scriptfilter, workflow

## 简介

Generate Alfred 3 or 4 Workflow Results in PHP with a laugh.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
