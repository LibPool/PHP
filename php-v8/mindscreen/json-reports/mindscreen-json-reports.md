# mindscreen/json-reports

> 标签: TYPO3 CMS, monitoring, reports

## 简介

Outputs TYPO3 reports as JSON for processing in monitoring or alerting systems

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
