# countriesdb/validator

> 标签: API-Client, address-validation, backend, composer, countries, countriesdb, country-codes, country-validation, geography, iso-3166, iso-3166-1, iso-3166-2, laravel, location-validation, packagist, php, province-codes, rest-api, server-side, state-codes, subdivision-codes, subdivision-validation, subdivisions, validation

## 简介

PHP validation client for CountriesDB with Laravel validation rules and a standalone Http-based validator for country and subdivision code checks against the CountriesDB backend API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
