# sodacards/sdk

> 标签: api, game-topup, gift-cards, payments, sdk, sodacards

## 简介

The official PHP SDK for the SODACARDS Developer API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://developer.sodacards.com
- 源码仓库：https://github.com/SODACARDS/sodacards-php.git
- Packagist 页面：https://packagist.org/packages/sodacards%2Fsdk

- Composer 安装：`composer require sodacards/sdk`
