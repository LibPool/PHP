# melodicdev/framework

> 标签: cache, console, cqrs, dependency-injection, events, framework, jwt, logging, middleware, mvc, php, routing, session, validation

## 简介

A modern PHP 8.2+ framework with CQRS, JWT authentication, and middleware pipeline

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
