# ssbehat/behat-quicksetup

> 标签: BDD, framework, silverstripe, web

## 简介

Set up SilverStripe framework extension for Behat quickly

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
