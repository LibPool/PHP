# pressgang-wp/bosun

> 标签: PHP

## 简介

WP-CLI package that composes AI agent guidelines and skills for PressGang WordPress themes — the bosun pipes the conventions to the crew.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
