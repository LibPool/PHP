# alejandro-fiore/zfr-cors

> 标签: Zend Framework, cors, cross origin sharing resource, rest, zf2

## 简介

Laminas module that let you deal with CORS requests

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
