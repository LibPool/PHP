# recodex-id/rewire

> 标签: laravel, livewire, starter-kit

## 简介

A reusable Laravel starter kit for internal and client projects -- authentication, roles, a blog, and a back office ready to go.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
