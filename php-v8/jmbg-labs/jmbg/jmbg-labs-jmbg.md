# jmbg-labs/jmbg

> 标签: citizen-number, identifier, jmbg, national-id, serbia, validation, validator

## 简介

Validate Serbian unique master citizen number (JMBG - Jedinstveni Matični Broj Građana)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
