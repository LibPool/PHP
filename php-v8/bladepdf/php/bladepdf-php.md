# bladepdf/php

> 标签: api, bladepdf, chromium, html to pdf, pdf, php sdk

## 简介

Framework-agnostic PHP SDK for the BladePDF managed Chromium API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
