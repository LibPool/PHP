# bladepdf/laravel

> 标签: api, blade, blade templates, bladepdf, chromium, html to pdf, invoice, laravel, pdf, pdf generation, puppeteer, tailwind css

## 简介

Generate production-ready PDFs from Laravel Blade views with managed Chromium, automatic assets, and a fluent API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
