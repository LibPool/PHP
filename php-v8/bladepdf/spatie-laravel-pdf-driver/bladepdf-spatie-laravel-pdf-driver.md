# bladepdf/spatie-laravel-pdf-driver

> 标签: bladepdf, chromium, laravel, laravel-pdf, pdf, pdf driver, spatie

## 简介

Use BladePDF as a managed Chromium driver for Spatie Laravel PDF.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
