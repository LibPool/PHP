# ingestao-vetorial/sdk-php

> 标签: PHP

## 简介

Standalone PHP 8.2 SDK for the Ingestão Vetorial API — Guzzle-based, Laravel-compatible.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
