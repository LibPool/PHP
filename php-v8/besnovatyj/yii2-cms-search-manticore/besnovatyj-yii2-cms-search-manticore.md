# besnovatyj/yii2-cms-search-manticore

> 标签: cms, fulltext, lemmatization, manticore, search, sphinx, yii2

## 简介

Ядро сквозного поиска на Manticore Search для Yii2 CMS: настоящая лемматизация русского, поиск с опечатками и с ошибочной раскладкой клавиатуры, подсказки «возможно, вы имели в виду». Подключается к фасаду besnovatyj/yii2-cms-search, требует запущенный демон searchd.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
