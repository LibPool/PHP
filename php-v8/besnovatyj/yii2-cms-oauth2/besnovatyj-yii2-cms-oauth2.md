# besnovatyj/yii2-cms-oauth2

> 标签: api, cms, oauth2, rest, yii2

## 简介

OAuth2-сервер (интеграция league/oauth2-server) для REST-слоя Yii2 CMS: выдача и валидация Bearer-токенов.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
