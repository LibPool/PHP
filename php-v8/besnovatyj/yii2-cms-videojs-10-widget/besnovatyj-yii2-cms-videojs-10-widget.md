# besnovatyj/yii2-cms-videojs-10-widget

> 标签: extension, player, video, videojs, web-components, yii2

## 简介

Video.js v10 (Web Components) widget for Yii2 CMS. Supports local MP4 via VideoJS v10 and iframe embed for YouTube, Rutube, VK, Vimeo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
