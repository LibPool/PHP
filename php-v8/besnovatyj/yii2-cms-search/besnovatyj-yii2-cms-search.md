# besnovatyj/yii2-cms-search

> 标签: cms, facade, fulltext, search, yii2

## 简介

Фасад сквозного поиска по сайту для Yii2 CMS: собирает контент модулей через контракт SearchableProvider в единый каталог документов и рисует выдачу. Движок поиска (TNTSearch, Manticore, ...) подключается отдельным пакетом-ядром и переключается в настройках.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
