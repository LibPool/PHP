# besnovatyj/yii2-cms-modman

> 标签: cms, modman, module-manager, modules, yii2

## 简介

Система управления модулями Yii2 CMS (compile-not-patch): discovery, реестр состояния, компиляция производных конфигов, lifecycle установки/удаления модулей.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
