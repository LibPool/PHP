# besnovatyj/yii2-cms-blocks

> 标签: blocks, cms, theme, widget-areas, yii2

## 简介

Модуль блоков Yii2 CMS: управляемое из админки содержимое мест, объявленных темой

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
