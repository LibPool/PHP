# besnovatyj/yii2-cms-yandex-smart-captcha

> 标签: captcha, cms, smartcaptcha, validator, widget, yandex, yii2

## 简介

Yandex SmartCaptcha (расширенный метод) для Yii2 CMS: виджет, серверный верификатор и валидатор

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
