# besnovatyj/debug-panel-modules

> 标签: cms, debug, yii2

## 简介

Yii2 debug-панель со списком зарегистрированных модулей приложения и их конфигом (dev-only).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
