# besnovatyj/yii2-cms-admin-panel

> 标签: admin, cms, command-palette, navigation, yii2

## 简介

Глобальный модуль админ-панели: индекс меню всех локаций, палитра команд (Ctrl/Cmd+K), кнопки быстрых действий в шапке и страница «Настройки»

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
