# besnovatyj/yii2-cms-dashboard

> 标签: admin, cms, dashboard, yii2

## 简介

Панель главной страницы админки: сбор, включение и упорядочивание плиток-виджетов установленных модулей

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
