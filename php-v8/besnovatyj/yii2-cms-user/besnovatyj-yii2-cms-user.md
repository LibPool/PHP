# besnovatyj/yii2-cms-user

> 标签: auth, cms, oauth2, rbac, user, yii2

## 简介

Модуль пользователей, аутентификации и RBAC для Yii2 CMS (User/Identity, кабинет, вход/регистрация/сброс пароля, менеджер ролей и правил).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
