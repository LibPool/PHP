# besnovatyj/yii2-cms-apcu

> 标签: apcu, cache, cms, yii2

## 简介

Модуль просмотра и управления пользовательским кэшем APCu (порт apc.php) для Yii2 CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
