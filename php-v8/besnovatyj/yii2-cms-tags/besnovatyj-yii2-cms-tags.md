# besnovatyj/yii2-cms-tags

> 标签: cms, tags, taxonomy, yii2

## 简介

Общие теги для Yii2 CMS: один словарь и одна таблица связей на все контентные модули, форма назначения тегов, админка, страница тега и облако на фронте. Модули подключаются через контракт TaggableProvider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
