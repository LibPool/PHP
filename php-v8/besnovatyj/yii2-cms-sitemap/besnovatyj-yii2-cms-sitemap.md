# besnovatyj/yii2-cms-sitemap

> 标签: Sitemap, cms, seo, yii2

## 简介

Карта сайта для Yii2 CMS: собирает адреса модулей через контракт SitemapProvider в XML-карту (с индексом и нарезкой по лимитам протокола) и человеческую HTML-карту. Ни одного контентного модуля не знает поимённо.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
