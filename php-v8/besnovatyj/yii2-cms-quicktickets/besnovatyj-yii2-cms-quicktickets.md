# besnovatyj/yii2-cms-quicktickets

> 标签: afisha, cms, quicktickets, tickets, yii2

## 简介

Интеграция с API Афиша сервиса Quick Tickets для Yii2 CMS: кеш ответов, журнал расхода баллов, просмотр данных в админке

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
