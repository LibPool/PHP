# besnovatyj/yii2-cms-file-manager

> 标签: cms, filemanager, widget, yii2

## 简介

Standalone-виджет файлового менеджера для Yii2 (ядро filemanager-core + AssetBundle + PHP-виджет). Без CKEditor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
