# besnovatyj/yii2-cms-kernel

> 标签: cms, kernel, yii2

## 简介

Тонкое ядро (SDK) модулей Yii2 CMS: базовый класс модуля (CmsModule), базовая миграция (BaseMigration), url-хелпер. Зависит только от yii2 и контрактов.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
