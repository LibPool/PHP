# holduix/recaptcha

> 标签: bot, captcha, codeigniter, google, protection, recaptcha, security, spam, v2, v3

## 简介

Google reCAPTCHA integration for PHP (supports v2 and v3)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
