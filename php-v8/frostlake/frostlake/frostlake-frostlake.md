# frostlake/frostlake

> 标签: database, driver, frostlake, snowflake, sql

## 简介

Zero-dependency PHP driver for the Frostlake SQL engine over its HTTP protocol

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
