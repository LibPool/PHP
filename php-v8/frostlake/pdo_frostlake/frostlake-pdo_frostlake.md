# frostlake/pdo_frostlake

> 标签: database, driver, frostlake, pdo, snowflake, sql

## 简介

PDO driver for the Frostlake SQL engine over its HTTP protocol, with pdo_snowflake's surface

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
