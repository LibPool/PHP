# finaldream/wordpress-easy-301-redirects

> 标签: 301, redirection

## 简介

Modern and Easy 301 redirects for Wordpress. Intend to replace Simple 301 Redirects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
