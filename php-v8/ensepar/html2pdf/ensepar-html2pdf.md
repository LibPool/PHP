# ensepar/html2pdf

> 标签: html, html2pdf, pdf

## 简介

Unofficial fork of 'html2pdf' with Composer support. (Fixed composer dependency problem)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
