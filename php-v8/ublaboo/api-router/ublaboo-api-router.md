# ublaboo/api-router

> 标签: api, nette, rest, restapi, restrouter, route, router, routes, routing

## 简介

RESTful Router for your Apis in Nette Framework - created either directly or via attributes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
