# waotomatis/sdk

> 标签: WABA, php, sdk, waotomatis, whatsapp, whatsapp-api

## 简介

Official PHP SDK for WAOtomatis — headless WhatsApp (WABA Cloud API).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
