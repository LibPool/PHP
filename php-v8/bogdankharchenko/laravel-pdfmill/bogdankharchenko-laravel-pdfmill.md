# bogdankharchenko/laravel-pdfmill

> 标签: cloudflare-workers, laravel, openapi, pdf, pdf-lib

## 简介

Laravel client for the pdfmill API: merge, edit, fill, stamp and inspect PDFs on Cloudflare Workers. Generated from the API's OpenAPI spec.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
