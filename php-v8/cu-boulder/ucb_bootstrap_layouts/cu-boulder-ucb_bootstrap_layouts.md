# cu-boulder/ucb_bootstrap_layouts

> 标签: PHP

## 简介

Removes the default Drupal Layout Builder layouts and replaces them with bootstrap layouts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
