# daydevelops/vote

> 标签: laravel, vote

## 简介

A package built for laravel applications which allows items to be voted on. Items can be upvoted or downvoted which counts towards a total score.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
