# cymdeveloppement/roundcube-announcement

> 标签: Announcement, banner, motd, news, roundcube, roundcube-plugin, webmail

## 简介

Shows HTML or Markdown announcements (dialog or banner) once per user when they open their mailbox

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
