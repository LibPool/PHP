# alcea/cnp

> 标签: CNP, Validare, php, validator

## 简介

PHP Validation for Personal Identification Number (Validare PHP pentru Cod Numeric Personal CNP)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
