# l-david-l/laravel-dompdf-no-alpha-png

> 标签: dompdf, laravel, pdf

## 简介

A fork of barryvdh/laravel-dompdf with no PNG alpha processing. A DOMPDF Wrapper for Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
