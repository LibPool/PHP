# rezgui/phpserial

> 标签: laravel, php-serial, phpserial, rezgui, rsolution-dz

## 简介

Multi-platform serial port access convenience class for Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
