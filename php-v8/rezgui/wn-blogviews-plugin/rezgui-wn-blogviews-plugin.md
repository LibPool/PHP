# rezgui/wn-blogviews-plugin

> 标签: blog, cms, extension, plugin, post, winter

## 简介

Extension to the Winter.Blog plugin by add views tracking to blog posts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
