# icicleio/react-adapter

> 标签: adapter, loop, promise

## 简介

Adapts the event loop and promises of Icicle to interfaces compatible with components built for React.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
