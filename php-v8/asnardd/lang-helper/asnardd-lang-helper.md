# asnardd/lang-helper

> 标签: Asnardd, artisan, lang-helper, laravel, translations

## 简介

A simple package for Laravel to help you create lang files easily with a simple artisan command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
