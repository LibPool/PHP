# adequaat/laravel-postnl-api

> 标签: adequaat, laravel, laravel-postnl-api

## 简介

This package makes it easy to request barcodes and labels at PostNL from Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
