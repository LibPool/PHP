# eightynine/filament-subscription

> 标签: PHP

## 简介

Tenant subscriptions, entitlements, usage tracking, and billing (Paddle + Tanzania custom providers) for Filament v4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
