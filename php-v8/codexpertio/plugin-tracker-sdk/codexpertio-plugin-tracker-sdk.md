# codexpertio/plugin-tracker-sdk

> 标签: analytics, opt-in, sdk, telemetry, wordpress

## 简介

Telemetry SDK for WordPress plugins reporting to Plugin Tracker. Consent-gated, opt-in only.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
