> 标签: access, database, dbal, mssql, mysql, odbc, oracle, pdo, postgresql, sqlite, sqlsrv

## 简介

Dibi is Database Abstraction Library for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
