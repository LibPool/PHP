# husail/cnab-sdk

> 标签: cnab, cnab150, cnab240, cnab400

## 简介

SDK for reading and writing CNAB 240, 150 and 400 files, built on top of husail/edi-sdk.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
