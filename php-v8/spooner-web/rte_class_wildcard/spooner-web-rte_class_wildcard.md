# spooner-web/rte_class_wildcard

> 标签: PHP

## 简介

Possibility to set wildcards in the allowed classes for RTE in TYPO3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
