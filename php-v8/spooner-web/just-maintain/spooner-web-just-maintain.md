# spooner-web/just-maintain

> 标签: PHP

## 简介

Setup a maintenance page and enable / disable it easy and fast. Website only accessible as logged in BE user.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
