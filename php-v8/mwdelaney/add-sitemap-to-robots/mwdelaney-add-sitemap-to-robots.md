# mwdelaney/add-sitemap-to-robots

> 标签: Sitemap, plugin, robots, wordpress

## 简介

Add typical XML sitemap to robots.txt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
