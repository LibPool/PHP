# mwdelaney/sage-wp-nav-submenu

> 标签: nav_menu, submenu, wordpress

## 简介

Get submenu items from a WordPress menu based on parent or sibling

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
