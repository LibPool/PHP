# mwdelaney/acf-cover-media

> 标签: advanced custom fields, plugin, wordpress

## 简介

Easy, consistent cover media fields for WordPress and ACF Pro 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
