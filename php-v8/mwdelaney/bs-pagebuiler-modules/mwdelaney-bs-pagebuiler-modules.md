# mwdelaney/bs-pagebuiler-modules

> 标签: bootstrap, pagebuilder, plugin, wordpress

## 简介

Bootstrap styled modules for PageBuilder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
