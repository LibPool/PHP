# mwdelaney/sage-fonts-preload

> 标签: fonts, preload, sage, wordpress

## 简介

Automatically preload fonts from the Sage mix manifest

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
