# bitweb/id-services

> 标签: Authentication, ID Card, ID kaart, allkirjastamine, autentimine, id-card, mobiil id, mobiilID, mobile id, mobile-id, signing

## 简介

BitWeb extension for Estonian ID-Card and Mobile ID authentication and signing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
