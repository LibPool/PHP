# jtolj/html-attributes

> 标签: HTML Attributes, attributes, escape attributes, templates, templating

## 简介

A Fluent Interface for Handling HTML Attributes in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
