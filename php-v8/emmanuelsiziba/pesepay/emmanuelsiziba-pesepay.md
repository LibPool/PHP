# emmanuelsiziba/pesepay

> 标签: emmanuel siziba, integration, payment, pesepay

## 简介

Pesepay online payment integration package for seamless payment processing.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
