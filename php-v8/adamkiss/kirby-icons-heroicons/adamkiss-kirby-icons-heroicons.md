# adamkiss/kirby-icons-heroicons

> 标签: icons, kirby, kirby-plugin, snippets

## 简介

Heroicons as snippets for Kirby CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
