# adamkiss/kirby-log-viewer

> 标签: kirby, kirby-cms, kirby-plugin

## 简介

Log Viewer is a panel area for Kirby CMS displaying (parsed and highlighted) log files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
