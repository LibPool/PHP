# stacss/laravel-upd

> 标签: PDF GENERATOR, dompdf, laravel upd, upd, upd laravel, УПД, акт, счёт-фактура, универсальный передаточный документ, упд pdf, упд ларавел

## 简介

Универсальный пакет для печати УПД (универсальный передаточный документ) в Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
