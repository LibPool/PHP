# rogerarruda/laravel-metronic-components

> 标签: PHP

## 简介

Components for Laravel Blade based on the Metronic Admin Template (http://bit.ly/Metronic-Template)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
