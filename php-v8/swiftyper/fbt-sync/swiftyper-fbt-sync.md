# swiftyper/fbt-sync

> 标签: cli, deploy, framework, i18n, internationalization, php, sync, translations

## 简介

Extension for automatic deployment of fbt framework translations for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
