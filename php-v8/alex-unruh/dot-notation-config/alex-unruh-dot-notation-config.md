# alex-unruh/dot-notation-config

> 标签: access, config, data, dot, notation

## 简介

An abstraction layer to get data from array or a file built on Dflydev\DotAccessData\Data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
