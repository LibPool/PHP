# hmphu/magemulti

> 标签: PHP

## 简介

Something that similar to Magento Go service :). This extension allow you host multiple clients on the same Magento codebase

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
