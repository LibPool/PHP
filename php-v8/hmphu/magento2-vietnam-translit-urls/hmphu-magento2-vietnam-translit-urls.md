# hmphu/magento2-vietnam-translit-urls

> 标签: PHP

## 简介

Friendly url for vietnamese accented characters ("ồ" => "o", "ừ" => "u").

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
