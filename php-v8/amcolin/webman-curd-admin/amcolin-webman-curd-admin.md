# amcolin/webman-curd-admin

> 标签: DSL, admin, curd, lowcode, plugin, rbac, webman

## 简介

webman 应用插件（composer 分发版）：自包含的 CURD/DSL/Schema 页面引擎 + 登录/RBAC 中后台底座。内含 plugin/curd，宿主 composer require 后由 webman 官方插件安装器（workerman/webman-framework 的 support\Plugin）自动调用本包 src/Install.php 拷贝到 {项目}/plugin/curd 开箱即用。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
