# mailazy/php-sdk

> 标签: email api, email library, mailazy, phpsdk, send email, smtp

## 简介

Mailazy SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/mailazy/mailazy-php
- 源码仓库：https://github.com/mailazy/mailazy-php.git
- Packagist 页面：https://packagist.org/packages/mailazy%2Fphp-sdk

## 获取地址

- Composer 安装：`composer require mailazy/php-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/mailazy/php-sdk.json
- PHP 要求：>=5.6
