# valksor/typesafe-sdk-php

> 标签: PHP

## 简介

Unofficial, unaffiliated PHP SDK for the TypeSafe AI System One API, with 1:1 parity to the official JavaScript and Python SDKs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
