# adonyarik/pgsql-enums

> 标签: enum, laravel, migrations, postgres, postgresql, schema

## 简介

Native PostgreSQL ENUM types in Laravel migrations (DB and Blueprint macros that create, convert, redefine and drop them safely) and helpers that list the cases of PHP enums.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
