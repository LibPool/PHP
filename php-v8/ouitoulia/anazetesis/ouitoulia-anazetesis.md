# ouitoulia/anazetesis

> 标签: PHP

## 简介

Anazētēsis (Ricerca) è un modulo drupal che gestisce search api, le viste e i blocchi usate per presentare i risultati di ricerche sui siti delle scuole.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
