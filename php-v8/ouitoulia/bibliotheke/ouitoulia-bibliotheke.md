# ouitoulia/bibliotheke

> 标签: PHP

## 简介

Bibliothéke è un modulo drupal che gestisce le configurazioni di Media necessarie all'implementazione dell'architettura dei contenuti delle scuole.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
