# ouitoulia/keryx

> 标签: PHP

## 简介

Keryx (banditore) è un modulo drupal che gestisce le funzionalità di albo pretorio e amministrazione trasparente.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
