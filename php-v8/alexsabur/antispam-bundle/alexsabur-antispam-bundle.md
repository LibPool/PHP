# alexsabur/antispam-bundle

> 标签: antispam, bundle, form, protection, spam, symfony, twig

## 简介

This bundle provides some basic features to reduce spam in symfony forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
