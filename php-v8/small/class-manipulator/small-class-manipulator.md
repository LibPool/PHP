# small/class-manipulator

> 标签: ast, class, enum, generator, interface, parser, php, trait

## 简介

Modern PHP source-code manipulation for classes, interfaces, traits and enums.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
