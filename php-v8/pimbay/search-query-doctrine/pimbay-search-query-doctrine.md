# pimbay/search-query-doctrine

> 标签: dbal, doctrine, orm, pagination, query-builder, search

## 简介

Doctrine DBAL/ORM adapters for pimbay/search-query over a QueryBuilder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
