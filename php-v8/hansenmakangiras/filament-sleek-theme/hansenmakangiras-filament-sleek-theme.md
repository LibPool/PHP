# hansenmakangiras/filament-sleek-theme

> 标签: filament, filament-plugin, filament-sleek-theme, filamentphp, hansenmakangiras, laravel, sleek, theme

## 简介

A modern, sleek, responsive, and customizable theme for FilamentPHP v4 & v5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
