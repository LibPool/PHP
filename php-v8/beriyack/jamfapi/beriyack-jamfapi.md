# beriyack/jamfapi

> 标签: api, apple, device management, jamf, mdm, php, sdk, zuludesk

## 简介

Un client PHP pour interagir avec l'API de Jamf, construit sur beriyack/api-client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
