# whalesky-labs/jd-sdk-php

> 标签: ecommerce, jd, jingdong, jzt, pop, sdk, self-operated, swoole

## 简介

京东开放平台 PHP SDK，支持京准通、POP、自营、V1 和 SP API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
