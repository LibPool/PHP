# emotality/panacea-laravel

> 标签: laravel, panacea, panaceamobile, sms, transactional sms

## 简介

Laravel package to send transactional SMSes via PanaceaMobile.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
