# xiaohuyun/xhysanctum

> 标签: auth, xhysanctum, xiaohuyun

## 简介

xiaohuyun Sanctum provides a featherweight authentication system for SPAs and simple APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
