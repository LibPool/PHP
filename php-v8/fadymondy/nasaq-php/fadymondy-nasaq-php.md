# fadymondy/nasaq-php

> 标签: alpinejs, arabic, blade, design-system, filament, laravel, livewire, rtl, shadcn, tailwindcss

## 简介

Nasaq design system for Laravel: Blade components (<x-nq::button>), Alpine behaviours, Livewire wire:model support and a FilamentPHP plugin. Same markup and Tailwind classes as the React components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
