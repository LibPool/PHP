> 标签: health, laravel, monitoring, wizjo

## 简介

Endpoint diagnostyczny dla monitoringu Wizjo Tools: baza, kolejka, dysk, harmonogram.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
