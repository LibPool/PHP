# monospice/spicy-identifiers

> 标签: dynamic, method, parser, variable

## 简介

An easy way to parse and manipulate identifier names, such as dynamic method names.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
