# monospice/laravel-redis-sentinel-drivers

> 标签: laravel, lumen, redis, sentinel

## 简介

Redis Sentinel integration for Laravel and Lumen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
