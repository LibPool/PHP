# armsys-tech/armada

> 标签: alpine, blade, components, dark-mode, design-system, laravel, livewire, mobile-first, ui

## 简介

Blade and Livewire UI components for Laravel: light/dark themes, mobile-first, no Tailwind required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
