# hoceineel/filament-undo-toast

> 标签: filament, hoceineel, laravel, notifications, soft-deletes, toast, undo

## 简介

Gmail-style undo toasts for Filament delete, restore, edit and detach actions, with a countdown and mod+z.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
