# hoceineel/filament-sidebar-editor

> 标签: drag-and-drop, filament, hoceineel, laravel, menu, navigation, sidebar

## 简介

Let each tenant, user or panel hide, show and reorder Filament navigation groups and pages, with drag and drop and a live preview.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
