# moloni/moloni-print

> 标签: ESC-POS, Moloni, Moloni Print Client

## 简介

Library to create JSON for Moloni Print Client based on a document/cashflow object

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
