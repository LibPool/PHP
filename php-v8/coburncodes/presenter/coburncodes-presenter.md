# coburncodes/presenter

> 标签: laravel, laravel-plugin, presenter, view-presenter

## 简介

A presenter package for Laravel 5.5+ based off of the package by Laracasts

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
