# rockschtar/wordpress-cronjob

> 标签: PHP

## 简介

Library for use with roots/bedrock based WordPress projects. Simplifys the creation of WordPress cronjobs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
