# andrepayone/payone-sdk-silent-logger

> 标签: logger, payment, payone, psr-3, sdk

## 简介

A PSR-3 Noop-Logger Implementation for the SDK for PAYONE Payment Integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
