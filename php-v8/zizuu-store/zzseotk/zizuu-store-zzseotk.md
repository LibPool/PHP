# zizuu-store/zzseotk

> 标签: PHP

## 简介

"PrestaShop SEO toolkit" module. It handles a few SEO-related improvements, such as "hreflang", "canonical" and "noindex"

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
