# dgoriaev/mp3info

> 标签: audio, id3, id3v1, id3v2, mp3, mpeg

## 简介

The fastest php library to extract mp3 tags & meta information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
