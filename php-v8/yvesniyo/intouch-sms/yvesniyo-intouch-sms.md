# yvesniyo/intouch-sms

> 标签: intouch, library, php, rwanda, sms

## 简介

This is a php library to help developers include sms service, with IntouchSms gateway from RWANDA

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
