# jakubzapletal/payment-webpay-bundle

> 标签: PHP

## 简介

Payment Bundle for Symfony2 providing an access to the GP webpay API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
