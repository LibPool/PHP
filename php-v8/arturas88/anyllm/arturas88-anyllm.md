## 简介

Production-ready PHP library for LLMs - OpenAI, Anthropic, Google, Mistral, xAI, OpenRouter, Ollama. One interface, all providers, zero vendor lock-in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
