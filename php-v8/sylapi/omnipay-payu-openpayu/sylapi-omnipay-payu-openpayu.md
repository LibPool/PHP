# sylapi/omnipay-payu-openpayu

> 标签: gateway, merchant, omnipay, pay, payment, payu, purchase

## 简介

PayU gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
