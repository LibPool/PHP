# zestry-dev/wp-toolkit

> 标签: ajax, dependency-injection, modules, toolkit, wordpress, wordpress-plugin, wp-cli

## 简介

A toolkit for building WordPress plugins where a file in a directory is a feature: a per-plugin service container plus opt-in modules for CLI commands, admin pages, REST routes, post types, cron, blocks, migrations and more, copied into your plugin under your own namespace.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
