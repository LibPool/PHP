# tiny-pixel/wp-sensible-alignments

> 标签: block-editor, plugin, wordpress

## 简介

Add wrappers to alignwide and alignfull blocks on save

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
