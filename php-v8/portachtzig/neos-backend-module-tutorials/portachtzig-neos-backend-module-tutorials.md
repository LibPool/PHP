# portachtzig/neos-backend-module-tutorials

> 标签: PHP

## 简介

A very basic Neos CMS Backend Module for managing Client-based Video-Tutorials from External Services via embed-codes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
