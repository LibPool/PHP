# tielongphp/es-build-query

> 标签: build, elasticsearch, php, query

## 简介

对Elasticsearch-PHP进行查询语句封装 可实现链式调用 方便es查询

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
