# scope01/studio-file-viewer-bundle

> 标签: file-explorer, file-viewer, pimcore, pimcore-studio, scope01

## 简介

Server file viewer and editor for Pimcore Studio - browse, search and edit project files from within the Studio UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
