# ecomlogic/ebay-sdk

> 标签: api, ebay, sdk

## 简介

An eBay SDK for PHP. Use the eBay API in your PHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
