# ecomlogic/bol-sdk

> 标签: Bol.com, Bol.com Plaza Api, Bol.com api, Plaza api

## 简介

Interact with the Bol.com Plaza API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
