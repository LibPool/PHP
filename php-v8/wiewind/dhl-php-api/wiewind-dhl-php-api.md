# wiewind/dhl-php-api

> 标签: dhl, parcel, returns, shipment, shipping, tracking

## 简介

PHP client for DHL native REST APIs: Parcel DE Shipping v2, Returns v1, and Unified Shipment Tracking.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
