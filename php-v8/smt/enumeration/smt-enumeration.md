# smt/enumeration

> 标签: enum, enumeration

## 简介

Very basic (also lightweight) helper for enumeration classes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/saksmt/php-enum.git
- Packagist 页面：https://packagist.org/packages/smt%2Fenumeration
