# smt/buzz-realmed-curl-client

> 标签: Authentication, auth, browser, buzz, curl, http, realm

## 简介

BuzzBrowser curl client with support for http-realm authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
