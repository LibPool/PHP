# jolicode/media-bundle

> 标签: admin, bundle, gallery, media, symfony

## 简介

A media management bundle for Symfony applications, with Easyadmin and SonataAdmin integrations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
