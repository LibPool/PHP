# clarkwinkelmann/flarum-mithril2html

> 标签: SSR, flarum, html, mithril

## 简介

Renders Mithril components to HTML for use in blade templates

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
