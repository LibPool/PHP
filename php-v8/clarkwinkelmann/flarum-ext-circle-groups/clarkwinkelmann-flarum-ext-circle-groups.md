# clarkwinkelmann/flarum-ext-circle-groups

> 标签: design, extension, flarum, groups

## 简介

Add a color circle around avatars based on user group

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
