# jeremycurny/monolog-mysqlhandler

> 标签: database, log, logging, monolog, mysql

## 简介

A handler for Monolog that sends logs to MySQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
