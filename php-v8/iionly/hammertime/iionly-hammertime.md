# iionly/hammertime

> 标签: elgg, plugin

## 简介

Support swipe touch gestures to navigate in paginated lists and on Tidypics image pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
