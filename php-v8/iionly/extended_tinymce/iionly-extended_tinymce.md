# iionly/extended_tinymce

> 标签: elgg, plugin

## 简介

HTML WYSIWYG editor for Elgg based on the jquery Tinymce editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
