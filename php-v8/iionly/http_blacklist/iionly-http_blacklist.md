# iionly/http_blacklist

> 标签: elgg, plugin

## 简介

Block malicious IP addresses (and the people behind them) from accessing your site or redirect them to your honeypot site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
