# bruno-barros/w.eloquent

> 标签: framework, laravel, wordpress

## 简介

Wordpress integrated with Laravel via Composer. Together, but independents.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
