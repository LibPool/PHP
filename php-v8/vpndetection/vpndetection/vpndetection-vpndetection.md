# vpndetection/vpndetection

> 标签: Relay, cdn, datacenter-proxy, fraud-prevention, hosting, ip-geolocation, ip-intelligence, mobile-proxy, proxy-detection, residential-proxy, tor, vpn, vpn-detection

## 简介

Official PHP client library for the VPNDetection API. Detect VPNs, proxies, Tor, hosting and CDN IPs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
