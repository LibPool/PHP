# techwilk/twig-linewrap

> 标签: extension, filter, ical, linewrap, twig

## 简介

TWIG filter to wrap lines exceeding the specified length.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
