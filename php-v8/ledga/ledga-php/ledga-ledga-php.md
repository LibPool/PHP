# ledga/ledga-php

> 标签: Accounting, api, double-entry, finance, ledga, ledger, sdk

## 简介

PHP SDK for Ledga.io - Programmatic double-entry ledgers for finance, gaming and multi-tenant SaaS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
