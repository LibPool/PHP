# cakephp-app-installer/installer

> 标签: CakePHP-GUI-Installer, app-installer, cakephp, cakephp-4, installer

## 简介

GUI Installer Plugin for CakePHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
