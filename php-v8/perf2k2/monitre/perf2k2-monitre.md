# perf2k2/monitre

> 标签: linux monitoring, os monitoring, remote diagnostic, remote monitoring

## 简介

PHP library for remote linux monitoring/diagnostic with no installation needed

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
