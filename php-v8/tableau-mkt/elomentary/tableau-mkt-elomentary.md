# tableau-mkt/elomentary

> 标签: api, eloqua, rest

## 简介

The simple PHP Eloqua REST API client; object oriented, tested, and documented for PHP 5.3+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
