# jsanc623/phpbenchtime

> 标签: benchmark, benchtime, performance, profiler, stopwatch, timer

## 简介

A lightweight benchmark timer and lap profiler for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
