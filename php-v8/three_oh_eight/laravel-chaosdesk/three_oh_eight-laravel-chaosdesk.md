# three_oh_eight/laravel-chaosdesk

> 标签: chaosdesk, helpdesk, laravel, livewire, sdk, support

## 简介

Laravel SDK for ChaosDesk: drop-in Livewire support forms, automatic diagnostic context, and a server-to-server ticket ingest client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
