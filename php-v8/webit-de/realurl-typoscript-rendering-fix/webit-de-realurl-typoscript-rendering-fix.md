# webit-de/realurl-typoscript-rendering-fix

> 标签: PHP

## 简介

Fixes a bug in RealUrl which causes infinite loops when using the TypoScript rendering extension for AJAX.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
