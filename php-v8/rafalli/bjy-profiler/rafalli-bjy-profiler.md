# rafalli/bjy-profiler

> 标签: db, laminas, profiler

## 简介

Database profiler for Laminas\Db. Module forked from andrey-mokhov/bjy-profiler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
