# reshapify/sendseven-laravel

> 标签: laravel, messaging, sendseven, sms, webhooks, whatsapp

## 简介

Unofficial. SendSeven for Laravel: configured client, verified webhooks as Laravel events, channel onboarding redirects, a shared rate limit and a doctor command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
