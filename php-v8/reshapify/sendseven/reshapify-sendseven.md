# reshapify/sendseven

> 标签: Messenger, api, instagram, messaging, sdk, sendseven, sms, telegram, whatsapp

## 简介

Unofficial. A typed, fully documented PHP SDK for the SendSeven messaging API: WhatsApp, SMS, email, Telegram, Messenger, Instagram and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
