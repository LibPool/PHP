# nobledsmarts/db-sentry

> 标签: Nobledsmarts, db-sentry, laravel

## 简介

Laravel Helper package for backing up Mysql database specified in env file and saving it to a folder

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
