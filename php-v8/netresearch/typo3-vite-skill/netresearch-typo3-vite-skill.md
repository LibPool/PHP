# netresearch/typo3-vite-skill

> 标签: PHP

## 简介

Vite build setup, SCSS architecture, Bootstrap theming for TYPO3 v13+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
