# netresearch/deploy-rst

> 标签: reStructuredText, rst, wiki

## 简介

Deploys a README.rst file into a wiki, e.g. Confluence

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
