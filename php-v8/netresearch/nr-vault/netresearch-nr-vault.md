# netresearch/nr-vault

> 标签: api-keys, audit-log, credentials, encryption, envelope-encryption, key-rotation, libsodium, oauth, secrets, secrets-management, security, typo3, vault

## 简介

Secure secrets management for TYPO3 with envelope encryption, access control, and audit logging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
