# netresearch/nr-llm

> 标签: Gemini, ai, chatbot, claude, embeddings, extension, llm, ollama, openai, provider-abstraction, streaming, translation, typo3

## 简介

LLM Foundation - Shared AI foundation: configure LLM providers once for every AI extension, with encrypted API keys and services for chat, translation, vision and embeddings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
