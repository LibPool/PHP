# netresearch/t3-cowriter

> 标签: ai, backend, cowriter, extension, typo3

## 简介

AI Cowriter - AI assistant in CKEditor that helps editors write page content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
