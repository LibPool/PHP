# netresearch/typo3-upgrade-effort-model-skill

> 标签: ai-agent, effort-estimation, estimation, lts, rector, skill, typo3, upgrade

## 简介

Agent Skill for estimating TYPO3 LTS upgrade effort: risk multipliers, breaking-change baselines, version compatibility, Rector coverage, 7-phase assessment workflow

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
