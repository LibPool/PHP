# netresearch/nr-mcp-agent

> 标签: ai, backend, chat, extension, llm, mcp, typo3

## 简介

AI Chat - AI chat assistant for the TYPO3 backend, using nr-llm and an MCP server for tool calling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
