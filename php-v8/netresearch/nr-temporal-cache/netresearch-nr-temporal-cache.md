# netresearch/nr-temporal-cache

> 标签: cache, content, endtime, menu, publication, scheduling, starttime, temporal, typo3

## 简介

Temporal Cache Management - Automatic TYPO3 cache invalidation for time-based content (starttime/endtime), addressing Forge #14277. Three scoping strategies (global, per-page, per-content) and three timing strategies (dynamic, scheduler, hybrid). The default global scoping expires all page caches on every transition - read the Performance chapter before deployment.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
