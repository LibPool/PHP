# netresearch/agents-skill

> 标签: ai-agent, skill

## 简介

Netresearch AI skill for generating AGENTS.md, copilot-instructions.md, and other agent rule files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
