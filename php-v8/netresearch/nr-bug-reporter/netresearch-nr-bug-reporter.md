# netresearch/nr-bug-reporter

> 标签: backend, bug-report, error-handling, github, typo3

## 简介

TYPO3 backend bug reporter: attribute an error to its originating Composer package and open a prefilled issue on that package's upstream GitHub tracker. Adds an error-page report action and a proactive backend toolbar item.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
