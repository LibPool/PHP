# netresearch/markdown-to-pdf-skill

> 标签: PHP

## 简介

AI agent skill: convert Markdown files to styled PDFs using WeasyPrint. CSS-overridable for branded output.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
