# netresearch/jujutsu-workflow-skill

> 标签: PHP

## 简介

Agent-safe version-control workflows using Jujutsu (jj) with Git-backed repositories: jj for local change management, Git as the canonical remote/PR/CI/audit interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
