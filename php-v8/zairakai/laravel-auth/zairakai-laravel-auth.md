# zairakai/laravel-auth

> 标签: Authentication, fortify, laravel, sanctum, zairakai

## 简介

Headless authentication bridge for Laravel applications using Fortify and Sanctum

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
