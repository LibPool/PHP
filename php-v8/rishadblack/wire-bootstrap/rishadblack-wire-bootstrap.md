# rishadblack/wire-bootstrap

> 标签: Forms, alpine, blade-components, bootstrap, laravel, livewire, ui

## 简介

Livewire-native Bootstrap 5.3 UI: one artisan command sets up Bootstrap, Vite and a base layout, and every form field is a single Blade tag with its own label, wire:model binding, validation errors and loading states.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
