# rishadblack/wire-modals

> 标签: alpine, bootstrap, dynamic-component, laravel, livewire, modal

## 简介

On-demand Livewire components with Bootstrap 5 modals: mount a component when a button is clicked, call an action on it, and unmount it when its modal closes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
