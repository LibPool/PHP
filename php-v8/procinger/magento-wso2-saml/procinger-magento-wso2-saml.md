# procinger/magento-wso2-saml

> 标签: SSO, magento, saml, wso

## 简介

Basic Magento login/logout WSO2 Identity Server SAML module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
