# shadiakiki1986/fatca-ides-php

> 标签: FATCA, IDES, decryption, encryption

## 简介

PHP library for generation of FATCA IDES submission files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
