# mrmishmash/amazon_creators_api

> 标签: creatorsapi, creatorsapi-php-sdk

## 简介

Github mirror of CreatorsAPI 1.2.0 PHP SDK

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
