# coringawc/filament-acl

> 标签: CoringaWc, acl, filament, filament-plugin, laravel, permissions

## 简介

Contextual permissions for Filament resources, relation managers, and actions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
