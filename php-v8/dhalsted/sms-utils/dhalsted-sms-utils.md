# dhalsted/sms-utils

> 标签: composer, libphonenumber, php, twilio

## 简介

Validate SMS numbers using libphonenumber and Twilio

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
