# luri/anothercsrflib

> 标签: csrf, token

## 简介

An Another CSRF php Lib with deadline token for easy use in NO middleware project. If you want a middleware CSRF lib, see slim/csrf

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
