# luri/bddi

> 标签: database, db, interface, mysql, mysqli, sql

## 简介

library to facilitate SQL Requests set with automatic prepared statements and automatic connexion.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
