# nexus-actors/persistence-dbal

> 标签: PHP

## 简介

Nexus persistence DBAL adapter — Doctrine DBAL-backed event store, snapshot store, and durable state store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
