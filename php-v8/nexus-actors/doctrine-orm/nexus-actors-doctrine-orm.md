# nexus-actors/doctrine-orm

> 标签: PHP

## 简介

Nexus Doctrine ORM — pooled EntityManager, HTTP middleware, and EntityBehavior DSL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
