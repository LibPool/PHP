# nexus-actors/doctrine-dbal

> 标签: PHP

## 简介

Nexus Doctrine DBAL — coroutine-aware connection pool, HTTP scope middleware, and actor-side integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
