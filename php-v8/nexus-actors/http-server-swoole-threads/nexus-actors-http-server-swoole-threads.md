# nexus-actors/http-server-swoole-threads

> 标签: PHP

## 简介

Thread-mode HTTP server built on Swoole 6 native SWOOLE_THREAD; cross-thread pool-singleton actors via WorkerNode.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
