# petitchevalroux/php-cs-fixer-on-uncommited-lines

> 标签: PHP

## 简介

Simple php script to apply php-cs-fixer only on chunk containing uncommited line

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
