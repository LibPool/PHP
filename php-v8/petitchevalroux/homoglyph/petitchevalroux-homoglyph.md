# petitchevalroux/homoglyph

> 标签: PHP

## 简介

Replace all homoglyphs with latin characters equivalent, latin homoglyphs are not replaced

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
