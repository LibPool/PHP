# j0k3r/httplug-ssrf-plugin

> 标签: http, httplug, plugin, security, ssrf

## 简介

Server-Side Request Forgery (SSRF) protection plugin for HTTPlug

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
