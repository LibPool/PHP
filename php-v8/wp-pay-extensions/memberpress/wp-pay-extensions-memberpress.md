# wp-pay-extensions/memberpress

> 标签: extension, memberpress, pay, pronamic, wordpress, wp

## 简介

MemberPress driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
