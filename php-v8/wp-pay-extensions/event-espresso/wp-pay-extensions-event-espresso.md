# wp-pay-extensions/event-espresso

> 标签: espresso, event, event-espresso, events, extension, pay, pronamic, wordpress, wp

## 简介

Event Espresso driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
