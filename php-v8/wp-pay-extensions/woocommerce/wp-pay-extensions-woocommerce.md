# wp-pay-extensions/woocommerce

> 标签: extension, pay, pronamic, woocommerce, wordpress, wp

## 简介

WooCommerce driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
