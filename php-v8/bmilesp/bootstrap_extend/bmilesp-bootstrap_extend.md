# bmilesp/bootstrap_extend

> 标签: PHP

## 简介

Classes and helpers that extend CakePHP for a simple and powerful drop-in solution for Twitter Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
