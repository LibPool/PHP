# jaybizzle/statagist

> 标签: api, cli, packagist, statistics

## 简介

A simple CLI tool to quickly see package stats from Packagist.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://packagist.org/packages/jaybizzle%2Fstatagist
- 源码仓库：https://github.com/JayBizzle/statagist.git
- Packagist 页面：https://packagist.org/packages/jaybizzle%2Fstatagist
