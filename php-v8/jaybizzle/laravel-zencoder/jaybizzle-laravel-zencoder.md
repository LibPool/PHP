# jaybizzle/laravel-zencoder

> 标签: Thumbnails, a4m, api, audio, laravel, transcoding, video, zencoder

## 简介

A laravel wrapper around the zencoder API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
