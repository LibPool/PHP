# tringalama2/vcard

> 标签: .vcf, generator, php, vCard

## 简介

Fix for Vcard library from Jeroen Desloovere for temporary compatability with PHP 8.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
