# michaeljberry/amazon-mws-api

> 标签: Amazon MWS, amazon api, mws

## 简介

A PHP library to connect with, update to and pull data from Amazon MWS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
