# sunflowerfuchs/discord-tiktok-plugin

> 标签: PHP

## 简介

A plugin for sunflowerfuchs/discord-bot that adds improved tiktok embedding.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
