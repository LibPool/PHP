# masterpass/mpasscoresdk

> 标签: PHP

## 简介

PHP Core SDK for use with Masterpass Merchant Checkout Service SDK on MasterCard Developer Zone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://developer.mastercard.com
- 源码仓库：https://github.com/Masterpass/MasterCardCoreSDK-PHP.git
- Packagist 页面：https://packagist.org/packages/masterpass%2Fmpasscoresdk
