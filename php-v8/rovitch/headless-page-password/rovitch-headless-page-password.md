# rovitch/headless-page-password

> 标签: headless, json, page_password, pwa, typo3

## 简介

This extension provides integration with page_password to output content from TYPO3 in JSON format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
