# blib/blibphp

> 标签: blib, helper, sql, tools, useful

## 简介

Blib is a useful helper for legacy projects, many usefuls like build string for Sql and others, check modules.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
