# protung/easyadmin-plus-bundle

> 标签: Symfony Bundle, admin, backend, crud, doctrine, easyadmin, easyadmin bundle, phpunit, symfony

## 简介

Extensions for EasyAdmin: base CRUD controllers, also for editing entities through DTOs, an entity field linking to the CRUD controller of the related entity, JSON and callback-configurable fields, an enum filter, menu item matchers, and PHPUnit test cases for dashboards and CRUD actions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
