# protung/open-api-generator

> 标签: jms serializer, open api, open api schema generator, openapi, openapi generator, schema, specification, swagger, swagger schema generator, symfony

## 简介

Generate OpenAPI specifications from Symfony routes, forms, mapped request payloads, validation constraints and JMS Serializer metadata.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
