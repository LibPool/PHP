# drapor/cache-repository

> 标签: cache, caching, caching repository, eloquent, laravel, repository

## 简介

Simple to use Caching Repository for Laravel Eloquent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
