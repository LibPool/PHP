# jlchassaing/calameobundle

> 标签: calameo, ezplatform, ezpublish

## 简介

CalameoBundle add a new field type to ezplatform to link content to calaemo

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
