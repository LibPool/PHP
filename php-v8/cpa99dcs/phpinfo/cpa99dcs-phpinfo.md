# cpa99dcs/phpinfo

> 标签: phpinfo

## 简介

Provides PHPInfo functionality as a Zend Framework 3 module. Intended for development use

按 require.php 推断最低支持 PHP 3；已收录于 php-v5, php-v7, php-v8。
