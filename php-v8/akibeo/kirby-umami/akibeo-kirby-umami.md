# akibeo/kirby-umami

> 标签: analytics, cookieless, kirby, kirby-plugin, panel, privacy, umami

## 简介

Umami analytics for Kirby CMS: tracker script with CSP nonce, server-side events and a Panel stats view.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
