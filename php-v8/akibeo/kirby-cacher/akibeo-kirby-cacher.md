# akibeo/kirby-cacher

> 标签: cache, kirby, kirby-plugin, panel, redis

## 简介

Cache Manager for Kirby CMS: a Panel view with stats and a safe Clear Cache button for the file cache, the Redis pages cache and named cache namespaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
