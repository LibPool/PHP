# akibeo/kirby-altcha

> 标签: ALTCHA, Forms, captcha, cookieless, kirby, kirby-plugin, privacy, proof-of-work, spam

## 简介

ALTCHA for Kirby CMS: self-hosted, cookieless proof-of-work captcha with a challenge route, payload verification and a CSP-friendly widget.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
