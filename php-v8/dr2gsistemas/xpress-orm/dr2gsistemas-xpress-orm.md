# dr2gsistemas/xpress-orm

> 标签: database, entity, mariadb, mysql, orm, php8, repository

## 简介

ORM ligero para PHP 8.4 con atributos, relaciones y auto-migrate para MariaDB

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
