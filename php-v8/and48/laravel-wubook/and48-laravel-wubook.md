# and48/laravel-wubook

> 标签: laravel-package, laravel-wubook, wubook

## 简介

A WuBook bridge for Laravel 8.x https://wubook.net

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
