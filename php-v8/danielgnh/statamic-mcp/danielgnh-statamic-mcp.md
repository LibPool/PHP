# danielgnh/statamic-mcp

> 标签: addon, ai, claude, mcp, statamic

## 简介

MCP server for Statamic — manage entries, terms, and globals from AI clients over streamable HTTP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
