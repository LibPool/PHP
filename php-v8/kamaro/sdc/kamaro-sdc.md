# kamaro/sdc

> 标签: kamaro, sdc

## 简介

A package to interact with Sales Data Controllers (SDC) for Rwanda Revenue Authority

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/kamaroly/sdc
- 源码仓库：https://github.com/kamaroly/Sdc.git
- Packagist 页面：https://packagist.org/packages/kamaro%2Fsdc
