# jramke/fluid-types

> 标签: TYPO3 CMS

## 简介

Generates TypeScript types from Fluid Primitives component props and any #[TypeScript]-tagged PHP class in a TYPO3 project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
