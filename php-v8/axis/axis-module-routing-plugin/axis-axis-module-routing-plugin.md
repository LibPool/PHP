# axis/axis-module-routing-plugin

> 标签: plugin, routing, symfony

## 简介

symfony 1.x plugin that allows you to define routing configuration at module level.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
