# hannesvdvreken/guzzle-profiler

> 标签: Guzzle, debug, http, log, middleware, profiler, profiling, timeline

## 简介

A Guzzle middleware that profiles requests made by the client.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
