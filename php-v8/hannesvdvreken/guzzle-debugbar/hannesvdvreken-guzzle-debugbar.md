# hannesvdvreken/guzzle-debugbar

> 标签: Guzzle, debugbar, http, log, middleware, php, profiler, profiling

## 简介

A Guzzle middleware that logs requests to debugbar's timeline

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
