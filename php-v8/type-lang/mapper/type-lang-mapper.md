# type-lang/mapper

> 标签: Marshal, denormalizer, hydrator, mapper, normalizer, serializer, transformer, types, unmarshal

## 简介

Library for mapping variable types to other types

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
