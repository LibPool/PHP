# ilyasmohetna/iban

> 标签: Banking, IBAN, International Bank Account Number, PHP Library, bank details, finance, financial tools, iban checker, iban generator, iban parser, iban parsing, iban tools, iban validation, iban validator, package, php

## 简介

Iban is a PHP package for parsing, validating, and extracting bank details from IBANs with ease and accuracy. Simplify financial data handling in your applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
