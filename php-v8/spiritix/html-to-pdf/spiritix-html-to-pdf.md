# spiritix/html-to-pdf

> 标签: converter, html, htmltopdf, pdf, php, print

## 简介

Convert HTML markup into beautiful PDF files using the famous wkhtmltopdf library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
