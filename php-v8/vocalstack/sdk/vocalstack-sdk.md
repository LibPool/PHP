# vocalstack/sdk

> 标签: Transcription, api, captions, realtime, sdk, speech, speech-to-text, translation, vocalstack, websocket

## 简介

VocalStack speech API SDK for PHP: one client grouped by resource, file and link transcription, realtime WebSocket streaming.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
