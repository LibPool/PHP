# l3/photo-bundle

> 标签: PHP

## 简介

PhotoBundle client for RefPhoto Symfony2/Symfony3/Symfony4/Symfony5/Symfony6/Symfony7

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
