# liqwiz/laravel-sso-client

> 标签: SSO, laravel, oauth, passport, single sign-on

## 简介

Laravel SSO client package - turn any Laravel app into an SSO client using a Hub (OAuth2 IdP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
