# darvis/api-x

> 标签: ai-agent, claude, laravel, laravel-boost, laravel-mcp, mcp, mentions, model-context-protocol, oauth1, post-to-x, replies, social-media, tweet, twitter, twitter-api, x, x-api

## 简介

Post to X (Twitter) from Laravel: posts with an image, replies and your mentions through the X API v2, a setup wizard, artisan commands and an MCP server so Claude and other AI agents can post and reply for you.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
