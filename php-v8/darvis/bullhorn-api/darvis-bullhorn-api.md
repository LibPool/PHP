# darvis/bullhorn-api

> 标签: API-Client, ATS, bullhorn, bullhorn-rest-api, crm, laravel, laravel-boost, oauth2, php, recruitment, staffing

## 简介

PHP client for the Bullhorn REST API (staffing and recruitment CRM): OAuth login, a shared session that survives concurrent requests, entity, search and file helpers, and a Laravel integration with facade, encrypted session cache and Http::fake() support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
