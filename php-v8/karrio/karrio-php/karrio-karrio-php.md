> 标签: api, dhl-api, fedex-api, karrio, multi-carrier, php, sdk, shipping-api, ups-api

## 简介

karrio Multi-carrier Shipping API PHP client library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
