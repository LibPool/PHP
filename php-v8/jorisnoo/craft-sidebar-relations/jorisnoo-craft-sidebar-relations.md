# jorisnoo/craft-sidebar-relations

> 标签: Craft, cms, craftcms, navigation, relations, sidebar

## 简介

Adds nested element sources to the Craft CMS sidebar based on entry relations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
