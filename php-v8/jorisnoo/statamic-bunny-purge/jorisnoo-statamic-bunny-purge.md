# jorisnoo/statamic-bunny-purge

> 标签: Bunny.net, bunny, cache, cdn, purge, statamic, statamic-addon

## 简介

Automatically purge Bunny CDN cache when Statamic content changes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
