# b1-road/laravel

> 标签: auth, b1, bff, iam, laravel, oidc, rbac, road

## 简介

Official Road SDK for Laravel — BFF auth, proxy, and client for the Road IAM platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
