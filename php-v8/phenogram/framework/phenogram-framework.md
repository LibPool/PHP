# phenogram/framework

> 标签: Telegram-Bot-API, async, bot, framework, php, telegram, telegram-bot, type-safe

## 简介

Async, strictly typed Telegram bot framework for PHP 8.4

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
