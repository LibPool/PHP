# phenogram/bindings

> 标签: API-Client, Telegram-Bot-API, bindings, bot, sdk, telegram, telegram-bot, type-safe

## 简介

Zero-dependency, low-level, type-safe PHP bindings for the Telegram Bot API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
