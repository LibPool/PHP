# hawk-hhg/hawki-client-backend

> 标签: PHP

## 简介

A lightweight PHP backend for using HAWKI's external apps; that provides a secure, encrypted connection to your HAWKI instance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
