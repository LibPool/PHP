# devaloka/devaloka-translation

> 标签: i18n, internationalization, l10n, localization, plugin, translation, wordpress

## 简介

Provides an implementation of Symfony TranslationInterface for WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
