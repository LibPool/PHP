# liquiddesign/forms

> 标签: PHP

## 简介

Ⓕ Vícejazyčné formuláře do Nette, doplněné o nové prvky, wysiwyg, antispam kontrolu a prevenci doubleclicku

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
