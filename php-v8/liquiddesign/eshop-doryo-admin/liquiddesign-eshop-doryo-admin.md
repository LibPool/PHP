# liquiddesign/eshop-doryo-admin

> 标签: PHP

## 简介

Zápis do administrace e-shopu pro Doryo/Kolego — headless spouštění admin presenterů: gridy ke čtení, formuláře a akce s náhledem a tokenem, hromadné úpravy

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
