# joximu/imscp-monsta-ftp

> 标签: ftp, imscp, monstaftp, tools

## 简介

Provides the MonstaFTP Web-based FTP client for i-MSCP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
