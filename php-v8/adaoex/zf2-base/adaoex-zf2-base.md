# adaoex/zf2-base

> 标签: crud, framework, module, zf2

## 简介

Módulo 'BaseController' para projeto que utilize Zend Framework 2, por @adaoex

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
