# datitecnologia/sped-nfe

> 标签: nfce, nfe, nfephp, sped

## 简介

API para geração e comunicação da NFe e NFCe com as SEFAZ autorizadoras.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
