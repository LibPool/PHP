# aimanong/framework

> 标签: admin, ai, ai-first, aimanong, laravel, mcp

## 简介

Aimanong（AI 码农）—— 为 AI Agent 设计的后台开发框架（元包：内核 + Laravel 驱动）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
