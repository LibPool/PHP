# aimanong/core

> 标签: DSL, admin, ai, ai-first, aimanong

## 简介

Aimanong 框架无关内核 —— 声明 DSL 与四产物编译（零 illuminate 依赖）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
