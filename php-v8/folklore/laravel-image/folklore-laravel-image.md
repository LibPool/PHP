# folklore/laravel-image

> 标签: gd, gmagick, image, imagick, imagine, laravel, thumbnail, watermark

## 简介

URL-based image manipulation for Laravel, built on Imagine

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
