# kbrodej/drupal-extension-layout-builder

> 标签: Behat, drupal

## 简介

Additional step definitions for testing Drupal sites with layout builder using Behat.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
