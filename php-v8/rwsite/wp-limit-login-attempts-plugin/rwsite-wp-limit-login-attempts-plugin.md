# rwsite/wp-limit-login-attempts-plugin

> 标签: PHP

## 简介

WordPress Limit login attempts Plugin. Automatically blocked IP for many attempts login trys.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
