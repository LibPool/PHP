# lightmagic/socialite

> 标签: login, oauth, qq, social, wechat, weibo

## 简介

A collection of OAuth 2 packages that extracts from laravel/socialite.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
