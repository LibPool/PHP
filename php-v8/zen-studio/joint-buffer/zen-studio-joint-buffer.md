# zen-studio/joint-buffer

> 标签: hyperf, php, protobuf

## 简介

基于Google Protocol Buffer的Buffer拼装器，可以将两段Buffer进行拼装和拆解

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
