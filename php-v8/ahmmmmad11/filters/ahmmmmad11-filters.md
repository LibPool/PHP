# ahmmmmad11/filters

> 标签: Ahmed Mohamed, filters, laravel

## 简介

A wrapper package over spatie query builder package to simplify filters creation for Laravel Apps

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
