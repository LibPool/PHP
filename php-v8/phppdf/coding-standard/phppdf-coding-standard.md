# phppdf/coding-standard

> 标签: PHPPdf, checks, code, coding, coding-standard, coding-standards, cs, rules, sniffer, sniffs, standard, standards, style

## 简介

The coding standards for PHP_CodeSniffer we use at phppdf.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
