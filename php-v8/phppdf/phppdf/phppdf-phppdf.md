# phppdf/phppdf

> 标签: pdf

## 简介

A pure PHP library for creating and processing PDF files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/phppdf/phppdf.git
