# sgalinski/df-tabs

> 标签: PHP

## 简介

Tabs for Content Elements & Pages - Create tab-based TYPO3 content elements and page tabs with configurable interaction, animations, and autoplay.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
