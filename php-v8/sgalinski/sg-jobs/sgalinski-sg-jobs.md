# sgalinski/sg-jobs

> 标签: PHP

## 简介

Jobs Board & Applications - Manage job postings in TYPO3 and collect applications with file uploads, notifications, and CSV export/storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
