# sgalinski/sg-youtube

> 标签: PHP

## 简介

DEPRECATED: Legacy YouTube provider for TYPO3. Migrate to sgalinski/sg-video, the unified successor for YouTube/Vimeo videos, playlists, channels, and media-library style output.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
