# sgalinski/sg-teaser

> 标签: PHP

## 简介

Teaser Grid & Category Filters - Render TYPO3 subpage teasers in masonry/grid layouts with category filtering and frontend plugin integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
