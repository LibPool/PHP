# sgalinski/sg-cache-extender

> 标签: PHP

## 简介

Cache Manager: Clear All & Branch - Extend TYPO3 cache management with clear-all actions, page and branch cache flushing, backend buttons, and CLI support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
