# sgalinski/sg-logs

> 标签: PHP

## 简介

Log Viewer & Error Analytics - TYPO3 backend log viewer with grouping, solved markers, filtering, pagination, live tail, and optional metrics export.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
