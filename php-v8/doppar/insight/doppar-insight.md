# doppar/insight

> 标签: debug, debugbar, doppar, profiler, toolbar

## 简介

Doppar/Insight is a developer profiling and debugging toolbar for Doppar framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
