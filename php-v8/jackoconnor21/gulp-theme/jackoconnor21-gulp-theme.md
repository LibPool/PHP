# jackoconnor21/gulp-theme

> 标签: es6, gulp, npm, scss, silverstripe

## 简介

A gulp enabled theme for SilverStripe with ES6 and SCSS support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
