# djgadd/themosis-illuminate

> 标签: plugin, themosis

## 简介

A themosis plugin that implements the illuminate/cache packing with a WP_Object_Cache driver

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
