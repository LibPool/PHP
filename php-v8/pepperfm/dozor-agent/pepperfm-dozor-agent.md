# pepperfm/dozor-agent

> 标签: DoZoR, apm, laravel, monitoring, observability

## 简介

Self-hostable Laravel instrumentation and local agent starter inspired by laravel/nightwatch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
