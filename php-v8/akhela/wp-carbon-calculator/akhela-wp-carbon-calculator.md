# akhela/wp-carbon-calculator

> 标签: CO2, carbon footprint, environment, plugin, sustainability, website impact, wordpress

## 简介

Calculate the CO₂ impact of your web pages in real time, without API delays, directly from your WordPress admin panel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
