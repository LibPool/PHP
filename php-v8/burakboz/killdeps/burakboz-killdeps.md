# burakboz/killdeps

> 标签: PHP

## 简介

A powerful cleaner and analyzer tool that efficiently scans and deletes 'vendor' and 'node_modules' directories in PHP and JavaScript development environments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
