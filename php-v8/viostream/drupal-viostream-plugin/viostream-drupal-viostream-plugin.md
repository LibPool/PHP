# viostream/drupal-viostream-plugin

> 标签: drupal, embed, govCMS, media, video, viostream

## 简介

Provides a field formatter to embed Viostream videos in Drupal/GovCMS websites.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
