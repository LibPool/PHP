# readymate/build-sync

> 标签: assets, build, laravel, sync, vite

## 简介

Sync a Laravel install's compiled front-end build from a base install over HTTP, with a built-in UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
