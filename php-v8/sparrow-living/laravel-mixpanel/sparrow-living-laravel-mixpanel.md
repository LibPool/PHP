# sparrow-living/laravel-mixpanel

> 标签: PHP

## 简介

MixPanel wrapper for Laravel. Forked to work on Laravel 10.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
