# liturgical-calendar/alexa-newsbrief

> 标签: PHP

## 简介

Liturgy of the Day as an Amazon Alexa skill available for your daily news brief, using the Liturgical Calendar API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
