# zeromax/contao-responsive-images

> 标签: mobile, responsive

## 简介

Create smaller Images by defined Breakpoint and reading the client Screen Width

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
