# ironflow/halo-ui

> 标签: alpine, blade, blade-icons, components, halo-ui, laravel, tailwind, ui

## 简介

Modern, composable Blade UI component library for Laravel — elegant as shadcn, native as Blade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
