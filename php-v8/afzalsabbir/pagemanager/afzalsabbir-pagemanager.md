# afzalsabbir/pagemanager

> 标签: Content management system, admin panel, administer pages, backpack, cms, crud, manage pages, pagemanager, presentation pages, presentation website, wordpress

## 简介

Create admin panels for presentation websites on Laravel, using page templates and Backpack\CRUD.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
