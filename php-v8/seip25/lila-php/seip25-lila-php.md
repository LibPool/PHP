# seip25/lila-php

> 标签: Gemini, Opcache, SPA, ai, anthropic, apcu, api, bluebird-css, deepseek, fastcgi, high-performance, lila-js, llm, micro-framework, openai, php, redis, rest-api

## 简介

Ultra-fast, zero-dependency PHP 8.4+ micro-API framework with decoupled static frontend, Lila.js reactive SPA engine, Bluebird CSS, multi-driver DB, and universal AI engine (DeepSeek, Gemini, OpenAI, Claude, Ollama).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
