# gedankenfolger/gedankenfolger-event

> 标签: PHP

## 简介

TYPO3 14 Event extension with Content Blocks, Site Set, Bootstrap CSS/SCSS, ICS export.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
