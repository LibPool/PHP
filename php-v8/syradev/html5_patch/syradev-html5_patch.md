# syradev/html5_patch

> 标签: HTML5, Self-closing tags, TYPO3 CMS, W3C validation

## 简介

This extension patches TYPO3 to eliminate non-HTML5-standard self-closing tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
