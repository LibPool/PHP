# xueron/pails

> 标签: pails, phalcon, phalcon-rails, phinx, php, rails

## 简介

Pails (PhalconRails) is used to create a rails-like PHP app based on Phalcon.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
