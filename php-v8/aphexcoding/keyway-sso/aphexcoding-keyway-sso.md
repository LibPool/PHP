# aphexcoding/keyway-sso

> 标签: Azure AD, Craft, OpenID Connect, SAML2, SSO, attribute mapping, craft-plugin, craftcms, entra ID, group mapping, keycloak, oidc, okta, saml, service provider, single sign on

## 简介

SAML 2.0 and OIDC single sign-on for the Craft CMS control panel: group mapping, JIT provisioning and a diagnostics panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
