# jaewun/discourse-sso-laravel

> 标签: SSO, discourse, laravel

## 简介

A package specifically for Laravel, helping with Discourse's SSO login.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
