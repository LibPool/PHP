# rjcodes/rjcms

> 标签: admin, bread, cms, content-management, laravel, livewire

## 简介

A lightweight Laravel CMS package for rapidly building admin dashboards with minimal frontend coding.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
