# insoutt/ec-validator-laravel

> 标签: ec-validator-laravel, insoutt, laravel

## 简介

Validar Cédula, RUC, Placa y mas datos de Ecuador en Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
