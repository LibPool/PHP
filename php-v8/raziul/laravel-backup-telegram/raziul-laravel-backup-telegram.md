# raziul/laravel-backup-telegram

> 标签: laravel, laravel-backup, laravel-backup-telegram

## 简介

Send your Laravel backup files to a Telegram chat or channel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
