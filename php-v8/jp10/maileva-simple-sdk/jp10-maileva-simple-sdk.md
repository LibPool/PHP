# jp10/maileva-simple-sdk

> 标签: api, email, maileva, php, rest, sdk

## 简介

API pour envoyer et suivre des courriers postaux.  Elle comprend les fonctions clés pour :   - créer un envoi,  - ajouter des documents et des destinataires,  - choisir ses options,  - suivre la production.  Pour connaitre les notifications (webhooks) concernées par cette API, consultez la documentation de l'API <a href="/developpeur/notification_center">notification_center</a>.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
