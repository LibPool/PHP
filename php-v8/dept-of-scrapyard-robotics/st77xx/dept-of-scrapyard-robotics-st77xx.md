# dept-of-scrapyard-robotics/st77xx

> 标签: framework, scrapyard-io, ssd1306

## 简介

Drive ST77xx Full Color TFT displays over SPI with PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
