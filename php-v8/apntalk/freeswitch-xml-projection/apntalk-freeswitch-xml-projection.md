# apntalk/freeswitch-xml-projection

> 标签: PHP

## 简介

Standalone PHP package for rendering APNTalk SIP endpoint projections as FreeSWITCH mod_xml_curl directory XML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
