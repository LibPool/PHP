# azaelcodes/ab-experiments

> 标签: AB, AB Testing, ab experiments, ab test, experiments

## 简介

A server side AB experiments package for running AB tests on your site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
