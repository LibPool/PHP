# sgraaf/chatgpt-php

> 标签: ChatGpt, api, chatbot, client, openai, php, sdk

## 简介

A convenient PHP wrapper for the OpenAI ChatGPT API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
