# sgraaf/openai-php

> 标签: ChatGpt, GPT-3, api, client, openai, php, sdk

## 简介

A thin PHP wrapper for the OpenAI API built upon libcurl.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
