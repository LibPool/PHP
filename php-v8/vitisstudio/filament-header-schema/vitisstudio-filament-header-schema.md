# vitisstudio/filament-header-schema

> 标签: filament, filament-header-schema, laravel, vitisstudio

## 简介

Build rich Filament page headers with a schema instead of a Blade view.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
