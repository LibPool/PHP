# fooman/xero-php-oauth2

> 标签: api, openapispec, php, rest, sdk, xero

## 简介

Xero official PHP SDK for oAuth2 generated with OpenAPI spec 3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
