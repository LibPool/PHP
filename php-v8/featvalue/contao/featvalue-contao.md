# featvalue/contao

> 标签: client portal, contao, contao-bundle, featvalue

## 简介

Embeds the FeatValue client portal in a Contao website.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.featvalue.com/contao
- 源码仓库：https://github.com/FeatValue/contao-bundle.git
- Packagist 页面：https://packagist.org/packages/featvalue%2Fcontao
