# hireukraine/reverse-encoder

> 标签: AES-128-CBC, encryption, laravel, openssl

## 简介

Laravel package for reversible encryption, based on OpenSSL using AES-128-CBC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
