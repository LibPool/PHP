# mckenziearts/livewire-markdown-editor

> 标签: laravel, livewire, markdown

## 简介

GitHub-style markdown editor for Laravel with Livewire and Alpine.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
