# tillkruss/laravel-phpredis

> 标签: laravel, phpredis, redis

## 简介

A Redis driver for Laravel and Lumen that works with PhpRedis, the PCEL Redis Extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
