# nowise/uup-soap

> 标签: service, soap, uup, web, wsdl

## 简介

Export classes as SOAP service with builtin service description (WSDL) generation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
