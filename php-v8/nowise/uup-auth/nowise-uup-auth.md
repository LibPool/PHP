# nowise/uup-auth

> 标签: Authentication, auth, bmc, uup

## 简介

Flexible authentication stack supporting multiple credential obtaining methods and account validation backends.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
