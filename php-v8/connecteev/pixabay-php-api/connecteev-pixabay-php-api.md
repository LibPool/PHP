# connecteev/pixabay-php-api

> 标签: Pixabay, client, curl, http, http client, rest, web service

## 简介

PHP HTTP client library to access Pixabay's API for searching and retrieving public-domain images and videos.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
