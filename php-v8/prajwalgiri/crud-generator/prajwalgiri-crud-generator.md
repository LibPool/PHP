# prajwalgiri/crud-generator

> 标签: crud, generator, laravel, scaffold

## 简介

Laravel CRUD generator for Laravel 12+, with web and API scaffolding.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
