# mehr-als-nix/assumptions

> 标签: phpunit, testing

## 简介

Assumptions can be used to skip tests when common preconditions, like the PHP Version or installed extensions, are not met.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
