# ushainformatique/yiichimp

> 标签: framework, yiichimp

## 简介

YiiChimp is a web development framework written on top of high performance yii2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
