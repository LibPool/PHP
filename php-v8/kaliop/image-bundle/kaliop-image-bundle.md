# kaliop/image-bundle

> 标签: Webp, focal-point, ibexa, image, responsive-images, symfony, symfony-bundle

## 简介

A set of tools for managing images in Ibexa.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
