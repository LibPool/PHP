# gam6itko/ipquery-client

> 标签: IP, country, geoip, geolocation, ipquery, psr-17, psr-18

## 简介

Framework-agnostic PHP client for a self-hosted IPQuery geo service (akyriako/ipquery)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
