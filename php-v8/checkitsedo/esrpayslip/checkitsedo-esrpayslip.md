# checkitsedo/esrpayslip

> 标签: PHP

## 简介

Laravel Swiss ESR Payment Slip with Fpdf (e.g. for Invoiceninja)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
