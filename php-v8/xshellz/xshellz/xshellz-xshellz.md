# xshellz/xshellz

> 标签: gvisor, remote-execution, sandbox, ssh, xshellz

## 简介

Official PHP SDK for xShellz sandboxes: throwaway, gVisor-isolated Linux boxes you can spawn and run commands in from your own program.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
