# sitegeist/fluid-components

> 标签: components, fluid, html, template, typo3, typo3-extension, typo3-fluid

## 简介

Encapsulated frontend components with Fluid's ViewHelper syntax

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
