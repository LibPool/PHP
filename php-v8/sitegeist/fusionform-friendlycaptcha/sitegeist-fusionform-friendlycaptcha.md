# sitegeist/fusionform-friendlycaptcha

> 标签: PHP

## 简介

FriendlyCaptcha field and validator for Neos.Fusion.Form

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
