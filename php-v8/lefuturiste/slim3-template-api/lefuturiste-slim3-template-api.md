# lefuturiste/slim3-template-api

> 标签: PHP

## 简介

Slim3 template, ready to start. This is Api version of slim3 template with more lightly template.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
