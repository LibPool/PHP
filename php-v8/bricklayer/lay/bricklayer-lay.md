# bricklayer/lay

> 标签: bricklayer, fast php framework, lay, lite php framework, metaframework, php bricklayer

## 简介

A lite PHP builder meta-framework to get your projects up and running quickly

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
