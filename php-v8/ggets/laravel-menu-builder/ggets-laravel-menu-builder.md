# ggets/laravel-menu-builder

> 标签: builder, laravel, menu, wordpress

## 简介

Drag and Drop menu generator like Wordpress for Laravel 9+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
