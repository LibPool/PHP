# adcetera/adcetera_drupal

> 标签: PHP

## 简介

Adcetera Drupal - Tools for documentation, testing, and handling Internet Explorer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
