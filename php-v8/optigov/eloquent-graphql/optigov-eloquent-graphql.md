# optigov/eloquent-graphql

> 标签: api, eloquent, graphql, laravel, optiGov, orm

## 简介

This package provides automatic creation of GraphQL types and fields from Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
