# mjohann/paginated-file-reader

> 标签: PHP

## 简介

Um leitor paginado de arquivos como PDF, DOCX, ODT, TXT e MD, com estrutura extensível.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
