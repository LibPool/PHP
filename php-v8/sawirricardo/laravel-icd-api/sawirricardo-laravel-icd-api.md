# sawirricardo/laravel-icd-api

> 标签: laravel, laravel-icd-api, sawirricardo

## 简介

Use ICD codes in your laravel apps. https://icd.who.int/icdapi/

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
