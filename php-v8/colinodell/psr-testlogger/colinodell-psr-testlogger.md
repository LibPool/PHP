# colinodell/psr-testlogger

> 标签: log, logger, logging, mock, phpunit, psr, test, unit

## 简介

PSR-3 compliant test logger based on psr/log v1's, but compatible with v2 and v3 too!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
