# johnniefucker/flarum-ext-embed-video

> 标签: bbcode, dplayer, embed, flarum, flv, hls, video

## 简介

Allow users to embed video using DPlayer and BBCode

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
