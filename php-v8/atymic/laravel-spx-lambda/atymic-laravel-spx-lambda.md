# atymic/laravel-spx-lambda

> 标签: atymic, bref, lambda, laravel, octane, profiling, spx

## 简介

Trigger php-spx request profiles on Bref/Lambda and ship the reports to S3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
