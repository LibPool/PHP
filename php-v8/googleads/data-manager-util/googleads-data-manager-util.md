# googleads/data-manager-util

> 标签: ads, data-manager, google, utilities

## 简介

Utilities for working with the Data Manager API and PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://developers.google.com/data-manager
- 源码仓库：https://github.com/googleads/data-manager-php.git
- Packagist 页面：https://packagist.org/packages/googleads%2Fdata-manager-util
