# neuron-php/labor-board

> 标签: PHP

## 简介

Job queue dashboard for Neuron MVC and CMS applications: pending, delayed, reserved and failed jobs, retry, delete, dispatch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
