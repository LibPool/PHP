# kostajh/fix-suggestions

> 标签: PHP

## 简介

Generate and publish fix suggestions for MediaWiki core and extensions/skins. Currently for Gerrit, later for GitLab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
