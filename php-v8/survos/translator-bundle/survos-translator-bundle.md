# survos/translator-bundle

> 标签: PHP

## 简介

Engine-agnostic translation client bundle (Symfony 7.3 / PHP 8.4) with LibreTranslate adapter and optional caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
