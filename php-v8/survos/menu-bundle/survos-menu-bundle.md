# survos/menu-bundle

> 标签: knp-menu, menu, navigation, symfony-ux, twig

## 简介

Menus built by event listeners and drawn by composable Twig themes (Twig BlockChain), on top of knplabs/knp-menu

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
