# survos/ebay-php

> 标签: api, client, ebay, inventory, marketplace, openapi, sell

## 简介

eBay REST API client for PHP, generated from eBay's own OpenAPI 3 contracts. Framework-agnostic -- usable from Symfony, WordPress, or plain PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
