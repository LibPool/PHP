# survos/record-store

> 标签: PHP

## 简介

Provider-neutral contracts and models for application-backend record stores (Grist, Quickbase, ...). Framework-agnostic: no Symfony kernel, no container.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
