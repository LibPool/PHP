# survos/zebra-bundle

> 标签: labelary, symfony, thermal-printer, twig-component, zebra, zpl

## 简介

Symfony bundle for Zebra ZPL preview and printing workflows

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
