# survos/cloudflared-bundle

> 标签: cloudflare, cloudflared, dev, symfony, tunnel

## 简介

Expose a local Symfony dev app through a named cloudflared tunnel: derive its public URL from the running tunnel, probe that the tunnel really answers from this machine, and generate ingress from the Symfony CLI proxy index.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
