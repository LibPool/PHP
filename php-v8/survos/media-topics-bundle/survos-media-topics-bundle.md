# survos/media-topics-bundle

> 标签: IPTC, media-topics, newscodes, taxonomy, vocabulary

## 简介

IPTC Media Topics in a Symfony app: the vocabulary as a service, plus console commands and agent tools to browse and search it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
