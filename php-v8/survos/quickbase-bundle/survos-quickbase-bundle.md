# survos/quickbase-bundle

> 标签: api, integration, quickbase, symfony

## 简介

Symfony integration for the Quickbase JSON REST API, with a scoped client and record upserts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
