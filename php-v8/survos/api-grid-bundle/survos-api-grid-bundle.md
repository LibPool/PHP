# survos/api-grid-bundle

> 标签: symfony-bundle, symfony-ux

## 简介

incorporate DatatablesNet, using twig and stimulus, twig_component requires ^2.2

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
