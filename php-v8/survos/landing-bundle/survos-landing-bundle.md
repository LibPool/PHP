# survos/landing-bundle

> 标签: Skeleton, generator, symfony4, symfony5

## 简介

Add some tools and resources to a Symfony4.4/Symfony5 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
