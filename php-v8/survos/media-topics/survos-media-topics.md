# survos/media-topics

> 标签: IPTC, classification, genre, media-topics, newscodes, taxonomy, vocabulary

## 简介

IPTC Media Topics and Genre as a PHP library: the pinned vocabularies with hierarchy, translations, Wikidata and Subject Code mappings

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
