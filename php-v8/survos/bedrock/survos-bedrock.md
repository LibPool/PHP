# survos/bedrock

> 标签: PHP

## 简介

Makes a Roots Bedrock WordPress site work under the Symfony CLI local server: directory index, DB_PORT folding, and a shared installer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
