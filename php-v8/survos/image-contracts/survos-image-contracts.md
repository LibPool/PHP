# survos/image-contracts

> 标签: contracts, image, imagor, imgproxy, thumbnail

## 简介

Backend-neutral contracts for image URL building (imgproxy, imagor) and image metadata.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
