# survos/youtube-bundle

> 标签: oauth, symfony, upload, youtube

## 简介

YouTube channel fetching and resumable uploads for Symfony, powered by Google's official PHP client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
