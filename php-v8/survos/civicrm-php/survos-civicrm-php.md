# survos/civicrm-php

> 标签: api, apiv4, civicrm, crm

## 简介

CiviCRM APIv4 REST client. Framework-agnostic -- usable from Symfony, WordPress, or plain PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
