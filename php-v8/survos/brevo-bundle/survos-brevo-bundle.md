# survos/brevo-bundle

> 标签: brevo, email, newsletter, sendinblue, symfony, webhook

## 简介

Brevo (ex-Sendinblue) for Symfony: the official SDK on Symfony HttpClient, list/campaign commands, and webhook events re-dispatched for any listener.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
