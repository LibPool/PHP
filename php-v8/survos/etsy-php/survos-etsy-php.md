# survos/etsy-php

> 标签: api, client, etsy, listings, marketplace, openapi

## 简介

Etsy Open API v3 client for PHP, generated from Etsy's own OpenAPI 3 contract. Framework-agnostic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
