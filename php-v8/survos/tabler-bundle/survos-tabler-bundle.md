# survos/tabler-bundle

> 标签: symfony, symfony-ux

## 简介

Add some tools and resources to a Symfony 7.4/8 application, based on Tabler (tabler.io)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
