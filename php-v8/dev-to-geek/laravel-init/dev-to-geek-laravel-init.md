# dev-to-geek/laravel-init

> 标签: Dev2Geek, laravel, laravel-init

## 简介

A little package I use to add preconfigured tools (PHPStan, Larastan, Pint, Pail, ...) to my projects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
