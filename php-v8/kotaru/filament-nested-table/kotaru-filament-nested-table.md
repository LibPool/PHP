# kotaru/filament-nested-table

> 标签: drag-drop, filament, filament-nested-table, filamentphp, hierarchical, laravel, nested-set, pjedesigns, table, tree

## 简介

A Filament table component for displaying and managing nested set data structures with drag-and-drop reordering support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
