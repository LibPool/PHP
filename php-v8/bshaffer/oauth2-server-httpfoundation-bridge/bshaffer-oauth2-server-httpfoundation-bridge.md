# bshaffer/oauth2-server-httpfoundation-bridge

> 标签: auth, httpfoundation, oauth, oauth2

## 简介

A bridge to HttpFoundation for oauth2-server-php

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
