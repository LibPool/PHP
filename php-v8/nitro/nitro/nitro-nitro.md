# nitro/nitro

> 标签: blade, compiler, components, framework, full-stack, laravel, nitro, reactive

## 简介

A full-stack framework for Laravel. Write components in PHP and Blade; Nitro compiles them to JavaScript that runs in the browser, and calls the server only when you ask it to.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
