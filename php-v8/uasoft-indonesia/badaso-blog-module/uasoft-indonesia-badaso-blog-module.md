# uasoft-indonesia/badaso-blog-module

> 标签: admin, badaso, blog, dashboard, generator, laravel, news, panel, post, pwa, vue

## 简介

Post system on badaso, create blog & news site faster

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
