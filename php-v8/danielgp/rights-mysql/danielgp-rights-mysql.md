# danielgp/rights-mysql

> 标签: PHP

## 简介

Creates a dump of all MySQL accounts and their respective rights in a web page (ideal for MySQL upgrade or relocation)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
