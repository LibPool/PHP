# meysampg/yii2-formbuilder

> 标签: JS, extension, form, form-builder, yii2

## 简介

A drag and drop form builder with jQuery for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
