# meysampg/jqueryui-jtimepicker-addon

> 标签: PHP

## 简介

The jDateTimePicker addon adds a timepicker to jQuery UI Datepicker with support Jalali calendar.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
