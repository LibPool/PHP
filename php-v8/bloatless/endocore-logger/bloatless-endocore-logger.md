# bloatless/endocore-logger

> 标签: bloatless, endocore, file-logger, logger, null-logger, php, psr-3

## 简介

Logger component for the Endocore framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
