# bloatless/endocore-phtml-renderer

> 标签: bloatless, endocore, php, phtml, renderer, templating

## 简介

Phtml renderer component for the Endocore framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
