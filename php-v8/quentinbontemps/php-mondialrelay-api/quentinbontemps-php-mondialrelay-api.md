# quentinbontemps/php-mondialrelay-api

> 标签: PHP

## 简介

A PHP library for dealing with Mondial Relay API (http://api.mondialrelay.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
