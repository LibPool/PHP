# ifabula/sevola-sdk-php

> 标签: encryption, format-preserving, fpe, sdk, sevola

## 简介

PHP SDK for Sevola encryption service - Format-preserving and AES-GCM encryption

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
