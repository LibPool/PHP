# luilliarcec/laravel-imgur

> 标签: imgur, laravel, laravel-imgur, luilliarcec

## 简介

A simple package that allows interaction between Imgur and its application

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
