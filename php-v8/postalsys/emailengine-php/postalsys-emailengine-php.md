# postalsys/emailengine-php

> 标签: api, email, emailengine, imap, sdk, smtp

## 简介

Modern PHP SDK for EmailEngine - Send and receive emails via REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
