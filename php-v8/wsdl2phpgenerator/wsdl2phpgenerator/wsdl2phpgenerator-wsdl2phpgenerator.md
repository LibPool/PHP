# wsdl2phpgenerator/wsdl2phpgenerator

> 标签: soap, wsdl

## 简介

Simple class library for generating php classes from a wsdl file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
