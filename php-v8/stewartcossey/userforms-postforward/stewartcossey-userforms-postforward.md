# stewartcossey/userforms-postforward

> 标签: forwarding, post, post forwarding, silverstripe, userforms

## 简介

Allows you to forward POST forms to an additional URL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
