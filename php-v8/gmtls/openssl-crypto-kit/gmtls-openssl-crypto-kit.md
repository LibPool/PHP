# gmtls/openssl-crypto-kit

> 标签: decryption, ec, encryption, openssl, rsa, signing, verification

## 简介

A modern and extensible PHP cryptography toolkit powered by OpenSSL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
