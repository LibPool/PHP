# dilneiss/laravel-migrations-generator

> 标签: artisan, generator, laravel, lumen, migration, migrations

## 简介

Generates Laravel Migrations from an existing database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
