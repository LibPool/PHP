# hcancelik/sidecar-browsershot

> 标签: browsershot, hcancelik, lambda, laravel, sidecar, sidecar-browsershot

## 简介

A Sidecar function to run Browsershot on Lambda.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
