# jonesrussell/x-suite-laravel

> 标签: inertia, laravel, social-media, twitter, vue, x

## 简介

X (Twitter) integration suite for Laravel — posting, analytics, trends, auto-replies, and content discovery with Vue 3 + Inertia admin UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
