# sopheak/sp-jwt-auth

> 标签: Authentication, api-key, jwt, laravel, oauth

## 简介

First-party JWT access and rotating refresh token authentication for Laravel apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
