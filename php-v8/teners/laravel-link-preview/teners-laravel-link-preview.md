# teners/laravel-link-preview

> 标签: HTML Parser, caching, content preview, laravel, laravel package, link extractor, link information, link preview, metadata, parsing, php, teners, web scraping

## 简介

A Laravel package for extracting link previews with customizable parsers, and caching support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
