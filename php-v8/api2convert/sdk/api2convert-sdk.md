# api2convert/sdk

> 标签: OCR, api, api2convert, audio, convert, file conversion, image, pdf, sdk, video

## 简介

Official PHP SDK for the API2Convert file-conversion API. Convert, compress and transform images, documents, audio, video, ebooks, archives and CAD with one line of code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
