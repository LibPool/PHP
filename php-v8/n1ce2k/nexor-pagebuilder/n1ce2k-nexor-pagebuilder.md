# n1ce2k/nexor-pagebuilder

> 标签: blocks, cms, laravel, nexor, page-builder

## 简介

Модуль «Конструктор страниц» для NEXOR CMS: детальная страница элемента из блоков.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
