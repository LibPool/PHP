# n1ce2k/nexor-cms

> 标签: admin, cms, infoblocks, laravel, nexor

## 简介

NEXOR CMS — админ-панель для Laravel с инфоблоками, свойствами произвольных типов и системой ролей.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
