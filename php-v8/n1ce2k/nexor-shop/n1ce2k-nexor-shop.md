# n1ce2k/nexor-shop

> 标签: cart, cms, laravel, nexor, shop

## 简介

Модуль «Магазин» для NEXOR CMS: корзина Basic и Ultimate, промокоды, оформление и заказы.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
