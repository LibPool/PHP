# parabellumkoval/backpack-settings

> 标签: PHP

## 简介

Settings UI & Service for Laravel 8 + Backpack 4.1 (config/DB drivers, tabs, registry, aliases).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
