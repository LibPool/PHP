# synaq/zasa-bundle

> 标签: Symfony2, api, zimbra

## 简介

A Symfony2 wrapper for the Zimbra Soap Admin API (ZASA)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
