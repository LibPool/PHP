# triadev/laravel-elasticsearch-mapping

> 标签: elasticsearch, laravel, mapping

## 简介

A service provider for laravel with a fluent elasticsearch mapping builder.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
