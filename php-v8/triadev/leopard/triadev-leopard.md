# triadev/leopard

> 标签: elasticsearch, laravel, odm

## 简介

Leopard is an elasticsearch odm (Object Document Mapper) for laravel eloquent.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
