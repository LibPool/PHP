# becklyn/mimeo

> 标签: Becklyn, mirror, npm, package.json, symfony

## 简介

Mimeo: copy (static) assets from NPM packages into your symfony project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
