# becklyn/icon-loader

> 标签: Becklyn, cache, icons, loader, symfony

## 简介

Icon Loader: loads (svg) icons from different directories, provides a twig function and caches them.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
