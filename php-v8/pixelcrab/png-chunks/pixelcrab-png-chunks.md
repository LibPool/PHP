# pixelcrab/png-chunks

> 标签: add, chunks, class, get, php, png, remove

## 简介

Simple PHP class to handle(get, add, remove) PNG chunks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
