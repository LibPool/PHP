# haridarshan/laravel-url-signer-cloudfront

> 标签: aws, aws-php-sdk, aws-sdk-php-laravel, cloudfront, laravel-url-signer-cloudfront, private content, signed-cookie, signed-url

## 简介

Wrapper around the official AWS PHP SDK to generate CloudFront signed URLs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
