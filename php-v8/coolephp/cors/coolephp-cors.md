# coolephp/cors

> 标签: api, coole, cors, crossdomain

## 简介

Adds CORS (Cross-Origin Resource Sharing) headers support in Coole application. - 在 Coole 应用程序中添加 CORS（跨源资源共享）头支持。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
