# xyqweb/yii2-queue

> 标签: gii, queue, rabbitmq, yii

## 简介

Yii2 Queue Extension which supported RabbitMQ

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
