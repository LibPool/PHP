# x-blade/x-blade-visitor-tracker

> 标签: laravel, tracker, visitor, x-blade

## 简介

A simple Laravel package to track website visitors and store them in a JSON file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
