# salimi-my/admin-dashboard-template

> 标签: admin, dashboard, inertia, laravel, react, shadcn, starter-kit, tailwindcss

## 简介

A Laravel and Inertia React admin dashboard starter kit with a floating sidebar layout, users datatable, settings, and authentication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
