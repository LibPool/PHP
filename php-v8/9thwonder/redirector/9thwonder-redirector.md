# 9thwonder/redirector

> 标签: Craft, cms, craft-plugin, craftcms, redirector

## 简介

Automatically creates Retour static redirects using an entry dump.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
