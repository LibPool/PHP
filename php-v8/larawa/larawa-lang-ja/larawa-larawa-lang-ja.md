# larawa/larawa-lang-ja

> 标签: japanese, language-pack, larawa, larawa-plugin, translation

## 简介

Japanese dashboard language plugin for LaraWA.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://lara-wa.org
- 源码仓库：https://github.com/larawa-community/larawa-lang-ja.git
- Packagist 页面：https://packagist.org/packages/larawa%2Flarawa-lang-ja

## 历史版本号

## 获取地址

- Composer 安装：`composer require larawa/larawa-lang-ja`
- Packagist 仓库：https://repo.packagist.org/p2/larawa/larawa-lang-ja.json
