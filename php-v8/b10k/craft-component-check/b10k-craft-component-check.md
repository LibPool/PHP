# b10k/craft-component-check

> 标签: AI Agents, Craft, ci, cms, components, craft-plugin, craftcms, matrix, page builder, playwright, regression testing, smoke test, testing

## 简介

Craft tells Playwright what to test: finds where every Matrix block is actually used and runs desktop + mobile browser checks on those pages, without writing a single test.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
