# b10k/craft-component-guide

> 标签: Craft, authoring experience, block preview, blocks, cms, component library, components, craft-plugin, craftcms, design system, live preview, matrix, matrix blocks, page builder, storybook, twig

## 简介

A Storybook-style component browser inside the control panel — live previews for developers, a visual blocks gallery for editors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
