# deployecommerce/module-local-dev-tooling

> 标签: PHP

## 简介

Local development tooling for Magento 2: admin auto-login, 2FA bypass and a fixed /admin/ path on local hostnames. Dev dependency only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
