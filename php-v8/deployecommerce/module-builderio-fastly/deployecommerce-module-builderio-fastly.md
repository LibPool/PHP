# deployecommerce/module-builderio-fastly

> 标签: adobe commerce, builder.io, magento, magento2

## 简介

A magento 2 extensions that renders Builder.io content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
