# togomq/togomq-sdk

> 标签: gRPC, message-queue, messaging, pub-sub, sdk, togomq

## 简介

Official PHP SDK for TogoMQ - A modern, high-performance message queue service

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
