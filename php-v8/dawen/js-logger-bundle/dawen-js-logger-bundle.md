# dawen/js-logger-bundle

> 标签: javascript, logger, monolog, symfony

## 简介

A bundle that catches javascript errors and passes them to monolog for Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
