# kowts/sisp-cv

> 标签: cabo-verde, laravel, pagamentos, sisp, symfony, vinti4, yii2

## 简介

Biblioteca PHP pura para pagamentos SISP/Vinti4 de Cabo Verde.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
