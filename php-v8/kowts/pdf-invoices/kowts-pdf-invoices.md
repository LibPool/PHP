# kowts/pdf-invoices

> 标签: billing, dompdf, fatura, faturas, invoice, invoices, laravel, pdf, symfony, yii2

## 简介

Biblioteca PHP independente de frameworks para gerar faturas PDF.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
