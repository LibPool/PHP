# limen-ai/limen-ai

> 标签: Agent, ai, laravel, llm, rag, tools, workflows

## 简介

A reusable Laravel AI Agent Framework with agents, runtime, tools, skills, workflows, memory, knowledge, and chat UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
