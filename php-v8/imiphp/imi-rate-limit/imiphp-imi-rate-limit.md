# imiphp/imi-rate-limit

> 标签: PHP

## 简介

imi 框架的限流组件，可以针对方法、接口设置限流，通过设置总容量、单位时间内生成填充的数量、每次扣除数量实现限流。QQ群：17916227

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
