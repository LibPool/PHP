# imiphp/imi-amqp

> 标签: PHP

## 简介

支持在 imi 框架中使用 支持 AMQP 协议的消息队列，如：RabbitMQ

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
