# dpay/dpay-php

> 标签: checkout, dPay, edfali, libya, moamalat, mobicash, payments, sadad, sdk, webhooks

## 简介

Official DPay PHP SDK — hosted checkout sessions, payment sessions (EDFali, Sadad, MobiCash, MITF banks, Moamalat, Mastercard), signed webhooks and the sandbox, for PHP 8.1+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
