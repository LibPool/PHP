# davodm/dgcontent-ci

> 标签: API-Client, caching, codeigniter4, content-api, dg-content-ci, php

## 简介

A simple CodeIgniter 4 package to interact with DGTTeam Content API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
