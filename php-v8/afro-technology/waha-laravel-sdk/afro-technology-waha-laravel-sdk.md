# afro-technology/waha-laravel-sdk

> 标签: laravel, openapi, sdk, waha, whatsapp

## 简介

Laravel SDK for WAHA with multi-host, optional DB pinning, and OpenAPI generated client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
