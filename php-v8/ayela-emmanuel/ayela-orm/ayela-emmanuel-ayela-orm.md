# ayela-emmanuel/ayela-orm

> 标签: PHP

## 简介

This packge Is a Minimal ORM Setup for interacting with your SQL Database using PDO but abstracts the Database to a more OOP Approch

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
