# hdelacerna/php-crypto-utils

> 标签: PHP

## 简介

A lightweight PHP library for AES-256-CBC encryption/decryption using OpenSSL-compatible key derivation and formatting.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
