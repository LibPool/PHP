# mmt/laravel-feature-scaffold

> 标签: PHP

## 简介

Artisan commands to scaffold Laravel feature structure (make:feature, make:feature-model, make:feature-job, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
