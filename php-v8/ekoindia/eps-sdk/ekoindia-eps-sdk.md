# ekoindia/eps-sdk

> 标签: aeps, bbps, dmt, eko, eps, fintech, india, payments, sdk

## 简介

Backend-only PHP SDK for Eko Platform Services (EPS) APIs, with request signing built in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
