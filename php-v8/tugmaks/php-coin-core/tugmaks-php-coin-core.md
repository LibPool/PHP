# tugmaks/php-coin-core

> 标签: Bitcoin Core, Litecoin Core, client, rpc

## 简介

Simple php library for interacting with Litecoin/Bitcoin Core wallet via json rpc

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
