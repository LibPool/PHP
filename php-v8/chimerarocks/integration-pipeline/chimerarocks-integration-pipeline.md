# chimerarocks/integration-pipeline

> 标签: PHP

## 简介

Pacote para criação de microserviços de normalização de dados entre aplicações e o Espelho.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
