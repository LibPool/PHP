# mavenbird/module-admin-category-product-thumbnail

> 标签: PHP

## 简介

The Admin Category Product Thumbnail module enhances Magento 2's admin interface by providing administrators with the ability to view and manage product thumbnails directly within the category management screen. This module improves the visual organization of products, making it easier to identify and manage product listings in the admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
