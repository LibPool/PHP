# mavenbird/module-admin-category-product-link

> 标签: PHP

## 简介

The Admin Category Product Link module enhances Magento 2's admin interface by allowing administrators to efficiently link products to categories directly from the category management screen. This module simplifies stock updates, improves product organization, and streamlines category management processes, making it easier to manage large product catalogs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
