# rcm/responsive-hover-image

> 标签: PHP

## 简介

RCM block that provides a responsive image that can change when hovering over it. Also allows the image to be a link.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
