# rcm/brightcove

> 标签: content, manager, plugin, rcm, reliv

## 简介

Provides a Brightcove player integration for the Reliv Content Manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
