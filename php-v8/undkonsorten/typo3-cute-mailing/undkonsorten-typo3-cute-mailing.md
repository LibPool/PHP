# undkonsorten/typo3-cute-mailing

> 标签: direct_mail, email, newsletter, typo3

## 简介

A TYPO3 extension that makes mailing and newsletter sending cute. Send TYPO3 pages as emails (newsletter) to many recipients. Can be used as replacement for direct_mail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
