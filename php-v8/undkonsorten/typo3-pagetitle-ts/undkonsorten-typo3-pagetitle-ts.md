# undkonsorten/typo3-pagetitle-ts

> 标签: TypoScript, pagetitle

## 简介

TYPO3 extension to access the final page title, built by the PageTitle API, within TypoScript

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
