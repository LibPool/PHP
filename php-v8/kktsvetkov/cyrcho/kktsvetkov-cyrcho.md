# kktsvetkov/cyrcho

> 标签: cyrcho, cyrillic, latin, transliteration

## 简介

Converts cyrillic into latin using the correct transliteration rules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
