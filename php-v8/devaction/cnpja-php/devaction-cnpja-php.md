# devaction/cnpja-php

> 标签: cnpj, cnpjá, laravel, php, sdk

## 简介

PHP SDK for the CNPJá API — CNPJ, ZIP, RFB, Simples Nacional, CCC and SUFRAMA lookups.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
