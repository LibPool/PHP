# eboost/exact-target

> 标签: api, data extension, email, exacttarget, salesforce, soap

## 简介

Package to send an email to a data extention in salesforce using the ExactTarget SOAP api

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
