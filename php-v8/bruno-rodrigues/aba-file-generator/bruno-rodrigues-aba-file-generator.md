# bruno-rodrigues/aba-file-generator

> 标签: PHP

## 简介

Generate ABA bank transaction files from a collection of transactions. Forked from simonblee/aba-file-generator

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
