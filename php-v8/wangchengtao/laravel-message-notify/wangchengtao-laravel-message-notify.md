# wangchengtao/laravel-message-notify

> 标签: Feishu, dingtalk, exception, laravel, notify

## 简介

laravel 框架适配异常监控通知, 支持钉钉群机器人, 飞书群机器人以及自定义通道

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
