# spinningcatstudios/lingara-embed

> 标签: embed, language-learning, lingara, psr-7, webhooks

## 简介

The official Lingara embed server kit for PHP: mint player tokens, route signed webhooks to your players, and render the widget snippet.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
