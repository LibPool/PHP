# spinningcatstudios/lingara

> 标签: api, language-learning, lingara, psr-18, server-sent-events

## 简介

The official PHP library for the Lingara API: PSR-18 calls, foreach event streams, and OAuth client credentials.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
