# sesamy/sesamy-wordpress

> 标签: paywall, sesamy, subscriptions, wordpress

## 简介

Add Sesamy functionality (sesamy.com) to your WordPress website.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
