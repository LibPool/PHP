# fileeye/linuxlibertine-fonts

> 标签: PHP

## 简介

Linux Libertine and Biolinum fonts repackaged for Composer builds.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/FileEye/linuxlibertine-fonts
- 源码仓库：https://github.com/FileEye/linuxlibertine-fonts.git
- Packagist 页面：https://packagist.org/packages/fileeye%2Flinuxlibertine-fonts
