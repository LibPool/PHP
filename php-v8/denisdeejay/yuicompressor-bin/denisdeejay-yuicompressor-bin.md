# denisdeejay/yuicompressor-bin

> 标签: assetic, compressor, css, jar, javascript, minification, yui

## 简介

yuicompressor jar file ready for composer and packagist. Javascript and CSS minification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
