# denisdeejay/pdfparser

> 标签: extract, parse, parser, pdf, text

## 简介

(fork of smalot/pdfparser) Pdf parser library. Can read and extract information from pdf file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
