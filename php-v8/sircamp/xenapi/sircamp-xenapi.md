# sircamp/xenapi

> 标签: api, citrix, citrixapi, hypervisor, laravel, phpxenapi, vps, xen, xmlrpc

## 简介

A Xen PHP API for managment of Hypervisor and their Virtual Machine for php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
