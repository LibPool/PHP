# cfxmarkets/php-exchange-sdk

> 标签: api, cfx, cfxmarkets, client, exchange, sdk

## 简介

A public PHP SDK for accessing the CFX Markets exchange

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
