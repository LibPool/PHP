# openwines/references-bundle

> 标签: PIM, akeneo, openwines, reference data, wine

## 简介

Wine industry references data manager for OpenWines - Akeneo PIM Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
