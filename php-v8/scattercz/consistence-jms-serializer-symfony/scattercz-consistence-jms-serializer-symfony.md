# scattercz/consistence-jms-serializer-symfony

> 标签: PHP

## 简介

Symfony Bundle integrating Consistence library and JMS Serializer with Symfony 5 support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
