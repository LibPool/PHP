# sifadi/core

> 标签: cfdi, factura electronica, facturacion, mexico, pac, sat, sdk, sifadi, timbrado

## 简介

SDK PHP (framework-agnostic) para la API de Sifadi: timbra CFDI 4.0, cancela, descarga XML/PDF y consulta tu saldo de timbres.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
