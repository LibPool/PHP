# sifadi/laravel

> 标签: cfdi, factura electronica, facturacion, laravel, mexico, sat, sdk, sifadi, timbrado

## 简介

Integración de Sifadi para Laravel: ServiceProvider, Facade y config sobre el SDK sifadi/core (timbra CFDI 4.0 por API).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
