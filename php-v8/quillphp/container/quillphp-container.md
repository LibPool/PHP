# quillphp/container

> 标签: Autowiring, container, di, php, quill

## 简介

First-class DI container with autowiring for Quill PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://quillphp.com
- 源码仓库：https://github.com/quillphp/quill-container.git
- Packagist 页面：https://packagist.org/packages/quillphp%2Fcontainer

- Composer 安装：`composer require quillphp/container`
