# lucasbrito-wdt/correios

> 标签: correios, cws, etiqueta, frete, laravel, pre-postagem, rastreio

## 简介

Pacote Laravel para integração com as APIs do CWS (Correios Web Services) — Token, CEP, Preço, Prazo, Rastro e Pré-Postagem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
