# gitsbt/waylume-sdk

> 标签: guide, navigation, onboarding, sdk, tour, waylume

## 简介

Waylume SDK for adding multi-page navigation guides to PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
