# hkp22/laravel-reactions

> 标签: Rate, Rating, Unlike, dislike, eloquent, emotion, favorite, favourite, kudos, laravel, like, love, reaction, star

## 简介

Implement reactions (like, dislike, love, emotion etc) on Laravel Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
