# divad942/yii2-excel

> 标签: Active Record, PHPExcel, excel, export, import, yii2

## 简介

ActiveRecord import and export based on PHPExcel for Yii 2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
