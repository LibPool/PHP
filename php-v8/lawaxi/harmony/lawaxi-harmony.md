# lawaxi/harmony

> 标签: China, extension, flarum

## 简介

将未登录时的论坛伪装成博客 (用于中国大陆个人备案)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
