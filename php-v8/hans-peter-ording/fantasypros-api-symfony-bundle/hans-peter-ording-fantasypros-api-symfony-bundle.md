# hans-peter-ording/fantasypros-api-symfony-bundle

> 标签: PHP

## 简介

Symfony bundle to import NFL data from the FantasyPros public API into Doctrine entities via Symfony Messenger.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
