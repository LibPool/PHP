# hans-peter-ording/sleeper-api-client

> 标签: PHP

## 简介

Client library to consume the sleeper API (https://docs.sleeper.app/) and transform results into data transfer objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
