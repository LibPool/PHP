# codebes/gripp-sdk

> 标签: ERP, Gripp, Guzzle, api, crm, exact, exact-gripp, exact-online, invoicing, json-rpc, laravel, php, project-management, sdk, time-tracking

## 简介

PHP SDK for the Gripp CRM/ERP API. Fluent query builder, batch operations, and 54 resources for project management, invoicing, time tracking, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
