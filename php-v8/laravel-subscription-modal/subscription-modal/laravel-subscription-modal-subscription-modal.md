# laravel-subscription-modal/subscription-modal

> 标签: PHP

## 简介

Paquete para mostrar un modal de suscripción en la parte inferior derecha de aplicaciones Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
