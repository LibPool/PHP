# nyumbani/docs

> 标签: docs, laravel, nyumbani

## 简介

The docs engine of the Nyumbani packages: a page shell, interactive components and live demos, served only in the local environment, with its own styles and scripts so it works in any Laravel app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
