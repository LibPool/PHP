# nyumbani/daraja

> 标签: daraja, laravel, mpesa, safaricom

## 简介

A small Laravel client for Safaricom's Daraja API: STK push, C2B and Pull transactions, with the payloads, events and middleware to receive them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
