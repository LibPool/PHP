# nyumbani/messaging

> 标签: laravel, messaging, nyumbani, sms

## 简介

Queue SMS from any Nyumbani app through Nyumbani Connect: a message builder, handlers, rate-limited and retried delivery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
