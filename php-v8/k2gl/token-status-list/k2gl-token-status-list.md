# k2gl/token-status-list

> 标签: eudi, identity, jwt, openid4vc, revocation, sd-jwt, sd-jwt-vc, status-list, token-status-list, verifiable-credentials

## 简介

Token Status List (draft-ietf-oauth-status-list) in pure PHP: publish and check revocation status for JWTs, SD-JWTs and SD-JWT VCs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
