# k2gl/sd-jwt

> 标签: JWS, digital-identity, eudi, jwt, key-binding, openid4vc, rfc9901, sd-jwt, selective-disclosure, verifiable-credentials

## 简介

Selective Disclosure for JWTs (SD-JWT, RFC 9901) in pure PHP: issue, present, verify

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
