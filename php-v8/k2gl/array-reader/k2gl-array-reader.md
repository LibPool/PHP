# k2gl/array-reader

> 标签: PHPStan, array, casting, dto, json, psalm, type-safe, typed

## 简介

Read typed values from untyped arrays (JSON, CSV, config, request data) in PHP, with strict and lenient modes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
