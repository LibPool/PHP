# k2gl/signed-note

> 标签: Ed25519, checkpoint, note, rekor, signed-note, signing, sigstore, sumdb, supply-chain, transparency-log

## 简介

Parse, verify and sign signed notes — the transparency-log / Go sumdb format used by Sigstore Rekor checkpoints — in PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
