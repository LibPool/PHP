# lemoonade/laravel-analytics

> 标签: analytics, google, laravel, reports, retrieve, spatie

## 简介

A Laravel 5 package to retrieve Google Analytics data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
