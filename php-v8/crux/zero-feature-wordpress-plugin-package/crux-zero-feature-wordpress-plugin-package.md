# crux/zero-feature-wordpress-plugin-package

> 标签: PHP

## 简介

This package does exactly nothing. It bundles a WordPress plugin and is for Packagist and Composer usage in conjunction with WordPress demonstration purposes only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
