# codealist/module-contentbuilder

> 标签: PHP

## 简介

Codealist ContentBuilder library. It includes ContentBuilder rich text editor library into Magento Admin Panel CMS editor

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
