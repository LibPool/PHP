# podlove/podlove-timeline

> 标签: chapter, converter, mp4chaps, parser, podlove, psc, webvtt

## 简介

PHP library providing a toolkit to handle various timeline/chapter formats.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
