# heimseiten/contao-lesbares-css-framework-bundle

> 标签: backend, contao, css, framework, styles

## 简介

Lesbares CSS-Framework für Contao samt deutschem Klassen-Selektor im Backend (Artikel & Inhaltselemente).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
