# heimseiten/contao-settings-units-bundle

> 标签: Einheiten, Einstellungen, Speicherzeit, Upload-Dateigröße, backend

## 简介

Speicherzeiten und maximale Upload-Dateigröße in den Systemeinstellungen mit Einheitenauswahl eingeben: Tage statt Sekunden, MB statt Byte. Gespeichert wird unverändert der Wert in Sekunden bzw. Byte, eine Deinstallation ändert die Einstellungen also nicht.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
