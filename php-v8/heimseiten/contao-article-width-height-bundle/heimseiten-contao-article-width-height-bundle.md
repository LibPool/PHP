# heimseiten/contao-article-width-height-bundle

> 标签: Breite, Höhe, artikel

## 简介

Ermöglicht die Eingabe einer maximalen Breite und minimalen Höhe eines Artikels.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
