# heimseiten/contao-text-image-positioning-bundle

> 标签: flexbox

## 简介

Fügt Positionierungsoptionen im Textelement hinzu. Verfügbare Optionen, siehe: https://github.com/heimseiten/contao-text-image-positioning-bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
