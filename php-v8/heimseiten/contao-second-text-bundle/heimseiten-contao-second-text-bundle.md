# heimseiten/contao-second-text-bundle

> 标签: zweites Textfeld

## 简介

Fügt ein zweites Textfeld zu dem Inhaltselement 'Text' hinzu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
