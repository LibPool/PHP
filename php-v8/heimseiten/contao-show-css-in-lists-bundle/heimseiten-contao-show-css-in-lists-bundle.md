# heimseiten/contao-show-css-in-lists-bundle

> 标签: backend, contao, css, listing

## 简介

Zeigt CSS-IDs und CSS-Klassen in den Backend-Listenansichten (Seiten, Artikel, Inhaltselemente) von Contao an – pro Benutzer einschaltbar.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
