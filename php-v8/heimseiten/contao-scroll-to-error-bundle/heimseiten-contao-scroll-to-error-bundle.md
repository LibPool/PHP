# heimseiten/contao-scroll-to-error-bundle

> 标签: error, scroll

## 简介

Wenn ein Formular einen Fehler meldet, scrollt die Webseite an die Stelle des Fehlers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
