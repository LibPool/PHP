# safi/laralcn-ui

> 标签: blade, components, laravel, shadcn, tailwind, ui

## 简介

LaralCN-UI: a shadcn-style copy-and-own Blade component installer for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
