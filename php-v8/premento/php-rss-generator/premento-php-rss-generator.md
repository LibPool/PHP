# premento/php-rss-generator

> 标签: Facebook product feed generator, feed, generator, rss, writer

## 简介

Simple RSS generator library for PHP 5.5 or later.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
