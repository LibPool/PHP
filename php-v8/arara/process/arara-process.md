# arara/process

> 标签: command, daemon, fork, multitasking, pcntl, posix, process, spawn, task

## 简介

Provides a better API to work with processes on Unix-like systems

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
