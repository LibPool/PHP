# ricardoneudorfer/stripekit

> 标签: billing, checkout, elements, invoices, payments, php, stripe, subscriptions

## 简介

A complete, production-ready Stripe integration toolkit for PHP. Handles customers, payment methods, payments, checkout, subscriptions, invoices, coupons, webhooks and Stripe Elements with built-in timezone handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
