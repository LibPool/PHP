# magestat/module-cookie-law-banner

> 标签: cookie law banner, cookie message, magento 2, magento 2 cookie, magento 2 extension, magento 2 module

## 简介

This extension allows you enable an EU compliant consent cookie notification banner.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
