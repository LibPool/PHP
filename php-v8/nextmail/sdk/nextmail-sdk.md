# nextmail/sdk

> 标签: api, api client, email, email api, email templates, inbox, mailbox, nextmail, psr-18, sdk, send email, temp mail, transactional email, webhooks

## 简介

The official PHP SDK for the Nextmail API. Send email and broadcasts, work with threads, drafts, labels, templates, rules, webhooks, tracking, contacts, audiences, sign-up forms, domains, suppressions, files, API keys, roles, members, mailbox imports and disposable inboxes from PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
