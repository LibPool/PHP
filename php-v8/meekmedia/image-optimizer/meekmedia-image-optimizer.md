# meekmedia/image-optimizer

> 标签: MozJPEG, Webp, browser, client-side, compression, image, optimizer, oxipng, wasm

## 简介

Private, client-side image compression widget for any PHP site. MozJPEG, WebP and OxiPNG via WebAssembly - images never leave the visitor's browser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
