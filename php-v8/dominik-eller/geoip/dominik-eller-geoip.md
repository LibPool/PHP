# dominik-eller/geoip

> 标签: GeoTargets, criteria_id, geo, google ads, location, lookup

## 简介

Google Ads GeoTargets CSV updater and lookup as a reusable PHP 8.4 Composer package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
