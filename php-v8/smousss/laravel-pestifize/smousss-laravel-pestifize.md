# smousss/laravel-pestifize

> 标签: ChatGpt, GPT-3, ai, artificial intelligence, automated testing, gpt-4, laravel, openai, pest, phpunit, smousss, smousss pestifize, testing, unit testing

## 简介

Convert PHPUnit tests to Pest 2 using GPT-4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
