# autodoctor/vkmodule-socket

> 标签: client, library, php-driver, remote-control, smart-home, vkmodule

## 简介

PHP driver library for use with VKmodule 'Socket-N' type electronic devices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
