# toolstud-io/si_format

> 标签: si_format, toolstud-io

## 简介

PHP package to format numbers according to SI standards (milli, micro, nano... / Kilo, Mega, Giga...)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
