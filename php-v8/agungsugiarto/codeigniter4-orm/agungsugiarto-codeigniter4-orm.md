# agungsugiarto/codeigniter4-orm

> 标签: builder, codeigniter4, model, orm, query

## 简介

A Fluent ORM based model and query builder for CodeIgniter4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
