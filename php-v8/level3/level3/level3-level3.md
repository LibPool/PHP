# level3/level3

> 标签: HATEOAS, hal, rest, restfull

## 简介

A RESTful API builder based on 3-level model (URI, HTTP and Hypermedia)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
