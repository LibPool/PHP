# yramid/cli

> 标签: console, database, database migrations, db, migrations, pdo, symfony

## 简介

yramid/cli is a fast to setup and easy to use database migration tool for php 8.0 and above

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
