# jeandanyel/list-bundle

> 标签: PHP

## 简介

A flexible Symfony bundle for generating and customizing lists, capable of listing both Doctrine entities and data from external sources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
