# a21/lexicon-client

> 标签: Lexicon, a21, i18n, laravel, localization, translation

## 简介

Laravel client for Lexicon: export, pull, import, extract/push, and UGC entity_translations sync.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
