# drahosistvan/vatvalidation

> 标签: eu vat, validation, vat, vat validation, vies

## 简介

A simple wrapper for VIES VAT Validation WebService.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
