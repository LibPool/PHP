# continuousphp/zoho-subscriptions

> 标签: Zoho, api, plan, rest, subscription

## 简介

ZF2 module to interact with Zoho Subscriptions API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
