# bjornjohansen/spiderbear

> 标签: theme, wordpress

## 简介

SpiderBear is a WordPress theme forked from Intergalactic 2 by Automattic

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
