# batrox/portable-utf8

> 标签: UTF, clean, php, unicode, utf-8, utf8

## 简介

Portable UTF-8 library - performance optimized (unicode) string functions for php.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
