# mischafierz/polyglot-cms

> 标签: blog, cms, markdown, sqlite, themes

## 简介

A CMS for websites: Go content API, PHP themes, TypeScript admin panel, SQLite storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
