# geof-dev/filament-web3-auth

> 标签: Authentication, ethereum, filament, laravel, metamask, wallet, web3

## 简介

Web3 wallet authentication plugin for Filament

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
