# strikewood/woocommerce-affiliate-tracking

> 标签: affiliates, tracking, woocommerce, wordpress

## 简介

WooCommerce extension for adding affiliate tracking

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
