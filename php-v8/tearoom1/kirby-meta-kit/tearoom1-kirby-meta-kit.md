# tearoom1/kirby-meta-kit

> 标签: kirby, meta, panel, seo

## 简介

AI-powered SEO plugin for Kirby with bulk edit, automatic meta descriptions, live previews, sitemap generation, and Schema.org support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
