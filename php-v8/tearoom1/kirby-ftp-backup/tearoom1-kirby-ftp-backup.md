# tearoom1/kirby-ftp-backup

> 标签: backup, ftp, kirby, panel

## 简介

Kirby plugin that creates content backups and uploads them to a FTP server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
