# whiskerent/whisker-cart

> 标签: PHP

## 简介

Whisker — free, self-hosted e-commerce cart. Dev-only manifest: the shipped product has zero dependencies; composer is used exclusively for the test suite and never ships in release zips.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
