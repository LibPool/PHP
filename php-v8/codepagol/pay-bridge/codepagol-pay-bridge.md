# codepagol/pay-bridge

> 标签: bangla-qr, binance-pay, bkash, crypto, laravel, nagad, payment, payment-gateway, paypal, php, rocket, sslcommerz, stripe, upay

## 简介

A unified multi-gateway payment processing package for PHP and Laravel, supporting MFS (bKash, Nagad, Rocket, Upay), Cards, Net Banking, Crypto (Binance Pay, NOWPayments), and Bangla QR.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
