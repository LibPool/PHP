# four-bytes/four-rate-limiting

> 标签: PHP

## 简介

Generic rate limiting library for PHP APIs — Token Bucket, Fixed Window, Sliding Window, Leaky Bucket

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
