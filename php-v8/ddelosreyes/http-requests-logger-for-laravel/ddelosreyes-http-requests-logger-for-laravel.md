# ddelosreyes/http-requests-logger-for-laravel

> 标签: PHP

## 简介

A simple HTTP request logger for Laravel with buffered inserts and support for both relational databases and DynamoDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
