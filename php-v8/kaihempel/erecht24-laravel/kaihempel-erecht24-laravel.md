# kaihempel/erecht24-laravel

> 标签: Rechtstexte, eRecht24, imprint, laravel, legal, privacy-policy

## 简介

Laravel integration for the eRecht24 legal texts API (imprint, privacy policy, social media privacy policy).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
