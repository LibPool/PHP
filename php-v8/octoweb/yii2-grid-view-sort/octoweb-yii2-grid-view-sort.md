# octoweb/yii2-grid-view-sort

> 标签: grid, gridview, sortable, yii2

## 简介

Sortable modification of standard Yii2 GridView widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
