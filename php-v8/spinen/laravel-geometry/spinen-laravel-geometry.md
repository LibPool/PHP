# spinen/laravel-geometry

> 标签: geoPHP, geometry, laravel, library, spinen

## 简介

Wrapper over the geoPHP Class to make it integrate with Laravel better.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
