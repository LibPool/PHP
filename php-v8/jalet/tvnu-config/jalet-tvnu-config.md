# jalet/tvnu-config

> 标签: array, config, configuration, environment, ini, yaml

## 简介

Environment based configuration helper for multiple formats. INI, YAML, Databse (PDO) or Array.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
