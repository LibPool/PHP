# ecuafact/sdk

> 标签: api, ecuador, ecuafact, facturacion-electronica, sdk, sri

## 简介

Cliente oficial en PHP del API publico de facturacion electronica Ecuafact (contrato v1).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://docsapi.ecuafact.com/v1/guias/sdk-php
- 源码仓库：https://github.com/Ecuanexus/ecuafact-sdk-php.git
