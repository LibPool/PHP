# lmslfm/entrust

> 标签: PHP

## 简介

This package provides a flexible way to add role-based permissions to Laravel and is a fork from trebol/entrust from Zizaco/entrust

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
