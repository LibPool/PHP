# mariozabala/cima-laravel-client

> 标签: PHP

## 简介

Laravel client for the Spanish AEMPS CIMA (Centro de Información Online de Medicamentos) REST API v1.23

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
