# mvccore/ext-auth

> 标签: Authentication, auth, authenticate, authorization, ext, extension, framework, log in, log out, login, logout, mvc, mvccore, plug-in, plugin, sign in, sign out, signin, signout, user

## 简介

MvcCore - Extension - Auth - authentication module with automatic authentication module type detection by loaded classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
