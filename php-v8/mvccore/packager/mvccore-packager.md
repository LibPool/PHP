# mvccore/packager

> 标签: framework, mvc, mvccore, packager, packed app, packing, packing to phar, packing to php, single file app, super fast php app

## 简介

Library to pack any type of app into PHAR archive or any MvcCore app into single PHP super fast result file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
