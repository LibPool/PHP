> 标签: conjunctions, digits, ext, extension, framework, helper, line breaks, mvc, mvccore, new lines, plug-in, plugin, shortcuts, text, units, view, viewhelper

## 简介

MvcCore - Extension - View - Helper - Line Breaks - processing any visible text content for non-line breaking spaces.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
