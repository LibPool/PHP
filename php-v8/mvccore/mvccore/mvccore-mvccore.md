# mvccore/mvccore

> 标签: config, controller, core, debug, easy mvc, framework, model, mvc, mvccore, packed, packed app, packing, plugins, request, response, route, router, session, simple mvc, super fast app, tool, view

## 简介

MvcCore is PHP MVC framework to develop and pack projects (partialy or completely) into super fast single file apps and tools.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
