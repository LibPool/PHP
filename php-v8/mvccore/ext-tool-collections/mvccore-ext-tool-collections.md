> 标签: array, collection, dictionary, ext, extension, framework, list, map, mvc, mvccore, plug-in, plugin, set, tool, typed, vector

## 简介

MvcCore - Extension - Tool - Collections - extension with collection classes for typed arrays in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
