# mvccore/ext-tool-csp

> 标签: Policy, content, content-security-policy, csp, ext, extension, framework, mvc, mvccore, plug-in, plugin, security, tool

## 简介

MvcCore - Extension - Tool - Csp - utility to easilly complete `Content-Security-Policy` HTTP header.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
