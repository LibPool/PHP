# ahmadrezafatemikia/laravel-ampq

> 标签: PHP

## 简介

Elegant and minimal RabbitMQ (AMPQ) integration for Laravel 10–12, powered by php-amqplib.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
