# darkphp/apimonster

> 标签: API framework, PHP API, api monster, apimonster, framework, monster, mvc, php, php framework

## 简介

Fast PHP API Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
