# invoicexml/zugferd-xrechnung

> 标签: E-Invoice, EN-16931, EN16931, ERechnung, ZUGFeRD, cii, e-invoicing, e-rechnung, einvoice, invoice, kosit, leitweg-id, pdf-a-3, ubl, validation, xrechnung

## 简介

PHP client for ZUGFeRD and XRechnung e-invoices: create, validate, embed, render and extract EN 16931 invoices with the InvoiceXML API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
