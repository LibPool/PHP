# invoicexml/facturx

> 标签: E-Invoice, EN-16931, EN16931, ZUGFeRD, br-fr, cii, e-invoicing, einvoice, factur-x, facturation-electronique, facture-electronique, facturx, invoice, pdf-a-3, validation

## 简介

PHP client for Factur-X e-invoices: create, validate, embed and extract EN 16931 invoices with the InvoiceXML API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
