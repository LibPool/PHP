# ljjgit/alipaysdk-easysdk

> 标签: PHP

## 简介

支付宝官方 Alipay Easy SDK|这是从官方包fork出来的项目，一切原有代码版权均归官方所有|官方地址：https://github.com/alipay/alipay-easysdk/

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
