# sai97/laravel-amqp

> 标签: AMQP, laravel, laravel amqp, laravel-amqp, queue, rabbitmq

## 简介

基于php-amqplib/php-amqplib组件适配laravel框架的amqp封装库

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
