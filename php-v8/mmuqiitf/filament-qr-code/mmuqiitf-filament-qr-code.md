# mmuqiitf/filament-qr-code

> 标签: barcode-scanner, filament, filament-plugin, filament-v5, hardware-scanner, laravel, mmuqiitf, qr-code, sequential-scan

## 简介

A powerful, modern QR code package for Filament v5 supporting generation, camera reading, sequential fields, and hardware scanners.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
