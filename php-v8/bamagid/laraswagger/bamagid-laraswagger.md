# bamagid/laraswagger

> 标签: api, documentation, laraswagger, laravel, openapi, swagger, swagger-ui

## 简介

Automatic Swagger/OpenAPI documentation generator for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
