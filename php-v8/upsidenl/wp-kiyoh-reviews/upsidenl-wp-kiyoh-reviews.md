# upsidenl/wp-kiyoh-reviews

> 标签: PHP

## 简介

Fetches reviews from Kiyoh/KlantenVertellen XML feed and stores them as Custom Post Types.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
