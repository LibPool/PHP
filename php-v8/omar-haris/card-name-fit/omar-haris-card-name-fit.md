# omar-haris/card-name-fit

> 标签: arabic-names, bank-card, card-name, card-printing, character-limit, credit-card, debit-card, id-card, identity-card, latin-names, name-compress, name-fit, name-formatter, name-shorten, name-truncate, payment-card, php-library, security-card, visa

## 简介

PHP library to squeeze Arabic or English personal names to a fixed length for ID, bank or payment cards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
