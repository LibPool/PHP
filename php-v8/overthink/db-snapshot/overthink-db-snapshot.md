# overthink/db-snapshot

> 标签: laravel, mysql, mysqldump, overthink, snapshot, ssh

## 简介

Pull filtered MySQL snapshots from a remote server over SSH and restore them into your local database.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
