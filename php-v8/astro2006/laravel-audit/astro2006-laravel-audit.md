# astro2006/laravel-audit

> 标签: Audit, PHPStan, astro2006, claude, code-review, laravel, laravel-audit, pest, security

## 简介

AI-assisted audits for Laravel apps: a deterministic preflight (tests, browser tests, PHPStan, Composer) feeds Claude Code agents that review tests, frontend, backend and dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
