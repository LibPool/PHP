# bocharsky-bw/arrayzy

> 标签: OOP, array, arrayzy, helper, manipulation, utility, wrapper

## 简介

A native PHP arrays easy manipulation library in OOP way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
