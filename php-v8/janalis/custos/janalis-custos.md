# janalis/custos

> 标签: LSP, code quality, dev, fixer, inspections, linter, static analysis

## 简介

Fast PHP inspector and fixer with quick-fixes, shipped as a prebuilt binary.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
