# janalis/doctrineviz

> 标签: dbal, doctrine, graphviz, schema, symfony-bundle

## 简介

Generate Graphviz DOT diagrams from a Doctrine DBAL database schema.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
