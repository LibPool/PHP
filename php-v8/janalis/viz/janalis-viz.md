# janalis/viz

> 标签: diagram, dot, graphviz, mermaid, pdf, plantuml, png, svg

## 简介

Mermaid, Graphviz and PlantUML for PHP: native rendering with a CLI fallback, SVG/PNG/PDF export and conversion between the three

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
