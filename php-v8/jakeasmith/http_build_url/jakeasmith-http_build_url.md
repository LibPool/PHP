# jakeasmith/http_build_url

> 标签: PHP

## 简介

Deprecated: use PHP 8.5's built-in Uri\Rfc3986\Uri instead. Provides http_build_url() for environments without pecl_http.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
