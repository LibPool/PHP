# gguney/barista

> 标签: Automatic HTML Builder

## 简介

Improved HTML Builder for Laravel. Highly suggested to use with 'gguney/hammal' package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
