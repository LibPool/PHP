# ezappslab/filament-translatable

> 标签: PHP

## 简介

Filament Translatable adds locale-aware resource pages to FilamentPHP panels using Spatie Laravel Translatable

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
