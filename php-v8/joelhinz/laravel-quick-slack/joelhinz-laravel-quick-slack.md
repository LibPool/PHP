# joelhinz/laravel-quick-slack

> 标签: PHP

## 简介

An easy way of quickly sending messages to predefined Slack endpoints within a Laravel project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
