# mslinky/belugapay-ecommerce-php

> 标签: PHP

## 简介

Belugapay library to connect to ecommerce api, payment gateway for credit and debit cards for visa or mastercard.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
