# stefanfroemken/mysql-widget

> 标签: TYPO3 CMS, dashboard, mysql, status, typo3, widget

## 简介

Show MySQL status in widgets of TYPO3 DashBoard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
