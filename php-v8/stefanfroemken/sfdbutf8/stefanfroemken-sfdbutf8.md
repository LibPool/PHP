# stefanfroemken/sfdbutf8

> 标签: TYPO3 CMS, typo3, utf-8, utf8

## 简介

With this extension you can set all tables and columns to UTF-8 collation (no converting)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
