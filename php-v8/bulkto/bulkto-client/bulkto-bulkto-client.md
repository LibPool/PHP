# bulkto/bulkto-client

> 标签: bulk mail, composer, dkim, email, transactional mail

## 简介

BulkTo transactional & bulk mail PHP client (end-user API only).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
