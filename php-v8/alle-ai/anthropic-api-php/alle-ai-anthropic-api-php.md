## 简介

The go-to PHP library for the Anthropic API — Messages, streaming, tool use, vision, prompt caching, extended thinking, MCP, Files, Batches. Maintained by Alle-AI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
