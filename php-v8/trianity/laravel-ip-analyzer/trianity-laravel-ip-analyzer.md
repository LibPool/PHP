# trianity/laravel-ip-analyzer

> 标签: asn, geoip, ip-analysis, laravel, mmdb

## 简介

Local IP country and ASN analysis with extensible observation-based rules for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
