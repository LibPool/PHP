# darkstrata/credential-check

> 标签: breach, credential, darkstrata, k-anonymity, laravel, password, security

## 简介

DarkStrata credential breach checking SDK using k-anonymity. Only a 5-6 character hash prefix is ever sent to the API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
