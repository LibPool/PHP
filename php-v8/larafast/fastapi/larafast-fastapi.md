# larafast/fastapi

> 标签: API generator, fastapi, generate, generate api, larafast, scaffold

## 简介

A Fast Laravel package to help you generate CRUD API Controllers and Resources, Model

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
