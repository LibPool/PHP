# mikoweb/joomla-rapid-composer

> 标签: extension, installer, joomla

## 简介

A Composer plugin to install Joomla extensions into your installation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
