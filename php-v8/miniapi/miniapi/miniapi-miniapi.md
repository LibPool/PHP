# miniapi/miniapi

> 标签: api, json, rest, soap, wsse

## 简介

This Bundle provides everything you need to interact with web API. It's object-oriented, simple and powerful.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
