# traiwi/traiwijs

> 标签: JS, area, javascript, print, screenshot, traiwi

## 简介

TraiwiJS is a wrapper of commonly used JS functionalities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
