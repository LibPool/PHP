# ranfury/silverstripe-cms-styles

> 标签: admin, cms, silverstripe, theme

## 简介

A fresh, modern style for the Silverstripe CMS. Blocks the core CMS styles and replaces them with its own

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
