# invisnet/phpstan-compose-shapes

> 标签: PHPStan, array shape, sealed, static analysis

## 简介

PHPStan extension providing compose-shapes<A, B, ...> to merge sealed array shapes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
