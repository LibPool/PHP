# phpinnacle/franz

> 标签: api, connectors, kafka, kafka-connect, phpinnacle

## 简介

Framework-agnostic PHP client for the Apache Kafka Connect REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
