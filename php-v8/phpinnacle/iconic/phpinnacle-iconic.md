# phpinnacle/iconic

> 标签: Phosphor, filament, icons, laravel, phpinnacle

## 简介

Searchable icon picker and Phosphor icon integration for Laravel Filament.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
