# agencelex/notifications-slack

> 标签: notification system, notifications, slack, slack api, slack block kit, slack channel, slack incoming webhooks, slack integration, slack legacy attachments, slack notifications, slack web api, slack webhook, typo3

## 简介

Slack channel (Block Kit, legacy attachments, Incoming Webhooks and Web API) for Agence Lex Notifications on TYPO3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
