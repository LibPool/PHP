# yajima-tatsuro/jp-yen-formatter

> 标签: currency, formatter, japan, kanji, money, php, yen

## 简介

日本円の数値を「千円」「万円」などの単位に変換・フォーマットするPHPパッケージ

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
