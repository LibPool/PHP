# krecit/gemini-image-core

> 标签: PHP

## 简介

A standalone PHP client for Google Gemini Vision and Imagen 4. Generate high-quality images from text or image references seamlessly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
