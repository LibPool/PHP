# joeymckenzie/typestream

> 标签: auth, inertia, laravel, tailwind

## 简介

Jetsream-based scaffolding for the Laravel framework including TypeScript for Inertia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
