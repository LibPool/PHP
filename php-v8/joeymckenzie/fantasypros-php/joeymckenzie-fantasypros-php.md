# joeymckenzie/fantasypros-php

> 标签: API-Client, fantasy-football, fantasy-sports, fantasypros, nfl, saloon

## 简介

A PHP client for the FantasyPros API: players, rankings, projections, news and injuries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
