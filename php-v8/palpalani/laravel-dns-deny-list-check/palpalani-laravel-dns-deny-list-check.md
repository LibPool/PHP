# palpalani/laravel-dns-deny-list-check

> 标签: blacklist-check, dns-blacklist, dns-deny-list, dns-query, dnsbl, email-deliverability, email-reputation, ip-blacklist, ipv4, ipv6, laravel, laravel-package, rbl, smtp, spam-protection

## 简介

A modern Laravel package for checking IP addresses against verified DNS-based blacklists (DNSBL/RBL) to ensure email deliverability

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
