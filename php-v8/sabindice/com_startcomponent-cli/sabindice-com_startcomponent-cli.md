# sabindice/com_startcomponent-cli

> 标签: coverting, joomla, joomla3, joomla4

## 简介

A CLI script for easy converting Joomla 3 to Joomla 4 components (frontend)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
