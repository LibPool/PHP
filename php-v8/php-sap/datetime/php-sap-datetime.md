# php-sap/datetime

> 标签: PHPSAP, date, datetime, php-sap, sap, time, timestamp, week

## 简介

Extends PHP's DateTime class by SAP week, date, time and timestamp format.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
