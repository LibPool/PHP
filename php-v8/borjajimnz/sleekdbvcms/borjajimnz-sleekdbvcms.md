# borjajimnz/sleekdbvcms

> 标签: SleekDB CMS, cms

## 简介

SleekdbVCMS — lightweight PHP CMS on top of SleekDB, packaged as a Composer library with an installer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
