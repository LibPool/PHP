# pxlrbt/laravel-docs

> 标签: docs, documentation, laravel, markdown

## 简介

Render markdown documentation inside Laravel with a modern VitePress-inspired layout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
