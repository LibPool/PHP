# pedrogaldino/php-thread-pool

> 标签: multithread, parallel, php, pool, threads

## 简介

Implementação de uma interface para utilização de Thread Pool com PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
