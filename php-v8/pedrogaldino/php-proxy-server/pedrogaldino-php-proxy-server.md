# pedrogaldino/php-proxy-server

> 标签: http-proxy, https-proxy, php, php-proxy, proxy

## 简介

Servidor de proxy com suporte a HTTP(S) implementado em PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
