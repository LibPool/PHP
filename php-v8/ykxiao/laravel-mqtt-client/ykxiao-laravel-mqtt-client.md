# ykxiao/laravel-mqtt-client

> 标签: client, laravel, mqtt, publish, subscribe

## 简介

A wrapper for the ykxiao/laravel-mqtt-client library for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
