# webreboot/gdeslon-api

> 标签: affiliate, api, cpa, gdeslon, mcp, postback, sdk, yml

## 简介

Неофициальный PHP SDK, CLI и MCP-сервер для API вебмастеров партнёрской сети «Где Слон?» (gdeslon.ru)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
