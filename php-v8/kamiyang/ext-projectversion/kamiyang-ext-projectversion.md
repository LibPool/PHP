# kamiyang/ext-projectversion

> 标签: TYPO3 CMS, git, typo3, version

## 简介

Displays current project version based on 'VERSION' file or GIT revision.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
