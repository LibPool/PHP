# ssitu/nietzsche

> 标签: error-monitoring, mustache, php

## 简介

A Mustache wrap to render only perfect Mustache templates. Aka, monitor exceptions and missing variables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
