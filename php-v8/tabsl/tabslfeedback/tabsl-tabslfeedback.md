# tabsl/tabslfeedback

> 标签: OXID, anthropic, eshop, feedback, gitlab, modules, openai

## 简介

Feedback-Formular für Backend und Frontend mit KI-Aufbereitung und GitLab-Ticket-Anlage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
