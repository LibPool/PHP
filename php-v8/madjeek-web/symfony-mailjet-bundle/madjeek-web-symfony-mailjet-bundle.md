# madjeek-web/symfony-mailjet-bundle

> 标签: Mailjet, Messenger, async, bundle, email, mailer, php8, symfony, transactional

## 简介

A modern, async-ready Symfony 7 bundle for Mailjet — PHP 8.3, Messenger, HttpClient, Webhooks & full test coverage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
