# shopwarelabs/swag-media-gcp

> 标签: gcp, google cloud, shopware

## 简介

Shopware media adapter to store media files on Google Cloud Storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
