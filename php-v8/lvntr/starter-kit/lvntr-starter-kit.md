# lvntr/starter-kit

> 标签: admin-panel, ddd, inertia, laravel, primevue, starter-kit, vue

## 简介

Laravel Starter Kit with DDD architecture, Inertia.js, Vue 3, PrimeVue, and role-based permissions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
