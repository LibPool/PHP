# calvinalkan/wordpress-hook-api-clone

> 标签: PHP

## 简介

An exact copy of the Wordpress hook API Files, manually synced after every WP release

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
