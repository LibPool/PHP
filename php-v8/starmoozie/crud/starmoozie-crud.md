# starmoozie/crud

> 标签: Content management system, admin panel, admin panel for laravel, bootstrap 4 admin panel laravel, cms, coreui for laravel, crud, laravel admin, starmoozie

## 简介

Quickly build an admin interfaces using Laravel 6, CoreUI, Boostrap 4 and jQuery.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
