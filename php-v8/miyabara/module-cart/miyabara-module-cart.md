# miyabara/module-cart

> 标签: PHP

## 简介

Adapts the Magento 2 shopping cart shipping estimation UI for Brazilian storefronts (Brazil/Mexico/Colombia): shows only country and postcode, silently resolving the region from the postcode.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
