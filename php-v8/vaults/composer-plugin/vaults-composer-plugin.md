# vaults/composer-plugin

> 标签: composer, mirror, plugin, resilience, vaults

## 简介

composer deposit: deposit your composer.lock with Vaults resilient Composer infrastructure

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
