# faulker/bitter-laravel

> 标签: analytics, bitter, laravel, redis

## 简介

Adaption of the Bitter page to work with laravel. Bitter is a simple but powerful analytics library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
