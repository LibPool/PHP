# rewrit/rewrit

> 标签: laravel, migration, parity, pest, phpunit, rewrit, testing

## 简介

PHP SDK for emitting Rewrit observations from Pest, PHPUnit and Laravel tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
