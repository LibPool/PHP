# apsc-web/ubc_apsc_syndicated_canonical_url

> 标签: PHP

## 简介

Alter the canonical URL with origin domain name, label for content that has been syndicated.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
