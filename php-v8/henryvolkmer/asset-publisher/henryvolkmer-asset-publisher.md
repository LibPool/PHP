# henryvolkmer/asset-publisher

> 标签: PHP

## 简介

if you cant utilize a npm build pipeline, then you can use this Poormans assets publisher.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
