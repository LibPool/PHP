# remonode/laravel-sdk

> 标签: PHP

## 简介

Laravel SDK for API key management and Remonode portal integration. Generate, validate, rotate, and revoke API keys locally with optional portal sync.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
