# cakephp-plugin/sledgehammer

> 标签: PHP

## 简介

CakePHP plugin: Use the Sledgehammer Framework as a library in a CakePHP 2.x project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
