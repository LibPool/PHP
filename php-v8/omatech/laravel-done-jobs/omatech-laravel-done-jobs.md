# omatech/laravel-done-jobs

> 标签: laravel-done-jobs, omatech

## 简介

Quick way to save jobs that have been created without any problem. The antithesis of failed jobs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
