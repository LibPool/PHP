# acelaya/zf2-acmailer

> 标签: laminas, mail, mezzio, module

## 简介

Mail sending module for Mezzio and Laminas MVC applications (formerly Zend Expressive and Zend MVC)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
