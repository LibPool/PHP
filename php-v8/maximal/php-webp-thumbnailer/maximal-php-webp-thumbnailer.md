# maximal/php-webp-thumbnailer

> 标签: Webp, helper, image, imagine, thumbnail

## 简介

PHP (over Imagine) helper for creating and caching WebP thumbnails in real time

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
