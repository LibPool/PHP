# maximal/yii2-avif-thumbnailer

> 标签: avif, extension, helper, image, imagine, thumbnail, yii2

## 简介

Yii2 (over Imagine) helper for creating and caching AVIF thumbnails in real time

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
