# maximal/php-avif-thumbnailer

> 标签: avif, helper, image, imagine, thumbnail

## 简介

PHP (over Imagine) helper for creating and caching AVIF thumbnails in real time

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
