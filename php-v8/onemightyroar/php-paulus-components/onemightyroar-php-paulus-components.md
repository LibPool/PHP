# onemightyroar/php-paulus-components

> 标签: api, bootstrap, paulus, rest

## 简介

Components to enhance Paulus projects to enable quicker, more structured REST API's

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
