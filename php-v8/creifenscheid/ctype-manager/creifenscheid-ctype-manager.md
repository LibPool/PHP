# creifenscheid/ctype-manager

> 标签: PHP

## 简介

This TYPO3 extension implements a backend module through which available content and plugin types can be configured on page level.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
