# meta-tech/pws-client

> 标签: PwsAuth, client, http, webservice

## 简介

PwsClient is a php web service client managing PwsAuth protocol

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
