# icomm-api/bizgo-sdk-comm

> 标签: alimtalk, bizgo, brandmessage, infobank, kakao, lms, mms, navertalk, rcs, sdk, sms

## 简介

PHP SDK for the Bizgo Communication API: SMS/LMS/MMS, international SMS, RCS, Kakao AlimTalk/BrandMessage, Naver TalkTalk.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
