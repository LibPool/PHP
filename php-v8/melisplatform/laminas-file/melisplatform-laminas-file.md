# melisplatform/laminas-file

> 标签: file, laminas, melis, melisplatform

## 简介

Melis Platform fork of laminas/laminas-file - adds PHP 8.4 / 8.5 support. Locate PHP classfiles

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
