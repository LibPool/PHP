# melisplatform/laminas-mime

> 标签: laminas, melis, melisplatform, mime

## 简介

Melis Platform fork of laminas/laminas-mime - adds PHP 8.4 / 8.5 support. Create and parse MIME messages and parts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
