# melisplatform/laminas-crypt

> 标签: crypt, laminas, melis, melisplatform

## 简介

Melis Platform fork of laminas/laminas-crypt - adds PHP 8.4 / 8.5 support. Strong cryptography tools and password hashing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
