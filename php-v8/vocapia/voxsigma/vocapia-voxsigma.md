# vocapia/voxsigma

> 标签: Transcription, asr, speech-to-text, stt, vocapia, voxsigma

## 简介

PHP SDK for Vocapia VoxSigma speech-to-text binaries and REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
