# brewless/cli

> 标签: brewless, cli, deploy, laravel, php, serverless

## 简介

The command line client of Brewless: sign in, connect a project and deploy it to your own European cloud account.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
