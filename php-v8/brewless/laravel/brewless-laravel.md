# brewless/laravel

> 标签: brewless, deploy, laravel, serverless

## 简介

What a Laravel application needs to run on Brewless: the release, schedule and queue routes its own containers answer on, and trust in the edge in front of it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
