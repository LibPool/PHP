# codyjheiser/laravel-db2-eloquent

> 标签: PHP

## 简介

Laravel Eloquent extensions for IBM DB2 databases with column mapping, multi-column relationships, and auto-filtering

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
