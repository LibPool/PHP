# fritzmg/contao-mergecssclasses

> 标签: classes, contao, css, include, merge

## 简介

Small extension for Contao to automatically merge CSS classes in included elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
