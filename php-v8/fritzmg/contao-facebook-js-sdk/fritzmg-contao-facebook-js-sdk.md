# fritzmg/contao-facebook-js-sdk

> 标签: contao, facebook, javascript, sdk

## 简介

Automatically integrates the Facebook JavaScript SDK in the Contao frontend or backend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
