# xiaobai/mph

> 标签: PHP

## 简介

一个基于thinkphp的command类实现的用于给model自动增加或者更新属性注释的工具。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
