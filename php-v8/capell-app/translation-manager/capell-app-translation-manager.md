# capell-app/translation-manager

> 标签: capell, cms, laravel, translations

## 简介

File-based Capell translation editing with side-by-side locale comparison, missing and stale key checks, safe override writes, and optional reviewed AI drafting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
