# capell-app/migration-assistant

> 标签: capell, cms, cms-migration, content-migration, csv-import, dry-run-validation, export, import, laravel, media-migration, migration, rollback, wordpress-migration, xml-import

## 简介

Safely move pages and media into Capell — preview every change, validate before you write, and keep a rollback report for every import.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
