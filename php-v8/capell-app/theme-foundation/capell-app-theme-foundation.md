# capell-app/theme-foundation

> 标签: capell, cms, frontend, laravel, theme

## 简介

Capell's foundation theme with shared Blade layouts, runtime design tokens, deterministic DesignSpec v1 compilation, and validated Project Build theme artifacts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
