# capell-app/structured-content-library

> 标签: capell, cms, laravel, structured-content

## 简介

Typed, portable content records (testimonials, case studies, team, FAQs, services…) that Capell themes and packages render safely.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
