# pixelpeter/laravel-isocodes-validation

> 标签: iso, isocode, laravel, validation

## 简介

Laravel 12+ wrapper for the IsoCodes Validation library from ronanguilloux

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
