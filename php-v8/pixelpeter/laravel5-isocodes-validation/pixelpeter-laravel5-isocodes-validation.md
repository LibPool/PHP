# pixelpeter/laravel5-isocodes-validation

> 标签: iso, isocode, laravel, validation

## 简介

Laravel 5 wrapper for the IsoCodes Validation library from ronanguilloux

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
