# pavel-ekt/shell-wrapper

> 标签: exec, execute, shell, shell-wrapper, wrapper

## 简介

provides a simple way to work with shell commands

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
