# maxweb/save-url

> 标签: laravel, login, maxweb, redirect after login, save-url

## 简介

Laravel 5 package to redirect users to the last visited page on login.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
