# cino/laravel-chronos

> 标签: carbon, carbon-replacement, chronos, date, eloquent, laravel, lumen

## 简介

Replaces Carbon in Laravel by CakePHP's Chronos library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
