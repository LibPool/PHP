# coliving/laravel-duplicate

> 标签: copy, duplicate, eloquent, laravel, model, relations, replicate

## 简介

Duplicate any Eloquent model along with its underlying relationships

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
