# amorim778/byte-array-php

> 标签: Buffer, binary, byte, bytearray, endian

## 简介

A modern PHP ByteArray buffer with endian-aware read/write helpers, compression, and conversions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
