# digitalygo/envai-teams-sdk-php

> 标签: PHP

## 简介

Official PHP SDK for Envai: a framework-independent typed HTTP client and an ATP v3 runtime for chat, streaming, definitions and client tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
