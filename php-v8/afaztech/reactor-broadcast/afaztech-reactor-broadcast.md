# afaztech/reactor-broadcast

> 标签: Broadcast, afaztech, mass-message, reactor, telegram, telegram-bot

## 简介

Broadcast (send / copy / forward) with progress statistics for Reactor bots.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
