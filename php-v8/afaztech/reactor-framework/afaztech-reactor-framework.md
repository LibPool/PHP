# afaztech/reactor-framework

> 标签: async, bot framework, dependency injection, middleware, migrations, php, reactor, scheduler, telegram, telegram api, telegram bot

## 简介

A modern, asynchronous PHP framework for building powerful Telegram bots.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
