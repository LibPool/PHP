# envkey/envkey-php

> 标签: configuration, configuration management, dotenv, encryption, end-to-end encryption, env, environment variables, secrets, secrets management, security

## 简介

Keeps environment variables automatically in sync. Protects secrets with end-to-end encryption.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
