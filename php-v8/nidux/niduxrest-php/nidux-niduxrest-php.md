# nidux/niduxrest-php

> 标签: Nidux, api, client, curl, fluent, http, rest

## 简介

A modern, fluent HTTP client. Forked from Mashape, reimagined by Nidux, and open-sourced for the PHP community.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
