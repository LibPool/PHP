# macellan/laravel-encryption

> 标签: encryption, flexible-encryption, laravel, laravel-encryption, macellan

## 简介

Provides flexible data encryption adapter for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
