# abbadon1334/vegoia

> 标签: Pagerank, betweenness, centrality, community-detection, cpm, graph, graphrag, leiden, louvain, modularity, rag, statistics

## 简介

Graph algorithms and statistics for PHP. Leiden community detection, centrality, shortest paths and NIST-verified statistics, with zero runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
