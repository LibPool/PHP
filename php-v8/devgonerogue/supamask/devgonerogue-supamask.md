# devgonerogue/supamask

> 标签: asn, bot-blocking, ip-blocking, ip-intelligence, middleware, php, security, vpn-detection

## 简介

A lightweight PHP security middleware library for IP, bot, challenge, and traffic intelligence controls.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
