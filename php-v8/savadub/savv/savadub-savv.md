# savadub/savv

> 标签: framework, php, savadub, savv, wordpress-fallback

## 简介

The Savv PHP Framework - Lightweight, fast, and WordPress-friendly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
