# dallasmakerspace/cakephp-sparkpost-plugin

> 标签: cakephp, email, mandrill, plugin, sparkpost

## 简介

A CakePHP plugin for sending mail via SparkPost's REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
