# sevenspan/laravel-whatsapp

> 标签: laravel, laravel-whatsapp, whatsapp

## 简介

It uses whatsapp cloud API to send whatsapp messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
