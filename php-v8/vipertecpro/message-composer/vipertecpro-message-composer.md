# vipertecpro/message-composer

> 标签: IMessage, attachments, composer, email, mail, mobile, nativephp, share, sms

## 简介

Native email and SMS composers with attachments and result events — hand-written Swift and Kotlin for NativePHP Mobile.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
