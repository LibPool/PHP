# vipertecpro/pausewall-usage

> 标签: android, app-usage, digital-wellbeing, free, mobile, nativephp, screen-time, usage-stats

## 简介

Read-only app usage for NativePHP: how long each app was used today or over the last 7 days, from PHP. A free, tiny companion to Pausewall for NativePHP. Android only; iOS reports unsupported.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
