# vipertecpro/mobile-entitlements

> 标签: app-store, entitlements, google-play, in-app-purchase, laravel, rtdn, storekit, subscriptions

## 简介

Verified App Store Server Notifications V2 and Google Play RTDN webhooks with a per-user entitlement table for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
