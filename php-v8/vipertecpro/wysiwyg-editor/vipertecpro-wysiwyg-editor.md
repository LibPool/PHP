# vipertecpro/wysiwyg-editor

> 标签: editor, html, mobile, nativephp, rich-text, text, wysiwyg

## 简介

A fully native, hand-written WYSIWYG rich text editor for NativePHP Mobile — write with a real native toolbar, get clean HTML back.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
