# vipertecpro/app-analytics

> 标签: a-b-testing, analytics, events, feature-flags, firebase, mobile, nativephp, remote-config

## 简介

App Analytics & Remote Config for NativePHP: analytics events, user properties, screen views and feature flags with in-app defaults. Works with Firebase. Hand-written Swift and Kotlin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
