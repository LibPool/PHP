# vipertecpro/image-cropper

> 标签: crop, cropper, editor, image, mobile, nativephp, photo

## 简介

A fully native, hand-written freehand image cropper for NativePHP Mobile.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
