# vipertecpro/otp-autofill

> 标签: 2fa, autofill, mobile, nativephp, one-time-code, otp, sms, sms-retriever, verification

## 简介

SMS one-time-code autofill for NativePHP Mobile — a native code field with iOS keyboard autofill and the Android SMS User Consent and SMS Retriever APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
