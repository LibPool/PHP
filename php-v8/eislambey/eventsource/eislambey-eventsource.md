# eislambey/eventsource

> 标签: Server-Sent Events, client, eventsource, sse

## 简介

A simple EventSource / SSE (Server-Sent Events) client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
