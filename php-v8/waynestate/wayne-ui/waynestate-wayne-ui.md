# waynestate/wayne-ui

> 标签: accessibility, blade, design-system, laravel, wayne-state, wcag, wsu

## 简介

Wayne State University design system for PHP. Framework-free helpers plus optional Laravel Blade components, breadcrumbs and Inertia support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
