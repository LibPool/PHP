# romansulzhyk/filament-import

> 标签: csv, csv-import, excel, excel-import, filament, filament-plugin, filament-v4, filament-v5, filamentphp, import, importer, laravel, laravel-boost, romansulzhyk, spreadsheet, tsv, xlsx

## 简介

Import CSV and Excel (.xlsx) files into any Filament v4 or v5 resource immediately, without a queue: delimiter and encoding detection, header matching, validation, upserts and a downloadable report of failed rows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
