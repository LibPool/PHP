# gasparteixeira/api-boilerplate

> 标签: PHP7, api, boilerplate, jwt, rest, symfonfy4

## 简介

Boilerplate to create a REST API with Symfony 4.2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
