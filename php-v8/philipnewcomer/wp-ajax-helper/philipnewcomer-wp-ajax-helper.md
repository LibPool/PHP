# philipnewcomer/wp-ajax-helper

> 标签: ajax, wordpress

## 简介

A library to simplify AJAX requests in WordPress plugins and themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
