# ssch/typo3-rector

> 标签: automation, dev, migration, rector, refactoring, upgrade

## 简介

Instant fixes for your TYPO3 PHP code by using Rector.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
