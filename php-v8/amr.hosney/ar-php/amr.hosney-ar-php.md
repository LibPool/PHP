# amr.hosney/ar-php

> 标签: arabic, arabic-calendar, arabic-glyphs, arabic-numbers, arabic-segments-identifier, arabic-sentiment, arabic-sql-query

## 简介

Set of functionalities enable Arabic website developers to serve professional search, present and process Arabic content in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
