# reelworx/t3-fakefrontend

> 标签: PHP

## 简介

A library for TYPO3 extensions to initialize a 'fake frontend' environment. Mainly for CLI/BE purposes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
