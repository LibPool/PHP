# chilkat/chilkat

> 标签: certificates, chilkat, crypto, email, encryption, extension, ftp, http, imap, json, jwt, oauth2, pdf, rest, sftp, smtp, ssh, xml, zip

## 简介

Chilkat PHP extension: the CkHttp, CkCrypt2, CkEmail, CkZip, CkFtp2, CkSsh, ... classes, plus vendor/bin/chilkat-install which installs the matching native extension (chilkat.so / chilkat.dll) for your PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
