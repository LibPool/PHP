# schenke-io/laravel-invoice

> 标签: PHP

## 简介

A robust and flexible PHP package for Laravel that simplifies invoice management, currency handling, and complex VAT calculations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
