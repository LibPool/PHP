# attachmentav/virus-scan-sdk

> 标签: antivirus, attachmentav, laravel, malware, scan, security, sophos, symfony, virus

## 简介

An SDK to integrate virus and malware scan capabilities into PHP applications. Scan files for viruses, trojans, and other kinds of malware with attachmentAV powered by Sophos.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
