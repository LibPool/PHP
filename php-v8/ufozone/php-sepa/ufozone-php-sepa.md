# ufozone/php-sepa

> 标签: Banking, sepa, xml

## 简介

PHP class to create German SEPA files (XML) for credit transfer and direct debit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
