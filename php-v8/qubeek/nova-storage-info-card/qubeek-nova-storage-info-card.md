# qubeek/nova-storage-info-card

> 标签: card, laravel, nova, s3, storage

## 简介

A Laravel Nova card, that helps you to control your S3 type disks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
