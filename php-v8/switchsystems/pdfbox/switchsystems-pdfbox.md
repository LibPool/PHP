# switchsystems/pdfbox

> 标签: pdf

## 简介

Re-packaging of Apache PDFBox utlity for working with PDFs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://pdfbox.apache.org/
- 源码仓库：https://github.com/SwitchSystems/pdfbox.git
- Packagist 页面：https://packagist.org/packages/switchsystems%2Fpdfbox

## 历史版本号
