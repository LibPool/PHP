# sunrise/coder

> 标签: Coder, decoder, deserializer, encoder, fenric, serializer, sunrise

## 简介

A flexible data coder for encoding and decoding formats like JSON, YAML, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
