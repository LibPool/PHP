# sunrise/http-message

> 标签: fenric, http, psr-17, psr-7, request, response, rfc-7230, sunrise

## 简介

An HTTP message implementation based on PSR-7, PSR-17 and RFC-7230.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
