# sunrise/uri

> 标签: PHP7, fenric, http, parser, php8, psr-17, psr-7, rfc-3986, sunrise, uri

## 简介

URI wrapper for PHP 7.1+ based on RFC-3986, PSR-7 and PSR-17

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
