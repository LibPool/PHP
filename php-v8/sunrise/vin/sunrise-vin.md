# sunrise/vin

> 标签: PHP7, decoder, fenric, iso-3779, php8, sunrise, vin

## 简介

VIN decoder for PHP 7.1+ based on ISO-3779

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
