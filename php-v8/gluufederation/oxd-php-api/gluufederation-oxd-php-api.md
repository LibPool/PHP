# gluufederation/oxd-php-api

> 标签: PHP

## 简介

Protect your applications with oxd to enable single sign-on and API access management with OpenID Connect and UMA.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
