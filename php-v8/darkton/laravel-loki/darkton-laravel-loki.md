# darkton/laravel-loki

> 标签: grafana, laravel, logging, loki, otlp, redis

## 简介

A Laravel package for shipping logs to Grafana Loki via OTLP with Redis buffering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
