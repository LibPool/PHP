# lnkflow/laravel

> 标签: laravel, lnkflow

## 简介

Official Laravel SDK for LnkFlow link management, journeys, and conversions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/AppitStudio/lnkflow-laravel.git
