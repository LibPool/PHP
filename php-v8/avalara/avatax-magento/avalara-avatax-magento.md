# avalara/avatax-magento

> 标签: PHP

## 简介

Magento module for Avalara's AvaTax suite of business tax calculation and processing services. Uses the AvaTax REST v2 API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
