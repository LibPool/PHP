# matheuslm7/brazil-validator

> 标签: PHP

## 简介

Validation, normalization, and formatting for Brazilian data: CPF, CNPJ, CEP, phone numbers, e-mail, PIX keys, and Inscricao Estadual.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
