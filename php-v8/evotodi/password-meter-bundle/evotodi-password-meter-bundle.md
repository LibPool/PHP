# evotodi/password-meter-bundle

> 标签: PHP

## 简介

Password meter for symfony 7 that complements https://github.com/HamedFathi/PasswordMeter and passwordmeter.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
