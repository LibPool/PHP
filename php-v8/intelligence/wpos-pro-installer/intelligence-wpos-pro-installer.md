# intelligence/wpos-pro-installer

> 标签: composer, env, plugin, pro, wordpress, wp, wp offload s3 pro

## 简介

An install helper for WP S3 Offload Pro and it's addons

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
