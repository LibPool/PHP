# ashrafcodes/wasenderapi-laravel

> 标签: PHP

## 简介

Laravel package for WasenderAPI WhatsApp sessions, messages, contacts, groups, channels, uploads, and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
