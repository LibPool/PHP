# keypoint-solutions/laravel-vox

> 标签: Keypoint Solutions, laravel, laravel-vox

## 简介

A Laravel translation manager with AI backing and a friendly management GUI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
