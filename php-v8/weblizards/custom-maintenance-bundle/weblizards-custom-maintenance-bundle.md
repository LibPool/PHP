# weblizards/custom-maintenance-bundle

> 标签: maintenance, pimcore, pimcore-bundle

## 简介

Pimcore bundle for managing native and custom maintenance modes with scheduled windows, admin UI, CLI controls, Twig notices, and runtime status checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
