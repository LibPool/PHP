# mrkacmaz/laravel-ssp

> 标签: PHP

## 简介

Process server-side processing (SSP) for an Eloquent model, supporting dynamic filtering, sorting, and pagination.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
