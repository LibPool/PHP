# spykapp/filament-flat-theme

> 标签: filament, filament-flat-theme, filament-theme, laravel, php

## 简介

A simple theme for FilamentPHP based on a Flat design.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
