# digifa/mobile-detect-bundle

> 标签: device detect, device detector, mobile detect, mobile view managing, mobiledetect, mobiledetectbundle, symfony, symfony mobile detect, symfony mobiledetect

## 简介

Symfony 6.4, 7.0 / PHP 8.2 bundle to detect mobile devices, manage mobile view and redirect to the mobile and tablet version.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
