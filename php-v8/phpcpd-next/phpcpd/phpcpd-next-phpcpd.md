# phpcpd-next/phpcpd

> 标签: ci, clone-detection, code-quality, copy-paste-detector, duplication, phpcpd, static-analysis

## 简介

phpcpd-next — Copy/Paste (clone) detector for PHP 8.4+ with Type-1/2/3 detection. The maintained successor to the archived sebastianbergmann/phpcpd.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
