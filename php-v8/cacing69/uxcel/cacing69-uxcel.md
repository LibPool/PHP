# cacing69/uxcel

> 标签: data, excel, protect, unprotect

## 简介

Uxcel is a PHP library that can protect/unprotect some supported document for you.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
