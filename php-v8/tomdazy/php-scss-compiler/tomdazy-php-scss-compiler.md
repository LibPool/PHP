# tomdazy/php-scss-compiler

> 标签: compiler, php, sass, scss, scssphp, watcher

## 简介

Simple and lightweight SCSS compiler and watcher for PHP 8 using scssphp.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
