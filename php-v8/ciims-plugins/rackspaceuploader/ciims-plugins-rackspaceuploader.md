# ciims-plugins/rackspaceuploader

> 标签: PHP

## 简介

A CiiMS plugin to upload files to Rackspace Cloud files CDN

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
