# andrewcarteruk/cryptokey

> 标签: crypto, gen, generator, key, keygen

## 简介

A command line tool for generating keys using a CSPRNG.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
