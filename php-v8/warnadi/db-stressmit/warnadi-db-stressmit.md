# warnadi/db-stressmit

> 标签: PHP

## 简介

Smart database query benchmark, heuristic security auditor, and stress tester for Multi-Platform DB Stress Test (Laravel, WP, Symfony, CI, CLI).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
