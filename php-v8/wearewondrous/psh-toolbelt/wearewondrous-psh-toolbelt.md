# wearewondrous/psh-toolbelt

> 标签: drupal-10, lando, php 8.1, platform.sh

## 简介

Platform sh tools for a Drupal 10 and php 8.1.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
