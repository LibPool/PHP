# alifaraun/wallet

> 标签: balance, laravel, ledger, multi-currency, transactions, wallet

## 简介

Multi-currency, limit-aware wallet/ledger package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
