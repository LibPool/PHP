# qiuqiux/base-convert

> 标签: base62, baseConvert

## 简介

Converted from Binary,Octal,Decimal,Hexadecimal,Base62 and etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
