# zetacomponents/feed

> 标签: PHP

## 简介

This component handles parsing and creating RSS1, RSS2 and ATOM feeds, with support for different feed modules (dc, content, creativeCommons, geo, iTunes).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
