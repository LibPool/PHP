# vresende/datalayer

> 标签: crud, database, delete, destroy, pdo, save, sql server

## 简介

Datalayer is a Datalayer-based SQL Server database abstraction component

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
