# aalfiann/slim-jwt-skeleton

> 标签: api, jwt, microframework, rest, slimframework

## 简介

This is a skeleton to built rest api with slim framework 3 and JWT Auth.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
