# aalfiann/filebase

> 标签: database, document, file, file-files, filebase, flat, flat-file, key-value, serverless

## 简介

A Simple but Powerful Flat File Database Storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
