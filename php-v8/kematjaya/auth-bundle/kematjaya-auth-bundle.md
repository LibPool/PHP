# kematjaya/auth-bundle

> 标签: PHP

## 简介

API-first JWT authentication & simple RBAC for Symfony (API Platform friendly). Bring your own User entity via a small interface + factory contract.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
