# kematjaya/crud-maker-core

> 标签: PHP

## 简介

Shared renderer base class used by kematjaya/crud-maker-twig-bundle and kematjaya/crud-maker-api-bundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
