# cytopia/check_mysqldump-secure

> 标签: database, dump, export, icinga, mysql, mysqldump, nagios

## 简介

Nagios Plugin to monitor mysqldump database backups.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
