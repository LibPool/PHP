# secgin/api-library-base

> 标签: PHP

## 简介

PHP için API entegrasyonları için kütüphanerin oluşturlması kolaylaştırmak için tasarlanmıştır.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
