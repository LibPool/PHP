# thinkliveid/crew

> 标签: Gemini, Junie, agents, ai, claude, cli, codex, copilot, cursor, mcp, native, opencode, php, skills, slim, symfony

## 简介

A PHP CLI tool for managing AI agent skills, guidelines, and MCP configurations across multiple IDE coding assistants.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
