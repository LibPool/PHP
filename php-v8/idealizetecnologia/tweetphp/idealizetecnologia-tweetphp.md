# idealizetecnologia/tweetphp

> 标签: composer, php, twitter

## 简介

A PHP class for fetching tweets from a Twitter user's timeline, and rendering them as an HTML list

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
