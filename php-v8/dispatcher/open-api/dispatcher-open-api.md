# dispatcher/open-api

> 标签: builder, dispatcher, framework, openapi, route, slim, swagger

## 简介

Data driven dispatcher that implements the OpenApi specification

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
