# jfusion/curl

> 标签: curl, jfusion

## 简介

Curl Libery used for creating sessions using curl

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://jfusion.org
- 源码仓库：https://github.com/jfusion/org.jfusion.curl.git
- Packagist 页面：https://packagist.org/packages/jfusion%2Fcurl

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require jfusion/curl`
- Packagist 仓库：https://repo.packagist.org/p2/jfusion/curl.json
- 许可证：GPL-2.0+
- PHP 要求：>=5.3.10
