# teqneers/shamir

> 标签: PHP

## 简介

This is Shamir's Shared Secret implementation in PHP. It allows you to create shared secrets using the PHP classes or the CLI interface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
