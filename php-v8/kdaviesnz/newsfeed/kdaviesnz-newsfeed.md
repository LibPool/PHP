# kdaviesnz/newsfeed

> 标签: kdaviesnz, newsfeed

## 简介

Aggregate json newsfeed for New Zealand blogs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/kdaviesnz/newsfeed
- 源码仓库：https://github.com/kdaviesnz/newsfeed.git
- Packagist 页面：https://packagist.org/packages/kdaviesnz%2Fnewsfeed
