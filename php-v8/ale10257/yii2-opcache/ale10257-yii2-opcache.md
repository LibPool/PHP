# ale10257/yii2-opcache

> 标签: Opcache, extension, yii2

## 简介

Yii2 OpCache module - Show statistic, config, reset all, invalidate files, search in cached files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
