# lugsoft/afd-reader

> 标签: AFD, REP, arquivo afd, php, ponto, portaria 671, registro de ponto

## 简介

Biblioteca PHP para leitura e interpretação de arquivos AFD de registro eletrônico de ponto, conforme Portaria 671.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
