# bbs-lab/laravel-mail-mjml

> 标签: bbs, email, laravel, laravel-mail-mjml, mail, mjml

## 简介

Laravel package for building responsive emails with MJML and Mailables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
