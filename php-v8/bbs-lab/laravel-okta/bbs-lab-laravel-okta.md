# bbs-lab/laravel-okta

> 标签: Authentication, SSO, bbs, laravel, oauth, oidc, okta, socialite

## 简介

Framework-agnostic Okta SSO for Laravel: the Socialite Okta driver, login/callback/logout flow, lifecycle hooks and a pluggable panel seam that the nova-okta and filament-okta adapters build on.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
