# bbs-lab/jql-builder

> 标签: builder, jira, jql, php, sdk

## 简介

JQL builder is a supercharged PHP package that allows you to create Jira Query Language (JQL)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
