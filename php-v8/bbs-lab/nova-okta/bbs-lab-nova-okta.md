# bbs-lab/nova-okta

> 标签: Authentication, SSO, bbs, laravel, nova, oauth, oidc, okta, socialite

## 简介

Okta SSO for Laravel Nova: the Nova adapter for bbs-lab/laravel-okta — a custom login screen with an Okta button, the Nova login override and an optional Fortify two-factor challenge bridge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
