# abcaeffchen/sepa-documentor

> 标签: Banking, control list, file routing slip, files, finance, sepa, xml

## 简介

Generates file routing slips and control lists from SEPA file data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
