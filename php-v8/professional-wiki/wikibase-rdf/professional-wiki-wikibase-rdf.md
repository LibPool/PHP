# professional-wiki/wikibase-rdf

> 标签: RDF, mediawiki, wikibase

## 简介

Wikibase extension that allows defining RDF mappings for Wikibase Entities

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
