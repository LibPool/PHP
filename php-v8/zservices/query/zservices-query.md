# zservices/query

> 标签: cnpj, consulta, federal, ie, laravel, receita, sintegra

## 简介

Pacote para consultas em serviços do governo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
