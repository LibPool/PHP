# nepada/file-upload-control

> 标签: file, form, nette, upload

## 简介

File upload control for Nette forms: multi-file AJAX upload via blueimp-file-upload, Bootstrap 4 and 5 template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
