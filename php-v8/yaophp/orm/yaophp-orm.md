# yaophp/orm

> 标签: Active Record, database, orm, thinkphp, yaophp

## 简介

An orm lib independence from thinkphp 5.1.0RC1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
