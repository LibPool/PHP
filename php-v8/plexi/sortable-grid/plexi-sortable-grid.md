# plexi/sortable-grid

> 标签: blade, cruds, data-tables, grids, helpers, laravel

## 简介

Grade de dados com recursos de pesquisa, ordenação e seletor de registros para Laravel e Blade templates

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
