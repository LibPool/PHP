# kiora/sulu-s3-bundle

> 标签: Flysystem, Garage, media, minio, s3, storage, sulu

## 简介

S3 storage integration for Sulu CMS with Garage compatibility (S3 without ACL support)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
