# paytic/omnipay-paylike

> 标签: driver, gateway, merchant, omnipay, pay, paylike, payment

## 简介

Paylike driver for ThePhpLeague Omnipay multi-payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
