# paytic/omnipay-romcard

> 标签: driver, gateway, librapay, merchant, pay, payment

## 简介

romcard driver for ThePhpLeague Omnipay multi-payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
