# aristonet/entity-to-model-bundle

> 标签: code generator, converter, generator, scaffold, scaffolding

## 简介

It converts doctrine entities to typescript models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
