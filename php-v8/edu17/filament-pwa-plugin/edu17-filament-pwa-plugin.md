# edu17/filament-pwa-plugin

> 标签: edu17, filament-pwa-plugin, filamentphp, laravel, progressive-web-app, pwa

## 简介

A Progressive Web App (PWA) plugin for FilamentPHP panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
