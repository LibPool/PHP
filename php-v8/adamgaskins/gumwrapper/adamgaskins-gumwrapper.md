# adamgaskins/gumwrapper

> 标签: adamgaskins, gum, gumwrapper

## 简介

A php wrapper for Gum: a tool for glamorous shell scripts 🎀

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
