# tineye/tineye-api

> 标签: Computer Vision, Find Duplicates, Search by Image, TinEye API, reverse image search

## 简介

Library to reverse image search using the TinEye API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
