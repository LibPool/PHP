# junlz/rootphp

> 标签: framework, mvc, rootphp

## 简介

Simple and lightweight PHP framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.junlz.com
- 源码仓库：https://github.com/junlz/RootPHP.git
- Packagist 页面：https://packagist.org/packages/junlz%2Frootphp

- Composer 安装：`composer require junlz/rootphp`
