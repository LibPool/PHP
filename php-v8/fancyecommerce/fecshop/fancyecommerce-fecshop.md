# fancyecommerce/fecshop

> 标签: cart, ecommerce, fancyecommerce, fecshop, shop, yii2

## 简介

fancyecommerce yii2 fecshop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
