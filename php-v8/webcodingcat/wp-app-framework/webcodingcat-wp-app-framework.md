# webcodingcat/wp-app-framework

> 标签: block-theme, full-site-editing, gutenberg, tailwindcss, twig, wordpress

## 简介

Framework for standalone full site editing themes for WordPress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
