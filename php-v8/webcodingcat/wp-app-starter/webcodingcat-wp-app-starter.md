# webcodingcat/wp-app-starter

> 标签: block, plugin, starter, theme, wordpress

## 简介

Creates a theme, child theme or plugin built with wp-app-framework: composer create-project webcodingcat/wp-app-starter <directory>.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
