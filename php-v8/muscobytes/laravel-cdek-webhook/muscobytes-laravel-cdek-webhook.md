# muscobytes/laravel-cdek-webhook

> 标签: cdek, laravel, muscobytes, sdek, webhook

## 简介

Create endpoint in your Laravel application for CDEK with zero effort.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
