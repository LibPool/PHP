# x-laravel/username

> 标签: eloquent, history, laravel, reserved, username, validation

## 简介

Usernames for Eloquent models with configurable validation, reserved names, generation and a history that keeps old profile links working.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
