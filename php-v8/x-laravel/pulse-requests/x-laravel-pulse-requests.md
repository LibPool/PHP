# x-laravel/pulse-requests

> 标签: http, laravel, monitoring, pulse, requests

## 简介

Laravel Pulse card counting incoming requests by HTTP status, grouped by route pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
