# x-laravel/spatie-media-library-uuid-path

> 标签: laravel, media-library, path-generator, spatie, uuid

## 简介

A UUID-based path generator for spatie/laravel-medialibrary.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
