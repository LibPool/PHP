# x-laravel/sluggable

> 标签: eloquent, history, laravel, slug, sluggable, url

## 简介

Slugs for Eloquent models with language-aware generation, race-safe uniqueness and a history that keeps old links working.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
