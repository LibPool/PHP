# x-laravel/bookmarkable

> 标签: bookmark, bookmarkable, collections, eloquent, folders, laravel

## 简介

Bookmarks for Eloquent models with private or shared folders and a default folder for one-tap saving.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
