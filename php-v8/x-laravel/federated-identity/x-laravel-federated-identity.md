# x-laravel/federated-identity

> 标签: Federated Identity, ID Token, OpenID Connect, Social Login, apple, google, jwt, laravel, oidc, sign in with apple

## 简介

Verify Google, Apple and any OpenID Connect ID token sent from mobile and single-page apps, and link it to a Laravel account safely.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
