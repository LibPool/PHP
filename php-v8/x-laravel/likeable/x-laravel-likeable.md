# x-laravel/likeable

> 标签: eloquent, laravel, like, likeable, likers, polymorphic

## 简介

Likes for Eloquent models with polymorphic likers, liked-state queries and cleanup of orphaned likes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
