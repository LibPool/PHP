# postiefs/laravel-filament-sso

> 标签: SSO, entra-id, filament, laravel, microsoft-365, postiefs

## 简介

Filament panel plugin for the Postiefs SSO portal: a Microsoft 365 sign-in button next to the local login, portal-controlled sessions and sign-out to the launchpad.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
