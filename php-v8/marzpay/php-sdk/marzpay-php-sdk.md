# marzpay/php-sdk

> 标签: Uganda, api, collections, disbursements, laravel, marzpay, mobile-money, payments, sdk

## 简介

Official PHP SDK for MarzPay - Mobile Money Payment Platform for Uganda

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
