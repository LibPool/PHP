# koriaking/flarum-lang-ukranian

> 标签: flarum, language, locale, translation, ukranian

## 简介

Ukrainian language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
