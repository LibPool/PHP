# sjj/view-model

> 标签: View Model, laravel

## 简介

Laravel Model 数据访问层, ViewModel 业务展示层, 多项目 Model 共享, 提供只读数据,强类型访问.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
