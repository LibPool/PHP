# protonlabs/php-adblock-parser

> 标签: adblock, parser

## 简介

PHP parser for Adblock Plus filters. A fork of abandoned limonte/php-adblock-parser

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
