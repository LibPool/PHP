# jivochat/bigcommerce-api

> 标签: api, business, ecommerce, http, rest

## 简介

Enables PHP applications to communicate with the Bigcommerce API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://developer.bigcommerce.com
- 源码仓库：https://github.com/JivoChat/bigcommerce-api-php.git
