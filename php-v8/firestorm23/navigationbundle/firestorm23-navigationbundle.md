# firestorm23/navigationbundle

> 标签: PHP

## 简介

Symfony bundle for defining menu-structures and breadcrumbs in the KnpMenuBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
