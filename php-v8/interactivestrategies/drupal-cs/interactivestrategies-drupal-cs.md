# interactivestrategies/drupal-cs

> 标签: phpcs

## 简介

Custom Interactive Strategies code sniffer ruleset for Drupal projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
