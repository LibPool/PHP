# trademinator/indicators

> 标签: bcmath, ccxt, indicators, ohlcv, technical-analysis

## 简介

Framework-agnostic BCMath technical indicators, candlestick patterns and CCXT OHLCV normalization.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
