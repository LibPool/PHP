# konspyracylabs/filament-fuse

> 标签: circuit-breaker, filament, filament-fuse, filament-plugin, filamentphp, fuse, konspyracylabs, laravel, observability

## 简介

Filament panel plugin for harris21/laravel-fuse — a live circuit-breaker dashboard in the panel you already have.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
