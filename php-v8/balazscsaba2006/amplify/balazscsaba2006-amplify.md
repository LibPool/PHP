# balazscsaba2006/amplify

> 标签: Craft, Craft accelerated mobile pages, Craft amp, amp, amplify, cms, craft-plugin, craftcms

## 简介

Twig filter for Craft CMS to optimize rich text content for Google AMP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
