# ricoa/copywriting-correct

> 标签: copywriting-correct, php

## 简介

中英文文案排版纠正器，帮助解决中英文混排的排版问题

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
