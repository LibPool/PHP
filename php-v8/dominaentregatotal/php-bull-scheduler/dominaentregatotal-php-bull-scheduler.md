# dominaentregatotal/php-bull-scheduler

> 标签: bull, nodejs, php, queue, redis, scheduler

## 简介

PHP library to schedule Redis jobs for the NodeJS Bull Redis queue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
