# ceytek-labs/openai

> 标签: ChatGpt, Transcription, ai, api, image recognition, lite library, openai, php, text to speech

## 简介

A lightweight library for seamless integration with the OpenAI API in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
