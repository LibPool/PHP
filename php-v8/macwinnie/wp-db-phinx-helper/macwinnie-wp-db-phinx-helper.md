# macwinnie/wp-db-phinx-helper

> 标签: PHP

## 简介

Helper for WordPress plugins to be able to use [Phinx](https://phinx.org/) for DB migrations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
