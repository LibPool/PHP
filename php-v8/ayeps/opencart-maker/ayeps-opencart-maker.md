# ayeps/opencart-maker

> 标签: code generator, generator, scaffold, scaffolding

## 简介

Opencart Maker Tool - fast way to generate opencart extension, modules, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
