# klongchu/laravelpdfviewer

> 标签: ViewerJS, laravel, laravel-viewerJS, pdf-viewer

## 简介

A Laravel Package for viewing PDF files or documents on Web App

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
