# fosbury/fosbury

> 标签: client, http, http client, loyalty, passbook, rest, web service, wrapper

## 简介

Fosbury is an PHP API Client for Fosbury (http://fosbury.co)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
