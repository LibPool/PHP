# switon/crypto

> 标签: crypto, encryption, keys, openssl, switon

## 简介

Symmetric encryption, derived keys, plaintext validation, and key rotation for Switon Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
