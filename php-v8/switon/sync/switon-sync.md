# switon/sync

> 标签: channels, mutex, switon, synchronization

## 简介

In-process channels, mutexes, wait groups, and stacks for coroutine-aware coordination for Switon Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
