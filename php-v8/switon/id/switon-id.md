# switon/id

> 标签: ids, snowflake, switon, uuid

## 简介

Named ID generators for UUIDs, ULIDs, Snowflake, and compact public IDs for Switon Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
