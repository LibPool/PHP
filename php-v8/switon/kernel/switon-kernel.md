# switon/kernel

> 标签: bootstrap, kernel, providers, switon

## 简介

Application bootstrap for environment, config, provider lifecycle, and fatal error handling for Switon Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
