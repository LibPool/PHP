# switon/http-cache

> 标签: cache, filter, http, page-cache, responses, switon

## 简介

Redis-backed per-action HTTP caching with request-derived keys and ETag revalidation for Switon Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
