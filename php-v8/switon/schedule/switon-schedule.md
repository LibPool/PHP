# switon/schedule

> 标签: Tasks, schedule, scheduler, switon

## 简介

Recurring scheduled tasks with a shared app clock, discovery, and optional Redis locking for Switon Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
