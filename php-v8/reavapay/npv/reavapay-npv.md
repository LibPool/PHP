# reavapay/npv

> 标签: africa, laravel, mobile-money, mpesa, payments, reava-pay

## 简介

Reava Pay payment gateway connector for NPV — Admin UI, webhooks, transaction tracking, one-click connect, auto invoice receipts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
