# reavapay/jipange

> 标签: gateway, jipange, kenya, mpesa, payments, reavapay, split-bills

## 简介

Reava Pay payment gateway connector for Jipange — replaces direct M-Pesa integration with Reava Pay gateway processing for STK Push, B2C, B2B, and all payment operations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
