# samiksengupta/laravel-admin

> 标签: admin, laravel, laravel-admin, samiksengupta

## 简介

A quick way to set up an admin panel, API endpoints and routing for a Laravel project

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
