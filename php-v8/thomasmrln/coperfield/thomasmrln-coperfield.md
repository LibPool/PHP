# thomasmrln/coperfield

> 标签: abstraction, coperfield, database, db, php

## 简介

PHP class to apply a lighter abstraction for databases languages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
