# kmi/db-sync-tool

> 标签: database, drupal, export, import, symfony, sync, synchronisation, typo3, wordpress

## 简介

Python script to synchronize a database from and to client systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
