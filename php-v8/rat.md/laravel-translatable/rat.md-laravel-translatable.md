# rat.md/laravel-translatable

> 标签: eloquent, laravel, rat, translatable

## 简介

Awesome translatable Laravel Eloquent models (for MySQL, MariaDB, PostgreSQL, SQLite & MongoDB).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
