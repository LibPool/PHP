# dnadesign/gridfield-bulk-delete

> 标签: bulk, delete, gridfield, silverstripe

## 简介

A GridField component allowing to delete records in bulk

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
