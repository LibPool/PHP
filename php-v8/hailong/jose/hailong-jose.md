# hailong/jose

> 标签: ID Token, JOSE, JSON Web Encryption, JSON Web Signature, JSON Web Token, JWE, JWS, OpenID Connect, jwt

## 简介

JWT, JWS and JWE implementation in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
