# io-digital/laravel-sendgrid-driver

> 标签: io-digital, laravel, mail, sendgrid

## 简介

SendGrid driver for Laravel's mail configuration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
