# lfnds/sdk

> 标签: charity, donation

## 简介

PHP SDK for the elefunds API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://elefunds.github.io/elefunds-SDK/
- 源码仓库：https://github.com/elefunds/elefunds-PHP.git
