# codecorner/laravel-datagrid

> 标签: bulk-actions, datagrid, datatable, export, filters, grid, import, laravel

## 简介

Extensible, queue-powered data grid for Laravel with a backend-defined schema, Next.js and Blade renderers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
