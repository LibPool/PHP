# brs-software/html2pdf

> 标签: brs, html, pdf, wkhtmltopdf

## 简介

Common interface for converting HTML documents to PDF using adapters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
