# nocache-dev/laravel

> 标签: cache-control, cdn, http-cache, laravel, middleware, nocache.dev

## 简介

Correct Cache-Control headers for Laravel responses, plus artisan commands to check URLs and manage nocache.dev monitors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
