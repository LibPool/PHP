# byjesper/laravel-decision-support

> 标签: PHP

## 简介

Read-only, DB-backed decision-support guide engine for Laravel (graph-first, resumable evaluator, Mermaid).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
