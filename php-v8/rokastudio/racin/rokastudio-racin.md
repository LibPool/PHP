# rokastudio/racin

> 标签: active-record, api, framework, generators, json, jwt, orm, rails, rest

## 简介

A small, fast PHP 8.3+ framework for JSON APIs: Rails-style controllers and generators, ActiveRecord-style models, serializers, JWT auth, queues, mail, image uploads and WebSockets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
