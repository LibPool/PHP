# uptime-it/nova-ckeditor4-field

> 标签: CKEditor, laravel, nova

## 简介

This nova package allows you to use CKEditor 4 for text areas.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
