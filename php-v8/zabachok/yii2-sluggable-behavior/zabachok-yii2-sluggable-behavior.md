# zabachok/yii2-sluggable-behavior

> 标签: behavor, extension, slugg, translit, yii2

## 简介

Поведение для транслитерации кирилицы в латиницу.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
