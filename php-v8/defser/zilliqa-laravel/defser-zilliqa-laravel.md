# defser/zilliqa-laravel

> 标签: api, blockchain, contracts, laravel, php, sdk, token, wrapper, zil, zilliqa

## 简介

Laravel SDK wrapper for the PHP API client that interacts with the Zilliqa blockchain.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
