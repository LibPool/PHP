# clue/ndjson-react

> 标签: NDJSON, json, jsonlines, newline, reactphp, streaming

## 简介

Streaming newline-delimited JSON (NDJSON) parser and encoder for ReactPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
