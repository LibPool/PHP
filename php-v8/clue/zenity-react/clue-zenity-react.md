# clue/zenity-react

> 标签: async, desktop, dialog, gui, reactphp, zenity

## 简介

Zenity allows you to build graphical desktop (GUI) applications in PHP, built on top of ReactPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
