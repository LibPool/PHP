# clue/stream-filter

> 标签: bucket brigade, callback, filter, php_user_filter, stream, stream_filter_append, stream_filter_register

## 简介

A simple and modern approach to stream filtering in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
