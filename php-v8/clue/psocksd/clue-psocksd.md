# clue/psocksd

> 标签: SOCKS proxy, forwarding, proxy server, reactphp, server daemon, tcp tunnel

## 简介

The SOCKS tunnel / proxy server daemon written in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
