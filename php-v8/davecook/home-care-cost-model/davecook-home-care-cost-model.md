# davecook/home-care-cost-model

> 标签: aging-in-place, canada, cost-model, home-care, psw, tax-credit

## 简介

A reference cost model for Canadian home care service-mix decisions (PSW, housekeeping, nursing) with 2026 tax relief stack and per-province subsidy eligibility.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
