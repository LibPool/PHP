# mullema/k3-panel-view-extended

> 标签: PHP

## 简介

Allow single language pages/site/users in a multi language setup, hide buttons in topbar and sections.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
