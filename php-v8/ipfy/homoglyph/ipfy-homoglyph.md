# ipfy/homoglyph

> 标签: confusable, homoglyph, homograph, idn, unicode, uts39

## 简介

Detect visually confusable domain names using Unicode UTS #39.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
