# k-gun/oppa

> 标签: Abstraction Layer, Active Record, database, mysql, pgsql

## 简介

Oppa: Database abstraction, query building and active record implementation with PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
