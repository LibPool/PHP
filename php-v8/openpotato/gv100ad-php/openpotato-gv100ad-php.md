# openpotato/gv100ad-php

> 标签: destatis, gemeindeverzeichnis, germany, gv100ad, parser

## 简介

A PHP library for parsing GV100AD files (Gemeindeverzeichnis) provided by Destatis.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
