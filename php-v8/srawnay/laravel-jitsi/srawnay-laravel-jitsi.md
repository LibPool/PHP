# srawnay/laravel-jitsi

> 标签: laravel-jitsi, srawnay

## 简介

A package to generate view of a Jitsi Meet room using Jitsi Meet IFrame API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
