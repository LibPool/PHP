# nael_d/telegramify

> 标签: Telegram-API, php, security, sms-alternative, telegram, telegram-gateway, two-factor-authentication, verification-code

## 简介

Telegramify: Simplify Telegram verification code delivery, offering a more affordable, secure and reliable alternative to SMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
