# vvb/max-laravel

> 标签: Messenger, api, bot, laravel, max, max bot, max messenger, max-messenger, max.ru, notifications, php, sdk, webhook

## 简介

Laravel-пакет для интеграции с API мессенджера Max (боты, WebApp, уведомления, webhook).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
