# fogeto/laravel-server-orchestrator

> 标签: Metrics, laravel, monitoring, observability, orchestrator, prometheus

## 简介

Laravel Prometheus monitoring package for multi-project server orchestration. Compatible with Laravel 9-12.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
