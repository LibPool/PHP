# keenops/php-nhiftz

> 标签: api, claims, healthcare, nhif, ocs, sdk, servicehub, tanzania

## 简介

PHP wrapper for the NHIF Tanzania ServiceHub and OCS APIs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
