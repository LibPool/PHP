# keenops/auth-client

> 标签: SSO, auth-client, keenops, laravel, oauth2

## 简介

OAuth2 SSO client SDK for integrating Laravel applications with the Central Authentication Server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
