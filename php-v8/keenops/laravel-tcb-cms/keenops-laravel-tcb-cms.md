# keenops/laravel-tcb-cms

> 标签: Bank, TCB, cms, laravel, payment, tanzania

## 简介

Laravel package for integrating with Tanzania Commercial Bank's Cash Management System (CMS) API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
