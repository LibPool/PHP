# cuteninja/memoria-bundle

> 标签: api, common

## 简介

Common code handling fixtures for Cute-Ninja projects (Fixtures declared in config.yml, Command to load DB)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
