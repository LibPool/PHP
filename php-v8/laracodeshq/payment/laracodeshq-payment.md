# laracodeshq/payment

> 标签: laravel, multi-gateway, payment, payment-gateway, paypal, sslcommerz, stripe

## 简介

Universal multi-payment gateway package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
