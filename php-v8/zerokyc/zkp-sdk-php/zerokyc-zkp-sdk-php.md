# zerokyc/zkp-sdk-php

> 标签: Monero, USDT, Whmcs, bitcoin, blesta, crypto, gateway, payments, ton, woocommerce, zerokyc

## 简介

Official PHP SDK for the ZeroKYC Pay crypto payment gateway (no-KYC checkout for digital services).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
