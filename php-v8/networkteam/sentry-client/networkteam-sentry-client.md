# networkteam/sentry-client

> 标签: extension, monitoring, sentry, typo3

## 简介

A Sentry client for TYPO3. It forwards errors and exceptions to Sentry - https://sentry.io/

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
