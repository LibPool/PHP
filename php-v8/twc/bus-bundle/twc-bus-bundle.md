# twc/bus-bundle

> 标签: Symfony 4, command bus, cqrs, cqs, domain events, message bus, php, symfony, symfony 5

## 简介

Provide simple way to implement Message Bus concept in Symfony 4

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
