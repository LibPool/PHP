# zwernemann/magento2-chat

> 标签: PHP

## 简介

AI Chat for Magento 2 – free, open-source conversational AI assistant for the storefront (RAG product search + Anthropic Claude)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
