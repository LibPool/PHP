# promptphp/intercept

> 标签: Agent, ai, governance, laravel, middleware, observability, performance, pii-redaction, prompt-injection, promptphp, rate-limiting, security, semantic-caching

## 简介

A middleware collection for Laravel AI SDK agents providing middleware across security, observability, performance and guidance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
