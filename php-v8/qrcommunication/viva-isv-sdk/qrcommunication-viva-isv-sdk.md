# qrcommunication/viva-isv-sdk

> 标签: VivaWallet, isv, marketplace, payment, sdk, viva

## 简介

PHP SDK for Viva Wallet ISV Partner API — connected accounts, ISV orders, composite auth, Cloud Terminal

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
