# qrcommunication/withallo-sdk

> 标签: allo, api, calls, contacts, sdk, sms, webhooks, withallo

## 简介

PHP SDK for Withallo (Allo) API — webhooks, calls, contacts, SMS and phone numbers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
