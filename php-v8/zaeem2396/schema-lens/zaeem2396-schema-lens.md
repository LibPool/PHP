# zaeem2396/schema-lens

> 标签: artisan, cli, data-export, database, database-backup, destructive-changes, environments, laravel, migration, mysql, mysqldump, pgsql, postgresql, preview, schema, schema-diff

## 简介

Laravel package to preview migration files against current MySQL or PostgreSQL schema with destructive change detection and data export

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
