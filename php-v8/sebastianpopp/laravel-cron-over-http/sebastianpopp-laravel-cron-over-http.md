# sebastianpopp/laravel-cron-over-http

> 标签: Sebastian Popp, laravel, laravel-cron-over-http

## 简介

Run your Laravel cron jobs and queue over HTTP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
