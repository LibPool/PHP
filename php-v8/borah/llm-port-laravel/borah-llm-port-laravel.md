# borah/llm-port-laravel

> 标签: Borah, laravel, llm-port-laravel

## 简介

Wrapper around the most popular LLMs that allows drop-in replacement of large language models in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
