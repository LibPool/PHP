# rodrigoq/phpmailersendgrid

> 标签: email, mailer, phpmailer, sendgrid

## 简介

PHPMailer extension to send emails via Sendgrid (or save to file).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
