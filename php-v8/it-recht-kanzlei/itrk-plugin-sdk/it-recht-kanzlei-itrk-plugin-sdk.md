# it-recht-kanzlei/itrk-plugin-sdk

> 标签: Advertising, IT-Recht, Legal Texts, data privacy, terms and conditions

## 简介

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
