# breadbunch/ory-bundle

> 标签: bread, bundle, ory, ory-bundle, security, symfony

## 简介

Symfony 8+ integration bundle for Ory ecosystem (Kratos, Oathkeeper, Network)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
