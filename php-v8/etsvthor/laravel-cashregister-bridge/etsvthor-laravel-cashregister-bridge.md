# etsvthor/laravel-cashregister-bridge

> 标签: etsvThor, laravel, laravel-cashregister-bridge

## 简介

Connect a laravel application with the Thor cash register

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
