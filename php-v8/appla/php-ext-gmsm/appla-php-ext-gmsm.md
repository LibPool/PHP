> 标签: cryptography, gbt-32918, gmt-0009, guomi, libcrypto, openssl, php, php-extension, sm2, sm3, sm4

## 简介

High-performance PHP 8.3+ C extension for Chinese Commercial Cryptography (SM2/SM3/SM4, GB/T 32918, 32905, 32907) built on OpenSSL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
