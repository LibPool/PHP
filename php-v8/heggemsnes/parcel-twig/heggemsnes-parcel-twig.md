# heggemsnes/parcel-twig

> 标签: Craft, cms, craft-plugin, craftcms, parceltwig

## 简介

Get correct asset paths from Parcel when using Parcel Manifest.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
