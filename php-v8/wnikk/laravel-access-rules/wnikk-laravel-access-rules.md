# wnikk/laravel-access-rules

> 标签: Policy, abac, access-control, acl, attribute-based, authorization, gate, laravel, multi-tenant, permissions, rbac, roles, security, xacml

## 简介

Fast access control for Laravel: RBAC with roles, groups and unlimited inheritance, extended to ABAC: conditions on any model, its relations and aggregates, with list filtering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
