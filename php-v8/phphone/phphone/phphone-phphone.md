# phphone/phphone

> 标签: android, compiler, embedded-php, framework, hybrid, ios, mobile, php, phphone, sqlite

## 简介

Next-Generation PHP-Native Hybrid Framework and Compiler for Android, iOS, and Desktop with Embedded PHP 8.4 runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
