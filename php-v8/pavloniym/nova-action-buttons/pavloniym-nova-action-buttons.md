# pavloniym/nova-action-buttons

> 标签: actions, buttons, laravel, nova, nova-field

## 简介

Laravel Nova 5 field that runs resource actions from buttons on index and detail views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
