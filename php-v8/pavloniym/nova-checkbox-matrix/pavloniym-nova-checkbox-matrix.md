# pavloniym/nova-checkbox-matrix

> 标签: checkbox, laravel, matrix, nova, nova-field

## 简介

A Laravel Nova 5 field: a rows × columns checkbox matrix with search, avatars and per-column counters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
