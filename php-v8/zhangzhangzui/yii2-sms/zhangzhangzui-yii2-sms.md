# zhangzhangzui/yii2-sms

> 标签: AliyunSMS, aliyun, qcloud, qcloudsms, sms, tencentcloudSms, yii2

## 简介

Yii2 多渠道短信组件 — 模板映射 + 自动 Failover + 回执回调

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
