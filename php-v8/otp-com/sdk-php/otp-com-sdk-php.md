# otp-com/sdk-php

> 标签: 2fa, API-Client, one-time-password, otp, sdk, verification

## 简介

PHP client for the otp.com OTP API: send, verify, and resend one-time passwords.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
