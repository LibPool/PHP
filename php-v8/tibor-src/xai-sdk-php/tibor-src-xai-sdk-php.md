# tibor-src/xai-sdk-php

> 标签: grok, php, sdk, spacexai

## 简介

Unofficial PHP port of the experimental SpaceXAI TypeScript SDK (@xai-official/sdk).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
