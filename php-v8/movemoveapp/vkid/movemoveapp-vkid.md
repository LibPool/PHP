# movemoveapp/vkid

> 标签: laravel, movemove, oauth, pkce, sdk, vk

## 简介

VK ID OAuth 2.1 (id.vk.ru) Socialite provider with PKCE (cache-based, stateless-friendly).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
