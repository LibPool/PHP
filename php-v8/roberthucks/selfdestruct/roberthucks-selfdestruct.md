# roberthucks/selfdestruct

> 标签: roberthucks, selfdestruct

## 简介

A package used to give Laravel Models the ability to self-delete after a specified time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
