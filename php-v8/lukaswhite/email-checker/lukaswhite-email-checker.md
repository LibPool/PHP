# lukaswhite/email-checker

> 标签: PHP

## 简介

A PHP package that checks e-mail addresses to see if they're disposable, or from a provider of free addresses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
