# zephyrus-framework/core

> 标签: PHP

## 简介

Cohesive PHP 8.4+ framework — attribute routing, immutable HTTP, typed config, and security middleware out of the box.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
