# bugbuster/contao-lang_to_url

> 标签: addLanguageToUrl, contao, language

## 简介

Contao CMS - add language to URL only for defined domains

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
