# bugbuster/contao-botstatistics-bundle

> 标签: contao, counter, statistic

## 简介

Contao 5 BotStatistics Bundle - Counts the number of bot requests (visits, pages).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
