# bugbuster/browscap-lite

> 标签: Browscap, browser, detection

## 简介

The standalone PHP Browscap parser, lite version of crossjoin/Browscap for BugBuster Botdetection

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
