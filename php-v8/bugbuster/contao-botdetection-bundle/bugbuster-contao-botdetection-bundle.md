# bugbuster/contao-botdetection-bundle

> 标签: bots, bundle, contao, detection

## 简介

Contao bundle helper class to detect search engines, bots, spiders, crawlers ...

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
