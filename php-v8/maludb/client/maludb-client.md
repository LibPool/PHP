# maludb/client

> 标签: Audit, knowledge, llm, maludb, memory, postgresql, rag

## 简介

PHP driver for MaluDB — a memory DBMS on PostgreSQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/edwardhonour/maludb-core
- 源码仓库：https://github.com/maludb/maludb-client-php.git

## 获取地址

- Composer 安装：`composer require maludb/client`
- Packagist 仓库：https://repo.packagist.org/p2/maludb/client.json
- 许可证：PostgreSQL
