# yaroslawww/laravel-i18n-strings-batch

> 标签: js-i18n, laravel

## 简介

Simple way to transfer strings to js component without load all lang files or additional ajax requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
