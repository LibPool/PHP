# jwh315/laravel-capsule-wrapper

> 标签: PHP

## 简介

Use the Eloquent ORM outside of the Laravel Framework with an existing PDO database connection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
