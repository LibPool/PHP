# mosl/magic-link-bundle

> 标签: Passwordless, bundle, capability-url, magic-link, one-time, single-use, symfony, token

## 简介

Symfony bundle for single-use, expiring capability links that grant access without a user account

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
