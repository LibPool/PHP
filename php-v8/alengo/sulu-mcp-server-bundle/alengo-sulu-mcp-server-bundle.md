# alengo/sulu-mcp-server-bundle

> 标签: PHP

## 简介

Read-only HTTP API exposing local Sulu template XML files (pages, articles, blocks, snippets, properties) for use by MCP servers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
