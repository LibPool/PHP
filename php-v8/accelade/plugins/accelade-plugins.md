# accelade/plugins

> 标签: accelade, admin, generator, laravel, package, panel, plugins, scaffold

## 简介

Complete plugin system with generator, management, and auto-discovery for Accelade ecosystem

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/accelade/plugins
- 源码仓库：https://github.com/accelade/plugins.git
- Packagist 页面：https://packagist.org/packages/accelade%2Fplugins

- Composer 安装：`composer require accelade/plugins`
