# accelade/grids

> 标签: accelade, blade, cards, gallery, grids, laravel, masonry

## 简介

Grid components for Accelade - display data in cards, masonry layouts, and responsive grids

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
