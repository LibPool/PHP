# asfop/cache-kv

> 标签: cache, hot-key, key-value, kv, performance, php, redis, statistics

## 简介

简化缓存操作的 PHP 库，专注于实现若无则从数据源获取并回填缓存这一常见模式

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
