# johnnymck/shippingforecast

> 标签: PHP

## 简介

Shipping Forecast scraping library, pulling data from the BBC's shipping forecast page. Based on tnm/shipping-forecast

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
