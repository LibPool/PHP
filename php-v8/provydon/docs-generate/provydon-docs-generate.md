# provydon/docs-generate

> 标签: PHP

## 简介

Automatic API documentation for your Laravel app — zero annotations, OpenAPI 3.0 JSON & Swagger UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
