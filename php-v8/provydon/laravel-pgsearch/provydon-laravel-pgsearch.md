# provydon/laravel-pgsearch

> 标签: PHP

## 简介

PostgreSQL-friendly search for Eloquent (ILIKE + normalization; optional FTS/trigram later).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
