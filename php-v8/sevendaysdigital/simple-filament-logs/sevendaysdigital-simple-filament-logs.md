# sevendaysdigital/simple-filament-logs

> 标签: SevendaysDigital, laravel, simple-filament-logs

## 简介

Very simple log list for filament with helpers to use across code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
