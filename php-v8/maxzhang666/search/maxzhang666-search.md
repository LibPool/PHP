# maxzhang666/search

> 标签: blomstra, elastic, elasticsearch, extension, flarum, fulltext, search

## 简介

Replaces Flarum search with one powered by an elastic search server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
