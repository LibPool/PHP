# pralhadstha/aftership-laravel

> 标签: aftership, api, courier, delivery, driver-pattern, dto, ecommerce, laravel, logistics, parcel, sdk, shipment-tracking, shipping, tracking, webhook

## 简介

A modern Laravel wrapper for the AfterShip Tracking API with driver support, DTOs, and webhook handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
