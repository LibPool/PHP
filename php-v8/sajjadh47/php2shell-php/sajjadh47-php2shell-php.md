# sajjadh47/php2shell-php

> 标签: cve, php, php2shell, scanner, security

## 简介

Detect php2shell (CVE-2026-109618 / CVE-2026-109619) on remote PHP targets — behavioral multipart probes, version fallback, async CLI in PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
