# shibbirweb/peep

> 标签: debug, debugger, dump, laravel, mail, php, queries, sms, webhook

## 简介

Debug any PHP app in a separate window: values, queries, jobs, logs, exceptions, mail and SMS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
