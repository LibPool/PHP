# cyberwizard/laravel-ftp-deployer

> 标签: PHP

## 简介

Run Laravel Artisan commands on remote servers via FTP and HTTP triggers (useful for hosting without SSH).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
