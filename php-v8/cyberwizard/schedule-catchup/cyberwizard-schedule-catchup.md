# cyberwizard/schedule-catchup

> 标签: catchup, downtime, laravel, schedule, scheduler

## 简介

Automatic post-downtime catch-up for missed Laravel scheduled events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
