# cristian100/mouseover_detect

> 标签: desktop, event, javascript, jquery, mobile, mouseover, touch

## 简介

Detects if browser supports mouseover event.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
