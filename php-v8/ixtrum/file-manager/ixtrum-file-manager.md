# ixtrum/file-manager

> 标签: ajax, component, file manager, nette, php

## 简介

Comfortable PHP & AJAX file manager component for Nette framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
