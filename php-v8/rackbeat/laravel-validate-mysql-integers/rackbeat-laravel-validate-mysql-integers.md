# rackbeat/laravel-validate-mysql-integers

> 标签: bigint, int, integer, laravel, mysql, rule, smallint, tinyint, unsigned, validation

## 简介

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
