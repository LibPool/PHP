# sofizpay/sofizpay-php-sdk

> 标签: Algeria, Stellar, cib, dzt, edahabiya, payment, sdk, sofizpay

## 简介

The official SofizPay PHP SDK for digital payments, Stellar transactions, and Algerian bank deposits (CIB / Edahabiya).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
