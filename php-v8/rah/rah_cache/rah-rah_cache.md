# rah/rah_cache

> 标签: cache, flat, page, performance, plugin, speed, textpattern

## 简介

Flat full-page caching plugin for Textpattern CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
