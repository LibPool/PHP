# koolreport/mongodb

> 标签: Data Report, Reporting Tools, charts, mongodb, php

## 简介

Allow KoolReport to work with MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
