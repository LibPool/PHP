# hhvm/xhp-js

> 标签: JS, facebook, hack, hhvm, javascript, react, xhp

## 简介

Easily create JS controllers for XHP elements, and XHP wrappers for React elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
