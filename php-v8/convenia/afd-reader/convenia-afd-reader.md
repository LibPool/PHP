# convenia/afd-reader

> 标签: AFD, acjef, afdt, mte, php

## 简介

Pacote para leitura de Arquivo Fonte de Dados (AFD). Especificação do MTE referente a portaria 1.510/2009.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
