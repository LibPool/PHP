# jeroendesloovere/fork-cms-php-api

> 标签: Fork CMS, api, cms, php

## 简介

This Fork CMS PHP class can communicate with a Fork CMS websites API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
