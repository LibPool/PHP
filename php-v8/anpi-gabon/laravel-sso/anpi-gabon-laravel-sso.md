# anpi-gabon/laravel-sso

> 标签: SSO, anpi, gabon, laravel, oauth2, socialite

## 简介

Intégration OAuth 2.0 (SSO) pour les applications du périmètre ANPI-Gabon — Laravel Socialite driver.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
