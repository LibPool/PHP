# softspring/docker-php72-appengine-dev

> 标签: PHP

## 简介

Docker AppEngine Nginx+PHP image for developing with sudo and Xdebug

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
