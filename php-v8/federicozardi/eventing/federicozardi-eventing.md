# federicozardi/eventing

> 标签: PHP

## 简介

Framework-agnostic eventing toolkit for PHP: EventBridge publishing, DynamoDB event store, HMAC-secured webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
