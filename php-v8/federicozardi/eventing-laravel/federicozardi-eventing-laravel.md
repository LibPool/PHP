# federicozardi/eventing-laravel

> 标签: PHP

## 简介

Laravel integration for federicozardi/eventing: prebuilt EventBridge webhook with HMAC authentication and handler dispatch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
