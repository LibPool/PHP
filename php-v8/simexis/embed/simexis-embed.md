# simexis/embed

> 标签: embed, embedly, oembed, opengraph, simexis, twitter cards

## 简介

PHP library to retrieve page info using oembed, opengraph, etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
