# duncan3dc/oauth

> 标签: github, instagram, lovefilm, oauth, oauth2, twitter

## 简介

Handles basic OAuth/OAuth2 authentication along with classes for common services

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
