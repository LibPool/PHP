# rogerliao/phalcon

> 标签: PHP

## 简介

A PHP web framework inspired by the Koa concept, adopting its middleware design pattern for building modern and flexible web applications and APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
