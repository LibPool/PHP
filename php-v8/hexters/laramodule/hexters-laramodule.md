# hexters/laramodule

> 标签: laravel, laravel hmvc, laravel modular, laravel module, laravel package

## 简介

Laramodule is an HMVC pattern for the Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
