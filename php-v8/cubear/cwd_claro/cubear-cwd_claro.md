# cubear/cwd_claro

> 标签: PHP

## 简介

Light enhancements for the Drupal admin theme Claro; from Cornell University CIT-CD.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
