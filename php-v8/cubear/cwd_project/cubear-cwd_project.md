# cubear/cwd_project

> 标签: PHP

## 简介

A lightweight Drupal 8 child theme, to be used with cubear/cwd_base; from Cornell University CIT-CD.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
