# tecnickcom/tc-lib-pdf-filter

> 标签: compression, encryption, filter, pdf, tc-lib-pdf-filter

## 简介

PHP library to decode PDF compression and encryption filters

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
