# tecnickcom/tc-lib-pdf-encrypt

> 标签: aes, encrypt, encryption, pdf, rc4, tc-lib-pdf-encrypt

## 简介

PHP library to encrypt and decrypt PDF data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
