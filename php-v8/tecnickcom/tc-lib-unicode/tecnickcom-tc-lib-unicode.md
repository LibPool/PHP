# tecnickcom/tc-lib-unicode

> 标签: font, pdf, tc-lib-unicode, unicode, utf-8

## 简介

PHP library to process UTF-8 and Unicode text

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
