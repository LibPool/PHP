# richnessagency/rich-whatsapp

> 标签: laravel, messaging, notifications, rich-whatsapp, whatsapp, whatsapp-web

## 简介

Laravel integration package and dashboard for a standalone WhatsApp Web Node.js bridge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
