# peppol-sh/sdk

> 标签: Belgium, E-Invoice, EN16931, api, e-invoicing, einvoicing, invoice, laravel, peppol, peppol-bis, sdk, ubl

## 简介

Official PHP SDK for the peppol.sh Peppol API: Peppol e-invoicing (UBL, EN 16931) for PHP and Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
