# fansipan/fansipan

> 标签: api, http, psr17, psr18, psr7, sdk

## 简介

A simple package that allows you to write your API integrations or SDKs in a elegant way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
