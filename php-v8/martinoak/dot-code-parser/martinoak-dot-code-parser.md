# martinoak/dot-code-parser

> 标签: dot, dot-code, parser, tin, tire, tyre

## 简介

Parse tire DOT codes into factory code, size code, week and year of manufacture.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
