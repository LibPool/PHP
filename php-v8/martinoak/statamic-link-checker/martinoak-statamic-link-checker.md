# martinoak/statamic-link-checker

> 标签: broken-links, link-checker, statamic, statamic-addon

## 简介

Universal link checker for Statamic v6 – checking link availability in content and showing them in CP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
