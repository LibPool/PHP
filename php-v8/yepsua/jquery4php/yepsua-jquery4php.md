# yepsua/jquery4php

> 标签: jQuery plugins, jQuery4PHP, jQueryUI, jquery, php

## 简介

Makes easy writing javascript code (jQuery syntax) using PHP objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
