# innerloop-dev/lightspeed

> 标签: Broadcasting, WebSockets, laravel, pusher, realtime, swoole

## 简介

Swoole-based, Pusher-compatible realtime server for Laravel with multi-worker relay, shared presence, per-resource write leases, and multi-instance owner routing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
