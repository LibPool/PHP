# tcytra/enraiged-exports

> 标签: enraiged, exports

## 简介

Enraiged Exports provides data exporting feature for Laravel Enraiged projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
