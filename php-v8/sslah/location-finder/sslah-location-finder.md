# sslah/location-finder

> 标签: OpenStreetMap, address-search, coordinates, geocoding, laravel, location-finder, nominatim, reverse-geocoding

## 简介

🚀 Laravel Location Finder - Professional geocoding package with OpenStreetMap. Clean API, consistent field naming, comprehensive error handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
