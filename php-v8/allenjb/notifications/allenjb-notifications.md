# allenjb/notifications

> 标签: AllenJB, email, error, notifications, reporting, sentry

## 简介

Library for handling error reports and developer notifications (via email or Sentry)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
