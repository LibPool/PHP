# m1ge0/bootsjet

> 标签: bootstrap, jetstream, laravel

## 简介

A Laravel 13-ready package for Jetstream + Livewire to switch from Tailwindcss to Bootstrap.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
