# 2chain/pimcore-messenger-dashboard

> 标签: PHP

## 简介

Pimcore admin dashboard for Symfony Messenger queues, with audit stats, delete/requeue, and permission gating.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
