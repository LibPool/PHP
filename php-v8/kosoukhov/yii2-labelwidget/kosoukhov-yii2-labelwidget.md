# kosoukhov/yii2-labelwidget

> 标签: extension, interface, label, widget, yii2

## 简介

Extension for Yii2 Framework to work with label bootstrap component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
