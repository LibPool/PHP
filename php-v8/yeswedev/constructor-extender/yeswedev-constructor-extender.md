# yeswedev/constructor-extender

> 标签: PHP

## 简介

Un trait qui permet de créer des fonctions qui seront appelé lors de l'instanciation de la classe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
