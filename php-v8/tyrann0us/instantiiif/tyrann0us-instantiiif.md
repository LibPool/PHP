# tyrann0us/instantiiif

> 标签: iiif, images, mediawiki

## 简介

MediaWiki Foreign FileRepo that hotlinks images from IIIF sources (Presentation API v2/v3).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
