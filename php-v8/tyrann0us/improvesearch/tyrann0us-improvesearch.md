# tyrann0us/improvesearch

> 标签: mediawiki, mysql, search

## 简介

MediaWiki extension that widens the built-in MySQL search: substring page titles, a wikitext-free search index and snippets, and no pointless thumbnail lookups.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
