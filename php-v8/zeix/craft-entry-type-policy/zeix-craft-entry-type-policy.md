# zeix/craft-entry-type-policy

> 标签: Craft, cms, craft-plugin, craftcms, entry-types, multisite, permissions

## 简介

Restrict which user groups may create entries of a given entry type, and how many entries of that type a section may hold — per site. Rules are editable in the control panel or version-controlled in a config file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
