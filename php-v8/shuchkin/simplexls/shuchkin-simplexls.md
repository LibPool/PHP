# shuchkin/simplexls

> 标签: backend, excel, parser, php, xls

## 简介

Parse and retrieve data from old format Excel XLS files. MS Excel 97 workbooks PHP reader.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
