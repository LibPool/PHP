# chocofamilyme/pubsub

> 标签: Microservice, events, eventsource, phalcon, pubsub

## 简介

Библиотека для реализаций паттерна Pub/Sub

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
