# chocofamilyme/pubsub-life

> 标签: Microservice, events, eventsource, pubsub

## 简介

Библиотека для реализаций паттерна Pub/Sub

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
