# lasselehtinen/mockingbird-webhook-client

> 标签: laravel, lasselehtinen, mockingbird-webhook-client

## 简介

This package receives Mockingbird webhooks and convert them into strongly typed Laravel events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
