# bem/bh

> 标签: BEM, bemjson, bh

## 简介

Template engine. BEMJSON -> HTML processor. PHP port of https://github.com/bem/bh

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
