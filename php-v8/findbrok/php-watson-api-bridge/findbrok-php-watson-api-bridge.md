# findbrok/php-watson-api-bridge

> 标签: Bridge, api, ibm, php, watson

## 简介

A simple PHP Wrapper around IBM Watson API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
