# mmanos/laravel-sqspushqueue

> 标签: aws, beanstalk, elastic, elasticbeanstalk, laravel, push, queue, sqs, worker

## 简介

An AWS SQS push queue driver for Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
