# cloud-solutions/zend-sentry

> 标签: log, logging, raven, sentry, zend-framework

## 简介

A Zend Framework 3 module that lets you log to the Sentry.io service.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
