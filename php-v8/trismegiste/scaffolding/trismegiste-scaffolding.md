# trismegiste/scaffolding

> 标签: phpunit, scaffolding, symfony

## 简介

Scaffolding for phpunit in symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/trismegiste%2Fscaffolding

## 获取地址

- Packagist 仓库：https://repo.packagist.org/p2/trismegiste/scaffolding.json
- PHP 要求：>=5.4
