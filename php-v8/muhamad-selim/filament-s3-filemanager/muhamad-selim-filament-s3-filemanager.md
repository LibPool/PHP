# muhamad-selim/filament-s3-filemanager

> 标签: PHP

## 简介

A Filament plugin for S3 file management with file and folder selection support. Supports Filament v3 and v4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
