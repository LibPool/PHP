# joacub/sphinxsearch

> 标签: indexing, query builder, search, search engine, sphinx, sphinxql, zf2

## 简介

Sphinx Search library provides SphinxQL indexing and searching features

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
