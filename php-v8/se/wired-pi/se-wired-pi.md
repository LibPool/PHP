# se/wired-pi

> 标签: GPIO, wiringPi

## 简介

WiredPi is a library for connecting php and the Raspberry Pi GPIO via wiringPi

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
