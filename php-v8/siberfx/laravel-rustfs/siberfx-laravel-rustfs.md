# siberfx/laravel-rustfs

> 标签: Flysystem, RustFS, admin-api, filesystem, iam, laravel, minio, object-storage, s3, storage

## 简介

RustFS for Laravel 13+: S3 data plane (buckets, objects, versioning, object lock, lifecycle, replication, encryption, notifications, select), the full RustFS Admin API (IAM, quotas, tiers, pools, heal, KMS, site replication...) and a "rustfs" filesystem disk.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
