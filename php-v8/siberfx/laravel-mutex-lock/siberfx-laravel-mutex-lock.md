# siberfx/laravel-mutex-lock

> 标签: advisory-lock, concurrency, laravel, lock, mutex, mysql, php-lock, postgresql, sqlite

## 简介

Laravel integration for php-lock/lock: database-backed mutexes for MySQL/MariaDB, PostgreSQL and SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
