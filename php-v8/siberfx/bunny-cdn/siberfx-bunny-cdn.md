# siberfx/bunny-cdn

> 标签: Bunny.net, Flysystem, bunny, bunnyCDN, cdn, dns, filesystem, laravel, storage, stream

## 简介

Bunny.net API client (pull zones, storage, stream, DNS) with a Flysystem v3 adapter and Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
