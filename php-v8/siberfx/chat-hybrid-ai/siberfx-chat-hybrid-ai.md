# siberfx/chat-hybrid-ai

> 标签: Gemini, Messenger, ai, chat, chatbot, claude, laravel, laravel-ai, live-chat, openai, react, support, vue

## 简介

API-first hybrid chat for Laravel: chat bubble, admin inbox, AI agents (Laravel AI SDK) that can search and check your data, human handoff, email transcripts, React and Vue widgets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
