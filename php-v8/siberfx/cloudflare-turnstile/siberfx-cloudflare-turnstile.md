# siberfx/cloudflare-turnstile

> 标签: blade, bot-protection, captcha, cloudflare, laravel, turnstile, validation

## 简介

Cloudflare Turnstile CAPTCHA integration for Laravel: Blade widget, validation rule, middleware and testing fake.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
