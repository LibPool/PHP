# siberfx/codelab-stats

> 标签: analytics, code-labs, codelabs, laravel, privacy-analytics, statistics

## 简介

Laravel client for CodeLabs Analytics (analytics.code-labs.nl): cached stats, a dashboard summary and optional JSON proxy routes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
