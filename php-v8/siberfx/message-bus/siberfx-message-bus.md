# siberfx/message-bus

> 标签: Broadcasting, Messenger, WebSockets, blade, command-bus, cqrs, event-bus, laravel, livewire, message-bus, query-bus, queue, react, realtime, reverb, vue

## 简介

A Symfony Messenger inspired message bus for Laravel: buses, middleware, transports, retries, failure transport and realtime broadcasting (Reverb, Pusher, Ably, webhooks) with first-party React, Vue, Livewire and Blade integrations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
