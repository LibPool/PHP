# moodlehq/moodle-plugin-ci

> 标签: actions, ci, github, moodle, testing, travis

## 简介

Helps running Moodle plugins analysis checks and tests under various CI environments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
