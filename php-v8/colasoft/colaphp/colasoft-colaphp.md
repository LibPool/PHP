# colasoft/colaphp

> 标签: High Performance, colaphp, framework, php, workerman

## 简介

High performance HTTP Service Framework for PHP based on Workerman.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.colaphp.com/
- 源码仓库：https://github.com/colaphp/colaphp.git
- Packagist 页面：https://packagist.org/packages/colasoft%2Fcolaphp

## 获取地址

- Composer 安装：`composer require colasoft/colaphp`
