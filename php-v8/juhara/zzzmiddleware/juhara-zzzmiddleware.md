# juhara/zzzmiddleware

> 标签: cache, library, middleware, php, slim, slim-3

## 简介

A cache middleware for Slim Framework (3.0) using ZzzCache

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
