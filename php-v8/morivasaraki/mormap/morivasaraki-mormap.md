# morivasaraki/mormap

> 标签: librenms, mormap, network, physical-map, topology

## 简介

MorMap: image-based port anchors and editable orthogonal cable maps inside LibreNMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
