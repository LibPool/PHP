# tenma/stubs

> 标签: Fibers, PHPStan, async, ide-helper, stubs, tenma

## 简介

Stubs of Tenma's PHP API (Http\Server, Threading\Task, FileSystem, Data, ...) for IDEs and PHPStan

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
