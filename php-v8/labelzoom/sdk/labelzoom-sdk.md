# labelzoom/sdk

> 标签: TSPL, barcode, dpl, epl, ipl, label, labelzoom, pdf, sbpl, zebra, zpl

## 简介

Official PHP SDK for the LabelZoom API. Converts barcode labels between ZPL, EPL, IPL, TSPL, DPL, SBPL, PDF, LabelZoom XML/JSON and raster images.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
