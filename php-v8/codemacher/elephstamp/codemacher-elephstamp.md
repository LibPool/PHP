# codemacher/elephstamp

> 标签: bitcoin, certification, notary, opentimestamps, ots, proof, timestamp

## 简介

PHP 8.2-compatible fork of CondorcetVote/ElephStamp for OpenTimestamps proofs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
