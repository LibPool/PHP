# codemacher/t3vault

> 标签: PHP

## 简介

T3Vault - Backup manager. Provides a backend module (admins only) embedding the standalone T3Vault application and provisions it independently of TYPO3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
