# gardenjs/typo3-fluid-proxy

> 标签: PHP

## 简介

Proxy / discovery / assets for Gardenjs TYPO3 Fluid renderer (render via TYPO3 bridge)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
