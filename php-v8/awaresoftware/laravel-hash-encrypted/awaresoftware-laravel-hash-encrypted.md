# awaresoftware/laravel-hash-encrypted

> 标签: AES-GCM, blind-index, eloquent, encrypted-search, hmac, laravel

## 简介

Searchable encrypted columns for Laravel: an HMAC blind index and an AES-256-GCM ciphertext packed into a single, indexable database value.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
