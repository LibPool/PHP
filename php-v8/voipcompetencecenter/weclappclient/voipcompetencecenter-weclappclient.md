# voipcompetencecenter/weclappclient

> 标签: client, php, rest-api, rfc7807, v2, weclapp

## 简介

Ein PHP-Client für die Weclapp REST-API v2 mit vollständiger Feature-Unterstützung

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
