# localgovdrupal/localgov_publications_importer

> 标签: PHP

## 简介

PDF to HTML publication importer for the LocalGovDrupal distribution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
