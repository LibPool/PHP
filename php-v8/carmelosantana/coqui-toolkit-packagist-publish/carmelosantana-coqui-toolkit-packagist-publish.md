# carmelosantana/coqui-toolkit-packagist-publish

> 标签: coqui, package-publishing, packagist, php-agents, toolkit

## 简介

Packagist package publishing toolkit for Coqui — submit, edit, and update packages on Packagist.org

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- Packagist 页面：https://packagist.org/packages/carmelosantana%2Fcoqui-toolkit-packagist-publish
