# revenexx/app-sdk

> 标签: app-sdk, open-runtimes, postgrest, revenexx, sdk, serverless

## 简介

revenexx App SDK for PHP — build revenexx Apps: a typed data client (mock, remote and runtime adapters), a router with one-line CRUD routes, App settings, the acting person and App events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
