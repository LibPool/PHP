# drop-in-gaming/scalingwpdb

> 标签: PHP

## 简介

LudicrousDB is a database class that supports replication, failover, load balancing, & partitioning, based on Automattic's HyperDB drop-in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
