# displace/ext-whisper

> 标签: PHP

## 简介

PHP 8.3+ native, in-process speech-to-text via whisper.cpp: 16kHz WAV in, text + timestamped segments out.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
