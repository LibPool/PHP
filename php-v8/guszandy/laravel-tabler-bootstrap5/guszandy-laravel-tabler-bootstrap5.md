# guszandy/laravel-tabler-bootstrap5

> 标签: Bootstrap 5, admin, composer, dashboard, laravel, package, tabler, vite

## 简介

Laravel package for integrating the Tabler admin template, built on Bootstrap 5 and Vite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
