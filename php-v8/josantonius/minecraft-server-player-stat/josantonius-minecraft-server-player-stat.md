# josantonius/minecraft-server-player-stat

> 标签: library, minecraft, minecraft-1-17, minecraft-player-stats, minecraft-server-player-stat, minecraft-server-stats, php, spigot

## 简介

PHP library to get live statistics about players on Minecraft servers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
