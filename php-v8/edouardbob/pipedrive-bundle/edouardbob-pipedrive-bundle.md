# edouardbob/pipedrive-bundle

> 标签: pipedrive, symfony, sync

## 简介

Internal bundle to sync entity fields ans calculated methods to pipedrive custom fields

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
