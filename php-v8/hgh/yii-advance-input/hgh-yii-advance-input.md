# hgh/yii-advance-input

> 标签: javascript, jquery, php, yii2

## 简介

Using this library, You can add widgets which have, on/off button, label, description, icon and unit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
