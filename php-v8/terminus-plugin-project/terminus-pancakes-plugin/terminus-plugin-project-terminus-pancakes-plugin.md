# terminus-plugin-project/terminus-pancakes-plugin

> 标签: PHP

## 简介

Terminus Plugin to open Pantheon Site Databases in your Favorite SQL Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
