# wordpruss/wordpruss

> 标签: library, php, wordpress, wordpress-development

## 简介

A reusable set of clean and beautified PHP classes that wrap WordPress functionalities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
