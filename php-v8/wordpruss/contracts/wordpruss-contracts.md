# wordpruss/contracts

> 标签: php, php-library, wordpress, wordpress-development

## 简介

A couple of interfaces that set common behaviors between the wordpruss classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
