# hotkv/client

> 标签: cache, client, hotkv, key-value, resp, sdk

## 简介

A high-performance PHP client for HotKV, a RESP2/RESP3-compatible in-memory data store with built-in AI and LLM-serving features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
