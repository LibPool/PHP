# laofu110/tools

> 标签: Pinyin

## 简介

业务工具集合：汉子转拼音、GeoHash类、redis客户端（支持geo操作）、page分页（支持常规多页分页与简洁版的上下页分页）、分词操作类（支持返回全部分词结果与部分热门词）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
