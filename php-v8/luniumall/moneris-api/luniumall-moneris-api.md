# luniumall/moneris-api

> 标签: api, eSELECTplus, moneris

## 简介

An easier way to consume the (truly awful) Moneris eSELECTplus API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
