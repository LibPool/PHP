# falconmedia/m2-categorythumbnails

> 标签: PHP

## 简介

Magento 2 module to Create a widget for Homepage to show categories and add subcategories to category page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
