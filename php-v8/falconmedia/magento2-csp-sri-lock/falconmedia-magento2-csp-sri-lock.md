# falconmedia/magento2-csp-sri-lock

> 标签: PHP

## 简介

Prevents corrupted sri-hashes.json in Magento 2 by adding atomic writes and file locking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
