# falconmedia/magento2-belco-hyva

> 标签: PHP

## 简介

Belco.io Magento Module compatible with Hyvä Themes to install widget code and sync customer information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
