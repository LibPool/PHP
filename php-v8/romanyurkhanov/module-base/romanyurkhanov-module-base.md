# romanyurkhanov/module-base

> 标签: PHP

## 简介

RomanYurkhanov Base module for Magento 2. All RomanYurkhanov modules requires this module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
