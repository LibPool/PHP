# nfephp-org/sped-da

> 标签: CCe, Dacte, Danfe, nfe, nfephp, sped

## 简介

sped-da contêm as classes para criação dos documentos auxiliares referidos no projeto Sped.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
