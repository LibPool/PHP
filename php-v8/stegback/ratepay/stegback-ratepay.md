# stegback/ratepay

> 标签: Stegback, ratepay-payment-gateway

## 简介

ratepay package is for communication beetween client side and ratepay api, you can send direct array to xml api request.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
