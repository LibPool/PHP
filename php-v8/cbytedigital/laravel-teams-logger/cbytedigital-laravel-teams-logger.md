# cbytedigital/laravel-teams-logger

> 标签: PHP

## 简介

Laravel package to log exceptions to a Microsoft Teams channel using Microsoft Teams Webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
