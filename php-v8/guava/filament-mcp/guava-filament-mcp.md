# guava/filament-mcp

> 标签: Guava, filament, filament-mcp, laravel, mcp

## 简介

Give your Filament panels MCP capabilities. Expose resources, records and actions to AI agents - configurable and secure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
