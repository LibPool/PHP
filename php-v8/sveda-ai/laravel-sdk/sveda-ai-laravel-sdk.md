# sveda-ai/laravel-sdk

> 标签: Agent, ai, copilot, laravel, mcp, sdk, sveda

## 简介

Embed a Sveda AI agent in Laravel (sessions + host MCP). https://sveda.dev/docs/hosts/laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
