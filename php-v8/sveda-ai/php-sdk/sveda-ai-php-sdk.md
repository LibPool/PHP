# sveda-ai/php-sdk

> 标签: Agent, ai, client, copilot, sdk, sveda

## 简介

Embed a Sveda AI agent from PHP. Docs: https://sveda.dev/docs/hosts/php

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
