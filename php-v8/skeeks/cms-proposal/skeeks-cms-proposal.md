# skeeks/cms-proposal

> 标签: cms, crm, pdf, proposal, quote, skeeks, yii

## 简介

Commercial proposals for SkeekS CMS CRM: versions, items with sections, templates, PDF and a personal link for every sending

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
