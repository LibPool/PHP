# skeeks/cms-shop-paysystem-yookassa

> 标签: component, framework, skeeks, yii

## 简介

Способ оплаты ЮKassa для SkeekS CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
