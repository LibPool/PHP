# skeeks/cms-admin

> 标签: admin, cms, framework, skeeks, yii, yii2

## 简介

Admin controll panel for SkeekS CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
