# skeeks/yii2-google-api

> 标签: api, client, component, google, skeeks, yii, yii2

## 简介

Component for work with google api based on google/apiclient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
