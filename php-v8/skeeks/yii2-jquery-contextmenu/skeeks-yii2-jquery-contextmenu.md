# skeeks/yii2-jquery-contextmenu

> 标签: cms, framework, skeeks, yii, yii2

## 简介

jQuery contextMenu plugin & polyfill for yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
