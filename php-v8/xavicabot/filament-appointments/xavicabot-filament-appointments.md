# xavicabot/filament-appointments

> 标签: PHP

## 简介

FilamentPHP 4/5 Appointment Picker (Tucalendi-style) + Admin resources + Google Calendar availability sync

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
