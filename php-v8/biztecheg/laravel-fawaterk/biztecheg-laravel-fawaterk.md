# biztecheg/laravel-fawaterk

> 标签: Egypt, fawaterak, fawaterk, laravel, payment, payment-gateway, webhooks

## 简介

Security-first Laravel integration for the Fawaterk payment gateway: API v3, verified webhooks and a payments ledger. Unofficial.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
