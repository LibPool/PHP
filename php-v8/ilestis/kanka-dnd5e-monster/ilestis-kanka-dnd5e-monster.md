# ilestis/kanka-dnd5e-monster

> 标签: 5e, dnd, kanka, monsters

## 简介

An attribute template for D&D 5th edition monsters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
