# yidas/yii2-composer-bower-skip

> 标签: bower, bower asset, framework, yii2

## 简介

A Composer package that allows you to install or update Yii2 without Bower-Asset

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
