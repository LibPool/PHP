# yidas/yii2-fontawesome

> 标签: asset, asset bundle, font awesome, yii

## 简介

Font Awesome Asset Bundle for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
