# yidas/yii2-bootstrap

> 标签: asset, asset bundle, bootstrap, yii, yii2

## 简介

Bootstrap Asset Bundle extension for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
