# yidas/yii2-auto-asset-bundle

> 标签: asset, asset-bundle, framework, view, yii2

## 简介

Base Asset Bundle for Yii2 to auto-allocate JS & CSS files for each View

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
