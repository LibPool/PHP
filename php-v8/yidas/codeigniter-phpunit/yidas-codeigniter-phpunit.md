# yidas/codeigniter-phpunit

> 标签: codeigniter, phpunit, test-driven-development, unit-test

## 简介

CodeIgniter 3 PHPUnit Test extension library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
