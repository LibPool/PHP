# yidas/taifex-report

> 标签: TW Stock, crawler, php, stock, taifex

## 简介

Taiwan Futures Exchange difference report (臺灣期貨交易所差異報表)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
