# yidas/yii2-language

> 标签: framework, i18n, language, language-map, yii2

## 简介

Yii 2 Framework Language extension with Status Keep and Map

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
