# envless/sdk

> 标签: AES-GCM, Config management, api, api client, encrypted secrets, env, env vars, environment variables, envless, pbkdf2, psr-18, sdk, secret management, secrets, secrets versioning

## 简介

The official PHP SDK for the Envless API. Manage workspaces, products, projects, environments, variables, versions, members, roles, keys and webhooks from PHP, with every value encrypted on your machine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
