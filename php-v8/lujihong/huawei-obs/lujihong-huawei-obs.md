# lujihong/huawei-obs

> 标签: OBS, filesystems, huawei, hyperf, php, storage, swoole

## 简介

基于华为云官方最新 OBS PHP SDK v3.21.6 适用于hyperf等框架

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
