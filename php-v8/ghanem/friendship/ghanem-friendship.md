# ghanem/friendship

> 标签: friend system, friends, friendship, laravel

## 简介

A polymorphic friendship system for Laravel — friend requests, blocking, mutual friends, and events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
