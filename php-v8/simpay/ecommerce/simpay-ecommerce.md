# simpay/ecommerce

> 标签: ecommerce, gateway, payments, php-sdk, simpay

## 简介

PHP SDK for integrating SimPay payments into e-commerce platforms

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
