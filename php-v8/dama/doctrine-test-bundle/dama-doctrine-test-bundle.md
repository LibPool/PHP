# dama/doctrine-test-bundle

> 标签: doctrine, isolation, performance, symfony, testing, tests

## 简介

Symfony bundle to isolate doctrine database tests and improve test performance

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
