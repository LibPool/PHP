# drutiny/drutiny

> 标签: Audit, Drush, drupal, report, ssh

## 简介

This is a generic Drupal 7 and Drupal 8 site auditing and optional remediation tool.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
