# vigenphp/installer

> 标签: framework, installer, php, scaffolding, vigen

## 简介

The Vigen installer. `vigen create my-app` - like `laravel new`, but for Vigen.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
