# vigenphp/vigen

> 标签: ai, cli, code-generation, framework, llm, php, vibe-coding

## 简介

Vigen is a modern PHP framework built around AI-first development and vibe coding. Describe what you want. Vigen builds it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
