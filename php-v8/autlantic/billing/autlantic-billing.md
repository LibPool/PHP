# autlantic/billing

> 标签: USDC, autlantic, base, billing, subscriptions, webhooks

## 简介

Official Autlantic Billing server SDK for PHP (hosted API + webhook verify)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
