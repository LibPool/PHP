# doublesecretagency/craft-cpjs

> 标签: Craft, cms, cp-js, craft-plugin, craftcms, javascript

## 简介

Add custom JavaScript to your Control Panel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
