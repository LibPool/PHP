# tech-ed/simpl-otp

> 标签: PHP

## 简介

A simple and lightweight Laravel package for generating and verifying one-time passwords (OTPs), enhancing authentication security in your Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
