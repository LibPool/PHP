# michaelgatuma/laravel-kopokopo

> 标签: kopokopo, laravel, michaelgatuma, mpesa

## 简介

A simple package for developers to consume Kopokopo Mpesa API in Laravel 8

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
