# namingo/registrars

> 标签: api, domain, dynadot, godaddy, name.com, namecheap, namecom, namesilo, opensrs, opusdns, registrar

## 简介

Cardo DRS - a unified PHP interface for working with multiple domain registrar APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
