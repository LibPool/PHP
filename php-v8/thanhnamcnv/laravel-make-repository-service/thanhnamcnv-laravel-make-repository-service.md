# thanhnamcnv/laravel-make-repository-service

> 标签: PHP

## 简介

A simple package to create a make:repository, make:service command for Laravel 8+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
