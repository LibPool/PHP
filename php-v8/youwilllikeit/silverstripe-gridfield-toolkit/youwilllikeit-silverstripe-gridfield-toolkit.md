# youwilllikeit/silverstripe-gridfield-toolkit

> 标签: cms, gridfield, inline-edit, silverstripe, ux

## 简介

Advanced UX/UI components for the Silverstripe CMS GridField: inline editing, undo, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
