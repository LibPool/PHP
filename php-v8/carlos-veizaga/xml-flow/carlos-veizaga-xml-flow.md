# carlos-veizaga/xml-flow

> 标签: fluent, invoicing, xml, xml-builder, xmldsig, xsd

## 简介

A fluent, agnostic XML builder with native support for xsi:nil and complex namespaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
