# n5s/wp-hook-kit

> 标签: actions, filters, hooks, wordpress

## 简介

A lightweight WordPress hook helper library. Register hooks before WordPress loads, run callbacks only once, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
