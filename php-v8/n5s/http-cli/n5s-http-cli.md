# n5s/http-cli

> 标签: Guzzle, cli, command-line, http, http-client, symfony, testing

## 简介

Serverless HTTP client - make requests to PHP scripts on the command line

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
