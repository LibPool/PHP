# n5s/dtcg-tokens

> 标签: css, design-tokens, dtcg, symfony, twig

## 简介

PHP-first runtime library for DTCG design tokens, with Twig and Symfony bridges

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
