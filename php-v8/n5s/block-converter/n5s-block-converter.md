# n5s/block-converter

> 标签: block-editor, blocks, converter, gutenberg, html, legacy-content, migration, shortcodes, wordpress

## 简介

A library to convert legacy or arbitrary HTML content into WordPress blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
