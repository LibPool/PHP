# tobse/cakephp-image-cropper

> 标签: cakephp, cakephp-plugin, crop, cropper, formhelper, image, upload, vite

## 简介

Standalone CakePHP 5 plugin that adds a client-side image cropper (Cropper.js + Vite) with a FormHelper integration and server-side GD cropping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
