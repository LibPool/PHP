# darylldoyle/safe-svg

> 标签: PHP

## 简介

Enable SVG uploads and sanitize them to stop XML/SVG vulnerabilities in your WordPress website

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
