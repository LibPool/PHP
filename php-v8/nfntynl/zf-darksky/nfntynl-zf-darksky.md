# nfntynl/zf-darksky

> 标签: darksky, forecast, weather, zend framework 2, zf2

## 简介

Simple DarkSky Weather Forecast API Zend Framework module using Guzzlehttp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
