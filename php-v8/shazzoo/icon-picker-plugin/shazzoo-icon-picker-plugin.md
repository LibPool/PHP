# shazzoo/icon-picker-plugin

> 标签: PHP

## 简介

Icon picker for Content Studio Core: a searchable icon grid field, a Blade Icons set and an admin icon library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
