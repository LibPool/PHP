# shazzoo/assistant-plugin

> 标签: PHP

## 简介

AI assistant for Content Studio: visitors ask questions and get answers from the site's own content, via laravel/ai (Claude, ChatGPT, Gemini and more).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
