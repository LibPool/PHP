# cynchro/modux-ia

> 标签: ai, embeddings, llama, llm, php, rag

## 简介

SDK para integrar IA (LLM + RAG) directamente en aplicaciones PHP — sin Python, sin Node.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
