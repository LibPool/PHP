# ruiadr/utils

> 标签: PHP

## 简介

Fonctionnalités statiques de base pour PHP incluant différents utilitaires (tableaux, les dates, le HTML, HTTP etc.).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
