# mauroziux/laravel-url-shortener

> 标签: bitly, laravel, redirect, shortener, tracking, url

## 简介

Laravel Package for shortening urls with Laravel 10 and 11 support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
