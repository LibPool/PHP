# honk/honk

> 标签: alerts, honk, honk-honk, laravel, monitoring, notification-channel, notifications, push, push-notifications, sdk

## 简介

Official PHP client for Honk! Honk! (honk-honk.app): send events from apps, scripts and automations to your phone. Laravel facade, queued sends and notification channel included.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
