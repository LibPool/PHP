# phillipsharring/handlr-app

> 标签: PHP

## 简介

Full-stack Handlr app skeleton — HTMX/Handlebars/Tailwind frontend + PHP Pipe+Handler backend, scaffolded in one command

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
