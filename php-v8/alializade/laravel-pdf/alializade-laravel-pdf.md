# alializade/laravel-pdf

> 标签: laravel, mpdf, pdf, php8.1

## 简介

Generate PDFs in Laravel with this mPDF wrapper.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
