# diglin/magento2-language-fr-ch

> 标签: fr, fr_CH, french, i18n, language pack, magento, magento 2, magento2, module, plugin

## 简介

Magento2 French Language Pack (fr_CH) / based on https://github.com/Imaginaerum/magento2-language-fr-fr

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
