# initphp/config

> 标签: Settings, config, config-manager, configuration, dot-notation, dotted-path, initphp, parameter-bag, php, php-library

## 简介

Advanced configuration manager for PHP with dotted-path access, file/directory/class loaders and a static facade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
