# initphp/parameterbag

> 标签: config, container, dot-notation, initphp, parameter-bag

## 简介

Single and multi-dimensional parameter bag with dot-path access for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
