# initphp/views

> 标签: Rendering, blade, initphp, php, template, template-engine, twig, view, views

## 简介

A small, adapter-based view rendering layer for PHP with PurePHP, Blade and Twig back-ends.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
