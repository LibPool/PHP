# initphp/database

> 标签: active-record, database, datatables, dbal, initphp, mysql, orm, pdo, pgsql, query-builder, soft-delete, sqlite

## 简介

InitPHP Database — QueryBuilder, DBAL and ORM facade for the InitORM stack, plus a server-side DataTables.js helper.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
