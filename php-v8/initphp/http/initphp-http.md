# initphp/http

> 标签: curl, emitter, http, http-client, http-factory, http-message, psr-17, psr-18, psr-7, psr-7-client, psr-7-factory, psr-7-message, request, response, stream, uploaded-file, uri

## 简介

Standards-compliant PSR-7 / PSR-17 / PSR-18 HTTP message, factory, client and response emitter implementation for PHP 7.4+.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
