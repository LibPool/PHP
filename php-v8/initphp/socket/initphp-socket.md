# initphp/socket

> 标签: Socket, client, initphp, networking, server, ssl, stream, tcp, tls, udp

## 简介

Lightweight TCP, UDP, TLS and SSL socket server/client toolkit for PHP 8.1+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
