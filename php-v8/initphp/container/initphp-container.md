# initphp/container

> 标签: Autowiring, PSR-11, container, dependency-injection, di, ioc

## 简介

Minimal PSR-11 dependency injection container with reflection-based autowiring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
