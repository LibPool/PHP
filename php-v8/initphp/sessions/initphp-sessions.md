# initphp/sessions

> 标签: cookie, initphp, memcache, memcached, mongodb, mysql, pdo, postgresql, redis, save handler, session, session handler, sessions, sqlite

## 简介

Framework-agnostic PHP session manager with pluggable save handlers (File, Cookie, PDO, Redis, Memcache/Memcached, MongoDB).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
