# triaubaral/phaster

> 标签: build, meta-task, phaster, phing, task, tool

## 简介

Collection of meta tasks based on phing in order to make your build process easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
