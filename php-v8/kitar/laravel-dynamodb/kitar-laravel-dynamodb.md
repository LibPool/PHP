# kitar/laravel-dynamodb

> 标签: auth, database, dynamodb, laravel, model

## 简介

A DynamoDB based Eloquent model and Query builder for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
