# kyslik/laravel-filterable

> 标签: filter, kyslik, laravel, laravel-filterable, query-strings

## 简介

Using URL query strings to filter Eloquent queries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
