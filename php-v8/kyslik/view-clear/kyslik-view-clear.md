# kyslik/view-clear

> 标签: artisan, clear, command, laravel, laravel5, view

## 简介

Simple artisan command to clear view folder in Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
