# intaro/hstore-bundle

> 标签: Symfony2, hstore, postgresql

## 简介

The HStoreBundle contains DBAL type hstore and registers Doctrine type hstore

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
