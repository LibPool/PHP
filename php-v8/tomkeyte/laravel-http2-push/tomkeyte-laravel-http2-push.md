# tomkeyte/laravel-http2-push

> 标签: http2, laravel, laravel-http2-push, push, seo

## 简介

A cache aware provider for HTTP2 Push within a Laravel application

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
