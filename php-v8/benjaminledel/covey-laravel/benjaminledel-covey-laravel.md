# benjaminledel/covey-laravel

> 标签: Agent, Tinker, ai-agent, covey, laravel, logs, support

## 简介

Give a covey agent (covey.work) a door into your Laravel application: schema, read-only queries and the application log behind a read token, tinker behind a write token, so writes carry their own guard rails.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
