# curder/laravel-query-cache

> 标签: cache, duplicate, eloquent, laravel, model, query

## 简介

Cache all {select} queries or only the duplicate ones for a specific Eloquent model

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
