# crankybearmedia/crankierkit

> 标签: Kirby CMS, kirby, kirby3

## 简介

An opinionated scaffold of a Kirby CMS PlainKit project using Composer for PHP dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
