# posthastemail/laravel-mailer

> 标签: email, laravel, mail, mailer, posthaste, transactional-email

## 简介

Laravel mail driver for the Posthaste transactional email API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
