# phpty/tty

> 标签: ffi, raw-mode, stty, termios, tty

## 简介

Reads and changes the state of the Tty this process is attached to: raw mode, size, and whether a stream is a Tty at all.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
