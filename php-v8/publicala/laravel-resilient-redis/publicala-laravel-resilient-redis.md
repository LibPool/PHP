# publicala/laravel-resilient-redis

> 标签: laravel, phpredis, reconnect, redis, resilience, retry, tls, valkey

## 简介

Retry transient phpredis connect failures in Laravel, and recover commands that lose their connection on every Laravel version.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
