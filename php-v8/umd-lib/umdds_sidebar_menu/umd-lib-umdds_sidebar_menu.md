# umd-lib/umdds_sidebar_menu

> 标签: PHP

## 简介

This module provides a customized sidebar menu for the UMD Libraries Design System theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
