# umd-lib/umdlib_fcrepo_solr_helper

> 标签: PHP

## 简介

Solr helper module for UMD Digital. Contains Single Directory Component for Digital details display.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
