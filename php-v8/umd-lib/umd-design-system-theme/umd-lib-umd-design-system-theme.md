# umd-lib/umd-design-system-theme

> 标签: PHP

## 简介

Drupal base theme provided by UMD Libraries utilizing Single Directory Components for the UMD Design System.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
