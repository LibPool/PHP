# emericklaw/sqlanywhere-pdo

> 标签: PHP

## 简介

PDO-compatible userland wrapper around the ext-sqlanywhere (sasql_*) procedural extension for SAP SQL Anywhere

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
