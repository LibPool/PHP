# monetra/monetra_magento2

> 标签: magento, magento2, method, module, monetra, payment, transafe

## 简介

A Magento 2 module for processing payments through a Monetra server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
