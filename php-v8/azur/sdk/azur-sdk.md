# azur/sdk

> 标签: api, azur, comprobantes electronicos, ecuador, factura, facturación electrónica, sdk, sri

## 简介

SDK oficial de PHP para la API de AZUR: facturación electrónica del SRI de Ecuador (comprobantes, catálogos, inventario, cartera, webhooks y emisión directa).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
