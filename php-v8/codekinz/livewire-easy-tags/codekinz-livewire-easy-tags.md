# codekinz/livewire-easy-tags

> 标签: PHP

## 简介

A Laravel tag system for artisans which is built in Livewire, Laravel Spatie tags, Tagify and Alpine Js.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
