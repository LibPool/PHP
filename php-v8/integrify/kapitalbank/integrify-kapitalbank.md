# integrify/kapitalbank

> 标签: api, azerbaijan, integration, integrify, kapitalbank, payment, payment-gateway

## 简介

Kapital Bank e-commerce şlüzü inteqrasiyası — sifariş, kart yaddaşı, clearing, geri qaytarma və saxlanılmış kartla ödəniş.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
