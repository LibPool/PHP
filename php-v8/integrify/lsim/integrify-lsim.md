# integrify/lsim

> 标签: api, azerbaijan, integration, integrify, lsim, sms

## 简介

LSIM SMS inteqrasiyası — tək və toplu SMS göndərilməsi, hesabat və balans sorğuları.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
