# integrify/epoint

## 简介

EPoint ödəniş şlüzü inteqrasiyası — ödəniş, kart yaddaşı, payout, refund və bölünmüş ödənişlər.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
