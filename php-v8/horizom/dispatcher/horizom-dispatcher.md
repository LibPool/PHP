# horizom/dispatcher

> 标签: dispatcher, horizom, middleware, php, pipeline, psr-15

## 简介

A PSR-15 middleware dispatcher and pipeline for PHP 8+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
