# axllent/silverstripe-links-to-blank

> 标签: links, silverstripe

## 简介

Extension to add add target="_blank" to all outgoing links & downloads

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
