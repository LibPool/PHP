# axllent/silverstripe-gfmarkdown

> 标签: markdown, silverstripe

## 简介

GitHub Flavored Markdown editing & rendering using Parsedown

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
