# astral-php/astral-core

> 标签: astral, core, di, framework, microframework, mvc, php, psr

## 简介

Astral Core — moteur PHP 8.1+ (HTTP, DI, router, auth, DAO, vues, CLI) pour les applications et composants Astral

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
