# astral-php/astral-starter

> 标签: Skeleton, astral, mvc, php, starter

## 简介

Astral Starter — application from scratch (auth, admin, layout simple) basée sur astral-core

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
