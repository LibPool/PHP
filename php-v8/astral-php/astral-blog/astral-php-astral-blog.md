# astral-php/astral-blog

> 标签: astral, blog, cms, mvc, php

## 简介

Astral Blog 1.0 — application blog complète (articles, tags, commentaires, auth, admin) basée sur astral-core + starter

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
