# astral-php/astral-shipping

> 标签: astral, colissimo, frais-de-port, mondial-relay, php, sendcloud, shipping

## 简介

Frais de port multi-options pour Astral : forfait, barèmes poids/pays, Colissimo, Mondial Relay, retrait boutique, API agrégateur (Sendcloud)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
