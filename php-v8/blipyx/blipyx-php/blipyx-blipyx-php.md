# blipyx/blipyx-php

> 标签: blipyx, events, laravel, pub-sub, realtime, shared-hosting, websocket

## 简介

PHP client for Blipyx — publish realtime events over HTTP and authorize private channels. Works on any hosting.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
