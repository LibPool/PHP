# sanchescom/php-wifi

> 标签: access-point, cli, headless, hostapd, hotspot, iot, netsh, networkmanager, networksetup, nmcli, provisioning, raspberry-pi, watchdog, wifi, wireless, wpa-cli, wpa-supplicant

## 简介

Cross-platform PHP library for Wi-Fi: scan, join, known networks, and on Linux a hotspot and a watchdog that keeps a headless device (Raspberry Pi) online.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
