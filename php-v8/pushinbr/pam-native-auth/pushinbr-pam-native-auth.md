# pushinbr/pam-native-auth

> 标签: PHP

## 简介

Secure sessions, encrypted credential vaults and OAuth 2.1/PKCE primitives for PAM Native.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
