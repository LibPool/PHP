# pushinbr/pam-native-calls

> 标签: android, callkit, calls, callstyle, ios, pam-native, push, pushkit, voip

## 简介

System call surfaces for PAM Native: CallStyle incoming and ongoing notifications, lock-screen call UI, call actions and push-driven ringing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
