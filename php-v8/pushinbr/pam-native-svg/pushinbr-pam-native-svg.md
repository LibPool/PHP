# pushinbr/pam-native-svg

> 标签: android, animation, icons, ios, native, pam, php, progress, svg, vector

## 简介

Native SVG for PAM Native: retained vector nodes, gradients, dashes and render-thread animations on Android Canvas and Core Animation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
