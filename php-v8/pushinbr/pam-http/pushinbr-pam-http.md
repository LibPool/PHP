# pushinbr/pam-http

> 标签: api, dependency-injection, http, middleware, openapi, pam, php, router, validation

## 简介

Elegant HTTP routing and middleware for the Pam runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
