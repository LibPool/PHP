# pushinbr/pam-native-webrtc

> 标签: WebRTC, android, ios, pam-native, video-call, voice-call

## 简介

Native WebRTC peer connections, GPU video rendering and call audio routing for PAM Native.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
