# pushinbr/pam-native-audio

> 标签: android, audio, avplayer, exoplayer, ios, pam-native, player, voice-notes

## 简介

Headless native audio player for PAM Native: queues, playback rate, audio focus, caching and proximity earpiece routing for voice notes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
