# pushinbr/pam-http-psr

> 标签: pam, php, psr-15, psr-17, psr-7

## 简介

PSR-7, PSR-15 and PSR-17 implementations for Pam.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
