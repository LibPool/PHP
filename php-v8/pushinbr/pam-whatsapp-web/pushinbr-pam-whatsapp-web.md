# pushinbr/pam-whatsapp-web

> 标签: pam, php, whatsapp, whatsapp-web

## 简介

Persistent WhatsApp Web client for PHP on PAM, without Node.js or Puppeteer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
