# pushinbr/pam-desktop

> 标签: desktop, pam, php, rust, servo

## 简介

Elegant PHP-first desktop applications powered by Pam, Rust, and Servo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
