# sowrensen/svg-avatar-generator

> 标签: avatar, avatar-generator, laravel, sowrensen, svg-avatar-generator, svg-generator

## 简介

Offline SVG avatar generator for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
