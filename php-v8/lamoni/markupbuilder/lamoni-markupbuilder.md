# lamoni/markupbuilder

> 标签: builder, dom, html, markup, php

## 简介

A PHP class used for building a single-level DOM object using method chaining and dynamic methods

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
