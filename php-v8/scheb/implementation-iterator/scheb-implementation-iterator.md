# scheb/implementation-iterator

> 标签: implementation, iterator, reflection

## 简介

Iterates a PSR-4 compliant directory for implementations of a class/interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
