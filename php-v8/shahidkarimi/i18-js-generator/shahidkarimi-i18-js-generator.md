# shahidkarimi/i18-js-generator

> 标签: javascript, laravel, translation, vue-i18n, vuejs

## 简介

Generate JavaScript files from laravel language files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
