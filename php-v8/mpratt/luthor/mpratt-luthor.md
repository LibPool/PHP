# mpratt/luthor

> 标签: Mark down, extendable markdown, lexer, markdown, md, parser

## 简介

An extendable Markdown Lexer/Parser for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
