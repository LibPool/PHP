# niji/xml-parser-bundle

> 标签: XmlParserBundle, symfony, xml, xmlparser

## 简介

Symfony bundle that allows easy parsing of XML documents using a YAML mapping file and XPath.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
