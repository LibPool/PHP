# gpio/pwm

> 标签: GPIO, pwm, scrapyard-io

## 简介

GeneralPurposeIO PWM: the gpio.pwm connection manager, driver, factory and channel transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
