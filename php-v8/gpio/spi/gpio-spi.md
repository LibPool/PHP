# gpio/spi

> 标签: GPIO, scrapyard-io, spi

## 简介

GeneralPurposeIO SPI: the gpio.spi connection manager, driver, factory and chip-select transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
