# gesdinet/bidla

> 标签: changelog, contributors, generator, git, markdown, vcs

## 简介

Bidla is a PHP Tool for help developers to generate Changelog and Contributors files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
