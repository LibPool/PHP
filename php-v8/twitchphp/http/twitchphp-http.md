# twitchphp/http

> 标签: async, helix, http, oauth2, reactphp, twitch, twitchphp

## 简介

Non-blocking HTTP client and OAuth2 helper for the Twitch Helix API, on ReactPHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
