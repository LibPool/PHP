# deshithemes/css-cleaner

> 标签: bootstrap, css, frontend, laravel, minify, optimization, optimizer, performance, purgecss, tailwind

## 简介

🚀 Laravel package to purge and minify CSS files with zero config. Removes unused CSS, minifies styles, and boosts performance. Built with ❤️ by DeshiThemes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
