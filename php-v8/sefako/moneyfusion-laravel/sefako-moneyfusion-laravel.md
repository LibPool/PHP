# sefako/moneyfusion-laravel

> 标签: billing, gateway, invoice, laravel, moneyfusion, payment

## 简介

Un package Laravel pour intégrer le système de paiement MoneyFusion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
