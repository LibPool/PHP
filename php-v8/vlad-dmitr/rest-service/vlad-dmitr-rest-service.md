# vlad-dmitr/rest-service

> 标签: api, php, rest, restful

## 简介

PHPRestService is a simple and fast PHP class for server side RESTful APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
