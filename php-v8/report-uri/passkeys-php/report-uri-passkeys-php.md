# report-uri/passkeys-php

> 标签: Authentication, FIDO2, passkey, passkeys, webauthn

## 简介

A security-focused PHP WebAuthn (FIDO2 / Passkeys) server library, forked from lbuchs/WebAuthn

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
