# report-uri/magento2-csp-reporting

> 标签: PHP

## 简介

Beta. Fills in the four CSP Report URI fields Magento ships empty, so violation reports reach a collector instead of nowhere.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
