# infinety-es/crud

> 标签: create, crud, delete, infinety, read, update

## 简介

Quickly build an admin interface for your Eloquent models, using Laravel 5. Build a CMS in a matter of minutes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
