# suifeng/applet-paylogin

> 标签: PHP

## 简介

微信小程序、字节小程序、支付宝小程序（支付、手机号解密、获取Token、支付异步通知、退款、订单查询）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
