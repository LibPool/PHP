# cyberjq/yii2-sphinx

> 标签: active-record, fulltext, search, sphinx, yii2

## 简介

Sphinx full text search engine extension for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
