# mariodevv/laravel-redsys-subscriptions

> 标签: bizum, cashier, laravel, payments, recurring, redsys, spain, subscriptions, tpv

## 简介

Suscripciones y cobros recurrentes con Redsys para Laravel. Tokenizacion COF/MIT y firma HMAC SHA-512.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
