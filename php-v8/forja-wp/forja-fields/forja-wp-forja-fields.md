# forja-wp/forja-fields

> 标签: custom-fields, metabox, theme, wordpress

## 简介

Campos personalizados para WordPress definidos por código, con la interfaz de administración de ACF/SCF.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
