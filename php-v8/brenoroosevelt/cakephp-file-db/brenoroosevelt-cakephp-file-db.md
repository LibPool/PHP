# brenoroosevelt/cakephp-file-db

> 标签: PHP

## 简介

Armazena arquivos no Banco - plugin para CakePHP 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
