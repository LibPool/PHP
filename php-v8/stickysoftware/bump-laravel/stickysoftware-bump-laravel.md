# stickysoftware/bump-laravel

> 标签: Metrics, analytics, bump, counters, events, laravel, milestones

## 简介

Laravel client for Bump: send events from your app, and Bump keeps exact running totals.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
