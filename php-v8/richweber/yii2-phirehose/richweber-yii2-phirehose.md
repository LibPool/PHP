# richweber/yii2-phirehose

> 标签: api, phirehose, php, streaming, twitter

## 简介

A PHP interface to the Twitter Streaming API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
