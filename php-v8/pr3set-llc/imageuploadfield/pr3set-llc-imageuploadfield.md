# pr3set-llc/imageuploadfield

> 标签: field, image, silverstripe, upload

## 简介

SilverStripe UploadField pre-configured for Image uploads. Allows max file size to be set site wide.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
