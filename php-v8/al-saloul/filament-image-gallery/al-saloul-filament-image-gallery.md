# al-saloul/filament-image-gallery

> 标签: Viewer, al-saloul, filament, flip, flip-image, fullscreen-view, gallery-controls, image-gallery, image-navigation, image-preview, image-rotate, image-slider, image-viewer, laravel, lightbox, mirror-image, next-prev, photo-gallery, rotate, slideshow, zoom

## 简介

A Filament plugin for displaying image galleries with zoom, rotate, and flip capabilities

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
