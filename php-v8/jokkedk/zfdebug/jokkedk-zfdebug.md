# jokkedk/zfdebug

> 标签: PHP

## 简介

ZFDebug is a plugin for the Zend Framework for PHP5, providing useful debug information displayed in a small bar at the bottom of every page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
