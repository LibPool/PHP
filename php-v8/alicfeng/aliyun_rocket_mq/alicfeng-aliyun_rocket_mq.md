# alicfeng/aliyun_rocket_mq

> 标签: PHP

## 简介

基于阿里云官方SDK增强组件，更加优雅的应用姿势、更加灵活的动态配置，让应用层服务组件更加标准规范

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
