# deskhq/laravel-worktree

> 标签: DeskHQ, laravel, laravel-worktree

## 简介

Per-worktree isolation so multiple agents can work on a Laravel project concurrently

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
