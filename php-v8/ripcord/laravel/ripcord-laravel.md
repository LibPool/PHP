# ripcord/laravel

> 标签: change-intelligence, error-tracking, laravel, observability, ripcord

## 简介

Ship Laravel errors and deploy events to Ripcord — no application code, one config block.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
