# rikkeisoft/cakephp2

> 标签: PHP

## 简介

Template for CakePHP v2 project of RikkeiSoft Co. Ltd.,

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/rikkeisoft/cakephp2
- 源码仓库：https://github.com/rikkeisoft/cakephp2.git
- Packagist 页面：https://packagist.org/packages/rikkeisoft%2Fcakephp2

## 获取地址

- Composer 安装：`composer require rikkeisoft/cakephp2`
- Packagist 仓库：https://repo.packagist.org/p2/rikkeisoft/cakephp2.json
- PHP 要求：>=5.3.0
