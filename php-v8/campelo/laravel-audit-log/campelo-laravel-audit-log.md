# campelo/laravel-audit-log

> 标签: Audit, activity, history, laravel, log, tracking

## 简介

Automatic audit logging for Laravel applications - track who, when, where, what changed

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
