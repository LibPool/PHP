# slash197/reges-laravel

> 标签: Romania, inspectia-muncii, laravel, reges, reges-online, revisal

## 简介

Laravel bridge for slash197/reges, the PHP client for the REGES Online API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
