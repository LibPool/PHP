# slash197/reges

> 标签: Romania, hr, inspectia-muncii, payroll, reges, reges-online, revisal

## 简介

PHP client for the REGES Online API (Romanian general register of employees, Inspectia Muncii)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
