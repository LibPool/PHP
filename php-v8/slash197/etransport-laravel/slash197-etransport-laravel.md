# slash197/etransport-laravel

> 标签: Romania, anaf, e-transport, etransport, laravel, ro-e-transport, uit

## 简介

Laravel bridge for slash197/etransport, the PHP client for ANAF's RO e-Transport system

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
