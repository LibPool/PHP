# arianrashidi/pocketapi

> 标签: api, arianrashidi, pocket, pocket-api, pocketapi, read it later

## 简介

A simple PHP wrapper for the Pocket API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
