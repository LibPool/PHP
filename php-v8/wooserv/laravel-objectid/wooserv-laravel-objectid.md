# wooserv/laravel-objectid

> 标签: ObjectId, Unique ID, database, eloquent, id generator, laravel, laravel macro, laravel objectid, laravel package, migration, model id, mongodb, ulid, uuid, wooServ

## 简介

Elegant, fast ObjectId generator for Laravel models with automatic ID assignment, schema macro, and helper function.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
