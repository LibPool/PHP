# kunicmarko/sonata-auto-configure-bundle

> 标签: autoconfigure, sonata, sonata-admin, symfony

## 简介

Symfony Bundle that auto configures Sonata Admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
