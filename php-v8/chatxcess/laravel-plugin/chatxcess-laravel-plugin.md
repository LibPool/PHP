# chatxcess/laravel-plugin

> 标签: chatbot, chatxcess, connect, laravel

## 简介

Chatxcess Connect plugin for Laravel tenants — securely expose role-scoped data to Chatxcess over a signed internal endpoint. Data never leaves your server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
