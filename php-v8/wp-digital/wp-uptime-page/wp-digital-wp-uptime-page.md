# wp-digital/wp-uptime-page

> 标签: page, pingdom, plugins, uptime, wordpress

## 简介

Adds Uptime Page like from Pingdom into site's Dashboard.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
