# asteriskpound/openapi-psr7-validator

> 标签: http, openapi, psr7, validation

## 简介

Validate PSR-7 messages against OpenAPI (3.0.2) specifications expressed in YAML or JSON

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
