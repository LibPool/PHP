# stidges/laravel-country-flags

> 标签: countries, country, country-flags, emoji, flag, laravel, unicode

## 简介

A Laravel 5.5 wrapper for the stidges/country-flags package

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
