# kibi/druckerwolke

> 标签: PHP

## 简介

Druckerwolke is a PHP class for cloud printing PDF Documents using Druckerwolke.de

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
