# metrixs/mx-cookieless-analytics

> 标签: analytics, cookieless, craftcms, gdpr, privacy

## 简介

Cookieless, privacy-friendly web analytics. Opt-in tracking (off until you connect), GDPR-friendly, EU-hosted. Automatic site verification, no DNS records needed. Includes an AI traffic panel, GEO/SEO/security audits (Team, Pro, Agency), and a read-only MCP server for AI assistants.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
