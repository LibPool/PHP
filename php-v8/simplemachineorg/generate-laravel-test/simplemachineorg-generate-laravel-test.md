# simplemachineorg/generate-laravel-test

> 标签: generate-laravel-test, iambateman, laravel

## 简介

Use AI to dynamically create a test for a PHP Class in your application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
