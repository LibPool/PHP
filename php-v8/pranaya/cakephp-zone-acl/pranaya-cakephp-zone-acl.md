# pranaya/cakephp-zone-acl

> 标签: acl, cakephp, plugin, zoneacl

## 简介

A CakePHP Acl plugin based on application zones for flexibility and simplicity

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
