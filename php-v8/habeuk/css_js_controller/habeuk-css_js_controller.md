# habeuk/css_js_controller

> 标签: PHP

## 简介

Permet de selectionner les fichiers css et js qui doivent etre charger en fonction des pages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
