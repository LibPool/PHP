# monciego/tachi-kit

> 标签: inertia, laravel, permissions, react, shadcn, starter-kit

## 简介

Cut through boilerplate. An opinionated Laravel, React and Inertia starter kit with authentication, role-based permissions and user management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
