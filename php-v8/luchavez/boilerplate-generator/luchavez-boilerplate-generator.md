# luchavez/boilerplate-generator

> 标签: BoilerplateGenerator, laravel

## 简介

A boilerplate generator for building packages and implementing DDD on Laravel 8|9|10.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
