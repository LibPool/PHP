# luchavez/aws-ses-bounce

> 标签: AwsSesBounce, laravel

## 简介

Blacklisting bounced email addresses on AWS Simple Email Service (SES) for Laravel 8|9|10

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
