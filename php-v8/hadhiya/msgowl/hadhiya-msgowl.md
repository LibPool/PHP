# hadhiya/msgowl

> 标签: hadhiya, laravel, msgowl

## 简介

The official MsgOwl SMS and OTP wrapper for the Hadhiya ecosystem.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
