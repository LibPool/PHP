# uninett/feide-secret-generator

> 标签: PHP

## 简介

A simple script demonstrating how to generate secrets suitable to use for two-factor authentication in Feide.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
