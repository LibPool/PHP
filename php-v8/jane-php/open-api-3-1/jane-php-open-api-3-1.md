# jane-php/open-api-3-1

> 标签: jane, openapi

## 简介

Generate a PHP Client API (PSR7/PSR18 compatible) given a OpenApi 3.1.x specification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
