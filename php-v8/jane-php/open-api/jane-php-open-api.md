# jane-php/open-api

> 标签: jane, openapi, swagger

## 简介

Generate a PHP Client API (PSR7/PSR18 compatible) given a OpenApi 3.x specification

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
