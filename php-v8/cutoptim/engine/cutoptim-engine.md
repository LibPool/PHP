# cutoptim/engine

> 标签: api client, cut list, cutoptim, cutting optimization, nesting, panel saw

## 简介

Official client for the CutOptim Engine API — cutting optimization (2D panels, 1D linear, timber, true-shape nesting) over HTTPS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/cutoptim/engine-php.git
