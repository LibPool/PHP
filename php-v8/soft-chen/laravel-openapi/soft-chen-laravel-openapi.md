# soft-chen/laravel-openapi

> 标签: api-docs, laravel, laravel-openapi, openapi, soft-chen

## 简介

根据 Laravel 路由和控制器 结合 DocBlocks 生成 OpenAPI 文档。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
