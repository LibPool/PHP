# nava/myinvois

> 标签: E-Invoice, Malaysia, laravel, myinvois, tax

## 简介

PHP client library for Malaysia's MyInvois API for tax document submissions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
