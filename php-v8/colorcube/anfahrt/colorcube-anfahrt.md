# colorcube/anfahrt

> 标签: anfahrt, directions, extension, map, typo3

## 简介

A TYPO3 extension that provides a simple Google Map plugin with marker and popup window

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
