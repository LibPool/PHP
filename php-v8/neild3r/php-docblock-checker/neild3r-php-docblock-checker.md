# neild3r/php-docblock-checker

> 标签: checker, code quality, comment, docblock, php, phpci, testing

## 简介

A simple tool for checking that your PHP classes and methods use docblocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
