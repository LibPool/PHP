# connect24/connect24

> 标签: South-Africa, connect24, email, messaging-api, popia, sms, sms-api, whatsapp

## 简介

Official PHP client for the Connect24 communications API — email, SMS and WhatsApp.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
