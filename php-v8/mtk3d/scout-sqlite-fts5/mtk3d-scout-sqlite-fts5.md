# mtk3d/scout-sqlite-fts5

> 标签: bm25, fts5, full-text-search, fuzzy-search, laravel, scout, search, sqlite

## 简介

A Laravel Scout driver that indexes your models in SQLite FTS5 virtual tables, with BM25 ranking and a typo-tolerant multi-pass search cascade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
