# syncgw/roundcube_plugin

> 标签: CalDAV, CardDAV, activesync, addressbook, calendar, cell phone, handy, notes, roundcube, smart phone, sync, synchronization, tasklist, todo

## 简介

Select address books, calendars, task lists, notes and mail in RoundCube for synchronization with sync*gw.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
