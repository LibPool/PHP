# transactpro/phpci-stash-build

> 标签: PHP

## 简介

PHPCI Plugin for Atlassian Bitbucket Server (Stash) build status integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
