# mrkoopie/wp_wrapper

> 标签: PHP

## 简介

Wraps WordPress functions into mockable objects. Used for WP_ajaxfilter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
