# mrkoopie/laravel-ai-harness

> 标签: agents, ai, claude, codex, harness, laravel

## 简介

A small Composer tool that gives Codex and Claude a consistent Laravel runtime through Herd, Valet, Yerd, Sail, or native PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
