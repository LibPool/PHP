# mrkoopie/wp_ajaxfilter

> 标签: ajax, archive filter, wordpress

## 简介

Generate HTML forms and filter archive data in WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
