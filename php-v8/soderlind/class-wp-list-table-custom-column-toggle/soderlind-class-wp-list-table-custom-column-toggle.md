# soderlind/class-wp-list-table-custom-column-toggle

> 标签: table, toggle, wordpress, wp

## 简介

Add a toggle column to WP_Table or its siblings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
