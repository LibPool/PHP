# soderlind/ps-last-updated

> 标签: admin, admin-columns, last-updated, wordpress, wordpress-plugin

## 简介

Adds a sortable Last Updated column to public post type admin lists.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
