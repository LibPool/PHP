# soderlind/vmfa-ai-ability

> 标签: PHP

## 简介

Exposes Virtual Media Folders operations as WordPress Abilities API tools for AI agents and MCP adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
