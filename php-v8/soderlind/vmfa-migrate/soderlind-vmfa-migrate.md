# soderlind/vmfa-migrate

> 标签: PHP

## 简介

Migration add-on for Virtual Media Folders. Import folders from Enhanced Media Library, FileBird, Real Media Library, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
