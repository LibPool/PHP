# soderlind/kjeks-google

> 标签: consent-mode-v2, cookie-consent, ga4, gdpr, google-analytics, google-consent-mode, google-tag-manager, gtm, kjeks, privacy, wordpress, wordpress-plugin

## 简介

Google Consent Mode v2 for Kjeks: wires GA4 and Google Tag Manager to the visitor's Kjeks consent choices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
