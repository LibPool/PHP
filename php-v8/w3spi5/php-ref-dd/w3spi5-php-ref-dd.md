# w3spi5/php-ref-dd

> 标签: dd, debug, var_dump

## 简介

A nicer print_r/var_dump alternative for PHP 8.0+ using dd() like in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
