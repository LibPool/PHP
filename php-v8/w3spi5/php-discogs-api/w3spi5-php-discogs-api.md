# w3spi5/php-discogs-api

> 标签: api, discogs

## 简介

The forked and updated as of end of 2024, Discogs API, that makes it easy for developers to communicate with the Discogs platform

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
