# w3spi5/bigdump

> 标签: bigdump, database, dump, import, migration, mysql, sql

## 简介

Staggered MySQL Dump Importer - Import large MySQL dumps on servers with execution time limits

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
