# udir-moodle/qtype_essaywiris

> 标签: PHP

## 简介

Wiris Quizzes Essay question type — Composer/Packagist mirror of the Moodle plugin qtype_essaywiris, auto-updated from the Moodle plugins directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
