# udir-moodle/auth_saml

> 标签: PHP

## 简介

SAML Authentication (simpleSAMLphp required) — Composer/Packagist mirror of the Moodle plugin auth_saml, auto-updated from the Moodle plugins directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
