# vdechenaux/brotli-bin-amd64

> 标签: amd64, brotli, linux, x86-64, x86_64

## 简介

Brotli binary provided by google/brotli and compiled for amd64

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
