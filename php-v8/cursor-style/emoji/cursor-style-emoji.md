# cursor-style/emoji

> 标签: cursor-style, emoji, png, skin-tone, unicode

## 简介

Original Cursor Style 3D emoji catalog with exact Unicode skin-tone variants and PNG URLs from 16 to 1024 pixels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
