# edgar-orozco/versiones

> 标签: laravel, versiones

## 简介

Paquete para administrar ramas, versiones y tags en un proyecto git montado en un servidor web

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
