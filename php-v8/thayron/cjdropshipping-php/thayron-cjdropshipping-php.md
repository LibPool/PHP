> 标签: Dropshipping, api, cjdropshipping, laravel, sdk

## 简介

Framework-agnostic PHP SDK for the CJdropshipping API 2.0, with an optional Laravel bridge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
