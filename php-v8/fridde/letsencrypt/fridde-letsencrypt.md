# fridde/letsencrypt

> 标签: certificate, letsencrypt, shared hosting, ssl

## 简介

PHP script for automatic issuing and renewal of Let's Encrypt SSL certificates on shared hostings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
