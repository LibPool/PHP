# newage/generators

> 标签: generators, newage

## 简介

Code generators for Zend Framework 2 in console.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/newage/generators
- 源码仓库：https://github.com/newage/generators.git
- Packagist 页面：https://packagist.org/packages/newage%2Fgenerators
