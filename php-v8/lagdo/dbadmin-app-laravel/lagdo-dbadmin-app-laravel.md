# lagdo/dbadmin-app-laravel

> 标签: database, laravel, mariadb, mysql, php, postgresql, sqlite

## 简介

A web based database management tool with multiple DBMS support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
