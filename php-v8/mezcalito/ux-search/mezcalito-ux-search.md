# mezcalito/ux-search

> 标签: faceted search, listing, meilisearch, search, symfony-ux

## 简介

Effortless search and faceted search with Symfony UX and Mezcalito UX Search

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
