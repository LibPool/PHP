# open-admin-ext/multi-language

> 标签: extension, open-admin

## 简介

Allow to multilanguage support for open-admin based on laravel-translatable, Credits for orginal implementation: Andrey Kravchenko

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
