# codingmatters/skeleton-app

> 标签: skeleton application

## 简介

PSR-Compliant Skeleton Application (initially based on Zend Expressive Skeleton Application)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
