# podio-labs/podio-client

> 标签: podio, podio-api, podio-client, podio-sdk, psr-18

## 简介

Modern, framework-agnostic PHP client for the Podio API. PSR-18, OAuth handled, fully typed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
