# podio-labs/podio-laravel

> 标签: laravel, podio, podio-api, podio-laravel

## 简介

Laravel integration for the Podio API. A Podio facade with config-driven auth and token caching.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
