# niktomo/konayuki

> 标签: apcu, distributed-id, id, laravel, snowflake

## 简介

High-throughput 63-bit Snowflake ID generator backed by APCu shared memory

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
