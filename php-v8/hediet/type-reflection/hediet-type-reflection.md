# hediet/type-reflection

> 标签: class, metadata, primitive, reflection, runtime, type

## 简介

A library which provide classes to reflect php types in an unified way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
