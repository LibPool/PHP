# uselagoon/lagoon-php-sdk

> 标签: api, devops, hosting, lagoon, sdk

## 简介

PHP Library for interacting the the Lagoon API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
