# gruya/laravel-mobile-api-starter-kit

> 标签: api, laravel, mobile, otp, sanctum, starter-kit

## 简介

Minimal type safe starter kit for mobile-first apps with OTP and action pattern.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
