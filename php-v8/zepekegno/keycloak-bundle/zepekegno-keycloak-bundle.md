# zepekegno/keycloak-bundle

> 标签: Authentication, SSO, keycloak, oidc, openid-connect, symfony-bundle

## 简介

Symfony bundle for Keycloak integration (OIDC, SSO, user management)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
