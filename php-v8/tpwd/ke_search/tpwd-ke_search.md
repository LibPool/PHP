# tpwd/ke_search

> 标签: TYPO3 CMS, faceted search, faceting, ke_search, kesearch, search

## 简介

Faceted search - Search Extension for TYPO3, including faceting search functions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
