# ericjank/message

> 标签: message, messaging, notification, user-to-user

## 简介

A framework-agnostic PHP 5.4+ user-to-user messaging library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
