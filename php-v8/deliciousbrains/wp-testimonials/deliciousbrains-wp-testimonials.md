# deliciousbrains/wp-testimonials

> 标签: PHP

## 简介

WordPress must-use plugin for managing testimonials, importing from tweets and displaying them.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
