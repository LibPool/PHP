# firstphp/wechat

> 标签: 微信, 微信API, 微信授权, 微信第三方授权

## 简介

微信第三方授权-适用于微信第三方平台开发者

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
