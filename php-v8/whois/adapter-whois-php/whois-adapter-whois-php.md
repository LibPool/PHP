# whois/adapter-whois-php

> 标签: PHP

## 简介

Uma adaptação da biblioteca phpWhois - Todos os direitos e créditos são para os autores: www.phpwhois.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
