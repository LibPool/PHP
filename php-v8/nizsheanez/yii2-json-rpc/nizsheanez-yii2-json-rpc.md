# nizsheanez/yii2-json-rpc

> 标签: json, jsonrpc, rpc, yii, yii2

## 简介

A lightweight JsonRpc Server and Client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
