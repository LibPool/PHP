# tylerfiekens/graphqlite-laravel

> 标签: GraphQLite, graphql, laravel

## 简介

A Laravel service provider package to help you get started with GraphQLite in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
