# atik/atik-pdf

> 标签: PHP

## 简介

Enterprise-grade hybrid Laravel PDF package with ultra-fast large-table PDF generation and full Bangla font support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
