# dyanakiev/laravel-file-manager

> 标签: CKEditor, file, file-manager, filemanager, files-manager, filesmanager, image, laravel, mafftor, manager, tinymce, upload

## 简介

The file manager intended for using Laravel with CKEditor / TinyMCE / Colorbox

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
