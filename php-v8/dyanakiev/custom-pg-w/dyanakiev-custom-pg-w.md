# dyanakiev/custom-pg-w

> 标签: builder, extension, laravel, migrations, php, postgres, postgresql, schema

## 简介

Custom pg driver based on umbrellio/laravel-pg-extensions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
