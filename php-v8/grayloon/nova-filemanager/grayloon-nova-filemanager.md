# grayloon/nova-filemanager

> 标签: filemanager, laravel, nova

## 简介

Filemanager tool for Laravel Nova. Forked from GrayloonEs/nova-filemanager

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
