# kayya/api-sdk

> 标签: api-marketplace, hmac, kayya, laravel, middleware, psr-15, webhook

## 简介

Integrasi server tenant dengan marketplace Kayya API: verifikasi panggilan gateway, tanda tangan webhook & sinkronisasi.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
