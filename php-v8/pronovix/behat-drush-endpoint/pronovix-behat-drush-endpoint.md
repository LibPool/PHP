# pronovix/behat-drush-endpoint

> 标签: Behat, Drush, testing

## 简介

Drush commandfile for use with drupal/drupal-driver.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
