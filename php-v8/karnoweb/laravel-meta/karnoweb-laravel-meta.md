# karnoweb/laravel-meta

> 标签: eloquent, laravel, meta, metadata, versioning

## 简介

Typed, optionally versioned metadata for Laravel Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
