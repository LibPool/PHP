# jarjobs/sonatadtomodelmanager

> 标签: Model Manager, Sonata Admin, dto

## 简介

Bundle for handling Sonata Admin form data with data-transfer-object instead of entity

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
