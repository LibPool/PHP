> 标签: API-Client, Guzzle, audio, clean-api, discogs, discogs-api, library, lightweight, minimal-dependencies, modern-php, music, php, php8, vinyl, web-api

## 简介

Lightweight Discogs API client for PHP 8.1+ with built-in resilience and minimal dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
