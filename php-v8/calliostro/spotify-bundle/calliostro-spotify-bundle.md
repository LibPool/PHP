# calliostro/spotify-bundle

> 标签: API-Client, audio, lightweight, music, php, php8, spotify, spotify-api, streaming, symfony, symfony-bundle, web-api

## 简介

Lightweight Symfony bundle for the Spotify Web API with autowiring, resilience, and rate limiting support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
