> 标签: API-Client, Guzzle, audio, audioscrobbler, clean-api, last-fm, lastfm, lastfm-api, library, lightweight, minimal-dependencies, modern-php, music, php, php8, scrobbling, web-api

## 简介

Lightweight Last.fm API client for PHP 8.1+ with built-in resilience and minimal dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
