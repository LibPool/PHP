> 标签: API-Client, Guzzle, audio, clean-api, library, lightweight, minimal-dependencies, modern-php, music, php, php8, spotify, spotify-api, spotify-web-api, streaming, web-api

## 简介

Lightweight Spotify Web API client for PHP 8.1+ with built-in resilience and minimal dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
