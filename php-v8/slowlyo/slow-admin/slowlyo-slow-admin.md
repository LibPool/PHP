# slowlyo/slow-admin

> 标签: SlowAdmin, admin, laravel

## 简介

采用 laravel、amis、vue3 打造的后台框架，拥有 120+ 种组件，只用后端代码就能实现复杂的页面效果，学习成本低，让开发者能够快速构建高效的后台管理系统。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
