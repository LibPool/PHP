# slowlyo/slow-amis-json-parse

> 标签: amis, extension, json-parse, slow-admin

## 简介

将 amis 的 json 结构转换为 SlowAdmin 代码

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
