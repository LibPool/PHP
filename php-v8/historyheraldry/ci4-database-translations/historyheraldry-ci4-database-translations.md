# historyheraldry/ci4-database-translations

> 标签: codeigniter4, database, i18n, localization, translations

## 简介

Database-backed translations and deployable translation seed generation for CodeIgniter 4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
