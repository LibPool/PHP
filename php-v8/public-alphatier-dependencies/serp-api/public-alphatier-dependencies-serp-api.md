# public-alphatier-dependencies/serp-api

> 标签: SERP, api, client, curl, google, json, localisation, rest, result, search, walmart, xml, yandex, youtube

## 简介

Scrape Google, Bing, Baidu, Ebay, Youtube, Walmart, Yandex search result at scale using SerpApi.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
