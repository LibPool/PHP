# unite-cms/doctrine-orm-bundle

> 标签: PHP

## 简介

Adds doctrine orm support (MySQL, PostgreSQL, MariaDB etc.) for unite cms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
