# parad0x/event-calendar

> 标签: bs-date, calendar, event-calendar, laravel, nepali-calendar, nepali-date

## 简介

A Laravel event calendar component with Nepali date support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
