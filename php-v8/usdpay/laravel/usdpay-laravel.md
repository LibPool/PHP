# usdpay/laravel

> 标签: BEP20, USDT, crypto-payments, laravel, payment-gateway, payments, stablecoin, ton, trc20, tron, usdpay

## 简介

Official Laravel SDK for accepting USDT payments with USDPAY.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://usdpay.me/integrations/laravel
- 源码仓库：https://github.com/probizi/usdpay-laravel.git
- Packagist 页面：https://packagist.org/packages/usdpay%2Flaravel

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require usdpay/laravel`
- Packagist 仓库：https://repo.packagist.org/p2/usdpay/laravel.json
- 许可证：MIT
- PHP 要求：^8.2
