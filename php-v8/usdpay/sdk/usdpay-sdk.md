# usdpay/sdk

> 标签: BEP20, USDT, bsc, crypto payment gateway, crypto payments, payment api, payment gateway, ton, trc20, tron, usdpay, usdt api, usdt payments, webhook

## 简介

PHP SDK for accepting USDT payments directly to your wallet with automatic payment verification and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
