# pjhl/yii2-pwstrength

> 标签: password, strength, validation, validator, yii2

## 简介

This extension provides a simple password validator for Yii Framework 2.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
