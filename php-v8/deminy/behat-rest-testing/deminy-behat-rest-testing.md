# deminy/behat-rest-testing

> 标签: Behat, php, rest

## 简介

Demo on doing feature tests with Behat 3 and how to start writing feature tests for REST APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
