# deminy/counit

> 标签: phpunit, swoole

## 简介

To run time/IO related unit tests (e.g., sleep function calls, database queries, API calls, etc) faster using Swoole.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
