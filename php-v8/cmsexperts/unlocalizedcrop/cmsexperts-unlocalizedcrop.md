# cmsexperts/unlocalizedcrop

> 标签: PHP

## 简介

Disables cropping for translated records. Cropping of localized records are automatically taken from the original language

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
