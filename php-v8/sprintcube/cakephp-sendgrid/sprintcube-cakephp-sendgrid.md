# sprintcube/cakephp-sendgrid

> 标签: cakephp, email, sendgrid

## 简介

SendGrid plugin for CakePHP 4 - Send emails using SendGrid API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
