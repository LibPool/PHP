# brusch/unzer-php-sdk

> 标签: PHP

## 简介

This is a fork of unzerdev/php-sdk that supports PHP8 until the official SDK provides support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
