# webumer/bcb-php-sdk

> 标签: api, bcb, bcb-group, payments, php, sdk, virtual-iban, webhooks

## 简介

Unofficial PHP SDK for BCB Group Client API (payments, beneficiaries, virtual IBANs, webhooks).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
