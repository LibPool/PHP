# bugo/scss-php

> 标签: compiler, css, dart-sass, pure-php, sass, scss

## 简介

Pure PHP compiler for SCSS/Sass, fully compatible with the Dart Sass specification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
