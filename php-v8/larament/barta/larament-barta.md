# larament/barta

> 标签: SMS Service, bangladesh, barta, sms, sms api, sms api bangladesh, sms gateway, sms gateway bangladesh, sms notification, sms notification bangladesh, sms provider, sms provider bangladesh, sms sender, sms sender bangladesh, sms service bangladesh

## 简介

Barta is a Laravel package designed to integrate popular Bangladeshi SMS gateways seamlessly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
