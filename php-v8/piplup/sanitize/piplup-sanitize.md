# piplup/sanitize

> 标签: Escape, html, kses, sanitize, security, xss

## 简介

WordPress-like sanitization and escaping utilities for PHP — framework-agnostic, secure by design.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
