# asha23/arlo-base-wordpress

> 标签: Arlo, Wordpress framework, base theme, composer, vagrant, wordpress, wp

## 简介

A Composer Framework to help you get WordPress up and running in around a minute

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
