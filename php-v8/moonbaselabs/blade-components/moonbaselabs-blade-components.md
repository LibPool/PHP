# moonbaselabs/blade-components

> 标签: alpinejs, blade, laravel, tailwind, ui

## 简介

A set of themeable components built with Tailwind CSS and AlpineJS for use with Laravel Blade.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
