# backendprogramer/laravel-redirect-panel

> 标签: backendprogramer, laravel, laravel-redirect-panel

## 简介

A panel for adding redirects to the `.htaccess` file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
