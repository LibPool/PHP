# aarsteinmedia/divi-stubs

> 标签: divi, static analysis

## 简介

DIVI function, class, and global variable declaration stubs for easier static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
