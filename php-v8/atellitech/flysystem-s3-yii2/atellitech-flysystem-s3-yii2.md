# atellitech/flysystem-s3-yii2

> 标签: Flysystem, filesystem, s3, yii2

## 简介

It's an adapter of AWS S3 for Yii2 that integrating with atellitech/flysystem-yii2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
