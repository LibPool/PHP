# confeature/confeature-php-sdk

> 标签: confeature, configcat, configuration, feature-flag, feature-toggle

## 简介

Confeature PHP SDK. Drop-in compatible with configcat/configcat-php-sdk (Confeature Constitution Principle II).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
