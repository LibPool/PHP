# stefansl/divider

> 标签: contao, divider, extension, horizontal, hr, rule, ruler, usability

## 简介

ContentElement for Contao to generate hr. Simply choose element type "divider" and save.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
