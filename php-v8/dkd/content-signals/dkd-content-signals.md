# dkd/content-signals

> 标签: PHP

## 简介

Adds Content-Signal meta tags to pages per contentsignals.org spec, configurable globally via TypoScript and per page via TCA fields.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
