# wpjscc/reactphp-log

> 标签: async, log, logger, logging, non-blocking, reactphp

## 简介

Non-blocking logging for PHP based on reactphp, and Monolog.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
