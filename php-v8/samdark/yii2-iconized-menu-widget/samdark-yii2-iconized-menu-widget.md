# samdark/yii2-iconized-menu-widget

> 标签: extension, favicon, icon, menu, yii

## 简介

IconizedMenu automatically adds favicons in front of menu links

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
