# novay/laravel-uuid

> 标签: UUID RFC4122

## 简介

Laravel package to generate and to validate a UUID according to the RFC 4122 standard. UUID Versions 1, 3, 4 and 5 are supported.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
