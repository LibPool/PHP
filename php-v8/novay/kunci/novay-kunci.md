# novay/kunci

> 标签: PHP

## 简介

Core Laravel package for secure encryption/decryption with pluggable key management drivers (file-based, Cloud KMS or Hardware Token/HSM/PKCS#11).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
