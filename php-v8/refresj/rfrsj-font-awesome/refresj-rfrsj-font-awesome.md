# refresj/rfrsj-font-awesome

> 标签: PHP

## 简介

Font Awesome for CKEditor - Integrates Font Awesome 7 Pro+ icons into the CKEditor 5 RTE! Font Awesome license required and not included.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
