# krafsys/payment-manager

> 标签: Nigeria, bachs, flutterwave, gateway, kora, korapay, monnify, payments, paystack

## 简介

A unified, dependency-free PHP interface for Paystack, Flutterwave, Monnify, Kora, and Bachs payment gateways.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
