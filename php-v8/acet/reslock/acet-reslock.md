# acet/reslock

> 标签: advisory lock, file lock, flock, lock, php, race condition, resource lock

## 简介

Dependable advisory resource lock - for files and other contentious resources

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
