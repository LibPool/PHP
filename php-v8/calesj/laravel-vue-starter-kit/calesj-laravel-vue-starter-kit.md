# calesj/laravel-vue-starter-kit

> 标签: inertia, laravel, starter-kit, vue

## 简介

Personal Laravel 12 + Vue 3 + Inertia.js starter kit with authentication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
