# owlycode/streaming-bird

> 标签: api, php, streaming, twitter

## 简介

A PHP client for the Twitter Streaming APIs inspired from Phirehose.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
