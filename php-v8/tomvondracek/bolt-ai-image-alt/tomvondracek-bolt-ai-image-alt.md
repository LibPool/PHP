# tomvondracek/bolt-ai-image-alt

> 标签: accessibility, ai, alt, bolt, bolt-extension, florence-2

## 简介

In-browser AI generation of image ALT texts for the Bolt CMS admin (Florence-2 + Chrome Translator API). No API costs, image data never leaves the browser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
