# tomvondracek/bolt-discussion

> 标签: PHP

## 简介

📦 Pluggable, themeable discussion / comments module for Bolt CMS 6 (replies, reactions, async submit, REST polling).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
