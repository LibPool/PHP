# tomvondracek/bolt-llms-txt

> 标签: ai, bolt, bolt-extension, llm, llms-txt, seo, twig

## 简介

Bolt CMS extension that serves a dynamic /llms.txt (llmstxt.org), rendered from your own Twig template with HTTP caching, ETag and HTML-to-Markdown filters built in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
