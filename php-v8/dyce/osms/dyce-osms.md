# dyce/osms

> 标签: api, client, curl, http client, json, orange, php, requests, rest, restful, sms, web service

## 简介

PHP library wrapper of the Orange SMS API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
