# vzool/bug-notifier

> 标签: BugNotifier, bitbucket, bug, e-mail, flyingluscas, github, issues, laravel, vzool

## 简介

Get notified every time an exception is thrown in your application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
