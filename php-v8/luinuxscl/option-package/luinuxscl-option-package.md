# luinuxscl/option-package

> 标签: configuración, laravel, options, polimórfico

## 简介

Paquete Laravel para gestionar opciones polimórficas asociadas a cualquier modelo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
