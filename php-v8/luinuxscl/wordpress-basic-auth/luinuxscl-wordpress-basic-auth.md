# luinuxscl/wordpress-basic-auth

> 标签: PHP

## 简介

Autenticación básica para WordPress en Laravel. Proporciona middleware y funcionalidades para la autenticación básica de WordPress.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
