# popphp/pop-pdf

> 标签: create pdf, extract pdf text, html-to-pdf, import pdf, merge pdf, pdf, pdf generation, php, php pdf library, php pdf processing, pop, pop php

## 简介

PHP PDF library for generating and importing PDF documents. A component of the Pop PHP Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
