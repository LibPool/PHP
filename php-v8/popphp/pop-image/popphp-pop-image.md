# popphp/pop-image

> 标签: draw image, image, image crop, image effects, image resize, image text, php, php image library, php image processing, pop, pop php

## 简介

PHP Image library for generating, editing and effecting images. A component of the Pop PHP Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
