# popphp/pop-loader

> 标签: PSR-4, autoloader, loader, pop, pop php, psr-0

## 简介

Pop Loader Component for Pop PHP Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
