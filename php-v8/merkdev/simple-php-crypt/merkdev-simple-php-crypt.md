# merkdev/simple-php-crypt

> 标签: crypt, hash, php

## 简介

Converts an integer to YouTube style (like) crypted string. Simple crypt class for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
