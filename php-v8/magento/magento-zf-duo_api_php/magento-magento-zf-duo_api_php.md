# magento/magento-zf-duo_api_php

> 标签: PHP

## 简介

A PHP implementation of the Duo API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://duo.com/
- 源码仓库：https://github.com/magento/magento-zf-duo_api_php.git
- Packagist 页面：https://packagist.org/packages/magento%2Fmagento-zf-duo_api_php

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require magento/magento-zf-duo_api_php`
- Packagist 仓库：https://repo.packagist.org/p2/magento/magento-zf-duo_api_php.json
- PHP 要求：>=8.0
