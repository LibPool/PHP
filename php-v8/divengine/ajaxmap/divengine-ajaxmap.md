# divengine/ajaxmap

> 标签: ajax, front-end

## 简介

Div Ajax Mapping allow mapping PHP functions, static methods and arbitrary data when instance a JavaScript class

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
