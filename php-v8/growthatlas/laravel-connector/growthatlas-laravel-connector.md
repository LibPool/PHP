# growthatlas/laravel-connector

> 标签: PHP

## 简介

Official GrowthAtlas connector package for Laravel applications. Exposes the GrowthAtlas Connector API v1 endpoints to receive and publish AI-generated SEO content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
