# wasabi-web/mongodm

> 标签: mongodb, mongodm, orm

## 简介

MongoDB ORM that includes support for references, embed and multilevel inheritance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
