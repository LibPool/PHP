# madbox-99/laravel-google-connect

> 标签: PHP

## 简介

Unified Google OAuth (Ads + Search Console + Analytics) connection for multi-tenant Laravel + Filament apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
