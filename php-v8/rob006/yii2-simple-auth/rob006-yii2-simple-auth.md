# rob006/yii2-simple-auth

> 标签: Authentication, auth, extension, yii2

## 简介

Yii 2 extension that provides simple authentication based on a secret key.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
