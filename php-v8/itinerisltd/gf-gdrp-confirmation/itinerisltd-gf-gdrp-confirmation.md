# itinerisltd/gf-gdrp-confirmation

> 标签: gravityforms, wordpress, wp

## 简介

Encrypt personal information in query string and pre-populate them to Gravity Forms fields

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
