# itinerisltd/gf-sendgrid-dynamic-template-notification

> 标签: dynamic-template, email, gravity-forms, gravityforms, sendgrid, wordpress, wp

## 简介

Send GravityForms notifications via SendGrid dynamic transactional templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
