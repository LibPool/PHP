# itinerisltd/crop-thumbnails-cdn-cache-busting

> 标签: cache, cdn, crop-thumbnails, wordpress, wp

## 简介

Bust CDN caches after cropping thumbnails. Requires the Crop-Thumbnails plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
