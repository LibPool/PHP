# itinerisltd/itineris-prevent-wp-user-enumeration

> 标签: Users, owasp, security, wordpress

## 简介

Prevent User Enumeration in WordPress to satisfy security reports.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
