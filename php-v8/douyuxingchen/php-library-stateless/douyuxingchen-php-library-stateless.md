# douyuxingchen/php-library-stateless

> 标签: PHP

## 简介

无状态的PHP库。通过此SDK您可以轻松地管理项目中的不同服务，并确保它们在各种情况下都能保持正确的状态。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
