# geoffselby/puzzle-prelaunch-preset

> 标签: jigsaw, puzzle cli

## 简介

A modern, minimal prelaunch preset for Jigsaw powered by Tailwind CSS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
