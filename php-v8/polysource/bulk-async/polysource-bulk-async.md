# polysource/bulk-async

> 标签: Messenger, async, bulk, mercure, polysource, symfony

## 简介

Polysource — async bulk actions via Symfony Messenger + live progress via Mercure SSE.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
