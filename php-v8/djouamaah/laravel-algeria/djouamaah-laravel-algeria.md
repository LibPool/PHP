# djouamaah/laravel-algeria

> 标签: Algeria, Wilaya, algerie, baladiya, code postal, commune, daira, laravel, postal code, الجزائر

## 简介

All Algerian wilayas, dairas, communes and postal codes (69 wilayas / 1541 communes) for Laravel: migrations, seeder, Eloquent models, validation rules and a ready-made API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
