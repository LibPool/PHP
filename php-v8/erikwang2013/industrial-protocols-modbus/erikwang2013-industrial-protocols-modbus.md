# erikwang2013/industrial-protocols-modbus

> 标签: industrial-protocols, modbus, modbus-rtu, modbus-tcp, plc

## 简介

Modbus TCP/RTU/ASCII 协议包 — 支持 FC 01/03/04/06/10，纯 PHP Socket 实现

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
