# erikwang2013/industrial-protocols-profinet

> 标签: industrial-protocols, plc, profinet, siemens

## 简介

Profinet NRT 协议包 — DCP 设备发现 + Record Data 读写（RT 通道需 ERTEC 硬件）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
