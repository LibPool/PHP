# erikwang2013/industrial-protocols-bacnet

> 标签: bacnet, bacnet-ip, building-automation, industrial-protocols

## 简介

BACnet/IP 协议包 — 支持 Who-Is/I-Am 设备发现和 ReadProperty，UDP 通信

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
