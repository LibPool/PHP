# erikwang2013/consul-php

> 标签: PHP

## 简介

PHP Consul client with full API v1 coverage, service discovery, and config center. Auto-integrates with Laravel, Hyperf, webman, and ThinkPHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
