# erikwang2013/apidoc-php

> 标签: apidoc, api文档, attributes, attribute生成, markdown, php接口文档, 接口文档, 自动生成api

## 简介

基于PHP 8 attributes生成API文档，兼容Laravel、ThinkPHP、Hyperf、Webman等框架；在线调试、Markdown文档、多应用/多版本、Mock数据、授权访问、接口生成器、代码生成器等众多实用功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
