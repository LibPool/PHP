# erikwang2013/etcd

> 标签: etcd, etcd-client, etcd-v3, hyperf, laravel, thinkphp, webman

## 简介

PHP etcd v3 client with gRPC + HTTP dual transport. Supports Laravel, Hyperf, ThinkPHP, Webman.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
