# erikwang2013/jwt-webman

> 标签: erik, erikwang2013, hyperf, jwt, laravel, thinkphp, webman

## 简介

A JWT plugin compatible with webman, Laravel, ThinkPHP, and Hyperf. Suitable for distributed deployment, simple and fast installation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
