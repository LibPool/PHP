# erikwang2013/industrial-protocols-hart

> 标签: fieldbus, hart, industrial-protocols, process-automation

## 简介

HART 协议包 — 4-20mA FSK 调制解调器通信，支持 PV/回路电流/设备信息读取

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
