# amzn-spapi/sdk

> 标签: amazon, openapi-generator, php, rest, sdk, sp-api

## 简介

Amazon Selling Partner APIs official client library for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
