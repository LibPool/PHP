# temant/auth-manager

> 标签: PHP

## 简介

Full-featured authentication & authorization library: session auth, JWT, TOTP 2FA, hierarchical RBAC, rate limiting, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
