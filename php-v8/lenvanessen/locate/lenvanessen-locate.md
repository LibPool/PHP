# lenvanessen/locate

> 标签: Craft, address, cms, craft-plugin, craftcms, google-maps, locate, locations, map, proximity-search

## 简介

Harness the power of the Google Autocomplete API inside Craft. Adds an autocomplete search box to Craft entries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
