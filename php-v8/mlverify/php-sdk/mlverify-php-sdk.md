# mlverify/php-sdk

> 标签: aml, api, kyc, mlverify, php, sdk, swagger

## 简介

PHP Library from SwaggerHub, for use with MLVerify.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://mlverify.com
- 源码仓库：https://github.com/MLVerify/PHP-SDK.git
- Packagist 页面：https://packagist.org/packages/mlverify%2Fphp-sdk

- Composer 安装：`composer require mlverify/php-sdk`

- 许可证：proprietary
- PHP 要求：>=5.5
