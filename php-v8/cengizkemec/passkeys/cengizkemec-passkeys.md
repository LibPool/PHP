# cengizkemec/passkeys

> 标签: FIDO2, extension, flarum, passkey, webauthn

## 简介

Passkey (WebAuthn/FIDO2) authentication for Flarum 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
