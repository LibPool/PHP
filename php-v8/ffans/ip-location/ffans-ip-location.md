# ffans/ip-location

> 标签: China, IP, flarum, geolocation, ip-geolocation, ip-region, location

## 简介

Compliant IP geolocation display for internet platforms serving Mainland China.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
