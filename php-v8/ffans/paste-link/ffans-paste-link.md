# ffans/paste-link

> 标签: extension, flarum, link, markdown, parser, paste

## 简介

Turn selected text into a Markdown link by pasting a URL in Flarum's default composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
