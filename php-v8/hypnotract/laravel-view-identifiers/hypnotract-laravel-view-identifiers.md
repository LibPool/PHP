# hypnotract/laravel-view-identifiers

> 标签: class, global, id, identifiers, laravel, view

## 简介

A quick way to set classes and id to main HTML DOM element in Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
