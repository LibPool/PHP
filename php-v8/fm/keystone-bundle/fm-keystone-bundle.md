# fm/keystone-bundle

> 标签: Authentication, Openstack, identity, keystone, token

## 简介

A Symfony2 implementation of the OpenStack Identity Service API A.K.A. Keystone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
