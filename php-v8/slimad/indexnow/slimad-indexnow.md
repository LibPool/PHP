# slimad/indexnow

> 标签: bing, crawling, indexing, indexnow, naver, search-engine, seo, seznam, yandex, yep

## 简介

Framework-agnostic IndexNow client and queue for submitting URL changes to participating search engines (Bing, Yandex, Seznam, Naver, Yep).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
