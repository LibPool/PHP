# carlcs/craft-pushovernotificationchannel

> 标签: craftcms, notifications, pushover

## 简介

A Pushover notification channel for the Craft Notifications plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
