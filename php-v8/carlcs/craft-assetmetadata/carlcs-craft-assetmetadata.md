# carlcs/craft-assetmetadata

> 标签: asset, audio, craftcms, field, image, metadata

## 简介

Asset Metadata plugin for Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
