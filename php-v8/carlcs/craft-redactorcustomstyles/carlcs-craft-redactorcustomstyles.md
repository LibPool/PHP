# carlcs/craft-redactorcustomstyles

> 标签: Redactor, buttons, craftcms, styles

## 简介

Redactor Custom Styles plugin for Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
