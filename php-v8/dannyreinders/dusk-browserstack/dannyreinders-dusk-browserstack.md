# dannyreinders/dusk-browserstack

> 标签: BrowserStack, dusk, laravel, testing, webdriver

## 简介

Easily run Laravel Dusk tests on BrowserStack.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
