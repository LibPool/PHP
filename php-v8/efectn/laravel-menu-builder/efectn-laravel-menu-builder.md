# efectn/laravel-menu-builder

> 标签: builder, drag and drop, laravel, menu, wordpress

## 简介

Wordpress like drag & drop menu builder for Laravel 9.x

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
