# idanieldrew/esb

> 标签: laravel, php, publish, queue, rabbitmq, subscribe

## 简介

This package support Pub/Sub rabbitmq and also support queue driver laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
