# webwingscz/skautis-symfony

> 标签: junak, skaut, skautis, soap, symfony

## 简介

Symfony bundle pro webové služby skautISu (is.skaut.cz): typovaný SOAP klient, přihlašování a role.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
