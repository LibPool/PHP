# ansas/propel-helper

> 标签: helper, orm, propel, readonly, validation

## 简介

Propel helper - helper classes (traits) for Propel2 ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
