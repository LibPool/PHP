# debril/rss-atom-bundle

> 标签: Syndication, atom, feed, jsonfeed, rss

## 简介

RSS / Atom and JSONFeed support for Symfony

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
