# dgtlss/atlas

> 标签: Agent, ai, ai-seo, atlas, json, laravel, markdown, routes

## 简介

Expose selected Laravel routes as agent-readable Markdown and JSON without changing their HTML behavior.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
