# dartui/multiinfo

> 标签: laravel, multiinfo, polkomtel, sms

## 简介

Polkomtel MultiInfo integration for sending SMS from Laravel applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
