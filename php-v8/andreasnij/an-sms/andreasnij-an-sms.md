# andreasnij/an-sms

> 标签: 46elks, cellsynt, nexmo, premium sms, psms, sms, twilio, vonage

## 简介

A PHP library to send and receive SMS text messages through various gateways/providers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
