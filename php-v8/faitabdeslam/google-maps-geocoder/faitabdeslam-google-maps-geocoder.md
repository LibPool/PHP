# faitabdeslam/google-maps-geocoder

> 标签: geocode, geocoder, geocoding, gmap, gmaps, google, map, maps

## 简介

A PHP wrapper for the Google Maps Geocoding API v3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
