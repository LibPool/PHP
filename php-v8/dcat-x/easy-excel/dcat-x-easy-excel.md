# dcat-x/easy-excel

> 标签: csv, excel, export, import, ods, openspout, reader, spreadsheet, writer, xlsx

## 简介

A simple and elegant Excel read/write library based on OpenSpout, with minimal memory usage

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
