# sergiynezbritskiy/magento2-translations-checker

> 标签: PHP

## 简介

CLI tool to verify that every translatable phrase of a Magento 2 module is present and translated in its i18n dictionaries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
