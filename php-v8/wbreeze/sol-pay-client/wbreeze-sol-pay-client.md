# wbreeze/sol-pay-client

> 标签: PHP

## 简介

Server-side PHP client for the pay-on-chain metering program: PDA derivation, instruction building, account decoding, preflight, and error mapping. Mirrors wasm-client's core surface for servers with no Rust toolchain and no WASM runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
