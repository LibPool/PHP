# eskono/mcp-client

> 标签: ai, client, json-rpc, llm, mcp, model-context-protocol, sdk

## 简介

Framework-agnostic PHP 8.3+ SDK implementing the client side of the Model Context Protocol (MCP).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
