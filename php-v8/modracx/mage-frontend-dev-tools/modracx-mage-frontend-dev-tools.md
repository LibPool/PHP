# modracx/mage-frontend-dev-tools

> 标签: PHP

## 简介

Storefront developer toolbar and profiler for Magento 2 — works on Luma, Hyva and Breeze

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
