# carlosedu011brasil/laravel-recorder-logger

> 标签: PHP

## 简介

Componente Vue para gravação de tela com logger embutido (console, requests, erros, rotas)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
