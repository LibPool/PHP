# wiznetic/corenetic-base

> 标签: PHP

## 简介

Corenetic Framework — bare core skeleton. A modular PHP framework with attribute-based routing, middleware pipeline and event-driven kernel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
