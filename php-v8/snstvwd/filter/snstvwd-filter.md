# snstvwd/filter

> 标签: dfa, filter, sensitive word

## 简介

PHP基于确定有穷自动机算法（DFA）的敏感词过滤器

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
