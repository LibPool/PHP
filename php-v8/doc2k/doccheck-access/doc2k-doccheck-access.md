# doc2k/doccheck-access

> 标签: PHP

## 简介

DocCheck Access is a lightweight TYPO3 extension that provides DocCheck OAuth authentication for frontend access.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
