# kinedu/cfdi-xml

> 标签: Kinedu, cfdi, sat

## 简介

Librería para generar la estructura XML de los Comprobantes Fiscales (CFDI)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
