# pdir/contao-weather-get

> 标签: OpenWeatherMap, composer, contao, forecast.io, weather, wetter, yahoo weather

## 简介

Contao extension for displaying weather using yahoo / openweathermap / forecast.io

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
