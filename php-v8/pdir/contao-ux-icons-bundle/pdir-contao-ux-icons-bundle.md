# pdir/contao-ux-icons-bundle

> 标签: PHP

## 简介

Renders local and remote SVG icons in your Contao Twig templates. Adds a icon picker widget to Contao.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
