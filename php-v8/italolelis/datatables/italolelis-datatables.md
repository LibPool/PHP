# italolelis/datatables

> 标签: datatables, grid, wrapper

## 简介

A PHP wrapper for DataTables (http://www.datatables.net) plugin for jQuery.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
