# phillarmonic/allegro-redis-odm-bundle

> 标签: PHP

## 简介

Redis ODM (Object Document Mapper) for Symfony - store and retrieve PHP objects using Redis

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
