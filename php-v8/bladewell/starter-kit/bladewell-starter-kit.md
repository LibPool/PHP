# bladewell/starter-kit

> 标签: blade, bladewell, laravel, starter-kit, tailwind

## 简介

A Laravel starter kit with Bladewell Blade widgets, Tailwind CSS and AI agent setup, and no database. No React, Vue or Alpine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
