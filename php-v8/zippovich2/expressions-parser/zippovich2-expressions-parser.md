# zippovich2/expressions-parser

> 标签: RPN, arithmetical expressions parser, equation, expressions parser, logical expressions parser, math, reverse polish notations, shunting-yard

## 简介

Used shunting-yard algorithm to parse any expressions and RPN(Reverse Polish Notations) to execute it.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
