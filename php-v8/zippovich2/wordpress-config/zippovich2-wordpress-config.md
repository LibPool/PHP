# zippovich2/wordpress-config

> 标签: actions, config, filters, hooks, wordpress, yaml

## 简介

This package allows you to configure filters and actions via yaml config files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
