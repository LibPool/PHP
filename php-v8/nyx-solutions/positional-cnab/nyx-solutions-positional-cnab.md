# nyx-solutions/positional-cnab

> 标签: PHP

## 简介

Parser de arquivos de configuração CNAB baseado no projeto de Glauber Portella (https://github.com/glauberportella/cnab-layouts-parser).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
