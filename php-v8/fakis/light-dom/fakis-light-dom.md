# fakis/light-dom

> 标签: builder, dom, escaper, html, selector, xss

## 简介

A lightweight, secure HTML DOM builder for PHP, with jQuery-style selectors and auto-escaping.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
