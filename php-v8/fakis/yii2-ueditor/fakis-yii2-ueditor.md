# fakis/yii2-ueditor

> 标签: extension, ueditor, yii2

## 简介

富文本编辑器，针对Yii2框架封装的百度UEditor编辑器

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
