# spiggle/filament-portal-snapshot

> 标签: database, db-snapshots, demo-reset, filament, filament-plugin, filament-v4, filament-v5, laravel, snapshots, spiggle

## 简介

Filament 4/5 plugin for creating, scheduling, restoring, exporting and remotely storing database snapshots with automated demo resets.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
