# spiggle/rules-engine

> 标签: automation, filament, laravel, rules-engine, spiggle

## 简介

Tenant-scoped Filament rules engine with preset triggers, idempotent execution, and audit logs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
