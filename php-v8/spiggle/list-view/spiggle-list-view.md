# spiggle/list-view

> 标签: filament, filament-plugin, laravel, list, spiggle, table

## 简介

Filament v5 plugin that toggles tables between table and alphabetical list views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
