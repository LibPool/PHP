# digedag/t3sportsbet

> 标签: TYPO3 CMS, betgame, sports

## 简介

Bet game based on TYPO3 extension T3sports.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
