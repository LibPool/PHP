# bernskiold/laravel-data-scrubber

> 标签: bernskiold, data-scrubber, laravel, personal data, pii

## 简介

A package for Laravel to clean or scrub data such as PII from models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
