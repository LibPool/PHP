# goktugcy/worker-safety

> 标签: frankenphp, laravel, octane, php, roadrunner, sarif, static-analysis, swoole, worker

## 简介

Static analysis for PHP applications running on persistent workers. Detect cross-request state risks before they reach production.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
