# hbgl/php-code-128-encoder

> 标签: Barcode Font, CODE 128, Libre Barcode, barcode, encoder

## 简介

Encode text for use with Code 128 fonts such as Libre Barcode 128.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
