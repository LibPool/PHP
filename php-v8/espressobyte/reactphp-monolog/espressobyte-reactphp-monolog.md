# espressobyte/reactphp-monolog

> 标签: PHP

## 简介

A simple PSR file logger for react php forked from https://github.com/sunvalley-technologies/react-php-file-logger

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
