# antalaron/video-gif

> 标签: animated gif, gif, thumbnail, video, video processing

## 简介

PHP library to create animated gif thumbnails for videos

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
