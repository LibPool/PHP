# raliqala/any-conversions

> 标签: any-conversions, raliqala

## 简介

Everything conversion like Kilograms to Pounds, temperature, weight,volume, speed, length, angle, time etc..

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
