# atwx/silverstripe-htmlfield-cleaner

> 标签: cleaner, cms, html, silverstripe, tinymce

## 简介

Cleans HTML fields (tags, attributes, inline styles) of DataObjects before writing, configurable via YAML

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
