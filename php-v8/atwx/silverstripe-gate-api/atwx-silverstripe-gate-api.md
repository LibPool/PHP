# atwx/silverstripe-gate-api

> 标签: api, atwx, cms, mcp, module, silverstripe, silverstripe-gate

## 简介

A Silverstripe module adding a JWT authenticated content API to the SilverGate modules. Answers API calls where gate-client is installed, makes them where gate-manager is.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
