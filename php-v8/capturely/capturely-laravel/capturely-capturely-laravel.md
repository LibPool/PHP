# capturely/capturely-laravel

> 标签: capturely, capturely.app, pptr converter

## 简介

Laravel Package for capturely.app html/url to pdf/png/jpeg conversion service

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
