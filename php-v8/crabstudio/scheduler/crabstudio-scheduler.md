# crabstudio/scheduler

> 标签: anhtuank7c, cakephp, crabstudio, cron job, scheduler, task

## 简介

Makes scheduling tasks in CakePHP much simpler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
