# solution25/smarty-address-validation

> 标签: PHP

## 简介

Smarty Integration validates and standardizes US addresses in Shopware 6 using Smarty APIs. It auto-fills city and ZIP and blocks invalid addresses during registration and checkout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
