# iamdevroyal/nativephp-mobile-biometrics

> 标签: Fingerprint, biometrics, faceid, laravel, mobile, nativephp, security, touchid

## 简介

Biometric authentication plugin for NativePHP Mobile (Touch ID, Face ID, Fingerprint) — BIOMETRIC_STRONG enforcement, timeout-bounded native calls, and pre-flight availability checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
