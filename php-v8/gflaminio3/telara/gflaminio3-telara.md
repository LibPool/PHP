# gflaminio3/telara

> 标签: laravel, php, storage, telegram

## 简介

A custom Laravel package that provides a storage disk for uploading files to Telegram and retrieving them seamlessly

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
