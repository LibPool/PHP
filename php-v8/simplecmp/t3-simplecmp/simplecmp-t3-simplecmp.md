# simplecmp/t3-simplecmp

> 标签: PHP

## 简介

TYPO3 integration for SimpleCMP — consent manager (banner + recorder + service DB + CMS bridge).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
