# naroga/queue-manager

> 标签: daemon, manager, php, queue, worker, workers

## 简介

A simple PHP-based queue manager, with an interface for registering custom workers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
