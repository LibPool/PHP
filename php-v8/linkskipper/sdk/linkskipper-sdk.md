# linkskipper/sdk

> 标签: API-Client, URL-Shortener, link-resolver, linkskipper, sdk

## 简介

Official PHP client for the Link Skipper link-resolving API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
