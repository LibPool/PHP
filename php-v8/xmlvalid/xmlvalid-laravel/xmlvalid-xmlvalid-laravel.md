# xmlvalid/xmlvalid-laravel

> 标签: E-Invoice, EN16931, factur-x, laravel, peppol, schematron, ubl, validation, xml, xrechnung, xsd

## 简介

Laravel integration for the xmlvalid API: a validation rule for XML and e-invoices (Peppol, XRechnung, Factur-X, UBL, XSD, Schematron), webhooks as events, Artisan commands

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
