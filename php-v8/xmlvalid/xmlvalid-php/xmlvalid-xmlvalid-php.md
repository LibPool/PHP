# xmlvalid/xmlvalid-php

> 标签: E-Invoice, EN16931, factur-x, peppol, schematron, ubl, validation, xml, xrechnung, xsd

## 简介

PHP client for the xmlvalid API: validate XML and e-invoices (Peppol, XRechnung, Factur-X, UBL, CII) against XSD, DTD, RelaxNG and Schematron business rules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
