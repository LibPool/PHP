# xmlvalid/xmlvalid-symfony

> 标签: E-Invoice, EN16931, bundle, factur-x, peppol, schematron, symfony, ubl, validation, xml, xrechnung, xsd

## 简介

Symfony bundle for the xmlvalid API: a validator constraint for XML and e-invoices (Peppol, XRechnung, Factur-X, UBL, XSD, Schematron), webhooks as events, console commands

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
