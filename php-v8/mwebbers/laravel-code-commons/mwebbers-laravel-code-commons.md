# mwebbers/laravel-code-commons

> 标签: commons, laravel, livewire, scope-driven, structure

## 简介

Shared Laravel/Livewire conventions: typed mixed-narrowing (Json), reusable stable sortable-table and pagination concerns, a lazy-table skeleton, and a SCOPE<->test coverage checker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
