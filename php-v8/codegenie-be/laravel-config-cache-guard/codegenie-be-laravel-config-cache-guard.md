# codegenie-be/laravel-config-cache-guard

> 标签: artisan, artisan-call, auto-repair, codegenie, config-cache, config-cache-guard, deployment, deployment-cache, env, exec-disabled, ftp-deployment, laravel, laravel-config, laravel-config-cache, laravel-route-cache, php, route-cache, shared-hosting, stale-cache, stale-config, stale-routes

## 简介

Prevent Laravel from using stale config or route cache after deployment changes, with Composer autoload integration and in-app auto repair for shared hosting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
