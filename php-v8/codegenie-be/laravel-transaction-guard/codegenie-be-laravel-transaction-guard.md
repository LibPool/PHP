# codegenie-be/laravel-transaction-guard

> 标签: after-commit, ci, codegenie, database, developer-tools, laravel, queue, static-analysis, transactions

## 简介

Static analysis for unsafe jobs, events, mail, notifications and irreversible side effects inside Laravel database transactions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
