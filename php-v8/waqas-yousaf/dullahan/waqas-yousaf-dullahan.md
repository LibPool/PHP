# waqas-yousaf/dullahan

> 标签: PHP

## 简介

Dullahan is a lightweight, high-performance, and feature-rich Laravel Headless CMS & Editorial Blog Package. It provides a fully session-isolated admin panel, a rich text editor, built-in SEO optimizations, dynamic sitemaps, ready-made Blade components, and a secure headless JSON API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
