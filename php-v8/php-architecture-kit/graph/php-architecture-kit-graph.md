# php-architecture-kit/graph

> 标签: data-structure, ddd, framework-agnostic, graph

## 简介

Graph data structure implementation to use as base for any (including Domain) Graphs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
