# ppag/contao-autoupdate-bundle

> 标签: Audit, composer, contao, security, update

## 简介

Daily security and patch-level updates for Contao 5.3/5.7 installations, with backup, health check and rollback.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
