# biskyt/yii-debug-toolbar

> 标签: debug, extension, yii

## 简介

Debug panel for Yii 1.1 (Ported from Yii 2), updated for PHP 8.1+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
