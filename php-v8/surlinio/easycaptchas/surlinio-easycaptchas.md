# surlinio/easycaptchas

> 标签: Forms, captcha, php, privacy, spam

## 简介

A lightweight, self-hosted and privacy-friendly CAPTCHA solution for PHP forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
