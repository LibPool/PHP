# shopxo/shopxo

> 标签: B2C, mall, orm, shop, shopxo, thinkphp, 商城, 小程序, 开源商城

## 简介

ShopXO domestic leading enterprise-class B2C free open source e-commerce system!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
