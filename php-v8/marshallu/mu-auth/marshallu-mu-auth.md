# marshallu/mu-auth

> 标签: plugin, wordpress

## 简介

MU Auth is a WordPress plugin that provides a simple way to authenticate users against the Marshall University SSO.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
