# marshallu/herd-editor

> 标签: acf, blocks, editor, plugin, wordpress

## 简介

A third editing mode for WordPress, alongside Classic and the Block Editor, for sites whose pages are built from ACF blocks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
