# rradutzu/zend2-doctrine-dynamic-db

> 标签: PHP

## 简介

Laminas Doctrine Module that allows defining connections using dynamic database names

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
