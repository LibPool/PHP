# jonathanraftery/bullhorn-rest-client

> 标签: api, bullhorn, client, rest

## 简介

Simple REST client for the Bullhorn API, including automated OAuth2 login

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
