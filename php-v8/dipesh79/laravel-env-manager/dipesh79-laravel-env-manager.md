# dipesh79/laravel-env-manager

> 标签: PHP

## 简介

Manage Laravel environment variables with ease using Artisan commands and a basic web interface for visual management.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
