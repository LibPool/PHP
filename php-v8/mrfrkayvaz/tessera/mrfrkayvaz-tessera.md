# mrfrkayvaz/tessera

> 标签: 2fa, Authentication, laravel, multi-factor, one-time-password, otp, password

## 简介

A Laravel package that designed to generate, manage and validate secure one-time passwords (OTP) for enhanced user authentication and multi-factor security workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
