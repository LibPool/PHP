# mrfrkayvaz/privata

> 标签: laravel, personal-data, privacy

## 简介

A Laravel package that provides tools for masking, anonymizing, and managing personal data to help with privacy compliance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
