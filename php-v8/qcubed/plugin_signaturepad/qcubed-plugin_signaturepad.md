# qcubed/plugin_signaturepad

> 标签: digital signature, qcubed, signature

## 简介

QCubed wrapper for the HTML5 canvas based smooth signature drawing http://szimek.github.io/signature_pad/.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
