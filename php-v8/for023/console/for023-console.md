# for023/console

> 标签: console, development, drupal, symfony

## 简介

The Drupal CLI. A tool to generate boilerplate code, interact with and debug Drupal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
