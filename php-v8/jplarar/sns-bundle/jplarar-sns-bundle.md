# jplarar/sns-bundle

> 标签: SNS, aws-sdk, jplarar

## 简介

A simple Symfony2 bundle for the API for AWS SNS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
