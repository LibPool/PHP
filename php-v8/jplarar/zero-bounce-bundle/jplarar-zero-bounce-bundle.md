# jplarar/zero-bounce-bundle

> 标签: jplarar, symfony, zero bounce

## 简介

A simple Symfony 3 bundle for the API for ZeroBounce.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
