# jplarar/s3-bundle

> 标签: aws-sdk, jplarar, s3

## 简介

A simple Symfony2 bundle for the API for AWS S3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
