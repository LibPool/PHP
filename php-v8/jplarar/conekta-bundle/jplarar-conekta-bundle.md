# jplarar/conekta-bundle

> 标签: conekta, jplarar, symfony

## 简介

A simple Symfony 3 bundle for the API for Conekta.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
