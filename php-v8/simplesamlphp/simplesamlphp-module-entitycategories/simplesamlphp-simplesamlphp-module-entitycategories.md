# simplesamlphp/simplesamlphp-module-entitycategories

> 标签: RnS, SAML2, coco, code of conduct, entity categories, refeds, research and scholarship, saml, simplesamlphp

## 简介

A SimpleSAMLphp module to define attribute release policies based on entity categories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
