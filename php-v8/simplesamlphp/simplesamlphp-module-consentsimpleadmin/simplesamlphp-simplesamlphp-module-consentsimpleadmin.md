# simplesamlphp/simplesamlphp-module-consentsimpleadmin

> 标签: PHP

## 简介

A SimpleSAMLphp module implementing a very simple user interface for managing consent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
