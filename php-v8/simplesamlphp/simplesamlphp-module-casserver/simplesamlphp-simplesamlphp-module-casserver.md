# simplesamlphp/simplesamlphp-module-casserver

> 标签: cas, cas 1.0, cas 2.0, server

## 简介

CAS 1.0 and 2.0 compliant CAS server module for simpleSAMLphp

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
