# simplesamlphp/simplesamlphp

> 标签: SAML, SAML2, idp, oauth, shibboleth, sp, ws-federation, 认证

## 简介

A PHP implementation of a SAML 2.0 service provider and identity provider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
