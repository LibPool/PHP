# simplesamlphp/simplesamlphp-module-memcachemonitor

> 标签: memcachemonitor, simplesamlphp

## 简介

A module that is able display usage statistics of a memcache(d) store

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
