# simplesamlphp/composer-xmlprovider-installer

> 标签: PHP

## 简介

A composer plugin that will auto-generate a classmap with all classes that implement SerializableElementInterface.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
