# simplesamlphp/simplesamlphp-module-logpeek

> 标签: modules, simplesamlphp

## 简介

A SimpleSAMLphp module to provide a web API to access the log files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
