# simplesamlphp/simplesamlphp-module-oidc

> 标签: OpenID Connect, OpenId, connect, oauth2, oidc

## 简介

A SimpleSAMLphp module adding support for the OpenID Connect protocol

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
