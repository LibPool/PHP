# simplesamlphp/simplesamlphp-module-yubikey

> 标签: otp, simplesamlphp, yubikey

## 简介

A SimpleSAMLphp module that adds support for YubiKey devices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
