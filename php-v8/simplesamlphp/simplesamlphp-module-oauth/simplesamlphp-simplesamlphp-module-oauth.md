# simplesamlphp/simplesamlphp-module-oauth

> 标签: oauth1, simplesamlphp

## 简介

A SimpleSAMLphp module that allows integration with OAuth1,

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
