# busybee/urljoin

> 标签: http, rel2abs, relative2absolute, url-concatenation, urljoin, urllib

## 简介

Library to correctly join relative and absolute URLs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
