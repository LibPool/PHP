# jield-webdev/jield-authorize

> 标签: PHP

## 简介

Small helper module to integrate BjyAuthorize (the kokspflanze/bjy-authorize fork) with dynamic assertions, which cannot be serialized

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
