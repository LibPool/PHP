# ihexiang/requests

> 标签: PHP Requests, delete, get, head, options, patch, post, put

## 简介

PHP Requests 支持 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS 等请求

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
