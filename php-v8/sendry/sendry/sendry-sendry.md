# sendry/sendry

> 标签: email, email-api, laravel, sdk, sendry, transactional-email

## 简介

Official PHP SDK for the Sendry email API, with first-class Laravel support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
