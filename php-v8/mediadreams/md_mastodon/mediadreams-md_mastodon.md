# mediadreams/md_mastodon

> 标签: TYPO3 CMS, extension, mastodon, mastodon api, social, social network, typo3

## 简介

Show data from Mastodon social network via API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
