# kostasch/greeklish

> 标签: greek, greeklish, kostasch, laravel, slug, transliteration

## 简介

Convert Greek text to greeklish (latin) and generate URL friendly slugs for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
