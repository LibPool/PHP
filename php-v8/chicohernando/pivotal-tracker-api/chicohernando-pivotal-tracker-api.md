# chicohernando/pivotal-tracker-api

> 标签: api, pivotaltracker, v5

## 简介

Library that provides a PHP interface to interact with the PivotalTracker API V5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
