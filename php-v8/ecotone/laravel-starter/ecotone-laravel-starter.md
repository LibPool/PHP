# ecotone/laravel-starter

> 标签: EventSourcing, ecotone, lite, starter

## 简介

Provides quickstart to build Ecotone Lite Application with Event Sourcing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
