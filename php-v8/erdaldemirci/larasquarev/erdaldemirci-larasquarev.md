# erdaldemirci/larasquarev

> 标签: api, client, foursquare, laravel

## 简介

Simple and extensible Foursquare API PHP Client with Laravel Support based on Guzzle 6

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
