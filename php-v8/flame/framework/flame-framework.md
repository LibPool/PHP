# flame/framework

> 标签: Simple, flame, framework, jsifalda, nette, tools

## 简介

Flame is simple and smart FRAMEWORK based on Nette

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
