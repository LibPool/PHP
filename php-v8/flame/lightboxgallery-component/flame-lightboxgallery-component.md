# flame/lightboxgallery-component

> 标签: component, flame, gallery, lightbox, nette

## 简介

Simple gallery component based on LightBox2 for Nette

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
