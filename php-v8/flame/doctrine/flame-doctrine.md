# flame/doctrine

> 标签: doctrine, doctrine2, flame, framework, nette, tools

## 简介

Collection of classes for working with Doctrine2 on Kdyby/Doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
