# catshredengera/laravel-agent

> 标签: Agent, Mobile-Detect, browser, crawler, desktop, jenssegers, laravel, mobile, platform, user agent, useragent

## 简介

Drop-in replacement for the unmaintained jenssegers/agent — same Agent API, on modern Mobile-Detect (v4 and v2)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
