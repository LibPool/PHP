# salesoftech/amocrm-api-php-salesoftech

> 标签: PHP

## 简介

Multi-tenant wrapper for amocrm/amocrm-api-php with pluggable storages (SQL, file, NoSQL)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
