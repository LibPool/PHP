# savinmikhail/enforce-aaa-pattern-rector

> 标签: dev, static analysis

## 简介

Rector rule to enforce the presence of 'arrange', 'act', 'assert' structure of phpunit tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
