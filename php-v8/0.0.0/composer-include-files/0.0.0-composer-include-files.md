# 0.0.0/composer-include-files

> 标签: autoload, composer

## 简介

Include files at a higher priority than autoload files. Useful for overriding Laravel helpers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
