# risetechapps/media-for-laravel

> 标签: conversions, laravel, media, risetechapps, storage, uploads

## 简介

Laravel package for advanced media and upload management, with exact storage accounting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
