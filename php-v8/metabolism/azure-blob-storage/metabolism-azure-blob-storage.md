# metabolism/azure-blob-storage

> 标签: plugin, wordpress

## 简介

Sync WordPress media, including Timber-generated images, with Azure Blob Storage for optimized storage and performance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
