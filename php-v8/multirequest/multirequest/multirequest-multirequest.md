# multirequest/multirequest

> 标签: curl, multirequest, multithread, php, request

## 简介

PHP library for easy and flexible multithread requests handling by CURL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
