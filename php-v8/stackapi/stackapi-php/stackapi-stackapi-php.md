# stackapi/stackapi-php

> 标签: Nigeria, api, bvn, fintech, kyc, logistics, nin, payments, payouts, sms, stackapi, virtual cards

## 简介

Official PHP SDK for StackApi: payments, payouts, messaging, identity, bills, virtual cards, logistics and more behind one key.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
