# suzumaze/bear-sunday-mcp-server

> 标签: LSP, bear-sunday, language-server, mcp, phpactor

## 简介

Read-only MCP adapter for BEAR.Sunday semantics exposed by Phpactor LSP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
