# peterbenke/pb-tt-address-googlemaps

> 标签: extension, frontend, google, maps, typo3

## 简介

Extends the extension tt_address with frontend view in Google maps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
