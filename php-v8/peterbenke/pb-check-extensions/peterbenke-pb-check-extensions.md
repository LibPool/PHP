# peterbenke/pb-check-extensions

> 标签: backend, extension, scheduler, typo3

## 简介

Checks, if there are updates available for installed extensions and sends an email

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
