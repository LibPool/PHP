# peterbenke/pb-rel-nofollow

> 标签: extension, frontend, links, nofollow, typo3

## 简介

Adds a rel-nofollow-attribute to extern links. You can exclude URLs by typoscript.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
