# mouseketeers/silverstripe-consent-userforms

> 标签: consent, gdpr, silverstripe, userforms

## 简介

SilverStripe UserForms integration for silverstripe-consent-forms: CMS-editable consent fields and automatic consent recording

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
