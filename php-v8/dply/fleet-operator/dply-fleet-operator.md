# dply/fleet-operator

> 标签: fleet, http, middleware, monitoring, openapi, operator, php

## 简介

PHP middleware, config, and OpenAPI spec for Fleet Console operator APIs (GET …/summary and …/readme).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
