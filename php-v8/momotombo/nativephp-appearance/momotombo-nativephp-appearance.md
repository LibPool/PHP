# momotombo/nativephp-appearance

> 标签: appearance, dark-mode, light-mode, nativephp, nativephp-mobile, theme

## 简介

Application-local light, dark, and system appearance preference for NativePHP Mobile.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
