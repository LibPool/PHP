# tabacitu/ball-starter-kit

> 标签: ball-stack, bootstrap, framework, laravel, livewire, starter-kit

## 简介

A Laravel starter kit using the BALL stack - Bootstrap, Any-JS, Laravel, Livewire.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
