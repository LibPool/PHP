# iyottt/laravel-filemanager

> 标签: CKEditor, file, filemanager, image, laravel, manager, tinymce, upload

## 简介

Fork: from unisharp/laravel-filemanager, A file upload/editor intended for use with Laravel 5 to 10 and CKEditor / TinyMCE

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
