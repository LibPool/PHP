# finlight/client

> 标签: API-Client, entity-extraction, financial-news, finlight, fintech, market-data, news-api, sentiment-analysis, stock-news, webhooks

## 简介

PHP client for the finlight.me financial news API - search sentiment-scored, entity-tagged market news and verify finlight webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
