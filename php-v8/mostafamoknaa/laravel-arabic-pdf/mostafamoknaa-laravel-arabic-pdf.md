# mostafamoknaa/laravel-arabic-pdf

> 标签: Glyphs, arabic, arabic-pdf, bidi, dompdf, farsi, laravel, pdf, persian, rtl, shaping

## 简介

Generate PDFs with correct Arabic text in Laravel: connected letters (glyph shaping), right-to-left word order (bidi) and RTL tables, built on dompdf.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
