# darflen/framework

> 标签: darflen, framework

## 简介

Framework used for the Darflen social media project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://darflen.com
- 源码仓库：https://github.com/darflen/framework.git
- Packagist 页面：https://packagist.org/packages/darflen%2Fframework
