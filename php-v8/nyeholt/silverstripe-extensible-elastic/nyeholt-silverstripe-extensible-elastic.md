# nyeholt/silverstripe-extensible-elastic

> 标签: elastic search, full-text, search, silverstripe

## 简介

An elastic search adapter for extensible search

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
