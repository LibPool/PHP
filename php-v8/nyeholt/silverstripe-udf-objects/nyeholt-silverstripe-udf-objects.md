# nyeholt/silverstripe-udf-objects

> 标签: silverstripe, symbiote, userforms

## 简介

Map Silverstripe UDF submissions to specific data objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
