# productowner-ro/symfony-profiler-mcp

> 标签: PHP

## 简介

Symfony bundle that exposes profiler data via MCP protocol to AI-powered IDEs. Built on symfony/mcp-bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
