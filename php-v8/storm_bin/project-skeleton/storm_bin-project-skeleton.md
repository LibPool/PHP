# storm_bin/project-skeleton

> 标签: api, framework, illuminate, laravel, mvc, storm

## 简介

Storm Framework - Un framework PHP modulaire et léger, construit avec les composants Illuminate (Laravel). Fournit une structure MVC flexible pour les applications web et API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
