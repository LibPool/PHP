# valiton/datatrans-bundle

> 标签: datatrans, payment

## 简介

Symfony3 bundle for providing access to Datatrans payment. This is an extension to the JMSCorePaymentBundle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
