# taras-koval/laravel-starter

> 标签: laravel, publish, scaffolding, starter

## 简介

Publishes and updates Laravel starter files (controllers, models, config, etc.) into existing projects through a single Artisan command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
