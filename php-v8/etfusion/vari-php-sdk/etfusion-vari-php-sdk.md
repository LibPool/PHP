# etfusion/vari-php-sdk

> 标签: api, etfusion, mtls, sdk, v-ari, vari

## 简介

PHP SDK for the V-ARI Stable API (mutual TLS): identity, certificate rotation, stream metrics and custom lists.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
