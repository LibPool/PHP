# franjsco/crypto-fear-greed-index

> 标签: api, bitcoin, client, cryptocurrency

## 简介

A PHP package to fetch Bitcoin Crypto Fear and Greed Index data from alternative.me

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
