# pensoft/oc-meta-plugin

> 标签: cms, html, link, meta, october, plugin

## 简介

Provides an easy interface to insert HTML meta and link tags into an October CMS layout or page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
