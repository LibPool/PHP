# relaypdf/relaypdf

> 标签: LibreOffice, Markdown-to-PDF, documents, html-to-pdf, pdf, relaypdf, url-to-pdf

## 简介

Official PHP SDK for RelayPDF — HTML, Markdown, URL, and templates to PDF, LibreOffice convert, PDF tools, barcodes, zip, async jobs, and webhook verification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
