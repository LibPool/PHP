# rapidwebltd/search

> 标签: PHP

## 简介

Search allows you to easily add an intelligent search engine to your website or web application. It can be configured to search any database table.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
