# laraxgram/tempora

> 标签: Tempora, bot, carbon, date, datetime, laragram, laraquest, telegram, time

## 简介

Advanced interface for working with date and time, based on Carbon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
