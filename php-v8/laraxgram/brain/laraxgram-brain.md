# laraxgram/brain

> 标签: ai, dev, laragram

## 简介

LaraGram Brain accelerates AI-assisted development by providing the essential context and structure that AI needs to generate high-quality, LaraGram-specific code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
