# laraxgram/sentinel

> 标签: laragram, sentinel

## 简介

Watch over your LaraGram bot: updates, webhooks, Telegram API calls, exceptions and performance in one dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
