# laraxgram/mongodb

> 标签: database, eloquent, laragram, laravel, model, mongo, mongodb

## 简介

A MongoDB based Eloquent model and Query builder for LaraGram.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
