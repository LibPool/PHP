# laraxgram/citadel

> 标签: auth, citadel, laragram, oauth, telegram, tokens

## 简介

API authentication for LaraGram: personal access tokens, SPA sessions and a full OAuth2 server with Telegram sign-in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
