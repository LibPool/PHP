# develupers/laravel-cache-compress

> 标签: cache, compression, develupers, laravel

## 简介

Add compression support to your Laravel cache. (MongoDB, Redis, Memcached and MySQL supported)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
