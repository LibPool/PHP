# develupers/laravel-cdn-headers

> 标签: develupers, laravel, laravel-cdn-headers

## 简介

Set proper cache-control headers for Cloudflare CDN to cache pages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
