# satishsinghdevbha/amazon-mws-laravel

> 标签: amazon, api, laravel, mws, php

## 简介

A Laravel library for Amazon's MWS web services, supporting Laravel 5-7+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
