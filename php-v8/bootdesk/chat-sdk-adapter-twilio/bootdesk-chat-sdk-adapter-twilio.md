# bootdesk/chat-sdk-adapter-twilio

> 标签: PHP

## 简介

Twilio adapter for bootdesk/chat-sdk-core — SMS and MMS via Twilio Messaging API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
