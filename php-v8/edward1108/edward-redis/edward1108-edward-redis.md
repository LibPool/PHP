# edward1108/edward-redis

> 标签: edward-redis, edward1108, redis, thinkphp

## 简介

ThinkPHP框架的Redis扩展，支持多种Redis使用方法。支持ThinkPHP6.0和ThinkPHP5.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
