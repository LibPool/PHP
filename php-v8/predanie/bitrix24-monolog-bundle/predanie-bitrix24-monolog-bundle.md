# predanie/bitrix24-monolog-bundle

> 标签: Bitrix24, webhook

## 简介

Allows you send errors to a bitrix24 chat using a webhook integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
