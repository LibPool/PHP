# fennectra/framework

> 标签: api, framework, frankenphp, jwt, mvc, orm, php

## 简介

Fennectra — PHP 8.3+ high-performance MVC API framework with built-in compliance (SOC 2, ISO 27001, NF525, GDPR)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
