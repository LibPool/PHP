# bandar/bandar

> 标签: engine, template, template engine

## 简介

Fully tested, super minimalistic PHP template engine for PHP 5.2, 5.3, 5.4, 5.5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
