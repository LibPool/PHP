# world-from-space/dynacrop

> 标签: PHP

## 简介

SDK for accessing DynaCrop service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://bitbucket.org/world_from_space/dynacrop-sdk-php

- Packagist 页面：https://packagist.org/packages/world-from-space%2Fdynacrop
