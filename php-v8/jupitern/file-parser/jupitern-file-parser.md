# jupitern/file-parser

> 标签: File parser, csv, dsv, tsv, variable-length-delimited

## 简介

read, filter, parse and format {csv, tsv, dsv, variable-length-delimited} and other txt files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
