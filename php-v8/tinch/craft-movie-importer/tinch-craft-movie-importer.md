# tinch/craft-movie-importer

> 标签: Craft, cms, craft-plugin, craftcms, import, movies, tmdb

## 简介

Import movies from TMDB into Craft entries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
