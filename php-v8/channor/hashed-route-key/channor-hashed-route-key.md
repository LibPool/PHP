# channor/hashed-route-key

> 标签: hashids, laravel, obfuscation, opaque-route-key, route-key

## 简介

Deterministic opaque route keys for integer IDs with keyed integrity checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
