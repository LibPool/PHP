# ypho/scryfall

> 标签: Api Wrapper, magic, magic the gathering, scryfall, scryfall.com

## 简介

A wrapper around the API from Scryfall (scryfall.com)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
