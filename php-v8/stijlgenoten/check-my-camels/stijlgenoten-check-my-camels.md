# stijlgenoten/check-my-camels

> 标签: camelcase, check, classname, laravel, tool

## 简介

Case sensitive classname checker for Laravel apps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
