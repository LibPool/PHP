# kirimi/kirimi-php

> 标签: API-Client, automation, communication, kirimi, messaging, notification, otp, otp-verification, php, sms, whatsapp, whatsapp-api, whatsapp-bot, whatsapp-client

## 简介

Official PHP client library for the Kirimi WhatsApp API. Send messages, handle OTP verification, and manage WhatsApp communication with ease.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
