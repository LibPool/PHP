# squirrelphp/twig-php-syntax

> 标签: foreach, php, syntax, twig

## 简介

Adds common PHP syntax to twig templates, like ===, foreach and continue/break.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
