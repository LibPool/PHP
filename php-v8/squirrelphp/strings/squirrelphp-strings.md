# squirrelphp/strings

> 标签: filters, php, random, strings, urls

## 简介

Common string operations in PHP: filter a string, generate a random string, condense an integer into a string, and modify URLs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
