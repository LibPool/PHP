# flatrate/wiki-supabase-oauth

> 标签: SSO, flarum, nicknames, oauth, oauth2, pkce, supabase

## 简介

FlatRate Wiki Supabase OAuth 2.1 SSO provider and public-auth gate for Flarum 1.8.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
