# flatrate/flarum-live-chat

> 标签: Xelson, chat, flarum, flatrate, live-chat, neon-chat, push-edx

## 简介

FlatRate.wiki-owned hardened realtime live chat for Flarum (derived from Neon Chat / Xelson).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
