# flatrate/flarum-composer-ui

> 标签: composer, flarum, flatrate, mobile

## 简介

Mobile presentation shell for the FlatRate.wiki Flarum 1.8 discussion and reply composer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
