# screenshotscout/sdk

> 标签: screenshot, screenshot-api, screenshotscout, sdk, url-to-image, webpage-screenshot, website-screenshot

## 简介

Official PHP SDK for the Screenshot Scout screenshot API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- Packagist 页面：https://packagist.org/packages/screenshotscout%2Fsdk
