# talleu/md-to-ooxml

> 标签: OOXML, converter, docx, markdown, word, xml

## 简介

A lightweight PHP library to convert Markdown to Office Open XML (OOXML) and .docx files

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
