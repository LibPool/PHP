# kongoon/yii2-theme-ratchakarn

> 标签: extension, theme, yii2, ราชการ

## 简介

Ratchakarn theme for Yii Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
