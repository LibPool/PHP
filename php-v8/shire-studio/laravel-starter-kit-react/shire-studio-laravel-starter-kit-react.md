# shire-studio/laravel-starter-kit-react

> 标签: framework, laravel, react, shadcn

## 简介

An end-to-end type-safe Laravel 13 starter kit with auto-generated TypeScript types, React 19, and shadcn/ui components for fast front-end prototyping

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
