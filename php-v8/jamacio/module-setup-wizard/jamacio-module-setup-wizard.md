# jamacio/module-setup-wizard

> 标签: adobe-commerce, installer, magento, magento2, mysql-search, sample-data, setup-wizard, web-installer

## 简介

Web Setup Wizard for Magento 2.4: install Magento or bring a store up from an existing database in the browser, with no web server configuration. Includes a basic MySQL search engine to run without OpenSearch/Elasticsearch.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
