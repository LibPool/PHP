# instana/opentelemetry-php-exporter

> 标签: contrib, exporter, instana, opentelemetry, otel, tracing

## 简介

Instana exporter for OpenTelemetry PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
