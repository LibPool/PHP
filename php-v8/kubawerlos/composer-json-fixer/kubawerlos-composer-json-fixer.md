# kubawerlos/composer-json-fixer

> 标签: composer, fixer

## 简介

A tool for fixing and cleaning up `composer.json` file according to its schema and best practices.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
