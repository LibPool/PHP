# jl6m/swagger-lite

> 标签: Guzzle, api, client, http, openapi, rest, swagger

## 简介

Guzzle client that can execute operations defined in Swagger

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
