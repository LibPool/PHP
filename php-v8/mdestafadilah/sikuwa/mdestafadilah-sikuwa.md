# mdestafadilah/sikuwa

> 标签: apime, evolution-api, fonnte, gateway, openwa, sdk, waxum, whatsapp, whatsapp-api, wuzapi, wwebjs

## 简介

SDK PHP dengan satu antarmuka untuk banyak gateway WhatsApp unofficial: Fonnte, OpenWA, ApiMe, Evolution API, Wuzapi, Wwebjs, dan Waxum.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
