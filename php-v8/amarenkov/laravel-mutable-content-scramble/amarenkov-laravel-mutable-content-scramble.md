# amarenkov/laravel-mutable-content-scramble

> 标签: api-documentation, custom-fields, dynamic-fields, laravel, openapi, scramble, stoplight-elements

## 简介

Scramble OpenAPI extension for laravel-mutable-content: field labels in request docs, lists of values as enums, self-hosted Stoplight Elements.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
