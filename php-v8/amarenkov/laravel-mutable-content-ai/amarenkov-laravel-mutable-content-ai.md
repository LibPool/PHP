# amarenkov/laravel-mutable-content-ai

> 标签: agents, ai, dynamic-fields, eloquent, laravel, llm, memory, tool-calling

## 简介

AI agents for laravel-mutable-content apps: long-term memory and a run journal with conversation history for laravel/ai agents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
