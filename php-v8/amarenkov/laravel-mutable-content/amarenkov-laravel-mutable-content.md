# amarenkov/laravel-mutable-content

> 标签: audit-log, change-log, custom-fields, database-triggers, dynamic-fields, eloquent, jsonb, laravel, lov, mariadb, postgresql

## 简介

Laravel models with user-defined fields: typed JSON fields added without migrations, lists of values, and a trigger-based change log on PostgreSQL and MariaDB.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
