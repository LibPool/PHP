# amarenkov/laravel-mutable-content-filament

> 标签: admin, custom-fields, dynamic-fields, eloquent, filament, filament-plugin, jsonb, laravel

## 简介

Filament 5 admin panel for laravel-mutable-content: forms and tables built from field definitions, screens to manage fields and lists of values, change log authorship.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
