# zecreeps/module-bridge-magento-pimcore-integration

> 标签: PHP

## 简介

Magento-Pimcore bridge module for magento 2.4.x.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
