# lab123/lumen-notification

> 标签: laravel, laravel-notification, lumen, lumen-notification, notification, wrapper

## 简介

Laravel Notifications wiring for Illuminate-based apps (ex-Lumen): service provider, mail/services config and artisan commands

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
