# yuan1994/wechat_web_devtools

> 标签: wechat, wechat_web_devtools, 小程序, 微信网页开发

## 简介

微信开发者工具（wechat_web_devtools）Linux版，支持微信小程序开发和微信网页开发

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
