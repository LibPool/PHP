# butschster/proto-parser

> 标签: ast, gRPC, parser, php, php8, proto, protobuf, protocol-buffers

## 简介

Proto parser is a library for parsing Protocol Buffers files into AST

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
