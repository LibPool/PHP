# kayschima/tischtennis-live-php

> 标签: kayschima, tischtennis-live-php

## 简介

Dies ist ein ein PHP-Wrapper für die Tischtennis Live API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
