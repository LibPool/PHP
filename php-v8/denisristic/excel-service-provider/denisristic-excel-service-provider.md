# denisristic/excel-service-provider

> 标签: PHPExcel, excel, php, silex, symfony, xls

## 简介

A wrapper for PHPExcel usage in Silex 2 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
