# fluxfiles/fluxfiles

> 标签: Flysystem, file-manager, jwt, media, r2, s3, storage, upload

## 简介

Standalone PHP file manager with multi-storage support (Local/S3/R2)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
