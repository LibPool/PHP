# ajohnson6494/shippo-php

> 标签: FedEx, Uber, address, dhl, shipping, shyp, tracking, ups, usps

## 简介

A PHP library for connecting with multiple carriers (FedEx, UPS, USPS) using Shippo.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
