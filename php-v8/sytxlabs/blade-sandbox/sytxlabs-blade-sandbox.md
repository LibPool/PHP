# sytxlabs/blade-sandbox

> 标签: blade, dto, laravel, livewire, sandbox, security, templates

## 简介

A default-deny security sandbox for rendering untrusted Laravel Blade templates, views, components, DTOs and Livewire views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
