# sytxlabs/laravel-webmcp

> 标签: W3C, WebMCP, agents, ai, ai-agents, alpinejs, browser, chrome, laravel, livewire, mcp, model-context-protocol

## 简介

Expose laravel/mcp tools and resources as WebMCP tools (document.modelContext) in the browser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
