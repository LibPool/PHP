# zjpay/laravel-cpcn

> 标签: cpcn, laravel, payment, yqf

## 简介

Laravel package for CPCN (中金支付 壹企付) message gateway APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
