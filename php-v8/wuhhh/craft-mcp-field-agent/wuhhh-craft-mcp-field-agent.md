# wuhhh/craft-mcp-field-agent

> 标签: Craft, ai, cms, content-modelling, craft-plugin, craftcms, fields, mcp, model-context-protocol

## 简介

Content modelling tools for Craft MCP. Create, modify and delete fields, entry types and sections from an AI assistant, with the destructive paths gated behind plans a model cannot forge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
