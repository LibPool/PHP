# jsvrcek/ics

> 标签: .ics, RFC 5545, calendar, export, ical, multi-byte safe

## 简介

abstraction layer for creating multi-byte safe RFC 5545 compliant .ics files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
