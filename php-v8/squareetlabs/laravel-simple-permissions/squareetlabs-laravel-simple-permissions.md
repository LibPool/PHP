# squareetlabs/laravel-simple-permissions

> 标签: abilities, access-control, access-control-list, acl, audit-logging, authorization, blade-directives, caching, entity-permissions, groups, laravel, middleware, permission-management, permissions, policies, rbac, role-based-access-control, user-management

## 简介

A comprehensive Laravel package for advanced permission management. Features RBAC, granular permissions, entity-specific abilities, global groups, audit logging, and seamless Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
