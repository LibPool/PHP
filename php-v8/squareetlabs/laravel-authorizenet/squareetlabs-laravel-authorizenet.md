# squareetlabs/laravel-authorizenet

> 标签: authorizenet, gateway, laravel, payment, payment-processing

## 简介

This package allows laravel application to use authorizenet api easily.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
