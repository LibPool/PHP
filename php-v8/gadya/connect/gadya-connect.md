# gadya/connect

> 标签: filament, gadya, laravel, monitoring, support

## 简介

Connects a Laravel site to the Gadya Media portal: signed check-ins with versions and health, help from inside the admin, and one-click sign-in for the Gadya team.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
