# munshiprodip/bulksmsbd-laravel

> 标签: bangladesh-sms, bulksmsbd, laravel, otp, package, sms, sms-gateway

## 简介

Clean, modern, PSR-12 compliant Laravel wrapper package for the BulkSMSBD SMS Gateway API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
