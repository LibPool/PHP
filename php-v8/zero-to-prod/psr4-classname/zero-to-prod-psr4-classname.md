# zero-to-prod/psr4-classname

> 标签: psr4 classname, psr4-classname, zero-to-prod

## 简介

Generates a valid PSR-4 Compliant Classname from a string.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
