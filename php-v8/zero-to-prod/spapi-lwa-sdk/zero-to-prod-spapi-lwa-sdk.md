# zero-to-prod/spapi-lwa-sdk

> 标签: spapi-lwa-sdk, zero-to-prod

## 简介

A Software Development Kit for connecting to Amazons Selling Partner API with Login With Amazon (LWA).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
