# zero-to-prod/spapi-tokens-cli

> 标签: spapi-tokens-cli, zero-to-prod

## 简介

A CLI for getting a Restricted Data Token (RDT) for Amazon Selling Partner API (SPAPI).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
