# zero-to-prod/spapi-lwa

> 标签: spapi-lwa, zero-to-prod

## 简介

Connect to Amazons Selling Partner API with Login With Amazon (LWA).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
