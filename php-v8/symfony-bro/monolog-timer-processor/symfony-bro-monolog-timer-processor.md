# symfony-bro/monolog-timer-processor

> 标签: log, logger, monolog, processor, timer

## 简介

A processor for Monolog that adds timing info to the message contexts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
