# analytics-platform/platform

> 标签: analytics, error-monitoring, firewall, laravel, rate-limit, security, server-monitoring, waf

## 简介

Firewall, error monitoring and server analytics for your PHP or Laravel site, run from your analytics dashboard.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
