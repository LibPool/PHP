# sllhsmile/hyperf-log

> 标签: Guzzle, database, hyperf, logging, redis, trace

## 简介

Structured API, Redis, database and Guzzle logging for Hyperf.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
