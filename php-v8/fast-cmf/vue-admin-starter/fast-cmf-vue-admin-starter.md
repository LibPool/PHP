# fast-cmf/vue-admin-starter

> 标签: framework, laravel

## 简介

Laravel 13 + Vue 3 后台管理启动模板：RBAC 权限、菜单管理、媒体中心、操作日志开箱即用。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
