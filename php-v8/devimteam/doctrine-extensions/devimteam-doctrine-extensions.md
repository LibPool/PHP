# devimteam/doctrine-extensions

> 标签: database, doctrine, dql, function, mysql, postgresql, type

## 简介

Doctrine Extensions for MySQL and PostgreSQL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
