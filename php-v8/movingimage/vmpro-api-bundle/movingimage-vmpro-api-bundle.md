# movingimage/vmpro-api-bundle

> 标签: PHP

## 简介

Official Symfony bundle for interacting with the MovingIMAGE Video Manager Pro public API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
