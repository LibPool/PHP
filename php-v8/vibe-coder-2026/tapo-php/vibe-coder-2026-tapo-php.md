# vibe-coder-2026/tapo-php

> 标签: PHP

## 简介

PHP library for TP-Link Tapo smart plugs/bulbs (P100, P105, P110, L530). Based on https://github.com/almottier/TapoP100/commit/04c452fd8af9d8505e4177ba3df157372ce3ee0c

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
