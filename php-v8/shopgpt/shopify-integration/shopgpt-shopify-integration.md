# shopgpt/shopify-integration

> 标签: laravel, multi-tenant, oauth, shopify

## 简介

Multi-tenant Shopify authentication for Laravel — OAuth, expiring offline tokens, automatic refresh.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
