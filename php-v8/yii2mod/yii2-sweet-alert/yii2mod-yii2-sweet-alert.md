# yii2mod/yii2-sweet-alert

> 标签: yii2, yii2 alert, yii2 sweet alert

## 简介

Alert widget based on SweetAlert extension {@link http://tristanedwards.me/sweetalert)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
