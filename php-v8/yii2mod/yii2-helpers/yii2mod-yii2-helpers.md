# yii2mod/yii2-helpers

> 标签: yii2, yii2 array helpers, yii2 helpers

## 简介

Collection of useful helper functions for Yii Framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
