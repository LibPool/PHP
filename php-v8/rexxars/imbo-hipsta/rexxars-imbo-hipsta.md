# rexxars/imbo-hipsta

> 标签: hipstamatic, hipster, image transformation, instagram, transformations

## 简介

Imbo transformations for generating Instagram / Hipstamatic-like images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
