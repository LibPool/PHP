# creakiwi/yaml-fixtures

> 标签: Fixture, persistence

## 简介

Symfony YamlFixtures on top of DoctrineFixturesBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
