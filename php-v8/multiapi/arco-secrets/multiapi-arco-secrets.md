# multiapi/arco-secrets

> 标签: aws, lambda, parameter-store, secrets, secrets-manager, ssm

## 简介

arco-ssm: and arco-secret: references for AWS SSM Parameter Store and Secrets Manager

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
