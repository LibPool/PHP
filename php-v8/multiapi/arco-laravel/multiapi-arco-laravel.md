# multiapi/arco-laravel

> 标签: aws, frankenphp, lambda, lambda-web-functions, laravel, octane, serverless

## 简介

Laravel integration for Arco (Octane on AWS Lambda Web Functions)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
