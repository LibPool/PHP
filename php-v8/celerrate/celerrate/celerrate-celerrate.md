# celerrate/celerrate

> 标签: PHPStan, analyzer, php, static analysis

## 简介

Celerrate for Composer projects: installs the platform's celerrate binary and exposes vendor/bin/celerrate

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
