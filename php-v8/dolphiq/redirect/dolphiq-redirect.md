# dolphiq/redirect

> 标签: Craft, cms, craft-plugin, craftcms, redirect, seo

## 简介

Craft redirect plugin provides an easy way to enter and maintain 301 and 302 redirects and 404 error pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
