# tetthys/pie-minimal-batcher

> 标签: PHP

## 简介

Ultra-minimal, bank-agnostic sharded batcher with RabbitMQ 4.1 and per-identity cooldown.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
