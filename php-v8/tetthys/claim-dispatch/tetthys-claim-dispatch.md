# tetthys/claim-dispatch

> 标签: bus, claim, command, dispatch, job, laravel, pipeline

## 简介

Minimal contracts for claim→process→dispatch pipelines, with built-in Laravel adapter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
