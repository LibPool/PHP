# phpexperts/rest-speaker

> 标签: api, json, php, rest, restful

## 简介

A quick and easy GuzzleHTTP extension for effortlessly handling RESTful APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
