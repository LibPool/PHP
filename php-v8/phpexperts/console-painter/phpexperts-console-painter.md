# phpexperts/console-painter

> 标签: bash colors, bash formatting, console colors, terminal colors

## 简介

A quick and easy library for colorizing and stylizing ANSI consoles.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
