# newerton/yii2-boleto-remessa

> 标签: newerton, yii2, yii2-boleto-remessa

## 简介

Biblioteca com boletos e sistema de remessa e retorno para o Yii2 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
