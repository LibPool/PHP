# goodnesskay/laravel-slack

> 标签: Automatic Invite, laravel, packages, slack, slack api

## 简介

A Laravel Package that makes Invitation to Slack Channels seamless

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
