# boxybird/atomic

> 标签: fragments, htmx, php, plugin, router, wordpress

## 简介

Atomic integrates HTMX fragments into WordPress, enabling dynamic partial page updates without full reloads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
