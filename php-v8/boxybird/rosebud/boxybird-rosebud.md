# boxybird/rosebud

> 标签: cinema, data transfer objects, dto, movie, php, tmdb, tv, tv episode, tv show, wrapper

## 简介

A TMDB (The Movie Database) API wrapper. Includes Data Transfer Objects (DTO).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
