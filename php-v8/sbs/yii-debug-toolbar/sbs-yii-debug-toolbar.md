# sbs/yii-debug-toolbar

> 标签: debug, extension, yii

## 简介

Debug panel for Yii 1.1 (Ported from Yii 2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
