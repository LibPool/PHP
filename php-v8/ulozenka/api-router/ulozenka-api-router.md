# ulozenka/api-router

> 标签: api, nette, rest, restapi, restrouter, route, router, routes, routing

## 简介

RESTful Router for your Apis in Nette Framework - created either directly or via annotation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
