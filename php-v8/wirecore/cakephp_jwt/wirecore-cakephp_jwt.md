# wirecore/cakephp_jwt

> 标签: Authentication, authenticate, cakephp, jwt

## 简介

CakePHP plugin for authenticating users by JSON Web Tokens

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
