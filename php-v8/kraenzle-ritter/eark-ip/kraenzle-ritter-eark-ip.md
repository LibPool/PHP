# kraenzle-ritter/eark-ip

> 标签: aip, archives, csip, digital-preservation, dip, e-ark, information-package, mets, oais, premis, sip

## 简介

Read, validate and write E-ARK information packages (CSIP, SIP, AIP, DIP) in plain PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
