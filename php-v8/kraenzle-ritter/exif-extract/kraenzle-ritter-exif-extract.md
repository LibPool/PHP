# kraenzle-ritter/exif-extract

> 标签: IPTC, digital-preservation, exif, exiftool, metadata, technical-metadata, xmp

## 简介

Unified PHP interface for extracting technical metadata (EXIF, IPTC, XMP, …) from media files using ExifTool.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
