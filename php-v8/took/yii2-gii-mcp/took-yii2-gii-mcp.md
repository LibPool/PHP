# took/yii2-gii-mcp

> 标签: ai-tools, anthropic, claude, code-generation, gii, json-rpc, mcp, model-context-protocol, scaffolding, yii2

## 简介

Model Context Protocol (MCP) server for Yii2 Gii scaffolding - enables AI agents to generate models and CRUD interfaces

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
