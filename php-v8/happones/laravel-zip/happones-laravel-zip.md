# happones/laravel-zip

> 标签: backup, extract, laravel, laravel-zip, laravel10, laravel11, laravel8, laravel9, merge, multiple, unzip, zip, ziparchive

## 简介

laravel-zip is the world's leading zip utility for file compression and backup.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
