# happones/kinetix

> 标签: PHP

## 简介

The hybrid framework for Laravel + Vue 3 + Inertia.js — fluent PHP APIs that render a polished shadcn/Vue UI, spanning backend and frontend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
