# happones/laravel-evolution-client

> 标签: api, evolution, evolution-api, laravel, whatsapp

## 简介

Laravel Client for Evolution API, allowing easy integration with WhatsApp.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
