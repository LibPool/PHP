# solberlight/mailjet-bundle

> 标签: Mailjet, api, bundle, symfony, user, v3

## 简介

Symfony bundle for Mailjet API V3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
