# wesselstam/sepa-xml

> 标签: PHP

## 简介

SepaXML is a class that converts your direct debit information to PAIN.008.001.02 XML files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
