# fluxa/fluxa

> 标签: api, framework, json, micro-framework, php8, rest

## 简介

Ultra-minimalist, high-performance API micro-framework for PHP 8.3+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
