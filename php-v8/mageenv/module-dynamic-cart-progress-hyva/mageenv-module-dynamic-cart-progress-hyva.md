# mageenv/module-dynamic-cart-progress-hyva

> 标签: PHP

## 简介

Hyva storefront integration for MageEnv Dynamic Cart Progress - Alpine.js Mini Cart and Cart Page components consuming the shared progress payload. No business logic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
