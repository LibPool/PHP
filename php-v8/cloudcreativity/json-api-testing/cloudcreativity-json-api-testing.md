# cloudcreativity/json-api-testing

> 标签: JSON-API, api, cloudcreativity, json, jsonapi, jsonapi.org

## 简介

PHPUnit test helpers to check JSON API documents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
