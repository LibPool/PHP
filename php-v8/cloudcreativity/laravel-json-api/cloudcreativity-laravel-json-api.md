# cloudcreativity/laravel-json-api

> 标签: JSON-API, api, cloudcreativity, json, jsonapi, jsonapi.org, laravel

## 简介

JSON API (jsonapi.org) support for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
