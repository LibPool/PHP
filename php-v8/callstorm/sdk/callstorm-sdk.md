# callstorm/sdk

> 标签: api, campaigns, sdk, voice, voxcore, webhooks

## 简介

Official PHP SDK for the Callstorm external API (outbound voice campaigns).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://callstorm.ai
- 源码仓库：https://github.com/dvalenci/callstorm-sdk-php.git
- Packagist 页面：https://packagist.org/packages/callstorm%2Fsdk

## 历史版本号

- 当前版本：v0.3.0

## 获取地址

- Composer 安装：`composer require callstorm/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/callstorm/sdk.json
