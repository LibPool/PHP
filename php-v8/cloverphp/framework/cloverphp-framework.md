# cloverphp/framework

> 标签: clover, cloverphp, framework, rest, router

## 简介

Clover: Clover PHP is a modern, unopinionated, and lightweight Express.js-style framework for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
