# inpsyde/translation-cache

> 标签: cache, caching, i18n, internationalization, l10n, language, languages, localization, mo file, performance, translate, translation, translations, wordpress

## 简介

Improves site performance by caching translation files using WordPress object cache.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
