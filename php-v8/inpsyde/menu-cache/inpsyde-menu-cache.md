# inpsyde/menu-cache

> 标签: cache, menu, nav-menu, plugin, transient, wordpress, wp, wp_nav_menu

## 简介

Easily cache rendered menus using the Transients API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
