# hk2/search-sanitizer

> 标签: Basant, HK2, basantmandal, extension, magento-module, magento2, magento2-extension, sanitize, sanitize search, search, search security, security

## 简介

Sanitizes Magento storefront search queries by removing suspicious SQL-related keywords and characters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
