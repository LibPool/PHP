# hk2/core

> 标签: Basant, HK2, basantmandal, core, magento-module, magento2

## 简介

HK2 Core module - The foundational base module for all Magento 2 HK2 extensions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
