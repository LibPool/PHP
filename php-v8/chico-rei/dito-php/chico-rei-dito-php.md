# chico-rei/dito-php

> 标签: dito, dito php

## 简介

Esse pacote tem como objetivo automatizar a integração com a Rest API da Dito.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
