# hungnth/laravel-12-vue-inertia-wayfinder-starter-kit

> 标签: framework, laravel

## 简介

A starter kit for Laravel 12 with Vue 3, Inertia.js, and Wayfinder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
