# hungnth/laravel-12-starter-kit-react-inertia-ziggy

> 标签: framework, laravel, starter-kit

## 简介

A starter kit for Laravel 12 with React, Inertia.js, and Ziggy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
