# ux2dev/gps-bulgaria

> 标签: fleet, gps, gps-bulgaria, iot, laravel, sdk, telematics

## 简介

Framework-agnostic PHP SDK for the GPS Bulgaria IoT API (iot.gps.bg)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
