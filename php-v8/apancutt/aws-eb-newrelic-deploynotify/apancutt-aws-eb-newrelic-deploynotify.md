# apancutt/aws-eb-newrelic-deploynotify

> 标签: PHP

## 简介

Send AWS Elastic Beanstalk deployment notifications to New Relic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
