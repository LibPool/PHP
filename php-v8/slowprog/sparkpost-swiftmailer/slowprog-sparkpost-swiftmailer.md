# slowprog/sparkpost-swiftmailer

> 标签: sparkpost, swiftmailer

## 简介

A SwiftMailer transport implementation for SparkPost

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
