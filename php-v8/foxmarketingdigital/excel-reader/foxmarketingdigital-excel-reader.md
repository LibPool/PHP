# foxmarketingdigital/excel-reader

> 标签: excel, ler excel, reader, xls, xlsx

## 简介

Uma biblioteca para leitura de arquvivos xls e xlsx

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
