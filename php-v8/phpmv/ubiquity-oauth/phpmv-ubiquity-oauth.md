# phpmv/ubiquity-oauth

> 标签: framework, mvc, oauth2, php, php-framework, tools

## 简介

Oauth 2 client for Ubiquity framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
