# phpmv/ubiquity-mysqli

> 标签: database, framework, mvc, mysql, mysqli, orm, php, sql

## 简介

Mysqli wrapper for PHP Ubiquity framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
