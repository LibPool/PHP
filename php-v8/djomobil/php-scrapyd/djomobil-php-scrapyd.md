# djomobil/php-scrapyd

> 标签: scraping, scrapy, scrapyd, spider

## 简介

Package de communication avec l'API Scrapyd pour gérer les spiders et les tâches de scraping

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
