# mix-code/jawaly-sms

> 标签: 4jawaly, 4jawaly-sms, api, gateway, laravel, messaging, mix-code, notification, php, sms, sms-integration, text-message

## 简介

Laravel and PHP package to send SMS notifications using the 4jawaly SMS API gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
