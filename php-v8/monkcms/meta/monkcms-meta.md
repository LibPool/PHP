# monkcms/meta

> 标签: cms, ekklesia, ekklesia360, monk, monkcms, monkdev

## 简介

A collection of classes to generate module meta information for the MonkCMS API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
