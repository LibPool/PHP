# octedia/fix-monolog-custom-log-files

> 标签: data-exporter, logging, magento, magento2, monolog, saas

## 简介

Fix Monolog implementations to use custom log files for SaaS Common and Data Exporter modules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
