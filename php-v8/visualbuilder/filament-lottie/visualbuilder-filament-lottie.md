# visualbuilder/filament-lottie

> 标签: animation, component, filament, lottie, schema, visualbuilder

## 简介

Lottie animation Schema component and Blade component for Filament panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
