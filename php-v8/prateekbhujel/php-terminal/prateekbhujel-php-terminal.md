> 标签: ansi, cli, console, extension, keyboard, php-extension, pie, raw-mode, terminal, tty, unix, windows

## 简介

Native terminal primitives for PHP CLI on Unix and Windows

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
