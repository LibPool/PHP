# prateekbhujel/prototype-dom

> 标签: HTML5, dom, html, prototype, rich-text, traversal, xml

## 简介

Fluent traversal and rich-text transformations on native PHP 8.4+ DOM nodes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
