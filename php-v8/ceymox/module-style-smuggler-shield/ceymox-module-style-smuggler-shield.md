# ceymox/module-style-smuggler-shield

> 标签: PHP

## 简介

Magento 2 / Adobe Commerce security module that blocks the StyleSmuggler GraphQL template-injection RCE.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
