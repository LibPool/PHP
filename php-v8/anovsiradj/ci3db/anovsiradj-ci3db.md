# anovsiradj/ci3db

> 标签: PHP

## 简介

Standalone CodeIgniter3 DataBase Query Builder with monkey-patched technique.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
