# giordanolima/loterias-api

> 标签: caixa, caixa econômica federal, cef, loterias

## 简介

Web crawler para buscar os resultados das loterias da caixa

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
