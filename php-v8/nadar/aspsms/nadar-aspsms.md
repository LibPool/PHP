# nadar/aspsms

> 标签: api, aspsms, curl, gateway, php, sms

## 简介

Simple to use sms sending class for the aspsms.com gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
