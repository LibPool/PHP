# tabi/laravel-sdk

> 标签: api, laravel, messaging, sdk, tabi, whatsapp

## 简介

Laravel integration for the Tabi WhatsApp Business Messaging API (wraps tabi/sdk)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
