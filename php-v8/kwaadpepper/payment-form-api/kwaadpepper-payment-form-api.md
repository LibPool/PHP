# kwaadpepper/payment-form-api

> 标签: api, e-commerce, lyra, payment, php, sdk

## 简介

Common API to make Lyra payment platform integration easier in PHP based websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
