# webtorque/examinator

> 标签: PHP

## 简介

A SilverStripe module for conducting online exams, this is a first draft and pretty rough, so use at your own peril

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
