# symplify/easy-coding-standard

> 标签: Code style, automation, fixer, static analysis

## 简介

Use Coding Standard with 0-knowledge of PHP-CS-Fixer and PHP_CodeSniffer

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
