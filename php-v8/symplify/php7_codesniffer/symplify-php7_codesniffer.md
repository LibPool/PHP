# symplify/php7_codesniffer

> 标签: PHP7, code sniffer, phpcs, standards, symplify

## 简介

PHP7_CodeSniffer detects and fixes violations against your coding standard.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
