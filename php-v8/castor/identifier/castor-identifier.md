# castor/identifier

> 标签: 128-bit, guid, identifier, php-extension, rfc4122, rfc9562, ulid, uuid

## 简介

High-performance 128-bit identifier extension for PHP (UUIDs and ULIDs)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
