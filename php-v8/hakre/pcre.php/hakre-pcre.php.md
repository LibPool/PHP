# hakre/pcre.php

> 标签: PCRE, cli, files, git, regex, replace, search, shell, utility

## 简介

CLI utility for PCRE pattern search and replace through list of files (line based)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
