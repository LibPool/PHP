# vicheanath/crudbooster

> 标签: admin-panel, backend, crud, crud-generator, crudbooster, generator, laravel

## 简介

CRUDBooster (classic 5.x architecture) maintained for PHP 8.2+ and Laravel 12/13 - CRUD generator for an advanced Laravel backend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
