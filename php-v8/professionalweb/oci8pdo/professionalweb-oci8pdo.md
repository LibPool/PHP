# professionalweb/oci8pdo

> 标签: component, oci8, oracle, pdo, yii2

## 简介

Extension for the Yii Framework - Oracle PDO simulation using the PHP OCI8 functions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
