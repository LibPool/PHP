# scholarly/providers

> 标签: citation, crossref, graph, laravel, openalex, scholarly, sdk, semantic scholar

## 简介

Unified PHP SDK for scholarly data providers with adapters, caching, and graph exporter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
