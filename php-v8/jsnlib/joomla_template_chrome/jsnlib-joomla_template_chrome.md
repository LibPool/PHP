# jsnlib/joomla_template_chrome

> 标签: chrome, joomla, template

## 简介

讓製作模板區塊的部分，可以分離 PHP 與 HTML

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
