# salioudiabate/select

> 标签: Combobox, dropdown, laravel, livewire, multiselect, select, ui

## 简介

A soft, modern select/combobox kit for Livewire — single, searchable, async and multi-select, one design system, zero build step, and safe to render inside a Modal (github.com/salioudiabate/modal) dialog out of the box.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
