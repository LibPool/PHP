# salioudiabate/log-viewer

> 标签: datatable, journal, laravel, livewire, log-viewer, logs

## 简介

A multi-source Laravel log file viewer for Livewire, built on top of livewire-datatable — real search/sort/pagination/export instead of hand-rolled pagination, per-entry detail in a Modal, redaction of sensitive data, and a purge action that's actually permission-gated and backed up.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
