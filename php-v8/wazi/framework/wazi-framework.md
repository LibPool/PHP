# wazi/framework

> 标签: PSR-11, framework, kioo, pedagogique, php, psr-15, psr-17, psr-7, template-engine, wazi

## 简介

Wazi, le framework PHP où tout est clair : puissant, simple, et pensé pour comprendre ce qu'on construit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
