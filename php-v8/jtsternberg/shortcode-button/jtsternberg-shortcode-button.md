# jtsternberg/shortcode-button

> 标签: CMB2, shortcodes, wordpress

## 简介

Tinymce and Quicktag buttons (and modals) for outputting shortcodes. Built to work with CMB2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
