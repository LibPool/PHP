# smart-raya/ippanel-laravel

> 标签: IPPanel, SmartRaya, sms

## 简介

A simple API extension for send text message By IPPanel in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
