# apigopro/slim-cors-middleware

> 标签: cors, middleware, psr-15, slim

## 简介

PSR-15 CORS middleware for Slim Framework 4, spiritual successor to tuupola/cors-middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
