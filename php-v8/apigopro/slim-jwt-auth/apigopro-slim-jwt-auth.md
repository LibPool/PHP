# apigopro/slim-jwt-auth

> 标签: Authentication, jwt, middleware, psr-15, slim

## 简介

PSR-15 JWT authentication middleware for Slim Framework 4, spiritual successor to tuupola/slim-jwt-auth, built on firebase/php-jwt 7.x.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
