# christiaangoossens/tls_icon

> 标签: icon, roundcube, tls

## 简介

Displays TLS status next to the sender name (just like authres_status) in Roundcube, supports local mails and detecting weak TLS ciphers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
