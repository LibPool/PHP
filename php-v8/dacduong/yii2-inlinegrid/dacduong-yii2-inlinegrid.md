# dacduong/yii2-inlinegrid

> 标签: Excel like, extension, inline gridview, widget, yii2

## 简介

Inline Gridview for editing content like in Excel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
