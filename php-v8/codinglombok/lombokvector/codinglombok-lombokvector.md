# codinglombok/lombokvector

> 标签: cosine-similarity, deterministic, embedding, lombok-ecosystem, vector

## 简介

Vector math with bit-identical results across PHP, Rust, TypeScript, Python and Go: dot product, cosine similarity, L2 distance, normalization, batch ranking. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
