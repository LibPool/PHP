# natsumework/redis-autocomplete

> 标签: autocomplete, laravel, redis

## 简介

Provide an easy way for your laravel app to use redis to speed up autocomplete queries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
