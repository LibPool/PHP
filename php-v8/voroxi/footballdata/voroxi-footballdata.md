# voroxi/footballdata

> 标签: api, fixtures, football, footballdata, odds, predictions, soccer, sports, standings

## 简介

Official PHP SDK for the footballdata.io football data API (fixtures, predictions, standings, odds, FIFA rankings and more).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://footballdata.io
- 源码仓库：https://github.com/voroxi/footballdata-php.git
- Packagist 页面：https://packagist.org/packages/voroxi%2Ffootballdata
