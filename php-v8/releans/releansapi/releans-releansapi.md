# releans/releansapi

> 标签: Releans API, api, sdk

## 简介

The Releans SDK enables developers to use Releans Services in their code. You can get started in minutes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
