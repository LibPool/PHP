# jbaron-mx/laravel-recombee

> 标签: jbaron-mx, laravel, laravel-recombee

## 简介

An expressive fluent API wrapper around Recombee's SDK to use within Laravel applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
