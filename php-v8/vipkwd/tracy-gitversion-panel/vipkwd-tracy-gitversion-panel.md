# vipkwd/tracy-gitversion-panel

> 标签: branch, debug, git, log, nette, vipkwd

## 简介

Tracy DebugBar panel displaying current project git branch.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
