# vizuh/october-clicktrail

> 标签: PHP

## 简介

See which campaign, keyword, click ID and landing page created each form submission. First-touch/last-touch attribution for October CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
