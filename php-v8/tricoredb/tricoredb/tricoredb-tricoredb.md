# tricoredb/tricoredb

> 标签: cache, client, database, document, driver, graph, sql, tricore, tricoredb, vector

## 简介

Native PHP driver for TriCoreDB: SQL with server-side parameters, transactions, documents, cache, vectors, graphs and LLM context over the tricore wire protocol, with no runtime dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
