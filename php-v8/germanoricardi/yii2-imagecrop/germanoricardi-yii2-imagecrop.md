# germanoricardi/yii2-imagecrop

> 标签: crop, crop class, yii2 crop, yii2 image crop

## 简介

PHP class to crop images with yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
