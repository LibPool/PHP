# taldres/laravel-geocode-cache

> 标签: cache, coordinates, geocode, geocoding, google-maps, laravel

## 简介

A geocoding cache for Laravel with retention limits, scheduled deletion and locks against duplicate lookups.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
