# taldres/laravel-immutable-attributes

> 标签: attributes, data-integrity, eloquent, immutable, laravel, model

## 简介

Guard Eloquent model attributes against changes once a row exists: declare them with #[Immutable] and every save that would alter them throws.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
