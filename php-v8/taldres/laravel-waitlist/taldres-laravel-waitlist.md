# taldres/laravel-waitlist

> 标签: consent, double-opt-in, early-access, gdpr, headless, laravel, privacy, waitlist

## 简介

Privacy-first, headless waitlist package for Laravel: subscription cycles with versioned consent records, atomic state changes, data access and erasure APIs, reporting that survives an erasure, double opt-in, events and CSV export. No dashboard, no mail delivery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
