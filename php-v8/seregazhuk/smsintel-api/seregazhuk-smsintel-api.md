# seregazhuk/smsintel-api

> 标签: lib, php, smsintel

## 简介

A PHP wrapper for the SmsIntel api. Provides one interface for both XML and JSON API requests.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
