> 标签: Relationships, ai, artisan, clean-architecture, composer-package, crud, ddd, developer-tools, generator, laravel, laravel-package, openapi, repository, scaffolding, service, swagger, testing

## 简介

Generate production-style Laravel feature structure from one Artisan command: CRUD, APIs, services, repositories, tests, OpenAPI docs, modules, and AI-ready project context.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
