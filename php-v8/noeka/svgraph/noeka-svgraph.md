# noeka/svgraph

> 标签: PHP

## 简介

JavaScript-free SVG chart rendering for PHP. Sparkline, line/area, bar, pie/donut, and progress charts as static markup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
