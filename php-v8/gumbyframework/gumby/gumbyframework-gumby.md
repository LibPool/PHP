# gumbyframework/gumby

> 标签: css, gumby, gumby2, sass

## 简介

A Flexible, Responsive CSS Framework - Powered by Sass

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
