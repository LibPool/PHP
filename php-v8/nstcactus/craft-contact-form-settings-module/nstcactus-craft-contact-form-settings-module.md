# nstcactus/craft-contact-form-settings-module

> 标签: PHP

## 简介

A Craft module to manage multiple contact forms using the contact-form & contact-form-extensions plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
