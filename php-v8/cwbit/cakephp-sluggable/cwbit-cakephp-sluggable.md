# cwbit/cakephp-sluggable

> 标签: cakephp, plugin, slug, sluggable

## 简介

Plugin for CakePHP 3.x that enables automatic, configurable slugging of database fields

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
