# ts3serverbot/query

> 标签: serverquery, ssh, teamspeak, teamspeak3, teamspeak6, ts3serverbot, webquery

## 简介

Open-source PHP Query client for TeamSpeak 3 and TeamSpeak 6 over SSH and WebQuery. Developed under TS3ServerBot.com.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
