# doss/laravel-db-backup

> 标签: backup, database, google-drive, laravel, mysqldump, pg_dump, s3

## 简介

Back up your Laravel database and upload it to Google Drive, S3, FTP or any storage with `php artisan db:backup`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
