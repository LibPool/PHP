# emnify/emnify-sdk

> 标签: api, php, rest, sdk, swagger

## 简介

Supply your swarm of IoT devices with cloud connectivity by emnify. Automate your routines with this SDK for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
