# railsware/mailtrap-php

> 标签: email, laravel, mail, mailtrap, mailtrap-io, php, plugin, sdk, symfony

## 简介

The Mailtrap SDK provides methods for all API functions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
