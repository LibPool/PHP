# phptdgram/schema

> 标签: phptdgram, schema, tdlib, telegram

## 简介

The PHP TD Gram Schema generated TdLib Schema Classes using phptdgram/schema-generator from td_api.tl file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
