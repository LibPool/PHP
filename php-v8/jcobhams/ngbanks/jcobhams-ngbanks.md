# jcobhams/ngbanks

> 标签: Nigerian, banks, cbn, fintech, money

## 简介

PHP Implementation for Lightweight Zero dependency npm package to get list of banks in Nigeria (Recognized by CBN)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
