# vielhuber/ppthelper

> 标签: PHP

## 简介

MCP server that turns Markdown into editable PowerPoint decks via Pandoc with a dynamically themed reference.pptx.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
