# enpii/wp-site-enpii-boilerplate

> 标签: boilerplate, laravel, wordpress, wordpress laravel

## 简介

The WordPress boilerplate for WordPress development with Laravel ready

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
