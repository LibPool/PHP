# onion/interfaces

> 标签: PHP

## 简介

Package containing only the interfaces of 'onion' libraries, allowing to use code without installing the whole framework and using code written for the framework outside it

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
