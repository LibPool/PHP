# paymfi/paymfi-php

> 标签: api, ewallet, mfi, payments, paymfi, sacco, sdk

## 简介

PHP client for the PayMfi eWallet & Payments API: signed requests, hosted checkout, server-side verification and webhook signature checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
