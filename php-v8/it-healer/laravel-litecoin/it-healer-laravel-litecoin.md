# it-healer/laravel-litecoin

> 标签: it-healer, laravel, litecoin, ltc, php

## 简介

A library for Laravel that allows you to create and manage the Ethereum cryptocurrency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
