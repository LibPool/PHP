# 6phere/horizon-wildcard-consumer

> 标签: PHP

## 简介

Extended Laravel Horizon providing listening dynamically added queues matched by wildcard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
