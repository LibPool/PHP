# sobhansgh/torob-sync

> 标签: e-commerce, jwt, laravel, product-feed, torob, torob-sync, webhook, ترب

## 简介

اتصال فروشگاه‌های لاراولی به ترب (Torob) بر اساس Product API v3، احراز هویت JWT و وبهوک به‌روزرسانی محصول

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
