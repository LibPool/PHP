# michalsn/codeigniter4-uuid

> 标签: codeigniter, codeigniter4, model, ulid, uuid

## 简介

UUID and ULID package for CodeIgniter 4 with support for Model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
