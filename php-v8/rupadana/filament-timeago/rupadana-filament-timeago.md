# rupadana/filament-timeago

> 标签: filament-timeago, laravel, rupadana

## 简介

Display the age of each record, indicating when it was created, updated, and (if applicable) deleted.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
