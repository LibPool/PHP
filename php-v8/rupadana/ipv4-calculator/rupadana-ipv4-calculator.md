# rupadana/ipv4-calculator

> 标签: IP, address, calculator, cidr, ipv4, network, subnet

## 简介

Network calculator for subnet mask and other classless (CIDR) network information.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
