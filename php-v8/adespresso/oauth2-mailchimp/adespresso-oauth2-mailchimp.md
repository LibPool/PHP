# adespresso/oauth2-mailchimp

> 标签: PHP

## 简介

Mailchimp OAuth 2.0 client provider for PHP League OAuth2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
