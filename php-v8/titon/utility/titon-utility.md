# titon/utility

> 标签: collection, config, crypt, format, inflector, number, path, registry, sanitize, string, time, titon, utility, validate

## 简介

The utility package provides convenience classes for basic tasks like validation, formatting, sanitization and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
