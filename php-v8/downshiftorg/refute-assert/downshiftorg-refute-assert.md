# downshiftorg/refute-assert

> 标签: phpunit

## 简介

Use refuteX terminology instead of assertNotX for PHPUnit assertions, plus some extra assert/refute pairs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
