# bimthebam/silverstripe-lucide-icons

> 标签: icons, lucide, silverstripe

## 简介

Provides Lucide icons as an inline SVG template helper for Silverstripe CMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
