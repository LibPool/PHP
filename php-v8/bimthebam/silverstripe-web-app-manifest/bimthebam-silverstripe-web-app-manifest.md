# bimthebam/silverstripe-web-app-manifest

> 标签: manifest, module, pwa, silverstripe, web app

## 简介

Configurable web app manifest generator for SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
