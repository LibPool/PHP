# gabrielqs/boleto

> 标签: PHP

## 简介

Módulo Magento 2 para emissão de boletos, com geração de arquivos de remessa, e processamento de arquivos de retorno

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
