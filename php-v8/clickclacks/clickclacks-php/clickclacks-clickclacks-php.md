# clickclacks/clickclacks-php

> 标签: analytics, clickclacks, events, laravel, product-analytics, server

## 简介

Server-side SDK for ClickClacks product analytics. Batches, gzips and retries events safely, with an optional Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
