# argws/asaas-sdk-php

> 标签: PHP

## 简介

SDK PHP NÃO OFICIAL para a API do Asaas. Baseada na SDK Java e gerada a partir da documentação/OpenAPI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
