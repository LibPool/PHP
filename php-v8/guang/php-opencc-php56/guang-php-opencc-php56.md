# guang/php-opencc-php56

> 标签: PHP

## 简介

中文简繁转换，支持词汇级别的转换、异体字转换和地区习惯用词转换（中国大陆、台湾、香港、日本新字体）。基于 [BYVoid/OpenCC](https://github.com/BYVoid/OpenCC) 数据实现。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
