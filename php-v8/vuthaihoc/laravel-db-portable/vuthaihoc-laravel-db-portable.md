# vuthaihoc/laravel-db-portable

> 标签: cockroachdb, database, fts5, fulltext, json, laravel, matrixone, migration, mirror, mysql, portable, postgresql, sqlite, xtdb

## 简介

Portable Laravel query builder and schema helpers for PostgreSQL/CockroachDB, MySQL/MariaDB/MatrixOne and SQLite (whereFullText() on SQLite with FTS5), tools to switch databases (scan, audit, copy), and mirrors keeping chosen tables in other databases through the queue (analytics, XTDB history)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
