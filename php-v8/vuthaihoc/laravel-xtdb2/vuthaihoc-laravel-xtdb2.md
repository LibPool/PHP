# vuthaihoc/laravel-xtdb2

> 标签: bitemporal, database, driver, eloquent, laravel, postgres-wire, xtdb

## 简介

An XTDB 2 database driver for Laravel: Eloquent, Query Builder and migrations over the PostgreSQL wire protocol, with bitemporal queries

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
