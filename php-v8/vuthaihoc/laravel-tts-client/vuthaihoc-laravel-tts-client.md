# vuthaihoc/laravel-tts-client

> 标签: Piper, laravel, text-to-speech, tts

## 简介

Laravel client for the Piper TTS API (laravel-tts-api): signs temporary tokens locally, synthesizes and streams speech.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
