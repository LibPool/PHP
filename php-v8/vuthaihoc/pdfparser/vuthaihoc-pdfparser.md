# vuthaihoc/pdfparser

> 标签: PHP

## 简介

Fork of prinsfrank/pdfparser: PDF parsing, text & image extraction, plus an experimental Imagick page renderer, HTTP Range reading and parser fixes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
