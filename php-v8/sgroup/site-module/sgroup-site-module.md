# sgroup/site-module

> 标签: Craft, cms, craftcms, plugin

## 简介

A base module for S. projects and other modules to extend from for Craft CMS development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
