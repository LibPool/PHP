# pixelcoda/search-platform

> 标签: ai-search, autocomplete, faceted-search, headless-search, meilisearch, pagination, pgvector, rag, react-search, typo3, typo3-ai-search, typo3-meilisearch, typo3-rag, typo3-search, typo3-semantic-search, typo3-vector-search

## 简介

AI-powered Search & Answers platform for TYPO3, Headless CMS and React apps with Meilisearch, pgvector, autocomplete, faceted search, pagination, analytics, Docker and optional RAG answers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
