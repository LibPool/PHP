# jacobjoergensen/laravel-fmt

> 标签: blade, formatter, laravel, livewire, php, tailwind

## 简介

Formatter for PHP, Blade, and Livewire 4 with first-class Tailwind class sorting. It also formats HTML, CSS, Markdown, JSON, YAML, and XML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
