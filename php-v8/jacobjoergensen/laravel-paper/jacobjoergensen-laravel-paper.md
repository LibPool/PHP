# jacobjoergensen/laravel-paper

> 标签: cms, content, eloquent, flat-file, frontmatter, laravel, markdown

## 简介

A flat-file Eloquent driver for modern Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
