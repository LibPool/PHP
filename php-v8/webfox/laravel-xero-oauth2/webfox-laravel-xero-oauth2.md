# webfox/laravel-xero-oauth2

> 标签: laravel, laravel-xero-oauth2, oauth2, webfox, xero

## 简介

A Laravel integration for Xero using the Oauth 2.0 spec

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
