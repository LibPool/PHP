# webfox/silverstripe-blog-search

> 标签: blog, search, silverstripe, webfox

## 简介

A Silverstripe extension to add Blog Search functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
