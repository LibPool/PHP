# pdftoolkit/pdf-reader

> 标签: iso-32000-1, object-model, pdf, pdf-1.7, pdf-2.0, php, reader

## 简介

A bounded PDF object reader with password, certificate and source PDF MAC authentication for PHP 8.3+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
