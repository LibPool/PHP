# pdftoolkit/pdf-to-html

> 标签: accessibility, derivation, html, pdf, pdf-2.0, tagged-pdf

## 简介

Semantic HTML from tagged PDF with explicit objects, source PDF MAC policy and authenticated permissions for PHP 8.3+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
