# pdftoolkit/opentype

> 标签: Glyphs, font-variations, fonts, gdef, gpos, gsub, kerning, ligatures, object-model, opentype, php, typography

## 简介

Pure-object OpenType metadata, variable outlines, metrics, substitutions and glyph positioning

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
