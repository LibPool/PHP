# pdftoolkit/pdf-fonts

> 标签: fonts, object-model, pdf, php

## 简介

Bounded static TrueType conversion to explicit PDF font objects for PHP 8.3+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
