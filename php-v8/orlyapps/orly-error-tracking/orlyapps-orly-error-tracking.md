# orlyapps/orly-error-tracking

> 标签: laravel, orly-error-tracking, orlyapps

## 简介

Report Laravel exceptions to Orly – filtered request, user and context, flood-safe.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
