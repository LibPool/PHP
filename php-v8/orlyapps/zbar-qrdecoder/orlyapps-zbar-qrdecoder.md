# orlyapps/zbar-qrdecoder

> 标签: decode, laravel, php, qr, qrcode, zbar

## 简介

A PHP wrapper for Zbar. Decodes images/photos containing QR codes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
