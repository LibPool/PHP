# sopinet/uploadfiles-bundle

> 标签: Symfony2, bundle, field, file, oneupload, upload

## 简介

Symfony2 Bundle - File field to facilitate the use of the One Upload Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
