# waxedphp/galleria

> 标签: PHP

## 简介

A free JavaScript image gallery framework that simplifies the process of creating beautiful image galleries for the web and mobile devices - within WaxedPHP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
