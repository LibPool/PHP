# waxedphp/bootstrap

> 标签: PHP

## 简介

Powerful, extensible, and feature-packed frontend toolkit - within WaxedPHP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
