# waxedphp/plyr

> 标签: PHP

## 简介

A simple, accessible and customisable media player for Video, Audio, YouTube and Vimeo - within WaxedPHP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
