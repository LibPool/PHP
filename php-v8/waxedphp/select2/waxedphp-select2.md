# waxedphp/select2

> 标签: PHP

## 简介

A customizable select box with support for searching, tagging, remote data sets, infinite scrolling, and many other - within WaxedPHP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
