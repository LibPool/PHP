# eightcedars/filament-inactivity-guard

> 标签: eightcedars, filament auto logout, filament idle session, filament inactivity guard, filamentphp, laravel

## 简介

Gracefully auto-logout users from idle/inactive Filament sessions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
