# austral/entity-file-bundle

> 标签: Austral, Files entities, file entity, uploads

## 简介

File uploads, thumbnails and download for entity to Symfony. Compress file with squoosh-cli

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
