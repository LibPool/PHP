# smtpfast/smtpfast-laravel

> 标签: email, laravel, mail, mail-driver, smtpfast, transactional-email

## 简介

Send Laravel mail through the SMTPfast API, with the SMTPfast PHP client and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
