# renderbit/laravel-sms

> 标签: api, laravel, messaging, renderbit, sms, text

## 简介

Framework-agnostic PHP library for sending SMS via Renderbit, with Laravel support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
