# kqdog/mn-captcha

> 标签: captcha, easycaptcha, gif, thinkphp, 验证码

## 简介

ThinkPHP 8 图形验证码扩展，一比一还原 EasyCaptcha 视觉效果，支持 PNG/GIF动态/算术/中文验证码

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
