# adrian7/mailchimp-api-v3

> 标签: api, mailchimp, php, v3

## 简介

Simple API wrapper for Mailchimp API version 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
