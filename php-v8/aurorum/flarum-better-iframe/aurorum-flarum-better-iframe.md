# aurorum/flarum-better-iframe

> 标签: aurorum, flarum, iframe

## 简介

A Flarum extension.This extension makes it possible to use <iframe> element in flarum. It allows almost all iframe attributes. It's written by Aurorum Studio. Visit our website: https://dev.aurorum.co .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
