# jordihales/acf-force-edit-mode

> 标签: acf, gutenberg, mu-plugin, wordpress

## 简介

Restore ACF Blocks V2 in-canvas edit mode in the WordPress 7.1+ block editor.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
