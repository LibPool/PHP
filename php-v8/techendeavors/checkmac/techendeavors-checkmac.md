# techendeavors/checkmac

> 标签: checkmac, cloudflare, dns, dns-over-https, google, laravel, techendeavors

## 简介

CheckMAC takes the MAC address of a network interface and returns the manufacturer of the equipment

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
