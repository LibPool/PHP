# eliothumerez/entrust

> 标签: acl, auth, illuminate, laravel, permission, roles

## 简介

Este componente proporciona una manera flexible de agregar permisos basados en roles, módulos, formularios, campos y acciones a Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
