# vudev/pagination

> 标签: library, page, pagination, plugin, yandex

## 简介

This library provides an opportunity to quickly add pagination of pages to your project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
