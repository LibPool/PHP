# bml/sentry-symfony-cron-monitor

> 标签: cron, errors, logging, sentry, symfony

## 简介

Symfony cron monitoring integration for Sentry (http://getsentry.com)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
