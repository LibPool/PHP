# nanobe/nanobe-bundle

> 标签: nanobe, symfony

## 简介

NanobeBundle makes using Nanobe with Symfony Framework easy and convenient. Nanobe is a PHP interface abstraction layer for web applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
