# phpterminal/phpterminal-modules-firewall

> 标签: php, terminal

## 简介

PHPTerminal-modules-firewall is an firewall module for PHPTerminal to manage PHPFirewall library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
