# seanmorris/sm-no-saccade-style

> 标签: PHP

## 简介

PHP-CS-Fixer style package for left-rail punctuation, Allman blocks, tabs, and tight control parens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
