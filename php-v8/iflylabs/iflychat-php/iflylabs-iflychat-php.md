# iflylabs/iflychat-php

> 标签: Live Chat, chat, chat room, community, embed chat, friends, group chat, html5 chat, mobile chat, one to one chat, popup chat

## 简介

A real time enterprise chat solution which can be integrated into any PHP website

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
