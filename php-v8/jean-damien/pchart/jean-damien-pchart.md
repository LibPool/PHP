# jean-damien/pchart

> 标签: charts, pchart, pogolotti

## 简介

pChart is a PHP class oriented framework designed to create anti-aliased charts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
