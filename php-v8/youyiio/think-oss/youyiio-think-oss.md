# youyiio/think-oss

> 标签: Object Storage Service, aliyun, oss, qiniu, thinkphp, thinkphp5

## 简介

Object Storage Service(oss) plugin for thinkphp 5.1.x, now suport aliyun/qiniu vendor.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
