# soundintheory/fuel-cmf

> 标签: admin, bootstrap, cmf

## 简介

A CMF for rapid web application development, built upon FuelPHP and Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
