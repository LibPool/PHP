# visit-x/arc-phpunit

> 标签: arc, phabricator, phpunit7, testing, unit-test

## 简介

Arcanist util to run tests and generate code coverage reports for phpunit7 format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
