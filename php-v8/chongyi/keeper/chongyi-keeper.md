# chongyi/keeper

> 标签: PHP

## 简介

基于 Swoole 实现的后台多进程工具，可以快速创建拥有更多可能性的应用

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
