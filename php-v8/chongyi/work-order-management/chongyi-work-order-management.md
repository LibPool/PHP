# chongyi/work-order-management

> 标签: laravel, team management, work order

## 简介

工单管理工具，小团队沟通工具。是作者平日的 laravel 框架研究中诞生的程序。该工具可用于团队之间的通知、BUG 报告、工作日报等等。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
