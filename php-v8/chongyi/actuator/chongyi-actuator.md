# chongyi/actuator

> 标签: PHP

## 简介

轻松调用 shell 命令，同时实现双向进程管道的读写操作，以实现更为丰富的进程调用功能。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
