# sabercoding/php-ots

> 标签: PHP

## 简介

Aliyun OTS SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.aliyun.com/product/ots
- 源码仓库：https://github.com/sabercoding/php-ots.git
- Packagist 页面：https://packagist.org/packages/sabercoding%2Fphp-ots

## 获取地址

- Composer 安装：`composer require sabercoding/php-ots`
- Packagist 仓库：https://repo.packagist.org/p2/sabercoding/php-ots.json
- PHP 要求：>=5.5
