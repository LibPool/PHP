# pantaovay/incubator

> 标签: framework, incubator, phalcon

## 简介

Adapters, prototypes or functionality that can be potentially incorporated to the C-framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
