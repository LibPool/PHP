# moonlandsoft/autogrow

> 标签: autogrow, extension, jquery, textarea, yii2

## 简介

The Jquery autogrow extension for texarea in yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
