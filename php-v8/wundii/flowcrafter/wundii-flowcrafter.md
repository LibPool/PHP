# wundii/flowcrafter

> 标签: flow, message-driven, orchestration, state-machine, workflow

## 简介

PHP library for defining, executing, and monitoring message-driven workflows (state machines)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
