# wundii/structron

> 标签: Value Object, code generator, doc generator, doc tool, documentation, dto, entity, markdown, php, phpdoc, reflection

## 简介

A PHP library for generating human-readable documentation from structured data objects like DTOs, Entities, and Value Objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
