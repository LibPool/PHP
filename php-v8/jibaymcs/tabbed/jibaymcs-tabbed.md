# jibaymcs/tabbed

> 标签: JibayMcs, filament, filament-plugin, filamentphp, laravel, tabbed

## 简介

A FilamentPHP plugin to manage records in manageable tabs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
