# summernote/summernote

> 标签: wysiwyg

## 简介

Super Simple WYSIWYG Editor on Bootstrap(3.0 and 2.x).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
