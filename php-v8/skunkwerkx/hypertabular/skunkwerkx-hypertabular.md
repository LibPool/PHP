# skunkwerkx/hypertabular

> 标签: csv, ffi, parser, rust, tabular, tsv, validation

## 简介

Delimited text (CSV, TSV) and workbooks (XLSX, ODS) read a batch at a time into typed columns, every cell a HyperCast Success/Fault verdict — direct native FFI into a Rust core that owns no memory.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
