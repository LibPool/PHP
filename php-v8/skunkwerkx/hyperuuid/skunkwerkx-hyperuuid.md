# skunkwerkx/hyperuuid

> 标签: PHP

## 简介

RFC 9562 UUID v4/v5/v7 generation — direct native FFI into a Rust core, no runtime bridge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
