# g2planet/laravel-saml

> 标签: SSO, acl, auth, idp, illuminate, laravel, login, saml, sp

## 简介

SAML support to make a laravel application to both a SAML IDP and a SAML SP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
