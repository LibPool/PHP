# agavi/agavi

> 标签: framework, mvc

## 简介

Agavi is a full-featured MVC-style framework for PHP5 with a strong focus on structure, code reusability and flexibility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
