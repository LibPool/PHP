# memdevs/tag

> 标签: PHP

## 简介

Ability to create tags and store in a data store. Includes ability to set custom data for tag. A tag can have multiple values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
