# mityugin/mark-a-spot

> 标签: PHP

## 简介

Mark-a-Spot is a Drupal distribution for crowdmapping and public civic issue tracking

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
