# blumster/yii2-model-based-controller

> 标签: controller, extension, yii2

## 简介

Base model controller, which automatically loads an ActiveRecord before every call.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
