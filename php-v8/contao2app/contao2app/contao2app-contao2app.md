# contao2app/contao2app

> 标签: android, app, blappsta, contao, ios, mobile

## 简介

Contao2App provides methods to use contao as the data source for blappsta mobile apps. (http://www.blappsta.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
