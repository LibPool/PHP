# monkeytips/monkeytips-walletd-rpc-php

> 标签: TurtleCoin, php

## 简介

A PHP wrapper for the TurtleCoin walletd daemon RPC interface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
