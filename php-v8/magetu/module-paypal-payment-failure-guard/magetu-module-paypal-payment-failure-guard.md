# magetu/module-paypal-payment-failure-guard

> 标签: graphql, mage-os, magento, magento2, module, payflow, paypal, security

## 简介

Stops an unauthenticated caller from making a Magento 2 or Adobe Commerce store email itself payment-failed merchant notifications through core Magento_PaypalGraphQl, without disabling the module.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
