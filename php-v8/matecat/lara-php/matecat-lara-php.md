# matecat/lara-php

> 标签: PHP

## 简介

Matecat Lara SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://laratranslate.com/
- 源码仓库：https://github.com/matecat/lara-php.git
- Packagist 页面：https://packagist.org/packages/matecat%2Flara-php

## 历史版本号

## 获取地址

- Composer 安装：`composer require matecat/lara-php`
- Packagist 仓库：https://repo.packagist.org/p2/matecat/lara-php.json
- 许可证：MIT
- PHP 要求：>=5.6.0
