# net-os/laravel-netos-debug

> 标签: debugbar, debugging, laravel, net-os, ray

## 简介

Ships debugbar data for every request to the NetOS Debug desktop app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
