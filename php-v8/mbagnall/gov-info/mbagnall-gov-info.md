# mbagnall/gov-info

> 标签: api.govinfo.gov, gov, govinfo, govinfo.gov

## 简介

A fork for a library for using api.govinfo.gov. Compatible with Drupal 9 until it can use console 5

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
