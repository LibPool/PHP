# lunixi/php-sdk

> 标签: Ed25519, gateway, lunixi, payment, sdk, webhook

## 简介

Lunixi payment gateway PHP SDK — framework-agnostic client for payments, webhooks and platform services. Used standalone or bundled (scoped) inside the WordPress/WooCommerce, OpenCart and other integrations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
