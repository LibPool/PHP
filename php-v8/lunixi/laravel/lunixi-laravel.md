# lunixi/laravel

> 标签: gateway, laravel, lunixi, payment, webhook

## 简介

Laravel integration for the Lunixi PHP SDK — configuration, container bindings, webhook route, checkout form component and payment reconciliation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
