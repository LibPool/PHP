# minspec/skeleton

> 标签: Skeleton, caddy, composer-project, frankenphp, minspec, symfony

## 简介

Minimal MinSpec project skeleton built on the Symfony Docker / FrankenPHP runtime baseline.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
