# sunergos/og-pilot-php

> 标签: laravel, og-image, og-pilot, opengraph, social-media

## 简介

PHP client for the OG Pilot Open Graph image generator with Laravel support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
