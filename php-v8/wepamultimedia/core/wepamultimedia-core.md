# wepamultimedia/core

> 标签: core, laravel, wepamultimedia

## 简介

Core is the base package for the configuration of an administration system based on Laravel and Vue using Jetstream and Inertia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
