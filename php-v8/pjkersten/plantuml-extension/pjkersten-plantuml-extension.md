# pjkersten/plantuml-extension

> 标签: mediawiki, uml

## 简介

MediaWiki extension which renders plantuml markup as UML diagramm graphics

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
