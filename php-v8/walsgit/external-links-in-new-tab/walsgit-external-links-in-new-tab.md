# walsgit/external-links-in-new-tab

> 标签: extension, flarum, flarum-extension, forum, links, nav, url

## 简介

Opens all external links in a new tab

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
