# laralogs/laralogs

> 标签: debug, laravel, logging, logs, monitoring, web-interface

## 简介

A beautiful Laravel package for viewing and managing application logs with a modern web interface

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
