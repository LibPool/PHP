# glenwell/admin-module

> 标签: admin, laravel, panel

## 简介

Admin module based on TCG's Laravel Voyager and nwidart's Laravel modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
