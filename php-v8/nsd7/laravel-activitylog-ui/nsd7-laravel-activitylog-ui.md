> 标签: Audit, activity-log, activitylog, admin, alpinejs, analytics, audit-log, audit-trail, csv, dashboard, export, history, laravel, laravel-activitylog, laravel-package, logging, monitoring, spatie, tailwind, tailwindcss, timeline, ui

## 简介

A beautiful Tailwind CSS dashboard for Spatie Laravel Activitylog — browse, filter, diff, analyse and export your audit/activity logs. Analytics charts, timeline, saved views, dark mode, full record history, CSV/JSON/Excel/PDF export, multi-database, zero build step.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
