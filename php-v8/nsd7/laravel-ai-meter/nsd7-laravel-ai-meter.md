# nsd7/laravel-ai-meter

> 标签: Agent, ai, anthropic, budget, cost, dashboard, finops, laravel, laravel-package, llm, metering, monitoring, observability, openai, prism, token, usage

## 简介

Self-hosted metering + budget enforcement for AI/LLM & agent calls in Laravel. Traces, token/cost attribution, a built-in dashboard, and multi-scope spend limits — with no external service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
