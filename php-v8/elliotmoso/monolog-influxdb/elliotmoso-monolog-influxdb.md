# elliotmoso/monolog-influxdb

> 标签: influxdb, laravel, log, logging, monolog, symfony

## 简介

A handler for Monolog that sends messages to InfluxDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
