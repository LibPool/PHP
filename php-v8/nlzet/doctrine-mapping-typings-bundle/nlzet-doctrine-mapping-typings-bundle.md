# nlzet/doctrine-mapping-typings-bundle

> 标签: cli, doctrine, symfony, typescript

## 简介

symfony bundle to convert doctrine entities into typescript typings

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
