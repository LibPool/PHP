# antoksa/callable-that-proxy

> 标签: antoksa, callable, dynamic, lightweight, proxy, runtime, that

## 简介

Lightweight proxy to create a callable from a 'dynamic' object during runtime

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
