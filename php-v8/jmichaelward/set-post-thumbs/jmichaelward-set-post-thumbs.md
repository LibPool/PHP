# jmichaelward/set-post-thumbs

> 标签: PHP

## 简介

A simple WP-CLI command to query posts for their content and set the first found image as the post thumbnail.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
