# makuro/directus_keycloak_client

> 标签: authorisation, authorization, client, directus, keycloak, oauth, oauth2

## 简介

Keycloak OAuth 2.0 Client Provider for the headless CMS directus based on the PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
