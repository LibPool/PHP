# dancasdev/gac

> 标签: gac, php

## 简介

GAC (Granular Access Control) es una Librería PHP para gestionar permisos y restricciones de acceso con granularidad por módulo, rol, usuario y alcance jerárquico. Compatible con MySQL y PostgreSQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
