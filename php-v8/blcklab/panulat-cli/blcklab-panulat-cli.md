# blcklab/panulat-cli

> 标签: cli, console, framework, panulat, php, scaffolding

## 简介

Panulat CLI: lightweight development scaffolding commands and the black executable for Panulat REST API projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
