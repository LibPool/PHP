> 标签: bootstrap, framework, laravel, laravel-ready, laravel-ready-starter, laravel-starter, laravel-starter-kit, laravel-starter-template, starter-kit, starter-template, tailwindcss

## 简介

Batteries included ready to use empty laravel starter project template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
