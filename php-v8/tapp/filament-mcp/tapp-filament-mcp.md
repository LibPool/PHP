# tapp/filament-mcp

> 标签: filament, laravel, mcp, sanctum, tapp

## 简介

MCP for Laravel apps in Filament: a token page with one Sanctum ability per tool, setup steps for any AI agent, tool-call enforcement and an optional audit log.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
