# tapp/laravel-aws-secrets-manager

> 标签: laravel-aws-secrets-manager, tapp

## 简介

Use AWS Secrets manager to load environment variables for configuration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
