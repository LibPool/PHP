# tapp/filament-footer

> 标签: configurable, copyright, filament, footer, i18n, laravel, multilingual

## 简介

A Filament plugin to add a customizable copyright footer to all panels

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
