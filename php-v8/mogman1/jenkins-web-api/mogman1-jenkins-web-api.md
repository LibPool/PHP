# mogman1/jenkins-web-api

> 标签: api, ci, jenkins

## 简介

PHP API wrapper for retrieving information from Jenkins and triggering builds.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
