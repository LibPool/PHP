# devoton/qrcode

> 标签: data-uri, laravel, laravel qr code, native qr engine, native-php, packagist, php, php qr code, png, qr code, qr-code, qr-code-generator, qr-code-svg, svg

## 简介

Open-source Laravel QR code generator with a native PHP engine for SVG, PNG and data URI output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
