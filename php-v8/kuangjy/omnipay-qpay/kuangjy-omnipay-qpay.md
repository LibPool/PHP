# kuangjy/omnipay-qpay

> 标签: PHP

## 简介

QPay(QQ Wallet) driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
