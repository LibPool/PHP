# pixadelic/adobe-experience-cloud-php-sdk

> 标签: Adobe Campaign Standard, Adobe Experience Cloud, adobe, php

## 简介

An Adobe Experience Cloud API client php implementation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
