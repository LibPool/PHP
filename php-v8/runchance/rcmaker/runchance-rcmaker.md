# runchance/rcmaker

> 标签: High Performance, oneness of fpm and cli mode, php http framework, standalone http service, standalone php process manager

## 简介

rcmaker is oneness of fpm and cli high performance php framework, support workerman and swoole run mode

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
