# phpskills/phpskills

> 标签: elo, matchmaking, ranking, skill, trueskill

## 简介

Implementation of Microsoft's TrueSkill matchmaking system for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
