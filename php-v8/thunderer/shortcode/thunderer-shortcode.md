# thunderer/shortcode

> 标签: bbcode, engine, library, parser, shortcode

## 简介

Advanced shortcode (BBCode) parser and engine for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
