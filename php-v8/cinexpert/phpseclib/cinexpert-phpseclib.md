# cinexpert/phpseclib

> 标签: BigInteger, aes, asn.1, asn1, blowfish, crypto, cryptography, encryption, rsa, security, sftp, signature, signing, ssh, twofish, x.509, x509

## 简介

PHP Secure Communications Library - Pure-PHP implementations of RSA, AES, SSH2, SFTP, X.509 etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
