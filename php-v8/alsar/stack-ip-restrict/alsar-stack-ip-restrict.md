# alsar/stack-ip-restrict

> 标签: ip restrict, stack, stack middleware

## 简介

Stack middleware for allowing application access for specific IP addresses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
