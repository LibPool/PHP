# monsieurbiz/sylius-no-commerce-plugin

> 标签: monsieurbiz, sylius, sylius-plugin

## 简介

Disable the e-commerce on your Sylius.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
