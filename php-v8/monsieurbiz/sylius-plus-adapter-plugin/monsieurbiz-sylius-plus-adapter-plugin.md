# monsieurbiz/sylius-plus-adapter-plugin

> 标签: monsieurbiz, sylius, sylius-plugin

## 简介

This plugin offer tools to adapt your plugins to Sylius Plus RBAC system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
