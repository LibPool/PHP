# monsieurbiz/sylius-shipping-slot-plugin

> 标签: monsieurbiz, sylius, sylius-plugin

## 简介

A Sylius plugin which allow you to choose a delivery date and time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
