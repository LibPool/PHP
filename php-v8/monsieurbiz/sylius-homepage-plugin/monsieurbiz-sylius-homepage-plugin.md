# monsieurbiz/sylius-homepage-plugin

> 标签: monsieurbiz, sylius, sylius-plugin

## 简介

Add a homepage management to your Sylius using the Rich Editor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
