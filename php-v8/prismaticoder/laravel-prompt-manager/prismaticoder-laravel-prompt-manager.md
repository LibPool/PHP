> 标签: ChatGpt, ai, artificial-intelligence, gpt, language-models, laravel, laravel-package, laravel-prompt, llm, nlp, openai, prompt, prompt-engineering, text-generation

## 简介

Laravel package for seamlessly managing, versioning and testing AI prompts when integrating with LLMs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
