# brianlmoon/php-safelist-check

> 标签: cidr, ipv4, ipv6, safelist

## 简介

Provides a simple way to check whether an address or domain is on a safelist

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
