# codestudios/php-chrome-html2pdf

> 标签: chrome, headless, html, html2pdf, pdf, php, puppeteer

## 简介

A PHP library for converting HTML to PDF using Google Chrome

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
