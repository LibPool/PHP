# dhluther/yii2-swivel

> 标签: Behavior, component, extension, helper, swivel, yii2

## 简介

A Yii 2.0 plugin to provide easy access and integration with zumba/swivel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
