# duyld2108/laravel-file-manager

> 标签: CKEditor, Webp, avif, file, filemanager, image, intervention, laravel, manager, media, resize, tinymce

## 简介

Standalone Advanced File Manager for Laravel with Intervention Image v4.1+ support, auto image resizing, WebP/AVIF conversion, disk thumbnail cache and enterprise security

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
