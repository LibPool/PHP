# cryptoway/php-sdk

> 标签: USDT, bitcoin, crypto, cryptocurrency, cryptoway, hmac, invoice, payment, payment-gateway, sdk, webhook

## 简介

PHP SDK for the Cryptoway crypto payment gateway: invoices paid on Cryptoway's page or on your own, permanent deposit addresses per customer, webhook checks and the money rules the shop plugins use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
