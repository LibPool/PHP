# notfoundnl/siteboss-framework

> 标签: NotFound, laravel, siteboss-framework

## 简介

SiteBoss® framework is a headless CMS for Laravel. It will produce a JSON for a UI to consume.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
