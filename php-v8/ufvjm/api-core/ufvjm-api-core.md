# ufvjm/api-core

> 标签: api, laravel, ufvjm

## 简介

Pacote de funcionalidades básicas para autenticação e comunicação com a APIs dos sistemas da UFVJM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
