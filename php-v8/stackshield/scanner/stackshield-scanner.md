# stackshield/scanner

> 标签: Audit, ci, composer-audit, devsecops, laravel, scanner, security, security-headers, static-analysis

## 简介

Run Laravel security posture checks locally from inside your application. Config and runtime checks that pair with StackShield's outside-in scanning. No account required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
