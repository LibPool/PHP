# activeants/magento2-byteapifix

> 标签: ActiveAnts, PHPCGI, byte, cgi, magento2

## 简介

Module to fix the missing Authorization header under PHP in CGI mode.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
