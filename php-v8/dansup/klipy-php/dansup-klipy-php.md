# dansup/klipy-php

> 标签: clips, gif, klipy, laravel, memes, php, stickers

## 简介

PHP / Laravel client for the Klipy API (GIFs, Stickers, Clips, Memes, AI Emojis).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
