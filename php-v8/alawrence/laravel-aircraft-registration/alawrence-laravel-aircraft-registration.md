# alawrence/laravel-aircraft-registration

> 标签: aircraft, aircraft registrations, laravel, lumen, registrations, validation

## 简介

Validation and information package for worldwide aircraft registrations, for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
