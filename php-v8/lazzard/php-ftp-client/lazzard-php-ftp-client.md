# lazzard/php-ftp-client

> 标签: ftp-client, ftp-library, php, php-ftp-client

## 简介

This library provides helper classes and methods to manage your FTP files in an OOP way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
