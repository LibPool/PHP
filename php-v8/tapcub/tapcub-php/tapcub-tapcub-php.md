# tapcub/tapcub-php

> 标签: analytics, events, product-analytics, server-side, tapcub, tracking

## 简介

TapCub server-side SDK for PHP: events, sign-ups, identities, user profiles, items and accounts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
