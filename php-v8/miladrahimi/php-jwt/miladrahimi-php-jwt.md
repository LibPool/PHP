# miladrahimi/php-jwt

> 标签: JSON Web Token, decoder, encoder, jwt, parser, token, validator, verifier

## 简介

A PHP implementation of JWT (JSON Web Token) generator, parser, verifier, and validator

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
