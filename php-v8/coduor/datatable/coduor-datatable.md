# coduor/datatable

> 标签: ajax, datatables, jquery, laravel

## 简介

This is a laravel 7 package for the server and client side of datatablaes at http://datatables.net/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
