# bako/behat-selenium-animator

> 标签: Behat, animation, animator, gif, selenium, testing

## 简介

Generate gif animation from behat selenium steps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
