# makinacorpus/simple-xml-reader

> 标签: SimpleXML, XMLReader, iterator, xml

## 简介

Extends XMLReader PHP class, for simple SAX-reading and XPath queries of huge XML files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
