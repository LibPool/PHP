# makinacorpus/goat-query

> 标签: database, mysql, orm, pdo, postgresql, symfony

## 简介

Goat SQL query builder built over a PHP to SQL and SQL to PHP type converter

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
