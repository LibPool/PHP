# svent/pageclasses

> 标签: Pageclasses, TYPO3 CMS, TYPO3 Extension, body tag, css

## 简介

Adding one or more CSS classes to the body tag of the rendered pages. The extension provides inheritance, separate handling of subpages and includes classes for frontend- and backend-layouts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
