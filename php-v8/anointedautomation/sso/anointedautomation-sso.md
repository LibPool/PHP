# anointedautomation/sso

> 标签: SSO, anointed-automation, laravel, oidc, openid-connect, pkce

## 简介

Sign in with Anointed Automation for PHP and Laravel: OpenID Connect authorization code + PKCE S256, ID token verification, logout and back-channel logout.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
