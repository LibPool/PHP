# hipdevteam/elementor-converter-bridge

> 标签: elementor, elementor-pro, kit, migration, rest-api, theme-builder, wordpress, wordpress-plugin

## 简介

Secure REST endpoints for the Elementor Converter Platform to create/update WordPress pages, Elementor Theme Builder templates, and apply Elementor kit globals + Custom Fonts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
