# hipdevteam/bb-post-categories

> 标签: PHP

## 简介

Beaver Builder Module to display Post Categories list. Allows explicitly including/excluding certain categories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
