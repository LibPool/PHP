# hipdevteam/ion-mu

> 标签: hipdevteam, ion-mu, mu-plugin, site-intelligence, wp-activity-logger

## 简介

ION MU — WordPress mu-plugin that fire-and-forgets activity events to Site Intelligence

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
