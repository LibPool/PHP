# hipdevteam/hip-bb-gallery

> 标签: PHP

## 简介

Custom fork of Beaver Builder Gallery Module. Support for full width collages as well as more traditional grid layouts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
