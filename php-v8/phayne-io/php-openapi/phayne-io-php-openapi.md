# phayne-io/php-openapi

> 标签: api, api-specification, openapi, php, schema, swagger

## 简介

Read and write OpenAPI yaml/json files and make the content accessable in PHP objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
