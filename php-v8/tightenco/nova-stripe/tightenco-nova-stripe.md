# tightenco/nova-stripe

> 标签: laravel, nova, stripe, tighten, tightenco

## 简介

A tool to create a quick Stripe dashboard in your Laravel Nova admin panels

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
