# mlevent/tcmb

> 标签: PHP

## 简介

TCMB'ın yayınladığı döviz kuru bilgilerine günlük ya da geçmişe dönük ulaşabilir, para birimlerini dönüştürebilirsiniz.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
