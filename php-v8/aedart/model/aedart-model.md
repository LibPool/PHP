# aedart/model

> 标签: dto, getter, model, setter

## 简介

Collection of getter- / setter-interfaces with various trait implementations, for different kinds of 'common' properties.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
