# leandroibarra/lumen-request-parser

> 标签: PHP

## 简介

A request query parameter parser for REST-APIs based on ngabor84/lumen-api-query-parser and for Laravel's Lumen framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
