# shawty81/multiprocessor

> 标签: PHP

## 简介

Easy usable class for very fast and memory efficient scripts, processing lots of data by utilizing the power of pcntl_fork()

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
