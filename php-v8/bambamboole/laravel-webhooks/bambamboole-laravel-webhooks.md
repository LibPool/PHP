# bambamboole/laravel-webhooks

> 标签: laravel, webhooks

## 简介

Attribute-driven outgoing webhooks for Laravel: discover webhook events, manage subscriptions, deliver signed payloads.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
