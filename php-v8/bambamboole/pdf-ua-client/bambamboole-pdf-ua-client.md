# bambamboole/pdf-ua-client

> 标签: accessibility, laravel, pdf, pdf-ua

## 简介

Laravel client for rendering accessible PDF/UA documents with pdf-ua-api.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
