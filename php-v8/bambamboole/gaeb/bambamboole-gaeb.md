# bambamboole/gaeb

> 标签: AVA, bambamboole, boq, gaeb, parser, writer, xml

## 简介

A small PHP library to parse, write and validate GAEB DA XML 3.3 files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
