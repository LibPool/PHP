# bambamboole/extended-testbench

> 标签: TestBench, ai, boost, laravel, package-development

## 简介

Extends Orchestra Testbench for Laravel package development - makes Laravel Boost work out of the box.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
