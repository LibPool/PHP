# bambamboole/laravel-oidc-server

> 标签: laravel, oauth2, oauth2-server, oidc, openid-connect

## 简介

OpenID Connect provider (server) for Laravel — the engine behind bambamboole/laravel-oidc

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
