# bestyii/yii2-easywechat

> 标签: bestyii, easywechat, php, wechat, yii2

## 简介

WeChat SDK for yii2, 基于 w7corp/easywechat

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
