# bestyii/yii2-easy-wechat

> 标签: bestyii, easywechat, php, wechat, yii2

## 简介

WeChat SDK for yii2, 基于 overtrue/easywechat

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
