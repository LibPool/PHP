# webtechsolutions/module-ai-async-processor

> 标签: PHP

## 简介

Generic asynchronous AI task processing infrastructure (RabbitMQ/AMQP) for Magento 2, decoupling synchronous AI API calls from the HTTP request-response cycle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
