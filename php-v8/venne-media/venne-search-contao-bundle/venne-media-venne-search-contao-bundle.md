# venne-media/venne-search-contao-bundle

> 标签: contao, contao-bundle, fulltext, meilisearch, pdf, search

## 简介

Volltext-Suche für Contao mit Live-Indexing von Seiten und Datei-Inhalten (PDF, DOCX, ODT, RTF). Tippfehler-Toleranz, mehrsprachig, ACL-aware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
