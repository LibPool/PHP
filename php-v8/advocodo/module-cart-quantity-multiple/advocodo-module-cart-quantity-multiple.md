# advocodo/module-cart-quantity-multiple

> 标签: cart, checkout, magento, magento2, multiple, php

## 简介

Only allows checkout when cart contents are multiple of X.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
