# joopschilder/reactphp-input-stream

> 标签: PHP

## 简介

Wraps a non-blocking input to behave like a stream so it can be used in a ReactPHP EventLoop

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
