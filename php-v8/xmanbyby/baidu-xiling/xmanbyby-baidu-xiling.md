# xmanbyby/baidu-xiling

> 标签: PHP

## 简介

百度羲灵（Xiling）数字人音视频合成SDK，基于Guzzle的PHP客户端。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
