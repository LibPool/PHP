# folivaresrios/chileanrut

> 标签: chile, chileanrut, rut

## 简介

Package entrega una serie de metodos que permite verificar la validez del Rut Chileno.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
