# tomgould/turbopush

> 标签: chunked-upload, file-upload, large-files, resumable-upload, upload

## 简介

PHP endpoint for TurboPush chunked uploads: validates, stores and safely reassembles file chunks sent by the TurboPush browser client.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
