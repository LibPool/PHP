# fullscreeninteractive/silverstripe-keyvaluefield

> 标签: silverstripe, versioned

## 简介

A Silverstripe FormField for extending TextField with several parts (keys)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
