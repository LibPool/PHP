# fullscreeninteractive/silverstripe-manyfield

> 标签: silverstripe, versioned

## 简介

SilverStripe FormField for adding dynamic data to forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
