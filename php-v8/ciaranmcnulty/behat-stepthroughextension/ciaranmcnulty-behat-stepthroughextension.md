# ciaranmcnulty/behat-stepthroughextension

> 标签: BDD, Behat, TDD

## 简介

Extension for behat to help debug failing scenarios

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
