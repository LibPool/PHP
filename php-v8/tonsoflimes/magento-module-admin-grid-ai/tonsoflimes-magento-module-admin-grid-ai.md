# tonsoflimes/magento-module-admin-grid-ai

> 标签: PHP

## 简介

Magento2 module that adds AI capabilities to admin grids (filters, columns, mass actions) using OpenAI's-compatible API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
