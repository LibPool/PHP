# shintio/yii2-proxy-httpclient

> 标签: curl, extension, httpclient, proxy, yii2

## 简介

Native httpclient with custom or autoparsed free proxy servers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
