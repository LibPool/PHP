# lawnstarter/laravel-darksky

> 标签: darksky, laravel, laravel-darksky, lawnstarter

## 简介

Provides a Wrapper for the DarkSky API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
