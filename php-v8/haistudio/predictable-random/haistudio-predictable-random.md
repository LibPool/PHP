# haistudio/predictable-random

> 标签: Craft, cms, craft-plugin, craftcms, predictable-random

## 简介

Generates a predictable random number based on a starting seed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
