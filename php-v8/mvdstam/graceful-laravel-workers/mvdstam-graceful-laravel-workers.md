# mvdstam/graceful-laravel-workers

> 标签: graceful, laravel, queue, workers

## 简介

Provides a way to stop Laravel Worker daemons (and jobs) gracefully.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
