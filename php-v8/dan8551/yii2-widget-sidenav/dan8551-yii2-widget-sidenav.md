# dan8551/yii2-widget-sidenav

> 标签: bootstrap, extension, jquery, menu, navigation, plugin, sidenav, widget, yii2

## 简介

Simple Sidebar is an off canvas sidebar navigation template for Bootstrap created by Start Bootstrap. Extended for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
