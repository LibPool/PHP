# janiv/shelf

> 标签: BGG, Board Game, BoardGameGeek

## 简介

BoardGameGeek API 2.0 Wrapper for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
