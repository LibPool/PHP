# talaria/talaria

> 标签: apm, error-tracking, logging, psr-3, talaria, tracing

## 简介

Official PHP SDK for Talaria — exceptions, PSR-3 logging, batched ingest, and optional tracing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
