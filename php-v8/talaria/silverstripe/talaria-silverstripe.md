# talaria/silverstripe

> 标签: apm, error-tracking, monolog, silverstripe, talaria

## 简介

Silverstripe adapter for Talaria — Monolog, Injector, browser SDK inject, and optional request/DB/queue tracing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
