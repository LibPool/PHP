# guisehn/willdurand-nmap

> 标签: PHP

## 简介

nmap is a PHP wrapper for Nmap, a free security scanner for network exploration. Updated for PHP 7.1

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
