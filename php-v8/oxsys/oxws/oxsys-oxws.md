# oxsys/oxws

> 标签: framework, oxws, websites

## 简介

Oxws, sigla para Oxsys Websites, é um framework que possibilita criar Websites e uma forma simples, rápida e eficiente.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
