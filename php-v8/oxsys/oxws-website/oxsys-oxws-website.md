# oxsys/oxws-website

> 标签: framework, oxws, website

## 简介

Website reutilizável do Oxws, modifique livremente os módulos para adequar ao seu projeto.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
