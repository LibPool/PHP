# amici/craft-super-dynamic-fields

> 标签: amici, checkboxes, custom, dropdown, dynamic, json, multi select, options, radio, select

## 简介

Use JSON templates as field options for dropdown, radio, checkboxes, or multi-select.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
