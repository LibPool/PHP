# mikica/zf2-qrcode-bitcoin

> 标签: bitcoin, qrcode, zf2

## 简介

Create bitcoin QR code - Zend 2 form helper

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
