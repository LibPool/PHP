# tomcan/soundtouchapi

> 标签: Bose, SoundTouch

## 简介

SoundTouchApi is a library that allows you to control SoundTouch enabled Bose speakers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
