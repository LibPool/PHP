# acunsoft/acun-ui

> 标签: PHP

## 简介

Acun UI for Laravel, free: Blade and Livewire components (<acun:*>), the Tailwind CSS theme and the Alpine.js runtime in one package. npm takes the CSS and JS from the Composer copy: "@acunsoft/acun-ui": "file:vendor/acunsoft/acun-ui". The panel layouts and menu, the paid components, form modals and e-commerce are in acunsoft/acun-pro.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
