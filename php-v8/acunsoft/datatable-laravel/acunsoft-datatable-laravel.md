# acunsoft/datatable-laravel

> 标签: acun-datatable, datatable, eloquent, laravel

## 简介

Laravel and Livewire for Acun DataTable: an allowlisted, Turkish-aware Eloquent query layer, a JSON endpoint for the HTTP data source and a Livewire table trait with accessible Blade views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
