# sudnonk/furigana-tsukeruyatsu

> 标签: PHP

## 简介

英数字にフリガナを振るライブラリです。This library converts alphabet and numbers to Japanese ruby in Hiragana and Katakana.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
