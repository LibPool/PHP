# donutsnl/glpisaml

> 标签: Authentication, glpi, plugins

## 简介

Full refactor of the initial phpSaml plugin for GLPI to comply with PSR and utilize native GLPI objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
