# guzzlehttp/retry-subscriber

> 标签: Guzzle, http, retry

## 简介

Retries failed HTTP requests using customizable retry strategies (Guzzle 4+)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
