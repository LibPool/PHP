# roundly-consulting/geolocation-for-laravel

> 标签: geocoding, geolocation, ip-geolocation, laravel, roundly-consulting

## 简介

Resolve a client's location and travel distance through pluggable geolocation providers for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
