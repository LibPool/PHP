# roundly-consulting/jwt-for-laravel

> 标签: HS256, JWS, auth, jwt, laravel, roundly-consulting, rs256

## 简介

Native RS256 user tokens and HS256 service tokens, guards, jti denylist and claim-based authorization for Laravel — zero third-party crypto.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
