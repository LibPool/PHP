# roundly-consulting/connections-for-laravel

> 标签: Relationships, connections, laravel, permissions, roundly-consulting

## 简介

Many-to-many connections between Eloquent models with permissions and expirations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
