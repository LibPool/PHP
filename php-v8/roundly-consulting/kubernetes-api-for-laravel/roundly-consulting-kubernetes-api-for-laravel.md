# roundly-consulting/kubernetes-api-for-laravel

> 标签: Roundly Consulting, kubernetes, kubernetes-api, laravel, traefik

## 简介

A fluent, Eloquent-style client for the Kubernetes API in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
