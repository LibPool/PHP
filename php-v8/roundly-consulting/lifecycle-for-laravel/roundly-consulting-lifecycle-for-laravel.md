# roundly-consulting/lifecycle-for-laravel

> 标签: audit-trail, expiry, laravel, lifecycle, roundly-consulting, state-machine, status, transitions, workflow

## 简介

Status lifecycles for Eloquent models: guarded named transitions, limits and quotas, expiry and scheduled transitions, rollbacks and an append-only history.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
