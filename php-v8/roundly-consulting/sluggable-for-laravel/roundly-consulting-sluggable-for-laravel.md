# roundly-consulting/sluggable-for-laravel

> 标签: i18n, jsonb, laravel, roundly-consulting, route-model-binding, seo, slug, sluggable

## 简介

Single- and multi-language (json/jsonb locale-map) slugs for Eloquent: multiple columns per model, scoped per-locale uniqueness with engine-native indexes, locale-aware route binding, SEO slug history — native, zero third-party deps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
