# roundly-consulting/refresh-tokens-for-laravel

> 标签: auth, laravel, refresh-token, rotation, roundly-consulting, security, sessions

## 简介

Opaque, rotating refresh tokens and device sessions for Laravel — SHA-256 at rest, atomic anti-double-spend rotation, family revocation on reuse. Zero third-party runtime deps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
