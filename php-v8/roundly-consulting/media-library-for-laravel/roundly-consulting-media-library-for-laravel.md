# roundly-consulting/media-library-for-laravel

> 标签: laravel, media, media-library, roundly-consulting, storage, uploads

## 简介

Native Laravel media library: polymorphic media buckets, multi-disk storage, and global media.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
