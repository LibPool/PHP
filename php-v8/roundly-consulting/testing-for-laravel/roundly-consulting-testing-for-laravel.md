# roundly-consulting/testing-for-laravel

> 标签: TestBench, laravel, pest, roundly-consulting, testing

## 简介

Dev-only test machinery for Laravel packages and apps: base test cases, a structural migration-order pin, and Pest expectations that can always fail

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
