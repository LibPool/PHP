# roundly-consulting/money-for-laravel

> 标签: Arbitrary-precision, ECB, bcmath, currency, discounts, exchange-rates, iso-4217, laravel, minor-units, money, roundly-consulting, tax

## 简介

Immutable arbitrary-precision Money and Currency value objects for Laravel: ISO 4217 + custom currencies, exact decimal parsing, rounding-safe arithmetic and allocation, locale formatting, Eloquent casts and schema macros, validation, discounts, tax, and pluggable exchange rates (array, database, ECB).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
