# roundly-consulting/permissions-for-laravel

> 标签: acl, authorization, laravel, permissions, roles, roundly-consulting

## 简介

Native roles & permissions for Laravel — single-guard, cache-backed, additive-grant registry with Gate integration and zero third-party runtime deps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
