# roundly-consulting/package-toolkit-for-laravel

> 标签: blueprint, laravel, macros, package, roundly-consulting, service-provider, toolkit

## 简介

A native, dependency-free toolkit for building Laravel packages: a fluent package-bootstrap builder, schema key-type macros, and database/config/model helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
