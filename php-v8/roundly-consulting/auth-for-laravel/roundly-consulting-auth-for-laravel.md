# roundly-consulting/auth-for-laravel

> 标签: 2fa, Authentication, auth, jwt, laravel, magic-link, otp, passkeys, roundly-consulting, sessions

## 简介

Headless multi-guard authentication for Laravel: password, magic link, email OTP and passkey login, 2FA challenges, JWT + rotating refresh sessions, invitations, verification and activity logging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
