# roundly-consulting/google-places-for-laravel

> 标签: distance-matrix, geocoding, google, google-places, laravel, places, roundly-consulting

## 简介

Query the Google Places API — place details, autocomplete, reverse geocoding, and distance matrix — from Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
