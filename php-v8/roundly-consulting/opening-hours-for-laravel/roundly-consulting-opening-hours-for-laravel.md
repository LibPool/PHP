# roundly-consulting/opening-hours-for-laravel

> 标签: availability, booking-slots, business-hours, dst, holidays, laravel, opening-hours, roundly-consulting, schedules, timezone

## 简介

Opening hours, seasonal schedules, exceptions and bookable availability for any Eloquent model — DST-correct, native, zero third-party deps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
