# roundly-consulting/git-for-laravel

> 标签: bitbucket, git, github, gitlab, laravel, roundly-consulting

## 简介

Access git repositories (GitHub, GitLab, Bitbucket) through a single Laravel-native API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
