# roundly-consulting/tags-for-laravel

> 标签: autocomplete, categories, hierarchical, labels, laravel, multilingual, roundly-consulting, tagging, tags, taxonomy

## 简介

Typed taxonomies for any Eloquent model: flat or nested, single- or multi-select, curated or free-form, tenant-scoped and translatable, with autocomplete, usage counts and query scopes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
