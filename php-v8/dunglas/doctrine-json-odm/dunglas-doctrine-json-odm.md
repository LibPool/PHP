# dunglas/doctrine-json-odm

> 标签: database, json, mysql, odm, orm, postgresql, rdbms

## 简介

An object document mapper for Doctrine ORM using JSON types of modern RDBMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
