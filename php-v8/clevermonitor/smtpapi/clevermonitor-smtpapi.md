# clevermonitor/smtpapi

> 标签: CleverAIM, CleverMonitor, api, clever, email, mail, mailing, newsletter

## 简介

Compatible version of PHP SMTP API Client for CleverAIM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
