# micschk/silverstripe-asset_icons

> 标签: Thumbnails, asset-admin, icons, pdf, silverstripe

## 简介

Category-coloured file-type icons and rendered preview thumbnails (PDF, SVG, EPS) for Silverstripe's Asset Admin and UploadField

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
