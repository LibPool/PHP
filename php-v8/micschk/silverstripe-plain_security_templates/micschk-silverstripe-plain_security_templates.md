# micschk/silverstripe-plain_security_templates

> 标签: security, silverstripe, templates, theme

## 简介

Templates for security pages to mirror CMS styling (login etc)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
