# micschk/silverstripe-svg-images

> 标签: assets, image, silverstripe, silverstripe-module, svg, svg-sanitizer, uploads, vector

## 简介

SVG as real images in Silverstripe 5 and 6: CMS thumbnails and previews, vector resize/crop/fill in templates, and sanitized uploads

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
