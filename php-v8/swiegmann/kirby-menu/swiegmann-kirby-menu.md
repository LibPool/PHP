# swiegmann/kirby-menu

> 标签: kirby-plugin, menu, navigation

## 简介

This Kirby CMS-Plugin lets you build and render structured menues with a variety of features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
