# swiegmann/kirby-alternate-snippets

> 标签: kirby, kirby-plugin, snippets

## 简介

This Kirby CMS-Plugin applies custom snippets based on slugs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
