# rikkonem/watermarklite-plugin

> 标签: image, october, octobercms, plugin, upload, watermark

## 简介

OctoberCMS plugin which allows to add watermark to uploaded images automatically

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
