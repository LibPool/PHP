# mofing/omnipay-alipay

> 标签: alipay, gateway, merchant, omnipay, pay, payment, purchase

## 简介

Alipay gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
