# polashmahmud/inertia-toast

> 标签: inertiajs, laravel, notification, toast, vue

## 简介

Simple InertiaJS + Vue + Laravel toast notification system using vue-sonner.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
