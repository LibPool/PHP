# huoxin/auto-image-dimensions

> 标签: flarum

## 简介

Automatically fetches and applies width and height dimensions to Flarum image tags to prevent layout shift (CLS).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
