# jhuet/zdt-logger-module

> 标签: log, module, zdt, zf3

## 简介

A ZF3 module to log data using Zend\Log and write them to ZendDeveloperTools toolbar.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
