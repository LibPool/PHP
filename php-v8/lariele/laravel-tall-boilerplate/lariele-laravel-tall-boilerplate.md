# lariele/laravel-tall-boilerplate

> 标签: framework, laravel

## 简介

Boilerplate with Lariele components created with Tailwind CSS, Alpine JS, Laravel, Livewire - TALL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
