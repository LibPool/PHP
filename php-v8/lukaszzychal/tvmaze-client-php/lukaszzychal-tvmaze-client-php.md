# lukaszzychal/tvmaze-client-php

> 标签: api, episodes, http-client, psr-18, shows, tv, tvmaze

## 简介

PSR-18 PHP client for the TVMaze API (shows, people, schedules, episodes, cast)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
