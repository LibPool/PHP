# prolix/image-bundle

> 标签: Symfony2, bundle, form, image, local, picture, remote

## 简介

Allow to crop local and remote image before uploading them through a classic form.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
