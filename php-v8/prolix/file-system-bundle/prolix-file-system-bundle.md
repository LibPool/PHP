# prolix/file-system-bundle

> 标签: File abstraction layer, filesystem, gaufrette

## 简介

Symfony Kitpages FileSystem Bundle. Abstraction layer for files (local, S3)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
