# prolix/restclientbundle

> 标签: REST client curl POST GET PUT DELETE OPTIONS CONNECT PATCH TRACE HEAD content-type payload library plugin

## 简介

Provides REST request methods. Mapper bundle for php internal curl library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
