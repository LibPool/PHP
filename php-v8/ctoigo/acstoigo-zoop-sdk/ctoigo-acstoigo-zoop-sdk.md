# ctoigo/acstoigo-zoop-sdk

> 标签: acstoigo, checkout, ctoigo, intermediary, libraries, marketplace, sdk, toigo, zoop

## 简介

API para integração com a ZOOP para boleto e cartão.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
