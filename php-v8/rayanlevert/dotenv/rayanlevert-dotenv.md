# rayanlevert/dotenv

> 标签: dotenv, env, php

## 简介

Dependency-free environment file handler (.env) loading variables and its values in $_ENV, $_SERVER and getenv() in the PHP userland

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
