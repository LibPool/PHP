# voltra/filament-svg-avatar

> 标签: Voltra, avatar, filament, filament-svg-avatar, laravel, laravel-filament

## 简介

Change the default avatar url provider with one for inline SVGs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
