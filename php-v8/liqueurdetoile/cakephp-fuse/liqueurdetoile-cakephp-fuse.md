# liqueurdetoile/cakephp-fuse

> 标签: database, filter, fuse, fuzzy, orm

## 简介

Cakephp 3/4 plugin that implements fuzzy search based on Fuse

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
