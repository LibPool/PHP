# floopfloop/sdk

> 标签: API-Client, floopfloop, sdk, vibe-coding

## 简介

Official PHP SDK for the FloopFloop API — build, refine, and manage FloopFloop projects from any PHP codebase.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
