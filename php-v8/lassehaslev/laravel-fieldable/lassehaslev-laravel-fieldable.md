# lassehaslev/laravel-fieldable

> 标签: PHP

## 简介

Add functionality to add field and values dynamicly to laravel. How you use them is up to you.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
