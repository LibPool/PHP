# klevu/module-m2-indexing-products-exclude-by-visibility

> 标签: PHP

## 简介

Add-on module to klevu/module-m2-indexing-products to exclude product indexing based on global visibility

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
