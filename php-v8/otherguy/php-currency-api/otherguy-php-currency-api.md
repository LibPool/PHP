# otherguy/php-currency-api

> 标签: currency, currency-api, currency-conversion, currency-converter, currency-rates, exchange-rate-api, exchange-rates, fluent-interface, php8, psr-18

## 简介

A PHP API Wrapper to offer a unified programming interface for popular Currency Rate APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
