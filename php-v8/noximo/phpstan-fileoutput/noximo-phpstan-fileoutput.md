# noximo/phpstan-fileoutput

> 标签: Error formatter, PHPStan, file output

## 简介

An error formatter for PHPStan that exports analysis result into HTML file

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
