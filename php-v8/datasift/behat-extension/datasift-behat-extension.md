# datasift/behat-extension

> 标签: Behat, api, datasift, ms-lib-testrest, restful, testing, testrest

## 简介

Library to test end-to-end RESTful services using Behat

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
