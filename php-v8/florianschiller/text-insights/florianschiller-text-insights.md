# florianschiller/text-insights

> 标签: reading-time, text-analysis, ukrainian, word-count

## 简介

A lightweight PHP library for analyzing Ukrainian UTF-8 text.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
