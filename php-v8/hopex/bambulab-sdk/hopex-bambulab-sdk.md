# hopex/bambulab-sdk

> 标签: 3d-printer, bambu-lab, bambulab, ftps, mqtt, php, sdk

## 简介

Typed PHP SDK for local control and monitoring of Bambu Lab 3D printers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
