# vanio/vanio-domain-bundle

> 标签: Domain Driven, ddd, doctrine

## 简介

Symfony2 Bundle providing some additional features suitable when programming your domain.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
