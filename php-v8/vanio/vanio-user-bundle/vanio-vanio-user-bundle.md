# vanio/vanio-user-bundle

> 标签: bundle, oauth, user

## 简介

Symfony2 Bundle integrating FOSUserBundle and HWIOAuthBundle with some additional features and sane defaults

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
