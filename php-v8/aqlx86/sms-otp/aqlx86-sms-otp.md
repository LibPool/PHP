# aqlx86/sms-otp

> 标签: isms, laravel, otp, sms

## 简介

SMS OTP for Laravel 5 using iSMS gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
