# psyllium/amqp

> 标签: PHP

## 简介

Symfony psyllium adapter for amqp

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://bitbucket.org/ebrandpl/amqp
- 源码仓库：https://bitbucket.org/ebrandpl/amqp.git
- Packagist 页面：https://packagist.org/packages/psyllium%2Famqp

## 获取地址

- Composer 安装：`composer require psyllium/amqp`
- Packagist 仓库：https://repo.packagist.org/p2/psyllium/amqp.json
- PHP 要求：^8.3
