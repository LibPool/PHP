# emran-alhaddad/statamic-graphql-protect

> 标签: PHP

## 简介

Protect Statamic /graphql (rebing/graphql-laravel) with token + optional IP allow list.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
