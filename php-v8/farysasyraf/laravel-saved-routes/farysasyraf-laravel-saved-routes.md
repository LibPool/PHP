# farysasyraf/laravel-saved-routes

> 标签: admin, database routes, dynamic routes, laravel, roles, routes

## 简介

Add routes to a Laravel app from a page in the app: each one stored in the database, pointing to one of your controllers, open to everyone logged in or only to chosen roles.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
