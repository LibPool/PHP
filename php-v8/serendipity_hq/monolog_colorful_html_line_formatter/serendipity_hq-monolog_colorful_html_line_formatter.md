# serendipity_hq/monolog_colorful_html_line_formatter

> 标签: colorful, formatter, html, monolog

## 简介

Formats Monolog's log lines to make them colorful when displayed in HTML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
