# serendipity_hq/oauth-guzzle-middleware

> 标签: Guzzle, oauth

## 简介

OAuth middleware for Guzzle (6+)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
