# luwes/craft3-codemirror

> 标签: Craft, cms, codemirror, craft-plugin, craftcms

## 简介

Add the awesome in-browser code editor CodeMirror as a field type.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
