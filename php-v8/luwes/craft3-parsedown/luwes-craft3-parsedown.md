# luwes/craft3-parsedown

> 标签: Craft, cms, craft-plugin, craftcms, parsedown

## 简介

Adds Parsedown, the PHP Markdown parser to Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
