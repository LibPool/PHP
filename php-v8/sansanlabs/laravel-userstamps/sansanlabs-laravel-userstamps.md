# sansanlabs/laravel-userstamps

> 标签: created_by, deleted_by, eloquent, laravel, model-events, updated_by, userstamps

## 简介

Package to add userstamps to models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
