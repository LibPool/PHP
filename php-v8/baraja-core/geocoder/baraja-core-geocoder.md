# baraja-core/geocoder

> 标签: PHP

## 简介

Rewrite real address to geo coordinates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/baraja-core/geocoder
- 源码仓库：https://github.com/baraja-core/geocoder.git

## 获取地址

- Composer 安装：`composer require baraja-core/geocoder`
- Packagist 仓库：https://repo.packagist.org/p2/baraja-core/geocoder.json
- PHP 要求：^8.0
