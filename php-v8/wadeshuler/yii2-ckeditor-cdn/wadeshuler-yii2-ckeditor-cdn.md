# wadeshuler/yii2-ckeditor-cdn

> 标签: CKEditor, cdn, extension, widget, yii2

## 简介

My restriction free version of a CKEditor CDN extension for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
