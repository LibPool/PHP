# adrianjean/matrix-horizontal-columns

> 标签: Craft, cms, columns, craft-plugin, craftcms, grid, matrix, page builder

## 简介

Lays out nested Matrix column entries side-by-side on a 12-column grid in the control panel, with drag-and-drop reordering in any direction.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
