# thewebsolver/tws-admin-onboarding

> 标签: admin, onboarding, plugin, theme, wizard, wordpress

## 简介

An easy and extendible admin onboarding wizard for WordPress Plugins and Themes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
