# php-n8n/client

> 标签: API-Client, automation, composer, n8n, n8n-client, php, php-client, psr, psr-17, psr-18, webhook, webhooks, workflow, workflow-automation

## 简介

A lightweight, strongly typed PHP client for triggering n8n webhooks and tracking workflow executions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
