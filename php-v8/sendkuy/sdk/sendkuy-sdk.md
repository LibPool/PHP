# sendkuy/sdk

> 标签: email, indonesia, messaging, notifications, otp, sendkuy, sms, whatsapp, whatsapp-api

## 简介

PHP SDK for the SendKuy API: send WhatsApp, SMS and email from your own code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 源码仓库：https://github.com/sendkuy/sendkuy-php.git
