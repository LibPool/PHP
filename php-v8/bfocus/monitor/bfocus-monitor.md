# bfocus/monitor

> 标签: bfocus, error tracking, erros, exceptions, laminas, laravel, mezzio, monitor, monitoramento, psr-15

## 简介

Monitoramento de erros do bFocus para PHP: captura os erros não tratados e manda para o bFocus, onde viram demanda. Laravel e PSR-15 (Laminas/Mezzio/Slim).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
