# imyangjin/yii2-mysql-json

> 标签: extension, json, mysql, mysql json, yii2

## 简介

extend yii2-ActiceRecord And yii2-ActiveQuery with use mysql json make simple.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
