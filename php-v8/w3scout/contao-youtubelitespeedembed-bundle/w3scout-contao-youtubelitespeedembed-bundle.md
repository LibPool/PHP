# w3scout/contao-youtubelitespeedembed-bundle

> 标签: bundle, contao, content element, media, video, youtube

## 简介

A lightweight, performance-focused YouTube embed element that drastically reduces page weight and load time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
