# dashworthy/foundry

> 标签: Dashworthy, actions, laravel, queries

## 简介

Single-argument actions and queries with a shared Data object and reusable preconditions for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
