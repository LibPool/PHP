# nodisrupt/laravel-agent

> 标签: composer, laravel, monitoring, nodisrupt, security, vulnerability

## 简介

Reports a Laravel app's installed Composer dependencies to NoDisrupt, so its packages can be matched against known vulnerabilities. For apps that can't be versioned remotely (Laravel Cloud, Vapor, Forge, self-hosted).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
