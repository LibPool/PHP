# aws/aws-sdk-php-zf2

> 标签: amazon, aws, cloudfront, dynamodb, ec2, s3, sqs, zend, zf2

## 简介

Zend Framework 2 Module that allows easy integration the AWS SDK for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
