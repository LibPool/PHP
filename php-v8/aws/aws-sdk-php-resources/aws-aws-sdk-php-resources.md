# aws/aws-sdk-php-resources

> 标签: amazon, aws, cloud, dynamodb, ec2, glacier, s3, sdk

## 简介

A resource-oriented API for interacting with AWS services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
