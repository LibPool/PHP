# bunny/bunny

> 标签: AMQP, bunny, exchange, message, messaging, queue, queueing, rabbit, rabbitmq, react, react-php, reactphp

## 简介

Performant pure-PHP AMQP (RabbitMQ) sync/async (ReactPHP) library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
