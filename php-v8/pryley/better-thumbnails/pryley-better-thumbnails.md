# pryley/better-thumbnails

> 标签: Thumbnails, plugin, wordpress

## 简介

WordPress plugin that adds a Media option to place the image sizes in a sub-directory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
