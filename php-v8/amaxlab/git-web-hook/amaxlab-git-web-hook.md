# amaxlab/git-web-hook

> 标签: HOOK, git, php, web, web-hook

## 简介

Library for git web hook handle (supported and tested gitlab.com and github.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
