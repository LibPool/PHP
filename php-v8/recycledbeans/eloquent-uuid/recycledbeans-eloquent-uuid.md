# recycledbeans/eloquent-uuid

> 标签: PHP

## 简介

A quick and easy way to use UUID primary keys in Laravel Eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
