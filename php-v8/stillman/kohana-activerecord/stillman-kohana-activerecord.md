# stillman/kohana-activerecord

> 标签: Active Record, activerecord, ar, database, kohana

## 简介

ActiveRecord pattern for Kohana 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
