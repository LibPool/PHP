# stillman/autoloader

> 标签: PSR-4, autoloader, zend

## 简介

Extended autoloader class with support of PSR-4 and Zend file naming standards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
