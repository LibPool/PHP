# yvkibira/laravel-sitemap-generator

> 标签: PHP

## 简介

Agnostic Laravel sitemap package — discovers routes, excludes by pattern, resolves dynamic parameters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
