# champs-libres/async-uploader-bundle

> 标签: PHP

## 简介

Upload file from browser to openstack swift or amazon s3 (later) using temp-url middleware.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
