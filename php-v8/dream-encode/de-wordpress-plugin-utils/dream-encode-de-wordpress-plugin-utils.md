# dream-encode/de-wordpress-plugin-utils

> 标签: logger, plugin, upgrader, utilities, wordpress

## 简介

Reusable WordPress plugin utilities including upgrader and logger abstracts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
