# fduarte42/zend-expressive-static-files

> 标签: PHP

## 简介

A PSR-15 middleware that serves static assets for you. Is similar to the "serve-static" npm package.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
