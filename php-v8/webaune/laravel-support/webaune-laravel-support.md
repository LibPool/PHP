# webaune/laravel-support

> 标签: contract, helper, laravel, mimetype, support, timezones, trait, validator, webaune

## 简介

Common support helpers, contracts, and traits required by various packages. Validator functionality, and basic controller included out-of-the-box.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
