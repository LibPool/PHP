# yadivyanshu/magento2-order-webhook

> 标签: PHP

## 简介

Magento 2 module that sends order events to a configurable webhook endpoint. Test package for Packagist deployment pipeline.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
