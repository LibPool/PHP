# jwread/lib-allure

> 标签: PHP

## 简介

A set of utilities, helpers and shims. It aims to be pretty modular and lightweight. API Docs are here; http://jamesread.github.io/libAllure/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
