# diiimonn/yii2-widget-spinner-canvas

> 标签: canvas, extension, jquery, loading, spinner, widget, yii2

## 简介

A widget to render canvas with animated loading spinners

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
