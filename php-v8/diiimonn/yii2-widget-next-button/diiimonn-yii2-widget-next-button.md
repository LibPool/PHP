# diiimonn/yii2-widget-next-button

> 标签: ajax, button, extension, jquery, next, widget, yii2

## 简介

Widget render wrap container for a list with next button

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
