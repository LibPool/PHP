# ujnana/pinex

> 标签: components, laravel, livewire, livewire-components, pinex, shadcn, shadcn-ui, tailwind, tailwindcss, ui, ui-components

## 简介

A beautiful, modern component library for Laravel Livewire applications with shadcn/ui inspired design and Tailwind CSS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
