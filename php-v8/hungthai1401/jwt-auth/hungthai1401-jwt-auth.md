# hungthai1401/jwt-auth

> 标签: Authentication, JSON Web Token, auth, jwt, laravel

## 简介

JSON Web Token Authentication for Laravel and Lumen (fork from tymon/jwt-auth)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
