# liquidrazor/file-locator

> 标签: dependency-injection, di-registry, file-discovery, file-locator, filesystem, php

## 简介

Minimal filesystem discovery component for LiquidRazor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
