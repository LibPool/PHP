# liquidrazor/dto-api-bundle

> 标签: PHP

## 简介

A DTO-first Symfony bundle for building boring JSON APIs with streaming responses and autogenerated OpenAPI documentation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
