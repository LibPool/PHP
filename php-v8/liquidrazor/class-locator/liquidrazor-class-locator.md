# liquidrazor/class-locator

> 标签: PSR-4, class-discovery, class-locator, composer, php, validation

## 简介

Minimal deterministic class discovery and validation library for PHP 8.3+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
