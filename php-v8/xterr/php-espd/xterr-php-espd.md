# xterr/php-espd

> 标签: e-procurement, espd, procurement, qualification, ubl, xml, xsd

## 简介

Typed PHP classes for ESPD (European Single Procurement Document) based on ESPD-EDM v4.1.0 / UBL 2.3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
