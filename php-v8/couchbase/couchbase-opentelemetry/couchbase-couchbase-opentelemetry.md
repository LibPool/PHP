# couchbase/couchbase-opentelemetry

> 标签: Metrics, couchbase, observability, opentelemetry, tracing

## 简介

OpenTelemetry integration for the Couchbase PHP Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
