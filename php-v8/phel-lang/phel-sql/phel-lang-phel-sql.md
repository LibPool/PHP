# phel-lang/phel-sql

> 标签: honeysql, lisp, phel, query-builder, sql

## 简介

Data-driven SQL DSL for Phel Lang. HoneySQL-style. Pure data in, [sql params] out.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
