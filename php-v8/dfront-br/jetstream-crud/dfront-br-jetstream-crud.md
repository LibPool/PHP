# dfront-br/jetstream-crud

> 标签: laravel, livewire-crud

## 简介

Scaffold Livewire Components, migrations, factory and crud in one command based on database tables

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
