# laraartisan/laraartisan-sso-client

> 标签: PHP

## 简介

Laravel-based SSO package enabling centralized authentication across multiple Laravel applications with secure token-based login and user synchronization

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
