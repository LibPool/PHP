# azumamagus/get-cnpj

> 标签: brasil, brasil-api, cnpj, cnpj-ws, cnpjá, receita-ws

## 简介

Biblioteca PHP para consulta de CNPJ em APIs públicas brasileiras, com fallback entre provedores e rate limiting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
