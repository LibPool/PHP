# xcoreplatform/pricelist-magento2

> 标签: PHP

## 简介

Creates Tier Prices by using the data synchronised with https://github.com/xcoreplatform/magento2-restapi.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
