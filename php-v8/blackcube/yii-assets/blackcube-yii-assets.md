# blackcube/yii-assets

> 标签: assets, manifest, vite, webpack, yii

## 简介

Vite and Webpack asset bundles for Yii with scaffolding command

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/blackcubeio/yii-assets
- 源码仓库：https://github.com/blackcubeio/yii-assets.git
- Packagist 页面：https://packagist.org/packages/blackcube%2Fyii-assets

## 获取地址

- Composer 安装：`composer require blackcube/yii-assets`
