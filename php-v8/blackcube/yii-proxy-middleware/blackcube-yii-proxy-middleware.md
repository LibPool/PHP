# blackcube/yii-proxy-middleware

> 标签: cidr, middleware, proxy, psr-15, trusted-hosts, yii

## 简介

Yiisoft TrustedHostsNetworkResolver fork with CIDR support in withTrustedIps()

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
