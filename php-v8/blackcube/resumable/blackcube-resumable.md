# blackcube/resumable

> 标签: chunked-upload, fileprovider, resumable, upload, yii

## 简介

Resumable.js server side for Yii: chunked upload, preview and delete actions on the temporary store of blackcube/fileprovider

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
