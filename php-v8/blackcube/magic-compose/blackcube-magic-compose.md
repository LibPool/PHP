# blackcube/magic-compose

> 标签: composition, events, getter-setter, magic-methods, magic-properties, method-composition, php-attributes, traits

## 简介

Simple solution for magic methods and method composition using attributes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
