# freepeace13/laraversine

> 标签: distance, eloquent, geolocation, geospatial, gps, haversine, laravel, latitude, longitude, mariadb, mysql, nearby, nearest, postgresql, radius, sqlite

## 简介

Find the nearest locations in Laravel with Eloquent using the haversine formula. Fast bounded radius and nearest-record search on MySQL, MariaDB, PostgreSQL and SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
