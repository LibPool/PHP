# sejator/ws-server-php

> 标签: PHP

## 简介

PHP SDK untuk publish event ke WebSocket Server melalui HTTP dengan HMAC SHA256 signature.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
