# datec/datec-losungen

> 标签: bruedergemeinde, datec, front-end, losungen, watchwords

## 简介

Adds a plugin to display the daily german watchwords (Losungen).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
