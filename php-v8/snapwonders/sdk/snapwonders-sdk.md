# snapwonders/sdk

> 标签: API-Client, ai-image-detection, c2pa, content-credentials, forensics, hide-and-reveal, image-conversion, image-forensics, mcp, media-analysis, snapwonders, steganography, vaultify, watermark-detection

## 简介

Official PHP SDK for the snapWONDERS API — steganography (hide & reveal), forensic media analysis, and format conversion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
