# mishonorarios/mishonorarios-php

> 标签: bhe, boletas, chile, facturacion, honorarios, mishonorarios, sii

## 简介

SDK oficial de MisHonorarios para emitir y consultar boletas de honorarios electrónicas (Chile) desde PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
