# chillerlan/php-qrcode

> 标签: phpqrcode, qr, qr code, qr-reader, qrcode, qrcode-generator, qrcode-reader

## 简介

A QR Code generator and reader with a user-friendly API. PHP 8.2+

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
