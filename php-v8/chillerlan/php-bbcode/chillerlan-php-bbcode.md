# chillerlan/php-bbcode

> 标签: HTML5, bbcode, markdown, parser

## 简介

A powerful, extensive recursive regexp BBCode parser. PHP 7.2+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
