# starbug/testing

> 标签: Starbug, acceptance-testing, fixtures, php, phpunit, testing, web-testing

## 简介

PHPUnit-based web acceptance and database testing utilities for Starbug PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
