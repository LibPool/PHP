# ditliti/php-sdk

> 标签: PHP

## 简介

Official framework-agnostic PHP SDK for Ditliti (works with Symfony, WordPress, or vanilla PHP) - error tracking, tracing, replays, and profiling ingestion.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
