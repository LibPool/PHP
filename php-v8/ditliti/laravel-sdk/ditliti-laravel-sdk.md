# ditliti/laravel-sdk

> 标签: PHP

## 简介

Official Laravel exception reporter SDK for Ditliti (self-hosted error tracking, tracing, replays, and profiling ingestion).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
