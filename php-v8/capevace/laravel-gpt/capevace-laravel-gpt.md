# capevace/laravel-gpt

> 标签: GPT-3, ai, capevace, gpt, language-model, laravel, llm, openai, text-generation

## 简介

A Laravel package for interacting with OpenAI's GPT-3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
