# porro/craft-connector

> 标签: Craft, advisories, craft-plugin, craftcms, end of life, monitoring, porro, security, site health, updates

## 简介

Site health for Craft CMS 4–5: security advisories, end-of-life PHP and Craft, updates, dev mode, migrations and the queue, in a control panel section and dashboard widget. Free; connect Porro to add uptime, SSL, domain and server checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
