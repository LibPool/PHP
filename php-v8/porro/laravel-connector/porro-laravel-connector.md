# porro/laravel-connector

> 标签: laravel, monitoring, porro, security

## 简介

Read-only Porro connector for Laravel: versions, advisories, scheduler, queues, migrations and backups.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
