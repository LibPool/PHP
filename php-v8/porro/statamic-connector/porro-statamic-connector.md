# porro/statamic-connector

> 标签: advisories, end of life, monitoring, porro, security, site health, statamic, statamic-addon, updates

## 简介

Site health for Statamic: security advisories, end-of-life PHP, Laravel and Statamic versions, updates and the scheduler, in a control panel utility and dashboard widget. Free; connect Porro to add uptime, SSL, domain and server checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
