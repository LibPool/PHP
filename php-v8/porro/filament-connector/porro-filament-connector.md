# porro/filament-connector

> 标签: advisories, end of life, filament, filament-plugin, laravel, monitoring, porro, security, site health, updates

## 简介

Site health for Filament 3–5: security advisories, end-of-life PHP and Laravel, Filament and Laravel updates and the scheduler, on a panel page and dashboard widget. Free; connect Porro to add uptime, SSL, domain and server checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
