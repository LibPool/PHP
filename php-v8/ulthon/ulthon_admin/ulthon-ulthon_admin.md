# ulthon/ulthon_admin

> 标签: admin, thinkphp, ulthon, ulthon_admin

## 简介

基于ThinkPHP6.0和layui的快速开发的后台管理系统。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
