# infocyph/otp

> 标签: aotp, email-otp, grid-otp, hmac, hotp, mobile-otp, ocra, otp, passkey, rfc4226, rfc6238, rfc6287, sha, sms-otp, totp, webauthn

## 简介

Standalone OTP and MFA primitives for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
