# infocyph/uid

> 标签: ObjectId, cuid2, id, key, ksuid, nanoid, random-id, rfc4122, rfc9562, snowflake, sonyflake, sortable-id, tbsl, typeid, ulid, unique, uuid, uuidv7, xid

## 简介

High-performance ID toolkit for PHP with UUID, ULID, TypeID, ObjectID, coordinated IDs, and compact ID utilities.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
