# infocyph/cachelayer

> 标签: apcu, cache, mariadb, memcached, memoization, memoize, mongodb, mysql, pdo, postgres, psr-16, psr-6, redis, scylladb, sqlite, tiered-cache, valkey, weakmap

## 简介

PSR-6/PSR-16 cache layer with local, distributed, and cloud adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
