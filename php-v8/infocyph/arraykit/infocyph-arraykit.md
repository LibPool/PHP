# infocyph/arraykit

> 标签: array, collection, config, dot-notation, dotenv, dto, pipeline

## 简介

PHP data and configuration primitives: arrays, collections, dot paths, dotenv, hooks, and DTO hydration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
