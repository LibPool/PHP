# dewsign/pusher-agent

> 标签: PHP

## 简介

Vuex/Axios/Pusher store to enable SPAs to work with remote data without needing to interact with Ajax

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
