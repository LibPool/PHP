# sereny/postgrest

> 标签: database, driver, eloquent, laravel, postgres, postgrest

## 简介

A PostgREST connection driver that lets Laravel Eloquent models talk to a PostgREST server over HTTP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
