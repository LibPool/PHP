# reinerttomas/czech-vocative

> 标签: czech, declension, gender, name, vocative

## 简介

Converts Czech names to vocative case (5th grammatical case) and detects gender from a name.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
