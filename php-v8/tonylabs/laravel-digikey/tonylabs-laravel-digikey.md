# tonylabs/laravel-digikey

> 标签: api, components, digikey, electronics, laravel, oauth2

## 简介

Laravel package for DigiKey Product Information API V4 with OAuth2 authentication

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
