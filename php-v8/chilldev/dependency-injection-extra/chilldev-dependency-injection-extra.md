# chilldev/dependency-injection-extra

> 标签: Symfony2, chilldev, dependency injection

## 简介

Commonly used patterns for Symfony2 DI provided out of the box.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
