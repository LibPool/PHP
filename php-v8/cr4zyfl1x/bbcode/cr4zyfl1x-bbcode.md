# cr4zyfl1x/bbcode

> 标签: bbcode, bbcodeparser, parser, stringformat, stringutil

## 简介

A naive attempt at a BBCode 'parser' written in PHP. It uses regex and thus fails at complex, nested tags.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
