# collab/module-sidebar-cart

> 标签: cart sidebar, magento, magento2

## 简介

Module which allows You to choose if cart dropdown should be replaced by sidebar.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
