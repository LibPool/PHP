# edgedesign/menu-from-headings-generator-bundle

> 标签: PHP

## 简介

Generator, that can parse given html content and create menu structure from headings in it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
