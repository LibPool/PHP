# denisgold/media-module

> 标签: Thumbnails, asgardcms, files, filters, library, media

## 简介

Media module for AsgardCMS. Handles the media library by Denis Stoliarchuk.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
