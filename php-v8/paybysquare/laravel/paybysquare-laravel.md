# paybysquare/laravel

> 标签: bysquare, laravel, pay-by-square, payment, qr, slovakia

## 简介

Laravel integration for paybysquare/php: config defaults, facade, and Blade QR component.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
