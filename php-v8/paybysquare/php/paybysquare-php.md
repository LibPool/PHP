# paybysquare/php

> 标签: IBAN, bysquare, pay-by-square, payment, qr, sepa, slovakia

## 简介

Pay By Square (Slovak payment QR standard) payload generator. Pure PHP, no extensions, no shell-outs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
