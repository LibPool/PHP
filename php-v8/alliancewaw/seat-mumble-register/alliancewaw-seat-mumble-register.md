# alliancewaw/seat-mumble-register

> 标签: eve-online, seat

## 简介

This plugin provide an extension to generate a certificate for SeAT user and regist it to mumble server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
