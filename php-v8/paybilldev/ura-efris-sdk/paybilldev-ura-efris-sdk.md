> 标签: Uganda, api, efris, einvoicing, fiscal, sdk, tax, ura

## 简介

PHP SDK for Uganda Revenue Authority (URA) EFRIS System-to-System (S2S) API integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
