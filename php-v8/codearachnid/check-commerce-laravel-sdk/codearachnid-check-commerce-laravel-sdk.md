# codearachnid/check-commerce-laravel-sdk

> 标签: ach, check-commerce, codearachnid, eCheck, laravel, payments, rtp, sdk

## 简介

Laravel integration for the Check Commerce (OBP Link) API — a service provider, publishable config, facade, cache-backed token store and testing fake around the codearachnid/check-commerce-php-sdk client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
