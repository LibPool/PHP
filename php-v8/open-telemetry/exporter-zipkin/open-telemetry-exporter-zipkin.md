# open-telemetry/exporter-zipkin

> 标签: contrib, exporter, opentelemetry, otel, tracing, zipkin

## 简介

Zipkin exporter for OpenTelemetry PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
