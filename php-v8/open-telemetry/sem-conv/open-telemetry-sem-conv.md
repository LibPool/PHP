# open-telemetry/sem-conv

> 标签: Metrics, apm, logging, opentelemetry, otel, semantic conventions, semconv, tracing

## 简介

Semantic conventions for OpenTelemetry PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
