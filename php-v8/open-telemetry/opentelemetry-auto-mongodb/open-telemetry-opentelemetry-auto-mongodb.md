# open-telemetry/opentelemetry-auto-mongodb

> 标签: instrumentation, mongo, mongodb, open-telemetry, opentelemetry, otel, tracing

## 简介

OpenTelemetry auto-instrumentation for MongoDB

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
