# open-telemetry/opentelemetry-metrics-runtime

> 标签: Metrics, open-telemetry, opentelemetry, otel, php, runtime

## 简介

OpenTelemetry PHP runtime metrics (memory, GC, OPcache, CPU)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
