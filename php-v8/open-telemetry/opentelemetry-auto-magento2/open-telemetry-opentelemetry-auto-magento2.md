# open-telemetry/opentelemetry-auto-magento2

> 标签: instrumentation, magento2, open-telemetry, opentelemetry, otel, tracing

## 简介

OpenTelemetry auto-instrumentation for Magento2

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- Packagist 页面：https://packagist.org/packages/open-telemetry%2Fopentelemetry-auto-magento2
