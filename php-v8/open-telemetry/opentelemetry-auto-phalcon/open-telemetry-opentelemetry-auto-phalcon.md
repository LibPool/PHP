# open-telemetry/opentelemetry-auto-phalcon

> 标签: instrumentation, open-telemetry, opentelemetry, otel, phalcon, tracing

## 简介

OpenTelemetry auto-instrumentation for the Phalcon PHP framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
