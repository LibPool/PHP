# open-telemetry/opentelemetry-auto-pdo

> 标签: instrumentation, open-telemetry, opentelemetry, otel, pdo, tracing

## 简介

OpenTelemetry auto-instrumentation for PDO

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
