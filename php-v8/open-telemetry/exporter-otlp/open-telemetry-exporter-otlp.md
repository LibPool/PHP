# open-telemetry/exporter-otlp

> 标签: Metrics, exporter, gRPC, http, opentelemetry, otel, otlp, tracing

## 简介

OTLP exporter for OpenTelemetry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
