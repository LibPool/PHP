# open-telemetry/detector-digitalocean

> 标签: detector, digitalocean, open-telemetry, opentelemetry, otel, tracing

## 简介

OpenTelemetry resource detector for DigitalOcean

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
