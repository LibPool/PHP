# open-telemetry/opentelemetry-auto-laravel

> 标签: instrumentation, laravel, open-telemetry, opentelemetry, otel, tracing

## 简介

OpenTelemetry auto-instrumentation for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
