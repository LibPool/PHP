# open-telemetry/gen-jaeger-thrift

> 标签: jaeger, opentelemetry, otel, thrift, tracing

## 简介

PHP Thrift files for communication with Jaeger.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
