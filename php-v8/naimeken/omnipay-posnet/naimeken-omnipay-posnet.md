# naimeken/omnipay-posnet

> 标签: PHP

## 简介

Posnet(Yapıkredi, Vakıfbank, Anadolubank sanal pos) gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
