# zeerats/laravel-lang-lint

> 标签: artisan, i18n, lang, laravel, localization, translations

## 简介

Artisan commands that find missing and unused translation keys in Laravel language files and keep those files formatted.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
