# norberttech/aceeditor-bundle

> 标签: ace, bundle, code, editor, form, javascript, symfony

## 简介

Bundle that integrate excellent JavaScript ace editor into Symfony Form.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
