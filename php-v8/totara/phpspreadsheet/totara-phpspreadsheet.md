# totara/phpspreadsheet

> 标签: OpenXML, excel, gnumeric, ods, php, spreadsheet, xls, xlsx

## 简介

Totara fork of PHPSpreadsheet - Read, Create and Write Spreadsheet documents in PHP - Spreadsheet engine

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
