# hypernic/nawala

> 标签: blocked, domain, komdigi, library, nawala, php

## 简介

Hypernic Nawala is a PHP library to check whether a website or domain is blocked in Indonesia.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
