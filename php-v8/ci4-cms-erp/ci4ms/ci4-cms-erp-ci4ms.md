# ci4-cms-erp/ci4ms

> 标签: PHP

## 简介

Modular CodeIgniter 4 CMS featuring RBAC admin, theming, blog/page management, elFinder media integration, and CLI tooling for rapid customization.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
