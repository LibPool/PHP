# crustum/cakephp-attribute-resolver

> 标签: attributes, cakephp, metadata, php8, reflection

## 简介

PHP Attribute discovery and resolution library for CakePHP applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
