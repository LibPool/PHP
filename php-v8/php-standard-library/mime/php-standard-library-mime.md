# php-standard-library/mime

> 标签: content-type, mime, mime-type

## 简介

MIME media types, multipart body construction, content sniffing, S/MIME cryptography, and DKIM signing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
