# php-standard-library/hash

> 标签: cryptography, hash, hmac

## 简介

Cryptographic and non-cryptographic hashing with Algorithm enum, timing-safe comparison, and HMAC

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
