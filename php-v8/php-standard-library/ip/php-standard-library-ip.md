# php-standard-library/ip

> 标签: IP, ipv4, ipv6, networking

## 简介

Immutable, binary-backed value object for IPv4 and IPv6 addresses with parsing, classification, and comparison

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
