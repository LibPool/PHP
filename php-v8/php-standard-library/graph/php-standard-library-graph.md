# php-standard-library/graph

> 标签: Algorithm, DFS, bfs, graph

## 简介

Immutable directed and undirected graph data structures with BFS, DFS, topological sort, and cycle detection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
