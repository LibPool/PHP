# php-standard-library/dnssec

> 标签: DNSSEC, dns, security, validation

## 简介

DNSSEC validation with full trust chain verification, RRSIG signatures, and NSEC/NSEC3 proofs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
