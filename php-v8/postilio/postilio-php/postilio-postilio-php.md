# postilio/postilio-php

> 标签: api, email, postilio, psr-18, transactional, webhooks

## 简介

The official PHP client for the Postilio API: European transactional email.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://postilio.eu
- 源码仓库：https://github.com/Postilio/postilio-php.git
- Packagist 页面：https://packagist.org/packages/postilio%2Fpostilio-php
