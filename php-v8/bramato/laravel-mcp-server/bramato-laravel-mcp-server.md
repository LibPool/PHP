# bramato/laravel-mcp-server

> 标签: ai, json-rpc, laravel, llm, mcp, model-context-protocol, reverb

## 简介

A base Laravel package for building Model Context Protocol (MCP) servers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
