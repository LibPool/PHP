# sunjinglong/think-filesystem

> 标签: PHP

## 简介

适用于thinkphp8的文件系统扩展,支持 Aliyun  Qiniu COS OBS FTP GOOGLE QCloud S3 SFTP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
