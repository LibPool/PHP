# rtcamp/wp-phpcs

> 标签: phpcs, standards, static analysis, vipcs, wordpress, wpcs

## 简介

rtCamp PHP_CodeSniffer standards for WordPress projects (rtCampWP + rtCampWP-Basic).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
