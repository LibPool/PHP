# rtcamp/stripe-xero-csv

> 标签: csv, stripe, xero

## 简介

Export Stripe's balance affecting transactions in a CSV file, recognisable by Xero Import CSV Statement feature.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
