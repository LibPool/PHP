# rtcamp/plugin-elementary

> 标签: PHP

## 简介

All backend functionality: post types, taxonomies, blocks, REST endpoints, settings, shortcodes, and custom roles.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
