# rtcamp/wp-primitives

> 标签: framework, library, rtcamp, wordpress, wordpress-plugin, wordpress-theme

## 简介

Contracts, loaders and utilities for building WordPress plugins and themes on a shared, tested base.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
