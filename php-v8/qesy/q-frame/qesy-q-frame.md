# qesy/q-frame

> 标签: QFrame, Qesy, framework, php

## 简介

A simple php Framework .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/qesy/q-frame
- 源码仓库：https://github.com/Qesy/Q-Frame.git
- Packagist 页面：https://packagist.org/packages/qesy%2Fq-frame

## 获取地址

- Composer 安装：`composer require qesy/q-frame`
- Packagist 仓库：https://repo.packagist.org/p2/qesy/q-frame.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4.0
