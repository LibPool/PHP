# antonythorpe/rollbar

> 标签: error monitoring, rollbar, silverstripe

## 简介

Rollbar Integration for SilverStripe.  Rollbar automates error monitoring and triaging, so developers can fix errors that matter within minutes, and build software quickly and painlessly.  See rollbar.com for more information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
