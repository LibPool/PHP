# peteconsuegra/pete-laravel-plugin

> 标签: PHP

## 简介

WordPress Pete Plugin — Create and import Laravel apps in a scalable WordPress environment with free SSL and one-click integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
