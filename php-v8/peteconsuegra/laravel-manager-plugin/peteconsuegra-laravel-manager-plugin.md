# peteconsuegra/laravel-manager-plugin

> 标签: PHP

## 简介

Laravel Manager plugin for WordPress Pete (create/import Laravel apps and link with WordPress).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
