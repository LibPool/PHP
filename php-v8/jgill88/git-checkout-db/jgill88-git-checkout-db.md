# jgill88/git-checkout-db

> 标签: jgill88, laravel, mail

## 简介

This package mailtraps your outgoing mail and provides a fully-featured inbox to view your messages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
