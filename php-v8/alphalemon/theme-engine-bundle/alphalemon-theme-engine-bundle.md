# alphalemon/theme-engine-bundle

> 标签: cms, theme, themes

## 简介

ThemeEngineBundle adds theming feature to any Symfony2 application, adding themes packed as standard Symfony2 Bundles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
