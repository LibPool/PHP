# cresset/wick

> 标签: Pint, code-style, formatter, laravel, php

## 简介

An unconfigurable, Laravel Pint-style PHP formatter. Fetches a prebuilt Rust binary on demand; powered by Mago.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
