# cresset/magequery

> 标签: cli, dependency-injection, developer-tools, magento, magento2

## 简介

A fast Magento 2 codebase inspector (magequery: DI resolution, plugins, events, cron, routes, config across scopes, live DB introspection) and its write-side companion (magecommand: DI compile, static content). Fetches prebuilt Rust binaries on demand.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
