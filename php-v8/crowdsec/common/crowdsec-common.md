# crowdsec/common

> 标签: bouncer, capi, client, crowdsec, curl, lapi, rest, security, watcher

## 简介

Common PHP code used by other php libs from CrowdSec SDK

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
