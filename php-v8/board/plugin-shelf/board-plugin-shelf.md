# board/plugin-shelf

> 标签: board, documents, kanban, markdown, notes, shelf

## 简介

Shelf — a document board type for Board: file-explorer tree, collaborative markdown notes (TipTap + Yjs) and file storage under a quota.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
