# board/plugin-notify

> 标签: automation, board, discord, kanban, notifications, slack, webhook

## 简介

Notify — post Board card events to Slack or Discord via an incoming webhook, as an automation action.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
