# tekintian/dompdf

> 标签: PHP

## 简介

默认支持中文的dompdf, HTML转PDF工具类, DOMPDF is a CSS 2.1 compliant HTML to PDF converter

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
