# tekintian/phpenv

> 标签: PHP

## 简介

env操作封装，用于自动加载解析.env环境变量 自动适配助手函数env 自动数据过滤和数据类型转换 The phpenv parser and phpoption package for parser and load .env

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
