# pr0ggy/kanta

> 标签: assert, assertion, php, testing, unit, validation

## 简介

An easy-to-use, exception-based functional assertion library for PHP 5.6 and later

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
