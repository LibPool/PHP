# sly/notification-pusher

> 标签: android, apns, apple, gcm, iphone, message, notification, push, pusher

## 简介

Standalone PHP library for easy devices notifications push.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
