# uzinfo/laravel-api-generator

> 标签: api, artisan, commands, crud, generator, laravel, repository, resource, service

## 简介

Laravel API generator package for creating controllers, services, repositories, resources and requests with stubs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
