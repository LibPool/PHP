# yan/semaphore-sms-bundle

> 标签: semaphore, sms, symfony semaphore, symfony sms

## 简介

Bundle for sending sms via Semaphore.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
