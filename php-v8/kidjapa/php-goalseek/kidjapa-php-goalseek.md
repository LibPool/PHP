# kidjapa/php-goalseek

> 标签: LibreOffice, calc, goalseek

## 简介

A simple goalseek function for PHP. Using the goalseek function from Libre Office

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
