# bisae/platform

> 标签: PHP

## 简介

bisae-platform es la plataforma base de BISAE para el desarrollo de soluciones digitales modulares. Proporciona la estructura, convenciones y mecanismos necesarios para que desarrolladores construyan plataformas, módulos y aplicaciones desacopladas sobre el kernel BISAE, manteniendo escalabilidad, consistencia arquitectónica y evolución controlada.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
