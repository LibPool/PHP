# bisae/kernel

> 标签: PHP

## 简介

BISAE es una plataforma que crea plataformas. Facilita la automatización y sistematización de procesos al modelarlos como operaciones mentales del ingenio humano, permitiendo construir software modular, auditable y evolutivo para comunidades de desarrollo y conocimiento.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
