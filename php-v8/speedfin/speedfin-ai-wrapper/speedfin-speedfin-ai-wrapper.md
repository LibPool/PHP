# speedfin/speedfin-ai-wrapper

> 标签: admin, ai, knowledge, rag

## 简介

Wrapper for Speedfin AI knowledge API and admin CRUD.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
