# xuanchen/tencent-map-api

> 标签: PHP

## 简介

腾讯地图api sdk封装 tencent map services api,based on GuzzleHttp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
