# stolt/json-merge-patch

> 标签: JSON merge patch, json, json modification

## 简介

Implementation of JSON Merge Patch (https://tools.ietf.org/html/rfc7396).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
