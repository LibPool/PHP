# stolt/php-cs-fixer-custom-fixers

> 标签: PHP

## 简介

A growing set of custom fixers for PHP-CS-Fixer (https://cs.symfony.com/).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
