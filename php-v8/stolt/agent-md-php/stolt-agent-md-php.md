# stolt/agent-md-php

> 标签: agent.md, ai, cli, configuration, markdown, php, universal

## 简介

A PHP wrapper for AGENT.md, the universal agent configuration file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
