# stolt/llms-txt-php-cli

> 标签: cli, dev, llms, llms-txt, php, port

## 简介

A CLI for writing, reading, and validating llms.txt Markdown files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
