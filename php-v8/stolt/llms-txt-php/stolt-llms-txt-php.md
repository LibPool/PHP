# stolt/llms-txt-php

> 标签: llms, llms-txt, llms.txt, php, port

## 简介

A library for creating, parsing, validating, discovering, and expanding llms.txt files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
