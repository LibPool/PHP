# paulmozo/php-cypher-query-builder

> 标签: cypher, neo4j, query

## 简介

A PHP library for generating Cypher queries to be used with Graph databases such as Neo4J

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
