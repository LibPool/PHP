# zfr/zfr-oauth2-server-module

> 标签: oauth, oauth 2, server

## 简介

Zend Framework 2 module for ZfrOAuth2Server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
