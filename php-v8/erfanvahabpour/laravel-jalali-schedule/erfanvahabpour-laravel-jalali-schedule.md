# erfanvahabpour/laravel-jalali-schedule

> 标签: Jalali, Verta, cron, laravel, persian, schedule, scheduler, shamsi, solar-hijri

## 简介

Seamless Jalali (Solar Hijri) scheduling macros for Laravel tasks and console commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
