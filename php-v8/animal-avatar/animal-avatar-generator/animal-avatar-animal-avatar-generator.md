# animal-avatar/animal-avatar-generator

> 标签: avatar, generator, laravel, packagist, svg

## 简介

Generate deterministic animal SVG avatars from string seeds (PHP + Laravel)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
