# olleksi/flarum-swipe

> 标签: extension, flarum, gestures, mobile, swipe

## 简介

Add swipe gestures to Flarum for better mobile navigation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
