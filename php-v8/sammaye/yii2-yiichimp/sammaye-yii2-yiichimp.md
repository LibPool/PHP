# sammaye/yii2-yiichimp

> 标签: Yii2 Extension, extension, mailchimp, sammaye, yii2, yii2-extension

## 简介

A Yii2 ext for the MailChimp 3.0 API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
