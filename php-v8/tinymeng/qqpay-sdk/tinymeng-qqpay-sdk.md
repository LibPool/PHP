# tinymeng/qqpay-sdk

> 标签: QQ支付, qpay, qqpay

## 简介

QQ钱包支付第三方 PHP SDK，基于官方最新版本。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
