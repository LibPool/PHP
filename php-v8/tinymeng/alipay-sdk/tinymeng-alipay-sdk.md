# tinymeng/alipay-sdk

> 标签: alipay, 支付宝

## 简介

支付宝开放平台第三方 PHP SDK，基于官方最新版本，支持公钥和公钥证书2种模式。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
