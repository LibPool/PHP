# juleica-php/client

> 标签: api, client, ehrenamt, jugendleiter, juleica, sport

## 简介

Framework-agnostic PHP client for the JuLeiCa (Jugendleiter/in-Card) validity API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
