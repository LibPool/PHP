# juleica-php/laravel

> 标签: api, client, ehrenamt, jugendleiter, juleica, laravel, sport

## 简介

Laravel-Bridge (Service Provider, Facade, Config-Publishing) für juleica-php/client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
