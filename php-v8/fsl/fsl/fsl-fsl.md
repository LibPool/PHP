# fsl/fsl

> 标签: api, docker, framework, micro, microservices, php, router

## 简介

Fresh Squeezed Limonade (FSL): a PHP micro-framework for rapid development of Microservices and REST API's and Web Apps

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
