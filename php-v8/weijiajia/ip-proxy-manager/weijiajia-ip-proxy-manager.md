# weijiajia/ip-proxy-manager

> 标签: huasheng, ip management, ip proxy, proxy manager, proxy service, stormproxies

## 简介

A powerful PHP IP proxy service management framework providing a unified interface for multiple proxy providers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
