# ayup-creative/laravel-dsql

> 标签: PHP

## 简介

Advanced DSL search parser for Laravel with virtual columns, operators, relationship traversal and export-ready queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
