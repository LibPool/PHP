# insolita/yii2-adminlte-widgets

> 标签: AdminLTE, widget, yii2

## 简介

Widgets for AdminLTE theme (Box with remember collapse state, Timeline, Tile, Callout, SmallBox etc)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
