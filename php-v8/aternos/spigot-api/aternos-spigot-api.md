# aternos/spigot-api

> 标签: api, minecraft, php, plugins, spigot, spigotmc

## 简介

PHP Client for the SpigotMC XenforoResourceManagerAPI. This client is based on the openapi spec.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
