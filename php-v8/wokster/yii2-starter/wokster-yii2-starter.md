# wokster/yii2-starter

> 标签: advanced, framework, project template, starter, wokster, yii2

## 简介

Yii 2 Starter based on Advanced Project Template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
