# liquipedia/sqllint

> 标签: junit, lint, sql

## 简介

A thin wrapper around the SqlParser from the phpMyAdmin project which can be used to lint any amount of sql files from the command line.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
