# robtec20/create-bundle

> 标签: PHP

## 简介

Symfony Bundle for createphp and create.js. The easiest way to make any site editable and have semantic annotations with RDFa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
