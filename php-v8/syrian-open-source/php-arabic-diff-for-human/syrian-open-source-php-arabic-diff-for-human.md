# syrian-open-source/php-arabic-diff-for-human

> 标签: laravel, syrian open source

## 简介

PHP Package to convert time difference to Arabic human readable string

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
