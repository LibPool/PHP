# edvnetwork/php-ssh

> 标签: PHP

## 简介

PHP sdk for connect to servers via ssh, sftp an more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://www.edv-network.group
- 源码仓库：https://github.com/edvnetwork/php-ssh.git
- Packagist 页面：https://packagist.org/packages/edvnetwork%2Fphp-ssh
