# loganstellway/wp-customize-google-fonts

> 标签: gutenberg, mailchimp, wordpress

## 简介

Add Google Fonts components to Theme Customizer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
