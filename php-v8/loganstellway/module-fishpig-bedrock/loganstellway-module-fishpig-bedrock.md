# loganstellway/module-fishpig-bedrock

> 标签: PHP

## 简介

Extends FishPig WordPress module to support Bedrock WordPress boilerplate

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
