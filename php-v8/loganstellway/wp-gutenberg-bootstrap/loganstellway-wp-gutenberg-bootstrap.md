# loganstellway/wp-gutenberg-bootstrap

> 标签: bootstrap, gutenberg, wordpress

## 简介

Bootstrap blocks for WordPress editor Gutenberg

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
