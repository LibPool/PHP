# lenorix/laravel-datadis-client

> 标签: laravel, laravel-datadis-client, lenorix

## 简介

Laravel integration for lenorix/datadis-client: Datadis electricity data on Laravel's Http, cache and configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
