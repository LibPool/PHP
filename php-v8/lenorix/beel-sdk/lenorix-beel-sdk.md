# lenorix/beel-sdk

> 标签: API-Client, api, beel, beel-sdk, invoicing, lenorix, payment, sdk, verifactu

## 简介

Unofficial community PHP SDK for the BeeL invoicing API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
