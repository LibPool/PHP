# gsteel/goatee

> 标签: handlebars, mustache, php, template

## 简介

A small library for parsing and rendering nested models into string literals using a familiar mustache/handlebars format without additional features

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
