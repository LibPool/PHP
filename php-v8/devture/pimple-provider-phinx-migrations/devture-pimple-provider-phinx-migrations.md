# devture/pimple-provider-phinx-migrations

> 标签: database, migrations, phinx, pimple

## 简介

Pimple Services Provider which provides DB migrations powered by Phinx

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
