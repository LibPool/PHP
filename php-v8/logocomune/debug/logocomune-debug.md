# logocomune/debug

> 标签: cli, debug, debugging, html, print_r, var_dump, var_export

## 简介

simple debugging tool which prints human-readable information about a variable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
