# samlittler/luhn-mod-16

> 标签: Mod, checksum, luhn

## 简介

A PHP library for calculating Luhn Mod 16 checksums as used by Royal Mail and others

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
