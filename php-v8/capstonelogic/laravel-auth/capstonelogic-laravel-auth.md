# capstonelogic/laravel-auth

> 标签: acl, auth, eloquent, laravel, permissions, roles, security

## 简介

Light-weight role-based permissions for Laravel 5 built in Auth system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
