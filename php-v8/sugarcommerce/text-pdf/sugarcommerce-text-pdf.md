# sugarcommerce/text-pdf

> 标签: invoice, pdf, receipt, report, reverse-charge, statement, svg, table, vat

## 简介

PDF generation with no dependencies. Invoices, statements and receipts with tables, vector SVG logos, multi-page flow, EU VAT treatments including reverse charge, and 11 languages. Injection-safe.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
