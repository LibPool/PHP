# sugarcommerce/sqlite

> 标签: database, migrations, pdo, schema, sqlite, transactions, wal

## 简介

SQLite for web applications: correct pragmas, type-aware binding, immediate write transactions with retry, schema introspection and idempotent migrations. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
