# sugarcommerce/format-utils

> 标签: avatar, bytes, duration, file-type, format, humanize, truncate

## 简介

Display formatting: byte sizes, durations, compact numbers, word-safe truncation, deterministic initials avatars, file-type labels and content types, and forgiving search. Parses back what it formats. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
