# sugarcommerce/http-client

> 标签: client, curl, http, outbound, security, ssrf, webhooks

## 简介

Outbound HTTP client with SSRF protection on by default. Validates and pins the target address, re-validates every redirect hop, and caps response size. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
