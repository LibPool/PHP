# sugarcommerce/sanitize

> 标签: input, sanitisation, sanitization, security, validation

## 简介

Untrusted strings in, something safe to store out. Control characters and display-spoofing Unicode stripped, addresses and URLs validated, integers clamped, allow-lists for the values that reach SQL as identifiers. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
