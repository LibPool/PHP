# sugarcommerce/rate-limit

> 标签: 429, apcu, brute-force, rate-limit, sliding-window, sqlite, throttle

## 简介

Sliding-window rate limiting with atomic counters. APCu, SQLite, file and in-memory stores, standard rate-limit headers, and an API that makes forgetting the identity key impossible. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
