# sugarcommerce/web-security

> 标签: csrf, gdpr, sanitisation, security, session, validation

## 简介

Signed-cookie sessions for a single shared password, CSRF tokens with nothing to store, and keyed hashing for the values an application must compare but never read back.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
