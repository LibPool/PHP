# sugarcommerce/zip-stream

> 标签: archive, download, stream, zip, zip64

## 简介

Write a ZIP straight to the client without building it first. Members are streamed through, so a 40 GB archive costs a buffer rather than disk, and ZIP64 turns on by itself when the numbers need it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
