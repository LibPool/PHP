# sugarcommerce/paginate

> 标签: admin, pagination, search, sorting, sqlite

## 简介

Paging, sorting and search for list screens, with the column names allow-listed because they cannot be bound as parameters. Returns a page object that knows how to render its own controls.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
