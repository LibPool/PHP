# sugarcommerce/oauth-server

> 标签: RFC7009, authorization-server, mcp, oauth, oauth2.1, pkce, rfc7591, rfc8414, rfc8707, rfc9728

## 简介

The authorization-server half of OAuth 2.1 for a remote MCP server: protected resource and authorization server metadata, Client ID Metadata Documents and dynamic registration, authorization code with S256 PKCE, resource-bound opaque tokens, rotating refresh tokens with reuse detection, and revocation. Storage is yours.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
