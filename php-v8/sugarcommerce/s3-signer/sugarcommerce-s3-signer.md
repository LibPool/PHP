# sugarcommerce/s3-signer

> 标签: aws, backblaze, cloudflare-r2, object-storage, presigned-url, r2, s3, signature-v4, sigv4, spaces

## 简介

AWS Signature Version 4 signing for S3-compatible object storage. Presigned URLs and signed request headers, no HTTP client, no SDK. Verified against Cloudflare R2, AWS S3, Backblaze B2 and DigitalOcean Spaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
