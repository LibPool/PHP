# sugarcommerce/http

> 标签: csp, http, request, response, router, templates

## 简介

A request, a response, a router and a template renderer for plain PHP. Small enough to read in one sitting, complete enough that an application never touches a superglobal.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
