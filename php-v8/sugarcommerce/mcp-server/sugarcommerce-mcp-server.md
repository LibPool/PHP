# sugarcommerce/mcp-server

> 标签: ai, json-rpc, llm, mcp, model-context-protocol, tools

## 简介

A Model Context Protocol server for plain PHP. Implements the 2026-07-28 revision, and serves 2025-11-25 and 2025-06-18 clients: stateless per-request negotiation, JSON-RPC 2.0 over Streamable HTTP, typed tools with JSON Schema validation, and scope-based authorization. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
