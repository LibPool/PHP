# sugarcommerce/signed-tokens

> 标签: Authentication, Passwordless, expiring, hmac, jwt-alternative, magic-link, signed-url, token

## 简介

HMAC-signed, expiring, namespaced tokens for URLs. Magic sign-in links, password resets, download URLs and unsubscribe links with no database row. Zero dependencies, supports secret rotation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
