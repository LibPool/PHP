# sugarcommerce/cli

> 标签: arguments, argv, cli, command-line, console, table

## 简介

Command-line plumbing for PHP apps: argument parsing with typed reads, aligned tables and help listings, returned as strings. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
