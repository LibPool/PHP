# brainstud/geolocation

> 标签: IP, brainstud, geolocation, ipgeo, laravel, timezone

## 简介

A laravel package to get the country and timezone (geolocation) of the request

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
