# makallio85/rocksoftware-cakephp-users

> 标签: SSO, authentik, cakephp, oidc, openid-connect

## 简介

CakePHP 5 plugin for everything about signing in to a Rock Software application: Rock Software ID (OpenID Connect), password sign-in, sessions, sign-in history, the users page and the user menu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
