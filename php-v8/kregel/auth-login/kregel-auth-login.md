# kregel/auth-login

> 标签: auth, auth-flow, laravel, laravel-login, login

## 简介

This is the original auth flow for Laravel, just brought to the package environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
