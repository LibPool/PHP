# b24io/loyalty-php-sdk

> 标签: Bitrix24, bonus cards, loyalty program, loyalty program SDK, rest-api

## 简介

B24io.Loyalty: PHP-SDK for bonus cards and loyalty program for Bitrix24

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
