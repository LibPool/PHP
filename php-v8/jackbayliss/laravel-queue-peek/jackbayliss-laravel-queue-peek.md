# jackbayliss/laravel-queue-peek

> 标签: JackBayliss, laravel, laravel-queue-peek

## 简介

A read-only Artisan command to peek at jobs sitting in your Laravel queues.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
