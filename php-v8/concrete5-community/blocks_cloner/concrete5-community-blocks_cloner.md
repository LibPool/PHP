# concrete5-community/blocks_cloner

> 标签: CIF, addon, attribute, block, clone, cms, concrete, concrete5, concreteCMS, copy, export, import, package, page, xml

## 简介

A ConcreteCMS package to copy blocks and page attributes between websites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
