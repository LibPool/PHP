# concrete5-community/boolean_rich

> 标签: PHP

## 简介

Provide a boolean (checkbox) attribute with a Rich Text label for Concrete CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
