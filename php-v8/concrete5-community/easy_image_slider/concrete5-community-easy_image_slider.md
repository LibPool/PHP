# concrete5-community/easy_image_slider

> 标签: addon, carousel, concrete5, package, slider, touch

## 简介

Easy Slider is a touch enabled block that lets you create beautiful responsive carousel slider

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
