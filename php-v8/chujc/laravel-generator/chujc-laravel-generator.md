# chujc/laravel-generator

> 标签: api, controller, generator, laravel, lumen, model

## 简介

Laravel, Lumen脚手架 按规则自动生成model文件以及controller，request文件

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
