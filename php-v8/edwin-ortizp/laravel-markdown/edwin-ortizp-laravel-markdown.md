# edwin-ortizp/laravel-markdown

> 标签: blade, editor, laravel, livewire, markdown

## 简介

Framework-independent Markdown editor UI and safe viewer for Laravel Blade, with optional Livewire 3/4 integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
