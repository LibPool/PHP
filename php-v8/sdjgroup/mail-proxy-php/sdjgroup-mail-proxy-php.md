# sdjgroup/mail-proxy-php

> 标签: attachment, email, mail, mail-proxy, multipart, sdk, smtp

## 简介

Framework-agnostic PHP SDK for the mail proxy service: hand a mail with many recipients and attachments to the proxy in a few lines, with typed errors and zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
