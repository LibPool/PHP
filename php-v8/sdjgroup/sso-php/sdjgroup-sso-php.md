# sdjgroup/sso-php

> 标签: Authentication, OpenId, SSO, authorization-code, login, oauth2, sdk, single-sign-on

## 简介

Framework-agnostic PHP SDK for the SSO unified login service: OAuth2 authorization-code flow in a few lines, with built-in state (CSRF) protection and typed errors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
