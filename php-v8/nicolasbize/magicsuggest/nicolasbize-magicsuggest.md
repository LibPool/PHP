# nicolasbize/magicsuggest

> 标签: PHP

## 简介

MagicSuggest is a multiple selection auto-suggest input box for Bootstrap 3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
