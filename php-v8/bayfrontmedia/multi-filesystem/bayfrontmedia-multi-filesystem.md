# bayfrontmedia/multi-filesystem

> 标签: disk, filesystem, php, storage

## 简介

An easy-to-use library used to manage multiple Flysystem adapters from a single class.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
