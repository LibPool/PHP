# bayfrontmedia/bones-web

> 标签: Bones, bones-web, tailwind, tailwindcss, webpack

## 简介

A starter kit to begin building a web application with Tailwind using the Bones framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
