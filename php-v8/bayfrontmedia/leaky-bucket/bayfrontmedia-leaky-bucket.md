# bayfrontmedia/leaky-bucket

> 标签: leaky-bucket, php, rate-limit, throttle

## 简介

Framework-agnostic throttling using the leaky bucket algorithm.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
