# bayfrontmedia/encryptor

> 标签: decrypt, decryption, encrypt, encryption, encryptor, openssl, php

## 简介

A fast, simple two-way encryption library utilizing OpenSSL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
