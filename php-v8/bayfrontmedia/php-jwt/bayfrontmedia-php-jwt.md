# bayfrontmedia/php-jwt

> 标签: decode, encode, json, jwt, php, token

## 简介

A simple library to encode and decode JSON Web Tokens (JWT) in PHP, conforming to RFC 7519.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
