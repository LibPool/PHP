# bayfrontmedia/cron-scheduler

> 标签: cron, cronjob, crontab, php

## 简介

A flexible framework-agnostic cron job scheduler using human-readable expressions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
