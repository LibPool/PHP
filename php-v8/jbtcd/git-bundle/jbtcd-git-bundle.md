# jbtcd/git-bundle

> 标签: debug, git, jbtcd, symfony, toolbar

## 简介

A short way to show Git Branch and Commits in the Symfony Web Debug Toolbar

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
