# benhall14/php-imap-reader

> 标签: email, imap, mail, mailbox, php, pop3

## 简介

A PHP class that makes working with IMAP in PHP simple.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
