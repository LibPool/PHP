# superbig/craft3-calendarlinks

> 标签: Craft, calendar links, cms, craft-plugin, craftcms

## 简介

Generate add-to-calendar links for Google, iCal and other calendar systems.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
