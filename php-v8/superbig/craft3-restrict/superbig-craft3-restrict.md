# superbig/craft3-restrict

> 标签: Craft, cms, craft-plugin, craftcms, restrict

## 简介

Restrict access to the CP based on a IP whitelist

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
