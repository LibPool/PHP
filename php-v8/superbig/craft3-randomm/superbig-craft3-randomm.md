# superbig/craft3-randomm

> 标签: Craft, cms, craft-plugin, craftcms, randomm

## 简介

Fieldtype that allows you to create random things via chance.js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
