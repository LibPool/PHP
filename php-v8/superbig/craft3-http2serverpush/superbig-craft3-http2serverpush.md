# superbig/craft3-http2serverpush

> 标签: Craft, cms, craft-plugin, craftcms, http2 server push

## 简介

Automatically add HTTP2 Link headers for CSS, JS and image assets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
