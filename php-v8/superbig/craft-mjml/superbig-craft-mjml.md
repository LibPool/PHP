# superbig/craft-mjml

> 标签: Craft, cms, craft-plugin, craftcms, mjml

## 简介

Render Twig emails with MJML, the only framework that makes responsive email easy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
