# superbig/craft3-logoutredirect

> 标签: Craft, cms, craft-plugin, craftcms, logout redirect

## 简介

Configure where to send users after they logout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
