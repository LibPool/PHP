# tknoweb/ai-sql-assistant-bundle

> 标签: ai, sql, symfony

## 简介

Statistics assistant for Symfony: an AI model (Claude, OpenAI, Gemini, a local model...) answers questions in natural language by writing SQL on a MySQL, MariaDB, PostgreSQL, SQL Server or SQLite database, without ever seeing a stored value

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
