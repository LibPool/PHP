# bigdropinc/yii2-find-by-attribute

> 标签: activerecord, attribute, extension, find, yii2

## 简介

Allowed to use magic methods for finding active records by attributes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
