# solucionatico/laravel-passport-mongodb

> 标签: laravel, mongodb, oauth, passport

## 简介

Laravel Passport provides OAuth2 server support to Laravel with MongoDB Jenssegers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
