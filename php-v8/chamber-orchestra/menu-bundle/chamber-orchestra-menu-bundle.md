> 标签: access-control, active-menu, authorization, badge, breadcrumb, builder-pattern, caching, dynamic-badge, fluent-api, menu, menu-builder, menu-bundle, menu-item, navbar, navigation, navigation-bundle, navigation-menu, php, php-8, psr-6, role-based-access, route-matching, runtime-extension, sidebar, symfony, symfony-8, symfony-bundle, tag-aware-cache, tree-menu, twig, twig-extension, voter

## 简介

Symfony 8 navigation menu bundle with fluent tree builder, route-based active-item matching, role-based access control, runtime extensions for dynamic badges, PSR-6 tag-aware caching, and Twig rendering

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
