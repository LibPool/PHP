# flsouto/htcklist

> 标签: Forms, choices, fields, html, multichoice, options, widgets

## 简介

Generates a list of checkboxes for multi selection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
