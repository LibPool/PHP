# tungsten/growdough

> 标签: Craft, cms, craft-plugin, craftcms, growdough

## 简介

This plugin allows collecting donation designations in a Donations List that works similar to a shopping cart.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
