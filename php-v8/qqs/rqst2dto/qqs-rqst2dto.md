# qqs/rqst2dto

> 标签: Data Transfer Object, codegen, dto, form request, generate, laravel, request

## 简介

A package for generating DTOs from Laravel request classes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
