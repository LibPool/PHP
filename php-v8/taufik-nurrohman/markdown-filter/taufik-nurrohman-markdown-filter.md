# taufik-nurrohman/markdown-filter

> 标签: commonmark, converter, extra, filter, markdown, parser, safe, security

## 简介

Safely replace text in a Markdown document.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
