# dennisdigital/dev_scripts

> 标签: console, development, drupal, symfony

## 简介

Install Drupal console with custom commands to be used for Drupal development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
