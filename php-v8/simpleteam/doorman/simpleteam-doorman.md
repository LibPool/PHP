# simpleteam/doorman

> 标签: Craft, Doorman, cms, craft-plugin, craftcms

## 简介

This plugin guards the url you either don't want to show or you don't want to hit it too often

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
