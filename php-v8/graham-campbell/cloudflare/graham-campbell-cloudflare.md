# graham-campbell/cloudflare

> 标签: CloudFlare API, Graham Campbell, GrahamCampbell, Laravel CloudFlare, Laravel-CloudFlare, cloudflare, framework, laravel

## 简介

CloudFlare Provides A Simple CloudFlare Module For Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
