# aggrosoft/oxid-direct-sku-search

> 标签: OXID, eshop, modules

## 简介

Redirect user to product if sku matches in search and no other results found

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
