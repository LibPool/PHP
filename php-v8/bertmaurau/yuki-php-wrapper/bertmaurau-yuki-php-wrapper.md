# bertmaurau/yuki-php-wrapper

> 标签: library, php, wrapper, yuki

## 简介

PHP Wrapper for the Yuki SOAP Webservice

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
