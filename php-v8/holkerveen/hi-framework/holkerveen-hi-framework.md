# holkerveen/hi-framework

> 标签: PHP

## 简介

A lightweight PHP framework with routing, dependency injection, Doctrine ORM, Twig templating, and PSR-7 HTTP support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
