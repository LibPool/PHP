# luketowers/oc-tinypng-plugin

> 标签: image optimization, laravel, tinyjpg, tinypng, winter, wintercms

## 简介

Automatically optimize resized images in Winter CMS with TinyPNG

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
