# vanry/laravel-scout-tntsearch

> 标签: laravel, scout, search, tntsearch

## 简介

包含中文分词的 Laravel Scout TNTSearch 驱动，支持 scws, phpanalysis 和 jieba 分词。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
