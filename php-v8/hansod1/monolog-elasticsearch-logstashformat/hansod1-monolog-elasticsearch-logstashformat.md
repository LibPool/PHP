# hansod1/monolog-elasticsearch-logstashformat

> 标签: elasticsearch, kibana, logstash, monolog

## 简介

Use the logstash formatter with elasticsearch, forked from nulpunkt/monolog-elasticsearch-logstashformat

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
