# pinatra/framework

> 标签: PHP

## 简介

Pinatra is a PHP verison of Sinatra: a DSL for quickly creating web applications in PHP with minimal effort.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
