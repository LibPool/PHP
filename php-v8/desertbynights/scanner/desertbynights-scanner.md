# desertbynights/scanner

> 标签: csv, scanner, url

## 简介

Scans URLs from a CSV file and report inaccessible URLs. This component is a test, extracted form 'Modern php' by Josh Lockhart.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
