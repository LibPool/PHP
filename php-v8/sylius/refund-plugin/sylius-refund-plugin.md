# sylius/refund-plugin

> 标签: e-commerce, refunds, sylius, sylius-plugin, symfony

## 简介

Plugin provides basic refunds functionality for Sylius application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
