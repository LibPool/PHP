# sylius/grid-bundle

> 标签: admin, api, crud, doctrine, grid, resource, sylius

## 简介

Amazing grids with support of filters and custom fields integrated into Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
