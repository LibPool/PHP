# buqiu/repository

> 标签: database, eloquent, laravel, repositories, repository

## 简介

Laravel Repository 是 Laravel 的一个软件包，用于抽象数据库层。 这使应用程序易于维护。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
