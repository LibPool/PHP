# buqiu/arr

> 标签: PHP

## 简介

数组增强组件主要是对数组等数据进行处理，如无限级分类操作、商品规格的迪卡尔乘积运算等

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
