> 标签: cryptographically secure, cryptography, digit, digits, generator, passcode, passcode generator, password, password generator, security

## 简介

A simple way to generate random cryptographically secure passcodes and passwords

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
