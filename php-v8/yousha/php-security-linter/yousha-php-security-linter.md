# yousha/php-security-linter

> 标签: cis, code-analysis, linter, owasp, php, secure-coding, security, security-audit, security-best-practices, security-linter, static-analysis, vulnerability-detection

## 简介

A PHP tool to lint PHP files for security issues based on CIS and OWASP best practices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
