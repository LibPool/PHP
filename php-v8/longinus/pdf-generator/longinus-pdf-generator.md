# longinus/pdf-generator

> 标签: PHP

## 简介

This is an package available to easy generate pdfs with Package Mpdf/mpdf on laravel >= 9.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
