# drakelid/librenms-netbox-context

> 标签: dcim, ipam, librenms, netbox, network, plugin, source-of-truth

## 简介

LibreNMS NetBox Context - NetBox device, interface, cabling and circuit context inside LibreNMS device and port views

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
