# drakelid/librenms-dashboard-widgets

> 标签: dashboard, librenms, monitoring, widget

## 简介

LibreNMS plugin bundling six custom dashboard widgets: device group down count, top bandwidth by device group, uplink utilization overview, top device temperatures, flapping devices and recently added devices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
