# drakelid/librenms-ups-battery

> 标签: librenms, plugin, sensors, ups

## 简介

LibreNMS plugin: rank devices by a selected sensor class (UPS runtime, load, charge ...)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
