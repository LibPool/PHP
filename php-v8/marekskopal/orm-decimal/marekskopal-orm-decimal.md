# marekskopal/orm-decimal

> 标签: decimal, ext-decimal, orm

## 简介

Decimal type from ext-decimal PHP extension mapper for MarekSkopal ORM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
