# ismailnakkar/laravel-listing

> 标签: blade, filter, laravel, listing, pagination, search, sort

## 简介

Easy, typed querying and filtering for Blade list pages: declare filters and sorts once, and no query string ever bounces the page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
