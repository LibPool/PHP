# ismailnakkar/laravel-safe-html

> 标签: html, laravel, sanitizer, validation, xss

## 简介

Clean user-typed HTML so it is safe to print with {!! !!} in Laravel, plus a length rule that counts an entity as one character.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
