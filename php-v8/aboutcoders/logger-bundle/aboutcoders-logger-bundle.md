# aboutcoders/logger-bundle

> 标签: bundle, client, log, logger, rest

## 简介

A symfony bundle to log messages from external applications over a REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
