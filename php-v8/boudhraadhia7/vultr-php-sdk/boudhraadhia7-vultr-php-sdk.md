# boudhraadhia7/vultr-php-sdk

> 标签: API-Client, cloud, psr-18, sdk, vps, vultr, vultr-api

## 简介

A modern, typed PHP client for the Vultr API v2 with retries, cursor pagination and PSR-18 support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
