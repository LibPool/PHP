# codelytv/php-bootstrap

> 标签: Skeleton, TDD, boilerplate, bootstrap, kata

## 简介

Starting point if you want to bootstrap a project in PHP following best practices.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
