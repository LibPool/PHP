# sophireak/laracheck

> 标签: ai, developer-tools, git-hook, laravel, pre-push

## 简介

A smart pre-push helper script for Laravel teams. Checks setup, fixes safe issues, and explains problems with AI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
