# inly/core-web

> 标签: core, inly, snapshots, statamic

## 简介

Core snapshots, the Core API client, Core's signed pings, snapshot sitemaps, a chat relay, CDN media components and the Statamic connector API for Statamic websites fed by an Inly Core backoffice.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
