# venpath/tipaltipayments

> 标签: tipalti

## 简介

Wrapper for the Tipalti SOAP API.  Forked from: https://github.com/kamil-zielinski/tipaltipayments

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
