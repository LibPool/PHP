# uuf6429/bitbucket-reporter

> 标签: PHP

## 简介

A tool that creates and submits Bitbucket Code Insights reports from (PHPUnit) JUnit/Clover test results.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
