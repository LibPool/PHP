# meghdadfadaee/nova-form-dock

> 标签: Forms, laravel, nova, sticky, user-interface

## 简介

An adaptive, accessible action dock for long Laravel Nova resource forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
