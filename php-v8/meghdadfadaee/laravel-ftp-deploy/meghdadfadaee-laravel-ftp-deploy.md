# meghdadfadaee/laravel-ftp-deploy

> 标签: deploy, ftp, laravel, sync-state

## 简介

Deploy changed Laravel project files over FTP using a sync-state manifest.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
