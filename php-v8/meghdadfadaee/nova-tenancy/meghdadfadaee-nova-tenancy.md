# meghdadfadaee/nova-tenancy

> 标签: laravel, multi-tenancy, nova, nova-tool, saas, tenancy, tenant-switcher

## 简介

A framework-agnostic tenant selector, context manager, and dynamic branding tool for Laravel Nova.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
