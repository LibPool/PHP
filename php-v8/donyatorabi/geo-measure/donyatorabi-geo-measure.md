# donyatorabi/geo-measure

> 标签: PHP

## 简介

GeoMeasure: A lightweight PHP library for geodesic distance, bearings, and midpoints (Haversine & Vincenty).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
