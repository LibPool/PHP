# acdh-oeaw/easyrdf

> 标签: Linked Data, RDF, Semantic Web, Turtle, rdfa, sparql

## 简介

ACDH fork of the EasyRdf library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
