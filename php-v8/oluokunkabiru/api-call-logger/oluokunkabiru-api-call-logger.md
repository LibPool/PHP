# oluokunkabiru/api-call-logger

> 标签: Audit, Guzzle, api, api-logger, debugging, http-client, laravel, logger, php, redaction, request-logging, third-party, webhook

## 简介

Provider-agnostic Laravel logger for third-party API calls and incoming webhooks: captures request, response, headers, status and latency with automatic redaction of credentials and PII, plus retry, pruning and a built-in dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
