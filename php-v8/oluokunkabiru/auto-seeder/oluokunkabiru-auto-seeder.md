# oluokunkabiru/auto-seeder

> 标签: auto-seed, database, faker, laravel, seeder, testing

## 简介

Framework-agnostic PHP package that auto-seeds database tables by introspecting model schemas and generating realistic random data via Faker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
