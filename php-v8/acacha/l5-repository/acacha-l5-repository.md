# acacha/l5-repository

> 标签: acacha, cache, eloquent, laravel, model, repository

## 简介

Laravel 5 - Repositories to the database layer. Based on prettus/l5-repository

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
