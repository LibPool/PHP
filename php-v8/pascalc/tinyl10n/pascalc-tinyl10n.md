# pascalc/tinyl10n

> 标签: l10n, locale detection

## 简介

Easy locale detection and automatic fallback to the best locale possible, other l10n niceties

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
