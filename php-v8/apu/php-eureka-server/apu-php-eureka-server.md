# apu/php-eureka-server

> 标签: discovery server, eureka, php, spring cloud

## 简介

A PHP client for Spring Cloud Eureka discovery server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
