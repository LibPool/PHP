# kisame76/filament-tree-table

> 标签: expandable, filament, filamentphp, hierarchy, laravel, nested, table, tree

## 简介

Expandable parent/child tree rows for Filament v4.3+ & v5 tables — inline sub-rows, search/filter aware, expand & collapse all.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
