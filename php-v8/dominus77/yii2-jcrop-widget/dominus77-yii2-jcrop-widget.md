# dominus77/yii2-jcrop-widget

> 标签: Dominus77, extension, jcrop, widget, yii2

## 简介

Jcrop Image Cropping Plugin for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
