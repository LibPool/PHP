# yiier/yii2-bootstrap4-select

> 标签: bootstrap, extension, select, selectpicker, yii2

## 简介

Yii2 wrapper for boostrap4-select.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
