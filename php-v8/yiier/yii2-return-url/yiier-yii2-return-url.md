# yiier/yii2-return-url

> 标签: filter, returnUrl, yii2

## 简介

Keeps current URL in session for login actions so we can return to it if needed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
