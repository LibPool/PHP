# ianfortier/loom-downloader

> 标签: download, ianfortier, laravel, loom, loom-downloader, php, video

## 简介

Loom Downloader is a simple PHP package to download videos from loom.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
