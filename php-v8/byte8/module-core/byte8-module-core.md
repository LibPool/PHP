# byte8/module-core

> 标签: activation, byte8, license-key, magento, magento-2, magento2

## 简介

Core utility module providing shared services and components for Byte8 Magento 2 modules — admin menu chassis, dedicated logger handlers, framework utilities, and the shared product activation gate consumed by the free byte8/module-* extensions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
