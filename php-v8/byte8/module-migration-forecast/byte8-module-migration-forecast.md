# byte8/module-migration-forecast

> 标签: db_schema, declarative-schema, deployment, mage-os, magento, magento-2, magento2, online-ddl, setup-upgrade, zero-downtime

## 简介

Forecast what setup:upgrade will do to your Magento 2 / Mage-OS database before you run it — pending DDL classified against MySQL's online-DDL matrix and costed by live row counts — and optionally gate the upgrade on it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
