# netflie/whatsapp-cloud-api

> 标签: PHP

## 简介

The first PHP SDK to send and receive messages using a cloud-hosted version of the WhatsApp Business Platform

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
