# axtiva/flexible-graphql-bundle

> 标签: PHP

## 简介

Schema first bundle for generate php code from graphql sdl to TypeRegistry with webonyx/graphql-php for symfony framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
