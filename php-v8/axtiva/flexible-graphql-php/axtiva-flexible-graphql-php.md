# axtiva/flexible-graphql-php

> 标签: PHP

## 简介

Schema SDL first lib for generate php code from graphql sdl to TypeRegistry with webonyx/graphql-php

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
