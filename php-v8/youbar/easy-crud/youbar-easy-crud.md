# youbar/easy-crud

> 标签: api, controller, crud, laravel, resource, rest

## 简介

Convention-driven CRUD controllers for Laravel. Magic by default, overridable everywhere.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
