# altayalp/ftp-client

> 标签: ftp, ftp client, php ftp, sftp, ssh, ssh ftp

## 简介

FTP and SFTP client for Php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
