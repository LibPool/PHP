# mrmarkfrench/mysql-converter

> 标签: csv, mysql

## 简介

A quick-and-dirty tool for converting raw MySQL query output to CSV.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
