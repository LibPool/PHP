# adriengras/umami-php

> 标签: analytics, http-client, saloon, tracking, umami

## 简介

Client PHP transport-only pour l'API Umami Analytics (v3.1.0), bâti sur Saloon v4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
