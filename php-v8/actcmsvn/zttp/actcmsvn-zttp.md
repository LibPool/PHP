# actcmsvn/zttp

> 标签: Guzzle, http

## 简介

Một máy khách HTTP tập trung vào trải nghiệm của nhà phát triển, được tối ưu hóa cho hầu hết các trường hợp sử dụng phổ biến.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
