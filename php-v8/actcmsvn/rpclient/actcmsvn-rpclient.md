# actcmsvn/rpclient

> 标签: BMF, Banking, Malaysia, Online banking, RaudahPay, Raudhah, payment, payment gateway

## 简介

Máy khách wrapper của RaudhahPay Gateway

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
