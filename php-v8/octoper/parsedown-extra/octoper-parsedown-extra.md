# octoper/parsedown-extra

> 标签: markdown, markdown extra, parsedown, parser

## 简介

An extension of Parsedown that adds support for Markdown Extra.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
