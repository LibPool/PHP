# silverstripe/search-data-extractor

> 标签: search, search-data-extractor, silverstripe

## 简介

This module provides a RESTful like API endpoint to expose model data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
