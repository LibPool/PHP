# silverstripe/textextraction

> 标签: fulltext, pdf, silverstripe

## 简介

Text Extraction API for SilverStripe CMS (mostly used with 'fulltextsearch' module)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
