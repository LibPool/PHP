# silverstripe/mimevalidator

> 标签: cwp, fileinfo, mime, silverstripe, upload, validator

## 简介

Checks uploaded file content roughly matches a known MIME type for the file extension.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
