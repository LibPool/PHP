# silverstripe/postgresql

> 标签: database, postgresql, silverstripe

## 简介

SilverStripe now has tentative support for PostgreSQL ('Postgres')

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
