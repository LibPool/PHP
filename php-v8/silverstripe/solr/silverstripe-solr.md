# silverstripe/solr

> 标签: search, silverstripe, solr

## 简介

Solr integration for SilverStripe. Note that this is NOT related to the silverstripe/fulltext package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
