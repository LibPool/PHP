# silverstripe/documentconverter

> 标签: cwp, silverstripe

## 简介

Imports OpenOffice-compatible files (doc, docx, etc) into SilverStripe pages and content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
