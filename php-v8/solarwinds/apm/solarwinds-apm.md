# solarwinds/apm

> 标签: instrumentation, observability, opentelemetry, performance, solarwinds_apm, swo

## 简介

Solarwinds specific OpenTelemetry SDK for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
