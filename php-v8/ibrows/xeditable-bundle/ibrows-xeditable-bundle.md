# ibrows/xeditable-bundle

> 标签: Symfony2, XeditableBundle, bootstrap, form, inline-edit, x-editable

## 简介

bootstrap x-editable symfony2 forms integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
