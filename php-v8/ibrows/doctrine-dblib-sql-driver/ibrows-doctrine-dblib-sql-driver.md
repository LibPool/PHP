# ibrows/doctrine-dblib-sql-driver

> 标签: PHP

## 简介

Doctrine driver for connection over pdo, dblib, freetds, (ms)sql server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
