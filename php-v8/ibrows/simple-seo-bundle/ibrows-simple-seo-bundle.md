# ibrows/simple-seo-bundle

> 标签: Symfony2, bundle, ibrows, seo

## 简介

A Symfony2 Bundle to add some SEO functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
