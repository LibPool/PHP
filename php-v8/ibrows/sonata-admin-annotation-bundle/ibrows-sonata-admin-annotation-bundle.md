# ibrows/sonata-admin-annotation-bundle

> 标签: annotation, ibrows, sonata

## 简介

Manage Sonata Form, Data, List and ShowMapper over annotations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
