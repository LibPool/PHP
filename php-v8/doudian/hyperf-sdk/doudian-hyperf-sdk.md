# doudian/hyperf-sdk

> 标签: Doudian, api, coroutine, douyin, e-commerce, hyperf, sdk, swoole

## 简介

抖店开放平台 PHP SDK for Hyperf Framework - 支持协程、依赖注入、连接池的高性能 SDK

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
