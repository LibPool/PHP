> 标签: laravel, laravel crud, laravel crud generator, laravel multi-auth crud, laravel multiauth crud, laravel multiple crud generator

## 简介

create crud system for guards generated by iMokhles's MultiAuth package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
