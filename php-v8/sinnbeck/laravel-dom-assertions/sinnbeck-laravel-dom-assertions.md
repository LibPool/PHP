# sinnbeck/laravel-dom-assertions

> 标签: assertions, blade, dom, laravel, view

## 简介

Adds fluent DOM assertion helpers to Laravel's test responses

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
