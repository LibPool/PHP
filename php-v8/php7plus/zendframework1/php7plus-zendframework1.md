# php7plus/zendframework1

> 标签: ZF1, framework

## 简介

Adjusted Zend Framework 1 for php 7 greater than 7.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://framework.zend.com/
- 源码仓库：https://github.com/MateuszPles/Zend1ForPhp7Plus.git
