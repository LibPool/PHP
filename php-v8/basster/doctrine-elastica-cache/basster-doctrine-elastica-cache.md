# basster/doctrine-elastica-cache

> 标签: PHP

## 简介

A doctrine-cache compatible caching solution utilizing elasticsearch as cache through elastica

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
