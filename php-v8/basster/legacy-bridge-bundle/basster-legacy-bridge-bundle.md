# basster/legacy-bridge-bundle

> 标签: PHP

## 简介

Bridge Bundle for wrapping legacy php projects (e.g. without frontcontrollers) into a symfony application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
