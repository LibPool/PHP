# zaiblab/mysql-backup

> 标签: CI4, backup, ci4 database, codeigniter backup, codeigniter4, database, database export, mysql, mysql backup, php, restore

## 简介

PHP library for backing up and restoring MySQL databases — fully compatible with CodeIgniter 4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
