# avanti/php-sdk

> 标签: api, avanti, delivery, logistics, order, php, sdk

## 简介

Avanti PHP SDK - 用于对接 Avanti API 的 PHP 开发工具包

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
