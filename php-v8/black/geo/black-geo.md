# black/geo

> 标签: black-project, coordinates, geo, libary, value-object

## 简介

PHP 5.4+ library to make working with Geo coordinates safer, easier, and fun

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
