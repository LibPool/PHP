# treeshainfotech/laravel-vapi

> 标签: ai, laravel, sdk, vapi, voice

## 简介

A Laravel wrapper for the Vapi PHP server SDK — config, facade, webhooks, and testing fakes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
