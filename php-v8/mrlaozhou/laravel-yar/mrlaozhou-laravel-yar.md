# mrlaozhou/laravel-yar

> 标签: laravel, mrlaozhou, rpc, yar

## 简介

Laravel-Yar 基于PHP yar实现了Laravel完全兼容Route模式的RPC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
