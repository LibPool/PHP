# symfony-cmf/cmf-phpcr-dbal-pack

> 标签: PHP

## 简介

Meta repository to install dbal implementation of with doctrine/phpcr-dbal-symfony-pack.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
