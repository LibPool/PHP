# michalskoula/codeigniter-ai-translation

> 标签: PHP

## 简介

This package allows you to translate your CodeIgniter 3/4 language files to any language using Anthropic or OpenAI REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
