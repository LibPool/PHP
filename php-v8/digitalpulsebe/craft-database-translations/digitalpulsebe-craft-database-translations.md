# digitalpulsebe/craft-database-translations

> 标签: Craft, cms, craft-plugin, craftcms, utm tracker

## 简介

Manage Craft i18n translations and store in database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
