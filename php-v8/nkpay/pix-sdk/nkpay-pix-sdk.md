# nkpay/pix-sdk

> 标签: PHP

## 简介

SDK PHP para a API Pix (BCB, OpenAPI v2.9.0) - cobranças, recebimentos, devoluções e webhooks. Compatível com PSPs que seguem o padrão (ex.: Banrisul).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
