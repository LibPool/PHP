# edenspiekermann/craft-jwt-auth

> 标签: Craft, cms, craft jwt, craft-plugin, craftcms

## 简介

Enable authentication to Craft through the use of JSON Web Tokens (JWT)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
