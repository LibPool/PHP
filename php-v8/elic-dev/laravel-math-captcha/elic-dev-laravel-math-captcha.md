# elic-dev/laravel-math-captcha

> 标签: captcha, laravel, laravel5, math, math-captcha

## 简介

A simple math captcha for Laravel form validation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
