# ar2rsoft/yii2-amocrm

> 标签: amoCRM, api, crm, extension, yii2

## 简介

Расширение для Yii Framework 2 реализующее клиент для работы с API amoCRM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
