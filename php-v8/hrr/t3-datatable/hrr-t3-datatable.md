# hrr/t3-datatable

> 标签: ajax, backend-module, data-grid, datatable, datatables, doctrine-dbal, extbase, fluid, pagination, search, server-side-processing, sorting, t3-datatable, typo3, typo3-13, typo3-14, typo3-datatable, typo3-extension

## 简介

T3 DataTable – a server-side searchable, sortable, paginated DataTable extension for TYPO3 backend modules, built on the DataTables protocol with Doctrine DBAL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
