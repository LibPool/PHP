# rate-api/rate-api-php

> 标签: api, crypto, currency, exchange-rate, forex, rate-api

## 简介

Official PHP client for the Rate-API.com exchange-rate & crypto API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
