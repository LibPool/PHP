# podlibre/podcast-namespace

> 标签: PHP

## 简介

Generate PHP translation files for CodeIgniter4 from the podcast-namespace's Persons Taxonomy json files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
