# rapira/laravel

> 标签: laravel, octane, rapira, server, worker

## 简介

Laravel bridge for Rapira: classic, worker and dispatcher modes on top of Laravel Octane

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
