# php-llp/php-llp

> 标签: LLP, ai, chat, embeddings, llm, php, rag, vector-store

## 简介

A lightweight, zero-dependency PHP library for building LLM applications. Supports PHP 7.4+.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
