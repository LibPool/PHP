# unitpost/laravel

> 标签: PHP

## 简介

Laravel wrapper for the official Unitpost PHP SDK.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.unitpost.com/docs
- 源码仓库：https://github.com/unitpostcom/unitpost-laravel.git
- Packagist 页面：https://packagist.org/packages/unitpost%2Flaravel

## 历史版本号

- 当前版本：0.3.0

- 0.3.0

## 获取地址

- Composer 安装：`composer require unitpost/laravel`
- Packagist 仓库：https://repo.packagist.org/p2/unitpost/laravel.json
- 许可证：MIT
- PHP 要求：>=8.2
