# unitpost/unitpost

> 标签: PHP

## 简介

Official Unitpost SDK for PHP — send email and manage contacts, segments, campaigns, templates, domains, webhooks, and suppressions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
