# aslnbxrz/simple-translation

> 标签: i18n, l10n, laravel, scanner, translation

## 简介

Lightweight file-first translations with DB backup for Laravel. Per-scope export and scanning.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
