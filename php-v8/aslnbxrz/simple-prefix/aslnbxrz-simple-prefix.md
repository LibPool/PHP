# aslnbxrz/simple-prefix

> 标签: accessor, eloquent, laravel, model, prefix, trait

## 简介

Tiny, fast Eloquent prefix generator (trait + optional interface) with zero-hassle defaults.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
