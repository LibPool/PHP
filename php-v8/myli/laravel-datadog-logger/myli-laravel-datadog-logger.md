> 标签: Agent, DataDog, api, datadog-logger, datadogagent, datadoglog, formatter, handler, laravel, log, logger, management, monolog, php

## 简介

Custom laravel monolog logger for datadog logs management, both api and agent ways

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
