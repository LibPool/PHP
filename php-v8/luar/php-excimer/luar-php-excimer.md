# luar/php-excimer

> 标签: PHP

## 简介

Implements the MediaWiki Excimer class for ease of use. Generate a json file that you can upload to speedscope.app to view the profile.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
