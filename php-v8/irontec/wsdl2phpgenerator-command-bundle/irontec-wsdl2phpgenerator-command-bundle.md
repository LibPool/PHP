# irontec/wsdl2phpgenerator-command-bundle

> 标签: PHP

## 简介

Provides wsdl2phpgenerator/wsdl2phpgenerator as a command on your Symfony Project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
