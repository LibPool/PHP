# irontec/send-file-to-client

> 标签: 206, Partial Content, http, php

## 简介

Clase para servir archivos con 'HTTP/1.1 206 Partial Content'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
