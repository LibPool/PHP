# hostatlas/queue-monitor

> 标签: horizon, hostatlas, laravel, monitoring, queue, redis

## 简介

Push Laravel queue metrics to HostAtlas for monitoring, alerting, and visualization.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
