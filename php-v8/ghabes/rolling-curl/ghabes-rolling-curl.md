# ghabes/rolling-curl

> 标签: asynchronous, curl, http, multi, parallel, requests

## 简介

Rolling-Curl: A non-blocking, non-dos multi-curl library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
