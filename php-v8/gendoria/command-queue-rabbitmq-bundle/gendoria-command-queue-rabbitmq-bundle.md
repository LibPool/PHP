# gendoria/command-queue-rabbitmq-bundle

> 标签: PHP

## 简介

RabbitMQ driver bundle for Gendoria Command Queue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
