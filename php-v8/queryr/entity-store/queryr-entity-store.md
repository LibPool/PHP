# queryr/entity-store

> 标签: DataModel, Fingerprint, lookup, terms, wikibase

## 简介

Provides persistence and basic lookup capabilities for collections of Wikibase entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
