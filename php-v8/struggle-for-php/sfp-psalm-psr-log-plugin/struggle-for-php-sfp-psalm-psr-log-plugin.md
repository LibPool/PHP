# struggle-for-php/sfp-psalm-psr-log-plugin

> 标签: PSR3, psalm, psalm-plugin, static analysis, static-analysis

## 简介

Stubs to let Psalm understand psr/log (PSR-3) strictly

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
