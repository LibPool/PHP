# arffsaad/qdiz

> 标签: PHP

## 简介

A simple no-framework redis queue system. Not using a framework but need a redis queue for delayed execution of long running tasks? Just qdiz (nuts).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
