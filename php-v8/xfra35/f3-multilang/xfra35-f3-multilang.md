# xfra35/f3-multilang

> 标签: F3, fatfree, localization, multilingual

## 简介

Route localization plugin for the PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
