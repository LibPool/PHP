# ulasimarsiv/seo-pack

> 标签: PHP

## 简介

Gelişmiş Flarum SEO: Meta Etiketleri, Sitemap ve Google Indexing API Entegrasyonu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
