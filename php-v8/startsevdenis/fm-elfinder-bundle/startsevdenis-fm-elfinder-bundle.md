# startsevdenis/fm-elfinder-bundle

> 标签: elfinder, file manager

## 简介

ElFinder bundle, adds ElFinder file manager to your Symfony2 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
