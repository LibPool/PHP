# appssquare/payment-validator

> 标签: easykash, fawry, hmac, hyperpay, kashier, payment, paymob, paypal, paytabs, signature, webhook

## 简介

Extensible signature/authenticity validation for payment gateway callbacks and webhooks (Paymob, EasyKash, HyperPay, Kashier, Fawry, PayTabs, PayPal, ...).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
