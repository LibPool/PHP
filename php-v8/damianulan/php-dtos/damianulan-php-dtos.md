# damianulan/php-dtos

> 标签: Data Transfer Object, dto, extension

## 简介

Provides a template for creating robust and efficient data-transfer-objects (DTOs) in your PHP projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
