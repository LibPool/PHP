# borsaco/telegram-bot-api-bundle

> 标签: Telegram-Bot-API, api, bot, php, symfony, telegram

## 简介

A simple wrapper for telegram-bot-api.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
