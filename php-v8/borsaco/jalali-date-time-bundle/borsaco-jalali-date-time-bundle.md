# borsaco/jalali-date-time-bundle

> 标签: Jalali, Symfony2, data, php, symfony, symfony3

## 简介

A bundle to using jalali date time in Symfony applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
