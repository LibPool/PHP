# selfphp/env-schema

> 标签: config, dotenv, env, env-schema, environment variables, schema, typecheck, utility, validation

## 简介

Validate .env environment variables in PHP using a declarative schema.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
