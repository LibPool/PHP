# litesoc/litesoc-php

> 标签: Audit, SIEM, laravel, litesoc, logging, security, threat-detection

## 简介

Official PHP SDK for LiteSOC - Security event tracking and threat detection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
