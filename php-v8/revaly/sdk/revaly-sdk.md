# revaly/sdk

> 标签: payments, rap, revaly, sdk

## 简介

Revaly RAP SDK for PHP: hand-written runtime (typed failure classes, reconcile helper, values-free logging, mock transport) over the generated core.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
