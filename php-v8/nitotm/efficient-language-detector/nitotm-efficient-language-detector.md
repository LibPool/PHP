# nitotm/efficient-language-detector

> 标签: detection, detector, language, language classification, language detection, language detector, language identification, language recognition

## 简介

Fast and accurate natural language detection. Detector written in PHP. Nito-ELD, ELD.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
