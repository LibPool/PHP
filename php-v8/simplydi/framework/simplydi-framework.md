# simplydi/framework

> 标签: PSR-11, Skeleton, laminas, mezzio, middleware, psr, psr-15, psr-7

## 简介

A Fullstack PHP Framework based on Mezzio (Zend Expressive)!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
