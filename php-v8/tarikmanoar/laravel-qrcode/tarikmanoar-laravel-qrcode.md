# tarikmanoar/laravel-qrcode

> 标签: Simple, generator, laravel, qrcode, wrapper

## 简介

Laravel QrCode is a QR code generator made for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
