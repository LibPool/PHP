# ecourty/text-chunker

> 标签: chunking, nlp, rag, splitting, text

## 简介

A framework-agnostic PHP library for chunking text and files using pluggable strategies and post-processors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
