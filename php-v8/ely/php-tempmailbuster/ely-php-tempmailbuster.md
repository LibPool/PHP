# ely/php-tempmailbuster

> 标签: email, validation

## 简介

Control emails with black and white lists; make lists of domains using regular expressions and validate emails with them

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
