# jobinja/threads-io-php-plug

> 标签: Threads.io, event, php, wrapper

## 简介

Plug Threads.io to your PHP application and start collecting events data from your users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
