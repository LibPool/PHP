# jweiland/mail-link-fixer

> 标签: PHP

## 简介

Mail Link Fixer (EXT:mail_link_fixer) - CLI command to fix javascript:linkTo_UnCryptMailto() hrefs in RTE Fields

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
