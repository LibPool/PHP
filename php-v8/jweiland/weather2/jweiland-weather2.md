# jweiland/weather2

> 标签: TYPO3 CMS, typo3, weather alert, weather report, weather2

## 简介

Weather Forecasts and Alerts - Display weather data and weather alerts using various Weather APIs. Default APIs: OpenWeatherMap and Deutscher Wetterdienst

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
