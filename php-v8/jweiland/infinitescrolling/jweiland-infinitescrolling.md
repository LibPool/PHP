# jweiland/infinitescrolling

> 标签: TYPO3 CMS, infinite scrolling, infinitescrolling, scrolling, typo3

## 简介

Infinite Scrolling - With this extension you can read nearly every paginator and realize infinite scrolling

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
