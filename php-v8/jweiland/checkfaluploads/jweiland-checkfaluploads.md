# jweiland/checkfaluploads

> 标签: TYPO3 CMS, checkfaluploads, typo3

## 简介

Displays a checkbox that must be checked to upload files in backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
