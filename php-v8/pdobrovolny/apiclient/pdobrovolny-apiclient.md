# pdobrovolny/apiclient

> 标签: google

## 简介

Client library for Google APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/pdobrovolny/google-api-php-client.git
