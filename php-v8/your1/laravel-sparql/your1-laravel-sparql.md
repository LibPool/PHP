# your1/laravel-sparql

> 标签: RDF, database, eloquent, laravel, model, multi-tenancy, sparql

## 简介

A SPARQL based Eloquent model and Query builder for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
