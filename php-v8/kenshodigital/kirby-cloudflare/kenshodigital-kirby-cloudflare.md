# kenshodigital/kirby-cloudflare

> 标签: cache, cdn, cloudflare, cms, kirby

## 简介

Enables Cloudflare Cache for pages in Kirby projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
