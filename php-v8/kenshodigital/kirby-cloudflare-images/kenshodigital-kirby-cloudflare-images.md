# kenshodigital/kirby-cloudflare-images

> 标签: cdn, cloudflare, cms, image, kirby, transformation

## 简介

Transforms images with Cloudflare Images in Kirby projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
