# carejobs/carejobs

> 标签: API-Client, carejobs, healthcare, jobs, mcp, nursing

## 简介

PHP client for the free CareJobs.Now US healthcare jobs API: search open jobs, posted hourly pay, employers and states. No API key.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
