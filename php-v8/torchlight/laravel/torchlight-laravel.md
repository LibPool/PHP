# torchlight/laravel

> 标签: Code highlighting, laravel, syntax highlighting

## 简介

A Laravel Client for Torchlight, the syntax highlighting API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 源码仓库：https://github.com/torchlight-api/torchlight-laravel.git
