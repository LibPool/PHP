# tekton/wp-meta

> 标签: PHP

## 简介

A simple component that adds a Meta Tags metabox to Wordpress posts that lets you manually define meta keywords and description.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
