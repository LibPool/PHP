# drmonty/datatables-plugins

> 标签: datatable, datatables, filter, grid, internationalisable, page, sort, table

## 简介

Plug-ins for DataTables

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
