# brunonatali/event-loop

> 标签: asynchronous, event-loop

## 简介

ReactPHP's core reactor event loop that libraries can use for evented I/O.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
