# hihaho/laravel-encryptable-trait

> 标签: eloquent, encryptable, laravel, model

## 简介

Laravel encryptable trait, easily make certain fields for eloquent models encryptable

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
