# hihaho/laravel-js-store

> 标签: hihaho, laravel-js-store

## 简介

Laravel JS Store - Easily render data to your blade templates to use in your frontend, like Vue

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
