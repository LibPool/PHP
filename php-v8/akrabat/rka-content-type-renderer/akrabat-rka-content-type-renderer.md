# akrabat/rka-content-type-renderer

> 标签: json, psr7, xml

## 简介

Render an array to a JSON/XML/HTML PSR-7 Response based on a PSR-7 Request's Accept header.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
