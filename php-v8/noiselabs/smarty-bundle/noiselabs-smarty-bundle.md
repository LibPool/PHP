# noiselabs/smarty-bundle

> 标签: noiselabs, smarty, symfony, templating

## 简介

This Symfony bundle provides integration for the Smarty3 template engine.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
