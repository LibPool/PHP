# lychee-org/nestedset

> 标签: database, hierarchy, laravel, nested sets, nsm

## 简介

Nested Set Model for Laravel 10.0 and up (fork with patches for Lychee)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
