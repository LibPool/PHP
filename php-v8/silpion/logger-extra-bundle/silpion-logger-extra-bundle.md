# silpion/logger-extra-bundle

> 标签: Symfony2, bundle, extra, logging

## 简介

Extra logging features for Monolog in a Symfony2 bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
