# campusdomar/pumukit-import-bundle

> 标签: Symfony2, bundle, campusdomar, import, pumukit

## 简介

Import bundle for Symfony2 to import Series data from PuMuKIT v1.7, exported previously in XML files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
