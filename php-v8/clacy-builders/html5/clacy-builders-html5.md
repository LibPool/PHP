# clacy-builders/html5

> 标签: HTML5, builder, calendar, html, writer

## 简介

HTML5 Express is a library for creating HTML5 documents. It comes with the calendar trait.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
