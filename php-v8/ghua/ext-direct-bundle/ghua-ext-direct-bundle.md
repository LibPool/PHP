# ghua/ext-direct-bundle

> 标签: Symfony2, bundle, extdirect, extjs

## 简介

ExtDirect implementation for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
