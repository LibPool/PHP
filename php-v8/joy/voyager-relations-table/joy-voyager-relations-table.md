# joy/voyager-relations-table

> 标签: cms, joy, joy-voyager-relations-table, laravel, voyager, voyager-relations-table, voyager-voyager-relations-table

## 简介

This Laravel/Voyager module adds VoyagerRelationsTable support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
