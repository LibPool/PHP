# joy/nova-api

> 标签: api, cms, joy, joy-nova-api, laravel, nova, nova-api, swagger, swagger-ui

## 简介

This Laravel/Nova module adds REST Api with swagger support to Nova.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
