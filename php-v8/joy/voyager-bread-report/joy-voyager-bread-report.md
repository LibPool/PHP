# joy/voyager-bread-report

> 标签: bread-report, cms, joy, joy-voyager-bread-report, laravel, voyager, voyager-bread-report

## 简介

This Laravel/Voyager module adds VoyagerBreadReport support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
