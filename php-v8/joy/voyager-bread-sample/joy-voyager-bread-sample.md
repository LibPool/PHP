# joy/voyager-bread-sample

> 标签: bread-sample, cms, joy, joy-voyager-bread-sample, laravel, voyager, voyager-bread-sample

## 简介

This Laravel/Voyager module adds VoyagerBreadSample support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
