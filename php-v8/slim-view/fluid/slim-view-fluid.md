# slim-view/fluid

> 标签: fluid, framework, slim, template, typo3, view

## 简介

Slim Framework view helper built on top of the TYPO3 Fluid templating engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
