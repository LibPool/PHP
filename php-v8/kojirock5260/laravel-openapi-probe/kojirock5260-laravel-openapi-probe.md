# kojirock5260/laravel-openapi-probe

> 标签: api, contract testing, fuzzing, laravel, openapi, testing

## 简介

Generate requests from an OpenAPI document, send them to your Laravel app in-process, and report where the responses disagree with the document

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
