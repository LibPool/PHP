# 0mithun/php-zkteco

> 标签: Fingerprint, attendances, biometric, laravel, tcp, udp, zkteco

## 简介

A PHP package for managing ZKTeco biometric devices with TCP and UDP protocol support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
