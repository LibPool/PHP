# oki-technologies/laravel-module-test

> 标签: coverage, laravel, laravel-modules, nwidart, pest, testing

## 简介

Run a nwidart/laravel-modules suite a module at a time, with coverage scoped to each module, per-module floors and an exportable scoreboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
