# radynsade/database-clock

> 标签: clock, database, db, mariadb, mysql, pdo, pgsql, postgres, postgresql, psr-20, time

## 简介

PSR-20 clock implementation backed by databases server time.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
