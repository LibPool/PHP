# jontynewman/oku-file

> 标签: file, filesystem, fs, jontynewman, oku, system

## 简介

Functionality for assisting with persistence via a file system for JontyNewman\Oku.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
