# sonergia/laravel-sendinblue

> 标签: laravel, laravel5, laravel7, laravel8, lumen, mailing, sendinblue, stmp

## 简介

Laravel's mail transport for SendinBlue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
