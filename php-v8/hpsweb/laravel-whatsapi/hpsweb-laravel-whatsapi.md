# hpsweb/laravel-whatsapi

> 标签: PHP

## 简介

Uma classe PHP fácil de usar para acessar a API do WhatsApp do meu servidor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
