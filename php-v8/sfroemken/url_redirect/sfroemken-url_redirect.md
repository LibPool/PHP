# sfroemken/url_redirect

> 标签: TYPO3 CMS, redirect, typo3, url, url_redirect

## 简介

Redirect any URL to a new location

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
