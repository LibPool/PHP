# itstructure/yii2-field-widgets

> 标签: field, multilanguage, widget, yii 2, yii2

## 简介

The form field widgets for Yii2 Framework with multilanguage mode support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
