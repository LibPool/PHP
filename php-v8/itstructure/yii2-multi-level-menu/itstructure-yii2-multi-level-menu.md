# itstructure/yii2-multi-level-menu

> 标签: menu, multilevel, yii 2, yii2

## 简介

Widget for rendering multilevel menu for Yii2 Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
