# spomky-labs/pki-framework

> 标签: DER, Private Key, ac, algorithm identifier, asn.1, asn1, attribute certificate, certificate, certification request, cryptography, csr, decrypt, ec, encrypt, pem, pkcs, public key, rsa, sign, signature, verify, x.509, x.690, x509, x690

## 简介

A PHP framework for managing Public Key Infrastructures. It comprises X.509 public key certificates, attribute certificates, certification requests and certification path validation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
