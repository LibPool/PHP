# urban-brussels/wfs-client

> 标签: WFS, geo, geoserver, gis, symfony

## 简介

Fluent PHP client to query WFS layers as objects, optimized for GeoServer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
