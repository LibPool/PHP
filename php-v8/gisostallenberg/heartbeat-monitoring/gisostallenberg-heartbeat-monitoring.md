# gisostallenberg/heartbeat-monitoring

> 标签: cron, cronitor, dead-man-switch, healthchecks, heartbeat, monitoring, pulsetic, sentry, uptime-kuma

## 简介

Adapter-based, DSN-driven heartbeat / cron-job / dead-man's-switch monitoring for healthchecks.io, Uptime Kuma, Pulsetic, Cronitor and Sentry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
