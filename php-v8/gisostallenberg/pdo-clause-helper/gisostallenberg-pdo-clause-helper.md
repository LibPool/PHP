# gisostallenberg/pdo-clause-helper

> 标签: PHP

## 简介

Utility to create placeholder strings to use in WHERE ... IN () clauses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
