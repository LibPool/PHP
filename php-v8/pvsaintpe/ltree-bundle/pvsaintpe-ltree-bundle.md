# pvsaintpe/ltree-bundle

> 标签: ltree, nested, php, php8, postgresql, symfony, symfony4, symfony5

## 简介

Symfony 4 bundle for postgresql ltee extension

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
