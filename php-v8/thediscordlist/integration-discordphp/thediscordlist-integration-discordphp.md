# thediscordlist/integration-discordphp

> 标签: bot-list, discord, discord-bot, discord-php, discordphp, reactphp, thediscordlist, webhooks

## 简介

Official TheDiscordList integration for DiscordPHP: auto-post server count, shard heartbeats and slash commands, and verify inbound webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
