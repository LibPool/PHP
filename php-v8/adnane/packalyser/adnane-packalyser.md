# adnane/packalyser

> 标签: PHP

## 简介

Packalyser is a laravel package to list your dependencies & dev dependencies in a much organized & human-readable way .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
