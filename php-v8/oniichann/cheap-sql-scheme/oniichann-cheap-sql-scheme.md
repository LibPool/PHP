# oniichann/cheap-sql-scheme

> 标签: database, diagram, erd, laravel, migrations, schema, sql

## 简介

Визуальный редактор схем БД для Laravel: таблицы, колонки и связи на холсте, импорт из SQL-дампа или миграций, экспорт в миграции Laravel и .sql для MySQL, PostgreSQL и SQLite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
