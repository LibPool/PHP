# peptolab/peptolab-qa-tools

> 标签: coding-standards, formatter, linter, mago, peptolab, qa, static-analysis

## 简介

Shared QA toolchain for Peptolab packages: Mago formatting, linting and static analysis, plus the PHPUnit baseline and CI workflow. Forked from contenir/contenir-qa-tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
