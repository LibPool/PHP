# lochmueller/faq

> 标签: FAQ, TYPO3 CMS

## 简介

Basic FAQ (Frequently Asked Questions) extension in a clean extbase/fluid structure. Questions and Question categroies with a smart plugin structure.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
