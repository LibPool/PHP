# lochmueller/language-detection

> 标签: TYPO3 CMS, detection, language

## 简介

Modern language detection middleware for TYPO3. Based on PSR-7, PSR-14 & PSR-15.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
