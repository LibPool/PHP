# backstrap/backstrap

> 标签: backbone, bootstrap, browser, client, ui

## 简介

The Backstrap JavaScript library provides a layer of functionality tying together Bootstrap and Backbone.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
