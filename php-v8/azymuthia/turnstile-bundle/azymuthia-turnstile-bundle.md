# azymuthia/turnstile-bundle

> 标签: bundle, captcha, cloudflare, login, security, symfony, turnstile

## 简介

Strict Cloudflare Turnstile verification for Symfony firewalls and forms, refusing whenever it cannot verify.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
