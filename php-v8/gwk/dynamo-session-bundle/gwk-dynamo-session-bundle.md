# gwk/dynamo-session-bundle

> 标签: aws, bundle, dynamodb, session, symfony

## 简介

DynamoDB Session Handler Bundle for Symfony 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
