# brivio-ro/sdk

> 标签: Romania, anaf, brivio, e-factura, fgo, invoicing, oblio, smartbill

## 简介

Official Brivio PHP SDK — invoicing, contacts, articles, locations and module entitlements, plus drop-in compatibility shims for migrating from FGO, SmartBill and Oblio.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
