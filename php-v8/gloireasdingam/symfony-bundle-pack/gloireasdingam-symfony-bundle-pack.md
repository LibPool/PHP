# gloireasdingam/symfony-bundle-pack

> 标签: bundle, doctrine, easyadmin, fixtures, liip, symfony, vich

## 简介

Pack de configuration pour FOSUserBundle, EasyAdminBundle, StofDoctrineExtensionsBundle, LiipImagineBundle, VichUploaderBundle et DoctrineFixturesBundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
