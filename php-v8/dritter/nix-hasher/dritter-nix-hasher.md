# dritter/nix-hasher

> 标签: PHP

## 简介

Provide an easy way to generate SRI Hashes and an Implementation of Nix base32 algorithm.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
