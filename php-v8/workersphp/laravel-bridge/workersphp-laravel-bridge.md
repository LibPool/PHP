# workersphp/laravel-bridge

> 标签: PHP

## 简介

Cloudflare-native Laravel drivers for Workers PHP: D1 database, KV and Durable Object caches, R2 storage, Queues, broadcasting and mail.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
