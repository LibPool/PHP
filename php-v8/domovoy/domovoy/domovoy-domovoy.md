# domovoy/domovoy

> 标签: W3C, code-generation, html, php84, template, type-safe, virtual-dom

## 简介

Type-safe virtual DOM for PHP 8.4+ with typed HTML elements generated from W3C specs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
