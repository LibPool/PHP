> 标签: Content Tools, content, eolica, frontend, frontend translations, laravel, laravel-content-tools, page translations, translations

## 简介

A Laravel package for editing your web frontend translations directly on the page

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
