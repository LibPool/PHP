# daffie/canvas_revisions

> 标签: PHP

## 简介

Revision handling for Drupal Canvas content on the PostgreSQL with JSON entity storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
