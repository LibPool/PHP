# daffie/drupal-core-pgsql-module-remover

> 标签: PHP

## 简介

Composer plugin that removes the pgsql module from Drupal core so a contrib/custom module named 'pgsql' can be used.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
