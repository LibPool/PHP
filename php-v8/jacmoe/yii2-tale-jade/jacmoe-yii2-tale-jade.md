# jacmoe/yii2-tale-jade

> 标签: jade, renderer, tale, yii2

## 简介

A Tale Jade for PHP integration for the Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
