# sydgren/laravel-shipit

> 标签: artisan, ci, deployment, laravel, shipit

## 简介

Trigger and monitor ShipIt deployments from Artisan — php artisan shipit:deploy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
