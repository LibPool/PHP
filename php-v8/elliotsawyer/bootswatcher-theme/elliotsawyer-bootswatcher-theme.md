# elliotsawyer/bootswatcher-theme

> 标签: PHP

## 简介

Bootstrap 5 Silverstripe theme with support for Bootswatch theme switching. Includes the default Bootstrap stylesheet out of the box. Install elliotsawyer/bootswatcher for full CMS-based theme picking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
