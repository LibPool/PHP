# moneymoves/sdk

> 标签: USDC, checkout, money moves, payments, stablecoins, webhooks

## 简介

The official PHP library for the Money Moves Business API: checkouts, payments, settlements, refunds, disputes and webhooks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
