# xquik/x-twitter-scraper

> 标签: API-Client, automation, follower-export, media-download, profile-tweets, sdk, tweet-search, twitter-api, webhooks, x-api

## 简介

PHP SDK for Twitter search, followers, webhooks & X automation through Xquik. Not affiliated with X Corp.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
