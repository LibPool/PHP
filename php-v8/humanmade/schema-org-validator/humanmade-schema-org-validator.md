# humanmade/schema-org-validator

> 标签: JSON-LD, rich results, schema.org, structured data, validation

## 简介

Validate schema.org JSON-LD graphs against the full vocabulary and optional rule profiles such as Google rich results.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
