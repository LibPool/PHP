# humanmade/hm-rest-ability

> 标签: PHP

## 简介

OAuth2 discovery endpoints and a REST API ability for exposing WordPress to MCP clients via the MCP Adapter

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
