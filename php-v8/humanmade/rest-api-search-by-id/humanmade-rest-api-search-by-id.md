# humanmade/rest-api-search-by-id

> 标签: PHP

## 简介

WordPress plugin to support the include & exclude parameters on the REST API /search endpoint.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
