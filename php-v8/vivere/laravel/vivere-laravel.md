# vivere/laravel

> 标签: cron, heartbeat, laravel, monitoring, scheduler, vivere

## 简介

Monitor every Laravel scheduled task with Vivere: get alerted when a task fails, exits non-zero, or doesn't run at all.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
