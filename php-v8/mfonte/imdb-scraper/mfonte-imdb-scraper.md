# mfonte/imdb-scraper

> 标签: api, film, imdb, movie, search

## 简介

Locale-Aware PHP IMDb Scraper, with a fluent API for searching for Movies and TV Shows, and retrieving detailed information about them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
