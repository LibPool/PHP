# oxid-esales/eshop-demodata-installer

> 标签: PHP

## 简介

This tool is used to copy pictures from demo data repository to OXID eShop, during setup process.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
