# coroq/form

> 标签: filter, form, input, nested-form, type-safe, validation

## 简介

Type-safe PHP form validation library with filtering, nested forms, and typed error objects. Zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
