# jacomeit/lexware-php-mcp

> 标签: claude, lexoffice, lexware, mcp, model-context-protocol

## 简介

Unofficial read-only MCP server for Lexware Office (formerly lexoffice), built on the official PHP MCP SDK. Not affiliated with Haufe Group.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
