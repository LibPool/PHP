# egorlaw/ckeditor_codemirror

> 标签: CKEditor, javascript, plugin, text-highlight

## 简介

Composer wrapper for CKEditor Codemirror plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
