# sarder/pdfstudio

> 标签: chromium, dompdf, html-to-pdf, laravel, pdf, tailwind

## 简介

Design, preview, and generate PDFs using HTML and TailwindCSS in Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
