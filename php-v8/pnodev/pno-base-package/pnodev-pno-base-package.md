# pnodev/pno-base-package

> 标签: Site Package, documentation, typo3

## 简介

The TYPO3 base extension that is used for all TYPO3 projects at pno

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
