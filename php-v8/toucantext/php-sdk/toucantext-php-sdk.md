# toucantext/php-sdk

> 标签: PHP

## 简介

The ToucanText PHP SDK is a simple to use interface to help you send and retrieve messages quickly and efficiently.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
