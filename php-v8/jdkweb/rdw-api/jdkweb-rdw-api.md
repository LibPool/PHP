# jdkweb/rdw-api

> 标签: api, laravel, overheid.io, php, rdw

## 简介

Wrapper for RDW API for getting vehicle information from opendata.rdw.nl

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
