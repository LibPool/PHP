# pharsem/expo-sdk

> 标签: expo, expo-push, notifications, push, react-native, sdk

## 简介

A modern, dependency-free PHP SDK for the Expo push notification service, with honest send results.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
