# magium/magento1-clairvoyant-ui

> 标签: PHP

## 简介

A Magento 1 based UI to build Magium Selenium tests in the Admin UI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
