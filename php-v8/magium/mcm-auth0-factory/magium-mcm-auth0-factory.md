# magium/mcm-auth0-factory

> 标签: PHP

## 简介

This library provides a configured instance of the Auth0 PHP adapter using the Magium Configuration Manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
