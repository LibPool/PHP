# magium/mail

> 标签: magento, selenium, testing, webdriver

## 简介

This package allows you to create one-off transactional emails to be used with Magium Selenium tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
