# verisec/verisec-php

> 标签: MICR, aml, api, bin, card, cheque, face, identity verification, kyc, liveness, mrz, sdk, verisec

## 简介

The official PHP library for the VeriSec API: identity (KYC) and Financial checks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
