# omegaalfa/lazy-object

> 标签: lazy-ghost, lazy-object, lazy-proxy, php, reflection

## 简介

Small typed facade for PHP 8.4 native lazy proxies and lazy ghosts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
