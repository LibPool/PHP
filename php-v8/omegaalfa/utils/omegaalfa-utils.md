# omegaalfa/utils

> 标签: .env, configuration, env-loader, environment, utilities

## 简介

A lightweight, zero-dependency PHP utility package designed to provide essential helper functions for small scripts, microservices, and CLI applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
