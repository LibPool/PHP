# mauriciopiber/test-listener-xhprof

> 标签: phpunit, xhprof

## 简介

Fork of the original: A TestListener for PHPUnit that uses XHProf for automated profiling of the tested code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
