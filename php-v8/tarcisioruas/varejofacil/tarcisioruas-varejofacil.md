# tarcisioruas/varejofacil

> 标签: VarejoFacil, api, sdk

## 简介

SDK para comunicao de Projetos PHP com a API do ERP varejofacil

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
