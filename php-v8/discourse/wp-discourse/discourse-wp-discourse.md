# discourse/wp-discourse

> 标签: discourse, wordpress

## 简介

WordPress plugin that allows you to use Discourse as a community engine for your WordPress blog.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
