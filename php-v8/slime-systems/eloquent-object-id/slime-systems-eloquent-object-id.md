# slime-systems/eloquent-object-id

> 标签: ObjectId, bson, chronological, cursor-pagination, eloquent, id, identifier, keyset, laravel, mongodb, object-id, pagination, primary-key, sortable-id, timestamp, unique-id, unique-identifier, uuid

## 简介

MongoDB-style BSON's ObjectId for Eloquent and Laravel. Provides unique, chronologically ordered IDs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
