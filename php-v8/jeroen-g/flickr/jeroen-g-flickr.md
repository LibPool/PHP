# jeroen-g/flickr

> 标签: JeroenG, api, flickr, laravel, php

## 简介

Modern PHP package to make Flickr API calls. Ships with Laravel implementation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
