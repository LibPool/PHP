# skyzyx/monolog-json-pretty-print-formatter

> 标签: json, log, monolog, pretty

## 简介

Pretty-prints JSON responses in the Monolog JsonFormatter!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
