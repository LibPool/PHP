# honkio/laravel

> 标签: canada, casl, email, honkio, laravel, mail, notifications, sms

## 简介

Laravel mail transport and SMS notification channel for HonkIO: Canadian SMS and email, CASL built in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
