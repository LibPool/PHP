# samsara/fermat

> 标签: arbitrary precision, bigint, large numbers, math, numbers, trigonometry

## 简介

A library providing math and statistics operations for numbers of arbitrary size.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
