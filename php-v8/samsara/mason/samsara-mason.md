# samsara/mason

> 标签: attributes, docblock, documentation, phpdoc

## 简介

A PHPDoc docblock interpreter that is simple, easy to use, and provides Attribute alternatives.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
