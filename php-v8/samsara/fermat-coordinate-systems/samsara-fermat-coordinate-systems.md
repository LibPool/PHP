# samsara/fermat-coordinate-systems

> 标签: bigint, cartesian coordinates, coordinate, coordinates, cylindrical coordinates, large numbers, math, numbers, polar coordinates, spherical coordinates

## 简介

A module for the Fermat math library which adds coordinate systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
