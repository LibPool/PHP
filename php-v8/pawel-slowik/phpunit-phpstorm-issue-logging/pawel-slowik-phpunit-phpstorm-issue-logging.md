# pawel-slowik/phpunit-phpstorm-issue-logging

> 标签: testing

## 简介

Show PHPUnit's test warnings / notices / deprecations in PhpStorm UI. Workaround for PHPUnit issue #4711

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
