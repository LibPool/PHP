# sabioweb/api-chatgpt

> 标签: PHP

## 简介

A pure PHP OOP multi-model ChatGPT integration package supporting OCR, Mathematics, Programming, Chat Bot, and Speech models

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
