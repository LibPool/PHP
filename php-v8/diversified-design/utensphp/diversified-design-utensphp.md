# diversified-design/utensphp

> 标签: arrays, helper, numbers, output, php8, strings, utilities

## 简介

PHP 8 utility library providing helper functions for strings, numbers, arrays, output handling, and environment inspection

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
