> 标签: Context, ai, api-documentation, blueprint, ci-cd, class-signatures, cli, code-generation, coding-agent, developer-tools, json, llm, php, reflection, static-analysis, tokens, toon

## 简介

Generates a JSON blueprint of a PHP library's class signatures — optimised for coding-agent contexts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
