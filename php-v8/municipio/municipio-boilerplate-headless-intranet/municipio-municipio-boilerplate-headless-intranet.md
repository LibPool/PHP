# municipio/municipio-boilerplate-headless-intranet

> 标签: PHP

## 简介

Boilerplate for a headless intranet setup of Wordpress with Municipio

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
