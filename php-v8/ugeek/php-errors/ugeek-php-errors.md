# ugeek/php-errors

> 标签: error, error-handler, exception, log, psr-3

## 简介

重写PHP错误处理程序，捕获所有PHP运行时错误并支持通过设置日志器将错误日志记录到日志中。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
