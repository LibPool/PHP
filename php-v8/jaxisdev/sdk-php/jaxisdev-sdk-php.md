# jaxisdev/sdk-php

> 标签: Cognito, api, billing, jaxis, messaging, php, sdk, sms, whatsapp

## 简介

Official Jaxis SDK for PHP - developer-first APIs for SMS, WhatsApp and Billing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
