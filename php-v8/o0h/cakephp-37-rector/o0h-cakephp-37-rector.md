# o0h/cakephp-37-rector

> 标签: PHP

## 简介

Auto fixer for CakePHP Fixtures import declaration to migrate CakePHP 3.7.x.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
