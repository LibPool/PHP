# mtymek/mini-url

> 标签: bit.ly, middleware, psr-7, psr7, short url, shorten, url, url shortener

## 简介

Short URL library, built on PSR-7 and middleware

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
