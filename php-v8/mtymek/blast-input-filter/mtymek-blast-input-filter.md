# mtymek/blast-input-filter

> 标签: PHP

## 简介

Configuration-based setup of zend-validator, zend-filter and zend-inputfilter for Expressive applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
