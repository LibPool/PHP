# nickjacobs/silverstripe-edit-links

> 标签: cms, edit link, editor, elemental, silverstripe

## 简介

Front-end edit badges for SilverStripe pages and Elemental blocks, linking editors straight to the CMS edit form. Auto-injects with no template changes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
