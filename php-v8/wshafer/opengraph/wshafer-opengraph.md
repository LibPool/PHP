# wshafer/opengraph

> 标签: content, manager, open graph, plugin, rcm, reliv

## 简介

Adds an Open Graph tag manager to the Reliv Content Manager.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
