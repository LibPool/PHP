# txtmsg/php-sdk

> 标签: PHP

## 简介

Official PHP SDK for TXTMSG.lk SMS Gateway API v3 — Send bulk SMS, transactional SMS, and manage contacts from any PHP application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
