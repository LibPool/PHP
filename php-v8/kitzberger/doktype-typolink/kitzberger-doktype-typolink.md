# kitzberger/doktype-typolink

> 标签: TYPO3 CMS

## 简介

Enhance doktype 3 ("Link to External URL") to support typolinks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
