# coffeecode/uploader

> 标签: Coffeecode, Image upload, file upload, media upload, upinside, upload

## 简介

It is a easy PHP upload manager for images, files and media in your application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
