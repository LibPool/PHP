# coffeecode/cropper

> 标签: Coffeecode, image cache, image crop, image thumb, thumbnails jpg, thumbnails png, thumbnails webp, upload, webp converter

## 简介

It is a easy and simple PHP image cropper and cache thumb manager

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
