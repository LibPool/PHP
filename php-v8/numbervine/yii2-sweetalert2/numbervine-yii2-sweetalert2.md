# numbervine/yii2-sweetalert2

> 标签: sweetalert2, wrapper, yii2

## 简介

A wrapper to include sweetalert2 assets in yii2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
