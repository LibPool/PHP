# deka/media

> 标签: deka webdesign, laravel-media

## 简介

Toolset for handling media (images and documents) in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/Dirk-Kokx/laravel-media
- 源码仓库：https://bitbucket.org/dkdesign/laravel-media.git
- Packagist 页面：https://packagist.org/packages/deka%2Fmedia

## 历史版本号

- 当前版本：1.0

- 1.0

## 获取地址

- Composer 安装：`composer require deka/media`
- Packagist 仓库：https://repo.packagist.org/p2/deka/media.json
