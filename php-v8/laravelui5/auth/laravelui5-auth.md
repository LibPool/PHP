# laravelui5/auth

> 标签: Authentication, auth, laravel, laravelui5, ui5

## 简介

Password + session authentication for LaravelUi5 apps, with a UI5 frontend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
