# aarondfrancis/urlcrypt

> 标签: PHP

## 简介

PHP library to securely encode and decode short pieces of arbitrary binary data in URLs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
