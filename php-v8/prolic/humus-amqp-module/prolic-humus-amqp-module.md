# prolic/humus-amqp-module

> 标签: AMQP, humus, queue, rabbit, rabbitmq, zf2

## 简介

AMQP module for Zend Framework 2 to integrate RabbitMQ

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
