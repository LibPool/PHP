# dbhelper/dbhelper

> 标签: database, mongo, mysql, redis, sql server, sqlite

## 简介

use databaseobject to easily handle database[pdo,redis,mongodb]

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
