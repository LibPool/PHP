# magenerds/cronprocesscheck

> 标签: PHP

## 简介

Cron Process check for Magento 2. This modules checks if a cron job process crashed and sets its status to error.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
