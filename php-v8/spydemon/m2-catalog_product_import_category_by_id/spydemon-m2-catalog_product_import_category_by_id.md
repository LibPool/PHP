# spydemon/m2-catalog_product_import_category_by_id

> 标签: PHP

## 简介

Modify Magento 2 product import for identifying associated categories by ID instead of named paths.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
