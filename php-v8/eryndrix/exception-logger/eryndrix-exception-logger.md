# eryndrix/exception-logger

> 标签: exceptions, laravel, logging, psr-3

## 简介

Exception logging package for Laravel with PSR-3 levels and attribute-based configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
