# spiderweb/sylius-sendcloud-plugin

> 标签: sendcloud, shipping, sylius, sylius-plugin

## 简介

Sylius 2 plugin for SendCloud shipping automation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
