# ioteducation/gpio

> 标签: GPIO, iot, pi, pin, pins, raspberry, wiring pi, wiringPi

## 简介

An extension that works with a simple api to control GPIO's of Raspberry PI 3, using Wiring Pi library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
