# yannisme/melon

> 标签: flarum, melon, theme

## 简介

A fresh, modular Flarum 2.0 theme with brand customization, dark mode, and layout options.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
