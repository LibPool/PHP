# webpix-io/module-optimizer

> 标签: Webp, avif, cdn, core web vitals, image optimization, magento2, webpix

## 简介

WebPix Optimizer module for Magento 2 storefront images, CSS, JS, SVG and font delivery.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
