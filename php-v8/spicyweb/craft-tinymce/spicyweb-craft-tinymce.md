# spicyweb/craft-tinymce

> 标签: cms, craftcms, field, plugin, tinymce

## 简介

Adds the TinyMCE rich text editor as a Craft CMS field type

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
