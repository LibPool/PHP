# spicyweb/craft-batch-actions

> 标签: Neo, cms, craftcms, field, matrix, plugin

## 简介

A Craft CMS plugin for performing batch actions on Matrix and Neo blocks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
