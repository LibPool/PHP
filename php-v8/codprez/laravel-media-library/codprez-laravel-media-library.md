# codprez/laravel-media-library

> 标签: Thumbnails, Webp, inertia, laravel, library, media, media-manager, react, s3, upload, variants

## 简介

Media library with uploads, image variants (GD/Imagick), any disk (local or S3) and a selector UI for Laravel + Inertia + React.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
