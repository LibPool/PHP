# smtping/smtping-php

> 标签: Email Verifier, bulk email verification, disposable email, email validation, email verification, smtping, spamtrap

## 简介

Official SMTPing SDK for PHP: verify email addresses, run bulk list jobs, and check spamtrap, disposable, spambot and complainer lists.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
