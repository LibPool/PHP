# simonelanini/php-mexal-api

> 标签: API-Client, ERP, gestionale, mexal, passcom, passepartout, psr-18, webapi

## 简介

Client PHP framework-agnostic per le WebAPI Passepartout Mexal / Passcom (PSR-18).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
