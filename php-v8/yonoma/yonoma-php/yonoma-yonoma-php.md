# yonoma/yonoma-php

> 标签: email-api, email-sender, marketing-email, yonoma, yonoma-api, yonoma-php-sdk

## 简介

The official PHP client library for the Yonoma Email Marketing API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
