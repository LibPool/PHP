# pictum/pictum

> 标签: PHP

## 简介

Framework-independent Pictum asset helpers for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/usepictum/pictum-php.git
