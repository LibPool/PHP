# automattic/jetpack-cookie-consent

> 标签: PHP

## 简介

GDPR cookie-consent banner, CCPA opt-out, and consent logging for WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
