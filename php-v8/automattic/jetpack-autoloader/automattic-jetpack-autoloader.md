# automattic/jetpack-autoloader

> 标签: autoload, autoloader, composer, jetpack, plugin, wordpress

## 简介

Creates a custom autoloader for a plugin or theme.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
