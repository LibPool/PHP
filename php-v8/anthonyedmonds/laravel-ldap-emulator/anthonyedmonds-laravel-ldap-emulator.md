# anthonyedmonds/laravel-ldap-emulator

> 标签: active directory, emulator, laravel, ldap

## 简介

Automatically boot an LDAP emulator while working in a local environment.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
