# anthonyedmonds/laravel-mysqlite

> 标签: database, laravel, mysql, sqlite

## 简介

Generate MySQL and Sqlite3 expressions on the fly based on the active database

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
