# andrewsville/php-token-reflection

> 标签: library, reflection, tokenizer

## 简介

Library emulating the PHP internal reflection using just the tokenized source code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
