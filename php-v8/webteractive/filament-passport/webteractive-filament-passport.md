# webteractive/filament-passport

> 标签: admin, filament, laravel, oauth, passport

## 简介

A Filament plugin to manage Laravel Passport OAuth clients, tokens, and auth codes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
