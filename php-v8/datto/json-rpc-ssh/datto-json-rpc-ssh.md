# datto/json-rpc-ssh

> 标签: client, json, json-rpc, jsonrpc, php, php-json-rpc, rpc, server, ssh

## 简介

SSH client and server for JSON-RPC 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://datto.com
- 源码仓库：https://github.com/datto/php-json-rpc-ssh.git
- Packagist 页面：https://packagist.org/packages/datto%2Fjson-rpc-ssh

## 获取地址
