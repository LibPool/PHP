# datto/json-rpc

> 标签: json, json-rpc, jsonrpc, php, php-json-rpc, rpc

## 简介

Fully unit-tested JSON-RPC 2.0 for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
