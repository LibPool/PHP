# covermanager/fast-php-query-builder

> 标签: database, force-index, mysql, pdo, postgresql, profiler, query-builder, schema, sql

## 简介

Fast, lightweight PHP Query Builder with MySQL and PostgreSQL support, JSON schema provider, query profiler, and index hints. Forked from yiisoft/db.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
