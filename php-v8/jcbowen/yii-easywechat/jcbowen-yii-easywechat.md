# jcbowen/yii-easywechat

> 标签: easywechat, jcbowen, php, wechat, yii, yii2

## 简介

WeChat SDK for Yii2 , 基于 w7corp/easywechat 5.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
