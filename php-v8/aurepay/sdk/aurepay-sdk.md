# aurepay/sdk

> 标签: aurepay, brazil, openapi, payments, pix, sdk

## 简介

SDK oficial da API AurePay para PHP (tipado via OpenAPI)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://api.aurepay.com.br/docs/sdks
- 源码仓库：https://github.com/grupojrx/aurepay-php.git
- Packagist 页面：https://packagist.org/packages/aurepay%2Fsdk
