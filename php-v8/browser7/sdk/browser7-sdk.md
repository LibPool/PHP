# browser7/sdk

> 标签: API-Client, Rendering, automation, browser7, captcha, captcha-solver, geo-targeting, headless-browser, proxy, scraping, web-scraping 

## 简介

Official PHP SDK for Browser7 - Geo-targeted web scraping with automatic CAPTCHA solving and wait actions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
