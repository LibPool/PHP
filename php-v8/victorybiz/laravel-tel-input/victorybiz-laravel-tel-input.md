# victorybiz/laravel-tel-input

> 标签: blade, international-telephone-input, intl-tel-input, laravel, laravel-blade, laravel-livewire, laravel-tel-input, livewire, livewire-tel-input, tel-input, telephone-input, victorybiz

## 简介

Laravel Telephone Input component for Blade and Livewire based on the intl-tel-input JavaScript plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
