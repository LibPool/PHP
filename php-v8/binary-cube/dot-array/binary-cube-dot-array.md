# binary-cube/dot-array

> 标签: array, dot, dot-array, dotarray, php-array, php-array-json-path

## 简介

Navigate through array using JSON Dot notation path.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
