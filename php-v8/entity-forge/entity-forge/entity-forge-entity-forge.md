> 标签: code-generation, database-per-tenant, entity, framework, migrations, multi-tenant, multitenancy, orm, pdo, php, repository, saas, symfony-console, tenant-isolation

## 简介

A configuration-driven PHP framework for generating entity models and building multi-tenant SaaS applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
