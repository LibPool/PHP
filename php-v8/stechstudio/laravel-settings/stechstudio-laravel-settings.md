# stechstudio/laravel-settings

> 标签: Settings, eloquent, laravel, polymorphic, preferences

## 简介

Polymorphic, typed key/value settings for any Eloquent model.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
