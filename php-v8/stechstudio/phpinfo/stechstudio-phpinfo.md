# stechstudio/phpinfo

> 标签: configuration, php-info, phpinfo, pretty-phpinfo, server-info

## 简介

A beautiful, searchable replacement for phpinfo() with a clean programmatic API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
