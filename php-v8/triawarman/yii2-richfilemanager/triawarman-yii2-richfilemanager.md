# triawarman/yii2-richfilemanager

> 标签: extension, file manager, yii2

## 简介

Yii 2 wrapper for servocoder/RichFilemanager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
