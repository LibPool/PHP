# matrixcreate/contentiq-craft-import

> 标签: Craft, cms, content, contentiq, import, plugin

## 简介

Import ContentiQ content exports into Craft CMS 5 entries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
