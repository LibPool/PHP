# naiskit/laravel-oops

> 标签: 404, 500, error page, exception handler, laravel

## 简介

A friendly Laravel error page package that makes unexpected errors a little less frustrating.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
