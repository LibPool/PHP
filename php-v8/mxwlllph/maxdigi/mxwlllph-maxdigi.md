# mxwlllph/maxdigi

> 标签: api, digiflazz, laravel, wrapper

## 简介

A Laravel wrapper for the DigiFlazz API with async jobs and webhook handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
