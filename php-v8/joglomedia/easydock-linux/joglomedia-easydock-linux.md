# joglomedia/easydock-linux

> 标签: container, debian, docker, lemp, lnmp, nginx, php, ubuntu

## 简介

A fork of EasyDock for Linux. Docker LEMP stack easy integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
