# xaviworks/modular-schema-ui

> 标签: PHP

## 简介

A frontend-neutral modular schema-driven UI toolkit for Laravel with optional Blade, React, Vue, and Livewire adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
