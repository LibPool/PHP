# seothemes/core

> 标签: genesis-framework, wordpress, wordpress-plugin

## 简介

Core functionality plugin for SEO Themes Genesis child themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
