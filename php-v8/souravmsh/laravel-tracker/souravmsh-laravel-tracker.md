# souravmsh/laravel-tracker

> 标签: analytics, laravel, referral-tracking, tracker, visitor-logs

## 简介

A Laravel package for tracking visitor referrals and logging visitor data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
