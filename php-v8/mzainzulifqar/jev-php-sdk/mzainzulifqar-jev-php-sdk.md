# mzainzulifqar/jev-php-sdk

> 标签: ai, classification, decisions, jev, system-one, typesafe

## 简介

PHP SDK for TypeSafe AI System One models (Jev): send state and typed questions, get calibrated typed decisions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
