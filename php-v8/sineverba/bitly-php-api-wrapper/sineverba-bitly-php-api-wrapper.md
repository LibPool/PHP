# sineverba/bitly-php-api-wrapper

> 标签: api, bit.ly, bitly, php, wrapper

## 简介

PHP Wrapper for APIv4 Bit.ly

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
