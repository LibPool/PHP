# tvalimaa/mautic-altcha-bundle

> 标签: ALTCHA, Mautic, captcha, integration, plugin, proof-of-work, spam-protection

## 简介

Self-hosted, privacy-friendly ALTCHA (proof-of-work CAPTCHA) integration for Mautic forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
