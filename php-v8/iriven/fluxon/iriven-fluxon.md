# iriven/fluxon

> 标签: Forms, api, frontend, headless, php, runtime, schema, validation

## 简介

Fluxon is a PHP form engine for headless, frontend, runtime, and distributed form workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
