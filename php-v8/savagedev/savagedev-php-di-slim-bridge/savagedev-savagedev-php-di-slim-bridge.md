# savagedev/savagedev-php-di-slim-bridge

> 标签: PHP

## 简介

PHP-DI bridge for Slim 4 with fixes for psr/container v2. This package will be inactive when and if slim-bridge package is update.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
