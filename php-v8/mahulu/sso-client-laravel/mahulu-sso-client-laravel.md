# mahulu/sso-client-laravel

> 标签: Authentication, SSO, laravel, mahulu, oauth2

## 简介

Laravel package untuk integrasi dengan SSO Mahulu (OAuth 2.0 Authorization Code Flow)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
