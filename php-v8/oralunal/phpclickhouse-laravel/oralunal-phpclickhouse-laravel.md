# oralunal/phpclickhouse-laravel

> 标签: clickhouse, laravel, php

## 简介

Adapter of the most popular library https://github.com/smi2/phpClickHouse to Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
