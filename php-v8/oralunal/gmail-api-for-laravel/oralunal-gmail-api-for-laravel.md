# oralunal/gmail-api-for-laravel

> 标签: gmail-api-for-laravel, laravel, oralunal

## 简介

A Laravel package that allows you to use Gmail API as a mail driver

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
