# ijeffro/laralocker

> 标签: laravel, learning locker, lrs, xAPI

## 简介

A Laravel API connector for Learning Locker®, the open-source Learning Record Store.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
