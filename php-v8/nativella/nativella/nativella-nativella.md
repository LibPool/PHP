# nativella/nativella

> 标签: desktop, native, nativella, tauri

## 简介

The desktop APIs of Nativella for PHP: windows, menus, dialogs, notifications, clipboard, tray…

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
