# celdotro/marketplace

> 标签: api-wrapper, cel, cel-marketplace, celdotro, marketplace, marketplace-api-wrapper, php, wiki

## 简介

CEL.ro Marketplace API wrapper in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
