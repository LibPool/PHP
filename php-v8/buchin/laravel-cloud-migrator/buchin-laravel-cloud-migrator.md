# buchin/laravel-cloud-migrator

> 标签: cli, laravel, laravel-cloud, migration

## 简介

CLI tool for migrating Laravel Cloud applications between organizations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
