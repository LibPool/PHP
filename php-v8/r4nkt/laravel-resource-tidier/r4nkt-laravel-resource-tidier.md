# r4nkt/laravel-resource-tidier

> 标签: laravel, r4nkt, resource, tidy

## 简介

A simple-but-opinionated set of classes that allows for configurable tidying of various user resources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
