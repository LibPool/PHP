# jonatasrt/template

> 标签: html, php8, template, template-engine, view

## 简介

Template engine PHP 8+ sem código PHP no HTML: variáveis, blocos, objetos e modificadores. Compatível com a sintaxe do raelgc/template.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
