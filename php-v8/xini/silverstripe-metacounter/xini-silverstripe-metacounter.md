# xini/silverstripe-metacounter

> 标签: counter, limit, metadata, silverstripe

## 简介

Adds a counter to the meta fields for remaining characters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
