# cagri/nexus

> 标签: Agent, ChatGpt, ai, anthropic, claude, function-calling, gpt, llm, machine-learning, ollama, openai, php, streaming, tool-calling

## 简介

High-performance, provider-agnostic LLM agent framework for PHP. Supports OpenAI, Anthropic, Ollama, and any OpenAI-compatible API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
