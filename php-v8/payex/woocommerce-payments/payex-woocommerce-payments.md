# payex/woocommerce-payments

> 标签: PHP

## 简介

PayEx Payment Provider for WooCommerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/PayEx/payex-woocommerce-payments
- 源码仓库：https://github.com/PayEx/payex-woocommerce-payments.git
- Packagist 页面：https://packagist.org/packages/payex%2Fwoocommerce-payments

## 获取地址

- Composer 安装：`composer require payex/woocommerce-payments`

- 许可证：Apache-2.0
