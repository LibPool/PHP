# victorvolpe/php-pdo-wrapper

> 标签: database, db, mysql, pdo, php, wrapper

## 简介

A modern PDO wrapper for PHP 8.2+, supporting dynamic placeholders and secure database access.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
