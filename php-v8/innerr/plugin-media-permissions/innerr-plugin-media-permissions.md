# innerr/plugin-media-permissions

> 标签: PHP

## 简介

NativePHP plugin that contributes iOS Info.plist usage descriptions for camera, microphone, and photo library access (Innerr).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
