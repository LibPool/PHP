# mnlnk/php-ex

> 标签: php, php-ex, tools, utils

## 简介

Небольшое дополнение к PHP. Надеюсь, когда-нибудь они это добавят в стандартную библиотеку.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
