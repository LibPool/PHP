# hot-ui/hot-ui

> 标签: alpinejs, codeigniter, components, no-framework, shadcn, tailwind, ui, zero-dependency

## 简介

Hot-UI — zero-dependency shadcn-style UI component library for plain PHP 8.2+ with typed Alpine.js islands. No framework, no template engine: works in CodeIgniter 4, League Plates, Blade or any PHP app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
