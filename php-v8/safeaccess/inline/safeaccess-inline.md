# safeaccess/inline

> 标签: array-access, data-access, dot-notation, nested-data, null-safe, object-access, safeaccess

## 简介

Safe nested data access with dot notation for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
