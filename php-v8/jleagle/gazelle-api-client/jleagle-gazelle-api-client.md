# jleagle/gazelle-api-client

> 标签: cd, gazelle, torrent, tracker, what, what.cd

## 简介

A helper class to access the API on Gazelle sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
