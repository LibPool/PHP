# jleagle/omdb-imdb-api-client

> 标签: api, client, helper, imdb, omdb

## 简介

A package to retrieve movies and TV information from IMDB using the API at omdbapi.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
