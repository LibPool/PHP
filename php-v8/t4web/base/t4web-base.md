# t4web/base

> 标签: abstract classes, base, zf2

## 简介

ZF2 Module. A set of generic (abstract) classes which are commonly used across multiple modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
