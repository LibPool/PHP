# victord11/scout-elasticsearch-driver

> 标签: driver, elastic, elasticsearch, engine, laravel, scout, search

## 简介

The Elasticsearch Driver for Laravel Scout with support PHP 8 and Laravel 10

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
