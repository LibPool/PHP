# vmeditab/laravel-odbc-driver

> 标签: database, driver, odbc

## 简介

ODBC driver for Laravel 8.x & PHP 8.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
