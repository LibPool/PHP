# murdercode/laravel-shortcode-plus

> 标签: embed, laravel, laravel-shortcode-plus, murdercode, shortcode, shortcodes

## 简介

A package that allows you to use custom shortcodes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
