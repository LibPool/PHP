# libxa/socket

> 标签: Broadcasting, echo, libxa, libxaframe, pusher, reactphp, realtime, websocket

## 简介

A Pusher-protocol WebSocket server for LibxaFrame, built on ReactPHP. Works with Laravel Echo unchanged.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
