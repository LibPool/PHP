# libxa/framework

> 标签: Fibers, WebSockets, async, blade, framework, orm, php, router

## 简介

LibxaFrame core framework — Foundation, Router, Atlas ORM, Blade-X, Reactive, Modules, Frontend Adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
