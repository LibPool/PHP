# libxa/vite

> 标签: SPA, libxa, libxaframe, monolith, react, svelte, vite, vue

## 简介

Build a single-page app with LibxaFrame controllers and Vite components. No API, no client-side routes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
