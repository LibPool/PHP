# libxa/secure

> 标签: Audit, encryption, libxa, libxaframe, security, threat-detection

## 简介

Encryption with key rotation, audit logging and threat detection for LibxaFrame.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
