# ministryofweb/php-osm-tiles

> 标签: OpenStreetMap, coordinate, geographic, location, maptile, osm, tile

## 简介

A library to convert map tile numbers to coordinates and vice versa.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
