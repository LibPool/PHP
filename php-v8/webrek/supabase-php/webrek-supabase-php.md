# webrek/supabase-php

> 标签: gotrue, postgrest, realtime, sdk, storage, supabase, websocket

## 简介

Framework-agnostic PHP client for Supabase (database, auth, storage, edge functions, realtime).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
