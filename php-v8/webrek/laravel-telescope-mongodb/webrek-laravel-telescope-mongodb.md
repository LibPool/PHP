> 标签: apm, debugging, laravel, laravel-package, laravel-telescope, logging, mongodb, mongodb-driver, observability, telescope

## 简介

Native MongoDB storage driver for Laravel Telescope.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
