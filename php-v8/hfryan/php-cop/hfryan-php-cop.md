# hfryan/php-cop

> 标签: Audit, cli, composer, dependencies, security, vulnerability

## 简介

PHP Cop checks composer.lock and flags outdated or suspicious packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
