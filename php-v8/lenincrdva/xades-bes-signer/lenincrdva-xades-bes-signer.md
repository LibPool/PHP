# lenincrdva/xades-bes-signer

> 标签: digital-signature, ecuador, factura-electronica, p12, signature, sri, xades, xades-bes, xml, xmlsec

## 简介

PHP library to sign and verify XML documents under the XAdES-BES standard, compliant with the SRI (Ecuador) electronic invoicing requirements.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
