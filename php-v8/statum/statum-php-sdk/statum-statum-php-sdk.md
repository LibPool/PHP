# statum/statum-php-sdk

> 标签: airtime, kenya, mpesa, payments, sms, statum

## 简介

Official PHP SDK for Statum APIs (SMS, Airtime, Account)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
