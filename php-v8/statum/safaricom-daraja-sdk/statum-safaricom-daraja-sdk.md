# statum/safaricom-daraja-sdk

> 标签: Guzzle, daraja, laravel, mpesa, payments, safaricom, sdk

## 简介

Production-ready, type-safe PHP 8.2+ Safaricom Daraja SDK for M-Pesa STK Push, C2B, B2B/B2C and Pochi payments, Dynamic QR, Bill Manager, Lipa na Bonga, IoT SIM Portal, Mobile Center, KYC, and GSM/network utilities across web and mobile apps, with OAuth lifecycle management and optional Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
