# plumtreesystems/sylius-secure-trading-plugin

> 标签: sylius, sylius-plugin

## 简介

This is a sylius plugin that implements the PlumTreeSystems/SecureTrading gateway.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
