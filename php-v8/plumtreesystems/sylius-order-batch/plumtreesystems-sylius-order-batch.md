# plumtreesystems/sylius-order-batch

> 标签: sylius, sylius-plugin

## 简介

A plugin that lets you customize how you filter your orders and save them into batches.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
