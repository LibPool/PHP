# ancient-web/phpunit-test-time

> 标签: extension, paratest, performance, phpunit, testing

## 简介

PHPUnit extension that measures per-test execution time and writes a report sorted by duration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
