# b13/vh_imagedata

> 标签: B13base, TYPO3 CMS

## 简介

Viewhelper for accessing data of a (processed) image for further use (like <img>-tag w/ lazy loading etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
