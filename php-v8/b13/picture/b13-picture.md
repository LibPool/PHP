# b13/picture

> 标签: PHP

## 简介

Picture: Extended Image ViewHelper - Improved TYPO3 image ViewHelper creating picture elements with support for sizes, sources, additional image formats, etc.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
