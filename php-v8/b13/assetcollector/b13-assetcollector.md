# b13/assetcollector

> 标签: PHP

## 简介

Asset collector - Add CSS and SVG files and strings as inline style tag/inline svg to the html code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
