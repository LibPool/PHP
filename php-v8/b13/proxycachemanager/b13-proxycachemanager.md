# b13/proxycachemanager

> 标签: cache, cdn, proxy, purge, typo3, varnish

## 简介

TYPO3 Extension that automatically flushes cached URLs within a proxy / CDN.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
