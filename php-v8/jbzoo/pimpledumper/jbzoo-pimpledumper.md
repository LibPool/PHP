# jbzoo/pimpledumper

> 标签: ArrayAccess, autocomplete, container, di, idea, phpstorm, pimple, silex

## 简介

Easy way to auto create pimple.json and .phpstorm.meta.php for Pimple Container

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
