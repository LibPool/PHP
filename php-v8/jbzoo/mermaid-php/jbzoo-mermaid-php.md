# jbzoo/mermaid-php

> 标签: diagrams, flowcharts, mermaid, mermaid-js

## 简介

Generate diagrams and flowcharts with the help of the mermaid script language

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
