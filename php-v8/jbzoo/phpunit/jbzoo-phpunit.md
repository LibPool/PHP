# jbzoo/phpunit

> 标签: aliases, assert, assertion, debug, jbzoo, phpunit, short-syntax, testing

## 简介

PHPUnit toolbox with short assert aliases and useful functions around testing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
