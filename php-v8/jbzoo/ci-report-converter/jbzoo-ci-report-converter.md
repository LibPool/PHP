# jbzoo/ci-report-converter

> 标签: Codestyle, Github Actions, IntelliJ IDEA, PHPStan, actions, checkstyle, ci, continuous integration, github, inspections, junit, phan, phpcs, phploc, phpmd, phpmnd, phpstorm, pmd, psalm, teamcity, teamcity-inspections, tests

## 简介

The tool converts different error reporting standards for deep integration with popular CI systems (TeamCity, IntelliJ IDEA, GitHub Actions, etc)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
