# jbzoo/cli

> 标签: ELK, cli, command-line, console, console-application, cron, crontab, elastic, elk-stack, jbzoo, logstash, process, symfony, symfony-console, symfony-process, terminal

## 简介

The framework helps create CLI tools and provides new tools for symfony/console, symfony/process.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
