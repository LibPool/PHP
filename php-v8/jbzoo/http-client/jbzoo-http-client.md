# jbzoo/http-client

> 标签: Guzzle, client, curl, guzzlehttp, http, https, request, requests, rmccue

## 简介

Simple HTTP-client, wrapper around Guzzle and rmccue/requests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
