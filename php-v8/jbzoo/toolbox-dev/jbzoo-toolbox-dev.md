# jbzoo/toolbox-dev

> 标签: Toolbox, debug, dev, dev-kit, developer, devkit, jbzoo

## 简介

Developer toolbox only for JBZoo libs on github+travis

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
