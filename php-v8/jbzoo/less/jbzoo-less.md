# jbzoo/less

> 标签: compiler, css, gpeasy, jbzoo, leafo, less, less.js, lessc, lesscss, packagist, stylesheet

## 简介

PHP wrapper for any less-compilers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
