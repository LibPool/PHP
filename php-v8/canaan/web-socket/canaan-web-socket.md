# canaan/web-socket

> 标签: Socket, framework, laravel, php, server, web, websocket

## 简介

Laravel library for asynchronously serving WebSockets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
