# ewk/moonshine-resource-kit

> 标签: activatable, admin, drag-and-drop, laravel, moonshine, reorderable, sortable

## 简介

Drag & drop sorting and activity toggling toolkit for MoonShine 4 resources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
