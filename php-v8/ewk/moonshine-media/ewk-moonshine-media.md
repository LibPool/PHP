# ewk/moonshine-media

> 标签: admin, attachments, images, laravel, media, media-library, moonshine, uploads

## 简介

Media library for Laravel with a MoonShine 4 admin: folders, variants, usages, attachments, a picker field and a gallery field.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
