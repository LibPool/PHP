# ewk/laravel-openapi

> 标签: Swagger-PHP, api-documentation, laravel, openapi, swagger

## 简介

Reusable OpenAPI response envelopes, request bodies, parameters, and components for Laravel APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
