# ewk/moonshine-cms

> 标签: admin, blocks, cms, laravel, menus, moonshine, page-builder, pages, seo

## 简介

Block CMS for Laravel with a MoonShine 4 admin: blocks, a page tree with an address resolver, layouts, headers, footers and menus, metadata and a sitemap feed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
