# deviscoding/caniparse

> 标签: browser, can i use, caniuse, feature, parser, php

## 简介

Object-oriented PHP parser for raw CanIUse JSON data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
