# deviscoding/custom-time

> 标签: bootstrap, replacement, sass, time

## 简介

Cross browser time implementation using CSS and JQuery.  Compatible with Twitter Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
