# deviscoding/poly-pointer

> 标签: coarse, exactquery, media query level 4, metro, pointer, polyfill, tablet, touch

## 简介

Vanilla Javascript psuedo-polyfill for Media Query Level 4's '(pointer:coarse)'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
