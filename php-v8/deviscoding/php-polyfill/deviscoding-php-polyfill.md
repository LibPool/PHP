# deviscoding/php-polyfill

> 标签: PHP

## 简介

PHP Polyfill functions, interfaces, and classes in a PHP 7.0 friendly library for legacy applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
