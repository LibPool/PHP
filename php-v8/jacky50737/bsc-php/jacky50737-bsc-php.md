# jacky50737/bsc-php

> 标签: BEP20, binance, bnb, php

## 简介

支援 Binance 的 BNB 和 BEP20，包括地址創建、餘額查詢、交易轉帳、查詢最新區塊鏈、基於區塊鏈查詢資訊以及基於交易哈希查詢資訊等功能

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
