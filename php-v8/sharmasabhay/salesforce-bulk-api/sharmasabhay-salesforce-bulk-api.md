# sharmasabhay/salesforce-bulk-api

> 标签: api, bulk, client, salesforce

## 简介

Client for Salesforce Bulk Api. Easy way to manipulate your Salesforce data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
