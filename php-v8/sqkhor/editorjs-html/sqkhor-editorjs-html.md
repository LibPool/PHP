# sqkhor/editorjs-html

> 标签: editorjs, editorjs-html, html, json, parsing

## 简介

A utility to parse editorjs clean data to HTML. Based on editorjs-html by Pavittar Singh

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
