# x3d/think3-orm

> 标签: PHP

## 简介

ThinkPHP 3.2.x 中的 orm 库 独立封装，基以便一些遗留项目迁移核心的model层

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
