# companue/contacts

> 标签: companue, contacts, customers, laravel, multilingual, vendors

## 简介

Laravel package for managing contacts including customers, vendors, and other contact types with multilingual support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
