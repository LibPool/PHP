# leigh/poly1305

> 标签: Authentication, MAC, aes, authenticator, encryption, security

## 简介

Pure PHP implementations of the Poly1305 MAC algorithm.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
