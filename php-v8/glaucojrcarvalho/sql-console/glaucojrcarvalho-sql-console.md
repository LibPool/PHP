# glaucojrcarvalho/sql-console

> 标签: console, database, laravel, mysql, oracle, sql

## 简介

Browser SQL console for Laravel with safe-guarded execution and multi-connection support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
