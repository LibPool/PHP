# epsoftware/doctrine-odm-encrypt

> 标签: aes256, decrypt, doctrine, encrypt

## 简介

Package encrypts and decrypts Doctrine fields through life cycle events.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
