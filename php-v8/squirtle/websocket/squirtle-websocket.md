# squirtle/websocket

> 标签: client, event-loop, native, rfc6455, server, websocket

## 简介

PHP 8.2+ WebSocket server and client built on stream_select(), RFC 6455 compliant

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
