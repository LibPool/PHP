# ebsp/resting

> 标签: api, laravel, openapi, resources, rest, swagger, transformer, validation

## 简介

Typed REST resources, validation, and OpenAPI generation for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
