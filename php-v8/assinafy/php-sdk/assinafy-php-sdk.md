# assinafy/php-sdk

> 标签: API-Client, assinafy, digital-signature, e-signature, sdk

## 简介

Modern, framework-agnostic PHP SDK for the Assinafy digital signature API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
