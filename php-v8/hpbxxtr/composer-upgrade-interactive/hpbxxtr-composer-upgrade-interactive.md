> 标签: cli, composer, composer-plugin, dependencies, interactive, laravel-prompts, outdated, packagist, php, semver, tui, update, upgrade, yarn

## 简介

Interactive TUI for selectively upgrading Composer dependencies (yarn upgrade-interactive for PHP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
