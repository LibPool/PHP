# webiland/bitrix-install

> 标签: 1C-Bitrix, bitrix, docker

## 简介

bitrix-install: Docker starter for 1C-Bitrix (nginx, PHP 8.2, MySQL 8, Redis, MailHog, cron)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
