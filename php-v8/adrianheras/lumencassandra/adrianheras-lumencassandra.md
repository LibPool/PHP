# adrianheras/lumencassandra

> 标签: cassandra, cql, database, lumen, nosql, query builder

## 简介

Cassandra support for Lumen 5.7.x database query builder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
