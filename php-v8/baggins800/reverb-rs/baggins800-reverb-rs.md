# baggins800/reverb-rs

> 标签: Broadcasting, WebSockets, laravel, pusher, reverb, rust

## 简介

Laravel integration for reverb-rs, a drop-in Rust replacement for the Laravel Reverb WebSocket server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
