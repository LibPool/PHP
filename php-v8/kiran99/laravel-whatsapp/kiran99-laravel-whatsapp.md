# kiran99/laravel-whatsapp

> 标签: kiran99, laravel, laravel-whatsapp

## 简介

A Laravel package for sending WhatsApp messages using the WhatsApp Cloud API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
