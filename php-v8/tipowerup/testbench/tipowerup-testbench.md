# tipowerup/testbench

> 标签: PHP

## 简介

Shared testing foundation for TI PowerUp extensions. Provides full Laravel + TastyIgniter context in tests with dual-mode support (host app and standalone CI).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
