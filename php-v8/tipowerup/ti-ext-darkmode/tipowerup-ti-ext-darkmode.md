# tipowerup/ti-ext-darkmode

> 标签: dark-mode, darkreader, tastyigniter, theme

## 简介

Adds dark mode to TastyIgniter admin and storefront with scheduling support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
