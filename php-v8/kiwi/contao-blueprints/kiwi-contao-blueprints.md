# kiwi/contao-blueprints

> 标签: article templates, blueprints, contao, preview, templates

## 简介

This Contao bundle allows you to create reusable article blueprints with preview when inserting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
