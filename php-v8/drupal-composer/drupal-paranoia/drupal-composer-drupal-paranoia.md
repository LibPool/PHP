# drupal-composer/drupal-paranoia

> 标签: PHP

## 简介

Composer Plugin for improving the security of composer-based Drupal projects by moving all PHP files out of docroot.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
