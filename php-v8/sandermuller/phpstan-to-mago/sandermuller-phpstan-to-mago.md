# sandermuller/phpstan-to-mago

> 标签: PHPStan, mago, static-analysis, transpiler

## 简介

Transpile PHPStan rules into Mago analyzer plugins

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
