# sandermuller/boost-pipeline

> 标签: agents, ai, developer-tools, laravel, mcp, pipeline, verification

## 简介

A drip-feed verification pipeline as an MCP server: phases, steps, and a cursor the agent cannot move.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
