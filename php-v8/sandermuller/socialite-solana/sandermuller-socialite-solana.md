# sandermuller/socialite-solana

> 标签: auth, laravel, siws, socialite, solana, wallet

## 简介

A Laravel Socialite provider for Solana wallet sign-in (Sign-In With Solana).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
