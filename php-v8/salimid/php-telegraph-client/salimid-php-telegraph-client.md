# salimid/php-telegraph-client

> 标签: PHP

## 简介

The PHP Telegraph Client is a set of simple classes to interact with Telegra.ph.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
