# creativecrafts/laravel-module-design-commands

> 标签: CreativeCrafts Solutions, laravel, laravel-module-design-commands

## 简介

This is a simple package to create an opinionated laravel module design.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
