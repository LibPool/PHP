# rhaima/voltpanel

> 标签: admin, crud, inertia, laravel, panel, tailwind, vilt, vue

## 简介

A powerful admin panel builder for Laravel using the VILT stack (Vue, Inertia, Laravel, Tailwind)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
