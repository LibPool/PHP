# limesoda-com/ls-csp-widget

> 标签: LIMESODA, TYPO3 CMS, content security policy, csp, dashboard, extension, violations, widget

## 简介

Offers a widget to display the most recent content security policy (CSP) frontend violations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
