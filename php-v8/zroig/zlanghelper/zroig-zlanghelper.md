# zroig/zlanghelper

> 标签: i18n, inertia, laravel, translations, vue

## 简介

zLangHelper works as a simple translation helper for Laravel and Inertia projects. Making Laravel translations work as normal with Vue. You can find a guide at: https://github.com/Zroig/zLangHelper

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
