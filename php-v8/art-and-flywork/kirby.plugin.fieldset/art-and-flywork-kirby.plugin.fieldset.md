# art-and-flywork/kirby.plugin.fieldset

> 标签: PHP

## 简介

Panel field which loads a fieldset and stores the values in a single field as yaml

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
