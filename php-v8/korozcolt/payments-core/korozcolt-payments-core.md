# korozcolt/payments-core

> 标签: Wompi, colombia, epayco, framework-agnostic, mercadopago, payment-gateway, payments, psr-18

## 简介

Framework-agnostic core of korozcolt/payments: Wompi, MercadoPago and ePayco drivers for any PHP project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
