# korozcolt/ai-gateway

> 标签: ChatGpt, Gemini, OCR, OpenRouter, ai, anthropic, claude, gateway, laravel, llm, multimodal, nvidia, openai, structured-output

## 简介

A multi-provider AI gateway for Laravel: provider connections and encrypted API tokens stored in the database, Anthropic (Claude), OpenAI, OpenAI-compatible (OpenRouter, NVIDIA Build, Azure, Mistral, Groq), Gemini and fake drivers, multimodal requests and usage metering.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
