# mademedia/silverstripe-markdown

> 标签: markdown, silverstripe

## 简介

SilverStripe Module. Replaces TinyMCE editor with a Markdown editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
