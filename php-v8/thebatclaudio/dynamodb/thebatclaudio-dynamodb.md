# thebatclaudio/dynamodb

> 标签: aws, dynamodb, laravel

## 简介

Eloquent syntax for DynamoDB (fork of baopham/dynamodb that is abandoned)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
