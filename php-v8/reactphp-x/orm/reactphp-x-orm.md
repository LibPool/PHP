# reactphp-x/orm

> 标签: database, illuminate, mysql, orm, react, reactphp

## 简介

A database OMR for ReactPHP based on illuminate/database and react/mysql packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
