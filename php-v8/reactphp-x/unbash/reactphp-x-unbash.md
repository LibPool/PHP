# reactphp-x/unbash

> 标签: ast, bash, lexer, parser, posix, shell, tokenizer

## 简介

Fast, zero-dependency Bash parser for PHP - turns Bash source into a typed, source-positioned AST without executing it. A PHP port of webpro-nl/unbash.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
