# antlr/antlr-php-runtime-phpstan

> 标签: PHPStan, antlr4, php

## 简介

ANTLR4 PHP Runtime extensions for PHPStan.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
