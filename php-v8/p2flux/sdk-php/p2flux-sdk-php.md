# p2flux/sdk-php

> 标签: USDC, ai-agents, base, checkout, erc20, payments, paywall, recurring, stablecoin, subscriptions, x402

## 简介

P2Flux payment execution client. Your application keeps the subscription lifecycle; this charges when you say a renewal is due.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
