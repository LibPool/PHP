# nicolasbonnici/php-binance-api

> 标签: binance, cryptocurrency, websocket

## 简介

PHP Binance API is an asynchronous PHP library for the Binance API designed to be easy to use.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
