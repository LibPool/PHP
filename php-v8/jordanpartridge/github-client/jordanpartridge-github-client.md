# jordanpartridge/github-client

> 标签: API-Client, GitHub-API, git, github, github-client, issues, laravel, php, pull-requests, repositories, saloon, version-control

## 简介

Laravel client for the GitHub REST API, built with Saloon. Typed responses for repositories, issues, pull requests, commits, releases, and Actions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
