# jordanpartridge/spotify-client

> 标签: api, http-client, laravel, saloon, spotify

## 简介

A modern Laravel package for the Spotify Web API, built with Saloon HTTP client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
