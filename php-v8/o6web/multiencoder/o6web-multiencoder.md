# o6web/multiencoder

> 标签: PHP

## 简介

Package for managing multi-step encoding and decoding of strings/objects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://www.o6web.net
- 源码仓库：https://github.com/o6web/MultiEncoder.git
