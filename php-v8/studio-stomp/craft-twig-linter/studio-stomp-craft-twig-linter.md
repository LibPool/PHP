# studio-stomp/craft-twig-linter

> 标签: Craft, cms, craft twig linter, craft-module, craftcms

## 简介

A module for Craft CMS bringing `sserbin/twig-linter` to Craft CMS projects

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
