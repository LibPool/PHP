# oguzhanbayirli/laravel-turkiye

> 标签: IBAN, Turkiye, exchange-rates, laravel, number-to-words, tckn, tcmb, turkey, validation, vkn

## 简介

Turkish identity number (TCKN), tax number (VKN) and IBAN validation, amounts in Turkish words, and TCMB exchange rates for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
