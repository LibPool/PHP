# innova/angular-ui-tinymce-bundle

> 标签: Symfony2, angular, tinymce

## 简介

Symfony 2 bundle which provides Angular JS directive to integrate TinyMCE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
