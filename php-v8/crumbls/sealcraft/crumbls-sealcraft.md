# crumbls/sealcraft

> 标签: aws-kms, azure-key-vault, compliance, encryption, envelope-encryption, gcp-kms, hipaa, kms, laravel, vault

## 简介

Production-grade envelope encryption (DEK/KEK) for Laravel. AWS KMS, GCP Cloud KMS, Azure Key Vault, HashiCorp Vault Transit.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
