# crumbls/astrology

> 标签: PHP

## 简介

Internal Laravel package: natal chart engine (tropical + Vedic) with interactive D3 renderer, built on Swiss Ephemeris.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
