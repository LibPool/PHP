# sjonatas/service-runner

> 标签: PSR-11, cakephp, command-bus, ddd, dependency-injection, domain-driven-design, framework-agnostic, laravel, middleware, payload, php, pipeline, pipeline-pattern, runner, service, use-case

## 简介

A middleware pipeline runner for application services, composing use cases from ordered steps over an immutable payload.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
