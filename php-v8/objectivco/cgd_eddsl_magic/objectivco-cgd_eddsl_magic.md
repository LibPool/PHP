# objectivco/cgd_eddsl_magic

> 标签: PHP

## 简介

A drop-in class that magically manages Easy Digital Downloads Software Licensing for plugins and themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
