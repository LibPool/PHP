# redchamps/module-admin-notification-blocker

> 标签: admin, magento, magento2, notification, php

## 简介

This Magento 2 module will block admin notifications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
