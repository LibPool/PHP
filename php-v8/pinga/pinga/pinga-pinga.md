# pinga/pinga

> 标签: async, microframework, project template, swoole, swow

## 简介

Pinga Framework is a PHP microframework that seamlessly integrates with Swoole, Swow or Workerman, allowing for lightning-fast web applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
