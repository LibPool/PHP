# mindtwo/laravel-auto-create-uuid

> 标签: eloquent, laravel, model, trait, uuid

## 简介

Automatically generate UUIDs for Eloquent models on creation and replication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
