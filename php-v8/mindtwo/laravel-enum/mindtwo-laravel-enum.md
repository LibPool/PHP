# mindtwo/laravel-enum

> 标签: bensampo, enum, laravel, package, validation

## 简介

Simple, extensible and powerful enumeration implementation for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
