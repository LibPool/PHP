# mindtwo/laravel-ai-spark

> 标签: cloudflare-access, dgx-spark, laravel, laravel-ai, llm, nvidia, prism, vllm

## 简介

Laravel AI SDK driver for self-hosted, OpenAI-compatible vLLM servers such as the NVIDIA DGX Spark, with Cloudflare Access support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
