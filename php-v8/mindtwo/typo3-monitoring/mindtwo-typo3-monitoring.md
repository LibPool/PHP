# mindtwo/typo3-monitoring

> 标签: infrastructure, mindtwo, monitoring, security, typo3, typo3-extension

## 简介

TYPO3 extension of the mindtwo monitoring suite: CMS-specific collectors, console/scheduler push and a signed pull endpoint on top of mindtwo/base-monitoring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
