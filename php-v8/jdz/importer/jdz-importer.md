# jdz/importer

> 标签: JDZ, csv, import, spreadsheet, xlsx

## 简介

Spreadsheet import (xlsx / csv / ods) on top of PhpSpreadsheet

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
