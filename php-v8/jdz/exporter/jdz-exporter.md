# jdz/exporter

> 标签: JDZ, csv, export, spreadsheet, xlsx

## 简介

Spreadsheet export (xlsx / csv / ods / pdf) on top of PhpSpreadsheet

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
