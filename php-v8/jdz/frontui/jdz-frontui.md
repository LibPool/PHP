# jdz/frontui

> 标签: JDZ, asset, front, html, image, twig, ui, utilities

## 简介

Framework-agnostic front UI helpers (asset versioning, lazy/zoom image tags) for simple Slim/Twig sites

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
