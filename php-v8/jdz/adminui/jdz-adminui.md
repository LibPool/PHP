# jdz/adminui

> 标签: JDZ, admin, html, twig, ui, utilities

## 简介

Framework-agnostic admin UI rendering (list, columns, triggers, toolbar) and shared admin controller traits

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
