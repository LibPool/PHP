# ugiw/lumen-config-cache

> 标签: Ugiw, laravel, lumen-config-cache, lumen-package

## 简介

Adds the Laravel command `php artisan config:cache` to Lumen

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
