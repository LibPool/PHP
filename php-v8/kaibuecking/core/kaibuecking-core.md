# kaibuecking/core

> 标签: c4g, con4gis, con4gis_core, contao, core, corebundle, jQueryGui

## 简介

Core bundle with functionality needed for every con4gis application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
