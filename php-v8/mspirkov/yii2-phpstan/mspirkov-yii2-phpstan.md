# mspirkov/yii2-phpstan

> 标签: PHPStan, code analyse, code analysis, static analysis, yii, yii2

## 简介

PHPStan rules and type extensions for projects using the Yii2 framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
