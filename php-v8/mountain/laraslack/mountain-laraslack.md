# mountain/laraslack

> 标签: block-kit, laravel, notifications, slack, webhook

## 简介

Send alerts, notifications and Block Kit messages to Slack from Laravel via incoming webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
