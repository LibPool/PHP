# nadeemkhan/atlas-self-scan

> 标签: 3d, atlas, code-map, laravel, self-scan, static-analysis

## 简介

Install AtlasScope into a Laravel application and it maps that application: its own routes, controllers, models and tables, in 3D, at /atlas. No upload, no configuration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
