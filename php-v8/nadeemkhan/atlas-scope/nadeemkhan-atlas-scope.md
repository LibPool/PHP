# nadeemkhan/atlas-scope

> 标签: 3d, atlas, code-map, laravel, static-analysis, three.js, visualisation

## 简介

Scan a Laravel, C++, C# or Python project and explore it as a 3D map of routes, classes, models, namespaces and database tables.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
