# cemtekin/rest-explorer

> 标签: Postman, api, laravel, rest, route-explorer

## 简介

Automatically list Laravel backend APIs, generate Postman collections, and explore routes with a UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
