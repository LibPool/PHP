# yo-uganda/yopaymentsphp8x

> 标签: YoPayments, composer, mobile money, package

## 简介

A PHP 8.x Library to interact with the Yo! Payments API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
