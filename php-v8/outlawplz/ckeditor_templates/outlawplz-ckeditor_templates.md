# outlawplz/ckeditor_templates

> 标签: PHP

## 简介

This plugin provides a dialog to offer predefined content templates - with page layout, text formatting and styles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
