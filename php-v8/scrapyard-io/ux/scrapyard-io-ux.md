# scrapyard-io/ux

> 标签: framework, scene, scrapyard-io, ui, ux

## 简介

The ScrapyardIO Node-based UX library (layered Scene / Node / Drawable / UIComponent).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
