# elite-remote-firm/magento2-customer-attribute

> 标签: PHP

## 简介

Adds a unique, read-only UUID attribute to Magento 2 customers with GraphQL and admin grid support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
