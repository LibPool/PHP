# qopanza/sdk

> 标签: cryptography, encryption, ml-dsa, ml-kem, post-quantum, pqc, qopanza, security

## 简介

PHP client for the Qopanza API (post-quantum cryptography + crypto discovery)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
