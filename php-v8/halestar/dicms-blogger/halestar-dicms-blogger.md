# halestar/dicms-blogger

> 标签: PHP

## 简介

A plugin to the halestar/laravel-drop-in-cms that adds blogging capabilities to the CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
