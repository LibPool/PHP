# tenqz/lingua

> 标签: chain-of-responsibility, nlp, russian-language, text-analysis, text-cleanup, text-manipulation, text-normalization, text-processing

## 简介

A comprehensive PHP library for advanced text processing using Chain of Responsibility pattern

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
