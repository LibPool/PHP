# bladewright/builder

> 标签: blade, cms, laravel, livewire

## 简介

Build and edit a Laravel site from the browser — pages, layouts, components and blocks, seen as you make them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
