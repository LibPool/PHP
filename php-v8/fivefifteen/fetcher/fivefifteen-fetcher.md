# fivefifteen/fetcher

> 标签: JS, build, cli, compile, css, dependencies, dependency, download, end, fetch, fetched, file, front, front-end, frontend, git, http, https, hub, javascript, local, manage, manager, node, npm, package, pkg, sass, scss, style, stylesheet, tool, url

## 简介

A package manager written in PHP that supports installing dependencies from GitHub, npm, custom URLs, and local file paths.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
