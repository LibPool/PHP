# awonderphp/simplecacheredis

> 标签: PHP

## 简介

An implementation of the PSR-16 SimpleCache Interface for Redis with optional AEAD encryption

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
