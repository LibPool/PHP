# metolabs/satcfdi-php

> 标签: 32d, cfdi, csf, efirma, fiel, mexico, sat

## 简介

PHP client for metolabs-satcfdi-bridge, providing a stable interface to SAT-CFDI operations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
