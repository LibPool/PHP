# metolabs/banxico-cep

> 标签: PHP

## 简介

A small framework-agnostic PHP client for querying SPEI payment details and downloading Banco de Mexico CEP receipts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
