# nowo-tech/manual-kit-bundle

> 标签: bundle, commonmark, documentation, frankenphp, help, i18n, manual, markdown, nowo, symfony, symfony-bundle, translations

## 简介

In-app product manual for Symfony from your docs/manual Markdown: one source for GitHub and the app, translations per locale with stable anchors and stale-translation checks, admin-only chapters and blocks that fail closed, figures with a lightbox, search tags and an optional SearchKit provider.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
