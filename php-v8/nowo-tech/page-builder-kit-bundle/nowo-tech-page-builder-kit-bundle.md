# nowo-tech/page-builder-kit-bundle

> 标签: admin, cms, grapesjs, i18n, page-builder, seo, symfony, symfony-bundle, widgets

## 简介

Visual Symfony page builder powered by GrapesJS, with Doctrine persistence, locale-aware content, revisions, SEO, and Twig public rendering. Classic section/column/widget documents remain supported.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
