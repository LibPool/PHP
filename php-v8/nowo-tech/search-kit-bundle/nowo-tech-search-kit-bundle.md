# nowo-tech/search-kit-bundle

> 标签: autocomplete, bundle, command-palette, frankenphp, global-search, nowo, search, symfony, symfony-bundle, typeahead, ux-icons

## 简介

Global header search (command palette) for Symfony: a magnifier that stretches into a field, grouped permission-aware results from your own providers, Ctrl/⌘K, keyboard navigation, recents, UX Icons and theme tokens.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
