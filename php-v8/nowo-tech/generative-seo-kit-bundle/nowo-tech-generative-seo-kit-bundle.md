# nowo-tech/generative-seo-kit-bundle

> 标签: ai-crawlers, bundle, frankenphp, generative-engine-optimization, llms.txt, robots, seo, symfony

## 简介

Symfony Generative Engine Optimization kit (not geolocation): AI crawler robots policy via SeoKit, llms.txt, citation index and audit for FrankenPHP, php-fpm and Nginx.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
