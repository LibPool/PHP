# nowo-tech/php-quality-tools

> 标签: ci, code-style, composer-plugin, laravel, php-cs-fixer, phpunit, quality, rector, symfony, twig-cs-fixer

## 简介

Pre-configured quality tools for PHP projects (Rector, PHP-CS-Fixer, Twig-CS-Fixer) with automatic framework detection, plus CI gate scripts (Clover coverage threshold, module boundaries, latest-release-tag deploy guard), a PHPUnit SQL query-budget trait, ParaTest per-process isolation helpers, profiler-based route query scaling and missing-translation test traits, front-end / docs gates (no inline SVG, Vite asset budgets, Markdown links) AI agent co-author trailer checks / hooks, and quiet-run / junit-failures / changed-tests helpers (short gate summaries, failed tests of a JUnit log, tests covering the changes).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
