# nowo-tech/doctrine-encrypt-bundle

> 标签: Defuse, doctrine, encryption, frankenphp, gdpr, halite, key-rotation, php, symfony, symfony-bundle

## 简介

Symfony bundle (Symfony 7.4 and 8.x) that encrypts Doctrine entity fields at rest with Halite, Defuse or MySQL-compatible MysqlAes, with multiple keys and key rotation for GDPR-friendly storage.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
