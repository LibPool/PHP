# nowo-tech/controller-kit-bundle

> 标签: bundle, controller, doctrine, forward, frankenphp, multi-tenant, php, redirect, referer, symfony, symfony-bundle, traits, utilities, value-resolver

## 简介

Controller utilities for Symfony: redirectToReferer (configurable default route), SafeForwardTrait for safe request forwarding, RequiresValidFormTrait form guards and the #[MapScopedEntity] owner-scoped Doctrine entity argument resolver.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
