# nowo-tech/http-hardening-bundle

> 标签: cache, cdn, content-security-policy, csp, hardening, hsts, security-headers, session, symfony, symfony-bundle

## 简介

Symfony bundle for public HTTP hardening: security headers (nosniff, HSTS, Permissions-Policy, CORP), nonce-based Content-Security-Policy, public Cache-Control, www-to-apex redirect, safe internal redirects and optional anonymous session-cookie strip for CDN-friendly public GET pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
