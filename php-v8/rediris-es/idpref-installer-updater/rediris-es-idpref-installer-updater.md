# rediris-es/idpref-installer-updater

> 标签: RedIRIS, SIR, composer, idp, simplesamlphp

## 简介

Instalación de SimpleSAMLphp junto con los paquetes de REDIRIS para la instalación del IDP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
