# rediris-es/simplesamlphp-module-idp_installer

> 标签: RedIRIS, SIR, idp, installer, simplesamlphp

## 简介

A SimpleSAMLphp module for pre-installing an IdP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
