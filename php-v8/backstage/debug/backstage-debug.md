# backstage/debug

> 标签: backstagephp, debug, filament, laravel, logs

## 简介

Read back what your Laravel application did: exceptions, log lines, outgoing API calls and incoming webhooks, in a Filament UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
