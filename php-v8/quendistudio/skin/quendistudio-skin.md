# quendistudio/skin

> 标签: admin, backend, quendistudio, skin, ui, wintercms

## 简介

Enhanced Winter CMS backend skin with dropdown menus, breadcrumbs, and form navigation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
