# macerd/laravel-request-docs

> 标签: laravel, laravel-request-docs, rakutentech

## 简介

Automatically generate Laravel docs from request rules, controllers and routes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
