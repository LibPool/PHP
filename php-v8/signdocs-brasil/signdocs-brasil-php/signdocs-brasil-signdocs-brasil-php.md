# signdocs-brasil/signdocs-brasil-php

> 标签: assinador, assinatura, assinatura-de-documentos, assinatura-digital, assinatura-eletronica, biometria, brasil, brazil, certificado-digital, digital-signature, document-signing, e-signature, eSignature, electronic-signature, icp-brasil, pkcs7, signdocs, signdocs-brasil

## 简介

SDK oficial em PHP para a API SignDocs Brasil: assinatura eletrônica e digital com ICP-Brasil, biometria, OTP e trilha de evidências (Brazilian e-signature API SDK)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
