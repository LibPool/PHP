# fbf/laravel-places

> 标签: laravel, places

## 简介

A Laravel 4 package to add place listings to a site, e.g. bars, restaurants or hotels

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
