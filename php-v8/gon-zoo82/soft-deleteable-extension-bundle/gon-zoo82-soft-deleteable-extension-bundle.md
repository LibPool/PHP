# gon-zoo82/soft-deleteable-extension-bundle

> 标签: soft-deleteable

## 简介

Provides exta functions to the soft deleteable listener of gedmo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
