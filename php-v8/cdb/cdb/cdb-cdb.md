# cdb/cdb

> 标签: PHP

## 简介

Constant Database (CDB) wrapper library for PHP. Provides pure-PHP fallback when dba_* functions are absent.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
