# trentino-alto/adige

> 标签: activerecord, console, framework, migration, mvc, orm, php, validation, web

## 简介

A small PHP framework with HTTP, console, ORM, migrations, views and validation support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
