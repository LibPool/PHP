# antonmarin/traceable-pdo

> 标签: pdo, sql, trace

## 简介

Wrapper for PDO that adds trace of statement source to analyze slow SQL statements in real-time

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
