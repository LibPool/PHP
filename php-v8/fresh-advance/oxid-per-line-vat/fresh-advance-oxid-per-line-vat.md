# fresh-advance/oxid-per-line-vat

> 标签: OXID, eshop, modules

## 简介

Changing how OXID default VAT calculation works - VAT is calculated per line item, not on the total sum.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
