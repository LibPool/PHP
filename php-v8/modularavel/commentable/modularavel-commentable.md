# modularavel/commentable

> 标签: blade, commentable, commenting, comments, crsistemas, laravel, livewire, livewire-components, modularavel, replies, threaded-comments, threads

## 简介

A Laravel Blade Livewire package for threaded comments with replies

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
