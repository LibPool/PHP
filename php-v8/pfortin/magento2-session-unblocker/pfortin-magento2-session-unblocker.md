# pfortin/magento2-session-unblocker

> 标签: PHP

## 简介

Module for Magento 2 that prevents session blocking between concurrent AJAX requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
