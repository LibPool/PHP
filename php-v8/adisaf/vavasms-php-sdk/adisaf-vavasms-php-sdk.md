# adisaf/vavasms-php-sdk

> 标签: api, gateway, http, sms, vavasms

## 简介

Client library to send SMS using Vavasms SMS Gateway API (https://vavasms.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
