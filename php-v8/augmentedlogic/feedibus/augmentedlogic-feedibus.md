# augmentedlogic/feedibus

> 标签: feed, mediarss, php, rss, writer

## 简介

RSS writer library with support for most of the RSS specification, including Media RSS and GeoRSS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
