# rekurzia/yii2-sentry-log-target

> 标签: log, sentry, target, yii2

## 简介

Minimal implementation of Yii2 log target sending messages to Sentry.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
