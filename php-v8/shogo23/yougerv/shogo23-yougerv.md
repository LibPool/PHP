# shogo23/yougerv

> 标签: PHP

## 简介

Is a video streaming website created by [Gervic](https://www.facebook.com/gervic23) as part of portfolio written on CodeIgniter 4 Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
