# crushjs/aba-payway

> 标签: aba, cambodia, khqr, laravel, payment, payway

## 简介

Pay as You Wish in Cambodia - ABA PayWay payment gateway client for PHP and Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
