# crushjs/mini-pdf

> 标签: khmer, laravel, mpdf, pdf, unicode

## 简介

A lightweight PDF generator for Laravel with built-in Khmer (Unicode) support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
