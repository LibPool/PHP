# bluefrg/parsecsv

> 标签: PHP

## 简介

Extend PHP's native CSV parsing from the SplFileObject class but provide features to use the first row's values as keys on the remaining rows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
