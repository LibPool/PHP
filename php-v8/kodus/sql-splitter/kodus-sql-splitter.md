# kodus/sql-splitter

> 标签: PHP

## 简介

A simple facility to split SQL files into individual queries - supports MySQL, PostgreSQL and Microsoft SQL Server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
