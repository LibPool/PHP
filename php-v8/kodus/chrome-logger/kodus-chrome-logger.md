# kodus/chrome-logger

> 标签: PHP

## 简介

PSR-3 (logging), PSR-7 (HTTP) and PSR-15 (middleware) compliant alternative to the original ChromeLogger for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
