# techdivision/import-product-magic360

> 标签: PHP

## 简介

Pacemaker library providing basic import functionality for the Magic ToolBox Magic 360 image gallery view

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
