# alves/nfse-php-brazil

> 标签: mei, nfse, nfse-php-brazil

## 简介

Pacote para emissao de NFS-e para municipios brasileiros usando componentes NFePHP (https://github.com/nfephp-org)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
