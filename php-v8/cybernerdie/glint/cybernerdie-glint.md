# cybernerdie/glint

> 标签: ai, anthropic, laravel, llm, observability, openai, tracing

## 简介

Laravel-native LLM observability with local traces, generations, cost tracking, latency, errors, and alerts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
