# achedon12/golem

> 标签: bedrock, fake-player, integration-testing, minecraft, pmmp, pocketmine, pocketmine-mp, test-framework, testing

## 简介

Integration tests for PocketMine-MP plugins: a real server, simulated players, one command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
