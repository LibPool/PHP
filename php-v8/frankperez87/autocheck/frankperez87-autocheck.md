# frankperez87/autocheck

> 标签: PHP

## 简介

This API allows you to connect to the AutoCheck system in order to request the vehicle history report for a given VIN.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
