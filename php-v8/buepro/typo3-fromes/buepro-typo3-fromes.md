# buepro/typo3-fromes

> 标签: Messenger, TYPO3 CMS, email

## 简介

Frontend messenger provides a plugin to send emails to frontend users. Recipients can be compiled by help of a flexible filter.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
