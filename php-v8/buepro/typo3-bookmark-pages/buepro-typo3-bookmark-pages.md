# buepro/typo3-bookmark-pages

> 标签: bookmarks, extension, typo3

## 简介

A TYPO3 extension that provides bookmarks functionality of local pages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
