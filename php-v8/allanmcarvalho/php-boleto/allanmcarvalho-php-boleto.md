# allanmcarvalho/php-boleto

> 标签: allanmcarvalho, cakephp, php

## 简介

Ferramenta para gerar boletos, emitir remessas e ler retornos

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
