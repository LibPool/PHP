# allanmcarvalho/base-two-acl

> 标签: PHP

## 简介

Plugin for manage Access Control Level (ACL) for CakePHP 3 using the base 2 math power

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
