# dapphp/radius

> 标签: Authentication, authorization, chap, ms-chap, ms-chap v2, pap, radius, rfc1994, rfc2284, rfc2759, rfc2865, rfc2869

## 简介

A pure PHP RADIUS client based on the SysCo/al implementation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
