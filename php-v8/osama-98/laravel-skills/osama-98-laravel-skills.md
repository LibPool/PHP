## 简介

AI agent skills and guidelines for Laravel — auto-discovered by Laravel Boost and synced to Claude Code, Cursor, GitHub Copilot, Codex and Junie. Includes Backpack for Laravel v6 and HyperPay (OPPWA).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
