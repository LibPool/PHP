# taknone/liveproto

> 标签: api, async, client, live, liveproto, mtproto, php, proto, telegram, telegram-client

## 简介

An async , pure PHP MTProto Telegram client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
