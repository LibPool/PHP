# taknone/phptgcalls

> 标签: WebRTC, asynchronously, group-call, non-blocking, phone-call, php, phptgcalls, rust, stream, telegram, tgcalls, voip

## 简介

A high-performance , non-blocking PHP library for Telegram Group Calls and WebRTC streaming via Rust

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
