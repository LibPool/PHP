# jp3cki/yii-cli-color

> 标签: PHP

## 简介

Adding colors to console output (for Yii Framework 1) [forked from https://github.com/kevinkorb/yii-cli-color]

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
