# epiphyt/coding-standard

> 标签: PHP

## 简介

Epiphyt Coding Standard for PHP_CodeSniffer extends the WordPress Coding Standard by providing sniffs with additional checks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
