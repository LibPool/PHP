# ravisystems/ravimail-php

> 标签: email, marketing, ravimail, smtp, transactional

## 简介

Official PHP SDK for the RaviMail REST API v1 (api.ravimail.com.br).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
