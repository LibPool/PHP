# dainsys/mailing

> 标签: PHP

## 简介

Mailing and recipients management package for Dainsys. This package allows you to Associate recipients to your mailable files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
