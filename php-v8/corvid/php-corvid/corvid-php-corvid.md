# corvid/php-corvid

> 标签: database, embedded, full-text-search, geo, graph, hybrid-search, vector-search

## 简介

PHP bindings for corvid — a native PHP extension over the embedded database's typed C ABI

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
