# radebatz/openapi-introspector

> 标签: Swagger-PHP, documentation, introspection, laravel, openapi, routes, slim, swagger

## 简介

Documents the routes your Laravel or Slim application already has: reads them from the framework and contributes them to the OpenAPI document swagger-php builds, so nothing is declared twice. The reverse of openapi-router.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
