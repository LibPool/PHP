# pano-php/framework

> 标签: framework, lightweight, minimal, nano-framework, pano-framework, php

## 简介

A lightweight PHP Nano Framework - Minimal execution foundation with full developer control

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
