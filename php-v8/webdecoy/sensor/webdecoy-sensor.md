# webdecoy/sensor

> 标签: ai-crawlers, bot-detection, security, sensor

## 简介

Report bot and AI-crawler detections to WebDecoy from any PHP application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://webdecoy.com
- 源码仓库：https://github.com/WebDecoy/php-sensor.git
- Packagist 页面：https://packagist.org/packages/webdecoy%2Fsensor

- Composer 安装：`composer require webdecoy/sensor`
