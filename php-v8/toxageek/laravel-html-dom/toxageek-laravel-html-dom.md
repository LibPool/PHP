# toxageek/laravel-html-dom

> 标签: PHP

## 简介

A fast, simple and reliable HTML document parser for Laravel. Created based on PHP Simple HTML DOM Parser

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
