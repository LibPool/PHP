# j13k/yaml-lint

> 标签: cli, lint, symfony, syntax, utility, yaml, yml

## 简介

A compact command line utility for checking YAML file syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
