# fqathf/loglytics

> 标签: Viewer, crashlytics, laravel, log, loglytics

## 简介

A lightweight and powerful Crashlytics-like log viewer package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
