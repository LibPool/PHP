# xiidea/ezrbac

> 标签: Role Based Access Control, codeigniter

## 简介

A simple yet easy to implement Role Based Access Control Library for Codeigniter

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
