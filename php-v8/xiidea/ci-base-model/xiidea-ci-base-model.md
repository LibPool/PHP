# xiidea/ci-base-model

> 标签: CI_Base_Model, codeigniter, crud, model

## 简介

An extension of CodeIgniter's base Model class for providing a couple handy methods

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
