# mihanentalpo/fast-fuzzy-search

> 标签: compare, fuzzy, search

## 简介

Fast fuzzy search in an array of strings for the most similiar ones

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
