# rayanetenorios/pix-payload

> 标签: Pagamento, brcode, payload, pix, qrcode

## 简介

Gerador de payload Pix BR Code (EMV) para criação de QR Code de pagamento.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
