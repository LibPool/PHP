# purplespider/silverstripe-elemental-draft-lock

> 标签: blocks, draft, elemental, lock, publish, silverstripe

## 简介

Lets editors lock an individual Elemental block as draft, so publishing the page does not publish it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
