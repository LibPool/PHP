# purplespider/silverstripe-visual-block-picker

> 标签: blocks, cms, editor, elemental, silverstripe

## 简介

Replaces the Elemental "Add block" popover with a visual picker showing screenshots, descriptions and groups

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
