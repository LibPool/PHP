# dgreda/cache-factory

> 标签: cache, factory, memcached, psr-6, redis

## 简介

Simple factory for php-cache/cache library (PSR-6 Cache implementation)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
