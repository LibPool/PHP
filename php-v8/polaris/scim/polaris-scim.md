# polaris/scim

> 标签: PHP

## 简介

SCIM for Polaris for PHP: a SCIM 2.0 server per organization with provisioning tokens, users and groups projected onto members and roles, organization self-service and operator routes

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
