# polaris/passwordless

> 标签: PHP

## 简介

Passwordless sign-in for Polaris for PHP: magic links, email one-time codes (sign-in, email verification, password reset), phone codes for a verified second contact, one-time tokens for session transfer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
