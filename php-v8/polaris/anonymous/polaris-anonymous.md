# polaris/anonymous

> 标签: PHP

## 简介

Anonymous sign-in for Polaris for PHP: guest sessions, an explicit conversion into a real account through a host hook, pruning of the guests nobody converted

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
