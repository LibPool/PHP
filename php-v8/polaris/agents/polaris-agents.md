# polaris/agents

> 标签: agent-auth, agent-authentication, agentic, ai-agents, approvals, capabilities, delegation, mcp, oauth2, php, polaris, receipts, token-exchange

## 简介

AI agents as principals for Polaris for PHP: registration and host enrolment, delegated and autonomous agents over OAuth (token exchange with act, client credentials, private_key_jwt), signed request JWTs, capability grants with constraints and budgets, approvals, signed receipt chains and a kill switch

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
