# polaris/social

> 标签: PHP

## 简介

Social sign-in for Polaris for PHP: OAuth 2.0 and OpenID Connect providers (Google, Apple, Microsoft, GitHub and sixteen more, or any OAuth 2 server), account linking, Google One Tap, provider tokens on the user's behalf, an OAuth proxy for preview origins

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
