# polaris/mcp

> 标签: ai-agents, dpop, llm-tools, mcp, mcp-auth, mcp-server, model-context-protocol, oauth2, php, polaris, protected-resource, rfc9728

## 简介

Polaris for PHP and the Model Context Protocol: protect any PHP MCP server with Polaris-issued tokens (RFC 9728, DPoP), and serve every Polaris endpoint and CLI command as an MCP tool under the caller's own permissions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
