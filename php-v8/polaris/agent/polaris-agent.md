# polaris/agent

> 标签: agent-auth, agent-sdk, agentic, ai-agents, oauth2, php, polaris, private-key-jwt, receipts, token-exchange

## 简介

The PHP agent SDK for Polaris for PHP: discover a Polaris server, register or enrol an agent, request grants and poll approvals, sign request JWTs, call capabilities and verify receipts

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
