# polaris/passkey

> 标签: PHP

## 简介

Passkeys for Polaris for PHP: WebAuthn registration and discoverable sign-in with conditional UI, a passkey as a core MFA factor, naming and removal

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
