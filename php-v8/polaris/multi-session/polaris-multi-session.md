# polaris/multi-session

> 标签: PHP

## 简介

Multi-session for Polaris for PHP: several signed-in accounts on one device, switching between them without signing in again, revoking one, and the last sign-in method for the client to pre-select

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
