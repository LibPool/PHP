# polaris/oauth-provider

> 标签: authorization-server, ciba, device-flow, dpop, oauth2, oauth2-provider, oauth2-server, oidc, openid-connect, php, pkce, polaris, token-exchange

## 简介

Polaris for PHP as an OAuth 2.1 and OpenID Connect provider: authorization code with PKCE, refresh rotation, client credentials, device flow, CIBA, token exchange, DPoP, dynamic registration and client ID metadata documents, discovery

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
