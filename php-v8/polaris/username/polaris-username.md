# polaris/username

> 标签: PHP

## 简介

Username for Polaris for PHP: sign in with a username or an email through core's password path, case-insensitive unique usernames with a display form, validation rules from configuration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
