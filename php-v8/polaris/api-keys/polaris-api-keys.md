# polaris/api-keys

> 标签: Authentication, Bearer, api-key, api-keys, php, polaris, rate-limit, rbac

## 简介

API keys for Polaris for PHP: keys owned by users and organizations with a permission subset, rate limit, expiry and rotation, accepted as a principal on every Polaris route

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
