# polaris/sentinel

> 标签: PHP

## 简介

Sentinel for Polaris for PHP: a local risk engine on sign-up, sign-in, password reset and code sends (velocity, credential stuffing, bots, disposable domains, impossible travel, IP rules, devices, breached passwords) that observes, challenges or blocks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
