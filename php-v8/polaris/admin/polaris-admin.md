# polaris/admin

> 标签: PHP

## 简介

Admin for Polaris for PHP: the operator API over users, sessions, MFA, organizations, audit drains and stats, for admin users and API keys, every action audited

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
