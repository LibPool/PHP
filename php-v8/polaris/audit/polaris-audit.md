# polaris/audit

> 标签: PHP

## 简介

Audit for Polaris for PHP: a catalogued, redacted, append-only audit store with sinks, per-organization drains, a query API, retention and an optional hash chain

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
