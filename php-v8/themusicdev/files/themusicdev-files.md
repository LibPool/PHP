# themusicdev/files

> 标签: Flysystem, cakephp, file-management, files, plugin, storage, uploads

## 简介

CakePHP 5 plugin: reusable uploads and file management with Flysystem v3 storage, a stored_files ledger, collections (virtual folders) and gated serving

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
