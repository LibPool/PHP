# themusicdev/seo

> 标签: JSON-LD, Sitemap, cakephp, canonical-url, plugin, redirects, robots.txt, seo, structured-data

## 简介

CakePHP 5 plugin: page meta, structured data (JSON-LD), sitemap, robots.txt, and 301/410 redirects from one page index

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
