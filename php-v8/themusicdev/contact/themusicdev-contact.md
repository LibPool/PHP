# themusicdev/contact

> 标签: Honeypot, cakephp, contact-form, inquiries, plugin, spam-protection

## 简介

CakePHP 5 plugin: contact-form intake with an inquiries table and honeypot / submit-timing spam handling

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
