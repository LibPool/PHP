# themusicdev/trailing-slash

> 标签: cakephp, canonical-url, middleware, plugin, redirect, seo, trailing-slash

## 简介

CakePHP 5 plugin: one middleware that 301-redirects trailing-slash URLs to the slash-free canonical form

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
