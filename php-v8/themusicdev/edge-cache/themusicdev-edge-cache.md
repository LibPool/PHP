# themusicdev/edge-cache

> 标签: Etag, cache, cache-control, cakephp, cdn, cloudflare, csrf, plugin

## 简介

CakePHP 5 plugin: cache headers for CDN-fronted sites (public pages cached at the edge, forms and everything else never), cookie guard, ETag, Cloudflare purge

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
