# jeanvaljean/cakephp-timezone

> 标签: cakephp, datetime, timezone

## 简介

Timezone and Datetime plugin for CakePHP 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
