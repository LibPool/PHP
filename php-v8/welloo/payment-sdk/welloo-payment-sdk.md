# welloo/payment-sdk

> 标签: checkout, merchant, mobile-money, payment, sdk, transfer, welloo, withdrawal

## 简介

SDK PHP pour créer un paiement via redirection (checkout hébergé), initier un transfert, lister les transactions et consulter le solde avec le prestataire Welloo. Utilisable en PHP natif, Laravel, Symfony... ; ne jamais exposer côté navigateur.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
