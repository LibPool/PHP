# webpacks/notigen

> 标签: email, laravel, notifications, slack, sms, template, webpacks

## 简介

A Laravel package that simplifies the process of creating, managing, and sending custom notifications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
