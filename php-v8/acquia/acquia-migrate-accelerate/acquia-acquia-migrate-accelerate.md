# acquia/acquia-migrate-accelerate

> 标签: PHP

## 简介

An enhanced UI and assistant for Drupal migrations. See https://www.acquia.com/drupal9/accelerate-your-migration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
