# acquia/drupal-recommended-settings

> 标签: acquia, drupal, drupal-recommended-settings

## 简介

The composer plugin for adding drupal-recommended-settings for Acquia Cloud.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
