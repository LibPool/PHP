# yurunsoft/pay-sdk

> 标签: PHP

## 简介

PHP 集成支付 SDK ，集成了支付宝、微信支付的支付接口和其它相关接口的操作。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
