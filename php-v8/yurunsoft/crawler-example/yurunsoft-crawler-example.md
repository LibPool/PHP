# yurunsoft/crawler-example

> 标签: PHP

## 简介

宇润爬虫框架(Yurun Crawler) 是一个低代码、高性能、分布式爬虫采集框架，这可能是最一把梭的爬虫框架。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
