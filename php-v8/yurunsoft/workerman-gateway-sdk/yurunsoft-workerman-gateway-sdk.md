# yurunsoft/workerman-gateway-sdk

> 标签: PHP

## 简介

一个支持在 Swoole 或其它非 Workerman 环境，开发 Gateway Worker 的组件。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
