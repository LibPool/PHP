# yurunsoft/imi

> 标签: PHP

## 简介

imi 是一款支持长连接微服务分布式的 PHP 开发框架，可在 PHP-FPM、Swoole、Workerman 和 RoadRunner 等多种容器环境下运行。它支持 HttpApi、WebSocket、TCP、UDP、MQTT 服务的开发。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
