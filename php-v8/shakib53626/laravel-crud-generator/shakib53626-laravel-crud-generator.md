# shakib53626/laravel-crud-generator

> 标签: PHP

## 简介

A Laravel package to generate CRUD scaffold (Migration, Model, Controller, Requests, Resource) with one command.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
