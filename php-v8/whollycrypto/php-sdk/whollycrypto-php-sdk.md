# whollycrypto/php-sdk

> 标签: Lightning, bitcoin, crypto, merchant, payments, sdk, whollycrypto

## 简介

Lightweight PHP client for the Wholly Crypto self-hosted merchant API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
