# mtolhuys/laravel-env-scanner

> 标签: laravel-env-scanner, mtolhuys

## 简介

Checks environmental variables used in the env() and getenv() helper functions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
