# ruleboy21/easy-builder

> 标签: database, mysql, postgresql, query builder, sql, sqlite

## 简介

A lightweight, dependency free, framework agnostic query builder for PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
