> 标签: folklore, gd, gmagick, image, imagick, imagine, laravel, thumbnail, watermark

## 简介

Image manipulation library for Laravel 8 forked from folklore/image

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
