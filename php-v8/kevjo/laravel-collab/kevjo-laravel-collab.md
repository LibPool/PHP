# kevjo/laravel-collab

> 标签: collaboration, concurrent-editing, laravel, laravel12, locking, optimistic-locking, pessimistic-locking, php85, real-time

## 简介

Real-time collaborative editing for Laravel with intelligent locking and conflict resolution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
