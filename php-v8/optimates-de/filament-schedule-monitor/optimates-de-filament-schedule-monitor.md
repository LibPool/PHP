# optimates-de/filament-schedule-monitor

> 标签: PHP

## 简介

Read-only Filament UI for spatie/laravel-schedule-monitor: scheduled task status, run history and descriptions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
