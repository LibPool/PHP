# polishsymfonycommunity/symfony-mocker-container

> 标签: BDD, Behat, TDD, mock, mockery, test

## 简介

Provides base Symfony dependency injection container enabling service mocking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
