# omniboost/aws-iam-proof-auth

> 标签: Authentication, aws, iam, laravel, middleware, sts

## 简介

Service-to-service authentication with the caller's AWS IAM identity: sign outgoing requests and verify incoming ones with AWS-IAM-PROOF headers. Includes Laravel middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
