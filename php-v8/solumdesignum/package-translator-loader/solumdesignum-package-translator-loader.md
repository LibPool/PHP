# solumdesignum/package-translator-loader

> 标签: PackageTranslatorLoader, laravel, laravel-package-translator-toade, loader, package, package-translator-toader, translator

## 简介

Laravel Package Translator Loader is translations loader for your package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
