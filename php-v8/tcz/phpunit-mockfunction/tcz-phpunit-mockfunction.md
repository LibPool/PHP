# tcz/phpunit-mockfunction

> 标签: mock, phpunit, runkit, testing, unit

## 简介

PHPUnit extension that uses runkit to mock PHP functions (both user-defined and system)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
