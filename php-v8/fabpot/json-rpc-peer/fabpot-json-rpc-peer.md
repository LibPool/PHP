# fabpot/json-rpc-peer

> 标签: LSP, amphp, async, json-rpc, jsonrpc, mcp, stdio

## 简介

An asynchronous, bidirectional JSON-RPC 2.0 peer over message-oriented transports, built on amphp

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
