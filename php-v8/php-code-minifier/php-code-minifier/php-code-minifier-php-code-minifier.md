# php-code-minifier/php-code-minifier

> 标签: code, minification, minifier, minify, php, php-code-minifier

## 简介

PHP Code Minifier is a tool that allows you to minify your PHP code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
