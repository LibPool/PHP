# frank-lar/sse

> 标签: EventStream, Server-Sent Events, php-sse, sse

## 简介

An easy-to-use, object-oriented PHP library for Server-Sent Events

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
