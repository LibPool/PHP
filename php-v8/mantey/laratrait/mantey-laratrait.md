# mantey/laratrait

> 标签: artisan, command, laratrait, laravel, laravel traits, trait

## 简介

An easy way to create a trait with php artisan command

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
