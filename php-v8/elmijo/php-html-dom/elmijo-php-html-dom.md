# elmijo/php-html-dom

> 标签: PHP

## 简介

Esta Es una Herramienta que permite convertir y manipular una cadena de texto con formato html en un objeto php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
