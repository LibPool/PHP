# pedhot-dev/nepotismfree-di-autowire

> 标签: PHP

## 简介

An optional Autowire / Resolver layer for NepotismFree-DI. Strict DI stays strict; this resolver sits on top.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
