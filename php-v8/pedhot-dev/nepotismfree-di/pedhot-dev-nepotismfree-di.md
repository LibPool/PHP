# pedhot-dev/nepotismfree-di

> 标签: PHP

## 简介

A high-performance, opinionated, strict Dependency Injection Container for PHP 8.1+. No magic, no hidden wiring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
