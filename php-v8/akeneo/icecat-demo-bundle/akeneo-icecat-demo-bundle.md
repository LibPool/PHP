# akeneo/icecat-demo-bundle

> 标签: data, demo, generator

## 简介

Akeneo PIM Icecat Demo Bundle (For more information about Icecat, please see http://icecat.biz)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
