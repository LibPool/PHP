# nickdekruijk/minify

> 标签: JS, css, javascript, laravel5, minify, sass, scss

## 简介

A package for automaticaly minifying CSS, SCSS and Javascript for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
