# nickdekruijk/laravel-visitors

> 标签: analytics, laravel, pageviews, tracking, visitors

## 简介

A simple, privacy friendly visitor tracking for Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
