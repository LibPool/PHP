# usman/linkedinapi

> 标签: api, client, linkedin, oauth, sdk

## 简介

LinkedIn API. Handles OAuth, CSRF protection. Easy to implement and extend. This is a standalone library for any composer project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
