# usman/make-services

> 标签: actions, artisan, command, developer-tools, dto, generator, interface, laravel, repository, services, traits

## 简介

Comprehensive Laravel package for generating services, repositories, interfaces, actions, DTOs and more with artisan commands

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
