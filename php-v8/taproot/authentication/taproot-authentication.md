# taproot/authentication

> 标签: PHP

## 简介

Makes adding indieauth login (client app) and token generation (server app) to your Silex/Symfony app as easy as it should be.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
