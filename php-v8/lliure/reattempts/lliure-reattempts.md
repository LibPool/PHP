# lliure/reattempts

> 标签: PHP

## 简介

Esse pacote tem como objetivo gerar querys/consultas automaticamente para o teste de retentavivas ao decorrer de um periodo estipulado.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
