# vortech/softdeletes-flag

> 标签: boolean, database, eloquent, flag, index, laravel, mysql, performance, soft-delete, soft-deletes, softdeletes-flag, unique-index, vortech

## 简介

Drop-in soft deletes for Laravel Eloquent that use an indexed boolean flag instead of a nullable timestamp, for faster queries in high-load applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
