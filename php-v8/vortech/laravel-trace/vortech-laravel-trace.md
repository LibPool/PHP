# vortech/laravel-trace

> 标签: change-feed, eloquent, incremental, laravel, sync

## 简介

One-way, change-based synchronization of published Eloquent data between two Laravel applications: a source change feed and a remote pull engine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
