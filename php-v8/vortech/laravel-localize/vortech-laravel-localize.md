# vortech/laravel-localize

> 标签: eloquent, i18n, laravel, localization, multilingual, translations

## 简介

Typed, per-model translation tables for Eloquent: a locale view with exact fallback rules, transactional bulk saves and a unique validation rule.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
