# vortech/laravel-stash

> 标签: key-value, laravel, stash, storage, vortech

## 简介

Store and retrieve loose, non-sensitive values in a file, a database or any custom driver.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
