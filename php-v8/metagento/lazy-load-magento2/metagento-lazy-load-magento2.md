# metagento/lazy-load-magento2

> 标签: magento 2 free extension, magento 2 lazy load, magento 2 lazy load images, magento lazy load, magento lazy load extension, magento lazy load product, magento lazy loading, magento optimization

## 简介

This Magento 2 extension improve the load speed of your website by loading images with Lazy Load

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
