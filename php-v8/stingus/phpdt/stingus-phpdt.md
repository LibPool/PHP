# stingus/phpdt

> 标签: Double, array, boolean, integer, object, strict, string, type

## 简介

PHP data type validation: primitives (int, double, bool, array, string) and objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
