# sukarix/statera

> 标签: fat-free, framework, php, sukarix, testing-tools

## 简介

Statera - Statera is a unit testing kit designed specifically for the Sukarix Framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
