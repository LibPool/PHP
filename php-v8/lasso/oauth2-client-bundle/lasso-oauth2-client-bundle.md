# lasso/oauth2-client-bundle

> 标签: Symfony2, api, client, oauth

## 简介

Access APIs protected by the oauth2 authentication scheme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
