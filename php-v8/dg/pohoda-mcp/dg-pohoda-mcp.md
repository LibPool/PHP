# dg/pohoda-mcp

> 标签: Accounting, XML-API, ai, invoices, mcp, mserver, pohoda, stormware

## 简介

MCP server pro účetní software Pohoda. Umožňuje AI asistentům číst a vytvářet faktury, objednávky, zásoby, kontakty a další agendy přes mServer XML API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
