# dg/google-services

> 标签: api, calendar, gmail, google, mcp, meet, slides

## 简介

Ergonomic PHP wrapper for Google APIs (Gmail, Calendar, Meet, Slides) plus a single-user MCP server exposing them as tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
