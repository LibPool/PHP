# shoplygg/shoply-php

> 标签: api, digital-goods, ecommerce, sdk, shoply, webhooks

## 简介

Shoply's API from your own server: every route as a method, safe retries, pages, checking webhooks, and OAuth for apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
