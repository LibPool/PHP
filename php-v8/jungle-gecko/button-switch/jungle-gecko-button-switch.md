# jungle-gecko/button-switch

> 标签: JS, ajax, form, javascript

## 简介

Beautiful styling of inputs (radio buttons, checkboxes) wrapped with Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
