# rootsoft/algorand-php

> 标签: algorand, algorand-php, blockchain, rootsoft

## 简介

Community SDK to interact with the Algorand network, in PHP & Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
