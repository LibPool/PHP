# sandi/tokopedia-php-sdk

> 标签: Tokopedia, tokopedia-api, tokopedia-api-sdk, tokopedia-sdk, tokopedia-sdk-api

## 简介

PHP SDK for Tokopedia API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
