# revstrat/silverstripe-agegate

> 标签: age, agegate, gate, silverstripe

## 简介

Adds age-gate for verifying visitor's eligibility to view restricted content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
