# dwgebler/encryption

> 标签: PHP

## 简介

Encryption wrapper for PHP using libsodium — simple API for symmetric and asymmetric encryption, password hashing, digital signing, and message authentication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
