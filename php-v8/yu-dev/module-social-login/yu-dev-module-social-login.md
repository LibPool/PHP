# yu-dev/module-social-login

> 标签: Authentication, SSO, ecommerce, facebook-login, hybridauth, magento, magento2, oauth, oauth2, sign-in-with-apple, sign-in-with-google, social-login

## 简介

Social login for Magento 2 — sign in with Google, Facebook, Apple, X (Twitter), GitHub, LinkedIn, Microsoft, Amazon, Yahoo. Powered by HybridAuth.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
