# tomk79/px2-publish-for-multi-device

> 标签: pickles2

## 简介

複数のデバイス向けのバージョンをパブリッシュできる、 Pickles 2 用のパブリッシュプラグイン。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
