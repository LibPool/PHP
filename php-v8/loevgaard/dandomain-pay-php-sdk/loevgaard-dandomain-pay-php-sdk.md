# loevgaard/dandomain-pay-php-sdk

> 标签: dandomain, payments, php

## 简介

A library for using the Dandomain Pay API to make payments in the Dandomain webshop system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
