# canebaycomputers/valorpay

> 标签: laravel, payments, recurring billing, valor paytech, valorpay

## 简介

Laravel client for ValorPay: hosted payment pages, transaction lookups, card tokens, subscriptions and webhook hints.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
