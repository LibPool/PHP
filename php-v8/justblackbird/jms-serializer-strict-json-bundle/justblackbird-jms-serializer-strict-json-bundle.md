# justblackbird/jms-serializer-strict-json-bundle

> 标签: jms, json, serializer, symfony

## 简介

Symfony integration for JMS Serializer strict JSON deserializer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
