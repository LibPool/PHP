# glowingblue/null-driver

> 标签: driver, email, flarum, migration, null

## 简介

Exposes Flarum's NullDriver to be selected as an email driver in the Admin settings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
