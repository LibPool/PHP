# marzsv/sv-dte-signer

> 标签: dte, el-salvador, factura-electronica

## 简介

PHP SDK for signing Documentos Tributarios Electrónicos (DTE) for El Salvador using JWS RS512

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
