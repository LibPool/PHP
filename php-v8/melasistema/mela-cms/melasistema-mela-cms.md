# melasistema/mela-cms

> 标签: agentic, cms, filament, laravel, multilanguage

## 简介

MelaCMS core: an agentic-coding-friendly CMS for Laravel built on Filament, Blade and Alpine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
