# hnraytek/flame-module-kernel

> 标签: attribute-driven, auto-discovery, composer, dependency-injection, event-driven, flame, kernel, modular, module, php-attributes, plugin, thinkphp

## 简介

A declarative, auto-discovering, event-driven module kernel for PHP 8+/一款 php 8+ 的声明式、自动发现、事件驱动的模块内核

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
