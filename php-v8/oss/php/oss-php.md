# oss/php

> 标签: oss

## 简介

PHP library for Open Search Server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.open-search-server.com/
- 源码仓库：https://github.com/lemonde/oss-php.git
- Packagist 页面：https://packagist.org/packages/oss%2Fphp
