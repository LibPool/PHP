# treedevs/novacontent-connect

> 标签: PHP

## 简介

Módulo de integración con Novacontent Commerce para enriquecimiento asistido de atributos del catálogo Magento 2

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
