# anexia/zf2-monitoring

> 标签: PHP

## 简介

A zf2 module to monitor runtime (php, zf2) versions, composer package versions and composer package licences

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
