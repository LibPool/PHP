# anexia/laravel-basemodel

> 标签: PHP

## 简介

A laravel module that provides traits to extend eloquent model's filter, search, sorting, pagination, functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
