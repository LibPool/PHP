# anexia/composer-tools

> 标签: PHP

## 简介

fetch version and licence information of installed composer packages from packagist

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://packagist.org/packages/anexia%2Fcomposer-tools
- 源码仓库：https://github.com/anexia-it/anexia-composer-tools.git
- Packagist 页面：https://packagist.org/packages/anexia%2Fcomposer-tools
