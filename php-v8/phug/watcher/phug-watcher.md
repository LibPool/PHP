# phug/watcher

> 标签: directory, phug, pug, watcher

## 简介

Watcher for Phug, Pug (ex-Jade) PHP port, HTML template engine structured by indentation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
