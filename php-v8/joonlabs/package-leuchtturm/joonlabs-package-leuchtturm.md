# joonlabs/package-leuchtturm

> 标签: joonlabs, laravel, leuchtturm

## 简介

This package provides automatic creation of GraphQL types and fields from Eloquent Models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
