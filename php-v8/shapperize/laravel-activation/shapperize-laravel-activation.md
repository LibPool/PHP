# shapperize/laravel-activation

> 标签: activation, hints, laravel, onboarding, product-tour, saas

## 简介

Aha-moment activation for Laravel SaaS apps: proof-of-value steps, plan gates, regression, tour and hint state.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
