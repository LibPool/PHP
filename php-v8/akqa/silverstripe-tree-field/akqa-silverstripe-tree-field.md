# akqa/silverstripe-tree-field

> 标签: cms, drag-and-drop, formfield, hierarchy, silverstripe, tree

## 简介

A reusable hierarchical tree form field for Silverstripe CMS with inline add, drag and drop, and side-by-side editing

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
