# wadify/store-key-client-php

> 标签: dynamodb, key-value-db, wadify

## 简介

Provides a client for store key databases (like DynamoDB, redis, etc..)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
