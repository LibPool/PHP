# trydoku/php-sdk

> 标签: api, document-generation, docx, pdf, sdk, trydoku

## 简介

Official PHP client for the TRYDOKU document generation API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://www.trydoku.com
- 源码仓库：https://github.com/Trydoku/php-sdk.git
