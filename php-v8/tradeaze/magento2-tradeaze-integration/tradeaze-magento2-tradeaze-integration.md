# tradeaze/magento2-tradeaze-integration

> 标签: delivery, logistics, magento, magento-2, magento2, shipping, tradeaze

## 简介

Magento extension to integrate Tradeaze delivery methods with the Magento ecommerce platform

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
