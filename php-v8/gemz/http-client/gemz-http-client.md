# gemz/http-client

> 标签: gemz, http-client

## 简介

Gemz Http Client is a simple Symfony Http-Client wrapper to provide an easy development experience for most use cases.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
