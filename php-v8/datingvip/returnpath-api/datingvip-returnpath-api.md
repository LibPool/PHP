# datingvip/returnpath-api

> 标签: returnpath

## 简介

PHP Client Library for Return Path API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://api.returnpath.com/
- 源码仓库：https://github.com/DatingVIP/returnpath-api-php.git
- Packagist 页面：https://packagist.org/packages/datingvip%2Freturnpath-api

## 获取地址

- Composer 安装：`composer require datingvip/returnpath-api`
- Packagist 仓库：https://repo.packagist.org/p2/datingvip/returnpath-api.json
- PHP 要求：>=5.3.0
