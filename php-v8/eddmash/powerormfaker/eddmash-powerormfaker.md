# eddmash/powerormfaker

> 标签: faker, orm, php

## 简介

powerormfake generates dummy data when using PowerOrm. An extension of Faker library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
