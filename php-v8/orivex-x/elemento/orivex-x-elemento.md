# orivex-x/elemento

> 标签: Forms, builder, component, fluent, html, templates, theming, xss-prevention

## 简介

Modern PHP HTML template builder with fluent interface, form building, theming, and component system.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
