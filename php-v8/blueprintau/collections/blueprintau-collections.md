# blueprintau/collections

> 标签: array, blueprintau, collection, enumerable

## 简介

A pure, standalone array wrapper for BlueprintAU — generic Collection and Enumerable contract with no dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
