# lunarphp/panel-addon-example

> 标签: PHP

## 简介

Starter template and reference add-on for lunarphp/panel: a page, a nav item, a slot, and a table extension registered at runtime without recompiling the panel. Fork it with `composer create-project lunarphp/panel-addon-example`.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
