# lunarphp/upgrade

> 标签: ecommerce, laravel, lunar, rector, upgrade

## 简介

Upgrade tooling for migrating Lunar v1.x installations to v2.x.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://packagist.org/packages/lunarphp%2Fupgrade
- 源码仓库：https://github.com/lunarphp/upgrade.git
- Packagist 页面：https://packagist.org/packages/lunarphp%2Fupgrade
