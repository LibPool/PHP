# lunarphp/filament

> 标签: ecommerce, filament, headless, laravel, lunar

## 简介

Filament components, widgets, and schemas for Lunar — composable building blocks for any Filament v5 panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
