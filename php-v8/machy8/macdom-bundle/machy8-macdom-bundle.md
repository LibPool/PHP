# machy8/macdom-bundle

> 标签: bundle, html, macdom, minification, preprocessor, templating

## 简介

Macdom HTML Preprocessor bundle for Symfony framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
