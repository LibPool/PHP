# machy8/xhtml-formatter

> 标签: beautifier, formatter, html, xhtml, xml

## 简介

Simple, lightweight, customizable (X)HTML and XML formatter / beautifier.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
