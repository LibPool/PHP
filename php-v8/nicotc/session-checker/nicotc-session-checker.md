# nicotc/session-checker

> 标签: PHP

## 简介

Cuando un usuario inicia sesión en tu aplicación Session Checker verificará si ya tiene una sesión abierta en otro navegador. Si se encuentra una sesión abierta, se mostrará un mensaje al usuario informando que ya tiene una sesión abierta en otro lugar y se cerrará la sesión anterior. De esta manera, se evita que los usuarios tengan varias sesiones abiertas al mismo tiempo y se mejora la seguridad y confiabilidad de tu aplicación.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
