# andreibesleaga/zfeeder

> 标签: Syndication, aggregator, atom, feedreader, jsonfeed, opml, rss, zfeeder

## 简介

zFeeder 2.0 - the 2004 PHP RSS aggregator, rebuilt for 2026. Flat-file or SQLite, OPML subscriptions, template driven, embeddable in one line.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
