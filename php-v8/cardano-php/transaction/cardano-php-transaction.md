# cardano-php/transaction

> 标签: cardano, cbor, coin-selection, signing, transaction

## 简介

Cardano transaction serialization, addresses, native scripts, slot arithmetic, fees, minimum UTxO, coin selection, transaction building and witness assembly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
