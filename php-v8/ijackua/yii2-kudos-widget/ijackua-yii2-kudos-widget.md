# ijackua/yii2-kudos-widget

> 标签: extension, kudos, like, widget, yii

## 简介

Yii2 widget for Svbtle style Kudos. Based on JS from https://github.com/masukomi/kudos

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
