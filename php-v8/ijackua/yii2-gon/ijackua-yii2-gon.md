# ijackua/yii2-gon

> 标签: extension, javascript, yii

## 简介

Push data from PHP controller to JS variable (inspired by https://github.com/gazay/gon)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
