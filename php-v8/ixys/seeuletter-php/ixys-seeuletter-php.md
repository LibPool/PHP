# ixys/seeuletter-php

> 标签: api, mailing, printing, rest, seeuletter, web service, wrapper

## 简介

Seeuletter.com API PHP wrapper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
