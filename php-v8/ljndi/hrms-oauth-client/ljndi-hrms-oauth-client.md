# ljndi/hrms-oauth-client

> 标签: HRMS, SSO, identity, ljndi, oauth, oauth2, pkce

## 简介

OAuth 2.1 PKCE client for Continue with LJNDI HRMS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
