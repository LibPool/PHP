# adapik/cms

> 标签: DER, asn.1, asn1, ber, binary, cades, cms, decoding, encoding, pkcs7, x690

## 简介

A PHP Library that allows you to decode ASN.1 CMS using Basic Encoding Rules (BER).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
