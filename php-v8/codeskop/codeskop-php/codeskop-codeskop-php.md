# codeskop/codeskop-php

> 标签: Guzzle, apm, codeskop, error-monitoring, laravel

## 简介

Codeskop server SDK for PHP: errors, incoming requests and outgoing API calls from Laravel and plain PHP apps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
