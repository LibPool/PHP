# jonasva/laravel-vision

> 标签: OCR, gcloud, google, laravel, vision

## 简介

A Laravel 5 package to interact with Google Cloud Vision.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
