# viget/wordpress-site-starter

> 标签: boilerplate, cms, components, ddev, tailwind, vite, wordpress

## 简介

A custom WordPress Site Starter Kit by Viget.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
