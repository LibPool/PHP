# viget/craft-disqus-notify

> 标签: Craft, cms, craft-plugin, craftcms, disqus notify

## 简介

Notify authors when a comment is added via Disqus.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
