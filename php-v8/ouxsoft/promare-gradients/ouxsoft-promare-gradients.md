# ouxsoft/promare-gradients

> 标签: css, gradients, neon, sass, web

## 简介

Promare Gradients standardizes the use of neon colors on the web for backgrounds..

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
