# barbasolution/filament-knowledge-base

> 标签: filament, knowledge-base, laravel, multilingual

## 简介

A configurable multilingual knowledge base resource and browser for Filament panels.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
