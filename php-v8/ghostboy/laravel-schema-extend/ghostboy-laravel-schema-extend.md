# ghostboy/laravel-schema-extend

> 标签: comment, laravel, mysql, schema

## 简介

support MySQL 'column comment' and 'table comment'.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
