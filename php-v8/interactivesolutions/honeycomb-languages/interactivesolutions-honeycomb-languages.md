# interactivesolutions/honeycomb-languages

> 标签: ISO codes, back end language, content language, front end language, honeycomb, information, language, language family, languages, native name, package, world languages

## 简介

HoneyComb languages package. Information about languages arround the world. (Language family, language, native name, iso codes). Availability to select language for front end, back end, conttent.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
