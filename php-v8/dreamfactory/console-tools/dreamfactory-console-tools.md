# dreamfactory/console-tools

> 标签: Symfony2, console, dreamfactory, utility

## 简介

A library of helper classes for working with the Symfony2 Console component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
