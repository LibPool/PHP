# dreamfactory/df-aws

> 标签: api, aws, dreamfactory, dynamodb, redshift, rest, s3

## 简介

AWS package containing services for the DreamFactory Platform 2.0.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
