# dreamfactory/package-installer

> 标签: cloud, dsp, installer, jetpack, plugin

## 简介

DreamFactory Services Platform(tm) Package Installer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
