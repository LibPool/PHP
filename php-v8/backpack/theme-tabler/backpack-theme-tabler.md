# backpack/theme-tabler

> 标签: Backpack Addon, Backpack for Laravel, ThemeTabler, backpack, laravel

## 简介

UI for Backpack v6 that uses Tabler and Bootstrap v5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
