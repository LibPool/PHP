# marksamp/ibge-localidades

> 标签: Localidades, Municipios, api, brasil, estados, ibge

## 简介

Biblioteca PHP para consumir APIs do IBGE, com foco inicial em localidades (Estados e Municípios)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
