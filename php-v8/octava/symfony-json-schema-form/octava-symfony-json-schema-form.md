# octava/symfony-json-schema-form

> 标签: PHP

## 简介

Clone of limenius/liform. Symfony json schema form is a library for serializing Symfony Forms into JSON schema.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
