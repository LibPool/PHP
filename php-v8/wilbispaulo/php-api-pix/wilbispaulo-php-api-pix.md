# wilbispaulo/php-api-pix

> 标签: PHP

## 简介

Biblioteca de classes para gerar o PIX COPIA E COLA (txt) e o PIX QRCode (Base64 img).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
