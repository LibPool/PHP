# trotexnet/laravel-plesk

> 标签: api, facade, laravel, package, plesk

## 简介

A Laravel wrapper and facade package for the Plesk RPC API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
