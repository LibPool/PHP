# sunfoxcz/price-calculator

> 标签: DPH, calculation, calculator, discount, price, reduction, tax, vat

## 简介

Library for easier price calculation using VAT and discount.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
