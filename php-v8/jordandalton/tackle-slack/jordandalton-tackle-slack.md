# jordandalton/tackle-slack

> 标签: ai, laravel, slack, tackle

## 简介

Drive a Laravel Tackle coding session from Slack — over Socket Mode, so it works from anywhere with no public URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
