# jordandalton/tackle-telegram

> 标签: ai, laravel, tackle, telegram

## 简介

Drive a Laravel Tackle coding session from Telegram — outbound-only, so it works from anywhere with no public URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
