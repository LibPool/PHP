# ballen/sluginator

> 标签: friendly, slug, url

## 简介

A simple URL slug creation library for PHP, simply feed it a string (such as a blog title) and it will create a URL friendly slug.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
