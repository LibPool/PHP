# ballen/metar

> 标签: ICAO, METAR, api, flightsim, ivao, noaa, pilots, vatsim, weather

## 简介

A PHP library to query aerodrome METAR information.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
