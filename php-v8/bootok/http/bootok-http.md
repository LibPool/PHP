# bootok/http

> 标签: EasyHttp, client, http, symfony, webman

## 简介

基于 Symfony HttpClient 的 HTTP 客户端，完全兼容 yzh52521/easyhttp 门面 API（高版本 PHP 替代方案）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
