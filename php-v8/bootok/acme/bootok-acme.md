# bootok/acme

> 标签: ACME, certificate, dns-01, letsencrypt, ssl, tls, wildcard

## 简介

纯 PHP 实现的 ACME v2 (RFC 8555) 客户端，DNS-01 验证，PHP 8.2+，无重依赖

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
