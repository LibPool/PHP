# webino/webino-dbdump

> 标签: database, db, dump, framework, webino, zend, zf2

## 简介

Database Dump Utility for Zend Framework 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
