# webino/zend-escaper

> 标签: ZendFramework, escaper, zf

## 简介

Securely and safely escape HTML, HTML attributes, JavaScript, CSS, and URLs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
