# webino/nette-tester

> 标签: Xdebug, assertions, clover, code coverage, nette, pcov, phpdbg, phpunit, testing, unit

## 简介

Nette Tester: enjoyable unit testing in PHP with code coverage reporter. 🍏🍏🍎🍏

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
