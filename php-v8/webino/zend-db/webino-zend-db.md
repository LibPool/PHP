# webino/zend-db

> 标签: ZendFramework, db, zf

## 简介

Database abstraction layer, SQL abstraction, result set abstraction, and RowDataGateway and TableDataGateway implementations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
