# lukasyelle/dusk-prodsafe

> 标签: laravel, testing, webdriver

## 简介

Laravel Dusk provides simple end-to-end testing and browser automation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
