# gnutix/blackhole

> 标签: PHP

## 简介

Blackhole is a small set of classes that helped me build websites back in the old days. Entirely static, no tests at all, not production ready, and surely full of bugs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
