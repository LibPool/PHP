# adrianorsouza/codeigniter-phpmailer

> 标签: codeigniter, mail, phpmailer

## 简介

CodeIgniter Mail Plugin Powered by PHPMailer Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
