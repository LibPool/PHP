# shel/neos-nginx-cache

> 标签: Neos, caching, flow, http, invalidation, nginx, proxy, purge

## 简介

A plugin for Neos CMS to auto purge NGINX proxy cache after publishing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
