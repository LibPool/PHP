# shel/neos-norman-nodely

> 标签: PHP

## 简介

Probably one of the best Neos CMS plugins ever, providing an amazing 'AI' assistant in the Neos backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
