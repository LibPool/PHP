# shel/neos-logs

> 标签: Neos, Viewer, analyse, exception, flow, log, logfile, logging, neoscms

## 简介

Allows access to logfiles and exceptions from the Neos CMS backend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
