# shel/neos-themebuilder

> 标签: Neos, colorpicker, editor, neoscms, theme, themebuilder

## 简介

A plugin for NeosCMS which provides integrator/editor tools to define and use themes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
