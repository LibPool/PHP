# h1ch4m/blade-component-previewer

> 标签: PHP

## 简介

A Laravel package for visually creating, editing, and previewing Blade components with live editing of Blade, CSS, and JS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
