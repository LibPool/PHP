# thelia/query-builder-module

> 标签: PHP

## 简介

QueryBuilder module for Thelia 3 — Generic rule engine: build condition trees in the back-office, compile them to SQL and trigger actions (product lists, cart and product discounts) on front-office hooks and through the API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
