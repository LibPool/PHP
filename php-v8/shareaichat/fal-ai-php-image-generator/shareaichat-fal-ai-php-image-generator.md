# shareaichat/fal-ai-php-image-generator

> 标签: ai-art, ai-image-generator, ai-sdk, fal, fal-ai, flux, flux-dev, flux-kontext, flux-schnell, generative-ai, image-generation, php-ai, shareaichat, stable-diffusion, text-to-image

## 简介

A zero-dependency PHP SDK for generating AI images with fal.ai — FLUX.1 Schnell, FLUX.1 Dev, FLUX Kontext and Stable Diffusion XL. Simple text-to-image, batch generation and image-to-image support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
