# nakipelo/tourism-api

> 标签: Russia, api, fsa, hotels, laravel, package, resorts, tourism

## 简介

A Laravel 12 package for working with Russian Tourism API (tourism.fsa.gov.ru)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
