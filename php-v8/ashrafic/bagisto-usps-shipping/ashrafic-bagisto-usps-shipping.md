# ashrafic/bagisto-usps-shipping

> 标签: bagisto, checkout, ecommerce, laravel, shipping, usps

## 简介

USPS shipping for Bagisto 2.x — live commercial rates at checkout via the USPS Prices v3 OAuth API, label printing and refunds via the Labels v3 API, per-product package dimensions, and nonstandard-classification fallback.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
