# pardalesteban/orm-helper-php

> 标签: database, library, orm, pdo, php, sql

## 简介

Mini ORM helper para PHP. Facilita el uso de PDO sin tener que crear un ORM desde cero cada vez.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
