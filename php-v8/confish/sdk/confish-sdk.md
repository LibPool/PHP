# confish/sdk

> 标签: config, configuration, confish, feature-flags, sdk

## 简介

Official PHP SDK for confish — typed configuration, actions, logs, feeds, and webhook verification.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
