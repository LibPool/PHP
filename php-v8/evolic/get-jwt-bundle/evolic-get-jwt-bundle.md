# evolic/get-jwt-bundle

> 标签: Authentication, JWS, bundle, jwt, symfony5

## 简介

This Symfony bundle provides a security listener to return a JWT

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
