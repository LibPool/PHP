# nicksdot/phpstan-phpstorm-error-identifiers

> 标签: PHP

## 简介

Custom PHPStan formatter to show error identifiers in PhpStorm inspection output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
