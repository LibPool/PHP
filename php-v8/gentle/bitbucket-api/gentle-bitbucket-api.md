# gentle/bitbucket-api

> 标签: api, bitbucket

## 简介

Bitbucket API wrapper for PHP >= 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/gentlero/bitbucket-api.git
