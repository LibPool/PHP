# mralaminahamed/squad-modules-lite-stubs

> 标签: PHPStan, divi, squad-modules, static analysis, stubs, wordpress, wordpress-plugin

## 简介

Squad Modules for Divi function and class declaration stubs for static analysis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
