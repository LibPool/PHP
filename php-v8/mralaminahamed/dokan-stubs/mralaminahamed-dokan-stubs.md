> 标签: PHPStan, dokan, multivendor, static analysis, stubs, woocommerce, wordpress, wordpress-plugin

## 简介

Dokan Multivendor Marketplace function and class declaration stubs for static analysis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
