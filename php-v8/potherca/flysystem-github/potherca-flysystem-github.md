# potherca/flysystem-github

> 标签: Flysystem, adapter, flysystem-adapter, flysystem-github, github, potherca

## 简介

Flysystem adapter for Github

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
