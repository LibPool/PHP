# nuthouse-cis/sxgeo

> 标签: IP, location, sxgeo, sypexgeo

## 简介

PHP library Sypex Geo API (http://sypexgeo.net)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
