# safegrd/laravel

> 标签: backup, database-backup, disaster-recovery, encryption, laravel, mysql, postgresql, restore, safegrd, sqlite

## 简介

Back up a Laravel app with SafeGrd: the database, .env and storage/app in one encrypted backup, locked against deletion and test-restored on a schedule.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
