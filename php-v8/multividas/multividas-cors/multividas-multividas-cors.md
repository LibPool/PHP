# multividas/multividas-cors

> 标签: multividas, multividas-cors

## 简介

Multividas CORS middleware is a package designed to handle Cross-Origin Resource Sharing (CORS).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
