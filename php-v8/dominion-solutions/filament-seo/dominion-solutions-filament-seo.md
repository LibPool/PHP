# dominion-solutions/filament-seo

> 标签: filament, laravel, meta, open-graph, seo

## 简介

Clean page titles, unique meta descriptions, and Open Graph/Twitter tags for Laravel + Filament, managed from the Filament admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
