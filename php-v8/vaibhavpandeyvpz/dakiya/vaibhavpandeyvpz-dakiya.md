# vaibhavpandeyvpz/dakiya

> 标签: client, curl, http, library, psr-18, psr-7

## 简介

Tiny HTTP client for exchanging PSR-7 messages, based on PSR-18.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
