# vaibhavpandeyvpz/jweety

> 标签: Authentication, JSON Web Token, RFC7519, hmac, jwt

## 简介

Simple JWT (RFC 7519) encoding/decoding and validation library, for PHP >= 8.2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
