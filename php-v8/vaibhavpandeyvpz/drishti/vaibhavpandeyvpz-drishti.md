# vaibhavpandeyvpz/drishti

> 标签: logger, logging, psr-3

## 简介

A lightweight, flexible PSR-3 compliant logging library with configurable backends and zero dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
