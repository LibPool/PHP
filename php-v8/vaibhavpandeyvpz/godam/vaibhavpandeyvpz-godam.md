# vaibhavpandeyvpz/godam

> 标签: cache, psr-16, psr-6

## 简介

A modern, PSR-6 and PSR-16 compliant caching library for PHP 8.2+ with support for multiple storage backends.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
