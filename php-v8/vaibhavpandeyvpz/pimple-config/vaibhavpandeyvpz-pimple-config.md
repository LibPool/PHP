# vaibhavpandeyvpz/pimple-config

> 标签: config, pimple, provider, service

## 简介

A service provider for Pimple to load configuration from simple PHP files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
