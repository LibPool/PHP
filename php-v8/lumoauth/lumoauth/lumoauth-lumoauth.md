# lumoauth/lumoauth

> 标签: abac, agents, auth, authorization, lumoauth, mcp, oauth, oidc, zanzibar

## 简介

Official LumoAuth PHP SDK — RBAC / ReBAC / ABAC checks, agent identity, JIT permissions, AAuth request signing. Framework integrations: lumoauth/symfony-bundle, lumoauth/laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
