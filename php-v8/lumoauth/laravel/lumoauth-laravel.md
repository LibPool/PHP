# lumoauth/laravel

> 标签: auth, authorization, laravel, lumoauth, oauth

## 简介

LumoAuth for Laravel: service provider, LumoAuth facade and a permission middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
