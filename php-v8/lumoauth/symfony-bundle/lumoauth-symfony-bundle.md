# lumoauth/symfony-bundle

> 标签: auth, authorization, bundle, lumoauth, oauth, symfony

## 简介

LumoAuth for Symfony: configuration, an autowired LumoAuth client, and an access-token handler for the security component.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
