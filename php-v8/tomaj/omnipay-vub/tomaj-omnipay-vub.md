# tomaj/omnipay-vub

> 标签: epay, eplatby, gateway, merchant, omnipay, pay, payment, vub

## 简介

VUB eplatby driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
