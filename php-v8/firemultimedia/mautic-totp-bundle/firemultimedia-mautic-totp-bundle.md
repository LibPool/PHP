# firemultimedia/mautic-totp-bundle

> 标签: 2fa, Mautic, Two-factor Authentication, integration, one-time password, otp, plugin, time-based one-time password, totp

## 简介

This plugin adds generic time-based one-time password (TOTP) integration to mautic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
