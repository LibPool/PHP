# yaangvu/laravel-rpc

> 标签: api, json-prc, rpc

## 简介

Easy implementation of the JSON-RPC 2.0 server for the Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
