# rabosh/laravel

> 标签: PHP

## 简介

Laravel SDK for pushing billing events to the Rabosh billing platform

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://bitbucket.org/rabosh/rabosh-laravel
- 源码仓库：https://bitbucket.org/rabosh/rabosh-laravel.git
- Packagist 页面：https://packagist.org/packages/rabosh%2Flaravel
