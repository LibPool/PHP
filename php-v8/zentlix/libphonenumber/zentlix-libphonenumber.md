# zentlix/libphonenumber

> 标签: libphonenumber, phone-number, phonenumber, spiral, telephone number

## 简介

Integrates Google's phone number handling library into Spiral Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
