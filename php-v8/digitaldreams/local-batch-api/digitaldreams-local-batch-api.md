# digitaldreams/local-batch-api

> 标签: PHP

## 简介

Drop-in replacement for Anthropic and OpenAI batch APIs, self-hosted against Ollama or LM Studio.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
