# j4wx/laravel-actions-scramble

> 标签: PHP

## 简介

Extensions for Scramble to enable automatic parsing of routes when using laravel actions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
