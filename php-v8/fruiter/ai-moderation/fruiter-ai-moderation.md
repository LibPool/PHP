# fruiter/ai-moderation

> 标签: ai, compliance, content, extension, flarum, moderation, openai

## 简介

AI 内容合规审核扩展：基于任意 OpenAI 兼容 API 自动检查用户发布的内容（Flarum 1.8+ / PHP 7.4+）。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
