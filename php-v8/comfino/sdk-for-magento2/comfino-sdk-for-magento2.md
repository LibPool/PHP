# comfino/sdk-for-magento2

> 标签: PHP

## 简介

Comfino PHP SDK adapter for Magento 2 - wires Magento native services to SDK PSR interfaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
