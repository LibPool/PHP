# comfino/php-api-client

> 标签: api, bnpl, client, comfino, gateway, installments, pay later, payment, psr-18, psr-7

## 简介

ComfinoPay PHP API client library for the ComfinoPay payment gateway with PSR-7/17/18 support - portable protocol layer for the ComfinoPay REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
