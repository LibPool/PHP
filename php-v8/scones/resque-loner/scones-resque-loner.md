# scones/resque-loner

> 标签: Tasks, message queue, psr-12, queue, resque, task queue, unique jobs

## 简介

resque-loner is a plugin for scones/resque to make your jobs unique.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
