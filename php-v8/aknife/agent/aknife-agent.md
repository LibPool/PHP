# aknife/agent

> 标签: iplocation, useragent, 浏览器标识

## 简介

获取IP、语言、操作系、浏览器、手机备的名称等

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
