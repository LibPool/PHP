# konradmichalik/typo3-routing-mcp

> 标签: PHP

## 简介

Expose annotated typo3-routing frontend routes as MCP tools via a Streamable HTTP endpoint.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
