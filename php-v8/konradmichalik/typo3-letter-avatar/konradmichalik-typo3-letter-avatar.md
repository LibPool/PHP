# konradmichalik/typo3-letter-avatar

> 标签: PHP

## 简介

Letter Avatar - TYPO3 extension, which generates colorful backend user avatars using name initials letter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
