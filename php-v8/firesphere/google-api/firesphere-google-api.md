# firesphere/google-api

> 标签: Ninja Unicorns, Unicorns, analytics, api, google, ninja, silverstripe

## 简介

Connect to the Google Analytics API to get page visits

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
