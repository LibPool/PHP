# marcoshoo/propel-eloquent

> 标签: eloquent, laravel, propel, propel2

## 简介

Propel2 behavior that makes model classes virtually extend a Eloquent model class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
