# sseidelmann/codesniffer-installer

> 标签: PHP_CodeSniffer, phpcs, standards

## 简介

Composer plugin for installing PHP_CodeSniffer standards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
