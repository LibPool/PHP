# jainilnagar/navkit

> 标签: Craft, cms, craft-plugin, craftcms, menu, menus, navigation

## 简介

A full-featured navigation and menu builder for Craft CMS — multi-site, structured, translation-ready.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
