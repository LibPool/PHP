# northbridg3/levtowords

> 标签: BGN, faktura, lev

## 简介

Converts a number to BGN (New Bulgarian Lev) words description. Useful for generating invoices.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
