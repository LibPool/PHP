# pnscripts/pn-shop-core

> 标签: cms, e-commerce, laravel, pn-shop, shop

## 简介

The PN Scripts Shop platform core: catalog, cart, checkout, orders, payments, shipping, tax, CMS, SEO, promotions, returns, plugins, themes, APIs and the installer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
