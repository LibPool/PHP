# gaomingcode/tinymce

> 标签: editor, html, javascript, richtext, tinymce, wysiwyg

## 简介

Web based JavaScript HTML WYSIWYG editor control.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
