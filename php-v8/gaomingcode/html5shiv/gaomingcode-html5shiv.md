# gaomingcode/html5shiv

> 标签: html5shiv

## 简介

Defacto way to enable use of HTML5 sectioning elements in legacy Internet Explorer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
