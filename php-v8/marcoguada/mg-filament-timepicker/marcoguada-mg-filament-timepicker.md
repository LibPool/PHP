# marcoguada/mg-filament-timepicker

> 标签: 12h, 24h, filament, filament-plugin, filamentphp, laravel, linear, marcoguada, mg-filament-timepicker, popup, radial, timepicker, timepicker-popup, timepicker-popup-linear, timepicker-popup-radial

## 简介

A Filament v5 plugin that enhances timepicker fields with a popup time selector.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
