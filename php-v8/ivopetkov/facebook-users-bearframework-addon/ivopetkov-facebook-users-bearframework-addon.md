# ivopetkov/facebook-users-bearframework-addon

> 标签: Users, addon, bear framework, facebook

## 简介

Facebook login provider for the for the Bear Framework users addon

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
