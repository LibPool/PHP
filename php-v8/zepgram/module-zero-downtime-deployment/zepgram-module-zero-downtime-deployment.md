# zepgram/module-zero-downtime-deployment

> 标签: PHP

## 简介

Disable native change detection from Magento2 to allow Zero Downtime Deployment (ZDD)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
