# zayono/zayono-php

> 标签: africa, mobile-money, payment-gateway, payments, sdk, zayono

## 简介

Official PHP SDK for the Zayono unified Mobile Money payment gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
