# masroore/stopwords

> 标签: analyzer, natural language processing, nlp, php, stop list, stop word, stop words, stop-word, stop-words, stopword, stopword list, stopwords, string, text, tokenize, word

## 简介

A PHP package to remove common stopwords from an input text, it covers most languages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
