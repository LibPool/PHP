# masroore/html2text

> 标签: html, html2text, text

## 简介

A PHP package to convert HTML into a plain text format

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/masroore/php-html2text
- 源码仓库：https://github.com/masroore/php-html2text.git
- Packagist 页面：https://packagist.org/packages/masroore%2Fhtml2text
