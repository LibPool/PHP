# youshido/cms

> 标签: bundle, cms, symfony

## 简介

Bundle for easy integrations CMS in symfony project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/Youshido/AdminBundle
- 源码仓库：https://github.com/Youshido/CMS.git
- Packagist 页面：https://packagist.org/packages/youshido%2Fcms

## 获取地址

- Composer 安装：`composer require youshido/cms`
- Packagist 仓库：https://repo.packagist.org/p2/youshido/cms.json
- 许可证：MIT
- PHP 要求：>=5.4
