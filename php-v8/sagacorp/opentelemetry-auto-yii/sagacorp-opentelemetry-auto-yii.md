# sagacorp/opentelemetry-auto-yii

> 标签: instrumentation, open-telemetry, opentelemetry, otel, tracing, yii

## 简介

OpenTelemetry auto-instrumentation for Yii

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
