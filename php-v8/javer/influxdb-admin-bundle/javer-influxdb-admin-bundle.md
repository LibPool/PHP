# javer/influxdb-admin-bundle

> 标签: admin, influxdb, odm, sonata, symfony

## 简介

Provides integration of InfluxDB ODM with SonataAdminBundle

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
