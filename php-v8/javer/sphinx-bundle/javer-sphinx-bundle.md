# javer/sphinx-bundle

> 标签: Symfony2, doctrine2, search, sphinx, sphinxql, symfony

## 简介

Provides integration of Sphinx search engine with Symfony using SphinxQL

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
