# mattdi/telebirr-ussd

> 标签: PHP

## 简介

Laravel integration package for Telebirr SOAP payment APIs, including asynchronous USSD Push / Buy Goods.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
