# ssntpl/cloud-storage

> 标签: Flysystem, cloud-storage, laravel, ssntpl

## 简介

Laravel Storage Driver to sync files on to the multiple disks asynchronously

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
