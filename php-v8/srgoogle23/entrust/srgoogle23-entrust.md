# srgoogle23/entrust

> 标签: acl, auth, illuminate, laravel, permission, roles

## 简介

This package provides a flexible way to add Role-based Permissions to Laravel. Supports laravel 11|12

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
