# erelke/hungarian-validator-bundle

> 标签: PHP

## 简介

Symfony bundle a Magyarorszagon hasznalt hivatalos adatok (ugy mint: szemelyi szam, adoazonosito jel...) validalasara

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
