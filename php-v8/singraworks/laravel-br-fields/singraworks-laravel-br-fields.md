# singraworks/laravel-br-fields

> 标签: brasil, brazil, cast, cnpj, cpf, eloquent, laravel, lgpd, validation

## 简介

Laravel validation rules and Eloquent casts for Brazilian CPF and CNPJ numbers, on top of singraworks/br-fields.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
