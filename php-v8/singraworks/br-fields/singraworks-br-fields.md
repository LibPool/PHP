# singraworks/br-fields

> 标签: brasil, brazil, cnpj, cpf, formatting, lgpd, redaction, validation

## 简介

Validate, format, and redact Brazilian CPF and CNPJ numbers. Pure PHP, no Composer dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
