# franzip/serp-page-serializer

> 标签: SERP, json, page, search-engine, serializer, xml

## 简介

Serialize/deserialize Search Engine Result Pages to JSON and XML (JMS/Serializer wrapper).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
