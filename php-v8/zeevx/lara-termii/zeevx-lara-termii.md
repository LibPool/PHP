# zeevx/lara-termii

> 标签: lara-termii, laravel, otp, sms, termii, voice, whatsapp, zeevx

## 简介

A modern Laravel package for the Termii messaging & OTP API - https://www.termii.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
