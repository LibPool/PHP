# zeevx/php-brimble-sandbox

> 标签: api, brimble, sandbox, sdk

## 简介

Framework-agnostic PHP SDK for the Brimble Sandbox API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
