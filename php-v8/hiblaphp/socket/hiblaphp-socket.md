# hiblaphp/socket

> 标签: Connection, HiblaPHP, Socket, async, stream

## 简介

Async, streaming plaintext TCP/IP and secure TLS socket server and client connections for HiblaPHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
