# atoria/alfred

> 标签: ai, ai-agent, dashboard, developer-tools, explainability, filament, github, gitlab, inertia, jira, laravel, livewire, openai, pull-request, tickets

## 简介

Point at anything in your Laravel app and ask how it is calculated, change it with AI, or report it. Plain-language explanations, AI-proposed UI changes with live preview, tickets (Jira, GitHub, GitLab, Linear, Trello, ClickUp, Asana) and pull requests (GitHub, GitLab, Bitbucket).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
