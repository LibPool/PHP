# filipvanreeth/image-resolution

> 标签: PHP

## 简介

Shows the image resolution (DPI/PPI) in the media list view of the full image by using the PHP Imagick extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
