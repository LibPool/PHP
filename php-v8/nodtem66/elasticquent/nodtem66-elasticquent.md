# nodtem66/elasticquent

> 标签: elasticsearch, eloquent, laravel

## 简介

Maps Laravel Eloquent models to Elasticsearch types with cviebrock/laravel-elasticsearch

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
