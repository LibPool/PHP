# typo3-contentblocks/composer-plugin

> 标签: content-blocks, typo3

## 简介

This composer plugin manages registration of Content Blocks for the Content Blocks API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
