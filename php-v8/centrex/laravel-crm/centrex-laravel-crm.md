# centrex/laravel-crm

> 标签: centrex, clv, crm, laravel, laravel-crm, pipeline

## 简介

Core CRM package for companies, contacts, leads, deals, activities, CLV calculation, and pipeline analytics

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
