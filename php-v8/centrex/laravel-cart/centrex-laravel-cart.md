# centrex/laravel-cart

> 标签: centrex, laravel, laravel-cart

## 简介

Shopping cart for Laravel with session, cookie, and database storage, Livewire components, and REST API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
