# platoniq/random-name-generator

> 标签: alliteration, generator, random, video game

## 简介

A library to create interesting, sometimes entertaining, random names with multi-language support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
