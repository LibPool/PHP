# primehover/danfebr

> 标签: Danfe, laravel, lumen, nfe, nota fiscal

## 简介

Pacote em Laravel/Lumen para conexão com a API da danfe.br.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
