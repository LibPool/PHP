# apavliukov/laravel-ai-core

> 标签: PHP

## 简介

Shared AI core on top of laravel/ai: model catalogue with prices, request ledger, executor, queue, cost accounting and batch polling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
