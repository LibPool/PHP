# apavliukov/laravel-devtools

> 标签: PHP

## 简介

Shared Laravel dev tooling: the laravel-finalize Boost skill, a translation completeness checker, and a Claude Code Stop-hook backstop.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
