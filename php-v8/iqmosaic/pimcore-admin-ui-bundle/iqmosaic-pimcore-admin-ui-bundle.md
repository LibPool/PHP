# iqmosaic/pimcore-admin-ui-bundle

> 标签: PHP

## 简介

This is a UI bundle that allows for the direct uploading of documents to a data object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
