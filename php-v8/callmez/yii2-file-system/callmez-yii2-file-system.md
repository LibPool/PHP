# callmez/yii2-file-system

> 标签: Flysystem, file, qiniu, storage, system, yii2

## 简介

This extension provides a filesystem solution for Yii 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
