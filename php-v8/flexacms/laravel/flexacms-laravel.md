# flexacms/laravel

> 标签: cms, flexa, headless, laravel, sdk

## 简介

Laravel client for the Flexa headless CMS: fluent queries, caching and typed entries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
