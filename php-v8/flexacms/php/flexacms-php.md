# flexacms/php

> 标签: API-Client, cms, flexa, headless, sdk

## 简介

Framework-agnostic PHP client for the Flexa headless CMS. Pluggable HTTP transport and cache, no dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
