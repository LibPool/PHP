# loumray/wpforms

> 标签: Forms, plugins, theme, wordpress

## 简介

Advanced forms library for development in wordpress using a real object oriented approach

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
