# samwilson/kohana_mailqueue

> 标签: email, kohana, mail, queue, swiftmailer

## 简介

Kohana module to queue, send, and log email messages from an application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
