# samwilson/unlinked-wikibase

> 标签: mediawiki, wikibase

## 简介

MediaWiki extension providing access to Wikibase entities from wikis that are not linked to a Wikibase site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
