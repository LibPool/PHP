# arunchaitanyajami/wp-api-jwt-auth

> 标签: PHP

## 简介

A simple plugin to add JSON Web Token (JWT) Authentication to WP REST API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
