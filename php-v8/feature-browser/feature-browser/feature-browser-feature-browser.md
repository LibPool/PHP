# feature-browser/feature-browser

> 标签: PHP

## 简介

Feature Browser takes your Behat .feature files and turns them alchemy-like into an interactive user manual.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
