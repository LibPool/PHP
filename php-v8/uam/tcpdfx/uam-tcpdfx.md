# uam/tcpdfx

> 标签: TCPDF, fpdf, fpdi, pdf

## 简介

Extension of TCPDF library and FPDI library with added convenience methods.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
