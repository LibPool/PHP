# uam/aws-bundle

> 标签: aws, bundle, cloud, s3, symfony

## 简介

Symfony bundle to provide a wrapper service around AWS S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
