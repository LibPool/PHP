# uam/datatables-bundle

> 标签: bootstrap, bundle, datatables, jquery, symfony

## 简介

Datatables jquery plugin packaged as a Symfony bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
