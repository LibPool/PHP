# everapi/numlookupapi-php

> 标签: IP, api, numlookupapi, numlookupapi-php, numlookupapi.com, phone verification api

## 简介

A PHP wrapper for the numlookupapi.com API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
