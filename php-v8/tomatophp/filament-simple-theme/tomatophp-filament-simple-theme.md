# tomatophp/filament-simple-theme

> 标签: filament, filament-theme, filament-theme-simple, laravel, php

## 简介

A simple theme for FilamentPHP with custom user menu in sidebar

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
