# tomatophp/tomato-figma

> 标签: converter, figma, html, laravel, php, splade, tailwind, tomato

## 简介

Plugin to convert figma file to HTML/CSS/TailwindCSS/Flutter Style

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
