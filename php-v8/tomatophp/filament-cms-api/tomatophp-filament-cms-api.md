# tomatophp/filament-cms-api

> 标签: api, cms, filament-cms, filamentphp, laravel, php, tomatophp

## 简介

Read-only JSON API for TomatoPHP Filament CMS posts and categories

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
