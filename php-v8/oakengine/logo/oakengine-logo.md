# oakengine/logo

> 标签: animation, javascript, logo, oakengine, svg

## 简介

JavaScript library for creating and animating the OakEngine logo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://oakengine.com
- 源码仓库：https://github.com/oakengine/logo.git
- Packagist 页面：https://packagist.org/packages/oakengine%2Flogo
