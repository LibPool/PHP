# 4k1r0/codeigniterdb

> 标签: codeigniter, database, mysql, mysqli, pdo

## 简介

Use the database library separately from CodeIgniter 3 (fork from evolution/codeigniterdb)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
