# scrappy-hu/laravel

> 标签: api, laravel, playwright, scraping, scrappy, webhooks

## 简介

Official Scrappy SDK for Laravel — submit scrape jobs and verify webhooks against api.scrappy.hu.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
