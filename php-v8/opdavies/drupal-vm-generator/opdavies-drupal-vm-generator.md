# opdavies/drupal-vm-generator

> 标签: drupal, drupal-vm, vagrant

## 简介

A CLI tool for generating Drupal VM configuration files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
