# opdavies/sculpin-table-of-contents-bundle

> 标签: sculpin, sculpin-bundle, table-of-contents, twig

## 简介

A Sculpin bundle that provides a Twig filter for extracting a nested table of contents from rendered heading content.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
