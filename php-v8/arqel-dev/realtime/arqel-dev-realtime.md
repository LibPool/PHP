# arqel-dev/realtime

> 标签: Broadcasting, WebSockets, arqel, laravel, realtime, reverb

## 简介

Realtime broadcasting integration for Arqel — Reverb-friendly events for Resource updates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
