# msschl/monolog-seq-handler

> 标签: handler, monolog, seq, structured logging

## 简介

msschl/monolog-seq-handler sends log records to a Seq-Server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
