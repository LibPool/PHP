# saiashirwadinformatia/sendsms

> 标签: bulk, free for student package, send, sms

## 简介

Send SMS using Sai Ashirwad Bulk SMS Service

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
