# mattbailey/widget_blogcategories

> 标签: blog, categories, silverstripe, widget

## 简介

A SilverStripe widget that outputs a list of your blog categories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
