# tyloo/setting

> 标签: config, laravel

## 简介

Persistent configuration settings for Laravel - Create, Read, Update and Delete settings stored in files using JSON

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
