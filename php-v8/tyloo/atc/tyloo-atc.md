# tyloo/atc

> 标签: api, json-schema, phpunit, symfony, testing

## 简介

Fluent API testing for Symfony with JSON Schema validation, container mocking, and in-memory infrastructure swaps.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
