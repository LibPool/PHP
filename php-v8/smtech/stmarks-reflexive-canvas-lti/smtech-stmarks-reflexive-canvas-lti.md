# smtech/stmarks-reflexive-canvas-lti

> 标签: PHP

## 简介

A toolbox for managing LTI authentication and tool provider development (with St. Mark's templating)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
