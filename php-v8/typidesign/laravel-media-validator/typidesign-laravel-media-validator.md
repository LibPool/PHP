# typidesign/laravel-media-validator

> 标签: audio, codec, laravel, media, typidesign, validation, validator, video

## 简介

A Laravel validator for audio and video files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
