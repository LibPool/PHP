# shirokovnv/laravel-query-api-backend

> 标签: LaravelQueryApiBackend, laravel

## 简介

Unified API for running queries with eloquent models from any http client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
