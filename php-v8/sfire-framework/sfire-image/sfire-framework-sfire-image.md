# sfire-framework/sfire-image

> 标签: colors, crop, filter, flip, framework, images, resize, sFire

## 简介

Apply filters, crop, resize, flip and determine colors in images.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
