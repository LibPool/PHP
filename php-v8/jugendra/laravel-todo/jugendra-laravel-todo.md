# jugendra/laravel-todo

> 标签: create-todo-list-in-laravel, laravel, todo

## 简介

Here you can create a todo list of your tasks. And you can close and delete tasks from the list

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
