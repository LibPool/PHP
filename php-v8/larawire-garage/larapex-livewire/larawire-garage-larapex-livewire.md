# larawire-garage/larapex-livewire

> 标签: PHP

## 简介

Laravel wrapper for ApexCharts javascript plugin advanced features with livewire

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
