# rcrowe/phing-hipchat

> 标签: chat, hipchat, message, notification, phing

## 简介

Send messages to a Hipchat room from your Phing build file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
