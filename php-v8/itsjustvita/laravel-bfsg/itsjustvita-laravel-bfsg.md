# itsjustvita/laravel-bfsg

> 标签: a11y, accessibility, barrierefreiheit, bfsg, european-accessibility-act, laravel, mcp, wcag

## 简介

BFSG and WCAG 2.1 accessibility checks for Laravel: a CI-ready check command, middleware, reports, English and German messages, and an MCP server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
