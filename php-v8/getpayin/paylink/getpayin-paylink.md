# getpayin/paylink

> 标签: checkout, cybersource, getpayin, paylink, payment-gateway, payments, webhooks

## 简介

Official server-side PHP SDK for the PayLink payment integration API (checkouts, payment operations, card tokens, recurring mandates, webhook verification).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
