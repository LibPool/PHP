# patrickkunka/mixitup

> 标签: animate, filtering, javascript, sorting

## 简介

A high-performance, dependency-free library for animated filtering, sorting and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
