# adamthehutt/eloquent-constructed-event

> 标签: PHP

## 简介

Eloquent model trait to add a 'constructed' event, which will fire immediately after object construction

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
