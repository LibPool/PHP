# happenv-com/filament-passkeys

> 标签: 2fa, Authentication, FIDO2, MFA, filament, filament-passkeys, filament-plugin, filamentphp, happenv, laravel, multi-factor, passkey, passkeys, two-factor, webauthn

## 简介

Filament 5 multi-factor authentication via WebAuthn passkeys, powered by laravel/passkeys.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
