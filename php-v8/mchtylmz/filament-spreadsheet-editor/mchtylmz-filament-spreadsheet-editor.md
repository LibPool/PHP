# mchtylmz/filament-spreadsheet-editor

> 标签: filament, laravel, livewire, spreadsheet, tabulator

## 简介

A Filament v5 plugin that provides an Excel-like spreadsheet editor for Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
