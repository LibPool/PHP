# czonetech/ajaxified-catalog

> 标签: ajax layered navigation, layered navigation, magento 2, magento2 ajax, magento2 ajax catalog, magento2 layered navigation

## 简介

Implements AJAX loading in layered navigation and product list sections.

按 require.php 推断最低支持 PHP 0；已收录于 php-v5, php-v7, php-v8。
