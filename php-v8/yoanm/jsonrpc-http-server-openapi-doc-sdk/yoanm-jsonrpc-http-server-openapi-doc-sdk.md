# yoanm/jsonrpc-http-server-openapi-doc-sdk

> 标签: PHP

## 简介

SDK to generate Http JSON-RPC server documentation for OpenAPI v3.0.0

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
