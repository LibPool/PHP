# ryanbeiden/artifactsmmo-php

> 标签: API-Client, artifacts-mmo, openapi, php, sdk

## 简介

A type-safe PHP SDK for the Artifacts MMO game API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
