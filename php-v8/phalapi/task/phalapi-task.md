# phalapi/task

> 标签: phalapi, phalapi-task, task

## 简介

PhalApi 2.x 扩展类库 - Task计划任务，以接口服务形式实现的新型计划任务。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/phalapi/task.git
- Packagist 页面：https://packagist.org/packages/phalapi%2Ftask
