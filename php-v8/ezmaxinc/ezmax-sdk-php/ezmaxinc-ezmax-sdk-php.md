# ezmaxinc/ezmax-sdk-php

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

This API expose all the functionnalities for the eZmax and eZsign applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
