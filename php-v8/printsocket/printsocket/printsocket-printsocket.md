# printsocket/printsocket

> 标签: Cloud Print, api, escpos, print, printer, printing, printsocket, sdk, zpl

## 简介

PHP client for the PrintSocket cloud print API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
