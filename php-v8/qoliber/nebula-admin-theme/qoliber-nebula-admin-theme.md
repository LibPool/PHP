# qoliber/nebula-admin-theme

> 标签: PHP

## 简介

Nebula admin theme and modules for Magento 2 / Mage-OS. Targets Magento 2.4.7+ (or Mage-OS 2.0+) on PHP 8.1+.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
