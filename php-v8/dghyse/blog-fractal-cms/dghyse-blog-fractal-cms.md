# dghyse/blog-fractal-cms

> 标签: blog, fractal-cms, fractalcms

## 简介

Projet squelette Blog basé sur FractalCMS – prêt à l'emploi pour démarrer rapidement.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
