# unzerdev/magento2

> 标签: magento, magento2, payment, payment-gateway, php

## 简介

This extension for Magento 2 provides a direct integration of the Unzer payment types to your Magento 2 shop via the Unzer Payment API (PAPI).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
