# mahdi-morovati/mongodb-passport

> 标签: laravel, mongodb, oauth, passport

## 简介

A package to allow laravel/passport use with jenssegers/laravel-mongodb

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
