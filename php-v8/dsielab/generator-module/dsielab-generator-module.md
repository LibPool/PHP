# dsielab/generator-module

> 标签: PHP

## 简介

An extension based on infyom/laravel-generator and nwidart/laravel-modules to create a complete laravel modular application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
