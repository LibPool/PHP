# octacrafts/oc-qr

> 标签: barcode, iso-18004, png, qr, qr-code, qrcode, svg

## 简介

Framework-agnostic QR Code generation library for PHP (ISO/IEC 18004)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
