# ngandu-dev/lugha

> 标签: ai, chatbot, embeddings, generative, llm, nlp, openai, rag

## 简介

Lugha is a PHP Generative AI framework to build chatbot, RAG systems and AI-powered applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
