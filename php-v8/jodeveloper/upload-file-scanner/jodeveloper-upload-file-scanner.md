# jodeveloper/upload-file-scanner

> 标签: clamav, file-scanner, jodeveloper, laravel, virus-scanner

## 简介

A Laravel package for scanning uploaded files using ClamAV

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
