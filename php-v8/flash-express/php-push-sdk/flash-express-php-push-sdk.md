# flash-express/php-push-sdk

> 标签: flash-express, json-rpc, notification, push, rocketMq

## 简介

FlashExpress Push Message SDK - 支持多场景 push 消息发送、站内信、设备 token 获取，通过 JSON-RPC 调用 ard-api / by_rpc

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
