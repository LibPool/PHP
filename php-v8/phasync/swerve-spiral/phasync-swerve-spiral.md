# phasync/swerve-spiral

> 标签: application server, long-running, phasync, psr-15, spiral, swerve, websocket

## 简介

Run Spiral applications on swerve: booted once per worker, WebSockets and Server-Sent Events, no rewrite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
