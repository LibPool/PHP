# phasync/ext-phasync

> 标签: async, coroutine, epoll, extension, fiber, phasync

## 简介

PHP extension that makes blocking I/O (PDO, mysqli, curl, streams, sleep) wait cooperatively inside phasync coroutines, with an epoll Poller and per-coroutine requests (sapi()).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
