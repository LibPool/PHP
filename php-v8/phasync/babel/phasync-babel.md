# phasync/babel

> 标签: phasync, php, source rewriting, token_get_all, transpiler

## 简介

Source rewriting tool that redirects function calls and class names to alternative implementations, based on token_get_all()

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
