# phasync/plug

> 标签: PHP

## 简介

Translate whole PHP applications with phasync/babel so their blocking calls go to phasync/hooked's cooperative replacements: what ext-phasync does (sapi(), non-blocking I/O), done in userspace

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
