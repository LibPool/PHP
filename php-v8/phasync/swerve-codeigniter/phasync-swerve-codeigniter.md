# phasync/swerve-codeigniter

> 标签: application server, codeigniter, codeigniter4, long-running, phasync, psr-15, swerve, websocket

## 简介

Run CodeIgniter 4 applications on swerve: booted once per worker, WebSockets and Server-Sent Events, no rewrite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
