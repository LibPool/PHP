# phasync/doctor

> 标签: Fibers, linter, phasync, static analysis, swerve

## 简介

Static scanner that reports process-global state patterns which misbehave when several requests overlap in one PHP worker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
