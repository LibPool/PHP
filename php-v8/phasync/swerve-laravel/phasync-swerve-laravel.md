# phasync/swerve-laravel

> 标签: application server, laravel, long-running, phasync, swerve, websocket

## 简介

Run Laravel applications on swerve: a fresh application per request, WebSockets and Server-Sent Events, no rewrite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
