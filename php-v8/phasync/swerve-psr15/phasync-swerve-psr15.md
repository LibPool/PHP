# phasync/swerve-psr15

> 标签: application server, long-running, mezzio, phasync, psr-15, psr-7, slim, swerve

## 简介

Run any PSR-15 request handler on swerve: Slim, Mezzio or your own, booted once per worker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
