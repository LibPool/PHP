# phasync/swerve-laminas

> 标签: application server, laminas, laminas-mvc, long-running, phasync, psr-15, swerve, websocket, zend-framework

## 简介

Run Laminas MVC applications on swerve: streamed responses, WebSockets and Server-Sent Events, no rewrite.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
