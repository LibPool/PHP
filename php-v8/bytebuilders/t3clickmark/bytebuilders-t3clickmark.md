# bytebuilders/t3clickmark

> 标签: PHP

## 简介

Visual website feedback for TYPO3 agencies. Content element recognition, backend edit links, screenshot capture, and annotation tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
