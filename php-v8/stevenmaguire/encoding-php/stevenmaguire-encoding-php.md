# stevenmaguire/encoding-php

> 标签: api, endcoding, endcoding.com, oauth1, php, video

## 简介

A php client for consuming the Encoding.com API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
