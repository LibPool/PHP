# ressourcenmangel/rsmbouncemailprocessor

> 标签: cute_mailing, email, newsletter, typo3

## 简介

A TYPO3 extension that handles bounce mails in combination with cute_mailing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
