# juniyasyos/table-repeater

> 标签: awcodes, filament, juniyasyos, laravel, plugin, table repeater

## 简介

A custom table repeater plugin for Filament Forms v4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
