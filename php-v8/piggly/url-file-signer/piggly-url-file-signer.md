# piggly/url-file-signer

> 标签: encryption, piggly, security, sign, url

## 简介

Generate a URL with unique parameters and a signature to prevent invalid accesses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
