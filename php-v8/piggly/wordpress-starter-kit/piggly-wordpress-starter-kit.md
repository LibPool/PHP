# piggly/wordpress-starter-kit

> 标签: plugins, plugins development, wordpress, wordpress development

## 简介

A smart Wordpress Starter Kit to plugins development.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
