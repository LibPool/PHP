# markdown-office/commonmark-generic-directives

> 标签: attributes, commonmark, container-directive, directive, extension, leaf-directive, markdown, text-directive

## 简介

A standalone league/commonmark extension implementing the Generic Directives RFC: container (:::), leaf (::) and text (:) directives with attribute, #id and .class syntax.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
