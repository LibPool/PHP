# markdown-office/markdown-presentation

> 标签: PowerPoint, deck, frontmatter, markdown, pptx, slides, slidev, theme, yaml

## 简介

The PowerPoint half of markdown-office: a Slidev-compatible deck splitter and a strict theme resolver for Markdown slide decks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
