# markdown-office/markdown-word

> 标签: PhpWord, commonmark, converter, docx, gfm, markdown, pandoc, template, word

## 简介

Pure PHP Markdown to Word (DOCX) generator and back, built on PHPWord. Full CommonMark and GitHub-Flavored Markdown support, configurable styling, Word template rendering, and a table of contents, footnotes and a document's own header and footer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
