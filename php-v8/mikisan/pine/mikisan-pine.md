# mikisan/pine

> 标签: framework, pine

## 简介

Pine Framework is MVC2 framework with extended striking codes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/feijoa-pine/PineFramework.git
