# stadiamaps/api

> 标签: Stadiamaps, api, geocoding, geospatial, rest, routing, sdk

## 简介

The Stadia Maps Geospatial APIs provide you with the data you need to build awesome applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
