# samjuk/m2-module-tinymce-anchors

> 标签: PHP

## 简介

Introduce the Anchor plugin into the TinyMCE editor to allow for easy linking to text content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
