# omnipay/sagepay

> 标签: gateway, merchant, omnipay, pay, payment, purchase, sage pay, sagepay

## 简介

Sage Pay driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
