# se7enxweb/ggsysinfo

> 标签: Opcache, admin, cache, exponential, exponential-extension, ezpublish-legacy, logs, monitoring, phpinfo, system information

## 简介

System information for Exponential administrators and developers: PHP and opcode cache panels, cache, storage, log and content statistics, system status checks with JSON output, QA checks and developer listings of modules, views, fetch functions, policies and template operators.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
