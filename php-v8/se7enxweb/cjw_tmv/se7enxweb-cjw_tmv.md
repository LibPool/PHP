# se7enxweb/cjw_tmv

> 标签: Exponential 6, TMV, events, exponential, feed, legacy extension

## 简介

CJW TMV event feed: the events of the Tourismusverband Mecklenburg-Vorpommern event database for Exponential, imported as content objects and drawn in lists, filters and Layouts blocks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
