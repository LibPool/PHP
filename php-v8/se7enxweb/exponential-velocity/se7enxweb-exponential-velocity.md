# se7enxweb/exponential-velocity

> 标签: http, php, server, static, webserver, websocket

## 简介

Pure-PHP Web Server. No NGinX or PHP-FPM needed. Handle 10x more traffic instead!

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
