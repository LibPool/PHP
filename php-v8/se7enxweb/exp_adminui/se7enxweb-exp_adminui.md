# se7enxweb/exp_adminui

> 标签: Exponential 6, Netgen Admin UI, admin ui, administration, design, exponential, legacy extension, siteaccess

## 简介

Exponential Admin UI: the Admin UI look and layout (ported from Netgen Admin UI) for the Exponential administration, served by its own adminui siteaccess on top of the admin4l design

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
