# se7enxweb/expai

> 标签: Exponential 6, ai, anthropic, claude, drafts, exponential, legacy extension, writing assistant

## 简介

Exponential Intelligence: a provider-neutral AI writing assistant for the Exponential 6 administration interface that writes drafts as the editor and never publishes on its own

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
