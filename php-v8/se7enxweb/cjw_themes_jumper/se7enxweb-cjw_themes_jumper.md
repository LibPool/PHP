# se7enxweb/cjw_themes_jumper

> 标签: Exponential 6, design, exponential, legacy extension, siteaccess, starter, theme

## 简介

CJW Themes Jumper: the design starter for Exponential, served by the starter siteaccesses (port of the Nexus v2 starter look)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
