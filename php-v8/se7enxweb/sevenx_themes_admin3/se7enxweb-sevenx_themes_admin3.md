# se7enxweb/sevenx_themes_admin3

> 标签: admin, design, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, ezpublish-compatible

## 简介

eZ Publish extension which provides for a brand new default administration via admin3 design for any ezpublish compatible installations via a separate extension providing the design. Great for all eZ Publish based websites. Great for smart developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
