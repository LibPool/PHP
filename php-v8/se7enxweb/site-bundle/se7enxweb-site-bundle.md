# se7enxweb/site-bundle

> 标签: ibexa, netgen, site-bundle

## 简介

7x Netgen Site Bundle is an Ibexa 5.x / Symfony 7 bundle that implements common features that are used to implement websites

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
