# se7enxweb/owtranslate

> 标签: admin, exponential, extension, i18n, localization, translation, translation.ts

## 简介

Exponential extension that collects the i18n strings of your extensions' templates and PHP files into translation.ts files for every site language, and lets you translate them in the admin with inline editing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
