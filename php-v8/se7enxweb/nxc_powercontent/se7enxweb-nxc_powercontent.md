# se7enxweb/nxc_powercontent

> 标签: content, create, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, module, power, remove, solution, update

## 简介

NXC Power Content is a simple eZ Publish Platform (Legacy) class and module extension which provides advanced features for dynamic content creation, update and removal. Useful in a rest api and general content manipulation extensions. Great for advanced developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
