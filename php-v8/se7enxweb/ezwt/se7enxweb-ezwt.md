# se7enxweb/ezwt

> 标签: PHP

## 简介

eZ Publish Legacy website toolbar extension. Great for editing small to medium sized website content by untrained end users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
