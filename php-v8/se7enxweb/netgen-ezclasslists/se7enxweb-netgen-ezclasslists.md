# se7enxweb/netgen-ezclasslists

> 标签: admin, bulk delete, content class, exponential, exponential-legacy, extension, ezpublish-legacy, list

## 简介

Lists by class for Exponential: an administration tab that lists objects by content class, filtered by subtree, dates and owner, and lets you quickly edit or delete them.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
