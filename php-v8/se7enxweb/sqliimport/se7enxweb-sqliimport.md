# se7enxweb/sqliimport

> 标签: content import, cronjob, csv, exponential, exponential-legacy, import, legacy-extension, migration, rss, xml

## 简介

SQLI Import for Exponential: a framework and admin interface to import external content (XML, CSV, RSS, any source) into Exponential through import handlers, run immediately or on a schedule by a cronjob.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
