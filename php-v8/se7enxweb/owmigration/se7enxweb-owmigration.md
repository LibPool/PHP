# se7enxweb/owmigration

> 标签: Exponential 6, content classes, deployment, exponential, legacy extension, migrations, object states, roles, workflows

## 简介

OWMigration for Exponential: versioned up and down migrations for content classes, roles, workflows and object states, run from the command line, with an admin tab that generates the migration code from the existing definitions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
