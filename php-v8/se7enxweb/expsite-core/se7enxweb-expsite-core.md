# se7enxweb/expsite-core

> 标签: PHP

## 简介

Site helper classes (breadcrumb path, redirect, mail) for Exponential CMS. Ported from netgen/site-bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
