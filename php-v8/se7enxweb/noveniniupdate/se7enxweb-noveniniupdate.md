# se7enxweb/noveniniupdate

> 标签: cluster, configuration, deployment, environment, exponential, exponential-legacy, extension, ezpublish-legacy, ini

## 简介

Noven INI Update for Exponential: switch INI settings, config.php constants and the cluster configuration between environments (local, dev, preprod, prod) from one XML file, in the administration or on the command line, with a diff and backups.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
