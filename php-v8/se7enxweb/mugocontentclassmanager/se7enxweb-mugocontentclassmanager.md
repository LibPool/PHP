# se7enxweb/mugocontentclassmanager

> 标签: admin, content class, content objects, exponential, exponential-legacy, extension, ezpublish-legacy

## 简介

Mugo Content Class Manager for Exponential: an administration tab that lists every content class with its number of objects and pages through the objects of each class.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
