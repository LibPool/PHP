# se7enxweb/sevenx_themes_simple

> 标签: design, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, ezpaypal-compatible, webshop

## 简介

Exponential extension which provides for a brand new default design for any ezwebin, ezflow or ezdemo website. Great for all ecommerce websites. Great for smart developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
