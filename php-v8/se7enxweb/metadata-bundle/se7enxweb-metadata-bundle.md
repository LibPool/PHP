# se7enxweb/metadata-bundle

> 标签: PHP

## 简介

Metadata bundle for Ibexa 5.x / Exponential Platform. Based on xrowmetadata extension for eZ Publish Legacy.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
