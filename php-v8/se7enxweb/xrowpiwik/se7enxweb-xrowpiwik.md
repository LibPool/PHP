# se7enxweb/xrowpiwik

> 标签: analytics, clickheat, exponential, exponential-extension, ezpublish-legacy, matomo, piwik, privacy, statistics, web-analytics

## 简介

Piwik (Matomo) web analytics for Exponential: a tracking script delivered through ezjscore, an optional ClickHeat click tracker and an admin tab that shows your Piwik dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
