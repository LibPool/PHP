# se7enxweb/ezpaypal

> 标签: Redirect Gateway, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, payment gateway, paypal

## 简介

eZ Publish extension which provides for real time payment processing for ecommerce websites. Great for smart developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
