# se7enxweb/ezcontentstaging

> 标签: PHP

## 简介

eZ Content Staging provides content synchronization from one eZ Publish installations to another via REST configured on both instalations of eZ Publish. Great for smarter developers!.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
