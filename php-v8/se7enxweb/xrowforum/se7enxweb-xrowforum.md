# se7enxweb/xrowforum

> 标签: bbcode, community, exponential, exponential-extension, ezpublish-legacy, forum, moderation, private-messages

## 简介

Forum and private messaging for Exponential: unread flags, moderators per forum, user ranks, BB code editor, smilies, censoring, forum statistics and an admin tab to configure it all.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
