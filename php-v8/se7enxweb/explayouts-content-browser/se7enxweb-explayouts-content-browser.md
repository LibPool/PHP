# se7enxweb/explayouts-content-browser

> 标签: PHP

## 简介

Content browser backend for selecting content items in Exponential Layouts on Exponential Legacy / Exponential 6.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
