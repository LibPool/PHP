# se7enxweb/xrowadmin

> 标签: admin, administration, developer-tools, exponential, exponential-extension, ezpublish-legacy, maintenance, switch-user, system-check

## 简介

Administrator and developer tools for Exponential: switch to another user, run SQL, test mail and SOAP, check the system and Solr, move and swap nodes, plus maintenance scripts and cronjob parts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
