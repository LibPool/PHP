# se7enxweb/exponential-platform-dxp-core

> 标签: PHP

## 简介

7x Exponential Platform DXP (Stable; Open Source) core. Provides the Content Repository, its APIs, and the application's Symfony framework integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
