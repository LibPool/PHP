# se7enxweb/ocdropbox

> 标签: cronjob, dropbox, exponential, extension, import, prototype

## 简介

Exponential extension, an unfinished prototype of a Dropbox folder importer: a cronjob that creates folders and files from a Dropbox folder in the content tree, and an admin tab to connect a Dropbox account.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
