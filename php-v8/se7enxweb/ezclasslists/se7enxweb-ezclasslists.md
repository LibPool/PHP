# se7enxweb/ezclasslists

> 标签: admin, content class, exponential, exponential-extension, ezpublish-legacy, list

## 简介

Adds a "Lists by class" tab to the Exponential administration interface that lists content objects by content class, sorted and paged, so they can be viewed, edited or removed quickly.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
