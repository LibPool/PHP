# se7enxweb/ezupdate

> 标签: composer, composer package updates, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, kernel updater, manager, module, update, vcs, view

## 简介

eZ Update offers composer package(s) updates - Use this feature to update your website to the latest available release via composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
