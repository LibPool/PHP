# se7enxweb/sevenx_hacker-news-delta

> 标签: design, eZ Publish Legacy, eZ Publish Platform, exponential, exponential-compatible, extension, ez publish, news, social media

## 简介

eZ Publish extension which provides for a brand new design called 7x Hacker News Delta for any sevenx_themes_simple based website. Great for all news social media websites. Great for smart developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
