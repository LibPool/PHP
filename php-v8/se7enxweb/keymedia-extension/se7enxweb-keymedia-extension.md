# se7enxweb/keymedia-extension

> 标签: Brightcove, DAM, datatype, exponential, exponential-legacy, extension, ezpublish-legacy, image, keymedia, media, video

## 简介

KeyMedia for Exponential: a datatype, an Online Editor custom tag and an admin tab that connect content to the KeyMedia media service, with search, upload, tags and named crops of images and video.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
