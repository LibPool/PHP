# se7enxweb/adminaid

> 标签: Exponential 6, administration, class translation, database search, debugging, exponential, legacy extension, user switch

## 简介

AdminAid for Exponential: an admin tab with a database search by ID or text, detailed content object views, lists of all objects of a class, class translation in every language on one page, and switching to another user without a password for debugging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
