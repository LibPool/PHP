# t3/fluid

> 标签: PHP

## 简介

Just a meta package for TYPO3's Fluid template engine, with easy to remember package name.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/TYPO3/Fluid
- 源码仓库：https://bitbucket.org/t--3/fluid.git
- Packagist 页面：https://packagist.org/packages/t3%2Ffluid
