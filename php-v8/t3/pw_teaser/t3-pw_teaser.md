# t3/pw_teaser

> 标签: PHP

## 简介

Create powerful, dynamic page teasers with data from page properties and its content elements. Based on Extbase and Fluid Template Engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
