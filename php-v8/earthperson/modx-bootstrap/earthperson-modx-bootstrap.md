# earthperson/modx-bootstrap

> 标签: bootstrap, modx

## 简介

Extra for MODX Revo for starting with Twitter Bootstrap - open source front-end framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
