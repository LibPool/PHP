# lucasdcrk/xsolla-sdk-php

> 标签: api, games, payment, sdk, xsolla

## 简介

Fork of Xsolla SDK for PHP (support latest PHP versions). Xsolla is the authorized reseller and merchant providing e-commerce services for online games.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
