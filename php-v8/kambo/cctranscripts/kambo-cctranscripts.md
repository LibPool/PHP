# kambo/cctranscripts

> 标签: anthropic, claude, claude-code, converter, html, transcripts

## 简介

Convert Claude Code session files to HTML transcripts (PHP port)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
