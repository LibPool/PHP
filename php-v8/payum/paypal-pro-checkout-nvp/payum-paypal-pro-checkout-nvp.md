# payum/paypal-pro-checkout-nvp

> 标签: payment, paypal, pro checkout

## 简介

The Payum extension. It provides Paypal ProCheckout payment integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
