# payum/payum-yii-extension

> 标签: authorize.net, be2bill, instant notification, offline, omnipay, payex, payment, paypal, paypal express checkout, paypal pro checkout, recurring payment, stripe

## 简介

Rich payment solutions for Yii framework. Paypal, payex, authorize.net, be2bill, omnipay, recurring paymens, instant notifications and many more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
