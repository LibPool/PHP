# romainmillan/mobile-navigation-bundle

> 标签: ios, mobile, navigation, pwa, stimulus, symfony, symfony-bundle, symfony-ux, twig-component

## 简介

iOS 26 "liquid glass" mobile navigation for Symfony: tab bar, sheets, large title, grouped lists with swipe actions, as Twig components and Stimulus controllers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
