# romainmillan/web-push-notification

> 标签: laravel, push-notifications, pwa, service-worker, symfony, symfony-bundle, vapid, web-push

## 简介

Web Push notifications for Symfony and Laravel: subscription storage, VAPID delivery, SSRF-hardened transport and a ready-to-use service worker.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
