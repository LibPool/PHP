# spark-php/skeleton

> 标签: Skeleton, framework, mvc, php, spark

## 简介

The Spark application skeleton — start a new project with composer create-project spark-php/skeleton my-app

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
