# nette/code-checker

> 标签: code checker, code quality, latte, lint, linter, neon, nette

## 简介

✅ Nette Code Checker: finds and fixes formal errors in PHP, Latte, NEON, JSON and YAML files, such as encoding, line endings, indentation and trailing whitespace.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
