# nette/php-generator

> 标签: PHP, code, nette, php, scaffolding, 代码生成

## 简介

🐘 Nette PHP Generator: generates neat PHP code for you. Supports new PHP 8.5 features.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
