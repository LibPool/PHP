# nette/neon

> 标签: config, configuration, data format, neon, nette, parser, yaml

## 简介

🍸 Nette NEON: a human-friendly data format, simpler than YAML and with entities for objects. Comes with a fast encoder and decoder.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
