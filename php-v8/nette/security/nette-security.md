# nette/security

> 标签: Authentication, acl, authorization, login, nette, password hashing, permissions, rbac, roles, security

## 简介

🔑 Nette Security: authentication and authorization. Login and user identity, roles, ACL with resources and assertions, and safe password hashing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
