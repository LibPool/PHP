# nette/nette

> 标签: framework, metapackage, mvc

## 简介

👪 Nette Framework - innovative framework for fast and easy development of secured web applications in PHP (metapackage)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
