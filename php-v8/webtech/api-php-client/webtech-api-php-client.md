# webtech/api-php-client

> 标签: php, rest client, webtech

## 简介

Um simples cliente PHP que proporciona acesso fácil aos endpoints do Code Chat BR.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
