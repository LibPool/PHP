# ladmin/engine

> 标签: Admin scaffolding, admin page, ladmin, laravel, laravel admin

## 简介

Ladmin Engine is an package to support Laravel Admin scaffolding.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
