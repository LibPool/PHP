# fastpress/framework

> 标签: fastpress, framework, micro-framework, mvc, php

## 简介

A lightweight PHP micro-framework for building web applications with MVC, dependency injection, and middleware.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
