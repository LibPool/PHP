# datomatic/laravel-enum-collections

> 标签: Datomatic, laravel, laravel-enum-collections

## 简介

A package to save a collection of Enums in a Eloquent field and interact with him

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
