# strarsis/sage9-onepager-lib

> 标签: PHP

## 简介

Single page support for Sage 9 based themes. – Helper library (Adopted from WordPress Twenty Seventeen theme.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
