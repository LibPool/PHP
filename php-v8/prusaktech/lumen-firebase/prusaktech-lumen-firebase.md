# prusaktech/lumen-firebase

> 标签: FCM, firebase, gcm, lumen

## 简介

A Lumen package for the Firebase PHP Admin SDK based off Kreait Firebase

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
