# dhtpublic/dht_ai_support

> 标签: ai, drupal, mcp, support

## 简介

AI-powered Support Bot for Drupal — reads code, queries DB, answers questions via D-HT MCP-Server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
