# paxha/lararole

> 标签: Role Management, User management, lararole, laravel, laravel library, laravel role management, laravel user management

## 简介

Lararole is a Laravel library, provides Role Management with permissions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
