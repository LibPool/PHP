# webpatser/fledge-pulse-elasticsearch

> 标签: elasticsearch, fledge, laravel, pulse

## 简介

Elasticsearch storage driver for Fledge Pulse: entries in a data stream with ILM retention, fiber-async reads and bulk writes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
