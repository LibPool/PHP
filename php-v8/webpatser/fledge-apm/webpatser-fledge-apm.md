# webpatser/fledge-apm

> 标签: Fibers, apm, fledge, laravel, opentelemetry, otlp, tracing

## 简介

Fiber-aware OpenTelemetry tracing for the Fledge framework, exported as OTLP to Elastic APM or any OTel backend.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
