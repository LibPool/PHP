# webpatser/fledge-pulse

> 标签: fledge, laravel, pulse

## 简介

Fiber-native fork of Laravel Pulse for the Fledge framework: a real-time application performance monitoring tool and dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
