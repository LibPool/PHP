# webpatser/torque

> 标签: Coroutines, Fibers, async, fledge, laravel, queue, redis-streams

## 简介

Coroutine-based queue worker for Laravel — N jobs per process via PHP Fibers and Redis Streams

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
