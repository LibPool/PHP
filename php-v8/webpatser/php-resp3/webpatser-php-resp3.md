# webpatser/php-resp3

> 标签: PHP

## 简介

PECL extension that parses RESP3 wire-protocol bytes into PHP values, plus PHP adapters for amphp/redis and Fledge.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
