# webpatser/resonate

> 标签: Broadcasting, Fibers, WebSockets, fledge, laravel, pusher, reverb

## 简介

Fiber-based WebSocket server: a drop-in replacement for Laravel Reverb, built on fledge-fiber

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
