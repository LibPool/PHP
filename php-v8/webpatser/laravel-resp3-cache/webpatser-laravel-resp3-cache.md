# webpatser/laravel-resp3-cache

> 标签: cache, laravel, php-resp3, redis, resp3, valkey

## 简介

Synchronous Redis client and Laravel cache driver backed by the ext-resp3 C parser.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
