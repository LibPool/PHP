# webpatser/qr-code

> 标签: barcode, calendar, generator, png, qr, qr-code, svg, vCard, wifi

## 简介

Modern QR Code Generator for PHP - Support for multiple output formats and QR code types

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
