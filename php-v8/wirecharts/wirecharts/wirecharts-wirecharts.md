# wirecharts/wirecharts

> 标签: blade, charts, flux, laravel, livewire

## 简介

Flux-style chart components for Laravel Livewire 4. 30+ chart types in one elegant package.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
