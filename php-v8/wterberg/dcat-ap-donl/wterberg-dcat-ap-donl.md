# wterberg/dcat-ap-donl

> 标签: PHP

## 简介

Allows for creation and validation of datasets conforming to the DCAT-AP-DONL 1.1 metadata standard

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
