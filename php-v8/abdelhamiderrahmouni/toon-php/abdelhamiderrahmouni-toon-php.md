# abdelhamiderrahmouni/toon-php

> 标签: PHP

## 简介

Token-Oriented Object Notation – Associative arrays and JSON for LLMs at half the token cost. it is a PHP port of johannschopplich/toon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
