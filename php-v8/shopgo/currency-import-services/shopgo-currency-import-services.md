# shopgo/currency-import-services

> 标签: PHP

## 简介

A module that adds Yahoo! Finance and Google Finance currency rate import services to Magento 2.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
