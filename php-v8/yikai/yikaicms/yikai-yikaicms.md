# yikai/yikaicms

> 标签: cms, content-management, enterprise, lightweight, php

## 简介

A lightweight enterprise CMS built with PHP 8.0+, no framework dependency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
