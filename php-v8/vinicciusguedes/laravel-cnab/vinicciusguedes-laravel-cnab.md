# vinicciusguedes/laravel-cnab

> 标签: boleto, cnab, cnab240, cnab400, laravel-cnab, remessa, vinicciusguedes

## 简介

Biblioteca para gerar boletos, remessas e leitura de retorno em laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
