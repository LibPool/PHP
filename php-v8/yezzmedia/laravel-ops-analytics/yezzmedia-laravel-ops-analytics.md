# yezzmedia/laravel-ops-analytics

> 标签: PHP

## 简介

Ops-facing analytics delivery posture, tracker health, and consent-aware dispatch package for the Yezz Media Laravel platform.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
