# tencent/tls-sig-api-v2

> 标签: im, tencent, trtc

## 简介

tls-sig-api-v2 适用于腾讯云通信生成用户账号签名。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
