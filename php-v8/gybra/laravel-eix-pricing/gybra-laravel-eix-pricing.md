# gybra/laravel-eix-pricing

> 标签: eix, laravel, market-data, quotes

## 简介

Ingest EIX pre-trade data and expose the latest persisted quote by ISIN in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
