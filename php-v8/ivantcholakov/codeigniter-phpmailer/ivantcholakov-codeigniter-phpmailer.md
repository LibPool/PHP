# ivantcholakov/codeigniter-phpmailer

> 标签: codeigniter, php, phpmailer

## 简介

A CodeIgniter 3 compatible email-library powered by PHPMailer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
