# mente/max-mind-geo-ip-bundle

> 标签: geoip, maxmind, symfony

## 简介

Bundle integrating MaxMind GeoIP database into symfony application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
