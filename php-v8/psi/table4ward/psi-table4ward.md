# psi/table4ward

> 标签: contao, table, tinymce

## 简介

Provides a TinyMCE editor for each cell of the table content-element. Just doubleclick a cell to open the rich-text-editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
