# microgears/webstone-pdo

> 标签: microGears, webstone-pdo

## 简介

Wrapper around PDO that defines a simple and consistent interface for accessing databases in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
