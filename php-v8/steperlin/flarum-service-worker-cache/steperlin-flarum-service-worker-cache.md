# steperlin/flarum-service-worker-cache

> 标签: cache, extension, flarum, performance, pwa, service-worker

## 简介

Flarum扩展：通过Service Worker实现智能缓存，显著提升论坛加载速度和用户体验

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
