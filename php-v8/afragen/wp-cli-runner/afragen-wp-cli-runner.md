# afragen/wp-cli-runner

> 标签: testing, wp-cli

## 简介

Helper to test custom WP-CLI commands by bootstrapping WP-CLI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
