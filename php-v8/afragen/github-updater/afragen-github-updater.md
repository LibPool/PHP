# afragen/github-updater

> 标签: plugin, theme, updater, wordpress

## 简介

A plugin to automatically update GitHub, Bitbucket, GitLab, or Gitea hosted plugins, themes, and language packs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
