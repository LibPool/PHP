# xve/laravel-yuki-api-client

> 标签: Accounting, laravel, soap, xve, yuki

## 简介

Laravel client for the Yuki accounting SOAP webservices (Sales, VAT, AccountingInfo).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
