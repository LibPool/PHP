# sdelfi/yii2-sitemap-module

> 标签: Sitemap, module, xml, yii2

## 简介

Yii2 module for automatically generation XML Sitemap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
