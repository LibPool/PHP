# syriable/filament-menu-builder

> 标签: filament, filament-plugin, laravel, menu, menu-builder, navigation, syriable

## 简介

A lightweight, extensible menu builder for Filament with dynamic placements, drag & drop tree editing and draft/publish workflow.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
