# syriable/filament-icon-hub

> 标签: blade-icons, filament, filament-plugin, icon-picker, icons, laravel

## 简介

A lightweight, extensible icon picker and icon provider system for Filament.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
