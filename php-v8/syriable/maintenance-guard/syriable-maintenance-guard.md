# syriable/maintenance-guard

> 标签: laravel, livewire, maintenance, maintenance-mode, middleware

## 简介

Dynamic, extensible access control for Laravel's native maintenance mode.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
