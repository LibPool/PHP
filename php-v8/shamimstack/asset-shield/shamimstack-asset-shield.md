# shamimstack/asset-shield

> 标签: assets, hmac, laravel, obfuscation, security, signing, vite

## 简介

Laravel-native asset protection layer for Vite-powered applications. Opaque, signed, expiring asset URLs. Source maps off. Vendor-safe JS obfuscation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
