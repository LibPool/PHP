# friendsofcat/laravel-couchbase

> 标签: couchbase, database, eloquent, laravel, model

## 简介

A Couchbase based Eloquent model and Query builder for Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
