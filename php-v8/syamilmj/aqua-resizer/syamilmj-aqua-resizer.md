# syamilmj/aqua-resizer

> 标签: assets, image, optimization, resize, wordpress

## 简介

This small script will allow you to resize & crop WordPress images uploaded via the media uploader on the fly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
