# robbiekibler/laravel-posthog-logs

> 标签: laravel, logging, logs, observability, opentelemetry, otlp, posthog

## 简介

Send Laravel logs to PostHog using OpenTelemetry OTLP format

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
