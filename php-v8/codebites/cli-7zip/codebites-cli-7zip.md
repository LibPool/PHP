# codebites/cli-7zip

> 标签: 7z, 7zip, archive, cli, compression, decompression, wrapper, zip

## 简介

A wrapper for 7-zip CLI to compress, decompress and manipulate archives.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
