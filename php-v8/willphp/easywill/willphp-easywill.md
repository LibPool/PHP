# willphp/easywill

> 标签: aphp, framework, orm, 一鱼框架

## 简介

一鱼PHP框架 APHP Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/willphp/aphp.git
