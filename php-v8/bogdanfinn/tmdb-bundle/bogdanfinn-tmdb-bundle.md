# bogdanfinn/tmdb-bundle

> 标签: api, bundle, symfony, tmdb

## 简介

Symfony Bundle for accessing https://www.themoviedb.org API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
