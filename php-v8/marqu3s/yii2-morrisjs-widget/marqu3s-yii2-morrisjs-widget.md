# marqu3s/yii2-morrisjs-widget

> 标签: Morris.js, chart, extension, widget, yii

## 简介

Morris.js charts widget for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
