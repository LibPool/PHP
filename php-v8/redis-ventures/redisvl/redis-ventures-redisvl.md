# redis-ventures/redisvl

> 标签: PHP

## 简介

Redis Vector Library (RedisVL) enables Redis as a real-time database for LLM applications, based on Predis PHP client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
