# birdcar/authkit-laravel

> 标签: authkit-laravel, birdcar, laravel

## 简介

A "batteries included" implementation of AuthKit and the entire WorkOS Suite for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
