# silversoft/api-signer

> 标签: Ed25519, api, hmac, http-message-signatures, http-signatures, rfc9421, security

## 简介

HTTP request signing and verification per RFC 9421 (HTTP Message Signatures), with no dependencies. The Node counterpart is @silversoft/api-signer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
