# silversoft/api-client

> 标签: api, client, http, http-signatures, rfc9421

## 简介

Klient wewnętrznego API: JSON po HTTP z podpisem RFC 9421, bez zależności zewnętrznych.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
