# er.dhruvmishra/sendotp

> 标签: client, msg91, sendotp

## 简介

A PHP library to send OTP messages using MSG91 API (PHP 8.2 compatible)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
