# jamie-humm/kirby-super-structure

> 标签: kirby, kirby-cms, kirby-plugin, multilang, structure, translate

## 简介

Kirby Super Structure: a structure field with per-field translate: false support and stable row UUIDs for multi-language sites.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
