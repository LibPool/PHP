# jwn25/php-esewa

> 标签: esewa, laravel, nepali payment gateway, payment

## 简介

Package to integrate esewa with php/Laravel for Omnipay payment library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
