# mileswu/filament-quill-editor

> 标签: Miles Wu, filament-quill-editor, laravel

## 简介

A Filament v5 compatible rich text editor field powered by Quill.js

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
