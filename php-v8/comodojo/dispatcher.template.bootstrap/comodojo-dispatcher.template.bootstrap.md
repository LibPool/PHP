# comodojo/dispatcher.template.bootstrap

> 标签: bootstrap, comodojo, dispatcher, template

## 简介

A simple, bootstrap-based template for comodojo/dispatcher.framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
