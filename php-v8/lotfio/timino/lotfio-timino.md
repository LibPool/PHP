# lotfio/timino

> 标签: php, php lightweight mvc, php mvc, php simple framework, php solid, tim, timino

## 简介

Timino is a simple, lightweight and S.O.L.I.D PHP MVC framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
