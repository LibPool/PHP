# kytoonlabs/opentelemetry-auto-guzzle

> 标签: Guzzle, instrumentation, open-telemetry, opentelemetry, otel, tracing

## 简介

OpenTelemetry auto-instrumentation for Guzzle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
