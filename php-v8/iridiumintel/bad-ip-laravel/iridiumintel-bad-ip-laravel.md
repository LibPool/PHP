# iridiumintel/bad-ip-laravel

> 标签: PHP

## 简介

Laravel wrapper for bad_ip PHP SDK – automatic guards for IP, TOR, queries, bots, and login

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
