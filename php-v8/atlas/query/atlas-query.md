# atlas/query

> 标签: database, db, delete, dml, insert, mysql, pdo, pgsql, postgres, postgresql, query, select, sql, sql server, sqlite, sqlserver, update

## 简介

Object-oriented query builders and performers for MySQL, Postgres, SQLite, and SQLServer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
