# nuvalis/mzflash

> 标签: anax, anax-mvc, education, flash, message, mzFlash

## 简介

Session based flash message class. Written for Anax-MVC part of the dbwebb course.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
