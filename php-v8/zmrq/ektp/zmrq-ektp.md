# zmrq/ektp

> 标签: data, ektp, generator, identity, indonesia, ktp, nik

## 简介

PHP library to generate fake Indonesian eKTP/NIK numbers with valid format for testing and development purposes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
