# pageon/pageon-doctrine-data-grid-bundle

> 标签: PHP

## 简介

A bundle that wraps around the knp paginator bundle and doctrine to generate a data grid from your entity

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
