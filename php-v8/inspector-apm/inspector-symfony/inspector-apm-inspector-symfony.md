# inspector-apm/inspector-symfony

> 标签: bundle, error-tracking, inspector, messenger-monitoring, monitoring, php, symfony

## 简介

Code Execution Monitoring for Symfony applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
