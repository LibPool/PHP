# inspector-apm/cakephp

> 标签: apm, cakephp, error-monitoring, inspector, monitoring, profiling

## 简介

Code Execution Monitoring for CakePHP applications, powered by Inspector.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
