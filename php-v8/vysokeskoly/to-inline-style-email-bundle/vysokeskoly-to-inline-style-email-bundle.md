# vysokeskoly/to-inline-style-email-bundle

> 标签: bundle, css, email, inline, style, symfony

## 简介

A Symfony bundle for using the CssToInlineStyles translator by tijsverkoyen

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
