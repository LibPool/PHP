# ruslanmedia/php-fcm

> 标签: FCM, android, chrome, cloud, firebase, google, ios, notifications, php

## 简介

PHP API for Firebase Cloud Messaging from Google

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
