# laraviz/laraviz

> 标签: canvas, database, debug, dev-tools, laravel, routes, visualization

## 简介

Interactive canvas-based visualization of your entire Laravel application — database, routes, services, events, and flow.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
