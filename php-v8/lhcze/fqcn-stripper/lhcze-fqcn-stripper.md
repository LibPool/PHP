# lhcze/fqcn-stripper

> 标签: class, formatter, fqcn, namespace, php, string, stripper, utility

## 简介

Utility for extracting and formatting FQCN base names with string transformation support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
