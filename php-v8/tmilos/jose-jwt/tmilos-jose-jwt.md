# tmilos/jose-jwt

> 标签: JOSE, JSON Web Encryption, JWE, JWS, Javascript Object Signing and Encryption, json web tokens, jwa, jwt

## 简介

Javascript Object Signing and Encryption JOSE PHP library, supporting JSON Web Tokens JWT and JSON Web Encryption JWE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
