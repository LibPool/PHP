# martinjuul/duckdb

> 标签: analytics, database, duckdb, extension, olap, sql

## 简介

Native DuckDB driver for PHP (C extension). Synchronous, streaming and asynchronous queries, prepared statements, transactions, bulk appender, typed errors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
