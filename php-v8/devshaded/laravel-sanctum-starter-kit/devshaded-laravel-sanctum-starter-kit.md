# devshaded/laravel-sanctum-starter-kit

> 标签: api, laravel, sail, sanctum, starter-kit

## 简介

An API-only Laravel starter kit with Sanctum bearer tokens and Docker development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
