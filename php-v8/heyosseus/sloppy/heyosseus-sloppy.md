# heyosseus/sloppy

> 标签: Pint, ai, ai-agents, ci, code-quality, code-review, filament, laravel, mcp, pest, php, rector, slop, static-analysis, technical-debt

## 简介

Static analysis for the debt AI coding agents leave behind, on any PHP project: 33 rules, architecture policies and module boundaries you describe, git-diff review, coverage-aware reading order, PHPStan baseline-growth detection, a Rector and Pint fix pass, Pest expectations, CI annotations, agent rulesets, Claude Code hooks and an MCP server. Runs inside PHPStan through the separate heyosseus/phpstan-sloppy extension. Extra rules and dashboards for Laravel. Deterministic, local, no LLM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
