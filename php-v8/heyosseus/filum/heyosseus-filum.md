# heyosseus/filum

> 标签: Broadcasting, chat, filament, filament-plugin, laravel, livewire, messaging, presence, real-time, reverb

## 简介

Broadcasting-agnostic real-time chat between admin users, inside a Filament panel. Works with Reverb, Pusher, Ably or no broadcaster at all. Dark-first, English and Georgian.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
