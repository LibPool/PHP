# heyosseus/phpstan-sloppy

> 标签: PHPStan, ai, ai-agents, ai-code-review, claude-code, code-quality, code-review, eloquent, larastan, laravel, n-plus-one, phpstan-extension, phpstan-rules, pull-request, quality-gate, sloppy, static-analysis, technical-debt

## 简介

Sloppy's rules inside your PHPStan run: swallowed exceptions, god methods, N+1 queries, placeholder bodies, weakened tests and the rest of the debt AI coding agents leave in PHP, reported as PHPStan errors. Diff mode, editor mode, a quality gate and a result cache included.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
