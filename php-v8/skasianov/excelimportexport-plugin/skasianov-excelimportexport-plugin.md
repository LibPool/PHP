# skasianov/excelimportexport-plugin

> 标签: PHP

## 简介

OctoberCMS plugin. Provides replacement for ImportExportController with XLSX/XLS/ODS support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
