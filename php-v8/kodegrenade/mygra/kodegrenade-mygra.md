# kodegrenade/mygra

> 标签: cli, data-migration, database, etl, migration, mysql, postgresql, sqlite, sqlserver

## 简介

Config-driven data migration between MySQL, PostgreSQL, SQLite and SQL Server: transforms, validation, ID mapping, resume and verify

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
