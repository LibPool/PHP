# wobqqq/fortifyipblocker-plugin

> 标签: blocklist, firewall, fortify, ip-blacklist, ip-blocker, laravel, october, october-plugin, octobercms, security

## 简介

Fortify module for October CMS: blocks the IP addresses and subnets you list

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
