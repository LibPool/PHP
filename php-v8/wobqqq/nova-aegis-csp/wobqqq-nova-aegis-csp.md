# wobqqq/nova-aegis-csp

> 标签: aegis, content-security-policy, csp, laravel, laravel-nova, nova, security, xss

## 简介

Aegis module for Laravel Nova: a Content-Security-Policy header for the site and the Nova panel, edited from the Aegis settings

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
