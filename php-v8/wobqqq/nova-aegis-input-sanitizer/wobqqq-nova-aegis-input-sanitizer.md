# wobqqq/nova-aegis-input-sanitizer

> 标签: aegis, input-sanitizer, laravel, laravel-nova, nova, security, waf, xss

## 简介

Aegis module for Laravel Nova: blocks XSS, template injection, command injection and path traversal payloads before they reach the application

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
