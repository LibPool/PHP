# wobqqq/fortifyadminipaccess-plugin

> 标签: access-control, admin, admin-panel, fortify, ip-whitelist, laravel, october, october-plugin, octobercms, security

## 简介

Fortify module for October CMS: opens the backend only to the IP addresses on a whitelist

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
