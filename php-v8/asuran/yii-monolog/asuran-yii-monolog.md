# asuran/yii-monolog

> 标签: debug, error, exception, log, monitoring, monolog, yii

## 简介

Extension for using monolog with yii 1.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
