# shtrihstr/wp-image-editor-aws-lambda

> 标签: plugins, wordpress

## 简介

Image Editor Class for Image Manipulation through Node.js modules and AWS Lambda.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
