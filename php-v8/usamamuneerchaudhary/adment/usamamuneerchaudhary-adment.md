# usamamuneerchaudhary/adment

> 标签: ads, adsense, banners, filament, filament-plugin, laravel

## 简介

Production-grade ad & Google AdSense manager for Filament v5, placements, responsive creatives, click tracking, and a public API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
