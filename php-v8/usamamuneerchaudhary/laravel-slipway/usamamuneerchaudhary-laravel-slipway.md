# usamamuneerchaudhary/laravel-slipway

> 标签: bitbucket-pipelines, cd, ci, ci-cd, devops, github-actions, gitlab-ci, laravel, pipelines, policy-as-code

## 简介

Define your CI/CD pipeline once in config/slipway.php and compile it to GitHub Actions, Bitbucket Pipelines and GitLab CI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
