# giorgiolucca/vagalume-sdk

> 标签: api, sdk, vagalume

## 简介

SDK não oficial da API do vagalume desenvolvida em PHP (https://api.vagalume.com.br/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
