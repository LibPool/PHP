# nativephp/mobile-vibe

> 标签: PHP

## 简介

Websockets for NativePHP Mobile — live server events (Pusher protocol: Vask / Reverb / Pusher)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
