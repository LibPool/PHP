# nativephp/web-ui

> 标签: SSR, edge, laravel, mobile, nativephp, web

## 简介

EDGE web render target for NativePHP — the same screens as HTML in a browser

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
