# dealerweb/einvoice

> 标签: E-Invoice, EN16931, PDFA, Viewer, ZUGFeRD, cii, e-invoicing, e-rechnung, einvoice, electronic-invoicing, factur-x, generator, html, invoice, kosit, parser, pdf, peppol, schematron, ubl, validator, visualizer, xrechnung

## 简介

E-invoicing in pure PHP: read, validate, visualize and create XRechnung, ZUGFeRD / Factur-X and Peppol BIS invoices (EN 16931, UBL and CII) - with the verdicts of the official validators, no Java needed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
