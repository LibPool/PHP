# ubc-web-services/ubc_chosen_style_tweaks

> 标签: PHP

## 简介

A Drupal 8 module to add some style tweaks to the default Chosen styles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
