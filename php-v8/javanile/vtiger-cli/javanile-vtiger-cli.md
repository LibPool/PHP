# javanile/vtiger-cli

> 标签: automation, command-line, crm, vtiger, vtiger-extension

## 简介

Command-line utility for Vtiger CRM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
