# biru/payhub

> 标签: Doku, PayHub, biru, birupay, duitku, midtrans, payment, payment-gateway, qris, virtual-account

## 简介

Official PHP SDK for Biru PayHub Centralized Multi-Platform Payment Gateway (Midtrans, Duitku, DOKU)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
