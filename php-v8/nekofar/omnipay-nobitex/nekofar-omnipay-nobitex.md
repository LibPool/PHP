# nekofar/omnipay-nobitex

> 标签: bitcoin, gateway, litecoin, merchant, nobitex, omnipay, payment, purchase

## 简介

Nobitex driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
