# nekofar/omnipay-yekpay

> 标签: gateway, merchant, omnipay, payment, purchase, yekpay

## 简介

Yekpay driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
