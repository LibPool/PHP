# nekofar/omnipay-zarinpal

> 标签: gateway, merchant, omnipay, payment, purchase, zarinpal

## 简介

ZarinPal driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
