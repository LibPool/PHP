# markjun/medoo

> 标签: database, database library, lightweight, mariadb, mssql, mysql, oracle, php framework, postgresql, sql, sqlite

## 简介

The lightweight PHP database framework to accelerate development(Adapted from catfan/Medoo)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
