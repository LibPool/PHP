# rebeccathedev/search-parser

> 标签: PHP

## 简介

A parser that converts a freeform query into an intermediate object, that can be converted to query many backends (SQL, ElasticSearch, etc).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
