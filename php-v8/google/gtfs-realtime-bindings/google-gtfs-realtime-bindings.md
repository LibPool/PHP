# google/gtfs-realtime-bindings

> 标签: gtfs-realtime

## 简介

PHP classes generated from the GTFS-realtime protocol buffer specification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
