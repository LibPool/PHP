# dalysie/mailhuset

> 标签: api, email, mailhuset, smtp, transactional

## 简介

Official PHP client for the Mailhuset transactional email API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/Dalysie-ceo/mailhuset-php.git
