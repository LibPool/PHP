# tranquil-tools/laravel-table-builder

> 标签: ComfyCoders BV, laravel, laravel-table-builder

## 简介

Define Laravel tables in PHP: columns, filters, search, sorting, bulk and row actions, export and reordering, independent of any frontend

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
