# muathye/laravel-wallet

> 标签: credits, currency, laravel-wallet, muath-ye, payment, virtual, wallet

## 简介

Easy to use virtual wallet for your laravel app

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
