# renekorss/phpexcelformatter

> 标签: excel, format, php, spreadsheet, xls, xlsx

## 简介

PHPExcelFormatter is class to make it more simple to get data from Excel documents.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
