# maxara/statamic-live-preview

> 标签: PHP

## 简介

Click-to-edit bridge for the Statamic live preview: hovering a block highlights it, clicking jumps to the matching set in the publish form.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
