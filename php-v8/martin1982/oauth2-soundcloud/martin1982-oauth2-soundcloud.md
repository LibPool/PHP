# martin1982/oauth2-soundcloud

> 标签: Authentication, authorization, client, oauth, oauth2, soundcloud

## 简介

SoundCloud Oauth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
