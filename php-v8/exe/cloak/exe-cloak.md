# exe/cloak

> 标签: Fingerprint, http, http client, php, tls, tls13

## 简介

Low-level HTTP client with TLS 1.3 and HTTP fingerprint control - in pure PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
