# hanshs474/kavel

> 标签: ai, image-editing, image-generation, kavel, no-api-key, text-to-image

## 简介

Generate and edit images from PHP with no API key and no account, via the free tier of kavel.ai

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
