# hanshs474/emaki

> 标签: ai-video, emaki, image-to-video, seedance, seedance-2, seedance-2.5, text-to-video, video-generation

## 简介

Official SDK for emaki (emaki.ai), the Japanese-language AI video generator for Seedance 2.5 and Seedance 2.0. Generate Seedance clips and images from PHP with one API key.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
