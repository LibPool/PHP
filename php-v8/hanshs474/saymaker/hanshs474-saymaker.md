# hanshs474/saymaker

> 标签: ai, image-generation, kling, saymaker, seedance, text-to-image, text-to-video, veo, video-generation

## 简介

Generate images and video from PHP on SayMaker: Veo 3.1, Kling 3.0, Seedance 2.0, Nano Banana 2, GPT Image 2.5 and more with one API key

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
