# theunwindfront/tailwindcss-fluid-scale

> 标签: PHP

## 简介

Tailwind CSS v4 plugin for automatic fluid typography and dynamic scale calculations using native clamp().

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
