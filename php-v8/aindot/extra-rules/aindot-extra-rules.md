# aindot/extra-rules

> 标签: aindot, extra-rules, laravel

## 简介

A package that include extra rules for Laravel, Kuwait Civil ID validation, ISBN10, ISBN13 and more in development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
