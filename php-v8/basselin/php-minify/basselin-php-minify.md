# basselin/php-minify

> 标签: minify, php_strip_whitespace

## 简介

PhpMinify is a little tool to minify your application php like the javascript minify tools.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
