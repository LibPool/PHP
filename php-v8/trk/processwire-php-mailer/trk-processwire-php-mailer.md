# trk/processwire-php-mailer

> 标签: mailer, php-mailer, processwire

## 简介

This module extends WireMail base class, integrating the PHPMailer mailing library into ProcessWire.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
