# osedea/laravel-rest

> 标签: api, command bus, laravel, rest

## 简介

A bundle providing a RESTful API for the Laravel framework version 5 using the command bus.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
