# iotacb/contao-smart-image-area

> 标签: Object Detection, contao, face detection, focal point, image, important part, mediapipe

## 简介

Automatic important image areas using local face detection, object detection and visual saliency for Contao 5.7

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
