# mateusz-blaszczyk/php-ocsclient

> 标签: client, ocs, oktawave, php-ocsclient, storage

## 简介

PHP library to communicate with Oktawave OCS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
