# quantumtecnology/falcon-crmhub-sdk

> 标签: api, crm, crmhub, falcon, falcon-vendas, phone-verification, sdk, transactional-messaging, whatsapp

## 简介

PHP SDK for the Falcon Vendas (CrmHub) API — WhatsApp phone verification, transactional messaging and customer registration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
