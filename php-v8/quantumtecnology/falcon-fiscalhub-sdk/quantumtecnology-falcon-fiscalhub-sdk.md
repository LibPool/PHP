# quantumtecnology/falcon-fiscalhub-sdk

> 标签: api, danfse, falcon, fiscalhub, invoice, nfs-e, nfse, nota-fiscal, sdk

## 简介

PHP SDK for the Falcon Fiscal Hub API — issue, query and cancel Brazilian service invoices (NFS-e, padrão nacional)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
