# deepayment/sdk

> 标签: merchant-api, payment, payout

## 简介

Merchant open API SDK (Ed25519 / RFC 9421 signing, X25519 sealed box body encryption)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
