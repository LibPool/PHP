# jackiedo/omnipay-vnpay

> 标签: gateway, merchant, omnipay, pay, payment, purchase, vnpay

## 简介

VnPay gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
