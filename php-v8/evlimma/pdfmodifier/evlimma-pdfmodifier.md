# evlimma/pdfmodifier

> 标签: CodigoSpace, Evlimma, PDFEditar, PDFModificar, pdf

## 简介

Add texts with font and size in pdf files | Adicionar textos com fonte e tamanho em arquivos pdf

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
