# pianqifei/smscode

> 标签: PHP

## 简介

A tool used send smscode support 'tengxin' 'lexin' 'yunpian','aliyun'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
