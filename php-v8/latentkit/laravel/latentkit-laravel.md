# latentkit/laravel

> 标签: ai, laravel, latentkit, llm

## 简介

Official Laravel integration for LatentKit's route-based AI gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://docs.latentkit.com/integrations/laravel
- 源码仓库：https://github.com/amirehman/latentkit-laravel.git
- Packagist 页面：https://packagist.org/packages/latentkit%2Flaravel

## 历史版本号

- 当前版本：v0.1.0-alpha.1

## 获取地址

- Composer 安装：`composer require latentkit/laravel`
- Packagist 仓库：https://repo.packagist.org/p2/latentkit/laravel.json
- 许可证：MIT
- PHP 要求：^8.3
