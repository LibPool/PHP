# selrahcd/phpunit-test-run-logger

> 标签: PHP

## 简介

A test run logger for PHPUnit. Records the results of test runs for improving TDD workflow.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
