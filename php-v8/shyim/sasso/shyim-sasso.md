# shyim/sasso

> 标签: compiler, css, extension, sass, scss

## 简介

PHP extension wrapping the sasso pure-Rust SCSS to CSS compiler, built with ext-php-rs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
