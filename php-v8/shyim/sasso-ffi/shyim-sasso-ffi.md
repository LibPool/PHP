# shyim/sasso-ffi

> 标签: compiler, css, ffi, polyfill, sass, sasso, scss

## 简介

Pure-PHP FFI polyfill for ext-sasso (shyim/sasso), the pure-Rust SCSS to CSS compiler

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
