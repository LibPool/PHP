# shyim/scssphp-compat

> 标签: css, less, sass, scss, stylesheet

## 简介

A performance-focused, drop-in compatible fork of scssphp/scssphp (a SCSS compiler written in PHP).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
