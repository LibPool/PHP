# shyim/akari

> 标签: PHP

## 简介

A high-performance PHP observability extension. Automatic OpenTelemetry tracing, sampling, and profiling - zero-config, near-zero overhead.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
