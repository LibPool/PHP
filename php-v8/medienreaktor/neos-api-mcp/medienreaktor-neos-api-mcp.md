# medienreaktor/neos-api-mcp

> 标签: PHP

## 简介

An MCP server for Neos 9 on top of the Neos API: Claude and other MCP clients work with your content, signed in as a Neos user.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
