# rebelinblue/laravel-zxcvbn

> 标签: laravel, passwords, security, validation, zxcvbn

## 简介

Service provider to use the zxcvbn project by @dropbox in Laravel 5.4 and above

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
