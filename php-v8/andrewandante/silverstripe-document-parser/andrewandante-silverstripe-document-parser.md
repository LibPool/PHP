# andrewandante/silverstripe-document-parser

> 标签: PHP

## 简介

Adds DocumentParser package to extract contents of .doc, .docx, .rtf and .txt files for search etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
