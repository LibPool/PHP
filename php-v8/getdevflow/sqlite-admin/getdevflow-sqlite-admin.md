# getdevflow/sqlite-admin

> 标签: adminer, database-management, mysql, phpLiteAdmin, sqlite

## 简介

SQLite admin plugin for Devflow CMF inspired by phpLiteAdmin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
