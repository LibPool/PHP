# getdevflow/easy-mde

> 标签: easy-markdown-editor, easy-mde, easymde, editor, markdown, markdown-editor

## 简介

A simple, beautiful, and embeddable JavaScript Markdown editor for Devflow CMF.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
