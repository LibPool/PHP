# getdevflow/vapor

> 标签: theme, themes, vapor, vapor-theme

## 简介

Ported from Ghost, Vapor is a minimal and responsive theme with a focus on typography.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
