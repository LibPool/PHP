# getdevflow/custom-fields

> 标签: custom-fields, customfields, metadata, user-meta, usermeta

## 简介

A powerful and flexible developer-friendly custom fields plugin for Devflow CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
