# openadm/yii2-basic-app

> 标签: AdminLTE, admin, framework, openadm, openadmin, yii2

## 简介

OpenAdm是一个基于Yii2的后台开源骨架，集成了用户和插件系统,使用主题功能,默认使用AdminLTE2的模板的主题,可以非常方便的开发新的功能。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
