# marks-software-gmbh/yab-cms-ff

> 标签: AdminLTE, api, bootstrap, cakephp, cakephp5, cms, content-management, eav, php8, rest, sqlite

## 简介

Yet Another Boring CMS – Fast Forward (YAB CMS). A CakePHP 5 + PHP 8 powered Bootstrap CMS with AdminLTE.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
