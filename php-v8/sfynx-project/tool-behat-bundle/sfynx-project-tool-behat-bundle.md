# sfynx-project/tool-behat-bundle

> 标签: Behat, Mink, tests

## 简介

This Bundle provides context tools (WebApi, Ajax, Xpath, hidden field) to run mink tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
