# sfynx-project/cmf-plugin-content-bundle

> 标签: cmf, widget

## 简介

This Bundle provide a plugin with several widgets like Article, Tag, media, rub, test to work with the CMF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
