# sfynx-project/template-theme-flatlab-bundle

> 标签: Flatlab, cmf, template

## 简介

This Bundle provides the Flatlab theme for the cmf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
