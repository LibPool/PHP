# execut/yii2-crud-fields

> 标签: yii2 fields, yii2 grid

## 简介

A behavior for standard fields logic in CRUD based on kartik dynagrid and detailView

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
