# execut/yii2-widget-bootstraptreeview

> 标签: bootstrap, extension, form, input, jquery, plugin, tree, yii2

## 简介

Bootstrap Tree View widget wrapper for yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
