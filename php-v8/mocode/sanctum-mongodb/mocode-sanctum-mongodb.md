# mocode/sanctum-mongodb

> 标签: auth, laravel, mongodb, sanctum

## 简介

Laravel Sanctum Mongodb provides a featherweight authentication system for SPAs and simple APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
