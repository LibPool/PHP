# sid-payment/module-instant-eft

> 标签: SID, eft, payment gateway, payments, sid instant eft

## 简介

Payment gateway module for directing payments through SID Instant EFT

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
