# gomoob/php-websocket-server

> 标签: Ratchet, gomoob, websocket

## 简介

WebSocket server with tags management, forward your messages on the right clients with ease !

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
