# slruslan/laravel-eloquent-custom-casts

> 标签: PHP

## 简介

Provides Laravel Eloquent trait to enable custom class object casting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
