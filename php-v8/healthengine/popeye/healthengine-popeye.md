# healthengine/popeye

> 标签: aop, functional, micro, middleware, slim, stack

## 简介

Popeye is a generic middleware stack inspired by the Slim micro framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
