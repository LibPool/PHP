# madmatt/silverstripe-iplists

> 标签: IP, allowlist, cms, denylist, iplists, security, silverstripe

## 简介

Create allow and deny lists based on IP addresses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
