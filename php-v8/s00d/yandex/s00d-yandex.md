# s00d/yandex

> 标签: api, client, curl, disk, php, rest, restful, sdk, yandex, yandex disk, диск, яндекс, яндекс диск

## 简介

PHP SDK для работы с некоторыми сервисами яндекса (Яндекс.Диск, Yandex.Disk)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
