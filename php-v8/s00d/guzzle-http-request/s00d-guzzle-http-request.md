# s00d/guzzle-http-request

> 标签: Guzzle, http, laravel, multi, multiple, request

## 简介

GHR is a simple Guzzle wrapper + multiple request + DomCrawler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
