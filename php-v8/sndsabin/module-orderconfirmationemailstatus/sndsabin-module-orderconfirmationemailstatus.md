# sndsabin/module-orderconfirmationemailstatus

> 标签: PHP

## 简介

This module adds a column in the sales order grid showing the status of the order confirmation email.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
