# youniwemi/wp-settings-kit

> 标签: PHP

## 简介

WP Settings Kit is a lightweight library for easily creating WordPress settings pages and Post metaboxes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
