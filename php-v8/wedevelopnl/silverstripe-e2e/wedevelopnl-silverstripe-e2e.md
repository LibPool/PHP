# wedevelopnl/silverstripe-e2e

> 标签: development, e2e, gitlab, silverstripe

## 简介

Helper module to run E2E tests against a Silverstripe website inside CI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
