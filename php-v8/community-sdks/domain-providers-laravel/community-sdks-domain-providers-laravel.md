# community-sdks/domain-providers-laravel

> 标签: PHP

## 简介

Laravel bridge for community-sdks/domain-providers-php with DB-backed provider registry and TLD sync.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
