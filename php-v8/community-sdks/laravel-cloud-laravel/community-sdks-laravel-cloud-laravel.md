# community-sdks/laravel-cloud-laravel

> 标签: api, laravel, laravel-cloud, sdk

## 简介

A simple Laravel wrapper for the Community SDKs Laravel Cloud PHP client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
