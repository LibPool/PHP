# gcego/rendering

> 标签: Rendering, admin, blade, components, gcego, laravel

## 简介

Rendering for GCEGO Studio: renderer registry, Blade rendering of components and registered definitions, and render operations for gcego/runtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
