# gcego/runtime

> 标签: admin, execution, gcego, kernel, laravel, runtime

## 简介

Execution kernel for GCEGO Studio: operation dispatch, trusted execution contexts, typed handlers and fail-closed authorization.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
