# gcego/data

> 标签: admin, data, eloquent, gcego, laravel, pagination, query

## 简介

Universal data access and query engine for GCEGO Studio: declarative sources, Eloquent, query builder and collection providers, secure filtering, searching, sorting, pagination, aggregation, relationships and scoped record resolution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
