# gcego/blueprints

> 标签: admin, blueprints, declarative, gcego, laravel

## 简介

Declarative feature definitions for GCEGO Admin Studio: Blueprint::define() with typed, validated, immutable definition objects, discovered through gcego/registry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
