# gcego/core

> 标签: admin, framework, gcego, laravel

## 简介

Laravel integration kernel for GCEGO Studio: configuration, lifecycle, package coordination, extensions and diagnostics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
