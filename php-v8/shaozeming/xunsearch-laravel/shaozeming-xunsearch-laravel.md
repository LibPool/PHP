# shaozeming/xunsearch-laravel

> 标签: PHP

## 简介

基于XunSearch（讯搜）sdk的全文搜索Laravel 5.*，支持全拼，拼音简写，模糊,同义词搜索

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
