# webplode/s3-uploads

> 标签: wordpress

## 简介

WordPress plugin to store uploads on S3 with WebP offload (webplode fork)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/webplode/S3-Uploads.git
