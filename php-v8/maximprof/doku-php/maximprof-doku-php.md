# maximprof/doku-php

> 标签: Doku, api, doku api v2

## 简介

DOKU payment gateway API wrapper. Fork of https://github.com/otezz/doku-php/ with support for HTTPS in staging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
