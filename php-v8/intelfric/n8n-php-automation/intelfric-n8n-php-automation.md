# intelfric/n8n-php-automation

> 标签: automation, flow, laravel, n8n, workflow, zapier

## 简介

A visual automation engine for Laravel, similar to n8n, Zapier, or Huginn

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
