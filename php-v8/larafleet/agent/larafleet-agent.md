# larafleet/agent

> 标签: devops, heartbeat, laravel, monitoring, security

## 简介

Laravel monitoring agent for LaraFleet – sends heartbeats with version, security advisory, queue, and uptime data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
