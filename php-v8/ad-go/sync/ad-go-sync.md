# ad-go/sync

> 标签: active-active, codeigniter, codeigniter4, multi-master, replication, shield, sync, synchronization

## 简介

Active-active database synchronisation for two CodeIgniter 4 instances over HTTPS (no JSON, no schema changes to existing tables).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
