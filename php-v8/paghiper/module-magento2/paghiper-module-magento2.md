# paghiper/module-magento2

> 标签: PHP

## 简介

Módulo Oficial do PagHiper para Magento 2.4.x com emissão de Pix e Boletos registrados com retorno automático.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
