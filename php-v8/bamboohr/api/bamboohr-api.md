# bamboohr/api

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

Official PHP SDK for the BambooHR API. https://documentation.bamboohr.com

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
