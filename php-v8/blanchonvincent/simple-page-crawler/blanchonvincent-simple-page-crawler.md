# blanchonvincent/simple-page-crawler

> 标签: PHP

## 简介

ZF2 module v0.3.0 - Provide a crawler to get web page informations : title, meta, heading tags and images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
