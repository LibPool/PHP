# bcmarketplace/module-carousel-fusion

> 标签: PHP

## 简介

Magento 2 wrapper for Owl Carousel v2.3.4 jQuery widget with accessibility enhancements and modern browser API support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
