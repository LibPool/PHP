# rawphp/raw-yaml

> 标签: yaml

## 简介

RawYaml is a wrapper around Symfony's Yaml Library and is used by RawPHP framework and other applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
