# rawphp/warp

> 标签: laravel, performance, pest, phpunit, testing

## 简介

Warm-worker test engine for Laravel + Pest — boots the app once per process and hands each test a sandboxed clone

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
