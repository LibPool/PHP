# vlfesko/m2-module-pagecache-extended-vcl

> 标签: magento2, varnish

## 简介

Patches Varnish 4 VCL by adding cache purge via browser by Ctrl+F5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
