# phppkg/config

> 标签: JSON5, config, config-load, config-manage, ini, json, library, php, toml, yaml

## 简介

Config manage, load, get. Supports INI,JSON,YAML,NEON,PHP format file

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
