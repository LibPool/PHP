# limon/laravel-zender

> 标签: gateway, laravel, limon, otp, php, sdk, sms, ussd, whatsapp, zender

## 简介

Official PHP & Laravel SDK for Zender Messaging Platform (SMS, WhatsApp, OTP, USSD)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
