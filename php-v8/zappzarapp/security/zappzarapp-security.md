# zappzarapp/security

> 标签: audit-logging, content-security-policy, cors, csp, csrf, headers, hsts, password, php8, rate-limiting, sanitization, security, sri, subresource-integrity, xss

## 简介

Comprehensive PHP security library: CSP, Security Headers, CSRF, Cookies, Password Validation, Input Sanitization, Rate Limiting, SRI, and Audit Logging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
