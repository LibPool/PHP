# dtgfranca/laravel-tools

> 标签: Shift, artisan, laravel, rector, upgrade

## 简介

Automated Laravel version upgrade toolkit with code transformation rules (Rector).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
