# xstrm/laravel-xstrm

> 标签: analytics, error-tracking, laravel, monitoring, performance

## 简介

Analytics, error tracking and performance monitoring for Laravel. Privacy-first, EU-hosted.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
