# builtbyberry/laravel-swarm

> 标签: agents, ai, laravel, orchestration, swarm

## 简介

Multi-agent swarm orchestration for Laravel, built on Laravel AI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
