# ggggino/wordbundle

> 标签: Symfony2, bundle, office, word

## 简介

This is a Symfony2 Bundle helps you to read and write Word files, thanks to the PHPWord library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
