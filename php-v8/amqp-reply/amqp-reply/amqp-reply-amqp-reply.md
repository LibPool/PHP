# amqp-reply/amqp-reply

> 标签: AMQP, Messenger, microservices, rabbitmq, reply, response, rpc

## 简介

A variation of 'amqp-messenger' that allows to send a message and wait for a reply

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
