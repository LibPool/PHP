# vnagara/geoip-module

> 标签: Zend Framework, geoip, zf, zf2

## 简介

Geoip module for zend framework application to store Record. It utilize maxmind database and API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
