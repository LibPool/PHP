# akza/akza

> 标签: admin-panel, akza, cms, headless-cms, laravel, postgres

## 简介

Akza — self-hosted, instance-per-project admin panel & headless CMS for Laravel + Postgres.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
