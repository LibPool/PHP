# aeliot/todo-registrar

> 标签: GitHub Issue, GitLab Issue, Issue Tracking, JIRA API, Readmine Issue, TODO comment, TODO registrar, create issue, static analysis, todo tracking, yandex tracker

## 简介

Register TODOs from source code in issue tracker

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
