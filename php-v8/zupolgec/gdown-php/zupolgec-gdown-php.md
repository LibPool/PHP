# zupolgec/gdown-php

> 标签: curl, download, downloader, google-drive, wget

## 简介

Google Drive Public File Downloader when Curl/Wget Fails - PHP implementation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
