# enemis/media-bundle

> 标签: file, media, pdf, thumbnail, upload, youtube

## 简介

Media management system for symfony application, inspired and based on Sonata Media Project

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
