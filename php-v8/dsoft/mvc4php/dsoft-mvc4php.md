# dsoft/mvc4php

> 标签: dbms, mvc, mysqli

## 简介

This package allow users to manage most common operations with databases, based on mysqli functions. It also includes support for MVC components.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
