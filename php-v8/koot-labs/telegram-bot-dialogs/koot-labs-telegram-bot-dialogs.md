# koot-labs/telegram-bot-dialogs

> 标签: laravel, telegram, telegram-dialog

## 简介

Telegram Bot API PHP SDK extension that allows to implement dialogs in bots

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
