# raazpuspa/iap-validator

> 标签: PHP

## 简介

Composer package to validate in-app purchase receipts made to iTunes or Google through mobile apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
