# nfe/nfe

> 标签: api, brazil, invoice, nfe, nfe.io, nfse, nota-fiscal, sdk

## 简介

SDK PHP oficial da NFE.io — PHP 8.2+, zero dependências em runtime, paridade com o SDK Node.js.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
