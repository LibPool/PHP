# netzmacht/contao-font-awesome

> 标签: FontAwesome, icon font, icons

## 简介

Integrates Font Awesome into Contao frontend and backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
