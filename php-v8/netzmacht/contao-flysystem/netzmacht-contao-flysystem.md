# netzmacht/contao-flysystem

> 标签: abstraction, contao, filesystem, filesystems, flysyste

## 简介

This integrates the flysystem filesystem abstraction into Contao

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
