# dardangashi/filament-api-explorer

> 标签: api, api-explorer, documentation, filament, laravel, openapi, swagger

## 简介

An OpenAPI-driven API explorer for Filament panels: browse endpoints, inspect response schemas, copy request samples and send live GET requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
