# premmohantyagi/apihub-laravel

> 标签: ai, api, email, integration, laravel, openai, payments, sdk, sms, stripe, twilio

## 简介

ApiHub for Laravel: one unified, driver-based interface over global third-party APIs covering payments, AI, email, SMS & messaging, and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
