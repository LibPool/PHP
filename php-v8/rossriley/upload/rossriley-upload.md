# rossriley/upload

> 标签: file, form, upload, validation

## 简介

Framework agnostic upload library - Forked from siriusphp for PHP 5.3 compatibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
