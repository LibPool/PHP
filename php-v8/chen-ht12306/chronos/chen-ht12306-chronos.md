# chen-ht12306/chronos

> 标签: carbon, date, datetime, laravel, time, timestamp, timezone

## 简介

一个优雅的 PHP 日期时间处理库，类似 Carbon，提供链式调用和丰富的时间操作方法

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
