# sheadawson/silverstripe-rateable

> 标签: Rating, silverstripe

## 简介

An extension that adds a star rating system + UI to any DataObject type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
