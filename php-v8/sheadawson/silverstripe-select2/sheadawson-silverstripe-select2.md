# sheadawson/silverstripe-select2

> 标签: Forms, ajax, silverstripe

## 简介

A set of silverstripe form fields based on http://ivaynberg.github.com/select2/s

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
