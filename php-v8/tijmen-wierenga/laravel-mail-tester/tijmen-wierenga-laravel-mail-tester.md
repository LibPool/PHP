# tijmen-wierenga/laravel-mail-tester

> 标签: PHP

## 简介

An extension to Laravel's TestCase which allows you to run unit tests on emails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
