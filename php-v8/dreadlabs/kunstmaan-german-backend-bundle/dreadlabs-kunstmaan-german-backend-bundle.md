# dreadlabs/kunstmaan-german-backend-bundle

> 标签: cms, german, kunstmaan, translation

## 简介

Adds and overrides german translations for the Kunstmaan CMS backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
