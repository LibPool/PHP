# bummzack/swiftmailer-emogrifyplugin

> 标签: emogrifier, plugin, swiftmailer

## 简介

Inline CSS in the HTML output of SwiftMailer using Emogrifier.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
