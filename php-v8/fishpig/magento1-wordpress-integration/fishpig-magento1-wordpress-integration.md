# fishpig/magento1-wordpress-integration

> 标签: PHP

## 简介

Magento WordPress Integration module for Magento 1 CE and Magento 1 EE.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
