# fishpig/magento2-wordpress-integration-yoastseo

> 标签: PHP

## 简介

Magento 2 WordPress Inegration Addon module to support the WordPress SEO plugin by Yoast.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
