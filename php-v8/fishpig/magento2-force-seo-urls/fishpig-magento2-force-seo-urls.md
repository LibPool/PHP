# fishpig/magento2-force-seo-urls

> 标签: PHP

## 简介

Redirect system URLs (eg. catalog/product/view/id/123) to the proper SEO URL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
