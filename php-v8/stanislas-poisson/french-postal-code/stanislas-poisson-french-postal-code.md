# stanislas-poisson/french-postal-code

> 标签: INSEE, communes, dataset, doctrine, eloquent, france, geocoding, gps, laravel, open-data, postal-code, symfony

## 简介

The regions, departments, communes and postal codes of France, with one GPS point per postal code: the data, the models and a loader for Laravel and Symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
