# zeixcom/craft-index-views

> 标签: Craft, cms, craft-plugin, craftcms, element-index, entries, productivity, views

## 简介

Save and switch between named views on your Craft CMS element indexes. Columns, sort, filters, view mode and source are stored per user in the database, with optional team sharing and per-user dynamic conditions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
