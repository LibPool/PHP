# wieni/wmentity_overview

> 标签: PHP

## 简介

Improved EntityListBuilders with support for paging, table sorting, table dragging, filtering, bulk actions, database queries and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
