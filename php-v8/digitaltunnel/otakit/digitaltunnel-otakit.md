# digitaltunnel/otakit

> 标签: PHP

## 简介

OtaKit is a Laravel package designed to facilitate the generation and validation of One-Time Passwords (OTPs) within Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
