# maaf/devtools

> 标签: Devtools, debug, inspector, maaf, profiler, telescope

## 简介

MAAF DevTools Package - Request inspector (Telescope-like), module-level log view, and query profiler

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
