# netglue/zf2-ssl-module

> 标签: module, netglue, ssl, zend, zf2

## 简介

ZF2 Module that helps enforce the use of an SSL connection for HTTP requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
