# netglue/mandrill-api

> 标签: Guzzle, mail, mandrill

## 简介

PHP library for interacting with the v1 Mandrill REST API using GuzzlePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
