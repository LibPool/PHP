# netglue/zend-expressive-mail-template

> 标签: email, expressive, mail, netglue, template, zend

## 简介

A module that provides a way of easily configuring and sending email messages using existing templating engines available in Zend Expressive.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
