# netglue/expressive-prg

> 标签: expressive, netglue, prg, zend

## 简介

Middleware to implement the Post/Redirect/Get pattern in Zend Expressive

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
