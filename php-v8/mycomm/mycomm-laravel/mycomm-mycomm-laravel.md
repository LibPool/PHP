# mycomm/mycomm-laravel

> 标签: laravel, messaging, mycomm, sms, webhooks

## 简介

Laravel integration for the MyComm PHP SDK: configuration, a facade, a signed webhook route and a testing fake.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
