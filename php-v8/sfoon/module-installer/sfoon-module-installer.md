# sfoon/module-installer

> 标签: composer, e-commerce, plugin, sfoon

## 简介

A Composer plugin that helps install modules for Sfoon E-Commerce.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
