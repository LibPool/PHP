# chatixy/statamic-chatixy

> 标签: ai-chat, chat, chatixy, customer-support, live-chat, statamic, statamic-addon, widget

## 简介

Chatixy AI support agent for Statamic - paste your widget key, the loader is added to every front-end page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
