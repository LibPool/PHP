# chatixy/contao-chatixy

> 标签: ai-chat, chat, chatixy, contao, customer-support, live-chat, widget

## 简介

Chatixy AI support agent for Contao - paste your widget key, no code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
