# chatixy/shopware6-chat

> 标签: ai-chat, chat, chatixy, customer-support, live-chat, shopware, widget

## 简介

Chatixy AI support agent for Shopware 6 - no-code storefront install.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
