# chatixy/silverstripe-chatixy

> 标签: ai-chat, chat, chatixy, customer-support, live-chat, silverstripe, widget

## 简介

Chatixy AI support agent for Silverstripe CMS - paste your widget key in Settings, no code.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
