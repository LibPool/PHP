# atom-azimov/uploader

> 标签: PHP

## 简介

This is a simple yet flexible PHP library for file uploads via ORM embeddable objects, ORM entities, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
