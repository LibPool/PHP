# serrvius/amqp-rpc-extender

> 标签: AMQP, cqrs, gRPC, rabbitmq, rpc, symfony

## 简介

The extension for symfony/amqp-messenger to implement RPC calls

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
