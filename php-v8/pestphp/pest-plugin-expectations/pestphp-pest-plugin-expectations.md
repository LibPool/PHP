# pestphp/pest-plugin-expectations

> 标签: expectations, framework, pest, php, test, testing, unit

## 简介

Add expectations testing capabilities to Pest or PHPUnit

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
