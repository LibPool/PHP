# edrisaturay/filament-starter-minimal

> 标签: PHP

## 简介

Minimal Filament v5 starter plugin: essential panel plugins only (Shield-first, extensible registry).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
