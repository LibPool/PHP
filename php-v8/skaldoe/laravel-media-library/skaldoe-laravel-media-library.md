# skaldoe/laravel-media-library

> 标签: attachments, file-manager, laravel, media-library, upload

## 简介

Médiathèque réutilisable (dossiers, upload, attachments polymorphiques) pour projets Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
