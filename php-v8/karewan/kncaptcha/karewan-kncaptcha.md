# karewan/kncaptcha

> 标签: anti-bot, bot-protection, captcha, equihash, pow, privacy, proof-of-work, security

## 简介

Server side of KnCaptcha for PHP 8.3+: privacy-friendly proof-of-work captcha, stateless challenges, memory-hard Equihash puzzles checked in microseconds

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
