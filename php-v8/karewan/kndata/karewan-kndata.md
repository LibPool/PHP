# karewan/kndata

> 标签: attributes, dto, fast, hydrator, java, json, kotlin, mapper, mapping, serializer, swift, typescript, validation, validator

## 简介

Strict and fast PHP 8.3+ data mapping and validation (JSON, forms, arrays) with TypeScript, Java, Kotlin and Swift type generation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
