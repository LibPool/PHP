# karewan/knroute-inertia

> 标签: SPA, SSR, adapter, fast, inertia, inertiajs, knroute, router, vue

## 简介

Fast Inertia.js v3 server-side adapter for the KnRoute PHP 8.3+ router

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
