# winardiaris/nusoap

> 标签: client, http, nusoap, php, soap, transport, xml

## 简介

Custom NuSOAP for PHP 5.6 - 7.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
