# hexagono/responsive-horizontal-menu

> 标签: PHP

## 简介

This package generates a blade component with responsive header-menu function based on bootstrap-flex for standard sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
