# mpyw/laravel-local-class-scope

> 标签: builder, database, eloquent, illuminate, laravel, macro, query, scope

## 简介

A tiny macro that reuse a global scope class as a local scope

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
