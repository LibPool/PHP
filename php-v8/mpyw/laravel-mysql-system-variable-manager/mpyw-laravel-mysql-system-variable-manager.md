# mpyw/laravel-mysql-system-variable-manager

> 标签: illuminate, laravel, mysql, system, variable

## 简介

A tiny extension of MySqlConnection that manages session system variables

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
