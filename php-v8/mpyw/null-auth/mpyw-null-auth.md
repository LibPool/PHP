# mpyw/null-auth

> 标签: Dummy, auth, illuminate, laravel, none, nothing, null

## 简介

Null Guard for Laravel. Designed for Middleware-based authentication and testing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
