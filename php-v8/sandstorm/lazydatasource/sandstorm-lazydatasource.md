# sandstorm/lazydatasource

> 标签: Neos, react

## 简介

Neos package implementing a lazy data source for the UI; so that the elements are loaded lazily on demand.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
