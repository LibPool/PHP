# sandstorm/fuzzer

> 标签: PHP

## 简介

Improve your Functional and Unit Tests by Fuzzing: A technique to find missing edge cases in tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
