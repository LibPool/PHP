# cronox/cake-cron-jobs

> 标签: cakephp, cakephp3, cron, cron jobs

## 简介

CakePHP3 Plugin to create jobs for CRON

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
