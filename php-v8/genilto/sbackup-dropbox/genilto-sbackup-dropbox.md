# genilto/sbackup-dropbox

> 标签: adapter, backup, dropbox, sbackup, send

## 简介

SBackup adapter to work with backups on Dropbox

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
