# uverify/uverify-php

> 标签: Nigeria, aml, bvn, face-match, kyc, liveness, nin, uverify

## 简介

Official PHP library for the Bytid API (formerly UVerify): BVN, NIN and ID checks, liveness, face match, ID documents and AML screening for Nigeria.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
