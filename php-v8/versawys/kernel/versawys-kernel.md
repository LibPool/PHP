# versawys/kernel

> 标签: framework, mvc, php, twig, versaORM

## 简介

Núcleo del framework versaWYS-PHP: enrutamiento, middlewares, sesión/JWT, Twig, CLI y VersaORM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
