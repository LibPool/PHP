# versawys/versawys

> 标签: PHP

## 简介

Esqueleto de proyecto versaWYS-PHP: panel de administración en Vue 3 + TypeScript sobre el kernel versawys/kernel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
