# bnbwebexpertise/laravel-elfinder

> 标签: elfinder, filebrowser, laravel, tinymce

## 简介

A Laravel Package to integrate elFinder 2 forked from original barryvdh/laravel-elfinder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
