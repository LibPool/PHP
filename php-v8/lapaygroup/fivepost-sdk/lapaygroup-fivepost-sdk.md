# lapaygroup/fivepost-sdk

> 标签: PHP

## 简介

SDK для работы с API транспортной компании 5post (https://fivepost.ru)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
