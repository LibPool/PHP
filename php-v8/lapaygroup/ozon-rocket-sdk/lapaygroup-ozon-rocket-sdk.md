# lapaygroup/ozon-rocket-sdk

> 标签: PHP

## 简介

SDK для работы с API транспортной компании Ozon Rocket (https://rocket.ozon.ru)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
