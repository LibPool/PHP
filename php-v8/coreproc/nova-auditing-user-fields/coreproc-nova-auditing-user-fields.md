# coreproc/nova-auditing-user-fields

> 标签: laravel, nova

## 简介

A Laravel Nova field that works with the Laravel Auditing package to see who created or last updated a resource.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
