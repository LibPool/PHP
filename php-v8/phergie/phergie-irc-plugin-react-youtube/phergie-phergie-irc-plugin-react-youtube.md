# phergie/phergie-irc-plugin-react-youtube

> 标签: bot, irc, phergie, plugin

## 简介

Phergie plugin for providing information about YouTube videos

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
