# heyday/silverstripe-elastica

> 标签: elastica, elasticsearch, search, silverstripe

## 简介

Provides Elastic Search integration for SilverStripe DataObjects using Elastica

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
