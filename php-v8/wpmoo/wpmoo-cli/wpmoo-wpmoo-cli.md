# wpmoo/wpmoo-cli

> 标签: cli, framework, plugin, wordpress, wp-cli, wpmoo

## 简介

WPMoo CLI - modular commands for the WPMoo framework (PHP 7.4+)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
