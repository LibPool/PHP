# websightnl/yii2-sybase

> 标签: sybase

## 简介

Yii2 schema support for Sybase database, tested with SQL Anywhere 12.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
