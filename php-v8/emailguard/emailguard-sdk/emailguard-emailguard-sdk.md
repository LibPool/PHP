# emailguard/emailguard-sdk

> 标签: api, emailguard, sdk

## 简介

EmailGuard public API PHP SDK. See https://emailguard.co/docs/api-reference/guides/sdk-php for setup, authentication, and examples.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
