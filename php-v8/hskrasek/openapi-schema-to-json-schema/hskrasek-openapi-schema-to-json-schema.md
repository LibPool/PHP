# hskrasek/openapi-schema-to-json-schema

> 标签: convert, converter, json, openapi, schema

## 简介

PHP library to convert OpenAPI schema objects to JSON Schema

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
