# grzegurz/symfony-asset-mapper-typescript-enabler

> 标签: asset-mapper, react, symfony, typescript

## 简介

Small extension that allows use of .tsx files when creating React components in symfony/ux-react supplied by sensiolabs/typescript-bundle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
