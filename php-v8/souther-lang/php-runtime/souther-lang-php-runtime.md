# souther-lang/php-runtime

> 标签: PHP

## 简介

What every PHP binding of a Souther library built by souther-native-compiler runs on: loading the library, a run's arena, handles, and failures

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
