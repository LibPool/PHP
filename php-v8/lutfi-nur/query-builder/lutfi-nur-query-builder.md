# lutfi-nur/query-builder

> 标签: datatable, laravel, mysql, postgresql, query-builder, yajra

## 简介

Fluent datatable query builder for Laravel with Yajra Datatables. Supports MySQL and PostgreSQL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
