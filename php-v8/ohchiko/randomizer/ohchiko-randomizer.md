# ohchiko/randomizer

> 标签: generator, laravel, ohchiko, password, randomizer

## 简介

A laravel helper to generate random text. Initial purpose is for user password.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
