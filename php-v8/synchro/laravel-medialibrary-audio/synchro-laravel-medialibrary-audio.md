# synchro/laravel-medialibrary-audio

> 标签: audio, conversion, laravel, laravel-medialibrary, media

## 简介

Audio file thumbnail generator for Spatie's Laravel Media Library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
