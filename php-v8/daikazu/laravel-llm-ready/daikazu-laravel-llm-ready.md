# daikazu/laravel-llm-ready

> 标签: daikazu, laravel, laravel-llm-ready

## 简介

Serve LLM-optimized markdown versions of your Laravel pages by appending .md to any URL.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
