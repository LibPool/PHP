# tommy-dai/screenshot

> 标签: phantomjs, print-screen, screen, 小程序海报, 截图

## 简介

网页截图服务，用于生成小程序海报。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
