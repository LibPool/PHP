# eekes/sulu-webspace-settings-bundle

> 标签: Settings, cms, sulu, sulu-bundle, webspace

## 简介

Compose per-webspace settings in Sulu 3 the way you compose page templates, instead of one oversized global settings snippet.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
