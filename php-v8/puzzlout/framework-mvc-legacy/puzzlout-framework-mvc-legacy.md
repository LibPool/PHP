# puzzlout/framework-mvc-legacy

> 标签: Puzzlout, dev, easymvc, jl, web

## 简介

The Puzzlout framework to be used to build MVC websites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
