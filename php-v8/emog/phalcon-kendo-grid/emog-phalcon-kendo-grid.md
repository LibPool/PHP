# emog/phalcon-kendo-grid

> 标签: KendoGrid, phalcon, plugin

## 简介

KendoGrid Adapter for Phalcon Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
