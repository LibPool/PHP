# sobit/paylane

> 标签: paylane

## 简介

The original PayLane REST client optimized to be used with Composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://devzone.paylane.com/api-guide/
- 源码仓库：https://github.com/sobit/paylane.git
- Packagist 页面：https://packagist.org/packages/sobit%2Fpaylane
