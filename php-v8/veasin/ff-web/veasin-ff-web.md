# veasin/ff-web

> 标签: PHP

## 简介

Web middleware collection for ff — CORS, CSRF, gzip, JSON, logging, rate limiter, static file serving, and auth (Basic/Token/JWT/API Key)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
