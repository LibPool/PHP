# 3mad/fee-collection

> 标签: PHP

## 简介

Laravel package for fee collection with upcoming payments, invoices, receipts, wallet balance tracking, and optional PDF documents.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
