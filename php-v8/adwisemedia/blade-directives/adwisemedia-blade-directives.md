# adwisemedia/blade-directives

> 标签: blade, blade-directives, directives, roots, sage, wordpress

## 简介

A set of Blade directives for use with Roots Sage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
