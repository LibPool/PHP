# heidelpay/magento2-merchant-gateway

> 标签: magento, magento2, payment, payment-gateway, php

## 简介

This extension for Magento 2 provides a direct integration of the heidelpay payment types to your Magento 2 shop via the heidelpay merchant gateway (MGW).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
