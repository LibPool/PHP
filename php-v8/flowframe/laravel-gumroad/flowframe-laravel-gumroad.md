# flowframe/laravel-gumroad

> 标签: Flowframe, laravel, laravel-gumroad

## 简介

Perform actions on Gumroad sales like inviting customers to GitHub repositories, or creating licenses

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
