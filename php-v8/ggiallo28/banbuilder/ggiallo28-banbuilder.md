# ggiallo28/banbuilder

> 标签: filter, language, profanity, strings, swear

## 简介

Library to easily handle profanity filtering in PHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
