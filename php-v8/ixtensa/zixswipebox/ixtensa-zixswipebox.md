# ixtensa/zixswipebox

> 标签: contao, extension, mobile gallery, mobile gallery with swipe gestures, smartphone gallery, swipe gallery

## 简介

Smartphone gallery for Contao. Optimize Contao gallerys for smartphones/mobile devices and add swipe gestures.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
