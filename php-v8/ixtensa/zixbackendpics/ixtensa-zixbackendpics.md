# ixtensa/zixbackendpics

> 标签: Seite, background, contao, extension, hintergrundbild, image, page

## 简介

Enables you to add an image to every page's settings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
