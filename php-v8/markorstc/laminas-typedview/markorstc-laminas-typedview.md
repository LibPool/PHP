# markorstc/laminas-typedview

> 标签: laminas, typed, view

## 简介

Strongly typed view layer, as extension for Laminas MVC system, focused on easy code navigation and type hinting

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
