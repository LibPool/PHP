# utopia-php/schedule

> 标签: cron, framework, interval, php, schedule, scheduler, upf, utopia

## 简介

An opinionated scheduler that reconciles schedules from a source of truth and dispatches cron, interval, delayed and fixed-time occurrences without silently skipping a run

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
