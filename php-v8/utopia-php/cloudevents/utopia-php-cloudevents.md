# utopia-php/cloudevents

> 标签: cloudevents, framework, php, upf, utopia

## 简介

Lite & fast micro PHP CloudEvents implementation that is **easy to use**.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
