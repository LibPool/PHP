# utopia-php/swoole

> 标签: framework, http, php, server, swoole, upf, utopia

## 简介

An extension for Utopia Framework to work with PHP Swoole as a PHP FPM alternative

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
