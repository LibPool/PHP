# utopia-php/feed

> 标签: Streams, cloudevents, events, feed, framework, http-feeds, php, upf, utopia

## 简介

A simple library for publishing and consuming pull-based HTTP event feeds

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
