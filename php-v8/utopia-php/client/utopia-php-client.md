# utopia-php/client

> 标签: client, curl, http, php, psr-18, swoole, utopia

## 简介

A lightweight PSR-18 HTTP client with cURL and Swoole coroutine backends

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
