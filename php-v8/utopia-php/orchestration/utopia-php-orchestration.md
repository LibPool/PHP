# utopia-php/orchestration

> 标签: docker, framework, kubernetes, orchestration, php, swarm, upf, utopia

## 简介

Lite & fast micro PHP abstraction library for container orchestration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
