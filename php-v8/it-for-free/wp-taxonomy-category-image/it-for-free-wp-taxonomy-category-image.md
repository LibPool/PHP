# it-for-free/wp-taxonomy-category-image

> 标签: taxonomy categoty item image file, wordpress, wp

## 简介

Taxonomy Category Image Field Добавит возможность добавлять изображение к элементам таксономии

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
