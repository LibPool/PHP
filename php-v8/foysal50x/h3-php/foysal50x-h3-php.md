# foysal50x/h3-php

> 标签: Uber, ffi, geography, geospatial, gis, h3, hexagonal, indexing, spatial

## 简介

PHP FFI bindings for Uber's H3 hexagonal hierarchical geospatial indexing system

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
