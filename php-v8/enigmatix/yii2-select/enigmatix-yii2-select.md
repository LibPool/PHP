# enigmatix/yii2-select

> 标签: activefield, activeform, form, framework, select2, widget, yii2

## 简介

Yii2 wrapper for the Select2 javascript widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
