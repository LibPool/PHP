# syftnex/laravel-role-enums

> 标签: authorization, backed-enum, enum, laravel, roles

## 简介

Infrastructure to use PHP Backed Enums as roles in Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
