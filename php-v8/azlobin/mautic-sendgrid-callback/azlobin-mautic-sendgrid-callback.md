# azlobin/mautic-sendgrid-callback

> 标签: Mautic, plugin, sendgrid, webhook

## 简介

Mautic plugin to process SendGrid Event Webhook callbacks for bounce and complaint handling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
