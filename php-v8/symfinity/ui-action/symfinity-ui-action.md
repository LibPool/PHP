# symfinity/ui-action

> 标签: Forms, accessibility, html, http, symfinity, ux, validation

## 简介

Native HTTP action semantics validation (navigate, submit, delete, download)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
