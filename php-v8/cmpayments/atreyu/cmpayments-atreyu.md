# cmpayments/atreyu

> 标签: dependency injection, dependency injector container, dic, ioc

## 简介

Atreyu is a dependency injector for bootstrapping object-oriented PHP applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
