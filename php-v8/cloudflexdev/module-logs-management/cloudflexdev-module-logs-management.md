# cloudflexdev/module-logs-management

> 标签: logs, logs display, logs management, logs view, magento 2, magento 2 logs, magento logs management, magento2-extension, magento2-module, magento2-plugin

## 简介

A module for Magento 2 that allows you to view Magento logs in the admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
