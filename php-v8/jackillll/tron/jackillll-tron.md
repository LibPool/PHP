# jackillll/tron

> 标签: blockchain, cryptocurrency, dapp, jackillll, laravel, laravel-package, laravel-tron, smart-contracts, trc20, tron, tron-api, tron-lib, tron-php, tron-rest-api, trx, web3

## 简介

A PHP API for interacting with Tron (Trx) blockchain with Laravel integration - Based on iexbase/tron-api

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
