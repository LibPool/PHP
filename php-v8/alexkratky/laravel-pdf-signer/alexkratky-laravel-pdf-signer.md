# alexkratky/laravel-pdf-signer

> 标签: a1, certificate, icp brasil, laravel, sign, sign pdf, x509

## 简介

Sign PDF files with valid x509 certificates

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
