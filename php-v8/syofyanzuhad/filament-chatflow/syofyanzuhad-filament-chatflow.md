# syofyanzuhad/filament-chatflow

> 标签: filament-chatflow, laravel, syofyanzuhad

## 简介

A conversational chatbot flow builder plugin for Filament v4 with conditional logic and floating chat widget

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
