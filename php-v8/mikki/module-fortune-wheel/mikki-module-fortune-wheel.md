# mikki/module-fortune-wheel

> 标签: PHP

## 简介

Server-side Fortune Wheel for Magento newsletter subscribers. Magento picks the reward; the storefront only animates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
