# ripplesanalytics/ripples-php

> 标签: analytics, php, revenue, ripples, tracking

## 简介

Official PHP SDK for Ripples Metrics (ripples.sh): server-side event tracking

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
