# frenzy/turbolinks

> 标签: ajax, assets, javascript, larasset, laravel, pjax, turbolinks

## 简介

Frenzy Turbolinks makes following links in your web application faster with Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
