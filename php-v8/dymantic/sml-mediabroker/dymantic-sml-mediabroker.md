# dymantic/sml-mediabroker

> 标签: PHP

## 简介

Media broker fir dymantic/multilingual-posts that uses spatie/laravel-medialibrary

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
