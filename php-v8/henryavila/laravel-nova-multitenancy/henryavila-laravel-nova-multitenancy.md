# henryavila/laravel-nova-multitenancy

> 标签: henryavila, laravel, laravel-nova-multitenancy

## 简介

Integrate the multi tenancy single database in Laravel Nova.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
