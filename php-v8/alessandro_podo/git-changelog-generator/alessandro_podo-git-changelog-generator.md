# alessandro_podo/git-changelog-generator

> 标签: PHP

## 简介

Es ist möglich aus einem Git Commit anhand von metadaten ein Changelog zu generieren, dass Leserechte hat

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
