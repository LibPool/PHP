# mreep/multi-file-php-templates

> 标签: engine, multi-file, multiple, php, stubs, template

## 简介

A simple extendable PHP templating engine that allows you to use multiple files for your templates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
