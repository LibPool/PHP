# liyuze/method-chaining-proxy

> 标签: method chaining, method chaining proxy, php

## 简介

通过代理方式实现方法链式调用，消除控制语句对链式的影响。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
