# bajankristof/dumper

> 标签: dumper, var-dumper

## 简介

A dead simple PHP var dumper created for those who can not afford PHP 7.0+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
