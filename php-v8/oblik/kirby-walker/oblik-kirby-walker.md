# oblik/kirby-walker

> 标签: export, import, kirby, kirby-plugin, traverse, walk

## 简介

Kirby 3 plugin for exporting, importing, and iterating over site content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
