# oblik/kirby-git

> 标签: kirby, kirby-plugin

## 简介

Shows you Git changes in the Kirby panel and allows you to add/commit/push them, manually or automatically.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
