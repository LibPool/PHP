# toxor88/yii2-widget-fineuploader

> 标签: FineUploader, extension, yii2

## 简介

Enhanced Yii2 wrapper for the Fineuploader.js plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
