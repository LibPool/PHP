# toxor88/yii2-widget-switchery

> 标签: checkbox, extension, form, jquery, plugin, switchery, widget, yii2

## 简介

Enhanced Yii2 wrapper for the Switchery.js plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
