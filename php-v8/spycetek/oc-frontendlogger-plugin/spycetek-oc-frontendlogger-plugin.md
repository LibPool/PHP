# spycetek/oc-frontendlogger-plugin

> 标签: PHP

## 简介

This is an OctoberCMS plugin that helps developer to record frontend logs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
