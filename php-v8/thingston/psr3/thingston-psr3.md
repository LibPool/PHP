# thingston/psr3

> 标签: PSR3, aws, azure, azure-monitor, cloud-logging, cloudwatch, cloudwatch-logs, google-cloud, google-cloud-logging, log, logger, logging, monolog-alternative, papertrail, pdo, php, php8, psr-3, psr-log, rotating-file, slack, syslog, webhook

## 简介

A lightweight, dependency-free PSR-3 logger with pluggable local and cloud adapters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
