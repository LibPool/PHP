# icedream/composer-post-create-project-cmd-helper

> 标签: PHP

## 简介

Provides hook scripts to assist with base projects to further tweak instances set up from it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
