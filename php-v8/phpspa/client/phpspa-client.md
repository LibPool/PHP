# phpspa/client

> 标签: SPA, php, phpspa, starter, vite

## 简介

PhpSPA + Vite + Tailwind starter project that mixes PhpSPA pages with hydrated client navigation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
