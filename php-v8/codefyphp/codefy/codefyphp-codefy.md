# codefyphp/codefy

> 标签: application, codefy, codefy-php, codefyphp, container, framework, php-framework, routing

## 简介

PHP framework for Domain Driven Development, CQRS, and Event Sourcing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
