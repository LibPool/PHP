# codefyphp/skeleton

> 标签: Skeleton, codefy, codefy-php, codefyphp, routing

## 简介

Skeleton package for creating a new CodefyPHP Framework project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
