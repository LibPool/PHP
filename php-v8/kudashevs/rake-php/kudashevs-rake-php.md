# kudashevs/rake-php

> 标签: Rapid Automatic Keyword Extraction, extract keywords, keywords, php, rake

## 简介

A PHP implementation of the Rapid Automatic Keyword Extraction (RAKE) algorithm.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
