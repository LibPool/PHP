# kudashevs/laravel-parsedown

> 标签: laravel, markdown, parsedown

## 简介

A Laravel Parsedown wrapper that converts Mardown text into HTML.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
