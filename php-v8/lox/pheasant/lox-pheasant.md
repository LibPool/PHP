# lox/pheasant

> 标签: 99designs, activerecord, datamapper, mysql, orm

## 简介

A lightweight data mapper for MySQL and PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
