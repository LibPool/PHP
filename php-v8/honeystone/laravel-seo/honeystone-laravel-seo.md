# honeystone/laravel-seo

> 标签: JSON-LD, honeystone, laravel, metadata, opengraph, seo, twitter

## 简介

SEO metadata and JSON-LD package for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
