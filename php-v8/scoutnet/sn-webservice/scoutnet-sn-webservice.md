# scoutnet/sn-webservice

> 标签: Pfadfinder, ScoutNet, ScoutNet API

## 简介

This class is needed to comunicate with the scoutnet.de server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
