# shipfast/live-edit

> 标签: cms, in-place-editing, laravel, live-edit, nextjs, react, static-site, wordpress

## 简介

ShipFast Live Edit: in-place editing for sites that are already built, on Laravel, WordPress, Next.js, React or plain HTML. Tag the elements; the people who own the site edit text, images, links, icons, styles and lists on the page itself.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
