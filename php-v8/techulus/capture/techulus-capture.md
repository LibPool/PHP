# techulus/capture

> 标签: capture, content extraction, pdf, screenshot, web scraping

## 简介

Official PHP SDK for Capture (capture.page). Capture screenshots, generate PDFs, extract content and metadata from web pages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 源码仓库：https://github.com/techulus/capture-php.git
