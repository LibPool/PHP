# mozzy/php-connector

> 标签: error-reporting, monitoring, mozzy, observability

## 简介

Privacy-first Mozzy Connector Protocol v1 reporting for generic PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
