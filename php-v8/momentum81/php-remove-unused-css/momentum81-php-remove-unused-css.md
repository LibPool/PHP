# momentum81/php-remove-unused-css

> 标签: momentum81, php-remove-unused-css

## 简介

PHP Remove Unused CSS is a tool to remove unused CSS from your website using PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
