# motaword/sdk

> 标签: MotaWord API, api, automation, collaborative, human, localization, sdk, translation

## 简介

Use MotaWord API to post and track your translation projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
