> 标签: dynamic-notifications, flash-notifications, laravel, laravel-toastr, livewire, livewire-toaster, magic, notifications, php, toaster, toastr

## 简介

Laravel Toaster Magic is a lightweight, flexible toast library for Laravel projects, with no jQuery, Bootstrap, or Tailwind dependency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
