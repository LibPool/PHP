# hda-ppl/hda-rights-management-group-type

> 标签: backend, groups, rights, typo3

## 简介

TYPO3 14.3 group type layer for PPL Rights Management that classifies backend groups as people or rights groups without changing TYPO3 permissions.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
