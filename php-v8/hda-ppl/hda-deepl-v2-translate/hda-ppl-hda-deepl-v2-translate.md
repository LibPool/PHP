# hda-ppl/hda-deepl-v2-translate

> 标签: TYPO3 CMS, backend, deepl, file translation, frontend, translation

## 简介

TYPO3 14.3 extension for DeepL V2 text and file translation in frontend plugins and backend modules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
