# hunglv-fs/laravel5-telescope

> 标签: debugbar, debugging, laravel, laravel5, legacy, n-plus-one, profiler, queue, telescope

## 简介

Telescope for Laravel 5.0: requests, queries, queue jobs, artisan commands, exceptions, logs, cache and an N+1 report, for legacy apps that cannot run laravel/telescope.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
