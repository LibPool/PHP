# muffin/github

> 标签: api, cakephp, github, muffin, webservice

## 简介

Github Webservice (API) for CakePHP 3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/usemuffin/github
- 源码仓库：https://github.com/UseMuffin/Github.git
- Packagist 页面：https://packagist.org/packages/muffin%2Fgithub
