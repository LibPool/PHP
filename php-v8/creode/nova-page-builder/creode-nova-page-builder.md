# creode/nova-page-builder

> 标签: creode, laravel, nova-page-builder

## 简介

Exposes a simple customisable page builder in Laravel Nova, built on top of Flexible Content fields.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
