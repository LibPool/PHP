# creode/laravel-nova-assets

> 标签: creode, laravel, laravel-nova-assets

## 简介

Takes the existing Laravel Assets module and adds functionality to make it work in Nova.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
