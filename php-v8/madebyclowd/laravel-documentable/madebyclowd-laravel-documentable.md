# madebyclowd/laravel-documentable

> 标签: document, documentable, laravel, minio, multipart, r2, s3, storage, versioning

## 简介

Customizable, S3-compatible-first document storage for Laravel — dedup, versioning, multipart uploads, orphan cleanup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
