# wildwolf/wp-yubico-otp

> 标签: 2fa, Authentication, otp, plugin, security, wordpress, yubico

## 简介

WordPress plugin to provide support for the Yubico OTP authentication

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
