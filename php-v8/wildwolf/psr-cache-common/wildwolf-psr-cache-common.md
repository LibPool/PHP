# wildwolf/psr-cache-common

> 标签: PHP

## 简介

Common classes for wildwolf/* PSR-6 and PSR-16 compliant caches

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
