# wildwolf/wp-disable-browse-happy

> 标签: browse-happy, browsehappy, plugin, privacy, wordpress

## 简介

WordPress plugin to disable calls to the BrowseHappy API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
