# wildwolf/psr-memory-cache

> 标签: cache, memory cache, psr16, psr6

## 简介

PSR-6 and PSR-16 compliant memory cache

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
