# wildwolf/ww-remove-jquery-migrate

> 标签: jquery, jquery migrate, plugin, wordpress

## 简介

WordPress plugin to remove jQuery Migrate from jQuery dependencies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
