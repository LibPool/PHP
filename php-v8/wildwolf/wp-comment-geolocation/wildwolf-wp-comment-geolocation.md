# wildwolf/wp-comment-geolocation

> 标签: comments, geolocation, plugin, wordpress

## 简介

A WordPress plugin to add "IP Geolocation" column to "Manage Comments" screen

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
