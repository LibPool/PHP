# clearissylius/invoicing-plugin

> 标签: CIF, NIF, invoice, invoicing, iva, libro-registro, pdf, spain, sylius, sylius-plugin, vat

## 简介

Full Sylius 2 invoicing replacement: configurable PDF templates, per-channel numbering, Spanish NIF/CIF on addresses, rectifying invoices, libro registro Excel export and migration from sylius/invoicing-plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
