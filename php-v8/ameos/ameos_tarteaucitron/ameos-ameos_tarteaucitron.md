# ameos/ameos_tarteaucitron

> 标签: Tarte Au Citron, cms, gdpr, typo3

## 简介

Integrates tarteaucitron.js in TYPO3 (see : https://opt-out.ferank.eu )

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
