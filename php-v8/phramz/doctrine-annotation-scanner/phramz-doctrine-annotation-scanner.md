# phramz/doctrine-annotation-scanner

> 标签: annotation, doctrine, scanner

## 简介

library to scan files and folders for annotated classes using doctrine annotations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
