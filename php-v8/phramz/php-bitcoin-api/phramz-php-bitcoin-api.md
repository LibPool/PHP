# phramz/php-bitcoin-api

> 标签: api, bitcoin, json-rpc, php

## 简介

PHP implementation of the bitcoind JSON-RPC API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
