# phramz/staticfiles-middleware

> 标签: StackPHP, middleware, stack, staticfiles, webserver

## 简介

This library will serve static files from a local directory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
