# rurounize/laminas-flash-noty-messenger

> 标签: flashmessenger, js-noty, laminas, notifications

## 简介

View Helper for beautiful JS notifications for Laminas.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
