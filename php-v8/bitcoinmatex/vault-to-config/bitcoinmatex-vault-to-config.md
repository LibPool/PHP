# bitcoinmatex/vault-to-config

> 标签: PHP

## 简介

Nette CLI app: renders a Latte configuration template using secrets from HashiCorp Vault and generates NEON for deployment.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
