# kingson-de/marshal-serializer

> 标签: Marshal, deserialization, deserializer, json, mappers, marshalling, serialization, serializer, unmarshalling, xml

## 简介

Marshal is serializing / marshalling data structures to a format that can be used to build messages for transferring data through the wires.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
