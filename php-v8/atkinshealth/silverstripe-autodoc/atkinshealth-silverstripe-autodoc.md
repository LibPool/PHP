# atkinshealth/silverstripe-autodoc

> 标签: orm, silverstripe

## 简介

Automatically generate PHPDoc comments for DataObject subclasses based on fields and relations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
