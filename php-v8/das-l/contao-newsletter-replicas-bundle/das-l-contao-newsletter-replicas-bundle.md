# das-l/contao-newsletter-replicas-bundle

> 标签: PHP

## 简介

Insert newsletters as references across multiple mailing lists so you don't have to insert and edit the same newsletter data multiple times

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
