# kauffinger/livewire-chat-kit

> 标签: chat, fluxui, laravel, livewire, llms, prism

## 简介

A clean streamed chat kit for Laravel Livewire. Built with FluxUI & Prism.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
