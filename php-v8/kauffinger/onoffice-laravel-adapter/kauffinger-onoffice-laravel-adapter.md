# kauffinger/onoffice-laravel-adapter

> 标签: kauffinger, laravel, onoffice-laravel-adapter

## 简介

A joyful way to interact with the onOffice API using Laravel and Saloon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
