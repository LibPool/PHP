# blockshiftnetwork/chat-markdown-converter

> 标签: BlockshiftNetwork, ChatGpt, ai, chat, chat-markdown-converter, discord, instagram, laravel, llm, markdown, php, slack, telegram, whatsapp

## 简介

Convert AI-generated Markdown to WhatsApp, Telegram, Discord, Slack and Instagram compatible formats using an Intermediate Representation (IR).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
