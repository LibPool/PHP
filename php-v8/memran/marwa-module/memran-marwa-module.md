# memran/marwa-module

> 标签: Marwa, PSR-11, discovery, modules, php

## 简介

Framework-agnostic, PSR-11 friendly module management library for PHP apps (Marwa ecosystem compatible).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
