# memran/php-testify

> 标签: BDD, TDD, expect, jest, php, phpunit, test, testing, vitest, watch

## 简介

Expressive PHP testing on top of PHPUnit with expect() assertions, describe()/it() specs, and watch mode.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
