# memran/marwa-db

> 标签: PHP

## 简介

Lightweight, framework-agnostic PHP database toolkit: connections, query builder, ORM, schema, migrations, seeders, debug panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
