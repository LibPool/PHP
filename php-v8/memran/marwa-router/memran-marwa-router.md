# memran/marwa-router

> 标签: league-route, php8-attributes, psr-15, psr-16, psr-7, router, routing

## 简介

Attribute + fluent routing over league/route with PSR-7/15/16 support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
