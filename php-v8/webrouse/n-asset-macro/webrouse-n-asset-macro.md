# webrouse/n-asset-macro

> 标签: PHP

## 简介

Asset macro for Latte and Nette Framework useful for assets cache busting (with gulp, webpack, etc.)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
