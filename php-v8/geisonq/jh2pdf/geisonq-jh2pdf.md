# geisonq/jh2pdf

> 标签: dompdf, html-to-pdf, pdf, pdf-generation, puppeteer-alternative, shared-hosting, wkhtmltopdf-alternative

## 简介

Pixel-perfect HTML to PDF in PHP without a browser on the server: the user's browser measures the layout, PHP only draws the PDF. No headless Chrome, runs on shared hosting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
