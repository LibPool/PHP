# wiserobot/module-iomnic

> 标签: PHP

## 简介

WiseRobot iOmniC provides near real-time connectivity to multiple platforms (Rithum, Magento 2, etc.)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
