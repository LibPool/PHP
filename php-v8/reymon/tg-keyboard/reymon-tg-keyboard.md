# reymon/tg-keyboard

> 标签: Telegram-API, api, bot, builder, keyboard, madelineproto, mtproto, telegram

## 简介

An easy keyboard builder for Telegram Api & Mtproto syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
