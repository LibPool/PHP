# stobys/laravel-crafter

> 标签: laravel-crafter, stobys

## 简介

Convinient way to generate all files for new model (model, controller, views, routes, migration, seeder, etc)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
