# remcosmitsdev/buildable-serializer-bundle

> 标签: PHP

## 简介

An OPT-in performance boost for the symfony serializer component. By moving runtime overhead to buildtime.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
