# flyhjaelp/gmail2laravel

> 标签: gmail2laravel, laravel

## 简介

A Laravel package to help manage multiple Gmail Clients on the same platform.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
