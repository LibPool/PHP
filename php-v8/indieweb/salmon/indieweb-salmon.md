# indieweb/salmon

> 标签: indieweb, magic signatures, ostatus, salmon

## 简介

A set of PSR-0 autoloadable classes for dealing with the Salmon protocol and magic signatures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
