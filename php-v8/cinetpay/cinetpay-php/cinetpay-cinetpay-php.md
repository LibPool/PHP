# cinetpay/cinetpay-php

> 标签: cinetpay, integration, mobile, money

## 简介

easily integrate cinetpay's gateway on your php web site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
