# jonbaldie/explicitness-checker

> 标签: code-quality, explicitness, functional-programming, implicit-dependencies, php, static-analysis

## 简介

A tool to analyze explicitness of PHP code (implicit inputs/outputs).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
