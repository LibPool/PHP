# hbvsoft/jpgraph

> 标签: chart, data, graph, jpgraph, pie

## 简介

Composer Friendly, full refactor of JpGraph, library to make graphs and charts - PHP 8.2 compatible, deprecated removed

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
