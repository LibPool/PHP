# ev-soft/clever-html-engine

> 标签: form-builder, frontend, html, html-generator, i18n, named-arguments, php2html, php8, tables, ui-components

## 简介

php2html: build HTML5 pages, forms, tables and cards with PHP 8 functions - translation, hints, themes and CSRF built in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
