# web-vision/ai-llms-txt

> 标签: Policy, ai, cms, crawling, llm, typo3

## 简介

TYPO3 extension for generating .well-known/llm.txt links according to llmstxt.org specification

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
