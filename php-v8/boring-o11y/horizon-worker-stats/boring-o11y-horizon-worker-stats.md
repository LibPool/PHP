# boring-o11y/horizon-worker-stats

> 标签: CPU, horizon, laravel, memory, queue, redis, workers

## 简介

Worker memory and CPU charts for the Laravel Horizon dashboard: what your whole worker fleet is using, over the last day.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
