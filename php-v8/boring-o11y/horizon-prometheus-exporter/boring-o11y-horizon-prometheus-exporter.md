# boring-o11y/horizon-prometheus-exporter

> 标签: Metrics, grafana, horizon, laravel, prometheus, queue, redis

## 简介

A Prometheus scrape endpoint for Laravel Horizon: per-queue and per-job-class counters, queue depth, wait and worker gauges, with a matching Grafana dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
