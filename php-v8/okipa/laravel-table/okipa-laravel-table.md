# okipa/laravel-table

> 标签: generate, generation, generator, html, laravel, laravel-table, list, livewire, okipa, package, php, table

## 简介

Generate tables from Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
