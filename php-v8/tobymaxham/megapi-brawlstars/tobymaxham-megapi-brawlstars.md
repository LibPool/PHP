# tobymaxham/megapi-brawlstars

> 标签: brawlstars, tobymaxham, zhylon

## 简介

This package can be used to interact with the MegAPI and the Brawl Stars API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
