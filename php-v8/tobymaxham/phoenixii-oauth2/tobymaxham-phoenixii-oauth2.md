# tobymaxham/phoenixii-oauth2

> 标签: oauth, phoenix-oauth, tobymaxham

## 简介

A Package to use the OAuth2 API from PhoenixII.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
