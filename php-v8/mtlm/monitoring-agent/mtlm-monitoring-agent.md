# mtlm/monitoring-agent

> 标签: Metrics, api-monitoring, laravel, monitoring, mtl-monitoring-agent, performance, request-monitoring, request-tracker, server-monitoring, uptime

## 简介

Laravel server monitoring agent for collecting request performance, status, memory, and endpoint metrics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
