# artflow-studio/uploader

> 标签: alpine, cropper, image, laravel, livewire, upload, uploader

## 简介

A Livewire file uploader with a built-in image editor, client-side re-encoding and per-instance isolation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
