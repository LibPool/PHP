# artflow-studio/tenancy

> 标签: database, enterprise, isolation, laravel, livewire, multi-tenancy, saas, tenancy

## 简介

Enterprise-grade standalone Laravel multi-tenancy package for Laravel 12 — domain-based isolation, Livewire 3 integration, and zero stancl/tenancy dependency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
