# artflow-studio/accountflow

> 标签: Accounting, bookkeeping, finance, laravel, ledger, livewire, reports, transactions

## 简介

A complete, drop-in accounting module for Laravel — accounts, transactions, transfers, budgets, assets, loans, equity and financial reports, with Livewire 4 UI and AFTable listings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
