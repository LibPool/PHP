# artflow-studio/pwa

> 标签: asset-optimization, caching, csrf, laravel, livewire, mobile, offline, performance, progressive-web-app, pwa, service-worker, session-management, webapp

## 简介

A comprehensive Progressive Web Application package for Laravel with advanced session handling, CSRF protection, dynamic routing, and configurable asset caching

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
