# mosuka/litsea

> 标签: extension, nlp, pos, segmentation, tokenizer, word

## 简介

PHP extension for Litsea, a compact word segmentation and POS tagging library (no embedded models)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
