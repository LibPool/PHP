# pranil-joshi/module-currency-converter

> 标签: PHP

## 简介

Magento 2 storefront module: a currency exchange converter backed by the Frankfurter API, with live rate lookup and historical charting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
