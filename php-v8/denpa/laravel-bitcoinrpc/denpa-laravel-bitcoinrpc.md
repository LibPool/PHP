# denpa/laravel-bitcoinrpc

> 标签: Guzzle, api, bitcoin, jsonrpc, laravel

## 简介

Bitcoin JSON-RPC Service Provider for Laravel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
