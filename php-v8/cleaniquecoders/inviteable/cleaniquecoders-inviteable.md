# cleaniquecoders/inviteable

> 标签: Invitation, Invite, laravel, package, polymorphic

## 简介

A polymorphic invitation system for Laravel. Any Eloquent model can have invitations.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
