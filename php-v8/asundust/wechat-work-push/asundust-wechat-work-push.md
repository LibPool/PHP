# asundust/wechat-work-push

> 标签: extension, laravel-admin, push, wechat, work

## 简介

利用企业微信应用消息向微信发送通知(无需公众号，不需要安装企业微信客户端，低成本推送消息解决方案)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
