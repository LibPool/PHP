# asundust/dcat-auth-captcha

> 标签: auth, auth captcha, captcha, dcat-admin, extension, login, multiple platform, sliding captcha

## 简介

Sliding captcha for Dcat-Admin auth, Multiple platform support / Dcat-Admin登陆 (滑动)验证插件 多平台支持

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
