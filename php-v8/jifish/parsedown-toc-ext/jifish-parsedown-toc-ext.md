# jifish/parsedown-toc-ext

> 标签: TOC, markdown, parsedown, table-of-contents

## 简介

TOC extension for parsedown and parsedown-extra with automatic heading IDs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
