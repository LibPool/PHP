# xgc1986/finalizer

> 标签: code quality, final, syntax

## 简介

A simple utility library that checks for PHP classes that should or shouldn't be marked as final

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
