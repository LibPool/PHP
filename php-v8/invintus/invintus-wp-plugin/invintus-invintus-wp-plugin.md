# invintus/invintus-wp-plugin

> 标签: PHP

## 简介

Official Invintus plugin for embedding live and on-demand video from Invintus Media Platform.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
