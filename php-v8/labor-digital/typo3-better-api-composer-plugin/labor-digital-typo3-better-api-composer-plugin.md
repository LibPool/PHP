# labor-digital/typo3-better-api-composer-plugin

> 标签: PHP

## 简介

TYPO3: Provides a global auto-loader hook which runs before TYPO3's class alias loader

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
