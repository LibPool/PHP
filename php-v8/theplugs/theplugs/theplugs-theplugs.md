# theplugs/theplugs

> 标签: fast, framework, mvc, php, plugs

## 简介

ThePlugs Framework is a modern, lightweight PHP framework by Amisu Usman (Celio Natti) - built for developers who crave speed, structure, and freedom. Its modular design and intuitive syntax make web development faster, cleaner, and more connected - your power source for smart PHP projects. ⚡

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
