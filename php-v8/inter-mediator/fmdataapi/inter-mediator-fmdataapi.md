# inter-mediator/fmdataapi

> 标签: FileMaker, INTER-Mediator, api, rest

## 简介

FMDataAPI is the class library in PHP for accessing FileMaker database with FileMaker Data API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
