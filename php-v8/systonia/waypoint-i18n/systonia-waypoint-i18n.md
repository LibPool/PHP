# systonia/waypoint-i18n

> 标签: PHP

## 简介

Translations and per-request locale for Waypoint: catalogs, {placeholder} and plural messages, $this->t() in views, translated validation errors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
