# marcocesarato/php-conventional-changelog

> 标签: changelog, commit, commits, convention, conventional, conventional-changelog, conventional-changelog-preset, conventional-commit, conventional-commits, conventionalcommits, generation, git, history, php, readme, tag

## 简介

Generate changelogs and release notes from a project's commit messages and metadata and automate versioning with semver.org and conventionalcommits.org

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
