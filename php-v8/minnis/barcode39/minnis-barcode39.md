# minnis/barcode39

> 标签: CODE 39, barcode image, barcode scan, barcode39, barcodes, base64, code_39, gif, jpg, png, print barcodes, scancode

## 简介

The Barcode Code_39 Generator provides a lightweight easy-to-use class to generate Code 39 barcodes in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
