# opilo/webservice

> 标签: Laravel SMS Driver, Opilo, messaging, sms, web service

## 简介

This is a client of Opilo (www.opilo.com) Web Service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
