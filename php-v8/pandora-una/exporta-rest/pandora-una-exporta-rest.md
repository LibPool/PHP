# pandora-una/exporta-rest

> 标签: apigility, csv, framework, pandora, pdf, rest, zf2

## 简介

Exporta para CSV e PDF resultados rest do APIGILITY

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
