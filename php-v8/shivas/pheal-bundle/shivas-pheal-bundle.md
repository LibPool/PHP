# shivas/pheal-bundle

> 标签: EVE API, EVE Online, Pheal

## 简介

pheal/pheal wrapper/factory bundle for use with Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
