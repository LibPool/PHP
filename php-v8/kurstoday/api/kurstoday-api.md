# kurstoday/api

> 标签: API для получения курсов валют, История курсов валют, Курс валют API, Курс валют в банках Украины, Курс валют на сайт

## 简介

Бесплатный API клиент для получения курсов валют из сайта https://kurstoday.com/

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
