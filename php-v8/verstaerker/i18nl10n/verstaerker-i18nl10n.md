# verstaerker/i18nl10n

> 标签: i18n, isotope, l10n, language, multilingual

## 简介

The simplest way to create and manage multi-language sites with Contao.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
