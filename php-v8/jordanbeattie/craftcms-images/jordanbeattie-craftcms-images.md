# jordanbeattie/craftcms-images

> 标签: Craft, cms, craft-plugin, craftcms

## 简介

Render images in craftcms with optimized template tags

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
