# kainiklas/filament-scout

> 标签: filament, filament-scout, filamentphp, kainiklas, laravel

## 简介

Filament Plugin to integrate Scout into Global Search and Table Search.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
