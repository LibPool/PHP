# hyperf-plus/route

> 标签: annotation, api, hyperf, hyperf-plus, php, route

## 简介

HPlus 路由增强组件 - 提供强大的路由注解系统，支持自动路由注册和参数验证

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
