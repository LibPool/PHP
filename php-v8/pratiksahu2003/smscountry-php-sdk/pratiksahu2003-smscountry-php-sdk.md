# pratiksahu2003/smscountry-php-sdk

> 标签: bulk-sms, laravel, messaging, php, sms, smscountry

## 简介

Official-style PHP SDK for SMS Country bulk SMS API. Works with plain PHP, Laravel, Symfony, and any PHP framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
