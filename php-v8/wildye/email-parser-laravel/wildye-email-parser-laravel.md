# wildye/email-parser-laravel

> 标签: email, inbound, laravel, parser, webhook

## 简介

Laravel integration for GhostParse: a verified webhook route that turns inbound email into Laravel events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
