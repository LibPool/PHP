# honestlydesign/etch-builders

> 标签: blocks, builder, etch, gutenberg, wordpress

## 简介

Builder API for serializing Etch blocks, styles, and dynamic data.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
