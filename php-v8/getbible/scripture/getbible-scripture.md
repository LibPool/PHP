# getbible/scripture

> 标签: SWORD, bible, crosswire, getbible, joomla, scripture

## 简介

Validated, lazy Bible objects backed by CrossWire SWORD modules

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
