# forgeomni/superagent

> 标签: Agent, ai, anthropic, cli, laravel, llm, tool-use

## 简介

AI Agent SDK — standalone CLI or Laravel integration. Run the full agentic loop in-process with tool use support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
