# lizhijun/php-totp

> 标签: otp, rfc6238, security, totp

## 简介

基于时间的一次一密(Time-based One-time Password, TOTP)算法php函数库

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
