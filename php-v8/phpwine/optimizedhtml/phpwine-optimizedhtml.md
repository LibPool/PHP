# phpwine/optimizedhtml

> 标签: html, optimizer, phplibrary

## 简介

HTML Frontend Framework Design for backend OptimizedHTML PHPWine written in PHP (Hypertext Preprocessor)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
