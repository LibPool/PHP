# beaconbox/beaconbox-php

> 标签: beaconbox, eu, notifications, sms, transactional, whatsapp

## 简介

Official PHP SDK for BeaconBox, order updates your customers actually receive.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
