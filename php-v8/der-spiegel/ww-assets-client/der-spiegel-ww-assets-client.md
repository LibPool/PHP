# der-spiegel/ww-assets-client

> 标签: PHP

## 简介

PHP client for the WoodWing Assets (formerly: Elvis DAM) system https://www.woodwing.com/en/products/woodwing-assets

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
