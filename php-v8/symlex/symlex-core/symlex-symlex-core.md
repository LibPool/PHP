# symlex/symlex-core

> 标签: dependency injection, kernel, micro-framework, performance, rest, router, symfony

## 简介

Minimalistic Kernel and Routers based on Symfony Components

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
