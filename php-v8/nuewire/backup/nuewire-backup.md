# nuewire/backup

> 标签: backup, database-backup, filesystem, laravel, livewire, spatie

## 简介

Database and full file-storage backups for the Nuewire platform using Spatie Laravel Backup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
