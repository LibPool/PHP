# nuewire/acl

> 标签: acl, laravel, livewire, permissions, roles, spatie

## 简介

Optional roles and permissions UI for Nuewire users, powered by spatie/laravel-permission.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
