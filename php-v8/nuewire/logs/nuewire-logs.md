# nuewire/logs

> 标签: activity-log, audit-trail, laravel, livewire, request-log, system-log

## 简介

Platform audit trails, HTTP request logs, and Laravel system log viewer for Nuewire.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
