# systemseed/simplesamlphp-module-rollbar

> 标签: logger, rollbar, simplesamlphp

## 简介

A SimpleSAMLphp module adding support for Rollbar logger handler.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
