# felipemateus/iptv-channels

> 标签: IPTV, IPTVCHannels, channel, channels, channels-list, channels-m3u8, iptv-channels, iptv-laravel, iptv-playlist, laravel, laravel-package, m3u8, m3u8-iptv, playlist

## 简介

This package controls the IPTV channel list and generates an m3u8 file using laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
