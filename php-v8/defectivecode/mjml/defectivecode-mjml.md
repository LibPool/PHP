# defectivecode/mjml

> 标签: PHP

## 简介

Compile MJML to responsive HTML emails directly in PHP without requiring Node.js. Wraps the official MJML engine with full Laravel integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
