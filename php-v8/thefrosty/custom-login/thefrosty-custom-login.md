# thefrosty/custom-login

> 标签: PHP

## 简介

A simple way to customize your WordPress <code>wp-login.php</code> screen! A <a href="https://frosty.media/">Frosty Media</a> plugin.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
