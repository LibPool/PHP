# sujanshresthanet/esewa-php-sdk

> 标签: api, esewa, gateway, nepal, payment, php

## 简介

eSewa payment gateway integration in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
