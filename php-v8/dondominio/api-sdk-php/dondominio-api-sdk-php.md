# dondominio/api-sdk-php

> 标签: api, domain, dondominio, mrdomain, sdk

## 简介

DonDominio/MrDomain API SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
