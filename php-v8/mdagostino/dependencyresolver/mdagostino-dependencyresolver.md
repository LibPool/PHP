# mdagostino/dependencyresolver

> 标签: PHP

## 简介

Generic dependency resolver. Returns a flat array of components to load them respecting their dependencies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
