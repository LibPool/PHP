# sbrendtro/yii2-sendgrid

> 标签: sendgrid, yii2, yii2 mailer, yii2 sendgrid, yii2 sendgrid mailer

## 简介

Yii2 Mailer extension for SendGrid with batch mailing support. This extension is based on wadeshuler/yii2-sendgrid, with small adaptations

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
