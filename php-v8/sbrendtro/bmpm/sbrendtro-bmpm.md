# sbrendtro/bmpm

> 标签: PHP

## 简介

Beider-Morse Phonetic Matching (BMPM) algorithm, with an object-oriented interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
