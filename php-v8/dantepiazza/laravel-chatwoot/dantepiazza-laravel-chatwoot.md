# dantepiazza/laravel-chatwoot

> 标签: PHP

## 简介

Laravel integration for Chatwoot – webhook routing, bot workflow engine and Chatwoot API helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
