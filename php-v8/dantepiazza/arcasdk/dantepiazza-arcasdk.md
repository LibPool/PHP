# dantepiazza/arcasdk

> 标签: afip, arca, cae, contribuyente, factura-electronica, free, padron

## 简介

Librería independiente para Web Services de ARCA (ex AFIP). Fork libre de limitaciones.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
