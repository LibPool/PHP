# ytubes/facades

> 标签: facade, facades, laravel, yii, yii2, yii2-facades

## 简介

Laravel like facades support for Yii 2 application components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
