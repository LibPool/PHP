# jakreiter/recaptcha2-bundle-proxyable

> 标签: form, recaptcha, symfony

## 简介

Provide Google Recaptch2 form type with ability to use proxy to comunicate with Google server

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
