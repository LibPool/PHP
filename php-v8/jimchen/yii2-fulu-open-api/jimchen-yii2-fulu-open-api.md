# jimchen/yii2-fulu-open-api

> 标签: PHP

## 简介

福禄开放平台API，是福禄开放平台对外提供的安全、低成本、高可靠的虚拟充值服务。用户可以通过调用API，在任何应用、任何时间、任何地点采购虚拟商品，也可以通过用户Web控制台对数据进行简单的管理。适合各种网站、开发企业及开发者使用。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
