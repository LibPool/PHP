# infusionweb/laravel-robots-route

> 标签: laravel, robots.txt, route

## 简介

A route for serving a basic robots.txt in Laravel 5.1+, based on configuration settings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
