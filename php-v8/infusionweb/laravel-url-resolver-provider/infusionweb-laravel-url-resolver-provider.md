# infusionweb/laravel-url-resolver-provider

> 标签: PhpUrlResolver, URLResolver, laravel

## 简介

Provides a Laravel 5 service provider and facade for URLResolver.php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
