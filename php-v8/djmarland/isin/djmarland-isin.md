# djmarland/isin

> 标签: 6166, ISIN, iso 6166, iso6166

## 简介

A PHP Library for storing a validating an ISIN (International Securities Identification Number / ISO 6166)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
