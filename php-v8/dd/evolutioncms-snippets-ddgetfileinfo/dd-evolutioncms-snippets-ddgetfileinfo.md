# dd/evolutioncms-snippets-ddgetfileinfo

> 标签: MODX Evo, dd group, dd studio, ddgetfileinfo, divandesign, evo, evo cms, evolution cms, evolutioncms, file extension, file info, file mime, file size, file size in human format, file size in mb, file type, get file info, human readable file size, modx, modx evolution, readable file size

## 简介

Displays information about a file: type, mime, size in readable format, path, name, extension, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
