# dd/evolutioncms-snippets-ddgetchunk

> 标签: MODX Evo, dd group, dd studio, ddgetchunk, divandesign, evo, evo cms, evolution cms, evolutioncms, get chunk, modx, modx evolution, parse chunk

## 简介

Snippet gets the chunk contents by its name. For example, it useful to get chunks inside JS code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
