# itliusha/blade-quicksand-icons

> 标签: blade, laravel, quicksand

## 简介

这是一个可以轻松在 Laravel blade 里轻松使用  quicksand-icons 图标库的 Laravel 包

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
