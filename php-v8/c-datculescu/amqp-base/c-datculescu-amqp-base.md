# c-datculescu/amqp-base

> 标签: AMQP, message-bus, rabbitmq

## 简介

Allows easy declaration and management of complex AMQP configurations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
