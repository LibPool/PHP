# danieltoader/php-crypttor

> 标签: PHP

## 简介

A simple php library to deal with encrypting and decrypting strings using OpenSSL or MCrypt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
