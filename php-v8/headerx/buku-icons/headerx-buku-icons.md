# headerx/buku-icons

> 标签: blade, buku-icons, headerx, icons, laravel, svg

## 简介

# Installs over 50,000 icons. From https://blade-ui-kit.com/blade-icons

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
