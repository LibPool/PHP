# noraitec/filament-flatpickr-plugin

> 标签: PHP

## 简介

Plugin de Filament que integra Flatpickr con soporte completo para su API y configuración avanzada de calendario.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
