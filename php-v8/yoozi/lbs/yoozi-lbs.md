# yoozi/lbs

> 标签: LBS, baidu, geocoding, golem, place, yoozi

## 简介

百度 LBS WEB 服务 API 的 PHP 封装实现.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
