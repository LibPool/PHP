# daedaloslabs/filament-shelly

> 标签: filament, filament-plugin, iot, laravel, sensors, shelly, widgets

## 简介

Show live Shelly Cloud sensor stats (temperature, humidity, power, door/window, custom) on any Filament page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
