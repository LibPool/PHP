# simialbi/opening-hours

> 标签: hours, opening, opening-hours, schedule, spatie

## 简介

A helper to query and format a set of opening hours based on Opening hours by spatie

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
