# pledg/sylius-payment-plugin

> 标签: payment, pledg, sylius, sylius-plugin

## 简介

Payment Gateway Plugin using PledgBySofinco (Sylius 2.x)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
