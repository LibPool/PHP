# busyphp/workflow

> 标签: state machine, workflow, 工作流, 状态机

## 简介

基于BusyPHP实现的工作流状态机，开发人员只需要简单配置即可实现复杂的状态流程转换

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
