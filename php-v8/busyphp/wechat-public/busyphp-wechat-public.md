# busyphp/wechat-public

> 标签: 公众号, 微信公众号

## 简介

用于BusyPHP微信公众号管理，支持菜单、自动回复简单管理以及各种公众号事件预设

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
