# busyphp/sms

> 标签: 短信发送, 短信验证码

## 简介

支持短信验证码发送、验证，支持发送提醒短信、营销短信等，整合了主流的短信接口，如：腾讯云、阿里云等

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
