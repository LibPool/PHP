# busyphp/oauth

> 标签: oauth2.0, 三方登录

## 简介

用于BusyPHP进行OAuth2.0三方登录的基本组件，支持目前主流的三方登录

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
