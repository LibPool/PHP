# busyphp/queue

> 标签: queue, 队列

## 简介

基于ThinkPHP官方改进的一个消息队列服务，它支持消息队列的一些基本特性，发布，获取，执行，删除，重发，失败处理，延迟执行，超时控制，多队列，内存限制 ，启动，停止，守护等

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
