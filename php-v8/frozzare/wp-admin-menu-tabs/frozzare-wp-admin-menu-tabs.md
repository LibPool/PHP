# frozzare/wp-admin-menu-tabs

> 标签: admin, menu, tabs

## 简介

Add edit and admin tabs to admin menu and move updates after option menu

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
