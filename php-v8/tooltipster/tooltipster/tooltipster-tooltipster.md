# tooltipster/tooltipster

> 标签: jquery, plugin, replacement, tooltip

## 简介

Tooltipster is a flexible and extensible jQuery plugin for modern tooltips.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
