# henshall/php-stripe-wrapper

> 标签: PHP

## 简介

Simple Stripe wrapper used to make purchases, subscription, and distribute money wbetween accounts with Stripe Connect.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
