# coderflex/laravel-csv

> 标签: coderflex, laravel, laravel-csv, livewire

## 简介

A Laravel livewire CSV Importer, to handle importing millions of rows without a hustle.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
