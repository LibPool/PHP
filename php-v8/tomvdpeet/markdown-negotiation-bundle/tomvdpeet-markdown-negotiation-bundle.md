# tomvdpeet/markdown-negotiation-bundle

> 标签: accept-header, bundle, content-negotiation, markdown, symfony

## 简介

Symfony bundle to negotiate Markdown responses from HTML routes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
