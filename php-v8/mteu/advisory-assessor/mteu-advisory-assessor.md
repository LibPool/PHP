# mteu/advisory-assessor

> 标签: CycloneDX, SBOM, advisory, security, vex, vulnerability

## 简介

PHP library for recording triage decisions on security advisory findings as VEX statements

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
