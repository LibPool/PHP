# mteu/advisory-matcher

> 标签: advisory, nvd, osv, packagist, security, vulnerability

## 简介

PHP library for matching installed packages against security advisories from Packagist, OSV and NVD

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
