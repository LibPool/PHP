# ejm/flow-bundle

> 标签: bus, command bus, flow, message bus, network

## 简介

Bundle for build and visualize the network of messages flowing on a message bus

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
