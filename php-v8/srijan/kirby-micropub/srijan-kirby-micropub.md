# srijan/kirby-micropub

> 标签: indieweb, kirby, kirby-plugin, micropub

## 简介

Micropub server endpoint for Kirby 5 — create, update, delete, and query posts from IndieWeb clients

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
