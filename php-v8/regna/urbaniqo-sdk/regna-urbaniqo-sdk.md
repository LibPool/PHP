# regna/urbaniqo-sdk

> 标签: sdk, ticketing, transit, transport, urbaniqo

## 简介

Official PHP SDK for the Urbaniqo Transit protocol — sell your tickets, passes and subscriptions through the Urbaniqo app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
