# ikkez/f3-flash

> 标签: F3, fatfree, flash, session

## 简介

Add simple Flash Messages and Flash Keys to PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
