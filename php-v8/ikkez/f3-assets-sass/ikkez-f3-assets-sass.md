# ikkez/f3-assets-sass

> 标签: F3, css, fatfree, sass, scss

## 简介

SASS addon for the Assets plugin for PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
