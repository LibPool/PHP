# ibitcoin/php-api

> 标签: api, bitcoin, cryptocurrency, ibitcoin, ibitcoin.se, litecoin, php, receive

## 简介

Interact easily with iBitcoin.se API methods using PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
