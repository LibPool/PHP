# rumenx/php-vcard

> 标签: addressbook, contacts, laravel, php, symfony, vCard

## 简介

Framework-agnostic PHP package to generate vCard files, with Laravel and Symfony support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
