# vardot/entity-definition-update-manager

> 标签: PHP

## 简介

Entity Definition Update Manager - Provides developers with a class to perform automatic entity updates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
