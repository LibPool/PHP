# askhinton/sdk

> 标签: api, askhinton, crm, sdk

## 简介

Official PHP SDK for the AskHinton CRM API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://app.askhinton.com
- 源码仓库：https://github.com/cortova/cortova-php.git
- Packagist 页面：https://packagist.org/packages/askhinton%2Fsdk

## 历史版本号

- 当前版本：v0.1.0

- v0.1.0

## 获取地址

- Composer 安装：`composer require askhinton/sdk`
- Packagist 仓库：https://repo.packagist.org/p2/askhinton/sdk.json
- 许可证：Apache-2.0
- PHP 要求：>=8.1
