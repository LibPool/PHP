# nayzo/json-schema-validator-bundle

> 标签: bundle, http, json, openapi, schema, validation

## 简介

Symfony bundle used to handle Json Schema validation for PSR7 & PSR17

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
