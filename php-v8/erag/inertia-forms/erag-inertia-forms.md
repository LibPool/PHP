# erag/inertia-forms

> 标签: Forms, form-builder, inertia, inertiajs, laravel, react, svelte, tailwind, validation, vue

## 简介

Define Laravel forms in PHP and render them with Inertia.js in Vue, React, or Svelte. Validation, conditional visibility, authorization, and model binding included.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
