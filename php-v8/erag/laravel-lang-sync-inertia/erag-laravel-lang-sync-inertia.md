# erag/laravel-lang-sync-inertia

> 标签: dynamic-translations, i18n, inertia, inertia-lang, inertiajs, lang-manager, lang-sync, language-manager, language-sync, laravel, laravel-i18n, laravel-inertia, laravel-l10n, localization, multi-language, react i18n, svelte i18n, translation-helper, translation-sync, translations, vue i18n

## 简介

A powerful Laravel package for syncing and managing language translations across backend and Inertia.js (Vue/React/Svelte) frontends, offering effortless localization, auto-sync features, and smooth multi-language support for modern Laravel applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
