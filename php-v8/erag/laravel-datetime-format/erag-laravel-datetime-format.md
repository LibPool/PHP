# erag/laravel-datetime-format

> 标签: carbon, cast, date, datetime, format, laravel

## 简介

Format Eloquent date and datetime values consistently across models, Blade, and APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
