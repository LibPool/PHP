# tetsuo13/piwik_tracking_api

> 标签: analytics, mail, piwik, roundcube, tracking

## 简介

Add Piwik tracking server-side code to all requests in Roundcube

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
