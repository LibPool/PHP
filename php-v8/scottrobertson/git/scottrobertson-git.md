# scottrobertson/git

> 标签: git

## 简介

Simple Git wrapper in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://github.com/scottrobertson/php-git
- 源码仓库：https://github.com/scottrobertson/php-git.git
- Packagist 页面：https://packagist.org/packages/scottrobertson%2Fgit

## 历史版本号

- 当前版本：v0.1

- v0.1

## 获取地址

- Composer 安装：`composer require scottrobertson/git`
- Packagist 仓库：https://repo.packagist.org/p2/scottrobertson/git.json
- 许可证：MIT
- PHP 要求：>=5.3.3
