# nicodemuz/doctrine-fixtures-timing-bundle

> 标签: PHP

## 简介

A Symfony bundle to load Doctrine fixtures with timing information and a top slowest fixtures report

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
