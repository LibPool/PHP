# agroxy/yii2-sms

> 标签:  sms,  sms sender.,  turbosms, yii2

## 简介

The message sender. The package includes sending for service turbosms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
