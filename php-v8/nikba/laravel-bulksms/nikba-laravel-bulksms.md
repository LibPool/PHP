# nikba/laravel-bulksms

> 标签: api, bulksms, laravel, messaging, notification, sms

## 简介

A modern Laravel package to send and manage SMS messages using the BulkSMS JSON REST API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
