# awcodes/filament-table-repeater

> 标签: awcodes, filament, laravel, plugin, table repeater

## 简介

A modified version of the Filament Forms Repeater to display it as a table.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
