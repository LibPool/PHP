# awcodes/scribble

> 标签: awcodes, laravel, scribble

## 简介

A Rich Text Editor plugin for Filament Forms.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/awcodes/scribble
- 源码仓库：https://github.com/awcodes/scribble.git
- Packagist 页面：https://packagist.org/packages/awcodes%2Fscribble
