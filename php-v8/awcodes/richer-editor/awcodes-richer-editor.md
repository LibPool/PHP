# awcodes/richer-editor

> 标签: awcodes, filament, filamentphp, laravel, richer-editor

## 简介

A collection of extensions and tools to enhance the Filament Rich Editor field.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
