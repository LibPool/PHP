# awcodes/sparky

> 标签: filament, laravel, sparky, starter-kit

## 简介

An opinionated Laravel starter kit with Filament, Filament Blueprint, Boost and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
