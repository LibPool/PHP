# awcodes/dimmer

> 标签: awcodes, dimmer, laravel

## 简介

Dimmer is a simple package to easily add a light/dark/system mode switcher to your Laravel app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
