# awcodes/botly

> 标签: awcodes, botly, filament, laravel, robots, robots.txt

## 简介

Botly is a Filament plugin to manage your site's robots.txt file directly from a Filament admin panel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
