# awcodes/preset-color-picker

> 标签: awcodes, color-picker, filament, plugin, preset-color-picker

## 简介

A color picker field for Filament Forms that uses preset color palettes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
