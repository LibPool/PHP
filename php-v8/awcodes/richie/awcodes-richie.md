# awcodes/richie

> 标签: awcodes, filament, filamentphp, laravel, rich editor, richie, wysiwyg

## 简介

Another rich text editor for Filament, built with Tiptap.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
