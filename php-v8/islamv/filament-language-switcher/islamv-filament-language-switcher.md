# islamv/filament-language-switcher

> 标签: filament, i18n, language-switcher, laravel, locale, plugin, rtl

## 简介

An elegant, reliable and fully customizable Language Switcher plugin for Filament panels with RTL and multi-subdomain support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
