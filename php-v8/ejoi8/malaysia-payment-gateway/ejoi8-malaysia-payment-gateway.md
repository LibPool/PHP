# ejoi8/malaysia-payment-gateway

> 标签: Malaysia, chip, fpx, gateway, laravel, payment, paypal, stripe, toyyibpay

## 简介

Malaysian payment gateway integrations for Laravel (Chip, ToyyibPay, FPX) plus Stripe & PayPal

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
