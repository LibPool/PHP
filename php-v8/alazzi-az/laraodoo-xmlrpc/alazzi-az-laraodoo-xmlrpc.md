# alazzi-az/laraodoo-xmlrpc

> 标签: PHP

## 简介

Odoo-Xmlrpc PHP for Laravel is a supercharged PHP API client that allows you to interact with the Odoo XML-RPC API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
