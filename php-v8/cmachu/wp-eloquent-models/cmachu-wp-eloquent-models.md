# cmachu/wp-eloquent-models

> 标签: eloquent, laravel, wordpress

## 简介

A Laravel wrapper for wordpress which turns all Wordpress models into Laravel Eloquent Models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
