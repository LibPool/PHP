# alcaitiff/laravel-urlencode

> 标签: alcaitiff, laravel, laravel5, urlencode

## 简介

Allow Urlencoded slashed and more in routing parameters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
