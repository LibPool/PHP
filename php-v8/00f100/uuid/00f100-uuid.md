# 00f100/uuid

> 标签: guid, identifier, uuid

## 简介

A PHP 5.3+ library for generating RFC 4122 version 1, 3, 4, and 5 universally unique identifiers (UUID).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
