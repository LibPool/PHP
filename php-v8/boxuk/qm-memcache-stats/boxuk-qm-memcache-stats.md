# boxuk/qm-memcache-stats

> 标签: PHP

## 简介

WordPress plugin to provide Memcache Stats to the awesome Query Monitor plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
