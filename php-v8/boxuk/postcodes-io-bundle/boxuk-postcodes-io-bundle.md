# boxuk/postcodes-io-bundle

> 标签: Guzzle, postcode, postcodes.io

## 简介

A Symfony2 bundle for interaction with the postcodes.io service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
