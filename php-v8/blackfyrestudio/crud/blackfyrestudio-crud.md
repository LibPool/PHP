# blackfyrestudio/crud

> 标签: Admin Generator, bauhaus alternative, crud, crud for laravel, crud generator, laravel, laravel crud generator, scaffolding, scaffolding laravel

## 简介

A Laravel 5.1 CRUD package based on krafthaus/bauhaus, although greatly modified...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
