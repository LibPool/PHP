# saffer-it/librenms-netconf

> 标签: evpn, junos, librenms, netconf, plugin

## 简介

LibreNMS plugin that collects values over SSH/NETCONF (Junos '| display xml') and maps them onto sensors, port metrics and custom metrics via YAML definitions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
