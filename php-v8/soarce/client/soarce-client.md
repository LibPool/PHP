# soarce/client

> 标签: SOARCE, Xdebug, codecoverage, qa, testing

## 简介

This is the client for SOARCE providing and endpoint for external code coverage collection and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
