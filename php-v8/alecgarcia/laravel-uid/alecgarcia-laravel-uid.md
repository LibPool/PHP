# alecgarcia/laravel-uid

> 标签: LaravelUid, UID, laravel

## 简介

Create UIDs like the ones Stripe generates. These can be used on your models or on their own.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
