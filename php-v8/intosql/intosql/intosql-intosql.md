# intosql/intosql

> 标签: converter, csv, excel, mysql, postgresql, sql, sqlite, xlsx

## 简介

Convert spreadsheets, CSV and JSON into SQL with the IntoSQL API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
