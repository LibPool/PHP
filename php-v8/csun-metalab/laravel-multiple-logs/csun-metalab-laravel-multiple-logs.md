# csun-metalab/laravel-multiple-logs

> 标签: PHP

## 简介

Composer package for Laravel 5 that adds a few additional log files as well as facades to write to them.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
