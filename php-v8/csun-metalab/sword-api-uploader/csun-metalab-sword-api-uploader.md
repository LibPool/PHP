# csun-metalab/sword-api-uploader

> 标签: PHP

## 简介

Allows for the uploading of documents in a Laravel application to a repository that uses the SWORD API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
