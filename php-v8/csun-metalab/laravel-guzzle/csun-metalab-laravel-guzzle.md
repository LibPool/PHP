# csun-metalab/laravel-guzzle

> 标签: PHP

## 简介

Composer package for Laravel 5.0 and above that provides a consistent method of interacting with Guzzle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
