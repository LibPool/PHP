# csun-metalab/laravel-force-https

> 标签: PHP

## 简介

A small Composer package for Laravel 5.0 and above to force HTTPS in the URL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
