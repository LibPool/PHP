# jncarter123/soundboard

> 标签: WebSockets, dashboard, laravel, multi-tenant, pusher, reverb

## 简介

A multi-app control panel for Laravel Reverb: database-backed apps, live and historical metrics, RBAC, and an API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
