# balebot/balebot

> 标签: Bale, bale-messenger, balebot, bot, laravel, php, sdk, telegram-like

## 简介

The most complete PHP SDK for Bale Messenger bots. Supports Laravel out of the box.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
