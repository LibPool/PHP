# cwola/a5m2-invoker

> 标签: A5M2, cwola, php, sql

## 简介

Provides a simple execute from PHP to 'A5:SQL Mk-2'(A5M2).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
