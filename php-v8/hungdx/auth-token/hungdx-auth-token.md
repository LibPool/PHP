# hungdx/auth-token

> 标签: Auth Token, Authentication, Authentication Token, Laravel Auth, laravel

## 简介

The Authentication driver using token for Laravel Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
