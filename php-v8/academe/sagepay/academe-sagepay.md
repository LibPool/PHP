# academe/sagepay

> 标签: gateway, merchant, payment, sagepay

## 简介

A library to handle the back-end processing for the SagePay Server (protocol v3) service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
