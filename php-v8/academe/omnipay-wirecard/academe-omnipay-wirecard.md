# academe/omnipay-wirecard

> 标签: gateway, merchant, omnipay, pay, payment, wirecard

## 简介

Wirecard payment gateway driver for the Omnipay 3.x payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
