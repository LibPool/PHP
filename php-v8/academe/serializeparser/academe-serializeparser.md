# academe/serializeparser

> 标签: php, serialize, unserialize

## 简介

A PHP parser for serialized data, to be able to 'peek' into serialize strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
