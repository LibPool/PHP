# academe/opayo-pi

> 标签: gateway, merchant, payment, sagepay

## 简介

A library to handle the message content and structure for the Opayo Pi (was Sage Pay Integration) payment gateway

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
