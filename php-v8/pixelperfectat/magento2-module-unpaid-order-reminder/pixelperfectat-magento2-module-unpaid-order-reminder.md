# pixelperfectat/magento2-module-unpaid-order-reminder

> 标签: bank-transfer, magento, magento2, payment, pending-payment, reminder

## 简介

Reminds a shopper about an order still awaiting payment, with the instructions needed to complete it

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
