# pixelperfectat/coding-standard

> 标签: PHP

## 简介

PixelPerfect shared Magento module coding standard: phpcs ruleset (extends Magento2), phpstan config, and the pinned QA toolchain.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
