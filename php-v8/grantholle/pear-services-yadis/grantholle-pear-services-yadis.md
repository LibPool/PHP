# grantholle/pear-services-yadis

> 标签: PHP

## 简介

A psr-4 compliant port of pear/services_yadis, an implementation of the Yadis Specification 1.0 protocol

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
