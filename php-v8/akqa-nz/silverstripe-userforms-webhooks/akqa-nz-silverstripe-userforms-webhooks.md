# akqa-nz/silverstripe-userforms-webhooks

> 标签: api, silverstripe, userforms, webhook

## 简介

Post Silverstripe UserDefinedForm submissions to configurable webhooks with CMS-managed headers, conditions, and request logging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
