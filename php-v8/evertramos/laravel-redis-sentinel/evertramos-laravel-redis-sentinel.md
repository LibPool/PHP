# evertramos/laravel-redis-sentinel

> 标签: laravel, redis

## 简介

An extension of Laravels Redis driver which supports connecting to a Redis master through Redis Sentinel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
