# staempfli/magento2-module-mailcatcher

> 标签: catch, catcher, email, magento2, mail, module

## 简介

magento 2 module to catch, log and redirect emails on local and dev

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
