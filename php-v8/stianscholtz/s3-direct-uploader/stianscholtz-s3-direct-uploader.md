# stianscholtz/s3-direct-uploader

> 标签: file-uploader, laravel, s3, upload

## 简介

A headless Laravel file uploader to upload files to s3 directly from the client.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
