# nicolae-soitu/filament-translations

> 标签: cache translations, database, database translations, db, filament plugin, i8n, language, laravel, laravel-translation-loader, loader, php, spatie, translate, translation UI, translation manager, translations

## 简介

Manage your translation with DB and cache, you can scan your languages tags like trans(), __(), and get the string inside and translate them use UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
