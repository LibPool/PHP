# synthigy/sdk

> 标签: client, dataset, iam, sdk, synthigy

## 简介

Thin PHP client for Synthigy's /data endpoint: reads, writes, XSQL, OAuth and typed code generation. No watch/SSE layer.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
