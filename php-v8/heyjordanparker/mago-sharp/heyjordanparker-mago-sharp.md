# heyjordanparker/mago-sharp

> 标签: dev

## 简介

PHP#'s checker and toolchain: checks PHP and PHP# code, compiles PHP#, and lints and formats PHP.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
