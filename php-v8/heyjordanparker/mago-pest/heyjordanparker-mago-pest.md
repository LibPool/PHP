# heyjordanparker/mago-pest

> 标签: mago, pest, static-analysis

## 简介

Mago analyzer support for Pest: $this in test closures, dynamic test properties, and expectation chains.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
