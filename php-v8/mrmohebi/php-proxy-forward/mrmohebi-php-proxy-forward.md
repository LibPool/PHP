# mrmohebi/php-proxy-forward

> 标签: curl, curlphp, http, http-proxy, php, php-proxy, proxy, proxy-script

## 简介

Forward your HTTP/HTTPS requests to another server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
