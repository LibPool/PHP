# marque/squidink

> 标签: ast, bbcode, laravel, markdown, text

## 简介

Format-agnostic text pipeline for Marque — parse any supported syntax to a document AST, render it safely to anything

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
