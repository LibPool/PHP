# evolution-cms/evo-ui

> 标签: DaisyUI, evocms, evolution-cms, livewire, manager-ui

## 简介

A Livewire and DaisyUI powered UI foundation for modern Evolution CMS manager modules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
