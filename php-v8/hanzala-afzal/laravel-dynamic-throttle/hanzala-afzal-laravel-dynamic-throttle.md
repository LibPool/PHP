# hanzala-afzal/laravel-dynamic-throttle

> 标签: dry-run, laravel, middleware, rate-limit, rate-limiter, rate-limiting, throttle, throttling

## 简介

Runtime-managed, identity-aware rate limiting for Laravel: change limits without a deploy, per user or token, and dry-run them first.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
