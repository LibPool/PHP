# wegetfinancing/php-sdk

> 标签: PHP

## 简介

The WeGetFinancing PHP SDK provides convenient access to the WeGetFinancing API from applications written in the PHP language.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
