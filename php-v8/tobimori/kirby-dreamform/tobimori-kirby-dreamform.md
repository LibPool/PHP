# tobimori/kirby-dreamform

> 标签: PHP

## 简介

Kirby DreamForm is an opiniated form builder plugin for Kirby CMS 4+ that makes forms work like magic

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
