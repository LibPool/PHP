> 标签: bot, telegram, telegram bot, تلگرام, ربات تلگرام, ساخت ربات تلگرام

## 简介

A lightweight PHP wrapper for the Telegram Bot API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
