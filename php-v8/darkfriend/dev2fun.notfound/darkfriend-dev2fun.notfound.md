# darkfriend/dev2fun.notfound

> 标签: 404, 404 page, bitrix, darkfriend, Битрикс, модуль, страница 404

## 简介

Модуль добавляет поддержку страниц 404 для 1С-Битрикс

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
