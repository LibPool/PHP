# theorgman/newton

> 标签: theorgman

## 简介

A simple project designed to learn the process of creating and releasing PHP packages using GitHub and Packagist.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/theorgman/newton
- 源码仓库：https://github.com/theorgman/newton.git
- Packagist 页面：https://packagist.org/packages/theorgman%2Fnewton

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require theorgman/newton`
- Packagist 仓库：https://repo.packagist.org/p2/theorgman/newton.json
- 许可证：MIT
- PHP 要求：^8.1
