# preee/php-dependency-analysis

> 标签: analysis, architecture, dependency, graph, phpda

## 简介

Static code analysis to find violations in a dependency graph

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
