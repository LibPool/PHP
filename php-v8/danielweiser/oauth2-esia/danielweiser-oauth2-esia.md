# danielweiser/oauth2-esia

> 标签: esia, oauth2, oauth2-provider, openid-connect

## 简介

Allows to authenticate in ESIA and get authenticated individual personal information.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
