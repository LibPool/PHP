# leobenelli/composer-check-bundle

> 标签: bundles, composer, show, symfony

## 简介

Symfony Bundle to check Version alignment (via Composer) with the latest Bundle versions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
