# thomsontochi/laravel-agent-loops

> 标签: agent-harness, agents, ai, laravel, llm

## 简介

A Laravel agent harness with swappable loops. Pick how your AI agent thinks, switch with one line, compare which works best.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
