# ahmed-aliraqi/laravel-deep-link

> 标签: app-links, apple-app-site-association, assetlinks, deep-link, deep-links, laravel, mobile, share, smart-app-banner, universal-links

## 简介

Universal Links, Android App Links and smart landing pages for Laravel: shareable URLs that open the mobile app when it is installed and fall back to the stores when it is not.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
