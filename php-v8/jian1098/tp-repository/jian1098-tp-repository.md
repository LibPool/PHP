# jian1098/tp-repository

> 标签: PHP

## 简介

thinkphp框架命令行创建Repository和Transform Class(即仓库层和转化器，基于controller-service-repository目录架构)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
