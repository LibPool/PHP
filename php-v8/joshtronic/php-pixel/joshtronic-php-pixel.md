# joshtronic/php-pixel

> 标签: beacon, gif, image, pixel, png, tracking, transparent

## 简介

Generate a 1x1 transparent pixel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
