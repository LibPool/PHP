# futureecom/omnipay-stripe

> 标签: gateway, merchant, omnipay, pay, payment, payment-intents, stripe

## 简介

Stripe Payment Intents driver for the Omnipay payment processing library.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
