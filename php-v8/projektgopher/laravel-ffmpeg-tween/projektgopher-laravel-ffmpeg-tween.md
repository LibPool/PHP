# projektgopher/laravel-ffmpeg-tween

> 标签: ProjektGopher, laravel, laravel-ffmpeg-tools

## 简介

Generates strings for use in ffmpeg commands to tween between values with easings.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
