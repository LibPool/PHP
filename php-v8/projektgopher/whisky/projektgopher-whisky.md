# projektgopher/whisky

> 标签: ProjektGopher, cli, dev, git, hooks, laravel, php, whisky

## 简介

A simple CLI tool for managing a project's git hooks across multiple members.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
