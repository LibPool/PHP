# toneflix-code/fakerphp-lorem-toneflix

> 标签: faker, generator, images, laravel, lorem, php, placeholder

## 简介

An alternative image provider for fakerphp using Lorem Toneflix.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
