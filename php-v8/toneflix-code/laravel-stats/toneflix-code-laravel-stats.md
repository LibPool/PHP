# toneflix-code/laravel-stats

> 标签: Metrics, laravel, laravel-stats, legacy, stats

## 简介

A simple Laravel package to help you quickly get usage metrics and data from your app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
