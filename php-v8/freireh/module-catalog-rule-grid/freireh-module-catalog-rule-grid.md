# freireh/module-catalog-rule-grid

> 标签: PHP

## 简介

Este módulo adiciona uma funcionalidade para visualizar uma descrição breve das regras diretamente na grid de regras de catálogo no Magento 2.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
