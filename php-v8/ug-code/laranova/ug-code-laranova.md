# ug-code/laranova

> 标签: Postman, api, debug, documentation, laravel, testing

## 简介

Postman-like API test interface for Laravel. Pre-script Faker tags, HTTP Client wrapper, SPA UI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
