# maximo-perez-villalba/framework-environment

> 标签: PHP

## 简介

El componente implementa una arquitectura liviana de control del ambiente de ejecución PHP, con fines pedagógicos.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
