# maximo-perez-villalba/class-properties-reader

> 标签: PHP

## 简介

La clase lee vía reflexión todos las propiedades de una clase incluyendo las propiedades privadas de su jerarquía.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
