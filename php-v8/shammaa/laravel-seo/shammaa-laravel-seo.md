# shammaa/laravel-seo

> 标签: PHP

## 简介

Professional SEO package for Laravel with support for OpenGraph, Twitter Cards, LinkedIn, and Schema.org structured data

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
