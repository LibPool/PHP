# shammaa/laravel-arabic-search

> 标签: arabic, arabic-search, eloquent, fulltext, laravel, normalization, regex, search, tashkeel

## 简介

High-performance Arabic search and matching library for Laravel with flexible regex, diacritics removal, and Eloquent integration

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
