# shammaa/laravel-sitemap

> 标签: PHP

## 简介

Professional, scalable Sitemap generator for Laravel with automatic model discovery, flexible chunking strategies, and advanced caching

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
