# bagisto/bagisto-rma

> 标签: bagisto, product rma, rma

## 简介

help customers to request for return / cancel / exchange products during the stipulated time-period.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
