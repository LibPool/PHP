# akika/laravel-mpesa

> 标签: Akika, daraja, digital, laravel, mpesa, payment

## 简介

A single-tenant Laravel package for integrating Mpesa Daraja API. The package supports Laravel version 5 and above.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
