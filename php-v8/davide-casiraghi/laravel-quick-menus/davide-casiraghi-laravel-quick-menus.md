# davide-casiraghi/laravel-quick-menus

> 标签: davide-casiraghi, laravel-quick-menus

## 简介

A Laravel package to generate Bootstrap 4 multi language menus.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
