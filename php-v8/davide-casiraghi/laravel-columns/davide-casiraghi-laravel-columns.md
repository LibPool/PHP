# davide-casiraghi/laravel-columns

> 标签: davide-casiraghi, laravel-columns

## 简介

A Laravel library to generate responsive columns with multi language contents.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
