# vmans/typo3-kesearch-categories

> 标签: categories, extension, ke_search, typo3

## 简介

Extension provides connection between ke_search and TYPO3 categories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
