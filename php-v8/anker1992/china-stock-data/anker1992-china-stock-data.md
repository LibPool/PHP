# anker1992/china-stock-data

> 标签: PHP

## 简介

提供国内财经门户网站股票相关数据,目前有新浪和凤凰网的数据

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
