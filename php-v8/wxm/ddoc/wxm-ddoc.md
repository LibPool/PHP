# wxm/ddoc

> 标签: api, database, doc, laravel

## 简介

基于 laravel 框架, 读取数据库信息生成数据库字典, 通过控制器注释生成API接口文档, 注册 ddoc 路由网页形式呈现

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
