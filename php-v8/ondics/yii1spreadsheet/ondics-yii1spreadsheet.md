# ondics/yii1spreadsheet

> 标签: LibreOffice, Yii1, excel, export, spreadsheet, xls, xlsx

## 简介

Yii1 extension for export to a spreadsheet, e.g. Excel, LibreOffice etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
