# imazed/laravel-helpscout-beacon

> 标签: beacon, customer-support, help-scout, helpscout, laravel

## 简介

Embed the Help Scout Beacon in a Laravel application, with Secure Mode signatures generated server-side.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
