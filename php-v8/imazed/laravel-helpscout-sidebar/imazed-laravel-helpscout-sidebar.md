# imazed/laravel-helpscout-sidebar

> 标签: customer-support, help-scout, helpscout, laravel, sidebar

## 简介

Render Laravel application data inside the Help Scout conversation sidebar, resolving customers server-side through the Help Scout Mailbox API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
