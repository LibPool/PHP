# fanxd/owl-knowledge

> 标签: extension, owl-admin

## 简介

Owl Admin 扩展，用于管理知识库、分类以及 AI 驱动的知识场景，支持多租户和可见性控制

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
