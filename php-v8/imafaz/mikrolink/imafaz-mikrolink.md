# imafaz/mikrolink

> 标签: MikroLink, api mikrotik, imafaz, mikrotik, mikrotik api

## 简介

lightweight library for manage mikrotik router os with api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
