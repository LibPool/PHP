# gozoro/yii2-rbac-console

> 标签: auth, authmanager, console, rbac, yii2

## 简介

RBAC configuration and managment tool in the console.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
