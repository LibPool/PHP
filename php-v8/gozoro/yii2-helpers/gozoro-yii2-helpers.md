# gozoro/yii2-helpers

> 标签: helpers, html, json, url, yii2

## 简介

Helpers for Yii2 Framework. Extends standard helpers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
