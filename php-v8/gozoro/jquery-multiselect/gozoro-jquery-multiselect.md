# gozoro/jquery-multiselect

> 标签: checboxes, dropdown, jquery, multiselect

## 简介

A jQuery plugin multiselect with checkboxes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
