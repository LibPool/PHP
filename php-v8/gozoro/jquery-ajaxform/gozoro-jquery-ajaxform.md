# gozoro/jquery-ajaxform

> 标签: ajax, ajaxform, form, jquery, submit

## 简介

A jQuery plugin to submit forms with files via AJAX and to get a response with errors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
