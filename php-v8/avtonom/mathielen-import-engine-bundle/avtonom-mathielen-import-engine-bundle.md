# avtonom/mathielen-import-engine-bundle

> 标签: csv, import

## 简介

A generic import (and export) -engine that provides easy to use yet powerful features

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
