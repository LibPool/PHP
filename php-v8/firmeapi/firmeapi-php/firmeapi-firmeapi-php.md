# firmeapi/firmeapi-php

> 标签: CUI, Romania, anaf, api, business, company, firmeapi, sdk

## 简介

Official PHP SDK for FirmeAPI.ro - Romanian company data API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
