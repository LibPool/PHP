# softon/indipay

> 标签: CitrusPay, Indian Payment Gateways, ccavenue, ebs, instamojo, laravel 5, mocker, paytm, payumoney

## 简介

The Laravel 5+ Package for Indian Payment Gateways. Currently supported gateways: CCAvenue, PayUMoney, EBS, CitrusPay, InstaMojo, ZapakPay, Paytm, Mocker.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
