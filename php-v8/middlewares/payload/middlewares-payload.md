# middlewares/payload

> 标签: http, json, middleware, payload, psr-15, psr-7, server, url-encode

## 简介

Middleware to parse the body of the request with support for json, csv and url-encode

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
