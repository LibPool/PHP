# middlewares/geolocation

> 标签: IP, geocode, geolocation, http, middleware, psr-15, psr-7, server

## 简介

Middleware to geolocate the client using the ip address

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
