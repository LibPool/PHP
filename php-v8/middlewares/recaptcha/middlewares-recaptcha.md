# middlewares/recaptcha

> 标签: captcha, google, http, middleware, psr-15, psr-7, recaptcha, security, server

## 简介

Middleware to use Google reCAPTCHA for spam prevention

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
