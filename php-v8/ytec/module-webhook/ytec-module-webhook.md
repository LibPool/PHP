# ytec/module-webhook

> 标签: integration, liquid, magento, magento 2 module, magento2, magento2 extension, magento2 module, webhook, webhooks

## 简介

Configurable outgoing webhooks for Magento 2 with Liquid payload templating, conditions, authorization, retries and delivery logs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
