# zero-config/preacher

> 标签: blog, git, markdown, php, prism, static, twig, website

## 简介

Personal static website generator using GitHub Flavored Markdown, Twig and Git.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
