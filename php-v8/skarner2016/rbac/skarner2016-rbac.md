# skarner2016/rbac

> 标签: menu, pdo, permission, php, rbac, roles

## 简介

Framework-agnostic RBAC for PHP: role-only permissions with menu, route and button types.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
