# khalidumar/behatformatter

> 标签: PHP

## 简介

This will create a formatter for Behat 3! Fast, Easy and Pretty! & Added support for php 7.2+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
