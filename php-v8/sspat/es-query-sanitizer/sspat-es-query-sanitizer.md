# sspat/es-query-sanitizer

> 标签: Escape, elasticsearch, query, sanitize

## 简介

Simple helper class to sanitize ElasticSearch reserved characters from query strings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
