# sspat/doctrine-nullable-embeddables

> 标签: doctrine, embeddable, nullable

## 简介

Patches doctrine/orm to allow usage of nullable embeddables

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
