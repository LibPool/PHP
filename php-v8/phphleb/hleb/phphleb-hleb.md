# phphleb/hleb

> 标签: framework, hleb, hleb2, php, phphleb

## 简介

PHP Framework HLEB2 is the foundation of the web application. Provides ease of development and application performance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
