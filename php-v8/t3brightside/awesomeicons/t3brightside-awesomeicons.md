# t3brightside/awesomeicons

> 标签: extension, fontaweome, icon, typo3

## 简介

Adds Font Awesome icon tabs for pages and content elements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
