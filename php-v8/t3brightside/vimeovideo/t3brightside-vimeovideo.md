# t3brightside/vimeovideo

> 标签: gdpr, responsive, typo3, video, vimeo

## 简介

TYPO3 CMS extension for Vimeo with custom cover images, gallery, pagination, GDPR, and backend previews. Demo: https://microtemplate.t3brightside.com. Demo: https://microtemplate.t3brightside.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
