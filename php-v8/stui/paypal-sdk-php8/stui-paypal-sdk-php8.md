# stui/paypal-sdk-php8

> 标签: payments, paypal, rest, sdk

## 简介

PayPal's PHP 8 SDK for REST APIs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：http://paypal.github.io/PayPal-PHP-SDK/
- 源码仓库：https://github.com/stuii/PayPal-PHP8-SDK.git
