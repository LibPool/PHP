# justpush/laravel-notification-channel

> 标签: justpush, laravel, notification channel, notifications, push notifications

## 简介

JustPush notification channel for Laravel: send push notifications to iOS and Android with $user->notify().

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
