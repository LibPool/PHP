# vercy/payments

> 标签: bitpay, crypto, cryptomus, flutterwave, laravel, nowpayments, payments, paypal, paystack, stripe

## 简介

Unified payment gateway integration for Laravel - Paystack, Flutterwave, Stripe, PayPal, NowPayments, Cryptomus, BitPay

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
