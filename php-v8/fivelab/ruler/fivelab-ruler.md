# fivelab/ruler

> 标签: DSL, clickhouse, doctrine, doctrine-orm, elastica, elasticsearch, filter, opensearch, query-builder, rule, ruler, rulerz, search, specification

## 简介

Apply string filter rules to Doctrine ORM, Elasticsearch/Elastica and ClickHouse query builders.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
