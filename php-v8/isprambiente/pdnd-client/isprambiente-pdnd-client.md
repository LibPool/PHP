# isprambiente/pdnd-client

> 标签: Authentication, api, client, pdnd, php

## 简介

Client PHP per autenticazione e chiamata API PDND (Piattaforma Digitale Nazionale Dati).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
