# getghostr/cockroachdb-laravel

> 标签: cockroachdb, cockroachdb-laravel, eloquent, getghostr, laravel

## 简介

Simple CockroachDB driver for Laravel 6+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
