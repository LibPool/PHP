# myaghobi/f3-captcha

> 标签: Fat-Free-Framework, captcha, f3-captcha, fat-free-plugin

## 简介

A better captcha for Fat-Free Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
