# myaghobi/f3-benchmark

> 标签: F3, Fat-Free-Framework, benchmark, debug, fat-free-plugin

## 简介

A benchmark helper plugin for Fat-Free framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
