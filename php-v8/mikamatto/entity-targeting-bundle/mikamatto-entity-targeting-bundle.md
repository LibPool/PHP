# mikamatto/entity-targeting-bundle

> 标签: Audience, bundle, criteria, entity, filtering, role-filter, symfony, targeting, user-roles

## 简介

A Symfony bundle to manage and filter entities based on customizable targeting criteria, ideal for audience-specific content management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
