# hmennen90/php-steamworks

> 标签: game, php-extension, steam, steamworks, valve

## 简介

PHP extension providing access to the Valve Steamworks SDK via a flat C API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
