# hmennen90/laravel-graphql

> 标签: api, dataLoader, graphql, laravel, schema, subscriptions

## 简介

A hand-written GraphQL engine with first-class Laravel integration (code-first + SDL).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
