# hmennen90/php-vulkan

> 标签: 2d, 3d, Vulkan, compute, engine, game, gpu, graphics

## 简介

PHP Vulkan API bindings for 2D/3D graphics and GPU compute — built for PHPolygon engine

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
