# reddingwebdev/abuseipdb

> 标签: Abuse, IP, abuseipdb, blacklist, psr-18, security, symfony

## 简介

Framework-agnostic PHP client for the AbuseIPDB APIv2 (PSR-18), with an optional Symfony bundle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
