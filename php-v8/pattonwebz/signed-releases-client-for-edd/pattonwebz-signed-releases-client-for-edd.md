# pattonwebz/signed-releases-client-for-edd

> 标签: PHP

## 简介

Verifies minisign (Ed25519) signatures on plugin release zips before WordPress installs them. Companion to the Signed Releases for EDD store extension.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
