# scottjs/wp-dotenv

> 标签: PHP

## 简介

Helper scripts to enable WordPress to use dotenv config files, similar to Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
