# ofix/panda-log

> 标签: debug, log, logging, panda-log, yii2-extension

## 简介

panda-log is a yii2-extension for log and view debug information

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
