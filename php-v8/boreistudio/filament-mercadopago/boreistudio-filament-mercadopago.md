# boreistudio/filament-mercadopago

> 标签: filament, laravel, mercadopago

## 简介

Filament plugin for Mercado Pago integration — Checkout Pro, Point, QR, OAuth, Webhooks

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
