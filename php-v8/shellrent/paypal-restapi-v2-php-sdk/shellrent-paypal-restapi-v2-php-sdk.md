# shellrent/paypal-restapi-v2-php-sdk

> 标签: checkout, orders, payments, paypal, rest, sdk

## 简介

PayPal's PHP SDK for Checkout REST APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
