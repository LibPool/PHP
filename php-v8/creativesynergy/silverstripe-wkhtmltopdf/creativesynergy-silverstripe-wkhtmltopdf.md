# creativesynergy/silverstripe-wkhtmltopdf

> 标签: pdf, silverstripe, wkhtmltopdf

## 简介

Adds the possibility to create PDFs from all DataObjects with WKHTMLTOPDF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
