# arfaram/ezplatform-activities-log

> 标签: ezplatform, ibexa

## 简介

UI Interface for several system activities and user history for eZ Platform Ibexa 4+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
