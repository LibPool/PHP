# mbo2olivier/makuta_client

> 标签: Partner application, api, e-makuta, m-pesa, mobile payment, web service client

## 简介

PHP Client for e-Makuta ; Client PHP pour e-Makuta. Permet d'intégrer le système de paiement e-Makuta à son site web en PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
