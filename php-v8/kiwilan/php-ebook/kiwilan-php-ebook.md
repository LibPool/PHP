# kiwilan/php-ebook

> 标签: CBA, audiobook, azw, azw3, book, calibre, cb7, cbam, cbr, cbt, cbz, comic, comicinfo, cover, ebook, epub, epub2, epub3, fb2, metadata, mobi, opf, pdf, php

## 简介

PHP package to read metadata and extract covers from eBooks, comics and audiobooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
