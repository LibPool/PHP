# kiwilan/php-http-pool

> 标签: Guzzle, concurrency, http, kiwilan, php, pool, requests

## 简介

PHP package with easy-to-use GuzzleHttp pool wrapper to make concurrent requests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
