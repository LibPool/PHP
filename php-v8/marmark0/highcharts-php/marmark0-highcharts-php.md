# marmark0/highcharts-php

> 标签: charts, highcharts, highstock, javascript, php

## 简介

A php wrapper for highcharts and highstock javascript libraries (for PHP 8.2)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
