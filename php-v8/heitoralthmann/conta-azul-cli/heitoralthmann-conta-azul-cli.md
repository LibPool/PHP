# heitoralthmann/conta-azul-cli

> 标签: API-Client, cli, conta-azul, oauth2, php, symfony-console

## 简介

CLI PHP/Symfony para as APIs Financeiro, Pessoas, Produtos e Serviços da Conta Azul

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
