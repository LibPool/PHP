# hasnayeen/blade-ssg

> 标签: Hasnayeen, blade-ssg, laravel

## 简介

Filament plugin for static site generation for Laravel with blade component supported markdown.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
