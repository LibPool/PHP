# mohan-devstack/magento2-guest-order-to-customer

> 标签: admin, customer, guest-order, magento, magento2, order-assignment

## 简介

Map Magento 2 guest orders to an existing customer account with the same email, from a "Map to Customer" button on the admin order view page.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
