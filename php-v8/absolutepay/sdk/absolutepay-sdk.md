# absolutepay/sdk

> 标签: absolutepay, api, crypto, payments, payouts, sdk, stablecoin

## 简介

Official AbsolutePay SDK — accept crypto payments, send payouts, and reconcile.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
