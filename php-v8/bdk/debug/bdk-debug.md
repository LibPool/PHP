# bdk/debug

> 标签: ChromeLogger, debug, debugging, errorhandler, firephp, inspect, logger, php-debugbar, phpdebugconsole, psr-3, var_dump, whoops

## 简介

Browser/javascript like console class for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
