# devable/rectorphp-junit

> 标签: ci, junit, output-format, rector

## 简介

Restores JUnit XML output (--output-format=junit) to Rector 2.x, removed upstream in rectorphp/rector-src PR #8250

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
