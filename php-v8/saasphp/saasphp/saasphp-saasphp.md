# saasphp/saasphp

> 标签: alpine, filament, inertia, laravel, mysql, php, react, saasphp, starterkit, tailwind

## 简介

A Laravel Starter Kit with React, Inertia, Filament, Tailwind, and Alpine.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
