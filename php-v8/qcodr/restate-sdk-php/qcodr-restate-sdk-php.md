# qcodr/restate-sdk-php

> 标签: durable-execution, php, restate, sdk, workflow

## 简介

PHP SDK for Restate (restate.dev); Durable execution for services, virtual objects and workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
