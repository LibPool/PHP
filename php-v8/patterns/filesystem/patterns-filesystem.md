# patterns/filesystem

> 标签: adapter, capability, disk, filesystem, pattern, port, s3, storage

## 简介

Filesystem pattern - the seven operations every storage backend can honour, plus an opt-in capability for the ones that can describe a path.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
