# patterns/event-channel

> 标签: channel, contract, event, events, pattern, publish, pubsub, subscribe

## 简介

Event Channel pattern - a transport-agnostic contract for publishing and subscribing to named events.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
