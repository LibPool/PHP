# patterns/unit

> 标签: contract, dna, identity, pattern, provenance, unit, versioning

## 简介

Unit pattern - a named, versioned identity for code that produces data, so every record can say which unit and which version made it.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
