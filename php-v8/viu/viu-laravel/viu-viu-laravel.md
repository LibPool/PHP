# viu/viu-laravel

> 标签: kafka, laravel, logging, loki, monolog, observability, viu

## 简介

Laravel SDK for Viu logging platform — Monolog Handler, Facade, HTTP/Kafka transport

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
