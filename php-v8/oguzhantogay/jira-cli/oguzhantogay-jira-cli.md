# oguzhantogay/jira-cli

> 标签: JIRA API, cli, command-line, jira, jira issues, php

## 简介

A PHP CLI tool to interact with Jira issues directly from the terminal.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
