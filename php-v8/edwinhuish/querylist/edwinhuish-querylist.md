# edwinhuish/querylist

> 标签: QueryList, crawler, dom, domquery, spider

## 简介

Simple, elegant, extensible PHP Web Scraper (crawler/spider),Use the css3 dom selector,Based on DomQuery! 简洁、优雅、可扩展的PHP采集工具(爬虫)，基于DomQuery。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
