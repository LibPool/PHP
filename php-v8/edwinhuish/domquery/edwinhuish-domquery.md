# edwinhuish/domquery

> 标签: css, dom, html, jquery, selector, xml

## 简介

DomQuery is a PHP library that allows easy 'jQuery like' DOM traversing and manipulation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
