# inapps/inapps-modules

> 标签: architecture, laravel, laravel-modules, php, psr-12

## 简介

InApps module structure maker for its laravel projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
