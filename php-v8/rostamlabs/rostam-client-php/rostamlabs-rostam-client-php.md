# rostamlabs/rostam-client-php

> 标签: client, key-value, rostam, tcp, vector-database

## 简介

A PHP client for Rostam - speaks the native binary TCP protocol of its key-value engine, with connection pooling, pipelining, TLS and token auth. No framework, no extensions beyond core streams.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
