# studiocreativateam/pab

> 标签: bugs, crash-reporting, crash-reports, error-handler, error-monitoring, log, logging

## 简介

A PHP SDK for PAB (https://studio-creativa.pl)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
