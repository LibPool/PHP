# tatlead/html-speaker

> 标签: html-element, html-speaker, text-to-speech, tts

## 简介

A custom html element makes Text-To-Speech function easier to use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
