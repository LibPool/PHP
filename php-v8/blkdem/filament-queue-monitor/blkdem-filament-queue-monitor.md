# blkdem/filament-queue-monitor

> 标签: database, filament, laravel, monitor, queue, redis

## 简介

A lightweight queue monitoring plugin for Filament. Not a replacement for Laravel Horizon.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
