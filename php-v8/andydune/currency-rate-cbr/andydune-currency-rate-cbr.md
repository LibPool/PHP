# andydune/currency-rate-cbr

> 标签: php

## 简介

Code for obtaining and parsing XML-data on currency rates of the Central Bank of the Russian Federation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
