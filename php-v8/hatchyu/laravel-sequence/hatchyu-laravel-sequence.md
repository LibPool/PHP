# hatchyu/laravel-sequence

> 标签: PHP

## 简介

Concurrency-safe Laravel sequence numbers using database transactions, row-level locking, grouping, formatting, and model integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
