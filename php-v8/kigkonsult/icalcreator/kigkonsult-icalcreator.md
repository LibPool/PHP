# kigkonsult/icalcreator

> 标签: alarm, availability, calendar, daylight, event, ical, json, location, management, participant, resource, rfc2445, rfc5545, rfc5870, rfc6321, rfc6868, rfc7529, rfc7808, rfc7953, rfc7986, rfc9073, rfc9074, standard, todo, vCalendar, valarm, vevent, vfreebusy, vjournal, vtimezone, vtodo, xml

## 简介

iCalcreator is the PHP implementation of rfc2445/rfc5545 and rfc updates, management of calendar information

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
