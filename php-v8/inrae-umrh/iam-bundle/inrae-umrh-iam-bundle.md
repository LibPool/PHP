# inrae-umrh/iam-bundle

> 标签: PHP

## 简介

Bundle Symfony pour l'authentification OAuth2/OIDC avec le système IAM de l'INRAE

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
