# istiak-tridip/laravel-sqids

> 标签: laravel, laravel-sqids, php, sqids

## 简介

Laravel wrapper for Sqids to obscure database IDs with unique, URL-safe identifiers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
