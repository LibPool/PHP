# jarrin/wefact-php-sdk

> 标签: api, billing, client, invoicing, laravel, wefact

## 简介

Modern, strongly-typed, PSR-compliant PHP client for the WeFact v2 API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
