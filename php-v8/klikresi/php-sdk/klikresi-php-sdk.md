# klikresi/php-sdk

> 标签: courier, indonesia, klikresi, ongkir, resi, shipping, tracking

## 简介

Official PHP SDK for the Klik Resi API: shipment tracking, shipping rates, and Indonesian location lookup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
