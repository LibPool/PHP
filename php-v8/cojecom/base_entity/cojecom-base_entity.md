# cojecom/base_entity

> 标签: PHP

## 简介

A base entity for Symfony projects using Doctrine ORM. Available in 2 flavours : incremental numeric IDs & UUIDs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
