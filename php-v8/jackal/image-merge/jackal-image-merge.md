# jackal/image-merge

> 标签: IPTC, Webp, crop, exif, gd, image, merge, resize, thumbnail, watermark, xmp

## 简介

A simple PHP library to manipulate images: resize, crop, rotate, filters, text and merging (JPEG, PNG, GIF, WebP)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
