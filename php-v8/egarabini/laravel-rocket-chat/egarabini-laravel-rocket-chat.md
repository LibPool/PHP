# egarabini/laravel-rocket-chat

> 标签: API-Client, laravel, rocket-chat, rocket-chat-laravel

## 简介

Rocket Chat REST API client for Laravel 7.x.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
