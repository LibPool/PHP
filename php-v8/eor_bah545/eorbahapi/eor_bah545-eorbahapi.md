# eor_bah545/eorbahapi

> 标签: EorbahAPI, api-php, php-web-frameworks-apis

## 简介

EORBAH API est un framework web PHP moderne, rapide et haute performance, conçu pour construire des API avec une syntaxe épurée, inspiré de frameworks modernes comme Express.js et FastAPI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
