# sevada/nie-validator

> 标签: NIE, identity, laravel, spain, spanish, validation, validator

## 简介

Laravel validation rule for Spanish NIE (Número de Identidad de Extranjero) numbers

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
