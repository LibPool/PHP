# basedigital/forms

> 标签: Forms, aire, laravel

## 简介

Motor de formulários neutro de framework CSS (fluent builder + validação client-side), mantendo a facade Aire:: por compatibilidade

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
