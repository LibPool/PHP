# t3sbs/t3sb-package

> 标签: t3sbootstrap

## 简介

The EXT t3sbootstrap requires this extension as a site package for outsourced files from 'CDN to local' and 'Custom SCSS' etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
