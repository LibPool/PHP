# t3sbs/t3sbootstrap

> 标签: TYPO3 CMS, bootstrap, typo3

## 简介

Bootstrap Components - Startup extension to use Bootstrap 5 classes, components and more out of the box.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
