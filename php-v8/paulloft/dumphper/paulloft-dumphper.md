# paulloft/dumphper

> 标签: debug, debugger, dump, dumper, dumphper, var_dump

## 简介

DumPHPer is an advanced PHP variable dumper, that shows detailed info in a simple way..

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
