# arcanisgk/web-cli-detector

> 标签: PHP

## 简介

WEB CLI detector: is a library that allows any development to detect if it is running through the PHP CLI service or a Web Server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
