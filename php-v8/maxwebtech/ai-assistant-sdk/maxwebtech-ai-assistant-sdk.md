# maxwebtech/ai-assistant-sdk

> 标签: ai, assistant, chat, chatbot, conversation, jwt, sdk, widget

## 简介

PHP SDK for AI Assistant integration with JWT authentication and conversation limits

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
