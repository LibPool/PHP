# dorpmaster/dbal-amphp-postgres

> 标签: amphp, async, dbal, doctrine, postgres, postgresql

## 简介

PostgreSQL-only Doctrine DBAL driver backed by an AMPHP transport.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
