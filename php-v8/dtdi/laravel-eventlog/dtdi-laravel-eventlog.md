# dtdi/laravel-eventlog

> 标签: Event Log, OCEL, XES, laravel, laravel-eventlog, process mining, process science

## 简介

A package for exporting event log tables to Process Mining Logs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
