# teamchallengeapps/upcloud-metrics

> 标签: PHP

## 简介

Poll UpCloud managed database metrics and dispatch an event when CPU, disk or memory usage breaches configured thresholds.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
