# sabitahmad/laravel-bkash

> 标签: SabitAhmad, laravel, laravel-bkash

## 简介

Unofficial Bkash Package for Laravel providing seamless integration with Bkash payment gateway.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
