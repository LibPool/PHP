# baks-dev/products-stocks-telegram

> 标签: baksdev, bundle, library, module, plugin, product, stocks, symfony, telegram

## 简介

Модуль управления складским учетом продукции с помощью Telegram

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
