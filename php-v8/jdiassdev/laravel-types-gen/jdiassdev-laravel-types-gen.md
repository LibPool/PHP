# jdiassdev/laravel-types-gen

> 标签: api-resource, formrequest, generator, laravel, types, typescript

## 简介

Generate TypeScript types from Laravel FormRequests and API Resources.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
