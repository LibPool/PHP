# lindera/lindera

> 标签: Chinese, extension, japanese, korean, morphological-analysis, nlp, tokenizer

## 简介

PHP extension for Lindera, a multilingual morphological analysis library (no embedded dictionaries)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
