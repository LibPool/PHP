# chengkangzai/laravel-waha-saloon-sdk

> 标签: cck, laravel, laravel-waha-saloon-sdk

## 简介

WAHA SDK that is generated from WAHA postman collection that is wrapped in SaloonPHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
