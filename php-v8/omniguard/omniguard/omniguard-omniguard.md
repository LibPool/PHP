# omniguard/omniguard

> 标签: authorization, bitmasking, heuristic-discovery, high-performance, laravel, multitenancy, orchestrator, permissions, php, rbac, security, sovereign-code, zero-dependency

## 简介

The absolute sovereign authorization orchestrator for Laravel. Zero-dependency runtime, heuristic discovery, and JIT binary bitmasking optimized for $1 shared hosting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
