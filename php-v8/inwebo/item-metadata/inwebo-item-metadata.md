# inwebo/item-metadata

> 标签: archive.org, internet-archive, json-patch, metadata, wayback-machine

## 简介

PHP client library for the Internet Archive Item Metadata API

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
