# inwebo/seo-bundle

> 标签: breadcrumbs, bundle, metadata, seo, symfony

## 简介

A lightweight Symfony bundle to manage SEO metadata and breadcrumbs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
