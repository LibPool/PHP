# inwebo/paginator-bundle

> 标签: bundle, doctrine, pagination, symfony, twig

## 简介

A lightweight Symfony bundle providing Doctrine-backed pagination with Twig helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
