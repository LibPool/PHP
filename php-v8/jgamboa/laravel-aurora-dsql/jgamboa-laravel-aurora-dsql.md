# jgamboa/laravel-aurora-dsql

> 标签: aurora, aws, dsql, laravel, postgres

## 简介

Laravel driver for Amazon Aurora DSQL: IAM token auth, DSQL-compatible schema builder (inline PK/FK, ASYNC indexes, identity) and migration helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
