# codiblenet/laravel-mail-reacher

> 标签: email, laravel, mail-reacher, mailer, transactional-email, transport

## 简介

Official Laravel mail transport for Mail Reacher.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
