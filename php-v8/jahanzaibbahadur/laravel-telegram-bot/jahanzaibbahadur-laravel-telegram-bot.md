# jahanzaibbahadur/laravel-telegram-bot

> 标签: bot, laravel, telegram

## 简介

Package to integrate PHP Telegram Bot library in Laravel 6.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
