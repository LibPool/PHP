# xddesigners/silverstripe-custom-cms-logo

> 标签: cms, custom, logo, silverstripe

## 简介

Allows you to customize CMS logo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
