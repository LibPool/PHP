# xddesigners/silverstripe-better-forms

> 标签: Forms, admin, cms, grid, layout, silverstripe, tooltip, ux

## 简介

Nicer CMS forms: a Bootstrap grid layout field, help tooltips after labels, and per-field colour/outline styling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
