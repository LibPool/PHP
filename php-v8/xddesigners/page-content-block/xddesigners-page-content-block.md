# xddesigners/page-content-block

> 标签: blocks, editor, elemental, elements, silverstripe

## 简介

Adds a page content block to SilverStripe elemental editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
