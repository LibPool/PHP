# xddesigners/silverstripe-qr-code-generator

> 标签: cms, qr, qr-code, qrcode, silverstripe

## 简介

Create QR codes with an embedded logo and short redirect URLs, managed in the SilverStripe CMS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
