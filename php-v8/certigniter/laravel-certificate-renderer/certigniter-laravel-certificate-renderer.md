# certigniter/laravel-certificate-renderer

> 标签: certificate, certigniter, igniter, laravel, pdf

## 简介

Open, parse, and render Certigniter .igniter certificate packages as PDFs from any Laravel app.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
