# webvariants/eventlog

> 标签: PHP

## 简介

AddOn for SallyCMS to log events

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.sallycms.de/
- 源码仓库：https://bitbucket.org/webvariants/eventlog
- Packagist 页面：https://packagist.org/packages/webvariants%2Feventlog
