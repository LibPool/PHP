# webvariants/scaffold

> 标签: PHP

## 简介

AddOn for SallyCMS, providing Scaffold (CSS preprocessor) for the asset cache system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
