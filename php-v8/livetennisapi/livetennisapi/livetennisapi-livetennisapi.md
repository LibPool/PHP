# livetennisapi/livetennisapi

> 标签: API-Client, ITF, atp, live-scores, livescore, odds, sdk, sports, sports-api, tennis, tennis-api, wta

## 简介

Official PHP client for the Live Tennis API — real-time tennis scores, players, fixtures, head-to-heads, a 1968-onward results archive, point-by-point tapes, rally and charting data, rankings, match-winner market prices and model win-probability for ATP, WTA, Challenger, ITF and juniors.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
