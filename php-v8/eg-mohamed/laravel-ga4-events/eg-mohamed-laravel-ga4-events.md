# eg-mohamed/laravel-ga4-events

> 标签: Google Tag Manager, MohamedSaid, analytics, datalayer, facebook pixel, gtm, laravel, meta pixel

## 简介

A Laravel package to push events to Google Tag Manager dataLayer and Meta Pixel from PHP, Livewire, and JavaScript.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
