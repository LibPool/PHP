# eg-mohamed/paymob-payout

> 标签: eg-mohamed, laravel, paymob-payout

## 简介

Laravel wrapper for Paymob Payouts API to check balance, track transactions, and perform instant cash-in.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
