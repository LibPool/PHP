# arno974/lizmap-altiprofil

> 标签: altitude, dem, jelix, lizmap, module, profile

## 简介

Jelix module for Lizmap, which adds tools to get a profile graph from a DEM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
