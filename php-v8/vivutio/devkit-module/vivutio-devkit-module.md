# vivutio/devkit-module

> 标签: devkit, symfony, vivutio

## 简介

The vivutio development kit: the fleet gate, which creates a project from the skeleton and proves the platform installs and runs as one product. Development only.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
