# vivutio/property-module

> 标签: hospitality, property, symfony, tourism, vivutio

## 简介

Properties for vivutio: the camps, lodges and hotels an organization runs, each a place to post people and a scope to grant permissions at.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
