# vivutio/skeleton

> 标签: Skeleton, symfony, tourism, travel, vivutio

## 简介

An empty vivutio installation: the core and nothing else, the same for every supplier, operator and agent. Add the modules that apply to you.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
