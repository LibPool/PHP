# vivutio/vivutio

> 标签: core, platform, symfony, tourism, travel, vivutio

## 简介

The vivutio core: identity, the shell, the registry, places, partners and the hub connection, shipped as one package and one version.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
