# maftuhichsan/sqlite-wilayah-indonesia

> 标签: PHP

## 简介

Database SQLite wilayah Indonesia (provinsi, kabupaten, kecamatan, desa) berdasarkan BPS (Badan Pusat Statistik).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
