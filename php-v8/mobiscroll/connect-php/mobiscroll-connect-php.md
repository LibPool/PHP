# mobiscroll/connect-php

> 标签: CalDAV, apple-calendar, calendar-api, calendar-connectivity, calendar-sync, google-calendar, mobiscroll, oauth2, outlook-calendar, scheduling

## 简介

PHP client for Mobiscroll Connect, the calendar connectivity layer for scheduling products — Google Calendar, Microsoft Outlook, Apple Calendar and CalDAV through one API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
