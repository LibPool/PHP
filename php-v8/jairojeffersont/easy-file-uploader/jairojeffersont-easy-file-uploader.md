# jairojeffersont/easy-file-uploader

> 标签: PHP

## 简介

Biblioteca PHP simples para upload e exclusão de arquivos com validação de tipo e tamanho.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
