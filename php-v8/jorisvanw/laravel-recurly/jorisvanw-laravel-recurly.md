# jorisvanw/laravel-recurly

> 标签: api, billing, laravel, laravel 5, recurly, recurring

## 简介

A simple Laravel 5 service provider for including the Recurly PHP client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
