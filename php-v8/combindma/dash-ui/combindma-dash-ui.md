# combindma/dash-ui

> 标签: combind, dash-ui, laravel

## 简介

A streamlined and stylish UI component library for Laravel Blade, crafted with TailwindCSS and AlpineJs for simplicity and elegance.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
