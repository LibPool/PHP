# pwnraid/bnet

> 标签: api, battle.net, blizzard, bnet, diablo, starcraft, warcraft

## 简介

Library for working with the Battle.net Web APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
