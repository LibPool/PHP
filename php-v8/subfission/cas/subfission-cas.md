# subfission/cas

> 标签: SSO, cas, laravel, laravel 10, laravel 11, laravel 6, laravel 7, laravel 8, laravel 9, phpCAS

## 简介

Adds CAS support to Laravel 5.x - 11.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
