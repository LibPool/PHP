# wali/smart-seeder

> 标签: PHP

## 简介

A PHP/Laravel package for generating fake localized data (Arabic names, Hijri dates, Saudi IBAN, etc.).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
