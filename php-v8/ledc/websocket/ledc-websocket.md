# ledc/websocket

> 标签: PHP

## 简介

Su WebSocket是一个go语言编写的高性能WebSocket服务器，支持客户端连接管理、UID管理、群组管理、消息推送、RPC调用等功能；完全参考GatewayWorker设计的HTTP管理API接口。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
