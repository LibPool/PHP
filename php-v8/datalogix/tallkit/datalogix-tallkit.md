# datalogix/tallkit

> 标签: alpine, blade, components, kit, laravel, livewire, tailwind, tall

## 简介

A set of components to utilize in your Laravel Blade views using TALL stack.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
