# osmianski/packages

> 标签: composer, packages

## 简介

A library that returns a list of installed Composer packages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://github.com/osmianski/packages
- 源码仓库：https://github.com/osmianski/packages.git
- Packagist 页面：https://packagist.org/packages/osmianski%2Fpackages

## 获取地址

- Composer 安装：`composer require osmianski/packages`
