# elmyrockers/ezflash

> 标签: PHP

## 简介

EzFlash PHP library - Lightweight, simple and easy way to display flash message with Bootstrap 5 (Alert) template

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
