# oleant/laravel-visit-analytics

> 标签: UTM, analytics, laravel, privacy, visit-log

## 简介

Privacy-focused visit analytics for Laravel 10/11/12 with UTM and Referrer tracking.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
