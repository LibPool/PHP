# hanovate/cas

> 标签: SSO, cas, laravel, laravel 7, laravel 8, phpCAS

## 简介

Adds CAS support to Laravel 7.x or 8.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
