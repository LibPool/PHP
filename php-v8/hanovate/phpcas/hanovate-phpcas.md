# hanovate/phpcas

> 标签: apereo, cas, hanovate, jasig, laravel

## 简介

Provides a simple API for authenticating users against a CAS server for Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
