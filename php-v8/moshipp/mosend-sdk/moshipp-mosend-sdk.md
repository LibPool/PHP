# moshipp/mosend-sdk

> 标签: api, messaging, mosend, sdk, whatsapp, whatsapp-business

## 简介

SDK oficial de PHP para la API de Mosend (WhatsApp Business, Web Chat, Bot, Billing, Webhooks).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
