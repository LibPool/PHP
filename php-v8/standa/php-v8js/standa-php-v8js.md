# standa/php-v8js

> 标签: extension, javascript, php-ext, pie, v8

## 简介

V8 JavaScript Engine for PHP (PIE-installable wrapper around phpv8/v8js, php8 branch)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
