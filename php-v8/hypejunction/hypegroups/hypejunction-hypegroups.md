# hypejunction/hypegroups

> 标签: elgg, groups, plugin, subtypes

## 简介

Extended group functionality for Elgg — subtypes, hierarchies, fields, and tools management.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
