# hypejunction/hypeinbox

> 标签: elgg, inbox, messages, plugin

## 简介

Enhanced messaging for Elgg — multiple inboxes, message threading, and real-time updates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
