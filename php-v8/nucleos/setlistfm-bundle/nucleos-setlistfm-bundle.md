# nucleos/setlistfm-bundle

> 标签: api, bundle, setlist, setlist.fm, symfony, webservice client

## 简介

This bundle provides services for using the setlist.fm API with symfony.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
