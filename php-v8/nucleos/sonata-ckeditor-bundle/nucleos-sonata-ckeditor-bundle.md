# nucleos/sonata-ckeditor-bundle

> 标签: CKEditor, autoconfigure, sonata, sonata-media, symfony

## 简介

Symfony Bundle that allows sonata media management for the CKEditor.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
