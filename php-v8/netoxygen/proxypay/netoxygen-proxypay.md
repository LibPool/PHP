# netoxygen/proxypay

> 标签: payment, proxypay, sha

## 简介

ProxyPay library. Provides methods to compose SHA signatures and to check ProxyPay responses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
