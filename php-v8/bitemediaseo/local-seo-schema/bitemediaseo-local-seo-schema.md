# bitemediaseo/local-seo-schema

> 标签: JSON-LD, ai-seo, bitemediaseo, geo-seo, local-seo, pozycjonowanie-stron-szczecin, schema-org, seo, seo-szczecin, structured-data

## 简介

Lekki helper PHP do generowania danych Schema.org JSON-LD dla local SEO, uslug i pozycjonowania stron w Szczecinie.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
