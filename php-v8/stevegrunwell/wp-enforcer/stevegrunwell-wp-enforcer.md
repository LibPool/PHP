# stevegrunwell/wp-enforcer

> 标签: PHP_CodeSniffer, coding standards, git hooks, wordpress

## 简介

Git hooks to encourage well-written WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
