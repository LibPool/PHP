# chenm/websafe

> 标签: PHP

## 简介

专为支持psr-4规范框架开发的web安全防御脚本，支持POST、GET、COOKIE、SESSION等方面的常见注入防御，后续会完善更多外部数据层面的漏洞防护和相关功能

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
