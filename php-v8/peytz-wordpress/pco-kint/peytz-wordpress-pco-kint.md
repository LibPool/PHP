# peytz-wordpress/pco-kint

> 标签: debug, kint, plugin, wordpress

## 简介

Kint debugger for WordPress - a powerful and modern PHP debugging tool.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
