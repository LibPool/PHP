# yjx/easy-di

> 标签: PSR-11, container, container-interop, dependency injection, di, ioc, psr11

## 简介

An easy dependencies inject container, which implements Psr-11.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
