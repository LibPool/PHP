# cxgphper/swoft-limiter

> 标签: cxgphper, limiter, php, swoft, swoole

## 简介

The component is a current limiter based on swoft Redis component that can be executed a limited number of times in a limited time.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
