# hibernator/hibernator-phplib

> 标签: PHP

## 简介

Write PHP code that sleeps for months. A Durable Execution Engine using Fibers and Replay Pattern to replace complex cron/queue logic.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
