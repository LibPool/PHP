# log1x/captured

> 标签: captured, capturedapp, macos, screenshot

## 简介

A bulletproof rewrite of the Captured PHP script for use with CapturedApp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
