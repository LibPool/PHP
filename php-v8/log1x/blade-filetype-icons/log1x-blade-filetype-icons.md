# log1x/blade-filetype-icons

> 标签: File Icons, File Type Icons, blade, laravel

## 简介

A package to easily make use of dmhendricks/file-icon-vectors in your Laravel Blade views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
