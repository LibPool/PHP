# log1x/blade-svg-sage

> 标签: blade, roots, sage, svg, wordpress

## 简介

Composer package to add support for Blade SVG by Adam Wathan to Roots Sage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
