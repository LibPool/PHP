# stephenjude/filament-feature-flags

> 标签: filament-feature-flags, laravel, stephenjude

## 简介

Filament implementation of feature flags and segmentation with Laravel Pennant.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
