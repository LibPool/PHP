# stephenjude/filament-jetstream

> 标签: filament, filament-jetstream, laravel, starter kit, stephenjude

## 简介

A Laravel starter kit built with Filament inspired by Jetstream.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
