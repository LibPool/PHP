# ananto-in/mf-categories

> 标签: amfi, fintech, india, mutual-funds, open-data, sebi

## 简介

Open reference data for Indian mutual fund scheme categories: SEBI's categorization with stable IDs, characteristics, AMFI label aliases and change history.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
