# mikespub/web-comic-reader

> 标签: PHP

## 简介

Web Based cbr/cbz/cbt comic book reader. Written in HTML5 and Javascript

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
