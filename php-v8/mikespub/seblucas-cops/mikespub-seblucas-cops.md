# mikespub/seblucas-cops

> 标签: PHP

## 简介

Calibre OPDS (and HTML) PHP Server : web-based light alternative to Calibre content server / Calibre2OPDS to serve ebooks (epub, mobi, pdf, ...)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
