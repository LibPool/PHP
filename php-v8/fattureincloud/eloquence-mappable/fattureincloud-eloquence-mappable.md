# fattureincloud/eloquence-mappable

> 标签: eloquent, laravel, mappable

## 简介

Flexible Searchable, Mappable, Metable, Validation and more extensions for Laravel Eloquent ORM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
