# omniphp/framework

> 标签: async, framework, http, orm, queue, redis, router, template, workerman

## 简介

OmniPHP — The universal PHP framework. Lightweight, Workerman-based: HTTP router & middleware, query builder & migrations, Redis Stream queue, template engine, cache, i18n and structured logging.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
