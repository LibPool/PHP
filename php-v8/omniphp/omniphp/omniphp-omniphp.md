# omniphp/omniphp

> 标签: Skeleton, framework, omniphp, workerman

## 简介

OmniPHP application skeleton — a ready-to-run Workerman project layout for the OmniPHP framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
