# manja/typo3-storage-connector

> 标签: TYPO3 CMS, digital asset management, manja, typo3

## 简介

Provides a Manja driver for TYPO3 File Abstraction Layer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
