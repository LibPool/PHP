# gleisonnanet/cidades-gratis

> 标签: cidades, estados, ibge, php

## 简介

Com esse pacote você poderá consultar, gratuitamente, Cidades diretamente no site do IBGE.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
