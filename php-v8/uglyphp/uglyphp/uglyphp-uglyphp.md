# uglyphp/uglyphp

> 标签: blade, css, design-system, design-tokens, laravel, livewire, styling

## 简介

A typed, zero-runtime design-system engine for Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
