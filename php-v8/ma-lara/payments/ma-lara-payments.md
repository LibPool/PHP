# ma-lara/payments

> 标签: laravel, online-payments, payment, payment-gateway, payments, paymob, paymob-mobile-wallet, php, stripe

## 简介

A Laravel payment gateway package that provides a unified API for integrating multiple payment providers, including Stripe and Paymob, with support for payments, payment verification, retries, refunds, transactions, and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
