# marketplacer/magento2-plugin-marketplacer

> 标签: PHP

## 简介

Summary package for Marketplacer brands and sellers on listings and in orders

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
