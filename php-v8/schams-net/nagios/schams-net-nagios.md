# schams-net/nagios

> 标签: PHP

## 简介

Monitors TYPO3 instances and warns about insecure extensions, old TYPO3 versions, wrong PHP versions, etc. Requires a Nagios monitoring server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
