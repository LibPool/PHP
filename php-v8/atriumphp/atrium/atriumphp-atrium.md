# atriumphp/atrium

> 标签: admin, admin-panel, crud, dashboard, live-components, symfony, ux

## 简介

A PHP-configured, modular admin panel framework for Symfony, powered by Live Components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
