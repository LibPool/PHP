# iyoworks/validation

> 标签: Laravel 4, laravel, validation

## 简介

Provides a base class to implement validation as a service. Also adds a little sugar to Laravel's validator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
