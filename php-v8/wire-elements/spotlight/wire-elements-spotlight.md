# wire-elements/spotlight

> 标签: laravel, livewire-ui, spotlight

## 简介

Livewire component that provides Spotlight/Alfred-like functionality to your Laravel application.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
