# morrislaptop/laravel-popo-caster

> 标签: laravel-popo-caster, morrislaptop

## 简介

Automatically cast JSON columns to rich PHP objects in Laravel using Symfony's Serializer

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
