# roukmoute/pdf

> 标签: AES-GCM, iso-32000-1, iso-32000-2, object-model, pdf, pdf-1.7, pdf-2.0, pdf-mac, php, tagged-pdf, xmp

## 简介

Explicit PDF 1.7/2.0 objects and writing with executable specification rules, conservative redaction, signatures, encryption and tagged-structure validation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
