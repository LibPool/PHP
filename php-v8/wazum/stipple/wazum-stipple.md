# wazum/stipple

> 标签: ansi, braille, cli, half-block, icons, render, svg, symfony, terminal, tui

## 简介

Render small SVG icons to monochrome ANSI for terminal UIs — Symfony TUI, Laravel Prompts, Symfony Console or plain CLI.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
