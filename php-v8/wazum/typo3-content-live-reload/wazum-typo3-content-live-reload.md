# wazum/typo3-content-live-reload

> 标签: Hmr, cache tags, developer experience, live reload, typo3, vite

## 简介

Live-reloads the open frontend tabs affected by a content change in the backend, using TYPO3 cache tags to reload only the tabs that show the changed record.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
