# zfegg/sms-sender

> 标签: Sender, captcha, handler, sms, sms-sender, zfegg

## 简介

SMS sender service. And use for send sms captcha handler / 短信发送模块, 并且用于发送短信验证码处理程序

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
