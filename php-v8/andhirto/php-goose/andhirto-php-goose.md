# andhirto/php-goose

> 标签: content, extractor, http, readability, scraper, scraping, text, website

## 简介

Readability / Html Content / Article Extractor & Web Scrapping library written in PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
