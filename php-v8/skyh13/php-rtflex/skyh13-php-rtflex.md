# skyh13/php-rtflex

> 标签: PHP

## 简介

A simple library to allow parsing of RTF files and strings. Forked from silvermine/php-rtflex.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
