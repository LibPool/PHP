# dhorrigan/capsule

> 标签: database, laravel

## 简介

A simple wrapper class for the Laravel Database package.  This is only to be used outside of a Laravel application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
