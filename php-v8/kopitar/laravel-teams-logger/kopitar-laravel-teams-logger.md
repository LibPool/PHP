# kopitar/laravel-teams-logger

> 标签: Teams, handler, laravel, monolog

## 简介

Laravel package for sending configurable messages to Microsoft Teams via the incoming webhook url

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
