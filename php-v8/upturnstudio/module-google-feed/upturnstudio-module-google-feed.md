# upturnstudio/module-google-feed

> 标签: PHP

## 简介

Google Merchant Center product feeds with configurable attribute mapping, ad-click capture on orders, and a REST API for spend-vs-sales attribution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
