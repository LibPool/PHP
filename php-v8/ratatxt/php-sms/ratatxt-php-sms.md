# ratatxt/php-sms

> 标签: Simple, phone, php, ratatxt, simcard, sms

## 简介

SMS Library for PHP. Simple SMS API that uses your regular simcard load

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
