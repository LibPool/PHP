# nofuzz/framework

> 标签: Microservice, PHP7, api, framework, php-framework, rest, rest-api

## 简介

A PHP nano framework for REST API's & Micro-Services

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
