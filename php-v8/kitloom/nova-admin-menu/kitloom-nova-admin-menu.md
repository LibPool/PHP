# kitloom/nova-admin-menu

> 标签: admin, drag-and-drop, laravel, menu, navigation, nova, sidebar, sorting

## 简介

Manage the Laravel Nova admin menu from the admin panel: reorder and nest entries by dragging, move them between sections, rename them, set icons, hide them, restrict them to permissions, and add sections and links of your own.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
