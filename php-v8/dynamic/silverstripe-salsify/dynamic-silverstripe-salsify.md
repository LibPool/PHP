# dynamic/silverstripe-salsify

> 标签: PIM, PXM, cms, salsify, silverstripe

## 简介

Salsify integration for SilverStripe websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
