# dynamic/foxystripe

> 标签: Foxycart, dynamic, ecommerce, foxystripe, silverstripe

## 简介

FoxyStripe is a SilverStripe ecommerce module that integrates with FoxyCart for order processing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
