# dynamic/silverstripe-elemental-carousel

> 标签: cms, silverstripe

## 简介

A block to implement dynamic/silverstripe-carousel, a simple carousel for Silverstripe in Bootstrap.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
