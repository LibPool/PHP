# daanra/mailgun

> 标签: bogardo, email, laravel, mail, mailgun

## 简介

Laravel package for sending mail via the Mailgun API with support for Laravel 7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
