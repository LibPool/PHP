# nickjbedford/hooks

> 标签: actions, filters, hooks

## 简介

Hooks is a small library that provided hookable actions and filters, similar to WordPress. This can be used in any PHP 8.0+ project.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
