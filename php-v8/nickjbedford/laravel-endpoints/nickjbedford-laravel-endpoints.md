# nickjbedford/laravel-endpoints

> 标签: api, json, rest

## 简介

The Laravel Endpoints framework provides an easy way to implement API endpoints in separate Responsable-style classes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
