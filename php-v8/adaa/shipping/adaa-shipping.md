# adaa/shipping

> 标签: carriers, ecommerce, labels, laravel, multi-vendor, php, shipping, tracking

## 简介

Framework-agnostic multi-carrier shipping library for PHP with optional Laravel integration. Platform-owned and merchant-owned connections, normalized statuses, idempotent shipments.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
