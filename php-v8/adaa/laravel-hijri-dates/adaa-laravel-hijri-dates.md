# adaa/laravel-hijri-dates

> 标签: calendar, date, hijri, islamic, laravel

## 简介

Hijri (Islamic) date support for Laravel, using geniusTS/hijri-dates.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
