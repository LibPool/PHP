# bloke/smd_prognostics

> 标签: change, detect, diagnostics, filesystem, plugin, security, textpattern, trojan

## 简介

Pro-active diagnostics that alarm when things have changed in Textpattern CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
