> 标签: audio, conversion, ffmpeg, fluent, hls, laravel, media, processing, ritechoice23, streaming, video

## 简介

A fluent, chainable API for working with FFmpeg in Laravel applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
