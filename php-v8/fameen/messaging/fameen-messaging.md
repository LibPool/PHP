# fameen/messaging

> 标签: email, fameen, laravel, messaging, notifications, sms, whatsapp

## 简介

SDK PHP officiel de l'API Fameen Messaging (SMS, WhatsApp, Email) — zéro dépendance, avec pont Laravel intégré.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
