# sura/php-ffmpeg

> 标签: audio, audio processing, avconv, avprobe, ffmpeg, ffprobe, video, video processing

## 简介

FFMpeg PHP, an Object Oriented library to communicate with AVconv / ffmpeg

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
