# fmaj/cloudfront-trusted-proxies

> 标签: PHP

## 简介

Provides a way to retrieve cloudfront proxies ip ranges with caching mechanism

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
