# seoshop/seoshop-php

> 标签: api, client, ecom, lightspeed, php

## 简介

PHP client for the Lightspeed eCom API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/SEOshop/API-PHP-Client.git
