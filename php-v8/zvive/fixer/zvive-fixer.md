# zvive/fixer

> 标签: laravel, php-cs-fixer, tooling

## 简介

PHP CS Fixer w/ additional fixers based off of permafrost-dev/phpcsfixer-preset

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
