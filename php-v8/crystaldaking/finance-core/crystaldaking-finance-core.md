# crystaldaking/finance-core

> 标签: Accounting, Audit, decimal, finance, fintech, idempotency, ledger, money, php-sdk

## 简介

Framework-agnostic PHP financial core for money, assets, ledgering, fees, audit, events and idempotency.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
