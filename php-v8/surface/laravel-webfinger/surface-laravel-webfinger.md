# surface/laravel-webfinger

> 标签: activitypub, laravel, laravel-webfinger, mastodon, trovster, webfinger

## 简介

A Laravel package to create an ActivityPub webfinger.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
