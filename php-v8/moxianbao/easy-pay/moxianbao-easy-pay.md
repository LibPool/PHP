# moxianbao/easy-pay

> 标签: alipay, easy-pay, gateway, lakala, leshua, pay, payment, php-sdk, sdk, wechat-pay, wechatpay

## 简介

Framework-agnostic PHP payment SDK for Alipay, Wechat Pay, Leshua, and Lakala with unified gateway APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
