# ofbeaton/phpami

> 标签: ami, asterisk, astx, pagi, pami, phpagi, phpami

## 简介

Asterisk Manager Interface (AMI) for PHP 5.4+ supporting legacy v1.4 to v13 with no thrills.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
