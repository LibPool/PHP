# areia-lab/laravel-traffic-control

> 标签: PHP

## 简介

Traffic control toolkit for Laravel — advanced throttling, blocking, bot detection, analytics, and dashboard.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
