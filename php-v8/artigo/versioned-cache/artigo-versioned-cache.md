# artigo/versioned-cache

> 标签: cache, cache-invalidation, cache-stampede, psr-6, redis, symfony, thundering-herd

## 简介

Tag invalidation that never gets slower: a tag-aware symfony/cache adapter for Redis 8.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
