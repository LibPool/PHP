# chatflowphp/core

> 标签: chatbot, conversation, scenes, state-machine, telegram

## 简介

Platform-neutral conversational runtime for PHP: scenes as states on top of chatflowphp/automata.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
