# zendframework/zend-captcha

> 标签: ZendFramework, captcha, zf

## 简介

Generate and validate CAPTCHAs using Figlets, images, ReCaptcha, and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
