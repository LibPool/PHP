# zendframework/zendservice-amazon

> 标签: amazon, ec2, s3, simpledb, sqs, zf2

## 简介

OOP wrapper for the Amazon web service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
