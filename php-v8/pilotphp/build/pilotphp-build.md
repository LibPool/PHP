# pilotphp/build

> 标签: agent-first, build, orchestration, pilotphp

## 简介

Universal infrastructure-only build orchestrator for PilotPHP declaration replay, stage graphs, and artifact publication.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
