# pilotphp/container

> 标签: agent-first, compiled, container, dependency-injection, pilotphp

## 简介

Compiled dependency injection container for the PilotPHP Agent-First framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
