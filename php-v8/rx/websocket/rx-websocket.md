# rx/websocket

> 标签: WebSockets, react, reactive, rfc6455, rx, rx.php, rxphp, websocket

## 简介

Websockets for PHP using Rx

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
