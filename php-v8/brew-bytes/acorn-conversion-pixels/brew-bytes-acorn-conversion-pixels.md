# brew-bytes/acorn-conversion-pixels

> 标签: Advertising, acorn, facebook-pixel, linkedin-insight, meta-pixel, pixels, roots, sage, tiktok-pixel, wordpress

## 简介

Drop-in advertising-pixel integration for Roots Sage themes — Meta, LinkedIn, TikTok, Pinterest, X, Reddit, and Snap pixels with consent-required defaults and the unified custom-events API from acorn-analytics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
