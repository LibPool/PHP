# phpviet/omnipay-vnpay

> 标签: payment, payment-gateway, phpviet, vietnam-payment, vietnam-payment-gateway, vnpay

## 简介

Thư viện hổ trợ tích hợp cổng thanh toán VNPay.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
