# ericmann/ext-c2pa

> 标签: PHP

## 简介

PHP 8.3+ native C2PA Content Credentials: read/validate manifests and sign Media Library images incl. derivatives.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
