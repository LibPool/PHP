# ccarver/queue-watcher-laravel

> 标签: PHP

## 简介

Laravel integration for the queue-watcher Go package — emits job telemetry over stdout as newline-delimited JSON.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
