# allus/company-data

> 标签: allme, allus, company-data, sdk

## 简介

PHP SDK for the allus company-data API: typed, plaintext, slug-keyed conclusions with transparent decryption.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
