# drefined/ratelimit-bundle

> 标签: api, rest, x-rate-limit

## 简介

This bundle provides functionality to limit calls to actions based on rate limits

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
