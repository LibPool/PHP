# tvdijen/simplesamlphp-module-ldappasswordreset

> 标签: ldap, password, reset, simplesamlphp

## 简介

A module that provides password reset functionality for LDAP-backends

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
