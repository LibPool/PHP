# deanar/yii2-file-processor

> 标签: Thumbnails, crop, extension, files, images, resize, upload, yii2

## 简介

Upload and process files and images for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
