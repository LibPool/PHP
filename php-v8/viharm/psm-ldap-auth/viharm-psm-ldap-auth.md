# viharm/psm-ldap-auth

> 标签: ad, auth, ldap, openldap, php, php server monitor, psm

## 简介

Module for authenticating PHP Server Monitor users against a directory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
