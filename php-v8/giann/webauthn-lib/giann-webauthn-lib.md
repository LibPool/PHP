# giann/webauthn-lib

> 标签: FIDO2, fido, webauthn

## 简介

Fork of web-auth/webauthn-lib that supports Android FIDO2/Passkey attestations

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
