# xiaohigh/pscws4

> 标签: PHP

## 简介

借助开源免费分词系统pscws4,实现一个简单的php分词类文件,方便进行中文分词

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
