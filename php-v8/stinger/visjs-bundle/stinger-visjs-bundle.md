# stinger/visjs-bundle

> 标签: browser, browser based, chart, graph, javascript, linechart, network, timeline, vis, visualization, web based

## 简介

Symfony2 Bundle for the dynamic, browser-based visualization library developed by http://visjs.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.visjs.org
- 源码仓库：https://github.com/Stinger-Soft/VisJsBundle.git
