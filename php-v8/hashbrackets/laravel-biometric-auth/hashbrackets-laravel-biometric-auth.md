# hashbrackets/laravel-biometric-auth

> 标签: Authentication, FIDO2, Fingerprint, Passwordless, biometric, faceid, laravel, passkeys, webauthn, windows-hello

## 简介

Passwordless biometric authentication package for Laravel using WebAuthn/FIDO2 standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
