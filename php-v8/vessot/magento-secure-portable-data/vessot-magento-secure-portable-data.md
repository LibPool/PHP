# vessot/magento-secure-portable-data

> 标签: PHP

## 简介

VESSOT (Vault Encrypted Single Source Of Truth) integration for Magento 2. Syncs order and customer data to VESSOT secure storage service.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
