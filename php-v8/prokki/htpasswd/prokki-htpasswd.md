# prokki/htpasswd

> 标签: Authentication, MD5, apache, basic, bcrypt, blowfish, crypt, htpasswd, password

## 简介

This symfony user provider reads user from the htpasswd file.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
