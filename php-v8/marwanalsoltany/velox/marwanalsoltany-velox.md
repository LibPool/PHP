# marwanalsoltany/velox

> 标签: auth, crud, framework, micro-framework, mvc, php, static-website-generator

## 简介

The minimal PHP micro-framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
