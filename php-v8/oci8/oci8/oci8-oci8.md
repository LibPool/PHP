# oci8/oci8

> 标签: database, oci8, oracle

## 简介

The OCI8 extension lets you access Oracle Database.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/php/pecl-database-oci8
- 源码仓库：https://github.com/php/pecl-database-oci8.git

- 许可证：PHP-3.01
