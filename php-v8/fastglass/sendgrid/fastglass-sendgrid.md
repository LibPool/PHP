# fastglass/sendgrid

> 标签: email, grid, send, sendgrid, twilio sendgrid

## 简介

This library allows you to send emails through SendGrid using PHP and Guzzle 6.x.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
