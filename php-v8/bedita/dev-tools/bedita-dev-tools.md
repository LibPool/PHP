# bedita/dev-tools

> 标签: bedita, cake5, cakephp, debug_kit, plugin, scrutinizer

## 简介

A plugin to give some useful tools to BEdita developers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
