# albertorc87/easyapi

> 标签: PHP

## 简介

EasyAPI es un micro framework pensado en el desarrollo de APIs con arquitectura REST y que no depende de ninguna librería.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
