# hofff/contao-trueurl

> 标签: alias, contao, folderurl, page, path, url

## 简介

Folderlike page alias' with different editing tools and an improved frontend page selection algorithm.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
