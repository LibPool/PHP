# hofff/contao-iconfont

> 标签: FontAwesome, contao, icon, iconfont

## 简介

Insert tag for Contao Open Source CMS to insert FontAwesome icons and individual icons

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
