# mobiweb/sdk

> 标签: 2fa, One Time Password, Two Factor Authentication, api, asynch, hlr, hlr lookup, messaging, mobile lookup, mobile number lookup, mobiweb, otp, php, smpp, smpp api, sms

## 简介

4.0.3 PHP library for communicating with the MobiWeb REST APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
