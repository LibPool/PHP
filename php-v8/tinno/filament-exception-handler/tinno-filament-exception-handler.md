# tinno/filament-exception-handler

> 标签: filament, filament-exception-handler, filament-exceptions, laravel

## 简介

Plug and play exception handler for Filament using bezhansalleh/filament-exceptions

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
