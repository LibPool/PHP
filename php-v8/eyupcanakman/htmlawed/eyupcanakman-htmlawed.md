# eyupcanakman/htmlawed

> 标签: PHP

## 简介

PHP 8.4+ compatible fork of vanilla/htmlawed — a composer wrapper for the htmLawed library to purify & filter HTML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
