# eyupcanakman/simple-html-dom

> 标签: HTML Parser, dom, php dom

## 简介

A modern HTML DOM parser for PHP using DOMDocument and Symfony CssSelector.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
