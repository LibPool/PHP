# carlosdev/model-change-logger

> 标签: Audit, Audit Log, activity log, activity logger, change log, change logger, change tracking, eloquent audit, eloquent changes, eloquent model audit, eloquent model changes, eloquent observer, laravel, laravel audit, laravel model audit, laravel model change, logger, model change logger, model change tracking, model changes, model logger, tracks changes

## 简介

Laravel package to log create, update, and delete events in Eloquent models with JSON snapshots and user attribution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
