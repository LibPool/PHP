# spinx/sidekiq-job-php

> 标签: processing, queue, redis, resque, sidekiq, worker

## 简介

Push and schedule jobs to Sidekiq from PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
