# aklump/loft_data_grids

> 标签: csv, excel, export, spreadsheet

## 简介

PHP Classes to allow data placement in a grid structure and exporting in various data formats.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
