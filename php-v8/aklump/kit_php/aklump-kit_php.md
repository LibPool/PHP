# aklump/kit_php

> 标签: CodeKit, The Kit Language

## 简介

PHP classes for compiling CodeKit's Kit Language (for HTML).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
