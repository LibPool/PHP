# joomlatools/joomla-catcher

> 标签: events, extension, joomla, nooku, plugins

## 简介

A bundle of plugins and a library for catching and debug Joomla! events

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
