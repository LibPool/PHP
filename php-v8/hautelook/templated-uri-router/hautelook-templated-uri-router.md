# hautelook/templated-uri-router

> 标签: HATEOAS, RFC 6570, json, router, symfony, uri, url, xml

## 简介

Symfony URL generator that provides an RFC-6570-compatible router.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
