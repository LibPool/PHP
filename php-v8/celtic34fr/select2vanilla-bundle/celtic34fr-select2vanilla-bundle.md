# celtic34fr/select2vanilla-bundle

> 标签: PHP

## 简介

Symfony bundle for using the vanilla JavaScript library celtic34fr/select2vanilla as a FormType

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
