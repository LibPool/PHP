# php-mcp/laravel

> 标签: ai, laravel, laravel mcp, laravel mcp prompts, laravel mcp resources, laravel mcp sdk, laravel mcp server, laravel mcp tools, laravel model context protocol, llm, mcp, model-context-protocol, tools

## 简介

Laravel SDK for building Model Context Protocol (MCP) servers - Seamlessly integrate MCP tools, resources, and prompts into Laravel applications

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
