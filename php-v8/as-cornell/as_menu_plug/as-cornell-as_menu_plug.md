# as-cornell/as_menu_plug

> 标签: PHP

## 简介

Configurations, functions and templates to add in-page anchor links as link fields under that page's menu item.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
