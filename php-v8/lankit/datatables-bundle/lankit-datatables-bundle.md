# lankit/datatables-bundle

> 标签: LanKit, LanKitDatatables, datatables

## 简介

DataTables.js server-side processing for Doctrine Entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
