# ricv/tablesigniter

> 标签: codeigniter, codeigniter4, datatables

## 简介

This library will help you use jQuery Datatables based on CodeIgniter4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
