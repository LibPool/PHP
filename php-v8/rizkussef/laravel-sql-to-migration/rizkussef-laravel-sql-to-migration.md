# rizkussef/laravel-sql-to-migration

> 标签: convert sql to laravel migration, laravel, laravel migration generator, mysql to laravel migration, php artisan migration generator, sql to migration

## 简介

A Laravel package to convert raw SQL CREATE TABLE statements into Laravel migrations automatically.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
