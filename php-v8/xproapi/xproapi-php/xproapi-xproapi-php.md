# xproapi/xproapi-php

> 标签: Followers, api, tweets, twitter, x, xproapi

## 简介

PHP client for the Xproapi X (Twitter) data API: profiles, followers, followings, tweets, search.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
