# smartdesk/debug-logger

> 标签: debug, hooks, logger, timers, wordpress

## 简介

Human-friendly WordPress debug logger with hook status block and optional rotating file sink.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
