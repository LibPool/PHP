# maltyxx/orm

> 标签: maltyxx, orm, orm codeigniter

## 简介

Librairie ORM for CodeIgniter 2 and CodeIgniter 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
