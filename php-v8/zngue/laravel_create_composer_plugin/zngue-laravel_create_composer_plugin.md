# zngue/laravel_create_composer_plugin

> 标签: PHP

## 简介

Laravel composer自动创建包，让你不在为开发而烦恼，轻轻松松创建自己的包

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
