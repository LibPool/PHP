# kariricode/devkit

> 标签: KaririCode, PHPStan, cli, code-quality, code-style, coverage, developer-tools, devkit, linting, phar, php-cs-fixer, php84, phpunit, psalm, quality, rector, refactoring, static-analysis, testing, toolchain

## 简介

Zero-config PHP quality toolchain for KaririCode Framework. Bundles PHPUnit, PHPStan, PHP-CS-Fixer, Rector, and Psalm under a single `kcode` CLI — isolated in .kcode/ so it never pollutes production dependencies.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
