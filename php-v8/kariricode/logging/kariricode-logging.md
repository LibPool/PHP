# kariricode/logging

> 标签: Application Logging, Asynchronous Logging, Context Logging, Error logging, KaririCode, Log Processor, Log Rotator, System Monitoring, framework, log formatter, log handler, logger, logging, php, psr-3

## 简介

A robust, flexible, and PSR-3 compliant logging component for the KaririCode Framework, providing comprehensive logging capabilities for PHP applications.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
