# praxisnetau/serverpilot-api

> 标签: api, model, php, serverpilot, wrapper

## 简介

A wrapper and data model for the ServerPilot API implemented in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
