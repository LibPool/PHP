# holartweb/axora-cms

> 标签: admin, cms, laravel, vue

## 简介

AxoraCMS — современная, гибкая и удобная CMS для создания быстрых, масштабируемых и красивых сайтов.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
