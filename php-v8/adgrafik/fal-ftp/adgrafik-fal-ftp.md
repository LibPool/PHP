# adgrafik/fal-ftp

> 标签: PHP

## 简介

Provides a FTP and FTP-SSL driver for the TYPO3 File Abstraction Layer (FAL) to manage files via filemanager (filelist).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
