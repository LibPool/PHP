# clean-composer-packages/pdf-js

> 标签: mozilla, pdf, pdf.js, pdfjs

## 简介

Composer build of Mozilla's PDF.js library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
