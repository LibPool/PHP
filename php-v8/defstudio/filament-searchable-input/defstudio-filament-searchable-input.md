# defstudio/filament-searchable-input

> 标签: Forms, defstudio, filament, filamentphp, input, laravel, searchable

## 简介

A searchable autocomplete input for Filament forms

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
