# aminuddin12/insider-pack

> 标签: Users, admin, insider, laravel, package

## 简介

Paket modular Laravel untuk mengelola pengguna internal (staf, admin, developer) secara terpisah.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
