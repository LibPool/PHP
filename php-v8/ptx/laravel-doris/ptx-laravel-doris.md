# ptx/laravel-doris

> 标签: doris-orm, laravel-doris, laravel-starrocks, starrocks-orm

## 简介

This laravel extension adds support for doris and starrocks to the query builder and eloquent.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
