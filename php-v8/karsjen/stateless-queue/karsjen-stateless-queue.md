# karsjen/stateless-queue

> 标签: SNS, aws, cloud-run, google-cloud, laravel, pubsub, push-queue, queue, serverless, stateless, webhook

## 简介

Push-based Laravel queue for stateless runtimes. Publishes jobs to Google Cloud Pub/Sub or AWS SNS and executes them from a signed webhook — no queue worker required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
