# iqrf/iqrf-gateway-configuration-manager

> 标签: iqrf, iqrf-gateway, iqrf-gateway-daemon, iqrf-gateway-webapp, nette

## 简介

PHP library for managing configuration of IQRF Gateway software with Nette framework integration for our PHP projects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
