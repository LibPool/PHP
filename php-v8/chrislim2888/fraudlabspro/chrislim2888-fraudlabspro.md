# chrislim2888/fraudlabspro

> 标签: fraud, fraud detection, fraud prevention, fraudlabs, fraudlabspro

## 简介

Fraud Prevention API to screen order transaction for online fraud. It helps to minimize fraud losses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
