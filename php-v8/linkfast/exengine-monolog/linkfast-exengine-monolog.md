# linkfast/exengine-monolog

> 标签: exengine, exengine-extension, logger, logging, monolog, psr-3

## 简介

Monolog logger extension for the ExEngine microframework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
