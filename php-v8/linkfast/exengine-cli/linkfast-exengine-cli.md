# linkfast/exengine-cli

> 标签: cli, exengine, generator, microframework, scaffolding

## 简介

exen: command line tool for the ExEngine microframework (new projects, dev server, generators, extensions).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
