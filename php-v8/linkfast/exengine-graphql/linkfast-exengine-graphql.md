# linkfast/exengine-graphql

> 标签: bff, exengine, exengine-extension, graphql, persisted-queries, schema-first

## 简介

GraphQL for the ExEngine microframework: schema-first, precompiled schema, persisted queries.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
