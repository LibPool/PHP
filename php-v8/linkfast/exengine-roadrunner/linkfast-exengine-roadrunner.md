# linkfast/exengine-roadrunner

> 标签: application-server, exengine, exengine-extension, psr-7, roadrunner, worker

## 简介

RoadRunner application server support for the ExEngine microframework: long-running HTTP workers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
