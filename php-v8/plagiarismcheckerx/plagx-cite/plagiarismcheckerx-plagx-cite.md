# plagiarismcheckerx/plagx-cite

> 标签: Bibliography, academic-writing, apa, apa-citation, bibtex, citation, citation-generator, csl-json, doi, in-text-citation, laravel, mla, mla-citation, reference-list, works-cited

## 简介

Free APA and MLA citation generator and reference checker for PHP: reference lists, in-text citations, BibTeX import/export, DOI to citation and duplicate reference detection. By Plagiarism Checker X.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
