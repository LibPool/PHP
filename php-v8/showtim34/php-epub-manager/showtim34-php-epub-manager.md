# showtim34/php-epub-manager

> 标签: e-book, epub

## 简介

Package to create and stream e-books in the ePub 2.0 and 3.0 formats.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
