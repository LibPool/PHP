# ryckakas/cursor-walk

> 标签: Connection, Relay, cursor, cursor-pagination, graphql, iterator, pagination

## 简介

The fetching half of cursor pagination for PHP: walk paginated upstream APIs lazily, with cursor round-tripping and Relay connection output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
