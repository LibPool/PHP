# harry/auth-rbac-abac

> 标签: abac, access-control, acl, auth, authorization, permission, rbac, think-orm, thinkphp

## 简介

基于 ThinkPHP 8 的 Auth + RBAC + ABAC 权限控制组件（PHP 8.4+）。可插拔 ORM（think-orm 8 / PDO）与缓存（Redis / APCu / array），多守卫、门面、组合判定门。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
