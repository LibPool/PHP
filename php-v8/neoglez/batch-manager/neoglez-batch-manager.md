# neoglez/batch-manager

> 标签: zf2

## 简介

The BatchManager is an attempt to port the Drupal Batch API to the Zend Framework 2 event-driven, service-oriented arquitecture.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
