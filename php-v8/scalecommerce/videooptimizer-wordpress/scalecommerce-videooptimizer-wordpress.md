# scalecommerce/videooptimizer-wordpress

> 标签: PHP

## 简介

VideoOptimizer for WordPress & WooCommerce — adaptive video delivery from the VideoOptimizer CDN.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
