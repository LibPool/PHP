# skydiver/laravel-flysystem-b2

> 标签: Flysystem, b2, backblaze, filesystem, laravel

## 简介

Adds Backblaze B2 driver to use with Laravel filesystem

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
