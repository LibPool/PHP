# markguinn/silverstripe-related_products

> 标签: ecommerce, silverstripe

## 简介

Submodule for Silverstripe shop/ecommerce which allows you to specify related products for any Buyable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
