# markguinn/silverstripe-fb-like-button

> 标签: facebook, like button, silverstripe

## 简介

Super simple Silverstripe extension to add Facebook like buttons to pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
