# raise-studio/import

> 标签: PHP

## 简介

Raise Import — Import for Filament. The simplest and most complete CSV/Excel import plugin. Supports Filament 4 & 5.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
