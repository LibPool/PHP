# texhub/moy-sklad

> 标签: ERP, inventory, laravel, moy-sklad, moysklad, multi-tenant, php, texhub, warehouse, webhooks

## 简介

Full-featured MoySklad (МойСклад) JSON API 1.2 SDK for any PHP framework with first-class Laravel & multi-tenant support: products, stock, images, counterparties, orders, reports and webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
