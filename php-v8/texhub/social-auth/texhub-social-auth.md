# texhub/social-auth

> 标签: Authentication, SSO, github, google, laravel, oauth, oauth2, php, social-login, texhub

## 简介

Simple, elegant social OAuth 2.0 login for any PHP framework with first-class Laravel support — Google & GitHub out of the box, easily extensible.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
