# texhub/telegram

> 标签: bot-api, laravel, multi-tenant, php, telegram, telegram-bot, telegram-business, texhub, webhooks

## 简介

Full-featured, multi-tenant Telegram Bot API & Telegram Business SDK for any PHP framework with first-class Laravel support: messages, media, keyboards, webhooks, long polling and more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
