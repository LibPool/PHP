# texhub/alif-pay

> 标签: Tajikistan, acquiring, alif, alif-pay, laravel, marketplace, payment, payment-gateway, php, texhub, tokenization, webcheckout

## 简介

Alif Acquiring (WebCheckout) payment gateway SDK for any PHP framework with first-class Laravel support: payments, tokenization and token charges, marketplace split-payments, webhooks and the Alif provider protocol.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
