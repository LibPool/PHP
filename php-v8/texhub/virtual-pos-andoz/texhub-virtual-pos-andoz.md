# texhub/virtual-pos-andoz

> 标签: Tajikistan, andoz, cash-register, fiscal, laravel, ofd, php, receipt, tax, texhub, virtual-pos, vkassa

## 简介

Virtual POS / fiscal cash register (Andoz / ОФД) API SDK for any PHP framework with first-class Laravel support: device status, shifts, receipts & corrections, fiscal documents, X/FN/cash reports, cash in/out and universal counters.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
