# zithara/webhook

> 标签: PHP

## 简介

Zithara Magento 2 plugin for syncing Customers, Orders and Cart data from merchants magento ecommerce to Zithara.AI CRM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
