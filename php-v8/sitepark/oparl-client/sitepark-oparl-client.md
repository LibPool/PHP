# sitepark/oparl-client

> 标签: oparl, open data, psr-18, ratsinformationssystem

## 简介

Client for OParl 1.0 and 1.1, the standard interface of German council information systems

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
