# 8grams/bedrock

> 标签: bedrock, composer, roots, wordpress, wp, wp-config

## 简介

WordPress boilerplate with SQLite integration out of the box. Forked from roots/bedrock.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
