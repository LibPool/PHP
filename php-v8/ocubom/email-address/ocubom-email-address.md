# ocubom/email-address

> 标签: RFC 1123, RFC 3696, RFC 4291, RFC 5321, RFC 5322, RFC1123, RFC3696, RFC4291, RFC5321, RFC5322, address, email, validator

## 简介

Email address value object checked against RFC 3696, RFC 1123, RFC 4291, RFC 5321 and RFC 5322.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
