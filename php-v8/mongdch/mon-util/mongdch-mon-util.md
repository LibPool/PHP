# mongdch/mon-util

> 标签: mon, tool, util

## 简介

常用的PHP工具类库，包含了各种各式各样的工具，如：容器、时间、验证器、多语言、图片处理、二维码生成、IP地址解析、文件操作、数据安全、数据字典等等等等。。。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
