# gilsegura/shared

> 标签: PHP

## 简介

Framework-agnostic DDD, Event Sourcing and CQRS building blocks: domain value objects, aggregates, event store, command/query buses, criteria DSL and read models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
