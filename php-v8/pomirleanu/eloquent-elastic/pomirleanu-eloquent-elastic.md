# pomirleanu/eloquent-elastic

> 标签: PHP

## 简介

Provides Elasticsearch indexing and managing functionality for Laravel Eloquent Models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
