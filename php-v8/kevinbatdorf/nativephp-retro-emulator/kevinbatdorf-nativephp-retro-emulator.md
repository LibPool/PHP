# kevinbatdorf/nativephp-retro-emulator

> 标签: PHP

## 简介

Native retro emulation for NativePHP Mobile apps — NES, SNES, Game Boy, Game Boy Color, Game Boy Advance, and Genesis via swappable cores (ares, SameBoy, mGBA, or bring-your-own libretro)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
