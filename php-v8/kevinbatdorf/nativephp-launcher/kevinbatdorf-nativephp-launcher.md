# kevinbatdorf/nativephp-launcher

> 标签: android, home-screen, laravel, launcher, multi-display, nativephp, nativephp-plugin

## 简介

Make a NativePHP Mobile app the Android home screen: list installed apps, open one on a display, and answer the HOME intent

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
