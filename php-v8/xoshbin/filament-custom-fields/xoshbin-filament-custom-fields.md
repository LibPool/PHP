# xoshbin/filament-custom-fields

> 标签: Xoshbin, custom-fields, filament, laravel, plugin

## 简介

A Filament v4 plugin for adding custom fields to any model

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
