# kuijperit/gc-datatable

> 标签: Google Charts, charts, generate json, google, json datatable

## 简介

PHP Library for generating JSON datatable for Google Charts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
