# sanjid29/laravel-starter-core

> 标签: PHP

## 简介

Core infrastructure for Laravel starter kit — base controllers, traits, middleware, and CRUD scaffolding commands.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
