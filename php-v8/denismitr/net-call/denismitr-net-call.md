# denismitr/net-call

> 标签: Guzzle, client, http, request

## 简介

Easy to use and mockable HTTP client, wraps most common http calls functionality around Guzzle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
