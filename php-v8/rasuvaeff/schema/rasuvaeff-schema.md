# rasuvaeff/schema

> 标签: fuzzing, generators, json-schema, property-testing, schema, validation

## 简介

Schema-as-code combinators for PHP: one definition drives runtime validation, property-based generation and JSON Schema export

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
