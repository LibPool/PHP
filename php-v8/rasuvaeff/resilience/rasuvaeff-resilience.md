# rasuvaeff/resilience

> 标签: PHP

## 简介

Resilience pipeline for PHP: composes retry, circuit breaker, and bulkhead in the correct order with the exception glue built in

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
