# rasuvaeff/yii3-recaptcha

> 标签: captcha, recaptcha, validator, widget, yii, yii3

## 简介

Google reCAPTCHA v2/v3 widget and validator for Yii3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
