# rasuvaeff/bulkhead

> 标签: apcu, bulkhead, concurrency, fpm, redis, resilience

## 简介

Cross-process concurrency limiter (bulkhead) for PHP-FPM, backed by Redis or APCu

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
