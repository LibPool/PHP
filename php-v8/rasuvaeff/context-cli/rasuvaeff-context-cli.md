# rasuvaeff/context-cli

> 标签: Context, cancellation, cli, graceful-shutdown, pcntl, signals, worker

## 简介

Graceful shutdown for PHP CLI workers: OS signals cancel a rasuvaeff/context Context

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
