# rasuvaeff/yii3-metrics

> 标签: Metrics, counter, gauge, histogram, observability, yii3

## 简介

Vendor-neutral metrics facade (counters, gauges, histograms) for Yii3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
