# rasuvaeff/link-preview

> 标签: link-preview, metadata, opengraph, psr-18, ssrf, twitter-cards

## 简介

Link preview for PHP: SSRF-safe PSR-18 fetching and OpenGraph, Twitter Cards and HTML metadata extraction

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
