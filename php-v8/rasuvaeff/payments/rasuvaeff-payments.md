# rasuvaeff/payments

> 标签: contracts, payment-gateway, payments, webhooks

## 简介

Provider-neutral payment contracts, PSR-18 transport and webhook pipeline for PHP

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
