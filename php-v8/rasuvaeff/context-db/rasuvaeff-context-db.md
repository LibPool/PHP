# rasuvaeff/context-db

> 标签: Context, deadline, mariadb, mysql, pdo, postgresql, statement-timeout, timeout

## 简介

Database-side statement timeouts from a rasuvaeff/context budget for MySQL, MariaDB and PostgreSQL over PDO

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
