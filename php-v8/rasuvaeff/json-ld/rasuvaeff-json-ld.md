# rasuvaeff/json-ld

> 标签: JSON-LD, RDF, jsonld, linked-data, n-quads, processor, semantic-web

## 简介

JSON-LD 1.1 processor for PHP: expand, flatten, node API, RDF and N-Quads

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
