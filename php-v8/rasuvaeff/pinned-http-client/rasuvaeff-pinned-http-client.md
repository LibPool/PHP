# rasuvaeff/pinned-http-client

> 标签: Guzzle, dns-pinning, dns-rebinding, http-client, psr-18, security, ssrf

## 简介

PSR-18 client for untrusted URLs: resolves the host, checks every address and pins the connection to the checked addresses

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
