# hampel/sparkpost-laravel

> 标签: driver, email, laravel, mail, sparkpost

## 简介

Laravel mail driver for SparkPost, built on hampel/sparkpost-transport

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
