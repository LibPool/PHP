# hampel/sparkpost

> 标签: api, email, psr-18, sparkpost

## 简介

A PHP client for the SparkPost API - transmissions, message events and suppression - over any PSR-18 HTTP client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
