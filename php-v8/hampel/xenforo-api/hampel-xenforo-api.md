# hampel/xenforo-api

> 标签: api, forum, psr-18, rest, xenforo

## 简介

A PHP client for the XenForo REST API - core endpoints, add-on extensions and OAuth2 - over any PSR-18 HTTP client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
