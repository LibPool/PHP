# hampel/console-report

> 标签: cli, console, laravel, laravel-zero, symfony-console, xenforo

## 简介

Console output for CLI tools that report on themselves - settings dumps and validation checks, with paths printed whole

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
