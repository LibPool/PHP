# hampel/xenforo-phpstan

> 标签: PHPStan, phpstan-extension, static analysis, xenforo

## 简介

PHPStan for XenForo add-ons - the configuration an add-on needs to be analysed against a forum, the methods class extensions add to core classes, the container shortcuts, and the legacy class names XenForo 2.3 aliases at runtime

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
