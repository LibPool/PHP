# hampel/sparkpost-transport

> 标签: email, mailer, sparkpost, symfony, transport

## 简介

A Symfony Mailer transport for SparkPost, built on hampel/sparkpost

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
