# hampel/linode-api-laravel

> 标签: akamai, api, dns, domains, laravel, linode

## 简介

Laravel service provider, manager and facade for the Linode (Akamai Cloud) API client, with Http::fake() support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
