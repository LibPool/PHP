# hampel/linode-api

> 标签: akamai, api, dns, domains, linode, psr-18

## 简介

A PHP client for the Linode (Akamai Cloud) API - domains, DNS records and account verification - over any PSR-18 HTTP client

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
