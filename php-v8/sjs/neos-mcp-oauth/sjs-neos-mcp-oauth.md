# sjs/neos-mcp-oauth

> 标签: PHP

## 简介

OAuth2 authentication for Neos MCP server - enables self-service OAuth client creation and authorization

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
