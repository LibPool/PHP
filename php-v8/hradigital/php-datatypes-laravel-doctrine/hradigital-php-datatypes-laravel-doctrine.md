# hradigital/php-datatypes-laravel-doctrine

> 标签: Domain Driven Design, custom types, datatypes, dbal, ddd, doctrine, hradigital, laravel, value objects

## 简介

Doctrine DBAL Types for the hradigital/php-datatypes objects, auto-wired into Laravel.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
