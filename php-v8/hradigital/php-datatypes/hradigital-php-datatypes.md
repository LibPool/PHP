> 标签: Domain Driven Design, Scalar Objects, aggregates, datatypes, ddd, domain, entities, entity, immutable objects, mutable objects, php, value objects

## 简介

Easy way to build up and sanitize your application objects.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
