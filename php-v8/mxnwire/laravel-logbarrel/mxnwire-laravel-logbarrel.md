# mxnwire/laravel-logbarrel

> 标签: PHP

## 简介

Log every incoming HTTP request (and optionally its response) to a dedicated channel, with redaction and fine-grained options

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
