# dotlines-io/ghoori

> 标签: dotlines-io, ghoori

## 简介

This is the core package for Ghoori Payment integration. Both for OnDemand and Subscription Payment Integration

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
