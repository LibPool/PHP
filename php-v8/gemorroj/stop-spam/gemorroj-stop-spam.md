# gemorroj/stop-spam

> 标签: antispam, blacklist, spam-detection, spam-filtering, spam-protection, stopforumspam

## 简介

Wrapper for API www.stopforumspam.com (api.stopforumspam.org)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
