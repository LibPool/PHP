# ascariodev/sereno-php

> 标签: errors, logging, monolog, sereno

## 简介

Sereno SDK for PHP: sends logs and errors to Sereno from plain PHP, Symfony and any Monolog setup.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
