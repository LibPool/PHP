# welfordmedia/barclaycard-epdq-gateway

> 标签: Craft, barclaycard epdq ecommerce gateway, cms, craft-plugin, craftcms

## 简介

A Barclaycard ePDQ eCommerce payment gateway for use with Craft CMS and Craft Commerce 4.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
