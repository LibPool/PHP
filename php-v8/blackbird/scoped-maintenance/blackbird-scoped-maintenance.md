# blackbird/scoped-maintenance

> 标签: PHP

## 简介

This module allows you to enable maintenance mode for specific stores in a Magento instance while leaving others accessible.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
