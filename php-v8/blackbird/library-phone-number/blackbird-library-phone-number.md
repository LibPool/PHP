# blackbird/library-phone-number

> 标签: lib, library, magento, magento2, phone, phone number, php

## 简介

Phone number library utilities for Magento 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
