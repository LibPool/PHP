# blackbird/module-link-header

> 标签: core web vitals, lcp, link header, magento2, magento2-module, performance, preload

## 简介

Send preload, preconnect... links declared by templates as an HTTP Link response header, kept through the full page cache and the block HTML cache

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
