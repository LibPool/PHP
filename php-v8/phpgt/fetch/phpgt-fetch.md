# phpgt/fetch

> 标签: ajax, async, asynchronous, curl, curl_multi, fetch, get, http, http-client, post, xmlhttprequest

## 简介

Asynchronous HTTP client with promises.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
