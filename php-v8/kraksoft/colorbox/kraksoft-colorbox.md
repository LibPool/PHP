# kraksoft/colorbox

> 标签: jquery, lightbox, modal, popup, ui, window

## 简介

A light-weight, customizable lightbox plugin for jQuery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
