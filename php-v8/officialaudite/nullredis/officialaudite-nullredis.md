# officialaudite/nullredis

> 标签: cache, file cache, rate limit, redis, shim

## 简介

A tiny file-backed Redis-like shim for PHP (KV, sets, sorted sets)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
