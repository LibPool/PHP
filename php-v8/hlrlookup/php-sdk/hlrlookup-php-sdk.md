# hlrlookup/php-sdk

> 标签: Telecoms, hlr, hlr-lookup, mnp, number-portability, number-validation, phone-number, sms

## 简介

PHP SDK for the HLR Lookup API - HLR, MNP, and Number Validation lookups

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
