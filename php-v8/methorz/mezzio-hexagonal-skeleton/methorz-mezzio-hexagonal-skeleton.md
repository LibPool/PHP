# methorz/mezzio-hexagonal-skeleton

> 标签: Skeleton, clean-architecture, ddd, domain-driven-design, hexagonal-architecture, mezzio, php8, rest-api

## 简介

Mezzio skeleton with architecture choice: minimal or hexagonal (DDD). Includes optional packages for modern PHP 8.5.12+ REST API development.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
