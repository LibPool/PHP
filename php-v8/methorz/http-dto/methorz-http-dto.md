# methorz/http-dto

> 标签: dto, http, middleware, psr-15, serialization, validation

## 简介

Automatic HTTP ↔ DTO conversion via PSR-15 middleware

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
