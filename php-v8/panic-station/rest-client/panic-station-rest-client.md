# panic-station/rest-client

> 标签: PHP

## 简介

A simple REST client based on PECL HTTP extension v2. PSR-0 and PSR-3 compliant.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
