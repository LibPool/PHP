# webdna/commerce-order-notes

> 标签: Craft, cms, commerce order notes, craft-plugin, craftcms

## 简介

Add notes to an order, they can also affect price.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
