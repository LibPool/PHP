# diffhead/php-dto

> 标签: Data Transfer Object, data interaction, dto, library, package, php, php8

## 简介

Simple library that provides suitable data transfer object for PHP applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
