# fronty/sylius-netaxept

> 标签: gateway, netaxept, payment, sylius, sylius-plugin

## 简介

Integration of Netaxept API to Sylius as a new payment method.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
