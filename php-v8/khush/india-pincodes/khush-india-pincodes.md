# khush/india-pincodes

> 标签: Pincode, address, india, india post, pin code, postal code

## 简介

Offline India PIN code lookup: every post office for a PIN with its type, delivery status, district and state, plus the list of Indian states and union territories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
