# elyar/laravel-service-tokens

> 标签: Authentication, api, laravel, microservices, service-to-service, tokens

## 简介

Token authentication for service-to-service calls between Laravel apps, with per-route permissions and an interactive manager.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
