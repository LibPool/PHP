# sitask/xml-feed-parser

> 标签: feed, news, parser, sita, slovakia, xml

## 简介

Framework-agnostic PHP parser for SITA (Slovenska tlacova agentura) XML news feeds.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
