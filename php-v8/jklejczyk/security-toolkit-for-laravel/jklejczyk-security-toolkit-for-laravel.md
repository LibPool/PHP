# jklejczyk/security-toolkit-for-laravel

> 标签: Audit, appsec, cvss, cwe, laravel, scanner, security, vulnerability

## 简介

Security audit for Laravel 12 and 13 in one Artisan command: configuration, file storage, authentication and dependency checks with clear recommendations, CWE and CVSS.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
