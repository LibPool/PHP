# lottevo/lottevo-php

> 标签: api, lottery, lottevo, results, sdk

## 简介

A thin PHP client for the Lottevo lottery data API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://lottevo.com/docs/sdks
- 源码仓库：https://github.com/astefalabs/lottevo-php.git
- Packagist 页面：https://packagist.org/packages/lottevo%2Flottevo-php
