# dannyvanholten/wp-growl-notifications

> 标签: PHP

## 简介

Show your WordPress admin notices in a growlike / better way, and snooze them whenever you see fit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
