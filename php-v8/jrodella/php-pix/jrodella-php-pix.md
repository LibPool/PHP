# jrodella/php-pix

> 标签: bcb, emv, payment, piggly, pix, qrcode

## 简介

Uma biblioteca para preparar e gerar o código Pix do Banco Central do Brasil. (Isso é uma fork de: piggly/php-pix)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
