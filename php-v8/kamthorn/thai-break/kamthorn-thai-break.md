# kamthorn/thai-break

> 标签: TCPDF, dompdf, laravel, line-breaker, mpdf, tcc, thai, thai-break, tokenizer, word-segmentation

## 简介

Fast, high-accuracy Thai word segmentation & typographic line breaker for PHP and Laravel (dompdf, mPDF, Web)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
