# ruudk/payment-adyen-bundle

> 标签: adyen, payment

## 简介

A Symfony2 Bundle that provides access to the Adyen API. Based on JMSPaymentCoreBundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
