# daniel-pfeil/samlauthentication

> 标签: Authentication, SSO, saml, serviceprovider, typo3

## 简介

This extension adds a authentication method for SAML with different service provider.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
