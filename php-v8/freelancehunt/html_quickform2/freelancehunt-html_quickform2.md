# freelancehunt/html_quickform2

> 标签: Forms, PEAR, javascript, quickform, validation, wizard

## 简介

Provides methods to create, validate and render HTML forms in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
