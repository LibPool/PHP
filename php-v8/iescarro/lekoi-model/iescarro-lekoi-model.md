# iescarro/lekoi-model

> 标签: database, framework, lekoi, mysqli, orm, php, sqlite

## 简介

A lightweight ORM and database abstraction layer for the Lekoi PHP framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
