# spiral-packages/cqrs

> 标签: command-bus, cqrs, query-bus, spiral, spiral-packages

## 简介

Lightweight message bus supporting CQRS for Spiral Framework

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
