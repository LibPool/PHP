# voku/agent-edit

> 标签: Agent, agent-map, ai, coding-agent, llm, php, refactoring, source-mutation

## 简介

Deterministic, evidence-backed source mutation for coding agents: validate, apply transactionally and verify agent-map plans.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
