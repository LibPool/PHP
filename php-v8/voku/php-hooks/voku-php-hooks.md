# voku/php-hooks

> 标签: actions, filters, filters-system, hook-system, hooks

## 简介

A fork of the WordPress filters hook system rolled in to a class to be ported into any PHP-based system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
