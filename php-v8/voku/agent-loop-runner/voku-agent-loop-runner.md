# voku/agent-loop-runner

> 标签: Agent, agent-loop, ai, coding-agent, execution-plane, git-worktrees, llm, process-manager, runner, supervision, workspaces

## 简介

Optional execution plane for voku/agent-loop: host adapters, isolated workspaces, process supervision, and restart-safe governed execution.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
