# voku/agent-kanban

> 标签: Agent, ai, coding-agent, git-native, kanban, llm, markdown, task-management, todo

## 简介

Markdown TODO Kanban parser, renderer, and verifier for coding-agent workflows.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
