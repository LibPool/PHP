# voku/agent-graph

> 标签: Agent, coding-agent, graph, sqlite, sqlite-vec

## 简介

Deterministic SQLite graph indexing and shared SQLite runtime support for coding-agent tooling.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
