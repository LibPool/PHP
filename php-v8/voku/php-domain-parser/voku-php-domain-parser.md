# voku/php-domain-parser

> 标签: Public Suffix List, domain parsing, url parsing

## 简介

Fork: Public Suffix List based URL parsing implemented in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
