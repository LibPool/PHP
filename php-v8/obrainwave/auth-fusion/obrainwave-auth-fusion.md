# obrainwave/auth-fusion

> 标签: Authentication, api-auth, jwt, laravel, passport, sanctum

## 简介

Unified authentication package for Laravel supporting Sanctum, JWT, and Passport

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
