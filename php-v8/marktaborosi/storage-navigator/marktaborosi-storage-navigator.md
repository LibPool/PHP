# marktaborosi/storage-navigator

> 标签: Flysystem, archive, file browser, filesystem, ftp, navigator, renderer, sftp, storage, twig, zip

## 简介

A simple lightweight universal storage/file browser and navigator library with rendering options.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
