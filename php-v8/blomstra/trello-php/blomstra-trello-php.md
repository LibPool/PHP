# blomstra/trello-php

> 标签: api, fork, trello, trello api wrapper

## 简介

PHP Trello API Wrapper (+missing models) from https://github.com/sanovskiy/Trello-API-PHP-Wrapper

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
