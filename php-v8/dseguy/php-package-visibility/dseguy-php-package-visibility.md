# dseguy/php-package-visibility

> 标签: encapsulation, namespace, package-private, php, static-analysis, visibility

## 简介

Namespace-scoped visibility (private/protected/public) for PHP classes, interfaces, traits, and enums.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
