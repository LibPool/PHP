# dseguy/php-gremlin

> 标签: GraphML, graph, graph-database, graphbinary, graphson, gremlin, tinkerpop

## 简介

PHP client for Apache TinkerPop Gremlin Server 4.0 over its HTTP protocol

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
