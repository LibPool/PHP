# firebrandhq/silverstripe-hail

> 标签: Hail, content, news, silverstripe

## 简介

Silverstripe 5 plugin to integrate with Hail (https://get.hail.to)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
