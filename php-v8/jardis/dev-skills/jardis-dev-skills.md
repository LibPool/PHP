> 标签: Headgent, agents.md, ai-assisted, ai-assisted-development, claude-code, codex, composer-plugin, cursor, ddd, domain-driven-design, gemini-cli, github-copilot, jardis, skills

## 简介

Composer plugin that installs Jardis Skills and aggregates AGENTS.md for AI-assisted development (Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
