# kwasii/livewire-mapcn

> 标签: geojson, kwasii, laravel, livewire, livewire-mapcn, mapcn, maplibre, maps

## 简介

Beautiful MapLibre maps for Laravel Livewire, inspired by mapcn: markers, popups, routes with progress, arcs, GeoJSON, clusters and 3D.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
