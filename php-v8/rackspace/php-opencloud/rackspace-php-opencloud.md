# rackspace/php-opencloud

> 标签: Openstack, nova, opencloud, rackspace, swift

## 简介

PHP SDK for Rackspace/OpenStack APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
