# useclassy/laravel

> 标签: blade, css, laravel, tailwind, useclassy

## 简介

Laravel integration for UseClassy - Transform class:modifier syntax in Blade templates

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
