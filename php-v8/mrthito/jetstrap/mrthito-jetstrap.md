# mrthito/jetstrap

> 标签: bootstrap, jetstream, laravel

## 简介

A Laravel 8 package to easily switch TailwindCSS resources generated by Laravel Jetstream to Bootstrap 4 or 5.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
