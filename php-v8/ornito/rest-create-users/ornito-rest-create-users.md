# ornito/rest-create-users

> 标签: Authentication, JSON Web Token, authorization, json, jwt, rest, restful

## 简介

Create users in Bolt CMS through API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
