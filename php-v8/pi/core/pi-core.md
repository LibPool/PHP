# pi/core

> 标签: Pi Engine, laminas, multitenant, pi, saas

## 简介

Pi is a multi-tenant application development engine for cloud ready SaaS platform with support for SSO/OAuth.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
