# kittinan/crypt-time-php

> 标签: PHP

## 简介

CryptTime-PHP is a simple class to encrypt string with timeout. the encryption use AES128/PKCS7.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
