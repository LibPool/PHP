# oyswonder/html2pdf

> 标签: PHP

## 简介

A Simple package for easily generating PDF documents from HTML.This package is specially for laravel but you can use this without laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
