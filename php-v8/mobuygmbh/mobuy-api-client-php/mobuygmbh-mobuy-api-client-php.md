# mobuygmbh/mobuy-api-client-php

> 标签: api, php, sdk, swagger

## 简介

PHP API Client for mobuy Payment (Swagger generated)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
