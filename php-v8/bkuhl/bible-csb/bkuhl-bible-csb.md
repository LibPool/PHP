# bkuhl/bible-csb

> 标签: PHP

## 简介

A PHP library for interacting with the Christian Standard Bible (CSB). Users must obtain permission for CSB text usage from Holman Bible Publishers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
