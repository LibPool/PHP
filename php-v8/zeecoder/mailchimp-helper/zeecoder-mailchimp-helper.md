# zeecoder/mailchimp-helper

> 标签: PHP

## 简介

A set of useful methods for interacting with MailChimp, using the drewm/mailchimp-api library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
