# baconfy/indicators

> 标签: bigdecimal, decimal, indicators, technical-analysis, trading

## 简介

Technical analysis indicators over exact decimal math. Framework-free, deterministic, no I/O.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
