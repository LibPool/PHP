# dev-garden/composer-check-user-api

> 标签: PHP

## 简介

ComposerCheckUserApi is a service to create call requests to ComposerCheckApi, which checks for outdated packages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
