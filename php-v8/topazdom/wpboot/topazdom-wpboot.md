# topazdom/wpboot

> 标签: WordPress Plugin Boilerplate, WordPress Plugin Developemt, WordPress Theme Boilerplate, WordPress Theme Developemt, cli, command-line, developer, development, plugin, template, theme, wordpress, wp

## 简介

A Free and OpenSource Lightweight CLI tool to quickly bootstrap WordPress Theme and Plugin Development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
