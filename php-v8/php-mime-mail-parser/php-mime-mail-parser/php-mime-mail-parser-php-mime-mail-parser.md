# php-mime-mail-parser/php-mime-mail-parser

> 标签: MimeMailParser, mail, mailparse, mime, parser, php

## 简介

A fully tested email parser for PHP 8.2+ (mailparse extension wrapper).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
