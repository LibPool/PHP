# polytypo/polytypo

> 标签: i18n, l10n, normalize-typography, quotes, typography, unicode

## 简介

Normalize typography across languages: quotes, dashes, ellipses, apostrophes, symbols and no-break spaces.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
