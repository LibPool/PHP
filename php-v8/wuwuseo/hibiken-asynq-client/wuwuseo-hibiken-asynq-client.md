# wuwuseo/hibiken-asynq-client

> 标签: PHP

## 简介

优化版 PHP 客户端，用于与 go hibiken/asynq 任务队列系统交互，提供流畅的 API、中间件支持和性能优化

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
