# cwssrl/azure-storage-php

> 标签: azure, php, sdk, storage

## 简介

This project provides a set of PHP client libraries that make it easy to access Microsoft Azure storage APIs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
