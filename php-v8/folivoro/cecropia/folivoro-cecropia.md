# folivoro/cecropia

> 标签: PHP

## 简介

Cecropia is a mu-plugin used to bootstrap the Sloth framework in standalone folivoro projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
