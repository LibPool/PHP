# redbutton/js-localization

> 标签: javascript, laravel, localization, messages, translation

## 简介

Laravel package to provide localizations to the Javascript code. Cloned from andywer/js-localization, updated for Laravel 7

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
