# php-notify/notify-symfony-notyf

> 标签: flash-notifications, minimalist-notifications, notyf, open-source, phpflasher, symfony, user-feedback

## 简介

Adopt Notyf's simple flash notifications in Symfony projects with PHPFlasher. Streamline user notifications in Symfony with Notyf's elegant simplicity.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
