# php-notify/notify-symfony-sweet-alert

> 标签: alerts, bundle, flex, laravel, lumen, messages, notifications, notify, php, pnotify, sweetalert, symfony, toastr, yoeunes

## 简介

PHP Flasher Symfony adapter for Sweet Alert 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
