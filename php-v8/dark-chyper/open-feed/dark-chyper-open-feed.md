# dark-chyper/open-feed

> 标签: Syndication, atom, feed, rss, xml

## 简介

A lightweight, framework-agnostic PHP library to generate RSS feeds with XMLWriter

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
