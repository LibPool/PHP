# pentagonal/database-dbal

> 标签: database, dbal, doctrine, helper, lazy, persistence

## 简介

Just to extend `Doctrine DBAL` in an easier way for `lazy people`

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
