# uams-web/statamic-multisite-forms

> 标签: Forms, multisite, statamic, statamic-addon

## 简介

Per-site forms for multisite Statamic: site assignment, per-site overrides, and site-separated submissions in flat files.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
