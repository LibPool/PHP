# uams-web/statamic-alpine-csp-forms

> 标签: statamic, statamic-addon

## 简介

CSP-safe Alpine form JavaScript driver for Statamic public forms, with its browser-side field-conditions evaluator.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
