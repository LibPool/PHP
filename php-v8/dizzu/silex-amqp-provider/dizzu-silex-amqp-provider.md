# dizzu/silex-amqp-provider

> 标签: AMQP, queue, rabbitmq, silex

## 简介

AMQP service provider for the Silex framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
