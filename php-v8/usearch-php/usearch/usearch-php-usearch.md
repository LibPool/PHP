# usearch-php/usearch

> 标签: ann, embeddings, hnsw, rag, search, similarity, usearch, vector

## 简介

In-process vector similarity search for PHP, backed by a statically linked build of USearch

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
