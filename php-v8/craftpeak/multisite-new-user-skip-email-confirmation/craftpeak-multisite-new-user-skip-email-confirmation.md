# craftpeak/multisite-new-user-skip-email-confirmation

> 标签: wordpress

## 简介

Mimic the super-admin 'Skip Confirmation Email' checkbox for users that can create other users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
