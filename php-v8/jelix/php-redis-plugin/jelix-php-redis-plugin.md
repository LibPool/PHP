# jelix/php-redis-plugin

> 标签: jcache, jelix, jkvdb, redis

## 简介

Redis plugins for Jelix, using a pure PHP Redis API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
