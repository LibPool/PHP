# jelix/composer-module-setup

> 标签: composer, composer-plugin, jelix

## 简介

Plugin for Composer to declare Jelix modules automatically into a Jelix application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
