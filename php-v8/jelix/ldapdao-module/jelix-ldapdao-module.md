# jelix/ldapdao-module

> 标签: dao, jelix, ldap

## 简介

module for Jelix,allowing to authenticate with an ldap server and to register users locally.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
