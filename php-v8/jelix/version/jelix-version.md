# jelix/version

> 标签: comparator, composer, semver, version

## 简介

Parse any version syntax, including semantic version. Compare version, using Composer version constraints syntax.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
