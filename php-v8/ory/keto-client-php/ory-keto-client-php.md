# ory/keto-client-php

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

Documentation for all of Ory Keto's REST APIs. gRPC is documented separately.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
