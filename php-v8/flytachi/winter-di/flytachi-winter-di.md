# flytachi/winter-di

> 标签: Autowiring, PSR-11, container, dependency-injection, di, winter

## 简介

Lightweight PSR-11 DI container for Winter framework (autowiring, scopes, attributes)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
