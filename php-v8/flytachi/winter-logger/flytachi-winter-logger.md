# flytachi/winter-logger

> 标签: fpm, logger, monolog, psr-3, swoole, winter

## 简介

Multi-runtime PSR-3 logger for Winter framework (FPM, Swoole, CLI)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
