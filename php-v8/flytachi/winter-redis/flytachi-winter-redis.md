# flytachi/winter-redis

> 标签: cache, coroutine, php, pool, redis, swoole, winter

## 简介

Pooled Redis for long-running PHP — coroutine-safe connections, typed stores and an optional PSR-16 adapter.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
