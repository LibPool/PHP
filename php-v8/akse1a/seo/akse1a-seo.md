# akse1a/seo

> 标签: Sitemap, html, meta, open-graph, schema, seo, xml

## 简介

A PHP library for working with SEO meta tags, Open Graph, Schema.org markup, and sitemap.xml generation

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
