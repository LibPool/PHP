# berlioz/html-selector

> 标签: PHP

## 简介

Berlioz HTML Selector is a PHP library to do queries on HTML files (converted in SimpleXMLElement object) like jQuery on DOM.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
