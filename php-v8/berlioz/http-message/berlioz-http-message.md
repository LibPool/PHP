# berlioz/http-message

> 标签: PHP

## 简介

Berlioz HTTP Message is a PHP library whose implements PSR-7 (HTTP message interfaces) and PSR-17 (HTTP Factories) standards.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
