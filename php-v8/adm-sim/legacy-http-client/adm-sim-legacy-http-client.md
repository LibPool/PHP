# adm-sim/legacy-http-client

> 标签: PHP

## 简介

Legacy HTTP Client for very old PHP (e.g.: PHP5). Minimum PHP version is 5.3 (needed for namespace)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
