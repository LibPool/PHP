# robertboes/blade-selfhst-icons

> 标签: blade, icons, laravel, selfh.st

## 简介

A package to easily make use of selfh.st Icons in your Laravel Blade views.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
