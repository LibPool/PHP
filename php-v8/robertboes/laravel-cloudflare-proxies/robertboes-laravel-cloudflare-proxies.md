# robertboes/laravel-cloudflare-proxies

> 标签: cloudflare, laravel, trusted-proxies, x-forwarded-for

## 简介

Trust Cloudflare's published ranges and the private proxy hop, so the client IP and scheme are right behind Cloudflare.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
