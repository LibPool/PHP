# internetdata/internetdata

> 标签: asn, bogon, internetdata, ip-database, ip-geolocation, ip-intelligence, maxmind-db, mmdb, rdns, threat-intelligence, whois

## 简介

Official PHP client library for the InternetData API. Download and verify licensed IP and ASN databases.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
