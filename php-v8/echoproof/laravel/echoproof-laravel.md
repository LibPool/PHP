# echoproof/laravel

> 标签: ai-agents, echoproof, laravel, regression, replay, testing

## 简介

Record real Laravel traffic as Echoproof snapshots, without a proxy

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
