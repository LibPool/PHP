# yomastrategic/yomafleet-payment

> 标签: gateway, laravel, payment, providers

## 简介

Yoma Fleet Payment Gateway Package for Visa, Master, JCB, Wave , Kpay,etc...

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
