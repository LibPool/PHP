# timefrontiers/php-sms

> 标签: Africastalking, phone, sms, timefrontiers, twilio

## 简介

Multi-driver SMS messaging for PHP 8.5+. Handles outbound sends, delivery webhooks, message logging, and driver‑based routing with automatic continent selection.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
