# timefrontiers/php-sql-database

> 标签: database, mysql, mysqli, pdo, php, sql

## 简介

PHP SQL Database manager supporting MySQLi and PDO with backward compatibility

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
