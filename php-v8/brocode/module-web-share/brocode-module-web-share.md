# brocode/module-web-share

> 标签: brocode, magento, magento2, product-page, share-buttons, social-share, web-share, web-share-api

## 简介

A "Share" button for Magento 2 product pages, category pages and CMS pages: the device's native share sheet via the Web Share API, with admin-configurable share links as a script-free fallback.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
