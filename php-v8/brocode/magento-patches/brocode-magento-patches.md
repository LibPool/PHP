# brocode/magento-patches

> 标签: adobe-commerce, composer-plugin, magento, magento2, patches, security

## 简介

Composer commands to add Magento 2 security, quality and custom patches safely: per-package split, edition/version aware, idempotent, validated before anything is written. Applies via cweagans/composer-patches 2.x.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
