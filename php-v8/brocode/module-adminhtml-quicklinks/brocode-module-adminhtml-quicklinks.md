# brocode/module-adminhtml-quicklinks

> 标签: Favorites, admin, adminhtml, bookmarks, brocode, magento, magento2, quick-links, usability

## 简介

Personal quick links for Magento 2 admin users: favorite any backend page with one click, keep the links one click away in the admin header, and manage them - reorder, rename, pin, add external links - under System > Tools.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
