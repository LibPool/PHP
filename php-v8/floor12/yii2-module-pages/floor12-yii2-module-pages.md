# floor12/yii2-module-pages

> 标签: floor12, yii, yii 2, yii2, yii2 module

## 简介

Yii2 module to organize pages with sitemap, breadcrumbs and many more.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
