# snowmannunu/weather

> 标签: amap, gaode, laravel, php, qweather, sdk, weather

## 简介

A weather SDK with multi-provider support (AMap, QWeather, etc.).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
