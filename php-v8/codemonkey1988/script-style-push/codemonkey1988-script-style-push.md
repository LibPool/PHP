# codemonkey1988/script-style-push

> 标签: TYPO3 CMS, http2, push, script_style_push

## 简介

TYPO3 Extension to push javascript and css files over a http/2 connection.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
