# moirei/eloquent-metrics

> 标签: Chart.js, Metrics, analytics, chartisan, charts, eloquent, laravel, moirei

## 简介

Retrieve metric data on Eloquent Models for analytics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
