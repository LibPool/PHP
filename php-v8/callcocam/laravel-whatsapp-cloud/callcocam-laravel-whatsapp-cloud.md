# callcocam/laravel-whatsapp-cloud

> 标签: laravel, messaging, meta, whatsapp, whatsapp-cloud-api

## 简介

Núcleo reutilizável da WhatsApp Cloud API (Meta) para Laravel: envio de templates/sessão/interativo por-tenant, webhook com assinatura e eventos, e gestão de templates via Artisan.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
