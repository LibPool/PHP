# valorin/version

> 标签: db, version, zf2

## 简介

A simple database versioning system for ZF2 applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/valorin/valversion
- 源码仓库：https://github.com/valorin/valversion.git
