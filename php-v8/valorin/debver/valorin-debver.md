# valorin/debver

> 标签: deb-version, debian, ubuntu, version

## 简介

Simple PHP helper class for comparing Debian/Ubuntu package version strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
