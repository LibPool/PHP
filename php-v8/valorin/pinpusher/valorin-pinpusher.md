# valorin/pinpusher

> 标签: PHP

## 简介

Simple Pebble Timeline Pin API wrapper, with full support for all of the Pebble Timeline API options.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
