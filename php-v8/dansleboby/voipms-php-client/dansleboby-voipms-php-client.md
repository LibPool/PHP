# dansleboby/voipms-php-client

> 标签: Guzzle, api, client, voip, voip.ms

## 简介

A robust PHP client for the VoIP.ms API, built on Guzzle with PSR-3 logging

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
