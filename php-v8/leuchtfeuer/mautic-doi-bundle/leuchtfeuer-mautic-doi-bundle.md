# leuchtfeuer/mautic-doi-bundle

> 标签: Double, Mautic, doi, integration, opt-in, optin, plugin

## 简介

Universal email verification for Mautic, including Double Opt-In (DOI)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
