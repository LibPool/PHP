# leuchtfeuer/companylistwidget

> 标签: Mautic, integration, plugin

## 简介

Add Widget that lists Companies (filtered by segment and/or tag) in the Dashboard

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
