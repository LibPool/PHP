# leuchtfeuer/typo3-mautic-form

> 标签: TYPO3 CMS

## 简介

TYPO3 plugin to seamlessly integrate forms generated in Mautic Open Source Marketing Automation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
