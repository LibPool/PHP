# leuchtfeuer/mautic-floodlight-b2b-bundle

> 标签: Mautic, integration, plugin

## 简介

Floodlight for B2B plugin: Detect and qualify companies from anonymous leads in Mautic, using the Floodlight for B2B service

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
