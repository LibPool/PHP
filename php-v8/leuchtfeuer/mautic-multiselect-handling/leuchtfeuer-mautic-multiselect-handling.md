# leuchtfeuer/mautic-multiselect-handling

> 标签: Mautic, integration, multiselect, plugin

## 简介

Provides custom campaign and form actions to manage multiselect fields.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
