# php-pg/pgproto3

> 标签: amphp, decode, encode, postgres, postgresql, protocol, wire

## 简介

Is an encoder and decoder of the PostgreSQL wire protocol version 3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
