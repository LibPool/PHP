# kitfiscal/client

> 标签: PHP

## 简介

Client PHP pentru kitfiscal API — estimator fiscal PFA / SRL Micro / SRL Profit, Romania 2026 (WooCommerce, PrestaShop, Magento, Laravel).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
