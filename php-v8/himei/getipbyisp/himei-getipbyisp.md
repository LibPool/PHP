# himei/getipbyisp

> 标签: cli, console, curl, ip ranges

## 简介

Simple cURL based console application for getting IP ranges from suip.biz web-services by city, country or ISP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
