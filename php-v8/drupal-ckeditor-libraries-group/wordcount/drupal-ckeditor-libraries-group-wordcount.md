# drupal-ckeditor-libraries-group/wordcount

> 标签: CKEditor, plugin, wordcount

## 简介

CKEditor 4 wordcount plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
