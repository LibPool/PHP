# leophp/search_dni

> 标签: cakephp3, consulta, curl, peru, reniec

## 简介

Clase para realizar consultas a Reniec Peru mediante el número de DNI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
