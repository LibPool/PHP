# vladpimk/laravel-translation-pim

> 标签: PHP

## 简介

Fork of joedixon/laravel-translation. Added support for illuminate/support versions through 13.x to enable compatibility with Laravel 13 and PHP 8.4. The version has not been fully tested

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
