# pharaonic/php-diff

> 标签: array diff, change detection, compare, diff, myers, pharaonic, php, structured diff, text diff, unified diff

## 简介

Semantic structured diffs and GitHub-style text diffs for PHP: added, removed, modified and moved values with paths, identity-aware lists, redaction, hunks, unified patches and HTML.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
