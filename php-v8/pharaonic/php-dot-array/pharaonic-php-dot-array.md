# pharaonic/php-dot-array

> 标签: array, asterisk, dot notation, pharaonic, php, php array, php dot array

## 简介

Access array data quickly/easily using dot-notation and asterisk.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
