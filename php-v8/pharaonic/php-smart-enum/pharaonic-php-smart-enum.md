# pharaonic/php-smart-enum

> 标签: backed enum, enum, enums, native enum, pharaonic, php, php enum, trait

## 简介

Smart, lightweight helpers for native PHP enums.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
