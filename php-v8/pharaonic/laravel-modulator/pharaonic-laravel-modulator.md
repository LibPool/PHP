# pharaonic/laravel-modulator

> 标签: laravel, laravel Modules, laravel hmvc, laravel modulator, php

## 简介

Laravel Modulator (HMVC) Creator in an easy and simple way.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
