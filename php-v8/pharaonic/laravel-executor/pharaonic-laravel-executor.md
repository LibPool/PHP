# pharaonic/laravel-executor

> 标签: laravel execute action on production server, laravel execute automated task on production server, laravel execute command on production server, laravel execute job on production server, laravel executor

## 简介

Laravel Executor is a package that allows you to execute commands, actions, jobs, and automated tasks on your production server.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
