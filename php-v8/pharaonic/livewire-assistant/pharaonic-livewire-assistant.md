# pharaonic/livewire-assistant

> 标签: javascript, laravel, livewire, livewire-assistant, select2

## 简介

Shared Blade and JavaScript foundation that binds JavaScript widgets to Livewire components.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
