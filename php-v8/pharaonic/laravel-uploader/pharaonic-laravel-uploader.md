# pharaonic/laravel-uploader

> 标签: larave files, laravel, laravel uploader, laravel uploads, php, secure, uploader

## 简介

Laravel Uploader to upload files and handling visibility.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
