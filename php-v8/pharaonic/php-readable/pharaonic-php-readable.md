# pharaonic/php-readable

> 标签: Number Format, bytes, currency, duration, file size, human readable, money, pharaonic, php, readable

## 简介

Framework-agnostic, human-friendly formatting for PHP: numbers, bytes, money, durations, plus small array and string inspection helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
