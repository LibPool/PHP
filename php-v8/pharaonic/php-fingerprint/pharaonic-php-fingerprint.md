# pharaonic/php-fingerprint

> 标签: Fingerprint, canonical, change detection, checksum, deduplication, hash, hmac, idempotency, pharaonic, php, signature

## 简介

Deterministic fingerprints and ordered signatures for PHP data: canonical map ordering, configurable list semantics, path-aware normalization, hashing, HMAC and protocol-safe field signing.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
