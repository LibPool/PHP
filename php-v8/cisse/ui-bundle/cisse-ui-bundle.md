# cisse/ui-bundle

> 标签: components, symfony, symfony-ux, tailwind, twig, ui

## 简介

A Symfony UI bundle containing reusable anonymous Twig components styled with TailwindCSS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
