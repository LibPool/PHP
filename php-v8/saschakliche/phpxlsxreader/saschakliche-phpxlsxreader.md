# saschakliche/phpxlsxreader

> 标签: OOXML, php, spreadsheet, xlsx

## 简介

A very simple library for reading Office Open XML (OOXML) spreadsheet files (XLSX)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
