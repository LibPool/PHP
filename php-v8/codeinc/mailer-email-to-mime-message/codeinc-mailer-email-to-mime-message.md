# codeinc/mailer-email-to-mime-message

> 标签: PHP

## 简介

A library to convert Code Inc.’s mailer emails to MIME messages using a component of the Zend Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
