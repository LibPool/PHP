# codeinc/cloudrun-auth-http-client

> 标签: PHP

## 简介

A PSR-7 HTTP client based on Guzzle for services hosted on Google Cloud Platform Cloud Run

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
