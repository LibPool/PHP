# rlorenzo/mago-wordpress

> 标签: coding-standards, linter, mago, static-analysis, wordpress, wpcs

## 简介

Mago extension for WordPress: WPCS-equivalent linter rules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
