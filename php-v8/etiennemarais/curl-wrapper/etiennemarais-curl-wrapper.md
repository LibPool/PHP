# etiennemarais/curl-wrapper

> 标签: api, curl, header, headers, wrapper

## 简介

Curl wrapper for easy api service consumptions with easier header management

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
