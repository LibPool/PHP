# etiennemarais/legit

> 标签: api, legit, mobile verification

## 简介

Legit is a simple service for easy Atlas user verification via a unique user identifier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
