# gurb/sdk

> 标签: community, embed, gurb, mygurb, sdk

## 简介

Official PHP SDK for the Gurb community platform. Reads your community's data, manages members and permissions, and mints embed sessions. Server-side only — it holds your secret API key.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
