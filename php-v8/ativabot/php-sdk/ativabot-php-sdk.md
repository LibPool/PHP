# ativabot/php-sdk

> 标签: WABA, api, ativabot, crm, laravel, sdk, whatsapp

## 简介

SDK oficial em PHP para integração com a API Externa do AtivaBot CRM

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
