# bebebus/merchant-openapi-sdk

> 标签: merchant, openapi, payment, sdk

## 简介

商户支付 OpenAPI 的 PHP 8 SDK（零第三方依赖，仅用标准库与 ext-curl）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
