# midhunmonachan/deploymate-laravel

> 标签: PHP

## 简介

Laravel 12 dev-only package that generates and validates a minimal deploy.yaml manifest for deploymate.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
