# davidxu/yii2-igt

> 标签: GeTui, extension, igt, yii2

## 简介

The iGetui SDK integration for the Yii2 framework and PHP 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
