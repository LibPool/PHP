# davidxu/yii2-base

> 标签: Yii2 Extension, base library, yii2

## 简介

This is a base library with set of foundation classes and components used by all Yii2 extensions by David Xu.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
