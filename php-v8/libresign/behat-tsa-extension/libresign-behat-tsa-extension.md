# libresign/behat-tsa-extension

> 标签: Behat, libresign, nextcloud, rfc3161, tsa

## 简介

Behat extension that boots a local RFC3161 TSA server for deterministic integration tests

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
