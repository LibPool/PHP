# betanow/laravel-ai-seeder

> 标签: ai, faker, laravel, llm, openai, seeder

## 简介

Seed Eloquent models with realistic data generated by an LLM (OpenAI or any OpenAI-compatible server)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
