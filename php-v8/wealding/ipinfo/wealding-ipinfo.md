# wealding/ipinfo

> 标签: IP, geo, geoip, geolocation, ipdb, ipinfo, ipip.net, ipipfreedb, qqwry

## 简介

get ipinfo from ipipfreedb and qqwry.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
