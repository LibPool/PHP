# cleantalk/php-anticrawler

> 标签: ai crawlers, anti-crawler, anti-scraping, bad bots, block list, bot blocker, bot detection, claudebot, cleantalk, crawler, crawler detect, gptbot, scraper, spam, user-agent

## 简介

PHP library to block unwanted crawlers, scrapers and bad bots by User-Agent, IP block lists and allow lists. No captcha, works on any PHP site. Self-hosted alternative to Cloudflare bot management.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
