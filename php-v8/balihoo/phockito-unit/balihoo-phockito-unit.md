# balihoo/phockito-unit

> 标签: PHP Unit, mock, phockito, test, unit

## 简介

A library easing the combination of Phockito & PHP Unit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
