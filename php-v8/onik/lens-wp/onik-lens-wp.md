# onik/lens-wp

> 标签: cdn, images, optimization, wordpress, youtube

## 简介

ONIK Lens WordPress Plugin — optimizes images and YouTube embeds via the ONIK Lens CDN.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
