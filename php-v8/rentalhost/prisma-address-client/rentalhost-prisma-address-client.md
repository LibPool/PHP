# rentalhost/prisma-address-client

> 标签: PHP

## 简介

The prisma-address-client uses the Rentalhost Webservice to retrieve Brazilian CEP informations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
