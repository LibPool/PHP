# lapalabs/skeleton-bundle

> 标签: Skeleton, base, bundle, lapalabs, layout, markup, template

## 简介

The HTML markup skeleton of base templates for Symfony Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
