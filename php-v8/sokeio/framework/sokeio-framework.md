# sokeio/framework

> 标签: PHP

## 简介

a Laravel-based web application development package that provides support for developing modules, plugins, themes, livewire, and shortcodes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
