# ngarak-dev/nextsms

> 标签: PHP

## 简介

A Laravel package to send SMS using NextSMS API. Basically a folk from https://github.com/omakei with updated packages support for laravel 10 and 11

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
