# launchsol/launchsol-oms

> 标签: PHP

## 简介

Pairs a Magento store with LaunchOMS, pushes newly placed orders to LaunchOMS, and exposes a small token-authenticated API LaunchOMS uses to discover store views and push inventory back.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
