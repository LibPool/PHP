# msdevbytes/filament-currency-switcher

> 标签: Currency Switcher, Filament v4, filament, switcher

## 简介

A Filament v4 plugin to add a currency switcher with automatic conversion

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
