# rhapsody-project/angular-js-bundle

> 标签: angular, angularjs, javascript, mvc

## 简介

AngularJS bundle for Symfony 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
