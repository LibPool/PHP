# microscrap/mpsse

> 标签: bindings, framework, ftdi, mpsse, scrapyard-io

## 简介

MPSSE SPI/I2C/GPIO helpers extending the FTDI package

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
