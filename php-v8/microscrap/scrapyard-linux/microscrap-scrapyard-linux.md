# microscrap/scrapyard-linux

> 标签: GPIO, drivers, linux, posix, scrapyard-io

## 简介

Native Linux connection drivers for the ScrapyardIO GPIO framework: gpiod, i2c-dev, spidev, termios and sysfs PWM over ext-posi

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
