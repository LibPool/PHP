# microscrap/uart

> 标签: bindings, framework, posi, scrapyard-io, serial, termios, uart

## 简介

Unix UART / Serial Bindings for The PHP Posi Extension

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
