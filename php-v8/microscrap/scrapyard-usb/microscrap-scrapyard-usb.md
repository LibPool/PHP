# microscrap/scrapyard-usb

> 标签: GPIO, drivers, ftdi, mpsse, scrapyard-io, usb

## 简介

USB connection drivers for the ScrapyardIO GPIO framework: MPSSE digital, I2C and SPI plus FTDI UART over ext-ftdi

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
