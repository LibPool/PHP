# oxapay/oxapay-laravel

> 标签: crypto, gateway, laravel, oxapay, payments, sdk

## 简介

Official Laravel SDK for OxaPay crypto payment gateway (Laravel 8-12).

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://oxapay.com
- 源码仓库：https://github.com/OxaPay/oxapay-laravel.git
- Packagist 页面：https://packagist.org/packages/oxapay%2Foxapay-laravel

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require oxapay/oxapay-laravel`
- Packagist 仓库：https://repo.packagist.org/p2/oxapay/oxapay-laravel.json
- 许可证：Apache-2.0
- PHP 要求：^8.0
