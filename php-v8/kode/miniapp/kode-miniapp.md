# kode/miniapp

> 标签: miniprogram, mp, openPlatform, wechat, 企业微信, 公众号, 小程序, 微信开放平台, 微信支付, 抖音, 支付宝, 钉钉, 飞书

## 简介

多平台小程序、公众号、企业号、微信开放平台统一接入 SDK（微信、支付宝、抖音、百度、QQ、企业微信、钉钉、飞书）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
