# kode/queue

> 标签: AMQP, beanstalkd, coroutine, database, dead-letter, job-queue, kafka, message-queue, php84, queue, rabbitmq, redis, worker, 延迟队列, 消息队列, 队列

## 简介

现代化 PHP 8.4+ 队列组件：不可变消息对象、可见性超时与至少一次投递、内建 Worker 与死信存储，支持 Redis / 数据库 / Beanstalkd / AMQP / Kafka 等多种后端

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
