# kode/scheduling

> 标签: cron, schedule, scheduler, task, timer, 定时任务

## 简介

通用 Cron 调度器：支持任意 callable / task 的简洁健壮 PHP 定时任务库

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
