# kode/jwt

> 标签: Authentication, Fingerprint, JWK, JWKS, OpenId, SSO, discovery, fpm, hyperf, introspection, jwt, laravel, mlo, oauth, oauth2, openid-connect, php84, roadrunner, security, swoole, thinkphp, token

## 简介

为现代 PHP 应用提供安全、灵活、高性能的 JWT 身份验证解决方案，支持单点登录（SSO）、多点登录、黑名单管理、自动续期、多平台适配，兼容 FPM、Swoole、RoadRunner 等运行环境。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
