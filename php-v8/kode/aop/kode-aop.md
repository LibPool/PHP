# kode/aop

> 标签: aop, aspect, attribute, interceptor, php84, php85, pointcut, proxy

## 简介

基于 PHP 8.4+ 原生属性（Attribute）实现的轻量级、高性能、高扩展性 AOP（面向切面编程）组件

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
