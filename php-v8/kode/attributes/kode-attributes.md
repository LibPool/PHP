# kode/attributes

> 标签: annotations, attributes, kode, kodephp, metadata, php84, php85, reflection

## 简介

轻量级、健壮的 PHP 8.4+ 属性读取器，为 kodephp 框架和主流 PHP 框架提供基础组件支持

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
