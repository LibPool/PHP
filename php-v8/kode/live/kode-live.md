# kode/live

> 标签: aliyun-live, hls, live, playback, recording, rtmp, srt, streaming, tencent-css, vod

## 简介

多平台直播综合包：推拉流地址签名、录制自动落对象存储、回放与断点续传下载的统一编排（PHP 8.4+）。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
