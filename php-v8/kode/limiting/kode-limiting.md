# kode/limiting

> 标签: concurrency, distributed, leaky-bucket, limiting, rate-limit, rate-limiter, semaphore, sliding-window, throttle, token-bucket

## 简介

PHP 8.4+ 限流器，支持令牌桶、漏桶、滑动窗口、滑动窗口计数器、固定窗口计数器与多规则组合限流，内置内存/APCu/Redis/Memcached/PDO 存储与分布式并发控制

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
