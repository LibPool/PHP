## 简介

企业级 PHP AI Agent 框架，兼容 Symfony AI 生态。支持短剧生成（多 Agent 协作）、多模态（文生图/视频/数字人/Seedance）、Monolog 日志、Fiber 协程、进程管理、AI 字幕、配音旁白、视频剪辑、工作流预设等企业级功能。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
