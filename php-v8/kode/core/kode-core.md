# kode/core

> 标签: app, bootstrap, config, container, core, coroutine, di, distributed, kode, launcher, runtime, service-provider

## 简介

Kode Core —— 关联 kode 生态包的应用启动器（App::boot）：加载配置 → 注册服务 → 启动运行时。DI 由 kode/di 提供，运行时由 kode/runtime 提供，ServiceProvider 与 Config 内置于本包。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
