# kode/http

> 标签: async, coroutine, fiber, http, kode, kode-fibers, kode-parallel, kode-process, middleware, php8, php84, php85, psr-15, psr-17, psr-7, server, swoole, workerman

## 简介

现代化、高性能的 PHP HTTP 服务端库，支持 PSR-7/PSR-15/PSR-17 标准，多运行时环境（Swoole、Workerman、FPM），深度集成 kode/process、kode/fibers、kode/parallel

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
