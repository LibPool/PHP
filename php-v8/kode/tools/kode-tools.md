# kode/tools

> 标签: IP, array, crypto, curl, geo, helper, message, php, php8, pipe, pipeline, qrcode, string, time, tools, tree

## 简介

PHP8.4+通用工具包，包含消息体、数组处理、字符串处理、时间处理、加解密、IP、地理计算、Curl、二维码、全局辅助函数等

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
