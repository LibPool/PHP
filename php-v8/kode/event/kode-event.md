# kode/event

> 标签: aspect-oriented, async, coroutine, dispatch, event, subscribe

## 简介

轻量级解耦事件编排库，支持事件派发、监听、订阅、异步事件、协程安全，可结合 kode/aop 做切面事件

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
