# kode/router

> 标签: coroutine, dispatcher, distributed, fast-route, fiber, kodephp, parallel, process, psr-15, router, routing, swoole

## 简介

高性能路由组件：编译期与运行期彻底分离，路由表一次编译、多进程共享，原生适配 Fiber 协程 / 多线程 / 多进程与分布式链路透传

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
