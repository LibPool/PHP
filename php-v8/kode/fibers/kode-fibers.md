# kode/fibers

> 标签: PHP

## 简介

Kode/Fibers - 高性能 PHP Fiber 协程调度器。提供协程池、上下文传递、分布式调度、断路器、负载均衡、RPC 通信（JSON/gRPC/WebSocket）、分布式事务（2PC/TCC/Saga）、多框架集成等企业级特性。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
