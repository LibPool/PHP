# kode/process

> 标签: cluster, distributed, event-loop, ipc, load-balancer, multiprocessing, native, php, pool, process, queue, reactor, runtime, signal, snowflake, swoole, worker, workerman

## 简介

PHP 8.4+ 进程编排内核：默认自研 Native 运行时（零扩展、master-worker 多进程），兼容 Swoole/Workerman，内置分布式集群能力（服务发现、分布式锁、Leader 选举、负载均衡、分布式 ID、限流、集群 RPC）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
