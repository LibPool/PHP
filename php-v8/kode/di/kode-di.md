# kode/di

> 标签: PSR-11, attribute, container, coroutine, dependency-injection, di, fiber, ioc, kodephp, php8.4

## 简介

高性能 PHP 8.4+ 依赖注入容器，支持属性注入、生命周期管理、协程上下文隔离，兼容 PSR-11

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
