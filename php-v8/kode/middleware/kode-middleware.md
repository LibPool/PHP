# kode/middleware

> 标签: coroutine, distributed, fiber, kodephp, middleware, parallel, pipeline, process, psr-15, psr-7, router

## 简介

轻量、可重入、协程安全的 PSR-15 中间件管道，串联路由前后三段式生命周期，原生融合多进程 / 多线程 / Fiber 协程与分布式链路透传

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
