# kode/facade

> 标签: container, facade, kodephp, proxy, psr, static

## 简介

适用于 PHP 8.4+ 的健壮、通用门面组件，兼容 Laravel、Symfony、ThinkPHP、Webman 和 KodePHP。

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
