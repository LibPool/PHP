# kode/http-client

> 标签: async, client, concurrent, coroutine, fiber, http, middleware, php84, psr-17, psr-18, psr-7, swoole, swow

## 简介

现代化、高性能的 PHP HTTP 客户端，支持多运行时环境（FPM、CLI、Swoole、Swow、Fiber）

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
