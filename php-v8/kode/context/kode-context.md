# kode/context

> 标签: Context, coroutine, distributed, fiber, opentelemetry, php84, request-context, swoole, swow, tracing, w3c-trace-context, 上下文, 分布式, 协程, 纤程, 链路追踪

## 简介

轻量级、高性能的 PHP 协程/纤程上下文管理库，支持分布式多机器部署与 W3C Trace Context 标准

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
