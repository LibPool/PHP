# kode/session

> 标签: cache, cookie, coroutine, distributed, fiber, file, kode, psr-15, redis, session

## 简介

kode/session - 分布式会话管理器，支持文件、Redis、Cookie、内存等驱动

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
