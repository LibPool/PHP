# kode/console

> 标签: cli, command, console, framework, kodephp, php84, php85, terminal

## 简介

健壮、通用的 PHP 控制台组件，要求 PHP 8.4+，内置签名 DSL、注解式命令、中间件与事件系统

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
