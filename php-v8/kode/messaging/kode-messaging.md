# kode/messaging

> 标签: coap, coroutine, datagram, fiber, iot, kode, long-polling, longpolling, messaging, mqtt, php, php8, pubsub, realtime, rpc, sse, udp, websocket

## 简介

统一消息层，封装 **11 种长连接 / 实时消息协议**（WebSocket、SSE、MQTT、UDP、Long-Polling、CoAP、NATS、STOMP、gRPC Streaming、WebTransport、RTMP），提供**一致的 API**、**协议无关的消息抽象**和**可插拔的扩展点**

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
