# coretsia/platform-errors

> 标签: coretsia, deterministic, error-descriptor, error-handling, errors, exception-mapping, framework, observability, php, redaction, runtime

## 简介

Coretsia error handling runtime package: deterministic exception mapping, safe error normalization, and redacted diagnostics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
