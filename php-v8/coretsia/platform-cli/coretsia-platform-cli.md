# coretsia/platform-cli

> 标签: cli, command-discovery, commands, coretsia, deterministic, framework, kernel-operations, php, redaction, runtime

## 简介

Coretsia CLI runtime package: tag-first command discovery, Kernel operations, and deterministic safe output.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
