# php-on-couch/php-on-couch

> 标签: apache, couch, couchdb, db, driver, nosql

## 简介

CouchDB NoSQL database access in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
