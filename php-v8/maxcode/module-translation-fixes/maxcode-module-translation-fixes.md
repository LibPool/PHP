# maxcode/module-translation-fixes

> 标签: PHP

## 简介

EN: Magento 2 module that makes translatable the strings Magento does not expose to translation. It contains no translations: they come from language packs. FR : Module Magento 2 qui rend traduisibles les chaînes que Magento n'expose pas à la traduction. Il ne contient aucune traduction : elles viennent des packs de langue.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
