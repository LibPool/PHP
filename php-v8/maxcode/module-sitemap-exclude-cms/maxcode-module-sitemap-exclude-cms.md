# maxcode/module-sitemap-exclude-cms

> 标签: Sitemap, cms, magento2, seo

## 简介

EN: Adds an “Exclude from XML sitemap” checkbox to the SEO tab of each Magento 2 CMS page: ticked pages are left out of the generated sitemaps. FR : Ajoute une case « Exclure du plan de site XML » dans l'onglet SEO de chaque page CMS Magento 2 : les pages cochées sont retirées des plans de site générés.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
