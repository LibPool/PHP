# aestron/aestron-openapi-sdk

> 标签: Aestron, client, library, sdk

## 简介

Aestron openapi sdk for PHP - Use Aestron openapi sdk client in your PHP project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
