# jonquintero/laravel-module-maker

> 标签: artisan, generator, laravel, modules, scaffold, stubs

## 简介

Artisan command to scaffold Laravel modules from custom stubs.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
