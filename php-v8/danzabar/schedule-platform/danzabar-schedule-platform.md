# danzabar/schedule-platform

> 标签: PHP

## 简介

Uses various packages to create a schedule keeper webplatform that you can generate and keep track of schedules with.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
