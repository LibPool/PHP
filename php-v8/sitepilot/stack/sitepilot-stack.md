# sitepilot/stack

> 标签: PHP

## 简介

Effortlessly provision high-performance cloud servers and containers, fine-tuned for WordPress and Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
