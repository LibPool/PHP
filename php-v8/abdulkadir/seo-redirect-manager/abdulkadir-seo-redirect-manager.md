# abdulkadir/seo-redirect-manager

> 标签: 301-redirects, 404-monitor, Craft, cms, craft-cloud, craft-plugin, craftcms, redirect, redirects, seo, short-links, url-aliases

## 简介

Enterprise SEO Redirect Manager for Craft CMS 5. High-performance exact and regex matching, 404 monitoring, automated URI change redirects, CSV import/export, redirect chain and loop detection, and short links.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
