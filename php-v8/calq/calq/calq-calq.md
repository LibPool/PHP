# calq/calq

> 标签: calq

## 简介

Calq API client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/Calq/Client-PHP
- 源码仓库：https://github.com/Calq/Client-PHP.git
- Packagist 页面：https://packagist.org/packages/calq%2Fcalq

## 获取地址

- Composer 安装：`composer require calq/calq`
- Packagist 仓库：https://repo.packagist.org/p2/calq/calq.json
- 许可证：Apache-2.0
- PHP 要求：>=5.3.0
