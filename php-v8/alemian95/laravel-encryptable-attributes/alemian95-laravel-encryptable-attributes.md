# alemian95/laravel-encryptable-attributes

> 标签: PHP

## 简介

Laravel Package to effortlessy encrypt and decrypt from database model attributes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
