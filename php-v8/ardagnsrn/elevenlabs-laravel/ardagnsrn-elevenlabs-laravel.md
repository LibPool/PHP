# ardagnsrn/elevenlabs-laravel

> 标签: ArdaGnsrn, elevenlabs-laravel, laravel

## 简介

This is an Open Source Laravel package for ElevenLabs Text to Speech API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
