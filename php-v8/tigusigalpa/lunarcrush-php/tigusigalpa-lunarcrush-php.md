# tigusigalpa/lunarcrush-php

> 标签: API-Client, crypto, laravel, lunarcrush, sdk, social-analytics

## 简介

A modern, framework-agnostic PHP SDK for the LunarCrush API v4, with first-class Laravel 10, 11, 12 & 13 integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
