# tigusigalpa/bitget-php

> 标签: api, bitget, crypto, laravel, sdk, trading, uta

## 简介

A production-grade PHP/Laravel SDK for the Bitget Unified Trading Account (UTA) API v3.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
