# tigusigalpa/bingx-php

> 标签: PHP

## 简介

BingX API v3 client for PHP with Laravel 8-13 integration - TWAP orders, trailing stops, multi-assets margin, advanced risk management

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
