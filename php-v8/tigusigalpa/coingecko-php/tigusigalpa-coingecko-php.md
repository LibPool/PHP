# tigusigalpa/coingecko-php

> 标签: Coingecko, api, bitcoin, blockchain, crypto, crypto-prices, cryptocurrency, ethereum, laravel, market-data, php

## 简介

A PHP/Laravel package for CoinGecko API integration with support for core REST endpoint groups, markets, contracts, and WebSocket subscription helpers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
