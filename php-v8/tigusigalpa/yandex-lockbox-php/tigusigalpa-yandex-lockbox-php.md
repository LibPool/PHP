# tigusigalpa/yandex-lockbox-php

> 标签: client, laravel, lockbox, php, sdk, secrets, yandex

## 简介

PHP/Laravel client library for Yandex Lockbox (secrets storage) API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
