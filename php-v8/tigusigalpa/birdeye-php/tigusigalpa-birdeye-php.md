# tigusigalpa/birdeye-php

> 标签: BirdEye, api, crypto, defi, laravel, market-data, sdk, solana

## 简介

A PHP client for the Birdeye crypto market data API, with optional Laravel 10-13 integration.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
