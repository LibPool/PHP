# moffhub/sms-handler

> 标签: Africastalking, advanta, africa, bulk-sms, delivery-report, laravel, laravel-package, nexmo, onfon, sms, sms-gateway, sms-notification, sms-provider, sms-template, twilio, vonage

## 简介

Unified SMS gateway for Laravel with multi-provider support (Advanta, Africa's Talking, Twilio, Nexmo, Onfon). Queue-ready, delivery tracking, fallback chains, templating, and analytics.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
