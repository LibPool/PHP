# vlucas/spot2

> 标签: database, datamapper, dbal, doctrine, entity, mapper, model, orm

## 简介

Simple DataMapper built on top of Doctrine DBAL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
