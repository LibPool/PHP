# luancosta/is-cnpj

> 标签: alfanumérico, brasil, cnpj, validacao, validation

## 简介

Biblioteca PHP para validacao de CNPJ (numerico e alfanumerico) com suporte a mascaras

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
