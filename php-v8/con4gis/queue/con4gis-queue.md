# con4gis/queue

> 标签: QueueBundle, batch, c4g, con4gis, processing, queue, stack

## 简介

The batch processing brick of the Contao GIS-kit con4gis.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
