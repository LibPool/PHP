# con4gis/framework

> 标签: FrameworkBundle, c4g, con4gis, contao, framework, frontend, module

## 简介

The framework brick of the Contao GIS-kit con4gis. Useful for developing frontend modules.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
