# simonschaufi/typo3-phone

> 标签: libphonenumber, phone, typo3, validation

## 简介

Adds phone number functionality to TYPO3 based on Google's libphonenumber API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
