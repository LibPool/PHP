# smartpack/wordpress-woocommerce-plugin

> 标签: plugin, woocommerce, wordpress

## 简介

WordPress SmartPack addon to WooCommerce with full integration to smartpack.dk system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
