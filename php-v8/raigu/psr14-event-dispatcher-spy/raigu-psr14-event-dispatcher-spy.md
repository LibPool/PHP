# raigu/psr14-event-dispatcher-spy

> 标签: PHP

## 简介

PSR-14 event dispatcher implementation for testing if the subject under test is emitting expected event.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
