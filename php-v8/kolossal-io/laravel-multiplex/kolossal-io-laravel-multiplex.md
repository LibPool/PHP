# kolossal-io/laravel-multiplex

> 标签: eloquent, kolossal, laravel, laravel-multiplex, meta, metadata

## 简介

A Laravel package to attach versioned meta data to Eloquent models.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
