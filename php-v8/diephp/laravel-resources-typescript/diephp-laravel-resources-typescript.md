> 标签: api, codegen, enum, generate, interfaces, jsonresource, laravel, laravel-package, laravel-resource, laravel-typescript, php-enum, resources, types, typescript, typescript-generator

## 简介

Generate TypeScript interfaces and type aliases from Laravel JsonResource classes, including enum support

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
