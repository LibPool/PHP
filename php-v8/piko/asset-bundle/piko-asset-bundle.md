# piko/asset-bundle

> 标签: asset, assetBundle, bundle, piko framework

## 简介

An helper to manage and publish a collection of assets inside the public path of a Piko framework project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
