# bk2k/syntax

> 标签: Prismjs, TYPO3 CMS, extension, syntax highlighting

## 简介

Lightweight, robust, elegant syntax highlighting content element based on PrismJS

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
