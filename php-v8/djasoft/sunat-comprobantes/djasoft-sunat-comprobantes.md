# djasoft/sunat-comprobantes

> 标签: comprobantes, facturacion-electronica, greenter, igv, peru, sunat

## 简介

Cálculo de totales e IGV y contenido del código QR para comprobantes de pago electrónicos de SUNAT (Perú). Sin dependencias de framework.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
