# chr15k/php-typos

> 标签: chr15k, cli, code-quality, developer-tools, php, spell-checker, spellcheck, static-analysis, typos

## 简介

Native, ultra-fast spellchecking and fixing for PHP codebases.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
