# justijndepover/php-check

> 标签: check, justijndepover, php, php-cs-fixer, phpunit

## 简介

Helper package to fix coding styles and run unit testing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
