# orlinkzz/waha-php

> 标签: api, bot, laravel, waha, whatsapp

## 简介

PHP client for WAHA (WhatsApp HTTP API) with built-in anti-banned flow

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
