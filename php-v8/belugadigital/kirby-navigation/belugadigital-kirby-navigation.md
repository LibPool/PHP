# belugadigital/kirby-navigation

> 标签: field, kirby, kirby-cms, kirby-plugin, menu, navigation

## 简介

Kirby 5 field for hierarchical menus with drag & drop level indentation.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
