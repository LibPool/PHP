# ucf/brand-child-theme

> 标签: PHP

## 简介

WordPress theme for brand website with brand guidelines. This is a child theme of the UCF-WordPress-Theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
