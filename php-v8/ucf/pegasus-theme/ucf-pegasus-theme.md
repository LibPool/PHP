# ucf/pegasus-theme

> 标签: PHP

## 简介

Wordpress theme for Pegasus Magazine.  Built off of UCF's Generic Theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
