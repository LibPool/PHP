# ucf/ucf-degree-cpt-plugin

> 标签: PHP

## 简介

Provides a custom post type, taxonomies and other utilities for describing UCF degree programs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
