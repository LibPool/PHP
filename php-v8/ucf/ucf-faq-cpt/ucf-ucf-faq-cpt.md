# ucf/ucf-faq-cpt

> 标签: PHP

## 简介

Provides a custom post type for describing FAQs and creates supporting shortcodes. This plugin supports the UCF Athena Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
