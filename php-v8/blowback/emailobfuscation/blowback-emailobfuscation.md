# blowback/emailobfuscation

> 标签: EMO, email, obfuscation, processwire

## 简介

Email Obfuscation module for email addresses with 64 base crypting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
