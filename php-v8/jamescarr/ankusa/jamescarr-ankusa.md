# jamescarr/ankusa

> 标签: admin, ankusa, claim-check, routes, webhook

## 简介

Client SDK for Ankusa deployments: the claim-check gateway client, the route-management, operator (admin) and source-management clients, and a webhook-receiving header helper.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
