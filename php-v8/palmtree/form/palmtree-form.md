# palmtree/form

> 标签: ajax, bootstrap, captcha, form, form-builder, recaptcha

## 简介

Form builder with Bootstrap v5/v4 classes, validation, Recaptcha support, AJAX submissions and more

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
