# um/sms-charset-detector

> 标签: UCS, gsm, sms, sms charset

## 简介

Small library for detecting whether your sms is using gsm charset only or not

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
