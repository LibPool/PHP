# ph3nol/docker-arch

> 标签: developer-tools, devops, docker, docker-compose, generator

## 简介

Generate Web/CLI projects Dockerized environments, from 1 simple YAML file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
