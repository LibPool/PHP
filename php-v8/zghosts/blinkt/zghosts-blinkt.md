# zghosts/blinkt

> 标签: GPIO, blinkt, pi, pin, pins, raspberry

## 简介

A library for using the pimoroni blinkt on a Raspberry Pi

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
