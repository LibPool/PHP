# defr/socialite-module

> 标签: laravel, login, oauth, pyrocms, socialite, streams-platform

## 简介

The social login addon for the PyroCMS and the Streams Platform.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
