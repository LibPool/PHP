# onebot/libonebot

> 标签: OneBot, libonebot, php, starter

## 简介

PHP 的 LibOneBot 库，通过此库可快速接入 OneBot 生态

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
