# neilime/geshi-twig-extension

> 标签: Syntax highlighter, geshi, twig

## 简介

Twig extension to work with Geshi - Generic Syntax Highlighter rendering

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
