# neilime/zf2-assets-bundle

> 标签: JS, Zend Framework, assets, bundle, cache, css, less, zf2

## 简介

Zend Framework module that provides assets bundling / caching

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
