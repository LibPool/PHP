# werwolflg/yii2-wschat

> 标签: Ratchet, backbone, chat, extension, websocket, yii2

## 简介

Private chat based on web sockets and ratchet php (Yii2)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
