# alejandroherr/silex-esngalaxysecurityserviceprovider

> 标签: PHP

## 简介

Cas security service provider for silex to authenticate with the ESN Galaxy

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
