# inuitviking/imms

> 标签: cms, html, imms, inuitviking, management system, markdown, markup, markup language, md, plugins, text, themes, wiki

## 简介

Fully automatic SSG. Host this somewhere, forget about it, have your static content up to date, always.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
