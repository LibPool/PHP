# proteusthemes/sticky-menu

> 标签: customizer, menu, proteusthemes, sticky, theme, wordpress, wp

## 简介

Sticky menu PHP composer package for all newer PT themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
