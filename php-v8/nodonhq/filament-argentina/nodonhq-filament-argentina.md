# nodonhq/filament-argentina

> 标签: CUIT, DNI, argentina, cbu, cuil, cvu, filament, laravel, validation

## 简介

Argentine form fields, table columns and validation rules for Filament: CUIT/CUIL, DNI, CBU/CVU, alias, phone, provinces, pesos and IVA condition.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
