# jhuddle/laravel-mermaid

> 标签: laravel, mermaid

## 简介

Automatic generation of Mermaid diagrams from Laravel app structure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
