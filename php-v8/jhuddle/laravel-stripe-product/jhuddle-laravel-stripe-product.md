# jhuddle/laravel-stripe-product

> 标签: cashier, laravel, stripe

## 简介

Uses Laravel Cashier to update the app DB with products fetched from the Stripe API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
