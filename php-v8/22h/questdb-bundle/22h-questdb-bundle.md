# 22h/questdb-bundle

> 标签: bundle, database, migrations, profiler, questdb, symfony, time-series

## 简介

Symfony bundle integrating the QuestDB REST client and migration manager.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
