# sagar-s-bhedodkar/laravel-index-advisor

> 标签: PHP

## 简介

Monitor Eloquent/DB queries in your Laravel application and suggest scaffold migrations for missing indexes.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
