# arzcode/filament-magic-login

> 标签: Authentication, Passwordless, filament, laravel, login, magic-link

## 简介

Passwordless "email me a login link" option for Filament panels, alongside the standard password form.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
