# arzcode/filament-docs

> 标签: documentation, filament, filamentphp, laravel, markdown, screenshots

## 简介

An in-panel user manual for Filament: one markdown file per screen, laid out like the panel's own navigation, with screenshots taken by Playwright.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
