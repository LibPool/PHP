# tyxla/carbon-breadcrumbs

> 标签: Settings, admin, advanced, after, auto, before, breadcrumb, breadcrumbs, carbon, configuration, developer, extending, glue, trail, wordpress

## 简介

A basic WordPress plugin for breadcrumbs with advanced capabilities for extending.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
