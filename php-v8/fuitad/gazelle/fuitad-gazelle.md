# fuitad/gazelle

> 标签: animation, cgwire, kitsu, pipeline, vfx, zou

## 简介

PHP library for the Kitsu API (zou), based on the gazu python library

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
