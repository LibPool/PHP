# fuitad/gazelle-laravel-wrapper

> 标签: PHP

## 简介

A Laravel wrapper for the Kitsu/Zou production tracker PHP client (fuitad/gazelle)

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
