# phpmicroservice/phalcon-ide-stubs

> 标签: Devtools, Eclipse, autocomplete, ide, netbeans, phalcon, phpstorm, stub, stubs

## 简介

The most complete Phalcon Framework IDE stubs library which enables autocompletion in modern IDEs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
