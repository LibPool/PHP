# ebook/toastr

> 标签: alerts, ebook, flash messages, frontend, laravel, messages, notification, pop-up, toast, toastr, user interface

## 简介

A Laravel package for displaying toast notifications. Using this you can show success, error, warning, info messages.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
