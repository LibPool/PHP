# pinkeen/api-debug-bundle

> 标签: Guzzle, api, bundle, debug, symfony, toolbar

## 简介

Allows easy API consumer debugging with web debug toolbar extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
