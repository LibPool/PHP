# progmancod/dms-filter-bundle

> 标签: bundle, dms, filter, symfony

## 简介

DMS Filter Bundle, makes Annotation based entity filtering available in Symfony

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
