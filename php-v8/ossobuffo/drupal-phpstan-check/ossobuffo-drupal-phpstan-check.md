# ossobuffo/drupal-phpstan-check

> 标签: PHP

## 简介

Composer command to run Drupal-specific phpstan check on Drupal 11+, based on mglaman/drupal-check.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
