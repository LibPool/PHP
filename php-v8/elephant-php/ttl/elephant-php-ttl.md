# elephant-php/ttl

> 标签: Http Cache, Value Object, cache, cache duration, cache ttl, caching, expiration, no magic value, response caching, time to live, ttl, vo

## 简介

An immutable Time To Live value object for the cache and other places where you need to specify a time rather than a magic value.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
