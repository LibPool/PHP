# elephant-php/byte-size

> 标签: byte-size, bytes, conversion, file-size, filesize, formatter, value-object

## 简介

ByteSize uses binary conversion (1024-based) for file-size formatting.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
