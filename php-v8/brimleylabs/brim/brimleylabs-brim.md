# brimleylabs/brim

> 标签: ai, embeddings, laravel, machine-learning, nlp, ollama, openai, pgvector, semantic-search, similarity-search, vector-database, vector-search

## 简介

Semantic search for Laravel using Ollama and pgvector. Local-first, privacy-focused, no API keys required.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
