# oxblue/oauth2-procore

> 标签: Authentication, authorization, client, oauth, oauth2, procore

## 简介

An OAuth2 wrapper to authenticate with Procore

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
