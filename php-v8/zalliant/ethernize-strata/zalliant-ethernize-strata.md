# zalliant/ethernize-strata

> 标签: ethernize, framework, php

## 简介

Strata: persistence foundation (PDO connections, query builder, transactions, migrations) for Zalliant Ethernize.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
