# alitycs/alitycs-sdk-php

> 标签: alitycs, analytics, events, tracking

## 简介

Alitycs Analytics SDK for PHP — server-side event tracking with batching, sessions, and retry.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
