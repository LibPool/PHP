# tdy/pdf

> 标签: 731633799, DoubleY, TdY, pdf, pdf helper, tdpdf

## 简介

PDF文件处理 添加文字水印 添加图片以及图片旋转

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
