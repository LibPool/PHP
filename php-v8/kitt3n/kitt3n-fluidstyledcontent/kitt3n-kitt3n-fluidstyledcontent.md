# kitt3n/kitt3n-fluidstyledcontent

> 标签: TYPO3 Kit, fluidstyledcontent, kitt3n, override

## 简介

Extension to override things from fluidstyledcontent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
