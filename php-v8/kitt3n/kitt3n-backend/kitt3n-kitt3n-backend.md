# kitt3n/kitt3n-backend

> 标签: TYPO3 Kit, kitt3n

## 简介

All configuration (page & user) for the TYPO3 backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
