# alexdesignworks/dcr

> 标签: drupal, jscs, jslint, lint, linter, phpcs, standards

## 简介

Shell script wrapper around PHP_CodeSniffer and JSCS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
