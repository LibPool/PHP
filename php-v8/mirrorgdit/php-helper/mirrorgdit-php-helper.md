# mirrorgdit/php-helper

> 标签: memcached, mirrorgdit, mysql, mysqli, pdo, php, redis

## 简介

PHP各种辅助类、Memcached、Redis、Mysql、Mysqli、PDO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
