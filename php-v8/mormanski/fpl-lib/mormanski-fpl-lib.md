# mormanski/fpl-lib

> 标签: Fantasy Football, Premier league, api, epl, library, php

## 简介

PHP Library to access the undocumented https://fantasy.premierleague.com API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
