# mikescott/slim3-minifier

> 标签: html, minifier, minify, slim, slim3

## 简介

A middleware for Slim 3 that minifies HTML output

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
