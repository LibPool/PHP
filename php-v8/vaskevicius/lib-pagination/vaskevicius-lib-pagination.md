# vaskevicius/lib-pagination

> 标签: cursor, doctrine, limit, offset, page, pagination, paginator

## 简介

Paginates Doctrine QueryBuilder using cursor based or offset based pagination

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
