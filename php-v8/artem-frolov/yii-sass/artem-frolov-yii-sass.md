# artem-frolov/yii-sass

> 标签: compass, css, sass, scss, yii

## 简介

Sass (SCSS) and Compass support for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
