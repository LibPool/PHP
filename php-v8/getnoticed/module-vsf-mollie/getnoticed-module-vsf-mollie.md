# getnoticed/module-vsf-mollie

> 标签: PHP

## 简介

A Vue Storefront API adoptation for Magento 2, that offers additional fields required for the implementation of Mollie.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
