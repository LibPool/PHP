# samuell/cdn-plugin

> 标签: cdn, manifest, octobercms, sync

## 简介

Push, sync, clear and serve assets to/from a CDN or include manifest files from webpack or laravel-mix.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
