# t3rrific/aws-cloudfront-manager

> 标签: PHP

## 简介

Backend module that lets backend users trigger Amazon CloudFront invalidations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
