# parseapi/sdk

> 标签: IP, currency, email validation, geolocation, parseapi, phone validation, postal, timezone, weather

## 简介

Official ParseAPI client for PHP. One key, minimal JSON, fast.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
