# nextvisit/claim-md-php

> 标签: api, claimmd, insurance-claims, php-wrapper, x12

## 简介

An unofficial PHP wrapper for the official Claim.MD API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
