# nivseb/php-mock-server-connector

> 标签: mock, mocking, php, phpunit, request, test, testing

## 简介

Small tool to use mock-server/mockserver in a easy way from php based tests.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
