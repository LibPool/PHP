# asdfdotdev/session

> 标签: asdf, session, sessions

## 简介

The asdf_ session class endeavors to make it easier to use basic best practices in PHP sessions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
