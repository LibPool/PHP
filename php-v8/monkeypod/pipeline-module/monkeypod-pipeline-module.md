# monkeypod/pipeline-module

> 标签: PHP

## 简介

MonkeyPod Pipeline supports donor moves management and other sales-funnel use cases for nonprofit organizations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
