# conneredu300/cnab_yaml

> 标签: boleto, cnab, cnab240, cnab400, edi, remessa, retorno, yaml

## 简介

Especificação do formato Cnab240 e Cnab400 traduzida para Yaml

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
