# fikrimastor/mykad

> 标签: FikriMastor, MyKad, laravel, laravel-package

## 简介

Mykad package is a laravel package, purposely to validate, parse, and format Malaysian Identity Card (MyKad) numbers.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
