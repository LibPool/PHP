# cronwatcher/laravel

> 标签: cron, cronwatcher, laravel, monitoring, scheduler

## 简介

CronWatcher.io Laravel integration package for monitoring and syncing scheduled tasks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
