# ftab/php-dogecoinrpc

> 标签: Guzzle, api, dogecoin, jsonrpc

## 简介

Dogecoin JSON-RPC client based on php-bitcoinrpc

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
