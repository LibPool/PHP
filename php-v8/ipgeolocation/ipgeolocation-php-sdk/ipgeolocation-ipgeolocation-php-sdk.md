# ipgeolocation/ipgeolocation-php-sdk

> 标签: Abuse, IP, api, asn, bulk-lookup, domain-lookup, geolocation, hostname, ip-geolocation, ip-location, ip-lookup, ipgeolocation, ipv4, ipv6, php, sdk, security, timezone, user-agent

## 简介

Official PHP SDK for the IPGeolocation.io IP Location API with single and bulk lookup support.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
