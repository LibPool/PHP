# scottoffen/markdown-converter

> 标签: alerts, gfm, github-flavored-markdown, html, markdown, math, mermaid, safe, sanitize, tables

## 简介

Converts Markdown to safe HTML, with GitHub-style tables, images, and alerts.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
