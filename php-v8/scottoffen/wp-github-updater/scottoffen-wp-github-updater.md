# scottoffen/wp-github-updater

> 标签: github, plugin, releases, theme, updater, wordpress

## 简介

Update WordPress plugins and themes from GitHub releases using both public and private repositories.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

- 官网：https://github.com/scottoffen/wp-github-updater
- 源码仓库：https://github.com/scottoffen/wp-github-updater.git
