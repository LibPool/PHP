# kazistm/laravel-scoped-backup

> 标签: backup, database-backup, database-restore, dataset-export, disaster-recovery, eloquent, laravel, mariadb, monitoring, mysql, postgresql, retention, scoped-backup, sqlite

## 简介

Laravel backup and recovery package for full-database backups and scoped Eloquent data exports and restores, with integrity verification, dry-run validation, retention policies, and health monitoring.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
