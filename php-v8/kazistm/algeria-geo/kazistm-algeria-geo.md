# kazistm/algeria-geo

> 标签: 69 wilayas, Algeria, Wilaya, algeria geo, algeria locations, algerian cities, communes, coordinates, daira, database seeder, geolocation, laravel, laravel geo, laravel seeder

## 简介

Laravel package providing complete Algerian geo data (69 Wilayas and Communes) with slugs, coordinates and optimized seeders.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
