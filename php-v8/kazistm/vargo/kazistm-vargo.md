# kazistm/vargo

> 标签: Algeria, Dz, Ecotrack, Procolis, Yalidine, algerian-delivery, cash-on-delivery, cod, delivery, dz-delivery, dz-shipping, ecommerce-dz, laravel, livraison-algerie, maystro, mdm-express, noest, package-tracking, shipment, shipping, shipping-gateway, unified-api, zimou-express, zr-express

## 简介

A unified Laravel integration package for 90+ Algerian delivery providers (Yalidine, EcoTrack, Procolis, ZR Express, Maystro, Noest, MDM, Zimou). Standardizes shipment creation, tracking, and location normalization with a single consistent API.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
