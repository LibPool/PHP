# rsdim/phpquery

> 标签: PHP

## 简介

Variation of phpquery library from the original code available in the [Google Code Archive](https://code.google.com/archive/p/phpquery/) for php 8.3

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
