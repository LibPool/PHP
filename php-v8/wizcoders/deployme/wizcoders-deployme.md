# wizcoders/deployme

> 标签: PHP

## 简介

Gitea push-to-deploy webhook endpoint for Laravel, guarded by an Authorization header and an HMAC payload signature.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
