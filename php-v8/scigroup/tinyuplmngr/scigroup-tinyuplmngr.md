# scigroup/tinyuplmngr

> 标签: Symfony2, doctrine2, file manager, form, plupload, tinymce

## 简介

TinyMCE + Plupload very minimalistic upload manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
