# n1215/http-router

> 标签: psr-15, psr-7, router

## 简介

A PSR-7 / PSR-15 compatible router interface and a PSR-15 server request handler implementation for routing.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
