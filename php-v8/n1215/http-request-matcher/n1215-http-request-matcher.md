# n1215/http-request-matcher

> 标签: http-request, matcher, psr-7

## 简介

Matcher interface for PSR-7 HTTP request, like preg_match() for string.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
