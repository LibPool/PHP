# rocketweb/module-shopping-feed-migration-rocketweb

> 标签: PHP

## 简介

Optional, explicit migration of Rocket Web feed configuration to Mage-OS Shopping Feed.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
