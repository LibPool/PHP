# limeq/package-support

> 标签: limeq, php, support

## 简介

Base support package for limeQ packages

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。

## 官网

- 官网：https://limeq.com
- 源码仓库：https://gitlab.com/limeq/package-support.git
- Packagist 页面：https://packagist.org/packages/limeq%2Fpackage-support

- Composer 安装：`composer require limeq/package-support`
