# beatswitch/lock

> 标签: acl, asserts, beatswitch, conditions, drivers, permissions, roles, security

## 简介

A flexible, driver based Acl package for PHP 5.4+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
