# draliragab/socialize

> 标签: facebook, instagram, laravel, linkedin, social, twitter, x

## 简介

Unified Laravel social media publishing for Facebook, Instagram, X, and LinkedIn.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
