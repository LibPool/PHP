# narya/php-sdk

> 标签: msgpack, narya, php, runtime, uds, worker

## 简介

PHP SDK for the Narya Runtime Engine (Go) - Worker, protocol, lifecycle, UDS + MessagePack bridge

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
