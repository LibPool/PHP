# antonbelousgit/laravel-ses-event-manager

> 标签: bounce, click, delivery, email, events, http, https, laravel, open, send, ses, webhooks

## 简介

A Laravel package to manage incoming SES email events with http/s webhooks.

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
