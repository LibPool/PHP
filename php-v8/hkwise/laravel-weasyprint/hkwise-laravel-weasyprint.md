# hkwise/laravel-weasyprint

> 标签: WeasyPrint, blade to pdf, css3 pdf, html to pdf, laravel, pdf, pdf generation

## 简介

A Laravel wrapper for WeasyPrint to generate PDFs

按 require.php 推断最低支持 PHP 8；已收录于 php-v8。
