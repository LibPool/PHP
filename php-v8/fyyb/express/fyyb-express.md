# fyyb/express

> 标签: Fyyb, api, framework, micro, router

## 简介

PHP micro framework that helps you quickly write simple yet powerful web applications and APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
