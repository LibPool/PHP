# thibaud-dauce/moloquent-inheritance

> 标签: inheritance, laravel, model, mongo

## 简介

Provide single table inheritance for Moloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
