# flexibuild/php-safe

> 标签: safe, template, yii2

## 简介

Yii2 template engine. Php-Safe compiler generates php code like source but with safe echo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
