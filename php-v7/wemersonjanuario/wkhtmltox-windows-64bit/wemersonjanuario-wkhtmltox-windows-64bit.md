# wemersonjanuario/wkhtmltox-windows-64bit

> 标签: binary, convert, htmltoimage, htmltopdf, pdf, snapshot, thumbnail, wkhtmltoimage, wkhtmltopdf, wkhtmltox

## 简介

Convert html to pdf/images using webkit (qtwebkit). Static linked windows binary for 64 bit systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
