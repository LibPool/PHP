# wordpress-hyperion/api2pdf

> 标签: PHP

## 简介

Plugin permettant d'utiliser l'api en ligne api2pdf pour générer des pdf à partir du html

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
