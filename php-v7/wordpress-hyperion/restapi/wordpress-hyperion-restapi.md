# wordpress-hyperion/restapi

> 标签: PHP

## 简介

Plugin permettant d'abstraire la complexité  au niveau de la gestion de l'API rest de wordpress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
