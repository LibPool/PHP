# sammaye/yii2-pq

> 标签: db, pagination, query, yii2

## 简介

A paged query class for Yii2 to deal with PHP7 changed in mysqlnd

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
