# webcoast/character-counter

> 标签: character, cms, count, counter, input, rte, seo, textarea, typo3

## 简介

Show a character counter below text fields in TYPO3 CMS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
