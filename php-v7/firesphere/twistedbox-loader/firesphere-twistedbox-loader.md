# firesphere/twistedbox-loader

> 标签: PHP

## 简介

CLI tool to quickly initiate a base TwistedBytes Vagrant box with SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
