# firesphere/haveibeenpwnd

> 标签: haveibeenpwned, password, silverstripe

## 简介

Check if a user password is found in the Have I Been Pwned database.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
