# gloo/module-sso

> 标签: PHP

## 简介

A Sign Sign On Extension based on OAuth2 that provides the ability to log into magento using data from IdPs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
