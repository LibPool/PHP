# creativesoftworks/behat-wiremock-context-extension

> 标签: PHP

## 简介

A Behat Extension that makes use of Wiremock as a test double for API calls

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
