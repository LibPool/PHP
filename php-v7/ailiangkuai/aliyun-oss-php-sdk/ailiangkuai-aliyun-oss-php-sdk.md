# ailiangkuai/aliyun-oss-php-sdk

> 标签: PHP

## 简介

Aliyun OSS SDK for PHP (fork for swoole)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
