# faryshta/yii2-clockpicker

> 标签: clockpicker, jquery, timepicker, yii, yii2

## 简介

Yii2 wrapper for clockpicker (clock-like time picker) plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
