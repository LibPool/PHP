# async-aws/flysystem-s3

> 标签: Flysystem, amazon, async-aws, aws, filesystem, s3, sdk

## 简介

Flysystem S3 adapter from AsyncAws.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
