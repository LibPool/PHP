# umobi/sped-nfse-amtec

> 标签: nfe, nfephp, nfse, nfse goiania, sped, webservice

## 简介

API para geração e comunicação de RPS e NFSe no padão AMTEC Goiania.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
