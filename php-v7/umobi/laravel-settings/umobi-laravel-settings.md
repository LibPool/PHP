# umobi/laravel-settings

> 标签: Settings, key-value, laravel, persistent, storage

## 简介

Persistent settings manager for laravel, using pivoted database table

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
