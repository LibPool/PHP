# jobinja/laravel-djangoable-auth

> 标签: PHP

## 简介

An authentication driver for Laravel5 which allows to authenticate users using their legacy Django PBKDF2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
