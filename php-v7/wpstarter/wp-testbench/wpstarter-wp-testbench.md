# wpstarter/wp-testbench

> 标签: phpunit, test, testing, unit, wordpress

## 简介

A tool to set up a WordPress test environment for PHPUnit testing

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
