# schubu/iseed

> 标签: artisan, generators, laravel, seed

## 简介

This is a fork of the original package Orangehill/Iseed by Tihomir Opacic (tihomir.opacic@SchuBudev.com). Generate a new Laravel database seed file based on data from the existing database table.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
