# pentarim/sylius-affiliate-bundle

> 标签: affiliate, ecommerce, referral, shop

## 简介

Affiliate & referral system for Sylius applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
