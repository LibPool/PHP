# rentmarket/eleqhant

> 标签: eloquent, laravel

## 简介

Eloquent extension to provide a little bit more functionality. Works for both L4 and L5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
