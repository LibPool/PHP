# jtangas/auth-bundle

> 标签: PHP

## 简介

symfony authorization bundle utilizing FOSUserBundle, JWT, and necessary tools for a JWT Based Rest Environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
