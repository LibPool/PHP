# aniruddh/phprouter

> 标签: PHP Route, fast php router, php router, php routing, phproute, phprouter, phprouting, router, routing, simple php router

## 简介

A simple, lightweight, and fast PHP router with supported middleware and trailing slash or non-trailing slash mode.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
