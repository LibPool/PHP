# josbeir/cakephp-json-api

> 标签: cakephp, json, jsonapi

## 简介

json-api specification plugin for CakePHP - http://jsonapi.org/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
