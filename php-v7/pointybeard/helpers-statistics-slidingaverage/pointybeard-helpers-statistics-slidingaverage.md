# pointybeard/helpers-statistics-slidingaverage

> 标签: PHP

## 简介

Ring buffer for calculating average of a changing set; helps to reduce jitter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
