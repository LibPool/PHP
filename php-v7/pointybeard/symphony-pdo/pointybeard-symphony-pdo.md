# pointybeard/symphony-pdo

> 标签: database, pdo, symphony, wrapper

## 简介

Wraps the core Symphony CMS database connection with a PDO based library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
