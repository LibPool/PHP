# pointybeard/kickstarter-export-parser

> 标签: archive, import, kickstarter, parser

## 简介

A PHP library for opening and parsing backer exports from Kickstarter campaigns.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
