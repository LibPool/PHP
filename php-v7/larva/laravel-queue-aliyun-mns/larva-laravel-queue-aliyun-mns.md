# larva/laravel-queue-aliyun-mns

> 标签: aliyun, mns, queue

## 简介

This is a Laravel queue adapter for the Aliyun MNS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
