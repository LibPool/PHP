# larva/laravel-queue-tencent-cloud-cmq

> 标签: cmq, laravel, queue, tencnet

## 简介

This is a Laravel queue adapter for the Tencnet Cloud CMQ.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
