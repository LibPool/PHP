# osotov/bitrix-module-installer-plugin

> 标签: PHP

## 简介

Bitrix modules installation plugin. Plugin adds modules to /local/modules/{$name} location

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
