# wujunzhong/rap-to-postman

> 标签: Postman, rap, rap-to-postman, rappostman

## 简介

Convert the json exported by RAP into the json format imported by Postman

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
