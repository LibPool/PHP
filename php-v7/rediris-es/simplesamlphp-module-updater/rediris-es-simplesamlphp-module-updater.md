# rediris-es/simplesamlphp-module-updater

> 标签: RedIRIS, SIR, idp, simplesamlphp, updater

## 简介

A module to backup and update SimpleSAMLphp installations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
