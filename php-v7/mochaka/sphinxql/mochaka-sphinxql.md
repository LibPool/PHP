# mochaka/sphinxql

> 标签: Sphinx RT, laravel, laravel5, search, sphinxql

## 简介

Integrate SphinxQL with Laravel 5. Simplifies Laravel-Sphinx(RT) search

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
