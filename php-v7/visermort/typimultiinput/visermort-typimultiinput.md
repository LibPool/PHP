# visermort/typimultiinput

> 标签: Typi, cms, extension, laravel, multiinput, multilingual

## 简介

Extension for TypiCMS. For making multi value fields.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
