# adt/single-recipient-mailer

> 标签: PHP

## 简介

Component modifies `Nette\Mail\Message` to send all the emails to one address. Sutaible for non production environments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
