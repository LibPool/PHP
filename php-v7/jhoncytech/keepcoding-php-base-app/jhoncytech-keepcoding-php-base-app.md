# jhoncytech/keepcoding-php-base-app

> 标签: bootcamp, devops, keepcoding

## 简介

Aplicación base para pruebas en módulos de Keepcoding Academy

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
