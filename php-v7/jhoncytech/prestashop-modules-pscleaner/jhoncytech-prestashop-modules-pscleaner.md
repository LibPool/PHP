# jhoncytech/prestashop-modules-pscleaner

> 标签: PHP

## 简介

Prestashop module for help you to remove testing data from your prestashop online store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
