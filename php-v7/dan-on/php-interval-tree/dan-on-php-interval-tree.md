# dan-on/php-interval-tree

> 标签: PHP

## 简介

Is an implementation of interval binary search tree according to Thomas Cormen book "Introduction to Algorithms".

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
