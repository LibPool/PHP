# tvaliasek/tnt-czech-stemmer

> 标签: czech, stemmer, tntsearch

## 简介

Fork of x3wils port of stemmer for Czech language for use as stemmer for TNTSearch

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
