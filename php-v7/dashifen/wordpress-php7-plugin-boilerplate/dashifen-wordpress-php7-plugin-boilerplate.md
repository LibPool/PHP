# dashifen/wordpress-php7-plugin-boilerplate

> 标签: PHP

## 简介

An object-oriented boilerplate for WordPress templates using features of PHP 7.1.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
