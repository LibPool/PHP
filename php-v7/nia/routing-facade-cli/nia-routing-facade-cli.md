# nia/routing-facade-cli

> 标签: Simple, cli, facade, nia, request, response, router, routing, shell

## 简介

CLI routing facade to simply add CLI routes to a given router.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
