# comur/image-bundle

> 标签: Form Type, crop, image, jcrop, jquery upload, upload

## 简介

A bundle providing fields for image upload with jquery upload and image cropping with jcrop for symfony2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
