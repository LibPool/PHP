# postor/yii2-for-sae

> 标签: adapt, sae, saestorage, sinaapp, yii 2, yii2

## 简介

The adapt for Yii2 framework to run on sina app engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
