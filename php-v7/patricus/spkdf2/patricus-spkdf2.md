# patricus/spkdf2

> 标签: PHP

## 简介

A Creative Commons 0 library for PKDF2. pkdf2_encrypt(payload, pass, iterations=100000) and pkdf2_decrypt() work the same.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
