# bw/active-menu-item-bundle

> 标签: active, bw, highlight, item, menu

## 简介

The active menu item highlighting of simple HTML menu in Symfony applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
