# slashplus/identity

> 标签: Age verification, EAT, Personalausweis, Reisepass, age check, eAufenthaltstitel, id card check, passport check, residence permission check

## 简介

Verify the age of a person using the german id card, german passport or german residence permission (eAT).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
