# tuowt/cakephp3-soft-delete

> 标签: cakephp, cakephp 3, plugin, soft delete

## 简介

SoftDelete plugin for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
