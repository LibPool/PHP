# nfaiz/sqlhighlighter

> 标签: codeigniter, codeigniter4, database, debug, sql, syntax, toolbar

## 简介

CodeIgniter 4 SQL Highlighter using highlightjs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
