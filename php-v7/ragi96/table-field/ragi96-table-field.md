# ragi96/table-field

> 标签: kirby-table, kirby3, kirby3-cms, kirby3-plugin, table, table-field

## 简介

Table-Field is a kirby 3 field plugin to make nice extendable tables

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
