# towa/towa-gdpr-plugin

> 标签: plugin, towa-gdpr-plugin

## 简介

Towa Gdpr Plugin for a gdpr compatible cookie notice

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
