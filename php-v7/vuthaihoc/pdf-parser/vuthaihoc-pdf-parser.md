# vuthaihoc/pdf-parser

> 标签: parser, pdf, pdf-parser, pdftotext

## 简介

PHP library to parse text from PDF files, use symfony/process 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
