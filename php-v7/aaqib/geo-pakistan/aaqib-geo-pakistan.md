# aaqib/geo-pakistan

> 标签: PHP

## 简介

Provide Provinces, divisions, districts, Tehsils/Talukas and cities relations database for Pakistan.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
