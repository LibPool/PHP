# clank-ai/rtf-converter

> 标签: PHP

## 简介

A simple RTF to Plain Text Converter using regular expressions. Support for PHP, Python, Javascript and CSharp

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
