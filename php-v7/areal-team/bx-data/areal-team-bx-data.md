# areal-team/bx-data

> 标签: 1C-Bitrix, 1С-битрикс, akop, bitrix, classes, highload blocks, Битрикс

## 简介

Классы для удобного доступа к данным в 1C-Bitrix

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
