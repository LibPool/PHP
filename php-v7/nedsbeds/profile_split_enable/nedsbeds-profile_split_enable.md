# nedsbeds/profile_split_enable

> 标签: PHP

## 简介

Allows Drupal sites using multiple profiles, CMI and config split to have a config split defined for each profile

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
