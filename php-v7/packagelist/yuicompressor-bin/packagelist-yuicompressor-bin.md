# packagelist/yuicompressor-bin

> 标签: compressor, css, javascript, minification, yui

## 简介

YUI Compressor packaged for composer. JavaScript and CSS minification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
