# nzldev/domain-whois

> 标签: asn, dns, domain, info, lookup, parser, tld, whois

## 简介

This package contains a class that can fetch DNS records and whois info.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
