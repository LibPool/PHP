# abdoub/omnipay-skrill

> 标签: gateway, merchant, omnipay, pay, payment, skrill

## 简介

Skrill driver for the Omnipay (3.0.x-dev) payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
