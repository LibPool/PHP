# binarybuilds/laravel-mail-manager

> 标签: debugging, email, laravel, mail, monitoring

## 简介

A Laravel mail manager to record and re-send all outgoing emails.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
