# drewwaltonstech/valet-gentoo

> 标签: gentoo, laravel, linux, valet, wwdhhd, zonda

## 简介

A more enjoyable local development experience for Gentoo Linux.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
