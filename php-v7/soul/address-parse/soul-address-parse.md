# soul/address-parse

> 标签: address, parse

## 简介

收货地址解析，成功率99%以上，支持（身份证号，电话，座机，区号，省市区街道地址)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
