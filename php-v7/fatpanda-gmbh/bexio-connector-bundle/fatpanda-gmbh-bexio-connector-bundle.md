# fatpanda-gmbh/bexio-connector-bundle

> 标签: bexio, symfony

## 简介

This bundle wraps the fatpanda-gmbh/bexio-connector library for symfony apps

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
