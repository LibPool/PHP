# tonjoo/tiga-framework

> 标签: faux mvc, framework, mvc, tiga, wordpress

## 简介

Framework Component for Tiga - WordPress Faux MVC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
