# clue/socks

> 标签: async, react, socks client, socks protocol, socks server, tcp tunnel

## 简介

Async SOCKS proxy client and server (SOCKS4, SOCKS4a and SOCKS5)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
