# clue/icmp-react

> 标签: Socket, async, diagnose, echo request, icmp, network, ping, reactphp

## 简介

Simple async lowlevel ICMP (ping) messages for react

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
