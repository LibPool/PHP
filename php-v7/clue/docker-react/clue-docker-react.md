# clue/docker-react

> 标签: async, container, docker, reactphp

## 简介

Async, event-driven access to the Docker Engine API, built on top of ReactPHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
