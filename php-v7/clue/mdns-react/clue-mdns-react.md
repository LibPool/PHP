# clue/mdns-react

> 标签: Avahi, Bonjour, Multicast DNS, RFC 6762, async, mDNS, reactphp, zeroconf

## 简介

Multicast DNS (mDNS) resolver for zeroconf networking ala Bonjour/Avahi

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
