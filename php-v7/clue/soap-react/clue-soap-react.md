# clue/soap-react

> 标签: reactphp, soap, soapclient, webservice, wsdl

## 简介

Simple, async SOAP webservice client library, built on top of ReactPHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
