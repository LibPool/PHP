# clue/redis-protocol

> 标签: parser, protocol, redis, resp, serializer, streaming

## 简介

A streaming Redis protocol (RESP) parser and serializer written in pure PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
