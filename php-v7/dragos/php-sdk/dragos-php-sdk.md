# dragos/php-sdk

> 标签: exacttarget, fuel sdk, fuel-sdk, marketing cloud, php sdk, salesforce, sdk

## 简介

Salesforce Marketing Cloud Fuel SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
