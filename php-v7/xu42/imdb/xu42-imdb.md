# xu42/imdb

> 标签: imdb, xu42

## 简介

Crawl IMDb movie rating, content rating, release date, poster, presentation, director, actor, duration and other information

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
