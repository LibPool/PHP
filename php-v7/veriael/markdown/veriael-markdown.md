# veriael/markdown

> 标签: formatting

## 简介

More complete flarum-markdown fork. Includes missing BBCode shortcuts in addition to Markdown ones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
