# webignition/guzzle-request-headers-middleware

> 标签: Guzzle, headers, middleware, psr7

## 简介

Middleware for setting headers on all requests sent by a Guzzle 6 client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
