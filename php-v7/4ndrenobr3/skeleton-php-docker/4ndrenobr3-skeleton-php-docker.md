# 4ndrenobr3/skeleton-php-docker

> 标签: PHP

## 简介

Este é um esqueleto de aplicação PHP compatível com PSR, em um ambiente Docker. Ele segue uma arquitetura personalizada semelhante ao MVC.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
