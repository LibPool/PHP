# chenbool/jwt

> 标签: jwt, token

## 简介

一个简单的 PHP JSON Web Tokens (JWT) 加密/解密插件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/chenbool/jwt.git
- Packagist 页面：https://packagist.org/packages/chenbool%2Fjwt
