# web-tp3/tp3-feuser-register

> 标签: PHP

## 简介

A self-registration variant of Kasper Skårhøj's Front End User Admin extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
