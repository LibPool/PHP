# jixk/make-mscr

> 标签: PHP

## 简介

测试模块，请勿用于生产！！！MSCR脚手架，一键生成 Model、Service、Controller、Request类文件。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
