# sy-records/xhprof2flamegraph

> 标签: flamegraph, tideways, xhprof

## 简介

将xhprof产生的数据转为可以生成flamegraph火焰图的格式并生成火焰图

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
