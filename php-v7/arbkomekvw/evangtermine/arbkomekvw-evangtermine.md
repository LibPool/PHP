# arbkomekvw/evangtermine

> 标签: TYPO3 CMS, ekvw, evangtermine, front-end, termine

## 简介

Integrates the output of the "Evangelische Termine" web application into TYPO3 web sites

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
