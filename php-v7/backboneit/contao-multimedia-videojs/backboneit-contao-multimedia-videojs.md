# backboneit/contao-multimedia-videojs

> 标签: contao, multimedia, player, video

## 简介

VideoJS integration into backboneIT multimedia extension for Contao CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
