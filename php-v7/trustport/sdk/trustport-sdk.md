# trustport/sdk

> 标签: 2fa, MFA, auth, passkey, qr-login, trustport, webauthn

## 简介

Trustport — passkey-based phone verification. Server-side SDK for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
