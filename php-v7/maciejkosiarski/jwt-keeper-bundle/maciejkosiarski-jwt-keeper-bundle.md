# maciejkosiarski/jwt-keeper-bundle

> 标签: bundle, jwt, symfony

## 简介

Bundle to keep fresh and valid json web token in cache.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
