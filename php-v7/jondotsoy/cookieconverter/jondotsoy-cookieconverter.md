# jondotsoy/cookieconverter

> 标签: PHP

## 简介

Permite trabajar con cadenas de textos obtenidas en los headers http y capturar los valores de las cookies o viceversa crear una cadena http con las cookies a partir de valores.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
