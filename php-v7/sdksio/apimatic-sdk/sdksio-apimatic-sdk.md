# sdksio/apimatic-sdk

> 标签: PHP

## 简介

Use APIMatic API to generate SDKs in Python, Typescript, PHP, Ruby, and GO. You can generate On-Prem portal and many more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
