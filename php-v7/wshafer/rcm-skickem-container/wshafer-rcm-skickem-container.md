# wshafer/rcm-skickem-container

> 标签: content, manager, plugin, rcm, reliv

## 简介

A Reliv Content Manager Plugin for adding an HTML area containing a sticky responsive side menu

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
