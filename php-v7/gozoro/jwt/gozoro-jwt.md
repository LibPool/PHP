# gozoro/jwt

> 标签: RFC7519, jsonwebtoken, jwt

## 简介

A simple PHP class to encode and decode JSON Web Tokens (JWT), conforming to RFC 7519.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
