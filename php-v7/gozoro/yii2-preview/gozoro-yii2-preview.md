# gozoro/yii2-preview

> 标签: crop, cropping, image, preview, resize, resizing, yii2

## 简介

Yii2 component for resizing, cropping and creating preview image and saving to cache folder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
