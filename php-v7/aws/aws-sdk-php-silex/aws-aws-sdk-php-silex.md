# aws/aws-sdk-php-silex

> 标签: amazon, aws, dynamodb, ec2, s3, sdk, silex

## 简介

A simple Silex service provider for including the AWS SDK for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
