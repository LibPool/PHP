# aws/aws-sdk-php-laravel5

> 标签: Laravel 4, amazon, aws, dynamodb, ec2, laravel, s3, sdk

## 简介

A simple Laravel 4 service provider for including the AWS SDK for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
