# shipmonk/phpstan-dev

> 标签: PHPStan, static analysis, testing

## 简介

Development utilities for PHPStan rules testing, extracted from shipmonk/phpstan-rules

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
