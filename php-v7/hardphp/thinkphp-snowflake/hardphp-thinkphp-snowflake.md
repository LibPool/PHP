# hardphp/thinkphp-snowflake

> 标签: PHP

## 简介

thinkphp6.0 snowflake,使用snowflake算法生成全局唯一且趋势递增的ID

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
