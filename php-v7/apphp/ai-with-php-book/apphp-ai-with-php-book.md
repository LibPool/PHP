# apphp/ai-with-php-book

> 标签: PHP

## 简介

This book will try to explain the basics of Artificial Intelligence and Machine Learning in a way that’s easy to understand.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
