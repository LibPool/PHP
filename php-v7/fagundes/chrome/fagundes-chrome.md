# fagundes/chrome

> 标签: browser, chrome, chromium, crawl, headless, pdf, screenshot

## 简介

Instrument headless chrome/chromium instances from php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
