# linkorb/flow

> 标签: EventSourcing, EventStore, cqrs, flow, linkorb, projector, state, stream

## 简介

Flow: ultra light-weight eventsourcing, state management and projection library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
