# linkorb/filespace

> 标签: GridFS, cloud storage, filespace, mongodb, namespace, objectstorage, s3, storage

## 简介

Flexible storage solution for end-user data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
