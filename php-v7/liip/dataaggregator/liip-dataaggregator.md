# liip/dataaggregator

> 标签: data aggregation, data filtering, liip

## 简介

The data aggregator cumulates information provided by a loader and routes them to a persistence layer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
