# konekt/serpa-sync-bundle

> 标签: ERP, serpa, sylius

## 简介

Bundle for managing synchronization of Serpa data with Sylius Sync Bundle

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
