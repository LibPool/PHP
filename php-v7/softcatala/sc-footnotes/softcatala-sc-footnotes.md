# softcatala/sc-footnotes

> 标签: PHP

## 简介

Elegant and easy to use footnotes for WordPress. Based on John Watson fd-footnotes plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
