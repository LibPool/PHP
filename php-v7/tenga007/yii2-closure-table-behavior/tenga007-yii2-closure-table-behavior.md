# tenga007/yii2-closure-table-behavior

> 标签: Behavior, closure table, extension, yii2

## 简介

This extension allows you to get functional for closure table trees.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
