# yidas/socket-mailer

> 标签: Socket, fsockopen, mailer, php, smtp

## 简介

PHP SMTP Mailer library using fsockopen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
