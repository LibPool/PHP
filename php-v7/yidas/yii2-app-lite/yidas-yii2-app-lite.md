# yidas/yii2-app-lite

> 标签: bower, framework, lite, project template, yii2

## 简介

Yii 2 Lite Application Template with Bower vendor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
