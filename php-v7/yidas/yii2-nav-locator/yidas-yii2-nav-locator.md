# yidas/yii2-nav-locator

> 标签: extension, helper, locator, navigation, yii, yii2

## 简介

Yii 2 Navigation Routing Locator for active menu identification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
