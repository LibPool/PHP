# yidas/codeigniter-model

> 标签: MY_Model, base model, codeigniter, model

## 简介

CodeIgniter 3 ORM Base Model pattern with My_model example

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
