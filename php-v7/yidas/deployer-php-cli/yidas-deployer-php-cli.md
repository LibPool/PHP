# yidas/deployer-php-cli

> 标签: continuous-integration, deployment, php-cli, rsync

## 简介

Code deployment tool based on RSYNC running by PHP-CLI script

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
