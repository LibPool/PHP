# wolfsoft/botguard-php

> 标签: api, botguard

## 简介

PHP Integration Library for BotGuard web site protection service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://botguard.net/en/documentation/integration
- 源码仓库：https://github.com/wolfsoft/botguard-php.git
- Packagist 页面：https://packagist.org/packages/wolfsoft%2Fbotguard-php
