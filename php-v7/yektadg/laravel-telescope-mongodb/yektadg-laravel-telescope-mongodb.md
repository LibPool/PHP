# yektadg/laravel-telescope-mongodb

> 标签: debugging, laravel, monitoring

## 简介

An elegant debug assistant for the Laravel framework compatible with mongodb.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
