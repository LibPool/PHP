# morphatic/laravel-auto-deploy

> 标签: deploy, git, laravel, push-to-deploy

## 简介

Add push-to-deploy capability to your Laravel project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
