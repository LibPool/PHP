# riskivy/yii2-geoip

> 标签: geoip, geolocation, maxmind, yii2

## 简介

Yii 2 GeoIP extension. Returns country, city, lat, lng of current or specified IP (uses MaxMind's GeoIP2 databases)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
