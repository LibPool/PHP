# badtudou/me-card

> 标签: PHP

## 简介

MeCard is a data file similar to vCard but used by NTT DoCoMo in Japan in QR code format for use with Cellular Phones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
