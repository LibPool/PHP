# taggrs/magento2-data-layer

> 标签: PHP

## 简介

This extension collect eccommerce data from Magento 2 and pushes it to the Google Tag Manager DataLayer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
