# sellerlabs/consul-php-sdk

> 标签: PHP

## 简介

SDK to talk with consul.io API. Forked from sensiolabs/consul-php-sdk to provide Guzzle 6.0 compatibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
