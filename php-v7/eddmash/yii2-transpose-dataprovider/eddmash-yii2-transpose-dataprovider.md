# eddmash/yii2-transpose-dataprovider

> 标签: dataprovider, eav, extension, transpose, yii2

## 简介

A Yii2 data provider that transpose data into a table format

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
