# shengya/kingdee

> 标签: ERP, K3cloud, kingdee, laravel, webapi

## 简介

Kingdee K3Cloud WebAPI SDK with Laravel integration, call recording and base-data synchronization.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
