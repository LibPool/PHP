# wkwkrnht/2017-by-wkwkrnht

> 标签: PHP

## 简介

The theme for Wordpress which has 1-colum and user can open menu and share-menu on anywhere

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
