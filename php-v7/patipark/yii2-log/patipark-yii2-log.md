# patipark/yii2-log

> 标签: PHP

## 简介

ใช้ในการเก็บ Log ของ Active Record Model  โดยเก็บทุกฟิวด์ของตาราง ก่อน/หลัง การแก้ไข ไว้ในตารางในรูปแบบ JSON

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
