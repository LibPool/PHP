# ngdot/contao-changenewsmore

> 标签: contao, news

## 简介

This extension makes it possible to replace 'Read more ...' with an individual text. Works for all forwarding destinations!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
