# bhexpress/bhexpress-api-client

> 标签: bhe, bhexpress, boletas de honorarios electrónicas, sii

## 简介

Cliente para realizar la integración con los servicios web de BHExpress desde PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
