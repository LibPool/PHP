# schnitzler/fluid-styled-responsive-images

> 标签: fluid, images, responsive, typo3

## 简介

Enables creation of responsive images for fluid styled content elements.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
