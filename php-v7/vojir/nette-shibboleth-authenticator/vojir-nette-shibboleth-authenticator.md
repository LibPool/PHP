# vojir/nette-shibboleth-authenticator

> 标签: Authentication, nette, shibboleth

## 简介

Simple extension for Shibboleth authentication in Nette projects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
