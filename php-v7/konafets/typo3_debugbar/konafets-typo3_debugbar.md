# konafets/typo3_debugbar

> 标签: cms, debugbar, debugging, php, typo3

## 简介

Utilizes the PHP Debugbar to provide information of the system health to the frontend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
