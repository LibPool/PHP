# bernardosilva/git-hooks-php

> 标签: checkstyle, git, hooks, php-cs-fixer, pre-commit

## 简介

Composer git-hook package with hooks for your php projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
