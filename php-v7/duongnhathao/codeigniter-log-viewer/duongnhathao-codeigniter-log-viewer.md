# duongnhathao/codeigniter-log-viewer

> 标签: Code Igniter, log viewer, php

## 简介

This is a simple Log Viewer for viewing Code Igniter log files on the browser

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
