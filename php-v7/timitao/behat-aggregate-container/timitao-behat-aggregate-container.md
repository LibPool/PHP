# timitao/behat-aggregate-container

> 标签: Behat, extension, terminal, test

## 简介

Aggregate of few containers implementing Psr\Container\ContainerInterface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
