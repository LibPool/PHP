# clowdy/vimeo-api

> 标签: clowdy, video, videos, vimeo

## 简介

Composer wrapper for Vimeo PHP library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/clowdy/vimeo.php
- 源码仓库：https://github.com/clowdy/vimeo.php.git
- Packagist 页面：https://packagist.org/packages/clowdy%2Fvimeo-api
