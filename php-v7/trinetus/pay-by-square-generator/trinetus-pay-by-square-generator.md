# trinetus/pay-by-square-generator

> 标签: generator, pay by square, qrcode, slovak

## 简介

PHP implementation of Pay By Square generator based on code of Jan Fecik.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
