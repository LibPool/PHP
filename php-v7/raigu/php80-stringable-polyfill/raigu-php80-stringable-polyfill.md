# raigu/php80-stringable-polyfill

> 标签: compatibility, polyfill, portable, stringable

## 简介

Polyfill to backport PHP8.0 Stringable feature to lower PHP versions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
