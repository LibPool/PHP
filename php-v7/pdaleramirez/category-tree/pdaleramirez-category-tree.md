# pdaleramirez/category-tree

> 标签: Craft, category tree, cms, craft-plugin, craftcms

## 简介

Builds a category tree structure for your menu and links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
