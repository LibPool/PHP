# codigosecafe/grifo-hash

> 标签: GrifoHash, MD5, codigosecafe, password

## 简介

Grifo é uma classe PHP para gerar hashing de senha e validação.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
