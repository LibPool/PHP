# codigosecafe/str-utf8

> 标签: PHP

## 简介

Classe responsável por converter Windows-1252 e ISO-8859-1 para UTF-8. Alem de auxiliar com alguns metodos

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
