# capslock-studio/node-deploy-server-php-pusher

> 标签: PHP

## 简介

Lightweight cross platform self-hosted deployment server solution client in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
