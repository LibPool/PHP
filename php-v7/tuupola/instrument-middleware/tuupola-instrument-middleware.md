# tuupola/instrument-middleware

> 标签: Metrics, influxdb, instrument, middleware, psr-7

## 简介

PSR-7 Middleware for instrumenting PHP applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
