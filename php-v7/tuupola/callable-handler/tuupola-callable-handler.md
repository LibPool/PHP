# tuupola/callable-handler

> 标签: middleware, psr-15, psr-7

## 简介

Compatibility layer for PSR-7 double pass and PSR-15 middlewares.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
