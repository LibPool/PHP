# axazara/php-cs

> 标签: code-style, php, php-cs-fixer

## 简介

Axa Zara PHP Code style configuration for `php-cs-fixer` based on PSR-12.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
