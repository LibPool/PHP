# ossinkine/swiftmailer-punycode-plugin

> 标签: punycode, swiftmailer, swiftmailer-plugin

## 简介

Swiftmailer plugin to convert domain in email addresses to punycode

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
