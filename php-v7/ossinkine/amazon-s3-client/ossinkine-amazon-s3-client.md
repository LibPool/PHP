# ossinkine/amazon-s3-client

> 标签: amazon, amazon web services, aws, s3, simple storage service

## 简介

Browser client for Amazon S3 (Simple Storage Service)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
