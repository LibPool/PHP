# iblues/annotation-test-unit

> 标签: PHP

## 简介

Laravel ATU Base on annotation's and laravel phpunit.一个基于注解和laravel单元测试的 自动化测试包

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
