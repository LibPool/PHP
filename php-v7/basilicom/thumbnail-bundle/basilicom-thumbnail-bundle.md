# basilicom/thumbnail-bundle

> 标签: async, pimcore, thumbnail

## 简介

This Bundle provides asynchronous thumbnail creation for Pimcore.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
