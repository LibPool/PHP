# gregorybiter/ocm-cli

> 标签: artisan, cli, developer-tools, module-manager, ocm, ocmod, opencart

## 简介

Autonomous Artisan-like developer toolkit & CLI for OpenCart modules and extensions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
