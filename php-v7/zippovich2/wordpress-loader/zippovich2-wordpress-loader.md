# zippovich2/wordpress-loader

> 标签: .env, constants, env, environment, loader, variables, wordpress, wrapper

## 简介

Loading constants and environment variables from .env files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
