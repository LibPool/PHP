# aivec/wcex-cptm-cli

> 标签: PHP

## 简介

CLI for deploying new ZIP files and updating information on a server hosting the WCEX Commercial Plugin/Theme Manager plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
