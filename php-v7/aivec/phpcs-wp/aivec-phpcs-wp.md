# aivec/phpcs-wp

> 标签: PHP

## 简介

Aivec coding standards for vanilla PHP and WordPress PHP libraries/projects/plugins/themes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
