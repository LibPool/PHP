# italia/spid-symfony-bundle

> 标签: SPiD, idp, oauth, sp, ws-federation

## 简介

A Bundle to make Symfony3 capable of using SPID authentication, based on italia/spid-php-lib

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
