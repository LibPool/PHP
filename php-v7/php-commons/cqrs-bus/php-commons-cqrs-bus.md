# php-commons/cqrs-bus

> 标签: PHP

## 简介

CQRS Bus is Symfony 4.3+ Bundle with Command Bus & QueryBus using Symfony Messanger

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
