# linkshare/oauth2-linkshare

> 标签: authorisation, authorization, client, oauth, oauth2

## 简介

OAuth provider for connecting to LinkShare's developer APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
