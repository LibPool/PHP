# hiqdev/omnipay-interkassa

> 标签: Interkassa, merchant, omnipay, payment, php

## 简介

InterKassa driver for the Omnipay PHP payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
