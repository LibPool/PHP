# hiqdev/omnipay-ecoin

> 标签: ecoin, merchant, omnipay, payment, php

## 简介

eCoin driver for Omnipay PHP payment library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
