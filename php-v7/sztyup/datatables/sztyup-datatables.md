# sztyup/datatables

> 标签: data-table, datagrid, datatable, datatables, grid, pagination, table

## 简介

Datatables serverside and html generator for LaravelDoctrine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
