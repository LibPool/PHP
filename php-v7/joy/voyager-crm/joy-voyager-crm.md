# joy/voyager-crm

> 标签: cms, joy, joy-voyager-crm, laravel, voyager, voyager-crm, voyager-voyager-crm

## 简介

This Laravel/Voyager module adds VoyagerCrm support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
