# joy/voyager-export

> 标签: cms, joy, joy-voyager-export, laravel, voyager, voyager-export, voyager-voyager-export

## 简介

This Laravel/Voyager module adds VoyagerExport support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
