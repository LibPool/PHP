# joy/voyager-dashboard

> 标签: cms, joy, joy-voyager-dashboard, laravel, voyager, voyager-dashboard, voyager-voyager-dashboard

## 简介

This Laravel/Voyager module adds VoyagerDashboard support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
