# joy/voyager-core

> 标签: cms, joy, joy-voyager-core, laravel, voyager, voyager-core, voyager-voyager-core

## 简介

This Laravel/Voyager module adds VoyagerCore support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
