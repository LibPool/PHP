# joy/voyager-bread-notification

> 标签: bread-notification, cms, joy, joy-voyager-bread-notification, laravel, voyager, voyager-bread-notification

## 简介

This Laravel/Voyager module adds VoyagerBreadNotification support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
