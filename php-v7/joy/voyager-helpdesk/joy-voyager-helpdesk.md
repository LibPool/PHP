# joy/voyager-helpdesk

> 标签: cms, joy, joy-voyager-helpdesk, laravel, voyager, voyager-helpdesk, voyager-voyager-helpdesk

## 简介

This Laravel/Voyager module adds VoyagerHelpdesk support to Voyager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
