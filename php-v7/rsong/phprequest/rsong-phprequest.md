# rsong/phprequest

> 标签: Socket, curl, http, php, php http client, request

## 简介

A light weight PHP http client implements PSR7, use socket/curl for sending requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
