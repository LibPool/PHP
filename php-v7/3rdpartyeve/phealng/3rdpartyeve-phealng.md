# 3rdpartyeve/phealng

> 标签: EVE API, EVE Online, Pheal, PhealNG

## 简介

PHP Eve Api Library, a simple PHP lib to access the EVE Online API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
