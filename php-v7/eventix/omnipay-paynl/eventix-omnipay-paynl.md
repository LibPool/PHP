# eventix/omnipay-paynl

> 标签: eventix, gateway, merchant, omnipay, pay, pay.nl, payment, paynl

## 简介

Pay.nl driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
