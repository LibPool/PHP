# jakeroid/yii2-liqugallery-widget

> 标签: gallery, widget, yii2

## 简介

Simple gallery widget with AJAX upload and main image option

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
