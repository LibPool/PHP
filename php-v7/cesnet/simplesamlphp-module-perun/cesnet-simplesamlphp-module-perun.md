# cesnet/simplesamlphp-module-perun

> 标签: perun, simplesamlphp

## 简介

Module which allows SSP to communicate with Perun IAM https://perun.cesnet.cz

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
