# cesnet/simplesamlphp-module-perunauthorize

> 标签: authorize, perun, simplesamlphp

## 简介

A SimpleSAMLPHP module for authorize working with module Perun

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
