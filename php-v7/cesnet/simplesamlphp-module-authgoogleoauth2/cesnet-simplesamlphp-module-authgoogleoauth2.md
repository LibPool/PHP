# cesnet/simplesamlphp-module-authgoogleoauth2

> 标签: google, oauth2, simplesamlphp

## 简介

A SimpleSAMLPHP module which allows authentication against Google OAuth2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
