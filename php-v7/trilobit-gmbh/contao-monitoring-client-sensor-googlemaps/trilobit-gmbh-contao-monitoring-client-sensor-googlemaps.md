# trilobit-gmbh/contao-monitoring-client-sensor-googlemaps

> 标签: contao, dlh_googlemaps, monitoring

## 简介

Provides a sensor for the MonitoringClient, which reads the Google-Maps data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
