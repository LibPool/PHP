# trilobit-gmbh/contao-monitoring-scan-client-worker-update-googlemaps-installed

> 标签: contao, dlh_googlemaps, monitoring

## 简介

Provides a component to update the system of a monitored entry with the scanned googlemaps data from the client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
