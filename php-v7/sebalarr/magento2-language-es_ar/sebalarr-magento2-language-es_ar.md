# sebalarr/magento2-language-es_ar

> 标签: PHP

## 简介

Magento 2 Spanish (Argentina) language package - Paquete de idioma Español (Argentina) para Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
