# sabre/amf

> 标签: AMF0, AMF3, ActionScript, Remoting, amf, flash

## 简介

SabreAMF is a Flash Remoting server and client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
