# ruudk/campfire-exception-bundle

> 标签: Symfony2, campfire, exception, log

## 简介

A Symfony2 Bundle that logs exceptions to a Campfire chat room

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
