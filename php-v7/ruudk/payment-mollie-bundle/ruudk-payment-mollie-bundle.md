# ruudk/payment-mollie-bundle

> 标签: mollie, payment

## 简介

A Symfony2 Bundle that provides access to the Mollie API. Based on JMSPaymentCoreBundle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
