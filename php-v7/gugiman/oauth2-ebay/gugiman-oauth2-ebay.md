# gugiman/oauth2-ebay

> 标签: Authentication, api, authorization, client, ebay, oauth, oauth2, php

## 简介

Ebay OAuth 2.0 support for the PHP League's OAuth 2.0 Client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
