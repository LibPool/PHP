# entidi/silverstripe-autotoc

> 标签: TOC, autotoc, contents, index, silverstripe, table of contents

## 简介

Dynamically generate the table of contents from $Content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
