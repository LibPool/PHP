# entidi/silverstrap

> 标签: bootstrap, module, silverstrap, silverstripe, theme

## 简介

A Silverstripe theme based on Bootstrap front end framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
