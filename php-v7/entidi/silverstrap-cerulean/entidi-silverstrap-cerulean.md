# entidi/silverstrap-cerulean

> 标签: bootstrap, cerulean, silverstrap, silverstripe

## 简介

Silverstrap customization that uses the Cerulean theme from bootswatch.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
