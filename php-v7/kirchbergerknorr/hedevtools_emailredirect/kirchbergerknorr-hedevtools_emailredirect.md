# kirchbergerknorr/hedevtools_emailredirect

> 标签: PHP

## 简介

Email Redirect allows a developer to redirect all email from a Magento store to a specific address.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
