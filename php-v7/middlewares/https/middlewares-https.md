# middlewares/https

> 标签: Strict-Transport-Security, http, https, middleware, psr-15, psr-7

## 简介

Middleware to redirect to https and adds the Strict-Transport-Security header

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
