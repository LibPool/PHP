# middlewares/base-path-router

> 标签: http, middleware, psr-15, psr-7, routing, server

## 简介

A PSR-15 middleware for hierarchical dispatching based on path prefixes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
