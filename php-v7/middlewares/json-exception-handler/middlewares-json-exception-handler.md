# middlewares/json-exception-handler

> 标签: exception, handler, http, json, middleware, psr-15, psr-7, server

## 简介

Middleware to catch exceptions and output them as JSON

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
