# middlewares/debugbar

> 标签: debugbar, http, middleware, psr-15, psr-7, server

## 简介

Middleware to insert PHP DebugBar automatically in html responses

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
