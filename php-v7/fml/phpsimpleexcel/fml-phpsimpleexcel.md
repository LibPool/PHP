# fml/phpsimpleexcel

> 标签: excel, fml, funkymonkeylabs, xls

## 简介

PHPSimpleExcel is a library basing on oliverschwarz/php-excel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
