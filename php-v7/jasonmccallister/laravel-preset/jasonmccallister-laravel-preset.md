# jasonmccallister/laravel-preset

> 标签: PHP

## 简介

Presets for Laravel applications with Docker, PHPCS, PHPUnit, and etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
