# minerva-framework/minerva-web-token

> 标签: PHP

## 简介

Biblioteca desenvolvida para fornecer uma base a autenticação multi-fator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
