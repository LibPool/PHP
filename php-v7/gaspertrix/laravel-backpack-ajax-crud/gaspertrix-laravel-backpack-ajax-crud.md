# gaspertrix/laravel-backpack-ajax-crud

> 标签: ajax, backpack, crud, fly, gaspertrix, laravel

## 简介

Add AJAX CRUD and items on the fly support for Laravel Backpack

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
