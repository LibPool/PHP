# cashoutguard/cashoutguard-php

> 标签: cashout, cashoutguard, device-fingerprint, fraud, fraud-prevention, gpt, offerwall, rewards

## 简介

PHP client for the CashoutGuard fraud-prevention API (rewards, GPT and offerwall sites).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
