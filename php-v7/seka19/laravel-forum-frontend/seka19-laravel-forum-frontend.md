# seka19/laravel-forum-frontend

> 标签: discuss, forum, frontend, laravel, laravel-8

## 简介

A frontend for riari/laravel-forum providing views written with Bootstrap 3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
