# capham/user-module

> 标签: Authentication, asgardcms, authorisation, user

## 简介

User module for AsgardCMS. Handles the authentication and authorisation as well as the user management.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
