# graphql-by-pop/graphql-voyager

> 标签: Gato, GatoGraphQL, api, graphiql, graphql, php

## 简介

GraphQL Voyager client for GraphQL by PoP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
