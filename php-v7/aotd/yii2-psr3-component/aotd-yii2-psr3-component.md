# aotd/yii2-psr3-component

> 标签: log, logger, psr-3, yii2

## 简介

Allows you to use the Yii2 logger with libraries that are expecting a PSR-3 compatible logger

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
