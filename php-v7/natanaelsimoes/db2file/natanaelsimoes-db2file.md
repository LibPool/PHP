# natanaelsimoes/db2file

> 标签: conversion, converter, database, json, xml

## 简介

Retrieve data from database and generate/print JSON or XML file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
