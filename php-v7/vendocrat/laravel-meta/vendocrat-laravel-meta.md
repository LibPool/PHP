# vendocrat/laravel-meta

> 标签: eloquent, laravel, meta, meta data, metable, model

## 简介

Simple and fluent meta data for Eloquent Models in Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
