# wondeotec/emailbidding-sdk

> 标签: api, emailbidding, php, sdk

## 简介

Collection of scripts to allow interactions with Emailbidding API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
