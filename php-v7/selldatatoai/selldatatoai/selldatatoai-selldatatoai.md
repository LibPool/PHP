# selldatatoai/selldatatoai

> 标签: ai data broker, ai data value score, ai training data, company data api, firmographics, lead scoring, sell data to ai, technographics

## 简介

PHP client for the AI Data Value Score API from selldatatoai.com: score company domains 0 to 100 for the data AI buyers want, singly or in batches of 100.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
