# chibex/ozioma-php

> 标签: api, birthday, birthday contact, birthday message, birthday sms, bulk sms, chibex, contact, message, messaging, newsletter, ozioma, ozioma-php, sms, sms newsletter, subscriber

## 简介

Ozioma for PHP library helps to make API calls to Ozioma Cloud Messaging and Communications Platform for birthday contact and sms newsletter subscription.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
