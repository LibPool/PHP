# struzik-vladislav/epp-client

> 标签: domains, epp, registrar, registry

## 简介

PHP library for communicating with EPP(Extensible Provisioning Protocol) servers

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
