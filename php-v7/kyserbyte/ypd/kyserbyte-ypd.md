# kyserbyte/ypd

> 标签: annotation, decorator, meta-programming, php

## 简介

Ypd Php Decorator implements "decorators/annotations and meta-programming" in PHP, via doc comments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
