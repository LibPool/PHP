# alves/sped-pos

> 标签: nfce, nfe, nfephp, sped

## 简介

Biblioteca para impressão da DANFCe em impressoras térmicas compatíveis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
