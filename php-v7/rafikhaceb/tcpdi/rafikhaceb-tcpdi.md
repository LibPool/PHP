# rafikhaceb/tcpdi

> 标签: TCPDF, pdf, tcpdi, tcpdi_parser

## 简介

TCPDI is a PHP class for importing PDF to use with TCPDF

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
