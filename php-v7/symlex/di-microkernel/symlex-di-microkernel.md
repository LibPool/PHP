# symlex/di-microkernel

> 标签: Agile, bootstrapping, dependency injection, kernel, lean, micro-framework, performance, symfony

## 简介

Micro-Kernel for PHP Applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
