# cypresslab/angular-ng-routing-bundle

> 标签: Js Routing, angular.js, javascript, routing

## 简介

A way to expose your Symfony2 routing to Angular $resource service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
