# etrepat/laravel-compleet

> 标签: autocomplete, laravel, redis, search

## 简介

Laravel integration for Compleet: A Redis-backed service for fast autocompleting

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
