# brighttalk/acs-query-builder

> 标签: PHP

## 简介

Provides an object oriented way to programmatically build queries for the Amazon Cloud Search service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
