# regionhalland/region-halland-plugin-wp-remove-dashboard-meta

> 标签: PHP

## 简介

Denna plugin tar bort alla meta-boxar från dashboard utom 'aktivitet'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
