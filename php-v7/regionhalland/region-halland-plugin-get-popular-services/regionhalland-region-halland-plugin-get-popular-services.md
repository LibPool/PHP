# regionhalland/region-halland-plugin-get-popular-services

> 标签: PHP

## 简介

Front-end-plugin som returnerar de mest använda tjänsterna från vår e-tjänsteportal

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
