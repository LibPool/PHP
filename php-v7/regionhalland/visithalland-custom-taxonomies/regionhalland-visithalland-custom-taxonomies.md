# regionhalland/visithalland-custom-taxonomies

> 标签: PHP

## 简介

Wordpress plugin for adding custom taxonomies used on https://www.visithalland.com.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
