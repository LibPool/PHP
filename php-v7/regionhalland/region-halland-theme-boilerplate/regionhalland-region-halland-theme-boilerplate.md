# regionhalland/region-halland-theme-boilerplate

> 标签: wordpress

## 简介

Region Hallands starttema. Använd detta tema som en grund för utveckling av nya teman

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
