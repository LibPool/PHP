# regionhalland/region-halland-plugin-news-archive-taxonomi-category

> 标签: PHP

## 简介

Skapa posttyp news inkl. taxonomi och använder archive.php för att visa nyheterna

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
