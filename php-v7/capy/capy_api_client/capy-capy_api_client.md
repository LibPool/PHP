# capy/capy_api_client

> 标签: PHP

## 简介

Capy PHP HTTP client library makes verify puzzle/avatar and evaluate blacklist/riskbase for capy's services become easier

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
