# waughj/wp-scripts

> 标签: plugin, scripts, stylesheets, wordpress

## 简介

WordPress component for easily adding CSS stylesheets & JavaScript files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
