# aait/php-name-parser

> 标签: PHP

## 简介

PHP library to split names into their respective components (first, last, etc). Fork of joshfraser/PHP-Name-Parser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
