# sachoo/cassandra-stubs

> 标签: cassandra, database, datastax, driver, nosql, stubs

## 简介

PHP stubs for the php cassandra extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
