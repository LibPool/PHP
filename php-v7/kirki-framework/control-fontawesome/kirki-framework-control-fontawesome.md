# kirki-framework/control-fontawesome

> 标签: customizer, framework, wordpress

## 简介

Font-Awesome field for the Kirki Customizer framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
