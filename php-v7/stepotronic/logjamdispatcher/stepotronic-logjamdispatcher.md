# stepotronic/logjamdispatcher

> 标签: logjam, php, zeromq

## 简介

Basic client to dispatch log messages to logjam using ZeroMQ.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
