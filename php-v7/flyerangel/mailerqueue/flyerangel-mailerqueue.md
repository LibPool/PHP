# flyerangel/mailerqueue

> 标签: async, mailer, redis, yii2

## 简介

The Async mailer for the Yii framework 2.0,which is optimised from doctorjason version.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
