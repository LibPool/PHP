# sentrasoft/laravel-indonesia

> 标签: desa, indonesia, kabupaten, kecamatan, kelurahan, kota, laravel, provinsi, sentrasoft

## 简介

Berisi data Provinsi, Kabupaten/Kota, Kecamatan, dan Keluarahan/Desa di seluruh Indonesia

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
