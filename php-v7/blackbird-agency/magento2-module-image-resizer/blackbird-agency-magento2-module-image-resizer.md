# blackbird-agency/magento2-module-image-resizer

> 标签: PHP

## 简介

Magento 2 Module to add simple image resizing capabilities in all blocks and .phtml templates

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
