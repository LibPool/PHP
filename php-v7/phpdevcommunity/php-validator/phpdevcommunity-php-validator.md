# phpdevcommunity/php-validator

> 标签: PHP

## 简介

PHP Validator is a fast, extensible, and simple PHP validation library that allows you to easily validate various types of data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
