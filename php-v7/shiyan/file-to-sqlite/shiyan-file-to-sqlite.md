# shiyan/file-to-sqlite

> 标签: OOP, console, file, php, regex, sqlite

## 简介

Copies data from a file to an SQLite database using regular expressions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
