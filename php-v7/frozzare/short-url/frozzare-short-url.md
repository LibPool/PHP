# frozzare/short-url

> 标签: address, permalink, plugin, short, url, wordpress

## 简介

Short url field for WordPress. Like Simple Address in EPiServer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
