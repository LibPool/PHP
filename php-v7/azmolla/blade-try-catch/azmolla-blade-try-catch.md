# azmolla/blade-try-catch

> 标签: blade, error-handling, laravel, try-catch

## 简介

Blade directives for try-catch-finally blocks in Laravel Blade templates

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
