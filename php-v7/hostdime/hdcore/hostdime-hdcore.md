# hostdime/hdcore

> 标签: PHP

## 简介

A wrapper around the HostDime API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://api.hostdime.com/
- 源码仓库：https://github.com/hostdime/hdcore-php.git
- Packagist 页面：https://packagist.org/packages/hostdime%2Fhdcore
