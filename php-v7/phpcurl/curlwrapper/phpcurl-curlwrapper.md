# phpcurl/curlwrapper

> 标签: OOP, Phpcurl, curl, curl_multi, curl_share, dependency, injection, mock, phpunit, testable, testing, wrapper

## 简介

The simplest OOP wrapper for curl, curl_multi, curl_share functions. Use CURL as a dependency, not hard-coded!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
