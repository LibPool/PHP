# block-chen/blocksdk-php

> 标签: Polygon, bitcoin, blockchen, blocksdk, ethereum, klaytn, sdk

## 简介

Pure (no dependencies) implementation of blocksdk

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
