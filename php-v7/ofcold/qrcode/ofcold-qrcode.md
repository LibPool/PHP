# ofcold/qrcode

> 标签: PHP

## 简介

An easy-to-use PHP QrCode generator.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://ofcold.com
- 源码仓库：https://github.com/ofcold/qr-code.git
- Packagist 页面：https://packagist.org/packages/ofcold%2Fqrcode

- 1.0.2

## 获取地址

- Composer 安装：`composer require ofcold/qrcode`
- Packagist 仓库：https://repo.packagist.org/p2/ofcold/qrcode.json
- PHP 要求：^7.2
