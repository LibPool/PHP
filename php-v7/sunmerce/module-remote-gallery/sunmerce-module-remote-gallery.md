# sunmerce/module-remote-gallery

> 标签: PHP

## 简介

Displays remote CDN image URLs instead of the native product media gallery for easier image syndication between servers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
