# uriweb/uri-program-finder

> 标签: PHP

## 简介

URI Program Finder is a WordPress plugin used to search URI degree programs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/uriweb/uri-program-finder.git
