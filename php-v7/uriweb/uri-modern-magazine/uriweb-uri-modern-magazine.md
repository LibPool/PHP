# uriweb/uri-modern-magazine

> 标签: PHP

## 简介

URI Modern Magazine is a WordPress child theme designed for the University of Rhode Island Magazine site.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
