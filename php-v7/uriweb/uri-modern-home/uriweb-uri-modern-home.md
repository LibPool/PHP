# uriweb/uri-modern-home

> 标签: PHP

## 简介

URI Modern Home is a child theme designed for the University of Rhode Island homepage site.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://www.uri.edu
- 源码仓库：https://github.com/uriweb/uri-modern-home.git
- Packagist 页面：https://packagist.org/packages/uriweb%2Furi-modern-home
