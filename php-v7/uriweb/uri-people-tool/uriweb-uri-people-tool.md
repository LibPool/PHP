# uriweb/uri-people-tool

> 标签: PHP

## 简介

URI People Tool is a Wordpress plugin that makes it easy to create and edit bibliographic posts for people.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
