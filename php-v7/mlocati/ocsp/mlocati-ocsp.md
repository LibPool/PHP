# mlocati/ocsp

> 标签: certificate, check, https, ocsp, online certificate status protocol, revocation, revoke, revoked, security

## 简介

Library to query HTTPS Certificates revocation status using the Online Certificate Status Protocol (OCSP)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
