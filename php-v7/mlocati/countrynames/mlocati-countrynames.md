# mlocati/countrynames

> 标签: countries, country, localized

## 简介

A PHP library to work with localized country names

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/mlocati/countrynames
- 源码仓库：https://github.com/mlocati/CountryNames.git
- Packagist 页面：https://packagist.org/packages/mlocati%2Fcountrynames
