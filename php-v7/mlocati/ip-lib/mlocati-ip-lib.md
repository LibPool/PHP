# mlocati/ip-lib

> 标签: IP, address, addresses, ipv4, ipv6, manage, managing, matching, network, networking, range, subnet

## 简介

Handle IPv4, IPv6 addresses and ranges

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
