# somnambulist/doctrine-enum-bridge

> 标签: ddd, doctrine, enumerations

## 简介

Allows any enumeration library to be used with Doctrine type system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
