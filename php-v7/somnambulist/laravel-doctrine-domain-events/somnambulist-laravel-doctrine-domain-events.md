# somnambulist/laravel-doctrine-domain-events

> 标签: doctrine, domain events, laravel, laravel-doctrine, validation

## 简介

Adds domain events to Doctrine entities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
