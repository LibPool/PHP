# lloc/composer-i18n-scripts

> 标签: PHP

## 简介

Simplify the internationalization of your WordPress plugin or theme using WP-CLI — powered by Composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
