# bouncer/bouncer

> 标签: bouncer, log, logging

## 简介

A PHP library to log and analyse HTTP traffic, throttle and block suspicious agents.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
