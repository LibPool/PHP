# rbdwllr/wordpress-salts-generator

> 标签: cli, keys, salts, wordpress

## 简介

A key and salts generator for WordPress that works with both wp-config and .env files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
