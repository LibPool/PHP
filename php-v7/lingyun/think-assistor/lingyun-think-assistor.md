# lingyun/think-assistor

> 标签: PHP

## 简介

ThinkPHP6 composer extension package development assistor. thinkphp6 扩展包开发的一些辅助工具。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
