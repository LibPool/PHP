# morpht/morphos

> 标签: PHP

## 简介

A scalable, modern Drupal CMS prototype theme, integrating cutting-edge front-end tools and a flexible, component-based design system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
