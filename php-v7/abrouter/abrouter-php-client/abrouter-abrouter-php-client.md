# abrouter/abrouter-php-client

> 标签: PHP

## 简介

AbrPHPClient :construction_worker_woman: is a PHP library to run ab-tests via ABRouter.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
