# andydune/rzn-view-files-path

> 标签: component, php, rzn, zf2

## 简介

A ZF2 module allows you to change the paths to view files (css, js, images) easily.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
