# ssmix/bootstrap-theme

> 标签: bootstrap, mix, silverstripe, theme

## 简介

The SilverStripe theme that uses Bootstrap 4 with Laravel Mix

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
