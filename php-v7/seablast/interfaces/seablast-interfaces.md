# seablast/interfaces

> 标签: PHP

## 简介

Shared interface contracts for the Seablast for PHP ecosystem, currently including the IdentityManagerInterface contract.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
