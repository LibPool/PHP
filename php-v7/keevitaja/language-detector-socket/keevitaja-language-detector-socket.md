# keevitaja/language-detector-socket

> 标签: detection, detector, language, language classification, language detection, language detector, language identification, language recognition

## 简介

A high-performance PHP language detection service using Unix sockets and Efficient Language Detector.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
