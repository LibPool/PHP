# wikichua/simplecontrolpanel

> 标签: laravel, simplecontrolpanel

## 简介

A simple admin control panel for Laravel 6. Forked from kejodion/laravel-admin-panel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
