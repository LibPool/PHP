# exoticca/yaml-sort-checker

> 标签: sorter, yaml

## 简介

YAML sort checker checks if your YML files are properly sorted to prevent merge conflicts

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
