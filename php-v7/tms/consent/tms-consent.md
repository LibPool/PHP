# tms/consent

> 标签: Klaro, consent-management, cookie, ePrivacy, gdpr, neoscms, third-party

## 简介

Simple, lightweight and customizable consent manager for Neos CMS based on Klaro!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
