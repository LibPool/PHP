# m2e/multichannel-magento-adobe-commerce

> 标签: ecommerce, global marketplace, m2e, m2e pro connector, magento, marketplace extension for magento 2, multichannel connect

## 简介

M2E Multichannel Connect is a native Adobe Commerce (Magento 2) extension that allows merchants to manage all their M2E marketplace integrations in one place.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
