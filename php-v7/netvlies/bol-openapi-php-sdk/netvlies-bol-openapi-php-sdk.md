# netvlies/bol-openapi-php-sdk

> 标签: PHP

## 简介

The Bol OpenApi SDK for PHP developers enables you to easily develop products over the Bol OpenApi.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
