# vega6/syvid-sdk

> 标签: Anuj Sharma, Anuj TBE, TBE, app.syvid.io, php syvid, social upload videos, syvid, syvid app, syvid.io, upload to syvid, upload videos, upload videos to youtube and facebook, vega6, vega6 syvid, vega6 syvid upload, vega6 webware technologies

## 简介

Manage user campaigns and upload videos to user's campaign using access token.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
