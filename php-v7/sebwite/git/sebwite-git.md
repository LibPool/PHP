# sebwite/git

> 标签: PHP

## 简介

Github/Bitbucket api with equal interface and flysystem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/sebwite%2Fgit
- 源码仓库：https://bitbucket.org/sebwitepackages/sebwite-git.git
- Packagist 页面：https://packagist.org/packages/sebwite%2Fgit
