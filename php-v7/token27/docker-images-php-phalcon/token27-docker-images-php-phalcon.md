# token27/docker-images-php-phalcon

> 标签: alpine, docker, phalcon, php

## 简介

An easy way to create and maintain PHP Phalcon Docker images.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
