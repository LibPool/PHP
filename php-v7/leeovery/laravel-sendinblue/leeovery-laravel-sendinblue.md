# leeovery/laravel-sendinblue

> 标签: laravel-sendinblue, leeovery

## 简介

Mail driver for Laravel to send emails via the SendInBlue v3 API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
