# timelsass/wp-php-version-check

> 标签: PHP

## 简介

Composer package to verify that WordPress and PHP versions satisfy a minimum version requirement.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
