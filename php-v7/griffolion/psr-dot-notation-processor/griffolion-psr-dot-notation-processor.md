# griffolion/psr-dot-notation-processor

> 标签: log, logging, psr-3

## 简介

Allows dot notation when using curly bracket interpolation in Monolog log messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
