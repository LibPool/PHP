# os2forms/os2forms_egir_profile

> 标签: PHP

## 简介

This profile adds the configuration and initial install of OS2forms 2.1 med Forløb as well as the EGIR integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
