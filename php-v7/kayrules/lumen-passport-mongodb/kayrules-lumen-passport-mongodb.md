# kayrules/lumen-passport-mongodb

> 标签: laravel passport, lumen, mongodb, php

## 简介

Making Laravel Passport work with Lumen and MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
