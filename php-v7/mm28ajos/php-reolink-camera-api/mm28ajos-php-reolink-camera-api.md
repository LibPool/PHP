# mm28ajos/php-reolink-camera-api

> 标签: IP, Reolink, api, camera, client

## 简介

A minimal PHP API for Reolink cameras.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
