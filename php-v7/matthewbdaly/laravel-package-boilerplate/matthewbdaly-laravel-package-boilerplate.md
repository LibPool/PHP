# matthewbdaly/laravel-package-boilerplate

> 标签: laravel, lumen

## 简介

Starting boilerplate for Laravel packages. Override the content in here when creating your own package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
