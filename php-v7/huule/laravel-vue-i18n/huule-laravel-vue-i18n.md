# huule/laravel-vue-i18n

> 标签: laravel, vue-i18n

## 简介

Generates a vue-i18n compatible include file from your Laravel translations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
