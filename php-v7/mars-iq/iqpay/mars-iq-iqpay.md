# mars-iq/iqpay

> 标签: amwal, aps, e-payment, switch, zaincash

## 简介

Php Api for iraq e-payment 4 providoor aps,zaincash,amwal,switch in one class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
