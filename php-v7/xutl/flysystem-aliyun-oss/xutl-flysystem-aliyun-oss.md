# xutl/flysystem-aliyun-oss

> 标签: Flysystem, aliyun, oss

## 简介

This is a Flysystem adapter for the Aliyun OSS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
