# xutl/yii2-back-to-top-widget

> 标签: back-to-top, extension, scroll, top, yii2

## 简介

A Yii 2 widget to add back-to-top button.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
