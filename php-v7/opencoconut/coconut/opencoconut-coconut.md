# opencoconut/coconut

> 标签: cloud, encoding, h264, transcoding, video, web service

## 简介

Coconut is a Cloud Video Encoding Service built for developers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
