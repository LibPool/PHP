# webcomm/magento-boilerplate

> 标签: PHP

## 简介

A boilerplate project for creating beautiful sites using Magento, powered by Foundation 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
