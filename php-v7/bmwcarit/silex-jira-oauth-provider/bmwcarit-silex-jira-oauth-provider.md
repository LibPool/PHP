# bmwcarit/silex-jira-oauth-provider

> 标签: jira, oauth, provider, silex

## 简介

A silex service provider that allows oauth authentication with Atlassian JIRA

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
