# afischoff/php-bird-brain-robot-server

> 标签: PHP

## 简介

A PHP wrapper for the Bird Brain Robot Server written by BirdBrain Technologies LLC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
