# nikovonlas/flarum-ext-web-push

> 标签: flarum, notification, onesignal, push, web

## 简介

Adds Web Push notification feature to flarum with OneSignal service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
