# davidyell/currency-exchange

> 标签: cakephp, currency, exchange, exchange rates, prices

## 简介

A CakePHP 2 helper for displaying prices in various currencies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
