# awsome/paa

> 标签: amazon, aws, php, product, rest, webservice

## 简介

This is an implementation of a client for the Amazon Product Advertising API in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
