# eliasis-framework/wordpress-plugin

> 标签: Eliasis, Eliasis Framework, php, plugin, wordpress

## 简介

Skeleton for create WordPress plugins with Eliasis Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
