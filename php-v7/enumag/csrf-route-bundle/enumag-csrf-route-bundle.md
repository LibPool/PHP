# enumag/csrf-route-bundle

> 标签: csrf, route, security

## 简介

Symfony bundle which provides a simple way to add CSRF tokens to routes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
