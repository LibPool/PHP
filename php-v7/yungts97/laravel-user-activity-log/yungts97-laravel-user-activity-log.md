# yungts97/laravel-user-activity-log

> 标签: activity, laravel, log, user

## 简介

A simple laravel package by yungts97 to easily monitor your laravel app user activity.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
