# geeks4change/hubs4change

> 标签: PHP

## 简介

Provides an enhanced starting place for site building, see also https://gitlab.com/geeks4change/hubs4change/h4c, built on drutopia.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
