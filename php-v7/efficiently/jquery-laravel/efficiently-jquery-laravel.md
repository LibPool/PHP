# efficiently/jquery-laravel

> 标签: ajax, asset pipeline, assets, javascript, jquery, larasset, laravel, laravel 6, laravel 7, laravel 8, pipeline, ujs, unobtrusive

## 简介

This package provides jQuery and the jQuery-ujs driver for your Laravel >= 6 application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
