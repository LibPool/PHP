> 标签: Laravel 5.1, Laravel 5.2, Sprockets, asset-pipeline, assets, coffeescript, css, javascript, laravel, laravel 5, less, manifest, mincer, minify, node, pipeline, precompile, sass, scss, source-map, sourcemaps, versioning

## 简介

Larasset is a library for Laravel 5 which manage assets in an easy way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
