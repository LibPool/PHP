# micronative/sns

> 标签: SNS, amazon, aws, messaging, queue

## 简介

Message Queue Amazon SNS Transport (fork and improve from enqueue/sns)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
