# scheb/two-factor-bundle

> 标签: 2fa, Authentication, symfony, two-factor, two-step

## 简介

Provides two-factor authentication for Symfony applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
