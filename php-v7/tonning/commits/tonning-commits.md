# tonning/commits

> 标签: commits, tonning

## 简介

A Laravel package to get latest git commit messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/tonning/commits
- 源码仓库：https://github.com/tonning/commits.git
- Packagist 页面：https://packagist.org/packages/tonning%2Fcommits

## 历史版本号

- 当前版本：0.1

- 0.1

## 获取地址

- Composer 安装：`composer require tonning/commits`
- Packagist 仓库：https://repo.packagist.org/p2/tonning/commits.json
- 许可证：MIT
- PHP 要求：^7.1
