# blackquadrant/capsule-crm-api-wrapper-php

> 标签: PHP

## 简介

A simple to use, standards compliant, exhaustive api wrapper for CapsuleCRM for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
