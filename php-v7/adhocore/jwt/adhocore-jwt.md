# adhocore/jwt

> 标签: auth, json-web-token, jwt, jwt-auth, jwt-php, token

## 简介

Ultra lightweight JSON web token (JWT) library for PHP5.5+.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
