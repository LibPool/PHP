# shiroi/think-reflection-annotation

> 标签: PHP

## 简介

thinkphp的反射插件(同个注解反射某个class、某个method、某个param、通过观察者模式关联绑定的某个method处理多个事务)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
