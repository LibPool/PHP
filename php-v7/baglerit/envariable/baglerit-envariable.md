# baglerit/envariable

> 标签: PHP

## 简介

Adds an Artisan command, envariable:encrypt, which adds an encrypted variable to the .env file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
