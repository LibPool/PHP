# tenolo/twig-extensions-bundle

> 标签: base, bundle, extension, extensions, symfony, tenolo, twig

## 简介

basic twig extensions for symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
