# tenolo/doctrine-table-prefix-bundle

> 标签: bundle, doctrine, entity, prefix, symfony, table, tenolo

## 简介

Adds the feature to add table prefix to an entity.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
