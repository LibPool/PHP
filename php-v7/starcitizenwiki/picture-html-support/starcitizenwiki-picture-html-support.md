# starcitizenwiki/picture-html-support

> 标签: PHP

## 简介

A MediaWiki extension that wraps thumbnails with picture elements, and allows adding additional source elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
