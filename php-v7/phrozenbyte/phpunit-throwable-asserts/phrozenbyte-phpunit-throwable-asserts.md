# phrozenbyte/phpunit-throwable-asserts

> 标签: php, phpunit, phpunit-assertions, phpunit-extension

## 简介

Provides various Throwable-related PHPUnit assertions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
