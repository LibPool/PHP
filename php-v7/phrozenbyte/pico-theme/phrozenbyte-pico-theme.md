# phrozenbyte/pico-theme

> 标签: default-theme, pico, pico-theme, picocms, picocms-theme

## 简介

This is PhrozenByte's fork of Pico's default theme. Pico is a stupidly simple, blazing fast, flat file CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
