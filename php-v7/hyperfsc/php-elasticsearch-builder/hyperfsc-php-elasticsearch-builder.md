# hyperfsc/php-elasticsearch-builder

> 标签: elasticsearch, elasticsearch-query-dsl, hypefactors, php, query-builder

## 简介

A PHP implementation of the Elasticsearch Query DSL.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
