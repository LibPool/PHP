# tabgeo/country

> 标签: countrycode, geoip, geolocation, location, tabgeo

## 简介

geoip (only countries) php library (http://tabgeo.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
