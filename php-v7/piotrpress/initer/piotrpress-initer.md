# piotrpress/initer

> 标签: .env, .ini, array, array-access, array-object, config, config-file, configuration, configuration-file, env, environment-variable, environment-variables, initer

## 简介

This library reads/writes flat array data from/to key=value format compatible with .ini and .env files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
