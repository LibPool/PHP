# piotrpress/wordpress-installer

> 标签: composer, composer-installer, composer-plugin, installer, wordpress, wordpress-core, wordpress-dropin, wordpress-muplugin, wordpress-plugin, wordpress-plugins, wordpress-theme, wordpress-themes

## 简介

This composer plugin sets installation paths for WordPress core, plugins, mu-plugins, themes and drop-ins outside of vendor directory.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
