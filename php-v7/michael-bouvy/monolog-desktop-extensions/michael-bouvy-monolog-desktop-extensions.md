# michael-bouvy/monolog-desktop-extensions

> 标签: PHP

## 简介

Monolog extensions (handlers / formatters) for desktop notifications (notify-send, Growl ...).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
