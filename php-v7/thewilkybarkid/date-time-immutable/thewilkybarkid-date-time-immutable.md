# thewilkybarkid/date-time-immutable

> 标签: PHP

## 简介

Polyfill for the DateTimeImmutable class added in PHP 5.5.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
