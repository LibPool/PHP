# akizor/scaffold

> 标签: akizor, generator, kubis, laravel, scaffold

## 简介

Base project structure generator for Laravel 8+ empty projects. Uses TailwindCSS and VueJs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
