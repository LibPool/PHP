# dklemmt/contao_dk_mmenu

> 标签: contao, menu, mobile, navigation

## 简介

Implementation of mmenu as an extension for the Contao Open Source CMS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
