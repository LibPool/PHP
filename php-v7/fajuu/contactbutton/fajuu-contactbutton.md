# fajuu/contactbutton

> 标签: contactbutton, fajuu, flarum

## 简介

Adds a contact button, which opens an email with the administrator's addressee.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
