# wdalmut/php-deb-describe

> 标签: deb, debian, packager, php-deb, ubuntu, yml

## 简介

A simple debian packager wrapper for PHP applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
