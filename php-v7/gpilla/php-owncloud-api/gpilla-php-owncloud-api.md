# gpilla/php-owncloud-api

> 标签: WebDAV, file sharing, owncloud, rest

## 简介

OwnCloud php API for file sharing, at least.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
