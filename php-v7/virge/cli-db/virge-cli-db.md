# virge/cli-db

> 标签: PHP

## 简介

Virge::Database is used to connect to databases, run db schema migrations, and is used heavily by Virge::ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
