# yoage/yii2-easy-wechat4

> 标签: extension, wechat sdk, yii2

## 简介

WeChat SDK for yii2, based on overtrue/wechat 4.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
