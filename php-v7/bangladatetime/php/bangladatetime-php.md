# bangladatetime/php

> 标签: Bangla, Bangla Calendar, Date Conversion, bangladesh, datetime

## 简介

A PHP library to convert DateTime to Bangla format and Bangla calendar.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
