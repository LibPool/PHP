# hkvstore/richfilemanager

> 标签: JS, file, filemanager, fileupload, manager, php, rich, upload

## 简介

RichFilemanager - highly customizable open-source file manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
