# n1215/jugoya

> 标签: Middleware Dispatcher, middleware, psr-15, request handler

## 简介

A simple HTTP application builder using PSR-15 HTTP Server Request Handler and Middleware.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
