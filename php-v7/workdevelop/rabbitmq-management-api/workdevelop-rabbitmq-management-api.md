# workdevelop/rabbitmq-management-api

> 标签: message queue, rabbitmq, rest

## 简介

An object oriented wrapper for the RabbitMQ Management HTTP Api

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
