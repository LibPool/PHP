# workdevelop/presentation-replacer

> 标签: PowerPoint, odp, php, pptx, presentation, zip

## 简介

This package replaces pre-defined variables in presentations with data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
