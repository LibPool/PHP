# kalfheim/sanitizer

> 标签: filter, filtering, laravel, sanitation, sanitizer

## 简介

Data sanitizer for PHP with built-in Laravel support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
