# felixnagel/privacyguard

> 标签: TYPO3 CMS, cleanup, database, dsgvo, gdpr, records, scheduler

## 简介

This scheduler task cleans database records in TYPO3 CMS to improve the privacy of your customers. Useful for GDPR / DSGVO compliance.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
