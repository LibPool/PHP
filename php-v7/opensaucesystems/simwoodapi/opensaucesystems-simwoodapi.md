# opensaucesystems/simwoodapi

> 标签: OpenSauceSystems, api, simwood, simwood.com, voip

## 简介

A simple object orientated way to interact with the simwood.com API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
