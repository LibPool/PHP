# opensaucesystems/dvlasearch

> 标签: OpenSauceSystems, dvla, dvlasearch

## 简介

A simple object orientated way to interact with the dvlasearch API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
