# thefrozenfire/dataobjectcruft

> 标签: dev, silverstripe

## 简介

A tool for finding and removing tables, fields and indexes which are no longer needed in a SilverStripe database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
