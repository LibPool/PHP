# dnadesign/silverstripe-embed

> 标签: cms, embed, silverstripe

## 简介

Adds embed and video a dataobject along with dataextension to apply embed to existing objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
