# dnadesign/silverstripe-elemental-media

> 标签: elemental, image, media, media object, silverstripe, video, youtube

## 简介

A media object element to position an image or video alongside content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
