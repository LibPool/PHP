# snilius/twig-sort-by-field

> 标签: PHP

## 简介

A Twig Extension filter to sort an array of entries (objects or arrays) by the specified field

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
