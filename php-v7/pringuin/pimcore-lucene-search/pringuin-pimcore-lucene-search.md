# pringuin/pimcore-lucene-search

> 标签: lucene, pimcore, search

## 简介

Pimcore 10.x Website Indexer (powered by Zend Search Lucene)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
