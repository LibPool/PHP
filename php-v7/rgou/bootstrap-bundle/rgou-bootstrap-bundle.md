# rgou/bootstrap-bundle

> 标签: bootstrap, bundle, symfony, theme, twitter

## 简介

Twitter Bootstrap Symfony2 bundle with generator for Doctrine ORM and ODM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
