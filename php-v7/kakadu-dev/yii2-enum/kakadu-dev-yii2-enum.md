# kakadu-dev/yii2-enum

> 标签: enum, extension, logic, models, structure, yii2

## 简介

Extension provide very simply use enum for models (and others) in yii2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
