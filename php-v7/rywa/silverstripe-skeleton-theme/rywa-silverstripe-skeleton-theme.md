# rywa/silverstripe-skeleton-theme

> 标签: Skeleton, css, responsive, silverstripe, theme

## 简介

SilverStripe Theme Based on Skeleton: A Beautiful Boilerplate for Responsive, Mobile-Friendly Development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
