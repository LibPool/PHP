# code-distortion/currency

> 标签: accurate, arbitrary, bcmath, calculations, code distortion, comparisons, currency, i18n, immutable, internationalisation, l10n, laravel, localisation, math, numberformatter, precision

## 简介

Arbitrary precision currency maths with locale-aware formatting - integrated with Laravel or stand-alone

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
