> 标签: accurate, arbitrary, bcmath, calculations, code distortion, comparisons, decimal, floating, i18n, immutable, internationalisation, l10n, laravel, localisation, math, number, numberformatter, percent, precision, real, realnum

## 简介

Arbitrary-precision floating-point maths with locale-aware formatting - integrated with Laravel or stand-alone

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
