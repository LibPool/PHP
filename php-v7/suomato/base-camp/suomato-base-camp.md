# suomato/base-camp

> 标签: bulma, composer, starter-theme, timber, webpack, wordpress

## 简介

Awesome WordPress starter theme with own CLI for developers based on modern web technologies.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
