# suomato/hubspot-rss-parser

> 标签: hubspot, parser, rss-feed

## 简介

Parsing HubSpot rss-feed and turning it into Array of PHP objects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
