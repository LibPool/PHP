# thiagoarioli/yii2-rest-doc-slade-version

> 标签: api, doc, rest, slate, yii2

## 简介

A Yii2 tool to create slate index.md for you REST controllers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
