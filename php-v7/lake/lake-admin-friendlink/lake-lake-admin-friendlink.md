# lake/lake-admin-friendlink

> 标签: addon, admin, database, lake, lake-admin

## 简介

The lake-admin-friendlink is an addon package for lake-admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
