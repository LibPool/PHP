# lake/login-captcha

> 标签: captcha, dcat-admin, extension, lake, login-captcha

## 简介

Dcat-admin login captcha extension. / Dcat-admin 登录验证码。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
