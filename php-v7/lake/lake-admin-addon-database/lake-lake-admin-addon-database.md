# lake/lake-admin-addon-database

> 标签: addon, admin, database, lake, lake-admin

## 简介

The lake-admin-addon-database is an addon package for lake-admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
