# bybzmt/memcached

> 标签: memcache, memcached, sasl

## 简介

An all PHP implementation of the PECL memcached extension with SASL PLAIN Auth support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
