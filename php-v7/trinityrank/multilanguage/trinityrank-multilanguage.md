# trinityrank/multilanguage

> 标签: alternate, laravel, multilanguage, nova, trinityrank

## 简介

Add alternate multilanguage tags for same pages but on other language

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
