# neapoli/katataxeis

> 标签: Katatáxeis, drupal, module

## 简介

Katatáxeis, dal greco graduatorie, è un modulo Drupal per la gestione delle graduatorie interne della scuola

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
