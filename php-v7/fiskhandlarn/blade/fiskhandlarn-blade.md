# fiskhandlarn/blade

> 标签: blade, laravel, render, template, view, wordplate, wordpress

## 简介

A library for using Laravel Blade templates in WordPress/WordPlate.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
