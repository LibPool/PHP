# xaisyndicatelab/xsimarket

> 标签: digital, laravel, marketplace, shop

## 简介

A complete ecommerce api solution with both REST and GraphQL support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
