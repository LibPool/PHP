# accentinteractive/laravel-blocker

> 标签: accentinteractive, laravel-blocker

## 简介

Block bad bots and users that visit certain (exploit) urls for a set amount of time.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
