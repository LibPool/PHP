# cjworx/laravel-smsmkt

> 标签: cjworx, laravel, laravel-smsmkt, smsmkt

## 简介

A Laravel client for sending SMS via SMSMKT.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
