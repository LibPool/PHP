# mahdiyazdani/wp-breadcrumbs

> 标签: plugin, wordpress

## 简介

Library to be bundled with WordPress themes and plugins to display a simple and easy to use breadcrumbs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
