# ourgapps/gentelella

> 标签: PHP

## 简介

Fork of the popular bootstrap 3 admin template Gentelella. We only added composer.json file. We used that for our projects. We use composer-script for building projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
