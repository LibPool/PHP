# parallalax/symfonyapidebugbundle

> 标签: PHP

## 简介

Use REST ClientGuzzle as a service for SF4 and provides a log for each ws call in the debug toolbar

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
