# jvitasek/dumpanddie

> 标签: dd, dump-and-die, tracy

## 简介

Dump and die (dd) as known in Laravel for Tracy (Nette Framework debugger).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
