# challgren/cakephp-cloudflare-deploy

> 标签: cakephp, cloudflare, deploy

## 简介

Useful console commands for deploying CakePHP apps using Cloudflare.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
