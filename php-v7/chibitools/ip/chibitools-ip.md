# chibitools/ip

> 标签: IP, geo, geoip, geolocation, ipdb, ipip.net

## 简介

IPIP.net officially supported IP database ipdb format parsing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.ipip.net
- 源码仓库：https://github.com/Tiny-Box/IPDB.git
- Packagist 页面：https://packagist.org/packages/chibitools%2Fip

## 历史版本号

## 获取地址

- Composer 安装：`composer require chibitools/ip`
- Packagist 仓库：https://repo.packagist.org/p2/chibitools/ip.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4.0
