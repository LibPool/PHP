# marqu3s/yii2-composer-installer-plugin

> 标签: PHP

## 简介

A composer installer plugin to allow the use of a package as a common folder in the advanced Yii2 template.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
