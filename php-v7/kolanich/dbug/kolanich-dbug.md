# kolanich/dbug

> 标签: ColdFusion, cfdump, debug, output, table, visualization

## 简介

A debug output library which is used to visualize different datatypes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
