# zephyr/allmysms-bundle

> 标签: allmysms, api, bundle, mms, rest, sms, symfony

## 简介

This bundle provides load of AllMySMS API for your Symfony Project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
