# elzdave/benevolent

> 标签: Authentication, Benevolent, REST API, laravel, user provider

## 简介

A custom user provider to authenticate users to REST API within Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
