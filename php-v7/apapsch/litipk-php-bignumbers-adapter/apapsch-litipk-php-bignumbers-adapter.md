# apapsch/litipk-php-bignumbers-adapter

> 标签: bcmath, bignum, decimal, gmp, number

## 简介

Adapts litipk/php-bignumers to php-decimal.io interface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
