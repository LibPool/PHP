# nektria/routing-sdk-php

> 标签: carrier, ecommerce, nektria, recs, routing, sdk

## 简介

Nektria Responsive eCommerce Shipping (ReCS) SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
