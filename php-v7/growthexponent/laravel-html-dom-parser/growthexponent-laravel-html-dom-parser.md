# growthexponent/laravel-html-dom-parser

> 标签: dom, html, laravel, laravel html dom parser, parser

## 简介

Laravel wrapper for the PHP HTML DOM Parser package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
