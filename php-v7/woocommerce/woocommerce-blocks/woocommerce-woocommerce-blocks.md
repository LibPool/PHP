# woocommerce/woocommerce-blocks

> 标签: blocks, gutenberg, woocommerce

## 简介

WooCommerce blocks for the Gutenberg editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
