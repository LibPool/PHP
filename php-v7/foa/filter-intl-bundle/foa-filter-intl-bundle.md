# foa/filter-intl-bundle

> 标签: filter, intl, sanitize, validate

## 简介

Integration bundle for Aura.Filter with Aura.Intl

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
