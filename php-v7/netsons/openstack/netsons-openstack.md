# netsons/openstack

> 标签: Openstack, api, php, sdk

## 简介

PHP SDK for OpenStack APIs. Supports BlockStorage, Compute, Identity, Images, Networking and Metric Gnocchi

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
