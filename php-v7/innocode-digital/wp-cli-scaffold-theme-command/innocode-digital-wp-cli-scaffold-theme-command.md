# innocode-digital/wp-cli-scaffold-theme-command

> 标签: PHP

## 简介

Generates starter code for a theme based on Innocode theme skeleton.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
