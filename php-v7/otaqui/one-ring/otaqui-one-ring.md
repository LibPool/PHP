# otaqui/one-ring

> 标签: decision, engine, logic, rules

## 简介

The One Ring Rules Engine - a general purpose library providing ready made, extensible and data-driven rules creation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
