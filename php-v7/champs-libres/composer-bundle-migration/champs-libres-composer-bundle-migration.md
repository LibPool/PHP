# champs-libres/composer-bundle-migration

> 标签: doctrine, doctrine migrations, symfony

## 简介

Move DoctrineMigrations files from installed bundle to root package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
