# tysonandre/phantypocheck

> 标签: codespell, gettext, phan, phan-plugin, typo

## 简介

A plugin for Phan that checks for typos (using codespell's dictionary).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
