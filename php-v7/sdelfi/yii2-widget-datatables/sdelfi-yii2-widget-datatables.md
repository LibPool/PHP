# sdelfi/yii2-widget-datatables

> 标签: bootstrap4, datatables, extension, javascript, jquery, library, table, yii2

## 简介

DataTables widget for Yii2 with Bootstrap 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
