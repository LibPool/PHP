# qqzeng/qzdb

> 标签: IP, geolocation, ip-lookup, ipv6, offline, qzdb

## 简介

Offline, zero-dependency PHP reader for .qzdb IP geolocation databases (IPv4 / IPv6 dual-stack).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
