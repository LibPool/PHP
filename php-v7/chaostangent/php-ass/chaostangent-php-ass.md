# chaostangent/php-ass

> 标签: ass, mkv, mp4, ssa, subtitle, subtitles

## 简介

A library for reading Advanced Sub Station Alpha subtitle files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
