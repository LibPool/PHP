# bnomei/kirby3-page-sqlite

> 标签: cache, kirby3, kirby3-cms, kirby3-plugin, page, performance, sqlite

## 简介

Kirby 3 Plugin to cache the content file using SQLite

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
