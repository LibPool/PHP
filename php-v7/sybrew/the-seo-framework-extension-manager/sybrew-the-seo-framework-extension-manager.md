# sybrew/the-seo-framework-extension-manager

> 标签: plugin, seo, wordpress

## 简介

A WordPress plugin that allows you to manage extensions for The SEO Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
