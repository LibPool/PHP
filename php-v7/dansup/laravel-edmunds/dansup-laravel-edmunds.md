# dansup/laravel-edmunds

> 标签: automotive, edmunds, laravel, sdk, vehicle, vin

## 简介

An unoffical Edmunds SDK for the Laravel Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
