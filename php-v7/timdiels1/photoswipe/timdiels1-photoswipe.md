# timdiels1/photoswipe

> 标签: PHP

## 简介

Fork for Drupal of the PhotoSwipe repository: JavaScript image gallery for mobile and desktop, modular, framework independent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
