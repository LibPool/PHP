# litvinenko/app

> 标签: PHP

## 简介

General-purpose Litvinenko\Common\App class that can dispatch events in Magento style and create singletones in Magento style

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
