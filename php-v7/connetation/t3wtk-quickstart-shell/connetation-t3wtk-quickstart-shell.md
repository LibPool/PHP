# connetation/t3wtk-quickstart-shell

> 标签: PHP

## 简介

DDEV quickstart for TYPO3 14 projects built on the Connetation TYPO3 Web Toolkit (base, elements, sitepackage)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
