# myaghobi/f3-migrations

> 标签: Fat-Free-Framework, database, f3-migrations, fat-free-plugin, migration, sql

## 简介

A database helper plugin for the Fat-Free framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
