# lumidev/extended-admin-grid

> 标签: PHP

## 简介

Le module LumiDev Extended Admin Grid ajoute des colonnes clés aux grilles des factures, commandes et avoirs Magento 2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
