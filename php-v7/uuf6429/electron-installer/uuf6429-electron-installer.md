# uuf6429/electron-installer

> 标签: binaries, electron, headless

## 简介

A Composer package which installs the Electron binary (Linux, Windows, Mac) into `/bin` of your project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
