# titledk/silverstripe-gallery

> 标签: gallery, silverstripe

## 简介

A simple gallery backend for SilverStripe 3 with advanced directory saving rules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
