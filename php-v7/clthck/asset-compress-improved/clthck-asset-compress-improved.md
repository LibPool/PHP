# clthck/asset-compress-improved

> 标签: assets, cakephp, coffee-script, less, minifier, postcss, sass

## 简介

An improved version of markstory/asset_compress. An asset compression plugin for CakePHP 3. Provides file concatenation and a flexible filter system for preprocessing and minification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
