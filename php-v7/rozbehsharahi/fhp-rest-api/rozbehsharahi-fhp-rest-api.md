# rozbehsharahi/fhp-rest-api

> 标签: Simple, ember, file, flat, json, rest, restful

## 简介

Super quick setup of a PHP-REST-API without the use of MySQL, Apache, ...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
