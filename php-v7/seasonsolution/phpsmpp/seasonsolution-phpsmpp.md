# seasonsolution/phpsmpp

> 标签: PHP

## 简介

PHPSMPP is a full-featured SMS creation, transfer and receive class for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
