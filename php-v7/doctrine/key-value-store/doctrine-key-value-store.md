# doctrine/key-value-store

> 标签: PHP

## 简介

Simple Key-Value Store Abstraction Layer that maps to PHP objects, allowing for many backends.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
