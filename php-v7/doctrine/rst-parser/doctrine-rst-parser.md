# doctrine/rst-parser

> 标签: html, latex, markup, parser, reStructuredText, rst

## 简介

PHP library to parse reStructuredText documents and generate HTML or LaTeX documents.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
