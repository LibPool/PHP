# maestroerror/imageme

> 标签: PHP

## 简介

Image upload & management class, created specially for performance and security - easy to use, chainable, supports JPEG & WebP file extensions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
