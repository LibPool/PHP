# wigner/simplesamlphp-module-totp

> 标签: PHP

## 简介

SimpleSAMLphp authentication processing filter for TOTP-based 2FA using PITS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
