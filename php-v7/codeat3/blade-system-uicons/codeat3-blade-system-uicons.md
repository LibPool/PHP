# codeat3/blade-system-uicons

> 标签: blade, laravel, system, uicons

## 简介

A package to easily make use of "System UIcons" in your Laravel Blade views.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
