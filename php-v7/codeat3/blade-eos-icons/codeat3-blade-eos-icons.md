# codeat3/blade-eos-icons

> 标签: blade, eos-icons, laravel

## 简介

A package to easily make use of "EOS Icons" in your Laravel Blade views.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
