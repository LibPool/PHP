# stepovenko/laravel-amocrm

> 标签: amoCRM, api, crm, laravel

## 简介

ServiceProvider и Facade для Laravel 5 предоставляющие интеграцию с API amoCRM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
