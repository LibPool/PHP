# easybib/silex-qafoo-provider

> 标签: logging, performance, profiler, qafoo, tideways

## 简介

Silex provider for the qafoo profiler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
