# easybib/form-decorator

> 标签: PHP

## 简介

EasyBib_Form_Decorator is a set of Twitter Bootstrap decorators for Zend_Form

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
