# palanik/slim-apc-cache

> 标签: apc, apccache, cache, slim, slimapccache, slimcache, slimphp

## 简介

Cache Middleware for PHP Slim micro framework using APC Cache

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
