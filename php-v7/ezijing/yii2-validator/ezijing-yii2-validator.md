# ezijing/yii2-validator

> 标签: validator, yii2-validator, 验证器

## 简介

Yii2的参数验证器，兼容model的rules;减少验证参数的时候要新建model的烦恼

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
