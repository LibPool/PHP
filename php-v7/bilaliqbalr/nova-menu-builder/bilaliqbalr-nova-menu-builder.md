# bilaliqbalr/nova-menu-builder

> 标签: builder, laravel, menu, nova, optimistdigital

## 简介

This Laravel Nova package allows you to create and manage menus and menu items.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
