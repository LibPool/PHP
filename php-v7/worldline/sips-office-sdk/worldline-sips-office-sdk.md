# worldline/sips-office-sdk

> 标签: bancontact, payments, psp, sips, worldline

## 简介

This library simplifies the use of Sips 2.O, the e-payments API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
