# mascame/artificer-pagination-plugin

> 标签: artificer, laravel, pagination, plugin

## 简介

Pagination plugin. Provides pagination to models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
