# mascame/artificer

> 标签: Admin Interface, admin, administration, artificer, eloquent admin, laravel

## 简介

Artificer is the admin panel Laravel deserves. Built on top of your Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
