# silentbyte/sb-dynlex

> 标签: flex, language, lex, lexer, parser

## 简介

A dynamically configurable lexer library featuring a fluid API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
