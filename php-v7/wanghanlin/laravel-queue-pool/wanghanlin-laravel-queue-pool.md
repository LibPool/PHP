# wanghanlin/laravel-queue-pool

> 标签: laravel, laravel-queue-pool

## 简介

A Laravel package provide pool command to start multiple queue worker all at once.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
