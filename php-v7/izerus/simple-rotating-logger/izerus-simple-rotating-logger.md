# izerus/simple-rotating-logger

> 标签: log, logger, monolog, rotate, rotating, size

## 简介

Monolog, but simpler: Static syntax (Log::info()) + automatic log rotation by file size.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
