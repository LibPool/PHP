# dlintin/zipstream-php

> 标签: stream, zip

## 简介

ZipStream is a library for dynamically streaming dynamic zip files from PHP without writing to the disk at all on the server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
