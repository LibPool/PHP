# jymusic/filedownloader

> 标签: file, filedownloader, jymusic

## 简介

PHP file downloader

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/jymusic/filedownloader
- 源码仓库：https://github.com/jymusic/filedownloader.git
- Packagist 页面：https://packagist.org/packages/jymusic%2Ffiledownloader

## 获取地址

- Composer 安装：`composer require jymusic/filedownloader`
- Packagist 仓库：https://repo.packagist.org/p2/jymusic/filedownloader.json
