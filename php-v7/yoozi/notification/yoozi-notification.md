# yoozi/notification

> 标签: golem, notification, wrapper, yoozi

## 简介

A simple library to wrap common notification transports, such as email, socket.io and etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
