# yoozi/miner

> 标签: golem, metadata, readability, summarize, webpage, yoozi

## 简介

PHP library to extract the metadata from a public web page and/or summarize it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
