# zombie-flesh-eaters/mu-loader

> 标签: PHP

## 简介

Composer 2 plugin that generates a WordPress MU-plugin autoloader file from configured folders.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
