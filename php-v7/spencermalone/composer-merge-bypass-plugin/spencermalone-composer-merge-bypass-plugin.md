# spencermalone/composer-merge-bypass-plugin

> 标签: composer, conflict, merge, plugin

## 简介

Hides merge conflicts in composer.lock and vendor/composer/installed.json

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
