# anper/russian-id

> 标签: EMP, INN, bik, check, checksum, kpp, ks, oms, orgn, orgnip, rs, snils, validate, verify, БИК, ЕМП, ОГРНИП, ОМС, инн, корреспондентский счёт, кпп, огрн, расчётнный счёт, снилс

## 简介

Простой валидатор для идентификаторов российских физических и юридических лиц. Проверяет только checksum.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
