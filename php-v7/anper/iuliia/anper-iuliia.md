# anper/iuliia

> 标签: cyrillic, iuliia, latin, translate, translit, transliterate

## 简介

Transliterate Cyrillic → Latin in every possible way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
