# mxmorozov/yii2-thumbnail-action

> 标签: Thumbnails, actions, extension, yii2

## 简介

This extension purpose is to make thumbnails of images on the fly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
