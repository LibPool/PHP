# jadu/twig-attribute-parser

> 标签: PHP

## 简介

Takes an array of attributes to be converted into HTML formatted attributes ready for use in an HTML element.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
