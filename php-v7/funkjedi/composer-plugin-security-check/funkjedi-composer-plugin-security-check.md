# funkjedi/composer-plugin-security-check

> 标签: PHP

## 简介

Plugin for Composer to check if your application uses dependencies with known security vulnerabilities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
