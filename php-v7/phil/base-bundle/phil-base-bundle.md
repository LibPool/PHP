# phil/base-bundle

> 标签: HTML5, boilerplate, h5b, html, twig

## 简介

HTML5 boilerplate in symfony2 with twig. Add security tools. Add Quality Tools.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
