# comtele/comtele_sdk

> 标签: api, comtele, rest, sdk, sms, telephony

## 简介

SDK para envio de mensagens de texto usando a plataforma Comtele

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
