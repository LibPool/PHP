# fakis/yii2-aceeditor

> 标签: aceeditor, extension, yii2

## 简介

在线代码编辑器，针对Yii2框架封装的Ace编辑器

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
