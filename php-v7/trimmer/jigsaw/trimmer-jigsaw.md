# trimmer/jigsaw

> 标签: blade, generator, laravel, site, static

## 简介

A fork of Adam Wathan's jigsaw static site builder repurposed to build bash and conf files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
