# gpupo/similarity

> 标签: compare, diff, distance, levenshtein, similarity, string

## 简介

Calculate the similarity between strings and numbers working in a different way from a diff tool

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
