# cv001/log4php

> 标签: log, logging, php

## 简介

A versatile logging framework for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://logging.apache.org/log4php/
- 源码仓库：https://github.com/cv001/logging-log4php.git
- Packagist 页面：https://packagist.org/packages/cv001%2Flog4php

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require cv001/log4php`
- Packagist 仓库：https://repo.packagist.org/p2/cv001/log4php.json
- 许可证：Apache-2.0
- PHP 要求：>=5.2.7
