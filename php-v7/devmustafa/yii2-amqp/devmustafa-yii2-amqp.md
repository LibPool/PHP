# devmustafa/yii2-amqp

> 标签: AMQP, extension, rabbitmq, yii

## 简介

Yii2 extension enables you to use RabbitMQ with native Yii2 syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
