# rkl/redirects-export

> 标签: TYPO3 CMS, csv, excel, export, redirects, typo3

## 简介

Allows you to export redirects from the redirects module to a CSV file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
