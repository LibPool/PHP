# shali/think-msg

> 标签: Feishu, dingtalk, message, msg, qq, sms, thinkphp, wechat

## 简介

thinkphp-msg 是一个基于 thinkphp 的消息推送扩展。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
