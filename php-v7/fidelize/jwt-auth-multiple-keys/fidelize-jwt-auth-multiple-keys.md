# fidelize/jwt-auth-multiple-keys

> 标签: Authentication, JSON Web Token, auth, jwt, laravel

## 简介

Add multiple keychain support to tymon/jwt-auth package

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
