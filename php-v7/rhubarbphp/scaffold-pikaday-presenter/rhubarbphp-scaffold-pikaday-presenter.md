# rhubarbphp/scaffold-pikaday-presenter

> 标签: date, datepicker, javascript, php, pikaday, rhubarb

## 简介

Provides a presenter for picking dates with the Pikaday javascript library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
