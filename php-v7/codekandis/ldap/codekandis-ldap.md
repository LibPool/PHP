# codekandis/ldap

> 标签: classes, interfaces, ldap, php, wrapper

## 简介

`codekandis/ldap` is a library providing LDAP wrapper interfaces and classes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
