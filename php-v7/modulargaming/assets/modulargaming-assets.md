# modulargaming/assets

> 标签: assets, kohana, modulargaming

## 简介

Assets module for Kohana Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/modulargaming/assets
- 源码仓库：https://github.com/modulargaming/assets.git
- Packagist 页面：https://packagist.org/packages/modulargaming%2Fassets

## 获取地址

- Composer 安装：`composer require modulargaming/assets`
- Packagist 仓库：https://repo.packagist.org/p2/modulargaming/assets.json
