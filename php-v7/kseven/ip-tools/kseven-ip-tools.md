# kseven/ip-tools

> 标签: IP, Match, compare, ipv4, ipv6, mask, subnet, tools, utilities

## 简介

PHP IP Tools for manipulation with IPv4 and IPv6

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
