# adriansuter/psr7-minify-middleware

> 标签: middleware, minify, psr7

## 简介

PSR-7 Middleware that minifies the response body (HTML Minify).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
