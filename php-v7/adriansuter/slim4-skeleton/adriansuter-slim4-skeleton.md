# adriansuter/slim4-skeleton

> 标签: PHP

## 简介

Web application skeleton that uses the Slim4 Framework, PHP-DI, Nyholm PSR7 and Twig.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
