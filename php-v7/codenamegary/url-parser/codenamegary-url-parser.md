# codenamegary/url-parser

> 标签: codenamegary, parsing, url

## 简介

Parse, merge and modify URLs while maintaining integrity of all parts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
