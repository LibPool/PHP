# tfrommen/highlightjs

> 标签: code, highlight, highlight.js, syntax

## 简介

A simple Highlight.js-based syntax highlighter plugin for WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
