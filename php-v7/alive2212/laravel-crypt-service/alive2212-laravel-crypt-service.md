# alive2212/laravel-crypt-service

> 标签: LaravelCryptService, laravel

## 简介

This is laravel crypt service for create rsa & .. key to crypt and decrypt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
