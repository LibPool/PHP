# alive2212/laravel-mobile-passport

> 标签: LaravelMobilePassport, laravel

## 简介

This is an illuminate package for one time authentication (OTP) with OAuth2 Base

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
