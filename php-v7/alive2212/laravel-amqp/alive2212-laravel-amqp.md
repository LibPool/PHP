# alive2212/laravel-amqp

> 标签: PHP

## 简介

{This is Fork of anik/amqp package}  of php-amqplib wrapper that eases the consumption of RabbitMQ. A painless way of using RabbitMQ

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
