# devsng/laravel-interswitch

> 标签: DevsNG, Interswitch, laravel, webpay

## 简介

Interswitch WebPay Integration package for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
