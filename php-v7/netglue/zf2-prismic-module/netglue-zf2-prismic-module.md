# netglue/zf2-prismic-module

> 标签: netglue, prismic.io, zf2

## 简介

ZF2 module for the Prismic PHP SDK. Simple wrapper and some added convenience.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
