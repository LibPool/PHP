# netglue/ng-mtmail

> 标签: email, module, netglue, template, zend, zf2

## 简介

ZF2 Module providing a multipart template driven email message creation service using the ZF view layer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
