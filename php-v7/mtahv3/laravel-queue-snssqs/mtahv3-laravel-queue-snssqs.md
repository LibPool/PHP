# mtahv3/laravel-queue-snssqs

> 标签: PHP

## 简介

Provides ability to handle Laravel Queues from a fan-out SNS/SQS pattern

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
