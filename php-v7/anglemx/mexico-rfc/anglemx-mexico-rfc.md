# anglemx/mexico-rfc

> 标签: angle, mexico, rfc, sat

## 简介

PHP utility to handle Mexico SAT's (Tax Authority) RFC (Tax ID)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
