# aloisogomes/boletototal

> 标签: Emissao, boleto, php, remessa, retorno

## 简介

Projeto para emissão de boletos, geração de arquivos de remessa e recepção de arquivos de retorno

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
