# nael_d/guardify

> 标签: Authentication, PHP7, cookie-check, csrf, form-validation, hmac, ip-check, open-source, php, security, token-scoping, user-agent-check

## 简介

Robust CSRF protection for PHP applications with HMAC validation, IP/UA binding, and AJAX support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
