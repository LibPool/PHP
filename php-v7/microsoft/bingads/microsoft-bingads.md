# microsoft/bingads

> 标签: bing ads, bingads, microsoft advertising, php, sdk

## 简介

This project provides the PHP client library for the SOAP-based Bing Ads API at Microsoft.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
