# iumio/fgm

> 标签: PHP7, components, core, iumio, iumio-framework, mvc, php, php-framework

## 简介

FGM (Framework Graphic Manager) is a web tools to manage framework components

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
