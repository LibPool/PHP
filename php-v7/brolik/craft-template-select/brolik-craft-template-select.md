# brolik/craft-template-select

> 标签: Craft, cms, craft-plugin, craftcms, template select

## 简介

A fieldtype that allows you to select a template from a dropdown. Based on superbig's plugin

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
