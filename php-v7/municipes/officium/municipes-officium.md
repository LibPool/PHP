# municipes/officium

> 标签: PHP

## 简介

Officĭum è un modulo Drupal che gestisce il tipo di contenuto Unità organizzativa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
