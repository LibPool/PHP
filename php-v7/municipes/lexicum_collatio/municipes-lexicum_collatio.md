# municipes/lexicum_collatio

> 标签: PHP

## 简介

Lexicum Collatio è un modulo Drupal che importa le voci di tassonomia utilizzate dai Comuni.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
