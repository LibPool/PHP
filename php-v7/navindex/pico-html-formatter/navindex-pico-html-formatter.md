# navindex/pico-html-formatter

> 标签: Navindex, beautify, format, html, html-formatter, indent, minify, php, pico, picocms, picocms-plugin

## 简介

This is a Pico wrapper for the HTML Formatter library from Navindex.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
