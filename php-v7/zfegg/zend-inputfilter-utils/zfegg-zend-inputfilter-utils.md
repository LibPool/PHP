# zfegg/zend-inputfilter-utils

> 标签: filter, validator

## 简介

更多的 ZendFramework 输入过滤工具(过滤器和验证器).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
