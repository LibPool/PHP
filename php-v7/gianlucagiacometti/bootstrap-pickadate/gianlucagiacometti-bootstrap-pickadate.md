# gianlucagiacometti/bootstrap-pickadate

> 标签: bootstrap, date, datepicker, pickadate

## 简介

Date picker extension for the Bootstrap date input element

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
