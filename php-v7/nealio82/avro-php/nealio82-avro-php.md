# nealio82/avro-php

> 标签: PHP

## 简介

Implementation of Apache's Avro PHP library with Composer support, PSR-4 autoloading, namespaces, and type hinted method parameters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
