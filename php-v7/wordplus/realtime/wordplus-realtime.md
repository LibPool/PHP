# wordplus/realtime

> 标签: WebRTC, channels, group calls, presence, realtime, video calls, websocket, wordpress

## 简介

The realtime SDK for any WordPress plugin, theme or custom code on WordPlus Cloud: channels, presence and events, calls between two people that ring in the browser, group calls, and a drop-in call screen, on the connection a page shares with WordPlus's own plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
