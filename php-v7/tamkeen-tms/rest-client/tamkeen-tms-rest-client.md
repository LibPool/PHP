# tamkeen-tms/rest-client

> 标签: api, lms, php, rest, tms

## 简介

PHP REST client for Tamkeen's API (tamkeentms.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
