# romeoz/rock-mongodb

> 标签: Active Record, dao, dbal, mongo, mongodb, orm, query builder

## 简介

Object Document Mapper (ODM) for MongoDB.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
