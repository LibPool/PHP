# university-of-denver/quicksilver-autopilot-notification

> 标签: PHP

## 简介

Send a notification to a Drupal site when an Autopilot visual regression test is complete

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
