# fabiomezzo/pdfparser

> 标签: extract, parse, parser, pdf, text

## 简介

Pdf parser library. Can read and extract information from pdf file. Forked from smalot/pdfparser

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 源码仓库：https://github.com/FabioMezzo/pdfparser.git
