# ecphp/doctrine-oci8

> 标签: cursor, database, doctrine, oci, oci8, oracle

## 简介

Doctrine's OCI8 (Oracle) driver with cursor support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
