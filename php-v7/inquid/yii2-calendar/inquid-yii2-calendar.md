# inquid/yii2-calendar

> 标签: activerecord, calendar, dataprovider, extension, view, widget, yii2

## 简介

CalendarView widget for Yii 2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
