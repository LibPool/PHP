# alvaro/xmltoarray

> 标签: Connection, PHP7, PSR-4, array, xml, xml-to-array, xmltoarray

## 简介

Easy way to convert Xml into Array.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
