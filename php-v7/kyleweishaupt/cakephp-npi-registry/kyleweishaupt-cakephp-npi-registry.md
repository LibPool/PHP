# kyleweishaupt/cakephp-npi-registry

> 标签: api, cakephp, cms, npi

## 简介

CakePHP Plugin for interacting with the NPPES NPI Registry.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
