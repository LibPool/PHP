# kapersoft/npmsearch-api

> 标签: kapersoft, npm, npmsearch, npmsearch-api, package, packages, search

## 简介

Search for NPM packages using npmsearch.com API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
