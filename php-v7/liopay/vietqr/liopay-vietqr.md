# liopay/vietqr

> 标签: EMVCo, QR-Payment, bank-transfer, fastfund, ibft, napas, payment, qr-code, qr-generator, qr-parser, vietnam, vietnamese-payment, vietqr

## 简介

Production-ready PHP library for building and parsing VietQR (NAPAS FastFund 24/7 IBFT) QR codes compliant with EMVCo 1.5.2 specification.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
