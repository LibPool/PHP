# 42a-consulting/selenium-server-standalone

> 标签: selenium, testing

## 简介

Composer distribution of Selenium Server Standalone, the browser automation framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
