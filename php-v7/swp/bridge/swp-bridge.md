# swp/bridge

> 标签: Bridge, Connection, Superdesk, library, publisher, symfony, tenant

## 简介

Tools which help to make a connection between Superdesk and Superdesk Web Publisher

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
