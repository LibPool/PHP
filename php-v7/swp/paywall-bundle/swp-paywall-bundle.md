# swp/paywall-bundle

> 标签: Superdesk, billing, paywall, publisher, publishing, subscriptions

## 简介

Paywall implementation for Symfony applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
