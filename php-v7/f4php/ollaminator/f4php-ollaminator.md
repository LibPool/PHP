# f4php/ollaminator

> 标签: client, f4, ollama

## 简介

Ollaminator is ollama client implementation for F4, a (really) lightweight web application framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
