# hulang/think-ip

> 标签: China, Chinese, IP, IP数据库, database, location, 数据库

## 简介

IP数据库 IPV4 IPV6(解析为国家、省、市、县、运营商)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
