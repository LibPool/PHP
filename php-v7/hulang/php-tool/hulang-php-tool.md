# hulang/php-tool

> 标签: library, php

## 简介

数组转树形处理类、时间助手类、文件及文件夹处理类、字符串操作类、手机号码归属地、银行号归属地、Zip压缩和解压

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
