# hingeltd/wordpress-starter

> 标签: bedrock, boilerplate, composer, docker, wordpress, wp, wp-config

## 简介

WordPress boilerplate with Bedrock, Lumberjack, Laravel mix on Docker

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
