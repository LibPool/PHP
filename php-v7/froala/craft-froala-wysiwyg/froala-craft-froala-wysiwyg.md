# froala/craft-froala-wysiwyg

> 标签: Craft, craftcms, craftcms plugin, froala, plugin, wysiwyg

## 简介

Craft 3 CMS plugin for Froala WYSIWYG HTML Rich Text Editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
