# froala/nova-froala-field

> 标签: editor, field, froala, laravel, nova, wysiwyg

## 简介

A Laravel Nova Froala WYSIWYG Editor Field.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
