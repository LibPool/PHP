# puli/symfony-bridge

> 标签: PHP

## 简介

Integrates the Puli library with the Symfony components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/puli/symfony-bridge.git
- Packagist 页面：https://packagist.org/packages/puli%2Fsymfony-bridge
