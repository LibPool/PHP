# earthperson/htmlpagelinker

> 标签: htmlpagelinker

## 简介

Linking web page as one file after saving as "Web Page, complete" in a browser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
