# tfranek/webuntis

> 标签: api, json rpc, webuntis, webuntisapi

## 简介

A API library that make it easy to access the Webuntis JSON RPC 2.0 API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
