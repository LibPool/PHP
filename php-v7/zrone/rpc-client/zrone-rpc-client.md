# zrone/rpc-client

> 标签: hyperf, json-rpc, php, rpc, rpc-client, swoole

## 简介

An abstract rpc server component for Hyperf.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
