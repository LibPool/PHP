# dwy/facebook-conversion

> 标签: Craft, craft-plugin, craftcms, facebook

## 简介

Craft CMS plugin to send web events directly to Facebook

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
