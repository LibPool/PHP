# webeweb/bootstrap-bundle

> 标签: bootstrap, bundle, symfony, theme, webeweb

## 简介

Integrate Bootstrap theme with Symfony 2 and more

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
