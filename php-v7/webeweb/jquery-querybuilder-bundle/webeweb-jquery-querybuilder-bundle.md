# webeweb/jquery-querybuilder-bundle

> 标签: bundle, jquery, querybuilder, symfony, webeweb

## 简介

Integrate jQuery QueryBuilder with Symfony 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
