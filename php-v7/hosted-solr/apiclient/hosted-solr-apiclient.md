# hosted-solr/apiclient

> 标签: TYPO3 CMS, drupal, magento, solr, typo3

## 简介

PHP Api Client for hosted-solr.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://www.hosted-solr.com
- 源码仓库：https://github.com/dkd/hosted_solr-php-api.git
