# acquia/http-hmac-php

> 标签: PHP

## 简介

An implementation of the HTTP HMAC Spec in PHP that integrates with popular libraries such as Symfony and Guzzle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
