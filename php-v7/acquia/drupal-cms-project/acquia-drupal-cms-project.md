# acquia/drupal-cms-project

> 标签: PHP

## 简介

Drupal with a bunch of useful stuff and a scaffold tailored to Acquia hosting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
