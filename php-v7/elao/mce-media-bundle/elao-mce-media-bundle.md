# elao/mce-media-bundle

> 标签: bundle, elao, media, tiny_mce

## 简介

This bundle handles the integration of File Manager and Image Manager plugins inside TinyMCE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
