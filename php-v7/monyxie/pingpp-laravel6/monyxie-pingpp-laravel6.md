# monyxie/pingpp-laravel6

> 标签: Pingxx, laravel, laravel 5, pingpp

## 简介

Simple Pingpp wrapper for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
