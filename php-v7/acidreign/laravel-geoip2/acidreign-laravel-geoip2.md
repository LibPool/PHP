# acidreign/laravel-geoip2

> 标签: geoip, geoip2, laravel, maxmind

## 简介

Laravel wrapper for MaxMind GeoIP2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
