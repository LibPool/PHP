# pluginkollektiv/statify

> 标签: plugin, statistics, wordpress

## 简介

Compact, easy-to-use and privacy-compliant stats plugin for WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
