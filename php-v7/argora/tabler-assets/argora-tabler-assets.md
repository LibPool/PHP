# argora/tabler-assets

> 标签: PHP

## 简介

Compiled Tabler UI assets (CSS, JS, fonts, etc.) for PHP projects without NPM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
