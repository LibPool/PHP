# isaacdew/load-data

> 标签: PHP

## 简介

Fluent syntax for loading large CSV files into MySQL using LOAD DATA INFILE in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
