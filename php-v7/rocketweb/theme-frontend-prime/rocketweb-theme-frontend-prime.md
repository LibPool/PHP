# rocketweb/theme-frontend-prime

> 标签: PHP

## 简介

Rocket Web Prime theme based on Magento Blank that includes our most common customizations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
