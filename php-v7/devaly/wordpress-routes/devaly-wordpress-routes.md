# devaly/wordpress-routes

> 标签: redirects, rewrite, routes, routing

## 简介

Manage rewrites and routes in WordPress with this dead-simple plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
