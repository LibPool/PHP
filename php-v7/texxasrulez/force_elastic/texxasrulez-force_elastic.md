# texxasrulez/force_elastic

> 标签: elastic, mobile, plugin, responsive, roundcube, skin

## 简介

Roundcube plugin that forces the Elastic skin on mobile devices at runtime (without changing user prefs).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
