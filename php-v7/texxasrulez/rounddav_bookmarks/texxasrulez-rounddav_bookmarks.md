# texxasrulez/rounddav_bookmarks

> 标签: PHP

## 简介

Plugin for Shared and Private Bookmarks using RoundDAV Server and rounddav_provision plugin

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
