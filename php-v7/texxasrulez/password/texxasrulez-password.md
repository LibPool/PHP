# texxasrulez/password

> 标签: PHP

## 简介

Password Change for Roundcube. Plugin adds a possibility to change user password using many methods (drivers) via Settings/Password tab.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
