# dumkaaa/boxberry-api-c2c

> 标签: api, boxberry, c2c, delivery

## 简介

Реализация Boxberry API для работы с сервисами ПиП(письма и посылки) и ЛК (в т.ч. для частных лиц)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
