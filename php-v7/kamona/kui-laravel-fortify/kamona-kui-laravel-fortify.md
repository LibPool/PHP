# kamona/kui-laravel-fortify

> 标签: auth, dashboard, fortify, k-ui, laravel, tailwindcss, ui

## 简介

Front-end scafolding for laravel/fortify based on kui-dashboard

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
