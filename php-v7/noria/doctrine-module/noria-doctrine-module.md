# noria/doctrine-module

> 标签: doctrine, module, zf

## 简介

Zend Framework Module that provides Doctrine basic functionality required for ORM and ODM modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
