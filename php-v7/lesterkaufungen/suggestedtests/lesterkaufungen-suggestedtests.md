# lesterkaufungen/suggestedtests

> 标签: benchmark, memory, performance, phpunit, snapshot, spy, testing

## 简介

PHPUnit helpers for PHP 7.4+: performance and memory budgets backed by a native OS bridge (ext-ffi), eventually, given/when/then steps, spies, snapshots and seeded test data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
