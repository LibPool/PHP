# kozyaxbiz/php-qrcoder

> 标签: image, php, poster, qrcode, uyghur

## 简介

A PHP library for generating QR codes and posters with Uyghur language support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
