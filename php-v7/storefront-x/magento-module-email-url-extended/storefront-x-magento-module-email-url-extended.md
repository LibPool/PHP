# storefront-x/magento-module-email-url-extended

> 标签: PHP

## 简介

Magento 2 module extends Magento Email module, this module requires StorefrontX SfxStoreConfig module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
