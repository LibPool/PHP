# ceddyg/clara-dataflow

> 标签: clara, csv, dataflow, entity, export, import, laravel, xls, xml

## 简介

Repository to create dataflow from the database using query builder.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
