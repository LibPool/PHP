# quiet-metrics/php-metrics

> 标签: analytics, privacy, rgpd, sans-cookies, server-side

## 简介

Package cœur Quiet Metrics (PHP pur) : mesure d'audience sans cookie de pistage, 100 % côté serveur, imblocable par les adblockers. Fondation des ponts Laravel et Symfony.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
