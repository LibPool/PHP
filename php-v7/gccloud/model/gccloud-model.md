# gccloud/model

> 标签: codeigniter, library, parser

## 简介

CodeIgniter 3 Model extension, working with maltyxx Origami package (see https://github.com/maltyxx/origami)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
