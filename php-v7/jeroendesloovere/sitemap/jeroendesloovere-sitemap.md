# jeroendesloovere/sitemap

> 标签: Sitemap, generator, symfony, xml

## 简介

Library for generating (one or multiple) Sitemaps and a SitemapIndex.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
