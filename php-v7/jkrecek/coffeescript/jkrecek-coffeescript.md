# jkrecek/coffeescript

> 标签: JS, coffee, coffeescript, javascript

## 简介

A port of the CoffeeScript compiler to PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
