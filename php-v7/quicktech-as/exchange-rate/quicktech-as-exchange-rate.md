# quicktech-as/exchange-rate

> 标签: currency, exchange rate, illuminate, laravel

## 简介

Package Laravel to currency conversion using ExchangeRate API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
