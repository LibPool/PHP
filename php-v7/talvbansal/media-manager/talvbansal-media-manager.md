# talvbansal/media-manager

> 标签: Media Manager, Vue.js, blog, bootstrap, developers, easel, file uploader, files, laravel, media, minimal, uploader

## 简介

A media browser and uploader for laravel apps written in vue js and bootstrap

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
