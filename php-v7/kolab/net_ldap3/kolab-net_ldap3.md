# kolab/net_ldap3

> 标签: PEAR, ldap, vlv

## 简介

A successor of the PEAR:Net_LDAP2 module providing advanced functionality for accessing LDAP directories

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
