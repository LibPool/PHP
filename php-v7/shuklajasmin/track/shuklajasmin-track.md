# shuklajasmin/track

> 标签: PHP

## 简介

Track package helps you track your every URL. Also, the package delivered to you the number of open rates and delivery rate.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
