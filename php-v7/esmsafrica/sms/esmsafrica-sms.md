# esmsafrica/sms

> 标签: africa, bulk sms, esms, messaging, otp, sms

## 简介

Official PHP SDK for the eSMS Africa SMS API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
