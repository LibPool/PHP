# mpclarkson/stringy

> 标签: manipulation, object oriented, string, text

## 简介

A PHP Library that provides a consistent api for object oriented manipulation of strings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
