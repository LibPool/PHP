# api-swoole/sapi

> 标签: api-swoole, coroutine, php, swoole, tcp, udp, websocket

## 简介

基于swoole实现的一个轻量级框架，支持http、websocket、tcp、udp。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
