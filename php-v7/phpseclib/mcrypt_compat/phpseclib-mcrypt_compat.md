# phpseclib/mcrypt_compat

> 标签: cryptograpy, encryption, mcrypt, polyfill

## 简介

PHP 5.x-8.x polyfill for mcrypt extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
