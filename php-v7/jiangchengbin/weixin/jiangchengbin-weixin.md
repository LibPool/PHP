# jiangchengbin/weixin

> 标签: api, jiangchengbin, wei-xin

## 简介

Laravel 5 wrapper for the WeiXin API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
