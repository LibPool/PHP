# tristanfrn/pdf-invoice

> 标签: invoice, pdf, tristanfrn

## 简介

Library to generate PDF invoices - Fork for french format

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
