# radmas/vich-jms-integration

> 标签: bundle integration, integration

## 简介

Easy integration between VichUploaderBundle and JMSSerializerBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
