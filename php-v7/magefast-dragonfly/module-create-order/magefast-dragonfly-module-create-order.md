# magefast-dragonfly/module-create-order

> 标签: PHP

## 简介

Magento module Dragonfly_CreateOrder. Create order programmatically. Can use for the orders import.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
