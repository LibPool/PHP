# michaeldouglas/debeziumstream

> 标签: Douglas, consumer, debezium, kafka, michael

## 简介

A client library to work with debezium and apache kafka for Database stream.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
