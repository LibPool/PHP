# mamatveev/yii2-amazon-ses-mailer

> 标签: aws, extension, ses, yii2

## 简介

Extension for sending emails via amazon ses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
