# kch/pcc-3-deklaracja-bundle

> 标签: bundle, pcc, pcc-3, symfony

## 简介

Symfony 2 Bundle for PCC-3 declaration library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
