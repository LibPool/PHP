# kch/pcc-3-deklaracja

> 标签: pcc3

## 简介

Klasy umożliwiające budowę Deklaracji PCC3 i automatyczną budowę xml za pomocą JMS_Serializer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
