# skrepr/teams-connector

> 标签: ActionCard, Teams, card, microsoft, ms teams, php, section, webhook

## 简介

A simple PHP package for sending messages to Microsoft Teams

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
