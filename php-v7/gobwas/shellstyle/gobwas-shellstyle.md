# gobwas/shellstyle

> 标签: color, echo, output

## 简介

ShellStyle is a simple php class that allows you to get wrapped Unix/Linux colored output with ANSI escape codes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
