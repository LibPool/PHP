# unicodeveloper/laravel-hackathon-starter

> 标签: framework, laravel

## 简介

Boilerplate for building MVP web applications with Laravel & getting ahead in Hackathons

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
