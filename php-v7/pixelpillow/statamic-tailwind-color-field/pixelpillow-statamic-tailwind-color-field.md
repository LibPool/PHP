# pixelpillow/statamic-tailwind-color-field

> 标签: PHP

## 简介

This Statamic field type lets you choose Tailwind color names for use in the frontend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
