# ziack/zoho-crm-orm

> 标签: Zoho, Zoho CRM, ZohoCRM, orm

## 简介

An ORM like package used to manipulate data from your Zoho CRM Account through the API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
