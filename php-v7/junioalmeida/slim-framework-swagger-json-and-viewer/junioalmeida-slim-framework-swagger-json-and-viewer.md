# junioalmeida/slim-framework-swagger-json-and-viewer

> 标签: api, api-rest, framework, micro, slim, slim-framework, swagger

## 简介

Gera json Swagger e visualização da documentação por meio deste mesmo json.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
