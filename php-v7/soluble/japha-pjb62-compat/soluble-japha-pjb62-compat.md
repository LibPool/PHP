# soluble/japha-pjb62-compat

> 标签: Bridge, compatibility, java, phpjavabridge

## 简介

Soluble PHP Java bridge PJB62 compatibility layer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
