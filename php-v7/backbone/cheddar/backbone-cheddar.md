# backbone/cheddar

> 标签: cardpay, cheddar, comfortpay, czech republic, eplatby, gpwebpay, iterminal, latvia, money, payment, slovakia, sporopay, tatrapay, trustpay

## 简介

PHP bindings for Cheddar payment gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
