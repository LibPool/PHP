# markup/contentful-bundle

> 标签: cms, contentful

## 简介

A Symfony2 bundle to integrate with the Contentful APIs (Content Delivery and Content Management) for PHP 5.6+.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
