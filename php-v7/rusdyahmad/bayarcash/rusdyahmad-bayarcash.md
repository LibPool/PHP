# rusdyahmad/bayarcash

> 标签: bayarcash, duitnow, fpx, gateway, payment

## 简介

A PHP client library for integrating with the Bayarcash payment gateway, supporting FPX and DuitNow.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
