# seandowney/backpackstorecrud

> 标签: laravel backpack, manage products, shop, store

## 简介

Basic Store management interface for Laravel 5 using Backpack CRUD.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
