# eminos/statamic-feedback

> 标签: PHP

## 简介

Visual feedback and annotation tool for Statamic. Pin feedback to page elements, capture screenshots, @mention teammates, and track everything from the Control Panel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
