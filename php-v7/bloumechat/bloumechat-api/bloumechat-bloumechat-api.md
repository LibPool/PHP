# bloumechat/bloumechat-api

> 标签: api, bloumechat, module, oauth2, php

## 简介

PHP module pour interagir avec l'API OAuth2 de BloumeChat.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
