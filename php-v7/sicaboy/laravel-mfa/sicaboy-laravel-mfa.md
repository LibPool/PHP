# sicaboy/laravel-mfa

> 标签: 2-Factor, 2fa, Authentication, MFA, laravel, multi-factor, security, two-factor

## 简介

A Laravel package of Multi-factor Authentication (MFA/2FA) with a middleware.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
