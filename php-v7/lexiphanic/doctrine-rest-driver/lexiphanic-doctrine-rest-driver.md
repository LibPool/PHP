# lexiphanic/doctrine-rest-driver

> 标签: REST API doctrine ORM DBAL driver

## 简介

Use a REST API as if it was your local database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
