# ker0x/cake_gcm

> 标签: Google Cloud Messaging, cake3, cakephp, gcm

## 简介

CakeGCM is a plugin for CakePHP to send notification to an Android device through Google Cloud Messaging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
