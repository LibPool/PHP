# comicrelief/omnipay-worldpay-xml

> 标签: gateway, merchant, omnipay, pay, payment, worldpay

## 简介

WorldPay XML driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
