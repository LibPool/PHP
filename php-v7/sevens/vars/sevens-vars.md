# sevens/vars

> 标签: array manipulator, decrypt, encode, encrypt, string

## 简介

Simple Variable library Package For Encoding and Manipulating Strings and Arrays.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
