# industrious-mouse/laravel-dotmailer

> 标签: PHP

## 简介

Laravel wrapper for the dotmailer-api-v2-client library (https://github.com/romanpitak/dotmailer-api-v2-client)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
