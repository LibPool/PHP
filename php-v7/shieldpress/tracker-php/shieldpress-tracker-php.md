# shieldpress/tracker-php

> 标签: apm, laravel, monitoring, performance, php, security, shieldpress, tracking, uptime

## 简介

Website tracking, monitoring & security SDK for PHP — Laravel, Symfony, Slim, and vanilla PHP. Reports metrics to ShieldPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
