# fromholdio/silverstripe-formaction-link

> 标签: Forms, silverstripe

## 简介

A type of FormAction that renders as a link/anchor rather than button or input.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
