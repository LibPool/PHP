# milan-miscevic/inert

> 标签: action, action-container, controller, factory, framework, inert, mini-php-framework, mvc, php-framework, response, service-container

## 简介

Mini PHP framework with basic MVC and service container support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
