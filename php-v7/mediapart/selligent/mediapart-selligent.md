# mediapart/selligent

> 标签: api, client, mailing, selligent, soap

## 简介

Selligent Client API. Use to manage your Selligent data from PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
