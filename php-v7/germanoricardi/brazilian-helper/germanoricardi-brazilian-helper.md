# germanoricardi/brazilian-helper

> 标签: brazilian states, estados brasileiros, extension, extensão, php, php brasil, php brazil, php brazilian states, php cep, php cnpj, php cpf, php estados brasileiros

## 简介

PHP extension with Brazilian states and formats for CPF, CNPJ and ZIP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
