# rncosta/traducao_magento2_pt_br

> 标签: PHP

## 简介

Tradução para Português do Brasil oficial do Magento 2, seguindo algumas necessidades especificas de negócio

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
