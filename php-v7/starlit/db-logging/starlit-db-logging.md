# starlit/db-logging

> 标签: database, handler, logging, monolog, mysql, orm, pdo

## 简介

Adds logging for the starlit/db package by providing a database monolog handler.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
