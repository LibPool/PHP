# fast-elephant/laravel-regeo

> 标签: PHP

## 简介

逆地理解析 坐标转地址服务 优先请求QQ地图服务 失败后请求高德地图服务

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
