# lautr/qrcode-bundle

> 标签: bundle, code, endroid, qr, qrcode, symfony

## 简介

Endroid Qr Code Bundle for Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
