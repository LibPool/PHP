# greensea/keccak

> 标签: keccak, sha-3

## 简介

Pure PHP implementation of Keccak. Fork from kornrunner/php-keccak, support PHP 7.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
