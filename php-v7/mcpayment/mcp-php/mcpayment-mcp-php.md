# mcpayment/mcp-php

> 标签: mcpayment

## 简介

Official PHP package for MCPayment API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/mcpayment/mcp-php
