# mastercard/oauth1-signer

> 标签: mastercard, oauth1, oauth1a, openapi, php

## 简介

Zero dependency library for generating a Mastercard API compliant OAuth signature.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
