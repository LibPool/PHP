> 标签: PHPStan, contact-form, fluent-forms, static analysis, stubs, wordpress, wordpress-plugin

## 简介

Fluent Forms function and class declaration stubs for static analysis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
