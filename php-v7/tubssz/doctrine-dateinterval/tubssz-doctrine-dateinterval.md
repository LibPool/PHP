# tubssz/doctrine-dateinterval

> 标签: date, doctrine, interval

## 简介

Supports DateInterval in Doctrine DBAL and ORM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
