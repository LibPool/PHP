# samson/data-grid-bundle

> 标签: angular, angularjs, datagrid, datatables

## 简介

AngularJS based datagrid bundle for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
