# monarobase/country-list

> 标签: countries, laravel

## 简介

List of all countries with names and ISO 3166-1 codes in all languages and data formats for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
