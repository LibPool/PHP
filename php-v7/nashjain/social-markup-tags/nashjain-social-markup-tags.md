# nashjain/social-markup-tags

> 标签: facebook, open graph, opengraph, twitter cards

## 简介

Simple PHP Library to generate Open Graph protocol and Twitter Card markup tags for websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
