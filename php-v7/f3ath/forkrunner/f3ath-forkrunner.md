# f3ath/forkrunner

> 标签: execution, fork, parallel, pcntl, pcntl_fork, pcntl_waitpid

## 简介

A simple framework to run code in parallel processes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
