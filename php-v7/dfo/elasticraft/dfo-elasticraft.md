# dfo/elasticraft

> 标签: Craft, cms, craft-plugin, craftcms, elasticraft

## 简介

Elasticsearch plugin for Craft 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
