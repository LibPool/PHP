# paulyg/dbalite

> 标签: abstraction, database, mysql, pdo, postgres, query, sqlite

## 简介

A lightweight PDO based Database Abstraction Layer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
