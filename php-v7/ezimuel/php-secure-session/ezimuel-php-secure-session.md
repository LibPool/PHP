# ezimuel/php-secure-session

> 标签: Authentication, encrypt, session

## 简介

Encrypt and authenticate PHP session data using AES-256 and HMAC-SHA256

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
