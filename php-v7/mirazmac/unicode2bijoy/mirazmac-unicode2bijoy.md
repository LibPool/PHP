# mirazmac/unicode2bijoy

> 标签: bijoy, bijoy ansi, text, text processing, unicode

## 简介

PHP class to convert unicode to Bijoy ANSI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
