# mirazmac/php-deep-fry

> 标签: deep fry, deep fryer, image fryer, image processing, meme, meme fryer

## 简介

A Deep Fryer written in PHP to cook some smokin' hot memes!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
