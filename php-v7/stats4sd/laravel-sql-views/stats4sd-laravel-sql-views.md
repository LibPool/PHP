# stats4sd/laravel-sql-views

> 标签: laravel, sql

## 简介

A small package to help automate the creation and updating of MySQL views within a Laravel project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
