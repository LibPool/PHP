# atelierspierrot/webfilesystem

> 标签: directory, file, spl, webserver

## 简介

Extending the SPL file system to manage webserver based file system (such as assets).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
