# zizther/craftcms-ddev

> 标签: Craft, cms, craftcms, ddev

## 简介

A Craft CMS starter project using DDEV for local hosting and Vite for front-end bundling and HMR.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
