# veraandco/module-mongodb

> 标签: codeception, mongodb

## 简介

MongoDB module for Codeception with multidatabase support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://codeception.com/
- 源码仓库：https://github.com/neo3k/module-mongodb.git
- Packagist 页面：https://packagist.org/packages/veraandco%2Fmodule-mongodb
