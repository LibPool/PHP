# h4ck3r31/psalm-issue-filter-plugin

> 标签: PHP

## 简介

Allows to filter/skip code issues based on code snippets within PsalmPHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
