# alorel/alo-framework

> 标签: 5.4, framework, lightweight, mvc, php

## 简介

AloFramework is an incredibly lightweight and flexible MVC framework for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
