# red-jasmine/jwt-auth

> 标签: Authentication, jwt, laravel, red-jasmine

## 简介

JWT Authentication package for Red Jasmine Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
