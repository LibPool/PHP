# devjs/eloquent-resources

> 标签: PHP

## 简介

Package for generic resource classes. Interfaces, Controllers, Validations, Entities, Repositories, Criterias etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
