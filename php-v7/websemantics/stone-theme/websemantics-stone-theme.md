# websemantics/stone-theme

> 标签: addon, laravel, pyrocms, theme

## 简介

Responsive admin theme for PyroCMS 3 built with AdminLTE 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
