# lbhurtado/missive

> 标签: contacts, lbhurtado, missive, sms

## 简介

Add SMS domain to a Laravel project - route, models, migrations, jobs, notifications, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
