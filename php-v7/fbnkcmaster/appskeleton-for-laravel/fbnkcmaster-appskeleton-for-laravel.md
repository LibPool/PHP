# fbnkcmaster/appskeleton-for-laravel

> 标签: appskeleton, generator, laravel

## 简介

Custom artisan command for Laravel 5 to help speed up you web app development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
