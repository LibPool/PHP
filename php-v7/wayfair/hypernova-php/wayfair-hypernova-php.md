# wayfair/hypernova-php

> 标签: hypernova, react, wayfair

## 简介

A PHP client for hypernova.  https://github.com/airbnb/hypernova

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
