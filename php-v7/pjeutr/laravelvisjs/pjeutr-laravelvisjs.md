# pjeutr/laravelvisjs

> 标签: VISJS, chart, graphics, laravel5, pjeutr, reports

## 简介

Simple package to facilitate and automate the use of charts in Laravel 5.x using Visjs library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
