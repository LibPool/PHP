# suramon/sf-propel-sql-diff-plugin

> 标签: PHP

## 简介

Generate diff.sql file, which contains difference between schema.yml and current database structure

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
