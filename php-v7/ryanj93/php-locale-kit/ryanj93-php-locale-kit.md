# ryanj93/php-locale-kit

> 标签: localization, sqlite, sqlite3, translation

## 简介

A simple library that allows to manage language packages and translate texts with PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
