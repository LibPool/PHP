# loadsys/cakephp-loadsys-theme

> 标签: bake, cakephp, plugin, templates

## 简介

CakePHP 3.x bake generation theme that matches Loadsys' code sniffer standards.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
