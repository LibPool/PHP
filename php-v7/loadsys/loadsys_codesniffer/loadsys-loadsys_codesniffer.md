# loadsys/loadsys_codesniffer

> 标签: codesniffer, framework

## 简介

Loadsys CodeSniffer Standards, uses the CakePHP core team's as a base.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
