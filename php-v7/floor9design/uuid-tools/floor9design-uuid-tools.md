# floor9design/uuid-tools

> 标签: floor9design, uuid-tools

## 简介

A set of useful uuid tools to extend the `webpatser/laravel-uuid` package

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
