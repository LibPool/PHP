# orchestra/debug

> 标签: debug, laravel, orchestra-platform, orchestral, profiler

## 简介

Artisan Debug Profiler for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
