# fresh/firebase-cloud-messaging-bundle

> 标签: FCM, Firebase Cloud Messaging, Push-Notification, android, api client, bundle, cloud, firebase, ios, messaging, notification, push, symfony, web-push, web-push-notification

## 简介

Provides integration with Firebase Cloud Messaging API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
