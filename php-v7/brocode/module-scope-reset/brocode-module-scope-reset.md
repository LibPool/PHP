# brocode/module-scope-reset

> 标签: PHP

## 简介

Restore store-view attribute inheritance over the Magento 2 REST API by sending the CSV importer's empty-value constant

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
