# shfx17/zohocrmapi

> 标签: PHP

## 简介

ZohoAPI Plugin v1.0. Get data from ZohoCRM in Guzzle and add to database in CraftCMS do it using GraphQL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
