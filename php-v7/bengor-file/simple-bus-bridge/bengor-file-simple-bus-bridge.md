# bengor-file/simple-bus-bridge

> 标签: adapter, ddd, file, simple-bus

## 简介

Adapter to make File compatible with Matthias Noback's SimpleBus

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
