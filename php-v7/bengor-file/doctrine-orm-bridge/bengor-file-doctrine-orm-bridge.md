# bengor-file/doctrine-orm-bridge

> 标签: adapter, ddd, doctrine, file, orm

## 简介

Adapter to make File compatible with Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
