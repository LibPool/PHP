# labsllm/llm-wrapper

> 标签: PHP

## 简介

Biblioteca PHP que integra diferentes serviços de LLM (ChatGPT, Claude, Gemini) em um wrapper único

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
