# joelbutcher/laravel-facebook-graph

> 标签: facebook, facebook-graph, graph-sdk, laravel, php, php8

## 简介

Laravel wrapper for the Facebook Graph SDK for PHP 7.4 and PHP 8.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
