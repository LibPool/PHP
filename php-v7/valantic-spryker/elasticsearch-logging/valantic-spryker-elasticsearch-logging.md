# valantic-spryker/elasticsearch-logging

> 标签: spryker

## 简介

Adds spryker logclient to elasticsearch, you will be able to see executed elasticsearch api calls with its details.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
