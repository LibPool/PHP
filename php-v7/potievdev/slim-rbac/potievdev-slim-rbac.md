# potievdev/slim-rbac

> 标签: Authentication, authorization, middleware, potievdev, rbac, slim

## 简介

Role Based Access Control middleware for Slim 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
