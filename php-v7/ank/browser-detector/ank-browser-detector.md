# ank/browser-detector

> 标签: browser, detection, language, operating system, os, 操作系统, 浏览器, 设备型号

## 简介

根据UA判断浏览器类型和版本，操作系统，设备型号

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
