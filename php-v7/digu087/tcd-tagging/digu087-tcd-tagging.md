# digu087/tcd-tagging

> 标签: PHP

## 简介

Use PHP traits to extend Laravel Eloquent Models to allow Tags. Models can be marked as Taggable. You can also assocaite a tag with multiple groups

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
