# chineseboost/php-pinyin

> 标签: PHP

## 简介

Pinyin and hanzi tools in pure PHP | 纯PHP的汉语拼音和汉字工具

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
