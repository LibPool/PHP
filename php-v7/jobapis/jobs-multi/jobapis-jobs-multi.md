# jobapis/jobs-multi

> 标签: api client, job boards, jobs, multiple job boards

## 简介

Making it easy to get jobs from multiple job boards.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
