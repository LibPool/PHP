# fluoresce/doctrine-undeletable

> 标签: behaviour, delete, doctrine, undeletable, undeleteable

## 简介

Doctrine annotation to make entities undeletable.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
