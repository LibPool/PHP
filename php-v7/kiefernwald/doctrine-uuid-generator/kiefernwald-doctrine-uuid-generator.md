# kiefernwald/doctrine-uuid-generator

> 标签: auto, doctrine, identifier, uuid

## 简介

Use UUIDv4 as generated id in Doctrine ORM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
