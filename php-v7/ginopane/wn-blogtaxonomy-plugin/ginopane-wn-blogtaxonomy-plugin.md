# ginopane/wn-blogtaxonomy-plugin

> 标签: blog, cms, gino pane, taxonomy, wintercms

## 简介

A robust Winter CMS plugin which extends Winter Blog Plugin with useful taxonomies

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
