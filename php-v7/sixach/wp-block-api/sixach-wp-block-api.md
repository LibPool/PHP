# sixach/wp-block-api

> 标签: composer, library, wordpress

## 简介

Small collection of helpful interfaces and classes for the development of WordPress Blocks and Extensions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
