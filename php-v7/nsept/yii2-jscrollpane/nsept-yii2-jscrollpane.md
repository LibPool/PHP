# nsept/yii2-jscrollpane

> 标签: extension, jScrollPane, jquery, scroll, widget, yii2

## 简介

A jQuery plugin which allows you to replace a browser's default scrollbars.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
