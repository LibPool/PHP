# igorvolnyi/yii2-translit-cyrillic

> 标签: cyrillic, extension, translit, yii2

## 简介

Translit helper for Yii 2 framework. Forked from dkhlystov/yii2-translit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
