# amphp/artax

> 标签: async, client, http, non-blocking, parallel, rest

## 简介

Asynchronous parallel HTTP/1.1 client built on the Amp concurrency framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
