# verbanent/eloquent-binary-uuid

> 标签: binary, eloquent, hex, laravel, ordered, uuid

## 简介

Ordered binary UUID in Laravel / Eloquent based on UUID version 1

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
