# inwendo/slack-bundle

> 标签: api, bundle, logger, messaging, monolog, slack, symfony

## 简介

Symfony2 Integration for Slack - supporting Monolog

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
