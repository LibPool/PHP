# wizofgoz/crester

> 标签: PHP

## 简介

PHP library for interacting with the Eve Online CREST and XML APIs through a fluent, english-like interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
