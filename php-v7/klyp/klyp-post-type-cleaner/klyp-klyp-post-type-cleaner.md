# klyp/klyp-post-type-cleaner

> 标签: cleaner, plugin, post type, wordpress

## 简介

This plugin allows you to clean your database by deleting obsolete post types.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
