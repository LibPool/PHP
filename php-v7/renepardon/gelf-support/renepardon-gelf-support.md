# renepardon/gelf-support

> 标签: gelf-support, laravel, renepardon, symfony

## 简介

A composer compliant package to support GELF logging within laravel/symfony projects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
