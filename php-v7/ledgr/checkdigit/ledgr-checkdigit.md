# ledgr/checkdigit

> 标签: Check digit, luhn, modulo 10, modulo 11, modulo 97

## 简介

Helper classes to calculate and validate ckecksums

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
