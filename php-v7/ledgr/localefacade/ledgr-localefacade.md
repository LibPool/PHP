# ledgr/localefacade

> 标签: intl, locale, symfony locale

## 简介

OO wrapper to symfony/locale (and the Locale class of the Intl extension)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
