# zobe/taskinfo

> 标签: PHP

## 简介

`zobe/taskinfo` is in process messaging base classes which is mainly targeted to amphp coroutines

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
