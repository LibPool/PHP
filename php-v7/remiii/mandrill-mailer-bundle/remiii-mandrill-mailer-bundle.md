# remiii/mandrill-mailer-bundle

> 标签: api, bundle, mail, mailer, mandill, swiftmailer, symfony

## 简介

MandrillMailerBundle add support for Mandrill API on Swiftmailer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
