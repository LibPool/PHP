# alfnru/user_alias

> 标签: Authentication, alias, login, security

## 简介

Plugin allows users to log in using aliases (user and/or domain) from Postfix

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
