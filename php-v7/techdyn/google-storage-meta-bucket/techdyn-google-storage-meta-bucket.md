# techdyn/google-storage-meta-bucket

> 标签: PHP

## 简介

A simple GCP storage bucket wrapper to automatically set metadata (cache-control, etc) on uploaded files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
