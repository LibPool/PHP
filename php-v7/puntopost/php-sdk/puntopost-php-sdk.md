# puntopost/php-sdk

> 标签: api, delivery, logistics, mexico, parcel, pudo, puntopost, sdk, shipment

## 简介

Official PHP SDK for the PuntoPost parcel delivery API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
