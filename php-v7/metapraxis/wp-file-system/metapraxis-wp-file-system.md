# metapraxis/wp-file-system

> 标签: files, filesystem, uploads, wordpress, wp-filesystem

## 简介

A safe and convenient object-oriented wrapper for the WordPress Filesystem API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
