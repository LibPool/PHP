# typrint/phinx

> 标签: database, database migrations, db, migrations, phinx

## 简介

Phinx makes it ridiculously easy to manage the database migrations for your PHP app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
