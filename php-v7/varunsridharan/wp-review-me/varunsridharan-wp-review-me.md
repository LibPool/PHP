> 标签: codecanyon, envato, envato-market, paid themes, plugin review, review, templatemonster, theme review, themeforest, wordpress, wordpress plugin, wordpress review, wordpress theme

## 简介

This library provides developers to ask end user to review their product (theme / plugin)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
