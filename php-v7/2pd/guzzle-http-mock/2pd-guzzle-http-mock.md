# 2pd/guzzle-http-mock

> 标签: Guzzle, client, http, mock, mocking, testing

## 简介

A mock library for verifying requests made with the Guzzle Http Client, and mocking responses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
