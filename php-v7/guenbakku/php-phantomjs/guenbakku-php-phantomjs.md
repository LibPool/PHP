# guenbakku/php-phantomjs

> 标签: Headless Browser, phantomjs, testing

## 简介

A PHP wrapper for loading pages through PhantomJS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
