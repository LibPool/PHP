# svg-edit/svgedit

> 标签: drawing, editor, svg, svg-edit

## 简介

SVG-edit is a fast, web-based, javascript-driven SVG drawing editor that works in any modern browser.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
