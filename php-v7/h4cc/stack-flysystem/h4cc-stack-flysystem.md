# h4cc/stack-flysystem

> 标签: files, http, rest, stack

## 简介

A Stack HttpKernel for Flysystem filesystems as a single purpose application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
