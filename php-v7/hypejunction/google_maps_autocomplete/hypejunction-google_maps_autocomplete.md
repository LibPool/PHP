# hypejunction/google_maps_autocomplete

> 标签: autocomplete, elgg, location, maps, plugin

## 简介

Replaces location input with Google Maps Autocomplete

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
