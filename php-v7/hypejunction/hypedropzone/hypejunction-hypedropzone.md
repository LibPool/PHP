# hypejunction/hypedropzone

> 标签: drag-n-drop, dropzone, elgg, plugin, upload

## 简介

Drag-n-drop file uploads for Elgg

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
