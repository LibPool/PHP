# hypejunction/ckeditor_addons

> 标签: CKEditor, elgg, plugin, wysiwyg

## 简介

Improved CKEditor for Elgg

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
