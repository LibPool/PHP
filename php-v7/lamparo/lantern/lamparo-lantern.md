# lamparo/lantern

> 标签: drupal, lamparo, monitoring, php, wordpress

## 简介

La lanterne de lamparo : un fichier posé sur un site pour en lire l'état, en lecture seule.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
