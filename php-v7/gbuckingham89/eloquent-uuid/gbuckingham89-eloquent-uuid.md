# gbuckingham89/eloquent-uuid

> 标签: eloquent, laravel, php, uuid

## 简介

A simple package for using UUID's (UUID4) with Laravel's Eloquent.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
