# franciscoernestoteixeira/show-dependencies

> 标签: cli, composer, dependencies, lock, packagist, versions

## 简介

CLI tool to list installed Composer dependencies with their actual installed versions (from composer.lock or vendor/).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
