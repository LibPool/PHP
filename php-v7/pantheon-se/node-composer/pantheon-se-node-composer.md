# pantheon-se/node-composer

> 标签: Node.js, frontend, javascript, npm, yarn

## 简介

Installs Node.js, NPM, and Yarn into vendor/bin

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
