# pantheon-se/pantheon_autopilot_demo

> 标签: PHP

## 简介

Simple demo to showcase Pantheon Autopilot VRT detection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
