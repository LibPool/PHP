# slince/process

> 标签: child process, fork, pcntl, pipe, posix, process, semaphore, shared memory, system v

## 简介

The process wrapper and manager based on pcntl and posix.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
