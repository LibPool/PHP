# slince/smartqq

> 标签: php-qq, php-smartqq, php-webqq, qq, smartqq, webqq

## 简介

The wrapper for smartqq api using php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
