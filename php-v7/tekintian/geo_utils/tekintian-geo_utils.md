# tekintian/geo_utils

> 标签: GPS坐标, WGS-84转换工具, 国测局火星坐标GCJ-02转换工具, 工具, 百度坐标 BD-09转换工具

## 简介

目前最全面的地理坐标转换工具，支持GPS坐标 WGS-84，百度坐标 BD-09，国测局 火星坐标GCJ-02之间的相互转换

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
