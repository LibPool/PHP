# tekintian/curl_http_request

> 标签: PHP cURL, curl, curl http请求类, 伪装IP, 工具

## 简介

超级灵活，强大，可自定义的curl http请求类， 可伪装来源，agent, 伪装IP地址等等，支持POST, GET等方式

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
