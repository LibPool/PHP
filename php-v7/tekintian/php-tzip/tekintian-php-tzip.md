# tekintian/php-tzip

> 标签: archive tool, php archive, php download, zip, zip压缩工具, 压缩工具, 工具

## 简介

一个简单快速的zip文件压缩打包下载工具类,支持PHP5,php7, php8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
