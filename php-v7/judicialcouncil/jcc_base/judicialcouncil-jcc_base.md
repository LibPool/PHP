# judicialcouncil/jcc_base

> 标签: PHP

## 简介

JCCBase is a base theme for Drupal. Integrates Exygy/courtyard pattern library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
