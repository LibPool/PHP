# social-media/social-media-facebook

> 标签: facebook, php, social media

## 简介

This Social Media Facebook PHP Class can (un)publish posts to Facebook.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
