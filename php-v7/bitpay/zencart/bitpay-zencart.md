# bitpay/zencart

> 标签: bitcoin, bitpay, ecommerce, payment, plugin, zencart

## 简介

BitPay payment plugin for ZenCart

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
