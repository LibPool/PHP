# bitpay/prestashop

> 标签: bitcoin, bitpay, ecommerce, payment, plugin, prestashop

## 简介

BitPay payment plugin for PrestaShop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
