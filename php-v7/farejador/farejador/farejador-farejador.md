# farejador/farejador

> 标签: PHP

## 简介

Script para realizar sniff (phpcs) de código legado em projetos que utilizam git como VCS, considerando apenas as linhas alteradas

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
