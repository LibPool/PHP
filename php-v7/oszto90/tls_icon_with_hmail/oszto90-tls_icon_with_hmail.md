# oszto90/tls_icon_with_hmail

> 标签: icon, logging, ssl, tls

## 简介

Displays a lock next to the message if it was received using TLS1.2 or 1.3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
