# novactive/phpcs-novastandards

> 标签: checkstyle, codesniffer, ez publish, psr2, standards

## 简介

Novactive PHP_CodeSniffer coding standards for eZ Publish, Symfony2, ...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
