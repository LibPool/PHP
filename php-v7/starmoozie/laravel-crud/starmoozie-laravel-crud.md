# starmoozie/laravel-crud

> 标签: Admin Interface, Content management system, admin panel, admin panel for laravel, base, bootstrap 4 admin panel laravel, bread, cms, content management framework, coreui for laravel, create, crud, delete, laravel admin, read, starmoozie, update

## 简介

Quickly build an admin interfaces using Laravel, CoreUI, Bootstrap and jQuery.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
