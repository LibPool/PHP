# dropbox-factory/dropbox-factory

> 标签: Dropbox API, dropbox client

## 简介

Lightweight factory class for managing Dropbox API instance

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
