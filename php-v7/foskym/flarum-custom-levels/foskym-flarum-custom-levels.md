# foskym/flarum-custom-levels

> 标签: custom, extension, flarum, levels, user

## 简介

Flarum Custom Levels, levels can be customized, and can trigger events.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
