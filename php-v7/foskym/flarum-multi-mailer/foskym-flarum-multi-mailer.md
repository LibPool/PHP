# foskym/flarum-multi-mailer

> 标签: flarum, mailer, multi, smtp

## 简介

Allow you to use different smtp configs determined by user email domain suffix.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
