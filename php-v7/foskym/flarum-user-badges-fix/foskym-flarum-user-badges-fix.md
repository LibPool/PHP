# foskym/flarum-user-badges-fix

> 标签: flarum

## 简介

Fix notifications error caused by user badges because of no badges included in some pages without UserSerializer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
