# custom-d/laravel-legacy-soft-deletes

> 标签: customd, laravel-legacy-soft-deletes

## 简介

Packages to allow us to use legacy soft deleting in laravel to deal with our zon modules

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
