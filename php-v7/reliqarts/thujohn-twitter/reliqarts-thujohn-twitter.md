# reliqarts/thujohn-twitter

> 标签: laravel, laravel6, thujohn, twitter

## 简介

Twitter API for Laravel. Literally the Twitter API built by thujohn, supporting Laravel ^6.0.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
