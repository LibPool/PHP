# intaro/pinba-bundle

> 标签: php, pinba, symfony

## 简介

Collects and sends execution time of Doctrine queries, Twig renders and Redis requests as pinba timers to pinba server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
