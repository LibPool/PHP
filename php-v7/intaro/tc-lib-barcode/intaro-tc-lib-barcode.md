# intaro/tc-lib-barcode

> 标签: 3 of 9, ANSI MH10.8M-1983, CBC, CODABAR, CODE 11, CODE 128 A B C, CODE 39, CODE 93, EAN 13, EAN 8, ECC200, Intelligent Mail Barcode, Interleaved 2 of 5, KIX, Klant, MSI, Onecode, PHARMACODE, PHARMACODE TWO-TRACKS, POSTNET, RMS4CC, Standard 2 of 5, UPC-A, UPC-E, USD-3, USPS-B-3200, USS-93, barcode, datamatrix, pdf417, planet, qr-code, royal mail, tc-lib-barcode, upc

## 简介

PHP library to generate linear and bidimensional barcodes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
