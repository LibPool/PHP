# laravel-enso/user-groups

> 标签: laravel-enso, user-groups, vue-bulma, vue-spa

## 简介

User group management backend for Laravel Enso

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
