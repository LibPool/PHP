# polevaultweb/edd-sl-plugin-updater

> 标签: edd, updates, wordpress

## 简介

Easy Digital Downloads WordPress plugin updater class for Software Licenses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
