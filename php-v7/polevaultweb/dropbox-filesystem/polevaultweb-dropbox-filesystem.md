# polevaultweb/dropbox-filesystem

> 标签: codeception, dropbox, filesystem

## 简介

Dropbox extension of the Codeception Filesystem module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
