# softpampa/moip-assinaturas-php

> 标签: assinaturas, moip, pagamentos, payments, subscriptions

## 简介

Biblioteca simples de integração com a API de Assinatura da MoiP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
