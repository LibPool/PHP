# nanapi/cakephp-fluent-logger

> 标签: cakephp, fluent, log, plugin

## 简介

Fluent log engine plugin for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
