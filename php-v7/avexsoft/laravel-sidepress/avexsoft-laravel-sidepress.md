# avexsoft/laravel-sidepress

> 标签: Sidepress, laravel, wordpress

## 简介

Let Wordpress share the same domain root, side-by-side, with Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
