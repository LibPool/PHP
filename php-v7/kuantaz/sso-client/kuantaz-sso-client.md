# kuantaz/sso-client

> 标签: Authentication, MDS, SSO, chile, laravel

## 简介

Cliente SSO para integración con el sistema de autenticación del Ministerio de Desarrollo Social de Chile

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
