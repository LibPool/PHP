# delatbabel/nestedmenus

> 标签: eloquent, heirarchy, l5, laravel, laravel5, menus

## 简介

A Laravel 5 package for nested menus with database storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
