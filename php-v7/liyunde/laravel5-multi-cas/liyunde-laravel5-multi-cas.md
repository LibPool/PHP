# liyunde/laravel5-multi-cas

> 标签: MultiCAS, SSO, cas, laravel, phpCAS

## 简介

Multi CAS server SSO authentication for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
