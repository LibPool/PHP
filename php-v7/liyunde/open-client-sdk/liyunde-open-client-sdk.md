# liyunde/open-client-sdk

> 标签: AliPay Like, Uboxol, open client, sop

## 简介

开放平台SDK,非对称加密开放平台客户端,类似支付宝开放平台的客户端功能,支持SOP服务网关

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
