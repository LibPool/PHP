# garethp/php-ews

> 标签: Microsoft Exchange, NTLM, calendar, contacts, email, ews, exchange web services, php, push notification, soap

## 简介

A PHP Library to interact with the Exchange SOAP service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
