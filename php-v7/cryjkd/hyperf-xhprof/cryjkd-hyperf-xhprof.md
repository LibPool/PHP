# cryjkd/hyperf-xhprof

> 标签: analysis, flamegraph, hyperf, performance, profiler, swoole, xhprof

## 简介

A coroutine-safe, xhprof-style performance profiler for Hyperf 2.2 and 3.1 (no C extension required).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
