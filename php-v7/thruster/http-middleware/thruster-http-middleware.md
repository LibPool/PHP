> 标签: http, http-middleware, httpmidldeware, middleware, middlewares, psr-7, thruster

## 简介

Thruster HttpMiddleware Component (PSR-7 based middlewares dispatcher)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
