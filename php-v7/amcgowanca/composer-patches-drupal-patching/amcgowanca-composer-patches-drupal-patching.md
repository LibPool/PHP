# amcgowanca/composer-patches-drupal-patching

> 标签: PHP

## 简介

A work-around solution for patching Drupal 8 core with cweagans/composer-patches.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
