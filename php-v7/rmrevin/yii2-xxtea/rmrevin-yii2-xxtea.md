# rmrevin/yii2-xxtea

> 标签: encrypt, xxtea, yii2

## 简介

Extension for yii2 encryption algorithm XXTEA

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
