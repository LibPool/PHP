# xsme/php-api-adescom

> 标签: adescom, api, pbx, soap, telecommunication

## 简介

PHP library for communication with Adescom PBX system via SOAP API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
