# bigfork/silverstripe-oauth

> 标签: Authentication, oauth, oauth2, silverstripe

## 简介

SilverStripe OAuth2 authentication, based on the PHP League's OAuth2 client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
