# bigfork/supergroupedlist

> 标签: grouped, groupedlist, list, silverstripe

## 简介

An extension of SilverStripe’s GroupedList that supports traversing relations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
