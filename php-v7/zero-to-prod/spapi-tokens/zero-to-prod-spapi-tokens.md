# zero-to-prod/spapi-tokens

> 标签: spapi-tokens, zero-to-prod

## 简介

Get a Restricted Data Token (RDT) for Amazon Selling Partner API (SPAPI).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
