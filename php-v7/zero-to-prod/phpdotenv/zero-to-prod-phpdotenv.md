# zero-to-prod/phpdotenv

> 标签: phpdotenv, zero-to-prod

## 简介

Loads environment variables from `.env` to `getenv()`, `$_ENV`

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
