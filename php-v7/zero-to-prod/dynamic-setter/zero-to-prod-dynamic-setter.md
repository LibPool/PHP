# zero-to-prod/dynamic-setter

> 标签: Dynamic Setter, dynamic-setter, zero-to-prod

## 简介

Fluently set class properties with dynamic methods.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
