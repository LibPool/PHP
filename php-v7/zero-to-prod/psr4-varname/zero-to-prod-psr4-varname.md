# zero-to-prod/psr4-varname

> 标签: psr4 varname, psr4-varname, zero-to-prod

## 简介

Generates a valid PSR-4 Compliant variable name from a string.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
