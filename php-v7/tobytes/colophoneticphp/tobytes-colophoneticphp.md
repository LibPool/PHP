# tobytes/colophoneticphp

> 标签: cologne, phonetic, php

## 简介

A class for retrieving the cologne phonetic (Kölner Phonetik) value of a string.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
