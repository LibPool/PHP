# flatorb/gamification

> 标签: Gamification, badges, flatorb, laravel, membership, points

## 简介

Add gamification to Laravel with points, reputation, member levels, and badges.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
