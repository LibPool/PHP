# placecodex/coinparams-bitwasp-addon

> 标签: PHP

## 简介

These are addon classes to integrate bitwasp bitcoin-php with coinparams for multicoin functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
