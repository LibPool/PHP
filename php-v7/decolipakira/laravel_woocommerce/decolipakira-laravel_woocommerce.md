# decolipakira/laravel_woocommerce

> 标签: PHP

## 简介

Esta é uma biblioteca para facilitar a integração com a API do WooCommerce utilizando o framework Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
