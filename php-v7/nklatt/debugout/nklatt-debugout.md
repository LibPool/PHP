# nklatt/debugout

> 标签: debug, logger, logging, output, package

## 简介

DebugOut for PHP, for tracing code execution the old-fashioned way: with printlines.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
