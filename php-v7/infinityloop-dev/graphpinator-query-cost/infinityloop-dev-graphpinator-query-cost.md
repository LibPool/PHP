# infinityloop-dev/graphpinator-query-cost

> 标签: PHP

## 简介

Modules to limit maximum query cost by resticting maximum depth or number of nodes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
