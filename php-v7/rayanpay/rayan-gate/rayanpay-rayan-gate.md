# rayanpay/rayan-gate

> 标签: Bank, gateways, payment, rayanpay, rest, soap

## 简介

The gateway is the interface between the acceptor and the bank payment gateways.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
