# promisepay/promisepay-php

> 标签: api, escrow, marketplace, marketplace payments, payments, promisepay

## 简介

PHP SDK for the PromisePay API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
