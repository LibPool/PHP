# frknikiz/laravel-quick-elfinder

> 标签: elfinder, laravel, laravel4.2, package, quick

## 简介

Laravel Quick Elfinder package allows you to use Elfinder quickly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
