# sms77/prestashop-api

> 标签: communication, marketing, prestashop, sms

## 简介

Sms77.io module for PrestaShop 1.6 & 1.7 applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
