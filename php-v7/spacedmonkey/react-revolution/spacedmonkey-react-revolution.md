# spacedmonkey/react-revolution

> 标签: themes, wordpress

## 简介

A WordPress theme based on the _s by Automattic, but uses react and REST API to render content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
