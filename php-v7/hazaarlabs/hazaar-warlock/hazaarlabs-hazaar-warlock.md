# hazaarlabs/hazaar-warlock

> 标签: WebSockets, hazaar, hmvc, php, signals

## 简介

A realtime signalling engine for Hazaar MVC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
