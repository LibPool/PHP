# hazaarlabs/hazaar-dbi

> 标签: database, hazaar, hmvc, pdo, php

## 简介

The DataBase Interface for Hazaar MVC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
