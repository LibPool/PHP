# johnie/talandewebb

> 标签: accessibility, plugin, screenreader, wordpress

## 简介

WordPress plugin for Funka Nu screen reader application Talande Webb Plus

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
