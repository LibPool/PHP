# steffenmaechtel/exception_handling_for_typo3_db

> 标签: cms, typo3

## 简介

TYPO3 CMS extension: Throw exception in case of error instead of show error with DebugUtility::debug

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
