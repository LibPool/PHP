# matthiasnoback/php-coding-dojo

> 标签: PHP

## 简介

Empty project which can be used in a PHP and PHPUnit-oriented coding dojo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
