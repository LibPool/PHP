# we-push-it/yii2-splunk-log-target

> 标签: extension, log, splunk, yii

## 简介

Yii 2 log target which can log to Splunk Enterprise via curl

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
