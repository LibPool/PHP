> 标签: analyser, command line, compressor, database, database query log, export, laravel, memory, performance, performance tool, php, php performance analyser, php performance tool, php-performance, query, query analyser, query log, terminal, time, web

## 简介

PHP performance tool analyser your script on time, memory usage and db query. Support Laravel and Composer for web, web console and command line interfaces.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
