# rekalogika/domain-event-outbox

> 标签: Microservice, cqrs, ddd, doctrine, domain, domain-driven-design, domain-event, event, event-dispatcher, event-listener, outbox, symfony

## 简介

Implementation of the transactional outbox pattern on top of rekalogika/domain-event

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
