# rekalogika/gotenberg-pdf-bundle

> 标签: margin, paper, pdf, print

## 简介

Symfony Bundle for generating PDF using Gotenberg API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
