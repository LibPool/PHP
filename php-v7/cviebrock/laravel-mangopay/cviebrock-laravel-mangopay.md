# cviebrock/laravel-mangopay

> 标签: laravel, lumen, mangopay, payments

## 简介

Laravel/Lumen wrapper for the office Mangopay SDK library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
