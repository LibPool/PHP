# milesasylum/schnoop-schema

> 标签: database, ddl, mysql, sql

## 简介

Schnoop Schema is a collection of PHP classes for describing a MySQL database schema.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
