# rosell-dk/exec-with-fallback

> 标签: command, exec, fallback, open_proc, resiliant, sturdy

## 简介

An exec() with fallback to emulations (proc_open, etc)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
