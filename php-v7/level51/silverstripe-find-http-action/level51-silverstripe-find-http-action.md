# level51/silverstripe-find-http-action

> 标签: crud, http, silverstripe, silverstripe-trait

## 简介

Finds actions by HTTP method used on the request.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
