# shyevsa/yii2-redis-sentinel

> 标签: redis, sentinel, yii2

## 简介

Yii2 Redis Connection with auto resolve redis `host` and `port` master from redis-sentinel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
