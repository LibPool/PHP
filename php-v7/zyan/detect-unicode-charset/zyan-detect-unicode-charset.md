# zyan/detect-unicode-charset

> 标签: 判断包含中文, 判断包含日文, 判断包含泰文, 判断包含韩文, 判断字符串, 字符串, 字符串工具

## 简介

判断字串中包含中文、日文、韩文、或泰文等各国语言文字的方法

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
