# kkguan/ide-helper

> 标签: PHP

## 简介

Yaf、Yar、Yac、Yaconf、Redis、Swoole等框架或C扩展代码自动补全

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
