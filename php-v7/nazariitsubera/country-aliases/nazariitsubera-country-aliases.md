# nazariitsubera/country-aliases

> 标签: PHP

## 简介

ISO 3166-1 alpha-2 lookup for thousands of dirty country spellings, plus a PHP helper.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
