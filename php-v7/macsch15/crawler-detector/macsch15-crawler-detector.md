# macsch15/crawler-detector

> 标签: bot, botdetector, crawler, crawlerdetector, useragent

## 简介

Fat-free, standalone and fast web crawler (bot) detector

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
