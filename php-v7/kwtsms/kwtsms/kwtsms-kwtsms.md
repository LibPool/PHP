# kwtsms/kwtsms

> 标签: kuwait, kwtsms, messaging, notification, otp, sms, sms-gateway

## 简介

kwtSMS API Client for PHP. Official library to interface with the Kuwait SMS gateway (kwtsms.com)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
