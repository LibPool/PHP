# andvab/geonames-bundle

> 标签: Symfony2, geonames

## 简介

Geonames bundle. Create tables and populate them with data from the service Geonames.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
