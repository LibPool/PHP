# revoke/websockets-rabbitmq

> 标签: WebSockets, framework, ipub, ipublikuj, nette, tools, zeromq, zmq

## 简介

RabbitMQ pusher & consumer implementation for ipub/websockets-wamp

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
