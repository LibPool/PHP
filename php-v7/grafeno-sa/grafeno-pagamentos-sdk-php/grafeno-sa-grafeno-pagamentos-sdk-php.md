# grafeno-sa/grafeno-pagamentos-sdk-php

> 标签: FIDC, ccb, charges, cnab, escrow, grafeno, payments, transfers

## 简介

SDK desenvolvido em PHP para integração com as APIs da grafeno.digital.

按 require.php 推断最低支持 PHP 6；已收录于 php-v7, php-v8。
