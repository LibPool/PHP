# icit/wp-less

> 标签: PHP

## 简介

Provides a LESS compiler compatible with wp_enqueue_style() for rapid CSS development in themes and plugins.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
