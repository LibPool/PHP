# serpapi/serpapi-php

> 标签: SERP, api, apple, client, curl, datamining, duckduckgo, google, homedepot, json, learning, localisation, ml, naver, rest, result, scrape, search, store, walmart, xml, yandex, youtube

## 简介

Get Google, Bing, Baidu, eBay, Yahoo, Yandex, Home Depot, Naver, Apple, DuckDuckGo, Yelp and YouTube search results via SerpApi.com

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
