# arminvieweg/slim-routing-manager

> 标签: router, routing, routing manager, slim, slimframework

## 简介

Controller and annotation based routing for the Slim Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
