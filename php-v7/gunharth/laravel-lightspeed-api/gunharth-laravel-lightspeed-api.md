# gunharth/laravel-lightspeed-api

> 标签: api, laravel, laravel-lightspeed-api, lightspeed, seoshop

## 简介

A Laravel wrapper for the Lightspeed Seoshop API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
