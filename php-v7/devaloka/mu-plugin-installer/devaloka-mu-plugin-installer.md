# devaloka/mu-plugin-installer

> 标签: composer, installer, mu-plugin, plugin, wordpress

## 简介

A Composer Installer for WordPress MU plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
