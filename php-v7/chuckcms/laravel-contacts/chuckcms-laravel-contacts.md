# chuckcms/laravel-contacts

> 标签: chuckcms, contacts, laravel, module

## 简介

An easy way for attaching contacts to Eloquent models in Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
