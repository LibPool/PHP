# kanedo/bedrock-vagrant

> 标签: capistrano, composer, stack, vagrant, wordpress, wp

## 简介

A modern WordPress stack with Vagrant forked from roots/bedrock

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
