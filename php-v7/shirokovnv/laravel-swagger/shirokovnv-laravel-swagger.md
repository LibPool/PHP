# shirokovnv/laravel-swagger

> 标签: auto-documentation, laravel, rest-api, swagger, testing

## 简介

The fork of the ronasit/laravel-swagger repo. Provided middleware for generating of swagger-documentation file by run testing of RESTful API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
