# codersandip/telescope-exporter

> 标签: Postman, curl, export, laravel, telescope

## 简介

Convert Laravel Telescope requests to Postman Collections and cURL commands

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
