# eluhr/yii2-uuid-attribute-behavior

> 标签: Behavior, extension, uuid, yii2

## 简介

This behavior automatically generates a UUID for the given attribute on create.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
