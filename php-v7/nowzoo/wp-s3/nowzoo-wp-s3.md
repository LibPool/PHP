# nowzoo/wp-s3

> 标签: aws, cloudfront, s3, wordpress

## 简介

Stores WordPress uploads on Amazon S3. Optionally allows you to use a Cloudfront distribution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
