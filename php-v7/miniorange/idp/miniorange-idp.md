# miniorange/idp

> 标签: PHP

## 简介

Miniorange Saml IDP Extension provides SSO/Login to any of your third party site using Typo3 user credentials

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
