# miniorange/keycloak_sso

> 标签: PHP

## 简介

Keycloak SSO extension for Typo3 allows your backend and frontend users to log into TYPO3 using Keycloak credentials.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
