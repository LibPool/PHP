# eventee/eventee

> 标签: event, event-dispatcher, event-emitter, observer

## 简介

Eventee is a minimalistic and powerfull event dispatching library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
