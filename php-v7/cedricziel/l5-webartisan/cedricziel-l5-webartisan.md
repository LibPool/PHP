# cedricziel/l5-webartisan

> 标签: artisan, laravel, laravel5

## 简介

Artisan for the web. Execute Artisan command on a webpage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
