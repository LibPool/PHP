# cedricziel/doctrine-driver-pdo-pgsql

> 标签: PHP

## 简介

A doctrine dbal driver for PostgreSQL that honors the unix_socket option

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
