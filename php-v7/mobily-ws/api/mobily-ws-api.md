# mobily-ws/api

> 标签: api, mobily, mobily.ws, sms

## 简介

Mobily-api is the PHP library for sending sms through internet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://mobily.ws/
- 源码仓库：https://github.com/mobily-ws/api.git
- Packagist 页面：https://packagist.org/packages/mobily-ws%2Fapi

## 获取地址

- Composer 安装：`composer require mobily-ws/api`
- Packagist 仓库：https://repo.packagist.org/p2/mobily-ws/api.json
