# bahaso/aminin-passport-client

> 标签: PHP

## 简介

Aminin Passport Client provides Resource server of Auth server (OAuth2 server <Aminin Passport>)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
