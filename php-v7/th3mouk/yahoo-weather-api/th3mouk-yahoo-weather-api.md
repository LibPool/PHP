# th3mouk/yahoo-weather-api

> 标签: api, forecasts, weather, yahoo, yahoo api

## 简介

A PHP weather forecast library based on Yahoo Weather API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
