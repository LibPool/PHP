# th3mouk/cms-content-manager-bundle

> 标签: bundle, cms, content, manager, symfony

## 简介

Simple content manager bundle for Symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
