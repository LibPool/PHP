# riipandi/laravel-optikey

> 标签: laravel, nanoid, ulid, uuid

## 简介

Use UUID, Ulid, or nanoid as optional or primary key in Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
