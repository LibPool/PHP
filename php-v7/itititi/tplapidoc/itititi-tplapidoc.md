# itititi/tplapidoc

> 标签: api, doc, php, tplapidoc

## 简介

基于自定义模板，生成你想要的api文档。简单易用且具备可拓展性。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
