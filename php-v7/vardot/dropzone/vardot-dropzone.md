# vardot/dropzone

> 标签: drag and drop, dragndrop, drupal, drupal-library, file upload, upload

## 简介

Dropzone distribution build, laid out for Drupal, packaged as a Drupal library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
