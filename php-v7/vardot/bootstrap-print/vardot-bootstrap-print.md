# vardot/bootstrap-print

> 标签: PHP

## 简介

Bootstrap print for Bootstrap v3. Mange grids using Bootstrap v3 for printed media.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
