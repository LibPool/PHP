# vardot/ace

> 标签: ace, code editor, drupal, drupal-library, editor

## 简介

Ace (Ajax.org Cloud9 Editor) minified no-conflict build, packaged as a Drupal library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
