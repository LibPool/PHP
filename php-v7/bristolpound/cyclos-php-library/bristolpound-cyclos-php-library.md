# bristolpound/cyclos-php-library

> 标签: Cyclos

## 简介

Official API library for integrating 3rd party software with the Cyclos 4 software (http://www.cyclos.org)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网
