# index-now-ru/sdk

> 标签: Sitemap, crawl-audit, indexnow, llms, seo, индексация

## 简介

Серверный PHP SDK для REST API Index-Now.ru: отправка URL, статусы, статистика и облачный краулинг-аудит.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
