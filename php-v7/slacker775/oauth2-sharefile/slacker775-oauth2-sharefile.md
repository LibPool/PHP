# slacker775/oauth2-sharefile

> 标签: oauth, oauth2, sharefile

## 简介

ShareFile OAuth 2.0 Client Provider for the PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
