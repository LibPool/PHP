# mvccore/example-cdcol

> 标签: Authentication, albums, auth, cd albums, cd collection, cds, credentials, crud, crud application, crud sample, framework, login, mvccore

## 简介

MvcCore Example - CD collection - classic CRUD example with default SQLite database and authentication.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
