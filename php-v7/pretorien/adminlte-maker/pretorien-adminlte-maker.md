# pretorien/adminlte-maker

> 标签: AdminLTE, crud

## 简介

AdminLTE Maker helps you create controllers and templates boostraped for AdminLTE theme bundle

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
