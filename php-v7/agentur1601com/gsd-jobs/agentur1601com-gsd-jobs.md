# agentur1601com/gsd-jobs

> 标签: PHP

## 简介

Extends the calendar bundle of contao with fields that simplify the implementation of jobs from google structured data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
