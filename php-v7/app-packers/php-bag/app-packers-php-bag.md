# app-packers/php-bag

> 标签: Basisregistraties Adressen en Gebouwen, bag, postcode

## 简介

Vanilla PHP package for BAG (Basisregistraties Adressen en Gebouwen) from the Kadaster.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
