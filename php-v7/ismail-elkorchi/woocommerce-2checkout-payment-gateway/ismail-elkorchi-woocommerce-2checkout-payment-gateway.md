# ismail-elkorchi/woocommerce-2checkout-payment-gateway

> 标签: plugins, wordpress

## 简介

Allows you to use 2Checkout payment gateway with the WooCommerce plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
