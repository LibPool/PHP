# samdark/yii2-webshell

> 标签: console, extension, shell, webshell, yii2

## 简介

A web shell that allows to run yii console commands and create your own commands.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
