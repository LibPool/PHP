# samdark/yii2-psr-log-target

> 标签: extension, log, psr-3, yii

## 简介

Yii 2 log target which uses PSR-3 compatible logger

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
