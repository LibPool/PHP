# spatie/laravel4-googletagmanager

> 标签: Google Tag Manager, laravel, laravel-googletagmanager, spatie

## 简介

Google Tag Manager integration for Laravel 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
