# wecodemore/wp-ssl

> 标签: composer, ssl, wordpress, wp

## 简介

Helper class for WordPress projects to see if something is really SSL or not

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
