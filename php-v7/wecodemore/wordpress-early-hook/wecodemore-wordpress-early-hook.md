# wecodemore/wordpress-early-hook

> 标签: actions, filters, hooks, wordpress, wordpress actions, wordpress filters, wordpress hooks, wp, wp actions, wp filters, wp hooks

## 简介

Small library to safely add WordPress hooks before WordPress is loaded.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
