# justinbarkhuff/laravel-stats

> 标签: laravel-stats, spatie

## 简介

A fork of spatie/laravel-stats which is backwards compatible with PHP 7.4+ and MySQL 5.7

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
