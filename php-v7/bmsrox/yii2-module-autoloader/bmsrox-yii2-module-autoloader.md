# bmsrox/yii2-module-autoloader

> 标签: autoload, bmsrox, extension, modules, yii2

## 简介

Extension to autoload modules dynamically

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
