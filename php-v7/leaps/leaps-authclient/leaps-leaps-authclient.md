# leaps/leaps-authclient

> 标签: OpenId, auth, leaps, oauth

## 简介

External authentication via OAuth and OpenID for the Leaps framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
