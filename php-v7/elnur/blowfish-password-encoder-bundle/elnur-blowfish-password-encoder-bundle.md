# elnur/blowfish-password-encoder-bundle

> 标签: bcrypt, blowfish, password-encoder, security

## 简介

Blowfish (bcrypt) based password encoder for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
