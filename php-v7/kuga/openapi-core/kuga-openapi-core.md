# kuga/openapi-core

> 标签: PHP

## 简介

kuga核心SDK，在https://github.com/misnet/kuga-openapi-sdk 上进行了简化，去掉业务相关的逻辑，只保留框架层级相关接口

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
