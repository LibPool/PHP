# darkeum/jpgraph

> 标签: chart, data, graph, jpgraph, pie

## 简介

Composer Friendly, full refactor of JpGraph, library to make graphs and charts

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
