# micro/plugin-logger-monolog

> 标签: PHP

## 简介

Micro Framework: Monolog logger adapter for  "micro/plugin-logger-core".

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
