# prolixlib/image-bundle

> 标签: bundle, form, image, local, picture, remote, symfony

## 简介

Allow to crop local and remote image before uploading them through a classic form.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
