# ucs/adminstrap

> 标签: UCS, backend, backoffice, bootstrap, css, rad, symfony

## 简介

Admin layer for twitter bootstrap themes, widgets and additional designs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
