# mbm-rafal/laravel-single-dispatch

> 标签: dispatched, laravel, middleware

## 简介

Laravel Dispatcher extension for maintaining duplicate jobs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
