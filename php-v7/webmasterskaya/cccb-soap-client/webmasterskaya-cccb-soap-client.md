# webmasterskaya/cccb-soap-client

> 标签: PHP

## 简介

PHP-SOAP клиент для работы с web-сервисами ЕДИНОЙ ИНФОРМАЦИОННОЙ СИСТЕМЫ «Спецсвязь» (ЕИС «Спецсвязь»)
