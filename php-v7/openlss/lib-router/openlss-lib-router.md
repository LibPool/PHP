# openlss/lib-router

> 标签: call handling, dynamic routing, route defaults, router

## 简介

Router for handling web calls, allows dynamic registration at runtime

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
