# arhframe/yamlarh

> 标签: Arhframe, framework, inject, injector, yaml

## 简介

Inject data and import other formatted file into your formatted file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
