# gringlas/cakephp-ep-authenticate

> 标签: PHP

## 简介

Authenticate Object for stateless authenticate. It can be used to get permanent authentication during development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
