# terminal42/mage-tools

> 标签: contao, deployment, mage, magephp, symfony

## 简介

Magephp tools for easier deployment of Contao and Symfony systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
