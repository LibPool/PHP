# calchen/laravel-dingtalk

> 标签: Ding, dingding, dingtalk, laravel, lumen, 丁丁, 钉钉

## 简介

钉钉 SDK Laravel/Lumen 扩展包（Dingtalk SDK for Laravel/Lumen）

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
