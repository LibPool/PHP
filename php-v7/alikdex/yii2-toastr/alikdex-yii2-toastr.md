# alikdex/yii2-toastr

> 标签: extension, jquery, notifications, toastr, yii2

## 简介

Yii2 widget for jquery toastr notifications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
