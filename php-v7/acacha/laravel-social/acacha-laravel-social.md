# acacha/laravel-social

> 标签: acacha, laravel-social

## 简介

Social Login/Register implementation using Laravel Socialite and AdminLTE Laravel package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
