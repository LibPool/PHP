# kant1/php-jsonschema-resolver

> 标签: JsonSchema, json, ref, resolver

## 简介

Simple JSON Schema parser which resolve the ref operator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
