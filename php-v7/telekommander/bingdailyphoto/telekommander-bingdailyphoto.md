# telekommander/bingdailyphoto

> 标签: bing

## 简介

BingPhoto is a simple PHP class to fetch Bing's image of the day with meta data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
