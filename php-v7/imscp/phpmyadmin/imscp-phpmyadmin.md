# imscp/phpmyadmin

> 标签: imscp, phpmyadmin, sql, tools

## 简介

Provides the PhpMyAdmin SQL administration tool for i-MSCP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
