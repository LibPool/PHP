# ppag/contao-backend-theme-bundle

> 标签: PHP

## 简介

Contao Bundle for adding the new Contao 5.4 Backend Icons and a narrow Version of the Backend Theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
