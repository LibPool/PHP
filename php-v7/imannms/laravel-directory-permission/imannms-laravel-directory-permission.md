# imannms/laravel-directory-permission

> 标签: directory, laravel, permission

## 简介

Artisan command to set appropiate permission for storage and bootstrap/cache directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
