# hyder/converter

> 标签: converter, hyder, image, image-to-pdf, laravel, pdf, pdf-to-image

## 简介

This is a Laravel package that provides an easy-to-use interface to convert PDF files to images using the Imagick PHP extension.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
