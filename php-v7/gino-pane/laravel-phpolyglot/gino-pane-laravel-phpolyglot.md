# gino-pane/laravel-phpolyglot

> 标签: grammar correction, ibm watson api, ibm watson tts, laravel, laravel package, localization, spelling, spelling correction, text-to-speech, translation, tts, yandex api, yandex dictionary api, yandex translate api

## 简介

Laravel package wrapper for PHP package for translation, spelling correction and text-to-speech (TTS) synthesis using external APIs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
