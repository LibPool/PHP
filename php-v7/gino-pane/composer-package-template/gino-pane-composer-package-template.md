# gino-pane/composer-package-template

> 标签: Skeleton, boilerplate, composer, composer package template, composer template, package, package template, template

## 简介

Basic composer package template for creating other packages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
