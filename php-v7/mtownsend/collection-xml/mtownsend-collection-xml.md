# mtownsend/collection-xml

> 标签: collection, laravel, soap, toSoapXml, toXML, xml

## 简介

The missing XML support for Laravel's Collection class.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
