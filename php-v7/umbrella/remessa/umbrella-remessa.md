# umbrella/remessa

> 标签: PHP

## 简介

ya-remessa é uma biblioteca para geração de arquivos de remessa de forma simples em PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
