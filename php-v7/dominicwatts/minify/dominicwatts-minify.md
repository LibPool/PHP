# dominicwatts/minify

> 标签: PHP

## 简介

Minify HTML including inline CSS and JS to speed up your site. Works with default Magento CSS/JS merger.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
