# ilama/basic-slim-boilerplate

> 标签: boilerplate, framework, gulp, semantic, slim, twig

## 简介

A basic boilerplate for the Slim PHP framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
