# slowlyo/dcat-tencent-map-selection

> 标签: dcat-admin, extension, map

## 简介

用于扩展DcatAdmin, 增加腾讯地图选点表单组件

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
