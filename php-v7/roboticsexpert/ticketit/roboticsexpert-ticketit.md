# roboticsexpert/ticketit

> 标签: helpdesk, laravel, support, ticket

## 简介

A simple helpdesk tickets system for Laravel 5.1, 5.2, 5.3 and 5.4 which integrates smoothly with Laravel default users and auth system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
