# daniel-km/omeka-s-module-common

> 标签: Omeka S, Omeka S module, development, library

## 简介

Module for Omeka S: Manage internal features used in various modules: bulk functions, form elements, view helpers, one-time methods for install, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
