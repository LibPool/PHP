# martinlindhe/data-calling-codes

> 标签: PHP

## 简介

Data set with calling codes based on https://en.wikipedia.org/wiki/List_of_country_calling_codes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
