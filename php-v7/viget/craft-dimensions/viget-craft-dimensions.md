# viget/craft-dimensions

> 标签: Craft, cms, craft-plugin, craftcms, dimensions

## 简介

Replicate the Craft Commerce Dimensions fields as a standalone field type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
