# tyondo/mnara

> 标签: acl, admin, authorization, gui, laravel, permissions, rbac, roles

## 简介

User management package with ACL for managing Users / Roles / Permissions in Laravel 5.3 and 5.4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
