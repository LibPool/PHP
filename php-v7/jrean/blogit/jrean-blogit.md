# jrean/blogit

> 标签: blog, framework, git, github, laravel, laravel blog, markdown

## 简介

Blog with Git(hub). For Laravel 5.*. Fetch and Parse Documents hosted on Github.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
