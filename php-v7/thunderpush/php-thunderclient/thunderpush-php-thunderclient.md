# thunderpush/php-thunderclient

> 标签: beacon, pubsub, push, thunderpush

## 简介

A PHP library for sending messages to Thunderpush server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
