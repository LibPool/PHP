# corelib/core

> 标签: PHP

## 简介

Corelib is mainly a Object Relational Mapper (ORM) for PHP. It focuses on flexibility and ease of use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
