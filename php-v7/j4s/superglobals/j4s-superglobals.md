# j4s/superglobals

> 标签: cookies, filtration, get, post, session, superglobals, validation

## 简介

Classes for work with superglobals $_GET, $_POST, $_SESSION, $_COOKIE

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
