# riverskies/laravel-mobile-detect

> 标签: blade, detection, laravel, mobile

## 简介

Instant mobile detection access directly from within Blade templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
