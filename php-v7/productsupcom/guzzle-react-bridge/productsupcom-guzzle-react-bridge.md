# productsupcom/guzzle-react-bridge

> 标签: Guzzle, async, curl, http, promises, react

## 简介

Guzzle HTTP client bridge with ReactPHP event loop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
