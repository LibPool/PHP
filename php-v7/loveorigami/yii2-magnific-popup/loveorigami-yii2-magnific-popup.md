# loveorigami/yii2-magnific-popup

> 标签: magnific-popup, widget, yii2

## 简介

This widget is wrapper for awesome jQuery plugin Magnific Popup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
