# libriciel/cakephp-checks

> 标签: PHP

## 简介

Plugin CakePHP 3.x permettant de faciliter la vérification d'un application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://gitlab.libriciel.fr/CakePHP/LibricielChecks
