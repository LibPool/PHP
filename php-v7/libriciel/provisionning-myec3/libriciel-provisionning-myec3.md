# libriciel/provisionning-myec3

> 标签: PHP

## 简介

Application web permettant de servir de endpoint à MyEC3 (Worldline) afin de provisionner les applications Libriciel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
