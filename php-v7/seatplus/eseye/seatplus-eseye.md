# seatplus/eseye

> 标签: PHP

## 简介

A fork of eveseat/eseye: A Standalone PHP ESI (EVE Swagger Interface) Client Library. Supports Monolog ^2.0 and php redis

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
