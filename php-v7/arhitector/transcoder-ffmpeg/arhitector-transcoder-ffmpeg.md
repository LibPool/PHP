# arhitector/transcoder-ffmpeg

> 标签: adapter, audio, conversion, ffmpeg, transcoder, transcoding, video

## 简介

The FFMpeg adapter for a arhitector/transcoder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
