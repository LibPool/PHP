# dj-thd2/mysql-pdo-cache

> 标签: PHP

## 简介

MySQL transparent PDO wrapper with (somewhat) smart query caching on Redis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
