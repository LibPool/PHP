# org_heigl/captainhook_sendtime_backend_tine2

> 标签: PHP

## 简介

Send the time from a time-entry in your git commit-message to a Tine2.0 instance

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
