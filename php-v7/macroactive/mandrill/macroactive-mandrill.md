# macroactive/mandrill

> 标签: api, email

## 简介

Unofficial API client library for the Mandrill email as a service platform. Based on https://bitbucket.org/mailchimp/mandrill-api-php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
