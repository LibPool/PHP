# bravist/laravel-district-explorer

> 标签: PHP

## 简介

District Explorer For Laravel with AutoNavi. 中国行政区划数据，访问高德在线数据获取最新区划数据。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
