# m165437/igc2kmz-php

> 标签: google earth, igc, kml, kmz, laravel, paragliding

## 简介

PHP wrapper for Python script igc2kmz, an IGC to Google Earth converter.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
