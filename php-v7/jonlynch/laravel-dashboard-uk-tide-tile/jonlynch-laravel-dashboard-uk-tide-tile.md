# jonlynch/laravel-dashboard-uk-tide-tile

> 标签: jonlynch, laravel-dashboard

## 简介

A package to add UK tide tiles to Laravel Dashboard

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
