# wojtekn/magento2-cron-manager

> 标签: PHP

## 简介

Magento 2 module which allows enabling/disabling Magento 2 cron jobs in crontab.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
