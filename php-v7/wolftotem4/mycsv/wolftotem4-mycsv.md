# wolftotem4/mycsv

> 标签: csv, mysql

## 简介

The PHP CLI tool helps you to convert the result from MySQL command to CSV format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
