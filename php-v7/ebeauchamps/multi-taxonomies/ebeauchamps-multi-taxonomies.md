# ebeauchamps/multi-taxonomies

> 标签: PHP

## 简介

Simplify relations between 2 taxonomies. The value of the second one dynamically adjusts from the value of the first one.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
