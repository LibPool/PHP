# bamboopayment/bamboopayment-sdk

> 标签: bamboopayment, pago, payments, pci, php, sdk, siempre

## 简介

PHP SDK to interact with BambooPayment PCI API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
