# evheniy/jquery-bundle

> 标签: jquery, latest, symfony

## 简介

The JqueryBundle adds the ability to add latest jQuery to your application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
