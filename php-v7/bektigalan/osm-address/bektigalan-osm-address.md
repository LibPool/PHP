# bektigalan/osm-address

> 标签: PHP

## 简介

tools untuk mendapatkan kota/kodepos/provinsi dari alamat yang dimasukkan

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
