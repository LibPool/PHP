# pretzlaw/wp-integration-test

> 标签: PHP

## 简介

Mocking return value of functions/filters and more for testing WordPress with PHPUnit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
