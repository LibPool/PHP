# mv/free-sms-api-bundle

> 标签: Symfony2, bundle, free, mobile, sms, sms free, sms free mobile

## 简介

Bundle SF2 that use library api free mobile sending SMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
