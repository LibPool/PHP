# vrobin/alipay-sdk

> 标签: PHP

## 简介

支付宝（蚂蚁金服）开放平台第三方 PHP SDK，基于官方 3.3.2 版本。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://packagist.org/packages/vrobin%2Falipay-sdk
- 源码仓库：https://github.com/health901/alipay-sdk-php.git
- Packagist 页面：https://packagist.org/packages/vrobin%2Falipay-sdk
