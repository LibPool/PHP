# mikemix/mxrecaptcha

> 标签: Zend Framework, recaptcha, zf2, zf2 form

## 简介

ZF2 Form integration with v2.0 reCaptcha

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
