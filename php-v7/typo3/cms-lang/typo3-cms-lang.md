# typo3/cms-lang

> 标签: PHP

## 简介

Contains all the core language labels in a set of files mostly of the "locallang" format. This extension is always required in a TYPO3 install.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
