# typo3/cms-info

> 标签: PHP

## 简介

TYPO3 CMS Info - TYPO3 backend module for displaying information, such as a pagetree overview and localization information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
