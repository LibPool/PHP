# ntzwbr/markdown

> 标签: extensible, fast, gfm, markdown, markdown-extra

## 简介

A super fast highly extensible markdown parser for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
