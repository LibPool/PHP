# pratyushpundir/laravel-bulma-preset

> 标签: bulma, laravel, laravel bulma, laravel presets

## 简介

Use Bulma instead of Bootstrap along with versioned asset files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
