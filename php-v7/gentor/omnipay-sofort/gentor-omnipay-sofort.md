# gentor/omnipay-sofort

> 标签: gateway, omnipay, payment, provider, sofort, uberweisung

## 简介

SOFORT Überweisung gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
