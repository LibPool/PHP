# phalapi/cli

> 标签: cli, phalapi, phalapi-cli

## 简介

PhalApi 2.x 扩展类库 - CLI命令行，可用于开发命令行应用，基于GetOpt，主要作用是将命令参数进行解析和处理。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
