# phalapi/fast-route

> 标签: fast-route, phalapi, phalapi-fast-route

## 简介

PhalApi 2.x 扩展类库 - FastRoute路由，可以通过配置实现自定义路由配置，从而轻松映射到PhalApi中的service接口服务。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
