# nickford/acf-swatch

> 标签: PHP

## 简介

This is a simple ACF Add-on field allowing the creation of color swatches that behave as radio buttons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
