# acassan/remoteserver

> 标签: Symfony2, bundle, remote, server

## 简介

This is a Symfony2 Bundle helps you to read and process action on remote server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
