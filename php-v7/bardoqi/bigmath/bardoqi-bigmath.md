# bardoqi/bigmath

> 标签: BigInteger, PHP7, bigcomplex, bigdecimal, bigmath, integer, math, phpmath

## 简介

A PHP library to work with big integers and big decimals in most easy way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
