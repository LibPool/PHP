# codera21/sf

> 标签: codeigniter, laravel, php, php framework, simple framework, yii

## 简介

Simple php framework inspired by codeigniter, laravel, yii

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
