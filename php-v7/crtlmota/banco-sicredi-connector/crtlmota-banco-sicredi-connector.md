# crtlmota/banco-sicredi-connector

> 标签: Banco Sicredi Boletos Cobrança webhook

## 简介

Abstração de comunicação rest com a API do Banco Sicredi v3.3, apenas curl

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
