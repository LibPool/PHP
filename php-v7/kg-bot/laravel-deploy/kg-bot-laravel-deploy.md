# kg-bot/laravel-deploy

> 标签: bitbucket, deploy, git, github, laravel, vcs

## 简介

Laravel package used to automatically deploy code from GIT version controls

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
