# bellevue7k/span-classes

> 标签: bard, statamic

## 简介

A custom button for Bard to allow a span with a class to be added to selected text. In this instance, Les Mills group fitness class types.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
