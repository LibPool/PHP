# gravityforms/gravityformscli

> 标签: cli, gravityforms, wordpress, wp-cli

## 简介

A set of WP-CLI commands to manage Gravity Forms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
