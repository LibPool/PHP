# pcfreak30/wordpress-plugin-framework

> 标签: PHP

## 简介

A simple PSR-4 and composer ready plugin framework for the modern wordpress age

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
