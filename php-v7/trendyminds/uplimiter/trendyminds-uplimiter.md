# trendyminds/uplimiter

> 标签: Craft, cms, craftcms, plugin, uplimiter

## 简介

Easily define the maximum file upload size per user group in Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
