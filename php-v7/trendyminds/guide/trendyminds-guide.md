# trendyminds/guide

> 标签: Craft, cms, craft-plugin, craftcms, usermanual

## 简介

A Craft CMS plugin to display a help guide in the control panel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
