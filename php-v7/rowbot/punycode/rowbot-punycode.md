# rowbot/punycode

> 标签: punycode, rfc-3492, rfc3492

## 简介

A Bootstring encoding of Unicode for Internationalized Domain Names in Applications (IDNA).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
