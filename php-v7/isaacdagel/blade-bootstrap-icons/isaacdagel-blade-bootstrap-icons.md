# isaacdagel/blade-bootstrap-icons

> 标签: blade-bootstrap-icons, isaacdagel

## 简介

A package to easily integrate Bootstrap SVG icons into your Laravel project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
