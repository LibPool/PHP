# automattic/jetpack

> 标签: PHP

## 简介

Jetpack supercharges your self‑hosted WordPress site with the awesome cloud power of WordPress.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
