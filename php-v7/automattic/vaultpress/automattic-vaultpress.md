# automattic/vaultpress

> 标签: PHP

## 简介

VaultPress is a subscription service offering real-time backup, automated security scanning, and support from WordPress experts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
