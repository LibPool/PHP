# automattic/php-thrift-sql

> 标签: Impala, database, hive, sql, thrift

## 简介

A PHP library for connecting to Hive or Impala over Thrift

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
