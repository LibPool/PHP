# camspiers/silverstripe-loggerbridge

> 标签: PHP

## 简介

Provides a bridge between PSR-3 loggers (like monolog) and SilverStripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
