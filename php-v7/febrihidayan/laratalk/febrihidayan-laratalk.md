# febrihidayan/laratalk

> 标签: chatting, laratalk, laravel, messages, packages, pusher, realtime

## 简介

Laratalk provides Laravel based chat between users and groups

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
