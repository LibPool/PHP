# clawsonm/cakephp-propay

> 标签: cakephp

## 简介

CakePHP 2.x wrapper plugin for ProPay API services. Uses auto generated WSDL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
