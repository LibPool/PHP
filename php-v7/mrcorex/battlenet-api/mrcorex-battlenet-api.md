# mrcorex/battlenet-api

> 标签: battle, battle.net, battlenet, blizzard, diablo, starcraft, wow

## 简介

php api for Battle.net game APIs ( https://dev.battle.net/ ).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
