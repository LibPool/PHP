# alextartan/flysystem-libsodium-adapter

> 标签: Flysystem, encryption, libsodium

## 简介

On-the-fly encrypt and decrypt flysystem files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
