# alextartan/guzzle-psr18-adapter

> 标签: Guzzle, adapter, psr18

## 简介

Lightweight wrapper over Guzzle to comply with PSR18

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
