# flarum-lang/spanish-argentina

> 标签: es_AR-locale, flarum, flarum-locale, locale, spanish-argentina, spanish-argentina-locale

## 简介

Spanish (Argentina) language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
