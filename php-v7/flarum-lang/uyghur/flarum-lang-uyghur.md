# flarum-lang/uyghur

> 标签: flarum, flarum-locale, locale, ug-locale, uyghur, uyghur-locale

## 简介

Uyghur language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
