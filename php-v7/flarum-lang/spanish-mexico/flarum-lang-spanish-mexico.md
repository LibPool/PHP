# flarum-lang/spanish-mexico

> 标签: es_MX-locale, flarum, flarum-locale, locale, spanish-mexico, spanish-mexico-locale

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
