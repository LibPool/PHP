# flarum-lang/armenian

> 标签: armenian, armenian-locale, flarum, flarum-locale, hy-locale, locale

## 简介

Armenian language pack for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
