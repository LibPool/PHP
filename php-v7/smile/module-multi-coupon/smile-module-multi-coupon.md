# smile/module-multi-coupon

> 标签: cart, coupon, magento2, multiple, salesrule

## 简介

Extension of Magento2 Sales Rule to allow multiple coupon usage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
