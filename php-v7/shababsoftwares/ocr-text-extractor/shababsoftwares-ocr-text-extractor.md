# shababsoftwares/ocr-text-extractor

> 标签: OCR, Tesseract, image, php, text

## 简介

This is a simple php project using Tesseract to extract text from any image.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
