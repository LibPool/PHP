# smtgr14/twig-debugbar

> 标签: PHP debug bar, extension, twig

## 简介

A Twig extension to provide access to PHP Debug Bar's rendering functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
