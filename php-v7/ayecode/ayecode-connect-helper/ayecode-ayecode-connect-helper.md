# ayecode/ayecode-connect-helper

> 标签: AyeCode Connect, ayecode, wp

## 简介

Provides helper functionality for installing AyeCode Connect.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
