# jbzoo/profiler

> 标签: benchmark, memory, microtime, performance, phpunit, profiler, tests, timer

## 简介

Simple Profiler for PHP code and unit tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
