# jbzoo/lang

> 标签: jbzoo, lang, language, locale, localisation, translation

## 简介

Lightweight library for easy translation based on simple formats (php arrays, json, yml, ini)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
