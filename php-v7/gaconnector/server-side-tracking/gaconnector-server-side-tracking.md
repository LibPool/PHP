# gaconnector/server-side-tracking

> 标签: analytics, attribution, crm, ga, gaconnector, google-analytics, server-side, tracking

## 简介

GA Connector server-side tracking library for PHP: render the tracker bootstrap and proxy tracking calls through your own domain.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
