# cleentfaar/tissue

> 标签: anti-virus, clamav, security, virus

## 简介

A PHP library that scans your files for viruses using the adapter of your choice

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
