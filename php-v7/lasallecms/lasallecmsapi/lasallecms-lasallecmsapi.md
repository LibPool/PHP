# lasallecms/lasallecmsapi

> 标签: Bob Bloom, LaSalleCMS, South LaSalle, apit, laravel, laravel5

## 简介

The internal API for the LaSalle Content System.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
