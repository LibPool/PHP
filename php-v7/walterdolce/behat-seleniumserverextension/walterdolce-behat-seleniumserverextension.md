# walterdolce/behat-seleniumserverextension

> 标签: BDD, Behat, TDD, chrome, firefox, selenium, testing

## 简介

A behat extension for people who forget to download & start the selenium server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
