# plexcellmedia/firestore

> 标签: app engine, firestore, firevel, google cloud, laravel

## 简介

Firestore wrapper for Laravel app running inside Google App Engine.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
