# fabiancernota/yii2-mpdf

> 标签: component, extension, html, mpdf, pdf, utf8, yii2

## 简介

A fixed version of zolex/yii2-mpdf which allows portait and landscape selection and supports php7.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
