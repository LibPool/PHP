# uinno/code-analysis

> 标签: PHP

## 简介

Review your code to detect, understand and fix issues fast. Security issues in code, Static Code Analysis, Refactoring issues, Coding Standards issues.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
