# breadthe/laravel-silent-spam-filter

> 标签: breadthe, laravel-silent-spam-filter

## 简介

Silently filter spam messages based on a custom keyword/keyphrase blacklist.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
