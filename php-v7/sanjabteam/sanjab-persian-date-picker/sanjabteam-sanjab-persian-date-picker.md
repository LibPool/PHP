# sanjabteam/sanjab-persian-date-picker

> 标签: laravel, sanjab

## 简介

Persian date picker for laravel sanjab (https://github.com/sanjabteam/sanjab)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
