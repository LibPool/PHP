# the-bit-bang/php-svg-framework-svgf

> 标签: PHP

## 简介

Provides funtionality for creating, reading, modifying and writing svg files in php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
