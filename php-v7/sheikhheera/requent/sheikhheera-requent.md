# sheikhheera/requent

> 标签: api, gql, graph, json, laravel, query, requent, transformer

## 简介

A GraphQL like interface to map a request to eloquent query with data transformation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
