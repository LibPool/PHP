# denshoch/dendenmarkdown

> 标签: epub, epub3, japanese, markdown

## 简介

Just a little help for them. This is a Markdown dialect optimized for EPUB 3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
