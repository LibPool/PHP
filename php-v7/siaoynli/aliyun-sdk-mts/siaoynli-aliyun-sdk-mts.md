# siaoynli/aliyun-sdk-mts

> 标签: alicloud, aliyun, mts, sdk

## 简介

aliyun-php-sdk-mts 封装，支持composer方式使用

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
