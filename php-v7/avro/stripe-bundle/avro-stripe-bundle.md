# avro/stripe-bundle

> 标签: billing, credit card, plan, subscription

## 简介

Symfony2 Bundle for managing user subscriptions and payments with Stripe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
