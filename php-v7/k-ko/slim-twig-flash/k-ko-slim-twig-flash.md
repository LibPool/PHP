# k-ko/slim-twig-flash

> 标签: extension, flash, framework, message, provider, slim, twig3, view

## 简介

A Twig 3 extension to access Slim Flash messages in templates

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
