# eloquent/endec

> 标签: base16, base32, base32hex, base64, base64url, codec, decode, decoding, encode, encoding, hex, react, stream, streaming

## 简介

Versatile encoding implementations for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
