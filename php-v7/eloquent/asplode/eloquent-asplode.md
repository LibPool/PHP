# eloquent/asplode

> 标签: error, errorexception, exception, failure, fault, handler, handling

## 简介

Drop-in exception-based error handling for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
