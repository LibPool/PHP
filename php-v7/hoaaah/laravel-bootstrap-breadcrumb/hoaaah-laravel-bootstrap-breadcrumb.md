# hoaaah/laravel-bootstrap-breadcrumb

> 标签: PHP

## 简介

A packages for create bootstrap breadcrumb dynamically.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
