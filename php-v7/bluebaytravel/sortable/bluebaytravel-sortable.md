# bluebaytravel/sortable

> 标签: api, bluebaytravel, eloquent, laravel, model, request, sort, sortable

## 简介

Alternative sortable trait based on jedrzej/sortable

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
