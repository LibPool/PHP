# taavit/twig-extra-bundle

> 标签: Symfony2, date, datetime, twig

## 简介

This bundles provides extra twig extensions and filter (DateTime prettifier)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
