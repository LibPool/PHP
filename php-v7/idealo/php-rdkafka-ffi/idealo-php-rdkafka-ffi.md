# idealo/php-rdkafka-ffi

> 标签: client, ffi, kafka, librdkafka, php

## 简介

PHP Kafka client - binding librdkafka via FFI

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
