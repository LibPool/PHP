# yordanny90/bigxml

> 标签: XMLReader, bigxml, large-xml, streaming, xml

## 简介

Libreria para leer archivos XML grandes sin cargarlos completamente en memoria.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
