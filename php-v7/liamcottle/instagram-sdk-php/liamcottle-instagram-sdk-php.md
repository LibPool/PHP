# liamcottle/instagram-sdk-php

> 标签: api, instagram, php, private, sdk

## 简介

This is an unofficial SDK for the Instagram Private API in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
