# zerosonesfun/flarum-ext-bittykitty

> 标签: cat, discussion, emoji, kitty

## 简介

Retro 8-bit style kitty emoji BBCode.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
