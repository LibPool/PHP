# wwwision/renderlets-provider

> 标签: PHP

## 简介

Neos package to provide snippets of data/rendered content (aka 'renderlets') to be consumed by Wwwision.Renderlets.Consumer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
