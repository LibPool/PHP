# josegonzalez/cakephp-sanction

> 标签: auth, authorization, cakephp

## 简介

Centralize all of those permissions in a single file using the Sanction plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
