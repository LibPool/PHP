# corollarium/psr6-profilecachepool

> 标签: cache, profile, psr-6

## 简介

A PSR-6 compatible cache pool for profiling cache access, hits and misses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
