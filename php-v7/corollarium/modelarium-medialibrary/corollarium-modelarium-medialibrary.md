# corollarium/modelarium-medialibrary

> 标签: graphql, laravel, media, modelarium, web

## 简介

Integrates Spatie Laravel-media-library with Modelarium and GraphQL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
