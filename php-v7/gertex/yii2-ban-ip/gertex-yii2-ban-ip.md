# gertex/yii2-ban-ip

> 标签: extension, yii2

## 简介

Extension to black IP addresses to access the system after x number of 404 errors within x minutes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
