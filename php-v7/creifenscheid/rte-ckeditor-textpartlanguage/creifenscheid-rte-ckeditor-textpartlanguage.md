# creifenscheid/rte-ckeditor-textpartlanguage

> 标签: PHP

## 简介

This TYPO3 extension implements the text part language feature for CKEditor 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
