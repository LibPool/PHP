# denglevi/yii2_fecshop_elasticsearch

> 标签: elasticsearch, fecshop, yii2

## 简介

fecshop elasticsearch extension for category, product, search page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
