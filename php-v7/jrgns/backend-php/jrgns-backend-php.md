# jrgns/backend-php

> 标签: backend, framework

## 简介

PHP Framework that tries to do it all.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://backend-php.net
- 源码仓库：https://github.com/jrgns/backend-php.git
- Packagist 页面：https://packagist.org/packages/jrgns%2Fbackend-php
