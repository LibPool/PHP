# tgkw-adc/ip2location-php

> 标签: area code, geolocation, ip geolocation, ip2location, ip2locationlite, isp, mcc, mnc, time zone, usage type, zip code

## 简介

[Official Release] IP2Location PHP API to get location info from IPv4 and IPv6 address.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
