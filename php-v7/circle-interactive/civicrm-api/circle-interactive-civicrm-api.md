# circle-interactive/civicrm-api

> 标签: civicrm, developer api, remote api library

## 简介

An API library to enable and facilitate interacting with a remote CiviCRM site.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
