> 标签: JOSE, JWE, JWK, JWKSet, JWS, Jot, RFC7515, RFC7516, RFC7517, RFC7518, RFC7519, jwa, jwt

## 简介

JSON Object Signing and Encryption interfaces.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
