> 标签: JOSE, JWE, JWK, JWKSet, JWS, Jot, RFC7515, RFC7516, RFC7517, RFC7518, RFC7519, RFC7520, jwa, jwt

## 简介

JSON Object Signing and Encryption library for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
