# spomky-labs/php-aes-gcm

> 标签: AES-GCM, Galois Counter Mode, aes, gcm

## 简介

AES GCM (Galois Counter Mode) PHP implementation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
