# myli/laravel-jobs-plain

> 标签: laravel, php, pubsub

## 简介

Custom connectors for Laravel that supports plain JSON instead of laravel-specifics format

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
