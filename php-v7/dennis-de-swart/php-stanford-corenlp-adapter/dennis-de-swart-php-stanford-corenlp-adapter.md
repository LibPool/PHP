# dennis-de-swart/php-stanford-corenlp-adapter

> 标签: ner, nlp, parser, pos, stanford

## 简介

PHP adapter for use with Stanford CoreNLP tools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
