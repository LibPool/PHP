# newtovaux/dev-bootstrap

> 标签: PHP

## 简介

Dev-only bootstrap script exposed via vendor/bin/bootstrap for PHP Laravel projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
