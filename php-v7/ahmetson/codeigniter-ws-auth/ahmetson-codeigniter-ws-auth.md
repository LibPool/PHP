# ahmetson/codeigniter-ws-auth

> 标签: PHP

## 简介

Authentication system for CodeIgniter that works with WebSocket Server Ratchet-php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
