# genesis-global/salesforce-bundle

> 标签: salesforce

## 简介

Symfony bundle that provides OAuth2 authentication and exposes Salesforce REST API methods in OOP friendly way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
