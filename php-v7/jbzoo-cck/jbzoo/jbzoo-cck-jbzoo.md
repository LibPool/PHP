# jbzoo-cck/jbzoo

> 标签: PHP

## 简介

JBZoo App is universal Joomla CCK, application for YooTheme Zoo component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
