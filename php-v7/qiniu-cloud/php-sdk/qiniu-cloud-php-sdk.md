# qiniu-cloud/php-sdk

> 标签: cloud, qiniu, sdk, storage

## 简介

Qiniu Resource (Cloud) Storage SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
