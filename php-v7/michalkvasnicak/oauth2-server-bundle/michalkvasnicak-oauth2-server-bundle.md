# michalkvasnicak/oauth2-server-bundle

> 标签: Authentication, authorization, oauth, security, symfony

## 简介

Symfony OAuth 2.0 server bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
