# secomapp/browsershot

> 标签: browser, convert, image, laravel, phantomjs, screenshot, webpage

## 简介

Convert a webpage to an image from spatie

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
