# ongr/ongr-strict-standard

> 标签: coding, phpcs, psr, standard, symfony

## 简介

Strict PHPCS standard for PSR-2 code based on Squiz standards

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
