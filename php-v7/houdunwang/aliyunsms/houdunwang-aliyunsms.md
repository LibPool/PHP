# houdunwang/aliyunsms

> 标签: hdphp, houdunwang, sms, 后盾人, 后盾网, 向军老师, 短信, 阿里云发送短信

## 简介

使用阿里云短信平台发送短信，请先在阿里云开通短信服务后使用

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
