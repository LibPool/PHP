# houdunwang/validate

> 标签: hdphp, houdunwang, validate, 后盾人, 后盾网, 向军老师, 表单验证

## 简介

Validate组件提供了方便的验证机制，快速实现验证业务。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
