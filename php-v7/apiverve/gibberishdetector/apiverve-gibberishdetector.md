# apiverve/gibberishdetector

> 标签: api, apiverve, gibberish detector, gibberishdetector, nonsense detector, spam detection, text quality, text validation

## 简介

Gibberish Detector analyzes text using bigram frequency and vowel ratios to identify nonsensical or randomly generated content.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
