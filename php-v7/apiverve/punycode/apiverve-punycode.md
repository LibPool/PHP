# apiverve/punycode

> 标签: api, apiverve, idn, internationalized domain name, punycode, unicode, xn--

## 简介

Convert between Unicode and Punycode for internationalized domain names (IDN).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
