# apiverve/vowelcounter

> 标签: api, apiverve, consonant counter, letter frequency, text analysis, vowel counter, vowel percentage, vowelcounter

## 简介

Vowel Counter analyzes text to count vowels and consonants, providing detailed breakdowns and percentages for linguistic analysis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
