# apiverve/zipcodes

> 标签: Zipcodes, api, apiverve, free zip code lookup api, get city and state from zip code api, zip code lookup api, zip code to city, zipcode api

## 简介

Zip Codes Lookup finds all postal codes within a US city or resolves a five-digit ZIP code to its city and state. Paid plans add geographic coordinates.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
