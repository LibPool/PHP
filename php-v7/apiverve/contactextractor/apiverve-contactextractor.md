# apiverve/contactextractor

> 标签: api, apiverve, contact extractor api, contactextractor, extract addresses from website, extract emails from url, find email addresses on page, scrape phone numbers from website

## 简介

Contact Extractor scrapes public email addresses, phone numbers, and physical addresses from any web page URL. It tallies the findings and returns unique records found on the page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
