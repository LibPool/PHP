# apiverve/emojidecorator

> 标签: add emojis to text, api, apiverve, auto emoji insert, decorate text with emojis, emoji decorator api, emojidecorator, text emoji generator

## 简介

Emoji Decorator inserts relevant emojis into plain text strings. Submit any sentence or passage to receive the complete string decorated with fitting emojis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
