# apiverve/worldholidays

> 标签: api, apiverve, get holidays by country, global holiday schedule, national holidays by country code, public holiday calendar, world holidays api, worldholidays

## 简介

World Holidays lists public holidays and observances for any two-letter country code. It returns holiday dates, official names, and event types across the year.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
