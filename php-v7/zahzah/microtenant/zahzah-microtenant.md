# zahzah/microtenant

> 标签: PHP

## 简介

Package ini memungkinkan anda agar dapat mengelola multi tenant beserta dengan versioning didalamnya

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
