# gilberg-vrn/php-foursquare

> 标签: PHP

## 简介

A simple PHP library for accessing the foursquare API (see: https://developer.foursquare.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
