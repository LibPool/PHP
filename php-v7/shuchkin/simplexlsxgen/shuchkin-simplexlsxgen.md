# shuchkin/simplexlsxgen

> 标签: backend, creator, excel, generator, php, writer, xlsx

## 简介

Export data to Excel XLSx file. PHP XLSX generator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
