# sarfraznawaz2005/queryline

> 标签: eloquent, graph, laravel, query, sql

## 简介

QueryLine is a laravel package to show time graph against run quries on a page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
