# cleaniquecoders/laravel-boilerplate

> 标签: framework, laravel, osinitiative, web-app-boilerplate

## 简介

Web Application Boilerplate Based on Laravel Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
