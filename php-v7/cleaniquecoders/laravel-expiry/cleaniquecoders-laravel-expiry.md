# cleaniquecoders/laravel-expiry

> 标签: account, expiry, laravel, package, password, user

## 简介

Enable expiry on user's account and user's password.

按 require.php 推断最低支持 PHP 2；已收录于 php-v5, php-v7, php-v8。
