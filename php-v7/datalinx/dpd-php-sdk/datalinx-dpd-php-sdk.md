# datalinx/dpd-php-sdk

> 标签: Slovenia, api, croatia, dpd, easyship, hrvatska, php, sdk, slovenija, webservice

## 简介

PHP SDK for DPD Slovenia and Croatia

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
