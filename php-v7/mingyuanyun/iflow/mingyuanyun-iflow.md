# mingyuanyun/iflow

> 标签: flow, workflow

## 简介

基于事件的轻量级流程引擎组件,可以很简单的创建流程、流程步骤及控制流程流转,通过对流程事件的定义,很方便的处理具体业务逻辑。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
