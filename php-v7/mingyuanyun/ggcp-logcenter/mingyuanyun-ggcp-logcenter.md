# mingyuanyun/ggcp-logcenter

> 标签: logcenter, logger, mingyuanyun

## 简介

云链公共产品日志中心服务 SDK，提供日志中心的日志记录以及检索功能

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
