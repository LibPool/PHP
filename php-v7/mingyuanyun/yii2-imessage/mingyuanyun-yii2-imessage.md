# mingyuanyun/yii2-imessage

> 标签: app, mail, message, sms, wechat, yii2

## 简介

消息发送组件，集成多渠道消息（邮件、企业微信、短信、APP）消息，内置重试机制、统一返回格式，支持下云（短信类支持公共组短信及阿里云短信）。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
