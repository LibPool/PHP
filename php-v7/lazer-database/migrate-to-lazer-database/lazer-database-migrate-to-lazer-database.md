# lazer-database/migrate-to-lazer-database

> 标签: Simple, database, db, file, flat, json, lazer, migration

## 简介

PHP library to transfer data to Lazer-Database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
