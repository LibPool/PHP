# devuri/raydiumxe

> 标签: PHP

## 简介

Effortlessly spin up a fully-configured WordPress site in no time, that support multiple tenants from a single installation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
