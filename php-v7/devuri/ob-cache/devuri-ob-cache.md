# devuri/ob-cache

> 标签: cached-data, ob-cache, wordpress

## 简介

A simple versatile and easy-to-use PHP class designed for managing caching in WordPress environments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
