# kjgcoop/trilium-daily-note-toolkit

> 标签: PHP

## 简介

Shared bootstrap and idempotent-section-append helpers for the trilium-* daily-note scripts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
