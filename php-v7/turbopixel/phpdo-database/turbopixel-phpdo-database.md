# turbopixel/phpdo-database

> 标签: PHP7, database, lightweight, mysql, pdo, php, wrapper

## 简介

A lightweight PHP7 database wrapper class.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
