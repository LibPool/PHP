# antecedent/patchwork

> 标签: aop, aspect, interception, monkeypatching, redefinition, runkit, testing

## 简介

Method redefinition (monkey-patching) functionality for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
