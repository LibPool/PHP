# sowe/websocketio

> 标签: event, swoole, websocket, websocketio

## 简介

SocketIO implementation using RFC6455-compliant websockets only. Built on top of Swoole Websocket Server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
