# vivlong/phalapi-xredis

> 标签: phalapi, phalapi-redis, redis

## 简介

PhalApi 2.x 扩展类库 - Redis 丰富基础redisCache类功能,更贴切复杂场景下的redis使用。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
