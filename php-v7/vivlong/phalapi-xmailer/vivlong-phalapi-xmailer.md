# vivlong/phalapi-xmailer

> 标签: phalapi, phalapi-xmailer, xmailer

## 简介

PhalApi 2.x扩展类库，基于PHPMailer的邮件发送。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
