# kasperh/php-gratisdns

> 标签: dns, gratisdns

## 简介

Alter DNS entries at GratisDNS via php. Administrer dine DNS indstillinger hos GratisDNS via php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
