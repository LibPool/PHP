# digitalstate/bpm-camunda-sdk

> 标签: camunda, camunda bpm, sdk

## 简介

PHP SDK for camundaBPM process services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://camunda.org
- 源码仓库：https://github.com/DigitalState/Bpm-Camunda-Sdk.git
- Packagist 页面：https://packagist.org/packages/digitalstate%2Fbpm-camunda-sdk
