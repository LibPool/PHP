# kohana/koharness

> 标签: kohana, tests

## 简介

Creates test harnesses for kohana modules by bootstrapping a temporary kohana application with dependencies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
