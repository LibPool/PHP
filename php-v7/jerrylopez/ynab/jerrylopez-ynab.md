# jerrylopez/ynab

> 标签: api, php, sdk, ynab

## 简介

PHP wrapper for the YNAB API. Read the documentation at https://api.youneedabudget.com

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
