# bfg/chartjs

> 标签: chart, chartjs, graphics, laravel5, reports

## 简介

Simple package to facilitate and automate the use of ChartJs v2 library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
