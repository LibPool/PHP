# hello-solucoes/bras-pag

> 标签: Bras Pag, Cartão de Crédito, pagamentos

## 简介

Projeto para se comunicar com o soap da BrasPag

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
