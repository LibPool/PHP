# eckinox/bolt-navigation-ui

> 标签: PHP

## 简介

A Bolt 5 extension that provides a user-friendly interface to manage navigations, straight from the admin section.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
