# burovoordeboeg/wp-theme-class

> 标签: theme setup, wordpress

## 简介

This theme class provides basic out-of-the-box support which takes the hassle out of setting up a theme from scratch every time.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
