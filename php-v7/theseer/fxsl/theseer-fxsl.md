# theseer/fxsl

> 标签: PHP

## 简介

An XSL wrapper / extension to the PHP 5.x XSLTProcessor with Exception and extended Callback support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
