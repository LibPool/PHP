# shela/omnipay-btcpayserver

> 标签: bitcoin, btcpayserver, gateway, merchant, omnipay, pay, payment

## 简介

BTCPayServer driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
