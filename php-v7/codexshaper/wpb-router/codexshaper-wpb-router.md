# codexshaper/wpb-router

> 标签: builder, plugin, router, wordpress, wpb

## 简介

Illuminate router for Wordpress plugin builder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
