# php-architecture-kit/actor

> 标签: actor, ddd, framework-agnostic, identity

## 简介

Actor abstraction for PHP applications - represents who performs actions in the system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
