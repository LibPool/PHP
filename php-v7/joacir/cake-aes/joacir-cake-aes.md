# joacir/cake-aes

> 标签: AES-256, encrypt, lgpd, php

## 简介

Encrypt and decrypt fields using AES-256 plugin for CakePHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
