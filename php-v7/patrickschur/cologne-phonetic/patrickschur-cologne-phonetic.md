# patrickschur/cologne-phonetic

> 标签: cologne, kölner, phonetic, phonetik

## 简介

Implementation of Cologne Phonetics (Kölner Phonetik) in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
