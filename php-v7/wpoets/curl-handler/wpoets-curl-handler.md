# wpoets/curl-handler

> 标签:  Awesome Enterprise, Low Code, curl, shortcode, wordpress

## 简介

Handler for sending curl request in Awesome Enterprise

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
