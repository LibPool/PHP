# wpoets/debug-handler

> 标签:  Awesome Enterprise, Low Code, debugbar, shortcode, wordpress

## 简介

Add support for php-debugbar to make it easier for debugging within awesome enterprise

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
