# leytech/leytech_fixurlrewrites

> 标签: PHP

## 简介

Module to fix the longstanding URL re-indexing bug in Magento 1.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
