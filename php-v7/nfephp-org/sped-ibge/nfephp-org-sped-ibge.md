# nfephp-org/sped-ibge

> 标签: Estatos, Municipios, ibge, sped

## 简介

Library to access the services of IBGE to obtain the codes used by the system SPED

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
