# nfephp-org/sped-averbacao

> 标签: averbacao, nfephp, sped

## 简介

API para comunicação e Averbação dos CTes, MDFes e NFes com as Seguradoras.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
