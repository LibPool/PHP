# hansott/range-regex

> 标签: Match, brace, expansion, glob, hansott, number, numeric, range, ranges, regex, validation

## 简介

Returns a regex-compatible range from two numbers, min and max.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
