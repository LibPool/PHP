# sehrgut/wp-eu-vat-helpers

> 标签: PHP

## 简介

WordPress helper shortcodes to display prices including applicable VAT rate for the user's location (based on IP address)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
