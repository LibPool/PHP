# vnay92/laravel-custom-queue

> 标签: PHP

## 简介

A Queue Handler For Messages that are not Laravel Jobs. Useful while communicating between Laravel and External Systems

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
