# heineref/kirby-helpsection

> 标签: HeinerEF, helpsection, kirby-cms, kirby-plugin, kirby5, multilingual

## 简介

This multilingual Kirby plugin allows Panel users to display help how to work in the Panel, which can be called up directly in the Panel by clicking on the question-mark-icon in the Panel menu on the left.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
