# heineref/kirby-listsubpages

> 标签: HeinerEF, kirby-cms, kirby-plugin, kirby3, kirby4, kirby5, kirbytag, listSubpages

## 简介

The KirbyTag “listsubpages” generates a list of all subpages — e.g. the visible ones — in the form of a link list

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
