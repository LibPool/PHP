# craftcms/commerce-paypal

> 标签: commerce, craftcms, omnipay, paypal, yii2

## 简介

PayPal integration for Craft Commerce 3.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
