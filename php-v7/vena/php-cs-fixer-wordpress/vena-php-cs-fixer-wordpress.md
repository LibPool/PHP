# vena/php-cs-fixer-wordpress

> 标签: PHP

## 简介

A custom ruleset for PHP CS Fixer (close to) Wordpress Coding Standards

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
