# skynettechnologies/aipdfaccessibilityremediation-plugin

> 标签: accessibility, ada, aoda, en301549, october, octobercms, pdf, pdf-ua, remediation, section508, wcag

## 简介

AI PDF Accessibility Remediation — upload or crawl for PDFs, run AI accessibility remediation, review per-check findings and download WCAG / PDF-UA conformant files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
