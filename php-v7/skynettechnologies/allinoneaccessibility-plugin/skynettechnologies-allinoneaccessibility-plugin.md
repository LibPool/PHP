# skynettechnologies/allinoneaccessibility-plugin

> 标签: PHP

## 简介

Quick Web Accessibility Implementation with All in One Accessibility!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
