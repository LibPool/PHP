# grayhoax/phptelebot

> 标签: bot, bot-api, php-telegram, telegram, telegram-bot

## 简介

Telegram bot framework written in PHP with full Bot API 9.2 support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
