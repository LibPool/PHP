# sahilr2050/yii2-cloudwatch-logs

> 标签: aws, cloudwatch, log, yii2

## 简介

Yii2 Logger target to dump app logs to cloudwatch in AWS in chronological order.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
