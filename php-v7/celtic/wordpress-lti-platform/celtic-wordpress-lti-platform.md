# celtic/wordpress-lti-platform

> 标签: LTI, platform, plugin, tool, wordpress

## 简介

Plugin to allow WordPress to act as an LTI platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
