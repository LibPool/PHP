# andersundsehr/aus-driver-amazon-s3

> 标签: PHP

## 简介

Provides a FAL driver for the Amazon Web Service AWS S3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
