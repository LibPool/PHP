# elevenlab/laravel-geo

> 标签: geo, geospatial, laravel, spatial

## 简介

Spatial OGC objects integration for Laravel 5.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
