# elevenlab/php-sdk-boilerplate

> 标签: boilerplate, php, sdk

## 简介

PHP boilerplate library to help integrate SDKs for a generic API system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
