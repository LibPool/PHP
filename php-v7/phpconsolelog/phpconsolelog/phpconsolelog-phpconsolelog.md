# phpconsolelog/phpconsolelog

> 标签: console, debug, debugging, logging, realtime, websocket

## 简介

Real-time console logging for PHP applications with WebSocket support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
