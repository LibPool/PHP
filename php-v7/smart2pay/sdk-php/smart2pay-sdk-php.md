# smart2pay/sdk-php

> 标签: Smart2Pay, alternative payments, nuvei, payments, sdk

## 简介

Smart2Pay SDK - enable payments on your site easily 200+ methods, 80+ countries

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
