# rares/image-crop-bundle

> 标签: bootstrap, crop, image, vich

## 简介

A bundle that lets you crop images using Cropper jQuery library and integrates with VichUploaderBundle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
