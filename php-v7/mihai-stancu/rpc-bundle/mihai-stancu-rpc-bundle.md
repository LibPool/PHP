# mihai-stancu/rpc-bundle

> 标签: json-rpc, rpc, xml-rpc

## 简介

A symfony RPC Client and Server implementation which integrates the symfony/serializer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
