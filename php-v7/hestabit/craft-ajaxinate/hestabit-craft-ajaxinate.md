# hestabit/craft-ajaxinate

> 标签: Craft, ajax loadmore, categories, categories filters, category, cms, craft-plugin, craftcms, custom queries, element queries, entries filters, entries loader and filter, entry query, filter, filtering, filters, future entries, multiple filters, multiple load more, multiple loader, on scroll, page load

## 简介

With this Plugin, you have now an option to load more entries (using ajax). You can refine the content that you want to load by using Filters based on Fields and custom entry query.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
