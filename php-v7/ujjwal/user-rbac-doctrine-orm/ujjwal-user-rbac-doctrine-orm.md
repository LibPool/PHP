# ujjwal/user-rbac-doctrine-orm

> 标签: ZendFramework, module, zf2

## 简介

A Zend Framework 2 module to easily integrate ZfcUserDoctrineORM and ZfcRbac

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
