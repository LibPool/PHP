# hascoding/cms

> 标签: PHP

## 简介

Simple and Open Source PHP Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://hascoding.com
- 源码仓库：https://github.com/HasCoding/HasCodingCMS.git
- Packagist 页面：https://packagist.org/packages/hascoding%2Fcms

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require hascoding/cms`
- Packagist 仓库：https://repo.packagist.org/p2/hascoding/cms.json
- 许可证：GPL-3.0-or-later
- PHP 要求：>=5.6
