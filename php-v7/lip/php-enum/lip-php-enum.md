# lip/php-enum

> 标签: enum, enum-map, enum-set, enumeration, enumerator, enummap, enumset, map, set, type, type-hint, typehint, 枚举

## 简介

PHP 枚举基类，使用类 const 作为枚举值，每一项均含有 key、value 与 label。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
