# havvg/propel-boolean-extra-behavior

> 标签: Behavior, boolean, propel

## 简介

The BooleanExtraBehavior adds more readable accessors and mutators for boolean values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
