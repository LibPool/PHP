# efficimo/tilkee-php

> 标签: PHP

## 简介

PHP implementation of Tilkee API https://tilkee.readme.io/ (fork https://gitlab.com/hbs-research/tilkee-php)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
