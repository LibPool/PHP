# defabr13k/laravel-cogs

> 标签: PHP

## 简介

Cogs for Laravel is a Composer package that adds handy Artisan Console Commands for MySQL database administration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
