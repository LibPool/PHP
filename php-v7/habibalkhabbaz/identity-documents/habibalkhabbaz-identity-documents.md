# habibalkhabbaz/identity-documents

> 标签: IdentityDocuments, laravel, mrz, passport

## 简介

Package to parse identity documents like passports

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
