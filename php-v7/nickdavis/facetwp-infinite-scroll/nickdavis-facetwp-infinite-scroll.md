# nickdavis/facetwp-infinite-scroll

> 标签: PHP

## 简介

WordPress plugin which adds infinite scroll functionality to FacetWP templates. Requires developer config.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
