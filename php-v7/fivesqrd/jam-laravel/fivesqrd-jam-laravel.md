# fivesqrd/jam-laravel

> 标签: laravel, laravel 5

## 简介

A Laravel 5 service provider for the AWS DynamoDB session handler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
