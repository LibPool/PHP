# kotchuprik/yii2-x-editable

> 标签: extension, x-editable, yii2

## 简介

X-editable extensions for Yii 2. Fork marciocamello/yii2-x-editable with some features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
