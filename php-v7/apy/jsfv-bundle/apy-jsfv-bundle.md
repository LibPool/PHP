# apy/jsfv-bundle

> 标签: form, g11n, i18n, javascript, l10n, symfony, validation

## 简介

Symfony2 Javascript Form Validation Bundle with localisation support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
