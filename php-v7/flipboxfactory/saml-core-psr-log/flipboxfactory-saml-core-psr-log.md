# flipboxfactory/saml-core-psr-log

> 标签: cms, craftcms, log, psr, yii2

## 简介

SAML SSO Core logger to support the different versions of psr/log

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
