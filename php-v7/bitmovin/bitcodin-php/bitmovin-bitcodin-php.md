# bitmovin/bitcodin-php

> 标签: DRM, MPD, api, bitcodin, bitmovin, dash, encoding, hls, m3u8, mp4, mpeg-dash

## 简介

Bitcodin PHP API Client Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
