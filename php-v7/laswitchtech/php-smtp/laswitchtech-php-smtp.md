# laswitchtech/php-smtp

> 标签: PHP

## 简介

This PHP SMTP email library provides a simple and easy-to-use solution for sending emails using SMTP servers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
