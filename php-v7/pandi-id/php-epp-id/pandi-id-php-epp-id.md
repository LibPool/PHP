# pandi-id/php-epp-id

> 标签: client, domains, epp, registrar, registry, tcp

## 简介

A High Level EPP (Extensible Provisioning Protocol) TCP/SSL Client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
