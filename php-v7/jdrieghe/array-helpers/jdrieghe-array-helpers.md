# jdrieghe/array-helpers

> 标签: PHP

## 简介

A collection of convenience methods to deal with arrays in php. Somewhat inspired by Laravel array helpers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
