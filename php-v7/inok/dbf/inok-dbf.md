# inok/dbf

> 标签: dbase, dbf, foxpro, memo

## 简介

Package for reading DBASE-files (FoxPro) with/without MEMO-fields

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
