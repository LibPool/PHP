# webhooker/webhooker-sdk

> 标签: webhooker, webhooker-sdk, webhooks

## 简介

SDK for communicating with the WebHooker.io API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
