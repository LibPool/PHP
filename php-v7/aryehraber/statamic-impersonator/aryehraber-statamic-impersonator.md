# aryehraber/statamic-impersonator

> 标签: Authentication, impersonator, statamic

## 简介

Give Admins the ability to authenticate as any user for easier debugging.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
