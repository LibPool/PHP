# perk11/russianisocc

> 标签: PHP

## 简介

Getting Russian country name by ISO code. Получение полного русского названия страны в PHP по ISO-коду

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
