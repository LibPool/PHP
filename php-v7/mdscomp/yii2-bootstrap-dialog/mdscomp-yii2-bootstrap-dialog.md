# mdscomp/yii2-bootstrap-dialog

> 标签: bootstrap3 dialog, wrapper, yii2

## 简介

Yii2 Bootstrap3 Dialog Wrapper - Make use of Bootstrap Modal more monkey-friendly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
