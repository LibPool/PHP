# genealabs/jumpstart

> 标签: jumpstart, laravel, missing

## 简介

Provides the missing views and other functionality to jumpstart your Laravel project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
