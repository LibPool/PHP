# ibrows/boxalino-bundle

> 标签: Symfony2, boxalino, bundle, ibrows

## 简介

A Symfony2 Bundle to export and search entities using the boxalino web services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
