# proklung/bitrixannotatedresolversbundle

> 标签: PHP

## 简介

Addon for Symfony bundle for transform parameters of request to DTO. Bitrix specify part

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
