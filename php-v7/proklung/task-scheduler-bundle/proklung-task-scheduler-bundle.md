# proklung/task-scheduler-bundle

> 标签: PHP

## 简介

A task scheduler for custom Symfony using CRON jobs porting that allows you to run tasks periodically

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
