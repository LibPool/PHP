# proklung/bitrix-model-bundle

> 标签: bitrix, bitrix-bundle, bitrix-symfony

## 简介

Бандл для Битрикс + Symfony для обращения с моделями инфоблоков.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
