# proklung/bitrix.redis.module

> 标签: bitrix, bitrix-cms, bitrix-d7, bitrix-module

## 简介

Поддержка очередей Redis (и не только) в Битриксе

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
