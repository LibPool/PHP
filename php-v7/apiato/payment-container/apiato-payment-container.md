# apiato/payment-container

> 标签: PHP

## 简介

An Apiato container which acts as a generic foundation to "plug in" different containers that interacts with specificpayment gateways (e.g., PayPal, Stripe, ...)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
