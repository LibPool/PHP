# bakraj/databasewatcher

> 标签: DataBaseWatcher, database, laravel, monitoring, statistics

## 简介

Laravel Package to track and monitor DB requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
