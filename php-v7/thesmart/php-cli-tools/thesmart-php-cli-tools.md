# thesmart/php-cli-tools

> 标签: cli, command line, progress bar, prompt, stdout, tabs

## 简介

A collection of tools to help with command line development in PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
