# abnermouke/supports

> 标签: PHP

## 简介

Supports是Abnermouke整理的PHP开源工具包，安装非常简单，因为它是一个标准的Composer包，这意味着只要使用的是PHP都可以正常使用它。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
