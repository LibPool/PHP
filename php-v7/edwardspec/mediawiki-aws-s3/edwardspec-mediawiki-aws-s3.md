# edwardspec/mediawiki-aws-s3

> 标签: PHP

## 简介

Allows MediaWiki to use Amazon S3 to store uploaded files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
