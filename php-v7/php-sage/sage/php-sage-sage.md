# php-sage/sage

> 标签: debug, debug_backtrace, dump, dumper, json_decode, php, sage, var_dump

## 简介

☯ Insightful PHP debugging assistant.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
