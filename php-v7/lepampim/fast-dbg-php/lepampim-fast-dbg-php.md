# lepampim/fast-dbg-php

> 标签: debug, dump, var_dump

## 简介

Library for debugging PHP pages simply and quickly in an HTML environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
