# justijndepover/laravel-google-recaptcha-v2

> 标签: PHP

## 简介

Easily add Google Recaptcha V2 to your Laravel application forms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
