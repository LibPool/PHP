# bahramali/telegram-bot-php

> 标签: PSR-4, bot, php, telegram, telegram bot php

## 简介

Telegram-Bot-PHP is a PHP library for interacting with the official Telegram Bot API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
