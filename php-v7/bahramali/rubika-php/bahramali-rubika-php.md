# bahramali/rubika-php

> 标签: PSR-4, Rubika-PHP, bot, manage rubika, php, rubika

## 简介

Rubika-PHP is a PHP Library for interaction with rubika (social network)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
