# robtesch/watson_tts

> 标签: ibm, php, text-to-speech, tts, watson

## 简介

A Laravel package for making use of IBM's Watson Text-To-Speech Service

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
