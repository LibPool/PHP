# skilla/lint-namespaces

> 标签: PHP

## 简介

Search all psr-4 namespaces defined in composer.json and check that all files under this namespaces are really complaint with these

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
