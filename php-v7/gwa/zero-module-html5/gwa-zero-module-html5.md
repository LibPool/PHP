# gwa/zero-module-html5

> 标签: Clean up, clean, library, soil, wordpress, zero, zero-library

## 简介

A wordpress html5 module for the zero-library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
