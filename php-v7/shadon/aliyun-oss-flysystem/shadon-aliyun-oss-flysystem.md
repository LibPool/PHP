# shadon/aliyun-oss-flysystem

> 标签: PHP

## 简介

This is a Flysystem adapter for the Aliyun OSS ~2.2.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
