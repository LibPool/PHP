# mtvs/eloquent-aggregate-rating

> 标签: PHP

## 简介

Automatic ratings aggregation for a Laravel Eloquent model with reviews.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
