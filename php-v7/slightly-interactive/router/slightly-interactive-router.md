# slightly-interactive/router

> 标签: PSR-11, psr-15, psr-7, psr11, psr15, psr7

## 简介

A PSR-7 and PSR-15 compliant router.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
