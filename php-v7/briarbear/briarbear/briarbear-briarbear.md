# briarbear/briarbear

> 标签: BriarBear, http, lscgzwd, swoole, yii2

## 简介

BriarBear, a framework to easy integration swoole and php frameworks

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
