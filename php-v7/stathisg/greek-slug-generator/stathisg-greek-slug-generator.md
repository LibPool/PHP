# stathisg/greek-slug-generator

> 标签: greek, greeklish, slug

## 简介

A slug (pretty URL) generator, which supports Greek UTF-8 encoded characters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
