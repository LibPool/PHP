# 2amigos/yii2-semantic-ui

> 标签: dosamigos, extension, library, yii, yii2-semantic-ui

## 简介

Semantic UI Extension library for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
