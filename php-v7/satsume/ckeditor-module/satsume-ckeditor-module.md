# satsume/ckeditor-module

> 标签: CKEditor, ckeditor module, zend framework 2, zf2

## 简介

A module to implement a ckeditor form element for Zend Framework 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
