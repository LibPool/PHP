# netom/phparsec

> 标签: functional, parser, recursive

## 简介

Library for implementing recursive descent parsers. (Very) loosely based on Haskell's attoparsec module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
