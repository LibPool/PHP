# ianez/yii2-bootstrap-multiselect

> 标签: bootstrap4, bootstrap5, extension, multiselect, widget, yii2

## 简介

Yii2 widget wrapper for David Stutz's bootstrap-multiselect plugin, featuring automatic detection and support for Bootstrap 4 and Bootstrap 5.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
