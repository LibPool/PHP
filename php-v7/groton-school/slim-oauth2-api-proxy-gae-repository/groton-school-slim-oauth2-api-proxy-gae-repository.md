# groton-school/slim-oauth2-api-proxy-gae-repository

> 标签: PHP

## 简介

Firestore access token repository for Slim OAuth2 API proxy running on Google App Engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
