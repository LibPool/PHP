# johnturingan/phpword

> 标签: PHP

## 简介

A fork from PHPOffice/PHPWord. PHPWord - A pure PHP library for reading and writing word processing documents (OOXML, ODF, RTF, HTML, PDF)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
