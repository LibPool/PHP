# jason-symbiote/silverstripe-contentreplace

> 标签: silverstripe, symbiote

## 简介

This module replaces certain tags in WYSIWYG content with SilverStripe templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
