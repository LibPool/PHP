# brussens/yii2-avatar-behavior

> 标签: Behavior, avatar, yii 2, yii2

## 简介

Behavior for the transparent operations of avatar thumbnails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
