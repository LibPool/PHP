# codesleeve/fixture

> 标签: Fixture, database, integration, test, testing

## 简介

A framework agnostic, simple (yet elegant) fixture library for php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
