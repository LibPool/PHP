# leoloso/pop-graphql-voyager

> 标签: graphiql, graphql, pop

## 简介

Integrate the GraphQL Voyager on the PoP API Demo site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
