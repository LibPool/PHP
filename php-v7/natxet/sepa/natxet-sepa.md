# natxet/sepa

> 标签: Cuadernos, Wire Transfer, sepa

## 简介

Generating SEPA Cuadernos standard files for wire transfers in Spain

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
