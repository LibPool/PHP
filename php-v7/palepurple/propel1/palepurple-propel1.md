# palepurple/propel1

> 标签: Active Record, database, legacy, mapping, orm, persistence

## 简介

Fork of Propel ORM (v1.7.x) with minor patches (phpdoc, PHP 7.x compatability etc)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
