# ifyazilim/dosyayukleme

> 标签: dosya yükleme, file upload, upload

## 简介

PHP ile dosya yükleme işlerinde kullanılan kütüphanedir.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
