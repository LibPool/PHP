# gregu92/bootstrap-select

> 标签: bootstrap, dropdown, form, javascript, jquery, replacement, select

## 简介

The jQuery plugin extending original jQuery plugin from https://snapappointments.com/bootstrap-select

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
