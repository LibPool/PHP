# treestone/postmigration

> 标签: Migration_, data-migration-tool, magento 2, migration, treestone

## 简介

Treestone extension to run after M1 to M2 migration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
