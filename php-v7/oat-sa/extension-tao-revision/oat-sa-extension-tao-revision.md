# oat-sa/extension-tao-revision

> 标签: TAO, computer-based-assessment

## 简介

The extension allows saving the intermediate state of objects and restoring them

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
