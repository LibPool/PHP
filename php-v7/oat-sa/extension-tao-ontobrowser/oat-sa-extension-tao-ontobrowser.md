# oat-sa/extension-tao-ontobrowser

> 标签: OAT, QTI, TAO, computer-based-assessment

## 简介

extension to browse ontology classes and resource into TAO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
