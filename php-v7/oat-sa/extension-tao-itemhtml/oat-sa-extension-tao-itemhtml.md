# oat-sa/extension-tao-itemhtml

> 标签: OAT, QTI, TAO, computer-based-assessment

## 简介

extension to manage HTML items in TAO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
