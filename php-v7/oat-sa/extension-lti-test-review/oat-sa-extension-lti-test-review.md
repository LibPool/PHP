# oat-sa/extension-lti-test-review

> 标签: TAO, computer-based-assessment

## 简介

Extension for reviewing passed tests, with the display of actual and correct answers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
