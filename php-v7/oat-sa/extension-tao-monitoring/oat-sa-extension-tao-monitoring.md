# oat-sa/extension-tao-monitoring

> 标签: TAO, tao-monitoring

## 简介

Extension for monitoring of the tao events. Fast access to statistics data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
