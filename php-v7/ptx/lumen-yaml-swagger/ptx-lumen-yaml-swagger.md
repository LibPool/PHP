# ptx/lumen-yaml-swagger

> 标签: PtxTech, lumen, swagger, yaml

## 简介

Swagger文档，用PHP注释可读性差，维护性差，使用YAML格式

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
