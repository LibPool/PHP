# fg/cakephp-multiplayer

> 标签: embed, html, media, player, video

## 简介

A plugin to use the Multiplayer library in a CakePHP 2 project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
