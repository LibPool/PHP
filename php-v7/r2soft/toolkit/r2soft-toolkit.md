# r2soft/toolkit

> 标签: chrome, headless, html-to-pdf, pdf, r2soft, toolkit

## 简介

Toolkit utilitário em PHP puro (ex.: URL→PDF via Chrome headless, helpers diversos).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
