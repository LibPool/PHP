# kasperfranz/laravel-plain-sqs

> 标签: aws, laravel, lumen, php, sqs

## 简介

Custom SQS connector for Laravel that supports custom format JSON

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
