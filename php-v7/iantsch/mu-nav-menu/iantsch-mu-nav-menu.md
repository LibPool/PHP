# iantsch/mu-nav-menu

> 标签: plugins, wordpress

## 简介

WordPress must-use plugin to register a custom extended front-end menu walker and new wrapper function for BEM styled CSS classes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
