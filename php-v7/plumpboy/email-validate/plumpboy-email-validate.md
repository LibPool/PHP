# plumpboy/email-validate

> 标签: PHP

## 简介

A library for validating email via SMTP, extends from https://github.com/semplon/php-smtp-email-validation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
