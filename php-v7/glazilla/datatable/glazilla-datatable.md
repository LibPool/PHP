# glazilla/datatable

> 标签: datatables, pdo-mysql, pdo-pgsql, slimframework

## 简介

Class generating JSON output form mysql/pdo pgsql/pdo usable for Javascript library DataTables

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
