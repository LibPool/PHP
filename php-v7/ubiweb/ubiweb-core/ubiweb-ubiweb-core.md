# ubiweb/ubiweb-core

> 标签: PHP

## 简介

Core framework for Ubiweb network.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/ubiweb-media/ubiweb-core.git
