> 标签: dns-lookup, domain-availability, php, rdap, reverse-whois, typosquatting, whois, whois-api, whois-lookup

## 简介

PHP WHOIS API client: live, historical, reverse and bulk WHOIS, DNS lookup, domain availability, typosquatting

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
