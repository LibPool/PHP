# makusu/silex-skeleton-rest

> 标签: PHP

## 简介

This skeleton / boilerplate is built using Silex for general ReSTful (API) purposes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
