# zhangchunsheng/php-qrcode

> 标签: autoload, dependency, package

## 简介

php qrcode is qrcode utils written in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/zhangchunsheng/php-qrcode.git
