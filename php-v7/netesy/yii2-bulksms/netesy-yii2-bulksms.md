# netesy/yii2-bulksms

> 标签:  api,  sms, extension, yii2

## 简介

A simple class to handle the bulk sms api for Nigerian bulk sms hhtp api connection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
