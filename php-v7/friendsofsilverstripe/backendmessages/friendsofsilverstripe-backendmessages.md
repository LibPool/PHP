# friendsofsilverstripe/backendmessages

> 标签: cms, message, notification, silverstripe, warning

## 简介

DRY way to create message boxes in SilverStripe backend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
