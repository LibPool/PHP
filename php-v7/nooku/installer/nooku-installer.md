# nooku/installer

> 标签: component, framework, installer, joomla, nooku, platform

## 简介

A Composer plugin to install Nooku Framework into any Joomla site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
