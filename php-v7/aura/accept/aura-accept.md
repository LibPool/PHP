# aura/accept

> 标签: accept, accept-charset, accept-encoding, accept-language, content negotiation, content type, media type

## 简介

Provides content-negotiation tools using Accept* headers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
