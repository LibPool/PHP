# swisnl/json-api-server

> 标签: JSON-API, json-api-server, laravel, laravel-api, swisnl

## 简介

Set up a JSON API in Laravel in just a few minutes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
