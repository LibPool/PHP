# tomhaoye/aliyun-dysms-sdk

> 标签: aliyun, dayu, sdk, sms

## 简介

Aliyun SMS message SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
