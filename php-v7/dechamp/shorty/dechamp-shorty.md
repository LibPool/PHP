# dechamp/shorty

> 标签: array, helper, isset, shorten

## 简介

Just a few tools to help avoid annoying things such as long logic where it should be simple.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
