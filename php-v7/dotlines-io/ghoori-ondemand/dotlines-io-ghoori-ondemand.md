# dotlines-io/ghoori-ondemand

> 标签: dotlines, dotlines-io, ghoori-ondemand

## 简介

This package can be used for OnDemand Payment integration with Ghoori Platform.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
