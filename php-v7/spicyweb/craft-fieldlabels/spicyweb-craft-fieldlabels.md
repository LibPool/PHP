# spicyweb/craft-fieldlabels

> 标签: craft-plugin, craftcms

## 简介

Override Craft CMS field labels and instructions in the field layout designer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
