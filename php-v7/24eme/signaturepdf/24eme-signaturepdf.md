# 24eme/signaturepdf

> 标签: PHP

## 简介

Free open-source web software for signing PDF (alone or with others) and also organize pages, edit medata and compress pdf

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
