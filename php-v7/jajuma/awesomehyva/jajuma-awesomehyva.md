# jajuma/awesomehyva

> 标签: PHP

## 简介

This Magento 2 extension allows using Font Awesome 5 icons with Hyvä Themes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
