# danny3b/cakepdf

> 标签: PHP

## 简介

CakePHP plugin for creating and/or rendering Pdfs, several Pdf engines supported.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
