# zeevin/libiocm

> 标签: OceanConnect, iocm, nb-iot, nbiot, 中国电信北向API

## 简介

中国电信物联网开放平台API对接库

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
