# sqits/laravel-api-skeleton

> 标签: Skeleton, api, artisan, crud, laravel, resource

## 简介

Package to create a complete Laravel API resource according to stub files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
