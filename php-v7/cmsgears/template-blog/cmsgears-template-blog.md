# cmsgears/template-blog

> 标签: blog, cmsgears, template, yii, yii 2, yii2

## 简介

The blog template uses core, forms, and cms modules with blog theme for website and admin theme for admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
