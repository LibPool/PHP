# cmsgears/widget-login

> 标签: ajax login, cmsgears, login, widget, yii2

## 简介

Login Widget for CMSGears provide Ajax based login and registration forms that can be called at desired location on a web page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
