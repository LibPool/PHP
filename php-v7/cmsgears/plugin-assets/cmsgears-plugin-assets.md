# cmsgears/plugin-assets

> 标签: assets, cmsgears, plugin, yii2

## 简介

Assets plugin provides asset bundles for standard and bower assets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
