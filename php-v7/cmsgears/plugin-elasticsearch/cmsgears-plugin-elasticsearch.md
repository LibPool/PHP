# cmsgears/plugin-elasticsearch

> 标签: cmsgears, elasticsearch, plugin, yii2

## 简介

Elasticsearch plugin for CMSGears provide component to process CRUD operations and search on Elasticsearch Server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
