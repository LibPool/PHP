# cmsgears/widget-club

> 标签: club, cmsgears, widget, yii2

## 简介

The Club widget for CMSGears. It provide options to render pagination widgets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
