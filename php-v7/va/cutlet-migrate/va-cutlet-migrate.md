# va/cutlet-migrate

> 标签: laravel, laravel-migration, laravel-migrations, laravel7, laravel7-package, laravel8, laravel9, migration, migrations, php

## 简介

A package to use migrate:update command with options for migrations in custom directories in laravel apps.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
