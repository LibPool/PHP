# shipphp/faster

> 标签: backup, deploy, deployment, ftp, git-deployment, multi-project, php-deployment, profile-management, restore, sync, upload

## 简介

Professional PHP deployment tool with git-like push/pull functionality, global installation, and profile management

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
