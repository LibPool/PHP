# samjuk/magento-patch-installer

> 标签: adobe-commerce, composer-plugin, magento, magento2, patches, security

## 简介

Applies Magento 2 / Adobe Commerce security patches, verifies they stay applied, and fails loudly when they do not

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
