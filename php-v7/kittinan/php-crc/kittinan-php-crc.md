# kittinan/php-crc

> 标签: ccitt, crc, crc1, crc16, crc16dnp, crc16qt, crc16usb, modbus, xmodem, zmodem

## 简介

Calculates CRC checksums for input data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
