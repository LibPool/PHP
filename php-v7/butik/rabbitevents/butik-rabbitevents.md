# butik/rabbitevents

> 标签: bus, event bus, events, laravel, queue, rabbitmq

## 简介

Laravel back-to-back broadcasting events. It uses RabbitMQ as the transport.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
