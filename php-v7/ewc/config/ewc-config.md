# ewc/config

> 标签: EWC, bash, cli, config, json, parsers, php, yaml

## 简介

Parse configuration options from multiple source types into a single interactive config object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
