# milivojsa/laravel-chrome

> 标签: chrome, dom, headless, laravel, webpage

## 简介

A Laravel Wrapper for Chrome Headless. Get the DOM of any webpage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
