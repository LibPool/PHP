# tomlerendu/microapi

> 标签: api, application, interface, lightweight, programming, rest

## 简介

An extremely lightweight PHP framework for creating APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
