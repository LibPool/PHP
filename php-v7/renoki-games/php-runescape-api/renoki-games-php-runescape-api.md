# renoki-games/php-runescape-api

> 标签: School, api, laravel, old, php, runescape, wrapper

## 简介

Runescape API is a simple wrapper for Old School Runescape, written in PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
