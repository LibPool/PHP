# doctorbeat/mysql-continued

> 标签: PHP

## 简介

A dropin replacement for the removed mysql_* functions in php7. Backward compatibility for deprecated mysql functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
