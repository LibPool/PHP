# estey/hipsupport

> 标签: HipSupport, Laravel 4, Live Chat, hipchat, laravel

## 简介

An easy to install Live Chat system that uses HipChat and Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
