# eslkem/gbx-parser

> 标签: ManiaPlanet, gbx, parser

## 简介

This package is made to parse Maniaplanet's GBX files and extract useful information from them.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
