# hacoidev/logmanager

> 标签: backpack, laravel, log interface, log manager, logs

## 简介

An interface to preview, download and delete Laravel log files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
