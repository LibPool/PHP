# twistor/flysystem-guzzle

> 标签: Flysystem, Guzzle

## 简介

An HTTP adapter for Flysystem that uses Guzzle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
