# utexas/utexas_smtp_helper

> 标签: drupal

## 简介

Provides a configuration override for SMTP credentials for use with Pantheon Hosting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
