# utexas/utexas_qualtrics_filter

> 标签: drupal

## 简介

Custom text filter to allow Qualtrics forms into WYSIWYG fields

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
