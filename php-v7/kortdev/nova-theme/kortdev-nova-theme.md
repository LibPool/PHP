# kortdev/nova-theme

> 标签: KortDev Theme, Laravel Nova Theme, Responsive Laravel Nova Theme, laravel, nova

## 简介

Kort.dev Laravel Nova theme based on 'A Responsive Laravel Nova theme'.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
