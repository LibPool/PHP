# backdrop/drush

> 标签: PHP

## 简介

This project allows you to use Drush with Backdrop CMS. Drush is a command-line tool for manipulating content management systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
