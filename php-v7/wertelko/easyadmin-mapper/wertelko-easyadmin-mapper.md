# wertelko/easyadmin-mapper

> 标签: content, easyadmin, symfony

## 简介

Simple bundle that allows map objects in the EasyAdmin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
