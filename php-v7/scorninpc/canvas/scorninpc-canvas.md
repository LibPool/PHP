# scorninpc/canvas

> 标签: PHP

## 简介

Re-work for modern PHP version of Canvas, great lib for image manipulation originally written by Davi Ferreira

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
