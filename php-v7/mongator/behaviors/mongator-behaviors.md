# mongator/behaviors

> 标签: behaviors, mongator

## 简介

Bahaviors for Mongator, the Simple, powerful and ultrafast Object Document Mapper (ODM) for PHP and MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
