# cornford/logical

> 标签: execution, laravel, logic, logical, persisted, results, sorted, statement

## 简介

An easy way execute logical statements over a none persisted results set in Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
