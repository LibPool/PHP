# rubix/iris

> 标签: Example Project, classification, cross validation, data science, dataset, iris flower, k nearest neighbors, knn, machine learning, ml, php, php ml, rubix ml, rubixml, tutorial

## 简介

An introduction to machine learning in Rubix ML using the famous Iris dataset and the K Nearest Neighbors classifier.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
