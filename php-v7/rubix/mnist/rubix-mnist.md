# rubix/mnist

> 标签: Example Project, Neural network, classification, cross validation, data science, dataset, dropout, feed forward, image classification, image recognition, machine learning, ml, mnist, multilayer perceptron, php, php ml, relu, rubix ml, rubixml, tutorial

## 简介

Handwritten digit recognizer using a feed forward neural network and the MNIST dataset of 70,000 human-labeled handwritten digits.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
