> 标签: Example Project, classification, classifier, credit score, cross validation, data science, data visualization, dataset, default risk prediction, dimensionality reduction, logistic regression, machine learning, manifold learning, ml, one hot, php, php ml, rubix ml, rubixml, t sne, t-sne, tutorial

## 简介

An example project that predicts the risk of credit card default using a Logistic Regression classifier and a 30,000 sample dataset of credit card customers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
