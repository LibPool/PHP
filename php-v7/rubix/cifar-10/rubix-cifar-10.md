# rubix/cifar-10

> 标签: Example Project, Neural network, batch norm, cifar 10, cifar-10, classification, cross validation, data science, dataset, dropout, elu, exponential linear unit, feed forward, image classification, image recognition, machine learning, ml, multilayer perceptron, php, php ml, rubix ml, rubixml, tutorial

## 简介

Use the famous CIFAR-10 dataset to train a multi-layer neural network to recognize images of cats, dogs, and other things.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
