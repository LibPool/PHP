# dotman/laravel-covid

> 标签: covid, covid-19, laravel, laravel-covid

## 简介

Covid-19 - A simple Laravel package for reporting covid-19 cases across the world.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
