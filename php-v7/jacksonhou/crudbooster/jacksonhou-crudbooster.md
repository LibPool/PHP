# jacksonhou/crudbooster

> 标签: admin-panel, backend, crud, crud-generator, crudbooster, generator, laravel

## 简介

CRUDBooster Is CRUD Generator Based On Laravel Easy To Make An Advanced Backend. And Resolve Some Bugs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
