# dmstr/yii2-vue-shufflejs-widget

> 标签: Shuffle.js, Vue.js, extension, javascript, yii2

## 简介

Yii2 Widget for Vue.js & VueShuffleJs plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
