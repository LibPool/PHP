# dmstr/yii2-cookie-button

> 标签: cms, extension, yii2

## 简介

Widget to store 0/1 in a cookie for Yii2 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
