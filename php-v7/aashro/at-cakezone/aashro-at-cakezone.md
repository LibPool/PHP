# aashro/at-cakezone

> 标签: PHP

## 简介

Modern TYPO3 v13 bakery template built with Content Blocks for showcasing cakes, menus, and bakery services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
