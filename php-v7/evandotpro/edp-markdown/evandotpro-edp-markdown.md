# evandotpro/edp-markdown

> 标签: ZendFramework, markdown

## 简介

A minimalist ZF2 module for adding markdown support to Zend Framework 2 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
