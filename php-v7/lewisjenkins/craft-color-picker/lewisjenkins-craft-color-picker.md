# lewisjenkins/craft-color-picker

> 标签: Craft, cms, craft color picker, craft-plugin, craftcms, lj color picker

## 简介

A simple color picker for Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
