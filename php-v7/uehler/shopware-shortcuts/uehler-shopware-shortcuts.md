# uehler/shopware-shortcuts

> 标签: backend, plugin, shopware, shortcuts

## 简介

this is a plugin for shopware 5.2 or newer which adds new shortcuts for the backend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
