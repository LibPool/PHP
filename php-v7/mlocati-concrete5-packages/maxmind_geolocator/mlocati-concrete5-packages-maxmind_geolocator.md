# mlocati-concrete5-packages/maxmind_geolocator

> 标签: concrete, concrete5, concreteCMS, geolocalization, geolocator, location, locator, maxmind

## 简介

Add a geolocator that uses a local MaxMind database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
