# mlocati-concrete5-packages/acme

> 标签: ACME, Concrete CMS, certificate, concrete, concrete5, concreteCMS, https, let s encrypt, lets encrypt, letsencrypt, package, security, ssl, tls

## 简介

A package for ConcreteCMS to create and manage HTTPS certificates for your websites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
