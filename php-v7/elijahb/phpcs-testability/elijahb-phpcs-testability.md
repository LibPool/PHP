# elijahb/phpcs-testability

> 标签: php-code-sniffer, phpcs, phpunit, sniff

## 简介

PHPCodeSniffer sniffs for unit test code testability check

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
