# suin/xoopsunit

> 标签: PHP

## 简介

XoopsUnit is a extension of PHPUnit. You can write simplier test code with XoopsUnit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
