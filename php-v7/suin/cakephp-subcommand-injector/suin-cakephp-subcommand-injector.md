# suin/cakephp-subcommand-injector

> 标签: cakephp, cakephp3

## 简介

CakePHP Subcommand Injector make it possible that automatical adding Task classes as subcommands of a Shell class.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
