# suin/php-cs-fixer-rules

> 标签: php-cs-fixer, rules

## 简介

A Rule set for PHP-CS-Fixer mainly targeting PHP 7.1 or higher.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
