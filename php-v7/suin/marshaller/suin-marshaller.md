# suin/marshaller

> 标签: class, decoder, encoder, json, marshaller, object, unmarshaller

## 简介

Type-safe data mapping between JSON and a PHP class object.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
