# riimu/kit-urlparser

> 标签: parser, psr-7, rfc3986, uri, url

## 简介

RFC 3986 compliant url parsing library with PSR-7 Uri component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
