# rasim/image-palette

> 标签: color, extractor, gd, image, laravel, palette

## 简介

Extracts colors from an image and generates a color palette against a whitelist of colors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
