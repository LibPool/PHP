# vhrb/elastic-search

> 标签: elastic, elasticsearch, es, nette, search

## 简介

Integration official PHP client for Elasticsearch into Nette Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
