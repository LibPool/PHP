# jakubboucek/legacy-escape

> 标签: PHP

## 简介

Right escape data inserted to HTML, CSS, JS and URL. Substrate of Latte/Latte package.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
