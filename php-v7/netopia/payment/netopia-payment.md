# netopia/payment

> 标签: PHP

## 简介

Set of library that give you the means to incorporate NETOPIA Payments functionality into your website applications and mobile apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
