# joacub/doctrine-orm-module

> 标签: doctrine, module, orm, zf2

## 简介

Zend Framework 2 Module that provides Doctrine ORM functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
