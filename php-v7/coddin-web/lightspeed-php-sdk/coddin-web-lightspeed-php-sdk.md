# coddin-web/lightspeed-php-sdk

> 标签: api, client, ecom, lightspeed, php

## 简介

An improved PHP client for the Lightspeed eCom API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
