# meesoverdevest/wp_on_laravel

> 标签: laravel, package, wordpress

## 简介

A package that syncs WordPress posts, categories and tags with your laravel project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
