> 标签: composer, env, plugin, pro, wordpress, wp, wp-migrate-db, wpmdb

## 简介

An install helper for Wordpress Migrate DB Pro

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
