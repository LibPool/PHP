# bronek/code-complexity

> 标签: PHP

## 简介

Simple tool to measure code cyclomatic complexity as described on https://phpmd.org/rules/codesize.html

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
