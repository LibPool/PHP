# blitzr/php-client

> 标签: PHP

## 简介

The official Blitzr API Client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://api.blitzr.com/
- 源码仓库：https://github.com/blitzr/blitzr-php-client.git
- Packagist 页面：https://packagist.org/packages/blitzr%2Fphp-client
