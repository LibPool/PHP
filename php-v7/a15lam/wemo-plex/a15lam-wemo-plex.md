# a15lam/wemo-plex

> 标签: DLNA, Home Theater, Wemo, plex, wemo-plex

## 简介

Control Wemo devices by Plex Media Server activity

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
