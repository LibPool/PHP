# workhouse-advertising/omnipay-mpgs

> 标签: gateway, merchant, mpgs, omnipay

## 简介

Mastercard Payment Gateway Service (MPGS) gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
