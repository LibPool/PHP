# hickeroar/zf2-route-inheritance

> 标签: extend, framework, override, route, routing, zf2

## 简介

Allows ZF2 routes to extend other routes, overriding options.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
