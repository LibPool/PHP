# dskzpt/typo3-ux-chartjs

> 标签: ViewHelpers, chartjs, extension, stimulus-js, typo3

## 简介

Easily build and render Chart.js charts in PHP and Fluid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
