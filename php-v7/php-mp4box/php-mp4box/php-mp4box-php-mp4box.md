# php-mp4box/php-mp4box

> 标签: gpac, mp4box

## 简介

PHP MP4Box, an Object Oriented library for easy file conversion with MP4 Box

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
