# mageplaza/module-smtp

> 标签: Facebook ADS, Marketing Automation, Messenger, email, email marketing, email settings, facebook, gmail smtp, google ads, magento 2, magento 2 smtp, magento smtp, mageplaza, sms, sms marketing, smtp, web push notification, whatsapp

## 简介

SMTP Extension for Magento 2 helps the owner of store simply install SMTP (Simple Mail Transfer Protocol) server which transmits the messages into codes or numbers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
