# phax/phax-bundle

> 标签: Symfony2, ajax, php

## 简介

A php/javascript symfony2 bundle which provide a structure for ajax calls

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
