# linio/queue

> 标签: distributed, linio, queue, rabbit, rabbitmq

## 简介

Abstracts work queues, used to distribute time-consuming tasks among multiple workers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
