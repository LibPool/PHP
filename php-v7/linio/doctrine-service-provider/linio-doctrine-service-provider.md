# linio/doctrine-service-provider

> 标签: dbal, doctrine, linio, orm, pimple

## 简介

Doctrine DBAL and ORM service providers for Pimple 3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
