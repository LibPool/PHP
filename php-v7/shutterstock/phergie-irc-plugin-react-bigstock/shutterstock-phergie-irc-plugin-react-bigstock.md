# shutterstock/phergie-irc-plugin-react-bigstock

> 标签: bot, irc, phergie, plugin

## 简介

Phergie plugin for Use Bigstock API to search for and display images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
