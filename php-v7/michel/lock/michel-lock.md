# michel/lock

> 标签: flock, lock, mutex, native-php, process-synchronization

## 简介

A flexible PHP locking library designed to prevent race conditions in CLI and web environments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
