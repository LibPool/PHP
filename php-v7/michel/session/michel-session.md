# michel/session

> 标签: PHP

## 简介

PHP Session is a PHP library that optimizes session management, utilizing PHP's native session handling mechanisms for enhanced security and efficiency.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
