# tanseercena/php-exchange-rates

> 标签: PHP

## 简介

PHP Exchange Rates Library/Package provides APIs for latest exchange rates and historical rates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
