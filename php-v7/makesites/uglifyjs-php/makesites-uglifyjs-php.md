# makesites/uglifyjs-php

> 标签: minify, saas, uglifyjs

## 简介

Using UglifyJS as a service for JavaScript minification in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
