# dg/adminer

> 标签: database, elasticsearch, mongodb, mssql, mysql, oracle, postgresql, sqlite

## 简介

Customization for Adminer, the best database management tool written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
