# bidibidi/origin

> 标签: bidibidi, laravel, layouts, page, starter

## 简介

Add most common pages (about-us, contact, faq.. etc) to laravel project with basic layouts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
