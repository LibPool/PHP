# cpsit/t3events_course

> 标签: course, events, extension, typo3

## 简介

Courses is an extension for the TYPO3 CMS. It extends t3events by functionality for managing courses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
