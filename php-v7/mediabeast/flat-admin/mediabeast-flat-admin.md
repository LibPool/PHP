# mediabeast/flat-admin

> 标签: admin, flat, mediabeast, silverstripe, theme

## 简介

Custom CSS theme for SilverStripe 3 Admin Interface

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
