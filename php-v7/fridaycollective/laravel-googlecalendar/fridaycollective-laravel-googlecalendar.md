# fridaycollective/laravel-googlecalendar

> 标签: api, gmail, laravel

## 简介

Google Calendar API package for Laravel based on dacastro4/laravel-gmail

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
