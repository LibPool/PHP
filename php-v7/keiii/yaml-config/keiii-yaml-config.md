# keiii/yaml-config

> 标签: config, yaml

## 简介

YAML config utilize symfony components (The Config Component and The Yaml Component) to provide symfony like configuration for any application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
