# dothiv/dothiv-valueobject-bundle

> 标签: Symfony2, ValueObject, bundle

## 简介

dotHIV valueobject bundle for Symfony2 is a collection of value objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
