# gracious/interconnect-magento1

> 标签: PHP

## 简介

Webhook module for Magento 1 that channels data to the Gracious Interconnect webservice which in turn formats and proxies the data to connected consumer services

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
