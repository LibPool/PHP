# elgervb/imagemanipulation

> 标签: color utils, gd, image filters, image overlays, image reflection, image rotate, image thumbnail, image watermark, images, manipulation

## 简介

Library for image manipulation in PHP with GD

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
