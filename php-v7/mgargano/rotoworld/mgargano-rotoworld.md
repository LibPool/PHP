# mgargano/rotoworld

> 标签: fantasy news, fantasy sports news, rotoworld

## 简介

Composer package that parses Rotoworld's DOM for news stories

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
