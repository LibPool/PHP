# craos/pgdump

> 标签: craos, dump, oberdanbrito, pgdump, postgresql

## 简介

Executa o dump aprimorado do banco de dados PostgrSQL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
