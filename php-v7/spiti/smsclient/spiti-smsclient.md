# spiti/smsclient

> 标签: api, devino, devinosms, devinotelecom, sms

## 简介

PHP-класс для работы с API сервисов СМС уведомлений

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
