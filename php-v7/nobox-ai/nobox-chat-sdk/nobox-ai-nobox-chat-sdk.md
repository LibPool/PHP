# nobox-ai/nobox-chat-sdk

> 标签: chat, inbox, nobox, nobox-ai, sdk, signalr, webhook, websocket, whatsapp

## 简介

Official PHP SDK and Real-time SignalR WebSocket Client for NoBox.Ai platform integration

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
