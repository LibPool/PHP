# ritey/mailgun

> 标签: laravel, mail, mailgun

## 简介

A laravel 4.1 wrapper for sending mail via the Mailgun API in Laravel 4 style

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
