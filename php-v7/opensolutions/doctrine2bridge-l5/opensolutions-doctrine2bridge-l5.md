# opensolutions/doctrine2bridge-l5

> 标签: doctrine2, laravel

## 简介

Adds the the power of Doctrine2 to Laravel 5 (with support for SQL logging and authentication)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
