# tp5er/images

> 标签: image, 图片水印, 生成缩略图, 裁剪图片

## 简介

一个不依赖任何框架的image操作类，独立thinkphp3.2.3中Image类

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
