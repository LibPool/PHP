# sinkcup/location-based-service-php

> 标签: PHP

## 简介

PHP LBS 位置服务（composer版）：geocoding地理编码、反向地理编码、距离计算

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
