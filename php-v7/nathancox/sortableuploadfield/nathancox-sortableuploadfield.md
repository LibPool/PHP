# nathancox/sortableuploadfield

> 标签: cms, files, silverstripe, uploadfield

## 简介

A subclass of UploadField that allows for sorting the managed files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
