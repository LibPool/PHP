# nihilarr/the-movie-db-api

> 标签: api, library, movie, php, themoviedb, tmdb

## 简介

A (very) simple library to access The Movie DB data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
