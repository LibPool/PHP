# crmplease/coder

> 标签: Coder, code-generation

## 简介

Coder is library for code-generation, e.g. add property to class, parameter to method, value to array and etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
