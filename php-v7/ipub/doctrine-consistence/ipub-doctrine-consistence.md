# ipub/doctrine-consistence

> 标签: consistence, doctrine, ipub, ipublikuj, nette, tools

## 简介

Consistence registration extension for Nette and Doctrine 2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
