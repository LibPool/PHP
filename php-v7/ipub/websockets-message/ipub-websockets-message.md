# ipub/websockets-message

> 标签: WebSockets, framework, ipub, ipublikuj, message, nette, tools

## 简介

Extension for implementing classic websocket messages with ipub/websockets websocket server with client side

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
