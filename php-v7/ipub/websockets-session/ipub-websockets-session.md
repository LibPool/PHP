# ipub/websockets-session

> 标签: WebSockets, framework, ipub, ipublikuj, nette, session, tools

## 简介

Extension for implementing sessions into ipub/websockets server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
