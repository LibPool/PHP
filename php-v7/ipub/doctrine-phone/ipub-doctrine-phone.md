# ipub/doctrine-phone

> 标签: doctrine, ipub, ipublikuj, nette, phone, tools

## 简介

Phone number manipulation for Nette Framework and Doctrine 2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
