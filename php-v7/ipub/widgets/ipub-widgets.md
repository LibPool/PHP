# ipub/widgets

> 标签: components, ipub, ipublikuj, nette, tools, widgets

## 简介

Extension for Nette Framework to manage page dynamical component alias widgets.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
