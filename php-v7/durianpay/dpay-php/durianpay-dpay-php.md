# durianpay/dpay-php

> 标签: PHP

## 简介

SDK that wraps collections of Durianpay's APIs, written in php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/durianpay/dpay-php.git
