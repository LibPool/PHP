# milesherndon/s3-backups

> 标签: Craft, S3 Backups, aws, cms, craft-plugin, craftcms, s3

## 简介

Plugin to backup Craft to AWS S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
