# firebase-php/google-auth

> 标签: Authentication, firebase-php, google, oauth2

## 简介

A fork of Google Auth Library used in Firebase PHP project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
