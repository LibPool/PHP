# awd-studio/smsc

> 标签: api, sms, smsc

## 简介

An API for sending messages with the https://smsc.ua / https://smsc.ru / https://smsc.kz / https://smsc.tj / https://smscentre.com services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
