# processmaker/pmql

> 标签: PHP

## 简介

An Eloquent trait that provides the pmql scope to allow converting simple sql criteria clauses to Eloquent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
