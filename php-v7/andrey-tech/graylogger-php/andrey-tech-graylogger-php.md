# andrey-tech/graylogger-php

> 标签: 1.1, PSR3, gelf, graylog, log, logger, logging, tcp

## 简介

Простой PSR-3 логгер в Graylog в формате GELF версии 1.1 по протоколу TCP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
