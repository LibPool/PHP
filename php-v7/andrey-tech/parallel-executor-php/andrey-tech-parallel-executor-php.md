# andrey-tech/parallel-executor-php

> 标签: parallel, threads

## 简介

Класс, выполняющий задачи в нескольких отдельных параллельных потоках PHP при помощи расширения parallel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
