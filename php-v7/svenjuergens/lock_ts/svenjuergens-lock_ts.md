# svenjuergens/lock_ts

> 标签: TypoScript Templates, backend, extension, typo3

## 简介

A simple write protection for TypoScript Templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
