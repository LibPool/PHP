# mckelvey/property-router

> 标签: Craft, cms, craft-plugin, craftcms, property router

## 简介

Parses URL to provide for dynamic property searches.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
