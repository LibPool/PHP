# wrdx/facebook-cake-session-persistent-data-handler

> 标签: PHP

## 简介

CakePHP 2.x session handler for Facebook php-graph-sdk

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
