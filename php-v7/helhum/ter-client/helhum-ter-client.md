# helhum/ter-client

> 标签: PHP

## 简介

Client for interacting with the official TYPO3 Extension Repository (TER). Contains API Symfony Commands

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
