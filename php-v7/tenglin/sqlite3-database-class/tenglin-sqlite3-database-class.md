# tenglin/sqlite3-database-class

> 标签: database, php, sqlite3

## 简介

Wrapper for a PHP sqlite3 class, which utilizes sqlite3 and prepared statements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
