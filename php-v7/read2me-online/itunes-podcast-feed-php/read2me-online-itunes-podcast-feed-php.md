# read2me-online/itunes-podcast-feed-php

> 标签: itunes, podcast feed, rss

## 简介

A tiny PHP library for generating iTunes-compatible podcast feeds.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
