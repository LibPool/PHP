# insolita/yii2-fixturegii

> 标签: extension, yii2

## 简介

gii fixture helper - generate fixture classes; faker templates; fixture data files from table

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
