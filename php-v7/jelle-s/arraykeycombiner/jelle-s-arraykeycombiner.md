# jelle-s/arraykeycombiner

> 标签: PHP

## 简介

Combines arrays by searching for intersections and adding them to the master array. Keys are combined using a delimiter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
