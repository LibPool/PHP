# foobarfighters/zend-server-web-api

> 标签: Web API, deploy, zend server, zendserver

## 简介

PHP wrapper for the Zend Server Web API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
