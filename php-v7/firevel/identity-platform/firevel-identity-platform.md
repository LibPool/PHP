# firevel/identity-platform

> 标签: Authentication, auth, firebase, firevel, google cloud, identity platform, import, laravel

## 简介

Import firebase users from Laravel using Google Identity Platform API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
