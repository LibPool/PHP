# firevel/firequent

> 标签: app engine, eloquent, firequent, firestore, firevel, google cloud, laravel, serverless

## 简介

Limited implementation of Eloquent based on Firestore.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
