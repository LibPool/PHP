# idci/aws-ses-bundle

> 标签: amazon, mail, ses

## 简介

A bundle that embed the php library `php-aws-ses` from daniel-zaharie into Symfony 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
