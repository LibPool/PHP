# gruppodigitouch/adform-php-sdk

> 标签: Guzzle, adform, api

## 简介

AdForm APIs Client for PHP based on Guzzle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
