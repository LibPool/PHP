# catzconnect/catzconnect-php

> 标签: catzconnect, email, messaging, otp, push, sdk, sms, voice, whatsapp

## 简介

Official PHP SDK for Catz Connect: send email, WhatsApp, push, SMS and voice messages and manage voice/video calls through one encrypted API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
