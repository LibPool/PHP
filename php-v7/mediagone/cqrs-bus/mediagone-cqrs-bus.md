# mediagone/cqrs-bus

> 标签: bus, command, cqrs, ddd, event, middleware, query

## 简介

DDD ready implementation of Command, Event and Query bus.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
