# imtigger/unicode-filter

> 标签: filter, php, string, unicode

## 简介

PHP Unicode string filter library based on Unicode Blocks defined by Unicode standard

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
