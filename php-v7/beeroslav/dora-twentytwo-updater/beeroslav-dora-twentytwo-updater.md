# beeroslav/dora-twentytwo-updater

> 标签: PHP

## 简介

WordPress updater class for plugins and themes hosted in private GitHub repositories, using release assets for secure auto-updates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
