# garlic/graphql

> 标签: graphql, microservices

## 简介

GraphQL Bundle uses for sending and receiving graphql queries among microservices through Garlic Message Bus.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
