# nancheng/pfinal-webuploader

> 标签: Q哥, pfinal, php-uploader, webuploader, 南丞

## 简介

基于webuploader插件封装的laravel扩展包

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
