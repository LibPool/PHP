# veniva/zcms

> 标签: Zend Framework, cms, doctrine, micro-cms

## 简介

A light weight CMS based on Zend Framework 3 and Doctrine 2 ORM

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
