# bbmri/simplesamlphp-module-lshostel

> 标签: bbmri, bbmri-eric, lifescience hostel, simplesamlphp

## 简介

A SimpleSAMLphp module providing template for DiscoPower and user-facing parts of the SSP for LifeScience Hostel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
