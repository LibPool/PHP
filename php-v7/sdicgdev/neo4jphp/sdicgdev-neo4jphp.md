# sdicgdev/neo4jphp

> 标签: database, graph, neo4j

## 简介

Wrapper for the Neo4j graph database REST interface. Works with PHP 7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
