# netresearch/typo3-site-conformance-skill

> 标签: PHP

## 简介

Netresearch AI skill for TYPO3 site/project conformance — deployable repos (type:project + Docker/Compose): layout, containers, Concourse CI, supply-chain, secrets, Valkey/ofelia

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
