# netresearch/peer-qa-review-skill

> 标签: PHP

## 简介

Round-1 IT QA peer-review runbook: lifecycle, checklist, severity vocabulary, comment template, edge cases, anti-patterns. Generic for any IT/Ops team.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
