# netresearch/typo3-project-upgrade-skill

> 标签: PHP

## 简介

Claude Code skill for upgrading deployed TYPO3 project instances across major versions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
