# apihub-cdc/rcc-ficoscore-simulacion-client

> 标签: api, apihub, php, sdk

## 简介

Esta API simula el Reporte de Cédito Consolidado con FICO® Score.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
