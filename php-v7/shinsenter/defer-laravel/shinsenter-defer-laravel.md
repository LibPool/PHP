# shinsenter/defer-laravel

> 标签: defer-laravel, defer.php, laravel, lazy loading, lazyload, lazyload css, lazyload font, lazyload image, lazyload js, lazyload video, loading lazy, lumen, performance, shinsenter

## 简介

🚀 A Laravel package that focuses on minimizing payload size of HTML document and optimizing processing on the browser when rendering the web page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
