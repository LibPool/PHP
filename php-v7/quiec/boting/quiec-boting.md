# quiec/boting

> 标签: Multi-thread, api, telegram, telegram bot

## 简介

Simple but powerful and Async(multi-thread) Telegram Bot library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
