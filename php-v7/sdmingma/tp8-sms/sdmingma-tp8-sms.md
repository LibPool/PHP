# sdmingma/tp8-sms

> 标签: aliyun, sms, tencent, thinkphp, verification Code

## 简介

ThinkPHP 8.0 SMS SDK - 支持阿里云、腾讯云等多平台短信验证码发送

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
