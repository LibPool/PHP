# mimmi20/wurflcache

> 标签: Wurfl, cache

## 简介

the Cache Classes for the Wurfl PHP Library for PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
