# unbug4120/php-simple-html

> 标签: Simple, dom, html, parser, php, simplehtmldom

## 简介

A fast, simple and reliable HTML document parser for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
