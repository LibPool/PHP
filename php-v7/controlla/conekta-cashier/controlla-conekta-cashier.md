# controlla/conekta-cashier

> 标签: billing, conekta, controlla, laravel

## 简介

Controlla Cashier nos da una interface para cobrar subscripciones con Conketa en Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
