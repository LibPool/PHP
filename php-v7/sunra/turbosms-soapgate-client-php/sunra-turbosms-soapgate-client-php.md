# sunra/turbosms-soapgate-client-php

> 标签: gate, sms, soap

## 简介

Client library for connect to soap gate of TurboSMS.ua

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
