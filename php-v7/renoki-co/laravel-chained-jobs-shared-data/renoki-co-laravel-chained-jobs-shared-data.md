# renoki-co/laravel-chained-jobs-shared-data

> 标签: jobs, laravel, php, queue, shared

## 简介

Share data between chained jobs in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
