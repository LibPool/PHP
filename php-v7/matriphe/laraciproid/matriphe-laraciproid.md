# matriphe/laraciproid

> 标签: city, data, id, ina, indonesia, laravel, province, seeder

## 简介

Indonesia city and province data migration and seeder for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
