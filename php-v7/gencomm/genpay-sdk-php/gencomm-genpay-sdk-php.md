# gencomm/genpay-sdk-php

> 标签: checkout, gencomm, genpay, intermediary, libraries, marketplace

## 简介

Cliente em PHP para integração server-side com APIs GenPay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
