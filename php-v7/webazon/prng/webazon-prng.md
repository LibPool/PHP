# webazon/prng

> 标签: PHP

## 简介

KISS-PRNG | Простой алгоритм шифрования на основе генератора псевдослучайных чисел

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
