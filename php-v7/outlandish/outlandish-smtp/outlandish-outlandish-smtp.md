# outlandish/outlandish-smtp

> 标签: plugin, smtp, wordpress, wp

## 简介

Provides a number of different ways to set how WordPress sends emails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
