# integer-net/magento2-configurable-wysiwyg

> 标签: PHP

## 简介

Configure the Magento 2 WYSIWYG Editors: Remove buttons, adjust headings, ...

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
