# cmgtools/breeze-icons

> 标签: breeze, css, framework, front-end, web

## 简介

Breeze Icons is icon library providing several useful and good looking icons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
