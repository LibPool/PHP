# cmgtools/velocity

> 标签: JS, framework, front-end, velocity, web

## 简介

Velocity is a JavaScript library which provide utilties, UI components and MVC framework implementation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
