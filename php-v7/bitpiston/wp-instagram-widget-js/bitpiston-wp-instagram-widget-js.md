# bitpiston/wp-instagram-widget-js

> 标签: PHP

## 简介

A client side drop-in replacement for Scott Evans's WP Instagram Widget plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
