# imelgrat/opml-parser

> 标签: HTML Parser, OPML iterator, OPML parser, PHP iterator, opml, parser, parser HTML, playlist parser, rss parser, xml, xml parser

## 简介

OPML Parser Class: Extract the properties of content from OPML files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
