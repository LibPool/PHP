# securesubmit/heartland-php

> 标签: api, heartland, heartland payment systems, hps, payment processing, securesubmit

## 简介

PHP SDK for processing payments via Portico Gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
