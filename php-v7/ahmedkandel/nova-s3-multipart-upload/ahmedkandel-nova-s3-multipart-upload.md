# ahmedkandel/nova-s3-multipart-upload

> 标签: aws, laravel, nova, s3, upload

## 简介

A Laravel Nova s3 multipart upload tool.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
