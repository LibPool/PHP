# piggly/php-pix-app

> 标签: PHP

## 简介

Um projeto simples de uma aplicação para gerar os pix para pagamento de forma mais rápida e prática.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
