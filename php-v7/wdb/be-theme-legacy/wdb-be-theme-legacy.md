# wdb/be-theme-legacy

> 标签: backend, cms, extension, icons, modules, theme, typo3

## 简介

Displayes colored Icons in the backend of TYPO3 v14 like in former versions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
