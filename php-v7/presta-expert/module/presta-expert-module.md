# presta-expert/module

> 标签: boilerplate, example, module, prestashop

## 简介

The boilerplate for module for PrestaShop 1.5 - 1.7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
