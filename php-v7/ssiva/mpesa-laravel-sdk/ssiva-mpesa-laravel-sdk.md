# ssiva/mpesa-laravel-sdk

> 标签: PHP

## 简介

This package provides a seamless integration of M-PESA Daraja APIs in Laravel applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
