# ssiva/yii2-mpesa-sdk

> 标签:  daraja,  mpesa, extension, yii2

## 简介

This package provides a seamless integration of M-PESA Daraja APIs in Yii2 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
