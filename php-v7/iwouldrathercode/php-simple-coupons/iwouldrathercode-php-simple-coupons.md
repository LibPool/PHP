# iwouldrathercode/php-simple-coupons

> 标签: Simple, coupon, coupons, generator, random_bytes, simple coupon, token, unique, voucher

## 简介

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
