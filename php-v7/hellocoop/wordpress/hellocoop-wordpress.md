# hellocoop/wordpress

> 标签: OpenId, wordpress

## 简介

Free and simple to setup plugin provides registration and login with the Hellō Wallet. Users choose from popular social login, email, or phone.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
