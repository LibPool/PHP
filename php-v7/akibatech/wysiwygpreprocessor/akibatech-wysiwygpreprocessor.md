# akibatech/wysiwygpreprocessor

> 标签: bbcode, link, path, plugin, processor, tags, textarea, wysiwyg

## 简介

A PHP library for processing wysiwyg/textarea output.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
