# monospice/laravel-view-composers

> 标签: composer, creator, laravel, view

## 简介

An intuitive abstraction for organizing Laravel View Composers and View Creators

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
