# dickyermawan/yii2-telegram-log

> 标签: extension, log, telegram, telegram-log, yii2

## 简介

Yii2 telegram log to sends logs in Yii2 to telegram.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
