# pschwisow/phergie-irc-plugin-react-altnick

> 标签: bot, irc, phergie, plugin

## 简介

Phergie plugin for switching to alternate nicks when primary is not available

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
