# sjaakp/yii2-bandoneon

> 标签: accordion, extension, widget, yii, yii2

## 简介

Lightweight accordion widget for Yii 2.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
