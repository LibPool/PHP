# phower/router

> 标签: PHP

## 简介

PHP routing package compliant with PSR-7.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/phower%2Frouter
- 源码仓库：https://github.com/phower/router.git
- Packagist 页面：https://packagist.org/packages/phower%2Frouter
