# phower/config

> 标签: config, php

## 简介

Simplified methods to handle configuration data in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/phower/config
- 源码仓库：https://github.com/phower/config.git
- Packagist 页面：https://packagist.org/packages/phower%2Fconfig
