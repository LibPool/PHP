# leedavis81/drest-common

> 标签: api, doctrine2, rest

## 简介

Common components shared between leedavis81/drest (server) and leedavis81/drest-client libraries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
