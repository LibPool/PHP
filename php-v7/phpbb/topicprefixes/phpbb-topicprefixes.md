# phpbb/topicprefixes

> 标签: PHP

## 简介

An official phpBB extension for topic prefixes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.phpbb.com/customise/db/extension/topicprefixes/
- 源码仓库：https://github.com/phpbb-extensions/topicprefixes.git
