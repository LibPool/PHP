# phpbb/titania

> 标签: PHP

## 简介

This adds a very powerful and large customisation database to your forum. It is codenamed titania.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/phpbb/customisation-db.git
