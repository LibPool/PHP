# mademedia/silverstripe-cloudinary

> 标签: cloudinary, madehq, mademedia, silverstripe

## 简介

Adds the Cloudinary browser to the CMS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
