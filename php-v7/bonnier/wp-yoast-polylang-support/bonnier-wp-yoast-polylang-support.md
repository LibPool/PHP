# bonnier/wp-yoast-polylang-support

> 标签: plugin, wp, yoast seo

## 简介

Wordpress mu plugin that enables Yoast settings to be stored per language created in Polylang

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
