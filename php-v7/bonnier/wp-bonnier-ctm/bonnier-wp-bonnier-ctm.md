# bonnier/wp-bonnier-ctm

> 标签: PHP

## 简介

This plugin allows you to integrate your site with Cthe Campaign Teaser Manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
