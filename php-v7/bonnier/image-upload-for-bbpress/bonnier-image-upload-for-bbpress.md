# bonnier/image-upload-for-bbpress

> 标签: bbPress, plugin, wordpress

## 简介

Upload inline images to BBPress forum topics and replies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
