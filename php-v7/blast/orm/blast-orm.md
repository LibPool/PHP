# blast/orm

> 标签: database, entity, mapper, orm, query, repository, sql

## 简介

Framework agnostic data access and persistence based on Doctrine 2 DBAL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
