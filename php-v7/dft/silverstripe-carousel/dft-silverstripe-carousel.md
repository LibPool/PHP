# dft/silverstripe-carousel

> 标签: carousel, silverstripe, slider

## 简介

A base framework for creating sliders/carousels on your SilverStripe site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
