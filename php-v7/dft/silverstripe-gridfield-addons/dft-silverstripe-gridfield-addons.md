# dft/silverstripe-gridfield-addons

> 标签: component, gridfield, silverstripe

## 简介

GridFieldAddOns is a collection of plugins for the Silverstripe GridField.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
