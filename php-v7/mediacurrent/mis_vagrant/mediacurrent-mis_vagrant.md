# mediacurrent/mis_vagrant

> 标签: drupal, vagrant, virtual machine, vm

## 简介

A VM for local Drupal development, built with Vagrant + Ansible

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
