# win0err/pghelpers

> 标签: pg_array_parse, php, postgres, postgresql

## 简介

A set of helper functions in PHP for working with PostgreSQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
