# santanamic/wc-z4money

> 标签: Z4Money, boleto, brazil, credtcard, e-commerce, payments

## 简介

Take payments on CredtCard and Boleto using Z4Money.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
