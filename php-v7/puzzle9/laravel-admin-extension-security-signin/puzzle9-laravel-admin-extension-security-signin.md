# puzzle9/laravel-admin-extension-security-signin

> 标签: extension, laravel-admin, security-signin

## 简介

适用于 laravel-admin 的 安全登录扩展,支持登录时验证码、限流、rsa加密等

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
