# fireworkweb/fwd

> 标签: Laravel Zero, cli, console, docker, docker-compose, framework, fwd, laravel

## 简介

Tool for simple docker based environments for Laravel applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
