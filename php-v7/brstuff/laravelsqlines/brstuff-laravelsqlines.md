# brstuff/laravelsqlines

> 标签: LaravelSqlines, brstuff, laravel, sqlines

## 简介

Simple laravel package to manage the sync of databases over Sqlines

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
