# hitrov/oci-api-php-request-sign

> 标签: api, oci, request, signature

## 简介

This package generates proper HTTP headers to sign Oracle Cloud Infrastructure API requests

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
