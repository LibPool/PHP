# kykint/php-weasyprint

> 标签: WeasyPrint, pdf, php

## 简介

PHP library allowing PDF generation from an url or a html page. Wrapper for Kozea/WeasyPrint.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
