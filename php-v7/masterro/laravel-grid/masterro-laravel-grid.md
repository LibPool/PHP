# masterro/laravel-grid

> 标签: PHP

## 简介

Base component to build grids(tables) with filtering and sorting for JS Datatables jQuery plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
