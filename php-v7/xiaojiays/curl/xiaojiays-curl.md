# xiaojiays/curl

> 标签: curl, laravel

## 简介

Custom PHP Curl library for the Laravel 5 framework - developed by xiaojiays

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
