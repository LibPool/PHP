# hawksearch/esindexing-magento-2

> 标签: PHP

## 简介

Hawksearch ES Indexing module for Magento Open Source and Adobe Commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
