# linushstge/proxmox

> 标签: KVM, OpenVZ, Proxmox, Virtualization, api

## 简介

A simple PHP 7+ Proxmox API client for VE and MG.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
