# thepixeldeveloper/sitemap-bundle

> 标签: Sitemap, bundle, symfony, xml

## 简介

A Symfony Bundle that integrates thepixeldeveloper/sitemap.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
