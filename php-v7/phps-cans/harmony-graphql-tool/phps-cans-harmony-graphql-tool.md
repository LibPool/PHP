# phps-cans/harmony-graphql-tool

> 标签: graphql, serviceprovider

## 简介

This package contains tools to be able to easily implement graphql in your application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
