# sylius-labs/behat-chrome-extension

> 标签: Behat, chrome, driver, headless

## 简介

Behat extension for controlling Chrome without Selenium — fork maintained by SyliusLabs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
