# nagno/phpspec-bootstrap-magento2

> 标签: PHP

## 简介

Bootstraps Mage2 for phpspec before the tests are running so the dinamically generated classes will work

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
