# rfussien/laravel-db-dictionary

> 标签: laravel-db-dictionary, rfussien

## 简介

Laravel package to generate a DB dictionary supporting MySql

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
