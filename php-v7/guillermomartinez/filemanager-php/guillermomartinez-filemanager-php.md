# guillermomartinez/filemanager-php

> 标签: PHP

## 简介

Filemanager for php, it is the connector to the File Manager, regardless of the GUI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
