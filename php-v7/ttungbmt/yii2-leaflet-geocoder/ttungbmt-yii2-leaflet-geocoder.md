# ttungbmt/yii2-leaflet-geocoder

> 标签: 2amigos, extension, leaflet, maps, widget, yii, yii2

## 简介

Leaflet Interactive Maps Extension Library for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
