# thasmo/honeypot-blacklist

> 标签: Honeypot, api, blacklist, http, spam

## 简介

A simple PHP library for querying the Project Honeypot Http:BL API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
