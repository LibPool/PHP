# few-far/statamic-sitekit

> 标签: PHP

## 简介

We use Statamic, but we always bolt on these extra batteries + conventions so projects start at our baseline.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
