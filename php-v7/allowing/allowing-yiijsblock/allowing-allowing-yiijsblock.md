# allowing/allowing-yiijsblock

> 标签: helper, js block, yii2

## 简介

yii2 的一个 js block 插件包。因为在视图写的 js 无法插入到 body 的底部，这个包可以解决

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
