# dowilcox/knp-menu-laravel

> 标签: PHP

## 简介

Laravel package to create navigation menus, based on KnpLabs/KnpMenu.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
