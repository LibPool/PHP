# pxlbros/lightncandy-cli

> 标签: PHP

## 简介

A PHP CLI wrapper for the mustache/handlebars PHP implementation lightncandy to aid build processes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
