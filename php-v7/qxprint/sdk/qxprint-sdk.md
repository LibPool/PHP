# qxprint/sdk

> 标签: PHP

## 简介

The QxPrint PHP SDK is a library designed to facilitate the integration and use of QxPrint's printing services in PHP applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
