# eliep/avro-rpc-php

> 标签: avro, rpc, serialization

## 简介

An Avro RPC client in PHP (compatible with the Avro RPC server in Java)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
