# theaminulai/feedback-sdk

> 标签: deactivation, feedback, modal, plugin, sdk, wordpress

## 简介

Client SDK — adds a deactivation feedback modal to any WordPress plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
