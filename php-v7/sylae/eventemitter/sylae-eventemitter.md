# sylae/eventemitter

> 标签: EventEmitter, emitter, event, events

## 简介

This is an Event Emitter equivalent to Node.js' Event Emitter.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/sylae/EventEmitter
- 源码仓库：https://github.com/sylae/eventemitter.git
- Packagist 页面：https://packagist.org/packages/sylae%2Feventemitter
