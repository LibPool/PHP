# nuicart/dutchgeo

> 标签: PHP

## 简介

For all the non dutch speakers that seek a way to convert a Dutch postalcode to a lat/long map coordnates using the Google maps API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
