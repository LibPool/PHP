# controlaltjeff/p7m-fattura-decoder

> 标签: PHP

## 简介

PHP library per decodificare file PKCS#7 (.p7m) ed estrarre il contenuto XML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
