# lonnieezell/codeigniter-forensics

> 标签: codeigniter, debug, profiler, spark

## 简介

A high-powered, customizable Profiler replacement for CodeIgniter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
