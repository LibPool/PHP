# angellco/print-shop

> 标签: Craft, cms, craft-plugin, craftcms, print shop

## 简介

Everything you need to build a print shop with Craft Commerce 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
