# cnp/wp-filter-add-flex-layout-label-to-title-bar

> 标签: PHP

## 简介

Adds a label to collapsed ACF flex layout fields.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
