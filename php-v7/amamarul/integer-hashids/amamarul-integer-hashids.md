# amamarul/integer-hashids

> 标签: Integers Hashids, Laravel 5.4 hashids, Laravel Integers Hashids, Prefixed hashids, Prefixed integer hashids, laravel, laravel 5.4

## 简介

Laravel Integers Hashids Generator. Encode and decode ids to Integers. Also generate prefixed hashids

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
