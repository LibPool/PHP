> 标签: Laravel 5.4 Localization Using Translation Strings As Keys, Laravel Json Locations Manager, laravel, laravel 5.4

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
