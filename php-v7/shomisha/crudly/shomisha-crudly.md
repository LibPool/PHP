# shomisha/crudly

> 标签: cli, code-generation, crud, generation, laravel

## 简介

Crudly is a CLI tool for generating all of your mechanisms for CRUD using a simple command line wizard.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
