# robbertkl/simplepdf

> 标签: pdf

## 简介

Simple extension of ZendPdf, allowing top-to-bottom geometry using arbitrary units (e.g. inches or centimeters)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
