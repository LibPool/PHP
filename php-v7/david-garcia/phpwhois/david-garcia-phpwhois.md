# david-garcia/phpwhois

> 标签: php, phpwhois, whois

## 简介

phpWhois - library for querying whois services and parsing results. Based on phpwhois.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
