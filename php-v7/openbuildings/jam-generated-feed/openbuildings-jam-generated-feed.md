# openbuildings/jam-generated-feed

> 标签: cache, feed, generate, kohana, task, xml

## 简介

A module to generate xml files based on a jam collection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
