# presta/cms-core-bundle

> 标签: Symfony2, bundle, cms, prestaconcept, symfony-cmf

## 简介

PrestaCMS Core bundle : CMS based on Symfony2 and Symfony-CMF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
