# piedweb/cms-bundle

> 标签: PHP

## 简介

CMS built on top of Symfony (Admin, Front, Page Management, Media Management, Static Generator,...).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
