# fnash/desugar-constructor

> 标签: desugar, generator, refactor

## 简介

Desugar a php8 class constructor with equivalent class properties and constructor assignments

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
