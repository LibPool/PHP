# paymentsdk/payment-sdk

> 标签: PHP

## 简介

Secure and user-friendly checkout and direct charge API SDK for PHP applications for PaymentSDK Transactions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
