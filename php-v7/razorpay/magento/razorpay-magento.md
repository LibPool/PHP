# razorpay/magento

> 标签: india, magento, netbanking, payment gateway, payments, razorpay, wallets

## 简介

Razorpay Magento 2.0 plugin for accepting payments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
