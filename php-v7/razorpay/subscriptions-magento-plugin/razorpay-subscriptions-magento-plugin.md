# razorpay/subscriptions-magento-plugin

> 标签: india, magento, netbanking, payment gateway, payments, razorpay, recurring, wallets

## 简介

Razorpay Magento 2.X plugin for accepting recurring payments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
