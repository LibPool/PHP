# masum-packagist/countries-states-cities-php

> 标签: PHP

## 简介

A PHP package for retrieving countries, states, cities, ISO2 codes, and phone codes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
