# traw/powermail-jira

> 标签: TYPO3 CMS, issues, jira, powermail

## 简介

Base extension - Post powermail form submissions as jira issues

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
