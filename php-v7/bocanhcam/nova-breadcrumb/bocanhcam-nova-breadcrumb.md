# bocanhcam/nova-breadcrumb

> 标签: breadcrumb, breadcrumbs, laravel, nova

## 简介

A Laravel Nova package provides an easy way to define and manage breadcrumbs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
