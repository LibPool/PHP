# anfischer/dto

> 标签: anfischer, dto

## 简介

A PHP implementation of the Data Transfer Object pattern (https://martinfowler.com/eaaCatalog/dataTransferObject.html)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
