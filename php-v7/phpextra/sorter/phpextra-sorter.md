# phpextra/sorter

> 标签: array, collections, objects, psr-0, sort, sorter

## 简介

Sort arrays and objects by multiple fields with unicode characters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
