# schematicon/collection-generator

> 标签: Postman, api, generator, schematicon, structure

## 简介

Schematicon Doc Generator is generator for Postman Collection JSON files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
