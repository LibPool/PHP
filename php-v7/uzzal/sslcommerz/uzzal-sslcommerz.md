# uzzal/sslcommerz

> 标签: gateway, laravel, payment, sslcommerz

## 简介

Laravel library for SSLCommerz payment gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
