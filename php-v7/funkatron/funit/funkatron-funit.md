# funkatron/funit

> 标签: Simple, microphp, test, testing, unit

## 简介

A simple test suite for PHP 5.3+, partially inspired by QUnit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
