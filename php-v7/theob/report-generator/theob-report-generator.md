# theob/report-generator

> 标签: dompdf, excel, export, pdf, phpspreadsheet, report

## 简介

A PHP library for generating reports in Excel, PDF, and HTML formats

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
