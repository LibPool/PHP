# oratush/libforms-bootstrap

> 标签: bootstrap, form, generation, validation

## 简介

Output reference implementation to draw a libforms form using bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
