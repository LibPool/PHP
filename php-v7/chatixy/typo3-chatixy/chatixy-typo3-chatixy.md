# chatixy/typo3-chatixy

> 标签: ai-chat, chat, chatixy, customer-support, live-chat, typo3, widget

## 简介

Chatixy AI support agent for TYPO3 - no-code front-end install.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
