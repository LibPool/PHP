# wingify/wingify-fme-php-sdk

> 标签: fme, sdk, wingify

## 简介

Wingify Feature Management and Experimentation server-side SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
