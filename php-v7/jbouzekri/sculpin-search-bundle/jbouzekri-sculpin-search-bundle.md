# jbouzekri/sculpin-search-bundle

> 标签: bundle, indextank, php, sculpin, search

## 简介

Provides search in static site via indextank search engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
