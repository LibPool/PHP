# sanampatel/staticpress

> 标签: NetlifyCMS, StaticPress, cms, forestry, static

## 简介

StaticPress.io is static CMS which works with Jigsaw staticsite generator also supports forestry

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
