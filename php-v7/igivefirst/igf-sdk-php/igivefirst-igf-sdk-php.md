# igivefirst/igf-sdk-php

> 标签: api

## 简介

PHP SDK for the iGivefirst Donation API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://igivefirst.github.io/igivefirst-api-php/
- 源码仓库：https://github.com/iGivefirst/igivefirst-api-php.git
- Packagist 页面：https://packagist.org/packages/igivefirst%2Figf-sdk-php

- 当前版本：1.0.0

## 获取地址

- Composer 安装：`composer require igivefirst/igf-sdk-php`

- 许可证：Apache-2.0
