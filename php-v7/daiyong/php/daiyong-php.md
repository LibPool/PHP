# daiyong/php

> 标签: curl, database, file, function, mail, php

## 简介

php工具包，包含数据库操作、文件操作、远程抓取、一些常用的方法、邮件发送等

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
