# feedwriter/feedwriter

> 标签: RSS 1.0, atom, feed, rss, rss 2.0, rss2

## 简介

Generate feeds in either RSS 1.0, RSS 2.0 or ATOM formats

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
