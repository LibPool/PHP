# twohill/silverstripe-standard-base

> 标签: PHP

## 简介

The base SilverStripe installation recipe with development tools. Uses Webpack for frontend and Docker for hosting

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
