# routiller/routiller

> 标签: laravel-like, rest-api, routing, wordpress

## 简介

Laravel-like REST API routing for WordPress plugins. Conflict-free, multi-plugin safe.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
