# bixgomez/visiblocks

> 标签: block editor, gutenberg, usability, wordpress, wordpress plugin

## 简介

Makes the WordPress block editor's hidden editing affordances visible and discoverable.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
