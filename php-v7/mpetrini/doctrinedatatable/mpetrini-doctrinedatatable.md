# mpetrini/doctrinedatatable

> 标签: datatable, doctrine, jquery

## 简介

Bridge between jQuery Datatable ServerSide and Doctrine ORM

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
