# gdpr-extensions-com/gdpr-extensions-com-pinterest-pin

> 标签: PHP

## 简介

A TYPO3 extension for Pinterest Pin integration with GDPR compliance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
