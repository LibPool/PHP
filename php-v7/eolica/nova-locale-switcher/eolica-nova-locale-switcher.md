# eolica/nova-locale-switcher

> 标签: eolica, laravel, locale, nova, switcher

## 简介

A simple locale switcher for Nova without any concrete localization implementation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
