# webard/nova-calendar

> 标签: calendar, date, event-calendar, events, laravel, nova

## 简介

A powerful event calendar Tool for Laravel's Nova 4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
