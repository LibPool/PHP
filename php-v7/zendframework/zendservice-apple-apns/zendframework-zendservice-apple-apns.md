# zendframework/zendservice-apple-apns

> 标签: ZendFramework, apns, apple, notification, push, zf

## 简介

OOP Zend Framework wrapper for Apple Push Notification Service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
