# zendframework/zend-config-aggregator-modulemanager

> 标签: PHP

## 简介

Consume zend-mvc modules as configuration providers within zend-config-aggregator.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
