# zendframework/zend-skeleton-installer

> 标签: ZendFramework, skeleton-installer, zf

## 简介

Installer plugin for Zend Framework skeleton application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
