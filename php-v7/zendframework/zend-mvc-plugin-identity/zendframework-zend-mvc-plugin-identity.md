# zendframework/zend-mvc-plugin-identity

> 标签: ZendFramework, mvc, zf

## 简介

Plugin for retrieving the current authenticated identity within zend-mvc controllers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
