# zendframework/zend-view

> 标签: ZendFramework, view, zf

## 简介

Flexible view layer supporting and providing multiple view layers, helpers, and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
