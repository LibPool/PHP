# zendframework/zendservice-google-gcm

> 标签: ZendFramework, gcm, google, notification, push, zf

## 简介

OOP wrapper for Google Cloud Messaging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
