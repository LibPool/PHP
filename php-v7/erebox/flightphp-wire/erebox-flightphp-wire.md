# erebox/flightphp-wire

> 标签: flight, flightphp, openapi, restapi, routing

## 简介

Convenzioni di progetto su FlightPHP: bootstrap, controller base, routing via attributi, generatore OpenAPI.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
