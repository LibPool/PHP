# mmvi/twofactor_webauthn

> 标签: Authentication, fido, login, security, webauthn

## 简介

This RoundCube plugin adds WebAuthn/FIDO2 verification to the login process

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
