# ecks/ecks

> 标签: PHP

## 简介

An array decorator that adds a fluid functional interface similar to that of an Array in Ruby. Inspired by underscore.php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
