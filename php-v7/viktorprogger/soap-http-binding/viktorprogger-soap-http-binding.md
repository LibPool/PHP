# viktorprogger/soap-http-binding

> 标签: http, psr-7, soap

## 简介

A PHP library for binding SOAP messages to PSR-7 HTTP messages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
