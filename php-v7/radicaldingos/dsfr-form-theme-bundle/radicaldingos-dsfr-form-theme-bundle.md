# radicaldingos/dsfr-form-theme-bundle

> 标签: PHP

## 简介

A Symfony 4+ bundle integrating a Twig form theme for "Système de Design de l'État" (DSFR)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
