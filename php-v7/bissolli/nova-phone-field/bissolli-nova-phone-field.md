# bissolli/nova-phone-field

> 标签: input mask, laravel, nova, phone mask

## 简介

Nova Phone Number field with a dynamic mask based on the country code inserted by the user.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
