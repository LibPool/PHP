# bissolli/twitter-php-scraper

> 标签: laravel, profile, scraper, tweets, twitter

## 简介

Twitter PHP Scraper. Get account information, tweets, likes, re-tweets and comments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
