# bissolli/php-css-js-minifier

> 标签: css, javascript, laravel, merge, minifier, minify

## 简介

A PHP Class to merge and minify CSS and JavaScript files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
