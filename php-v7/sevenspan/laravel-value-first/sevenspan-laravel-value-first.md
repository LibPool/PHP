# sevenspan/laravel-value-first

> 标签: laravel, laravel-value-first, laravel-valuefirst, value-first, valuefirst

## 简介

It uses ValueFirst API to send whatsapp messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
