# jeeb/magento2-plugin

> 标签: bitcoin, jeeb, magento, merchant

## 简介

Cryptopayments integration for Magento 2 via Jeeb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
