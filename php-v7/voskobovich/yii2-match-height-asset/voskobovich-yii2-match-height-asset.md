# voskobovich/yii2-match-height-asset

> 标签: JS, asset, frontend, matchheight, yii2

## 简介

A responsive equal heights jQuery plugin for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
