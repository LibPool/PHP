# mrgswift/webdav

> 标签: Filder, WebDAV, php, stream, wrapper

## 简介

The simple PHP WebDAV client and stream wrapper forked from gletournel/WebDAV.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
