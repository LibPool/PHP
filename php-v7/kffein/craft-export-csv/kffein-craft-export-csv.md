# kffein/craft-export-csv

> 标签: Craft, cms, craft-export-csv, craft-plugin, craftcms

## 简介

A plugin to export entries to CSV files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
