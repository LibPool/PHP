# dutifruti/php-sdk

> 标签: PHP

## 简介

Zoho CRM API SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/DutiFruti/zcrm-php-sdk.git
