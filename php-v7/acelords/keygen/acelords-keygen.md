# acelords/keygen

> 标签: acelords, generator, key, key generator, keygen, lexxyungcarter, php, random

## 简介

A fluent PHP random key generator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
