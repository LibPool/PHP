# mkocansey/bladewind-content

> 标签: blade, bladewindui, content, laravel, tailwindcss

## 简介

BladewindUI content bundle — installs all content components (Card, Accordion, Avatar, Tag, Timeline, Statistic, Rating, Chart, Progress, Empty State, and more)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
