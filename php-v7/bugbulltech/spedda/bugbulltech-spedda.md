# bugbulltech/spedda

> 标签: CCe, Dacte, Danfe, nfe, nfephp, sped

## 简介

sped-da contêm as classes para criação dos documentos Sped.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
