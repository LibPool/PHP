# setechsolutions/php-whois

> 标签: availability, domain, expiration, laravel, lookup, parser, php, rdap, tld, whois

## 简介

Domain lookups over RDAP with WHOIS fallback, for plain PHP and Laravel 6 to 13: registrar, dates, name servers, availability

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
