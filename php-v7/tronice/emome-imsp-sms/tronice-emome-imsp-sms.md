# tronice/emome-imsp-sms

> 标签: cht, imsp, php, sms

## 简介

emome-imsp-sms 中華電信 emome 簡訊特碼 PHP client library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
