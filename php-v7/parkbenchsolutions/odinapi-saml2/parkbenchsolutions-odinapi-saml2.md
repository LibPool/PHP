# parkbenchsolutions/odinapi-saml2

> 标签: SAML2, laravel, onelogin, saml

## 简介

Park Bench version of aacotroneo/laravel-saml2A which is a Laravel package for Saml2 integration as a SP (service provider), based on OneLogin toolkit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
