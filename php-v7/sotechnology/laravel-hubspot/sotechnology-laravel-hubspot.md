# sotechnology/laravel-hubspot

> 标签: api, hubspot, laravel

## 简介

This will create contact in hubspot and list contacts. Forked for Laravel 5.1 support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
