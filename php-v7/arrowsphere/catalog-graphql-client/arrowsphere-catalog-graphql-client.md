# arrowsphere/catalog-graphql-client

> 标签: api, arrowsphere, graphql

## 简介

The official PHP client for ArrowSphere's Catalog GraphQL API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
