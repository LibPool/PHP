# lyn-huang/laravel-kafka

> 标签: driver, event-bus, kafka, laravel, queue, rdkafka

## 简介

Apache Kafka Queue driver & event bus for Laravel (PHP 7.4+).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
