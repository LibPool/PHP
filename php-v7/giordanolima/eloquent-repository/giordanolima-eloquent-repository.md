# giordanolima/eloquent-repository

> 标签: eloquent, laravel, repository

## 简介

Repository pattern for Eloquent ORM with a powerfull cache for database queries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
