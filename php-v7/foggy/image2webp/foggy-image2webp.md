# foggy/image2webp

> 标签: Webp, image to webp

## 简介

Grab all pictures in the url page and convert them to webp format, supporting gif, jpg, png, jpeg

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
