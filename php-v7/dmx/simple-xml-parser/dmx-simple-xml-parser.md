# dmx/simple-xml-parser

> 标签: SimpleXML, parser, xml

## 简介

A simple XML Parser which parses an XML into a normalized array based on SimpleXMLElement.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
