# php-extended/php-tempmailaddress-com-api

> 标签: api, php, tempmailaddress.com

## 简介

A php API wrapper to connect to tempmailaddress.com API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
