# php-extended/php-ulid-parser-object

> 标签: implementation, object, parser, php, ulid

## 简介

A library that implements the php-extended/php-ulid-parser-interface library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
