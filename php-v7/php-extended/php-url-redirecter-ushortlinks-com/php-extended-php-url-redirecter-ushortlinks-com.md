# php-extended/php-url-redirecter-ushortlinks-com

> 标签: php, redirecter, url, ushort-links.com

## 简介

Library to retrieve hidden links from ushort-links.com website

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
