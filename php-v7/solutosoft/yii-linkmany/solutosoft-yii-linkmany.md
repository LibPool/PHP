# solutosoft/yii-linkmany

> 标签: Behavior, active-record, fill, load, relation, yii2

## 简介

Load, validate and save automatically related Active Record models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
