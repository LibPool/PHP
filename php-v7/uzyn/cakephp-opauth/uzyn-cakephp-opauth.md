# uzyn/cakephp-opauth

> 标签: Authentication, OPAuth, auth, cakephp, oauth

## 简介

Opauth plugin for CakePHP v2.x, allowing simple plug-n-play 3rd-party authentication with CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
