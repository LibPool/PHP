# ddinchev/yii-factory-girl

> 标签: PHP

## 简介

Yii 1.1 fixture replacement framework. Inspired by factory_girl_rails and kengos' FactoryGirl for Yii.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
