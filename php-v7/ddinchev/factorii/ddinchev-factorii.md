# ddinchev/factorii

> 标签: PHP

## 简介

Yii 2.0 test db fixtures replacement library. Roughly based on Laravel's model factories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
