# gtuk/php-lepton

> 标签: compression, decompression, dropbox, jpeg, jpg, lep, lepton, php

## 简介

A php wrapper library for Dropbox Lepton compression tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
