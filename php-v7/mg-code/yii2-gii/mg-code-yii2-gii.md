# mg-code/yii2-gii

> 标签: abstract, base, extension, generator, gii, model, yii, yii2

## 简介

Abstract model generator for Yii2 Gii code generator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
