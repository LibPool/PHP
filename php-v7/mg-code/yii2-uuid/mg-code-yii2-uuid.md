# mg-code/yii2-uuid

> 标签: extension, track, unique, user, uuid, yii2

## 简介

Assigns UID to user and allows to perform varios actions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
