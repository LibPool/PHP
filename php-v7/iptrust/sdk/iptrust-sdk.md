# iptrust/sdk

> 标签: IP, asn, bot detection, geolocation, ip intelligence, iptrust, proxy, tor, vpn

## 简介

Official PHP SDK for the IP Trust API: IP geolocation, ASN, company, hosting, bot, VPN, proxy and Tor detection.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/IP-Trust/iptrust-php.git
