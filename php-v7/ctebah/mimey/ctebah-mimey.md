# ctebah/mimey

> 标签: apache, file-extension, mime, mime-type, mime.types

## 简介

PHP package for converting file extensions to MIME types and vice versa.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
