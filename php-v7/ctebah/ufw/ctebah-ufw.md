# ctebah/ufw

> 标签: Forms, api, assets, backend, extensible, framework, micro-framework, middleware, mvc, mysql, routing, validation

## 简介

A compact, highly extensible PHP framework for building robust backend services, platforms, and web portals.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
