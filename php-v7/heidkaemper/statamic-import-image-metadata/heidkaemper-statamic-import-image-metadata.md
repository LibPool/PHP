# heidkaemper/statamic-import-image-metadata

> 标签: PHP

## 简介

Read EXIF and IPTC metadata when uploading an image to Statamic

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
