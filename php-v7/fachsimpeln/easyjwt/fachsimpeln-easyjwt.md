# fachsimpeln/easyjwt

> 标签: Authentication, Simple, easy, json, jwt, token

## 简介

A easy-to-use implementation of of JWT Standard (JSON Web Tokens)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
