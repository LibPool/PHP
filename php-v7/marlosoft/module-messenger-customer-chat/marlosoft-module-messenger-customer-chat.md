# marlosoft/module-messenger-customer-chat

> 标签: PHP

## 简介

Facebook Messenger's customer chat plugin integration for Magento 2.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
