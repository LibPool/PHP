# mobileka/scope-applicator

> 标签: filtering, filters, laravel, scopes, yii

## 简介

Scope Applicator is a PHP trait that makes data filtering and sorting easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
