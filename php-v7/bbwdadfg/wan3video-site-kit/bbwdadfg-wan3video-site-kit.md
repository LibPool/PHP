# bbwdadfg/wan3video-site-kit

> 标签: ai-video, image-to-video, text-to-video, url-helpers, wan3

## 简介

URL helpers and metadata utilities for WAN 3.0 Video (wan3video.art)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
