# behappy/wordpress-bundle

> 标签: bundle, ekino, symfony, wordpress

## 简介

A Symfony bundle to link Symfony with Wordpress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
