# muvon/kiss-request-trait

> 标签: curl, http, json, kiss, request, trait

## 简介

KISS implementation of RequestTrait with usage of CURL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
