# muvon/kiss-binary-codec

> 标签: binary, codec, decoder, encoder, kiss, lightweight

## 简介

Binary codec for encoding multiple structures with predefined config

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
