# mmieluch/laravel-vfs-provider

> 标签: Flysystem, laravel, php, php-vfs, service provider, vfs

## 简介

A Laravel service provider for Flysystem's wrapper around PHP-VFS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
