# danjam/slim-mustache-view

> 标签: framework, mustache, slim, template, view

## 简介

Simple Slim 3 framework view renderer for mustache templates using Mustache.php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
