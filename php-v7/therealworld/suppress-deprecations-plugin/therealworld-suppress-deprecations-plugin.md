# therealworld/suppress-deprecations-plugin

> 标签: PHP

## 简介

Suppresses Symfony deprecation notices during Composer operations in legacy OXID 6 projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
