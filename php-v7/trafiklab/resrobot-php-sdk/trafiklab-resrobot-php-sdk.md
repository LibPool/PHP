# trafiklab/resrobot-php-sdk

> 标签: Public Transport, api, php, resrobot, sdk, trafiklab

## 简介

Use Swedish public transport data in your project with ResRobot

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
