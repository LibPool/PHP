# angus-dv/pars-news

> 标签: PHP

## 简介

This project provides a restful API for managing articles on a news site. It allows users to create, read, update, and delete articles efficiently.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
