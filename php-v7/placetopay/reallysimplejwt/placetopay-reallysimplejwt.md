# placetopay/reallysimplejwt

> 标签: Authentication, json, json web tokens, jwt, php, tokens

## 简介

A really simple library to generate user authentication JSON Web Tokens.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
