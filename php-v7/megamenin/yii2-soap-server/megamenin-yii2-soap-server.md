# megamenin/yii2-soap-server

> 标签: server, soap, yii2

## 简介

SOAP server for the Yii 2 framework based on the Yii 1 implementation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
