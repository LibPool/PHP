# ntholenaar/laravel-multisafepay-client

> 标签: client, laravel, multisafepay

## 简介

Laravel bridge for the ntholenaar/multisafepay-client package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
