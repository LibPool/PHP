# pierre-adrien/laravel-cookie-consent

> 标签: PHP

## 简介

This package provides a fully configurable cookie-consent popup for a Laravel project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
