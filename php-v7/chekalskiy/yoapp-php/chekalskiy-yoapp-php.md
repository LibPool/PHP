# chekalskiy/yoapp-php

> 标签: Yo, api, justyo.co, yoapp

## 简介

PHP wrapper for Yo app API (justyo.co)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
