# oliezekat/mylastrss

> 标签: RDF, aggregator, atom, feed, parser, rss

## 简介

Simple yet powerfull class to parse several RSS & Atom feeds

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
