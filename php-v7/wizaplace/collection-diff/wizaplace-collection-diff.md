# wizaplace/collection-diff

> 标签: PHP

## 简介

Collection Diff allows you to compare 2 data collections to find operations to do: CREATE, UPDATE or DELETE data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
