# wapplersystems/newslayouts

> 标签: PHP

## 简介

Extends EXT:news plugins and records with individual layout settings. Supports bootstrap css framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
