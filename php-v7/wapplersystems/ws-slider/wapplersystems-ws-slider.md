# wapplersystems/ws-slider

> 标签: TYPO3 CMS, flexslider, slick, swiper, tinyslider, typo3

## 简介

universal slider extension for tinyslider, swiper, flexslider, ...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
