# saintsweeto/hunterio

> 标签: hunter-php, hunter-sdk, hunter.io

## 简介

A PHP wrapper for Hunter.io v2 API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
