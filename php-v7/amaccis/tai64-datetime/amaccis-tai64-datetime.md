# amaccis/tai64-datetime

> 标签: TAI64, TAI64N, TAI64NA, date, datetime, time

## 简介

A PHP library that extends DateTime class, in order to allow to handle Tai64.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
