# jazzsequence/wp-show-tracker

> 标签: PHP

## 简介

Track shows that you (or your kids) watch. Set a weekly limit and display an alert when the limit is reached.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
