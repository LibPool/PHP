# jazzsequence/hello-ziggy

> 标签: PHP

## 简介

Instead of "Hello Dolly", this plugin will display a random lyric from David Bowie's "Ziggy Stardust".

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
