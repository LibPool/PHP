# mathieutu/laravel-open-in-editor

> 标签: Devtools, laravel-open-in-editor, vuejs

## 简介

Let the "Open in Editor" feature from browser devtools works with Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
