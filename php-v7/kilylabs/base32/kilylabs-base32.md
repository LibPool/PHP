# kilylabs/base32

> 标签: base32, decode, ejz, encode

## 简介

PHP library for Base32 encode/decode operations. (fork from deleted ejz/base32)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
