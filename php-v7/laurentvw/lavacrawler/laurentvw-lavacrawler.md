# laurentvw/lavacrawler

> 标签: Harvest, Match, content, crawler, crawling, data, extract, extractor, matcher, mining, parse, parser, scrape, scraper, scraping, spider, text

## 简介

A web scraper for PHP to easily extract data from web pages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
