# sevenymedia/bulksmscenter-http-api

> 标签: PHP

## 简介

This repository contains the open source PHP client for the BulkSMSCenter HTTP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
