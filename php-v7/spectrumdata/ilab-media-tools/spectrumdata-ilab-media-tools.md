# spectrumdata/ilab-media-tools

> 标签: cropping, imgix, s3, wordpress

## 简介

Tools for cropping, uploading to S3, serving through Imgix

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
