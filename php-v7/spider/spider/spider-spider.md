# spider/spider

> 标签: database, graphs, gremlin, neo4j, ogm, orientdb, orm, tinkerpop

## 简介

Simple and flexible graph database abstraction.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
