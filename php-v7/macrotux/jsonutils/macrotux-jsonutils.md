# macrotux/jsonutils

> 标签: PHP7, json, json decode, json encode, php

## 简介

JsonUtils, Utils for encode - decode JSON in PHP7, with control errors and Exception

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
