# agoradesign/agoradesign

> 标签: PHP

## 简介

Drupal default Installation Profile for agoradesign KG. Install with commonly used features pre-configured and some very important third party modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
