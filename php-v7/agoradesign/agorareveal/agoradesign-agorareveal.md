# agoradesign/agorareveal

> 标签: PHP

## 简介

Agoradesign Drupal 8 Foundation Reveal integration module. Basic integration of Foundation Reveal, offering an Ajax command to control Reveal modals. However it doesn't include the library itself.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
