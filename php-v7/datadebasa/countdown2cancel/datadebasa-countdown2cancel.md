# datadebasa/countdown2cancel

> 标签: PHP

## 简介

Library PHP untuk menghitung mundur dan auto-cancel berdasarkan batas waktu.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
