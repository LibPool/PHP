# justcarmen/jc-fancy-research-links

> 标签: genealogy, webtrees, webtrees-module

## 简介

A sidebar module for webtrees that provides shortcuts to popular research websites, using the individual data as a search reference.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
