# moehrenzahn/wp-toolkit

> 标签: OOP, wordpress

## 简介

An object-oriented framework around common WordPress functionality to jumpstart theme and plugin development.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
