# vkr/custom-logger-bundle

> 标签: Symfony2, logs, monolog, symfony3

## 简介

A bundle for logging to non-default files in Symfony2/3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
