# vkr/symfony-web-uploader

> 标签: Symfony2, api, drupal8, laravel, php, symfony3, upload

## 简介

PHP library that simplifies file uploading process to external APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
