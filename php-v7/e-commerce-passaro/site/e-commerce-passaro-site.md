# e-commerce-passaro/site

> 标签: e-commerce-passaro, ecommerce, site, zf3

## 简介

Essa é uma biblioteca para gerenciamento de um site e-commerce

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
