# e-commerce-passaro/paypal

> 标签: e-commerce-passaro, ecommerce, paypal, zf3

## 简介

Uma biblioteca para integração com o paypal

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
