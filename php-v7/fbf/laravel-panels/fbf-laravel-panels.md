# fbf/laravel-panels

> 标签: PHP

## 简介

A Laravel 4 package for adding multiple types of widgets like carousels, accordions and tabsets to a website

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
