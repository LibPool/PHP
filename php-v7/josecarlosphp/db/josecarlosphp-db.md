# josecarlosphp/db

> 标签: database, db, mysql, mysqli, pdo, php

## 简介

PHP classes to interact with databases. Works with MySQL, MySQLi, and PDO.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
