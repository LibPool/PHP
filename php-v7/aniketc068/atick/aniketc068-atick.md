# aniketc068/atick

> 标签: LTV, adobe, cades, cms, digital-signature, esign, green-tick, pades, pdf, pkcs11, rfc-3161, sign-pdf, timestamp, usb-token

## 简介

Standalone PDF digital-signature library for PHP — PAdES & CMS signing with a PFX/PEM file, USB tokens (PKCS#11), the Windows certificate store and Indian eSign (CCA); RFC-3161 timestamps, long-term validation (LTV) and a green-tick verified-signature appearance that Adobe shows as valid. Zero dependencies.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
