> 标签: PSR-4, autocomplete, bazzline, cli, component, console, free as in freedom, lgpl, php, psr, readline, unix

## 简介

free as in freedom php component to easy up usage of php readline implementation in php 5.3 and above

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
