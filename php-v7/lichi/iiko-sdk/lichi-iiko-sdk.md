# lichi/iiko-sdk

> 标签: iiko, iiko api, iiko biz, iiko card, iiko cloud, iiko php sdk, iiko transport, lichi

## 简介

PHP SDK for IIKO (Card/Biz/Cloud/Transport)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
