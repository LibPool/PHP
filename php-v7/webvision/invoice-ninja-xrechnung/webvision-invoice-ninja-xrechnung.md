# webvision/invoice-ninja-xrechnung

> 标签: PHP

## 简介

Add-on module for Invoice Ninja 5.x to create electronic invoices for Germany's xRechnung format

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
