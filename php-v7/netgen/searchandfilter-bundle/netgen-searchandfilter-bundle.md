# netgen/searchandfilter-bundle

> 标签: PHP

## 简介

Netgen Search And Filter Bundle is an eZ Publish 5 solution for configuring pages with custom searching and filtering

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
