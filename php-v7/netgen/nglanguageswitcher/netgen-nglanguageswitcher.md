# netgen/nglanguageswitcher

> 标签: PHP

## 简介

Netgen Language Switcher is an extension that provides another way of generating links for language switcher in eZ Publish

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
