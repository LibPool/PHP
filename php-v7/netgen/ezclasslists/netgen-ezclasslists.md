# netgen/ezclasslists

> 标签: PHP

## 简介

Adds a tab in the administration interface that lists objects by content class and lets you quickly edit or delete them.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
