# netgen/ngresponsiveimages

> 标签: PHP

## 简介

eZ Publish 4 extension that eases creation and usage of responsive images by leveraging eZ Publish image aliases

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
