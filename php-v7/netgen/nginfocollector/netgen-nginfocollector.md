# netgen/nginfocollector

> 标签: PHP

## 简介

nginfocollector is an eZ Publish legacy extension that integrates GDPR features into eZ Publish legacy collected information

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
