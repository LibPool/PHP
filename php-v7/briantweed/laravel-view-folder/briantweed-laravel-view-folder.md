# briantweed/laravel-view-folder

> 标签: LaravelViewFolder, laravel

## 简介

Create view folder structure with sub folders for partials, components and modals as ell as basic CRUD files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
