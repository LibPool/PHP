# lorenzo/cakephp-fixturize

> 标签: Fixture, cakephp, test, testsuite

## 简介

Provides custom Fixture classes to help managing test fixtures in pure SQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
