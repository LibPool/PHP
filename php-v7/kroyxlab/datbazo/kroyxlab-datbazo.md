# kroyxlab/datbazo

> 标签: Esperanto, base de datos, bazo, database, datumo, pdo, php, sql

## 简介

DatBazo(Datuma Bazo, Base de datos en Esperanto) es un SQL-query constructor el cual trabaja con PDO.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
