# elefant/app-httpshell

> 标签: api, app, cms, debugging, elefant, http, rest, shell, testing

## 简介

Http Shell is an HTTP testing and debugging tool for the Elefant CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
