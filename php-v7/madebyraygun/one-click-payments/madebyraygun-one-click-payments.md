# madebyraygun/one-click-payments

> 标签: Craft, cms, craft-plugin, craftcms, one-click payments

## 简介

Payments plugin for Craft CMS using Formie and Stripe Checkout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
