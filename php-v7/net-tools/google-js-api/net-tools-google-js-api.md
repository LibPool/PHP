# net-tools/google-js-api

> 标签: PHP

## 简介

Composer library for Google API browser helpers (javascript) ; ECMASCRIPT 5+ required

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
