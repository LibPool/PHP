# sulaco-tech/psr7-sessions

> 标签: psr15, psr7, session

## 简介

Implementation of a PSR-7 and PSR-15 compatible middleware that enables sessions in PSR-7 based applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
