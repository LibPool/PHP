# imaginaria/datetimeparser

> 标签: PHP

## 简介

Imaginaria::DateTimeParser, DateTimeParser converts a date/time string to a UNIX timestamp according to the specified pattern

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
