# kot13/laracent

> 标签: broadcaster, centrifugo, laravel

## 简介

Centrifugo broadcaster for laravel >= 5.7 and Centrifugo >= 2.1.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
