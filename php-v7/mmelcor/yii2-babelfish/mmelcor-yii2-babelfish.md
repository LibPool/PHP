# mmelcor/yii2-babelfish

> 标签: database, gui, manager, multi-site, po, translations, yii2

## 简介

A translation manager for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
