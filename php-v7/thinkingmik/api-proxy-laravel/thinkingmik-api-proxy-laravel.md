# thinkingmik/api-proxy-laravel

> 标签: ajax, api, javascript, laravel, oauth, proxy

## 简介

A Laravel helper proxy package for javascript API calls

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
