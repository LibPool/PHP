# enygma/duoauth

> 标签: api, duoauth, rest, twofactor

## 简介

PHP library to interface with the DuoAuth Two-Factor REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
