# codementality/flysystem-stream-wrapper

> 标签: PHP

## 简介

Adapts Flysystem filesystems to PHP stream wrappers. (fork of twistor/flysystem-stream-wrapper_

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
