# rl404/simple-php-cache

> 标签: Simple, cache, filesystem, json

## 简介

A light, simple but powerful PHP5 Cache Class which uses the filesystem for caching.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
