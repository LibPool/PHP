# rl404/mal-scraper

> 标签: PHP

## 简介

Unofficial MyAnimeList API that scrap and parse everything from MyAnimeList web into array and json

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
