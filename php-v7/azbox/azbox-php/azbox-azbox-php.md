# azbox/azbox-php

> 标签: Azbox, PHP translation, api, multilingual, translation

## 简介

The library to integrate Azbox translation to PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/azbox-io/azbox-php.git
