# amelaraby/magento-2-mageplaza-social-login-api

> 标签: Amazon Login, Facebook login, FourSquare Login, Google login, Instagram Login, LinkedIn Login, Microsoft Live Login, Social Login, Twitter login, Yahoo Login, facebook, google, login, magento 2, magento 2 social login, magento 2 social login api, social API, social proof, twitter

## 简介

An extension for Magento 2 Mageplaza Social Login extension which expose an APIs to login via social media access tokens

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
