# smalot/pdfparser

> 标签: PDF, extract, parse, parser, pdf, text, 解析

## 简介

Pdf parser library. Can read and extract information from pdf file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
