# xeops/xero-php

> 标签: PHP

## 简介

A client implementation of the Xero API, with a cleaner OAuth interface and ORM-like abstraction.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
