# angel-source-labs/laravel-expression-grammar

> 标签: PHP

## 简介

Database Grammar Helper for Laravel. Returns appropriate SQL based on driver for database connection.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
