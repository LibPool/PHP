# hidro/module-newrelic-cronjob

> 标签: PHP

## 简介

Adding Magento 2 cronjob's jobcode as NewRelic transaction name

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
