# adeelq/magento2-log-viewer-downloader

> 标签: PHP

## 简介

A module that shows list of all log files. User can view the logs file in the viewer as well as download it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
