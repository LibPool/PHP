# adeelq/magento2-core-config-data-viewer

> 标签: PHP

## 简介

A module which adds grid in admin backOffice for Magento core_config_data table.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
