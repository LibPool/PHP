# mcaskill/sage-theme-wrapper

> 标签: roots, sage, wordpress, wp

## 简介

Standalone version of the Sage theme layout wrapper for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
