# tungltdev/laravel-php-jwt

> 标签: Authentication, jwt, laravel, php, token

## 简介

A simple library to encode and decode JSON Web Tokens (JWT) in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
