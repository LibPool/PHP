# wr/onepage-bundle

> 标签: article, contao, navigation, one, onepage, page

## 简介

This Onepage Bundle add a one page navigation module to Contao Open Source CMS. No jQuery required!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
