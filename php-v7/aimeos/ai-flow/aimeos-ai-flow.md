# aimeos/ai-flow

> 标签: adapter, aimeos, e-commerce, flow, neoscms, shop, typo3

## 简介

Flow/NeosCMS adapter for Aimeos web shops and e-commerce solutions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
