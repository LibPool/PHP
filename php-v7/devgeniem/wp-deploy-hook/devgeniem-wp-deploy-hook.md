# devgeniem/wp-deploy-hook

> 标签: PHP

## 简介

A WordPress plugin that registers a hook that can be run via WP CLI during deploy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
