# devgeniem/wp-exhale

> 标签: exporter, framework, wordpress, wp

## 简介

Creates Developer friendly xml api endpoint for 3rd party integrations on your data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
