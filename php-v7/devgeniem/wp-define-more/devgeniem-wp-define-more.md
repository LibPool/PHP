# devgeniem/wp-define-more

> 标签: define, filesize, max, options, uploads, wordpress, wp

## 简介

Adds useful definable constants which are missing from the WP Core.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
