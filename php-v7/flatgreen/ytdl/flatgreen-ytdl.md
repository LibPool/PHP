# flatgreen/ytdl

> 标签: youtube-dl, yt-dlp

## 简介

A PHP wrapper for youtube-dl or yt-dlp tool. Close to the command line, with a caching system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
