# cymdeveloppement/roundcube-gdrive-attachments

> 标签: attachments, email, google-drive, large-files, roundcube, roundcube-plugin, webmail

## 简介

Uploads attachments larger than the message size limit to a Google shared drive with a service account, and inserts a download link in the message

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
