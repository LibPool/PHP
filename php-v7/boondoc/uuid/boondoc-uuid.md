# boondoc/uuid

> 标签: PHP

## 简介

A PHP5.6+ class for handling and generating RFC 4122 versions 1, 3, 4 and 5 Universally Unique Identifiers (UUIDs).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
