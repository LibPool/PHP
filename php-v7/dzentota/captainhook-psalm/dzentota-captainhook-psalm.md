# dzentota/captainhook-psalm

> 标签: captainhook, git, php, pre-commit, psalm

## 简介

Captain Hook Plugin to check for newly introduced Psalm errors

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
