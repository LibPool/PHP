# yogeshsuhagiya/clone-product

> 标签: PHP

## 简介

Magento module (Command line utility/admin module) to copy all the existing simple products (New) in set of 2 (Used and Refurbished)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
