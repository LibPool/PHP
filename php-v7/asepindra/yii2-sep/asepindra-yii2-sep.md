# asepindra/yii2-sep

> 标签: extension, form, widget, yii2

## 简介

Collection of useful widgets for Yii Framework 2.0 extending functionalities for Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
