# letflow/laravel-feature-toggle

> 标签: feature-flags, feature-toggles, laravel, toggles

## 简介

Simple feature toggles for Laravel PHP and Javascript

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
