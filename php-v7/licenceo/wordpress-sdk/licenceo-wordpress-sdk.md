# licenceo/wordpress-sdk

> 标签: PHP

## 简介

SDK d'intégration des licences Licenceo pour plugins et thèmes WordPress (activation, revalidation, mises à jour, remontée de plantage).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
