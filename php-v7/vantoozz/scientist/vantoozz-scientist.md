# vantoozz/scientist

> 标签: dayle, experiment, framework, scientist, test, testing

## 简介

A PHP 5.3 experimentation library inspired by Github's own Scientist.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
