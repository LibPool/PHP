# ikkez/f3-validation-engine

> 标签: F3, GUMP, cortex, fatfree, model, validation

## 简介

Validation engine for Cortex and the PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
