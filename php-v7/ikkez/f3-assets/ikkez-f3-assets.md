# ikkez/f3-assets

> 标签: F3, JS, css, fatfree, minify

## 简介

CSS/JS Assets Plugin for PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
