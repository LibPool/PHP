# ikkez/f3-schema-builder

> 标签: F3, fatfree, sql

## 简介

SQL Schema Builder Plugin for PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
