# ikkez/f3-cortex

> 标签: F3, fatfree, mongo, orm, sql

## 简介

A multi-engine ORM / ODM for the PHP Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
