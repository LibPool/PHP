# owowagency/laravel-has-users-with-roles

> 标签: Has users, laravel, roles, traits

## 简介

A trait for Laravel models which have many users with roles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
