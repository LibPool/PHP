# zero-config/cli

> 标签: Small footprint, cli, gzip, http, pipe, pipeline, stderr, stdin, stdout, transformer, zero configuration

## 简介

CLI tooling with zero configuration required.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
