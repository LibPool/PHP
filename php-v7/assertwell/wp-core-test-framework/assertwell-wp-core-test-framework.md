# assertwell/wp-core-test-framework

> 标签: testing, wordpress

## 简介

Streamline testing WordPress plugins and themes using the WordPress core test framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
