# happyr/stomp-bundle

> 标签: fusesource stomp-php, message, queue, stomp

## 简介

A Symfony2 Bundle to wrap the fusesource/stomp-php library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
