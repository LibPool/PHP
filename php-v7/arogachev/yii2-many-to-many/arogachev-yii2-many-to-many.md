# arogachev/yii2-many-to-many

> 标签: Behavior, many-to-many, relation, validator, yii2

## 简介

Many-to-many ActiveRecord relation for Yii 2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
