# sixbysix/magento2-trojanorder

> 标签: PHP

## 简介

Prevents bots creating fake orders while attempting to exploit CVE-2022-24086

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
