# kudos/regmatch

> 标签: kudos, regex, regular expression

## 简介

A class that takes as input a pseudo regular expression and outputs a random string that would match it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
