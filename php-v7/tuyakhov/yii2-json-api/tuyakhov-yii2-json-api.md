# tuyakhov/yii2-json-api

> 标签: JSON-API, api, json, json api, rest, yii2

## 简介

Implementation of JSON API specification for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
