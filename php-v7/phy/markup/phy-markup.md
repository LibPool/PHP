# phy/markup

> 标签: builder, html, psr-3

## 简介

Dynamic HTML builder, nothing super worth while. It does supports default HTML3, HTML4, HTML5, and XHTML tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
