# mhndev/pongo

> 标签: mongo, mongodb, php-mongo

## 简介

working with mongodb in php, no ODM, no Data Mapper just use mongo json queries itself

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
