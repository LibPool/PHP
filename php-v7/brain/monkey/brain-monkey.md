# brain/monkey

> 标签: Monkey Patching, interception, mock, mock functions, mockery, patchwork, redefinition, runkit, test, testing

## 简介

Mocking utility for PHP functions and WordPress plugin API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
