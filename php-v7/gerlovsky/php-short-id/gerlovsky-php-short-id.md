# gerlovsky/php-short-id

> 标签: PHP

## 简介

Short ID generator. The library help you generate short id like youtube, vimeo, bit.ly, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
