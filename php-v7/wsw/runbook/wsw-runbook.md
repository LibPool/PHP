# wsw/runbook

> 标签: PHP

## 简介

Um interpretador de runbooks escrito em PHP para automação de respostas operacionais em linha de comando.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
