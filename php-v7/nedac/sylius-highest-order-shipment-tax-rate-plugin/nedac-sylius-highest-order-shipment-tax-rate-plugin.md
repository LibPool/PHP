# nedac/sylius-highest-order-shipment-tax-rate-plugin

> 标签: Rate, highest, nedac, order, shipment, sylius, sylius-plugin, tax

## 简介

Sylius plugin that applies the highest tax rate of all order items in an order to the shipping costs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
