# homelan/acorn-disk

> 标签: ADL, DFS, SSD, acorn, adfs

## 简介

Provides class for reading disk images for 8-bit Acorn machines (dfs/adfs)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
