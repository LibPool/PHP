# guilhermecfviana/mercadobitcoin

> 标签: bitcoin, mercadobitcoin, unofficial

## 简介

Um cliente PHP não oficial para a trade-api do mercadobitcoin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
