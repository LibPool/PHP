# baltictransline/monolog-discord-handler

> 标签: PSR3, discord, integration, log, logging, monolog, webhook

## 简介

A simple monolog handler for support Discord webhooks

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
