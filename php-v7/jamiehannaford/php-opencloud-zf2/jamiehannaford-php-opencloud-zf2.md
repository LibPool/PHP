# jamiehannaford/php-opencloud-zf2

> 标签: PHP

## 简介

ZF2 module that allows easy interaction with Rackspace/OpenStack APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
