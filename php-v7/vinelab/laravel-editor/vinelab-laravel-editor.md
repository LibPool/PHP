# vinelab/laravel-editor

> 标签: PHP

## 简介

Markdown Text Editor (WYSIWYG) with social network embeds support and a nifty json output.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
