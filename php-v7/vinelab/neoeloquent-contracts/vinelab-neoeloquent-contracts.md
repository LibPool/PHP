# vinelab/neoeloquent-contracts

> 标签: PHP

## 简介

Fork of the Illuminate Contracts package to be used in Vinelab/NeoEloquent.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
