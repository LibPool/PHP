# jaxon-php/jaxon-toastr

> 标签: Jaxon, ajax, javascript, notification, php, xajax

## 简介

Jaxon notification plugin with the Toastr library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
