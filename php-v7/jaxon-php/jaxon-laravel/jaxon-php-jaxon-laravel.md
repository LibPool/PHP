# jaxon-php/jaxon-laravel

> 标签: Jaxon, ajax, laravel, php

## 简介

Jaxon library integration for the Laravel framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
