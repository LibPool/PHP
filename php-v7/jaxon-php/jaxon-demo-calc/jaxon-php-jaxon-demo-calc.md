# jaxon-php/jaxon-demo-calc

> 标签: Jaxon, ajax, calculator, demo, php

## 简介

A simple calculator implemented as a Jaxon package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
