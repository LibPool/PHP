# dreamfactory/df-firebird

> 标签: database, dreamfactory, firebird, pdo_firebird, pdo_interbase, sql

## 简介

Firebird SQL Database support for DreamFactory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
