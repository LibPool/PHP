# dreamfactory/df-couchdb

> 标签: api, couchdb, database, db, dreamfactory, nosql, rest

## 简介

The DreamFactory(tm) CouchDB Service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
