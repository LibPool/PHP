# dreamfactory/lib-php-common-platform

> 标签: dsp, dsp-core, sdk

## 简介

DreamFactory Services Platform(tm) Components Library/SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
