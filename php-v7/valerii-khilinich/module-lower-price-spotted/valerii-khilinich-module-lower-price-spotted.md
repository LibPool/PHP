# valerii-khilinich/module-lower-price-spotted

> 标签: PHP

## 简介

Custom magento module that adds the ability for the customer to request a lower product price.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
