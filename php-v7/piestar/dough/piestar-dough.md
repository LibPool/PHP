# piestar/dough

> 标签: dough, mail merge, placeholders, template, templating, tokens

## 简介

A tiny, deliberately limited templating language for user-authored tokens in mail merges.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
