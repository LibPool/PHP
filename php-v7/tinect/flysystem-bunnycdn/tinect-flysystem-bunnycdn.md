# tinect/flysystem-bunnycdn

> 标签: PHP

## 简介

Flysystem adapter for BunnyCDN. This is a temporarily productive fork of platformcommunity/flysystem-bunnycdn

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
