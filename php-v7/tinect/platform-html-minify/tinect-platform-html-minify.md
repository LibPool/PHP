# tinect/platform-html-minify

> 标签: backend, html, minify, shopware

## 简介

This plugin delivers minified HTML and minified inline JavaScript to visitors.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
