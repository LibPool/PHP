# evanshunt/wp-replace-social-icons

> 标签: icons, plugin, social, wordpress

## 简介

A WordPress plugin to allow theme overrides of social media icons

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
