# ideallystudio/magento2-merchant-toolkit

> 标签: PHP

## 简介

Magento 2 admin enhancements to preview products, categories and CMS pages per store view.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
