# wepe/wepetables

> 标签: codeigniter, codeigniter4, datatables

## 简介

Wepetables will help you to use jQuery Datatables in server side with CodeIgniter4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
