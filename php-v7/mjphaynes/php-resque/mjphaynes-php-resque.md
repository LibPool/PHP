# mjphaynes/php-resque

> 标签: background, job, php, php-resque, queue, redis, resque, worker

## 简介

Redis backed library for creating background jobs and processing them later.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
