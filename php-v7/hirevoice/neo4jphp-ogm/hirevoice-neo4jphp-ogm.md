# hirevoice/neo4jphp-ogm

> 标签: database, doctrine, entity-mapper, graph, neo4j

## 简介

Doctrine2-style entity mapper for Neo4j graph database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
