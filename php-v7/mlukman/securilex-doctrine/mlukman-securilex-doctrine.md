# mlukman/securilex-doctrine

> 标签: doctrine, securilex, security, silex

## 简介

Securilex is a simplified security provider for Silex. Securilex-Doctrine adds support to use Doctrine as the source of user authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
