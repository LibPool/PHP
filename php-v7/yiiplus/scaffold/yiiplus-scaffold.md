# yiiplus/scaffold

> 标签: framework, project template, scaffold, yii2

## 简介

scaffold是一个基于Yii2高级项目模版工程化实现的应用程序

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
