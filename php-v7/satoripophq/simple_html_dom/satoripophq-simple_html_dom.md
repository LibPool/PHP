# satoripophq/simple_html_dom

> 标签: dom, php dom

## 简介

A HTML DOM parser written in PHP5+ let you manipulate HTML in a very easy way!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
