# concrete5-community/dark_mode_editor

> 标签: CKEditor, addon, background, cms, concrete, concrete5, concreteCMS, dark, dark mode, darkmode, editor, light, lightmode, package, toggle

## 简介

A ConcreteCMS package that adds a Dark Mode Toggle to CKEditor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
