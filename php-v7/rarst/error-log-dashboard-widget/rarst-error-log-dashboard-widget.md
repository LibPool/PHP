# rarst/error-log-dashboard-widget

> 标签: log, wordpress

## 简介

Robust zero-configuration and low-memory WordPress plugin to keep an eye on error log

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
