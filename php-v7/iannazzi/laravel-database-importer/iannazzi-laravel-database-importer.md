# iannazzi/laravel-database-importer

> 标签: generators, laravel

## 简介

From an existing database for laravel 5 Create Migrations Models, Seeds, Factories, and Tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
