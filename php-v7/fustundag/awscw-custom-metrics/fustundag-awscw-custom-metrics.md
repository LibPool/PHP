# fustundag/awscw-custom-metrics

> 标签: alert, amazon, aws, cloudwatch, custom, data, metric, monitor

## 简介

Send custom metric data to AWS CloudWatch for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
