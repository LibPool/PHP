# zorac/php-resque

> 标签: background, job, php, queue, redis, resque

## 简介

Redis backend library for creating background jobs and processing them later. PHP port based on resque for Ruby.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
