# nelexa/guzzle-doh-middleware

> 标签: Guzzle, dns, dns-over-https, doh, middleware

## 简介

A Dns over Https (DoH) middleware for Guzzle >= 6.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
