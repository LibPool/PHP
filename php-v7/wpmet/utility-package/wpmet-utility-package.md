# wpmet/utility-package

> 标签: PHP

## 简介

Utility packages for Wpmet plugin, It will be used to serve Stories, Notice , Banner and Ratings

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
