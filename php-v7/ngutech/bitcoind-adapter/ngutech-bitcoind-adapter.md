# ngutech/bitcoind-adapter

> 标签: adapter, bitcoin, bitcoind

## 简介

Bitcoind service adapter for Daikon-CQRS projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
