# prezto/permission

> 标签: acl, permissions, psr-7

## 简介

PSR-7 permission middleware. Sets the status code to 401 if needed according to user defined rules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
