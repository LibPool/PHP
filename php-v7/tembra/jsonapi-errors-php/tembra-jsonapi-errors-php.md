# tembra/jsonapi-errors-php

> 标签: JSON-API, api, error, errors, json, json api

## 简介

A PHP implementation of JSON API Errors compliant format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
