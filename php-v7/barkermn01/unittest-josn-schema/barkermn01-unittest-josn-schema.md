# barkermn01/unittest-josn-schema

> 标签: PHP

## 简介

Allows Unit testing of JSON-Schema's against a supplied JSON-Schema schema or an in-schema defined schema

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
