# coccoinomane/wordpress-analytics

> 标签: PHP

## 简介

Let Google Analytics communicate with WordPress and track user activity beyond pageviews

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
