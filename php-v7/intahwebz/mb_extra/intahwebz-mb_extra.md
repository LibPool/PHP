# intahwebz/mb_extra

> 标签: mb_string, php, utf-8, utf8

## 简介

A collection of PHP multi-byte string functions that are not present in the mb_string extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
