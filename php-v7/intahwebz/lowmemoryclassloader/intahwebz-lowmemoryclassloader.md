# intahwebz/lowmemoryclassloader

> 标签: autoloader, classloader, optimized

## 简介

A PHP class loader that uses a minimal amount of memory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
