# gibilogic/tinymce-bundle

> 标签: editor, tinymce, wysiwyg

## 简介

This Bundle integrates TinyMCE WYSIWYG editor into a Symfony2 project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
