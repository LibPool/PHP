# rstgroup/zend-psr7bridge

> 标签: ZendFramework, http, psr, psr-7, zend, zf

## 简介

PSR-7 &lt;-&gt; zend-http message conversions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
