# dmk/mkdam2fal

> 标签: DAM, TYPO3 CMS, fal, migration

## 简介

This extension migrates your Dam-data into FAL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
