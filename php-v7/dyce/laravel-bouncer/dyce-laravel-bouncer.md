# dyce/laravel-bouncer

> 标签: auth, bouncer, dyce, laravel

## 简介

Laravel Bouncer provides a featherweight authentication system for gaming APIs built with Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
