# dyce/laravel-prerender

> 标签: dyce, laravel, prerender

## 简介

Laravel middleware for prerendering javascript-rendered pages on the fly for SEO

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
