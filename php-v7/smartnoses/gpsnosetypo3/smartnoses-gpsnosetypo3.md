# smartnoses/gpsnosetypo3

> 标签: PHP

## 简介

Extension to integrate GpsNose into TYPO3 - GpsNose connects anonymous people to the real world using the web and mobiles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
