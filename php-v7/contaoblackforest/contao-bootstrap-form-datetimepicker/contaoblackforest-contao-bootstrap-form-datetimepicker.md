# contaoblackforest/contao-bootstrap-form-datetimepicker

> 标签: bootstrap, contao, datepicker, form

## 简介

Bootstrap datetimepicker for forms in Contao CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
