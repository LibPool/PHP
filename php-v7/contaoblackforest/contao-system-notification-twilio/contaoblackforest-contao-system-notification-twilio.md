# contaoblackforest/contao-system-notification-twilio

> 标签: backend, contao, frontend, mms, module, notification, sms, system, twilio

## 简介

Contao system notification send sms/mms with twilio for Contao OpenSource CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
