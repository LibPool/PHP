# pkerrigan/paypal-ewp

> 标签: EWP, encrypted buttons, payments, paypal

## 简介

A PHP library for generating encrypted PayPal buttons (EWP)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
