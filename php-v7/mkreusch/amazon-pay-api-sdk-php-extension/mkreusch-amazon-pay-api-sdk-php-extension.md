# mkreusch/amazon-pay-api-sdk-php-extension

> 标签: PHP

## 简介

Add a convenience layer to the Amazon Pay PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
