# scil/mthaml-more

> 标签: HAML, mthaml, snippet

## 简介

Add more features like snippet to MtHaml, one way to "Don't Reinvent the Wheel"

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
