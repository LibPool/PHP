# tourze/tencent-cloud-sms-bundle

> 标签: PHP

## 简介

腾讯云短信服务集成模块，支持消息发送、状态同步和统计分析

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
