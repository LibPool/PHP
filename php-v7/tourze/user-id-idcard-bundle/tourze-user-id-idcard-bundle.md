# tourze/user-id-idcard-bundle

> 标签: PHP

## 简介

用户身份证验证模块，提供身份证号码的存储、验证和管理功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
