# tourze/wechat-work-media-bundle

> 标签: PHP

## 简介

企业微信媒体资源管理服务包，支持上传和管理图片、语音、视频等媒体文件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
