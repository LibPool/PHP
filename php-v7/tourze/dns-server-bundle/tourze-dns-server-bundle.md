# tourze/dns-server-bundle

> 标签: PHP

## 简介

DNS服务端管理系统，支持权威DNS解析和上游DNS服务器配置

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
