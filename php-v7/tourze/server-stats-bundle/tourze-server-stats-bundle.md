# tourze/server-stats-bundle

> 标签: PHP

## 简介

功能强大的 Symfony Bundle，用于收集、存储和可视化全面的服务器统计信息和监控数据，包括 CPU、内存、网络流量、磁盘 I/O 等系统指标

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
