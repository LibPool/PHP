# tourze/proxy-protocol-core

> 标签: PHP

## 简介

A PHP core library for parsing and generating Proxy Protocol. Supports both V1 (text format) and V2 (binary format) versions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
