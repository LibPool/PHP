# cviniciussdias/dependency-resolver

> 标签: PHP

## 简介

Dependency Resolver. A simple component to resolve classes dependencies and instantiate them automagically.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
