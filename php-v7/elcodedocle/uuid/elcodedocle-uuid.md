# elcodedocle/uuid

> 标签: UUIDv3, UUIDv4, UUIDv5, Universal Unique Identifier, uuid

## 简介

UUID v3, v4, v5 generator class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
