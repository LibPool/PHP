# softwarezhu/pate

> 标签: pate, template engine, zope

## 简介

Pate is a PHP Attribute Template Engine inspired by PHPTAL but run much faster. It use native dom to make it fast.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
