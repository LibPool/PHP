# softwarezhu/phptal

> 标签: phptal, template engine, zope

## 简介

PHPTAL is a templating engine for PHP5 that implements Zope Page Templates syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
