# dv-team/json

> 标签: PHP

## 简介

A wrapper-class for json_encode and json_decode to automatically set some constants like JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
