# zozlak/guzzle-proxy-client

> 标签: PHP

## 简介

A wrapper around GuzzleHttp Client honoring proxy settings in http_proxy, https_proxy and no_proxy environment variables

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
