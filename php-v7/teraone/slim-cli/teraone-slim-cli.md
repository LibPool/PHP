# teraone/slim-cli

> 标签: cli, framework, middleware, slim

## 简介

Making a mock GET request through the CLI and enabling the same application entry point on CLI scripts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
