# utilvo/utilvo-shield-filters

> 标签: adblock, blocklist, filterlist, parser, ublock-origin

## 简介

Zero-dependency parser and domain matcher for Adblock Plus 2.0 and uBlock Origin static network filter rules.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
