# utilvo/utilvo-pdf-merger

> 标签: merge-pdf, pdf, pdf-merger, pdf-parser, xref

## 简介

Lightweight PHP library for inspecting PDF binary headers, counting pages, validating xref tables, and merging multiple PDF byte streams.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
