# marcusball/case-helper

> 标签: PHP

## 简介

Easily convert between camelCase, PascalCase, kebab-case, snake_case, SCREAMING_SNAKE_CASE, Train-Case, and string case! Note: This is a fork of nabil1337/case-helper, which appears abandoned.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
