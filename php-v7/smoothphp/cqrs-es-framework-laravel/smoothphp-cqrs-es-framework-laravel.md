# smoothphp/cqrs-es-framework-laravel

> 标签: cqrs, event sourcing, laravel

## 简介

Laravel adapter for the SmoothPhp CQRS-ES-Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
