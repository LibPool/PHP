# novay/notifier-module

> 标签: Laravel-Exceptions, email, email-notification, email-notifications, exception, exception-email, exception-emails, exception-handler, exception-messages, laravel, notification

## 简介

Laravel exception notifier will send an email of the error along with the stack trace to the chosen recipients.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
