# locaine/lcn-image-uploader-bundle

> 标签: Image upload, Symfony2, ajax, file upload

## 简介

Easy ajax image file uploads for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
