# locaine/lcn-template-block-bundle

> 标签: symfony 2, twig

## 简介

Populate blocks of template code from PHP/Twig and output them later in a Twig Template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
