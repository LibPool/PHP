# locaine/lcn-include-assets-bundle

> 标签: symfony 2, twig

## 简介

Include JS and CSS files in Symfony 2 as you did in Symfony 1 (use_javascript/use_stylesheet)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
