# locaine/lcn-wysihtml5-bundle

> 标签: Form Type, symfony 2, twig, wysiwyg

## 简介

WYSIWYG form type for Symfony2 using WYSIHTML5 and HTMLPurifier libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
