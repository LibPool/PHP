# wcatron/mysql-db-framework

> 标签: Object Based, mysql, odm

## 简介

A MySQL ODM (assistant) extremely flexible for any project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
