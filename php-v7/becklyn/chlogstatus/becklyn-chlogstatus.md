# becklyn/chlogstatus

> 标签: PHP

## 简介

Generates a changelog from a commit range. Updates all jira tickets within that range with a deployment status.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
