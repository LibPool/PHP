# press-bits/media-library-svg-display

> 标签: PHP

## 简介

Enable display of Scalable Vector Graphics (SVG) in the WordPress media library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
