# obydul/easyfeed

> 标签: RSS feed parser, laravel atom feed, laravel create rss feed, laravel feed generator, laravel feed parser, laravel feed reader, php feed creator, php feed generator, php feed parser, php feed reader

## 简介

EasyFeed is a simple PHP package to create and read RSS & Atom feed specially for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
