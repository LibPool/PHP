# econda/php-sdk

> 标签: PHP

## 简介

Client library to access econda services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.econda.com
- 源码仓库：https://github.com/econda/php-sdk.git
- Packagist 页面：https://packagist.org/packages/econda%2Fphp-sdk

## 历史版本号

- 当前版本：v0.1.3-beta2

## 获取地址

- Composer 安装：`composer require econda/php-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/econda/php-sdk.json
- 许可证：MIT
- PHP 要求：>=5.3.0
