# divante-ltd/pimcore-mysql-object-search

> 标签: pimcore, pimcore-plugin

## 简介

Similar to Pimcore's Advanced Object Search, but does not need Elasticsearch

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
