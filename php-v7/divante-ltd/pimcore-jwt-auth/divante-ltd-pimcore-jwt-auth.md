# divante-ltd/pimcore-jwt-auth

> 标签: jwt, pimcore, pimcore-plugin

## 简介

Module allowing to use JWT with Pimcore User object

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
