# link0/profiler-bundle

> 标签: Symfony2, bundle, link0, profiler

## 简介

Profiler bundle for Symfony2 to profile automatically using the event listener

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
