# sf2h/sftp-bundle

> 标签: ftp, server, sftp, ssh, symfony, transfer

## 简介

This bundle provide quite simple functions for interact with SFTP servers

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
