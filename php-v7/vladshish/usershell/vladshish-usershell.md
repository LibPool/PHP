# vladshish/usershell

> 标签: cakephp, group, shell, user

## 简介

Additional tools for create, complete and set permission for users, groups in CakePHP applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
