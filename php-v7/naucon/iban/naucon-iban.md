# naucon/iban

> 标签: BBAN, IBAN, checksum, parse, sepa, swift, validate, validation

## 简介

This package parses and validates International Bank Account Number (IBAN).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
