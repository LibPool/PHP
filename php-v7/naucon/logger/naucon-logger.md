# naucon/logger

> 标签: PSR3, gelf, log, logger, psr-3

## 简介

This package contains a simple logging class for php that handle one or more PSR-3 compatible loggers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
