# interactivesolutions/honeycomb-acl

> 标签: Authentication, Users, access, acl, control, control list, honeycomb, laravel, package, permissions

## 简介

HoneyComb access control list (ACL) package for users permissions and authentication.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
