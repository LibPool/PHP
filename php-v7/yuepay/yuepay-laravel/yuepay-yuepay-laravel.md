# yuepay/yuepay-laravel

> 标签: RSA2, cnyepay, laravel, payment, yuepay, 微信支付, 支付宝, 粤收付, 聚合支付

## 简介

粤收付（cnyepay）支付 SDK for Laravel，支持支付宝/微信/QQ钱包等多种支付方式

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
