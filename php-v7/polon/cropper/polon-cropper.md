# polon/cropper

> 标签: Polon, image cache, image crop, image thumb, thumbnails jpg, thumbnails png, thumbnails webp, upload, webp converter

## 简介

This is an easy and simple PHP image resizer with thumbnail cache management.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
