# wepesi/jwt

> 标签: JSON Web Token, PHP token, ibmussa, jwt, token

## 简介

simple json token web for simple authentication and token genetator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
