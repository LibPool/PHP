# simpsyst/router

> 标签: Diego Matos, SimpSyst, route, router, routes

## 简介

A classic SimpSyst Router is easy, fast and extremely uncomplicated. Create and manage your routes in minutes!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
