# jarves/jarves

> 标签: PHP CMS, WCMS, cms

## 简介

An open-source Content-Management-System CMS as Symfony Bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://jarves.io/
- 源码仓库：https://github.com/jarves/jarves.git
- Packagist 页面：https://packagist.org/packages/jarves%2Fjarves

## 获取地址
