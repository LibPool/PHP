# ramesh-dada/download-button

> 标签: 1Dot, bbcode, download, flarum

## 简介

Add visual Download button with size and filename to Flarum posts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
