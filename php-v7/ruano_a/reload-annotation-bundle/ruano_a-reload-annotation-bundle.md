# ruano_a/reload-annotation-bundle

> 标签: PHP

## 简介

A Symfony bundle providing a PHPUnit extension reloading the database if an annotation is present on test methods.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
