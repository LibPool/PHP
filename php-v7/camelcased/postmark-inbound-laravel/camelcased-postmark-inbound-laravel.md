# camelcased/postmark-inbound-laravel

> 标签: email, inbound, laravel, parser, postmark

## 简介

This is an Inbound Parser for Postmark meant to be used with Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
