# onethirtyone/aws-s3-mime-handler

> 标签: PHP

## 简介

A Laravel Package to parse AWS SES messages from an S3 Bucket

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
