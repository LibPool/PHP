# cds/nhs-number-validation

> 标签: nhs, validate, validation

## 简介

A simple PHP class to validate a NHS Number and return a correctly formatted version.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
