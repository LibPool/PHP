# yurunsoft/macro

> 标签: PHP

## 简介

支持在 PHP 代码中使用类似 C/C++ 中的宏，进行代码预编译。可以方便兼容不同版本和环境下运行的 PHP 代码。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
