# zwei/composer-vendor-directory

> 标签: php composer vendor directory

## 简介

composer-vendor-directory library for PHP.composer-vendor-directory  package is used to get the composer vendor directory.composer-vendor-directory包用于获取作composer vendor目录路径.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
