# jim-moser/zf2-validators-empty-or

> 标签: validation, validator, zf2

## 简介

Logical OR validator chains and empty value validator for Zend Framework 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
