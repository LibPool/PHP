# jeffersonglemos/dropbox-v2-php

> 标签: api, dropbox, php, sdk

## 简介

A PHP SDK for Dropbox's v2 API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
