# dreadlabs/kunstmaan-config-bundle

> 标签: cms, config, kunstmaan

## 简介

Opinionated configuration for your Kunstmaan CMS instance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
