# josebaroni/jobmonitor

> 标签: PHP

## 简介

JobMonitor is a Laravel package created to track Job resources usage and find stuck queue workers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
