# eleme/thrift-php

> 标签: thrift

## 简介

Mirror of apache thrift client lib of php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/Eleme/thrift-php
- 源码仓库：https://github.com/eleme/thrift-php.git
- Packagist 页面：https://packagist.org/packages/eleme%2Fthrift-php

- 许可证：Apache-2.0
