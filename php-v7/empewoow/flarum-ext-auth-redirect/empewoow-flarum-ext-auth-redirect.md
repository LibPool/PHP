# empewoow/flarum-ext-auth-redirect

> 标签: Authentication, links, redirect, user

## 简介

Redirect authentication methods; login, logout, and register links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
