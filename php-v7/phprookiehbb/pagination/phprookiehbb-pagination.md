# phprookiehbb/pagination

> 标签: array, pagination, tp5

## 简介

适用于所有程序的数组分页，内置分页样式,可定制样式,稍微修改一下可使用与所有的情形下的数组分页

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
