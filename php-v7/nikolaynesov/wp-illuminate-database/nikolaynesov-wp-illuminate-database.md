# nikolaynesov/wp-illuminate-database

> 标签: bedrock, composer, database, eloquent, illuminate, roots, stack, vagrant, wordpress, wp

## 简介

Illuminate Database wrapper plugin for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
