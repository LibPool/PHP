# ugarit/cashier-braintree

> 标签: billing, braintree, cashier, ugarit

## 简介

Ugarit Cashier provides an expressive, fluent interface to Braintree's subscription billing services.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
