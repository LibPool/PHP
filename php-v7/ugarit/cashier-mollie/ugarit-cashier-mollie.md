# ugarit/cashier-mollie

> 标签: Apple Pay, Europe, billing, credit card, debit card, mollie, recurring, sepa, subscriptions, ugarit

## 简介

Ugarit Cashier provides an expressive, fluent interface to Mollie's subscription billing services.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
