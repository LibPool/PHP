# okaufmann/qwertee-php

> 标签: Okaufmann, qwertee-php

## 简介

Simple client to access Qwertees (https://www.qwertee.com) todays and last chance tees

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
