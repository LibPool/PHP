# streams-sro/gaston

> 标签: API-Client, Transcription, gaston, speech-to-text, translation

## 简介

PHP client for the Gaston API (transcription, translation and sentence search).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
