# bgli100/rdb-helper

> 标签: PHP

## 简介

Deal with differences within PHP RDBMS APIs. Also provide facade class for global access. It does not try to generalize or simplify writing SQL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
