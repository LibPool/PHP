# bgli100/c-pchart

> 标签: CpChart, c-pChart, charts, pchart, statistics

## 简介

Port of "pChart" library into PHP 5+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
