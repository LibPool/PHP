# commerce-wa-ols/nicknames

> 标签: diminutives, nickname, nicknames

## 简介

Find nicknames for a given name or perform a reverse search on a nickname.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
