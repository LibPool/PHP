> 标签: Metrics, aggregation, analytics, cache, dashboard, grafana, laravel, laravel-package, logging, monitoring, observability, performance, production, telemetry, time-series

## 简介

A high-performance Laravel metrics collection package with caching, aggregation, and Grafana integration for production monitoring

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
