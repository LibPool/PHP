# edofre/laravel-fullcalendar

> 标签: calendar, event, fullcalendar, javascript, laravel

## 简介

Laravel component for fullcalendar package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
