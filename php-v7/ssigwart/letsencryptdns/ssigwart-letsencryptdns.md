# ssigwart/letsencryptdns

> 标签: ACME, acmev2, aws, letsencrypt, route53, ssl, wildcard

## 简介

PHP Let's Encrypt Wildcard DNS Client (AWS Route53 support)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
