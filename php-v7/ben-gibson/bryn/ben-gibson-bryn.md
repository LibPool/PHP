# ben-gibson/bryn

> 标签: Rate, conversion, currency, exchange

## 简介

A PHP library for calculating monetary conversions. This repository contains the interfaces and domain models only.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
