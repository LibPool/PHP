# chuckbe/chuckcms-template-frankfurt

> 标签: chuckbe, chuckcms, cms, laravel, php

## 简介

A ChuckCMS template named 'Frankfurt' - lightweight and responsive.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
