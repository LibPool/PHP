# darkin1/intercom

> 标签: Guzzle, api, intercom, intercom.io, laravel

## 简介

Wrapper on the Intercom class provided by Intercom - with support for Laravel 5.x, 6.x, 7.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
