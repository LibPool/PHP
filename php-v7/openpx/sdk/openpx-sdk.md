# openpx/sdk

> 标签: commerce, openpx, product-information, schema

## 简介

OpenPX SDK (early release): the OpenPX schema for describing products once and publishing them to every channel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://openpx.org
- 源码仓库：https://github.com/openpx-org/openpx-sdk-php.git
- Packagist 页面：https://packagist.org/packages/openpx%2Fsdk
