# webconsul/ebay-api-bundle

> 标签: api, ebay, finding, shopping, trading

## 简介

Wrapper for eBay API. Bundle for Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
