# moderntribe/tribe-storage

> 标签: Flysystem, aws, azure, cloud-storage, digital-oceans-spaces, google-cloud-storage, media, moderntribe, offload, rackspace, s3, wasabi, wordpress

## 简介

A WordPress plugin to upload files to many different storage types like Azure, s3, DO Spaces

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
