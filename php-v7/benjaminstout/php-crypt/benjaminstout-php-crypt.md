# benjaminstout/php-crypt

> 标签: PHP

## 简介

Barebones Cryptography Library for PHP – libsodium (NaCl), OpenSSL, Mcrypt, and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
