# sergiosaad/datalayer

> 标签: datalayer, daviw, sergiosaad

## 简介

PHP DatabaseLayer to work with MVC projects based on DaviW framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
