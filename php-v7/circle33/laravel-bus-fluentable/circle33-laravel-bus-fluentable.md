# circle33/laravel-bus-fluentable

> 标签: laravel, laravel-bus-fluentable

## 简介

Make Laravel testing batched jobs more fluent.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
