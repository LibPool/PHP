# constructions-incongrues/vanilla-discussiontypes

> 标签: PHP

## 简介

Vanilla Forums plugin to handle custom discussion types. This is the base plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
