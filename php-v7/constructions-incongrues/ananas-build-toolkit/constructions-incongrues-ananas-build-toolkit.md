# constructions-incongrues/ananas-build-toolkit

> 标签: PHP

## 简介

L'Ananas Build Toolkit est un framework de configuration et de déploiement de projet logiciel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
