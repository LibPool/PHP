# coffreo/php-cs-fixer-config

> 标签: PHP

## 简介

Provides a configuration factory and multiple Coffreo rule sets for friendsofphp/php-cs-fixer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
