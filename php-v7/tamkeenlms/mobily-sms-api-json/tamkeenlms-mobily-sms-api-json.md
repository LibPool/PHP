# tamkeenlms/mobily-sms-api-json

> 标签: api, mobily, sms, sms-api

## 简介

A non-official API client for Mobily.ws SMS service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
