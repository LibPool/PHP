# cinghie/yii2-fontawesome

> 标签: font awesome, yii2 font, yii2 font awesome, yii2 fontawesome

## 简介

Asset Bundle to include Font Awesome on your Yii 2 project

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
