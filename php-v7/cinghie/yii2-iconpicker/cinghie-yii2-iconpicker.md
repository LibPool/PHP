# cinghie/yii2-iconpicker

> 标签: extension, yii2

## 简介

Widget for bootstrap-iconpicker plugin http://victor-valencia.github.io/bootstrap-iconpicker/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
