# paga/paga-collect

> 标签: Paga, paga-collect, payment

## 简介

This document lists the different RESTful web services Paga offers allowing anyone (payment request initiator) to initiate a payment request to a third party and automatically get notified when the payment request is fulfilled

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
