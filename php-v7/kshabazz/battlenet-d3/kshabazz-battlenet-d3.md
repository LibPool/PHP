# kshabazz/battlenet-d3

> 标签: api, blizzard, diablo 3, rest, web

## 简介

An API (written in PHP) for accessing Battle.net Diablo 3 REST service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
