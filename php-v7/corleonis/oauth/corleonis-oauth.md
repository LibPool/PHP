# corleonis/oauth

> 标签: oauth, oauth client, oauth provider, oauth server, oauth v1

## 简介

This is a PHP oAuth v1 client/provider library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
