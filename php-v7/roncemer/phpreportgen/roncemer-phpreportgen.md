# roncemer/phpreportgen

> 标签: csv, html, ods, pdf, report, reporting, reports, tsv, xls, xlsx

## 简介

HTML, CSV, TSV, XLS, PDF reporting package, with nested sections and totaling

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
