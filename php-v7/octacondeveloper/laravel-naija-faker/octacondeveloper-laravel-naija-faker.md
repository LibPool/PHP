# octacondeveloper/laravel-naija-faker

> 标签: PHP

## 简介

A Laravel package that generates fake data for user to use in the project. A local version of Fzaninotto's faker for Nigerian developers quick data that they can relate to

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
