# tonix-tuft/cliche

> 标签: cli, command, command-line, command-line-interface, commands

## 简介

A tiny PHP library to execute CLI commands meant to be overused to the point of becoming trite or irritating.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
