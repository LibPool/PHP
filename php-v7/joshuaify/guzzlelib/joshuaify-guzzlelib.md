# joshuaify/guzzlelib

> 标签: api, api-requests, client, codeigniter, guzzlelib, joshuaify, laravel, php

## 简介

A wrapper library for Guzzle HTTP client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
