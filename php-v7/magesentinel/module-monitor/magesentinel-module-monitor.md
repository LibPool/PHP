# magesentinel/module-monitor

> 标签: checkout, checkout-monitoring, diagnostics, hyva, magento, magento2, magento2-module, store-health, synthetic-monitoring, uptime

## 简介

Store health page, 15-minute health emails, weekly summary and a real-browser test purchase for Magento 2. Optional connector for MageSentinel checkout monitoring.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
