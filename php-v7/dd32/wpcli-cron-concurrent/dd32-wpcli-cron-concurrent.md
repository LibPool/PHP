# dd32/wpcli-cron-concurrent

> 标签: concurrent, cron, wp-cli

## 简介

Runs WordPress cron tasks concurrently via wp-cli.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
