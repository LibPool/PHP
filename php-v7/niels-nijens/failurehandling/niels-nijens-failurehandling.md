# niels-nijens/failurehandling

> 标签: Errorhandling, Failurehandling, error, exceptions, logging

## 简介

An error and exception handling library for PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
