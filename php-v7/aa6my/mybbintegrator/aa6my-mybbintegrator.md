# aa6my/mybbintegrator

> 标签: connecter, integrator, mybb

## 简介

PHP Class which offers MyBB functionality for own use (integration into website).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
