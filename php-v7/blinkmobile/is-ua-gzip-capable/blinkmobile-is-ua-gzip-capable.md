# blinkmobile/is-ua-gzip-capable

> 标签: PHP

## 简介

(Hopefully) small algorithm to determine whether or not to GZIP an HTTP response

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
