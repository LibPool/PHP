# k3progetti/software-version-bundle

> 标签: PHP

## 简介

Bundle Symfony che manda al server delle versioni il PHP e il Symfony che girano davvero nel progetto

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
