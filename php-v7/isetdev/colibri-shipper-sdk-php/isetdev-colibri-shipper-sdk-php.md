# isetdev/colibri-shipper-sdk-php

> 标签: Freteasy, api, sdk

## 简介

This is the official PHP SDK for Integration with FretEasy API. https://www.freteasy.com.br

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
