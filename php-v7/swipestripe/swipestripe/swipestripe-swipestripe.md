# swipestripe/swipestripe

> 标签: e-commerce, ecommerce, shop, silverstripe, swipe stripe, swipestripe

## 简介

Ecommerce module to create online shops using SilverStripe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
