# jincon/tinypay

> 标签: PHP

## 简介

Tinypay以最简单的方式，整合微信支付、支付宝支付、银联支付、百度支付、字节跳动支付。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
