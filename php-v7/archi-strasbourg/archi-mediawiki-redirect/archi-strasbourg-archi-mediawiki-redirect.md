# archi-strasbourg/archi-mediawiki-redirect

> 标签: PHP

## 简介

Script that redirects old Archi-Wiki URLs to new MediaWiki URLs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
