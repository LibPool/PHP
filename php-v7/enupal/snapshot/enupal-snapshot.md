# enupal/snapshot

> 标签: Craft, cms, craft-plugin, craftcms, image, pdf, snapshot

## 简介

PDF or Image generation from a Url or HTML page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
