# perchten/wordpress_attachmentfromimg

> 标签: attachment, functional, image, util, wordpress

## 简介

Single function to get wordpress attachment id from an img src

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
