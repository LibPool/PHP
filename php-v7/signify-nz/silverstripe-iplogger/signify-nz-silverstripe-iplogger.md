# signify-nz/silverstripe-iplogger

> 标签: IP, event, fail2ban, logging, silverstripe, spam

## 简介

Logs and limits events based on client IP and a set of rules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
