# googlei18n/myanmar-tools

> 标签: detector, myanmar-font, myanmar-tools, unicode, zawgyi

## 简介

Zawgyi and Unicode Font Detector using Markov Model (Machine Learning)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
