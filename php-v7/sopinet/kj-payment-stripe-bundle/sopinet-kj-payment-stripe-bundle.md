# sopinet/kj-payment-stripe-bundle

> 标签: Symfony2, payment, stripe

## 简介

Payment Bundle providing access to the Stripe API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
