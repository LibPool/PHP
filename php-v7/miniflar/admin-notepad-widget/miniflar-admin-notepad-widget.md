# miniflar/admin-notepad-widget

> 标签: admin, flarum, flarum-admin, flarum-admin-notepad, notepad

## 简介

Adds a notepad widget to your Admin Dashboard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
