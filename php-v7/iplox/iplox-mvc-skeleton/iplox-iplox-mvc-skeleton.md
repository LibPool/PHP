# iplox/iplox-mvc-skeleton

> 标签: PHP

## 简介

A skeleton mvc-app using Iplox, Smarty, jQuery and Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
