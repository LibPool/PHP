# ont/laravel-uploader

> 标签: filesystem, upload

## 简介

Implementation of Ont\Interfaces\Uploader which saves files in local filesystem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
