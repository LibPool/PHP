# m2de/bugherd-laravel

> 标签: bugherd, laravel

## 简介

A Laravel Helper package to install the [Bugherd](https://www.bugherd.com/) script

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
