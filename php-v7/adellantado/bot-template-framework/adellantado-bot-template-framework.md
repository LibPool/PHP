# adellantado/bot-template-framework

> 标签: Bot Template Framework, Botman, chatbot

## 简介

Easy to build bot scenarios and run them on top of Botman

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
