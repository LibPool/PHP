# cyvelnet/laravel-easycart

> 标签: Laravel cart, easycart, shopping cart

## 简介

A simple & easy to use yet powerful laravel cart solution

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
