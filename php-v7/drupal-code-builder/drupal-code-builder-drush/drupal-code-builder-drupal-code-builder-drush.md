# drupal-code-builder/drupal-code-builder-drush

> 标签: PHP

## 简介

Provides Drush commands for generating Drupal code using Drupal Code Builder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
