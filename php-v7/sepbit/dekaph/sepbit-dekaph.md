# sepbit/dekaph

> 标签: SEPBIT, calendar, converter, date, dekatrian, gregorian

## 简介

This is a simple library to convert Dekatrian and Gregorian.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
