# jenbuzz/laravel-uuid

> 标签: Universally unique identifier, eloquent, laravel, ramsey uuid, uuid

## 简介

Adds a uuid to a model using ramsey/uuid

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
