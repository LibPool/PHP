# docalist/docalist-biblio-thumbnails

> 标签: docalist

## 简介

Docalist-Biblio Extension: provides default thumbails for notices with links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
