# thomas-keil/dynamic-dropdown

> 标签: Dynamic Dropbox Module, pimcore, plugin

## 简介

Populate Comboboxes with Object content of a selected folder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
