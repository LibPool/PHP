# craftremote/plugin

> 标签: Craft, cms, craft-plugin, craftcms, craftremote

## 简介

Remotely manage your Craft CMS installs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
