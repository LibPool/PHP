# milsdev/wordpress-plugin-sarcofag

> 标签: PHP

## 简介

Wordpress plugin, brings EventDispatcher, DependencyInjection and MVC to the Wordpress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
