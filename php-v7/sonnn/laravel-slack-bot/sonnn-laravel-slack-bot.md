# sonnn/laravel-slack-bot

> 标签: command, exception, jobs, laravel, slack

## 简介

Sends a message to Slack when something goes wrong with your Laravel application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
