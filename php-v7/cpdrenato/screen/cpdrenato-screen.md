# cpdrenato/screen

> 标签: capture, phantomjs, print-screen, screen

## 简介

A PHP Class to interact with PhantomJs and capture screenshot of a webpage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
