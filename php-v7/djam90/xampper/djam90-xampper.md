# djam90/xampper

> 标签: apache, hosts, virtual host, xampp, xampper

## 简介

Easily add an xampp virtual host and an entry in the hosts file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
