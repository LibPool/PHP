# eideasy/eideasy-php

> 标签: PHP

## 简介

Create ASIC-E digital signature containers and add XAdES signatures to the container. Helper SDK for eID Easy API-s.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
