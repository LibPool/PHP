# rogermaciel/cakephp-acl-manager

> 标签: acl, cake3, cakephp, cakephp3, manager, plugin

## 简介

AclManager plugin for CakePHP 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
