# pingyi/json-serializer

> 标签: closure, json, php, serialize, serializer

## 简介

Mixed of two repositories for serializing and unserializing PHP variables, object and closure.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
