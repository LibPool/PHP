# jerodev/laravel-font-awesome

> 标签: FontAwesome, laravel, svg

## 简介

A Laravel package that renders Font Awesome icons server-side

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
