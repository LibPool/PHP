# cognito/omnipay3-zippay

> 标签: gateway, merchant, omnipay, omnipay3, pay, payment, zipPay

## 简介

Zippay driver for the Omnipay 3 payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
