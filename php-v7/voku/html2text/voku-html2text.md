# voku/html2text

> 标签: HTMLToText, HtmlIntoText, email, html, html-to-text, text

## 简介

Only a Fork of -> html2text: Converts HTML to formatted plain text

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
