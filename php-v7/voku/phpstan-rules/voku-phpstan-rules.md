# voku/phpstan-rules

> 标签: PHPStan, phpstan-extreme-rules, phpstan-rules

## 简介

Provides additional rules for phpstan/phpstan.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
