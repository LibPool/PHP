# phirecms/phirecms

> 标签: Content management system, PHP CMS, cms, phire, phire cms

## 简介

Phire CMS, a robust content management system written in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
