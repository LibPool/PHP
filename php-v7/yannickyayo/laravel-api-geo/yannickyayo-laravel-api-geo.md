# yannickyayo/laravel-api-geo

> 标签: YannickYayo, laravel, laravel-api-geo

## 简介

Wrapper Laravel pour communiquer avec l'API GEO du gouvernement français.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
