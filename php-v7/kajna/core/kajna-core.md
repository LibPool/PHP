# kajna/core

> 标签: Simple, api, framework, k, lightweight, php, rest, router

## 简介

Simple and lightweight yet powerful PHP framework for writing REST APIs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
