> 标签: helper, ide, laravel, october, octobercms, php, phpstorm, vscode

## 简介

OctoberCMS plugin to make development easier by providing IDE helpers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
