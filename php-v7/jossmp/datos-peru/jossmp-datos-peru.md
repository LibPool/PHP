# jossmp/datos-peru

> 标签: EsSalud, Mintra, consulta, curl, peru, php, reniec

## 简介

Clase para realizar consultas a reniec, essalud, ministrio del trabajo con el numero de DNI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
