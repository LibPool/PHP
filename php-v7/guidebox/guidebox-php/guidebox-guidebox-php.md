# guidebox/guidebox-php

> 标签: api, guidebox, rest, streaming, web service, wrapper

## 简介

Guidebox API PHP wrapper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
