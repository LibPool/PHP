# deathbeam/fwphp

> 标签: Skeleton, application, barebone, boilerplate, framework, naked

## 简介

Blazing fast and simple PHP micro framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://deathbeam.github.io/fwphp
- 源码仓库：https://github.com/deathbeam/fw.php.git
- Packagist 页面：https://packagist.org/packages/deathbeam%2Ffwphp
