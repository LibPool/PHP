# eberhm/phoenix-server-bundle

> 标签: PHP

## 简介

This bundle integrates eberhm/phoenix library into Symfony2 framework as a bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
