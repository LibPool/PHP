# hauerheinrich/hh-tt-address-places

> 标签: TYPO3 CMS, address, companies, extension, places

## 简介

Simply adds places / companies TCA for EXT:tt_address.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
