# hauerheinrich/hh_openstreetmap

> 标签: OpenStreetMap, TYPO3 CMS, extension, map

## 简介

Hauer-Heinrich - Simple OpenStreetMap, can use multiple markers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
