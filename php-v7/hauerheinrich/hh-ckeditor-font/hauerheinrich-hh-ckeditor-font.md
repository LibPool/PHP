# hauerheinrich/hh-ckeditor-font

> 标签: CKEditor, TYPO3 CMS, extension, typo3

## 简介

CKEditor 5 Font buttons for TYPO3 v13: class-based font color, font background color and font family pickers, fully configurable via RTE YAML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
