# stevenbuehner/zend-bootstrap-view

> 标签: bootstrap, module, partial templates, zend, zf2

## 简介

Partial View-Templates to render the ZendForms (and in the future potentially others elements of bootstrap). This module needs bootstrap V3 included in its stylesheet path.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
