# andkom/php-bitcoin-wallet

> 标签: bitcoin, wallet, wallet.dat

## 简介

A simple PHP library for reading Bitcoin wallet.dat file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
