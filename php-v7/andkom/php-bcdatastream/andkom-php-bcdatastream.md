# andkom/php-bcdatastream

> 标签: binary, bitcoin, stream

## 简介

A simple stream implementation in PHP for reading/writing binary data in Bitcoin protocol.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
