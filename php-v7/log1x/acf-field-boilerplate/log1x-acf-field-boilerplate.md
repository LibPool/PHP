# log1x/acf-field-boilerplate

> 标签: acf, acf-field, wordpress, wordpress-plugin

## 简介

A clean starting point for custom Advanced Custom Fields field types.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
