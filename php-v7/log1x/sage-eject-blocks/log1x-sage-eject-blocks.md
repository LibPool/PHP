# log1x/sage-eject-blocks

> 标签: gutenberg, wordpress

## 简介

Eject Sage 10 editor scripts to a optional lazy-loaded plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
