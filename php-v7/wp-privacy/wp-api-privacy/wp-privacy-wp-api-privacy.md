# wp-privacy/wp-api-privacy

> 标签: plugin, privacy, wordpress

## 简介

Strips potentially identifying information from outbound requests to the WordPress.org API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
