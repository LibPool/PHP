# lcinhk/flarum-imgur-upload

> 标签: PHP

## 简介

Simple image upload from the Flarum editor, added support for custom proxy_pass URL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
