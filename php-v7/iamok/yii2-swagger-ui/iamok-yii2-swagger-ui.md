# iamok/yii2-swagger-ui

> 标签: extension, swagger, yii2

## 简介

扩展集成 swagger-ui 和 swagger-php，根据注释自动生成 OpenAPI 文档。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
