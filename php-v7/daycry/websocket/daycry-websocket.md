# daycry/websocket

> 标签: PHP7, Ratchet, codeigniter, codeigniter websocket, codeigniter4, php-library, realtime, websocket

## 简介

Websocket using Ratchet Websocket technology for CodeIgniter 4

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
