# smt/open-popo

> 标签: entity, object, phpunit, plain old php object, test

## 简介

Simple library for easy testing Plain Old PHP Objects (inspired by open-pojo)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
