# tad80/optimisticlock

> 标签: cakephp, optimistic lock

## 简介

CakePHP behavior plugin to implement optimistic locking for RDBMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
