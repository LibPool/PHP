# 20tries/arr

> 标签: arr, array, array dot, array helper, dot, dot notation, helper

## 简介

A package for aiding the handling of arrays using 'dot notation'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
