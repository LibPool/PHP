# ondercsn/social-link-processor

> 标签: formatting, sanitization, social-media, url, validation

## 简介

A comprehensive PHP library for validating, formatting, and sanitizing social media links

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
