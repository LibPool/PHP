# laravolt/workflow

> 标签: bpmn, camunda, laravel, laravolt

## 简介

This package is used to connect Laravolt with Camunda BPMN to make it easier.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
