# sikker/notnosql

> 标签: Simple, key-value, nosql, pdo, storage

## 简介

The SQL-based NoSQL library for PHP -- it's NoSQL, even though it's not!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
