# yakeing/php_fsockopen

> 标签: fsockopen, tcp, udg, udp, unix

## 简介

fsockopen is the wrapper function for socket socket links

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
