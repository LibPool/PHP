# krupa/laravel-ocs

> 标签: Openstack, files, filesystem, filesystems, ocs, oktawave, swift

## 简介

Oktawave Cloud Storage service provider for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
