# michielkempen/laravel-encryptable

> 标签: Laravel Encryptable, Michiel Kempen

## 简介

A trait to automatically encrypt/decrypt sensitive attributes of Laravel models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
