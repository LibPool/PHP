# dastanaron/yii2-migrate-updater

> 标签:  migrate,  migrations,  update, extension, yii2

## 简介

The extension allows you to save data when performing a ./yii migrate/redo

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
