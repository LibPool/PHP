# haakco/reliese-laravel-models

> 标签: laravel, reliese

## 简介

Fork of Reliese Components for Laravel Framework code generation. With patches for postgresql, and a couple other things.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
