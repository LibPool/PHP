# stianscholtz/tab-manager-laravel

> 标签: Stian-Scholtz, laravel, tab-manager-laravel

## 简介

This is a Laravel package used to manage browser tab specific session data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
