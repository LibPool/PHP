# hurtak/phpautocolor

> 标签: CIEDE2000, color, coloring, colorize, colors, dye

## 简介

Simple PHP class for automated coloring with visually distinct colors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
