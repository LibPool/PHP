# khaleejinfotech/youtube-data-api-laravel

> 标签: PHP

## 简介

YouTube Metadata normal grabs singular details about a video and its uploader.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
