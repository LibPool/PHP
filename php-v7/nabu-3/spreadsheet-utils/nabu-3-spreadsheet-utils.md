# nabu-3/spreadsheet-utils

> 标签: datasheet, excel, microsoft, ms-excel, msexcel, msoffice, nabu, nabu-3, spreadsheet

## 简介

nabu-3 Utilities to manage Spreadsheets based on library phpoffice/phpspreadsheet

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
