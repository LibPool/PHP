# silinternational/idp-pw-api-phoneverification-nexmo

> 标签: PHP

## 简介

PhoneVerification component for IdP PW API that uses Nexmo services for SMS/Voice verification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
