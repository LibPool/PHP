# silinternational/simplesamlphp-module-expirychecker

> 标签: PHP

## 简介

simpleSAMLphp module for warning users that their password will expire soon or has already expired.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
