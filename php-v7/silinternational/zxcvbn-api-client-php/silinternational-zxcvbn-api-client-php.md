# silinternational/zxcvbn-api-client-php

> 标签: zxcvbn

## 简介

PHP client library for interacting with Zxcvbn API. See https://github.com/wcjr/zxcvbn-api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
