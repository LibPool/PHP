# silinternational/simplesamlphp-module-silauth

> 标签: PHP

## 简介

SimpleSAMLphp auth module implementing various security measures before calls to IdP ID Broker backend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
