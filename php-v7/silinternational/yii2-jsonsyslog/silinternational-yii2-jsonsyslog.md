# silinternational/yii2-jsonsyslog

> 标签: json, log, syslog, yii2

## 简介

Yii2 log target for sending data to Syslog as a JSON encoded string

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
