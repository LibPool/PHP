# silinternational/simplesamlphp-module-profilereview

> 标签: PHP

## 简介

A simpleSAMLphp module for prompting the user to review their profile (such as 2fa, email, etc.).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
