# silinternational/yii2-json-log-targets

> 标签: file, json, log, syslog, target, yii2

## 简介

A collection of Yii2 log targets that format the log message as a JSON string.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
