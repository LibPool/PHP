# webxid/edmo

> 标签: PHP

## 简介

EDMo - it is Entity Data Model (EDM) tool. No reflection or other extra things, which doesn't need to use in Live

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
