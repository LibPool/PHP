# hashworks/phergie-xrel-plugin

> 标签: bot, irc, nfo, phergie, plugin, xrel

## 简介

Phergie plugin to access the xREL.to API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
