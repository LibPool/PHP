# jyoungblood/http-request

> 标签: HTTP requests, curl, http client, utilities

## 简介

PHP functions to handle sending and receiving HTTP requests with CURL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
