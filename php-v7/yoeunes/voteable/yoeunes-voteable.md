# yoeunes/voteable

> 标签: dislike, down vote, laravel, like, likeable, up vote, vote, voteable

## 简介

This package helps you to add user based voting system to your model.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
