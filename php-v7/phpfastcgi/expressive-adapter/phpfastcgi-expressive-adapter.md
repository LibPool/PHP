# phpfastcgi/expressive-adapter

> 标签: daemon, expressive, fast cgi, fastcgi, server, zend

## 简介

A PHPFastCGI adapter for the Zend Expressive framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
