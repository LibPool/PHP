# phpfastcgi/speedfony-bundle

> 标签: bundle, daemon, fast cgi, fastcgi, server, speedfony

## 简介

A bundle to integrate a FastCGI daemon with the symfony2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
