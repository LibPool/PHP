# lipis/flag-icons

> 标签: country, country-flags, css, icon-css, svg

## 简介

A curated collection of all country flags in SVG — plus the CSS for easier integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
