# deadsimple/hyva-alpine-confetti

> 标签: PHP

## 简介

A deadsimple wrapper to use the confetti plugin from Jack Web Heller directly in you Hyvä theme and forms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
