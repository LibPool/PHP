# hardwiregaming/ts3-php

> 标签: teamspeak3

## 简介

Clone of TS3 PHP Framework 1.1.23 providing the library as composer project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/fkubis/teamspeak-php-framework
- 源码仓库：https://github.com/lastlifegg/ts3-php.git
- Packagist 页面：https://packagist.org/packages/hardwiregaming%2Fts3-php
