# harness/ff-server-sdk

> 标签: harness, harness featureflags, harness ff, harness php

## 简介

PHP Server SDK for integrating with Harness Feature Flag service.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
