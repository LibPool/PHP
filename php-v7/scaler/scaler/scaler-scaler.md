# scaler/scaler

> 标签: BMP, Webp, avif, compress, convert, crop, gif, heic, heif, image, jpeg, optimize, photo, png, resize, scale, tiff, transform

## 简介

Scaler.pics API for efficient photo and image resizing, conversion and document thumbnail generation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
