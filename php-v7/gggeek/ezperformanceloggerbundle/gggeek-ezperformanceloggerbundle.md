# gggeek/ezperformanceloggerbundle

> 标签: PHP

## 简介

The 'bundle' version of the ezperformancelogger extension for eZ Publish

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
