# vovanmix/phinx-laravel-style

> 标签: laravel, migrations, phinx

## 简介

Extension on top of Phinx to make migrations in Laravel 5 style with good IDE support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
