# geraldvillorente/terminus-sweeper

> 标签: PHP

## 简介

A tool for sweeping/cleaning users dashboard by removing thememselves from the site and delete owned frozen site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
