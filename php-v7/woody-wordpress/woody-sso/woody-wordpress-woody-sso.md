# woody-wordpress/woody-sso

> 标签: PHP

## 简介

This plugin replaces the native wordpress connection system with the SSO (single sign on) button of Raccourci Agency: THE STUDIO

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
