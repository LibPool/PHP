# devpirates/templated-php-mvc

> 标签: PHP

## 简介

Library to help people quickly build and maintain an mvc project in php with lots of helpful built in tools and utilities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
