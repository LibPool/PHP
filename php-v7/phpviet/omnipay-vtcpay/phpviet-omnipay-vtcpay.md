# phpviet/omnipay-vtcpay

> 标签: payment, payment-gateway, phpviet, vietnam-payment, vietnam-payment-gateway, vtcpay

## 简介

Thư viện hổ trợ tích hợp cổng thanh toán VTCPay.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
