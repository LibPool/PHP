# ccerda0520/alternative-http-header

> 标签: PHP

## 简介

A Magento 2 module that uses a custom http remote address header used by Cloudflare or other CDN/proxies.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
