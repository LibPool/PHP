# ccohen/huawei-api

> 标签: E5180, api

## 简介

A barebones API to interact with the Huawei E5180 router

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/HSPDev/Huawei-E5180-API
- 源码仓库：https://github.com/clementcohen/Huawei-E5180-API.git
- Packagist 页面：https://packagist.org/packages/ccohen%2Fhuawei-api
