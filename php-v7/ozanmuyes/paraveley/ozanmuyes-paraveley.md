# ozanmuyes/paraveley

> 标签: form, laravel 5, parsley, request

## 简介

Automatically generate Parsley rules depending on Laravel's FormRequest.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
