# lmihaylov/pass-generator

> 标签: generator, pass-generator, passgenerator, password, password generator, php password generator, simple and elegant password generator

## 简介

A simple and elegant PHP password generator for either browser and console environments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
