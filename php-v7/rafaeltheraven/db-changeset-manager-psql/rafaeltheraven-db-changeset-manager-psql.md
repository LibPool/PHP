# rafaeltheraven/db-changeset-manager-psql

> 标签: PHP

## 简介

Automate the process of applying SQL files (changesets) to databases of different environments or users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
