# fgendorf/php-gravityzone-api

> 标签: antivirus, api, bitdefender, gravityzone, rest, security

## 简介

A library to interact with the BitDefender GravityZone REST API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
