# pushword/page-scanner

> 标签: 404, broken-link-checker, crawler, dead-links, link-checker, pushword, seo

## 简介

Find dead links, 404, 301 and more (command line or admin).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
