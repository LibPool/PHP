# pushword/api

> 标签: api, content-api, headless-cms, openapi, pushword, rest, symfony

## 简介

REST API mirror of the Pushword admin (Page, Media, …). Token-authenticated, OpenAPI-described.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
