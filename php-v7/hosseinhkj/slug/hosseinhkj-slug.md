# hosseinhkj/slug

> 标签: farsi, laravel, persian, slug

## 简介

A simple Laravel 5.x package to create Persian (Farsi) slugs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
