# ampersandtarski/siam

> 标签: PHP

## 简介

Ampersand module for Sessions, Identity and Access Management (SIAM). Contains ADL scripts that can be reused.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
