# flyingmana/piecrust

> 标签: PHP

## 简介

a personal fork of piecrust-php/piecrust from giftnuss/PieCrust: A lightweight CMS and static website generator.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
