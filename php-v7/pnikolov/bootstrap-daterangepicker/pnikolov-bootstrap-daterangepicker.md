# pnikolov/bootstrap-daterangepicker

> 标签: bootstrap component, date picker, date range picker

## 简介

Slim wrapper of Bootstrap Date range picker.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
