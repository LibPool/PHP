# nails/common

> 标签: Nails, Shed Collective, codeigniter

## 简介

Nails is a framework for CodeIgniter designed to make building interactive web applications fast.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
