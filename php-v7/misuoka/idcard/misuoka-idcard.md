# misuoka/idcard

> 标签: birthdate, constellation, gender, idcard, misuoka, region

## 简介

身份证号码校验及信息提取。信息包含：出生日期、性别、年龄、星座、出生地等

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
