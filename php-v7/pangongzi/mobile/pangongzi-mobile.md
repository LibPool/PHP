# pangongzi/mobile

> 标签: china-mobile, geolocation, location, mobile, phone-number, php, 归属地查询, 手机号归属地

## 简介

高性能中国大陆手机号码归属地查询库，基于二进制数据文件实现，支持毫秒级查询响应

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
