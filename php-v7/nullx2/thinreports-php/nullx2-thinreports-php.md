# nullx2/thinreports-php

> 标签: pdf, reporting

## 简介

An implementation of Thinreports Generator in PHP, may be. It provides easy and simple way for generating a PDF on pure PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
