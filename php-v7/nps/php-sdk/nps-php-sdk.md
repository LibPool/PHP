# nps/php-sdk

> 标签: NPS, api, ingenico, payment processing

## 简介

A Php SDK for Ingenico ePayments - NPS LatAm Services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
