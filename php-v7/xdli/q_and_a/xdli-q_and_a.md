# xdli/q_and_a

> 标签: answer, extension, laravel-admin, question, questions and answers

## 简介

in a exam, create paper-questions-answers extension for laravel-admin . (生成一张问卷(考卷)，包含问题和对应的选项和正确答案。)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
