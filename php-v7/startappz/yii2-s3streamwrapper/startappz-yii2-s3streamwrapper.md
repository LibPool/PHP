# startappz/yii2-s3streamwrapper

> 标签: amazon, extension, s3, stream warapper, yii2

## 简介

Register s3:// steam wrapper to be used into yii2 applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
