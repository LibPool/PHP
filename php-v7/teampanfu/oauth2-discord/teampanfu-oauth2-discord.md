# teampanfu/oauth2-discord

> 标签: Authentication, authorization, client, discord, oauth, oauth2

## 简介

Discord OAuth 2.0 Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
