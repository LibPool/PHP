# cruzer/dolphin

> 标签: dolphin, orm, php, query builder

## 简介

Dolphin ORM and Query Builder with Laravel Eloquent like syntax but very small footprint

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
