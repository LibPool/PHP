# zanbug/php-sdk

> 标签: error-monitoring, error-tracking, exceptions, monitoring, zanbug

## 简介

Zanbug error & monitoring SDK — framework-agnostic PHP core (captures exceptions, requests, auth & session).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
