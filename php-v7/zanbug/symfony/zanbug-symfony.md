# zanbug/symfony

> 标签: error-monitoring, error-tracking, exceptions, monitoring, symfony, zanbug

## 简介

Zanbug error & monitoring SDK — Symfony bundle that auto-captures exceptions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
