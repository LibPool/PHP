# fortpesa/fortpesa-php

> 标签: fortpesa, kenya, m-pesa, mpesa, payments, stk-push

## 简介

PHP client for the Fortpesa M-Pesa API: STK Push, transaction status, wallet balance and signed webhooks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
