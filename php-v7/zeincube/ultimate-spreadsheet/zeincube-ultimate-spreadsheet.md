# zeincube/ultimate-spreadsheet

> 标签: OpenXML, excel, gnumeric, ods, php, spreadsheet, xls, xlsx

## 简介

Ultimate php spreadsheet library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
