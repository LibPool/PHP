# imiphp/imi-prometheus

> 标签: PHP

## 简介

imi 框架普罗米修斯（Prometheus）服务监控指标组件。imi Prometheus component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
