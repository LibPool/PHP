# spacedealer/yii2-geonames

> 标签: Guzzle, api, client, extension, geonames, rest, yii2

## 简介

Yii2 extension for geonames.org webservice api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
