# pmvc-plugin/yo_swagger

> 标签: hello, plug-in, pmvc

## 简介

Swagger spec generator for PMVC yo rest framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
