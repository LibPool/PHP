# carlhannes/find-namespace-php

> 标签: class, command, command-line, fqcns, namespace

## 简介

Find namespaces in PHP projects using this php cli tool

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
