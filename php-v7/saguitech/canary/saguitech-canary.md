# saguitech/canary

> 标签: PHP

## 简介

Canary is a cleaner version of the PHP language, like SASS for CSS, or TypeScript to Javascript, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
