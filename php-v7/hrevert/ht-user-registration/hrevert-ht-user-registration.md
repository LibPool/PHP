# hrevert/ht-user-registration

> 标签: module, zf2

## 简介

A Zend Framework 2 module which extends the registration feature of ZfcUser with email address verification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
