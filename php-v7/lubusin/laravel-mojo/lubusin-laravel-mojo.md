# lubusin/laravel-mojo

> 标签: instamojo, laravel, package

## 简介

Laravel Mojo provides an expressive, fluent interface to Instamojo's payment and refund services.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
