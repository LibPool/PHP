# shaozeming/laravel-translate

> 标签: PHP

## 简介

一个集成百度翻译，有道翻译，Google翻译的PHP composer package  for laravel5.* and lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
