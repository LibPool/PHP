# shaozeming/aliyun-core

> 标签: PHP

## 简介

基于阿里云api sdk core封装的composer组件包，便于shaozeming/aliyun-vod，shaozeming/aliyun-oss(开发中)，shaozeming/aliyun-ecs(开发中)加载,便于维护和即时跟新官方sdk,解决核心类名在项目中冲突的问题

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
