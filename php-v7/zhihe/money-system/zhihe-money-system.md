# zhihe/money-system

> 标签: access control, economy, flarum, money, pay to view

## 简介

Advanced money system for content access control with view costs and tag-based restrictions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
