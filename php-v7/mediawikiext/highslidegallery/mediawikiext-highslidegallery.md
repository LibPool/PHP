# mediawikiext/highslidegallery

> 标签: extension, gallery, highslide, images, lightbox, mediawiki, youtube

## 简介

MediaWiki extension: HighslideGallery leverages Highslide JS-powered galleries for images and YouTube videos: supports thumbnails or inline anchor text, slideshow grouping via hsgid and MediaWiki-style captions within an interactive overlay.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
