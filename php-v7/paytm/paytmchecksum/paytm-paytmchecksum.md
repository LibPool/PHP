# paytm/paytmchecksum

> 标签: Paytm PHP, Paytm checksum, Paytm payment, Paytm signature, checksum, paytm, signature

## 简介

This is for paytm checksum creation and verification in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
