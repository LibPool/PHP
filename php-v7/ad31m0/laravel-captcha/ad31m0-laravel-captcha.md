# ad31m0/laravel-captcha

> 标签: Laravel Captcha, botdetect, captcha, captcha generator, captcha package, laravel captcha package

## 简介

Laravel Captcha Package -- BotDetect PHP CAPTCHA generator integration for the Laravel framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
