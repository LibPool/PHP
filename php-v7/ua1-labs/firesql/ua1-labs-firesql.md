# ua1-labs/firesql

> 标签: dbal, fire, firestudio, mongo, nosql, orm, sql, ua1, ua1-labs, ua1labs

## 简介

Set your SQL database on fire by making it into a NoSQL database.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
