# librenms/ip-util

> 标签: IP, IP-Tools, cidr, ipv4, ipv6, network, subnet

## 简介

IPv4 and IPv6 Address/Network parsing utility classes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
