# helpforfitness/woocommerce-php-api-client

> 标签: api, woocommerce, wordpress

## 简介

PHP client for Woocommerce API 2.2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
