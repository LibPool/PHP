# odinshat/yii-clickatell-smscomponent

> 标签: clickatell, sms, yii

## 简介

Yii component for interfacing with the Clickatell SMS HTTP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
