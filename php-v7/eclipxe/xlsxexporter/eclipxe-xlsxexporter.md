# eclipxe/xlsxexporter

> 标签: excel, office-open-xml, xlsx

## 简介

PHP Office Open XML Spreadsheet (xlsx) exporter

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
