# nyco/wp-open-data-transients

> 标签: data, open data, transients, wordpress

## 简介

Interface for saving Open Data endpoints as WordPress Transients.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
