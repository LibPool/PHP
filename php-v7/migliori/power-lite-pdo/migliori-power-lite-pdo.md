# migliori/power-lite-pdo

> 标签: database, pdo, wrapper

## 简介

PowerLitePdo is a PDO wrapper that provides a simple and powerful way to interact with a database.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
