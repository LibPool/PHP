# atmonshi/sender

> 标签: Sender, laravel, provider, sms

## 简介

an sms gate to send messages form a provider like newtags.com.sa.com.sa and mobily.ws

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
