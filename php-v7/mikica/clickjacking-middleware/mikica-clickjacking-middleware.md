# mikica/clickjacking-middleware

> 标签: X-Frame-Options, clickjacking, middleware, psr-7

## 简介

Provides clickjacking protection via the X-Frame-Options header.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
