# fotomerchant/paypal-rest-bundle

> 标签: payments, paypal, rest

## 简介

Allows you to interact with the PayPal REST API via the PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
