# jstewmc/url

> 标签: locator, php, resource, uniform, url

## 简介

A class for creating, parsing, and manipulating Uniform Resource Locators (URL)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
