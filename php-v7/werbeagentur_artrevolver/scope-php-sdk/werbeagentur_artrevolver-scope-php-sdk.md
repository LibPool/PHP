# werbeagentur_artrevolver/scope-php-sdk

> 标签: ATS, SCOPE-Recruiting, artrevolver, heyrecruit, recruiting, scope

## 简介

PHP SDK for implementing Heyrecruit with rest api.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
