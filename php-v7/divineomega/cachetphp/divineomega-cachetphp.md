# divineomega/cachetphp

> 标签: JS, api, cachet, javascript, library, page, status

## 简介

cachet.php is a PHP client library for the Cachet status page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
