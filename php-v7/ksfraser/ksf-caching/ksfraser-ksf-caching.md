# ksfraser/ksf-caching

> 标签: PHP

## 简介

Multi-backend caching abstraction layer supporting Redis, Database, File, and Memory backends with TTL and statistics

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
