# ksfraser/ksf_gpg

> 标签: PGP, encryption, frontaccounting, gnupg, gpg, keyserver, openpgp, signing

## 简介

GPG business logic library providing key management, signing, encryption, and keyserver operations

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
