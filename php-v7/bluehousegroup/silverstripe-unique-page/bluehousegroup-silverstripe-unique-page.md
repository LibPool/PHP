# bluehousegroup/silverstripe-unique-page

> 标签: page, silverstripe, sitetree

## 简介

Prevents admin users from creating more than one instance of a page class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
