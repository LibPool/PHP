# promptpay/promptpaymentsapi

> 标签: Prompt Payments API, api, sdk

## 简介

All requests to the Prompt Pay API are sent via the HTTP POST method to one of our API endpoint URLs.  HTTP Request Method : POST API Endpoint : http://promptpayments.io/payment/process JSON Content-Type : application/json All calls to the Prompt Pay API require merchant authentication and merchant access key. Sign up for a account to quickly get started. Sandbox payment can be also initiated while merchant set the service mode as test in merchant dashboard. It will be live while the mode will be set as active mode.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
