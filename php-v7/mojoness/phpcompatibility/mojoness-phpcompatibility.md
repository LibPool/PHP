# mojoness/phpcompatibility

> 标签: compatibility, phpcs, standards

## 简介

This is a set of sniffs for PHP_CodeSniffer that checks for PHP version compatibility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
