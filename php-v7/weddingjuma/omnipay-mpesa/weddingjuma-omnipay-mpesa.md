# weddingjuma/omnipay-mpesa

> 标签: gateway, merchant, mpesa, omnipay, pay, payment

## 简介

Mpesa driver for the Deadan payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
