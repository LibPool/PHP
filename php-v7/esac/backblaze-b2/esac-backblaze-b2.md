# esac/backblaze-b2

> 标签: b2, backblaze, backblaze-api, backblaze-b2, backup, cloud, filesystem, storage

## 简介

An SDK for working with B2 cloud storage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
