> 标签: api, application, backorder, cert, connector, dns, domain, hexonet, isp, ispapi, premium, preregistration, registration, sdk, ssl

## 简介

API connector library for the insanely fast HEXONET backend API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
