# sgalinski/sgc-core

> 标签: browsersync, cli, frontend-build, image-optimization, javascript, release-automation, sass, sgalinski, sgc, typo3

## 简介

SGC Core by sgalinski: CLI task runner and frontend build toolchain for TYPO3 projects with Sass/JavaScript pipelines, BrowserSync workflows, linting, image optimization, inline SVG generation, and release automation support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
