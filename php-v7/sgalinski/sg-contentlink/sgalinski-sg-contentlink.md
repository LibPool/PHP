# sgalinski/sg-contentlink

> 标签: PHP

## 简介

sgalinski Contentlink - Possibility to set a link around a whole content element. (Include static template)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
