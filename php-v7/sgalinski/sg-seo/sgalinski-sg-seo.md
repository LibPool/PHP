# sgalinski/sg-seo

> 标签: PHP

## 简介

SEO Toolkit: Sitemap & Meta - Advanced TYPO3 SEO toolkit with smart XML sitemap filtering, static generation, image optimization, and meta controls.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
