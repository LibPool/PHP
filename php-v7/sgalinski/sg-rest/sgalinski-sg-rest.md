# sgalinski/sg-rest

> 标签: PHP

## 简介

DEPRECATED: Legacy REST API base for TYPO3. Migrate to sgalinski/sg-apicore as the successor for modern API routing, authentication, and endpoint registration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
