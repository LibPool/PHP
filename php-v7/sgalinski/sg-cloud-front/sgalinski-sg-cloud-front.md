# sgalinski/sg-cloud-front

> 标签: PHP

## 简介

sgalinski Amazon CloudFront - Implements the Amazon CloudFront Service for TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
