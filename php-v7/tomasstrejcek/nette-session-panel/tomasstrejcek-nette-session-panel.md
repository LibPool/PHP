# tomasstrejcek/nette-session-panel

> 标签: nette, panel, session

## 简介

Nette DebugBar panel, that allows you inspect your sessions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
