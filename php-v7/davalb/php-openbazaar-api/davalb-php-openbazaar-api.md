# davalb/php-openbazaar-api

> 标签: api, openbazaar

## 简介

The OpenBazaar API makes it easy for developers to communicate with the OpenBazaar marketplace

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
