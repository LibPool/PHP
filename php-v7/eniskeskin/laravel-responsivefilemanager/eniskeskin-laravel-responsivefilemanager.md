# eniskeskin/laravel-responsivefilemanager

> 标签: filemanager, laravel, responsive

## 简介

Integrate Alberto Peripolli's Responsive File Manager with Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
