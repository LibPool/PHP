# macfly/yii2-pinpoint-plugin

> 标签: pinpoint, yii2

## 简介

Pinpoint plugin to instrument Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
