# macfly/yii2-authclient-adfs

> 标签: adfs, authclient, oauth2, yii2

## 简介

Adfs Oauth2 client for yii2-authclient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
