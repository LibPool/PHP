# macfly/yii2-authclient-oauth2

> 标签: authclient, oauth2, oauth2-server-php, yii2

## 简介

OAuth2 client for yii2-oauth2-server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
