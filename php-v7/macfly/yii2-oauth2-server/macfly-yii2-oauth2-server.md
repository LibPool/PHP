# macfly/yii2-oauth2-server

> 标签: extension, module, oauth, oauth2, yii

## 简介

Wrapper for filsh yii2-oauth2-server provide authorize, token, user controller

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
