# cdi/cdiuser

> 标签: doctrine, doctrine-orm-module, zf3, zfc-user

## 简介

Modulo de usuarios para usar junto a ZfcUser, rbac y Doctrine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
