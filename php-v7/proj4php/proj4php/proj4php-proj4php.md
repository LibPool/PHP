# proj4php/proj4php

> 标签: coordinates, geographic, proj4, proj4js

## 简介

A PHP-Class for geographic coordinates transformation using proj4 definitions, thanks to a translation from Proj4JS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
