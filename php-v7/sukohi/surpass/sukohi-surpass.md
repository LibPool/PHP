# sukohi/surpass

> 标签: PHP

## 简介

A PHP package mainly developed for Laravel to manage uploading images using Ajax and displaying thumbnail.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
