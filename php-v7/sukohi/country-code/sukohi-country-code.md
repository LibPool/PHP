# sukohi/country-code

> 标签: PHP

## 简介

Country codes based on iso 3166-1 like country name, alpha-2 code, alpha-3 code or numeric code for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
