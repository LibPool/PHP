# sukohi/laravel-js-helper

> 标签: Sukohi, js-helper, laravel

## 简介

A Laravel package that provides helper functions for JavaScript like route(), dd() and constant().

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
