# maximo-perez-villalba/tool-uuid

> 标签: PHP

## 简介

UUID (Universally Unique IDentifier). Herramienta para generar y validar claves irrepetibles de 8 caracteres.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
