# umer936/cake-p-h-p-tightrope

> 标签: PHP

## 简介

If you make a CakePHP error, it deletes the folder the error was generated from. Don't make a mistake.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
