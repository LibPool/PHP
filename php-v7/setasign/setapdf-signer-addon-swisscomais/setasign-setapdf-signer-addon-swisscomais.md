# setasign/setapdf-signer-addon-swisscomais

> 标签: PHP

## 简介

A signature module and batch processor for the SetaPDF-Signer component wrapping the Swisscom AIS webservice.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
