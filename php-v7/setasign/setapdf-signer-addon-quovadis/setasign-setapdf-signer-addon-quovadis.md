# setasign/setapdf-signer-addon-quovadis

> 标签: PHP

## 简介

A SetaPDF-Signer component signature module for the QuoVadis Signing and Validation Service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
