# setasign/setafpdf

> 标签: SetaFPDF, SetaPDF, fpdf, pdf

## 简介

SetaFPDF is a clone of FPDF with an almost compatible interface while using SetaPDF-Core internally for the PDF generation.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
