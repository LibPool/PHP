# setasign/setapdf-signer-addon-pkcs11

> 标签: PHP

## 简介

A SetaPDF-Signer component signature add-on for accessing keys through the PKCS11 interface.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
