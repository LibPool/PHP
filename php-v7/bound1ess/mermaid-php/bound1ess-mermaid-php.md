# bound1ess/mermaid-php

> 标签: PHP

## 简介

PHP adapter for the Mermaid project by @knsv (github.com/knsv/mermaid).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
