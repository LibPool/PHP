# gollumsf/mjml-binary

> 标签: Simple, gollumsf, hash, token, url

## 简介

MJML compiled binary in composer for php without nodejs for MjmlBundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
