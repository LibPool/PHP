# studio98/basic-shopify-api

> 标签: api, graphql, rest, shopify

## 简介

A basic Shopify API wrapper with REST and GraphQL support, powered by Guzzle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
