# reflex/query-filters

> 标签: PHP

## 简介

Add query filters to Eloquent Models, copied from https://github.com/laracasts/Dedicated-Query-String-Filtering

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
