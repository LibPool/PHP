# kunicmarko/form-annotation-bundle

> 标签: Forms, annotations, symfony, symfony-forms

## 简介

This is a Symfony Bundle that adds helper annotations for symfony forms.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
