# kunicmarko/sonata-annotation-bundle

> 标签: annotations, sonata, sonata-admin, symfony

## 简介

Symfony Bundle that adds annotations for Sonata Admin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
