# miinto/laravel-mssql

> 标签: laravel, mssql

## 简介

Laravel extension which allows to use MS SQL specific column types like 'datetime2', 'real' and 'uniqueidentifier'.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
