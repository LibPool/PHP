# psvneo/hartmann-os-shoe-finder-sdk

> 标签: PHP

## 简介

This library provides an easy API to communicate with the hartmann-os-shoe-finder-api.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
