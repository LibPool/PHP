# psvneo/qa-toolset-t3-configs

> 标签: config, qa, tool, typo3

## 简介

This package contains only config files for the package `psvneo/qa-toolset-t3`.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
