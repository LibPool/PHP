# psvneo/typo3-extension-cb_kesearch_indexer

> 标签: extension, indexer, ke_search, typo3

## 简介

Extends ke_search with the possibility to index 'Content Blocks'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
