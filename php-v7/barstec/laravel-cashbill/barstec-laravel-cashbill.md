# barstec/laravel-cashbill

> 标签: api, cashbill, framework, laravel, package, payments

## 简介

Package for easily integrating cashbill payments with Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
