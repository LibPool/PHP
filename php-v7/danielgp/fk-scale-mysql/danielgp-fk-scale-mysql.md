# danielgp/fk-scale-mysql

> 标签: PHP

## 简介

Scaling up the column type for fields used in foreign keys in MySQL can be a daunting activity, now this will be no more!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
