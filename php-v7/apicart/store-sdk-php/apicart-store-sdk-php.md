# apicart/store-sdk-php

> 标签: api, apicart, ecommerce, php, sdk, store-api

## 简介

Apicart Store API SDK in PHP implementing comunications via HTTP client.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
