# carloswph/wp-serializer-query

> 标签: csv, json, symfony, wordpress, wp, wp symfony, wp_query, xml

## 简介

Uses Symfony Serializer to generate JSON, CSV or XML output from WP_Query.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
