# carloswph/ibgecode-php

> 标签: brasil, brazil, brazilian, ibge

## 简介

Simple library to retrieve Brazilian city and respective state from the IBGE code.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
