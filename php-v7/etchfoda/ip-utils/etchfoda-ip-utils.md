# etchfoda/ip-utils

> 标签: IP, ipv4, ipv6, matching, subnet

## 简介

small library to deal with IPv4 & IPv6 addresses and subnets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
