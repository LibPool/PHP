# hfrahmann/opauth

> 标签: Authentication, OPAuth, facebook, flow, google, login, twitter, typo3, typo3flow

## 简介

This is a package to use Opauth with your TYPO3 Flow project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
