# rflex-spa/analytics-laravel

> 标签: PHP

## 简介

Server-side product analytics (PostHog) for rFlex Laravel systems: events, identify/group, feature flags.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
