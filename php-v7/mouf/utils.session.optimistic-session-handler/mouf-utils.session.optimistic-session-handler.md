# mouf/utils.session.optimistic-session-handler

> 标签: handler, session

## 简介

Session handler that releases session lock quickly. Useful for multiple ajax calls on the same page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
