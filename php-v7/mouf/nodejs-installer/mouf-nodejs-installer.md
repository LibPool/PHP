# mouf/nodejs-installer

> 标签: installer, nodejs, npm

## 简介

An installer package that let's you install NodeJS and NPM as a Composer dependency.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
