# mouf/utils.common.doctrine-cache-wrapper

> 标签: annotations, doctrine, mouf, wrapper

## 简介

Provide an install script for a Doctrine's Cache in Mouf Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
