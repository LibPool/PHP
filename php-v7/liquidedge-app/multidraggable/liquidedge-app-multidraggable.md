# liquidedge-app/multidraggable

> 标签: PHP

## 简介

A jQueryUI plugin enabling the selection, drag and drop of multiple ui-draggable elements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
