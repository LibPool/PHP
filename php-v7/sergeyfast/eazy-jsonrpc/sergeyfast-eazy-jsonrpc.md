# sergeyfast/eazy-jsonrpc

> 标签: json rpc 2, json-rpc, jsonrpc, jsonrpc2, rpc2, smd

## 简介

PHP JSON-RPC 2.0 Server/Client Implementation with SMD & Swagger support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
