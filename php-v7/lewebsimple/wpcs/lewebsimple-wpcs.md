# lewebsimple/wpcs

> 标签: phpcs, standards, wordpress

## 简介

PHP_CodeSniffer rules (sniffs) to enforce WordPress coding conventions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
