# toanld/laravel-model

> 标签: laravel, laravel lumen connect random database with weight, lumen, master slaves connection laravel, model, multi connection laravel, multi connection lumen

## 简介

Laravel model support multi connection format master - slaves. Connect random a slave with weight

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
