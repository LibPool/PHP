# unbxd/magento2-search-js

> 标签: PHP

## 简介

The Magento 2 module, which provides possibility enable unbxd search, autosuggest , analytics and browse features

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
