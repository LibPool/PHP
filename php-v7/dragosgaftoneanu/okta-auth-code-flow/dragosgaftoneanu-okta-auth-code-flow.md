# dragosgaftoneanu/okta-auth-code-flow

> 标签: PHP

## 简介

Simple library to do authorization code flow and retrieve details also from /userinfo and /introspect.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
