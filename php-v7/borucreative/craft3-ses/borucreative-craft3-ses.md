# borucreative/craft3-ses

> 标签: Amazon SES, craft-plugin, craftcms

## 简介

A CraftCMS v3 Mail Transport strategy using Amazon SES

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
