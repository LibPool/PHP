# simplesquid/vend-sdk

> 标签: point-of-sale, sdk, simplesquid, vend, vend-sdk

## 简介

An unoffical PHP SDK for Vend POS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
