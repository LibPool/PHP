# rwandabuild/murugo_api_auth

> 标签: PHP

## 简介

Package that will use Murugo auth to all 3rd party laravel projects with only API structure

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
