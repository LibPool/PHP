# lubna/custom-error-bundle

> 标签: PHP

## 简介

Symfony bundle to customize and override default error pages (404, 403, 500, 401) with Twig templates and error controller support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
