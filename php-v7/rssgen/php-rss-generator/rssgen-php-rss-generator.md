# rssgen/php-rss-generator

## 简介

Simple RSS generator library for PHP 5.5 or later. clone from Bhaktaraz Bhatta ttps://github.com/bhaktaraz/php-rss-generator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
