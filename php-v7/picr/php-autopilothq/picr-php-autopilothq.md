# picr/php-autopilothq

> 标签: autopilot, autopilothq, picr

## 简介

PHP wrapper for interacting with the AutopilotHQ API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
