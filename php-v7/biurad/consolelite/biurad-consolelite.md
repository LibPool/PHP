# biurad/consolelite

> 标签: PHP7, autoloader, biurad, biurad-toolbox, composer-lite, php5

## 简介

This is the light weight version of Symfony Console

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
