# alexsoft/webserver-config-generator

> 标签: apache, config, generator, laravel, nginx

## 简介

Package for generating webserver configuration file for your Laravel app

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
