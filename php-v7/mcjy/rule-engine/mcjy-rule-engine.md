# mcjy/rule-engine

> 标签: PHP

## 简介

A flexible and extensible PHP promotion rule engine for shopping cart scenarios — supports discounts, tiered offers, member pricing, and more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
