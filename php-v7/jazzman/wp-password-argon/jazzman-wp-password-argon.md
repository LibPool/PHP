# jazzman/wp-password-argon

> 标签: PHP

## 简介

Securely store WordPress user passwords in database with Argon2i hashing and SHA-512 HMAC using PHP's native functions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
