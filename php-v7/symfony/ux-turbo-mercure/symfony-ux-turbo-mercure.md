# symfony/ux-turbo-mercure

> 标签: hotwire, mercure, symfony-ux, turbo

## 简介

Mercure bridge for Symfony UX Turbo

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
