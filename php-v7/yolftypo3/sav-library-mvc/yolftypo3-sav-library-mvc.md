# yolftypo3/sav-library-mvc

> 标签: Extension generator, SAV Library, TYPO3 CMS, kickstarter

## 简介

Library based on fluid and extbase for extensions generated with the SAV Library Kickstarter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
