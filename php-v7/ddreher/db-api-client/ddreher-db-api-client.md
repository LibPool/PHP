# ddreher/db-api-client

> 标签: api, bahn, deutsche bahn, open data, stations, timetable, train

## 简介

A php client library for the deutsche bahn timetable API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
