# steadfastcollective/md5-twig-filter

> 标签: Craft, cms, craft-plugin, craftcms, md5 twig filter

## 简介

A filter for twig to hash a string with MD5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
