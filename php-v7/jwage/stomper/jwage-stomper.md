# jwage/stomper

> 标签: hornetq, rabbitmq, stomp

## 简介

PHP Stomp library that provides additional functionality on top of the default Stomp API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
