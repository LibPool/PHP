# tlangelani/sybase-database

> 标签: database, sap, sap ase, sybase, sybase ase

## 简介

A simple database package for Sybase/SAP ASE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
