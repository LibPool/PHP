# bencoderus/min-auth

> 标签: Authentication, api, auth, bencoderus, client, laravel, min-auth, php

## 简介

This package serves as a token based client authentication system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
