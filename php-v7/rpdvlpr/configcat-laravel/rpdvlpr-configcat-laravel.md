# rpdvlpr/configcat-laravel

> 标签: configcat, configcat laravel, feature flag, feature toggle, user targeting

## 简介

Laravel plugin for the ConfigCat php-sdk

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
