# sintret/yii2-diesel

> 标签: AdminLTE, dynagrid, gii, import export excel, personalize, sintret, yii2

## 简介

Yii2 Generator extension for Gii plugin with adminlte and base on dynagrid. parsing excel, access control with easyly

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
