# xenji/prowlphp

> 标签: api, webservices

## 简介

PHP library to access the webserives of Prowl (http://www.prowlapp.com/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/xenji/ProwlPHP.git
