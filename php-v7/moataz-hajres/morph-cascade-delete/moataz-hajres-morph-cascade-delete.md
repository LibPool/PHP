# moataz-hajres/morph-cascade-delete

> 标签: delete cascade, laravel, morph, polymorphic

## 简介

A simple laravel package to enable cascade deleting on polymorphic relations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
