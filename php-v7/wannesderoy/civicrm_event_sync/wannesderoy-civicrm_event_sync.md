# wannesderoy/civicrm_event_sync

> 标签: Drupal 8, civicrm

## 简介

Enables a full sync between the CivCRM Event entity and a Drupal node type event.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
