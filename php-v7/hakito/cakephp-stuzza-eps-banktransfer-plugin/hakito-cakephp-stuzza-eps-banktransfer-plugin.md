# hakito/cakephp-stuzza-eps-banktransfer-plugin

> 标签: bank transfer, cakephp, eps, payments, stuzza

## 简介

CakePhp Plugin for EPS bank transfer payments

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
