# hakito/cakephp-paypal-rest-plugin

> 标签: cakephp, payment, paypal, rest

## 简介

PayPal plugin for CakePHP using the REST api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
