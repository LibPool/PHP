# emarref/xdebug-bundle

> 标签: PHP

## 简介

Simplify the use of a debugging tool in your IDE by automatically setting/removing cookies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
