# sevenecks/tableify

> 标签: array to table, cli, command line, console, formatting, logging, php, pretty printer, shell, string, table printer

## 简介

Transform a multidimensional array into a pretty table that can be echoed to the screen or logged to a file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
