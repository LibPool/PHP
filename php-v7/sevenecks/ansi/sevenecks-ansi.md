# sevenecks/ansi

> 标签: ansi, cli, color, colors, console, shell

## 简介

This package offers an API to colorize strings of text with various ANSI colors using static methods.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
