# kartik-v/yii2-number

> 标签: currency, extension, format, mask, number, number control, widget, yii2

## 简介

Number control and format mask input for Yii2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
