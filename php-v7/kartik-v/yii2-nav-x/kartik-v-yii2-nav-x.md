# kartik-v/yii2-nav-x

> 标签: Context, click, extension, menu, mouse, widget, yii2

## 简介

An extended bootstrap Nav widget for Yii 2 with submenu drilldown.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
