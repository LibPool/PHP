# kartik-v/yii2-sortable-input

> 标签: bootstrap, extension, input, jquery, range, sortable, widget, yii2

## 简介

Sortable input widget based on yii2-sortable extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
