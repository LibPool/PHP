# ngawidev/nethttp

> 标签: api, async, client, curl, http, middleware, promise, proxy, request

## 简介

Lightweight PHP HTTP client with fluent interface, cURL-powered, async/await support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
