# sabir/chatgpt

> 标签: ChatGpt, GPT-3, api, chatbot, gpt, gpt3, laravel

## 简介

A Laravel package for interacting with ChatGPT APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
