# owk/yii2-circular-navigation

> 标签: circular nav, circular navigation, extension, menu, navigation, widget, yii2

## 简介

Circular navigation widget for Yii 2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
