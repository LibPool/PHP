# wieni/wmscaffold

> 标签: PHP

## 简介

Provides Drupal services and Drush 9 commands for easy creation of fields & entity types, code style fixing, model & controller generating and more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
