# opb/slim-basic-auth

> 标签: auth, http auth, middleware, slim

## 简介

HTTP Basic Auth Middleware for the Slim PHP Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
