# privacyidea/simplesamlphp-module-privacyidea

> 标签: PHP

## 简介

Add multi-factor authentication to simpleSAMLphp. The second factors are managed in privacyIDEA.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
