# jampire/toc-markdown-extra

> 标签: PHP Markdown Extra, TOC, extra, markdown, table of contents

## 简介

Adds Table of Contents capability to PHP Markdown Extra package

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
