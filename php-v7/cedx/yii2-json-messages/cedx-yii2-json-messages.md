# cedx/yii2-json-messages

> 标签: catalog, i18n, internationalization, json, locale, messages, translation, yaml, yii2

## 简介

JSON and YAML message sources for the Yii Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
