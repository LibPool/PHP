# acelaya/zf2-acqrcode

> 标签: endroid, module, php, qr, zf2

## 简介

QR Code generation module for Zend Framework 2 based on Endroid QR code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
