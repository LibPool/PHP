# acelaya/doctrine-enum-type

> 标签: doctrine, enum, type

## 简介

A custom Doctrine type that maps column values to enum objects using myclabs/php-enum

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
