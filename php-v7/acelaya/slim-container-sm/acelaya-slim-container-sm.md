# acelaya/slim-container-sm

> 标签: Zend Framework, dependency injection, dic, slim, zf2

## 简介

A Slim framework container wrapping a ZF2 ServiceManager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
