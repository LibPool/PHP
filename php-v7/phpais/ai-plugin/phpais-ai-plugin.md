# phpais/ai-plugin

> 标签: Volcano, ai, deepseek, laravel, php, qianwen, thinkphp, wenxin

## 简介

PHP AI 插件，整合文心、千问、火山、deepseek、混元、智谱清言、月之暗面等AI模型接口，支持ThinkPHP和Laravel框架

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
