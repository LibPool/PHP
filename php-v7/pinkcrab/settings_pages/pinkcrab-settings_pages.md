# pinkcrab/settings_pages

> 标签: PHP

## 简介

PinkCrab frameworks settings page api wrapper. Requires the PinkCrab framework and PinkCrab Form_Fields libraries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
