# pinkcrab/admin-pages

> 标签: PHP

## 简介

The PinkCrab framework package for creating admin pages/groups using inheritance very easyly from plugins and themes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
