# elgentos/module-baseurlpath

> 标签: PHP

## 简介

Allow Magento config to have a base url path instead of root without moving Magento 2 into a subdirectory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
