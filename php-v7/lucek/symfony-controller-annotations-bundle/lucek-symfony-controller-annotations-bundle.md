# lucek/symfony-controller-annotations-bundle

> 标签: PHP

## 简介

Symfony Controller Annotation reader component that gives you ability to create & read your own created (controller-method related) annotations for easier usage.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
