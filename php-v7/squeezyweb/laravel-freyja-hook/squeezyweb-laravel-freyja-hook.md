# squeezyweb/laravel-freyja-hook

> 标签: PHP

## 简介

A wrapper around Freyja Hook for Laravel. Create arbitrary hooks to execute actions or filter data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
