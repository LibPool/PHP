# batkor/editorjs_dependencies

> 标签: dependencies, drupal, editorjs

## 简介

Provides dependencies libraries for 'editorjs' module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
