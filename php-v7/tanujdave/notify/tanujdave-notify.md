# tanujdave/notify

> 标签: api, messaging, notify, transition

## 简介

Notify is messaging service for Omega2. which responsible for sending message to Alpha or AWS sns based on priority.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
