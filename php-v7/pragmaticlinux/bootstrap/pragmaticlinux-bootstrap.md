# pragmaticlinux/bootstrap

> 标签: css, framework, front-end, html

## 简介

Bootstrap framework for frontend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.pragmaticlinux.org
- 源码仓库：https://github.com/PragmaticLinux/bootstrap.git
- Packagist 页面：https://packagist.org/packages/pragmaticlinux%2Fbootstrap

## 历史版本号

- 当前版本：v3.3.4

## 获取地址

- Composer 安装：`composer require pragmaticlinux/bootstrap`
- Packagist 仓库：https://repo.packagist.org/p2/pragmaticlinux/bootstrap.json
- 许可证：MIT
- PHP 要求：>=5.3.0
