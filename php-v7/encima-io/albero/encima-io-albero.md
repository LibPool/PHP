# encima-io/albero

> 标签: albero, baum, eloquent, laravel, nested set, php

## 简介

Albero is an implementation of the Nested Set pattern for Laravels eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
