# maritechpro/datetimeable-propel-behavior

> 标签: PHP

## 简介

The extension of propel behavior timestampable to allow DATETIME type of columns

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
