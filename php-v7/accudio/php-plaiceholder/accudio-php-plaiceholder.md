# accudio/php-plaiceholder

> 标签: PHP

## 简介

PHP implementation of Plaiceholder - CSS, SVG, Base64 and Blurhash image placeholders.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
