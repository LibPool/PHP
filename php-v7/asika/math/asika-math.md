# asika/math

> 标签: Arbitrary-precision, BigInteger, BigRational, arithmetic, bigdecimal, brick, math

## 简介

Arbitrary-precision arithmetic library for PHP 5.3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
