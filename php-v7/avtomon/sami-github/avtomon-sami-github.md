# avtomon/sami-github

> 标签: github, sami

## 简介

A Sami theme for GitHub Markdown formatted documentation. (this is a fork of phine/sami-github)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
