# tanjemark/laravel-remote

> 标签: artisan, commands, database, db-sync, laravel, remote, ssh, sync

## 简介

Execute commands remotely using SSH.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
