# skyraptor/densitywaves-php

> 标签: density, density wave theory, php, theory, wave, waves

## 简介

DensityWaves PHP - Generate star positions based on density wave theory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
