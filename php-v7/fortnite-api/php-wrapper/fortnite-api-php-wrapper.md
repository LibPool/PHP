# fortnite-api/php-wrapper

> 标签: Fortnite, api, client, fortnite-api, fortnite-api.com, framework, michel-pi, wrapper

## 简介

PHP wrapper for https://fortnite-api.com

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
