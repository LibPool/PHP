# laravelfy/parsedown-extra-plugin

> 标签: markdown, markdown extra, parsedown, parser

## 简介

Configurable Markdown to HTML converter with Parsedown Extra.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
