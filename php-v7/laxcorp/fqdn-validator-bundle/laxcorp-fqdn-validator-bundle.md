# laxcorp/fqdn-validator-bundle

> 标签: Fully Qualified Domain Name validator

## 简介

For Symfony's validator Fully Qualified Domain Name.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
