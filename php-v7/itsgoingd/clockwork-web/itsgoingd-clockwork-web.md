# itsgoingd/clockwork-web

> 标签: debugging, logging, profiling

## 简介

Embeddable webapp version of Clockwork, a Chrome extension for PHP development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
