# webiny/login

> 标签: Authentication, authorization, login

## 简介

Login application that uses Webiny Framework Security component.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/Webiny/Login.git
- Packagist 页面：https://packagist.org/packages/webiny%2Flogin
