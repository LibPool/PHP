# webiny/htpl

> 标签: template engine

## 简介

PHP template engine based on html tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.webiny.com/
- 源码仓库：https://github.com/Webiny/Htpl.git
- Packagist 页面：https://packagist.org/packages/webiny%2Fhtpl
