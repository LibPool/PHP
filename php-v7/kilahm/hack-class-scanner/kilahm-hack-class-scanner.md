# kilahm/hack-class-scanner

> 标签: ClassScanner, autoload, hack, hhvm, scan

## 简介

Recursively scan a directory for hack classes and/or interfaces

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
