# macedigital/silex-jms-serializer

> 标签: jms, provider, serializer, silex

## 简介

Use JMS Serializer for (de-)serializing object graphs in silex applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
