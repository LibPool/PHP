# mr-luke/searcher

> 标签: eloquent, laravel, rest, searching

## 简介

Laravel 5 package for REST Url-based quering, filtering & sorting Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
