# semhoun/slim-mailer

> 标签: email, emails, mailer, slim, slim-framework, slim-mail, slim-mailer, slim4, swiftmailer

## 简介

Email support for the Slim 4 Framework using Twig and Swift Mailer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
