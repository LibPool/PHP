# coldtrick/fontawesome

> 标签: elgg, icon, plugin, theme

## 简介

Gives Elgg site admins the ability to configure / upload specific versions of Font Awesome icon packs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
