# coldtrick/saml_sso

> 标签: SSO, elgg, plugin

## 简介

Provides SAML 2.0 based Single Sign On features for Elgg based on the OneLogin SAML library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
