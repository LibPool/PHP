# coldtrick/friend_request

> 标签: elgg, friends, plugin

## 简介

Let users confirm friend requests. Make friends like on Facebook or LinkedIn

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
