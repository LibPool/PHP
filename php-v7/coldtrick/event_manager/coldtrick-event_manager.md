# coldtrick/event_manager

> 标签: elgg, events, plugin

## 简介

Manage events, from a simple appointment to a multi day event with day programs and subscriptions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
