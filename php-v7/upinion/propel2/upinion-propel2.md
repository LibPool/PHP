# upinion/propel2

> 标签: Active Record, orm, persistence

## 简介

Propel2 is an open-source Object-Relational Mapping (ORM) for PHP 5.5 and up.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/Upinion/Propel2.git
