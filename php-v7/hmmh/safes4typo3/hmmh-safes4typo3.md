# hmmh/safes4typo3

> 标签: Skeleton, decoupled, fluid, front-end, frontend, scaffolding, server, stage, staging, stand-alone, standalone, typo3

## 简介

Front-end stage server for developing stand-alone fluid templates without having to use TYPO3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
