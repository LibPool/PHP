# rodzewicz/tr-xml-sec-libs

> 标签: PHP

## 简介

Based on robrichards/xmlseclibs library to Sign SOAP XML requests modified by adding the SecurityTokenReference

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
