# pitana/pitana.js

> 标签: framework, scalable, webcomponents

## 简介

pitana.js, framework for developing large scale modular JavaScript applications using Custom Elements

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
