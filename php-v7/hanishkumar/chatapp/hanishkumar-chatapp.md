# hanishkumar/chatapp

> 标签: Chat Application, Laravel Chat, chat

## 简介

ChatApp is a PHP library designed to make it easy to consume and produce chat application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
