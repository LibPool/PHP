# dada-amater/dependentselectbox

> 标签: nette, selectbox

## 简介

Selectbox whose options are depended on another selectbox. Library for Nette Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
