> 标签: Laravel Breeze, Laravel multiauth, api auth, auth for api, bitfumes, breezer., jwt auth, sanctum api

## 简介

Full API authentication in laravel with social login

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
