# amattu2/golo365-wrapper

> 标签: PHP

## 简介

A Golo365.com and X431.com API wrapper class for interacting with their hidden diagnostic APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
