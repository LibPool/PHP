# eye4web/eye4web-zfc-user-force-logout

> 标签: ZendFramework, eye4web, module, zfcuser

## 简介

Adds the functionality to force a user to logout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
