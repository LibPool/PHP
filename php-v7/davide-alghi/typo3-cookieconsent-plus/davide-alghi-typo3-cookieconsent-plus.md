# davide-alghi/typo3-cookieconsent-plus

> 标签: consent, cookie, cookieconsent, gdpr, privacy, typo3

## 简介

Cookie Consent Plus adds some new features to Dirk Persky's Cookie Consent extension (dp_cookieconsent).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
