# eghojansu/shap

> 标签: php framework, shap, shap php, simple php, simple php framework

## 简介

Bootstrap for new Light Simple PHP Web Project that require bcosca/fatfree

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
