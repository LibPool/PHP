# camc/bugsnag-deploy

> 标签: PHP

## 简介

Simple package to provide a Laravel 5 artisan command to trigger deployment notifications to bugsnag

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
