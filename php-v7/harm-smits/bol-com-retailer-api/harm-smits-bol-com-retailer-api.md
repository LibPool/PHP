# harm-smits/bol-com-retailer-api

> 标签: Bol.com, api, bol, php

## 简介

A PHP Client for the BOL.com v5 API with async support and full object mapping

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
