# bopoda/robots-txt-parser

> 标签: google, parser, robots.txt, yandex

## 简介

PHP Class for parsing robots.txt files according to Google, Yandex specifications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
