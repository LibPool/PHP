# lnch/laravel-pjax

> 标签: laravel-pjax, lnch, pjax

## 简介

A Laravel Facade to create blocks of content that will reload on any links

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
