# gokure/http-client

> 标签: Guzzle, http, http-client, hyperf

## 简介

An expressive, minimal API around the Guzzle HTTP client for Hyperf.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
