# zanysoft/unicode-inpage-converter

> 标签: Unicode converter, Urdu Unicode, inpage, urdu

## 简介

Urdu Unicode to inPage and inPage to Urdu Unicode converter using php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
