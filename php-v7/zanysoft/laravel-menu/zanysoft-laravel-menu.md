# zanysoft/laravel-menu

> 标签: builder, laravel, menu, wordpress

## 简介

drag and drop menu generator like wordpress for laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/zanysoft/laravel-menu
- 源码仓库：https://github.com/zanysoft/laravel-menu.git

## 获取地址

- Packagist 仓库：https://repo.packagist.org/p2/zanysoft/laravel-menu.json
- PHP 要求：>=5.5.9
