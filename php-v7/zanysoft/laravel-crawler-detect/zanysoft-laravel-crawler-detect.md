# zanysoft/laravel-crawler-detect

> 标签: bot, crawler, crawler detect, crawler detector, crawlerdetect, detect, laravel, php crawler detect, spider, user-agent

## 简介

A Laravel package to detect web crawlers via the user agent

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
