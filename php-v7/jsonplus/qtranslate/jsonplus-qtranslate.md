# jsonplus/qtranslate

> 标签: PHP

## 简介

an JSONplus extension to provide i18n support to human-readable strings like markdown based upon the qTranslate syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
