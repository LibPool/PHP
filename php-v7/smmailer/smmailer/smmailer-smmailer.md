# smmailer/smmailer

> 标签: PHP

## 简介

A reusable PHP email package using PHPMailer, phpdotenv, and a black-gold HTML template.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
