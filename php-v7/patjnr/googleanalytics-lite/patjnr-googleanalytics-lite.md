# patjnr/googleanalytics-lite

> 标签: chitosystems, google, googleanalytics, googleanalytics-lite, silverstripe

## 简介

The Google Analytics Lite module consists of just 1 (one) component: The Google Logger injects the google analytics javascript snippet into your source code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
