# space48/magento2-cms-content-setup

> 标签: cms, install

## 简介

Provides tooling for initial CMS content creation by FE developer using install scripts and fixtures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
