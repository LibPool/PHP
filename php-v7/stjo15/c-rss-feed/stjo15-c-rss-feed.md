# stjo15/c-rss-feed

> 标签: feed, framework, micro, module, mvc, rss

## 简介

An RSS module to add RSS functionality to MVC frameworks. Developed for Anax-MVC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
