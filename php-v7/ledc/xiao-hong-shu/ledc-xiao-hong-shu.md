# ledc/xiao-hong-shu

> 标签: PHP

## 简介

小红书开放平台，自研商家SDK（授权API、公共API、素材API、商品API、库存API、订单API、售后API等）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
