# ledc/crmeb-poster

> 标签: PHP

## 简介

Crmeb单商户系统-海报插件，支持设计商品海报、用户海报、线下店铺海报、线下渠道海报、线下活动海报。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
