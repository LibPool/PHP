# torann/assets

> 标签: asset management, asset pipeline, assets, laravel, laravel4, pipeline

## 简介

Simple asset management for Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
