# torann/laravel-cloudsearch

> 标签: amazon cloudsearch, aws, cloudsearch, eloquent, laravel, search

## 简介

Index and search Laravel models on Amazon's CloudSearch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
