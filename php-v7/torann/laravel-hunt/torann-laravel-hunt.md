# torann/laravel-hunt

> 标签: elasticsearch, elasticsearch 5, eloquent, laravel, search, unified search

## 简介

Unified search for Laravel models using Elasticsearch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
