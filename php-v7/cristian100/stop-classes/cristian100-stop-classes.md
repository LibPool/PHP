# cristian100/stop-classes

> 标签: effect, javascript, jquery, timed

## 简介

This library adds timed stop classes like stop-500, stop-750, stop-1000 and stop-1250.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
