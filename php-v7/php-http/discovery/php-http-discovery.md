# php-http/discovery

> 标签: HTTP, adapter, client, discovery, factory, http, message, psr17, psr7, 自动发现

## 简介

Finds and installs PSR-7, PSR-17, PSR-18 and HTTPlug implementations

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
