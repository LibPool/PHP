# upassist/neos-schemaorg

> 标签: PHP

## 简介

Schema.org structured data (JSON-LD) for Neos CMS — Organization, LocalBusiness, Service, WebPage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
