# upassist/neos-llms

> 标签: PHP

## 简介

llms.txt generator for Neos CMS — AI discoverability via a site-wide mixin and per-page opt-out

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
