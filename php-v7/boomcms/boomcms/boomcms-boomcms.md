# boomcms/boomcms

> 标签: PHP

## 简介

BoomCMS is built on Laravel 5 and released under the MIT license. BoomCMS is designed to be easy to use for content editors and developers alike

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
