# xenon/nagad-api

> 标签: Bangladeshi payment gateway, api, nagad, nagad gateway, nagad payment gateway, nagad php api, nagad php library, nagad php sdk, nagad sdk, payment gateway

## 简介

This is Bangladeshi nagad payment gateway api development library for php. This library can be used easily as pacakge dependency in your php application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
