# freygeist-dev/php_xlsxwriter

> 标签: excel, library, php, xls, xlsx

## 简介

PHP Library to write XLSX files (freygeistDev fork)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
