# wwnorden/vehicles

> 标签: Fahrzeuge, silverstripe, vehicle, vehicles

## 简介

SilverStripe 4+ vehicles module for storing and archiving vehicles

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
