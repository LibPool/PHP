# daniel-spravtsev/yoomoney-sdk-php

> 标签: money, payment, php, sdk, yoomoney

## 简介

Yoomoney API SDK for PHP (forked from yandex.money sdk)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
