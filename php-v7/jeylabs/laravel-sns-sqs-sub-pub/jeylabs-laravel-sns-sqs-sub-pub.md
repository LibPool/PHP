# jeylabs/laravel-sns-sqs-sub-pub

> 标签: SNS, aws, event-driven, laravel, lumen, microservices, queue, sns publishing, sns subscription, sqs

## 简介

A simple Laravel service provider which adds a new queue connector to handle SNS subscription queues.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
