# jeylabs/laravel-dotenv-editor

> 标签: dotenv, dotenv-editor, laravel

## 简介

A package for editing the .env file in your Laravel root.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
