# jeylabs/wit

> 标签: laravel, laravel wit, wit, wit.ai

## 简介

PHP Library for Wit.ai API with Laravel 5.3 Support out of the box!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
