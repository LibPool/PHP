# native5/native5-sdk-services-php

> 标签: identity, jobs, messaging

## 简介

PHP Services SDK for invoking Native5 Hosted Services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
