# make-software/casper-php-sdk

> 标签: blockchain, casper, node, rpc, sdk

## 简介

PHP 7.4+ library for interacting with Casper blockchain node RPC API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
