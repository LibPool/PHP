# proxeuse/fortify-tabler

> 标签: fortify-ui, laravel, tabler.io

## 简介

A preset for FortifyUI based on the Tabler Bootstrap framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
