# govtnz/silverstripe-sqlexplorer

> 标签: silverstripe, sql

## 简介

A SilverStripe module to provide read-only access to a database for suitably privileged users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
