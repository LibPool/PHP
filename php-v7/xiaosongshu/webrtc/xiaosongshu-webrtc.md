# xiaosongshu/webrtc

> 标签: OBS, WebRTC, h264, opus, pull, push, sfu, srtp, whep, whip

## 简介

Dependency-free WebRTC protocol implemented in PHP, offering a native WebRTC service.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
