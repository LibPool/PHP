# olegpro/bitrix-sphinx

> 标签: bitrix, orm, sphinx

## 简介

Пакет добавляет в 1С-Битрикс возможность работать с индексами sphinx, через ORM D7

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
