# vbpupil/payment-card

> 标签: credit, debit, gift card

## 简介

A PaymentCard Object which supports card types such as Debit, Credit and Gift cards.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
