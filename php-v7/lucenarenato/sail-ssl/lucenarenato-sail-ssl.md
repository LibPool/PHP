# lucenarenato/sail-ssl

> 标签: docker, laravel, nginx, sail, ssl

## 简介

Laravel 5,6,7 e php7.2 - Laravel Sail plugin to enable SSL (HTTPS) connection with Nginx.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
