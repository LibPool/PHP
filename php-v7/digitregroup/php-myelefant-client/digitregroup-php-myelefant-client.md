# digitregroup/php-myelefant-client

> 标签: PHP

## 简介

myElefant PHP Client - myElefant is able to send SMS, Facebook Messenger, Push, Viber, Wechat, RCS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
