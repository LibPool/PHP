# jigal/t3adminer

> 标签: adminer, database, dev, mariadb, mysql, phpmyadmin, postgresq, sqlite, typo3

## 简介

Adminer as BE module to work with the database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
