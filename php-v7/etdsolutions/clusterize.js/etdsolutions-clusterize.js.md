# etdsolutions/clusterize.js

> 标签: cluster, grid, large, list, scroll, table

## 简介

Tiny vanilla JS plugin to display large data sets easily

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
