# etdsolutions/highcharts

> 标签: PHP

## 简介

Shim repository for Highcharts JS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.highcharts.com
- 源码仓库：https://github.com/etd-framework/highcharts.git
- Packagist 页面：https://packagist.org/packages/etdsolutions%2Fhighcharts

## 历史版本号

- 当前版本：4.0.4

- 4.0.4

## 获取地址

- Composer 安装：`composer require etdsolutions/highcharts`
- Packagist 仓库：https://repo.packagist.org/p2/etdsolutions/highcharts.json
