# mhaendler/tp-minify

> 标签: asset, laminas, minify, obfuscation

## 简介

Laminas module which uses the Steve (mrclay) Clay's Minify library for styles and scripts obfuscation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
