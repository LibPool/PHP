# jasir/component-tree-panel

> 标签: component, debugging, nette, presenter

## 简介

Debug panel for Nette Framework. Displays presenter and components hiearchy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
