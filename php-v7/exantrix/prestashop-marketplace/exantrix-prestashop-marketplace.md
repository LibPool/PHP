# exantrix/prestashop-marketplace

> 标签: 3d-printing, DTF, exantrix, marketplace, module, prestashop

## 简介

Module PrestaShop 1.7 / 8 : vendez vos produits sur la marketplace Exantrix (catalogue et stock synchronises, commandes recues automatiquement).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
