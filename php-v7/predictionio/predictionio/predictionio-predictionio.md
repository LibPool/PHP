# predictionio/predictionio

> 标签: prediction, predictionio, recommendation, rest, restful, web service

## 简介

Apache PredictionIO API PHP Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/apache/predictionio-sdk-php.git
