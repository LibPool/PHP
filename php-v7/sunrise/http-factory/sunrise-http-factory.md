# sunrise/http-factory

> 标签: PHP7, factory, fenric, http, php8, psr-17, psr-7, sunrise

## 简介

HTTP factory for PHP 7.1+ based on PSR-17

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
