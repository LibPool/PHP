# iliain/php-zoo-ids

> 标签: random, usernames, zoo-ids

## 简介

A PHP version of bryanmylee's zoo-ids, originally written in JavaScript

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
