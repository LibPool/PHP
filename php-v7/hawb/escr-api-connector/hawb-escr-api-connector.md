# hawb/escr-api-connector

> 标签: PHP

## 简介

Package that talks to the API of the European Student Card Router to Insert, Update and Delete Card Holders and corresponding European Student Cards. Also retrieve the QR Code for validating a digital ESC.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
