# fivefifteen/primer

> 标签: boilerplate, example, starter, template, theme, wordpress

## 简介

A WordPress theme boilerplate. The perfect starting point for your custom WordPress theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
