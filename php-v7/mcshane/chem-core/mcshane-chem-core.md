# mcshane/chem-core

> 标签: PHP

## 简介

No-Brainer core db code repository management utilizing TheDataBaseMachine ORM framework. Template project coming soon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
