# it-blaster/redirect-bundle

> 标签: forward, redirect, symfony

## 简介

Auxiliary Symfony2 bundle. Perenapravlenie from the pages of the old site to the new site page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
