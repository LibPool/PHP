# it-blaster/attach-file-bundle

> 标签: Behavior, form, sluggable, type

## 简介

Symfony2 bundle. The ability to attach files to the form.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
