# schnti/umami

> 标签: kirby, kirby-cms, kirby-plugin

## 简介

Simple Kirby plugin adding an Umami analytics link to the Panel and a frontend tracking snippet.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
