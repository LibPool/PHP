# su-sws/acquia_purge_d8cache

> 标签: PHP

## 简介

Varnish cache invalidation on Acquia hosting service using cache tags provided by D8Cache module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
