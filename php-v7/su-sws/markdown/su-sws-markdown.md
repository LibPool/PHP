# su-sws/markdown

> 标签: PHP

## 简介

Provides Markdown integration for Drupal and allows content to be formatted in a simple plain-text syntax that is transformed into valid HTML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
