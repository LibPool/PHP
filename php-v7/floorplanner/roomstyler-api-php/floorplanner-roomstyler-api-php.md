# floorplanner/roomstyler-api-php

> 标签: Api Wrapper, api, floor planner, floorplanner, room styler, roomstyler, wrapper

## 简介

A PHP wrapper for the Roomstyler API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
