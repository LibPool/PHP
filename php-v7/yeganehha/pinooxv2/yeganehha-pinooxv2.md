# yeganehha/pinooxv2

> 标签: PHP

## 简介

pinoox is a simple environment for web management and development. You can do whatever you want on the web and add your desire features to your website in a simple way

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
