# wenpeng/validator

> 标签: Php Validator, batch validate, batch validator, php validate

## 简介

一个超轻量的 PHP 批量验证类, 简单高效, 扩展方便

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
