# awsafanam/yii2-basic-starter

> 标签: PHP

## 简介

Basic Yii starter kit with user management and roll management integrated with Yii2 Easy Installer and CoreUI Backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
