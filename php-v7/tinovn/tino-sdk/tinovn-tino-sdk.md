# tinovn/tino-sdk

> 标签: api, domain, hostbill, hosting, sdk, tino, tinohost, vps

## 简介

Official PHP SDK for the Tino UserAPI (https://api.tino.vn)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
