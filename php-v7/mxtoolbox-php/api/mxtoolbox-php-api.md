# mxtoolbox-php/api

> 标签: MX, api, dns, mxtoolbox, php, wrapper

## 简介

PHP wrapper for the MxToolbox API that aims to offer all of the functionality available from the raw API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
