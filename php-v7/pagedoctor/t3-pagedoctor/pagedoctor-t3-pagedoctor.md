# pagedoctor/t3-pagedoctor

> 标签: Pagedoctor, TYPO3 CMS, content elements, deployment

## 简介

Pagedoctor - Rapidly build and deploy content elements for TYPO3 CMS without one line of code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
