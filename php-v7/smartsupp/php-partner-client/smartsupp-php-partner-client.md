# smartsupp/php-partner-client

> 标签: chat

## 简介

API client allows to register and login (obtain API key) from Smartsupp partner API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.smartsupp.com/
- 源码仓库：https://github.com/smartsupp/php-auth-client.git
- Packagist 页面：https://packagist.org/packages/smartsupp%2Fphp-partner-client
