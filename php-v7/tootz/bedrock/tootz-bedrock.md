# tootz/bedrock

> 标签: bedrock, composer, roots, wordpress, wp, wp-config

## 简介

WordPress boilerplate with modern development tools, easier configuration, an improved folder structure, util functions and walkers, and Sharp starter theme

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
