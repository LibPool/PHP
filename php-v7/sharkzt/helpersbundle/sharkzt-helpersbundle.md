# sharkzt/helpersbundle

> 标签: framework, helper, purification, validation

## 简介

Helpers bundle, that extends symfony validator, html purifier classes for easy usage

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
