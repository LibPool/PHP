# wagnermontanini/goomerapi

> 标签: Goomer API, GoomerAPI, WagnerMontanini

## 简介

Criar uma API RESTful capaz de gerenciar os restaurantes e os produtos do seu cardápio.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
