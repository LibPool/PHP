# sngularai/neo4j-php-ogm

> 标签: annotations, cypher, database, graph, mapper, mapping, neo4j, ogm

## 简介

PHP Object Graph Mapper for Neo4j

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
