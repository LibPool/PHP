# markenwerk/json-pretty-printer

> 标签: Pretty print, json

## 简介

A PHP library providing pretty printing JSON strings for PHP < 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
