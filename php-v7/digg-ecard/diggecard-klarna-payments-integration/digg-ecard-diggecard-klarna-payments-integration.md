# digg-ecard/diggecard-klarna-payments-integration

> 标签: PHP

## 简介

A Magento 2 module that allow to work Diggecard with Klarna Payments methods

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
