# undefinedoffset/sortablegridfield

> 标签: gridfield, silverstripe, sort, sortable

## 简介

Adds drag and drop functionality to Silverstripe's GridField

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
