# cse/helpers-word

> 标签: collection, collections, converter, cse, framework, helper, helpers, inclination, library, string, strings, text, texts, tool, tools, transliterate, utilities, utility, utils, word, words

## 简介

The helpers allows you to modify string data. Inclination, transliterate, convert month date and convert number or amount to word - all this is available in this library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
