# stevelacey/laravel-mail-preview

> 标签: laravel, mail, mailcatch, mailcatcher, mailgrab, mailtrap

## 简介

Adds a 'preview' mail driver for testing emails in Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
