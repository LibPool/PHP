# metrictower/funnypot-wordpress

> 标签: PHP

## 简介

Thin WordPress adapter over the funnypot-policy decision engine (piece D). Normalizes the WP request, asks the shared policy engine for a Decision, and executes it. All decision logic lives in funnypot-policy.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
