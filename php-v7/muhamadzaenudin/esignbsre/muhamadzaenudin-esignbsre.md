# muhamadzaenudin/esignbsre

> 标签: PHP

## 简介

Package untuk penggunaan API E-Sign dari BSSN dengan bahasa PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
