# elsayed85/laravel-api-exceptions

> 标签: api, exceptions, framework, json, laravel

## 简介

All in one solution for exception for JSON REST APIs on Laravel and Lumen.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
