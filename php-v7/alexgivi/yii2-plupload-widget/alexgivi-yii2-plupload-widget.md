# alexgivi/yii2-plupload-widget

> 标签: extension, plupload, yii2

## 简介

Plupload Widget for Yii2, using Moxiecode plupload

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
