# capeandbay/birdeye

> 标签: BirdEye, Cape and Bay, Customer Experience, laravel

## 简介

Client-side SDK Package for Laravel that integrates with the BirdEye REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
