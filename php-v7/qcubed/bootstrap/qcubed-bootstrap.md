# qcubed/bootstrap

> 标签: bootstrap, qcubed

## 简介

QCubed wrappers for Twitter Bootstrap. Specifically for QCubed v4 and above.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
