# sputnik/newsletter-bundle

> 标签: email, newsletter, subscriber

## 简介

Provides subscriber functionality for various newsletters/subscription lists.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
