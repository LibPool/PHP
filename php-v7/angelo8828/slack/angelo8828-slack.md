# angelo8828/slack

> 标签: laravel, slack

## 简介

A simple PHP package for sending messages to Slack, with a focus on ease of use and elegant syntax. Future-proofed version of https://github.com/maknz/slack

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
