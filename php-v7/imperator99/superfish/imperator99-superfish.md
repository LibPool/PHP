# imperator99/superfish

> 标签: jquery, plugin

## 简介

A fork of the Superfish library for the Drupal Superfish module. Slight changes made to enhance accessibility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
