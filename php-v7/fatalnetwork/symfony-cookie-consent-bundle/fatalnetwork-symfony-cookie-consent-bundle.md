# fatalnetwork/symfony-cookie-consent-bundle

> 标签: PHP

## 简介

Symfony bundle for implementing Cookie Consent to comply to AVG/GDPR.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
