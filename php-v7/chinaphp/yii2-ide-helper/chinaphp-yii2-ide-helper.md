# chinaphp/yii2-ide-helper

> 标签: autocomplete, helper, ide, phpdoc, phpstorm, types, yii2

## 简介

Yii2 IDE Helper - 为 Yii2 框架提供 PhpStorm 智能代码补全支持

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
