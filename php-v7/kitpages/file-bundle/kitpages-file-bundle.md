# kitpages/file-bundle

> 标签: encoding, files, kitpages cms, resize, upload

## 简介

FileBundle manages uploads and manipulations of files for the Kitpages CMS Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
