# kitpages/simple-cache-bundle

> 标签: cache, doctrine

## 简介

Very simple cache system for symfony2. The cache data are saved in one table in database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
