# batsirai/gateway

> 标签: batsirai, gateway, laravel, payfast, payfast api

## 简介

A wrapper for payment gateways that you may want to intergrate

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
