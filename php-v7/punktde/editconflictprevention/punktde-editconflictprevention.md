# punktde/editconflictprevention

> 标签: PHP

## 简介

Prevents edit conflicts when multiple editors are working on the site by either warn the user or deny editing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
