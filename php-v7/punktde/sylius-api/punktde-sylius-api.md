# punktde/sylius-api

> 标签: API Platform, Flow framework, Neos, api, shop, sylius

## 简介

Sylius Shop Admin API Client for the Flow Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
