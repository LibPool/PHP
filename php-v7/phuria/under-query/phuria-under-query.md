# phuria/under-query

> 标签: builder, mysql, query, sql

## 简介

Lightweight PHP Query Builder primarily focused on building reusable SQL queries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
