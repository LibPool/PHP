# webloper/gravatar

> 标签: gravatar, webloper

## 简介

A small library intended to provide easy integration of... Gravatar :)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/webloper/gravatar
- 源码仓库：https://github.com/webloper/gravatar.git
- Packagist 页面：https://packagist.org/packages/webloper%2Fgravatar
