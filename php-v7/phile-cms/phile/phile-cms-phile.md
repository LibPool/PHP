# phile-cms/phile

> 标签: cms, file, flat, markdown, plugins, twig

## 简介

A file-based CMS with a swappable parser, template engine, cache and storage services, error handler, and meta parser.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
