# szagot/impulse

> 标签: PHP7, command-line, css, images, php

## 简介

Compacta CSS e imagens (jpg, png e gif) de uma pasta (e/ou subpastas) e os otimiza para web. (PHP / Command Line)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
