# tigrov/yii2-array-field

> 标签: array, attribute, field

## 简介

ArrayField - Yii2 extension to edit array field in forms generated by ActiveForm.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
