# esign/craft3-fields

> 标签: Craft, cms, craft-plugin, craftcms, nsm-fields

## 简介

Address, telephone and email fields for CraftCMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
