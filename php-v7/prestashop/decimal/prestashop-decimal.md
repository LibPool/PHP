# prestashop/decimal

> 标签: bcmath, decimal, math, precision, prestashop

## 简介

Object-oriented wrapper/shim for BC Math PHP extension. Allows for arbitrary-precision math operations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
