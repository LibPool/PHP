# maptechnica/mtapi

> 标签: boundaries, boundary, city, congressional district, county, fsa, gis, maptechnica, province, school district, state, zcta, zcta5, zip, zip code, zipcode

## 简介

A Laravel package that allows you to access the MapTechnica API easily.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
