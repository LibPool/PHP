# webbuilders-group/silverstripe-google-maps-embed

> 标签: google, maps, oembed, silverstripe

## 简介

Adds support for embedding Google Maps in Silverstripe via oEmbed

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
