# magium/mcm-zend-db-factory

> 标签: PHP

## 简介

A factory for configuring zendframework/zend-db adapters using the Magium Configuration Manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
