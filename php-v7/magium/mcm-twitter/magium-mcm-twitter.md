# magium/mcm-twitter

> 标签: PHP

## 简介

This is a simple library that manages the configuration for the abraham/twitteroauth library using the Magium Configuration Manager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
