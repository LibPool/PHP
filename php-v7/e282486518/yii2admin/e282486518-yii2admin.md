# e282486518/yii2admin

> 标签: admin, metronic, yii2, yii2后台

## 简介

通用的yii2后台，基于Yii2的advanced应用程序模板，采用metronic4.5.6作为前后台模板，整合RBAC、Menu、Config、Migration多语言、RESTfull等等

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
