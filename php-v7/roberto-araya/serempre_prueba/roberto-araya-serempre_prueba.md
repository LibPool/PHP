# roberto-araya/serempre_prueba

> 标签: PHP

## 简介

Módulo Drupal 8 con las funcionalidades solicitadas en la prueba para el cargo de desarrollador en Serempre.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
