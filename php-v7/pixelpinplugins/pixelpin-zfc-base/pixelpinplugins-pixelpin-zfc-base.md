# pixelpinplugins/pixelpin-zfc-base

> 标签: zf2

## 简介

A set of genetic (abstract) classes which are commonly used across multiple modules.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
