# studioemma/bundle-installation-bundle

> 标签: PHP

## 简介

This Bundle adds helper functions to allow easy installation of Pimcore Bundles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
