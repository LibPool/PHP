# andywaite/sim-telemetry-parser

> 标签: PHP

## 简介

Library to parse UDP packets from racing sims. Currently supports Codemasters' F1 2020 only.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
