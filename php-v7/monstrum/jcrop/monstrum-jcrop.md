# monstrum/jcrop

> 标签: crop, image drag and crop, thumbnail, zoom and crop

## 简介

Image Editor in standard jQuery plugin Structure. Fork from https://github.com/tapmodo/Jcrop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
