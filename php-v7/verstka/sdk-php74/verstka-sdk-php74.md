# verstka/sdk-php74

> 标签: api, cms, editor, php74, sdk, verstka

## 简介

PHP 7.4 SDK for Verstka API v2: open editor sessions, verify callbacks, download and process material content (media + fonts).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
