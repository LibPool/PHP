# keenlysoft/keenly

> 标签: cli, keenly, keenly framework, php framework, routing, smarty

## 简介

A lightweight PHP framework for small web applications and command-line tools

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
