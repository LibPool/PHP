# laravelbook/ardent

> 标签: Active Record, activerecord, database, eloquent, framework, laravel, orm, sql, validation

## 简介

Self-validating smart models for Laravel 5's Eloquent ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
