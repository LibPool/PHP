# lvht/protobuf

> 标签: proto

## 简介

proto library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://developers.google.com/protocol-buffers/
- 源码仓库：https://github.com/lvht/protobuf-php.git
- Packagist 页面：https://packagist.org/packages/lvht%2Fprotobuf
