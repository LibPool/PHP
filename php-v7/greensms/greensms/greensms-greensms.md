# greensms/greensms

> 标签: api, greensms, rest, sms, viber

## 简介

GREENSMS API: SMS, WhatsApp, Viber, VK, Voice, Call, HLR

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
