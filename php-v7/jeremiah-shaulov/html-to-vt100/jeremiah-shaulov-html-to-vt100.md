# jeremiah-shaulov/html-to-vt100

> 标签: html, terminal

## 简介

Convert HTML to VT100 terminal codes, to print colored and styled messages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
