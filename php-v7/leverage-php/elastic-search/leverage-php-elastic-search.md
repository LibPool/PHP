# leverage-php/elastic-search

> 标签: PHP

## 简介

High level Elastic Search client built on top of Elastic's low level client.  Probably slower but definitely more developer friendly.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
