# vrkansagara/zfskeleton

> 标签: Skeleton, application, framework, php, zend, zf2

## 简介

Zend Framework Skeleton Application for every project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
