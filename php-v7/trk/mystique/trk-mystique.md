# trk/mystique

> 标签: builder, dynamic, fieldtype, form, inputfield, processwire

## 简介

Mystique is a config file based field creation module for ProcessWire CMS/CMF by ALTI VE BIR IT.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
