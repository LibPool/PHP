# localgovdrupal/localgov_campaigns

> 标签: PHP

## 简介

Provides campaign sections using page builder paragraph types for LocalGovDrupal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
