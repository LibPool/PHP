# symbio/apc-bundle

> 标签: apc, apcu, symfony, task

## 简介

Provides a command line tasks to operate with APC (APCu) cache from the console

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
