# rumbletalk/rumbletalk-sdk-php

> 标签: api, chat, php, room, rumbletalk, sdk

## 简介

RumbleTalk API Client Library for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
