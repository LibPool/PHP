# masterpis/db2as400

> 标签: COM, Connection, as400, db2, odbc, query

## 简介

Packages for Db2 As400 connection. Connection based on general connection string COM and ODBC

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
