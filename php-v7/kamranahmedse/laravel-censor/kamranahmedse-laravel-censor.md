# kamranahmedse/laravel-censor

> 标签: censor, censor-pages, kamranahmedse, laravel, laravel-censor, middleware, redact, route

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
