# sunmant/phpconst2js

> 标签: PHP

## 简介

A small library for converting PHP class constants to JSON array. You can use it when you new constants values from PHP backend in JavaScript code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
