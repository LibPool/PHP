# dorsataio/squibble

> 标签: database, php framework, postgresql, sql

## 简介

Squibble is an easy to use PHP SQL library for accelerating development.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
