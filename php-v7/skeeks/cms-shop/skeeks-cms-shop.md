# skeeks/cms-shop

> 标签: Sx, app, cms, module, shop, skeeks, yii2

## 简介

Интернет магазин для SkeekS CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
