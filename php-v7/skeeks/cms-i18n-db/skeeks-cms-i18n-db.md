# skeeks/cms-i18n-db

> 标签: component, framework, i18n, skeeks, yii

## 简介

Storage translations in a database component for SkeekS CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
