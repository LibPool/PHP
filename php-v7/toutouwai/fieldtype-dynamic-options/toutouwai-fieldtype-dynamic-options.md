# toutouwai/fieldtype-dynamic-options

> 标签: module, processwire

## 简介

A ProcessWire Fieldtype module for dynamic options that are generated at runtime.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
