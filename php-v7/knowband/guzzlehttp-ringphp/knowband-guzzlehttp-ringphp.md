# knowband/guzzlehttp-ringphp

> 标签: PHP

## 简介

Provides a simple API and specification that abstracts away the details of HTTP into a single PHP function.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
