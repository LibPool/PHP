# janisto/yii2-timepicker

> 标签: date, datetime, extension, time, timepicker, widget, yii2

## 简介

Yii 2 widget for jQuery Timepicker Addon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
