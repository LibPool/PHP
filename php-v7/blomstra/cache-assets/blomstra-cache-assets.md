# blomstra/cache-assets

> 标签: JS, assets, blomstra, cache, css, extension, flarum

## 简介

Allows caching js and css ahead of any browser request.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
