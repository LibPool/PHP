# alxyzhv/slim-template

> 标签: Skeleton, mvc, php, slim, template

## 简介

A Slim Framework skeleton application with MVC structure and Eloquent ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
