# shevabam/php-extract-meta-url

> 标签: description, extract, favicon, image, keywords, rss, title, url

## 简介

Extract title, description, keywords, image, favicon and RSS from URL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
