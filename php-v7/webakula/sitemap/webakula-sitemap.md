# webakula/sitemap

> 标签: Simple, Sitemap, generator, laravel, seo, seo optimized, separated files

## 简介

A simple sitemap generator for PHP Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
