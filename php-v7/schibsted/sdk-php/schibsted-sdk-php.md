# schibsted/sdk-php

> 标签: SPiD, api, oauth2, php, rest

## 简介

OAuth2 and REST client for connecting and accessing the SPiD API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
