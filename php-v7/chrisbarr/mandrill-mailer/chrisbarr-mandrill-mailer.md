# chrisbarr/mandrill-mailer

> 标签: mailer, mandrill

## 简介

SwiftMailer-like interface for sending emails using the Mandrill Messages API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
