# micmania1/silverstripe-blog

> 标签: blog, news, silverstripe

## 简介

A fresh take on blogging in Silverstripe set out to tackle the issue of a cluttered Site Tree.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
