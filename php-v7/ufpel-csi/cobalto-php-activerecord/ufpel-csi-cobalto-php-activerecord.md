# ufpel-csi/cobalto-php-activerecord

> 标签: activerecord, orm

## 简介

cobalto-php-activerecord is an open source ORM library  for mysql and postgres based on the ActiveRecord pattern.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
