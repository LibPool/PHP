# hevelop/stripe-module-payments-graphql

> 标签: PHP

## 简介

This module exposes GraphQl API for Magento 2 Stripe Payments module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
