# dandelionmood/openexchangerates

> 标签: api, currencies, currency, money, open, openexchange, openexchangerates, rates, wrapper

## 简介

Wrapper for OpenExchangeRates API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
