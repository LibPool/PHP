# peterls/smsru

> 标签: api, sms, sms.ru

## 简介

Доработанный PHP-класс для работы с api сервиса [sms.ru](http://sms.ru)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
