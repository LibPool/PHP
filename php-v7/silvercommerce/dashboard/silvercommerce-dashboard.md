# silvercommerce/dashboard

> 标签: commerce, dashboard, ecommerce, products, sales, silverstripe

## 简介

Add dashboard to show stats from shop i.e. recent sales

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
