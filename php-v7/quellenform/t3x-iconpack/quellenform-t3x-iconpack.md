# quellenform/t3x-iconpack

> 标签: CKEditor, extension, iconfont, icons, typo3, webfont

## 简介

Provides an iconpack-registry for custom iconpacks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
