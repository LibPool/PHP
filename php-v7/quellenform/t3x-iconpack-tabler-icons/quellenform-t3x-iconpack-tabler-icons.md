# quellenform/t3x-iconpack-tabler-icons

> 标签: CKEditor, extension, iconfont, icons, typo3, webfont

## 简介

This Extension registers an Iconpack-Provider for EXT:iconpack which allows you to use the "Tabler Icons" in TYPO3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
