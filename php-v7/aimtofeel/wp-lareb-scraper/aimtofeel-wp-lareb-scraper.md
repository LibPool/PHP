# aimtofeel/wp-lareb-scraper

> 标签: wordpress

## 简介

Manages cron jobs which scrapes the Lareb website for up-to-date static data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
