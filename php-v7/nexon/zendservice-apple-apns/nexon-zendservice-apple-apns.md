# nexon/zendservice-apple-apns

> 标签: apns, apple, notification, push, zf2

## 简介

OOP Zend Framework 2 wrapper for Apple Push Notification Service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
