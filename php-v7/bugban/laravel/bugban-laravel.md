# bugban/laravel

> 标签: bugban, error-tracking, laravel, monitoring

## 简介

Bugban SDK — Laravel integration: automatic exception, request, auth & session capture.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
