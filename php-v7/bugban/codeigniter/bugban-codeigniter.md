# bugban/codeigniter

> 标签: bugban, codeigniter, error-tracking, exceptions, monitoring

## 简介

Bugban error & monitoring SDK — CodeIgniter 3 & 4 adapter.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
