# bugban/yii2

> 标签: bugban, error-tracking, exceptions, monitoring, yii, yii2

## 简介

Bugban error & monitoring SDK — Yii2 extension that auto-captures exceptions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
