# digedag/rn-base

> 标签: TYPO3 CMS, mvc

## 简介

A base library for extensions. Uses MVC design principles and domain driven development for TYPO3 extension development.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
