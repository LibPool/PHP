# digedag/t3sponsors

> 标签: TYPO3 CMS, catalog, mvc

## 简介

Simple TYPO3 extension with sponsors and categories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
