# feryardiant/wpdev

> 标签: bedrock, boilerplate, composer, roots, wordpress, wp-config

## 简介

WordPress boilerplate based-on Bedrock by Roots.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
