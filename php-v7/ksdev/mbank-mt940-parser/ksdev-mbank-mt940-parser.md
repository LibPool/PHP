# ksdev/mbank-mt940-parser

> 标签: ksdev, mbank-mt940-parser

## 简介

Parser for the mBank MT940 daily statement export file format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
