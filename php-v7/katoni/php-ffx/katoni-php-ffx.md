# katoni/php-ffx

> 标签: encryption, ffx, fpe, katoni, php-ffx

## 简介

A pure PHP implementation of Format-preserving, Feistel-based encryption (FFX).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
