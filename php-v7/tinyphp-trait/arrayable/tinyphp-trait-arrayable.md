# tinyphp-trait/arrayable

> 标签: PHP

## 简介

La clase asociada puede simular ser una variable array y a la vez poder ejecutar funciones de clase

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
