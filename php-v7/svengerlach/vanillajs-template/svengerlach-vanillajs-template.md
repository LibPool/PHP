# svengerlach/vanillajs-template

> 标签: PHP

## 简介

Port of John Resig's micro templating approach to PHP for server-side pre-compilation of simple JavaScript templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
