# socalnick/scn-http-cache

> 标签: cache-control, edge side includes, esi, varnish, zf2

## 简介

Adds several features to help make ZF2 applications cacheable.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
