# magento-ecg/magniffer

> 标签: PHP

## 简介

An extendable, XPath driven, static code analysis tool for Magento, built on the top of PHP-Parser library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
