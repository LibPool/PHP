# gemvc/library

> 标签: PHP

## 简介

Server Agnostic (openSwoole/Nginx/Apache) Rest Api Microservice ready Framework/Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
