# elfsundae/laravel-agent

> 标签: Agent, browser, laravel, mobile, user agent

## 简介

A PHP mobile/desktop User-Agent parser, with support for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
