# amantinetti/laravel-influxdb2

> 标签: PHP

## 简介

A service made to provide, set up and use the library from influxdata influx client php 2 in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
