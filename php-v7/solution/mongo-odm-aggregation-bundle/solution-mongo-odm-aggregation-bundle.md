# solution/mongo-odm-aggregation-bundle

> 标签: aggregation, mongo, pipeline, query

## 简介

This Bundle integrates mongo aggregation queries into you Symfony2 project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
