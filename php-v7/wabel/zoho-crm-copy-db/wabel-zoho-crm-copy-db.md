# wabel/zoho-crm-copy-db

> 标签: Zoho, Zoho CRM, ZohoCRM, copy, orm

## 简介

This package contains code to help you copy ZohoCRM records directly into your database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
