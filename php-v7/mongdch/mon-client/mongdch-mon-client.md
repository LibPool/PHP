# mongdch/mon-client

> 标签: http, https, tcp, udp

## 简介

PHP网络请求客户端，支持HTTP、TCP、UDP、异步并发HTTP，支持业务钩子

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
