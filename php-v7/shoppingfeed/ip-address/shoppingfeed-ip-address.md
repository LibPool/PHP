# shoppingfeed/ip-address

> 标签: PHP

## 简介

provides the capabilities to create, manipulate and operate on IPv4 and IPv6 addresses and networks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
