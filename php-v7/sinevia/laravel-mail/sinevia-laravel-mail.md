# sinevia/laravel-mail

> 标签: laravel, laravel5, lumen, mail, sinevia

## 简介

Laravel's mail transport for Sinevia Web Services Mail

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
