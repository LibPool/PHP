# trogon/otus-pdf

> 标签: Otus PDF, document generator, pdf, pdf creator, pdf generation

## 简介

Object oriented PDF document generation library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
