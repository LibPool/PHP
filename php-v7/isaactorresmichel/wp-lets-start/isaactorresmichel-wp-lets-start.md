# isaactorresmichel/wp-lets-start

> 标签: PHP

## 简介

A modern WordPress boilerplate repository. Integrates composer packages, namespacing and a better directory structure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
