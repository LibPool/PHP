# wp_builder_app/wp_builder_app

> 标签: app, framework, plugin, wordpress

## 简介

The Wordpress Plugin Framework for Builder Complex Application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
