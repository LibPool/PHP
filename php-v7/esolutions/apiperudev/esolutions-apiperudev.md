# esolutions/apiperudev

> 标签: PHP

## 简介

Cliente HTTP universal para la API de apiperu.dev (RUC/DNI, SUNAT, CPE, tipo de cambio, etc.). Compatible con PHP 7.2+ y Laravel 5.7 a 13 (y standalone).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
