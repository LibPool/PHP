# 9pay/wallet

> 标签: 9pay, 9pay wallet

## 简介

Library for use for connect with wallet 9pay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://9pay.vn
- 源码仓库：https://github.com/boydepdai92/9pay-wallet.git
- Packagist 页面：https://packagist.org/packages/9pay%2Fwallet

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require 9pay/wallet`
- Packagist 仓库：https://repo.packagist.org/p2/9pay/wallet.json
- 许可证：MIT
- PHP 要求：>=5.3.0
