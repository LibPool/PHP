# creativestyle/fastsimpleimport

> 标签: PHP

## 简介

Wrapper for Magento2 ImportExport functionality, which imports products and customers from arrays

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
