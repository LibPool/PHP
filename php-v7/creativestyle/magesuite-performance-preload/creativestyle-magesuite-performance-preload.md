# creativestyle/magesuite-performance-preload

> 标签: PHP

## 简介

Extension implements plugin that injects original collection into product entities returned by it for use in lazy-preloading by other modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
