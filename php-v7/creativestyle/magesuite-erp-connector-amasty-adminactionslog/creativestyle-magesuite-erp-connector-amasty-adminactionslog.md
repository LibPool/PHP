# creativestyle/magesuite-erp-connector-amasty-adminactionslog

> 标签: PHP

## 简介

Bridge module to hide sensitive data from erp-module in the Amasty AdminActionsLog

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
