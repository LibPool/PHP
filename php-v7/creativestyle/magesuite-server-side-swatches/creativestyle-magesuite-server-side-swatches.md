# creativestyle/magesuite-server-side-swatches

> 标签: PHP

## 简介

Magento module that moves rendering of swatches from JavaScript to PHP for better frontend performance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
