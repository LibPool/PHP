# creativestyle/magesuite-catalog-product-listing-compatibility

> 标签: PHP

## 简介

Module extends catalog product listing and related widgets, to allow choosing MageSuite products carousel as listing template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
