# creativestyle/magesuite-pwa-instant-purchase

> 标签: PHP

## 简介

The module extends magesuite-pwa module with instant-purchase feature support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
