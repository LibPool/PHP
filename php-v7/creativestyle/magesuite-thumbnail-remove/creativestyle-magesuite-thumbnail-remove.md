# creativestyle/magesuite-thumbnail-remove

> 标签: PHP

## 简介

Extension that allows to remove thumbnails generated by lazy resize extension trough REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
