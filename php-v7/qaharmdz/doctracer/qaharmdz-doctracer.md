# qaharmdz/doctracer

> 标签: docblocks, php

## 简介

DocTracer helps you to create meaningful API documentation reports. Reflecting PHP class information and show markdown formatted documentation on one page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
