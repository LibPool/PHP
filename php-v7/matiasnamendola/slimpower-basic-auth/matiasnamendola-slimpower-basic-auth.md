# matiasnamendola/slimpower-basic-auth

> 标签: auth, php, slim, slimpower

## 简介

HTTP Basic Authentication Middleware for SlimPower Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
