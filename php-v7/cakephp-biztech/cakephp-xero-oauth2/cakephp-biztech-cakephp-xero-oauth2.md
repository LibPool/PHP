# cakephp-biztech/cakephp-xero-oauth2

> 标签: api, cakephp, cakephp-plugin, oauth2, sdk, xero, xero-api

## 简介

Xero Oauth2 API plugin for CakePHP 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
