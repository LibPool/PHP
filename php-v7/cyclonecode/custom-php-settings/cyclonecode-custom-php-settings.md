# cyclonecode/custom-php-settings

> 标签: .htaccess, Settings, apache, apache2, development, environment variable, php, php settings, plugin, wordpress

## 简介

Customize php settings for you wordpress installation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 源码仓库：https://github.com/Cyclonecode/custom-php-settings.git
