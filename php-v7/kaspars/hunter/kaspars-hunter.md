# kaspars/hunter

> 标签: competitive programming, online judge, uhunt, uva

## 简介

Hunter is an easy to use uHunt wrapper to receive information from UVA servers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
