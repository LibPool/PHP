# infinum/eightshift-blocks

> 标签: blocks, composer, gutenberg, installer, plugin, wordpress

## 简介

WordPress Blocks libs developed by Eightshift team to use in modern WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
