# nysander/amukana-plvalidator-bundle

> 标签: IBAN, dowod osobisty, identity card, nip, pesel, regon, validator

## 简介

This bundle provides an validators specific for Polish Users (PESEL, NIP, REGON, Identity Card, Iban

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
