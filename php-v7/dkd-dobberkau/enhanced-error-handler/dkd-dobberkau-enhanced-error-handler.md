# dkd-dobberkau/enhanced-error-handler

> 标签: PHP

## 简介

Enhanced TYPO3 Debug Exception Handler with copy-to-clipboard functionality similar to Laravel Ignition

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
