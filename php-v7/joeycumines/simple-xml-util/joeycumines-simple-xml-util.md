# joeycumines/simple-xml-util

> 标签: PHP

## 简介

Utilities to improve maintainability of code that relies on PHP's simplexml_load_string.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
