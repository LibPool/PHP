# davidnineroc/qrcodeplus

> 标签: DavidNineRoc, multicolour, polychrome, qrcode, qrcodeplus, 彩色二维码

## 简介

可以生成四色， 九色， 十六色， 背景图二维码， 彩色二维码！

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
