# dragu/bitcoin-ecdsa

> 标签: ECDSA, bitcoin

## 简介

PHP library allowing to generate BTC addresses from private keys

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
