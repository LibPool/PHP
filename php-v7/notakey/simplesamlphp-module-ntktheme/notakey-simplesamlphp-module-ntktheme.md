# notakey/simplesamlphp-module-ntktheme

> 标签: notakey, simplesamlphp-theme

## 简介

A SimpleSAMLphp Notakey branded theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
