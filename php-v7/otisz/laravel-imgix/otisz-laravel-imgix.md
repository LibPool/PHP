# otisz/laravel-imgix

> 标签: cdn, image, image-processing, imgix, laravel, laravel-6, laravel-7, laravel-8

## 简介

Laravel package for generating Imgix URLs for your images

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
