# kommuna/jirawebhook

> 标签: atlassian, jira, reflection, webhook

## 简介

PHP classes for Atlassian Jira webhook data structure with events

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
