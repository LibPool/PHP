# outscraper/outscraper

> 标签: Google Maps scraper, Google Reviews scraper, extractor, google, google maps, outscraper, scrape google maps, scraper, webscraper

## 简介

PHP bindings for the Outscraper API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
