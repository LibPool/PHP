# menatwork/piwiktrackingtag

> 标签: analytics, frontend, piwik, statistics

## 简介

Includes the tracking code of the web analytics software Piwik

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
