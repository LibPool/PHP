# t3ran13/php-graphene-node-client

> 标签: Golos, Graphene, Steemit, Web Socket client for graphene node

## 简介

PHP client for connection to Graphene node (steem/golos)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
