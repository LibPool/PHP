# giofreitas/wordpress

> 标签: composer, wordpress, wp-config

## 简介

Just a package that set everything you need to get WordPress running successfully with composer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
