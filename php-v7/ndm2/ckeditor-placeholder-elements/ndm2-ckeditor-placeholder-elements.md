# ndm2/ckeditor-placeholder-elements

> 标签: CKEditor, placeholder, plugin

## 简介

A CKEditor plugin that adds support for predefined placeholder elements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
