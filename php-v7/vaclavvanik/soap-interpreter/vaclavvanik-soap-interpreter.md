# vaclavvanik/soap-interpreter

> 标签: request, response, soap, wsdl

## 简介

Interpreting of SOAP 1.1 and SOAP 1.2 messages

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
