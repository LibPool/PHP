# alterfw/meta-box

> 标签: custom-field, meta-box, select2, ui, wordpress, wordpress-plugin, wp-admin

## 简介

Easily create custom meta boxes in WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
