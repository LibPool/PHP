# musaid/slim3-skeleton

> 标签: Skeleton, slim-framework

## 简介

Simple Slim Framework 3 skeleton with Twig & Monolog.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
