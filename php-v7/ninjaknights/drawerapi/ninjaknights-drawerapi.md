# ninjaknights/drawerapi

> 标签: PHP

## 简介

PocketMine-MP virion designed to draw shapes and text in the world using the PrimitiveShapesPacket.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
