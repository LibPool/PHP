# ogogo/forgotpassword

> 标签: zf2, zfcuser

## 简介

Adding Forgot Password functionalitiy to ZfcUser (Custom)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
