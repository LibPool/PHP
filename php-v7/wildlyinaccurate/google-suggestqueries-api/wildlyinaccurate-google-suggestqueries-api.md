# wildlyinaccurate/google-suggestqueries-api

> 标签: PHP

## 简介

PHP library for retrieving suggestions from Google's suggestqueries API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
