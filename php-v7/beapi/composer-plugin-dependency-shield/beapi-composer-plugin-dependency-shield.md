# beapi/composer-plugin-dependency-shield

> 标签: PHP

## 简介

Composer plugin that checks WordPress plugin PHP/WP requirements against the project after install/update.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
