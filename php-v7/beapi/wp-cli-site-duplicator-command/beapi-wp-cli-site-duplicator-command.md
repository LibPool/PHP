# beapi/wp-cli-site-duplicator-command

> 标签: PHP

## 简介

A WP-CLI command for duplicating a site (blog) on a WordPress mutisite network

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
