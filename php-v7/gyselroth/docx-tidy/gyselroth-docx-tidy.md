# gyselroth/docx-tidy

> 标签: docx, markup, minification, office, tidy, word, xml

## 简介

Simplify markup of DOCX XML by tidying successive elements w/ redundant properties / types.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
