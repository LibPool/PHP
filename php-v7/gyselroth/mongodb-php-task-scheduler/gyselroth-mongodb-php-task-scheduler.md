# gyselroth/mongodb-php-task-scheduler

> 标签: async, mongodb, task-scheduler

## 简介

Asynchronous task scheduler for PHP based on MongoDB

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
