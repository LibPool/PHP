# hydrawiki/custom-mw-fixers

> 标签: Hydra, fixer, php-cs-fixer

## 简介

A set of custom fixers for PHP CS Fixer and the Hydra project

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
