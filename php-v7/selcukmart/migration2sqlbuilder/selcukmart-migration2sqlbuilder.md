# selcukmart/migration2sqlbuilder

> 标签: PHP

## 简介

This library is for migration natural sql to sql builder format. It supports only first depth and general usage of sql.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
