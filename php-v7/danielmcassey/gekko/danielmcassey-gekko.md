# danielmcassey/gekko

> 标签: gekko, shortener, url

## 简介

GEKKO Shortener is a Laravel ready made package to run your own URL shortener service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
