# screamz/securedownload-bundle

> 标签: cache, caching, document, download, memcached, redis, secure, sessions, stash, symfony

## 简介

Allow to secure file download.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
