# ak1r0/flysystem-filepathstrategy

> 标签: Flysystem, GED, document

## 简介

Add a 'File path strategy' to Flysystem. Allow to set globaly how files must be stored.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
