# epicarrow/git-changelog

> 标签: changelog, commits, git, laravel, version

## 简介

A simple service to parse the git log of an application to a readable changelog.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
