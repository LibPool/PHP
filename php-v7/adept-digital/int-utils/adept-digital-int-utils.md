# adept-digital/int-utils

> 标签: integer, leading zero, logical shift, overflow, pop count, rotate, trailing zero, unsigned, wasm, webassembly, wrap

## 简介

Utilities for emulating WebAssembly 32-bit and 64-bit integer operations in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
