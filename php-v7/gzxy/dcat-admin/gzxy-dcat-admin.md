# gzxy/dcat-admin

> 标签: admin, dcat, form, grid, laravel, laravel admin

## 简介

Dcat Admin - 基于 Laravel 的后台系统构建工具（dcat/laravel-admin 的维护分支）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
