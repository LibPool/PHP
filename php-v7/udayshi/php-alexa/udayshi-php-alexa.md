> 标签: Alexa, PHP7, alexa-library, alexa-php, alexa-sdk, alexa-skill, alexa-skill-php, alexa-ssml, alexa-template, alexa-without-lamda, echo, echo-php, echo-show, echo-show-php, php, php-alexa, show, ssml, template, us-alexa

## 简介

This is PHP Helper library  for Alexa and  Echo Show to generate response with few lines of code.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
