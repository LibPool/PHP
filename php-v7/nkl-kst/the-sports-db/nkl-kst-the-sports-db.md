# nkl-kst/the-sports-db

> 标签: TheSportsDB, library, php

## 简介

PHP library to get sports data from TheSportsDB (https://www.thesportsdb.com)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
