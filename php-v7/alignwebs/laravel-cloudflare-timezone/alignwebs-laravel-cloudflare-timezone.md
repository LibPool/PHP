# alignwebs/laravel-cloudflare-timezone

> 标签: alignwebs, laravel-cloudflare-timezone

## 简介

Laravel app timezone by cloudflare's [CF-IPCountry] HTTP header

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
