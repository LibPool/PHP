# thiio/orderdesk

> 标签: PHP

## 简介

This is a SDK built in PHP for consuming orderdesk api as detailed in https://www.orderdesk.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
