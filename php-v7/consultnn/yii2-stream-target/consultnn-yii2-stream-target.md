# consultnn/yii2-stream-target

> 标签: log, stderr, stdout, stream, yii2

## 简介

Yii2 log target for php stream wrappers, like php://stdout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
