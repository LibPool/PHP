# visualweber/error-handler-custom

> 标签: db, doctrine, error, expressive, handler, log, logger, logging, mail, psr7, zf2, zf3

## 简介

A Error Handler for your ZF2 and ZF3 application to trap php errors & exceptions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
