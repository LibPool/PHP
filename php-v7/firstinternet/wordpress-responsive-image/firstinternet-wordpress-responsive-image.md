# firstinternet/wordpress-responsive-image

> 标签: Webp, lazyload, wordpress

## 简介

Generate responsive Wordpress images. Supports .webp, lazyload, bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
