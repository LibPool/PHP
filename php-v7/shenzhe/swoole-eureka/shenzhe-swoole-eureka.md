# shenzhe/swoole-eureka

> 标签: discovery server, eureka, php, spring cloud, swoole

## 简介

A swoole client for Spring Cloud Eureka discovery server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
