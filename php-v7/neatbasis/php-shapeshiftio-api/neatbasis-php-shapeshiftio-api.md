# neatbasis/php-shapeshiftio-api

> 标签: PHP

## 简介

A PHP component for the crypto currency buying and selling shapeshift.io service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
