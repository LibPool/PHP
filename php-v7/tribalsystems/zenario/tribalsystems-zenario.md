# tribalsystems/zenario

> 标签: cms, content management, wysiwyg, zenario

## 简介

Zenario is a web-based content management system for sites with one or many languages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
