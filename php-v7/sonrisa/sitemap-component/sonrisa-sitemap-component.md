# sonrisa/sitemap-component

> 标签: Sitemap, image, index, media, news, video, xml

## 简介

Standalone sitemap builder 100% standards compliant. Build for PHP5.3 and above.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
