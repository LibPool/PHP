# stevad/yii2-xhprof

> 标签: debug, extension, profiling, xhprof, yii, yii2

## 简介

Simple extension to profile Yii Framework 2.x applications with Facebook XHProf

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
