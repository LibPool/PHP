# weberlei/wp-weberlei-notitle

> 标签: PHP

## 简介

Wordpress plugin that adds a dropdown admin option in every page to hide the title from rendering on a page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
