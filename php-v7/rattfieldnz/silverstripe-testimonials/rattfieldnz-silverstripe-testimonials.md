# rattfieldnz/silverstripe-testimonials

> 标签: page, silverstripe, testimonlials, widget

## 简介

Add testimonials to a SilverStripe site, either via a page or a widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
