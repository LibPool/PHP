# rattfieldnz/safe-urls

> 标签: Safe Browsing API, google, laravel, safe-urls

## 简介

A laravel package to check URLs with Google's Safe Browsing API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
