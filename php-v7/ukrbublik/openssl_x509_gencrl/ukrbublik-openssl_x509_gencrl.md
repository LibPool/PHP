# ukrbublik/openssl_x509_gencrl

> 标签: asn.1, asn1, certificate, certificate-authority, certificate-revocation-lists, certificates, cryptography, openssl, openssl-extension, php, x.509, x509

## 简介

Missing OpenSSL function on PHP to create CRL (certificate revocation list) for CA

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
