# dnna/swiftmailer-enqueue-bundle

> 标签: enqueue, queue, spool, swiftmailer

## 简介

Swiftmailer Spool using the Enqueue message queue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
