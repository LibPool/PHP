# tgraboski/tarjan

> 标签: PHP

## 简介

A simple cycle-detection algorithm. Given an edge-edges adjacency list, it returns a list of cycles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
