# tmountjr/muted-log

> 标签: exception, laravel, monolog

## 简介

Provides a "muted" log writer. The primary purpose is to log exceptions without including parameters in the stack trace.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
