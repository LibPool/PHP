# jkphl/iconizr

> 标签: css, data uri, generator, grunticon, icon, mobile, optimize, optipng, performance, php, png, pngcrush, pngquant, retina, sass, scalable, scour, sprite, svg, svgo, vector

## 简介

A PHP command line tool for converting SVG images to a set of CSS icons (SVG & PNG, single icons and / or CSS sprites) with support for image optimization and Sass output

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
