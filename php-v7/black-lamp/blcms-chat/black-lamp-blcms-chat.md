# black-lamp/blcms-chat

> 标签: blcms, chat, cms, component, yii2

## 简介

Component with basic methods for work with chat for Black Lamp CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
