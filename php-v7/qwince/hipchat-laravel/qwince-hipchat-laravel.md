# qwince/hipchat-laravel

> 标签: hipchat, laravel, package

## 简介

HipChat PHP Client Wrapper for Laravel 4 and 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
