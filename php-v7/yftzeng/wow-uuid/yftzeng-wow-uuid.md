# yftzeng/wow-uuid

> 标签: security, uuid, wow

## 简介

Wow! Uuid for PHP. Simple and Fast. Compliance with RFC 4122, but only UUID version 1 and version 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
