# pimlie/laravel-datatables-mongodb

> 标签: datatables, laravel, mongodb

## 简介

Laravel DataTables plugin to support Mongodb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
