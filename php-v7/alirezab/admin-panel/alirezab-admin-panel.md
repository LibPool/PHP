# alirezab/admin-panel

> 标签: admin, laravel, laravel admin, laravel admin panel

## 简介

A nice Admin Panel with RTL support For Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
