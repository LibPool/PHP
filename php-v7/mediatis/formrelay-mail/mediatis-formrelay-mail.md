# mediatis/formrelay-mail

> 标签: extension, form, formrelay, formrelay_mail, mail, typo3

## 简介

Mail delivery system based on Mediatis Formrelay

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
