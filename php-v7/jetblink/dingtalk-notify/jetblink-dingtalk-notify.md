# jetblink/dingtalk-notify

> 标签: api, dingtalk, message, notify, robot, sdk

## 简介

简单易用的钉钉机器人通知(支持加签). Easy dingtalk robot notification sdk.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
