# loveduckie/silverstripe-canonical

> 标签: canonical, html, seo, silverstripe

## 简介

Adds a simple canonical tag in Silverstripe 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
