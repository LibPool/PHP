# idfive/idfive_paragraphs

> 标签: Drupal 11, components, drupal, paragraphs

## 简介

This module is designed to provide base idfive kitchen sink widgets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
