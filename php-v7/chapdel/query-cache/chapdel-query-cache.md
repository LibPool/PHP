# chapdel/query-cache

> 标签: caching, eloquent, laravel, query, remember, sql

## 简介

Adding cache on your Laravel Eloquent queries' results is now a breeze.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
