# fgm/composer-check

> 标签: Drush, composer, drupal, update, versions

## 简介

A Drush plugin to check installed versus requested versions of vendor packages in Drupal 9/8 projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
