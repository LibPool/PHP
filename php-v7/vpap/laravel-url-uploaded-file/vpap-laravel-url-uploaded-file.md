# vpap/laravel-url-uploaded-file

> 标签: laravel, laravel-url-uploaded-file

## 简介

A package to leverage Laravel's UploadedFile functionality from URLs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
