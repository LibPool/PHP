# machinateur/php-qpdf-ffi

> 标签: pdf, php-ffi, qpdf, transform

## 简介

A really simple PHP integration for qpdf leveraging its JSON job file functionality with PHP-FFI to C.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
