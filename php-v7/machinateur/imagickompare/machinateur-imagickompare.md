# machinateur/imagickompare

> 标签: compare, image-magick, imagick, pdf, png

## 简介

A little PHP function that can compare PDFs and images using the Imagick PHP extension.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
