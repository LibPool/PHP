# romdim/yii2-snackbarjs

> 标签: snackbarjs, yii, yii2

## 简介

Composer package for implementing FezVrasta's Snackbar Js in Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
