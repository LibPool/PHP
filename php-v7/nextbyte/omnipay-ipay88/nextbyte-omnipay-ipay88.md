# nextbyte/omnipay-ipay88

> 标签: gateway, ipay88, merchant, omnipay

## 简介

iPay88 gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
