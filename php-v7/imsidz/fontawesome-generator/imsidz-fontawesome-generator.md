# imsidz/fontawesome-generator

> 标签: FontAwesome, faker, icon-generator

## 简介

Faker extension for randomly picking a FontAwesome Icon

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
