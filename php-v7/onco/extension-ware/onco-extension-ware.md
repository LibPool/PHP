# onco/extension-ware

> 标签: PHP

## 简介

Browse external extension catalogs and install, update and manage Shopware plugins from composer feeds directly in the administration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
