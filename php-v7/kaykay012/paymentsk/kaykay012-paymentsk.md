# kaykay012/paymentsk

> 标签: extension, fecshop, yii2, 易极付

## 简介

fecshop支付-易极付 国际信用卡支付,支持 Visa, MasterCard, JCB卡种等

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
