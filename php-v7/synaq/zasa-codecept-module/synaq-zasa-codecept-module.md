# synaq/zasa-codecept-module

> 标签: PHP

## 简介

Zimbra Admin SOAP API module for Codeception using the SYNAQ ZASA bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
