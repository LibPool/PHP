# heimfisch/simple_layout

> 标签: theme

## 简介

A minimal and responsive blog theme for the Automad CMS based on the beautiful Foundation framework, including a light and a dark color scheme. Check out the demo page and all available templates https://dev.heinisch-design.de/demo/simplelayout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
