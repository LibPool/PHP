# bigbank/gcm-message

> 标签: android, gcm, iphone, push message

## 简介

A PHP library to send messages to devices registered through Google Cloud Messaging

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
