# chris-ops-sys/battery-calculator

> 标签: battery-calculator, lifepo4, lithium-battery, litrue-battery, watt-hour

## 简介

A lightweight PHP calculation utility for lithium and LiFePO4 battery packs by LiTrue Battery.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
