# nevermnd/yii2-hinter

> 标签: bootstrap, hinter, yii2

## 简介

Bootstrap alert hinter.js widget for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
