# eldadfux/mailgun-lite

> 标签: Simple, api, lite, mailgun

## 简介

A lite and minimalistic PHP client library for sending mails using Mailgun API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
