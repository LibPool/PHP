# simonwelsh/hasoneedit

> 标签: cms, has_one, silverstripe

## 简介

Allows editing the fields of a has_one object directly in the CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
