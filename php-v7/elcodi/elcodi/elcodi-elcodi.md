# elcodi/elcodi

> 标签: bundle, components, ecommerce, elcodi, symfony

## 简介

Barebones Ecommerce functionality for Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
