# aldirifai/sastrawi

> 标签: bahasa, indonesia, indonesian, kata dasar, root word, stem

## 简介

PHP library for stemming Indonesian language (Bahasa Indonesia)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
