# abdoulhaqjr/laravel-translated-routes

> 标签: PHP

## 简介

Traduction automatique des routes Laravel selon la langue de l'utilisateur, sans préfixe /en ou /fr.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
