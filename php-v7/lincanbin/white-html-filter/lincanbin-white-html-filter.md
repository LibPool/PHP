# lincanbin/white-html-filter

> 标签: filter, html, whitelist, xss

## 简介

A lightweight php-based HTML tag and attribute whitelist filter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
