# csoellinger/silverstripe-admin-icons

> 标签: addon, admin, class, constants, helper, icons, module, plugin, silverstripe, silverstripe-module, silverstripe-vendormodule, vendor, vendormodule

## 简介

Little helper classes to get SilverStripe admin icon names easily.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
