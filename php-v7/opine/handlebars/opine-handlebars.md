# opine/handlebars

> 标签: handlebars

## 简介

Wrapper to Zordius LightnCandy Handlebars PHP compiler for compiling all layouts and partials in opine projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
