# anolilab/wordpress-salt-generator

> 标签: composer, generator, salts, wordpress

## 简介

Generates the salts for the Wordpress Composer projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
