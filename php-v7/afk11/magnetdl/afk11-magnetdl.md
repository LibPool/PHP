# afk11/magnetdl

> 标签: daemon, download, link, magnet, sftp, torrent, transmission

## 简介

Download magnet url's using a local Transmission Daemon, and upload using sftp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
