# pfeurean/authorizenet

> 标签: authorize.net, authorizenet, bluepay, ecommerce, payment

## 简介

Official PHP SDK for Authorize.Net (with a BluePay Patch)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
