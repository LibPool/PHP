# chalcedonyt/laravel-redis-tagger

> 标签: laravel, redis, tagging

## 简介

A Helper function for Redis in Laravel to organize tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
