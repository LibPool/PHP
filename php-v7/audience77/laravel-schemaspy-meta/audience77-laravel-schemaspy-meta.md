# audience77/laravel-schemaspy-meta

> 标签: database, er diagram, laravel, schema, schemaspy

## 简介

Generate schemaspy-meta.xml from Laravel Eloquent Models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
