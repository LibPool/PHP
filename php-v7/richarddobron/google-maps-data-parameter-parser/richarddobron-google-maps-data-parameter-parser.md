# richarddobron/google-maps-data-parameter-parser

> 标签: PHP

## 简介

PHP parser and builder for the "data" parameter (Protocol Buffers) in Google Maps URLs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
