# xi/dialog-bundle

> 标签: ajax, dialog

## 简介

Xi Dialog bundle is basic jQuery dialog with ajax features from xi/ajax-bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
