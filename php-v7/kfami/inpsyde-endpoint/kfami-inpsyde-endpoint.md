# kfami/inpsyde-endpoint

> 标签: PHP

## 简介

Inpsyde Endpoint is a plugin that has been built to show my skills towards my job application at Inpsyde.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
