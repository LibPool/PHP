# amelexik/cms

> 标签: Sx, app, cms, extension, framework, skeeks, skeeks cms, yii2

## 简介

SkeekS CMS — control panel and tools based on php framework Yii2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
