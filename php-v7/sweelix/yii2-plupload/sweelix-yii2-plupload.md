# sweelix/yii2-plupload

> 标签: asynchronous, behaviors, file, plupload, yii

## 简介

PHP 5.4+ Sweelix Yii2 plupload extension - easy asynchronous file uploads

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
