# iaaron/my-composer-demo

> 标签: PHP

## 简介

这是我的第一个 `composer` 包,主要用来学习 `composer` 包的发布过程.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
