# ecommercebox/actionml

> 标签: actionml, harness, prediction, predictionio, recommendation, rest, restful, web service

## 简介

ActionML Harness API PHP Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://actionml.com
- 源码仓库：https://github.com/ecommercebox/harness-php-sdk.git
- Packagist 页面：https://packagist.org/packages/ecommercebox%2Factionml
