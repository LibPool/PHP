# ixc-soft/tcpdf

> 标签: IXCQRcode, IXCTCPDF, barcodes, ixc, ixcsoft, pdf

## 简介

Adaptação da IXCSoft sobre o pacote TCPDF.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
