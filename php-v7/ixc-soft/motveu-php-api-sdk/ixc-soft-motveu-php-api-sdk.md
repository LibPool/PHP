# ixc-soft/motveu-php-api-sdk

> 标签: PHP API, ixc, ixcsoft, jacon, middleware, motveu, php

## 简介

Adaptação da IXCSoft sobre o pacote moTV.eu / JACON PHP SDK para funcionamento em PHP >= 7.0.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
