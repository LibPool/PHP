# pixelstudio/edje-wp-theme

> 标签: library, plugin, wordpress

## 简介

A WordPress starter theme for developer using Timber Library and ACF Pro.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
