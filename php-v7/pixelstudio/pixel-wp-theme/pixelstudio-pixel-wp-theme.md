# pixelstudio/pixel-wp-theme

> 标签: template, theme, wordpress

## 简介

WordPress boilerplate theme built with Gutenberg and good-old widgets

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
