# pixelstudio/gutenberg-px

> 标签: editor, gutenberg, plugin, wordpress

## 简介

WordPress editor with minor customization for version compatibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
