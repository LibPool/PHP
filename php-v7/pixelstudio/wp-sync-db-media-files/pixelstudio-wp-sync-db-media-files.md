# pixelstudio/wp-sync-db-media-files

> 标签: media, plugin, wordpress, wp-sync-db

## 简介

WordPress plugin to sync Media files between different installs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
