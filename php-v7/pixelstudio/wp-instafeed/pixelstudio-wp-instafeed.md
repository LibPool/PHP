# pixelstudio/wp-instafeed

> 标签: feed, instagram, plugin, wordpress

## 简介

WordPress plugin to display Instagram photos of any user. Works without Access Token!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
