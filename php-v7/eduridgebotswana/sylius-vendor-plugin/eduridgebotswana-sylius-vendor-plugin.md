# eduridgebotswana/sylius-vendor-plugin

> 标签: sylius, sylius-brand, sylius-plugin, sylius-vendor

## 简介

Vendor plugin for Sylius. Add Vendor (Brand) to your products

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
