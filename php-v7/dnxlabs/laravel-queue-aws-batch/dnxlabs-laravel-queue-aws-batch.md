# dnxlabs/laravel-queue-aws-batch

> 标签: aws, batch, laravel, queue

## 简介

Laravel Queue for AWS Batch, enabling users to submit jobs for processing to a Batch queue.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
