# taufik-nurrohman/kirby-minify

> 标签: PHP

## 简介

CSS, HTML, JavaScript, JSON, PHP, and XML compressor for Kirby CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
