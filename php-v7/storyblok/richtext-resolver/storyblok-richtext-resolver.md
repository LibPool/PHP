# storyblok/richtext-resolver

> 标签: html, render, richtext, storyblok, text

## 简介

A package allowing you to get an HTML string from the richtext field of Storyblok.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
