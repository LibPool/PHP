# coolephp/goaop

> 标签: aop, aspect, coole, goaop, php

## 简介

Bringing the goaop to Coole. - 将 goaop 集成到 Coole。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
