# yiiviet/yii2-validator

> 标签: Viet Nam validator, validator, yii2

## 简介

Extension hổ trợ các validator dữ liệu đặc thù trong nước.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
