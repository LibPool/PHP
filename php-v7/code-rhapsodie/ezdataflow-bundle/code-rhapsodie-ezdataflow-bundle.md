# code-rhapsodie/ezdataflow-bundle

> 标签: data processing, dataflow, export, ibexa, import

## 简介

Import/export bundle for Ibexa based on Code-Rhapsodie Dataflow

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
