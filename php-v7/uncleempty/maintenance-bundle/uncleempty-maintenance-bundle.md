# uncleempty/maintenance-bundle

> 标签: Symfony2, bundle, maintenance

## 简介

Symfony2 bundle, adding functionality to switch web-site into maintenance mode

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
