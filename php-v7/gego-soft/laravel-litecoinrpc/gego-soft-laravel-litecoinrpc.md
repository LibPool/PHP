# gego-soft/laravel-litecoinrpc

> 标签: Guzzle, api, jsonrpc, laravel, litecoin

## 简介

Litecoin JSON-RPC Service Provider for Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
