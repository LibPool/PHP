# valentino/telegram-bot-message-extension

> 标签: api, bot, extension, telegram

## 简介

A bot can send messages that will expire after some time. Create a message queue. Update different types of messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
