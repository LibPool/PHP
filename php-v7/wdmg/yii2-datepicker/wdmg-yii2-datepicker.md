# wdmg/yii2-datepicker

> 标签: bootstrap, datepicker, extension, wdmg, widget, yii, yii2

## 简介

Bootstrap3 DatePicker Widget for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
