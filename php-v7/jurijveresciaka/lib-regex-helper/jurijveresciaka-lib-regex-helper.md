# jurijveresciaka/lib-regex-helper

> 标签: preg_match, regex

## 简介

Regex helper library provides abstraction level of PHP preg_match function.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
