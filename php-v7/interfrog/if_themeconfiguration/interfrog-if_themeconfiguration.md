# interfrog/if_themeconfiguration

> 标签: extension, theme, themeconfiguration, typo3

## 简介

TYPO3 extension for creating themes with a style composing via TYPO3 backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
