# interfrog/if_basic

> 标签: basic, extension, ifPage, theme, typo3

## 简介

IfPage Basic - Distribution package based upon the if_themeconfiguration extension with basic template and styles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
