# pickles2/pickles2-for-github-pages

> 标签: cms, pickles2

## 简介

DB不要、オープンソースのPHP製静的CMS - for GitHub Pages

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
