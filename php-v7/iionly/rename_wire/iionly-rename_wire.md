# iionly/rename_wire

> 标签: elgg, plugin

## 简介

Change the branding of The Wire plugin by editing the language file of the Rename The Wire plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
