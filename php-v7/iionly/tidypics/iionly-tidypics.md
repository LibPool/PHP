# iionly/tidypics

> 标签: elgg, plugin

## 简介

Tidypics plugin provides a photo gallery with albums, tagging, and a slideshow.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
