# iionly/customsize_groupimage

> 标签: elgg, plugin

## 简介

Displays the group profile image in master size (same size as original uploaded image if smaller than 10240px).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
