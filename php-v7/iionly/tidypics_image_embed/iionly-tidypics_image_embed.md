# iionly/tidypics_image_embed

> 标签: elgg, plugin

## 简介

Tidypics Image Embed allows to embed an image to a post via Elgg's bundled Embed plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
