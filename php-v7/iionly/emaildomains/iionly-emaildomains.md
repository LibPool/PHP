# iionly/emaildomains

> 标签: elgg, plugin

## 简介

Limit new user signon to those with email addresses of specified domains or block user signons with email addresses of certain domains.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
