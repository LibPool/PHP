# iionly/monolingual

> 标签: elgg, plugin

## 简介

This plugin removes the option for users to select their preferred site language in user settings. Admins are the exception to this.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
