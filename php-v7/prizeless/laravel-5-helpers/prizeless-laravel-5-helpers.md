# prizeless/laravel-5-helpers

> 标签: helpers, laravel, laravel5

## 简介

Group of common and easy to use base classes for a Laravel 5.1 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
