# ianmustafa/laravel-jwt

> 标签: Skeleton, framework, ianmustafa, jwt, laravel

## 简介

A Laravel 6 RESTful API skeleton with JWT authentication.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
