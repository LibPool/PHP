# pavel-ekt/docker-wrapper

> 标签: container, docker, docker-wrapper, shell, wrapper

## 简介

provides a simple way to work with docker shell commands

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
