# plivo/php-sdk

> 标签: api, plivo, plivo xml, sms, voice calls

## 简介

A PHP SDK to make voice calls & send SMS using Plivo and to generate Plivo XML

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
