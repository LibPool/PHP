# beyerz/simple-hmvc-bundle

> 标签: Hierarchical model view controller, Symfony2, hmvc, symfony

## 简介

Symfony bundle to support the HMVC design pattern

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
