# mmaaikel/html-qrcode-maker

> 标签: PHP

## 简介

A simplified version of the HTML QR-code maker for easily generating a Twig file into a HTML.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
