# kyegil/leiebasen-poweroffice-api

> 标签: PHP

## 简介

Plugin til kyegil/leiebasen integrering med PowerOffice API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
