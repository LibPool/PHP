# colender/google-translate

> 标签: google, laravel, php, translate

## 简介

Free Laravel package for Paid Google Translate REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/colender/google-translate.git
- Packagist 页面：https://packagist.org/packages/colender%2Fgoogle-translate
