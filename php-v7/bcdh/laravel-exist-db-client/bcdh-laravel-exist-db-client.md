# bcdh/laravel-exist-db-client

> 标签: eXist-db, laravel, php

## 简介

A client that abstracts out the XML RPC calls for eXist-db for Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
