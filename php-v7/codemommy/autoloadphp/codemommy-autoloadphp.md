# codemommy/autoloadphp

> 标签: AutoloadPHP, CodeMommy, autoload, php

## 简介

Automatic load namespaces, classes and files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
