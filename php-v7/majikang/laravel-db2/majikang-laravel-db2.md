# majikang/laravel-db2

> 标签: database, db2, laravel, odbc, pdo

## 简介

laravel-db2 is a simple DB2 service provider for Laravel. Customized by Seuic

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
