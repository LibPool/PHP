# hsyir/laravel-selfupdater

> 标签: auto update, auto-update, laravel, laravel application, self update, self-hosted laravel application, self-update, update

## 简介

Providing an auto-updating functionality for your self-hosted Laravel application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
