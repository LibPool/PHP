# agy-koala/yii2-highcharts-widget

> 标签: extension, highcharts, highmaps, highstock, widget, yii2

## 简介

Highcharts widget for Yii 2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
