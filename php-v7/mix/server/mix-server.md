# mix/server

> 标签: coroutine, mix, server, swoole, tcp

## 简介

Tcp server library based on Swoole coroutine

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/mix-php/server.git
