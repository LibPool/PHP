# mix/vega

> 标签: framework, mix, vega

## 简介

Mix Vega is a HTTP web framework written in PHP support Swoole, WorkerMan

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/mix-php/vega.git
