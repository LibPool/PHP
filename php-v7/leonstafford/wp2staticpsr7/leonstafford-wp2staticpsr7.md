# leonstafford/wp2staticpsr7

> 标签: http, message, psr-7, request, response, stream, uri, url

## 简介

Safely namespaced guzzle psr7 for WP2Static

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
