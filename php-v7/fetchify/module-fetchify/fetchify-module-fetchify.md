# fetchify/module-fetchify

> 标签: PHP

## 简介

Adds data capture and validation products by Fetchify (previously Crafty Clicks) to Magento 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
