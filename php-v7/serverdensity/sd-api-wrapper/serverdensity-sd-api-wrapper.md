# serverdensity/sd-api-wrapper

> 标签: api, php, sd, serverdensity, wrapper

## 简介

A php wrapper for the Server Density API v2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
