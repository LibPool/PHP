# phpoffice/phppowerpoint

> 标签: LibreOffice, PowerPoint, odp, php, ppt, pptx, presentations

## 简介

PHPPresentation - Read, Create and Write Presentations documents in PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
