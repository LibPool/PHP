# mvaessen/binance-api

> 标签: api, binance

## 简介

Simple Binance API Wrapper, written in PHP. Includes the basics and assumes you know your way around.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
