# jakiboy/pducky

> 标签: big data, csv, data analysis, duckdb, json, parquet, php, sql, sqlite3, xml

## 简介

Run fast SQL queries on massive datasets (CSV, JSON, and Parquet) powered by DuckDB.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
