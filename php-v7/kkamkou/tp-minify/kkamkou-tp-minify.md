# kkamkou/tp-minify

> 标签: asset, minify, obfuscation, zf2

## 简介

Zend Framework 2 module which uses the Steve (mrclay) Clay's Minify library for styles and scripts obfuscation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
