# gevman/yii2-html-lazyload

> 标签: Block Lazy Load, Yii-Widget, composer, lazy load, lazyload, yii2

## 简介

Yii2 Lazy load Widget for html blocks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
