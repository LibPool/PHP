# fnayou/zeppelin

> 标签: Guzzle, api, configuration, description, web-services

## 简介

Simple Guzzle configurator using client configuration and api descriptions files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
