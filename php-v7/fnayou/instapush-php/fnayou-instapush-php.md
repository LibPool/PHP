# fnayou/instapush-php

> 标签: api, instapush, notification, php, push, sdk, wrapper

## 简介

PHP wrapper for Instapush.im APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
