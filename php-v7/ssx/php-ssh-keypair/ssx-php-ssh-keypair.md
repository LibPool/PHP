# ssx/php-ssh-keypair

> 标签: keys, rsa, ssh

## 简介

Simple wrapper to generate RSA/SSH key-pairs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
