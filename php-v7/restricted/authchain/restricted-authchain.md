# restricted/authchain

> 标签: Authentication, auth, eloquent, imap, laravel, ldap, security

## 简介

Laravel 4 chain authentication (LDAP, IMAP, IP, Eloquent)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
