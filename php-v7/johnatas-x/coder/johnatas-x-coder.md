# johnatas-x/coder

> 标签: code review, phpcs, standards

## 简介

Coder is a library to review Drupal code.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://www.drupal.org/project/coder
- 源码仓库：https://github.com/johnatas-x/coder.git
- Packagist 页面：https://packagist.org/packages/johnatas-x%2Fcoder
