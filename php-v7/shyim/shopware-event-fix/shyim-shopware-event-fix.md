# shyim/shopware-event-fix

> 标签: event-fix, phpunit, shopware

## 简介

Fixes Event Listener in PHPUnit. Needed for Shopware Versions under 5.5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
