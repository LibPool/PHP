# sabinchacko/toaster

> 标签: PHP

## 简介

A beautiful toaster component for Laravel redirections, with messages - With the help of Livewire & TailwindCSS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
