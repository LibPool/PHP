# sofa/eloquence

> 标签: eloquent, laravel, mappable, metable, mutable, searchable

## 简介

Flexible Searchable, Mappable, Metable, Validation and more extensions for Laravel Eloquent ORM.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
