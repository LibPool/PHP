# vizad/intuit

> 标签: intuit, oauth, oauth1, quickbooks

## 简介

OAuth 1.0 Client for Intuit using The PHP League OAuth1-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
