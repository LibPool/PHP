# mensbeam/uri

> 标签: WHATWG, ext-uri, polyfill, rfc3986, uri, url

## 简介

An implementation of the PHP URI extension for older PHP versions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
