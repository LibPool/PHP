# mickgeek/yii2-actionbar

> 标签: bulk actions, extension, grid, widget, yii2

## 简介

A control bar with bulk actions for the GridView widget.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
