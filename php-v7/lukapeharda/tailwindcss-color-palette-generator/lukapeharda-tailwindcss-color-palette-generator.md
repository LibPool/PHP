# lukapeharda/tailwindcss-color-palette-generator

> 标签: color, generator, palette, tailwindcss

## 简介

Generate TailwindCSS color palette from a single color.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
