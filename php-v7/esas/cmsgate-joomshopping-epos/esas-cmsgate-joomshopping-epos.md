# esas/cmsgate-joomshopping-epos

> 标签: api, cmsgate, epos, erip, joomla, joomshopping, payment gateway

## 简介

Joomla joomshopping to Epos (ERIP) cms payment gate library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
