# pecee/dropbox-sdk

> 标签: dropbox, pecee, php, php-sdk, sdk, v2, version 2

## 简介

Mini, lightweight version of the Dropbox v2 SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
