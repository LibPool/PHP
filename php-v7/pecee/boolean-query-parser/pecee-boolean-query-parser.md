# pecee/boolean-query-parser

> 标签: boolean query formatter, boolean query parser, boolean search parser, database, fulltext query format, mysql, mysql fulltext formatter, parser, query formatter, query parser

## 简介

Convert a boolean search query into a query that is compatible with a fulltext search.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
