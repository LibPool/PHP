# pecee/tinder-sdk

> 标签: api, http, pecee, rest, sdk, service, tinder, web

## 简介

Easy to use PHP SDK for accessing Tinder data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
