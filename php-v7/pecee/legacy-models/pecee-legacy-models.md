# pecee/legacy-models

> 标签: framework, legacy, models, pecee, upgrade

## 简介

Composer module for adding legacy model support for pecee framework version 3 and greater.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
