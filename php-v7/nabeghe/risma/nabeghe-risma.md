# nabeghe/risma

> 标签: binder, chaining, helper, library, placeholder-replacement, risma, string, string-helper, string-manipulation, string-support, support, template-engine, text, text-binder, text-morpher, text-processing, variable-binding

## 简介

A lightweight, zero-dependency string template engine and interpreter for PHP — embed logic, conditionals, and function pipelines directly inside strings.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
