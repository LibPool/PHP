# incognito-coder/ic-telegram-bot

> 标签: Telegram-Bot-API, bot, php, php8, telegram, telegram-bot, telegram-stars

## 简介

Lightweight, zero-dependency PHP Telegram Bot library based on the official Telegram Bot API (supporting Bot API 7.x - 8.3+)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
