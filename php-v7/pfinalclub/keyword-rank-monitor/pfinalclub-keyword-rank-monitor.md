# pfinalclub/keyword-rank-monitor

> 标签: bing, fastadmin, google, keyword, monitor, ranking, seo, yahoo

## 简介

关键词排名监控系统 - 支持批量导入关键词，自动查询Google、Bing、Yahoo排名

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
