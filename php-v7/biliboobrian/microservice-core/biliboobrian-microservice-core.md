# biliboobrian/microservice-core

> 标签: Microservice, framework, laravel, lumen

## 简介

A set of core functionality and convenience classes for a Lumen microservice.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
