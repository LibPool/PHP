# kitt3n/kitt3n-assets

> 标签: TYPO3 Kit, assets, kitt3n, resources

## 简介

Default assets for TYPO3 projects with kitt3n.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
