# kitt3n/kitt3n-layouts

> 标签: TYPO3 Kit, backendlayout, kitt3n, layout

## 简介

All necessary configuration for the TYPO3 backend layouts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
