# sasanet/eloquent-model-generator

> 标签: eloquent-model-generator, sasanet

## 简介

Fork of Reliese Components for Laravel Framework eloquent code generation with sql server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
