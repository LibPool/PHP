# bitninja/ninjarpc

> 标签: json, protobuf, protocol-buffers, rabbitmq, redis, rpc

## 简介

Microservice RPC through message queues.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
