# elliotsawyer/silverstripe-mysql-ssl

> 标签: database, mysql, silverstripe, ssl

## 简介

Restores support for SSL MySQL connections in Silverstripe 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
