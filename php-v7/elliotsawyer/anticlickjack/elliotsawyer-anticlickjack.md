# elliotsawyer/anticlickjack

> 标签: clickjack, owasp, security, silverstripe

## 简介

Template shim to prevent clickjacking on a SilverStripe website

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
