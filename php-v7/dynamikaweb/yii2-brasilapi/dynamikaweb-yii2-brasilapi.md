# dynamikaweb/yii2-brasilapi

> 标签: BrasilApi, dynamika, yii, yii2

## 简介

yii2 widget for zip code queries from Brazil, using BrasilApi resources

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
