# adyoi/jquery-displayresolution

> 标签: displayresolution, jquery, resolution, screen, viewport, widget

## 简介

jQuery plugin for displaying screen resolution, viewport size and scroll position

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
