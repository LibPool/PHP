# aoe/directrequest

> 标签: directrequest, extbase, typo3

## 简介

Extension to fake an HTTP request and perform a direct request to the frontend triggered by the backend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
