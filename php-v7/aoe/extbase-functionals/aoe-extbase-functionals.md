# aoe/extbase-functionals

> 标签: extbase, functional, typo3, unit

## 简介

Testing-Framework for Extbase-Extensions to easily manage functional controller tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
