# aoe/codingstandards

> 标签: AOE GmbH, code sniffer, codingstandards, phpcs

## 简介

Provide multiple coding standards and sniffs for PHPCS using the AOE conventions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
