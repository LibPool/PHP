# goose-studio/symlinked-extensions

> 标签: PHP

## 简介

Replaces composer installed plugins, themes and mu-plugins with symlinks to defined folders.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
