# fosforus/authblock-shortcode

> 标签: shortcode, silverstripe

## 简介

Creates a shortcode block to test if a user is logged in or not and render content as desired.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
