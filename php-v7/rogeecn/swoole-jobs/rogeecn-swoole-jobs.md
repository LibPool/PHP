# rogeecn/swoole-jobs

> 标签: job, scheduler, swoole, 调度

## 简介

基于swoole的job调度组件，类似gearman的分布式任务处理系统

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
