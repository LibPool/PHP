# haridarshan/instagram-php

> 标签: instagram, instagram-api, php-instagram-api

## 简介

Implements the Instagram APIs specified by http://instagram.com/developer/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
