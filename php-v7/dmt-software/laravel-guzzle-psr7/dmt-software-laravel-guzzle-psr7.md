# dmt-software/laravel-guzzle-psr7

> 标签: Guzzle, laravel, psr-7

## 简介

Use guzzle for PSR-7 server-request and response in Laravel 6 and up.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
