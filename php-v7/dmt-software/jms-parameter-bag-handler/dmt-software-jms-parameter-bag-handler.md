# dmt-software/jms-parameter-bag-handler

> 标签: PHP

## 简介

A JMS serializer handler that serializes and deserializes bag of parameters that are not predefined

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
