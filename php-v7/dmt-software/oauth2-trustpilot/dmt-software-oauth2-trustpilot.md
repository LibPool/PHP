# dmt-software/oauth2-trustpilot

> 标签: Trustpilot, authorization, client, oauth, oauth2

## 简介

A Trustpilot Client Provider for The PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
