# onema/nexmo-cli

> 标签: cli, console, demo, nexmo, sms, text-to-speech

## 简介

Send SMS and Voice messages from the command line using the Nexmo API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
