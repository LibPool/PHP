> 标签: cdek, delivery, sdk, v2.0, СДЭК, служба доставки

## 简介

PHP SDK для API v2.0 от сервиса интеграции компании СДЭК

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
