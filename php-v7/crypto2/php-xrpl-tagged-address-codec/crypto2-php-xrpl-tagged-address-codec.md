# crypto2/php-xrpl-tagged-address-codec

> 标签: PHP

## 简介

Encode and Decode an XRPL account address and destination tag to/from X-formatted (tagged) address

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
