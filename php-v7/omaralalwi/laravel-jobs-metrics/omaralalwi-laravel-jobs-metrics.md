# omaralalwi/laravel-jobs-metrics

> 标签: background jobs, execution time, horizon extension, job metrics, job monitoring, jobs, laravel, laravel horizon, laravel job metrics, laravel job tracker, laravel performance, laravel queue, memory tracking, omaralalwi, performance monitoring, queue, queue metrics

## 简介

Tracks job memory consumption — works with or without Horizon, and enables long-term performance analysis via database logging.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
