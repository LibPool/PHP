# skinnybot/plugin-installer

> 标签: bot, botphp, discord, discordphp, installer, php, plugin, skinny

## 简介

The plugin installer for Skinny.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
