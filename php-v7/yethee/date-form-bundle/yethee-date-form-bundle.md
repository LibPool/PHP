# yethee/date-form-bundle

> 标签: date-formatter, form

## 简介

This bundle fixed issue with timezone Europe/Moscow when used ICU < 54.1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
