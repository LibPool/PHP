# mridang/pearify

> 标签: PEAR, PSR-4, magento, package

## 简介

Pearify converts PSR-4 Composer packages to PEAR compliant code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
