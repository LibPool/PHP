# thelia/tiptap-module

> 标签: PHP

## 简介

TipTap WYSIWYG editor module for Thelia 3 back-office Twig (modern replacement for legacy Tinymce module).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
