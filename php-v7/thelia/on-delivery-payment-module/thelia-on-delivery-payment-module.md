# thelia/on-delivery-payment-module

> 标签: PHP

## 简介

OnDeliveryPayment module for Thelia: payment collected by the carrier upon delivery.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
