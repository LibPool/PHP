# rootsoft/laravel-ipfs

> 标签: ipfs, laravel, laravel-ipfs, php, rootsoft

## 简介

Laravel package to communicate with IPFS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
