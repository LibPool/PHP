# scorpio/sphinx-search

> 标签: Sphinx Search, scorpio, sphinx

## 简介

A set of classes wrapping the SphinxClient extension in a object-oriented way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
