# wula/jqadmin

> 标签: WebUI, adminUi, backendui, dashboard, jqadmin, layui

## 简介

jQadmin UI based on layui for wula framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
