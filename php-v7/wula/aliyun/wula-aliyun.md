# wula/aliyun

> 标签: aliyun, sdk

## 简介

Aliyun Core SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.aliyun.com
- 源码仓库：https://github.com/windywany/wula-aliyun-core-sdk.git
- Packagist 页面：https://packagist.org/packages/wula%2Faliyun

## 历史版本号

- 当前版本：v1.0.0

- v1.0.0

## 获取地址

- Composer 安装：`composer require wula/aliyun`
- Packagist 仓库：https://repo.packagist.org/p2/wula/aliyun.json
- 许可证：Apache-2.0
- PHP 要求：>=5.5.0
