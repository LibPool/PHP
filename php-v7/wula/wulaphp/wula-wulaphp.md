# wula/wulaphp

> 标签: HOOK, module, mvc, php, php framework, plugin

## 简介

一个小巧的PHP MVC框架。它的名来自《异星战场》里那个速度极快的火星狗狗，它真的很快！

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
