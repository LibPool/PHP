# phpbbde/externalimgaslink

> 标签: PHP

## 简介

Displays every image as a link, which is included with [img] bbcode and not hosted with the own board.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
