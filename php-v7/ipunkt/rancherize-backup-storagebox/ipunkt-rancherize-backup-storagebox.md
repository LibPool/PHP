# ipunkt/rancherize-backup-storagebox

> 标签: PHP

## 简介

Rancherize plugin adding backup commands for use witha a hetzner storagebox

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
