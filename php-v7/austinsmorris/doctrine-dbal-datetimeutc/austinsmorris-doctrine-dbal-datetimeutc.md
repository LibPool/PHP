# austinsmorris/doctrine-dbal-datetimeutc

> 标签: datetime, dbal, doctrine, utc

## 简介

A custom Doctine DBAL type to use PHP DateTime objects set to the UTC timezone.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
