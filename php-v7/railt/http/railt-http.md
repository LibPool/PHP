# railt/http

> 标签: Batching, graphql, http, http request, http response, laravel, parsing, request, response, symfony, zend

## 简介

The Railt HTTP component provides objects to build GraphQL requests from the client.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
