# gdecris/writer-ivey

> 标签: csv, excel, file, tsv, writer

## 简介

Tabular data file writer. Used to convert tabular data into delimited/excel files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
