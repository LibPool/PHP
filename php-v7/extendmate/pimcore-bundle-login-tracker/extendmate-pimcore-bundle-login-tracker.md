# extendmate/pimcore-bundle-login-tracker

> 标签: login attempt detector, login history, login insights, login log, login monitor, login tracker, security audit trail, user login history

## 简介

Tracks login activities of pimcore users.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
