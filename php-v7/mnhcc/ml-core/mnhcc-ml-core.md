# mnhcc/ml-core

> 标签: autoloader, framework, mvc, php54

## 简介

Minimalus Layoutilus — core autoloader, base object model, helpers, config and event bus

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
