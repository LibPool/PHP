# telstatic/rakan

> 标签: OBS, cos, filesystem, kodo, laravel, oss, rakan, xayah

## 简介

Laravel 文件系统扩展,适配 阿里云OSS,七牛云KODO,腾讯云COS,华为云OBS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
