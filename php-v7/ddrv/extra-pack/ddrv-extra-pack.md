# ddrv/extra-pack

> 标签: Extras, binary, binary-data, binary-string, pack, unpack

## 简介

Extras for pack() and unpack() functions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
