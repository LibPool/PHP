# piyush/excel-importer

> 标签: excel, import, parser, reader, spreadsheet, xls, xlsx

## 简介

A lightweight PHP package to import Excel files (.xlsx and .xls) with data type support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
