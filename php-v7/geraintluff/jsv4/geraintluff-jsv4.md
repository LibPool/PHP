# geraintluff/jsv4

> 标签: Geraint Luff, JSON Schema, geraintluff, json, schema, v4, validator

## 简介

A (coercive) JSON Schema v4 Validator for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
