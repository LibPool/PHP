# calibrate/calibr8_cookie_compliance

> 标签: Drupal 8, gtm

## 简介

Ask users to allow this site to store cookies on local machine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
