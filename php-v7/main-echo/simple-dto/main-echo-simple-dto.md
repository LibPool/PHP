# main-echo/simple-dto

> 标签: api, data transfer objects, dto, restful

## 简介

A fork of `phpexperts/simple-dto`—a quick and easy DTO package.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
