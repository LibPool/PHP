# summernote-next/summernote-next

> 标签: bootstrap, editor, rich-text, summernote, summernote-next, vanilla-js, wysiwyg

## 简介

Vanilla JS WYSIWYG editor with Bootstrap 5 integration and a UI toolkit-independent Classic UI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
