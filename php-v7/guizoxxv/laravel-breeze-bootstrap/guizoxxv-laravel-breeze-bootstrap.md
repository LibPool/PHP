# guizoxxv/laravel-breeze-bootstrap

> 标签: PHP

## 简介

A Laravel package to use Bootstrap scaffolding with Breeze.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
