# k10r/codestyle

> 标签: custom-fixer, fixer, k10r, php-cs-fixer

## 简介

Kellerkinder codestyle definitions for different PHP versions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
