# rennokki/elasticscout

> 标签: driver, elastic, elasticsearch, engine, laravel, scout, search

## 简介

Elasticsearch driver for Laravel Scout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
