# sgvsv/php-mass-files-converter

> 标签: convert, encoding, files, utf-8

## 简介

Mass recursive convert files in given directory from given encoding to UTF-8

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
