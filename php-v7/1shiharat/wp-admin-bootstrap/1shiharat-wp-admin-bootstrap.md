# 1shiharat/wp-admin-bootstrap

> 标签: bootstrap, wordpress

## 简介

Bootstrap Based CSS Framework for WordPress admin screen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
