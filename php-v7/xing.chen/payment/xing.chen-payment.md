# xing.chen/payment

> 标签: PHP

## 简介

支持支付宝支付、微信支付、小程序支付、IOS苹果内购、payPal支付、银联、首信易，payssion支付，可生成支付宝、微信app、小程序签名,头条/字节跳动

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
