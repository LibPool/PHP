# xing.chen/yii-import-excel

> 标签: import excel, yii, yii2, 导入excel

## 简介

yii导入excel表格的扩展程序，程序对常用导入套路进行了封装，可大大简化编写代码的工作量。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
