# limanweb/xlsxwriter

> 标签: excel, laravel

## 简介

Laravel extensions to to output an Excel compatible spreadsheet in (Office 2007+) xlsx format

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
