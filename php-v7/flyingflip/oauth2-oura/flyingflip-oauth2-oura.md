# flyingflip/oauth2-oura

> 标签: PHP

## 简介

Oura OAuth 2.0 Client Provider for the PHP League Oauth2-Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
