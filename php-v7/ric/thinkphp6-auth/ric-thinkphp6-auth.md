# ric/thinkphp6-auth

> 标签: auth, think, thinkphp6, 多端用户权限, 权限验证

## 简介

think6多端用户登录退出auth权限控制

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
