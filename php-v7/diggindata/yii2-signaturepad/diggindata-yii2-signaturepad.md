# diggindata/yii2-signaturepad

> 标签: pad, signature, widget, yii2

## 简介

Yii2 widget to display a signature pad using https://github.com/INTELOGIE/signature_pad

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
