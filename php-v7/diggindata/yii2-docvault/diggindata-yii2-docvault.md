# diggindata/yii2-docvault

> 标签: diggindata, documents management, yii2, yii2-docvault

## 简介

Documents management System for Yii2 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
