# zhong0060/morepanel

> 标签: dcat-admin, extension

## 简介

一键生成管理面板,支持Admin免密登陆其它管理面板,每个管理面板自身独立(管理员，权限，角色),Saas系统最方便的实现

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
