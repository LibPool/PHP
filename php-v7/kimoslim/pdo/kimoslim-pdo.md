# kimoslim/pdo

> 标签: database, framework, pdo, slim

## 简介

PHP 7.2 Compatible Fork of PDO database library for Slim Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
