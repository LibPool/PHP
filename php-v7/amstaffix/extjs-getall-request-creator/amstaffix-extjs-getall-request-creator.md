# amstaffix/extjs-getall-request-creator

> 标签: PHP

## 简介

Вспомогательная библиотека, которая эмулирует GET All запрос от ExtJS. Применяется в создании тестов

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
