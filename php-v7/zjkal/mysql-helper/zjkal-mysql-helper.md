# zjkal/mysql-helper

> 标签: export, helper, import, mysql, php, zjkal

## 简介

一个便捷的MySQL导入导出的助手类库。 a mysql import and export helper library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
