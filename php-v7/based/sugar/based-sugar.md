# based/sugar

> 标签: auth, breeze, laravel, tailwind, typescript, vite

## 简介

Minimal Laravel authentication scaffolding with Vue, Vite, Typescript and Tailwind.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
