# bogdan-lapadat-p2c/shopify-dependency-lib

> 标签: PHP

## 简介

SDK to interact with the Shopify API for use by Plentymarkets. Original code is donutdan4114/shopify

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
