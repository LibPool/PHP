# xtntx/cake-jetbrains-test

> 标签: cakephp, idea, phpstorm, phpunit

## 简介

Bridge between CakePHP and Jetbrains IDE test runner

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
