# kanxphp/core

> 标签: integrity, php, polyfill, safe-php, security

## 简介

Secure, future-proofed PHP wrappers for Data Integrity and Security.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
