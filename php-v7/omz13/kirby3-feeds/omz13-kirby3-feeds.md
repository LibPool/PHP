# omz13/kirby3-feeds

> 标签: Sitemap, kirby3, plugin

## 简介

kirby3 plugin to generate syndication feeds (atom, json, rss) from collections

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
