# buggerfall/laravel-amqp-queue

> 标签: AMQP, laravel, queue

## 简介

Laravel queue connector, using the AMQP PECL extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
