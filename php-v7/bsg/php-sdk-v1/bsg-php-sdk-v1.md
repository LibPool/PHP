# bsg/php-sdk-v1

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

Comprehensive API for sending SMS, Viber messages, HLR/MNP requests and service management

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
