# bsg/php-sdk

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

BSG One-API SDK for SMS, Viber, RCS, WhatsApp and messaging services

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
