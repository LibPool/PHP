# blackman-ai/client

> 标签: ai, api, blackman, llm, openai, sdk

## 简介

Official PHP client for Blackman AI - The AI API proxy that optimizes token usage

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
