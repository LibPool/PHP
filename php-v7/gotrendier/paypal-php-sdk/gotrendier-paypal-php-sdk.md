# gotrendier/paypal-php-sdk

> 标签: payments, paypal, rest, sdk

## 简介

PayPal's PHP SDK for REST APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://paypal.github.io/PayPal-PHP-SDK/
- 源码仓库：https://github.com/gotrendier/paypal-php-sdk.git
- Packagist 页面：https://packagist.org/packages/gotrendier%2Fpaypal-php-sdk

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- Composer 安装：`composer require gotrendier/paypal-php-sdk`
- Packagist 仓库：https://repo.packagist.org/p2/gotrendier/paypal-php-sdk.json
- 许可证：Apache-2.0
- PHP 要求：>=5.3.0
