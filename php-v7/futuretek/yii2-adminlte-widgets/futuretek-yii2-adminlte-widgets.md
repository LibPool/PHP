# futuretek/yii2-adminlte-widgets

> 标签: AdminLTE, extension, widget, yii2

## 简介

Widgets for AdminLTE theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
