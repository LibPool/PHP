# dvorakjan/phpsock-connector

> 标签: PHP

## 简介

PHP connector of PHPsock library which mediates WebSocket communication between JS clients and PHP server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
