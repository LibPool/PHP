# cedriclange/ci-phpunit

> 标签: codeigniter, monkey patch, phpunit, test, unit testing

## 简介

An easier way to use PHPUnit with CodeIgniter 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
