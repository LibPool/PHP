# lexik/colissimo-bundle

> 标签: Symfony2, bundle, colissimo

## 简介

This bundle provides a wrapper for the lexik/ws-colissimo library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
