# wildwolf/ww-hide-wplogin

> 标签: login, plugin, security, wordpress

## 简介

A WordPress plugin to hide wp-login.php and use a custom URL for logging in.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
