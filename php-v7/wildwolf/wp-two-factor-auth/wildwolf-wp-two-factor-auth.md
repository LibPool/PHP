# wildwolf/wp-two-factor-auth

> 标签: 2fa, hotp, otp, plugin, security, totp, wordpress

## 简介

WordPress plugin for two factor authentication

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
