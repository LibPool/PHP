# tplxp/curl

> 标签: curl, lxp, php, thinkphp, tp, tp6

## 简介

Thinkphp framework custom curl library developed by lxp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
