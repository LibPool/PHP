# dinkbit/conekta-cashier

> 标签: billing, conekta, dinkbit, laravel

## 简介

Dinkbit Cashier nos da una interface para cobrar subscripciones con Conketa en Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
