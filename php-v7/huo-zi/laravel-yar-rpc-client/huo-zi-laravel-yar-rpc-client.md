# huo-zi/laravel-yar-rpc-client

> 标签: client, laravel, rpc, yar

## 简介

基于Laravel框架服务注册及门面的yar客户端，提供优雅的Yar Rpc服务调用。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
