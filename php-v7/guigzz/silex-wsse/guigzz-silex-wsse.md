# guigzz/silex-wsse

> 标签: Authentication, api, auth, silex, stateless, webservice, wsse

## 简介

Full WSSE authentication for silex projects based on Symfony2 documentation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
