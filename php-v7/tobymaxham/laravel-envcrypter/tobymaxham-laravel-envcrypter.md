# tobymaxham/laravel-envcrypter

> 标签: decrypt, encrypt, laravel, tobymaxham

## 简介

This package can be used to encrypt and decrypt your .env file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
