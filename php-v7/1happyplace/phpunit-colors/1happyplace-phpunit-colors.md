# 1happyplace/phpunit-colors

> 标签: colors, output, phpunit

## 简介

Class that adds color to PHPUnit testing output using ANSI escape coding

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
