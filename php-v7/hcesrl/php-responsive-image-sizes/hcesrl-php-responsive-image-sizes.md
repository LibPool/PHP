# hcesrl/php-responsive-image-sizes

> 标签: PHP

## 简介

Retrieve the correct sizes for a responsive image based on its intrinsic width and its width on screen

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
