# bigcommerce/php-resque-pause

> 标签: PHP

## 简介

php-resque-pause is a PHP port of resque-pause, which adds support for pausing / unpausing Resque jobs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
