# digiaonline/lumen-contentful-sync

> 标签: contentful, lumen, sync, synchronization

## 简介

A framework for synchronizing content from Contentful to a Lumen API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
