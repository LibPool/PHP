# ipip/datx

> 标签: IP, datx, geo, geoip, geolocation, ipip.net

## 简介

IPIP.net官方支持的IP数据库datx格式解析库

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.ipip.net
- 源码仓库：https://github.com/ipipdotnet/datx-php.git
- Packagist 页面：https://packagist.org/packages/ipip%2Fdatx

## 历史版本号

- 当前版本：v0.2.0

- v0.2.0

## 获取地址

- Composer 安装：`composer require ipip/datx`
- Packagist 仓库：https://repo.packagist.org/p2/ipip/datx.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4.0
