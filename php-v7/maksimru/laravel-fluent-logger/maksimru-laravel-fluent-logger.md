# maksimru/laravel-fluent-logger

> 标签: fluent, laravel, log, logging, lumen, stackdriver

## 简介

fluent logger for laravel and lumen with stackdriver support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
