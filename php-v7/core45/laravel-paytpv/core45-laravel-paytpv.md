# core45/laravel-paytpv

> 标签: BankStore, laravel, paytpv

## 简介

Payment module of PAYTPV BankStore IFRAME/FULLSCREEN/XML/JET for Laravel 5.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
