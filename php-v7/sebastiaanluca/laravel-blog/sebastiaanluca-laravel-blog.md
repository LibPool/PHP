# sebastiaanluca/laravel-blog

> 标签: Sebastiaan Luca, blog, laravel

## 简介

A simple-to-use blog system you can pull into any existing Laravel project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
