# suchal/php-paypal-ipn

> 标签: ipn, paypal, php

## 简介

Forked. A class to listen for and handle Instant Payment Notifications (IPN) from the PayPal server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
