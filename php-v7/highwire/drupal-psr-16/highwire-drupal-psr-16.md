# highwire/drupal-psr-16

> 标签: cache, drupal, psr-16

## 简介

Convert Drupal 8 Cache objects to PSR-16 compliant cache objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
