# ressourcenmangel/rsmoembed

> 标签: oembed, soundclud, vimeo, youtube

## 简介

A simple content element to embed elements like facebook, youtube, soundcloud, ...

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
