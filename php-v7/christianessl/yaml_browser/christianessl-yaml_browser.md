# christianessl/yaml_browser

> 标签: extension, typo3

## 简介

Browse and debug YAML definitions in TYPO3 in a similar way to the TypoScript Object Browser.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
