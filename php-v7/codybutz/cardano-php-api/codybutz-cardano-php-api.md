# codybutz/cardano-php-api

> 标签: Guzzle, cardano, cardano-explorer, php

## 简介

An open-source project to allow users to connect to the Cardano API using PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
