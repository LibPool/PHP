# utf6/phalapi-excel

> 标签: excel, phalapi

## 简介

PahlApi2.x 接口框架利用 PHPExcel 处理Excel 文件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
