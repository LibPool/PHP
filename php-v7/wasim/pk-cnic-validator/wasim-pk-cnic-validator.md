# wasim/pk-cnic-validator

> 标签: PHP

## 简介

A PHP package for validating Pakistan CNIC (Computerized National Identity Card) numbers with and without dashes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
