# kadokweb/uploader

> 标签: Image upload, Kadok, KadokWeb, file upload, media upload, upload

## 简介

It is a easy PHP upload manager for images, files and media in your application

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
