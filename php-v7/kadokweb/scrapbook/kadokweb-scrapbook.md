# kadokweb/scrapbook

> 标签: Buffer, Flysystem, apc, buffered, cache, caching, commit, couchbase, filesystem, key, memcached, mitigation, mysql, postgresql, protection, psr-16, psr-6, psr-cache, psr-simple-cache, redis, rollback, sql, sqlite, stampede, store, transaction, transactional, value

## 简介

Scrapbook is a PHP cache library, with adapters for e.g. Memcached, Redis, Couchbase, APC(u), SQL and additional capabilities (e.g. transactions, stampede protection) built on top.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
