# 13dagger/slugify

> 标签: slug, slugify, url

## 简介

String to slug converter with both cyrillic and european languages support. Requires iconv, uses intl if possible.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
