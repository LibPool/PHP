# gcdtech/rhubarb-scaffold-migratable-assets

> 标签: assets, rhubarb

## 简介

Provides a scaffold and an AssetCatalogueProvider allowing for migration of assets between providers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
