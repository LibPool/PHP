# psychicat/monero-php

> 标签: Monero, Poloniex, Shapeshift, cryptocurrency

## 简介

A PHP library for the Monero simplewallet JSON-RPC interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
