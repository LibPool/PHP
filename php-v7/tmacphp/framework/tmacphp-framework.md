# tmacphp/framework

> 标签: TmacPHP, framework

## 简介

The Tmac PHP Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.t-mac.org/
- 源码仓库：https://github.com/wentmac/framework.git
- Packagist 页面：https://packagist.org/packages/tmacphp%2Fframework

## 历史版本号

- 当前版本：v1.0.1

- v1.0.1

## 获取地址

- Composer 安装：`composer require tmacphp/framework`
- Packagist 仓库：https://repo.packagist.org/p2/tmacphp/framework.json
- 许可证：Apache-2.0
- PHP 要求：>=5.1.0
