# grandt/relativepath

> 标签: file path

## 简介

A class for cleaning up/collapsing relative paths. Like real_path, but without the need for the path to exist on the filesystem.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
