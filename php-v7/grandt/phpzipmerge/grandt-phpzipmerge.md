# grandt/phpzipmerge

> 标签: archive, compressed, compression, merge, phpzip, pkzip, stream, zip

## 简介

Merge and stream multiple Zip files on the fly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
