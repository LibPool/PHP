# bravo3/cloud-controller

> 标签: aws, azure, cloud, google cloud

## 简介

A library to control cloud resources on AWS, Google Cloud and Windows Azure

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
