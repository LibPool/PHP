# casterke/simplepay-laravel

> 标签: SimplePay, casterke, laravel, otp, simplepay-laravel

## 简介

OTP SimplePay integration for Laravel applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
