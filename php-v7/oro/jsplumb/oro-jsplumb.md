# oro/jsplumb

> 标签: connectivity, javascript, svg, visual

## 简介

jsPlumb provides a means for a developer to visually connect elements on their web pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
