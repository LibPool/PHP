# crazy-max/cws-crypto

> 标签: bcrypt, blowfish, crypto, password, pbkdf2

## 简介

PHP class for password hashing with multi encryption methods.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
