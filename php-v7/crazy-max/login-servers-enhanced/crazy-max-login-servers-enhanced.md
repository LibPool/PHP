# crazy-max/login-servers-enhanced

> 标签: adminer, login-servers

## 简介

Fork of the official login-servers Adminer plugin with enhancements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
