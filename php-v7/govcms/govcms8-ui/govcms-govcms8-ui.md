# govcms/govcms8-ui

> 标签: govCMS, govCMS8

## 简介

A Drupal 8 theme for govCMS incorporating the DTA UI Kit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
