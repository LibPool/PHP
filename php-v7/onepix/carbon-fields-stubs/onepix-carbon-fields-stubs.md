# onepix/carbon-fields-stubs

> 标签: PHPStan, carbon fields, psalm, static analysis, wordpress

## 简介

Stubs for the Carbon Fields plugin for static analysis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
