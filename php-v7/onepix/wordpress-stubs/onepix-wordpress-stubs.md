# onepix/wordpress-stubs

> 标签: PHPStan, psalm, static analysis, wordpress

## 简介

WordPress function and class declaration stubs for static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
