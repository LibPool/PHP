# ely/php-code-style

> 标签: Code style, php-cs-fixer

## 简介

Set of PHP-CS-Fixer rules used in the development of Ely.by PHP projects

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
