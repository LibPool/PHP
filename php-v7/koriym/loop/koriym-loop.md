# koriym/loop

> 标签: PHP

## 简介

Converts iterable data sets (e.g., database results, CSV files) into an entity list generator with loop context (isFirst, isLast, index, iteration).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
