# fafas/elastica-querybuilder

> 标签: elastica, elasticsearch, search

## 简介

This library provides an easy way to manage several query, filters, aggregation and others in elastica structure

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
