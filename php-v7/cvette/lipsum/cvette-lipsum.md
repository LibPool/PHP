# cvette/lipsum

> 标签: flow, ipsum, lorem, neoscms

## 简介

This Neos plugin adds a 'Lorem Ipsum' node type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
