# maer/oauth2-simple-client

> 标签: PHP

## 简介

Wrapper for league/oauth2-client with a simplified API and possibility to allow/deny e-mail addresses/domains

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
