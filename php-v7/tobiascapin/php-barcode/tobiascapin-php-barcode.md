> 标签: CODE 128, barcode, datamatrix, pdf417, php barcode, qr code, qrcode

## 简介

Fork of Jucksearm Barcode Generation Package inspired by Nicola Asuni.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
