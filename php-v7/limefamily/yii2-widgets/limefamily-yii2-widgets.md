# limefamily/yii2-widgets

> 标签: components, widgets, yii2-widget

## 简介

An asset bundle for bootstrap3-widgets for Yii 2.0 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
