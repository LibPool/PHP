# anh/datetimepicker-bundle

> 标签: PHP

## 简介

Symfony bundle which implements jQuery UI date and time pickers in a Form Type Extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
