# anh/feed-bundle

> 标签: PHP

## 简介

Bundle provides symfony integration of 'anh/feed-builder' library. Building and validating RSS 2.0 and Atom 1.0 feeds.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
