# tanzhenxing/ueditor-thinkphp

> 标签: thinkphp, ueditor, upload

## 简介

Ueditor upload file SDK for ThinkPHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
