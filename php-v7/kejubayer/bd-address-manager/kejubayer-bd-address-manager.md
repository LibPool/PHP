# kejubayer/bd-address-manager

> 标签: address, address hierarchy, bangla english address, bangladesh, bd address, bd address laravel, division district upazila union, dropdown location laravel, geo data, laravel, laravel package, location

## 简介

Laravel package for managing Bangladesh address hierarchy (Division, District, Upazila, Union) with multilingual support, helper functions, and JSON seeder.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
