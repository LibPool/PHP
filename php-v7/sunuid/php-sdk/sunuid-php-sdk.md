# sunuid/php-sdk

> 标签: Authentication, identity, kyc, php, qr-code, sdk, sunuid, verification

## 简介

SDK PHP pour l'intégration des QR codes d'authentification et KYC SunuID

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
