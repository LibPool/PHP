# drmyersii/dingo-api

> 标签: api, dingo, laravel, restful

## 简介

My maintained version of Dingo API, a RESTful API package for the Laravel and Lumen frameworks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
