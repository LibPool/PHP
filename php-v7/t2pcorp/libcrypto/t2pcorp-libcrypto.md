# t2pcorp/libcrypto

> 标签: PHP

## 简介

A PHP library for cryptographic operations with KMS integration, Caching(local,redis) and Secret manager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
