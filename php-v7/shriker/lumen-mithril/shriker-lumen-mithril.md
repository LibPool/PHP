# shriker/lumen-mithril

> 标签: boilerplate, laravel, lumen, lumithril, mithril, mithriljs, starter, template

## 简介

A quick start project template with Lumen and Mithril.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
