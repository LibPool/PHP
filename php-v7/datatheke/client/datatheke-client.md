# datatheke/client

> 标签: datatheke

## 简介

PHP client for the Data Management System Datatheke ([http://www.datatheke.com/](http://www.datatheke.com/))

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
