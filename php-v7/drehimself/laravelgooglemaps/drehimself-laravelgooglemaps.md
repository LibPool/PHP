# drehimself/laravelgooglemaps

> 标签: gmap, google, googlemap, laravel, map

## 简介

Laravel Google Map package for 5.x. You can use all google map features in laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
