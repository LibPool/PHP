# softon/sweetalert

> 标签: POPUP BOXES, laravel 5, sweetalert2

## 简介

Laravel 5 Package for SweetAlert2. Use this package to easily show sweetalert2 prompts in your laravel app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
