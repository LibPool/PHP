# cg-i2ce/ezpublish-kernel

> 标签: PHP

## 简介

eZ Publish API and kernel. This is the heart of eZ Publish 5. This is a v2014.11 kernel, maintained for bugfixes by Netgen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
