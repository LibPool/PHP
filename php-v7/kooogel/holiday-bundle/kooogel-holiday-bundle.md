# kooogel/holiday-bundle

> 标签: bundle, holiday, symfony

## 简介

kooogel/HolidayBundle provides a simple class to get holidays for a specified country

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
