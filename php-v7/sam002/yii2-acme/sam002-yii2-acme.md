# sam002/yii2-acme

> 标签: ACME, certificate, letsencrypt, security, tls, yii2

## 简介

YII2 extension for certificate management using ACME (Automatic Certificate Management Environment)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
