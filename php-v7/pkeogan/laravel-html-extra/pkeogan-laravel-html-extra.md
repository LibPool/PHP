# pkeogan/laravel-html-extra

> 标签: AdminLTE, blade, laravel

## 简介

A Laravel 5.5 Package that expands LaravelCollective/html further with different js plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
