# iotype-ai/sdk

> 标签: OCR, asr, farsi, iotype, nlp, persian, persian-ocr, speech-recognition, speech-to-text, text-to-speech, translation, tts

## 简介

Official PHP SDK for iotype (iotype.com) — Persian, English and Arabic speech recognition, OCR, translation and text-to-speech.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/iotype-ai/iotype-api.git
