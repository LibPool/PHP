# tecsin/yii2-tinymce

> 标签: extension, tinymce, yii2

## 简介

TinyMCE extension for Yii2, with elFinder as its file picker features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
