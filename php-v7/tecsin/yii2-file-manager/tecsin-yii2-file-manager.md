# tecsin/yii2-file-manager

> 标签: elfinder, extension, file, tecsin, tinymce, wysiwyg, yii2

## 简介

A file manager on elFinder 2.1.20 and TinyMCE 4 for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
