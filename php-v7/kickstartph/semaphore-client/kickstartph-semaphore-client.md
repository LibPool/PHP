# kickstartph/semaphore-client

> 标签: api, client, rest, semaphore, sms, web service

## 简介

A wrapper for accessing the Semaphore SMS API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
