# urguardian4ngel/flarum-ext-fb-crawler

> 标签: crawler, facebook, seo

## 简介

An extension that allows the Facebook Crawler to crawl protected pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
