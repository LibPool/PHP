# alexstewartja/laravel-attribute-observer

> 标签: alexstewartja, laravel, laravel-attribute-observer

## 简介

Observe (and react to) attribute changes made on Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
