# icecave/collections

> 标签: array, collection, container, hash, map, queue, sequence, stack

## 简介

A PHP collection library loosely inspired by the .NET runtime and the C++ STL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
