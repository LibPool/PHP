# icecave/traitor

> 标签: code, generate, interface, mock, mocking, testing, trait

## 简介

Compose new classes using interfaces and traits at runtime.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
