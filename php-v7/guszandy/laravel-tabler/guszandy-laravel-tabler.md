# guszandy/laravel-tabler

> 标签: composer, laravel, package, tabler

## 简介

Laravel Package for integrating Tabler template and this package is Laravel Mix friendly.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
