# venkatesh-kcet/url_analyzer

> 标签: Extracts URLS, analyzer, composer, composer-package, php, url

## 简介

Extracts useful data from urls (domain, subdomains, top level ...)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
