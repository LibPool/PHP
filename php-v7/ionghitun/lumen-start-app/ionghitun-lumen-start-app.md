# ionghitun/lumen-start-app

> 标签: boilerplate, framework, ionghitun, laravel, lumen

## 简介

Boilerplate for laravel lumen framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
