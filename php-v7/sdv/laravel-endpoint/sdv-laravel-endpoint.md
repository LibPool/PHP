# sdv/laravel-endpoint

> 标签: api, laravel, rest, scaffolding, search

## 简介

Laravel Endpoint is a CRUD REST API package for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
