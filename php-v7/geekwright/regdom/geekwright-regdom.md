# geekwright/regdom

> 标签: public, regdom, suffix, tld

## 简介

OO adaptation of Florian Sager's regdom library for querying Mozilla Public Suffix List

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
