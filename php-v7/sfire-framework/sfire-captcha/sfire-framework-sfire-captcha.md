# sfire-framework/sfire-captcha

> 标签: captcha, framework, image, images, sFire, validation, verification

## 简介

Turing test to tell computers and humans apart made easy with sFire captcha.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
