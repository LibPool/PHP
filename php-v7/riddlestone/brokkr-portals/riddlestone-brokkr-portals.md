# riddlestone/brokkr-portals

> 标签: brokkr, config, laminas

## 简介

A Laminas module to pull configuration together for portals, such as a public portal, an admin portal, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
