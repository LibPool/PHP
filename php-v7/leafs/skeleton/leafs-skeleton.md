# leafs/skeleton

> 标签: framework, leaf, leaf api, leafPHP

## 简介

A boiler-plate application for rapid development with Leaf PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
