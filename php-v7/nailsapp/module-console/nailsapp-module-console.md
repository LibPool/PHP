# nailsapp/module-console

> 标签: Console Module, Nails, Shed Collective, cli, codeigniter

## 简介

This is the "Console" module for Nails.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
