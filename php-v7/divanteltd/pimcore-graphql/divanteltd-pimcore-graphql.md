# divanteltd/pimcore-graphql

> 标签: bundle, graphql, pimcore

## 简介

Graphql Bundle for Pimcore 5. Adding possibility to manipulate DataObject through graphQl.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
