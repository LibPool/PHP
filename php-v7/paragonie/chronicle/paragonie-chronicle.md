# paragonie/chronicle

> 标签: BLAKE2, BLAKE2b, append-only, blakechain, cryptography, hash, hash-chain, sapient, security

## 简介

Public hash chain powered by Slim Framework, Sapient, and Blakechain

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
