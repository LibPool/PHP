# nystudio107/retour

> 标签: PHP

## 简介

Retour allows you to intelligently redirect legacy URLs, so that you don't lose SEO value when rebuilding & restructuring a website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
