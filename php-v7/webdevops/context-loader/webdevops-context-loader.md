# webdevops/context-loader

> 标签: TYPO3 CMS

## 简介

Context configuration loader for TYPO3 (TYPO3_CONTEXT)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
