# mpratt/simple-lifestream

> 标签: life-stream, lifestream, lifestreaming

## 简介

A library that returns lifestream events from a bunch of social sites/services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
