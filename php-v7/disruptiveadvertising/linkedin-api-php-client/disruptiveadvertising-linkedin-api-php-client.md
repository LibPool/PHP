## 简介

LinkedIn API PHP SDK with OAuth 2.0 & CSRF support. Can be used for social sign in or sharing on LinkedIn. Examples. Documentation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
