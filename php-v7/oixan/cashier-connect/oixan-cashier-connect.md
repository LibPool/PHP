# oixan/cashier-connect

> 标签: billing, laravel, stripe

## 简介

Laravel Cashier Connect add support for Stripe Connect to Laravel Cashier.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
