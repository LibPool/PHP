# devture/silex-db-migrations-bundle

> 标签: bundle, database, migrations, phinx, silex

## 简介

Silex bundle that provides DB migrations (powered by Phinx)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
