# divinity76/php-httpreadfile

> 标签: HTTP 206 Partial Content, HTTP 304 Not Modified, readfile

## 简介

readfile() with 304 Not Modified and 206 Partial Content support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
