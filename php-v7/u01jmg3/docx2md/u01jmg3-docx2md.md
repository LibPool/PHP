# u01jmg3/docx2md

> 标签: conversion, docx, markdown, md

## 简介

Convert Microsoft Word files (.docx) to Markdown files (.md)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
