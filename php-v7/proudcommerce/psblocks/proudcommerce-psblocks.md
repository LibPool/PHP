# proudcommerce/psblocks

> 标签: OXID, admin, blocks, modules

## 简介

psBlocks - Module for managing oxid template blocks in shop admin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
