# vishwac09/authzero

> 标签: PHP

## 简介

Integrate Drupal 9/10 website with the Auth0 Single Sign-On (SSO) platform.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
