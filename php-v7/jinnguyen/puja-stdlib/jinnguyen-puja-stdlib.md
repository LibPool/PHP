# jinnguyen/puja-stdlib

> 标签: Standard lib, file system, filesystem, folder, puja

## 简介

Puja-Stdlib provides basic functions such as File,Folder and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
