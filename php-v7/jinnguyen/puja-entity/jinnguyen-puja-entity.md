# jinnguyen/puja-entity

> 标签: entity, puja

## 简介

Puja-Entity is an abstract layer to manage a entity object and easy to get the Docblock document

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
