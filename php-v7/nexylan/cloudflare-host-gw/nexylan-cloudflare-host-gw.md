# nexylan/cloudflare-host-gw

> 标签: Hosting Provider, api, cloudflare, sdk

## 简介

A PHP sdk to communicate with CloudFlare Hosting Provider API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
