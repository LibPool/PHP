# hskrasek/laravel-async-beanstalkd

> 标签: async, beanstalkd, laravel

## 简介

Provides an asynchronous beanstalkd queue driver for the Laravel framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
