# kuba93/datagrid

> 标签: datagrid, grid, nette

## 简介

DataGrid for Nette Framework: filtering, sorting, pagination, tree view, table view, translator, etc

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
