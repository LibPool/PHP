# nmrkt/guzzle5-oauth2-subscriber

> 标签: Guzzle, guzzle4, oauth, oauth2, provider, subscriber

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
