# yqcode/querylist-ext-phantomjs

> 标签: PHP

## 简介

QueryList V3 Plugin: Use PhantomJS to crawl Javascript dynamically rendered pages.(headless WebKit )

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
