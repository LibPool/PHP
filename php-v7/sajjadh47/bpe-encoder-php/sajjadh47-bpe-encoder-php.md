# sajjadh47/bpe-encoder-php

> 标签: PHP

## 简介

BPE (Byte-Pair Encoding) Encoder Decoder for OpenAI's GPT-2 / GPT-3 Implemented In Pure PHP, Zero Dependency, Multi Byte Supported.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
