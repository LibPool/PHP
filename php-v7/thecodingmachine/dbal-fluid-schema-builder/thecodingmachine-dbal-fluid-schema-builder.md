# thecodingmachine/dbal-fluid-schema-builder

> 标签: PHP

## 简介

Build and modify your database schema using Doctrine DBAL and a fluid syntax.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
