# thecodingmachine/tdbm-graphql

> 标签: PHP

## 简介

A class generator that will generate GraphQL types from your database schema (using thecodingmachine/graphqlite).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
