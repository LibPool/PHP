# ballen/distical

> 标签: calculator, distance, gps, lat, latitude, lng, long, longditude, mapping

## 简介

A distance (Lat/Long) calculation library for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
