# belniakmedia/craft-allow-nbsp-twig-filter

> 标签: Craft, allow nbsp twig filter, cms, craft-plugin, craftcms

## 简介

Unescape escaped nbsp entities via twig filter.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
