# aichenk/phalcon-server

> 标签: PHP

## 简介

以phalcon框架作为服务代码模板，支持restful，包含api模块及cli模块，controller仅作预留

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
