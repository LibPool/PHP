# austin/kunaki-api-laravel

> 标签: kunaki, laravel

## 简介

A PHP implementation of Kunaki.com's HTTP API for Laravel applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
