# kdion4891/laravel-livewire-tables

> 标签: PHP

## 简介

A dynamic, responsive Laravel Livewire table component with searching, sorting, checkboxes, and pagination.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
