# zhongshaofa/easyadmin

> 标签: admin, easyadmin, thinkphp

## 简介

基于ThinkPHP6.0和layui的快速开发的后台管理系统。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
