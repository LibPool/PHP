# bunny-launcher/bunny-sdk

> 标签: Bunny.net, api, bunny, bunny-launcher, bunnyCDN, cdn, sdk

## 简介

PHP SDK for bunny.net 🐰

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
