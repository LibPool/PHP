# yogeshkoli/user-ip

> 标签: Get Current user IP Address, PHP IP Address, REMOTE_ADDR, ip address

## 简介

PHP Class to get active user IP Address.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
