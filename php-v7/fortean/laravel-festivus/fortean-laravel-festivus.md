# fortean/laravel-festivus

> 标签: Guzzle, festivus, laravel, rest

## 简介

Festivus: A Guzzle-based REST client for Laravel with packaged service descriptions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
