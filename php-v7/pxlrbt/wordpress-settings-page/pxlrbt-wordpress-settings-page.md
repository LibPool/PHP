# pxlrbt/wordpress-settings-page

> 标签: Settings, library, options, wordpress, wp

## 简介

WordPress package for use in plugins or themes to handle WordPress settings pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
