# snipe/safebrowsing

> 标签: Snipe, google, malware, rbl, safebrowsing, url

## 简介

Laravel package to allow you to easily integrate the Google Safebrowing API into your application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
