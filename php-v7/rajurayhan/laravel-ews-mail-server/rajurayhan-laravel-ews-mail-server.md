# rajurayhan/laravel-ews-mail-server

> 标签: PHP

## 简介

Send Email from Laravel using Microsoft Exchange Web Services (EWS).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
