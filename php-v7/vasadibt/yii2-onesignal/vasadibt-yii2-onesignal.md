# vasadibt/yii2-onesignal

> 标签: api, extension, notifications, onesignal, restful, yii2

## 简介

This is a restful api to onesignal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
