# alexey-kupershtokh/opcode-cli

> 标签: Opcache, apc, cache, cli, fastcgi, opcode

## 简介

A tool for interacting with php opcode cache (APC or OpCache) from command line.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
