# nordsoftware/lumen-dynamodb

> 标签: PHP

## 简介

DynamoDB module for Lumen framework. Based on https://github.com/baopham/laravel-dynamodb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
