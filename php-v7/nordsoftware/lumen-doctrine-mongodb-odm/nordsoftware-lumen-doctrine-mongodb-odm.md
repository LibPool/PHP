# nordsoftware/lumen-doctrine-mongodb-odm

> 标签: PHP

## 简介

Doctrine MongoDB ODM module for the Lumen PHP framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
