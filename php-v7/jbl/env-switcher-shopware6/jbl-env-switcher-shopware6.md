# jbl/env-switcher-shopware6

> 标签: PHP

## 简介

A Simple Plug-In which allows the shop administrator to switch between dev <-> prod mode without touching .env file.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
