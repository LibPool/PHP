# losthost/swanctl-server

> 标签: PHP

## 简介

A view of swanctlModel on a vpn-server created with https://github.com/jawj/IKEv2-setup#vpn-server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
