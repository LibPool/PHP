# xzhiyu/thinkphp-qiniu-sdk

> 标签: PHP

## 简介

基于tp5.1的七牛云sdk，实现了文件上传与文件管理

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
