# phpterminal/phpterminal-plugins-auth

> 标签: php, terminal

## 简介

PHPTerminal-plugins-auth is an authentication plugin for phpterminal application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
