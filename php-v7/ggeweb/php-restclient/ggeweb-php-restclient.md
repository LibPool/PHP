# ggeweb/php-restclient

> 标签: api, client, curl, json, rest, xml

## 简介

A generic REST API client for PHP (Forked from tcdent/php-restclient)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
