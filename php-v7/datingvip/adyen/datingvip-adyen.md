# datingvip/adyen

> 标签: HPP, adyen, api, payment

## 简介

DatingVIP PHP implementation of the Adyen Hosted Payment Pages (HPP)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
