# klinson/aws-s3-minio

> 标签: aws, cloud, klinson, minio, s3

## 简介

Flexible and feature-complete minio client for PHP, depend on aws/aws-sdk-php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
