# klinson/ms-xiaoice

> 标签: Intel MKL-DNN, big data, klinson, microsoft, msxiaobing, xiaobing, xiaoice, 大数据, 小冰, 微软, 深度神经网络

## 简介

基于微软小冰实现接口，微软小冰使用深度神经网络和大数据训练进行对图片的科学鉴定，如评分、计算年龄

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
