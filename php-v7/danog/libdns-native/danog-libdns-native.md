# danog/libdns-native

> 标签: dns, dns_get_record, message, native function, php

## 简介

Encoder/decoder for PHP's dns_get_record raw format based on libdns

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
