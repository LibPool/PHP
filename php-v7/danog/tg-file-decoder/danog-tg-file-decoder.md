# danog/tg-file-decoder

> 标签: audio, bot api, file ID, files, mtproto, stickers, telegram, video

## 简介

Decode Telegram bot API file IDs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
