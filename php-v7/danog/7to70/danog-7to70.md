# danog/7to70

> 标签: 7to70, PHP7, abstract, convert, spatie, syntax, tree

## 简介

Convert PHP 7 code to PHP 7.0 code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
