# yiisoft/yii2-redis

> 标签: Redis, active-record, cache, redis, session, yii2, 缓存

## 简介

Redis Cache, Session and ActiveRecord for the Yii framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
