# trollandtoad/fpdf

> 标签: fpdf, pdf

## 简介

I took the original FPDF library made by Oliver Plathey and refactored it to use PSR-4 autloading. This version corresponds with the fpdf 1.8.1.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
