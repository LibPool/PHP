# mrpck/mysqldb

> 标签: ConnectionString, MySqlDB, database, dbconnection, laravel, mysql

## 简介

The MySqlDB Class Library is a high level wrapper around the MySql.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
