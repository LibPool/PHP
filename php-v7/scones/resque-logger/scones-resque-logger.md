# scones/resque-logger

> 标签: Tasks, message queue, psr-12, queue, resque, task queue

## 简介

resque-logger is a psr/log plugin for scones/resque to log all events

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
