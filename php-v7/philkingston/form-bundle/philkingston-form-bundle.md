# philkingston/form-bundle

> 标签: form

## 简介

Provides Twitter Bootstrap form theme, a help type extension, Ajax/Tunnel/Select2 entity form types and javascript helpers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
