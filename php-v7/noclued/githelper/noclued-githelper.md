# noclued/githelper

> 标签: PHP

## 简介

Helper for git extra info like 'get file names changed in last two commits', 'get new lines from last two commits', etc. You need to have accessable git!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
