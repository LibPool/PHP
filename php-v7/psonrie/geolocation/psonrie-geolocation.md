# psonrie/geolocation

> 标签: IP, freegeoip, geo, geo-location, geoip, laravel, location, php

## 简介

Laravel service provider to retrieve a users location by their IP Address

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
