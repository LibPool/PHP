# huysynf/laravel-mcp-laravel8

> 标签: laravel, mcp

## 简介

Laravel MCP backported for Laravel 8+ support. Rapidly build MCP servers for your Laravel applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
