# norbertjurga/php-jwt

> 标签: jwt, php

## 简介

Forked firebase/php-jwt library to encode and decode JSON Web Tokens (JWT) in PHP with empty payload support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
