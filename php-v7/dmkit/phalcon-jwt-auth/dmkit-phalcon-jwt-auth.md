# dmkit/phalcon-jwt-auth

> 标签: Authentication, jwt, phalcon

## 简介

A simple JWT middleware for Phalcon Micro to handle stateless authentication

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
