# hubmais/h-plugin-waha

> 标签: hubmais, laravel, notifications, waha

## 简介

Plugin Laravel to send notification to WhatsApp via Waha

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
