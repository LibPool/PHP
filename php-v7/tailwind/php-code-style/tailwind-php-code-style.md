# tailwind/php-code-style

> 标签: code sniffer, phpcs, squizlabs

## 简介

A SquizLabs Code Sniffer 3 coding standard and set of rules for Tailwind's PHP codebase.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
