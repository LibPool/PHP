# wireframe-framework/site-wireframe-boilerplate

> 标签: processwire, site-profile

## 简介

A ProcessWire starter site profile based on the wireframe output framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
