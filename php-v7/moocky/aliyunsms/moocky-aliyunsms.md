# moocky/aliyunsms

> 标签: AliyunSMS, alibabacloud, dysmsapi, laravel, lumen, php, sms

## 简介

基于alibabacloud/dysmsapi-20170525 接入短信服务

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
