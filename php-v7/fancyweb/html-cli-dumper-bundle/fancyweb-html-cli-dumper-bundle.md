# fancyweb/html-cli-dumper-bundle

> 标签: console, dump, html, var-dumper

## 简介

Symfony bundle to view cli dumps as HTML dumps in your browser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
