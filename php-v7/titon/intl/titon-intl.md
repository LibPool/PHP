# titon/intl

> 标签: bundle, catalog, domain, g11n, globalization, i18n, internationalization, intl, l10n, locale, localization, message, resource, titon, translate

## 简介

The Intl package provides tools for the localization and internationalization of an application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
