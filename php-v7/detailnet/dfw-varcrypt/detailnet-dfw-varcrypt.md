# detailnet/dfw-varcrypt

> 标签: detailnet, dfw, encryption, environment, variables

## 简介

DETAIL Framework library for working with encrypted environment variables

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
