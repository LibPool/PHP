# detailnet/dfw-apigility-module

> 标签: apigility, detailnet, dfw, module, zf

## 简介

Zend Framework Module containing tools for ZF Apigility

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
