# prolic/humus-mvc

> 标签: ZF1, humus, mvc, zf2

## 简介

HumusMvc integrated ZF2's ModuleManager and ServiceManager in a ZF1 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
