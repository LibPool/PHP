# fzizmann/phantomjs-2.1.1-linux-win-x64

> 标签: binary, linux, phantomjs, win, x64

## 简介

PhantomJS static linked binary for 64 bit linux and windows systems.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
