# kitzberger/dragon-drop

> 标签: TYPO3 CMS

## 简介

ViewHelper to add 'copy-paste' to EXT:mask containers in the page module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
