# kitzberger/cli-toolbox

> 标签: TYPO3 CMS

## 简介

TYPO3 CLI toolbox: run copy/move/delete commands of DataHandler via CLI'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
