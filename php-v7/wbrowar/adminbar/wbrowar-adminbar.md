# wbrowar/adminbar

> 标签: Craft, admin bar, admin toolbar, admin-bar, author experience, ax, cms, craft-plugin, craftcms, toolbar

## 简介

Front-end shortcuts for clients logged into Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
