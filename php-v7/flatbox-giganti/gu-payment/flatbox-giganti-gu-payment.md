# flatbox-giganti/gu-payment

> 标签: billing, iugu, laravel, pagamentos

## 简介

GuPayment fornece uma interface para controlar assinaturas do iugu.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
