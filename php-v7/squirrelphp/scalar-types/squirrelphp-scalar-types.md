# squirrelphp/scalar-types

> 标签: coercions, php, scalar

## 简介

Make the coercive mode and strict mode behavior of PHP accessible explicitly via functions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
