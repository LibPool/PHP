# torresani/redirectanalytics

> 标签: PHP

## 简介

Tracks TYPO3 redirects via Google Analytics 4 Measurement Protocol (server-side)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
