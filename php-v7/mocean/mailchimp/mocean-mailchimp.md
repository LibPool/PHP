# mocean/mailchimp

> 标签: email, mailchimp, mocean, sms

## 简介

Mailchimp Integration with Mocean API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://moceanapi.com
- 源码仓库：https://github.com/MoceanAPI/mocean-mailchimp.git
- Packagist 页面：https://packagist.org/packages/mocean%2Fmailchimp
