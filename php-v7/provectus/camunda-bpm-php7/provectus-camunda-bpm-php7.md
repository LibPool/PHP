# provectus/camunda-bpm-php7

> 标签: camunda, camunda bpm, sdk

## 简介

PHP 7.x SDK for camundaBPM process services by Provectus inc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
