# globus-studio/fatfree-core

> 标签: PHP

## 简介

A powerful yet easy-to-use PHP micro-framework designed to help you build dynamic and robust Web applications - fast!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
