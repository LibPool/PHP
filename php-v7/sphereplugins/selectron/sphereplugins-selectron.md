# sphereplugins/selectron

> 标签: PHP

## 简介

A package to add admin tab for the hooks and filter as well as query selector for various frontend rendering at third party themes reliably

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
