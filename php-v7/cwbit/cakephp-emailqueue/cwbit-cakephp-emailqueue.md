# cwbit/cakephp-emailqueue

> 标签: PHP

## 简介

A configurable, queue-based plugin for queuing and sending Emails in CakePHP 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
