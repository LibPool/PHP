# superduperbundle/game-prices

> 标签: api client, deals, game keys, game prices, price comparison, steam

## 简介

PHP client for the free SuperDuperBundle Game Price API: lowest listed PC game key prices by name, Steam app ID or store URL.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
