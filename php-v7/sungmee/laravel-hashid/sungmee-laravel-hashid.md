# sungmee/laravel-hashid

> 标签: hash, laravel, packages

## 简介

为 Laravel 量身定制的类似 Youtube 上的 ID（数字）加密解密扩展包。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
