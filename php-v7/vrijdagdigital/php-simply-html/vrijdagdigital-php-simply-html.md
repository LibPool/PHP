# vrijdagdigital/php-simply-html

> 标签: css, html, selector, xml

## 简介

Simplify add, delete, modify, get nodes in html files by using css selector

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
