# etc-plugins/etc_datepicker

> 标签: datepicker, plugin, textpattern

## 简介

Datepicker UI widget for Textpattern CMS administration panels.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
