# smoren/array-view

> 标签: array, array-index, array-view, array-viewer, collection, collections, data-view, indexing, negative, negative-indexes, python-like, range, selector, slice, slicing, view

## 简介

Create array views for easy data manipulation, select elements using Python-like slice notation, enable efficient selection of elements using index lists and boolean masks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
