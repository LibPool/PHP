# sussexdev/module-sampleuicomponent

> 标签: PHP

## 简介

A Magento 2 sample module demonstrating how to implement a grid and form UI Component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
