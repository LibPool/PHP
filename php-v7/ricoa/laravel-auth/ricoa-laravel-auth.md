# ricoa/laravel-auth

> 标签: laravel, menu, permission

## 简介

一个基于 Laravel5 的后台权限、菜单管理解决方案

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
