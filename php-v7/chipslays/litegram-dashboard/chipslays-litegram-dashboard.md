# chipslays/litegram-dashboard

> 标签: bot, dashboard, litegram, telegram

## 简介

Ready-to-use dashboard bots manager based on Litegram library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
