# strapless/icons

> 标签: css, deviscoding, font, icons, sass, scss, strapless, svg

## 简介

CSS Classes, Mixins and Functions to manage icons in CSS and SCSS projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
