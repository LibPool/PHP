# wikifab/wikifab-style-module

> 标签: Chameleon, Wikifab, bootstrap, mediawiki, skin, twitter, wiki

## 简介

Skin for wikifab based on chameleon skin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
