# wikifab/page-loading-spinner

> 标签: PHP

## 简介

This is a mediawiki extension to add a loding spinner while edit page is net yet fully loaded

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
