# qqchen/dify-laravel

> 标签: ai, dify, laravel, llm, sdk

## 简介

Dify SDK for Laravel, supporting Knowledge Base and Chat APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
