# powerbuoy/sleek-menu

> 标签: PHP

## 简介

Cleans up the menu HTML by removing IDs and redundant classes. Also fixes active-classes on post type and taxonomy archives.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
