# unoapp-dev/omnipay-cardconnect

> 标签: cardconnect, gateway, merchant, omnipay, pay, payment, payments

## 简介

Cardconnect driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
