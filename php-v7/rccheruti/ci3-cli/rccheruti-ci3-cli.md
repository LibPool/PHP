# rccheruti/ci3-cli

> 标签: cli, codeigniter, codeigniter3, generator

## 简介

Ferramenta de linha de comando para CodeIgniter 3, inspirada no Artisan.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
