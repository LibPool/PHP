# uitm/laravel-arabic-html

> 标签: arabic, arabic-calendar, arabic-dompdf, arabic-glyphs, arabic-html

## 简介

Convert laravel view to arabic html (pdf) by using ArPHP and dompdf with arabic fonts and text. Forked from abalselwi/laravel-arabic-html to Support Laravel 11 and 12.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
