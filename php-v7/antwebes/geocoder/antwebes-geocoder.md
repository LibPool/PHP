# antwebes/geocoder

> 标签: abstraction, geocoder, geocoding, geoip

## 简介

The almost missing Geocoder PHP 5.3 library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
