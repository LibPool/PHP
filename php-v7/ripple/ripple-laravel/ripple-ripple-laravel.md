# ripple/ripple-laravel

> 标签: Broadcasting, WebSockets, laravel, pusher, realtime

## 简介

Laravel broadcasting driver + CLI for the ripple WebSocket server (Pusher-compatible).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
