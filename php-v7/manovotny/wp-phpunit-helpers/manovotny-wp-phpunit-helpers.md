# manovotny/wp-phpunit-helpers

> 标签: phpunit, test, tests, wordpress

## 简介

Simple PHPUnit helpers for testing WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
