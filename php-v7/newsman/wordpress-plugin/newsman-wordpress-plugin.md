# newsman/wordpress-plugin

> 标签: email, marketing, newsletter, newsman, remarketing, search, subscriber, woocommerce, wordpress

## 简介

Newsman plugin for WordPress and WooCommerce.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
