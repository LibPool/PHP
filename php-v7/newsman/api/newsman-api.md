# newsman/api

> 标签: email marketing, newsman

## 简介

Newsman.app PHP API 1.2 wrapper. Easy manage your newsman.app subscribers, newsletters and segments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
