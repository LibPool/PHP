# jorijn/bitcoin-bolt11

> 标签: bitcoin, bolt11, lightning-network

## 简介

A library for decoding lightning network payment requests as defined in BOLT #11

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
