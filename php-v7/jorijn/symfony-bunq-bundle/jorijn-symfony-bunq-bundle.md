# jorijn/symfony-bunq-bundle

> 标签: PHP

## 简介

A Symfony 3.4 LTS compatible Bundle for interaction with the European bunq bank

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
