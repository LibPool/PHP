# klei/phut

> 标签: TDD, testing, unit test

## 简介

A small and simple unit testing framework for PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://klei.se/phut
- 源码仓库：https://github.com/klei/phut.git
- Packagist 页面：https://packagist.org/packages/klei%2Fphut
