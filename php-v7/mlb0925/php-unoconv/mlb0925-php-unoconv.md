# mlb0925/php-unoconv

> 标签: unoconv

## 简介

Unoconv PHP, an Object Oriented library for easy file conversion with LibreOffice's unoconv

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
