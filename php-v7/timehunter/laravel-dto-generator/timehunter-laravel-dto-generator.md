# timehunter/laravel-dto-generator

> 标签: LaravelDTOGenerator, array to json, array to model, class generator, dto, dto generator, json generator, json to class, json to model, laravel, model generator, php dto geneeator

## 简介

A generator that creates PHP Data Transfer Object by array schema.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
