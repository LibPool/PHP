# ignited/laravel-sns-broadcaster

> 标签: Broadcasting, SNS, aws, laravel

## 简介

Sns Messages as queues using extended laravel sqs driver.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
