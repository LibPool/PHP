# astepin/rabbitmq-module

> 标签: AMQP, Zend Framework, rabbitmq, zend module, zf2, zf3

## 简介

Integrates php-amqplib with Zend Framework 3 and RabbitMq

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
