# fucodo/dialog-overlay

> 标签: PHP

## 简介

Container-CE mit HTML5-Dialog (modal) + Web Component (Cookie-gesteuert).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
