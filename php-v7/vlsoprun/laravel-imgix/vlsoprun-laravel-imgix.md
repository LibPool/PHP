# vlsoprun/laravel-imgix

> 标签: cdn, image, images, imgix, laravel

## 简介

Support for laravel imgix client library for generating URLS with imgix.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
