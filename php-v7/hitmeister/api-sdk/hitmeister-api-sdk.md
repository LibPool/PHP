# hitmeister/api-sdk

> 标签: api, hitmeister, kaufland, kaufland-sdk, kaufland.de, real-digital, real.de, real.digital, sdk

## 简介

Kaufland.de onlineshop API SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.kaufland.de/api/v1/
- 源码仓库：https://github.com/hitmeister/api-sdk-php.git
