# hkp22/laravel-bannable

> 标签: ban, block, eloquent, forbid, laravel, restrict, user

## 简介

Laravel bannable package is for blocking and banning Eloquent models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
