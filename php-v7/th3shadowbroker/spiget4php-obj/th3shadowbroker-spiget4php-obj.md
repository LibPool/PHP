# th3shadowbroker/spiget4php-obj

> 标签: PHP

## 简介

An optional extension for spiget4php providing different objects to work with the Spiget-API results.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
