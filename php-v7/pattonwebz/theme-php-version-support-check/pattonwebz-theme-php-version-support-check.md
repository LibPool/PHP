# pattonwebz/theme-php-version-support-check

> 标签: PHP

## 简介

A class used to do PHP version checking on theme activation and revert if min PHP version not met.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
