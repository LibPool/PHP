# gooddaywp/primera

> 标签: babel, blade, laravel, mix, theme, woocommerce, wordpress, wp

## 简介

A modern starter theme for WordPress using Laravel's Blade templating engine.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
