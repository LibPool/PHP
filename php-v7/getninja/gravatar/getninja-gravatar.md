# getninja/gravatar

> 标签: Api Wrapper, PSR-2, gravatar

## 简介

A flexible, gravatar API wrapper for Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/GetNinja/Gravatar
- 源码仓库：https://github.com/dryhopped/Gravatar.git
- Packagist 页面：https://packagist.org/packages/getninja%2Fgravatar
