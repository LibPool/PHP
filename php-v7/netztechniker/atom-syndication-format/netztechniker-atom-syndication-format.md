# netztechniker/atom-syndication-format

> 标签: RFC 4287, atom, developer, feed

## 简介

Models the RFC 4287 specification (Atom Syndication Format).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
