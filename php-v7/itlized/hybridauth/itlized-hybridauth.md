# itlized/hybridauth

> 标签: OpenId, facebook, google, hybridauth, itlized, login, oauth, social, twitter, yahoo

## 简介

Open source social sign on PHP library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
