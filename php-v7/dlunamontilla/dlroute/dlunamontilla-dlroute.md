# dlunamontilla/dlroute

> 标签: PHP

## 简介

Sistema de enrutamiento para usar en DLUnire o cualquier otro proyecto.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
