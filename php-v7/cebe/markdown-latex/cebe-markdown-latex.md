# cebe/markdown-latex

> 标签: extensible, fast, gfm, latex, markdown, markdown-extra

## 简介

A super fast, highly extensible markdown parser for PHP, that converts markdown files into latex

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
