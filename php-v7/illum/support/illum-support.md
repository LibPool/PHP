# illum/support

> 标签: PHP

## 简介

versão simplificada do Illuminate/Support sem muitas das dependencias originais. baseado em clarkeash/str

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
