# profburial/wkhtmltopdf-binaries-wheezy

> 标签: binary, pdf, wkhtmltopdf

## 简介

All the wkhtmltopdf binaries for Debian Wheezy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
