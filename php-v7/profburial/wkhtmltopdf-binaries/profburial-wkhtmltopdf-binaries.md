# profburial/wkhtmltopdf-binaries

> 标签: binary, convert, pdf, snapshot, thumbnail, wkhtmltopdf

## 简介

All the binaries for wkhtmltopdf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
