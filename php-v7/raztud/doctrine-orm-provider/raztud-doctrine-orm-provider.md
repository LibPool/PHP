# raztud/doctrine-orm-provider

> 标签: database, doctrine, extension, orm, provider, silex

## 简介

Simple Doctrine ORM provider for Silex

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
