# acdh-oeaw/arche-biblatex

> 标签: PHP

## 简介

ARCHE dissemination service generating CSL-formatted citations as well as CSL-JSON and BibLaTeX bibliographic entries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
