# byjg/anydataset-sparql

> 标签: PHP

## 简介

Anydataset SparQL abstraction. Anydataset is an agnostic data source abstraction layer in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
