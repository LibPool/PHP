# project-a/silex-routing

> 标签: PHP

## 简介

Silex-Routing provides advanced routing for Silex through connecting symfony-cmf/Routing with Silex.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
