# chamilo/settings-bundle

> 标签: Settings, config, configuration, ecommerce, shop, webshop

## 简介

Settings system for Symfony applications, editable via web user interface.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
