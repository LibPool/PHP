# websightnl/gearman

> 标签: Tasks, daemon, gearman, jobs, workers

## 简介

PHP library for dispatching, handling and managing Gearman Workers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
