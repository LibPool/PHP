# macx/rfc-4122-uuid

> 标签: RFC-4122, php, uuid

## 简介

PHP-Class to generate valid RFC 4122 compliant Universally Unique IDentifiers (UUID) version 3, 4 and 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
