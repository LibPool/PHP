# kosv/yii2-grid-roweditable

> 标签: editor, extension, grid, kosv, row, widget, yii2

## 简介

Extension for editing rows for yii2 grid widget.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
