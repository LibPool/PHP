# coreproc/laravel-docker-internal-install-command

> 标签: PHP

## 简介

Provides your Laravel app with baseline Docker files for use in CoreProc internal environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
