# zhengbingdong/ip-addrs

> 标签: PHP

## 简介

无需注册, 完全免费IP归属地查询API,快速查询IP地址的地理位置、运营商等信息,不限量，随便用

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
