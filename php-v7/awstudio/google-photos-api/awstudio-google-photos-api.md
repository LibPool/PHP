# awstudio/google-photos-api

> 标签: PHP

## 简介

Google Photos API using Picasa endpoints. Let You get Albums, Pictures and Videos of Users with the acces token

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
