# lemonbrain/concrete5_graphql_websocket_security

> 标签: PHP

## 简介

GraphQL and websocket secure package that is installable via composer for concrete 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
