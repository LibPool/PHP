# dockcodes/dockaccess-alt-generator

> 标签: accessibility, ai, alt text, dockaccess, image, wcag

## 简介

Framework-agnostic PHP client for the dockaccess.org AI alt text generator, with strict image validation before anything leaves the server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
