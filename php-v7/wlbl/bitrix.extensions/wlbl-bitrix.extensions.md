# wlbl/bitrix.extensions

> 标签: 1С Битрикс, bitrix, wlbl

## 简介

Несколько полезных функций для повседневной работы с битриксом

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
