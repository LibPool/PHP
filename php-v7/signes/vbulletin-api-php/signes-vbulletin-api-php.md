# signes/vbulletin-api-php

> 标签: api, vbulletin

## 简介

This package gives you possibility to easy integrate your system with vBulletin 5 API using simple methods calls.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
