# coderteams/yii2-imageboss

> 标签:  ImageBoss,  Responsive, widget, yii2

## 简介

Renders IMG tags with the ImageBoss third party service acording to device screen size

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
