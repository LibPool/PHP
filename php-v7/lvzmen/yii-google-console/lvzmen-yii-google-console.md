# lvzmen/yii-google-console

> 标签: admin, backend, google console, php, theme, yii, yii2

## 简介

Yii Backend Bootstrap Template as same as Google Console.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
