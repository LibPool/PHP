# brixms/yii2-phpdotenv

> 标签: .env, dotenv, getenv, phpdotenv, yii2

## 简介

Yii2 extension for .env / Dotenv / env() / getenv()

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
