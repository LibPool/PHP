# lazarow/elo

> 标签: PHP

## 简介

The special function "elo" that can be used instead of the standard "var_dump" method with the "Yakalelo" phrase.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
