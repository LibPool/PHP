# martin-kozianka/contao-timetags

> 标签: contao, countdown, timesince, timetags

## 简介

Inserttags for contao {{timesince::OPTIONS}}, {{countdown::OPTIONS}},{{countdown_days::OPTIONS}}

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
