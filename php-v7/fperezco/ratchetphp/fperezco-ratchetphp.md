# fperezco/ratchetphp

> 标签: Ratchet, WebSockets, server, sockets, websocket

## 简介

A fork of PHP WebSocket library from cboden/ratchet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
