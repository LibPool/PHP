# api-check/php-client

> 标签: address-api, address-validation, address-verification, apicheck, laravel, postal-code

## 简介

A wrapper around ApiCheck API to validate addresses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
