# tapha/mws-laravel

> 标签: Amazon-api, amazon, api, config, fba, laravel, mws, persistent, php

## 简介

A minimal service provider to set up and use the MWS API PHP library in Laravel 5.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
