# abliteration/abliteration

> 标签: abliteration, api, catalog, llm, openapi

## 简介

Auto-generated PHP client for the abliteration.org LLM catalog API. Covers every route on /api/v1 with typed models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/neymark/php-abliteration.git
