# fraserreed/memcached-manager

> 标签: memcache, memcached

## 简介

Memcached Manager is a modern implementation of the memcached.php script for PHP 5.3, 5.4, 5.5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
