# woduda/kohana-dashboard

> 标签: dashboard, kohana, library, module

## 简介

Kohana 3.3 module for creation of simple dashboards/panels

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
