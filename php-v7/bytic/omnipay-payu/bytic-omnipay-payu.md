# bytic/omnipay-payu

> 标签: driver, gateway, merchant, omnipay, pay, payment, twispay

## 简介

PayU driver for ThePhpLeague Omnipay multi-payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
