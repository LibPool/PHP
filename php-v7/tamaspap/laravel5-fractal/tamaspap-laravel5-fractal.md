# tamaspap/laravel5-fractal

> 标签: Api transformer, fractal, laravel5

## 简介

A simple fractal service provider and transformer generator for laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
