# goalio/goalio-forgotpassword-doctrine-orm

> 标签: zf2

## 简介

Doctrine2 ORM storage adapter for GoalioForgotPassword.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
