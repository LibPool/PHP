# saintberry/phantomjs-extension

> 标签: PHP

## 简介

Adds a PhantomJs driver to Behat's Mink extension. This will automatically start and stop PhantomJs in your tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
