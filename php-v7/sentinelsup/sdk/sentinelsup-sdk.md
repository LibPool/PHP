# sentinelsup/sdk

> 标签: antidetect, bot-detection, device-fingerprinting, fraud-detection, fraud-prevention, proxy-detection, vpn-detection, woocommerce

## 简介

Official Maskbreak SDK for browser-backed fraud checks and cloud/Tor IP lookups.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
