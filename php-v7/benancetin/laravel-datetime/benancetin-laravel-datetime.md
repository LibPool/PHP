# benancetin/laravel-datetime

> 标签: date, datetime, laravel, package, time, utc

## 简介

datetime is laravel package to print date and time in a given format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
