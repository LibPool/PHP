# muspelheim/c3charts-bundle

> 标签: bundle, c3js, chart, charting, charts, graph, graphs, muspelheim, symfony

## 简介

Simple bundle for building pretty charts based on c3js

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
