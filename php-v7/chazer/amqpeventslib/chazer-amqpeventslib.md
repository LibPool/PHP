# chazer/amqpeventslib

> 标签: AMQP, rabbitmq

## 简介

Use AMQP protocol (RabbitMQ) for publish events between distributed apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
