# php-base-project/php-base-project

> 标签: PHP

## 简介

A packagist ready package to start a new PHP 7 project including Composer, PHPUnit, Travis, CodeClimate and StyleCI.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
