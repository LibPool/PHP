# dproject/primitive-php

> 标签: api, diver project, dproject, dproject primitive, php primitive, primitive

## 简介

Library with utility classes to work with basic of PHP and requirement for other libraries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
