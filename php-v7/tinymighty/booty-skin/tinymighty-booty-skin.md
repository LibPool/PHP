# tinymighty/booty-skin

> 标签: mediawiki, skin, wiki

## 简介

A modern mobile-first responsive MediaWiki theme built on Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
