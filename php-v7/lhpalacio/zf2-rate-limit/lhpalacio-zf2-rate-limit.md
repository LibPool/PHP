# lhpalacio/zf2-rate-limit

> 标签: API rate limit, apigility, rate limit, throttle

## 简介

A Zend Framework 2 module that helps you to deal with rate limit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
