# shivas/bouncer-bundle

> 标签: SNS, aws, blacklist, bounce, ses, swiftmailer

## 简介

Symfony2 bundle for AWS SES/SNS Bounce topic listener and swiftmailer filter

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
