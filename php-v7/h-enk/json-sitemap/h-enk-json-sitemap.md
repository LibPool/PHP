# h-enk/json-sitemap

> 标签: Sitemap, wordpress

## 简介

WordPress plugin that generates a JSON sitemap on non-production environments - for use with UnCSS as a PostCSS plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
