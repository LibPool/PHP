# ricardogarfe/teamleader

> 标签: PHP

## 简介

PHP Teamleader is a (wrapper)class to communicate with Teamleader (http://www.teamleader.be).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
