# mageomni/redis-cache

> 标签: redis, wordpress

## 简介

A persistent object cache backend powered by Redis. Supports Predis, PhpRedis, Relay, replication, sentinels, clustering and WP-CLI.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
