# latevaweb/laravel-query-updater

> 标签: api, keep data, laravel, laravel-query-updater, rest

## 简介

Easily update Eloquent models from put API requests without losing data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
