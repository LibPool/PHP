# artur-stepien/wargaming-papi

> 标签: wargaming, wg, world of tanks, wot

## 简介

Provides a useful interface to connect and use Wargaming Public API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
