# boletosimples/boletosimples

> 标签: boleto, boletosimples, ecommerce, simples

## 简介

A PHP client library for easily accessing Boleto Simples API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
