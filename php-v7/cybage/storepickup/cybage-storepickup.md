# cybage/storepickup

> 标签: PHP

## 简介

An extension to add option for store pickup shipping method on checkout page by Cybage

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://packagist.org/packages/cybage%2Fstorepickup
- 源码仓库：https://github.com/supportecom/Cybage-Storepickup.git
- Packagist 页面：https://packagist.org/packages/cybage%2Fstorepickup

- Composer 安装：`composer require cybage/storepickup`
- Packagist 仓库：https://repo.packagist.org/p2/cybage/storepickup.json
