# neos/event-sourcing-symfony-bridge

> 标签: PHP

## 简介

Symfony bridge to integrate Event Sourcing and CQRS pattern in your Symfony framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
