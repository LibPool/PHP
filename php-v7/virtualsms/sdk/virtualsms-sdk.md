# virtualsms/sdk

> 标签: 2fa, account-verification, ai-agents, mcp, otp, phone-verification, php-sdk, sms-api, sms-verification, virtual-number

## 简介

Official PHP SDK for the VirtualSMS API: SMS verification, number rentals, and matching-country proxies on real carrier-issued mobile numbers (not VoIP), across 2500+ services in 145+ countries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
