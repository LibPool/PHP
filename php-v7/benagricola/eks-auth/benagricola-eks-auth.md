# benagricola/eks-auth

> 标签: aws, aws-eks, eks, kubernetes

## 简介

Provides a pre-authenticated HTTPClient for consumption by existing PHP Kubernetes Client libraries

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
