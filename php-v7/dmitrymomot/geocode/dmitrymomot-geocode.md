# dmitrymomot/geocode

> 标签: address, api, geocode, geocoding, google, laravel, latitude, longitude

## 简介

Google Geocoding API for Laravel 4 (fork jcf/geocode with updated guzzle)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
