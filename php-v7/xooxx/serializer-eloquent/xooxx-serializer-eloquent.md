# xooxx/serializer-eloquent

> 标签: PHP

## 简介

Eloquent Driver for outputting valid API responses in JSON, JSON API and HAL+JSON API formats.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
