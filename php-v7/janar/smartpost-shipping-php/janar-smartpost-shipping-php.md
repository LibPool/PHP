# janar/smartpost-shipping-php

> 标签: api, client, pakiautomaat, smartpost

## 简介

Simple client library for PHP to create shipments using smartpost web service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
