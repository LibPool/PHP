# qobo/omnipay-zotapay

> 标签: cakephp, gateway, merchant, omnipay, pay, payment, symfony, wallet, zotapay

## 简介

zotapay driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
