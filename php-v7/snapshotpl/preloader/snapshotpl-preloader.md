# snapshotpl/preloader

> 标签: Opcache, darkghosthunter, php-7.4, preloader

## 简介

Preloader helper to create a PHP-ready preload script from Opcache.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
