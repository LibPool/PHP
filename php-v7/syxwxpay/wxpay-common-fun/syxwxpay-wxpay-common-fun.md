# syxwxpay/wxpay-common-fun

> 标签: PHP

## 简介

基于微信支付封装的方法，继承了：回调签名验证丶证书的获取丶签名的生成丶报文的解密等

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
