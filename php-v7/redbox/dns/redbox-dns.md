# redbox/dns

> 标签: dns, it, migration, networking, server, tools, unix, utilities, windows

## 简介

Quickly retrieve any type of DNS record you wish using PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
