# redbox/dreamweaver

> 标签: adobe, decode, development, dreamweaver, encode, passwords, security, utility

## 简介

This simple and easy to tool allows you to encode or decode Adobe Dreamweaver passwords.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
