# ctf0/tagos

> 标签: ctf0, gui, laravel, manager, tagging, tagos

## 简介

GUI to manage tags in laravel based on spatie/laravel-tags

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
