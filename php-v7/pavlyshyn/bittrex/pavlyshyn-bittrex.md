# pavlyshyn/bittrex

> 标签: bitcoins, bittrex, cryptocurrency

## 简介

API Wrapper for the Bittrex cryptocurrency exchange

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
