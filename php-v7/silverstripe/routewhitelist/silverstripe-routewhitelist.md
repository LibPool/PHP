# silverstripe/routewhitelist

> 标签: 404, ddos, routes, silverstripe

## 简介

Provides a whitelist of known valid URL patterns in a SilverStripe website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
