# silverstripe/spellcheck

> 标签: cwp, hunspell, silverstripe, spellcheck

## 简介

Improves spellcheck support for SilverStripe CMS, including an implementation for HunSpell.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
