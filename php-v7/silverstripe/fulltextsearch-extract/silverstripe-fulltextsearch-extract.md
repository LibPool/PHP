# silverstripe/fulltextsearch-extract

> 标签: PHP

## 简介

Necessary SOLR plugins for doc and pdf extraction, to go with silverstripe/fulltextsearch

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
