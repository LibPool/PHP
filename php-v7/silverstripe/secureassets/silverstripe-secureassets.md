# silverstripe/secureassets

> 标签: assets, files, secure, silverstripe

## 简介

Adds access restrictions to folders in assets, similar to the way you secure pages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
