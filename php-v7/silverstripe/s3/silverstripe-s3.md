# silverstripe/s3

> 标签: aws, filesystem, s3, silverstripe

## 简介

Adds SilverStripe support for using the S3 adapter for Flysystem

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
