# dreamboycx/tp6-secure-middleware

> 标签: PHP

## 简介

ThinkPHP6 安全中间件合集(SQL注入检测、CORS跨域、IP黑名单、接口签名)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
