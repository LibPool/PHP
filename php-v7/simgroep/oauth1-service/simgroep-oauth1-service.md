# simgroep/oauth1-service

> 标签: oauth, security

## 简介

Server library  for server side implementation of OAuth 1. Integrates easily with a framework, but can also be used outside of one.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
