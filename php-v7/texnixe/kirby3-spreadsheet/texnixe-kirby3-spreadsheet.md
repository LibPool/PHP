# texnixe/kirby3-spreadsheet

> 标签: kirby3, kirby3-cms, kirby3-plugin

## 简介

Kirby 3 plugin to include spreadsheet files as tables in Kirby textarea fields

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
