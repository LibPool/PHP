# mike27cubes/runscope-guzzle-plugin

> 标签: Guzzle, runscope

## 简介

This package adds Runscope support to the Guzzle 5.x PHP library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
