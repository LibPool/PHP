# security/pbkdf2

> 标签: hash, password, pbkdf2, rsa, salt

## 简介

An implementation of PBKDF2 invented by RSA Laboratories. Useful for password strengthening.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
