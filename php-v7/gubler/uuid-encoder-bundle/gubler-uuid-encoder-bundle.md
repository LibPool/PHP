# gubler/uuid-encoder-bundle

> 标签: bundle, gubler, symfony, uuid

## 简介

This bundle provides Symfony integration for gubler/uuid-encoder.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
