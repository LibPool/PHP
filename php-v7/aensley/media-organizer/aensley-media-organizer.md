# aensley/media-organizer

> 标签: Webp, audio, avi, avif, dng, flac, heic, heif, image, jpeg, jpg, media, mkv, mov, mp3, mp4, ogg, png, riff, tiff, video, vorbis, webm

## 简介

Organize image, video, and audio files (or any files) into date-based folders.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
