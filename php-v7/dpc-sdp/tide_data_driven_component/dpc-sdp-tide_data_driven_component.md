# dpc-sdp/tide_data_driven_component

> 标签: PHP

## 简介

Data Driven Component content type and related configuration for Tide Drupal 10 distribution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
