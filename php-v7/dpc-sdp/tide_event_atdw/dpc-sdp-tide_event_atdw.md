# dpc-sdp/tide_event_atdw

> 标签: PHP

## 简介

Provides event importer from Australian Tourism Data Warehouse for Tide Drupal 8 distribution

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
