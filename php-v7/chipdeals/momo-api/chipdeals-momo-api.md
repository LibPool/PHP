# chipdeals/momo-api

> 标签: mobile-money, momo, momo-api, moov-money, mtn-momo, orange-money, payment, payment-api

## 简介

Easy use mobile money api to access all Africa mobile wallets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
