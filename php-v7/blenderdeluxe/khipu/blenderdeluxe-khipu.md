# blenderdeluxe/khipu

> 标签: PHP

## 简介

Composer package for Tifon's Khipu Library (https://github.com/khipu/lib-php) modified for personal use all rights for them

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
