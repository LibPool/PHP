# integready/yii2-pwstrength-widget

> 标签: extension, helpers, widgets, yii2

## 简介

Yii2 widget created on basis of jquery plugin https://github.com/ablanco/jquery.pwstrength.bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
