# ajcastro/fk-adder

> 标签: database, fk, foreign key, migration

## 简介

Lets you add foreign keys in a swift! Foreign key adder in laravel migration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
