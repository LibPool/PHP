# cajogos/php-temp-cache

> 标签: cache, caching, temp

## 简介

Simple PHP caching system that uses a tmp folder in a Linux environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
