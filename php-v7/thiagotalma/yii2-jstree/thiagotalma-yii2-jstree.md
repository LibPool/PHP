# thiagotalma/yii2-jstree

> 标签: extension, form, jstree, widget, yii2

## 简介

Widget for Yii Framework 2.0 to use JsTree

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
