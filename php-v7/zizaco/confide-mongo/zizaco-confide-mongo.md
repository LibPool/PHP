# zizaco/confide-mongo

> 标签: auth, illuminate, laravel

## 简介

Confide Mongo is a authentication solution for Laravel that uses mongolid-laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
