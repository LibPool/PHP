# alexstack/laravel-cms-plugin-system-file

> 标签: amila laravel cms, amila laravel cms plugin, file manager, laravel, laravel file, laravel file manager, php file manager, system file explorer

## 简介

Laravel system file explorer, can view & edit files online.(eg. .php/.blade.php/.js/.html/.txt/.json/.css)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
