# demi/safe-text

> 标签: antispam, data, email, grabbing, hide, personal, phone, yii2

## 简介

Hiding personal data(email, phone, etc.) from spam grabbing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
