# genai/property

> 标签: PHP

## 简介

Compile-time config (.env / .ini) binder: compiles #[Property] classes into a container fragment so config resolves as DI beans. Runtime is PHP 5.3.29.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
