# moesif/moesif-slim

> 标签: Moesif, api, debugging, log, logging, middleware, slim

## 简介

Moesif Collection/Data Ingestion Middleware for Slim Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
