# digimix/wpmu-blogid

> 标签: wordpress

## 简介

WordPress plugin for displayin blog IDs, $blogid, as an admin column on WordPress multisites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
