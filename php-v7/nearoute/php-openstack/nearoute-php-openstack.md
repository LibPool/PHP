# nearoute/php-openstack

> 标签: Openstack, api, php, sdk

## 简介

PHP SDK for OpenStack APIs. Fork from php-opencloud/openstack, support for Nearoute Cloud Platform.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
