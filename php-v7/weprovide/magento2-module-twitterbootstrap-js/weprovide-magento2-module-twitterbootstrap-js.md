# weprovide/magento2-module-twitterbootstrap-js

> 标签: PHP

## 简介

Add Twitter Bootstrap javascript from CDN as a require.js module shim. With fallback to local version.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
