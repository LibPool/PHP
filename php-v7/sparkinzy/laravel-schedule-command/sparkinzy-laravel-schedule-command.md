# sparkinzy/laravel-schedule-command

> 标签: PHP

## 简介

命令中直接定义定时任务，避免Kernel中大量定义定时任务

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
