# pixelant/recall

> 标签: cache, memory

## 简介

TYPO3 extension that remembers settings from a different request using a hash. E.g. recall settings or data used in the main request within an eID request.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
