# pixelant/pxa-data-provider

> 标签: TYPO3 CMS

## 简介

Configurable data provider for easy data sharing with external scripts such as Google Tag Manager.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
