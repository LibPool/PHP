# pruvo/laravel-google-cloud-tasks-queue

> 标签: PHP

## 简介

Laravel serverless queue using Google Cloud Tasks with Google Cloud Run.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
