# activeants/magento2-postcodevalidator

> 标签: Dutch, magento2, postcode, validator

## 简介

A minor enhancement to the postcode validator for Dutch postcodes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
