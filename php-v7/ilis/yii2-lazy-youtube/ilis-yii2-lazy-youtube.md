# ilis/yii2-lazy-youtube

> 标签: extension, lazy, loader, yii2, youtube

## 简介

YouTube lazy load. Accelerate page loading with youtube video.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
