# nita-transfert/sdk

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

SDK PHP officiel des APIs partenaires NITA (v2) : authentification, signature HMAC et clients types pour P2CASH, P2W, P2P et Achat en ligne.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
