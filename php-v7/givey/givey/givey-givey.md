# givey/givey

> 标签: PHP

## 简介

PHP library for https://api.givey.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/givey/givey-php
- 源码仓库：https://github.com/givey/givey-php.git
- Packagist 页面：https://packagist.org/packages/givey%2Fgivey

## 获取地址

- Composer 安装：`composer require givey/givey`
- Packagist 仓库：https://repo.packagist.org/p2/givey/givey.json
- PHP 要求：>=5.3.0
