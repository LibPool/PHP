# wbrframe/pdf-to-html

> 标签: Poppler-utils, pdftohtml, php

## 简介

PDF to HTML converter with PHP using tools, like poppler-utils

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
