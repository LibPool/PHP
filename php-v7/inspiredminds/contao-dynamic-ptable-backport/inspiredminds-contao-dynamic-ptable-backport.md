# inspiredminds/contao-dynamic-ptable-backport

> 标签: PHP

## 简介

Contao extension to backport the automatic dynamic ptable support from Contao 4.10 and up to Contao 4.9.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
