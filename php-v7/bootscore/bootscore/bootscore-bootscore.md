# bootscore/bootscore

> 标签: bootcommerce, bootscore, bootstrap, theme, woocommerce, wordpress

## 简介

A powerful, free Bootstrap 5 starter theme for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
