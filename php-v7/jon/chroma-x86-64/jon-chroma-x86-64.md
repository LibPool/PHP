# jon/chroma-x86-64

> 标签: chroma, code, highlight, syntax

## 简介

A compiled version of the Chroma syntax highlighter CLI for x86-64 systems

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
