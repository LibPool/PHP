# timersys/geotargeting-pro

> 标签: geolocation, geotargeting, plugin, wordpress

## 简介

WordPress plugin for geotargeting that works with GeotargetingWP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
