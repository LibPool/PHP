# myra-security-gmbh/cdn-client

> 标签: api, cdn, myracloud, upload

## 简介

Framework agnostic php implementation of the latest myracloud.com cdn api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
