# mediaessenz/diskusage

> 标签: TYPO3 CMS, backend, diskusage, filelist, plugin, vuejs

## 简介

Extension to visualize disk usage of TYPO3 storages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
