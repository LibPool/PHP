# asolomatin/php-big-bit-mask

> 标签: bitmap

## 简介

Bitmask compatible with JavaScript big-bit-mask - the bitmask serializable into a base64-like, url-safe string.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
