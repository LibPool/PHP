# alejodaraio/cloudflare-purgefile

> 标签: cache, cloudflare, expire, purge, tags

## 简介

Small library for purge files on Cloudflare using the API version 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
