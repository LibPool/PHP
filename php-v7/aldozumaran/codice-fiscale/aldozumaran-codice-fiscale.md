# aldozumaran/codice-fiscale

> 标签: codice fiscale, php

## 简介

A library to calculate and check the validity of the italian fiscal code (codice fiscale)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
