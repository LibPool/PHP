# rothkj1022/php-cache-class

> 标签: PHP

## 简介

A simple file based cache based from Erik Giberti's FileCache class, forked from lodev09/php-cache-class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
