# dilneiss/laravel-cors

> 标签: api, cors, crossdomain, laravel

## 简介

Adds CORS (Cross-Origin Resource Sharing) headers support in your Laravel application

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
