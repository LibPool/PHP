# dikderoy/yii-pophpconvertor

> 标签: PHP

## 简介

yii 1.x command to convert yii::t php source files to gettext and vice-versa

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
