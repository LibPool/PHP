# pvlksn/calendar

> 标签: calendar, fullcalendar, jquery calendar

## 简介

This bundle allows you to integrate the jQuery FullCalendar plugin into your Symfony3 application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
