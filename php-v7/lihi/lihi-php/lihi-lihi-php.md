# lihi/lihi-php

> 标签: API-Client, URL-Shortener, lihi, otp, sdk, short-url, sms

## 简介

Official PHP SDK for the Lihi URL shortener and SMS APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
