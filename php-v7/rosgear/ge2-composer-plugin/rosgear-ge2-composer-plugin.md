# rosgear/ge2-composer-plugin

> 标签: composer, plugin, rosgear

## 简介

Composer plugin for installing components, themes and libraries of the RosGear web application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
