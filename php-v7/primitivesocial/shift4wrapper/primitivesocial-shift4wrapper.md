# primitivesocial/shift4wrapper

> 标签: I4GO, Shift4, Shift4Wrapper, laravel

## 简介

Wrapper for Shift4 API for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
