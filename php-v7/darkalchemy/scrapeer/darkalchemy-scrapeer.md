# darkalchemy/scrapeer

> 标签: PHP

## 简介

Scrapeer, a tiny PHP library that lets you scrape HTTP(S) and UDP trackers for torrent information.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
