# cohensive/laravel-amp

> 标签: cohensive, laravel-amp, wearejust

## 简介

Package that helps you set up AMP (Accelerated Mobile Pages) using Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
