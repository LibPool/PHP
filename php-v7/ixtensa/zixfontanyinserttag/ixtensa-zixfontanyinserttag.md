# ixtensa/zixfontanyinserttag

> 标签: contao, extension, font, icon, inserttag

## 简介

Provides a Contao insert-tag for font icons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
