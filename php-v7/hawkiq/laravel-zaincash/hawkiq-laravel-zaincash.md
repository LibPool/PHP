# hawkiq/laravel-zaincash

> 标签: PHP

## 简介

Laravel package to use in Laravel helps you to make dealing with Zain Cash API easier

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
