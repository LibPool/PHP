# hawkiq/adminltev4

> 标签: JS, admin, back-end, css, less, responsive, template, theme, web

## 简介

AdminLTE v4 - admin control panel and dashboard that's based on Bootstrap 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
