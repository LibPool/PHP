# damianociarla/geo-form-field-bundle

> 标签: Symfony2, callback, field, form, geocoding, google, javascript

## 简介

DCSGeoFormFieldBundle adds a new field type for geolocation addresses in Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
