# knut7/php-graphic

> 标签: graphic, graphics, image, mvc

## 简介

This is a package to create dynamic graphics in php. Simple and easy to use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
