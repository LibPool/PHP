# import-ai/flarum-webhook-notification

> 标签: flarum, notification, webhook

## 简介

Webhook notification channel for Flarum - sends notifications via HTTP webhooks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
