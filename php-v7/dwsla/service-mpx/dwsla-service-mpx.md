# dwsla/service-mpx

> 标签: The Platform, mpx, php

## 简介

A PHP 5.4 library for accessing MPX services from ThePlatform (mpx.theplatform.com)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
