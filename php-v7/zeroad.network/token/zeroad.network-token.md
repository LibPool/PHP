# zeroad.network/token

> 标签: HTTP-header, access-token, ad-free, ads-free, api, auth, authorization, composer, content-access, entitlement, feature-flags, middleware, paywall, php, sodium, subscription, token, web-server, welcome-header, zero-ad, zeroad

## 简介

An HTTP-header-based "access / entitlement token" library for Zero Ad Network partnering sites using PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
