# nevadskiy/laravel-uuid

> 标签: eloquent, laravel, uuid

## 简介

The package provides UUID keys functionality for Eloquent models with one single trait.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
