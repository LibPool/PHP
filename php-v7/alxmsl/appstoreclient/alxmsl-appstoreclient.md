# alxmsl/appstoreclient

> 标签: apple, appstore, inapp, itunes, purchases

## 简介

AppStore client for iTunes purchases receipts verification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
