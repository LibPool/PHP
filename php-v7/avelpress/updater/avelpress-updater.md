# avelpress/updater

> 标签: avelpress, plugin, updater, wordpress

## 简介

Offers new versions of a WordPress plugin distributed outside wordpress.org on the WordPress update screen. Optional add-on for AvelPress, also usable on its own.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
