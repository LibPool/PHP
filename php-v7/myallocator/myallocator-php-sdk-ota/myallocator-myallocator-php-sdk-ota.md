# myallocator/myallocator-php-sdk-ota

> 标签: channel, manager, myallocator

## 简介

PHP SDK for OTA's to easily integrate with the MyAllocator OTA BuildToUs API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
