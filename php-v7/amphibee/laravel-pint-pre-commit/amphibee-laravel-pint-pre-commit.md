# amphibee/laravel-pint-pre-commit

> 标签: HOOK, Pint, git, laravel

## 简介

Laravel Pint pre-commit hook allow you to analyse your code with the awesome Laravel Pint.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
