# amphibee/menu-item-type-maker

> 标签: amphibee, item, menu, wordpress, wp

## 简介

Wrapper for the Menu Item Types plugin (https://fr.wordpress.org/plugins/menu-item-types)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
