# webvpf/wn-robots-plugin

> 标签: winter cms, wintercms, wintercms-plugin

## 简介

Robots - plugin for Winter CMS. Adds robots.txt for your site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
