# zround/sphinxapi

> 标签: manticore, search, sphinx, sphinxql

## 简介

Sphinx searchd client using SphinxQL (MySQL protocol) instead of deprecated native binary protocol

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
