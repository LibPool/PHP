# uhi67/yii2-datepicker

> 标签: DateTimePicker, bootstrap, datepicker, extension, widget, yii2

## 简介

Bootstrap 3 Date/time picker widget for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
