# ubl/pubman_importer

> 标签: TYPO3 CMS, escidoc, pubman

## 简介

queries an escidoc server for journals and displays from journal to content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
