# ubl/ubl_vufind_auth

> 标签: Authentication, TYPO3 CMS, vufind

## 简介

Authenticates users based on authenticated vufind session

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
