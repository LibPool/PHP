# tarcisioruas/php-bitgrail-sdk

> 标签: api, bitgrail, sdk

## 简介

PHP BitGrail API is a PHP library for the BitGrail API designed to be easy to use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
