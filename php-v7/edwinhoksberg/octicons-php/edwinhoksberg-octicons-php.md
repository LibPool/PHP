# edwinhoksberg/octicons-php

> 标签: github, icons, octicons, svg

## 简介

A simple PHP library for displaying the Github Octicons font icons in svg format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
