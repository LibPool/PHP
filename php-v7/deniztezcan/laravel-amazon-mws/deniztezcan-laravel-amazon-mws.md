# deniztezcan/laravel-amazon-mws

> 标签: amazon, api, laravel, mws, php

## 简介

Use Amazon's MWS web services with Laravel 5.x/6.0. Based on sonnenglas/amazon-mws-laravel and creacoon/amazon-mws-laravel package and modified to make it compatible with latest Laravel releases (+ bugfixes for setting a text/xml header).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
