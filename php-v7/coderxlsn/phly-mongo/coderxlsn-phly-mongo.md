# coderxlsn/phly-mongo

> 标签: module, mongo, mongodb, zend, zf2

## 简介

ZF2 Module providing services and paginators surrounding MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
