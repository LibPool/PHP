# marqant-lab/marqant-pay-subscriptions

> 标签: PHP

## 简介

Extension package for the marqant/marqant-pay package, providing recurring billing through subscriptions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
