# buonaparte/bnp-lazy-listener

> 标签: eventmanager, lazy, zf2

## 简介

This library allows you to attach Lazy Listeners to a ZF2 EventManager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
