# garbetjie/monolog-bigquery-handler

> 标签: bigquery, log, logging, monolog

## 简介

A configurable Monolog handler for writing logs to BigQuery.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
