# nofutur3/tracy-gitpanel

> 标签: branch, debug, git, nette, panel, tracy

## 简介

nette extension - adds the GIT panel to the tracy panel - shows current GIT branch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
