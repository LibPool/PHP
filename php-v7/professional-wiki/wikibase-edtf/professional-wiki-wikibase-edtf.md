# professional-wiki/wikibase-edtf

> 标签: EDTF, Extended Date Time Format, Semantic Web, datatype, datetime, extension, mediawiki, seasons, standard, structured data, time interval, uncertainty, wiki, wikibase, wikidata

## 简介

Adds the EDTF data type to Wikibase

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
