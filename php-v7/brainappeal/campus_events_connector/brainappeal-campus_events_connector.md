# brainappeal/campus_events_connector

> 标签: event, events, eventtool, extension, typo3, veranstaltung

## 简介

Campus Events Connector - Manage events, appointments, registrations and participants centrally with Campus Events. To use this extension, a Campus Events installation or access to the API is required. For more information see https://www.campus-events.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
