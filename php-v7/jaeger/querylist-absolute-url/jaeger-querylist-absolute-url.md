# jaeger/querylist-absolute-url

> 标签: PHP

## 简介

QueryList Plugin: Converting relative urls to absolute.QueryList插件:转换URL相对路径到绝对路径.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
