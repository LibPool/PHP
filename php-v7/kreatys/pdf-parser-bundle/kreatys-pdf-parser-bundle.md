# kreatys/pdf-parser-bundle

> 标签: parser, pdf

## 简介

Integration of the smlot/pdfparser library for parsing PDF files in Symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
