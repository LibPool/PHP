# mateuszblaszczyk/gpx-to-json

> 标签: gpx, json, parser

## 简介

It parses .gpx file to JSON with distance and timestamp

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
