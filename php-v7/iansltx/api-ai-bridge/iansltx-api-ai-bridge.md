# iansltx/api-ai-bridge

> 标签: Dialogflow, NLU, api.ai, bot, natural language

## 简介

A set of middlewares + helpers for responding to Dialogflow web hooks

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
