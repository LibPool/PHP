# iansltx/gcm-client

> 标签: FCM, android, firebase, gcm, google, library, push

## 简介

A client for Firebase Cloud Messaging for Android's message API (via Legacy endpoints)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
