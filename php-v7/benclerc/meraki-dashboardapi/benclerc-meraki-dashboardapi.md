# benclerc/meraki-dashboardapi

> 标签: api, php, sdk, swagger

## 简介

Swagger generated PHP library for Meraki Dashboard API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://swagger.io
- 源码仓库：https://github.com/benclerc/Meraki-DashboardAPI.git
- Packagist 页面：https://packagist.org/packages/benclerc%2Fmeraki-dashboardapi
