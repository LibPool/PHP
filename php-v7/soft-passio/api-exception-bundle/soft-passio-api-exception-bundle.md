# soft-passio/api-exception-bundle

> 标签: api exceptions, api-problem, problem json

## 简介

catch all Symfony errors and convert it to problem json RFC7807 response

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
