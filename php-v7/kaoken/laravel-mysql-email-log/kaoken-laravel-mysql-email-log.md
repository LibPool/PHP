# kaoken/laravel-mysql-email-log

> 标签: email, laravel, monolog, mysql

## 简介

Save logs handled by Laravel in Mysql, and send mail when it is over specified level.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
