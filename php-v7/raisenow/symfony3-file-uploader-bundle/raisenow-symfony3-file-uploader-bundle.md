# raisenow/symfony3-file-uploader-bundle

> 标签: Image transform, Symfony Bundle, blueimp, bundle, file, multiple file upload, punkave, symfony, symfony-2.0, symfony-2.1, upload, uploader

## 简介

Multiple file uploads for Symfony2 with the BlueImp uploader. Also scales uploaded images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
