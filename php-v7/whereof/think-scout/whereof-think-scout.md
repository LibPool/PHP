# whereof/think-scout

> 标签: php, thinkphp

## 简介

Thinkphp Scout provides a driver based solution to searching your Eloquent models. Inspired By Laravel Scout.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
