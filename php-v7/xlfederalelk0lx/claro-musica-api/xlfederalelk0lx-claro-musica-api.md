# xlfederalelk0lx/claro-musica-api

> 标签: PHP

## 简介

Script para utilizar la Api de claro musica y poder obtener listas de reproduccion, generos y canciones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
