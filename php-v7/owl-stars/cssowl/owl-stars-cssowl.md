# owl-stars/cssowl

> 标签: css, less, owl-stars, sass, scss, spriteowl, stylus

## 简介

Cssowl is Owl-Stars mixins library with support for LESS, SASS/SCSS & Stylus.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
