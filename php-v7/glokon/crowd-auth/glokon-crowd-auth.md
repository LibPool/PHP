# glokon/crowd-auth

> 标签: Authentication, atlassian, auth, crowd, laravel

## 简介

A simple way to implement Atlassian Crowd Authentication into your application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
