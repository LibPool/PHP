# lagan/template-manytoone

> 标签: lagan, mamy-to-one, mamytoone, many-to-one, property, template

## 简介

Template to edit Lagan many-to-one properties.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
