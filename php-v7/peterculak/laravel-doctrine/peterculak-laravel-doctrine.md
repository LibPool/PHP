# peterculak/laravel-doctrine

> 标签: Doctrine 2, doctrine, laravel, orm

## 简介

The Doctrine 2 implementation that melts with Laravel 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
