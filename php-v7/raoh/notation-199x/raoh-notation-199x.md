# raoh/notation-199x

> 标签: PHP

## 简介

The rules for reading text that Raoh and Souther share: Unicode 18.0.0 case conversion and normalization, White_Space, scalar values, temporal text and the pattern language, answered alike whatever Unicode version PHP was built with

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
