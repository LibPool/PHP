# liharsw/midtrans-php

> 标签: PHP

## 简介

PHP Wrapper for Midtrans Payment API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://midtrans.com
- 源码仓库：https://github.com/liharsw/midtrans-php.git
- Packagist 页面：https://packagist.org/packages/liharsw%2Fmidtrans-php
