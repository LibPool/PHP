# helsingborg-stad/multisite-role-propagation

> 标签: PHP

## 简介

Plugin to quickly set a role for a multisite user on multiple blogs in a network

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
