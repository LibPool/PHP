# helsingborg-stad/customer-feedback

> 标签: PHP

## 简介

This WordPress plugin adds a feedback form to the end of every page (or any other activated post type).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
