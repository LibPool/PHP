# maxeckel/livewire-editorjs

> 标签: livewire-editorjs, maxeckel

## 简介

This Package aims for an easy integration of Editor.JS with Laravel Livewire

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
