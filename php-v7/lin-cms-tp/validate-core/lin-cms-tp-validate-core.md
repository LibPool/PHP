# lin-cms-tp/validate-core

> 标签: PHP

## 简介

LinCms TP 的反射验证器核心类，含参数中间件封装，路由参数验证中间件，方法注释参数提取器，基于`wangyu/reflex-core`扩展

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
