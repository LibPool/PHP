# jentry/module-logs-management

> 标签: log, log management, logs, logs management, magento 2, magento 2 logs

## 简介

Magento2\Adobe Commerce module to view logs from admin interface and archive them by cron

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
