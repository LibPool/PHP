# stef77dd/videothumbnailsprite

> 标签: ffmpeg, ffmpegthumbnailer, jwplayer, sprite

## 简介

PHP library for generating video thumbnail sprites

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
