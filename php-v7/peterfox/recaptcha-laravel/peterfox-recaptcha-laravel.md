# peterfox/recaptcha-laravel

> 标签: laravel, recaptcha, validation

## 简介

A simple package for adding and validating Recaptcha fields in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
