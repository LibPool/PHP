# riconet/t3-extension-social-clubs-events

> 标签: PHP

## 简介

This extension connect the extension 'rico_social_clubs' with extension 'rico_events'.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
