# pintu1991/omnipay-globalpayments

> 标签: gateway, globalpayments, merchant, omnipay, pay, payment, payments

## 简介

globalpayments driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
