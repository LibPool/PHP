# woit/wit-pwamanifest

> 标签: extension, manifest, pwa, pwamanifest, typo3, woit

## 简介

This extension is to create an interface where you can manage your manifest data which can used to generate a PWA.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
