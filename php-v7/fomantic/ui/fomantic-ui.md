# fomantic/ui

> 标签: css, fomantic, fomantic-ui, framework, semantic, ui

## 简介

Fomantic empowers designers and developers by creating a shared vocabulary for UI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
