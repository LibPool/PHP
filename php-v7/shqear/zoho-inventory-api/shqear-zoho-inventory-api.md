# shqear/zoho-inventory-api

> 标签: Zoho, api, inventory, php

## 简介

Client library for ZOHO Inventory API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.zoho.com/inventory/api/v1/
- 源码仓库：https://github.com/shqear93/zoho-inventory-api.git
- Packagist 页面：https://packagist.org/packages/shqear%2Fzoho-inventory-api
