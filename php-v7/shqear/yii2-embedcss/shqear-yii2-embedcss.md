# shqear/yii2-embedcss

> 标签: block, cascade stylesheet, css, embed, extended, extension, yii2

## 简介

Embed Css with IDE checking or intellisense.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
