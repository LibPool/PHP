# jacricelli/php_codesniffer

> 标签: phpcs, standards

## 简介

PHP_CodeSniffer tokenises PHP, JavaScript and CSS files and detects violations of a defined set of coding standards.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
