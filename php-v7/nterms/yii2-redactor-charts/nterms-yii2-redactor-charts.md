# nterms/yii2-redactor-charts

> 标签: Redactor, chartjs, extension, nterms, yii, yii 2, yii2

## 简介

An asset bundle to use chart.js plugin for Imperavi Redactor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
