# bestjf/php-dfa-sensitive

> 标签: PHP

## 简介

To achieve the filtering of sensitive words, based on the determination of finite automata (DFA) algorithm.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
