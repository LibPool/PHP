# uri2x/php-cql

> 标签: PHP

## 简介

A native Apache Cassandra and ScyllaDB connector for PHP based on the CQL binary protocol with support for persistent connections

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
