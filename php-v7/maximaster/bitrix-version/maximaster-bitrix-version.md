# maximaster/bitrix-version

> 标签: PHP

## 简介

Объявляет об используемой версии Битрикс, для возможности её учёта другими пакетами.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
