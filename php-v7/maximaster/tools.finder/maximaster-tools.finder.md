# maximaster/tools.finder

> 标签: PHP

## 简介

Библиотека, облегчающая поиск идентификаторов разных сущностей для 1С-Битрикс

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
