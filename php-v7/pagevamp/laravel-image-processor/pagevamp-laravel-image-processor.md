# pagevamp/laravel-image-processor

> 标签: PHP

## 简介

Package for uploading / resizing images into disk. Tested with s3/local & laravel 5.8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
