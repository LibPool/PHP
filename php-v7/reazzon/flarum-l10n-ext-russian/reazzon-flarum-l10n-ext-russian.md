# reazzon/flarum-l10n-ext-russian

> 标签: extension, flarum, language, locale, localization, russian, translation

## 简介

Flarum Extensions Russian language pack.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
