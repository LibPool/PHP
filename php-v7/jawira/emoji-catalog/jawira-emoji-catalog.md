# jawira/emoji-catalog

> 标签: catalog, emoji, emojis, emoticons, smileys, smilies, unicode

## 简介

Get access to +3950 emojis as class constants

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
