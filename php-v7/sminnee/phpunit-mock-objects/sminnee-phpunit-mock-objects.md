# sminnee/phpunit-mock-objects

> 标签: mock, xunit

## 简介

Mock Object library for PHPUnit (fork to add PHP 7.4 support to 3.4)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
