# fluidphp/framework

> 标签: PHP Library, application programming, debug php, easy php, help php, php developer tools, php framework, php toolcase, php tools

## 简介

Core files for fluidphp framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
