# fluidphp/translator-helper

> 标签: Xml Reader, php framework, xml parser, xml translator

## 简介

FluidPHP framework translator helper class that uses xml as database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
