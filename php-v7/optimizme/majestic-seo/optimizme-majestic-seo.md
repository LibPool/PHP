# optimizme/majestic-seo

> 标签: PHP

## 简介

PHP library for making requests to the Majestic SEO API, based on nticaric/majestic-seo-api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
