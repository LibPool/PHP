# bav/symfony

> 标签: Bank, account, bankaccount, bav, check, konto, symfony, validation

## 简介

Symfony Validator Component extension for German banking

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
