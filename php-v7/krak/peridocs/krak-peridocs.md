# krak/peridocs

> 标签: auto-documentation, auto-generate, documentation, peridot, peridot-plugin

## 简介

Peridot plugin for generating markdown documentation from your tests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
