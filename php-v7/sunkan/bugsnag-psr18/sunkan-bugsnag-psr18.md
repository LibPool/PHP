# sunkan/bugsnag-psr18

> 标签: bugsnag, errors, exceptions, logging, tracking

## 简介

Official Bugsnag notifier for PHP applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
