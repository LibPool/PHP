# pkg6/easy-im

> 标签: easy-im, im, 极光IM, 环信IM, 网易云信IM, 腾讯IM, 融云IM

## 简介

非官方即时通信 IM，支持腾讯IM，环信IM，极光IM，融云IM，网易云信IM等

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
