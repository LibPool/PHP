# borsaco/doctrine-prefix-bundle

> 标签: doctrine, doctrine-bundle, php, prefix, symfony

## 简介

Bundle to add prefix to tables and columns database

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
