# taitava/swiftmailer-imapsentfolder

> 标签: email, imap, sent

## 简介

A SwiftMailer plugin that stores a copy of all sent messages to a folder on an IMAP email server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
