# taitava/silverstripe-cmseditlink

> 标签: cms, editor, link

## 简介

An easy way to generate links to edit any DataObjects in the CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
