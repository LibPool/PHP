# cyberpearuk/phpunit-skelgen

> 标签: Skeleton, phpunit, testing, xunit

## 简介

Tool that can generate skeleton test classes from production code classes and vice versa

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
