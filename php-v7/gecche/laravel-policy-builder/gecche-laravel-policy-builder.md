# gecche/laravel-policy-builder

> 标签: acl, eloquent, gate, laravel, model, permissions

## 简介

A simple way to build allowed list of eloquent models (acl)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
