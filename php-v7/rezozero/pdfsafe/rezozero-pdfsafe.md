# rezozero/pdfsafe

> 标签: PHP

## 简介

Twig extension to clean-up an HTML content for PDF generation (psliwa/php-pdf)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
