# cpliakas/doctrine-password

> 标签: doctrine, password, phpass

## 简介

Adds a password type to Doctrine that hashes and compares passwords using the phpass library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
