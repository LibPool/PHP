# dhiraj/yii2-ffmpeg-static

> 标签: PHP

## 简介

Provides static ffmpeg binaries for windows, linux and mac x86_64 platforms with a convenient path lookup for both ffmpeg and ffprobe.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
