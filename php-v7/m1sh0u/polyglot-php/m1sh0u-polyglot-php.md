# m1sh0u/polyglot-php

> 标签: i18n, language, polyglot, translate

## 简介

Polyglot.php is a replica of the Airbnb's Polyglot.js I18n helper library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
