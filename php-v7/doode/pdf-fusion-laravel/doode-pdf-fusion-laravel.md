# doode/pdf-fusion-laravel

> 标签: FUSION, laravel, laravel-pdf-merge, merger, pdf, pdf-merge, pdfmerge

## 简介

Laravel package to merge several PDF files into one.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
