# esperecyan/html-filter

> 标签: PHP

## 简介

ホワイトリストによる要素名と属性名のチェックを行うシンプルなHTMLフィルターです。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
