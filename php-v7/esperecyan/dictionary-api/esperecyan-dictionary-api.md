# esperecyan/dictionary-api

> 标签: PHP

## 简介

従来の辞書形式を「主に単語で答えるゲームにおける汎用的な辞書形式」に変換する Web API を提供します。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
