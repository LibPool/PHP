# alberon/htmltopdf

> 标签: binary, htmltopdf, pdf, wkhtmltopdf

## 简介

HTML to PDF PHP wrapper with executable files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
