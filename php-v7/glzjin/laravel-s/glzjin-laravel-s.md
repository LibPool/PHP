> 标签: High Performance, LaravelS, async event, async task, coroutine, http server, inotify reload, memory resident, swoole, websocket server

## 简介

? LaravelS: Speed up Laravel/Lumen by Swoole, 'S' means Swoole, Speed, High performance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
