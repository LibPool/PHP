# packvium/packvium

> 标签: 3d-bin-packing, 3d-packing, bin-packing, cartonization, container-loading, deterministic, logistics, packing-algorithm, pallet-packing, truck-loading

## 简介

Deterministic 3D bin-packing and cartonization engine for pallets, containers, trucks and shipping cartons. Exact integer geometry, reproducible results.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
