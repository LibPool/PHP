# packvium/native-bridge

> 标签: 3d-bin-packing, 3d-packing, bin-packing, cartonization, container-loading, deterministic, ffi, logistics, packing-algorithm, pallet-packing, truck-loading

## 简介

Packvium backend bridge: the Rust engine over FFI when available, pure PHP otherwise.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
