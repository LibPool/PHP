# intelli-dust/vario-ng

> 标签: VOLVO, VarioNG, api, client, curl, json, rest

## 简介

VarioNG (VOLVO) REST API client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
