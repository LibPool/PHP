# yousha/codecop

> 标签: code-checker, code-quality, coding-standards, development-tools, php, php-linter, qa-tool, static-analyser

## 简介

A lightweight static analyzer that scan PHP files for quality issues.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
