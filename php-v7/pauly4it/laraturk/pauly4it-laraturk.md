# pauly4it/laraturk

> 标签: amazon mechanical turk, api, laravel, turk

## 简介

Provides a Laravel 5 package to communicate with the Amazon Mechanical Turk API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
