# menes1337/3dcart-api-php-client

> 标签: PHP

## 简介

PHP client library for accessing 3dCart Soap API, Soap Advanced API and REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
