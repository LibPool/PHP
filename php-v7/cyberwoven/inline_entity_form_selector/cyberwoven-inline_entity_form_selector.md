# cyberwoven/inline_entity_form_selector

> 标签: drupal

## 简介

This converts the autocomplete entity selector on the inline entity form module to a select field.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
