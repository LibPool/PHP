# ndg0/laravel-socialite-auth

> 标签: auth, laravel, socialite

## 简介

A quick drop-in solution for authenticating users with Laravel socialite.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
