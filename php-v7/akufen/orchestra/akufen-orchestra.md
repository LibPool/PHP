# akufen/orchestra

> 标签: mvc, orm, phalcon, wordpress

## 简介

A minimalist object-oriented superset for WordPress using Phalcon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
