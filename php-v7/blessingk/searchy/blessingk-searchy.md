# blessingk/searchy

> 标签: fuzzy, laravel, search

## 简介

Laravel Searchy makes user driven searching easy with fuzzy search, basic string matching, Levenshtein Distance and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
