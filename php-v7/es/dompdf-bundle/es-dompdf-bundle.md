# es/dompdf-bundle

> 标签: bundle, dompdf, pdf, symfony

## 简介

This bundle provides a wrapper for using dompdf inside symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
