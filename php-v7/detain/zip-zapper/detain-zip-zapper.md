# detain/zip-zapper

> 标签: Postal Routing Number, cap, cep, eircode, npa, numro postal dacheminement, pin code, plz, postal addressing codde, postal code, postal expedition code, postal index number, postcode, validator, zip, zip code, zipcode, zone improvement plan

## 简介

Validates Zip/Postal Codes for any country and gives that countries name for thier verions of Zip/Post code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
