# vulcandigital/silverstripe-facebookseo

> 标签: PHP

## 简介

A simple page extension to give content authors the ability to modify the content displayed within facebook

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
