# voodoo-mobile/readmegen

> 标签: generator, log parser, readme, vcs

## 简介

Readme file / doc generator. It uses VCS logs as a source of information.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
