# voodoo-mobile/zip-factory

> 标签: zip, ziparchive, zipfactory

## 简介

Factory class that creates either ZipArchive or PclZip PHP 5.2.17 and up

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
