# voodoo-mobile/yii2-imperavi-widget

> 标签: Redactor, extension, imperavi, widget, wysiwyg, yii, yii 2, yii2

## 简介

The imperavi redactor widget for Yii 2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
