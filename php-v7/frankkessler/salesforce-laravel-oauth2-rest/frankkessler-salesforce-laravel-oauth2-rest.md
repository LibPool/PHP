# frankkessler/salesforce-laravel-oauth2-rest

> 标签: oauth2, rest, salesforce

## 简介

A Salesforce REST api wrapper utilizing oAuth2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
