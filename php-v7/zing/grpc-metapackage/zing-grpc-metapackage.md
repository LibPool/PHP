# zing/grpc-metapackage

> 标签: composer, gRPC, metapackage

## 简介

gRPC meta is a simple composer inclusion list of gRPC: no API, simply require it

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
