# zing/yii2-psr-simple-cache

> 标签: cache, caching, psr, yii2

## 简介

A PSR simple caching interface implementation that routes to the Yii caching

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
