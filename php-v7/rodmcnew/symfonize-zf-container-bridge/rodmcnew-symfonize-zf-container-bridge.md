# rodmcnew/symfonize-zf-container-bridge

> 标签: PHP

## 简介

Allows you to use the Symfony 2 DI container in Zend Framework 2 apps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
