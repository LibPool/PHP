# webman/skills

> 标签: agent-skills, claude-code, codex, webman, workerman

## 简介

Agent Skills for developing, reviewing, debugging, testing, and deploying Webman applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
