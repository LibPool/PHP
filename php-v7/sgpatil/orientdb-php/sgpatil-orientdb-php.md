# sgpatil/orientdb-php

> 标签: PHP Orientdb Driver, database, graph, orientdb

## 简介

PHP Wrapper for the Orientdb database (REST)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
