# neercsys/flarum-ext-bosanski

> 标签: bosanski, extension, flarum, locale, translation

## 简介

Bosnian language pack for Flarum's third party extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
