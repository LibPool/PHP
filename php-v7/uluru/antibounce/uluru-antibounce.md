# uluru/antibounce

> 标签: SNS, aws, cakephp, ses

## 简介

Anti bounce plugin is able to prevent the email that bounceed from being sent it again once.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
