# webiators/module-multichatonwhatsapp

> 标签: PHP

## 简介

MultiChat On Whatsapp for Magento 2 by Webiators allows your visitors to  chat with you on WhatsApp.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
