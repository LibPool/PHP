# webiators/module-buynowbutton

> 标签: PHP

## 简介

Buy Now Button extension by Webiators allows store admin to automatically register guest buyers as customers without forcing the users to log in or register for checkout.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
