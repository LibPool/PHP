# atomicplan/plate-partials

> 标签: Integrators, Site Extension, Site Package, TYPO3 CMS, TypoScript

## 简介

provides fluid partials for generic use, partials are sorted in a atomic structure

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
