# atomicplan/plate-kesearch-ajaxbased

> 标签: PHP

## 简介

a template stack that provides layouts for keSearch and Ajax based search results

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
