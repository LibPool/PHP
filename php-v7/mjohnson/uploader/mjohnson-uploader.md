# mjohnson/uploader

> 标签: attachment, cakephp, file, plugin, uploader, validation

## 简介

File uploader and validation plugin for CakePHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
