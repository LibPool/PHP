# alcalyn/js-vars

> 标签: i18n, javascript, routing, service, symfony, translation

## 简介

Class to contains variables, routes and translations to pass to javascript.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
