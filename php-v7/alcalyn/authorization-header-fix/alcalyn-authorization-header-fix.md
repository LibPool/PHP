# alcalyn/authorization-header-fix

> 标签: apache, php, symfony

## 简介

Simple listener that restore Authorization header in a Symfony Request under Apache.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
