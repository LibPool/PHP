# leedohyung-dba/ses-topic-sniffer

> 标签: SNS, aws, php, ses

## 简介

A PHP library for catch detail information to SES topic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
