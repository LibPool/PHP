# starmile/partner-sdk

> 标签: Partner-API, cross-border, logistics, sdk, shipping, starmile

## 简介

Official PHP SDK for the Starmile Partner API — cross-border logistics integration (catalogue, orders, status pool, inbound events).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
