# emitra/emitra-php

> 标签: Socket.io, emitra, events, pub-sub, realtime, websocket

## 简介

PHP client for Emitra — real-time WebSocket event streaming

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
