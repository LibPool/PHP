# niif/simplesamlphp-module-attributescope

> 标签: filter, module, scope, simplesamlphp, sp

## 简介

Filter to remove attribute values which are not properly scoped.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
