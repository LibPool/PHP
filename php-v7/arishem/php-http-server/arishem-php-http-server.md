# arishem/php-http-server

> 标签: http-server, middleware, php, router, websocket

## 简介

A lightweight, in-house PHP HTTP server with WebSocket support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
