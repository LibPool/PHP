# walterjrp/tables

> 标签: data-table, data-table-server-side, datatable, laravel-enso

## 简介

Data Table library with server-side processing and a VueJS component

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
