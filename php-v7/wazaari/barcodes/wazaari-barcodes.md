# wazaari/barcodes

> 标签: CODABAR, CODE 128, CODE 39, barcode, barcodes, datamatrix, ean, generator, pdf417, qr code, qrcode

## 简介

Barcode generator for PHP supporting 20+ barcode types

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
