# samuelbie/mpesa

> 标签: B2C, Mpesa SDK, Reversal, b2b, c2b, laravel, m-pesa, mpesa, open-api, php, query

## 简介

This is an interface to communicate with Mpesa Open API Mozambique

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
