# easydowork/yii2-rotate-captcha

> 标签: captcha, rotate captcha, yii2

## 简介

基于isszz/rotate-captcha组件开发yii2图片旋转验证码

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
