# strider2038/json-rpc-client

> 标签: client, http, jsonrpc, jsonrpc2, psr18, tcp, unix

## 简介

Flexible JSON RPC v2 client for PHP written in object-oriented style

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
