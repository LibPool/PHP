# deltalab/custom-pixel-qrcode

> 标签: phpqrcode, qrcode

## 简介

Custom renderer for QRCodes, using pre-rendered images as pixels

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
