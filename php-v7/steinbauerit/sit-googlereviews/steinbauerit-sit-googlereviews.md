# steinbauerit/sit-googlereviews

> 标签: PHP

## 简介

A TYPO3 extension which shows Google ratings. A Google Places API Key and a Place ID are required.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
