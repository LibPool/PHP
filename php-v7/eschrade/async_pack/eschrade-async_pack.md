# eschrade/async_pack

> 标签: PHP

## 简介

This library is used as part of a Jetty PHP implementation with ActiveMQ.  It is largely a serialization/deserialization mechanism, using Stomp.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
