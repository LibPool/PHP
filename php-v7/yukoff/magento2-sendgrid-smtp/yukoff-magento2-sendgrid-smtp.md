# yukoff/magento2-sendgrid-smtp

> 标签: email, magento 2, magento2, sendgrid, smtp

## 简介

Configure Magento 2 to use SendGrid SMTP server to send email

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
