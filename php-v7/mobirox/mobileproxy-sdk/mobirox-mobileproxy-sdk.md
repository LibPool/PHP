# mobirox/mobileproxy-sdk

> 标签: API-Client, http-proxy, mobile-proxy, mobileproxy, proxy, scraping, socks5

## 简介

Official PHP SDK for MobileProxy.Space API — private mobile proxies on real GSM devices

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://mobileproxy.space
- 源码仓库：https://github.com/mobileproxy/php-sdk.git
- Packagist 页面：https://packagist.org/packages/mobirox%2Fmobileproxy-sdk
