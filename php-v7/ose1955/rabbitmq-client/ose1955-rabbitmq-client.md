# ose1955/rabbitmq-client

> 标签: AMQP, laravel, lumen, rabbitmq

## 简介

Laravel/Lumen Async and DirectRpc interfaces for RabbitMQ using AMQP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
