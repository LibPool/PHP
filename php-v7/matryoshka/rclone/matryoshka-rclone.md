# matryoshka/rclone

> 标签: Openstack Swift, Sync files, amazon S3, ceph, dropbox, file transfer, rclone, sftp, yandex disk

## 简介

A simple rclone wrapper

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
