# mfn/cakephp2-postgres-no-meta

> 标签: cakephp, database, postgres

## 简介

A CakePHP2 Postgres database driver without getColumnMeta() support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
