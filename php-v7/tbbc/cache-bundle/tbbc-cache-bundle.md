# tbbc/cache-bundle

> 标签: cache, cache abstraction, caching

## 简介

Symfony Bundle - Cache abstraction and method annotations for controlling cache

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
