# prgfx/neos-dynamic-placeholder

> 标签: Neos, ckeditor5, clienteval, neoscms

## 简介

Enables setting the Neos inline editor placeholder with ClientEval

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
