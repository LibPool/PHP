# prgfx/neos-pathsegment-edtor-fix

> 标签: PHP

## 简介

Resets defaults and adds options to customize special-character handling in the neos uri-path-segment editor.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
