# hesunfly/php-excel

> 标签: csv, excel, html, swoole, xls, xlsx

## 简介

php excel 导入导出, 由于需要在swoole中使用，所以重新构建了该扩展包，原地址：https://github.com/jianyan74/php-excel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
