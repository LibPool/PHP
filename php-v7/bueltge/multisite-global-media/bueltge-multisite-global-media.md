# bueltge/multisite-global-media

> 标签: multisite, muplugin, wordpress

## 简介

Multisite Global Media is a WordPress plugin which shares media across the Multisite network.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
