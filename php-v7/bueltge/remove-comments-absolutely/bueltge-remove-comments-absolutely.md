# bueltge/remove-comments-absolutely

> 标签: comments, plugin, wordpress

## 简介

Deactivate comments functions and remove areas absolutely from the WordPress install

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
