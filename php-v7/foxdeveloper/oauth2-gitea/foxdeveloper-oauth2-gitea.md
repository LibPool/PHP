# foxdeveloper/oauth2-gitea

> 标签: authorisation, authorization, client, gitea, oauth, oauth2

## 简介

Gitea OAuth 2.0 Client provider for the PHP League OAuth2-Client

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
