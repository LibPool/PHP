# gektor1/usaepay-php

> 标签: gateway, merchant, pay, payment, usaepay

## 简介

Fork of USAePay's PHP API library that includes composer package support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
