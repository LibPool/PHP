# devster/buzz-wsse-plugin

> 标签: Authentication, api, buzz, plugin, rest, wsse

## 简介

Buzz plugin to manage WSSE authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
