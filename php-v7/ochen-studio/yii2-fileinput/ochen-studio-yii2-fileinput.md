# ochen-studio/yii2-fileinput

> 标签: PHP

## 简介

Based on Krajee (kartik-v) advanced fileinput widget with no-ajax files removal posibility

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
