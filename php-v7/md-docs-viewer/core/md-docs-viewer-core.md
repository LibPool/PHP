# md-docs-viewer/core

> 标签: Viewer, docs, markdown, mermaid, psr-15

## 简介

Framework-agnostic Markdown docs viewer with Mermaid flowcharts and mindmap layout (PSR-15)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
