# joshuabedford/laravel-word-filter

> 标签: filter, laravel, profanity, validate, validation, word

## 简介

A word and/or profanity filter for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
