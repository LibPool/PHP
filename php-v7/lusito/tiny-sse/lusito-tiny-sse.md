# lusito/tiny-sse

> 标签: ServerSentEvents, commet, eventsource, polling, push, sse

## 简介

TinySSE is small helper to publish Server Sent Events aka EventSource.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
