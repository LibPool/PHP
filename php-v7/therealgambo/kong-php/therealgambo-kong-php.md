# therealgambo/kong-php

> 标签: api-gateway, kong, kong gateway, mashape-kong

## 简介

A PHP7 compliant library for interacting with the Kong Gateway Admin API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
