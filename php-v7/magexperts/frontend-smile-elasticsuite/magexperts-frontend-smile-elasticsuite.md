# magexperts/frontend-smile-elasticsuite

> 标签: PHP

## 简介

Magexperts_ViraSmileElasticsuite makes Smile_Elasticsuite compatible with Viraxpress Frontend Themes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
