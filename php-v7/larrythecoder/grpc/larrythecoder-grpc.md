# larrythecoder/grpc

> 标签: rpc

## 简介

gRPC library for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/larryTheCoder/php-grpc-library.git
