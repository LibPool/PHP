# ucsf/restorm-bundle

> 标签: orm, rest, ucsf

## 简介

REST-based ORM for Symfony - Obtain objects from a REST service... just like using an ORM

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
