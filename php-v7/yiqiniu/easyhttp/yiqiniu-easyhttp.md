# yiqiniu/easyhttp

> 标签: EasyHttp, curl, easy-http, http, php, php-http, phphttp

## 简介

EasyHttp 是一个轻量级、语义化、对IDE友好的HTTP客户端，支持常见的HTTP请求、异步请求和并发请求，让你可以快速地使用 HTTP 请求与其他 Web 应用进行通信。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
