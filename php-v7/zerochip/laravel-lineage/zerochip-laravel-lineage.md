# zerochip/laravel-lineage

> 标签: eloquent, eloquent-realtionships, laravel

## 简介

A Laravel package for chain calling eloquent relationships

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
