# heywooden/yunlock

> 标签: file, lock, memcache, memcached, php, redis

## 简介

PHP阻塞锁和非阻塞锁机制，内置解决并发锁重复执行的方案。目前支持文件File、Redis、Memcache、Memcached。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
