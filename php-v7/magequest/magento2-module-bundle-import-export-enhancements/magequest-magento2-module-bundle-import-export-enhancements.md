# magequest/magento2-module-bundle-import-export-enhancements

> 标签: PHP

## 简介

A Magento 2 module that improves the bundle product import export functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
