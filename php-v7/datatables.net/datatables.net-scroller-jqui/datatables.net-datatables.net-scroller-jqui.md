# datatables.net/datatables.net-scroller-jqui

> 标签: Virtual Scrolling, datatables, jQuery UI, jQueryUI, jquery, scroller, table

## 简介

Scroller for DataTables with styling for jQueryUI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
