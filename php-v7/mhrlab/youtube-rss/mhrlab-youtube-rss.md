# mhrlab/youtube-rss

> 标签: php, rss, youtube-feed, youtube-rss

## 简介

Small and easy-to-use library for consuming YouTube feeds

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
