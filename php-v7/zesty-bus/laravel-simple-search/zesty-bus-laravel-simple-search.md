# zesty-bus/laravel-simple-search

> 标签: Simple, laravel, laravel-simple-search, search, searching

## 简介

A simple wildcard search on eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
