# dominikveils/global-sms

> 标签: globalsms, globalsms.co.il, sms

## 简介

globalsms.co.il PHP helper class. Implements basic GlobalSMS API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
