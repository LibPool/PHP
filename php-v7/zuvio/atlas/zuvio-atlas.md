# zuvio/atlas

> 标签: atlas, cron, healthcheck, heartbeat, job, laravel, monitoring, zuvio

## 简介

Zuvio Atlas job/cron-run monitoring SDK — report start/finish/fail of scheduled jobs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
