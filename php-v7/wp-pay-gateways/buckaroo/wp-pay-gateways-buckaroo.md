# wp-pay-gateways/buckaroo

> 标签: buckaroo, gateway, pay, pronamic, wordpress, wp

## 简介

Buckaroo driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
