# wp-pay-gateways/paydutch

> 标签: gateway, pay, paydutch, pronamic, wordpress, wp

## 简介

PayDutch driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
