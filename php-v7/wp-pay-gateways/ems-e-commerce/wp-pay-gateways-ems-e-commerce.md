# wp-pay-gateways/ems-e-commerce

> 标签: EMS, gateway, pay, pronamic, wordpress, wp

## 简介

EMS e-Commerce Gateway driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
