# wp-pay-gateways/ideal

> 标签: gateway, ideal, pay, pronamic, wordpress, wp

## 简介

iDEAL driver for the WordPress payment processing library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
