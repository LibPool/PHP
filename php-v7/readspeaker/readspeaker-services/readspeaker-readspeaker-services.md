# readspeaker/readspeaker-services

> 标签: PHP

## 简介

A Typo3 extension for easily integrating ReadSpeaker webReader and docReader into your website. Please note that you need a valid ReadSpeaker license in order to use this extension. Learn more on www.readspeaker.com.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
