# lostlink/ark-crypto

> 标签: api, ark, blockchain, crypto, currency

## 简介

A simple PHP Cryptography Implementation for the Ark Blockchain.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
