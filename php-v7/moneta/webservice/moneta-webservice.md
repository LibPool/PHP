# moneta/webservice

> 标签: Merchant.API, Payment service, moneta.ru

## 简介

PHP library for access to MONETA.MerchantAPI (http://moneta.ru), psr-0 coding standard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
