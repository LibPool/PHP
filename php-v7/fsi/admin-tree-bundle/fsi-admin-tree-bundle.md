# fsi/admin-tree-bundle

> 标签: admin, bundle, doctrine-extensions, fsi, gedmo, symfony, tree

## 简介

Provides integration for fsi/admin-bundle with gedmo/doctrine-extensions tree.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
