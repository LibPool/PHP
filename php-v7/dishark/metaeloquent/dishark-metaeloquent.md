# dishark/metaeloquent

> 标签: eloquent, laravel, metatags

## 简介

Meta Eloquent is an eloquent booster that allows it to easily manage HTTP Meta tags

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
