# ccuffs/uffs-ru-scraping

> 标签: PHP

## 简介

Biblioteca para obter dados dos restaurantes universitários da UFFS de forma automatizada

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
