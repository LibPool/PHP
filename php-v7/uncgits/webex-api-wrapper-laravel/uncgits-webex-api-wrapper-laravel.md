# uncgits/webex-api-wrapper-laravel

> 标签: api, laravel, php, uncg, uncgits, webex

## 简介

Laravel Wrapper for WebEx API PHP Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
