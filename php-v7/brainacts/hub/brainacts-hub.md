# brainacts/hub

> 标签: PHP

## 简介

BA Hub - extension for magento 2 store that create menu for BrainActs extension and get information from BA service about installed BrainActs extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
