# alt3/tokens

> 标签: adapter-pattern, alt3, framework-agnostic, hhvm, php, tokens

## 简介

The framework agnostic library for generating (secure) token objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
