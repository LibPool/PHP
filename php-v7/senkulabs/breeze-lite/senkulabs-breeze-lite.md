# senkulabs/breeze-lite

> 标签: inertia, laravel, laravel-breeze, svelte

## 简介

Unofficial Laravel Breeze for Inertia + Svelte.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
