# businessboomers/theme-frontend-baseboomers

> 标签: PHP

## 简介

This theme works as a base for other themes of magento2 created by BusinessBoomers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
