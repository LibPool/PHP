# kamiyang/ext-t3cv_export

> 标签: TYPO3 CMS, typo3

## 简介

Extbase console command to dump and export TYPO3 CONF VARS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
