# didrive_mod/jobdesc

> 标签: didrive, module, nyos, uralweb.info

## 简介

Реестр работ связка модулей отделы + работники + выход на работу

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
