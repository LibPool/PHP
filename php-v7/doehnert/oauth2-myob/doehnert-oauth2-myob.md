# doehnert/oauth2-myob

> 标签: PHP

## 简介

This package provider MYOB OAuth 2.0 support for the PHP Leagu's OAuth 2.0 Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
