# package-hub/semver

> 标签: php, semver

## 简介

Package to check version according to Semantic Versioning 2.0.0 (http://semver.org).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/PackageHub/SemVer
- 源码仓库：https://github.com/PackageHub/SemVer.git
- Packagist 页面：https://packagist.org/packages/package-hub%2Fsemver
