# ph-7/cookiesession

> 标签: cookie, cookie session, php 7, secure, secure cookie, secure session, session

## 简介

Very light library to manage easily and simply the Session and Cookie with PHP 7+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
