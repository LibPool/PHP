# carry0987/filetree

> 标签: PHP

## 简介

A PHP library for generating signed and encrypted URLs with FileTree-API, using AES-256-GCM and HMAC-SHA256

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
