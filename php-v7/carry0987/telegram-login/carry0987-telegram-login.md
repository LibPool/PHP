# carry0987/telegram-login

> 标签: PHP

## 简介

TelegramLogin is a robust and user-friendly Composer package designed to streamline and simplify the Telegram login process for PHP-based applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
