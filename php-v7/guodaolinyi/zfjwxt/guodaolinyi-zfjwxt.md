# guodaolinyi/zfjwxt

> 标签: 正方教务系统, 正方教务系统爬虫, 正方爬虫

## 简介

正方教务系统爬虫，自动识别验证码，实现课表、四六级成绩等教务系统数据查询功能。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
