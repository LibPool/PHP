# pnglabz/cakephp-elastic-email

> 标签: cakephp, elasticemail, email

## 简介

ElasticEmail plugin for CakePHP 3 - Send transactional emails using Elastic Email API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
