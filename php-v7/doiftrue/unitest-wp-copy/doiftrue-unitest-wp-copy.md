# doiftrue/unitest-wp-copy

> 标签: PHP

## 简介

Collection of WordPress core functions and classes that can be used in unit tests to simulate WordPress environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
