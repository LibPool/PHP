# dotit/sms-sending-bundle

> 标签: dotit, sending, sms, tunisiesms

## 简介

SmsSendingBundle is a Symfony 3.4 bundle for tunisiesms Api .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
