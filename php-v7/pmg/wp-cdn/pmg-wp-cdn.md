# pmg/wp-cdn

> 标签: cdn, wordpress

## 简介

Simple origin-pull CDN plugin for WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://packagist.org/packages/pmg%2Fwp-cdn
