# maniyatech/magento2-buynow

> 标签: PHP

## 简介

Instant "Buy Now" button for Magento 2 product pages to speed up checkout and improve user experience.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
