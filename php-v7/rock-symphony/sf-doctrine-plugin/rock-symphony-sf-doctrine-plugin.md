# rock-symphony/sf-doctrine-plugin

> 标签: doctrine, orm, symfony

## 简介

symfony 1.x plugin to add sfDoctrine support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
