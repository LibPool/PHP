# rock-symphony/propel-orm

> 标签: Active Record, database, mapping, orm, persistence

## 简介

Rock Symphony Propel is an open-source Object-Relational Mapping (ORM) for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
