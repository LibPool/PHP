# jokermario/php-jwt-flavour

> 标签: Enhanced, jwt, php

## 简介

A simple library to encode and decode JSON Web Tokens (JWT) in PHP. This flavour includes a unique identifier in the JWT Header

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
