# risan/jne

> 标签: JNE, Tariff, http client, indonesia, shipment

## 简介

PHP HTTP client library for checking JNE shipment prices.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
