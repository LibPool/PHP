# luoyou/hyperf-json-relation

> 标签: PHP

## 简介

基于hyperf的json-relation，解决数据库中使用json字段的关联with问题

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
