# guanguans/laravel-dump-sql

> 标签: dd, debug, dump, laravel, mysql, sql

## 简介

laravel 中轻松容易的输出完整的 SQL 语句。 - Easy output of complete SQL statements for laravel framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
