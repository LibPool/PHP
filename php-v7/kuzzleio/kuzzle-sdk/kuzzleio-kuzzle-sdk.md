# kuzzleio/kuzzle-sdk

> 标签: PHP

## 简介

Official PHP SDK for Kuzzle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://kuzzle.io
- 源码仓库：https://github.com/kuzzleio/sdk-php.git
- Packagist 页面：https://packagist.org/packages/kuzzleio%2Fkuzzle-sdk

- Packagist 仓库：https://repo.packagist.org/p2/kuzzleio/kuzzle-sdk.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4
