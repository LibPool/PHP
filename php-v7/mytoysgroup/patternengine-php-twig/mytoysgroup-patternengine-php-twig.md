# mytoysgroup/patternengine-php-twig

> 标签: pattern engine, pattern lab, twig

## 简介

MyToys Group implementation of Twig-based PatternEngine for Pattern Lab; Forked from pattern-lab/patternengine-twig

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
