# moeen-basra/laravel-passport-mongodb

> 标签: laravel, oauth, passport

## 简介

Laravel Passport provides OAuth2 server support to Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
