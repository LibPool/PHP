# msyk/dropbox-api-shortlivedtoken

> 标签: Dropbox API, dropbox, oauth2, php

## 简介

Sample implementation of generating access token from refresh token.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
