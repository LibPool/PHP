# technodelight/php-cli-cross-platform-open

> 标签: PHP

## 简介

Opens a file or URL in the user's preferred application in CLI (cross platform)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
