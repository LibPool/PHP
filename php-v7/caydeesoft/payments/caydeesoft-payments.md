# caydeesoft/payments

> 标签: B2C, MTN Mobile Money, Mobile Payments, africa payments, airtel money, b2b, c2b, eazzypay, equity bank, kenya payments, laravel payments, m-pesa, mobile money, mpesa, payment callbacks, safaricom daraja, stk push, t-kash, tigo pesa, tkash

## 简介

Laravel mobile money payment gateway package for M-Pesa, Airtel Money, T-Kash, EazzyPay, MTN and Tigo callbacks, STK push, refunds, balances and disbursements.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
