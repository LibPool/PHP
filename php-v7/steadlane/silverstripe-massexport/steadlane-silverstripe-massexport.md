# steadlane/silverstripe-massexport

> 标签: PHP

## 简介

A tool that allows you to export multiple Models at once and zip them into a single file for a specific date range

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
