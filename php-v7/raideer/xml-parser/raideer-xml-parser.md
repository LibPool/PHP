# raideer/xml-parser

> 标签: abstract syntax tree, ast, lexer, parser, xml

## 简介

XML parser written in PHP for usage in IDE tools. Produces an Abstract Syntax Tree.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
