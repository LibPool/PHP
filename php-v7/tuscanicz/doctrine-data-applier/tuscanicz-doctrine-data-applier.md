# tuscanicz/doctrine-data-applier

> 标签: data, doctrine, migrations

## 简介

Symfony bundle for Doctrine Migrations of data using doctrine entities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
