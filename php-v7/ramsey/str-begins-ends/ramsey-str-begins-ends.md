# ramsey/str-begins-ends

> 标签: mb_str_begins, mb_str_ends, mb_str_ibegins, mb_str_iends, polyfill, str_begins, str_ends, str_ibegins, str_iends, strings

## 简介

Provides functions to test whether a string begins or ends with a certain substring.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
