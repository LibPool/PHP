# wyrihaximus/ratchet-model-push

> 标签: Ratchet, cakephp

## 简介

Allows models to push data on write operations to wyrihaximus/ratchet.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
