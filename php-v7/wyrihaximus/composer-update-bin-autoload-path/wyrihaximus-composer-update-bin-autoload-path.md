# wyrihaximus/composer-update-bin-autoload-path

> 标签: PHP

## 简介

🏰 Composer plugin that fills a bin file with the absolute composer autoload path

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
