# algolia/algoliasearch-inventory-magento-2

> 标签: PHP

## 简介

Algolia Search Inventory module for Magento 2.3.x, 2.4.x and Algolia Search 3.* extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
