# namesco/ztal

> 标签: phptal, template engine, zend, zope

## 简介

ZTal makes integrating the PHP templating system PHPTAL into Zend Framework easy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
