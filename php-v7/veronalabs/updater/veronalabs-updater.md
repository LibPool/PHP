# veronalabs/updater

> 标签: PHP

## 简介

A custom update checker for WordPress plugins and themes based on yahnis-elsts/plugin-update-checker and own private license server updater.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
