# kinedu/cfdi-pac

> 标签: Kinedu, cfdi, pac, sat

## 简介

Librería para timbrar un CFDI con algún Proveedor Autorizado de Certificación (PAC)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
