# kinedu/cfdi-xslt

> 标签: Kinedu, cfdi, sat

## 简介

Librería para descargar los XSLT de la Cadena Original del Servicio de Administración Tributaria (SAT)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
