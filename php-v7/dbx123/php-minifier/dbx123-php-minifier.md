# dbx123/php-minifier

> 标签: CSS3, HTML5, JS, compress, css, free, html, javascript, min, minify, open source, php, php5, phpmin

## 简介

A PHP minifier for HTML, CSS and JS files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
