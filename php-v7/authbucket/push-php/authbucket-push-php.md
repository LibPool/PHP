# authbucket/push-php

> 标签: PSR-1, PSR-2, PSR-4, apns, gcm, notification, oauth2, psr-3, push, silex

## 简介

Push notifications for mobile devices based on the Symfony Components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
