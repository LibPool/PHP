# realripley00/laravel-simple-page-builder

> 标签: cms, eloquent, laravel, laravel5

## 简介

Simple static page content management for Larvel projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
