# devpoint/search-client-database-eloquent

> 标签: database, eloquent, laravel, php, searchclient

## 简介

SearchClient database wrapper for Laravel Eloquent.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
