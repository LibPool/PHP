# fontis/customergroupaccess-mage2

> 标签: PHP

## 简介

Provides a convenience class for implementing customer group based access in your Magento 2 extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
