# viewcomposersimple/simple

> 标签: PHP

## 简介

Generates a basic structure of View Composer in Laravel on execution of 'view:composer' console command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
