# bariew/yii2-invisible-recaptcha

> 标签: extension, recaptcha, validation, yii2

## 简介

Validates form post with Goolge Invisible Recaptcha

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
