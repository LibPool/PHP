# checkitsedo/checkit-adventcalendar

> 标签: PHP

## 简介

A customizable responsive advent calendar show Modals based on pages as content placeholders for the several wickets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
