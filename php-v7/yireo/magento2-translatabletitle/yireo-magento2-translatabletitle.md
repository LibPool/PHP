# yireo/magento2-translatabletitle

> 标签: composer-installer, magento

## 简介

Magento 2 extension to make XML layout titles translatable

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/yireo/Yireo_TranslatableTitle
- 源码仓库：https://github.com/yireo/Yireo_TranslatableTitle.git
- Packagist 页面：https://packagist.org/packages/yireo%2Fmagento2-translatabletitle

## 获取地址

- Composer 安装：`composer require yireo/magento2-translatabletitle`
- Packagist 仓库：https://repo.packagist.org/p2/yireo/magento2-translatabletitle.json
- 许可证：OSL-3.0
- PHP 要求：>=7.0.0
