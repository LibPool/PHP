# yireo/magento2-clean-modules

> 标签: Yireo, magento, magento 2

## 简介

Magento 2 module to remove invalid entries from app/etc/config.php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
