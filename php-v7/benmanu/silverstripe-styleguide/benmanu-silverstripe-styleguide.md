# benmanu/silverstripe-styleguide

> 标签: kss, silverstripe, styleguide

## 简介

Generates a styleguide for a SilverStripe theme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
