# flix-tech/guzzle-circuit-breaker-middleware

> 标签: PHP

## 简介

A Guzzle 6 middleware to integrate `ejsmont-artur/php-circuit-breaker`

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
