# shiyang/yii2-infinite-scroll

> 标签: infinite-scroll, jquery, plugin, widget, yii2

## 简介

Yii2 extension for infinite-scroll jQuery plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
