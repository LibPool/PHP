# trtlservices/ts-api-php

> 标签: TRTL API Wrapper, TRTL Apps, TRTL Services, TurtleCoin, TurtleCoin Apps

## 简介

PHP wrapper for TRTL Services RESTFUL API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
