# key-warden/sdk

> 标签: Ed25519, activation, key-warden, keywarden, licence, license, licensing, offline-verification

## 简介

Official PHP client for Key-Warden - validate software licences online (seat- and revocation-aware) or verify signed Ed25519 tokens offline against your embedded public key.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
