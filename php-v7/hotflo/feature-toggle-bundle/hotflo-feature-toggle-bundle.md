# hotflo/feature-toggle-bundle

> 标签: PHP

## 简介

A Symfony2 Bundle implementing the https://github.com/JoshuaEstes/FeatureToggle library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
