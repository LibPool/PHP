# chenyongze/esign-sdk

> 标签: PHP

## 简介

根据e签宝官方文档开发的一个 PHP 扩展包,API V2 SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
