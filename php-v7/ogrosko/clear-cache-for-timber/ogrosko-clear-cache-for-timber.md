# ogrosko/clear-cache-for-timber

> 标签: clear cache, timber, wordpress

## 简介

WordPress Plugin extends Timber WP plugin with clearing cache functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
