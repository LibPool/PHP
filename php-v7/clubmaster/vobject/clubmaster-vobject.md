# clubmaster/vobject

> 标签: VObject, iCalendar, vCard

## 简介

The VObject library for PHP allows you to easily parse and manipulate iCalendar and vCard objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
