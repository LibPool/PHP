# packfire/php5.3-compat

> 标签: OOP, compatibility, library

## 简介

Provides class and interface compatibility between PHP 5.3 and PHP 5.4 through autoloading.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
