# ianrothmann/langserve-php-client

> 标签: PHP

## 简介

A PHP Client for your LangServe project that is able to call API endpoints such as invoke, batch and stream.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
