# ianrothmann/laravel-rocket-upload

> 标签: PHP

## 简介

Back-end handler for file uploads. Designed to complement the Rocket Vue App Framework Multiple File Upload.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
