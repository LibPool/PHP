# laracasts/integrated

> 标签: goutte, integration, laracasts, laravel, testing

## 简介

Simple, intuitive integration testing with PHPUnit.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
