# greenplugin/yandex-pdd

> 标签: api, pdd, pdd client, rest, yandex, yandex api, yandex dns

## 简介

This is simple way to use yandex pdd api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
