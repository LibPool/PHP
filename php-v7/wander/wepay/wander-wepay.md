# wander/wepay

> 标签: WePayPartner, WePayV3, WeXinPay, wechatpay, wepay

## 简介

微信支付v3版 for PHP,支持微信支付v3版商户直连模式（WePay）和服务商模式（WePayPartner）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- Packagist 页面：https://packagist.org/packages/wander%2Fwepay
