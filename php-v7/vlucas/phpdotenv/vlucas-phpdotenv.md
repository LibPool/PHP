# vlucas/phpdotenv

> 标签: dotenv, env, environment, 环境变量, 配置

## 简介

Loads environment variables from `.env` to `$_ENV` and `$_SERVER` automagically, and optionally to `getenv()`.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
