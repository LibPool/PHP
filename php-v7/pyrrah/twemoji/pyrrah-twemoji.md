# pyrrah/twemoji

> 标签: emoji, symfony, twemoji, twemoji symfony

## 简介

The simple way to use Twitter Emoji (Twemoji) for Symfony 6.x.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
