# jeyroik/sm-plugin-route-from-start

> 标签: PHP

## 简介

Plugin for jeyroik StateMachine. Just make start state more human-adopted.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
