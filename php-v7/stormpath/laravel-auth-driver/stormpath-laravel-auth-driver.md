# stormpath/laravel-auth-driver

> 标签: Authentication, authorization, laravel, stormpath

## 简介

Drop-in Auth Driver to use Stormpath services for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
