# stormpath/laravel

> 标签: Authentication, Users, accounts, authorization, laravel, stormpath

## 简介

Build simple, secure web applications with Stormpath and Laravel!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
