# stormpath/sdk

> 标签: Authentication, User management, api, cloud, group management, security, stormpath, user security

## 简介

A PHP wrapper for Stormpath's API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
