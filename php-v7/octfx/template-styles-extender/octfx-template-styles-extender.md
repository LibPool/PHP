# octfx/template-styles-extender

> 标签: TemplateStyles, TemplateStylesExtender, extension, mediawiki

## 简介

Extends TemplateStyles with new CSS properties

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
