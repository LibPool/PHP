# flogar/htmltopdf

> 标签: flogar, representacion-impresa, wkhtmltodf

## 简介

Flogar Reporte Html a Pdf usando wkhtmltopdf

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
