# mahocommerce/module-mcrypt-compat

> 标签: maho, mahocommerce, mcrypt

## 简介

Mcrypt compatibility module for Maho >=25.5.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
