# wikia/simplehtmldom

> 标签: PHP

## 简介

A simple PHP HTML DOM parser written in PHP5+, supports invalid HTML, and provides a very easy way to handle HTML elements.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
