# tamashiro/ndse

> 标签: PHP

## 简介

NDSE - Network Dynamic Simulation Engine. A PHP package for electrical power system load flow and transient stability analysis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
