# phalcana/userguide

> 标签: Phalcana, kohana, phalcon

## 简介

Userguide module for Phalcana project based of the module for Kohana of the same name

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
