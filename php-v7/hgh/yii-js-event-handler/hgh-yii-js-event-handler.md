# hgh/yii-js-event-handler

> 标签: javascript, jquery, php, yii2

## 简介

Using this library, You can define custom events and trigger them on other events trigger.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
