# kachkaev/daf-bundle

> 标签: abstraction, database, dataset, postgres, postgresql

## 简介

Simplifies processing of the datasets stored in a postgresql database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
