# langming/captcha

> 标签: ImageMagick, VerifyCode, captcha, imagick, laravel, 验证码

## 简介

适用于laravel的验证码扩展包，支持英文、中文，数字运算

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
