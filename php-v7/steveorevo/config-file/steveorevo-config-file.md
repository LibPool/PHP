# steveorevo/config-file

> 标签: config, ini, parse

## 简介

Allows for easy querying and updating of popular configuration and source code file formats (Apache config, PHP, ini, etc).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
