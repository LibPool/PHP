# liuwave/think-filesystem-driver-cos

> 标签: cos, filesystem, think-filesystem-driver-cos, 对象存储, 腾讯云

## 简介

这是一个基于腾讯云对象存储的thinkphp6.0 Filesystem驱动

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
