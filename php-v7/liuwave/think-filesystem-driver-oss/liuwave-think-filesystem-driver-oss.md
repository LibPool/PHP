# liuwave/think-filesystem-driver-oss

> 标签: filesystem, oss, think-filesystem-driver-oss, 对象存储

## 简介

这是一个基于阿里云对象存储的thinkphp6.1.1 Filesystem驱动

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
