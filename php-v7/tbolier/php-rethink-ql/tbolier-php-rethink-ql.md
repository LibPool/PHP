> 标签: adapter, database, driver, nosql, nosql-database, php, php-rethinkdb, php-rethinkdb-driver, reql, rethinkdb, rethinkdb-adapter, rethinkdb-ql

## 简介

A clean and solid RethinkDB driver for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
