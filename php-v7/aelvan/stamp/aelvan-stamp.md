# aelvan/stamp

> 标签: Craft, asset-rev, cms, craft-plugin, craftcms, timestamp

## 简介

A simple plugin for adding timestamps to filenames.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
