# pravda1979/yii2-tinymce

> 标签: tinymce, wysiwyg, yii2

## 简介

TinyMCE WYSIWYG HTML Editor for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
