# diegonz/php-wake-on-lan

> 标签: lan, magicpacket, wake, wakeonlan

## 简介

Wake on lan target enabled devices by sending magic packets to them from PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
