# vivre-tech/rest-grid

> 标签: api, grid, rest, rest-grid, yii2

## 简介

For Yii2: This extension provides the ability like GridView but for REST.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
