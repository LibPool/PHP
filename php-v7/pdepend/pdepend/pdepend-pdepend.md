# pdepend/pdepend

> 标签: PHP Depend, PHP_Depend, dev, pdepend

## 简介

Official version of pdepend to be handled with Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
