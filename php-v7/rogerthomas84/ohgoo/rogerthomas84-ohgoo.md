# rogerthomas84/ohgoo

> 标签: Authentication, auth, oauth, ohgoo

## 简介

OhGoo is a simple OAuth library for authenticating Google users with your application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
