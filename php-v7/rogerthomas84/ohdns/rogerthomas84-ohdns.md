# rogerthomas84/ohdns

> 标签: AAAA, MX, a, dns, lookup, ohdns

## 简介

OhDns is a DNS record lookup library for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
