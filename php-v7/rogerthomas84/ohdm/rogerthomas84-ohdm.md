# rogerthomas84/ohdm

> 标签: object document mapper, odm, ohdm

## 简介

OhDM is a PHP Object Document Mapper (ODM) for MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
