# ferguson/yii2-base

> 标签: base, extension, ferguson, foundation, widget, yii2

## 简介

Base library and foundation components for all Yii2 ferguson extensions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
