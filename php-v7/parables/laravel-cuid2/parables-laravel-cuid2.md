# parables/laravel-cuid2

> 标签: cuid, cuid2, eloquent, laravel, model

## 简介

This package allows you to easily work with Cuid2 in your Laravel models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
