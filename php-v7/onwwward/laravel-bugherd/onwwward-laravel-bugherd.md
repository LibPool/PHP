# onwwward/laravel-bugherd

> 标签: bug tracking, bugherd, laravel, lumen

## 简介

Laravel 5 wrapper for Bugherd API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
