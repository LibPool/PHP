# brianhenryie/composer-phpstorm

> 标签: composer, excludefolder, phpstorm

## 简介

Composer script to exclude folders from PhpStorm code navigation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
