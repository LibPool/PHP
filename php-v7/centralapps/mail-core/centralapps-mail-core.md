# centralapps/mail-core

> 标签: email, mail, mailgun, postmarkapp

## 简介

Abstract mail component for external APIs and Services, including PostmarkApp and Mail Gun

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
