# pmh/pdf-report-bundle

> 标签: bundle, pdf, report, symfony

## 简介

Symfony Bundle. Wrapper of wkhtmltopdf that uses twig templating to generate pdf files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
