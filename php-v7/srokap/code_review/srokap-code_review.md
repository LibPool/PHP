# srokap/code_review

> 标签: analyzer, elgg, plugin, tools

## 简介

Elgg plugin that analyzes plugins code and provides basic information on code quality, compatibility and structure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
