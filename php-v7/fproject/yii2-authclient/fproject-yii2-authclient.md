# fproject/yii2-authclient

> 标签: authenticate, fproject, oauth, yii2

## 简介

F-Project Extended OAuth client components for Yii 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
