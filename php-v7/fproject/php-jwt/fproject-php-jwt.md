# fproject/php-jwt

> 标签: PHP

## 简介

A simple library to encode and decode JSON Web Tokens (JWT) in PHP. Support several key types including JWK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
