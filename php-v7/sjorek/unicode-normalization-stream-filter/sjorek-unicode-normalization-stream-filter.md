# sjorek/unicode-normalization-stream-filter

> 标签: nfc, nfd, nfkc, nfkd, normalization, stream, stream-filter, unicode, utf8

## 简介

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
