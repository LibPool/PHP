# fousheezy/fzy-doctrine-utils

> 标签: PHP

## 简介

Doctrine utility classes used in nearly any project that interacts with Doctrine repositories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
