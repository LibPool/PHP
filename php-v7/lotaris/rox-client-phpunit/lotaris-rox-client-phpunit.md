# lotaris/rox-client-phpunit

> 标签: analytics, phpunit, rox, test

## 简介

PHPUnit client for submitting test results to ROX Center.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
