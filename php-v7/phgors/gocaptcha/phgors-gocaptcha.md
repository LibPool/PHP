# phgors/gocaptcha

> 标签: behavioral-captcha, captcha, click-captcha, gd, go-captcha, php, rotate-captcha, slide-captcha

## 简介

PHP 行为验证码库（点选/滑动/旋转），go-captcha 生态 PHP 后端实现

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
