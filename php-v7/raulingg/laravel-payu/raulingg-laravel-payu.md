# raulingg/laravel-payu

> 标签: laravel, pagos, payu, payu latam, payu peru

## 简介

Una interfaz fluida para Laravel usando el SDK oficial de PayU Perú.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
