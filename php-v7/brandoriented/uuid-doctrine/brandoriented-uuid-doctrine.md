# brandoriented/uuid-doctrine

> 标签: database, doctrine, guid, identifier, uuid

## 简介

Allow the use of ramsey/uuid as a Doctrine field type.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
