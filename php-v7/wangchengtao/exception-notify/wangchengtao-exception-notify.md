# wangchengtao/exception-notify

> 标签: Feishu, dingtalk, exception, notify

## 简介

异常监控, 支持钉钉群机器人,飞书群机器人,企业微信群机器人, 以及自定义通道

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
