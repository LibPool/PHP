# nzo/left-sidebar-bundle

> 标签: left-sidebar, menu, template

## 简介

The NzoLeftSidebarBundle is a Symfony Bundle used to handle Left SideBare Menu

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
