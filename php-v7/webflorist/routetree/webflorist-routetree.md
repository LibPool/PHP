# webflorist/routetree

> 标签: laravel, localization, multi-language, php, route

## 简介

RouteTree: Advanced Route Management for Laravel (>=v5.5)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
