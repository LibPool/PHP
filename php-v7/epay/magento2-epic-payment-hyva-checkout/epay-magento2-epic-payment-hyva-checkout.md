# epay/magento2-epic-payment-hyva-checkout

> 标签: PHP

## 简介

Hyvä Checkout compatibility module for ePay EPIC Payment for Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
