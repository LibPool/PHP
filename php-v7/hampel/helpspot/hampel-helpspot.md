# hampel/helpspot

> 标签: Guzzle, HelpSpot, api, help desk

## 简介

Wrapper for the HelpSpot helpdesk system API using Guzzle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
