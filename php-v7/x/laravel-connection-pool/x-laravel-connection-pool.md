# x/laravel-connection-pool

> 标签: async, concurrency, coroutine, database, laravel, php, pool, swoole

## 简介

Connection pooling for illuminate/database and the Swoole PHP Extension

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
