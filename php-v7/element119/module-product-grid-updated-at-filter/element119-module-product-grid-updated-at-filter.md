# element119/module-product-grid-updated-at-filter

> 标签: PHP

## 简介

A Magento 2 module that allows admins to filter product's by their updated at timestamp.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
