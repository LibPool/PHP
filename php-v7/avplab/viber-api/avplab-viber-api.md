# avplab/viber-api

> 标签: REST API, php, viber, viber-api

## 简介

Viber Api supplies comfortable way to deal with Viber Rest API and Viber Bot creation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
