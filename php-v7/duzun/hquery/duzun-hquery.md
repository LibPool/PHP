# duzun/hquery

> 标签: broken-html, crawling, css-selectors, efficient, fast-parser, fastest, html, http, index, invalid, invalid-html, jquery-like, jquery-selectors, parser, php, psr-7, scraper, scraping, selectors, url, web, xhtml, xml

## 简介

An extremely fast web scraper that parses megabytes of HTML in a blink of an eye. No dependencies. PHP5+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
