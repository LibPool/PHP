# random-cuber/contextmenu_folder

> 标签: Context, create, delete, filter, folder, locate, mailbox, menu, rename, view

## 简介

Adds context menus with mailbox operations

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
