> 标签: CSS-Framework, css, dark-mode, framework, frontend, kardocss, mobile-first, responsive, tailwind-alternative, utility-first

## 简介

Framework CSS moderno, mobile-first y ultra-ligero con Dark Mode y PurgeCSS integrados

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
