# robinthehood/syntax-highlighter

> 标签: highlighting, html, php, syntax

## 简介

With SyntaxHighlighter you can easily output syntax highlighted code as HTML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
