# benrowe/laravel-config

> 标签: config, filter, laravel, read, write

## 简介

A basic laravel runtime configuration handler that is stored as simple key/values.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
