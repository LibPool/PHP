# itryit/laravel-ps-redis

> 标签: PHP

## 简介

A simple sentinel/redis driver wrapper for laravel 5.*. Rewrited For jamescauwelier/psredis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
