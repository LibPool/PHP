# inspirenmy/php-math-parser

> 标签: math calculator, math parser, shunting-yard algorithm

## 简介

Simple mathematical expression parser and calculator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
