# dalholm/laravel-spa-starter-kit

> 标签: SPA, admin, laravel, template, vue

## 简介

A simple lightweight SPA admin template based on laravel and vuejs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
