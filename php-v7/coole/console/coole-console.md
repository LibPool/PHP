# coole/console

> 标签: console, coole

## 简介

Console component of the Coole framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://github.com/coole/console
- 源码仓库：https://github.com/coolephp/console.git
- Packagist 页面：https://packagist.org/packages/coole%2Fconsole

- Composer 安装：`composer require coole/console`
