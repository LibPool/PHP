# ffans/bbcode-studio

> 标签: bbcode, embed, flarum, formatter, media

## 简介

Custom BBCode rules, media embeds, and composer buttons for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
