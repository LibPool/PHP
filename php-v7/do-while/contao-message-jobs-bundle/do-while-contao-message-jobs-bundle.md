# do-while/contao-message-jobs-bundle

> 标签: contao, messages, notification, sql, widget

## 简介

Generate messages notifications from SQL selects within Contao backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
