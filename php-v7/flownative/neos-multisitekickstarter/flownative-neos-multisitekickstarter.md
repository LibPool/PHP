# flownative/neos-multisitekickstarter

> 标签: PHP

## 简介

A simple generator for Neos sites, prepared to be separated in a multi-site setup.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
