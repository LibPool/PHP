# unionco/calendarize

> 标签: Calendarize, Craft, cms, craft-plugin, craftcms

## 简介

A calendar field type providing functionality for recurrence.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
