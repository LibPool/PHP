# yalv/alipay-f2fpay

> 标签: alipay, f2fpay, yalv

## 简介

A library to use alipay-f2fpay for ss-panel-mod-with-f2fpay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
