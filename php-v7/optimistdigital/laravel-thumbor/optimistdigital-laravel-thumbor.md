# optimistdigital/laravel-thumbor

> 标签: laravel, outl1ne, thumbor

## 简介

This Laravel package is a wrapper around 99designs/phumbor package which generates Thumbor URLs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
