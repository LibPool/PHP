# optimistdigital/laravel-scout-batch-searchable

> 标签: batch, laravel, scout

## 简介

This Laravel package adds a BatchSearchable trait to allow batching Scout updates.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
