# lucasbramos/wordpress-hooks-load

> 标签: PHP

## 简介

Classe que irá realizar o carregamento das actions e filters que serão utilizadas nos plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
