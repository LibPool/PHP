# netzhirsch/cookie-opt-in-bundle

> 标签: contao, cookie, cookiebar, opt-in

## 简介

Cookie Bar für Contao CMS. Cookies werden erst nach einer Einwilligung gesetzt. Einwilligungen werden aufgezeichnet und können vom Besucher widerrufen werden. Einzelne Cookies und oder ganze Gruppen können angenommen bzw. abgelehnt werden. Weitere Infos auf Github und https://www.netzhirsch.de/contao-cookie-opt-in-bundle.html

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
