# atiksoftware/php-class-facebook

> 标签: facebook, pass, php, post, share, user

## 简介

PHP image or text post on facebook as mobile login with username and password.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
