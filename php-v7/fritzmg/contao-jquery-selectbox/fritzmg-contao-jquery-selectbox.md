# fritzmg/contao-jquery-selectbox

> 标签: contao, extension, form, jquery, select

## 简介

Contao integration for the jQuery selectBox plugin by marcj

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
