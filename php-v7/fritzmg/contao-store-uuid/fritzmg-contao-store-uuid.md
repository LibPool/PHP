# fritzmg/contao-store-uuid

> 标签: HOOK, contao, file, form, uuid

## 简介

Mini extension which integrates a storeFormData hook to automatically convert file paths to UUIDs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
