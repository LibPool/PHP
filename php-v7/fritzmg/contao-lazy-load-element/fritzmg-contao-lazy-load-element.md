# fritzmg/contao-lazy-load-element

> 标签: contao, content, element, lazy, load, module

## 简介

Contao extension to allow lazy loading of content elements or modules.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
