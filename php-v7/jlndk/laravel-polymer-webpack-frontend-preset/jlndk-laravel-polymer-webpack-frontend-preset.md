# jlndk/laravel-polymer-webpack-frontend-preset

> 标签: laravel, polymer, preset, webpack

## 简介

Laravel 5.5.X Front-end preset for Polymer 2.x using webpack.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
