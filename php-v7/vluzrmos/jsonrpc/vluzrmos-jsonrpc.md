# vluzrmos/jsonrpc

> 标签: client, curl, http, json rpc, json-rpc, jsonrpc, rpc, server

## 简介

JSON-RPC 2.0 Client and Server implementation for PHP 5.6+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
