# jesseschalken/set

> 标签: PHP

## 简介

java.utils.Set for PHP implementing ArrayAccess, Countable and IteratorAggregate with O(1) conversion to/from array keys

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
