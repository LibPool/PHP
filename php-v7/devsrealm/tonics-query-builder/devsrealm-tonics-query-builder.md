# devsrealm/tonics-query-builder

> 标签: PHP

## 简介

Tonics SQL Query Builder is a library for building SQL in a modular and a hookable manner

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
