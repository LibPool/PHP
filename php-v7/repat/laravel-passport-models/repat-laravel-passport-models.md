# repat/laravel-passport-models

> 标签: eloquent, laravel, model, oauth, passport

## 简介

Eloquent Models for the oauth_ tables as created by laravel/passport

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
