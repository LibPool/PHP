# repat/laravel-5-dbug

> 标签: cfdump, dbug, debug, dump, laravel

## 简介

A library for nicer looking variable dumps comparable to ColdFusion's cfdump.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
