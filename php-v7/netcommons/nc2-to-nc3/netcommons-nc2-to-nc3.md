# netcommons/nc2-to-nc3

> 标签: cakephp, nc2-to-nc3

## 简介

Nc2ToNc3 Plugin for NetCommons3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
