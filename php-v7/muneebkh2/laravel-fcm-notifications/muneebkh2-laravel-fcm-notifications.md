# muneebkh2/laravel-fcm-notifications

> 标签: PHP

## 简介

Laravel package for sending push notifications using Firebase Cloud Messaging (FCM).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
