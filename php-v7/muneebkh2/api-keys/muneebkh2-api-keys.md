# muneebkh2/api-keys

> 标签: api, api-auth, api-keys, api-token, authorizatoin, laravel, token

## 简介

Generate and use header based API token for laravel api's.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
