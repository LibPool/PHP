# duamel/medoo

> 标签: database, lightweight, mariadb, mssql, mysql, oracle, php framework, postgresql, sql, sqlite

## 简介

The lightest PHP database framework to accelerate development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
