# blackmesasl/silex-chromephp

> 标签: chromephp, serviceprovider, silex

## 简介

Silex package to implement ChromePHP as ServiceProvider

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
