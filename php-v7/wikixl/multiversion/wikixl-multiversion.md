# wikixl/multiversion

> 标签: configuration, multiversion, simplesamlphp

## 简介

Enables SimpleSamlPHP MultiVersion behavior. Easily configures multi domains on one codebase.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
