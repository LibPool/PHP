# ktquez/laravel-tinymce

> 标签: CKEditor, editor, laravel, lumen, textarea, tinymce, wysiwyg

## 简介

TinyMCE editor for Laravel and Lumen Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
