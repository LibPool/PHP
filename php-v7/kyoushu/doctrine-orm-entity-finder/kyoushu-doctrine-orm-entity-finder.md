# kyoushu/doctrine-orm-entity-finder

> 标签: PHP

## 简介

Boilerplate for building finder classes to be used with Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
