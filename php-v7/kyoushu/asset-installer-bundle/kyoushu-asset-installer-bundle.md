# kyoushu/asset-installer-bundle

> 标签: PHP

## 简介

A bundle for copying vendor assets (e.g. images, webfonts) into the web directory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
