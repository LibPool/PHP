# kusflo/prestashop-webservice

> 标签: ERP, api, arrays, date, filter, php, prestashop, store, webservices

## 简介

PHP wrapper for PrestaShop Webservices 1.7.x and 1.6.x.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
