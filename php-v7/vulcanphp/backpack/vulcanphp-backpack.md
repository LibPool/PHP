# vulcanphp/backpack

> 标签: PHP

## 简介

Backend Kit for Hyper Framework to Build a Panel, CRUD, FORMS, AUTH, and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
