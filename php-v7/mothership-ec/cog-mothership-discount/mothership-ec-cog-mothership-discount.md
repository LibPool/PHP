# mothership-ec/cog-mothership-discount

> 标签: campaign, cog, discount, mothership, offer

## 简介

Cog module for discount building blocks in Mothership

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
