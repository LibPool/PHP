# bettergist/concurrency-helper

> 标签: fast, fork, multi-threaded, multithreaded, parallel

## 简介

A super simple way to concurrently run many PHP instances.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
