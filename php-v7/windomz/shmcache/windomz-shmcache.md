# windomz/shmcache

> 标签: PHP

## 简介

A lightweight, abstract, scalable, out-of-the-box shared memory operation, makes use of the PHP Shared Memory Functions(shmop).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
