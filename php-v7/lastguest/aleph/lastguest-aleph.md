# lastguest/aleph

> 标签: fast, framework

## 简介

A simple PHP framework for very small sites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/lastguest/aleph
- 源码仓库：https://github.com/lastguest/aleph.git
- Packagist 页面：https://packagist.org/packages/lastguest%2Faleph
