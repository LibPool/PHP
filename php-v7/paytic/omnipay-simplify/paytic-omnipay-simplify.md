# paytic/omnipay-simplify

> 标签: driver, gateway, mastercard, merchant, omnipay, pay, payment, simplify

## 简介

Mastercard Simplify driver for the Omnipay PHP library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
