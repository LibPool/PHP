# paytic/omnipay-common

> 标签: omnipay, pay, payment

## 简介

Common classes for drivers extending ThePhpLeague Omnipay multi-payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
