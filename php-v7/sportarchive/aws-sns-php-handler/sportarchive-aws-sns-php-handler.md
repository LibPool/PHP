# sportarchive/aws-sns-php-handler

> 标签: SNS, aws

## 简介

Small library to manipulate AWS SNS. Send GCM and APNS messages to topics and endpoints. Format notifications correctly.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
