# ion-bazan/laravel-container-debug

> 标签: command, container, debug, laravel, services

## 简介

Lists available services in Laravel IoC Container. Works with Laravel 5.4-14.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
