# ghoster/module-amasty-image-imageoptimizer-for-weltpixel

> 标签: PHP

## 简介

Magento 2 add-on to make Amasty_ImageOptimizer work with WeltPixel theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
