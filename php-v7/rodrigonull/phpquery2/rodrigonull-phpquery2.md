# rodrigonull/phpquery2

> 标签: PHP

## 简介

phpQuery is a server-side, chainable, CSS3 selector driven Document Object Model (DOM) API based on jQuery JavaScript Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
