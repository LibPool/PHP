# dataweb1/enable_devel_info_on_ddev

> 标签: PHP

## 简介

Drupal module that enables Devel Info on DDEV whatever the perms are. (for e.g. dpm())

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
