# mglaman/phpstan-civicrm

> 标签: PHP

## 简介

Extension for [PHPStan](https://phpstan.org) to allow static analysis of CiviCRM.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
