# shieldfy/shieldfy-php-client

> 标签: shieldfy, shieldfy-php-client

## 简介

This is the official PHP SDK for Shieldfy (shieldfy.io)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
