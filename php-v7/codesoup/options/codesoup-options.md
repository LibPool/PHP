# codesoup/options

> 标签: CMB2, Settings, acf, composer-package, custom-post-type, extensible, framework-agnostic, metabox, options, wordpress

## 简介

Framework-agnostic WordPress options manager using custom post types. Supports ACF, custom metaboxes, and extensible integrations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
