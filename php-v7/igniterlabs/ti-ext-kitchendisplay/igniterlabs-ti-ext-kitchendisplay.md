# igniterlabs/ti-ext-kitchendisplay

> 标签: PHP

## 简介

This extension displays orders in a simplified way to help kitchen staff to move orders to their different status swiftly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
