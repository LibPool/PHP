# cyneek/yii2-routes

> 标签: filter, route, yii, yii2

## 简介

Routing and filtering extension system for Yii2 framework that emulates the Laravel routing system.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
