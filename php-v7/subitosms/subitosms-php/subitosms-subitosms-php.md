# subitosms/subitosms-php

> 标签: api, gateway, sms, subitosms

## 简介

Client PHP semplice e senza dipendenze per le API HTTP di SubitoSMS.it.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
