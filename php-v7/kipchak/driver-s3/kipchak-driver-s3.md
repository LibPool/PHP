# kipchak/driver-s3

> 标签: Mamluk, apis, microservices, object storage, s3

## 简介

An Object Storage (S3) driver (dependency) for the Kipchak API Development Kit (ADK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
