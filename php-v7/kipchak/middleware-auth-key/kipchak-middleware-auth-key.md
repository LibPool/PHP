# kipchak/middleware-auth-key

> 标签: Mamluk, api keys, apis, http, microservices

## 简介

The Official API Key Auth Middleware for the Kipchak API Development Kit (ADK)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
