# carpcai/address-parser

> 标签: PHP

## 简介

A PHP library covers PHP 5.4 to 7.3, split an address street to street, states, city, zipcode.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
