# yaboroda/ybsy-file-bundle

> 标签: bundle, files, symfony

## 简介

This bundle provide tools for uploading files and link it to existing doctrine entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
