# buddha-code/buco-static-xhr-http-cache

> 标签: cache, http, plugin, shopware

## 简介

Shopware plugin to enable HTTP caching for shop pages in modal boxes

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
