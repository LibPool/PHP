# cspray/labrador-coding-standard

> 标签: Labrador, coding-style, php

## 简介

A PHP_CodeSniffer ruleset for the coding style in all Labrador packages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
