# brouzie/xml-iterator

> 标签: XMLReader, xml-iterator, xml-parser

## 简介

Fast and memory efficient XML iterator based on XmlReader.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
