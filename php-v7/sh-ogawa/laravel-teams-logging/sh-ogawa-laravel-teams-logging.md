# sh-ogawa/laravel-teams-logging

> 标签: PHP

## 简介

Laravel handler to sending messages to Microsoft Teams using the Incoming Webhook connector

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
