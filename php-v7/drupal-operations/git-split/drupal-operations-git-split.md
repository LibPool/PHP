# drupal-operations/git-split

> 标签: PHP

## 简介

Adds composer git:split composer command for easy splitting of a git repository into many others.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://drupal.org/project/operations
- 源码仓库：https://github.com/operations-project/git-split.git
- Packagist 页面：https://packagist.org/packages/drupal-operations%2Fgit-split
