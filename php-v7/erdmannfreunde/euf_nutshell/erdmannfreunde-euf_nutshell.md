# erdmannfreunde/euf_nutshell

> 标签: base framework, contao, euf nutshell, nutshell

## 简介

Base Framework for Contao CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
