# val/doctrine-table-prefix-service-provider

> 标签: cilex, doctrine, pimple, prefix, silex, table

## 简介

Doctrine event listener to dynamically add a table prefix.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
