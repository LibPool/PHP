# gdmedia/silverstripe-jquery

> 标签: jquery, silverstripe

## 简介

Use a newer version (3.1.0) of jQuery outside of the CMS and disable including framework jQuery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
