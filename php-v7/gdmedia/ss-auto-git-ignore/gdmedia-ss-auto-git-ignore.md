# gdmedia/ss-auto-git-ignore

> 标签: PHP

## 简介

A Composer post-update-cmd script to automatically add Composer managed SilverStripe modules and themes to .gitignore

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
