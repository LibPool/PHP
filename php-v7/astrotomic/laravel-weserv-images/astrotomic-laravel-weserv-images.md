# astrotomic/laravel-weserv-images

> 标签: astrotomic, images, laravel-weserv-images, weserv

## 简介

A fluent URL generator for images.weserv.nl with Laravel bindings.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
