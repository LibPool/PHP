# heimseiten/contao-columns-bundle

> 标签: flexbox, nebeneinander, spalten

## 简介

Eine Spaltenaufteilung der Inhaltselemente kann im Artikel eingestellt werden. Einzelne Inhaltselemente können für die Spaltenanzeige deaktiviert werden.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
