# heimseiten/contao-theme-settings-bundle

> 标签: variablen

## 简介

Erlaubt Einstellungen wie Hauptfarbe, Schriftgröße usw. im Theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
