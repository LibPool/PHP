# rickcy/yii2-tarantool

> 标签: cache, db, extension, tarantool, yii2, yii2-cache, yii2-db, yii2-tarantool

## 简介

Extension for Tarantool's connection in the Yii2 application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
