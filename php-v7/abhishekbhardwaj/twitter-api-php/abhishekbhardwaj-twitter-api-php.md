# abhishekbhardwaj/twitter-api-php

> 标签: api, php, sdk, twitter

## 简介

Simple PHP wrapper for Twitter v1.1 API. Uses Guzzle!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
