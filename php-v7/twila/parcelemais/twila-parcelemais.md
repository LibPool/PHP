# twila/parcelemais

> 标签: cdc, parcelemais, sdk, twila

## 简介

SDK oficial em PHP para a API do Parcele+ (crédito direto ao consumidor e parcelamento no momento da compra)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
