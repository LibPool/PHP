# gmail-logo/generator

> 标签: PHP

## 简介

The gmail logo generator on PHP. Beta version customized for Laravel, can be used with any PHP framework or in native PHP developement.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
