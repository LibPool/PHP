# resist/ecc-calculations

> 标签: PHP

## 简介

Native classes of Eurocode based calculations for structural design on https://structure.hu

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://resist.hu
- 源码仓库：https://github.com/r3sist/ecc-calculations.git
- Packagist 页面：https://packagist.org/packages/resist%2Fecc-calculations
