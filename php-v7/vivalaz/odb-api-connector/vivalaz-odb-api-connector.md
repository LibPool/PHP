# vivalaz/odb-api-connector

> 标签: api, big data, grinevich, opendatabot, php, ukraine, vivalaz

## 简介

A PHP package, that provides all OpenDataBot API endpoints in one place.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
