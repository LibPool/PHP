# faonni/module-re-captcha-b2b

> 标签: PHP

## 简介

Extension is integrate Google Recaptcha with B2B Extension your Magento2 store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
