# faonni/module-customer-handle

> 标签: PHP

## 简介

add custom layout handles for frontend magento2 to add customer_logged_in and customer_logged_out handles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
