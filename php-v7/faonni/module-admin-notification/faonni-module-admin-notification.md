# faonni/module-admin-notification

> 标签: PHP

## 简介

Extension to add a RSS feed url to the Admin Notification stream in the Magento2 backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
