# mammothwp/wp-self-test

> 标签: abilities-api, pre-push, rest-api, self-test, testing, wordpress, wp-cli

## 简介

Manifest-driven self-test suite for WordPress plugins: register a manifest of cases from your plugin folder and run them from wp-admin, WP-CLI, the Abilities API and a pre-push hook.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
