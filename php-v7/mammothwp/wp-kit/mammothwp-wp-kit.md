# mammothwp/wp-kit

> 标签: abilities-api, library, rest-api, validation, wordpress, wp-cli

## 简介

Declare a WordPress feature once and expose it as a REST route, a WP-CLI command and a WordPress Ability from the same definition.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
