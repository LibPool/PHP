# bakgul/laravel-query-helper

> 标签: PHP

## 简介

A package to add some wrapper around filtering, groupping, sorting and maybe more to write queries faster.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
