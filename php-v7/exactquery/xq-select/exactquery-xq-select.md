# exactquery/xq-select

> 标签: bootstrap, exactquery, replacement, sass, select

## 简介

Cross browser <select> implementation using CSS, JQuery, and Twitter Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
