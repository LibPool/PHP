# laravel-liberu/avatars

> 标签: avatar, avatars, laravel, laravel-liberu

## 简介

User Avatar manager dependency for Laravel Liberu

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
