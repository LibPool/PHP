# laravel-liberu/documents

> 标签: documents, documents-manager, file-uploader, laravel-liberu

## 简介

Documents Manager for Laravel Liberu

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
