# laravel-liberu/versions

> 标签: laravel-enso, pessimistic-lock, trait, versions

## 简介

Prevents update conflicts using the pessimistic lock pattern in Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
