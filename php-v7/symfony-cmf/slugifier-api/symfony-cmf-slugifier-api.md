# symfony-cmf/slugifier-api

> 标签: slugify, urlize

## 简介

Provides a basic slugifier interface to transform text into strings suitable for URLs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
