# freemius/wordpress-sdk

> 标签: freemius, plugin, sdk, theme, wordpress, wordpress-plugin, wordpress-theme

## 简介

Freemius WordPress SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
