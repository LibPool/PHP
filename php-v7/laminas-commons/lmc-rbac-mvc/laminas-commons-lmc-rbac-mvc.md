# laminas-commons/lmc-rbac-mvc

> 标签: laminas, module, permissions, rbac

## 简介

Laminas Framework MVC Module that provides a layer of features of Laminas\Permissions\Rbac

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
