# jlz/laravel-snowflake

> 标签: laravel, laravel-snowflake, snowflake

## 简介

雪花算法：分布式环境，生成全局唯一的订单号

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
