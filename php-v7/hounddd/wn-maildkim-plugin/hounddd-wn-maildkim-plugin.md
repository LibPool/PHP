# hounddd/wn-maildkim-plugin

> 标签: dkim, email, plugin, security, winter, winter cms

## 简介

Add support for DKIM-signed outgoing emails in Winter CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
