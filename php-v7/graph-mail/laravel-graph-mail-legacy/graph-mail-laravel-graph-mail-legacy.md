# graph-mail/laravel-graph-mail-legacy

> 标签: Office365, azure-ad, laravel, laravel8, mail, mailer, microsoft-graph, outlook, smtp-alternative, swiftmailer

## 简介

Send Laravel 8 mail through the Microsoft Graph API (Mail.Send application permission) — no SMTP, no app passwords, works with modern-auth-only tenants. PHP 7.3+ / Laravel 8 compatible fork of graph-mail/laravel-graph-mail.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
