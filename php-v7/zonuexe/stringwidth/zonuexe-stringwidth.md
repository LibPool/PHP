# zonuexe/stringwidth

> 标签: eastasian, eaw, string, unicode, width

## 简介

Measure string width (support Unicode east asian ambiguous width)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
