# ajaxray/short-code

> 标签: code, convert, hash, psr-3, random, revert, short-code

## 简介

ShortCode generator for PHP. Create short, reversible or random, hash like codes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
