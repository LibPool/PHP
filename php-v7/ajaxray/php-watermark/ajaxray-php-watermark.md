# ajaxray/php-watermark

> 标签: image, image-manipulation, imagemagick-watermark, imagemagick-wrapper, watermark

## 简介

Add text or image watermark on images.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
