# smarch/watchtower

> 标签: admin, authorization, gui, laravel, permissions, rbac, roles, shinobi

## 简介

Front-end for the Shinboi Auth system of Users / Roles / Permissions in Laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
