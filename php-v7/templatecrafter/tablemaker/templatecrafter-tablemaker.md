# templatecrafter/tablemaker

> 标签: Craft, cms, craft-plugin, craftcms, craftcms3, supercool, table maker

## 简介

A user-definable table field type for Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
