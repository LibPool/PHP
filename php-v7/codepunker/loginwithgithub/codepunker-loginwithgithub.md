# codepunker/loginwithgithub

> 标签: github, login, php

## 简介

codepunker/loginwithgithub is a lightweight user authenticator that exploits the github api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
