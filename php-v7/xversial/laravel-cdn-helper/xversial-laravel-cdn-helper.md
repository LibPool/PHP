# xversial/laravel-cdn-helper

> 标签: asset, blade, cdn, helper, laravel, static

## 简介

Laravel CDN Helper, adds blade directive to statically write asset links into compiled views.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
