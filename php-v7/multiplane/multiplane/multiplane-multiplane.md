# multiplane/multiplane

> 标签: PHP

## 简介

Skeleton to build Multiplane with Cockpit CMS v1 via composer with a clean root directory

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
