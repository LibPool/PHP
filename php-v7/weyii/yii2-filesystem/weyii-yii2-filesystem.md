# weyii/yii2-filesystem

> 标签: Flysystem, file, filesystem, qiniu, storage, weyii, yii2

## 简介

This extension provides a filesystem solution for Yii 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
