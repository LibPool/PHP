# d3/oxid-wysiwyg-replacement

> 标签: PHP

## 简介

Empty replacement for the WYSIWYG + VisualCMS module if it is not used and should be removed from the installation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
