# d3/oxid-twofactor-passwordless

> 标签: 2fa, CTAP, FIDO2, OXID, Passwordless, credential, d3, eshop, login, modules, passkey, public key, second factor, solokey, token, two factor, webauthn, yubikey

## 简介

Passwordless login for OXID eShop (Webauthn / FIDO2 based)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
