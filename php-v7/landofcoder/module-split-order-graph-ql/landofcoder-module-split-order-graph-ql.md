# landofcoder/module-split-order-graph-ql

> 标签: magento 2, magento 2 split order, magento 2 split order graph ql, magento 2 split quote, magento extension, magento quote, split order, split quote

## 简介

This extension allows your Magento store to split the order into an order for each item in the cart.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
