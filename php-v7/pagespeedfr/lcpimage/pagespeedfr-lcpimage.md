# pagespeedfr/lcpimage

> 标签: PHP

## 简介

Magento 2 Lcp preload image on each page / resize image and transform into webp with yireo for google page speed test

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
