# nojimage/cakephp-rest

> 标签: cakephp, datasource

## 简介

A CakePHP Plugin containing a DataSource for interacting with ReSTful web services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
