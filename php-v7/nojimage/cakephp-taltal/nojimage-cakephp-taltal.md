# nojimage/cakephp-taltal

> 标签: cakephp, phptal, view

## 简介

CakePHP TALTAL – PHPTAL View plugin. This plugin provides PHPTAL View Class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
