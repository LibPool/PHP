# filternet/filternet

> 标签: censorship, dns-hijacking, filtering, filternet, iran, sni

## 简介

A simple utility to check whether the given url/domain is blocked in Iran.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
