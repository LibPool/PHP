# designitgmbh/monkey-settings

> 标签: designitgmbh, monkeySettings

## 简介

monkeySettings allow you to manage user and global settings easily in laravel 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
