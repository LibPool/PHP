# heartsentwined/zf2-doctrine

> 标签: cli, doctrine, zf2

## 简介

wrapper for DoctrineORMModule + DoctrineModule's CLI, tailored for yaml config files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
