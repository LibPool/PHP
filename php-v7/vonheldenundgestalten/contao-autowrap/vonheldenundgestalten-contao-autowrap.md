# vonheldenundgestalten/contao-autowrap

> 标签: PHP

## 简介

Contao 5.3 bundle to wrap content elements for easier page layout and HTML organization.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
