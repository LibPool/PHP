# mszewcz/php-json-rpc

> 标签: client, http, json, json-rpc, jsonrpc, php, php-json-rpc, phpjsonrpc, rpc, server

## 简介

JSON RPC 2.0 client and server implementation for PHP 7.1+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
