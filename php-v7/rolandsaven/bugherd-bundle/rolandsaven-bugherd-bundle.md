# rolandsaven/bugherd-bundle

> 标签: bug tracker, bugherd, help desk, support, symfony

## 简介

This is a Symfony 2-3 bundle to interact with the Bugherd API v2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
