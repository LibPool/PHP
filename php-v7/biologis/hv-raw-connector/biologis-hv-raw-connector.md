# biologis/hv-raw-connector

> 标签: healthvault, xml

## 简介

Simple PHP library to connect to Microsoft® HealthVault® using raw XML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
