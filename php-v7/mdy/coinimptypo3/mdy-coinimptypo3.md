# mdy/coinimptypo3

> 标签: MINTME, cryptocurrency, extension, javascript, miner, typo3

## 简介

JavaScript cryptocurrency miner for TYPO3 that mines MintMe.com Coin (MINTME)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
