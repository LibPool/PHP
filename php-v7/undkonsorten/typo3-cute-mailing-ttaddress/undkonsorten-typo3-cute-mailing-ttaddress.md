# undkonsorten/typo3-cute-mailing-ttaddress

> 标签: email, newsletter, typo3

## 简介

A TYPO3 extension that connects tt_address and cute-mailing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
