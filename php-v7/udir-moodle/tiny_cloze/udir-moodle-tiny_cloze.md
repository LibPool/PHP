# udir-moodle/tiny_cloze

> 标签: PHP

## 简介

Cloze question editor — Composer/Packagist mirror of the Moodle plugin tiny_cloze, auto-updated from the Moodle plugins directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
