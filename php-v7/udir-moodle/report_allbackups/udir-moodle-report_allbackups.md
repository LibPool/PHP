# udir-moodle/report_allbackups

> 标签: PHP

## 简介

All backups — Composer/Packagist mirror of the Moodle plugin report_allbackups, auto-updated from the Moodle plugins directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
