# rcezea/httplogger

> 标签: PHP

## 简介

Lightweight and flexible logging library for PHP applications. It enables developers to send log data to a remote server and log to local files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
