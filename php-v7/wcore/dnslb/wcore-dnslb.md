# wcore/dnslb

> 标签: PHP

## 简介

DNS-based load balancer and autoscaler (Route 53 latency routing or Cloudflare round robin) for Linode and AWS EC2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
