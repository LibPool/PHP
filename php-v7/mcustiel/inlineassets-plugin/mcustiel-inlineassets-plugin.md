# mcustiel/inlineassets-plugin

> 标签: assets, cms, inline, october, scripts, styles

## 简介

Provides inlineStyles and inlineScripts that embed the assets in the HTML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
