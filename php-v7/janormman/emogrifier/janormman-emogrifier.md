# janormman/emogrifier

> 标签: PHP

## 简介

Copy of pelagios emogrifier. Converts CSS styles into inline style attributes in your HTML code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
