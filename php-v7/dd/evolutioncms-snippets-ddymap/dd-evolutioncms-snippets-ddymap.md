# dd/evolutioncms-snippets-ddymap

> 标签: MODX Evo, dd group, dd studio, ddymap, divandesign, evo, evo cms, evolution cms, evolutioncms, map, modx, modx evolution, yandex map

## 简介

A snippet that allows Yandex.Maps to be rendered on a page in a simple way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
