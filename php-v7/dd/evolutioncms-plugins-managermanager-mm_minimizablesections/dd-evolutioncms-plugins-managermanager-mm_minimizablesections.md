# dd/evolutioncms-plugins-managermanager-mm_minimizablesections

> 标签: MODX Evo, close section, collapse section, dd group, dd studio, divandesign, evo, evo cms, evolution cms, evolutioncms, managermanager, minimizable sections, minimize section, mm, mm widget, mm_minimizablesections, modx, modx evolution

## 简介

A widget for ManagerManager plugin that allows sections to be minimizable on the document edit page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
