# dd/evolutioncms-plugins-managermanager-mm_requirefields

> 标签: MODX Evo, dd group, dd studio, divandesign, evo, evo cms, evolution cms, evolutioncms, managermanager, mm, mm widget, mm_requirefields, modx, modx evolution, require document field, require tv

## 简介

A widget for ManagerManager plugin that allows document fields (or TVs) to become required.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
