# tomjamon/tailwindlaravel

> 标签: bootstrap, form, html, laravel, tailwindcss

## 简介

Custom HTML generator for Laravel (Based on LaravelCollective HTML)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
