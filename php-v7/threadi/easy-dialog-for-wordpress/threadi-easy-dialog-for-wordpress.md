# threadi/easy-dialog-for-wordpress

> 标签: PHP

## 简介

Provides a simple react-driven dialog-modal for the WordPress-backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
