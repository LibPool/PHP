# ynacorp/carbon-field-uniqid

> 标签: carbon-field, carbon-field-uniqid, wordpress

## 简介

Carbon Fields extension, that adds a number field type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
