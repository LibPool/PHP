# codeonweekends/mpesa-php-sdk

> 标签: PHP

## 简介

(Unofficial) PHP SDK for the MPesa payment gateway by Vodacom Mozambique

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
