# t2softwaregroup/cnpjvalidator

> 标签: cnpj, cnpjvalidation, cnpjvalidator, validation, validator

## 简介

A simple package to validate CNPJ Alphanumeric.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
