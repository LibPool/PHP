# jinya/profiling-bundle

> 标签: PHP

## 简介

Dumps the symfony profiler data into yaml files to be usable outside of the symfony web profiler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
