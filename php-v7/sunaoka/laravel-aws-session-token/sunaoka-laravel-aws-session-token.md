# sunaoka/laravel-aws-session-token

> 标签: credentials, lambda, laravel

## 简介

Add AWS_SESSION_TOKEN to Laravel's AWS configuration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
