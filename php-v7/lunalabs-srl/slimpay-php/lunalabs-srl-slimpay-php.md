# lunalabs-srl/slimpay-php

> 标签: PHP

## 简介

A simple PHP package to integrate the SlimPay checkout on your application that supports both iframe and redirect checkout

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
