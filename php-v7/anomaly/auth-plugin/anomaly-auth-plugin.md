# anomaly/auth-plugin

> 标签: Streams, auth, plugin

## 简介

A Streams Platform plugin that provides API access to Laravel's Auth class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
