# anomaly/wysiwyg_widget-extension

> 标签: WYSIWYG extension, dashboard module, widget

## 简介

A freestanding WYSIWYG widget for the Dashboard module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
