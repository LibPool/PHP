# anomaly/landed-theme

> 标签: HTML5 UP theme, streams addon, streams theme, theme

## 简介

A dark, slick, modern, responsive, adjective-drenched theme by HTML5 UP!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
