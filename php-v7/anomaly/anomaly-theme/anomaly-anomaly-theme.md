# anomaly/anomaly-theme

> 标签: laravel, streams-platform, theme

## 简介

The official admin theme for Streams Platform products from AnomalyLabs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
