# leproxy/leproxy

> 标签: HTTP proxy, HTTPS proxy, LeProxy, SOCKS proxy, async, proxy server, reactphp

## 简介

LeProxy is the HTTP/SOCKS proxy server for everybody!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
