# vendi-advertising/ftp_implicit_ssl

> 标签: PHP

## 简介

Simple wrapper for cURL functions to transfer an ASCII file over FTP with implicit SSL/TLS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
