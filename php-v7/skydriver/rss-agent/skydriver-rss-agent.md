# skydriver/rss-agent

> 标签: feed, parser, rss

## 简介

Package to read the RSS Feeds from URL according RSS v2 standards (https://validator.w3.org/feed/docs/rss2.html)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
