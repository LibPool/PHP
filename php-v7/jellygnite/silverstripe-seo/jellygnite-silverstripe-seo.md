# jellygnite/silverstripe-seo

> 标签: facebook, opengraph, optimisation, optimization, search, seo, silverstripe, twitter

## 简介

An all-in-one SEO module for SilverStripe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
