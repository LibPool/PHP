# lovecn/alipaybatchphp

> 标签: PHP

## 简介

支付宝转账api，php版。本package尽量保持官方sdk代码和使对autoload做处理。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
