# lunacy/yii2-helpers

> 标签: extension, helper, yii2

## 简介

扩展了yii2框架本身的一些helper，以及自己添加的一些helpers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
