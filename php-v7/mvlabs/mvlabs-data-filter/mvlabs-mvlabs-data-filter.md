# mvlabs/mvlabs-data-filter

> 标签: datafilter, php, query filter, selectionCriteria

## 简介

MvlabsDataFilter is a PHP5 OO abstraction to manage SQL query filters.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
