# afragen/the-events-calendar-category-colors

> 标签: calendar, category, colors, events, stellarwp

## 简介

This plugin adds event category background coloring to The Events Calendar plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
