# timothecrespy/yousign-api-php-client

> 标签: api, rest, yousign

## 简介

A PHP client library for accessing Yousign REST APIs (https://yousign.com/en-uk/api)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
