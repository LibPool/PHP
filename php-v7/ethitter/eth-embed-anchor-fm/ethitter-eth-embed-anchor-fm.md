# ethitter/eth-embed-anchor-fm

> 标签: anchor.fm, audio, embed, oembed, podcast, shortcode

## 简介

Add Anchor.fm oEmbed support to WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
