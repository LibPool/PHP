# tinymeng/pay-sdk

> 标签: QQ支付, alipay, wechatpay, 微信支付, 支付宝支付

## 简介

支付宝、微信、QQ、等支付开放平台第三方 PHP SDK，基于官方最新版本。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
