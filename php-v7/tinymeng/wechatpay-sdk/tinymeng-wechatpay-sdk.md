# tinymeng/wechatpay-sdk

> 标签: Wxpay, wechat, 微信支付

## 简介

微信支付第三方 PHP SDK，基于官方最新版本，包含V2和V3两种接口。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
