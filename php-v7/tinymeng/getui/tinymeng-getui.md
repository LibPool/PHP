# tinymeng/getui

> 标签: GeTui, Uniapp, thinkphp, 个推, 免费推送, 安卓推送, 推送SDK, 推送服务, 消息推送

## 简介

个推推送，提供安卓(Android)和iOS推送SDK，为App开发者提供高效稳定推送技术服

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
