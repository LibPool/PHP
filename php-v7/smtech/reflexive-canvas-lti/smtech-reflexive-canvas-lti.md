# smtech/reflexive-canvas-lti

> 标签: PHP

## 简介

LTI tool provider class that includes the "reflexive" reach back into Canvas via the API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
