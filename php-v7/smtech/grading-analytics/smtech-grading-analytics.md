# smtech/grading-analytics

> 标签: PHP

## 简介

Track and present rich feedback on faculty behavior in Canvas (akin to the course analytics data on on students)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
