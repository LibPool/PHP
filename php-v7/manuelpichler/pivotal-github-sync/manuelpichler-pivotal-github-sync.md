# manuelpichler/pivotal-github-sync

> 标签: github, issue, pivotaltracker, synchronize

## 简介

Tool to synchronize GitHub and Pivotaltracker issues bidirectional.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
