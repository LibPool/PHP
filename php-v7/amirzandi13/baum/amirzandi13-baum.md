# amirzandi13/baum

> 标签: database, eloquent, laravel, laravel 5, laravel 6, laravel 7, nested set

## 简介

Baum is an implementation of the Nested Set pattern for Eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
