# vespula/spot-tools

> 标签: database, orm, reverse, spot, spot2, tables

## 简介

A library for generating SpotORM entities from existing database tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
