# vespula/slim-skeleton

> 标签: Skeleton, framework, slim, slim3

## 简介

A Starting point for creating Slim Framework v3 applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
