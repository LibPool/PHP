# victuxbb/jsonpatch

> 标签: json, json operations, json pointer, patch operations

## 简介

Implementation of JSON Patch (http://tools.ietf.org/html/rfc6902)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
