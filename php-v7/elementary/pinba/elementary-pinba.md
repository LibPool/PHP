# elementary/pinba

> 标签: PHP

## 简介

Pinba and Timers classes provides simple interface that allows you to construct arbitrary Pinba data packets in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
