# sanotto/atk-attribute-yearmonth

> 标签: Skeleton, atk, framework, search

## 简介

ATK Attribute to handle year/month entries in the form YYYY-MM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
