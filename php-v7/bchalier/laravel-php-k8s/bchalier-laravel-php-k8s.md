# bchalier/laravel-php-k8s

> 标签: k3s, k8s, kube, kubernetes, laravel, php

## 简介

Just a simple port of renoki-co/php-k8s for easier access in Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
