# faboslav/yii2-progressive-media

> 标签: Blur, extension, faboslav, iframe, image, img, javascript, lazy, lazyload, load, loading, media, progressive, progressivemedia, yii2

## 简介

Yii2 Progressive Media is a extension for Yii2 which allows to lazyload images and iframes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
