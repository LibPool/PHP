# ikaijian/wechat

> 标签: OffiaAccount, miniprogram, work, 企业微信, 微信 SDK, 微信公众号, 微信小程序, 微信开放平台, 微信支付

## 简介

微信 SDK 包含企业微信、微信小程序、微信公众号、微信开放平台、微信支付等微信集合接口

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
