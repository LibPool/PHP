# begimov/thanks

> 标签: PHP

## 简介

Give thanks (in the form of a GitHub ⭐) to your fellow PHP package maintainers (not limited to Symfony components)!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
