# grok/grok-php-client

> 标签: grok, grok sdk, grok-php-client

## 简介

This is a community-driven, unofficial PHP SDK designed to simplify integration with the Grok AI API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
