# kappa/sandbox

> 标签: PHP

## 简介

Base project structure for Nette Framework and Kappa components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/Kappa-org/Sandbox
- 源码仓库：git@github.com:Kappa-org/Sandbox.git
- Packagist 页面：https://packagist.org/packages/kappa%2Fsandbox

- 当前版本：v1.0.0

## 获取地址

- Composer 安装：`composer require kappa/sandbox`
- Packagist 仓库：https://repo.packagist.org/p2/kappa/sandbox.json
