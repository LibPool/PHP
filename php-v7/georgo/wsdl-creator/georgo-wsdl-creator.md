# georgo/wsdl-creator

> 标签: annotations, creator, generator, php, reflections, soap, wsdl

## 简介

PHP WSDL creator using PHPdoc (annotations, reflections).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
