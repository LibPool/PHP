# alex-the-coder/image-analizer

> 标签: bounding-box, color-palette, colorfulness, computer-vision, fourier-transform, hasler-susstrunk, image-analysis, imagick, object-detection, texture-analysis

## 简介

High-performance computer vision tool using Imagick to isolate, align, and analyze multi-colored objects on monotonic backgrounds. Extracts spatial, frequency (DFT), and 256-color palette metrics to identify artistic content, paintings, or screens within product images.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
