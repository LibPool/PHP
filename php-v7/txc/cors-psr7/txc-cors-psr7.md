# txc/cors-psr7

> 标签: Cross Origin Resource Sharing, Cross-Origin Resource Sharing, cors, psr-7, psr7, txc, w3.org, www.w3.org

## 简介

Framework agnostic (PSR-7) CORS implementation (www.w3.org/TR/cors/)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
