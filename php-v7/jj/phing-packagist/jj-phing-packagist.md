# jj/phing-packagist

> 标签: composer, composer.json, composer.phar, packagist, packagist.org, task, taskdef

## 简介

Phing extension to load task direct from packagist.org libs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
