# dsnoeck/laravel-push-notification

> 标签: apns, gcm, laravel, notification, push

## 简介

Laravel package to send push notifications to mobile devices (apns, gcm)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
