# xatoo/silex2-mongodb-provider

> 标签: database, mongo, mongodb, provider, silex

## 简介

MongoDB service provider for the Silex 2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
