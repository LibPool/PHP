> 标签: api, eloquent-transformer, json, laravel-model-transformer, nested, presentit, presentit-laravel, rest, transformer

## 简介

Transformers for nested Eloquent models and collection for building API with Laravel framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
