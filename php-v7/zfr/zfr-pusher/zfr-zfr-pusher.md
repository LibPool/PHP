# zfr/zfr-pusher

> 标签: events, publish, pusher, real time, rest, trigger

## 简介

PHP library for interacting with the Pusher REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
