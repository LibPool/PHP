# zfr/zfr-mailchimp-bundle

> 标签: Symfony2, campaign, mail, mailchimp

## 简介

Symfony bundle for integrating the ZfrMailChimp library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
