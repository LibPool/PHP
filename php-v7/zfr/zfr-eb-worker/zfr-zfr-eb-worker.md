# zfr/zfr-eb-worker

> 标签: elastic beanstalk, expressive, middleware, sqs

## 简介

Thin abstraction around AWS SQS for Elastic Beanstalk worker environments

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
