# gdoisdev/ms-framework

> 标签: ajax, framework, http, messaging, php

## 简介

Micro-framework PHP para mensageria, controle de fluxo e padronização de respostas HTTP e AJAX.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
