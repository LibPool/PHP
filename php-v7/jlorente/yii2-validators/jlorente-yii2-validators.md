# jlorente/yii2-validators

> 标签: address, color, name, richtext, validator, yii2

## 简介

A compilation of useful validators for the Yii2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
