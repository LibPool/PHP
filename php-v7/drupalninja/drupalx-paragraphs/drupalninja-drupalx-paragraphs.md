# drupalninja/drupalx-paragraphs

> 标签: drupal recipe, recipe

## 简介

Paragraph types used in the DrupalX distribution recipe.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
