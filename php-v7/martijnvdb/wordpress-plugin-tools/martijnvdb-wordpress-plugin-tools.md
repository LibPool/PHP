# martijnvdb/wordpress-plugin-tools

> 标签: custom fields, plugin, post type, wordpress

## 简介

A simple library to quickly create Wordpress plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
