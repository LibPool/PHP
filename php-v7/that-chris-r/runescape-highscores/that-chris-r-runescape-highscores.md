# that-chris-r/runescape-highscores

> 标签: api, highscores, runescape

## 简介

A set of classes to better manipulate the RuneScape lite highscores API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
