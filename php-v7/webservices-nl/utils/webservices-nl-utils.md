# webservices-nl/utils

> 标签: utils, webservices.nl, webservicesnl

## 简介

Webservices Utils library with all purpose functions (array, string, entity, json)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
