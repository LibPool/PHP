# fbalabanov/yii2-ajax-modal

> 标签: ajax-modal, bootstrap, modal, yii2

## 简介

A wrapper around Yii2 Bootstrap Modal for using an ActiveForm via AJAX inside

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
