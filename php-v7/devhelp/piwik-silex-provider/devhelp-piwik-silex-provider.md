# devhelp/piwik-silex-provider

> 标签: piwik

## 简介

integration of devhelp/piwik-api into Silex. Allows to create services for piwik api methods

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
