# devhelp/procedure

> 标签: PHP

## 简介

introduces mechanism that allows you to define steps with its arguments that are going to be interpreted in order they are defined in the procedure

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
