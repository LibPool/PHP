# aspose/barcode

> 标签: aspose, barcode, generator, java, php, recognition

## 简介

Aspose.BarCode for PHP via Java is a robust barcode generation and recognition component.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
