# aspose/3d-sdk-php

> 标签: 3d, aspose, aspose cloud, php

## 简介

A PHP library for communicating with the Aspose.3D Cloud API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
