# kop/yii2-turbosms

> 标签: sms, soap, turbosms, yii2

## 简介

A Yii2 component for working with TurboSMS.ua SOAP service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
