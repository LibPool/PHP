# dsbaars/nostr-php-nwc

> 标签: PHP

## 简介

Nostr Wallet Connect (NIP-47) implementation in PHP (nostr-php)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
