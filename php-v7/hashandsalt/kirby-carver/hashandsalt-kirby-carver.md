# hashandsalt/kirby-carver

> 标签: PHP

## 简介

Kirby 3 Carver plugin for using PHP and the power of Kirby to create custom html tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
