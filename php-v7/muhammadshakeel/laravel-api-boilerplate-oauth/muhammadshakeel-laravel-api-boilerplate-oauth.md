# muhammadshakeel/laravel-api-boilerplate-oauth

> 标签: api, dingo, laravel, oauth, oauth2, restful, server

## 简介

A RESTful API starter pack for Laravel 5 with OAuth2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
