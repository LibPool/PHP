# syntaxerro/mail-api-sdk

> 标签: PHP

## 简介

Simple PHP SDK for syntax-shell.me HTTP <=> SMTP|IMAP api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
