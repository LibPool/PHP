# tp/solarium-extensions-bundle

> 标签: PHP

## 简介

A collection of useful extensions for the NelmioSolariumBundle created by Seldaek.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
