# ortho/laravel

> 标签: laravel, ortho

## 简介

An easy Laravel integration to ortho

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/OrthoHQ/laravel-ortho.git
- Packagist 页面：https://packagist.org/packages/ortho%2Flaravel
