# bulgaria-php/glagol-php-overriding

> 标签: PHP

## 简介

Library for handling in-method overriding based on argument signature. Created for the purposes of Glagol DSL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
