# bedrockstreaming/newrelic-guzzle-http-host

> 标签: PHP

## 简介

A workaround to report Guzzle requests with correct Host Http header in NewRelic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
