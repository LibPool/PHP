# quibax/http

> 标签: api, client, curl, http, json, laravel, xml

## 简介

An http library developed for the laravel framework. aliases itself as HttpClient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
