# neonexus/ionicons-bundle

> 标签: PHP

## 简介

Easy integration of Ionicons into Symfony2 projects (based on similar package by Coding Fogey).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
