# tagmeo/framework

> 标签: framework, tagmeo

## 简介

The Tagmeo framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://tagmeo.com
- 源码仓库：https://github.com/tagmeo/framework.git
- Packagist 页面：https://packagist.org/packages/tagmeo%2Fframework

- 当前版本：v0.0.1

## 获取地址

- Composer 安装：`composer require tagmeo/framework`
- Packagist 仓库：https://repo.packagist.org/p2/tagmeo/framework.json
- 许可证：MIT
- PHP 要求：>=5.6
