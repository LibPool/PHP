# capdataopera/php-sdk

> 标签: Opera, RDF, capdata, ontology, sdk

## 简介

Development kit to expose and fetch CapData Opera ontology in RDF format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
