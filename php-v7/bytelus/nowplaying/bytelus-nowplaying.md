# bytelus/nowplaying

> 标签: PHP

## 简介

A lightweight PHP adapter for viewing the current now playing data in Icecast and SHOUTcast 1/2. A part of the Radiolize software suite.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
