# aaemnnosttv/wordpress-tests-core-installer

> 标签: phpunit, tests, wordpress

## 简介

A custom installer to install the WordPress core phpunit library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
