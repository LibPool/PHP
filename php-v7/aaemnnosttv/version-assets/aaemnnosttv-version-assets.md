# aaemnnosttv/version-assets

> 标签: PHP

## 简介

A WordPress plugin to automatically apply a content-based version on all of your assets to optimize browser caching.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
