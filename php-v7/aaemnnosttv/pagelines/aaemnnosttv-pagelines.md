# aaemnnosttv/pagelines

> 标签: PHP

## 简介

PageLines 2.X is a fork of the PageLines Framework which was discontinued with the launch of PageLines DMS on July 24th, 2013.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
