# buting/cliapp-updater

> 标签: incremental-update, php, rollback, thinkphp, updater, webman

## 简介

Framework-independent PHP updater for the apps.cli.cc release and licensing service

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
