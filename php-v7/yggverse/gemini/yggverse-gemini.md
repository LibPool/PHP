# yggverse/gemini

> 标签: Gemini, client, gemini-protocol, request, response, yggverse

## 简介

PHP 8 Library for Gemini Protocol

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
