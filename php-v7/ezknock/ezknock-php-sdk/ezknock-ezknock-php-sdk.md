# ezknock/ezknock-php-sdk

> 标签: Guzzle, api, ezknock, ezknockmarketplace.com

## 简介

EZ Knock API client built on top of HTTPlug

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
