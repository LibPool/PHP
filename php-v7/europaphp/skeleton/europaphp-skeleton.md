# europaphp/skeleton

> 标签: Simple, controller, fast, mvc, scalable, view

## 简介

A feather-weight, extremely-fast, diverse, scalable and productive PHP 5.4 View Controller framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
