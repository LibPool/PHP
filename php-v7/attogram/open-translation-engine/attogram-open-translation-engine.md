# attogram/open-translation-engine

> 标签: attogram, dictionary, translation, translation dictionary

## 简介

The Open Translation Engine (OTE) is a collaborative translation dictionary manager for the open content web. PHP / SQLite / Attogram Framework module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
