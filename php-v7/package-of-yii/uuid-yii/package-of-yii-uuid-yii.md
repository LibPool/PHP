# package-of-yii/uuid-yii

> 标签: php, ramsey, uuid, yii2

## 简介

Ramsey Uuid for Yii 2 applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
