# pear/xml_xrd

> 标签: PHP

## 简介

PHP library to parse and generate "Extensible Resource Descriptor (XRD) Version 1.0" files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
