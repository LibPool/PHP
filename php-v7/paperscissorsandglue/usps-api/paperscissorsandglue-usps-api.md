# paperscissorsandglue/usps-api

> 标签: USPS-API, paperscissorsandglue

## 简介

PHP USPS API integration on PHP based on original library by Vincent Gabriel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
