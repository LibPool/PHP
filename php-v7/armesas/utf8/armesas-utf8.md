# armesas/utf8

> 标签: grapheme, i18n, unicode, utf-8, utf8

## 简介

Portable and performant UTF-8, Unicode and Grapheme Clusters for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
