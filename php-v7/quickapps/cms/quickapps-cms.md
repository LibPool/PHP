# quickapps/cms

> 标签: cakephp, cmf, cms, framework

## 简介

QuickAppsCMS, open source content management system for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://quickappscms.org
- 源码仓库：https://github.com/quickapps/cms.git
- Packagist 页面：https://packagist.org/packages/quickapps%2Fcms

## 获取地址

- Composer 安装：`composer require quickapps/cms`
- Packagist 仓库：https://repo.packagist.org/p2/quickapps/cms.json
