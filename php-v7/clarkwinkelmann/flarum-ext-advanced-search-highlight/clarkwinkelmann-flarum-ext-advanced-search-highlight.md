# clarkwinkelmann/flarum-ext-advanced-search-highlight

> 标签: flarum, highlight, search

## 简介

Highlight search results in HTML post content and partial Meilisearch hits.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
