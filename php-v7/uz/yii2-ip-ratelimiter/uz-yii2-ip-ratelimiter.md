# uz/yii2-ip-ratelimiter

> 标签: ratelimiter, yii2

## 简介

Allow guest clients to be rate limited, using their IP as the identifier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
