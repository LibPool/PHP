# uz/yii2-poll

> 标签: poll, poll-widget, widget, yii2, yii2-poll-widget

## 简介

Widget to create custom polls for Yii 2.0 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
