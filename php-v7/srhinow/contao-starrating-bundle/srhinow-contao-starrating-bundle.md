# srhinow/contao-starrating-bundle

> 标签: Rating, Simple, Sterne-Bewertung, bewertung, star

## 简介

Eine Sterne-bewertung die per Insert-tag an beliebiger Stelle positioniert wird und ab dem ersten Vote erst im Backend in einer Bewertungs-Verwaltung erscheint.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
