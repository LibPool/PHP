# jdr/mailer-swift-mailer-bridge

> 标签: jdr, mailer-swift-mailer-bridge

## 简介

Bridge for jdr/mailer that allows you to send emails using swift mailer

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
