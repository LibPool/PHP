# jdr/uuid-doctrine-odm

> 标签: jdr, uuid-doctrine-odm

## 简介

Allow the use of a ramsey/uuid UUID as Doctrine ODM field type.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
