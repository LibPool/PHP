# liwenyu/yii2-translate

> 标签: currency, i18n, message-source, translation, yii2

## 简介

Yii2 货币替换消息源组件 - 自动替换翻译结果中的货币单位并填充货币符号

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
