# gomoob/php-metadata-extractor

> 标签: exif, gomoob, image, metadata, metadata-extractor, photo

## 简介

PHP wrapper to easily call the Java metadata-extrator library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
