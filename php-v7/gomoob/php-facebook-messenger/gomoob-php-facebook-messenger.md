# gomoob/php-facebook-messenger

> 标签: gomoob, notification, push, pushwoosh

## 简介

A PHP Library to easily work with the Facebook Messenger REST Web Services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
