# davejamesmiller/laravel-boris

> 标签: laravel

## 简介

Adds an 'artisan boris' command to run the Boris REPL in the Laravel environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
