# juanbenitez/manychat-response-generator

> 标签: bot, chatbot, json, juanbenitez, manychat

## 简介

PHP package to generate Manychat JSON responses for bots.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
