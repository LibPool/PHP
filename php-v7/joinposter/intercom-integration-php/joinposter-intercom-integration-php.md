# joinposter/intercom-integration-php

> 标签: Guzzle, api, intercom, intercom.io

## 简介

Intercom API client built on top of Guzzle 6 for Poster POS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
