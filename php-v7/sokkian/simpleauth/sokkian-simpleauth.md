# sokkian/simpleauth

> 标签: Authentication, Passwordless, magic-link, php, security

## 简介

A lightweight, secure PHP library for passwordless authentication using magic links

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
