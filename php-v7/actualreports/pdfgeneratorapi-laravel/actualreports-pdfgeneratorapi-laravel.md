# actualreports/pdfgeneratorapi-laravel

> 标签: Laravel PDF Generator, pdf

## 简介

PDF Generator API package for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
