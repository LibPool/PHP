# marsberrys/laravel-sqs-plain-queue

> 标签: aws, illuminate, laravel, lumen, queue, sqs, sqs-raw

## 简介

Adds a Laravel queue driver for Amazon SQS FIFO queues.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
