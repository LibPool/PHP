# tekton/framework

> 标签: PHP

## 简介

Tekton is a lightweight PHP micro-framework, designed to integrate as a shim in older codebases to enable modern design patterns

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
