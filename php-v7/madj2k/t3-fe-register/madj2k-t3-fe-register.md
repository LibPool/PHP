# madj2k/t3-fe-register

> 标签: Frontend Users, TYPO3 CMS, login, register, registration, user groups

## 简介

Extension for registration of FE-Users and FE-Usergroups

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
