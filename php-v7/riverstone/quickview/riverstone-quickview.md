# riverstone/quickview

> 标签: PHP

## 简介

Quickview& ajaxcart Extension  view product details directly from the category page & add product to the cart without reloading the page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
