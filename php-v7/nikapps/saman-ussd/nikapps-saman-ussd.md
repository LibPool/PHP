# nikapps/saman-ussd

> 标签: 724, Bank, gateway, iran, nikpay, pardakht, payment, saman, ussd

## 简介

A php package for connecting to Saman 724 USSD gateway

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
