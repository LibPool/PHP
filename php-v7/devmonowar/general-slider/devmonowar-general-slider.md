# devmonowar/general-slider

> 标签: block, carousel, elementor, gutenberg, image slider, responsive slider, slider, slideshow, splide, wordpress, wordpress-plugin

## 简介

Create reusable carousel sliders in minutes — no jQuery, block-ready, accessible, and no coding required. Assets load only where a slider runs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
