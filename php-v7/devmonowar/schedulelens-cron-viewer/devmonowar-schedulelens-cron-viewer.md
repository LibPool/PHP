# devmonowar/schedulelens-cron-viewer

> 标签: cron, cron job manager, cron-manager, health, missed-schedule, scheduled posts, scheduler, wordpress-plugin, wp-cron

## 简介

See all scheduled jobs, catch overdue tasks, run or pause events, and check cron health - lightweight, admin-only, 100% free.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
