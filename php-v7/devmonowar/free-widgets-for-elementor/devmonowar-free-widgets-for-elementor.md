# devmonowar/free-widgets-for-elementor

> 标签: countdown-timer, elementor, elementor-addons, elementor-widgets, page-builder, pricing-table, table-of-contents, widgets, wordpress, wordpress-plugin

## 简介

A lightweight, 100% free set of essential Elementor widgets that the free core doesn't include.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
