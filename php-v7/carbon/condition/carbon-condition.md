# carbon/condition

> 标签: FUSION, Neos, carbon, condition, flow, helper

## 简介

This package provides some fusion helper for making writing conditions (`@if`) easier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
