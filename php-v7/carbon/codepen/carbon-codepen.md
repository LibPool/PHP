# carbon/codepen

> 标签: PHP

## 简介

Code alongside a live preview rendered by Fusion. You can configure it further to use Javascript to preview or inject JS and styles via Fusion

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
