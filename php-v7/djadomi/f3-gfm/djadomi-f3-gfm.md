# djadomi/f3-gfm

> 标签: fat-free, github-flavoured, markdown

## 简介

GitHub-Flavoured Markdown plugin for Fat-Free Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
