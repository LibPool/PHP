# webwhales/guzzle-conditional-mock-handler

> 标签: Guzzle, http, mocking

## 简介

Offers a way to load mocked responses conditionally with Guzzle instead of a fixed queue

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
