# staabm/xhprof.io

> 标签: frontend, gui, profiler, xhprof

## 简介

GUI to analyze the profiling data collected using XHProf - A Hierarchical Profiler for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
