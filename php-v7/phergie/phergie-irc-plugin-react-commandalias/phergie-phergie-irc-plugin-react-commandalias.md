# phergie/phergie-irc-plugin-react-commandalias

> 标签: bot, irc, plugin, react

## 简介

Phergie plugin for enabling the use of custom aliases for existing bot commands

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
