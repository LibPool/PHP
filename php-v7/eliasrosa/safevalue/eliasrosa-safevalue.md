# eliasrosa/safevalue

> 标签: eliasrosa, safevalue

## 简介

Cria valor seguro, com a possibilidade de checar se o valor foi alterado.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
