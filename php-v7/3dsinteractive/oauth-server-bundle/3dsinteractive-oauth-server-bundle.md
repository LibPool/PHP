# 3dsinteractive/oauth-server-bundle

> 标签: api, oauth, server

## 简介

Server side implementation of the OAuth 1.0 protocol based on RFC 5849

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
