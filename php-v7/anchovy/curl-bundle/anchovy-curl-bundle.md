# anchovy/curl-bundle

> 标签: PHP cURL, Symfony2 cURL, curl

## 简介

This bundle provides a simple OOP interfaces for cURL php wrapper.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
