# bmack/modern-template-building

> 标签: PHP

## 简介

A homage to the old-style marker-based templating of TYPO3. Includes TEMPLATE and FILE cObjects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
