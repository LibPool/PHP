# startcodein/indicsoundex

> 标签: bn_IN, en_US, gu_IN, hi_IN, india, indicsoundex, kn_IN, language, ml_IN, or_IN, pa_IN, soundex, startcodein, ta_IN, te_IN, unicode

## 简介

Indian language soundex package based on Santhosh Thottingal's algorithm.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
