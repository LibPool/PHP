# umbalaconmeogia/yii2-ssosubdomain

> 标签: SSO, subdomains, yii2

## 简介

Library to help implementing SSO on subdomains.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
