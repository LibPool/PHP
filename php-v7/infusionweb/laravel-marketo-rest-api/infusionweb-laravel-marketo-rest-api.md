# infusionweb/laravel-marketo-rest-api

> 标签: Marketo, api, laravel, rest

## 简介

Provides a Laravel 5 service provider and facade for Marketo REST API Client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
