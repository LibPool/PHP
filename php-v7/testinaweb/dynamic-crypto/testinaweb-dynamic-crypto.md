# testinaweb/dynamic-crypto

> 标签: decrypt, decrypter, encrypt, encrypter, mcrypt

## 简介

A php library to encrypt and decrypt strings with dynamic keys

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
