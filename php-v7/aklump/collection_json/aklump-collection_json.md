# aklump/collection_json

> 标签: amundsen, hypermedia, json, vnd.collection

## 简介

Php objects for working with hypermedia Collection+JSON (http://amundsen.com/media-types/)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
