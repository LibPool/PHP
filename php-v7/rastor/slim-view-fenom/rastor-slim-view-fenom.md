# rastor/slim-view-fenom

> 标签: fenom, framework, renderer, slim, template, tpl, view

## 简介

Slim adapter for render fenom views into a PSR-7 Response object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
