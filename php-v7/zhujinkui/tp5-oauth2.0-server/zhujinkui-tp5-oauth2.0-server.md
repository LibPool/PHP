# zhujinkui/tp5-oauth2.0-server

> 标签: PHP

## 简介

This is a class library of Oauth2.0 based on ThinkPHP5, which is a modern standard for protecting access to API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
