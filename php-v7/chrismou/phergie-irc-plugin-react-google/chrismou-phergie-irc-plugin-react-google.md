# chrismou/phergie-irc-plugin-react-google

> 标签: bot, irc, phergie, plugin

## 简介

Phergie plugin for returning Google search results and estimated result counts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
