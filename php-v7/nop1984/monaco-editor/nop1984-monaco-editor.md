# nop1984/monaco-editor

> 标签: editor, online editor

## 简介

This repository created to store JS Build of Monaco Editor for Composer package. Exact copy of build on official site, but not in zip

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
