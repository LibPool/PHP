# digicademy/cobj_xpath

> 标签: Digital Humanities, Xpath, typo3, xml

## 简介

Extends TYPO3 with a new content object XPATH for flexible querying of XML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
