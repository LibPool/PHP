# gpaton/parse-bundle

> 标签: bundle, parse, parse.com, sdk, symfony

## 简介

Integration for Parse.com PHP SDK in your Symfony2 Project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
