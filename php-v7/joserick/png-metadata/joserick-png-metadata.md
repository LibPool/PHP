# joserick/png-metadata

> 标签: exif, exiftool, metadata, png, xmp

## 简介

A PHP library for extract the metadata (XMP, EXIF) within a PNG format image.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
