# linkworld/alipaysdk-openapi

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

支付宝开放平台v3协议文档，兼容了v2版本sdk的自动引入

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
