# scratcher28/glide-optimizer

> 标签: glide, image, optimizer

## 简介

An optimizer manipulator for Glide that uses ps/image-optimizer package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
