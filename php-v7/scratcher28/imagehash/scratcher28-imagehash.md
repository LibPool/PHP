# scratcher28/imagehash

> 标签: ahash, dhash, hash, image hash, imagehash, perceptual, phash

## 简介

Perceptual image hashing for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
