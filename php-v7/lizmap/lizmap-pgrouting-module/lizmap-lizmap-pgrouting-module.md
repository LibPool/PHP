# lizmap/lizmap-pgrouting-module

> 标签: jelix, lizmap, module, pgrouting, routing

## 简介

Jelix module for Lizmap, which adds tools to manage routes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
