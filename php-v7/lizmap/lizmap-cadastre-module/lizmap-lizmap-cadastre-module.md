# lizmap/lizmap-cadastre-module

> 标签: cadastre, jelix, lizmap, module

## 简介

Jelix module for Lizmap, which adds tools to interact with french cadastral data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
