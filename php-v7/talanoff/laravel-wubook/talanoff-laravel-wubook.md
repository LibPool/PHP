# talanoff/laravel-wubook

> 标签: Talanoff, laravel-package, laravel-wubook, wubook

## 简介

A WuBook bridge for Laravel 5.x, 6.x, 7.x http://wubook.net

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
