# xylis/faker-besson-scenario-provider

> 标签: PHP

## 简介

Generate random scenario that could be written by Luc Besson (with Audi cars, cabs and hookers)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
