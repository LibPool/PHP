# venustheme/magento2-setup

> 标签: magento 2 module setup, venustheme, venustheme setup

## 简介

Module magento 2 setup to use export/import magento 2 extension sample data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
