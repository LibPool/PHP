# aarailfan/aarailfan_b5

> 标签: PHP

## 简介

A Drupal 9/10 bootstrap5 subtheme built for https://www.aarailfan.com.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
