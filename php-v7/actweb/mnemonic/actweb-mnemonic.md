# actweb/mnemonic

> 标签: mnemonic, password

## 简介

Converts passed text into mnemonic text, ideal for making passwords easier to read, also includes a password generator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
