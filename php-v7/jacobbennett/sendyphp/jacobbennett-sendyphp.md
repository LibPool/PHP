# jacobbennett/sendyphp

> 标签: Sendy, newsletter

## 简介

A PHP Library for interfacing with the Sendy newsletter system (http://sendy.co)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
