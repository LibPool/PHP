# silverback/svbk-wp-email

> 标签: PHP

## 简介

Send Wordpress emails with templates through Email Services API (Sendinblue, Mandrill..)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
