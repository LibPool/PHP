# tixelrocks/long-env

> 标签: aws, eb, elastic beanstalk, env, php

## 简介

A helper function that adds support for long environment variables (eg for AWS)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
