# irazasyed/larasupport

> 标签: larasupport, laravel, laravel lumen support, laravel package support, laravel packages, lumen packages, lumen support

## 简介

Adds Laravel Package Support in Lumen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
