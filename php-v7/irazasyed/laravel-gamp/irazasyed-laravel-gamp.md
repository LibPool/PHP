# irazasyed/laravel-gamp

> 标签: analytics, ga measurement protocol, google analytics, laravel google analytics, lumen google analytics, measurement protocol, tracking

## 简介

Send analytics data to Google Analytics from Laravel. A package for GA Measurement Protocol API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
