# cecula/vereafy

> 标签: 2-factor authentication, 2fa, Authentication, Cecula, Cecula PHP, Two-factor Authentication, Vereafy, Vereafy PHP, tfa, two-factor

## 简介

A PHP Library for Integrating with Vereafy Two-Factor Authentication (2FA) Service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
