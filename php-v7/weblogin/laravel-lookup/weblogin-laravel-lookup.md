# weblogin/laravel-lookup

> 标签: cast, eloquent, laravel, laravel-lookup, lookup, weblogin

## 简介

Laravel lookup objects and Eloquent casts for static data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
