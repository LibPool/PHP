# rvtraveller/qs-revert-all-features-d7

> 标签: PHP

## 简介

Quicksilver implementation to revert all features in a Drupal 7 site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
