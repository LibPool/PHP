# rvtraveller/qs-db-sanitization

> 标签: PHP

## 简介

Quicksilver implementation to sanitize a production database when it is rolled back to a prior environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
