# erachain/sdk-php

> 标签: api, blockchain, erachain, library, php, sdk

## 简介

Библиотека для работы с блокчейн сетью Erachain

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
