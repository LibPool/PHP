# mkungla/aframe-php

> 标签: aframe, php

## 简介

Just a idea and test case repo to find out what would be the best way to structure the PHP API for creating A-Frame 3D and virtual reality scenes. This repo is nothing for production use at this point!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
