# thinframe/http

> 标签: cookies, headers, http, interfaces, thinframe

## 简介

collection of PHP classes that simplifies the work with the HTTP protocol.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
