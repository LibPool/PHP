# monei/monei-php-sdk

> 标签: api, monei, monei pay, pay, payment gateway, payments, php, rest, sdk

## 简介

The MONEI SDK will allow you to interact with our API in an easy and predictable way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
