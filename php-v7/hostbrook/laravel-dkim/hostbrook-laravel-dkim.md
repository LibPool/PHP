# hostbrook/laravel-dkim

> 标签: PHP

## 简介

Laravel 9.x, 10.x, 11.x, 12.x and 13.x package to sign emails with DKIM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
