# jun3/lumen-make

> 标签: PHP

## 简介

Lumen Job, Modle, Controller, Command, Middleware, Logic, Service, Task, Event, Exception, Provider, Listener 自动创建脚手架

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
