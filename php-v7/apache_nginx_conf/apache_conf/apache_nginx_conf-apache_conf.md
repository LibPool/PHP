# apache_nginx_conf/apache_conf

> 标签: apache2, conf, config, parser, php

## 简介

This is a set of classes for working with configuration files of the Apache2 web server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
