# dek-cz/meta-canonical-control

> 标签: canonical, component, header, meta, nette, seo

## 简介

Nette control for managing meta data and canonical link in HTML header.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
