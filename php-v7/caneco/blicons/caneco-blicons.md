# caneco/blicons

> 标签: blade, blicons, caneco, icons, laravel, svg

## 简介

A package to use your SVG icon sprite in your Laravel Blade views.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
