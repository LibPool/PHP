# botdelive/botdelive

> 标签: PHP

## 简介

BotDelive is a Push Notification and 2-factor authentication API service that works over the chat bots (Telegram and Messenger).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
