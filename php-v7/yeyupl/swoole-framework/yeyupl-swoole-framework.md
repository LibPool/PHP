# yeyupl/swoole-framework

> 标签: Socket, client, framework, library, server, webserver, websocket

## 简介

PHP Networking framework & Application Server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
