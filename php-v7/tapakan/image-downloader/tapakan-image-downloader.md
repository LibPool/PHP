# tapakan/image-downloader

> 标签: downloader, image, remote

## 简介

PHP lib for download images from remote host

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/Tapakan/image-downloader.git
- Packagist 页面：https://packagist.org/packages/tapakan%2Fimage-downloader
