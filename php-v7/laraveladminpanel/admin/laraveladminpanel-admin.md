# laraveladminpanel/admin

> 标签: admin, laravel, panel

## 简介

A Laravel Admin Package to make your life easier and steer your project in the right direction

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
