# wormling/phparia

> 标签: ARI, ami, asterisk, call, client, ivr, php, rest, telephony, voip

## 简介

Asterisk REST Interface (ARI) client for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
