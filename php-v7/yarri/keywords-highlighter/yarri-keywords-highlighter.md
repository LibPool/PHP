# yarri/keywords-highlighter

> 标签: highlight, highlighting, html, keyword, keywords, search

## 简介

Highlights keywords (typically a search query) in a HTML string

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
