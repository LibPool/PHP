# yarri/my-blowfish

> 标签: blowfish, hash, hashing, password, passwords

## 简介

Simple class for passwords hashing and checking using Blowfish algorithm

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
