# klsoft/yii3-doctrine

> 标签: doctrine, orm, yii3

## 简介

The package provides an easy way to integrate the Yii 3 framework with the Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
