# klsoft/yii3-rbac-doctrine

> 标签: authorisation, authorization, doctrine, orm, rbac, yii3

## 简介

The package provides Yii RBAC storage using the Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
