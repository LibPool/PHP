# pollen-solutions/wp-kernel

> 标签: component, kernel, pollen-solutions, wordpress

## 简介

Pollen Solutions - Wordpress Kernel Component - Basic tools for building a web application based on Wordpress and the Pollen Solutions component suite.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
