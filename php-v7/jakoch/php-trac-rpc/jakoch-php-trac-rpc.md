# jakoch/php-trac-rpc

> 标签: api, curl, json, rpc, trac, xml

## 简介

A library to interact with a Trac Bugtracker API via remote procedure calls.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
