# brayniverse/laravel-route-view-helper

> 标签: helper, laravel, routing, view

## 简介

Syntactic sugar for those occasions when you only want to display a basic view.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
