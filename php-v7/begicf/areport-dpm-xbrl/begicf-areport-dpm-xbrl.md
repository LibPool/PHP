# begicf/areport-dpm-xbrl

> 标签: DPM, adaptiv, packaging, report, xbrl

## 简介

AreportDpmXBRL is a package for parsing XBRL taxonomy which is created by EU standards

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
