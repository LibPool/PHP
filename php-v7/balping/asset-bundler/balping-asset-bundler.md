# balping/asset-bundler

> 标签: assets, laravel, laravel Modules, mix

## 简介

Bundles assets for Laravel Mix from Laravel Modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
