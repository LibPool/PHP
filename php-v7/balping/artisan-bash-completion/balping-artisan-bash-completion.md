# balping/artisan-bash-completion

> 标签: artisan, bash, completion, laravel

## 简介

Adds bash completion for Laravel 9+ artisan CLI.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
