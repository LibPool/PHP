# mastermunj/advanced_html_dom

> 标签: Xpath, dom, jquery, xml

## 简介

A better drop-in replacement for PHP's simple html dom.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
