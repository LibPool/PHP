# tuhuokeji/diandicms

> 标签: ai开源框架, python开源框架, yii2

## 简介

店滴云-针对多商户业务开发的一套管理cms,支持多运营主体,单运营主体运营开发

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
