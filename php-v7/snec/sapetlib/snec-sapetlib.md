# snec/sapetlib

> 标签: api, eventticketing, sap, snec, xmlrpc

## 简介

Library for using SAP Event Ticketing APIs like XMLRPC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
