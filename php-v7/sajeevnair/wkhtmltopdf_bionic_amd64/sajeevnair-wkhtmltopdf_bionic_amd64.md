# sajeevnair/wkhtmltopdf_bionic_amd64

> 标签: PHP

## 简介

Convert html to pdf using webkit (qtwebkit). Static linked linux binary for Ubuntu 18.04 (bionic) amd64

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
