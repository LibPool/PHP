# arcanedev/route-viewer

> 标签: Viewer, arcanedev, laravel, route

## 简介

Route Viewer is a package that allows you to view all Laravel routes eloquently

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
