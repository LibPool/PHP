# arcanedev/breadcrumbs

> 标签: bootstrap, breadcrumbs, foundation, html, laravel, navigation, twitter, zurb

## 简介

A simple way to create breadcrumbs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
