# seravo/wp-custom-bulk-actions

> 标签: bulk action, custom, posts, wordpress

## 简介

Custom bulk actions for any type of posts in WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
