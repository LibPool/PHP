# robinmarechal/database-rest-unwrapper

> 标签: DatabaseRestUnwrapper, RobinMarechal

## 简介

A simple way to unwrap your database as a RESTful API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
