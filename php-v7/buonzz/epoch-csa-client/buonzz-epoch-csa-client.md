# buonzz/epoch-csa-client

> 标签: adult, api, billing, client, epoch

## 简介

PHP Client Library for interacting with Epoch's Customer Search API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
