# buonzz/laravel-4-freegeoip

> 标签: freegeoip.net, geoip, ip to location, maps, no local geodatabase required, retrieve location, track location

## 简介

Laravel 4 Library for detecting geogpraphical location info of your visitors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
