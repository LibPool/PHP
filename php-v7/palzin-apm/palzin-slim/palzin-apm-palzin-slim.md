# palzin-apm/palzin-slim

> 标签: monitoring, palzin, php, slim

## 简介

Real-Time monitoring Slim package using Palzin Monitor (APM).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
