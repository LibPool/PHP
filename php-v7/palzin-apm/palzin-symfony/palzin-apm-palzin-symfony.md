# palzin-apm/palzin-symfony

> 标签: bundle, monitoring, palzin, php, symfony

## 简介

Real-Time monitoring Symfony package using Palzin Monitor (APM)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
