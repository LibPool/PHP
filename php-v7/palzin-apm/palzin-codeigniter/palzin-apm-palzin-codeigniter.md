# palzin-apm/palzin-codeigniter

> 标签: codeigniter4, monitoring, palzin, php

## 简介

Real-Time monitoring Codeigniter package using Palzin Monitor (APM).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
