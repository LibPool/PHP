# jitesoft/xml2struct

> 标签: array, convert, parsing, xml

## 简介

Simple lib to convert a xml file into a tree structure of nodes, an array structure or a json string.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
