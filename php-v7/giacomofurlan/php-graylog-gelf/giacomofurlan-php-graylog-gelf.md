# giacomofurlan/php-graylog-gelf

> 标签: gelf, graylog2, logger, psr, udp

## 简介

A PHP PSR-3 compliant logger to send data to graylog2 (GELF format)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
