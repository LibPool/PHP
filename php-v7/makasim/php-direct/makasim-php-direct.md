# makasim/php-direct

> 标签: direct, ext js, server

## 简介

Php direct server for ExtJs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/makasim/php-direct
- 源码仓库：https://github.com/makasim/php-direct.git
- Packagist 页面：https://packagist.org/packages/makasim%2Fphp-direct
