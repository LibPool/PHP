# archipro/silverstripe-db-json

> 标签: cms, silverstripe

## 简介

A Silverstripe CMS module to enable the creation of MySQL 8 JSON column on DataObjects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
