# cartograf/geocoder

> 标签: cartograf, geocoder

## 简介

Barebones geocoder class using cUrl. Not a replacement for willdurand/geocoder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
