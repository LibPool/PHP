# francerz/http-utils

> 标签: http, http-factory, http-message, psr-17, psr-7

## 简介

PHP HTTP utils compatible with PSR-7, PSR-17

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
