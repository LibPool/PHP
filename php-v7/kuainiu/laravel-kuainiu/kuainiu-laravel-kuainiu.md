# kuainiu/laravel-kuainiu

> 标签: kuainiu, socialite

## 简介

API client wrapper for Laravel & Connect provider for Laravel Socialite

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
