# recoil/kernel

> 标签: Thread, async, asynchronous, continuation, coroutine, event, generator, green, multitasking, react

## 简介

Reusable components for implementing Recoil kernels.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
