# espend/idea-badge

> 标签: PHP

## 简介

Provides badges support for statistics of IntelliJ IDEA / PhpStorm Plugin Repository with the help of Poser library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
