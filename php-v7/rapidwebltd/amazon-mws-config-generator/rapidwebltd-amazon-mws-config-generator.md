# rapidwebltd/amazon-mws-config-generator

> 标签: PHP

## 简介

Generate configuration files for PHP Amazon MWS library - https://github.com/CPIGroup/phpAmazonMWS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
