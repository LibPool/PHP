# dlapps/consul-php-envvar

> 标签: consul, environment, php, variable

## 简介

Define missing environment variables from Consul KV and expose them in Symfony 3.2+ containers

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
