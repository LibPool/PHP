# ujamii/neos-mailjetsubscription

> 标签: PHP

## 简介

Adds 2 new form finishers for the form builder to sub/unsub to mailjet mailing list

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
