# ujamii/ujamii-geocoder

> 标签: PHP

## 简介

Connecting http://geocoder-php.org/Geocoder with TYPO3 DataHandler API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
