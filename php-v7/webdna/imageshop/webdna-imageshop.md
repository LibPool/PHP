# webdna/imageshop

> 标签: Craft, cms, craft-plugin, craftcms, imageshop

## 简介

Imageshop DAM Integration for CraftCMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
