# techone/think-excel

> 标签: OpenXML, excel, gnumeric, ods, php, spreadsheet, thinkphp, xls, xlsx

## 简介

A pure PHP library for reading and writing spreadsheet files for ThinkPHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
