# abbotton/alipay-sdk

> 标签: PHP

## 简介

支付宝（蚂蚁金服）开放平台第三方 PHP SDK，基于官方最新版本。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
