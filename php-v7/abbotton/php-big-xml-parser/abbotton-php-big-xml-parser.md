# abbotton/php-big-xml-parser

> 标签: PHP XML解析, SAX XML, SAX-Parser, abbotton, 大型XML解析

## 简介

使用PHP SAX Parser解析大型XML文件

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
