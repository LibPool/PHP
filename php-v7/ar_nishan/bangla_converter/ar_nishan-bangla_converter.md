# ar_nishan/bangla_converter

> 标签: PHP

## 简介

Bangla/Bengali string transformation library which can convert Bangla string Unicode/Avro to Bijoy and also Bijoy to Avro

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
