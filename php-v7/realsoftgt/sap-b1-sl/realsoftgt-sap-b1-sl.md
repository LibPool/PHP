# realsoftgt/sap-b1-sl

> 标签: PHP

## 简介

SAPBOSL es el puente entre su desarrollo Laravel y SAP Business One Service Layer utilizando Laravel HTTP Client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
