# asprega/breadcrumb-bundle

> 标签: breadcrumb, breadcrumbs, bundle, symfony

## 简介

A bundle for generating dynamic breadcrumbs in Symfony applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
