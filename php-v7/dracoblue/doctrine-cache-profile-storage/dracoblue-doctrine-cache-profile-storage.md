# dracoblue/doctrine-cache-profile-storage

> 标签: cache, profiler, symfony

## 简介

Use a Doctrine Cache as ProfilerStorageInterface for Symfonys Web Profiler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
