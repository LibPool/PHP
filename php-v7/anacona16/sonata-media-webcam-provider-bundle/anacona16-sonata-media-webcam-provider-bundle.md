# anacona16/sonata-media-webcam-provider-bundle

> 标签: SonataMediaBundle, image, webcam

## 简介

Enable webcam provider for Sonata Media Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
