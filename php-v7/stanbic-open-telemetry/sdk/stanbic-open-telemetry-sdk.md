# stanbic-open-telemetry/sdk

> 标签: Metrics, apm, logging, opentelemetry, otel, sdk, tracing

## 简介

SDK for OpenTelemetry PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
