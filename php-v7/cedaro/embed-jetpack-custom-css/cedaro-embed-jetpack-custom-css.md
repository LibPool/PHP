# cedaro/embed-jetpack-custom-css

> 标签: wordpress

## 简介

A WordPress plugin to embed Jetpack Custom CSS in the document head to improve performance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
