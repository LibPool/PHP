# idct/sftp-client

> 标签: idct, scp, sftp, ssh, ssh2

## 简介

Library that provides wrapper methods around SSH2 and SFTP to simplify file download/upload over SSH/SCP/SFTP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
