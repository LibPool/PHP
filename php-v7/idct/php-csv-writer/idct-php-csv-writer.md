# idct/php-csv-writer

> 标签: csv, csvwriter, eol, idct, io, text, textwriter

## 简介

CsvWriter based on a buffered TextWriter with EOL support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
