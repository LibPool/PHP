# oihana/php-m2m

> 标签: API-Client, client-credentials, jwt, jwt-bearer, m2m, machine-to-machine, oauth2, oidc, php, php74, zitadel

## 简介

Lightweight, OIDC-compliant Machine-to-Machine (M2M) HTTP client for APIs protected by JWT — implements the OAuth 2.0 jwt-bearer flow (RFC 7521 + RFC 7523). PHP 7.4 compatibility branch.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
