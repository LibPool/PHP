# leewillis77/open-exchange-rates-api

> 标签: api, currency, exchange rate

## 简介

A PHP wrapper for the 'open exchange rates' API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
