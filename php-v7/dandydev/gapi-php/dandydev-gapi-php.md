# dandydev/gapi-php

> 标签: 2.4, google analytics

## 简介

Gapi-php is a new version of the Gapi-php class, for accessing Google Analytics accounts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
