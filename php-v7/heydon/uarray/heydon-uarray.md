# heydon/uarray

> 标签: RocketSoftware, u2

## 简介

Allow manipulation of PICK Dynamic Arrays in PHP for use with RockSoftware's U2 products

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
