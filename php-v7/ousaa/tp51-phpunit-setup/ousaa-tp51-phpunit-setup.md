# ousaa/tp51-phpunit-setup

> 标签: PHP

## 简介

一键为 ThinkPHP 5.1 项目配置 PHPUnit 测试环境

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
