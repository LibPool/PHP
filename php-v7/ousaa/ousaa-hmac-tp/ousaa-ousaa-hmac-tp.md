# ousaa/ousaa-hmac-tp

> 标签: Authentication, api, hmac, signature, thinkphp

## 简介

ThinkPHP 通用 HMAC 签名认证包，服务端验签与客户端签名一体

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
