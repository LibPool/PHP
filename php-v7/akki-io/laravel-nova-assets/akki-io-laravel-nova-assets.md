# akki-io/laravel-nova-assets

> 标签: akki-io, laravel-nova, laravel-nova-assets

## 简介

A simple package for laravel nova to manage all nova related assets.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
