# barryvdh/assetic-filters

> 标签: PHP

## 简介

Additional CSSminFilter and UriPrependFilter, using the mrclay/minify libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
