# hab/ntriples

> 标签: RDF, Semantic Web, linked open data, lod, n-triples, ntriples

## 简介

A simple library for publishing data encoded as N-Triples

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
