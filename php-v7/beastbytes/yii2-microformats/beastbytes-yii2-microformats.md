# beastbytes/yii2-microformats

> 标签: microformat, microformats, microformats2, widget, yii2

## 简介

Yii2 Widget to generate microformats2 from model data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
