# karyamedia/karya

> 标签: Skeleton, codeigniter, karya, project, starter-kit

## 简介

Karya web application framework base on Codeigniter MVC architecture.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
