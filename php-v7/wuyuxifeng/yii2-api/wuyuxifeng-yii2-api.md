# wuyuxifeng/yii2-api

> 标签: PHP

## 简介

基于yii2的restful组件.一个基于yii2的restful接口组织方案，自动生成在线文档供前端工程师阅读

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
