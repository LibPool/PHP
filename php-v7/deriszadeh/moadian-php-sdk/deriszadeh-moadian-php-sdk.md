# deriszadeh/moadian-php-sdk

> 标签: PHP

## 简介

PHP SDK for working with tp.tax.gov.ir (سامانه مودیان مالیاتی)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
