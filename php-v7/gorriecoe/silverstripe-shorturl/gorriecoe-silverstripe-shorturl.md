# gorriecoe/silverstripe-shorturl

> 标签: Shorturl, cms, link, silverstripe

## 简介

Provides a shorter path to URLs using your domain.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
