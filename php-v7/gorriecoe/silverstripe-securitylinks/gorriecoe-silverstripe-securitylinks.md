# gorriecoe/silverstripe-securitylinks

> 标签: link, login, logout, silverstripe

## 简介

Adds a login, logout and lost password link types to Link Object.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
