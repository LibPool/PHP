# gorriecoe/silverstripe-devbuildkey

> 标签: build, dev, devbuild, silverstripe

## 简介

Enables the use of the key press ctrl+d or alt+d to run dev build.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
