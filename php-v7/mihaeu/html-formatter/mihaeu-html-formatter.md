# mihaeu/html-formatter

> 标签: clean, formatter, html, pretty

## 简介

HTML Formatter pritifies HTML content by applying proper intendation (no tidy, purification, etc.).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
