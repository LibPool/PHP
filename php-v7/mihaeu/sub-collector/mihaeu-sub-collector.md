# mihaeu/sub-collector

> 标签: SubDB, movie, subtitle

## 简介

Sub-Collector is a console based app written in PHP, its main purpose is to batch collect subtitles.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
