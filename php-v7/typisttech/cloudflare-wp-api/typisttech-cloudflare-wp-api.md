# typisttech/cloudflare-wp-api

> 标签: cloudflare, cloudflare-wp-api, typisttech, wordpress

## 简介

WordPress HTTP API replacement of the jamesryanbell/cloudflare package.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
