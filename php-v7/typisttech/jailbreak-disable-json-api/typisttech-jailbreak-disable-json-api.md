# typisttech/jailbreak-disable-json-api

> 标签: wordpress, wp

## 简介

Allow whitelisted REST routes to pass through [Disable REST API](https://wordpress.org/plugins/disable-json-api/) filters

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
