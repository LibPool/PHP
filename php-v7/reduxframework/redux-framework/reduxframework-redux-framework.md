# reduxframework/redux-framework

> 标签: Settings, customizer, framework, options, plugin, redux, wordpress

## 简介

Build better and beautiful sites in WordPress, faster.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
