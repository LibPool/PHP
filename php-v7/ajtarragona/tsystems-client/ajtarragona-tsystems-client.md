# ajtarragona/tsystems-client

> 标签: laravel, laravel5

## 简介

Client per serveis de l'ERP de Tsystems (Tercers, Padró, Vialer)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
