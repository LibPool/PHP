# mitto/sms-backend-app

> 标签: mitto, sms

## 简介

Application framework for running services for sending SMS, viewing sent SMS and aggregated statistics.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
