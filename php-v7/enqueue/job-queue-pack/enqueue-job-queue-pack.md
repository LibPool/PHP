# enqueue/job-queue-pack

> 标签: doctrine, enqueue, job, queue

## 简介

A pack to install Enqueue's job queue with Doctrine as a storage in a Symfony Flex application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
