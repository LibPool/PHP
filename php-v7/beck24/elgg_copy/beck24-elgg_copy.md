# beck24/elgg_copy

> 标签: clone, copy, dev, development, elgg, plugin

## 简介

A tool to sync data between a production and develpment elgg instance

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
