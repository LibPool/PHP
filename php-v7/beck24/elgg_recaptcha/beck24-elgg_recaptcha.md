# beck24/elgg_recaptcha

> 标签: captcha, elgg, plugin, recaptcha, spam

## 简介

Provides recaptcha protection for forms

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
