# yalesov/zf2-assetwig

> 标签: ZendFramework, asset management, assetic, twig, zf2

## 简介

Integrates Assetic and Twig to a ZF2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
