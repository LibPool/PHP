# jcbowen/mysql-helper-yii2

> 标签: Mysql Helper, MysqlHelperYii2, jcbowen, yii2

## 简介

基于yii2的mysql维护助手，可以将表结构以数组方式储存下来，也可以轻松实现表的差异对比及生成对应的修复sql语句

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
