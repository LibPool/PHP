# jcbowen/jcbase-yii2

> 标签: jcbase, jcbowen, jiuchet, yii2

## 简介

自用yii2基础扩展库，提供一些常用的封装，方便开发。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
