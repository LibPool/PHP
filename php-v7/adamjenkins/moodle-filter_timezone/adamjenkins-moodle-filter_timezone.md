# adamjenkins/moodle-filter_timezone

> 标签: PHP

## 简介

Converts date/time spans inserted by the companion tiny_timezone TinyMCE plugin from the timezone they were authored in to the timezone of the viewing user

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
