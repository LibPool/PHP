# adamjenkins/moodle-mod_aiescape

> 标签: PHP

## 简介

A Moodle activity module that creates an AI-driven interactive escape room experience using Moodle's core_ai subsystem

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
