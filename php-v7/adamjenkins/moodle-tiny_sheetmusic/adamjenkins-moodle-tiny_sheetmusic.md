# adamjenkins/moodle-tiny_sheetmusic

> 标签: PHP

## 简介

The sheet-music authoring plugin for Moodle's TinyMCE editor: a toolbar button and Insert menu item that open the local_sheetmusic score editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
