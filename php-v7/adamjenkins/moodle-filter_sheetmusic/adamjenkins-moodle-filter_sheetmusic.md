# adamjenkins/moodle-filter_sheetmusic

> 标签: PHP

## 简介

A Moodle text filter that renders sheet music wherever Moodle displays text, using the local_sheetmusic engine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
