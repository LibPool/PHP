# adamjenkins/moodle-filter_ruby

> 标签: PHP

## 简介

A Moodle text filter that adds furigana (ruby) readings above difficult kanji, with word lists that each course can customise for itself

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
