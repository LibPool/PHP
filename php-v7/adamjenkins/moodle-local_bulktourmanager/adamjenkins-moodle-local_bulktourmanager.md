# adamjenkins/moodle-local_bulktourmanager

> 标签: PHP

## 简介

Adds bulk import/export/delete for tool_usertours guided tours directly onto the existing User tours admin page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
