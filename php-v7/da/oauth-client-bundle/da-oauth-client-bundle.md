# da/oauth-client-bundle

> 标签: bundle, client, da, oauth, symfony

## 简介

DaOAuthClientBundle is a Symfony2's bundle allowing to use an application as an oauth client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
