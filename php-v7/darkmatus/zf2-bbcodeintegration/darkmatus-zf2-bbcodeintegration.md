# darkmatus/zf2-bbcodeintegration

> 标签: bbcode

## 简介

Integration of Decoda BBCode-parser as ViewHelper into ZF2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
