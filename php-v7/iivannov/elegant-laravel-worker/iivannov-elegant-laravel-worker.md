# iivannov/elegant-laravel-worker

> 标签: deadlock, laravel, php, queue, sigterm, worker

## 简介

Elegant way to gracefully handle SIGTERM signal in Laravel queue worker

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
