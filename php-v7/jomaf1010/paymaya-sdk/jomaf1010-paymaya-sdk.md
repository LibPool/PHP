# jomaf1010/paymaya-sdk

> 标签: paymaya, payments, rest, sdk

## 简介

Cloned PHP SDK for PayMaya APIs. Accept credit and debit card payments on your web app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
