# bluesheep/php-jsonenv

> 标签: PHP

## 简介

A light-weight package for PHP that loads environment variables (such as database credentials) from a JSON-encoded source.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
