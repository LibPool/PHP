# datafactory/ezpublish-legacy

> 标签: PHP

## 简介

eZ Publish LegacyStack (4.x), maintained by Netgen for compatibility with eZ Platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
