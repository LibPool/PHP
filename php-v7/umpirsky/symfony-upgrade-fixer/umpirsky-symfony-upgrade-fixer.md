# umpirsky/symfony-upgrade-fixer

> 标签: PHP

## 简介

Analyzes your Symfony project and tries to make it compatible with the new version of Symfony framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
