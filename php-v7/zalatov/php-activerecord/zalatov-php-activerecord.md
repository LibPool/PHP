# zalatov/php-activerecord

> 标签: activerecord, orm

## 简介

php-activerecord is an open source ORM library based on the ActiveRecord pattern.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/zalatov/php-activerecord.git
