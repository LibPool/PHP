# dchesterton/phpdoc-to-return

> 标签: PHP

## 简介

Convert PHPDoc @return hints to PHP7/Hack native return type syntax

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
