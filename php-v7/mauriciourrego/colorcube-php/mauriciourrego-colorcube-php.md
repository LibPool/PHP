# mauriciourrego/colorcube-php

> 标签: PHP

## 简介

Dominant color extraction from RGB images — PHP port of Ole Krause-Sparman's algorithm.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
