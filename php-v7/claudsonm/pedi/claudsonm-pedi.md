# claudsonm/pedi

> 标签: Pagseguro, cielo, claudsonm, edi, electronic data interchange, parser

## 简介

Electronic Data Interchange (EDI) file parser for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
