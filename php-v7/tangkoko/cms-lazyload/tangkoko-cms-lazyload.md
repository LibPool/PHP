# tangkoko/cms-lazyload

> 标签: PHP

## 简介

This module is a fork of magesuite/cms-lazyload converts images inserted into static blocks to be lazy loaded

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
