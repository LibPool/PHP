# venca-x/social-login

> 标签: Facebook login, Google login, Social Login, Twitter login, nette, php

## 简介

Nette addon. Login with social networks ( Faceboook, Google, Twitter )

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
