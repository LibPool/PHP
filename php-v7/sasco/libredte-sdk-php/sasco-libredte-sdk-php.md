# sasco/libredte-sdk-php

> 标签: api, chile, dte, facturación electrónica, sii

## 简介

Cliente para realizar la integración con los servicios web de LibreDTE desde PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://www.libredte.cl
- 源码仓库：https://github.com/LibreDTE/libredte-api-client-php.git
