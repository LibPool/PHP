# codemax/wp-plugin-env

> 标签: PHP

## 简介

El proyecto contiene la clase WPPluginEnv que permite resolver la ruta de ubicación del plugin y su url.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
