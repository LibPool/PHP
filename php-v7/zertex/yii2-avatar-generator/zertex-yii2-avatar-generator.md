# zertex/yii2-avatar-generator

> 标签: avatar, avatar-generator, userpic, yii 2, yii2

## 简介

Avatar generator for Yii2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
