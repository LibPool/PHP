# zertex/yii2-gridview-pagesize-widget

> 标签: extension, grid-view, page-size, widget, yii2

## 简介

Widget for enabling dynamic page size selection on GridView

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
