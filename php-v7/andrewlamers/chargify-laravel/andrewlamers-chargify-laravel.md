# andrewlamers/chargify-laravel

> 标签: chargify, chargley, laravel

## 简介

Laravel service provider for chargifys API using the chargley chargify SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
