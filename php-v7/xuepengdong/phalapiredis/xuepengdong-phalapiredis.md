# xuepengdong/phalapiredis

> 标签: phalapi, phalapi-redis, redis

## 简介

兼容phalapi/redis 所有方法； Redis 增强版

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
