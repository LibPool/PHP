# bushbaby/zf2-module-phing-service

> 标签: module, phing, zf2

## 简介

Zend Framework 2 module for Phing, a PHP project build system or build tool based on Apache Ant.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
