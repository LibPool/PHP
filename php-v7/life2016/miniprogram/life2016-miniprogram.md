# life2016/miniprogram

> 标签: miniprogram, wechat, yii2-miniprogram, 小程序, 微信

## 简介

MiniProgramSDK是一个PHP的小程序开发包。封装微信小程序后端相关接口，比如解密信息（用户信息、手机号）、获取小程序码等

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
