# jinowom/layui-gii

> 标签: PHP

## 简介

基于Yii2框架，通过gii生成layui布局,包括Crud脚手架（Generator）、model脚手架、生成统一的API格式的脚手架。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
