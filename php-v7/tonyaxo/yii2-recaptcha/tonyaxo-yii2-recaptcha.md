# tonyaxo/yii2-recaptcha

> 标签: extension, recaptcha, widget, yii2

## 简介

Yii2 Google reCaptcha implementation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
