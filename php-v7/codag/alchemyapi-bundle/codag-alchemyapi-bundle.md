# codag/alchemyapi-bundle

> 标签: alchemy, alchemyapi, api

## 简介

Symfony2 Bundle for AlchemyAPI integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
