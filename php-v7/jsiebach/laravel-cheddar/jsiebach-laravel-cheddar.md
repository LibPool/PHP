# jsiebach/laravel-cheddar

> 标签: CheddarGetter, laravel

## 简介

An unofficial service provider for using CheddarGetter in Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
