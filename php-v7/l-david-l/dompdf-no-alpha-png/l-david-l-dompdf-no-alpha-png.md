# l-david-l/dompdf-no-alpha-png

> 标签: PHP

## 简介

A fork of dompdf/dompdf with no PNG alpha processing. DOMPDF is a CSS 2.1 compliant HTML to PDF converter

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
