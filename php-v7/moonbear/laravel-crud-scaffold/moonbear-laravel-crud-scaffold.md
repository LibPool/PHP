# moonbear/laravel-crud-scaffold

> 标签: PHP

## 简介

A Laravel package to help you generate nearly complete CRUD pages like crazy!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
