# gladyshev/yii2-rucaptcha

> 标签: anticaptcha, extension, rucaptcha, yii, yii2

## 简介

Yii2 rucaptcha.com captcha recognition extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
