# vicens/captcha

> 标签: captcha, laravel, laravel5, verification Code, 验证码

## 简介

一个简单的laravel5图形验证码扩展包

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
