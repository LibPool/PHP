# ergebnis/php-cs-fixer-config

> 标签: PHP

## 简介

Provides a configuration factory and rule set factories for friendsofphp/php-cs-fixer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
