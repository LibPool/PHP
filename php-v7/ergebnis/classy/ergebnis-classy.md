# ergebnis/classy

> 标签: classes, classy, constructs, finder, interfaces, traits

## 简介

Provides collectors for classy constructs (classes, enums, interfaces, and traits).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
