# cryptommer/web3

> 标签: USDT, contract, dai, eth, sign, web3

## 简介

A simple encapsulation of Web3 framework in PHP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
