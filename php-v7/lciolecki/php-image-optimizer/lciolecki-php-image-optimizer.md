# lciolecki/php-image-optimizer

> 标签: image, optimizer, php

## 简介

PHP image file optimizer (uses https://github.com/bensquire/php-image-optim)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
