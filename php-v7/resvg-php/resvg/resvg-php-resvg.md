# resvg-php/resvg

> 标签: image, png, rasterizer, resvg, svg

## 简介

Render SVG to PNG in-process, backed by a statically linked build of resvg

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
