# fahimxyz/wp-shift-db

> 标签: db, plugin, wordpress, wp-shift-db

## 简介

WP Shift DB eliminates the manual work of migrating a WP database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
