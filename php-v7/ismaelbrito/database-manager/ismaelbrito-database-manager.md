# ismaelbrito/database-manager

> 标签: PHP

## 简介

Biblioteca em PHP para gerenciar conexões e operações com MySQL usando PDO, com suporte a CRUD e tipagem moderna.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
