# dunglas/php-schema

> 标签: RDF, doctrine, entity, enum, model, owl, schema.org, semantic, symfony

## 简介

Various tools to generate a data model based on Schema.org vocables

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
