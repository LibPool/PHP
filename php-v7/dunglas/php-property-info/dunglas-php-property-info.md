# dunglas/php-property-info

> 标签: doctrine, phpdoc, property, symfony, type, validator

## 简介

Retrieve type and description of PHP properties using various sources

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
