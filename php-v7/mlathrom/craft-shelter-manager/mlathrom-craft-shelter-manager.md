# mlathrom/craft-shelter-manager

> 标签: Craft, cms, craft-plugin, craftcms, shelter manager

## 简介

Adds animals from Shelter Manager to Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
