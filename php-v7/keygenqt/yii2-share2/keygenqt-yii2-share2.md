# keygenqt/yii2-share2

> 标签: share, share2, soc, yandex, yii2

## 简介

An easy way to add buttons soc network share. Widget uses the Yandex Block "Share".

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
