# keygenqt/yii2-datepicker

> 标签: extension, jquery, keygenqt, plugin, widget, yii2

## 简介

Widget datepicker jquery ui with update style.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
