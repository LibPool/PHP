# kba-team/legacy-mpdf

> 标签: PHP

## 简介

LEGACY VERSION 5.4! A PHP class to generate PDF files from HTML.

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
