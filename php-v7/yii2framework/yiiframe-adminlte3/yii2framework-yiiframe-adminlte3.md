# yii2framework/yiiframe-adminlte3

> 标签: extension, yii2, yiiframe, yiiframework

## 简介

Adminlte3 Background Administration framework resource file for YiiFrame

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
