# marc-mabe/php-enum

> 标签: enum, enum-map, enum-set, enumeration, enumerator, enummap, enumset, map, set, type, type-hint, typehint

## 简介

Simple and fast implementation of enumerations with native PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
