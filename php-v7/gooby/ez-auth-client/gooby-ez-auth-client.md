# gooby/ez-auth-client

> 标签: SSO, jwt, php

## 简介

Client for using the gooby/ez-auth-server to enable SSO across multiple sub domains with JWTs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
