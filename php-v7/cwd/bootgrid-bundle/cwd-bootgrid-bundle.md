# cwd/bootgrid-bundle

> 标签: bootgrid, bootstrap, bundle, grid, symfony, table

## 简介

Integrates Bootgrid as Symfony Bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
