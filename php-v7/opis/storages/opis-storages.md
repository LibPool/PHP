# opis/storages

> 标签: cache, config, database, opis, redis, session, storage

## 简介

This package provides storage implemenatations for Opis Cache, Opis Session and Opis Config

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
