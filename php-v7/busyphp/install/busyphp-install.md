# busyphp/install

> 标签: BusyPHP install, BusyPHP安装器

## 简介

用来安装BusyPHP依赖的基本数据的安装程序，安装成功后可通过 Composer 命令删除

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
