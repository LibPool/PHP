# spiffy/spiffy-view-twig

> 标签: PHP

## 简介

Spiffy\View\Twig is a twig compatability layer built on Spiffy\View.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
