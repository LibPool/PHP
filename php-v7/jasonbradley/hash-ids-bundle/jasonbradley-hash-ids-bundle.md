# jasonbradley/hash-ids-bundle

> 标签: hashids

## 简介

Symfony2 Bundle for HashIds library - http://hashids.org/php/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
