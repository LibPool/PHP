# waibelp/yamlizer

> 标签: deserializer, json, php, serializer, yaml, yml

## 简介

Yamlizer is an PHP object serializer built with an eye on simplicity and performance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
