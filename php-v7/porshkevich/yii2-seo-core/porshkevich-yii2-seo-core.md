# porshkevich/yii2-seo-core

> 标签: extension, meta, seo, url, yii2

## 简介

Seo Core extension for the Yii2 framework. Control tags and url aliases.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
