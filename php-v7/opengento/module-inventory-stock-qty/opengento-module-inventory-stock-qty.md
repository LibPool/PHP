# opengento/module-inventory-stock-qty

> 标签: PHP

## 简介

FIX Magento (Adobe Commerce) Multi-Stock-Inventory (MSI) stock quantity.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
