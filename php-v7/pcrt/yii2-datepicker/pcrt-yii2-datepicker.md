# pcrt/yii2-datepicker

> 标签: assets, helper, tempusdomini, theme, yii2

## 简介

Yii2-datepicker widget based on TempusDomini

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
