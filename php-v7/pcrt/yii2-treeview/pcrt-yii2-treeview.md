# pcrt/yii2-treeview

> 标签: assets, fancytree, helper, theme, yii2

## 简介

Yii2-treeview widget based on FancyTree

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
