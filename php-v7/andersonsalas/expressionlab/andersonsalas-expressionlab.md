# andersonsalas/expressionlab

> 标签: PHP

## 简介

Expression Lab is a sandboxed diagnostics and data inspection environment for WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
