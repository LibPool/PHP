# wake/silex-twig-assetic-integration-provider

> 标签: assetic, silex, twig

## 简介

An integration library of Twig and Assetic works for Silex.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
