# sudocoder/s3fileuploader

> 标签: PHP

## 简介

this package is to upload file and copy file from one bucket to another on S3 by just providing bucket detail and file name of S3 for multiple systems. Also check the existance of file on S3 and download the file from S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
