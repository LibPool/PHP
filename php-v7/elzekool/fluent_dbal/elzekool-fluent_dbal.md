# elzekool/fluent_dbal

> 标签: database, dbal, fluent, library, pdo

## 简介

Easy to use and framework independant fluent database abstraction layer on top of PDO.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
