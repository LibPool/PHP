# ultraner/sdk

> 标签: africa, airtel money, mobile money, mpesa, mtn momo, payments, paypal, stripe, ultraner

## 简介

Ultraner PHP SDK, one API for payments across Africa (mobile money, cards, PayPal, wallets).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/Ultraner/ultraner-php.git
