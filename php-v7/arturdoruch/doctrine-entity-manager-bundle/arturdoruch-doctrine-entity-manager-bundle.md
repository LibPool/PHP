# arturdoruch/doctrine-entity-manager-bundle

> 标签: Doctrine entity manager

## 简介

Helps to create and access to the own doctrine entity manager classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
