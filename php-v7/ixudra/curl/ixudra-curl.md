# ixudra/curl

> 标签: Ixudra, curl, laravel

## 简介

Custom PHP Curl library for the Laravel framework - developed by Ixudra

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
