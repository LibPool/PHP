# jozefgrencik/slovak-postal-codes

> 标签: gps, municipalities, postal codes, psc, slovakia, streets, zip

## 简介

Slovak postal codes (PSČ) with municipalities, streets and GPS coordinates, updated daily from the Ministry of Interior address register.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
