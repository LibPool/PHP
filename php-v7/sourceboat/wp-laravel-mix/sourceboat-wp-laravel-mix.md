# sourceboat/wp-laravel-mix

> 标签: laravel, mix, wordpress

## 简介

Get versioned Laravel Mix file paths in WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
