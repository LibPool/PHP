# digipolisgent/kimai-security-plugin

> 标签: Kimai, kimai-plugin

## 简介

A Kimai 2 plugin, which adds some security related functionality .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
