# austinheap/laravel-security-txt

> 标签: laravel, route, security, security.txt

## 简介

A package for serving `security.txt` in Laravel 5.5+, based on configuration settings.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
