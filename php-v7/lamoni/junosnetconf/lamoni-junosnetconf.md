# lamoni/junosnetconf

> 标签: juniper, junos, netconf, php

## 简介

A Juniper NETCONF XML Management Protocol implementation in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
