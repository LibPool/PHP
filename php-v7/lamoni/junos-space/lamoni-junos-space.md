# lamoni/junos-space

> 标签: junos, management, network, php, platform, space

## 简介

A PHP API for interacting through REST API with Juniper's Junos Space Network Management Platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
