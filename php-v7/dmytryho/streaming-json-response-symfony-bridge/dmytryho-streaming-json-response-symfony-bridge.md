# dmytryho/streaming-json-response-symfony-bridge

> 标签: PHP

## 简介

Streamable JSON response for Symfony based on violet/streaming-json-encoder

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
