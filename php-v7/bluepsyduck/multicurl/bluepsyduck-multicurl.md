# bluepsyduck/multicurl

> 标签: BluePsyduck, curl, multicurl

## 简介

Simple library helping with requesting multiple resources at once using multi cUrl.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
