# tubepress/tubepress

> 标签: embed, embedding, embeds, galleries, media, video, vimeo, youtube

## 简介

Modern video galleries for the web.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
