# insenseanalytics/omnipay-razorpay

> 标签: india, netbanking, payment gateway, payments, razorpay, wallets

## 简介

Razorpay Omnipay 3.0 plugin for accepting payments

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
