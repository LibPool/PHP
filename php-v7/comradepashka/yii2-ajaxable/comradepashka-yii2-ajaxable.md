# comradepashka/yii2-ajaxable

> 标签: ajaxable, extension, yii2

## 简介

Ajaxable behavior for autodetection and handling AJAX requests

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
