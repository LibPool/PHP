# rnsharma93/lara-ftp-deployer

> 标签: PHP

## 简介

A blazing fast, highly optimized FTP-based deployment package for Laravel applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
