# siad007/versioncontrol_hg

> 标签: PHP

## 简介

VersionControl_HG is a library that provides an OO interface to handle Mercurial repositories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
