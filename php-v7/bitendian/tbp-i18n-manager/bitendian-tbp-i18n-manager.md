# bitendian/tbp-i18n-manager

> 标签: gettext, i18n, modules, multilanguage, services, tbp

## 简介

Management package for i18n static texts for TBP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
