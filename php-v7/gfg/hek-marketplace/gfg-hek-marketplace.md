# gfg/hek-marketplace

> 标签: PHP

## 简介

HekMarketplace plugin to provide integration between your software and ExternalShop (kanui/tricae/dafiti)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
