# drupal/commerce_recipe_project_browser

> 标签: commerce

## 简介

Recipe that installs the Commerce Project Browser for discovering Commerce integrations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
