# drupal/commerce_recipe_stripe_payment_element

> 标签: commerce, commerce_payment

## 简介

Recipe that configures the Stripe Payment Element as a Commerce payment gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
