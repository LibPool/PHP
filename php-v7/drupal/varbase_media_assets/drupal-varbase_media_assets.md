# drupal/varbase_media_assets

> 标签: Demo Content, Varbase recipes, assets, drupal recipe, drupal recipes, media, recipe, varbase recipe

## 简介

A recipe to manage importing default demo media assets for Varbase Media Types.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
