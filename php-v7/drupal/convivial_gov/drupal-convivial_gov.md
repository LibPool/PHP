# drupal/convivial_gov

> 标签: PHP

## 简介

A starter site for government built on Drupal Canvas and Recipes providing editor-friendly components for best-practice government sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
