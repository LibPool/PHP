# drupal/lupus_decoupled_recipe_canvas

> 标签: PHP

## 简介

A recipe to install Lupus Decoupled Drupal with Canvas integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
