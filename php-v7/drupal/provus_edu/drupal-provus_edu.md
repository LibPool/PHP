# drupal/provus_edu

> 标签: PHP

## 简介

A complete Drupal CMS recipe for higher education websites. Installs content types, views, menus, and configuration for a production-ready college or university site in a single command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
