# drupal/media_image_styles

> 标签: PHP

## 简介

Provides focal point-based image styles, responsive image styles, SVG image media type, and view modes for media.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
