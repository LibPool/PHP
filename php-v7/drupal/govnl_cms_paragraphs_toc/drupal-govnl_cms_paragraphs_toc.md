# drupal/govnl_cms_paragraphs_toc

> 标签: PHP

## 简介

Recipe for a Table of Contents paragraph and block type in GovNL CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
