# drupal/agent_access

> 标签: PHP

## 简介

Drupal-side connectivity and authorization for external AI agents through existing user accounts; this implementation assembles MCP + OAuth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
