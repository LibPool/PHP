# drupal/bistro

> 标签: PHP

## 简介

Provides functionality to configure restaurant menus for a restaurant, bar, pub, bistro, or café web site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
