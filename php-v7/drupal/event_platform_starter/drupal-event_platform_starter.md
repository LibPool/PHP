# drupal/event_platform_starter

> 标签: PHP

## 简介

Provides a freshly installed version of the Drupal Event Platform, set up and ready to start customizing for your event.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
