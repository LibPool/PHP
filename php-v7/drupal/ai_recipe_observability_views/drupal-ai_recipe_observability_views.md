# drupal/ai_recipe_observability_views

> 标签: PHP

## 简介

Store AI provider events in SQL and provide searchable logs and usage charts through Views.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
