# drupal/lupus_decoupled_blog

> 标签: PHP

## 简介

A recipe to install Drupal CMS Blog recipe including Lupus Decoupled Drupal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
