# drupal/drupal_cms_accessibility_tools

> 标签: PHP

## 简介

Adds automated checks to help ensure content conforms to web accessibility guidelines.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
