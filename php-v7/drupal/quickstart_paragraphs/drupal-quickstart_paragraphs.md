# drupal/quickstart_paragraphs

> 标签: drupal recipe, drupal recipes, recipe

## 简介

Creates Paragraph Types required to create a basic site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
