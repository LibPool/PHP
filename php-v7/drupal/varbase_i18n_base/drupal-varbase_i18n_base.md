# drupal/varbase_i18n_base

> 标签: Drupal Canvas, TMGMT, Varbase recipes, ai translation, drupal recipe, drupal recipes, i18n, internationalization, multilingual, recipe, translation, varbase recipe

## 简介

A recipe to manage internationalization, languages, and translation support with default configurations and permissions for Varbase multilingual sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
