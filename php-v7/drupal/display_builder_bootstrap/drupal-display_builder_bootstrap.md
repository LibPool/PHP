# drupal/display_builder_bootstrap

> 标签: drupal recipe, drupal recipes, recipe

## 简介

Provide a Display Builder Demo website with Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
