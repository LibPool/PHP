# drupal/maplibre_gl_js

> 标签: PHP

## 简介

Mirror of the Maplibre GL javascript library tagged as a Drupal library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/maplibre/maplibre-gl-js/

- Packagist 页面：https://packagist.org/packages/drupal%2Fmaplibre_gl_js
