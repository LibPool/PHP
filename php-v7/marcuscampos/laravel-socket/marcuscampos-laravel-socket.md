# marcuscampos/laravel-socket

> 标签: Socket, elephant, io, laravel, react

## 简介

Socket gun based on Elephant.io for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
