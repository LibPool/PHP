# m4tlch/laravel-blog

> 标签: admin, blog, feed, laravel, news, package, panel, posts, rss, update, write

## 简介

Simple blog (with admin panel) for Laravel based on webdevetc/m4blog

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
