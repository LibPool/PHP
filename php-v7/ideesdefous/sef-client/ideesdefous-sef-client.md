# ideesdefous/sef-client

> 标签: fencing, scores, sef

## 简介

This package is used to retrieve data from the SEF-Scores platform for different tournaments

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
