# unionofrad/li3_lldr

> 标签: g11n, li3, lithium, lldr, locale, php

## 简介

A Lithium plugin with additional g11n resources constituting the Lithium Locale Data Repository.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
