# superhuit/wp-graphql-redirection

> 标签: graphql, redirection, wordpress

## 简介

Exposes Redirection WP plugin in the WP-GraphQL schema

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
