# akondas/chess.php

> 标签: PHP

## 简介

chess.php is a PHP chess library that is used for chess move generation/validation, piece placement/movement, and check/checkmate/stalemate detection

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
