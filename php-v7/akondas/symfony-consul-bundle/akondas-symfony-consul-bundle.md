# akondas/symfony-consul-bundle

> 标签: consul, microservices, php, symfony, symfony-bundle

## 简介

Auto register symfony app with Consul

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
