# dramos/authorize-net-php-sdk

> 标签: authorize.net, ecommerce, payment, php

## 简介

A PHP library for working with all Authorize.Net APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
