# adyen/adyen-magento2-expresscheckout

> 标签: PHP

## 简介

Official Adyen Magento2 plugin to add express payment method shortcuts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
