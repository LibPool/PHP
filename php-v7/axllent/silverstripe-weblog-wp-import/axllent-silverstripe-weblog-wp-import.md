# axllent/silverstripe-weblog-wp-import

> 标签: blog, import, silverstripe

## 简介

WordPress import tool for the Silverstripe Weblog module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
