# axllent/silverstripe-analytics-js

> 标签: analytics, googleanalytics, silverstripe, tracking

## 简介

Google Universal Analytics tracking code for Silverstripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
