# drupal-spider/drupal-fullcalendar

> 标签: drupal-library, fullcalendar

## 简介

FullCalendar libraries for Drupal projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
