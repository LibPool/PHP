# tidalgo22/administrator

> 标签: admin, administrator, cms, database, laravel, laravel-administrator

## 简介

A database interface package for Laravel (Legacy of Frozennode Laravel-Administrator) and (exodusanto Laravel-Admin)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
