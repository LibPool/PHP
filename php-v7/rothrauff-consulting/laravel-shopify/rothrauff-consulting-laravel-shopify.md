# rothrauff-consulting/laravel-shopify

> 标签: laravel, laravel-shopify, rothrauff-consulting, shopify

## 简介

A Laravel wrapper for the Shopify API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
