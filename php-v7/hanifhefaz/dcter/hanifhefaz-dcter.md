# hanifhefaz/dcter

> 标签: PHP

## 简介

A composer package used to convert Jalali, Hijri, Gregorian and Julian dates to each others. Plus some extra utilities and helpers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
