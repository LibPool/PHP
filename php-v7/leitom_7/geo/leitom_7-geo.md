# leitom_7/geo

> 标签: geo, laravel, leitom, redis

## 简介

A package that leverage redis geospatial functionality for super fast searching and integrates beautifully with Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
