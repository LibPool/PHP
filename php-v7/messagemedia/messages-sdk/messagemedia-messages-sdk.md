# messagemedia/messages-sdk

> 标签: api, messages, sdk

## 简介

The MessageMedia Messages API provides a number of endpoints for building powerful two-way messaging applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
