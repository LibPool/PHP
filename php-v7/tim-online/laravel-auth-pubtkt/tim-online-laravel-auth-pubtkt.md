# tim-online/laravel-auth-pubtkt

> 标签: SSO, laravel, mod_auth_pubtkt

## 简介

Laravel login server for mod_auth_pubtkt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
