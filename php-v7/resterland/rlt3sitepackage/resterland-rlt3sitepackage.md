# resterland/rlt3sitepackage

> 标签: HTML5, LitElement, TSconfig, TYPO3 CMS, TypoScript, extension, fluid, javascript, php, sitepackage, yaml

## 简介

TYPO3 CMS Sitepackage Starter Kit. Contains website templates, assets, configuration and custom code for my TYPO3 projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
