# helori/laravel-files

> 标签: combine, compress, convert, helori, image, optimize, pdf, zip

## 简介

Utilities to manipulate images and PDF files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
