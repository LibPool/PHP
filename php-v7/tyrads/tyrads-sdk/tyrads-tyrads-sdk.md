# tyrads/tyrads-sdk

> 标签: PHP7, api, iframe, offerwall, php5, php8, sdk, tyrads

## 简介

Official TyrAds SDK for PHP - Compatible with PHP 5.5+ through PHP 8.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
