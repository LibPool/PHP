# guillaumepotier/pdfxtractor

> 标签: pdfconverter, pdftojpeg, pdftojpg, pdfxtractor

## 简介

Convert PDFs to JPEG images like a charm!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
