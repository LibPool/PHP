# ddesrosiers/classy-soap-client

> 标签: object, soap

## 简介

A wrapper to PHP's SoapClient that allows interaction will a SOAP service via classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
