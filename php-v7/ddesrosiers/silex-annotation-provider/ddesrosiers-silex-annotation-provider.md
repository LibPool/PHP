# ddesrosiers/silex-annotation-provider

> 标签: annotation, provider, service, silex

## 简介

A silex service provider that allows the use of annotations in ServiceControllers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
