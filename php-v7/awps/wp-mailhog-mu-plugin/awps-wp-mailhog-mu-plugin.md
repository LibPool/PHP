# awps/wp-mailhog-mu-plugin

> 标签: PHP

## 简介

WordPress Mailhog MU Plugin. Designed to be used in tandem with docker-compose

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
