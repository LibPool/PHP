# chronon/ymlp

> 标签: cakephp, component, plugin, ymlp

## 简介

A CakePHP 2.x plugin component that interfaces with YMLP/Your Mailing List Provider's API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
