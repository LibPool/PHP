# wxm/pdd-sdk

> 标签: kernel, laravel, lumen, pdd, php, pinduoduo, sdk

## 简介

拼多多 SDK 封装, 调用简单、语义化增强。支持 Laravel/Lumen。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
