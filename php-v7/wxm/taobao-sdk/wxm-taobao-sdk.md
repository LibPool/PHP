# wxm/taobao-sdk

> 标签: kernel, laravel, lumen, php, sdk, taobao, taobaoke

## 简介

淘宝 SDK 封装, 调用简单、语义化增强。支持 Laravel/Lumen。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
