# bold-commerce/module-checkout-payment-booster-swissup-firecheckout-compatibility

> 标签: PHP

## 简介

Compatibility module for Bold Payment Booster integration for Adobe Commerce with Swissup Firecheckout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
