# tiitoo/input-mask-bundle

> 标签: PHP

## 简介

A simple Symfony bundle that implements Form classes for RobinHerbots/Inputmask jQuery plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
