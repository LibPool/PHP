# myttyy/directory-file

> 标签: PHP

## 简介

>=PHP7.1适用的目录&文件工具库类，包含目录(文件)创建、复制、剪贴，生成遍历树，以及指定目录查找文件等操作

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
