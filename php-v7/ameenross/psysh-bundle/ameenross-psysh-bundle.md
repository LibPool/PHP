# ameenross/psysh-bundle

> 标签: REPL, console, interactive, psysh, shell, symfony

## 简介

A port of the PHP REPL PsySH for Symfony 2.x.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
