# bfday/php-base64-data-url

> 标签: PHP

## 简介

Library to work with base64 data URL scheme. More info in https://ru.wikipedia.org/wiki/Data:_URL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
