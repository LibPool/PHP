# novinvision/simple-uploader

> 标签: PHP

## 简介

A laravel package for upload file with npm inertia-bootstrap-forms package or simple manage upload files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
