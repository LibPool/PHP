# heimrichhannot/contao-exporter-bundle

> 标签: backend, bundle, contao, csv, developer, excel, export

## 简介

A backend module for exporting any contao entity to file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
