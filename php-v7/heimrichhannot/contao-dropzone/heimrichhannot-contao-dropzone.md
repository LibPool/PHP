# heimrichhannot/contao-dropzone

> 标签: contao, dropzone, upload, widget

## 简介

Contao front end widget that provides dropzonejs.com functionality.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
