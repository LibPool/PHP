# heimrichhannot/contao-privacy-bundle

> 标签: PHP

## 简介

This bundle contains functionality concerning privacy and the European Union's "General Data Protection Regulation" (GDPR).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
