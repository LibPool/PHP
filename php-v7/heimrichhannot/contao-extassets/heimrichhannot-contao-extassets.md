# heimrichhannot/contao-extassets

> 标签: JS, bootstrap, contao, css, font awesome

## 简介

External CSS & JS assets groups with bootstrap and font-awesome support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
