# heimrichhannot/contao-avisota_inline_css

> 标签: avisota, contao, css, developer, inline, module

## 简介

Extends the avisota newsletter system with inlining css.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
