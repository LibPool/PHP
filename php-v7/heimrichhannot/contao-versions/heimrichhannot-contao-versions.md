# heimrichhannot/contao-versions

> 标签: contao, versions

## 简介

Create versions within contao with ease and prevent entities from being purged by fromTable name. Also usable in frontend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
