# heimrichhannot/contao-tree-bundle

> 标签: PHP

## 简介

A contao bundle to create a tree structure like an organization chart in the contao backend and output it in the frontend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
