# heimrichhannot/contao-events-bundle

> 标签: PHP

## 简介

This bundle offers useful functionality concerning the entities "tl_calendar" and "tl_calendar_events" of the Contao CMS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
