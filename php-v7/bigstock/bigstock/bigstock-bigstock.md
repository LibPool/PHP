# bigstock/bigstock

> 标签: Bigstock, Shutterstock, api, client, library, module, php, stock photo

## 简介

PHP Bigstock API Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Packagist 仓库：https://repo.packagist.org/p2/bigstock/bigstock.json
- PHP 要求：>=5.3.0
