# dictpedia/zhuyin-pinyin

> 标签: Chinese, Pinyin, php, zhuyin

## 简介

A PHP library that deals with Zhuyin to Pinyin and Pinyin to Zhuyin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
