# farit-slv/sypex-geo-bundle

> 标签: IP Location, geoip, position, sypexgeo

## 简介

An adaptation of SypexGeo library to Symfony Bundle system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
