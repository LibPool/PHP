# benjamindean/one-line-apc

> 标签: apc, apcu, cache

## 简介

Dead simple wrapper class for APC and APCu which capable of setting and getting cached data in one line.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
