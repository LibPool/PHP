# prawee/yii2-auth-module

> 标签: extension, yii2

## 简介

Yii 2 User Authentication & Role Based Access Control (RBAC) Module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
