# mxc-commons/mxc-servicemanager

> 标签: PSR-11, ZendFramework, dependency-injection, di, dic, mxc-commons, service-manager, servicemanager, servicemanager-component, services, zf

## 简介

Zend ServiceManager 3.2 refactored for much better performance.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
