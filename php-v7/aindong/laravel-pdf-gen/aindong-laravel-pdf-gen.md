# aindong/laravel-pdf-gen

> 标签: IMAGE PREVIEW generator, Laravel pdf, PDF GENERATOR, laravel image

## 简介

A wkhtmltopdf and wkhtmltoimage wrapper for laravel applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
