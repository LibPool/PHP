# vection-framework/messenger

> 标签: command-bus, cqrs, event-bus, framework, message-broker, message-bus, message-queue, php, php-cqrs, query-bus, service-bus, transport

## 简介

A PHP message bus component for using as service bus (CQRS) and message transportation (queues).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
