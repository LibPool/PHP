# ufado/tron-api

> 标签: iexbase, tron-api, tron-lib, tron-php, tron-rest-api, ufado

## 简介

A PHP API for interacting with Tron (Trx),support Stake2.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
