# cachewerk/ext-relay

> 标签: PHP

## 简介

The fastest Redis client for PHP. 100× faster cache reads, near-zero bandwidth, no code changes required.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
