# kingson-de/marshal-json-serializer

> 标签: Marshal, deserializer, json, mappers, marshalling, serialization, serializer, unmarshalling

## 简介

Marshal JSON Serializer will directly serialize the data to JSON, it is built on top of the Marshal Serializer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
