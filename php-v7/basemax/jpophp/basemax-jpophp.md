# basemax/jpophp

> 标签: json, lexer, parser

## 简介

PHP JSON Parser (JSONParser PHP, JSONPHP) is a library for parsing the data in JSON format.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
