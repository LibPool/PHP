# prodigyphp/laravel-ssh-tunnel

> 标签: laravel, lumen, mysql, ssh, tunnel

## 简介

Easy creation & maintenance of an SSH Tunnel for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
