# jjpmann/ee-subscribe

> 标签: Emma, ee2, eecms, freeform, real magnet, subscribe

## 简介

Subscribe module for Real Magnet and others with Freeform Field type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
