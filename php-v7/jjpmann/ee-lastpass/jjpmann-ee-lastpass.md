# jjpmann/ee-lastpass

> 标签: eecms, lastpass

## 简介

Allows you to use Lastpass SAML to login via ExpressionEngine

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
