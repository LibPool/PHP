# batistackapp/rocket-chat

> 标签: chat, laravel, notification-channel, notifications, rocket.chat, rocketchat

## 简介

Rocket.Chat Notifications channel for Laravel 5.6+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
