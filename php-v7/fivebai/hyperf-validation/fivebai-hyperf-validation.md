# fivebai/hyperf-validation

> 标签: PHP

## 简介

hyperf/validation封装应用，解决验证类自定义方法创建、不同场景自定义方法灵活增减

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
