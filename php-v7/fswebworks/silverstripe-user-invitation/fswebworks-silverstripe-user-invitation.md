# fswebworks/silverstripe-user-invitation

> 标签: silverstripe, user invitation

## 简介

A SilverStripe module to handle user invitations to your secure website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
