# sgomez/simplesamlphp-module-dbal

> 标签: dbal, doctrine

## 简介

A SimpleSAMLphp module adding support for Doctrine/DBAL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
