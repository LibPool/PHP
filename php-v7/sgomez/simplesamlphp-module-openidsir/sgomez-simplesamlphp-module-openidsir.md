# sgomez/simplesamlphp-module-openidsir

> 标签: oauth2

## 简介

A SimpleSAMLphp filter for SIR OpenID attributes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
