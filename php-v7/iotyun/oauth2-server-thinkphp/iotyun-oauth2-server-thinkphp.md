# iotyun/oauth2-server-thinkphp

> 标签: PHP

## 简介

A plugin for implementing an OAuth2 server in ThinPHP6. Built on top of the PHP League's OAuth2 Server.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
