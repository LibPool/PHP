# mygento/kkm

> 标签: atol, magento

## 简介

Модуль интеграции фискальных кассовых аппаратов для Magento в соответствии с 54-ФЗ

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
