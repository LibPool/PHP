# wujidadi/pangtshiu

> 标签: helper

## 简介

Custom PHP helper library, named in Taiwanese Hoklo ("pang-tshiú" means "helper")

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
