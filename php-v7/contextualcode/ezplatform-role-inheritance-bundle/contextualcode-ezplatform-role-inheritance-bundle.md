# contextualcode/ezplatform-role-inheritance-bundle

> 标签: ezplatform, ezpublish, inheritance, role

## 简介

eZ Platform bundle which provides user role inheritance.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
