# thegeekengineer/laravel-packager

> 标签: Skeleton, laravel, package, packager

## 简介

A cli tool for creating Laravel packages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/TheGeekEngineer/laravel-packager
- 源码仓库：https://github.com/TheGeekEngineer/laravel-packager.git
- Packagist 页面：https://packagist.org/packages/thegeekengineer%2Flaravel-packager

## 历史版本号

- 当前版本：V1.0.1

## 获取地址

- Composer 安装：`composer require thegeekengineer/laravel-packager`
- Packagist 仓库：https://repo.packagist.org/p2/thegeekengineer/laravel-packager.json
- 许可证：EUPL-1.1
- PHP 要求：^7.1|^8.0
