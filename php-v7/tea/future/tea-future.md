# tea/future

> 标签: compatibility, polyfill, portable, shim

## 简介

Polyfill backporting some PHP 5.4+, 5.5+ ,5.6+, 7.0+ and 7.1+ features to lower PHP versions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
