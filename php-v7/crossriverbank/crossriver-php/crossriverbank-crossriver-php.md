# crossriverbank/crossriver-php

> 标签: PHP

## 简介

A PHP HTTP Client conforming to the HAL hypermedia type for the Crossriver processing API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
