# portrino/typo3-fractal-view

> 标签: extbase, fractal, json, typo3, view

## 简介

Integrates the fractal package (https://fractal.thephpleague.com/) into TYPO3 Extbase

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
