# lsx/recaptcha

> 标签: PHP

## 简介

Implementación flexible de Google reCAPTCHA para aplicaciones PHP con soporte para múltiples versiones.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
