# brandonhudson/lightning

> 标签: framework, micro, mqtt

## 简介

PHP micro framework for MQTT, letting you quickly connect, publish, and subscribe to topics.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
