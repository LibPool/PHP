# thedmsgroup/mautic-enhancer-bundle

> 标签: Marketing Automation, Mautic, marketing, plugin

## 简介

Various contact enhancer integrations for Mautic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
