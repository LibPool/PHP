# leaseweb/guzzle-bundle

> 标签: Guzzle, Symfony2, api, curl

## 简介

Guzzle API call functionality with full Web Debug Toolbar integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
