# christianbarkowsky/tabcontrol

> 标签: contao, tab, tabcontrol, tabs

## 简介

Create tabs as content element. Extension for Contao Open Source CMS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
