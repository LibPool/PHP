# aaronjan/housekeeper

> 标签: housekeeper, laravel, repository

## 简介

Powerful, simple Repository-Pattern implementation for Laravel (>=5.1), and it come with tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
