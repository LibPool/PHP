# jcleng/think-queue-rabbitmq

> 标签: PHP

## 简介

为 ThinkPH5.0 队列增加 RabbitMQ 驱动(forked https://github.com/jayazhao/think-queue-rabbitmq)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
