# dashzeveg/flarum-open-links-in-new-tab

> 标签: flarum

## 简介

A Flarum 2.0 extension that automatically opens links in a new tab.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
