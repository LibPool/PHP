# as-cornell/as_saml_gate

> 标签: PHP

## 简介

Creates SSO accounts only for people a saml_role_mapping recognises; everyone else is told to contact an administrator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
