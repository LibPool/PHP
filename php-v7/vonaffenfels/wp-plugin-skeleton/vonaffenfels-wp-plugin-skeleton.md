# vonaffenfels/wp-plugin-skeleton

> 标签: PHP

## 简介

Skeleton for development of Wordpress plugins using the vAF Wordpress Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
