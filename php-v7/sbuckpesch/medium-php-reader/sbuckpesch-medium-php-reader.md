# sbuckpesch/medium-php-reader

> 标签: medium, php-sdk, posts, read, user

## 简介

Easy SDK for reading Medium posts of a user by parsing mediums JSON feed.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
