# adcetera/adcetera_accessibe

> 标签: PHP

## 简介

Adcetera accessiBe - A simple module to inject accessiBe scripts into a site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
