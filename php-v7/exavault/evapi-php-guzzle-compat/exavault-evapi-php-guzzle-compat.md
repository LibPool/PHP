# exavault/evapi-php-guzzle-compat

> 标签: exavault, file transfer, php

## 简介

PHP Guzzle6 Compatibility SDK for ExaVault API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
