# murtadah/dashboard

> 标签: PHP

## 简介

Complete dashboard with automatic menu discovary based on user's roles and permission the system is also integrated with charts and datatables

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
