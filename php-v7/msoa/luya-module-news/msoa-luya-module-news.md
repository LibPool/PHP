# msoa/luya-module-news

> 标签: luya, luya-module, module, news, php, yii, yii2

## 简介

The news module will provided you a basic news system with categories and tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
