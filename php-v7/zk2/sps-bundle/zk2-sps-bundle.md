# zk2/sps-bundle

> 标签: admin panel, content manager, pagination, report, search, sort, sps

## 简介

Bundle implements the concept of "Search - Pagination - Sort" for tabular data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
