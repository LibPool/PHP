# danielspeir/rust

> 标签: REST router, Reverse Routing, router, routing

## 简介

Rust is a full-featured router for PHP 5.4+ with Reverse Routing and RESTful API support.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
