# iranimij/openlabel-hyva-bundle

> 标签: badges, hyva, mage-os, magento2, openlabel, product-labels, stickers

## 简介

OpenLabel for Hyvä in one require: product labels for Magento 2 and Hyvä (core, Hyvä render package and the shared base module). Free and MIT.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
