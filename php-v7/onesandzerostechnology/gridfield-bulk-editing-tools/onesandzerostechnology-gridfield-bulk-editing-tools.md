# onesandzerostechnology/gridfield-bulk-editing-tools

> 标签: PHP

## 简介

SilverStripe 3 GridField component to upload images and edit records in bulk

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
