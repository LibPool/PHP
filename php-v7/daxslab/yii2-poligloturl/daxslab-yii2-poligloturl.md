# daxslab/yii2-poligloturl

> 标签: i18n, seo, url, yii2

## 简介

Extension to help setup the language of an application based on params specifing the language

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
