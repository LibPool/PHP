> 标签: card-payments, checkout, credit-card, ecommerce, fiat-payments, gateway, laravel, merchant, payment-gateway, payment-processing, payments, paypal, php-sdk, stripe, unified-checkout, wordpress

## 简介

GembaPay PHP SDK — unified payment gateway for Stripe card payments and PayPal. Funds settle directly to the merchant.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
