# crazymeeks/accountlocker

> 标签: Laravel account locker, laravel

## 简介

A laravel package for lock and unlock user account when reached the max login attempt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
