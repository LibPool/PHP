# rafaeltovar/php-tus-aws-s3

> 标签: PHP

## 简介

Simple, light, minimum TUS server connected with AWS S3. Based on https://github.com/ankitpokhrel/tus-php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
