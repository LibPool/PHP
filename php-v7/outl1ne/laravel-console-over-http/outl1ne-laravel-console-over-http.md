# outl1ne/laravel-console-over-http

> 标签: console, laravel, outl1ne

## 简介

Run console commands over HTTP connection for Laravel applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
