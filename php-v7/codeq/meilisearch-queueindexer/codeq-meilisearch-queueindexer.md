# codeq/meilisearch-queueindexer

> 标签: PHP

## 简介

Asynchronous node indexing for Medienreaktor.Meilisearch via the Flowpack JobQueue.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
