# codeq/workspace-review

> 标签: PHP

## 简介

Human-readable workspace change review module for Neos CMS: word-level text diffs, editor-aware value labels, explicit visibility changes and per-page change summaries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
