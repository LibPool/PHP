# ajimix/asana-api-php-class

> 标签: api, asana

## 简介

A dependency free, lightweight PHP class that acts as wrapper for Asana API. Lets make things fast and easy! :)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
