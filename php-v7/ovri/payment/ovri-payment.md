# ovri/payment

> 标签: Bank, Banking, IPS-payment, card processing, credit card, gateway, moneytigo, ovri, ovri banking, payment, payment gateway, processor

## 简介

Composer Library for payment gateway Ovri.com / Ovri.app

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
