# orakaro/ioc

> 标签: Facades Design Pattern, dependency injection, inversion of control, ioc

## 简介

Tiny IoC module for static mocking in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
