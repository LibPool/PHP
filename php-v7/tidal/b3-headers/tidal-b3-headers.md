# tidal/b3-headers

> 标签: b3, b3-propagation, headers, zipkin

## 简介

An Interface which provides Zipkin B3 propagation headers as constants

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
