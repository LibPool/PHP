# syntaxx/wasm-php-runtime

> 标签: PHP

## 简介

Prebuilt PHP WebAssembly runtime (php.wasm + php.js)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
