# xcart/xcart-tools

> 标签: PHP

## 简介

Allows you to perform various development actions from CLI, e.g. redeploying X-Cart. Install it via `composer global require xcart/xcart-tools` command

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
