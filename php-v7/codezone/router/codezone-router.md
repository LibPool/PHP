# codezone/router

> 标签: PHP

## 简介

A FastRoute-based router for use in Roots-based WordPress plugins and themes or any plugin or theme that use Illuminate/Container.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
