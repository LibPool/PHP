# szmnmichalowski/szm-noty

> 标签: extension, notification, noty, zend

## 简介

jQuery plugin to notifications for Zend Framework 2/3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
