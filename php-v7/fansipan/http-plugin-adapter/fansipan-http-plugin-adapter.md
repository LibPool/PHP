# fansipan/http-plugin-adapter

> 标签: adapter, fansipan, http, httplug, middleware, plugin

## 简介

Fansipan adapter middleware for HTTPlug plugins

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
