# mcfedr/periodic-queue-driver-bundle

> 标签: doctrine, job, queue, schedule, task

## 简介

A bundle for running symfony background tasks with doctrine as the driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
