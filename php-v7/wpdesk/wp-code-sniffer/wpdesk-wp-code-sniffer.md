# wpdesk/wp-code-sniffer

> 标签: admin, code sniffer, phpcs, wordpress

## 简介

Library for WP Desk Coding Standards in plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
