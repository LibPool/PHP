# mapkyca/known-vagrant

> 标签: blogging, community, indieweb, publishing, social, vagrant

## 简介

Vagrant wrapper for the Known project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
