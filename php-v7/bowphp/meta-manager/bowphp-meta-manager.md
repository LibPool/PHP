# bowphp/meta-manager

> 标签: PHP

## 简介

Meta Manager is an SEO tool that is used to improve SEO of a Bowphp web application by adding recommended meta tags to your web pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
