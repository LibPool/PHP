# kameli/quickpay-v10

> 标签: api, form, gateway, payment, quickpay, v10

## 简介

A library to communicate with the Danish payment gateway Quickpay

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
