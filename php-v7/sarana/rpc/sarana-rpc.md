# sarana/rpc

> 标签: PHP

## 简介

Laravel package to interact with blockchain RPC nodes (e.g. Ethereum, BSC) using Tatum API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
