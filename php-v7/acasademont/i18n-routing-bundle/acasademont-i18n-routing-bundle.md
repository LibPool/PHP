# acasademont/i18n-routing-bundle

> 标签: multilanguage, routing, translation

## 简介

This bundle allows you to create i18n routes. Fork of the jms/i18n-routing-bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
