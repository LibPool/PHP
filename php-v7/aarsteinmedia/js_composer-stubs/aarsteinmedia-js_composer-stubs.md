# aarsteinmedia/js_composer-stubs

> 标签: js_composer, static analysis

## 简介

WPBakery Page Builder function, class, and global variable declaration stubs for easier static analysis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
