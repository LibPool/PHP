# ramcoelho/slim-skeleton

> 标签: microframework, psr7, rest, router

## 简介

Uma estrutura de aplicação Slim Framework 3.0 para desenvolvimento rápido. Baseado em slim/slim-skeleton

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
