# itsjavi/bootstrap-colorpicker

> 标签: bootstrap, colorpicker

## 简介

Bootstrap Colorpicker is a modular color picker plugin for Bootstrap 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
