# chabter/laravel-dutch-postalcode-lookup

> 标签: PHP

## 简介

Laravel wrapper to perform a Dutch postal code (postcode) lookup using the publicly available PDOK Locatieserver v3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
