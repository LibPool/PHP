# kekesed/cloudflare-adaptor

> 标签: PHP

## 简介

An easy way to normalize your Cloudflare-altered HTTP Information with a single line.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
