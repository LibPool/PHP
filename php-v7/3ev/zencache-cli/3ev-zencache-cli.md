# 3ev/zencache-cli

> 标签: cache, cli, wordpress, wp-cli, zencache

## 简介

Provide a CLI interface to the ZenCache Wordpress plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
