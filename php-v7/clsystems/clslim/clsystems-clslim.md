# clsystems/clslim

> 标签: api, eloquent, framework, php-di, robo, slim

## 简介

Skeleton Framework with Slim 4, PHP-DI and Eloquent ORM. Quick setup with Robo

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
