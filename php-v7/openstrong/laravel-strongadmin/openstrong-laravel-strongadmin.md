# openstrong/laravel-strongadmin

> 标签: laravel, layui, php, 后台管理

## 简介

在1分钟内构建一个功能齐全的管理后台。基于 layui 前端框架开发的 Laravel 后台管理框架。功能有 权限管理、菜单管理、角色管理、日志记录等。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
