# retrowaver/strawpoll-voter

> 标签: PHP

## 简介

Simple library for PHP that adds votes in strawpoll.me polls. Pretty fast since it uses concurrent requests.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
