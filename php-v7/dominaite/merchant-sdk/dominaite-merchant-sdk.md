# dominaite/merchant-sdk

> 标签: PHP

## 简介

Server-side PHP client for the Dominaite merchant API: create hosted checkout sessions from your own backend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
