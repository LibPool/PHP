# cstudios/page-cache

> 标签: Craft, cms, craft-plugin, craftcms, page cache

## 简介

This plugin utilizes the PageCache filter from yii2 into your craft 3 instance

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
