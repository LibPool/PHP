# level-2/maphper

> 标签: Object relational mapper, data mapper, dba, model, orm

## 简介

A lightweight ORM using the DataMapper pattern, creates database tables on the fly.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
