# einhasad/mpdf-light

> 标签: Simple, lightweight, ligth, minimal, mpdf, nofont, pdf, php, utf-8

## 简介

Lightweight mPDF fork without font subsetting

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
