# socket-manager/rest-api

> 标签: api-server, async, chunked-transfer, cross-platform, event-driven, http-message, ipc, multipart-upload, non-blocking, oauth2, php-framework, php-rest-api, psr-7, range-request, rest-api, restful-api, server-sent-events, socket-manager, sse, state-machine, streaming-api, web-api

## 简介

PHP製のREST-API/RESTful-APIサーバー開発環境。PSR-7準拠、ステートマシン対応、ChunkedやSSEなどの高度なAPI処理をサポート。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
