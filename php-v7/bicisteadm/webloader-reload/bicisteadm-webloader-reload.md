# bicisteadm/webloader-reload

> 标签: assets, css, javascript, nette, reload, webloader

## 简介

Tool for loading or deploying CSS and JS files into web pages

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
