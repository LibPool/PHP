# namet/socialite

> 标签: baidu, github, nameT, oauth2, oschina, qq, socialite, wechat, weibo

## 简介

a OAuth2 client package, with QQ|Wechat|Weibo|Github|Baidu|OSChina inside

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
