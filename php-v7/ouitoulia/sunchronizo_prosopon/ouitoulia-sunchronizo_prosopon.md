# ouitoulia/sunchronizo_prosopon

> 标签: PHP

## 简介

Sunchronìzo pròsopon è un modulo Drupal che importa i ruoli e dati di esempio delle scuole.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
