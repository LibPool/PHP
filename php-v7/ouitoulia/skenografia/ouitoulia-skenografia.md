# ouitoulia/skenografia

> 标签: PHP

## 简介

Skenografia è un sub-theme drupal, basato su bootstrap_italia, che implementa il design delle scuole.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
