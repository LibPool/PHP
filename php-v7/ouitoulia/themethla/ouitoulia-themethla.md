# ouitoulia/themethla

> 标签: PHP

## 简介

Thémethla è un modulo drupal che gestisce i tipi di contenuto dell'architettura dell'informazione delle scuole.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
