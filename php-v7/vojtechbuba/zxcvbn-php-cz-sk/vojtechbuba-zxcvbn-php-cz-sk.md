# vojtechbuba/zxcvbn-php-cz-sk

> 标签: password, zxcvbn

## 简介

Realistic password strength estimation PHP library based on Zxcvbn JS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
