# ciebit/js-acionador

> 标签: JS, acionador, alvo, ciebit

## 简介

Módulo que utiliza de um alvo e um acionador para efetuar ações diversas

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
