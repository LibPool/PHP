# ciebit/construtor

> 标签: construtor, css, html, javascript

## 简介

Ferramenta para montagem dinâmica de páginas HTML, mesclagem de arquivos CSS e JS

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
