# chr15k/laravel-blade

> 标签: blade, engine, laravel, templates

## 简介

Use the simple and yet powerful Laravel Blade templating engine as a standalone component.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
