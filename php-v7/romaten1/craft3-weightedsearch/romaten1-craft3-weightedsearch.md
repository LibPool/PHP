# romaten1/craft3-weightedsearch

> 标签: Craft, cms, craft-plugin, craft3, craftcms, weighted search

## 简介

A remake of the weighted search plugin for Craft 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
