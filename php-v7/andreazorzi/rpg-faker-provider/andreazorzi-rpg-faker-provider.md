# andreazorzi/rpg-faker-provider

> 标签: Andrea Zorzi, dnd, dnd-5e, dnd-character, dungeons-and-dragons, dungeons-and-dragons-5th-edition, faker, faker-php, php, rpg, rpg-character, rpg-character-generator, rpg-faker, rpg-faker-provider

## 简介

A PHP Faker provider that generates random RPG characters based on Dungeons & Dragons 5th Edition.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
