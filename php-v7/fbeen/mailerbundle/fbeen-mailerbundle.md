# fbeen/mailerbundle

> 标签: Swift Mailer

## 简介

This bundle is a tiny layer on top of the Swift Mailer Bundle that is included in each standard Symfony framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
