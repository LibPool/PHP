# ifsnop/martinez-rueda-php

> 标签: PHP

## 简介

Robust and tested library for boolean operations on polygons (union, intersection, difference, xor)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
