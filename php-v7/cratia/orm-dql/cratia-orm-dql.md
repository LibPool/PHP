# cratia/orm-dql

> 标签: PHP

## 简介

DQL stands for Dialect Query Language and is an Object Query, DQL provides powerful querying capabilities over your object model.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
