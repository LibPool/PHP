# oleglfed/laravel-ddd

> 标签: ddd, domain driven development, domains, laravel, package

## 简介

Generates domains for laravel Domain Driven Development

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
