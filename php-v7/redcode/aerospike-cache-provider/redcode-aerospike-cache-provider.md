# redcode/aerospike-cache-provider

> 标签: aerospike, cache, doctrine, provider

## 简介

Adds aerospike provider to use it through the doctrine/cache

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
