# backbee/toolbar-bundle

> 标签: No backend CMS, User management, bundle, cms, content management, core

## 简介

Toolbar bundle is the bridge between backbee/backbee-php and backbee/backbee-js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
