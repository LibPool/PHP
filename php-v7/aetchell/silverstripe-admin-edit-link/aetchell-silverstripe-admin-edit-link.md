# aetchell/silverstripe-admin-edit-link

> 标签: admin, silverstripe

## 简介

Adds a link to the edit page in the CMS if you are logged in as administrator

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
