# rjacobsen/eloquent-model-generator

> 标签: artisan, eloquent, laravel, model

## 简介

Auto-generates all Eloquent models from the database in a Laravel 5 project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
