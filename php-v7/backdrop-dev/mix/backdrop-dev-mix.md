# backdrop-dev/mix

> 标签: classicpress, wordpress

## 简介

Backdrop Mix is a helper class for ClassicPress or WordPress plugins themes and plugins using Laravel Mix.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
