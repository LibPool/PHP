# mucts/laravel-sobot

> 标签: PHP

## 简介

根据智齿智能客服系统提供了包含完整业务流程的开放平台接口（Open API），基于PHP开发的一套API插件。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
