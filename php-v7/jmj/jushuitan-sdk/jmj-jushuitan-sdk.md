# jmj/jushuitan-sdk

> 标签: jushuitan, sdk, 聚水潭

## 简介

Jushuitan ERP SDK,用于PHP对接聚水潭开放平台相关接口

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
