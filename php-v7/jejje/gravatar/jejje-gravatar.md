# jejje/gravatar

> 标签: PHP

## 简介

A very simple package to get a Gravatar image or Profile. Made for education purposes for http://jejje.net

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://jejje.net/php/laravel-5-gravatar-package/
- 源码仓库：https://github.com/jejje/gravatar.git
- Packagist 页面：https://packagist.org/packages/jejje%2Fgravatar
