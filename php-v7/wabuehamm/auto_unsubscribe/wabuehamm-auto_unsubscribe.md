# wabuehamm/auto_unsubscribe

> 标签: elgg, plugin

## 简介

Automatically unsubscribes all users from a discussion topic after the first notification.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
