# nilesh/laravel-smtp

> 标签: PHP

## 简介

this laravel package incorporate to end-user to create dynamic configuration of SMTP in existing project and allow sending mail through it.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
