# winify/dompdf-loadr

> 标签: alias, autoloader, classloader, composer

## 简介

Composer plugin which preloads dompdf constans by injecting them in composer autoload file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
