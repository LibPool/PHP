# winex01/backpack-permission-manager

> 标签: Backpack Addon, Backpack Permission Manager, Backpack for Laravel, backpack, laravel

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
