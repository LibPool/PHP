# pixney/hjortron-theme

> 标签: addon, cms, laravel, pixney, pyrocms, theme

## 简介

A Pyro LDP Administration theme created by Pixney.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
