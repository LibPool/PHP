# jedrzej/validator-extended-syntax

> 标签: laravel, validation

## 简介

Laravel 4/5 package that adds validator negation to Laravel's validation module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
