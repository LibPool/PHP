# lakuapik/php-helper-id

> 标签: fungsi php indonesia, php, php helper, php indonesia

## 简介

Kumpulan fungsi bantuan PHP yang digunakan secara umum di Indonesia.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
