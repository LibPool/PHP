# nimut/testing-framework

> 标签: TYPO3 CMS, phpunit, testing

## 简介

TYPO3 testing framework that provides base classes and configuration for PHPUnit tests

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
