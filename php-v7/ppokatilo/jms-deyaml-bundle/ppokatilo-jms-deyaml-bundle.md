# ppokatilo/jms-deyaml-bundle

> 标签: deserialization, jms, symfony, yaml

## 简介

Symfony bundle adding YAML deserialization to the JMS serializer bundle

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
