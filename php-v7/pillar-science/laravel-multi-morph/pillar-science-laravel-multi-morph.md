# pillar-science/laravel-multi-morph

> 标签: Relationships, laravel, morph, polymorphic, relations

## 简介

Allows to use multiple MorphBy relationships with same model

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
