# se468/laravel-mail-preview

> 标签: laravel, mail

## 简介

Extension to Laravel-Mail-Preview by Mohamed Said. Adds a 'preview' and 'local' mail driver for testing emails in laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
