# dhluther/yii-swivel

> 标签: Behavior, component, extension, helper, swivel, yii

## 简介

A Yii plugin to provide easy access and integration with zumba/swivel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
