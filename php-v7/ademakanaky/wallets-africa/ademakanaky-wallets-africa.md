# ademakanaky/wallets-africa

> 标签: api, open source, php, wallet, wallets africa

## 简介

PHP implementation of Wallets Africa (https://wallets.africa) API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
