# balpom/cookie

> 标签: RFC 6265, RFC6265, cookie, cookiejar, http, php, platine

## 简介

Based on Platine Cookie library (cookie management in accordance with the RFC 6265 specification).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
