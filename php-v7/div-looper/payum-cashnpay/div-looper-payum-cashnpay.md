# div-looper/payum-cashnpay

> 标签: CASHnPAY, fawry, payment

## 简介

Extension for Payum which add support for CASH'nPAY payment gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
