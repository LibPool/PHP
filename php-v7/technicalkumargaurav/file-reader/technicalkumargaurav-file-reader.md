# technicalkumargaurav/file-reader

> 标签: csv, excel, parser, pdf, php, reader

## 简介

A PHP application to read and process Excel, CSV, PDF files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
