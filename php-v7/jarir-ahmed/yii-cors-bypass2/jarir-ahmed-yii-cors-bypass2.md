# jarir-ahmed/yii-cors-bypass2

> 标签: PHP

## 简介

A package to replace the index.php file in a Yii application to bypass CORS policy for React and Vue.js

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
