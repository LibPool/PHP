# viz-blockchain/viz-php-lib

> 标签: VIZ, jsonrpc, php, transaction

## 简介

Native PHP class for VIZ Keys, Transaction, JsonRPC

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
