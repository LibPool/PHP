# techwilk/twig-slim-csrf

> 标签: csrf, extension, globals, key, twig, value

## 简介

TWIG extension to expose Slim CSRF values in templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
