# au/profileiconaccess

> 标签: AU, access, avatar, elgg, icon, plugin

## 简介

Users can set access on their profile icon, if another user doesn't have access they see the default image

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
