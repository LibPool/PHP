# au/comment_tracker

> 标签: AU, comment tracker, comments, elgg, plugin, subscriptions

## 简介

Manage notifications/subscriptions for comment threads

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
