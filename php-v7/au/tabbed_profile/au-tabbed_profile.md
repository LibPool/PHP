# au/tabbed_profile

> 标签: elgg, plugin, profile, tabbed profile

## 简介

Users/Groups can have multiple profile pages for different contexts/viewers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
