# au/mt_activity_tabs

> 标签: AU, activity, activity tabs, elgg, plugin

## 简介

Adds tabs to the activity page filtering activity to specific groups and collections

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
