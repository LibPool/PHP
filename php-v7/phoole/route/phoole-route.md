# phoole/route

> 标签: fast-route, library, middleware, phoole, php, psr-15, psr-7, route, swoole

## 简介

Slim, fast and full compatible PSR-7 & PSR-15 routing library for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
