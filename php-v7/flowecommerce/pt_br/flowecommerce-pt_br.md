# flowecommerce/pt_br

> 标签: PHP

## 简介

Magento2 - Language Pack para tradução ao Português do Brasil (pt_BR) - Brazilian Portuguese Language Pack

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
