# innoweb/silverstripe-fastly

> 标签: caching, cdn, fastly, silverstripe

## 简介

Integration of the Fastly CDN for Silverstripe CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
