# blitze/content

> 标签: PHP

## 简介

Create and manage content types for phpBB SiteMaker

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/blitze/phpBB-ext-sitemaker_content
- 源码仓库：https://github.com/blitze/phpBB-ext-sitemaker_content.git
- Packagist 页面：https://packagist.org/packages/blitze%2Fcontent

## 历史版本号

- 当前版本：3.0.0-RC4
