# ocramius/ocra-lorem-module

> 标签: ipsum, lorem, zf2

## 简介

Module that provides Lorem Generator utilities for ZendFramework 2 Applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
