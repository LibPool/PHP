# wykleph/html-scraper

> 标签: PHP

## 简介

An API for taking json sitemaps generated by the webscraper.io extension, and emulating webscraper.io's scraping behavior.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
