# imponeer/composer-nodejs-installer

> 标签: Node.js, frontend, javascript, node, nodejs, npm

## 简介

Installs specific nodejs version in vendor/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
