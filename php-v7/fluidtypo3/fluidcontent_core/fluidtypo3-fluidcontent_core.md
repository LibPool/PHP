# fluidtypo3/fluidcontent_core

> 标签: TYPO3 CMS, bootstrap, fedext, fluid, fluidcontent, flux, templating

## 简介

Replace css_styled_content with your own templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
