# ocubom/html-bundle

> 标签: compress, html, minify, symfony, symfony-bundle

## 简介

A Symfony bundle to integrate several custom utilities for HTML manipulation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
