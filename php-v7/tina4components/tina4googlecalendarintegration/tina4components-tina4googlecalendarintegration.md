# tina4components/tina4googlecalendarintegration

> 标签: PHP

## 简介

This is a package that will allow you to add Google Calendar functionality to any tin4 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
