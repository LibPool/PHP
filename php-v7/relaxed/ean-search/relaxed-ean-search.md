# relaxed/ean-search

> 标签: ASIN, ISBN, ISBN13, LCCN, barcode, ean, gtin, rest, upc, webservice

## 简介

A PHP class for EAN and ISBN name lookup and validation using the API on ean-search.org

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.ean-search.org/ean-database-api.html
- 源码仓库：https://github.com/eansearch/ean-search.git
- Packagist 页面：https://packagist.org/packages/relaxed%2Fean-search
