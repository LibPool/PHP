# eugenevdm/nova-text-card

> 标签: card, laravel, nova, text

## 简介

A fork of Eric Lagarda's custom card for Laravel Nova to show Text in cards with some good options

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
