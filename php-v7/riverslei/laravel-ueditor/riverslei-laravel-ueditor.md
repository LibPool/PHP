# riverslei/laravel-ueditor

> 标签: baidu ueditor, laravel-ueditor, laravel5, laravel5 富文本编辑器, qiniu, ueditor

## 简介

支持laravel5的UEditor，同时支持本地与七牛文件上传

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
