# tangniyuqi/yii2-simplemde

> 标签: SimpleMDE, editor, markdown, yii2

## 简介

The simplemde markdown editor widget for the Yii framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
