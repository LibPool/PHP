# vitalik74/yii2-smsimple

> 标签: sms, yii2, yii2 sms extension

## 简介

Отправка смс сообщений через сервис smsimple

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
