# glowgaia/gappy

> 标签: PHP

## 简介

Gappy - how I imagine "G API" is pronounced - is exactly that; an API for GaiaOnline. Rid yourself of repetitive boilerplate code and build your custom Gaia application today!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
