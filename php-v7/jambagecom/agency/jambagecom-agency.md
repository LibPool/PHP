# jambagecom/agency

> 标签: extension, frontend user, registration, typo3

## 简介

Agency Registration. - An improved variant of Kasper Skårhøj's Front End User Admin extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
