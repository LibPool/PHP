# iamtong/laravel-admin-login-check-safe

> 标签: extension, laravel-admin, login-check-safe

## 简介

登录添加验证码，后台用户锁定，错误次数过多锁定，密码强制修改，添加密码修改记录，登录日志

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
