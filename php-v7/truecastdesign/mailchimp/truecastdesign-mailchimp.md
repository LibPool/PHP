# truecastdesign/mailchimp

> 标签: api, list, mailchimp, mailing

## 简介

This library provides a simple MailChimp API v3 to signup people to a mailing list.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
