# besimple/wsdl2php

> 标签: soap, wsdl, wsdl2php

## 简介

BeSimple WSDL 2 PHP library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 获取地址

- Composer 安装：`composer require besimple/wsdl2php`
- Packagist 仓库：https://repo.packagist.org/p2/besimple/wsdl2php.json
- PHP 要求：>=5.3.0
