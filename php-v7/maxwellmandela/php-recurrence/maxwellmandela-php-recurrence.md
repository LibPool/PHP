# maxwellmandela/php-recurrence

> 标签: dates, events, recurrence, recurring, rrule

## 简介

PHP library for working with recurrence rules, uses simshaun/recurr

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
