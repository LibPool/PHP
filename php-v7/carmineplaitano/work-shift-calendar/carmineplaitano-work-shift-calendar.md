# carmineplaitano/work-shift-calendar

> 标签: Shift, calendar, module, vkurko, work, yii2

## 简介

Yii2 module to manage work shifts via vkurko calendar. Made for backend applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
