# smartpay-co/sdk-php

> 标签: smartpay

## 简介

The Smartpay PHP SDK offers easy access to Smartpay API from applications written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
