# ppm_fulfillment/magento-fulfillment

> 标签: fulfillment, magento, ppm

## 简介

Magento 2 plugin to interface with PPM Fulfillment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
