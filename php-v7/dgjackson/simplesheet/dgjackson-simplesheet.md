# dgjackson/simplesheet

> 标签: Craft, cms, craft-plugin, craftcms, simplesheet

## 简介

Provides an additional Spreadsheet Field Type for Craft CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
