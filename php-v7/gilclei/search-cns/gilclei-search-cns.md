# gilclei/search-cns

> 标签: CNS, cartao sus, client, consulta, datasus, php, sus, webservice

## 简介

Projeto de uma biblioteca para consultar dos dados do usuário SUS na base de dados do Datasus

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
