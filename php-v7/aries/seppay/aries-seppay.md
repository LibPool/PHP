# aries/seppay

> 标签: aries, gateway, laravel, pay, pay.ir, payment, payment-gateway, saman, saman-electronic-pardaz, sep

## 简介

A Laravel package for using to pay.ir payment gateways

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
