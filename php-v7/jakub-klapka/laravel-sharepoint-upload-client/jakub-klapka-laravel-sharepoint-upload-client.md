# jakub-klapka/laravel-sharepoint-upload-client

> 标签: microsoft, oauth, sharepoint, upload

## 简介

Simple library for file uploading to Microsoft Sharepoint site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
