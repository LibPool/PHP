# popphp/pop-bootstrap

> 标签: PHP

## 简介

A skeleton application for the Pop Web Application Framework, using Bootstrap Material Icons and Font Awesome frameworks.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
