# popphp/pop-file

> 标签: directory, directory traversing, file uploads, php, pop, pop php

## 简介

Pop File Component for Pop PHP Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
