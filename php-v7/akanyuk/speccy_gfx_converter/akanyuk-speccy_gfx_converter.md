# akanyuk/speccy_gfx_converter

> 标签: convertor

## 简介

Convert various formats of ZX Spectrum graphics into PNG or GIF file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
