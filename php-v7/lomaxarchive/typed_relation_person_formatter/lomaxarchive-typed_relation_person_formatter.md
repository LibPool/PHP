# lomaxarchive/typed_relation_person_formatter

> 标签: PHP

## 简介

Provides a custom formatter for typed_relation fields that modifies name and relator display.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
