# gohany/circuitbreaker-symfony-bundle

> 标签: PHP

## 简介

Symfony bundle wiring for Gohany/Circuitbreaker (PHP 7.4, Symfony 5.4+).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
