# cliffparnitzky/task-center

> 标签: Tasks, contao, task center

## 简介

Provides a task center which allows you to create tasks, assign them to other users and track their progress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
