# cliffparnitzky/tiny-mce-horizontal-ruler

> 标签: contao, horizontal ruler, tiny editor, tinymce, tinymce plugin, tinymce4

## 简介

Special TinyMCE plugin that adds a menu item and button which allows to insert a horizontal ruler.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
