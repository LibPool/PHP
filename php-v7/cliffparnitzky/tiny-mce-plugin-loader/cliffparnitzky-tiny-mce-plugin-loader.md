# cliffparnitzky/tiny-mce-plugin-loader

> 标签: contao, tiny editor, tinymce, tinymce plugin, tinymce5

## 简介

Special extension that will load additional TinyMCE plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
