# cliffparnitzky/backend-logs

> 标签: contao, log file

## 简介

Provides a special functionality to display error.log, email.log and other configured logfiles in Contao backend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
