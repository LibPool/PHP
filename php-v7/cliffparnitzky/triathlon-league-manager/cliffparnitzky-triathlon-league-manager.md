# cliffparnitzky/triathlon-league-manager

> 标签: contao, league, triathlon

## 简介

Managing triathlon league tables and teams for displaying it in frontend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
