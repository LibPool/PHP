# basilicom-pimcore-plugin/humans

> 标签: avatar, pimcore, plugin

## 简介

Pre-installed people avatars instead of robot defaults.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
