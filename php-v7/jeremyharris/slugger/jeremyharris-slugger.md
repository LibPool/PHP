# jeremyharris/slugger

> 标签: cakephp, plugin, seo, slug

## 简介

Slugger is a plugin for CakePHP that automatically generates slugs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
