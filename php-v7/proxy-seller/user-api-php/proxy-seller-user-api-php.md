# proxy-seller/user-api-php

> 标签: client-api, proxy, proxy-seller, residential-proxy, sdk

## 简介

PHP SDK for the Proxy-Seller Client API v2: orders, proxy lists and exports, balance and auto top-up, resident packages, subpackages and lists.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
