# turbo/php-ffmpeg

> 标签: audio, audio processing, avconv, avprobe, ffmpeg, ffprobe, video, video processing

## 简介

基于php-ffmpeg/php-ffmpeg，增加一些功能和支持m3u8，后续会继续更新支持

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
