# furic/leaderboards

> 标签: daily, highscore, leaderboard, leaderboards, monthly, ranking, score, weekly

## 简介

RESTful API serving the leaderboards and reporting the scores to your client app.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
