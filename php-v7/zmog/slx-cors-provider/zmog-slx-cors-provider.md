# zmog/slx-cors-provider

> 标签: cors, cross, origin, provider, resource, service, sharing, silex

## 简介

A silex service provider that adds CORS services to silex

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
