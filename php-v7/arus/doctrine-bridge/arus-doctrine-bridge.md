# arus/doctrine-bridge

> 标签: PHP7, arus, doctrine, fenric, php8

## 简介

Arus // Doctrine Bridge for PHP 7.2+ (incl. PHP 8) based on PHP-DI

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
