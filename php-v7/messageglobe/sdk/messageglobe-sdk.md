# messageglobe/sdk

> 标签: email, messageglobe, messaging, rest, sdk, sms, smtp

## 简介

Official MessageGlobe PHP SDK — send SMS via the REST API and email via SMTP. Framework- and CMS-agnostic.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
