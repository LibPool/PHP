# ionepub/lunar

> 标签: Chinese, calendar, lunar, lunar2solar, solar, solar2lunar, today

## 简介

农历公历转换，阳历转阴历，阴历转阳历，今天的阴历日期 A Chinese calendar transform class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
