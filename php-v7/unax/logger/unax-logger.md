# unax/logger

> 标签: PHP

## 简介

Logger with eight methods for writing logs to the eight RFC 5424 levels (debug, info, notice, warning, error, critical, alert, emergency).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
