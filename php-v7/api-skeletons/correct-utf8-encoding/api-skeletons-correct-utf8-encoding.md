# api-skeletons/correct-utf8-encoding

> 标签: PHP

## 简介

Correct badly encoded and multiple encoded UTF8 characters by examining each byte in a string.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
