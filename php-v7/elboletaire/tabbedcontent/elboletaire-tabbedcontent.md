# elboletaire/tabbedcontent

> 标签: PHP

## 简介

Lightweight JS tabs plugin with HTML 5 history API for jQuery or Zepto

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
