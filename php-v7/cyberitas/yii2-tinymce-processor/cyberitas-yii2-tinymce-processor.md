# cyberitas/yii2-tinymce-processor

> 标签: text, tinymce, wysiwyg, yii2

## 简介

Yii 2 extension providing WordPress-style text processing from a TinyMCE editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
