# ken/laravel-voyager-blog

> 标签: laravel, litepie, voyager

## 简介

Create a blog very easy with litepie Blog & laravel voyager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
