# datahihi1/tiny-env-encryptor

> 标签: PHP

## 简介

Encrytor helper for TinyEnv: A simple PHP library to manage environment variables in a secure way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
