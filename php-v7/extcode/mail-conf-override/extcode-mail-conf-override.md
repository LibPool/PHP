# extcode/mail-conf-override

> 标签: TYPO3 CMS, configuration, mail, override, smtp

## 简介

The extension allows different mail configurations for mail from addresses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
