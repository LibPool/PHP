# tanoconsulting/ezdbintegritybundle

> 标签: database, ezplatform

## 简介

Validates database data and binary file storage of eZPlatform 3 (aka Ibexa OSS/DXP)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
