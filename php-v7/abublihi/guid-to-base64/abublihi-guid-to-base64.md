# abublihi/guid-to-base64

> 标签: ObjectGUID, base64, guid, immutable id, immutableid, microsoft

## 简介

Convert microsoft ldap objectGuid to Base64.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
