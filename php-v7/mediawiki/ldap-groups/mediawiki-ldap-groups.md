# mediawiki/ldap-groups

> 标签: extension, groups, ldap, mediawiki, wiki

## 简介

Map group membership from a directory service to MediaWiki.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
