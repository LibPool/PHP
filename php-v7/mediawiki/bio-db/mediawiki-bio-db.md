# mediawiki/bio-db

> 标签: SMW, Semantic MediaWiki, database, mediawiki

## 简介

Retrieve information from an existing Biological Database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
