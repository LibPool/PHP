# mediawiki/mermaid

> 标签: mediawiki, mermaid, parser function

## 简介

Provides a parser function to generate diagrams and charts with the help of the mermaid script language

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
