# mediawiki/page-forms

> 标签: Forms, PF, Page Forms, Semantic Forms, mediawiki, wiki

## 简介

Forms for creating and editing wiki pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
