# mediawiki/validator

> 标签: ParamProcessor, SMW, Semantic MediaWiki, mediawiki, validator

## 简介

MediaWiki wrapper for the ParamProcessor library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
