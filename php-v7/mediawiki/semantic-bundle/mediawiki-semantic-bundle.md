# mediawiki/semantic-bundle

> 标签: Page Forms, Result format, Semantic Forms, Semantic MediaWiki, breadcrumb links, cite, compound queries, extra special properties, glossary, interlanguage links, knowledge management, lua, maps, mediawiki, mermaid, semantic meta tags, structured data, timeline, wiki

## 简介

Bundle extension that installs and loads Semantic MediaWiki and associated extensions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
