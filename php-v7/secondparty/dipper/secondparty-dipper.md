# secondparty/dipper

> 标签: parser, yaml

## 简介

A fast YAML parser that parses for the more commonly-used subset of YAML’s v1.0 and v1.2 specs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
