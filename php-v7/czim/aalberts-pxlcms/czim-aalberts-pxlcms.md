# czim/aalberts-pxlcms

> 标签: cms, database, eloquent, laravel

## 简介

Laravel adapter for the Aalberts PXL CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
