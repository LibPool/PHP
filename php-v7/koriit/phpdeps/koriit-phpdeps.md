# koriit/phpdeps

> 标签: circular-dependencies, dependencies, php

## 简介

Library for finding circular dependencies between modules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/Koriit/PHPDeps
- 源码仓库：https://github.com/Koriit/PHPDeps.git
- Packagist 页面：https://packagist.org/packages/koriit%2Fphpdeps

## 获取地址

- Composer 安装：`composer require koriit/phpdeps`
