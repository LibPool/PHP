# miranj/craft-sheets-to-tables

> 标签: Craft, craftcms, csv, excel, spreadsheet, table

## 简介

Adds a Twig function to convert Spreadsheets into HTML tables.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
