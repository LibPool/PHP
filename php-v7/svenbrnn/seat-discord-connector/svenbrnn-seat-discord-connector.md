# svenbrnn/seat-discord-connector

> 标签: PHP

## 简介

A SeAT plugin which maintain user access on a Discord Guild based on defined pattern.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
