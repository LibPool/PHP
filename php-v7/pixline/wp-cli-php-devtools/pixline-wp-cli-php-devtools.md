> 标签: development, phpcpd, phpcs, phpdcd, phploc, phpmd, phpreport, phpunit, wp-cli

## 简介

Wrapper around common development utilities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
