# bis-gmbh/polyfill-intl-idn

> 标签: compatibility, idn, intl, polyfill, portable, shim

## 简介

Symfony polyfill for intl's idn_to_ascii and idn_to_utf8 functions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
