# cecil/theme-leon

> 标签: cecil, docs, documentation, theme

## 简介

Cecil Léon theme: a documentation theme with a warm and editorial look

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
