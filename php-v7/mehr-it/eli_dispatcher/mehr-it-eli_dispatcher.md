# mehr-it/eli_dispatcher

> 标签: PHP

## 简介

Flexible and lightweight request dispatcher (and emitter) for PHP applications based on PSR-7 and PSR-15 standards

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
