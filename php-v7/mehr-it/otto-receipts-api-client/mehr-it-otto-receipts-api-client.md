# mehr-it/otto-receipts-api-client

> 标签: api, otto, php, receipts, sdk, swagger

## 简介

PHP client for Otto receipts API generated using Swagger

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
