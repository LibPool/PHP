# schachbulle/contao-playchess-bundle

> 标签: contao, playchess, registrierung, schach

## 简介

Nimmt Registrierungen für die Schachplattform Playchess auf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
