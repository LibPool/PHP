# schachbulle/contao-simplecolumns-bundle

> 标签: contao, inhaltselement, layout, spalten

## 简介

Inhaltselemente für einen mehrspaltigen Seitenaufbau, aufbauend auf der Contao-2-Fassung von Mario Müller.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
