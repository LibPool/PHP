# schachbulle/contao-wortliste-bundle

> 标签: begriffe, contao, glossar, wortliste

## 简介

Verwaltet eine Wortliste, etwa für Glossare oder Begriffserklärungen.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
