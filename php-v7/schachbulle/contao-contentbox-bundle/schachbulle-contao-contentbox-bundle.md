# schachbulle/contao-contentbox-bundle

> 标签: box, contao, inhaltselement, layout

## 简介

Inhaltselement, das andere Inhaltselemente in einer gestaltbaren Box zusammenfasst.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
