# schachbulle/contao-einstellungen-bundle

> 标签: Einstellungen, backend, contao, tl_settings

## 简介

Stellt Einstellungen im Backend wieder her, die Contao ab Version 4.7 nicht mehr anbietet.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
