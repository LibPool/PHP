# schachbulle/contao-chessresults-bundle

> 标签: chess-results, contao, schach, tabelle, turnier

## 简介

Inhaltselement, das Turniertabellen von chess-results.com in die eigene Seite einbindet.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
