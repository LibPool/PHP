# schachbulle/contao-synapsis-bundle

> 标签: community, contao, forum, synapsis

## 简介

Synapsis-Forum für Contao 4.13 und Contao 5. Die Software wurde mit Claude Code (Opus 4.8, Fable 5) programmiert.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
