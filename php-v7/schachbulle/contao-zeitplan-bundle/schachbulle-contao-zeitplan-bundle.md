# schachbulle/contao-zeitplan-bundle

> 标签: contao, schach, schedule, zeitplan

## 简介

Verwaltung und Frontend-Darstellung von bunten Zeitplan-Tabellen für Contao 4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
