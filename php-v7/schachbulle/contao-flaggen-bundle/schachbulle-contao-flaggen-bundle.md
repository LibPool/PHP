# schachbulle/contao-flaggen-bundle

> 标签: contao, flaggen, inserttag, iso, lander

## 简介

Stellt ein Inserttag bereit, das Flaggensymbole im Format 4:3 anhand des dreistelligen ISO-Ländercodes anzeigt.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
