# schachbulle/contao-counter-bundle

> 标签: Statistik, contao, zugriffe, zähler

## 简介

Zählt die Zugriffe auf Seiten, Artikel und Nachrichten, gibt die Zahlen im Frontend aus und wertet sie im Backend mit Diagrammen aus.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
