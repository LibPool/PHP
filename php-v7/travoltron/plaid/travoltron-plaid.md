# travoltron/plaid

> 标签: Travoltron, laravel, laravel5, plaid

## 简介

Laravel specific wrapper for Plaid. Bankdata for developers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
