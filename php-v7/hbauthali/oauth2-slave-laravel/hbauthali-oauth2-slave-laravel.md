# hbauthali/oauth2-slave-laravel

> 标签: api, laravel, lumen, oauth, oauth2, server

## 简介

An OAuth 2.0 bridge for Laravel and Lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
