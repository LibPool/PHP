# harmolipi/activecampaign-v3-api-wrapper-php

> 标签: PHP

## 简介

This is a PHP wrapper designed to consume the V3 ActiveCampaign API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
