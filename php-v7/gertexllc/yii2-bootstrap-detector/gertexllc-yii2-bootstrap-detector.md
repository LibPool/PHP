# gertexllc/yii2-bootstrap-detector

> 标签: bootstrap, detector, yii2

## 简介

A Yii2 component to detect the used Bootstrap version and return it.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
