# service-direct/php-partners-sdk

> 标签: api, partners, php, sdk, service direct

## 简介

A simple PHP library to integrate with Service Direct's Partners API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
