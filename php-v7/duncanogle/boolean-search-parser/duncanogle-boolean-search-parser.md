# duncanogle/boolean-search-parser

> 标签: boolean, fulltext, logic, mysql, search

## 简介

A way to translate Boolean Search logic into MySQL Fulltext Parameters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
