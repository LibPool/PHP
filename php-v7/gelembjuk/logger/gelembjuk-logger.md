# gelembjuk/logger

> 标签: PHP

## 简介

Allows to add logging functions to different classes, helps to handle errors, log errors and display error screen. Can catch warnings and fatal errors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
