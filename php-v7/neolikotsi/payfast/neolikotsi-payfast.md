# neolikotsi/payfast

> 标签: laravel, package, payfast

## 简介

Laravel 5.4+|6+|7+ package for processing ITN payments through payfast.co.za

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
