# chk/hideforguest

> 标签: PHP

## 简介

CHK HideForGuest Extension Hide's,  Price and Add To Cart of Magento2 Shop Guest Users

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
