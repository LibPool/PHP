# bluora/laravel-php-elixir-watch

> 标签: elixir, laravel, php, watch

## 简介

Provides the watch functionality to Laravel PHP-Elixir

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
