# ninty9notout/sitetreenav

> 标签: silverstripe, sitetreenav

## 简介

An extension which provides the functionality to add nested <code><ul></code> SiteTree menus into the template.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
