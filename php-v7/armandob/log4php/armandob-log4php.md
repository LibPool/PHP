# armandob/log4php

> 标签: log, logging, php

## 简介

A versatile logging framework for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://logging.apache.org/log4php/
- 源码仓库：https://github.com/armando-basile/logging-log4php.git
- Packagist 页面：https://packagist.org/packages/armandob%2Flog4php
