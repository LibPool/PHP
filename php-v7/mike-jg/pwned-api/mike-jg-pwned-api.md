# mike-jg/pwned-api

> 标签: password, security, web service

## 简介

PwnedApi is a PHP library to work with the API at https://haveibeenpwned.com/API/v2/

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
