# sobyte/qcloud-image

> 标签: QcloudImage, sdk, tentcent

## 简介

腾讯云 万象优图（Cloud Image） SDK for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
