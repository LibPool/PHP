# zetta-code/zend-skeleton-application

> 标签: framework, mvc, zf

## 简介

Skeleton Application for Zend Framework zend-mvc applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
