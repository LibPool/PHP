# gussi121/tesseract_ocr

> 标签: OCR, Tesseract, text recognition

## 简介

A wrapper to work with Tesseract OCR inside PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
