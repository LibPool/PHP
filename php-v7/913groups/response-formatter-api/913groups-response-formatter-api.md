# 913groups/response-formatter-api

> 标签: PHP

## 简介

Un utilitaire PHP léger pour le Framework Slim permettant de standardiser les réponses API au format JSON et XML.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
