# mage2pro/etsy

> 标签: Handmade, Vintage, ecommerce, etsy, integration, magento, magento 2, magento extension, marketplace

## 简介

The «Etsy» extension for Magento 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
