# mage2pro/flag

> 标签: Country flag, ecommerce, magento, magento 2, magento extension

## 简介

A Magento 2 interface to the lipis/flag-icon-css library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
