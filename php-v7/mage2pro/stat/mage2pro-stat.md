# mage2pro/stat

> 标签: magento 2

## 简介

The module fixes the «Cannot gather stats» error on clearing the static files cache via the Magento 2 backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
