# mage2pro/facebook-login

> 标签: Authentication, Facebook login, ecommerce, facebook, facebook api, magento, magento 2, magento extension, oauth2, single sign-on

## 简介

The «Facebook Login» extension for Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
