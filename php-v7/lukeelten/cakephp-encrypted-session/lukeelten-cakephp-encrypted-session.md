# lukeelten/cakephp-encrypted-session

> 标签: cakephp, encryption, session

## 简介

Encrypted Session Middleware which encrypts the session on server-side with a per-user key.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
