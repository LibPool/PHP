# pavel-paliy/php-graphql-client

> 标签: builder, client, graph-ql, graphql, php, query, query-builder

## 简介

GraphQL client and query builder (fork of gmostafa/php-graphql-client, because this library outdated).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
