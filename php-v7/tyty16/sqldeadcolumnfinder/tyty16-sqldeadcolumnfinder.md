# tyty16/sqldeadcolumnfinder

> 标签: columns, dead, finder, mysql, null, pdo, sql, unique

## 简介

Finds columns that are null or only have one unique value

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
