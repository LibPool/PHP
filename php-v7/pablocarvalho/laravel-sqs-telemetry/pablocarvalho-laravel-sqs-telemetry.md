# pablocarvalho/laravel-sqs-telemetry

> 标签: PHP

## 简介

A Laravel SDK for sending exception and request telemetry to AWS SQS asynchronously with batching and memory buffer.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
