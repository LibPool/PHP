# lysak/yii2-sypexgeo

> 标签: extension, geo, module, sypexgeo, yii2

## 简介

Yii2 extension for Sypex Geo API (http://sypexgeo.net)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
