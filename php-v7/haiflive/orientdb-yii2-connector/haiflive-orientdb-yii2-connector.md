# haiflive/orientdb-yii2-connector

> 标签: PHP

## 简介

Yii2 connector to orientDB, php7, query builder, command builder, ActiveRecord relations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
