# heyday/laravel-anonymised-sql-dumps

> 标签: gdpr, heyday, laravel-anonymised-sql-dumps

## 简介

Generate anonymised SQL dumps for Laravel. Wrapper for ifsnop/mysqldump-php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
