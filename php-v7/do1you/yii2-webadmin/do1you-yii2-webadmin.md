# do1you/yii2-webadmin

> 标签: admin, extension, webadmin, yii2

## 简介

基于YII2.0框架的整合的后台管理界面，实现了权限、配置、日志等基础功能。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
