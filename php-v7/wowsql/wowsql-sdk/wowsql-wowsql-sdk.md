# wowsql/wowsql-sdk

> 标签: PHP

## 简介

Official PHP client library for WOWSQL - PostgreSQL Backend-as-a-Service with S3 Storage

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
