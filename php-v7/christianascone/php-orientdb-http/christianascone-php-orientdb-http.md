# christianascone/php-orientdb-http

> 标签: orientdb

## 简介

A set of PHP libraries in order to use OrientDB from PHP with HTTP Protocol.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
