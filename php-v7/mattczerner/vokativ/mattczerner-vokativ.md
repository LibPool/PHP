# mattczerner/vokativ

> 标签: PHP

## 简介

Fork knihovny bigit/vokativ upravený pro PHP verzi 8. Knihovna pro skloňování českých jmen do 5. pádu pro účely generování oslovení.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
