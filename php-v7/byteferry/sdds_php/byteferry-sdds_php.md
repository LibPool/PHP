# byteferry/sdds_php

> 标签: Sdds, Socket, binary stream, byte array, byte buffer, byte stream, network binary stream, php7.1, stream, stream buffer

## 简介

A PHP library to work with stream decode and encode according to the SDDS Specification.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
