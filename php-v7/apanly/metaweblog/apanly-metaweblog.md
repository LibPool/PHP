# apanly/metaweblog

> 标签: 51cto, cnblogs, csdn, metaweblog, oschina, sina, 同步博文

## 简介

通过MetaWeblog协议同时管理51cto,csdn,sina,163,oschina,cnblogs等博客

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
