# aalfiann/parallel-request-php

> 标签: async, curl, non-blocking, parallel, request

## 简介

A PHP class to create multiple request in parallel (non-blocking).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
