# aalfiann/img-spoof

> 标签: image, image-spoof, referer-image, referer-spoof, spoof

## 简介

This is a very simple and fast to get an image with spoofing referer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
