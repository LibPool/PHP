# dekodeinteraktiv/dekode-label-environment

> 标签: PHP

## 简介

Adds a banner to the frontend and an item to the admin bar informing about the server environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
