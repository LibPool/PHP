# phpdocumentor/template-new-black

> 标签: documentation, phpdoc, template

## 简介

Web 2.0 template with dark sidebar for phpDocumentor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
