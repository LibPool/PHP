# phpdocumentor/template-zend

> 标签: ZendFramework, documentation, phpdoc, template, zend, zf

## 简介

Official Zend Framework Template for phpDocumentor2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
