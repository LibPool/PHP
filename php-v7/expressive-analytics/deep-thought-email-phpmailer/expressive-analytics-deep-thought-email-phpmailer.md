# expressive-analytics/deep-thought-email-phpmailer

> 标签: deep thought, http

## 简介

Deep Thought module for sending email via PHP Mailer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
