# mrcnpdlk/blox

> 标签: annotation, block, comment, docblock, documentation, parser, phpDocumentor, phpdoc, tag

## 简介

A parser for block comment documentation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
