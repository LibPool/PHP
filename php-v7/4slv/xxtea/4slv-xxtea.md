# 4slv/xxtea

> 标签: crypt, cryptography, decrypt, encrypt, library, security, xxtea

## 简介

XXTEA is a fast and secure encryption algorithm. This is a XXTEA library for PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
