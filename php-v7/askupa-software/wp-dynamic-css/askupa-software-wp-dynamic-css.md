# askupa-software/wp-dynamic-css

> 标签: dynamic css, dynamic style, plugin, wordpress

## 简介

Render CSS using dynamic data from WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
