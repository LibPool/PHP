# dengtao/dingtalk

> 标签: dingding, dingtalk, easydingtalk, sdk, 钉钉

## 简介

EasyDingTalk, Alibaba Dingtalk SDK for PHP(基于EasyDingTalk修改，仅部分功能可用)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
