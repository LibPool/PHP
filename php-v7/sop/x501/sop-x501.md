# sop/x501

> 标签: attribute, dn, ldap, rdn, x.501, x.520, x501, x520

## 简介

A PHP library for X.501 ASN.1 types, X.520 attributes and DN parsing.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
