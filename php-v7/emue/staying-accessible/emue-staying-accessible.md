# emue/staying-accessible

> 标签: PHP

## 简介

A very basic Kirby CMS plugin to help website contributors maintain good accessibility practices when editing content.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
