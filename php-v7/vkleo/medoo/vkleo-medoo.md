# vkleo/medoo

> 标签: PHP

## 简介

vkleo/medoo 是一个 Webman 插件，提供了一个流畅的查询构建器接口来操作 Medoo ORM。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
