# jach/json-schema-middleware

> 标签: json, schema, slim, validation

## 简介

PSR-7 Middleware for Slim 3 the enables validation of JSON posted to en endpoint

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
