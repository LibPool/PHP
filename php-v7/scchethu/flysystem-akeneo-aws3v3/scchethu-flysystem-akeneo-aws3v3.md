# scchethu/flysystem-akeneo-aws3v3

> 标签: PHP

## 简介

Flysystem adapter for the Akeneo AWS S3/DO SDK v3.x Connector

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
