# phpnomad/core

> 标签: PHP

## 简介

The central PHPNomad orchestration package — bundles essential dependencies for building platform-agnostic PHP applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
