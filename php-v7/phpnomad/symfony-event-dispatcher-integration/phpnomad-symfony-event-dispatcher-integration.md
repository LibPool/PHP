# phpnomad/symfony-event-dispatcher-integration

> 标签: PHP

## 简介

Integrates PHPNomad's event architecture with Symfony's event dispatcher.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
