# squille/core

> 标签: framework, php

## 简介

Core is a PHP micro-framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://core.squille.org/
- 源码仓库：https://github.com/jairhumberto/Core.git
- Packagist 页面：https://packagist.org/packages/squille%2Fcore
