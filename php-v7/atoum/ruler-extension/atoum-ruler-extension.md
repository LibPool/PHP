# atoum/ruler-extension

> 标签: TDD, atoum, atoum-extension, ruler, test, unit testing

## 简介

The atoum ruler-extension allows you to filter your tests using Hoa\Ruler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
