# atoum/praspel-extension

> 标签: assertion, atoum, checker, contract, data, generation, library, praspel, specification, test

## 简介

Include Praspel inside atoum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
