# atoum/apiblueprint-extension

> 标签: apiblueprint, atoum, atoum-extension, test

## 简介

Compile and run tests written in the API Blueprint format (`.apib`) with atoum

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
