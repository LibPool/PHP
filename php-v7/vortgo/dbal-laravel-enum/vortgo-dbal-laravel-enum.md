# vortgo/dbal-laravel-enum

> 标签: database, dbal, enum, laravel, persistence, queryobject

## 简介

DBAL package for laravel migrations. Added field type - enum

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
