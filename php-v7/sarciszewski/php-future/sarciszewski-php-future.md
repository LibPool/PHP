# sarciszewski/php-future

> 标签: compatibility, future, hash_equals, security

## 简介

Polyfill new (5.6+) features into old (5.4+) versions of PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
