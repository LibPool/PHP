# simplicity-ag/bjy-profiler

> 标签: db, profiler, zdt, zf2

## 简介

Database profiler for Zend\Db (also plugin for ZendDeveloperTools)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
