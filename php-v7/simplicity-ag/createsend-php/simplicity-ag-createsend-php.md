# simplicity-ag/createsend-php

> 标签: api, campaign, monitor

## 简介

A php library which implements the complete functionality of the Campaign Monitor API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
