# mihaiz/deck

> 标签: card, deck, hearthstone, magic the gathering, mtg

## 简介

Library to describe decks for deck-building games such as Magic the Gathering or Hearthstone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
