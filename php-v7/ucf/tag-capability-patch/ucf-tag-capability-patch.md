# ucf/tag-capability-patch

> 标签: PHP

## 简介

Ensures tag-like terms cannot be created without the user having the appropriate manage_terms capability.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
