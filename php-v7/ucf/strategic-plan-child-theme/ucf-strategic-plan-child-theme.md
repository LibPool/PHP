# ucf/strategic-plan-child-theme

> 标签: PHP

## 简介

Child theme for UCF's Strategic Plan website.  Built as a child theme of the UCF WordPress Theme, using the Athena Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
