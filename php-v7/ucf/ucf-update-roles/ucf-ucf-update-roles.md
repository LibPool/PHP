# ucf/ucf-update-roles

> 标签: PHP

## 简介

Updates the administrator and editors roles on a multisite to allow the 'unfiltered_html' capability.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
