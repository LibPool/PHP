# ucf/ucf-pegasus-list-shortcode

> 标签: PHP

## 简介

Provides a shortcode for displaying the latest issues of Pegasus, UCF's official alumni magazine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
