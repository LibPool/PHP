# ucf/ucf-video-vtt

> 标签: PHP

## 简介

Plugin that provides a series of tools for developers to properly enqueue descriptive text tracks for videos (vtt files) for their videos.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
