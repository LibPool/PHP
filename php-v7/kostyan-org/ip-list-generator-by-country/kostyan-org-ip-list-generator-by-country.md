# kostyan-org/ip-list-generator-by-country

> 标签: IP, block, cli, filter, qbittorrent, utility

## 简介

CLI utility that generates a block list file for the qBittorrent program by IP addresses

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
