# bukashk0zzz/booleantype-bundle

> 标签: bool, boolean, bundle, form, symfony, type

## 简介

A simple Symfony bundle that adds boolean form field type.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
