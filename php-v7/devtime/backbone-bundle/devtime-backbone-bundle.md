# devtime/backbone-bundle

> 标签: Symfony2, backbone, backbone.js, underscore

## 简介

Easily setup and use backbone.js with Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
