# codename/rest

> 标签: api, codename, core, endpoint, framework, rest

## 简介

This library supplies the core parts for constructing an API-only endpoint-calling-style app

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
