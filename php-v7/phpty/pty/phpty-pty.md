# phpty/pty

> 标签: ffi, openpty, process, pseudo-terminal, pty

## 简介

Create pseudo-terminal pairs and start child processes on them, through FFI.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
