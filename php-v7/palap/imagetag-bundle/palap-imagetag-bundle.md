# palap/imagetag-bundle

> 标签: image, image comment, image tag, tag

## 简介

Symfony2 image tag. Add colored tags with label to your image on symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
