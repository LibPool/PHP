# hmlb/phpunit-vw

> 标签: continuous integration, extension, hmlb, phpunit, quality, scandal, vw

## 简介

VW PhpUnit makes your failing tests pass CI tools scrutiny!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
