# route2api/route2api

> 标签: Postman, api-documentation, markdown, openapi, thinkphp

## 简介

Generate OpenAPI and Markdown API documents from ThinkPHP routes and controllers.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
