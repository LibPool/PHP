# anessoft/yii2-apidoc

> 标签: anessoft, yii2, yii2-apidoc

## 简介

用于自动载入接口文档及提供接口调试

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
