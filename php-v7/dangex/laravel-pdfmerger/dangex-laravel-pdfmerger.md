# dangex/laravel-pdfmerger

> 标签: laravel, merger, pdf, pdfmerger, webklex

## 简介

Generic PDF merger for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
