# mysteryinfosolutions/yourbulksms

> 标签: PHP

## 简介

A framework-agnostic PHP SDK for YourBulkSMS gateway with optional Laravel support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
