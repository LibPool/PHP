# michaelesmith/dyndns-processor-digitalocean

> 标签: PHP

## 简介

a processor for the dyndns-kit framework to use Digital Ocean's API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
