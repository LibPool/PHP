# stomaskov/browsershot

> 标签: chrome, convert, headless, image, pdf, puppeteer, screenshot, webpage

## 简介

Convert a webpage to an image or pdf using headless Chrome

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
