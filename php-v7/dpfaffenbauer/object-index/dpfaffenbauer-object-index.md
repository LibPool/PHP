# dpfaffenbauer/object-index

> 标签: pimcore, pimcore-plugin

## 简介

ObjectIndex lets you create Indexes and Filters of Objects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
