# singh/simplesaml

> 标签: SAML2, SSO, laravel, okta, single sign-on

## 简介

This package provides a wrapper to onelogin/php-saml library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
