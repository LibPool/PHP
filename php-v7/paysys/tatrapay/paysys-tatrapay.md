# paysys/tatrapay

> 标签: Bank, gateway, tatrabank, tatrapay

## 简介

Library for Tatra bank TatraPay gateway in Nette framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/PaySys/TatraPay
- 源码仓库：https://github.com/PaySys/TatraPay.git
- Packagist 页面：https://packagist.org/packages/paysys%2Ftatrapay
