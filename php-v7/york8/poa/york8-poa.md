# york8/poa

> 标签: framework, generator, koa, middleware, react-php

## 简介

POA Web框架灵感来自于Node.js的KOA框架，基于React-PHP，使用生成器来实现中间件，轻松的组合管理多个中间件之间的协作

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
