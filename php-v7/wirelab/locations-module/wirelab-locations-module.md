# wirelab/locations-module

> 标签: Locations module, locations, pyrocms, pyrocms 3, wirelab

## 简介

Locations module for PyroCMS 3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
