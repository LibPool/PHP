# wirelab/shares-plugin

> 标签: plugin, pyrocms, pyrocms 3, shares, wirelab

## 简介

Plugin which provides users with a quick way of adding customizable share links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
