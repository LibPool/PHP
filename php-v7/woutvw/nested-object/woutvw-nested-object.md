# woutvw/nested-object

> 标签: PHP

## 简介

A PHP class that allows creating nested objects with the flexibility of JSON but the advantages of PHP classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
