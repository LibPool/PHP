# teaminmedias-pluswerk/ke_search_hooks

> 标签: PHP

## 简介

Hooks example for ke_search. Feel free to use this as a kickstarter for your own custom indexer or hooks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
