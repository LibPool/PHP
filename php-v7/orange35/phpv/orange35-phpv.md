# orange35/phpv

> 标签: PHP

## 简介

PHP Wrapper to run a correct PHP CLI version specified in the .htaccess_dev, .htaccess or .phpv file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
