# ifacesoft/ice

> 标签: database, framework, http, ice, iceframework, ifacesoft, mysql, orm, web

## 简介

Ice Open Source PHP Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
