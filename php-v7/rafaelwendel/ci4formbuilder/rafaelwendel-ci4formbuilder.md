# rafaelwendel/ci4formbuilder

> 标签: builder, codeigniter4, form, php

## 简介

Library to build and manage forms in a CodeIgniter 4 projects (Object-Oriented way).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
