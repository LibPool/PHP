# fabiooak/yii2-log-json

> 标签: PHP

## 简介

Extends the file logging changing the output to JSON format. It's a useful extension to integrate with FileBeat and ELK stack.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
