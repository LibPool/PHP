# waldhacker/hcaptcha

> 标签: PHP

## 简介

TYPO3 Extension to add hCaptcha to EXT:form - The privacy friendly captcha alternative.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
