# consulmedics/imap-access

> 标签: consulmedics, edwink, imap, mailbox-access

## 简介

Access certain folders in an IMAP mailbox. Developed for specific needs in Consulmedics.*

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
