# luism-s/multilingualslim

> 标签: i18n, l10n, multilanguage, multilingual, slim

## 简介

Multilanguage support for Slim micro-framework 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
