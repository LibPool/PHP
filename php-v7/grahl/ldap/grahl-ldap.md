# grahl/ldap

> 标签: active directory, ldap

## 简介

An abstraction in front of PHP's LDAP functions, compatible with PHP 5.3.9 onwards.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
