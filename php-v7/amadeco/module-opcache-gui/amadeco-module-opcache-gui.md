# amadeco/module-opcache-gui

> 标签: PHP

## 简介

Magento 2 OPcache Control GUI with React-based interface - Performance monitoring and optimization dashboard for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
