# albertcht/appengine-php-sdk

> 标签: appengine, google, sdk

## 简介

Google App Engine PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://cloud.google.com/appengine/docs/php/
- 源码仓库：https://github.com/albertcht/appengine-php-sdk.git
