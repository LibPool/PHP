# luilliarcec/laravel-ecuador-locations

> 标签: ecuador, laravel, locations

## 简介

Set of provinces, cantons and parishes or cities of Ecuador.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
