# hexters/ladmin

> 标签: Admin scaffolding, admin page, ladmin, laravel, laravel admin

## 简介

Admin page scaffolding for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
