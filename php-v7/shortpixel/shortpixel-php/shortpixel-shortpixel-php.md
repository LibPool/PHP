# shortpixel/shortpixel-php

> 标签: api, compress, images, optimize, shortpixel

## 简介

ShortPixel PHP SDK. Read more at https://shortpixel.com/api-tools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
