# atk4/behat-mink-selenium2-driver

> 标签: ajax, browser, javascript, selenium, testing, webdriver

## 简介

Selenium2 (WebDriver) driver for Mink framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
