# homlity/sdk-smarthome

> 标签: colombia, crm, homlity, inmobiliaria, leads, php, real-estate, sdk, smart-inmobiliario

## 简介

SDK oficial de PHP de Homlity para consultar inventario inmobiliario (inmuebles, ubicaciones y tipos) y registrar leads en el CRM.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
