# dealerdirect/qa-tools

> 标签: code quality, php, qa, quality, stylecheck, unittest

## 简介

Meta package for installing all PHP QA tools you'll ever need

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
