# fraserpage/no-cry-cli

> 标签: cli, plugins, wordpress, wp-cli

## 简介

No-cry: A CLI tool that makes updating Wordpress plugins and WP Core (hopefully) not want to make you cry.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
