# forme/wp-rest-api-psr7

> 标签: psr-7, wordpress, wp rest api

## 简介

Provides PSR-7 and WP REST API Response and Request classes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
