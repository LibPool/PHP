# picophp/picophp

> 标签: PHP

## 简介

PicoPHP - Lightweight PHP framework heavily inspired by Laravel but not 0.01% as good. Whatever...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
