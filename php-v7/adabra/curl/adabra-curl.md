# adabra/curl

> 标签: asynchronous, bot, crawler, curl, http, multi, request, spider

## 简介

A simple and lightweight cURL library with support for asynchronous requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
