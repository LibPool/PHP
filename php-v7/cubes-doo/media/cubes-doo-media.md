# cubes-doo/media

> 标签: composer, vimeo php, vimeo-php, youtube php, youtube-api

## 简介

Media library for interaction with Youtube and Vimeo web media Api's.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
