# siipoland/infobip-api-php-client

> 标签: 2fa, Infobip, api, msisdn, openapi, php, rest, sdk, sms, tfa, whatsapp

## 简介

PHP library for consuming Infobip's API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
