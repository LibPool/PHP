# wtyd/githooks

> 标签: cli, commit, console, git, githooks, hooks, pre-commit, precommit, qa

## 简介

Manage git hooks in a simple and sophisticated way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
