# yohn/picocss

> 标签: CSS-Framework, css, dark-mode, dark-theme, lightweight, minimal, minimalist, minimalistic, native-html, scss-framework, semantic

## 简介

Minimal CSS Framework for semantic HTML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
