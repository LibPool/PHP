# syan/active-record

> 标签: Active Record, Simple, database, lite, micro, orm, pdo, relation

## 简介

Micro Active Record library in PHP, support chain calls, events, and relations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
