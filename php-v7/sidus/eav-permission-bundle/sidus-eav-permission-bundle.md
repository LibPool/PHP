# sidus/eav-permission-bundle

> 标签: eav, permissions, roles

## 简介

Integrates attribute-level permissions based on roles for the Sidus/EAVModelBundle

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
