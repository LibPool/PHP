# sunjiaqiang/codeigniter-integration

> 标签: PHP

## 简介

基于CI框架3.1.9的hmvc模式整合的一些插件和常用功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
