# tanwencn/supervisor

> 标签: file-content-fromat, file-parsing-viewer, laravel, log-viewer

## 简介

方便的输出日志文件、自定义文本、DB表等，你想监控的行为记录。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
