# honzito/bacon-qr-code-basis

> 标签: PHP

## 简介

QR Code Generator for PHP - BaconQrCode cleaned to basic QRCode generator library with minimum requirements.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
