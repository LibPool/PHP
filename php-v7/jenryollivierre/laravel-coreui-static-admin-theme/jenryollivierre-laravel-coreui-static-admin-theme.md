# jenryollivierre/laravel-coreui-static-admin-theme

> 标签: PHP

## 简介

A laravel admin theme made from the coreui static theme for bootstrap 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
