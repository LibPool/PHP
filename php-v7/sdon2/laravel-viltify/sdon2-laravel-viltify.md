# sdon2/laravel-viltify

> 标签: PHP

## 简介

A starter kit that integrates Laravel with Vue CLI, Inertia.js, TailwindCSS and Vuetify

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
