# goncziakos/tiny-task-manager

> 标签: issue manager, project manager, symfony, task, task manager

## 简介

Tiny Tasks Manager is a simple project, bug, task, issue and etc. management application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
