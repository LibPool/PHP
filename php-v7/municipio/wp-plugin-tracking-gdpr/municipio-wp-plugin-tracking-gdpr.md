# municipio/wp-plugin-tracking-gdpr

> 标签: PHP

## 简介

WordPress plugin that adds more GDPR and tracking features to Municipio

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
