# municipio/content-insights-for-editors

> 标签: analytics, broken links, content insights, editors, matomo

## 简介

Content Insights for Editors is a WordPress plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
