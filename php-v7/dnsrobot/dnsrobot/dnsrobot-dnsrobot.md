# dnsrobot/dnsrobot

> 标签: api, dkim, dmarc, dns, lookup, network, spf, ssl, whois

## 简介

PHP client for the DNS Robot API — DNS lookups, WHOIS, SSL checks, SPF/DKIM/DMARC validation, and more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
