# sprintcube/cakephp-rest

> 标签: CakePHP Rest, CakePHP Rest Api, REST API, api, cakephp, rest

## 简介

Rest API plugin for CakePHP 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
