# alcaeus/mongodb-gridfs-wrapper

> 标签: GridFS, database, mongodb

## 简介

PHP stream wrapper for GridFS files in MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
