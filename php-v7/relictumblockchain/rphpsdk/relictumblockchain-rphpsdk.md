# relictumblockchain/rphpsdk

> 标签: relictum, relictum-php, relictum-sdk, relictumblockchain

## 简介

A library for PHP that interacts with the relictum blockchain API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
