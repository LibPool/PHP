# innova/angular-ui-translation-bundle

> 标签: Symfony2, angular, translation

## 简介

Provides a new Angular JS filter which can access to Symfony 2 translations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
