# innova/angular-ui-resource-picker-bundle

> 标签: Claroline, Symfony2, angular, picker, resource

## 简介

Integrate Claroline resource picker into Angular JS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
