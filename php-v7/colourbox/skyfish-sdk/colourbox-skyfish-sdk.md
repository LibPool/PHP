# colourbox/skyfish-sdk

> 标签: sdk, skyfish

## 简介

Package that simplifies interacting with the Skyfish API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://www.skyfish.com
- 源码仓库：https://github.com/ColourboxDevelopment/SDK-PHP-Skyfish.git
