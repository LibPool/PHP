# vantiv/cnp-payments-sdk

> 标签: CNP, ecommerce, payments, sdk, vantiv

## 简介

The Vantiv eCommerce PHP SDK is a PHP implementation of the [Vantiv eCommerce](https://docs.worldpay.com/apis/cnpapi). XML API. This SDK was created to make it as easy as possible to connect process your payments with Vantiv eCommerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
