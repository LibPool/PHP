# nilportugues/haljson

> 标签: api, hal, json, psr7, response, serializer, transformer

## 简介

HAL+JSON & HAL+XML API transformer outputting valid API responses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
