# nilportugues/jsend

> 标签: api, jsend, json, psr7, response, serializer, transformer

## 简介

JSend API transformer outputting valid API responses.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
