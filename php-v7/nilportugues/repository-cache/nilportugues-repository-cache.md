# nilportugues/repository-cache

> 标签: adapters, cache, ddd, hexagonal, nil portugues, nilportugues, pageable, pagination, ports, ports and adapters, repository

## 简介

Implementation of a base repository with cache layer using StashPHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
