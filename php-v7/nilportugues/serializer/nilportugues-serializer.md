# nilportugues/serializer

> 标签: json, serialize, serializer

## 简介

Serialize PHP variables, including objects, in any format. Support to unserialize it too.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
