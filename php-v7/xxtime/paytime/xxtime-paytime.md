# xxtime/paytime

> 标签: payment, 支付

## 简介

移动支付SDK,Apple Pay,Google Pay,Alipay,Paypal,mycard,mol,paymentwall

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
