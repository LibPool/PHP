# thaiphan/magento-s3

> 标签: amazon, aws, magento, s3

## 简介

Use Amazon S3 as the file storage backend for your Magento store.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
