# lucbu/angkor-cms

> 标签: add-ons, cms, laravel, multilingual, theme

## 简介

A CMS made with Laravel 5. Multilingual, Multi-themes, Add-ons...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
