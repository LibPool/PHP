# edno/codeception-gherkin-param

> 标签: BDD, codeception, extension, gherkin, module, test

## 简介

Codeception module for supporting parameter notation in Gherkin features

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
