# taktwerk/tw-yii2-rest

> 标签: api, rest, restful, yii2

## 简介

The enhanced restful api for Yii Framework 2.0 based on HarryZheng0907's yii2-rest

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
