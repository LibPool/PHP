# tedivm/stash-bundle

> 标签: apc, cache, caching, memcached, redis, sessions, stash, symfony

## 简介

Incorporates the Stash caching library into Symfony.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
