# zakirullin/csrf-middleware

> 标签: csrf, http, middleware, psr-15, psr-7, server, token

## 简介

PSR-15 middleware to handle CSRF-token verification

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
