# fschwaiger/laravel-ldap

> 标签: laravel, ldap

## 简介

Simple LDAP integration for Laravel 5. Comes with file based ACL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
