# misterxin/simple-page

> 标签: PHP

## 简介

mister.xin单页应用，方便个人博客简介，企业简介页面，产品简介页面

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 官网：https://mister.xin/
- 源码仓库：https://github.com/zandiy/simple-page.git
