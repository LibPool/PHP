# yiiexttbq/adminlte

> 标签: PHP

## 简介

对dmstr/yii2-adminlte-asset的扩展, 并与mdmsoft/yii2-admin结合

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
