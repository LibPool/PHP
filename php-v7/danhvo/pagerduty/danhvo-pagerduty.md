# danhvo/pagerduty

> 标签: PagerDuty, alerting, laravel, laravel-package, notification-channel, notifications

## 简介

A Laravel notification channel for sending PagerDuty events.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
