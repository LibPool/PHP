# simplecomplex/time

> 标签: datetime, php, time, utils

## 简介

Time extends native DateTime class to fix shortcomings and defects, and provide more, simpler and safer getters and setters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
