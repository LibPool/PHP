# cccaaavvv/so-cms

> 标签: admin, administrator, crud, laravel, panel

## 简介

Administrative interface builder for Laravel. Build on SleepingOwl fork

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
