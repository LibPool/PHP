# ajulcab/laravel-generate-model

> 标签: ajulcab, generate, laravel, model, reliese

## 简介

Reliese Components for Laravel Framework code generation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
