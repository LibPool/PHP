# pravodev/laravel-couchdb

> 标签: PHP

## 简介

A CouchDB v2.0.0 based Eloquent model and Query builder for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
