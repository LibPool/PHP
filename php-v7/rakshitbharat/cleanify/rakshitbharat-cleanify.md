# rakshitbharat/cleanify

> 标签: cleanify, rakshitbharat

## 简介

Clean all type of cache which are related to Laravel right from route or console command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
