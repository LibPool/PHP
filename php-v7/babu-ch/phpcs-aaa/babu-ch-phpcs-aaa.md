# babu-ch/phpcs-aaa

> 标签: aaa, arrange-act-assert, phpcs, phpunit, test

## 简介

PHP_CodeSniffer standard that enforces the Arrange-Act-Assert pattern in test code.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
