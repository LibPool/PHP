# derekderaps/kalaponents

> 标签: drupal

## 简介

Kalagraphs provides a flexible Paragraph type that allows editors to choose with which Twig template to render it.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
