# robinncode/onubadok

> 标签: language, laravel, localization, php, translation

## 简介

This is a Composer package for translating your PHP software to other languages, primarily in Bengali.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
