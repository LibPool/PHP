# infince/soap-api

> 标签: Zimbra API, client, library, soap, web service

## 简介

PHP wrapper library around the Zimbra Soap API (web service) Upgraded to work on Guzzel 7.*

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
