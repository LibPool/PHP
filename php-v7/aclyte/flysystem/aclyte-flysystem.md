# aclyte/flysystem

> 标签: Cloud Files, WebDAV, abstraction, aws, cloud, copy.com, dropbox, file systems, files, filesystem, filesystems, ftp, rackspace, remote, s3, sftp, storage

## 简介

Filesystem abstraction: Many filesystems, one API. Maintained Flysystem 1.x fork with PHP 8.4 support.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
