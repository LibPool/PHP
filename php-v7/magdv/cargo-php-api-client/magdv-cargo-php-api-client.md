# magdv/cargo-php-api-client

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

REST-Full API для логистической биржи cargomart.ru

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
