# adrianorosa/laravel-geolocation

> 标签: geoip, geolocation, ipinfo, laravel, laravel-geolocation

## 简介

Laravel Geo Location package to get details for a given IP Address

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
