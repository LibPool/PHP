# stmllr/typo3-zahnstocher

> 标签: TYPO3 CMS

## 简介

Zahnstocher (en. toothpick) helps you when piercing into programming code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
