# teppokoivula/snippets

> 标签: module, processwire

## 简介

ProcessWire CMS/CMF module for allows embedding HTML/JS/CSS snippets into page markup.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
