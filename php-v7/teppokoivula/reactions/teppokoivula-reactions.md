# teppokoivula/reactions

> 标签: module, processwire

## 简介

Reactions is a ProcessWire CMS/CMF module for adding the ability for visitors to add reactions for pages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
