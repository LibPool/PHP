# yuanshe/wechat-sdk

> 标签: wechat, weixin, 公众号, 公众平台, 微信

## 简介

一个非常容易上手的微信公众平台SDK

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
