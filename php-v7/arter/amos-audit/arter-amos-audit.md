# arter/amos-audit

> 标签: Audit, logging, trail, yii2

## 简介

This is a FORK of Yii2 Audit records and displays web/cli requests, database changes, php/js errors and associated data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
