# htmlburger/carbon-fields

> 标签: PHP

## 简介

WordPress developer-friendly custom fields for post types, taxonomy terms, users, comments, widgets, options and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
