# htmlburger/wpemerge-plugin

> 标签: plugin, starter plugin, wordpress, wpemerge

## 简介

A modern WordPress starter plugin which uses the WP Emerge framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
