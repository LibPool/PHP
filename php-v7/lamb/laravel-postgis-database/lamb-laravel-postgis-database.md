# lamb/laravel-postgis-database

> 标签: database, laravel, postgis

## 简介

An extended Postgres driver for Laravel 4 that provides support for PostGIS features.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
