# lamb/laravel-generic-database

> 标签: database, generic, laravel, pdo

## 简介

A database driver for Laravel 4 that provides support for generic PDO drivers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
