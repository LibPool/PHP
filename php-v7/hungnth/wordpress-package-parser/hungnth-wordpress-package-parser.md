# hungnth/wordpress-package-parser

> 标签: package, parser, wordpress

## 简介

A PHP package for parsing WordPress plugin, theme, and generic package metadata.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
