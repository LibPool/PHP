# bastinald/livewire-bootstrap-auth

> 标签: PHP

## 简介

Laravel starter kit with Livewire & Bootstrap 5 auth scaffolding.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
