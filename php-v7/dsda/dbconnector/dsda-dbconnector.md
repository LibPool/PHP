# dsda/dbconnector

> 标签: database, framework, mysql, sql, sqlite, web service

## 简介

DBConnector is library to connect app with mysql or sqlite databases via PDO

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
