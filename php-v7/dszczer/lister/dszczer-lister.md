# dszczer/lister

> 标签: doctrine list, lister, propel list, symfony 2 list, symfony list

## 简介

List generator for Symfony 2.8/3.x, ready to use with Propel 2 or Doctrine 2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
