# larbrary/tawk

> 标签: chat, chat widget, laravel, support chat, tawk, tawk to, tawk-to, tawk.to, tawkto, website chat, widget

## 简介

Website chat widget (tawk.to integration for Laravel).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
