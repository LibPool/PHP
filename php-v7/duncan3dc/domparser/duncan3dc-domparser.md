# duncan3dc/domparser

> 标签: domdocument, generation, html, parser, parsing, writer, xml

## 简介

Wrappers for the standard DOMDocument class to provide extra functionality for html/xml parsing

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
