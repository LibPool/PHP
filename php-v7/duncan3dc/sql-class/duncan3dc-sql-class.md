# duncan3dc/sql-class

> 标签: abstraction, cache, database, mssql, mysql, mysqli, odbc, postgres, redshift, sql, sqlite

## 简介

A simple database abstraction layer, with an on disk caching facility.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
