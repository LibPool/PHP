# plasticstudio/form-submission-cleanup

> 标签: cms, silverstripe

## 简介

Configurable queued-job cleanup for SilverStripe form submission DataObjects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
