# josantonius/wp-image-handler

> 标签: attachment, hhvm, image, php, wordpress

## 简介

Adding, updating and deleting images from WordPress posts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
