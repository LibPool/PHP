# langleyfoxall/laravel-config-to-env

> 标签: PHP

## 简介

⚙ Artisan command that replaces all variables in a Laravel config file with calls to env()

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
