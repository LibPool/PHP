# takeit/amp-html-bundle

> 标签: AMPHTML, amp, amp-html, google, html

## 简介

Provide AMP HTML conversion to your Symfony2/Symfony3 projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
