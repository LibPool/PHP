# drsdre/yii2-redis-counter

> 标签: atomic, counter, extension, redis, yii2

## 简介

Redis Counter implements fast atomic counters using Redis storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
