# unisharp/laravel-jwt

> 标签: concurrency, jwt, laravel, reissue, token

## 简介

A jwt package for reisssuing token purpose based on jwt-auth package.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
