# unisharp/s3-presigned

> 标签: aws, laravel, php, pre-signed, s3, upload

## 简介

An AWS S3 package for pre-signed upload purpose in Laravel and PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
