# sheadawson/silverstripe-blocks

> 标签: blocks, silverstripe, widgets

## 简介

An alternative to the SilverStripe Widgets module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
