# mihasicehcek/json_parser

> 标签: PHP

## 简介

Simple wrapper over json_decode/json_encode php functions. Throws exceptions when decoding/encoding fails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
