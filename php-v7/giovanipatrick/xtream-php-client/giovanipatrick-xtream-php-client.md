# giovanipatrick/xtream-php-client

> 标签: IPTV, epg, player-api, vod, xtream, xtream-codes

## 简介

A PHP 7.0+ client for Xtream-compatible IPTV Player APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
