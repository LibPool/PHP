# gsl/civicrm-cli-utils

> 标签: PHP

## 简介

Miscelanious utils. Bootstrap CiviCRM and wrap API for command-line use.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
