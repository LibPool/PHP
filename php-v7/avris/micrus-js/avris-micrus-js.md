# avris/micrus-js

> 标签: JS, javascript, localization, micrus, php, routing, translation

## 简介

JavaScript plugin for Micrus framework (handles routing and localization)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
