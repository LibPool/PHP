# figuren-theater/ft-admin-ui

> 标签: MP6, admin, ui, widgets, wordpress

## 简介

Clean and helpful UI to make digital content editing for your figuren.theater WordPress website a friendly experience.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
