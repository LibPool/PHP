# figuren-theater/coding-standards

> 标签: WordPressVIPMinimum, coding-standards, wordpress, wpcs

## 简介

Coding standards for PHP, JavaScript and CSS within the figuren.theater WordPress Multisite network.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
