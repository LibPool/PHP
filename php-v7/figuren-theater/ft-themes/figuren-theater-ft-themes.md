# figuren-theater/ft-themes

> 标签: blockthemes, full-site-editing, themes, wordpress

## 简介

WordPress Themes usable in the figuren.theater Multisite network.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
