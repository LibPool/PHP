# jtsternberg/localgpt

> 标签: Gemini, ai, cli, console, gpt

## 简介

A command-line interface for creating and interacting with local, file-based custom GPTs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
