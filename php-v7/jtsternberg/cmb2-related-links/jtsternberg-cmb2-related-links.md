# jtsternberg/cmb2-related-links

> 标签: CMB2, meta, wordpress

## 简介

Custom field for CMB2 which adds a releated links repeatable group field.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
