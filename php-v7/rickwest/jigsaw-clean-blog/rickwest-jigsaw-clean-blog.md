# rickwest/jigsaw-clean-blog

> 标签: blog, generator, jigsaw, site, starter, static, template

## 简介

Blog starter template for Jigsaw static site generator by Tighten

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
