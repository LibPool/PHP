# davay/module-snowflakes

> 标签: magento2, magic-snowflakes, module, snowflakes

## 简介

Magento2 module that will add magic-snowflakes to your store

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
