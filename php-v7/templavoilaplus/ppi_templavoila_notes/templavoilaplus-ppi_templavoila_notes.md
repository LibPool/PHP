# templavoilaplus/ppi_templavoila_notes

> 标签: TemplaVoila, extension, typo3

## 简介

Show sys_note records in TemplaVoilà! Plus page module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
