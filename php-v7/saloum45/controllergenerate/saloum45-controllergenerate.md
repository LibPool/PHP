# saloum45/controllergenerate

> 标签: PHP

## 简介

😊Un package Laravel qui facilite la génération dynamique de contrôleurs,migrations et de routes dans une application Laravel😊

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
