# dcsg/mailchimp-api-connector

> 标签: abstraction, api, mailchimp

## 简介

Lightweight Mailchimp API connector for PHP 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
