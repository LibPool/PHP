# daku/nette-guzzle-bluescreen

> 标签: Guzzle, nette, tracy-panel

## 简介

This extension adds a new panel to Tracy Bluescreen for Guzzle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
