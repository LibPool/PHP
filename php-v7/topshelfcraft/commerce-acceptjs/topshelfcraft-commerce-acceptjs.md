# topshelfcraft/commerce-acceptjs

> 标签: Accept.js, AcceptJS, Craft, authorize, authorize.net, cms, commerce, craft-commerce, craft-plugin, craftcms, gateway

## 简介

Accept.js (Authorize.net) payment gateway for Craft Commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
