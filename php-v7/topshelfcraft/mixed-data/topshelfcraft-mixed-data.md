# topshelfcraft/mixed-data

> 标签: Craft, craft-plugin, craftcms, data, json, mixed

## 简介

A simple JSON-backed field for storing mixed data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
