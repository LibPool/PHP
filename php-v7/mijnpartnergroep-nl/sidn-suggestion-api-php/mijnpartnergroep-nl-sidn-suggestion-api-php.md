# mijnpartnergroep-nl/sidn-suggestion-api-php

> 标签: .nl, SIDN, api, suggestion

## 简介

SIDN Suggestion API client library for PHP. SIDN is the registrar for .nl fqdn's.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
