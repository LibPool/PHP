# theardent/centrifuge-broadcaster

> 标签: broadcaster, centrifuge, centrifugo, laravel

## 简介

Centrifuge broadcaster for laravel >= 5.3, support Centrifuge v2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
