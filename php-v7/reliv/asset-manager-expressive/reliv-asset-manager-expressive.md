# reliv/asset-manager-expressive

> 标签: JS, assetmanager, css, middleware, module, reliv, static

## 简介

Zend Expressive adapter for rwoverdijk/assetmanager

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
