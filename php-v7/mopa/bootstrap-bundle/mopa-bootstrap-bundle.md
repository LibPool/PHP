# mopa/bootstrap-bundle

> 标签: bootstrap, bootstrap form, extra form, form, template

## 简介

Easy integration of twitters bootstrap into symfony2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
