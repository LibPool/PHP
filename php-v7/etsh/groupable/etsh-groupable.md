# etsh/groupable

> 标签: group, groupable, laravel, package

## 简介

A laravel package for grouping content - like a simplified Organic Groups for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
