# weison-tech/yii2-scroll-pager

> 标签: pager, pagination, scroll, scrolling, yii, yii2

## 简介

Infinite AJAX scrolling for Yii2 ListView widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
