# unisender/omnipay-qiwi

> 标签: gateway, omnipay, pay, payment, qiwi

## 简介

Qiwi driver for Omnipay PHP payment library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
