# ariarijp/mackerel-client

> 标签: monitoring

## 简介

mackerel-client-php is an unofficial port of mackerelio/mackerel-client-ruby.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
