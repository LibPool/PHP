# atukai/at-php-settings

> 标签: AtPhpSettings, Settings, atukai, php, zf2

## 简介

A ZF2 module for managing php settings.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
