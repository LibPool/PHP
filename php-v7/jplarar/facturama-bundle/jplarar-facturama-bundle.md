# jplarar/facturama-bundle

> 标签: Facturama, jplarar, symfony

## 简介

A simple Symfony2+ bundle for the API for Facturama.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
