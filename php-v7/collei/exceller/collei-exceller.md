# collei/exceller

> 标签: csv, excel, spreadsheet, xls, xlsx

## 简介

A simple wrapper for the PHPOffice/PHPSpreadsheet package. Read excel files with ease.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
