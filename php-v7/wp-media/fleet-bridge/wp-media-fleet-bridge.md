# wp-media/fleet-bridge

> 标签: PHP

## 简介

Accept verified commands from Fleet in a WordPress plugin: a command signed by Fleet, plus a consent grant signed by the licence vendor.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
