# wp-media/wp-imagify-partner

> 标签: Imagify, wordpress

## 简介

A php class allowing WordPress plugin developers to promote Imagify through their own plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
