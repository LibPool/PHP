# slashworks/contao-simple-svg-icons-bundle

> 标签: PHP

## 简介

Simply use SVG icons from an SVG icon sprite file with Contao inserttags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
