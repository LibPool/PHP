# gsu/ftp-sftp-transfer

> 标签: ftp, sftp, ssh

## 简介

A PHP class to transfer data using sftp and ftp protocols.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
