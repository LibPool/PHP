# sofwar/abiosgaming-api-php

> 标签: abios, api, esports, game, gaming

## 简介

A PHP Library for interacting with Abios Gaming's API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
