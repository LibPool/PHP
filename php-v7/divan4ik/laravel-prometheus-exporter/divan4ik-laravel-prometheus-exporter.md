# divan4ik/laravel-prometheus-exporter

> 标签: Metrics, laravel, prometheus

## 简介

A laravel and lumen service provider to export metrics for prometheus.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
