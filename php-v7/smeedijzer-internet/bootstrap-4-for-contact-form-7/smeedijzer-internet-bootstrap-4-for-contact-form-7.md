# smeedijzer-internet/bootstrap-4-for-contact-form-7

> 标签: addon, bootstrap, bootstrap 4, bootstrap framework, cf7bs, contact form, contact form 7, contact form 7 addon, plugin, wordpress, wpcf7

## 简介

This plugin modifies the output of the popular Contact Form 7 plugin to be styled in compliance with themes using the Bootstrap CSS framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
