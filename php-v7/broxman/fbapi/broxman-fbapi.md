# broxman/fbapi

> 标签: fusebill, fusebill api, php fusebill api

## 简介

PHP Library for Fusebill API (https://developer.fusebill.com/v1.0/reference)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
