# mariojgt/biscotto

> 标签: Cookie manager, analytics, cookie, cookie gdpr, gdpr, gdpr laravel, laravel, laravel gdpr, script gdpr

## 简介

A Laravel Package Biscotto, will help you enable and disable cookies or scripts that required gdpr compliance.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
