# it-brains/laravel-release-scripts

> 标签: deploy, laravel

## 简介

Laravel Release Scripts, easy to set up one-off execute scripts that will be running during deploy script.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
