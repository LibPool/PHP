# samynw/pimcore-monitoring-manager

> 标签: PHP

## 简介

Provides an easy tool for using your monitoring software to monitor jobs within a Pimcore application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
