# laobai/cloud-storage

> 标签: cloud-storage, qiniu, thinkphp, thumbnail, upload, video-thumbnail, watermark

## 简介

云存储上传组件，支持七牛云/本地存储，自动生成视频封面、图片缩略图、文字水印，兼容ThinkPHP5/6/8

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
