# xd-google/apiclient

> 标签: google

## 简介

Client library for Google APIs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://developers.google.com/api-client-library/php
- 源码仓库：https://github.com/cxpang/apiclient.git
- Packagist 页面：https://packagist.org/packages/xd-google%2Fapiclient

## 历史版本号

- 当前版本：v1.1

## 获取地址

- Composer 安装：`composer require xd-google/apiclient`
- Packagist 仓库：https://repo.packagist.org/p2/xd-google/apiclient.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4
