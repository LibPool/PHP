# diego-rlima/laravel-cors

> 标签: PHP

## 简介

Simple package to add CORS (Cross-Origin Resource Sharing) headers to the Laravel application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
