# illchuk/zfc-user-substitute

> 标签: ZendFramework, zf3, zfcuser

## 简介

It's like the su command for ZfcUser & ZF3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
