# wpsmith/plugin

> 标签: dependency, extension, plugin, wordpress

## 简介

Core class for extending WordPress plugins and hiding WordPress plugins on the plugins page.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
