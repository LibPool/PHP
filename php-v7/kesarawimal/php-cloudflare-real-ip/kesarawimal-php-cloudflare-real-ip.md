# kesarawimal/php-cloudflare-real-ip

> 标签: cloudflare, laravel, php, real ip address

## 简介

Get the real IP for PHP applications behind Cloudflare's reverse proxy.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
