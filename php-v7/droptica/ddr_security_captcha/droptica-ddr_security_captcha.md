# droptica/ddr_security_captcha

> 标签: drupal recipe, drupal recipes, recipe

## 简介

Installs and configures the CAPTCHA module for enhanced form security.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
