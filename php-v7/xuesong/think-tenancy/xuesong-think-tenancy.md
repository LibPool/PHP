# xuesong/think-tenancy

> 标签: multi-database, multi-tenancy, saas, tenancy, thinkphp, thinkphp-saas

## 简介

A Thinkphp multi-database tenancy package that respects your code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
