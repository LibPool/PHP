# phpmicroservice/mongo-odm

> 标签: mongo, mongodb, odm

## 简介

mongodb的对象化工具,通过面向对象的操作来操作mongodb数据库

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
