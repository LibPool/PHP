# phpmicroservice/pms-frame

> 标签: Microservice, phalcon, swoole, tcp, websockect

## 简介

一个采用Swoole做底层,采用Phalcon作为框架类库的微服务框架

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
