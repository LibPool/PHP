# pceuropa/yii2-menu

> 标签: bootstrap menu, creator, drag end drop, extension, menu builder, yii2

## 简介

Menu bootstrap builder. Sort by drag and drop

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
