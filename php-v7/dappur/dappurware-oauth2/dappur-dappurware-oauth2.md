# dappur/dappurware-oauth2

> 标签: dappur, dappurware, framework, oauth2

## 简介

Oauth2 support package for the Dappur Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
