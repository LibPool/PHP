# hopefeda/cookielize

> 标签: cookie, cookielize, language, laravel, locale, localization

## 简介

This package adds changing locale/language functionality to your laravel app using cookies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
