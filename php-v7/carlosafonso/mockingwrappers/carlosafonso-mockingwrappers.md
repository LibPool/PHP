# carlosafonso/mockingwrappers

> 标签: PHP

## 简介

A collection of wrappers over standard PHP functions to allow dependecy injection-based mocking

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
