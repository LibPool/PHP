# laranex/laravel-biometric-auth

> 标签: laranex, laravel, laravel-biometric-auth

## 简介

A laravel package to provide asymmetric biometric authentication

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
