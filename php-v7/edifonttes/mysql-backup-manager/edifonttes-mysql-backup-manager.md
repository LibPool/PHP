# edifonttes/mysql-backup-manager

> 标签: backup, database, google-drive, mysql

## 简介

Biblioteca PHP para backup de banco de dados MySQL com suporte a SQL e ZIP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
