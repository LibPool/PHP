# yiyon/laravel-permission-merchant

> 标签: acl, laravel, permission, permissions, rbac, roles, security, spatie

## 简介

Permission handling for Laravel 5.4 to 5.8,增加多商户权限, 北京易用联友

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
