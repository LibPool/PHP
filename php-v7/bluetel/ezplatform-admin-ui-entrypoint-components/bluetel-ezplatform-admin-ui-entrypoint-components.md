# bluetel/ezplatform-admin-ui-entrypoint-components

> 标签: PHP

## 简介

Set of admin UI components for loading assets directly from the webpack encore entrypoint.json

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
