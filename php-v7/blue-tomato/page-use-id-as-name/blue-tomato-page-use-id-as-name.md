# blue-tomato/page-use-id-as-name

> 标签: id, name, processwire, url

## 简介

Overrides the name field (used for url) with the page-id and hides the field from the admin GUI

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
