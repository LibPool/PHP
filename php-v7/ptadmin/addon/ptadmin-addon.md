# ptadmin/addon

> 标签: PTAdmin, addon, admin, html, 低代码平台, 插件应用, 管理后台

## 简介

ptadmin 管理平台插件应用管理包，需要搭配PTAdmin 管理平台使用

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
