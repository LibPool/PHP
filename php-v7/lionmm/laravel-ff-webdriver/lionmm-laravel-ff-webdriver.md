# lionmm/laravel-ff-webdriver

> 标签: firefox, laravel, selenium, webdriver

## 简介

Selenium Firefox web-driver interface for Laravel 5.1.* - 5.2.*

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
