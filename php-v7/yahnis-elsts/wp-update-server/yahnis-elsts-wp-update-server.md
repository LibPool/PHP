# yahnis-elsts/wp-update-server

> 标签: automatic updates, plugin updates, theme updates, wordpress

## 简介

Custom update API server for WordPress plugins and themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
