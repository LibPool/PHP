# zao-web/qbo-connect-ui

> 标签: json, wordpress, wp-api

## 简介

Provides UI for connecting to Quickbooks Online over OAuth.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
