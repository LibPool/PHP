# mpdf/mpdf

> 标签: PDF, pdf, php, utf-8, 生成

## 简介

PHP library generating PDF files from UTF-8 encoded HTML

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
