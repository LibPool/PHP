# hipay/hipay-enterprise-sdk-js

> 标签: PHP

## 简介

The HiPay Fullservice SDK for JavaScript allows you to tokenize credit or debit cards against the HiPay Fullservice payment platform.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
