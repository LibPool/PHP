# hipay/hipay-wallet-cashout-mirakl-integration

> 标签: PHP

## 简介

Turnkey integration which handles cash-out operations between HiPay and the Mirakl marketplace solution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
