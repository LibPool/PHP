# fabricekabongo/auth0-api-authentication-bundle

> 标签: PHP

## 简介

Integrate with Auth0 to bring API authentication to Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
