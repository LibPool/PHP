# wangbj/think-upload

> 标签: think, upload

## 简介

自定义一个上传服务[整合本地、七牛云、阿里云、腾讯云] 环境: ThinkPHP:8.0 PHP:8.1 理论上 php >= 7.1 thinkPHP >= 5.0 都可以使用

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
