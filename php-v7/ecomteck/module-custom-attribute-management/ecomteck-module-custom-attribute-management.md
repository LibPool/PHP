# ecomteck/module-custom-attribute-management

> 标签: PHP

## 简介

A Magento 2 module is extended of magento 2 attributes management to manage custom attributes on backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
