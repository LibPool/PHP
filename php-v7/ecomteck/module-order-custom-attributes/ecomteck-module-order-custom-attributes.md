# ecomteck/module-order-custom-attributes

> 标签: PHP

## 简介

A Magento 2 module is allow admin create, manage custom attributes to display on checkout page, order info

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
