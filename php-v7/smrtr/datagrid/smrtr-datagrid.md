# smrtr/datagrid

> 标签: datagrid, selectors, smrtr

## 简介

Smrtr DataGrid is a searchable backend datagrid class with applications in data management, analysis and reporting.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
