# porthd/simpledataedit

> 标签: Feedit, TYPO3 CMS, editing, frontend

## 简介

Simple frontend-editing with TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
