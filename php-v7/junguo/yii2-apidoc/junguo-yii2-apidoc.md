# junguo/yii2-apidoc

> 标签: api, doc, php exlanatory, yii2

## 简介

[重大更新!]适合中小型公司使用.可作为调试工具(postman),可作为文档.简单配置,不切入系统.一切以提高开发效率,提高生产力为基准

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
