# ehaerer/fe-upload-example

> 标签: TYPO3 CMS, example, frontend, upload

## 简介

An example extension to show upload of files in TYPO3 frontend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
