# ehaerer/php-fetch-mail

> 标签: PHP

## 简介

PHP-library to fetch e-mails from an SMTP mailbox to store the e-mail and attachment(s).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
