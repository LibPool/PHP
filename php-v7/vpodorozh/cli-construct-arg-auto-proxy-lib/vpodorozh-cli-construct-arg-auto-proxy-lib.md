# vpodorozh/cli-construct-arg-auto-proxy-lib

> 标签: PHP

## 简介

Makes all Magento CLI commands construct dependencies be injected as Proxy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
