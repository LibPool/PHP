# mrfeathers/php-fpcalc

> 标签: Fingerprint, acoustid, chromaprint, fpcalc, library, music, php

## 简介

PHP wrapper for command-line fingerprint generator - fpcalc

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
