# ecomdev/mysql-test-utils

> 标签: PHP

## 简介

Bare minimum MySQL Test utilities for writing automated tests of software that relies on MySQL as data storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
