# coliving/canvas

> 标签: blog, canvas, laravel, platform, publishing

## 简介

A Laravel publishing platform. This is fork from austintoddj/canvas to make it support Laravel 12

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
