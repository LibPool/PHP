# coliving/eloquent-filter

> 标签: dynamic-filters, eloquent, eloquent filter, filter, laravel, laravel filter, laravel filter multiple parameters, laravel query filter, laravel tools, query, query-filter, search

## 简介

The Eloquent Filter is a package for filter data of models by the query string. Easy to use and fully dynamic.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
