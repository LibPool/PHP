# coliving/laravel-block-bots

> 标签: PHP

## 简介

Block bots and high traffic offenders using Redis. This is forked from Potelo/laravel-block-bots to make it support Laravel 10

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
