# mika56/spfcheck-dns-direct

> 标签: PHP

## 简介

Provide a DNSRecordGetterInterface for using custom DNS servers for mika56/spfcheck

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
