# premium-contao-themes/pct_articlewrapper

> 标签: catalog, contao, customcatalog, customelements, isotope, premium-contao-themes, premiumcontaothemes, themes

## 简介

Allows to create articles that wrap other articles in between

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
