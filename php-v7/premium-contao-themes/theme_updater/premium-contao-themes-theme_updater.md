# premium-contao-themes/theme_updater

> 标签: contao, premium-contao-themes, premiumcontaothemes, seamedia themes, themes

## 简介

Update manager for the Premium Contao Themes: EclipseX, EclipseX + CustomCatalog Bundle. https://www.premium-contao-themes.com/

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
