# sanskrit/sanscript

> 标签: devanagari, iast, itrans, romanization, sanskrit, transliteration

## 简介

Transliteration library for Sanskrit and other Indian languages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
