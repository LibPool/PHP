# cyberwani/trai-sms-header

> 标签: PHP

## 简介

A PHP library for inspecting TRAI-compliant SMS headers (operator, circle, and message type mapping) with DLT sender lookup.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
