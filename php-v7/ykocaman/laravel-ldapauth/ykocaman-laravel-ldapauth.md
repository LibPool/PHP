# ykocaman/laravel-ldapauth

> 标签: Authentication, LdapAuth, laravel, ldap

## 简介

Basic ldap authentication for laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
