# net2rent/php-connector

> 标签: connector, net2rent, php

## 简介

PHP connector to consume net2rent API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.net2rent.com/
- 源码仓库：https://github.com/net2rent/php-connector.git
- Packagist 页面：https://packagist.org/packages/net2rent%2Fphp-connector

## 历史版本号

- 当前版本：0.2.1

- 0.2.1

## 获取地址

- Composer 安装：`composer require net2rent/php-connector`
- Packagist 仓库：https://repo.packagist.org/p2/net2rent/php-connector.json
- PHP 要求：>=5.3.3
