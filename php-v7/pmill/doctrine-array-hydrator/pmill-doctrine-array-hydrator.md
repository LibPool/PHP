# pmill/doctrine-array-hydrator

> 标签: array, doctrine, hydrator, php

## 简介

An array to entity hydrator for Doctrine 2 entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
