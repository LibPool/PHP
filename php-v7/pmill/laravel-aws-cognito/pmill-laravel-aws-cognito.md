# pmill/laravel-aws-cognito

> 标签: Authentication, Cognito, api, aws, guard, laravel, php

## 简介

A Laravel guard for AWS Cognito user pools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
