# huoxin/filter-rule-manager

> 标签: ast, automod, filter, flarum, manager, moderation, rule

## 简介

A powerful and customizable AST-based moderation and filtering engine for Flarum.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
