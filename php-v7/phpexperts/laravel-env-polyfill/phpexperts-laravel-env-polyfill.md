# phpexperts/laravel-env-polyfill

> 标签: 5.7, env, laravel, shim

## 简介

Use Laravel's pre-5.8 env() function in your non-Laravel projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
