# jdavidbakr/replaceable-model

> 标签: jdavidbakr, replaceable-model

## 简介

Adds 'REPLACE' and 'INSERT IGNORE' query capability to eloquent models

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
