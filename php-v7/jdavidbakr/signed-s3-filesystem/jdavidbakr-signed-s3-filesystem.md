# jdavidbakr/signed-s3-filesystem

> 标签: SignedS3Filesystem, jdavidbakr

## 简介

Extension of the Laravel S3 filesystem to return signed URLs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
