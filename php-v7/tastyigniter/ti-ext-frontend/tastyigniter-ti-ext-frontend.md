# tastyigniter/ti-ext-frontend

> 标签: PHP

## 简介

Manage basic components like Slider, Featured Menu Items, Banners and Newsletter

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
