# moee/sns-autoconfirm-bundle

> 标签: PHP

## 简介

Automatic subscription confirmation of AWS SNS HTTP(s) endpoints with Symfony (alpha)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
