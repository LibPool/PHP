# s-anasol/vk

> 标签: antigate, api, captcha, oauth, proxy, vk, vk.com

## 简介

The PHP class for vk.com API. With HTTP proxy and captcha recognition via antigate support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
