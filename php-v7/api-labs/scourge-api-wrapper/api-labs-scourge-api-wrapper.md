# api-labs/scourge-api-wrapper

> 标签: api, laravel, scourge, wrapper

## 简介

An API wrapper to help websites interfacing with an API based on the scourge-api package.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
