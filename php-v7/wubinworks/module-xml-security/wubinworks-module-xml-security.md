# wubinworks/module-xml-security

> 标签: cosmic sting, cosmicsting, cve-2024-34102, encoding, enhancement, magento 2, magento2, php-fpm, security, xml, xml encoding, xml entity, xml security, xxe

## 简介

A replacement of `\Magento\Framework\Xml\Security` for Magento 2 with enhanced security.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
