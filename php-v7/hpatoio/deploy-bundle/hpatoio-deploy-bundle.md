# hpatoio/deploy-bundle

> 标签: command, deploy

## 简介

Easy deploy via rsync. Porting of Symfony 1 project:deploy command.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
