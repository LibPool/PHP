# andredebrito/phpviacep

> 标签: consulta cep, php, viacep

## 简介

Componente PHP para consumo da API VIA CEP (https://viacep.com.br/)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
