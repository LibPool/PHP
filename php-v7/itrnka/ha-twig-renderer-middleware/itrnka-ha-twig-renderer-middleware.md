# itrnka/ha-twig-renderer-middleware

> 标签: HA, renderer, template, twig

## 简介

Twig template renderer middleware for ha framework. This is a proxy to Twig.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
