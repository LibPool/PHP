# silverstripe-australia/silverstripe-sesmail

> 标签: amazon, email, ses, silverstripe

## 简介

Custom Mailer type that sends mail via Amazon's SES

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
