# silverstripe-australia/grouped-cms-menu

> 标签: cms, group, grouped, grouping, menu, module, silverstripe

## 简介

Allows you to group CMS menu items.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
