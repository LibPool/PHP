# yasanov/dater

> 标签: date, datetime, php, time, timezone

## 简介

Compact PHP library for working with date/time in different formats & timezones. Updated jstz

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
