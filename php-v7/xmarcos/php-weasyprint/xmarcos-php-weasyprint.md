# xmarcos/php-weasyprint

> 标签: WeasyPrint, pdf, php, php56

## 简介

Backport of pontedilana/php-weasyprint for legacy applications running PHP 5.6.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
