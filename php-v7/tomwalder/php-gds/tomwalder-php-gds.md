# tomwalder/php-gds

> 标签: appengine, cloud datastore, datastore, firestore, gae, google, nosql

## 简介

Google Cloud Datastore Library for PHP. Also Firestore in Datastore mode.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
