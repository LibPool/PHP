# liorchamla/faker-prices

> 标签: faker, fixtures, prices

## 简介

Provides typical and credible prices for Faker (fzaninotto/faker or fakerphp/faker) library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
