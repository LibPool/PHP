# rocky114/spreadsheet

> 标签: csv, excel, memory, office, php, read, scale, spreadsheet, write, xlsx

## 简介

PHP library to read and write spreadsheet files (CSV, XLSX)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
