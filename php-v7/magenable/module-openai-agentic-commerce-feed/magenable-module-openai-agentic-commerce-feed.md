> 标签: agentic commerce, magento 2 openai agentic commerce, openai agentic commerce

## 简介

This Magento 2 module provides the ability to generate feed files for OpenAI Agentic Commerce

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
