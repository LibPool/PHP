# foxtech6/mutexsafe

> 标签: flock, lock, locker, locking, memcached-lock, mutex, pdo-lock, php, redis-lock

## 简介

This library will help you use mutex more effectively. Different mutex for different components are presented. In addition, you can add your own lockers and use within the library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
