# bmunyoki/mpesa

> 标签: PHP

## 简介

Laravel Mpesa package providing Mpesa STK, B2C, C2B and Reversal functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
