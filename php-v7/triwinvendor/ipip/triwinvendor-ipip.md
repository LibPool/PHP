# triwinvendor/ipip

> 标签: IP, geo, geoip, geolocation, ipdb, ipip.net

## 简介

IPIP.net officially supported IP database ipdb format parsing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.ipip.net
- 源码仓库：https://github.com/TriwinVendor/ipip.git
- Packagist 页面：https://packagist.org/packages/triwinvendor%2Fipip

## 获取地址

- Packagist 仓库：https://repo.packagist.org/p2/triwinvendor/ipip.json
- PHP 要求：>=5.4.0
