# zvermafia/alif-api-wrapper

> 标签: api, library, package, wrapper

## 简介

API wrapper for the alif.uz (online transliteration service, uzbek latin <=> uzbek cyrillic)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
