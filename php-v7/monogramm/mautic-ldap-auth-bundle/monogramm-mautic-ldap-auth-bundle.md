# monogramm/mautic-ldap-auth-bundle

> 标签: Authentication, Mautic, ldap, plugin

## 简介

This plugin enables LDAP authentication for mautic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
