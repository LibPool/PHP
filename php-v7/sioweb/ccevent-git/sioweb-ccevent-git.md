# sioweb/ccevent-git

> 标签: PHP

## 简介

Composer plugin event handler, run plugin scripts right after installer (post-[update|install]-cmd) is done.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
