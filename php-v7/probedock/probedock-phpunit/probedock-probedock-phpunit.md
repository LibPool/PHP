# probedock/probedock-phpunit

> 标签: analytics, phpunit, probedock, test

## 简介

PHPUnit probe to publish test results to Probe Dock.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
