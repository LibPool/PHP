# slub/slub-zotero

> 标签: extension, slub_zotero, typo3

## 简介

This extension should call the zotero api and present the SLUB bibliography on the website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
