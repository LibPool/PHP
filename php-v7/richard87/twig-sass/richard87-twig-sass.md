# richard87/twig-sass

> 标签: sass, twig

## 简介

A Twig extension/function to render inline SASS files for SEO purposes or to render CSS files with easy customizability

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
