# cobraprojects/quest

> 标签: fuzzy, laravel, php, quest, search

## 简介

A package that provides pseudo fuzzy-searching to Laravel database queries.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
