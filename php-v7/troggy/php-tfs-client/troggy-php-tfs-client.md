# troggy/php-tfs-client

> 标签: tee, tfs

## 简介

PHP API for Team Foundation Server. Essentially just a PHP wrapper for TFS command line client (Team Explorer Everywhere)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
