# amazeelabs/silverback_cloudinary

> 标签: PHP

## 简介

A module that creates a graphql field to expose cloudinary image urls based on a config input.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
