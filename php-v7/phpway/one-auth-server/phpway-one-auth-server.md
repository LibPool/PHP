# phpway/one-auth-server

> 标签: SPA, oauth2, one-auth

## 简介

Simple OAuth2 server implementation with limited functionality designed for Single Page Applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
