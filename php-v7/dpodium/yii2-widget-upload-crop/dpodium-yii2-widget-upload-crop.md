# dpodium/yii2-widget-upload-crop

> 标签: crop, fileupload, widget, yii2, zoom

## 简介

Yii2 widget for file upload and allow user to zoom and crop the image

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
