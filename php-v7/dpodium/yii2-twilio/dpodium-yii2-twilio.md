# dpodium/yii2-twilio

> 标签: sms, twilio, yii2

## 简介

Yii2 twilio is a wrapper for the Twilio PHP library. Allow yii2 application to use twilio services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
