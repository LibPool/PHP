# flagrow/flarum-ext-analytics

> 标签: analytics, extension, flagrow, flarum, google-analytics, piwik

## 简介

Tracks analytics using googles and piwik metric tool analytics

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
