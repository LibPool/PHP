# flagrow/mail-drivers

> 标签: extension, flarum, mailgun, mandrill, ses

## 简介

Send email via Mailgun, Mandrill or SES api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
