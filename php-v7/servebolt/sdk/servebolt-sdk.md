# servebolt/sdk

> 标签: PHP

## 简介

A PHP SDK for communicating with the Servebolt API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://servebolt.com
- 源码仓库：https://github.com/Servebolt/php-sdk.git
