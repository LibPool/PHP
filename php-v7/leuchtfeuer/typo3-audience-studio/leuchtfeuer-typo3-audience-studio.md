# leuchtfeuer/typo3-audience-studio

> 标签: Audience Studio, TYPO3 CMS, automation, marketing, salesforce

## 简介

Add-on TYPO3 extension that enhances the "EXT:marketing_automation" TYPO3 extension by connecting it to Salseforce Audience Studio

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
