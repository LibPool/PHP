# simukti/zf1-extras

> 标签: zend framework 1 extras, zf1-extras

## 简介

Zend Framework 1 extra library only, without tests, demos, bin, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
