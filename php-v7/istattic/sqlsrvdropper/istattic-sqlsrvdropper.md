# istattic/sqlsrvdropper

> 标签: laravel, mssql, sqlsrv

## 简介

A simple class to enable dropping SQLSrv Columns within a Laravel migration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
