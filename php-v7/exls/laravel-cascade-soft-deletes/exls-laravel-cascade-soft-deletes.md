# exls/laravel-cascade-soft-deletes

> 标签: PHP

## 简介

Cascading queued or regular deletes and restores for Eloquent models that implement soft deletes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
