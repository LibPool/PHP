# moolre/moolre-php

> 标签: Ghana, mobile-money, moolre, payment, payments, php-sdk

## 简介

Framework-agnostic PHP SDK for initiating and verifying Moolre payments.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
