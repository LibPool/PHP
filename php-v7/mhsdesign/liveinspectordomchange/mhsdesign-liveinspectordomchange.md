# mhsdesign/liveinspectordomchange

> 标签: PHP

## 简介

Neos Live Inspector Package, which reflects changes to the dom via MhsDesign.LiveInspectorJsEvents

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
