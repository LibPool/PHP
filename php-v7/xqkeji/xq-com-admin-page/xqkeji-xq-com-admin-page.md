# xqkeji/xq-com-admin-page

> 标签: PHP

## 简介

新齐通用后台管理页面系统的普通页面的js、css等前端程序的composer包。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
