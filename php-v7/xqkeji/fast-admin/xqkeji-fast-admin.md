# xqkeji/fast-admin

> 标签: PHP

## 简介

一个基于新齐低代码开发框架的后台管理系统，包含xq-app-admin后台管理模块，并可根据需要安装其他后台管理模块。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
