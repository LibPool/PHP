# klaussilveira/simple-shm

> 标签: PHP

## 简介

SimpleSHM is a simple and small abstraction layer for shared memory manipulation using PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
