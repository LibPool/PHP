# antonowano/qiwi-topup

> 标签: PHP

## 简介

Top-Up API is intended for merchants or payment service providers (PSP) who need to send money to QIWI Wallet users.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
