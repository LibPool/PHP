# barbushin/swoole-blackfire

> 标签: blackfire, profiler, profiling, swoole

## 简介

Blackfire profiler for PHP applications running on Swoole web-server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
