# theoknoep/gpx-difficulty-score

> 标签: PHP

## 简介

Simple PHP Lib for evaluate the difficulty of a GPX file (based on elevation)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
