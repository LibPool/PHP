# yii2tech/ar-file

> 标签: active, attachment, file, image, record, thumbnail, transformation, yii2

## 简介

Provides support for ActiveRecord file attachment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
