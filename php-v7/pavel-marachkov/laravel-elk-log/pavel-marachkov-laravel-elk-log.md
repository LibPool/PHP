# pavel-marachkov/laravel-elk-log

> 标签: elasticsearch, laravel, log

## 简介

Integrate laravel with elastic search for sending all logs to elastic search

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
