# akeneo-labs/direct-to-mongodb

> 标签: PIM, akeneo, data, e-commerce, ecommerce, performances

## 简介

Akeneo PIM Bundle to use direct to DB method to save products

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
