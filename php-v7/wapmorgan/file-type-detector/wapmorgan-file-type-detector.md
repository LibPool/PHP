# wapmorgan/file-type-detector

> 标签: files, filetype, formats, mimetype

## 简介

Detects file type by filename or content and generates correct mimetype.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
