# shchedrakov/translation-bundle

> 标签: extract, extraction, i18n, interface, multilanguage, translation, ui, webinterface

## 简介

Puts the Symfony Translation Component on steroids

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
