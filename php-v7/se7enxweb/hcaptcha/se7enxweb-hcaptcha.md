# se7enxweb/hcaptcha

> 标签: Forms, captcha, datatype, eZ Publish Legacy, eZ Publish Platform, extension, ez publish, recaptcha comparable, user registration

## 简介

eZ Publish Legacy extension which provides a simple captcha solution for user registration and any forms. Great for smart developers!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
