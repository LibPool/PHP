# se7enxweb/ezplatform-kernel

> 标签: PHP

## 简介

Kernel used by se7enxweb/exponential-platform and derivatives. Provides the Content Repository, its APIs, and the application's Symfony framework integration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
