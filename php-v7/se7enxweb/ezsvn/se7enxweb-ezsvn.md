# se7enxweb/ezsvn

> 标签: eZ Publish Legacy, eZ Publish Platform, extension, ez publish, north-america, subversion, svn, vcs, version-control

## 简介

eZ Publish Legacy extension which provides feature complete simple solution for version management of resources using Subversion (SVN) for version control of extension content. Great for smart developers!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
