# se7enxweb/ezpm

> 标签: eZ Publish Legacy, eZ Publish Platform, ez publish, im, messaging, private, secret, statistics, user features

## 简介

eZ Complete Private Messaging solution for your existing eZ Publish Websites. This is a Module Extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
