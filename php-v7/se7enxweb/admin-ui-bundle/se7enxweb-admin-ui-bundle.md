# se7enxweb/admin-ui-bundle

> 标签: admin, admin-ui, admin-ui-bundle, ezplatform, ezpublish, netgen

## 简介

7x Netgen Admin UI implements an alternate administration UI for Exponential Platform / Ibexa OSS, based on eZ Publish Legacy administration interface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
