# se7enxweb/xrowmetadata

> 标签: PHP

## 简介

Add SEO Meta Data to content objects also provides sitemap capabilities to eZ Publish

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
