# se7enxweb/ezodf-ls

> 标签: PHP

## 简介

This extension provides for the import and export of OpenOffice.org Writer documents within eZ Publish Legacy

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
