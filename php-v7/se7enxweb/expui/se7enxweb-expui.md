# se7enxweb/expui

> 标签: Exponential 6, YUI replacement, exponential, jQuery 4, jquery, legacy extension, ui

## 简介

Exponential UI: the jQuery 4 API (Exp.*) that delivers the admin's and the site designs' interactive features, replacing YUI

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
