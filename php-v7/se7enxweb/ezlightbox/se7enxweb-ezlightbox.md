# se7enxweb/ezlightbox

> 标签: PHP

## 简介

eZ Publish Legacy feature addition. Adds support for lightboxes with your website via a stable extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
