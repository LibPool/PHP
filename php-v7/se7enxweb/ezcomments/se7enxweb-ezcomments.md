# se7enxweb/ezcomments

> 标签: PHP

## 简介

eZ Publish Legacy comments extension (alternative; stores comments seperate from ezpublish for easy usage)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
