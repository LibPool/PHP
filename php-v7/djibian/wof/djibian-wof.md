# djibian/wof

> 标签: PostType, framework, taxonomies

## 简介

Wordpress Object Framework plugin to help developing custom post types or custom taxonomies

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
