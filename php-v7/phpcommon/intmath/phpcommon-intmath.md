# phpcommon/intmath

> 标签: arithmetic, integer, intmath, math, number, overflow, phpcommon

## 简介

A library for arithmetic operations on integers that wraps around upon overflow.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
