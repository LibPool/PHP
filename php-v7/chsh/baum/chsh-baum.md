# chsh/baum

> 标签: database, eloquent, laravel, laravel 8, nested set

## 简介

A fork of the etrepat nested set package with compatability for Laravel 8-9.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
