# mervick/socialauther

> 标签: PHP

## 简介

SocialAuther is a PHP library to simplify the implementation of authentication for website through the popular social networks and services: vk.com, odnoklassniki.ru, mail.ru, yandex.ru, google.com. facebook.com. Based on https://github.com/stanislav-protasevich/SocialAuther

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
