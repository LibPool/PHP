# jelix/diff-plugin

> 标签: castor, diff, jelix, jtpl

## 简介

a plugin for Jelix or Castor to render show differences between two content in a template

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
