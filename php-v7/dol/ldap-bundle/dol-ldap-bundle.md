# dol/ldap-bundle

> 标签: Authentication, ldap, multi-domains

## 简介

This bundle improves FR3DLdapBundle by adding the ability to connect to multiple LDAP domains.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
