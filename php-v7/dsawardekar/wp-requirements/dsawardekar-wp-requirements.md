# dsawardekar/wp-requirements

> 标签: minimum, system requirements, wordpress

## 简介

Library for handling minimum system requirements in WordPress Plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
