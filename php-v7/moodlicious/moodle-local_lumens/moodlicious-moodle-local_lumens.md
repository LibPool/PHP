# moodlicious/moodle-local_lumens

> 标签: PHP

## 简介

Super duper energy saving mode for Moodle. Flashlight overlay. Darkens page except cursor area. Good for OLED.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
