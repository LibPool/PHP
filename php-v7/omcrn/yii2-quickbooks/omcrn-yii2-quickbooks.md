# omcrn/yii2-quickbooks

> 标签:  extension,  quickbooks, yii2

## 简介

quickbooks online oauth2 and API wrapper for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
