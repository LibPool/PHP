# calcinai/phpi-websocket

> 标签: GPIO, pi, raspberry, rpi, websocket

## 简介

Scaffolding for Websocket server using Ratchet & PHPi

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
