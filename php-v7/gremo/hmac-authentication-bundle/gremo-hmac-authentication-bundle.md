# gremo/hmac-authentication-bundle

> 标签: Authentication, hmac, rest, security

## 简介

Symfony bundle adding REST HMAC HTTP authentication

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
