# gremo/email-obfuscator

> 标签: antispam, email, laravel, obfuscation, spam, twig

## 简介

A text filter for automatic email obfuscation using  Javascript or CSS fallback

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
