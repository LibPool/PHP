# restruct/docsys-tools

> 标签: PHP

## 简介

Umbrella package: portable DocSys CLI tool wrappers + system tool paths (GS, convert, soffice)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
