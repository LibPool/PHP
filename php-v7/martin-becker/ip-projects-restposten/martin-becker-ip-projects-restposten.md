# martin-becker/ip-projects-restposten

> 标签: IP-Projects, Restposten API

## 简介

Restposten API Wrapper für die IP-Projects Restposten API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
