# wolnosciowiec/domain-certificate-check

> 标签: PHP

## 简介

A Zend Diagnostics check that notifies about the upcoming expiration of your domains.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
