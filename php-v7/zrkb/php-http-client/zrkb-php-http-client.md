# zrkb/php-http-client

> 标签: Guzzle, api, client, http, json, php, rest

## 简介

Simple PHP HTTP client based on Guzzle for calling JSON RESTful APIs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
