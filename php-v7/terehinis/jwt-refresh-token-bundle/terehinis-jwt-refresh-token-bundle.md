# terehinis/jwt-refresh-token-bundle

> 标签: jwt refresh token bundle symfony json web

## 简介

Implements a refresh token system over Json Web Tokens in Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
