# tentwentyfour/blockdiag-mediawiki-extension

> 标签: diagram, mediawiki

## 简介

Blockdiag wrapper for Mediawiki

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
