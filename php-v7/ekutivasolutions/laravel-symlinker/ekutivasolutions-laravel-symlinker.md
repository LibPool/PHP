# ekutivasolutions/laravel-symlinker

> 标签: PHP

## 简介

Easy symbolic link from 'public/storage' to 'storage/app/public' for Laravel 5.2 and under.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
