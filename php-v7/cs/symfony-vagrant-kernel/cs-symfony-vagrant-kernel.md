# cs/symfony-vagrant-kernel

> 标签: cache, speedup, symfony, vagrant

## 简介

Speeds up Symfony when host source dir is shared over network with Vagrant box.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
