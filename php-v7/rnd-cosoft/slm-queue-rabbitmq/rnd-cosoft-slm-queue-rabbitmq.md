# rnd-cosoft/slm-queue-rabbitmq

> 标签: job, laminas, queue, rabbitmq

## 简介

Laminas Framework module that integrates RabbitMQ as queuing system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
