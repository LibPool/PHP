# rnd-cosoft/queue-doctrine

> 标签: database, db, doctrine, job, laminas, mezzio, queue

## 简介

Laminas Framework module that integrates Doctrine as queuing system

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
