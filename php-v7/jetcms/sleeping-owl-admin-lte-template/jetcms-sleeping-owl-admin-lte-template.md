# jetcms/sleeping-owl-admin-lte-template

> 标签: admin, administrator, crud, laravel, template

## 简介

AdminLTE template for sleeping-owl/admin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
