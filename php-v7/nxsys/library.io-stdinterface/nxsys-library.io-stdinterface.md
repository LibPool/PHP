# nxsys/library.io-stdinterface

> 标签: OOP, StreamHandler, io

## 简介

Composable, extendable, standardizable interfaces to supersede PHP's IO objects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
