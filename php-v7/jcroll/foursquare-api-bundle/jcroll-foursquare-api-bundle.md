# jcroll/foursquare-api-bundle

> 标签: api, client, foursquare

## 简介

Symfony2 bundle for the jcroll/foursquare-api-client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
