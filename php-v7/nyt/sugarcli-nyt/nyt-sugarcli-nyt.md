# nyt/sugarcli-nyt

> 标签: sugarcli, sugarcrm

## 简介

SugarCli is a command line tool to install and manage SugarCRM installations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
