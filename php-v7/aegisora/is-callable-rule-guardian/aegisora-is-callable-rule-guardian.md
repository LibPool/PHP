> 标签: aegisora, aegisora-ecosystem, callable, guardian, is-callable, is-callable-check, is-callable-rule, php, rule, rule-guardian, validation

## 简介

Is Callable Rule Guardian provides a simple shortcut for callable validation using aegisora/guardian and aegisora/is-callable-rule

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
