# rybakit/twig-deferred-extension

> 标签: defer, extension, lazy, override, twig

## 简介

An extension for Twig that allows to defer block rendering.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
