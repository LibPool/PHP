# rybakit/phive-task-queue

> 标签: queue job task worker scheduler priority delayed

## 简介

A lightweight task queue on top of rybakit/phive-queue

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
