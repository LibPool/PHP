# n0nag0n/super-model

> 标签: PHP

## 简介

A simple base model you can extend to reduce your hard coded SQL queries and get 90% of your db requests done quick.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
