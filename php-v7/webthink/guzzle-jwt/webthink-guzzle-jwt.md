# webthink/guzzle-jwt

> 标签: Guzzle, http, jwt, middleware, webthink

## 简介

This package contains useful classes and interfaces for requiring a JWT token

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
