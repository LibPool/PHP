# gemini/waiter

> 标签: coroutine, hyperf, php, swoole, waiter

## 简介

A library which waiting for coroutine to end for Hyperf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
