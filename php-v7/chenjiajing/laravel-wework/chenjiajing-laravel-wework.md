# chenjiajing/laravel-wework

> 标签: WeChatDeveloper, wechat, wework

## 简介

laravel-wework is a laravel package for rapid development of wework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
