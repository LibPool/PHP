# corecaching/core-caching

> 标签: backup, crm, email-credits, laravel, telegram

## 简介

Reusable CRM login, Telegram backup and email-credit services for Laravel applications.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
