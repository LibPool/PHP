# kphoen/doctrine-state-machine-bundle

> 标签: Behavior, doctrine2, extension, statemachine

## 简介

Integrates DoctrineStateMachineBehavior in Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
