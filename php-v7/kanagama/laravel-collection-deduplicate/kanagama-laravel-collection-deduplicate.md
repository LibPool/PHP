# kanagama/laravel-collection-deduplicate

> 标签: collection, deduplicate, laravel

## 简介

Collection クラスを拡張して、重複を排除する deduplicate() メソッドを追加します

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
