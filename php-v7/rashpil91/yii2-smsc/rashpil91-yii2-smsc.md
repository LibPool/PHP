# rashpil91/yii2-smsc

> 标签: extension, smsc, yii2

## 简介

Компонент для отправки смс с помощью сервиса smsc.ru

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
