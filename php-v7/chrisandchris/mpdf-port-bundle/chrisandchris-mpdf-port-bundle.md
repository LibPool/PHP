# chrisandchris/mpdf-port-bundle

> 标签: mpdf, pdf

## 简介

A for of the tfox/mpdf-port-bundle with enhanced response handling

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
