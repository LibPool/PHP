# naif/saudiaddress

> 标签: Saudi Arabia, address, addresses, laravel, national-address, php, saudi, saudiaddress

## 简介

Laravel wrapper for the Saudi National Address APIs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
