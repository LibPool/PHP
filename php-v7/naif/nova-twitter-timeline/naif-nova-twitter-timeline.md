# naif/nova-twitter-timeline

> 标签: laravel, mentions, nova, timeline, tweets, twitter

## 简介

A Laravel Nova card that display the latest user timeline and mentions tweets

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
