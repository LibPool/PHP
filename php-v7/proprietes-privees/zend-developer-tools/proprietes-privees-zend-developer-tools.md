# proprietes-privees/zend-developer-tools

> 标签: debug, developer, module, zf2

## 简介

Module for developer and debug tools for working with the ZF2 MVC layer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
