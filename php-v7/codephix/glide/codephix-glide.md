# codephix/glide

> 标签: ImageMagick, editing, gd, image, imagick, league, manipulation, processing

## 简介

Wonderfully easy on-demand image manipulation library with an HTTP based API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
