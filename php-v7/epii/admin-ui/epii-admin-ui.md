# epii/admin-ui

> 标签: PHP

## 简介

EpiiAdmin php开源交互性管理后台框架,基于Thinkphp5.1+Adminlte3.0+Require.js, 让复杂的交互变得更简单！Phper快速搭建交互性平台的开发框架

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
