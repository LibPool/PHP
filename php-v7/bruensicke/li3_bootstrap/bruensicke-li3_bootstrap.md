# bruensicke/li3_bootstrap

> 标签: bootstrap, css, li3, lithium, twBootstrap, twitter

## 简介

lithium plugin to drive lithium with twitter bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
