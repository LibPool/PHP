# dl/honeypotformfield

> 标签: Forms, Honeypot, Neos, formbuilder, spamprotection

## 简介

Spam protection using a honeypot field for the Neos form builder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
