# yulibo/hyperf-validate

> 标签: framework, hyperf, php, swoole

## 简介

支持request 和方法场景验证，兼容tp5写法 性能比官方验证器提高50%

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
