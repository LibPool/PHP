# emilmoe/bugsnag

> 标签: bugsnag

## 简介

Bugsnag Laravel wrapper adds autoloader and other new Laravel features that isn't included already.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
