# wszdb/flarum-shareurl

> 标签: copy, extension, flarum, link, warning

## 简介

A Flarum plugin that adds external link warning and one-click copy link functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
