# ericychu/aliyun-mns

> 标签: PHP

## 简介

PHP SDK of MNS(Message Service) for Ali Cloud Developer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.aliyun.com
- 源码仓库：https://github.com/EricYChu/aliyun-mns.git
