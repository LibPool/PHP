# ericychu/flarum-ext-bbcode-emoji

> 标签: formatting

## 简介

Convert text and unicode emoji into Twemoji. Only for BBCode WYSIWYG Editor extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
