# okeanos/yii2-chartist

> 标签: charting, chartist, charts, extension, plot, responsive charts, yii2

## 简介

Chartist.js extension for Yii2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
