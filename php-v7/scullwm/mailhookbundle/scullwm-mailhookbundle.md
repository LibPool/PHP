# scullwm/mailhookbundle

> 标签: HOOK, Mailjet, api, bundle, mail, mandrill, sparkpost, symfony, webhook

## 简介

A bundle to catch API webhook from differents mail service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
