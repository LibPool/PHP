# datlechin/flarum-offline-indicator

> 标签: flarum, indicator, offline

## 简介

A simple offline indicator that shows when the user loses internet connection.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
