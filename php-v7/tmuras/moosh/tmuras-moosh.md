# tmuras/moosh

> 标签: cli, moodle, shell

## 简介

Moosh stands for MOOdle SHell. It is a command-line tool that will allow you to perform most common Moodle tasks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
