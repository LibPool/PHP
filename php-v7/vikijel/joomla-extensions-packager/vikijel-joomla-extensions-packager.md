# vikijel/joomla-extensions-packager

> 标签: PHP

## 简介

Library for generating All-In-One install packages (*.zip) with multiple extensions for Joomla! CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
