# madeyourday/contao-rocksolid-theme-assistant

> 标签: contao, themes

## 简介

Contao Extension: Modify colors and other properties of .css.base and other .base files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
