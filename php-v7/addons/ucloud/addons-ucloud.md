# addons/ucloud

> 标签: cdn, l5, laravel, laravel 5, ucloud

## 简介

The package is a class of https://docs.ucloud.cn/api.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
