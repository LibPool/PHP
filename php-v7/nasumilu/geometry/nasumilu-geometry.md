# nasumilu/geometry

> 标签: Polygon, feature, geometry, geometrycollection, gis, linestring, multipoint, multipolygon, point, polyhedralsurface, tin, triangle, well-known binary, well-known text, wkb, wkt

## 简介

Component provides the basic geometry classes used in Geographical Information Systems (GIS).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
