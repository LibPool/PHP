# apokalipscke/webapp-skeleton

> 标签: Skeleton, bootstrap, symfony, webapp, webpack, webpack encore

## 简介

A skeleton to start a new Symfony webapp with bootstrap and webpack encore.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
