# comodojo/rpcserver

> 标签: comodojo, jsonrpc, phprpc, rpc, rpc server, xmlrpc

## 简介

Extensible XML and JSON(2.0) RPC server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
