# joomlatools/logman-zoo

> 标签: extension, joomla, logman, plugins, yootheme, zoo

## 简介

Handles logging of YOOtheme Zoo events

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
