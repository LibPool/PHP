# joomlatools/framework-ckeditor

> 标签: CKEditor, component, joomla, wysiwyg

## 简介

A re-usable component that provides a CKeditor integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
