# joomlatools/logman-mtree

> 标签: extension, joomla, logman, mosets, mtree, plugins, tree

## 简介

Handles logging of Mosets Tree events

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
