# itnelo/reactphp-webdriver

> 标签: php, reactphp, selenium, webdriver

## 简介

An async, W3C compliant PHP client for Selenium Grid server (hub)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
