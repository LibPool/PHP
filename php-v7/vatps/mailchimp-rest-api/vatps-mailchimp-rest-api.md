# vatps/mailchimp-rest-api

> 标签: api, class, mailchimp, php

## 简介

Very Easy to use MailChimp REST Enabled API 3.0 Wrapper Class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
