# aracoool/dhttp

> 标签: client, curl, http, http client, json, php, requests, rest, restful, web service

## 简介

Simple and lightweight HTTP client based cURL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
