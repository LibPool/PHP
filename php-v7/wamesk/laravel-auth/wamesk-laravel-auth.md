# wamesk/laravel-auth

> 标签: PHP

## 简介

OAuth2 authorization with API endpoints. Also includes registration process, login, password reset, email validation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
