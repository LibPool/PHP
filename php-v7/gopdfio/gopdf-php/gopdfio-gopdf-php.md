# gopdfio/gopdf-php

> 标签: api, convert, document, gopdf, html, pdf

## 简介

Convert HTML documents to PDF using the gopdf API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
