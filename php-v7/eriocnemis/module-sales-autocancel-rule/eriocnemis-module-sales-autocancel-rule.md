# eriocnemis/module-sales-autocancel-rule

> 标签: PHP

## 简介

The extension allows store owners to set up rule for an automated cancellation for orders after a specified time.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
