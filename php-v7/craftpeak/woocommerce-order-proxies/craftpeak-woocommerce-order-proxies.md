# craftpeak/woocommerce-order-proxies

> 标签: woocommerce, wordpress

## 简介

A WooCommerce plugin to allow proxies as metadata on a per-order basis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
