# craftpeak/acf-untappd-beer

> 标签: acf, wordpress

## 简介

This is a custom field for ACF which adds an AJAX-powered Untappd Beer Picker.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
