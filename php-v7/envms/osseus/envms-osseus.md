# envms/osseus

> 标签: api, application, fluent, framework, legacy, library, refactor, restful

## 简介

Osseus is a standalone PHP framework / library to update and refactor legacy code

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
