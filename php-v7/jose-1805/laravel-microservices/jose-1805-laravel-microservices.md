# jose-1805/laravel-microservices

> 标签: PHP

## 简介

Paquete para desarrollar aplicaciones basadas en microservicios  (api gateway <-> microservices)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
