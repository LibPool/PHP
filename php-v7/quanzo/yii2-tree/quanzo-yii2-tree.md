# quanzo/yii2-tree

> 标签: adjacency list, adjacency list tree, tree, yii2, yii2 module

## 简介

Ajax tree mapping. Adjacency list tree type. The ability to change the structure.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
