# pearl/csv-json-converter

> 标签: csv, csv to json, data converter, json, json to csv, php

## 简介

Convert CSV to JSON and JSON to CSV file format using PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
