# basantsd/db-backup-laravel-ci

> 标签: daily-backup, database backup, laravel ci backup

## 简介

A Laravel and CI package for daily database backups sent via email

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
