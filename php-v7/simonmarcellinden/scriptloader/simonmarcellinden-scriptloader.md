# simonmarcellinden/scriptloader

> 标签: ScriptLoader, javasdscript, laravel, script, style, stylesheet

## 简介

Package for load dynamically Scripts & Styles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
