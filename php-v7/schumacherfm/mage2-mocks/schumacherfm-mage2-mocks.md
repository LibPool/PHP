# schumacherfm/mage2-mocks

> 标签: PHP

## 简介

This Magento2 module provides mock classes when you have physically removed unneeded modules with dependencies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
