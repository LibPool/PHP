# ischenko/yii2-jsloader-requirejs

> 标签: Behavior, assets, requirejs, view, yii2

## 简介

An Yii2 extension that allows to handle asset bundles via requirejs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
