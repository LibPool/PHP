# poa/httprouter

> 标签: framework, generator, middleware, poa, router

## 简介

基于POA洋葱圈模型的路由器中间件，通过实现路由规则来定制路由器具体的动作

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
