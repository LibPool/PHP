# gdadesenv/admindomain

> 标签: PHP

## 简介

Pacote Laravel para adiministrar os 'Domínios' dentro do GDA Admin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
