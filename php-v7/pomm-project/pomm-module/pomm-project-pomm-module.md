# pomm-project/pomm-module

> 标签: module, pomm2, zf2

## 简介

Zend Framework 2 Module that provides Pomm2 basic functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
