# common-gateway/customer-notifications-bundle

> 标签: common, common-gateway-plugin, commongateway, conduction, customer, gateway, notifications, symfony

## 简介

A bundle containing logic for handling notifications & sending email/sms messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
