# c006/yii2-paypal-ipn

> 标签: extension, ipn, paypal, yii2

## 简介

This is a simple PayPal IPN listener, no other files required.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
