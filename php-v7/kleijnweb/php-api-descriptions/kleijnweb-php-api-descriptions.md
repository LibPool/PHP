# kleijnweb/php-api-descriptions

> 标签: openapi, swagger

## 简介

A PHP7 library for loading api descriptions and using them to validate PSR7 messages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
