# afsardo/getid3

> 标签: getid3, metadata, tags

## 简介

This package integrates the GetId3 library with the Symfony2 project, emulating the PSR-0 CS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
