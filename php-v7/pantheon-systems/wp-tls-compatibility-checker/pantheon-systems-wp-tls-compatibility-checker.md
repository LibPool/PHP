# pantheon-systems/wp-tls-compatibility-checker

> 标签: PHP

## 简介

A scanner for outgoing HTTP requests in WordPress code to check TLS 1.2/1.3 compatibility.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
