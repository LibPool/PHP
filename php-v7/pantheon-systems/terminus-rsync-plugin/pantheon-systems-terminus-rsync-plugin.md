# pantheon-systems/terminus-rsync-plugin

> 标签: PHP

## 简介

Rsync - Terminus Plugin that provides a quick shortcut for rsync-ing files to and from a Pantheon site.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
