# pantheon-systems/terminus-carbon-plugin

> 标签: PHP

## 简介

A Terminus plugin for fetching carbon impact and other sustainability data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
