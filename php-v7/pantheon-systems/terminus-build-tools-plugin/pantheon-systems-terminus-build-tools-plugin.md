# pantheon-systems/terminus-build-tools-plugin

> 标签: PHP

## 简介

Build Tools - A Terminus plugin that contain commands to manage build assets on Pantheon.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
