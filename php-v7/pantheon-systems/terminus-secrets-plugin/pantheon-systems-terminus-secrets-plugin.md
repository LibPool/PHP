# pantheon-systems/terminus-secrets-plugin

> 标签: PHP

## 简介

Secrets - A Terminus plugin that allows for manipulation of a 'secrets' file for use with Quicksilver.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
