# franjsco/bitcoinfees

> 标签: api, bitcoin, cryptocurrency, fee

## 简介

A PHP package to fetch Bitcoin fee predictions from bitcoinfees.earn.com

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
