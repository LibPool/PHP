# phpxmlrpc/extras

> 标签: jsonrpc, webservices, xmlrpc

## 简介

A collection of server-side addons that might be of use for development of xml-rpc (and json-rpc) based applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
