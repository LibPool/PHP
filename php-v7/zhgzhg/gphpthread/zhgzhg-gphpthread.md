# zhgzhg/gphpthread

> 标签: Thread, async, asynchronous, concurrent, fork, multithreading, parallel, pcntl, posix, promise, shell

## 简介

Generic PHP Threads library using only pure PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
