# foogile/nb-remote-phpunit

> 标签: netbeans, phpunit, remote, vagrant

## 简介

Execute PHPUnit tests over ssh using NetBeans

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
