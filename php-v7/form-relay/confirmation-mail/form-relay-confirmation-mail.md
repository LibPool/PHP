# form-relay/confirmation-mail

> 标签: Relay, data, email, form, formhandler, framework, mail, submission

## 简介

FormRelay route for (formatted) confirmation emails.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
