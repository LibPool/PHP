# securiscan/gauth

> 标签: Guzzle, authorization, laravel, lumen

## 简介

This package adds a request authorization layer to the Guzzle client which currently supports Oauth2 and Passport.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
