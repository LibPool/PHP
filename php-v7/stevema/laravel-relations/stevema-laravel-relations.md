# stevema/laravel-relations

> 标签: laravel, map, model-relation, morph, relation, relations

## 简介

laravel的模型关系管理 项目中一堆模型的关系 管理起来很不舒服 写个插件专门做关系管理

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
