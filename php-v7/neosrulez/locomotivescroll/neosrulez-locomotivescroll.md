# neosrulez/locomotivescroll

> 标签: PHP

## 简介

A Neos CMS package to use Locomotive Scroll (https://locomotivemtl.github.io/locomotive-scroll/)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
