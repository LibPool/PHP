# neosrulez/tinypng

> 标签: PHP

## 简介

A package to automate your JPEG and PNG compression workflow with the TinyPNG API in Neos CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
