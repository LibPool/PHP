# nitropack/magento2-extension

> 标签: cache, cdn, cloud, cwv, ecommerce, extension, magento2, nitropack, performance, speed

## 简介

The official NitroPack extension for Magento 2.3 and Magento 2.4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
