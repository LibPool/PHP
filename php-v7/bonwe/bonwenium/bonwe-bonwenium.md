# bonwe/bonwenium

> 标签: PHP

## 简介

基于改装的webdriver,selenium思想，采用模块化封装的php自动化测试框架。开发者只需要掌握基础前端知识，基础php知识，就能通过精简的开发实现复杂自动化测试，大幅度提升开发效率，降低自动化测试门槛。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
