# yeroon/doctrine-fictures-extra-bundle

> 标签: doctrine-fixtures, fixtures

## 简介

Adds a command to validate, drop and create schema and load fixtures in one go.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
