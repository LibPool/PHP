# proxiedmail/laravel-receive-email

> 标签: PHP

## 简介

Laravel Receive Email via ProxiedMail library allows creating proxy-emails and receiving emails via webhooks, Rest API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
