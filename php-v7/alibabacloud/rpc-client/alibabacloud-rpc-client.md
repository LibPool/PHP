# alibabacloud/rpc-client

> 标签: alibaba, alibabacloud, client, rpc

## 简介

Alibaba Cloud RPC Client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
