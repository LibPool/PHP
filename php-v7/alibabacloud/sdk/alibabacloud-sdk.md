# alibabacloud/sdk

> 标签: alibaba, alibabacloud, aliyun, cloud, library, sdk, 云服务, 阿里云

## 简介

Alibaba Cloud SDK for PHP - Easier to Use Alibaba Cloud in your PHP project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
