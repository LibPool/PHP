# wisembly/jsgettext

> 标签: gettext.js, handlebars, i18n, parser, po2json, poEdit, xgettext

## 简介

Javascript poEdit parser written in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
