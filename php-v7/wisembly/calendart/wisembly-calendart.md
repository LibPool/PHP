# wisembly/calendart

> 标签: Agenda, calendar, events, schedule, scheduler

## 简介

Manage remote calendars (google, office 365, ...) through an unified api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
