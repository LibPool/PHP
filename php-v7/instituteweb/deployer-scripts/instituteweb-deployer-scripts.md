# instituteweb/deployer-scripts

> 标签: PHP

## 简介

PHP deployer scripts (deployer.org) to build local and deploy remote iw_master TYPO3 distribution.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
