# drewlabs/curl-rest-client

> 标签: PHP

## 简介

Built on top of curl client library, it offers REST supported HTTP verbs for sending request to backend service.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
