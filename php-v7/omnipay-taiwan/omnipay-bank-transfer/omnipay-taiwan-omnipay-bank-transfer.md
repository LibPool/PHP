# omnipay-taiwan/omnipay-bank-transfer

> 标签: bank-transfer, omnipay

## 简介

BankTransfer driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
