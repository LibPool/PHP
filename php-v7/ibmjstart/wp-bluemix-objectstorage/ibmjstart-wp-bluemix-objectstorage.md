# ibmjstart/wp-bluemix-objectstorage

> 标签: bluemix, object, objectstorage, softlayer, storage

## 简介

WordPress plugin to use IBM Object Storage for media

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
