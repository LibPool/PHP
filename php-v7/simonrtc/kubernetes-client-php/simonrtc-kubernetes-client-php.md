# simonrtc/kubernetes-client-php

> 标签: api, client, k8s, kubernetes, php, rest

## 简介

Kubernetes API client in PHP supporting REST operations and Watches

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
