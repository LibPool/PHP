# phelium/encryptor

> 标签: decrypt, encrypt, encryption, hash, openssl, security

## 简介

A simple PHP encryption and decryption class with OpenSSL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
