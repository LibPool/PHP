# paysera/lib-wallet-bundle

> 标签: Paysera, payments, wallet, wallet api

## 简介

Symfony2 bundle for integration with Paysera Wallet API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
