# uran1980/php-electrum-api

> 标签: api, bitcoin, electrum, jsonrpc, payment

## 简介

PHP wrapper for Electrum JSONRPC-API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
