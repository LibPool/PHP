# uran1980/yii2-code-prettify

> 标签: code prettify, code syntax highlighter, yii2

## 简介

Yii2 Code syntax highlighter based on Google-Code-Prettify library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
