# bizley/contenttools

> 标签: contenttools, editor, extension, html, widget, wysiwyg, yii2

## 简介

ContentTools editor implementation for Yii 2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
