# ttlphp/workerman-annotation

> 标签: gateway-worker, workerman, workerman-annotation

## 简介

基于GatewayWorker注解处理，通过注解解析绑定各模块调用，并且提供HTTP协议支持。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
