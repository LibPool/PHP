# humanmade/hm-rewrite

> 标签: PHP

## 简介

HM_Rewrite is a wrapper for the WordPress WP Rewrite system. http://hmn.md/wordpress-rewrite-rules-hm-core-style/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
