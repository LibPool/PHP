# humanmade/clean-up-leftover-multi-meta

> 标签: PHP

## 简介

Remove duplicate meta values for any single meta key with multiple meta value rows in the database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
