# humanmade/hm-social-share-links

> 标签: PHP

## 简介

Wires the core Social Links block up to dynamic, per-page share-intent URLs (Facebook, X, LinkedIn, WhatsApp, Reddit, Pinterest, email) via the Block Bindings API, plus a ready-made pattern to insert them.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
