# yfktn/tulisan

> 标签: PHP

## 简介

October CMS Plugin untuk fasilitas menulis konten dengan fitur berlimpah namun tetap berpenampilan sederhana.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
