# jonassiewertsen/statamic-cookie-consent

> 标签: addon, consent, cookie, statamic

## 简介

A Statamic cookie consent wrapper for the Spatie package 'laravel-cookie-consent'

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
