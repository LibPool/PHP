# sana/yii2-image-by-url

> 标签: extension, image, url, yii2

## 简介

Расширение для загрузки картинки по URL (jpg, png, gif).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
