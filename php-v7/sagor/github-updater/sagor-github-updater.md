# sagor/github-updater

> 标签: artisan, git, github, laravel, updater

## 简介

A Laravel package for automated Github pulls and Artisan commands by moh-sagor.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
