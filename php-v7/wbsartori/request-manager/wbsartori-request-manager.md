# wbsartori/request-manager

> 标签: PHP

## 简介

Request Manager is a PHP HTTP client library containing the abstraction of the Guzzle and PhpCurlClass libraries

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
