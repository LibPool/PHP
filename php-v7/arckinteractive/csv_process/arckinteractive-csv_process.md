# arckinteractive/csv_process

> 标签: csv, elgg, import, plugin

## 简介

Provides an interface for uploading/processing csvs with custom callbacks for other plugins

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
