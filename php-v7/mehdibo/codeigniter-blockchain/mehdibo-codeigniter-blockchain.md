# mehdibo/codeigniter-blockchain

> 标签: blockchain, blockchain api, blockchain wallet, codeigniter

## 简介

A CodeIgniter library to use the Blockchain Wallet API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
