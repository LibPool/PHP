# phpzlc/document-bundle

> 标签: api-doc, api-document, doc, document, phpzlc, symfony

## 简介

文档组件，用于编写接口文档,通过命令生成,在线的,可测试,可交付的技术文档。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
