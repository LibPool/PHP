# inkline/inkline

> 标签: PHP

## 简介

Inkline is a modern UI/UX framework for Vue.js, designed for creating flawless content-rich responsive web applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
