# blobfolio/blob-phone

> 标签: formatting, libphonenumber, phone, php

## 简介

A light(er)weight implementation of Google's amazing libphonenumber for PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
