# blobfolio/blob-common

> 标签: data, formatting, parsing, php, sanitizing

## 简介

An expansive PHP toolkit with functions for sanitizing, formatting, parsing, etc.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
