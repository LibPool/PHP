# caseyamcl/wosclient

> 标签: caseyamcl, ddn, storage, web object scalar, wos, wosclient

## 简介

A portable PHP client library to access data in a DDN (WOS) Web Object Scalar API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
