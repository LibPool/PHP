> 标签: Tronapifull, USDT, blockchain, energy, staking, trc20, tron, tron-api, tron-lib, tron-php, 区块链, 波场

## 简介

增强版波场（TRON）API接口库，提供更完善的功能和更稳定的表现，简化TRON区块链应用开发

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
