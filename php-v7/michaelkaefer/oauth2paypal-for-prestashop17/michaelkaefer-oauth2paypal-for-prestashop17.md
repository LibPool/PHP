# michaelkaefer/oauth2paypal-for-prestashop17

> 标签: oauth, oauth2, paypal, php, prestashop

## 简介

Enables you in PrestaShop 1.7 to use oauth2-paypal.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
