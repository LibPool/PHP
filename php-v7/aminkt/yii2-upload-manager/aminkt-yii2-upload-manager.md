# aminkt/yii2-upload-manager

> 标签: manager, module, upload, upload manager, yii

## 简介

Upload manager system based and inspired from Wordpress upload manager.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
