# eadortsu/eloquent-datatable

> 标签: datatable, eloquent, laravel

## 简介

Eloquent DataTable plugin for server side ajax call handling.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
