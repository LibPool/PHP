# digitalerase/wp-remote-users-sync

> 标签: plugin, wordpress

## 简介

Synchronise users automatically and securely between multiple wordpress sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
