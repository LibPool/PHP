# digitalerase/deployer-extended-wordpress-composer

> 标签: bedrock, composer, deployer, roots, wordpress

## 简介

Composer based WordPress deployment with deployer.org.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
