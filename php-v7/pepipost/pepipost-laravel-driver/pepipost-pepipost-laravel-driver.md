# pepipost/pepipost-laravel-driver

> 标签: laravel, laravel mail driver, pepipost

## 简介

This library adds a 'pepipost' mail driver to Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
