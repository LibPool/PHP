# sourcebroker/t3apitranslatr

> 标签: PHP

## 简介

Bridge between ext:t3api and ext:translatr which allows to get language labels as JSON.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
