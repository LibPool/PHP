# iamntz/wp-vite-manifest

> 标签: PHP

## 简介

Add support for vite manifest inside wp so you can load assets from generated vite manifest and have HMR enabled.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
