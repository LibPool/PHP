# iamntz/carbon-fields-urlpicker

> 标签: carbon-field, carbon-fields-urlpicker, wordpress

## 简介

Carbon Fields extension that adds a URL picker field type.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
