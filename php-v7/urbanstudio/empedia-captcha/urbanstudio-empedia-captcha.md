# urbanstudio/empedia-captcha

> 标签: bot-protection, captcha, gdpr, privacy, spam

## 简介

SDK für EMPEDIAcaptcha: Bot-Prüfung (siteverify), Inhaltsprüfung (check) und Widget-Helfer. Ohne Abhängigkeiten.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
