# tecksolke-tpay/client-api

> 标签: PHP

## 简介

This api is client based, makes requests to the clients apps and accounts. Also has t-pay m-pesa API's

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
