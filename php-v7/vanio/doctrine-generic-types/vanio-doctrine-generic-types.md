# vanio/doctrine-generic-types

> 标签: doctrine, doctrine2, generic types, generics

## 简介

An extension for Doctrine2 DBAL allowing usage of generic types

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
