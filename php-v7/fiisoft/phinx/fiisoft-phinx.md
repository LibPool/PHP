# fiisoft/phinx

> 标签: console, migration, phinx

## 简介

Console-commands to use Phinx's library console-commands in custom console application (based on symfony/console package).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
