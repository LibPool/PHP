# makinacorpus/drupal-ulog

> 标签: PHP

## 简介

Minimalistic module that replaces Drupal 7 error handler to provide full stack trace for errors

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
