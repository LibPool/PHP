# eduardoboucas/wp-api-post-groups

> 标签: PHP

## 简介

Allows multiple groups of posts with different filters to be obtained from the WP-API in a single request

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
