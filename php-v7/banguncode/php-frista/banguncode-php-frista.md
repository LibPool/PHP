# banguncode/php-frista

> 标签: Facial Recognition, bpjs, bridging, frista

## 简介

A simple PHP library for BPJS Kesehatan facial recognition integration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
