# banguncode/php-icare

> 标签: bpjs, bridging, icare, jkn

## 简介

A simple PHP library for accessing the healthcare history of JKN participants.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
