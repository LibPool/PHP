# cav-s-a/nova-advanced-command-runner

> 标签: artisan, bash, commands, laravel, nova, shell

## 简介

Laravel Nova tool for running Artisan and bash(shell) commands.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
