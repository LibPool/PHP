# redcatphp/templix

> 标签: CSS3 Selectors, HTML5, Recursive Extends, Template Motor, Templix, dom, jquery, template, template engine, xml

## 简介

Templix - HTML5 based Template Engine with Recursive Extends and CSS3 Selectors to work on DOM like with Jquery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
