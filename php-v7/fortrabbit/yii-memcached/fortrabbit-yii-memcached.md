# fortrabbit/yii-memcached

> 标签: cache, caching, craftcms, memcache, memcached, mutex, session, yii2

## 简介

Memcached Session & Cache for Craft CMS / Yii2 on fortrabbit

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
