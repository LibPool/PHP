# gaxz/yii2-cron-manager

> 标签: Tasks, background, cron, crontab, manager, module, yii2

## 简介

Simple and flexible background tasks manager module for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
