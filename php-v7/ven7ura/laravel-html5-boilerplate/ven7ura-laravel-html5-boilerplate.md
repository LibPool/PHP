# ven7ura/laravel-html5-boilerplate

> 标签: HTML5, boilerplate, layout, template

## 简介

HTML5 Boilerplate template integrated to Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
