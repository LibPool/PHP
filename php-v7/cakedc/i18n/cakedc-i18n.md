# cakedc/i18n

> 标签: cakephp, i18n

## 简介

I18n Plugin for CakePHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://cakedc.com
- 源码仓库：https://github.com/CakeDC/i18n.git
- Packagist 页面：https://packagist.org/packages/cakedc%2Fi18n

## 历史版本号

- 当前版本：1.2.0

- 1.2.0

## 获取地址

- Composer 安装：`composer require cakedc/i18n`
- Packagist 仓库：https://repo.packagist.org/p2/cakedc/i18n.json
- 许可证：MIT
- PHP 要求：>=5.2.8
