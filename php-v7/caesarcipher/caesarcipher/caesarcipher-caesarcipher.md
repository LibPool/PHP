# caesarcipher/caesarcipher

> 标签: Caesar cipher, cipher

## 简介

A PHP package for encoding, decoding and cracking the Caesar shift cipher

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
