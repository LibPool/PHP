# parenthesis/dingconnect-api-php

> 标签: api, dingconnect, php, sdk, swagger

## 简介

A PHP Client for the  DingConnect Mobile Top-Up API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
