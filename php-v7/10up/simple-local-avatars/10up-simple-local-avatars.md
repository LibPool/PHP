# 10up/simple-local-avatars

> 标签: 10up, wordpress

## 简介

Adds an avatar upload field to user profiles. Generates requested sizes on demand just like Gravatar!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
