# bgaze/bootstrap4-dialogs

> 标签: alert, bootstrap, confirm, dialogs, javascript, jquery, prompt

## 简介

A collection of flexible dialogs based on Bootstrap 4 modals

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
