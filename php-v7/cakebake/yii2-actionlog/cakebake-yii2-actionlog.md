# cakebake/yii2-actionlog

> 标签: actionlog, activerecord, extension, log, yii2

## 简介

Logs user actions like create, read, update, delete and custom

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
