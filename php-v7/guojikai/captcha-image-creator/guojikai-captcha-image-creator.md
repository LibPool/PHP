# guojikai/captcha-image-creator

> 标签: Chinese, captcha

## 简介

A captcha image creator,written by PHP. 一个PHP写的支持的中文的验证码图片生成工具，仅生成验证码图片不进行缓存，需二次封装使用。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
