# yongtiger/yii2-admin

> 标签: admin, extension, rbac, yii2

## 简介

GUI manager for RABC (Role Base Access Control) Yii2. Easy to manage authorization of user

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
