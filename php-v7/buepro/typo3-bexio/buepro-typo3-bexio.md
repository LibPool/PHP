# buepro/typo3-bexio

> 标签: bexio, bookkeeping, cms, typo3

## 简介

Provides console commands and an API to interact with Bexio resources and emits events when invoices get paid.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
