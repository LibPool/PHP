# justintime50/phpcs-short-scalar-types

> 标签: PHP

## 简介

PHPCS sniff to enforce short scalar type names in comments (bool, int, etc.)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
