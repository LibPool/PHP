# rafsouza/mrk-jwt

> 标签: .env, jwt, jwt-token

## 简介

Este componente PHP oferece métodos para manipulação de JWT e JWK em arquivos .env

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
