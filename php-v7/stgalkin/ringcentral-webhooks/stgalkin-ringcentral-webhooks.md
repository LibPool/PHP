# stgalkin/ringcentral-webhooks

> 标签: Glip, php, ringcentral, webhook

## 简介

Simple wrapper for https://ringcentral.com/ using webhooks

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
