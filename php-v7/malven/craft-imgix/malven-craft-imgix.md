# malven/craft-imgix

> 标签: Craft, cms, craft-plugin, craftcms, imgix

## 简介

Tools for working with the Imgix image-generation service in Craft

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
