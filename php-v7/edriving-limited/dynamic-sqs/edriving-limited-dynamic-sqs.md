# edriving-limited/dynamic-sqs

> 标签: dynamic-sqs, edriving-limited, laravel

## 简介

Adds support for custom SQS payloads in Laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
