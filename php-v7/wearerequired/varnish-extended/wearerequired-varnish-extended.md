# wearerequired/varnish-extended

> 标签: cache, purge, varnish, wordpress

## 简介

WordPress plugin to extend Varnish HTTP Purge to purge the cache on multiple backends.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
