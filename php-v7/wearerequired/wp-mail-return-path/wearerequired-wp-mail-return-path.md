# wearerequired/wp-mail-return-path

> 标签: return-path, spf, wordpress, wp-mail

## 简介

WordPress mu-plugin to set sender/return path for mail if not set..

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
