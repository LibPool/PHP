# wearerequired/register-default-theme-directory

> 标签: themes, wordpress

## 简介

WordPress mu-plugin to register the theme directory for the default WordPress themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
