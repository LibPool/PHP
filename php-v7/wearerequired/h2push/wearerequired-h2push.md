# wearerequired/h2push

> 标签: http2, server-push, wordpress

## 简介

Sends Link headers to bring HTTP/2 Server Push for scripts and styles to WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
