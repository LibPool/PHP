# simplesamlphp/simplesamlphp-module-aggregator

> 标签: SAML2, metadata

## 简介

A SAML 2.0 metadata aggregator for SimpleSAMLphp.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
