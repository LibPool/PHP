# simplesamlphp/simplesamlphp-module-riak

> 标签: riak, simplesamlphp

## 简介

A module that is able to store key/value pairs in a Riak store

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
