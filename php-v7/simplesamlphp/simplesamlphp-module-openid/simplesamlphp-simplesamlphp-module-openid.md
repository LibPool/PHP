# simplesamlphp/simplesamlphp-module-openid

> 标签: OpenId, consumer

## 简介

A SimpleSAMLphp module adding support for the OpenID protocol.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
