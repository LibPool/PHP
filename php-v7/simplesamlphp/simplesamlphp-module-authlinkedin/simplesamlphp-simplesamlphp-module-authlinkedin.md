# simplesamlphp/simplesamlphp-module-authlinkedin

> 标签: linkedin, simplesamlphp

## 简介

A module that is able to authenticate against LinkedIn

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
