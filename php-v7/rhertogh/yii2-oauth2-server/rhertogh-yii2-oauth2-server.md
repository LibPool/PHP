# rhertogh/yii2-oauth2-server

> 标签: OpenID Connect, oauth 2, yii2

## 简介

A Yii2 Oauth 2 and OpenID Connect server based on thephpleague/oauth2-server

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
