# z_bodya/yii-coordinatepicker

> 标签: coordinate, maps, user interface, widget

## 简介

Widget to pick coordinates using google map in modal window

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
