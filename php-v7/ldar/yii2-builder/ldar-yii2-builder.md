# ldar/yii2-builder

> 标签: builder, extension, form, widget, yii2

## 简介

Build forms (single-row or multi-row/tabular) easily for Yii Framework 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
