# namelesscoder/typo3-repository-client

> 标签: PHP

## 简介

Client for interacting with the official TYPO3 Extension Repository (TER). Contains API and CLI scripts.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
