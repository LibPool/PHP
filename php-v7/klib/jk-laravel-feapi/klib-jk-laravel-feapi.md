# klib/jk-laravel-feapi

> 标签: PHP

## 简介

一个简单的支持RESTful接口的前后端组件模块，从JKGlib框架下移植到Laravel框架

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
