# oldcodefork/isocountries

> 标签: countries, iso2, iso3

## 简介

IsoCountries - a simple class for managing ISO2 and ISO3 countries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
