# kesha-dev/sortable

> 标签: extension, gridview, sortable, widget, yii2

## 简介

Yii2 GridView widget base on jQuery UI sortable widget

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
