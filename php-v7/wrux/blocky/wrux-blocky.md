# wrux/blocky

> 标签: Craft, block parser, cms, craft-plugin, craftcms

## 简介

Map a matrix field into an array of blocks to render in twig.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
