# bebound/sdk-php

> 标签: Be-Bound, handler, middleware, n4b, psr-15, push, sdk, webhook

## 简介

Simple library to implement Be-Bound on a PHP 7 backend

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
