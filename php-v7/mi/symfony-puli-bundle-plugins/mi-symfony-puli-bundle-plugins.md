# mi/symfony-puli-bundle-plugins

> 标签: bundle, plugin, puli, symfony

## 简介

Extend BundleWithPlugins to use Puli as Class Discovery

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
