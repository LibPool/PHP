# teameero/pami

> 标签: action, ami, asterisk, client, event, manager, monitor, telephony, voip

## 简介

Asterisk Manager Interface (AMI) (Asterisk 16.16.0) client for PHP, event driven, object oriented

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
