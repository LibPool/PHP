# coreation/php-shapefile

> 标签: ESRI, Shapefile, dbf, shape, shp

## 简介

PHP library to read any ESRI Shapefile and its associated DBF into a PHP Array or WKT

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
