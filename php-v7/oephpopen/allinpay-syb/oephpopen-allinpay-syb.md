# oephpopen/allinpay-syb

> 标签: Allinpay, alipay, payment, syb, unionpay, wechat, 收银宝, 通联支付

## 简介

Allinpay SYB (通联收银宝) payment SDK. Supports unified pay / query / refund / cancel / close, H5 cashier (onepay) & H5 unionorder with RSA (SHA1) / RSA2 (SHA256) / SM2 signing and SM4 sensitive-field encryption. Zero framework dependency, PHP 7.2+ compatible.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
