# zeal-io/namespace-placeholder

> 标签: namespace, placeholder, reserved, security

## 简介

Reserved namespace placeholder. Holds the 'zeal-io' vendor on Packagist so that internal package names cannot be registered by a third party. Not for public use.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
