# manticoresoftware/php-sql-parser

> 标签: creator, mysql, parser, sql

## 简介

A pure PHP SQL (non validating) parser w/ focus on MySQL dialect of SQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
