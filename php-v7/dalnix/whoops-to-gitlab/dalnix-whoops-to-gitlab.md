# dalnix/whoops-to-gitlab

> 标签: api, git, gitlab, laravel

## 简介

A possibility to allow your users to send an issue to gitlab upon Whoops

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
