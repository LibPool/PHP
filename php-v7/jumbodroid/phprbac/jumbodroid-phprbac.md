# jumbodroid/phprbac

> 标签: authorization, laravel, php, rbac

## 简介

PHP RBAC is a wrapper around the OWASP/rbac package to support the Laravel framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
