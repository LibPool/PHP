# onedesign/oneshipstation

> 标签: Craft, plugin, shipstation

## 简介

A Craft CMS plugin for integrating Craft Commerce with ShipStation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
