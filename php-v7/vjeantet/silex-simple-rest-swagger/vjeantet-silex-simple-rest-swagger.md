# vjeantet/silex-simple-rest-swagger

> 标签: api, framework, rest, silex, swagger

## 简介

A simple silex skeleton for rest api with swagger documentation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
