# saeven/zf2-circlical-trans

> 标签: i18n, trans, translator, twig, zf2

## 简介

ZF3 module that glues Twig's {% trans %} and the standard translator together

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
