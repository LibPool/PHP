# saeven/zf2-purifier

> 标签: Purifier, filter, html, purify, zf2

## 简介

HTML Purifier as filter and view helper for Zend Framework 2.5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
