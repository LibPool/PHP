# saeven/circlical-twig-extractor

> 标签: PHP

## 简介

The Twig Gettext Extractor is Poedit friendly tool which extracts translations from twig templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
