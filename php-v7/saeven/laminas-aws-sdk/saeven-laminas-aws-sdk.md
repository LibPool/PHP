# saeven/laminas-aws-sdk

> 标签: amazon, aws, cloudfront, dynamodb, ec2, s3, sqs, zend, zf2

## 简介

Laminas Module that allows easy integration the AWS SDK for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
