# anroots/pgca

> 标签: commit, commit analysis, commit message, git, pgca

## 简介

Analyzes Git commit messages for poor committing practices and reports a list of violations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
