# jvelletti/jvchat

> 标签: TYPO3 CMS, chat room, jvchat

## 简介

jv chat , made vjchat compatible for TYPO3 LTS 13.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
