# jvelletti/jv-deepltranslate-piflexform

> 标签: PHP

## 简介

Extends the extension wv_deepltranslate to handle translations of flexforms.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
