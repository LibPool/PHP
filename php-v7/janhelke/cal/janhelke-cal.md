# janhelke/cal

> 标签: PHP

## 简介

A calendar combining all the functions of the existing calendar extensions plus adding some new features. It is based on the ical standard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
