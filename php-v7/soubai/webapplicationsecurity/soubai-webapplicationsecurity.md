# soubai/webapplicationsecurity

> 标签: PHP

## 简介

WebSecurity is a PHP class to Help Devlopper to prevent a almost webapplication security fails

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
