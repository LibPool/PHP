# hasokeyk/yurt-ici-kargo

> 标签: PHP

## 简介

Bu kütüphane ile php alt yapılı sisteminize "yurt içi kargo" firmasına ait kargo işlemlerinizi entegre edebilirsiniz.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
