# lvlup-dev/screenshot-api-laravel

> 标签: PHP

## 简介

Uses screenshotapi.net to easily fetch screenshots from urls.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
