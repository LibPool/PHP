# elidrissidev/magento-api2basicauth

> 标签: magento, magento-module, openmage, openmage-module

## 简介

HTTP Basic authentication support for Magento 1.9 and OpenMage's Api2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
