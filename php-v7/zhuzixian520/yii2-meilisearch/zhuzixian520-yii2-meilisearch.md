# zhuzixian520/yii2-meilisearch

> 标签: extension, yii2

## 简介

This extension provides the MeiliSearch integration for the Yii framework 2.0.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
