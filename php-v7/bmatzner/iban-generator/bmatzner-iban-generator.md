# bmatzner/iban-generator

> 标签: BBAN, BIC, IBAN, sepa, swift

## 简介

Generates IBAN code from bank code and bank account number

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
