# webempresario/api-sii-chile

> 标签: api, chile, contribuyente, empresas, geocoding, rut, sii, tax

## 简介

Cliente PHP para la API SII Chile: consulta empresas chilenas por RUT (razón social, giro, actividades económicas, domicilios con coordenadas GPS incluidas).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
