# olafnorge/console-mutex

> 标签: command, console, laravel, locker, mutex, overlapping

## 简介

Prevents overlapping for Laravel console commands.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
