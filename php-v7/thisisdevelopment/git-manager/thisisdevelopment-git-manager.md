# thisisdevelopment/git-manager

> 标签: PHP

## 简介

Provides a uniform api to access and manage repositories / team / users for all major git platforms (github/gitlab/gitea/bitbucket)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
