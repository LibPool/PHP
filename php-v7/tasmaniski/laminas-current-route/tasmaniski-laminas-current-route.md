# tasmaniski/laminas-current-route

> 标签: helper, laminas framework, route, view

## 简介

View Helper for reading current route info: Controller, Action, Module name

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
