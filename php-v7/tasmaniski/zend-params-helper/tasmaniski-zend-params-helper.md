# tasmaniski/zend-params-helper

> 标签: Zend Framework, helper, laminas framework, params, view

## 简介

View Helper for reading data from $_GET, $_POST and Routes in view

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
