# aiviemarketing/mautic-recaptcha

> 标签: Mautic, aivie, integration, plugin

## 简介

This plugin brings reCAPTCHA integration to Aivie and mautic.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
