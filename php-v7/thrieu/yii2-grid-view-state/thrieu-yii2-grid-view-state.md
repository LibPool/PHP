# thrieu/yii2-grid-view-state

> 标签: extension, filter, gridview, widget, yii2

## 简介

Save filters from GridView to session, keep the filter state between pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
