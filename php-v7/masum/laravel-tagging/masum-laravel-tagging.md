# masum/laravel-tagging

> 标签: auto-generate, laravel, polymorphic, tagging, tags

## 简介

A flexible Laravel package for automatic tag generation and management for any model

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
