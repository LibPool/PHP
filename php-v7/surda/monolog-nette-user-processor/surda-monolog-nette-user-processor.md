# surda/monolog-nette-user-processor

> 标签: diagnostics, log, logging, monolog, nette, processor

## 简介

Adds extra data about the current user to the log message.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
