# dekiakbar/indonesia-regions-php-client

> 标签: api, bps, indonesia, php, region

## 简介

This package will retrieve and extract regions of Indonesia from https://bps.go.id

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
