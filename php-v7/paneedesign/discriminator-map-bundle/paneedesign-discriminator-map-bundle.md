# paneedesign/discriminator-map-bundle

> 标签: bundle, discriminator, doctrine, orm, php, symfony

## 简介

Dynamic DiscriminatorMap extender for Symfony with Doctrine ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
