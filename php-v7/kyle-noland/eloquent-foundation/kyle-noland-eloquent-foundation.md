# kyle-noland/eloquent-foundation

> 标签: PHP

## 简介

A set of base classes for working with Laravel Eloquent Repositories, Models, Collections and Observers

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
