# smart-gamma/symfony-errors-telegram-bot

> 标签: PHP

## 简介

The Telegram bot allows to send notifications about Symfony critical errors to the configured project's chat

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
