# alexluke/grunt-haml-php

> 标签: HAML, grunt, gruntplugin, mthaml, php

## 简介

Process HAML templates using MtHaml, a PHP port of Haml.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
