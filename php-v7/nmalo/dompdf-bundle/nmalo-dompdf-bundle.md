# nmalo/dompdf-bundle

> 标签: bundle, development, symfony

## 简介

A wrapper for using DomPDF inside Symfony 2 (fork from SlikNL/DompdfBundle)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
