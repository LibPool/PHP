# lch/breadcrumb-bundle

> 标签: breadcrumb, microdata, rdfa

## 简介

Provide event-oriented logic to normalize breadcrumbs, and RFDa/microdata minimal presentation

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
