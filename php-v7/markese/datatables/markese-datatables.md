# markese/datatables

> 标签: Markese, datatables

## 简介

Create HTTP responses compatible with Datatables for JQuery from Eloquent Models, Query Builders, and Laravel Collections.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
