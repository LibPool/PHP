# sayedenam/sayed-dashboard

> 标签: PHP

## 简介

A complete admin dashboard package for Laravel applications with user management, RBAC, and CRUD generation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
