# leizongmin/leiphp

> 标签: framework, mvc, restful, web

## 简介

轻量级的 PHP MVC 框架 Lightweight MVC framework for simplistic PHP apps

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
