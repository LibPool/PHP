# components/bootstrap-cyborg

> 标签: bootstrap, css

## 简介

Shim repository for the Bootstrap Bootswatch Cyborg theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：http://bootswatch.com/
- 源码仓库：https://github.com/components/bootstrap-cyborg.git
- Packagist 页面：https://packagist.org/packages/components%2Fbootstrap-cyborg
