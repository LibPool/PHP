# brightmarch/testing-bundle

> 标签: Symfony2, phpunit, testing, tests

## 简介

Symfony bundle to aid with functional and unit testing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
