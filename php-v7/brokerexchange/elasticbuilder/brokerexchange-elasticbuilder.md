# brokerexchange/elasticbuilder

> 标签: builder, elasticsearch, eloquent, generator, laravel, query

## 简介

Query Builder for Elasticsearch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
