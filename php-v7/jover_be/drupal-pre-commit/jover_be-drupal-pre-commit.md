# jover_be/drupal-pre-commit

> 标签: code review, drupal, git, phpcs, pre-commit, standards

## 简介

A Git pre-commit hook to check Drupal Coding Standards and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
