# genmato/core

> 标签: PHP

## 简介

Genmato Core module used as base module for other Genmato extension for Magento 1.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://github.com/Genmato/Core
- 源码仓库：https://github.com/Genmato/Core.git
