# jall/aop-monolog-bundle

> 标签: aop, go-aop, logging, monolog

## 简介

A symfony bundle to allow simple AOP logging with the Monolog library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
