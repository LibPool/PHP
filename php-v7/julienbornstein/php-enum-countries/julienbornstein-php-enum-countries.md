# julienbornstein/php-enum-countries

> 标签: country, enum

## 简介

Country ISO 3166-1 alpha-2 and alpha-3 enum classes for myclabs/php-enum library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
