# dreamjobs/sitemap-generator

> 标签: Sitemap, cron, xml, yii2

## 简介

Yii2 component for generate sitemap.xml files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
