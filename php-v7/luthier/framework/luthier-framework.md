# luthier/framework

> 标签: dependency-injection, framework, luthier, micro-framework, middleware, routing

## 简介

Versatile PHP micro-framework for build APIs and websites quickly

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
