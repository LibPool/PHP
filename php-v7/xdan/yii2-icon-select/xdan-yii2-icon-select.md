# xdan/yii2-icon-select

> 标签: icon image picker, icon picker, icon select, widget, yii, yii 2, yii2

## 简介

yii2 widget for image-icons choosing, based on iconselect.js

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
