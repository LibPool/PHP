# thiagocfn/mikrotikconnection

> 标签: PHP

## 简介

Biblioteca em PHP para conectar e extrair informações de wi-fi de um mikrotik

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
