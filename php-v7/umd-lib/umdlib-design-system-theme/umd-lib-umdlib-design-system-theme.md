# umd-lib/umdlib-design-system-theme

> 标签: PHP

## 简介

Opinionated adaptation of the UMD Design System tailored for libraries sites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
