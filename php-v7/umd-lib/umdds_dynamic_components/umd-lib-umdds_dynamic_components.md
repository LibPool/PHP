# umd-lib/umdds_dynamic_components

> 标签: PHP

## 简介

UMD Libraries Dynamic Components module providing dynamic blocks and autocomplete functionality.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
