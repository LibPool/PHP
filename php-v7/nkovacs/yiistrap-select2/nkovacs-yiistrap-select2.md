# nkovacs/yiistrap-select2

> 标签: extension, select2, widget, yii

## 简介

Select2 widget for Yiistrap, based on crisu83/yiistrap-widgets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
