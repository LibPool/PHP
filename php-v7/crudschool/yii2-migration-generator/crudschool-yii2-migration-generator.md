# crudschool/yii2-migration-generator

> 标签: extension, yii2

## 简介

Set of gii tools for generating  files for migration by schema of table , phpdoc or table data

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
