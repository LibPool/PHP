# tomcorbett/opentok-laravel

> 标签: OpenTok, streaming, video streaming

## 简介

A laravel bundle for the OpenTok PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
