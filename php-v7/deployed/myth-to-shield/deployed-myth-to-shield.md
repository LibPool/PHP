# deployed/myth-to-shield

> 标签: Authentication, authorization, codeigniter, codeigniter4, myth, myth-auth, shield

## 简介

Tool to migrate from MythAuth to CodeIgniter Shield

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
