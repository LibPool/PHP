# mvc5/framework

> 标签: PSR-11, config, container, dependency injection, event, middleware, plugin, psr, route, router, view

## 简介

A PHP 5.6 programming environment with named arguments.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
