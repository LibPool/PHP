# moxuandi/yii2-umeditor

> 标签: extension, html编辑器, umeditor, yii2, 在线编辑器, 百度编辑器MINI版

## 简介

UMeditor，简称UM，是为满足广大门户网站对于简单发帖框，或者回复框需求所定制的在线富文本编辑器。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
