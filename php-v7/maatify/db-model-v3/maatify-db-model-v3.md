# maatify/db-model-v3

> 标签: database, handler, model, mysql, pdo, php

## 简介

Official PHP library for maatify.dev MySql Database Model handler, known by our team

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
