# maatify/google-fcm

> 标签: FCM, handler, php

## 简介

Unofficial Firebase Admin SDK for PHP its PHP library for maatify.dev FCM handler, known by our team

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
