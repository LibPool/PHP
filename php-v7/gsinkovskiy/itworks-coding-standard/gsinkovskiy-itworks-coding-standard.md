# gsinkovskiy/itworks-coding-standard

> 标签: Coding Standard, phpcs, symfony3

## 简介

Customized CodeSniffer ruleset for the ITWorks Soft projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
