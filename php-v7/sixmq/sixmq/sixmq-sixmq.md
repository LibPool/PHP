# sixmq/sixmq

> 标签: PHP

## 简介

SixMQ 是基于 IMI 框架 (PHP + Swoole) 开发的 PHP 消息队列

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
