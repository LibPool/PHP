# bpm-finder/app

> 标签: PHP

## 简介

PHP SDK for audio tempo calculation, Tap BPM interval analysis, delay note divisions, and reverb pre-delay formulas. Powered by the BPM Finder App.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
