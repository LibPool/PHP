# alek13/gears-pdf

> 标签: builder, converter, docx, pdf, template

## 简介

[`gears/pdf` fork] A PDF builder using HTML or DOCX templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
