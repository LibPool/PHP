# php-middleware/block-robots

> 标签: middleware, psr, psr-15, psr-7, robots, seo

## 简介

PSR-15 middleware to avoid search engine indexing with PSR-7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
