# render25/render25

> 标签: email, laravel, php, render25, resend-alternative, sdk, smtp, transactional-email

## 简介

Official PHP client library for Render25 transactional email service

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
