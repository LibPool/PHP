# divotek/admin

> 标签: admin, cmf, cms, extranet, framework, laravel, panel, platform, rad

## 简介

Platform for back-office applications, admin panel or CMS your Laravel app.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
