# ecs/ocbcleartmp

> 标签: O3-Shop, OXID, admin, modules

## 简介

Clear the tmp directory from the backend. For O3-Shop and OXID eShop 6.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
