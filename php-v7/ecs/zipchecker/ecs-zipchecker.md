# ecs/zipchecker

> 标签: plz, postleitzahl, zip

## 简介

Stellt einen schnellen PLZ-Vergleich bei der Bestellung unter &Uuml;bersicht zur Verf&uuml;gung.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
