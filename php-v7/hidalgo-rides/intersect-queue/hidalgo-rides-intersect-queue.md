# hidalgo-rides/intersect-queue

> 标签: PHP

## 简介

Queue processing system that allows cron-like processors to be defined and ran using a single script entry point.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
