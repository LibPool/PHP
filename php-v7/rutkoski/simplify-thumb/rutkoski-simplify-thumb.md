# rutkoski/simplify-thumb

> 标签: effects, image, resize, thumbnail

## 简介

Thumbnail generation and image processing, extendable and with a fluent interface.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
