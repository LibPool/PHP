# mtymek/blast-view

> 标签: layout, renderer, template, view helper, zend view

## 简介

Standalone template renderer using templating engine from Zend Framework 2 - Zend\View.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
