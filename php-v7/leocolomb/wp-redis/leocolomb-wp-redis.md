# leocolomb/wp-redis

> 标签: cache-advanced, cache-object, cache-page, redis, wordpress, wordpress-cache, wordpress-dropin

## 简介

A persistent cache backend for WordPress powered by Redis.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
