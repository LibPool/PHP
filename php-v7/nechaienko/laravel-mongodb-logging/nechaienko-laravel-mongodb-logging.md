# nechaienko/laravel-mongodb-logging

> 标签: database, db, laravel, log, logging, mongodb

## 简介

Custom Larvel 5.6+ Log channel handler that can store log events to MongoDB databases. Uses Laravel native logging functionality.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
