# axisops/plugin-repository-manager

> 标签: PHP

## 简介

A Composer plugin that configures axisops/* package sources and dependency channels (--local/--alpha/--beta/--rc/--prod) at runtime

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
