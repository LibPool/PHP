# just-core/threatcrowd

> 标签: HA, Service Oriented Architechture, api, enterprise, framework, http, just-core, scan, wrapper

## 简介

PHP Wrapper for https://github.com/threatcrowd/ApiV2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
