# webdriver-binary/binary-geckodriver

> 标签: Browser Testing, acceptance testing, binary, binary downloader, browser driver, composer extension, composer plugin, downloader, firefox automation, geckodriver, test-automation, testing, webdriver

## 简介

Utility for downloading GeckoDriver (Firefox automation) binary for current os/platform

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
