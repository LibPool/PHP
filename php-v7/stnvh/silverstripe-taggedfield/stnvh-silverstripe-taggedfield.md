# stnvh/silverstripe-taggedfield

> 标签: blog, field, silverstripe, tag, tagged, tagger

## 简介

Creates a tag field, similar to how a ListBoxField looks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
