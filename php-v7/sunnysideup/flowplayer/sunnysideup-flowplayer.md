# sunnysideup/flowplayer

> 标签: Silverstripe-CMS, cms, flowplayer, silverstripe

## 简介

helps you to add a 'flow player' (video application) to your Silverstripe application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
