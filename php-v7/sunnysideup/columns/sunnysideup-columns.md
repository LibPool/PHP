# sunnysideup/columns

> 标签: Content Blocks, Contentblocks, Page Design, Silverstripe-CMS, cms, columns, silverstripe

## 简介

Adds the ability to add several content columns.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
