# sunnysideup/ecommerce_quick_coupons

> 标签: Silverstripe-CMS, cms, e-commerce, ecommerce, feed, shop, silverstripe, xml

## 简介

Allows coupons for particular products to be added quickly!

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
