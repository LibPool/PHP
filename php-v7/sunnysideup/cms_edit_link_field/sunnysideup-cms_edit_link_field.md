# sunnysideup/cms_edit_link_field

> 标签: CMSEditLink, Silverstripe-CMS, cms, silverstripe

## 简介

Adds EDIT IN CMS link to any object within the Silverstripe CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
