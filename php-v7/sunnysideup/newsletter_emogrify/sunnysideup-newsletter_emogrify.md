# sunnysideup/newsletter_emogrify

> 标签: Silverstripe-CMS, cms, css, emogrify, newletter, newsletter_emogrify, silverstripe

## 简介

create nicely formatted emails for the silverstripe newsletter module using the emogrifier technique.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
