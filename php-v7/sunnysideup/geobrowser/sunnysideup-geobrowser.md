# sunnysideup/geobrowser

> 标签: Silverstripe-CMS, cms, geobrowser, silverstripe

## 简介

create geographic hierarchies using a database of twenty-five-thousand cities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
