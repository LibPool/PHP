# sunnysideup/share_this_simple

> 标签: Silverstripe-CMS, Site Tree Extensions, cms, facebook, pinterest, share, share links, silverstripe, social media, twitter

## 简介

Silverstripe Module that provides a simple way to add share this links to your website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
