# sunnysideup/release

> 标签: Silverstripe-CMS, bitbucket, ci, cms, git, pipelines, release, silverstripe

## 简介

Auto-release latest version of a branch.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
