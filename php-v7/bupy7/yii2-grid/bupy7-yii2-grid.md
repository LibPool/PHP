# bupy7/yii2-grid

> 标签: extension, grid, grid view, module, yii2

## 简介

Simple extended `yii\grid\GridView` with buns.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
