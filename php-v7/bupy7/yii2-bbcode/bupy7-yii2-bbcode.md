# bupy7/yii2-bbcode

> 标签: Behavior, bbcode, extension, parser, yii2

## 简介

A lightweight but extensible BBCode parser for Yii2 with filter HtmlPurifier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
