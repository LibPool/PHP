# trismegiste/yuurei

> 标签: dbal, microframework, mongodb, nosql, odm

## 简介

Schemaless Object Document Mapper for MongoDB

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
