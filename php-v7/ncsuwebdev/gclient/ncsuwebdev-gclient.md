# ncsuwebdev/gclient

> 标签: google, laravel, ncstate, ncsu

## 简介

Google API Client Wrapper for Laravel 5.6+ support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
