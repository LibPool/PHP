# huaiyang/breakpoint

> 标签: PHP

## 简介

在方法函数内部直接终止，将错误信息通过json的方式通知客户端，个人瞎搞，仅供参考，请勿用到线上项目！

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
