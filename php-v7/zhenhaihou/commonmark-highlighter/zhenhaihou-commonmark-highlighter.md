# zhenhaihou/commonmark-highlighter

> 标签: commonmark-highlighter, zhenhaihou

## 简介

Highlight your markdown code blocks with 升级league/commonmark版本，添加表格，删除线的转换

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
