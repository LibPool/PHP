# moneroo/moneroo-php

> 标签: AxaZara, laravel, mobile-money, moneroo, moneroo-laravel, moneroo.io, payment

## 简介

This is simple PHP Package to interact with Moneroo API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
