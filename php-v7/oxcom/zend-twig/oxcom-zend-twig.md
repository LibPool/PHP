# oxcom/zend-twig

> 标签: module, twig, zf, zf3

## 简介

ZendTwig is a module that integrates the Twig template engine with Zend Framework 3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
