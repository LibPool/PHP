# dziki/monolog-sentry-bundle

> 标签: bundle, logger, logging, monolog, sentry, symfony

## 简介

Improve logging to Sentry with user, user agent, revision and Symfony version data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
