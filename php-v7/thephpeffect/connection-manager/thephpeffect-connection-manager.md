# thephpeffect/connection-manager

> 标签: database, mysql, mysqli, pdo, php

## 简介

A simple connection manager for any OOP db connection in PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
