> 标签: extended, extra, i18n, internationalisation, internationalization, language, locale, localisation, localization, multilingual, silverstripe, table, translatable, translation

## 简介

Extended silverstripe fluent module. Locales data are be stored in seperate tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
