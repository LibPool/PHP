# kenjis/ci-phpunit-test

> 标签: codeigniter, codeigniter3, monkey patch, phpunit, test, unit testing

## 简介

An easier way to use PHPUnit with CodeIgniter 3.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
