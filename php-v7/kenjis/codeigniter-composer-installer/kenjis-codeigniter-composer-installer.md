# kenjis/codeigniter-composer-installer

> 标签: codeigniter, composer, installer

## 简介

Package to install CodeIgniter3 via Composer with secure folder structure.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
