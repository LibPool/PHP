# waxedphp/dropzone

> 标签: PHP

## 简介

DropzoneJS is an open source library that provides drag’n’drop file uploads with image previews - within WaxedPHP environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
