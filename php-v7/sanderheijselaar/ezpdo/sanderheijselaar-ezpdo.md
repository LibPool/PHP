# sanderheijselaar/ezpdo

> 标签: mysql, pdo, php, postgresql, sqlite

## 简介

A simple PHP PDO class for MySQL

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
