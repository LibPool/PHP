# thinkcmf/cat

> 标签: extension, internals, phalcon, zephir

## 简介

Zephir is a compiled high level language aimed to the creation of C-extensions for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
