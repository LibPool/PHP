# brickfox/ext-application-bundle

> 标签: PHP

## 简介

A Symfony 2 bundle to integrate Sencha Ext JS into a Symfony 2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
