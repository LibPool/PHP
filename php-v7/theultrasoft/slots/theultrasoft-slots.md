# theultrasoft/slots

> 标签: PHP

## 简介

Slots is a sequence load balancer optimized by slots and max load. This class can be used to load balance proxies and achieve better anonymity.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
