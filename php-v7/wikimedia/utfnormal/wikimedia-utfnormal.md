# wikimedia/utfnormal

> 标签: PHP

## 简介

Contains Unicode normalization routines, including both pure PHP implementations and automatic use of the 'intl' PHP extension when present

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
