# wikimedia/arc-lamp

> 标签: excimer, flamegraph, performance, profiling, sampling

## 简介

Flame graphs and log processing for PHP stack traces.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
