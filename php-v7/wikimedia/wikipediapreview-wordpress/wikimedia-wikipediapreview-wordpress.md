# wikimedia/wikipediapreview-wordpress

> 标签: card, facts, popup, wiki, wikipedia, wordpress

## 简介

WordPress plugin for Wikipedia Preview

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
