# wikimedia/langconv

> 标签: Wikimedia, language converter, mediawiki

## 简介

Finite-State Transducer implementation of MediaWiki LanguageConverter

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
