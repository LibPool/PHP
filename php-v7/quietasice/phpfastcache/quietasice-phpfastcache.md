# quietasice/phpfastcache

> 标签: APC Cache, apc, cache, cache class, caching, cookie, files cache, memcache, memcached, mysql cache, pdo cache, php cache, predis, redis, wincache

## 简介

PHP Cache Class - Supported Redis, Cookie, Predis, APC, MemCached, WinCache, Files, PDO, Reduce mySQL Call by Caching

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
