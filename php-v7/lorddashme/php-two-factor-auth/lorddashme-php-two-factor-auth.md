# lorddashme/php-two-factor-auth

> 标签: Authentication, hotp, otp, rfc4226, rfc6238, totp, two-way-authentication

## 简介

A PHP library for RFC 4226 and RFC 6238.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
