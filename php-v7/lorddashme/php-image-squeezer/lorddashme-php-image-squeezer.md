# lorddashme/php-image-squeezer

> 标签: compression, ffmpeg, image, lossy

## 简介

A simple PHP package for image compression powered by FFMPEG.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
