# lorddashme/php-cryptor

> 标签: cryptorgraphy, decrypt, encrypt

## 简介

A PHP package wrapper for cryptography functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
