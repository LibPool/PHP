# andrew-svirin/cfonb-php

> 标签: cfonb, ebics, etebac, parser, swift

## 简介

A PHP Parser for CFONB 120 signatures, 240 transfers. Helper for EBICS.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
