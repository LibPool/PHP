# douyuxingchen/php-library-stateful

> 标签: PHP

## 简介

有状态的库旨在简化您的业务代码和优化您的业务架构，将底层基础设施沉淀到基础库，如 Redis 分布式锁定，数据查询缓存等等。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
