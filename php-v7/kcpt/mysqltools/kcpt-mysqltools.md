# kcpt/mysqltools

> 标签: commands, console, database, kcpt, laravel, mysql

## 简介

KCPT's easy database dump/import commands for MySQL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
