# tig/core

> 标签: PHP

## 简介

Brings all tig.nl Magento 2 modules under one configuration tab

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

- 源码仓库：https://github.com/tig-nl/core-magento2.git
