# frdl/oidplus-plugin-alternate-id-tracking

> 标签: oiplus

## 简介

Track/Cache AltIds e.g. to enable reverse look-up of original identifiers by its alternate id.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
