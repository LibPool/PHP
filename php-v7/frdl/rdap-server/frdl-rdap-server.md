# frdl/rdap-server

> 标签: OIDplus, frdlweb, oid, php, rdap, server, weid, whois

## 简介

Rdap Server (OIDplus aware, with WHOIS-fallback/-remarks)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
