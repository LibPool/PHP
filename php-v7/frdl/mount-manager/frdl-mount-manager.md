# frdl/mount-manager

> 标签: fs, ftp, ftps, mount, php, protocols, streamwrapper

## 简介

PHP stream wrapper library to magically mount local or remote filesystems.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
