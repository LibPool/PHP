# sanderdekroon/parlant

> 标签: parlant, posts, querybuilder, sanderdekroon, wordpress

## 简介

An expressive way to query posts in WordPress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
