> 标签: BDD, Mock, TDD, library, mock, mock objects, mockery, stub, test, test double, testing, 测试

## 简介

Mockery is a simple yet flexible PHP mock object framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
