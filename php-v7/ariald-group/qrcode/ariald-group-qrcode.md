# ariald-group/qrcode

> 标签: php, qrcode

## 简介

A PHP class to generate QR Code. Fork of ariald-group/qrcode with composer support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
