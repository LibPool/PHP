# omnipay/2checkout

> 标签: 2checkout, 2co, gateway, merchant, omnipay, pay, payment, twocheckout

## 简介

2Checkout driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
