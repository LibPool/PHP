# omnipay/rabobank

> 标签: gateway, ideal, merchant, omnikassa, omnipay, pay, payment, rabobank

## 简介

Rabobank Omnikassa driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
