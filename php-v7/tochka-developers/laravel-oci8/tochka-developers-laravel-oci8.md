# tochka-developers/laravel-oci8

> 标签: laravel, laravel4, laravel5, oci8, oracle, pdo_oci

## 简介

Oracle DB driver for Laravel 4|5 via OCI8

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
