# zmbakh/nurkassa-php-sdk

> 标签: nurkassa, php, sdk

## 简介

A PHP SDK for working with the API of Nurkassa. Created by the owner company.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
