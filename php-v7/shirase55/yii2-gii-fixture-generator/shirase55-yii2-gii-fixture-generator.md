# shirase55/yii2-gii-fixture-generator

> 标签: Fixture, gii, yii 2, yii2

## 简介

Fixture class generator for Gii module of Yii2 Framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
