# sync667/zendesk_api_client_php_med

> 标签: PHP

## 简介

PHP Client for Zendesk REST API. See https://developer.zendesk.com/rest_api/docs/core/introduction .

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
