# qingbing/yii2-configure

> 标签: form-configure, header-configure, php, replace-configure, site-configure, yii

## 简介

yii配置组件，包含：网站配置、表头配置、表单配置、替换配置等

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
