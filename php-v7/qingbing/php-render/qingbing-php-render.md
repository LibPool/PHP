# qingbing/php-render

> 标签: action, controller, framework, php, render, route, view-action, view-render, web

## 简介

继承php-web : controller，在原有的基础上支持页面渲染，视图叠加等操作

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
