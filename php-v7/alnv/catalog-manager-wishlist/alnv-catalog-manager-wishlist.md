# alnv/catalog-manager-wishlist

> 标签: catalog, contao, extension, manager, wishlist

## 简介

Extension for Catalog Manager. This Extension allows you to create a wishlist.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
