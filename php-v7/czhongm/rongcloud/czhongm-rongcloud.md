# czhongm/rongcloud

> 标签: rlcoud, rong cloud, rongCloud, sdk

## 简介

Rong Cloud Server SDK in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
