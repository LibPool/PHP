# thelan/validator-pizza

> 标签: symfony

## 简介

Integrates validator.pizza with Symfony.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.validator.pizza/
- 源码仓库：https://github.com/thelan/validator-pizza.git
- Packagist 页面：https://packagist.org/packages/thelan%2Fvalidator-pizza

- 许可证：AGPL-3.0-or-later
