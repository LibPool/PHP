# mikehaertl/translatable

> 标签: i18n, translation, yii

## 简介

translatable is a Yii extension to transparently translate ActiveRecord attributes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
