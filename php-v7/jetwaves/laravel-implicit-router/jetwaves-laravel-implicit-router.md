# jetwaves/laravel-implicit-router

> 标签: PHP

## 简介

A simple Implicit Router/Controller Router for Laravel whose version >= 5.2 ( 5.5 tested )

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
