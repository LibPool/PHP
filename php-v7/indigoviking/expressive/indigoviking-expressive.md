# indigoviking/expressive

> 标签: Craft, PCRE, cms, craft-plugin, craftcms, expressive, preg, preg_filter, preg_match

## 简介

Adds PHP PCRE preg functions as Twig filters.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
