# larakit/cmd-vcs

> 标签: git, larakit, laravel, laravel 5, svn

## 简介

[Larakit] Библиотека для Laravel для мониторинга измененных файлов в vendor-пакетах

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
