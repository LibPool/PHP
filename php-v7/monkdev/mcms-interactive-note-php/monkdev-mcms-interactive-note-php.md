# monkdev/mcms-interactive-note-php

> 标签: Church, message, notes, sermon

## 简介

A PHP Library to transform HTML into an interactive fill the in blank style form

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
