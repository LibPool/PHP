# kaapiii/concrete5_doctrine_behavioral_extensions

> 标签: PHP

## 简介

Package adds Doctrine2 behavioral extensions to concrete5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
