# bytehunter/yii2-standard

> 标签: application template, bytehunter, framework, restful, yii2

## 简介

Yii2 template focused on serving RESTful API, with some cool extra features

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
