# egnd/bxsrc

> 标签: PHP

## 简介

Truncated core of CMS 1C-Bitrix. Contains only PHP classes and functions (no css, js, pictures, procedural PHP files, etc.)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
