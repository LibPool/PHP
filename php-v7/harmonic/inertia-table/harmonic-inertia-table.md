# harmonic/inertia-table

> 标签: InertiaTable, inertia, inertiajs, laravel

## 简介

Easily create Inertia JS tables from Eloquent models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
