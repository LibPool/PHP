# matiosfree/l-rbac

> 标签: ability, gate, laravel, permission, rbac, role

## 简介

The RBAC implementation for Laravel. Based on Laravel Abilities\Gates.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
