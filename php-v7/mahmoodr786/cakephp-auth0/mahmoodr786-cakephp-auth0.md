# mahmoodr786/cakephp-auth0

> 标签: Authentication, auth0, authenticate, cakephp, jwt

## 简介

CakePHP plugin for validating Auth0 JWT token and authenticating the user.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
