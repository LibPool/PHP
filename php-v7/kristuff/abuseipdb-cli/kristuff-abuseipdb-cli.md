# kristuff/abuseipdb-cli

> 标签: abuseipdb, api, client

## 简介

A CLI tool to check/report IP addresses, download blacklist with AbuseIPDB API V2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
