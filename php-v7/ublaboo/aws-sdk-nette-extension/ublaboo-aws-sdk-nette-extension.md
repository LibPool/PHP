# ublaboo/aws-sdk-nette-extension

> 标签: amazon, aws, di, extension, nette, php, sdk

## 简介

A Nette extension for the AWS SDK for PHP http://aws.amazon.com/sdkforphp/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
