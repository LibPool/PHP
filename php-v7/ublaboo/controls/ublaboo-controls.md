# ublaboo/controls

> 标签: controls, extension, nette

## 简介

Extension for Nette Framework: Controls: that has not translatable content (radiolist, selectbox), custom label text input

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
