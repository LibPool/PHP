# sourcetoad/bbii2

> 标签: forum, module, sourcetoad, yii2

## 简介

Bbii2 is an iteration of the bbii forum module, but migrated to Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
