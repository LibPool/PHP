# derhaeuptling/contao-mega-menu

> 标签: Mega Menu, contao, mega, menu, navigation

## 简介

Mega menu extension for Contao Open Source CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
