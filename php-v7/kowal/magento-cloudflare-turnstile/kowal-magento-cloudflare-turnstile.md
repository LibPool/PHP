# kowal/magento-cloudflare-turnstile

> 标签: PHP

## 简介

Protect your store from spam messages and spam user accounts with Cloudflare Turnstile

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
