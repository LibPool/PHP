# janpetr/algoliasearch-magento2-one-result-redirect

> 标签: PHP

## 简介

Magento 2 module to redirect to the product, when there is only one in a results

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
