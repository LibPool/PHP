# zvps/laravel-4-env-polyfill

> 标签: PHP

## 简介

Enables the env() function for providing default environment values and retrieving a variable from $_ENV.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
