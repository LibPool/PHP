# ferrumz/riak

> 标签: basho, client, crdt, data, database, datatype, driver, kv, nosql, riak

## 简介

Official Riak client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
