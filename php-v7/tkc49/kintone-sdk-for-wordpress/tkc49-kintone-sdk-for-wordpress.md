# tkc49/kintone-sdk-for-wordpress

> 标签: REST API, kintone, plugin, sdk, wordpress

## 简介

WordPress plugin development library for Kintone REST API integration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
