# beewilly/hive_ovr_hhvideoextender

> 标签: PHP

## 简介

Override hauerheinrich/hh-video-extender EXT for Cookie Consent Tool Support for embedded youtube & vimeo content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
