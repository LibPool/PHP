# ko7ta/laravel5.8-lets-encrypt

> 标签: certificate, encrypt, ko7ta, laravel, lets, ssl

## 简介

A Laravel package to easily generate SSL certificates using Let's Encrypt

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
