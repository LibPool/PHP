# paymentassist/creditsafe-callreport

> 标签: callreport, creditsafe, transunion

## 简介

PHP client for accessing the CreditSafe CallReport API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
