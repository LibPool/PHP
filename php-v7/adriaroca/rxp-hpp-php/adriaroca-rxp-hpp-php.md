# adriaroca/rxp-hpp-php

> 标签: HPP, payments, realex

## 简介

SDK to send requests and parse responses from Realex Payments using HPP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
