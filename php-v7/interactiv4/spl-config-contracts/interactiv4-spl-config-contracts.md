# interactiv4/spl-config-contracts

> 标签: config, contracts, interactiv4, spl

## 简介

This package contains aspect-oriented interfaces to read / put / compare config values.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
