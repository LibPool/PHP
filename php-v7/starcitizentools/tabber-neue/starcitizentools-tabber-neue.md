# starcitizentools/tabber-neue

> 标签: Tabber, TabberNeue, extension, mediawiki

## 简介

Allows to create tabs within a page. Forked from Extension:Tabber

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
