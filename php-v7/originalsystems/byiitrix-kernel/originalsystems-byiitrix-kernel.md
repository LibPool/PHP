# originalsystems/byiitrix-kernel

> 标签: bitrix, helper, migration, project template, yii2

## 简介

Bitrix kernel, based on yii with cli interface, helpers and component templates

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
