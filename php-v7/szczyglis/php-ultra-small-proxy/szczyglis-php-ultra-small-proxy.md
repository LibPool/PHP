# szczyglis/php-ultra-small-proxy

> 标签: client, cookies, crawler, http, networking, proxy, rewrite, web, webproxy, website

## 简介

Light-weight proxy with full support for sessions, cookies, POST/FORMS submiting and URLs rewriting

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
