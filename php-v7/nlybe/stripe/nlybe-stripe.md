# nlybe/stripe

> 标签: elgg, payments, plugin, stripe

## 简介

This plugin provides an Elgg API layer for interfacing with Stripe

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
