# nlybe/lang_selector

> 标签: elgg, i18n, plugin

## 简介

Provides a selector for users to easily change the language. Revised version from original Language Selector plugin by ColdTrick.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
