# factorio-item-browser/export-queue-client

> 标签: FIB, Factorio Item Browser, client, export, queue

## 简介

A client to access the export queue of the Factorio Item Browser.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
