# dataplans/dataplans-php

> 标签: dataplans, esim

## 简介

A PHP library designed specifically to connect with DataPlans API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.dataplans.io
- 源码仓库：https://github.com/DataPlans-io/dataplans-php.git
- Packagist 页面：https://packagist.org/packages/dataplans%2Fdataplans-php
