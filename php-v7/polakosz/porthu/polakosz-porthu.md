# polakosz/porthu

> 标签: PoLáKoSz, Port.hu, api, port, wrapper

## 简介

Library to search for movies and to get informations for a specific movie from https://port.hu/

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
