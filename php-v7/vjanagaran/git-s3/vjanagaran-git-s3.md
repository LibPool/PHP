# vjanagaran/git-s3

> 标签: aws, bucket, deploy, git, s3

## 简介

Easy way to deploy your git repo to an AWS S3 bucket

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
