# sheabunge/visual-term-description-editor

> 标签: PHP

## 简介

Replaces the plain-text editor for WordPress taxonomies with a visual WYSIWYG editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
