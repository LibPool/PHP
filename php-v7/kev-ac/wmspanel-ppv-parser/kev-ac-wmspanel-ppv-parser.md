# kev-ac/wmspanel-ppv-parser

> 标签: parser, wmspanel

## 简介

Parses pay-per-view json payload and creates media signatures for WMSPanel PPV framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
