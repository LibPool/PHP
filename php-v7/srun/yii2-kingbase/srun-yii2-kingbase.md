# srun/yii2-kingbase

> 标签: kingbase, kingbasees, pgsql, postgresql, yii2

## 简介

Yii2 KingbaseES PostgreSQL-mode schema compatibility layer for SRun projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
