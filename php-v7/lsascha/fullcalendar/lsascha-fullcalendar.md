# lsascha/fullcalendar

> 标签: Neos, calendar, flow

## 简介

full calendar (fullcalendar.io) implementation package for Flow / Neos

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
