# plhw/hf-api-client

> 标签: PHP

## 简介

PLHW API Client provides means to authenticate clients against with OAuth2 server and issue authorized requests to our api endpoints

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
