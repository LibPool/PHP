# presprog/kirby-seo-plugin

> 标签: PHP

## 简介

Opinionated SEO plugin for Kirby CMS. With meta description, open graph, sitemap and robots.txt

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
