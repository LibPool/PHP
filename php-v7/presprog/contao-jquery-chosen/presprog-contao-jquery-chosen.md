# presprog/contao-jquery-chosen

> 标签: PHP

## 简介

This extension adds the jQuery version of Chosen by Harvest to Contao. After install, simply add the j_jquery_chosen template in your theme.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
