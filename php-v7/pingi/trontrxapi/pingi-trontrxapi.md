# pingi/trontrxapi

> 标签: PHP

## 简介

Library for interacting with the Tron blockchain through Tron-Grid (add a few conditions to remove API dependencies - PINGI.CO PINGI.IR)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
