# alexeymezenin/laravel-gmt-timezones

> 标签: GMT, form, laravel, list, select, timezone, timezones

## 简介

Helps manage timezones in Laravel. Includes <select> form builder for timezones. Fork from camroncade/timezone with GMT used instead of UTC.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
