# eusonlito/disposable-email-validator

> 标签: disposable, email, emails, fake, spam, validate

## 简介

A PHP package to detect disposable emails based on multiple lists.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
