# eusonlito/magento2-language-es_es

> 标签: PHP

## 简介

Magento 2 Spanish (Spain) language package - Paquete de idioma Español (España) para Magento 2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
