# crockett95/projectplaceoauth

> 标签: PHP

## 简介

Service wrapper for Projectplace OAuth 1.0 for use with the PHPOAuthLib library by Lusitanian.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
