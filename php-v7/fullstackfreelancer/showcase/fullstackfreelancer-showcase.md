# fullstackfreelancer/showcase

> 标签: extension, frontend, gallery, masonry, modal, plugin, portfolio, presentation, projectgallery, showcase, typo3

## 简介

Showcase is a versatile tool designed for creating dynamic portfolios, engaging galleries, and impressive presentations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
