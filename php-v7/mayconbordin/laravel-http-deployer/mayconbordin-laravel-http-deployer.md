# mayconbordin/laravel-http-deployer

> 标签: deployment, http, laravel, shared hosting

## 简介

A tool for automated deployment of Laravel applications using HTTP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
