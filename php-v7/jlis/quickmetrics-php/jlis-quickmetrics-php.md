# jlis/quickmetrics-php

> 标签: Metrics, client, events, php, quickmetrics, sdk

## 简介

A unofficial PHP client for Quickmetrics (quickmetrics.io)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
