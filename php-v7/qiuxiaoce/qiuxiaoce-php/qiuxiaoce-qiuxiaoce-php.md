# qiuxiaoce/qiuxiaoce-php

> 标签: fixtures, football, premier-league, qiuxiaoce, soccer, sports-data, standings, xg

## 简介

Official PHP SDK for QiuXiaoCe (球小策) Football Big Data & AI Analysis API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
