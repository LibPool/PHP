# agile-bm/ado-db

> 标签: abstraction, database, layer, library, php

## 简介

This is a fork of adodb/adodb-php https://adodb.org/. ADOdb is a PHP database abstraction layer library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
