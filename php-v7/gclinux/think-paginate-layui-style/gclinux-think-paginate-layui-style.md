# gclinux/think-paginate-layui-style

> 标签: PHP

## 简介

用于修正layui 2.0分页样式与thinkphp分页样式的兼容

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
