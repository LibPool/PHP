# webburza/sylius-wishlist-plugin

> 标签: sylius, sylius-plugin, symfony, web.burza, webburza, wishlist

## 简介

Wishlist plugin for Sylius e-commerce platform.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
