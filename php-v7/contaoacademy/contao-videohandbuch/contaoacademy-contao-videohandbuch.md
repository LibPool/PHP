# contaoacademy/contao-videohandbuch

> 标签: Anwender, Redakteure, contao, handbuch, videohandbuch

## 简介

Contao Open Source CMS Videohandbuch für Redakteure. Die Schulungsvideos können direkt über das Backend von Contao abgespielt werden.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
