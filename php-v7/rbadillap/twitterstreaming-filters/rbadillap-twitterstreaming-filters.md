# rbadillap/twitterstreaming-filters

> 标签: api, realtime, streaming, twitter

## 简介

Extension of Twitter Streaming Library which provides methods to filter tweets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
