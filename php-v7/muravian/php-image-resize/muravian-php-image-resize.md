# muravian/php-image-resize

> 标签: crop, image, php, resize, scale, show

## 简介

Display image that are not in public folder with php. Real time View, Scale / Resize, Crop

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
