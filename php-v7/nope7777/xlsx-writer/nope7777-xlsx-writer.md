# nope7777/xlsx-writer

> 标签: excel, php, xlsx

## 简介

XLSXWriter - lightweight library for generating large Excel exports fast and without memory overflow.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
