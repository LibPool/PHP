# crabstudio/baokim

> 标签: anhtuank7c, baokim, cake3, cakephp3, crabstudio, payment gateway, search

## 简介

BaoKim payment gateway plugin for CakePHP 3.x

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
