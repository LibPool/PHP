# wladmonax/laravel-db-backup

> 标签: PHP

## 简介

Backup and restore databases. Encrypting dumps. Save dumps to db and uploading to Dropbox. Restore dump from Dropbox.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
