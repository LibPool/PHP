# cyx01/phpunit-merger

> 标签: TYPO3 CMS, coverage, phpunit, sonarqube

## 简介

Merge multiple PHPUnit reports into one file

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
