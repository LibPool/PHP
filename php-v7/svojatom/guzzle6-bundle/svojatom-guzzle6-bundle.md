# svojatom/guzzle6-bundle

> 标签: Guzzle, api, bundle, client, curl, http, http client, rest, web service

## 简介

Integrates Guzzle 6 into your Symfony application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
