# jmillerdesign/mandrill

> 标签: cakephp, mandrill, transport

## 简介

This enables using CakeEmail from CakePHP 2.x with Mandrill

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
