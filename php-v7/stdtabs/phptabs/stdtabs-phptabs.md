# stdtabs/phptabs

> 标签: guitar, midi, music, tablature, tabs

## 简介

A PHP library for reading, writing and rendering Guitar Pro and MIDI files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
