# madkom/docker-image-builder

> 标签: automate, build, builder, ci, continues integration, creator, docker, image, template

## 简介

Library for creating docker images from templates.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
