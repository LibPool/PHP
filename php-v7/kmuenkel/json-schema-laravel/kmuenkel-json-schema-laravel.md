# kmuenkel/json-schema-laravel

> 标签: json-schema, laravel, validation

## 简介

This is a Laravel Request-compatible override for opis/json-schema.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
