# schoenef/photon-osm-connector-bundle

> 标签: PHP

## 简介

Allows to easily use the [Photon API](https://photon.komoot.de/) in your symphony project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
