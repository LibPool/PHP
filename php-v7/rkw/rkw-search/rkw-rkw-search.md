# rkw/rkw-search

> 标签: RKW, Semantic Search, TYPO3 CMS, orientdb

## 简介

Extension for a semantic search based on OrientDb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
