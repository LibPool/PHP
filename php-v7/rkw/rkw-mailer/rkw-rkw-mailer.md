# rkw/rkw-mailer

> 标签: E-Mails, RKW, TYPO3 CMS, newsletter, queue

## 简介

Extension sending e-mails and bulk-mailings

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
