# rkw/rkw-pdf2content

> 标签: Magazin, RKW, TYPO3 CMS, ajax, content, javascript, pdf

## 简介

Extract text from PDFs and create TYPO3 sites with it!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
