# rkw/rkw-tools

> 标签: RKW, TYPO3 CMS, tools

## 简介

Extension for listing tools (PDFs, WebApps etc.) with metadata and filters

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
