# oliverklee/typo3-devsite

> 标签: sitepackage

## 简介

TYPO3 extension that contains the basics of a site which Oliver Klee uses for developing in TYPO3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
