# bibby/dusk-failures

> 标签: bibby, ci, dusk, laravel

## 简介

Package to add dusk:failures command to Laravel. Emails screenshots and console errors of all failed Dusk tests.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
