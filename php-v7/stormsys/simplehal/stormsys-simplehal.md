# stormsys/simplehal

> 标签: HalClient, hal, hal client, hypermedia

## 简介

SimpleHal is an easy to use library for consuming Hal API's

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
