# atomwares/atom-container

> 标签: PSR-11, atom, atomframework, container, dependency-injection, php

## 简介

Simple PSR-11 DI Container by Atom Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
