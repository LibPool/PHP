# buildrr/multisite

> 标签: cakephp, multisite

## 简介

A multi-site plugin for CakePHP 3.x, which lets you have host multiple sites from a single CakePHP install.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
