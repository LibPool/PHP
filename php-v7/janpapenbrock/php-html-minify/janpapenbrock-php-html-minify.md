# janpapenbrock/php-html-minify

> 标签: html, minify, optimization, performance, php, size, whitespace

## 简介

Trim down your page size by minifying HTML.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
