# aware/fpdf-symfony2

> 标签: PHP

## 简介

fpdf vendor for use with symfony2, based on toooni/fpdf

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/awarebe/fpdf-symfony2
- 源码仓库：https://bitbucket.org/awarebe/fpdf-symfony2.git
- Packagist 页面：https://packagist.org/packages/aware%2Ffpdf-symfony2

- Composer 安装：`composer require aware/fpdf-symfony2`
