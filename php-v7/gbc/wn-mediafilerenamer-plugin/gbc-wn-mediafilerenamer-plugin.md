# gbc/wn-mediafilerenamer-plugin

> 标签: media, plugin, sanitize, seo, winter, wintercms

## 简介

Media File Renamer plugin that sanitizes uploaded media names

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
