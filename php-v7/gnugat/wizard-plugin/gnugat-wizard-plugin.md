# gnugat/wizard-plugin

> 标签: bundle, install, symfony, wizard

## 简介

Automatically registers bundles in a Symfony2 application when running 'composer require'

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
