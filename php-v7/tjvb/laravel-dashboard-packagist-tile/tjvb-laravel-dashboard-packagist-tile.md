# tjvb/laravel-dashboard-packagist-tile

> 标签: laravel-dashboard-packagist-tile, tjvb

## 简介

A tile for Laravel Dashboard that shows statistics from packagist.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
