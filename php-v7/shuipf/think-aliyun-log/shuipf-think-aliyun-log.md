# shuipf/think-aliyun-log

> 标签: PHP

## 简介

基于阿里云日志服务收集ThinkPHP 6框架运行中的日志信息

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
