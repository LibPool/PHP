# garagist/fontawesome-alpinejs

> 标签: PHP

## 简介

Fetch fontawesome icons with AlpineJS. Cached with LocalStorage

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
