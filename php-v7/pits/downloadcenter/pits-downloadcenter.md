# pits/downloadcenter

> 标签: TYPO3 CMS, angular, category filter, documents, download, download center, downloads, extension, fal, file download, file list, files, search, typo3

## 简介

Frontend download center that lists FAL file collections in a fast Angular-based interface with keyword search, hierarchical category and file type filters, sorting and pagination. Editors manage downloadable documents with categories and thumbnails; visitors filter, sort and share deep-linked file lists.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
