# jrockenbauer/contao-backendutilities

> 标签: PHP

## 简介

Extension for add css style w25 (quarter size screen) in backend and select box for margin/padding in element and module.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
