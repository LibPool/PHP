# rsqueue/rsqueue-bundle

> 标签: queue, redis, rsqueue, symfony

## 简介

Redis Symfony2 Queue Bundle, a simple and soft redis based message queue for symfony2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
