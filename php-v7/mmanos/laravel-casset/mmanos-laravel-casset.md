# mmanos/laravel-casset

> 标签: asset, assets, compression, css, javascript, laravel, less, minification

## 简介

An asset management package for Laravel 4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
