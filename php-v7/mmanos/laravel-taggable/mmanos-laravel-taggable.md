# mmanos/laravel-taggable

> 标签: Taggable, eloquent, laravel, model, tag, tagging, tags

## 简介

A tagging package for Laravel 4 models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
