# react/promise-stream

> 标签: Buffer, async, promise, reactphp, stream, unwrap

## 简介

The missing link between Promise-land and Stream-land for ReactPHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
