# waavi/mailman

> 标签: Mailman, email, laravel, mailer, waavi

## 简介

Easier email sending for Laravel 5 with CSS inlining.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
