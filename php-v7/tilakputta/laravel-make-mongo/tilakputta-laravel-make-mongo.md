# tilakputta/laravel-make-mongo

> 标签: PHP

## 简介

Laravel Artisan Make Model command for Mongo Model using Jenssegers/MongoDb

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
