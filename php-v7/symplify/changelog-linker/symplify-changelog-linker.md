# symplify/changelog-linker

> 标签: PHP

## 简介

Generates beautiful CHANGELOG.md with links to PRs, versions and users grouped in Added/Changed/Fixed/Removed categories.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
