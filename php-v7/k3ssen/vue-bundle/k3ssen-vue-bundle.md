# k3ssen/vue-bundle

> 标签: php, php7.4, php8, php8.1, symfony, symfony5, symfony6, vue, vue2, vue3, vuejs

## 简介

Bundle for Symfony (4.4, 5, 6) applications that makes combining Twig and Vue easy

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
