# robopuff/tinypng

> 标签: tinify, tiny-jpg, tiny-png, tinyjpg, tinypng

## 简介

Modern TinyPNG client for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
