# dmcb/silverstripe-html-minification

> 标签: minifcation, minify, silverstripe

## 简介

Minifies HTML of Silverstripe HTTP responses

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
