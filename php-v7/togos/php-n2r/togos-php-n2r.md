# togos/php-n2r

> 标签: PHP

## 简介

Library (and stand-alone scripts) for handling /uri-res/N2R requests backed by a ccouch repository.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
