# erickskrauch/mcc-mnc

> 标签: E212, ISO 3166, countries, mcc, mnc

## 简介

A library to convert MCC to country code and vice-versa

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
