# erickskrauch/php-cs-fixer-custom-fixers

> 标签: Code style, dev, php-cs-fixer

## 简介

A set of custom fixers for PHP-CS-Fixer

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
