# vova07/yii2-start

> 标签: application, bootstrap, start, yii 2, yii2

## 简介

Yii2-Start it's a small Yii 2 application template for your fast project start.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
