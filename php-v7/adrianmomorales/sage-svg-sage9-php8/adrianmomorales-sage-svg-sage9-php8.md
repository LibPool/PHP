# adrianmomorales/sage-svg-sage9-php8

> 标签: wordpress

## 简介

WordPress package to enable a blade directive to use SVG images inline with Sage 9

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
