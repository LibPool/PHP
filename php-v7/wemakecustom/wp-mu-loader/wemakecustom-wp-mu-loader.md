# wemakecustom/wp-mu-loader

> 标签: plugins, wordpress

## 简介

Enables the loading of Wordpress plugins sitting in mu-plugins (as folders)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
