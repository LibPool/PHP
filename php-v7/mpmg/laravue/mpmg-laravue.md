# mpmg/laravue

> 标签: laravel, mpmg, vue, vuejs

## 简介

Code generation for MPMG projects that use Laravel and VueJs tecnologies.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
