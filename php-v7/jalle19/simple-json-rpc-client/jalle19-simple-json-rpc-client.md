# jalle19/simple-json-rpc-client

> 标签: jsonrpc

## 简介

Simple JSON-RPC 2.0 client which utilizes Zend for HTTP functionality

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
