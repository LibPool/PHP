# extensionbuilder/eb-expand-texticon

> 标签: PHP

## 简介

Expand BK2K Bootstrap Package content element “Text and Icon” with some open source SVG icon libraries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
