# dima-bzz/laravel-short-schedule

> 标签: dima-bzz, laravel-short-schedule, spatie

## 简介

Schedule artisan commands to run using a sub-minute frequency

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
