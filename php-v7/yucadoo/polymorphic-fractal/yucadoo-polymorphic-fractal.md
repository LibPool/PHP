# yucadoo/polymorphic-fractal

> 标签: api, fractal, polymorphic, transform, yuca

## 简介

Polymorphic Transformer implementation for PHP League's Fractal package.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
