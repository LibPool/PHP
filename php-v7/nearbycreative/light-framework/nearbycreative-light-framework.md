# nearbycreative/light-framework

> 标签: api, eloquent, framework, orm, php, router

## 简介

Light Framework makes it ridiculously easy to throw up a powerful JSON API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
