# smoolabs/wordpress-plugin-updater

> 标签: PHP

## 简介

A library for WordPress plugins, to utilize license verification and auto-updating using WordPress License Server.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
