# mkleine/magento2-german-language-pack

> 标签: de_DE, german, language, magento, magento2, translation

## 简介

German (Germany) language pack for Magento Open Source 2.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
