# santhoshjanan/codesnifferdoc

> 标签: PHP

## 简介

Helper to get the codesniffer page (for accessibility standards) based on errorcode

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
