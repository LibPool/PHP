# financialplugins/omnipay-cryptapi

> 标签: cryptapi, crypto, omnipay

## 简介

CryptAPI.io driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
