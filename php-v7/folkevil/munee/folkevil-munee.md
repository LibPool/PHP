# folkevil/munee

> 标签: asset management, asset optimisation, asset optimization, cache, coffeescript, css, image manipulation, javascript, less, lessphp, php, scss, scssphp

## 简介

Standalone PHP Asset Optimisation & Manipulation - On-The-Fly Image Resizing, On-the-fly LESS, SCSS, CoffeeScript Compiling, CSS & JavaScript Combining/Minifying, and Smart Client Side and Server Side Caching

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
