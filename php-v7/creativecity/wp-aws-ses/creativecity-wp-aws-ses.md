# creativecity/wp-aws-ses

> 标签: PHP

## 简介

AWS SES mailing in WordPress, including support for sending e-mail via SSL/TLS (such as Gmail)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
