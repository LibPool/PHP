# shiftonelabs/laravel-cors

> 标签: ShiftOneLabs, cors, laravel, laravel-cors

## 简介

Enables CORS for Laravel apps on a global or per-route basis.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
