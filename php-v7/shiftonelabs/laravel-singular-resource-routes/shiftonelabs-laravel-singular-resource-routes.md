# shiftonelabs/laravel-singular-resource-routes

> 标签: laravel, resource, routes, singular

## 简介

Adds support for singular resource routes to the Laravel router.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
