# shiftonelabs/codesniffer-standard

> 标签: Coding Standard, ShiftOneLabs, phpcs

## 简介

CodeSniffer standard to add a few extra checks not contained in PSR-2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
