# passworks/passworks-php

> 标签: apple, passbook, passkit, passworks, wallet

## 简介

Client for Passworks API allowing the creating of Apple Passbook/Wallet content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
