# boxed-code/laravel-eloquent-meta

> 标签: data, eloquent, laravel, meta, metadata, model

## 简介

Meta data framework for Laravel's eloquent models.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
