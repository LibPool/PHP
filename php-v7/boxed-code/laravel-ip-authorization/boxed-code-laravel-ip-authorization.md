# boxed-code/laravel-ip-authorization

> 标签: PHP

## 简介

Authorize access based on IPv4 & IPv6 addresses, ranges, subnets or wildcards.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
