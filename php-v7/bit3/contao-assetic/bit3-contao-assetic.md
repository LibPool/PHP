# bit3/contao-assetic

> 标签: JS, assets, contao, css, javascript, stylesheet, theme

## 简介

Assetic integration for Contao OpenSource CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
