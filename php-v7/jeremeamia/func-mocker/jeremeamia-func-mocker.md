# jeremeamia/func-mocker

> 标签: function, jeremeamia, mocking, testing

## 简介

Allows you to override global function used within a namespace for the purposes of testing.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
