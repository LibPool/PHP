# wangzd/laravel-dict

> 标签: PHP

## 简介

laravel-dict是一个用于管理系统常用的配置的简单封装.提高代码的扩展性，可以易读性

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
