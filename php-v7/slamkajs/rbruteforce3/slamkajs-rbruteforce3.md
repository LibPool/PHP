# slamkajs/rbruteforce3

> 标签: brute force, cakephp, egcservices, security

## 简介

CakePHP 3+ Plugin for Protection Against BruteForce Attacks

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
