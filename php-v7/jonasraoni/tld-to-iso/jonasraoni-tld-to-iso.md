# jonasraoni/tld-to-iso

> 标签: Iso3166, country, mapping, tld

## 简介

Maps top level domains (TLD) against countries using the ISO 3166-1 alpha-2 format and vice-versa.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
