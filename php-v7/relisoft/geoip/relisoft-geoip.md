# relisoft/geoip

> 标签: PHP

## 简介

GeoIP extension for nette framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://relisoft.cz
- 源码仓库：https://github.com/Isigar/nette-geoip.git
- Packagist 页面：https://packagist.org/packages/relisoft%2Fgeoip

## 获取地址

- Composer 安装：`composer require relisoft/geoip`
- Packagist 仓库：https://repo.packagist.org/p2/relisoft/geoip.json
- PHP 要求：>=7.1
