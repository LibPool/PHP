# bugphix/bugphix-laravel

> 标签: bugphix, bugphix-laravel, error, error-catcher, error-handler, error-logger, error-manager, error-monitoring, error-viewer, error-watcher, laravel-bugphix, laravel-error

## 简介

Capture and monitor detailed error logs with nice dashboard and UI.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
