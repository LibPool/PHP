# cetera-labs/library

> 标签: PHP

## 简介

Сторонние JS-библиотеки старого back-office Fastsite CMS 3.x: ExtJS 4.2, ace, js-beautify, cropper, html-minifier, плагин youtube для CKEditor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
