# dungang/yii2-inline-attachment

> 标签: PHP

## 简介

Easily paste and upload files/images in plain textareas http://git.razko.nl/InlineAttachment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
