# giorgio93p/bin-packing

> 标签: bin packing

## 简介

Implementation of a branch and bound algorithm for bin packing, where bins can have a lower bound on their capacity

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
