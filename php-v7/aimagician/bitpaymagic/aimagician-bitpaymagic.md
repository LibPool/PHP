# aimagician/bitpaymagic

> 标签: bitcoin, bitpay, library

## 简介

A Laravel 5 wrapper package for an amazing BitPay payment system

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
