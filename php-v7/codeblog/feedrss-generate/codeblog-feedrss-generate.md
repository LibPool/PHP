# codeblog/feedrss-generate

> 标签: CodeBlog, Facebook ADS, FeedRss, Google Merchant, feed, rss

## 简介

Generate an Rss Feed of the website content

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
