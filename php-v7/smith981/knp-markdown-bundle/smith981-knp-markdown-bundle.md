# smith981/knp-markdown-bundle

> 标签: bundle, knp, knplabs, markdown

## 简介

Knplabs markdown bundle transforms markdown into html

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
