# lens/lens

> 标签: lens, php, phpunit, test, testing, unit

## 简介

Lens is a unit-testing framework for PHP with readable tests that catch everything.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
