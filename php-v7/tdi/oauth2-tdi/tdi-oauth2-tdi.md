# tdi/oauth2-tdi

> 标签: PHP

## 简介

TDi OAuth 2.0 support for PHP Leagues Oauth 2.0 Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
