# 51degrees/fiftyone.pipeline.cloudrequestengine

> 标签: 51degrees

## 简介

Cloud request engine for 51Degrees Pipeline API. Used to send requests to the 51Degrees cloud service.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
