# luyadev/luya-testsuite

> 标签: luya, module, php

## 简介

TestCases and Data for LUYA Modules and Components. Makes testing less pain.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
