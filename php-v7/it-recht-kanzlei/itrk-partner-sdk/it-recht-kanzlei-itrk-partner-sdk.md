# it-recht-kanzlei/itrk-partner-sdk

> 标签: IT-Recht, ITKR, Partner-API, sdk

## 简介

SDK zur Verwendung der ITRK Partner-API und zum Ausführen und Abrufen von Bestellungen.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
