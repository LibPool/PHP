# dcarbone/file-object-plus

> 标签: SplFileObject, file, file iterator, pagination, php, search

## 简介

A simple extension of the PHP \SplFileObject class

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
