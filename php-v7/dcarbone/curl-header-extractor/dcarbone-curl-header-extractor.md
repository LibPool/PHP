# dcarbone/curl-header-extractor

> 标签: curl, extractor, file, header, headers, http, php, response

## 简介

Utility to extract headers from PHP CURL to file request.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
