# dcarbone/php-consul-api-bundle

> 标签: PHP

## 简介

Bundle to enable usage of dcarbone/php-consul-api inside of a Symfony 3 project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
