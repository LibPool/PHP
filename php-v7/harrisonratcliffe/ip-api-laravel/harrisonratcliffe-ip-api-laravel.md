# harrisonratcliffe/ip-api-laravel

> 标签: IP API, ip api laravel, ip api php, ip-api.com

## 简介

A simple Laravel package to get IP address information from ip-api.com

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
