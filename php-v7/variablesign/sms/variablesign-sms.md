# variablesign/sms

> 标签: arkesel, mnotify, otp, sms, sms online gh, usms gh

## 简介

A Laravel SMS Gateway Integration package for bulk SMS providers in Ghana

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
