# rinvex/addresses

> 标签: address, addressable, billing, city, country, eloquent, laravel, latitude, longitude, model, polymorphic, postal, primary, rinvex, shipping, state, street

## 简介

Rinvex Addresses is a polymorphic Laravel package, for addressbook management. You can add addresses to any eloquent model with ease.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
