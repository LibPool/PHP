# pinano/select2-bundle

> 标签: bundle, jquery, select2

## 简介

Symfony2 bundle for wrapping the famous select2 jquery plugin by @ivaynberg

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
