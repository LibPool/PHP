# artmedia-llc/instagram-php-scraper

> 标签: instagram, scraper

## 简介

Instagram PHP Scraper. Get account information, photos and videos without any authorization

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
