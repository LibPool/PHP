# intelogie/bootstrap-colorpicker

> 标签: PHP

## 简介

Fancy and customizable colorpicker plugin for Twitter Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
