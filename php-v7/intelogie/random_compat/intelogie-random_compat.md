# intelogie/random_compat

> 标签: csprng, pseudorandom, random

## 简介

PHP 5.x polyfill for random_bytes() and random_int() from PHP 7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
