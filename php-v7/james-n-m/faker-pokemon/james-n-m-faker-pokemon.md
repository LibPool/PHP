# james-n-m/faker-pokemon

> 标签: faker, faker-pokemon, pokemon, pokemon-faker

## 简介

Faker-Pokemon is a Faker provider that generates fake pokemon data for you!

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
