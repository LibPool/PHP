# xeeeveee/sudoku

> 标签: generation, generator, solver, solving, sudoku

## 简介

PHP sudoku logic library - Generate and solve sudoku puzzles

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
