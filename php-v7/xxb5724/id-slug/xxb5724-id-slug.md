# xxb5724/id-slug

> 标签: id, slug, slug-driver

## 简介

A Flarum 2.0 extension. Use id as slug in discussion URL.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
