# afeys/flphpfile

> 标签: chainable, file, helper, manipulation, util

## 简介

Helper clas to make handling ascii files in PHP a lot easier and more efficient

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
