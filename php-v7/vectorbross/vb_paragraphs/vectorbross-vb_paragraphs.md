# vectorbross/vb_paragraphs

> 标签: PHP

## 简介

Adds Vector BROSS paragraph types and functionality to edit them in the frontend.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
