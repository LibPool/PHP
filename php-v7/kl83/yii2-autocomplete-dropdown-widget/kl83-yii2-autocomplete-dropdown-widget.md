# kl83/yii2-autocomplete-dropdown-widget

> 标签: PHP

## 简介

Dropdown widget with autocomplete jQuery UI and ability to send in form identifier of the selected item.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
