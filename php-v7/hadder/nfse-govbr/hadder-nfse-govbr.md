# hadder/nfse-govbr

> 标签: nfse, nfse-govbr

## 简介

Pacote para geração de NFSe Dueto (Cachoeira do Sul) usando componentes NFePHP (https://github.com/nfephp-org)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
