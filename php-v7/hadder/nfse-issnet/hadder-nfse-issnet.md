# hadder/nfse-issnet

> 标签: fernando friedrich, hadder, issnet, nfse, nfse-issnet, rainart

## 简介

Pacote para geração de NFSe ISSNET  usando componentes NFePHP (https://github.com/nfephp-org)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
