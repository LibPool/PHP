# nhalstead/webhook-coordinator

> 标签: PHP

## 简介

Trigger Webhooks to post data to channels in php. This will work with Slack, Discord, and other systems that use WebHooks.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
