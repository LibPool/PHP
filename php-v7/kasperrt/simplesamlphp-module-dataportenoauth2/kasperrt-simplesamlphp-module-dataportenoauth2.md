# kasperrt/simplesamlphp-module-dataportenoauth2

> 标签: Authentication

## 简介

Provides OAuth2 dataporten as a connection option for providers in SimpleSAMLphp.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
