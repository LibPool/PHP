# f-liva/eloquent-to-raw-sql

> 标签: eloquent-to-raw-sql, laravel, to-raw-sql

## 简介

Exposes the eloquent toRawSql method to display the raw query in beautified form.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
