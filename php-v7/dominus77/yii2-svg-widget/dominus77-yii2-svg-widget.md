# dominus77/yii2-svg-widget

> 标签: Dominus77, extension, svg, widget, yii2

## 简介

The lightweight library for manipulating and animating SVG for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
