# carlosreig/request-data-extractor

> 标签: PHP

## 简介

A simple class that extracts the user IP, the user browser and the user operating system from the HTTP Request

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
