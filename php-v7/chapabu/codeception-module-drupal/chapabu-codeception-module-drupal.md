# chapabu/codeception-module-drupal

> 标签: codeception, drupal, test, testing

## 简介

A module for Codeception that exposes the Drupal API to test suites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
