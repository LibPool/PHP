# emotality/tawk-laravel

> 标签: chat, laravel, tawk, tawk.to, tawkto, widget

## 简介

A tawk.to chat widget for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
