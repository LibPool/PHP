# factorenergia/yii2-tag-dependency-helper

> 标签: cache, yii2

## 简介

Helper for unifying cache tag names with invalidation support in yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
