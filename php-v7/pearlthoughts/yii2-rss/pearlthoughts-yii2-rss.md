# pearlthoughts/yii2-rss

> 标签: PHP

## 简介

Yii2 Framework extension to provide functionality for consuming RSS and Atom feeds using zend-feed library.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
