# origammi/symfony-swiftmailer-email-validator

> 标签: PHP

## 简介

An extension to Symfony's EmailValidator which enforces the same grammar as Swiftmailer does.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
