# mgh-tech/magento2-dev-media-downloader

> 标签: PHP

## 简介

Magento 2 module for on-demand downloading of missing media files from a remote instance during development.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
