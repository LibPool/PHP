# dlevsha/nasgrate

> 标签: compare databases, database, database diff, database migration, database refactoring, database schema diff, database schema migration, database schema migration tool, database schemas, migrations

## 简介

Nasgrate is a console utility that let you organise database schema migration process at a consistent and easy way. It supports mysql, mssql, postgresql, oracle and other databases

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
