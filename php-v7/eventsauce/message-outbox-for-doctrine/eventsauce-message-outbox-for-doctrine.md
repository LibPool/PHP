# eventsauce/message-outbox-for-doctrine

> 标签: PHP

## 简介

Message Outbox Pattern implementation for Doctrine DBAL 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
