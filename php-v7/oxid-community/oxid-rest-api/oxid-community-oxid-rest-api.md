# oxid-community/oxid-rest-api

> 标签: OXID, api, framework, laravel, lumen, rest

## 简介

REST API for OXID eShop based on Laravel Lumen Framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
