# jakecleary/ultrapress-library

> 标签: framework, ultrapress, wordpress

## 简介

An advanced library for working with Wordpress; the core of the Ultrapress framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
