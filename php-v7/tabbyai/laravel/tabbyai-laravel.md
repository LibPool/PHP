# tabbyai/laravel

> 标签: api, integration, package, payment, payment gateway, sdk, tabby

## 简介

Laravel package for integrating with Tabby.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
