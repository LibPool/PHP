# axdlee/laravel-config-writer

> 标签: PHP

## 简介

Write to Laravel Config files and maintain file integrity. Support Laravel 5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
