# coderscare/device

> 标签: PHP

## 简介

Device Conditions - Provides additional TypoScript conditions for user agent detections based on the Matomo Device Detector Library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
