# laemmi/laemmi-yourls-comment-label

> 标签: comment, labels, plugin, yourls

## 简介

Plugin for YOURLS. Add comment and labels for url entry.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
