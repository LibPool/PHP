# medz/oss-stream-wrapper

> 标签: medz, oss, php, streamwrapper, wrapper

## 简介

A Aliyun OSS streamWrapper class and Aliyun OSS SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
