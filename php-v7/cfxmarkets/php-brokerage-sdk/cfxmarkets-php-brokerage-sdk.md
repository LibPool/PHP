# cfxmarkets/php-brokerage-sdk

> 标签: api, brokerage, cfx, client

## 简介

A public PHP api library to access the CFX Markets brokerage api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
