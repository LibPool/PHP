# cfxmarkets/php-public-models

> 标签: api, brokerage, cfx, data objects, exchange, framework

## 简介

This package provides all of CFX's public data objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
