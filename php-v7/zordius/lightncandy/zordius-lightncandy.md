# zordius/lightncandy

> 标签: handlebars, logicless, mustache, php, template

## 简介

An extremely fast PHP implementation of handlebars ( http://handlebarsjs.com/ ) and mustache ( http://mustache.github.io/ ).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
