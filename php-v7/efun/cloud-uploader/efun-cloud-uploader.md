# efun/cloud-uploader

> 标签: PHP

## 简介

PHP 通用云存储文件，大文件分片，base64上传类库，支持阿里云 OSS、腾讯云 COS、七牛云 Kodo

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
