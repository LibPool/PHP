# bnet/bnrepos

> 标签: abstraction, file, filesystem, media, repository

## 简介

lazy PHP5 library that provides Repositories as filesystem abstraction layer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
