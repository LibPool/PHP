# jyggen/youtubethumb

> 标签: image, thumbnail, youtube

## 简介

A PHP class created to help you load, edit and save thumbnails from videos on Youtube.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
