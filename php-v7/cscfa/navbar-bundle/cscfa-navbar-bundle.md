# cscfa/navbar-bundle

> 标签: cscfa, navbar

## 简介

The NavBarBundle is a symfony2 navbar manager that use a Resources/config/navbar.yml file to manage navbar display

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
