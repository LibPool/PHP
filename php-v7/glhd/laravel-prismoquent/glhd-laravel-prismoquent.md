# glhd/laravel-prismoquent

> 标签: Prismic, laravel, prismic.io

## 简介

Prismoquent lets you access Prismic.io using the same methods you're used to in Eloquent.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
