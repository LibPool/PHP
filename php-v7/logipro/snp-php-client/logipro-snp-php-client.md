# logipro/snp-php-client

> 标签: API-Client, SNP, psr-18, publishing, social-networks

## 简介

PHP client for the SocialNetworksPublisher (SNP) external API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
