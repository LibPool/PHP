# kassko/data-mapper-bundle

> 标签: access, dao, data, entity, extract, hydrate, hydration, mapper, orm, repository

## 简介

Integrates data-mapper in Symfony projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
