# sqmk/glovebox

> 标签: container, dependency injection, di, glovebox

## 简介

Glovebox - A lightweight Dependency Injection Container for PHP 5.4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
