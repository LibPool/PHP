# tarcisioq/api-beamer-php

> 标签: beamer, beamer-php, getbeamer

## 简介

A simple gateway for Beamer manager. Unofficial PHP library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
