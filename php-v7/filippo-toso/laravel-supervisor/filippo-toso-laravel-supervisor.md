# filippo-toso/laravel-supervisor

> 标签: PHP

## 简介

A simple supervisor tool that allows to run long lived Artisan commands (i.e. the queue) from the crontab

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
