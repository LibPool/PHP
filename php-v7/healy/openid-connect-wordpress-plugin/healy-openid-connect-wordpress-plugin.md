# healy/openid-connect-wordpress-plugin

> 标签: PHP

## 简介

Log in to your WordPress site with any OpenId-Connect standard compliant Identity Service Provider

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
