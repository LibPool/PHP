# akr4m/scoping

> 标签: database, eloquent, filter, laravel, model, scope

## 简介

This scopes allow you to add constraints to all queries for a given model. Filter your data easily.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
