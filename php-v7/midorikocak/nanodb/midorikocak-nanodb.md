# midorikocak/nanodb

> 标签: database, datasource, midorikocak, nanodb

## 简介

Nano DB is a tiny php library that allows you to define easily usable repositories.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
