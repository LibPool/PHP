# hoku-lib/t5o

> 标签: l10n, localization, t5o, tagengo

## 简介

Very simple localization library. The meaning of T5o is Tagengo. Tagengo is Japanese. This has the same meaning as localization.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
