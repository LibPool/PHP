# gjbateup/neoeloquent

> 标签: database, graph, neo4j, neoeloquent, ogm

## 简介

Laravel wrapper for the Neo4j graph database REST interface

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
