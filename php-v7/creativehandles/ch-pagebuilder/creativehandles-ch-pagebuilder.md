# creativehandles/ch-pagebuilder

> 标签: ch-pagebuilder, creativehandles

## 简介

Page builder for CORE CMS in Creativehandles, Something like a jigsaw puzzle :P

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
