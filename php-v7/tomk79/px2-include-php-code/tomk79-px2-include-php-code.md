# tomk79/px2-include-php-code

> 标签: pickles, pickles2

## 简介

Pickles 2 に、パブリッシュ後のコードにPHPを出力できる文法を追加します。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
