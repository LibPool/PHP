# bryanjhv/laravel-blade-cdn

> 标签: asset, blade, cdn, directive, laravel, url

## 简介

Blade directive to get asset URLs according to environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
