# starinc/abigail

> 标签: api, php, rest, restful

## 简介

Abigail is the fork from marcj/php-rest-service, which is a simple and fast PHP class for server side RESTful APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
