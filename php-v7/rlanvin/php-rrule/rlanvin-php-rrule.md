# rlanvin/php-rrule

> 标签: date, ical, recurrence, recurring, rrule

## 简介

Lightweight and fast recurrence rules for PHP (RFC 5545)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
