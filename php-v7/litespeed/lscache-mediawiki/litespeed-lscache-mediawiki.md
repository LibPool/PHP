# litespeed/lscache-mediawiki

> 标签: cache, litespeed, mediawiki

## 简介

MediaWiki Full Page Cache for LiteSpeed Web Server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
