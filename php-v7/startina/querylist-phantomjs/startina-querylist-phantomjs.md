# startina/querylist-phantomjs

> 标签: PHP

## 简介

QueryList Plugin: Use PhantomJS to crawl Javascript dynamically rendered pages.(headless WebKit ) 使用PhantomJS采集JavaScript动态渲染的页面

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
