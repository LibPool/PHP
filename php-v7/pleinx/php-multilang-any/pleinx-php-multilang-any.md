# pleinx/php-multilang-any

> 标签: api, i18n, multilang, multilanguage, multilingual, php, slim-framework, translation, translator, translator-tool, wordpress

## 简介

A simple resolver for language snippets.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
