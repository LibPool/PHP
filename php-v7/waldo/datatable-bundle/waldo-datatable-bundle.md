# waldo/datatable-bundle

> 标签: Symfony2, datatable, jquery

## 简介

Symfony2 Ajax Datagrid Bundle for doctrine2 entities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
