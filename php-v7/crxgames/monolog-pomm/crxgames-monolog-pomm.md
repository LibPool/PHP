# crxgames/monolog-pomm

> 标签: database, log, logging, monolog, pomm, postgresql

## 简介

A handler for Monolog that sends messages to Postgres via a POMM connection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
