# esysteme/mysql-sys

> 标签: PHP

## 简介

A collection of views, functions and procedures to help MySQL administrators get insight in to MySQL Database usage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
