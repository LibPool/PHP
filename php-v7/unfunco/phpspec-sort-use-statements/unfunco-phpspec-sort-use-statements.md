# unfunco/phpspec-sort-use-statements

> 标签: BDD, TDD, phpspec

## 简介

PhpSpec extension for sorting use statements in generated files.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
