# devdome/devdome-analytics

> 标签: analytics, bot-detection, cookieless, privacy, wordpress, wordpress-plugin

## 简介

Free cookieless WordPress analytics plugin: real-time visitor stats with humans, bots and AI crawlers counted separately, outbound click tracking, public Stats API and MCP server. Free alternative to Plausible, Fathom, Matomo, MonsterInsights and Google Analytics.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
