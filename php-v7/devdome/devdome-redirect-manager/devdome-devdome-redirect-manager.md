# devdome/devdome-redirect-manager

> 标签: 301-redirect, geo-targeting, redirects, wordpress, wordpress-plugin

## 简介

Free WordPress redirect plugin: 301/302/307/308/JavaScript redirects with geo targeting, device targeting, link rotation, scheduling and per-rule statistics. Free alternative to Redirection Pro features, Pretty Links Pro and ThirstyAffiliates Pro.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
