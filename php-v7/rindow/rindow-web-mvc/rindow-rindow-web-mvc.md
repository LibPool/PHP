# rindow/rindow-web-mvc

> 标签: framework, mvc, psr-7, rindow, web

## 简介

Web-MVC framework based on PSR-7 middleware

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
