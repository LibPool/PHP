# floor12/yii2-module-files

> 标签: files, floor12, upload, yii, yii 2, yii2, yii2 module

## 简介

Yii2 module to upload and manage files to your models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
