# webplusm/laraextjs

> 标签: LaraExtjs, extjs, laravel

## 简介

Laravel package interface for Sencha Extjs - CRUD operation

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
