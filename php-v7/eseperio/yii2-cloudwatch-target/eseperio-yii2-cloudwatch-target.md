# eseperio/yii2-cloudwatch-target

> 标签: aws, cloudwatch, log, yii2

## 简介

A Yii 2 log target for AWS Cloudwatch Logs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
