# eseperio/yii2-bootstrap

> 标签: bootstrap, yii2

## 简介

Modified version of the Twitter Bootstrap extension for the Yii framework to be compatible with bootstrap5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
