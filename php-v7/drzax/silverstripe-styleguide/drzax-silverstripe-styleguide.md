# drzax/silverstripe-styleguide

> 标签: silverstripe, style-guide

## 简介

A fork of the Kalei Style Guide designed to work with SilverStripe themes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
