# samuell/revisions-plugin

> 标签: Revisions, changes, octobercms

## 简介

Revisions allows to extend any model with Revisionable trait with more features and easy to use.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
