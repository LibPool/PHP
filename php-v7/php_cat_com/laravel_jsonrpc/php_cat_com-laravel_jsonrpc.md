# php_cat_com/laravel_jsonrpc

> 标签: jsonrpc, laravel, module, php-cat.com

## 简介

модуль для laravel 8 чтобы работать с помощью JsonRPC 2.0

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
