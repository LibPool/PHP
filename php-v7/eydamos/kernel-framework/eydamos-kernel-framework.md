# eydamos/kernel-framework

> 标签: PHP

## 简介

Provides everything needed for a kernel and bundles without the massive overhead of the symfony/http-kernel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
