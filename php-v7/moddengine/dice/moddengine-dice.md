# moddengine/dice

> 标签: dependency injection, dependency injection container, di, ioc

## 简介

A minimalist Dependency injection container (DIC) for PHP 7.1+ and PHP 8.0+.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
