# kit-tools/yii2-imagehandler

> 标签: extension, image, popover, widget, yii 2, yii2

## 简介

A library for image processing for Yii2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
