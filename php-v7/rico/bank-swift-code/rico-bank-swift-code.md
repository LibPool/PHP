# rico/bank-swift-code

> 标签: BIC, Bank, IBAN, code, php, swift

## 简介

Fetch bank swift codes the easiest and minamalest way possible.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
