# brightoak/wordpress-tools

> 标签: brightoak, wordpress, wordpress-tools

## 简介

A collection of tools for doing WordPress tasks in a modern PHP way.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
