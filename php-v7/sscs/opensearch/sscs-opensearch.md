# sscs/opensearch

> 标签: aliyun, aliyunopensearch, aliyunsearch, opensearch

## 简介

Encapsulation Aliyun open search API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
