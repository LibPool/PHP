# ghabxph/resolver

> 标签: PHP

## 简介

Dynamically resolve class using this Gabriel's Resolver. Inspired from Laravel's app()->make() class provider.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
