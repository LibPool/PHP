# genouest/bioinfo-bundle

> 标签: bioinfo, genouest

## 简介

This bundle contains some useful utils to manipulate bioinformatics data (fasta sequences for example).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
