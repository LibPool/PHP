# yowcow/mime-base64-urlsafe

> 标签: base64, mime, uri, url

## 简介

PHP-version of URL safe base64 encoding/decoding

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
