# kmcculloch/phpspec-code-sniffer

> 标签: PHP_CodeSniffer, code, phpspec, sniffer, standards

## 简介

Very simple PHPSpec code sniffing, based on PSR1 and PSR2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
