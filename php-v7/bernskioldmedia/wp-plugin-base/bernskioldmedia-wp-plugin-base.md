# bernskioldmedia/wp-plugin-base

> 标签: PHP

## 简介

A WordPress plugin base that contains helpful base classes and functions that we can extend upon when developing WordPress plugins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
