# mmedia/laravel-spa

> 标签: laravel-spa, mmedia

## 简介

Add required CORS settings and some routes to help with SPA authentication using Fortify and Sanctum

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
