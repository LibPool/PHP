# sunveloper/phpspec-phpspec

> 标签: BDD, SpecBDD, TDD, spec, specification, testing, tests

## 简介

Specification-oriented BDD framework for PHP 7.1+

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
