# openconextapps/simplesamlphp-module-vootgroups

> 标签: PHP

## 简介

Retrieves group membership information from a VOOT provider and adds the groups to a SAML attribute

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
