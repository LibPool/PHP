# imjoehaines/flowder

> 标签: fixture-loading, fixtures, mysql, sqlite, testing

## 简介

A simple and extensible fixture loader for PHP 7.3+, supporting SQLite and MySQL

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
