# crowdsec/bouncer

> 标签: IP, appsec, blocker, bouncer, captcha, crowdsec, geoip, http, ip range, middleware, security, waf

## 简介

The official PHP bouncer library for the CrowdSec Local API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
