# crowdsec/capi-client

> 标签: capi, client, crowdsec, curl, rest, security, watcher

## 简介

The official PHP client for the CrowdSec Central API (CAPI)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
