# crowdsec/lapi-client

> 标签: appsec, bouncer, client, crowdsec, curl, lapi, rest, security

## 简介

The official PHP client for the CrowdSec Local API (LAPI)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
