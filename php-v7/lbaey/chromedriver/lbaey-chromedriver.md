# lbaey/chromedriver

> 标签: Behat, Browser Testing, Chromedriver, MAC, linux, osx, selenium, windows

## 简介

Utility for installing Chromedriver, whatever platform you are on, for use with Behat

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
