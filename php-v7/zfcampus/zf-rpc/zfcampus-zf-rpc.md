# zfcampus/zf-rpc

> 标签: ZendFramework, module, rpc, zend, zf

## 简介

ZF2 Module for simplifying the creation of RPC services

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
