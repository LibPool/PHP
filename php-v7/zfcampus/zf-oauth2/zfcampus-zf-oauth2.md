# zfcampus/zf-oauth2

> 标签: ZendFramework, api, framework, oauth2, zf

## 简介

ZF module for implementing an OAuth2 server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
