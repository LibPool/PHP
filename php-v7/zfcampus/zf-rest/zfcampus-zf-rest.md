# zfcampus/zf-rest

> 标签: ZendFramework, module, rest, zend, zf, zf3

## 简介

ZF Module providing structure for RESTful resources

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
