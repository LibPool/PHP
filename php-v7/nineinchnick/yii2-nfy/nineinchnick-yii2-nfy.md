# nineinchnick/yii2-nfy

> 标签: PHP

## 简介

A generic message queue interface with various implementations for the Yii 2.0 framework. Basic interface included.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
