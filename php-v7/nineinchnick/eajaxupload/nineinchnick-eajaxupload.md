# nineinchnick/eajaxupload

> 标签: ajax, upload, yii

## 简介

Yii PHP Framework extension utilizing fileUploader js library to upload files through AJAX without Flash.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
