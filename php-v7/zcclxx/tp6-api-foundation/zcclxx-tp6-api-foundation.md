# zcclxx/tp6-api-foundation

> 标签: PHP

## 简介

ThinkPHP 6 API 基座：可插拔登录解析、request 注入用户、CRUD Logic 封装（可选 JWT）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
