# softcomtecnologia/asset-cdn

> 标签: AWS Cloudfront, cdn, content delivery network, laravel

## 简介

Serve Laravel Assets from a Content Delivery Network (CDN)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
