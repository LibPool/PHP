# softcomtecnologia/custom-accessor-and-mutator

> 标签: PHP

## 简介

to set attributes laravel model (accessors and mutators) without creating methods

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
