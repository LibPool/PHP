# anrdaemon/mylittlegallery

> 标签: PHP

## 简介

My Little Gallery, a PHP class and templates to create a quick drop-in HTML gallery.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
