# watafactory/dwh-query-doctrine-bundle

> 标签: PHP

## 简介

This bundle extends DWH Bundle registering the types according the Doctrine to build the Graphql Schema

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
