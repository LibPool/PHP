# atorscho/crumbs

> 标签: breadcrumbs, crumbs, laravel, navigation

## 简介

Breadcrumbs package for Laravel 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
