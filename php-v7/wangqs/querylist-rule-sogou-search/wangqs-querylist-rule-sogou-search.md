# wangqs/querylist-rule-sogou-search

> 标签: PHP

## 简介

QueryList Plugin: sogou with abstract. QueryList搜狗搜索插件,可增加搜索结果简介和关联搜索词

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
