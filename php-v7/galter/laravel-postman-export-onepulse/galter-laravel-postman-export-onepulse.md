# galter/laravel-postman-export-onepulse

> 标签: Postman, collection, export, laravel

## 简介

Export your Laravel routes to a Postman collection .json file

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
