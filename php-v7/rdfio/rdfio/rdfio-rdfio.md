# rdfio/rdfio

> 标签: Linked Data, RDF, Semantic MediaWiki, mediawiki

## 简介

RDFIO extension for importing data in RDF format to Semantic MediaWiki

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
