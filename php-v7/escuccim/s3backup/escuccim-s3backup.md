# escuccim/s3backup

> 标签: amazon S3, backup, backup db, escuccim, mysqldump

## 简介

Laravel shell command to backup files to Amazon S3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
