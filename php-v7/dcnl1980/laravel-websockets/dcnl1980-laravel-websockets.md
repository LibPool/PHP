# dcnl1980/laravel-websockets

> 标签: beyondcode, laravel, laravel-websockets, php

## 简介

An easy to launch a Pusher-compatible WebSockets server for Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
