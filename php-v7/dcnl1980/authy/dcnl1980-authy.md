# dcnl1980/authy

> 标签: Authentication, api, authy, laravel two-factor authentication, two-factor

## 简介

Plugin for enabling two-factor authentication in Laravel applications

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
