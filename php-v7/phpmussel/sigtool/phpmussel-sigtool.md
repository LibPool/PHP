# phpmussel/sigtool

> 标签: clamav, generator, phpmussel, signatures, sigtool

## 简介

Generates signatures for phpMussel using main.cvd and daily.cvd from ClamAV.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
