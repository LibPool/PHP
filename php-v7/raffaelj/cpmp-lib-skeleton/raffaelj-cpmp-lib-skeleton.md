# raffaelj/cpmp-lib-skeleton

> 标签: PHP

## 简介

Skeleton to use CpMultiplane and Cockpit CMS as libraries with a clean root directory (not compatible with Cockpit CMS v2)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
