# raffaelj/cockpit-bettermarkdown

> 标签: TOC, cockpit, markdown, parsedown

## 简介

Cache, task lists and ToC support for markdown conversion with Cockpit CMS v1

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
