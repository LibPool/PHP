# ollieday/yii2-uuid

> 标签: extension, guid, identifier, uuid, yii2

## 简介

Component for generating UUIDs with ramsey/uuid.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
