# palcera/palcera_theme

> 标签: PHP

## 简介

Base theme for Palcera CMS templates. Generated from Mercury, provides breakpoints, image styles, and core SDC components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
