# piratelp/ileaf

> 标签: Laravel CMS, flatfile cms

## 简介

Interactive Leaf: Flat file CMS component of Interactive Books' Atelier.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
