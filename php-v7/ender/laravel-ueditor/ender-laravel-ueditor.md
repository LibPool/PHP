# ender/laravel-ueditor

> 标签: editor, laravel, ueditor, wysiwyg

## 简介

A laravel package of ueditor,which is baidu's open source WYSIWYG editor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
