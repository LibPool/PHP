# cambridgeuniversity/ice-job-bundle

> 标签: PHP

## 简介

A Symfony2 bundle for processing ICE domain jobs using Gearman

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
