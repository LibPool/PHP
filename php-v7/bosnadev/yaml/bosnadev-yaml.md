# bosnadev/yaml

> 标签: config, larapress, laravel, symfony, yaml

## 简介

A package to add Yaml file support for Laravel 4 Configuration

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
