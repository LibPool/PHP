# sanpi/gtmetrix

> 标签: PHP

## 简介

A PHP REST client for the Web Testing Framework (WTF) Testing Service API. Currently only supports GTmetrix

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
