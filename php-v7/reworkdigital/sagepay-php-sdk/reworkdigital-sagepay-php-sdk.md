# reworkdigital/sagepay-php-sdk

> 标签: gateway, php, sagepay, sdk

## 简介

The official Sage Pay PHP SDK for server and direct integrations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
