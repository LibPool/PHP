# loungeroom/dompdf-bundle

> 标签: bundle, dompdf, pdf, symfony

## 简介

Integrates the Dompdf (0.8) library into a Symfony2 application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
