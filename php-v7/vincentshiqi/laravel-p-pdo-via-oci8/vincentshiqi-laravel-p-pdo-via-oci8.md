# vincentshiqi/laravel-p-pdo-via-oci8

> 标签: PHP

## 简介

PDO userspace driver proxying calls to PHP OCI8 driver

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
