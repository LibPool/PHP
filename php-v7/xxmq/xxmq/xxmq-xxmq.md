# xxmq/xxmq

> 标签: MQ, php queue, rocketMq, xiaoxiangxueyuan

## 简介

小象学院MQ 集成包

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
