# openeyes/oph-ci-phasing

> 标签: PHP

## 简介

Phasing module for OpenEyes, allows recording of multiple timed IOP values in a single event

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
