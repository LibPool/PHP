# magebitcom/magento2-hyva-checkout-utrust-payment

> 标签: PHP

## 简介

This module enables to use Utrust_Payment module with Hyva checkout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
