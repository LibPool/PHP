# affittocertificato/pushnotificationhandler

> 标签: affitto, certificato, notifications, push

## 简介

Lightweight implementation for push notifications from Affitto Certificato API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
