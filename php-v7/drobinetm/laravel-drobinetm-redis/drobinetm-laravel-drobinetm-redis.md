# drobinetm/laravel-drobinetm-redis

> 标签: drobinetm, laravel, redis

## 简介

Package to obtain the info of a redis server used by our application through a json response.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
