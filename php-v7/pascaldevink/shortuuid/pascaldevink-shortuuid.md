# pascaldevink/shortuuid

> 标签: guid, identifier, uuid

## 简介

PHP 7.4+ library that generates concise, unambiguous, URL-safe UUIDs

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
