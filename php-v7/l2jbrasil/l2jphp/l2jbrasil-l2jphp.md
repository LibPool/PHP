# l2jbrasil/l2jphp

> 标签: L2JBR, L2jBrasil, l2j

## 简介

A PHP Framework for standard L2J application development.: "One library to rule them all"

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
