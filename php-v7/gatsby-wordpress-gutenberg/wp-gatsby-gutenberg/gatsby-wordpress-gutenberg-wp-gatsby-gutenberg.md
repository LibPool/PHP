# gatsby-wordpress-gutenberg/wp-gatsby-gutenberg

> 标签: editor, gatsby, gutenberg, javascript, react, wordpress, wp

## 简介

Enhance your gatsby project with gutenberg.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
