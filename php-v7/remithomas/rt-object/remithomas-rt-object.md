# remithomas/rt-object

> 标签: duplicate, insert, mysql, nosql, object, zf2

## 简介

Create an entity class to use mysql like NOSQL way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
