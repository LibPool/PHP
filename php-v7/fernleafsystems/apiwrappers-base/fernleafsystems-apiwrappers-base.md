# fernleafsystems/apiwrappers-base

> 标签: PHP

## 简介

Forms the basis, and simplifies the implementation, of all Fernleaf Systems' API Wrappers

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
