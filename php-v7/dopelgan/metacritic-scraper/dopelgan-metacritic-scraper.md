# dopelgan/metacritic-scraper

> 标签: api, metacritic, metacritic-metadata, metacritic-scraper, metacritic-scraping, metacritic-webscrapping, metacritic.com, parser, php, scraper, scraping

## 简介

Library for retrieving movie, game, album, tv, person, video, company, story information from metacritic.com

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
