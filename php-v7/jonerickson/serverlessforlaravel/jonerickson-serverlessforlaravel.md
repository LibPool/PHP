# jonerickson/serverlessforlaravel

> 标签: bref, lambda, laravel, serverless, vapor

## 简介

A package to provide Serverless support for Laravel projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
