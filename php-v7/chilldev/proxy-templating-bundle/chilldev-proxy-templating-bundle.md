# chilldev/proxy-templating-bundle

> 标签: Symfony2, chilldev, engine, framework, templating

## 简介

Dynamic templating proxy references bundle for Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
