# omnilight/yz2

> 标签: administation panel, framework, yii, yz

## 简介

Yz2 extension for Yii2 framework adds ability to build Yii2 application very fast and confortable

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
