# eddturtle/direct-upload

> 标签: amazon, aws, direct, php, s3, signature, upload

## 简介

Composer Package to build an AWS Signature ready to Direct Upload to S3

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
