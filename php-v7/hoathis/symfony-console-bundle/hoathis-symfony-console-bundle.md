# hoathis/symfony-console-bundle

> 标签: bundle, console, hoa, library, symfony

## 简介

The Hoa\Console Symfony 2 bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
