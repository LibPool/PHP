# hoathis/symfony-console-bridge

> 标签: Bridge, console, hoa, library, symfony

## 简介

The Hoa\Console to Symfony\Console bridge.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
