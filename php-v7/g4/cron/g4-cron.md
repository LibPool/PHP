# g4/cron

> 标签: cron, task

## 简介

g4 cron like parser with ability to parse expressions with resolution in seconds - based on PHP Cron Expression Parser

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
