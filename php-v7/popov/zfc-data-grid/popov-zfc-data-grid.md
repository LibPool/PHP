# popov/zfc-data-grid

> 标签: agere, grid, zfc-datagrid

## 简介

Module for simple use and creating new Grid based on ZfcDatagrid

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
