# logicbrush/silverstripe-sitemappage

> 标签: Sitemap, silverstripe

## 简介

A module for the SilverStripe CMS which produces a page listing every (public) page on your site.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
