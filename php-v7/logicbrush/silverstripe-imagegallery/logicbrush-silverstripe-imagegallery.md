# logicbrush/silverstripe-imagegallery

> 标签: gallery, silverstripe

## 简介

A module for the SilverStripe CMS which allows you to organize images in a gallery format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
