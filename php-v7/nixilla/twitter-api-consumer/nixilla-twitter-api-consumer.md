# nixilla/twitter-api-consumer

> 标签: api, oauth2, twitter

## 简介

Twitter API consumer in PHP, supports API 1.1 and works with OAuth 1.1 as well as OAuth 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
