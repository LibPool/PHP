# mvs3d/laravel-redlock

> 标签: laravel redis lock, redis lock, redlock

## 简介

Redis distributed locks for laravel with using PhpRedis

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
