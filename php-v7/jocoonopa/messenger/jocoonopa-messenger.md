# jocoonopa/messenger

> 标签: Messenger, api, bot messenger, facebook, facebook messenger

## 简介

PHP Library to interact with Facebook Messenger Platform

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
