# nhymxu/php-floc-disable

> 标签: FLoC, nhymxu, php-floc-disable

## 简介

PHP middleware to disable Google's Federated Learning of Cohorts (FLoC) tracking

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
