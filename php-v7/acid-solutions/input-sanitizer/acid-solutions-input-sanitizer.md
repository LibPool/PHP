# acid-solutions/input-sanitizer

> 标签: acid, clean, codeigniter, fuelphp, input, laravel, package, php, sanitize, sanitizer

## 简介

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
