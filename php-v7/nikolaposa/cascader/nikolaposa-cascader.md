# nikolaposa/cascader

> 标签: cascade, cascade-creation, factory, generic, instantiate

## 简介

Utility for creating objects in PHP from constructor parameters definitions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
