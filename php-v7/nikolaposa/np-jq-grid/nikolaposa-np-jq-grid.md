# nikolaposa/np-jq-grid

> 标签: jqgrid, module, zend, zf2

## 简介

ZF2 Module which facilitates server-side integration of a JqGrid jQuery plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
