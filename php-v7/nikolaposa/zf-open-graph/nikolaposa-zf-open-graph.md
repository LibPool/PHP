# nikolaposa/zf-open-graph

> 标签: module, open graph, zend, zf2

## 简介

ZF2 module which facilitates insertion and utilization of OpenGraph meta tags

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
