# amendozadev/eth_rpc

> 标签: binance, ethereum, rpc, wallet

## 简介

Create Ethereum wallet and/or connect to JSON-RPC Endpoint from Ethereum or compatibles like BSC

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
