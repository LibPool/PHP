# sfynx-project/mobile-browscap-bundle

> 标签: Browscap, mobile

## 简介

This Bundle provides library to run Browscap Manager`s utilities and MobileDetect Manager`s utilities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
