# sfynx-project/tool-cache-bundle

> 标签: cache, file, memcache, tool, ttl

## 简介

This Bundle provides classes to cache handlers (memcache, files)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
