# sfynx-project/tool-migration-bundle

> 标签: migration

## 简介

This Bundle provides a command to execute migration with a versionning system like doctrine migration.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
