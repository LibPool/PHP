# qualityunit/tnef-decoder

> 标签: tnef decoder, winmail.dat

## 简介

TNEF Decoder library extracted from squirell mail plugin to decode winmail.dat file in email attachment

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
