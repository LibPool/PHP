# zarincheg/telegram-bot-dialogs

> 标签: PHP

## 简介

Telegram Bot API PHP SDK extension that allows to implement dialogs in bots

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
