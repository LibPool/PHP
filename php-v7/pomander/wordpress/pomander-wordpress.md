# pomander/wordpress

> 标签: deploy, git, pomander, svn, wordpress

## 简介

Pomander plugin to deploy and manage Wordpress sites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
