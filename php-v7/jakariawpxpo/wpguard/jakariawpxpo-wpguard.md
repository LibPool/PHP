# jakariawpxpo/wpguard

> 标签: guidelines, lint, phpcs, plugin, wordpress, wordpress.org, wpcs

## 简介

RuboCop/Brakeman-style checker for WordPress plugins: WordPress.org guideline candidates, PHPCS (WPCS) and Plugin Check in one report.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
