# simialbi/yii2-widget-timedropper

> 标签: picker, timedropper, timepicker, yii2

## 简介

Yii 2 Widget for timedropper jquery plugin of felice gattuso

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
