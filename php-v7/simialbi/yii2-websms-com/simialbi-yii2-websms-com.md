# simialbi/yii2-websms-com

> 标签: sms, sms api, websms, websms.com, yii2

## 简介

A PHP-client-library for using websms.com SMS services with yii2 framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
