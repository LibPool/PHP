# chabibnr/ayom

> 标签: basic, framework, oauth2, project template, rbac, yii2

## 简介

Project template for YII2 [AdminLTE Yii2 Oauth2 Mimin]

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
