# brotkrueml/typo3-example-site-sets-compat

> 标签: PHP

## 简介

Example of how to provide site sets in an extension that is compatible with older TYPO3 versions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
