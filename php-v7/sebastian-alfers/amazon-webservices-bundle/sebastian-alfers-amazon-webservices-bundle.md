# sebastian-alfers/amazon-webservices-bundle

> 标签: amazon, aws, web services

## 简介

A Symfony2 Bundle for interfacing with Amazon Web Services (AWS)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
