# noeles/tdengine-php

> 标签: PHP

## 简介

TDengine REST 客户端与 ORM 合并包（基于 yurunsoft/tdengine-restful-connector 与 albertwill/tdengine-orm 源码整合，命名空间未变）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
