# fomvasss/laravel-meta-tags

> 标签: Sitemap, laravel, meta, meta tags, seo, tags, xml-map

## 简介

A package to manage SEO (meta-tags, xml-fields, etc.)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
