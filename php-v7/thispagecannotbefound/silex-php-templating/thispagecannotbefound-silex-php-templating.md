# thispagecannotbefound/silex-php-templating

> 标签: Symfony2, phpengine, silex, templating

## 简介

Silex Service Provider for the Symfony 2 PHP Templating engine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
