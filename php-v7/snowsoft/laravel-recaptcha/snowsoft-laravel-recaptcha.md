# snowsoft/laravel-recaptcha

> 标签: captcha, laravel, recaptcha, validation

## 简介

Simple and painless Google reCAPTCHA package for Laravel framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
