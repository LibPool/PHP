# snowsoft/cdn-laravel-adapter

> 标签: cdn, cdn-services, filesystem, image, laravel, storage

## 简介

Laravel Storage adapter for CDN Services Node.js backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
