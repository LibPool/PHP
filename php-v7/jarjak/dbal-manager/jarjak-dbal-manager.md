# jarjak/dbal-manager

> 标签: database, dbal, persistence, queryobject

## 简介

Doctrine DBAL helper for bulk data imports in MySQL and other stuff.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
