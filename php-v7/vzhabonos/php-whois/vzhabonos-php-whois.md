# vzhabonos/php-whois

> 标签: asn, domain, info, lookup, parser, php, query, routes, tld, whois

## 简介

PHP WHOIS provides parsed and raw whois lookup of domains and ASN routes. PHP 7.2+ compatible

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
