# babylonpartners/php-dependency-imap

> 标签: email, imap, mail

## 简介

Object-oriented IMAP for PHP - altered for BabylonParters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
