# nedarta/yii2-clean-html-behavior

> 标签: Behavior, Purifier, html, yii2

## 简介

A Yii2 behavior to clean and sanitize HTML content in ActiveRecord attributes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
