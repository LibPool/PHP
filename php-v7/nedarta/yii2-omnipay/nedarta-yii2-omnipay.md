# nedarta/yii2-omnipay

> 标签: extension, omnipay, payment, paypal, stripe, yii2

## 简介

An elegant Omnipay payment processing extension for the Yii 2 framework.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
