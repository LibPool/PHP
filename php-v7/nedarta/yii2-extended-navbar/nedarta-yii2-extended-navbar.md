# nedarta/yii2-extended-navbar

> 标签: bootstrap5, navbar, widget, yii2

## 简介

An extended NavBar widget for Yii2 with support for external items and Bootstrap 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
