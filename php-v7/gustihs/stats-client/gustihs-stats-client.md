# gustihs/stats-client

> 标签: PHP

## 简介

PHP client to create stats

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://bitbucket.org/stats-team/php-client
- 源码仓库：https://bitbucket.org/stats-team/php-client.git
- Packagist 页面：https://packagist.org/packages/gustihs%2Fstats-client

## 历史版本号

- 1.0.0

## 获取地址

- Composer 安装：`composer require gustihs/stats-client`
- Packagist 仓库：https://repo.packagist.org/p2/gustihs/stats-client.json
- PHP 要求：>=5.4.0
