# aerex/baikal-storage-plugin

> 标签: Baikal, GTD, sabre, task, taskwarrior

## 简介

A Baikal plugin to sync iCal objects into storages such as taskwarrior and todist

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
