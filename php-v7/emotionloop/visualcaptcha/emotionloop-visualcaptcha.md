# emotionloop/visualcaptcha

> 标签: captcha, security, visualCaptcha

## 简介

PHP library for visualCaptcha. Still requires you to have the front-end companion.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
