# battis/bootstrapsmarty

> 标签: PHP

## 简介

A wrapper for Smarty to set (and maintain) defaults within a Bootstrap UI environment

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
