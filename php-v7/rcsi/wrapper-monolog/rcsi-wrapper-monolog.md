# rcsi/wrapper-monolog

> 标签: PHP

## 简介

Provides a common wrapper for Monolog that uses rcsi/filsystem-config to dictate log paths/levels

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
