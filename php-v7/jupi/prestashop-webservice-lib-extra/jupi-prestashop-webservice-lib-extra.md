# jupi/prestashop-webservice-lib-extra

> 标签: PHP

## 简介

A fully object-oriented way to interact with Prestashop webservice build on top of Prestashop Webservice lib

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
