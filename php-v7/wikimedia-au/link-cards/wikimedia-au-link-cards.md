# wikimedia-au/link-cards

> 标签: PHP

## 简介

A MediaWiki extension that adds a parser function for easy creation of linked 'card' UI components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
