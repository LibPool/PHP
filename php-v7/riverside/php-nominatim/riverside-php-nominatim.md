# riverside/php-nominatim

> 标签: OpenStreetMap, geocoding, nominatim, osm, php

## 简介

PHP client for Nominatim, a search engine for OpenStreetMap data.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
