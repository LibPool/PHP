# appserver-io/persistencecontainerclient

> 标签: persistence container doctrine

## 简介

Client to connect to a PHP ApplicationServer based persistence container.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
