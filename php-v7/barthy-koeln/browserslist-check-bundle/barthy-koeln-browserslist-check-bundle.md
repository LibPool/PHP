# barthy-koeln/browserslist-check-bundle

> 标签: PHP

## 简介

Detects browser versions, matches .browserslistrc files and serves encore builds accordingly.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
