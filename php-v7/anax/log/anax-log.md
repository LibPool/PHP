# anax/log

> 标签: anax, framework

## 简介

Anax Log module, for logging like PSR-3.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/canax/log
- 源码仓库：https://github.com/canax/log.git
- Packagist 页面：https://packagist.org/packages/anax%2Flog

## 获取地址

- Composer 安装：`composer require anax/log`
