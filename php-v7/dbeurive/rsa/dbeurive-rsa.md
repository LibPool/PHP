# dbeurive/rsa

> 标签: example, rsa

## 简介

This package contains a very basic service that performs RSA encoding and decoding. Please note that this package is just an example for an article.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
