# atomescrochus/laravel-gracenote

> 标签: atomescrochus, gracenote, laravel-gracenote

## 简介

A Laravel 5.* package to search the Gracenote Web API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
