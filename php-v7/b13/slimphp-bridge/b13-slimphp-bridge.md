# b13/slimphp-bridge

> 标签: api, psr-15, slimphp, typo3

## 简介

Provides a middleware for registering Slim PHP applications within TYPO3 Frontend Sites

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
