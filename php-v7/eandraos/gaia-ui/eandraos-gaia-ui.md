# eandraos/gaia-ui

> 标签: backend assets, cms, gaia project, laravel 5, ui

## 简介

Publish the different css/js assets for the gaia CMS project as well as the master page layout

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
