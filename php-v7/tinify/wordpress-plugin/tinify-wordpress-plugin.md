# tinify/wordpress-plugin

> 标签: plugin

## 简介

Speed up your website. Optimize your JPEG, PNG, and WebP images automatically with TinyPNG.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
