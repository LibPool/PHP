# leonardjke/omnipay-yoomoney

> 标签: merchant, omnipay, payment, php, yoomoney

## 简介

Yoomoney driver for Omnipay PHP payment library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
