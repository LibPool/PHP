# coooold/quick

> 标签: PHP

## 简介

a php framework with psr/http-message, psr/log, php-di/php-di, php-curl-class, relay/relay, zendframework/zend-diactoros, aura/router

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
