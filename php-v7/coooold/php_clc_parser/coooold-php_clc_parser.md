# coooold/php_clc_parser

> 标签: CLC, 中图分类, 中图分类号

## 简介

解析中图分类号解析器，获得一二级中图分类号

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
