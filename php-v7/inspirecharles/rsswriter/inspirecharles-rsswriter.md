# inspirecharles/rsswriter

> 标签: module, rss, writer, yii2

## 简介

Yii2 module for automatically generation RSS 2.0 feeds

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
