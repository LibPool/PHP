# cangak/yii-ajaxbs5

> 标签: ajax, crud, database, extension, gii, template, yii2

## 简介

Gii CRUD template for Single Page Ajax Administration for yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
