# nexocentric/silkworm

> 标签: Flexible, formatting, generator, html, parser, xml

## 简介

Silkworm is a flexible HTML generator for use in PHP projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
