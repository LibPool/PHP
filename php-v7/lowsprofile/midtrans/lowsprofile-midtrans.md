# lowsprofile/midtrans

> 标签: midtrans, payment, veritrans

## 简介

PHP Wrapper for Midtrans API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://midtrans.com
- 源码仓库：https://github.com/eriestrisnadi/midtrans-php.git
- Packagist 页面：https://packagist.org/packages/lowsprofile%2Fmidtrans
