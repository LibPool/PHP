# httpsoft/http-router

> 标签: http, http-router, php, psr-15, psr-7, route, router

## 简介

Simple and fast HTTP request router providing PSR-7 and PSR-15

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
