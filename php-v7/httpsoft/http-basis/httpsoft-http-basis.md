# httpsoft/http-basis

> 标签: PSR-11, http, http-framework, microframework, php, psr-15, psr-7

## 简介

Simple and fast HTTP microframework implementing PSR standards

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
