# changyy/laravel-oauth-library

> 标签: facebook, google, oauth, sdk

## 简介

Simple Facebook/Google OAuth Library for Laravel framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
