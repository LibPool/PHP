# shortlist-digital/wp-redirects-manager-role-plugin

> 标签: PHP

## 简介

A plugin to add the role to enable editors to add redirect rules

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
