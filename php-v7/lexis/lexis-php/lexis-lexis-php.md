# lexis/lexis-php

> 标签: API-Client, full-text-search, lexis, sdk, search

## 简介

Official PHP SDK for the Lexis search API (sync + search endpoints).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
