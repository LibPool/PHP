# refear99/easy-oss

> 标签: aliyun, easy-oss, oss, oss-sdk

## 简介

This package provides a easy way to access Aliyun OSS API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
