# refear99/easy-sinapay

> 标签: easy-sinapay, sinapay, sinapay-sdk

## 简介

This package provides a easy way to access SinaPay API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
