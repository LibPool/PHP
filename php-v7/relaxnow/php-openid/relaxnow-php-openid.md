# relaxnow/php-openid

> 标签: Authentication, OpenId, auth, yadis

## 简介

OpenID library for PHP5

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://github.com/openid/php-openid
- 源码仓库：https://github.com/relaxnow/php-openid.git
- Packagist 页面：https://packagist.org/packages/relaxnow%2Fphp-openid
