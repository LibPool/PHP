# morpara/morpos-magento2

> 标签: PHP

## 简介

MorPOS Payment Gateway for Magento 2 - Accept secure credit and debit card payments through MorPOS payment gateway

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
