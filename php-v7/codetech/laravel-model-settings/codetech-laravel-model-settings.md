# codetech/laravel-model-settings

> 标签: Settings, codetech, eloquent-models, laravel, laravel-model-settings, laravel-package, polymorphic-relations

## 简介

A Laravel package that allows you to assign settings to your models.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
