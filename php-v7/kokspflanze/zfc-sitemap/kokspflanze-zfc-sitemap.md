# kokspflanze/zfc-sitemap

> 标签: Sitemap, framework, laminas, navigation, zf

## 简介

Sitemap module for Laminas, based on zend-navigation with eventmanager

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
