# xbyter/apollo-client

> 标签: apollo, client, php, 阿波罗

## 简介

基于携程Apollo 阿波罗的PHP客户端，不依赖第三方扩展和框架并支持自定义配置格式同步（默认支持.env格式配置同步）。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
