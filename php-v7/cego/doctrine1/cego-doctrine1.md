# cego/doctrine1

> 标签: database, doctrine1, orm, symfony1

## 简介

PHP Database ORM for Symfony1. Do NOT use for new projects: please move to a newest Symfony release and Doctrine2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
