# marketo/silverstripe-performable-sitemaps

> 标签: Sitemap, silverstripe

## 简介

Creates a Sitemap PageType and generates sitemap.xml files specific to each domain

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
