# hopeofiran/avanak-laravel

> 标签: avanak, avanak laravel, avanak sms, avanak voice message

## 简介

This package helps us to use Avanak services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
