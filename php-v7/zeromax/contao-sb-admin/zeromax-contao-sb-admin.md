# zeromax/contao-sb-admin

> 标签: backend, bootstrap, contao module, responsive, theme

## 简介

Responsive Backend Theme for Contao Based on Startbootstrap Admin 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
