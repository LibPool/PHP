# naprstek/doctrine-functions

> 标签: database, doctrine, mssql, orm

## 简介

A set of User Defined Functions to Doctrine 2, basically for MSSQL.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
