# fasterize/magento2

> 标签: PHP

## 简介

Manage Fasterize cache from Magento admin and auto-trigger cache flush when it's necessary by using the Fasterize API service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
