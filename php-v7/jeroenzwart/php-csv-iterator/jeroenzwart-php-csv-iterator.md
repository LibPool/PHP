# jeroenzwart/php-csv-iterator

> 标签: csv, import, iterator, open, php, read, reader

## 简介

A simple CSV reader, to read as array/object with PHP Iterator

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
