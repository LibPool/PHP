# moz-morris/slim-skeleton

> 标签: Skeleton, sass, slim, twig

## 简介

A Slim Framework skeleton using Twig & Sass

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
