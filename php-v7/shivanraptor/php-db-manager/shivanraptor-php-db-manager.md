# shivanraptor/php-db-manager

> 标签: mariadb, mysql, mysqli, wrapper

## 简介

Easy-to-use PHP wrapper for MySQL database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
