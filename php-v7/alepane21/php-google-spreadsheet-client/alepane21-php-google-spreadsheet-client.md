# alepane21/php-google-spreadsheet-client

> 标签: google, spreadsheet

## 简介

Google Spreadsheet PHP Client (forked to work on PHP 5.2.1+)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
