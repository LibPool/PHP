# indigophp/fuel-gravatar

> 标签: avatar, gravatar, profile

## 简介

Gravatar package to return avatar, profile data, QR-code, VCF

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
