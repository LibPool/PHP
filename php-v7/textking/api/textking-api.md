# textking/api

> 标签: api, localization, rest, translation, web service

## 简介

Library to access the TEXTKING REST API for human translation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://www.textking.com/api
- 源码仓库：https://github.com/TextKing/textking-api-php.git
- Packagist 页面：https://packagist.org/packages/textking%2Fapi
