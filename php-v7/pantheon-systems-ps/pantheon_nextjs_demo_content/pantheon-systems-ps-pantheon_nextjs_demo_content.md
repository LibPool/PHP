# pantheon-systems-ps/pantheon_nextjs_demo_content

> 标签: PHP

## 简介

Pantheon-themed demo content for the single-site headless Next.js demo: articles, events, pages, tags, images, and menu links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
