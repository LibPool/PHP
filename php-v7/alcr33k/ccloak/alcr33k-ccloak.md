# alcr33k/ccloak

> 标签: anax, cloaking, feed, link, module, mvc

## 简介

CCloak is a simple wrapper-class for link cloaking

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
