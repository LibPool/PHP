# toneflix-code/fontawsome5-php

> 标签: fontawsome5, fontawsome5-php, icons, toneflix, toneflix-code

## 简介

Allows you to use fontawsome 5 icons in your php project.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
