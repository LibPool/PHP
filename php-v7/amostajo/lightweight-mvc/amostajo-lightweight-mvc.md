# amostajo/lightweight-mvc

> 标签: light, lightweight, mvc, wordpress

## 简介

A light weight (small) MVC framework for Wordpress plugins and themes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
