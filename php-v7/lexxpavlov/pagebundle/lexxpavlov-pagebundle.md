# lexxpavlov/pagebundle

> 标签: page, page bundle

## 简介

Symfony2 Page bundle with meta data, predefined form type and Sonata Admin service

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
