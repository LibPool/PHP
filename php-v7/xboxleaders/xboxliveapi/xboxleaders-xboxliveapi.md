# xboxleaders/xboxliveapi

> 标签: api, rest, xbox, xboxlive

## 简介

Simple & Powerful RESTful API for Xbox LIVE

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
