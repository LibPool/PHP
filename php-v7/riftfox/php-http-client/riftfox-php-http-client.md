# riftfox/php-http-client

> 标签: PHP

## 简介

A lightweight PSR-18 HTTP client wrapper allowing custom response transformation via result factories.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
