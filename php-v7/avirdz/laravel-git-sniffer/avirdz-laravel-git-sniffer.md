# avirdz/laravel-git-sniffer

> 标签: HOOK, codesniffer, git, laravel, phpcs, pre-commit

## 简介

An artisan command to check your code standards via pre-commit git hook.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
