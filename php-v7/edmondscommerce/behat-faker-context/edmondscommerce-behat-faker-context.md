# edmondscommerce/behat-faker-context

> 标签: Behat, Browser Testing, data, faker, testing

## 简介

A Behat Context that allows you to use Faker

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
