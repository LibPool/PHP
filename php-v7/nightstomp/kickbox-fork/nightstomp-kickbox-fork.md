# nightstomp/kickbox-fork

> 标签: email, free, kickbox, sendex, service, validation, verification

## 简介

Official kickbox API library client for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
