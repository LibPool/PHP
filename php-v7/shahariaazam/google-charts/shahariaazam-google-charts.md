# shahariaazam/google-charts

> 标签: cakephp, charts, google, plugin

## 简介

A CakePHP plugin for creating Google Charts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/shahariaazam/GoogleCharts.git
- Packagist 页面：https://packagist.org/packages/shahariaazam%2Fgoogle-charts
