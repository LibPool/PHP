# gorankrgovic/laravel-shortable

> 标签: Shortable, eloquent, laravel, shorten, youtube

## 简介

Laravel package for creating Youtube-like short IDs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
