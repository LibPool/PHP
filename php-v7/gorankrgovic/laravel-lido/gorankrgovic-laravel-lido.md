# gorankrgovic/laravel-lido

> 标签: download, eloquent, goran, krgovic, laravel, listen, trait, uuid

## 简介

Make Laravel Eloquent models Listenable and Downloadable using UUIDs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
