# rjjakes/wordpress-orm

> 标签: composer, doctrine, orm, plugin, sql, wordpress

## 简介

WORM. Doctrine style ORM for Wordpress.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
