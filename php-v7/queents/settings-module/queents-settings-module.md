# queents/settings-module

> 标签: admin one, admin panel, base, ineriajs, key-value, laravel, page, resource, setting, setting GUI, tailwind.css, vilt, vuejs

## 简介

VILT framework Settings module GUI to save key and value on database and cache it

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
