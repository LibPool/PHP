# simplon/feed

> 标签: atom, atom1.0, meta data, namespaces, read, rss, rss2.0

## 简介

Reads RSS 2.0 / ATOM 1.0 feeds. Supports namespaces and meta data.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
