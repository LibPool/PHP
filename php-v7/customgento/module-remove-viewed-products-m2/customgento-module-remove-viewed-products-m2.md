# customgento/module-remove-viewed-products-m2

> 标签: PHP

## 简介

Remove Viewed Products for Magento 2 removes the recently viewed products feature completely from Magento.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
