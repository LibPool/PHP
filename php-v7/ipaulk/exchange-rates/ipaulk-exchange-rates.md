# ipaulk/exchange-rates

> 标签: currency, exchange rate, finance, php, webservicex

## 简介

Retrieve currency exchange rate using several web services.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
