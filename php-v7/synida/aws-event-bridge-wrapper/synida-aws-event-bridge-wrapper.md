# synida/aws-event-bridge-wrapper

> 标签: Event Bridge, aws, putEvent

## 简介

PHP wrapper for basic PutEvent functionality for the EventBridge

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
