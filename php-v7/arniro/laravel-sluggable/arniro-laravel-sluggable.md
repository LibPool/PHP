# arniro/laravel-sluggable

> 标签: laravel, sluggable, translatable

## 简介

A package to generate a slug for Laravel models. Translatable columns are also supported.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
