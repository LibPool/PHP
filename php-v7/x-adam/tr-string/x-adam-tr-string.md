# x-adam/tr-string

> 标签: PHP

## 简介

It provides auxiliary functions to solve the problem of Turkish characters when converting text to lowercase and uppercase in php.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
