# simonkub/oauth2-todoist

> 标签: oauth2-todoist, simonkub

## 简介

This package provides Todoist OAuth 2.0 support for the PHP League's OAuth 2.0 Client.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
