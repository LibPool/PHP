# geoffroy-aubry/enum

> 标签: enum, enumeration, type-safe enum

## 简介

A simple-to-use PHP class that provides the ability to emulate and create type-safe enumerations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
