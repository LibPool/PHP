# geoffry304/yii2-widget-timer

> 标签: counter, extension, jquery, plugin, stopwatch, timer, widget, yii2

## 简介

Yii2 widget that displays controllable timer/stopwatch

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
