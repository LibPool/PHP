# dmtq/module-gift-receipt

> 标签: PHP

## 简介

The gift receipt feature in Magento 2 allows customers to choose whether they need a shopping receipt or not.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
