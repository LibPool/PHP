# sheershoff/yii2-sentry-component

> 标签: log, raven, sentry, yii2

## 简介

A Yii2 component for Sentry allowing data arrays passing through Yii2 logging methods

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
