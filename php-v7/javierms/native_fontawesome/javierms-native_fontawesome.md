# javierms/native_fontawesome

> 标签: FontAwesome, drupal, font awesome, fonts, gdpr, local, privacy

## 简介

Font Awesome 6 Free webfonts hosted 100% locally with high-priority CSS aggregation and zero external CDN requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
