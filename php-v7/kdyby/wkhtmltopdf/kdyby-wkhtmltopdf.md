# kdyby/wkhtmltopdf

> 标签: nette, pdf, wkhtmltopdf

## 简介

Wkhtmltopdf cli wrapper for Nette Framework

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
