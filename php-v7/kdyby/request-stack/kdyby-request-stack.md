# kdyby/request-stack

> 标签: http, kdyby, nette, request, stack

## 简介

Http Request stack service that wraps the Request value object for Nette Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
