# mmirzaee/yii2-api-boilerplate-jwt

> 标签: api, auth, boilerplate, jwt, rest, yii2

## 简介

A Yii2 Boilerplate to create a ready-to-use REST API in seconds

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
