# wpupdatephp/wp-update-php

> 标签: PHP

## 简介

Library to be bundled with WordPress plugins to enforce users to upgrade to PHP 5.4 hosting

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
