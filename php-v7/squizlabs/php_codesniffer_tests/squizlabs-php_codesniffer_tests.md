# squizlabs/php_codesniffer_tests

> 标签: phpcs, standards, tests

## 简介

A test lib that can easily be required & used in custom PHP_CodeSniffer rulesets

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
