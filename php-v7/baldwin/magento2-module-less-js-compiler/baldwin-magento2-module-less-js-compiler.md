# baldwin/magento2-module-less-js-compiler

> 标签: compiler, less, magento, magento2

## 简介

Allows Magento 2 to compile less files using the less nodejs compiler

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
