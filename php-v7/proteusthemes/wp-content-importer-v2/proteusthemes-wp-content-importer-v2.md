# proteusthemes/wp-content-importer-v2

> 标签: content, import, proteusthemes, theme, wordpress, wp

## 简介

Improved WP content importer used in OCDI plugin and MerlinWP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
