# proteusthemes/wai-aria-walker-nav-menu

> 标签: PHP

## 简介

WordPress menu walker which adds appropriate WIA-ARIA roles to dropdown menus.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
