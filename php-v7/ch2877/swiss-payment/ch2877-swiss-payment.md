# ch2877/swiss-payment

> 标签: Banking, credit-transfer, iso-20022, sepa, six, switzerland, xml

## 简介

PHP library to generate Swiss pain.001 messages (complies with ISO-20022)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
