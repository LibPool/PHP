# codemonauts/craft-time-field

> 标签: Craft, cms, craft-plugin, craftcms, field, time

## 简介

Craft CMS plugin to add a simple time field.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
