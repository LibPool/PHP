# codemonauts/craft-reverse-relations-field

> 标签: Craft, cms, craft-plugin, craftcms, relations

## 简介

Craft CMS plugin to add a reverse relations field for entries.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
