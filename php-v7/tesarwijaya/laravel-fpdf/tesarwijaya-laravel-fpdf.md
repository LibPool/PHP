# tesarwijaya/laravel-fpdf

> 标签: fpdf, laravel, pdf

## 简介

Laravel 5 package for use with Fpdf. It ships with Fpdf 1.81.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
