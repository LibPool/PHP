# alexsasharegan/open-graph

> 标签: graph, meta, open, open graph, open-graph, opengraph, seo

## 简介

A simple, scriptable way to create Open Graph meta tags.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
