# seoservice2020/phpmorphy

> 标签: nlp, phpmorphy

## 简介

phpMorphy - morphological analyzer library for Russian, Ukrainian, English and German languages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
