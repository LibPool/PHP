# e-ghl/merchant-api

> 标签: Merchant API, Reversal, capture, eghl, query, refund

## 简介

This package provides an easy interface to the merchants to interact with eGHL APIs i.e. Capture, Query, Refund and Reversal

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
