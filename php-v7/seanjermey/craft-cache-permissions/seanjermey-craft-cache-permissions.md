# seanjermey/craft-cache-permissions

> 标签: Craft, cache permissions, cms, craft-plugin, craftcms

## 简介

Plugin allows you to restrict who can clear each cache group.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
