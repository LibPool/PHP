# losgif/ys7-laravel

> 标签: hikvision, 海康威视, 萤石

## 简介

海康威视设备萤石开放平台(萤石云)Laravel SDK,用于接入海康设备直播,通信等功能

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
