# simitsdk/phplibs

> 标签: jasper, pdf, print format, print preview

## 简介

Several useful library for develop php based management system such as wysiwyg pdf document generator (phpjasperxml).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
