# assayer-pro/yii2-social-likes

> 标签: PHP

## 简介

Yii2 wrapper for social like buttons, see http://sapegin.github.io/social-likes/

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
