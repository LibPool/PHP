# magefan/module-blog-comments-recaptcha

> 标签: PHP

## 简介

Add recaptcha to Magefan Blog Comments. Require magento/module-re-captcha-validation-api >= 1.0.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
