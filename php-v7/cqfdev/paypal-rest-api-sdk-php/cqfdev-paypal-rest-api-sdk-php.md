# cqfdev/paypal-rest-api-sdk-php

> 标签: payments, paypal, rest, sdk

## 简介

PayPal's PHP SDK for REST APIs with psr/log package unlocked

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
