# hexianghui/bosonnlp-sdk

> 标签: bosonnlp, php

## 简介

bosonnlp-sdk is a PHP SDK for http://bosonnlp.com.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
