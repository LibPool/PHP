# 9thwonder/recursive-matrix

> 标签: Craft, cms, craft-plugin, craftcms, recursive matrix

## 简介

Allow matrices to be infinitely nested.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
