# enzyme/axiom

> 标签: axiom, ddd, enzyme, hex, interfaces, php

## 简介

A set of interfaces & classes for creating domain driven projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
