# indaxia/doctrine-orm-transformations

> 标签: array, doctrine, entity, json, orm

## 简介

Provides JSON-ready Doctrine ORM Entity-Array transfomtaions

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
