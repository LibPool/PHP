# cimrie/slick

> 标签: PHP

## 简介

Fluent ODM Metadata Builder for cimrie/odm, the FW Integration package for Doctrine MongoDB ODM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
