# renat-magadiev/zf3-bar-logger

> 标签: Zend Framework 3, tracy, zf3

## 简介

Tracy dumper as logger to Zend Developer Tools in ZF3 Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
