# triadev/laravel-elasticsearch-dsl

> 标签: DSL, elasticsearch, laravel

## 简介

A service provider for laravel with a fluent elasticsearch query and aggregation dsl.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
