# guzzlehttp/psr7

> 标签: HTTP, PSR-7, http, message, psr-7, request, response, stream, uri, url

## 简介

PSR-7 message implementation that also provides common utility methods

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
