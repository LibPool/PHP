# adamiecradek/ddd-bricks-zf2-event

> 标签: PHP

## 简介

This library extends ddd-bricks from AGmakonts and adds to it ZF2 event support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
