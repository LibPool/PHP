# zhiephie/lushi

> 标签: eloquent, indonesia, laravel, lushi, model, sushi

## 简介

A library of static Eloquent models for data Administrative Subdivisions of Indonesia.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
