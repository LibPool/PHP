# enikeishik/ufoframework

> 标签: Ufo, framework, mini, web

## 简介

UFO Framework is a PHP mini framework with small core and powerful modules.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://github.com/enikeishik/ufoframework
- 源码仓库：https://github.com/enikeishik/ufoframework.git
- Packagist 页面：https://packagist.org/packages/enikeishik%2Fufoframework
