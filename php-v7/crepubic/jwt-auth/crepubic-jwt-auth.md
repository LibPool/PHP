# crepubic/jwt-auth

> 标签: Authentication, JSON Web Token, auth, jwt, laravel, tymon

## 简介

JSON Web Token Authentication for Laravel 4 and 5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
