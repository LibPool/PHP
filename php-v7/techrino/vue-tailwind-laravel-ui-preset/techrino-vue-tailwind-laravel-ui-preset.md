# techrino/vue-tailwind-laravel-ui-preset

> 标签: PHP

## 简介

A Vue Tailwind Laravel UI Preset inspired by VueCLI

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
