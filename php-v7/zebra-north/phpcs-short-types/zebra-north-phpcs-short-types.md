# zebra-north/phpcs-short-types

> 标签: PHP

## 简介

Require the use of short scalar type names (bool, int) in comments, instead of long names (boolean, integer).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
