# ar-php/ar-php

> 标签: PHP

## 简介

helper library for dealing with arabic language

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/tawfekov/ar-php.git
