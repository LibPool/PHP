# laravel-frontend-presets/tachyons

> 标签: laravel, preset, tachyons

## 简介

Laravel 5.5 frontend preset for Tachyons

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
