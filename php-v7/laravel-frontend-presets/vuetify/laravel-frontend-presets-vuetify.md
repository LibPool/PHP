# laravel-frontend-presets/vuetify

> 标签: laravel, preset, vuetify

## 简介

Laravel 5.5+ Front-end preset for vuetify

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
