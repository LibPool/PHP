# laravel-frontend-presets/uikit3

> 标签: laravel, preset, uikit3

## 简介

Laravel 5.5.X Front-end preset for UIKit 3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
