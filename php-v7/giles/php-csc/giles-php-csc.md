# giles/php-csc

> 标签: PSR-11, phpcs, phpcsc, psr

## 简介

PHP code style check 利用git hook、phplint、phpcs在git commit的时候对php代码进行语法检测、代码风格检查，如果有问题，不允许提交。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
