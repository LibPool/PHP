# jinyicheng/thinkphp_status

> 标签: error code, thinkphp5, thinkphp_status

## 简介

像应用config一样应用status，让状态码错误码管理更方便，ThinkPHP5.0.*版

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
