# imsamurai/cakephp-twitter-bootstrap

> 标签: bootstrap, cakephp, helper, twitter

## 简介

Behavior for saving and reading serialized data from/into database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
