# studioibizz/oauth

> 标签: oauth, oauth1, oauth2

## 简介

This project enables OAuth v1.0 and v2.0 in a simple yet effective way.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
