# bradmkjr/monolog-wordpress

> 标签: database, log, logging, monolog, mysql, wordpress

## 简介

A handler for Monolog that sends messages to MySQL via WordPress Functions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
