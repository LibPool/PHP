# drupal-pattern-lab/bem-twig-extension

> 标签: PHP

## 简介

Twig function that inserts static classes into Pattern Lab and adds them to the Attributes object in Drupal

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
