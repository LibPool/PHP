# phoice/phlexa-expressive-skeleton

> 标签: PHP

## 简介

Skeleton application to build voice applications for Amazon Alexa with phlexa, PHP and Mezzio.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
