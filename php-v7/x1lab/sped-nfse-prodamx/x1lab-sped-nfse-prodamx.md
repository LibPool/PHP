# x1lab/sped-nfse-prodamx

> 标签: nfe, nfephp, nfse, sped

## 简介

API para geração e comunicação de RPS e NFSe no padão Prodam São Paulo SP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
