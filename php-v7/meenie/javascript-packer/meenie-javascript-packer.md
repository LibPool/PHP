# meenie/javascript-packer

> 标签: javascript packer

## 简介

Composer hosted mirror of the PHP Version of Dean Edwards' JavaScript Packer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://joliclic.free.fr/php/javascript-packer/en/
- 源码仓库：https://github.com/meenie/javascript-packer.git
- Packagist 页面：https://packagist.org/packages/meenie%2Fjavascript-packer
