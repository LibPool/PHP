# nitsan/ns-theme-extend

> 标签: TYPO3 CMS, bootstrap, frontend, responsive, theme

## 简介

The child theme of EXT:ns_basetheme

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
