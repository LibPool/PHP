# sastrawi/trka

> 标签: bahasa, indonesia, indonesian, named entity detector, natural language processing, nlp

## 简介

PHP library that guess entity in Bahasa Indonesia.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
