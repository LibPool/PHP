# the/promises

> 标签: PHP

## 简介

Provides The\Promise and The\PromiseInterface using GuzzleHttp. Other frameworks can provide compatible implementations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
