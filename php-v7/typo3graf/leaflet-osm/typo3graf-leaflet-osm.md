# typo3graf/leaflet-osm

> 标签: PHP

## 简介

Interactive and flexible shortcode to create multiple maps in posts and pages, and to add multiple markers on those maps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
