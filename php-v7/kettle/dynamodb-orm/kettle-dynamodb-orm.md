# kettle/dynamodb-orm

> 标签: aws, dynamodb, kettle, orm

## 简介

A lightweight object-dynamodb mapper for PHP5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
