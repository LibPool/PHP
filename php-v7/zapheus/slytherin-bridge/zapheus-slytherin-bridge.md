# zapheus/slytherin-bridge

> 标签: Bridge, integration, slytherin, zapheus

## 简介

Slytherin Integration bridge for Zapheus framework.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
