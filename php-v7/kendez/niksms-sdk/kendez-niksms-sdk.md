# kendez/niksms-sdk

> 标签: api, gRPC, messaging, niksms, rest, sms, telecommunication

## 简介

NikSms SDK for PHP - REST and gRPC client for NikSms SMS service

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
