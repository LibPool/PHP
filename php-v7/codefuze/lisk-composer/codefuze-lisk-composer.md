# codefuze/lisk-composer

> 标签: cryptocurrency, laravel, lisk, php

## 简介

Lisk Composer is a Lisk API package for use in Laravel and PHP composer projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
