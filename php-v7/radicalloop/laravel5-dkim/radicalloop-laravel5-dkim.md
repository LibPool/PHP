# radicalloop/laravel5-dkim

> 标签: dkim, email, laravel, spam

## 简介

A Laravel 5.x package to conditionally sign outgoing emails with DKIM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
