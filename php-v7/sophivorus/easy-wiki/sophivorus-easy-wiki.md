# sophivorus/easy-wiki

> 标签: mediawiki, mediawiki-api, wiki, wikipedia, wikipedia-api

## 简介

Friendly PHP client for the MediaWiki Action API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
