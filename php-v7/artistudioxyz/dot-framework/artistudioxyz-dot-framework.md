# artistudioxyz/dot-framework

> 标签: PHP

## 简介

Just another WordPress Plugin and Theme boilerplate with TailwindCSS, SASS, Blocks, ESLint, Prettier, and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
