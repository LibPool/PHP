# artistudioxyz/child-theme-boilerplate

> 标签: PHP

## 简介

Just another WordPress child theme Boilerplate using TailwindCSS, SASS, Prettier, and more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
