# juhedata/aliyun-oss

> 标签: AliyunOSS, aliyun, oss

## 简介

阿里云 OSS 官方 SDK 的 Composer 封装，支持 PHP7.2 项目，包括 Laravel、Symfony、TinyLara 等等。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
