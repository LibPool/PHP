# sinusbot/sinusbot-api-php

> 标签: api, http, php, sinusbot

## 简介

PHP Wrapper to communicate with the SinusBot API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
