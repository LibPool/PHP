# lanos/api-framework

> 标签: api, lanos, microframework, psr7, rest, router

## 简介

A framework for RESTFul Services, built upon Slim, utilizing Eloquent ORM and oAuth 2.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
