# fr3d/phpunit-selenium

> 标签: phpunit, selenium, testing, xunit

## 简介

Selenium v1 Server integration for PHPUnit v5

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
