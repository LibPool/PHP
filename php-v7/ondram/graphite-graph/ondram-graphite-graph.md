# ondram/graphite-graph

> 标签: builder, graph, graphite, url

## 简介

Graphite graph DSL to build URL query string for a graph (PSR-4 and PHP7 compatible)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
