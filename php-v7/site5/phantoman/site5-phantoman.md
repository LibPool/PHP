# site5/phantoman

> 标签: codeception, extension, headless, phantomjs

## 简介

The Codeception extension for automatically starting and stopping PhantomJS when running tests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
