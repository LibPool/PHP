# sendgrid/smtpapi

> 标签: X-SMTP, api, email, grid, send, sendgrid, smtp, smtpapi, twilio, xsmtp

## 简介

Build SendGrid X-SMTPAPI headers in PHP.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
