# laradic/config

> 标签: config, database, db, laravel, namespace, namespaces, persistent, save

## 简介

Laravel 5 config extensions: save to file/db. use namespaces, etc

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
