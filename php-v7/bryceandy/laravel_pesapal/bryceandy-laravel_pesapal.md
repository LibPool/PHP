# bryceandy/laravel_pesapal

> 标签: PHP

## 简介

An unofficial Pesapal API integration for Laravel. Multiple payment options including but not limited to M-Pesa, Tigo Pesa, Visa, Mastercard, American Express in Kenya, Tanzania & Uganda.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
