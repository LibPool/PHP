# femundfilou/kirby-cookie-consent

> 标签: kirby-plugin

## 简介

Cookie Consent is a customizable, easy-to-use privacy consent plugin for Kirby CMS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
