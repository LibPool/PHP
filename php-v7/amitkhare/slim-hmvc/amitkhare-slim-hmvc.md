# amitkhare/slim-hmvc

> 标签: PHP

## 简介

A HMVC modular library for Slim Framework. Use this library to start working on a new Slim Framework 3 with HMVC capebilities.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
