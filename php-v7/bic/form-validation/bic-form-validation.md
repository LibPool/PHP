# bic/form-validation

> 标签: form, form validation, javascript, twig, validation

## 简介

Let's take the form validation logic and apply it for js, other php scripts, an API...

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
