# marionnewlevant/embedded-assets-link

> 标签: Craft, cms, craft-plugin, craftcms, embedded assets link

## 简介

Adds a link to the Embedded Asset in the Control Panel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
