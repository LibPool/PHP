# yasglobal/make-paths-relative

> 标签: Domain Move, Multisite Compatibility, Portable URLs, Relative Links, SEO-Friendly URLs, Subdomain Migration, URL Migration

## 简介

Convert Absolute URLs to be relative in your fingertip.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
