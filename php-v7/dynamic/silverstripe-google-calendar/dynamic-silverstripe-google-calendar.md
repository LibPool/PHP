# dynamic/silverstripe-google-calendar

> 标签: calendar, cms, silverstripe

## 简介

A Silverstripe module for displaying Google calendars.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
