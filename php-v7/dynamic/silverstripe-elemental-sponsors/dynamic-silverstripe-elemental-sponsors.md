# dynamic/silverstripe-elemental-sponsors

> 标签: elemental, silverstripe, sponsors

## 简介

Display a list of sponsor logos with links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
