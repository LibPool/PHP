# dynamic/silverstripe-locator-react

> 标签: dynamic, geocode, google maps, location, locator, map, silverstripe

## 简介

A front end built in react for the SilverStripe Locator Module.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
