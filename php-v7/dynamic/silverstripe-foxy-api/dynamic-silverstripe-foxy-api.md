# dynamic/silverstripe-foxy-api

> 标签: Foxy.io, api, cms, ecommerce, silverstripe

## 简介

An API add-on module for SilverStripe Foxy.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
