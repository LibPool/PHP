# dynamic/viewable-dataobject

> 标签: dataobject, page, silverstripe, viewable

## 简介

DataExtension that easily allows a DataObject to be viewed like a Page

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
