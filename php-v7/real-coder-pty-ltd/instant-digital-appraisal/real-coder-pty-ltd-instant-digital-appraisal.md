# real-coder-pty-ltd/instant-digital-appraisal

> 标签: PHP

## 简介

Create Digital Appraisals for users, generate suburb reports using data from Domain API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
