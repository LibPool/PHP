# highliuk/vite

> 标签: Hmr, manifest, php, vite, vitejs

## 简介

Parse Vite.js manifest file easily and print tags in PHP to enjoy HMR

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
