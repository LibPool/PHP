# yjx/easy-router

> 标签: router, routing, 路由

## 简介

学习构建路由的练手作, 核心正则"参考" nikic/fast-route. 增加了部分语法糖, 同时占位符类型定义中允许使用分组等, 未使用 FastRoute 的分块合并正则表达式方法, 因此不适用于要求性能的项目.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
