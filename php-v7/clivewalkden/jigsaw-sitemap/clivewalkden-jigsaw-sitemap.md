# clivewalkden/jigsaw-sitemap

> 标签: Sitemap, jigsaw, laravel

## 简介

Sitemap and sitemap index builder for Jigsaw.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
