# clivewalkden/magento2-usersnap

> 标签: PHP

## 简介

A plugin for Magento 2 that outputs the Usersnap javascript code into the website

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
