# angelxmoreno/cakephp-tmdb-datasource

> 标签: api, cakephp, datasource, movie

## 简介

A CakePHP plugin for connecting to the TMDB API using a Datasource

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
