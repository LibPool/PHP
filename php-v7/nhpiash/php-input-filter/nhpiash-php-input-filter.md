# nhpiash/php-input-filter

> 标签: PHP

## 简介

A lightweight and reusable PHP package to sanitize and validate user inputs like strings, integers, emails, URLs, booleans, and arrays.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
