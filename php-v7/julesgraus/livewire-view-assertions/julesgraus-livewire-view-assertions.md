# julesgraus/livewire-view-assertions

> 标签: PHP

## 简介

Adds extra assertions to Livewires tests to assert that things are bound in the view of components

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
