# julesgraus/cross-origin-helpers

> 标签: PHP

## 简介

Enables some methods like the dd method from Laravel to work cross origin. just add a c before the function call.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
