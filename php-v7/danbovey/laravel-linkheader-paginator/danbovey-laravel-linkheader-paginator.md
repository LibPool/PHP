# danbovey/laravel-linkheader-paginator

> 标签: laravel, linkheader, pagination, paginator

## 简介

Laravel Paginator that moves pagination info to the HTTP LinkHeader

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
