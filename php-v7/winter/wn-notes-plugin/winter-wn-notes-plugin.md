# winter/wn-notes-plugin

> 标签: dynamic notes, macos notes, notes, winter, wintercms

## 简介

Easily add notes to any record in WinterCMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
