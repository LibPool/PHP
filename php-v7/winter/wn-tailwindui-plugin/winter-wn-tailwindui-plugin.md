# winter/wn-tailwindui-plugin

> 标签: cms, skin, tailwind, tailwindui, wintercms

## 简介

Provides a TailwindUI-based skin for the Winter CMS backend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
