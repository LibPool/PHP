# winter/wn-parsedown-plugin

> 标签: markdown, parsedown, plugin, winter, wintercms

## 简介

Reverts Markdown parsing back to the Parsedown library.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
