# sbuerk/typo3-symfony-di-test

> 标签: PHP

## 简介

Provides proof-of-concept implementation for Symfony DI techniques as TYPO3 extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
