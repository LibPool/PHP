# sbuerk/typo3-styleguide-selector

> 标签: PHP

## 简介

Meta package to require correct typo3/cms-styleguide version for used TYPO3 version

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
