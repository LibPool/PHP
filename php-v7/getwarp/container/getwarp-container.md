# getwarp/container

> 标签: PSR-11, container, dependency, di, injection, inversion of control, ioc, provider, psr11, service

## 简介

Decent dependency injection container compatible with PSR-11

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
