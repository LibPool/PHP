# getwarp/cycle-bridge

> 标签: criteria, cycle, orm

## 简介

Simplifies Cycle ORM integration with other Warp components (data-source, container, collection)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
