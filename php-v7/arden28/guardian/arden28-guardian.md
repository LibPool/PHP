# arden28/guardian

> 标签: arden28, guardian

## 简介

Guardian is a reusable, modular Laravel package designed to provide a comprehensive authentication system for modern web applications, specifically tailored for integration with a React frontend.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
