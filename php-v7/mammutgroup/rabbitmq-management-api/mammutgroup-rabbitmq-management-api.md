# mammutgroup/rabbitmq-management-api

> 标签: laravel, message queue, rabbitmq, rest

## 简介

An Laravel wrapper for the RabbitMQ Management HTTP Api

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
