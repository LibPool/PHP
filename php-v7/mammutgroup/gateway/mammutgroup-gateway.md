# mammutgroup/gateway

> 标签: Bank, Meli, Payline, dargah, gateway, ipay, iran, iranian-banks, jahanpay, laravel, mellat, pardakht, parsian, pasargad, pay, payment, persian-banks, poolport, port, sadad, saman, shaparak, zarinpal

## 简介

A Laravel package for connecting to all Iraninan payments gateways

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
