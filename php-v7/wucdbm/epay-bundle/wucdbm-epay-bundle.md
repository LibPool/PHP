# wucdbm/epay-bundle

> 标签: Symfony2, builder, menu, menu builder, wucdbm

## 简介

A Symfony2 bundle for working with the epay.bg payment gateway.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
