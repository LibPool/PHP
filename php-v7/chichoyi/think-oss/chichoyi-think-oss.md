# chichoyi/think-oss

> 标签: aliyun-oss, chichoyi-oss, object storage, oss, queue, think-oss, thinkphp, thinkphp5, 对象存储, 阿里云

## 简介

thinkphp( >5.0 ) oss cos 支持阿里云的对象存储

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
