# hehex/hehep-hevent

> 标签: PHP

## 简介

hehep-hevent 是一个PHP 用户事件组件,基本概念:事件,事件监听器,事件注解,事件管理器

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
