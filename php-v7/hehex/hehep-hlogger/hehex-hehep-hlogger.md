# hehex/hehep-hlogger

> 标签: PHP

## 简介

hehep-hlogger 是一个PHP日志基础组件,仿python logging模块,支持处理器、过滤器、格式器、上下文

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
