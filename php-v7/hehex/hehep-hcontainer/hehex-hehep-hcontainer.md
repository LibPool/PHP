# hehex/hehep-hcontainer

> 标签: PHP

## 简介

hehep-hcontainer 是一个di容器基础组件,提供类的实例化,对象属性依赖注入,AOP 拦截,容器文件扫描,等等功能

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
