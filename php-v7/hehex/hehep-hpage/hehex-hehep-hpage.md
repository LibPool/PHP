# hehex/hehep-hpage

> 标签: PHP

## 简介

hehep-hpage 是一个PHP分页组件,支持自定义分页器,支持自定义分页样式,支持lastId模式

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
