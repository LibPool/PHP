# lemonphp/webhook-shield

> 标签: protected-webhook, psr15, psr17, psr7, shield, webhook

## 简介

Protects against unverified webhooks from 3rd party services

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
