# queencitycodefactory/trash

> 标签: cakephp, muffin, orm, queencitycodefactory, trash

## 简介

Adds soft delete support to CakePHP 3 ORM tables.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
