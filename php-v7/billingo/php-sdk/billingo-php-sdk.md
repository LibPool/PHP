# billingo/php-sdk

> 标签: api, billingo, php, sdk

## 简介

billingo/php-sdk - PHP library from Packagist

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://www.billingo.hu
- 源码仓库：https://notabug.org/billingo/client-php-sdk
- Packagist 页面：https://packagist.org/packages/billingo%2Fphp-sdk

## 获取地址

- Composer 安装：`composer require billingo/php-sdk`

- 许可证：proprietary
- PHP 要求：>=5.5
