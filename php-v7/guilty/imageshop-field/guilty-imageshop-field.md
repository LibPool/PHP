# guilty/imageshop-field

> 标签: bildebank, craftcms, images, imageshop

## 简介

Integrates the Imageshop file picker into Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
