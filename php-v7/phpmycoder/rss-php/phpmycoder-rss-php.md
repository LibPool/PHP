# phpmycoder/rss-php

> 标签: atom, feed, rss

## 简介

RSS & Atom Feeds for PHP is a very small and easy-to-use library for consuming an RSS and Atom feed.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
