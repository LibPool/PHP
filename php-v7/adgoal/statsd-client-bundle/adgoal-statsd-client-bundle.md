# adgoal/statsd-client-bundle

> 标签: graphite, monitor, statsd, symfony

## 简介

Provides a statsd client and simple ready-to-use support for #Symfony2 Application

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
