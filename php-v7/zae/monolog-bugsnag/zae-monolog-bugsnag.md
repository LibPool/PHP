# zae/monolog-bugsnag

> 标签: bugsnag, debug, error, ezra, monolog, zae

## 简介

A monolog handler that will send messages to bugsnag

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
