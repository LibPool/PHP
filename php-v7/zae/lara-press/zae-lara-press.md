# zae/lara-press

> 标签: database, laravel, model, wordpress

## 简介

A set of models to use with Laravel's Eloquent to query a Wordpress database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
