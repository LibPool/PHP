# sayme/gulp-rev-bundle

> 标签: PHP

## 简介

The GulpRevBundle adds a simple twig filter for files revisioned with gulp-rev.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
