# bicpi/html-converter-bundle

> 标签: Symfony2, bicpi, bundle, converter, html, text

## 简介

This bundle provides Symfony integration of bicpi's html-converter library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
