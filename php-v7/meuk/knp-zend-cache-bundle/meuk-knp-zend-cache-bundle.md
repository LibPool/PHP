# meuk/knp-zend-cache-bundle

> 标签: bundle, cache, knp, knplabs, zend

## 简介

Integrates Zend Cache framework into Symfony2.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
