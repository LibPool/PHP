# stardothosting/modsecurity-parser

> 标签: PHP

## 简介

1:1 PHP port of msc_pyparser (ModSecurity SecRule parser) with JSON output

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
