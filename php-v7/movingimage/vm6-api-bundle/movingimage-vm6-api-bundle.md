# movingimage/vm6-api-bundle

> 标签: PHP

## 简介

Official Symfony bundle for interacting with the MovingIMAGE Video Manager 6 REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
