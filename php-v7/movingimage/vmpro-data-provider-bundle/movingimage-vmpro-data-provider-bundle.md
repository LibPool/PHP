# movingimage/vmpro-data-provider-bundle

> 标签: PHP

## 简介

Symfony bundle that wires the VMPro DataProvider's services into the service container

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
