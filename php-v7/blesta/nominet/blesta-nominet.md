# blesta/nominet

> 标签: PHP

## 简介

Nominet is the domain name registry that runs .UK and other top level domains, including .bbc, .wales and .bentley.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
