# blesta/duitku

> 标签: PHP

## 简介

Accept credit and debit cards, e-wallets, bank transfers, and send bulk payments via a single integration in Indonesia.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
