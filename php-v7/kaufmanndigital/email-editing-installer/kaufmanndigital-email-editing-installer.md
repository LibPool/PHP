# kaufmanndigital/email-editing-installer

> 标签: PHP

## 简介

Composer plugin to install MJML Node-Modules for kaufmanndigital/email-editing

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
