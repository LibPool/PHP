# davidnadejdin/sms-ru

> 标签: laravel

## 简介

Package for send sms via sms.ru. Based on official PHP class https://sms.ru/php

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
