# dominionenterprises/chef

> 标签: chef, ec2, knife

## 简介

A library that wraps jenssegers/php-chef and adds some functionality and support for knife-ec2.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
