# rahasistiyak/laravel-geo-data

> 标签: ISO codes, Laravel Countries, Phone code, city, country, currency, geo, geo database, geodata, laravel, laravel world data, location, region

## 简介

A Laravel package providing optimized access to region, country, phone code, city, and currency data

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
