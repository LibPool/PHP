# warlof/eveseat-mining-ledger

> 标签: PHP

## 简介

An extension for Eve SeAT which is providing Mining Ledger over ESI for 2.x version

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
