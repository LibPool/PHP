# blinkpay-nz/blink-debit-api-client-php

> 标签: blink-debit, blinkpay, cakephp, laravel, new-zealand, open-banking, payments, psr-18, symfony

## 简介

Framework-agnostic PHP client for the Blink Debit API (Blink PayNow and Blink AutoPay): consents, quick payments, payments, refunds, fixed recurring payments, transactions and webhooks, with PSR-18/PSR-16/PSR-6 adapters and Laravel, Symfony and CakePHP glue

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
