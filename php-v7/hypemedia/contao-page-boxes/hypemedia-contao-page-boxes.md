# hypemedia/contao-page-boxes

> 标签: boxes, contao, hype, hypemedia, page

## 简介

Extends the page with an image, title and subtitle, and allows you to select all enabled pages to be displayed as boxes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
