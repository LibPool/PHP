# deflopian/education-test-to-course

> 标签: PHP

## 简介

A Laravel module which provide connection between Courses/Lessons and Tests-Questions-Variants module. Alpha version, not recommended to use in production

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
