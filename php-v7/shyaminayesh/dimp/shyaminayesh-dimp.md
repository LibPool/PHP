# shyaminayesh/dimp

> 标签: dialog, dialog api, dialog ideamart, dialog php, ideamart, php, sms, ussd

## 简介

A Simple PHP Wrapper for Dialog IdeaMart API's.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
