# sebkln/ajaxselectlist

> 标签: ajax, extension, form, select list, typo3

## 简介

Provides a drop-down list which uses Ajax to load records into the page.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
