# lyquidity/xml-signer

> 标签: Policy, commitment type, counter signature, security, signature, timestamp, xades, xml, xmldsig

## 简介

A PHP to create and verify XAdES signature

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
