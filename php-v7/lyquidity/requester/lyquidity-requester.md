# lyquidity/requester

> 标签: certificate, check, https, ocsp, online certificate status protocol, request, revocation, revoke, revoked, rfc3161, rfc6069, security, timestamp, timestamp authority, tsa

## 简介

Library to query HTTPS Certificates revocation status using the Online Certificate Status Protocol (OCSP) and to make a request to a Timestamp authority (TSA)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
