# ifelsend/aliyun-oss-adapter

> 标签: aliyun, laravel, oss, storage

## 简介

Use Aliyun oss as Storage for Laravel 5.0+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
