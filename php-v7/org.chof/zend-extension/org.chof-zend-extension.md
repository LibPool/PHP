# org.chof/zend-extension

> 标签: PHP

## 简介

Zend Framework 1 Extension for webprojects including model and mapper, Rest controller and various utilities

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
