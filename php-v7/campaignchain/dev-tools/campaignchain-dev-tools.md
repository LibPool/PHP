# campaignchain/dev-tools

> 标签: campaignchain

## 简介

Various tools for developing with CampaignChain, e.g. to generate CampaignChain modules from the command line.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：http://www.campaignchain.com
- 源码仓库：https://github.com/CampaignChain/dev-tools.git
- Packagist 页面：https://packagist.org/packages/campaignchain%2Fdev-tools
