# brezgalov/php-simple-file-locker

> 标签: PHP

## 简介

Simple file locker for php from http://php.net/manual/ru/function.flock.php#117162

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
