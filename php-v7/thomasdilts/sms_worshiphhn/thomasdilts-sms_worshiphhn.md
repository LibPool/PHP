# thomasdilts/sms_worshiphhn

> 标签: sms, worshiphhn, yii2

## 简介

The SMS class that all sms libraries must subclass to be used by the worshiphhn project

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
