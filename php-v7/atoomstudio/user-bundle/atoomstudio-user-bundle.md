# atoomstudio/user-bundle

> 标签: google authenticator, sonata, user

## 简介

SonataUserBundle fork to restore compatibility with PHP 5.6 and 7.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
