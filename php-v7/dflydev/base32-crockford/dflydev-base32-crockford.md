# dflydev/base32-crockford

> 标签: base32, crockford, decode, decoder, encode, encoder

## 简介

Encode/decode numbers using Douglas Crockford's Base32 Encoding

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
