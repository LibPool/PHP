# braadiv/yii2-dynmodel

> 标签: Generate dynamic model, braadiv, dynamic form, dynamic model, dynamic multiple models model, extension, yii2

## 简介

It is widget to yii2 framework to Generate dynamic model or multiple models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
