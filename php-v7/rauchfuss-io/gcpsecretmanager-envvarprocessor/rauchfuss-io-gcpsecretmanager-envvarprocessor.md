# rauchfuss-io/gcpsecretmanager-envvarprocessor

> 标签: PHP

## 简介

A small Symfony Custom EnvVarProcessor bundle for retrieving Secrets from GCP Secret Manager

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
