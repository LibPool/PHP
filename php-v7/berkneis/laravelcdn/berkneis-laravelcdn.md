# berkneis/laravelcdn

> 标签: AWS S3, Assets Upload, amazon, aws, cdn, content delivery network, laravel, s3, upload

## 简介

Content Delivery Network (CDN) Package for Laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
