# rieznyk/laravel-infusionsoft

> 标签: infusionsoft, isdk, laravel, sdk

## 简介

This package provides port of the Infusionsoft SDK utilizing Laravel fascades.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
