# yab/quarx

> 标签: PHP

## 简介

Add a CMS to any Laravel app/website to gain control of: pages, blogs, galleries, events, custom modules, images and more.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
