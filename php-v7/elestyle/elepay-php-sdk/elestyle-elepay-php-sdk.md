# elestyle/elepay-php-sdk

> 标签: api, openapi, openapi-generator, openapitools, php, rest, sdk

## 简介

elepay APIはRESTをベースに構成された決済APIです。支払い処理、返金処理など、決済に関わる運用における様々なことができます。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
