# rise/jwt-auth

> 标签: Authentication, JSON Web Token, auth, jwt, laravel

## 简介

JSON Web Token Authentication for Laravel and Lumen

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
