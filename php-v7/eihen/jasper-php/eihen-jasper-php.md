# eihen/jasper-php

> 标签: Eihen, jasper-reports, jasperphp, jasperreports, jaspersoft, jasperstarter, php-reporting-tools, php-reports, reports

## 简介

A PHP library to compile and generate JasperReports using JasperStarter

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
