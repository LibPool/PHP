# ankalagon/git

> 标签: PHP

## 简介

A Git wrapper for PHP5.3+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/ankalagon/php-git.git
