# jaeger-app/platforms-ee2

> 标签: EECMS2, ExpressionEngine 2

## 简介

An ExpressionEngine 2 CMS Platform object for use with Jaeger.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
