# ryanshay/sos

> 标签: Blink, audio, emergency, morse, morse-code, sos, translator, visual

## 简介

A PHP library for translating between Natural Language and Morse code. Supports audio, visual, and blink translations.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
