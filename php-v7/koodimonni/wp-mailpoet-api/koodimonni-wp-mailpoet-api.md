# koodimonni/wp-mailpoet-api

> 标签: api, developer, mailpoet, wordpress, wrapper, wysija

## 简介

Easier Developer API for WordPress plugin Mailpoet

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
