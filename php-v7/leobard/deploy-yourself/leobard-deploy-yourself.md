# leobard/deploy-yourself

> 标签: PHP

## 简介

Kirby Plugin to deploy Kirby websites' code via git, push-web-hook, PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
