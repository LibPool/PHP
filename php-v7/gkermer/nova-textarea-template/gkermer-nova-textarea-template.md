# gkermer/nova-textarea-template

> 标签: laravel, nova, template, text, textarea

## 简介

A Laravel Nova textarea field with the ability to choose a text from templates.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
