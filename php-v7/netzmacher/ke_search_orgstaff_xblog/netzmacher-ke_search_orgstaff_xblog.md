# netzmacher/ke_search_orgstaff_xblog

> 标签: PHP

## 简介

Faceted Search Indexer for the Organiser table staff. Page for the detail view must have a xBlog plugin.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
