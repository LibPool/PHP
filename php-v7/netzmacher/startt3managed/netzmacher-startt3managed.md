# netzmacher/startt3managed

> 标签: start

## 简介

Backend style for a managed TYPO3 with CI of Die Netzmacher. Maybe a useful draft for your CI extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
