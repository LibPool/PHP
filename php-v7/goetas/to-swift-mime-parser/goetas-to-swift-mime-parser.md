# goetas/to-swift-mime-parser

> 标签: mail, mime, swift, swiftmailer

## 简介

Parse a generic mail stream, and convert it to a SwiftMailer Message

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
