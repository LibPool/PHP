# nick-denry/yii2-ckeditor-roxyfileman

> 标签: CKEditor, file manager, roxy, yii2

## 简介

Yii2 integration of Roxy File Manager to CKEditor

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
