# imanimen/speed-routes

> 标签: PHP

## 简介

This package helps you to boost your coding speed by just creating one file for your Logic, Method, Validations and Middlewares.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
