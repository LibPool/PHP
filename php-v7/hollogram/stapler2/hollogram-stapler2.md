# hollogram/stapler2

> 标签: aws, file, orm, paperclip, s3, upload

## 简介

Elegant and simple ORM-based file upload package for php.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
