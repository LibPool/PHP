# kissifrot/php-nntp

> 标签: PHP

## 简介

Client for communicating with servers throught the Network News Transfer Protocol (NNTP) protocol.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
