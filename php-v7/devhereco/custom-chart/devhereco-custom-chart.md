# devhereco/custom-chart

> 标签: chart, custom, laravel, package

## 简介

A Laravel package to extract data from any model to imploment it to your custom chart.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
