# open-code-modeling/json-schema-to-php

> 标签: json, parser, php, schema

## 简介

Parses JSON schema files and provides an API to easily generate code from JSON schema.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
