# prompt-cash/prompt-php-sdk

> 标签: PHP

## 简介

Prompt.Cash PHP SDK to create payments (including tokens) and short URLs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
