# christiaanbye/polyfill-each

> 标签: compatibility, each, php, polyfill, shim

## 简介

PHP 8.x polyfill for the removed each() function

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
