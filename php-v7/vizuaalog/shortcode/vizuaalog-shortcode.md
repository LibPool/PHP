# vizuaalog/shortcode

> 标签: laravel, pingpong, shortcode, wordpress

## 简介

Laravel - Simple shortcode based on wordpress shortcode

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
