# tollwerk/tw-squeezr

> 标签: PHP

## 简介

TYPO3 extension version of squeezr, another take on device-aware adaptive images and server side CSS3 media queries

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
