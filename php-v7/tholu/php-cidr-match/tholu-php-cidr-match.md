# tholu/php-cidr-match

> 标签: cidr, ipv4, ipv6, php

## 简介

CIDRmatch is a library to match an IP to an IP range in CIDR notation (IPv4 and IPv6).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
