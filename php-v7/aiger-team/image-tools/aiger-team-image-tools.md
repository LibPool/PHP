# aiger-team/image-tools

> 标签: crop, edit, images, immutable, k-means, modify, opacity, pictures, print text, resize, rotate, screenshot, stamp, transparent, watermark

## 简介

Light image editing tool with immutable objects style

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
