# distilleries/form-builder

> 标签: PHP

## 简介

Based on laravel-form-builder (https://github.com/kristijanhusak/laravel-form-builder). That add default component and add view system.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
