# kattsoftware/phassets

> 标签: PHP

## 简介

PHP library for assets management (processing, deployment and serving).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/kattsoftware/phassets
- 源码仓库：https://github.com/kattsoftware/phassets.git
- Packagist 页面：https://packagist.org/packages/kattsoftware%2Fphassets
