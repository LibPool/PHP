# offline/oc-cashier-plugin

> 标签: PHP

## 简介

October CMS plugin to handle Stripe and Braintree payments using Laravel Cashier

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
