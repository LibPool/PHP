# rapidsmsng/sms-php-sdk

> 标签: PHP

## 简介

Rapid SMS PHP SDK is built for Rapid SMS - Bulk SMS Application

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
