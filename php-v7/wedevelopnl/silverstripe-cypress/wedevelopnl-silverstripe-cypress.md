# wedevelopnl/silverstripe-cypress

> 标签: development, gitlab, silverstripe

## 简介

Helper module to run cypress tests on a Silverstripe website inside the GitLab CI.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
