## 简介

Get Google, Bing, Baidu, Ebay, Yahoo, Yandex, Home depot, Naver, Apple, Duckduckgo, Youtube search results via SerpApi.com

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
