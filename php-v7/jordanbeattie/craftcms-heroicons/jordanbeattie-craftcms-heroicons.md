# jordanbeattie/craftcms-heroicons

> 标签: Craft, Heroicons, cms, craft-plugin, craftcms, icons

## 简介

Utilise heroicons in Twig templates. This is an unofficial plugin and is in no way affiliated with Heroicons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
