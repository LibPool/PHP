# bootpress/blog

> 标签: blog, bootpress, cms, flat-file, markdown, twig

## 简介

A flat file Blog and CMS that doesn't skimp on features, and can be utilized in any website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
