# staplegun/speedbump

> 标签: Craft, cms, craft-plugin, craftcms, speedbump

## 简介

Alerts users when navigating to any un-whitelisted links.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
