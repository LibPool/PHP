# hugerte/hugerte

> 标签: contenteditable, editing, html, hugerte, javascript, rich editor, rich text, rich text editor, richtext, rte, text, wysiwyg

## 简介

Web based JavaScript HTML WYSIWYG editor control.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
