# adigital/cookie-consent-banner

> 标签: Craft, cms, cookie consent banner, craft-plugin, craftcms

## 简介

Add a configurable cookie consent banner to the website.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
