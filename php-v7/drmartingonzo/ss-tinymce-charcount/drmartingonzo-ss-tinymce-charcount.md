# drmartingonzo/ss-tinymce-charcount

> 标签: characters, silverstripe, tinymce

## 简介

Plugin for tinyMCE in siverstripe to count characters

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
