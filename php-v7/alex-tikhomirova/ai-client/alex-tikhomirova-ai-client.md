# alex-tikhomirova/ai-client

> 标签: Guzzle, ai, openai, php, responses-api

## 简介

Простой PHP-клиент для OpenAI Responses API на базе Guzzle.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
