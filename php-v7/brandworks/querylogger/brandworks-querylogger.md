# brandworks/querylogger

> 标签: brandworks, laravel, query location, query logger, query tracer

## 简介

Trace or log your (slow) queries in Laravel 4

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
