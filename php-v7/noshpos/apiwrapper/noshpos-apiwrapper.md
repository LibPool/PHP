# noshpos/apiwrapper

> 标签: api, pos, wrapper

## 简介

This library wraps the NoshPOS API and allows you to retrieve paginated basic data from NoshPOS.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
