# themismin/laravel-admin-ext-cos

> 标签: cos, extension, laravel, laravel-admin, pjax, sts, tencent-cloud, 多图上传, 多文件上传, 大文件上传, 腾讯云

## 简介

腾讯云 COS 的 laravel-admin 扩展。统一的单图/多文件字段、STS 分片直传、对象 Key 前缀安全约束、AsJsonArray 双编码兼容、扩展自带 PJAX 重建脚本与细分发布 tag

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
