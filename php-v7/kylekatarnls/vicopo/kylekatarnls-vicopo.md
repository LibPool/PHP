# kylekatarnls/vicopo

> 标签: PHP

## 简介

API HTTP et Script pour trouver les villes à partir d'un code postal et code postaux à partir d'une ville

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
