# clearcode/wordpress-framework

> 标签: blog, boilerplate, cms, composer, framework, wordpress, wp

## 简介

WordPress Framework boilerplate by Clearcode.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
