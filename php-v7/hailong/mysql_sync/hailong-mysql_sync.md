# hailong/mysql_sync

> 标签: database, diff, migration, mysql, script, sync

## 简介

A very lightweight but handy MySql database diff and sync tool.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
