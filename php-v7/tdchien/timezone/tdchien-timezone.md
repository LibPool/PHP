# tdchien/timezone

> 标签: timezone, timezones

## 简介

Update fix for dupplicate key in list timezone. Helps manage timezones in Laravel. Includes <select> form builder for timezones.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
