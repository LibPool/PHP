# soap/yii2-jasny-bootstrap

> 标签: bootstrap, extension, jasny, yii2

## 简介

Extension for Yii 2 to work with Jasny Bootstrap

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
