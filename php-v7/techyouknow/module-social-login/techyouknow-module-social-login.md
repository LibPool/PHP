# techyouknow/module-social-login

> 标签: Authentication, OpenId, api, apple, authorization, facebook, google, oauth, social, twitter

## 简介

Magento 2 social login like Google, Facebook, Apple, Instagram, Twitter, Amazon, Yahoo, LinkedIn, and GitHub

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
