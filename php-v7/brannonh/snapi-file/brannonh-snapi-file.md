# brannonh/snapi-file

> 标签: Simple, api, data, files, filesystem, fs, json, rest

## 简介

A simple PHP REST API to access data stored in the filesystem

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
