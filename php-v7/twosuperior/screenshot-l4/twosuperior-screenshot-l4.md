# twosuperior/screenshot-l4

> 标签: laravel, screenshot, screenshot-l4, twosuperior

## 简介

Screenshot tool for Laravel 4, recommended for internal use only.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
