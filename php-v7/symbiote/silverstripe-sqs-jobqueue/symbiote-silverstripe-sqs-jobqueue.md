# symbiote/silverstripe-sqs-jobqueue

> 标签: aws, queuedjobs, silverstripe, sqs, symbiote, thrive

## 简介

A module for interacting with AWS's Simple Queue Service (SQS)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
