# symbiote/silverstripe-pdfrendition

> 标签: pdf, silverstripe

## 简介

A module that makes use of the Flying Saucer XHTML renderer project to create PDFs from XHTML pages.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
