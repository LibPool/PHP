# symbiote/silverstripe-multisites-googleanalytics

> 标签: analytics, multisites, silverstripe

## 简介

Adds Google Analytics tracking code to each multisite

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
