# symbiote/silverstripe-frontend-authoring

> 标签: frontend, silverstripe, wysiwyg

## 简介

Provides frontend editing capabilities for SilverStripe pages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
