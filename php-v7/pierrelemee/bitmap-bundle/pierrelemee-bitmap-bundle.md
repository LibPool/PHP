# pierrelemee/bitmap-bundle

> 标签: Symfony Bundle, bitmap, data mapper

## 简介

Bitmap data mapper bundle for Symfony

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
