# vadiasov/users-admin

> 标签: PHP

## 简介

Creates user-roles DB table. Serve CRUD operation for "users" DB table. Serves user-roles operations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
