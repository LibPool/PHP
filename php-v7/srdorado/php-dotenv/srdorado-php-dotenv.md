# srdorado/php-dotenv

> 标签: env, load, php, server

## 简介

Loads environment variables from .env file to getenv(), $_ENV and $_SERVER

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
