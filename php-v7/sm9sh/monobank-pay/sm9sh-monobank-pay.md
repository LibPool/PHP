# sm9sh/monobank-pay

> 标签: PHP

## 简介

This is simple library for Monobank Acquiring called "MonoPay" based on REST API (v2304) docs located at https://api.monobank.ua/docs/acquiring.html

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
