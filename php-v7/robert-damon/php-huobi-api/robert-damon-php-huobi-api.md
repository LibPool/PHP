# robert-damon/php-huobi-api

> 标签: Huobi, cryptocurrency, rest

## 简介

PHP Huobi API is an asynchronous PHP library for the Huobi API designed to be easy to use.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
