# lasallecrm/listmanagement

> 标签: Bob Bloom, LaSalleCRM, Lists, South LaSalle, email, laravel, laravel5

## 简介

List management package for LaSalleCRM.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
