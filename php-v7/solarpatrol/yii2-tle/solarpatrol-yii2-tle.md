# solarpatrol/yii2-tle

> 标签: norad, satellites, space-track, storage, tle

## 简介

TLE storage component for Yii2 based on www.space-track.org API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
