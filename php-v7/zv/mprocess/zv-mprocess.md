# zv/mprocess

> 标签: Flexible, atomic, easy, lock, multi process, multi task, performance, php, queue, swoole, task execution

## 简介

Multi process task execution based on swoole/基于 swoole 的多任务进程管理

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
