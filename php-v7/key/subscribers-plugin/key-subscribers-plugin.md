# key/subscribers-plugin

> 标签: active campaign, cms, form, october, plugin

## 简介

Subscriber plugin for OctoberCMS, create forms and send them to Active Campaign, Zapier and more

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
