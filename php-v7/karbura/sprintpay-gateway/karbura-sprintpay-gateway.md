# karbura/sprintpay-gateway

> 标签: OM, extension, mobile money, momo, yii2

## 简介

Yii 2 package for sprintpay gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
