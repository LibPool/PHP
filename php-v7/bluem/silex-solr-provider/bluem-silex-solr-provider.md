# bluem/silex-solr-provider

> 标签: search, silex, solr

## 简介

Provides Apache Solr 4.* connectivity for Silex, Solr extension v2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
