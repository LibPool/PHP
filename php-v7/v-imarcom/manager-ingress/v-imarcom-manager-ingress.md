# v-imarcom/manager-ingress

> 标签: laravel, manager, oauth, providers, socialite

## 简介

Easily add new or override built-in providers in Laravel Socialite.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
