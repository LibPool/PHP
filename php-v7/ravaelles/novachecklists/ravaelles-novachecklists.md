# ravaelles/novachecklists

> 标签: checkbox, checkboxes, checklist, checklists, field, input, laravel, nova

## 简介

A Laravel Nova field to display a list of items to complete.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
