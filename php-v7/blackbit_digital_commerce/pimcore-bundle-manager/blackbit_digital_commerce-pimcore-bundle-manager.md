# blackbit_digital_commerce/pimcore-bundle-manager

> 标签: PHP

## 简介

Enables bundles for pimcore projects (replacement for bin/console pimcore:bundle:enable)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
