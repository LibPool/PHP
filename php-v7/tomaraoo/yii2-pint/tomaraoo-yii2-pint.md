# tomaraoo/yii2-pint

> 标签: code-style, formatter, phpcbf, phpcs, yii2

## 简介

A fast parallel code-style formatter for Yii2 projects across PHP 5.6 and modern PHP versions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
