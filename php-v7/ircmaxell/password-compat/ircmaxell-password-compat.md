# ircmaxell/password-compat

> 标签: hashing, password

## 简介

A compatibility library for the proposed simplified password hashing algorithm: https://wiki.php.net/rfc/password_hash

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
