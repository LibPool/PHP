# wpmetabox/meta-box-beaver-themer-integrator

> 标签: beaver-builder, beaver-themer, custom-field, meta-box, select2, ui, wordpress, wordpress-plugin, wp-admin

## 简介

Integrates Meta Box's custom fields with Beaver Themer.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
