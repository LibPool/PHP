# wpmetabox/mb-pods-migration

> 标签: custom-field, custom-fields, meta-box, pods, types, wordpress, wordpress-plugin

## 简介

Migrate Toolset custom fields to Meta Box

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
