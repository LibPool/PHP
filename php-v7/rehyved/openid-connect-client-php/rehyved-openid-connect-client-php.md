# rehyved/openid-connect-client-php

> 标签: OpenId, client, oauth

## 简介

An OpenID Connect/OAuth 2.0 Client implementation for PHP inspired by IdentityModel2

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
