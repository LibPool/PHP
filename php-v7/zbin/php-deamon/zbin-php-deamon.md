# zbin/php-deamon

> 标签: php-deamon, php守护进程, swoole, yii2, yii2守护进程, 守护进程, 让yii2跑在swoole上

## 简介

基于swoole守护进程，目前支持框架：yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
