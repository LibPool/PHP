# emhusnan/spreadsheet-reader

> 标签: OpenOffice, csv, excel, ods, spreadsheet, xls, xlsx

## 简介

This fork repo from nuovo/spreadsheet-reader.I added custom fix for php 7.2. Spreadsheet reader library for Excel, OpenOffice and structured text files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
