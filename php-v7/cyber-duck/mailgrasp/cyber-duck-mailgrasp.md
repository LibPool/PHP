# cyber-duck/mailgrasp

> 标签: emails, laravel, testing

## 简介

A package for Laravel applications (5.1) to add support for email testing in your test classes.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
