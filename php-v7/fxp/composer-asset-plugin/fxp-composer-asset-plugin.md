# fxp/composer-asset-plugin

> 标签: asset, bower, composer, dependency manager, nodejs, npm, package

## 简介

NPM/Bower Dependency Manager for Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
