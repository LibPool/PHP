# curder/aliyun-core

> 标签: aliyun, aliyun-core, sdk

## 简介

阿里云 PHP SDK 的核心依赖包的 composer 封装

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
