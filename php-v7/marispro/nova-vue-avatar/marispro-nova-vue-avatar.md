# marispro/nova-vue-avatar

> 标签: laravel, nova

## 简介

Vue Avatar (https://eliep.github.io/vue-avatar/) Field wrapper for Laravel Nova (https://nova.laravel.com/)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
