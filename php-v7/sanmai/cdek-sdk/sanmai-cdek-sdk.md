# sanmai/cdek-sdk

> 标签: cdek, delivery, sdk, СДЭК, служба доставки

## 简介

СДЭК PHP SDK, библиотека для работы с API СДЭК

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
