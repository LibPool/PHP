# upnid/pagarme-php

> 标签: api, pagarme, payments, restful

## 简介

Biblioteca PHP não oficial para acessar a API RESTful do Pagar.me.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
