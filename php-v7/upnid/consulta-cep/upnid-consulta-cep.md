# upnid/consulta-cep

> 标签: cep, consulta, consulta cep, correios

## 简介

Biblioteca para consultar CEPs através de diversos provedores.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
