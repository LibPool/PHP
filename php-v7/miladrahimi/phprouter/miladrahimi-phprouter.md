# miladrahimi/phprouter

> 标签: HTTP Router, URL Router, http, route, router, routing, url

## 简介

A powerful, lightweight, and very fast HTTP URL router for PHP projects.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
