# gsferro/microservico

> 标签: Microservice, api, laravel, websevices

## 简介

Criado com objetivo de generalizar o consumo de API/WEBSERVICES

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
