# maniaba/tctable

> 标签: TCPDF, maniaba, pdf, table, tctable

## 简介

Create quickly and efficiently tables without HTML formatting and with advanced page break options

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
