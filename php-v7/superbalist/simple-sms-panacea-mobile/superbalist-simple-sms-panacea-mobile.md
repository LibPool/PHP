# superbalist/simple-sms-panacea-mobile

> 标签: PHP

## 简介

An adapter for the simple-sms Laravel library for sending SMSs via the Panacea Mobile API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
