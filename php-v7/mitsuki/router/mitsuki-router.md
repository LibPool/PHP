# mitsuki/router

> 标签: attributes, fast-route, http-kernel, micro-framework, mitsuki, mvc, php8, router, routing, symfony-component

## 简介

A lightweight and high-performance PHP router for the Mitsuki framework, powered by Symfony Routing components.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
