# tacoberu/php-exif-tools

> 标签: exif, image

## 简介

php-exif-tools is a simple library for manipulate (read and write) with the EXIF meta-data of an image.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
