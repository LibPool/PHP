# espalda/espalda-php

> 标签: espalda, html, template

## 简介

Library for handling specific espalda markup in html's pages to facilitate development of dynamic pages

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
