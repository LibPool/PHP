# xthiago/id-value-object

> 标签: PHP

## 简介

A Value Object (VO) for Object Identity (ID). Includes a Doctrine DBAL type for persistence.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
