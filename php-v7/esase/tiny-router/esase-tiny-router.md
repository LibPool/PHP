# esase/tiny-router

> 标签: esase, framework, lightweight, microservices, mvc, routing, tinyframework

## 简介

Flexible routing system component for HTTP and console applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
