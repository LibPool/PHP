# hirviid/hirviid-cleeng-bundle

> 标签: cleeng

## 简介

This bundle provides a simple integration of the Cleeng PHP SDK into Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
