# alexbowers/laravel-timepiece

> 标签: chronograf, grafana, graphite, influx, influxdata, influxdb, laravel, telegraf, time series, timeseries

## 简介

A Laravel 5 package to interact with timeseries databases.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
