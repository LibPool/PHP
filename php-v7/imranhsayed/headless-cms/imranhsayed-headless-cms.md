# imranhsayed/headless-cms

> 标签: plugin, wordpress

## 简介

A WordPress plugin that adds features to use WordPress as a headless CMS with any front-end environment using REST API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
