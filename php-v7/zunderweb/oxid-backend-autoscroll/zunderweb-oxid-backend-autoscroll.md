# zunderweb/oxid-backend-autoscroll

> 标签: OXID, eshop, modules

## 简介

OXID eShop: Scrolls to selected list entry automatically in backend

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
