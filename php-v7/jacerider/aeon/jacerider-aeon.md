# jacerider/aeon

> 标签: PHP

## 简介

Aeon is a base theme for Drupal. It has Bootstrap, Sass, BrowserSync and Font Awesome built-in.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
