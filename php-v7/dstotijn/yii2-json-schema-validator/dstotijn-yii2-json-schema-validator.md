# dstotijn/yii2-json-schema-validator

> 标签: json, schema, validator, yii2

## 简介

A Yii2 extension that provides a validator class for JSON Schema validation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
