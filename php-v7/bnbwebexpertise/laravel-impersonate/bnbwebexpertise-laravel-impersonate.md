# bnbwebexpertise/laravel-impersonate

> 标签: auth, impersonate, impersonation, laravel, laravel-package, laravel-plugin, package, plugin, user

## 简介

Laravel Impersonate is a plugin that allows to you to authenticate as your users forked from 404labfr/laravel-impersonate.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
