# mhinspeya/module-remoteimages

> 标签: MHinspeya, catalog, external images, headless, image override, magento, magento2, module, product images, remote images

## 简介

Magento 2 module that enables external/remote product images stored as JSON URLs in a custom product attribute to be displayed natively across all catalog surfaces — including product listings, product detail gallery, mini-cart, and checkout cart — without importing images to the Magento media directory.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
