# renedekat/blmreader

> 标签: blmreader, renedekat

## 简介

BLM Reader to parse BLM files and output as CSV, Excel, Collection or Array

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
