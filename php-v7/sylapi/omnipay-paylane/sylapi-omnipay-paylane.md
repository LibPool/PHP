# sylapi/omnipay-paylane

> 标签: gateway, merchant, omnipay, pay, paylane, payment, purchase

## 简介

Paylane gateway for Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
