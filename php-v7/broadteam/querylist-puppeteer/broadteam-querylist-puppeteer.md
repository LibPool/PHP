# broadteam/querylist-puppeteer

> 标签: PHP

## 简介

QueryList Plugin: Use Puppeteer to crawl Javascript dynamically rendered pages.(Headless Chrome ) 使用Puppeteer采集JavaScript动态渲染的页面

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
