# phpmailer-shell/phpmailer-shell

> 标签: PHP

## 简介

PHP邮件发送外壳程序，集邮件发送（同步&异步）、收取于一体，使应用能够更加方便的嵌入邮件系统。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
