# topextend/ip2region

> 标签: Ip2Region

## 简介

Ip2Region for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

## 官网

- 官网：https://github.com/topextend/ip2region
- 源码仓库：https://gitee.com/topextend/ip2region.git
- Packagist 页面：https://packagist.org/packages/topextend%2Fip2region

## 获取地址

- Composer 安装：`composer require topextend/ip2region`
- Packagist 仓库：https://repo.packagist.org/p2/topextend/ip2region.json
- 许可证：Apache-2.0
- PHP 要求：>=5.4
