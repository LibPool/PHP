# mywhistlebox/mwb-sdk

> 标签: api, mywhistlebox, secure documents

## 简介

A PHP SDK to integrate with the MyWhistleBox platform

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
