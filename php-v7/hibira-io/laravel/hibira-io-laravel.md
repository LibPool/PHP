# hibira-io/laravel

> 标签: Broadcasting, WebSockets, echo, hibira, laravel, push notifications, realtime

## 简介

Laravel broadcasting, push notifications and webhooks for Hibira, with one composer require

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
