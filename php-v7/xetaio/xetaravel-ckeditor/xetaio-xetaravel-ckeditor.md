# xetaio/xetaravel-ckeditor

> 标签: CKEditor, Xetaravel, laravel

## 简介

A wrapper to use CKEditor with Laravel.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
