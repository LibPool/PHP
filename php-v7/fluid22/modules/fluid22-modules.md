# fluid22/modules

> 标签: container, dependency-injection, di, fluid22, modules, plugin, wordpress, wordpress-plugin

## 简介

Module system for developing plugins in WordPress

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
