# mkrysztofiak/smsplanet-php-client

> 标签: api client, mms, sms, smsplanet, smsplanet.pl

## 简介

Klient SMS API napisany w języku PHP, pozwalający na wysyłanie wiadomości SMS, MMS oraz korzystanie z innych funkcji dostępnych w serwisie SMSPLANET.pl

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
