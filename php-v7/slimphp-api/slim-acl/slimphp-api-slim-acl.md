# slimphp-api/slim-acl

> 标签: PHP

## 简介

A middleware module for Slim3 to provide ACL using ZF2's Zend\Permissions\Acl

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
