# devscreencast/aws-sdk-php-wrapper

> 标签: aws, file upload, php, php sdk, s3

## 简介

A simple wrapper over aws php sdk to perform basic file management task

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
