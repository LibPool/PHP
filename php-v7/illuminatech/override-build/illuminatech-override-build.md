# illuminatech/override-build

> 标签: assets, build, compile, laravel, materials, override, patch

## 简介

Allows re-building materials from 3rd party libraries with patch

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
