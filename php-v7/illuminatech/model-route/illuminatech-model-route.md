# illuminatech/model-route

> 标签: Match, laravel, matching, model, route, routing, slug

## 简介

Allows continuing route matching in case bound model does not exist

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
