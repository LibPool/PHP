# marlonfan/nsq_to_swoole

> 标签: Socket, client, nsq, php, swoole

## 简介

a strong php client for NSQ using swoole extension

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
