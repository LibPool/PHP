# firano/excelbundle

> 标签: Symfony2, bundle, excel, xls

## 简介

This is a Symfony2 Bundle helps you to read and write Excel files (including pdf, xlsx, odt), thanks to the PHPExcel library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
