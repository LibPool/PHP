# facebook/definition-finder

> 标签: autoload, definitions, hack, hhvm

## 简介

Find definitions in PHP or Hack files. Useful for autoloaders.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
