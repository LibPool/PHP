# leonid74/simple-logger-php

> 标签: debug, debugging-tool, logger, simple-logger

## 简介

Simple logger that sends debugging information to the file, to the screen, via email

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
