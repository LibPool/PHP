# pma987/test

> 标签: cabundle, cacert, certificate, ssl, tls

## 简介

Lets you find a path to the system CA bundle, and includes a fallback to the Mozilla CA bundle.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
