# specifi/yii2-datatables

> 标签: datatable, datatables, jquery, plugin, widget, yii, yii2

## 简介

Yii2 Extension for DataTables jQuery plug-in

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
