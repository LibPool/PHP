# cast/sha2

> 标签: PHP

## 简介

Transparent SHA2-256 Implementation for PHP. Based on https://github.com/spipremix/ecrire/blob/master/auth/sha256.inc.php

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
