# dev-lancer/mc-pack

> 标签: console, library, minecraft, motd, php, properties, query, rcon, server, sftp, ssh, www

## 简介

The library is designed to integrate the minecraft server with the website.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
