# phpmystic/kai

> 标签: PHP

## 简介

A fluent, exception-less PHP HTTP client library that uses a callback-based approach for handling responses. Built on cURL.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
