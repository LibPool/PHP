# lucamauri/wiki2ban

> 标签: fail2ban, mediawiki, php, security

## 简介

Log failed MediaWiki login attempts to a file consumable by Fail2Ban

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
