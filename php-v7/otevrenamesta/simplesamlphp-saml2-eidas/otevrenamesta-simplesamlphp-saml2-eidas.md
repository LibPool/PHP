# otevrenamesta/simplesamlphp-saml2-eidas

> 标签: SAML2, eID, eidas, php, saml, simplesamlphp

## 简介

PHP Library wrapped around simplesamlphp/saml2 providing helpers for eIDAS relevant integration

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
