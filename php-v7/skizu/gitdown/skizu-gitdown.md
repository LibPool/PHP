# skizu/gitdown

> 标签: commonmark, git, gitdown, markdown, parser

## 简介

Markdown parser for PHP based on the CommonMark spec with integration into git

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
