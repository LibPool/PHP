# lsclh/apidoc

> 标签: PHP

## 简介

根据fastadmin的文档自动生成思想,借用其模版适配的接口文档自动生成工具

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
