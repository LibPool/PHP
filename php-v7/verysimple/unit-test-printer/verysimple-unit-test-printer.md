# verysimple/unit-test-printer

> 标签: formatter, php, phpunit, resultprinter, unit test

## 简介

Formats PHPUnit output with verbose information about tests as they run.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
