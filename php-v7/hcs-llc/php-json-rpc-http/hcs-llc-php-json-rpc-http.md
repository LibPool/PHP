# hcs-llc/php-json-rpc-http

> 标签: client, http, json, json-rpc, jsonrpc, php, php-json-rpc, rpc, server

## 简介

Maintained fork of the abandoned datto/json-rpc-http package. Provides an HTTP client and server for JSON-RPC 2.0.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
