# zolotarev/yii2-semantic-ui

> 标签: semantic, semantic ui, widgets, yii2

## 简介

Semantic UI extension for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
