# ngocnh/translator

> 标签: language, laravel, multilingual, translation, translations, translator

## 简介

Laravel translator for multilingual Eloquent objects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
