# tpenaranda/bcoin-laravel

> 标签: api, bcoin, btc, laravel, node, tpenaranda

## 简介

A Laravel 5 package to connect with BCoin (bcoin.io) full node API.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
