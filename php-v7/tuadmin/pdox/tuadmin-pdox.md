# tuadmin/pdox

> 标签: builder, orm, pdo, php, query, sql

## 简介

Useful Query Builder, PDO Class for PHP. A simple access to your SQL records.(FIXED by tuadmin)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
