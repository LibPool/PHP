# joppuyo/acf-image-aspect-ratio-crop

> 标签: PHP

## 简介

ACF field that allows user to crop image to a specific aspect ratio

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
