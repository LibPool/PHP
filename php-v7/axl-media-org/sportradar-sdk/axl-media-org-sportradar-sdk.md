# axl-media-org/sportradar-sdk

> 标签: laravel, php, sdk, sportradar, sports

## 简介

PHP-based SDK to work with the Sportradar API & live events.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
