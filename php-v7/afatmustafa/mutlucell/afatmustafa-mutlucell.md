# afatmustafa/mutlucell

> 标签: api, laravel, mutlucell, sms

## 简介

Mutlucell SMS API wrapper for sending sms text messages for Laravel 10, 9, 8, 7, 6, 5 and 4.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
