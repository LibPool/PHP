# germania-kg/hash

> 标签: PSR3, callable, hash, password, psr-3, verify

## 简介

Callable wrapper around PHP's password hashing and verification, optional with PSR3 Logger support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
