# npetrovski/php5-image

> 标签: Black and White, Blur, Border, Brightness, Canvassize, Corner, Drop Shadow, Face Detector, Gaussian, Jitter, Layers, Negate, PSD, Scanlines, Shadow, Sobel Edge Detection, Vignette, captcha, colorize, filters, flip, gd, ico, image, information, ripple, rotate, thumbnail, tiles, trim, vanilla, watermark

## 简介

Object-oriented image handling and manipulation library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
