# tobya/tailwind-trumpet

> 标签: Tobya, laravel, tailwind-trumpet

## 简介

A Package to trumpet or expose Tailwind css classes that are set in code.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
