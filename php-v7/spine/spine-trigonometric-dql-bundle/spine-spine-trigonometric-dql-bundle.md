# spine/spine-trigonometric-dql-bundle

> 标签: SIN, Symfony2, Trigonometric, cos, doctrine2, dql, symfony3

## 简介

Set of triginometric functions for DQL in Doctrine.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
