# anomalous/iron-sql

> 标签: adapter, database, mysql, mysqli, pdo, php

## 简介

PHP database adapter for MySQL Databases. Inspired by MeekroDB.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
