# yupe/yupe

> 标签: cmf, cms, ecommerce, shop, web, yii, yupe

## 简介

Yupe is simple and lightweight CMF for web-development, built on top of Yii 1.x

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
