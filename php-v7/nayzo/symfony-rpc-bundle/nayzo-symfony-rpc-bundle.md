# nayzo/symfony-rpc-bundle

> 标签: bundle, rpc, server, symfony, xml-rpc, xmlrpc

## 简介

This Symfony bundle provide easy way to create XMLRPC server

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
