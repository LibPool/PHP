# falconavs/humus-amqp-bundle

> 标签: AMQP, humusamqp, message, queue, rabbitmq, symfony

## 简介

Integrates the HumusAmqp library into Symfony

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
