# pluswerk/typoscript-auto-fixer

> 标签: TYPO3 CMS, TypoScript

## 简介

Provides an auto fixer based on the TypoScript linter from Martin Helmich

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
