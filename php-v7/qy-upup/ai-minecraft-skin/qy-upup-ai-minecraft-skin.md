# qy-upup/ai-minecraft-skin

> 标签: PHP

## 简介

A robust PHP library providing seamless integration with AI-powered Minecraft skin generation services, enabling developers to programmatically create and manage customized character skins.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
