# b3nl/laravel-theme

> 标签: PHP

## 简介

Created my own laravel theme package, based on a model, a middleware and loading callbacks with an theme.php in a resource folder.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
