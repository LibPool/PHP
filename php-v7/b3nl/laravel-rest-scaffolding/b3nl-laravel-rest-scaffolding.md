# b3nl/laravel-rest-scaffolding

> 标签: api, framework, generator, laravel, rest

## 简介

Generates basic routes and requests for REST APIs.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
