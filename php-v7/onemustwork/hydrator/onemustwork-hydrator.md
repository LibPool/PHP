# onemustwork/hydrator

> 标签: Simple, array, hydrator, object

## 简介

Easy to use hydrator to hydrate objects from an array or extract objects to an array.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
