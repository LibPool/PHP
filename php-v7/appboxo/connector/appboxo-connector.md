# appboxo/connector

> 标签: extension, magento, magento 2 extension, magento 2 module, magento2 extension, magento2 module, module

## 简介

Appboxo Connector is Magento2 mdoule to providing basic connection link between Appboxo and client's stores.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
