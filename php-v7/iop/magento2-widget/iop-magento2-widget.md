# iop/magento2-widget

> 标签: composer-installer, magento

## 简介

Magento 2 widget to show 'Frequently Ordered Products' and 'Recently Ordered Products' for B2B logged customer. GraphQL API added.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
