# moc/synchronizeurl

> 标签: Neos, flow, url

## 简介

Neos CMS package that keep page titles and URLs in sync by updating the URL every time the title changes

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
