# bigwing/pet-and-go-wp

> 标签: api, http, petandgo, wordpress

## 简介

PHP library for interacting with the Pet and Go HTTP API inside of WordPress.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
