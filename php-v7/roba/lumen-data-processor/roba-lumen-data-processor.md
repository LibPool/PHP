# roba/lumen-data-processor

> 标签: csv, data, ppricessing, spreadsheet

## 简介

Processes spreadsheet data and outputs CSV for importing to a database

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
