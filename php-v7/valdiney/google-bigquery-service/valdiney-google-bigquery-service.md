# valdiney/google-bigquery-service

> 标签: GoogleBigQuery, bigquery

## 简介

This Service is used to abstrain the use of the BigQuery from Google using php language.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
