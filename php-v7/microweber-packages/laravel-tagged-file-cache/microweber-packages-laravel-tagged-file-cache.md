# microweber-packages/laravel-tagged-file-cache

> 标签: PHP

## 简介

Taggable File Cache driver for Laravel. Allows the use of Cache tags with a file cache.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
