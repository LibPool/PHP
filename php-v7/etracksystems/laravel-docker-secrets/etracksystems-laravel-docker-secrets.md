# etracksystems/laravel-docker-secrets

> 标签: docker, laravel, secrets, swarm

## 简介

Use Docker Swarm Secrets in your Laravel config files

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
