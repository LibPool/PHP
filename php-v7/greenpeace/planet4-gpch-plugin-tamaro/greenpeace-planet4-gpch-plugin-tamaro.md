# greenpeace/planet4-gpch-plugin-tamaro

> 标签: PHP

## 简介

A plugin to provide the RaiseNow Tamaro Widget as a configurable block.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
