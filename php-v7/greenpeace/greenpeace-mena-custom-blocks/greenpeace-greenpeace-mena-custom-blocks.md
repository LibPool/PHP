# greenpeace/greenpeace-mena-custom-blocks

> 标签: PHP

## 简介

Custom WordPress blocks for Greenpeace MENA campaign landing pages.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
