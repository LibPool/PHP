# greenpeace/planet4-plugin-migrated-urls

> 标签: PHP

## 简介

This repository contains the WordPress plugin that provides the old and new urls from migrated content from p3 to p4.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
