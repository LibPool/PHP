# greenpeace/planet4-gpnordic-plugin-portrait

> 标签: PHP

## 简介

This repository contains the wordpress plugin that allows petitions with device camera for attaching a photo.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
