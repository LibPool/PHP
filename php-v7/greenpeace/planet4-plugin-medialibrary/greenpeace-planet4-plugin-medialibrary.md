# greenpeace/planet4-plugin-medialibrary

> 标签: PHP

## 简介

This repository contains the wordpress plugin that connects Planet 4 with the Media Library platform.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
