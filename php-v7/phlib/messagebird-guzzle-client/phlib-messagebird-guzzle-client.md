# phlib/messagebird-guzzle-client

> 标签: Guzzle, Message Bird, client, http

## 简介

A guzzle specific client implementation for the Message Bird API.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
