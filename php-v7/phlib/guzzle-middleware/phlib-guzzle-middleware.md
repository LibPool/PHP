# phlib/guzzle-middleware

> 标签: Guzzle, absoluteurls, charset, middlware

## 简介

Guzzle Middleware: absolute urls, convert charset

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
