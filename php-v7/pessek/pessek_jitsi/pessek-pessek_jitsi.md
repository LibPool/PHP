# pessek/pessek_jitsi

> 标签: elgg, events, plugin

## 简介

Plugin which gives you the extensive functionality to manage Jitsi videoconferencing. Allows user to Join meetings directly from Browser and phone

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
