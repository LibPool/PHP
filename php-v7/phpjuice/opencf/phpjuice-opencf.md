# phpjuice/opencf

> 标签: collaborative filtering, collaborative filtering engine, recommendation, recommender, weighted slope one

## 简介

PHP implementation of the (Weighted Slopeone,Cosine, Weighted Cosine) rating-based collaborative filtering schemes.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
