# phpjuice/blueprint

> 标签: blueprint, crud, laravel

## 简介

Blueprint is a powerful CRUD generator to speed up the development of your laravel apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
