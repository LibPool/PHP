# luigel/laravel5-amazon-mws

> 标签: amazon, api, laravel, mws, php

## 简介

Use Amazon's MWS web services with Laravel. Based on creacoon/amazon-mws-laravel package and modified to make it compatible with latest Laravel releases (+ bugfixes).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
