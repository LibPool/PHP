# benjaminmedia/wp-duplicate-featured-image

> 标签: plugin

## 简介

Plugin will auto set first attachment image as feature image, hide duplicate first attachment image while showing post content

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
