# blog404de/securecookie

> 标签: contao, cookie, secure-flag, ssl

## 简介

Set secure-cookie flag for https-sites on Contao <4.0

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Composer 安装：`composer require blog404de/securecookie`
