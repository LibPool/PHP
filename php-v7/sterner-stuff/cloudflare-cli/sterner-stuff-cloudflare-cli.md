# sterner-stuff/cloudflare-cli

> 标签: PHP

## 简介

Provides a command line interface to the WordPress Cloudflare plugin, for performing cache purge actions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
