# zooroyal/coding-standard

> 标签: ZooRoyal, lint, phpcpd, phpcs, phpmd, standards

## 简介

This is the ZooRoyal coding standard.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
