# manmath/dockerci

> 标签: ci, codeigniter, docker, docker codeigniter, dockerci

## 简介

Docker Compose structure to quickly startup CodeIgniter PHP Framework projects

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
