# layas/tdlib-schema

> 标签: td, td-api, tdlib, tdlib-schema, thruster

## 简介

A TdLib PHP Schema with generator for generating PHP objects from td_api.tl file

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
