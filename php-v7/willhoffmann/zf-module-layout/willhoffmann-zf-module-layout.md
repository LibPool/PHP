# willhoffmann/zf-module-layout

> 标签: module layouts, zf2, zf3

## 简介

ZfModuleLayouts is a ZF2 module for making module-specific layouts

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
