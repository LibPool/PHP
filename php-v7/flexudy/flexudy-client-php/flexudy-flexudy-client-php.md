# flexudy/flexudy-client-php

> 标签: ILIAS, artificial intelligence, auto question generator, auto summary, e-learning, moodle, nlp

## 简介

Flexudy PHP REST API Client. Generate summaries and flashcards automatically. Visit flexudy.com to learn more.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
