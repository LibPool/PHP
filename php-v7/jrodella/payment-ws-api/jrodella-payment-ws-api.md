# jrodella/payment-ws-api

> 标签: api, e-commerce, lyra, payment, php, sdk, soap, ws, wsdl

## 简介

SOAP WS API to call Lyra payment services in PHP based websites.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
