# talesoft/tale-stream

> 标签: memory-stream, psr-17, psr-7, stream, stream-wrapper, temp-stream

## 简介

A basic PSR-7 and PSR-17 compatible stream utility library

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
