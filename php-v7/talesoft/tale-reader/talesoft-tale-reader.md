# talesoft/tale-reader

> 标签: expression-reader, psr-7, reader, stream-reader, text-reader

## 简介

A reading library that can read and parse strings and PSR-7 streams

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
