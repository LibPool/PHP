# talesoft/tale-http-runtime

> 标签: http, psr-7, runtime

## 简介

A basic, PSR-7 compatible HTTP runtime based on middlewares

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
