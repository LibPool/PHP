# malhal/laravel-createdby

> 标签: CreatedBy, Laravel CreatedBy, Laravel-CreatedBy, Malcolm Hall, framework, laravel, malhal, models, updatedBy, user

## 简介

A trait that adds createdBy and updatedBy user relations to your models

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
