# friendsofhyperf/mysql-grammar-addon

> 标签: addon, dev, grammar, hyperf, mysql, v3.2

## 简介

The MySqlGrammar addon for Hyperf.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
