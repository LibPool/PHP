# lou117/core-skeleton

> 标签: PHP

## 简介

Ready-to-use skeleton for Core microframework. See https://github.com/Lou117/core for more details about Core.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
