# quadram/laravel-websockets

> 标签: Quadram, beyondcode, laravel-websockets

## 简介

An easy to use WebSocket server (Forked because the original project needs to update some dependencies)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
