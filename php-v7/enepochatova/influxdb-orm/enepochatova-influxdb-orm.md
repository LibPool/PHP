# enepochatova/influxdb-orm

> 标签: PHP

## 简介

The PHP library which helps to convert entities to InfluxDB points and back. Uses annotations for entities configuration.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
