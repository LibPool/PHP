# ghi/laravel-obra-context

> 标签: cadeco, ghi, laravel, obra

## 简介

Paquete para intergrar la multiple tenencia para las obras de cadeco

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
