# wirebox/phpbrake

> 标签: airbrake, error, exception, logging, notifier

## 简介

Airbrake exception and error notifier for PHP

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://airbrake.io
- 源码仓库：https://github.com/Wirebox/phpbrake.git
- Packagist 页面：https://packagist.org/packages/wirebox%2Fphpbrake
