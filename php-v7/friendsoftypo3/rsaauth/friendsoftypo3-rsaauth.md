# friendsoftypo3/rsaauth

> 标签: PHP

## 简介

Legacy service to authenticate TYPO3 BE and FE users using private/public key encryption of passwords

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
