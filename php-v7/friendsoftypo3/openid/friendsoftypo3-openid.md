# friendsoftypo3/openid

> 标签: OpenId, typo3

## 简介

OpenID authentication for TYPO3 CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/FriendsOfTYPO3/openid.git
