# serendipity_hq/component-var-dumper-f

> 标签: debug, dump

## 简介

Adds functions dumpf() and ddf() to Symfony's VarDumper component to be used in CLI scripts to dump to a file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
