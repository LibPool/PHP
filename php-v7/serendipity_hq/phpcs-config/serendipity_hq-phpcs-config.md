# serendipity_hq/phpcs-config

> 标签: php cs, php cs fixer, phpcs, phpcs fixer

## 简介

Custom configuration for PHP CS Fixer used by Serendipity HQ.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
