# yuliusardian/validation

> 标签: PHP

## 简介

Use Laravel Validation outside of Laravel, This can be useful and helpful for validate any data for our projects.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
