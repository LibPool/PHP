# ipwho/ipwho-ip-geolocation-api

> 标签: IP, geoip, geolocation, ipwho

## 简介

Official PHP SDK for the IPWho IP geolocation API (lookup, me, bulk).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
