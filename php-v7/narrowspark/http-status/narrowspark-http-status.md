# narrowspark/http-status

> 标签: exception, http, http-status, http-status exceptions, psr-7, psr7, status

## 简介

A psr-7 package for working with HTTP statuses.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
