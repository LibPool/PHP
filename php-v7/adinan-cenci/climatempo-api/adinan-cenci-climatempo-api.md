# adinan-cenci/climatempo-api

> 标签: api, forecast, previsão do tempo, weather

## 简介

Uma api para previsão de tempo escrita em PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
