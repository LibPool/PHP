# neam/docker-stack

> 标签: docker, local-dev, nginx, php, php-fpm

## 简介

Toolkit for maintaining a Docker-based "one-process-per-container" stack for 12-factor web apps.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
