# graham-campbell/cms-cloudflare

> 标签: CMS CloudFlare, CMS-CloudFlare, CloudFlare API, Graham Campbell, GrahamCampbell, cloudflare, cms, framework, laravel

## 简介

CMS CloudFlare Is A CMS Core Plugin That Adds A CloudFlare Admin Module

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
