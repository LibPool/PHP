# graham-campbell/packagist-stats

> 标签: Graham Campbell, GrahamCampbell, Packagist Stats, Packagist-Stats, PackagistStats, cl, packages, packagist, stats

## 简介

Packagist Stats Is A CLI Tool To Display Download Stats For Packagist Packages

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
