# openmage-module-fostering/zookal_mock

> 标签: PHP

## 简介

Transparent auto detecting of disabled core modules & exten. Providing mock objects for not breaking Magento.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
