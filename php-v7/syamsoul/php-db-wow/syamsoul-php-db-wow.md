# syamsoul/php-db-wow

> 标签: database, db, mysql, php, syamsoulc, wow

## 简介

This package will make your life easier in handling MySQL database.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
