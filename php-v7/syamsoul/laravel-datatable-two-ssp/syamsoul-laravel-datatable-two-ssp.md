# syamsoul/laravel-datatable-two-ssp

> 标签: PHP

## 简介

DataTable SSP for Laravel. This package allows you to manage your DataTable from server-side in Laravel app.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
