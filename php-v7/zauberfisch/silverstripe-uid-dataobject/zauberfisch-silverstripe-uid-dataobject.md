# zauberfisch/silverstripe-uid-dataobject

> 标签: UID, guid, id, rfc4122, silverstripe, unique, uuid

## 简介

SilverStripe module for adding an unique id (UUID) to a DataObject

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
