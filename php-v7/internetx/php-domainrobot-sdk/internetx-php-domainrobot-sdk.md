# internetx/php-domainrobot-sdk

> 标签: PHP

## 简介

A php package for easy integration of the domainrobot API powered by InterNetX GmbH.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
