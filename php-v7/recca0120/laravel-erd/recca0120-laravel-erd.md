# recca0120/laravel-erd

> 标签: PHP

## 简介

Laravel ERD automatically generates Entity-Relationship Diagrams from your Laravel models and displays them using Vuerd.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
