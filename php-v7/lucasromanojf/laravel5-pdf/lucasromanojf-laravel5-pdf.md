# lucasromanojf/laravel5-pdf

> 标签: laravel, laravel5, pdf, wkhtmltopdf

## 简介

Provides the HTML2PDF functionality using the wkhtmltopdf library (Laravel 5)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
