# pfefferle/wordpress-activitypub

> 标签: PHP

## 简介

The ActivityPub protocol is a decentralized social networking protocol based upon the ActivityStreams 2.0 data format.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
