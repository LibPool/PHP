# robertov8/guzzle-zend

> 标签: PHP

## 简介

Abstrai o modelo de requisição do Guzzle e transforma em Zend Http Requests XD

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
