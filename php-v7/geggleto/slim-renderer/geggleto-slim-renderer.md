# geggleto/slim-renderer

> 标签: framework, php, phtml, renderer, slim, template, view

## 简介

Render PHP view scripts into a PSR-7 Response object.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
