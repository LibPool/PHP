# michaelmoussa/dent

> 标签: doctrine, doctrine entities, doctrine orm, doctrine test, doctrine testing, phpunit

## 简介

PHPUnit extension to support testing Doctrine ORM entity annotations

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
