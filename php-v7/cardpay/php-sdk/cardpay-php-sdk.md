# cardpay/php-sdk

> 标签: cardpay, php, sdk

## 简介

CardPay PHP SDK

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 官网：https://integration.cardpay.com
- 源码仓库：https://github.com/cardpay/php-sdk.git
- Packagist 页面：https://packagist.org/packages/cardpay%2Fphp-sdk

- PHP 要求：>=5.6
