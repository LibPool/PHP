# webcito/bs-worldcup

> 标签: PHP

## 简介

A lightweight jQuery plugin to display World Cup 2026 data using Bootstrap 4 or 5.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
