# webcito/bs-table

> 标签: PHP

## 简介

A lightweight and user-friendly table plugin for Bootstrap, designed to efficiently manage tables in a streamlined, Bootstrap-themed web environment.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
