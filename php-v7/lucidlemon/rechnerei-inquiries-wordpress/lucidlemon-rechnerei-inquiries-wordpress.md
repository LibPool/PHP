# lucidlemon/rechnerei-inquiries-wordpress

> 标签: PHP

## 简介

WordPress plugin: forwards outgoing site emails to your Rechnerei inquiries inbox.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
