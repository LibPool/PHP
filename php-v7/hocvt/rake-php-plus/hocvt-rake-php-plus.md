# hocvt/rake-php-plus

> 标签: Algorithm, automatic, extraction, keyword, rake, rapid

## 简介

Yet another PHP implementation of the Rapid Automatic Keyword Extraction algorithm (RAKE).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
