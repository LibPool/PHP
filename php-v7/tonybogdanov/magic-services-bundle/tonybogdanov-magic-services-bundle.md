# tonybogdanov/magic-services-bundle

> 标签: PHP

## 简介

Auto-magic service definition generator for Symfony 4.0+ / 5.0+

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
