# broccoli-html-editor/broccoli-field-summernote

> 标签: broccoli, pickles2

## 简介

WYSIWYGエディタ "summernote" によるフィールド機能を追加します。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
