# matthewerskine/json-error-renderer

> 标签: PHP

## 简介

A simple helper for Laravel/Lumen which will allow rendering of errors as JSON

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
