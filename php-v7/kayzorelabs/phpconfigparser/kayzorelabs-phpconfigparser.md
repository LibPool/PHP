# kayzorelabs/phpconfigparser

> 标签: config, configparser, kayzorelabs, noiselabs, parser

## 简介

A configuration file parser for PHP 7.1 and up

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
