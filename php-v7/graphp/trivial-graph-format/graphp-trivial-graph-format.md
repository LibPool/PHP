# graphp/trivial-graph-format

> 标签: TGF, Trivial Graph Format

## 简介

Trivial Graph Format (TGF) is a simple text-based file format for describing graphs

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
