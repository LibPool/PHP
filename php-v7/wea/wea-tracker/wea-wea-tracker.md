# wea/wea-tracker

> 标签: OXID, analytics, econda, emos, eshop, google, modules

## 简介

Econda emos tracking module for oxid esales (CE, PE and EE).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
