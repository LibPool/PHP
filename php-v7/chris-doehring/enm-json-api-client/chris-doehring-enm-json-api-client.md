# chris-doehring/enm-json-api-client

> 标签: api, client, json, psr-18, psr-7

## 简介

Abstract client-side php implementation of the json api specification (jsonapi.org)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
