# christopherdowson/sha512twigfilter

> 标签: Craft, cms, craft-plugin, craftcms, sha512 twig filter

## 简介

A filter for twig to hash a string with sha512

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
