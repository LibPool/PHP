# stolz/assets

> 标签: JS, agnostic, asset, assets, css, javascript, laravel, minify, pipeline

## 简介

An ultra-simple-to-use assets management library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
