# php-console/php-console

> 标签: chrome, debug, error handler, errors, google chrome, php

## 简介

PHP library for Google Chrome extension "PHP Console".

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
