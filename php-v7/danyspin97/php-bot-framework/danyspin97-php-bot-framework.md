# danyspin97/php-bot-framework

> 标签: bot, framework, telegram, telegram-bot

## 简介

PhpBotFramework is a framework for Telegram Bots' APIs.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
