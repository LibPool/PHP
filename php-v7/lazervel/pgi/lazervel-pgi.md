# lazervel/pgi

> 标签: integration, payment getway, php, razorpay

## 简介

PGI is a PHP library that provides ready-to-use integrations for multiple payment gateways.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
