# lazervel/cryptor

> 标签: codec, cryptor, decrypt, encrypt, lazervel, php

## 简介

Cryptor is a PHP library for easy and secure data encryption and decryption.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
