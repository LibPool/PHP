# bourdeau/handevaluator-bundle

> 标签: evaluator, poker, symfony, texas holdem

## 简介

Poker hand evaluator bundle for Symfony3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
