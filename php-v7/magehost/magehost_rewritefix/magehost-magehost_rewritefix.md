# magehost/magehost_rewritefix

> 标签: PHP

## 简介

MageHost_RewriteFix: Solves a problem most big ‪#‎Magento‬ 1.x shops face: an ever growing huge URL Rewrite table.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
