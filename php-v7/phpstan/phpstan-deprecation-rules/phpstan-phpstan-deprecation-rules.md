# phpstan/phpstan-deprecation-rules

> 标签: static analysis, 规则, 静态分析

## 简介

PHPStan rules for detecting usage of deprecated classes, methods, properties, constants and traits.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
