# andriichuk/keepenv

> 标签: dotenv, env, env-manager, env-spec, env-validation

## 简介

KeepEnv is a tool for checking and managing environment variables based on a specification file.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
