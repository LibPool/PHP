# kmfk/hateoas-bundle

> 标签: HATEOAS, bundle, json, symfony

## 简介

Symfony2 Bundle to add Hateoas compliant urls to JMS Serializer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
