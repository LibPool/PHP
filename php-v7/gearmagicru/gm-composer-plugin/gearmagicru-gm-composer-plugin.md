# gearmagicru/gm-composer-plugin

> 标签: composer, gearmagic, gm-composer, plugin

## 简介

Composer plugin for installing components, themes and libraries of the GearMagic web application

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
