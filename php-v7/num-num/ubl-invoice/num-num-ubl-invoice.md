# num-num/ubl-invoice

> 标签: E-Invoice, digital invoice, efff, einvoice, electronic invoice, euinvoice, invoice, peppol, peppol bis, peppol invoice, peppolbis, ubl, ubl invoice, ublinvoice, xml, xml invoice

## 简介

A modern object-oriented PHP library to create valid UBL and Peppol BIS 3.0 files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
