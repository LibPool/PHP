# citrus-soft/bitrix24-php-sdk

> 标签: Bitrix24, api, php, rest

## 简介

A powerfull PHP library for the Bitrix24 REST API. Fork of mesilov/bitrix24-php-sdk

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
