# ctrbts/secure-timthumb

> 标签: TimThumb, gd, image, legacy-support, security, thumbnail

## 简介

A secure, modern, drop-in replacement for the legacy TimThumb PHP script.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
