# fr3nch13/phpdoc-markdown

> 标签: documentation, markdown, phpDocumentor, phpdoc

## 简介

phpDocumentor template that generates Markdown documentation.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
