# lsmonki/php-ixr

> 标签: remote procedure call, rpc, xlm-rpc, xmlrpc

## 简介

Incutio XML-RPC library (IXR)

按 require.php 推断最低支持 PHP 4；已收录于 php-v5, php-v7, php-v8。
