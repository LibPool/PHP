# ipsocode/hypervel-influxdb

> 标签: InfluxDB2, coroutine, eloquent, hypervel, influxdb, influxdb3, influxql, query-builder, sql, swoole, time-series

## 简介

InfluxDB connections for Hypervel, with InfluxQL for InfluxDB 1.x, 2.x and 3 through a query builder of its own or Hypervel's, and an SQL database driver for InfluxDB 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
