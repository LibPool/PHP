# ipsocode/hypervel-cin7

> 标签: cin7, coroutine, dear, hypervel, inventory, saloon

## 简介

Cin7 Core API client for Hypervel, built on hypervel/saloon

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
