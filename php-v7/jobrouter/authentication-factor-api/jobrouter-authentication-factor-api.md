# jobrouter/authentication-factor-api

> 标签: PHP

## 简介

API stubs for developing a plugin that provides a 2FA authentication factor in JobRouter®

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
