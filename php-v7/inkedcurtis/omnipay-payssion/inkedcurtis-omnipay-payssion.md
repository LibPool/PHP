# inkedcurtis/omnipay-payssion

> 标签: gateway, merchant, omnipay, pay, payment, payssion

## 简介

Payssion driver for the Omnipay payment processing library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
