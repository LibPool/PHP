# levizwannah/zasenv

> 标签: API setup, Actors-Supporters Arrangement, ZAS, ZASS, Zwannah API Structure Specification, asa

## 简介

Set up the folders/directories of the API/Backend following the ZAS specification

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
