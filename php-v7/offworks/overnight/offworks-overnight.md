# offworks/overnight

> 标签: mysql, pdo, php-mysql, query builder

## 简介

Yet another simple and consistent pdo based php-mysql query builder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
