# oip/custom

> 标签: bitrix, catalog

## 简介

Standard product catalog for Bitrix CMS from ООО "Отдел Интернет-проектов"

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
