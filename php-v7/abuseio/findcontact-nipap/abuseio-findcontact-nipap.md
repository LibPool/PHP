# abuseio/findcontact-nipap

> 标签: abuseio, findcontact, laravel, nipap

## 简介

AbuseIO module for IP lookups against NIPAP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
