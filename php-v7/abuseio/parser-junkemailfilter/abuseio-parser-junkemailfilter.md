# abuseio/parser-junkemailfilter

> 标签: abuseio, junkemailfilter, laravel, parser

## 简介

Parser addon for handling notifications from junkemailfilter

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
