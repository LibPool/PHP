# estaheri/perfectapi

> 标签: perfect panel, perfect panel admin api, perfect panel api, perfect panel library, perfect panel php, perfect panel sdk

## 简介

php library for communicating perfect panel websites using API for clients and AdminAPI for panel owners

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
