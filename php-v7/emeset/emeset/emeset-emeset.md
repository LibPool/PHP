# emeset/emeset

> 标签: DAW, DAWM07, emeset, framework

## 简介

Estructura d'un projecte amb Emeset el framework per alumnes de DAW.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
