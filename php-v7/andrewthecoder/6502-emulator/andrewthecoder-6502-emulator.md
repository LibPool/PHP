# andrewthecoder/6502-emulator

> 标签: 6502, emulator, php, retrocomputing

## 简介

A 6502 microprocessor emulator written in PHP.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
