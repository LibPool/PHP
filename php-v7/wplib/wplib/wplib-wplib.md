# wplib/wplib

> 标签: library, modules, mvc, php, wordpress, wplib

## 简介

A PHP Library that Adds Modules and Applications to WordPress

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
