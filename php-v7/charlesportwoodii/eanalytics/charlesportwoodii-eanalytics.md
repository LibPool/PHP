# charlesportwoodii/eanalytics

> 标签: analytics, analytics.js

## 简介

EAnalytics is a Analytics.js wrapper for Yii Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
