# techsemicolon/laravel-migration-pipeline

> 标签: PHP

## 简介

A migration pipeline to make sure same migration is not run again in multiple server setup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
