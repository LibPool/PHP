# james.xue/laravel-filesystem-oss

> 标签: aliyun, filesystems, laravel, oss, storage

## 简介

用于laravel的aliyun oss文件系统存储 aliyun oss filesystem storage for laravel

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
