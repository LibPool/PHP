# phalcon/dd

> 标签: VarDumper, dd, debug, dump, phalcon, utils

## 简介

This package will add the `dd` and `dump` helpers to your Phalcon application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
