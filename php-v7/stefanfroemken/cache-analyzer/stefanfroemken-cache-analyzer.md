# stefanfroemken/cache-analyzer

> 标签: TYPO3 CMS, analyzer, cache, framework, typo3

## 简介

Analyze data sent to TYPO3 Caching Framework before it is written

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
