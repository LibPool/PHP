# stefanfroemken/plesk-widget

> 标签: TYPO3 CMS, plesk, typo3, widget

## 简介

TYPO3 extension to show plesk information as widget on TYPO3 DashBoard

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
