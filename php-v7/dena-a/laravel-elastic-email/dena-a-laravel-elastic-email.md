# dena-a/laravel-elastic-email

> 标签: elastic, elasticemail, email, laravel

## 简介

Wrapper for Elastic Email HTTP api to send mails using laravel

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
