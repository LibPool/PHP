# chargely/chargely-sdk-php

> 标签: SSO, api, billing portal, chargely, chargify, sdk, single sign on

## 简介

Chargely SDK for PHP - Use Chargely services in your PHP project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
