# mata/mata-framework

> 标签: framework, mata

## 简介

MATA Framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- Packagist 仓库：https://repo.packagist.org/p2/mata/mata-framework.json
- PHP 要求：>=5.4.0
