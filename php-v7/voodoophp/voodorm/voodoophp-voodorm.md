# voodoophp/voodorm

> 标签: fluent query, mysql, orm, pdo, postgresql, sqlite

## 简介

VoodOrm is a micro-ORM which functions as both a fluent select query API and a CRUD model class.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
