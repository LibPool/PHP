# smeghead/single-file-unit-test

> 标签: php, single-file, testing, unit-testing

## 简介

Zero-dependency single-file unit testing framework for PHP 5.6 and above.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
