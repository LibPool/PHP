# crphp/check

> 标签: Socket, curl, health check, ping, traceroute, tracert

## 简介

Está é uma biblioteca genérica voltada a efetuar testes/verificação de conectividade

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
