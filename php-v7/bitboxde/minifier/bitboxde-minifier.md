# bitboxde/minifier

> 标签: Craft, JS, cms, craft-plugin, craftcms, css, minifier, seo

## 简介

CSS, JS and HTML-Minifier-Plugin for Craft CMS

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
