# phpatom/di

> 标签: PSR-11, atom, container, dependency injection, dependency injection container, di, framework, inversion of control, ioc

## 简介

An expressive and flexible dependency injection container for PHP

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
