# afosto/oauth-client

> 标签: afosto, authorisation, authorization, client, oauth, oauth2

## 简介

Afosto Client Provider for The PHP League OAuth 2.0 Client

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
