# wwpass/apiclient

> 标签: PHP

## 简介

A PHP implementation of the WWPass API

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。

## 官网

- 官网：https://wwpass.com/
- 源码仓库：https://github.com/wwpass/wwpass-php-sdk.git
- Packagist 页面：https://packagist.org/packages/wwpass%2Fapiclient

- 许可证：Apache-2.0
