# geraldoandradee/haanga

> 标签: PHP

## 简介

Template compiler for PHP, Django-style (as much as possible). Pretty efficent by avoiding to have anything at run-time.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
