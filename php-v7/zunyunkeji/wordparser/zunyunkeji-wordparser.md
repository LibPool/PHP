# zunyunkeji/wordparser

> 标签: PHP

## 简介

基于基础词库并结合自定义词库进行分词的系统，也可进行敏感词检测。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
