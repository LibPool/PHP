# inpsyde/wp-rest-starter

> 标签: OOP, api, endpoint, rest, starter, wordpress, wp

## 简介

Starter package for working with the WordPress REST API in an object-oriented fashion.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
