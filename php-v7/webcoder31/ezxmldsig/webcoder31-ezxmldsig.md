# webcoder31/ezxmldsig

> 标签: SSO, document electronic signature, single sign on, token based authentication, xml digital signature, xmldsig, xmlseclibs

## 简介

An easy-to-use set of PHP classes for common use cases of XML Digital Signatures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
