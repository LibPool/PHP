# cmpayments/guzzle-psp-authentication-middleware

> 标签: Guzzle, api, oauth, psp

## 简介

Guzzle middleware which adds authentication-header to Guzzle-requests.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
