# s00d/redis-web

> 标签: gui, redis, slim, vue, web

## 简介

Redis-web is a simple web interface in Laravel and Vue to manage Redis databases.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
