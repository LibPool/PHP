# deviscoding/flexbox

> 标签: css, flexbox, responsive, sass, scss, strapless

## 简介

CSS Utility classes for easily utilizing flexbox.  Inspired by Bootstrap 4, but usable as a standalone component.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
