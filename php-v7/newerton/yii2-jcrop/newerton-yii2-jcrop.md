# newerton/yii2-jcrop

> 标签: extension, jcrop, jquery, yii2

## 简介

Jcrop is the quick and easy way to add image cropping functionality to your web application.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
