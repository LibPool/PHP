# newerton/feedback-html2canvas

> 标签: feedback, html2canvas

## 简介

With feedback.js plugin repository and html2canvas with layout Bootstrap 3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
