# error-feature/yii2-pdfprint

> 标签:  pdf print,  print,  yii2, extension, iframe

## 简介

Load PDF into iframe and call print.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
