# ardabeyazoglu/datetime

> 标签: date, datetime, locale, time, timezone

## 简介

Extends the native DateTime class adding useful features, shorthand methods and locale support

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
