# stekky81/yii2-jqplot

> 标签: PHP

## 简介

Yii2 jqPlot widget renders charts and graphs based on jQuery Plotting Plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
