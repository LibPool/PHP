# sbarre/eloquent-versioned

> 标签: eloquent, laravel, orm, versioning

## 简介

Add transparent versioning to Laravel 5.2's Eloquent ORM

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
