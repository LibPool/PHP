# hostnet/hn-dependency-injection-plugin

> 标签: container, dependency-injection, doctrine, symfony

## 简介

Introduces the Symfony DI container in a Symfony 1 application.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
