# svrunit/svrunit

> 标签: docker, server, svrunit, testing

## 简介

SVRUnit allows you to configure tests that you can run against your server, Docker container or even plain Docker images.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
