# pc-magas/amp

> 标签: amp, drupal, mobile

## 简介

A set of useful classes and utilities to convert html to AMP html (See https://www.ampproject.org/)

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
