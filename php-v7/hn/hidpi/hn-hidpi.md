# hn/hidpi

> 标签: 2x, dpi, hidpi, image, img, media, retina, srcset

## 简介

Drop-in HiDPI solution. No new view helpers or workflow required. No JavaScript hacks. Just a few assumptions.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
