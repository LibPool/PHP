# wp-graphql/wp-graphiql

> 标签: PHP

## 简介

GraphiQL IDE in the WP-Admin. Works with the WPGraphQL plugin. https://github.com/wp-graphql/wp-graphql

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
