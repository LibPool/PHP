# wp-graphql/wp-graphql-custom-post-type-ui

> 标签: PHP

## 简介

Add your Custom Post Types and Custom Taxonomies to the WPGraphQL Schema using Custom Post Type UI plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
