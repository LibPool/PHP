# bolt/pathogen

> 标签: file, filesystem, manipulation, path

## 简介

Fork of pathogen, a general-purpose path library for PHP, but without using isolator.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
