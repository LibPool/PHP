# nswdpc/silverstripe-datawrapper

> 标签: charts, datawrapper, elemental, iframe, maps, nsw, silverstripe

## 简介

Module providing Datawrapper chart and map support

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
