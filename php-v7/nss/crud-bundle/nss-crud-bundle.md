# nss/crud-bundle

> 标签: Symfony2, bootstrap, bootstrap3, crud, crud generator, form filters, pager

## 简介

Symfony2.8+ Improved Crud generator using Boostrap3 framework, requires pagerfanta/pagerfanta and lexik/form-filter-bundle. Intended to be used for my own Symfony2 projects. Integration in other project may require some basic code adaptations.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
