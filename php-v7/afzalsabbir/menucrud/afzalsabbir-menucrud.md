# afzalsabbir/menucrud

> 标签: MenuCRUD, backpack

## 简介

An admin panel for menu items, using Backpack\CRUD on Laravel 6+.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
