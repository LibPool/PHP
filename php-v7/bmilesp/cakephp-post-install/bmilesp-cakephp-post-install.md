# bmilesp/cakephp-post-install

> 标签: PHP

## 简介

Post CakePHP install scripts to automate setup. For use with Composer Post Install Automation Scripts.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
