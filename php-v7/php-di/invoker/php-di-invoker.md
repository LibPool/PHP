# php-di/invoker

> 标签: callable, dependency, dependency-injection, injection, invoke, invoker, 反射, 方法调用

## 简介

Generic and extensible callable invoker

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
