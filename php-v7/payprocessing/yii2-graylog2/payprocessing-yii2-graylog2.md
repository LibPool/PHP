# payprocessing/yii2-graylog2

> 标签: extension, gelf, graylog, graylog2, log, log target, yii2

## 简介

Graylog2 log TCP target for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
