# ssofy/php-sdk

> 标签: Authentication, SSO, auth, login, oauth, oauth2, sdk, ssofy

## 简介

Official SSOfy PHP SDK.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
