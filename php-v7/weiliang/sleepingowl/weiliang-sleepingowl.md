# weiliang/sleepingowl

> 标签: admin, administrator, crud, laravel

## 简介

Administrative interface builder for Laravel.提供更好的中文支持..

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
