# gaziantep-bilisim/onesignal_laravel

> 标签: laravel, notification, onesignal, push

## 简介

Send push notifications using Onesignal on Laravel applications.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
