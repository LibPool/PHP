# cap/cleanmedia

> 标签: PHP

## 简介

Magento 2 CLI Command : remove images of deleted product in the `/media/catalog/product` folder

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
