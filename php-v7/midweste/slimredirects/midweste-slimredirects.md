# midweste/slimredirects

> 标签: 301, php, redirect, slimredirects

## 简介

Redirect a request to a different domain. Supports wildcard, regex, http to https redirection.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
