# midweste/simplelogger

> 标签: log, logger, psr-3

## 简介

SimpleLogger is a collection of very simple loggers implementing \Psr\Log\LoggerInterface (PSR-3)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
