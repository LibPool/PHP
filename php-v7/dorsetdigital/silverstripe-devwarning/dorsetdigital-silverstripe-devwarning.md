# dorsetdigital/silverstripe-devwarning

> 标签: admin, cms, silverstripe

## 简介

Adds notices to remind you if you have a site in dev mode, and other things

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
