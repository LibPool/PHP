# dorsetdigital/silverstripe-url-rewriter

> 标签: cdn, silverstripe

## 简介

Rewrites the URLs of a SilverStripe site

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
