# nolimits4web/framework7-icons

> 标签: fonts, framework7, icon font, icons, ios, ios icons, web font

## 简介

Free iOS-icons font for Framework7

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
