# unreal4u/ds18b20-sensor-read

> 标签: mqtt, php

## 简介

Will read out the w1_slave file of a DS18B20 sensor and send the output to a MQTT broker

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
