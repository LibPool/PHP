# jackiedo/artisan-php-cs-fixer

> 标签: artisan, coding, develop, fixer, laravel, php, php-cs-fixer, standards

## 简介

A PHP-CS-Fixer bridge for use via Artisan CLI on Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
