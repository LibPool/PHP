# franktiao/html-diff

> 标签: html diff, html rich text diff, rich text diff

## 简介

Compare two html text and return a merged html text.（对比两个html文本，返回一个合并差异后的html文本）

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
