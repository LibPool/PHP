# zfpoly/manager-maker-bundle

> 标签: PHP

## 简介

creates or updates a Doctrine entity class with a Manager to handle its crud operations, and optionally an API Platform resource.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
