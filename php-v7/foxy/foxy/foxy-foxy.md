# foxy/foxy

> 标签: Bridge, asset, composer, dependency manager, nodejs, npm, package, yarn

## 简介

Fast, reliable, and secure NPM/Yarn/pnpm bridge for Composer

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
