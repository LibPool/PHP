# pawel-brzezinski/sulu-storage-bundle

> 标签: PHP

## 简介

Custom implements of filesystem for Sulu storage. This bundle replaces standard Sulu Media Storage filesystem.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
