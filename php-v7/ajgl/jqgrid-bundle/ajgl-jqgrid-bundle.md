# ajgl/jqgrid-bundle

> 标签: bundle, grid, javascript, jqgrid, jquery, symfony

## 简介

Adds JqGrid javascript widget to Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
