# ajgl/csv-rfc

> 标签: 4180, csv, rfc, rfc4180

## 简介

Drop in replacement for native PHP CSV related functions to read and/or write RFC4180 compliant CSV files

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
