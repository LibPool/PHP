# ajgl/jqueryui-bundle

> 标签: bundle, jQueryUI, javascript, jquery, symfony, ui

## 简介

Adds jQuery Ui javascript library to Symfony2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
