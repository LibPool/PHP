# ghostunicorns/module-amasty-shopby-brand-for-snowdog-menu

> 标签: PHP

## 简介

This module create a new menu type into Snowdog Menu that shows Amasty Shop By Brand Popup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
