# meridius/coding-standard

> 标签: Coding Standard, coding, php, standard

## 简介

Meridius Coding Standard for PHP_CodeSniffer uses selected rules from all default, Slevomat, Consistence and Symfony2 coding standards.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
