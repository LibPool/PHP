# gaomingcode/autosize

> 标签: autosize, form, textarea, ui

## 简介

Autosize is a small, stand-alone script to automatically adjust textarea height to fit text.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
