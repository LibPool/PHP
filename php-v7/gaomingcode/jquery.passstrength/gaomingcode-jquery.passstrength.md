# gaomingcode/jquery.passstrength

> 标签: html-passStrength, jquery, jquery-passStrength, jquery-plugin, passStrength

## 简介

The jQuery Form Plugin allows you to easily and unobtrusively upgrade HTML passStrength to use AJAX.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
