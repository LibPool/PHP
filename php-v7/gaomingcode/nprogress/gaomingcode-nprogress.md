# gaomingcode/nprogress

> 标签: bar, nprogress, progress, spinner

## 简介

For slim progress bars like on YouTube, Medium, etc.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
