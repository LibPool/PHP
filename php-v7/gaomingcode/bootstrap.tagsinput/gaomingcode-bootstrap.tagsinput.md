# gaomingcode/bootstrap.tagsinput

> 标签: bootstrap, tagsinput

## 简介

jQuery tags input plugin based on Twitter Bootstrap.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
