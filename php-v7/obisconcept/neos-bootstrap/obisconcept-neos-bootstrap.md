# obisconcept/neos-bootstrap

> 标签: PHP

## 简介

A Neos CMS package to integrate Twitter Bootstrap and Font Awesome. Besides it integrates some Bootstrap based node types.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
