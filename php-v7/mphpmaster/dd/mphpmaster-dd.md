# mphpmaster/dd

> 标签: PHP

## 简介

`dd` is a helper method in Laravel. This package will add the `dd` to your application. src: larapack/dd

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
