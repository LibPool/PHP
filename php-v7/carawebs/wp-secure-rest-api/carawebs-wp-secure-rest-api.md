# carawebs/wp-secure-rest-api

> 标签: PHP

## 简介

A very simple mu plugin for WordPress that disallows access to REST endpoints for users that are not logged in.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
