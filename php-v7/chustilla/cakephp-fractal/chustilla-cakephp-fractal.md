# chustilla/cakephp-fractal

> 标签: api, cakephp, cakephp-fractal, fractal, transform

## 简介

An easy to use Fractal integration for CakePHP 3 applications

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
