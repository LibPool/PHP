# thefox/macho

> 标签: Mach, MachO, binary, i386, x86, x86-64, x86_64

## 简介

PHP script for modifying Mach-O executable i386 and x86_64 files.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
