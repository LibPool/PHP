# singularity/yii2-daterangepicker

> 标签: singularity, singularity solution, typeahead, widget, yii, yii 2, yii2

## 简介

Date range picker for Yii2 framework

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
