# redpandacoding/fakealfred

> 标签: PHP

## 简介

FakeAlfred is a PHP library that will generate fake data for you. Utilizing fzaninotto/faker and knpuniversity/lorem-ipsum-bundle

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
