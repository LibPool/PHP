# yandex/detector

> 标签: api, detector, mobile, wap, yandex

## 简介

PHP-library for interactions with Yandex.Detector / PHP реализация API для работы с сервисом Яндекс.Детектор

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
