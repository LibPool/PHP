# lucatacconi/oak-island-stone-decryptor

> 标签: 90 feet inscribed stone, Decryptor, Oak Island, Treasure, code, dart, fun, hunt, lua, php

## 简介

PHP and LUA code made for fun to try to decode the Oak Island 90 feet inscribed stone

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
