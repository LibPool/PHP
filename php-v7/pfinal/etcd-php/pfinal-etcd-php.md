# pfinal/etcd-php

> 标签: etcd, etcd-client, etcd-php, etcdv3

## 简介

PHP client for Etcd v3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。

- 源码仓库：https://github.com/pfinal/php-etcd.git
- Packagist 页面：https://packagist.org/packages/pfinal%2Fetcd-php
