# http-interop/http-middleware

> 标签: http, middleware, psr, psr-15, psr-7, request, response

## 简介

Common interface for HTTP server-side middleware

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
