# planetadeleste/wn-locationtowns-plugin

> 标签: city, location, plugin, town, winter

## 简介

Adds towns to states managed by Winter.Location plugin.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
