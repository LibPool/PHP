# analogic/alert-bundle

> 标签: alert, bundle, exception, symfony

## 简介

Simple Symfony bundle for email alerting PHP exceptions and Javascript exceptions

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
