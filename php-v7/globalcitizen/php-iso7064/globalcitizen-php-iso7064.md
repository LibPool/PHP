# globalcitizen/php-iso7064

> 标签: PHP

## 简介

php-iban is a library implementing the pure ISO/IEC 7064 checksum functions.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
