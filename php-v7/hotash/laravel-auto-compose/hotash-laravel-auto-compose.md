# hotash/laravel-auto-compose

> 标签: hotash, laravel-auto-compose

## 简介

A PHP Package To Automatically Compose Route Parameters To Appropriate View In Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
