# yii2mod/yii2-array-query

> 标签: yii2, yii2 array query, yii2 array search

## 简介

Yii2 component that allows for searching/filtering the elements of an array.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
