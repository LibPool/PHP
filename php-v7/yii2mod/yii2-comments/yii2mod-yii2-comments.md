# yii2mod/yii2-comments

> 标签: yii2, yii2-comments, yii2-comments-module, yii2-manage-comments

## 简介

Comments module for Yii2

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
