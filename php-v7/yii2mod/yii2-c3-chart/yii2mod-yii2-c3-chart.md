# yii2mod/yii2-c3-chart

> 标签: yii2, yii2 c3 chart, yii2 c3.js

## 简介

Yii2 wrapper for D3-based reusable chart library

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
