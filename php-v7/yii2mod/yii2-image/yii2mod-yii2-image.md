# yii2mod/yii2-image

> 标签: extension, yii2

## 简介

Provides methods for the dynamic manipulation of images. Various image formats such as JPEG, PNG, and GIF can be resized, cropped, rotated.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
