# techdivision/pagedesigner-content-provisioning

> 标签: PHP

## 简介

Extends firegento/m2-content-provisioning module in order to support magenerds/pagedesigner editor.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
