# techdivision/rewritemodule

> 标签: URL rewriting, mod_rewrite, module, webserver

## 简介

A simple rewrite module for PHP based web servers.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
