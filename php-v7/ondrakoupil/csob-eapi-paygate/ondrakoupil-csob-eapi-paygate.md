# ondrakoupil/csob-eapi-paygate

> 标签: Bank, cards, commerce, csob, merchant, pay, payment

## 简介

PHP Client library for easy integration of ČSOB payment gateway

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
