# canteen/html5

> 标签: HTML5, document, html, markup, tags

## 简介

Create dynamic, valid HTML5 markup with a simple an intuitive PHP API

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
