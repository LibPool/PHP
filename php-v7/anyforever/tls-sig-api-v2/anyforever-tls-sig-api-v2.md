# anyforever/tls-sig-api-v2

> 标签: im, tencent

## 简介

tls-sig-api-v2 适用于腾讯云通信生成用户账号签名。此库增加了生成PrivateMapKey功能，如非必要，建议使用官方库。

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
