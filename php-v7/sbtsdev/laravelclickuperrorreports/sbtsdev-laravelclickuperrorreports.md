# sbtsdev/laravelclickuperrorreports

> 标签: LaravelClickupErrorReports, laravel

## 简介

Package for sending error reports from laravel to Clickup

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
