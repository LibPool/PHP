# oracle/oci-php-sdk

> 标签: objectstorage, oci, oracle, sdk

## 简介

OCI SDK for PHP - Oracle Cloud Infrastructure services in your PHP project

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
