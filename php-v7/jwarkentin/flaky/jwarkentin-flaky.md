# jwarkentin/flaky

> 标签: flake, flakeid, uuid

## 简介

Module for generating short, fixed-length, sequential UUIDs ideal for indexing in various tree based structures

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
