# alhambra/proxmoxve

> 标签: KVM, OpenVZ, Proxmox, Virtualization, api

## 简介

A simple PHP 5.5+ Proxmox API client.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
