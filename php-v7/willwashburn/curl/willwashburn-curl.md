# willwashburn/curl

> 标签: 1-1, curl, wrapper

## 简介

1-1 class mapping of the cURL library so it can be mocked / stubbed

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
