# xin/robot

> 标签: PHP

## 简介

Robot 是一套简单、灵活、优雅的API，目前接入了国内主流的两大办公机器人（钉钉、微信），你可以使用它快速接入你的应用，从而更快捷的实现，数据统计提醒、程序异常报警等功能。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
