# xin/helper

> 标签: PHP

## 简介

PHP项目日常开发必备基础库，数组工具类、字符串工具类、数字工具类、函数工具类、服务器工具类、加密工具类

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
