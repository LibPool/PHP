# xin/plugin

> 标签: PHP

## 简介

实现的一套轻量级插件调度管理器，可接入ThinkPHP、Laravel等主流框架，让你的应用拥有可拔插式的开发体验。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
