# xin/var-dumper

> 标签: PHP

## 简介

这是一款将变量用symfony/var-dumper打印到浏览器的包，支持Webman，Hyperf等框架。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
