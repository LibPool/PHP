# xin/process

> 标签: PHP

## 简介

基于 symfony/process 实现的 Process App Work 处理器，可以让您的应用程序更便捷的集成第三方外部程序。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
