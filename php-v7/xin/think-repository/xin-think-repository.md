# xin/think-repository

> 标签: PHP

## 简介

ThinkPHP Repository - 一个用于简化数据库操作的仓库模式实现，支持多种数据库驱动，提供优雅的查询构建器和模型关系管理，适用于ThinkPHP8框架的现代化PHP项目。

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
