# jweiland/replacer

> 标签: TYPO3 CMS, jw, replacer, typo3

## 简介

Replaces string patterns from the page. You can use it to replace URLs for Content Delivery Network (CDN).

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
