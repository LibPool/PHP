# jweiland/form2salesforce

> 标签: TYPO3 CMS, form, integration, salesforce, typo3

## 简介

Send data of form to salesforce API endpoint

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
