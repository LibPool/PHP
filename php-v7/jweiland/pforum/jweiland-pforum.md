# jweiland/pforum

> 标签: TYPO3 CMS, forum, lightweight, pforum, typo3

## 简介

Lightweight forum extension for TYPO3

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
