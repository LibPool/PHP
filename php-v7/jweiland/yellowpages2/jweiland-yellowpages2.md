# jweiland/yellowpages2

> 标签: TYPO3 CMS, directory, industry, typo3, yellowpages

## 简介

Industry directory with frontend self-registration, moderation via signed mail links, EXT:maps2 integration and native FAL uploads for logo and images

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
