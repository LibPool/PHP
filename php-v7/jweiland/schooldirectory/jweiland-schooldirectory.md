# jweiland/schooldirectory

> 标签: School, TYPO3 CMS, directory, schooldirectory, typo3

## 简介

This is a TYPO3 extension to manage schools

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
