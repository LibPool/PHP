# jweiland/glossary2

> 标签: TYPO3 CMS, glossar, glossary2, typo3

## 简介

This TYPO3 extension creates a glossary with A-Z links for you

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
