# jweiland/events2-reserve-connector

> 标签: TYPO3 CMS, event, events2, events2_reserve_connector, reserve, typo3

## 简介

This extension provides extended functionalities for integrating Events2 and Reserve extension.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
