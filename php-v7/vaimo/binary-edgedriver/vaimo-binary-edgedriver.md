# vaimo/binary-edgedriver

> 标签: Browser Testing, acceptance testing, binary, binary downloader, browser driver, composer extension, composer plugin, downloader, edgedriver, microsoft edge automation, test-automation, testing, webdriver

## 简介

Utility for downloading Microsoft Edge Driver binary with browser version detection

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
