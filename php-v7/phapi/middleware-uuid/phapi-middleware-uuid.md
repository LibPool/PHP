# phapi/middleware-uuid

> 标签: middleware, phapi, uuid

## 简介

Phapi UUID middleware generates and adds UUID to request and response for easier debugging.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
