# phapi/cache-nullcache

> 标签: cache, nullcache, phapi

## 简介

Phapi NullCache is a fallback cache package with a fake cache storage.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
