# astrasoftwares/astrapay

> 标签: B2C, c2b, daraja, mpesa, payment, php sdk, safaricom, stk push

## 简介

A complete PHP SDK for Safaricom M-Pesa Integration (STK Push, C2B, and B2C).

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
