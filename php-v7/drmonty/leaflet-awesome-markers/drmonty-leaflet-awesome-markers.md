# drmonty/leaflet-awesome-markers

> 标签: PHP

## 简介

Colorful, iconic & retina-proof markers for Leaflet, based on the Font Awesome/Twitter Bootstrap icons.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
