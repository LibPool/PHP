# drmonty/ekko-lightbox

> 标签: bootstrap, gallery, jquery, lightbox, modal

## 简介

A lightbox gallery plugin for Bootstrap 3 based on the modal plugin

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
