# drmonty/smartmenus

> 标签: dropdown, ui

## 简介

jQuery website menu plugin. Responsive and accessible list-based website menus that work on all devices.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
