# billyljren/easy-qrcode

> 标签: Simple, bacon, easy, generator, laravel, png, qrcode, svg, wrapper

## 简介

Easy QRCode is a QR code generator made for Laravel.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
