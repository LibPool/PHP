# uam/propel-s3object-behavior

> 标签: Behavior, aws, cloud, propel, s3

## 简介

A Propel behavior that allows objects to save a file to AWS S3.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
