# uam/aws-ecs-client

> 标签: ECS, amazon web services, product advertising API

## 简介

PHP client library for the AWS ECommerce Service (Amazon Product Advertising API)

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
