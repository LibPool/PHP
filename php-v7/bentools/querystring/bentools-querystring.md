# bentools/querystring

> 标签: psr-7, psr7, query string, querystring, uri, url

## 简介

Query String manipulation library. PHP 7.1+. No dependency, immutable, PSR-7 compliant.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
