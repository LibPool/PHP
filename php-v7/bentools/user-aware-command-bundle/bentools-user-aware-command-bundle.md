# bentools/user-aware-command-bundle

> 标签: PHP

## 简介

Provides a user value to Doctrine Entities that implements Gedmo Blameable when using Console commands.

按 require.php 推断最低支持 PHP 5；已收录于 php-v5, php-v7, php-v8。
