# grantholle/pear-crypt-diffiehellman

> 标签: PHP

## 简介

A port of Pear's implementation of Diffie-Hellman Key Exchange cryptographic protocol for PHP5

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
