# hansschouten/laravel-pagebuilder

> 标签: laravel, pagebuilder

## 简介

A drag and drop pagebuilder to manage pages in any Laravel project.

按 require.php 推断最低支持 PHP 7；已收录于 php-v7, php-v8。
